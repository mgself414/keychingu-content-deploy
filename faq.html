FAQ — 자주 묻는 질문

외국인 관광객이 서울 여행 전·후로 가장 자주 묻는 질문 20개

📌 입국·비자·여행 준비

한국 입국 시 비자가 필요한가요?
미국·일본·EU·동남아 대부분은 무비자 90일 체류. 다만 2021년부터 K-ETA (전자여행허가) 사전 신청 필수입니다. 출발 72시간 전까지 k-eta.go.kr에서 신청 (약 10,000원, 2년 유효). 2024년부터 일부 국가는 임시 면제 시행 중이니 최신 정보 확인 필수.
여행 베스트 시즌은 언제인가요?
봄 (4월) + 가을 (10월)이 압도적 1순위 — 벚꽃·단풍 + 쾌적한 날씨. 여름(6~8월)은 장마·폭염, 겨울(12~2월)은 영하 추위지만 일루미네이션·스키 매력. 피해야 할 시기: 황금연휴(5월 초·9월 추석·10월 초)는 항공·호텔 가격 2~3배.
한국 돈을 얼마나 환전해야 하나요?
실물 현금은 1일 5~10만원이면 충분. 대부분 카드 결제 + 모바일 페이. 명동·인사동 환전소가 환율 가장 좋음 (공항보다 3~5% 유리). 해외 신용카드(VISA/Master)는 거의 모든 매장 수용, AMEX는 일부 제한.

🚇 교통·이동

공항에서 시내까지 어떻게 가나요?
인천공항 (ICN) → 서울역: 공항철도 직통(43분, 9,500원) 또는 일반(58분, 4,750원). 김포공항(GMP)은 5호선·9호선 직결, 시내까지 30분 / 1,500원. 짐이 많으면 KAL 리무진(17,000원) 또는 카카오T(약 80,000원 콜택시). 자세히: 인천공항 도심이동 풀가이드.
지하철·버스는 어떻게 타나요?
T-money 카드(편의점 4,000원 판매) 충전식이 가장 편함. 지하철·버스·택시·편의점에서 모두 사용. 앱은 네이버 지도 + Subway Korea 추천. 구글맵은 도보·차량은 가능하나 대중교통 라우팅은 부정확. 티머니 외에 신용카드(컨택리스), 삼성/애플페이도 일부 게이트 지원.
택시는 어떻게 부르나요?
카카오T 앱이 표준 (한국판 Uber). 영어 UI 지원, 신용카드 등록 또는 현금. 길거리에서 잡아도 미터제로 OK. 외국인 관광택시(인터내셔널) 콜은 일반보다 20% 비쌈. 팁 문화 없음. 야간(00~04시) 20% 할증.
한국에서 공항·도시 간 이동은?
KTX 고속철도가 표준 — 서울 → 부산 2시간 30분 (59,800원). SRT는 KTX의 사설 운영 (수서출발, 약간 더 저렴). 고속버스는 KTX의 50% 가격이지만 시간 1.5배. 예매: letskorail.com (영어 지원).

📱 통신·결제·실용

인터넷·SIM은 어떻게 하나요?
3가지 옵션: ① 유심 (Prepaid SIM) 4G 무제한 / 5~30일 / 27,500~55,000원 (공항 부스 또는 사전 예약). ② eSIM — 호환 폰만, QR 코드 즉시 활성화. ③ 포켓 와이파이 1일 4,500원, 그룹용. 자세히: 유심·이심·로밍 가이드.
한국에서 음식 배달은?
배달의민족 (Baemin)이 표준 (영어 UI O). 호텔·에어비앤비에서 24시간 배달. 쿠팡이츠는 더 빠르지만 한국어 위주. 외국인 친화는 배민이 우세. 팁 문화 없음. 배달비 2,000~4,000원 별도.
한국어를 못하는데 괜찮나요?
관광 핫스팟(홍대·강남·명동·이태원)은 영어 메뉴·간단 영어 OK. 로컬 식당은 파파고 번역 앱 또는 사진 메뉴 가리키기 OK. 지하철·공항 영어 표기 100%. 비상 시 1330(관광 안내 24h 영어) 또는 112(경찰 영어).
한국 매장에서 결제는?
VISA/Master 신용카드 95% 매장 수용. 일부 노점·재래시장은 현금 전용. 삼성페이·애플페이·카카오페이는 한국 휴대폰 번호 + 한국 카드 필요 (외국인 어려움). 팁 문화 없음. 부가세 포함 가격.

🍴 음식·식당·문화

한국 음식 중 꼭 먹어야 할 것은?
외국인 추천 TOP 5: ① 한국식 BBQ ② 김치찌개 ③ 비빔밥 ④ 한국식 치킨 + 맥주 ⑤ 떡볶이. 보너스: 냉면(여름)·삼계탕·간장게장·길거리 음식(붕어빵·호떡)·한식 디저트(빙수·약과). 자세히: 한식 필수 체험.
식당에서 예약이 필요한가요?
파인다이닝·핫플 카페·BBQ 인기 매장은 예약 필수. 일반 식당은 walk-in OK. 예약 앱: 캐치테이블 (Catch Table)이 표준 (영어 UI 일부, 한국 번호 필요). 한국 번호 없으면 호텔 컨시어지 또는 인스타 DM 예약 추천.
채식·할랄·글루텐 프리 식당은?
이태원·홍대·연남동에 비건·할랄·글루텐 프리 식당 다수. 앱: Happy Cow (비건), Crescent Rating (할랄). 한국 식당 일반은 멸치·새우 육수가 기본이라 사전 확인 필수. 자세히: 비건·할랄 가이드.
한국 매너·문화 주의사항?
① 식사 시 어른 먼저 / ② 술 따를 때 두 손 / ③ 신발 벗기(한옥·찜질방·일부 음식점) / ④ 지하철 우측 통행·정숙 / ⑤ 사진은 사전 동의 / ⑥ 팁 없음 / ⑦ 거리에 흡연 구역 외 금연.

🛍 쇼핑·체험

면세 환급 어떻게 받나요?
30,000원 이상 + 외국인 여권 결제 시 즉시 환급(매장 내) 또는 공항 환급 가능. Global Blue / Global Tax Free 표시 매장. 결제 시 여권 제시 → 영수증 + 환급서 발급. 공항 환급은 출국 게이트 환급 카운터. 자세히 매장 직원에게 "Tax Free" 요청.
K-pop·아이돌 굿즈는 어디서?
홍대 (YG·SM 본사·KT&G 상상마당) + 강남 (SM Town COEX) + 명동 (라인 프렌즈·카카오 프렌즈). 앨범·포토카드는 신촌 현대백화점 영등포 또는 YES24·교보문고 강남. 자세히: K-팝 덕질 가이드.
한복 체험은 어디서?
경복궁·창덕궁 입구 한복 대여(약 15,000~30,000원/4시간). 한복 입으면 궁궐 입장 무료. 북촌 한옥마을 또는 인사동이 대표 포토 스팟. 자세히: 한복 체험 가이드.
찜질방·스파 체험은?
드래곤힐스파 (용산), 스파랜드 (잠실), 한솔찜질방 (홍대)가 외국인 친화. 영업 24시간, 입장 12,000~25,000원, 양머리 수건·식혜·수면실·찜질방·바데풀. 자세히: 찜질방 완벽 가이드.

🛟 비상·실용

응급 상황·관광 안내?
112 (경찰, 영어 가능) / 119 (소방·구급) / 1330 (관광 안내 24h 영어·중국어·일본어). 대사관 비상 연락처는 출국 전 저장 권장. 한국은 응급 진료 매우 빠르고 외국인 의료 보험 처리 가능.
