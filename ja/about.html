About KeyChinGu

初めてソウルを訪れる外国の友人たちに伝えたい、本当の韓国

KeyChinGu とは？

KeyChinGu（Key + Chingu、「友だちになるための鍵」）は、外国人旅行者がソウルをより深く、より正確に楽しめるよう、 1,278本の厳選ガイドを発信する個人運営のメディアプロジェクトです。

弘大（ホンデ / Hongdae / 홍대）、江南（カンナム / Gangnam / 강남）、鍾路（チョンノ / Jongno / 종로）、梨泰院（イテウォン / Itaewon / 이태원）、聖水（ソンス / Seongsu / 성수）、延禧洞（ヨニドン / Yeonhui-dong / 연희동）など8つのエリアを中心に、 カフェ、レストラン、バー、ショッピング、体験、自然、文化のコンテンツを 4言語（韓国語・英語・中国語・日本語）のフルセットで制作しています。

🔍 1,278本のディープダイブ 🎉 + 📚 166本のメタガイド

2026年に8つの軸で外国人のライフサイクルを余すところなくカバーするため、2つのクラスターを運営しています。

  • 🔍 1,278本のディープダイブ 🎉 — 定番の「12選・4軸」パターン（よくある質問6本 + 終日コース3本 + 季節の5軸）。 到着・必須情報144 + 食・飲み物169 + 文化・伝統259 + K-コンテンツ20 + ウェルネス45 + ショッピング76 + ナイトライフ48 + 郊外517。
  • 📚 166本のメタガイド 🎉（100本超のマイルストーン）— 18のセグメント（日本、中国、東南アジア、ヨーロッパ、アメリカ、中東など — 年間15.75M人） + 111のカテゴリー別メタ（韓国料理ディープダイブの8つのサブカテゴリーを含む：粉食（プンシク / bunsik / 분식）、お酒、餅（トック / tteok / 떡）、クッパ（gukbap / 국밥）、韓定食（ハンジョンシク / hanjeongsik / 한정식）、焼肉、麺類、餃子）+ 旅行スタイル別5タイプ + ソウル以外の24都市 + 実用メタ5本（K-ETA、交通、SIM） + 季節のイベント3本（10月のBIFF、7月のチメク、5月の宗廟祭礼 — うち2件はユネスコ関連）。

2件のユネスコ関連項目（700年の歴史を持つ安東（アンドン / Andong / 안동）焼酎、2018年の餅づくり）と、4シーズンのK-デザート完全網羅（春・夏・秋・冬）が軸になっています。

なぜ作ったの？

外国人旅行者は、韓国で次の3つの悩みにたびたび直面します。

  • GoogleとTripAdvisorの限界 — 韓国で地元の人に人気のスポットはNAVERやInstagramにあるのに、外国語の情報が少ない。
  • エリアごとに雰囲気が違う — 弘大（MZ世代）、江南（高級）、鍾路（伝統）、梨泰院（グローバル）。万人向けのおすすめでは誰も満足させられません。
  • 実用的な詳細情報の不足 — 営業時間、支払い方法、外国人への対応のしやすさこそ大切なのに、ガイドブックには載っていません。

KeyChinGu は、4言語のフルセット + エリアごとのキュレーション + 外国人への対応のしやすさの明記で、この3つをまとめて解決します。

🏃 アクティビティ

🛍 ショッピング

外国人に人気のショッピングスポット — 明洞（ミョンドン / Myeongdong / 명동）のコスメ、東大門（トンデムン / Dongdaemun / 동대문）のナイトショッピング、リアルなオリーブヤング購入品、ソウルの文房具＆雑貨。

📚 実用ガイド

到着時に外国人が必要とする実用情報 — SIM、ローミング、交通、ナビゲーション、仁川（インチョン / Incheon / 인천）空港からの移動など。

どんな人に向けたコンテンツ？

  • FIT（個人旅行者） — パッケージツアーではなく、自分のペースでソウルを楽しみたい旅行者。
  • MZ世代（20〜30代） — InstagramやTwitterでホットスポットを見つける、トレンドに敏感な層。
  • リピーター — ソウル2回目・3回目で、明洞や景福宮（キョンボックン / Gyeongbokgung / 경복궁）の先にあるディープなコンテンツを求める人。
  • 長期滞在者 — 日常生活と週末の文化コンテンツが必要な、留学生、デジタルノマド、交換留学生。
