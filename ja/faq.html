📌 入国・ビザ・旅行準備

韓国に入国するのにビザは必要ですか?
多くの国籍の方はビザなしで入国できますが、滞在できる期間はパスポートによって異なります。 K-ETA(電子渡航認証)の取得義務は、2026年1月1日から12月31日まで一時的に免除されています(法務部K-ETAのお知らせ)。免除の対象かどうかは、k-eta.go.kr の申請画面でパスポートをスキャンすると確認できます。 対象外の場合は申請してください。手数料は10,000 KRW、審査には通常最大72時間かかるため、出発の数日前までに申請しましょう。 K-ETAをお持ちでない場合は、到着3日前から e-arrivalcard.go.kr で無料のe-Arrival Cardを提出してください。
旅行のベストシーズンはいつですか?
春(4月)と秋(10月)がいちばんのおすすめです。桜や紅葉が楽しめ、気候も快適です。 夏(6〜8月)は梅雨と暑さがあり、冬(12〜2月)は氷点下になりますが、イルミネーションやスキーが楽しめます。 避けたい時期は長期連休(5月上旬、秋夕(チュソク)、10月上旬)です。航空券やホテルが早々に埋まり、料金も上がります。
両替はどのくらいすればいいですか?
ほとんどの場所でカードが使えます。屋台や市場用に少額の現金を持っておきましょう。 市内の両替所(明洞 (Myeongdong / 명동)、弘大 (Hongdae / 홍대))は空港より良いレートのことが多いので、空港では少額だけ両替するのがおすすめです。 海外発行のクレジットカード(VISA/Master)はほぼどこでも使えますが、AMEXは使える場所が少なめです。

🚇 交通・移動

空港から市内へはどう行けばいいですか?
仁川国際空港 (Incheon Airport / 인천공항、ICN) → ソウル駅 (Seoul Station / 서울역):AREX直通列車(43分、事前予約13,000 KRW、当日購入は18,500 KRW)または一般列車(約59分、T-money利用で4,750 KRW)。 金浦空港 (Gimpo Airport / 김포공항、GMP) は5号線と9号線に直結しています。 荷物が多いときは、空港リムジンバス(17,000 KRW)かKakaoTタクシー(料金は渋滞状況や時間帯によって変わります)をご利用ください。 詳しくはこちら:仁川空港から市内への完全ガイド。
地下鉄とバスの乗り方は?
チャージ式のT-moneyカード(コンビニで4,000 KRW)がいちばん手軽です。地下鉄、バス、タクシー、コンビニで使えます。 アプリはNaver MapまたはKakaoMapがおすすめです。Google Mapsでも場所は表示されますが、乗り換え案内は当てになりません。 チャージは駅の機械かコンビニで。カードでチャージできないこともあるので、現金も用意しておきましょう。
タクシーはどう呼びますか?
KakaoTアプリが定番です(韓国版Uber)。英語表示に対応しており、カード登録も現金払いも選べます。 路上で拾っても問題ありません。すべてメーター制です。 チップの習慣はありません。ソウルの深夜割増は、20%(午後10時〜11時、午前2時〜4時)、40%(午後11時〜午前2時)です。
都市間の移動はどうすればいいですか?
KTX高速鉄道が定番で、ソウル → 釜山 (Busan / 부산) は約2時間30分(一般席54,400 KRW)です。 2026年9月からSRTもKTXの名称で運行されているため、水西 (Suseo / 수서) 発の列車もKTXです。 高速バスはKTXより安いものの、時間はかかります。予約は letskorail.com またはKorailアプリから。

📱 通信・決済・実用情報

インターネット/SIMはどうすればいいですか?
3つの方法があります。① eSIM — たいていいちばんお得です。到着前に有効化しておきましょう。 ② 物理SIM — 空港のブースか市内の店舗で購入できます。③ ポケットWi-Fi — グループ旅行に便利です。 「無制限」プランは、1日のデータ量を超えると速度が落ちることが多いので、プラン内容を確認してください。詳しくはこちら:SIM・eSIM・ローミングガイド。
韓国のフードデリバリーはどう使いますか?
BaeminとCoupang Eatsが主なデリバリーアプリで、ホテルやAirbnbにも届けてもらえます。 アプリによっては韓国のSMS認証が必要です。ホテルのスタッフに手伝ってもらうか、アプリの海外版を使ってください。 チップは不要です。配達料が加算されるのが一般的です。
韓国語が話せなくても大丈夫ですか?
観光の中心エリア(弘大、江南 (Gangnam / 강남)、明洞、梨泰院 (Itaewon / 이태원))には英語メニューがあり、簡単な英語で十分です。 地元の食堂では、翻訳アプリのPapagoを使うか、写真付きメニューを指さして注文しましょう。 地下鉄や空港の案内表示には英語が併記されています。緊急時は、1330(英語対応の24時間観光案内)または112(警察)に電話してください。
韓国の店での支払い方法は?
VISA/Masterのクレジットカードはほぼどこでも使えます。一部の屋台や伝統市場は現金のみです。 Apple Payなどのモバイルウォレットは一部の店でしか使えないため、必ず実物のカードを持ち歩いてください。 チップは不要です。価格にはVAT(付加価値税)が含まれています。

🍴 グルメ・レストラン・文化

絶対に食べるべき韓国料理は?
外国人に人気のトップ5:① 韓国焼肉 ② キムチチゲ (kimchi jjigae / 김치찌개) ③ ビビンバ (bibimbap / 비빔밥) ④ 韓国フライドチキン+ビール ⑤ トッポッキ (tteokbokki / 떡볶이)。 ほかにもおすすめは、冷麺(夏)、参鶏湯、カンジャンケジャン、屋台グルメ(ブンオパン、ホットク)、韓国スイーツ(ピンス、薬菓)。 詳しくはこちら:韓国料理の基本ガイド。
レストランの予約は必要ですか?
ファインダイニング、人気カフェ、人気の焼肉店は予約が必要です。一般的な食堂は予約なしで入れます。 予約アプリはCatch Tableが定番です(一部英語表示、韓国の電話番号が必要)。 韓国の電話番号がない場合は、店頭のタブレットでウェイティングリストに登録するか、ホテルに電話予約を頼みましょう。
ヴィーガン/ハラール/グルテンフリーのレストランはありますか?
梨泰院、弘大、延南洞 (Yeonnam-dong / 연남동)には、ヴィーガン、ハラール、グルテンフリー対応のレストランが多くあります。 アプリは、Happy Cow(ヴィーガン)、Crescent Rating(ハラール)。 韓国料理にはカタクチイワシやエビの出汁がよく使われるので、必ず事前に確認してください。 詳しくはこちら:ヴィーガン・ハラールガイド。
知っておくべき韓国のマナーはありますか?
① 年長者が先に食べる / ② お酒は両手で注ぐ / ③ 靴を脱ぐ(韓屋、チムジルバン、一部の飲食店) / ④ 地下鉄では右側通行で静かに / ⑤ 写真を撮る前に確認する / ⑥ チップは不要 / ⑦ 指定区域以外の路上は禁煙。

🛍 ショッピング・体験

免税(タックスリファンド)の手続きは?
外国人パスポートをお持ちの方は、1店舗あたり15,000 KRW以上の購入が対象です。店頭での即時還付か、空港での還付を受けられます。 Tax Freeの表示がある店でパスポートを提示してください。店頭での還付は、1回の購入につき1,000,000 KRW、1回の旅行につき5,000,000 KRWが上限です。 それを超える還付は、保安検査後の空港キオスクで手続きします。出国するまで商品は未使用のままにしておきましょう。
K-POP/アイドルグッズはどこで買えますか?
弘大、明洞、江南にはK-POPやキャラクターグッズの店があります。行く前に営業しているか確認しましょう。 アルバムやフォトカードは、大型書店やレコード店を探してみてください。 詳しくはこちら:K-POPファンガイド。
韓服 (hanbok / 한복) の試着はどこでできますか?
景福宮 (Gyeongbokgung / 경복궁)と昌徳宮 (Changdeokgung / 창덕궁)の近くにある韓服レンタル店です。韓服(チョゴリに、チマまたはパジ)を着ると、景福宮に無料で入場できます。 北村韓屋村 (Bukchon Hanok Village / 북촌한옥마을)と仁寺洞 (Insadong / 인사동)が定番の撮影スポットです。 詳しくはこちら:韓服体験ガイド。
チムジルバン (jjimjilbang / 찜질방)・スパ体験はどうですか?
大型のチムジルバンを選び、行く前に営業しているかと営業時間を確認してください。 24時間営業のところもあり、羊の頭の形のタオル、シッケ (sikhye / 식혜)、仮眠室、サウナ室、浴場が楽しめます。 詳しくはこちら:チムジルバン完全ガイド。

🛟 緊急時・実用情報

緊急時・観光案内は?
112(警察)/ 119(消防・救急、英語対応)/ 1330(英語・中国語・日本語対応の24時間観光案内)。 出発前に、大使館の緊急連絡先を保存し、海外旅行保険の情報をすぐ出せるようにしておきましょう。
