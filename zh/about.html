KeyChinGu 是什么？

KeyChinGu（Key + Chingu，“成为朋友的钥匙”）是一个个人运营的媒体项目， 发布1,278 篇精选指南，帮助外国游客更深入、更准确地享受首尔。

我们以 8 大区域为中心 — 弘大 (Hongdae / 홍대)、江南 (Gangnam / 강남)、钟路 (Jongno / 종로)、梨泰院 (Itaewon / 이태원)、圣水 (Seongsu / 성수)、延禧洞 (Yeonhui-dong / 연희동)等 — 制作咖啡馆、餐厅、酒吧、购物、体验、自然和文化内容， 并提供韩语、英语、中文、日语四语言完整版。

🔍 1,278 篇深度专题 🎉 + 📚 210 篇主题指南

为了在 2026 年以 8 大主轴完整覆盖外国人的旅行全过程，我们运营两个内容集群：

  • 🔍 1,278 篇深度专题 🎉 — 标准的“12 选 4 轴”模式（6 个 FAQ + 3 条全天路线 + 5 个季节主轴）。 抵达与必备 144 + 餐饮 169 + 文化与传统 259 + K-content 20 + 身心疗愈 45 + 购物 76 + 夜生活 48 + 近郊 517。
  • 📚 210 篇主题指南 🎉（突破 100+ 的里程碑）— 18 个客源细分（日本、中国、东南亚、欧洲、美国、中东等 — 每年 15.75M） + 155 个类别主题（包括 8 个韩国美食深度子类别：粉食 (Bunsik / 분식)、酒类、年糕 (Tteok / 떡)、汤饭 (Gukbap / 국밥)、韩定食 (Hanjeongsik / 한정식)、烤肉、面食、饺子）+ 5 种同行类型 + 24 个首尔以外的城市 + 5 个实用主题（K-ETA、交通、SIM卡） + 3 个季节性活动（10 月的 BIFF、7 月的炸鸡啤酒 (Chimaek / 치맥)、5 月的宗庙祭礼 (Jongmyo Jerye / 종묘제례) — 其中 2 项为联合国教科文组织遗产项目）。

以 2 项联合国教科文组织遗产（有 700 年历史的安东 (Andong / 안동) 烧酒、2018 年的制作年糕）为支点，并全面覆盖四季 K-dessert（春、夏、秋、冬）。

我们为什么要做它？

外国游客在韩国经常遇到三个痛点：

  • Google 和 TripAdvisor 的局限 — 韩国当地人气的地方都在 Naver 和 Instagram 上，但外语信息很少。
  • 每个区域的氛围都不同 — 弘大（MZ 世代）、江南（奢华）、钟路（传统）、梨泰院（国际化）。千篇一律的推荐让谁都不满意。
  • 缺少实用细节 — 营业时间、支付方式、对外国人是否友好才是关键，但旅游指南书里往往没有。

KeyChinGu 以四语言完整版 + 分区域精选 + 明确标注对外国人的友好程度一次解决这三个问题。
