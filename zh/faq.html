📌 入境 · 签证 · 行前准备

入境韩国需要签证吗？
许多国籍的游客可以免签入境，可停留多久取决于您的护照。 K-ETA（电子旅行许可）在2026年1月1日至12月31日期间暂时免除（法务部K-ETA公告）。要确认免除是否适用于您，请在k-eta.go.kr申请页面扫描护照。 如果不适用，请申请 — 费用为10,000韩元，审核通常最长需要72小时，因此请在出发前几天申请。 如果没有K-ETA，请在抵达前3天起通过e-arrivalcard.go.kr提交免费的e-Arrival Card（电子入境卡）。
什么时候是最佳旅行季节？
春季（4月）+ 秋季（10月）是首选 — 有樱花、红叶，天气宜人。 夏季（6–8月）有雨季和高温；冬季（12–2月）气温在零度以下，但有灯饰和滑雪。 需避开：长假期（5月初、中秋节、10月初），这期间机票和酒店很早就会订满，价格也会上涨。
应该换多少钱？
大多数地方可以刷卡 — 请携带少量现金，用于路边摊和市场。 市内的换汇处（明洞 (Myeongdong / 명동)、弘大 (Hongdae / 홍대)）汇率通常比机场更好，所以在机场只换一点即可。 外国信用卡（VISA/Master）几乎到处都能用；AMEX则较少被接受。

🚇 交通 · 出行

如何从机场前往市区？
仁川机场 (Incheon Airport / 인천공항)（ICN）→ 首尔站：AREX直达列车（43分钟，提前预订13,000韩元；现场购票18,500韩元）或普通列车（约59分钟，使用T-money 4,750韩元）。 金浦机场 (Gimpo Airport / 김포공항)（GMP）与5号线和9号线直接相连。 行李较多时，请乘坐机场利木津巴士（17,000韩元）或KakaoT出租车（车费取决于路况和时段）。 更多：仁川机场进城完整指南。
如何乘坐地铁和公交？
可充值的T-money卡（便利店售价4,000韩元）最方便 — 可用于地铁、公交、出租车，也可在便利店使用。 App方面，请使用Naver Map或KakaoMap。Google Maps可以显示地点，但其公共交通路线规划不可靠。 可在车站的机器或便利店充值 — 请备一些现金，因为不一定能用银行卡充值。
如何叫出租车？
KakaoT App是标准选择（韩国的Uber）。它有英文界面；可绑定银行卡或用现金支付。 在路边招手拦车也可以 — 全部按计价器收费。 没有给小费的文化。首尔深夜加价：20%（晚上10–11点和凌晨2–4点），40%（晚上11点至凌晨2点）。
如何在城市之间出行？
KTX高速铁路是标准选择 — 首尔 → 釜山 (Busan / 부산)约2小时30分钟（54,400韩元，标准座）。 自2026年9月起，SRT列车以KTX的名义运行，因此从水西 (Suseo / 수서)出发的列车也是KTX。 高速巴士比KTX便宜，但耗时更长。请在letskorail.com或Korail App预订。

📱 网络 · 支付 · 实用信息

如何上网 / 获取SIM卡？
三种选择：① eSIM — 通常性价比最高；请在落地前激活。 ② 实体SIM卡 — 可在机场柜台或市内门店购买。③ 随身Wi-Fi — 适合团体使用。 “无限流量”套餐往往在达到每日流量上限后会降速 — 请确认套餐内容。更多：SIM卡 · eSIM · 漫游指南。
韩国的外卖是怎么运作的？
Baemin和Coupang Eats是主要的外卖App，可以送到酒店和Airbnb。 部分外卖App需要韩国短信验证 — 请向酒店求助，或使用App的国际版。 不需要小费。通常会另加配送费。
我不会说韩语 — 没问题吗？
热门旅游区（弘大、江南 (Gangnam / 강남)、明洞、梨泰院 (Itaewon / 이태원)）有英文菜单，基础英语就够用。 在本地餐厅，请使用Papago翻译App，或指着图片菜单点餐。 地铁和机场的标识都带有英文。遇到紧急情况，请拨打1330（24小时英语旅游咨询）或112（警察）。
韩国商店的支付是怎么运作的？
VISA/Master信用卡几乎到处都能用。部分路边摊和传统市场只收现金。 Apple Pay等手机钱包只在部分商店可用 — 请务必随身带一张实体卡。 没有给小费的文化。价格已含增值税（VAT）。

🍴 美食 · 餐厅 · 文化

有哪些韩国美食必吃？
外国游客的前5名：① 韩式烤肉 ② 泡菜汤 ③ 拌饭 ④ 韩式炸鸡配啤酒 ⑤ 炒年糕。 另有：冷面（夏季）、参鸡汤、酱油蟹、街头小吃（鲫鱼饼、糖饼）、韩式甜点（刨冰、药果）。 更多：韩国美食必吃指南。
需要预订餐厅吗？
高档餐厅、热门咖啡馆和人气烤肉店需要预订。普通餐厅可直接入店。 预订App：Catch Table是标准选择（部分界面有英文，需要韩国手机号）。 没有韩国手机号的话，可在门口的平板电脑上排队候位，或请酒店电话代订。
有纯素 / 清真 / 无麸质的餐厅吗？
梨泰院、弘大和延南洞 (Yeonnam-dong / 연남동)有很多纯素、清真和无麸质餐厅。 App：Happy Cow（纯素）、Crescent Rating（清真）。 请注意，韩国菜常用凤尾鱼或虾熬的高汤，所以务必提前确认。 更多：纯素 · 清真指南。
有哪些韩国礼仪需要了解？
① 长辈先用餐 / ② 双手斟酒 / ③ 脱鞋（韩屋、汗蒸房、部分餐厅） / ④ 在地铁上靠右站立并保持安静 / ⑤ 拍照前先征得同意 / ⑥ 不给小费 / ⑦ 除指定区域外，街头禁止吸烟。

🛍 购物 · 体验

如何办理退税？
持外国护照，单店消费满15,000韩元即可退税 — 可在店内即时退税，也可在机场退税。 请认准Tax Free标志并出示护照。店内退税上限为每笔购物1,000,000韩元、每次旅行5,000,000韩元。 金额更大的退税需在通过安检后到机场的自助机办理。离境前请保持商品未使用。
哪里可以买K-pop / 爱豆周边？
弘大、明洞和江南有K-pop和卡通形象周边商店 — 去之前请确认店铺是否营业。 专辑和小卡可以去大型书店和唱片店看看。 更多：K-pop粉丝指南。
哪里可以试穿韩服？
景福宫 (Gyeongbokgung / 경복궁)和昌德宫 (Changdeokgung / 창덕궁)附近的韩服租赁店。穿着韩服（上衣加裙子或裤子）可免费进入景福宫。 北村韩屋村 (Bukchon Hanok Village / 북촌한옥마을)和仁寺洞 (Insadong / 인사동)是经典的拍照地点。 更多：韩服体验指南。
汗蒸房 / 水疗体验怎么样？
请选择大型汗蒸房，并在出发前确认是否营业及营业时间。 有些24小时营业 — 可以体验羊头巾、食醢、睡眠室、桑拿房和浴池。 更多：汗蒸房完整指南。

🛟 紧急情况 · 实用信息

紧急情况 · 旅游咨询？
112（警察）/ 119（消防·救护，提供英语服务）/ 1330（24小时旅游咨询，提供英语、中文、日语服务）。 出发前请保存您所在国大使馆的紧急联系方式，并备好旅行保险信息。
