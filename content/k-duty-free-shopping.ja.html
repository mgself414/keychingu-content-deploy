🎯 誰のための回か

韓国を出る前に、化粧品・香水・腕時計・バッグを税金なしで買いたい旅行者のための回です。まず、2つの制度を分けておきます。

  • 免税店 (Duty Free / 면세점): 出国する人に、関税・付加価値税を除いて売る店です。市内免税店で支払うと商品の代わりに交換券をもらい、出国日に空港の引渡場で商品を受け取ります(ロッテ免税店 (Lotte Duty Free / 롯데면세점) 公式利用案内)。
  • タックスリファンド (Tax Refund / 택스리펀) (Tax Free・Tax Refund): デパートやオリーブヤング (Olive Young / 올리브영) のような一般の店で買った商品の付加価値税を返してもらう制度です。商品はその場で持って出ます。レジでその場で税金を引く即時還付 (Immediate Refund / 즉시환급) と、伝票をもらって市内のブースや空港で受け取る事後還付 (After-Purchase Refund / 사후환급) があります。

この回では、免税店13軒の場所・時間と、2つの制度の数字のルールを1枚にまとめました。市内免税店の選び方は#915、タックスリファンドの3つの経路の比較は#1231に、より詳しくあります。

⚠ 表記の原則: 店舗の住所・営業時間は、各免税店の公式店舗ページの値です(2026-11-24確認)。営業状態はカカオマップ (Kakao Map / 카카오맵) で「営業中」を確認しました(2026-11-24)。仁川空港店は運営会社ごとにターミナル1か所(ロッテT1、新羅T2)だけをカカオマップで確認し、残りのターミナルは公式店舗ページの値です。ブランド店舗ごとに閉店時間が異なる場合があると、ロッテ免税店が店舗ページに書いています。割引率・景品・為替レートはたびたび変わるので載せていません。

📋 先に知っておきたいルール

免税店のルール

  • 誰が買えるか: 海外へ出国する人なら、韓国人・外国人どちらも買えます。済州を含む国内旅行では買えません(ロッテ免税店公式利用案内、2026-11-24閲覧)。
  • 何を持っていくか: 店には、本人のパスポートと出国情報が見える航空券(E-ticket)を持っていきます。新羅免税店 (Shilla Duty Free / 신라면세점) は、出国日の60日前から買えると案内しています(新羅免税店公式ショッピングガイド、2026-11-24閲覧)。インターネット免税店では注文書にパスポートと出入国情報を入力しますが、間違えると商品を受け取れません(ロッテ免税店ショッピング手順)。
  • いくらまで買えるか: 出国するときの免税品の購入限度額は、韓国人・外国人どちらもありません(ロッテ免税店公式利用案内)。米ドル800ドルの免税限度は、韓国に入国するときに適用される値です。自分の国に入るときの限度は、その国の基準を別に確認してください。
  • どこで受け取るか: 市内・インターネットで買った商品は、出国日に指定の引渡場 (Pickup Counter / 인도장) で受け取ります。引渡場では、交換券・実物のパスポート・搭乗券を見せ、パスポート情報が合っているか確認を受けてから受領サインをします。ロッテ免税店は、出国の1時間前に引渡場に来るよう案内しています。出国日から15日たっても受け取らないと、注文はキャンセルされます(ロッテ免税店公式引渡場案内・利用案内、2026-11-24閲覧)。新羅・新世界 (Shinsegae / 신세계)・現代 (Hyundai / 현대) で買った商品は、各運営会社の引渡場案内に従います。この回に載せた引渡場の場所は、ロッテ免税店の基準です。引渡場を探す順序は#1332。

空港・港湾での還付 滞在中の購入金額に上限なし。カード・アリペイ・ウィーチャットで受け取ると1~2か月かかる 韓国観光公社、2025-10-21更新
  • 即時還付は、支払うときにパスポートを出すと、税金を引いた値で決済されます。一度に100万ウォン以上、または合計が500万ウォンを超えると、即時還付の代わりに伝票をもらい、市内のブースや空港で受け取ります。
  • 事後還付は、空港・港湾で受け取る道が基本です。順序は ① チェックインして搭乗券をもらう(預け荷物はまだ預けない) ② 買った物と還付伝票を税関職員に見せて、持ち出し確認印 (Export Stamp / 반출확인 도장) をもらう ③ 預け荷物を預ける ④ 最寄りの還付カウンターかキオスクで、パスポートと伝票を出して還付を申請する、です。現金での還付は、保安検査のあと免税エリアで受け取ります(韓国観光公社)。画面の順序は#1304。
  • 新品・未開封・未使用の状態でないと、持ち出し確認も還付も受けられません(韓国観光公社、2025-10-21更新)。
  • 領収書1枚が600万ウォンを超えると、市内のブースでは受け取れず、空港・港湾でのみ還付を受けられます(韓国観光公社)。
  • 免税店で買った物は、すでに税金が引かれているので、タックスリファンドの対象ではありません。

🏙 ソウル市内免税店 — 5軒

1. ロッテ免税店 ミョンドン本店 (Lotte Duty Free Myeongdong Main / 롯데면세점 명동본점)

ロッテ百貨店 (Lotte Department Store / 롯데백화점) 本店の建物の9~12階です。住所はチュン区 (Jung-gu / 중구)のウルチ路30 (Eulji-ro 30 / 을지로 30)、時間は09:30~20:00です。ロッテ免税店は、ブランドごとに店舗運営とショッピングの終了時間が異なると書いています。店舗の電話は02-759-6600、代表電話は1688-3000です(ロッテ免税店公式店舗ページ)。カカオマップは同じ建物をナムデムン路81 (Namdaemun-ro 81 / 남대문로 81)と表記しています。最寄り駅はウルチロイック駅 (Euljiro Ipgu / 을지로입구역)(2号線)です。

2. ロッテ免税店 ワールドタワー店 (Lotte Duty Free World Tower / 롯데면세점 월드타워점)

ロッテワールドタワー (Lotte World Tower / 롯데월드타워) の隣、エビニュエル チャムシル店 (Avenuel Jamsil / 에비뉴엘 잠실점) 8・9階です。住所はソンパ区 (Songpa-gu / 송파구)のオリンピック路300 (Olympic-ro 300 / 올림픽로 300)、時間は10:30~19:30です。店舗の電話は02-3213-3700です(ロッテ免税店公式店舗ページ)。最寄り駅はチャムシル駅 (Jamsil / 잠실역)(2・8号線)です。市内5軒のなかで最も早い19:30に閉まるので、夕方の予定の前に行きます。

3. 新羅免税店 ソウル店 (Shilla Duty Free Seoul / 신라면세점 서울점)

新羅ホテル (Shilla Hotel / 신라호텔) の隣にあります。住所はチュン区のトンホ路249 (Dongho-ro 249 / 동호로 249)、時間は09:30~20:00で、年中無休です。代表電話は1688-1110です。3号線トンデイック駅 (Dongdaeipgu / 동대입구역) の5番出口から新羅ホテルの正門へ行き、ホテルのシャトルバスに乗ります。タクシーで来た場合は、タクシーのレシートを外の案内デスクに出すと、当日型プリペイドカード10,000ウォンをもらえます(月1回)。駐車は購入に関係なくバレーパーキングができ、料金は別です(新羅免税店公式店舗ページ)。

4. 新世界免税店 ミョンドン店 (Shinsegae Duty Free Myeongdong / 신세계면세점 명동점)

新世界百貨店 (Shinsegae Department Store / 신세계백화점) 本店の8~12階です。住所はチュン区のテゲ路77 (Toegye-ro 77 / 퇴계로 77)です。時間は月~木 10:30~20:00、金~日と祝日 10:30~20:30です。4号線フェヒョン駅 (Hoehyeon / 회현역) の7番出口を出ます。電話相談は1661-8778(毎日09:00~18:00)です(新世界免税店公式店舗ページ)。ロッテ ミョンドン本店と同じチュン区 (Jung-gu / 중구)なので、1日の予定にいっしょに入れられます。

5. 現代免税店 貿易センター店 (Hyundai Duty Free Trade Center / 현대면세점 무역센터점)

現代百貨店 貿易センター店 (Hyundai Department Store Trade Center / 현대백화점 무역센터점) の建物の8・9階です。住所はカンナム区 (Gangnam-gu / 강남구)のテヘラン路517 (Teheran-ro 517 / 테헤란로 517)です。時間は月~木 10:30~20:00、金~日 10:30~20:30で、年中無休です。2号線サムソン駅 (Samseong / 삼성역) の5番出口が、百貨店の地下1階に直結しています。9階にメンバーシップ・団体デスクがあります。代表電話は1811-6688です(現代免税店公式店舗ページ)。

🌊 釜山・済州市内免税店 — 3軒

6. ロッテ免税店 釜山店 (Lotte Duty Free Busan / 롯데면세점 부산점)

ソミョン (Seomyeon / 서면) のロッテ百貨店 釜山店 (Lotte Department Store Busan / 롯데백화점 부산점) 8階です。住所はプサンジン区 (Busanjin-gu / 부산진구)のカヤ大路772 (Gaya-daero 772 / 가야대로 772)、時間は10:30~19:30です。店舗の電話は051-810-3880です(ロッテ免税店公式店舗ページ)。最寄り駅はソミョン駅 (Seomyeon / 서면역)(釜山1・2号線)です。金海空港から発つ日に合わせて買うと、ロッテの引渡場は金海国際空港 (Gimhae International Airport / 김해국제공항) 2階の12・13番ゲートの向かいにあります(06:00~22:00、ロッテ免税店引渡場案内)。

7. ロッテ免税店 済州店 (Lotte Duty Free Jeju / 롯데면세점 제주점)

チェジュ市 (Jeju-si / 제주시) のヨンドン (Yeon-dong / 연동) にあります。住所はトリョン路83 (Doryeong-ro 83 / 도령로 83)、時間は10:00~19:00です。店舗の電話は064-793-3000です(ロッテ免税店公式店舗ページ)。済州から他の地域へ行く国内線の乗客は買えません。海外へ発つ人だけが買えます(ロッテ免税店公式利用案内)。ロッテの引渡場は、済州国際空港 (Jeju International Airport / 제주국제공항) 3階の出入国管理の奥にあります(05:30~22:00、ロッテ免税店引渡場案内)。

8. 新羅免税店 済州店 (Shilla Duty Free Jeju / 신라면세점 제주점)

ロッテ済州店と同じヨンドン (Yeon-dong / 연동) にあります。住所はチェジュ市のノヨン路69 (Noyeon-ro 69 / 노연로 69)、時間は10:00~19:00で、年中無休です。代表電話は1688-1110です。ハルラ病院 (Halla Hospital / 한라병원) のバス停に、202・251・282番などの一般バスが停まります(新羅免税店公式店舗ページ)。国内線だけに乗る日程なら買えない点は、ロッテ済州店と同じです。

✈ 空港免税店 — 5軒

空港免税店は、出国審査を終えてからでないと入れません。市内で買った商品を受け取る引渡場も、出国審査のあとにあります。

9. ロッテ免税店 仁川空港店 (Lotte Duty Free Incheon Airport / 롯데면세점 인천공항점) (T1・T2)

第1旅客ターミナル3階(コンハン路272 (Gonghang-ro 272 / 공항로 272))と第2旅客ターミナル3階(第2ターミナル大路446 (Terminal 2-daero 446 / 제2터미널대로 446))にあります。どちらのターミナルも06:30~21:30に開き、年中無休です。21:30~06:30には夜間店舗が開きます。T1の主な店舗は11・29・34・117番ゲート付近、T2は245・248・249・251~253・255番ゲート付近です(ロッテ免税店公式店舗ページ)。ロッテT1の引渡場は、東側(11番ゲート向かいの4階、05:30~)と西側(45番ゲート向かいの4階、04:30~)、搭乗棟(シャトルトレインを降りて119番ゲートの4階、04:30~)にあります。T2は東側(274番ゲート方面、韓国伝統文化センター (Korean Traditional Culture Center / 한국전통문화센터)(東館) の向かいのエスカレーターで下の階へ、05:00~)と西側(225番ゲート方面、韓国伝統文化センターの向かいのエスカレーターで下の階へ、05:00~)です(ロッテ免税店引渡場案内)。

10. 新羅免税店 仁川空港店 (Shilla Duty Free Incheon Airport / 신라면세점 인천공항점) (T1・T2)

T1(コンハン路272 (Gonghang-ro 272 / 공항로 272))とT2(第2ターミナル大路446 (Terminal 2-daero 446 / 제2터미널대로 446)、新羅の公式ページはコンハン路446 (Gonghang-ro 446 / 공항로 446)と表記)のどちらも06:30~21:30です。主な店舗は、T1は1番出発ロビーと11番ゲート付近、T2は2番出発ロビーと251番ゲート付近で探します(新羅免税店公式店舗ページ)。カカオマップのT2の登録時間は06:50からで公式の値と異なるため、この回は公式の値を載せました。

11. ロッテ免税店 金浦空港店 (Lotte Duty Free Gimpo Airport / 롯데면세점 김포공항점)

金浦空港の国際線ターミナル (International Terminal / 국제선청사) 3階(カンソ区 (Gangseo-gu / 강서구)のハヌル路38 (Haneul-gil 38 / 하늘길 38))です。時間は06:10~20:30です。店舗の電話は02-2669-6705です(ロッテ免税店公式店舗ページ)。金浦空港から国際線で発つときに使います。ロッテの引渡場は、国際線34番ゲートの向かいからエスカレーターで上の階へ上がった所にあります(07:00~20:00、その日の運航時間によって変わります)。

12. ロッテ免税店 金海空港店 (Lotte Duty Free Gimhae Airport / 롯데면세점 김해공항점)

金海国際空港の国際線ターミナル (International Terminal / 국제청사) 2階(釜山カンソ区 (Gangseo-gu / 강서구)のコンハンジニプ路108 (Gonghang-jinip-ro 108 / 공항진입로 108))です。時間は06:30~21:30です。店舗の電話は051-979-1900です(ロッテ免税店公式店舗ページ)。カカオマップ基準の最寄り駅は、釜山金海軽電鉄の空港駅 (Airport / 공항역) です。

13. ロッテ免税店 済州空港店 (Lotte Duty Free Jeju Airport / 롯데면세점 제주공항점)

済州国際空港 (Jeju International Airport / 제주국제공항) 3階の国際線出発ロビー (International Departures / 국제선 출국장)(チェジュ市のコンハン路2 (Gonghang-ro 2 / 공항로 2))です。時間は06:00~22:00です。店舗の電話は064-798-4000です(ロッテ免税店公式店舗ページ)。済州空港から国際線で発つときだけ使います。

A. ミョンドンの1日 (ソウル出国の前日)

  2. 昼食のあと 新世界免税店 ミョンドン店 (Shinsegae Duty Free Myeongdong / 신세계면세점 명동점)(10:30~)。金~日は20:30まで開いている
  3. 午後 オリーブヤング・百貨店で一般のショッピング。Tax Free表示を見て、支払うときにパスポートを出して即時還付を受ける(1回100万ウォン未満)
  4. 出国日 空港の引渡場で交換券・パスポート・搭乗券を見せて、免税品を受け取る

B. カンナム・チャムシルの半日

  1. 午前 現代免税店 貿易センター店 (Hyundai Duty Free Trade Center / 현대면세점 무역센터점)(10:30~、サムソン駅 (Samseong / 삼성역) 5番出口)
  2. 午後 ロッテ免税店 ワールドタワー店 (Lotte Duty Free World Tower / 롯데면세점 월드타워점)(~19:30)。チャムシル駅 (Jamsil / 잠실역) まで2号線で直接行く

⚠ よくある失敗 3

  1. パスポートなしで市内免税店に行く — 店では、本人のパスポートと出国情報が見える航空券(E-ticket)を確認します(新羅免税店ショッピングガイド)。携帯電話にE-ticketを保存しておきます。
  2. 引渡場に出国の直前に行く — 出国当日の引渡場は混んでいます。ロッテ免税店は出国の1時間前に来るよう案内しています。英語の氏名・パスポート番号が注文情報と違うと、商品を受け取れません(ロッテ免税店引渡場案内)。
  3. 即時還付の限度を忘れる — 店舗での即時還付は、税額を含む1回100万ウォン未満、入国後の合計500万ウォン以下です(特例規定 第6条②)。超えたら伝票をもらい、市内のブースや空港で事後還付として処理します。領収書1枚が15,000ウォンより少ないと、タックスリファンドは受けられません(韓国観光公社)。

⚙ FAQ 3

  1. 市内免税店と空港免税店、どちらで買う? — 市内免税店は、店が広く、時間に余裕があるときに選ぶのがよいです。ただし商品は出国日に引渡場で受け取ります。空港免税店は、出国審査のあとすぐ持って搭乗します。
  2. 韓国に住む外国人も免税店で買える? — 免税店は、海外へ出国する人なら韓国人・外国人どちらも買えます(ロッテ免税店)。タックスリファンドは、韓国滞在6か月未満の外国人が対象です(韓国観光公社)。
  3. 免税店で買った物もタックスリファンドを受けられる? — いいえ。免税店の価格は、すでに税金が引かれた値です。タックスリファンドは、一般の店でTax Free表示を見て買った物にだけ受けられます。還付の経路ごとの条件は#1231。
