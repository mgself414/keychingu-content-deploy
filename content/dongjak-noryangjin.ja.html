銅雀 (トンジャク) ・鷺梁津 (ノリャンジン) は、銅雀区 (トンジャクク) の韓国No.1水産市場・考試村・青年文化をディープダイブできるエリアです。ノリャンジン水産市場 (노량진수산시장) (1971年開業、韓国最大・No.1水産市場) + ノリャンジン考試村 (노량진 고시촌) (韓国No.1の試験予備校街、韓国ドラマの定番舞台) + ノリャンジンカップ飯通り (노량진 컵밥 거리) + 国立ソウル顕忠院 (국립서울현충원) (韓国報勲No.1) + サダン (사당) ・イス (이수) (外国人居住・乗り換え駅) がこのエリアに凝縮されています。外国人のVlogやInstagramで最も頻繁に言及される韓国の市場・青年文化No.1の場所です。

ホンデ (홍대) (MZ世代・インディー)・カンナム (강남) (ラグジュアリー)・イテウォン (이태원) (グローバル) と比較すると、銅雀 (トンジャク) ・鷺梁津 (ノリャンジン) は市場・試験・青年・報勲の結びつきが強いです。外国人観光客の動線上、カンナム (강남) ・ホンデ (홍대) に隠れて見過ごされがちですが、ノリャンジン水産市場 (노량진수산시장) は外国人Vlogで1位 (BBC・CNN・日本のNHKなど海外メディアの定番 + 外国人VloggerのInstagramで1位) + ノリャンジン考試村 (노량진 고시촌) は韓国ドラマ「SKYキャッスル (스카이캐슬) 」・「梨泰院クラス (이태원클라쓰) 」・「ミセン (미생) 」などの定番舞台 = 外国人が韓国文化をディープダイブするのに最適な場所です。

特にノリャンジン水産市場 (노량진수산시장) (現新築2016年 + 旧1971年) は、韓国の産地直送水産物の卸売・小売No.1の場所です。早朝03時～05時の競り・朝の即席刺身・昼の海鮮丼は、外国人のInstagram・Vlogで不動のホットスポットNo.1です。ノリャンジン考試村 (노량진 고시촌) は毎年50万人以上の韓国の若者が集まる、韓国社会の一断面を見せるエリアです。#138 ホンデ (홍대) ・#173 ソチョ (서초) ・#174 ソウル大学 (서울대) ・#178 クァンジン (광진) ・#180 クロ (구로) ・カサン (가산) に続き、ISSUE 03 ⑲編 — キーチング (KeyChinGu) 初の銅雀区 (トンジャクク) 進出 (82件のクラスター)。

⚠ 外国人がよくする3つの間違い

1. 「ノリャンジン水産市場 (노량진수산시장) = ただの市場」 — 早朝競り・即席刺身の価値を認識していない

外国人観光客の動線上で最もよくある間違いです。ノリャンジン水産市場 (노량진수산시장) を単なる「市場」と認識していますが、実際には韓国No.1の水産卸売・小売市場です。早朝03時～05時の競り (外国人入場OK、無料) + 朝06時～10時の即席刺身・海鮮丼 + 昼11時～14時は外国人観光客のホットゾーンとなります。外国人Vlog・InstagramでNo.1のホットスポット。BBC・CNN・NHKなど海外メディアの定番舞台。韓国の海鮮をディープダイブするならここが1位です。

2. 「ノリャンジン考試村 (노량진 고시촌) = 韓国の予備校だけ」 — 韓国ドラマの定番舞台としての価値を認識していない

ノリャンジン考試村 (노량진 고시촌) (ノリャンジン予備校街) は単なる予備校街ではなく、韓国ドラマの定番舞台です。「SKYキャッスル (스카이캐슬) 」・「ミセン (미생) 」・「梨泰院クラス (이태원클라쓰) 」・「チーズ・イン・ザ・トラップ (치즈 인 더 트랩) 」など、韓国の青年・青春ドラマに多数PPL (プロダクトプレイスメント) されています。ノリャンジンカップ飯通り (노량진 컵밥 거리) は韓国の青年文化No.1の場所です。韓国ドラマファンがディープダイブするならここが1位です。

3. 「サダン (사당) ・イス (이수) = ただの乗り換え駅」 — 外国人居住・青春エリアとしての価値を認識していない

銅雀 (トンジャク) ・鷺梁津 (ノリャンジン) の風景

銅雀 (トンジャク) ・鷺梁津 (ノリャンジン) は、銅雀区 (トンジャクク) の中心部に位置する韓国No.1水産市場・考試村 (試験準備生が集まるエリア) ・青年・報勲が融合したエリアです。1971年のノリャンジン水産市場 (노량진수산시장) 開業 + 1980年代のノリャンジン予備校街の台頭 + 1955年の国立ソウル顕忠院 (국립서울현충원) 造成 + サダン (사당) ・イス (이수) の乗り換え駅周辺の青春エリアとして、韓国社会の一断面をディープダイブできるNo.1の場所です。

⚙ FAQ (8項目)

Q1. ノリャンジン水産市場 (노량진수산시장) の外国人入場時間?

24時間OK — 早朝03時～05時競り (外国人無料入場OK、韓国外国人Vlogで1位) / 朝06時～10時即席刺身・海鮮丼 / 昼11時～14時外国人観光客ホットゾーン。1・9号線ノリャンジン駅 (노량진역) 徒歩5分。

Q2. ノリャンジン水産市場 (노량진수산시장) の即席刺身の価格?

1人 ₩25,000～45,000 (約2,650～4,750円) (卸売価格 + 即席刺身)。早朝・朝の産地直送刺身。シンナムドゥ水産 (신남도수산) ・ソンソンジャン (손선장) など店舗により価格交渉OK。外国人価格交渉フレンドリー + 英語一部OK。

Q3. ノリャンジン考試村 (노량진 고시촌) の韓国ドラマ舞台はどこ?

ノリャンジン駅 (노량진역) 1番出口 → 銅雀大路 (トンジャクデロ) → 予備校街1.5km — 「SKYキャッスル (스카이캐슬) 」(エデュビッグバン)・「ミセン (미생) 」(会社員青年)・「梨泰院クラス (이태원클라쓰) 」(パク・セロイ青年)・「チーズ・イン・ザ・トラップ (치즈 인 더 트랩) 」など、韓国の青年ドラマの定番舞台。ノリャンジンカップ飯通り (노량진 컵밥 거리) (予備校街に隣接) = 韓国青年文化1位。

Q4. 銅雀 (トンジャク) ・鷺梁津 (ノリャンジン) の外国人フレンドリーな店舗は?

シンナムドゥ水産 (신남도수산) ・ケダンチプ (계단집) ・ペクソジョン イス (백소정 이수) ・ジャン・ブランジェリー (쟝블랑제리) ・ノドゥルソットゥッコン (노들솥뚜껑) は英語メニュー + カード決済 + 外国人フレンドリーが標準です。ノリャンジン水産市場 (노량진수산시장) の即席刺身は韓国語が主ですが、価格交渉 + 店員のフレンドリーさはOKです。

Q5. 国立ソウル顕忠院 (국립서울현충원) の外国人入場は?

無料 + 09:00～18:00 — 外国人自由入場OK。春4月の桜の名所1位 (外国人Instagram) + 韓国の報勲・戦争の歴史をディープダイブ。4・9号線ドンジャク駅 (동작역) 徒歩5分。

Q6. ノリャンジン (노량진) + ヨイド (여의도) + サダン (사당) の動線は?

ノリャンジン (노량진) (1・9号線) → ヨイド (여의도) (9号線1駅) → サダン (사당) (4号線乗り換え) → カンナム (강남) (2号線乗り換え)。ノリャンジン (노량진) + ヨイド (여의도) 漢江 (ハンガン) + サダン (사당) 居酒屋 = 1日フルデイ。

Q7. ノリャンジン水産市場 (노량진수산시장) で韓国式刺身を食べる方法は?

1段階: 1階の卸売店で刺身を購入 (価格交渉、通常1人 ₩30,000～50,000 (約3,150～5,300円)) → 2段階: 2階の食堂街へ移動 → 3段階: 食堂でメウンタン (辛い魚介鍋) ・パンチャン (おかず、無料の付け合わせ) ・ソジュ (韓国焼酎、16~25度) を追加注文 (席料 + メウンタン 1人 ₩1,000～10,000 (約100～1,050円))。外国人フレンドリーなガイドがあります。

Q8. ノリャンジン (노량진) の夜間の安全性は?

24時間安全 — ノリャンジン水産市場 (노량진수산시장) は24時間営業 + 考試村 (고시촌) は若者で活気があり + CCTV・私服警察が標準。外国人夜間VlogもOK。深夜以降はカカオタクシー (Kakao Taxi) の利用をおすすめします。
