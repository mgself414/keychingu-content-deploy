🎯 왜 자갈치 + 국제시장 + BIFF 가이드인가

부산 자갈치 시장 (Jagalchi Market) = 한국 #1 수산시장·1945년~ 80년+. 국제시장 (Gukje Market) = 한국 #2 시장 (광장시장 다음)·BIFF 광장 cluster·1950년~. 외국인 페인포인트 = (a) "자갈치 = 일반 시장" 잘못된 인식 (b) 한국 #1 수산·신선 회·해산물 매트릭스 #1 (c) 국제시장 = 한국전쟁 (1950~) 시작·외국인 매니아 매트릭스 (d) BIFF 광장 = 아시아 #1 영화제 (매년 10월) (e) 영문 메뉴 + 결제 카드 + 픽업 풀세트.

🏛 5축 deep dive

① 자갈치 시장 (1945~ 한국 #1 수산)

  • 시그니처: 1945년~ 80년+·한국 #1 수산시장
  • 외국인 친화도: ★★★★★ (영문·결제 카드·픽업)
  • 추천: 시장 = 가성비 (회덮밥 8,000~15,000원)·회집 = 시그너 (50,000~120,000원/2-3인용)

② 국제시장 (1950년~ 한국 #2)

  • 시그니처: 1950년 한국전쟁 시작·한국 #2 시장 (광장시장 다음)·호떡·길거리 음식·보세 의류
  • 외국인 친화도: ★★★★★ (영문·결제 카드)
  • 추천: 시장 산책 + 호떡 + 가성비 매트릭스

③ BIFF 광장 (Busan International Film Festival)

  • 시그니처: 아시아 #1 영화제·매년 10월·1996년~·30년+
  • 외국인 친화도: ★★★★★ (글로벌 매니아 #1)
  • 추천: 광장 산책 + 영화 핸드프린팅 + 카페 cluster·BIFF 시즌 (10월) = 외국인 매니아 매트릭스 #1

④ 광복로 + 남포동 (쇼핑)

  • 시그니처: 부산 #1 번화가·MZ 매장·인스타 fit
  • 외국인 친화도: ★★★★★ (영문·결제 카드)

⑤ 1일 코스

  • 시그니처: 자갈치 + 국제시장 + BIFF + 광복로 = 풀세트 매트릭스

⚠ 외국인 자주 실수 5가지

1. "자갈치 = 일반 시장": 한국 #1 수산시장 80년+·신선 회·해산물 매트릭스 #1.

2. "국제시장 = 일반 시장": 1950년 한국전쟁 시작·한국 #2 시장·호떡·보세 의류 매트릭스.

3. "BIFF = 일반 영화제": 아시아 #1 영화제 매년 10월·1996년~·글로벌 매니아 #1.

4. "회 = 다 같음": 자갈치 = 한국 #1 신선도·시즌 매트릭스 (굴·꽃게·전복·장어).

5. "광복로 = 일반 번화가": 부산 #1 번화가·MZ + 인스타 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 자갈치 회 + 국제시장 + BIFF + 광복로 = 4시간.

2. BIFF 시즌 (매년 10월): 사전 티켓 예약·외국인 매니아 매트릭스 #1·6개월+ 사전 예약 권장.

3. 자갈치 회: 광어·우럭 = 연중 / 굴 겨울·전복 여름·꽃게 봄·장어 여름 매트릭스.

4. 국제시장 호떡: 한국 #1·시즌 OK·1,500~3,000원/개.

5. 결제: 카드 OK 80%·노포 일부 현금·환급 일부 매장.

6. 추천 페르소나: 가족·시니어 = 자갈치 + 국제시장 / MZ·인스타 = BIFF + 광복로 / 매니아 = 시즌 매트릭스 + BIFF.
