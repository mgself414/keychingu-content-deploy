首尔精酿鸡尾酒吧指南 — 亚洲50佳级别的美食鸡尾酒吧

> 差异点：与首尔的街区酒馆、布帐马车 (pojangmacha / 포차)、马格利酒 (makgeolli / 막걸리) 指南不同，本文只收录全球酒吧评论家每年都会造访的精酿（mixology）鸡尾酒吧。韩屋 (hanok / 한옥) 酒吧、传统酒 (jeontongju / 전통주) 鸡尾酒、隐秘的私酒吧 (speakeasy) —— 只有在韩国才能喝到的一杯。

> ⚠️ 排名、地址与营业信息会变动。前往之前，请在Naver地图 (Naver jido / 네이버 지도) / Instagram 上搜索店名，确认营业与预约。

过去十多年间，首尔已崛起为亚洲最佳鸡尾酒城市之一。每年都有数家首尔酒吧登上亚洲50佳酒吧 (Asia 50 Best / 아시아 50 베스트)，其中一家更登上了全球50佳。关于"首尔为何成为鸡尾酒之都"的背景，会在姊妹篇（韩国鸡尾酒吧文化 explainer）中讲述，本文则按街区告诉你实际该去哪里。

⚠️ 外国人应了解的3件事

1. 预约是关键 —— 知名酒吧排队长或座位少。请通过CatchTable (캐치테이블)、Instagram 私信或电话提前预约。尤其是酒店品鉴吧（如 H Bar）必须预约。

2. 不懂鸡尾酒也OK —— 首尔酒吧以热情款待闻名。只要说出口味偏好——"清爽的/烟熏的/不太甜的 (sangkeumhan / smoky / dalji aneun / 상큼한·스모키한·달지 않은)"——调酒师就会推荐。许多酒吧甚至没有菜单。

3. 务必尝一杯烧酒 (soju / 소주) 或马格利酒 (makgeolli / 막걸리) 鸡尾酒 —— 首尔酒吧的全球差异点在于传统酒 (jeontongju / 전통주) 与韩国食材。这些组合只有在韩国才喝得到，所以至少要试一杯。

🍸 江南 (Gangnam / 강남) (清潭 (Cheongdam / 청담)·狎鸥亭 (Apgujeong / 압구정)·新沙 (Sinsa / 신사)) — 首尔鸡尾酒场景的发源地

首尔精酿鸡尾酒场景最初绽放的街区。名店聚集在清潭洞 (Cheongdam-dong / 청담동) 的岛山大路 (Dosan-daero / 도산대로) 一带，很适合酒吧巡游 (bar hopping)。

  • Zest — 清潭 (Cheongdam / 청담)。首尔 No.1，亚洲 #2·全球 #16（2025，建议核实）。以重新利用废弃食材的零浪费理念，加上韩国产地食材（济州 (Jeju / 제주) 柑橘·旧左 (Gujwa / 구좌) 胡萝卜等）调制的精致一杯。若在首尔只去一家，这是首选。建议预约。
  • Le Chamber — 清潭 (Cheongdam / 청담)。按下书架上的按钮才会开门的私酒吧。由世界冠军调酒师经营，藏有200余种威士忌，是首尔场景的鼻祖（2016年起连续上榜）。
  • Alice — 清潭 (Cheongdam / 청담)/狎鸥亭 (Apgujeong / 압구정)。从花店内暗门进入的"爱丽丝梦游仙境"主题酒吧。分子鸡尾酒与梦幻演绎。2025年亚洲 #13（荣获最高跃升奖）。
  • Pine & Co — 狎鸥亭 (Apgujeong / 압구정)。1980~90年代首尔复古情怀 + 真空·旋转蒸发等尖端技法 + 韩国传统食材。亚洲扩展榜 #52。
  • Cricket Seoul — 狎鸥亭 (Apgujeong / 압구정) 附近。专注于韩国传统酒 (jeontongju / 전통주) 教学与品鉴。以特调鸡尾酒形式体验全国各地鲜为人知的韩国酒。最适合韩国酒入门。
  • Elements — 清潭 (Cheongdam / 청담)。同时享用鸡尾酒 + 意面的餐饮吧。意面每日更换。
  • Villa Records — 新沙洞 (Sinsa-dong / 신사동) 地下。带1960~70年代太空时代氛围的黑胶聆听沙龙 (vinyl listening lounge)。是首尔数一数二的大型场地，故推荐4人以上团体。经典与分子版本兼备。
  • MIXOLOGY — 江南 (Gangnam / 강남)。把鸡尾酒当科学般对待的地方。以冰雕与大师课闻名。

🏯 钟路 (Jongno / 종로) (西村 (Seochon / 서촌)·北村 (Bukchon / 북촌)·光化门 (Gwanghwamun / 광화문)) — 韩屋与传统犹存的鸡尾酒

传统纹理犹存的街区。韩屋 (hanok / 한옥) 酒吧与历史概念酒吧聚集于此，照片与氛围都很特别。

  • Bar Cham — 西村 (Seochon / 서촌)（紫霞门路 (Jahamun-ro / 자하문로) 一带）。在由韩屋 (hanok / 한옥) 改造的空间中，把菜单分为全国6个地区，用各地区的传统酒与物产调制鸡尾酒。最能展现韩国文化的酒吧。亚洲 #6。排队可能很长，请尽早。
  • Bar Pomme — 西村 (Seochon / 서촌) 通仁洞 (Tongin-dong / 통인동)。Bar Cham 团队的苹果风土专门酒吧。以与忠州 (Chungju / 충주) 苹果农户直连的韩国苹果白兰地·卡尔瓦多斯为基底。（Bar Cham 排队长时，作为附近替代也很出色。）
  • Cham in Season — 社稷路 (Sajik-ro / 사직로)。Bar Cham 团队的季节专门2号店。每个季节用当季韩国食材整套更换菜单（秋季=苹果·梨·南瓜等）。
  • Gong-Gan — 安国 (Anguk / 안국)·北村 (Bukchon / 북촌) 韩屋村小巷。在韩屋 (hanok / 한옥) 内庭格局中，把童年记忆化作鸡尾酒并实践升级再造。亚洲 #63（大幅跃升）。很适合与北村 (Bukchon / 북촌) 观光串联。
  • Charles H — 光化门 (Gwanghwamun / 광화문) 四季酒店地下。1920~30年代装饰艺术私酒吧。不像典型酒店吧那般拘谨，气氛轻松、服务一流。亚洲 #96。
  • H Bar — 四季酒店，Charles H 内侧。8座独立空间的品鉴套餐（当季鸡尾酒+搭配，每人约 ₩150,000 (~1,100 RMB)，建议核实）。必须预约，适合特别的日子。
  • Cobbler — 延禧洞 (Yeonhui-dong / 연희동) 的一座韩屋 (hanok / 한옥)。入场便会奉上蓝莓酥派 (blueberry cobbler pie) 作为欢迎小食。无菜单，靠与调酒师对话调制经典一杯（推荐 Daiquiri）。20座小型场地。

🌃 其他街区 — 麻浦 (Mapo / 마포)·龙山 (Yongsan / 용산)·恩平 (Eunpyeong / 은평)

远离市中心的街区酒吧。想同时享受本地情调与高品质时。

  • Antidote — 麻浦 (Mapo / 마포) 孔德 (Gongdeok / 공덕)·大兴 (Daeheung / 대흥)（京义线林荫道 (Gyeongui-seon Sup-gil / 경의선숲길) 附近）。处方（解毒剂）概念——按症状设计的招牌鸡尾酒搭配韩国食材。透明到每杯鸡尾酒都用 QR 展示调制过程视频。很有 Instagram 感。
  • Notes — 龙山 (Yongsan / 용산) 孝昌公园站 (Hyochang-gongwon / 효창공원) 附近。贴近社区的小型酒吧，却有高端级别的鸡尾酒。适合想远离景点的清静时。
  • Kissk — 恩平 (Eunpyeong / 은평) 葛岘洞 (Galhyeon-dong / 갈현동)，位于北汉山 (Bukhansan / 북한산) 山脚（"kissk"=山脚）。带迪斯科时代氛围，营业至凌晨5点。即便在郊外，也是调酒师最推荐的"调酒师之吧"。适合悠闲收尾。
  • MMS — 以威士忌为中心的设计吧，以最具实验性（古怪）的菜单闻名（凤尾鱼泡沫·烟熏鸭等）。确切位置请于前往前核实。

🗺️ 外国人实战指南

  • 预约：人气酒吧与酒店品鉴吧请通过 CatchTable (캐치테이블) / Instagram 私信 / 电话提前预约。座位少的酒吧很多，故务必遵守人数。
  • 英语：越知名的酒吧越能用英语应对。只需说出偏好（口味·度数）即可。
  • 费用：鸡尾酒一杯约 ₩20,000~25,000 (~150~190 RMB)，酒店·品鉴更高（请核实时点与汇率）。已含服务费，故无需小费。
  • 身份证：仅限满19岁以上入场——请携带护照。
  • 推荐路线（酒吧巡游）：串联清潭 (Cheongdam / 청담)（Zest → Le Chamber → Alice）或西村 (Seochon / 서촌)（Bar Cham → Pomme → 附近）。钟路 (Jongno / 종로) 可与北村 (Bukchon / 북촌) 观光（Gong-Gan）相连，光化门 (Gwanghwamun / 광화문) 可与四季酒店（Charles H）相连。
  • 时机：平日（周日~周四）傍晚较清静。周五·周六拥挤，故开门即到。

❓ 常见问题

1. 一天去几家合适？ — 2~3家。每家一杯，慢慢品。串联在同一街区（清潭 (Cheongdam / 청담)·西村 (Seochon / 서촌)）可缩短移动。

2. 着装要求？ — 大多休闲即可。但酒店吧（如 Charles H）最好避免过于随便的着装（拖鞋·运动服）。

3. 一个人去也行吗？ — 坐在吧台座位，独自造访很自然，也便于与调酒师交谈。

4. 可以拍照吗？ — 大多可以，但请顾及座位与其他客人。部分私酒吧限制入口·内部拍摄，请先询问。

5. 推荐喝传统酒鸡尾酒的酒吧？ — Bar Cham（6地区）·Cricket（传统酒品鉴）·Zest（韩国产地食材）是代表。
