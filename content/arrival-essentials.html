⚠ 외국인 자주 실수 5가지

1. "인천공항 → 서울 = 비쌈": 인천공항 → 서울 = 공항철도 일반 4.3K (60분 한국 #1 가성비) + 직통 11K (43분) + 외국인 매니아 1순위.

2. "한국 4G = 비쌈": 한국 4G·5G = Klook eSIM 7일 30K·30일 80K + 외국인 가성비 1번지 (일본·미국 대비 50% 저렴) + KT·SKT·LGU+ 풀세트.

3. "T-money = 한국인만": T-money = 외국인 4K 카드·5K 충전 + 지하철·버스·편의점·자판기 풀세트 + 명동·인천공항·편의점 어디서나 + 외국인 매니아 1번지.

4. "KakaoPay·Naver Pay = 외국인 못 씀": KakaoPay·Naver Pay = 외국인 신용카드 등록 OK + KakaoMap 영어 + 외국인 매니아 1순위·시내 90%+ 매장.

5. "환전 = 공항만": 환전 = 명동 환전 1번지 (시내 환율 + 가성비) + 공항 + KEB하나·신한·우리 ATM + 외국인 매니아 풀세트.

① 도착·교통 (3)

1. 인천공항 → 서울 ★ 공항철도·KAL 리무진·택시

  • 공항철도 일반 4.3K (60분 서울역)·직통 11K (43분)
  • KAL 리무진 (시내 호텔 직행 16K)·택시 (60~100K)
  • 외국인 ★: ◎◎ — 한국 #1 가성비·KTO 인증

2. VISA·여권·K-ETA (#178)

  • 무비자 130+ 국가·K-ETA 사전 등록 (외국인 매니아 1번지)
  • 도착 비자 OK 국가·외국인 첫 방문 필수

3. 인천공항 환승 (1·2 터미널)

  • 12시간 환승 무료 시티투어 (외국인 매니아 1순위)
  • 외국인 패키지·12시간+·KTO 인증

② 통신 (3)

4. 4G·5G 유심·eSIM ★ 한국 #1

  • KT·SKT·LGU+ 풀세트
  • Klook eSIM 7일 30K·30일 80K (외국인 가성비 1번지)
  • 외국인 ★: ◎◎ — 즉시 활성화·외국인 매니아

5. 공항 WiFi 도시락·KT 와이브로

  • WiFi 도시락 1일 4K~ (Klook 예약)
  • KT 와이브로 30일 무제한
  • 외국인 ★: ◎◎ — 외국인 매니아 가성비

6. 카카오톡·KakaoMap·Naver Map

  • 카카오톡 (한국 #1 메신저 100%)
  • KakaoMap·Naver Map 영어 OK (외국인 매니아 1번지)
  • 외국인 ★: ◎◎ — 외국인 길찾기 1순위

③ 결제·환전 (3)

7. T-money 교통카드 ★ 한국 #1

  • 4K 카드 + 5K 충전·외국인 매니아 1번지
  • 지하철·버스·편의점·자판기 풀세트
  • 외국인 ★: ◎◎ — 외국인 첫 방문 필수

8. KakaoPay·Naver Pay·신용카드

  • 외국인 신용카드 (Visa·Master·Amex) 90%+ 매장
  • KakaoPay 외국인 등록 OK·Naver Pay
  • 외국인 ★: ◎◎ — 외국인 매니아 1순위

9. 환전 (공항·시내·KEB하나)

  • 명동 환전 1번지 (시내 환율 가성비 1번지)
  • 공항 + KEB하나·신한·우리 ATM (외국인 환전 풀세트)
  • 외국인 ★: ◎◎ — 외국인 가성비 1번지

④ 교통·실용 (3 + 추가 4)

10. 지하철 9 호선 + 25 호선 ★ 외국인 영어 OK

11. 시내버스·심야버스·택시

⚙ FAQ 6개

1. 외국인 인천공항 → 서울: 공항철도 일반 4.3K (60분)·직통 11K (43분)·KAL 리무진 16K.

2. 외국인 4G/5G 1순위: Klook eSIM 7일 30K (가성비)·30일 80K (장기)·KT/SKT/LGU+ 유심.

  • 시그니엘 (#356) / 신라 (#356) 호텔 체크인 → #208 시차 + 명동 야시장 (#13)

C. 외국인 첫 방문 3박4일 풀세트 (#178)
