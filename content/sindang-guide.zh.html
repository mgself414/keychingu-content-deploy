新堂洞 (Sindang-dong / 신당동) — 开始被称为"下一个圣水洞"的社区，市场·潮流酒吧·辣炒年糕三层结构

副标题：西方游客开始把这里当作住宿地点提起的早期信号社区——白天的首尔中央市场 (Seoul Jungang Market / 서울중앙시장)、夜晚的米铺街 (Ssajeon-geori / 싸전거리) 酒吧小巷、正宗辣炒年糕街三条主线 + 可步行到乙支路 (Euljiro / 을지로)·东大门 (Dongdaemun / 동대문) 的动线 + 为什么现在就该去

ISSUE 04 · #1311 · 2026-08-20

🎯 为什么现在是新堂洞

新堂洞 (Sindang-dong / 신당동) 正走在两三年前圣水洞 (Seongsu-dong / 성수동) 走过的同一条轨迹上。米铺街 (Ssajeon-geori / 싸전거리) 里老旧的店面开始有酒吧、餐厅进驻，西方旅行视频里也开始出现"想在首尔住这一带"的说法——观光人潮还没涌入。在爆红之前先走一遍这个社区，正是这里的核心价值。

项目 内容
位置 中区新堂洞——新堂站 (Sindang Station / 신당역，2·6号线) 一带
步行范围 乙支路15分钟·东大门(DDP)15分钟·清溪川 (Cheonggyecheon / 청계천) 10分钟
适合停留时长 半天(白天逛市场→晚上泡酒吧小巷)或晚上3小时
拥挤程度 低——只有周末晚上的米铺街会排队
费用 市场小吃 ₩5,000~15,000·酒吧鸡尾酒 ₩15,000~20,000

① 外国游客常犯的3个错误

1. 以为"新堂=辣炒年糕"就来了

辣炒年糕 (tteokbokki / 떡볶이) 街只是三条主线中的一条。真正撑起现在新堂洞的，是市场和酒吧小巷。

2. 觉得逛过广藏市场就等于逛过市场了

首尔中央市场 (Seoul Jungang Market / 서울중앙시장) 和广藏市场 (Gwangjang Market / 광장시장) 气质完全相反——这里不是给游客逛的，而是商人和居民的市场。没有拉客，价格也是本地价(是《被高估/被低估的首尔》攻略里推荐的代表替代地)。

3. 只在白天来

米铺街的酒吧都是傍晚才开门。必须把白天的市场和晚上的酒吧小巷连起来走，才能看到新堂洞的两幅面孔。

② 分三层逛新堂

第1层. 首尔中央市场 (Seoul Jungang Market / 서울중앙시장) — 白天的主线

就在新堂站1·2号出口正对面。这里是1911年开业的首尔三大市场之一，因为起家于大米、干货批发，至今仍保留着生活市场的质感。

  • 小吃巷：卖煎饼 (jeon / 전)、韩式血肠 (sundae / 순대)、刀削面 (kalguksu / 칼국수)、烤鱼的老字号 (nopo / 노포，经营30年以上的传统老店) 挤在窄窄的通道两侧。市场内吃一顿约₩7,000~12,000。
  • 也有本地人的固定动线：在干货店买明太鱼干 (nogari / 노가리)、半干明太鱼 (hwangtae / 황태) 当下酒菜，带去晚上的酒吧小巷(能不能带外食进店要现场确认)。
  • 外语菜单很少见——用手指点菜是常态。这正是这个市场的魅力所在。

第2层. 米铺街 (Ssajeon-geori / 싸전거리) 酒吧小巷 — 夜晚的主线

中央市场后面，曾经是卖米的老店(싸전)聚集的小巷。老旧店面被原样保留下来，酒吧、餐厅陆续进驻，形成了和乙支路的潮不一样的"市场潮"。

  • 酒神堂 (Jushindang / 주신당) ——已经成为新堂潮流地标的概念鸡尾酒吧。萨满 (musok / 무속，韩国传统巫俗信仰) 主题装潢和十二生肖鸡尾酒，在外国游客的评论里出现频率很高。经常需要排队。(已经证明够火，开出了江南 (Gangnam / 강남)、龙山 (Yongsan / 용산) 分店。)
  • 小巷深处还连着水乐 (Sunak / 수낙)、牛肉味 (Uyukmi / 우육미)、太太五花肉 (Taetae-samgyeop / 태태삼겹)、溪流馆 (Gyeryugwan / 계류관) 这类小型酒吧、餐厅——招牌都很小，逛一圈很容易漏看，得走两遍。
  • 小贴士：周末晚上效率最高的顺序是——先在酒神堂登记等位→逛一圈小巷→吃市场夜宵→回去入座。

第3层. 辣炒年糕街 — 正宗的主线

新堂站8号出口方向的辣炒年糕小巷。这里是1950年代马福林 (Ma Bok-rim / 마복림) 奶奶创立的即席辣炒年糕 (jeukseok-tteokbokki / 즉석 떡볶이，在桌上用小锅现煮的吃法) 的发源地。

  • 即席辣炒年糕是点单后在桌上边煮边吃，还可以加沙里 (sari / 사리，拉面、韧劲面、饺子等追加配料)——2人以上约₩15,000~25,000。
  • 重点是这和小吃摊式辣炒年糕(连锁店、一般小吃攻略里的辣炒年糕)是完全不同的类型。适合和《东大门市场购物》攻略搭配着逛。

③ 推荐动线2种

路线 动线 所需时间
半天全程路线 14点逛中央市场·吃小吃 → 清溪川散步 → 17点在辣炒年糕街早点吃晚饭 → 19点米铺街酒吧 6小时
晚间浓缩路线 17点中央市场小吃巷 → 米铺街2家酒吧 3小时
  • 和《明洞→乙支路傍晚徒步路线》连起来走：从那条路线的终点烤鱼干胡同 (Nogari-golmok / 노가리골목) 走到新堂洞只要15分钟——可以玩成夜场 (yajang / 야장，韩式路边纳凉摊文化) 一场在那边、米铺街二场在这边的加长版。

④ 实用小贴士

  • 支付：市场里部分老字号 (노포) 更喜欢收现金——建议带₩20,000现金。酒吧小巷可以刷卡。
  • 住宿角度：和明洞 (Myeongdong / 명동)、东大门这些观光圈只隔1~2站地铁，但住宿费更低——正好符合"像本地人一样住"的需求。不过这里没有大型酒店，以小型民宿为主。
  • 拍照礼仪：拍市场商户、店铺之前先打个招呼是基本礼貌。米铺街酒吧内部大多可以自由拍照。
  • 交通方式：地铁2号线·6号线新堂站。从乙支路走过来，途中跨过清溪川的这段路很好看。
