🎯 なぜ江陵 (カンヌン)・平昌 (ピョンチャン) 完全ガイドなのか

江陵 (カンヌン) = 韓国一の東海 (トンヘ) 都市 + 平昌 (ピョンチャン) = 2018年冬季オリンピック + 韓国一のスキーリゾート + KTX江陵線 (カンヌンソン) で1時間40分。外国人マニアにとって、ソウル郊外で最も人気のある目的地 (済州 (チェジュ) 島に次ぐ)。

⚠ 外国人がよくする間違い5選

1. 「江陵 (カンヌン) = 1泊2日でOK」: 江陵 (カンヌン) を満喫する外国人マニアは、2泊3日～3泊4日のフルセットで、江陵 (カンヌン) + 平昌 (ピョンチャン) + 旌善 (チョンソン)・束草 (ソクチョ) の郊外も楽しんでいます。

2. 「KTX江陵線 (カンヌンソン) = 速くない」: KTX江陵線 (カンヌンソン) は、ソウル → 江陵 (カンヌン) を1時間40分で結びます (2017年平昌 (ピョンチャン) 冬季オリンピックに向けて開通)。外国人マニアにとって最高のアクセスです。

3. 「龍平 (ヨンピョン)・ハイワン (하이원) = 高い」: 龍平 (ヨンピョン)・ハイワン (하이원)・昆池岩 (コンジアム)・フェニックス (휘닉스) は、外国人マニアにとって最高の場所 + 1泊2日～1週間のフルセットで楽しめます。外国人フレンドリーで英語対応もOKです。

4. 「安木 (アンモク) コーヒー通り = カフェだけ」: 安木 (アンモク) コーヒー通りは、韓国一のカフェストリート + テラロサ (테라로사) 本店・ボヘミアン (보헤미안) の聖地 + 外国人カフェマニアの聖地です。

5. 「平昌 (ピョンチャン) = 冬だけ」: 平昌 (ピョンチャン) は、夏 (五台山 (オデサン)・羊牧場 (ヤンテモクチャン))・秋 (紅葉 #229)・冬 (スキー #231)・春 (花 #230) と、一年中外国人マニアに人気の場所です。
