⚠ 외국인 자주 실수 5가지

1. "벚꽃 = 4월만": 한국 벚꽃 = 3월 말 (제주·부산)·4월 초 (서울·진해)·4월 중순 (강원) + 윤중로 (#303 한국 #1) + 외국인 인스타 1번지.

2. "여름 축제 = 한강 치맥만": 여름 = 보령 머드 축제 (7월 한국 #1)·부산 바다 축제·한강 불꽃 (9월) + 외국인 매니아 1번지 (#06 통합).

3. "단풍 = 어디나": 단풍 = 설악산 10월 중순 (한국 #1) → 내장산·남이섬 10월 말 → 서울 11월 초 (#229·#273 단풍 매트릭스).

4. "겨울 눈 = 강원만": 겨울 = 태백·평창 눈축제 (1월) + 화천 송어축제 + 스키 + DDP 일루미네이션 (도심) + 외국인 매니아 1번지.

5. "한국 4계절 = 야외만": 4계절 = #357 사찰음식·#359 차·다도·#365 한방·#364 호텔 스파 (실내) + 외국인 매니아 통합.
