韩国传统游戏文化 — 尤茨游戏 (Yunnori / 윷놀이)·毽子 (Jegi / 제기)·放风筝 (Yeon-naligi / 연날리기)，填满节日的游戏

节日游戏 (尤茨游戏 (Yunnori / 윷놀이)·放风筝) · 街头游戏 (毽子 (Jegi / 제기)·拍纸牌 (Ddakji / 딱지)·抓石子 (Gonggi / 공기)·弹珠) · 遗产游戏 (强羌水越来 (Ganggangsullae / 강강술래)·摔跤 (Ssireum / 씨름)) · ★《鱿鱼游戏》(Squid Game / 오징어 게임) 里的传统游戏 — 为外国人准备的韩国传统游戏解说。不是“这个游戏怎么玩”，而是“为什么都集中在节日、蕴含什么意义、为什么《鱿鱼游戏》里都出现了”。

2021年，全世界看到了同一个画面。巨大的人偶唱着 “无穷花开了”(Mugunghwa kkochi pieotseumnida / 무궁화 꽃이 피었습니다)，人们用针挑着 椪糖 (Dalgona / 달고나)，在巷子里拍打着 纸牌 (Ddakji / 딱지)。〈鱿鱼游戏〉(Squid Game / 오징어 게임) 展示的不是未来反乌托邦，而是 韩国孩子们数十年来在节日和巷子里玩的传统游戏。对外国人来说这新奇得令人震惊，但对韩国人而言，那就是童年本身。

本文不是“去哪里体验游戏”(→ 场所指南)，而是解读 韩国传统游戏为何集中在节日、每种游戏蕴含怎样的意义 (祈求丰收·驱邪避灾·共同体)，以及 《鱿鱼游戏》把其中哪些传到了全世界。这是韩国文化解说系列第 68 篇。

⚠️ 外国人常有的3大误解

1. “传统游戏是博物馆里的东西，现在没人玩了” ❌ — 尤茨游戏 (Yunnori / 윷놀이) 如今依然是春节客厅里全家一起玩的游戏。抓石子 (Gonggi / 공기)·拍纸牌 (Ddakji / 딱지) 在学校操场上孩子们仍在玩。《鱿鱼游戏》展示的游戏大多 是真实活着的游戏。

2. “应该是《鱿鱼游戏》创造的游戏吧” ❌ — 无穷花开了·椪糖 (Dalgona / 달고나)·纸牌 (Ddakji / 딱지)·弹珠·拔河 并非该剧发明，而是取自原本就有的韩国传统游戏。电视剧只是把它们 介绍 给了全世界。

3. “不过是消遣的游戏罢了” ❌ — 韩国传统游戏与 岁时风俗 (Sesi pungsok / 세시풍속，季节仪礼) 深深交织。正月的游戏是 祈求丰年 (祈丰, Gipung / 기풍)，放风筝是 驱邪避灾 (Aengmagi / 액막이)，强羌水越来 (Ganggangsullae / 강강술래) 是 丰饶·共同体 — 每种游戏都有其时节与意义。

① 何谓传统游戏 — 与节日·岁时风俗融为一体

韩国传统游戏 并非因为无聊而独自玩耍，而是配合节气·节日、由共同体一起进行的游戏 发展而来。据传尤茨游戏 (Yunnori / 윷놀이)·摔跤 (Ssireum / 씨름) 这类游戏 早在三国时代之前 就已存在。核心在于与 岁时风俗 (Sesi pungsok / 세시풍속，季节仪礼) 的结合 — 传统游戏因时节而意义有别。

  • 正月·二月 (春) → 祈丰 (祈豐, Gipung / 기풍) 仪礼 — 祈求一年 丰收 的游戏 (尤茨游戏 (Yunnori / 윷놀이)·拔河·放风筝)。
  • 夏 → 成长仪礼 — 祈愿作物茁壮成长的游戏。/ 秋 → 收获仪礼 — 感谢秋收的游戏 (强羌水越来 (Ganggangsullae / 강강술래))。

因此韩国传统游戏 集中在节日。春节有尤茨游戏 (Yunnori / 윷놀이)·跳板 (Neolttwigi / 널뛰기)·放风筝，中秋 (Chuseok / 추석) 有强羌水越来 (Ganggangsullae / 강강술래)·摔跤 (Ssireum / 씨름) — 游戏可以说就是 填满节日的仪式 (→ 参见 #1136 节日)。

② 节日游戏 — 尤茨游戏与放风筝，全家围坐的时光

尤茨游戏 (Yunnori / 윷놀이) 是 代表春节的家庭游戏。投掷削成半月形的 4根尤茨木条，按朝下与朝上的面数定点数 — 一根朝上为 do，两根为 gae，三根为 geol，四根为 yut，全部朝下为 mo。按其点数在 棋盘 (Malpan / 말판) 上移动棋子，先让所有棋子绕完一圈走出的一方获胜。规则简单，全家 (从孩子到老人) 都能一起玩，因此至今仍是 春节假期客厅里最常见的画面。棋盘和规则因地区略有不同。

放风筝 (Yeon-naligi / 연날리기) 是 冬季游戏。主要 从腊月底前后到正月大望日 (Jeongwol Daeboreum / 정월대보름) 期间放风筝。它超越单纯的游戏，特别之处在于是 驱邪避灾的仪式 — 把去年的厄运·坏事写在风筝上，正月大望日那天剪断风筝线放飞远处。寓意 “送走坏的、迎来福气”(送厄迎福, Songaek-yeongbok / 송액영복)，是把一年陈旧的烦忧放飞天空的 新出发仪礼。所以正月大望日一过，放风筝的季节也就结束了。

要点: 二者都是 家庭单位。尤茨游戏 (Yunnori / 윷놀이) 在室内围坐共玩，放风筝把厄运放飞冬日天空。韩国的节日游戏，重心在于 相聚甚于胜负。

③ 街头游戏 — 毽子·纸牌·石子·弹珠，巷子里的童年

如果说节日游戏属于家庭，那么 街头 (巷子) 游戏就是孩子们的日常。无需花钱，只用手和纸·石子就能玩，因此传播得更广。

  • 踢毽子 (Jegichagi / 제기차기): 用脚内侧踢 用韩纸 (Hanji / 한지) 包住硬币的毽子 (Jegi / 제기)，踢得多者获胜。类似西方的 沙包 (hacky sack)，毽子是 亲手制作 的手工品。
  • 拍纸牌 (Ddakji-chigi / 딱지치기): 用自己的纸牌用力拍打 厚厚折成的纸牌，把对方纸牌掀翻就赢走 的游戏。类似美国1990年代的 'Pog'，韩国战争后结实的纸张变得常见后便流行开来。
  • 抓石子 (Gonggi / 공기): 用一只手抛接 5颗小石子·小粒 的游戏，类似西方的 jacks。如今在学校里仍很常见。
  • 弹珠 (Gusulchigi / 구슬치기): 用手指弹玻璃珠，击中或赢走对方珠子的巷子游戏。

要点: 这些游戏 准备物几乎免费 (纸·石·硬币)，因此人人都玩 — 所以对大多数韩国人来说是 共同的童年记忆，也是〈鱿鱼游戏〉打动人心的原因之一。

④ 成为遗产的游戏 — 强羌水越来与摔跤

某些传统游戏超越了单纯的游戏，被列入 联合国教科文组织人类非物质文化遗产。

  • 强羌水越来 (Ganggangsullae / 강강술래): 主要在 全罗道地区，于 中秋 (Chuseok / 추석，农历八月十五) 望日之夜，女性们盛装打扮、手拉手 围成圆圈唱着‘强羌水越来’副歌并转动 的集体圆舞。它是歌·舞·乐融为一体的综合艺术，于 2009年列入联合国教科文组织人类非物质文化遗产。据传可追溯至马韩 (Mahan / 마한，古代国家) 约2000年的历史，是蕴含 协作·团结·和合 精神的秋收游戏。
  • 摔跤 (Ssireum / 씨름): 抓住腿绳 (Satba / 샅바) 把对方摔倒 的韩式传统摔跤，是节日·端午 (Dano / 단오) 的代表性较量游戏。因其同时锻炼身心、凝聚共同体的价值受到认可，于 2018年列入联合国教科文组织人类非物质文化遗产 — 而且是 韩朝有史以来首次共同申报 的项目，具有历史意义。

要点: 强羌水越来 (Ganggangsullae / 강강술래，和合) 与摔跤 (Ssireum / 씨름，团结) 都因 ‘共同’的价值 而获认可。韩国传统游戏的根基里，存在着 共同体。

⑤ ★ 《鱿鱼游戏》里的传统游戏 — 全世界重新发现

2021年〈鱿鱼游戏〉(Squid Game / 오징어 게임) 第一季引发全球轰动，把剧中出现的韩国传统游戏一举推上世界舞台。重要的是 — 这些游戏不是该剧创造的，而是原本就有的传统游戏。

第一季 (2021) 中出现的传统游戏

  • 无穷花开了 (Red Light, Green Light / 무궁화 꽃이 피었습니다): 只在抓人者喊 “无穷花开了”(Mugunghwa kkochi pieotseumnida / 무궁화 꽃이 피었습니다) 期间才能移动的游戏。无穷花 (Mugunghwa / 무궁화，木槿花) 是韩国国花，也出现在国歌中，象征 “开了又开” 顽强的生命力。
  • 椪糖 (Dalgona / 달고나) 抠糖: 从熔化白糖做成的扁平糖块上 不弄碎地把图案 (星星·雨伞) 抠下来 的游戏。起源于韩国战争后糖果稀缺年代的 平民零嘴。
  • 拍纸牌·弹珠·拔河: 上文③看到的纸牌 (Ddakji / 딱지)，以及巷子·运动会的代表性游戏原样登场。

第二季 (2024)·第三季 (2025) — 更深入

第二季 (2024年12月公开) 创下 Netflix 非英语电视部门 历史级纪录，介绍了更多传统游戏。在‘六角五种竞技’中，纸牌 (Ddakji / 딱지)·石子 (Gonggi / 공기)·抽陀螺·踢毽子 (Jegichagi / 제기차기) 作为小游戏被收入其中 (抽陀螺 = 冬季在冰面上用鞭子抽陀螺、比谁转得久的游戏)。一直延续到第三季 (2025年6月)，《鱿鱼游戏》把传统游戏变成了 全世界的通用语。

要点: 《鱿鱼游戏》反乌托邦式的设定与 天真的传统游戏 的对比带来了冲击。但对韩国人而言，那些游戏 不是恐怖，而是乡愁 — 这道落差正是该剧的核心装置 (→ K-剧的全球化参见 #1183)。

⑥ 岁时风俗与意义 — 游戏中蕴含的祈愿·避灾·共同体

把韩国传统游戏与外国游戏区分开来的，是 每种游戏都嵌入了时节与意义 这一点。

  • 丰饶的祈愿: 正月的游戏 (尤茨游戏 (Yunnori / 윷놀이)·拔河) 不是单纯的娱乐，而是 祈求丰年的祈丰仪礼。也曾有获胜的一方那年会丰收的信念。
  • 驱邪避灾 (厄막이, Aengmagi / 액막이): 放风筝是把陈年厄运写下、剪断风筝线放飞 的净化仪式。游戏本身就是 驱散坏气运的仪礼。
  • 共同体与和合: 强羌水越来 (Ganggangsullae / 강강술래，手拉手的圆舞)·摔跤 (Ssireum / 씨름，村庄较量)·拔河都需要 众人一起 才能成立 — 通过游戏，村庄合而为一。
  • 同在的情 (Jeong / 정): 节日游戏的目的本身就是 全家·邻里围坐 这件事，胜负在其次 (→ #1135 情文化)。

也就是说，韩国传统游戏是 历法·信仰·共同体熔于一炉的文化仪礼。“为何集中在节日”的答案就在这里。

⑦ 外国人体验 — 怎样可以玩玩看

传统游戏比起观看，亲手玩时 才更见真味。

  • 尤茨游戏 (Yunnori / 윷놀이): 规则最简单、道具也好找，最适合外国人入门。在韩屋村·民俗村·节日庆典可即兴体验，小巧的尤茨套装作为纪念品也很受欢迎。
  • 毽子 (Jegi / 제기)·石子 (Gonggi / 공기)·纸牌 (Ddakji / 딱지): 准备物简单，亲手制作后马上玩 很合适。在体验摊位或用一把石子就能当场学会。
  • 节日·庆典时机: 到 春节 (Seollal / 설날)·中秋 (Chuseok / 추석) 假期 或地方民俗庆典，就能实际看到尤茨游戏 (Yunnori / 윷놀이)·跳板 (Neolttwigi / 널뛰기)·放风筝。节日里古宫·民俗村常开放许多免费体验。
  • 放风筝 (Yeon-naligi / 연날리기): 冬季~初春可在汉江或开阔的公园放飞。了解写下厄运放飞的意义后再玩会更特别。

实战贴士: 若是“看了《鱿鱼游戏》才来的”，不妨从 椪糖 (Dalgona / 달고나) 抠糖 开始 — 咖啡馆·体验场所很常见，不弄碎星形抠出来的乐趣十足。接着转到 尤茨游戏 (Yunnori / 윷놀이)，就能品味韩国家庭游戏真正的氛围。

❓ 外国人常见问题 (FAQ)

  • 《鱿鱼游戏》里的游戏真是韩国游戏吗？ — 是的。无穷花开了·椪糖 (Dalgona / 달고나)·纸牌 (Ddakji / 딱지)·弹珠·拔河都是 原本就有的传统游戏。不是该剧发明的，而是介绍给了世界。
  • 现在的韩国人也玩这些游戏吗？ — 尤茨游戏 (Yunnori / 윷놀이) 如今仍是春节客厅里全家一起玩的。抓石子 (Gonggi / 공기)·拍纸牌 (Ddakji / 딱지) 在学校里孩子们仍在玩。它们不是博物馆里的遗物，而是活着的游戏。
  • 尤茨游戏的规则难吗？ — 不难。投掷4根尤茨木条，按朝下的面数 (do·gae·geol·yut·mo) 移动棋子，先绕完一圈的一方获胜。5分钟就能学会 — 是最适合外国人入门的游戏。
  • 有可以亲手玩游戏的地方吗？ — 在韩屋村·民俗村·节日庆典·古宫的体验摊位，可以亲手玩尤茨游戏 (Yunnori / 윷놀이)·毽子 (Jegi / 제기)·放风筝·椪糖 (Dalgona / 달고나)。春节 (Seollal / 설날)·中秋 (Chuseok / 추석) 假期尤其活动繁多。
  • 强羌水越来·摔跤为何特别？ — 二者都是 联合国教科文组织人类非物质文化遗产。强羌水越来 (Ganggangsullae / 강강술래，2009) 是中秋的女性圆舞，摔跤 (Ssireum / 씨름，2018) 是韩式摔跤、是 韩朝首次共同申报 的历史性项目。
