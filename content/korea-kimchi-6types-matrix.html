한국 김치 6종 매트릭스 — UNESCO 무형문화유산 한식 #1

> 부제: 외국인 관광객용 배추·깍두기·총각·열무·나박·동치미 6종 + 계절·지역별 시그니처 + 외국인 입문

ISSUE 03 · #822 · 2026-06-08

🎯 왜 한국 김치 매트릭스인가

외국인 한국 김치 페인포인트 = "배추김치만 알고 있다". 김장 (Kimjang, 김치 담그기 문화) = UNESCO 인류무형문화유산 (2013 등재, 정식 명칭 "Kimjang, making and sharing kimchi in the Republic of Korea"). 단, 김치 자체는 미등재 — 김장 (담그기·나누기 전통)이 등재 대상. 김치 = 글로벌 인지도 한식 #1 + 한국 식사 필수 반찬. 같은 "kimchi"라도 배추김치 (한국 #1)·깍두기 (무 깍기)·총각김치 (총각무 통째)·열무김치 (열무·여름)·나박김치 (물김치)·동치미 (겨울 동치미) 6종 완전 다른 음식. 외국인은 (a) 배추김치만 알고 다른 김치 미경험 (b) 매운맛 가감 모름 (c) 발효 단계 차이 모름 (d) 김장 문화 의미 모름. 본 가이드는 6종 매트릭스 + 지역·계절별 시그니처 + 외국인 입문 우선순위.

🏛 UNESCO 무형문화유산 — 김장 (Kimjang) 2013

김장 (Kimjang) 정의

  • 2013년 UNESCO 인류무형문화유산 등재
  • 정식 명칭: "Kimjang, making and sharing kimchi in the Republic of Korea"
  • ⚠ 김치 자체는 미등재 — 김장 (담그기·나누기 전통)이 등재 대상
  • 김장 = 겨울철 가족·공동체가 모여 김치를 대량으로 담그는 한국 문화
  • 시기: 11월 (입동~소설) 평균 기온 4°C 이하
  • 의미: 공동체·세대 전승·계절 음식 문화
  • 가구당 평균 50~100포기 배추 김장

외국인 김장 체험

  • 북촌 한옥마을 김장 체험 (가을 11월) — 외국인 #1 매니아
  • 전주 한옥마을 김장 체험 — 전통 정통
  • 김치 박물관 (서울) = 김치 역사·체험 1번지

🥬 김치 6종 deep dive

🥬 배추김치 (Baechu-kimchi) — 한국 #1 시그니처

  • 시그니처: 한국 #1 김치·UNESCO 무형문화유산 대표·식당 무료 반찬 #1
  • 종류:
  • 포기김치 (Whole): 배추 한 포기 통째
  • 막김치 (Mak): 배추 잘라서 (빠른 발효)
  • 백김치 (Baek, white): 고춧가루 없는 흰 김치 (외국인 입문)
  • 발효 단계:
  • 겉절이 (Geotjeori, 1~2일): 매운맛 약함·신선
  • 익은 김치 (Iken, 1~2주): 표준 발효
  • 묵은지 (Mukeunji, 6개월+): 깊은 신맛·찌개·볶음 매니아
  • 외국인 친화도: ★★★★★ (한국 식당 무료 반찬 #1)
  • 추천 입문: 백김치 (안 매움) → 겉절이 → 익은 김치 → 묵은지

🥕 깍두기 (Kkakdugi)

  • 시그니처: 무 깍기 (사각 cube) · 국밥 페어 #1
  • 재료: 무 + 고춧가루 + 새우젓 + 마늘·생강·설탕
  • 외국인 친화도: ★★★★★ (아삭·시원·국밥집 표준)
  • 추천 페어링: 설렁탕·곰탕·돼지국밥·BBQ

🥒 총각김치 (Chonggak-kimchi)

  • 시그니처: 총각무 통째 (작은 무, 영문 "young radish")
  • 재료: 총각무 + 고춧가루 + 젓갈 + 마늘
  • 외국인 친화도: ★★★★ (통째 아삭 + 매콤)
  • 추천 페어링: 막걸리·소주·맥주 (술 안주)

🌱 열무김치 (Yeolmu-kimchi) — 여름 #1

  • 시그니처: 열무 (young summer radish leaves) + 가벼움
  • 재료: 열무 + 고춧가루 + 찹쌀풀 + 마늘
  • 외국인 친화도: ★★★★ (여름 가벼움)
  • 추천 페어링: 열무국수 (Yeolmu-guksu) — 여름 1번지 / 비빔밥

💧 나박김치 (Nabak-kimchi) — 외국인 입문

  • 시그니처: 물김치 (Water kimchi) + 무·배추 얇게 썰기
  • 재료: 무·배추·물·고춧가루 약간·마늘
  • 외국인 친화도: ★★★★ (매콤하지 않음·시원한 국물)
  • 추천 페어링: 떡·만두·궁중요리 (담백 페어링)

❄ 동치미 (Dongchimi) — 외국인 부드러움 입문

  • 시그니처: 겨울 물김치 (Winter water kimchi) + 매콤하지 않음
  • 재료: 무 + 물 + 소금 + 배 + 마늘 (고춧가루 X 또는 약간)
  • 외국인 친화도: ★★★★★ (매콤하지 않음·국물 시원 #1)
  • 추천 페어링: 메밀국수 (동치미국수) — 동치미 국물 활용 / 평양냉면

백김치 안 매움 외국인 입문 #1
동치미 안 매움 외국인 부드러움 #1

> 외국인 매운맛 입문 순서: 백김치 → 동치미 → 나박 → 겉절이 → 익은 김치 → 묵은지

⚠ 외국인 자주 실수 5가지

1. "김치 = 배추김치만": 6종 풀세트. 동치미·백김치·나박 = 안 매움.

2. "김치 = 다 매움": 백김치·동치미 = 안 매움. 외국인 입문 1순위.

3. "김장 = 단순 김치 담그기": 김장 = UNESCO 인류무형문화유산 (2013) 공동체·세대 전승 문화.

4. "김치 = 발효 단계 동일": 겉절이 (1~2일) ↔ 익은 김치 (1~2주) ↔ 묵은지 (6개월+) 단계 완전 다름.

5. "한국 식당 김치 = 무료 1회": 식당 김치 = 무료 무제한 리필. "김치 좀 더 주세요" 요청 OK.

⚙ FAQ 8개

1. 외국인 입문 1순위: 백김치 또는 동치미 (안 매움) → 배추김치 겉절이 → 익은 김치 단계.

2. 국밥 페어링: 깍두기 (#1) — 모든 국밥집 무료 제공.

3. 여름 1순위: 열무김치 + 나박김치 + 동치미 (시원).

4. 김장 체험: 북촌·전주 한옥마을 김장 체험 (가을 11월).

5. 묵은지 활용: 김치찌개·김치볶음밥·묵은지 김밥·묵은지 라면.

6. 알레르기: 새우젓 (갑각류)·마늘·생강·고춧가루·콩 (양조간장) 사전 고지.

7. 채식·할랄·코셔: 일반 김치 = 새우젓·멸치액젓 포함 (비채식·비할랄). 사찰음식 김치 = 채식 OK ([#800](#800) 참조).

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

김치 = 발효 음식 (염분 ↑·매운맛 多). 임신부·고혈압·신장 환자 = 염분 주의. 어린이 = 백김치·동치미 (안 매움) 권장. 알레르기 (새우젓·멸치액젓·갑각류·마늘·고춧가루) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 김치 = 비할랄·비코셔 (새우젓 포함). → 사찰음식 김치 = 채식·할랄·코셔 가능 ([#800 사찰음식](#800)).
  • 채식·비건: 일반 김치 = 비채식 (새우젓·멸치액젓). → 사찰음식 김치 OR 비건 김치 (간장·콩 기반) 별도.
  • 글루텐 free: 일반 김치 = 글루텐 free OK (간장 빼면). 백김치·동치미 = OK.

✈️ 김치 한국에서 가져가기 (외국인 페인포인트 #1)

  • 기내 휴대 금지 — 김치 = 액체류 분류 (>100ml 액체 위탁수하물만)
  • 위탁 수하물 OK — 진공 포장·밀봉 컨테이너 필수
  • 추천 구매처:
  • 인천공항 면세점 — 진공 포장 김치 (귀국 직전 픽업)
  • 명동·강남 한식 선물 매장 — 외국인 친화 진공 포장
  • 이마트·롯데마트 김치 코너 — 가성비 진공 포장
  • 가격 anchor: 진공 포장 김치 1kg = 15,000~30,000원 (면세점) / 8,000~15,000원 (마트)
  • 유의사항: 일부 국가 (호주·뉴질랜드 등) 고체 음식 반입 제한 — 자국 규정 사전 확인 필수
