韩国特罗特 (Trot / 트로트) 文化 — 从奶奶的音乐到全世代的热潮

> 特罗特 (Trot / 트로트)·彭恰克 (Ppongjjak / 뽕짝)·折音唱法 (Kkeokgi / 꺾기)·Miss Trot (미스트롯)/Mr. Trot (미스터트롯) — 为外国人准备的韩国大众歌谣解说。不是“K-pop 之外的老歌”，而是“为什么·是什么·怎么样·★如何重新崛起”。

在韩国旅行时，你听到的不只是 K-pop。从市场小巷的音箱里、观光巴士上、餐厅的电视中 — 某处会飘来一首婉转哀切却又欢快、带着独特颤音的歌。外国人通常会当成“old Korean pop”一笔带过，但对韩国人而言，这是名为特罗特 (Trot / 트로트) 的、延续了近一个世纪的大众歌谣体裁。曾被贬为“爷爷奶奶的音乐”而被边缘化的特罗特，以2019〜2020 年的选秀综艺现象为契机，华丽地复活成为从 10 岁到 90 岁全世代为之疯狂的文化。本文不是讲“在哪家练歌房 (Noraebang / 노래방) 唱” (→ 交叉链接)，而是以外国人的视角解说特罗特是什么、为什么这样听、经历了怎样的历史、又如何重新崛起。这是韩国文化解说系列第 45 篇。

> 核心: 特罗特既是韩国最古老的大众歌谣体裁之一，也是最近一次、最炽热地再度流行的体裁。它不是“陈旧的音乐”，而是“不断重生的音乐”。

⚠️ 外国人常有的 3 种误解

1. “特罗特＝就是 K-pop 的老版本” ❌ — 特罗特是与 K-pop 彼此独立的体裁。K-pop 自 1990 年代起以舞曲·嘻哈·R&B 为基础瞄准全球市场，而特罗特是自 1930 年代延续至今、拥有独有的五声音阶·2 拍子·折音唱法 (Kkeokgi / 꺾기) 的韩国本土大众歌谣。两者都是“韩国大众音乐”，但根源与声音不同。

2. “特罗特＝只有老人听的音乐” ❌ — 2019 年以前这种认知确实很强。但在 Miss Trot (미스트롯)·Mr. Trot (미스터트롯) 选秀现象之后，特罗特成了从 10 多岁的偶像粉丝到 90 多岁老人共同享受的全世代文化。如今在韩国，特罗特更接近一种“时髦的复活体裁”。

3. “特罗特＝抄袭日本演歌 (Enka / 엔카)” ❌（禁止断言） — 这是韩国数十年来学界·评论界一直争论的敏感话题。既有承认演歌影响的视角，也有强调同时代相互影响·解放后独立发展的视角，二者并存（见下文 ③）。外国人若断言“是演歌的山寨”可能会失礼 — 以中立态度理解才是核心。

① 特罗特是什么 — 被称为“彭恰克”的韩国之魂

特罗特 (Trot / 트로트) 是韩国大众歌谣 (Gayo / 가요) 的一个体裁。韩国人也称之为彭恰克 (Ppongjjak / 뽕짝)，这是源自模仿“咚恰-咚恰”2 拍子节奏的拟声词的别称。

  • 特罗特的情感常被视为最直接盛装韩国人喜怒哀乐的容器。离别、故乡、母亲、人生的悔恨 — 它浓烈地歌唱人人都能共鸣的普遍情感。
  • 因此特罗特超越了单纯的音乐体裁，被视为与韩国人情绪（情 (Jeong / 정) · 恨 (Han / 한)）深度相连的大众文化符号。
  • 像《人生未完成》(Insaengeun Mi-wanseong / 인생은 미완성)、《故乡真好》(Gohyangi Joa / 고향이 좋아) 那样，歌词中的一句话直接像人生格言般被传诵的歌曲也很多。

如果说 K-pop 是“精致·全球”，那么特罗特就是“婉转·情 (情 / 정)·我们的情绪”。二者不是竞争，而是韩国大众音乐的两根支柱。

② 独特的声音 — 折音、五声音阶、2 拍子

特罗特一听难忘。这份独特来自几个音乐特征。

  • 折音 (Kkeokgi / 꺾기, 颤音唱法): 特罗特最大的特征。不把音直直唱出，而是细细颤动、上挑、摇曳的唱法。一般认为它受到韩国南道民谣 (Namdo Minyo / 남도 민요, 全罗道地区的民谣) 颤音唱法的影响。这“折音 (Kkeokgi / 꺾기)”同时造就了特罗特独有的哀切与兴致。
  • 五声音阶: 不用七声音阶（哆来咪发嗦拉西），而主要使用由五个音构成的音阶。或是小调五声音阶（“拉西哆咪发”系列），或是在大调五声音阶中强调特定音。这种音阶造就了“一听就是特罗特”的旋律。
  • 2 拍子节奏: “咚恰-咚恰”的反复 2 拍子为基础。别称“彭恰克 (Ppongjjak / 뽕짝)”本身就源自这种节奏。

> 参考: “特罗特”之名来自美国社交舞曲狐步舞 (foxtrot)，但实际的韩国特罗特与狐步舞除了同为 2 拍子之外几乎没有音乐上的关联。只是借了个名字而已。

③ 历史与起源 — 始于 1930 年代的“流行歌”(★演歌论争)

特罗特的历史几乎长达100 年。

  • 1930 年代初，日帝强占期的朝鲜开始出现近代大众歌谣，这便是特罗特的根源。当时还没有“特罗特”这个体裁名，而被称为“流行歌”(Yuhaengga / 유행가)、“流行小曲”(Yuhaeng Sogok / 유행소곡) 等。
  • 别称“彭恰克 (Ppongjjak / 뽕짝)”是在1960 年代中期才被冠上的（起初带有些许贬义，之后逐渐被中立的“特罗特”取代）。

★ 演歌 (Enka / 엔카) 起源论争 — 切勿断言

关于特罗特的起源，有一个外国人必须了解的敏感点。那就是与日本大众歌谣演歌 (Enka / 엔카) 的关系。在韩国，这是延续了数十年的真正的学术·社会论争。

  • 一方视角（演歌影响论）: 认为特罗特是在日帝强占期受日本演歌影响而形成的样式，是殖民地时期产物的批判性观点。1960 年代和 1980 年代曾两度爆发大规模的“彭恰克论争”(Ppongjjak Nonjaeng / 뽕짝 논쟁)，1984 年“彭恰克 (Ppongjjak / 뽕짝) 凭什么算是我们的”之类的挑衅性主张点燃了论争。
  • 另一方视角（相互影响·独立发展论）: 认为特罗特不仅受日本演歌影响，还与韩国传统民谣、西洋布鲁斯系音乐相互影响而形成，并在 1945 年解放后走上了与演歌不同的独立道路。尤其是 1940 年代以后特罗特所呈现的向大调·七声音阶的转变，被视为当时演歌所没有的特罗特独有发展。还强调歌词也是由韩国人用韩语承载韩式情绪所写。也有反驳将演歌起源论视为“殖民地受害意识”。

> 要点: 演歌是否影响特罗特是“韩国学界以中立态度争论的话题”，而非外国人可以一句“不就是抄演歌”来断定的事。在东亚近代大众音乐彼此影响的大潮流中，将特罗特理解为在韩国独立本土化·发展的体裁，才是中立的视角。

⑤ ★★ 现代的复活 — Miss Trot·Mr. Trot 现象

直到 2019 年，特罗特一直被困在“上了年纪的世代听的老歌”的认知里，被挤到边缘。彻底扭转这一格局的事件，正是TV 朝鲜 (TV Chosun / TV조선) 的两档选秀综艺。

  • 〈明日是 Miss Trot〉(Naeireun Miss Trot / 내일은 미스트롯) (2019, TV 朝鲜, TV조선): 发掘女性特罗特歌手的选秀。它把曾是非主流的特罗特推升为全国性现象。这一季的冠军正是宋佳人 (Song Ga-in / 송가인) — 成为代表 2020 年代特罗特再流行的歌手。
  • 〈明日是 Mr. Trot〉(Naeireun Mister Trot / 내일은 미스터트롯) (2020, TV 朝鲜, TV조선): 男性版选秀。2020 年 1 月播出，创下爆炸性收视率与话题度。这一季中林英雄 (Lim Young-woong / 임영웅) 夺冠（获得“真”(Jin / 진) 称号），跻身“国民歌手”之列。

这两档节目将特罗特一举推上主流文化的顶峰。此后涌现出大量特罗特选秀·综艺，以林英雄 (Lim Young-woong / 임영웅)·宋佳人 (Song Ga-in / 송가인) 为首的巨星们，拥有了不亚于 K-pop 偶像的庞大粉丝群。

> 从外国人视角看的重要一点: 在韩国，“Mr. Trot”(미스터트롯)·“林英雄”(임영웅) 不只是一档电视节目·一位歌手的名字，而是2020 年代韩国大众文化的核心现象。尤其是中老年粉丝群的火力，丝毫不逊于 K-pop 粉丝群。

⑥ 全世代为之疯狂的理由

特罗特复活最令人惊讶之处在于它不分世代。这是为什么呢？

  • 中老年层 — 怀旧与自豪: 看着从小听到大的“我这一代的音乐”华丽复活，他们强烈地凝聚起来。这是林英雄 (Lim Young-woong / 임영웅)·宋佳人 (Song Ga-in / 송가인) 粉丝群的核心火力。
  • MZ 世代 — “新鲜的”复古: 对没有亲历特罗特全盛期的年轻一代而言，特罗特反倒成了新鲜的素材。实力派新人的大量涌现，以及特罗特与舞曲·抒情曲等其他体裁的结合，连年轻人的耳朵也一并俘获。
  • 全家一起: 特罗特综艺成了奶奶和孙辈在同一台电视前一起享受的罕见内容。能创造跨世代的共同话题，是复活的一大动力。
  • “故事”的力量: 从默默无闻到成为巨星的选秀叙事，以及每位歌手的人生故事叠加在歌曲之上，营造出深度的沉浸感。

⑦ 外国人如何享受特罗特

> 为想更深入品味韩国大众文化的外国人准备的入门指南。

  • 入门曲: 在 YouTube 上从林英雄 (Lim Young-woong / 임영웅)·宋佳人 (Song Ga-in / 송가인) 等 Mr./Miss Trot 的热门舞台，或经典的李美子〈山茶花姑娘〉(Dongbaek Agassi / 동백아가씨)、罗勋儿〈故乡站〉(Gohyangyeok / 고향역) 听起，更容易感受特罗特的质感。（歌手·曲名·标记建议核实）
  • 侧耳倾听折音 (Kkeokgi / 꺾기): 集中听歌手如何颤动·上挑音符，特罗特独有的魅力才真正听得出来。这与 K-pop 顺滑的发声恰恰相反。
  • 挑战练歌房 (Noraebang / 노래방, 投币练歌房): 韩国练歌房里满是特罗特名曲。即便不懂歌词意思，2 拍子的兴致谁都能享受。若与韩国长辈一起，便是最佳破冰利器。
  • 观看特罗特综艺: 用带字幕的片段看 Mr./Miss Trot 的舞台，就能一下子理解“为什么韩国对这个体裁如此疯狂”。
  • 一点礼仪: 不要把特罗特贬为“土气的老歌”。对韩国人而言，特罗特是承载着情绪·历史·自豪的体裁。以好奇与尊重靠近，就会受到欢迎。

❓ 外国人常问的问题 (FAQ)

  • 特罗特和 K-pop 有什么不同？ — 两者都是韩国大众音乐，但 K-pop 是 1990 年代以后以舞曲·嘻哈为基础的全球导向体裁，而特罗特是自 1930 年代延续至今、拥有五声音阶·2 拍子·折音唱法 (Kkeokgi / 꺾기) 的韩国本土体裁。声音与情绪都不同。
  • 特罗特真的来自日本演歌 (Enka / 엔카) 吗？ — 这是韩国学界数十年来一直争论的话题。既有承认演歌影响的视角，也有强调与韩国传统·西洋音乐相互影响及解放后独立发展的视角。断言它是“演歌山寨”既不准确，也不礼貌。
  • “彭恰克 (Ppongjjak / 뽕짝)”是贬义词吗？ — 在 1960 年代起初带有些许贬义，但如今也被广泛用作亲切称呼特罗特的爱称。不过在正式·郑重的场合，用“特罗特”更稳妥。
  • Mr. Trot 真的那么火吗？ — 是的。2020 年播出后，它把特罗特推上了韩国主流文化的顶峰，是社会现象级的综艺。冠军林英雄 (Lim Young-woong / 임영웅) 目前是韩国拥有最庞大粉丝群的歌手之一。
  • 年轻人也听特罗特吗？ — 是的。复活之后，特罗特成了全世代文化。借助与其他体裁的结合、实力派新人的登场，MZ 世代的粉丝也很多。
