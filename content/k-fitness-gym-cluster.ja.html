ソウルの1日券ジム・運動9軒 — ホンデ・梨泰院・カンナム・ソンスで1日だけ運動する

🎯 こんな人に

旅行中も運動の習慣を続けたい人向けの回です。ソウルのジムは数か月単位の会員が基本ですが、1日利用券(1日券)を売る店も多くあります。この回は、1日券や1回券の値段を公式ページや日付のある訪問レビューで確認できた店だけを残しました。カカオマップ (Kakao Map / 카카오맵)で営業中と表示され、2026年10~11月に投稿されたレビューや写真がある店です。

⚠ 表記の原則: 営業時間はカカオマップの値です(2026-11-24確認)。オーナーが曜日ごとの時間を登録している店は「カカオマップのオーナー登録」、今週の表示だけがある店は「カカオマップの表示時間」と区別しました。カカオマップにない値は、公式ページや日付のあるレビューから取り、出典を付けました。料金は公式ページの値(2026-11-24確認)を先に使い、なければ2024-11-24以降に書かれたネイバーブログの訪問レビューの値を使いました。料金は店舗の事情で変わることがあります。駅の出口と歩く時間は、カカオマップの経路案内の値です。

① ホンデイック駅 — ジム3軒 + クライミングジム1軒

4軒とも、ホンデイック駅(2号線・空港鉄道・京義中央線)から歩いて1~2分の距離です。仁川空港から空港鉄道で直接来られるエリアなので、到着した日に運動するのにも向いています。

エイブルジム ホンデイック駅店 (Able Gym Hongik Univ. Station / 에이블짐 홍대입구역점)

LCタワーの地下2階にある大型ジムです。カカオマップのオーナー登録の時間は月曜 06:00から金曜 24:00まで休まず営業で、祝日は 09:00~21:00 です。週末の時間はカカオマップにありません。ブログのレビュー(2026-01-10)には土 00:00~21:00, 日 09:00~21:00, 毎月第2日曜は休みと出ています。ブログのレビュー(2025-09-29)によると、1日券は₩30,000で、駐車まですると₩35,000です。インフォデスクで登録して、アプリで出席を記録します(レビュー 2025-04-25)。運動着がサイズ別に、タオルと一緒に置かれています(同じレビュー)。1日券に含まれるかはレビューにありません。1日入場の案内文には、入場は1回だけで「24時間ではない」と書かれています。室内履きがないと利用できず、貴重品はカウンターに預けるようにとの内容もあります(レビュー 2025-07-27)。住所はマポ区 (Yanghwa-ro 186 / 양화로 186)で、ホンデイック駅4番出口から1分です。

ヘルスボーイジム ピラガール ホンデ店 (Healthboy Gym Pilates Girl Hongdae / 헬스보이짐필라걸 홍대점)

ジムとマシンピラティスを一緒に運営しています。月 06:00~金 24:00 通し営業, 土 00:00~21:00, 日・祝日 10:00~21:00です(カカオマップのオーナー登録)。会社の公式ブログ(2025-09-22)に、1日券₩25,000(Day Pass: KRW 25,000)と「外国人も利用可能」が英語併記で書かれています。2026-09-13のレビューも₩25,000で、ネイバーのレビューを書くと₩20,000に割り引くと書かれていました。2026-06-21のレビューには、運動着とタオルがたっぷり置いてあると出ています。1日券に含まれるかはレビューにありません。住所はマポ区 (Yanghwa-ro 176 / 양화로 176) 地下1階で、ホンデイック駅8番出口から2分です。

ジムボックス フィットネス ホンデイック駅店 (Gymboxx Fitness Hongik Univ. Station / 짐박스피트니스 홍대입구점)

メルキュール アンバサダー ソウル ホンデ (Mercure Ambassador Seoul Hongdae / 머큐어 앰배서더 서울 홍대)の建物の地下1~2階です。公式ホームページに1回券(1 TIME PASS)₩15,000, 当日1回利用, 会員ウェア込みと出ています。この回でいちばん安い店です。公式の時間は平日 06:00~24:00, 週末 09:00~21:00, 年中無休で、カカオマップの表示時間も同じです。2026-02-15のレビューによると、出席チェックのあと更衣室に行き、タオルが提供され、シャワー室は6つです。住所はマポ区 (Yanghwa-ro 144 / 양화로 144)で、ホンデイック駅9番出口から2分です。

ザ・クライム ヨンナム店 (The Climb Yeonnam / 더클라임 연남점)

ロープなしで低い壁を登るボルダリング専門のクライミングジムです。公式の会員ページによると、1日利用券は₩22,000(その日1店舗)です。クライミングシューズのレンタル₩3,000、チョーク₩1,000は別払いです(公式の英語ページ)。公式Q&Aは、クライミングの経験がまったくなければ、経験者と一緒に行くか、体験レッスンを受けてから利用するようにと案内しています。体験レッスン₩30,000には、必須のレッスン、1日利用、クライミングシューズのレンタルが含まれています。体験レッスンは店舗ごとに決まった時間に、定員4名の予約制で行われます(公式Q&A)。カカオマップのオーナー登録の時間は月~金 07:30~24:00, 土・日・祝日 08:00~22:00です。公式の英語ページは平日 07:00からと書いています。ブログのレビュー(2026-10-12)には、平日の昼間も人が多く、外国人も多いと書かれています。住所はマポ区 (Yanghwa-ro 186 / 양화로 186) 3階で、エイブルジム ホンデイック駅店と同じ建物です。ホンデイック駅4番出口から1分です。

梨泰院路の大通り沿いの3階にあるジムです。1階のドアではなく、建物の左側の石段を上がると入口があります(レビュー 2025-09-07)。平日 06:00~23:00, 土・日 10:00~18:00, 祝日 12:00~17:00です(カカオマップのオーナー登録)。1日券は₩22,000です(レビュー 2025-10-20, 2025-09-07)。2025-10-20のレビューによると、共用の運動着はなく、タオルだけもらえます。シャワー室はあり、室内履きは自分で用意します。運動着を着て行くか、別に持って行きます。住所はヨンサン区 (Itaewon-ro 216 / 이태원로 216)で、梨泰院駅3番出口から7分です。

③ カンナム駅 — ジム1軒 + クライミングジム1軒

ヘルスボーイジム カンナム駅店 (Healthboy Gym Gangnam Station / 헬스보이짐 강남역점)

カンナム駅3番出口の前、ファストファイブビル (Fastfive Building / 패스트파이브빌딩)の地下にある大型ジムです。カカオマップの表示時間(2026-11-24)は月~金 06:00~24:00, 土・日 08:00~21:00です。1日券は₩25,000です(レビュー 2026-09-12)。2025-02-23のレビューによると、1日券にタオルと運動着が含まれ、ロッカーも追加料金なしで使えます。同じレビューには、シャワーブースが多くドライヤーがあると書かれています。住所はカンナム区 (Teheran-ro 2-gil 27 / 테헤란로2길 27)で、カンナム駅3番出口から3分です。

④ ソンス — ダンス1軒

ワンミリオンダンススタジオ (1MILLION Dance Studio / 원밀리언댄스스튜디오)

K-popの振り付け動画で知られるダンススタジオです。公式ホームページ(英語・韓国語・日本語)のチケットページに1 Class 30,000 KRWと出ています。定期の受講券なしで、1回券だけ買ってレッスンをひとつ受けられます。カカオマップの表示時間(2026-11-24)は月~金 16:00~22:00, 土・日 15:00~21:30で、実際のレッスンはホームページの時間割を見ます。アフィリエイト手数料の告知が付いたブログ記事(2026-10-10)によると、手順はこうです。ホームページかアプリで登録し、顔が写ったプロフィール写真をアップロードして、チケットを買ってからレッスンを予約します。スタジオではマイページのQRコードで入ります。同じ記事によると、キャンセルはレッスンの60分前までできて、無断で休むとチケットが引かれます。2026-08-02のカカオマップの英語レビューには、空間の雰囲気はいいけれど、ダンスを順を追って習うには合わなかったと書かれていました。初めてなら入門レッスンから選びます。住所はソンドン区 (Ttukseom-ro 13-gil 33 / 뚝섬로13길 33)で、ソンス駅3番出口から9分です。

🗺 1日のコース2つ

A. ホンデ到着日 — 空港鉄道からそのまま

  1. 仁川空港から空港鉄道でホンデイック駅で降りる
  2. 4番出口のLCタワー3階にあるザ・クライム ヨンナム店 (The Climb Yeonnam / 더클라임 연남점)で、体験レッスン(₩30,000)でボルダリングをしてみる。体験レッスンは予約制で、店舗ごとに決まった時間に定員4名で開かれるので、公式ホームページかネイバー予約で先に時間を押さえる
  3. 筋トレまでするなら、同じ建物の地下2階のエイブルジム(₩30,000)か、9番出口のジムボックス(₩15,000)に移る。1日券は1日1回の入場が基本なので、1か所で終えるほうがいい

B. 梨泰院の週末の朝

  1. 土・日 09:00に開く梨泰院ジム (Itaewon Gym / 이태원짐)で運動する。毎月第3日曜は休館(カカオマップ)
  2. 第3日曜か、午前が遅くなったら、10:00に開くディスイズジム (This Is Gym / 디스이즈짐)に変える。土・日は18:00に閉まる
  3. 運動のあと、梨泰院駅のほうへ下りてきて昼食をとる

⚠ よくある失敗3

  1. 室内履きなしで行く — エイブルジム ホンデイック駅店は室内履きがないと利用できないと案内していて、ディスイズジム (This Is Gym / 디스이즈짐)にも室内履きを持って行くようにというレビューがあります。外で履いた靴とは別の、きれいな運動靴をひとつ用意します。
  2. 近所の大手チェーンならどこでも使えると思う — スポアニ (Spoany / 스포애니)の公式Q&Aは、1年会員とプレステージ会員を案内しているだけで、1日券の案内はありません。1日券は店ごとに違うので、この回のように1日の料金が確認できた店に行きます。
  3. 週末の時間を平日と同じと考える — 平日に夜通し開いているジムも、週末は21:00に閉まる店が多くあります。ディスイズジム (This Is Gym / 디스이즈짐)は土・日 18:00に閉まります。エイブルジム ホンデイック駅店は毎月第2日曜、梨泰院ジム (Itaewon Gym / 이태원짐)は第3日曜が休みです。

⚙ FAQ 3

  1. パスポートは必要? — この回の9軒の公式案内には、1日券を買うときにパスポートを求めるという内容はありません。ワンミリオンは、アフィリエイト手数料の告知が付いたブログ記事によると、登録のときに顔が写ったプロフィール写真をアップロードします。
  2. 運動着なしで行ってもいい? — 1日券に運動着が含まれると確認できた店は、ジムボックス(公式, 会員ウェア込み)とヘルスボーイジム カンナム駅店(レビュー 2025-02-23)です。梨泰院ジム (Itaewon Gym / 이태원짐)は、レビューの書き手が含まれているようだと書いています。ディスイズジム (This Is Gym / 디스이즈짐)はタオルだけです。クライミングジムは、公式の案内どおり長ズボンと靴下を用意します。
  3. クライミングは初めてだけど、1日券だけ買ってもいい? — ザ・クライムの公式Q&Aは、経験がまったくなければ、経験者と一緒に来るか、体験レッスンを受けてから利用するようにと案内しています。体験レッスン(₩30,000)には、1日利用とクライミングシューズのレンタルが含まれています。公式の基準では、中学2年生(15歳)以上が利用できます。
