외국인용 한국 김치 맛집 12선 — 김치가 그날 맛을 좌우하는 노포

> 부제: 외국인 관광객용 김치찌개 노포·김치만두·김치족발·김치보쌈·김치말이국수·김치국밥·김치전 12선 + 김치 자체가 시그니처인 매장

ISSUE 03 · #835 · 2026-06-08

🎯 왜 김치 맛집 12선 가이드인가

[#834 김치+탕/국 12선](#834)이 탕/국에서 김치(깍두기)가 결정 요인이라면, 본 가이드는 김치 자체가 시그니처·매장 메인 메뉴인 노포 12선. 핵심: (a) 김치찌개·김치만두·김치족발·김치보쌈·김치말이국수·김치국밥·김치전·김치볶음밥 등 김치 = 음식 이름·재료 1순위·매장 평가 핵심 (b) 노포·30년+ = 사장님이 김치 직접 담금 (시장 김치·공장 김치 X) (c) 묵은지 (6개월+ 발효) = 매콤·시큼 매트릭스 = 매니아 매장 1순위 (d) 외국인 페인포인트 = "김치 = 그냥 반찬"이라 김치 메인 매장 매니아 X.

본 가이드는 김치 메인 7축 12 시그니처 + 노포 매트릭스 + 외국인 동선 + 한국 매니아 매트릭스.

🍲 김치 메인 7축 deep dive

① 김치찌개 (Kimchi-jjigae) — 한국 #1 일상 한식

  • 시그니처: 묵은지 + 돼지 (또는 참치) + 두부·매콤·시큼·국물 끓는 매트릭스
  • 외국인 페인포인트: 한국 매니아 #1·외국인 일부 매운맛 강함
  • 추천 매장:
  • 광장·종로 노포: 김치찌개 노포 (광장시장·청진동)·사장님 묵은지
  • 명동·이태원 외국인 친화: 영문 메뉴·픽업 OK
  • 체인 (놀부 부대찌개·새마을·이천식당·등등): 접근성·표준
  • 김치 시그니처: 묵은지 (6개월+ 발효)·매장 직접 담금 (노포)
  • 외국인 친화도: ★★★★ (매운맛 가감 가능)

  • 외국인 페인포인트: 만두 = 글로벌 친화 #1·김치 = 한국 적응 #1

  • 동대문·종로 만둣국 (겨울): 김치만두 국 (#11)

⚠ 외국인 자주 실수 5가지

1. "김치 = 그냥 반찬": 김치찌개·김치만두·김치보쌈·김치국밥 = 김치 메인 메뉴. 김치 자체가 시그니처.

2. "김치 메인 = 다 매움": 김치만두·김치보쌈·김치말이국수 = 안 매움 or 가감 매트릭스. 김치찌개·김치국밥·김치찜 = 매콤 매니아 매트릭스.

3. "보쌈 = 그냥 삶은 고기": 보쌈 = 김치 메인 (보쌈 김치 전용)·삶은 고기 페어. 한국 매니아 #1·외국인 친화.

4. "김치 노포 = 사장님 김치 X": 노포 30년+ = 사장님이 김치 직접 담금 = 매장 평가 핵심. 깍두기·묵은지·배추김치 시즌 시그니처.

5. "김치 맛집 = 외국인 모름": 김치보쌈·김치만두·김치볶음밥 = 외국인 친화 매트릭스. 영문 메뉴·픽업 OK·체인 多.

⚙ FAQ 6개

1. 외국인 입문 1순위: 김치만두 (#4)·김치보쌈 (#6)·김치볶음밥 (#10) = 안 매움·친화 매트릭스.

2. 한국 매니아 1순위: 김치찌개 노포 (#1)·김치국밥 (#8)·김치찜 (#12) = 묵은지 매콤·시큼.

3. 막걸리 페어: 김치전 (#9)·빈대떡 + 막걸리 = 미슐랭 페어링 ([#687·#688](#687) cross).

4. 여름 시그니처: 김치말이국수 (#7)·열무국수·냉면 + 동치미 = 시원 매트릭스.

5. 노포 평가 신호: 깍두기·묵은지 직접 담금·시즌 시그니처·사장님 김치 가르침 = 매장 평가 핵심.

6. 알레르기·식이 제한: 김치찌개·김치국밥 = 돼지·새우젓 (비할랄)·매콤. 김치만두·김치보쌈 (안 매움 옵션) = 외국인 친화 ↑.

김치 메인 음식 = 발효 (염분 ↑·매운맛 多·기름 다수). 임신부·고혈압·신장 환자 = 빈도 주의. 알레르기 (새우젓·멸치액젓·갑각류·돼지·콩) 사전 고지. 식중독·복통 시 ☎ 1339.

  • 할랄·코셔: 김치찌개·김치국밥 (돼지) = 비할랄. → 김치만두 (소고기 옵션)·김치 자체 (사찰음식 별도)
  • 채식·비건: 김치 메인 = 대부분 비채식. → 사찰음식 김치 (강남·인사동) = 채식 김치
  • 글루텐 free: 김치 메인 = 대부분 OK (간장 빼면)·김치만두 = 글루텐 함유 (만두피 밀가루)

✈️ 외국인 페인포인트 #1 — 노포 vs 체인 선택 가이드

  • 노포 (30년+): 사장님 김치 직접·매장 시그니처·매콤 매니아·재방문 단골 노하우 ↑
  • 체인 (놀부·새마을·체인): 영문·픽업·결제·접근성 ↑·표준 김치
  • 외국인 권장 동선:
  • 첫 방문: 체인 (안전·영문·표준) → 노포 (매니아 매트릭스)
  • 재방문: 노포 단골·사장님 김치 share·시즌 시그니처
  • 노포 매니아 ROI: 서비스 김치·시즌 시그니처·사장님 한국 문화 share = 무료 가치 ↑

💰 Essential Tourist Tips

  • 김치 메인 음식 가격 anchor (2026년 6월 기준):
  • 김치찌개 = 9,000~16,000원
  • 김치만두 = 6,000~12,000원
  • 김치보쌈 = 25,000~45,000원 (2~3인용)
  • 김치말이국수 = 8,000~14,000원
  • 김치국밥 = 9,000~14,000원
  • 김치전 = 8,000~16,000원/장
  • 김치볶음밥 = 9,000~14,000원
  • 김치찜 = 12,000~18,000원
  • 족발 + 김치 = 25,000~50,000원 (2~4인용)
  • 김치 무료 무제한 리필 ([#831](#831) 식당 동선) — 김치 메인 음식 매장도 표준
