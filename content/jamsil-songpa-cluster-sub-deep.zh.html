📍 百济的土城 — 梦村土城·风纳洞土城

梦村土城 (Mongchon Toseong / 몽촌토성)，松坡区 (Ollimpik-ro 424 / 올림픽로 424)，☎ 02-2147-2001，是位于奥林匹克公园 (Ollimpik Gongwon / 올림픽공원) 内的百济土城。利用靠近汉江支流的自然地形，把泥土夯实筑成城墙，在北城墙发现了竖立木栅栏的痕迹。是外城和内城重叠的结构，是3~4世纪汉城时代建造的城，属于史迹。从奥林匹克公园北2门 (Buk 2-mun / 북2문) 往梦村土城方向走，有展示出土文物的梦村历史馆 (Mongchon Yeoksagwan / 몽촌역사관)。

  • 开放时间:步行·自行车 05:00~22:00，车辆 06:00~22:00。梦村历史馆 09:00~18:00。
  • 休息日:全年无休。费用:免费。停车:前10分钟免费，之后每10分钟600韩元。

风纳洞土城 (Pungnap-dong Toseong / 풍납동 토성)，松坡区 (Pungnap-dong / 풍납동)，☎ 松坡区厅文化遗产科 (Songpa-gucheong Munhwayusan-gwa / 송파구청 문화유산과) 02-2147-2600，是百济汉城时期用土筑成的平地城，形似船。与汉江相接的西城墙已消失，现在约剩2.7km，原来的周长推测为3.7km。最初城墙高10.8m，加筑两次后最高达13.3m。1925年大洪水时出土了青铜鐎斗和腰带装饰等，1963年起为国家指定史迹。里面确认了百济初期的道路痕迹和大型建筑遗址。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

📍 百济的坟墓 — 芳荑洞古坟群·石村洞古坟群

芳荑洞古坟群 (Bangi-dong Gobungun / 방이동 고분군)，松坡区 (Ogeum-ro 219 / 오금로 219)，☎ 松坡区厅文化遗产科 02-2147-2001，是建在低矮丘陵山脊上的坟墓群，1970年代发掘后经整修成为公园。现存坟墓8座，西边高处4座，东边低处4座。因第6号坟出土了新罗陶器，曾被认为是新罗坟墓，但随着在首尔Umyeon-dong (Umyeon-dong / 우면동)、河南Gwangam-dong (Hanam Gwangam-dong / 하남 광암동)、城南Pangyo (Seongnam Pangyo / 성남 판교) 等地接连发现百济的横穴式石室墓，据介绍，认为是百济坟墓的主张越来越有力。

  • 开放时间:08:00~18:00。休息日:全年无休。费用:免费。停车:每5分钟100韩元。

石村洞古坟群 (Seokchon-dong Gobungun / 석촌동 고분군)，松坡区 (Garak-ro 7-gil 21 / 가락로7길 21)，☎ 松坡区厅文化遗产科 02-2147-2608，是百济汉城时期国王和贵族的坟墓群。日本殖民时期调查时曾报告石村洞和Garak-dong (Garak-dong / 가락동) 一带有300余座，但现在只剩西边一部分。据韩国观光公社介绍，最大的3号坟是宽50.8m、高4.5m的3层积石冢，推测是百济近肖古王的坟墓。2015年之后的调查中出土了百济陶器、金饰品等。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

📍 湿地·公园·博物馆 — 芳荑洞生态景观保护区·Ogeum公园·松坡书籍博物馆

芳荑洞生态景观保护区，松坡区 (Dongnam-ro 397 / 동남로 397)，☎ 松坡区厅公园绿地科 (Songpa-gucheong Gongwon Nokji-gwa / 송파구청 공원녹지과) 02-2147-3401，是1970年代初为取烧砖的土而挖出水坑形成的人工湿地。随着人员出入受限，生物在此扎根。可以看到Mureokse (물억새)和Aegibudeul (애기부들)等湿地植物，以及绿头鸭和翠鸟等鸟类。因是保护区，禁止采摘，也不能带宠物。

  • 开放时间:09:00~17:00。休息日:每周一。费用:免费。
  • 停车:不可以。

Ogeum公园，松坡区 (Ogeum-dong 51 / 오금동 51)，☎ 02-400-0978，是把地铁5号线Ogeum站 (Ogeum-yeok / 오금역) 附近的小山改造成的公园。有生长着野生草花30余种和灌木20种的自然学习场、5处广场、9条步行道、儿童游乐场和运动设施。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

松坡书籍博物馆，松坡区 (Songpa-daero 37-gil 77 / 송파대로37길 77)，☎ 02-2147-2486，据韩国观光公社介绍，是全国首座公立书籍博物馆。1层有阶梯式多功能空间“Eoullim Hall (Eoullim Hol / 어울림홀)”和儿童体验展厅“Bookkium (Bukkium / 북키움)”，2层有以书和阅读为主题的常设·企划展厅和媒体图书馆。

  • 开放时间:10:00~18:00(入场截止 17:30)。休息日:每周一，1月1日，春节·中秋节当天。
  • 费用:免费。停车:前30分钟免费，之后每5分钟150韩元。

📍 市场与购物街 — Garak商场·Bangi市场·Pungnap Dokkaebi市场·Munjeong-dong Rodeo街

Garak商场，松坡区 (Yangjae-daero 932 / 양재대로 932)，☎ 02-3435-1000，是位于Garak农水产品批发市场 (Garak Nongsusanmul Domaesijang / 가락농수산물도매시장) 旁边的现代化购物中心，共7栋。销售栋地下1层是蔬果，1层是水产·干货·畜产品，2层是综合商场和厨房用品，3层是特色餐厅馆。

  • 开放时间:各店不同。休息日:全年无休(各店不同)。停车:可以。

Bangi市场，松坡区 (Garak-ro 243 / 가락로 243)，☎ 02-413-2100，是1980年代末起形成的小巷型市场。有卖衣服、蔬菜、鱼、水果、杂货的店铺140余家，小吃·年糕·小菜等吃的东西很多。

  • 开放时间·休息日:各店不同。停车:可以。

Pungnap Dokkaebi市场，松坡区 (Baramdeuri-gil 37-1 / 바람드리길 37-1)，☎ 070-8792-4500，起初是包袱商贩白天出现、傍晚消失的“鬼怪市场 (Dokkaebi Sijang / 도깨비시장)”，正在逐渐成为固定市场。卖农水产品、畜产品、衣服和小吃。离风纳洞土城很近。

  • 开放时间·休息日:各店不同。停车:可以。

Munjeong-dong Rodeo街，松坡区 (Dongnam-ro 4-gil 10 / 동남로4길 10)，☎ 02-400-1633，是国内外品牌折扣店聚集的街道，30多年来一直作为路边奥特莱斯。有运动、休闲、鞋类、正装、高尔夫服装的店铺。

  • 开放时间·休息日:各店不同。停车:每10分钟300韩元。

⚠ 行前须知 3 点

  1. 芳荑洞古坟群只在08:00~18:00开放 — 风纳洞土城和石村洞古坟群全天开放。
  2. 芳荑洞生态景观保护区和松坡书籍博物馆周一休息 — 保护区09:00~17:00开放，不能带宠物。
  3. 市场和Rodeo街各店开放时间不同 — 没有登记的统一营业时间。

⚙ FAQ 2

Q. 参观百济遗址要付费吗?

A. 按观光公社登记信息，梦村土城、风纳洞土城、芳荑洞古坟群、石村洞古坟群入场均免费。

Q. 推测是近肖古王坟墓的地方是哪里?

A. 石村洞古坟群的3号坟。是宽50.8m、高4.5m的3层积石冢。
