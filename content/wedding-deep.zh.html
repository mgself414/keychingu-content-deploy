🏮 传统婚礼——首尔2处

  • 云岘宫 (Unhyeongung / 운현궁) — 首尔钟路区三一大路464号 (Samil-daero / 삼일대로)，客服中心 02-766-9090(云岘宫官方网站)。婚礼在老乐堂 (Norakdang / 노락당) 举行
  • 2026年白天场婚礼: 4月4日~6月14日、9月5日~11月15日的周六·周日 11:00/13:00/15:00，每场30~40分钟。1,534,500韩元(含增值税，定金440,000韩元)。2026年白天场婚礼的咨询·预约已经截止
  • 2026年夜间场婚礼: 10~11月周六·周日 18:00，2,167,000韩元(含增值税，定金444,000韩元)。通过电话受理
  • 包含: 执行人员(执礼·司仪·侍母 (Sumo / 수모) 4名·工作人员)、婚礼服(新郎纱帽·团领袍·木靴 (Mokhwa / 목화) / 新娘圆衫·簇头里·发簪 (Binyeo / 비녀)·发带 (Daenggi / 댕기)，鞋子另计)、雁夫 (Girgeogabeom / 기럭아범) 服装、醮礼桌布置(青红线·瓢杯·栗子·红枣等)、签到簿·红包袋。礼堂(老乐堂)的币帛 (Pyebaek / 폐백) 另加220,000韩元
  • 咨询: 须先预约咨询，由主婚人或受委托人到场面谈后才能签约。不预约直接去，很难咨询
  • 2027年日程未能确认——请查看官方网站公告
  • 韩国之家 (Hanguk-ui Jip / 한국의집) — 首尔中区退溪路36街10号 (Toegye-ro 36-gil / 퇴계로36길)，婚礼咨询 02-3011-9236(韩国之家官方网站)。1957年作为迎宾馆建成，自1982年起举办传统婚礼
  • 2026年日程: 3~6月、9~11月的周六17时。仪式在中庭院子 (Jungjeong Madang / 중정마당)(室外) 举行
  • 包含: 场地租用(中庭)·醮礼桌布置·新郎新娘基本婚礼服·祝贺演出(三弦六角 (Samhyeon Yukgak / 삼현육각))·婚礼用具·执礼·执事·雁夫 (Girgeogabeom / 기럭아범) 服装。布置·造型(含鲜花)另与选定的外部公司签约
  • 宴席: 韩定食 (Hanjeongsik / 한정식) 套餐每人150,000韩元(含税，不含饮料·酒类)，最少60人~最多80人
  • 婚礼基本金额页面上没有——只说明“各套餐的选项·附加费用请向婚礼室咨询”。来访咨询须事先预约
  • 南山谷韩屋村 (Namsangol Hanok Maeul / 남산골한옥마을) 也一直举办传统婚礼(首尔市)，但这次无法连接其官方网站，未能确认2026~2027年的日程·金额。

🏨 酒店婚礼——首尔新罗酒店迎宾馆

  • 首尔新罗酒店迎宾馆 (Seoul Silla Hotel Yeongbingwan / 서울신라호텔 영빈관) — 首尔中区东湖路249号 (Dongho-ro / 동호로)(新罗酒店官方)。以展现韩国传统之美的独栋空间，介绍称设有室内花园·室外花园2处和宴会厅3处，从家庭式婚礼到户外婚礼都可举办
  • 容纳人数(套餐晚宴标准): 红宝石厅 (Rubi / 루비) 150人 · 黄玉厅 (Topaz / 토파즈) 130人 · 祖母绿厅 (Emerald / 에메랄드) 130人 · 室内花园 200人 · 室外花园 430人(新罗酒店官方)
  • 咨询: +82-2-2230-3321，Instagram @theshillawedding
  • 价格: 官方页面未公布——需要咨询
  • 其他酒店婚礼场地这次没能打开其官方婚礼页面确认，因此没有收录。挑选酒店请看 外国人韩国豪华酒店深度探索

📸 韩服·婚纱摄影——宫殿与云岘宫的规则

  • 景福宫等宫殿·宗庙·朝鲜王陵(宫陵遗迹本部 / Gungneung Yujeok Bonbu / 궁능유적본부) — 即使是游客的纪念拍摄，只要符合以下情形就需要事先拍摄许可，未经许可拍摄可能被叫停或被限制入场
  • 穿着礼服(韩服·婚纱等)，并带入2台相机以外的设备(三脚架·灯光·反光板等)的情形
  • 穿着礼服，每次拍摄有2名以上工作人员进入的情形——摄影师·个人抓拍摄影师·工作室员工，负责拍摄的熟人也算作工作人员
  • 使用礼服以外的非日常服装·道具的情形
  • 申请期限: 拍摄日前60天至前5天(含周末则为前7天)
  • 现场禁止: 宫内不得化妆·换衣服。拥挤的日子，每天拍摄次数以及殿阁台阶·月台 (Woldae / 월대) 上的拍摄可能受到限制
  • 景福宫入场: 外国成人(满19~64周岁)3,000韩元。传统韩服·生活韩服都属于免费参观对象，但必须上衣 (Jeogori / 저고리) 与裙子·裤子穿齐。只披一件外套 (Durumagi / 두루마기)，或牛仔裤配短上衣的，都不免费(宫陵遗迹本部)
  • 云岘宫 (Unhyeongung / 운현궁)(云岘宫官方网站) — 婚纱摄影公司·韩服租赁公司·工作室的韩服抓拍属于免费拍摄对象
  • 可拍摄时间: 每天 09:30~17:30，每队60分钟以内
  • 申请: 拍摄3天前之前，将纪念拍摄许可申请书和国家遗产保护承诺书通过电子邮件(unhyeongung_official@naver.com)提交
  • 设备: 只能带入三脚架1个·自拍杆1个。禁止灯光·录音设备、换衣服·化妆、吹泡泡。利用上马石 (Nodutdol / 노둣돌)·水井·石臼等文物的拍摄也不可以
  • 云岘宫周一休馆(遇公休日则正常开放)
  • 租韩服请看 韩国韩服租赁，从押金到还衣 — 零慌张流程手册，工作室拍摄请看 韩服写真

🧰 婚礼实务——预约、付款、法律手续、交通

  • 预约顺序: 云岘宫、韩国之家都是预约咨询 → 来访咨询 → 签约。云岘宫须由主婚人或受委托人亲自到场(云岘宫)。如果人在海外，先问清楚能否委托在韩国的家人或策划师担任受委托人
  • 语言: 两处是否提供英语主持，在官方页面上未能确认——需要翻译的话，咨询时询问
  • 付款: 定金先付(云岘宫白天场440,000韩元)。付款方式请看 外国人韩国支付系统深度探索
  • 宾客用餐: 韩国之家的宴席是韩定食 (Hanjeongsik / 한정식) 套餐。有素食·清真宾客的话，咨询时提前告知，替你开口说明的卡片请看 韩国饮食需求·辣度调节，零慌张手册 — 靠展示卡片就能搞定
  • 法律手续(结婚登记·签证): 本文不涉及。结婚登记由大法院电子家族关系登记系统 (Daebeobwon Jeonja Gajok Gwangye Deungnok Siseutem / 대법원 전자가족관계등록시스템) 说明，居留·结婚移民签证由法务部HiKorea (Beobmubu Hai Koria / 법무부 하이코리아) 说明。各国国籍的要求不同，因此请直接向本国使领馆和韩国机构确认
  • 交通: 韩国交通卡3种选择，零慌张手册 — 按我的行程原样挑卡

⚠ 常见失误4条

1. “朋友帮忙拍就不需要许可” — 宫陵遗迹本部把负责拍摄的熟人也算作工作人员。穿韩服·婚纱，工作人员2人以上就属于需事先许可的对象(宫陵遗迹本部)

2. “在宫里的洗手间换上婚纱就行” — 宫殿和云岘宫都禁止在园内换衣服·化妆(宫陵遗迹本部·云岘宫)

3. “传统婚礼哪个月都能办” — 云岘宫、韩国之家都是春秋两季制。云岘宫2026年白天场婚礼已经截止(云岘宫·韩国之家)

4. “只披一件短上衣也能韩服免费入场” — 必须上下装齐全(宫陵遗迹本部)
