为什么现在要去药令市——9大市场集群 + 韩国头号中药材

清凉里 (Cheongnyangni / 청량리)·祭基洞 (Jegi-dong / 제기동) 一带是9大市场组成的综合集群——京东市场 (Gyeongdong Sijang / 경동시장)、清凉里综合市场、农水产市场、水果市场、药令市 (Yangnyeongsi / 약령시) 等。京东市场药令市 = 韩国头号中药材批发市场。与K-Medical医疗观光(#404·#593)高度契合。

外国游客关注这一地区的原因有两个。首先，单一地铁站方圆500米内聚集了9大市场，一天之内即可逛遍。其次，药令市并非为观光而复原的场景，而是由真正的中医药师·批发商经营、拥有600年历史的日常生活市场。朝鲜王朝时代位于光化门的药令市，于20世纪60年代迁至祭基洞，延续至今。

12选4大分类

分类1：药令市中药材(3选)——韩国头号

1. 京东市场药令市

韩国最大的中药材批发市场。 位于东大门区药令中央路一带。拥有600年历史，聚集约1,000余家中药房·批发商。可按批发价购买人参、红参、中药材及韩方相关健康食品。

  • 营业时间：工作日·周六08:00–18:00。周日各店铺自行决定(多数休息，建议提前确认)。
  • 价格(2026年基准)：可单独购买中药材(红参100g ₩30,000–80,000 / 当归100g ₩5,000–15,000 / 枸杞100g ₩4,000–10,000，价格因等级·产地而异)。滋补中药全套(含韩医院处方)：₩250,000–420,000。
  • 外国游客契合度：由于批发市场的特性，以韩语沟通为主，能说外语的商家较少。建议先参观韩医药振兴中心后再前往。
  • 最佳时段：上午10:00–12:00人流较少，商家接待也较从容。傍晚大部分店铺已打烊。
  • 外国游客常见失误：部分店铺设有批发最低购买量要求。若想少量购买，请先用韩语确认"能零售吗？"(소매 됩니까?)。

2. 首尔韩医药振兴中心

位于东大门区药令中央路26号。 是外国游客初次接触药令市时的首选参观地。设有韩医药文化馆、体验项目及多语导览。

  • 营业时间：周二至周日09:00–18:00，周一固定休息。
  • 体验项目：韩方茶试饮、药材鉴别体验、韩方足浴、四象体质咨询。部分体验项目收费(₩3,000–10,000)。
  • 英语服务：有1~2名职员可用英语沟通(水平因到访时段而异，备有英文宣传册)。
  • 外国游客契合度：★★★★★。多语指示牌、免费参观区域、药材展示等，非常适合入门参观，即使没有韩方基础知识也能理解。
  • 交通：祭基洞站2号出口步行5分钟。

3. 药令市韩医院集群

京东市场药令市内及周边聚集了数十家韩医院，可进行滋补处方、针灸、四象体质咨询。

  • 营业时间：各家不同，通常为10:00–18:00。
  • 外国游客就诊：能用外语诊疗的韩医院较少，建议在首尔韩医药振兴中心咨询台咨询可提供口译支持的韩医院。
  • 价格：初诊₩30,000–50,000 / 针灸1次₩30,000–80,000 / 滋补药全套₩250,000–500,000。
  • 小贴士：与医疗观光套餐(#404)联动时可获得口译及预约支持。

分类2：清凉里市场(3选)

4. 清凉里综合市场

清凉里站一带9大市场的行政枢纽。与其说是单一名称的市场，不如说是多个市场连续排列而成的集群，由服装、干货、水果、水产、农产品等构成。

  • 营业时间：06:00–20:00(傍晚路边摊营业至22:00)。
  • 外国游客契合度：★★★☆☆。属于生活型市场，外语服务有限，适合以观光·体验氛围为目的前往。
  • 价格区间：食材类商品大量购买时价格约为零售价的60–80%。
  • 最佳时段：上午7:00–9:00最为热闹，下午2点后部分店铺开始收摊。

5. 清凉里传统市场

毗邻综合市场，是以老字号为中心的巷弄型市场，分布着杂货、熟食及老字号餐馆。

  • 营业时间：各店铺不同，通常为07:00–18:00。
  • 外国游客契合度：★★★☆☆。贴近当地人日常生活，适合以拍照·感受氛围为目的前往。
  • 注意事项：市场内公用洗手间仅1处，建议提前确认位置。

6. 清凉里光成商城

位于清凉里市场内部的拱廊式商场 (Gwangseongmall / 광성몰)，以服装、杂货、生活用品为主。

  • 营业时间：10:00–18:00，部分店铺周日休息。
  • 外国游客契合度：★★☆☆☆。相较购物，更适合帮助理解市场整体结构。

分类3：农水产·凌晨市场(3选)

7. 清凉里农水产市场

由70家商铺、4大分区构成。 经营蔬菜、水果、水产品、干货、调味料等，批发与零售并行。

  • 营业时间：04:00–17:00(凌晨04:00–08:00为批发高峰期)。
  • 价格：比零售价便宜20–40%，大量购买时可另行议价。
  • 外国游客契合度：★★★☆☆。凌晨到访可直接体验当地人的生活方式，上午9点后更方便进行一般零售购买。
  • 交通：清凉里站步行3分钟。
  • 关联篇目：可与#587凌晨市场系列串联行程。

8. 清凉里水产市场

农水产市场内的水产区域，经营活鱼与干货。

  • 营业时间：05:00–16:00。
  • 小贴士：干货方面中部市场(#597)更为专业，本市场则更适合购买新鲜水产品。

9. 清凉里水果市场

以高性价比水果而论堪称首尔第一。 以批发货源直接对接零售。

  • 营业时间：05:00–18:00。
  • 价格示例(2026年基准，随季节变动)：草莓1kg ₩5,000–10,000 / 苹果5kg ₩12,000–20,000 / 香瓜5kg ₩8,000–15,000。
  • 外国游客契合度：★★★★☆。语言障碍较低，用手指指认即可购买，少量购买大多也没问题。
  • 最佳时段：上午7:00–10:00新鲜度最佳。

分类4：外国游客·体验(3选)

10. 多语药房·药令市文化体验

药令市周边有多家可用英/中/日语应对的药房，是安全购买以中药为基础的健康食品——红参精、拱辰丹 (Gongjindan / 공진단) 等——的渠道。

  • 拱辰丹价格(2026年基准)：1丸₩30,000–80,000(药房销售款，等级差异较大，购买前需确认来源)。
  • 红参精：₩50,000–150,000(因容量·品牌而异)。
  • 外国游客常见失误：未确认成分·用量便购买，可能导致回国时无法通关。建议向药师索取英文成分表。

11. K-Medical医疗观光关联篇(#404·#593)

将药令市集群与医疗观光套餐联动的外国游客正在增加，通常将韩医院诊疗 + 药令市药材购买 + 韩医药振兴中心文化体验组合为一日行程。

  • 预约渠道：首尔医疗观光信息中心(位于1·2号线换乘站附近综合医院旁，提供英文支持)，建议提前确认。
  • 口译支持：东大门区保健所面向外国人的医疗口译服务(需提前预约，免费)，建议提前确认。

12. 干货·调味料店铺(关联#597)

京东市场内也有干货·调味料店铺，种类虽不及中部市场(#597)丰富，但可在游览药令市的动线中顺便购买。

  • 热门商品：干辣椒、香油、紫苏籽油、鳀鱼干、海带。
  • 包装：可要求真空包装，回国时能否随身携带需向各航空公司个别确认。

外国游客常犯的3个错误

错误1：周日前往药令市

药令市的中药房·韩医院大多数在周日休息。若计划周末前往，建议选择周六，或在出发前确认首尔韩医药振兴中心(营业时间：周二至周日)当天是否开放后再规划行程。

错误2：未确认中药·健康食品能否携带出境便购买

中药材·保健食品的通关规定因国家而异。尤其动物性成分(鹿茸、熊胆等)可能属于CITES公约管制对象，部分植物提取物在某些国家也需符合农药残留标准或取得进口许可。建议购买前向药师索取英文成分说明，并事先确认本国海关规定。

错误3：在批发市场尝试少量购买

清凉里农水产市场·京东药令市部分店铺设有批发最低数量或最低金额标准，应先确认是否可零售。专营零售的店铺通常会有单独标示，或多位于市场入口附近。

实用信息

交通

  • 药令市：1号线祭基洞站1号出口步行3分钟(进入药令市)，2号出口步行5分钟(韩医药振兴中心)。
  • 清凉里市场群：1号线·京义中央线·京春线·水仁盆唐线·KTX清凉里站，是首都圈铁路枢纽，交通极为便利。
  • 两区域连接：祭基洞站至清凉里站为1号线1站距离(2分钟)，步行连接约需15分钟。

支付

  • 韩医药振兴中心·大型中药房：大多可以刷卡。
  • 小型中药房·摊位·部分农水产市场：更倾向使用现金，建议随身携带₩50,000–100,000现金备用。
  • 清凉里市场区域：现金使用比例较高，ATM设于清凉里站内。

语言

  • 英语：韩医药振兴中心及部分可用外语服务的药房提供有限的英语应对。
  • 翻译软件：可用Papago、谷歌翻译的拍照翻译功能，实时确认中药材名称与价格标签。
  • 紧急情况：☎ 1330(旅游翻译热线，提供英·中·日·越南语24小时免费服务)。

中药材出境指南

  • 植物性中药材(人参、当归、黄芪等)：大多数国家允许个人使用量的少量携带，但必须为干燥·密封状态。
  • 动物性成分(鹿茸、海狗肾、熊胆等)：可能属于CITES公约管制对象，购买前务必确认成分。
  • 精华液·胶囊形态：属于加工完成品，通常较易携带出境，请确认是否有英文标签。
  • 拱辰丹：请确认是否含有麝香成分，麝香(Musk)属于CITES管制对象。
  • 原则：如有疑问，购买前可拨打☎ 1330用英语咨询。

常见问题5则

Q1. 首次到访药令市，该从哪里开始？

建议从首尔韩医药振兴中心(祭基洞站2号出口步行5分钟)开始。通过英文宣传册与展示空间先了解韩方基本概念，再逛药令市内的店铺会更加轻松，中心内还设有免费韩方茶试饮区。

Q2. 想接受中药处方，有能用外语沟通的韩医院吗？

可在首尔韩医药振兴中心咨询台获得能用外语应对的韩医院信息，也可利用东大门区保健所面向外国人的医疗口译服务(需提前预约，免费)陪同就诊，建议提前确认。

Q3. 大致价格区间是？

  • 中药材少量购买：₩5,000–30,000(因品项而异)
  • 滋补中药全套处方：₩250,000–420,000
  • 红参精：₩50,000–150,000
  • 拱辰丹1丸：₩30,000–80,000(因等级而异)
  • 水果市场少量购买：₩5,000–15,000
  • 农水产品：比零售价便宜20–40%

Q4. 值得凌晨前往吗？

清凉里农水产市场04:00–08:00为最繁忙时段，若以体验当地凌晨市场氛围为目的，该时段非常合适。药令市·韩医药振兴中心则建议09:00以后前往。

Q5. 一天之内能逛完药令市和清凉里市场吗？

可以。推荐动线：09:00韩医药振兴中心 → 10:00京东药令市 → 12:00市场内用餐 → 13:30清凉里综合市场·水果市场 → 15:00农水产市场 → 16:00结束行程。两区域相距地铁1站(步行15分钟)。
