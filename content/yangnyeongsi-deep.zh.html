首尔药令市·京东市场指南——药材市场漫步、韩医药博物馆泡脚、京东1960夜市（2026 官方信息）

🎯 本指南使用方法

从1号线祭基洞站 (Jegi-dong / 제기동역) 2号出口出发，就能步行串起首尔药令市 (Seoul Yangnyeongsi / 서울약령시)（药材街）→ 首尔韩方振兴中心 (Seoul Hanbang Jinheung Center / 서울한방진흥센터)（韩医药博物馆·泡脚）→ 京东市场 (Gyeongdong Sijang / 경동시장)（食材·夜市·星巴克京东1960 (Starbucks Gyeongdong 1960 / 스타벅스 경동1960)），是一条半天的路线。下文的时间和地址，只写2026-10-07在首尔市“我手中的首尔”、东大门区 (Dongdaemun-gu / 동대문구)、首尔韩方振兴中心官方页面上读到的数值；博物馆门票、周一是否闭馆、泡脚价格这类官方页面没有的信息，一律写作“未核实”。旧版指南中的“600年历史”“1960年代以前从光化门迁来”“祭基洞站1号出口”与官方记录不符，已删除。

🌿 首尔药令市——全国最大的药材市场

  • 首尔市官方介绍：全国最大的药材市场，相关店铺约1,000家，国内药材的约2/3、首尔人参和蜂蜜的约3/4都经由这里（我手中的首尔 2023）。
  • 历史（官方）：1970年代，*钟路 (Jongno / 종로)* 4·5街的药材商迁来此地，1995年被认定为首尔药令市，2013年被指定为文化观光型市场。
  • 09:00~18:00，药令中央路10号。这里是批发街，想少量购买请去挂有零售招牌的店铺。价格没有公示，因此不列出。
  • 外国游客提示：药材和保健食品各国的入境规定不同，回国前请先查询本国海关规定（本指南不对规定作任何断言）。

🏛 首尔韩方振兴中心——韩医药博物馆 + 泡脚

  • 由东大门区运营。3~10月 10:00~18:00，11~2月 10:00~17:00，闭馆日为1/1·春节·中秋（官方；2026年中秋9/25闭馆已发公告）。周一是否闭馆以及门票，在官方页面上没有读到——请到现场确认。
  • 展览：药草360种·文物420件。节目（官方列表）：药草泡脚体验·普济院韩方体验·普济院流动诊疗。泡脚费用官方未公布（二手来源为6,000韩元）。
  • 旧版指南中的“免费韩方茶品尝·四象体质咨询·英语工作人员”在官方页面上没有，已删除。
  • 药令中央路26号，祭基洞站2号出口。

🛒 京东市场——白天的市场、夜市、京东1960

  • 1960年开业，08:30~18:00（工作日·周末相同），高山子路36街3号，距祭基洞站2号出口381m（首尔市·东大门区官方）。是售卖药材·干货·蔬菜·水果·年糕等的食材市场。
  • 京东1960夜市：周五~周日 18:00~23:00（首尔市官方）。白天逛药令市，傍晚再来，正好一整天。
  • 星巴克京东1960：由1994年关门的京东剧场改造，位于3~4层的门店（首尔市官方）。营业时间各来源在09~23点与09~22点之间矛盾，故为未核实。
  • 京东广成商街：1948年成立，以食品为主（东大门区官方）。旧版指南中的“服装·杂货商场”是错误的。

📍 为什么没有清凉里一带的市场

  • 旧版指南中的“清凉里 (Cheongnyangni / 청량리) 9个市场集群·农水产品市场70家店·4个区域·水果价格”，这次没能打开官方页面核实，全部删除。清凉里综合市场将在#609中单独介绍。

🚇 交通·半天路线

  • 祭基洞站（1号线）2号出口 → 首尔药令市街（30分钟）→ 首尔韩方振兴中心（含泡脚1小时）→ 京东市场（食材·小吃1小时）→ 周五~周日可去京东1960夜市（18点起）。
  • 周一博物馆是否闭馆官方未公布，出发前请电话确认。有二手来源称周日药材店铺多半休息，所以工作日·周六白天最稳妥。

⚠ 常见错误5条

1. 走1号出口——药令市·博物馆·京东市场都在2号出口（官方）。

2. 9点去博物馆——10点开馆（11~2月17点闭馆）。

3. 周日去药材街——许多店铺休息（二手来源）。请选工作日·周六白天。

4. 想用批发价少量购买——请去挂零售招牌的店铺。

5. 带着药材随便出境——先查本国海关规定。

⚙ FAQ 6条

1. 博物馆门票多少钱？——官方页面上没有。请现场确认（二手来源为小额）。

2. 泡脚呢？——药草泡脚体验在官方节目列表中。费用未公布。

3. 夜市什么时候？——京东1960夜市 周五~周日 18:00~23:00。

4. 星巴克京东1960开到几点？——未核实（09~22/23点相互矛盾）。请查看门店页面。

5. 英语呢？——博物馆是否有英语导览·工作人员，官方未公布。请带好翻译App。

6. 为什么称“全国最大”？——这是首尔市官方资料的说法（约1,000家·国内药材2/3）。
