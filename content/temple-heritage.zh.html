⚠ 外国游客常犯的3个错误

1. “韩国寺庙 = 日本·中国寺庙”: 韩国寺庙 = 佛教 + 自然 + 韩式丹青 (Dancheong / 단청)·窗棂 (Munchangsal / 문창살) 的结合。与日本寺庙 (简单与自然结合)·中国寺庙 (宏大色彩) 有所不同。镇宽寺 (Jinkwansa Temple / 진관사)·吉祥寺 (Gilsangsa Temple / 길상사)·奉恩寺 (Bongeunsa Temple / 봉은사) 深度体验韩国丹青 (Dancheong / 단청)·韩国枫叶·韩国寺庙饮食 (Sachal Eumsik / 사찰음식)。

2. “朝鲜四大宫殿 = 都一样”: 四大宫殿各有特色:

  • 景福宫 (Gyeongbokgung / 경복궁) = 正宫·守门将交接仪式 (Sumunjang Gyodaesik / 수문장 교대식) (外国游客拍照首选)
  • 昌德宫 (Changdeokgung / 창덕궁) = 亲近自然·后苑 (Hu won / 후원) (联合国教科文组织)
  • 昌庆宫 (Changgyeonggung / 창경궁) = 日帝动物园 → 修复历史
  • 德寿宫 (Deoksugung / 덕수궁) = 韩国近代 (大韩帝国·日俄战争) + 石造殿 (Seokjojeon / 석조전) (西式)

3. “成均馆 (Sungkyunkwan / 성균관) = 普通学校”: 成均馆 (Sungkyunkwan / 성균관) 是1398年朝鲜第一教育机构 (朝鲜28位国王都在此接受教育) + 明伦堂 (Myeongnyundang / 명륜당)·大成殿 (Daeseongjeon / 대성전)·尊经阁 (Jonkyunggak / 존경각) 韩国第一传统建筑。外国游客体验韩服 (Hanbok / 한복)·深度探索韩国学问的首选。
