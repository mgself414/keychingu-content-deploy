釜山甜点之路 — 从红豆之城到意式冰淇淋

副标题: 咖啡之路(#1321)之后的下一站是甜点。釜山既是红豆之城——红豆刨冰、红豆粥小巷甚至被收录进地方文化大典,也是广安里的意式冰淇淋店与欧式风格烘焙咖啡馆逐年增多的城市。在本地收藏信号中,仅次于美食的第二大集群正是甜点——按传统红豆轴线、国际轴线、海景轴线三条脉络,整理出的釜山甜蜜地图。

ISSUE · #1324 · 2026-08-23

🎯 釜山甜点的三条脉络

汇总釜山本地策展账号的收藏就会发现,仅次于美食的第二大板块正是甜点(本次采集中釜山甜点信号共25条)。脉络分为三条:①以红豆为代表的传统轴线,②意式冰淇淋 (Gelato / 젤라또)·可丽饼 (Crepe / 크레페)·欧式烘焙的国际轴线,③临海而立的海景轴线。如果说首尔甜点圈靠"上新速度"运转,釜山则因为有红豆这一根源+大海这一背景,语法完全不同。

① 红豆之城 — 传统轴线

  • 釜山的红豆刨冰 (Patbingsu / 팥빙수)·红豆粥 (Patjuk / 팥죽)小巷甚至被收录进地方文化记录(釜山历史文化大典),红豆文化的根基之深可见一斑。冬天喝红豆粥、夏天吃红豆刨冰跨季而食,是釜山式的生活方式。
  • 白家红豆铺 (Baekpatjip / 백팥집)(东莱 (Dongnae / 동래)) — 专营手工红豆制成的红豆刨冰与红豆包 (Danpatppang / 단팥빵)。不过分甜腻的红豆刨冰搭配馅料扎实的红豆包是招牌组合,常常早早售罄,白天前往更保险。
  • 东莱老式红豆刨冰 (Dongnae Yennal Patbingsu / 동래옛날팥빙수) 这类老字号红豆刨冰店也在同一片区域——东莱正是K-pop巡礼(#1323)中BASECOFFEE所在的街区,很适合串联进甜点动线。
  • 伴手礼级K甜点:年糕专门店慧眼池 (Hyeanji / 혜안지)、烘焙点心专门店人香万里 (Inhyangmalli / 인향만리) 这类本地工坊型门店,在Instagram收藏信号中排名靠前——比起机场免税店,在社区工坊购买伴手礼才是当下的新语法。

点单小贴士: 红豆刨冰的吃法

1. 红豆刨冰的基本吃法是不搅拌、从最上层开始舀着吃——冰、红豆、配料的分层本身就是设计。

2. "不太甜"是一种称赞——越是手工红豆专门店,越靠红豆本身的味道而非糖分取胜。

3. 配上一个红豆包就能当一顿正餐——这是釜山红豆店基本的套餐感。

② 国际轴线 — 意式冰淇淋·可丽饼·欧式风情

  • La Mia Estate(라 미아 에스타떼)(广安里 (Gwangalli / 광안리)) — 本地推荐中被称为"意大利政府认证意式冰淇淋"的冰淇淋店。开心果口味是招牌选择。紧邻广安里海边散步道是其一大优势。
  • 可丽饼专门店(全浦 (Jeonpo / 전포) → 广安里扩张) — 从全浦起步,如今已在广安里开出2号店,可丽饼商圈正在壮大。基本玩法是自选配料定制。
  • 蒙贝尔庇护所 (Mongbel Shelter / 몽벨쉘터)(南浦 (Nampo / 남포)·光复路 (Gwangbok-ro / 광복로)) — 具有欧式风情的大型烘焙咖啡馆。因为紧邻BIFF广场 (BIFF Square / BIFF광장),自然能并入南浦观光动线(#244区域)。
  • 注意:百货商店·购物中心的快闪甜点属于限时活动,本篇不作介绍——把到访当下遇到的快闪店当作现场的意外惊喜就好。

③ 海景轴线 — 大海与甜味

  • 青沙浦 (Cheongsapo / 청사포)(海云台 (Haeundae / 해운대) 以东) — 海景咖啡馆聚集带的代表区域。这里聚集着许多三层建筑的咖啡馆,可以一边眺望全景海景一边享用咖啡与甜点(采集信号中的代表:OF咖啡沙龙 (Of Coffee Salon / 오브커피살롱))。只要从海云台闹市区挪开一站的距离,人流密度就骤然降低。
  • 广安里一带则流行买上意式冰淇淋、可丽饼走向海边的外带吃法——可以搭配广安大桥 (Gwangan Bridge / 광안대교) 夜景(#243)一起体验。

🗺 一日动线示例

时间 行程
上午 南浦 — 在蒙贝尔庇护所吃烘焙点心 + 光复路散步
午餐 猪肉汤饭 (Dwaeji-gukbap / 돼지국밥) 或小麦冷面 (Milmyeon / 밀면)(#1320)
下午 广安里 — 意式冰淇淋外带 → 海边散步
傍晚 移动至青沙浦 — 在海景咖啡馆享用甜点(18点前入店,#1321中提到的打烊文化)
晚上 东莱白家红豆铺白天常售罄,建议留到第二天白天——晚上去看广安大桥夜景(#243)
