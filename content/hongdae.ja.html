⚠ 初めて行く外国人がよくやる3つのミス

1. 弘大 (홍대) = ホンイク大学 (홍익대학교) の正門だけ見る

外国人旅行者にとっての弘大 (홍대) は正門よりも、弘大入口駅 (홍대입구역) (2号線) 9番出口〜オウルマダン路 (어울마당로)〜ワウサン路 (와우산로) 周辺。ストリートパフォーマンス・クラブ・デザインショップが集まるのは学校ではなく周辺の通り。正門で1枚写真を撮ったら通りへ出るのが正解。

2. クラブ・ライブハウスが常に外国人 ID を受け付けると思い込む

ローリングホール (롤링홀)・KT&G サンサンマダン (상상마당) のようなライブハウスはパスポートによる ID 確認が必須 (19歳以上・韓国規定)。外国人でも ID なし入場不可。DJ クラブは入場料 ₩20,000〜30,000 + ドリンク1杯付き。

3. 弘大 (홍대) だけ見てマンウォン (망원)・ヨンナム (연남) を見逃す

外国人は弘大 (홍대) 単独訪問が多いが、徒歩10分圏内にマンウォン市場 (망원시장) (市場体験) + ヨンナムドン (연남동) (トレンディーなカフェ横丁) + ハプチョン (합정) (OBJECT (오브젝트) メイン店舗) がある。動線をまとめれば充実した1日コースに。

弘大エリア (Hongdae & Around) の風景

弘大 (홍대) はマポグ (마포구) ソギョドン (서교동)・ドンギョドン (동교동)・ヨンナムドン (연남동)・ハプチョン (합정)・マンウォン (망원) をまとめた「Greater Hongdae」ゾーン。外国人は通常弘大入口駅 (홍대입구역) (2・6号線・空港鉄道) からスタート → オウルマダン路 (어울마당로) → クラブ・ライブハウス → マンウォン市場 (망원시장) またはヨンナムドン (연남동) カフェ横丁という終日ルートが定番。ミョンドン (명동)・カンナム (강남) と異なりMZ・インディー・アンダーグラウンドのトーンが圧倒的。

外国人旅行者の4つの目的:

1. K-インディー・ライブ音楽体験 (ローリングホール (롤링홀)・クラブFF (클럽 FF))

2. デザイン・アート・サブカルチャーショッピング (OBJECT (오브젝트)・テンクスブックス (땡스북스)・サンサンマダン (상상마당))

3. K-MZ カフェ・バーインスタコース (ヨンナム (연남)・ハプチョン (합정))

4. 市場・老舗グルメ (マンウォン市場 (망원시장)・コプチャン横丁 (곱창골목))

① 音楽・ライブ (2か所)

ローリングホール (롤링홀) (Rolling Hall)

1995年オープン、韓国第1世代ライブハウス。韓国インディー・ロックシーンの本拠地で、チャンナビ (잔나비)・ヒョクオ (혁오)・グッカステン (국카스텐) など数えきれないバンドの出発点。200〜300席規模で距離感が近い。外国人旅行者は K-インディーのセットリストを事前確認の上チケット予約推奨。

  • 住所: マポグ (마포구) オウルマダン路 (어울마당로) 6キル (6길) 18, B1
  • 営業: 公演スケジュールによる (通常19:00ドア / 20:00開演)
  • チケット: ₩40,000〜₩77,000 (バンドにより異なる)
  • シグニチャー: K-インディー第1世代ライブハウス
  • 理由: 韓国インディー音楽を体験する正統コース。英語案内・チケットサイト一部対応。

クラブFF (클럽 FF) (Club FF / Funky Funky)

弘大 (홍대) のDJ インディークラブの代表格。毎週金・土はライブ + DJ セット。外国人クラバーの比率が高く、エレクトロニカ・ハウス・テクノが中心。入場料にドリンク1杯付きが一般的。

  • 住所: マポグ (마포구) オウルマダン路 (어울마당로) 6キル (6길) 5-23, B1 (ソギョドン (서교동))
  • 営業: 金・土 22:00〜05:00 (シーズンにより変動)
  • 入場料: ₩20,000〜₩30,000 (ドリンク1杯付き)
  • シグニチャー: 外国人フレンドリーな DJ クラブ
  • 理由: 英語案内OK。ID (パスポート) 必須、19歳以上。

② デザイン・アート (3か所)

KT&G サンサンマダン弘大 (상상마당) (KT&G Sangsangmadang)

KT&G 後援のインディー総合文化施設。1F デザインショップ・2F カフェ・3〜4F ギャラリー・B1 インディー映画館。デザイングッズ + インディー展示 + 映画を一か所で。外国人旅行者に人気のコース。

  • 住所: マポグ (마포구) オウルマダン路 (어울마당로) 65 (ソギョドン (서교동))
  • 営業: 毎日11:00〜22:00 (映画館は別途)
  • シグニチャー: デザイングッズ・ギャラリー・インディー映画の複合
  • 理由: 韓国デザイン・インディー文化を1時間で凝縮体験。外国人多数訪問、英語案内可能。

テンクスブックス (땡스북스) (THANKS BOOKS) — #135 関連

書店 + カフェ + ギャラリーの3-in-1。1F に韓国デザイン・アートのセレクト本 (各書籍にスタッフの手書きメモ付き)、2F にギャラリー・セミナールーム。外国人がデザイン本・アートマガジンから韓国の視点を感じたいときにベスト。

  • 住所: マポグ (마포구) ヤンファ路 (양화로) 6キル (6길) 57-6 (弘大 (홍대))
  • 営業: 毎日12:00〜21:00
  • シグニチャー: 手書きメモキュレーション + デザイン・アートセレクト
  • 理由: #135 書店ガイドにて老舗・キュレーション軸として紹介。弘大コースで30〜60分の休憩 + グッズショッピング。

OBJECT (오브젝트)

弘大 (홍대)・ハプチョン (합정) エリアの K-インディーライフスタイルグッズショップ。韓国のイラストレーター・デザイナーとのコラボ商品が中心 (ステッカー・ノート・エコバッグ・マグカップ)。外国人旅行者のお土産・プレゼント第1候補。

  • 住所: マポグ (마포구) ワウサン路 (와우산로) 35キル (35길) 13 (弘大 (홍대)) — ハプチョン (합정)・ソギョ (서교) 分店あり
  • 営業: 毎日12:00〜21:00
  • シグニチャー: K-インディーイラスト・デザイングッズ
  • 理由: 単なるお土産ではなく韓国作家コラボ品。価格帯 ₩3,000〜₩30,000。

③ グルメ・老舗 (2か所)

弘大コプチャン横丁 (홍대 곱창골목) (Hongdae Gopchang Alley)

弘大 (홍대) オウルマダン路 (어울마당로) 5キル (5길) 周辺の夜の腸料理・老舗横丁。外国人より韓国人 MZ の比率が高いローカル老舗だが、外国人が老舗の屋外飲み文化を体験するのに最適なコース。

  • 住所: マポグ (마포구) オウルマダン路 (어울마당로) 5キル (5길) 周辺 (ソギョドン (서교동))
  • 営業: 店舗により異なる / 通常17:00〜02:00
  • メニュー: コプチャン (곱창)・マクチャン (막창)・テチャン (대창) 1人前 ₩15,000〜₩25,000
  • シグニチャー: 夜の老舗腸料理横丁
  • 理由: 韓国式の夜の飲み文化。キムチチゲ・ラーメンのサイドメニュー + ソジュ (소주)・ビール。

マンウォン市場 (망원시장) (Mangwon Market)

弘大 (홍대) から徒歩15分または6号線1駅。外国人旅行者の市場体験第1候補。トッポッキ (떡볶이)・チュィギム (튀김)・チョン (전)・クッパプ (국밥) などのストリートフード + 青果・鮮魚市場の雰囲気。クァンジャン市場 (광장시장) より小規模だがローカル感が強い。

  • 住所: マポグ (마포구) マンウォン路 (망원로) 22 (マンウォン (망원))
  • 営業: 毎日09:00〜22:00 (定休日は店舗により異なる)
  • シグニチャー: 外国人フレンドリーなローカル市場 + ストリートフード
  • 理由: クァンジャン市場 (광장시장) が観光地化しすぎて抵抗があるならマンウォン市場 (망원시장) へ。₩5,000〜₩10,000 前後のストリートフードが豊富。

④ 街歩き・体験 (1か所)

弘大プレイグラウンド (홍대 놀이터) (Hongdae Playground / 正式名: オウルマダン (어울마당))

弘大入口駅 (홍대입구역) 9番出口から徒歩3分。外国人旅行者のインスタスポット + バスキング第1候補。週末の夜は K-pop ダンスカバー・インディーバンドのライブが毎日異なる公演を披露。無料観覧。

  • 住所: マポグ (마포구) オウルマダン路 (어울마당로) (ソギョドン (서교동))
  • 営業: 24時間 (公演は通常18:00〜22:00)
  • シグニチャー: 外国人向けバスキング・K-pop ダンスインスタスポット
  • 理由: 弘大 (홍대) のスタート地点。30分散歩 + インスタ撮影。週末の夜がピーク。

⚙ FAQ 8問

Q1. 弘大 (홍대) 初訪問のコースは?

弘大入口駅 (홍대입구역) 9番出口 → 弘大プレイグラウンド (홍대 놀이터) (バスキング30分) → サンサンマダン (상상마당) (1時間デザインショップ・ギャラリー) → OBJECT (오브젝트) (30分グッズ) → オウルマダン路 (어울마당로) のレストランで昼食 → テンクスブックス (땡스북스) (1時間書店) → 夜はローリングホール (롤링홀) またはクラブFF (클럽 FF)。

Q2. 外国人向けクラブのID ポリシーは?

パスポートによる ID 確認が必須。19歳以上 (韓国の飲酒可能年齢)。クラブ入口でスタンプ + ドリンク1杯無料が一般的。

Q3. ライブ音楽チケットはどこで?

ローリングホール (롤링홀) 公式サイト、またはインターパク (인터파크)・イェス24 (예스24)。英語インターフェース一部対応。人気バンドは1〜2週間前に売り切れ。

Q4. マンウォン市場 (망원시장) vs クァンジャン市場 (광장시장) は?

クァンジャン市場 (광장시장): チョンノ (종로)、観光地化が進んでいる、マヤッキムパプ (마약김밥)・ピンデトク (빈대떡) などのシグニチャーメニューあり。マンウォン市場 (망원시장): マポ (마포)、ローカル感が強い、トッポッキ (떡볶이)・チュィギム (튀김)・チョン (전) など。観光客の波に流されたくないならマンウォン (망원)、定番コースを狙うならクァンジャン (광장)。

Q5. コプチャン (곱창) 初心者の外国人でも挑戦できる?

テチャン (대창) が最もハードルが低い (脂が少なく食感が良い)。コプチャン (곱창)・マクチャン (막창) は香りが強く好みが分かれる。ケンニプ (깻잎)・ニンニク・トウガラシで香りを抑えるのがコツ。キムチチゲ・ラーメンをサイドで頼むと安心。

Q6. 雨の日の弘大 (홍대) コースは?

室内中心 — サンサンマダン (상상마당) (4フロア複合) + テンクスブックス (땡스북스) (室内書店) + OBJECT (오브젝트) (グッズ) + オウルマダン路 (어울마당로) のカフェ。クラブ・ライブハウスは夜なので雨は関係なし。

Q7. K-pop グッズはどこで?

弘大 (홍대) は K-pop よりインディー・デザイングッズがメイン。K-pop グッズはミョンドン (명동) の K-Star Road またはカンナム (강남) の SM Town COEX の方が豊富。弘大 (홍대) の OBJECT (오브젝트) は作家コラボのライフスタイル商品中心。

Q8. 車椅子 / ベビーカーのアクセスは?

弘大プレイグラウンド (홍대 놀이터)・サンサンマダン (상상마당)・OBJECT (오브젝트) ハプチョン (합정) 店・マンウォン市場 (망원시장) はフラットな動線。ローリングホール (롤링홀)・クラブFF (클럽 FF)・テンクスブックス (땡스북스)・弘大コプチャン横丁 (홍대 곱창골목) は狭い路地・階段が多くアクセス困難。

5. 冬の温かい老舗: 12〜2月 弘大コプチャン横丁 (홍대 곱창골목) + マッコリ老舗 (#136 マッコリガイド関連)。
