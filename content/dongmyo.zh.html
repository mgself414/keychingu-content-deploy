东庙，为何必去？

“时光停滞的市场 — 价格也停滞的街区”

在首尔，外国游客最常听到的一句话是“旧时的首尔”。但如果问具体在哪里，答案就会有所不同。仁寺洞 (Insadong / 인사동) (工艺品旅游)？广藏市场 (Gwangjang Market / 광장시장) (传统美食)？两者都很有魅力，但它们都已为外国游客打理得井井有条。

东庙则不同。它是一个从1980年代末期自发形成的跳蚤市场，至今外国游客少于韩国老年人和MZ世代 (MZ, 指千禧一代和Z世代，通常是20-35岁的年轻人) 淘宝者。

KeyChinGu推荐东庙的4个理由：

1. 时间胶囊般的性价比 — ₩1,000 (~$0.75 / ~5 RMB / ~110 JPY) 吐司、₩6,000 (~$4.5 / ~32 RMB / ~660 JPY) 明太鱼汤、₩2,000 (~$1.5 / ~11 RMB / ~220 JPY) 宴会面无限续。价格冻结了20~30年的店铺集中在一条小巷 (golmok / 골목) 里。

2. 复古时尚淘宝 (vintage digging) — 在“衣服堆” (堆积如山的旧衣服) 中寻找宝藏的韩式复古文化。在Instagram上搜索“득템 (deuktem, 淘到宝)” (指淘到物超所值的好东西)，就会出现这条街。

3. 几乎是唯一一个世代交错的小巷 — 50~70岁的老顾客和20~30岁的淘宝者在同一个摊位前翻找是日常景象。这是在其他首尔热门地点看不到的风景。

4. 市场+汗蒸房+露天酒摊 1公里组合 — 中午市场淘宝 → 晚上在Sparex 东庙店 (Sparex Dongmyo / 스파렉스 동묘점) 汗蒸 (jjimjilbang / 찜질방, 韩式桑拿，提供休息、沐浴和各种汗蒸设施) → 晚上在钟路3街 (Jongno 3-ga / 종로3가) 的露天酒摊 (yajan / 야장, 在户外摆放桌椅的酒摊，常见于韩国街头) 喝米酒 (makgeolli / 막걸리, 一种韩国传统发酵米酒，酒精含量较低)。仅靠步行即可完成一天的行程。

东庙4区域地图

区域1 — 东庙正门 & 无车街区 (核心淘宝区)

位置: 东庙前站 (Dongmyo, 동묘앞 / 东庙前) 3号出口 → 步行1分钟 → 东庙正门前广场

特点: 周末 12:00 (12 PM)~18:00 (6 PM) 禁止车辆通行。人行道 + 车道全部变成摊位，展现东庙市场最直观的精髓。这里是“衣服堆”铺设最多的地方。

可看之处:

  • 衣服堆摊位: 堆积如山的衣服，每件₩1,000 (~$0.75 / ~5 RMB / ~110 JPY)~₩3,000 (~$2.25 / ~16 RMB / ~330 JPY)。尺寸/状况全凭运气。
  • 鞋子摊位: Nike·adidas 复古运动鞋 (不分真伪，主要看设计)。₩5,000 (~$3.75 / ~27 RMB / ~550 JPY)~₩30,000 (~$22.5 / ~160 RMB / ~3,300 JPY)。
  • 杂货摊位: 手表、包、打火机、LP唱片、磁带、旧漫画书。

提示: 初次来访，建议从摊位开始 → 然后前往小巷内的复古商店。摊位可以讲价，商店多为明码标价。

区域2 — 小巷复古商店 (入门者推荐)

位置: 东庙正门往里一个街区的小巷 (golmok / 골목)

特点: 比摊位淘宝难度低。衣服挂在衣架上，按尺寸和品类分类。价格是摊位的2~3倍，但节省时间。

代表店铺:

  • Salon de Bon (Salon de Bon / 살롱드봉) — 名品复古专卖店。Burberry·YSL·Maxmara 花呢、秋季套装等。以女装为主。每件₩30,000 (~$22.5 / ~160 RMB / ~3,300 JPY)~₩150,000 (~$112.5 / ~800 RMB / ~16,500 JPY)。
  • 众多无名仓库型店铺 — 老板亲自从日本·欧洲采购的批发复古商品。有很多有趣的街头服饰。

提示: 小巷 (golmok / 골목) 内的店铺有些不喜欢拍照。入店时建议轻轻问候 + 表达只是看看的意愿。

区域3 — 东大门 (Dongdaemun / 동대문) 旁夜市线 (傍晚时段)

位置: 东庙前站 (Dongmyo, 동묘앞 / 东庙前) 1号出口 → 往东大门方向步行5~10分钟

特点: 市场在 17:00 (5 PM)~18:00 (6 PM) 左右收摊后，路边摊 (붕어빵, 호떡, 어묵 等) 就会出现。连接东大门 (Dongdaemun / 동대문) 的街道是夜间散步的好去处。

区域4 — 东庙祠堂 (宝物第142号 东关王庙)

位置: 东庙正门内部

特点: 位于市场中心，但免费入场。1599年壬辰倭乱后受明朝影响而建的关羽祠堂。是韩国最古老的外来宗教建筑之一。

提示: 市场淘宝 (digging) 间隙的休息点。与市场喧嚣隔绝的安静空间形成独特的对比。也是拍照的好地方。

购物 — 衣服堆淘宝5阶段

初次来访，请按以下顺序：

阶段1 — 选择时间

  • 周六 14:00 (2 PM)~17:00 (5 PM): 新品上架后 + 无车街区 + 适中人流。KeyChinGu推荐 #1 时间段。
  • 周日上午: 最清闲。遇到会说英语的老板几率较低，但淘宝 (digging) 专注度高。
  • 平日 15:00 (3 PM)~17:00 (5 PM): 以韩国老顾客为主。外国人可能会引人注目。淘宝 (digging) 本身比较舒适。

阶段2 — 从摊位开始

不要一开始就进入小巷 (golmok / 골목) 复古商店，先在无车街区的摊位逛一圈。了解行情后，才能判断小巷 (golmok / 골mok) 店铺的价格是贵还是合理。

阶段3 — 讲价规则

  • 摊位: ₩1,000 (~$0.75 / ~5 RMB / ~110 JPY) 的衣服不讲价。₩10,000 (~$7.5 / ~54 RMB / ~1,100 JPY) 以上可以尝试说一句“조금만 깎아주세요 (jogeumman kkakkajuseyo)” (请稍微便宜一点)。
  • 店铺: 明码标价。只有捆绑购买时才可协商折扣。
  • 绝对不能做的事: 一开始就砍半价。在韩国市场文化中这被认为是无礼的。

阶段4 — 尺寸 / 状况检查

  • 韩国衣服尺码偏小 — XL 大约相当于美国 M 码。
  • 几乎没有镜子。可以套在外面试穿，或者让朋友帮忙看。
  • 污渍·破损检查由自己负责。几乎不接受退换货。

阶段5 — 支付

  • 摊位: 以现金为主。请提前准备好 ₩10,000 (~$7.5 / ~54 RMB / ~1,100 JPY) 面值的钞票。
  • 店铺: 接受刷卡的店铺越来越多。外国信用卡 (VISA·Master) 大部分也OK。
  • 几乎没有收据。

淘宝 (Digging) 清单 (基于Instagram评论)

  • 牛仔裤: Levi's 复古牛仔裤。摊位 ₩10,000 (~$7.5 / ~54 RMB / ~1,100 JPY)~₩30,000 (~$22.5 / ~160 RMB / ~3,300 JPY)，店铺 ₩50,000 (~$37.5 / ~270 RMB / ~5,500 JPY)~₩150,000 (~$112.5 / ~800 RMB / ~16,500 JPY)。
  • 夹克/外套: 日本夜行巴士 (yakio-ku) 批发。冬季 ₩30,000 (~$22.5 / ~160 RMB / ~3,300 JPY)~₩80,000 (~$60 / ~430 RMB / ~8,800 JPY)。
  • 花呢套装 (秋季): Salon de Bon 等名品复古。₩80,000 (~$60 / ~430 RMB / ~8,800 JPY)~₩300,000 (~$225 / ~1,600 RMB / ~33,000 JPY)。
  • 街头卫衣: 摊位 ₩5,000 (~$3.75 / ~27 RMB / ~550 JPY)~₩15,000 (~$11 / ~80 RMB / ~1,600 JPY)。

美食 — 价格停滞的5家店铺

1. ₩1,000 吐司路边摊 — “20年价格冻结”

位置: 东庙前站 (Dongmyo, 동묘앞 / 东庙前) 2~3号出口之间

特点: 面包片夹着卷心菜·鸡蛋·火腿。撒上葱花+海苔碎。20年来一直保持 ₩1,000 (~$0.75 / ~5 RMB / ~110 JPY)。外国游客也排队品尝的东庙招牌美食。

提示: 建议在午餐时间之前 (11:00 (11 AM)前) 去，排队会短一些。很多人一人吃2个。

2. 光州食堂 (Gwangju Sikdang / 광주식당) (明太鱼汤) — “30年老字号，08:00 (8 AM) 营业”

位置: 东庙前站 (Dongmyo, 동묘앞 / 东庙前) 3号出口步行5分钟 (建议在Naver地图上搜索准确位置)

菜单:

  • 明太鱼汤 (dongtae-tang / 동태탕, 一种用冷冻明太鱼制作的韩式辣汤) ₩6,000 (~$4.5 / ~32 RMB / ~660 JPY)
  • 营业: 08:00 (8 AM)~16:00 (4 PM) (食材售罄则提前打烊)

特点: 在韩国，₩6,000 (~$4.5 / ~32 RMB / ~660 JPY) 的明太鱼汤 (dongtae-tang / 동태탕) 几乎是独一无二的价格。30年传统。上午时段，老年顾客搭配米酒 (makgeolli / 막걸리) 享用的景象是东庙的招牌画面。即使是外国人，也能自然地融入其中。

提示: 没有英文菜单。建议出示图片或尝试说“동태탕 하나 (dongtaetang hana)” (一份明太鱼汤)。

3. 宴会面 (Janchi Guksu / 잔치국수) 无限续 ₩2,000 (多家无名小吃店)

位置: 东庙市场内小巷 (golmok / 골목)

特点: 鳀鱼高汤配细面条、海苔碎、葱花。无限续，但一碗通常就足够了。₩2,000 (~$1.5 / ~11 RMB / ~220 JPY) 是东庙市场的平均价格。

4. 参鸡刀削面 (Baeksuk Kalguksu / 백숙칼국수) ₩9,000 — 整只半鸡

位置: 市场内刀削面小巷 (golmok / 골목) (如爷爷刀削面 (Harabeoji Kalguksu / 할아버지칼국수)、高巴宇 (Gobau / 고바우)、海鲜元刀削面 (Haemulwon Kalguksu / 해물원칼국수) 等)

特点: 一碗刀削面里有整只半鸡 (手臂大小)。₩9,000 (~$6.75 / ~48 RMB / ~990 JPY)。一人一碗足够。两人一起吃会稍微不够。

5. 路边摊鸡爪·蚕蛹 (傍晚)

位置: 17:00 (5 PM) 以后无车街区尽头

特点: 无车街区整理后，夜市模式开启。鸡爪 (dakbal / 닭발, 韩式辣炒鸡爪) ₩7,000 (~$5.25 / ~37 RMB / ~770 JPY)，蚕蛹 (beondegi / 번데기, 煮熟或炒熟的蚕蛹，韩国特色小吃) ₩3,000 (~$2.25 / ~16 RMB / ~330 JPY)。搭配米酒 (makgeolli / 막걸리) ₩4,000 (~$3 / ~21 RMB / ~440 JPY)，感受路边摊露天酒摊 (yajan / 야장) 氛围。

体验 — 只有在东庙才能做的事

体验1 — 衣服堆淘宝 (Digging) 本身

上面提到的5个阶段就是体验。讲价、翻找衣服、听到老板用日语打招呼 (“いらっしゃい”) 的所有过程都是东庙式的购物。

体验2 — Sparex 东庙店 (Sparex Dongmyo / 스파렉스 동묘점) (24小时汗蒸房)

位置: 东庙前站 (Dongmyo, 동묘앞 / 东庙前) 4号出口步行3分钟 (首尔 钟路区 (Jongno-gu / 종로구) 芝峰路 (Jibong-ro / 지봉로) 19号，13楼)

特点:

  • 24小时营业 — 市场淘宝 (digging) 后可以汗蒸 (jjimjilbang / 찜질방) 结束，第二天乘坐首班车离开。
  • 13楼 — 可以从高处俯瞰市场景象。
  • 入场费12小时券约 ₩14,000 (~$10.5 / ~75 RMB / ~1,500 JPY) (2026年4月 기준)。
  • 外国人友好度: 日本·中华圈游客比例高。英文指引有限，但可以使用自助机。

提示: 市场购物后，也可以将其用作更换新买衣服的储物柜。

体验3 — 东关王庙 (Donggwanwangmyo / 동관왕묘) 祠堂庭院

参见上方区域4。免费，与市场隔绝的安静空间。拍照的好地方。

体验4 — 钟路3街 (Jongno 3-ga / 종로3가) 露天酒摊 (Yajan) (20:00 (8 PM) 以后前往)

从东庙步行15分钟或乘坐1号线一站 → 钟路3街站 (Jongno 3-ga / 종로3가) 13号出口。

为何一同前往？

  • 钟路3街 (Jongno 3-ga / 종로3가) 是MZ世代 (MZ) + 老年人同时热门之地 — 延续了东庙世代交错的氛围。
  • 13号出口一带20年以上历史的老字号 (nopo / 노포, 拥有30年以上历史的传统老店) 布帐马车 (pocha / 포차, 韩式路边摊，通常有帐篷遮盖，提供酒水和小吃) 密集。随便进哪家都平均水准以上。
  • 米酒 (makgeolli / 막걸리) ₩5,000 (~$3.75 / ~27 RMB / ~550 JPY) + 葱饼·泡菜饼·鸡爪 (dakbal / 닭발)·鸡蛋卷是标准菜单。

KeyChinGu推荐路线:

1. 东庙市场淘宝 (14:00 (2 PM)~17:00 (5 PM))

2. 光州食堂 (Gwangju Sikdang / 광주식당) 明太鱼汤 (dongtae-tang / 동태탕) 或刀削面 (17:00 (5 PM)~18:00 (6 PM))

3. Sparex 东庙店 (Sparex Dongmyo / 스파렉스 동묘점) 短暂汗蒸 (jjimjilbang / 찜질방) (18:00 (6 PM)~19:30 (7:30 PM))

4. 钟路3街 (Jongno 3-ga / 종로3가) 露天酒摊 (yajan / 야장) 米酒 (makgeolli / 막걸리) (19:30 (7:30 PM)~22:00 (10 PM))

东庙的差异化 — 与其他首尔市场的比较

市场 特性 外国人视角 与东庙的差异
广藏市场 (Gwangjang Market / 광장시장) 绿豆饼·麻药紫菜包饭·生拌牛肉 (美食中心) 非常友好，英文菜单多 美食中心，整洁有序
南大门市场 (Namdaemun Market / 남대문시장) 配饰·杂货·综合购物 英文流利 价格中等，以批发为主
仁寺洞 (Insadong / 인사동) 工艺品·茶·纪念品 最外国人友好 “旅游用”的印象

乙支路 (Euljiro / 을지로) 工业+潮人 (白天工厂，晚上酒吧) 英文一半 氛围重于美食
东庙 (Dongmyo / 동묘) 跳蚤+复古+高性价比餐厅+汗蒸房 几乎没有英文 价格停滞的街区 + MZ世代/老年人共存 + 淘宝体验

东庙独有的3个亮点:

1. ₩1,000 (~$0.75 / ~5 RMB / ~110 JPY)~₩5,000 (~$3.75 / ~27 RMB / ~550 JPY) 一件衣服 — 在其他任何首尔市场都很难找到的价格区间。

2. 20~30年价格冻结的餐厅 — ₩1,000 (~$0.75 / ~5 RMB / ~110 JPY) 吐司、₩6,000 (~$4.5 / ~32 RMB / ~660 JPY) 明太鱼汤 (dongtae-tang / 동태탕) 在东庙之外几乎绝迹。

3. 市场+汗蒸房 (jjimjilbang / 찜질방)+露天酒摊 (yajan / 야장) 1公里组合 — 唯一一个仅靠步行即可完成全天行程的街区。

外国人常见问题

Q1. 有会说英语的店铺吗？

几乎没有。摊位用数字 + 手势就足够了。店铺老板有时会说一点日语 (有采购日本复古商品的经验)。需要英语的时刻主要是询问尺寸，说“사이즈 (size)?” (尺寸？) 即可。

Q2. 可以刷卡吗？

摊位只收现金。接受刷卡的店铺越来越多，但还是建议提前准备5~10张 ₩10,000 (~$7.5 / ~54 RMB / ~1,100 JPY) 面值的钞票。东庙前站 (Dongmyo, 동묘앞 / 东庙前) 1号出口内有ATM。

Q3. 衣服干净吗？

是二手的。严重的污渍·破损由自己确认负责。回家后再次清洗是基本操作。部分店铺会贴上已干洗的标识。

Q4. 尺寸怎么选？

几乎没有镜子。可以套在外面试穿或请朋友帮忙看。韩国衣服尺码偏小，建议选择比平时大一码。

Q5. 可以拍照吗？

摊位全景 (整体照片) OK。老板的脸部特写、店铺内部特写请征得同意。“사진 찍어도 돼요 (sajin jjikeodo dwaeyo)?” (可以拍照吗？) 一句就足够了。

Q6. 危险吗？

与首尔其他核心旅游景点一样安全。但人多时请注意扒窃 — 背包背在前面，手机放在内口袋。

Q7. 外国人可以去露天酒摊 (yajan / 야장) 吗？

钟路3街 (Jongno 3-ga / 종로3가) 13号出口一带的露天酒摊 (yajan / 야장)外国人比例逐渐增加。部分地方会说英语。找个座位点米酒 (makgeolli / 막걸리)·葱饼 → 和旁边韩国老年人简单打个招呼是比较自然的流程。不建议强行进行深入对话。

季节性注意事项

春季 (3~5月)

  • 沙尘暴·雾霾严重的日子，摊位衣服可能会沾染灰尘。
  • 无车街区从4月开始人流显著增加。

夏季 (6~8月)

  • 中午 (13:00 (1 PM)~16:00 (4 PM)) 摊位非常炎热。推荐 16:00 (4 PM) 以后。
  • 市场小巷 (golmok / 골목) 有阴凉。店铺只有部分有空调。
  • 露天酒摊 (yajan / 야장) 夏季是旺季。

秋季 (9~11月)

  • KeyChinGu推荐最佳季节 — 花呢、毛衣、夹克新品上架。
  • 10~11月的周六下午是东庙一年中最好的时间。

冬季 (12~2月)

  • 部分摊位减少。以店铺淘宝 (digging) 为主。
  • 羽绒服·大衣淘宝 (digging) 季节。价格比夏季贵。
  • 汗蒸房 (jjimjilbang / 찜질방) 需求暴增 — Sparex 东庙店 (Sparex Dongmyo / 스파렉스 동묘점) 周末常满。
