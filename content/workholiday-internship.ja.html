🎯 なぜ外国人向けワーキングホリデー・インターンシップ完全ガイドなのか

韓国に長期滞在したい外国人、特に20～35歳のギャップイヤー・キャリアチェンジを考えているMZ世代 (ミレニアル世代とZ世代を合わせた若者層)にとって、最も重要なポイントはF-2-2ワーキングホリデー・D-10-3インターンシップです。#248 外国人ビザ後続ディープダイブ — ワーキングホリデー・インターンシップ専用フルセット。

⚠ 外国人がよくする5つの間違い

1. 「K-ETA = 働ける」: K-ETA・ノービザ90日 = 観光・短期のみ。働くにはF-2-2・E-2・E-7・E-9・D-10-3など別途ビザが必要です。

2. 「F-2-2ワーキングホリデー = 全員対象」: F-2-2 = 18～30歳 + 27の対象国 + 年1回の大使館抽選 + 外国人マニア最優先 (米国1,000人・カナダ4,000人・オーストラリア1,500人のクォータ)。

3. 「D-10-3インターンシップ = 誰でも取得可能」: D-10-3 = D-2 (留学) 卒業後3～6ヶ月のインターンシップ + 外国人マニアの韓国IT・企業実習No.1。

4. 「外国人 = 税金・社会保険免除」: 外国人 = 所得税源泉徴収 + 6ヶ月以上の健康保険義務加入 + 外国人マニア最優先 (不履行時はビザ更新拒否)。

5. 「不法職業斡旋 = よくあること」: 韓国No.1の外国人保護 = 不法職業斡旋・偽TEFL・ビザオーバーステイの処罰 + Hi Korea 1345 (外国人総合案内センター)・KCTU (韓国労働組合総連盟) 外国人支部への通報。

① F-2-2ワーキングホリデービザ (4)

1. F-2-2ワーキングホリデービザ ★ 韓国No.1

  • 外国人 ★: ◎◎ — 18～30歳・1～2年・非専門職労働OK
  • 資格: 18～30歳 (一部の国は35歳) + 本国居住 + 一定の資金 (USD $2,000以上推奨)
  • 申請: 本国の韓国大使館・年1回抽選・外国人マニアNo.1

2. F-2-2対象国27カ国

  • 外国人 ★: ◎◎ — 米・加・豪・NZ・EU・日・台湾・香港・イスラエルなど
  • マニア: オーストラリア1,500人・カナダ4,000人・米国1,000人・日本10,000人 (クォータ)

3. F-2-2申請 (大使館・年1回抽選)

  • 外国人 ★: ◎◎ — 本国大使館 + 毎年1～3月抽選
  • 外国人マニアの事前準備No.1

4. F-2-2取得後の活動

  • 外国人 ★: ◎◎ — 英語講師・サービス業・外国人向け店舗
  • 1～2年の自由活動 + 外国人マニアの長期滞在No.1

② D-10-3インターンシップビザ (2)

5. D-10-3インターンシップ・実習ビザ ★ 韓国No.1

  • 外国人 ★: ◎◎ — 卒業後3～6ヶ月の実習・外国人マニア
  • 対象: 韓国のD-2 (留学) 卒業生 + 外国人マニア最優先

6. D-10-3 vs D-10-1の違い

  • D-10-1 = 求職ビザ6ヶ月～2年 (#248)
  • D-10-3 = インターンシップ・実習3～6ヶ月 + 企業・研究所マニア

③ ビザ拡張・切り替え (2)

7. 外国人交換留学生・D-4語学研修

  • 外国人 ★: ◎ — 韓国語学堂6ヶ月～2年
  • 外国人マニアのD-2 (留学) 進学前段階

8. ビザ切り替え

  • 外国人 ★: ◎◎ — K-ETA→C-3→E-2 (英語講師)・D-2→E-7 (専門職)・F-2-2→F-6 (結婚) No.1

④ 税金・社会保険・労働 (4 + 追加4)

9. 外国人税金 (所得税・勤労所得税源泉徴収)

  • 外国人 ★: ◎◎ — 外国人マニア最優先
  • 所得税: 本国と韓国の二重課税防止協定 (DTA・米・加・豪・日・EUなど)

10. 外国人社会保険

  • 外国人 ★: ◎◎ — 6ヶ月以上滞在時に義務加入
  • 健康保険 (国民健康保険公団)・国民年金 (外国人加入者の韓国居住マニア)

11. 外国人労働法

  • 外国人 ★: ◎◎ — 最低賃金9,860ウォン (2024) (約1,100円) + 週52時間 + 外国人マニア保護
  • 外国人マニア最優先の権利

12. 外国人詐欺防止

  • 外国人 ★: ◎◎ — 不法職業斡旋・偽TEFL・ビザオーバーステイの処罰
  • 外国人安全最優先の通報先: Hi Korea 1345 (外国人総合案内センター)・KCTU (韓国労働組合総連盟) 外国人支部

💼 D-10-3インターンシップビザフルセット

資格:

  • 満18歳以上・OECD加盟国 (35カ国)・大学在学生/卒業後2年以内
  • 政府認定のインターンシップ機関・企業との約定書必須

期間:

  • 1次3ヶ月 + 1回延長 → 最長6ヶ月
  • D-10-2 (創業) への切り替え可能

賃金 (インターンシップ):

  • 手当: 月1,500,000～3,500,000ウォン (約165,000～385,000円) (企業別)
  • または無給 (学点認定時)
  • 時間: 週40時間以内・最低賃金9,860ウォン/時 (2026年) (約1,100円/時) 保証

人気分野:

  • IT・スタートアップ: Gangnam (カンナム)・Pangyo (パンギョ)・Seongsu (ソンス) クラスター
  • 貿易・物流: KOTRA (大韓貿易投資振興公社)・Samsung (サムスン)・LG (エルジー)・Hyundai (ヒョンデ)
  • K-content: HYBE (ハイブ)・SM (エスエム)・JYP (ジェイワイピー)・CJ ENM (シージェイイーエヌエム)
  • 外資系企業: Google Korea・Microsoft・Apple

💰 外国人賃金・税金・DTAフルセット

最低賃金 (2026年):

  • 時給9,860ウォン (約1,100円)・8時間 = 78,880ウォン/日 (約8,700円)・40時間/週 = 月約2,060,000ウォン (約226,600円)

平均賃金 (外国人マトリックス):

  • E-2英語教師: 月2,400,000～3,500,000ウォン (約264,000～385,000円)
  • E-7 IT/デザイン/金融: 月4,000,000～8,000,000ウォン (約440,000～880,000円) (大企業)
  • 外資系役員: 月8,000,000～15,000,000ウォン (約880,000～1,650,000円)
  • ワーキングホリデーアルバイト: 月1,500,000～2,800,000ウォン (約165,000～308,000円)
  • インターンシップ: 月1,500,000～3,500,000ウォン (約165,000～385,000円)

所得税:

  • 非居住者 (183日未満): 単一22% (地方税含む)
  • 居住者 (183日以上): 累進6～45%・年申告 (5月)
  • 外国人単一税19%オプション: 5年間適用・高度人材マニア

DTA (二重課税防止):

  • 90カ国以上と協定 (米国・EU・日本・中国・オーストラリア・カナダ・ロシアなど)
  • 韓国の税金 → 本国で控除可能
  • 申請: 本国の税務署・韓国居住証明 (NHIS (国民健康保険公団)・口座・銀行の写し)

NHIS (国民健康保険公団)・年金・雇用保険:

  • NHIS (国民健康保険公団): 外国人義務・月130,000ウォン～ (約14,300円～) (所得比例)・6ヶ月以上
  • 国民年金: F-2/F-4/F-5義務・DTAで本国送金可能
  • 雇用保険: 正規職義務・失業給付マトリックス

⚠ 外国人労働・生活の注意点

労働時間:

  • フルタイム: 週40時間以内・超過時は1.5倍の手当
  • 夜間 (22:00～06:00): 1.5倍
  • 週末・休日: 1.5倍

有給休暇: 1年以上勤続 = 年15日・その後2年ごとに1日追加 (最大25日)

解雇保護: 30日前通知または30日分の賃金・F-2-2で解雇時はビザ変更30日猶予

Anti-scam (詐欺防止):

  • パスポート・ARC (外国人登録証) の原本は絶対に譲渡しない
  • 賃金未払い: 1350 (労働部コールセンター・多言語対応) に通報
  • 詐欺採用: 検証済みのサイト (Saramin (サラムイン)・JobKorea (ジョブコリア)) を利用
