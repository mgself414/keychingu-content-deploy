🍱 4채널 deep dive

🍱 한정식 마지막 (Hanjeongsik Final Drinks)

핵심 가치: 6단계 코스 마지막 + 식혜·수정과 무료 #1.

  • 추천 매장:
  • 신라호텔 라연 (미슐랭 3스타) — 정통
  • 삼청각·인사동 한정식 — 정통
  • 가격 anchor: 한정식 코스 무료 포함 (40,000~150,000원 코스 전체)
  • 시간: 11:30~22:00
  • 외국인 친화도: ★★★★

🍚 가정식 후식 (Home-style Post-meal)

핵심 가치: 홈스타일 무료 + 식혜·매실차 + 가족 친화.

  • 추천 매장:
  • 종로·강남·명동 백반집 — 가성비
  • 한솥·본도시락 — 가성비 ([#854](#854))
  • 가격 anchor: 가정식 백반 무료 포함 (8,000~15,000원)
  • 시간: 11:00~22:00
  • 외국인 친화도: ★★★★ (가성비)

☕ MZ 카페·트렌드 (MZ Cafe Trend)

핵심 가치: MZ 트렌드·식혜 변형·매실 스파클링·동동주 trend.

  • 추천 매장:
  • MZ 한식 카페 (성수·홍대·강남) — 트렌드
  • 전통차 카페 (북촌·인사동) — 정통+MZ
  • 가격 anchor: 5,000~10,000원/1잔
  • 시간: 10:00~22:00
  • 외국인 친화도: ★★★★★ (MZ·영문·인스타)

🛒 마트·편의점 (Mart·Convenience Store)

핵심 가치: 24h 접근 + 캔·페트 가성비 #1.

  • 추천 매장:
  • 편의점 (CU·GS25·세븐일레븐·이마트24) — 24h
  • 이마트·롯데마트·홈플러스 — 마트
  • 가격 anchor: 2,000~7,000원/캔·페트
  • 시간: 24h (편의점)
  • 외국인 친화도: ★★★★★ (24h·캔·영문)

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가격·매니아·트렌드 완전 다름. 무료 = 한정식·가정식 / 트렌드 = MZ / 24h = 마트.

2. "한정식·가정식 = 비용": 한정식·가정식 마무리 음료 = 무료 포함.

3. "MZ 카페 = 차": MZ 카페 = 식혜 변형·매실 스파클링 (트렌드 음료).

4. "마트 = 단조": 마트·편의점 = 24h 접근·가성비·12종 이상 선택.

5. "동동주 = 카페 음료": 동동주 = 6~8% 알코올 술·MZ 카페에서도 알코올 음료로 제공.

⚙ FAQ 8개

1. 첫 마무리 음료 채널 = 어디: 한정식 코스 마지막 (#1 무료) → 마트 (가성비).

2. 인스타·vlog: 한정식 식혜 (#1)·MZ 카페 식혜 변형.

3. MZ 트렌드: MZ 카페 (#1) 식혜 변형·매실 스파클링.

4. 소화·해장: 매실차 (마트·가정식).

5. 알코올·임신: 동동주 = 임신부·운전 X.

6. 알레르기·임신: [#870 disclaimer](#870) 참조.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

식사 마무리 음료 4채널 모두 일반 음식. 임신부·어린이 = 식혜·수정과·매실차 OK (동동주 = X 술). 알레르기 (잣·생강) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 식혜·수정과·매실차 = OK / 동동주 = 알코올 X.
  • 채식·비건: 5종 채식 OK.
  • 글루텐 free: 6종 모두 OK.
