🥩 3チャンネル deep dive

🥩 精肉食堂 (Butcher's Restaurant)

核価値: 1階精肉売り+2階食堂、直接肉等級・部位選択。コスパ ★★★★★ コスパ雨ハンウ。

  • おすすめ店（ソウル）：
  • 馬場洞精肉食堂 cluster (城東区) — 韓国 #1 畜産物市場、韓牛 1++
  • ウィジョンブ精肉食堂（ウィジョンブ平和路） - 韓国BBQマニア1番地
  • 江南マジャンドン cluster (江南区) — 江南進出店
  • システム: 1階売り場で韓牛・韓金部位・等級選択（kg/近単位）→2階/同じ建物食堂移動→セルフ焼き
  • 価格アンカー（1人）：
  • 韓牛1+茶石150g = 25,000〜35,000ウォン
  • Han Woo 1 ++花の背中150g = 50,000〜70,000ウォン
  • ハンドンサムギョプサル200g = 15,000〜22,000ウォン
  • 商車林費1人5,000～10,000ウォン
  • 外国人親和性: ★★★ （英語メニューほとんどない、写真メニュー・翻訳アプリ活用）
  • 決済: 売り+食堂=分離OR一括(店舗別)
  • メリット: コスパ ★★★★★、等級・部位直接確認、卸売が近接
  • デメリット：英語のほぼX、セルフベーキング（失敗risk）、システム複雑

🏮 BBQ専門店 (BBQ Specialty Restaurant)

コアバリュー: フルサービス+本格的な韓国式ワン賞+スタッフの書き込み。飲み会・接待1位。

  • 種類:
  • 韓牛専門店：韓牛1++シグネチャー（江南・清潭・新羅ホテル） — 1人150,000～300,000ウォン
  • 味付けカルビ専門店：麻浦・太平路・鍾路韓牛カルビ屋 - 1人70,000～120,000ウォン
  • チェーンBBQ：セマウルレストラン、ハナム豚屋、ソガアンクックなど - 1人30,000〜60,000ウォン
  • おすすめ店（ソウル）：
  • 江南・清潭韓牛集：ウレオク・夜明けハウス・ハナムレストラン
  • 鍾路正統リブハウス: 韓日館・美進・駅前会館
  • 新羅ホテル韓国料理ラヨン（La Yeon） — ラグジュアリー1番地（ミシュランガイド）
  • システム: フルサービス
  • 価格アンカー（1人）：
  • チェーンBBQ 30,000～60,000ウォン
  • 韓牛カルビ本格70,000～120,000ウォン
  • 韓牛1++専門店 150,000～300,000ウォン
  • 外国人親和性: ★★★★★ — 英語メニュー・英語応対・観光地近く
  • 決済：カードOK・カウンターまたはテーブル1回（ホテル韓国料理店税10％＋サービス料10％別途）
  • 予約: 正統・韓牛専門店 = 1～2週間前必須 (キャッチテーブル・ネイバー予約)
  • 利点: フルサービス・英語応対・格式・接待適合
  • デメリット: 高価・予約困難

🛒 Market BBQ (Market BBQ)

核心価値: コスパ ★★★★ +市場の雰囲気+外国人vlog ★。広場市場麻薬キムバプ(Mayak Gimbap、"addictive"ニックネーム、政府勧告で英文表記中立化傾向)横カモメの虐殺路地=外国人インスタ1番地。

  • おすすめ市場（ソウル）：
  • 広場市場 (Gwangjang Market, 鍾路) — 麻薬キムバプ + カモメギサル・ヒョンチャン・ブタ殻路地、外国人マニア #1
  • 東大門BBQ通り（Dongdaemun BBQ Street） - 深夜運営店舗多（24hは一部店舗限定）、外国人東大門ショッピング後1ランク
  • 馬場洞畜産物市場 (城東区) — 韓国 #1畜産市場、精肉食堂と統合cluster
  • 公徳市場（Gongdeok Market、麻浦）
  • システム: 市場売り場 walk-in → 即席セルフベーキング → 売り場カウンター決済
  • 価格アンカー（1人）：
  • カモメキサル200g 15,000ウォン〜
  • コクチャン1人前12,000〜18,000ウォン
  • 豚皮1人分10,000～15,000ウォン
  • 酒（焼酎・ビール） 4,000～6,000ウォン
  • 外国人親和性：広場市場 ★★★★★ (英語メニュー・観光通訳) / 東大門 ★★★★ / 馬場洞 ★★★ / 公徳 ★★★
  • 決済: 毎代1回（現金・カード混用、小売代現金推奨）
  • 予約: walk-in基本（広場は週末30分～1h待機）
  • 利点: 苛性雨・雰囲気・外国人 vlog ★
  • 短所: 衛生偏差・座席狭さ・換気弱さ

⚠外国人の頻繁な誤り5つ

1. "精肉食堂= BBQ専門店": システムの完全な相違。精肉食堂＝マケ＋セルフ／専門店＝フルサービス。価格・雰囲気の両方差。

2. 「韓牛＝BBQ専門店のみ」：精肉食堂も韓牛1++販売。 同一グレード・同一部位基準、精肉食堂が卸売価格近接→一般専門店に比べ体感30～40％のコスパ比（店舗・シーズン別偏差あり）。

3. 「市場BBQ＝衛生X」：広場市場・東大門＝観光地店舗＝定期保健点検対象。ただし、各台別偏差可能 — 回転率・清浄度も直接確認することをお勧めします。

4. 「江南・清潭＝無条件高価」：江南にも精肉食堂cluster（1人35,000ウォン～）あり。検索時に「精肉食堂江南」キーワード。

5. 「予約 = すべて同じ難しさ」: 精肉食堂 = walk-in OK / 韓牛専門店 = 1～2週間前 / 市場 = walk-in (広場は大気)。

⚙ よくある質問8件

1. 最初のBBQ =どこ?: BBQ専門店フルサービス 1ランク(英語・職員焼き)。慣れれば精肉食堂。

2. 韓牛 1++ 苛性比: 精肉食堂 馬場洞 (卸売価格近接、同一等級・部位基準 一般専門店に対する体感30～40% 苛性比 — 店舗・シーズン別偏差)。

3. インスタ・写真: 広場市場のカモメの虐殺路地 (外国人 vlog 1番地)。

4. 会食・接待: BBQ専門店江南・清潭韓牛集。新羅ホテル韓国料理店＝最上位。

5. 単独BBQ: 市場BBQ（広場） 1人walk-in OK。精肉食堂の一部1人OK/専門店lunchのみOK。

6. アレルギー・妊娠医療: #804 disclaimer参照。市場BBQ =換気・狭さ→妊婦注意。

7. 決済・チップ: カードOK / チップX / ホテル 韓食堂サービス料10%+税10%。

8. VAT払い戻し: 飲食の一般還付対象ではない。

⚠医療・安全・食事ダイエット

BBQ 3チャンネルすべて直接調理 = 画像危険・豚/鶏 well-done必須。市場BBQ＝換気弱さ、服・髪のにおい＋妊婦・喘息患者の注意。広場市場＝食中毒の疑いがある場合☎1339（医療、英語）+☎1330（観光通訳）。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャ：一般韓国BBQ店舗＝ハラル・コーシャ認証未保有。 →イテウォン・江南一部認証店舗事前検索・予約（Eid・Makan・Halal Korean BBQ）。
  • ベジタリアン・ビーガン：3チャンネルともに肉類中心。 →[#799ベジタリアン・ビーガンマトリックス]（799_外国人_韓国_ベジタリアン_ビーガン_マトリックス_12線_deep_dive.md）参照OR別の店舗分離。
  • イスラム・ユダヤ・ヒンドゥー：宗教的食事=事前店舗確認。
