🎯 だれのために、なぜこの2か所か

慶州 (Gyeongju / 경주)で仏国寺 (Bulguksa / 불국사)と石窟庵 (Seokguram / 석굴암)を見たい外国人旅行者に合わせた号です。韓国語がわからなくても、出発前に時間とバス番号を合わせられるように書きました。

石窟庵は吐含山 (Tohamsan / 토함산)の中腹にあります。石窟庵の公式サイト(2026-11-25閲覧)は「吐含山の中腹に白色の花崗岩を使って人為的に石窟を造り」と書いています。国立公園公団 (Korea National Park Service / 국립공원공단)は、仏国寺から石窟庵へ行く道を吐含山の探訪コースとして紹介しています。石窟庵の公式サイトは「石窟庵は1995年12月に仏国寺とともにユネスコ世界文化遺産に共同登録された。」と書きました。そのため、2か所を1つの号にまとめました。

この号が答えるのは4つです。

  • 何時まで入れるか: 月ごとに入場締め切りの時刻が違います。
  • お金がかかるか: 観覧料は無料です。駐車とバスにお金がかかります。
  • 2か所のあいだをどう行き来するか: 12番バス、2.8kmの探訪路、自家用車の3つです。
  • 冬に何が変わるか: 入場締め切りが早まり、吐含山の頂上側の道が工事で塞がります。

慶州市内の遺跡と食堂、宿は、この号では扱いません。市内の夜の動線、市場、韓服は、下のRelated節の号にあります。

⚠ 表記の原則: 時間、料金、距離、行き方は、2026-11-25に閲覧した値です。出典は、仏国寺の公式サイト、石窟庵の公式サイト、慶州市庁 (Gyeongju City Hall / 경주시청)、国立公園公団、国家遺産ポータル (National Heritage Portal / 국가유산포털)です。料金は大人の定価です。17:00、17:30、18:00は閉門の時刻ではなく、入場締め切りの時刻です。国立公園公団の探訪ニュース画面には、掲載日が表示されていません。運営時間、料金、バスの運行、統制区間は変わることがあります。

🚌 行き方

1. ターミナルから仏国寺 — 市内バス10番、11番

慶州市庁の公式案内(2026-11-25閲覧)の値です。

  • 10番: ターミナルを出発して、瞻星台 (Cheomseongdae / 첨성대)と普門 (Bomun / 보문)を通り、仏国寺で折り返します。
  • 11番: 10番と同じ路線を反対方向に回ります。慶州市の案内は、11番も仏国寺を折り返し地点と書いています。
  • 時間: 10番はターミナル基準で始発が06:00、終バスが21:40です。約20分おきに来ます。
  • 直行するときの時間: 慶州市庁は「起点であるターミナルから折り返し地点の仏国寺まで、途中で停まらずに直行する場合、約35分~45分ほどかかります。」と書きました。市庁は、この値が交通状況によって変わると書きました。市内の観光地を回る路線なので、途中で停まるとさらにかかります。
  • 降りる所: 「仏国寺」停留所です。停留所から仏国寺まで歩いて3~5分です。
  • 料金: 一般1,500ウォン、青少年1,200ウォン、子ども800ウォンです。交通カードを使うと、一般は50ウォン割り引き、子どもと青少年は無料です(他地域の住民を含む)。
  • 10-1番は乗りません: 10-1番は仏国寺まで行きません。慶州ワールド (Gyeongju World / 경주월드)で折り返します。

仏国寺の公式サイトのアクセス案内も、仏国寺行きのバスを10番と11番と書いています。

2. 仏国寺から石窟庵 — 12番バス

石窟庵の公式サイトのアクセス案内(2026-11-25閲覧)の値です。

  • 行き: 仏国寺から12番バスに乗り換えます。
  • 帰り: 石窟庵の公式サイトが示した12番の時刻は、石窟庵から仏国寺へ行く「毎時ちょうど出発」です。
  • 石窟庵で: 石窟庵駐車場から石窟庵まで歩いて約10分です。

石窟庵に入る前に、帰りの時刻を決めておきます。この号の勧めです。

3. 仏国寺から石窟庵 — 歩いて2.8km

国立公園公団の公式探訪ニュース(2026-11-25閲覧)は、「仏国寺~石窟庵探訪コース」(総延長2.8km、約1時間)と紹介しています。仏国寺と石窟庵は、慶州国立公園 (Gyeongju National Park / 경주국립공원)の中にあります。2か所のあいだの山道が、国立公園の探訪路です。

秋の山火事注意期間(2026-11-15~2026-12-15)には、公団が吐含山の探訪路のうち仏国寺~石窟庵区間を一部開放します。この期間に歩く計画なら、12番バスもいっしょに決めておきます。この号の勧めです。

4. 自家用車

  • 市内から仏国寺: 仏国寺の公式サイトの案内で、国道7号線を蔚山 (Ulsan / 울산)方面へ行きます。クジョンドン (Gujeong-dong / 구정동)三叉路で左折します。地方道902号線を約2.5km行きます。
  • 仏国寺から石窟庵: 石窟庵の公式サイトの案内で、石窟庵の道しるべに従って吐含山の道を約20分行きます。石窟庵駐車場に着きます。
  • 駐車料金: 仏国寺は乗用車2,000ウォンです。石窟庵は小型・中型2,000ウォンです。

いつ建てた寺か

仏国寺の公式サイトの歴史案内(2026-11-25閲覧)は、創建の記録と大規模な改修の記録をあわせて紹介しています。

  • 528年: 新羅 (Silla / 신라)の法興王 (Beopheung / 법흥왕)の時に、寺を初めて建てたという記録があります。公式サイトは、この記録の出典を『仏国寺古今創記 (Bulguksa Gogeum Changgi / 불국사고금창기)』と書きました。同じ案内は、この記録が「文献的な根拠が弱く」とも書いています。
  • 751年: 公式サイトは「751年(景徳王 (Gyeongdeok / 경덕왕)10)に金大城 (Kim Dae-seong / 김대성)によって大きく改修され、塔と石橋なども造ったという。」と書きました。

その後のことも、同じ案内にあります。

  • 1593年: 「1593年、倭軍によって破壊された仏国寺は、1604年ごろから復旧と再建があらためて始まった。」
  • 1970~1973年: 1970年2月に復元工事を始めて、1973年6月に終えました。このとき、無説殿 (Museoljeon / 무설전)、観音殿 (Gwaneumjeon / 관음전)、毘盧殿 (Birojeon Hall / 비로전)、経楼 (Gyeongnu / 경루)、回廊を復元しました。

  • 仏国寺~石窟庵の探訪路: 秋の山火事注意期間(2026-11-15~2026-12-15)には、公団が吐含山の探訪路のうち仏国寺~石窟庵区間を一部開放します。この期間に歩く計画なら、12番バスもいっしょに決めておきます。この号の勧めです。
  • 気象特報が出ると石窟庵を統制することがあります: 石窟庵の公式サイトは、大雨、台風、大雪の注意報や警報が出ると、境内への出入りを統制することがあると書きました。石窟庵の公式サイトのお知らせ一覧には、日付が03-04とだけ表示された「3月4日 大雪のため入場不可。5日2時から入場可能。」という題のお知らせがあります。大雪が降ると入場が止まることがある例です。
  • 1日に2か所を見るなら: 冬は午前に出発します。この号の勧めです。
  • 問い合わせ: 石窟庵 054-746-9933。仏国寺 054-746-9913。慶州国立公園探訪案内所 (Gyeongju National Park Visitor Center / 경주국립공원 탐방안내소) 054-778-4100。

  3. 仏国寺から石窟庵までどう行く? — 3通りです。仏国寺で12番バスに乗り換えます。歩くと探訪路が2.8kmで、約1時間です。秋の山火事注意期間(2026-11-15~2026-12-15)には、この区間は一部開放です。車では、吐含山の道を約20分行きます。
  4. 休みの日はある? — 仏国寺も石窟庵も年中無休です。石窟庵は、大雨、台風、大雪の注意報や警報が出ると、境内への出入りを統制することがあります。
  5. 仏国寺はいつ建てた寺? — 仏国寺の公式サイトの歴史案内は、創建の記録と大規模な改修の記録をあわせて紹介しています。528年、法興王の時に寺を初めて建てたという記録があります。公式サイトは、この記録が「文献的な根拠が弱く」と書きました。751年には、金大城が寺を大きく改修しながら、塔と石橋を造ったという記録があります。
  6. 石窟庵から吐含山の頂上へ行ける? — 2026-11-01から2027-03-31までは行けません。石窟庵ジキムトから頂上へ行く1.4km区間を、工事で統制しています。公団は、2027-01-01の初日の出のときに期間限定で開ける予定だと書きました。
