🎯 このガイドの使い方

江北区の水踰・弥阿・牛耳は、牛耳新設線 (Ui-Sinseol / 우이신설선)(北漢山牛耳 ↔ 新設洞、13駅)の1路線で、北漢山トゥルレギルの入口・4・19民主墓地・松林公園・華渓寺がつながり、水踰駅(4号線)周辺にはレビューの多い地元の店が集まっているエリアです。名所の時間・住所・区間距離は、2026-10-07に国立公園公団・国家報勲部・江北区の公式ページで確認した値だけを載せました。飲食店9カ所はキーチングの場所プールからレビュー数(rv)の上位を選んだものなので、営業時間・定休日は当日に地図アプリで確認してください。以前のガイドにあった「トゥルレギル1区間は4・19墓地を含めて4時間」「牛耳駅」「江南から40~50分」は公式の情報と異なっていたため修正しました。

🚈 牛耳新設線 — このエリアの軸

  • 北漢山牛耳 → 松林公園 → 4.19民主墓地 → ガオリ → 華渓 → 三陽 → 三陽交差点 → ソルセム → 北漢山ボグクムン → 貞陵 → 城北女子大入口 → 普門 → 新設洞、13駅(運営会社の公式情報)。
  • 平日の北漢山牛耳発 始発05:30・終電24:37、日中は5分間隔(公式)。城北女子大入口(4号線)・普門(6号線)・新設洞(1・2号線)で乗り換えます。
  • 以前のガイドにあった「牛耳駅」という名前の駅はありません — 正しくは北漢山牛耳駅 (Bukhansan Ui / 북한산우이역)です。

🥾 北漢山トゥルレギル・牛耳嶺路

  • 1区間 松林の道: 北漢山牛耳駅側から出発、3.1km・約1.5時間(公式)。トゥルレギルなので登山靴がなくても歩けます。
  • 2区間 巡礼の道: 2.3km・約1時間10分、4・19民主墓地を通ります(公式)。1区間+2区間をつなげて半日です。
  • 牛耳嶺路(21区間): 6.8km・約3.5時間、予約制 — reservation.knps.or.kr、外国人・65歳以上・障がい者は電話予約(公式)。1日の人数制限・予約が必要な曜日は公式ページで確認してください。
  • 白雲台の頂上コースと牛耳探訪支援センターの時間は、今回は公式ページを確認できなかったため載せていません。

🕊 4・19民主墓地 — トゥルレギル2区間の途中

  • 1960年の4・19革命の犠牲者を祀る国立墓地(国家報勲部)。正門 3~10月 06:00~18:00・11~2月 07:00~17:00、記念館・参拝 09:30~17:30(冬季は16:30)、記念館は月曜休館(公式)。料金・英語案内は公式に掲示なし。
  • 牛耳新設線の4.19民主墓地駅から600m・5分(公式)。

🌲 北ソウル夢の森・松林公園・華渓寺

  • 北ソウル夢の森: 常時開放、月溪路 173、東門・西門からバス・地下鉄でアクセス(公式)。料金・定休日・夜間ライトアップは公式に掲示なし。
  • 松林公園: 三陽路 561、松 約1,000本・34,955㎡(江北区)。トゥルレギル1区間とあわせて回ります。
  • 華渓寺: 華渓寺ギル 117、テンプルステイ実施(公式 — 申込・料金は寺の公式ページ)。華渓駅から。

🛒 水踰伝統市場・牛耳市場

  • 江北区の公式市場リストに水踰伝統市場 (Suyu Jeontong Sijang / 수유전통시장)と牛耳市場 (Ui Sijang / 우이시장)があります(住所・電話は公式)。営業時間・定休日は公式に掲示なし — 平日の昼間が安心です。

🚶 半日コース2つ

  • A トゥルレギル+墓地: 北漢山牛耳駅 → トゥルレギル1区間(1.5h) → 2区間(1h10)・4・19民主墓地(月曜は記念館休館) → 4.19民主墓地駅 → 水踰駅 (Suyu / 수유역) で飲食店へ。
  • B 寺+公園: 華渓駅 (Hwagye / 화계역) → 華渓寺 → 松林公園 → 北漢山牛耳駅 → 夜は水踰。

⚠ よくある間違い5つ

1. 「牛耳駅」で検索する — 正しくは北漢山牛耳駅です。

2. 牛耳嶺路に予約なしで行く — 予約制です。外国人は電話予約。

3. トゥルレギル1区間で4・19墓地を探す — 墓地は2区間にあります。

4. 月曜日の記念館 — 休館です(墓域は正門の開門時間内なら入れます)。

5. 飲食店の時間を信じて行く — このガイドには載せていません。当日に地図アプリで確認してください。

⚙ FAQ 6つ

1. 登山はしなくてもいいですか? — トゥルレギル1・2区間は散歩レベルです(3.1km+2.3km)。

2. 墓地は何時までですか? — 正門18:00(11~2月は17:00)、記念館17:30(冬季は16:30)。

3. 牛耳嶺路の予約はどこでできますか? — reservation.knps.or.kr、外国人は電話で。

4. 公園の入場料は? — 松林公園は無料。北ソウル夢の森の料金は公式に掲示なし(公園自体は常時開放)。

5. 夜に牛耳新設線は走っていますか? — 平日の終電は24:37(北漢山牛耳発)。

6. 飲食店の選定基準は? — キーチングの場所プールのレビュー数順で、味の評価ではありません。
