  • K-content fusion: 청계천 빛초롱 + 한복 + K-드라마 매니아 풀세트

Tip 5

Tip 1 — 청계천 빛초롱 best 시간 (인스타 매니아)

  • best 시간: 17:30 (일몰 + 빛 시작) ~ 19:00 (빛 풀세트)
  • best 평일: 10/30 목·10/31 금·11/3 월 (인파 X)
  • 꿀팁: 광화문 → 청계광장 → 동측 2km 산책 풀세트
  • 인스타 spot: 청계광장 메인 + 다리 view + 종각 방향

  • 외국인 매니아: 1순위 인스타
  • 꿀팁: 한복 + 빛초롱 = 외국인 매니아 최고 인스타

Tip 4 — 옷차림 + 준비물 (저녁 풀세트)

  • 10월 하순 평균 저녁 8°C: 보온 layer + 패딩 + 모자
  • 신발: 운동화 (도심 walkable 풀세트)

  • 꿀팁: 저녁 5°C ↓·따뜻한 음료 준비

Tip 5 — 광장시장 + 청계천 풀세트 (외국인 매니아 #1)

  • 광장시장: 빈대떡 + 마약김밥 + 떡볶이 한국 #1 + EN 메뉴
  • 연계: 광장시장 (저녁 18:00) → 청계천 (19:00 빛초롱)
  • 꿀팁: 광장시장 마약김밥 = 외국인 매니아 1순위 (#357 cross)
