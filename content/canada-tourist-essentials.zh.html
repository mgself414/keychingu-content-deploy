加拿大游客韩国指南——K-ETA豁免·免签180天·入境自动通关·温哥华/多伦多航班·大使馆(2026年10月官方数据)

副标题: 加拿大护照K-ETA临时豁免至2026-12-31(驻加拿大大韩民国大使馆公告) · 观光、出差免签最长180天(加拿大政府travel.gc.ca) · 自2026-03-16起为入境自动通关适用国家(法务部) · 大韩航空正在销售温哥华、多伦多–仁川 (Incheon / 인천) 机票(大韩航空官方) · 加拿大驻韩大使馆 +82 2 3783 6000 — 截至2026-10-21

ISSUE 03 · #464 · 2026-05-27

🎯 本指南的使用方法

仁川机场 (Incheon Airport / 인천공항) 入境大厅,手持加拿大护照的人不排普通通关队伍,而是站到了自动通关闸机前——自2026年3月16日起,加拿大公民也成为入境自动通关的对象(法务部)。本指南只依据官方页面的数值,整理从加拿大来韩国短期旅行的人出发前要确认的四件事:入境文件(K-ETA、e-Arrival)、入境通关(自动通关闸机)、航班、当地的钱和联系方式。官方页面上没能确认的内容,就如实写明没有确认。打工度假、留学、就业等长期停留不在本篇范围内。

旧版指南中的“访韩加拿大人40万/年”“K-pop粉丝500万+”“Korean Canadian 25万+”“自由行90%·客单价$1,400”“打工度假每年4,000人”找不到官方来源,已删除。旧路线中的HYBE INSIGHT已经关闭,所以也去掉了。

🛂 入境文件——K-ETA与e-Arrival Card

  • K-ETA临时豁免: 从2026年1月1日持续到12月31日(K-ETA官方公告)。公告中没有列出适用国家名单,但驻加拿大大韩民国大使馆公告称“临时豁免政策对加拿大护照持有者延长至2026年12月31日”(大使馆公告,2026-03-13修订)。驻多伦多总领事馆公告也写明“加拿大豁免”(2025-12-18)。即便如此,出发前仍请在k-eta.go.kr申请页面扫描护照,就会显示是否“属于豁免对象”
  • 豁免了还能申请吗: 可以。如果想要免填入境卡之类的便利,可以申请K-ETA,此时需要付手续费(驻加拿大大使馆公告)。2027年以后是否延长尚未公布
  • 免签停留天数: 加拿大政府介绍,观光、出差目的可免签证停留最长180天(travel.gc.ca,2026-10-15更新)。驻多伦多总领事馆的帖子也写“最长6个月”(2024-09-11修订)。以观光客身份入境后,不能变更停留资格(travel.gc.ca)
  • 营利活动另算: 以获取报酬的活动为目的,必须办理签证(驻多伦多总领事馆)。学习、就业签证要在韩国境外办理(travel.gc.ca)
  • e-Arrival Card: 如果实际上没有获得K-ETA,就要提交e-Arrival Card。入境前3天起可在线免费填写,到达后用纸质表格填写也可以。加拿大政府警告“不要使用收费的入境卡网站”(travel.gc.ca)。步骤见#1289 e-Arrival卡手册

🛃 入境通关——自动通关闸机

  • 法务部于2025-11-03从4个国家和地区开始实施外国人入境自动通关,并在2025-12-01、2026-03-16两次扩大。加拿大是在2026-03-16加入的,适用对象共计42个国家和地区(法务部发布,2026-06-01)
  • 年龄条件、可使用的机场、出境自动通关,整理在#1412 自动通关·Smart Pass手册中
  • 同样是北美,美国不在这42个国家的名单内(法务部)。与持美国护照的同行者,队伍可能会分开

✈ 航班

  • 大韩航空: 官方网站上有温哥华(YVR)–仁川、多伦多(YYZ)–仁川的票价页面,显示2026年10月~2027年出发日期的各日票价(大韩航空官方)。是否直飞和每周班次数,这个页面上没有写。大韩航空新闻中心在2019年的文章里把仁川~多伦多介绍为“每周7班、每天直飞”,但作为现在的班次数来用,这个数值太旧了
  • 加拿大航空: 首尔航线的官方页面打不开。蒙特利尔、卡尔加里等其他城市出发的航班也没能确认——请在订票网站按日期搜索
  • 从仁川机场到首尔 (Seoul / 서울) 市区见#1249 机场铁路(AREX)指南

🥗 饮食

  • 素食: 很多人以为泡菜是素食,但泡菜的调味料大多含有腌虾酱、鱼露或肉类高汤(VisitKorea)。豆腐汤、焖豆腐也常加腌虾酱(VisitKorea)
  • 清真: VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的伊德 (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌萨丹路10街 (Usadan-ro 10-gil / 우사단로10길) 15号,每天12:00~21:00)是少数被韩国伊斯兰教中央会 (Hanguk Iseullamgyo Jungangheo / 한국이슬람교중앙회,KMF) 认定为清真的餐厅。认证可能变动,到访前请先确认。更多地方见#453 素食·清真指南
  • 过敏·饮食需求: 韩语出示卡片见#1300 饮食需求手册

🧰 韩国旅行实用信息——钱、通信、交通、联系方式

  • 取现: 部分大型银行的ATM接受外国借记卡、信用卡。单次取款限额较低,手续费占比可能偏大,接受加拿大账户的ATM大多有英文提示(travel.gc.ca)。银行卡与移动支付见#527 韩国支付系统
  • 通信: #1303 eSIM开通手册
  • 交通卡: #1298 三种交通卡怎么选 · 找路见#1295 Naver地图手册
  • 点餐·沟通: 语言不通时看#1339 点餐礼仪,旅游咨询·翻译拨打1330。一个人吃饭的地方见#348 Seoul Solo Diner Map
  • 加拿大驻韩大使馆: 首尔中区 (Jung-gu / 중구) 贞洞路 (Jeongdong-gil / 정동길) 21号,电话+82 2 3783 6000,邮箱seoul-cs@international.gc.ca。非工作时间的紧急情况请联系渥太华的Emergency Watch and Response Centre——在韩国可免费拨打001-800-2326-6831 · 002-800-2326-6831 · 008-800-2326-6831(加拿大政府travel.gc.ca,2026-03-23更新)
  • 安全等级: 加拿大政府对韩国的旅行建议是最低等级“Take normal security precautions”(travel.gc.ca)
  • 首次路线: 一天串起宫殿和宗庙的方法见#1255 首尔五大宫完全攻略,首尔以外见#1372 韩国黄金路线①

⚠ 常犯的4个错误

1. “K-ETA豁免,所以什么都不用交” — 如果没有获得K-ETA,就要提交e-Arrival Card。在线填写是免费的(travel.gc.ca)

2. “豁免明年也会继续” — 目前已公告的豁免期限只到2026-12-31(K-ETA公告)。如果是2027年出发,请重新确认

3. “加拿大eTA和韩国K-ETA是一回事” — 加拿大eTA是进入加拿大时需要的许可(外交部海外安全旅行)。与入境韩国无关

4. “免签就可以在当地工作” — 营利活动需要签证(驻多伦多总领事馆),而且以观光身份入境后不能变更停留资格(travel.gc.ca)
