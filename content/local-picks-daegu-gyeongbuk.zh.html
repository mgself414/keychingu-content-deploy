本地人推荐 ② 大邱·庆北 — 韩国观众在评论里点名的22家饭馆，只用Naver核实过

副标题：大邱一日游攻略(#1001)、庆州KTX(#1115)、安东河回村(#1053)都没覆盖的一条轴线——从韩国观众在YouTube评论区推荐的全国饭馆整理表里，只挑出大邱、庆北22家，用Naver本地搜索核实了店名、地址、业种是否存在，不做评价。大邱9家→大庆线轴线倭馆、龟尾5家→庆州、浦项、安东、闻庆、清道8家。龟尾、倭馆、闻庆、清道都是KeyChinGu第一次收录的城市。

ISSUE 06 · #1383 · 2026-09-18 · 本地人推荐 ②

🎯 为什么以"评论推荐"为标准

这一角只有一个来源。观众在韩国某YouTube频道上传的"全国饭馆"视频下用评论写下自己家门口的饭馆，按地区整理得最系统的评论被做成了一张217家的表。因为是韩国人推荐给韩国人的名单，外国人评论几乎没有，很多是上不了旅游名单的乡镇小馆。这一角的标准和局限写在①篇(#1382)里。

KeyChinGu只用Naver本地搜索核实了店名、地址、业种是否真实存在(2026-09-17)。24家大邱、庆北的店里22家得到确认，剩下2家(龟尾、庆州各1家)没通过，从正文排除。没有到店评价、排名、星级，也没有营业时间、价格——去的当天以Naver Place为准。

这一篇和①篇不同的地方是铁路。2024年12月开通的大庆线 (Daegyeong Line / 대경선)用电车把龟尾–倭馆–大邱–庆山连了起来，同年11月中部内陆线KTX-Eum (Jungbu Naeryuk Line KTX-Eum / 중부내륙선 KTX-이음)让板桥到闻庆只要约90分钟。22家里有一半就在这两条线上。

⚠ 标注原则：每家店的一行遵循店名 (罗马字) · 道路名地址 · Naver业种 · 交通的顺序。交通只写官方或2个以上信息源确认过的车站、公交，没确认的路段留"以Naver地图为准"。营业时间、休息日、价格全部未收集——去的当天在Naver Place确认。给出租车司机看，直接出示韩文地址就行。

① 大邱 — 9家，地铁1·2·3号线

如果说大邱一日游攻略(#1001)和八公山(#1005)是观光路线，这九家就是观众写下的家门口饭馆。牛骨汤、汤饭、绿豆煎饼、生肉、中餐、小吃——大邱人平日吃的东西。

  • 今日也绿豆煎饼 (Oneuldo Bindaetteok / 오늘도빈대떡) · 大邱中区达句伐大路446街7-16 (7-16 Dalgubeol-daero 446-gil, Jung-gu / 대구 중구 달구벌대로446길 7-16) · 韩食 · 煎饼·绿豆煎饼 · 防川市场本店——庆大医院站(2号线) 3号出口，步行约500米

防川市场紧挨着金光石街。绿豆煎饼(也叫nokdujeon，녹두전)是市场食物的代表，一般配马格利酒一起点。

  • 丰进牛骨汤 (Pungjin Gomtang / 풍진곰탕) · 大邱南区凤德路1街11 (11 Bongdeok-ro 1-gil, Nam-gu / 남구 봉덕로1길 11) · 韩食 · 牛骨汤·雪浓汤 · 靠近乾达岩站(3号线)，730路公交到凤德洞

牛骨汤是把牛骨、牛肉长时间炖煮出的清汤，盐和葱自己调味(和#1191里牛骨汤的小贴士一样)。

  • 南山 (Namsane / 남산에) · 大邱中区中央大路66街20 (20 Jungang-daero 66-gil, Jung-gu / 중구 중앙대로66길 20) · 日本料理 · 市中心中央大路——最近车站以Naver地图步行导航为准

中央路和半月堂之间市中心的一家日料店。大邱市中心以半月堂站 (Banwoldang Station / 반월당역)为坐标，1、2号线在此交汇。

  • 横城砂锅 (Hoengseong Ttukbaegi / 횡성뚝배기) · 大邱东区安心路624 (624 Ansim-ro, Dong-gu / 동구 안심로 624) · 韩食 · 汤饭 · 安心站(1号线)

1号线东端安心一带的汤饭店。砂锅 (ttukbaegi / 뚝배기)是汤饭盛出来时那种厚陶碗的名字。

  • 牛家生肉 (Uga Saenggogi / 우가생고기) · 大邱寿城区达句伐大路641街17-4 (17-4 Dalgubeol-daero 641-gil, Suseong-gu / 수성구 달구벌대로641길 17-4) · 韩食 · 生肉料理 · 寿城区东部——车站·公交以Naver地图为准

生肉，大邱人也叫mungtigi (뭉티기)，是大邱有名的生牛肉料理。因为是没煮过的牛肉，不习惯的人最好先有心理准备。

  • 韭菜杂菜 (Buchu Japchae / 부추잡채) · 大邱寿城区芝范路290 (290 Jibeom-ro, Suseong-gu / 수성구 지범로 290) · 韩食 · 寿城区东南部住宅区——从车站坐公交、出租车(以Naver地图为准)

店名就是菜名。韭菜杂菜是韭菜和肉一起炒的中式风味小菜，配饭吃。

  • 香甜炒年糕 (Dalgo Tteokbokki / 달고떡볶이) · 大邱达西区露天音乐堂路39街54 (54 Yaoeeumakdang-ro 39-gil, Dalseo-gu / 달서구 야외음악당로39길 54) · 小吃 · 综合小吃 · 斗流公园——斗流站(2号线) 14号出口

斗流公园、E-World旁边的小吃店。炒年糕、油炸物(twigim，튀김)、血肠(sundae，순대)、紫菜包饭(gimbap，김밥)是小吃的基本套餐。

  • 五福饭店 (Obok Banjeom / 오복반점) · 大邱达城郡花园邑明川路146 (146 Myeongcheon-ro, Hwawon-eup, Dalseong-gun / 달성군 화원읍 명천로 146) · 中餐 · 中餐馆 · 花园站(1号线) 2号出口步行圈

1号线南端花园的一家中餐馆。饭店 (banjeom / 반점)是中餐馆的旧式说法。

  • 元祖伊坊大婶 (Wonjo Ibang Ajimae / 원조이방아지매) · 大邱达城郡玄风邑玄风路6街5常设市场洞 (5 Hyeonpung-ro 6-gil, Hyeonpung-eup, Dalseong-gun, Sangseol Market area / 달성군 현풍읍 현풍로6길 5 상설시장동) · 韩食 · 从雪花鸣谷站(1号线终点站)转乘公交(路线·时间以Naver地图为准)

玄风是大邱西南角，店在玄风市场里面。阿吉妹 (ajimae / 아지매)是庆尚道方言里"大婶"的意思。

给外国游客的提示 — 大邱地铁有1、2、3号线三条，市中心换乘在半月堂站(1、2号线)。牛骨汤、汤饭可以一人点，生肉一般也是单人份，坐下前确认一下是生牛肉就行。

② 大庆线轴线 — 倭馆2 · 龟尾3

大庆线是2024年12月14日开通的通勤电车，连接龟尾–沙谷–北三(2026年2月28日新增)–倭馆–西大邱–大邱–东大邱–庆山。上下班时间约19分钟一班，平时约30分钟一班。龟尾到大邱约30分钟，住在大邱也能半天内往返倭馆、龟尾。

  • 万里宫 (Malligung / 만리궁) · 七谷郡倭馆邑石田路12街7 (7 Seokjeon-ro 12-gil, Waegwan-eup, Chilgok-gun / 칠곡군 왜관읍 석전로12길 7) · 中餐 · 中餐馆 · 大庆线倭馆站
  • 卡古里什锦炒码面 (Kkakkuri Jjamppong / 까꾸리짬뽕) · 七谷郡倭馆邑平章街21-10 (21-10 Pyeongjang-gil, Waegwan-eup, Chilgok-gun / 칠곡군 왜관읍 평장길 21-10) · 中餐 · 中餐馆 · 大庆线倭馆站

倭馆邑的两家中餐馆。什锦炒码面(jjamppong，짬뽕)是辣味海鲜汤面，和炸酱面一起是韩式中餐的两大支柱。两家都在倭馆站进城区那一侧——步行分钟数以Naver地图为准。

  • 金泰柱善山烤肠 (Kim Tae-ju Seonsan Gopchang / 김태주선산곱창) · 龟尾市松院西路77 (77 Songwonseo-ro, Gumi-si / 구미시 송원서로 77) · 韩食 · 烤肠·烤大肠 · 龟尾站(大庆线·KTX)一带——步行·公交以Naver地图为准
  • 大韩食堂 (Daehan Sikdang / 대한식당)，Daehan Gopchang · 龟尾市善山邑南门路44 (44 Nammun-ro, Seonsan-eup, Gumi-si / 구미시 선산읍 남문로 44) · 韩食 · 烤肠·烤大肠 · 龟尾站↔善山客运站170路公交(171-1、171-4备选)

龟尾的两家烤肠店。善山烤肠是起源于龟尾善山邑的牛小肠炒菜的名字，市区分店和善山本店两家都上了榜。

  • 赤洞面馆 (Jeokdong Guksu / 적동국수) · 龟尾市山东邑江东路1039 (1039 Gangdong-ro, Sandong-eup, Gumi-si / 구미시 산동읍 강동로 1039) · 韩食 · 面条 · 山东邑——从龟尾站·客运站的公交路线待确认，出租车更现实

龟尾东侧山东邑的一家面馆。这里的面条 (guksu / 국수)基本指宴会面(janchi guksu，잔치국수)，凤尾鱼高汤面是标配。

给外国游客的提示 — 烤肠是牛内脏炒菜，喜好分化明显。不少店最低要点两人份，收尾点一份炒饭是当地吃法。面条、中餐可以一人点。

太宗路上一家韩食店和一家泰国菜馆，太宗路是横穿庆州市中心的东西向大路。庆州的观光动线(#1115、#1366)在皇理团街 (Hwangnidan-gil / 황리단길)、大陵苑一带，太宗路是它西边的生活区。

  • 杏仁鸡 (Almond Chicken / 아몬드치킨) · 庆州市阳南面罗亚2街5-1 (5-1 Naa 2-gil, Yangnam-myeon, Gyeongju-si / 경주시 양남면 나아2길 5-1) · 炸鸡·调味鸡 · 庆州高速巴士客运站坐150路(往阳南方向)，约1小时20分，大致每小时一班

庆州东南沿海阳南面的一家炸鸡店，和阳南柱状节理(jusangjeolli，주상절리)在同一条路上，安排在同一天顺理成章。

  • 伊卡代托 (Ikkadaeto / 이까대토) · 浦项市南区九龙浦邑九龙浦街148 (148 Guryongpo-gil, Guryongpo-eup, Nam-gu, Pohang-si / 포항시 남구 구룡포읍 구룡포길 148) · 韩食 · 浦项站坐九龙浦1路(首班07:00，末班18:30，约40分钟一班)

九龙浦是以过鱼干(gwamegi，과메기)和日式老街闻名的港口小镇。末班车18:30，晚饭在这吃有点勉强。

  • 东岳谷锦财花园 (Dongakgol Geumjae Garden / 동악골금재가든) · 安东市卧龙面东岳谷街166 (166 Dongakgol-gil, Waryong-myeon, Andong-si / 안동시 와룡면 동악골길 166) · 韩食 · 辣炖鸡 · 安东站(KTX-Eum) → 往卧龙面方向510、511~514路公交

河回村(#1053)对面卧龙面的一家辣炖鸡(dakbokkeumtang)店。花园 (garden / 가든)是韩国给郊外大型餐厅取名的常见方式。

  • 永顺食堂 (Yeongsun Sikdang / 영순식당) · 闻庆市永顺面永顺路269 (269 Yeongsun-ro, Yeongsun-myeon, Mungyeong-si / 문경시 영순면 영순로 269) · 韩食 · 家常便饭 · 闻庆站(中部内陆线KTX-Eum，板桥出发约90分钟，每天往返8趟) → 出租车到永顺面，待确认
  • 松林食堂 (Solbat Sikdang / 솔밭식당) · 闻庆市中央6街6 (6 Jungang 6-gil, Mungyeong-si / 문경시 중앙6길 6) · 韩食 · 闻庆市区——从车站·客运站的交通待确认

闻庆在2024年11月30日KTX-Eum开通前只能靠大巴到达。白饭定食 (baekban / 백반)指一整桌米饭、汤、小菜，永顺食堂就是这样一家baekban店。

  • 探福水芹菜园 (Tambok Minari Garden / 탐복미나리가든) · 清道郡清道邑寒岾路382 (382 Hanjae-ro, Cheongdo-eup, Cheongdo-gun / 청도군 청도읍 한재로 382) · 韩食 · 清道站(无穷花号)对面客运站 → 往寒岾方向公交·出租车(路线待确认)

寒岾是清道的水芹(minari，미나리)种植区，春天(2~4月)水芹配五花肉(samgyeopsal，삼겹살)一起吃是当地的习俗。产季短，出发前确认时间。

给外国游客的提示 — 庆州站、安东站、闻庆站、浦项站全都在市区外或者离老城区有距离。别指望从车站直接走进去，多算一趟公交或出租车的时间。给出租车司机看韩文地址就行。

🚄 安上地方动线的方法

  • 大邱为据点+大庆线 — 大邱9家靠地铁，倭馆、龟尾5家靠大庆线。龟尾站约30分钟车程，一天内可以倭馆吃午饭、龟尾吃晚饭。
  • 接到庆州(#1115)一晚的行程里 — 太宗路两家在市区一侧，阳南杏仁鸡适合安排半天去柱状节理方向。庆州站在市区外(旧新庆州站)这一点，#1372~1374写得更详细。
  • 首尔→闻庆当天往返 — 从板桥坐KTX-Eum约90分钟。一天只有8趟往返，先看时刻表。
  • 安东(#1053) — 从KTX-Eum安东站出发，河回村在西边，卧龙面在东边，同一天两边都去会很赶。
  • 浦项九龙浦 — 浦项站出发公交40分钟一班，末班18:30，只能安排午饭。
  • 昌宁、居昌(#1382) — 那两条线主要从大邱西部客运站出发，接在这一篇的大邱行程里更顺。

⚠ 3个常见失误

1. 从庆州站走去市区 — 庆州站是原来的新庆州站，在市区外，多算一趟公交或出租车。

2. 傍晚去九龙浦 — 浦项站发的九龙浦1路末班车是18:30，安排在午饭时段。

3. 把大庆线当KTX时刻表看 — 这是平时30分钟一班的通勤电车，倭馆、龟尾直接刷交通卡上车就行。

⚙ 3个常见问题

1. 这份名单是谁选的？ — 是韩国YouTube观众在评论区写下的地方饭馆整理表。KeyChinGu只确认了是否存在、地址、业种，没有排名。

2. 邑、面的饭馆能刷卡吗？ — 能刷卡的店多了，但现金、转账还是更顺畅的文化。现金准备参考#1301。

3. 大邱为什么占了九家？ — 整理表里大邱、庆北仅次于首尔排第二多，其中9家在大邱市区。大邱观光动线见#1001~1005。
