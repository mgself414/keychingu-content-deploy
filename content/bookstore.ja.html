⚠ 初めての外国人がよくやる3つのミス

1. すべての大型チェーンが英語書籍を豊富に揃えていると思い込む

キョボ (교보)・ヨンプン (영풍)・アラジン (알라딘) には英語コーナーがあるがメインは韓国語。英語専門コレクションは イテウォン ブックス (이태원 북스) / セファ (세화) / ストレージ (스토리지) の3店が圧倒的。一般チェーンの英語コーナーはベストセラー中心のため、ニッチ・古本・写真集は物足りないことも。

2. 定休日を確認せず行って空振り

セファ エイゴショテン (세화 영어서점) は 金曜定休 (稀)、イテウォン ブックス (이태원 북스) は 水曜定休、チェクポゴ (책보고) は 月曜定休、テオショジョム (대오서점) は不定休。営業時間 + 定休日の両方を必ず確認。

3. ピョルマダン ドソグァン (별마당도서관) を「貸し出し図書館」と勘違い

入場無料だが 貸し出し不可、閲覧のみ。写真撮影は自由だが書籍を店外に持ち出し不可。インスタ映えスポット + 30分〜1時間の休憩用途として活用。

韓国の書店風景

ソウルには230万冊フラッグシップ (キョボ (교보)) から、50年の英語古本店 (イテウォン ブックス (이태원 북스))、1953年の老舗 (テオショジョム (대오서점))、13m本棚のインスタホットスポット (ピョルマダン (별마당))、コピーライターがキュレーションするセレクト本 (チェイナ チェクパン (최인아 책방)) まで — 単一カテゴリーに4つのトーンが共存する。

外国人観光客は (a) 韓国語入門書・翻訳小説を買う、(b) 英語の古本でコスパよく揃える、(c) 写真集・アートブックを狙う、(d) インスタ映え・観光コースのスポットとして立ち寄る — 4つの目的を事前に決めておくと動線が効率的になる。

4軸マッピング

  • ① 大型チェーン — 韓国書籍入門: キョボムンゴ (교보문고)・ヨンプンムンゴ (영풍문고)・アラジン カンナム (알라딘 강남)。韓国語ベストセラー・旅行書・翻訳小説を最も幅広く。
  • ② 英語専門 — 英語書籍の宝探し: イテウォン ブックス (이태원 북스)・セファ エイゴショテン (세화 영어서점)・ストレージ ブックアンドフィルム (스토리지 북앤필름)。英語比率80%以上、ニッチ・写真集・アートブックも含む。
  • ③ 老舗・キュレーション — 時間・こだわり: テオショジョム (대오서점)・テンクスブックス (땡스북스)・チェイナ チェクパン (최인아 책방)。1953年の老舗からキュレーターセレクト本・ギャラリー・コピーライターキュレーションまで。
  • ④ ランドマーク・体験 — 写真・コース: ピョルマダン ドソグァン (별마당도서관)・チェクポゴ (책보고)・アークアンドブック (아크앤북)・ハニャンムンゴ (한양문고)。インスタ映えスポット + 大型ショッピングモールと組み合わせ。

① 大型チェーン — 韓国書籍入門 (3店)

キョボムンゴ クァンファムン (교보문고 광화문)

韓国最大の書店チェーン キョボムンゴ (교보문고) のフラッグシップ。クァンファムン (광화문) 広場隣のキョボ生命ビル地下1階、9,000㎡規模・230万冊。韓国語ベストセラー・人文・旅行・漫画の全カテゴリー + 英語・中国語・日本語の外国書コーナー別途。店内スターバックス + 休憩スペース充実。クァンファムン観光後にひと休みするのにも最適。

  • 住所: チョンノ区 チョンノ (종로) 1, B1F (クァンファムン (광화문))
  • 営業: 毎日 09:30–22:00
  • シグネチャー: 230万冊 + 外国書4言語 + スターバックス
  • おすすめ理由: クァンファムン (광화문)・キョンボックン (경복궁) コースに自然に組み込める。韓国語入門書 + 英語ベストセラーを一か所で解決。

ヨンプンムンゴ チョンノ ホンジョム (영풍문고 종로 본점)

キョボ (교보) に次ぐ韓国第2位のチェーン。チョンゲチョン (청계천) 沿いのチョンノ本店は 10,600㎡・35万冊。B1書籍・B2「スタイリッシュ ギフトモール」(文具・電子機器・ギフト・ブランドショップ)。デジタル検索キオスク・イベントスペース完備。本 + ライフスタイルギフトをまとめて買いたい動線にぴったり。

  • 住所: チョンノ区 チョンゲチョンロ (청계천로) 41 (チョンノ本店 (종로 본점))
  • 営業: 毎日 10:00–22:00
  • シグネチャー: 35万冊 + B2ライフスタイルギフトモール
  • おすすめ理由: チョンゲチョン (청계천) 散策 + 本+おみやげを一度に。キョボ (교보) より気軽なコース。

アラジン チュンゴ カンナムジョム (알라딘 중고 강남점)

韓国最大の古本チェーン。カンナムデロ (강남대로) 沿い地下1階の ユニークな店舗デザイン + 幅広いコレクション。韓国語古本中心だが英語書籍・CD・文具も扱う。本代を抑えたいバックパッカー・長期滞在者に最適。

  • 住所: ソチョ区 カンナムデロ (강남대로) 381, 地下1階 (カンナム (강남))
  • 営業: 毎日 09:30–22:00
  • シグネチャー: 韓国語古本 + 英語一部 + コスパ
  • おすすめ理由: カンナム駅 (강남역) 徒歩5分。本代を抑えたいバックパッカーにおすすめ。

② 英語専門 — 英語書籍の宝探し (3店)

イテウォン ブックス (이태원 북스) (旧 Itaewon Foreign Bookstore)

ソウルで最も歴史のある英語専門古本店。50年以上の歴史。整理されていない本の山の中での トレジャーハント — クラシック・ノンフィクション・ファンタジー・歴史・アートブックまで幅広いカテゴリー。価格帯も多様 (₩3,000〜)。

  • 住所: ヨンサン区 ノクサピョンデロ (녹사평대로) 208, 1階 (イテウォン (이태원))
  • 営業: 月・金・土 11:00–19:30 / 火・木・日 14:00–19:30 / 水曜定休
  • シグネチャー: 50年英語専門 + トレジャーハント
  • おすすめ理由: イテウォン (이태원) 外国人エリアの中心。英語古本の価格帯が最も多様。

セファ エイゴショテン (세화 영어서점) (Sehwa's English Bookstore)

キルム駅 (길음역) 近くのミニマル英語専門書店。セリフフォントのサイン + 観葉植物インテリア。新刊・古本英語書籍 + 韓国小説の英語翻訳本キュレーションが強み。親切な女性オーナーのもと、リピーターの外国人訪問客多数。

  • 住所: ソンブク区 サミャンロ (삼양로) 15-2 (キルム (길음))
  • 営業: 月〜木・土 11:00–21:00 / 日 13:00–21:00 / 金曜定休
  • シグネチャー: 韓国小説英語翻訳本キュレーション
  • おすすめ理由: ハンガンジン (한강진)・イテウォン (이태원) 以外のセカンドストップ英語書店。下町の雰囲気 + オーナーのおすすめ。

ストレージ ブックアンドフィルム (스토리지 북앤필름) (Storage Book and Film)

イテウォン (이태원)・ハンナムドン (한남동) の路地に隠れた 写真集・アートブック専門店。国内外の写真家・イラストレーターの書籍中心。小さな店舗ながらニッチなコレクションの深さが際立つ。

  • 住所: ヨンサン区 ハンナムドン (한남동) 一帯 (イテウォン (이태원)・ハンナム (한남))
  • 営業: 火〜日 12:00–20:00 / 月曜定休 (シーズンにより変動)
  • シグネチャー: 写真集・アートブックのニッチキュレーション
  • おすすめ理由: イテウォン ブックス (이태원 북스) から徒歩10分。英語書籍コース締めくくり + 写真集・イラスト本ハント。

③ 老舗・キュレーション — 時間・こだわり (3店)

テオショジョム (대오서점) (Daeo Bookstore)

1953年創業、韓国最古の書店のひとつ。チャハムンロ 7キル (자하문로 7길) のハノク (한옥) 路地の中。古い韓国小説・詩集・古本中心。小さなハノク (한옥) の佇まいで インスタ映えスポットとしても人気。K-ドラマ・映画のロケ地になることも。

  • 住所: チョンノ区 チャハムンロ 7キル (자하문로 7길) 55 (ソチョン (서촌))
  • 営業: 不定期営業 (通常平日午前〜午後、休業多め — 事前確認推奨)
  • シグネチャー: 70年老舗 + ハノク (한옥) 路地
  • おすすめ理由: ソチョン (서촌)・キョンボックン (경복궁) コース + 時が止まったような韓国書店の雰囲気。写真・散策におすすめ。

テンクスブックス (땡스북스) (THANKS BOOKS)

ホンデ (홍대) ヤンファロ 6キル (양화로 6길) の路地。書店+カフェ+ギャラリーの3-in-1。1階韓国語書籍・雑誌 (デザイン・アート中心)、2階ギャラリー・セミナースペース。各書籍にスタッフが手書きメモを添付 — キュレーションの魅力が抜群。

  • 住所: マポ区 ヤンファロ 6キル (양화로 6길) 57-6 (ホンデ (홍대))
  • 営業: 毎日 12:00–21:00
  • シグネチャー: 手書きメモキュレーション + デザイン・アートセレクト
  • おすすめ理由: ホンデ (홍대) デザインスポット散策 + キュレーターによる本の紹介を文章で読む楽しさ。

チェイナ チェクパン (최인아 책방) (Choi Ina's Bookshop)

サムソンドン (삼성동)・ソルルン駅 (선릉역) 近く。広告コピーライター出身のチェイナ (최인아) 代表がキュレーションするセレクトブック。本+カフェの融合。ビジネス・人文・エッセイ中心。店内の音楽もキュレーション。

  • 住所: カンナム区 ソルルンロ (선릉로) 521 (ソルルン (선릉)/サムソン (삼성))
  • 営業: 毎日 11:00–22:00 (シーズンにより変動)
  • シグネチャー: コピーライターキュレーション + 音楽キュレーション
  • おすすめ理由: ソルルン (선릉)・コエックス (코엑스) コース + 韓国広告/マーケティングのインサイトに興味があるビジネストラベラーに。

⚙ FAQ 8選

Q1. 英語書籍だけ狙うなら、どこから?

イテウォン ブックス (이태원 북스) → ストレージ ブックアンドフィルム (스토리지 북앤필름) 徒歩10分コース。セファ エイゴショテン (세화 영어서점) はキルム (길음) (独立動線)。キョボ (교보)・ヨンプン (영풍)・アラジン (알라딘) はベストセラー中心のためニッチ・古本英語書籍は手薄。

Q2. 韓国語入門書 / 韓国語学習書は?

キョボムンゴ クァンファムン (교보문고 광화문) B1外国語学習コーナー、またはヨンプンムンゴ チョンノ ホンジョム (영풍문고 종로 본점)。K-pop・ドラマ関連の英語ガイドも豊富。韓国語単語帳は₩10,000前後。

Q3. 写真集・アートブックは?

ストレージ ブックアンドフィルム (스토리지 북앤필름) (イテウォン (이태원)) → テンクスブックス (땡스북스) (ホンデ (홍대) デザイン・アート) の2店が核心。ピョルマダン ドソグァン (별마당도서관) もファッション・アート雑誌が豊富だが、購入不可・閲覧のみ。

Q4. インスタ映えならどこ?

ピョルマダン ドソグァン (별마당도서관) (13m本棚) → テオショジョム (대오서점) (ハノク (한옥) 路地) → チェクポゴ (책보고) (コンテナ) — Top 3。ピョルマダン (별마당) は無料、テオ (대오) は撮影時にオーナーへ一声、チェクポゴ (책보고) は自由。

Q5. 定休日に注意が必要な店は?

  • セファ エイゴショテン (세화 영어서점): 金曜 定休
  • イテウォン ブックス (이태원 북스): 水曜 定休
  • チェクポゴ (책보고): 月曜 定休
  • ストレージ ブックアンドフィルム (스토리지 북앤필름): 月曜 定休 (シーズンにより変動)
  • テオショジョム (대오서점): 不定休 (訪問前にインスタ・電話で確認)

Q6. K-pop・ドラマ関連の英語グッズは?

キョボムンゴ クァンファムン (교보문고 광화문) B1 + ヨンプンムンゴ チョンノ (영풍문고 종로) B2ギフトモール。アークアンドブック (아크앤북) もライフスタイルグッズが充実。K-popフォトブックには英語キャプション一部あり。

Q7. 価格コスパは?

古本 = アラジン カンナム (알라딘 강남) / イテウォン ブックス (이태원 북스) / チェクポゴ (책보고)。新刊 = キョボムンゴ (교보문고) (会員割引5%) / ヨンプンムンゴ (영풍문고) (10%台割引イベント頻繁)。外国書は約30%割高 (輸入原価)。

Q8. 車椅子・ベビーカーのアクセスは?

キョボ (교보)・ヨンプン (영풍)・ピョルマダン (별마당)・アークアンドブック (아크앤북)・ハニャンムンゴ (한양문고) はエレベーター・フラットな動線あり。テオショジョム (대오서점)・セファ (세화)・イテウォン ブックス (이태원 북스) は狭い路地・階段でアクセス困難。
