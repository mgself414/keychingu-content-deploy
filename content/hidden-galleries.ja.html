サブタイトル: 国際ギャラリー 月~土 10~18時・日 10~17時 / PKM 火~日 10~18時 / アラリオ ソウル 火~土 11~18時 / ペース・リーマン・マーピン・タデウス・ロパック 漢南 火~土 / ペロタン・ホワイトキューブは清潭 島山公園 / ミュージアムハンミ三清 15,000ウォン・最終水曜無料 / ピクニックは中区 — 2026-10-08 時点の各ギャラリー公式サイト基準。商業ギャラリーはほとんどが無料ですが、公式の表記はありません

🎯 このガイドの使い方

ソウルの大きな美術館(#350)と違い、商業ギャラリーは展示の入れ替え中は閉まり、日・月曜に休む店が多いです。そのためこのガイドでは、2026-10-08 に各ギャラリーの公式サイトで確認した営業時間・休館日・住所・現在の展示だけを載せ、公式にない値(入場料・最寄り駅)は「未掲示」としています。以前のガイドにあった「すべて無料」は誤りでした。ミュージアムハンミは15,000ウォンで、大林美術館 (Daelim Museum / 대림미술관)・ディミュージアム (D Museum / 디뮤지엄)・グラウンドシーソー (Ground Seesaw / 그라운드시소) は有料の展示スペースです。地域も訂正しました。ペロタン ソウル (Perrotin Seoul / 페로탕 서울) と ホワイトキューブ ソウル (White Cube Seoul / 화이트큐브 서울) は漢南ではなく清潭 島山公園 (Cheongdam Dosan Park / 청담 도산공원)、グラッドストーン ソウル (Gladstone Gallery Seoul / 글래드스톤 서울) は漢南洞 (Hannam-dong / 한남동)、ピクニック (piknic / 피크닉) は中区の会賢 (Hoehyeon / 회현)です。学古斎 (Hakgojae / 학고재) はサイトが開かないため外しました。

⚠ よくある失敗5つ

1. 日・月曜のギャラリーめぐり — 商業ギャラリーの大半は休館です。国際ギャラリー(日曜は17時まで)とPKM(日曜も開館)だけが例外です。

2. ハングルの日 (Hangeulnal / 한글날) の漢南 (10/9) — ペース・エスター・シッパーは休館です。

3. 「全部無料」と思い込む — ミュージアムハンミは15,000ウォン、大林美術館・ディミュージアム・グラウンドシーソーは有料です。

4. ペロタン・ホワイトキューブを漢南で探す — 清潭 島山公園にあります。

5. 大林美術館・ピクニックの展示を期待する — 10/8 時点では準備中です。公式で確認してから行きましょう。

⚙ FAQ 6

1. 1日に何カ所回れますか? — 三清の5カ所は歩いて半日。漢南の4カ所は梨泰院路沿いでもう半日です。

2. 無料ですか? — 商業ギャラリーは通常無料ですが、公式の表記はありません。ミュージアムハンミは有料です。

3. 10月に必ず見たい展示は? — 国際ギャラリーの朴栖甫(~10/18) · アラリオのキム・インベ(~10/24) · ロパックのバゼリッツ(~11/14) · ミュージアムハンミのロジャー・バレン(10/16~)。

4. 日曜日は? — 国際ギャラリー(~17時)とPKMが開いています。ほかは休みです。

5. 英語は通じますか? — 海外系ギャラリー(ペース・ロパック・リーマン・マーピン・ペロタン・ホワイトキューブ・エスター・シッパー)は、英語サイトと英語対応が基本です。公式の表記はありません。

6. 学古斎は? — サイトに接続できないため、今回は外しました。
