首尔交通·导航完全指南 — 地铁·公交·出租车·App 全搞定

> 韩国的交通并不复杂。一份指南，让首尔尽在掌握。

英语/中文 主要地铁站及 App 均支持

费用 便利 vs 性价比自选 (出租车 = 贵，地铁 = 实惠)

Part 1：交通卡 — T-money vs Climate Card

一定需要吗？ 必须。每次用现金买票会吃亏。

T-money (提莫尼 / 티머니)

项目 说明
购买地点 GS25 (GS二十五 / GS25)、CU (CU便利店 / CU)、Emart (易买得 / 이마트)、各大便利店
购买价格 卡费 ₩2,500 + 充值金额 (最低 ₩2,000)
使用场所 地铁·公交·出租车·便利店均可
充值方式 便利店收银台·地铁站自动充值机 (24小时)
退款 离境前可退余额 (手续费 ₩500)

优点： 全韩国通用，是最佳选择。

Climate Card (气候卡 / 클라이밋 카드)

项目 说明
购买地点 GS25 (GS二十五 / GS25)、CU (CU便利店 / CU) 等便利店 (与 T-money 相同)
购买价格 卡费 ₩2,500 + 充值金额 (最低 ₩2,000)
使用场所 地铁·公交·出租车·便利店 (与 T-money 相同)
特点 以环保理念 (可回收材质) 推出

与 T-money 的区别： 几乎没有。便利店里有哪张买哪张即可。

交通卡使用小贴士

1. 购买时： 说 "T-money 卡 주세요 (T-money ka-deu ju-se-yo)" 或直接用手指着

2. 充值： 在便利店收银台或车站自动充值机 (推荐自动机，更方便)

3. 使用： 乘地铁·公交时将卡贴近读卡器 (听到"哔"声即可)

4. 查询余额： 便利店收银台或 App

5. 退款： 在机场或出境前的兑换处办理 (退还卡内余额，扣除手续费)

Part 2：地铁完全指南

首尔地铁基本信息

项目 说明
线路数 9 条主要线路 (1~9号线) + 支线
运营时间 基本为 05:30~午夜 (各线路略有不同)
深夜运营 无 (午夜~05:30 停运，请改乘深夜公交)
基本票价 ₩1,250 (10km 以内，约 6 RMB / 200 JPY)
附加费 超过 10km 每增加 100m 加收 ₩100
拥挤时段 工作日 08:00~09:00、17:00~18:00 最为拥挤

地铁站内设施

设施 说明
自动扶梯 左侧乘坐 (右侧留空，类似香港·日本的礼让文化)
卫生间 所有站均有 (部分需密码，通常免费)
便利店 GS25 (GS二十五 / GS25)·CU (CU便利店 / CU) (各站地下商业街)
咖啡厅 车站周边或地下商业街
问询处 各站均设有 (工作人员可用英语沟通)

地铁乘车完整流程

Step 1：查找目的地

方法 1：智能手机 App

  • 打开 Naver Map (네이버지도 / 네이버지도) 或 Kakao Map (카카오맵 / 카카오맵)
  • 输入"出发地 → 目的地"
  • 选择"公共交通"标签
  • 按推荐路线前行

方法 2：站内线路图

  • 在站内找大型地铁线路图
  • 确认当前站 (通常为红点标注)
  • 找到目的地
  • 确认所需线路

Step 2：进站

1. 找到闸机或自动检票机

2. 使用 T-money (提莫尼 / 티머니) 卡或购买一次性车票

3. 将卡贴近自动检票机 (听到"哔"声 = 正常)

4. 通过闸机

Step 3：前往站台

1. 跟随站台方向指示牌 (通常为向上箭头)

2. 确认"1号线方向"或"X方向"

3. 前往对应站台

Step 4：乘车

1. 在站台等候

2. 列车进站 (数字显示屏显示剩余时间)

3. 门开后上车 (先让下车乘客下车)

4. 抓紧扶手 (车厢晃动明显)

Step 5：下车

1. 确认站名 (车厢内数字显示屏 + 语音播报)

2. 到达目的地站时提前准备

3. 门开后下车

4. 确认"出口 1、2、3"后出站

Step 6：出站

1. 通过指示牌或手机地图确认出口

2. 乘扶梯或走楼梯

3. 通过闸机 (刷卡)

地铁换乘

在同一站换乘：

  • 通常可以换乘 (跟随指示牌)
  • 1小时内换乘无需额外付费

在不同站换乘：

  • 不可跨站换乘 (须在同一站内完成)

换乘时限：

  • 普通：1小时内 (无额外费用)
  • 超时：产生附加费

地铁实用小贴士

小贴士 说明
线路图太复杂 只信手机地图 App (更准确)
搞不清方向 找"Incheon (仁川 / 인천)"或"Myeongdong (明洞 / 명동)"方向标识
行程较长 1号线 40 分钟以上、2号线 60 分钟以上 (非常长)
行李多时 最末节车厢行李空间较大
女性专用车厢 工作日 20:00~22:00 指定 (乘车线有区分标识)
夜景推荐 乘2号线从 Gangnam (江南 / 강남) 至 Euljiro (乙支路 / 을지로) 区间欣赏夜景

Part 3：公交指南

公交类型

1. 普通公交 (蓝色)

项目 说明
票价 ₩1,250 (与地铁相同)
速度 较慢 (站点多)
推荐场景 短距离 + 风景好的路线

乘车方式：

  • 前门上车 + 刷卡
  • 后门下车

2. 座席公交 (红色/绿色，中央公交专用道)

项目 说明
票价 ₩1,450~2,500 (按距离计费)
速度 较快 (走中央公交专用道)
推荐场景 远距离 + 时间紧张时

特点：

  • 仅在道路中央专用车道行驶 (速度快)
  • 设有座椅，乘坐舒适 (普通公交可能需要站立)
  • 按距离收费

公交乘车流程

1. 在公交站等候：确认路线号

2. 公交到站：举手示意司机 (不举手司机可能不停车)

3. 上车：从前门上车

4. 刷卡：将 T-money (提莫尼 / 티머니) 卡贴近读卡器 (听到"哔"声)

5. 就座或抓紧扶手

6. 确认目的地：查看车辆前方数字显示屏上的站名

7. 准备下车：目的地站名出现时举手示意

8. 从后门下车：部分公交需再次刷卡

公交 App 查询方法

Naver Map (네이버지도 / 네이버지도) 或 Kakao Map (카카오맵 / 카카오맵)：

1. 输入公交站名称

2. 选择"公交"标签

3. 查看实时公交位置

4. 确认还有几站

5. 查看预计到站时间

Part 4：出租车 — 方便但价格较贵

出租车基本信息

项目 说明
起步价 ₩3,400 (基本 2km，约 16 RMB)
附加费 每 100m 加收 ₩100
时间费 堵车时每 35 秒加收 ₩100
深夜附加 00:00~04:00 加收 20%
总体费用 偏贵 (5km 约需 ₩15,000 以上，约 70 RMB)

出租车种类

种类 颜色 价格 特点
普通出租车 银色/黄色 基本价 最常见
模范出租车 黑色 贵约 20% 车况整洁，司机英语较好
大型出租车 灰色 贵约 50% 适合 4 人以上
打车 App 各色 浮动计费 Kakao T (카카오T / 카카오T)、Uber (优步)

乘坐出租车方法

路边拦车

1. 举手示意：向司机可见方向抬手

2. 出租车停车：司机看到后在停车线停靠

3. 告知目的地：用英语说或出示手机上的地址 (如听不懂可直接给司机看手机屏幕)

4. 上车：坐后排

5. 确认计价器：确认计价器已启动 (重要！)

6. 到达目的地：刷信用卡结算 (或付现金)

7. 小费：韩国没有给小费的习惯，找零请收好

通过打车 App 叫车

Kakao T (카카오T / 카카오T，最受欢迎)：

```

1. 安装 App 并登录

2. 输入"出发地" (自动定位当前位置)

3. 输入"目的地"

4. 点击"叫车"

5. 等待出租车到达

6. 手机上显示司机信息

7. 上车

8. 通过 App 结算 (绑定信用卡)

```

优点：

  • 可提前预估价格
  • 信用卡自动扣款 (无需现金)
  • 实时追踪出租车位置
  • 可查看司机信息

缺点：

  • 可能比计价器费用高 (浮动计费制)
  • 需要安装 App

出租车小贴士及注意事项

项目 说明
计价器 必须确认已启动。未启动则不要上车
找零 向司机索要找零 (韩国不需要给小费)
拒载 违法行为 (即使是短距离也必须搭载乘客)
刷卡支付 可使用信用卡 (司机会拿出 POS 机)
外国人注意 会英语的司机较少，最好在手机上显示地址给司机看
夜景游览 乘出租车沿汉江 (Han River / 한강) 周边主干道，可欣赏夜景

Part 5：导航 App — 完全指南

Naver Map vs Kakao Map

Naver Map (네이버지도 / 네이버지도)

优点：

  • 实时交通信息准确
  • 公共交通导航最为精准
  • 英语支持完善

缺点：

  • 在中国大陆无法正常访问
  • 部分小店信息较少

推荐对象： 大多数旅行者，尤其是乘地铁/公交时。

Kakao Map (카카오맵 / 카카오맵)

优点：

  • 在中国大陆可访问 (无需 VPN)
  • 餐厅·咖啡厅信息丰富
  • 可实时叫出租车 (联动 Kakao T / 카카오T)

缺点：

  • 英语支持相对较弱
  • 公共交通路线偶有不准确

推荐对象： 中国游客，以及需要大量餐厅信息时。

Naver Map 使用小贴士

```

1. 安装 App

2. 右上角"语言" → 切换为"English"

3. 在搜索栏输入"地区名"或"地址"

4. 选择"导航"

5. 选择交通方式 (地铁 / 公交 / 出租车 / 开车 / 自行车)

6. 点击"出发"

7. 实时导航开始

```

实时交通信息解读

Naver Map 界面：

显示 含义
绿色 交通畅通
黄色 轻微拥堵
红色 严重拥堵
灰色 无运行信息

中国游客专区：微信地图 (WeChat Map)

是什么？ 类似中国的百度地图·高德地图，内置于微信中。

优点：

  • 中国开发 (兼容性好)
  • 支持微信支付 (Wechat Pay)

缺点：

  • 韩国本地数据不足 (不推荐)

结论： Kakao Map (카카오맵 / 카카오맵) 是更好的替代选择。

Part 6：Ddareungi (首尔公共自行车 / 따릉이)

Ddareungi 是什么？

是什么？ 首尔的公共自行车系统，全市各处均设有租赁点。

项目 说明
租赁费 30 分钟内 ₩1,000 (约 5 RMB)，之后每 10 分钟加 ₩500
注册方式 通过 App (Ddareungi App / 따릉이 App) 或直接在租赁点注册
资格要求 需绑定信用卡 (押金概念)
特点 全首尔 1,400+ 个租赁点

Ddareungi 使用方法

1. 安装 App：下载"Ddareungi (따릉이)"App

2. 注册会员：绑定信用卡 (当天无法使用，需等待约 1 天)

3. 查找租赁点：在地图上确认租赁点位置

4. 取车：在 App 中输入自行车编号后解锁

5. 还车：将自行车插入租赁点空位 (自动上锁)

Part 7：前往机场完全指南

仁川机场 (Incheon Airport / 인천공항) → 首尔市区

交通方式 所需时间 价格 推荐度
机场铁路 60 分钟 ₩9,000 (~43 RMB) ⭐⭐⭐⭐
机场巴士 70~120 分钟 ₩10,000~15,000 ⭐⭐⭐⭐
豪华巴士 60~90 分钟 ₩25,000~35,000 ⭐⭐⭐
出租车 60~90 分钟 ₩70,000~100,000 (~480 RMB) ⭐

推荐组合：

  • 1~2人：机场铁路 (性价比高 + 速度快)
  • 3人以上：豪华巴士 (行李多时)
  • 入住特定酒店：机场巴士 (直达酒店)

机场铁路乘车方法

```

1. 抵达仁川机场 (Incheon Airport / 인천공항) → 跟随火车站指示牌

2. 购买机场铁路车票 (自动售票机或服务台，₩9,000)

3. 通过闸机 (出示车票)

4. 乘坐列车 (开往首尔站 Seoul Station / 서울역)

5. 到达首尔站 (所需约 60 分钟)

6. 换乘地铁 (首尔站连接 1·4 号线)

```

外国游客检查清单

```

[ ] 购买 T-money (提莫尼 / 티머니) 卡 (便利店)

[ ] 充值 (最少 ₩5,000)

[ ] 安装 Naver Map (네이버지도 / 네이버지도) 或 Kakao Map (카카오맵 / 카카오맵)

[ ] 手机设置韩语输入法 (用于搜索地址)

[ ] 收藏常去的地铁站·公交站

[ ] 拍下公交路线号 (以防搞错)

[ ] 提前用 App 确认出租车费用

[ ] 提前确认深夜交通信息

[ ] 提前确定前往机场的交通方式

```
