首尔交通·导航完全指南 — 地铁·公交·出租车·APP一次搞定

韩国交通并不难。有这一份指南，首尔就在你的掌握之中。

一图速览

项目 信息
公共交通 地铁·公交·出租车都很便宜（单程基本票价1,250~2,500韩元）
交通卡 T-money（티머니）或 Climate Card（클라이밋 카드）（便利店有售）
主要APP Naver地图 (Naver Map/네이버지도)、Kakao地图 (Kakao Map/카카오맵)、首尔交通公社 (Seoul Metro/서울교통공사) 官方APP

费用 便利 vs 性价比自行取舍（出租车 = 贵，地铁 = 便宜）

Part 1: 交通卡 — T-money vs Climate Card

真的需要吗？ 必备。每次用现金买票只会吃亏。

T-money（티머니）

项目 说明
购买地点 GS25、CU、易买得 (E-mart/이마트)，各家便利店均可
购买价格 卡费2,500韩元 + 充值余额（最低2,000韩元）
使用范围 地铁·公交·出租车·便利店均可
充值 便利店·车站自动充值机（24小时）
退款 出境前可退余额（手续费500韩元）

优点： 全韩国通用。最佳选择。

Climate Card（클라이밋 카드）

项目 说明
购买地点 GS25、CU等便利店（与T-money相同）
购买价格 卡费2,500韩元 + 余额（最低2,000韩元）
使用范围 地铁·公交·出租车·便利店（与T-money相同）
特点 出于环保理念（可回收再利用）而推出

与T-money的区别： 几乎没有。便利店里看到哪种买哪种都行。

交通卡使用小贴士

1. 购买时： 说"T-money 카드 주세요"（请给我一张T-money卡），或直接用手指一指

2. 充值： 便利店收银台或车站的自动充值机（自动充值机更方便）

3. 使用： 乘坐地铁·公交时把卡贴到读卡器上（"哔"一声）

4. 查询余额： 便利店收银台或APP

5. 退款： 在机场或出境前的换钱所办理（退还卡内余额 - 手续费）

Part 2: 地铁完全指南

首尔地铁基本信息

项目 说明
线路数量 9条主要线路（1~9号线）+ 支线
运营时间 基本为05:30~午夜（各线路略有不同）
深夜运营 无（午夜~05:30停运，请利用深夜公交）
基本票价 1,250韩元（10km以内）
加收费用 超过10km后按每段加收100韩元
拥挤时段 工作日上午8~9点、下午5~6点最挤

地铁站内设施

设施 说明
自动扶梯 靠左侧站立通行（右侧留空是当地习惯）
洗手间 每个站都有（个别需要密码，通常免费）
便利店 GS25·CU（各站地下商街均有）
咖啡店 车站周边或地下商街
咨询处 每个站都有（工作人员会讲英语）

地铁乘坐完整流程

Step 1: 查找目的地

方法1：智能手机APP

  • 打开Naver地图或Kakao地图
  • 输入"出发地 → 目的地"
  • 选择"公共交通"标签
  • 按推荐路线走即可

方法2：车站线路图

  • 在站内找到大幅地铁线路图
  • 确认当前所在站（通常是红点标记）
  • 确认目的地
  • 找到需要乘坐的线路

Step 2: 进站

1. 找到检票口或自动检票机

2. 使用T-money卡，或购买一次性交通卡

3. 把卡贴到自动检票机上（"哔"一声 = 正常）

4. 通过闸机

Step 3: 前往站台

1. 跟着站台方向指示牌走（通常是向上的箭头）

2. 确认"1号线方向"或"2号方向"等指示

3. 前往对应方向的站台

Step 4: 乘车

1. 在站台等候

2. 列车进站（电子显示屏会显示剩余到站时间）

3. 车门打开后上车（先下后上）

4. 抓好扶手（晃动较大）

Step 5: 下车

1. 确认站名（车内电子显示屏 + 语音报站）

2. 快到目的站时提前做好准备

3. 车门打开后下车

4. 确认"出口1、2、3"后出站

Step 6: 出站

1. 通过导览图或手机地图确认出口

2. 乘坐自动扶梯或走楼梯

3. 通过检票口（刷卡）

地铁换乘

在同一站换乘时：

  • 通常可行（跟着指示牌走）
  • 无额外费用（1小时内换乘）

在不同站换乘时：

  • 不可行（只能在同一站内换乘）

换乘时间限制：

  • 一般：1小时以内（无额外费用）
  • 超时：产生额外费用

地铁实用小贴士

贴士 说明
线路图看不懂 只信手机地图APP（更准确）
分不清方向 找"Incheon"（仁川）或"Myeongdong"（明洞/명동）等方向指示
乘车时间长 1号线40分钟+、2号线60分钟+（非常久）
行李多时 首尾车厢的行李空间更大
女性专用车厢 工作日晚8~10点设置（乘车位置有区分标识）
夜景好去处 推荐乘2号线，江南 (Gangnam/강남)~乙支路 (Euljiro/을지로) 区间

Part 3: 公交指南

公交种类

1. 普通公交（蓝色）

项目 说明
票价 1,250韩元（与地铁相同）
速度 慢（站点多）
推荐 短途 + 沿途风景好的路线

乘车方式：

  • 前门上车 + 刷卡
  • 后门下车

2. 座席公交（红/绿色，走公交专用中央车道）

项目 说明
票价 1,450~2,500韩元（按距离计费）
速度 快（利用中央公交专用道）
推荐 长途 + 赶时间的时候

特点：

  • 只在道路中央的专用车道行驶（快）
  • 有座位，舒适（普通公交可能要站着）
  • 票价按距离浮动

公交乘坐流程

1. 在公交站等候：确认车牌号码

2. 公交进站：举手向司机示意（不举手可能不停车）

3. 上车：从前门上车

4. 刷卡：把T-money卡贴到读卡器上（"哔"一声）

5. 找座位或抓好扶手

6. 确认目的地：在车头电子显示屏上确认站名

7. 下车准备：显示屏出现目的站时按铃或示意"要下车"

8. 从后门下车：再次刷卡（部分公交需要）

用APP查公交

Naver地图或Kakao地图：

1. 输入公交站名

2. 选择"公交"标签

3. 查看公交实时位置

4. 确认还剩几站

5. 确认预计到达时间

Part 4: 出租车 — 方便但贵

出租车基本信息

项目 说明
起步价 3,400韩元（起步2km）
里程费 每100m加收100韩元
时间费 每35秒加收100韩元（堵车时）
深夜加价 午夜~凌晨4点 +20%
总体费用 很贵（5km车程要15,000韩元+）

出租车种类

种类 颜色 价格 特点
普通出租车 银色/黄色 基准价 最常见
模范出租车 黑色 贵+20% 车况干净，司机会英语
大型出租车 灰色 贵+50% 适合4人以上乘客
打车APP 不限 浮动 Kakao T (카카오T)、Uber（价格浮动）

出租车乘坐方法

路边扬招

1. 举手示意：把手举起来让司机看到

2. 出租车停靠：司机看到后会在停车线停下

3. 说出目的地：用英语或说地址（听不懂就把手机上的地址给司机看）

4. 上车：坐后排座位

5. 确认计价：确认计价器已打开（重要！）

6. 抵达目的地：用信用卡结账（或现金）

7. 小费：韩国没有小费文化（找零也要收好）

用打车APP叫车

Kakao T（最受欢迎）：

```

1. 安装APP并登录

2. 输入"出发地"（自动定位当前位置）

3. 输入"目的地"

4. 点击"呼叫出租车"

5. 等待出租车到达

6. 手机上显示司机信息

7. 上车

8. 在APP内结算（绑定银行卡）

```

优点：

  • 可提前预估价格
  • 信用卡自动扣款（无需现金）
  • 实时追踪出租车位置
  • 可查看司机信息

缺点：

  • 可能比里程计费贵（浮动计价制）
  • 需要安装APP

出租车贴士 & 注意事项

项目 说明
计价器 务必确认已打开。没开就不要上车
找零 司机询问时记得拿好（在韩国不用给小费）
拒载 属于违法（即使是短途司机也必须载客）
刷卡结账 可用信用卡（司机会拿出POS机）
外国人 会英语的司机不多。把地址写在手机上给司机看是最稳妥的
夜景兜风 沿干线道路（汉江 (Han River/한강) 一带）乘出租车看夜景很不错

Part 5: 导航APP — 完全指南

Naver地图 vs Kakao地图

Naver地图

优点：

  • 实时路况信息准确
  • 公共交通路线规划最精准
  • 英语支持完善

缺点：

  • 在中国境内无法访问
  • 部分小店信息不足

推荐人群： 大多数游客。尤其是常坐地铁/公交的人。

Kakao地图

优点：

  • 在中国境内可以访问（无需VPN）
  • 餐厅·咖啡店信息丰富
  • 可实时叫出租车（与Kakao T联动）

缺点：

  • 英语支持相对较弱
  • 公共交通路线偶有不准

推荐人群： 中国游客，以及需要大量餐厅信息的人

Naver地图使用步骤

```

1. 安装APP并完成韩语环境设置

2. 右上角"语言" → 改为"English"

3. 在搜索栏输入"地名"或"地址"

4. 选择"路线"

5. 选择交通方式（地铁 / 公交 / 出租车 / 驾车 / 骑行）

6. 点击"出发"按钮

7. 开始实时导航

```

看懂实时路况信息

Naver地图界面：

显示 含义
绿色 交通顺畅
黄色 轻微拥堵
红色 严重拥堵
灰色 无路况信息

中国游客专属：微信地图 (WeChat Map)

是什么？ 类似中国的百度地图·高德地图。内置在微信里。

优点：

  • 中国开发（兼容性好）
  • 与微信支付联动

缺点：

  • 韩国数据不足（不推荐）

结论： Kakao地图才是更好的备选。

Part 6: Ttareungyi（따릉이）— 公共自行车

什么是Ttareungyi？

是什么？ 首尔的公共自行车系统。全城遍布租赁点。

项目 说明
租金 30分钟以内1,000韩元（此后每10分钟加收500韩元）
注册 通过APP（따릉이APP）或在租赁点直接注册
条件 需要信用卡（相当于押金）
特点 首尔各处共有1,400+个租赁点

Ttareungyi使用方法

1. 安装APP：下载"따릉이"APP

2. 注册会员：绑定信用卡（当天申请当天不可用，需1天）

3. 查找租赁点：在地图上确认租赁点位置

4. 租车：在APP内输入自行车编号解锁

5. 还车：把自行车插回租赁点的空位（自动上锁）

Part 7: 机场往返完全指南

仁川机场 (Incheon Airport/인천공항) → 首尔市区

交通方式 所需时间 价格 推荐度
机场铁路 60分钟 9,000韩元 ⭐⭐⭐⭐
机场巴士 70~120分钟 10,000~15,000韩元 ⭐⭐⭐⭐
机场大巴（Limousine） 60~90分钟 25,000~35,000韩元 ⭐⭐⭐
出租车 60~90分钟 70,000~100,000韩元 ⭐

推荐组合：

  • 独自或2人：机场铁路（性价比 + 快）
  • 3人以上：机场大巴（行李多的时候）
  • 入住指定酒店时：机场巴士（直达酒店）

机场铁路 (AREX/공항철도) 使用方法

```

1. 抵达仁川机场 → 跟着火车站指示牌走

2. 购买机场铁路车票（自动售票机或人工柜台，9,000韩元）

3. 通过闸机（出示车票）

4. 上车（开往首尔站 (Seoul Station/서울역) 或沿机场铁路各站方向）

5. 抵达首尔站（约60分钟）

6. 换乘地铁（首尔站可换乘1·4号线）

```

外国游客行前清单

```

[ ] 购买T-money卡（便利店）

[ ] 充值（最低5,000韩元）

[ ] 安装Naver地图或Kakao地图

[ ] 在手机上设置韩语输入法（用于搜索地址）

[ ] 收藏常去的车站·公交站

[ ] 给公交车牌拍照留存（以防搞混）

[ ] 提前查好出租车费用（用APP）

[ ] 提前了解深夜交通信息

[ ] 提前确定机场往返方式

```
