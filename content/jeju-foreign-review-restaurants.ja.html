済州の食堂14軒 — 外国人レビューが先に残った店だけ

サブタイトル: 黒豚・海女・太刀魚の刺身(#1060)、地元の人の名店と五日市場(#1348)、地元の人の名店 ⑦(#1388)に続く軸——空港近くのオゴムタン、旧市街の麺、ソンダンの窯焼きピザ、ウドの海女の食卓、ジュンムンの太刀魚の煮付け。Naverマップに外国語レビューが先に残った食堂だけを14軒選び、4エリアにまとめて宿泊エリア別に選びやすくした。黒豚の選び方は#1060、五日市場の使い方は#1348

ISSUE 06 · #1437 · 2026-11-23 · 済州の食堂

🎯 なぜ「三言語レビュー」が基準なのか

店を選んだ済州の食べ物編はすでに三本あります——黒豚・海女・太刀魚の刺身(#1060)、地元の人の名店と五日市場(#1348)、地元の人の名店 ⑦のチェジュ・イムジェ・タムナカンジャンケジャン・ミヨンイネ(#1388)。今回は、その三本に出てこなかった店だけを集めました。黒豚・太刀魚・海女の食卓のようにメニューの種類は#1060と重なっても、店は重なりません。

選定基準はひとつだけです——Naverマップに英語・日本語・中国語のレビューがそろって残る食堂。韓国人の人気ランキングではなく、すでに外国人が訪れて三言語で足跡を残した場所こそ、次の外国人旅行者にとって馴染みやすい選択だという判断です。レビュー数は2026-11時点で、店ごとに記載しました。例外はひとつ——キムゴギ (Kim Gogi / 김고기)は日本語レビューがありませんが(4・0・1)、西帰浦市内の夕食向け焼肉店で、メニューが1人前のグラム単位で登録されているため入れました。

⚠ 表記の原則：営業時間・定休日・メニュー価格は、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した値です(2026-11-23確認)。価格は代表メニュー1人前・1杯の値段を記載し、2人用メニューや1枚単位のメニューはその基準も併記しました。メニュー価格の登録が2年以上前の店は「カカオマップで当日確認」としました。食事面のヒントはメニュー名から読み取れるものだけを書きました——材料・アレルギーは注文前にスタッフに確認してください。済州は広いので、エリア間の移動は車かバスです。この回では移動時間を書きません——その日にカカオマップの道案内で確認してください。

① 空港周辺・新済州 — 3軒

済州空港周辺と新済州側です。到着日の最初の食事か、出発日の最後の食事をここで済ませるのに向いています。3軒とも午前9時前後に開きます。

  • ナムギョンオゴムタン — 魚で煮込んだオゴムタン・オゲジャンの店です。ナムギョンオゴムタン ₩18,000、ナムギョンオゲジャン ₩18,000、スンサルオクトムクイ (Sunsal Okdom Gui / 순살옥돔구이) ₩20,000。外国語レビュー合計が22件で、この回で最も多いです(EN・JA・ZH集計 5・3・3)。毎日 08:00~21:00、ブレイクタイム 15:00~17:00、定休日なし。済州市 (Jeju-si / 제주시)のヨンサム路96 (Yeonsam-ro 96 / 연삼로 96)。食事面のヒント：スープと焼き物は魚、黒豚のチャンスユク (Chan Suyuk / 찬수육) ₩22,000は豚肉です。生ものメニューはありません。
  • オジャングン — オクトムムグクと定食の膳を出す済州郷土料理店です。オクトムムグク ₩18,000、済州コサリビビンバ (Jeju Gosari Bibimbap / 제주고사리비빔밥) ₩13,000、ウドソンゲアルビビンバ (Udo Seongge-al Bibimbap / 우도성게알비빔밥) ₩23,000。大人数なら3~4人用の膳(₩120,000~₩220,000)もあります——サドンハンサン (Sadon Hansang / 사돈한상)(刺身盛り合わせ)・ヒャントハンサン (Hyangto Hansang / 향토한상)(サバの刺身)には刺身が入ります。毎日 09:00~21:00。済州市のシンデ路72 (Sindae-ro 72 / 신대로 72)。食事面のヒント：オクトム(アマダイ)・ウニの卵は海鮮、トンベゴギ (Dombegogi / 돔베고기)セット ₩45,000は豚肉です。生ものを避けるならオクトムムグクかトンベゴギセットのほうで、ソンゲアルビビンバのウニが生かどうかはスタッフに聞いてください。肉のない名前のメニューはコサリビビンバですが、だしやトッピングの材料も聞いてください。
  • チャンモシクタク — 石鍋ご飯にチゲを添える韓定食の店です。石鍋ご飯+チゲ ₩10,000、コンドゥレ (Gondeure / 곤드레)石鍋ご飯+チゲ ₩11,000、アワビ石鍋ご飯+チゲ ₩15,000、チャンモ定食 (Jangmo Jeongsik / 장모정식) ₩17,000——1人 ₩10,000~17,000。月~土 09:00~20:30、日曜定休。済州市のヨンシン路51 (Yeonsin-ro 51 / 연신로 51)。食事面のヒント：チャンモ定食(₩17,000)にはカンジャンケジャン (Ganjang Gejang / 간장게장)・アワビの醤油漬け・チェユクポックム (Jeyuk Bokkeum / 제육볶음)が一緒に出ます。カンジャンケジャンは生のカニを醤油に漬けた料理で、チェユクポックムは豚肉なので、生ものを避ける人や豚肉を食べない人は定食ではなく石鍋ご飯+チゲを選びましょう。コンドゥレ石鍋ご飯は山菜ご飯ですが、チゲのスープの材料は確認が必要です。

② 済州市の麺・クッパ — 3軒

済州市の麺・クッパの店です。クァンミョンシクタン・24時ククスフェグァンは旧市街の中、コンジュネククスは済州市の東のボンゲ洞 (Bonggae-dong / 봉개동)にあるので、地図アプリで位置を先に見てください。3軒とも1杯 ₩7,000~10,000です。

  • 24時ククスフェグァン — 名前は24時ですが、カカオマップの登録時間は06:30~23:40、火曜定休です。ミョルチグクス ₩7,000、コギグクス ₩8,000、スンデクッパ (Sundae Gukbap / 순대국밥) ₩8,000、サゴムモムグク (Sagol Momguk / 사골몸국) ₩8,000。06:30オープンはこの回の14軒で最も早く——早朝の散歩のあとの朝食や、遅い夜の一杯に向いています。済州市のナムソン路122-1 (Namseong-ro 122-1 / 남성로 122-1)。食事面のヒント：コギグクス・スンデ・豚皮は豚肉で、スープは煮干しと牛骨です。サゴムモムグクのモムグクは、ホンダワラ(モム)を豚のだしで煮込んだ済州のスープです。生ものメニューはありません。
  • クァンミョンシクタン — クッパ・スンデ・コギグクスを出す旧市街の老舗です。クッパ ₩9,000、コギグクス ₩9,000、ッタロクッパ (Ttaro Gukbap / 따로국밥) ₩10,000。外国語レビューは3件ですが、三言語が1件ずつバランスよく残っています(1・1・1)。月・火・木~日 11:00~18:00、水曜定休、夕方6時に閉まります。済州市のジュンアン路13ギル38 (Jungang-ro 13-gil 38 / 중앙로13길 38)。食事面のヒント：クッパ・スンデ・マクチャン (Makchang / 막창)など豚肉と内臓が中心なので、豚肉を食べない人には合いません。
  • コンジュネククス — コギグクスとモムグクの店です。コギグクス ₩8,500、ミョルチグクス ₩7,000、モムグク (Momguk / 몸국) ₩10,000、コンググクス (Kong Guksu / 콩국수) ₩10,000。火~日 09:00~20:00、ブレイクタイム 15:00~16:30、月曜定休。済州市のサムボン路353 (Sambong-ro 353 / 삼봉로 353)(ボンゲ洞)。食事面のヒント：コギグクスは豚肉です。モムグクはホンダワラ(モム)を豚のだしで煮込んだ済州のスープなので、豚肉を避けるなら外して選びましょう。ミョルチグクス・コンググクスのように肉のない名前のメニューも、だしは別に確認してください。

③ 東部 (クジャ・ソンサン・ウド) — 3軒

ソンサンイルチュルボン・ウド・ビジャリム側の行程に組み込むエリアです。3軒はソンダン・ソンサン・ウドに分かれているので、1日に全部入れるのではなく、その日に行く場所に合わせてひとつ選びます。3軒とも外国語レビューが13件以上で、三言語がそれぞれ4件以上残っています。

  • ドウボーイ — ソンダン (Songdang / 송당)のサワードウ窯焼きピザの店です。マルゲリータ (Margherita / 마르게리타) ₩23,000、プンギ (Pungi / 풍기) ₩28,000、ホワイトパイ (White Pie / 화이트파이) ₩29,000——ピザは1枚単位なので1人前の価格ではありません。ポレンタ (Polenta / 폴렌타) ₩15,000。木~日の 11:00~15:00だけ営業——月・火・水曜定休。 カカオマップのメニュー名が英語でも登録されています(BLUEBERRY, FENNEL & GINGER SODAなど)——この回で英語メニュー名を確認できた唯一の店です。外国語レビュー15件(5・5・5)。クジャ邑 (Gujwa-eup / 구좌읍)のビジャリム路2136 (Bijarim-ro 2136 / 비자림로 2136)。食事面のヒント：マルゲリータ・プンギ・ホウレンソウ&ゴマ (Spinach & Sesame / 시금치&참깨)のように肉の名前がないピザもありますが、トッピングの材料はスタッフに確認してください。店の紹介にシャルキュトリー (Charcuterie / 샤퀴테리)(食肉加工品——主に豚肉)が出てきます。生ものメニューはありません。
  • オンピョンパダハングルッ — ソンサン・オンピョン里 (Onpyeong-ri / 온평리)の海沿いにある海鮮・刺身の店です。クルパジョン ₩17,000、ソクファ (Seokhwa / 석화) ₩10,000、ブリの刺身 ₩20,000、海鮮盛り合わせ 小 ₩45,000・大 ₩65,000。刺身・盛り合わせは量と人数の基準が登録されていないので、注文のときに何人分の量か聞いてください。毎日 12:00~22:00、ブレイクタイム 15:30~17:00。ソンサン邑 (Seongsan-eup / 성산읍)のファンヘジャンソン路467 (Hwanhaejangseong-ro 467 / 환해장성로 467)。食事面のヒント：海鮮中心で、刺身・石花(カキ)は生ものです。海鮮盛り合わせにも刺身が入ることがあるので、構成を聞いてください。生ものを避けるならクルパジョンのほうを選びましょう。
  • ウドヘニョシクタン — ウド (Udo / 우도)の島内にある海女の海鮮の食卓です。ボマルバジラクカルグクス ₩15,000、ソラ粥 (Sora Juk / 소라죽) ₩15,000、ウニビビンバ (Seongge Bibimbap / 성게비빔밥) ₩20,000、ツノ付きサザエの刺身 (Ppulsora Hoe / 뿔소라회) ₩25,000(量は表記なし)。毎日 08:30~18:00——夕方6時閉店。ウド面 (Udo-myeon / 우도면)のウドヘアン路 440 (Udohaean-gil 440 / 우도해안길 440)。ウドは船で渡るので、ウド行きの船の時刻表を先に確認し、帰りの船の時間まで計算して昼食に合わせてください。ウドには名前の似た海女の家が複数あるので、住所で探しましょう。食事面のヒント：海鮮中心で、サザエ・アワビ・ホヤの刺身は生ものです。生ものを避けるならカルグクス・粥のほうです。

④ ソギポ・西部 — 5軒

  • トニラン (チェジュフッテジ本店) — ジュンムンセクタル洞 (Saektal-dong / 색달동)の黒豚焼きの店です。930スクソンフッテジクンゴギ (930 Sukseong Heuk Twaeji Geun Gogi / 930숙성흑돼지근고기) 500g(2人) ₩57,000、フンモクトンサル (Heuk Mokdeonsal / 흑목덜미살) 260g ₩28,000。焼き物に添えるボマルテンジャンットゥペギ (Bomal Doenjang Ttukbaegi / 보말된장뚝배기) ₩9,000、キムチマリグクス (Kimchi Mari Guksu / 김치말이국수) ₩7,000。毎日 11:00~01:00——この回の14軒で最も遅くまで営業しています。外国語レビュー15件(5・5・5)、カカオマップのレビューも1,909件残っています。西帰浦 (Seogwipo / 서귀포)のイルジュソ路953 (Iljuseo-ro 953 / 일주서로 953)——ソンサン店は別支店です。黒豚の部位・選び方は#1060。食事面のヒント：黒豚中心です。ボマル(海の巻貝)のテンジャン土鍋は海鮮。コサリメルビビンバ (Gosari Mel Bibimbap / 고사리멜비빔밥)・キムチマリグクスもありますが、材料はスタッフに確認してください。

  • ウンジョンイネ (ジュンムン本店) — ジュンムンの太刀魚・海鮮の石鍋ご飯の店です。スンサルカルチジョリム 1人 ₩12,000、チョンボクスンサルカルチジョリム (Jeonbok Sunsal Galchi Jorim / 전복순살갈치조림) 1人 ₩20,000、チョンボクトルソッパプ (Jeonbok Dolsot Bap / 전복돌솥밥) ₩15,000。大人数ならトンカルチグイ (Tong Galchi Gui / 통갈치구이)の膳(2人) ₩88,000。カカオマップにひとり飯のタグが付いています。毎日 09:00~22:00。西帰浦のチュンサンガンソ路726 (Jungsangan-seo-ro 726 / 중산간서로 726)(カカオマップの店名は「チェジュウンジョンイネ (Jeju Unjeongine / 제주운정이네)」)。食事面のヒント：カルチ・アワビ・オクトムなど海鮮中心で、生ものメニューはありません。
  • キムゴギ — 西帰浦市内ソホ洞 (Seoho-dong / 서호동)のサムギョプサルの店です。コッサムギョプ 200g ₩16,000、センデパムサムギョプ (Saeng Daepa Samgyeop / 생대패삼겹) 160g ₩16,000、トンハンジョンサル (Tong Hangjeongsal / 통항정살) 180g ₩19,000——メニューが1人前のグラム単位で登録されています——ひとりで注文できるかはスタッフに聞いてください。毎日 16:00~22:00、夜だけの営業です。西帰浦のシンドン路67ボンギル23 (Sindong-ro 67beon-gil 23 / 신동로67번길 23)。外国語レビューは4・0・1で日本語がありません。食事面のヒント：豚肉中心です。
  • パルンムル (ハンリム) — ハンリム・オンポ里 (Ongpo-ri / 옹포리)の海鮮・魚料理の店です。タクセウヘムルラミョン (Ttakseu Haemul Ramyeon / 딱새우해물라면)・チョンボクットゥペギ (Jeonbok Ttukbaegi / 전복뚝배기)・カルチジョリム・コドゥンオジョリム (Godeungeo Jorim / 고등어조림)・タクセウチム (Ttakseu Jjim / 딱새우찜)があります——メニュー価格は2024-11の登録値なので、現在の価格はカカオマップで当日確認してください。毎日 11:00~23:00。ハンリム邑 (Hallim-eup / 한림읍)のオンポ3ギル27 (Ongpo 3-gil 27 / 옹포3길 27)。カカオマップに屋外食堂のタグがあるので、冬は室内席があるかを写真で先に見ましょう。食事面のヒント：海鮮中心(タクセウ・アワビ・カルチ・サバ)で、生ものメニューはありません。

🗺 動線 — 宿泊エリア別に選ぶ

済州はエリア間が車・バスの距離なので、1日に複数のエリアを詰め込んで回る動線は向いていません。泊まる場所とその日の行程に合わせて、エリアをひとつ選びます。

A. 済州市に泊まるとき (空港・新済州・旧市街)

  1. 朝 旧市街の24時ククスフェグァン(06:30~、火曜定休)、または空港側のナムギョンオゴムタン(08:00~)
  2. 昼 旧市街のクァンミョンシクタンのクッパ(11:00~18:00、水曜定休)、または済州市のチャンモシクタクの石鍋ご飯(日曜定休)
  3. 夕方 新済州のオジャングンのオクトムムグク・膳(21:00まで)、ボンゲ洞のコンジュネククス(月曜定休、20:00まで)
  4. 出発日 ナムギョンオゴムタン——定休日なしで08:00に開きます(ブレイクタイム 15:00~17:00は避けます)

B. 東の行程 (ソンサン・ウド・ソンダン)

  1. ウドへ行く日 船の時刻表を確認 → ウドヘニョシクタンで昼食(18:00閉店)
  2. ソンサン側の夕食 オンピョンパダハングルッ(ブレイクタイム 15:30~17:00のあとの夕方営業)
  3. ソンダン・ビジャリムへ行く日 木~日ならドウボーイで昼食(11:00~15:00)。月~水曜は休みなので、Aの済州市の食堂かオンピョンパダハングルッに変えます。

C. 西帰浦・ジュンムンに泊まるとき

  1. 昼 サンバンサン側ならサゲバダ(2人基準)、ひとりならジュンムンのウンジョンイネの1人用カルチジョリム
  2. 西の海岸を回る日の昼 ハンリムのパルンムル
  3. 夕方 ジュンムンのトニランの黒豚(01:00まで)、または西帰浦市内のキムゴギ(16:00~22:00)

月曜はコンジュネククス・ドウボーイ、火曜は24時ククスフェグァン・ドウボーイ、水曜はクァンミョンシクタン・ドウボーイ、日曜はチャンモシクタクが休みです。バスで回るなら、出発前にカカオマップの道案内で終バスを確認してください。五日市場を組み込むなら#1348。

⚠ よくある失敗3つ

  1. 「24時」という名前だけを信じて早朝・深夜に行く — 24時ククスフェグァンのカカオマップの登録時間は06:30~23:40で、火曜は休みです。午前0時を過ぎても開いている店を探すなら、この回ではトニラン(01:00まで)だけです。
  2. 曜日・閉店時間を見ずに東へ出発する — ドウボーイは木~日の 11:00~15:00だけ営業します。月・火・水にソンダンまで行っても無駄足です。ウドヘニョシクタンは18:00、クァンミョンシクタンも18:00に閉まります。ブレイクタイム(ナムギョンオゴムタン・コンジュネククス・オンピョンパダハングルッ)も確認してください。
  3. 名前が同じ別の支店に行く — トニランにはソンサン店が、サゲバダにはエウォル店・ピョソン店が別にあり、ウドには海女の家が複数あります。地図アプリでは店名ではなく、この回の道路名住所で探しましょう。

⚙ よくある質問3つ

  1. ひとつだけ選ぶなら？ — 外国語レビュー合計が最も多いのはナムギョンオゴムタン(22件、EN・JA・ZH集計 5・3・3)。三言語がそれぞれ5件以上残っているのはドウボーイとトニラン(どちらも15件、5・5・5)。ひとりで食べるなら、1人用メニューが登録されているウンジョンイネ(スンサルカルチジョリム 1人 ₩12,000)。
  2. 英語メニューがある店は？ — カカオマップのメニュー名で英語の併記を確認できたのはドウボーイだけです。ほかは英語メニューがあるかどうかわかっていないので、翻訳アプリを用意しましょう。
  3. 黒豚・太刀魚・海女の食卓をもっと知りたいなら？ — 黒豚の部位と選び方、海女の食卓と太刀魚の刺身は#1060。五日市場に行く日と市場の食べ物は#1348。チェジュ・イムジェ・タムナカンジャンケジャン・ミヨンイネは#1388。
