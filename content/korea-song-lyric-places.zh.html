歌曲中的那些地方指南 — 《光化门恋歌》的德寿宫·光化门，《丽水夜海》的丽水，《回来吧釜山港》的冬柏岛，《木浦之泪》的儒达山等共20处

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“歌词中的那些地方”主题入选的地方中，按地区挑选了韩国观光公社登记有运营信息的20处 · 歌曲与地点的联系以投票推荐理由中写明的曲名为准(不收录歌词) · 登记了门票的地方有德寿宫(个人 1,000韩元)和光化门条目(成人 3,000韩元) · 德寿宫周一休息，光化门条目登记值为周二休息 · 七甲山部分路线管制(2026.10.20~12.15) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“歌词中的那些地方”主题入选的100处中，韩国观光公社旅游信息里登记有运营信息的地方中的20处。表中的排名和得票数就是这次投票的结果。并不是收录了与韩国观光公社信息相连的全部地方，而是综合考虑排名和地区分布后挑选的。丽水Yi Sun-sin广场 (Yeosu Yi Sun-sin Gwangjang / 여수 이순신광장)·Seokchon湖 (Seokchon Hosu / 석촌호수)·海云台 (Haeundae / 해운대)·Oryukdo岛 (Oryukdo / 오륙도)等也进入了投票，但没有收入。

与哪首歌相连，是照录投票推荐理由中写明的曲名和歌手名。歌词因版权原因没有收录。韩国观光公社的介绍中也写有歌曲的地方(Kim Kwang-seok再画路 (Kim Kwang-seok Dasigeurigi-gil / 김광석다시그리기길)·河东花开市场 (Hadong Hwagae Jangteo / 하동 화개장터)·木浦儒达山 (Mokpo Yudalsan / 목포 유달산)·青阳七甲山道立公园 (Cheongyang Chilgapsan Doripgongwon / 청양 칠갑산도립공원)等)，对这一点另行作了说明。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。没有登记值的栏写作“无登记值”。投票名单中的地址与韩国观光公社登记不同的地方，正文中另行说明。

📍 首尔 — 德寿宫·光化门·Maronie公园·清溪川·Seochon 村·仙游岛公园

德寿宫 (Deoksugung / 덕수궁)的地址是首尔中区 (Sejong-daero 99 / 세종대로 99)，☎ 02-771-9951。这里是1897年宣布成立的大韩帝国的皇宫。旧名是Gyeongungung 宫 (Gyeongungung / 경운궁)，传统建筑和西式建筑并存。投票推荐理由中提到了《光化门恋歌 (Gwanghwamun Yeonga / 광화문 연가)》中出现的德寿宫Doldam路 (Deoksugung Doldam-gil / 덕수궁 돌담길)和Jeongdong教会 (Jeongdong Gyohoe / 정동교회)，演唱者是Lee Moon-sae。

  • 开放时间:09:00~21:00(入场截止 20:00)。Seokjojeon殿 (Seokjojeon / 석조전)·Dondeokjeon殿 (Dondeokjeon / 돈덕전)·Jungmyeongjeon殿 (Jungmyeongjeon / 중명전)展馆的时间另行规定。
  • 休息日:每周一(遇法定节假日·替代公休日则开放，之后第一个非法定节假日休息)。费用:个人 1,000韩元。德寿宫美术馆 (Deoksugung Misulgwan / 덕수궁 미술관)的门票需另购。

光化门 (Gwanghwamun / 광화문)的地址是钟路区 (Sajik-ro 161 / 사직로 161)，☎ 02-3700-3901。这是景福宫 (Gyeongbokgung / 경복궁)的正门。据韩国观光公社介绍，它是在基坛上开了三个Hongyemun拱门 (Hongyemun / 홍예문)、规格最高的宫门，于2010年8月15日完成复原工程。投票推荐理由中把它写为《光化门恋歌 (Gwanghwamun Yeonga / 광화문 연가)》中出现的首尔象征。投票名单中的地址是国立古宫博物馆 (Hyoja-ro 12 / 효자로 12)。

  • 以下时间·休息日·费用是韩国观光公社光化门条目登记的数值。门本身何时开放、是否收费，登记值中没有另外说明，费用栏中同时写有“详情请电话咨询”。
  • 开放时间:1~2·11~12月 09:00~17:00，3~5·9~10月 09:00~18:00，6~8月 09:00~18:30。入场截止分别为1小时前。
  • 休息日:每周二(遇法定节假日·替代公休日则开放，之后第一个非法定节假日休息)。费用:成人(25~64岁) 3,000韩元，外国人(19~64岁) 3,000韩元。停车:可以(约240辆)。

Maronie公园 (Maronie Gongwon / 마로니에공원)的地址是钟路区 (Daehak-ro 104 / 대학로 104)，☎ 02-2148-4158。这座公园位于旧首尔大学文理学院·法学院所在地。公园因1929年种下的七叶树 (Maronie / 마로니에)得名，露天舞台上举办演出和文化活动。投票推荐理由中把它写为与歌曲《鸡尾酒之恋 (Cocktail Sarang / 칵테일 사랑)》相连的大学路 (Daehak-ro / 대학로)名胜。

  • 开放时间:全天开放。休息日:全年无休。

清溪川 (Cheonggyecheon / 청계천)位于钟路区 (Changsin-dong / 창신동)，☎ 首尔设施公团 (Seoul Siseol Gongdan / 서울시설공단) 02-2290-6114，是流经钟路区和中区之间、长10.84㎞的河流。2003年至2005年复原了5.84㎞的区间，并架设了22座桥。投票推荐理由中把它写为RM的个人歌曲《Seoul》中出现的地方。

  • 开放时间:全天开放。下雨时出于安全考虑可能管制出入。休息日:全年无休。费用:免费。

Seochon 村 (Seochon / 서촌마을)的地址是钟路区 (Pilun-daero 45 / 필운대로 45)，☎ Bukchon 村游客中心 (Bukchon Maeul Annaeso / 북촌마을안내소) 02-2148-4161，是对景福宫西侧村庄的称呼。这里有老店铺、韩屋和巷子壁画，据韩国观光公社介绍，是电影·电视剧·音乐录影带的热门取景地。投票推荐理由中把它写为蕴含着IU专辑《花书签 (Kkotgalpi / 꽃갈피)》氛围的巷子。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

仙游岛公园 (Seonyudo Gongwon / 선유도공원)的地址是永登浦区 (Seonyu-ro 343 / 선유로 343)，☎ 02-2631-9367~8，是把1978年至2000年用作净水场的岛屿于2002年改造成的生态公园。这里有只保留混凝土柱子的“绿色柱子花园 (Noksaek Gidungui Jeongwon / 녹색기둥의 정원)”和步行桥Seonyu桥 (Seonyugyo / 선유교)。投票推荐理由中把它写为RM的个人歌曲《Seoul》中出现的地方。

  • 开放时间:06:00~24:00。休息日:全年无休。费用:免费。停车:登记为不可。

📍 丽水 — 丽水海上缆车·突山大桥·Nangman 帐篷酒馆街

投票“歌词中的那些地方”主题中，有多处丽水名胜以Busker Busker的《丽水夜海 (Yeosu Bambada / 여수 밤바다)》为推荐理由入选。

丽水海上缆车 (Yeosu Haesang Keibeolka / 여수해상케이블카)的地址是丽水市 (Dolsan-ro 3600-1 / 돌산로 3600-1)，是在海面上连接突山和Jasan (Jasan / 자산)的缆车。据韩国观光公社介绍，它是亚洲第四座跨海的海上缆车，运营地板为钢化玻璃的水晶车厢15辆和普通车厢35辆。

  • 开放时间·休息日·费用:无登记值。

突山大桥 (Dolsan Daegyo / 돌산대교)的地址是丽水市 (Dolsan-ro 3617-7 / 돌산로 3617-7)，☎ 丽水市政府 (Yeosu Sicheong / 여수시청) 1899-2012，是把突山与陆地相连的桥。从2000年10月起点亮可呈现50多种颜色的景观照明。投票推荐理由中把它写为与《丽水夜海 (Yeosu Bambada / 여수 밤바다)》相配的夜景名胜(没有写歌手)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

丽水 Nangman 帐篷酒馆街 (Yeosu Nangman Pocha-geori / 여수 낭만포차거리)的地址是丽水市 (Hamel-ro 102 / 하멜로 102)，是位于Geobukseon大桥 (Geobukseon Daegyo / 거북선대교)下方广场的路边摊街。有18栋帐篷酒馆营业，介绍中说可以一边欣赏丽水夜景，一边观看街头演出。

  • 开放时间·休息日·费用:无登记值。

📍 釜山 — 广安里海水浴场·海云台冬柏岛·Dalmaji 小山

广安里海水浴场 (Gwangallie Haesuyokjang / 광안리해수욕장)的地址是釜山水营区 (Gwangan Haebyeon-ro 219 / 광안해변로 219)，☎ 051-622-4251，是以广安大桥 (Gwangan Daegyo / 광안대교)夜景闻名的海滩。夏天可以玩冲浪·桨板，还会举办演出·庆典·无人机表演。投票推荐理由中把它写为与IVE的《After LIKE》的夏日感性相配的地方。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

海云台冬柏岛 (Haeundae Dongbaekseom / 해운대 동백섬)的地址是海云台区 (Dongbaek-ro 67 / 동백로 67)一带，☎ 051-749-7621，因泥沙堆积与陆地相连，但至今仍被称为岛。环岛步道上有崔致远铜像和诗碑、美人鱼像、Nurimaru APEC馆 (Nurimaru APEC House / 누리마루 APEC하우스)。投票推荐理由中把它写为Cho Yong-pil的《回来吧釜山港 (Dorawayo Busanhange / 돌아와요 부산항에)》中出现的冬柏岛。投票名单中的地址是海云台区 (U-dong 710-1 / 우동 710-1)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Dalmaji 小山 (Dalmaji-dongsan / 달맞이동산)的地址是海云台区 (Dalmaji-gil 184 / 달맞이길 184)，☎ 051-749-4084，是从海云台海水浴场东侧翻越到Cheongsapo 村 (Cheongsapo / 청사포)的Wausan山 (Wausan / 와우산)半山腰的赏月山口。据韩国观光公社介绍，这里的月出曾被评为大韩八景 (Daehan Palgyeong / 대한 팔경)之一，1997年建造的Haewoljeong 亭 (Haewoljeong / 해월정)被介绍为赏月公园的象征。投票推荐理由中把它写为Choi Baek-ho的《去釜山的话 (Busane Gamyeon / 부산에 가면)》中出现的地方。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 岛屿 — Hyeopjae海水浴场·郁陵岛

Hyeopjae海水浴场 (Hyeopjae Haesuyokjang / 협재해수욕장)的地址是济州市 (Hallim-ro 329-10 / 한림로 329-10)，☎ 064-728-3981，是以掺有贝壳粉的白沙滩和前方海上的Biyangdo 岛 (Biyangdo / 비양도)闻名的海滩。水很浅，坡度平缓。投票推荐理由中把它推荐为欣赏《济州岛的蓝夜 (Jejudoui Pureun Bam / 제주도의 푸른 밤)》中济州海景的好去处。韩国观光公社的介绍中提到了SEVENTEEN送给粉丝的歌曲，但曲名在登记值中没有写明。投票名单中的地址是济州市 (Hyeopjae-ri 2497-1 / 협재리 2497-1)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

郁陵岛 (Ulleungdo / 울릉도)的地址是郁陵郡 (Dodong 1-gil 5-3 / 도동1길 5-3)，☎ 054-790-6454。据韩国观光公社介绍，它是韩国第九大岛，由火山活动形成。有44个附属岛屿，还有整修居民走过的路而成的郁陵Haedam路 (Ulleung Haedam-gil / 울릉 해담길)，共9条旧路线。投票推荐理由中把它写为因《郁陵岛扭扭舞 (Ulleungdo Twist / 울릉도 트위스트)》而闻名的地方。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 老歌之乡 — Kim Kwang-seok再画路·花开市场·Sangju Eunmorae 海滩·儒达山·月出山·七甲山

Kim Kwang-seok再画路 (Kim Kwang-seok Dasigeurigi-gil / 김광석다시그리기길)的地址是大邱中区 (Dalgubeol-daero 2238 / 달구벌대로 2238)，☎ 大邱观光信息中心 (Daegu Gwangwang Jeongbo Center / 대구관광정보센터) 053-627-1337，是在Kim Kwang-seok生活过的Daebong 洞 (Daebong-dong / 대봉동)的Bangcheon 市场 (Bangcheon Sijang / 방천시장)旁的巷子里，以他的生活和音乐为主题打造的壁画街。据韩国观光公社介绍，2010年开始建设，350m的墙面上有Kim Kwang-seok造型和壁画。每年秋天举办“Kim Kwang-seok 歌曲演唱比赛”。投票名单中的地址是大邱中区 (Daebong-dong 6-11 / 대봉동 6-11)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

河东花开市场 (Hadong Hwagae Jangteo / 하동 화개장터)的地址是河东郡 (Ssanggye-ro 15 / 쌍계로 15)，☎ 055-883-5722，是位于Seomjin江 (Seomjingang / 섬진강)与Hwagae川 (Hwagaecheon / 화개천)交汇处的传统市场。据韩国观光公社介绍，这里是岭南和湖南人互相往来的集市，是Kim Dong-ri的小说《驿马 (Yeongma / 역마)》的背景，也以歌曲《花开市场 (Hwagae Jangteo / 화개장터)》广为人知。2001年重新开业的常设市场。投票推荐理由中提到了Cho Young-nam的《花开市场 (Hwagae Jangteo / 화개장터)》。投票名单中的地址是河东郡 (Hwagae-myeon Tap-ri / 화개면 탑리)。

  • 开放时间·休息日:登记为因店铺而异。

南海 Sangju Eunmorae 海滩 (Namhae Sangju Eunmorae Beach / 남해 상주은모래비치)的地址是南海郡 (Sangju-ro 17 / 상주로 17)，☎ 南海郡政府 (Namhae Gun-cheong / 남해군청) 海洋休闲组 (Haeyang Rejeo-tim / 해양레저팀) 055-860-3073，是像屏风一样环绕Geumsan山 (Geumsan / 금산)、长2㎞的半月形沙滩。坡度平缓，举办夏季音乐节和冬季日出庆典。投票推荐理由中把它写为Duldasot的《夜船 (Bambae / 밤배)》的背景地。投票名单中的地址是南海郡 (Sangju-ro 17-4 / 상주로 17-4)。

  • 开放时间:全天开放。休息日:全年无休。停车:免费。淋浴间成人 2,000韩元。

木浦儒达山 (Mokpo Yudalsan / 목포 유달산)的地址是木浦市 (Jukgyo-dong San 27-3 / 죽교동 산27-3)，☎ 061-270-8411，被介绍为Noryeong山脉 (Noryeong Sanmaek / 노령산맥)的最后一座山峰。有五座亭子，从山顶可以望见多岛海。据韩国观光公社介绍，山下有Lee Nan-young演唱的《木浦之泪 (Mokpoui Nunmul / 목포의 눈물)》纪念碑。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

灵岩月出山国家公园 (Yeongam Wolchulsan Gungnip Gongwon / 영암 월출산국립공원)的地址是灵岩郡 (Cheonhwangsa-ro 280-43 / 천황사로 280-43)，☎ 061-473-5210，1988年被指定为第20个国家公园。顶峰是Cheonhwangbong 峰 (Cheonhwangbong / 천황봉)，高809m。投票推荐理由中写道，Ha Chun-hwa的《灵岩阿里郎 (Yeongam Arirang / 영암아리랑)》中经常出现月出山。

  • 开放时间:4~10月 04:00~15:00，11~3月 05:00~14:00。可能因气象条件管制。
  • 休息日:登记为有步道管制期间，请参阅官网。费用:免费。

青阳七甲山道立公园 (Cheongyang Chilgapsan Doripgongwon / 청양 칠갑산도립공원)的地址是青阳郡 (Janggok-gil 241 / 장곡길 241)，☎ 041-940-2721，是海拔561m的山，1973年被指定为道立公园。有9条登山路，从Hanti 岭 (Hanti-gogae / 한티고개)下到Janggoksa 寺 (Janggoksa / 장곡사)的路线游客最多，约需3小时。据韩国观光公社介绍，Chilgapsanjang 山庄 (Chilgapsanjang / 칠갑산장)一带有七甲山歌碑 (Chilgapsan Noraebi / 칠갑산노래비)。投票推荐理由中提到了Ju Byeong-seon的《七甲山 (Chilgapsan / 칠갑산)》。

  • 开放时间:可能因气象条件管制出入。
  • 休息日:登记为部分路线在2026.10.20~12.15管制。费用:免费。停车:免费。

⚠ 需提前了解的3点

  1. 休息的日子不同 — 德寿宫周一休息，韩国观光公社光化门条目登记为周二休息(详情登记为请电话 02-3700-3901 咨询)。
  2. 七甲山部分路线管制期间 — 登记有2026.10.20~12.15部分路线管制(期间结束后请再次确认)。月出山也有步道管制期间。
  3. 歌曲的联系以投票推荐理由为准 — 曲名和歌手照录推荐理由中写明的内容。韩国观光公社的介绍中也写有歌曲的地方有Kim Kwang-seok再画路·河东花开市场·木浦儒达山·青阳七甲山道立公园等。

⚙ FAQ 3

问:与《光化门恋歌 (Gwanghwamun Yeonga / 광화문 연가)》相连的地方有哪些?

答:是德寿宫(投票第1名)和光化门(第2名)。投票推荐理由中还一并提到了德寿宫Doldam路 (Deoksugung Doldam-gil / 덕수궁 돌담길)和Jeongdong教会 (Jeongdong Gyohoe / 정동교회)。

问:想看《丽水夜海 (Yeosu Bambada / 여수 밤바다)》中的风景去哪里?

答:这份指南收录的丽水地点是丽水海上缆车、突山大桥、丽水 Nangman 帐篷酒馆街。突山大桥从2000年起点亮景观照明。

问:哪些地方有门票?

答:登记了门票的是德寿宫(个人 1,000韩元)和光化门条目(成人 3,000韩元)。丽水海上缆车·丽水 Nangman 帐篷酒馆街·Maronie公园·河东花开市场·南海 Sangju Eunmorae 海滩没有门票登记值(Sangju Eunmorae 海滩只登记了淋浴间费用)。
