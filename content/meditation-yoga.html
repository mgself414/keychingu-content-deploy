⚠ 외국인 자주 실수 5가지

1. "한국 명상 = 한국인만": 한국 명상 = 사찰 명상 (진관사·봉은사·길상사) + 외국인 영어 OK + 템플스테이 (#332) + 외국인 매니아 1번지·#357 통합.

2. "요가 = 인도만": 한국 요가 = 요가원 외국인 영어 OK + Ashtanga·Hatha·Vinyasa + 외국인 글로벌 매니아 + #290 통합·#384 K-Beauty 결합.

3. "필라테스 = 비싸기만": 필라테스 = The Body Lab·The Pilates + 외국인 매니아 1번지 + 가성비 1회 20~50K + 강남·청담·#296·외국인 매니아.

4. "외국인 wellness = 호텔만": 외국인 wellness = 사찰 명상 (#357) + 차 (#359) + 한방 (#365) + 명상·요가 (#448) + 호텔 SPA (#364) + 외국인 wellness 5축 풀세트.

5. "외국인 영어 OK = 강남만": 외국인 영어 OK = 강남 (#142) + 홍대 (#138) + 이태원 (#144) + Klook·KKday·KTO 인증 + 외국인 매니아 풀세트.
