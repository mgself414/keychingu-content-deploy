🎯 本指南的使用方法

参观巴士在厂区里缓缓行驶,最后停在出口码头 — 现代汽车蔚山工厂 (Hyundai Motor Ulsan Plant / 현대자동차 울산공장) 的参观路线从文化会馆经第3工厂到达这个码头(现代汽车官方预约页面)。本指南写给想亲眼看看韩国企业如何制造产品的游客。标准只有一个: 在企业官方预约页面上正在运营,且个人或少数人员可以申请的地方。 符合标准的四处分为展览型(三星·现代Motorstudio)和工厂型(现代汽车蔚山·海特真露江原)。仅限团体或未能打开官方页面的地方,另列在⚠和最下方。

🏛 展览型 — 一个人也能去的2处

  • 三星创新博物馆 (Samsung Innovation Museum / 삼성이노베이션뮤지엄)(S/I/M) — 京畿道水原市 (Suwon / 수원시) 灵通区 三星路 (Samsung-ro / 삼성로) 129号,031-200-3113(水原市旅游官方页面)
  • 时间: 工作日13:00~14:00 讲解员导览(须提前预约),周六10:00~17:00自由参观(16:00停止入场)
  • 休馆: 公休日·补休日·劳动节·12月31日
  • 费用: 免费
  • 年龄: 满13周岁以上。小学生及以下须由监护人陪同(每2名儿童配1名监护人)
  • 语言: 工作日讲解员提供韩语·英语·汉语·日语·西班牙语,申请人数30人以下(水原市旅游官方页面)。官方网站设有英文"Tour Reservation"菜单(三星创新博物馆官方网站)
  • 现代汽车Motorstudio高阳 (Hyundai Motorstudio Goyang / 현대 모터스튜디오 고양) — 京畿道高阳市 (Goyang / 고양시) 一山西区 KINTEX路 (Kintex-ro / 킨텍스로) 217-6号,GTX-A KINTEX站 (Kintex / 킨텍스역) 1号出口。客服中心 1899-6611(现代Motorstudio官方网站)
  • 时间: 展览09:00~20:00。体验展览10:00~18:20(周末·公休日·旺季10:00~19:00),周一闭馆。常设展览·4D Ride须提前预约,15分钟前截止售票
  • 闭馆: 元旦,春节·中秋当天及次日
  • 费用(个人): 常设展览成人1万韩元·青少年7,000韩元·儿童5,000韩元,4D Ride成人7,000韩元,联票成人16,000韩元
  • 试驾: 10:00~17:00,须提前预约,周一休息
  • 网站有韩语·英语·汉语页面(现代Motorstudio官方网站)

🏭 工厂型 — 预约比较困难的2处

  • 现代汽车蔚山工厂 (Hyundai Motor Ulsan Plant / 현대자동차 울산공장) — 蔚山北区 (Buk-gu / 북구) 盐浦路 (Yeompo-ro / 염포로) 700号(蔚山工厂正门)(现代汽车官方预约页面)
  • 路线: 文化会馆 → 第3工厂 → 出口码头,约1小时30分钟。乘坐工厂提供的巴士参观
  • 费用: 免费。午餐·车辆·纪念品不提供
  • 个人参观: 每位申请人最多4人。11岁以下子女每位监护人最多带2人。部分场次标有"面向含未成年人的家庭·学生,不接受成人团体申请"
  • 预约方式: 以3个月为单位受理,每月第一个工作日上午9点开放日程。在线申请需通过i-PIN或本人名下手机认证 — 没有韩国手机的话,请先向参观咨询处询问
  • 外国人团体: 团体参观仅按巴士为单位受理,含外国人的团体按"企业·政府机关及外国人"类型申请
  • 咨询: 052-215-1021~1024(09:00~17:00,午休11:10~12:10除外),ulsantour@hyundai.com
  • 禁止在工厂内拍照及携带摄影设备
  • 海特真露江原工厂 (Hite Jinro Gangwon Plant / 하이트진로 강원공장) — 江原道洪川郡 (Hongcheon / 홍천군) 北方面 (Bukbang-myeon / 북방면) 道屯路 (Dodun-gil / 도둔길) 49号,参观咨询 033-430-8250~3(海特真露官方网站)
  • 对象: 满19周岁以上成人,须提前预约。海特真露的工厂中,目前开放参观的是江原工厂 (Gangwon / 강원공장)(海特真露官方FAQ)
  • 星期: 仅限周一至周五(周六·周日·公休日不可)
  • 受理: 至少在希望日期前3周申请,先到先得。确认结果于希望日期前2周通知。不接受电话申请
  • 人数: 单次申请最多45人。每场20~40人,所以少数人员可与同一时段的其他团体一起参观(海特真露官方FAQ)
  • 费用: 免费

🧰 产业观光实务 — 独自前往·预约·身份·交通

  • 独自前往: 三星创新博物馆 (Samsung Innovation Museum / 삼성이노베이션뮤지엄)(周六自由参观)和现代汽车Motorstudio高阳 (Hyundai Motorstudio Goyang / 현대 모터스튜디오 고양) 一个人也可以去。现代汽车蔚山工厂 (Hyundai Motor Ulsan Plant / 현대자동차 울산공장) 设有个人参观名额,海特真露则是少数人员加入其他团体的方式
  • 预约时间: 现代汽车蔚山每月第一个工作日09:00开放,海特真露3周前截止。旅行日期确定后,先订这两处
  • 身份确认: 现代汽车在线申请使用韩国式本人认证。先发邮件(ulsantour@hyundai.com)询问会更快
  • 支付: 4处中收费的只有现代汽车Motorstudio高阳 (Hyundai Motorstudio Goyang / 현대 모터스튜디오 고양) 的体验展览。刷卡·移动支付请见 外国人韩国支付系统深度探索
  • 交通: 水原·高阳乘坐首都圈地铁即可 — 韩国交通卡3种选择,零慌张手册 — 按我的行程原样挑卡。蔚山·洪川请见 韩国高速·城际巴士客运站,流程原样照搬 — App从一开始就完全不同
  • 蔚山一日行程: 蔚山产业观光

⚠ 常见的4个错误

1. "起亚的工厂也可以个人申请" — 起亚Auto Land (Kia AutoLand / 기아 오토랜드) 参观只接受能出具公函的教育机构·政府机关正式团体(15~30人),不接受个人和旅行社团体。外国人团体须有韩国人带队同行(起亚官方页面)

2. "海特真露的工厂哪里都能参观" — 目前开放参观的是江原工厂 (Gangwon / 강원공장)。官方注明利川工厂 (Icheon / 이천공장) 不开展参观(海特真露官方网站)

3. "在工厂里拍照发到网上就行" — 现代汽车蔚山工厂 (Hyundai Motor Ulsan Plant / 현대자동차 울산공장) 禁止拍摄及携带摄影设备(现代汽车官方预约页面)

4. "三星博物馆整个周末都开放" — 只有周六自由参观,工作日是13:00讲解员导览预约制。公休日休息(水原市旅游官方页面)
