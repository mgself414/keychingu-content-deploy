🎯 为什么要看"济州徒步游"指南

外国人游济州岛 (Jeju-do / 제주도) 最大的痛点就是租车。韩国租车基本要求国际驾照 (IDP·International Driving Permit),所以没带国际驾照的外国人·不开车的人·独自旅行者,常常卡在"没车到底能不能玩济州?"这一步。这也正是 Reddit 的 r/koreatravel·r/jeju 上反复出现 "4 nights in Jeju without a car — where to stay and what's realistic by bus?" 这类提问的原因(真实的需求信号)。

先说结论: 自济州2017年公共交通改革后,巴士网络很密。把快速(红)·干线(蓝)·支线(绿)巴士 + 观光地循环巴士 810/820 (Sightseeing Loop Bus / 관광지 순환버스) + KakaoT (카카오T) 出租车组合起来,不租车也能在 3晚4天内玩遍核心12选。关键是选好住宿基地和把路线分成东/西两天。

本指南涵盖 徒步12选 + 3晚4天巴士路线 + 住宿基地策略 + 实时App设置。

🚌 徒步4大交通工具 Deep Dive

① 快速巴士 (Express / 급행버스, 红色·100号段)

  • 招牌: 机场·主要据点最少停靠·济州–西归浦最快
  • 外国人友好度: ★★★★☆ (KakaoMap (카카오맵) 路线有英文)
  • 贴士: 101/102 = 海岸循环快速·从机场往西归浦/城山方向最快

② 干线巴士 (Trunk / 간선버스, 蓝色·200~300号段)

  • 招牌: 连接主要景点的主力·201(东海岸)·202(西海岸)·281(贯穿汉拿山)
  • 外国人友好度: ★★★★☆
  • 票价: 交通卡基本 ₩1,150~1,200 (~$0.85 / ~6 RMB / ~120 JPY)·长距离区间加收

③ 观光地循环巴士 810/820 (Sightseeing Loop / 관광지 순환버스)

  • 招牌: 810 = 东部(大川–城山·拒文岳等)·820 = 西部(中文–雪绿·和顺等) — 只循环景点
  • 外国人友好度: ★★★★★ (为徒步优化·定额 ₩1,150)
  • 贴士: 一天可跳玩多个景点·东/西一日游的骨架

④ KakaoT 出租车 (카카오T)

  • 招牌: 补干线空白·深夜·行李多时的最后一公里
  • 外国人友好度: ★★★★☆ (英文App·绑定银行卡)
  • 贴士: 济州出租车在市中心外派车会慢 → 留足时间·目的地用韩文保存

✈️ 交通 + 支付 (徒步必读)

  • 抵达: 首尔金浦→济州航班1小时·往返 ₩80,000~250,000 (~$60~185) / 釜山金海→济州50分钟
  • 机场→市区: 快速 101/102·干线 316/315·KakaoT (到市中心15~20分钟)
  • 交通卡: T-money (티머니)·Cashbee (캐시비) 便利店 (便利店 / 편의점) 购买充值(换乘有优惠) / 外国人也可用 WOWPASS·旅行卡
  • 支付: 巴士刷卡·现金皆可·出租车可刷卡·无小费
  • 急救: ☎ 1339(医疗)·1330(旅游翻译)·119

⚠ 外国人徒步5大常见失误

1. "济州没车玩不了": 改革后的网络 + 循环巴士 810/820 + KakaoT 覆盖核心12选。这个认知是错的。

2. "住哪都行": 徒步游基地占八成。锁定一个: 济州市(机场·巴士枢纽近) 或 西归浦(中文·偶来)。偏远民宿 = 巴士荒漠地狱。

3. "东西一天玩完": 济州很大(往返3小时+)。东部·西部要分不同天才现实。

4. "忽视末班车": 支线·循环巴士末班车很早(18~20点)。日落后移动靠 KakaoT 备用。

5. "牛岛·城山当天往返很赶": 城山+牛岛要留一整天。提前确认轮渡时刻表。

⚙ FAQ 6个

1. 真的不用租车吗?: 核心景点巴士OK。但内陆深处的오름(oreum, 火山锥)·夜间移动要配 KakaoT。

2. 循环巴士 810/820 怎么坐?: 东=810,西=820。定额 ₩1,150·循环主要景点。KakaoMap 查实时。

3. 城山日出峰日出: 04:00~20:00开放·门票 ₩5,000 (~$3.7 / ~27 RMB)·日出随季节约05~07点。

4. 去牛岛: 城山港轮渡约15分钟·往返约 ₩10,500·牛岛上有循环巴士/电动自行车。

5. 汉拿山徒步: 巴士可到城板岳 (Seongpanak / 성판악, 干线 281)·御里牧 (Eorimok / 어리목, 240) 登山口。登顶白鹿潭 (Baengnokdam / 백록담) 需提前预约。

6. 推荐人群: 独行·不开车 = 济州市基地 + 东/西一日游 / 情侣 = 西归浦 + 牛岛 / 预算型 = 巴士+免费自然(挟才·雪绿茶田)。

⚠ 医疗·安全·饮食 disclaimer

汉拿山登山 = 孕妇·心脏病患者请咨询医生·冬季冰爪·城板岳登顶提前预约。带鱼生鱼片·鲍鱼 = 甲壳·鱼类过敏注意。长时间坐巴士备好防晕车。急救 ☎ 1339·1330·119。

👥 5类人群路线

独行 (Solo Traveler)

  • 推荐: 济州市单基地 + 东/西一日游(用循环巴士)
  • 预算: ₩250,000~400,000/人 (3晚4天)
  • 招牌: 咖啡·海边·市场·单人黑猪肉노포 (nofo / 노포, 30年以上老店)

情侣 (Couple)

  • 推荐: 西归浦基地 + 牛岛骑行 + 部分偶来小路(巴士+步行)
  • 预算: ₩500,000~800,000/2人 (3晚)
  • 招牌: 夕阳(挟才·中文)·咖啡·海女 (haenyeo / 해녀, 女性潜水员) 之家

家庭 (Family with Kids)

  • 推荐: 济州市基地 + 循环巴士跳玩 + KakaoT备用
  • 预算: ₩600,000~1,000,000/4人 (3晚)
  • 招牌: 牛岛·海边·民俗村·婴儿车建议配出租车

MZ·ins (Millennial/Gen-Z)

  • 推荐: 月汀里·咸德·挟才咖啡街(巴士可步行到)
  • 预算: ₩250,000~450,000/人
  • 招牌: 海景咖啡·ins打卡点·牛岛电动自行车

预算型 (Budget Traveler)

  • 推荐: 巴士 + 免费自然(挟才·雪绿茶田·汉拿山入场免费)
  • 预算: ₩200,000~350,000/人
  • 招牌: 市场街边小吃·免费自然·青年旅舍·交通卡换乘优惠
