외국인 망원동 인덱스

MZ·트렌디 hidden gem — 망원시장·망리단길·합정·연남 hop 매트릭스 + 기존 publish 통합

망원동은 합정 인접·홍대 도보 15분·연남 도보 20분의 MZ·트렌디 hub. 외국인 관광객 1순위는 아니지만, 망원시장(전통)·망리단길(트렌디 카페·음식)·한강 망원지구 cluster가 외국 segment foodie·hidden gem lover에게 fit. 본 인덱스는 키친구의 망원동 관련 publish 콘텐츠 + saved 신호 통합 navigation.

1. 망원동 = 어떤 동네?

  • 위치: 마포구 서쪽 (2호선·6호선 망원역 + 합정역 도보 10분)
  • 사이즈: 1.5km × 1km (도보 30분 cover)
  • 인접: 합정·홍대·연남·상수 도보 권역
  • 분위기: MZ 트렌디·로컬·노포·시장 + 한강 인접
  • 외국인 비율: 5-10% (합정·홍대보다 낮음·hidden 분위기)

2. 망원동 sub-cluster

망원시장 (전통·시장·1970년대~)

  • 위치: 망원역 2번 출구
  • 시그니처: 분식·반찬·해산물·먹거리 노점
  • 외국인 fit: ★★ (현지인 시장·picture menu·번역 앱)

망리단길 (트렌디·MZ·맛집·카페)

  • 위치: 망원역 1번 출구 + 망원동 골목
  • 시그니처: 인디 다이닝·트렌디 카페·디저트·브런치
  • 외국인 fit: ★★ (MZ·인스타·트렌디)

한강 망원지구 (자연·피크닉·야경)

  • 위치: 망원역 → 한강공원 도보 15분
  • 시그니처: 한강 피크닉·산책·자전거 (외국인 unique)
  • 외국인 fit: ★★★ (한강 피크닉 1순위 권역 중 하나)

합정·연남 인접 (확장 동선)

  • 망원 → 합정 도보 10분
  • 망원 → 연남 도보 20분
  • 망원 → 홍대 도보 15분

5. 1일 표준 동선 (3 패턴)

Pattern A: 시장 + 한강 피크닉 (외국 1순위)

  • 11:00 망원역 2번 출구 → 망원시장 점심 (분식·반찬·해산물)
  • 13:00 망원시장 산책 + 먹거리 hop
  • 15:00 한강 망원지구 도보 15분 → 피크닉 (치맥)
  • 18:00 망리단길 디너 (인디 다이닝)
  • 21:00 합정 nightlife (Pattern 인접)

Pattern B: MZ·트렌디 카페·다이닝

  • 11:00 망리단길 brunch 카페
  • 13:00 망원동 디자인 카페 hop (3-4곳)
  • 15:00 망원시장 + 골목 산책
  • 18:00 망원동 인디 다이닝
  • 21:00 합정 와인 bar

Pattern C: 권역 hop (홍대·연남·망원)

  • 10:00 홍대 메인 산책
  • 12:00 연남 brunch
  • 14:00 연남 → 망원 도보 20분
  • 15:00 망원시장 + 망리단길
  • 18:00 합정 디너
  • 21:00 홍대 nightlife (옵션)

6. 외국인 fit Tips

영문 가능성

  • 상위: 망리단길 트렌디 매장 (영문 메뉴 일부)
  • 중상: 망원시장 (picture menu)
  • 로컬: 골목 노포·인디 (번역 앱 권장)

예산 (1인 1일)

  • Pattern A 시장 + 한강: ₩40,000~70,000 (가성비)
  • Pattern B MZ 트렌디: ₩60,000~120,000
  • Pattern C 권역 hop: ₩80,000~150,000

페르소나별

  • foodie·hidden gem: Pattern A (시장 + 한강)
  • MZ·인스타: Pattern B (망리단길)
  • 권역 explorer: Pattern C (홍대·연남·망원 hop)
  • 가족 fit: Pattern A (한강 피크닉)
  • K-drama 팬: 망원시장 (다수 촬영지)

시즌별

  • 봄 (4-5월): 한강 망원지구 (벚꽃)
  • 여름 (6-8월): 한강 피크닉·냉면·냉모밀 (saved 신호)
  • 가을 (10-11월): 망원시장 + 한강 단풍
  • 겨울 (12-2월): 망원시장 국밥·실내 카페
