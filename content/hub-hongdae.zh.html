为什么选弘大入口枢纽 —— 外国人住宿最集中的夜生活门户

弘大入口站 (Hongik Univ. Station / 홍대입구역) 是2号线·京义中央线 (Gyeongui-Jungang Line / 경의중앙선)·机场铁路 (AREX / 공항철도) 交汇的三线换乘站。通过机场铁路从仁川机场 (Incheon Airport / 인천공항) 直达,青年旅舍·旅社在首尔 (Seoul / 서울) 最为密集,因此被誉为外国旅客的大本营。从这里向新村 (Sinchon / 신촌)·梨大 (Ewha Womans Univ. / 이대)(2号线)·延南 (Yeonnam / 연남)·合井 (Hapjeong / 합정)·上水 (Sangsu / 상수)(2号线)·西江大 (Sogang Univ. / 서강대)·龙山 (Yongsan / 용산)(京义中央)·金浦机场 (Gimpo Airport / 김포공항)(机场)延伸。白天在延特朗公园 (Yeontral Park / 연트럴파크)(京义线林荫道 (Gyeongui Line Forest Park / 경의선숲길))散步,夜晚逛弘大俱乐部街 (Hongdae Club Street / 홍대 클럽거리) —— 24小时运转的青春枢纽。

本指南是与按线路系列(#1241~#1249)正交的新轴。"从弘大入口一站向 3 个方面放射" —— 以据点为中心串联"坐哪条线路能到什么"。这是地铁线路系列(Phase 2·换乘枢纽)的第四篇。

弘大入口枢纽放射型一日线路 3

线路 1. 入境首日(机场·住宿方面)

  • 仁川机场(入境) → 机场铁路 弘大入口(住宿入住) → 延特朗公园(京义线林荫道散步) → 弘大俱乐部街(夜晚)

  • fit: 年轻街区·购物·汉江。大学街氛围。

换乘·使用贴士 5 —— 弘大入口枢纽 200% 活用

Tip 1. 弘大入口是"外国人住宿门户"

通过机场铁路直达仁川机场(#1249) + 青年旅舍数量最多最密集。入境后作为首尔旅行大本营最为理想。

Tip 2. 3个方面性格各不相同

2号线=大学街·江边,京义中央=本地·住宿·散步,机场铁路=入境·国内线。按目的选择方面。

Tip 3. 沿京义线林荫道漫步

从弘大入口到延南·孔德的废弃铁道公园(#1235)散步。用步行代替地铁的延特朗公园。

Tip 4. 夜晚才是精华

弘大俱乐部街·现场音乐俱乐部·街头表演在夜晚才真正鲜活。请确认深夜公共交通·深夜巴士。

Tip 5. 一张交通卡搞定

一张 T-money 通乘 2·京义中央·机场铁路全部。机场铁路普通列车也用 T-money。
