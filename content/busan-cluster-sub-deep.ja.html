⚠️ 外国人がよくやるミス3

ミス1 — BIFFシーズンとBIFF広場を混同

BIFF広場（南浦洞通り）は年中無料開放されています。映画祭期間（毎年10月初旬の約10日間）でなくても、手形プレートや屋外展示を見ることができます。10月しか行けないと誤解して他のシーズンに訪問を見送る外国人が多いです。

ミス2 — 龍頭山公園のエスカレーターを知らずに階段を上る

龍頭山公園の入口（光復洞側）には無料エスカレーターがあります。これを知らずに急な階段を上る観光客が多いです。エスカレーター入口は光復路側の地下入口（ロッテ百貨店光復店方面）から入ります。

ミス3 — 国際市場を月曜に訪問

国際市場の店舗の一部は月曜休業、または正午以降の開店です。国際市場食堂横丁の飲食店はほとんどが火曜~日曜の営業です。月曜訪問の場合、シアッホットク横丁は開いていますが、商店街は縮小営業になります。

軸1: 国際市場（3選）— 1948正統

1. 国際市場 本館通り

位置: 釜山中区新昌洞4街 / 地下鉄1号線チャガルチ駅7番出口から徒歩7分、または南浦駅5番出口から徒歩5分。

無料/有料: 入場無料。買い物・食事の費用のみ。

外国人fit: 朝鮮戦争後の1948年に避難民が形成した市場で、釜山の歴史そのものです。衣類・生活用品・アクセサリー・観光土産が混在し、路地ごとに雰囲気が異なります。英語案内板があり、決済はほとんどカードが使えます。

アクセス・動線: 南浦駅5番出口 → 光復路 → 国際市場入口（徒歩5分）。または、チャガルチ駅7番出口 → 徒歩7分。市場内部は格子状の路地で区画されているため迷いません。

タイミング: 午前10時~午後6時が活気があります。午後7時以降は店舗の80%が閉まります。食堂横丁は夜まで営業しています。

BIFFシーズン連携: 10月のBIFF期間には、国際市場一帯に映画関連のポップアップブースや屋外上映が加わります。商人が映画祭特需を狙って夜間延長営業する場合もあります。

実用tip: 国際市場には「トッテギ市場(dotgi sijang / 도떼기시장)」という愛称があります。値札がない場所は値引き交渉が可能です。英語の「How much?」は通じます。

2. 国際市場 食堂横丁（シアッホットク・オムク）

位置: 国際市場内部5番ゲート方向の路地 / オムク横丁は光復洞の入口。

無料/有料: シアッホットク1個 約1,500ウォン、オムク串1~2本 1,000~2,000ウォン。

外国人fit: 釜山を代表する屋台グルメ2種がここにあります。シアッホットク（ひまわりの種・ピーナッツなどナッツたっぷり）はソウルのホットクと味が違い、釜山のオムク（おでん）は本場の味でスープまで無料提供する屋台形式が多いです。行列ができる店がおいしい店の目印です。

アクセス: 国際市場正門（新昌洞4街入口）から50m直進するとシアッホットクの屋台が見えます。

タイミング: 午前11時~午後9時。昼食直後（午後1~3時）が最も列が長いです。

グルテン・アレルギー: おでんには小麦粉が入っています。グルテンに敏感な方は注意してください。シアッホットクはナッツアレルギーの確認が必要です。

3. 国際市場 1948通り（歴史散策エリア）

位置: 国際市場中心部の歴史案内板エリア。市場内の案内地図では「1948通り」と表示。

無料/有料: 無料。案内板・壁画の散策。

外国人fit: 朝鮮戦争（1950~1953）の避難民の歴史とつながるストーリーレイヤーです。英語・日本語・中国語の案内板が設置されており、独力での散策が可能です。歴史に関心がある外国人（特に韓国近現代史に関心がある日本人・アメリカ人観光客）に向いています。

タイミング: 昼間の訪問が案内板を読むのに有利です。

軸2: BIFF・映画（3選）

4. BIFF広場（釜山国際映画祭広場）

位置: 釜山中区南浦洞5街 / 地下鉄1号線南浦駅6番出口から徒歩2分。

無料/有料: 屋外広場は無料。映画祭期間の上映プログラムは有料（チケット別途購入）。

外国人fit: アジア最大級の映画祭の一つである釜山国際映画祭（BIFF）は1996年からこの地域で開催されてきました。広場の床には韓国・アジア・世界の映画人100人以上の手形プレートが敷かれています。映画祭のオフシーズンでもこの手形は年中見ることができます。映画好きの外国人なら、好きな監督・俳優の手形を探す楽しみがあります。

アクセス: 南浦駅6番出口を出るとすぐにBIFF広場の看板が見えます。徒歩2分以内。

タイミング: 年中屋外観覧が可能です。夜間も照明があり手形散策ができます。10月のBIFFシーズンは人出が急増するため、午前早めの訪問がおすすめです。

BIFFシーズン（10月）の特記事項: 毎年10月初旬の約10日間開催。国内外の映画300本以上を上映、レッドカーペット行事、屋外上映、有名監督・俳優のGV（観客との対話）。チケットは事前オンライン予約必須（BIFF公式サイト: biff.kr）。当日窓口販売は早期に締め切られます。

実用tip: BIFF広場近くには南浦洞ファッションストリートがあり、映画祭期間中は監督・俳優の目撃が珍しくありません。ファッションストリートのカフェ・レストランはBIFF期間中、深夜0時まで延長営業します。

5. BIFFストリート・南浦洞映画文化通り

位置: BIFF広場周辺の南浦洞5街・6街一帯。広場からチャガルチ方面へ続く300m区間。

無料/有料: 無料散策。

外国人fit: 韓国映画のポスター壁画、映画関連のオブジェ、独立系映画館の看板が続く通りです。韓国映画（『パラサイト 半地下の家族』『オールド・ボーイ』『新感染 ファイナル・エクスプレス』など）に関心がある外国人には特に意味があります。南浦洞近辺には2~3の小規模ミニシアターがあり、英語字幕上映プログラムを不定期に運営しています。

タイミング: 昼は通り散策、夜は照明の雰囲気が良いです。

6. 釜山映像委員会・映画ロケ地散策

位置: 釜山海雲台区（映像委員会本部）ですが、南浦洞・中区一帯にロケ地が分散しています。

外国人fit: 釜山は『新感染 ファイナル・エクスプレス』『犯罪都市』など韓国映画の主要ロケ地です。映像委員会公式サイト（bfc.or.kr）でロケ地マップを無料提供しています。英語版もあり、映画ファンならセルフロケ地ツアーが組めます。南浦洞・影島・チャガルチ近辺にロケ地が集中しています。

実用tip: ロケ地ツアーは別途ガイドなしでも可能です。英語版ロケ地マップPDFを事前にダウンロードして徒歩散策してください。

軸3: 龍頭山・釜山タワー（3選）

7. 龍頭山公園

位置: 釜山中区光復洞2街 / 地下鉄1号線南浦駅7番出口から徒歩5分、またはエスカレーター利用。

無料/有料: 公園無料、24h開放。

外国人fit: 標高49mで釜山原都心（南浦洞・光復洞・チャガルチ・龍頭山）を一望できる最適地点です。天気が良ければ影島と釜山港が一目で見えます。公園内には花時計（1983年設置）・李舜臣将軍の銅像・八角亭があります。家族連れ・カップル双方に向いています。

アクセス: 南浦駅7番出口 → 光復路 → エスカレーター入口（地下）。エスカレーターで約3分で頂上部です。徒歩でも階段10分。

タイミング: 夜景（午後7時以降）が最も美しいです。春（3~4月)は花のシーズンで混み合い、10月のBIFFは広場と連携する訪問者が多いです。早朝6~8時は散歩する地元民だけで静かです。

エスカレーターの位置: ロッテ百貨店光復店方面から地下へ降りる入口があります。地上から案内表示に沿って進むだけです。

8. 釜山タワー

位置: 龍頭山公園頂上 / 龍頭山公園エスカレーター到着地点から徒歩1分。

無料/有料: 有料。大人12,000ウォン、青少年9,000ウォン、子供6,000ウォン（2025年基準）。カード決済可能。

営業時間: 10:00~22:00（年中無休）。

外国人fit: 高さ120mの360度回転展望台です。釜山原都心・釜山港・影島を四方から一望できます。天気が良い日は対馬（日本)が見えることもあります。内部展望フロアの一部が強化ガラスになっており、真下を見下ろせます。英語・日本語・中国語の案内完備。

おすすめタイミング: 日没前後（午後6~8時）に訪問すると、昼景と夜景の両方が見られます。夜10時直前の入場は短時間観覧になってしまうため、最低1時間前の入場をおすすめします。

BIFFシーズンの特記事項: 10月のBIFF期間はタワーのライトアップが映画祭テーマに変更される場合があります。

9. 龍頭山公園 花時計・インスタスポット

位置: 龍頭山公園頂上広場 / 釜山タワーの隣。

無料/有料: 無料。

外国人fit: 1983年に設置された大型花時計で、釜山原都心を背景に写真が撮れます。実際に動いている時計で、季節ごとに花のデザインが変わります。インスタ映えスポットとして日本人・中国人観光客に特に人気です。

タイミング: 昼の写真は花と背景がくっきり写り、夜間はライトアップで違った雰囲気になります。

軸4: 近隣cross（3選）

10. チャガルチ市場（#590 cross）

位置: 龍頭山公園・BIFF広場から徒歩10~15分 / チャガルチ駅10番出口。

連携ポイント: #590で詳しく扱った釜山No.1水産市場です。国際市場・BIFF広場を訪問した後、昼食または夕食でチャガルチへ移動する動線が最も効率的です。チャガルチ駅基準で国際市場（7番出口徒歩7分）、BIFF広場（南浦駅6番出口徒歩5分)ともに地下鉄1駅の距離です。

実用tip: チャガルチ市場は午前5時開場、チャガルチ2階レストランは午前8時から営業。昼食前にチャガルチ → 午後に国際市場・BIFF → 夕方に龍頭山夜景、という順序がベストです。

11. 影島大橋・影島跳開イベント

位置: 南浦洞から徒歩10分 / 影島大橋の上。

無料/有料: 無料。

外国人fit: 影島大橋は朝鮮戦争当時、避難民の待ち合わせ場所として歴史的な意味を持つ橋です。現在は毎日午後2時に跳開（橋が開く）イベントを行っています。約15分間、橋が開き船が通過する場面が見られます。地元民には馴染み深いですが、外国人には珍しい光景です。

タイミング: 跳開時間は午後2:00ちょうど。10~15分前に到着すると良い場所が確保できます。夜間の影島大橋のライトアップも見応えがあります。

12. ヒンヨウル文化村（影島）

位置: 釜山影島区永仙洞 / 南浦洞から市内バス66番で約20分、またはタクシー10分。

無料/有料: 村散策無料。

外国人fit: 影島の崖の上に形成された避難民の村で、狭い路地と海の眺望が独特です。映画『不当取引』のロケ地でもあります。村内には小さなギャラリー・カフェ・工房があり、英語案内板が設置されています。甘川文化村より知名度は低いですが、より静かで地元の雰囲気が強いです。

タイミング: 午前10時~午後5時の訪問が適しています。一部のカフェ・工房は午後6時前に閉まります。

FAQ 5

Q1. BIFF期間でなくてもBIFF広場に行く価値はありますか？

あります。BIFF広場は年中無料の屋外開放です。100以上の手形プレートは10月でなくても見られます。むしろオフシーズンは人出が少なく、ゆったり散策できます。

Q2. 龍頭山公園への入場方法 — エスカレーターは有料ですか？

無料です。南浦駅7番出口から光復路沿いに5分歩くと「龍頭山公園エスカレーター」入口の案内表示があります。地下へ降りて乗車すれば公園頂上部まで上がれます。

Q3. 釜山タワー vs. 海雲台セントゥム展望台 — どちらが良いですか？

南浦洞・チャガルチ・BIFF広場一帯を一望するなら釜山タワーです。海雲台・広安里を見るなら海雲台セントゥム展望台、または黄嶺山です。動線基準で南浦洞クラスターを1日で回るなら釜山タワーが適しています。

Q4. 国際市場で必ず食べるべきものは？

シアッホットク（ナッツホットク、1,500ウォン）とオムク串（1,000~2,000ウォン）です。2つ合わせて3,000ウォンあれば釜山を代表する屋台グルメ体験が完了します。

Q5. 10月のBIFFシーズンに初めて釜山を訪れる場合の注意点は？

BIFF期間（通常10月初旬10日間）は南浦洞・BIFF広場・チャガルチ一帯の宿泊費が普段より2~3倍上昇し、人出も急増します。宿は最低2~3か月前の予約が必須です。BIFF映画チケットの予約は開幕2~3週間前にbiff.krでオープンし、人気上映作は数分で完売します。

フルデイコース3

コース1. 南浦洞フルセット（1日）

チャガルチ駅到着 → チャガルチ市場（#10、午前8~10時） → 国際市場食堂横丁でシアッホットク・オムク（#2、午前10~11時） → 国際市場本館散策（#1、午前11~12時） → 昼食は国際市場の韓食 → BIFF広場で手形散策（#4、午後1~2時） → 影島大橋跳開イベント（#11、午後2時ちょうど） → 龍頭山公園散策・花時計（#7・#9、午後3~5時） → 釜山タワーで日没＋夜景（#8、午後6~8時）

想定費用: シアッホットク1,500ウォン + オムク2,000ウォン + 昼食10,000~15,000ウォン + 釜山タワー12,000ウォン + ショッピングは自由。

コース2. BIFF10月マニアコース

BIFF広場（#4、午前早め） → BIFFストリート散策（#5） → レッドカーペットポイントで待機（午後） → 屋外上映を夕方に。国際市場でのショッピングを合間に。釜山タワーはBIFFライトアップテーマの際に夜間訪問。

BIFFチケットの事前購入（biff.kr）必須。当日購入分はごくわずかです。

コース3. 釜山1泊クラスター

Day 1午前: チャガルチ → 国際市場 → BIFF広場 → 龍頭山夜景。Day 2午前: 影島ヒンヨウル文化村（#12） → 影島大橋跳開イベント（#11） → 午後は海雲台・広安里（#243 cross）または甘川文化村（#245 cross）。
