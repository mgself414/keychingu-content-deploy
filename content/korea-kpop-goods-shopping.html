> 부제: 외국인 관광객용 한국 굿즈 쇼핑 가이드 (BTS·NCT·K-drama·K-beauty·K-stationery) + 명동·홍대·강남·하이브 매트릭스

ISSUE 04 · #1089 · 2026-06-14

🎯 왜 한국 굿즈 쇼핑 가이드인가

한국 굿즈 쇼핑 = 외국인 매니아 매트릭스 #1 K-content 팬 + 굿즈 + 가져갈 수 있는 매트릭스. 외국인 관광객 페인포인트 = (a) "한국 굿즈 = 명동만" 잘못된 인식 — 명동·홍대·강남·하이브 인사이트 = 4대 굿즈 매트릭스 #1 (b) BTS·NCT·BLACKPINK·TWICE·K-drama·K-beauty·K-stationery = 7대 카테고리 cluster (c) "굿즈 = 너무 비싸" — 굿즈 = 카테고리 매트릭스 다양 (D 카드 5,000원~ / 앨범 25,000원~ / 콘서트 굿즈 50,000원~) (d) 공식 K-content 매장 + 비공식 매장 매트릭스 = 외국인 매니아 fit (e) 굿즈 + 콜린비 큐레이터(#1086)·골목 편집샵(#1088) cross.

본 가이드는 외국인 시각 한국 굿즈 7선 + 카테고리·매장·매니아 매트릭스 + 풀세트.

★ 한눈에 한국 굿즈 7선 매트릭스

# 굿즈 카테고리 시그너 매장 동네·역 외국인 매니아 포인트 가격대
1 BTS·HYBE 굿즈 (하이브 인사이트) ★ 하이브 인사이트 (용산) 용산 한강로 (용산역) 외국인 매니아 매트릭스 #1 + BTS 팬 매니아 + 영어 OK 10,000~200,000원
2 NCT·SM 굿즈 (코엑스·왕십리 SM) SM타운 코엑스·왕십리 강남 코엑스·성동 왕십리 (삼성·왕십리역) NCT·EXO·Red Velvet 팬 매니아 매트릭스 #1 10,000~150,000원
3 K-drama 굿즈 (KBS·MBC·JTBC) KBS 미디어 스튜디오 영등포 여의도 (여의도역) K-drama 팬 매니아 매트릭스 #1 + 도깨비·스카이캐슬 fit 5,000~100,000원
4 K-beauty 굿즈 (올리브영·아모레퍼시픽) ★ 명동 올리브영·아모레퍼시픽 중구 명동 (명동역) 외국인 매니아 매트릭스 #1 + K-beauty 풀세트 5,000~80,000원
5 K-stationery·문구 (텐바이텐·아트박스) 홍대 텐바이텐·강남 아트박스 마포 홍대·강남 (홍대입구·강남역) 외국인 매니아 + K-stationery 매트릭스 #1 1,000~30,000원
6 명동 K-pop 굿즈 거리 ★ 명동 K-pop 매장 cluster 중구 명동 (명동역) 외국인 매니아 매트릭스 #1 + 명동 K-pop cluster 5,000~100,000원
7 홍대 K-pop·인디 굿즈 홍대 인디 매장 cluster 마포 홍대 (홍대입구역) 홍대 매니아 + 인디 K-pop 매트릭스 5,000~50,000원

⚠ 외국인 자주 실수 3가지

1. "한국 굿즈 = 명동만": 7대 굿즈 매트릭스 = 명동·홍대·강남·용산·여의도·코엑스·왕십리 cluster #1. BTS 팬 = 하이브 인사이트 (1) 매트릭스 #1. NCT 팬 = SM타운 (2). K-drama 팬 = KBS 미디어 (3).

2. "굿즈 = 너무 비싸": 7대 카테고리 = 가격 매트릭스 다양. K-stationery (5) = entry-level (1,000~30,000원). K-beauty (4) = 중간 (5,000~80,000원). BTS·NCT 콘서트 굿즈 = 디자이너 (50,000~200,000원). 외국인 매니아 = 카테고리 매트릭스 선택.

3. "굿즈 = 영어 안 통하나": 7개 매장 = 영어 직원·영어 가이드 매트릭스 #1. 하이브 인사이트·SM타운·올리브영·아모레퍼시픽 = 외국인 매니아 fit. 명동·홍대 = 영어 OK 多.

⚙ FAQ 4개

1. 외국인 한국 굿즈 best 동선: Day 1: 명동 (4·6) → N서울타워 cross. Day 2: 홍대 (5·7) → 야장(#1071) cross. Day 3: 용산 하이브 (1) → 한남 야간 바(#1073) cross. Day 4: 강남 SM (2) → 코엑스·잠실. Day 5: 여의도 KBS (3) → 한강 야경(#1072) cross.

2. 외국인 굿즈 K-content 팬 매트릭스: (a) BTS·HYBE 팬 = 하이브 인사이트 (1) 매트릭스 #1 (b) NCT·EXO·Red Velvet 팬 = SM타운 (2) (c) K-drama 팬 = KBS 미디어 (3) + 방탈출(#1085) cross (d) K-beauty 팬 = 올리브영·아모레 (4) (e) K-stationery 팬 = 텐바이텐·아트박스 (5). 외국인 매니아 = 카테고리 매트릭스.

3. 굿즈 etiquette (외국인 시각): (a) 가격표 = 한국어 + 영어 부분 매트릭스 (b) 결제 = 카드·현금 OK + tax-free 매트릭스 (c) 사진 = 일부 제한 매트릭스 (d) 영어 직원 = 매장별 매트릭스 (e) 굿즈 보호 = 종이·박스 매니아 매트릭스.

4. 외국인 굿즈 tax-free 매트릭스: (a) 30,000원+ 결제 = tax-free 매트릭스 가능 (b) 외국인 매니아 = 여권 + 카드 결제 + tax-free 환급 매트릭스 (c) 인천공항 tax-free 카운터 = 외국인 매니아 fit (d) 명동·홍대·강남·코엑스 = tax-free 매장 多.
