🎯 为什么选择庆州 (Gyeongju / 경주) 完整指南

庆州 (Gyeongju / 경주) = 新罗 (Silla / 신라) 千年古都 (公元前57年~公元935年) + 韩国第一联合国教科文组织遗产城市 (佛国寺 (Bulguksa / 불국사)·石窟庵 (Seokguram / 석굴암) 1995年·庆州历史遗迹区 (Gyeongju Yeoksa Yujeok Jigu / 경주 역사 유적 지구) 2000年·良洞韩屋村 (Yangdong Hanok Maeul / 양동 한옥 마을) 2010年)。外国韩国历史爱好者首选之地。从KTX 庆州站 (Singyeongju-yeok / 신경주역) 仅需2小时。

⚠ 外国游客常犯的5个错误

1. “庆州 (Gyeongju / 경주) = 1晚2天就够了”: 庆州 (Gyeongju / 경주) 外国游客深度游 = 2晚3天~3晚4天全套行程 + 佛国寺 (Bulguksa / 불국사)·石窟庵 (Seokguram / 석굴암)·瞻星台 (Cheomseongdae / 첨성대)·东宫与月池 (Donggunggawolji / 동궁과월지)·良洞村 (Yangdongmaeul / 양동마을) + 郊区 安东 (Andong / 안동)·浦项 (Pohang / 포항)。

2. “佛国寺 (Bulguksa / 불국사) = 石窟庵 (Seokguram / 석굴암)”: 佛国寺 (Bulguksa / 불국사) = 新罗 (Silla / 신라) 751年 韩国第一寺庙 (释迦塔 (Seokgatap / 석가탑)·多宝塔 (Dabotap / 다보탑) 联合国教科文组织) + 石窟庵 (Seokguram / 석굴암) = 佛国寺 (Bulguksa / 불국사) 以东4公里处的石窟寺庙。

3. “瞻星台 (Cheomseongdae / 첨성대) = 只是个普通的塔”: 瞻星台 (Cheomseongdae / 첨성대) = 新罗 (Silla / 신라) 632年 世界第一天文台 (现存东亚最古老) + 外国游客必访景点。

4. “东宫与月池 (Donggunggawolji / 동궁과월지) = 只适合白天游览”: 东宫与月池 (Donggunggawolji / 동궁과월ji) (雁鸭池 (Anapji / 안압지)) = 新罗 (Silla / 신라) 第一夜景 (晚上7点~10点 / 19:00~22:00) + 外国游客Vlog首选地。
