🎯 だれのための、なぜこの10か所なのか

釜山に初めて行く外国人旅行者に合わせたリストです。海辺ではなく、釜山の山の斜面の町と朝鮮戦争の跡を見る日に使います。甘川文化村と草梁イバグキルは、どちらも斜面に家が重なるように建つ町を歩く道です。大淵洞の博物館と国連記念公園は、同じ道の上にあります。

3つのエリアに分けました。

  • 甘川エリア(2か所): 甘川文化村、峨嵋洞碑石文化村。
  • 草梁山腹道路エリア(5か所): 草梁イバグキル、168階段・草梁168階段ハヌルキル、イバグ工作所、柳致環の郵便ポスト、草梁チャイナタウン(上海通り)。
  • 大淵・釜田エリア(3か所): 釜山博物館、国連記念公園、釜山市民公園。

この号でいちばん先に読んでほしいのは、甘川文化村の特別管理地域の規定です。訪問時間、車両の通行、団体の訪問に、日付のついたルールができました。すぐ下の節に別にまとめました。

甘川文化村と峨嵋洞碑石文化村は、今も住民が暮らす町です。10か所のうち国連記念公園は、参拝する場所です。3か所とも、見て回る方法に条件がつきます。該当の項目に書きました。

⚠ 表記の原則: 時間、料金、距離、行き方は2026-11-24に閲覧した値です。出典は、甘川文化村公式サイト、釜山 東区庁 文化観光、釜山博物館、国連記念公園、釜山市民公園のサイトとVisit Busanです。駅から歩く時間の一部はカカオマップ経路案内の値で、該当の行に「カカオマップ」と明記しました。料金は大人の基準です。運営時間、料金、バスの路線は変わることがあります。

📌 まず、甘川文化村の特別管理地域 — 日付で見るルール

甘川文化村は2026-08-01に特別管理地域に指定告示されました。下の内容は、甘川文化村公式サイトの案内文(沙下区発行、2026-11-24閲覧)に書かれた値です。

案内文に書かれた内容

  • 訪問時間: 住居密集地域は、観光客の訪問時間が09:00~18:00です。
  • 区域の区分: 案内文の案内地図は、村を分けて管理しています。住居密集地域は訪問時間を設け、住居・商業混在地域はエチケットの指導とフォトゾーンの秩序管理を行い、関心地域はモニタリングを行います。
  • 車両の通行制限: カムネ2路 (Gamnae 2-ro / 감내2로) の一部、案内センターの入口から「思い出の影 (Memory Shadow / 추억의 그림자)」フォトゾーンまでの約1kmの区間は、案内文の施行日(2027-01-01)から観光客が乗った車両の通行を09:00~18:00に制限します。タクシーも含まれます。
  • 団体の訪問: 10人以上の団体の訪問客は、村の公式地図を買う必要があります。 案内文は、この項目の施行日を2026-08-01と書いています。
  • 大型バス: 事前予約制で運営します。
  • 管理する行為: 違法な駐停車、ごみの不法投棄、騒音、プライバシーの侵害。

🚦 歩く前に — 共通の安全とマナー

  • 甘川と峨嵋洞は住民が暮らす町です。 Visit Busanは、峨嵋洞碑石文化村の案内に「実際に住民が暮らしているので、静かに見学してください。」と書いています。甘川文化村の公式紹介も、住民の日常を尊重するよう呼びかけています。
  • 路地のマナー(この号の推奨): 案内文は、騒音とプライバシーの侵害を管理の対象に挙げています。下はこの号の推奨です。路地では声を小さくするほうがよいです。玄関の扉、窓の中、干してある洗濯物は写真に撮らないことをおすすめします。人の家の戸口をふさいで撮らないほうがよいです。ごみは持ち帰ることをおすすめします。
  • 坂と階段が多いです。 甘川文化村は天馬山 (Cheonmasan / 천마산) のふもとの段々状の住宅地で、草梁イバグキルには168階段があります。運動靴をはきます。
  • 月曜日を確かめます。 釜山博物館、イバグ工作所、柳致環の郵便ポストが月曜日に休みます。
  • 国連記念公園には、スリッパやビーチサンダルをはいては入れません。 きちんとした服装は推奨事項です。
  • 事故や緊急のときは119、犯罪の通報は112に電話します。

① 甘川エリア — 2か所

都市鉄道1号線の土城駅とチャガルチ駅から、マウルバスで上るエリアです。甘川文化村と峨嵋洞碑石文化村は互いに近く、Visit Busanも碑石文化村の案内で、甘川文化村が隣り合っていると紹介しています。

甘川文化村 (Gamcheon Culture Village / 감천문화마을)

  • どんな所: 甘川文化村公式の紹介によると、朝鮮戦争の避難民が定着してできた山腹の村です。1950年代に太極道 (Taegukdo / 태극도) の信仰村が造られ、今の姿が整いました。天馬山のふもとに家が段々状に建ち、後ろの家の日当たりと眺めをさえぎらないように建てた構造です。
  • 今の姿になったきっかけ: 2009年の文化体育観光部の「マウル美術プロジェクト (Maeul Art Project / 마을미술프로젝트)」です。
  • 案内センター: 09:00~18:00、年中無休。住所は釜山広域市 沙下区 カムネ2路 (Gamnae 2-ro / 감내2로) 203、電話は051-204-1444です。観光情報を提供し、路地ツアーの地図を売り、荷物預かり所を運営し、村のガイドの案内を担当します。
  • 訪問時間: 住居密集地域は09:00~18:00です(甘川文化村公式サイトの案内文)。上の特別管理地域の節を先に読んでください。
  • 見どころ: 公式サイトは、ハヌルマル展望台 (Haneulmaru Observatory / 하늘마루 전망대)(051-202-5557)、小さな博物館 (Small Museum / 작은박물관)、星の王子さまとフェネックの像、その下のお土産ショップ「小惑星B612 (Asteroid B612 / 소행성 B612)」を紹介しています。
  • 村に残る消費: 公式サイトは、住民協議会が運営する施設の収益を、住民の福祉と地域に還元すると書いています。小惑星B612のお土産ショップが、そうした施設です。
  • 体験プログラム: 陶芸、木工などの体験を09:00~16:00に予約制で運営します。
  • 行き方(公式サイトの案内):
  • 都市鉄道1号線の土城駅6番出口(釜山大学病院 (Pusan National University Hospital / 부산대병원))で、マウルバス 西区2 (Seogu 2 / 서구2)、西区2-2 (Seogu 2-2 / 서구2-2)、沙下区1-1 (Sahagu 1-1 / 사하구1-1) に乗り換えます。
  • 都市鉄道1号線のチャガルチ駅1番出口(忠武市場 (Chungmu Market / 충무시장) の停留所)で、マウルバス 西区2 (Seogu 2 / 서구2)、西区2-2 (Seogu 2-2 / 서구2-2)、沙下区1-1 (Sahagu 1-1 / 사하구1-1) に乗り換えます。
  • バスは、市内バス61番と、マウルバス 西区2 (Seogu 2 / 서구2)、西区2-2 (Seogu 2-2 / 서구2-2)、沙下区1 (Sahagu 1 / 사하구1)、沙下区1-1 (Sahagu 1-1 / 사하구1-1) が走っています。
  • 車で行く場合: 公式サイトは、村の駐車場が足りないとして公共交通を勧めています。公営駐車場は78台分と40台分です。大型バスは予約が必要です。カムネ2路の一部区間は、案内文の施行日(2027-01-01)から、09:00~18:00に観光客が乗る車両の通行を制限します。

峨嵋洞碑石文化村 (Ami-dong Tombstone Culture Village / 아미동 비석문화마을)

  • どんな所: Visit Busanによると、日本統治時代に日本人の共同墓地だった山の斜面です。朝鮮戦争のとき避難民がここに家を建てて村になり、墓地の墓石を階段の踏み石と家の礎石に使いました。階段の踏み石と家の礎石に使われた墓石を見ることができます。
  • 利用時間・料金: 毎日運営し、年中無休です。無料です。
  • 住所: 釜山広域市 西区 アミ路 (Ami-ro / 아미로) 49。
  • 行き方(Visit Busanの案内):
  • 都市鉄道1号線の土城駅8番出口から徒歩約15分。
  • マウルバス 沙下区1-1 (Sahagu 1-1 / 사하구1-1) または 西区2 (Seogu 2 / 서구2) に乗り、「山上教会 (Sansang Church / 산상교회)」(碑石文化村)で降ります。
  • カカオマップ経路案内の基準では、土城駅8番出口から770m、徒歩20分です。
  • 駐車: アミゴル (Amigol / 아미골) 公営駐車場。
  • 見学の方法: Visit Busanは「実際に住民が暮らしているので、静かに見学してください。」と書いています。墓石を近くでのぞき込むときは、家の内側にカメラを向けないほうがよいです。
  • 組み合わせ方: 甘川文化村と同じマウルバスの番号(沙下区1-1、西区2)が、2か所の案内の両方に出てきます。同じ日の半日にまとめます。

168階段・草梁168階段ハヌルキル (168 Stairs · Choryang 168 Stairs Haneul-gil / 168계단·초량168계단 하늘길)

柳致環の郵便ポスト (Yu Chi-hwan's Mailbox / 유치환의 우체통)

  • どんな所: イバグキルのコースの最後の地点です。展望台があります。
  • 運営時間(釜山 東区庁の公式案内): 火~土 10:00~19:00、日 09:00~18:00。
  • 休みの日: 月曜日、祝日。展望台は常時開放です。休みの日に行っても、展望台から見下ろすことはできます。
  • 行き方: 釜山駅7番出口から、イバグキルのコースに沿って最後まで歩きます。イバグ工作所、望洋路山腹道路展示館、チャン・ギリョ記念 ザ・ナヌムセンター、イバグキャンプを順に過ぎると着きます。

草梁チャイナタウン・上海通り (Choryang Chinatown · Shanghai Street / 초량 차이나타운·상해거리)

  • どんな所: 釜山 東区庁の公式案内によると、釜山駅前の大通りを渡ると赤い牌楼である上海門 (Shanghai Gate / 상해문) が出てきて、その奥が上海通りです。
  • 沿革(釜山 東区庁の公式案内):
  • 1884年に清国の領事館が開き、この一帯が清館通り (Cheonggwan Street / 청관거리) になりました。
  • 1993-08-24に釜山市と上海市が姉妹都市提携を結んだあと、「上海通り」という名前がつきました。
  • 2007年から2023年までは「チャイナタウン特区」でした。今は特区が解除されています。
  • 行き方: カカオマップ経路案内の基準で、上海門は釜山駅1番出口から40m、徒歩1分です。
  • 組み合わせ方: イバグキルは釜山駅7番出口、上海門は1番出口の側です。イバグキルを歩く前か、歩いて下りてきたあとに寄ります。電車の時間まで余った時間に見るのにも合います。

③ 大淵・釜田エリア — 3か所

釜山博物館と国連記念公園は、どちらも都市鉄道2号線の大淵駅3番出口から出ます。住所も同じ道の上です(ユエンピョンファ路 (Yuenpyeonghwa-ro / 유엔평화로) 63、ユエンピョンファ路93)。釜山駅からは、134番のバスが2か所へ行きます。釜山市民公園は釜山鎮区 (Busanjin-gu / 부산진구) のヨンジドン (Yeonji-dong / 연지동) にあり、カカオマップ経路案内の基準で、釜田駅2番出口から徒歩12分です。

⚠ よくある失敗3つ

  1. 甘川文化村をいつでも行ける所と思うこと — 甘川文化村は2026-08-01に特別管理地域に指定されました。住居密集地域の訪問時間は09:00~18:00で、案内文の施行日は2027-01-01です。カムネ2路の一部の約1kmの区間は、案内文の施行日(2027-01-01)から、09:00~18:00にタクシーを含む観光客が乗る車両の通行を制限します。日が暮れたあとに路地の写真を撮りに行く日程や、タクシーで村の奥まで入る日程は立てません。
  2. 168階段でモノレールを探すこと — 東区庁の公式案内は、階段の横の施設を傾斜型エレベーター「草梁168階段ハヌルキル」と紹介しています。モノレールに乗る日程は入れません。階段を歩いて上ることを基本にして、靴を合わせます。
  3. 国連記念公園を散歩の公園と思うこと — 国連記念公園は参拝する場所です。スリッパやビーチサンダルをはいては入れず、公園の中では食べ物を食べられません。11月は16:45に入場を締め切り、17:00に閉まります。遅くまで歩いたり休んだりする場所を探すなら、05:00~24:00に開いている釜山市民公園に行きます。

⚙ FAQ 3つ

  1. 甘川文化村には何時に行けばいい? ひとりで行っても地図を買う必要がある? — 09:00~18:00の間に行ってきます。案内センターが09:00~18:00に開き、住居密集地域の訪問時間も09:00~18:00です。地図の購入義務は、10人以上の団体の訪問客にあります。今(2026-11-24現在)は、案内文の施行日(2027-01-01)の前です。過料はカムネ2路の通行制限違反につき、2028-01-01からです。出典は、甘川文化村公式サイトの案内文です。
  2. 月曜日に行くと、どこが閉まっている? — 釜山博物館、イバグ工作所、柳致環の郵便ポストが月曜日に休みます。釜山市民公園のハヤリア芝生広場も、月曜日は入れません。月曜日にも開いている場所として案内に書かれているのは、甘川文化村の案内センター(年中無休)、峨嵋洞碑石文化村(年中無休)、国連記念公園(年中無休)、釜山市民公園(365日)です。柳致環の郵便ポストの展望台は、常時開放です。
  3. 入場料がかかる場所はある? — 釜山博物館、峨嵋洞碑石文化村、釜山市民公園は無料で、国連記念公園は入場料がありません。釜山市民公園の貸館の施設と駐車場は有料です。国連記念公園は、参拝客の乗用車を1時間30分無料で停められます。甘川文化村の陶芸・木工の体験は、09:00~16:00に予約制で運営します。
