🎯 왜 서울 K-드라마 촬영지 가이드인가

서울 K-드라마 촬영지 = 외국인 매니아 매트릭스 #1 K-content 팬 + 명소 + photogenic + Netflix 글로벌 reach. 외국인 관광객 페인포인트 = (a) "서울 K-드라마 = 도깨비만" 잘못된 인식 — 2024-2026 신작 5편 매트릭스 (눈물의 여왕·선재업고튀어·내 남편과 결혼해줘·이재·낭만닥터 김사부 시즌3) (b) #378 전국편(기생충·오징어게임·도깨비 12선)과 차별 = 서울만 narrow focus + 1박2일·3박4일 외국인 동선 (c) K-drama 팬 = Netflix·Disney+·Hulu 글로벌 200+국 매트릭스 #1 — 외국인 매니아 fit (d) 도깨비(2016)·별그대(2014)·이태원클라스(2020)·오징어게임(2021) 명작 5선 + 2024-2026 신작 5선 = 10편 cross 매트릭스 (e) 서울 K-drama + 한복(#1081)·야장(#1071)·한강 야경(#1072)·K-굿즈(#1089)·K-방탈출(#1085) cross 풀세트.

⚠ 외국인 자주 실수 3가지

1. "도깨비 풍경 = 강원도 강릉만": 도깨비 강릉 해변(주문진) = 한국 매트릭스 #1, 하지만 도깨비 서울 spot = 경복궁(1)·북촌(2)·N서울타워(4)·청계천(6)·시청(11) cross. 서울 1박2일 = 도깨비 풀세트 가능. 강릉(KTX 1시간 50분) = 옵션 1박2일 추가.

2. "K-드라마 = 옛날 드라마만": 2024-2026 신작 5편 매트릭스 = 눈물의 여왕(2024, 글로벌 Netflix #1)·선재업고튀어(2024, MZ peak)·내 남편과 결혼해줘(2024)·이재(2025)·낭만닥터 김사부 시즌3(2024). 신작 = 한강·청계천·익선·성수·망원 cross.

3. "촬영지 = 가까이 못 가": 12선 모두 외국인 무료 입장 + 일반인 사진 OK 매트릭스. 경복궁(1) = 한복 시 무료 입장 + 한복+궁궐 = 외국인 매니아 매트릭스 #1. 시청(11) 덕수궁 = 무료 입장. 한강공원(7) = 24시간 무료. 익선(8)·성수(9)·이태원(10) = 골목 자유롭게 photo.

⚙ FAQ 4개

1. 외국인 1박2일 K-드라마 서울 동선: Day 1 도깨비·이태원클라스 풀세트: 경복궁(1) 한복 + 북촌(2) 한옥 → 청계천(6) → 광장시장(3) 야장 → N서울타워(4) 야경. Day 2 신작 + 한강 풀세트: 익선(8) 한옥 + 성수(9) 핫플 → 한강공원(7) 눈물의 여왕 → 시청(11) 덕수궁 → 이태원(10) 야간 바(#1073).

2. 외국인 3박4일 K-드라마 풀가이드 + 외곽: Day 1-2 위 1박2일 → Day 3 망원·DDP: 망원(12) 이재 + DDP(5) 별그대 + 동대문 야시장. Day 4 외곽 옵션: 강릉 (도깨비 주문진 KTX 1시간 50분) 또는 경기 인천 (별그대·기생충 추가 spot).

3. 한복 + K-드라마 촬영지 photo etiquette: (a) 한복 대여 = 10,000~30,000원/일 (북촌·인사동·삼청 매장 多) (b) 경복궁(1)·창덕궁·덕수궁(11) = 한복 시 무료 입장 + 외국인 매니아 매트릭스 (c) 한복 + 다도 cross (#1081) = entry-level + 영어 OK (d) photo 시 다른 관광객 방해 X + 한복 etiquette (양손 사용·앉을 때 무릎 모음).

4. 외국인 K-드라마 시즌 best: 봄꽃 (4월 한강공원(7) 벚꽃·여의도 윤중로·N서울타워(4) 봄꽃) = 외국인 매니아 매트릭스 #1. 가을 단풍 (10월 북촌(2)·삼청·익선(8)·창덕궁 후원 단풍) = photo best. 여름 (6~8월 한강 야장(#1071)·청계천(6) 야경) / 겨울 (12~2월 N서울타워(4) 야경·잠수교 눈).
