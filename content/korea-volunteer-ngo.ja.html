⚠ 外国人がやりがちな失敗3つ

1. 「韓国のNGOは少ない」という規模の過小評価: 実際にはKOICA派遣規模は年間1,000人以上、グッドネイバーズは60カ国で海外事業を展開、ワールドビジョン韓国の支援者数は70万人規模です。韓国はODA受援国から供与国に転換した世界唯一の事例——その基盤インフラが国内にもそのまま存在します。

2. 「韓国のボランティアは韓国語のみ」という思い込み——英文チャネルの見落とし: KOICAヤングプロフェッショナル・1365ポータルの外国人登録・グッドネイバーズの英文ボランティア・国際ワークキャンプ(SCI Korea)は英語で申請・参加が可能です。韓国語は不要です。

3. 「ボランティア=短期のみ」という思い込み——長期滞在オプションの見落とし: F-1-Dデジタルノマドビザ(最長2年)+ボランティアの並行、KOICAヤングプロフェッショナルインターンシップ6〜12カ月、大学交換留学生ボランティアチームの1学期単位、いずれも可能です。ビザ条件は必ずKOICA・出入国管理事務所で個別に確認することをおすすめします。

🏢 機関別ディープガイド

1. KOICA(韓国国際協力団)

活動内容

  • 開発途上国向けODA事業の企画・実施・評価
  • 国内本部——城南 (Seongnam / 성남) 水井区——で事業企画・研究支援の役割
  • 国際開発協力教育プログラムの運営

参加方法(外国人向け)

  • KOICAヤングプロフェッショナル(Young Professional): 満20〜35歳、国際開発関連の専攻または経歴優遇。英文応募書類・面接。6〜12カ月インターンシップ。
  • KOICA市民社会協力室: 海外NGO・研究機関との協力MOU。機関単位での協力が可能。
  • 個人ボランティア: 公式ボランティアプログラムは主に韓国人対象。外国人はヤングプロフェッショナルルートを推奨。

費用: ヤングプロフェッショナル——所定のインターンシップ手当支給(金額は期別に異なる・応募時に確認)

申請: koica.go.kr → 採用/インターン公告 → 英文応募

アクセス: 城南市水井区大王板橋路825 / 地下鉄8号線 牡丹 (Moran / 모란) 駅から徒歩15分またはバス

ビザ: 短期観光ビザ(90日以内)で面接可能。インターンシップ確定時はD-2またはC-4ビザへの切り替えが必要——出入国管理事務所で個別に確認することを推奨。

2. UN韓国 — 仁川松島 (Incheon Songdo / 인천 송도) UNキャンパス

活動内容

  • 仁川延寿区松島に15以上の国連・国際機関が集積
  • 主要機関: UNESCAP・UNDP・WFP・UN Women・UNHCR・UNICEF・WHO WPROなど
  • 研修・カンファレンス・フェローシッププログラムを定期運営

参加方法(外国人向け)

  • UNインターンシップ: 各機関の公式サイトで個別公告。言語: 英語必須、一部フランス語優遇。
  • カンファレンス参加: 一部の公開イベントは事前登録で外国人も参加可能。UNESCAPのホームページで公開イベント日程を確認。
  • UNウィーク(毎年10月24日前後): 国連創設記念の公開イベント。参加費無料〜少額。

費用: インターンシップは無給(一部機関は所定の手当あり)。カンファレンス参加費は別途。

申請: unincheon.org / 各機関の公式採用ポータル(jobs.undp.orgなど)

アクセス: 仁川延寿区アートセンター大路 / 仁川空港鉄道+地下鉄1号線 国際業務地区駅から徒歩10分

外国人向け度: 英語公用環境・国際ネットワーク・韓国語不要。#193ヨーロッパ・#194アメリカマニア#1。

3. グッドネイバーズ (Good Neighbors / 굿네이버스)

活動内容

  • 国内社会福祉サービス+60カ国での海外開発事業
  • 児童支援・教育・給水・保健事業
  • 国内ボランティア: ソウル瑞草区本部・全国支部運営

参加方法(外国人向け)

  • ボランティアは英文で申請可能(gni.kr → Volunteerメニュー)
  • 短期ボランティア(1日〜数週間): 児童教育・イベント補助・翻訳サポート
  • 長期ボランティア: 協議のうえ決定

費用: 無料(ボランティア)。海外派遣プログラムは別途費用が発生。

言語: 英語でのやり取りが可能(国際協力室)。韓国語ができれば活動の幅が広がります。

申請: gni.kr または1365ボランティアポータルでグッドネイバーズのプログラムを検索

外国人向け度: 翻訳・通訳・グローバル教育活動で外国人ならではの強みを発揮できます。

4. 起亜対策(Korea Food for the Hungry International)・ワールドビジョン韓国

起亜対策の活動

  • 43カ国で児童・家庭・地域社会開発事業
  • 国内事務所: ソウル麻浦区
  • ボランティア: イベント補助・翻訳・広報サポート

ワールドビジョン韓国の活動

  • 国際NGOの韓国支部(ワールドビジョン本部=スイス・ジュネーブ)
  • 児童スポンサーシップ・災害救援・アドボカシー活動
  • 国内ボランティア: ソウル鍾路区本部・全国支部

参加方法(外国人向け)

  • 両機関とも1365ポータルまたは機関ホームページからボランティア申請が可能
  • 英語でのやり取りが可能かどうかは事前確認を推奨(国際チーム担当者にメールで問い合わせ)

費用: 無料(ボランティア)

申請: kfhi.or.kr / worldvision.or.kr

5. 1365ボランティアポータル(外国人の申請方法)

概要

  • 行政安全部運営の全国統合ボランティアプラットフォーム
  • 全国数千件のプログラムを検索・申請・実績管理

外国人の登録方法

1. 1365.go.krにアクセス

2. 会員登録 → 外国人登録番号で登録(外国人登録証が必要)

3. 地域・活動タイプ・日付を検索して申請

4. 実績が累積 → ボランティア確認書の発行が可能

注意: 外国人登録証(D-4・D-2など長期滞在ビザ所持者)がない場合、観光客の短期参加可否はプログラムごとに異なります。短期観光客は機関に直接問い合わせることを推奨。

言語: ポータルは韓国語が中心。英文案内は限定的——機関への直接連絡を並行することを推奨。

6. 寺院ボランティア — 真観寺 (Jingwansa / 진관사) ・海印寺 (Haeinsa / 해인사)

真観寺(ソウル銀平区)

  • ソウル市内の寺院・韓国伝統修行環境
  • テンプルステイ+ボランティアの融合プログラム
  • 外国人向けテンプルステイ: templestay.com(英文予約)
  • ボランティア活動: 清掃・供養・イベント補助。プログラムに含まれる場合と別途申請の場合あり。
  • 費用: テンプルステイ1泊₩80,000〜₩100,000(宿泊・食事込み)
  • アクセス: 地下鉄3号線 延新内 (Yeonsinnae / 연신내) 駅からバス乗り継ぎ20分

海印寺 — 慶尚南道陝川 (Hapcheon / 합천) 郡

  • 八万大蔵経のユネスコ世界記録遺産を保有する寺院
  • 長期ボランティア・修行プログラムを運営(1週間〜数カ月)
  • 外国人参加: 事前申請が必要。韓国語・英語対応可。
  • 費用: 無料〜少額(宿泊・食事提供プログラムあり・個別確認)
  • アクセス: 大邱東部ターミナル → 陝川行きバスで約1時間30分

外国人向け度: 英語対応可能なスタッフあり。韓国伝統文化体験+ボランティアの融合で#193・#367マニア#1。

7. 国際ワークキャンプ — SCI Korea・CCIVS

概要

  • SCI(Service Civil International)韓国支部: 2〜4週間の短期集中ボランティアキャンプ
  • 年間を通じて夏・冬シーズンのプログラムを多数運営
  • 全国の農村・都市・環境・文化財復元など多様なテーマ

参加方法(外国人向け)

  • SCI Korea公式サイト(scikorea.org)またはワークキャンプマッチングプラットフォーム(workcamp.org・workcampingkorea.or.kr)で検索・申請
  • 申請言語: 英語。韓国語不要。
  • 宿泊: ほとんどのプログラムに含まれる(ホスト機関が提供)

費用: 参加費₩100,000〜₩250,000(宿泊・食事込み)。航空券・交通費は別途。

ビザ: 短期観光ビザ(90日以内)で参加可能。滞在目的に合ったビザの確認を推奨。

外国人向け度: 英語公用・多国籍の参加者・宿泊込み=外国人にとって最適な入門ルート。

8. 大学ボランティアチーム — 延世 (Yonsei / 연세) ・高麗 (Goryeo / 고려) ・ソウル大

概要

  • 国内主要大学の交換留学プログラム+ボランティアチームの並行参加が可能
  • 延世大学国際処・高麗大学グローバルサービスラーニング・ソウル大学社会奉仕団が運営

参加方法(外国人向け)

  • 交換留学生の身分で在学中にボランティアチームへ参加可能
  • 一部の大学は在学生でない外国人のボランティアも受け入れ(国際処にメールで問い合わせ)
  • 活動: 多文化教育・環境・地域社会支援

費用: 無料(交通費の一部支援有無はプログラムごとに異なる)

申請: 各大学の国際処ホームページ・メール

外国人向け度: 英語でのやり取りが可能・多国籍な環境・ソウル拠点。交換留学と同時に進行可能。

❓ FAQ5つ

Q1. 観光ビザ(ビザなし入国)でボランティア活動は可能ですか?

短期無給のボランティアはほとんどの場合可能です。ただし、有給インターンシップ・雇用契約を伴う活動には適切な就労ビザが必要です。境界が不明確な場合は出入国・外国人庁(☎ 1345)への確認を推奨します。

Q2. 韓国語がまったくできなくても参加できるプログラムはありますか?

はい。KOICAヤングプロフェッショナル・UNインターンシップ・SCIワークキャンプ・寺院テンプルステイボランティア・グッドネイバーズ国際チーム・大学交換留学生ボランティアチームは英語で進行するか、英語でのやり取りが可能です。1365ポータルは韓国語中心なので、機関へのメール直接問い合わせを並行すればよいでしょう。

Q3. KOICAヤングプロフェッショナルはどの国籍でも応募できますか?

原則として国籍制限なく応募可能ですが、期別に募集条件が異なる場合があります。koica.go.krの公告文にある資格要件を必ず確認してください。

Q4. ボランティア実績証明書は発行してもらえますか?

1365ポータル登録活動の場合、累積時間に基づく確認書の発行が可能です。機関に直接ボランティアする場合は機関発行の確認書を依頼してください。KOICAヤングプロフェッショナルは終了後にインターンシップ修了証が発行されます。

Q5. 2〜4週間の短期滞在でも意味のあるボランティア参加は可能ですか?

SCI Koreaワークキャンプ(2〜4週間集中)、寺院ボランティア(3日〜1週間プログラム)、グッドネイバーズ・ワールドビジョンのイベント補助(1日単位)は短期滞在の外国人に最適です。機関と事前に協議してスケジュールを合わせることが重要です。
