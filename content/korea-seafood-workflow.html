한국 해산물 주문·조리·페어 워크플로우 — 통영 굴부터 마포 간장게장까지

부제: 외국인 관광객용 5-step + 4 조리법 + 페어·시기·영어 발화

ISSUE 03 · #874 · 2026-06-09

🎯 왜 한국 해산물 워크플로우 가이드인가

[#873 해산물 6종 매트릭스](#873) 알아도 — 주문·조리법·페어는 별개. 한국 해산물은 (a) 시장 정통 (통영·자갈치·소래포구·목포 1층 회판 2층 식당) (b) 횟집·전문점 (서울·강남·홍대) (c) 간장게장 전문점 (마포·강남) (d) MZ 새우장·꽃게탕. 조리법 = 회·찜·구이·국·간장양념 5가지. 외국인은 (1) 산낙지 = 천천히 씹기 모름 (2) 굴 = 생굴 vs 익힘 모름 (3) 간장게장 = 게장 손으로 먹기 모름 (4) 꽃게탕 = 가을 정통 모름. 본 가이드는 5-step + 조리법 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 시장 / 횟집·전문점 / 간장게장 / MZ 즉시 가성비·정통·매니아·트렌드 목적
2️⃣ 메뉴 주문 종·kg·1관 / 1인 / 1마리 1~5분 kg 단위 = 시장
3️⃣ 받기·세팅 회·찜·구이·국·간장양념 5조리법 10~30분 활어·생굴·익힘
4️⃣ 먹기·페어 초장·간장·소주·맥주 30~90분 산낙지 천천히
5️⃣ 결제 카드 OK / 시장 = 현금 일부 / 팁 X 1~5분 1/N 더치 OK

총 소요 시간: 시장 = 1~2h / 횟집 = 1.5~2.5h / 간장게장 = 1~2h / MZ = 1~1.5h

🦐 채널별 워크플로우

Type A — 시장 (통영·자갈치·소래포구·목포)

  • 시그니처: 활어 즉살·1층 회판 + 2층 식당
  • 시간: 시장별 (06:00~22:00)
  • 가격: kg 단위 + 식당 차림비 5,000~15,000원
  • 메뉴: 활어·생굴·산낙지·꽃게·대하
  • 외국인 친화도: ★★★★ (영문)

Type B — 횟집·전문점 (강남·홍대·이태원)

  • 시그니처: 정통 한 상·중급·고급
  • 시간: 17:00~24:00
  • 가격: 50,000~150,000원/1인
  • 메뉴: 회 + 매운탕 + 새우장 + 산낙지
  • 외국인 친화도: ★★★★ (영문)

Type C — 간장게장 전문점 (마포·강남)

  • 시그니처: 간장게장 #1·MZ 인스타·정통
  • 시간: 11:30~22:00
  • 가격: 30,000~80,000원/1인 (간장게장 한 마리)
  • 메뉴: 간장게장·꽃게탕·게장비빔밥
  • 외국인 친화도: ★★★★★ (글로벌 매니아)
  • 추천: 마포 게장 골목·강남 정통

Type D — MZ 새우장·꽃게탕 (홍대·강남·성수)

  • 시그니처: MZ 트렌드·새우장 인스타·간장 양념
  • 시간: 11:30~24:00
  • 가격: 25,000~50,000원/1인
  • 메뉴: 새우장·간장 게장 미니·MZ 변형
  • 외국인 친화도: ★★★★★ (MZ #1)

🍳 5조리법 매트릭스

조리법 시그니처 해산물 매니아
회 (Hoe·Live) 활어 회 + 산낙지 + 굴 활어 #1
찜·삶음 (Jjim) 꽃게찜 + 조개찜 + 새우찜 정통
구이 (Gui·Grill) 굴구이 + 대하 소금구이 + 오징어구이 가을 #1
국·탕 (Guk·Tang) 굴국밥 + 꽃게탕 + 낙지탕 해장·정통
간장 양념 (Jang) 간장게장 + 새우장 간장 매니아 #1

🌶 외국인 영어 발화 샘플

  • "활어 굴" = "Live oysters, please (생굴)"
  • "산낙지 천천히" = "Live small octopus — chew slowly! (질식 주의)"
  • "간장게장 1인" = "1 person serving of soy sauce crab"
  • "꽃게탕 매콤" = "Spicy blue crab stew, please"
  • "새우장" = "Shrimp in soy sauce (MZ trend)"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "굴 = 사계절": 굴 = 겨울 12~3월 #1·생굴 = 봄·여름 식중독 위험.

2. "산낙지 = 일반 회": 산낙지 = 살아있는 채로 잘게 잘라 천천히 (질식 위험).

3. "꽃게 = 1년 내내": 꽃게 = 가을 9~11월 #1 (간장게장 정통).

4. "간장게장 = 젓가락": 간장게장 = 손으로 까서 먹기·게장 비빔밥 OK.

5. "새우장 = 마늘 양념": 새우장 = 간장 양념 (마늘 양념 다름).

6. "통영 굴 = 일반": 통영 굴 = 남해 정통 #1 (생굴 12~3월).

7. "꽃게탕 = 매콤만": 꽃게탕 = 매콤 + 담백 둘 다 OK.

⚙ FAQ 8개

1. 첫 해산물 = 어떤 채널: 간장게장 전문점 (#1 매니아) → 통영 굴 (겨울).

2. 인스타·vlog: 마포 간장게장·통영 굴·서해 꽃게·목포 산낙지.

3. MZ 트렌드: 새우장·MZ 꽃게탕·간장게장 미니.

4. 간장게장 매니아: 마포 게장 골목·강남 정통.

5. 임신부: 생굴·산낙지 X·익힌 것 OK.

6. 알레르기: 갑각류·연체동물 사전 고지.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

해산물 = 식중독 주의 (특히 생굴 봄·여름)·산낙지 = 질식 위험. 임신부 = 익힌 것 OK·생굴·산낙지 X. 어린이 = 5세 이상 익힌 것. 알레르기 (갑각류·연체동물·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 갑각류·연체동물 = 할랄 일부 OK (저자별)·코셔 = X.
  • 채식·비건: 6종 비채식 / 채식 = 비빔밥·사찰음식.
  • 글루텐 free: 회·구이 OK / 간장 양념 = 글루텐 (Tamari 대체).
