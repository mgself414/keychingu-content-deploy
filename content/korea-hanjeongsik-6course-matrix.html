🎯 왜 한국 한정식 매트릭스인가

한정식(韓定食) = 한국 전통 코스 정찬 (Korean course meal) + 조선 궁중·반가 (양반 가문) 요리 전통.

외국인 한국 한정식 페인포인트 = "한정식이 너무 비싸고 메뉴 너무 많다". 한정식 = 한국 접대·격식·기념일 #1 + 글로벌 인지도 신라호텔 라연 미슐랭 3스타 (Seoul, 2017~연속). 같은 "Korean course meal"이라도 죽 (입맛 돋움)·전 (전채)·강 (메인)·탕 (국)·밥 (주식)·후식 (디저트) 6단계 정통 + 궁중 (Royal Court) vs 사대부 (Yangban Noble) 스타일 차이. 외국인은 (a) 코스 순서 모름 (b) 반찬 무료 무제한 모름 (c) 예약·드레스코드 모름 (d) 가격 (40,000~500,000원) 격차 이유 모름. 본 가이드는 6단계 코스 매트릭스 + 스타일별 + 외국인 입문 우선순위.

★ 한눈에 한정식 6단계 코스 매트릭스

단계 한국명·영문 메뉴 예시 의미·역할 외국인 친화도
1️⃣ 죽 (Juk) Porridge appetizer 잣죽·전복죽·호박죽 입맛 돋움·위 보호 ★★★★★ (#1 입문)
2️⃣ 전 (Jeon) Pancake appetizer 해물파전·녹두전·김치전 전채·반찬 시작 ★★★★★
3️⃣ 강 (Gang) Main course 갈비찜·불고기·잡채·구절판·궁중요리 메인 코스·핵심 ★★★★★
4️⃣ 탕 (Tang) Soup/stew 신선로·곰탕·미역국·맑은 탕 국·국물 ★★★★
5️⃣ 밥 (Bap) Rice + side dishes 흰밥·잡곡밥·죽순밥 + 반찬 12+종 주식·식사 마무리 ★★★★★
6️⃣ 후식 (Husik) Dessert 약과·수정과·식혜·과일·차 디저트·페어링 ★★★★★

6단계 = 한국 한정식 정통 코스 (간소화 매장 = 4~5 단계)

외국인 입문 1순위 = 6단계 풀 코스 (호텔 한식당 OR 인사동 한정식)

🏛 궁중 vs 사대부 vs 사찰 스타일

궁중 (Royal Court) 한정식

  • 시그니처: 조선 왕실 정통 요리·궁중요리 무형문화재
  • 메뉴 특징: 구절판·신선로·궁중떡볶이·궁중잡채·전유어 (전 모듬)
  • 분위기: 격식 ★★★★★·전통 의례
  • 추천 매장: 신라호텔 라연 (미슐랭 3스타) / 삼청각 / 궁중요리 전문점
  • 가격: 100,000~500,000원 (1인 코스)
  • 외국인 친화도: ★★★★★ (영문 메뉴·미슐랭)

사대부·양반 (Yangban Noble) 한정식

  • 시그니처: 조선 양반 가문 정통 한식
  • 메뉴 특징: 갈비찜·불고기·잡채·반찬 12+종 풀세트
  • 분위기: 격식 ★★★★ · 전통 한옥 多
  • 추천 매장: 인사동 한정식 cluster (한일관·미진)·전주 한옥마을 한정식·용수산 (1980 노포)
  • 가격: 40,000~150,000원
  • 외국인 친화도: ★★★★ (영문 메뉴 일부)

사찰음식 (Buddhist Temple)

  • 시그니처: 채식·할랄·코셔 가능·5훈채(파·마늘·부추·달래·흥거) 제외
  • 메뉴 특징: 채식 반찬·산채·두부·버섯·들기름·간장
  • 분위기: 한옥·사찰·정적
  • 추천 매장: 인사동 산촌 (사찰음식 노포)·진관사 템플스테이 식사·금당 (강남)
  • 가격: 30,000~100,000원
  • 외국인 친화도: ★★★★ (채식·할랄 인지)
  • 상세: #800 사찰음식

🍱 한정식 6단계 deep dive

1️⃣ 죽 (Juk) — 입맛 돋움

  • 종류:
  • 잣죽 (Pine nut porridge): 정통 궁중·부드러움
  • 전복죽 (Abalone porridge): 럭셔리·바다 향
  • 호박죽 (Pumpkin porridge): 가을 매니아
  • 녹두죽 (Mung bean porridge): 해독·시원
  • 흑임자죽 (Black sesame porridge): 한방·고소
  • 외국인 매니아: 잣죽 (#1 정통)
  • 추천 페어링: 김치 (시원·아삭)

2️⃣ 전 (Jeon) — 전채·반찬 시작

  • 종류:
  • 해물파전 (Seafood scallion pancake): 정통 #1
  • 녹두전 (Mung bean pancake): 광장시장 정통
  • 김치전 (Kimchi pancake): 가장 친근
  • 호박전 (Pumpkin pancake): 채식
  • 전유어 (Modeumjeon, 모듬전): 6+종 어울림
  • 궁중 전유어 (Royal): 약과식·격식
  • 외국인 매니아: 해물파전 (페어링 막걸리)
  • 추천 페어링: 막걸리·청주

3️⃣ 주요리 (Juyori, 主菜) — 메인 코스

  • 종류:
  • 갈비찜 (Braised short ribs): 정통 #1·달콤·부드러움
  • 불고기 (Bulgogi): 글로벌 인지도 #1
  • 잡채 (Japchae): 외국인 친화 채식
  • 구절판 (Gujeolpan): 궁중 정통·9 칸 모둠
  • 궁중떡볶이 (Royal tteokbokki): 간장 양념 정통
  • 신선로 (Sinseollo, royal hot pot): 국가무형유산 "조선왕조 궁중음식"(제38호, 1970 지정) 대표 메뉴
  • 궁중잡채 (Royal japchae)
  • 외국인 매니아: 갈비찜 + 불고기 (#1 입문)
  • 추천 페어링: 청주·소주

4️⃣ 탕 (Tang) — 국

  • 종류:
  • 신선로 (Sinseollo): 궁중 hot pot·약초 풀세트
  • 곰탕·설렁탕: 정통 노포 cross
  • 미역국 (Miyeokguk): 생일·산모 정통
  • 맑은탕 (Malgeun-tang): 해산물 정통 (매운맛 X) / 매운탕 (Maeun-tang): 매운맛 해산물
  • 어글탕 (Eogeul-tang): 사찰 채식
  • 외국인 매니아: 신선로 (궁중 정통)

5️⃣ 밥 (Bap) — 주식

  • 종류:
  • 흰밥 (White rice): 기본
  • 잡곡밥 (Multi-grain): 한방 보양
  • 돌솥비빔밥 (Dolsot bibimbap): 외국인 vlog #1
  • 궁중밥 (Royal rice): 정통
  • 반찬 12+종: 김치·깍두기·나물·전·구이·찜
  • 외국인 매니아: 돌솥비빔밥 + 반찬 풀세트

6️⃣ 후식 (Husik) — 디저트

  • 종류:
  • 약과 (Yakgwa): 궁중 정통 디저트
  • 수정과 (Sujeonggwa): 계피 + 생강 차
  • 식혜 (Sikhye): 쌀 발효 단 음료
  • 국화차·녹차: 차 페어링
  • 계절 과일: 사과·배·감
  • MZ 트렌드: 약과 라떼·약과 크루아상
  • 외국인 매니아: 약과 + 수정과 (#1 정통)

⚠ 외국인 자주 실수 5가지

1. "한정식 = 비싸기만": 인사동·전주 한정식 = 1인 40,000원~ 가성비 코스. 호텔만 100k+.

2. "6단계 = 같이 나옴": 6단계 = 순서대로 서빙 (죽 → 전 → 강 → 탕 → 밥 → 후식). 1~2h 식사.

3. "반찬 = 1회 제공": 한정식 반찬 = 무료 무제한 리필 (한식당 표준).

4. "예약 X = OK": 신라 라연·삼청각 = 1~2주 전 필수 예약. 인사동 한정식 = 주말 권장.

5. "드레스코드 X": 호텔 한식당 = smart casual 권장. 인사동·전주 = 자유.

⚙ FAQ 8개

1. 외국인 입문 1순위: 인사동 한정식 (가성비 ★) → 호텔 라연 (럭셔리 ★★★★★) 단계.

2. 인스타·vlog: 신라 라연 (미슐랭)·삼청각·인사동 한옥 한정식.

3. 데이트·기념일: 신라 라연·롯데호텔 한식당·삼청각.

4. 접대·비즈니스: 신라 라연 (#1) + 호텔 한식당 + 삼청각.

5. 예약: 신라·롯데 = 1~2주 전 / 인사동 = 주말 권장.

6. 알레르기: 해산물·소·돼지·계란·견과류 사전 고지.

7. 채식·할랄·코셔: 사찰음식 한정식 (#800) 또는 채식 한정식.

8. VAT 환급: 식음료 일반 환급 X / 호텔 = 봉사료 10% + 부가세 10%.

⚠ 의료·안전·식이 disclaimer

한정식 = 6단계 코스 식사 (1~2h). 임신부·면역저하 = 익힌 메뉴 권장 (회·생선회 코스 회피). 알레르기 (해산물·소·돼지·계란·견과류·꿀) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 한정식 = 비할랄. → 사찰음식 한정식 [#800] (채식·할랄 가능).
  • 채식·비건: 사찰음식 OR 채식 한정식 사전 요청 (잡채·전·찌개 채식 옵션).
  • 글루텐 free: 한정식 양념 (간장·고추장) 多. 사전 매장 확인.

💰 Essential Tourist Tips

  • 1인 평균 비용 (2026년 6월 기준):
  • 인사동·전주 한정식 = 40,000~80,000원
  • 사대부·양반 한정식 = 60,000~150,000원

  • 결제·팁:

  • 호텔 = 봉사료 10% + 부가세 10%
