🎯 本指南的使用方法

拿着空玻璃瓶爬上楼梯,把洗发水按需要的量装进去 — 这就是麻浦 (Mapo / 마포) 望远洞 (Mangwon-dong / 망원동) Almang商店 (Almang Shop / 알맹상점) 的补充装站(Almang商店官方网站)。本指南写给希望旅行时尽量少留下垃圾和碳排放的人。不涉及国家层面的统计或排名,只挑出游客今天就能做的事,分成四类: 骑公共自行车(首尔 Ddareungi (Ddareungi / 따릉이)·大田 Tashu (Tashu / 타슈))、带容器去补充装商店(Almang商店 (Almang Shop / 알맹상점))、逛逛再生利用空间(首尔再生利用广场 (Seoul Upcycling Plaza / 서울새활용플라자))。住宿垃圾分类和街头垃圾已整理成另外的文章并附上链接。这里的数值只写2026-10-21当天在运营机构官方网站上亲自打开确认过的内容。

🚲 公共自行车 — 首尔·大田

  • 首尔共享单车 (Ddareungi / 따릉이) (首尔自行车) — 由首尔市运营。当日票为1小时票1,000韩元·2小时票2,000韩元·3小时票3,000韩元。首次租赁后,只要在基本时间(60·120·180分钟)内归还,当天可不限次数再次租赁。超过基本时间每5分钟加收200韩元,租赁后4小时内未归还则视为被盗并报警处理。支付方式有手机·信用卡·PAYCO·KakaoPay·ZeroPay,以及Discover Pass(外国人专用)。运营中心 1599-0120(全年365天24小时)(首尔自行车官方网站)
  • 定期票(7·30·180·365天)仅限会员(首尔自行车官方网站)
  • 所有租赁点都可借还,但根据自行车种类,可归还的车桩形式(LCD型·QR型)不同,官方有此说明(首尔自行车官方网站)
  • Tashu (Tashu / 타슈) (大田) — 大田市公共自行车。年满15周岁,租赁时间05~24时(3~11月旺季为24小时),归还24小时。基本1小时免费,超出后每30分钟500韩元,每天每次的额外费用最高5,000韩元。1小时内归还后再次租赁,可不加收额外费用继续骑行(Tashu官方网站)。外国人的注册流程未能确认
  • 骑行路线请参考 韩国骑行步道指南

🫙 补充装商店 — Almang商店 (Almang Shop / 알맹상점) 望远店

  • Almang商店 (Almang Shop / 알맹상점) 望远店 — 首尔麻浦区 (Mapo-gu / 마포구) 世界杯路25街 (Worldcup-ro 25-gil / 월드컵로25길) 47号,3层。周二至周日12:00~20:00,周一休息,不可停车(Almang商店官方网站)
  • 可以做什么: 化妆品·洗涤剂·食材等,按自己带得走的量补充。Almang商店 (Almang Shop / 알맹상점) 自称"国内首家补充装站"(Almang商店官方网站)
  • 其他: 设有垃圾回收活动·零废弃教育·讲解员申请菜单(Almang商店官方网站)。具体接收哪些品类这次没有打开确认 — 到访前请查看网站的"垃圾回收"菜单
  • 支付: 也出售预付礼券(Almang商店官方网站)。是否可刷卡在官方页面未能确认
  • 如果行李里没有空容器,可以把在住宿处用完的小瓶子冲洗干净带去

♻ 再生利用空间 — 首尔再生利用广场 (Seoul Upcycling Plaza / 서울새활용플라자)

  • 首尔再生利用广场 (Seoul Upcycling Plaza / 서울새활용플라자) — 首尔城东区 (Seongdong-gu / 성동구) 汽车市场街 (Jadongchasijang-gil / 자동차시장길) 49号。周一至周六10:00~18:00,周六仅限预约参观者入场。每周日及春节·中秋连假闭馆。总机 02-2153-0400(0401)。由首尔设计财团 (Seoul Design Foundation / 서울디자인재단) 运营(首尔再生利用广场官方网站)
  • 目前正在进行: 截至2026-10-19的公告,网站上有资源循环市民活动"与爱丽丝同行的生态仙境"以及DDP设计商店"K-UP快闪店"的运营通知(首尔再生利用广场官方网站)。活动日期和地点请在公告正文中确认

⚠ 常见的4个错误

1. "首尔共享单车 (Ddareungi / 따릉이) 1小时票一次就能骑一整天" — 必须在60分钟内归还后再次租赁,如此反复。超出后每5分钟加收200韩元(首尔自行车官方网站)

2. "自行车晚还只要多付钱就行" — 首尔共享单车 (Ddareungi / 따릉이) 租赁后4小时未归还会被视为被盗(首尔自行车官方网站)

3. "周末随时都能去再生利用广场" — 周日闭馆,周六仅限预约参观者入场(首尔再生利用广场官方网站)

4. "补充装商店周一也营业" — Almang商店 (Almang Shop / 알맹상점) 望远店周一休息(Almang商店官方网站)
