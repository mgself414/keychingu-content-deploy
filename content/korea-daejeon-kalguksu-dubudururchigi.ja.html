🎯 なぜ大田老舗食品ガイドなのか

大田= 韓国5大広域市+老舗マニアマトリックス。シグネチャー＝ 大田式カルグクス（アンチョビ＋パンツ）・豆腐まぶた（大田老舗シグネチャー）・肋骨屋。外国人ペインポイント＝（a）大田カルグクス＝ソウル（チキンカルグクス）・大邱（西門カルグクス）と他のマトリックス（アンチョビ+パンツロックシグネチャー） (e) 英語メニューの一部・決済カード・ピックアップOK。

＃＃🍜大田剣麺ディープ（アンチョビ+パンツ）

シグネチャ

  • ソウルカルグクス：チキンカルグクス（チキンスープ）
  • 大邱カルグクス：序文カルグクス（アンチョビ+綿）
  • 大田剣麺: アンチョビ+パンツ+綿 = 大田単独マトリックス

外国人ペインポイント

  • "カルグクス=すべて同じ"間違った認識・3大広域時異なるマトリックス
  • パンツ（貝） = 外国人アンマコム・シーフードマニアfit
  • 価格: 6,000~12,000ウォン/ボウル・ソウル 8,000~14,000ウォンに比べてコスパ

###マニアフェア

  • カール麺+ 豆腐しゃぶり =大田老舗フルセット
  • カルグクス+マッコリ=マニア
  • カルグクス+キムチ=韓国標準

🍳 豆腐まぶた deep (大田単独シグネチャー)

シグネチャ

  • 名称: 豆腐 + ツルチギ（味付け炒め）
  • 材料: 豆腐+豚(またはキムチ)+味付け(コチョウ粉・醤油・ニンニク)
  • 分類: 大田老舗単独シグネチャー・ソウル・釜山・大邱X
  • 由来: 1970年～大田鈍山・流星老舗開始

外国人ペインポイント

  • 「豆腐=一般豆腐料理」誤認識
  • 豆腐+マッコム+豚=大田マニアマトリックス
  • 外国人親和性: ★★★ (マコム・マニアマトリックス)
  • 価格: 12,000~22,000ウォン/2-3人用

###マニアフェア

  • 豆腐咀嚼+ マッコリ =韓国 #1マニアフェア ([#687 cross](#687))
  • 豆腐まぶた+米=韓国標準
  • 豆腐しゃぶり+キムチ=マコム・シコマトリックス

＃＃⚠外国人の頻繁な誤り5つ

1. "カルグクス=すべて同じ": ソウル(鶏) vs タラ(アンチョビ) vs 大田(アンチョビ+パンツ) 他のマトリックス。

2. 「豆腐刈り込み＝一般豆腐」：大田老舗単独シグネチャー・1970年～・他都市X。

3. "マッコリペア=キムチジョンマン": 豆腐叩き+マッコリ=大田マニアマトリックス・ミシュランフェア([#688 cross](#688))。

4. "カルビ=ソウル・釜山と同じ": 流星カルビハウス= 5城ホテル cluster・斗山=外国人フレンドリー・英語メニュー。

5. 「清国章・スンドゥブ＝外国人X」：チョングクジャン＝韓国マニアマトリックス・外国人の呼び声（強い臭い）・スンドゥブ＝外国人にやさしい#1。

⚙ FAQ 6個

1. 外国人入門1順位: 大田カルグクス + 豆腐まぶた + カルビ + マッコリペア。

2. 大田カール麺正確な位置：大田駅近隣・鈍山・流星老舗cluster・50年+シグナー店のおすすめ。

3. 豆腐まぶたマッコリフェア: 韓国#1マニアマトリックス・鈍山・流星老舗店。

4. カルビ vs カルグクス: カルビ=マニア+マトリックス(50,000~120,000ウォン/2人) / カルグクス=苛性比(6,000~12,000ウォン)。

5. アレルギー: パンツ = 甲殻類 アレルギー・豆腐 = 豆アレルギー・カルビ = 牛・豚・醤油（大豆）アレルギー。

6. おすすめペルソナ: 家族・シニア = カルグクス + 肋骨 / MZ・マコムマニア = 豆腐まぶた + マッコリ / マニア = 老舗フルセット。

⚠医療・安全・食事ダイエット

大田カルグクス・豆腐しゃぶり = 塩分・マコム + 一部アレルゲン（甲殻類・豆・牛・豚・エビ）。妊婦・高血圧・腎臓患者＝頻度注意。アレルギーの予告が必要です。食中毒・腹痛☎1339。

食事制限：

  • ハラール・コーシャー：豆腐まぶた（豚）＝ビハラル・カルビ＝ビハラル/カルグクス＝一部OK・ベジタリアンオプションOK店舗一部
  • ベジタリアン・ビーガン：カール麺（パンツXオプション）・豆腐まぶた（豚Xオプション）＝店舗一部・事前要請推奨
  • グルテンフリー: カルグクス＝グルテン含有（小麦粉）・豆腐まき・カルビ＝OK多
