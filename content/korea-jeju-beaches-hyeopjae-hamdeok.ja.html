🎯 このガイドの使い方

済州島のビーチは、海水浴場の開場期間(2026年 6/24〜9/6)とそれ以外の季節でまったく違います。開場期間中は遊泳時間(10:00〜19:00)・安全要員・有料のパラソルがありますが、10月以降は泳げないものの、砂浜・海岸の散歩道・夕日はそのままです。以下の数値は2026-10-08に済州観光公社 (Jeju Gwangwang Gongsa / 제주관광공사) の visitjeju.net と西帰浦市 (Seogwipo-si / 서귀포시) の公式ページで確認できたものだけを載せ、公式にないバス番号・シャワー室の料金・中文穡達/梨湖テウの開場期間は「未掲示」としています。以前のガイドにあった「挾才は24時間無料」(砂浜は開いていますが、遊泳は時間制・レンタルは有料)、「6〜8月がシーズン」、「5つ星ホテル20万〜60万」「サーフィン3万〜8万」といった数値は公式と異なるため外しました。

🏖 挾才・咸徳 — 西と東の二大ビーチ

  • 挾才(翰林 (Hallim / 한림)): エメラルド色の浅い海、正面に飛揚島。2026年の開場は6/24〜9/6、遊泳は10〜19時、7/15〜8/15は21時まで(公式)。パラソル 20,000ウォン・平床 30,000ウォン。飛揚島行きの船は挾才ではなく翰林港から出ます。
  • 咸徳(朝天 (Jocheon / 조천)): 開場期間・時間は同じで、夜間遊泳なし(公式)。隣の犀牛峰の散歩道 2.5km は無料 — 照明のない区間があるので、日が暮れる前に。
  • どちらも入場は無料で、駐車場・シャワー室の料金は公式に未掲示です。

🏄 中文穡達 — サーフィンと滝

  • 西帰浦の中文観光団地 (Jungmun Gwangwang Danji / 중문관광단지) の中にあります。無料、駐車152台、約560m、4色の砂、シャワー室・更衣室・売店・キャンプ場(公式)。6〜7月に国際サーフィン大会。2026年の開場期間は公式ページになく、報道では他の海水浴場と同じとされています。
  • 歩いて行ける天帝淵の滝(09:00〜17:50、大人 2,500ウォン)・柱状節理帯(09:00〜17:50、駐車無料)とセットで回ります。
  • 済州空港 (Jeju Gonghang / 제주공항) からリムジンバス600番が中文観光団地を経由して西帰浦のKALホテルまで、18〜20分間隔で運行(公式)。

✈ 梨湖テウ — 空港のすぐ隣

  • 済州市トリ路 20、馬の形の灯台で知られるビーチ。2026年の開場期間・時間は公式に未掲示。フライトまで中途半端に時間が空いたときに立ち寄る場所です。

🍂 10月以降 — 泳がずに

  • 開場が終わると安全要員もパラソルもなくなり、遊泳はしません。その代わり、挾才の夕日・咸徳の犀牛峰・中文の滝・柱状節理帯はそのままです。風が強いので帽子とウインドブレーカーを。

🚌 行き方

  • 空港 → 中文: リムジンバス600番(公式)。挾才・咸徳行きの路線バスの番号は公式ページにないため記載しません — 地図アプリで確認を。
  • 東(咸徳)・西(挾才)・南(中文)は互いに遠く離れています。1日に2カ所以上まわると移動が長くなります。

⚠ よくある失敗5つ

1. 9月中旬に泳ぐ — 2026年は9/6で開場終了。

2. 咸徳で夜に泳ぐ — 夜間遊泳はありません。夏の1カ月だけ21時までなのは挾才のみ。

3. 挾才から飛揚島行きの船に乗る — 翰林港から出ます。

4. 夕暮れ時に犀牛峰へ登る — 照明のない区間があります。日が暮れる前に下山。

5. 4つのビーチを1日で回る — 東・西・南の移動が長くなります。

⚙ FAQ 6つ

1. 今年のシーズンは? — 6/24〜9/6、遊泳は10〜19時(挾才は7/15〜8/15 が21時まで)。

2. 入場料は? — 無料。パラソル 20,000ウォン・平床 30,000ウォン。

3. サーフィンは? — 中文穡達(無料・駐車152台)。レッスン料は公式に未掲示。

4. 滝の料金は? — 天帝淵 大人 2,500ウォン、09:00〜17:50。

5. 飛揚島は? — 翰林港から1日約4便、15分。天候により欠航。

6. 空港からすぐ行けるビーチは? — 梨湖テウ。中文へはリムジンバス600番。
