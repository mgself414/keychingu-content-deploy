⚠ 外国人がよくする間違い3つ

1. 「漢江屋外プール (한강수영장) = 川で泳ぐ」 — 屋外プールであることを知らない

外国人が "swim in Hangang River" と検索し、川で泳ぐものだと思って服のまま漢江 (한강) に入ろうとすることがあります (危険・法律で禁止)。実際の漢江屋外プール (한강수영장) は漢江公園 (한강공원) の隣にある屋外プール (浄水処理されたプール)で、7月～8月に無料で運営されます。漢江 (한강) 本流への立ち入りは安全上の理由から禁止されています。"Hangang outdoor swimming pool" と英語で検索するのが正確です。パンポ (반포)・トゥクソム (뚝섬)・ヨイド (여의도)・チャムシル (잠실)・クァンナル (광나루) の5か所で運営されており、詳しい運営期間はソウル市 (서울시) 公式サイトで確認してください。

2. 「ウォーターパークは同じ」 — 韓国4大ウォーターパーク (워터파크) の違いを知らない

外国人が「カリビアンベイ (캐리비안베이) しか知らず」に行って、値段が高いと不満を言うことがあります。実際の韓国のウォーターパーク (워터파크) は4種類あります:

  • カリビアンベイ (캐리비안베이) (₩60,000+) = 韓国最大、外国人認知度1位、7月～8月は1時間待ち
  • ロッテウォーターパーク (롯데 워터파크) (₩50,000) = 金海 (김해) (釜山 (부산) 圏域)、釜山旅行 (부산 여행) と組み合わせ可能
  • ウンジンプレイ都市 (웅진플레이도시) (₩40,000~55,000) = ソウル都心 (서울 도시) に近い、コスパが良い
  • オーシャンワールド (오션월드) (₩55,000~70,000) = 江原道 (강원도) 洪川 (홍천)、自然の風景 + スキーシーズンと組み合わせ可能
  • 選択ルール: コスパ重視ならウンジンプレイ都市 (웅진플레이도시) / 外国人向けフルセットならカリビアンベイ (캐리비안베이) / 釜山 (부산) と組み合わせるならロッテウォーターパーク (롯데 워터파크) / 自然を楽しむならオーシャンワールド (오션월드)

3. 「東海 (동해) と西海 (서해) = 同じ海」 — 違いを知らずに間違った選択をする

東海 (동해) (江陵 (강릉)・束草 (속초)・釜山 (부산)) = 澄んだ水・サーフィン・砂浜 (sand beach) / 西海 (서해) (ウルワンニ (을왕리)・仁川 (인천) 永宗島 (영종도)) = 干潟・夕日・水深が浅い。外国人が "Seoul nearest beach" と検索するとウルワンニ (을왕리) (西海 (서해)) が1位に表示されます — 仁川空港 (인천공항) の隣で1.5時間。しかし、砂浜 (sand beach) を期待する外国人にはがっかりするかもしれません (干潟が中心)。"Korean beach with clean water" = 東海 (동해) (江陵 (강릉)・釜山 (부산)) で、KTX で2～3時間かかります。初めて韓国を訪れる際は、事前に移動ルートを考慮してください。

  • 位置: 京畿道 (경기) 龍仁 (용인) エバーランド (에버랜드) (地下鉄盆唐線 (분당선) + シャトルバスまたは江南駅 (강남역) 直行バス)
  • 価格: 1日終日券 ₩60,000~75,000 (シーズン変動、エバーランド (에버랜드) コンボ +₩30,000)

  • シグネチャー: 韓国ウォーターパーク (워터파크) で世界1位。外国人Vlog・インスタでの露出が圧倒的。波のプール・チューブスライダー・アクアループ多数

外国人フレンドリー tip

1. 言語: カリビアンベイ (캐리비안베이)・ロッテウォーターパーク (롯데 워터파크)・海雲台 (해운대)・江陵 (강릉) = 英語OK。漢江屋外プール (한강수영장)・ウンジンプレイ都市 (웅진플레이도시)・ウルワンニ (을왕리) = 韓国語中心、Papagoを活用

2. 予約:

  • ウォーターパーク (워터파크) = シーズンピーク (7月～8月週末) はオンライン予約必須、平日は即時入場可能
  • KTX = SRT・KORAIL 公式アプリ (英語対応)、2～3日前予約推奨
  • 飛行機 = ジンエアー (진에어)・チェジュ航空 (제주항공)・ティーウェイ (티웨이) などのLCCが60～80%安い (外国人決済OK)

3. 決済: ウォーターパーク (워터파크)・KTX・飛行機 = カード100% / 漢江屋外プール (한강수영장) = 無料 / ビーチのレストラン = 一部現金

4. 水着: 漢江屋外プール (한강수영장) は水着必須 (半ズボン・普段着での入場X)。ウォーターパーク (워터파크) は施設内で購入可能 (外国人が高値で買うパターン → 事前購入推奨)

5. 紫外線対策: 韓国の夏は紫外線が強いので、SPF50+必須。コンビニエンスストア (편의점)・オリーブヤング (올리브영) で₩3,000~15,000

6. 浮き輪・浮き輪バッグ: 漢江屋外プール (한강수영장) は自身の浮き輪OK、ウォーターパーク (워터파크) は入場料に含まれるか、別途レンタルで₩5,000~10,000

7. ホテル: 釜山 (부산)・江陵 (강릉)・済州 (제주) = 外国人フレンドリーなホテル多数 (Booking.com・Agoda)。7月～8月シーズンは1週間前までの予約必須

8. ハラール・ヴィーガン:

  • ウォーターパーク (워터파크) 内のレストラン = 一般的な韓国料理 (한식)・チキン・ラーメン中心、ハラール・ヴィーガンオプションは限定的
  • ビーチ都市 (釜山 (부산)・江陵 (강릉)・済州 (제주)) = ハラール・ヴィーガンレストランが1～3軒 (Booking.comで検索)
  • #202 ヴィーガン・ハラールガイド (비건・할랄 가이드) 参照
