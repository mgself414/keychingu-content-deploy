> サブ: 外国人観光客用5色本格+全州韓屋村・石釜・セルフビビンバ・山菜・海鮮（UNESCO無形遺産cluster）

ISSUE 03・#879・2026-06-09

🎯 なぜ韓国ビビンバマトリックスなのか

外国人韓国ビビンバペインポイント="ビビンバ=一つ"知って全部同じだと思う。韓国ビビンバ= 5色ハーブ+ 5種類の変形マニア。同じ「Korean Bibimbap」でも全州（正統#1・宮中・UNESCO）・石鍋（Stone pot・熱・カリカリ）・セルフ（MZ・DIY）・山菜（査察食品cluster）・海鮮（回cluster cross）それぞれ異なる変形・マニア。外国人は（a）5色ハーブフルセットモルト（b）石鹸=熱さ+サクサクモルム（c）セルフビビンバ= MZモルト（d）サンチェ＝ベジタリアン本ガイドは5種マトリックス+5色+変形マニア。

🥬 5種 deep dive

🥬 全州ビビンバ (Jeonju Bibimbap) — 本物の#1

  • シグネチャー: 5色正統・宮中 + UNESCO無形遺産・韓屋村
  • 材料：5色ハーブ（ほうれん草、ニンジン、もやし、シダ、キキョウ）+卵+コチュジャン+ゴマ油・牛肉（オプション）
  • 外国人親和性: ★★★★★ (#1 本物・UNESCO)
  • おすすめストア:
  • 全州韓屋村ビビンバ老舗 — 本格#1
  • ソウル全州式ビビンバハウス（江南・弘大） - コソンビ
  • 時期: 四季・正統
  • 価格: 全州韓屋村 = 12,000~25,000ウォン / ソウル = 8,000~20,000ウォン
  • UNESCO無形遺産: 宮中料理 cluster登載 (2023)

🍲 石鍋ビビンバ (Dolsot Bibimbap) — グローバル #1

  • シグネチャー: 暑さ+サクサクヌルジ（最下）・寒い日マニア
  • 材料: 5色ハーブ+卵+コチュジャン+ 石鍋(stone pot)・サクサクヌルジ(最下)
  • 外国人親和性: ★★★★★ （グローバル#1・暑さ人気）
  • おすすめ店舗: 限定食・MZ韓国料理店・チェーン(ハン釜など)
  • 時期: 四季・冬 #1
  • 価格：10,000〜22,000ウォン
  • 注意: 石釜 = 非常に熱い (注意・皿受けを使用)

🥄 セルフビビンバ (Self Bibimbap・DIY) — MZ #1

  • シグネチャー: DIY・MZインスタ #1・材料選択
  • 材料：ご飯＋ハーブ8～12種（選択）＋味付け・卵・肉（選択）
  • 外国人親和性: ★★★★ (MZ #1・DIY)
  • おすすめストア:
  • MZセルフビビンバ店（弘大・江南・ソンス） - トレンド
  • セルフ韓国料理ビュッフェ - コスパ
  • 価格：8,000〜18,000ウォン/ 1人（セルフ無限詰め替え）

🌳 山菜ビビンバ (Sanchae Bibimbap) — ベジタリアン #1

  • シグネチャー: 査察食品 cluster cross・春山菜・菜食・ハラル #1
  • 材料: 5～8種の山菜（酔・シダ・ドラジ・ミナリなど）＋卵（選択）＋味噌味付け
  • 外国人親和性: ★★★★ (菜食・ハラール#1)
  • おすすめストア:
  • 陳関寺 ([#876](#876)) — 査察料理本格#1
  • 江原・全羅山菜ビビンバ屋 — 春本物
  • 時期: 春3～5月 #1・年中
  • 価格：査察食品コース25,000〜80,000ウォン/山菜屋10,000〜25,000ウォン

🦐 海鮮ビビンバ (Haemul Bibimbap) — シーフード cross

  • シグネチャー: 会・シーフードcluster cross・チャガルチ・統営本格
  • 材料: 5色ハーブ+灰・シーフード
  • 外国人親和性: ★★★ (シーフードマニア)
  • おすすめ店舗: チャガルチ・統営・江南会集・MZ韓国料理店
  • 価格：15,000〜40,000ウォン/ 1人

  • バランス・健康・本物

＃＃⚠外国人の頻繁な誤り5つ

1. "ビビンバ=一つ"：ビビンバ=5つの変形（全州・石釜・セルフ・山菜・海鮮）。

2. 「全州＝一般」：全州＝UNESCO無形遺産本格（5色・宮中）。

3. "石鍋 = 一般鉢": 石鍋 = 非常に熱い・サクサクの飢饉（最下）。

4. "セルフ=苛性肥満": セルフ=MZインスタ#1・材料フルセット。

5. "山菜=ベジタリアンのみプール": 山菜=査察食品cluster +春山菜・本格。

⚙ よくある質問8件

1. 外国人入門1順位: 全州(正統)+石釜(グローバル)→セルフ(MZ)。

2. インスタ・vlog: 全州韓屋村・石釜熱いvlog・セルフDIY。

3. MZトレンド：セルフビビンバ（#1）・石釜。

4. ベジタリアン・ハラール: 山菜ビビンバ(#1) + お寺料理。

5. 石釜注意: 非常に熱さ・皿受けの使用・子供注意。

6. アレルギー: 卵・シーフード・ニンニク・醤油グルテン事前告知。

7. 決済・チップ: カードOK/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

ビビンバ＝一般食品。妊婦・子ども＝OK（石釜熱気注意）。アレルギー（卵・シーフード・ニンニク・醤油グルテン）事前告知。石釜火傷注意。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：山菜・電柱＝OK（牛肉を除く）/海鮮＝甲殻類X/セルフ＝自由選択。
  • ベジタリアン・ビーガン：山菜 = #1 / 5色 = 卵オプション / シーフード = 非菜食。
  • グルテンフリー：醤油・コチュジャン調味料=グルテン（タマリ代替）。
