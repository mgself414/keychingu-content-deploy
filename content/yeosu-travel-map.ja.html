🎯 このガイドの使い方

麗水の主役は夜です — 突山大橋のライトアップ、亀船大橋の下の浪漫ポチャ通り、海の上のケーブルカー。昼は梧桐島の椿の林とアクアプラネット、少し足を延ばして向日庵。以下の時間・料金・住所は、2026-10-08に麗水市文化観光ページとアクアプラネットの公式サイトで確認した値だけを載せています。海上ケーブルカーの公式サイトは証明書エラーで開けなかったため、料金・時間は記載しません(二次情報の数値は載せていません)。現在は2026麗水世界島博覧会(9/5〜11/4)が開催中で、宿泊も交通も普段より混み合います。以前のガイドにあった「韓国No.1の夜の海」「訪韓外国人の5%以上」「1人8万〜50万ウォン」といった数値や、2012年エキスポ施設の紹介は、出典がないか現在の運営が確認できないため外しました。

🌃 夜 — 浪漫ポチャ通り・ハメル灯台・突山大橋

  • 浪漫ポチャ通り (Nangman Pocha Geori / 낭만포차 거리)(ハメル路102): 亀船大橋の下、屋台18軒、18:00〜01:00、カード決済可(麗水市公式)。毎月第1水曜日は休み — ただし4〜6月・8〜10月と連休期間は休みません。悪天候時は休業です。二次情報にある「冬は17〜24時」は公式と異なるため載せていません。
  • ハメル灯台 (Hamel Deungdae / 하멜등대)(ハメル路96): 無料、通年。ポチャ通りから歩いて行けます。
  • 突山大橋 (Dolsan Daegyo / 돌산대교): 夜間ライトアップは約50色(公式)。点灯時間は未掲示です。

🌳 昼 — 梧桐島・アクアプラネット

  • 梧桐島 (Odongdo / 오동도): 無料、屋外は24時間。駐車場から防波堤沿いに徒歩約15分、または梧桐島椿列車 (Odongdo Dongbaek Yeolcha / 오동도 동백열차) で片道1,000ウォン(3〜10月 09:30〜18:00・11〜2月は〜17:00、12〜13時は休憩)。市街地から車で約10分(公式)。麗水エキスポ駅 (Yeosu Expo / 여수엑스포역) からの徒歩時間は公式に未掲示です。
  • アクアプラネット麗水 (Aqua Planet Yeosu / 아쿠아플라넷 여수)(梧桐島路61-11): 毎日09:30〜19:00、発券締切18:00、年中無休。大人37,900・青少年/シニア34,900・子ども32,900ウォン(公式)。

🚡 ケーブルカー・鎮南館・向日庵 — 確認できなかったこと

  • 麗水海上ケーブルカー (Yeosu Haesang Cable Car / 여수해상케이블카): 突山公園 (Dolsan Gongwon / 돌산공원) ↔ 紫山公園 (Jasan Gongwon / 자산공원) 1.5km、キャビン50台(一般35・クリスタル15)までは麗水市の公式情報です。運営会社のサイトが開けないため、時間・料金・休みは未確認です — 現地のチケット売り場か運営会社に電話で確認してください。

  • 麗水世界島博覧会2026 (2026 Yeosu Segye Seom Bangnamhoe / 2026 여수세계섬박람회) の公式日程は2026-09-05〜11-04です(麗水市)。この期間は先に宿を押さえ、週末のポチャ通りは行列を覚悟してください。

🚄 行き方

  • KTX 龍山 → 麗水エキスポ駅(ソウル駅ではありません)。龍山駅 (Yongsan / 용산역) 発、麗水エキスポ駅 (Yeosu Expo / 여수엑스포역) 着です。所要時間と料金はコレールの公式ページが開けなかったため載せていません(二次情報では約3時間)。

  • 観光案内電話 1330(24時間、韓国語・英語・日本語)。

⚠ よくある失敗5つ

1. 第1水曜日の夜にポチャ通りへ — 休みです(4〜6月・8〜10月・連休は除く)。

2. ケーブルカーの料金をブログの値で信じる — 公式未確認です。現地で確認しましょう。

3. ソウル駅でKTXを探す — 龍山駅 (Yongsan / 용산역) 発です。

4. 博覧会期間に当日宿泊 — 9/5〜11/4は先に予約しましょう。

5. 梧桐島に車で入る — 駐車場までです。徒歩15分か椿列車を使います。
