＃韓国ビビンバの注文、ビビギ、ペアワークフロー - 全州正統から石鍋

サブ: 外国人観光客用5-step+ビビギーマナー+スパイス加減+英語発火

ISSUE 03・#880・2026-06-09

🎯 なぜ韓国ビビンバワークフローガイドなのか

[#879ビビンバ5種マトリックス](#879) 知っていても — 注文・ビビギ・ペアは別個。韓国ビビンバは（a）全州韓屋村正統（5色・宮中・UNESCO）（b）石鍋ビビンバ（熱・カリカリ）外国人は（1）ビビギ＝まんべんなく混ぜるマナーの知らない（2）コチュジャン・ごま油加減のマナーの知らない（3）石鹸のお姉さん＝本物の知らない（4）セルフ＝DIYのマナーの知らない。本ガイドは5-step+ビビギ+英語発話。

＃＃★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣チャンネル選択 全州/石鍋/セルフ/山菜/シーフード 即時
2️⃣メニュー注文 1人前/セルフコース 1～5分全州=本物の#1・石釜=グローバル#1
3️⃣受信・設定 5色ハーブ+卵+コチュジャン・ごま油 5〜10分 石釜=非常に熱い
4️⃣ビビギ・食べる コチュジャン・ごま油加減+ビビギ+食べる 30〜60分 均等混合マナー
5️⃣決済 カードOK / Tip X 1～3分セルフ=事前支払い

総所要時間: 全州 = 1~1.5h / 石釜 = 30~50分 / セルフ = 1~1.5h / 山菜 = 1.5~2h / シーフード = 1~1.5h

＃＃🍚チャンネル別ワークフロー

Type A — 全州韓屋村正統派

  • シグネチャー：5色・宮中・UNESCO無形遺産
  • 時間: 11:00～22:00
  • 価格：12,000〜25,000ウォン（全州）/ 8,000〜20,000ウォン（ソウル）
  • メニュー: 全州式ビビンバ・宮中・牛肉（オプション）
  • 外国人親和性: ★★★★★ (UNESCO本物)

Type B — 石釜ビビンバ

  • シグネチャー: 暑さ・サクサクヌルジ
  • 時間: 11:00～22:00
  • 価格：10,000〜22,000ウォン
  • メニュー: 石鍋・サクサクヌルジ・ベジタリアンOK
  • 外国人親和性: ★★★★★ (グローバル#1)
  • 注意: 非常に熱い・皿受けを使用

Type C — セルフビビンバ (DIY)

  • シグネチャー: MZ DIY・インスタ・材料選択
  • 時間: 11:00～22:00
  • 価格：8,000〜18,000ウォン（セルフ無限詰め替え）
  • メニュー: 8～12種材料自由選択
  • 外国人親和性: ★★★★ (MZ #1)

Type D — 山菜・査察料理

  • シグネチャー: 査察食品cluster・菜食 #1・春山菜
  • 時間: ランチ・ディナー（予約）
  • 価格：山菜屋10,000〜25,000ウォン/査察コース25,000〜80,000ウォン
  • メニュー：春の山菜と味噌の味付け
  • 外国人親和性: ★★★★ (ベジタリアン#1)

Type E — シーフードビビンバ

  • シグネチャー: 会・シーフードクロス・チャガルチ・統営
  • 時間: 11:30～22:00
  • 価格：15,000〜40,000ウォン/ 1人
  • メニュー: 5色+回・シーフード（狂魚・アワビ・エビ）
  • 外国人親和性: ★★★ (シーフードマニア)

🥄 ビビギ・味付けマナーマトリックス

ビビギーマナー(必須)

1. コチュジャン・ごま油加減：マコムvs淡白本人調節

2. 均一混合: 5色フルセット+卵+コチュジャン+ごま油

3. スプーン: ビビギ後1スプーンに5色すべて入る

4. 石鍋: ヒビギの前に釘をよく取り除く（サクサク）

5. セルフ: ビビギ=本人責任

コチュジャン加減

  • コチュジャンたくさん =マコム・本格（韓国式）
  • コチュジャン少なく =淡白・外国人入門
  • コチュジャンX =ベジタリアン・ハラール・外国人 (醤油味付け fallback)

ごま油加減

  • ごま油 =韓国正統・告訴
  • ごま油少なく =負担↓

＃＃🌶外国人英語発話サンプル

  • "ビビンバ本物" = "Bibimbap, the original Jeonju style please"
  • "石釜 + カリカリ" = "Dolsot (stone pot) bibimbap — for the crispy bottom"
  • "コチュジャン少ない" = "Less gochujang (red pepper paste), please"
  • "セルフ無限補充" = "Self-serve unlimited refills, please"
  • "ビビギ" = "Mix thoroughly — that's the Korean way!"
  • "カードですか？" = "Card accepted?"

＃＃⚠外国人の頻繁なミス7つ

1. 「ビビンバ=ビビじない」: ビビンバ=均等ビビギマナー(アンビビミーX)。

2. "コチュジャン=すべて入れる": コチュジャン= 本人加減 (マコム vs 淡白調節)。

3. "石釜=一般器": 石釜=非常に熱い・画像注意。

4. "サクサクヌルジ=捨てる":ヌルンジ=本物のマニア#1(よく取り除いて食べる)。

5. "セルフ=苛性肥満": セルフ=MZトレンド#1・材料フルセット。

6. "山菜=ベジタリアン人気X": 山菜=査察食品cluster +春山菜・本格。

7. 「シーフードビビンバ=回」：シーフードビビンバ=5色+シーフードクロス・他の食べ物。

⚙ よくある質問8件

1. 最初のビビンバ=どのチャンネル: 石釜 (#1グローバル) → 全州(本物)。

2. インスタ・vlog: 全州韓屋村・石釜熱さ・セルフDIY。

3. MZ トレンド: セルフ(#1)・石釜。

4. ベジタリアン・ハラール: 山菜(#1) + 査察料理 + 全州(牛肉を除く)。

5. 石釜注意: とても暑さ・子供注意。

6. アレルギー・妊娠: [#879 disclaimer](#879)参照。

7. 決済・チップ: カードOK/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

ビビンバ＝一般食品。妊婦・子ども＝OK（石釜焼け注意）。アレルギー（卵・シーフード・ニンニク・醤油グルテン・牛肉）事前告知。石釜火傷注意。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー: 山菜 = #1 / 全州・石釜 = 牛肉除く / 海鮮 = 甲殻類 X.
  • ベジタリアン・ビーガン：山菜 = #1 / 卵オプション。
  • グルテンフリー：醤油・コチュジャン＝グルテン（タマリ代替）。
