ソウルのランニングコース9か所 — 国民投票で選ばれた漢江・都心・森の道、距離と行き方

サブタイトル: 韓国観光公社「名所発掘100×100」のランニングコース国民投票で33位以内に入ったソウルの9か所を、漢江、都心、公園・森の道、江南の川の4エリアにまとめた。漢江公園3か所の8.4km・7.2km・11.5kmは、走るコースの距離ではなく公園の長さだ。オリンピック公園は22:00に園内への入場が終わり、清渓川は水門の開放が予想されると立ち入りを止める。盤浦の月光レインボー噴水は3月15日から10月までしか稼働しない。距離、開く時間、駅と出口、荷物を預ける場所を、機関の案内値を中心に整理した。景福宮のコースの距離は報道、清渓広場までの徒歩時間はカカオマップの値だ。

ISSUE 06 · #146 · 2026-11-24 · ソウルのランニングコース

🎯 だれのための、なぜこの9か所なのか

ソウル旅行中に1日くらい走りたい人に向けたリストです。川沿いの公園、都心の川、景福宮のあたり、森の公園、昔の線路の公園が混ざっています。

選んだ基準は一つです。韓国観光公社「名所発掘100×100」 (Korea Tourism Organization "100×100 Spot Discovery" / 한국관광공사 명소발굴 100×100)のランニングコース国民投票で33位以内に入ったソウルのコース9か所を、そのまま載せました。2・6・9位が漢江公園 (汝矣島・盤浦・トゥクソム)で、15位ソウルの森、18位清渓川、24位オリンピック公園、29位景福宮のテンテンランのコース、31位良才川、33位京義線森の道が続きます。59位 (85票)の南山北側循環路は9か所の外ですが、車と自転車が通らない道なので、最後にもう1か所足しました。同じ投票のソウル以外のコースは、#1445に別にまとめています。

この9か所は、ランニング専用のトラックではなく、散歩する人、自転車、観光客と一緒に使う道です。そのため、長さがどれくらいか、いつ開いていつ閉まるのか、どの駅の何番出口から出るのかを書きました。

⚠ 表記の原則: 距離、利用時間、料金、行き方は、ソウル市未来漢江本部 (Seoul Metropolitan Government Hangang Project Headquarters / 서울시 미래한강본부) (漢江公園)、ソウル施設公団 (Seoul Facilities Corporation / 서울시설공단) (清渓川)、韓国体育産業開発 (Hanguk Cheyuk Saneop Gaebal / 한국체육산업개발) (オリンピック公園)、国家遺産庁 宮陵遺跡本部 (Gungneung Yujeok Bonbu / 국가유산청 궁능유적본부) (景福宮)、江南区庁 (Gangnam-gu Office / 강남구청) (良才川)、ソウルの公園 (Seoul Parks / 서울의공원) (京義線森の道)、ソウル市の発表で2026-11-24に閲覧した値です。機関が数値を示していない項目は書いていません。走るのにかかる時間は入れていません。漢江公園のkm数値は公園の長さで、往復や周回数の計算は、機関の数値を単純に掛けた値です。清渓広場まで歩く時間は、カカオマップの経路検索の値です (2026-11-24)。景福宮のあたりのコースの説明は、報道を写しました。得票と順位は、韓国観光公社「名所発掘100×100」ランニングコース国民投票の値です。運営時間と出入りの方法は変わることがあります。

🚦 走る前に — 共通の安全とマナー

9か所とも、ランニング専用の道ではありません。施設が決めたルールと、大勢で使う道で守る一般的なマナーに分けて書きます。

  • 漢江公園の自転車ルール。 ソウル市未来漢江本部の案内によると、漢江公園では自転車は自転車道だけを走り、時速20km以下で走行し、右側通行を守って一列で行きます。夜はライトをつけます。
  • 走る人は自転車道に入らない。 これは規定ではなくマナーです。自転車は自転車道だけを走ることになっているので、走る人が歩行路を使えば、ぶつかることが減ります。盤浦漢江公園の紹介は、自転車道と散策路が分かれていると書いています。
  • 人が多い道では速度を落とす。 清渓川、京義線森の道の延南洞区間、景福宮のあたりは観光地のど真ん中です。狭い区間では歩きます。
  • 施設が決めたルールはそのまま守る。 清渓川は、自転車とインラインスケートに乗れず、動物を連れて入ることもできません (障害者補助犬は除く)。オリンピック公園の土城の中の散策路は歩行者優先の区間で、ペットの犬はリードをつけます。漢江公園は禁煙で、犬のリードをつけないと過料5万ウォン、ごみを置いていくと過料10万ウォンです。
  • 清渓川は水門の開放が予想されると立ち入りを止める。 避難の案内放送が流れたら、すぐ川の外に出ます。橋の下で雨宿りをしません。
  • 事故や緊急時は119に電話する。

荷物を預けて着替える場所

  • 汝矣ナル駅のランナーステーション (Runner Station / 러너스테이션): ソウル市が2024年5月に発表した施設です。5号線 汝矣ナル駅の中のB1~M1階にあります。更衣室、パウダールーム、ロッカー58個 (M1階42個、B1階16個)があります。
  • 地下鉄駅のランナー支援スペース3か所 (Runner Support Space / 러너지원공간): ソウル市が2025年10月に発表しました。5号線 光化門駅、4号線 会賢駅 (Hoehyeon Station / 회현역)、6号線 ワールドカップ競技場駅 (World Cup Stadium Station / 월드컵경기장역)にあります。毎日05:30~23:00に開き、地下鉄の運行時間に合わせて運営します。出入りはNaver QRまたはカカオトーク認証で行い、ソウル市は別の利用料金はないと発表しています。男女別の更衣室、個人用ロッカー、パウダールーム、ランニング用品の自動販売機があります。
  • 汝矣島漢江公園のオープン型シャワー室: 汝矣島漢江公園の案内センター (Information Center / 안내센터) 1階にあります。毎日06:30~22:00に開き、08:30~09:30と15:30~16:30は清掃の時間です。無料で、タオルと洗面用具は各自で用意します。入場はNaverアプリのQRコード認証で行います。男女のシャワーブースが5つずつあり、ロッカー13個、更衣室2室があります。シャワーは20分以内に終え、洗濯はできません。問い合わせは汝矣島案内センター 02-3780-0563です。

ランナー支援スペースはNaver QRまたはカカオトーク認証、シャワー室はNaverアプリのQRコード認証で入ります。

① 漢江 — 3か所

3か所とも、ソウル市未来漢江本部が管理する漢江公園です。以下のkm数値は、川に沿って延びる公園の長さで、決まったランニングコースの距離ではありません。出発点と折り返し点は、走る人が決めます。

汝矣島漢江公園 (Yeouido Hangang Park / 여의도한강공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 162票·2位。
  • 公園の長さ: 8.4kmです。漢江鉄橋の中央から、国会の裏のセッカン (Saetgang / 샛강)の方までです。端から端まで往復すると16.8kmです。
  • 行き方: 駅ごとに着く場所が違います。
  • 5号線 汝矣ナル駅 2・3番出口: 歩いて1分、公園の中心部。エレベーターは2番出口の近くにあります。
  • 9号線 国会議事堂駅 (Gukhoeuisadang Station / 국회의사당역) 1番出口: 歩いて1分、国会の裏側。
  • 9号線 セッカン駅 (Saetgang Station / 샛강역) 4番出口: 歩いて10分。
  • 5・9号線 汝矣島駅 (Yeouido Station / 여의도역) 1番出口: 歩いて15~20分。
  • 漢江バスの汝矣島船着場で降りると、公園にそのままつながります。
  • 施設: コンビニ4か所、トイレ24か所、日よけ、ベンチがあります。ムルビッ広場 (Mulbit Plaza / 물빛광장)の噴水は4~10月に稼働します。
  • 荷物とシャワー: 汝矣ナル駅の中にランナーステーションがあり、公園の案内センター1階にオープン型シャワー室があります。値は前の「荷物を預けて着替える場所」に書きました。
  • 住所・問い合わせ: ソウル 永登浦区 ヨイドンロ 330 (Yeouidong-ro 330 / 여의동로 330)。汝矣島案内センター 02-3780-0561~6。

盤浦漢江公園 (Banpo Hangang Park / 반포한강공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 143票·6位。
  • 公園の長さ: 7.2kmです。公園の紹介は、自転車道と散策路が7.2kmにわたって分かれていて、汝矣島・蚕院漢江公園 (Jamwon Hangang Park / 잠원한강공원)とつながっていると書いています。端から端まで往復すると14.4kmです。
  • 潜水橋 (Jamsugyo Bridge / 잠수교): 公園の紹介によると、潜水橋は車道を減らして歩道を広げ、自転車専用の車線があります。
  • 行き方:
  • 9号線 新盤浦駅 1番出口: 盤浦ナドゥルモク (Banpo Nadeulmok / 반포나들목)から入って、歩いて約15分。
  • 3・7・9号線 高速ターミナル駅 (Express Bus Terminal Station / 고속터미널역) 8-1・8-2番出口 (またはゴトゥモールG1): 盤浦大橋の方向へ歩いて約15分。
  • 4・9号線 銅雀駅 (Dongjak Station / 동작역) 1・2番出口: 漢江沿いに西来島 (Seoraeseom Island / 서래섬)の方向へ歩きます。
  • 月光レインボー噴水 (Banpo Moonlight Rainbow Fountain / 반포 달빛무지개분수): 盤浦大橋に設置した噴水で、全長1,140mです。2008年11月7日、ギネスに「世界で最も長い橋の噴水」として登録されました。観覧は無料で、予約なしに現地で見ます。
  • 運営期間: 3月15日から10月までです。11月から翌年3月14日までは利用期間ではありません。冬に盤浦を走るなら、噴水のない川辺を走ることになります。
  • 回(毎回20分): 3月15日~5月と10月は12:00、19:30、20:00、20:30、21:00。6~9月はここに21:30が加わります。平日と週末の区別はありません。
  • 稼働を止めるとき: 風速が秒速7m以上のとき、稼働時間に雨の予報があるとき、漢江の濁度が15NTU以上のときです。イベントがあると時間が変わることがあります。問い合わせ 02-3780-0578~9。
  • 施設: コンビニ2か所、トイレ7か所があります。
  • 住所・問い合わせ: ソウル 瑞草区 シンバンポロ11ギル 40 (Sinbanpo-ro 11-gil 40 / 신반포로11길 40)。盤浦案内センター 02-3780-0541~4。

トゥクソム漢江公園 (Ttukseom Hangang Park / 뚝섬한강공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 136票·9位。
  • 公園の長さ: 11.5kmです。衿湖洞の中浪川橋 (Jungnangcheon Bridge / 중랑천교)から、広津橋の上流側のソウル市境までです。3か所の中で最も長いです。端から端まで往復すると23kmです。
  • 行き方:
  • 7号線 紫陽駅 2・3番出口: 公園にそのままつながります (歩いて1分)。漢江公園のアクセス案内は「紫陽駅」と書き、同じサイトの公園紹介ページは「トゥクソム遊園地駅 2・3番出口」と書きました。
  • 2号線 建大入口駅 (Konkuk Univ. Station / 건대입구역) 5番出口: 1,000m。
  • 漢江バスのトゥクソム船着場で降りると、公園にそのままつながります。
  • 施設: コンビニ3か所、トイレ18か所、日よけ、ベンチがあります。
  • 住所・問い合わせ: ソウル 広津区 ガンビョンブクロ 2273 (Gangbyeonbuk-ro 2273 / 강변북로 2273)。トゥクソム案内センター 02-3780-0521~4。

② 都心 — 2か所

5号線 光化門駅にはランナー支援スペースがあり、荷物を置いて出発するのに便利です。

清渓川 (Cheonggyecheon Stream / 청계천)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 128票·18位。
  • 長さ: ソウル施設公団は、全長を8.12km、復元した区間を5.84kmと書いています。区間の一覧は、清渓広場 (Cheonggye Plaza / 청계광장)~毛廛橋 (Mojeongyo Bridge / 모전교) 150mから始まり、高山子橋 (Gosanja Bridge / 고산자교)~新踏鉄橋 (Sindap Railway Bridge / 신답철교) 307mで終わります。最初の橋は毛廛橋、最後の橋は高山子橋です。
  • 行き方: カカオマップの経路検索では、5号線 光化門駅 5番出口から清渓広場まで歩いて3分 (約120m)です。
  • 禁止事項: 市民の注意事項の禁止リストに、自転車とインラインスケートの利用、動物を連れての出入り (障害者補助犬は除く)、釣り、水泳、野営・炊事、喫煙・飲酒があります。走ることはこのリストにありません。ペットの犬と一緒に走る予定なら、ほかのコースを選びます。
  • 雨の日: 清渓川は雨の日に走る場所ではありません。
  • 雨で水門が開くと予想されると、立ち入りを止めます。
  • 清渓川のまわりに雨が降っていなくても、避難の案内放送が流れたら、すぐ川の外に出ます。上流に降った雨でも水かさが増します。
  • 橋の下で雨宿りをしません。雨が降ると水門が急に開いて、橋の下は危険です。
  • 急に降った雨で取り残された人のための非常用のはしごが39か所にあります。取り残されたら、清渓川総合状況室 02-2290-7111~3に電話します。

景福宮のテンテンランのコース (Gyeongbokgung Palace "Daengdaeng Run" loop / 경복궁 댕댕런 코스)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 111票·29位。
  • どんなコースか (報道): 報道によると、光化門、景福宮 (Gyeongbokgung Palace / 경복궁)、青瓦台 (Cheong Wa Dae / 청와대)、三清洞 (Samcheong-dong / 삼청동)、鍾路、清渓川をまわるランニングコースです。GPSで走った軌跡を線でつなぐと、耳としっぽのついた子犬の形が現れるので、テンテンラン (Daengdaeng Run / 댕댕런。子犬型GPSルート)という名前がつきました。報道は距離を約8kmと書き、景福宮と西村 (Seochon / 서촌)、仁寺洞 (Insa-dong / 인사동)がコースに入ると伝えました。
  • 距離: 約8kmは報道の値です。
  • 走る道と宮の中は別: 報道に出たコースは、景福宮、西村、仁寺洞、青瓦台、三清洞のあたりを通ります。宮の中は、観覧料を払って入る観覧区域です。ランニングと観覧は別に計画します。
  • 行き方: 5号線 光化門駅にランナー支援スペースがあります。5号線 光化門駅 5番出口から清渓広場までは、歩いて3分 (約120m、カカオマップの経路検索)です。景福宮の住所は、ソウル 鍾路区 サジクロ 161 (Sajik-ro 161 / 사직로 161)です。
  • 隣の見どころ — 景福宮: 国家遺産庁 宮陵遺跡本部の案内値です。
  • 休みの日: 毎週火曜日。火曜日が祝日や振替休日と重なると開き、その後の最初の祝日でない日に休みます。
  • 観覧時間: 11~12月と1~2月は09:00~17:00 (入場締め切り16:00)。3~5月と9~10月は09:00~18:00 (入場締め切り17:00)。6~8月は09:00~18:30 (入場締め切り17:30)。事情により短縮や調整をすることがあります。
  • 料金: 個人3,000ウォン (外国人は満19~64歳)。外国人の満18歳以下と満65歳以上は無料です。韓服を着ると無料です。水曜日の「文化のある日」の無料入場は、景福宮には適用されません。

③ 公園・森の道 — 3か所

ソウルの森は24時間開いていて、オリンピック公園は22:00に園内への入場が終わります。京義線森の道は、昔の線路に沿った細長い公園です。

ソウルの森 (Seoul Forest / 서울숲)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 130票·15位。
  • 利用時間: ソウル市の発表 (2026-10-30)は、ソウルの森が年中無休で24時間開放されると書いています。生態の森など一部の施設は、時間が別にあります。
  • 公園道: ソウル市の発表によると、ソウルの森の中の主な公園道の合計22,747.6mが歩行者専用道です。この道では自転車に乗れず、押して行きます。22,747.6mは公園道をすべて足した長さで、一周コースの距離ではありません。
  • 行き方: 水仁盆唐線 ソウルの森駅 4番出口から公園まで歩いて約2分です。

オリンピック公園 (Olympic Park / 올림픽공원)

  • 車と自転車: ソウル市は、この道を、車と自転車の通行が全面禁止で歩行者だけが通る散策路と紹介しました。車両の全面規制は1996年6月に始まりました。

  • 夜: ソウル市の記事は、夜になると照明が一つずつつくと書きました。

⚠ よくある間違い3

  1. 漢江公園の長さをコースの距離だと思う — 汝矣島8.4km、盤浦7.2km、トゥクソム11.5kmは、川に沿って延びる公園の長さです。一周するコースではないので、端まで行くと同じ道を戻ってくることになります。距離を決めて走りたいなら、時計やアプリで測りながら、折り返し点を自分で決めます。一周の距離が決まった所がいいなら、オリンピック公園の散歩/ジョギングコース (1,302m~4,290m)を使います。
  2. 雨の日に清渓川へ行く — 橋が多くて雨宿りができそうに見えますが、逆です。雨が降ると水門が急に開くことがあり、橋の下は危険で、水門の開放が予想されると、立ち入り自体を止めます。晴れた日でも避難の案内放送が流れたら、すぐ上がります。
  3. オリンピック公園で駅と時間を間違える — オリンピック公園駅は5号線と9号線です。8号線に乗るなら、夢村土城駅 1番出口から出ます。徒歩の出入りは22:00までで、その後は公園の中に入れません。夕方に走るなら、22:00前に入れるように時間を決めます。

⚙ FAQ 3

  1. 宿に寄らずに荷物を預けられる所は? — 汝矣島漢江公園の側は、5号線 汝矣ナル駅の中のランナーステーションに、更衣室とロッカー58個があります。光化門駅 (5号線)、会賢駅 (4号線)、ワールドカップ競技場駅 (6号線)のランナー支援スペースは、毎日05:30~23:00に開き、更衣室と個人用ロッカーがあります。出入りはNaver QRまたはカカオトーク認証で行います。シャワーは、汝矣島漢江公園の案内センター1階のオープン型シャワー室 (06:30~22:00、無料、NaverアプリのQRコード認証)で浴びます。
  2. 日が沈んだあとも走れる所は? — ソウルの森は年中無休で24時間開放です。オリンピック公園は徒歩の出入りが22:00までで、広場地域だけ24:00までです。夜の照明と閉まる時間は、#147 ソウルの夜間ランニングコース ガイドに別にまとめました。
  3. 11月末から冬の間に変わることは? — 盤浦の月光レインボー噴水は3月15日~10月しか稼働しないので、冬は見られません。汝矣島のムルビッ広場の噴水も4~10月しか稼働しません。景福宮は、11~12月と1~2月は09:00~17:00と観覧時間が短くなり、16:00に入場を締め切ります。
