⚠ 외국인 자주 실수 5가지

1. "한국 영화관 = 자막 없음": 영어 자막 OK = CGV·메가박스·롯데시네마 한국 영화 일부 영어 자막 + 외국 영화 100% 영어 + 외국인 매니아 1번지 + #438 통합.

2. "IMAX = 한국 1관": CGV 용산 IMAX = 아시아 최대 IMAX 라거 화면 + 외국인 매니아 1번지 + 다른 IMAX 도 5~10관 + 외국인 매니아.

3. "영화제 = 부산만": 영화제 = 부산국제영화제 (10월 아시아 #1) + 전주국제영화제 (5월) + 부천국제판타스틱영화제 (7월) + 서울국제여성영화제 + 외국인 매니아 + 외국인 정통 매니아.

4. "OTT = 영어 안됨": Netflix·Disney+ = K-content 90%+ 영어 자막 + 더빙 일부 + 외국인 매니아 1번지 + #378·#503 통합.

5. "독립영화 = 없음": 독립영화관 = KU시네마테크 + 인디스페이스 + 아트하우스 모모 + 필름포럼 + 외국인 정통 매니아 1번지 + #438 통합.
