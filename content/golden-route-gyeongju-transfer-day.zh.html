韩国黄金路线② 庆州换乘日 — 从庆州站到皇理团路，带着行李住一晚，去釜山坐火车还是大巴

副标题：庆州夹在首尔和釜山之间，是个"顺路"的城市，难就难在这里。KTX站在市区外20公里，住处在市区，第二天还要去釜山。这篇不讲景点——下午到了行李放哪、晚上看什么、早上坐火车还是大巴去釜山，就是这一天的顺序，当日往返之争也说清楚。

ISSUE · #1373 · 2026-09-10

🎯 定调——庆州不是路过站，是换乘日

在黄金路线(#1372)里，庆州是首尔和釜山之间的一晚。可这一晚是三座城市里最难安排的一晚。原因是地理——KTX庆州站 (Gyeongju Station / 경주역) 在市区外约20公里的乾川邑 (Geoncheon-eup / 건천읍)。 下车后还要再走30分钟才到住处，第二天要去釜山，要么再走一次这30分钟出去，要么在市区总站坐大巴。首尔和釜山都不会有的"从车站到市区"问题，只有庆州才有。

所以这一篇不讲庆州的景点，那交给#1115(一泊二日全指南)·#1366(夜景)·#1369·#1370。这一篇讲的是从到达到出发的一天顺序——行李、公交、住宿位置，以及去釜山的交通方式。

  • 时间结构：下午2点左右到达 → 市区移动30分钟 → 办理入住·放行李 → 傍晚夜景 → 住一晚 → 上午出发(住两晚则加一天佛国寺)
  • 三个核心决定：住一晚还是当天往返 / 住宿选在哪 / 去釜山坐火车还是大巴
  • 点名景点：只提大陵苑 (Daereungwon / 대릉원) 一处(夜景交给#1366)

为什么住一晚——把三种立场都摆出来

这个问题有三种立场，在Reddit上都很坚定。

1. "住一晚"：去过的人的回顾大多收敛到"下午到达住一晚，第二天上午出发"。理由是夜晚——陵墓和瞻星台 (Cheomseongdae / 첨성대) 亮灯的傍晚才是庆州的正篇(#1366)。

2. "大家都从釜山当天往返"：住在庆州的人有反驳——从釜山当天往返的游客占大多数，可那样看不到庆州。还有一句话，庆州市面积是首尔的三倍多。

3. "当天往返也够了"：确实有不少从釜山一日往返的报告，满意的帖子也不少。

这条路线选住一晚。理由有三个——反正在首尔去釜山的路上，不产生往返移动；行李寄放住处就能轻装走夜路；第二天上午班次去釜山，釜山第一天才完整。要看佛国寺·石窟庵就延长到住两晚(离市区坐车40分钟，占掉半天)。

选当天往返的话，基准要换——把行李放在釜山，早上KTX到庆州站30分钟，加上市区往返公交1小时，赶在上午10点前进市区。这个判断挂在#1114釜山篇。

📖 故事1——车站为什么绕开市区：2010年京釜高速线 (Gyeongbu High-Speed Line / 경부고속선) 通到庆州时，线路没有穿过市区。新罗 (Silla / 신라) 的陵墓和寺址铺满整个市区，为了避开文物才往西绕到乾川邑，车站以新庆州站 (Singyeongju Station / 신경주역)之名设在市区外。2021年底，市区里的旧庆州站关闭，2023年这座车站改名为庆州站。所以今天这一篇里的"30分钟"，是保文物换来的30分钟。

🚶 顺序——从到达到出发

起点是庆州站(KTX，原新庆州站)。从首尔站 (Seoul Station / 서울역)·水西站 (Suseo Station / 수서역) 出发约2小时(#1372)。

① 庆州站下车 → 市内公交 → 皇理团路 (🚌 约30分钟)

  • 车站前站台坐进市区的50·51·70路(约30分钟，10~15分钟一班)，或座位巴士700号段。车费用交通卡(#1298)。线路和时刻以庆州市公交信息当天确认为准——700号段也有开往东海岸甘浦 (Gampo / 감포) 方向的车，上车前要看清目的地牌。
  • 出租车约20公里，1万韩元中后段。两人同行的话，出租车和公交价差不大。
  • 车站里有私营行李寄存，但不是官方储物柜。行李带去住处。

② 皇理团路住处——办理入住和放行李 (停留约30分钟)

  • 住宿选在大陵苑旁的皇理团路 (Hwangnidan-gil / 황리단길)·皇南洞 (Hwangnam-dong / 황남동)。这是唯一一条走路就能到夜景景点的轴线，庆州市外客运站 (Gyeongju Intercity Bus Terminal / 경주시외버스터미널) 也在市区西边，不远。有些韩屋住处入住时间较晚，订房时问清楚"能不能先寄放行李"。
  • 大件行李到这里就停下。这一篇的核心——在庆州拖着行李箱走的时间，应该只有车站↔住处这30分钟。

③ 大陵苑 → 傍晚·夜景 (🚶 约10分钟 · 交由专篇)

  • 从住处走到大陵苑。日落时分进去，走在灯光亮起的陵墓之间。之后的傍晚·夜景动线以#1366为准——这一篇只写"走着去"。

④ [住一晚] → (住两晚则加)佛国寺·石窟庵 (🚌 约40分钟单程)

  • 选了住两晚的话，第二天坐市内公交10·11路去佛国寺(约35~45分钟，20分钟一班)，佛国寺到石窟庵坐12路接驳车。占一整天。住一晚的话跳过这一段。

⑤ 出发——去釜山坐火车还是大巴 (🚌 约50分钟 / 🚄 30分钟+接驳30分钟)

  • 市外大巴：从市区西边、位于江边路 (Gangbyeon-ro / 강변로) 的庆州市外客运站坐开往釜山老圃 (Nopo / 노포) 综合客运站的车，一天约50班，约50分钟，7,700韩元(深夜9,200韩元)。住处在市区的话，门到门这条路更快。订票用BusTago (버스타고)·T-money GO (티머니GO)——高速大巴App Kobus (코버스) 上查不到(#1297)。
  • KTX：坐市内公交到庆州站30分钟，再坐KTX约30分钟，到釜山站 (Busan Station / 부산역)。釜山住处在釜山站·南浦 (Nampo / 남포) 一带，或者KTX票已经买了，选这条。
  • 判断：釜山西面·海云台住处+带行李→坐去老圃的市外大巴转地铁1号线。釜山站附近住处→坐KTX。不管哪条，只要上午10点前出发，都能赶上釜山的午饭。

📖 故事2——皇南洞为什么成了住宿轴线：庆州的住宿原本集中在普门湖 (Bomun Lake / 보문호) 度假区。不坐车就出不了市区。2010年代后半，大陵苑围墙边皇南洞的韩屋巷子里开起咖啡馆和民宿，变成了皇理团路，如今成了唯一一条走路看夜景、走路去客运站方向都行的轴线。换乘日的住处要选这里，理由不是风景，是走路的距离。

🙏 礼仪——韩屋住处和陵墓之间

  • 韩屋巷子里住着居民。晚上10点后，行李箱轮子的声音要收起来提着走。
  • 大陵苑的陵墓(古坟)是王陵。不要爬上去。草坪内侧禁止进入。
  • 夜灯下不要用三脚架·闪光灯挡住别人的视线。
  • 市内公交后门下车，交通卡刷两次(换乘优惠)。

💡 容易懵的点

  • 庆州站≠市区：站前是乾川邑。订"车站附近的住处"，夜景和客运站都远。
  • 车站名字：2023年之前的资料写"新庆州站"。是同一个车站。市区里的旧庆州站2021年底已关闭——地图App里如果跳出两个"庆州站"，选KTX那个。
  • 700号段公交：有直达皇理团路的车，但开往甘浦的车也是700号段，上车前看清目的地牌。
  • 市外大巴在高速大巴App上查不到：庆州–釜山是市外线路，走BusTago·T-money GO。在Kobus上找不到是正常的。
  • 节假日：中秋·春节前后KTX售罄时，市外大巴还有余票(#1374)。
  • 韩屋入住时间：不少地方下午3~4点才能入住。下午2点左右到的话，先寄放行李就好。

FAQ 6

Q1. 当天往返还是住一晚，只看一个标准的话？

  • 想看夜景就住一晚。不想看、又不想换釜山住处，就当天往返。

Q2. 佛国寺·石窟庵一定要看吗？

  • 有时间就放在第二晚。住一晚的话，只逛市区——大陵苑·瞻星台·月精桥 (Woljeonggyo / 월정교)——也能看到庆州的一半(#1366)。

Q3. 行李怎么寄存？

  • 车站里有私营寄存服务，但不是官方储物柜。寄放在住处才是正解。釜山站在地铁1号线站内有官方储物柜。

Q4. 去釜山的票要提前买吗？

  • KTX在Korail+App (코레일+) 上大多当天也能买到(节假日除外)。市外大巴一天约50班，现场买票也行。

Q5. 从首尔直接去釜山，把庆州放在后面呢？

  • 釜山→庆州→首尔的顺序也行。庆州站有下午·傍晚开往首尔的KTX。只是带着行李进市区这个结构是一样的。

Q6. 租车呢？

  • 在庆州市内方便，但不适合三城路线。这一篇以大众交通为准。
