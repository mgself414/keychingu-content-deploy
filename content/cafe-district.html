⚠ 외국인 자주 실수 5가지

1. "한국 카페 = 그냥 카페": 한국 카페 = 외국인 인스타 1번지 + 베이커리·디저트·MZ 매니아 풀세트 + 12 cluster (성수·도산·익선·연남·강남) + 외국인 매니아.

2. "성수 카페 = 어디나": 성수 카페 = 카페 어니언 (#145·#01 한국 #1 베이커리 카페) + LBM (#361)·누데이크·OPS + 옛 공장 → 천상가옥 (#366) + 외국인 인스타 1번지.

3. "익선동 = 인사동": 익선동 = 한옥 + 카페 cluster 1번지 (#12·#297 인사동 인접) + 외국인 인스타·MZ 매니아 1번지.

4. "연남 = 홍대": 연남 = #156·#222 + 연트럴파크 + 카페 골목 1번지 + 외국인 매니아 1순위·MZ 매니아.

5. "강남 카페 = 비쌈만": 강남 카페 = 서래마을 (#173 한국 #1 프랑스) + 반포 + 청담 + 도산 + MAILLET (#361 한국 #1 프랑스 1995) + 외국인 매니아 럭셔리 1번지.

  • 혼자 (Solo): 1일 풀데이 효율 매트릭스·80,000~150,000원/인
  • 커플 (Couple): 1박 매니아 매트릭스·250,000~500,000원/2인 (1박)
  • 가족 (Family): 안전·교육·박물관·체험 매트릭스·200,000~400,000원/4인
  • MZ·인스타: 카페·야경·매니아 매트릭스·80,000~150,000원/인
  • 예산형 (Budget): 무료 입장·길거리 음식·30,000~80,000원/인
