ソウル東西軸① バス720番、独立門 (Independence Gate / 독립문) から清涼里 (Cheongnyangni / 청량리) まで — 600年の東西大路、車窓越しに

副題: 南北軸が50年前の直線なら、東西軸はソウル本来の軸。独立門からバス720番で光化門・鍾路を抜け東大門を車窓に清涼里へ。約2時間、下車は祭基洞一度。光化門・鍾路・東大門は降りない。Seoul E-W Axis 1回目。

ISSUE · #1356 · 2026-09-07

🎯 フレーム — ソウルを横に一度に読む方法

ソウル南北軸(#1353)はバス140番で江南大路・漢南大橋・南山1号トンネルを抜け、「江南が作られた順序」を見た。あの道は1969年から1976年の間に敷かれた。この回の道は違う。鍾路 (Jongno / 종로) は1394年に漢陽が首都になって以来、都城内を東西に貫いてきた大路だ。西の門敦義門 (Donuimun / 돈의문)から東の門興仁之門 (Heunginjimun / 흥인지문)まで、人と馬と商店が600年の間この道の上にあった。

地下鉄で移動すると、ソウルは島々の集まりのように見える。景福宮前と東大門の間に何があるのかは、地下からは見えない。このコースはその間を地上で通る — 独立門から市内バス720番に乗り、旧西門跡、光化門 (Gwanghwamun / 광화문)、鍾路1街から5街、東大門を車窓に見ながら都城外の清涼里まで。

  • 総所要時間: 約2時間(バス乗車約45~55分 + 祭基洞下車15分 + 余裕)
  • おすすめ時間帯: 平日午前10時出発 — 鍾路区間は午前ラッシュが終われば窓側席が空く。夕方ラッシュ(17~19時)は鍾路もバス専用車線が渋滞する
  • 傾斜: なし — 歩く区間は平地15分のみ

なぜ720番なのか — 西門・東門・東の関門を一路線が通る

恩平区鎮寛洞から東大門区踏十里(撮影所交差点)の間を往復する幹線バス720番は、ムアクチェ峠を越え独立門駅 (Dongnimmun Station / 독립문역) → 西大門駅 (Seodaemun Station / 서대문역) → 光化門 → 鍾路1街~6街 → 東大門 → 東廟前 (Dongmyo / 동묘앞) → 新設洞 (Sinseol-dong / 신설동) → 祭基洞 → 清涼里駅 (Cheongnyangni Station / 청량리역) を一本で通る。朝鮮都城の西門(敦義門)跡と東門(興仁之門)、そして都城外の東の関門・清涼里を一度に通過する路線だ。始発は午前4時、配車は平日約6〜10分(2026年4月の減便以降の基準・変動あり)。

📖 物語1 — 鐘楼の下を人と馬が通った道: 朝鮮は1413年に鐘楼を今の鍾路交差点に移し、1440年に再建して上階に鐘を吊るし、下を人と馬が通れるようにした。その鐘楼前の大通りが雲従街 (Unjongga / 운종가)、「雲のように人が集まる街」だった。国に物品を納める代わりに独占権を受けた六種の官許商店六矣廛 (Yugui-jeon / 육의전)がこの道に並んだ。鐘閣が「普信閣 (Bosingak / 보신각)」という名を受けたのは1895年3月15日。今その場所の上をバス専用車線が通っている。

🚶 コース — 車窓の順番そのままに

起点は地下鉄3号線独立門駅。大通りに立つと凱旋門に似た石造りの門が見える — 1897年に建てられた独立門だ。

① 独立門駅 → 独立門正面 → 720番停留所 (🚶 約3分)

  • 駅を出て独立門を正面に一度見た後、統一路沿いの独立門駅停留所で踏十里(撮影所交差点)方面の720番に乗る。停留所名はアプリ表記基準で確認する。
  • 独立門と西大門刑務所歴史館、霊泉市場をきちんと歩く夕暮れコースは#1357に別にある。ここでは乗るだけだ。

② 霊泉市場 → 西大門駅 (🚌 約4分・降車なし)

  • 出発してすぐ左の車窓に独立門霊泉市場 (Dongnimmun Yeongcheon Market / 독립문영천시장)のアーケード入口がかすめる(#1357)。統一路が終わり西大門駅停留所 — ここが朝鮮都城の西の門、敦義門が立っていた場所だ。
  • 📖 物語2 — 西門から東門まで: 敦義門は1915年、朝鮮総督府が路面電車の複線化と道路の直線化を理由に取り壊した。東の門、興仁之門は残った。このバスは無くなった門の跡から残った門まで、都城の東西大路をそのまま走る。鍾路の総延長は世宗大路交差点から新設洞まで4.2km(2010年に興仁之門~新設洞区間を鍾路に編入した後の基準)。

③ 貞洞交差点 → 光化門 (🚌 約5分・降車なし)

  • 西大門駅を過ぎると右手にソウル歴史博物館 (Seoul Museum of History / 서울역사박물관)とその奥に慶熙宮 (Gyeonghuigung / 경희궁)、左手に敦義門博物館村が車窓を過ぎていく。都城の中に入ったという合図だ。
  • 光化門停留所。右の窓に光化門広場とその先の光化門、後ろに北岳山が重なって見える。この回では降りない — 景福宮・光化門広場は#141・#1244が、鍾路3街 (Jongno 3-ga / 종로3가)ハブは#1254が扱う。

④ 鍾路1街 → 鍾路3街 → 鍾路5街 (🚌 約5分・降車なし)

  • 鍾路1街: 右に普信閣。毎年12月31日の深夜に鐘を打つ場所だ。鍾路3街: 左の路地の奥が益善洞、右がタプコル公園(#294・#1254)。鍾路5街: 右に広蔵市場 (Gwangjang Market / 광장시장)の入口(#1257)。
  • 鍾路はソウルでバスが最も密に停まる道のひとつだ。停留所ごとに人が乗り降りするリズム自体が、この区間の風景だ。

⑤ 東大門 (🚌 約6分・車窓のクライマックス)

  • 鍾路6街を過ぎると道路の真ん中に城門が現れる。興仁之門、1963年に宝物に指定された都城の東門だ。門の両脇を車が分かれて流れ、左後方に城郭が駱山へ上っていく(#1340昌信洞コースがその裏手だ)。
  • ここで都城が終わる。この回のクライマックスだが降りない — 東大門ショッピング・DDPは#172・#31・#1252がある。

⑥ 東廟前 → 新設洞 → 祭基洞下車 (🚌 約8分)

  • 興仁之門の外、旺山路。東廟前(#049古着市場)と新設洞を過ぎると、道の両側から漢方薬の匂いが先に来る。祭基洞駅 (Jegi-dong Station / 제기동역)停留所で降りる。

⑦ 祭基洞ミニウォーク — 京東市場 (Gyeongdong Market / 경동시장)入口15分 (🚶 約15分)

  • 停留所から京東市場入口まで歩き、在来市場一帯の入口をひと回りして戻る。1960年6月に開いた市場で、古山子路の西側は1995年にソウル薬令市 (Seoul Yangnyeongsi / 서울약령시)に指定された漢方薬材街だ。市場をきちんと歩く朝コースは#1358 — ここでは匂いと音だけを味わう。
  • 同じ停留所から踏十里方面の720番に再び乗る。

⑧ 清涼里駅下車 — 締めくくり (🚌 約3分)

  • 次の停留所、清涼里駅で降りる。都城外の東の関門 — 1号線・京義中央線が交わり、KTXが発着する駅だ。ソウル東西軸はここで終わる。720番は踏十里までさらに行くが、この回のソウル横断は清涼里で締めくくる。
  • その後の動線: 1号線で都心へ戻る、京義中央線で漢江沿い(#1248)へ、または江原道行きKTXへ。

🚌 乗り方・座席のコツ5

1. カード一枚: T-moneyまたは海外コンタクトレスカード(#1298)。乗るときも降りるときもタッチ — 乗り換え割引のため、降車タッチを忘れない。

2. 座席は右側(南側)の窓側: 踏十里方面基準で右側に座ると、光化門広場・普信閣・広蔵市場・興仁之門が全部右の窓に入ってくる。

3. 降車ベルは新設洞で: 「祭基洞駅」の案内放送(韓国語・英語)が流れる前、新設洞を過ぎるときにベルを押しておく。

4. 速い代案: 時間がなければ5号線西大門駅→光化門→東大門歴史文化公園、1号線東大門→清涼里で地下鉄縦断が可能だ。ただし鍾路の車窓は全部逃す。

5. 逆方向もできる: 清涼里から鎮寛洞方面の720番に乗れば、興仁之門を正面に見ながら都城に入っていく。夕方の逆方向はシリーズ拡張候補。

🙏 バスマナー — このコースの核心

  • 鍾路の停留所は道路の真ん中の島だ。横断歩道の信号でのみ渡る。
  • 鍾路区間は高齢の乗客が多い。前方の交通弱者席は空けておき、大きな荷物は後ろ扉付近に。
  • 車窓の撮影は隣の乗客がフレームに入らないように。通話は小声で。

💡 戸惑いポイント

  • 停留所名は方向ごとに違うことがある: 同じ交差点でも鎮寛洞方面と踏十里方面で停留所名が違う。アプリで方向を確認してからベルを押す。
  • 鍾路は夕方に混む: 17~19時の鍾路1~5街はバス専用車線も渋滞する。コースが3時間に延びる。
  • 祭基洞では15分だけ: 市場の奥深くまで入ると720番停留所へ戻る道を見失いやすい。入口を一周するだけにする。
  • 終電・配車は変わる: 2026年4月の減便以降、配車間隔が延びた。遅い時間はアプリで到着時刻を確認する。

FAQ 6

Q1. 観光バスではなく一般の市内バスか?

  • そうだ。シティツアーバスではなく、ソウルの人々が毎日乗る幹線バス720番だ。解説はないが、車窓が解説だ。料金も一般市内バスの料金。

Q2. 南北軸(#1353)とどう違うか?

  • 南北軸は1969~1976年に作った新しい道(江南大路・漢南大橋・トンネル)を通り、東西軸は1394年からあった古い道(鍾路)を通る。二つを続けて乗れば、ソウルを十字に読むことになる。

Q3. 光化門・鍾路で降りてはいけないか?

  • 降りてもいい。ただしこの回は通過が原則なので、その街の案内は各回(#141・#1254・#172)を見る。同方向の720番に30分以内に再び乗れば、乗り換え割引が適用される。

Q4. 全部で何停留所、何分か?

  • 独立門駅から清涼里駅まで停留所15カ所前後、乗車約45~55分(平日昼基準・推定)。時間帯によって大きく変わる。

Q5. 興仁之門は降りて見るべきではないか?

  • 道路の真ん中の門なので、バスの窓から見る角度がむしろいい。近くで見たいなら東大門駅で降りて城郭側へ — #1340昌信洞コースがその裏手を歩く。

Q6. 夜に乗ってもいいか?

  • 大丈夫だ。普信閣と興仁之門には夜間照明がある。ただしこの回は昼の鍾路のリズムが基準で、逆方向の夜間は拡張回で扱う。
