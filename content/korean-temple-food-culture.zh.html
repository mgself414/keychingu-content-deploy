韩国寺刹饮食 (Sachal Eumsik / 사찰음식) 文化 — 为什么韩国寺庙餐 (Jeolbap / 절밥) 不放肉和蒜，却如此清雅？

> 寺刹饮食 (Sachal Eumsik / 사찰음식)·五辛菜 (Osinchae / 오신채)·钵盂供养 (Baru Gongyang / 발우공양)·净宽师太 (Jeong Kwan Sunim / 정관스님) — 为外国人解读韩国寺庙餐 (Jeolbap / 절밥) 文化。这不是“素食餐厅介绍”，而是“为何如此清淡”。

初次接触韩国寺庙餐 (Jeolbap / 절밥) 的外国人会惊叹两次。第一次是“竟然一点肉都没有”，接着品尝一口野菜，会说“但为什么味道如此深邃清雅？”。即使不放蒜和洋葱，味道也绝不寡淡。它不依赖华丽的调料，而是以时令食材和长时间发酵的酱 (Jang / 장) 带来深沉的美味。这就是寺刹饮食 (Sachal Eumsik / 사찰음식) — 韩国佛教1700年来发展出的“饮食亦是修行”的饮食文化。2025年5月，韩国将寺刹饮食 (Sachal Eumsik / 사찰음식) 指定为国家非物质文化遗产 (Gukga Muyeong Yusan / 국가무형유산) (官方发布 — 建议确认)，同时，因登上Netflix《主厨的餐桌》的净宽师太 (Jeong Kwan Sunim / 정관스님)，它也成为全球美食界瞩目的韩食。本文并非介绍“哪里可以吃到” (→ 交叉链接)，而是从外国人的视角，解释为何要舍弃、为何要清淡、为何这是一种修行。这是韩国文化解读系列第6篇。

★ 一目了然 — 寺刹饮食 (Sachal Eumsik / 사찰음식) 的6大原则

原则 内容 一句话概括
无肉食 (Muyeuksik / 무육식) 不含肉类·鱼类 不杀生 (不杀生) — 对生命的慈悲
禁止五辛菜 (Osinchae Geumji / 오신채 금지) 禁用5种辛辣蔬菜 蒜·葱·韭菜·小蒜·兴渠 (阿魏) — 刺激会扰乱修行

> 核心一句话: 寺刹饮食 (Sachal Eumsik / 사찰음식) 的美学并非“加法”，而是“减法 (清淡)”。它的哲学不在于添加了什么，而在于舍弃了什么。

⚠️ 外国人常有的3个误解

1. “寺庙餐 (Jeolbap / 절밥) = 清淡无味的素食” ❌ — 寺刹饮食 (Sachal Eumsik / 사찰음식) 并非放弃美味的食物，而是制作美味的方式不同。它不依赖蒜·洋葱的强烈刺激，而是通过时令蔬菜的本味，以及陈年酱 (Jang / 장) (大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장))·酱菜 (Jangajji / 장아찌)·蘑菇·苏子来积累鲜味。它减少刺激，保留深度 — 更接近极简主义。

2. “僧侣专享的特殊餐食” ❌ — 虽然最初是修行者的餐食，但如今，随着寺庙寄宿 (Templestay / 템플스테이)·寺刹饮食 (Sachal Eumsik / 사찰음식) 课程·专门店·素食潮流的兴起，它已向普通大众和外国人敞开大门。在佛诞节，MZ一代 (MZ Sedae / MZ세대) 和外国人会排队体验。

3. “吃了就要改信佛教吗” ❌ — 体验寺刹饮食 (Sachal Eumsik / 사찰음식) 并非入教，而是一种饮食文化·健康体验。素食者·纯素食者、寻求排毒·正念的人，以及仅仅对“韩食之根”好奇的人，都可以享受。寺庙不会强迫信仰。

① 寺刹饮食 (Sachal Eumsik / 사찰음식) 是什么 — “饮食亦是修行”

寺刹饮食 (Sachal Eumsik / 사찰음식)，顾名思义，是寺庙 (Sachal / 사찰) 里吃的食物。但它不仅仅是“寺庙制作的素食”。核心在于将饮食视为修行的延伸。

  • 自佛教传入韩国1700多年以来，寺庙自给自足，发展出独特的烹饪方法。
  • 将食物视为药 (Yak / 약) — 并非为了取悦味蕾，而是为了维持身体，以继续修行所需的最低限度。
  • 因此，寺刹饮食 (Sachal Eumsik / 사찰음식) 的关键词不是华丽，而是简洁·清雅·节制。它不使用人工调味料·化学添加剂·防腐剂，保留食材的原始特性。
  • 佛教的“中道 (Jungdo / 중도)” — 避免两极，寻求平衡 — 也应用于餐桌。不多不少，恰到好处。

也就是说，吃寺庙餐 (Jeolbap / 절밥) 不仅仅是一顿素食，更是通过“舍弃与清淡”来亲身体验韩国佛教的世界观。

② 禁止五辛菜 (Osinchae Geumji / 오신채 금지) — 为什么不放蒜和葱

寺刹饮食 (Sachal Eumsik / 사찰음식) 中最让外国人感到新奇的一点。不放肉可以理解为“素食”，但为什么连蒜·洋葱这些普通的蔬菜也要舍弃呢？

五辛菜 (Osinchae / 오신채) = 五种辛辣蔬菜。传统上指蒜·葱·韭菜·小蒜·兴渠 (Heunggeo / 흥거, 阿魏) (★ 准确)。现代也将其解释为包括洋葱等葱属植物。

禁用这五种蔬菜并非简单的饮食规定，而是修行的逻辑。

  • 刺激会扰乱心神: 佛教经典 (如楞严经 (Neungeomgyeong / 능엄경)) 认为 — 生食这些辛辣蔬菜会助长嗔怒之心 (怒气)，熟食则会助长淫欲 (淫心)。两者都会破坏内心的平静，妨碍冥想。
  • 使身体浮躁: 强烈的香气和刺激会过度激发食欲·精力，使需要宁静专注的修行者身体无法安定。
  • 顾及僧团: 在多人共修的场所，避免因强烈的口臭给他人带来不便，这也是一个实用的原因。

> 参考 — 为什么辣椒可以？ 五辛菜 (Osinchae / 오신채) 中不包括辣椒 (辣椒粉)。辣椒是在壬辰倭乱前后才传入朝鲜半岛的较晚作物，因此在五辛菜 (Osinchae / 오신채) 概念确立时并不存在。所以寺刹饮食 (Sachal Eumsik / 사찰음식) 中常见的有不含蒜的“白泡菜 (Baekkimchi / 백김치)”，或使用辣椒粉但不放蒜·葱的泡菜 (Kimchi / 김치)。(历史背景 — 细节建议确认)

核心在于，这并非为了禁欲而禁欲，而是“舍弃扰乱心神之物，以便更清净地修行”。

③ 钵盂供养 (Baru Gongyang / 발우공양) — 零食物浪费的饮食仪式

寺刹饮食 (Sachal Eumsik / 사찰음식) 的哲学最鲜明地体现在钵盂供养 (Baru Gongyang / 발우공양) — 寺庙中僧侣们按照规定法式进行的传统饮食仪式。

  • 钵盂 (Baru / 발우) = 修行者各自的餐具套装 (通常是4个叠放的形式)。随着木鱼声，展开餐具，诵读经文 (小品经)，整个过程可能持续约一小时。
  • 按需取食，不留残羹: 不允许留下食物。因此，几乎不产生食物垃圾。
  • 最后一滴不剩: 用餐结束后，向碗中注水冲洗，然后将洗碗水 (天水) 也饮尽。不浪费一粒米，一滴水。干净到几乎不需要额外清洗。
  • 感恩冥想: 忆念一餐饭来到面前所经历的 — 农夫的汗水、自然的辛劳、施主的恩德 — 无数环节，以放下贪欲 (贪心) 的心境来用餐。

钵盂供养 (Baru Gongyang / 발우공양) 给外国人留下深刻印象。“零食物浪费 (zero-waste)”和“正念饮食 (mindful eating)”这些当今全球热门话题，韩国佛教早在数百年前就通过仪式实践。

④ 时令·自然 — 顺应自然馈赠

寺刹饮食 (Sachal Eumsik / 사찰음식) 的另一个支柱是时令 (Sikgyejeol / 시식) 和自然本味。

  • 当季之物，当季而食: 春季山野菜·楤木芽，夏季黄瓜·茄子，秋季蘑菇·桔梗，冬季干野菜·根茎蔬菜。顺应自然在当时提供的食材，身体也随之调整。
  • 排除人工味道: 不使用化学调味料 (味精)·防腐剂·人工添加剂。甜味也更多依赖水果·麦芽糖等自然之物，而非白糖。
  • 蘑菇·苏子·豆类替代肉类: 以蘑菇·豆类·豆腐补充动物性蛋白质，用苏子·坚果增加香醇和鲜味 (Umami)。

这种“时令·节制”的哲学并非寺刹饮食 (Sachal Eumsik / 사찰음식) 独有，而是与以阴阳五行平衡为基础的韩国整体饮食文化一脉相承。(→ [#1132 韩国小菜 (Banchan / 반찬) 文化](1132_korean_banchan_culture.md) 的五方色 (Obangsaek / 오방색)·五味 (Omi / 오미) 平衡，[#1134 韩国发酵·酱 (Jang / 장) 文化](1134_korean_fermentation_jang_culture.md))

⑤ 发酵 (Balhyo / 발효) — 无蒜亦有深味的秘密

“不放蒜和洋葱，怎么做出味道？” — 这是外国人最常问的问题，答案就是发酵 (Balhyo / 발효)。

  • 酱 (Jang / 장) 代替调料: 大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장)·辣椒酱 (Gochujang / 고추장) 等发酵酱 (Jang / 장) 是寺刹饮食 (Sachal Eumsik / 사찰음식) 风味的核心。经过数月至数年陈酿的酱 (Jang / 장)，与蒜带来的直接刺激不同 — 带来深沉而圆润的鲜味。可以说，时间就是调料。
  • 酱菜 (Jangajji / 장아찌) 的智慧: 将时令蔬菜用酱 (Jang / 장)·盐腌制，长时间保存的酱菜 (Jangajji / 장아찌)，既不浪费食材，又通过发酵提升风味。
  • 无蒜泡菜 (Kimchi / 김치): 寺庙的泡菜 (Kimchi / 김chi) 不放蒜·葱·鱼酱也能腌制。刺激性更小，但发酵的深度依然存在。

发酵 (Balhyo / 발hyo) 也是寺刹饮食 (Sachal Eumsik / 사찰음식) 与现代健康潮流的交汇点。随着发酵食品对肠道健康·免疫力有益的认知普及，“无蒜发酵带来的深味”反而被重新评价为精致美食。(发酵 (Balhyo / 발효) 的原理·种类请参考 → [#1134 韩国发酵·酱 (Jang / 장) 文化](1134_korean_fermentation_jang_culture.md))

⑥ 走向世界 — 净宽师太 (Jeong Kwan Sunim / 정관스님) 与《主厨的餐桌》

寺刹饮食 (Sachal Eumsik / 사찰음식) 进入世界美食界视野的决定性契机是净宽师太 (Jeong Kwan Sunim / 정관스님)。

  • 净宽师太 (Jeong Kwan Sunim / 정관스님) 是驻锡于全罗南道白羊寺 (Baegyangsa / 백양사) 天真庵 (Cheonjinam / 천진암) 的禅 (Seon / 선) 尼姑，为同修和偶尔的访客烹制食物。她本人表示“我不是厨师，而是僧侣”，将烹饪视为佛教修行的一种方式。
  • 2017年出演Netflix《主厨的餐桌》 (第三季第一集)，向全世界介绍了韩国寺刹饮食 (Sachal Eumsik / 사찰음식) (★ 准确 — Chef's Table 2017)。一位没有受过正规烹饪教育、没有餐厅的僧侣的哲学，吸引了世界各地的厨师。
  • 影响世界顶级厨师: 据悉，Noma餐厅的雷内·雷德泽皮、Le Bernardin餐厅的埃里克·里珀特等世界级厨师都从净宽师太 (Jeong Kwan Sunim / 정관스님) 的哲学中获得了灵感 (媒体报道略有差异 — 细节建议确认)。

净宽师太 (Jeong Kwan Sunim / 정관스님) 的信息始终如一 — 烹饪是放下自我，与自然·生命连接的修行。并非华丽的技巧，而是“清淡的哲学”打动了世界，这也是寺刹饮食 (Sachal Eumsik / 사찰음식) 超越单纯素食的原因。

⑦ 当下 — 与寺庙寄宿 (Templestay / 템플스테이)·素食相遇

传统修行餐食寺刹饮食 (Sachal Eumsik / 사찰음식) 如今乘着两大潮流进入日常生活。

  • 寺庙寄宿 (Templestay / 템플스테이) & 寺刹饮食 (Sachal Eumsik / 사찰음식) 课程: 外国人可以通过在寺庙住宿1-2晚的寺庙寄宿 (Templestay / 템플스테이) 或当日寺刹饮食 (Sachal Eumsik / 사찰음식) 制作课程，亲手处理食材，并以钵盂供养 (Baru Gongyang / 발우공양) 的方式用餐，亲身体验其哲学。首尔市中心 (安国洞 (Anguk-dong / 안국동) 等地) 也设有寺刹饮食 (Sachal Eumsik / 사찰음식) 文化体验馆。
  • 契合全球素食需求: 寺刹饮食 (Sachal Eumsik / 사찰음식) 本身接近纯素食 (Vegan) — 不含肉类·鱼类·鸡蛋·乳制品，甚至不含五辛菜 (Osinchae / 오신채)·人工添加剂，因此对于挑剔的纯素食旅行者来说，也是一个安心的选择。它与全球纯素食·植物基饮食热潮完美契合，成为来韩素食旅行者的首选体验。
  • MZ一代 (MZ Sedae / MZ세대)·健康关键词: “正念饮食”、“排毒”、“无添加”、“零浪费” — 当今全球健康热点话题，寺刹饮食 (Sachal Eumsik / 사찰음식) 中已全部包含。在佛诞节，MZ一代 (MZ Sedae / MZ세대) 和外国人会涌向寺刹饮食 (Sachal Eumsik / 사찰음식) 节庆和专门店。

> 重点: 对外国人来说，寺刹饮食 (Sachal Eumsik / 사찰음식) 并非“宗教食物”，而是“拥有1700年历史的韩国版纯素食·正念饮食文化”。这个角度大大降低了体验门槛。

⑧ 外国人体验 — 如何接近

> 具体“哪里可以吃到”(专门店·寺庙寄宿 (Templestay / 템플스테이) 预订处) 请参考下方的交叉链接指南。这里只谈“心态”。

  • 放下“不好吃”的偏见: 对于习惯浓郁调味的味蕾来说，初尝可能会觉得清淡。但两三口之后，食材本身的甜味·鲜味会逐渐显现。人们常说这是舌头不一定喜欢，但身体会喜欢的味道。
  • 纯素食·过敏安心: 由于不含五辛菜 (Osinchae / 오sinchae)·动物性成分·人工添加剂，对于纯素食者或对蒜·洋葱过敏的旅行者来说，这可能是一个特别安全的选择 (建议向店家确认)。
  • 作为“饮食冥想”来享受: 不求快，不求多，而是慢慢地·感恩地·不留残羹地。借用钵盂供养 (Baru Gongyang / 발우공양) 的精神来享用一餐，食物会带来不同的感受。
  • 体验式更深入: 相比单纯的用餐，寺刹饮食 (Sachal Eumsik / 사찰음식) 课程 (亲手制作) 或寺庙寄宿 (Templestay / 템플스테이) (在寺庙过夜) 能带来更深入的哲学体验。

❓ 外国人常见问题 (FAQ)

  • 寺刹饮食 (Sachal Eumsik / 사찰음식) 都是纯素食吗？ — 几乎都是。它不含肉类·鱼类·鸡蛋·乳制品，甚至不含五辛菜 (Osinchae / 오신채) (蒜·葱类)，因此比一般纯素食更严格。但蜂蜜·乳制品的使用可能因寺庙·地区而异，敏感者建议确认。
  • 不放蒜·洋葱会不好吃吗？ — 不会。经过数年陈酿的酱 (Jang / 장) (大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장))·酱菜 (Jangajji / 장아찌)·蘑菇·苏子会带来深沉的鲜味。它只是“不刺激”，而非“不好吃”。
  • 不同宗教信仰的人也能吃吗？ — 当然可以。寺刹饮食 (Sachal Eumsik / 사찰음식)·寺庙寄宿 (Templestay / 템플스테이) 并非强制信仰，而是开放的饮食文化·健康体验。无宗教信仰者·其他宗教信仰的外国人也欢迎。
  • 为什么辣椒 (辣味) 可以放？ — 辣椒不属于五辛菜 (Osinchae / 오신채) (蒜·葱·韭菜·小蒜·兴渠 (Heunggeo / 흥거))。它是较晚传入朝鲜半岛的作物，因此不属于传统禁忌对象。所以寺庙泡菜 (Kimchi / 김치) 中常见有辣椒粉但无蒜·葱的情况。
  • 如何才能 제대로 (Jedaelo / 제대로) 体验寺刹饮食 (Sachal Eumsik / 사찰음식)？ — 相比单纯的餐厅用餐，寺刹饮食 (Sachal Eumsik / 사찰음식) 课程 (亲手烹饪) 或寺庙寄宿 (Templestay / 템플스테이) (寺庙住宿+钵盂供养 (Baru Gongyang / 발우공양)) 能更深入地体验其哲学。(→ [cross-link](#cross-link))
