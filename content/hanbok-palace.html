⚠ 외국인 자주 실수 5가지

1. "경복궁 = 무료 입장만": 경복궁 = 3K 입장료 (한복 착용 시 무료) + 수문장 교대식 1일 2회 + 외국인 매니아 #1 + 영어 도슨트 (1일 3회).

2. "창덕궁 후원 = 들어감": 창덕궁 후원 (비원) = 예약 필수 + 영어 가이드 (1일 6회) + UNESCO 1번지 + 외국인 매니아 1순위.

3. "한복 = 비쌈": 한복 대여 = 15~30K/3시간 + 궁궐 무료 입장 패키지 + 한복남·한복 빌리기·색다른 한복 cluster (북촌·인사동·삼청동).

4. "창경궁 야간 = 일년 내내": 창경궁 야간 개장 = 봄·가을·여름 한정 (4·5·8·9·10월) + 외국인 인스타 1번지 + 외국인 야간 매니아.

5. "종묘 = 그냥 사당": 종묘 = UNESCO + 종묘제례악 (UNESCO 인류무형문화유산) + 조선왕조 600년 제향·외국인 정통 매니아.
