汉江夜景指南——盘浦月光彩虹喷泉、游船、汉江巴士、盘浦三色岛、鹭得岛，2026年10月官方信息

🎯 本指南使用方法

汉江夜景并不只属于夏天——2026年10月，盘浦喷泉每晚仍然喷水3场，游船有22点出航的班次，汉江巴士东·西2条航线照常运行，鹭得岛的灯光庆典持续到10/11。下面的时间和票价，只写2026-10-08当天从首尔市公告和运营方官方页面读到的数值。汉江事业本部网站正文打不开，所以喷泉和泳池改用首尔市官方公告代替；汉江巴士的票价在官方资料之间互相矛盾（2,500韩元 vs 3,000韩元），因此如实并列。旧版指南里的“喷泉世界第一”（→ 2008年吉尼斯“最长桥梁喷泉”1,140 m）、“游船1.5万~2.5万韩元”、“12·21·21:30喷泉”等数值与现状不符，已删去。夏季泳池（6/19~8/30）和首尔世界烟花节（9/5）已经结束。

⛲ 盘浦月光彩虹喷泉——夜间3场

  • 从盘浦大桥两侧喷出的喷泉，2008年获吉尼斯“世界最长桥梁喷泉”认证（1,140 m）（首尔市）。这里用这一表述取代旧版指南的“世界第一”。
  • 2026年改为节能运营，每天3场（19:30·20:00·20:30，每场20分钟）（首尔市公告 2026-06-01）。10月是否运营、本季结束日期、风大等取消标准，官方均未公布——出发前请查看汉江事业本部公告。
  • 公园免费、24小时开放。乘9号线新盘浦站1号口，或高速客运站站8-1·8-2号口。

🚢 游船·汉江巴士——在水面上

  • 衣恋游船 (E-Land Cruise / 이랜드크루즈)（汝矣岛码头，汝矣东路290号）：日落 18:00 · 月光音乐 19:00 · 星光 22:00 · 烟花音乐 19:30（指定日）。票价 观光19,900 / 日落·星光25,900 / 月光32,900 / 烟花45,900韩元（官方）。
  • 汉江巴士 (Hangang Bus / 한강버스)：2026-03-01复运。东线蚕室~汝矣岛，西线麻谷~汝矣岛，共7个码头（另有首尔林，10月前停靠）。成人票价官方资料在2,500韩元和3,000韩元之间分歧，乘船前请确认。夜间末班船的出处互相矛盾（东线20:27抵达 vs 22:30）——夜间乘坐请以当天时刻表为准。

🏝 盘浦三色岛·鹭得岛·首尔月亮

  • 盘浦三色岛 (Some Sevit / 세빛섬)（盘浦）：餐厅·屋顶酒吧（官方）。营业时间和入岛费用官方未公布。
  • 鹭得岛 (Nodeulseom / 노들섬)：首尔之光汉江光之岛庆典 (Seoul Light Hangang Bitseom Chukje / 서울라이트 한강 빛섬축제) 10/2~10/11 18:30~22:30，免费接驳车·汝矣岛出发的特别游船（首尔市）。9/18开放的1.5km滨水步道。
  • 首尔月亮 (Seouldal / 서울달)：8~10月 周日~周四 12~22点·周五周六 12~23点（首尔市）。2026年票价和周一是否休息均未公布。

🍗 汝矣岛——炸鸡啤酒·泡面文化

  • VisitSeoul把炸鸡啤酒 (Chimaek / 치맥)和便利店即食泡面列为汝矣岛汉江公园 (Yeouido Hangang Gongwon / 여의도한강공원)“必吃”的东西（官方）。汝矣渡口站 (Yeouinaru / 여의나루역) 2·3号出口。纛岛 (Ttukseom / 뚝섬)、望远 (Mangwon / 망원)、蚕院 (Jamwon / 잠원) 公园的车站·出口官方未公布。

🏊 夏季项目——今年已经结束

  • 汉江泳池·戏水场 2026：6/19~8/30，7/3起22点夜间开放，泳池 3,000/4,000/5,000韩元·戏水场 1,000/2,000/3,000韩元，蚕院 (Jamwon / 잠원) 未运营（首尔市）。明年6月公布。
  • 首尔世界烟花节 (Seoul Segye Bulkkot Chukje / 서울세계불꽃축제) 2026于9/5在汝矣岛举办，已经结束。

⚠ 常见错误5则

1. 等21点那场喷泉——2026年是19:30·20:00·20:30共3场。

2. 按2万韩元预算游船——月光32,900·烟花45,900韩元。

3. 断定汉江巴士票价——2,500~3,000互相矛盾，乘船前请确认。

4. 10月去泳池·烟花节——已经结束。改去鹭得岛光之岛庆典（~10/11）。

5. 夜里坐汉江巴士回程——末班时间出处互相矛盾。以地铁为主。

⚙ FAQ 6则

1. 一晚的路线怎么排？——汝矣岛炸鸡啤酒（汝矣渡口站2号口）→ 19:00或22:00游船 → 或盘浦喷泉 19:30~20:50。

2. 喷泉免费吗？——免费。公园24小时开放。

3. 游船在哪里上船？——汝矣岛码头（汝矣东路290号）。

4. 汉江巴士能到哪里？——蚕室~汝矣岛、麻谷~汝矣岛。首尔林至10月为止。

5. 10月有什么庆典？——鹭得岛光之岛庆典 10/2~11，18:30~22:30，免费。

6. 首尔月亮开到几点？——周五·周六到23点，其余日子22点（8~10月）。
