济州咖啡馆13家 — 只选外国评论率先留下的地方

副标题: 继济州东部面包店一行(#1407)、当地人餐厅与五日市场(#1348)、济州餐厅14家(#1437)之后的新轴线——机场附近的烘焙咖啡馆、老城区有英文菜单的烘焙室、Gyorae的庭院咖啡馆、月汀·金宁海边咖啡馆、涯月的酸面团面包、西归浦的面包店。只选Naver地图上外语评论率先留下的咖啡馆，共13家，分成4个区域，方便按住宿区域挑选。占座·马克杯·归还台这类咖啡馆内的规则见#1378

ISSUE 06 · #1438 · 2026-11-23 · 济州咖啡馆

🎯 为什么以"三语评论"为标准

已经有一篇挑选店铺的济州面包·咖啡馆篇——济州东部面包店一行(#1407)。这一篇13家里没有#1407出现过的店。只是月汀里的咖啡馆 (Cafe Guhalgu Jeju / 카페구할구 제주)与#1407里月汀里的面包店 (Oneuldo Hwachang / 오늘도화창)在同一条巷子 (Woljeong 5-gil / 월정5길)，金宁的咖啡馆 (Cafe Moalboal / 카페모알보알)与#1407里金宁的六家店在同一个街区，所以可以放进同一天的动线。

筛选标准只有一个——Naver地图上同时留有英语·日语·中文评论的咖啡馆。不是韩国人气排行，而是判断已经有外国人到访并用三种语言留下痕迹的地方，对下一位外国游客来说最不陌生。评论数是2026-11的快照，每家店都标出来。例外有两家——甜点咖啡馆 (Mamarong / 마마롱)和咖啡馆 (Janmulgyeol / 잔물결)没有中文评论(两家都是5·1·0)，但一家是涯月中山间的蛋糕甜点咖啡馆，一家是金陵的手冲烘焙咖啡馆，是西部区域风格不同的两家，所以收录。

⚠ 标注原则: 营业时间·休息日·菜单价格是店主登记在Kakao地图上的值(2026-11-23确认)。价格标的是1杯饮品·1份甜点的登记价。没有登记价格，或菜单登记超过2年的店标"以Kakao地图当日确认为准"。饮食提示只写菜名和店主菜单说明上能读出来的内容——食材·过敏原点单前向店员确认。济州很大，区域之间要坐车或公交移动。这一篇不标移动时间——当天用Kakao地图导航确认。

① 济州市 (机场·老城区) — 2家

济州机场附近和老城区。两家都在09:00开门——与面包店 (Sisterfield / 시스터필드)一起是13家里最早的。抵达当天的第一杯或离开当天的最后一杯可以放在这里。

  • 咖啡馆 (Yudong Coffee Sogeum Gongjang-jeom / 유동커피 소금공장점) — 位于济州机场附近的洞 (Yongdamsam-dong / 용담삼동)的烘焙咖啡馆。美式咖啡₩5,500，拿铁咖啡₩5,500，冷萃咖啡₩5,000，艾草年糕拿铁 (Ssuk-tteok Latte / 쑥떡라떼)₩6,000，海啸海云台咖啡 (Tsunami Haeundae Coffee / 쓰나미 해운대커피)₩6,500。美式咖啡可以在4种咖啡豆中选择(店主说明)。面包·甜点没有登记价格，到店里看。外语评论合计15条，是这一篇里最多的，英·日·中各留了5条的只有这一家。每天09:00~18:00(最后点单17:30)，休息日是春节·中秋当天。济州市 (Yongmaseo 1-gil 30 / 용마서1길 30)。Kakao地图上有免费停车·轮椅标签。饮食提示: 拿铁类含牛奶。艾草年糕拿铁如其名含年糕，所以要询问食材。咖啡类含咖啡因。
  • 烘焙室 (Kieki Roasting Room / 키에키 로스팅 룸) — 老城区的洞 (Ido 1-dong / 이도일동)的烘焙室。Kakao地图菜单12个里大部分以英文登记——Flat white ₩5,500，Latte ₩5,500，Cappuccino ₩6,000(Only hot)，Matcha latte ₩6,500，espresso ₩4,500，Biscotti ₩2,800，Almond bun ₩5,500，Sand cookie ₩4,500，把拿铁和Biscotti搭配的Latte & biscotti ₩8,000(这个套餐里的Biscotti也要问有没有坚果)。每天09:00~18:00。济州市 (Jungang-ro 88-1 / 중앙로 88-1)(Kakao地图上的店名相同)。Kakao地图上显示没有停车场，开车去的话先找附近的停车场。饮食提示: Almond bun含杏仁(坚果)。Biscotti是常放杏仁等坚果烤制的意大利点心，所以要问有没有坚果。小豆蔻拿铁(kiroro spice oat)菜名里有燕麦，但是否把牛奶换成了燕麦饮品，点单时询问。Matcha latte的抹茶和咖啡含咖啡因。

② 东部 (朝天·旧左) — 3家

分为中山间地带 (Gyorae / 교래)·月汀·金宁。中山间地带 (Gyorae / 교래)在朝天的中山间，月汀·金宁在东北侧海边。月汀·金宁两家与#1407的面包店在同一个街区，所以可以放进同一天。

  • 咖啡馆 (Cafe Malo / 카페말로) — 朝天邑的里 (Gyorae-ri / 교래리)的户外庭院咖啡馆。Kakao地图上登记的店名是咖啡馆 (Malo / 말로)。有拿铁 (Malona Latte / 말로나라떼)·美式咖啡·拿铁咖啡3个菜单，但价格登记是2023-04的值，所以现在的价格以Kakao地图当日确认为准。每天11:00~18:00(公休日相同)。朝天邑 (Namjo-ro 1785-12 / 남조로 1785-12)。Kakao地图上有可携带宠物·轮椅·免费停车标签。外语评论7条中英语有5条。饮食提示: 拿铁类含牛奶，咖啡类含咖啡因。
  • 咖啡馆 (Cafe Guhalgu Jeju / 카페구할구 제주) — 月汀里巷子里的济州老屋咖啡馆。Kakao地图登记的菜单只有美式咖啡₩6,500一个，其他饮品·甜点价格到店里看。每天10:00~19:30——是这个区域三家里最晚打烊的。旧左邑 (Woljeong 5-gil 48-2 / 월정5길 48-2)。有免费停车·可打包标签。外语评论10条(4·3·3)。饮食提示: 登记菜单只有美式咖啡一个，从菜名读不出任何提示——选甜点时要询问食材。
  • 咖啡馆 (Cafe Moalboal / 카페모알보알) — 金宁海边公路的海景咖啡馆。拿铁咖啡₩8,000，济州抹茶拿铁₩8,500，红薯拿铁₩8,500——登记了15种饮品，美式咖啡·冷萃咖啡·黑糖拿铁等的价格登记是2024-04的值，所以以Kakao地图当日确认为准，没有甜点价格。每天10:30~18:30。旧左邑 (Gujwahaean-ro 141 / 구좌해안로 141)。Kakao地图上有禁止儿童入内标签——带孩子的话选别的地方。也有可携带宠物·免费停车标签。外语评论10条(5·3·2)。饮食提示: 拿铁类菜名里有牛奶，抹茶拿铁有抹茶，黑糖拿铁有黑糖，红薯拿铁有红薯。抹茶和咖啡含咖啡因。

③ 西部 (涯月·翰林) — 4家

涯月 (Gwangnyeong·Jangjeon / 광령·장전)和翰林海岸 (Gwideok·Geumneung / 귀덕·금능)。四家里有三家营业日或营业时间短，所以绕西边的那天要先对好星期几和时间。

  • 甜点咖啡馆 (Mamarong / 마마롱) — 涯月邑的里 (Gwangnyeong-ri / 광령리)平和路边的蛋糕·闪电泡芙甜点咖啡馆。有闪电泡芙·Mamarong蛋糕·磅蛋糕·美式咖啡，但Kakao地图上的价格登记为“变动价格”，所以以Kakao地图当日确认为准。店主介绍里写着所有蛋糕都当天用动物性鲜奶油制作。周一休息，周二至周日10:00~18:00。涯月邑 (Pyeonghwa-ro 2783 / 평화로 2783)。有可携带宠物·可预约·可打包标签。外语评论6条中英语有5条，没有中文。饮食提示: 闪电泡芙·蛋糕·磅蛋糕是含面粉·鸡蛋·鲜奶油(乳制品)的甜点。Kakao地图介绍里提到了栗子香。咖啡含咖啡因。
  • 面包店 (Mampi / 맘피) — 涯月邑的里 (Jangjeon-ri / 장전리)的酸面团面包店。酸面团是不用商业酵母，而用面粉和水养出的天然发酵种来发起的面包——店主说明里写着德式面包 (Haus Brot)·巧克力法棍是天然发酵种。巧克力法棍₩7,000，牛奶吐司₩7,000，德式面包 (Haus Brot)₩8,500，White (牛奶咖啡) ₩6,000。只在周一至周四11:00~17:00营业——周五·周六·周日休息。 涯月邑 (Jangjeon-ro 117 / 장전로 117)。Kakao地图上只标了打包，能不能在店里吃要到店里看。饮食提示: 法棍·吐司是面粉面包，含麸质。牛奶吐司和White含牛奶，巧克力法棍含巧克力。咖啡含咖啡因。
  • 咖啡馆 (Jejusicha / 제주시차) — 翰林邑的里 (Gwideok-ri / 귀덕리)的以饮品为主的甜点咖啡馆。蜂蜜拿铁₩6,500，Flat white ₩5,500，香草拿铁冰沙₩7,000——登记菜单有3个，没有甜点价格。每天12:00~17:00，没有登记休息的星期几。翰林邑 (Gwideok 5-gil 20-14 / 귀덕5길 20-14)。Kakao地图上有没有停车场标签，也有可携带宠物标签。外语评论12条(4·4·4)，是西部区域最多的。饮食提示: 蜂蜜拿铁含蜂蜜和牛奶，香草拿铁冰沙也是拿铁，含牛奶。咖啡类含咖啡因。
  • 咖啡馆 (Janmulgyeol / 잔물결) — 翰林邑的里 (Geumneung-ri / 금능리)的手冲烘焙咖啡馆。Kakao地图登记的菜单只有Janmulgyeol综合手冲一个，价格登记是2024-02的值，所以现在的价格以Kakao地图当日确认为准。每天11:00~18:00。翰林邑 (Geumneung-gil 58-1 / 금능길 58-1)。有可预约·免费停车·可打包标签。名字相近的咖啡馆 (Janmulgyeol City Roasters / 잔물결시티로스터스)(Nohyeong)和咖啡馆 (Janmulgyeol Coffee House / 잔물결커피하우스)(Ido)是济州市一侧的另外两家店。外语评论6条中英语有5条，没有中文。饮食提示: 手冲咖啡含咖啡因。其他菜单没有登记，到店里看。

④ 西归浦·南部 — 4家

西归浦的洞 (Seho-dong / 서호동)·洞 (Gangjeong-dong / 강정동)(西侧)·洞 (Hahyo-dong / 하효동)，以及安德的里 (Deoksu-ri / 덕수리)。面包店 (Chaejeomseok Bakery / 채점석 베이커리)在Seho-dong，面包店 (Sisterfield / 시스터필드)在Gangjeong-dong，咖啡馆 (Sunaokohi / 스나오코히)在Hahyo-dong，咖啡馆 (Oh My Salon / 오마이살롱)在安德，四家很分散，所以先用地图应用看位置。

  • 面包店 (Chaejeomseok Bakery / 채점석 베이커리) — 西归浦Seho-dong的面包店。有玛德琳·炸酥粒面包·墨鱼汁奶油奶酪面包·核桃巴斯克·橄榄恰巴塔，但价格登记是2019~2023年的值，所以现在的价格以Kakao地图当日确认为准。没有登记饮品。每天10:00~22:00，是13家里登记营业到最晚的，但店主文案里有“准备好的面包卖完就提前打烊”。西归浦 (Seohonam-ro 32beon-gil 29 / 서호남로32번길 29)(Kakao地图店名为面包店 (Chaejeomseok Bakery Bonjeom / 채점석베이커리 본점))。有可预约·可打包标签。外语评论11条(5·3·3)，是这个区域最多的。饮食提示: 面包是面粉做的，含麸质。墨鱼汁奶油奶酪含墨鱼汁(海鲜)和奶油奶酪(乳制品)。核桃巴斯克的“巴斯克”通常指巴斯克芝士蛋糕，可能含奶油奶酪·鸡蛋·乳制品，也含核桃(坚果)。玛德琳常含鸡蛋·黄油——有过敏的话向店员询问。
  • 面包店 (Sisterfield / 시스터필드) — 西归浦Gangjeong-dong的面包店(Kakao地图店名为面包店 (Sisterfield Bakery / 시스터필드베이커리))。橄榄乡村面包₩4,500(2025-12登记)。奶茶磅蛋糕·柠檬姜磅蛋糕·黄油司康·青橄榄酥皮点心是2019~2021年的登记价，所以以Kakao地图当日确认为准。两种磅蛋糕的菜名里还并列写着英文“(1 piece)”。没有登记饮品。每天09:00~18:00。西归浦 (Worldcup-ro 8 / 월드컵로 8)——有同名的其他商号(咨询·税务)，所以用地址找。有可预约·可打包标签。外语评论9条(5·2·2)。饮食提示: 黄油司康含黄油(乳制品)，奶茶磅蛋糕如其名含奶茶。乡村面包·酥皮点心是面粉面包，含麸质，橄榄类菜单含橄榄。
  • 咖啡馆 (Sunaokohi / 스나오코히) — 下孝的洞 (Hahyo-dong / 하효동)的烘焙·手冲咖啡馆。有美式咖啡A·B类型、拿铁咖啡、奶茶、抹茶拿铁，甜点“绿茶之味”·“figue”——价格登记是2023~2024年的值，所以以Kakao地图当日确认为准。店主写的咖啡豆风味说明是美式咖啡A有肉桂·草莓·蜂蜜，B有巧克力·饼干，糖浆之类的材料是否另外加入，点单时询问。每天11:00~18:00。西归浦 (Hasinsang-ro 9beon-gil 2 / 하신상로9번길 2)。外语评论6条(2·2·2)。饮食提示: 拿铁·奶茶含牛奶。甜点“figue”在法语里是无花果，“绿茶之味”菜名里有绿茶。咖啡·抹茶·绿茶含咖啡因。
  • 咖啡馆 (Oh My Salon / 오마이살롱) — 安德面的里 (Deoksu-ri / 덕수리)的咖啡·甜点咖啡馆。Kakao地图登记的菜单只有用国产栗子亲手熬煮的糖渍栗子一个，价格登记是2023-05的值，所以现在的价格和饮品价格以Kakao地图当日确认为准。周一至周六12:00~17:00(最后点单16:30)，周日休息。 安德面 (Deoksuhoegwan-ro 74beon-gil 32 / 덕수회관로74번길 32)。有可携带宠物·轮椅·可预约标签。外语评论6条中英语有4条。饮食提示: 糖渍栗子含栗子。饮品菜单没有登记，到店里看。

🗺 动线 — 按住宿区域挑选

济州区域之间是坐车·公交的距离，所以一天里连着跑好几个区域的动线并不合适。按住的地方和当天的行程选一个区域。

A. 住在济州市时 (机场·老城区)

  1. 抵达当天·离开当天 机场附近的咖啡馆 (Yudong Coffee Sogeum Gongjang-jeom / 유동커피 소금공장점)(09:00~18:00，最后点单17:30)
  2. 逛老城区的那天 烘焙室 (Kieki Roasting Room / 키에키 로스팅 룸)(09:00~18:00)——没有停车场，放在步行去的那天

B. 东部行程 (Gyorae·月汀·金宁)

  1. 去中山间的那天 Gyorae的咖啡馆 (Cafe Malo / 카페말로)(11:00~18:00)
  2. 去月汀海边的那天 咖啡馆 (Cafe Guhalgu Jeju / 카페구할구 제주)(10:00~19:30)——与同一条巷子里#1407的面包店搭配
  3. 去金宁海边的那天 咖啡馆 (Cafe Moalboal / 카페모알보알)(10:30~18:30)——禁止儿童入内，带孩子的话换成月汀一侧

C. 西部行程 (涯月·翰林)

  1. 周一至周四 涯月面包店 (Mampi / 맘피)的面包(11:00~17:00) → 翰林咖啡馆 (Jejusicha / 제주시차)(12:00~17:00)或金陵咖啡馆 (Janmulgyeol / 잔물결)(11:00~18:00)
  2. 周五至周日 面包店 (Mampi / 맘피)休息，所以涯月甜点咖啡馆 (Mamarong / 마마롱)的蛋糕(10:00~18:00) → 金陵咖啡馆 (Janmulgyeol / 잔물결)
  3. 周一 甜点咖啡馆 (Mamarong / 마마롱)休息——排到面包店 (Mampi / 맘피)·咖啡馆 (Jejusicha / 제주시차)·咖啡馆 (Janmulgyeol / 잔물결)一侧

D. 住在西归浦·中文时

  1. 早晨 Gangjeong-dong的面包店 (Sisterfield / 시스터필드)(09:00起)——磅蛋糕以1块为单位
  2. 上午到下午早些时候 Seho-dong的面包店 (Chaejeomseok Bakery / 채점석 베이커리)——面包卖完会早打烊，所以早点去
  3. 去西归浦东边下孝一侧的那天 咖啡馆 (Sunaokohi / 스나오코히)(11:00~18:00)
  4. 去安德一侧的那天(周一至周六) 咖啡馆 (Oh My Salon / 오마이살롱)(12:00~17:00)

周一甜点咖啡馆 (Mamarong / 마마롱)，周五·周六·周日面包店 (Mampi / 맘피)，周日咖啡馆 (Oh My Salon / 오마이살롱)休息。咖啡馆 (Yudong Coffee Sogeum Gongjang-jeom / 유동커피 소금공장점)在春节·中秋当天休息。打算坐公交的话，出发前用Kakao地图导航确认末班车。济州餐厅见同一框架的#1437。

⚠ 3个常见失误

  1. 去营业日·营业时间短的店却在下午晚些时候才到 — 面包店 (Mampi / 맘피)只在周一至周四11:00~17:00营业，周五·周六·周日休息。咖啡馆 (Jejusicha / 제주시차)每天12:00~17:00，咖啡馆 (Oh My Salon / 오마이살롱)周一至周六12:00~17:00(最后点单16:30)。甜点咖啡馆 (Mamarong / 마마롱)周一休息。绕西边时17点以后才去的话，其中三家已经关门了。
  2. 只相信“到22:00”的登记时间，晚上去买面包 — 面包店 (Chaejeomseok Bakery / 채점석 베이커리)登记为10:00~22:00，但店主文案里有“准备好的面包卖完就提前打烊”。以面包为目的的话要早点去。
  3. 去了名字相近的其他店 — 咖啡馆 (Janmulgyeol / 잔물결)在济州市另有咖啡馆 (Janmulgyeol City Roasters / 잔물결시티로스터스)(Nohyeong)和咖啡馆 (Janmulgyeol Coffee House / 잔물결커피하우스)(Ido)。咖啡馆 (Cafe Malo / 카페말로)在Kakao地图上登记为咖啡馆 (Malo / 말로)，面包店 (Sisterfield / 시스터필드)登记为面包店 (Sisterfield Bakery / 시스터필드베이커리)，面包店 (Chaejeomseok Bakery / 채점석 베이커리)登记为面包店 (Chaejeomseok Bakery Bonjeom / 채점석베이커리 본점)。在地图应用里不要搜店名，用这一篇的道路名地址找。

⚙ 3个常见问题

  1. 只能选一家？ — 外语评论合计最多，且英·日·中各留了5条的是咖啡馆 (Yudong Coffee Sogeum Gongjang-jeom / 유동커피 소금공장점)(15条，5·5·5)这一家。机场附近，可以放进抵达当天或离开当天的行程。以面包为目的的话，选评论11条(5·3·3)的面包店 (Chaejeomseok Bakery / 채점석 베이커리)或面包店 (Sisterfield / 시스터필드)(价格以Kakao地图当日确认为准)。
  2. Kakao地图上菜单名是英文的店有哪些？ — 把Kakao地图菜单名登记为英文的是烘焙室 (Kieki Roasting Room / 키에키 로스팅 룸)(12个中的大部分)。面包店 (Sisterfield / 시스터필드)的两种磅蛋糕菜名后附有“(1 piece)”。其余的不知道有没有英文菜单，请准备好翻译App。
  3. 想更多了解济州的面包店和咖啡馆的使用方法？ — 济州东部面包店和金宁的六家店见#1407。占座·马克杯·归还台这类韩国咖啡馆内的规则见#1378。济州餐厅见同一框架的#1437，五日市场见#1348。
