🎯 なぜ韓国のボブマトリックスなのか

外国人韓国ボブペインポイント= "空気ごはんだけ知って他のご飯知らない"。韓国ボブ= 限定正統+MZトレンド+コスパ.同じ「Korean rice」でも魚墨鉄板（分食 cluster cross・#1 苛性雨）・明瞭飯（MZトレンド #1・塩味）・空気寄せ米（基本・限定定食・クロス） cluster)・チーズチャーハン(MZグローバル#1) それぞれ違うマニア。外国人は（a）魚墨鉄板＝分食苛性雨の知らない（b）明瞭飯＝MZインスタの分からない（c）栄養飯＝限定式5色の分からない（d）釜飯＝本物の知らない。本ガイドは6種マトリックス+限定式cross。

🍚 6種 deep dive

🍳 魚墨鉄板 (Eomuk-cheolpan) — コスパ #1

  • シグネチャー: 分食 cluster cross・苛性比 #1
  • 材料: 魚묵+ご飯+野菜・味付け(鉄板炒め)
  • おすすめ店: 分食店・MZ韓国料理店・チェーン
  • 価格：7,000〜12,000ウォン/ 1人
  • 外国人親和性: ★★★★★ (#1 コスパ)

🥚 ミョンラン(Myeongran-bap) — MZ #1

  • シグネチャー: MZトレンド#1・塩味・インスタ
  • 材料：明卵（pollock roe）+ご飯+卵・キム
  • おすすめ店: MZ韓国料理店・弘大・江南・梨泰院
  • 価格：10,000〜18,000ウォン/ 1人
  • 外国人親和性: ★★★★★ (MZ #1)

🍚 ご飯 (Gonggi-bap) — 基本

  • シグネチャー：基本1空気・限定式クロス
  • 材料：白米（または雑穀）
  • おすすめ: 家庭食・限定式・MZ韓国料理店（サイド）
  • 価格: 1,000~3,000ウォン/1空気
  • 外国人親和性: ★★★ (基本)

🥘 釜飯(Sot-bap) — 限定式本物

  • シグネチャー: 限定式本格・熱さ・サクサクヌルジ
  • 材料: ご飯+豆・雑穀・軟米+釜
  • おすすめ: 限定式 (#837)・MZ韓食堂
  • 価格: 限定式コース 40～150k (含む) / 単品 12,000～25,000ウォン
  • 外国人親和性: ★★★★

🌰 栄養ご飯 (Yeongyang-bap) — 限定食 5色

  • シグネチャー: 限定式5色cluster・本物・雑穀・ナッツ類
  • 材料：白米+雑穀・豆・ナッツ・ニンジン・標高
  • おすすめ: 限定式・全州限定式
  • 価格：限定式無料/単品10,000〜20,000ウォン
  • 外国人親和性: ★★★★

🧀チーズチャーハン (Cheese-bokkeum-bap) — MZ グローバル #1

  • シグネチャー: MZグローバル#1・チーズfusion・トレンド
  • 材料：チャーハン+チーズ・卵・キムチ（オプション）
  • おすすめ: MZ韓国料理店・チーズカフェ・弘大・江南
  • 価格：12,000〜20,000ウォン/ 1人
  • 外国人親和性: ★★★★★ (MZグローバル#1)

⚠外国人の頻繁な誤り5つ

1. 「ご飯＝一つ」：ご飯=6種マトリックス。

2. 「エアギャップ=無料」: エアバップ=1,000～3,000ウォン(限定式無料含む)。

3. 「明太子=単価」：明太子=MZインスタ#1・10～18k。

4. 「釜飯＝一般」： 釜飯＝限定食本格・サクサクの麺。

5. "チーズチャーハン=外国食": チーズチャーハン=韓国MZ fusion本物。
