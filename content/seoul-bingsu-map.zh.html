首尔刨冰指南 — 红豆刨冰·韩屋茶馆·鲜果刨冰9家(东冰库·夫冰·守然山房·La Fraiche Fruit)夏季限定与全年营业店铺 (2026年10月官方数据)

副标题: 东冰库 (Dongbinggo / 동빙고) 本店 10:30~22:00·全年无休(VisitKorea) · 夫冰 (Bubing / 부빙) 所有菜品均为1人份,周一·周二休息(VisitKorea) · 守然山房 (Suyeon Sanbang / 수연산방) 南瓜刨冰(VisitKorea) · La Fraiche Fruit (Rafeuleplureuteu / 라프레플루트) 不用冷冻水果,只用当季水果做刨冰(VisitKorea) · 酒店芒果刨冰从5月起季节性销售[二手资料] — 截至2026-10-21

🎯 本指南的使用方法

勺子一插下去,细细刨成的牛奶冰就轻轻塌陷,底下露出亲手熬煮的红豆 — 东冰库 (Dongbinggo / 동빙고) 的红豆刨冰在冰上堆满红豆、牛奶和年糕,拌匀了吃(VisitKorea)。本指南把首尔菜单上有刨冰的店分成三类:红豆刨冰专门店、韩屋茶馆刨冰、鲜果·抹茶刨冰。所有店铺都是韩国观光公社旅游信息(VisitKorea, TourAPI)中介绍过刨冰的地方。

不少店把刨冰当作夏季菜单,口味和价格每年都会变。所以这里只写了店名·地址·官方收录的菜品。今年的菜单和价格,去之前请通过店铺官方社交媒体或电话确认。我们把全年营业的刨冰专门店(东冰库)和只在夏季卖刨冰的茶馆区分开了,按季节挑选即可。

🍧 红豆刨冰专门店 — 2家

  • 东冰库 (Dongbinggo / 동빙고) 本店 — 首尔龙山区 (Yongsan-gu / 용산구) 二村路 (Ichon-ro / 이촌로) 319 现代公寓 (Hyundai Apartments / 현대아파트)(京义中央线西冰库站 (Seobinggo-yeok / 서빙고역) 1号出口附近)。10:30~22:00,全年无休。招牌菜是红豆刨冰,还有甜红豆粥 (danpatjuk / 단팥죽)·炒谷物粉红豆刨冰 (misutgaru patbingsu / 미숫가루팥빙수)·草莓刨冰·绿茶刨冰·咖啡刨冰。基本款是只放红豆和年糕的原味刨冰,年糕可以加。店面小,会发排队号。可打包·可预约·可刷卡,无停车位(附近有公共停车场)。电话 02-794-7171(VisitKorea)。离国立中央博物馆和国立韩文博物馆很近
  • 夫冰 (Bubing / 부빙) — 首尔钟路区 (Jongno-gu / 종로구) 彰义门路 (Changuimun-ro / 창의문로) 136(付岩洞 (Buam-dong / 부암동))。13:00~19:30(最后点单19:00),周一·周二休息。店名是“付岩洞刨冰店 (부암동 빙수집)”的缩写。红豆刨冰是招牌,还有草莓刨冰·焦糖刨冰·抹茶刨冰,据介绍甜玉米·土豆·无花果刨冰很受欢迎。所有菜品均为1人份,红豆是店家自己签约种植的。无停车位。电话 02-394-8288(VisitKorea)

🏠 韩屋茶馆刨冰 — 4家

  • 守然山房 (Suyeon Sanbang / 수연산방) — 首尔城北区 (Seongbuk-gu / 성북구) 城北路26街 (Seongbuk-ro 26-gil / 성북로26길) 8(城北洞 (Seongbuk-dong / 성북동))。周三至周五 11:30~17:50(最后点单17:00),周六 11:30~20:00(最后点单19:10),周日 11:30~19:50(最后点单19:00),周一·周二休息。这是首尔市民俗文化遗产“尚虚 李泰俊故居 (Sangheo Yi Tae-jun Gaok / 상허 이태준 가옥)”里由李泰俊 (Yi Tae-jun / 이태준) 的孙女经营的传统茶馆,招牌菜是南瓜刨冰。电话 02-764-1736(VisitKorea)
  • 半夏堂 (Banhadang / 반하당) — 首尔城北区 (Seongbuk-gu / 성북구) 城北路5街 (Seongbuk-ro 5-gil / 성북로5길) 36(城北洞1街 (Seongbuk-dong 1-ga / 성북동1가))。这是一家打通墙壁的韩屋咖啡馆,夏天供应放有干红枣的红豆刨冰。据介绍红枣和红豆100%产自韩国。还有手工果酱饮品(VisitKorea)。营业时间11:30~17:00，周二·周三休息(VisitKorea)
  • 旧茶馆 (Yetchatjip / 옛찻집) — 首尔钟路区 (Jongno-gu / 종로구) 仁寺洞街 (Insadong-gil / 인사동길) 33-1。这是地暖炕 (ondol / 온돌) 地板的传统茶馆,作为夏季菜单的刨冰,红豆是自己熬煮的。还有黄豆粉冰淇淋·覆盆子 (bokbunja / 복분자) 气泡饮(VisitKorea)。营业时间11:00~21:00，全年无休(VisitKorea)。仁寺洞茶馆路线请看益善洞·仁寺洞韩屋咖啡与传统甜点12精选
  • 月亮咖啡 (Dal Cafe / 달 카페) — 首尔钟路区 (Jongno-gu / 종로구) 三清路 (Samcheong-ro / 삼청로) 94-1(三清洞 (Samcheong-dong / 삼청동))。这是一家韩屋咖啡馆,招牌是用粗冰做的传统瓮罐刨冰。华夫饼每天早上在店里现拌面糊(VisitKorea)。营业时间平日10:00~17:30·周末10:00~18:00，全年无休(VisitKorea)

🍑 鲜果·抹茶刨冰 — 3家

  • La Fraiche Fruit (Rafeuleplureuteu / 라프레플루트) — 首尔城东区 (Seongdong-gu / 성동구) 首尔林2街 (Seoulsup 2-gil / 서울숲2길) 8-8(纛岛站 (Ttukseom-yeok / 뚝섬역) 8号出口,城水中学 (Seongsu Middle School / 성수중학교) 附近)。这是水果专门咖啡馆,招牌是水蜜桃刨冰·芒果刨冰,不用冷冻水果,用当季水果做刨冰。可携带宠物(VisitKorea)。官方渠道是Instagram @rafre_fruit(VisitKorea收录)。营业时间平日13:00~19:00·周末13:00~20:00，全年无休(VisitKorea)
  • 首尔林森林 (Forest Seoulsup / 포레스트 서울숲) — 首尔城东区 (Seongdong-gu / 성동구) 首尔林2街 (Seoulsup 2-gil / 서울숲2길) 20-12。有能看到首尔林的露台,卖用鲜水果而非冷冻水果做的鲜果刨冰和鲜水果手工麻糬(VisitKorea)。营业时间11:00~20:00(最后点单19:00)，全年无休(VisitKorea)
  • 土多咖啡 (Cafe Toda / 카페 토다) — 首尔瑞草区 (Seocho-gu / 서초구) 城村6街 (Seongchon 6-gil / 성촌6길) 39(新盆唐线良才市民之林站 (Yangjaesimin-ui-sup-yeok / 양재시민의숲역) 5号出口)。主打贝果·早午餐的咖啡馆,菜单上有抹茶刨冰。是农林畜产食品部认定的放心餐厅 (anshim sikdang / 안심식당),可携带宠物,有收费代客泊车(VisitKorea)。营业时间平日07:30~19:00·周末09:00~19:00，春节当天休息(VisitKorea)

🥗 饮食须知

  • 价格带: 9家店在VisitKorea收录信息中都没有价格。价格未公布 — 请看店内菜单或打电话确认。作为参考,据报道2026年首尔特级酒店的芒果刨冰为83,000~149,000韩元(韩国经济 2026-05-01 [二手资料]) — 官方价格请在各酒店渠道确认
  • 乳制品: 东冰库 (Dongbinggo / 동빙고) 的红豆刨冰是在冰上浇牛奶(VisitKorea)。很多店的刨冰会用牛奶冰·炼乳,乳糖不耐受或纯素食者点单前请先问清楚
  • 素食: 红豆·年糕·水果是植物性的,但配料可能含炼乳·奶油·冰淇淋。能不能去掉动物性食材因店而异
  • 过敏原: 请注意炒谷物粉 (misutgaru / 미숫가루)·黄豆粉(谷物·大豆)和坚果配料。东冰库 (Dongbinggo / 동빙고) 的炒谷物粉红豆刨冰,旧茶馆 (Yetchatjip / 옛찻집) 的黄豆粉冰淇淋(VisitKorea)
  • 清真(Halal): VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的伊德 (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙丹路10街 (Usadan-ro 10-gil / 우사단로10길) 15,每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF, 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。本指南中的店铺没有清真标识
  • 出示用卡片请看#1300 饮食需求手册

🧰 刨冰实用信息 — 独自一人、预约、支付、点单、交通

  • 独自一人: 夫冰 (Bubing / 부빙) 所有菜品都是1人份,独自去很方便(VisitKorea)。其他店请在点单前问清一碗的大小。适合独自去的地点地图请看首尔单人用餐地图 — 外国人1人餐厅·酒吧·咖啡馆12个招牌
  • 预约: 收录为可预约的是东冰库 (Dongbinggo / 동빙고) 本店。有人排队时领取排队号(VisitKorea)
  • 支付: 收录为可刷卡的是东冰库 (Dongbinggo / 동빙고) 本店(VisitKorea)。银行卡·移动支付请看外国人韩国支付系统深度探索
  • 点单: 很多咖啡馆是在柜台点单后领取震动叫号器 — 韩国咖啡厅震动叫号器流程,零慌张手册 — 点完餐之后该做什么。语言不通时请看语言不通时的礼仪 — 翻译App与自助点餐机时代的点餐礼仪
  • 交通: 东冰库 (Dongbinggo / 동빙고) 在西冰库站 (Seobinggo-yeok / 서빙고역) 1号出口,La Fraiche Fruit (Rafeuleplureuteu / 라프레플루트) 在纛岛站 (Ttukseom-yeok / 뚝섬역) 8号出口,土多咖啡 (Cafe Toda / 카페 토다) 在良才市民之林站 (Yangjaesimin-ui-sup-yeok / 양재시민의숲역) 5号出口(VisitKorea)。交通卡请看韩国交通卡3种选择,零慌张手册 — 按我的行程原样挑卡

⚠ 常见的4个错误

1. “刨冰只在夏天卖” — 东冰库 (Dongbinggo / 동빙고) 本店全年无休供应红豆刨冰。相反,半夏堂 (Banhadang / 반하당)·旧茶馆 (Yetchatjip / 옛찻집) 把刨冰作为夏季菜单介绍(VisitKorea) — 冬天可能没有刨冰,请打电话确认

2. “刨冰是一大碗大家分着吃” — 夫冰 (Bubing / 부빙) 所有菜品均为1人份(VisitKorea)。每家店不一样

3. “酒店刨冰随时都能吃” — 首尔新罗酒店 (Seoul Shilla Hotel / 서울신라호텔) “The Library (더 라이브러리)”的芒果刨冰于2026年5月1日开始销售,据报道价格为130,000韩元(韩国经济 [二手资料])。这是季节性销售,期间·价格·预约请在酒店官方渠道确认

4. “去年吃过的菜品今年也有” — 季节性刨冰每年都会变。按店名去找,但菜品请通过官方社交媒体·电话确认
