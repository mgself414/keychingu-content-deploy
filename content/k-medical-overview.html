왜 K-medical인가

한국 의료관광 = 연 60만+·세계 #5·다국어 풀 cover·외국인 매니아 1순위·CMC·아산·세브란스 + 강남·MZ 매니아 풀세트.

12선 4축

축 2: 전문분야 (3선)

2. KHIDI 다국어 풀 cover

5. Klook·KKday 패키지

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (당일 + 시내 핵심 풀세트)
  • 예산: 80,000~150,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용

⏱ 시간대별 동선 추천

점심 (11:00~14:00) 한정식·시그너 음식·박물관 가성비 매트릭스

✈️ 외국인 매니아 매트릭스

  • 외국인 첫 진입: 영문 풀세트·결제 카드 OK·픽업 매트릭스 #1
  • 재방문 매니아: 사장님 서비스·시즌 시그너·단골 노하우
  • 인스타 매니아: MZ 매트릭스 #1·한복·매니아 매트릭스
  • 귀국 후 매니아 유지: 한국 한인마트·글로벌 매장·SNS K-pop·K-드라마 매니아 매트릭스 #1

💡 추가 외국인 페인포인트 가이드

  • 언어: 영문·일문·중문 풀세트 매장 우선 추천·손가락 + 사진 주문 OK
  • 결제: 카드 80%·노포 일부 현금·모바일 페이 (카카오페이·네이버페이) 외국인 X
  • VAT 환급: 매장 표시 (Tax Refund)·5만원+ 환급·공항 환급 카운터
  • 응급: ☎ 1339 (의료, 영문)·☎ 1330 (관광 통역)·☎ 112 (경찰, 영문)·☎ 119 (소방·구급, 영문)
  • 무료 WiFi: 시내·도시철도·공항 풀세트·T 멤버십 + KT 외국인 SIM
