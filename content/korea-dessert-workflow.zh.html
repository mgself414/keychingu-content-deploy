🎯 为什么选择韩国甜品工作流程指南

即使您知道[#819 6种甜点矩阵](#819) — 点餐/用餐过程是分开的。韩国甜点是（a）街头=即时+现金（b）MZ咖啡馆=售货亭+卡+Instagram照片（c）酒店刨冰=预订+服务费+房费（d）韩屋咖啡馆=正宗氛围+传统饮料搭配。外国人对以下内容感到困惑：(1)即食热饼+小心烫伤(2)与团体分享刨冰+合影(3)MZ咖啡馆英文亭(4)不确定饮料搭配。本指南为5步+配对+Instagram拍摄技巧+英语口语。

★ 5 步工作流程概览

步骤 行动 时间 外国人的要点
1️⃣ 频道选择 街/MZ咖啡厅/酒店/韩屋咖啡厅 立即 根据时区、伴侣和预算量身定制
2️⃣ 菜单点菜 甜点+饮料搭配 2~5分钟 刨冰=2-3人共享的标准
3️⃣ 接收 + Instagram 照片 即时（街头）/ 5~10 分钟（咖啡馆） 5-10 分钟 照片#1=咖啡馆氛围+甜点
4️⃣ 饮食+配对 甜点+饮料（咖啡、茶、拿铁） 15-30 分钟 Hotteok = 小心烫伤（冷却后）
5️⃣ 付款 现金（街上）/卡（咖啡馆/酒店） 1~3分钟 酒店=10%服务费/街=现金

> 总行程时间：街道 = 10~15 分钟 / MZ 咖啡馆 = 30~60 分钟 / 酒店 = 1~2 小时

🍽 订单工作流程（按渠道）

🥞 街头小摊（A 型 — hotteok、bungeoppang、dalgona）

1. 排队等候（热门摊位=等待5-10分钟）

2. 准备现金 (2,000~4,000韩元)

3. 选择类型/数量（“请给我 2 个 hotteok”）

4. 即时获取（1-3分钟）— 注意高温

5. 站着吃或外卖

☕ MZ Cafe（B 型 — 药果、达戈纳拿铁、刨冰）

1. 柜台/自助服务终端订单

2. 菜单选择（甜点+饮品搭配）

3. 付款（卡、Kakao Pay、Samsung Pay OK）

4. 领取号码牌和震动铃

5. 餐桌餐（30~60分钟+Instagram照片）

🏨 酒店刨冰（C 型 — 新罗、乐天、威斯汀）

1. 提前预订（Naver 预订/电话）— 5 月至 9 月季节 = 建议提前 1-2 周

2. 酒店咖啡厅/酒廊入口

3. 选择菜单（40,000~80,000韩元，1份刨冰，2~3人分享）

4. 付款（房费、卡/10%服务费另算）

5. 1~2小时餐+Instagram照片

🏯 韩屋咖啡厅（D 型 — 仁寺洞、益善洞、北村）

1. 现场或预约

2. 选择菜单（传统+现代搭配）

3. 付款（刷卡即可）

4. 韩屋氛围+甜点 (1~2小时)

5. Instagram上排名第一（韩屋+甜点组合）

⚠ 外国人常犯的7个错误

1. “Hotteok = 立即食用”：Hotteok = 90~100°C 非常热。冷却1-2分钟后。小心儿童烧伤。

2. “刨冰=每人1块”：刨冰= 2-3人标准分享。每人1个=太多+性价比↓。

3. **《冰宿酒店预订》

4. “MZ Cafe Kiosk = English X”：部分自助服务终端支持英语。如果不知道，可以直接去柜台订购。

5. “甜点=餐后”：韩式甜点=专属狂热（咖啡厅时间=仅甜点可以1~2小时）。

6. “街头 = 卡可以”：街头摊位 = 建议使用现金。一些来自大摊位的卡片。

7. “Bungeoppang = 四个季节”：仅限冬季（11 月至 3 月）。夏天的时候几乎没有路边摊。

⚙ 8 个常见问题解答

1. 第一道甜点=哪个渠道：MZ Cafe（药瓜拿铁·达戈纳） 第一名（英语、Kiosk、Instagram）。

2. 酒店刨冰预订：新罗酒店（丽妍刨冰）·乐天酒店·威斯汀=Naver预订/电话。

3. 没有。 Instagram 上排名第一：仁寺洞韩屋咖啡馆、弘大 MZ 甜点咖啡馆、Bingsu 酒店。

4. MZ趋势：药果拿铁、达戈纳拿铁、药果牛角面包、绿茶刨冰。

5. 季节狂热：春天=药果/夏天=刨冰/秋天·冬天=Hotteok，Bungeobbang，Dalgona。

6. 过敏·怀孕：参见[#819免责声明](#819)。小心坚果、牛奶和蜂蜜。

7. 付款/小费： 街头 = 现金 / MZ 咖啡馆/连锁店 = 卡 / 酒店 = 10% 服务费 / 小费

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

Hotteok、Bungeoppang、菊花面包= 热甜点（90~100°C） — 小心烫伤（儿童请冷却1~2分钟）。刨冰=冷（牛奶过敏、糖↑）注意。孕妇=适当摄入坚果、蜂蜜、糖。过敏（麸质、坚果、牛奶、鸡蛋、蜂蜜、大豆）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

店铺信息免责声明：街边小摊/季节性店铺经常更换——建议参观前使用NAVER/Kakao地图或本地搜索。

饮食限制后备：

  • Halal/Kosher：6种类型中，获得认证的商店很少。 → Yakgwa/Dalgona = 不含动物成分（有些是清真/犹太洁食）。
  • 素食/纯素食：药果/达尔戈纳 = 素食还可以（检查蜂蜜和牛奶）/ Hotteok/刨冰 = 大量牛奶和鸡蛋 → 独立的纯素食咖啡馆。
  • 无麸质：仅提供刨冰（不包括面粉配料）。
