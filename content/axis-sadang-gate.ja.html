ソウル東西軸⑥ 舎堂、夕方 — ソウルを出る門: 食堂横丁・乗り換えバス停・冠岳山入口

副題: 2号線東半円(#1359)の西端。舎堂駅は出口14、冠岳・銅雀・瑞草三区が交わる。夕方の出口横丁・乗換バス停・南泰嶺の先、冠岳山入口まで約1時間半。登山なし。Seoul E-W Axis 6回目。

ISSUE · #1361 · 2026-09-07

🎯 フレーム — ソウルを出る門

ソウルの関門は空港とソウル駅だけではない。舎堂駅 (Sadang Station / 사당역) は毎晩数万人がソウルの外へ出る門だ。2号線と4号線が交わり、果川 (Gwacheon / 과천)・安養 (Anyang / 안양)・水原 (Suwon / 수원)・軍浦 (Gunpo / 군포)・華城 (Hwaseong / 화성) 方面の広域バスが駅前のバス停で人を乗せ、南泰嶺 (Namtaeryeong / 남태령) 峠を越える。南北軸(#1353)が南山トンネルで都心へ入ったのに対し、この回は都市が終わる場所に立つ。

同時に舎堂は三つの区の境界だ。交差点を基準に4・5・6番出口は冠岳区 (Gwanak-gu / 관악구)、7~10番出口は銅雀区 (Dongjak-gu / 동작구)、残りは瑞草区 (Seocho-gu / 서초구)。そして4番出口から15分で冠岳山 (Gwanaksan / 관악산) の登山道が始まる。この回は夕方にその境界を歩く — 帰宅ラッシュの乗り換えバス停、食堂横丁の灯り、そして山の入口の暗闇まで。

  • 総所要時間: 約1時間30分(徒歩約40分 + バス停・横丁滞在)
  • おすすめ時間帯: 午後5時30分~6時出発 — 乗り換えバス停が最も混む時間帯を過ぎ、日暮れ時に冠岳山入口に着く。登山道には入らないので暗くなっても構わない
  • 傾斜: 低~中 — 冠岳山入口方向だけ緩やかな上り坂

🚶 コース — 歩く順序そのままに

起点は舎堂駅。2号線東半円(#1359)の終着点であり4号線への乗換駅。

① 舎堂駅 → 出口を選ぶ → 食堂横丁 (🚶 約5分)

  • 出口が14カ所ある。2号線開通時は8カ所で、4号線開通で6カ所増えた。夕方コースは冠岳区側の4・5・6番出口方向から始める — 駅裏の路地に食堂・居酒屋が密集する。特定の横丁名は付けない(公式名称未確認)。横丁を一度通り抜ける: 帰宅客が席に着き始める時間だ。
  • 📖 物語1 — 三区が出会う交差点: 舎堂交差点は冠岳区・銅雀区・瑞草区の境界だ。一つの駅の出口が三区にまたがる場所はソウルでも珍しい。境界に置かれた駅はどの町の中心でもなく、代わりに「通り過ぎる場所」になった — それがこの駅の性格だ。

② 食堂横丁 → 広域バス乗り換え停留所 (🚶 約10分)

  • 横丁を出て舎堂交差点へ。駅前の道沿いの停留所ごとに果川・安養・水原・軍浦・華城・平沢 (Pyeongtaek / 평택) 方面の広域バスが停まる。夕方6時前後、列が長くなる光景がこの回の中心だ。ソウルの人がソウルを出て行く場面。
  • 📖 物語2 — 南泰嶺: これらのバスは南へ南泰嶺峠(標高183m)を越える。ソウル冠岳区・瑞草区と京畿道果川市の境界だ。4号線南泰嶺駅 (Namtaeryeong Station / 남태령역) には2017年から上り方向の広域バスが停まり、地下鉄に乗り換えられるようになった。峠一つがソウルと京畿道を分ける — この回が舎堂を「門」と呼ぶ理由だ。

③ 停留所 → 冠岳山入口方向 (🚶 約15分・緩やかな上り坂)

  • 4番出口方向へ戻り南へ。大通りを外れて観音寺 (Gwaneumsa / 관음사) 方向の路地に入るとすぐ住宅街が終わり山が始まる。冠岳山登山道入口 — 頂上(恋主台 (Yeonjudae / 연주대))までは2時間半から3時間かかる本格的な登山道だ(#148・#738)。
  • この回は入口までだけ。日暮れの入口から振り返ると、舎堂交差点の灯りとその向こうの都市が見える。

④ 入口 → カチ山近隣公園または舎堂駅復帰 (🚶 約10分)

  • オプション: 舎堂洞側のカチ山近隣公園 (Kkachisan Neighborhood Park / 까치산근린공원)(2006年末に生態陸橋で冠岳山とつながった)を経て下りれば、住宅街の上の散策路から村の夜景が開ける(位置・経路は現地の標識で確認)。時間がなければ来た道を舎堂駅へ。
  • 締めくくり: 舎堂駅。4号線で梨水 (Isu Station / 이수역)(総神大入口 (Chongshin University Station / 총신대입구역))・銅雀方面、または2号線で江南・蚕室方面へ復帰。

🙏 マナー — このコースの核心

  • 乗り換えバス停は帰宅ラッシュだ。列の間を横切ったり、停留所前で長く撮影したりしない。
  • 食堂横丁は夕方の営業開始時間だ — 店先の陳列・テーブルを撮影しない。
  • 冠岳山入口から先は登山道だ。日没後は入らない。
  • 横丁の裏手は住宅地だ。声を低くする。

💡 戸惑いポイント

  • 出口14カ所: 降りる前に4番出口(冠岳山・横丁方向)を決め、案内板に従う。反対側(瑞草区側)に出ると交差点を二度渡ることになる。
  • 停留所が分かれている: 広域バスの停留所は方向・路線別に複数ある。見物が目的なら交差点付近の一カ所で十分だ。
  • 冠岳山は夜に登らない: この回は入口が終点だ。登山は朝に(#148)。
  • 夕方ラッシュ: 5時半~7時、舎堂駅の乗り換え通路が混雑する。荷物が大きければ避ける。

FAQ 6

Q1. 観光客が舎堂に行く理由はあるか?

  • 「ソウルがどこで終わるか」を見に行く。広域バスの列と南泰嶺峠、その先の山。名所ではなく光景が目的だ。

Q2. 食堂横丁の名前は何か?

  • 公式名称を確認できなかったため名前は付けていない。4・5・6番出口裏の横丁で十分だ。

Q3. 冠岳山に登るには?

  • 舎堂駅4番出口から観音寺方向の登山道。頂上まで2時間半~3時間。登山編#148・#738・#594。

Q4. 梨水駅と舎堂駅は別の駅か?

  • 4号線で一駅隣だ。梨水駅は1985年の開通からわずか6日で「総神大入口(梨水)」に改名された。夕方の人波の一部は舎堂の次の駅であるここで降りる。

Q5. 総論(#1359)とどうつなぐか?

  • 2号線内回りを乙支路から舎堂まで乗って降りれば、この回につながる。午前に総論、夕方にこの回なら一日でちょうど合う。

Q6. 南泰嶺の先へ行ってみるには?

  • 4号線に乗り南泰嶺・果川方面へ一駅で京畿道だ。果川ソウル大公園 (Seoul Grand Park / 서울대공원)・競馬公園は#451・#553。
