🎯 なぜ韓国元ワークフローガイドなのか

[#882全6種マトリックス](#882) 知っていても — 注文・ペア・マナーは別個。韓国展は(a) 広場市場 ビンデトック路地 (vlog #1) (b) 伝統酒店・MZ韓食堂 (雨の日破戦+マッコリ) (c) 包装馬車 (焼酎・ビールフェア)外国人は（1）雨の日＝パジョン＋マッコリ韓国文化の知らない（2）広場ビンデトック＝インスタントブチモク（3）マッコリvs焼酎フェアモール（4）ホリデーサークル＝ゲストマナー不明。このガイドは5ステップ+マッコリフェア+英語発話。

🥞 チャンネル別ワークフロー

Type A — 広場市場のビンデ餅の路地 (vlog #1)

  • シグネチャー: vlog #1・即席ブチギ・老舗
  • 時間: 09:00～22:00
  • 価格：5,000〜15,000ウォン/ 1個
  • メニュー: 緑豆ビン大餅・肉ビン大餅・キムチビン大餅・麻薬キンバップ cross
  • 外国人親和性: ★★★★★ (vlog #1)

Type B — 伝統酒店・MZ韓国料理店（雨の日マッコリ）

  • シグネチャー: 雨の日の破戦+マッコリ#1・韓国文化正統派
  • 時間: 17:00～24:00
  • 価格：パジョン8〜20k +マッコリ5〜10k
  • メニュー：破戦・海鮮破戦・じゃがいも戦・キムチ戦・緑豆ビン大餅+マッコリ
  • 外国人親和性: ★★★★ (韓国正統文化)

Type C — 屋台（焼酎安酒）

  • シグネチャー：蘇州安住・通り・老舗
  • 時間: 18:00～02:00
  • 価格：キムチジョン・ハッバ5～12k
  • メニュー: キムチジョン・ドングランテン ホットバー・ゴルバンイムチム cross ([#862](#862))
  • 外国人親和性: ★★★ (韓国語正統)

Type D — 限定式・祝祭日（サークル正統）

  • シグネチャー: 限定式コース・名節・祭事正統（[#846](#846))
  • 時間: 11:30～22:00
  • 価格: 限定式コース 40～150k (サークル含む)
  • メニュー：サークル・山賊・ハーブ（名節正統）
  • 外国人にやさしい: ★★★★（英語の一部）

🍶 マッコリ・ペアマトリックス

  • シグネチャー：雨の日+パジョン+マッコリ= 韓国の本格的な雰囲気
  • 理由：雨の音+破戦の叫び声=韓国本物
  • MZトレンド：SNSインスタ#1認証

  • "パジョン+マッコリ" = "Korean savory pancake with Makgeolli rice wine"
  • 「雨の日の本物」 = "Rainy day tradition (Pajeon + Makgeolli)"
  • "広場ビンデトック本格" = "Gwangjang market mung bean pancake (vlog#1)"
  • "江原ジャガイモ" = "Gangwon potato pancake (regional specialty)"
  • "名節サークル" = "Holiday meatball pancake (Lunar New Year・Chuseok)"
  • "カードですか？" = "Card accepted?"

＃＃⚠外国人の頻繁なミス7つ

1. 「前＝破戦のみ」：全＝6種・多様。

2. 「雨の日=偶然」: 雨の日 = マッコリフェア#1韓国文化。

3. "広場 = 一般市場": 広場ビンデトック = vlog #1 即席ブチギ正統。

4. 「マッコリ＝1種」：マッコリ＝6種（長寿・国順党・地平・江原・MZ変形）。

5. 「祭り=一般食事」: 祭り= サークル・山賊・ハーブ本物 ([#846](#846))。

6. "緑豆=豆": 緑豆(mung bean) = ビンデ餅本格・豆と違う。

7. "じゃがいも=一般":じゃがいも= 江原本格薄・じゃがいも100%。

⚙ よくある質問8件

1. 初戦 = どのチャンネル: 広場市場 緑豆ビン大餅 (#1 vlog) → 伝統酒店破戦。

2. インスタ・vlog: 広場ビンデトック(#1)・雨の日破戦・江原ジャガイモ展。

3. MZトレンド：キムチジョン・ハッバ・MZマッコリペア。

4. マッコリマニア：パジョン+マッコリ（␈MASK24​​␈）。

5. 祭りマニア: サークル（旧正月・秋夕）。

6. アレルギー・妊娠: [#882 disclaimer](#882)参照。

7. 決済・チップ: カードOK / マーケット=現金一部/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

全＝一般食品・油使用。妊婦・子ども＝OK（マッコリX）。アレルギー（小麦粉グルテン・シーフード・豚・卵・緑豆）事前告知。マッコリ＝6～8％ アルコール・妊婦・運転X. 食中毒の疑いがある場合本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャ: パジョン・ジャガイモ戦・キムチ戦=OK(豚・甲殻類一部確認)/マッコリ=アルコールX(ハラルX)。
  • ベジタリアン・ビーガン: パジョン・ジャガイモ展・キムチジョンベジタリアンOK(卵オプション) / ビー菜食
  • グルテンフリー: 小麦粉含有→難易度・じゃがいも = 少ない（事前確認）。
