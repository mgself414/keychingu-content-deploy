⚠ 외국인 자주 실수 5가지

1. "기생충 촬영지 = 어렵게 찾음": 기생충 자하문 계단 = 종로구 자하문로 부근 (시내버스 1020·7022) + 외국인 매니아 vlog 1번지·아현동 슈퍼·정자동 외곽 패키지.

2. "오징어게임 = 그냥 TV쇼": 오징어게임 = Netflix 한국 #1 (2021·2024) + 쌍문동·강북·도봉·외국인 vlog 1번지·KTO 인증 코스 + 1박2일 풀세트.

3. "도깨비 = 한국에만 있음": 도깨비 촬영지 = 인천 차이나타운·강릉 주문진 방파제·운현궁·캐나다 퀘벡 + 외국인 매니아 1순위 (#144·#260).

4. "이태원 클라스 = 이태원에만": 이태원 클라스 = 녹사평·단밤·이태원 (#144) + 외국인 매니아 + 한남 1박2일 패키지.

5. "BTS MV = 못 찾음": BTS MV 촬영지 = HYBE 용산·SM 성수·YG 합정·JYP 강동 4 기획사 + 영동대로·반포·#207 후속 풀세트.

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (당일 + 시내 핵심 풀세트)
  • 예산: 80,000~150,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
