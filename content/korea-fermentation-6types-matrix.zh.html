🏺 6 种深度潜水

🟤 大酱 — 韩国美食 #1

  • 招牌：所有汤、炖菜和配菜的基本韩国食品·Meju → 黄豆酱 + 酱油单独正宗
  • 成分：Meju（发酵大豆块）+盐水
  • 发酵：6个月至1年+（传统Jangdokdae）
  • 外国人友善度：★★★★★（韩餐#1·日本微笑识别）
  • 与日本味噌的区别：韩国大酱 = 香气更浓，发酵↑，咸味 / 日本味噌 = 柔软，甜味
  • 主菜单：大酱炖菜、大酱汤、ssamjang (jang)、bossam

🌶 辣椒酱 — 全球 #1

  • 签名：K-food全球知名度#1 +是拉差替代品/辣酱全球趋势
  • 成分：Meju + 红辣椒粉 + 糯米 + 麦芽
  • 发酵：3~6个月
  • 外国人友好度：★★★★★（全球意识/趋势）
  • 全球扩张：CJ、大象全球出口、海外超市、亚马逊畅销书
  • 主菜单：石锅拌饭，炒年糕，炒肉，炖菜，酱汁

🤢Cheonggukjang — 浓浓的香气

  • 特色：快速发酵（2-3天）+浓郁香气+草本健康
  • 成分：大豆+秸秆（传统发酵培养基）
  • 外国人友善度：★★（刚开始要小心，类似日本的纳豆，香味浓郁）
  • 健康：益生菌↑·芽孢杆菌
  • 主菜单：清国酱炖菜和清国酱粉
  • 给外国人的提示：如果你喜欢日本纳豆，可以尝试一下，否则就避免它。

🟫 Ganjang — 全球

  • 招牌：Meju→黄豆酱+酱油分离正宗·传统朝鲜酱油与日本酿造酱油的区别
  • 类型：
  • 朝鲜干姜（Joseon ganjang）：正宗、咸、汤和蔬菜的狂热
  • 酿造酱油（Yangjo ganjang）：日式，甜，一般烹饪
  • 汤用酱油：仅用于汤
  • Jic酱油：一般烹饪
  • 外国人友好度：★★★★★（全球/日本酱油认可）
  • 主菜单：所有韩国调味料、汤、蔬菜和炒菜

🍶 醋（食草）

  • 类型：米醋、果醋（苹果、李子）、红醋、黑醋
  • 外国人友好度：★★★★（全球意识）
  • 主菜单：调味食品、醋汁、调料、煎饼、酸菜

🦐 Jeotgal — 狂热

  • 类型：
  • Saeujeot：泡菜、饺子和汤的调味料
  • 凤尾鱼鱼露 (Myeolchi aekjeot): 泡菜调味料 #1
  • 明太子（明南）：MZ Trend·Bob Fair
  • 咸鱿鱼：釜山招牌
  • 昌南咸鱼和带鱼酿盐：Mania
  • 外国人友好度：★★★（海鲜意识和发酵）
  • 主菜单：泡菜调料，配菜，米饭搭配

🏺 藏德台传统

Jangdokdae = 韩国发酵的正宗签名

  • Jangdokdae：院子里接收阳光的罐子（陶器）的集合
  • Meju→章节分离正统：

1. Making Meju (Autumn, boiling beans + fermentation)

2. Soaking soybean paste (New Year’s Day, Meju + Salt Water)

3. Separating the intestines (March, separating soybean paste and soy sauce)

4. 成熟（6个月至3年+）

  • 国外视频博客：
  • 顺昌长流村（全北）——传统红辣椒酱的故乡（地理标志和传统食品大师注册）
  • 潭阳长德台（全罗南道）— 东正教
  • 昌德宫（首尔）——朝鲜王朝正统皇家食品的一部分（国家非物质遗产第38号）

⚠ 外国人常犯的5个错误

1. "Korean soybean paste = Japanese miso": Korean soybean paste = Meju fermentation + rich aroma.日本人的微笑=温柔、甜美。不同的食物。

2. "Gochujang = Sriracha": Gochujang = fermented meju + spicy, sweet, complex flavor.是拉差=辣/甜。不同的类别。

3. "Cheonggukjang = Natto": Cheonggukjang = Korean fast-fermented soybean (oriental medicine health).日本纳豆=另一种发酵方法。相似/不同的食物。

4. “酱油 = 一种”：韩国酱油 = 朝鲜酱油（传统）与酿造酱油（普通） 区别。因菜单而异。

5. "Jeotgal = regular seafood": Jeotgal = fermented seafood (3 months to 1 year+).正宗的泡菜调料+米饭的搭配。

⚠ 医疗/安全/饮食免责声明

发酵食品=普通食品（药品X）。 谨防高盐分（黄豆酱、辣椒酱、酱油=盐↑）——高血压、肾病患者慎用。孕妇=适量清谷酱(cheonggukjang)等强发酵食品。儿童=清国酱和咸鱼爱好者请注意进入市场。过敏（大豆、海鲜、水果）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

饮食限制后备：

  • 清真/犹太洁食：豆酱、红辣椒酱、酱油、醋=酒精、动物成分
  • 素食/纯素食：豆酱、红辣椒酱、酱油、醋、Cheonggukjang = 素食 OK / Jeotgal = 非素食。
  • 无麸质：普通酱油/红辣椒酱=麸质
