⚠ 외국인 자주 실수 5가지

1. "한국 = 현금만": 한국 현금 사용률 = 20% 미만 (2026 기준) + 카드·페이 80% + WOWPASS·Naver Pay·KakaoPay 외국인 매니아 1번지 + #414 통합.

2. "외국 신용카드 = 안됨": Visa·Mastercard = 99% 매장 사용 OK + 외국인 매니아 #1 + 면세점·백화점·외국인 친화 식당 (#400) + 단, 일부 노포·전통시장은 현금 (#380).

3. "Naver Pay·KakaoPay = 외국인 못 씀": 외국인 OK = WOWPASS 연동 + 외국인 계좌 (F-2·F-5) + 한국 폰번호 + 외국인 매니아 1번지 + #252·#398 통합.

4. "송금 = 비쌈": Wise·Revolut·Remitly = 수수료 0.5~1% (은행 대비 1/5) + 외국인 매니아 #1 + 영어 OK + 외국인 매니아·#252 통합.

5. "카드 분실 = 답 없음": 24h 콜센터 = 외국인 영어 OK 콜센터 (Visa·Mastercard·신한·국민) + 카드 즉시 정지 + 재발급 1~3일 + #405 안전 통합.
