한국 비빔밥 5종 매트릭스 — 전주·돌솥·셀프·산채·해물 풀세트

> 부제: 외국인 관광객용 5색 정통 + 전주 한옥마을·돌솥·셀프 비빔밥·산채·해물 (UNESCO 무형유산 cluster)

ISSUE 03 · #879 · 2026-06-09

🎯 왜 한국 비빔밥 매트릭스인가

외국인 한국 비빔밥 페인포인트 = "비빔밥 = 한 가지" 알고 다 같다고 생각. 한국 비빔밥 = 5색 나물 + 5가지 변형 매니아. 같은 "Korean Bibimbap"이라도 전주 (정통 #1·궁중·UNESCO)·돌솥 (Stone pot·뜨거움·바삭)·셀프 (MZ·DIY)·산채 (사찰음식 cluster)·해물 (회 cluster cross) 각자 다른 변형·매니아. 외국인은 (a) 5색 나물 풀세트 모름 (b) 돌솥 = 뜨거움 + 바삭 모름 (c) 셀프 비빔밥 = MZ 모름 (d) 산채 = 채식 #1 모름 (e) 전주 = UNESCO 무형유산 모름. 본 가이드는 5종 매트릭스 + 5색 + 변형 매니아.

🥬 5종 deep dive

🥬 전주비빔밥 (Jeonju Bibimbap) — 정통 #1

  • 시그니처: 5색 정통·궁중 + UNESCO 무형유산·한옥마을
  • 재료: 5색 나물 (시금치·당근·콩나물·고사리·도라지) + 계란 + 고추장 + 참기름·소고기 (옵션)
  • 외국인 친화도: ★★★★★ (#1 정통·UNESCO)
  • 추천 매장:
  • 전주 한옥마을 비빔밥 노포 — 정통 #1
  • 서울 전주식 비빔밥집 (강남·홍대) — 가성비
  • 시기: 사계절·정통
  • 가격: 전주 한옥마을 = 12,000~25,000원 / 서울 = 8,000~20,000원
  • UNESCO 무형유산: 궁중요리 cluster 등재 (2023)

🍲 돌솥비빔밥 (Dolsot Bibimbap) — 글로벌 #1

  • 시그니처: 뜨거움 + 바삭 누룽지 (밑바닥)·추운 날 매니아
  • 재료: 5색 나물 + 계란 + 고추장 + 돌솥 (stone pot)·바삭 누룽지 (밑바닥)
  • 외국인 친화도: ★★★★★ (글로벌 #1·뜨거움 인기)
  • 추천 매장: 한정식·MZ 한식당·체인 (한솥 등)
  • 시기: 사계절·겨울 #1
  • 가격: 10,000~22,000원
  • 주의: 돌솥 = 매우 뜨거움 (조심·접시 받침 사용)

🥄 셀프비빔밥 (Self Bibimbap·DIY) — MZ #1

  • 시그니처: DIY·MZ 인스타 #1·재료 선택
  • 재료: 밥 + 나물 8~12종 (선택) + 양념·계란·고기 (선택)
  • 외국인 친화도: ★★★★ (MZ #1·DIY)
  • 추천 매장:
  • MZ 셀프 비빔밥 매장 (홍대·강남·성수) — 트렌드
  • 셀프 한식 뷔페 — 가성비
  • 가격: 8,000~18,000원/1인 (셀프 무한 리필)

🌳 산채비빔밥 (Sanchae Bibimbap) — 채식 #1

  • 시그니처: 사찰음식 cluster cross·봄 산나물·채식·할랄 #1
  • 재료: 5~8종 산채 (취·고사리·도라지·미나리 등) + 계란 (선택) + 된장 양념
  • 외국인 친화도: ★★★★ (채식·할랄 #1)
  • 추천 매장:
  • 진관사 ([#876](#876)) — 사찰음식 정통 #1
  • 강원·전라 산채 비빔밥집 — 봄 정통
  • 시기: 봄 3~5월 #1·연중
  • 가격: 사찰음식 코스 25,000~80,000원 / 산채집 10,000~25,000원

🦐 해물비빔밥 (Haemul Bibimbap) — 해산물 cross

  • 시그니처: 회·해산물 cluster cross·자갈치·통영 정통
  • 재료: 5색 나물 + 회·해산물 (광어·전복·새우·관자) + 고추장·계란
  • 외국인 친화도: ★★★ (해산물 매니아)
  • 추천 매장: 자갈치·통영·강남 횟집·MZ 한식당
  • 가격: 15,000~40,000원/1인

⚠ 외국인 자주 실수 5가지

1. "비빔밥 = 한 가지": 비빔밥 = 5가지 변형 (전주·돌솥·셀프·산채·해물).

2. "전주 = 일반": 전주 = UNESCO 무형유산 정통 (5색·궁중).

3. "돌솥 = 일반 그릇": 돌솥 = 매우 뜨거움·바삭 누룽지 (밑바닥).

4. "셀프 = 가성비만": 셀프 = MZ 인스타 #1·재료 풀세트.

5. "산채 = 채식만 풀": 산채 = 사찰음식 cluster + 봄 산나물·정통.

⚙ FAQ 8개

1. 외국인 입문 1순위: 전주 (정통) + 돌솥 (글로벌) → 셀프 (MZ).

2. 인스타·vlog: 전주 한옥마을·돌솥 뜨거움 vlog·셀프 DIY.

3. MZ 트렌드: 셀프 비빔밥 (#1)·돌솥.

4. 채식·할랄: 산채 비빔밥 (#1) + 사찰음식.

5. 돌솥 주의: 매우 뜨거움·접시 받침 사용·아이 주의.

6. 알레르기: 계란·해산물·마늘·간장 글루텐 사전 고지.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

비빔밥 = 일반 음식. 임신부·어린이 = OK (돌솥 뜨거움 주의). 알레르기 (계란·해산물·마늘·간장 글루텐) 사전 고지. 돌솥 화상 주의. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 산채·전주 = OK (소고기 제외) / 해물 = 갑각류 X / 셀프 = 자유 선택.
  • 채식·비건: 산채 = #1 / 5색 = 계란 옵션 / 해물 = 비채식.
  • 글루텐 free: 간장·고추장 양념 = 글루텐 (Tamari 대체).
