为什么梅雨季要选室内路线

首尔梅雨季（6月中旬~7月）=下雨也不断档的室内路线需求 + 圣水·弘大·江南大型复合文化空间·展览·购物中心·地下动线全套 + 无需雨伞也能尽兴的外国游客雨天方案。外国游客的痛点＝"一下雨行程就泡汤"→靠室内集群 + 地下连接动线来化解。

首尔梅雨季的降雨量约占全年平均降水量的30~35%,集中在6~7月这两个月。单日突降50mm以上暴雨的情况也不少见。这段时间访问首尔的外国游客普遍有两大烦恼。

1. 预约好的户外行程被雨水打乱时没有备选方案。

2. 不知道哪里是室内、规模多大、英语是否行得通。

本指南正是为了化解这两大烦恼。在圣水·弘大·江南3个区域之外,再加上雨天基础设施轴,构成4轴12选,只收录真实存在的空间。

外国人失误 TOP 3

失误1："以为下雨天只有COEX可去"

COEX确实是首选,但圣水·弘大也有大型室内复合空间。不必从江南出发移动1小时以上,在住宿所在区域内就能解决。如果住在弘大附近,KT&G想象广场弘大店 + 合井Mecenatpolis购物中心就足以填满半天行程。

失误2：只带一把伞出地铁站,结果遇上暴雨

首尔梅雨季不是简单的毛毛雨。5分钟内就能让雨伞失去作用的暴雨天也很常见。COEX·江南区域备有从地铁站直通室内的地下动线。提前掌握这条动线,就能不带伞移动。本指南#10有详细说明。

失误3：以为免费,结果去了才发现不能刷卡又没带现金

COEX星空图书馆完全免费。水族馆门票₩29,000,可以刷卡。圣水部分仓库型咖啡厅要求必须点单(以最低消费1杯饮品代替门票)。密室逃脱比起现场预约,提前预约明显更有利——下雨天同时到访的人会扎堆,现场等待1~2小时也很常见。

12选4轴深度攻略

轴1：圣水（3选）

1. 圣水联邦 (Seongsu Yeonbang / 성수연방)

地址：首尔城东区圣水二路14街14（2号线圣水站 (Seongsu Station / 성수역) 3号出口步行10分钟）

门票：免费（以各店铺消费为准）

营业时间：各店铺不同,大体为11:00~22:00（建议出发前确认）

英语沟通：★★★（主要店铺备有英文菜单·指引,员工基本英语可通）

圣水联邦是将圣水洞工厂地带改造而成的复合选品店·咖啡厅·画廊集合体。建筑本身结构相连,即使下雨也能在楼层间移动。它吸引外国游客的亮点有两个。一是作为拍照点的空间感——挑高天花板、斑驳砖墙、翻新质感,在Instagram上很出片。二是可以在一个地方看遍韩国本土品牌。

雨天提示：点一杯咖啡就能在店内待上2~3小时。不少外国游客评价称,雨声透进建筑内部的氛围也别具一格。

预算参考：咖啡1杯₩6,000~₩8,000。追加购物无上限。

2. Understand Avenue (언더스탠드애비뉴)

地址：首尔城东区往十里路 (Wangsimni-ro / 왕십리로) 83-21（2号线纛岛站 (Ttukseom Station / 뚝섬역) 1号出口步行5分钟）

门票：免费

营业时间：11:00~22:00（建议出发前确认）

英语沟通：★★★（以快闪店·选品店为主,英文指引部分覆盖）

Understand Avenue以户外集装箱布局为特色,但另设有独立的室内咖啡厅·选品店·快闪区域。雨大的日子应优先走室内动线,而非户外区域。作为圣水区域游览的起点很合适,与圣水联邦步行可达,常被安排为同一条路线。

雨天提示：下雨时以室内咖啡区和选品店为主循环游览。户外集装箱区域只做短暂停留。

预算参考：免费入场。咖啡·简餐₩8,000~₩15,000。

3. 大林仓库 (Daelim Changgo / 대림창고)

地址：首尔城东区圣水二路78（2号线圣水站步行5分钟,或纛岛站步行15分钟）

门票：无——须点饮品（最低1杯）

营业时间：10:00~22:00（建议出发前确认）

英语沟通：★★★（菜单英文并记,点单基本可用英语沟通）

这是将1970年代碾米厂改造而成的空间。12米挑高天花板、斑驳仓库质感、大型采光窗是其特色。雨声与仓库氛围结合,让不少外国游客称其为"韩国最独特的咖啡厅"。是梅雨季圣水路线的室内核心锚点。

雨天提示：下雨天的白天时段拍照效果最好(阴天光线与空间气质相配)。周末排队30分钟~1小时很常见——建议工作日前往。

预算参考：饮品₩7,000~₩10,000。

注意：停车位狭小。建议利用大众交通。

轴2：弘大·合井（3选）

4. KT&G想象广场弘大 (KT&G Sangsangmadang Hongdae / KT&G 상상마당 홍대)

地址：首尔麻浦区聚会广场路 (Eoulmadang-ro / 어울마당로) 65（2号线·机场铁路弘大入口站9号出口步行5分钟）

门票：画廊免费~₩5,000（按展览不同）,电影₩10,000~₩12,000,演出另计

营业时间：画廊12:00~20:00 / 设计商店12:00~21:00（建议出发前确认）

英语沟通：★★★（部分画廊展览备英文说明,部分电影场次有英文字幕）

这是弘大区域最稳定的室内据点。画廊轮番展出以现代美术·独立设计为主的展览。即使下雨也能整日停留——按画廊→设计商店闲逛→看一场电影的顺序,可以填满半天时间。对外国游客来说,这是少数能实际接触韩国独立艺术·设计的空间之一。

雨天提示：入场前建议在官网或Instagram确认当前展览。展览空档期只有设计商店营业。

预算参考：画廊免费~₩5,000 + 电影₩12,000 + 咖啡₩6,000。

5. 弘大密室逃脱·桌游咖啡厅·投币练歌房

位置：弘大入口站步行5~10分钟范围。弘大正门商圈密集。

门票：

  • 密室逃脱：₩15,000~₩25,000/人（按主题·人数不同）
  • 桌游咖啡厅：₩5,000~₩10,000/人（计时制或入场费）
  • 投币练歌房：₩500~₩1,000/首（或计时制₩3,000~₩5,000/10分钟）

英语沟通：★★★★（主要密室逃脱业者提供英文说明——如I'm Escape、Code K等主要连锁均提供英·中·日语提示）

这是雨天弘大的室内娱乐集合体。密室逃脱须提前在线预约——梅雨季周末很多业者无法现场预约。投币练歌房无需预约即可立即使用,外国游客也很容易上手。桌游咖啡厅虽有韩语游戏,但主要业者另设有备英文说明书的游戏专区。

雨天提示：在Klook·MyRealTrip提前预约密室逃脱可享折扣。下雨天下午2~5点最拥挤。

预算参考：密室逃脱₩20,000 + 桌游₩7,000 + 投币练歌房₩5,000 = 约₩30,000~₩35,000/人。

6. 合井Mecenatpolis购物中心 · AK&弘大

地址：首尔麻浦区杨花路45（2号线·6号线合井站直连）

门票：免费（购物中心）

营业时间：10:30~22:00（餐饮区营业至23:00,建议出发前确认）

英语沟通：★★★（主要国际品牌门店可用英语,问询台基本英语可通）

从合井站可直接从地下进入,不会淋到一滴雨。购物·用餐·咖啡都能在一处解决。对住在弘大区域的外国游客来说,这是雨天最近的室内备选方案。AK&弘大与Mecenatpolis之间有连接通道相通,实际上构成同一个大型复合商场动线。

雨天提示：用餐高峰（12~14点、18~20点）餐饮区排队可能较长——可提前或错后1小时,或提前预约。

预算参考：用餐₩12,000~₩20,000。追加购物无上限。

轴3：江南·COEX（3选）

7. COEX购物中心 (COEX Mall / 코엑스몰) + 星空图书馆 (Starfield Library / 별마당도서관)

地址：首尔江南区永东大路513 COEX（2号线三成站 (Samseong Station / 삼성역) 5·6号出口直连 / 9号线奉恩寺站7号出口步行5分钟）

门票：星空图书馆完全免费 / COEX购物中心免费

营业时间：COEX购物中心10:30~22:00 / 星空图书馆10:00~22:00

英语沟通：★★★★★（指示牌4国语言,问询台英语可通,国际品牌门店英语自不必说）

星空图书馆是首尔外国游客拍照打卡地压倒性第一名。13米高书架、大型多媒体艺术装置、免费开放,三大条件合为一体的空间。虽名为图书馆,实际上是任何人都能坐下休息或拍照的公共空间。借阅仅限会员,但阅览外国游客也可自由使用。

COEX购物中心本身是横跨地下4个区域的迷宫式结构。电影院(Megabox COEX)、水族馆(见下一项#8)、SMTOWN Artium(见下一项#9)、餐饮区、咖啡厅、便利设施全部以室内相连。从三成站可地下直连,无需走到地面即可进入。

雨天提示：下雨天可从三成站5号·6号出口直接从地下进入COEX。星空图书馆上午10~11点人少,适合拍照。

预算参考：免费入场。用餐₩12,000~₩20,000。咖啡₩6,000~₩9,000。

8. COEX水族馆 (COEX Aquarium / 코엑스 아쿠아리움)

地址：首尔江南区永东大路513 COEX B1（COEX购物中心地下直连）

门票：成人₩29,000 / 青少年₩24,000 / 儿童₩19,000（2026年基准,可能变动——建议查询官网确认）

营业时间：10:00~20:00（最后入场19:00）

英语沟通：★★★★（指示牌英文,部分员工可用英语,提供英文语音导览）

COEX水族馆是韩国国内数一数二的大型水族馆。据官网介绍,饲养着650余种、4万余只海洋生物。分为海底隧道、亚马逊区、企鹅区等区域,全程动线均为室内。对带孩子的外国游客而言,是梅雨季半天行程的第一顺位选择。

雨天提示：在Klook·KKday提前购票,比现场票价便宜10~15%。周末高峰时段(13~16点)会排队——建议开馆后立即入场。

预算参考：成人2人约₩58,000。含COEX购物中心用餐时人均₩40,000~₩50,000。

9. SMTOWN COEX Artium (SMTOWN 코엑스아티움)

地址：首尔江南区永东大路512地下1层（COEX对面,奉恩寺站7号出口步行3分钟）

门票：1楼周边商店免费 / SUM咖啡厅需购买饮品 / SUM DDP展览馆₩15,000~₩35,000（按展览项目不同,建议确认）

营业时间：11:00~21:00（建议出发前确认）

英语沟通：★★★★★（面向全球粉丝的空间——英·中·日语指引齐全）

这是可以在室内体验购买SM娱乐旗下艺人(EXO·NCT·aespa等)官方周边、拍照棚、展览的空间。对K-pop粉丝来说,是首尔之行不可缺席的一站。周边商店免费入场,无需消费也可自由参观。梅雨季江南路线中,COEX购物中心→星空图书馆→水族馆→SMTOWN这条动线,雨天可以构成半天到全天的行程。

雨天提示：展览项目因时期而异,建议提前在官方Instagram确认。周边商店无需预约即可立即入场。

预算参考：周边购买₩30,000~₩100,000（视消费意愿而定）。展览₩15,000~₩35,000。

10. 地下连接动线——不淋雨移动的方法

首尔江南区域的地下连接动线,外国游客大多不了解,但知道了会非常实用。核心路线如下。

COEX直连路线

  • 2号线三成站5·6号出口 → COEX购物中心 → 星空图书馆 → 水族馆 → SMTOWN Artium方向全程地下相连
  • 从三成站出发,无需一次走到地面即可使用COEX全部设施

江南地下商街路线

  • 新沙站~江南站~驿三站~宣陵站区间存在地下连接通道(各区间是否相连有所不同——出发前建议在地铁App或Naver地图确认"地下路线")
  • 江南站地下商街聚集时尚·杂货·餐饮门店

合井站直连路线

  • 合井站 → Mecenatpolis购物中心地下直连(可换乘2·6号线)

实用提示

  • 在Naver地图App中选择"地铁路线",可确认换乘通道·地下连接情况
  • Kakao地图提供相同功能。两款App均支持英文界面
  • Naver Map英文版：maps.naver.com → 语言设置English

12. 季节性室内备选方案——梅雨季以外的雨天应对

除梅雨季(6月中旬~7月)之外,首尔全年也常有突发降雨。

时期 降雨情况 推荐室内备选方案
3~5月(春季) 春雨·黄沙后降雨 COEX星空图书馆、圣水仓库型咖啡厅
6~7月(梅雨季) 集中暴雨,单日50mm+ 本指南1~11项全部
8月(夏季) 酷暑·阵雨 室内水族馆、购物中心空调场所
9~11月(秋季) 间歇性降雨 KT&G想象广场、画廊
12~2月(冬季) 雪·寒潮 COEX购物中心、Mecenatpolis购物中心

除湿·体温管理提示

  • 梅雨季室内因空调运转,比想象中更冷。建议携带一件薄长袖。
  • 雨伞收纳——大型购物中心入口通常备有雨伞收纳袋或伞架。COEX在入口免费提供雨伞套。

  • 便利店(CU·GS25)可即时购买折叠伞,价格₩5,000~₩10,000
  • 雨衣售价₩3,000~₩8,000
  • 部分地铁站内设有雨伞自动售卖机(覆盖率不高——便利店购买更稳妥)

语言·结算

  • 语言：COEX·SMTOWN 4国语言齐备。圣水·弘大主要商圈基本英语可通。小型咖啡厅建议使用翻译App(Google翻译相机功能)。
  • 结算：可刷卡比例80%以上(以江南·弘大为准)。部分小型咖啡厅偏好现金。建议准备₩10,000~₩20,000现金以备不时之需。

FAQ

Q1. 下雨天在首尔只能去一个地方的话?

COEX购物中心 + 星空图书馆。免费、三成站地下直连、4国语言指引齐全,还可追加选择水族馆·SMTOWN。半天到全天都能在室内解决。

Q2. 是K-pop粉丝,下雨天该去哪儿?

SMTOWN COEX Artium(#9)。周边商店免费入场、可购买官方周边、拍照棚。COEX地下直连,不会淋雨。

Q3. 带孩子的家庭旅行,遇上下雨怎么办?

强烈推荐COEX水族馆(#8)。650余种海洋生物,含海底隧道全程室内。之后在星空图书馆休息。COEX购物中心内的餐饮区还能顺路解决用餐。

Q4. 预算一天₩30,000以下也能在室内玩尽兴吗?

可以。星空图书馆(免费) + 圣水仓库型咖啡厅1杯(₩7,000~₩8,000) + 弘大投币练歌房(₩5,000~₩8,000) + 便利店用餐(₩5,000~₩7,000) = ₩25,000以内。

Q5. 密室逃脱在哪里预约?能用英语吗?

在Klook或MyRealTrip App中搜索"escape room Seoul"。可通过筛选确认是否提供英文提示。弘大主要密室逃脱业者(Code K、I'm Escape等连锁)基本都提供英文说明。有降雨预报的周末建议提前2~3天预约。
