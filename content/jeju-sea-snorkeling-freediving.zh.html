济州海上爱好 — 浮潜·自由潜水·体验潜水，何时·何地·和谁一起

副标题: 12~3月西归浦近海的月平均水温约15.7~19.2℃。海水浴场已经关闭，板浦浦口 (Panpo / 판포포구)和海边 (Sehwa / 세화)的裸身浮潜是夏天的事。冬天剩下的选择是西归浦潜水店的潜水·自由潜水项目，但Kakao地图上只登记了本周的营业时间，没有冬季出海船班。这一篇整理了有水下活动依据的4处海边(板浦浦口·海边 (Sehwa / 세화)·岛 (Munseom / 문섬)一带·港口 (Bomok / 보목포구))、Kakao地图上显示营业中的西归浦潜水店7家，以及法律实际规定的内容(禁止夜间·需许可水域等)，并附上条文编号。海水浴场开放时间·费用见#1059

🎯 这一篇怎么用

这一篇只讲下水的爱好。包括浮潜、自由潜水、水肺体验潜水和休闲潜水。在沙滩上玩的海水浴，以及海水浴场的开放时间·费用·设施，见#1059济州海滩指南。挟才·咸德在#1059里讲，Geumneung·Gimnyeong不在这一篇里讲。

先看时期。2026年济州海水浴场的开放时间是6/24~9/6，Visit Jeju 2026开放信息中的11处，按今天(2026-11-24)的情况都处于关闭状态。12~3月的现实和要等到夏天的事，已经在下面的季节表里先分开了。

⚠ 标注原则: 景点说明来自济州观光公社Visit Jeju和韩国观光公社观光信息里登记的内容。"韩国观光公社景点发掘100×100入选(国民投票N票)"是文化体育观光部·韩国观光公社国民投票的结果，并写明了主题名称。水温分开标注：气象厅海洋气象浮标的值(8月·12月)和民间网站的值(其余月份)。潜水店的营业时间·价格是Kakao地图店主登记值(2026-11-24查询)，登记超过2年的价格标为"价格以Kakao地图当日确认为准"。法律内容附有条文编号。

📍 景点4处 — 只选有水下活动依据的地方

① 板浦浦口 (Panpo / 판포포구) — 夏季浮潜，位于济州市 Hangyeong-myeon (Hangyeong-myeon / 한경면)

韩国观光公社景点发掘100×100入选(国民投票53票) — '贴合兴趣的纳米社群'主题。

  • 什么样的地方: Visit Jeju作为浮潜景点介绍的港口。海底是沙子，水很清。比西部其他海水浴场水深(Visit Jeju)。
  • 地址: 济州市 Panpo-ri 2877-3 (판포리 2877-3)。使用时间登记为"常年开放"。
  • 设施: 停车场·淋浴设施。韩国观光公社观光信息概要里写着，夏季板浦里青年会出借装备。
  • 注意: 有提示说不要从港口跳水·潜水。戏水季有救生员，但并非常年配置(Visit Jeju)。有提示说要看潮汐(涨潮·退潮)再下水，禁止做饭·自带垫子·帐篷。
  • 冬天: 板浦浦口不在指定海水浴场名单里。不建议冬天裸身下水浮潜。夏天来。

② 海边 (Sehwa / 세화) — 自由潜水者聚集的海滩，位于济州市 Gujwa-eup (Gujwa-eup / 구좌읍)

韩国观光公社景点发掘100×100入选(国民投票54票) — '贴合兴趣的纳米社群'主题。景点发掘推荐理由中介绍为自由潜水者聚集的地方。

  • 什么样的地方: 在济州Olle 20号线上，位于海边 (Sehwa / 세화)民俗五日市场和海女博物馆之间的海滩。
  • 不是指定海水浴场: 因为不是指定海水浴场，所以没有开放时间·救生员运营的提示(Visit Jeju·韩国观光公社观光信息)。
  • 注意: 满潮时沙滩会大幅缩小或被淹没。一篇2023年12月到访的评论(博客)写到，因为涌泉(从地下涌出的淡水)，水非常冷。
  • 设施: 公共停车场·洗手间。咨询电话064-728-7783。
  • 冬天: 这不是一个人下水的地方。夏天，和同伴一起去。

③ 岛 (Munseom / 문섬)一带 (岛 (Munseom / 문섬)·岛 (Seopseom / 섶섬)·岛 (Beomseom / 범섬)) — 西归浦近海船潜

岛 (Munseom / 문섬): 韩国观光公社景点发掘100×100入选(国民投票41票) — '贴合兴趣的纳米社群'主题。同一次投票的'K-运动与探险'主题里获得400票。

  • 什么样的地方: 西归浦港前海的岛屿。不是能自己游过去的地方，要乘西归浦港·港口 (Bomok / 보목포구)一带潜水店的船出海。潜水店 (All Blue Scuba Diving / 올블루 스쿠버다이빙)的Kakao地图说明里写着休闲潜水点是岛 (Seopseom / 섶섬)·岛 (Munseom / 문섬)·岛 (Beomseom / 범섬)，视当天天气和海况而定(2024-05登记文字)。
  • 天然保护区: 岛 (Munseom / 문섬)·岛 (Beomseom / 범섬)是天然纪念物第421号"Munseom·Beomseom天然保护区"(2000-07-18指定)。据国家遗产门户网站，这里被指定为限制公开区域，因管理·学术目的等进入岛屿需要获得国家遗产厅长的许可。可以认为登岛不是个人能做的事。海上活动只按潜水店定的潜点和日程进行。
  • 冬天: Kakao地图上只登记了本周(11/24~30)的营业时间，没有冬季出海日程。潜点可能因天气更换或取消。

④ 港口 (Bomok / 보목포구) — 前往岛 (Munseom / 문섬)·岛 (Beomseom / 범섬)的出发点 (西归浦市)

韩国观光公社景点发掘100×100入选(国民投票224票) — 'K-运动与探险'主题。

  • 什么样的地方: 景点发掘推荐理由中介绍为从港口 (Bomok / 보목포구)出发，在岛 (Munseom / 문섬)·岛 (Beomseom / 범섬)一带游泳并观赏软珊瑚的地方。洞 (Bomok-dong / 보목동)有好几家潜水·自由潜水店(下面潜水店名单里的自由潜水学校 (Jeju Freediving School / 제주프리다이빙스쿨)·自由潜水店 (Jeju Badang Freediving / 제주바당 프리다이빙)·潜水度假村 (Scuba King Diving Resort / 스쿠버킹다이빙리조트))。
  • 地址: 西归浦市 Bomokpo-ro 46 (보목포로 46)。有洗手间·停车场。
  • 注意: 韩国观光公社观光信息里有提示要确认满潮时间。

🏄 和谁一起 — 按自己的情况选

  • 第一次，没有证书 → 潜水店的体验潜水。教练负责装备和入水前教育。法律规定潜水店(经营者)有采取装备穿戴措施和登船前安全教育的义务(水中休闲法第11条第1款第4项)。
  • 有水肺证书 → 休闲潜水。潜水店 (Wow Divers / 와우다이버스)·潜水店 (All Blue Scuba Diving / 올블루 스쿠버다이빙)把水肺休闲潜水登记为持证者项目(潜水店规定)。带上证书卡和潜水日志。
  • 想学习或继续自由潜水 → 洞 (Bomok-dong / 보목동)·洞 (Seogwi-dong / 서귀동)自由潜水店的水深训练·休闲潜水·AIDA课程。AIDA是国际自由潜水教育机构，像AIDA1·2这样作为该机构的课程名称使用。
  • 带孩子一起 → 潜水店 (All Blue Scuba Diving / 올블루 스쿠버다이빙)的Kakao地图说明里写着体验潜水从满10岁起(2024-05登记文字，卖家说明)。法律规定，没有监护人陪同的未满14岁者，潜水店不得出借装备或让其乘船(第21条第3款)。监护人要一起去。
  • 一个人旅行 → 不要一个人做裸身浮潜·自由潜水。加入潜水店的项目，就会和教练·其他参加者一起下水。

🛟 安全与法律 — 把法律规定的和建议的分开

法律规定的 — 《水中休闲活动的安全及活性化等相关法律》(法律第20944号，2026-04-23施行)。法律涉及的活动是潜水(skin diving)·水肺潜水等由总统令规定的活动(第2条第2项)。施行令第2条把水中休闲活动规定为潜水(skin diving)·水肺潜水。裸身浮潜·自由潜水是否属于这里，法令中没有定义。无论哪种，夜间都不下水。

  1. 禁止夜间 — 日落后30分钟起至日出前30分钟，不得进行水中休闲活动(第13条第1款)。只有配备夜间安全装备和安全管理人员的情况属于例外。违反者处100万韩元以下罚款(第32条第1款第2项)。潜水店也不得在这个时间营业(第21条第3款)。冬天日落早，所以下午的行程要排短一些。
  2. 天气不好时 — 海洋警察署长或地方政府首长在气象·海面状况变差时，可以命令限制活动时间(第13条第2款)。对潜水店可以命令限制营业时间或暂时停业(第22条)。当天潜水店取消出海的话，要服从。
  3. 穿戴装备 — 活动者要按照安全管理规定穿戴人命安全所需的水中休闲装备，不得离开规定的活动区域(第8条)。第8条第1款还要求遵守《海上交通安全法》第33条第3款规定的事项。未穿戴装备·离开区域各处50万韩元以下罚款(第32条第2款)。
  4. 证书是潜水店一侧的要求 — 按法律·施行令，不要求个人持有证书，资格要求在潜水店里授课的"水中休闲教育者"一侧(第2条第10项，第11条第4款)。潜水店必须向海洋警察厅长登记(第15条第1款)。潜水店 (Wow Divers / 와우다이버스)·潜水店 (All Blue Scuba Diving / 올블루 스쿠버다이빙)把水肺休闲潜水登记为持证者项目(潜水店规定)。
  5. 走远时 — 前往10海里以上的行程属于向海警申报的对象(第12条第1款)。
  6. 需要许可的水域 — 西归浦海洋警察署告示第2026-01号(2026-06-30)把西归浦港·和顺港·城山浦港的部分海面定为'海洋休闲活动需许可水域'(依据: 《海上交通安全法》第33条第3款，同法施行令第14条第1款)。告示提示，在这片水域未经许可进行潜水(skin diving)·水肺潜水等，或违反许可条件，将被处以300万韩元以下罚款，并要求事先向西归浦海洋警察署长申请许可。水域坐标和图纸见告示。咨询电话西归浦海洋警察署海洋安全科064-793-2349。

建议的 (不是法律条款的安全守则)

  • 不要一个人下水。 法律正文里没有伙伴(2人1组)条款，但自由潜水·浮潜要两人以上互相照看着进行。
  • 使用救生衣或浮力装备。 尤其是在板浦浦口这样的海岸浮潜时。
  • 喝了酒的日子、身体不舒服的日子不下水。 法律规定潜水店不得向酒醉状态的人(第21条第3款第1项)出借装备或让其乘船。
  • 看潮汐。 板浦浦口·港口 (Bomok / 보목포구)都提示要看潮汐·满潮时间。

发生事故拨119 — 据政策简报(2022-10-11)，海上事故现在也拨119报警。犯罪是112。旅游信息咨询是济州旅游信息中心064-740-6000。

⚠ 常见失误3

  1. 冬天原样带着夏天计划去 — 12~3月西归浦海水月平均约15.7~19.2℃(民间水温网站badatime为准，西归浦2022~2025平均)。看着板浦浦口浮潜的照片冬天去，水会很冷，而且也不在海水浴场开放时间内(#1059)。
  2. 从港口跳水 — 板浦浦口有不要从港口跳水·潜水的提示。水清，看起来浅，也不要跳。
  3. 想在岛 (Munseom / 문섬)上岸 — 岛 (Munseom / 문섬)·岛 (Beomseom / 범섬)是限制公开区域，进入岛屿需要国家遗产厅长的许可。船潜只在潜水店定的潜点进行。

⚙ FAQ 3

  1. 12月济州的海怎么样? — 西归浦近海12月水温是马罗岛·西归浦浮标5年(2019~23)日平均范围18.4~20.6℃(气象厅)。海水浴场处于关闭期，板浦浦口·海边 (Sehwa / 세화)没有冬季救生员运营提示。西归浦潜水店7家中有5家在Kakao地图上标出了本周(11/24~11/30)的营业时间，但没有登记12月以后的运营·出海日程。
  2. 没有证书可以做水肺休闲潜水吗? — 潜水店 (Wow Divers / 와우다이버스)·潜水店 (All Blue Scuba Diving / 올블루 스쿠버다이빙)把水肺休闲潜水登记为持证者项目(潜水店规定)。按法律·施行令，不要求个人持有证书，潜水店有采取装备穿戴措施、安全教育和配备教育者的义务(第11条第1款)。没有证书的话，另有体验潜水项目。
  3. 只想浮潜的话去哪里? — 夏天(7~9月)去板浦浦口。海底是沙子，水清，韩国观光公社观光信息里写着夏季有村里青年会的装备出租。海滩开放时间·设施看#1059。
