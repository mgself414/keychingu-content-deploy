🎯 왜 한국 면안주 워크플로우 가이드인가

[#861 면안주 6종 매트릭스](#861) 알아도 — 주문·페어·매너는 별개. 한국 면안주는 (a) 장수동 족발 골목 (17:00~03:00 야식) (b) 광장시장 보쌈 (낮·vlog #1) (c) 종로 포장마차 (소주 + 골뱅이) (d) 한정식 코스 (수육·홍어삼합). 외국인은 (1) 새우젓 매너 모름 (2) 족발·보쌈 = 쌈 싸 먹는 방식 모름 (3) 소주 페어 매너 모름 (4) 홍어 = 매니아 음식 모름. 본 가이드는 5-step + 매너 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 장수동 족발 / 광장 보쌈 / 포장마차 / 한정식 즉시 야식·낮·소주 매니아 목적
2️⃣ 메뉴 주문 6종 + 1관 (2~3인) / 1인분 1~5분 1관 = 2~3인 공유
3️⃣ 받기·세팅 쌈채소·마늘·새우젓·김치 5~15분 쌈 싸 먹기
4️⃣ 먹기·페어 소주·막걸리·맥주 페어 30~90분 술 매너 (어른 먼저)
5️⃣ 결제 카드 OK / 시장·노포 = 현금 일부 / 팁 X 1~3분 1/N 더치 OK

총 소요 시간: 한정식 = 1.5~2.5h / 장수동 족발 = 1~2h / 광장 보쌈 = 30분~1h / 포장마차 = 1~3h

🍖 채널별 워크플로우

Type A — 장수동 족발 골목 (성북·전국 #1)

  • 시그니처: 17:00~03:00 야식 매니아·전국 #1
  • 시간대: 17:00~03:00
  • 가격: 25,000~50,000원/1관 (2~3인) + 1인 약 12,000~25,000원
  • 메뉴: 족발 (정통·매콤)·미니족·반반
  • 외국인 친화도: ★★★★★ (영문 메뉴·체인)
  • 야식 매니아: 술 + 야식 #1

Type B — 광장시장 보쌈 골목

  • 시그니처: vlog #1·MZ 인스타·낮·저녁
  • 시간대: 09:00~22:00
  • 가격: 20,000~40,000원/1관 (2~3인)
  • 메뉴: 보쌈·보쌈김치·쌈채소
  • 외국인 친화도: ★★★★★ (vlog #1·MZ)

Type C — 종로·강남 포장마차 (소주안주)

  • 시그니처: 골뱅이무침·소주 매니아·#1
  • 시간대: 18:00~02:00
  • 가격: 12,000~25,000원 (안주별)
  • 메뉴: 골뱅이무침·계란말이·우동·라면
  • 외국인 친화도: ★★★ (한국어 정통)
  • 소주 매니아: 안주 + 소주 #1

Type D — 한정식 코스 (수육·홍어삼합)

  • 시그니처: 한정식 6단계 코스 정통 ([#837](#837))
  • 시간대: 11:30~22:00 (점심·저녁)
  • 가격: 한정식 코스 40,000~150,000원
  • 메뉴: 수육·홍어삼합 (코스 일부)
  • 외국인 친화도: ★★★★ (영문 일부)

🍯 쌈·새우젓·소주 매너 매트릭스

쌈 싸 먹기 (족발·보쌈·수육)

1. 쌈채소 (상추·깻잎·배추) 손바닥 위

2. 고기 + 마늘 + 새우젓 (조금) + 김치

3. 쌈장 (선택) — 매콤 옵션

4. 손으로 싸서 한입 (입에 다 들어가게)

5. 입 다물고 씹기 (한국 매너)

새우젓 (Saeu-jeot) 매너

  • 양: 조금만 (짠맛 강함·1mm)
  • 용도: 족발·보쌈·수육 (돼지 비린맛 제거)
  • 외국인: "Salty shrimp paste"·"Just a tiny bit"

소주 매너 (한국식)

1. 어른 먼저 따른다 — 막내가 어른에게

2. 두 손으로 따른다 — 한 손 잔 + 한 손 팔뚝

3. 두 손으로 받는다 — 어른 앞 받을 때

4. 고개 돌려 마신다 — 어른 앞에서

5. 건배 (Geonbae) — 잔 부딪힘·"치얼스 (Cheers)"

🌶 외국인 영어 발화 샘플

  • "족발 1관" = "One Jokbal set (for 2~3 people)"
  • "보쌈 + 소주" = "Bossam with soju, please"
  • "안 맵게" = "Less spicy, please"
  • "홍어 = 발효" = "Hongeo = fermented skate (strong smell)"
  • "1/N" = "Split the bill, please"
  • "건배" = "Cheers! Geonbae!"

⚠ 외국인 자주 실수 7가지

1. "족발 = 보쌈": 족발 = 발 부분 (장수동) / 보쌈 = 삶은 고기 + 김치 쌈 (광장).

2. "1관 = 1인분": 1관 = 2~3인 공유 (1인 = 1인분 separately 주문).

3. "새우젓 많이": 새우젓 = 조금만 (짠맛 강함).

4. "쌈 = 그냥 먹기": 쌈 = 싸서 한입에 (입에 다 들어가게).

5. "술 따르기 = 한 손": 술 따르기 = 두 손·어른 먼저.

6. "홍어 = 일반 안주": 홍어 = 발효 매니아·암모니아 향 강함.

7. "제육 = 안주": 제육 = 밥 반찬 + 안주 모두 (가성비 #1).

⚙ FAQ 8개

1. 첫 면안주 = 어떤 채널: 광장 보쌈 (낮·vlog) + 장수동 족발 (밤).

2. 인스타·vlog: 광장 보쌈 골목·장수동 족발·종로 포장마차.

3. MZ 트렌드: 광장 보쌈·MZ 족발 체인·제육 도시락.

4. 소주 매니아: 골뱅이무침 + 족발 + 제육.

5. 장수동 시간: 17:00~03:00 (야식 매니아).

6. 알레르기·임신: [#861 disclaimer](#861) 참조.

7. 결제·팁: 카드 OK / 시장·노포 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

면안주 = 일반 음식. 임신부 = 한정 OK (홍어 발효 X). 어린이 = OK (매콤 조절). 알레르기 (돼지·해산물·고추) 사전 고지. 술 = 임신부·미성년자 X. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 = 돼지·해산물 모두 X / 할랄 = 비빔밥·잡채로 우회 ([#854](#854)).
  • 채식·비건: 6종 모두 비채식 / 채식 = 사찰음식·비빔밥.
  • 글루텐 free: 수육·보쌈·족발 = OK / 골뱅이무침 소면 X / 제육 양념 일부 X.
