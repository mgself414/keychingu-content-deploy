🎯 セグメント別の #1 の推奨事項

👤 一人旅 (ソロ)

  • 1位: ミョナンジャ、韓国料理店(コストパフォーマンスの高いワンサン) — 1人あたり12,000~18,000ウォン、おかずフルセット
  • 2位: 家庭料理（コストパフォーマンスが高い）
  • 3位：Chain・MZ（1人前弁当）
  • 避けてください：専門店の商品（1人あたりの費用対効果↓）

🏛 4 チャンネルの詳細

🏛専門レストラン

コアバリュー: 名物一品料理(カルビチム、プルコギ、チャプチェ)+本格老舗レストラン+デートとおもてなし。

  • おすすめストア (ソウル):
  • 光化門カルビチムレストラン — 本格的な老舗レストラン群
  • 鍾路プルコギレストラン — 本格的なソウル、燕陽、王宮プルコギ
  • 江南チャプチェレストラン — MZ トレンド
  • おすすめストア (地元):
  • 光陽プルコギクラスター (全南) — 光陽本場
  • 恩陽プルコギクラスター (蔚山) — スパイシーな本格派
  • Menu: Single item (galbijjim, bulgogi, japchae) + 5~7 side dishes + rice
  • 価格アンカー: 25,000~80,000ウォン(1名)
  • 外国人フレンドリー度：★★★★（一部英語あり）
  • 支払い: カードOK

🍱 妙安寺・韓国料理店

コアバリュー: 一食 + おかずフルセット + 費用対効果 #1。

  • 推奨エリア:
  • 鍾路面庵クラスター — 外国人に優しい
  • 江南・駅三韓国料理レストラン — オフィスワーカーのためのランチ
  • 明洞と仁寺洞の韓国料理店 — 外国人観光地
  • メニュー: メイン(プルコギ、豚肉、カルビ煮込み)+おかず5～7品+ご飯+スープ+キムチフルセット
  • 価格アンカー: 12,000~25,000ウォン(1人あたり1賞)
  • 外国人親和性: ★★★ (韓国語・写真メニュー)
  • 運営: 09:00～22:00 (24h一部)

🏠 仮定式 (Home-style)

核心価値: ホームスタイル+おかずフルセット+コスパ #1 +家族にやさしい。

  • おすすめストア:
  • 白半集 (Baekban-jip) — 韓国 #1 コソンビ 韓国料理
  • ランチホワイトバン - 会社員ランチ1ランク
  • 仮定式白斑チェーン — 外国人にやさしい一部
  • メニュー: メイン(焼肉・除肉・雑菜)+おかず5～7種(変動)+ご飯+局
  • 価格 anchor: 8,000~15,000ウォン (1人の白盤)
  • 外国人親和性: ★★★ (韓国語)
  • 運営: 06:00～21:00 (一部24h)
  • お支払い：カードOK /一部の現金

🏢 チェーン・MZカフェ (Chain・MZ Cafe)

コアバリュー：チェーンコスパ+ MZトレンドバリエーション+弁当。

  • おすすめチェーン:
  • ハン釜弁当 — 韓国 #1弁当チェーン
  • 本弁当 — コスパ
  • MZ韓国料理カフェ（弘大・江南・ソンス） - トリュフ雑菜・宮中焼肉トレンド
  • メニュー：お弁当（焼肉・育て・雑菜）・MZ変形
  • 価格 anchor: 8,000~20,000ウォン
  • 外国人親和性: ★★★★ (英語・キオスク)
  • 運営：10:00～22:00

＃＃⚠外国人の頻繁な誤り5つ

1. "4チャンネル = 類似": 価格・雰囲気・メニュー 完全相違。正統＝専門店／苛性比＝綿眼座・家庭式／トレンディ＝チェーン。

2. "仮定式=味X": 家庭式白斑=韓国 #1 コスパ・おかずフルセット。

3. "専門店=高価だけ":専門店 lunch 特選=20,000ウォン～

4. 「チェーン＝お弁当のみ」：MZ韓国料理カフェ＝トリュフ雑菜・宮中焼肉トレンド。

5. "面眼座=外国人X": 面眼座=写真メニュー・翻訳アプリ活用OK。

⚙ よくある質問8件

1. 最初の韓国料理=どのチャンネル: 面眼座・韓国料理店（一日置きコスパ）1ランク。

2. インスタ・vlog：専門店カルビチム・MZトリプル雑菜。

3. デート・記念日:専門店+限定式([#831](#831))。

4. 家族の同伴: 家庭用白斑+綿眼座。

5. MZ トレンド: チェーン・MZ カフェ トリュフ雑菜・宮中焼肉。

6. アレルギー・妊娠: [#852・#853 disclaimer](#852)参照。

7. 決済・チップ: カードOK / 家庭式・綿眼座 一部現金 / チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

肉おかず4チャンネルともに一般韓国料理。妊婦=十分に煮てOK。子供=スパイシーな育成加減。アレルギー（大豆・シーフード・ナッツ）の事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：一般＝ビハラル。 →ハーブ炒め・査察料理・梨泰院ハラール。
  • ベジタリアン・ビーガン：ハーブ炒め・MZビーガン雑菜 / 査察食品限定食。
  • グルテンフリー：醤油（小麦）多。事前店舗確認。
