🎯 왜 대전 과학기술 가이드인가

대전 = 한국 #1 과학기술 cluster·KAIST (1971년~) + 대덕연구단지 (1973년~·R&D 50년+) + 국립중앙과학관 (1990년~) + 엑스포 시민광장 (1993 대전 엑스포). 외국인 페인포인트 = (a) "한국 = 삼성·LG뿐" 잘못된 인식·KAIST = 한국 #1 과학 대학 (글로벌 50대) (b) 대덕연구단지 = 한국 R&D 70% (출연연 26개) (c) 국립중앙과학관 = 영문 풀세트·무료·외국인 가족 매니아 #1 (d) 엑스포 시민광장 = 1993 대전 엑스포 기념·MZ + 인스타 fit (e) STEM 매니아·과학 교육 매니아 fit.

🏛 5축 deep dive

① KAIST (한국 #1 과학 대학·1971년~)

  • 시그니처: 한국 과학기술원·1971년~·글로벌 50대 과학 대학
  • 외국인 페인포인트: 외국인 학생 비율 ↑ (글로벌 학생 매니아)·영문 풀세트
  • 추천: KAIST 캠퍼스 자유 산책·박물관·공학관 + 셔틀버스
  • 외국인 친화도: ★★★★ (영문 안내·결제 카드)
  • 이동: 대전역 시내버스 119번 (30분) 또는 대전도시철도

② 국립중앙과학관 (1990년~·무료)

  • 시그니처: 1990년~·영문 풀세트·무료·가족·어린이 매니아 #1
  • 외국인 친화도: ★★★★★ (영문 + 일문 + 중문 시그너)
  • 시간: 09:30~17:50·휴관 월요일·매주 토 야간 개관
  • 추천: 가족·어린이·STEM 매니아 = 4-6h 매니아 코스

③ 엑스포 시민광장 + 한빛탑 (1993)

  • 시그니처: 1993 대전 엑스포 기념·한빛탑 (99m·엑스포 상징)
  • 외국인 친화도: ★★★★ (영문 시그너·MZ + 인스타 fit)
  • 추천: 산책 + 한빛탑 + 카페 cluster·갑천 cross

④ 대덕연구단지 (R&D 50년)

  • 시그니처: 1973년~·한국 R&D 70%·출연연 26개·ETRI·KIST·KAERI cluster
  • 외국인 페인포인트: 일반 외국인 X·과학 매니아·학자 매트릭스
  • 외국인 친화도: ★★★ (사전 예약·영문 일부)
  • 추천: 매니아·학자·STEM 매트릭스

⑤ ETRI (한국전자통신연구원·1976년~)

  • 시그니처: 한국 IT R&D #1·1976년~·삼성·LG·SK 협력 R&D
  • 외국인 친화도: ★★★ (사전 예약·영문 풀세트)
  • 추천: IT·통신·과학 매니아 매트릭스 #1

⚠ 외국인 자주 실수 5가지

1. "한국 과학 = 삼성·LG뿐": KAIST = 글로벌 50대 과학 대학·대덕연구단지 = 한국 R&D 70%·외국인 STEM 매니아 fit.

2. "국립중앙과학관 = 어린이만": 영문 풀세트·천체·항공·우주 매니아 매트릭스·MZ + 가족 + 시니어 매니아 매트릭스.

3. "KAIST = 일반 대학": 한국 #1 과학 대학·외국인 학생 비율 ↑·캠퍼스 자유 산책 OK.

4. "엑스포 = 1993년 끝남": 엑스포 시민광장 = MZ + 인스타 fit·한빛탑 (99m)·갑천 cluster.

5. "대덕연구단지 = 일반 외국인 X": 매니아·학자·STEM 매트릭스·사전 예약 시 외국인 OK.

⚙ FAQ 6개

1. 외국인 입문 1순위: 국립중앙과학관 (무료·영문) + KAIST 캠퍼스 + 엑스포 시민광장.

2. 국립중앙과학관 시간: 09:30~17:50·휴관 월요일·매주 토 야간 개관 (~22:00).

3. KAIST 방문: 캠퍼스 자유 산책 OK·박물관·공학관 사전 예약 권장·매주 화·목 영문 가이드.

4. 대덕연구단지: 사전 예약 필수·외국인 학자·매니아 매트릭스·ETRI·KIST 영문 가이드 일부.

5. 시즌: 봄·가을 베스트·여름·겨울 (실내 박물관 = 연중 OK).

6. 추천 페르소나: 가족·어린이 = 과학관 1순위 / MZ·과학 매니아 = KAIST + 엑스포 / 매니아·학자 = 대덕 + ETRI + KIST.
