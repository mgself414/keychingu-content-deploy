副标题: 为第一次去釜山的旅行者，把甘川、草梁山腹道路、大渊·釜田三个片区的10处整理在一起。甘川文化村在2026-08-01被指定为特别管理地区，通知文把居住密集区域的参观时间写作09:00~18:00。草梁168阶梯旁边有倾斜式电梯"草梁168阶梯天空路"。釜山博物馆周一休息，免费。联合国纪念公园按2026-11-24的标准17:00关门。时间和票价是2026-11-24查阅到的值。

🎯 适合谁，为什么是这10处

这份清单是为第一次去釜山的外国旅行者准备的。不是看海边，而是用在看釜山山坡上的村子和朝鲜战争痕迹的日子。甘川文化村和草梁故事路 (Choryang Ibagu-gil / 초량 이바구길)，都是走在房屋层层叠叠建在坡上的村子里的路。大渊洞的博物馆和联合国纪念公园在同一条路上。

分成三个片区。

  • 甘川片区(2处): 甘川文化村 (Gamcheon Culture Village / 감천문화마을)、峨嵋洞碑石文化村 (Ami-dong Tombstone Culture Village / 아미동 비석문화마을)。
  • 草梁山腹道路片区(5处): 草梁故事路、168阶梯·草梁168阶梯天空路 (168 Stairs · Choryang 168 Stairs Haneul-gil / 168계단·초량168계단 하늘길)、故事工作所 (Ibagu Gongjakso / 이바구공작소)、柳致环的邮筒 (Yu Chi-hwan's Mailbox / 유치환의 우체통)、草梁中华街·上海街 (Choryang Chinatown · Shanghai Street / 초량 차이나타운·상해거리)。
  • 大渊·釜田片区(3处): 釜山博物馆 (Busan Museum / 부산박물관)、联合国纪念公园 (UN Memorial Cemetery in Korea / 유엔기념공원)、釜山市民公园 (Busan Citizens Park / 부산시민공원)。

这一篇最先要读的，是甘川文化村的特别管理地区 (Special Management Area / 특별관리지역)规定。参观时间、车辆通行、团体参观，出现了附有日期的规则。在紧接着的下一节单独整理了。

甘川文化村和峨嵋洞碑石文化村现在仍是居民居住的村子。10处当中，联合国纪念公园是参拜的地方。这三处，参观的方式都附有条件。写在相应的条目里。

⚠ 标注原则: 时间、票价、距离、交通方式，是2026-11-24查阅到的值。出处是甘川文化村官方网站、釜山东区厅文化观光、釜山博物馆、联合国纪念公园、釜山市民公园的官网以及Visit Busan。从车站步行的部分时间是Kakao Map路线值，相应的行里注明了"Kakao Map"。票价是成人标准。运营时间、票价、公交线路可能变动。

📌 先看甘川文化村特别管理地区 — 按日期看规则

甘川文化村在2026-08-01被指定公告为特别管理地区。以下内容是甘川文化村官方网站通知文(沙下区发布，2026-11-24查阅)中写的值。

通知文写的内容

  • 参观时间: 居住密集区域的游客参观时间是09:00~18:00。
  • 区域划分: 通知文的指引地图把村子分区管理。居住密集区域设参观时间，居住·商业混合区域做礼仪劝导和拍照点秩序管理，关注区域做监测。
  • 车辆通行限制: 甘内2路 (Gamnae 2-ro / 감내2로)的一部分，从游客中心入口到"回忆的影子 (Chueok-ui Geurimja / 추억의 그림자)"拍照点约1km的路段，从通知文的实施日(2027-01-01)起，09:00~18:00限制载有游客的车辆通行。出租车也包括在内。
  • 团体参观: 10人以上的团体参观者必须购买村子的官方地图。 通知文把这一项的实施日写作2026-08-01。
  • 大型巴士: 实行事先预约制。
  • 管理的行为: 违法停车、乱扔垃圾、噪音、侵犯隐私。

🚦 走路之前 — 共同的安全和礼仪

  • 甘川和峨嵋洞是居民居住的村子。 Visit Busan在峨嵋洞碑石文化村的指引中写道"这里是居民实际居住的地方，请安静参观。"甘川文化村官方介绍也恳请尊重居民的日常生活。
  • 小巷礼仪(这一篇的建议): 通知文把噪音和侵犯隐私列为管理对象。以下是这一篇的建议。在小巷里最好放低声音。建议不要把大门、窗内、晾着的衣物拍进照片。最好不要堵在别人家门口拍照。建议把垃圾带走。
  • 坡和台阶很多。 甘川文化村是天马山 (Cheonmasan / 천마산)山脚下的阶梯式居住地，草梁故事路上有168阶梯。穿运动鞋。
  • 注意周一。 釜山博物馆、故事工作所、柳致环的邮筒周一休息。
  • 联合国纪念公园不能穿拖鞋和人字拖进入。 着装整洁是建议事项。
  • 遇到事故或紧急情况拨打119，报案拨打112。

① 甘川片区 — 2处

这是从城市铁路1号线土城站和札嘎其站乘社区巴士上去的片区。甘川文化村和峨嵋洞碑石文化村彼此很近，Visit Busan在碑石文化村的指引中也介绍说甘川文化村就在附近。

甘川文化村 (Gamcheon Culture Village / 감천문화마을)

  • 是什么样的地方: 据甘川文化村官方介绍，这是朝鲜战争难民定居而形成的山腹村。1950年代太极道 (Taegukdo / 태극도)信仰村建成后，形成了现在的样子。房屋在天马山山脚下呈阶梯式排开，是为了不遮挡后面房屋的阳光和视野而建的结构。
  • 成为现在样子的契机: 2009年文化体育观光部的村庄美术项目。
  • 游客中心: 09:00~18:00，全年无休。地址是釜山沙下区 (Gamnae 2-ro 203 / 감내2로 203)，电话051-204-1444。提供观光信息，出售小巷游览地图，经营寄存处，负责村子的讲解员导览。
  • 参观时间: 居住密集区域是09:00~18:00(甘川文化村官方网站通知文)。先读上面的特别管理地区一节。
  • 看点: 官方网站介绍天空平台展望台 (Haneulmaru Observatory / 하늘마루 전망대)(051-202-5557)、小博物馆 (Jageun Bakmulgwan / 작은박물관)、小王子和沙漠狐雕塑，以及它下面的纪念品店"小行星B612 (Sohaengseong B612 / 소행성 B612)"。
  • 留在村子里的消费: 官方网站写道，居民协议会运营的设施的收益，会回馈给居民福利和当地。小行星B612纪念品店就是这样的设施。
  • 体验项目: 陶艺、木工等体验在09:00~16:00实行预约制。
  • 交通方式(官方网站指引):
  • 城市铁路1号线土城站6号出口，即釜山大学医院 (Busan National University Hospital / 부산대병원)前，换乘社区巴士西区2号、西区2-2号、沙下区1-1号。
  • 城市铁路1号线札嘎其站1号出口，即忠武市场 (Chungmu Market / 충무시장)站点，换乘社区巴士西区2号、西区2-2号、沙下区1-1号。
  • 有市内公交车61路和社区巴士西区2号、西区2-2号、沙下区1号 (Sahagu 1 / 사하구1)、沙下区1-1号行驶。
  • 自驾前往: 官方网站说村子的停车场不足，建议乘公共交通。公营停车场是78个车位和40个车位。大型巴士必须预约。甘内2路的部分路段，从通知文的实施日(2027-01-01)起，09:00~18:00限制载有游客的车辆通行。

峨嵋洞碑石文化村 (Ami-dong Tombstone Culture Village / 아미동 비석문화마을)

  • 是什么样的地方: 据Visit Busan，这是日本殖民时期曾是日本人公墓的山坡。朝鲜战争时难民在这里盖房子，形成了村子，把墓地的墓碑用作台阶的踏石和房屋的基石。可以看到用在台阶踏石和房屋基石上的墓碑。
  • 开放时间·票价: 每天运营，全年无休。免费。
  • 地址: 釜山西区 (Ami-ro 49 / 아미로49)。
  • 交通方式(Visit Busan指引):
  • 从城市铁路1号线土城站8号出口步行约15分。
  • 乘社区巴士沙下区1-1号或西区2号，在"山上教会·碑石文化村 (Sansang Gyohoe · Bisok Munhwa Maeul / 산상교회·비석문화마을)"下车。
  • 以Kakao Map路线为准，从土城站8号出口770m，步行20分。
  • 停车: Amigol公营停车场 (Amigol / 아미골 공영주차장)。
  • 参观方式: Visit Busan写道"这里是居民实际居住的地方，请安静参观。"近看墓碑时，最好不要把镜头对着房屋里面。
  • 搭配方式: 同样的社区巴士号码(沙下区1-1号、西区2号)在两处的指引中都出现。放在同一天的半天里一起走。

② 草梁山腹道路片区 — 5处

五处都从釜山站步行前往。故事路是从釜山站7号出口出发的步行路线，168阶梯、故事工作所、柳致环的邮筒依次出现在这条路线上。中华街就在釜山站前面。

草梁故事路 (Choryang Ibagu-gil / 초량 이바구길)

  • 路线(釜山东区厅官方指引): 从城市铁路1号线釜山站7号出口出发。以南鲜仓库 (Namseon Changgo / 남선창고) 遗址为起点，全程2.67km，56分。
  • 顺序: 旧百济医院·南鲜仓库遗址 (Gu Baekje Byeongwon · Namseon Changgo Teo / 구 백제병원·남선창고 터) → 围墙画廊·东区人物史围墙 (Damjang Gallery · Dong-gu Inmulsa Damjang / 담장갤러리·동구 인물사담장) → 168阶梯·Kim Min-bu展望台 (Kim Min-bu Observatory / 김민부 전망대)·168 The Deck (168 더 데크) → 鳕鱼子品牌研究所 (Myeongran Brand Institute / 명란브랜드연구소) → 故事工作所 → 望洋路山腹道路展览馆 (Mangyang-ro Sanbok-doro Exhibition Hall / 망양로 산복도로 전시관) → 张起吕纪念 The Nanum中心 (Jang Gi-ryeo Memorial The Nanum Center / 장기려기념 더나눔센터) → 故事营 (Ibagu Camp / 이바구 캠프) → 柳致环的邮筒。
  • 路的特点: 从平地的釜山站前出发，一直爬到山坡上的道路，也就是山腹道路。路线2.67km，所需56分(东区厅指引)。进入故事工作所和柳致环的邮筒参观的时间要另外加上。
  • 星期: 路线上的故事工作所和柳致环的邮筒，周一和公休日休息。周二~周日中选一天。

168阶梯·草梁168阶梯天空路 (168 Stairs · Choryang 168 Stairs Haneul-gil / 168계단·초량168계단 하늘길)

  • 是什么样的地方: 故事路路线的第三个地点。阶梯中间有Kim Min-bu展望台和168 The Deck。
  • 现在有的交通工具: 釜山东区厅官方指引把阶梯旁边的设施介绍为倾斜式电梯"草梁168阶梯天空路"，并写作故事路的新地标。
  • 单轨列车: 东区厅官方指引把阶梯旁边的设施介绍为倾斜式电梯"草梁168阶梯天空路"。不要安排乘单轨列车的行程。
  • 计划: 以步行爬上爬下阶梯为基本来安排行程。
  • 交通方式: 以Kakao Map路线为准，从釜山站7号出口543m，步行13分。

故事工作所 (Ibagu Workshop / 이바구공작소)

  • 是什么样的地方: 故事路路线的第五个地点。经过168阶梯和鳕鱼子品牌研究所之后出现。
  • 运营时间(釜山东区厅官方指引): 周二~周六10:00~19:00，周日09:00~18:00。
  • 休息日: 周一、公休日。
  • 交通方式: 以Kakao Map路线为准，从釜山站7号出口737m，步行19分。

柳致环的邮筒 (Yu Chi-hwan's Postbox / 유치환의 우체통)

  • 是什么样的地方: 故事路路线的最后一个地点。有展望台。
  • 运营时间(釜山东区厅官方指引): 周二~周六10:00~19:00，周日09:00~18:00。
  • 休息日: 周一、公休日。展望台全天开放。在休息日去，也可以在展望台上俯瞰。
  • 交通方式: 从釜山站7号出口沿故事路路线一直走到头。依次经过故事工作所、望洋路山腹道路展览馆、张起吕纪念The Nanum中心、故事营之后就到了。

草梁中华街·上海街 (Choryang Chinatown · Shanghai Street / 초량 차이나타운·상해거리)

  • 是什么样的地方: 据釜山东区厅官方指引，过了釜山站前的大马路，就是红色牌楼上海门，里面是上海街。
  • 沿革(釜山东区厅官方指引):
  • 1884年清朝领事馆开馆，这一带成为清馆街。
  • 1993-08-24釜山市和上海市结为友好城市后，有了"上海街"这个名字。
  • 2007年到2023年是"中华街特区"。现在特区已被解除。
  • 交通方式: 以Kakao Map路线为准，上海门距釜山站1号出口40m，步行1分。
  • 搭配方式: 故事路在釜山站7号出口，上海门在1号出口一侧。在走故事路之前，或者走完下来之后顺路去。也适合在等火车的剩余时间里看。

③ 大渊·釜田片区 — 3处

釜山博物馆和联合国纪念公园，都从城市铁路2号线大渊站3号出口出去。地址也在同一条路上，分别是 UN Pyeonghwa-ro 63 (유엔평화로 63)和 UN Pyeonghwa-ro 93 (유엔평화로 93)。从釜山站有134路公交车到这两处。釜山市民公园在釜山镇区 (Yeonji-dong / 연지동)，以Kakao Map路线为准，从釜田站2号出口步行12分。

釜山博物馆 (Busan Museum / 부산박물관)

  • 参观时间(釜山博物馆官网，2026-11-24): 周二~周日09:00~18:00。入场17:00截止。
  • 休息日: 每周周一和1月1日。周一是公休日的话，在之后的工作日休息。
  • 参观费: 免费。
  • 地址: 釜山南区 (UN Pyeonghwa-ro 63 / 유엔평화로 63)。
  • 交通方式(官网指引):
  • 城市铁路2号线大渊站3号出口朝UN环岛方向步行约10分。以Kakao Map路线为准是690m，11分。
  • 乘公交车134路(经由釜山站·南浦洞)、51路、68路，下车后步行约5分。
  • 乘公交车138路、138-1路、1006路，在"市立博物馆·釜山文化会馆 (Simnip Bakmulgwan · Busan Munhwahoegwan / 시립박물관·부산문화회관)"站下车，步行2分。
  • 咨询: 051-610-7111。
  • 参考: Kakao Map上写的是每天09:00~18:00(Kakao Map登记值，2026-11-24)。博物馆官网写的是周一闭馆。以官网为准。

联合国纪念公园 (UN Memorial Cemetery in Korea / 유엔기념공원)

  • 是什么样的地方: 是朝鲜战争中阵亡的联合国军长眠的墓地。公园官方指引写道，这里是参拜的地方，不是散步或休息的空间。
  • 开放时间(联合国纪念公园官方指引，2026-11-24): 365天全年无休开放。
季节 开门时间 停止入场 关门时间
冬季(10~4月) 09:00 16:45 17:00
夏季(5~9月) 09:00 17:45 18:00
  • 现在: 11月是冬季。要在16:45之前进入，17:00关门。
  • 门票: 没有。
  • 参观礼仪(官方指引):
  • 建议穿着庄重整洁。
  • 不能穿拖鞋和人字拖进入。
  • 公园内不能吃东西，也不能带食物进入。 食物在雕塑公园 (Jogak Gongwon / 조각공원)、和平公园 (Pyeonghwa Gongwon / 평화공원)、文化会馆广场 (Munhwahoegwan Gwangjang / 문화회관 광장)吃。
  • 可以拍个人纪念照。
  • 公共·公益目的的拍摄，包括YouTube和无人机拍摄，要和管理处协商。不允许商业拍摄。
  • 地址: 釜山南区 (UN Pyeonghwa-ro 93 / 유엔평화로 93)。
  • 交通方式(官方指引):
  • 城市铁路2号线大渊站3号出口步行约15分。
  • 从釜山站乘134路公交车，在"联合国公园 (UN Gongwon / 유엔공원)"下车。
  • 从西面乘68路公交车。
  • 自驾前往: 参拜者的轿车1小时30分钟免费。
  • 外语指引: 公园官网除韩语外，还可以选择英语、法语、土耳其语页面。

釜山市民公园 (Busan Citizens Park / 부산시민공원)

  • 运营时间(釜山市民公园官方指引，2026-11-24): 365天05:00~24:00。
  • 票价: 免费开放。租借设施和停车场收费。
  • 哈亚利亚草坪广场 (Hayaria Lawn Plaza / 하야리아잔디광장): 4月到次年1月周二~周日开放，周一不能进入。2~3月是草坪发芽的时期，全面管制。按2026-11-24的标准，周二~周日开放。
  • 位置: 釜山镇区 (Yeonji-dong / 연지동)。
  • 交通方式: 以Kakao Map路线为准，从东海线釜田站2号出口710m，步行12分。
  • 搭配方式: 这一篇的10处当中营业到最晚的地方。放在博物馆和联合国纪念公园关门之后的傍晚。

🗺 路线 — 半天·一天

顺序是按各处的开放·关门时间安排的。机构标注的所需数值是，故事路路线56分，从土城站8号出口到碑石文化村步行约15分，从大渊站3号出口到博物馆约10分，到联合国纪念公园约15分。

半天A — 甘川文化村和峨嵋洞 (不限星期)

  1. 城市铁路1号线土城站6号出口或札嘎其站1号出口 → 社区巴士西区2号·西区2-2号·沙下区1-1号 → 甘川文化村。
  2. 在游客中心(09:00起)获取观光信息。有行李就寄存在寄存处。
  3. 看天空平台展望台、小博物馆、小王子和沙漠狐雕塑。
  4. 社区巴士沙下区1-1号或西区2号 → "山上教会·碑石文化村" → 峨嵋洞碑石文化村。
  5. 从碑石文化村步行约15分到土城站8号出口(Visit Busan指引)。

甘川文化村居住密集区域的参观时间是09:00~18:00。这半天从上午开始。

半天B — 草梁故事路 (周二~周日)

  1. 釜山站7号出口 → 旧百济医院·南鲜仓库遗址 → 围墙画廊。
  2. 168阶梯。在Kim Min-bu展望台和168 The Deck休息。
  3. 故事工作所(周二~周六10:00~19:00，周日09:00~18:00)。
  4. 沿路线走到柳致环的邮筒。在展望台俯瞰。
  5. 向釜山站一侧下来，到上海门和上海街。

路线2.67km，所需56分(东区厅指引)。周二~周六故事工作所10:00开门。比这更早出发，到第3项就要等。

⚠ 常见的3个失误

  1. 以为甘川文化村是随时都能去的地方 — 甘川文化村在2026-08-01被指定为特别管理地区。居住密集区域的参观时间是09:00~18:00，通知文的实施日是2027-01-01。甘内2路的部分约1km路段，从通知文的实施日(2027-01-01)起，09:00~18:00限制包括出租车在内的载有游客的车辆通行。不要安排天黑后去拍小巷照片、乘出租车进到村子里面的行程。
  2. 在168阶梯找单轨列车 — 东区厅官方指引把阶梯旁边的设施介绍为倾斜式电梯"草梁168阶梯天空路"。不要安排乘单轨列车的行程。以步行爬阶梯为基本来安排，并配好鞋子。
  3. 以为联合国纪念公园是散步公园 — 联合国纪念公园是参拜的地方。不能穿拖鞋和人字拖进入，公园内不能吃东西。11月16:45停止入场，17:00关门。如果想找可以走到很晚、休息的地方，就去05:00~24:00开放的釜山市民公园。

⚙ 3个常见问题

  1. 甘川文化村要几点去？独自去也要买地图吗？ — 在09:00~18:00之内去一趟。游客中心09:00~18:00开放，居住密集区域的参观时间也是09:00~18:00。购买地图的义务在10人以上的团体参观者身上。现在(按2026-11-24的标准)还在通知文的实施日(2027-01-01)之前。罚款针对违反甘内2路通行限制，从2028-01-01开始。出处是甘川文化村官方网站通知文。
  2. 周一去的话哪里关门？ — 釜山博物馆、故事工作所、柳致环的邮筒周一休息。釜山市民公园的哈亚利亚草坪广场周一也不能进入。指引中写明周一也开放的地方，是甘川文化村游客中心(全年无休)、峨嵋洞碑石文化村(全年无休)、联合国纪念公园(全年无休)、釜山市民公园(365天)。柳致环的邮筒展望台全天开放。
  3. 有要付门票的地方吗？ — 釜山博物馆、峨嵋洞碑石文化村、釜山市民公园免费，联合国纪念公园没有门票。釜山市民公园的租借设施和停车场收费。联合国纪念公园的参拜者轿车可以免费停1小时30分钟。甘川文化村的陶艺·木工体验在09:00~16:00实行预约制。
