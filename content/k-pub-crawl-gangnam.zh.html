江南·梨泰院酒吧9家 — 步行连起清潭鸡尾酒巷和海方村坡道的两条路线

副标题: 江南站精酿啤酒屋2家，清潭岛山大路55街 (Dosan-daero 55-gil / 도산대로55길) 鸡尾酒吧3家，鹿沙坪·海方村3家，新龙山酿酒厂1家。清潭的3家在同一条巷子里，彼此相距160m，适合步行逛，从鹿沙坪到海方村是600多米的坡道。每家店都标了一杯啤酒或鸡尾酒的价格、下酒菜的价格、最低消费 (cover charge) 和饮食提示。在韩国可以喝酒的年龄和身份证规定也一并整理了。

#779 · 2026-11-24 修订 · 首尔酒吧

🎯 适合这样的人

适合吃完晚饭后想步行换两三家店喝酒的游客。不是在一个地方坐很久，而是选定一个街区，在店与店之间走着喝的"串酒吧 (pub crawl)"方式。只留下从地铁站可以步行到达、Kakao地图 (Kakao Map / 카카오맵) 上有店主登记的营业信息、并且有2026年10~11月发布的到访评价或照片的店。

⚠ 标注原则: 营业时间·休息日是店主登记在Kakao地图 (Kakao Map / 카카오맵) 上的值(2026-11-24确认)。价格只用了Kakao地图菜单中登记日期在2年以内的。像鸡尾酒吧这样登记价格比较旧的店，用的是标有日期的Naver博客到访评价里的价格，并在旁边附上了出处。饮食提示只写菜名上能读出来的内容，所以食材和过敏原点单前要向店员确认。店与店之间的步行距离是按OpenStreetMap步行路线量出来的值，从站到店的步行时间·出口是Kakao地图导航的值。

① 江南站 — 精酿啤酒2家

两家店在江南站两侧，相距1.2km(步行15分钟多)。两家选一家比较好。

精酿啤酒屋 (Goose Island Brewhouse / 구스아일랜드 브루하우스)

挂着美国芝加哥酿酒厂Goose Island之名的2层酒馆。Kakao地图标签上有屋顶露台。周一至周六11:30~24:00，周日11:30~23:00，白天也可以喝。Naver博客评价(2026-11-15)里写的价格是黑啤Black Hole ₩7,500，江南Style赛松 ₩9,000，甜柿三料啤酒 ₩10,000，芝士汉堡芝加哥披萨₩36,000。另一篇评价(2026-11-22)里，工作日午餐2人套餐是₩38,000。地址是江南区 (Gangnam-gu / 강남구) 驿三路118 (Yeoksam-ro 118 / 역삼로 118)，从江南站(2号线·新盆唐线)4号出口步行8分钟。

  • 饮食提示: 芝加哥披萨里芝士放得厚，芝士汉堡披萨里有牛肉。以烧烤拼盘之类的肉类菜品为主。没有确认过的素食菜单。

精酿啤酒披萨店 (Beer Room / 비어룸)

江南站北侧巷子里的精酿啤酒·柴火披萨店。周三至周日11:30~23:30，周一·周二休息。酒也可以按杯卖，但最显眼的是酒水无限畅饮。Kakao地图登记价是无限畅饮₩30,000(2025-08-07)，博客评价(2026-10-12)里写了1小时₩15,000、3小时₩30,000两种。无限畅饮包括精酿啤酒·葡萄酒·highball。下酒菜登记价是楔形薯条₩6,000，配火辣鸡肉芝士酱的玉米片₩5,000，玛格丽特披萨₩26,000(2025-12-11)，Diavola披萨₩36,000。地址是江南区 (Gangnam-gu / 강남구) 江南大路98街22 1层 (Gangnam-daero 98-gil 22 / 강남대로98길 22 1층)，从江南站11号出口走7分钟。

  • 饮食提示: 玛格丽特披萨里没有肉，但有芝士。Diavola和萨拉米菜品通常用猪肉加工肉。薯条是不含肉的菜品。玉米片配的火辣鸡肉芝士酱很辣，含乳制品。

② 清潭岛山大路55街 — 鸡尾酒吧3家

3家店聚在一条巷子里，距离狎鸥亭罗德奥站(水仁盆唐线)4号出口2~4分钟。三家都通过Catchtable接受预约。Le Chamber和Alice另收每人的最低消费。

鸡尾酒吧 (ZEST / 제스트)

把水果皮之类被丢弃的食材重新用在鸡尾酒里的"零废弃 (zero waste)"酒吧。在The World's 50 Best Bars 2026榜单上排第7位(the50.com, 2026-11-24确认)。周一至周五18:30~02:00，周六·周日15:00~02:00，周末下午就开门。2026-11-05发布的博客评价里写了鸡尾酒每杯₩26,000，无酒精的Natural Cola ₩15,000，但那是作者约1年前到访时的价格。2026-02-21的Kakao地图评价说调酒师用英语讲解得很好。地址是江南区 (Gangnam-gu / 강남구) 岛山大路55街26 1层 (Dosan-daero 55-gil 26 / 도산대로55길 26 1층)。

  • 饮食提示: 每杯鸡尾酒的食材不同，有季节水果·香草·雪莉酒等。Kakao地图摘要上有"部分禁止儿童入内"的标签。

鸡尾酒威士忌吧 (Le Chamber / 르챔버)

从书架形状的隐藏门进入的地下酒吧。按一下入口右侧书架最上层的书，门就会打开(博客评价 2026-09-27)。周一至周四19:00~03:00，周五·周六19:00~04:00，周日·公休日19:00~02:00，是这一篇里开到最晚的。点单之外另收最低消费每人₩10,000(博客评价 2026-10-05)。除了鸡尾酒，还可以整瓶点威士忌并寄存(同一篇评价)。Kakao地图摘要里说有钢琴现场演奏。2026-05-20的Kakao地图英文评价写道店员接待很好，价位偏高。地址是江南区 (Gangnam-gu / 강남구) 岛山大路55街42 地下1层 (Dosan-daero 55-gil 42 / 도산대로55길 42 지하 1층)。

  • 饮食提示: 据Kakao地图摘要，基本下酒菜是薯片和椒盐脆饼。这是以酒为主的酒吧，不要指望有正餐菜单。

鸡尾酒吧 (Alice / 앨리스)

以"爱丽丝梦游仙境"为主题装饰的地下鸡尾酒吧。每天18:00~02:00。据博客评价(2026-11-20)，最低消费每人₩10,000(含迎宾饮品)，同时会上一些小零食，招牌鸡尾酒全部是₩27,000。菜单是扑克牌的形状，牌上的数字表示酒精度。也有用韩国食材的酒，比如混合了烧酒·草莓·辣椒酱的鸡尾酒。地址是江南区 (Gangnam-gu / 강남구) 岛山大路55街47 地下1层 (Dosan-daero 55-gil 47 / 도산대로55길 47 지하 1층)。

  • 饮食提示: 鸡尾酒食材连烧酒·水果·酱类都用上了，有过敏的话点单前先说。不能喝酒的话，也要提前确认迎宾饮品。

③ 鹿沙坪·海方村 — 3家

从鹿沙坪站(6号线)前的鹿沙坪大路 (Noksapyeong-daero / 녹사평대로) 到海方村的新兴路 (Sinheung-ro / 신흥로)，是一路相连的坡道。Genie Pub和DANKYARD周一休息。Southside Parlor在Kakao地图上也登记为周一休息，但2026-11-19的博客评价里写的是周一营业。

得州风酒吧 (Southside Parlor / 사우스사이드팔러)

美国得州风的塔可·鸡尾酒吧，在4层，Kakao地图标签上有飞镖和屋顶露台。博客评价(2026-04-26)和Kakao地图摘要都说外国客人很多。Kakao地图登记的时间是周二至周四18:00~01:00，周五·周六18:00~02:00，周日18:00~01:00，周一休息。不过2026-11-19的博客评价写的是周一营业和周末17:00开门，所以周一要看Instagram公告。登记价(2026-07-01)是3个塔可₩16,000，芝士夹饼₩16,000，水牛城鸡肉或炸鸡三明治₩18,000，凯撒沙拉₩12,000。按博客评价，鸡尾酒是₩18,000(2026-11-19，以2杯季节招牌鸡尾酒为准)，Magpie淡色艾尔·海鸥IPA是₩9,000(2026-09-29)。同一篇11月评价说，如果同时点酒，周二塔可每个₩4,000，周三鸡翅半价。地址是龙山区 (Yongsan-gu / 용산구) 鹿沙坪大路218 4层 (Noksapyeong-daero 218 / 녹사평대로 218 4층)，从鹿沙坪站3号出口走7分钟。

  • 饮食提示: 菜单上有纯素辣香肠塔可。鱼肉塔可是鱼，鸡肉塔可·鸡翅是鸡肉。塔可饼皮和炸衣的材料点单时问一下。

鸡尾酒酒馆 (Genie Pub / 지니펍)

海方村主路新兴路上3层的休闲鸡尾酒酒馆。周二至周四18:00~01:00，周五18:00~02:00，周六17:00~02:00，周日18:00~01:00，周一休息。Kakao地图登记价(2026-10-06)是蜜桃压碎·自由古巴 ₩12,000，莫斯科骡子 ₩13,000，内格罗尼·长岛冰茶 ₩14,000，招牌"鹿沙坪站2号出口" ₩15,000等，整体为₩12,000~16,000。博客评价(2026-11-03)写道啤酒不到₩10,000。从靠窗的座位可以俯瞰海方村的街道。地址是龙山区 (Yongsan-gu / 용산구) 新兴路37 3层 (Sinheung-ro 37 / 신흥로 37 3층)，从鹿沙坪站2号出口走12分钟。

  • 饮食提示: Kakao地图标签上有披萨酒馆，但没有登记下酒菜价格。请当作以鸡尾酒为主的店去。

酿酒厂聆听吧 (DANKYARD Seoul / 댕크야드 서울)

提供自酿啤酒和音乐的2层酿酒厂兼聆听吧。周二至周四18:00~24:00，周五·周六18:00~01:00，周日16:00~23:00，周一休息。啤酒登记价(2025-12-02)是拉格₩9,000，Neugeut ₩11,500，波特·Genie世涛 ₩12,500，Gyeongpo双倍IPA ₩16,000，冰波克 ₩27,000。食物登记的是千层面₩20,000(2026-06-16)。Kakao地图评价(2026-02-07)写道啤酒阵容每个月都会变。地址是龙山区 (Yongsan-gu / 용산구) 新兴路5街11 2层 (Sinheung-ro 5-gil 11 / 신흥로5길 11 2층)，距Genie Pub 45m。

  • 饮食提示: Kakao地图摘要上有"素食菜单"的标签。是哪道菜，点单时问一下。千层面通常含芝士和肉酱。

④ 新龙山 — 1家

酿酒厂酒吧 (Hand and Malt Brew Lab / 핸드앤몰트 브루랩)

精酿啤酒酿造商Hand and Malt的Taproom，在新龙山站后面的"龙理团路 (Yongridan-gil / 용리단길)"。周一至周四17:00~23:00，周五17:00~24:00，周六14:00~24:00，周日14:00~23:00。按博客评价(2026-10-29)，首尔IPA 340mL是₩8,600。下酒菜登记价(2025-09-13)是辣椒酱肉酱年糕₩17,900，锅巴芝士土豆饼·Kkamang炸鱼薯条₩19,900，盐烤鸡脖肉₩22,900。1层有一面墙是整面落地窗。地址是龙山区 (Yongsan-gu / 용산구) 汉江大路38街19 (Hangang-daero 38ga-gil 19 / 한강대로38가길 19)，从新龙山站(4号线)1号出口走5分钟。距鹿沙坪2.2km，想和梨泰院路线连起来就要坐公交或出租车。

  • 饮食提示: 据Kakao地图菜单说明，辣椒酱肉酱年糕是在用牛肉碎煮的肉酱里放年糕、再铺上烤牛五花的年糕，Kkamang炸鱼薯条是裹上鱿鱼墨汁面糊炸的比目鱼。土豆饼里有芝士。鸡脖肉是鸡肉。

🗺 步行走的两条路线

A. 清潭鸡尾酒 (三家之间共160m)

  1. 18:30 狎鸥亭罗德奥站4号出口 → 鸡尾酒吧 (ZEST / 제스트)(4分钟)。周末15:00开门
  2. 20:00左右 转到鸡尾酒威士忌吧 (Le Chamber / 르챔버)(118m, 2分钟)。19:00开门
  3. 21:30左右 转到鸡尾酒吧 (Alice / 앨리스)(42m, 1分钟)

即使每家只喝一杯，最低消费也会收两次(每人₩20,000)。周五·周六想玩到很晚的话，把开到04:00的Le Chamber放在最后。

B. 鹿沙坪 → 海方村 (店与店之间约650m, 坡道)

  1. 18:00 鹿沙坪站3号出口 → 得州风酒吧 (Southside Parlor / 사우스사이드팔러)(7分钟)。用塔可和啤酒代替晚饭
  2. 20:00左右 沿新兴路到鸡尾酒酒馆 (Genie Pub / 지니펍)，610m(步行8分钟多，坡道)
  3. 21:30左右 在隔壁45m的酿酒厂聆听吧 (DANKYARD / 댕크야드) 用啤酒收尾。周五·周六开到01:00

这是按周二至周日安排的路线。周一Genie Pub和DANKYARD休息，Southside Parlor在Kakao地图上是休息，但2026-11-19的评价里写的是营业，所以去之前看Instagram公告。

⚠ 3个常见失误

  1. 周一安排B路线 — Genie Pub和DANKYARD周一休息。Southside Parlor在Kakao地图上周一休息，但2026-11-19的评价里写的是周一营业。Beer Room周一·周二休息。
  2. 不知道最低消费就进店 — Le Chamber在点单之外另收每人₩10,000，Alice含迎宾饮品每人₩10,000。在Alice，一杯招牌鸡尾酒加上最低消费是每人₩37,000。
  3. 不带身份证出门 — 酒吧·酒馆在入场或点单时会确认年龄。外国人带上护照原件最保险。

⚙ 3个常见问题

  1. 几岁开始可以喝酒？ — 青少年保护法把未满19岁视为青少年，但到了满19岁那一年的1月1日之后就不再算青少年。与生日无关，按出生年份计算，所以2026年出生于2007年或更早的人可以买酒。同一部法律规定不得向青少年卖酒，卖方有义务确认年龄和本人身份。这一篇里的店以酒为主，未成年人即使一起进去也不能点酒，也有完全不让入场的店。
  2. 吃素或不吃猪肉怎么办？ — Southside Parlor的纯素辣香肠塔可，Beer Room的玛格丽特披萨·薯条，从菜名上可以确认。DANKYARD在Kakao地图摘要上标有素食菜单。鸡尾酒的材料里可能有黄油·鸡蛋·乳制品，吃素·纯素的话点单时确认。
  3. 需要预约吗？ — 清潭三家和Southside Parlor·Hand and Malt，Kakao地图上连着Catchtable预约页面。周五·周六晚上去清潭的话，最好预约。Beer Room的无限畅饮，博客评价(2026-10-26)里有通过Naver预约购买券的内容。
