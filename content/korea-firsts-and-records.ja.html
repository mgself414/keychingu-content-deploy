🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「韓国の最初&最高 (Hanguk-ui Choecho & Choego / 한국의 최초&최고)」テーマで選ばれた場所のうち、韓国観光公社の観光情報の紹介文に「最初・最大・最も」のような記録が直接書かれている20か所を扱います。表の順位と得票数は、その投票結果です。

「最初」や「最高」のような記録は、出典によって言い方が変わりやすいものです。そのため、投票の推薦理由ではなく、観光公社の紹介文に書かれた記録だけを写し、本文には「観光公社の紹介によると」を付けました。候補は、投票順位60位前後までの場所のうち観光公社の情報番号がある場所の紹介文を確認して選んだもので、100か所すべてを確認したわけではありません。石窟庵 (Seokgulam / 석굴암)・国立中央博物館 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)・漢拏山 (Hallasan / 한라산)・宗廟 (Jongmyo / 종묘)のように得票が高い場所もありますが、紹介文に「最初・最大・最も」のような記録が書かれていないため入れませんでした。景福宮の紹介文にある「朝鮮王朝第一の法宮」は記録ではなく格式を表す言葉なので、同じ理由で外しました。投票の名称・住所が観光公社の登録と違う場所(益山 弥勒寺址の石塔・江陵 正東津駅の高速鉄道など)は、観光公社の表記に従いました。

運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。登録値がない欄は「登録値なし」と書きました。

📍 「初めて」の場所 — 瞻星台・紹修書院・広蔵市場・松島海水浴場・殿洞聖堂・華城行宮・順天湾国家庭園

慶州 瞻星台、慶州市 チョムソンノ 140-25、☎ シンギョンジュ駅 (Singyeongju-yeok / 신경주역) 観光案内所 054-771-1336は、新羅の善徳女王 (Seondeok Yeowang / 선덕여왕)の時代(在位 632~647)に建てられたと推定される天文観測台です。観光公社の紹介(国家遺産庁の資料を引用)によると、東洋で最も古い天文台として知られています。高さは約9mで、扇形の石を27段に積んでいます。

  • 開く時間: 夏期 09:00~22:00, 冬期 09:00~21:00。休み: 年中無休。料金: 無料。

栄州 紹修書院、栄州市 スンフン面 (Sunheung-myeon / 순흥면) ソベンノ 2740、☎ 054-639-5852は、1542年にプンギ (Punggi / 풍기)郡守の周世鵬 (Ju Sebung / 주세붕)が安珦 (An Hyang / 안향)をまつる祠堂を建てたことから始まりました。1550年に李滉 (Yi Hwang / 이황)の要請で「紹修書院」という名前を受けました。観光公社の紹介によると、建物の配置が自由なのは、書院の形式が定まる前に建てられた韓国で最初の初期書院だからです。

  • 開く時間: 11~2月 09:00~17:00, 3~5・9~10月 09:00~18:00, 6~8月 09:00~19:00。入場は観覧終了の1時間前までです。
  • 休み: 年中無休。料金(個人): 大人 2,000ウォン、青少年・軍人 1,330ウォン、子ども 660ウォン。

広蔵市場、チョンノ区 (Jongno-gu / 종로구) チャンギョングンノ 88、☎ 02-2267-0291は、観光公社の紹介によると、1905年に開いた韓国で最初の常設市場です。今は韓服 (Hanbok / 한복)の生地・織物・衣類・食べ物をすべて扱う総合市場で、観光公社の紹介によると、東門・北2門・南1門が出会う食べ物の屋台街が市場でいちばんにぎやかな場所です。

  • 開く時間・休み: 店舗ごとに異なると登録されています。

釜山 松島海水浴場、釜山 ソ区 (Seo-gu / 서구) ソンドヘビョンノ 100、☎ 051-240-4000は、観光公社の紹介によると、1913年に釜山で最初に開場した海水浴場です。海岸の生態公園であるアムナム公園 (Amnam Gongwon / 암남공원)とつながっています。

  • 開く時間: 06:00~23:00。休み: 年中無休。料金: 無料。

全州 殿洞聖堂、全州市 ワンサン区 (Wansan-gu / 완산구) テジョロ 51、☎ 063-284-3222は、朝鮮時代のカトリック殉教の地に1914年に完成した聖堂です。観光公社の紹介によると、ホナム (Honam / 호남)地方で最初に建てられたロマネスク様式の建物で、ビザンチン様式の鐘塔があります。

  • 開く時間: 09:00~17:00。休み: 年中無休。

水原 華城行宮、水原市 パルダル区 (Paldal-gu / 팔달구) チョンジョロ 825、☎ チケット売り場 031-5191-4677は、正祖 (Jeongjo / 정조)がヒョルリョンウォン (Hyeollyungwon / 현륭원)へ行く際に滞在した行宮です。観光公社の紹介によると、ファソン (Hwaseong / 화성)は世界遺産に選ばれただけでなく、韓国で最初の新都市開発の事例とも評価されています。

  • 開く時間: 3~10月 09:00~18:00, 11~2月 09:00~17:00。休み: 年中無休。
  • 料金(個人): 大人 2,000ウォン、青少年・軍人 1,500ウォン、小学生 1,000ウォン。

順天湾国家庭園、順天市 グッカジョンウォン1ホギル 47、☎ 061-749-3114は、観光公社の紹介によると、大韓民国第1号の国家庭園です。2013年にスンチョンマン国際庭園博覧会 (Suncheonman Gukje Jeongwon Bangnamhoe / 순천만국제정원박람회)を開いて造成し、926,992㎡に世界各国の伝統庭園とテーマ庭園があります。

  • 開く時間: 10~6月 09:00~20:00, 7~9月 09:00~21:00(どちらの時期も入場締め切り 19:00)。休み: 毎月最終週の月曜日。
  • 料金(個人): 成人 10,000ウォン、青少年・軍人 7,000ウォン、子ども 5,000ウォン。17時以降の夜間券は成人 5,000ウォン。

📍 「最も大きい・長い」場所 — 全州韓屋村・弥勒寺址・支石墓遺跡・ファンソン窟・土旺城瀑布・龍門寺のイチョウ・パルワンサンのケーブルカー

全州韓屋村、全州市 ワンサン区 キリンデロ 99、☎ 063-282-1330は、観光公社の紹介によると、韓屋 (Hanok / 한옥)700軒あまりが集まった国内最大規模の伝統韓屋村であり、全国唯一の都心の韓屋群です。1910年から造成され、キョンギジョン (Gyeonggijeon / 경기전)・オモクデ (Omokdae / 오목대)・ヒャンギョ (Hyanggyo / 향교)があります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 基本30分 1,200ウォン、追加15分 600ウォン。

益山 弥勒寺址、益山市 クンマ面 (Geumma-myeon / 금마면) ミルクサジロ 362、☎ 観光案内所 063-859-3873は、百済の武王 (Muwang / 무왕)の時代に建てた寺の跡で、ユネスコ世界遺産です。観光公社の紹介によると、国宝の弥勒寺址石塔は現在の高さ14.24mで、韓国で最古、最大の石塔です。ここでの「最古」は最も古いという意味で、投票の推薦理由にも「最古」と書かれています。紹介文はその理由として、以前の木塔の様式を石で忠実に再現した点を挙げています。東塔は1993年に9層(高さ27.67m)で復元しました。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

高敞 支石墓遺跡、高敞郡 コチャン邑 (Gochang-eup / 고창읍) コインドルゴンウォンギル 74、☎ 支石墓博物館 (Goindol Bangmulgwan / 고인돌박물관) 063-560-8666は、2000年にユネスコ世界遺産に登録されました。観光公社の紹介によると、単一区域としては韓国で最も大きい支石墓の群集で、高敞郡に支石墓1,748基があります(2023年調査基準。投票の推薦理由には447基と書かれています)。探訪コースは1~5コース 1.8㎞、6コース 1.7㎞です。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

三陟 ファンソン窟、三陟市 シンギ面 (Singi-myeon / 신기면) ファンソンノ 800、☎ 1533-8362は、観光公社の紹介によると、韓国最大規模の石灰岩洞窟で、約5億3千万年前にできました。洞窟の中で動物47種が見つかりました。入口までモノレールが走っています。

  • 開く時間: 3~10月 09:00~17:00, 11~2月 09:00~16:00。休み: 毎月18日(休日・連休なら次の平日)。
  • 料金(個人): 大人 4,500ウォン、敬老・青少年 3,000ウォン、子ども・軍人 2,000ウォン。モノレール 13歳以上 往復 7,000ウォン。

雪岳山 土旺城瀑布、ソクチョ市 ソラクトン (Seorak-dong / 설악동)、☎ 033-801-0900は、上段150m・中段80m・下段90m、合計320mの3段の滝です。観光公社の紹介によると、国内最長の連瀑で、冬は国内最大の氷瀑として知られています。2015年にピリョン滝 (Biryong Pokpo / 비룡폭포)の探訪路を延長して展望台まで開き、展望台は滝から1㎞以上離れています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

楊平 龍門寺のイチョウ、楊平郡 ヨンムン面 (Yongmun-myeon / 용문면) ヨンムンサンノ 782、☎ 031-773-0088は、樹齢約1,100年と推定される天然記念物です。高さ42.0m、胸高周囲11.0mで、観光公社の紹介によると、韓国のイチョウの中で、樹齢と高さのどちらも最も高い記録を持っています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 小型車 3,000ウォン。

パルワンサン観光ケーブルカー、平昌郡 テグァルリョン面 (Daegwallyeong-myeon / 대관령면) オリンピクロ 715 ドラゴンプラザ (Deuragon Peuraja / 드래곤프라자) 2階は、8人乗りのキャビン100台がつながった往復7.4㎞のケーブルカーです。観光公社の紹介によると、国内最大の長さです(この値は往復基準で、投票の推薦理由には3.7㎞と書かれています)。標高1,458mのパルワンサン頂上まで18分かかります。強風など天気が悪いと休みます。

  • 開く時間・休み・料金: 登録値なし。

📍 「果てと始まり」 — 艮絶岬・馬羅島・正東津駅

蔚山 艮絶岬、ウルチュ郡 (Ulju-gun / 울주군) ソセン面 (Seosaeng-myeon / 서생면) カンジョルゴッ1ギル 39-2、☎ 052-204-1751~6は、観光公社の紹介によると、朝鮮半島で最も早く日が昇る場所で、浦項のホミゴッ (Homigot / 호미곶)より1分、江陵のチョンドンジン (Jeongdongjin / 정동진)より5分ほど早く日が昇ります。観光公社の紹介によると、世界最大サイズの願いの郵便ポスト (Somang Uchetong / 소망우체통)もあり、はがきを入れると実際に配達されます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

済州 馬羅島、ソギポ市 (Seogwipo / 서귀포) テジョン邑 (Daejeong-eup / 대정읍) マラロ101ボンギル 46、☎ 064-760-4014は、観光公社の紹介によると、韓国最南端の島です。ウンジン港 (Unjinhang / 운진항)から船で30分ほどかかり、島の南の端に最南端の碑があります。島を一周するには1~2時間あれば十分です。

  • 開く時間: 常時開放(船の運航時間は別に確認)。休み: 年中無休。料金: 無料(船賃は別)。

江陵 正東津駅、江陵市 カンドン面 (Gangdong-myeon / 강동면) チョンドンヨッキル 17、☎ 砂時計観光案内センター (Moraesigye Gwangwang Annae Senteo / 모래시계관광안내센터) 033-640-4536は、観光公社の紹介によると、全国で海がいちばん近い駅です。景福宮 (Gyeongbokgung / 경복궁)のクァンファムン (Gwanghwamun / 광화문)から真東にあることから名前が付き、1995年にドラマ「砂時計 (Moraesigye / 모래시계)」で日の出の名所になりました。

  • 開く時間: 路線ごとに異なると登録されています。休み: 年中無休。

📍 「世界」の記録 — 万丈窟・ウポ沼・スペースウォーク

済州 万丈窟、済州市 クジャ邑 (Gujwa-eup / 구좌읍) マンジャングルギル 182、☎ 064-710-7903は、全長約7,400mの溶岩洞窟で、済州世界自然遺産の一部です。一般の人は第2入口から入り、1㎞だけ見ることができます。観光公社の紹介によると、開放区間の終わりにある高さ約7.6mの溶岩石柱は世界で最も大きい規模として知られています。

  • 開く時間: 09:00~18:00(入場締め切り 17:00)。休み: 毎月第一水曜日。
  • 料金(個人): 成人 4,000ウォン、青少年・子ども・軍人 2,000ウォン。

昌寧 ウポ沼、昌寧郡 ユオ面 (Yueo-myeon / 유어면) ウポヌプギル 220、☎ 055-530-2121は、面積2,505千㎡の沼地です。観光公社の紹介によると、2018年10月25日の第13回ラムサール条約締約国会議で世界で初めてラムサール湿地都市に認証されました。沼ができ始めたのは1億4,000万年前と紹介されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 無料。

浦項 ファノ公園 スペースウォーク、浦項市 プク区 (Buk-gu / 북구) ファノ公園ギル 30、☎ 054-270-5176は、トラックの長さ333m、階段717段の参加型作品です。観光公社の紹介によると、世界で最も美しい19の階段に選ばれたことがあります。雨や強風があると出入りが統制されます。

  • 開く時間: 4~10月 平日 10:00~20:00・週末 10:00~21:00, 11~3月 平日 10:00~17:00・週末 10:00~18:00。
  • 休み: 毎月第一月曜日(祝日なら翌日)、気象悪化・点検のとき。料金: 無料。

⚠ 事前に知っておきたい3点

  1. 記録は観光公社の紹介が基準です — 「最初・最大・最も」は観光公社の紹介文に書かれた表現を写したもので、ほかの資料では違う言い方をすることがあります。
  2. 休みが特別な場所があります — 万丈窟は毎月第一水曜日、ファンソン窟は毎月18日、スペースウォークは毎月第一月曜日、順天湾国家庭園は毎月最終週の月曜日に休みます。
  3. 天気によって閉まる場所があります — パルワンサンのケーブルカーとスペースウォークは強風など天気が悪いと運営せず、馬羅島は船の運航時間を別に確認する必要があります。

⚙ FAQ 3

Q. ソウルで見られる場所は?

A. ソウルには広蔵市場があります。観光公社の紹介によると、1905年に開いた韓国で最初の常設市場です。首都圏には、京畿の水原 華城行宮と楊平 龍門寺のイチョウもあります。

Q. お金がかかる場所は?

A. 入場料が登録された場所は、順天湾国家庭園(成人 10,000ウォン)、ファンソン窟(大人 4,500ウォン)、万丈窟(成人 4,000ウォン)、華城行宮(大人 2,000ウォン)、紹修書院(大人 2,000ウォン)です。馬羅島は、島は無料ですが船賃が別にかかり、パルワンサン観光ケーブルカーは料金の登録値がないため別に確認が必要です。

Q. 日の出で有名な場所は?

A. 艮絶岬と正東津駅です。観光公社の紹介によると、艮絶岬は朝鮮半島で最も早く日が昇る場所で、チョンドンジンより5分ほど早く日が昇ります。
