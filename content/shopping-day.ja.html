最適ルート分析: どの順番で回る?

ルートA: ミョンドン → カンナム → ソンス → ホンデ (推奨 ⭐⭐⭐⭐⭐)

メリット:

  • 午前から夜までエネルギー管理がしやすい
  • ショッピング強度の調整が可能 (ミョンドン 高強度 → カンナム ゆったり → ソンス・ホンデ 軽め)
  • 夜はホンデのナイトライフも楽しめる
  • 1日の流れが自然

タイムテーブル:

```

10:00~12:00 - ミョンドン (명동) (2時間、集中ショッピング)

12:00~13:00 - 移動+ランチ (ミョンドン駅 → カンナム駅、地下鉄20分)

13:00~15:30 - カンナム (강남) (2.5時間、ゆったりショッピング)

15:30~16:00 - 移動 (カンナム駅 → ソンス駅、地下鉄15分)

16:00~18:00 - ソンス (성수) (2時間、ポップアップ/感性ショッピング)

18:00~18:30 - 移動+夕食 (ソンス → ホンデ、地下鉄30分)

18:30~21:00 - ホンデ (홍대) (2.5時間、夜ショッピング+カルチャー)

```

ルートB: ミョンドン → ソンス → カンナム → ホンデ (次善)

メリット:

  • ソンスを午後の前半 (光が良い時間帯) に訪問できる
  • カンナムをピークタイム (15:00~17:00) に体験できる

デメリット:

  • 移動距離が増える
  • 夜にカンナムをうろつく (疲労感)

ルートC: ホンデ → ソンス → カンナム → ミョンドン (夜型)

メリット:

  • 午後からのスタートが可能 (朝はゆっくり)
  • ミョンドンを23:00 (PM11時) まで買い物できる

デメリット:

  • ホンデは午後~夜に盛り上がる (昼間は静か)
  • 体力消耗が激しい

タックスリファンド&免税 完全ガイド

タックスリファンド (Tax Refund)

とは? 外国人が韓国で購入した商品の付加価値税 (10%) の還付制度

タックスリファンドを受けるには

1. 最低購入額: 1店舗につき最低 ₩30,000 以上

2. 累計額: 同日に最低 ₩50,000 以上

3. レシート保管: 必ず保管すること

4. 還付窓口訪問: 空港または ミョンドン (명동) の還付窓口

タックスリファンド対応場所 (1日ショッピングコース上)

場所 営業時間 備考
ミョンドン 還付窓口 10:00~21:00 (AM10時~PM9時) ショッピング直後に即還付 (推奨)
カンナム駅 還付窓口 10:00~20:00 (AM10時~PM8時) カンナムショッピング後
仁川空港 還付窓口 24時間 出国直前 (行列あり)

ヒント:

  • 手数料: 還付額の3~5%
  • 還付方法: 現金/クレジットカード選択可
  • 必ず出国前に還付すること (商品の持ち出し証明が必要)
