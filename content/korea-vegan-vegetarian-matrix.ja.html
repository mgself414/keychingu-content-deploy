なぜ韓国のベジタリアン・ビーガンなのか

韓国のベジタリアン・ビーガンシーンは、外国人訪問者に予想外の選択肢を提供します。

仏教文化圏特有の寺院精進料理(sachal eumsik / 사찰 음식)は、肉・魚・五辛菜(osinchae / 오신채：ネギ・ニンニク・ニラ・ラッキョウ・アサフェティダ)を使わず、旬の野菜と発酵食品だけで味を出します。この伝統は現在、ソウル都心のビーガンレストランで現代的に再解釈されています。同時に梨泰院(Itaewon / 이태원)・弘大(Hongdae / 홍대)・江南(Gangnam / 강남)を中心に、国際レベルのビーガン専門店が登場しました。英語メニューとHappyCow登録を備えた店も増えています。

外国人が実際に出会うベジタリアン・ビーガンの韓国は、大きく二つの流れに分かれます。一つは寺院・伝統・UNESCO文化財とつながる流れ、もう一つは梨泰院・弘大・江南の国際型ビーガンクラスターです。この二つの流れを理解すれば、韓国ビーガン旅行の80%は解決します。

外国人がよくやる間違い3つ

間違い1：「韓国料理は肉ばかり」と諦める

韓国の伝統料理には菜食ベースのものが多くあります。ビビンバ(bibimbap / 비빔밥、卵抜きリクエスト可能)、ナムル(namul / 나물)のおかず、味噌チゲ(doenjang jjigae / 된장찌개、カタクチイワシ出汁に注意)は、もともと野菜中心です。寺院精進料理専門店でなくても、一般の韓食店でベジタリアンオプションを頼むと対応してもらえる場合があります。

間違い2：味噌チゲ・キムチをビーガンだと勘違いする

一般的な味噌チゲはカタクチイワシまたは貝の出汁を使います。一般的なキムチ(kimchi / 김치)にも塩辛(魚の発酵調味料)が入ります。ビーガンキムチは塩辛を使わずに漬けた別製品で、ベジタリアン専門店や寺院精進料理店でのみ確実に提供されます。注文時は「No fish sauce, no anchovy broth」と明示します。

間違い3：HappyCowを現地で初めて開く

梨泰院・弘大のビーガンレストランはブレイクタイム(14:00~17:00)があったり予約制が多かったりします。訪問前日にHappyCowで営業時間・予約要否・現在の営業状況を確認します。Googleマップの最近のレビューで実際に営業中か交差検証するのが安全です。

軸1：寺院精進料理を深掘り

1. 通度寺・海印寺・松広寺の寺院精進料理

背景：この三つの寺院は韓国三大寺院で、それぞれ精進料理の食堂(供養間または外部専門店)を運営するか、近隣に専門店が形成されています。

  • 通度寺(慶尚南道・梁山)：近隣の「通度寺近くの山菜ビビンバ」食堂が寺院精進料理スタイルで営業。通度寺自体の供養間は僧侶の食事用ですが、行事の際には外部に開放されます。
  • 海印寺(慶尚南道・陜川)：海印寺入口の「海印寺食堂街」に山菜ビビンバ・キノコ鍋専門店。肉抜きメニューの選択が可能。代表メニューの山菜ビビンバは₩12,000~15,000。
  • 松広寺(全羅南道・順天)：曹渓山登山コースと連携。寺院内部の供養間ではテンプルステイ参加者向けに鉢盂供養(barugongyang / 발우공양)を提供する(ビーガン、1人前)。

実用情報：

  • 三寺院とも、ソウルから高速バスで3~4時間の距離。
  • 英語案内：寺院の公式サイトに英語ページはあるが、食堂の英語メニューは不十分。写真メニューを指差して注文する方式。
  • ビーガン認証：なし。ただし寺院精進料理の伝統自体が五辛菜・肉類を排除。
  • ハラル：未認証。

2. 曹渓寺・奉恩寺(ソウル)の寺院精進料理

背景：ソウル都心の寺院。外国人のアクセスが良く、寺院精進料理の入門に適しています。

  • 曹渓寺近辺(鍾路区・雨情局路)：曹渓寺の隣で韓国仏教文化事業団が運営する精進料理専門店「鉢盂供養」——ソウルを代表する寺院精進料理レストラン。ランチコース₩25,000~45,000、ディナーコース₩45,000~80,000。英語メニューあり。予約推奨。2024ミシュランガイドソウルのビブグルマン掲載歴あり。
  • 奉恩寺近辺(江南区・三成洞)：奉恩寺自体の内部供養間は仏教行事の際に開放。奉恩寺のすぐ隣、COEX商圏に寺院精進料理の影響を受けたベジタリアンレストランが点在。

実用情報：

  • 交通：曹渓寺→地下鉄1号線鍾閣駅2番出口5分／奉恩寺→9号線奉恩寺駅1番出口5分。
  • 英語対応：鉢盂供養は英語メニュー・英語対応可能。奉恩寺内部の供養間は韓国語のみ。
  • ビーガン適合度：鉢盂供養★★★★★(五辛菜の調整リクエスト可能)。奉恩寺の供養★★★★。

3. 寺院精進料理クッキングクラス(英語進行)

背景：外国人向けの英語進行寺院精進料理クッキングクラスがソウルに定着しました。作って食べる体験まで含まれます。

  • 韓国寺刹飲食文化体験館(韓国仏教文化事業団運営)：ソウル鍾路区。英語進行の正規プログラム。1人₩70,000~120,000。2~3時間。参加者が自ら精進料理を2~3品調理した後、供養として食べます。事前予約必須。
  • Klook・KKday登録の精進料理クラス：「temple food cooking class Seoul」で検索すると複数業者が登録。レビュー確認後に選択。₩60,000~100,000程度。

実用情報：

  • 交通：韓国寺刹飲食文化体験館→地下鉄3号線安国駅6番出口徒歩5分。
  • 所要時間：2~3時間。午前10:00または午後14:00の回。
  • ビーガン適合度：★★★★★(授業全体が菜食・ビーガンベース)。

軸2：都心ビーガンクラスターを深掘り

4. 江南・清潭ビーガンクラスター

背景：江南区・瑞草区中心。ラグジュアリーなビーガンレストランとプレミアムビーガンカフェが密集します。外国人ビーガンマニアの1位ソウルエリア。

クラスターの特徴：

  • 清潭洞・狎鴎亭洞(Apgujeong-dong / 압구정동)：ファインダイニングスタイルのビーガンレストラン。トリュフ・有機食材を活用。1人₩50,000~100,000+。
  • 江南駅・新沙洞(Sinsa-dong / 신사동)：カジュアルなビーガンカフェ・ビーガンベーカリー。1人₩15,000~35,000。
  • HappyCowで「江南」または「Gangnam vegan」を検索→現在営業中の店リストを確認推奨(店の入れ替わりが早いため、店名を直接明示せずアプリ検索で)。

アクセス：

  • 地下鉄2号線江南駅、3号線狎鴎亭駅、7号線清潭駅。
  • カード決済100%。
  • 英語メニュー：ほとんどが英語・日本語併記。

5. 弘大・合井ビーガンカフェ

背景：弘大・合井一帯はMZ世代の外国人訪問客密度がソウルで最も高いエリアです。ビーガン・ベジタリアンカフェが独立系の小規模店として複数営業しています。英語対応可能なスタッフの比率が高く、Instagramアカウント運営が一般的です。

クラスターの特徴：

  • 弘大正門~上水駅区間：ビーガンデザート・ビーガンブランチカフェが密集。
  • 合井駅~望遠(Mangwon / 망원)駅：ローカルビーガン食堂・ベジタリアン日本料理・ビーガンメキシカンなどジャンルが多様。
  • メニュー価格：ビーガンブランチセット₩15,000~28,000／ビーガンケーキ+ドリンクセット₩12,000~20,000。
  • HappyCowで「Hongdae vegan」を検索→最新の営業店リスト。

アクセス：

  • 地下鉄2号線弘大入口駅、6号線上水駅・合井駅。
  • 週末昼は混雑。訪問は平日午前がおすすめ。
  • 英語：ほとんど対応可能、または英語メニュー表を用意。

6. 梨泰院ビーガンレストラン

背景：梨泰院はソウルで外国人比率が最も高い商圏です。ビーガン専門店が早くから定着し、英語100%対応の店舗が多数あります。国籍の多様性に比例してビーガンメニューのジャンルも幅広い(インド料理・メキシカン・アメリカンスタイルビーガンバーガー・韓国式ビーガンミックス)です。

クラスターの特徴：

  • 梨泰院路メインストリート~緑莎坪(Noksapyeong / 녹사평)駅区間：ビーガンインド料理(カレー・ダル)・ビーガンアメリカンバーガー。
  • 漢南洞(Hannam-dong / 한남동)方向：プレミアムビーガンレストラン。1人₩30,000~55,000。
  • 梨泰院駅裏路地(消防署通り)：カジュアルなビーガンカフェ・ビーガンベーカリー。1人₩10,000~20,000。
  • HappyCowで「Itaewon vegan」を検索→現在営業中の店をリアルタイム確認。

アクセス：

  • 地下鉄6号線梨泰院駅1番出口。
  • 英語対応：ほぼ100%。
  • ハラル併用の店舗も一部あり(ハラル表示を確認)。
  • ビーガン認証：店ごとの確認が必要(HappyCowのカテゴリフィルターを使用)。

軸3：K-foodビーガンを深掘り

7. ビビンバ・お粥・チヂミのベジタリアン版

ビビンバ：

  • 元の構成：ご飯+ナムル(ほうれん草・豆もやし・桔梗・ワラビ)+コチュジャン+卵+肉。
  • ビーガンリクエスト：「no egg, no meat」または「ベジタリアンビビンバ」とお願いする→肉・卵なしでナムルのみ。ナムル自体はビーガン。コチュジャンは一部製品にアミの塩辛が含まれる場合がある→寺院精進料理店のコチュジャンを使えば安全。
  • 価格：₩8,000~15,000。

お粥(juk / 죽)：

  • 野菜粥・キノコ粥・カボチャ粥はビーガンフレンドリー。アワビ粥・鶏粥は対象外。
  • ポンジュク(Bonjuk / 본죽)などのチェーン粥専門店に英語メニューあり。野菜粥₩7,000~12,000。

チヂミ(jeon / 전)：

  • パジョン(pajeon / 파전)・キムチジョン(kimchijeon / 김치전)は生地に卵を含まない場合がある。ただしキムチジョンは塩辛入りキムチの問題あり。
  • 寺院精進料理店のパジョン・椎茸チヂミはビーガン。₩8,000~16,000。

8. キンパ・ベジタリアンキムチチゲ

キンパ(gimbap / 김밥)：

  • 一般的なキンパ：卵・ハム・カニカマ・ツナを含む。
  • ベジタリアンキンパのリクエストまたは野菜キンパの選択：きゅうり・たくあん・にんじん・ほうれん草のみ。1本₩2,500~4,000。
  • コンビニ(CU・GS25・セブンイレブン)でも野菜キンパを販売。

ベジタリアンキムチチゲ：

  • 一般的なキムチチゲ：豚肉+塩辛入りキムチ。
  • ビーガン版：豆腐+ビーガンキムチ(塩辛なし)。寺院精進料理店・ベジタリアン専門店でのみ確実にビーガン。
  • 一般の韓食店でリクエストすると、肉は抜けても塩辛入りキムチ・カタクチイワシ出汁はそのまま残る場合が多い。

実用ポイント：コンビニの野菜キンパ+豆乳(植物性ミルク)の組み合わせは、予算重視のビーガン外国人にとって現実的な一食です。24時間営業、英語表記。

9. 寺院精進料理×K-foodフュージョン

背景：最近ソウルの一部レストランが、寺院精進料理の技法(五辛菜なし・発酵中心)を現代韓食に取り入れたメニューを提供しています。上級の外国人ビーガンフーディーの間で認知度が上がっています。

特徴：

  • 旬野菜コース：3~5種類のナムル料理+ビーガン味噌スープ+雑穀ご飯。₩25,000~50,000。
  • 発酵中心：醤油・味噌・コチュジャンの発酵ソースベースの調理。深い味わい。ビーガン適合。
  • こうした店はHappyCowの「vegan」+「Korean」の複合フィルターで探すか、Googleマップのレビューで「temple food」キーワードで探索。

12. シーズン — 釈迦誕生日(5月)BEST

釈迦誕生日(陰暦4月8日、陽暦4~5月)：

  • 全国の寺院で燃灯行事とともに、無料または安価な精進料理の振る舞いが行われる。
  • 曹渓寺・奉恩寺などソウルの大型寺院で、外国人も含む公開供養行事が行われる。
  • 燃灯会(yeondeunghoe / 연등회、UNESCO人類無形文化遺産2020登録)と連携。清渓川・鍾路一帯で提灯行列。

その他のシーズン：

  • 秋(9~11月)：寺院の紅葉シーズン。通度寺・海印寺訪問の最盛期。
  • 春(3~4月)：精進料理クラスの予約競争が激しい。
  • 通年：梨泰院・弘大・江南のビーガンクラスターはシーズンを問わず営業。

FAQ

Q1. 韓国のベジタリアン旅行は難しいと聞いたが、実際は？

梨泰院・弘大・江南のいずれかに宿を取れば、思ったより簡単です。HappyCow基準でソウル登録のビーガン・ベジタリアンフレンドリー店は300店以上。地方は難しいですが、精進料理専門店中心に動けば解決します。

Q2. 韓国のキムチはビーガンか？

一般的なキムチはアミの塩辛・カタクチイワシの魚醤が入るためビーガンではありません。ビーガンキムチ(塩辛なし)はベジタリアン専門店・精進料理店・一部スーパー(ビーガンラベル確認)で購入できます。

Q3. 精進料理と一般的な菜食の違いは？

精進料理は五辛菜(ネギ・ニンニク・ニラ・ラッキョウ・アサフェティダ)を使いません。一般的な菜食ではこの5種類の野菜を使うことが多いです。五辛菜アレルギー・宗教上の理由で避ける必要がある場合は、精進料理専門店を選びます。

Q4. ハラルレストランとビーガンレストランは重なるか？

梨泰院にはハラル認証のビーガンメニューを一緒に提供する店が一部あります。HappyCow+「Halal」の複合検索で探すか、店に直接ハラルかどうか確認します。完全な保証が必要な場合はハラル認証表示を目視で確認します。

Q5. ビーガンツアーの予算はどのくらい必要か？

予算型：1日₩20,000~40,000(コンビニキンパ・ベジタリアンキンパ・ビーガンカフェ1回)。中間型：1日₩60,000~100,000(ビーガンレストラン2回)。プレミアム型：1日₩150,000+(ファインダイニングビーガン1回+クッキングクラス)。
