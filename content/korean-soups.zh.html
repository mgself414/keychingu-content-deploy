韩国汤类美食 deep dive — 外国人韩食正宗12选

ISSUE 03 · #200 · 2026-05-19

🎯 为何选择韩国汤类美食指南

韩国餐桌的核心是汤类美食 (Guk·Tang·Jjigae / 국·탕·찌개) — 泡菜汤 (Kimchi Jjigae / 김치찌개)、大酱汤 (Doenjang Jjigae / 된장찌개)、排骨汤 (Galbitang / 갈비탕)、参鸡汤 (Samgyetang / 삼계탕)、雪浓汤 (Seolleongtang / 설렁탕)、部队锅 (Budae Jjigae / 부대찌개)、解酒汤 (Haejangguk / 해장국)、辣鱼汤 (Maeuntang / 매운탕) 是韩国第一的汤类美食。它们是外国人韩食深度体验的首选 (外国视频博主除了烤肉外最常挑战的)。

继KeyChinGu [#14 韩国美食必体验](14_korean_food_must_try.md) 和 [#62 韩国鸡肉料理](62_korean_chicken_dishes.md) 之后，本次带来韩国汤类美食全套 deep dive。

⚠ 外国人常犯的3个错误

1. “辣味 = 泡菜汤·部队锅”: 除了辣味，大酱汤 (Doenjang Jjigae / 된장찌개)、排骨汤 (Galbitang / 갈비탕)、雪浓汤 (Seolleongtang / 설렁탕)、参鸡汤 (Samgyetang / 삼계탕) 等清淡的汤类也是韩国第一。

2. “参鸡汤 = 冬季食物”: 参鸡汤是夏季滋补品 (Boyangsik / 보양식) 首选 (韩国三伏天 (Sambok / 삼복) — 初伏、中伏、末伏，通常在7月至8月)。

3. “部队锅 = 韩国传统”: 部队锅 (Budae Jjigae / 부대찌개) 是韩国战争后 (20世纪50年代) 由美军基地食物与韩式烹饪结合演变而来。东豆川 (Dongducheon / 동두천) 和议政府 (Uijeongbu / 의정부) 是其发源地。

① 泡菜汤 (Kimchi Stew) ★★

  • 特色: 韩国所有韩餐厅 + 韩式定食 (Jeongsik / 정식)
  • 价格: 7,000~12,000韩元 (₩7,000~12,000)
  • 吃法: 泡菜 (Kimchi / 김치) + 猪肉·金枪鱼 + 豆腐 + 米饭 + 腌萝卜 (Danmuji / 단무지)
  • 外国人需求: K-drama 中出镜率第一的美食
  • 原因: 韩国第一家常菜。

② 大酱汤 (Doenjang Stew)

  • 特色: 传统韩餐厅
  • 价格: 7,000~12,000韩元
  • 吃法: 大酱 (Doenjang / 된장) + 豆腐 + 蔬菜 + 米饭
  • 原因: 韩国传统发酵豆酱美食。

③ 排骨汤 (Galbitang)

  • 特色: 韩国排骨店 + 韩式定食 (Jeongsik / 정식)
  • 价格: 12,000~18,000韩元
  • 吃法: 排骨 + 萝卜 + 面条 + 泡菜 (Kimchi / 김치)
  • 原因: 韩国传统排骨汤。

④ 参鸡汤 (Samgyetang) ★ 夏季滋补品首选

  • 特色: 土俗村参鸡汤 (Tosokchon Samgyetang / 토속촌삼계탕) (光化门 (Gwanghwamun / 광화문)) · 高丽参鸡汤 (Goryeo Samgyetang / 고려삼계탕) (北仓洞 (Bukchang-dong / 북창동))
  • 价格: 18,000~25,000韩元 (约 $13 / 约 95 RMB / 约 1,900 JPY)
  • 吃法: 一整只鸡 + 人参·糯米·红枣 + 大蒜
  • 外国人需求: BBC·CNN 常客 + 7月至8月 (July-August) 首选
  • 原因: 韩国第一夏季滋补品 (Boyangsik / 보양식)。外国人韩食深度体验首选。

⑤ 雪浓汤 (Seolleongtang) ★ 韩国第一牛骨汤

  • 特色: 里门雪浓汤 (Imun Seollongtang / 이문설농탕) (钟路 (Jongno / 종로), 韩国第一老字号 (Nopo / 노포) 1904年)
  • 价格: 12,000~18,000韩元
  • 吃法: 奶白色牛骨汤 + 面条·米饭 + 自行添加葱花·盐·胡椒
  • 原因: 韩国第一牛骨汤老字号 (Nopo / 노포) (里门雪浓汤 (Imun Seollongtang / 이문설농탕) 是韩国历史最悠久的餐厅之一)。

⑥ 部队锅 (Budae Jjigae, Army Stew) ★★★

  • 特色: 农夫部队锅 (Nolbu Budae Jjigae / 놀부 부대찌개) · 东豆川 (Dongducheon / 동두천) · 议政府 (Uijeongbu / 의정부) 传统
  • 价格: 每人12,000~18,000韩元
  • 吃法: 火腿·香肠·芝士·拉面·泡菜 (Kimchi / 김치) · 豆子 + 辣汤
  • 外国人需求: K-drama 中出镜率第一 + 外国人熟悉的火腿·芝士组合
  • 原因: 韩国战争后 (20世纪50年代) 美军基地食物 + 韩式烹饪 → 韩国传统。

⑦ 解酒汤 (Haejangguk) (#198 挑战美食 참조)

请参考 [#198 外国人挑战美食 TOP 10](198_challenge_food.md)。

⑧ 辣鱼汤 (Maeuntang) ★★★★

  • 特色: 鹭梁津水产市场 (Noryangjin Sosan Sijang / 노량진수산시장) ([#181 铜雀·鹭梁津](181_dongjak_noryangjin.md)) 现做辣鱼汤
  • 价格: 每人15,000~30,000韩元
  • 吃法: 现做生鱼片 (Hoe / 회) + 辣鱼汤 (鳕鱼·鲻鱼·安康鱼·石斑鱼)
  • 原因: 韩国传统现做生鱼片 (Hoe / 회) + 辣汤。鹭梁津水产市场 (Noryangjin Sosan Sijang / 노량진수산시장) 第一。

⑨ 嫩豆腐汤 (Sundubu Jjigae) ★★

  • 特色: 北仓洞嫩豆腐 (Bukchang-dong Sundubu / 북창동 순두부) · 传统韩餐厅
  • 价格: 9,000~13,000韩元
  • 吃法: 嫩豆腐 (Sundubu / 순두부) + 辣酱 + 鸡蛋 + 米饭
  • 原因: 韩国传统豆腐美食 ([#175 麻谷·磨石坊姐妹店](175_magok_maetdolroman_sisters.md))。

⑩ 辣牛肉汤 (Yukgaejang) ★★★

  • 特色: 韩国所有韩餐厅
  • 价格: 10,000~14,000韩元
  • 吃法: 辣牛肉汤 + 蕨菜·大葱·辣椒油
  • 原因: 韩国第一辣牛肉汤。外国人挑战辣味的首选。

⑪ 年糕汤 (Tteokguk)

  • 特色: 春节 (Seollal / 설날) 家常菜 + 传统韩餐厅
  • 价格: 9,000~13,000韩元
  • 吃法: 年糕 + 牛肉汤 + 紫菜·鸡蛋
  • 原因: 韩国春节 (1月1日 (阳历) 和农历新年 (Lunar New Year)) 第一美食 — 吃一碗年糕汤就长一岁。

⑫ 豆芽汤饭 (Kongnamul Gukbap) ★ 全州式传统

  • 特色: 全州 (Jeonju / 전주) 式豆芽汤饭 + 钟路 (Jongno / 종로) 清进洞 (Cheongjin-dong / 청진동) 24小时
  • 价格: 7,000~10,000韩元
  • 吃法: 豆芽 + 鸡蛋 + 米饭 + 紫菜
  • 外国人需求: 24小时营业 + 外国人解酒首选
  • 原因: 全州 (Jeonju / 전ju) 式传统 + 24小时解酒。

⚙ 常见问题6个

1. 参鸡汤 (Samgyetang / 삼계탕) 对外国人友好的餐厅: 土俗村参鸡汤 (Tosokchon Samgyetang / 토속촌삼계탕) (光化门 (Gwanghwamun / 광화문))、高丽参鸡汤 (Goryeo Samgyetang / 고려삼계탕) (北仓洞 (Bukchang-dong / 북창동)) — 英文菜单 + 外国视频博主常去。

2. 雪浓汤 (Seolleongtang / 설렁탕) 老字号 (Nopo / 노포): 里门雪浓汤 (Imun Seollongtang / 이문설농탕) (1904年) — 韩国历史最悠久的老字号 (Nopo / 노포) 之一。

3. 部队锅 (Budae Jjigae / 부대찌개) 发源地: 东豆川 (Dongducheon / 동두천) · 议政府 (Uijeongbu / 의정부) (20世纪50年代美军基地 + 韩式)。

4. 辣鱼汤 (Maeuntang / 매운탕) 辣度: 鹭梁津水产市场 (Noryangjin Sosan Sijang / 노량진수산시장) 的餐厅可以调节辣度。

5. 年糕汤 (Tteokguk / 떡국) 外国人可以吃吗?: 1月春节 (Seollal / 설날) + 节日餐厅 — 外国人可自由入内。

6. 豆芽汤饭 (Kongnamul Gukbap / 콩나물국밥) 24小时营业吗?: 清进洞 (Cheongjin-dong / 청진동) ([#198 解酒汤](198_haejangguk.md)) + 全州 (Jeonju / 전주) 传统餐厅。
