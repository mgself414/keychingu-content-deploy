🎯 为什么"首尔艺术"成为焦点元指南

来韩外国游客中,艺术・博物馆动机的比重持续上升——尤其是欧美自由行达人和日本达人。韩国艺术=国立现代美术馆3馆 — 首尔・果川・清州・德寿宫(Deoksugung / 덕수궁)+ Leeum美术馆(Leeum / 리움미술관)+ 湖岩美术馆(Hoam / 호암미술관)+ 画廊集群 — 清潭(Cheongdam / 청담)・三清洞(Samcheong-dong / 삼청동)・仁寺洞(Insa-dong / 인사동)+ 联合国教科文组织韩国艺术 + K-art趋势。外国游客英文导览齐全,且多数免费入场。

本指南汇总艺术四轴12大招牌 + 1周完整体验路线。

⚠ 艺术三大误区

1. "美术馆=只有景福宫" — 未认知四大国立集群：只认识MMCA首尔馆。实际上MMCA4馆(首尔・果川・清州・德寿宫) + 国立中央博物馆 = 韩国艺术完整体验矩阵。

2. "私立=只有Leeum" — 未认知湖岩・爱茉莉达人路线：只认识Leeum。实际上Leeum(汉南) + 湖岩(龙仁) + 爱茉莉太平洋(龙山)三大私立集群 + 英文导览达人路线。

3. "画廊=只有清潭" — 未认知三清洞・仁寺洞的差异化：只认识清潭的奢华感。实际上三清洞(50+韩屋画廊) + 仁寺洞(传统・韩纸) + 清潭(奢华・现代)三大差异化集群。
