⚠ 외국인 자주 실수 5가지

1. "공예 = 인사동만": 전통공예 = 이천 (도자기 #1) + 전주 (한지 #1) + 통영 (나전) + 인사동 (#12 매듭·한지) + 외국인 정통 매니아 풀세트.

2. "도자기 = 비쌈": 도자기 = 이천·여주·강진 마을 + 외국인 영어 OK 워크숍 (15~30만원) + 박물관 무료 관람 + #143·#377 통합.

3. "한지 = 종이만": 한지 = 전주 한지 마을 + 등·부채·소품·#12 인사동 + 1000년 보존 UNESCO + 외국인 매니아 1번지.

4. "공예 = 영어 안됨": 영어 OK = 외국인 전통공예 KTO·Klook 패키지 + 인사동·이천·전주 워크숍 + 박물관 영어 도슨트 + #377·#178 통합.

5. "공예 = 박물관만": 공예 = 박물관 (#377·#514) + 마을 워크숍 (이천·전주·통영) + 외국인 1박2일 + #506 명절 체험 + 외국인 매니아 풀세트.
