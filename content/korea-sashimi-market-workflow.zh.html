韩国生鱼片 (Hoe) 点餐·市场·生鱼片店·辣鱼汤 (Mae-untang) 流程 — 从札嘎其 (Jagalchi) 到鹭梁津 (Noryangjin)

> 副标题: 外国游客专用5步流程 + 市场·生鱼片店·辣鱼汤 (Mae-untang) 套餐·英文对话

ISSUE 03 · #865 · 2026-06-09

🎯 为什么需要韩国生鱼片 (Hoe) 流程指南

即使了解 [#864 6种生鱼片综合指南](864_korean_hoe_6_types_matrix.md) — 点餐·市场·生鱼片店·辣鱼汤 (Mae-untang) 仍是独立环节。韩国生鱼片 (Hoe) 分为 (a) 市场传统 (鹭梁津 (Noryangjin / 노량진)·札嘎其 (Jagalchi / 자갈치)·统营 (Tongyeong / 통영)·苏莱浦口 (Soraepogu / 소래포구) 现杀活鱼) (b) 生鱼片店 (江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대)·梨泰院 (Itaewon / 이태원) 传统套餐) (c) 金枪鱼·三文鱼无限续 (MZ高性价比) (d) 韩定食 (Hanjeongsik / 한정식) (韩国传统套餐) 生鱼片套餐 (传统)。外国游客常遇到的问题包括 (1) 不知道市场1楼 (生鱼片摊位) 和2楼 (餐厅) 的区别 (2) 不知道韩式辣酱 (Chojang / 초장) 和芥末 (Wasabi / 와사bi) 的食用礼仪 (3) 不知道辣鱼汤 (Mae-untang / 매운탕) 是最后一道菜 (4) 不知道活鱼价格可以协商。本指南将提供5步流程 + 市场·生鱼片店 + 英文对话。

★ 5步流程一览

步骤 操作 时间 外国游客核心要点
1️⃣ 选择渠道 市场 / 生鱼片店 / 无限续 / 韩定食 (Hanjeongsik / 한정식) 即时 性价比·传统·MZ·奢华目的
2️⃣ 点餐 活鱼 1公斤 / 1份 (2~3人份) / 1人份 5~15分钟 市场 = 按公斤计价
3️⃣ 上菜·摆盘 生鱼片 + 韩式辣酱 (Chojang / 초장)·包饭蔬菜·蒜蓉·辣鱼汤 (Mae-untang / 매운탕) (可选) 10~20分钟 韩式辣酱 (Chojang / 초장)·包饭礼仪
4️⃣ 品尝·搭配 韩式辣酱 (Chojang / 초장) + 包饭 + 烧酒 (Soju / 소주)·啤酒 30~90分钟 辣鱼汤 (Mae-untang / 매운탕) = 最后一道菜
5️⃣ 结账 接受刷卡 / 市场 = 部分接受现金 / 无小费 1~5分钟 市场 = 价格可协商

> 总耗时: 市场 = 1~2小时 / 生鱼片店 = 1.5~3小时 / 无限续 = 1~2小时 / 韩定食 (Hanjeongsik / 한정식) = 2~3小时

🐟 不同渠道的流程

Type A — 市场 (鹭梁津 (Noryangjin / 노량진)·札嘎其 (Jagalchi / 자갈치)·统营 (Tongyeong / 통영)·苏莱浦口 (Soraepogu / 소래포구)·九龙浦 (Guryongpo / 구룡포))

  • 特色: 现杀活鱼传统·高性价比·1楼生鱼片摊位 + 2楼餐厅
  • 营业时间: 各市场不同 (鹭梁津 (Noryangjin / 노량진) = 凌晨批发·一般营业 09:00~22:00)
  • 价格: 活鱼 1公斤 = ₩20,000~₩60,000 (约 $15~$45 / 100~300 RMB / 2,000~6,000 JPY) + 餐厅服务费 ₩5,000~₩15,000/人
  • 菜单: 活鱼 1公斤 (如比目鱼 (Gwang-eo / 광어)·鰤鱼 (Bang-eo / 방어)·鲷鱼 (Domi / 도미)·斑鰶鱼 (Jeon-eo / 전어)) + 包饭蔬菜·辣鱼汤 (Mae-untang / 매운탕)
  • 外国游客友好度: ★★★★★ (英文菜单·对游客友好)
  • 鹭梁津 (Noryangjin / 노량진): ([#587 鹭梁津水产市场凌晨批发](587_noryangjin_fish_market_wholesale.md)) — 凌晨批发·普通餐厅
  • 札嘎其 (Jagalchi / 자갈치): ([#590 札嘎其市场深度探索](590_jagalchi_market_deep_dive.md)) — 釜山 (Busan / 부산) 第一·鰤鱼 (Bang-eo / 방어) 传统

Type B — 生鱼片店 (江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대)·梨泰院 (Itaewon / 이태원))

  • 特色: 传统套餐·中等价位
  • 营业时间: 17:00~24:00
  • 价格: ₩50,000~₩150,000/人 (传统套餐)
  • 菜单: 生鱼片 + 韩式辣酱 (Chojang / 초장) + 包饭蔬菜 + 辣鱼汤 (Mae-untang / 매운탕) + 酒水
  • 外国游客友好度: ★★★★ (英文菜单)

Type C — 金枪鱼·三文鱼无限续 (MZ·高性价比)

  • 特色: MZ潮流·性价比第一·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강nam)·新村 (Sinchon / 신촌)
  • 营业时间: 11:30~24:00
  • 价格: ₩25,000~₩50,000/人
  • 菜单: 金枪鱼腩 (toro)·红肉 / 三文鱼生鱼片 + 包饭蔬菜·乌冬面·辣鱼汤 (Mae-untang / 매운탕)
  • 外国游客友好度: ★★★★★ (全球MZ首选)

Type D — 韩定食 (Hanjeongsik / 한정식) 生鱼片套餐 (传统)

  • 特色: 韩定食 (Hanjeongsik / 한정식) 6道菜中的1~2道 ([#837 韩定食区域指南](837_hanjeongsik_cluster_guide.md))·传统奢华
  • 营业时间: 11:30~22:00
  • 价格: 韩定食 (Hanjeongsik / 한정식) 套餐 ₩40,000~₩150,000
  • 菜单: 生鱼片 (鲷鱼 (Domi / 도미)·比目鱼 (Gwang-eo / 광어)) + 套餐
  • 外国游客友好度: ★★★★

🌶 韩式辣酱 (Chojang) vs 芥末 (Wasabi)·包饭·辣鱼汤 (Mae-untang) 礼仪

韩式辣酱 (Chojang / 초장) (韩式辣酱)

  • 成分: 韩式辣酱 (Gochujang / 고추장) (一种发酵辣椒酱) + 醋 + 糖
  • 用途: 活鱼传统生鱼片·韩式吃法
  • 外国游客: "Spicy red sauce"·香辣·甜口

芥末 (Wasabi / 와사비)

  • 用途: 金枪鱼·三文鱼·熟成生鱼片·日式吃法
  • 外国游客: "Japanese horseradish"·清淡

包饭吃法 (Ssam Ssa Meokgi / 쌈 싸 먹기) (活鱼生鱼片传统)

1. 将包饭蔬菜 (如生菜 (Sangchu / 상추)·紫苏叶 (Kkaennip / 깻잎)·白菜 (Baechu / 배추)) 放在手掌上

2. 放上生鱼片 + 蒜蓉 + 韩式辣酱 (Chojang / 초장) + 大酱 (Doenjang / 된장) (一种发酵豆酱) (可选)

3. 用手包好，一口吃掉

4. 闭嘴咀嚼 (韩国礼仪)

辣鱼汤 (Mae-untang / 매운탕) 最后一道菜

  • 顺序: 生鱼片 → 辣鱼汤 (Mae-untang / 매운탕) (最后)
  • 食材: 生鱼片处理后的边角料 + 辣味调料 + 豆腐·豆芽
  • 外国游客: "Spicy fish stew finale"·传统

🌶 外国游客英文对话范例

  • "活比目鱼1公斤" = "1kg of live olive flounder, please"
  • "鰤鱼，冬季特色" = "Yellowtail, the winter specialty"
  • "辣鱼汤 (Mae-untang / 매운탕) 作为最后一道菜" = "Spicy fish stew finale, please"
  • "请少放辣 (指韩式辣酱 (Chojang / 초장))" = "Less spicy, please (초장)"
  • "请分摊账单" = "Split the bill, please"
  • "可以刷卡吗？" = "Card accepted?"

⚠ 外国游客常犯的7个错误

1. “市场1楼 = 用餐”: 市场1楼 = 生鱼片摊位 (raw fish counter) / 2楼 = 餐厅 (eating area) — 分开。

2. “活鱼 = 昂贵”: 市场活鱼 1公斤 = ₩20,000~₩60,000 (性价比第一)。

3. “韩式辣酱 (Chojang / 초장) = 芥末 (Wasabi / 와사비)”: 韩式辣酱 (Chojang / 초장) = 韩式辣酱 (Gochujang / 고추장) (韩国传统) / 芥末 (Wasabi / 와사비) = 日式 — 不同酱料。

4. “辣鱼汤 (Mae-untang / 매운탕) = 独立用餐”: 辣鱼汤 (Mae-untang / 매운탕) = 生鱼片最后一道菜 (生鱼片 → 辣鱼汤 (Mae-untang / 매운탕) 顺序)。

5. “价格不能协商”: 市场活鱼 = 价格可部分协商 (按公斤计价·根据新鲜度)。

6. “孕妇可以吃”: 孕妇 = 生鱼片不宜食用 (CDC建议) — 煮熟的辣鱼汤 (Mae-untang / 매운탕) 可以。

7. “无限续 = 活鱼”: 无限续 = 金枪鱼·三文鱼熟成·冷冻 (非活鱼)。

⚙ 8个常见问题

1. 第一次吃生鱼片 = 哪个渠道: 金枪鱼·三文鱼无限续 (MZ·高性价比) → 市场比目鱼 (Gwang-eo / 광어) (传统)。

2. Instagram·Vlog: 鹭梁津 (Noryangjin / 노량진) 凌晨·札嘎其 (Jagalchi / 자갈치) 鰤鱼 (Bang-eo / 방어)·金枪鱼腩 (toro) Instagram。

3. MZ潮流: 三文鱼·金枪鱼无限续·MZ生鱼片店。

4. 烧酒 (Soju / 소주) 爱好者: 生鱼片 + 辣鱼汤 (Mae-untang / 매운탕) + 烧酒 (Soju / 소주) (韩国传统蒸馏酒) = 传统搭配。

5. 市场营业时间: 鹭梁津 (Noryangjin / 노량진) = 凌晨批发·一般营业 09:00~22:00。

6. 过敏·怀孕: 参考 [#864 6种生鱼片综合指南](864_korean_hoe_6_types_matrix.md) (孕妇不宜食用生鱼片)。

7. 结账·小费: 市场 = 现金·刷卡 / 生鱼片店 = 接受刷卡 / 无小费。

8. 增值税退税: 餐饮一般不退税。

⚠ 医疗·安全·饮食免责声明

生鱼片 = 未煮熟的鱼肉·请注意食物中毒。孕妇 = 不宜食用生鱼片 (CDC建议)·辣鱼汤 (Mae-untang / 매운탕) = 可以。儿童 = 有限制 (建议5岁以上食用煮熟的食物)。过敏 (鱼类·甲壳类·酱油中的麸质) 请提前告知。如怀疑食物中毒 ☎ 1339 (医疗服务, 英文)。本指南为一般信息, 非医疗建议。

饮食限制备选方案:

  • 清真 (Halal)·犹太洁食 (Kosher): 6种生鱼片均为鱼类 = 清真 (Halal) 可食 / 犹太洁食 (Kosher) 需有鳞片+鱼鳍 = 可食。
  • 素食·纯素: 生鱼片 = 非素食 / 素食 = 拌饭 (Bibimbap / 비빔밥) (韩式混合米饭)·寺庙饮食。
  • 无麸质: 生鱼片本身可以 / 酱油·韩式辣酱 (Chojang / 초장) = 部分含麸质 (可用Tamari替代)。

  • 人均费用 (截至2026年6月):
  • 市场生鱼片 1公斤 = ₩20,000~₩60,000 + 餐厅服务费 ₩5,000~₩15,000/人
  • 金枪鱼·三文鱼无限续 = ₩25,000~₩50,000/人
  • 生鱼片店传统套餐 = ₩50,000~₩150,000/人
  • 金枪鱼传统套餐 = ₩80,000~₩200,000/人
  • 韩定食 (Hanjeongsik / 한정식) 生鱼片套餐 = ₩40,000~₩150,000
  • 结账·小费: 市场 = 现金·刷卡 / 生鱼片店 = 接受刷卡 / 无小费
  • 紧急情况: ☎ 1339 (医疗服务, 英文) / ☎ 1330 (旅游翻译)
