🎯 为什么要看这份韩国餐后收尾饮品全指南

外国游客对韩国饮品最大的痛点："我只知道配餐喝的饮料和酒，完全不知道饭后该喝什么。" 实际上韩国餐后收尾饮品 = 韩定食最后一道 + 家常菜后的甜品饮 + 醒酒招牌饮。英文里都统称"Korean traditional beverage"，但甜米露 (Sik-hye / 식혜，香甜·韩定食收尾No.1)、鱼肉发酵饭 (Sik-hae / 식해，鱼肉发酵·江原道 (Gangwon / 강원) 正宗)、水正果 (Sujeong-gwa / 수정과，肉桂·姜·柿饼)、东东酒 (Dong-dong-ju / 동동주，佐餐酒也当饮品喝)、梅子茶 (Maesil-cha / 매실차，醒酒·助消化)、醒酒汤 (Haejang-su / 해장수，豆芽醒酒系列) 各自扮演不同角色、拥有不同粉丝群。与传统饮品系列 (#840) 的区别在于 = "饭后收尾饮品"这个角度(韩定食·家常菜最后一道 + 隔天醒酒)。外国游客通常不知道：(a) 甜米露和鱼肉发酵饭完全不是一回事；(b) 韩定食有固定的收尾饮品；(c) 东东酒其实是酒精饮品，看起来却像普通饮料；(d) 醒酒汤属于醒酒系列的一部分。本指南整理6种全指南、收尾饮品与醒酒饮品。

🍹 6种深度解析

🍚 甜米露 (Sik-hye / 식혜) — 韩定食收尾No.1

  • 招牌特点：韩定食收尾No.1·香甜·传统
  • 食材：米饭 + 麦芽(엿기름) + 糖(饭粒漂浮其中)
  • 外国游客亲和度：★★★★★(入门首选，香甜易接受)
  • 推荐去处：
  • 韩定食餐厅 (#837) — 收尾No.1
  • 新罗酒店罗宴 (La Yeon / 라연)、三清阁 (Samcheonggak / 삼청각)、仁寺洞 (Insadong / 인사동) — 正宗
  • 超市·便利店(편의점，24小时营业的连锁商店) — 罐装·瓶装
  • 温度：冰凉(加冰)
  • 价格：韩定食内含 / 超市 = 2,000~5,000韩元(约11~26元人民币)/罐

🐟 鱼肉发酵饭 (Sik-hae / 식해) — 江原道正宗

  • 招牌特点：江原道 (Gangwon / 강원) 正宗·鱼肉发酵 + 米饭·粉丝向食物(名字虽像甜米露，实则完全不同)
  • 食材：明太鱼·多线鱼·比目鱼 + 米·辣椒粉·萝卜(发酵)
  • 外国游客亲和度：★★★(发酵味浓，适合发酵爱好者)
  • 推荐去处：江原道老字号 (nopo / 노포，经营30年以上的传统老店)、市场
  • 时令：四季皆有·江原道经典
  • 价格：市场 = 10,000~25,000韩元/袋(约53~132元人民币)
  • 注意：甜米露 = 香甜饮品(米饭+麦芽) / 鱼肉发酵饭 = 发酵小菜(江原道粉丝最爱) —— 名字相近，实际是完全不同的食物

🍂 水正果 (Sujeong-gwa / 수정과) — 冬季经典

  • 招牌特点：冬季经典·肉桂姜汁 + 柿饼 + 松子
  • 食材：肉桂·姜 + 柿饼 + 松子(装饰)
  • 外国游客亲和度：★★★★(冬季经典，微辣中带甜)
  • 推荐去处：韩定食全套、传统茶馆、MZ (MZ，韩国的年轻潮流世代) 咖啡厅、超市
  • 温度：冰凉(夏季)·温热(冬季)
  • 时令：冬季No.1·全年供应
  • 价格：韩定食内含 / 超市 = 3,000~7,000韩元(约16~37元人民币)/罐

🍶 东东酒 (Dong-dong-ju / 동동주) — 传统酒·佐餐酒

  • 招牌特点：佐餐酒·传统马格利酒类·浑浊发酵酒
  • 食材：米 + 酒曲(누룩，发酵引子)，发酵而成(米粒漂浮，"东东"意为"漂浮")
  • 外国游客亲和度：★★★★(搭上MZ马格利酒 (makgeolli / 막걸리，韩式浊米酒) 热潮·传统)
  • 推荐去处：韩定食餐厅、传统酒馆、MZ马格利酒聚集区
  • 时令：四季皆有·佐餐酒
  • 酒精度：6~8%
  • 价格：5,000~15,000韩元/瓶(约26~79元人民币)

🌿 梅子茶 (Maesil-cha / 매실차) — 醒酒·助消化

  • 招牌特点：醒酒·助消化·韩国传统草本饮品
  • 食材：梅子糖浆 + 水(温热·冰凉)
  • 外国游客亲和度：★★★★(助消化·醒酒，全球通用需求)
  • 推荐去处：家常菜、传统茶馆、超市、便利店
  • 温度：温热(助消化)·冰凉(夏季)
  • 时令：四季皆宜
  • 价格：家常菜内含 / 超市 = 2,000~5,000韩元(约11~26元人民币)

🍵 醒酒汤·豆芽汤 (Haejang-su / 해장수) — 隔天醒酒首选

  • 招牌特点：跨界醒酒系列·隔天饮用·豆芽汤
  • 食材：豆芽 + 萝卜·葱·辣椒·酱油
  • 外国游客亲和度：★★★(醒酒爱好者最爱)
  • 推荐去处：24小时本粥 (Bonjuk / 본죽) 连锁、汤饭店、醒酒系列
  • 时令：饮酒隔天清晨·醒酒
  • 价格：家常菜·汤饭店 = 8,000~15,000韩元(约42~79元人民币)
  • 详见：国饭 (gukbap / 국밥) 系列 (#807)

🍽 韩定食收尾 + 家常甜品 + 醒酒招牌

韩定食收尾 (#837)

  • 6道全套的最后一道 = 甜米露 + 水正果(甜品阶段)
  • 新罗酒店罗宴 (La Yeon / 라연)、三清阁 (Samcheonggak / 삼청각)、仁寺洞 (Insadong / 인사동) — 正宗
  • 免费内含

家常甜品饮

  • 甜米露·梅子茶 = 家常菜后免费甜品饮
  • 白饭套餐店 (baekban-jip / 백반집，韩式家常套餐店)、MZ韩餐厅 — 高性价比

隔天醒酒系列

  • 梅子茶 + 醒酒汤 = 隔天醒酒正宗组合
  • 24小时本粥、汤饭店 — 醒酒爱好者聚集地

传统酒馆·MZ马格利酒热潮

  • 东东酒·马格利酒 (makgeolli / 막걸리) = 传统酒系列 (#840)
  • 广藏市场 (Gwangjang Market / 광장시장)、仁寺洞传统酒馆 — 正宗

⚠ 外国游客常见的5个误区

1. "甜米露 = 鱼肉发酵饭"：甜米露 = 香甜饮品(米饭+麦芽) / 鱼肉发酵饭 = 发酵小菜(江原道正宗) —— 完全不同的食物。

2. "东东酒 = 普通饮料"：东东酒 = 6~8%酒精度的酒(佐餐酒)。

3. "水正果 = 茶"：水正果 = 肉桂姜汁柿饼饮(不是茶，是水果饮品)。

4. "韩定食饮品要另收费"：韩定食收尾饮品 = 免费内含(甜米露·水正果)。

5. "梅子茶 = 普通茶饮"：梅子茶 = 草本饮品(助消化·醒酒爱好者最爱)。

⚙ 常见问题8则

1. 外国游客入门首选：甜米露(韩定食收尾) + 水正果(冬季) → 梅子茶(助消化)。

2. 拍照·vlog推荐：韩定食收尾No.1甜米露、点缀柿饼的水正果、传统东东酒。

3. MZ潮流：MZ咖啡厅的甜米露创意饮、东东酒、梅子气泡饮。

4. 助消化·醒酒：梅子茶 + 醒酒汤。

5. 过敏提醒：请提前告知坚果(松子)过敏情况。

6. 酒精：东东酒 = 6~8%——孕妇、司机不宜饮用。

7. 付款·小费：韩定食·家常菜 = 可刷卡 / 无需小费。

8. 退税：餐饮一般不在退税范围内。

⚠ 医疗·安全·饮食注意事项

餐后收尾饮品属于日常食品。孕妇、儿童 = 甜米露、水正果、梅子茶没问题(东东酒 = 不可以，含酒精)。请提前告知过敏情况(坚果、姜)。如怀疑食物中毒，请拨打 ☎ 1339(医疗热线，提供英语服务)。本指南仅为一般信息，不构成医疗建议。

饮食限制应对方案：

  • 清真·犹太洁食：甜米露、水正果、梅子茶、醒酒汤、鱼肉发酵饭(视地区而定) = 没问题 / 东东酒 = 不可以，含酒精。
  • 素食·纯素：6种中5种 = 没问题 / 鱼肉发酵饭 = 鱼肉发酵(非素食)。
  • 无麸质：6种都没问题(若含酱油可用溜酱油(Tamari)替代)。
