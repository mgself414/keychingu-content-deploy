🎯 为什么是韩国烤肉全攻略

韩国烤肉是外国人体验韩食的首选 (外国Vlog·韩剧常客)。韩牛 (Hanwoo / 한우) (牛肉·顶级1++等级)·五花肉 (Samgyeopsal / 삼겹살)·调味排骨 (Yangnyeom Galbi / 양념갈bi)·羊肉串 (Yangkkochi / 양꼬치)·内脏烧烤 (Naejang BBQ / 내장 BBQ)是韩国烤肉的五大支柱。除了#130 首尔烤肉店 (Gogitjip / 고깃집)·#62 韩国鸡肉料理 (Dak-yori / 닭요리)之外，本篇将深度探索韩国烤肉全系列。

KeyChinGu (키친구) #143 江南韩食 (Gangnam Hansik / 강남 한식)·#178 广津 (Gwangjin / 광진) (建大烧烤)·#183 江东 (Gangdong / 강동) (Daram 韩食烧烤)·#188 麻浦 (Mapo / 마포)等韩国烤肉12精选综合指南。外国人韩食体验首选。

⚠ 外国人常犯的3个错误

1. “韩国烤肉 = 只有五花肉 (Samgyeopsal / 삼겹살)”: 韩国烤肉有五大支柱 (韩牛 (Hanwoo / 한우)·五花肉 (Samgyeopsal / 삼겹살)·调味排骨 (Yangnyeom Galbi / 양념갈비)·羊肉串 (Yangkkochi / 양꼬치)·内脏烧烤 (Naejang BBQ / 내장 BBQ)) — 挑战韩牛1++等级、五花肉 (Samgyeopsal / 삼겹살)、LA排骨 (LA Galbi / LA갈비)、大肠 (Makchang / 막창)、肥肠 (Gopchang / 곱창)、羊肉串 (Yangkkochi / 양꼬치) 全系列。

2. “韩牛 (Hanwoo / 한우) 价格太贵”: 韩牛 (Hanwoo / 한우) 1++等级 (人均₩80,000 (~$60 / ~430 RMB / ~8,500 JPY) ~ ₩150,000) + 韩牛 (Hanwoo / 한우) 午餐套餐 (₩30,000起，价格合理)。

3. “羊肉串 (Yangkkochi / 양꼬치) = 韩国食物”: 羊肉串 (Yangkkochi / 양꼬치) 源自中国新疆维吾尔，后经韩国改良 (1990年代华侨·东南亚居民增多)。九老 (Guro / 구로)·大林 (Daerim / 대림) 华侨街是其发源地。

⚙ 常见问题6个

1. 韩国烤肉礼仪: 长辈优先 + 双手倒酒 + 部分传统店铺需脱鞋。

2. 韩牛 (Hanwoo / 한우) 等级系统: 1++ → 1+ → 1 → 2 → 3 (1++为最高等级)。

3. 外国人友好店铺: Daram (다람)·河南猪肉店 (Hanam Daejijip / 하남돼지집)·88排骨 (88 Galbi / 88갈비)·建大烤肉小子 (Geondae Gogigupneunnom / 건대 고기굽는놈)。

4. 无限续盘 vs 传统老字号 (laozìhào) (30年以上的传统店): 无限续盘 (性价比高) vs 传统老字号 (laozìhào) (品质高)。

5. 羊肉串 (Yangkkochi / 양꼬치) 在哪里吃?: 九老 (Guro / 구로)·大林 (Daerim / 대림) 华侨街 (#180) 是首选。

6. 马场畜产品市场 (Majang Chuksammul Sijang / 마장축산물시장) 可以议价吗?: 可以，现场生鱼片·烤肉可享30%~50%批发价。
