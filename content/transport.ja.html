ソウル交通・ナビ完全ガイド — 地下鉄・バス・タクシー・アプリ全部解決

> 韓国の交通は難しくありません。このガイド一冊でソウルがあなたの手に入ります。

一目でわかる

項目 情報
公共交通 地下鉄・バス・タクシーすべて格安 (1回基本運賃 ₩1,250〜₩2,500 / 約130〜270 JPY)
交通カード T-money (ティーマネー) または Climate Card (クライメイトカード) — コンビニ (편의점, 日本のコンビニと同様、24時間営業) で購入可能
主要アプリ Naver Map (ネイバーマップ), Kakao Map (カカオマップ), Seoul Metro 公式アプリ
英語/中国語 主要駅・アプリともに対応
24時間 地下鉄は深夜0時〜05:00 (AM 5:00) 運行休止。深夜バス・タクシーは24時間
費用 利便性 vs コスパで選択 (タクシー = 高め、地下鉄 = 格安)

Part 1: 交通カード — T-money vs Climate Card

本当に必要？ 必須です。毎回現金で払うと損。

T-money (ティーマネー)

項目 説明
購入場所 GS25, CU, Emart (イーマート), コンビニならどこでも可
購入価格 カード代 ₩2,500 + 残高チャージ (最低 ₩2,000)
使える場所 地下鉄・バス・タクシー・コンビニすべて対応
チャージ コンビニ・駅の自動チャージ機 (24時間)
払い戻し 出国前に換金可能 (手数料 ₩500)

メリット: 韓国全土で使える。最良の選択肢。

Climate Card (クライメイトカード)

項目 説明
購入場所 GS25, CU などコンビニ (T-money と同じ)
購入価格 カード代 ₩2,500 + 残高 (最低 ₩2,000)
使える場所 地下鉄・バス・タクシー・コンビニ (T-money と同じ)
特徴 環境配慮 (リサイクル可能素材) で導入

T-money との違い: ほぼなし。コンビニにある方を気軽に買えばOK。

交通カード利用のコツ

1. 購入時: 「T-money カード ください」と言うか、指差しでOK

2. チャージ: コンビニのレジまたは駅の自動チャージ機 (自動機の方が簡単)

3. 使い方: 地下鉄・バス乗車時にカードリーダーにタッチ (「ピッ」という音)

4. 残高確認: コンビニのレジまたはアプリ

5. 払い戻し: 空港または出国前の両替所で (カード代 - 手数料を返金)

Part 2: 地下鉄完全ガイド

ソウル地下鉄の基本情報

項目 説明
路線数 主要9路線 (1〜9号線) + 支線
運行時間 基本 05:30〜深夜0時 (路線により異なる)
深夜運行 なし (深夜0時〜05:30 は深夜バスを利用)
基本運賃 ₩1,250 (~130 JPY) (10km以内)
追加運賃 10km超過ごとに ₩100 追加
混雑度 平日 08:00〜09:00 (AM)、17:00〜18:00 (PM) が最混雑

地下鉄駅内の施設

施設 説明
エスカレーター 左側に乗る (右側は歩く人のために空けるマナー)
トイレ 全駅あり (一部暗証番号式、基本無料)
コンビニ GS25・CU (全駅の地下商店街)
カフェ 駅周辺または地下商店街
案内所 各駅に設置 (スタッフの英語対応可)

地下鉄乗車の完全プロセス

Step 1: 目的地を調べる

方法1: スマートフォンアプリ

  • Naver Map (ネイバーマップ) または Kakao Map (カカオマップ) を開く
  • 「出発地 → 目的地」を入力
  • 「公共交通」タブを選択
  • おすすめルートに従う

方法2: 駅構内の案内図

  • 駅構内の大きな路線図を探す
  • 現在地を確認 (通常は赤い点)
  • 目的地を確認
  • 必要な路線を探す

Step 2: 駅に入る

1. 改札口または自動改札機を探す

2. T-money カードまたは一回用乗車券を購入

3. 自動改札機にカードをタッチ (「ピッ」= 正常)

4. ゲートを通過

Step 3: ホームへ移動

1. 乗り場方向の表示板に従う (通常は上向き矢印)

2. 「1号線」または「2番方向」を確認

3. 該当方向のホームへ移動

Step 4: 乗車

1. ホームで待機

2. 列車到着 (デジタル表示板に残り時間が表示)

3. ドアが開いたら乗車 (降りる人が先に降りてから)

4. つり革・手すりを掴む (揺れが大きい)

Step 5: 下車

1. 駅名を確認 (車内デジタル表示板 + 音声案内)

2. 目的の駅到着時に準備

3. ドアが開いたら下車

4. 「出口 1, 2, 3」を確認して出る

Step 6: 駅から出る

1. 案内図またはスマートフォンのマップで出口を確認

2. エスカレーターまたは階段を利用

3. 改札口を通過 (カードタッチ)

地下鉄の乗り換え

同じ駅で乗り換える場合:

  • 基本的に可能 (表示板に従う)
  • 追加料金なし (1時間以内の乗り換え)

別の駅で乗り換える場合:

  • 不可 (同一駅構内のみ乗り換え可能)

乗り換え制限時間:

  • 通常: 1時間以内 (追加料金なし)
  • 超過: 追加料金発生

地下鉄を使うときの便利なコツ

コツ 説明
路線図が複雑 スマートフォンのマップアプリだけ信じる (より正確)
方向で迷う 「Incheon (인천)」または「Myeongdong (명동)」方向を探す
長時間乗車 1号線は40分超、2号線は60分超 (非常に長い)
荷物が多いとき 先頭・最後尾車両は荷物スペースが広め
女性専用車両 平日夜 20:00〜22:00 に指定 (乗車ラインで区別)
夜景スポット 2号線で カンナム (강남)〜 Euljiro (을지로, 乙支路) 区間がおすすめ

Part 3: バスガイド

バスの種類

1. 一般バス (青色)

項目 説明
運賃 ₩1,250 (地下鉄と同じ)
速度 遅め (停留所が多い)
おすすめ 短距離 + 景色の良いコース

乗り方:

  • 前扉から乗車 + カードタッチ
  • 後扉から下車

2. 座席バス (赤/緑色、中央バス専用レーン)

項目 説明
運賃 ₩1,450〜₩2,500 (距離別)
速度 速い (中央バス専用レーン使用)
おすすめ 長距離 + 時間が少ないとき

特徴:

  • 道路中央の専用レーンを走る (速い)
  • 座席あり (快適。一般バスは立つ場合あり)
  • 距離により運賃が異なる

バス乗車プロセス

1. バス停で待つ: 番号を確認

2. バス到着: 手を挙げて運転手に合図 (しないと停まらない場合あり)

3. 乗車: 前扉から乗る

4. カードタッチ: リーダーに T-money カードをタッチ (「ピッ」という音)

5. 座るか手すりを掴む

6. 目的地確認: 車両前方のデジタル表示板で駅名を確認

7. 下車: 目的地の表示が出たら「降ります」と手を挙げる

8. 後扉から下車: カード再タッチ (一部のバス)

バスアプリの確認方法

Naver Map (ネイバーマップ) または Kakao Map (カカオマップ):

1. バス停を入力

2. 「バス」タブを選択

3. リアルタイムのバス位置を確認

4. あと何停留所かを確認

5. 予想到着時刻を確認

Part 4: タクシー — 便利だが高め

タクシーの基本情報

項目 説明
基本料金 ₩3,400 (基本 2km / ~370 JPY)
追加料金 100mごとに ₩100 追加
時間料金 35秒ごとに ₩100 (渋滞時)
深夜料金 深夜0時〜04:00 (AM 4:00) +20% 割増
目安 かなり高め (5km で ₩15,000+ / ~1,600 JPY+)

タクシーの種類

種類 色 価格 特徴
一般タクシー シルバー/イエロー 基本 最も一般的
模範タクシー (모범택시) ブラック +20% 高め 清潔、英語対応ドライバーあり
大型タクシー グレー +50% 高め 乗客4名以上向け
タクシーアプリ 全色 変動 Kakao T (カカオT)、Uber (ウーバー) (価格変動あり)

タクシーの乗り方

路上で拾う場合

1. 手を挙げて合図: ドライバーに見えるよう手を上げる

2. タクシー停車: ドライバーが気づいたら停車

3. 目的地を伝える: 英語または住所で (通じなければスマートフォンで住所を見せる)

4. 乗車: 後部座席に乗る

5. メーター確認: メーターが入っているか確認 (重要！)

6. 目的地到着: クレジットカードで支払い (または現金)

7. チップ: 韓国はチップ文化なし (おつりもきちんと受け取ってOK)

タクシーアプリで呼ぶ場合

Kakao T (カカオT) — 最も人気:

```

1. アプリをインストールしてログイン

2. 「出発地」を入力 (現在地が自動入力)

3. 「目的地」を入力

4. 「タクシー予約」をタップ

5. タクシーの到着を待つ

6. スマートフォンにドライバー情報が表示

7. 乗車

8. アプリで決済 (カード連動)

```

メリット:

  • 事前に料金の目安がわかる
  • クレジットカード自動決済 (現金不要)
  • タクシーの位置をリアルタイムで追跡
  • ドライバー情報を確認できる

デメリット:

  • 距離運賃より高くなる場合あり (変動料金制)
  • アプリのインストールが必要

タクシーのコツ・注意事項

項目 説明
メーター 必ず入っているか確認。入っていなければ乗らないこと
おつり ドライバーに確認してきちんともらう (韓国ではチップ不要)
乗車拒否 違法 (近距離でも乗せる義務あり)
カード決済 クレジットカード可 (ドライバーが POS 機を出してくれる)
外国人向け 英語対応ドライバーは少なめ。住所をスマートフォンで見せるのが最善
夜景ドライブ 幹線道路 (漢江沿い) でタクシーに乗って夜景を楽しむのもおすすめ

Part 5: ナビゲーションアプリ — 完全ガイド

Naver Map (ネイバーマップ) vs Kakao Map (カカオマップ)

Naver Map (ネイバーマップ)

メリット:

  • リアルタイム交通情報が正確
  • 公共交通のルート検索が最も精度高い
  • 英語サポートが充実

デメリット:

  • 中国からはアクセス不可
  • 一部の小規模店舗の情報が不足

おすすめ: ほとんどの旅行者に最適。特に地下鉄・バス利用時。

Kakao Map (カカオマップ)

メリット:

  • 中国からアクセス可能 (VPN 不要)
  • 飲食店・カフェ情報が豊富
  • リアルタイムのタクシー呼び出し可能 (Kakao T (カカオT) 連動)

デメリット:

  • 英語サポートが比較的弱め
  • 公共交通ルートが時々不正確

おすすめ: 中国人観光客、飲食店情報を多く必要とするとき

Naver Map (ネイバーマップ) 使い方のコツ

```

1. アプリをインストールして日本語設定

2. 右上の「言語」→「日本語」または「English」に変更

3. 検索欄に「地域名」または「住所」を入力

4. 「ルート検索」を選択

5. 交通手段を選択 (地下鉄 / バス / タクシー / 車 / 自転車)

6. 「出発」ボタン

7. リアルタイムのルート案内開始

```

リアルタイム交通情報の見方

Naver Map (ネイバーマップ) の画面表示:

表示色 意味
緑色 スムーズな交通
黄色 少し混雑
赤色 激しい渋滞
灰色 運行情報なし

中国人観光客向け特化: WeChat Map (ウィーチャットマップ)

これは何? 中国の Baidu Map (バイドゥマップ) などに近いサービス。WeChat (ウィーチャット) 内に内蔵。

メリット:

  • 中国製 (互換性が高い)
  • WeChat Pay (ウィーチャットペイ) と連動

デメリット:

  • 韓国のデータが不足 (非推奨)

結論: Kakao Map (カカオマップ) が次善策。

Part 6: Ttareungi (따릉이) — 公共自転車

Ttareungi (따릉이) とは?

これは何? ソウルの公共自転車シェアリングシステム。全域にレンタルステーションがある。

項目 説明
レンタル料 30分以内 ₩1,000 (追加10分ごとに ₩500)
登録方法 アプリ (Ttareungi アプリ) またはステーションで直接登録
条件 クレジットカード必要 (デポジット目的)
特徴 ソウル各所に1,400以上のステーション

Ttareungi (따릉이) 利用方法

1. アプリをインストール: 「따릉이 (Ttareungi)」アプリをダウンロード

2. 会員登録: クレジットカードを登録 (申込当日は不可、1日かかる)

3. ステーションを探す: 地図でステーションを確認

4. レンタル: アプリで自転車番号を入力してロック解除

5. 返却: ステーションの空いたスペースに自転車を差し込む (自動ロック)

Part 7: 空港移動完全ガイド

Incheon Airport (仁川空港, 인천공항) → ソウル市内

交通手段 所要時間 料金 おすすめ度
空港鉄道 60分 ₩9,000 (~970 JPY) ⭐⭐⭐⭐
空港バス 70〜120分 ₩10,000〜₩15,000 ⭐⭐⭐⭐
リムジン 60〜90分 ₩25,000〜₩35,000 ⭐⭐⭐
タクシー 60〜90分 ₩70,000〜₩100,000 ⭐

おすすめの組み合わせ:

  • 1人または2人: 空港鉄道 (コスパ + 速い)
  • 3人以上: リムジン (荷物が多いとき)
  • 特定のホテルに泊まるとき: 空港バス (ホテル直行)

空港鉄道の利用方法

```

1. Incheon Airport (仁川空港, 인천공항) 到着 → 電車駅の表示板に従う

2. 空港鉄道のチケットを購入 (自動券売機またはカウンター、₩9,000)

3. ゲートを通過 (チケット提示)

4. 電車に乗車 (Seoul Station (서울역) または空港鉄道各駅行き)

5. Seoul Station (서울역) 到着 (所要 60分)

6. 地下鉄に乗り換え (Seoul Station は1・4号線と接続)

```

外国人旅行者チェックリスト

```

[ ] T-money (ティーマネー) カードを購入 (コンビニで)

[ ] チャージ (最低 ₩5,000)

[ ] Naver Map (ネイバーマップ) または Kakao Map (カカオマップ) をインストール

[ ] スマートフォンに韓国語入力を設定 (住所検索用)

[ ] よく行く駅・停留所をお気に入り登録

[ ] バスの番号を写真に撮っておく (迷ったときの備え)

[ ] タクシー料金を事前に確認 (アプリ使用)

[ ] 深夜交通の情報を事前に確認

[ ] 空港からの移動方法を事前に決めておく

```
