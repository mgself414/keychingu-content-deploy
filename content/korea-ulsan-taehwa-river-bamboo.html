🎯 왜 태화강 + 십리대숲 가이드인가

울산 태화강 (Taehwa River) = 한국 #2 국가정원 (2019년 지정)·83만m²·12 테마 정원. 십리대숲 (Sipni Daesup) = 한국 #1 도심 대숲 4.3km. 외국인 페인포인트 = (a) "태화강 = 일반 강" 잘못된 인식 (b) 국가정원 2019년 지정 (한국 #1 = 순천만 / #2 = 태화강) (c) 십리대숲 = 4.3km·연중 산책·인스타 매트릭스 #1 (d) MZ + 카페 + 인스타 fit (e) 12 테마 정원 풀세트.

본 가이드는 5축 12 시그니처 + 십리대숲 + 12 테마 정원 + 외국인 영문 발화.

🏛 5축 deep dive

① 태화강 국가정원 (2019년·한국 #2)

  • 시그니처: 2019년 지정·83만m²·한국 #1 = 순천만·#2 = 태화강·12 테마 정원
  • 외국인 친화도: ★★★★★ (영문·MZ + 인스타 fit·산책)
  • 시간: 연중·무료·24h 개방
  • 추천: 산책 + 12 테마 + 인스타 = 2시간

② 십리대숲 (4.3km·한국 #1 도심 대숲)

  • 시그니처: 4.3km·한국 #1 도심 대숲·연중 산책·인스타 매트릭스 #1
  • 외국인 친화도: ★★★★★ (MZ + 인스타 fit)
  • 추천: 산책 1.5h + 자전거 (4.3km·45분)
  • 자전거 대여: 5,000~10,000원/시간

③ 태화강 산책 + 자전거 + 카페

  • 시그니처: 4.3km 산책로·자전거·카페 cluster·MZ + 가족 매니아 매트릭스
  • 외국인 친화도: ★★★★ (영문 + 결제 카드)
  • 추천: 산책 + 자전거 + 카페 = 인스타 풀세트

④ 시즌 매트릭스 (봄 벚꽃·가을 갈대·단풍)

  • 봄 (3-4월): 벚꽃 매트릭스·인스타 #1·태화강 + 도시 매니아
  • 가을 (9-11월): 갈대 + 단풍·인스타 #1·MZ 매니아
  • 여름·겨울: 호불호·실내 매니아 (박물관) 매트릭스

⑤ 박물관·문화 (울산 시립박물관)

  • 시그니처: 울산 시립박물관·영문 풀세트·무료 또는 5,000원
  • 외국인 친화도: ★★★★ (영문·교육적)
  • 추천: 1-2h 매니아 매트릭스

⚠ 외국인 자주 실수 5가지

1. "태화강 = 일반 강": 2019년~ 한국 #2 국가정원·83만m²·12 테마.

2. "십리대숲 = 작은 대숲": 4.3km·한국 #1 도심 대숲·연중 산책·인스타 매트릭스 #1.

3. "국가정원 = 단순 공원": 12 테마 정원·한국·외국·미래·체험·가족·어린이 매니아 #1.

4. "시즌 = 봄만": 봄 (벚꽃) + 가을 (갈대·단풍) = 양 시즌 매니아 매트릭스 #1.

5. "자전거 = 외국인 X": 4.3km 자전거 + 산책 = MZ 매니아 매트릭스·대여 5,000~10,000원/시간.

⚙ FAQ 6개

1. 외국인 입문 1순위: 십리대숲 + 국가정원 + 카페 cluster = 2-3시간 인스타.

2. 십리대숲 산책 vs 자전거: 산책 = 1.5h·자전거 = 45분·4.3km 풀세트.

3. 시즌: 봄 (3-4월 벚꽃)·가을 (9-11월 갈대·단풍) 매트릭스 #1·여름·겨울 호불호.

4. 12 테마 정원: 한국·외국·미래·체험·무료 매트릭스.

5. 자전거 대여: 5,000~10,000원/시간·시즌·날씨 확인.

6. 추천 페르소나: 가족·어린이 = 국가정원 + 카페 / MZ·인스타 = 십리대숲 + 자전거 / 매니아 = 시립박물관 + 산책 풀데이.
