済州オルム ガイド — 城山日出峰・サングムブリ・コムンオルム、セビョルオルム・ヨンヌニオルム・タランシオルム、サラオルム・ウィッセオルムまで20か所

サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「済州オルム」テーマで選ばれた場所のうち20か所 · 登録値で入場料を取る場所は城山日出峰(大人 5,000ウォン)・サングムブリ(成人 7,000ウォン)・コムンオルム(大人 2,000ウォン) · コムンオルムは火曜日休み、09:00~14:00に30分間隔で出発 · セビョルオルムは頂上まで約20分、タラビオルム・クンサンオルム・ペギャギオルムは約30分 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

オルム (Oreum / 오름)は済州の小さな火山体を指す言葉です。観光公社の紹介には、済州島に360余りの寄生火山が分布すると書かれています。このガイドは、そのうち文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「済州オルム」テーマで選ばれた53か所のうち、観光公社の観光情報で運営情報を確認できた20か所を扱います。表の順位と得票数は、その投票結果です。

ほとんどは無料で、20か所のうち10か所が常時開放として登録されています。料金が登録された場所のうち入場料を取るのは城山日出峰・サングムブリ・コムンオルムの3か所で、チョジオルムは料金の値が登録されていません。コムンオルムは決まった時刻に出発します。山房山は無料ですが、券売所からサンバングルサ (Sanbanggulsa / 산방굴사)までの散策路だけ見学できると登録されています。

サラオルム・ウィッセオルム・アンドルオルム・アブオルム・クンサンオルムには統制されることがあるので電話で問い合わせるようにという案内が付いていて、サラボンには統制区域を電話で確認するようにという案内があります。運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。

📍 入場料が登録された3か所 — 城山日出峰・サングムブリ・コムンオルム

城山日出峰、西帰浦市 城山邑 Ilchul-ro 284-12 (일출로 284-12)、☎ 064-783-0959 は、海抜180mで、約5,000年前に海の中で水中爆発した火山体です。ユネスコ世界自然遺産です。頂上には直径600mの噴火口があります。もとは火山島でしたが、砂と砂利が積もって陸とつながりました。観光公社の紹介によると、頂上から見る日の出は昔からヨンジュ10景 (Yeongju Sipgyeong / 영주 10경)の筆頭に数えられてきました。

  • 開く時間: 11~2月 06:00~18:00(券売締切 17:00)、3・4・9・10月 05:00~19:00(券売締切 18:00)、5~8月 04:30~20:00(券売締切 19:00)。
  • 休み: 毎月第1週の月曜日(祝日なら翌日)。
  • 料金(個人): 大人 5,000ウォン、青少年・軍人・子ども 2,500ウォン。駐車: 無料。
  • 案内: 自然遺産解説士の案内 09:00~17:00(探訪案内所で待機)。外国語案内は中国語が可能と登録されています。

サングムブリ、済州市 チョチョン邑 Bijarim-ro 768 (비자림로 768)、☎ 064-783-9900 は、周囲が2kmを超える火口で、天然記念物です。溶岩や火山灰を噴き出さず爆発だけが起きて穴だけが残った火山をマール (Maar)と呼び、観光公社の紹介には韓国に1つだけと書かれています。火口の中は、北側の崖が暖帯地域の常緑広葉樹群、南側の崖が温帯性の落葉樹群落と、植生が分かれます。

  • 開く時間: 3~6月・9~10月 09:00~18:40(入場締切 18:00)、7~8月・11~2月 09:00~17:40(入場締切 17:00)。締切時間は天候によって変わることがあります。
  • 休み: 年中無休。
  • 料金(個人): 成人 7,000ウォン、青少年・子ども(満4歳以上) 6,000ウォン。満65歳以上は身分証を出すと5,000ウォン。

コムンオルム、済州市 チョチョン邑 Seongyo-ro 569-36 (선교로 569-36)、☎ 064-710-8981 は、森に覆われて黒く見えることから、黒いオルム (Geomeun Oreum / 검은오름)とも呼ばれます。噴火口から流れ出た溶岩が、約4km続く谷をつくりました。

  • 開く時間: 09:00~14:00、30分間隔で出発します。1日11回探訪でき、詳しい探訪時間は公式ホームページを見るようにと登録されています。
  • 休み: 毎週火曜日、旧正月・秋夕の連休。天候が悪いと全面統制します。
  • 料金(個人): 大人 2,000ウォン、青少年・軍人 1,000ウォン、子ども 1,000ウォン。6歳以下と65歳以上は無料。

📍 城山・クジャ・ピョソン — ソプチコジ・ヨンヌニオルム・タランシオルム・アブオルム・アンドルオルム・ペギャギオルム・タラビオルム

ソプチコジ、西帰浦市 城山邑 Seopjikoji-ro 262 (섭지코지로 262)、☎ 064-784-2810 は、観光公社の紹介によると、城山邑 シニャンリ (Sinyang-ri / 신양리)の海岸に突き出た地形です。「コジ」は岬を意味する済州の方言です。丘の上には昔の烽燧台であるヒョプチャヨンデ (Hyeopjayeondae / 협자연대)があり、その北東の峰が赤い火山灰(ソンイ)でできたプルグンオルム (Bulgeun Oreum / 붉은오름)です。頂上の白い灯台まで鉄の階段が設けられています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

ヨンヌニオルム、済州市 クジャ邑 Jongdal-nongil (종달논길)、☎ 済州観光情報センター (Jeju Gwangwang Jeongbo Senteo / 제주관광정보센터) 064-740-6000 は、海抜247.8m、高さ88m、周囲2,685mです。観光公社の紹介には、360余りのオルムの中で唯一噴火口が3つあると書かれています。春・夏には芝、秋・冬にはススキに覆われます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 可能。

タランシオルム(ウォルランボン)、済州市 クジャ邑 セファリ (Sehwa-ri / 세화리) San 6 (산6)、☎ 064-740-6000 は、斜面がどちら側も急傾斜の円錐形のオルムです。てっぺんにじょうご形の深い噴火口があります。噴火口が月のように丸く見えることから、タランシという名前が付いたと言われています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 不可能。

アブオルム、済州市 クジャ邑 ソンダンリ (Songdang-ri / 송당리) San 164-1 (산164-1)、☎ 064-740-6000 は、オルムの周囲まで難なく登れると紹介されています。頂上に木鉢のように丸いクムブリ (Gumburi / 굼부리)(噴火口)があり、その中にスギが円形に育っています。

  • 開く時間: 一部の出入りが統制されることがあるので、訪問前に電話で問い合わせ。休み: 年中無休。料金: 無料。

アンドルオルム、済州市 クジャ邑 ソンダンリ San 66-2 (산66-2)、☎ 064-740-6000 は、馬蹄形の火口を持つ草地のオルムです。火口の内側の溝になった所にだけ木が茂って森を成しています。

  • 開く時間: 統制されることがあるので、訪問前に電話で問い合わせ。休み: 年中無休。料金: 無料。

ペギャギオルム、西帰浦市 ピョソン面 ソンウプリ (Seongeup-ri / 성읍리) San 1 (산1)、☎ 064-740-6000 は、薬草がたくさん育つことから付いた名前です。30分ほど登ると頂上に着き、円形競技場のようにくぼんだクムブリが現れます。トラック状の頂上に沿って、周りのいくつものオルムが見えます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

タラビオルム、西帰浦市 ピョソン面 ガシリ (Gasi-ri / 가시리) San 62 (산62)、☎ 064-740-6000 は、噴火口3つと峰6つでできています。頂上まで30分ほどかかります。観光公社の紹介によると、ススキは10~11月に最も多く咲き、冬まで残ります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 アエウォル・ハンリム・ハンギョン — セビョルオルム・クムオルム・チョジオルム

セビョルオルム、済州市 アエウォル邑 ポンソンリ (Bongseong-ri / 봉성리) San 59-8 (산59-8)、☎ 済州観光情報センター 064-740-6000 は、「夕方の空に明星のように寂しく立っている」ことから付いた名前です。峰が5つです。10月にはオルムにススキが咲きます。頂上まで20分ほどかかります。

  • 開く時間: 常時開放。料金: 無料。駐車: 可能。

クムオルム、済州市 ハンリム邑 クマクリ (Geumak-ri / 금악리) San 1-1 (산1-1)、☎ 064-740-6000 は、標高427.5m、周囲2,861mです。てっぺんに深さ52mの円形の噴火口があります。噴火口の中の湖は、以前は水が多かったものの、今は底が見えていると登録されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

チョジオルム、済州市 ハンギョン面、☎ 064-728-7952 は、周囲約900m、深さ約60mの急なじょうご形の噴火口を持つオルムです。斜面はクロマツが主体の鬱蒼とした森です。2007年の第8回「美しい森」全国大会で生命賞(大賞)を受けました。チョジオルム休憩所と展望台があります。

  • 休み: 年中無休。開く時間と料金は登録値がありません。

📍 アンドク・テジョン — 山房山・クンサンオルム・松岳山

山房山、西帰浦市 アンドク面 サゲリ (Sagye-ri / 사계리) San 16 (산16)、☎ 064-794-2940 は、平らな地形の上にそびえるドーム形の火山です。南西の中腹のサンバングル (Sanbanggul / 산방굴)から、ヨンモリヘアン (Yongmeori Haean / 용머리해안)が見えます。名勝を保護するための公開制限地域のため、券売所からサンバングルサまでの散策路だけ見学できると登録されています。

  • 開く時間: 09:00~17:50(入場締切 17:30)。日没時刻と天候によって変わったり統制されたりすることがあります。
  • 休み: 年中無休。料金: 無料。駐車: 無料。

クンサンオルム、西帰浦市 アンドク面 チャンチョンリ (Changcheon-ri / 창천리) 564、☎ 064-740-6000 は、道が舗装されていて、歩いて30分ほどかかります。頂上に角のようにそびえる岩が2つあります。頂上から漢拏山 (Hallasan / 한라산)、チュンムン観光団地 (Jungmun Gwangwang Danji / 중문관광단지)、マラド (Marado / 마라도)、山房山が見えます。

  • 開く時間: 一部統制されることがあるので、訪問前に電話で問い合わせ。休み: 年中無休。料金: 無料。駐車: クンサンオルム駐車場、無料。

松岳山、西帰浦市 テジョン邑 Songak-gwangwang-ro 421-1 (송악관광로 421-1)、☎ 西帰浦市庁 気候環境課 (Seogwipo-sicheong Gihu Hwangyeong-gwa / 서귀포시청 기후환경과) 064-760-2917 は、最初の噴火口の中に2つ目の噴火口ができた二重噴火口の火山です。済州オルレ (Jeju Olle / 제주 올레) 10コースが通る周回路から、ヒョンジェソム (Hyeongjeseom / 형제섬)とカパド (Gapado / 가파도)、遠くにマラドが見えます。道は険しくありませんが、風が多いです。海岸の断崖には、第二次世界大戦のとき日本軍が済州の人々を動員して掘った人工洞窟が15あります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 漢拏山登山コースのオルムと湿地のオルム — サラオルム・ウィッセオルム・ムルヨンアリオルム

サラオルム、西帰浦市 ナモン邑 シルレリ (Sillye-ri / 신례리) San 2-1 (산2-1)、☎ 064-740-6000 は、漢拏山のソンパナク (Seongpanak / 성판악)登山コースの南にあります。噴火口に水がたまった山頂火口湖があり、湖の周囲は2011年に名勝に指定されました。観光公社の紹介には、高地1,300mの凍りついた湖と雪に覆われた風景が壮観で、登山マニアが多く訪れると書かれています。

  • 開く時間: 統制されることがあるので、電話で問い合わせ。休み: 年中無休。料金: 無料。

ウィッセオルム、済州市 アエウォル邑 クァンニョンリ (Gwangnyeong-ri / 광령리) San 183-1 (산183-1)、☎ 漢拏山事務所 (Hallasan Samuso / 한라산 사무소) 064-713-9950 は、漢拏山のヨンシル (Yeongsil / 영실)登山コースに沿って続く3つのオルムです。上からプルグンオルム、ヌウンオルム (Nuun Oreum / 누운오름)、チョグンオルム (Jogeun Oreum / 족은오름)と呼びます。春にはチョルチュク (Cheolchuk / 철쭉)とチンダルレ (Jindallae / 진달래)が咲きます。登山道のそばにノルセム (Noru Saem / 노루샘)があります。

  • 開く時間: 一部統制されることがあるので、訪問前に電話で問い合わせ。休み: 年中無休。料金: 無料。

ムルヨンアリオルム、西帰浦市 ナモン邑 Taesu-ro 552 (태수로 552)、☎ 064-728-6200 は、噴火口に湿地を抱えたオルムです。2006年にラムサール条約湿地に指定されました。探訪は牧場の周りを半周したあとに始まります。映画「オオカミ少年 (Neukdae Sonyeon / 늑대소년)」を撮った場所と登録されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 済州市内 — サラボン

サラボン、済州市 Sarabong-dong-gil 61 (사라봉동길 61)、☎ 064-740-6000 は、済州港の東の海辺のオルムです。サラボンから見る夕焼け「サボンナクチョ (Sabong Nakjo / 사봉낙조)」はヨンジュ十景に入ります。頂上から北に海、南に漢拏山、足元に済州市内が見えます。一帯が公園で、パルガクチョン (Palgakjeong / 팔각정)があります。

  • 開く時間: 常時開放(統制区域は訪問前に電話で問い合わせ)。休み: 年中無休。料金: 無料。

⚠ 事前に知っておきたい3点

  1. コムンオルムはいつでも入れるわけではありません — 09:00~14:00に30分間隔で出発し、火曜日と旧正月・秋夕の連休は休みます。
  2. 山房山は見学区間が決まっています — 券売所からサンバングルサまでの散策路だけ見学できると登録されていて、日没時刻と天候によって統制されることがあります。
  3. 「統制されることがある」と付いたオルムは、行く前に電話します — サラオルム、ウィッセオルム、アンドルオルム、アブオルム、クンサンオルムがそう登録されています。サラボンは統制区域を電話で確認するようにとなっていて、コムンオルムは天候が悪いと全面統制します。

⚙ FAQ 3

Q. 短く登れるオルムは?

A. 登録情報に所要時間が書かれているのは、セビョルオルム(頂上まで20分ほど)、タラビオルム(30分ほど)、ペギャギオルム(30分ほど)、クンサンオルム(歩いて30分ほど)です。

Q. お金がかかる場所は?

A. 城山日出峰(大人 5,000ウォン)、サングムブリ(成人 7,000ウォン)、コムンオルム(大人 2,000ウォン)です。残りは無料で登録されていて、チョジオルムは料金の登録値がありません。

Q. ススキはどこで見られますか?

A. 観光公社の紹介にススキが書かれているのは、セビョルオルム(10月)、タラビオルム(10~11月に最も多く咲き、冬まで残る)、ヨンヌニオルム(秋・冬)です。
