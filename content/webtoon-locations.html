⚠ 외국인 자주 실수 5가지

1. "웹툰 = 만화만": 한국 웹툰 = 글로벌 1억+ (LINE Webtoon·KakaoPage) + 웹드라마 변환 (Tower of God·Solo Leveling·외모지상주의·사내맞선) + 외국인 매니아 1번지·#445 통합.

2. "Tower of God = TV만": Tower of God = 네이버 웹툰 한국 #1 글로벌 + 외국인 매니아 1번지 + SIU 작가·#445·#387 통합·외국인 글로벌 매니아.

3. "Solo Leveling = 외국인 못 봄": Solo Leveling = 카카오 페이지 + Netflix 글로벌 + 외국인 매니아 1번지 + Chugong·DICE·외국인 글로벌 매니아 1번지.

4. "웹툰 IP 촬영지 = 못 찾음": 웹툰 IP 촬영지 = #378·#503·#507 통합 + Klook·KKday 외국인 패키지 + 외국인 매니아 풀세트.

5. "외국인 웹툰 = 한국어만": 외국인 웹툰 = LINE Webtoon·KakaoPage 영어 OK + Twitter·YouTube vlog 외국인 글로벌 매니아 + #445 통합.
