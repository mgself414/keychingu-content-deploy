外国人がよくやりがちな失敗5つ

1. 「ビーガン=韓国にはない」という誤解

韓国のビーガンレストランは 2020年以降に爆発的に増加 — イテウォン (이태원)・ハンナム (한남)・ホンデ (홍대)・ヨンナム (연남)・ソンス (성수) に100軒以上のビーガン店舗あり。精進料理・菜食ラインナップも含めると、外国人ビーガンでも1週間の食事は問題なし。

2. 精進料理 = ビーガンという単純な思い込み

精進料理 (チャジュムシク / 사찰음식) は 肉・海産物NG + 五葷 (파/マネギ・マヌル/ニンニク・ブチュ/ニラ・タルレ/ノビル・フンゴ/アサツキ系) NG。一般的なビーガンとは異なるカテゴリー。韓国の精進料理レストランは非常に限られているが、正統派韓国ビーガンの第一候補。

3. 韓国レストランの「ビーガン」メニューを100%信頼すること

韓国の一般レストランで「ビーガン対応可」とされていても、だし・油・発酵調味料の確認が不十分なケースが多い。本当のビーガンなら認証ビーガン店舗または外国人向けビーガン専門店を選ぼう。

4. ハラール = イテウォン (이태원) にしかないと思い込むこと

ハラールレストランは イテウォン (이태원) イスラムモスク通り + カンナム (강남)・ミョンドン (명동)・ホンデ (홍대) の一部店舗にもある。東南アジア・中東・トルコ料理店が中心。韓国モスク認証店舗は韓国イスラム中央会 (KMF) の公式サイトで検索可能。

5. アレルギー表記だけを頼りにすること

韓国レストランのアレルギー表記は英語対応が一部のみ。グルテン・ナッツ・甲殻類・卵・乳製品・大豆アレルギーの方は英語メニュー + スタッフへの直接確認 + 写真提示が必須。

1️⃣ ビーガン (Vegan) — 動物性食品一切NG

韓国ビーガンレストランの分布:

  • イテウォン (이태원)・ハンナム (한남): 外国人フレンドリーなビーガンカフェ・ブランチ 30軒以上
  • ヨンナム (연남)・ソンス (성수)・ホンデ (홍대): MZトレンドビーガンレストラン 20軒以上
  • インサドン (인사동)・チョンノ (종로): 正統精進料理 5軒以上

検証済み韓国ビーガンラインナップ (参考):

  • プレンティ (Planty): ビーガン韓食 (ハンナム (한남)・イテウォン (이태원))
  • ラッシュ ビーガンカフェ: ビーガンブランチ (ホンデ (홍대))
  • バッテッド (Vatted): ビーガン洋食 (ソンス (성수)・ヨンナム (연남))
  • Whole Foods Market (韓国一部店舗): ビーガン食材
  • ソンジェ (Seonjae / 선재): 正統精進料理 (インサドン (인사동))

ビーガン韓食メニューのおすすめ:

  • ビビンバ (비빔밥) (肉・卵を抜くようリクエスト + コチュジャンのビーガン確認)
  • キムパプ (김밥) (卵・ハム・ツナを抜くようリクエスト)
  • チャンチグクス (잔치국수) (イワシ・肉だしを抜くようリクエスト — 難しい場合あり)
  • 精進料理 (사찰음식): 豆腐・山菜・雑穀ご飯は100%ビーガン

確認キーワード:

  • 「ビーガンイエヨ (비건이에요)」= 「I'm vegan」
  • 「コギ・センソン・ゲラン・ウユ・クル タ ッペジュセヨ (고기・생선・계란・우유・꿀 다 빼주세요)」= 「肉・魚・卵・牛乳・ハチミツを全部抜いてください」

2️⃣ ハラール (Halal) — イスラムの食事規定

韓国ハラールレストランの分布:

  • イテウォン (이태원) イスラムモスク通り: メインハラール横丁 (イテウォン駅 (이태원역) 徒歩5〜10分)
  • カンナム (강남)・ミョンドン (명동)・ホンデ (홍대) の一部店舗: インド・トルコ・マレーシア・インドネシア料理店

検証済み韓国ハラールラインナップ (参考):

  • イテウォン (이태원) イスラムモスク通り: トルコ・パキスタン・エジプト・マレーシア・インドネシア料理店 20軒以上
  • イード (Eid) ハラールレストラン: 韓国式ハラール (ソウル一部)
  • インド料理店 (イテウォン (이태원)・カンナム (강남)): Bombay Curry・Saffron など

韓国モスク認証店舗:

  • KMF (韓国イスラム中央会) 認証店舗検索 = 公式サイト
  • 店舗入口に「Halal Certified」の表示

ハラール韓食オプション (限定的):

  • 韓国カルビ・サムギョプサル (삼겹살) = 豚・牛の屠畜がハラール非対応のケース多数 → ハラール認証韓食堂を事前確認
  • 韓国タッカルビ (닭갈비)・海鮮 = 一部店舗でハラール対応可
  • 韓国ビビンバ (비빔밥)・チャンチグクス (잔치국수) = だし・肉を抜くようリクエスト (実質ビーガン化)

3️⃣ グルテンフリー (Gluten-Free)

韓国グルテンフリーレストラン (限定的):

  • 韓国料理の醤油 (カンジャン / 간장)・コチュジャン (고추장) は小麦含有が多い → 直接確認が必要
  • ハンナム (한남)・アプクジョン (압구정)・カンナム (강남) のグルテンフリーカフェ・レストラン 10軒以上
  • 米ベースの韓食 (ご飯・雑穀・トック (떡)) はグルテンフリー対応可

確認キーワード:

  • 「グルテン アルレルギエヨ (글루텐 알레르기예요)」= 「グルテンアレルギーです」
  • 「ミルカル・カンジャン ッペジュセヨ (밀가루・간장 빼주세요)」= 「小麦粉・醤油を抜いてください」— 醤油は韓国料理の基本なので対応困難な場合あり

4️⃣ コーシャ (Kosher) — ユダヤ教の食事規定

韓国コーシャレストラン (非常に限定的):

  • イテウォン (이태원) の一部店舗でコーシャオプション提供
  • イスラエル・中東料理店の一部で対応可
  • 公式コーシャ認証店舗は韓国にほぼ存在しない → 自炊またはビーガンオプションの活用を推奨

FAQ

Q1. 英語は通じますか?

ビーガンカフェ・ハラールレストランは95%英語対応。精進料理・韓国正統系は英語メニューが一部のみ。

Q2. ビーガン・ハラール認証はどこで確認できますか?

  • ハラール: KMF (韓国イスラム中央会) 公式サイト / 店舗入口の表示
  • ビーガン: 韓国ビーガン協会サイト / Happy Cow アプリ

Q3. 韓国の一般レストランで「ビーガン対応可」は信頼できますか?

要確認。だし・油・発酵調味料・魚醤が入っている可能性あり。100%ビーガン保証は認証店舗のみ。

Q4. 家族でビーガン・ハラール対応できますか?

イテウォン (이태원)・ハンナム (한남)・ホンデ (홍대) = ファミリーフレンドリーなビーガン・ハラール店舗多数。英語メニュー + アレルギー表記 + お子様用チェアが一般的。

Q5. 韓国料理ベースでビーガン・ハラール対応できますか?

  • ビーガン: 精進料理 (사찰음식)・ビビンバ (비빔밥) (肉・卵抜き)・豆腐韓食
  • ハラール: ハラール認証韓食堂 (限定的) → 韓食 + 認証確認

Q6. コンビニでビーガン・ハラール食品は買えますか?

韓国ビーガン協会認証コンビニライン (CU・GS25・セブン-イレブン一部店舗 — ビーガンキムパプ (김밥)・弁当・お菓子)。ハラールはほぼなし → フルーツ・ナッツ・ミネラルウォーター推奨。
