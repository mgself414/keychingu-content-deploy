📅 伏日2026 — 公式の日付

  • 初伏7/15（水）・中伏7/25（土）・末伏8/14（金） — 韓国天文研究院 (KASI / 한국천문연구원)の2026年月力要項。中伏と末伏の間が20日ある「月伏の年（中伏〜末伏20日）」です。旧版の7/16・7/26・8/15はすべて1日ずれていました(旧日付は各1日遅れ)。伏日 (Bongnal / 복날)(初伏 (Chobok / 초복)・中伏 (Jungbok / 중복)・末伏 (Malbok / 말복))当日は参鶏湯の店に行列ができるというのは常識ですが、公式の数値はありません。

🍗 参鶏湯とは — VisitKoreaの定義

  • 「下処理した若鶏に高麗人参・ナツメ・もち米・各種ナッツを入れて煮込んだ伝統の滋養食」(VisitKoreaの土俗村のページ)。「滋養食」そのものの公式定義は、開いたページにはありません。
  • ソウルで公式ページ(VisitKorea)に時間がある店は3つ。土俗村 (Tosokchon / 토속촌)(景福宮 (Gyeongbokgung / 경복궁)の近く、10~22時、ラストオーダー21時、年中無休、カード可)、高峰参鶏湯 (Gobong Samgyetang / 고봉삼계탕)(明洞、09~22時)、百済参鶏湯 (Baekje Samgyetang / 백제삼계탕)(明洞、09~22時、1971年創業)です。参鶏湯 (Samgyetang / 삼계탕)の価格は3店とも未掲示。土俗村の「1980年代創業・英語メニュー・ミシュランのファン」といった旧版の文は出典がありません。

🏨 ホテル — 確認できたのは羅宴の星だけ

  • 羅宴 (La Yeon / 라연)(新羅ホテル (The Shilla Seoul / 신라호텔)): ミシュラン ソウル2026 二つ星(ミシュラン公式)、La Liste 2026 Top 1,000(ホテル公式)。時間とコース料金は公式ページにありません → 予約時に確認してください。「滋養コース」というメニューは確認できません。
  • ウェスティン朝鮮ソウル (The Westin Josun Seoul / 웨스틴 조선 서울): 公式ダイニング一覧(Josun Deli・Aria・Hong Yuan・Sushi Cho・The Ninth Gate・Lounge & Bar・Rubrica)に韓国料理店がありません — 旧版の「韓定食」は削除しました。
  • ロッテホテル無窮花 (Lotte Hotel Mugunghwa / 롯데호텔 무궁화)・フォーシーズンズ・バンヤンツリー: ページ未描画・403のため未確認です。サービス料・付加価値税の文も公式には確認できません。

🌿 韓方・薬膳 — 公式は「医療観光の案内」まで

  • VisitKoreaの韓方 (Hanbang / 한방)のページ: 心と体を総合的に診る治療で、鍼・推拿 (Chuna / 추나)・韓薬・運動療法を体質と症状に合わせて処方します。公式ページに病院3軒・体験館3軒の一覧と1330があります。薬膳 (Yaksun / 약선)の食堂・薬膳コースの価格はどの公式ページにもないため記載しません。

🚜 農村・地方 — ウェルチョンと釜山

  • ウェルチョン (Welchon / 웰촌)(welchon.com、農村観光の公式ポータル): ファームステイ・テーマ体験村・季節体験(リンゴ狩り・お茶づくりなど)・パッケージショップ・VR村ツアー。ウナギ・黒ヤギの「滋養食農場」はポータルにありません。
  • 釜山コムジャンオ (Gomjangeo / 곰장어): Visit Busanがチャガルチ (Jagalchi / 자갈치)・温泉場 (Oncheonjang / 온천장)・海雲台市場 (Haeundae Market / 해운대시장)・機張 (Gijang / 기장)を炭火コムジャンオの区域として案内しています(時間・価格の記載なし)。旧版の「西面コムジャンオ通り」はページにありません。
  • 高敞 (Gochang / 고창)の風川ウナギ・水原 (Suwon / 수원)の牛頭クッパ・南原 (Namwon / 남원)のチュオタン・江原の黒ヤギは、公式ページを開けなかったため記載しません。

4. 薬膳コースの予約 — 公式ページなし。
