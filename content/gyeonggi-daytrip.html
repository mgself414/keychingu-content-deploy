⚠ 외국인 자주 실수 5가지

1. "경기도 = 너무 멀어": 경기도 = 수원 KTX 30분·고양 일산 지하철 30분·용인 1시간 + 외국인 자유여행 1번지·#430 렌터카·#392 통합.

2. "수원 화성 = 그냥 성": 수원 화성 = UNESCO 1997 (정조 1796) + 4 대문 + 행궁동 + #503 우영우 광교 + 외국인 매니아 1번지·#440·#377 통합.

3. "에버랜드 = 1박 필수": 에버랜드·캐리비안베이 = day-trip OK (서울 1시간) + 외국인 셔틀 (Klook) + #440 테마파크·외국인 가족 (#210) 매니아.

4. "DMZ = 위험": 파주 DMZ = 외국인 매니아 1번지·KTO 인증·Klook·KKday 외국인 영어 가이드 + 임진각·평화누리공원·외국인 역사 매니아·#377 통합.

5. "외국인 자유여행 = 어려움": 외국인 경기도 = 렌터카 (#430) + KTX/지하철/고속버스 + 외국인 영어 OK + KTO 인증 + 외국인 매니아 풀세트.
