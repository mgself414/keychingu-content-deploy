チェジュの海の趣味 — シュノーケリング・フリーダイビング・体験ダイビング、いつ・どこで・誰と

サブタイトル: 12~3月のソギポ (Seogwipo / 서귀포)の沖合の海は、月平均で約15.7~19.2℃です。海水浴場は閉まっており、パンポポグ (Panpo Port / 판포포구)とセファ (Sehwa / 세화)での素潜りのシュノーケリングは夏の話です。冬に残る選択肢はソギポのショップのダイビング・フリーダイビング商品ですが、カカオマップには今週の営業時間しか載っておらず、冬のボートの出航予定はありません。水中の活動の根拠がある海の4か所(パンポポグ・セファ・ムンソム (Munseom / 문섬)一帯・ボモクポグ (Bomok Port / 보목포구))、カカオマップに営業中と出ているソギポのショップ7軒、法律が実際に定めていること(夜間禁止・許可が必要な水域など)を、条文番号つきでまとめました。海水浴場の開場・料金は#1059

🎯 この回の読み方

この回が扱うのは水の中に入る趣味だけです。シュノーケリング、フリーダイビング、スクーバの体験ダイビングとファンダイビングです。砂浜での海水浴や、海水浴場の開場期間・料金・設備は、#1059のチェジュのビーチガイドにあります。ヒョプジェ・ハムドクは#1059で扱い、クムヌン・キムニョンはこの回では扱いません。

まず時期を見ます。2026年のチェジュの海水浴場の開場期間は6/24~9/6でした。ビジットチェジュ (Visit Jeju)の2026年開場情報にある11か所は、今日(2026-11-24)時点でいずれも閉場しています。12~3月の現実と、夏まで待つべきことを、下の季節表で先に分けました。

⚠ 表記の原則: スポットの説明は、済州観光公社のビジットチェジュ (Visit Jeju)と韓国観光公社の観光情報に登録された内容です。「韓国観光公社 名所発掘100×100 選定(国民投票N票)」は、文化体育観光部・韓国観光公社の国民投票の結果で、テーマ名もあわせて記しました。水温は、気象庁の海洋気象ブイの値(8月・12月)と、民間サイトの値(それ以外の月)に分けて記しました。ショップの営業時間・価格はカカオマップのオーナー登録値(2026-11-24照会)で、登録から2年を超えた価格は「価格はカカオマップで当日確認」としました。法律の内容には条文番号をつけました。

気象庁の値(海洋気象ブイ): マラド・ソギポの海洋気象ブイの過去5年('19~'23)の日平均の範囲は、8月が27.8~28.8℃、12月が18.4~20.6℃(2地点)です。上の表の民間サイトの値と同じ範囲です。どちらもソギポ南側の海の値なので、チェジュ北側のセファ・西側のパンポは異なることがあります。

冬のウェットスーツ: 15~19℃の水は、夏用の薄いウェットスーツでは耐えにくいです。

📍 スポット4か所 — 水中の活動の根拠がある場所だけ

① パンポポグ (Panpo Port / 판포포구) — 夏のシュノーケリング (チェジュ市ハンギョン面)

韓国観光公社 名所発掘100×100 選定(国民投票53票) — 「趣向密着ナノコミュニティ」テーマ。

  • どんな場所: ビジットチェジュがシュノーケリングの名所として紹介する港です。底が砂で、水が澄んでいます。西側の他の海水浴場より水が深いです(ビジットチェジュ)。
  • 住所: チェジュ市ハンギョン面パンポ里2877-3。利用時間は「常時開放」と登録されています。
  • 設備: 駐車場・シャワー施設。韓国観光公社の観光情報の概要に、夏にパンポ里の青年会が器材を貸すと出ています。
  • 注意: 港から飛び込み・ダイビングはしないようにという案内があります。海水浴シーズンには安全要員がいるとされていますが、常時配置ではありません(ビジットチェジュ)。潮(満ち潮・引き潮)を見て入るようにという案内があり、炊事・個人用マット・テントは禁止です。
  • 冬は: パンポポグは指定海水浴場の一覧にありません。冬に素潜りで入るシュノーケリングはおすすめしません。夏に来てください。

② セファ (Sehwa / 세화) — フリーダイバーが集まるビーチ (チェジュ市クジャ邑)

韓国観光公社 名所発掘100×100 選定(国民投票54票) — 「趣向密着ナノコミュニティ」テーマ。名所発掘の推薦理由に、フリーダイバーが集まる場所として紹介されました。

  • どんな場所: オルレ20コース上にあり、セファ民俗五日市場と海女博物館のあいだのビーチです。
  • 指定海水浴場ではありません: 指定海水浴場ではないので、開場期間・救助要員の運営の案内がありません(ビジットチェジュ・韓国観光公社の観光情報)。
  • 注意: 満潮のときは砂浜が大きく狭まるか、水没します。2023年12月に訪れた感想(ブログ)の1件は、湧水(地面から湧き出る淡水)のために水がとても冷たいと書いていました。
  • 設備: 公共駐車場・トイレ。問い合わせは064-728-7783。
  • 冬は: ひとりで入る場所ではありません。夏に、仲間といっしょに行ってください。

③ ムンソム (Munseom / 문섬)一帯 (ムンソム・ソプソム・ポムソム) — ソギポ沖のボートダイビング

ムンソム: 韓国観光公社 名所発掘100×100 選定(国民投票41票) — 「趣向密着ナノコミュニティ」テーマ。同じ投票の「K-スポーツ&アドベンチャー」テーマでは400票を得ました。

  • どんな場所: ソギポ港沖の島々です。ひとりで泳いで行ける場所ではなく、ソギポ港・ボモクポグ (Bomok Port / 보목포구)側のショップのボートで出ます。オールブルー (All Blue Scuba Diving / 올블루)のカカオマップの説明には、ファンダイビングのポイントはソプソム (Seopseom / 섶섬)・ムンソム・ポムソム (Beomseom / 범섬)で、その日の天気と海の状態で決めると書かれています(2024-05登録の文言)。
  • 天然保護区域: ムンソム・ポムソムは天然記念物第421号「ムンソム・ポムソム天然保護区域」(2000-07-18指定)です。国家遺産ポータルによると公開制限地域に指定されており、管理・学術目的などで島に出入りするには国家遺産庁長の許可が必要です。島に上がることは個人にはできないと考えてください。海側の活動は、ショップが決めたポイントと日程にだけ従います。
  • 冬は: カカオマップには今週(11/24~30)の営業時間しか載っておらず、冬のボートの出航予定はありません。天気でポイントが変わったり、中止になったりすることがあります。

④ ボモクポグ (Bomok Port / 보목포구) — ムンソム・ポムソム方面の出発点 (ソギポ市)

韓国観光公社 名所発掘100×100 選定(国民投票224票) — 「K-スポーツ&アドベンチャー」テーマ。

  • どんな場所: 名所発掘の推薦理由に、ボモクポグから出発してムンソム・ポムソム一帯で泳ぎ、軟サンゴを見る場所として紹介されました。ボモク洞にダイビング・フリーダイビングのショップが何軒かあります(下のショップ一覧のジェジュ フリーダイビングスクール・ジェジュ バダン・スクーバキング)。
  • 住所: ソギポ市ボモクポ路46。トイレ・駐車場あり。
  • 注意: 韓国観光公社の観光情報に、満潮の時間を確認するようにという案内があります。

🏄 誰と — 自分の状況別に選ぶ

  • 初めてで資格がない → ショップの体験ダイビング。インストラクターが器材と入水前の教育を担当します。法律は、ショップ(事業者)に器材の着用措置と乗船前の安全教育の義務を課しています(水中レジャー法第11条第1項第4号)。
  • スクーバの資格がある → ファンダイビング。ワウダイバーズ (Wow Divers / 와우다이버스)とオールブルー (All Blue Scuba Diving / 올블루)は、スクーバのファンダイビングを資格保有者向けの商品として登録しました(ショップの規定)。資格カードとログブックを持って行きます。
  • フリーダイビングを習いたい・続けたい → ボモク洞・ソギョ洞のフリーダイビングのショップの水深トレーニング・ファンダイビング・AIDAコース。AIDAは国際的なフリーダイビングの教育団体で、AIDA1・2のように、その団体のコース名として使われます。
  • 子どもと → オールブルー (All Blue Scuba Diving / 올블루)のカカオマップの説明には、体験ダイビングは満10歳からと書かれています(2024-05登録の文言、販売者の説明)。法律は、保護者が同行しない14歳未満の人に、ショップが器材を貸したり乗せたりすることを禁じています(第21条第3項)。保護者がいっしょに行ってください。
  • ひとり旅 → 素潜りのシュノーケリング・フリーダイビングをひとりでしないでください。ショップのプログラムに入れば、インストラクターや他の参加者といっしょに入ります。

🛟 安全と法律 — 法律が定めることと、すすめることを分けて

法律が定めること — 「水中レジャー活動の安全および活性化等に関する法律」(法律第20944号、2026-04-23施行)。法律が扱う活動は、スキンダイビング・スクーバダイビングなど大統領令で定める活動です(第2条第2号)。施行令第2条は、水中レジャー活動をスキンダイビング・スクーバダイビングと定めています。素潜りのシュノーケリング・フリーダイビングがここに含まれるかどうかは、法令に定義がありません。どちらの場合でも、夜は入りません。

  1. 夜間禁止 — 日没後30分から日の出前30分までは、水中レジャー活動をしてはいけません(第13条第1項)。夜間の安全装備と安全管理要員をそろえた場合だけが例外です。違反すると100万ウォン以下の過料です(第32条第1項第2号)。ショップもこの時間に営業してはいけません(第21条第3項)。冬は日が早く沈むので、午後の予定は短めに組んでください。
  2. 天気が悪いとき — 海洋警察署長や自治体の長は、気象・海面の状態が悪くなれば、活動時間を制限するよう命じることができます(第13条第2項)。ショップには、営業時間の制限や一時停止を命じることができます(第22条)。その日ショップが出航を中止したら従ってください。
  3. 器材の着用 — 活動する人は、安全管理規定に従って人命の安全に必要な水中レジャー器材を着用しなければならず、決められた活動区域を出てはいけません(第8条)。第8条第1項は、海上交通安全法第33条第3項が定めた事項も守るよう求めています。器材の未着用・区域からの逸脱は、それぞれ50万ウォン以下の過料です(第32条第2項)。
  4. 資格はショップ側の要件です — 法律・施行令の基準では、個人に資格を求めておらず、資格の要件はショップで教える「水中レジャー教育者」の側にあります(第2条第10号、第11条第4項)。ショップは海洋警察庁長に登録しなければなりません(第15条第1項)。ワウダイバーズ (Wow Divers / 와우다이버스)とオールブルー (All Blue Scuba Diving / 올블루)は、スクーバのファンダイビングを資格保有者向けの商品として登録しました(ショップの規定)。
  5. 遠くまで出るとき — 10海里以上出る日程は、海洋警察への届け出の対象です(第12条第1項)。
  6. 許可が必要な水域 — ソギポ海洋警察署告示第2026-01号(2026-06-30)は、ソギポ港・ファスン港・ソンサンポ港の一部の海面を「海洋レジャー活動許可必要水域」と定めました(根拠: 海上交通安全法第33条第3項、同法施行令第14条第1項)。告示は、この水域で許可なくスキンダイビング・スクーバダイビングなどをしたり、許可の条件に違反したりすると、300万ウォン以下の過料が科されると案内し、許可はソギポ海洋警察署長から事前に受けるよう求めています。水域の座標と図面は告示にあります。問い合わせはソギポ海洋警察署 海洋安全課 064-793-2349。

すすめること (法律の条項ではない安全の心得)

  • ひとりで入らない。 法律の本文にバディ(2人1組)の条項はありませんが、フリーダイビング・シュノーケリングは、2人以上でお互いを見ながらします。
  • ライフジャケットや浮力の器材を使う。 とくにパンポポグ (Panpo Port / 판포포구)のような海岸のシュノーケリングで。
  • お酒を飲んだ日、体調が悪い日は入らない。 法律は、酒に酔った状態の人(第21条第3項第1号)に、ショップが器材を貸したり乗せたりすることを禁じています。
  • 潮を見る。 パンポポグ・ボモクポグ (Bomok Port / 보목포구)のどちらも、潮・満潮の時間を見るよう案内しています。

事故が起きたら119 — 政策ブリーフィング(2022-10-11)によると、海の事故もいまは119に通報します。犯罪は112です。チェジュの旅行情報の問い合わせは、チェジュ観光情報センター 064-740-6000。

⚠ よくある失敗3つ

  1. 冬に夏の計画のまま行く — 12~3月のソギポの海は、月平均で約15.7~19.2℃です(民間の水温サイト badatime 基準、ソギポ 2022~2025の平均)。パンポポグ (Panpo Port / 판포포구)のシュノーケリングの写真を見て冬に行くと、水は冷たく、海水浴場の開場期間(#1059)でもありません。
  2. 港から飛び込む — パンポポグには、港から飛び込み・ダイビングはしないようにという案内があります。水が澄んで浅く見えても、飛び込まないでください。
  3. ムンソムに降りようとする — ムンソム・ポムソムは公開制限地域なので、島への出入りには国家遺産庁長の許可が必要です。ボートダイビングは、ショップが決めたポイントでだけ行います。

⚙ FAQ 3つ

  1. 12月のチェジュの海はどうですか? — ソギポ沖の12月の水温は、マラド・ソギポのブイの5年(2019~23)の日平均の範囲で18.4~20.6℃(気象庁)です。海水浴場は閉場期間で、パンポポグ・セファには冬の救助要員の運営の案内がありません。ソギポのショップ7軒のうち5軒が、今週(11/24~11/30)の営業時間をカカオマップに表示していますが、12月以降の営業・出航の予定は載っていません。
  2. 資格なしでスクーバのファンダイビングはできますか? — ワウダイバーズ (Wow Divers / 와우다이버스)とオールブルー (All Blue Scuba Diving / 올블루)は、スクーバのファンダイビングを資格保有者向けの商品として登録しました(ショップの規定)。法律・施行令の基準では、個人に資格を求めておらず、ショップには器材の着用措置と安全教育、教育者の配置の義務があります(第11条第1項)。資格がなければ、体験ダイビングの商品が別にあります。
  3. シュノーケリングだけしたいなら、どこへ? — 夏(7~9月)にパンポポグ (Panpo Port / 판포포구)へ行きます。底が砂で水が澄んでおり、夏には村の青年会の器材貸し出しがあると、韓国観光公社の観光情報に出ています。ビーチの開場期間・設備は#1059を見てください。
