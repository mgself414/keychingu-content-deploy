⚠ 외국인 자주 실수 5가지

1. "한국 영화 = 기생충만": 한국 영화 = 봉준호 (기생충·괴물·살인의 추억) + 박찬욱 (올드보이·박쥐·헤어질 결심) + 1000만 영화 (명량·신과함께·범죄도시·암살·내부자들) + 외국인 cinephile 매니아 1번지.

2. "오스카 = 기생충만": 한국 오스카·칸 = 기생충 (오스카 4관 2020)·헤어질 결심 (칸 감독상 2022)·박찬욱·봉준호·외국인 매니아 글로벌 1번지 + #378·#404 통합.

3. "한국 영화관 = 한국어만": CGV·롯데시네마·메가박스 = 외국인 영어 자막 + KakaoMap·Naver 예매 영어 OK + 외국인 매니아 1번지·#398 통합.

4. "한국 영화 = TV만": 한국 영화 = CGV 강남·롯데시네마·메가박스·IMAX·4DX·외국인 매니아 + Klook 영화관 패키지·외국인 영어 OK 풀세트.

5. "외국인 영화 패키지 = 없음": 외국인 영화 = BIFF (#404)·JIFF·Klook·KKday·KTO 인증 + 외국인 cinephile 패키지 + #378 K-드라마·#404 페스티벌 통합.
