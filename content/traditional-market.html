⚠ 외국인 자주 실수 5가지

1. "광장시장 = 일반 시장": 광장시장 = 1905 한국 #1 시장 + 빈대떡·녹두전·육회 외국인 vlog 1번지 + 종로 5가역 (1·5호선) + 22-23시 야시장.

2. "통인시장 = 그냥 시장": 통인시장 = 엽전 (5K = 도시락 풀세트) + 도시락 카페 MZ 1번지 + 서촌 #191·외국인 매니아 + 한국 정통.

3. "광장시장 = 외국인 못 가": 광장시장 = 영어 메뉴 OK + 가성비 5~15K + Klook·Airbnb 외국인 패키지·KTO 인증·외국인 vlog 1번지.

4. "자갈치 = 부산만": 자갈치 시장 (#244) = 부산 #1 수산 + 한국 #1 신선 회 + 외국인 vlog 1번지·KTX 외곽 매니아·1박2일 풀세트.

5. "전통시장 = 환전 어려움": 외국인 = 신용카드 + KakaoPay + Naver Pay + ATM + 5만원 현금 권장·외국인 매니아 풀세트.

⚙ FAQ 6개

1. 외국인 시장 1순위: 광장시장 (외국인 vlog #1)·남대문·통인 (도시락).

🗺 외국인 풀데이 코스 3개

A. 광장·남대문 도심 시장 풀데이

  • 09:00 광장시장 (빈대떡·녹두전·육회) → 12:00 남대문 시장 (갈치조림) → 15:00 동대문 시장 (DDP·#172) → 19:00 광장 야시장

B. 외곽 매니아 1박2일 (부산)

  • Day 1: KTX 서울→부산 → 부전시장 (돼지국밥) → 자갈치 시장 신선 회
  • Day 2: 부산 1박 → 약령시 (대구 350년) → 서울 복귀

C. 한국 정통 1박2일 (전주·광주)

  • Day 1: KTX 서울→전주 (#255) → 전주 남부 야시장
  • Day 2: 광주 양동시장 (#318) → 서울 복귀

  • 봄 3~5월: 신선 채소·딸기·외국인 매니아 1순위

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (당일 + 시내 핵심 풀세트)
  • 예산: 80,000~150,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
