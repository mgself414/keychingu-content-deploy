外国人のための忠清道日帰りガイド — 公州・扶余・清州・瑞山の4方面、1日に選ぶのは1つだけ（2026年 公式基準）

ISSUE 04 · #1041 · 2026-06-08

🎯 このガイドの使い方

忠清道の4都市は互いに離れています。公州 (Gongju / 공주) と扶余 (Buyeo / 부여) はバスで近いものの、清州 (Cheongju / 청주)（忠清北道）と瑞山 (Seosan / 서산)（忠清南道の西海岸）は、公州からそれぞれかなり遠い位置にあります。以前のガイドのように「清州 → 公州 → 扶余 → 瑞山」を1日で回るのは不可能です。1日に選ぶのは1軸だけにして、2日あれば公州と扶余をセットにします。以下の時間・料金・休館日は2026-10-07に各公式サイトで確認した値で、確認できなかった項目は「未確認」と書きました。

月曜日の注意: 国立公州博物館・国立扶余博物館・百済文化団地・青南台 (Cheongnamdae / 청남대) は月曜に休みます（公式）。月曜なら、公山城・扶蘇山城・定林寺址・海美邑城・看月庵のような屋外の遺跡で組みます。

🗺 ひと目でわかる — 4方面の選び方

① 公州 — ユネスコ 熊津百済（詳細は#1043）

  • 公山城 (Gongsanseong / 공산성): 3～10月 09:00～18:00 · 11～2月 09:00～17:00。大人3,000・青少年2,000・子ども1,000ウォン。65歳以上・未就学児は無料（公式）。
  • 武寧王陵 (Muryeong-wangneung / 무령왕릉)と王陵園: 同じ時間帯、同じ料金。共通券（武寧王陵＋公山城）は大人6,000ウォン（公式）。
  • 国立公州博物館 (Gungnip Gongju Bakmulgwan / 국립공주박물관): 09:00～18:00 · 無料 · 月曜休館（振替休日なら火曜）· 1/1・旧正月・秋夕。
  • 麻谷寺 (Magoksa / 마곡사)（ユネスコ山寺 2018）: 無料 · 通年開放 · 公州総合ターミナルから770番バスで約40分（公式）。
  • 行き方: 龍山 (Yongsan / 용산) ↔ 公州駅 (Gongju-yeok / 공주역) をKTX・SRTで約1.5時間（公州市のKTXページ）。公州駅から市内へはバスかタクシー。
  • 百済文化祭 (Baekje Munhwaje / 백제문화제) 2026: 10/3～10/11、公州・扶余で同時開催（公式）。

② 扶余 — ユネスコ 泗沘百済

扶余は百済最後の都泗沘 (Sabi / 사비)です（以前のガイドが公州に「泗沘都城」と書いたのは誤りです）。ユネスコ百済歴史地区8か所のうち、5か所が扶余（扶蘇山城・官北里・定林寺址・陵山里王陵園・羅城）、2か所が公州、2か所が益山です（UNESCO公式リスト）。

  • 定林寺址 (Jeongnimsaji / 정림사지)・定林寺址博物館: 3～10月 09:00～18:00 · 11～2月 09:00～17:00 · 年中無休。博物館は無料（扶余郡公式）。百済の五重石塔が立つ場所です。
  • 扶蘇山城 (Busosanseong / 부소산성)・落花岩 (Nakhwaam / 낙화암)・皐蘭寺 (Goransa / 고란사): 同じ時間帯 · 年中無休。大人2,000・青少年1,100・子ども1,000ウォン、65歳以上は無料（扶余郡公式）。観光案内所 041-830-2880。
  • 扶余王陵園 (Buyeo Wangneungwon / 부여왕릉원)（陵山里古墳群）: 同じ時間帯 · 年中無休。大人1,000・青少年600・子ども400ウォン（公式）。
  • 国立扶余博物館 (Gungnip Buyeo Bakmulgwan / 국립부여박물관): 無料 · 月曜休館・1/1・旧正月・秋夕（公式）。閉館時刻は公式の表が曖昧なので現地で確認します。
  • 百済文化団地 (Baekje Munhwa Danji / 백제문화단지)（復元テーマパーク）: 3～10月 09:00～18:00 · 11～2月 09:00～17:00 · 月曜休館（祝日なら開館）。大人6,000・青少年4,500・子ども3,000ウォン、65歳以上は無料（公式）。041-408-7290。
  • 宮南池 (Gungnamji / 궁남지): 料金・時間は公式の掲示を未確認（屋外の池の庭園）。
  • 行き方: 扶余には鉄道がありません。ソウル南部ターミナルからの市外バス、または公州からの市外バス（所要時間は予約サイトで確認 — 公式では確認できませんでした）。

③ 清州 — 青南台（大統領の別荘）

  • 青南台 (Cheongnamdae / 청남대): 観覧 09:00～18:00（12～1月は17:00）· 発券 09:00～16:30（12～1月は15:30）· 休館は月曜（祝日なら翌平日）・1/1・旧正月・秋夕の当日。一般6,000・青少年4,000・子ども3,000ウォン · 65歳以上・7歳未満は無料 · 駐車無料（公式）。モノレール 09:30～18:00（12～13時は運休）。
  • 行き方（公式）: 車で直接入って駐車し、チケット売り場で購入します — 以前のガイドの「シャトル必須」は現在の案内にありません。公共交通の直行は公式ページになく、清州市のシティツアーバス（清州市統合予約）が代案です。住所は清州市上党区文義面青南台路646。
  • 10月の臨時休館（公式SNS 10/2）: 10/6（火）・10/12（月）。
  • 秀岩谷 (Suamgol / 수암골) 壁画村: 屋外の村なので時間・料金はありません（公式の掲示は未確認）。清州市内からバス・タクシー。
  • 五松駅 (Osong-yeok / 오송역): ソウルからKTX・SRTで五松駅へ、清州市内まではバス・タクシー。以前のガイドの「KTX清州駅」は誤りです — 清州駅 (Cheongju-yeok / 청주역) にKTXは停まりません。

④ 瑞山 — 海美邑城・看月庵

  • 海美邑城 (Haemi Eupseong / 해미읍성)（瑞山九景の第1景）: 城郭の周囲1,800m・高さ5m、朝鮮の太宗18年～世宗3年に築城、1491年完成 · フランシスコ教皇の訪問地 · 韓国観光100選（公式）。住所 瑞山市海美面南門2路143 · 041-661-8005。時間・料金は公式ページに掲示なし。
  • 看月庵 (Ganwolam / 간월암)（第3景）: 満潮なら島、干潮なら陸になる海の寺 — 公式ページが看月島の潮見表を案内しているので、訪問前に確認します。朝鮮の太祖の王師・無学大師の創建 · 夕日の名所。住所 瑞山市浮石面看月島1道119-29。
  • 龍峴里磨崖如来三尊像 (Yonghyeon-ri Magae Yeorae Samjonsang / 용현리 마애여래삼존상)（第2景）: 国宝第84号、「百済の微笑」（公式）。
  • 行き方: ソウルから高速・市外バスで瑞山ターミナル (Seosan Teomineol / 서산터미널)（所要時間は予約サイトで確認）。3か所が離れているので、瑞山からは車が現実的です。
  • 瑞山のカンジャンケジャ（ワタリガニの醤油漬け）やオリグルジョッ（牡蠣の塩辛）といった食べ物の情報は、公式観光ページで根拠を確認できなかったため、このガイドには載せていません。

⚠ よくある間違い5つ

1. 1日に2軸以上 — 清州・瑞山は公州・扶余とセットにできません。1日1軸です。

2. 月曜に博物館・青南台 — 国立公州博物館・国立扶余博物館・百済文化団地・青南台は休館です。

3. 「KTX清州駅」 — ありません。五松駅へ行きます。

4. 「泗沘」を公州と思う — 泗沘は扶余です。公州は熊津 (Ungjin / 웅진)。

5. 潮見表を見ずに看月庵へ — 満潮だと入れません。公式の潮見表を確認します。

⚙ FAQ 6

1. 初めてならどの軸？ — 公州。KTXで直行でき、英語の案内がいちばん整っています（#1043）。

2. 2日あるなら？ — 公州1日＋扶余1日。公州↔扶余はバスで移動します。

3. 車なしで青南台は？ — 公式の案内は車での進入のみで、清州市のシティツアーバスが代案です。

4. 車なしで瑞山は？ — ターミナルまではバス、その先はタクシー・レンタカーが現実的です。

5. 料金の合計は？ — 公州は共通券6,000＋博物館無料 / 扶余は4か所合わせて約9,000 / 青南台6,000。食費は別です。

6. 百済文化祭は？ — 2026年10/3～10/11、公州・扶余で同時開催（公式）。祭りの期間は公州の宿が先に埋まります。
