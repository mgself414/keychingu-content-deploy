🎯 왜 해산물 4채널 비교 가이드인가

🦐 4채널 deep dive

🏝 통영 (Tongyeong)

핵심 가치: 남해 #1 + 굴 12~3월 정통 + 도미 봄.

  • 위치: 경남 통영 (KTX 부산 후 버스 1.5h = 총 4h)
  • 시그니처: 굴 (12~3월) + 도미·농어·한치 (봄·여름)
  • 가격 anchor: 굴 10,000~25,000원/1kg + 식당 차림비
  • 외국인 친화도: ★★★★ (영문 일부)

🌊 자갈치시장 (Jagalchi)

핵심 가치: 부산 시장·종합 + MZ vlog #1.

  • 위치: 부산 중구 자갈치 (KTX 2.5h)
  • 시그니처: 회·해산물 종합 (방어 겨울·낙지·꽃게)
  • 가격 anchor: 회 20,000~60,000원/1kg + 차림비
  • 외국인 친화도: ★★★★ (MZ #1)
  • 자세히: #590 자갈치 deep dive

🌅 서해 cluster (Sorae·Ganghwa·Anmyeon·Taean)

핵심 가치: 가을 꽃게·대하 #1 + 가족 여행.

  • 위치: 인천 소래포구·강화도·태안·안면도 (서울 1~2h)
  • 시그니처: 꽃게 (9~11월) #1·대하 (10~11월)·바지락 (봄)
  • 가격 anchor: 꽃게탕 15,000~30,000원 / 대하 소금구이 25,000~50,000원
  • 외국인 친화도: ★★★ (서해 한국어)

🍴 마포·강남 간장게장 (Mapo·Gangnam Soy Sauce Crab)

핵심 가치: 간장게장 #1 + 서울 정통 + MZ 인스타 #1.

  • 추천 매장:
  • 마포 게장 골목 — 정통 #1
  • 강남·압구정 간장게장 전문점 — 정통
  • 가격 anchor: 간장게장 30,000~80,000원/1인
  • 외국인 친화도: ★★★★★ (서울·영문·MZ)

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 시기·매니아 완전 다름. 굴 = 통영 / 회 = 자갈치 / 꽃게 = 서해 / 간장게장 = 마포.

2. "통영 = 가까움": 통영 = 서울 출발 4h (KTX + 버스).

3. "자갈치 = 굴만": 자갈치 = 종합 시장 (회·해산물·방어 cross).

4. "서해 = 일반 시장": 서해 = 가을 꽃게·대하 #1 (다른 계절 ↓).

5. "마포 = 비싸기만": 마포 간장게장 = 30,000~80,000원 정통 가치 (lunch 30,000원 가능).

⚙ FAQ 8개

1. 첫 해산물 채널 = 어디: 마포 간장게장 (서울·#1) → 통영 굴 (겨울).

2. 인스타·vlog: 마포 간장게장 (#1)·자갈치 (#1)·통영 굴.

3. MZ 트렌드: 자갈치 (#1)·마포 간장게장 (#1).

4. 겨울 매니아: 통영 굴 (#1) + 자갈치 방어.

5. 가을 매니아: 서해 꽃게·대하 (#1).

6. 알레르기·임신: #873 disclaimer 참조.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

해산물 4채널 모두 식중독 주의·산낙지 질식 위험. 임신부 = 생굴·산낙지 X·익힌 것 OK. 알레르기 (갑각류·연체동물·간장) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 갑각류·연체동물 = 할랄 일부 OK·코셔 X.
  • 채식·비건: 4채널 모두 비채식.
  • 글루텐 free: 간장 양념 = 글루텐 (Tamari 대체).
