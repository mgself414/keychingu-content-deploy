外国人がよくやる5つのミス

1. T1とT2を間違える

インチョン空港は2つのターミナル — T1・T2はシャトルバスで15分の距離。航空券の確認必須。間違えるとシャトル+30分追加。T2は大韓航空・デルタ・KLM・エールフランス、T1はそれ以外。

2. 空港で両替をしてしまう

空港の両替レートはミョンドン (명동)・市内より2〜3%悪い。空港では₩50,000程度の少額両替（タクシー・交通カード用）のみにして、市内で本格両替を。ミョンドン (명동) 路上両替所 (#63参照) のレートが最良。

3. AREX直通と一般の区別がわからない

AREX直通列車 = ソウル駅 (서울역) 直行43分 ₩11,000 (予約推奨、06:00〜22:00)

AREX一般列車 = 11駅停車1時間 ₩4,500 (24時間、予約不要)

同じ路線でも時間・価格の差は明確。荷物が少なければ一般、時間優先なら直通。

4. SIMと両替を同時に済ませない

空港内でSIMカード + ₩50,000両替を一度に処理すれば時間節約。空港出口直前のSK テレコム (SK텔레콤)・KT ブース + 両替所の隣に位置。

5. タクシーの客引き・メーター不使用に注意

空港出口での客引きタクシー = 違法 (正規タクシーは列に並んでピックアップ)。一般タクシーはメーターが入っているか確認 + レシートをもらう。カカオT (카카오T) 英語版アプリが安全。

★ インチョン空港 最初の6時間フルガイド

Step 1: 飛行機到着 → 入国審査 (15〜30分)

  • K-ETA (韓国電子渡航認証) — 事前申請必須 (90カ国ビザ免除入国時) https://www.k-eta.go.kr
  • 入国申告書 機内で記入 (英語OK)
  • 外国人レーン = 一般外国人 / K-ETA保有 = ファストトラック
  • 平日早朝・週末の混雑時は30分〜1時間待ちも

Step 2: 荷物受け取り (10〜30分)

  • 航空便到着の案内板を確認
  • 荷物紛失は航空会社カウンター (英語対応) で申告
  • カート無料

Step 3: 税関通過 (5分)

  • 申告なし = グリーンライン (外国人のほとんど)
  • 免税範囲：₩800,000 + 酒類1L + タバコ200本
  • 超過時はレッドライン

Step 4: 両替 + SIM (15〜20分)

  • 両替所 = 空港出口付近に多数 (₩50,000の少額のみ推奨)
  • SIMカードブース (SK・KT・LG U+) — 1日・5日・10日・30日オプション ₩5,000〜50,000
  • eSIMオプション — 端末対応なら更に便利
  • 外国人の韓国携帯番号 → カカオT (카카오T)・デリバリーアプリ登録可

Step 5: 都心移動 (1〜1.5時間)

① AREX直通列車 (Express) — 時間優先

路線: インチョン空港 T1・T2 → ソウル駅 (서울역) 直行 (途中停車なし)

価格: ₩11,000 (大人) / 子ども ₩4,500

所要: 43分 (T2発) / 51分 (T1発)

運行: 06:00〜22:00 (30分間隔)

予約: 空港鉄道英語版アプリ・ウェブサイト / 現地発券OK

ポイント:

  • 座席指定 + 荷物は座席横に置いてOK
  • WiFi・電源コンセント完備
  • ソウル駅 (서울역) 到着後、地下鉄乗り換え + KTX乗り換えが即可能
  • 時間優先 + 1〜2人分の荷物に最適

一言: 「43分直行 = 外国人の時間優先No.1」

② AREX一般列車 — コスパ重視

路線: インチョン空港 T1・T2 → ソウル駅 (서울역) (11駅停車)

価格: ₩4,500

所要: 1時間 (T2) / 1時間7分 (T1)

運行: 24時間 (5〜10分間隔)

予約: 不要 (現地カード払いOK)

ポイント:

  • 一般地下鉄と同じ座席 — 大きな荷物は少し不便
  • キンポ空港 (김포공항)・ホンデ入口 (홍대입구)・ソウル駅 (서울역) 停車 → 地下鉄乗り換えOK
  • 早朝到着時に24時間運行が強み
  • コスパ ₩4,500 = 外国人No.1

一言: 「₩4,500 + 24時間 = コスパ・早朝到着の正解」

③ 空港バス (リムジン) — ホテル直行の便利さ

主要路線:

  • 6001番: T1・T2 → チャムシル (잠실)・カンナム (강남)
  • 6015番: T1・T2 → ミョンドン (명동)・ソウル駅 (서울역)
  • 6021番: T1・T2 → ホンデ (홍대)・シンチョン (신촌)
  • 6101番: T1・T2 → カンナム (강남)・アックジョン (압구정)
  • その他 トンデムン (동대문)・イテウォン (이태원)・ヨイド (여의도) など30路線以上

価格: ₩15,000〜17,000

所要: 1〜1.5時間 (道路状況による)

運行: 05:00〜23:00 (15〜30分間隔)

予約: 空港1階チケット売り場 + 英語アプリ (KOBUS、EZL)

ポイント:

  • ホテルまたはホテル近くに停車 = 荷物を引いて乗り換えなし
  • 荷物スペース別途あり = 大きなキャリーを持つファミリーにNo.1
  • 英語アナウンスあり
  • ホテルまで同行するファミリー・年配者にNo.1

一言: 「ホテル直行 + 荷物スペース = ファミリー・大きなキャリー持ちの正解」

FAQ

Q1. 英語は通じますか？

100%。インチョン空港は韓国で最も外国人対応に慣れた場所。案内・表示・アプリすべて英語対応。

Q2. 早朝に到着したら？

AREX一般列車24時間 = ₩4,500。またはカカオT (카카오T) タクシー24時間。早朝の両替・SIMも対応可能。

Q3. K-ETAが取れなかったら？

韓国到着後に再申請可能 (1時間以内に結果)。ただし拒否された場合は入国拒否の可能性あり → 事前申請を強く推奨。

Q4. ビザが必要な国は？

韓国ビザ免除90カ国 (米国・日本・EU・オーストラリアなど K-ETAのみ)。それ以外はビザ必要 — 韓国領事館で事前取得。

Q5. 免税範囲を超えたら？

税関申告 → 関税納付。酒類1L・タバコ200本・土産品 ₩800,000が上限。

Q6. 紛失物・申告は？

T1・T2 紛失物センター (1階) + 英語対応OK。航空便の紛失は航空会社カウンターへ。
