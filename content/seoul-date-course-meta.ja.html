ソウルデートコースガイド — 7エリアを2026年10月の公式値で：無料の美術館・ギャラリー・漢江の夜景・路地散歩

サブタイトル: 漢南のリウム美術館やペースなどのギャラリー(月曜休館) · 合井・弘大のレッドロードと京義線森の道 · 延南の散歩 · 西村・北村・三清の国際ギャラリーと国立現代美術館(月曜も開館) · 狎鴎亭・清潭の道山公園ペロタン・ホワイトキューブ · 汝矣島・漢江の遊覧船22時と盤浦の噴水19:30~20:50 — 2026-10-08時点の各公式ページ基準(#216·#285·#350·#786の事実表を再利用)。レストラン・カフェの店名は記載しません

🎯 このガイドの使い方

デートコースは「どこで何をするか」がすべてですが、以前のガイドにはエリアごとの雰囲気とペルソナの表だけがあり、開いているか・いくらかの情報がありませんでした。今回は本日(2026-10-08)に公式ページで確認できた場所だけを — 美術館・ギャラリー(#285·#350)、弘大・延南(#216)、漢江(#786)、龍山(#710) — 7エリアに配置し直しています。レストラン・カフェ・バーは公式の出典がないため名前を載せず、「地図アプリのレビュー数」に任せます。ポイントは二つ。月曜日はギャラリー・リウム・ソウル市立が休みで、国立現代美術館ソウル館と国立中央博物館だけが開いています。水・土の夜は国立現代美術館(18~21時は無料)と国立中央博物館(21時まで)が開いています。

🌆 夜・夜景 — 曜日で選ぶ

  • 水・土: 国立現代美術館ソウル館が18~21時無料 → 国立中央博物館は21時まで → 盤浦の噴水3回(19:30~20:50、2026年は節電運営)。
  • 金・土: ソウルダルは23時まで · 汝矣島の遊覧船は22時のスターライト(25,900ウォン)。
  • 月曜日: ギャラリー・リウム・ソウル市立は休館 → 国立現代美術館ソウル館 + 国立中央博物館 + 漢江へ。
  • ソウル世界花火祭り(9/5)と漢江のプール(~8/30)は今年はもう終わっています(#786)。

🖼 昼 — 歩くコース二つ

  • 三清ギャラリー散歩(火~土): 安国駅 (Anguk / 안국역) 1番出口 → 国立現代美術館ソウル館 → 国際ギャラリー (Kukje Gallery / 국제갤러리)・PKM・アラリオ(無料の表記なし、たいていは無料) → ミュージアムハンミ (Museum Hanmi / 뮤지엄한미)(15,000ウォン) → ソウル工芸博物館 (Seoul Gongye Bangmulgwan / 서울공예박물관)(無料)。10月の展示は#285を参照。
  • 漢南ギャラリー散歩(火~土): 漢江鎮駅 (Hangangjin / 한강진역) 1番出口のリウム(常設展は無料) → 梨泰院路のペース・リーマンマピン → 独書堂路のロパク → 新龍山のAPMA(予約制)。10/9(ハングルの日)はペースとエスター・シッパーが休館です。

🌳 散歩 — お金がかからない二つ

  • 京義線森の道 延南区間: 弘大入口駅3番出口から447m、全長6.3kmの線形公園、無料(VisitSeoul)。
  • 盤浦漢江公園: 新盤浦駅1番出口・高速ターミナル駅8-1出口、24時間無料、夜の噴水は3回。

🍽 レストラン・カフェがない理由

  • どの公式ページも、特定のレストランやカフェをデートコースとして指定していません。お店は地図アプリのレビュー数と当日の営業状況で選んでください。このガイドは「どの駅・どの通りか」までを記します。

⚠ よくある間違い5つ

1. 月曜日に漢南・三清のギャラリーデート — すべて休館です。国立現代美術館ソウル館か国立中央博物館へ。

2. 盤浦の噴水を21時の回で計画 — 2026年は19:30・20:00・20:30の3回です。

3. 遊覧船の料金を2万ウォンと思い込む — ムーンライトは32,900ウォン、花火は45,900ウォンです。

4. APMAに現地でそのまま入場 — オンライン予約が必要です。

5. ペロタン・ホワイトキューブを漢南で探す — 場所は清潭の道山公園です。

⚙ FAQ 6つ

1. 初デートのコースは? — 水・土: 安国駅の国立現代美術館(18時から無料) → 三清で夕食 → 漢江の噴水19:30。

2. 無料だけで回るなら? — 京義線森の道 → 弘大レッドロードのバスキング → 盤浦の噴水。すべて無料です。

3. 雨の日は? — 国立現代美術館・国立中央博物館・リウムの常設展(無料)。#280を参照。

4. 記念日の夜は? — 遊覧船ムーンライト19時(32,900ウォン)かスターライト22時。

5. 月曜日は? — 国立現代美術館ソウル館 + 国立中央博物館 + 漢江。

6. レストランのおすすめは? — このガイドにはありません。地図アプリのレビュー数で選んでください。
