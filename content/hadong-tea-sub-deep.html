하동 화개·야생차박물관 12선

1. 하동 (한국 차 1200년 발상지)

  • 차별: 신라 흥덕왕 828년 첫 차 재배·한국 차 1200년 발상지·화개 쌍계사 인근 차나무 시비
  • kr cross: #675 전통차·#676 보성 sub

2. 하동야생차박물관 (2017 신규 개관)

  • 차별: 2003 차문화전시관 → 2017 야생차박물관 재개관·하동 차 풀세트·다실 다례 체험 무료
  • 운영: 09:00-18:00·월 휴무·입장료 1,000원
  • 체험: 전통차 만들기·하동녹차 다례 (무료)·체험관 보조 도구
  • 외국인 fit: ★★★★★ EN·JP 매니아·다례 무료 1순위

3. 쌍계사 (한국 차나무 시비)

  • 차별: 신라 723년 창건·삼법화상·한국 #1 차나무 시비 (한국 차 발상지 기념비)·불교 사찰
  • 외국인 fit: ★★★★ EN·JP 정통 매니아·#509 사찰 cross

4. 하동 화개장터 (5일장)

  • 차별: 하동 정통 5일장 (1·6일)·조영남 노래 화개장터·섬진강 변 매니아
  • 시그니처: 재첩국·다슬기·산나물·녹차
  • 외국인 fit: ★★★★ EN·JP 정통 매니아·#380 시장 cross

5. 십리벚꽃길 (한국 #1 벚꽃길)

  • 차별: 하동 화개 ~ 쌍계사 4km 벚꽃길·한국 #1 십리벚꽃길·4월 첫째 주 절정·1928년 식재
  • 외국인 fit: ★★★★★ EN·JP·CN MZ·SNS 봄 1순위

6. 하동 야생차문화축제 (5월)

  • 차별: 매년 5월·하동 #1 차 축제·다례 + 차 만들기 + 다식 체험·문화관광축제 지정
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·#675 cross

7. 화개 야생녹차 시그니처 (수제·소량)

  • 차별: 하동 야생녹차 = 손 채엽 + 9번 덖음 정통·보성 vs 하동 차이: 보성 = 평지 재배·하동 = 산지 야생
  • 시그니처: 화개 우전·해발 600m+ 야생차 100,000원~/100g
  • 외국인 fit: ★★★★ EN·JP 매니아·기념품 1순위

8. 청학동 + 삼성궁 (정통 도가·풍수)

  • 차별: 청학동 = 한국 #1 정통 마을·삼성궁 = 한국 정통 도가 사찰·전통 의복·풍수
  • 외국인 fit: ★★★★ EN·JP 정통 매니아 1순위

9. 지리산 국립공원 (한국 #1 hiking)

  • 차별: 한국 #1 국립공원 1967·지리산 1915m·천왕봉 + 노고단 풀세트·하동 화개 인근
  • 외국인 fit: ★★★★ EN·JP hiking 매니아·#511·#539 cross

10. 섬진강 + 평사리 (소설 토지)

  • 차별: 박경리 소설 "토지" 배경·최참판댁 + 평사리 들녘·섬진강 자전거길
  • 외국인 fit: ★★★ EN·JP 정통 매니아·#510 day-trip cross

11. 하동 1박 2일 + 쌍계사 1박

  • 접근: 서울 → 하동 KTX (구례구역) 약 3시간·서울 → 하동 버스 5시간 30분
  • 시티투어: 쌍계사-야생차박물관-화개장터-십리벚꽃길 풀 day / 6만원
  • 외국인 fit: ★★★★ EN·JP 1박 추천 (쌍계사 템플스테이 OK)

12. 하동 + 보성 + 광주 차 cluster (3 도시 1박 2일)

  • 차별: 한국 차 정통 풀세트 (1200년 발상지 하동 + #1 차밭 보성 + 광주 인근)·KTX 1일 cluster OK
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아·차 정통 1순위·#675·#676 cross

FAQ 6

Q1. 하동 vs 보성 차이? A. 하동 = 1200년 발상지 + 산지 야생녹차 (해발 600m+)·정통 매니아·보성 = #1 차밭 + 평지 재배·관광 매니아 1순위.

Q2. 야생차박물관 입장료? A. 성인 1,000원·09:00-18:00·월 휴무·다례 체험 무료.

Q3. 십리벚꽃길 시기? A. 매년 4월 첫째 주 절정·약 1주·4km 산책로.

Q4. 쌍계사 입장료? A. 성인 4,000원·08:00-18:00·한국 차나무 시비 매니아 1순위.

Q5. 하동 야생차문화축제? A. 매년 5월·문화관광축제·다례 + 차 만들기 풀세트.

Q6. 보성 + 하동 + 광주 cluster? A. KTX 1박 2일 OK·하동 → 보성 (구례구역 환승 약 1시간) → 광주 (KTX 1시간).
