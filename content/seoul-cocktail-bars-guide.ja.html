🍸 エリア別 — 何を飲むか (公式プロフィール基準)

  • 江南 島山大路の4軒: ゼスト (Zest / 제스트) はゼロウェイストで、ハルラボン (Hallabong / 한라봉) や旧左のニンジンを使った「済州ガリバルディ」、オメギ酒 (Omegisul / 오메기술) のギブソンが名物です。アリス (Alice / 앨리스) はスピークイージーで、シグネチャーはHippity Hoppity(ジン・アイスワイン・キウイ・椿・ディル)とDid I Melt?。ル・シャンブル (Le Chamber / 르 챔버) は本棚を引いて入る入口、ウイスキー約200種、ハードカバーの本のメニューが特徴で、Time Out(二次情報)によると毎日19:30〜04:00、狎鴎亭ロデオ駅 (Apgujeong Rodeo Station / 압구정로데오역) 4番出口です。エムプラスエムエスバー (M+MS Bar / M+MS 바) は住所のみ確認しました。
  • 鍾路の韓屋・ホテル3軒: バーチャム (Bar Cham / 바 참) は西村 (Seochon / 서촌) の韓屋バーで、地方の伝統酒で作るカクテル(トドク (Deodeok / 더덕) ネグローニなど)が楽しめます。コンガン (Gong Gan / 공간) は中庭のある韓屋で、幼い頃の記憶から着想したカクテルを出します。チャールズH (Charles H / 찰스 H) はフォーシーズンズ ソウルの地下にあり、ベルベットマティーニ(ハルラボン)とココナッツグローブが名物です。
  • 漢南の1軒: ソコ (Soko / 소코) は、ドライマティーニ、ピーナッツウイスキーカクテルのMr. Peanut、1920年代風のクラシックが魅力です。
  • 以前のガイドにあったクリケット・エレメンツ・ポム・アンチドート・ノッツ・キオスク・Hバー・ファイン&コー・コブラー (Cobbler / 코블러) は、今回の公式リストにない、または主張の出典が見つからなかったため、表から外しました。

🌙 夜の移動・ルール (公式)

  • お酒は19歳未満への販売禁止で、身分証の提示を求められることがあります(青少年保護法 (Youth Protection Act / 청소년보호법))。地下鉄は約05:30〜深夜0時(VisitSeoul)。タクシーの深夜料金は、一般の23〜02時が140ウォン/131m、22〜23時・02〜04時が120ウォン/131mです(VisitSeoul料金表)。観光案内は1330です。
  • 予約・ドレスコード・カバーチャージは公式プロフィールに記載がありません → バーの公式チャンネルで確認してください。

🗺 2つのコース

  • A 鍾路の韓屋バー: 西村 (Seochon / 서촌) のバーチャム → 安国 (Anguk / 안국) のコンガン → 光化門 (Gwanghwamun / 광화문) のチャールズH(ホテルなので遅い時間でも探しやすい)。
  • B 島山大路の4軒: 狎鴎亭ロデオ駅4番出口 → ル・シャンブル・ゼスト・アリス・エムプラスエムエスバーが島山大路55キル・49キルに集まっています(徒歩で移動)。

⚠ よくある間違い5つ

1. 2025年の順位を期待する — バーチャム6位→33位、ル・シャンブル50位→88位。

2. コブラーを延禧洞で探す — 公式住所は鍾路の社稷路12キル(今回のリストには未掲載)。

3. 営業時間を決めつける — 公式プロフィールは曜日のみ。時間はバーのチャンネルで。

4. カクテルの価格をウォンで決めつける — リストはUSDの平均のみ(バーチャム17〜ル・シャンブル25)。

5. 身分証なしで行く — 19歳確認の対象になり得ます。
