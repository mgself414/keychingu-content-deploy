首尔雪橇场指南——从6,000韩元的汉江雪道到主题乐园免费雪橇,第一次看雪的家庭需要的费用·日期·地铁出口

副标题: 汉江三处雪橇场(纛岛·蚕院·汝矣岛)全年龄6,000韩元且含轮胎雪橇,每天13~14点因整雪停开(首尔市官方) · 儿童大公园SLP儿童会馆雪橇场15,000韩元 · 首尔乐园·爱宝乐园只要买门票,雪橇免费(二手来源) · 芦原·瑞草等区立雪橇场2,000~8,000韩元——日期·费用以2025-26季公告为准,2026-27季请看12月公告

ISSUE 03 · #1416 · 2026-10-19

🎯 本篇回答的问题

"孩子从没见过雪,在首尔能坐雪橇吗","不想跑到滑雪场,半天能玩完吗"——来自东南亚·台湾·香港的家庭旅客每年冬天都在问。答案是"能,而且便宜"。首尔市在汉江 (Hangang / 한강) 沿岸三处公园堆出人造雪道,各区政府在大学操场和游泳池场地搭起临时雪橇场,郊外的主题乐园则让入园者免费滑雪橇。本篇把9处的费用·日期·地铁出口汇成一张表,并补上面向外国人的攻略里总是漏掉的两条规则——整雪时间和免费入场的证明。

⚠ 日期·费用以2025-26季(2025年12月~2026年2月)公告为准。雪橇场每年12月上旬~中旬公布当季运营计划,预告的开场日也可能往后推。2025-26季汉江雪橇场原预告12月19日开场,实际12月31日才开。出发前请打开下方SOURCES里的首尔市冬季指南页面确认一次。

① 汉江雪橇场三处——首尔市直营的基本款

三处规则相同。以下照搬首尔市公告(2025-26)。

  • 期间·时间: 2025-12-31~2026-02-18、50天无休 · 每天10:00~17:00(汝矣岛在首尔市指南页上也写作09:00开始,来源冲突——想早到请到现场确认)
  • 整雪时间: 每天13:00~14:00整理雪面,雪道不能滑。把午餐安排在这一小时就不吃亏
  • 费用: 全年龄一律6,000韩元。含轮胎雪橇租用·雪地游乐园 (nunnori-dongsan / 눈놀이동산) ·休息区使用,雪橇不另收租金
  • 免费·优惠: 36个月以下凭出生日期证明免费(出于安全不能坐雪橇) · 65岁以上·残障人士·国家功勋者·首尔多子女卡 (Dadungi Card / 다둥이카드) 持有者凭证明半价。首尔市公告所列的证明是居民登记誊本·医疗保险证之类的文件,截图照片不行——外国孩子的护照原件是否被认可,公告里没写,请先打电话或到现场确认,不行的话就按付6,000韩元来计划
  • 雪道: 大雪道80米(6岁以上~成人) · 小雪道30米(36个月~6岁) · 幼儿雪地游乐园
  • 安全: 三处都设医务室(配自动体外除颤器)

2025-26季三处都以啵乐乐 (Pororo / 뽀로로) 为主题布置: 纛岛"啵乐乐世界雪节",汝矣岛"露比 (Loopy / 루피) 与雪花派对",蚕院"白雪覆盖的啵乐乐森林村"。以汝矣岛为例,11:00有角色巡游,12:30·14:30有合唱秀,帐篷美食区卖拉面 (ramyeon / 라면) ·炒年糕 (tteokbokki / 떡볶이) ·杯饭 (cup-bap / 컵밥) ·热狗·三明治。行李寄存5,000韩元(提供啵乐乐布袋),抓公鱼 (bingeo-japi / 빙어잡이) ·迷你海盗船等收费项目在4,000~7,000韩元区间(二手)。

各处怎么去(首尔市媒体中心实测)

  • 纛岛: 7号线紫阳(纛岛汉江公园)站2号出口 → 步行5分钟。这个站2024年2月由纛岛游园地站 (Ttukseom Yuwonji Station / 뚝섬유원지역) 改名而来,是同一个站——首尔市指南页上的"纛岛游园地站2号出口"就是同一个地方,在地图App上搜哪个名字都可以。咨询 02-452-5955
  • 蚕院: 3号线蚕院站4号出口 → 步行20分钟。三处里最远。推婴儿车·带小孩的话,纛岛·汝矣岛更方便。夜间延长至20点: 12/31起到1月上旬每天,之后周六·周日·公休日——夜间日期各来源写法不一,出发前确认。咨询 02-536-8263
  • 汝矣岛: 9号线国会议事堂站1号出口 → 步行15分钟。位于汝矣岛汉江公园游泳池场地(第3停车场旁)。咨询 02-785-0478

门票: 在现场售票处买。能否刷卡这次没能确认——带一点现金。

② 儿童大公园SLP儿童会馆雪橇场——连抓公鱼一起打包

  • 费用: 雪橇场门票15,000韩元 · 抓公鱼体验券6,000韩元(提供捞网·鱼桶)
  • 期间: 2025-12-21~2026-02-23(首尔市SLP介绍页)、视天气变动。首尔市冬季指南主页写的是12/20~3/2,两个官方页面的期间不同。运营时间公告也没写,请电话确认(1800-5309)
  • 雪道: 初级·高级2条。36个月以下不能用高级道,36个月以上7岁以下只能用初级道
  • 怎么去: 7号线儿童大公园站2号出口
  • 比汉江贵2.5倍,但附带抓公鱼,而且儿童大公园本身免费入园,动物园·游乐场可以填满半天

③ 主题乐园两处——买了门票,雪橇就免费

  • 首尔乐园雪乐园(果川): 120米一般雪道 + 50米幼儿雪道,约8,500平方米。雪橇场·雪地游乐场对首尔乐园所有入园者免费,抓公鱼另收费、现场先到先得。2025年12月下旬开场(报道里只写"最近开场",未能确认确切日期),公告未写结束日(通常到2月)。4号线大公园站2号出口搭大象列车(收费)或步行(Newsis 2025-12-29 [二手])
  • 爱宝乐园Snow Buster(龙仁): 12月12日赛道·Snow Yard,12月19日雪地游乐场(雪滑梯·身体滑道·打雪仗靶子·木雪橇)分阶段开放。200米Express赛道(圆形轮胎,最多4人)按报道时点预定"下个月初"(1月初)启用,会随天气变动。爱宝乐园入园者免费,通常到2月中旬。龙仁轻轨爱宝乐园站有免费接驳车(Herald经济 2025-12-10 [二手])
  • 两园门票价格每年变动,面向外国人的折扣商品也多,本篇不写金额。请到官网确认

④ 区立雪橇场——居民免费,旅客付"其他人"价

各区政府在冬天运营一个多月的临时雪橇场。比汉江便宜或免费,但期间短,周一休息的多。

  • 芦原嗖嗖雪橇场: 首尔科学技术大学综合操场。2025-12-23~2026-01-25、10~17点。成人雪道90米7条赛道·儿童雪道50米5条(自动出发台)。芦原区居民免费,其他人3,000韩元。抓公鱼·烤栗子 (gunbam / 군밤) ·欧式蹦极。1月因大学入学考试休场两天——日期各来源不一,出发前确认(首尔新闻 2025-12-08 [二手])
  • 瑞草良才川冬季雪乐园: 良才川游泳池。2025-12-20~2026-02-22,周二~周日10~17点,周一·春节 (Seollal / 설날) 当天(2/17)休息。瑞草区居民6,000韩元,其他人8,000韩元。成人·幼儿雪道,蹦床·幼儿充气城堡·抓公鱼·冰壶·小卖部(Herald经济 2025-12-17 [二手])
  • 道峰冬季雪乐园: 1号线道峰站附近成均馆大学棒球场场地(道峰路168街30号,2024-25为准 [二手])。2024-25季12/27~2/2,周二~周日10~17点,道峰区居民免费·其他人2,000韩元,碰碰车·小火车·抓公鱼。2025-26季是否运营没能确认——道峰区公告发布之前不要排进行程(首尔市媒体中心 2025-01-21)
  • 居民价以居民登记为准,旅客全部付"其他人"价。即便如此,2,000~8,000韩元也与汉江相同或更便宜

⑤ 半天路线3案

A. 纛岛(东侧,瞄准开场)

10:00 紫阳(纛岛汉江公园)站2号出口 → 步行5分钟 → 纛岛雪橇场(刚开场排队短) → 12:50滑完 → 13:00~14:00整雪时间在美食区吃拉面 → 14:00再滑一轮,或紫阳(纛岛汉江公园)站 → 7号线1站 → 建大入口站 (Konkuk University Station / 건대입구역) 美食街·Common Ground

B. 汝矣岛(西侧,结合室内避寒)

10:30 国会议事堂站1号出口 → 步行15分钟 → 汝矣岛雪橇场 → 11:00巡游 → 13:00整雪时间吃午饭 → 14:30合唱秀 → 汝矣岛站 (Yeouido Station / 여의도역) → 到与汝矣岛站地下相连的The Hyundai Seoul取暖。巡游·表演时间以2025-26季啵乐乐主题为准,请在2026-27季公告里再确认

C. 儿童大公园(两个以上孩子)

10:00 儿童大公园站2号出口 → SLP儿童会馆雪橇场 → 抓公鱼 → 儿童大公园动物园·游乐场(免费) → 7号线1站 → 建大入口站

⑥ 穿着·准备·现场规则

  • 防水裤·手套·防水鞋: 轮胎雪橇会把裤子弄湿。带一双备用袜子和暖宝宝 (hot pack / 핫팩) (便利店1,000~2,000韩元)。防寒整体准备见 #1318
  • 年龄标准: 大雪道6岁以上,36个月以下禁止坐雪橇(只能免费入场)。小雪道也要监护人陪同
  • 13~14点: 汉江三处因整雪停开。当作午餐时间
  • 拥挤: 周末下午队很长。平日或刚开场更好
  • 天气: 人造雪,不下雪也开。下雨·强风·寒潮预警时可能缩短·中止,请看当天公告

⚠ 实际会踩的坑5个

1. 13点到达——正是整雪时间,要等一小时。瞄准10点或14点。

2. 从蚕院站走20分钟——推婴儿车·带小孩很吃力。选纛岛(5分钟)·汝矣岛(15分钟)。

3. 36个月以下免费只在有证明时——公告的证明是誊本·医疗保险证,外国护照能否通用要到现场确认。不行的话就付6,000韩元。

4. 区立雪橇场的"免费"只限居民——旅客付2,000~8,000韩元。

5. 相信预告的开场日来排行程——2025-26季汉江预告12/19 → 实际12/31开场。12月中旬出行的人出发前再看一次公告。

⚙ FAQ 3

1. 不下雪就不能滑吗?——人造雪,没关系。2025-26季汉江三处50天无休开放。

2. 大人也能滑吗?——大雪道从6岁到成人都可以,费用全年龄相同。

3. 想滑冰去哪?——首尔广场滑冰场 (Seoul Plaza Skating Rink / 서울광장 스케이트장) 1次1小时1,000韩元(含头盔·冰鞋租用,2025-12-19~2026-02-08,首尔市官方)。雪景·溜冰场见 #1319。
