🎯 このハンドブックの読み方 — タグ3種

韓国で外国人が戸惑う瞬間のほとんどは「知らないから」ではなく、「間違っているとすら知らなかったから」起きる。パンチャン (Banchan / 반찬) をもっとくださいと言っていいのか、バスにコーヒーを持って乗っていいのか、地下鉄のピンク色の座席に座っていいのか — 答えはすべて違う。だからこのハンドブックは項目ごとにタグを付ける。

  • [規定] — 法律・条例・公式ポリシー。破ると過料が出るか、拒否される。根拠は一番下のSOURCESに。
  • [慣習] — 法律ではないが、ほぼ全員がそうしている。しないと目立つ。
  • [任意] — やると印象がいいが、しなくても構わない。現地の人のように見せたいときだけのヌンチ (Nunchi / 눈치) 感覚だ。

各項目末尾の #番号 は、その状況を画面・動作レベルまで分解したパニックゼロマニュアルだ。この一枚は地図で、マニュアルは道案内だ。

⚠ 2026年9月時点: [規定]のうち2つは今まさに変わりつつある — カフェの紙コップ規制再導入(検討中、施行時期未定)と漢江公園 (Hangang Park / 한강공원) の禁酒区域指定(ソウル市議会係留中)。以下の本文には「変更中」と表示し、公開から1年以内に再確認する。

① 飲食店 — 8項目

韓国の食堂の基本は「店員をあまり呼ばないシステム」だ。箸は引き出し、水は浄水器、パンチャンはお代わり自由、会計はカウンター。客が動く代わりに速くて安い。この構造さえ分かれば、食堂の半分はもう分かったようなものだ(#1168)。

  • 箸・ナプキン [慣習] — まずテーブル横の引き出しを開けてみる。なければ容器に立ててある。
  • 店員の呼び方 [慣習] — テーブルの上の呼び出しベル。ベルがない店では大声で呼ばず、"チョギヨ" (Jeogiyo / 저기요) のひと言で十分だ。
  • 水・パンチャンはセルフ [慣習] — 壁に「水セルフ・パンチャンセルフ」の表示があれば自分で取りに行く。セルフでない店ではベルを押す。
  • パンチャンのお代わり [慣習] — ほとんど無料だ。空いた皿を見せるか、"パンチャン ド ジュセヨ" (Banchan deo juseyo / 반찬 더 주세요) と言う。全部食べきらなければいけないというルールはない。
  • 会計 [慣習] — カウンターでの後払いが基本、キオスクでの先払い・テーブルオーダーが増えている。テーブルでカードを渡す店は例外に近い(#1275)。
  • チップ [慣習] — ない。サービス料込みの店でも追加のチップは不要だ。
  • 食べ残し [任意] — 持ち帰りを頼める店が多い。ひとこと: "ナムン ゴ ポジャンヘジュセヨ" (Nameun geo pojanghae juseyo / 남은 거 포장해 주세요)。
  • 焼肉店 [慣習] — 店員が鉄板を替えたり肉を切ったりするのはサービスだ。はさみは普通の道具(#1290)。

② カフェ — 5項目

  • 席取り [慣習] — 注文前に上着・本・かばんで席を取るのが普通だ。財布・スマホまで置く人もいるが、旅行者は真似しないこと。
  • カップ [規定] — 店内で飲むなら使い捨てプラスチックカップの代わりにマグ・グラスで出される。テイクアウトなら使い捨て。紙コップは2026年現在は任意だが、規制再導入が検討中のため店舗ごとに異なることがある — 変更中。
  • 振動ベル [慣習] — ベルが鳴ったら受け取りカウンターで自分で受け取り、ストロー・ナプキン・水はセルフコーナーで(#1288)。
  • 長時間滞在 [慣習] — 1人1ドリンクが暗黙のルール(慣習)だ。コンセント席でパソコンを何時間も広げるのは、いい店とだめな店がある[任意] — 案内表示が答えだ。
  • 返却台 [慣習] — 飲み終わったカップとトレーは返却台(Return)に自分で持っていく。氷・残った飲み物・カップ・ストロー・蓋を区画ごとに分ける(#1276)。

③ 公共交通 — 9項目

  • 妊婦配慮席 [慣習] — ピンク色の座席は空いていても空けておくのが不文律だ。法的に座ってはいけない席ではないが(過料なし)、現地の人のほとんどが空けておく。
  • 交通弱者席 [慣習] — 車両両端の座席も同じだ。電車が混んでいても立っている方が自然だ。
  • リュック [任意] — 満員の地下鉄では前に抱えるか、手に持ち直す。
  • 通話・音 [慣習] — イヤホンなしで動画を流したり、大声で通話したりする人は「ヴィラン(悪役)」と呼ばれる(#1169)。通話は短く小さな声で。
  • バスの飲み物 [規定] — ソウル市内バスは蓋のないテイクアウトカップ、匂いの強い食べ物を持って乗車できない(ソウル市条例、2018年施行)。運転手が乗車を拒否することがある。蓋を閉めたタンブラー・密閉容器は可。
  • 地下鉄の食べ物 [慣習] — バスのような禁止条例はない。ただし匂いの強い食べ物は誰も食べない。
  • エスカレーター [慣習] — 現場では右側一列、左側は歩く人が慣習だ。公式には安全のため二列で立つことが推奨されているが、強制ではない — 周りに合わせて立てばいい。
  • バスの降車 [慣習] — ベルを押して後ろのドアから降り、カードをもう一度タッチする(乗り換え割引)(#1271)。
  • タクシー [慣習] — ドアは手で開け閉めする(自動ドアではない)。助手席に乗ってもいい。チップなし、お釣りはそのまま受け取る(#1273)。

④ 街・公共の場 — 7項目

  • ゴミ箱 [慣習] — 通りにはほとんどない。持ち歩いて、地下鉄駅の分別回収箱・コンビニのゴミ箱(購入客用)に捨てる(#1276)。
  • 喫煙 [規定] — バス停周辺10m・指定禁煙区域(ソウル基準)での違反は過料(最大10万ウォン)。それ以外の通りでの喫煙は規定の対象外だが、喫煙ブース・区域を使うのが慣習(#1330)。
  • 通行 [任意] — 階段・通路に右側通行の矢印があれば従う。
  • 公園での飲酒 [慣習・変更中] — 漢江公園でビールを飲む"チメク" (Chimaek / 치맥)は2026年9月現在は可能だ。ただしソウル市が禁酒区域指定を推進中(市議会係留)で、今後変わる可能性がある。騒音・ゴミは別問題だ。
  • ノーキッズゾーン・ノーペットゾーン [慣習] — 入口の表示をまず見る。あれば子供・ペット同伴での入店はできない。賛否のある制度だが、店の方針は尊重する。
  • エレベーター [慣習] — 閉ボタンをすぐ押すのは失礼ではなく基本動作だ(#1143 パリパリ精神)。
  • 黄砂・微細粉塵 [任意] — 春・冬の「悪い」日のマスクはよく見る光景だ。アプリ(エアコリアなど)で確認する。

⑤ 宿 — 6項目

Airbnb・ゲストハウス・韓屋ステイの初日の夜に戸惑いが集中する。案内文があれば、案内文がこのハンドブックより優先される。

  • 靴 [慣習] — 玄関で脱いで室内用スリッパに。オンドル (Ondol / 온돌) の宿・座敷式の食堂共通(#1141)。
  • ボイラー [慣習] — 壁パネルの[ 暖房 ]・[ 給湯 ]・[ 外出 ] 三つのボタンが要だ。お湯が出なければまず給湯モードを確認し、床が熱すぎれば暖房温度を下げる。
  • ゴミ [規定] — 一般ゴミはチョンリャンジェ (Jongnyangje / 종량제) 袋にのみ捨てる。袋はコンビニ・スーパーで売っており、価格と生ゴミの排出方式は自治区ごとに違うので宿の案内が優先だ。
  • 生ゴミ [規定] — 一般ゴミと分別する。専用袋・回収容器・RFID計量器のうち、宿が使っている方式に従う。
  • 騒音 [任意] — 夜10時以降は廊下・足音・洗濯機に注意する。アパート型の宿は階下への騒音に敏感だ。
  • トイレットペーパー [慣習] — 2018年以降はほとんどが便器に流す。古い建物に「ゴミ箱に捨ててください」という案内が貼ってあれば、それに従う(#1277)。

⑥ 飲み会の5つの所作 — ひとまとめ

会食・焼酎文化の「なぜ」は#1140にある。旅行者が実際に使う所作は五つだ。

1. 杯は両手で受け取る(片手なら、もう片方の手を肘に添える)。

2. 注ぐときも両手で、瓶のラベルは上向きに。

3. 年上の人の前では顔を少し横にそむけて飲む — 大げさにする必要はない。

4. 空いた杯にだけ注ぐ。残っている杯には注ぎ足さない。

5. これ以上飲めないときは杯を満たしたままにしておけばいい — "ケンチャナヨ" (Gwaenchanayo / 괜찮아요) のひと言。無理強いは以前よりずっと少なくなった。

⑦ 会話 — 3行

  • 名前を知らない相手は"サジャンニム (Sajangnim / 사장님)・イモニム (Imonim / 이모님)・チョギヨ"と呼ぶ。初対面の人が年齢を聞くのは呼び方を決めるためであって、失礼ではない(#1150)。
  • 敬語・タメ口は外国人に期待されていない。短い挨拶と笑顔で十分だ。
  • 直接的な表現を避ける「ヌンチ」がある(#1145) — "グルッセヨ" (Geulsseoyo / 글쎄요)はたいてい「いいえ」の意味だ。

⑧ ショッピング・決済 — 3項目

  • 現金 [慣習] — ほとんど必要ない。市場・一部の老舗・バスの現金乗車不可などは#1301。
  • セルフレジ [慣習] — コンビニのセルフレジ・深夜の無人店舗はカードタッチで入店(#1306)。
  • タックスリファンド [規定] — 即時還付の店舗と空港のキオスク(#1304)。

⑨ 写真・寺院 — 3項目

  • 店内・人 [慣習] — カフェ・市場の商品・店員・他の客は先に聞く。自撮りは自由。
  • 撮影禁止区域 [規定] — 軍事施設・空港の保安区域・一部の美術館展示室は表示に従う。本堂内部は撮影禁止のところが多い。
  • 寺院でのマナー [慣習] — 本堂前で靴・帽子を脱ぐ、静粛に(#1186・#1137)。

🙆 しなくてもいいこと7 — 過剰マナーの解消

1. チップ — ない。

2. タクシーのドアを開けてもらう — 運転手も開けてくれない。各自手で。

3. 深いお辞儀 — 軽い会釈で十分。観光客に大きなお辞儀を期待する人はいない。

4. パンチャンを全部食べきる — 残してもいい。残すのが普通だ。

5. 杯を空にする — 一気飲みは義務ではない。

6. 飲食店の予約電話 — アプリ・タブレット・現地待ちが基本(#1274)。電話が通じなくても行けない店というわけではない。

7. 完璧な敬語 — 外国人には期待されていない。「ありがとうございます」のひと言で十分だ。

⚠ よくある間違い5

1. ピンクの座席に座る — 空いていても空けておく。座っていると視線が集まる。

2. 蓋のないコーヒーを持ってバスに乗る — ソウルは条例で拒否されることがある。蓋を閉めるか、飲み終えてから乗る。

3. 禁煙区域・バス停10m以内での喫煙 — 過料。喫煙ブースを探す(#1330)。

4. チップを置いて出る — 店員が追いかけてきて返す。感謝は"チャル モゴッスムニダ" (Jal meogeosseumnida / 잘 먹었습니다) で伝える。

5. 宿のゴミを適当な袋に出す — 従量制の袋でなければ回収されない。

⚙ FAQ 5

1. [規定]だけ守ればいい? — 罰金は規定からしか出ない。ただし「現地人らしさ」は[慣習]で分かれる。[任意]は選択制だ。

2. バスにタンブラーは? — 蓋を閉めたタンブラー・保温ボトル・密閉容器は可。ストロー付きの缶・蓋のないカップが問題になる。

3. エスカレーターの左側に立ったら? — 後ろから歩いてくる人が待つことになる。ルール違反ではないが、右側に立つ方が気楽だ。

4. 漢江でビールを飲んでもいい? — 2026年9月現在は可能。禁酒区域指定が推進中なので、訪問時点の表示を確認する。

5. カフェでマグカップに入れてくれたけど持って出たいときは? — カウンターで言えば使い捨てカップに移してくれる。
