🎯 本手册阅读方法 — 3种标记

外国人在韩国慌张的瞬间，大多不是因为"不知道"，而是因为"不知道自己错了"。能不能多要一份小菜、能不能带着咖啡上公交车、能不能坐地铁的粉色座位 — 答案各不相同。所以这本手册给每一项都标注了标记。

  • [规定] — 法律·条例·官方政策。违反会被罚款或拒绝。依据见文末SOURCES。
  • [惯例] — 不是法律，但几乎所有人都这么做。不这样做会显得突出。
  • [可选] — 做了更好，不做也无妨。只在想显得像本地人时才需要。

每一项末尾的#编号，链接到把这个场景拆解成屏幕·动作单位的零慌张手册。这一张是地图，手册是路线指南。

⚠ 截至2026年9月：[规定]中有两项正在变动中 — 咖啡店纸杯限制重新推行(审议中，实施时间未定)和汉江公园禁酒区指定(首尔市议会待审)。下文中标注为"变动中"，发布后1年内会再次确认。

① 餐厅 — 8项

韩国餐厅的默认设置是"尽量少叫服务员的系统"。餐具在抽屉，水用饮水机，小菜靠续加，结账在柜台。客人多动一点，换来的是又快又便宜。懂了这套结构，餐厅的一半你已经会了(#1168)。

  • 餐具·纸巾 [惯例] — 先打开桌边的抽屉看看。没有的话插在筒里。
  • 叫服务员 [惯例] — 桌上的呼叫铃。没有铃的地方不要大声喊，说一句"请问一下 (Jeogiyo / 저기요)"就够了。
  • 水·小菜自取 [惯例] — 墙上贴着"水自取·小菜自取"标识就自己去拿。不是自取的地方按铃。
  • 小菜续加 [惯例] — 大部分免费。举起空盘子，或说"请再给点小菜 (Banchan deo juseyo / 반찬 더 주세요)"。没有必须吃完的规矩。
  • 结账 [惯例] — 柜台后付是基本，自助机先付·桌面点单正在增加。在桌上递卡结账的店接近例外(#1275)。
  • 小费 [惯例] — 没有。就算已含服务费的店，也不需要再加小费。
  • 剩菜 [可选] — 很多地方可以要求打包。一句话卡片："请把剩下的打包 (Nameun geo pojanghaejuseyo / 남은 거 포장해 주세요)"。
  • 烤肉店 [惯例] — 服务员帮忙换烤盘、剪肉是一种服务。剪刀是正常工具(#1290)。

② 咖啡店 — 5项

  • 占座 [惯例] — 点单前用外套·书·包占座是常态。也有人连钱包·手机都放下，但游客不要照做。
  • 杯子 [规定] — 堂食会用马克杯·玻璃杯代替一次性塑料杯。外带则用一次性杯。纸杯目前(2026年)是自愿性的，但重新推行限制正在审议中，各店可能不同 — 变动中。
  • 震动呼叫器 [惯例] — 响了就去取餐台自己取，吸管·纸巾·水在自助区(#1288)。
  • 久坐 [惯例] — 一人一饮品是不成文的规矩(惯例)。在插座座位摆几个小时电脑，有的店可以有的店不行[可选] — 以告示为准。
  • 回收台 [惯例] — 喝完的杯子和托盘要自己送到回收台 (bannapdae / 반납대)。冰块·剩余饮品·杯子·吸管·杯盖要分格放(#1276)。

③ 公共交通 — 9项

  • 孕妇专座 [惯例] — 粉色座位即使空着也要空着，这是不成文的规矩。法律上并非不能坐(没有罚款)，但大部分本地人都会空出来。
  • 老弱病残专座 [惯例] — 车厢两端座位同理。就算车厢拥挤，站着更自然。
  • 背包 [可选] — 客满地铁里背在前面或拿在手上。
  • 通话·声音 [惯例] — 不戴耳机外放视频或大声打电话的人，会被叫做"反派 (billeon / 빌런)"(#1169)。通话要短要小声。
  • 公交饮品 [规定] — 首尔市内公交车不能带着没有盖子的外带杯、有气味的食物上车(首尔市条例，2018年施行)。司机可以拒绝乘客上车。盖好盖的随行杯·密闭容器可以。
  • 地铁饮食 [惯例] — 没有像公交那样的禁止条例。但有气味的食物没人会吃。
  • 扶梯 [惯例] — 现场惯例是靠右单排站，左边留给走的人。官方立场是出于安全建议站两排，并非强制 — 跟着大家站就行。
  • 下公交 [惯例] — 按铃从后门下车，下车时再刷一次卡(换乘优惠)(#1271)。
  • 出租车 [惯例] — 车门要用手开关(不是自动门)。可以坐前排。没有小费，找零照常收下(#1273)。

④ 街头·公共场所 — 7项

  • 垃圾桶 [惯例] — 街上几乎没有。要一直带着，找地铁站分类回收箱·便利店垃圾桶(限购买顾客)扔掉(#1276)。
  • 吸烟 [规定] — 违反公交站周边10米·指定禁烟区(首尔标准)会被罚款(最高10万韩元)。其余街道吸烟不在规定范围内，但使用吸烟亭·区域是惯例(#1330)。
  • 通行 [可选] — 楼梯·通道有靠右通行箭头就按箭头走。
  • 公园饮酒 [惯例 · 变动中] — 在汉江公园喝啤酒的"炸鸡啤酒 (chimaek / 치맥)"，截至2026年9月是可以的。不过首尔市正在推进指定禁酒区(市议会待审)，以后可能会改变。喧哗·垃圾是另一回事。
  • 儿童谢绝·宠物谢绝 [惯例] — 先看入口标识。有的话就不能带小孩·宠物入内。这个制度有争议，但要尊重店家方针。
  • 电梯 [惯例] — 马上按关门键不是无礼，而是基本动作(#1143 快快文化)。
  • 细颗粒物 [可选] — 春·冬"差"的日子戴口罩很常见。用App(AirKorea等)确认。

⑤ 住宿 — 6项

民宿·青年旅舍·韩屋住宿的第一晚最容易慌张。有告示的话，告示比这本手册优先。

  • 鞋子 [惯例] — 在玄关脱鞋换室内拖鞋。温突 (ondol / 온돌)住宿·矮桌餐厅通用(#1141)。
  • 锅炉 [惯例] — 墙板上的[ 暖气 ]·[ 热水 ]·[ 外出 ]三个按钮是关键。没热水先确认热水模式，地板太烫就调低暖气温度。
  • 垃圾 [规定] — 一般垃圾只能扔进从量制垃圾袋 (jongnyangje bongtu / 종량제 봉투)。垃圾袋在便利店·超市买，价格和厨余垃圾投放方式因自治区而异，以住宿告知为准。
  • 厨余垃圾 [规定] — 与一般垃圾分开。按住宿使用的方式，用专用垃圾袋·收集桶·RFID计量器。
  • 噪音 [可选] — 晚上10点后注意走廊·脚步声·洗衣机。公寓式住宿对楼层间噪音很敏感。
  • 厕纸 [惯例] — 2018年以后大部分直接扔进马桶。老建筑贴有"请扔进垃圾桶"提示的，就照做(#1277)。

⑥ 酒局5个动作 — 一个专栏

聚餐·烧酒文化的"为什么"在#1140。游客实际会用到的动作有五个。

1. 酒杯用双手接(单手的话另一只手扶在手肘上)。

2. 倒酒时也用双手，酒瓶标签朝上。

3. 在长辈面前微微转头喝酒 — 不用做得太夸张。

4. 只给空杯倒酒。不往还有酒的杯子里加。

5. 喝不下了，杯子满着放那儿就行 — 说一句"没关系 (Gwaenchanayo / 괜찮아요)"。劝酒现在比以前少多了。

⑦ 对话 — 3行

  • 不知道名字的人，用"老板·阿姨·请问一下 (Sajangnim·Imonim·Jeogiyo / 사장님·이모님·저기요)"称呼。初次见面问年龄，是为了确定称呼，不是无礼(#1150)。
  • 敬语·平语不会被外国人期待做到。简短的问候和微笑就够了。
  • 有一种回避直说的"眼力见儿 (nunchi / 눈치)"(#1145) — "这个嘛 (Geulsseyo / 글쎄요)"通常就是"不"的意思。

⑧ 购物·支付 — 3项

  • 现金 [惯例] — 几乎不需要。支付宝·微信支付在韩国基本不能用，得用境外卡·现金·T-money交通卡。市场·部分老字号·公交不能现金乘车等参见#1301。
  • 自助结账 [惯例] — 便利店自助结账台·夜间无人商店刷卡进入(#1306)。
  • 退税 [规定] — 即时退税店铺和机场自助机(#1304)。

⑨ 拍照·寺庙 — 3项

  • 店内·拍人 [惯例] — 咖啡店·市场的商品·员工·其他顾客先问一句。自拍随意。
  • 禁止区域 [规定] — 军事设施·机场安检区·部分美术馆展厅按标识来。法堂内部大多禁止拍摄。
  • 寺庙礼仪 [惯例] — 法堂前脱鞋·摘帽，保持安静(#1186·#1137)。

🙆 不必做的事7条 — 化解过度礼节

1. 小费 — 没有。

2. 帮开出租车门 — 司机也不会开。各自用手开。

3. 深鞠躬 — 轻轻点头就够了。没人指望游客行大礼。

4. 吃完小菜 — 可以剩下。剩下才是常态。

5. 干杯喝完 — 一口闷不是义务。

6. 打电话订餐厅 — App·平板·现场排队是基本(#1274)。打不通电话不代表去不了。

7. 完美的敬语 — 不会被外国人期待做到。说一句"谢谢 (Gamsahamnida / 감사합니다)"就够了。

⚠ 常见失误5条

1. 坐粉色座位 — 空着也要空着。坐上去会引来目光。

2. 拿没盖盖子的咖啡上公交 — 首尔可能依条例被拒载。盖好盖子或喝完再上车。

3. 在禁烟区·站台10米内吸烟 — 会被罚款。找吸烟亭(#1330)。

4. 留下小费就走 — 服务员会追出来退还。谢意用"谢谢款待 (jal meogeosseumnida / 잘 먹었습니다)"表达。

5. 用普通袋子装住宿垃圾 — 不是从量制垃圾袋就不会被收走。

⚙ FAQ 5条

1. 只遵守[规定]就行吗？ — 罚款只会出在规定上。但"像本地人"这件事是[惯例]决定的。[可选]看个人。

2. 公交上能带随行杯吗？ — 盖好盖的随行杯·保温瓶·密闭容器可以。插着吸管的罐子·没盖盖子的杯子才是问题。

3. 在扶梯上站左边会怎样？ — 后面走路的人会等着。不算违规，但站右边更省心。

4. 能在汉江边喝啤酒吗？ — 截至2026年9月可以。禁酒区指定正在推进中，去的时候看当地标识。

5. 咖啡店用马克杯装，但要走了怎么办？ — 跟柜台说一声，会帮忙换到一次性杯里。
