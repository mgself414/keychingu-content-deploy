2026首尔Q弹甜品潮流——酸奶麻薯·披萨白米糕,年糕变身甜点的这个秋天10选

副标题: 继奶油年糕(#1233)之后填满首尔社交媒体的,是鲜果酸奶麻薯和披萨白米糕。年糕从"节日食品"变成"排队甜点"的2026年秋天——媒体统计的数字、酸奶麻薯5家·融合年糕4家·小份年糕店1家,以及在便利店先尝一口的方法。从当日食用·售罄时间到预约制,外国游客不白跑一趟的诀窍

🎯 为什么是"Q弹甜品"

韩国年糕本身的基础(打糕 (Injeolmi / 인절미)·松糕 (Songpyeon / 송편)·切糕 (Jeolpyeon / 절편))由#42 首尔年糕店·#473 年糕地图负责介绍。这一篇不同——只看2026年年糕成为甜品潮流这一现象。

数字先说话。"年糕朝圣" (Tteokji Sullye / 떡지순례,年糕+圣地巡礼的合成词) 一词最近一个月的博客提及量为1,077件,较去年同期增长2,278%;便利店GS25与年糕咖啡馆韩井善 (Hanjeongseon / 한정선) 合作推出的酸奶糯米糕 (Yogurt Chapssaltteok / 요거트 찹쌀떡) 上市13天卖出38万个(亚洲经济 2026-09-22)。在白米糕 (Baekseolgi / 백설기) 上铺番茄酱·芝士的披萨白米糕 (Pizza Baekseolgi / 피자설기),从釜山起源后谷歌搜索热度在2周内涨了10倍以上(《Money Today》2026-09-05)。相反,首尔传统年糕店·磨坊数量从2021年底的1,186家减少到2026年9月的1,021家——老字号年糕店在减少,只有新兴融合年糕店门前排长队。

流行周期也很短。从奶油年糕 (Butter Tteok / 버터떡)·迪拜耐嚼曲奇 (Dubai Chewy Cookie / 두쫀쿠)·开城酒饼 (Gaeseong Juak / 개성주악) 到披萨白米糕,甚至有分析指出如今的甜点每半个月就换一次新宠(Daum新闻 2026-09-25)。所以这一篇不是"永恒名店"名单,而是这个秋天当下该吃什么的清单。

⚠ 有效期: 本文为2026年9月末确认信息。含生果·酸奶的甜点常因当日到货量而提前售罄,潮流店铺的菜单也经常变化。店铺存续·地址已通过Naver地图登记确认,部分店铺的菜单构成标注为"据 Instagram 公告"——出发前请查看店铺Instagram最新公告。

🍓 酸奶麻薯——糯米糕里的生果与酸奶

酸奶麻薯 (Yogurt Mochi / 요거트모찌) 是在薄糯米糕 (Chapssaltteok / 찹쌀떡) 皮里包入生果(奇异果·草莓·芒果等)和酸奶奶油的年糕。最初用米纸在家自制的食谱先在海外社交媒体走红,后来在韩国由年糕咖啡馆做成成品出售,再度掀起热潮。

  • 韩井善 (Hanjeongseon / 한정선) — 圣水洞 (Seongsu-dong / 성수동): 这股潮流的中心店铺。整颗放入一个水果(金奇异果·超大草莓等)的糯米糕是招牌,名气大到能与GS25推出联名商品。据报道周末下午的取号排队登记曾在下午4点半左右就截止——工作日上午或刚开门时段更现实。从圣水站步行可达。和圣水角色快闪店(#1403)同一片区,适合安排在半天行程里。
  • 今日麻薯 (Oneul Mochi / 오늘모찌) — 木洞 (Mokdong / 목동): 水果麻薯每个约3,000韩元,是价格已确认的店铺。位于Omokgyo站附近的住宅区,虽偏离观光动线,但比圣水人少。周日休息,不可停车。
  • 米布兰 (Ssal Blanc / 쌀블랑) — 江东 (Gangdong / 강동): 以纽约芝士鲜奶油年糕 (New York Cheese Cream Tteok / 뉴욕치즈크림떡) 这类鲜奶油年糕 (Cream Tteok / 크림떡)闻名的年糕甜品咖啡馆。酸奶麻薯是本地账号公告里出现的菜单,是否常态销售请访问前确认。
  • 1020空间 (1020 Room / 1020룸) (乙支路 (Euljiro / 을지로))·软糖堂 (Mallangdang / 말랑당) (外大前 (Oedae-ap / 외대앞)): 本地账号"首尔酸奶麻薯14"(点赞2,600+)里提到的店铺。均在Naver地图上登记为咖啡馆·甜品店,酸奶麻薯销售据 Instagram 公告为准。乙支路与#1311新堂洞·乙支路动线相接。

🍕 披萨白米糕与融合年糕——白米糕上的番茄酱与芝士

披萨白米糕是在白米糕 (Baekseolgi / 백설기,白米年糕) 上铺番茄酱·芝士·意式辣香肠的年糕。它起源于釜山影岛 (Yeongdo / 영도) 的年糕店,经社交媒体扩散,如今首尔的社区年糕店也各自推出自己的版本。一个食用诀窍——不少测评提到微波炉加热约30秒能让Q弹的糕体和融化的芝士口感更佳。

  • 白君年糕坊 (Baekgun Tteokbang / 백군떡방) — 风纳洞 (Pungnap-dong / 풍납동) (松坡区): 披萨白米糕与红豆切糕 (Ang-kko Jeolpyeon / 앙꼬절편)。两个本地账号的名单上都标注了相同的营业时间(08:00~20:00)。因为是一早开门的社区年糕店,上午前往售罄的顾虑较少。
  • 片 (Pyeon / 편) — 九宜洞 (Guui-dong / 구의) (广津区): 在Naver上登记为年糕咖啡馆的店铺。披萨白米糕的销售以本地账号公告为准。
  • Sweet Plume Cake × 雪期素潭 (Seolgi Sodam / 설기소담) — 长安洞 (Jangan-dong / 장안동) (东大门区): 蛋糕品牌与年糕店联手打造的合作店铺。最能体现今年蛋糕与年糕界限日渐模糊的潮流。
  • 书库 (Seogo / 서고) — 方背洞 (Bangbae-dong / 방배동) (瑞草区): 只接受预约销售的小年糕店(Kakao频道"年糕店书库")。直接上门是买不到的——没有韩国手机号的话,可以请住宿前台代为预约。

🎁 小份年糕店与便利店——最简单的两个入口

  • 垫糕 (Goem / 굄) — 普门洞 (Bomun-dong / 보문동) (城北区): 虽是做周岁宴·纪念日年糕的店,但备有茶点用小份包装,方便旅行者一两个地买。周一~周六10~19点,周日仅限预约顾客。与城北洞小巷漫步(#1345)同属一个区域。
  • GS25 × 韩井善 酸奶糯米糕: 没时间排队的话就先在便利店尝一口。上市时江南·仁川机场门店的首批库存人气高到提前售罄,库存因店而异。请在便利店的甜品冷藏柜找。便利店食品全览见#1262。

🗓 半天路线——东侧转一圈

圣水 → 九宜洞 → 风纳洞: 上午圣水韩井善(刚开门时) → 乘2号线到九宜站片(披萨白米糕) → 转乘公交·地铁到风纳洞白君年糕坊。按这个顺序往东一路转过去。下午可以接乐天世界(#1404)或首尔奥林匹克公园赏枫(#273)。

乙支路番外: 乙支路3街1020空间 → 新堂洞市场·炒年糕胡同(#1311)。

⚠ 常见错误3条

1. 买回住宿第二天再吃 — 含生果·酸奶的麻薯原则上要当日食用,即使冷藏也要在含购买日在内的2天内吃完(以韩井善店内说明为准)。不适合当作带回国的伴手礼。

2. 下午晚些时候才去 — 人气店铺常在上午到早下午之间就卖光。公告反复提到当日销售量会因水果到货量而变化。

3. 没预约直接去预约制店铺 — 像书库这样只接受预约销售的店铺是存在的。请先确认表格中标注的"预约制"。

⚙ 常见问题解答(FAQ)3个

1. 只能吃一个的话? — 韩井善的整颗水果糯米糕。如果排队有负担,可以先尝GS25联名商品。

2. 和奶油年糕有什么不同? — 奶油年糕(#1233)是烤年糕加黄油的香浓温热系,酸奶麻薯是冰凉清爽系,披萨白米糕则是咸香正餐型。三者都是2026年潮流,不妨一次比较着吃。

3. 能刷卡·有英文菜单吗? — 各店铺情况未确认。小型年糕店几乎没有英文菜单,截图店名和菜单照片给店员看会更快。
