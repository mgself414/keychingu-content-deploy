🎯 왜 진주 가이드인가

진주 (Jinju) = 임진왜란 매니아 매트릭스·촉석루 + 진주성 (1592 진주대첩)·진주냉면·유등축제 (10월 매트릭스 #1). 외국인 페인포인트 = (a) "진주 = 안 알려짐" 잘못된 인식 (b) 촉석루 = 영남 #1 누각·임진왜란 1592 매트릭스 (c) 진주성 = 1592 + 1593 진주대첩 매트릭스 (d) 진주냉면 = 한국 #1 시그너 매트릭스 (e) 유등축제 (매년 10월) = 한국 매니아 매트릭스 #1.

본 가이드는 5축 12 시그니처 + 촉석루 + 진주성 + 유등축제.

★ 한눈에 5축 12 시그니처

🏛 5축 deep dive

① 촉석루 (영남 #1 누각)

  • 시그니처: 영남 #1 누각·진주성 + 임진왜란 1592 매트릭스·의기 논개
  • 외국인 친화도: ★★★★ (영문·문화·매니아)
  • 시간: 09:00~18:00·2,000원

② 진주성 + 1592 진주대첩

  • 시그니처: 임진왜란 1592 + 1593 진주대첩 매트릭스 #1·박물관·야경
  • 외국인 친화도: ★★★★ (영문·역사 매니아)

③ 유등축제 (매년 10월·매니아 #1)

  • 시그니처: 매년 10월 첫째~중순·한국 매니아 매트릭스 #1·남강 + 유등 + 인스타
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족·매니아)
  • 시즌: 매년 10월 1-2주

④ 진주냉면 (한국 #1 시그너)

  • 시그니처: 한국 #1 진주냉면 시그너 매트릭스·평양·함흥과 다른 매트릭스
  • 외국인 친화도: ★★★★ (안 매콤·외국인 입문)
  • 가격: 진주냉면 = 12,000~18,000원/그릇

⑤ 1박 + 카페 매니아

  • 시그니처: 진주 1박 매니아·유등축제 + 풀세트
  • 가격: 1박 = 60,000~250,000원

⚠ 외국인 자주 실수 5가지

1. "진주 = 안 알려짐": 임진왜란 매트릭스 #1·촉석루 영남 #1·진주냉면 한국 #1·유등축제 매니아 #1.

2. "촉석루 = 일반 누각": 영남 #1·임진왜란 1592 매트릭스.

3. "진주성 = 일반 성": 1592 + 1593 진주대첩 매트릭스 #1.

4. "유등축제 = 일반 축제": 매년 10월·한국 매니아 매트릭스 #1.

5. "진주냉면 = 어디서나 동일": 한국 #1 시그너·평양·함흥과 다른 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 촉석루 + 진주성 + 진주냉면 = 1일.

2. 유등축제 (10월): 매년 10월 1-2주·외국인 매니아 매트릭스 #1·사전 예약 권장.

3. 진주냉면 vs 평양·함흥: 진주 = 해물·갈비 + 매콤·매트릭스 다름.

4. 시즌: 봄·가을 베스트·10월 유등축제 매니아 #1.

5. 알레르기: 진주냉면 = 해산물·갈비·콩 사전 고지.

6. 추천 페르소나: 가족·시니어 = 촉석루 + 진주냉면 / MZ·인스타 = 카페 + 유등축제 / 매니아·역사 = 진주성 + 1박.

⚠ 의료·안전 disclaimer

진주 = 안전. 유등축제 = 야간 + 많은 인파·소매치기 주의. 응급 ☎ 1339·1330.
