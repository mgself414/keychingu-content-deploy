1. 《泪之女王》 (2024) — 爱情与背叛的奇幻豪宅

剧情背景: 讲述富家妻子怀疑丈夫出轨，并寻找真爱的心理剧

📍 主要拍摄地

又来屋 (Uraeok / 우리옛돌박물관) (首尔 (Seoul / 서울) 城北区 (Seongbuk-gu / 성북구))

  • 角色: 皇后集团 (Queens Group) 会长朴根宇 (Park Geun-woo / 박근우) 的豪宅 (金秀贤 (Kim Soo-hyun / 김수현)、金智媛 (Kim Ji-won / 김지원) 的豪宅场景)
  • 位置: 首尔市 (Seoul / 서울시) 城北区 (Seongbuk-gu / 성북구) 大使馆路13街 (Daesagwan-ro 13-gil / 대사관로13길) 66号
  • 地铁: 4号线 汉城大入口站 (Hansung University Station / 한성대입구역) → 出租车或步行15分钟
  • 特点: 韩屋 (Hanok / 한옥) (韩国传统房屋) 与现代建筑的结合，营造剧中奢华氛围
  • 参观提示: 博物馆正在运营中，参观拍摄地前务必提前确认
  • 如何拍出剧中效果: 利用豪宅花园里随时间变化的光线。下午15:00~16:00 (3~4 PM) 的逆光效果最富戏剧性

华克山庄酒店雅斯顿之家 (Walkerhill Hotel Aston House / 워커힐 호텔 애스톤 하우스) (首尔 (Seoul / 서울) 广津区 (Gwangjin-gu / 광진구))

  • 角色: 朴根宇 (Park Geun-woo / 박근우) - 尹海英 (Yoon Hae-young / 윤해영) 婚礼场景 (第4集)
  • 位置: 首尔市 (Seoul / 서울시) 广津区 (Gwangjin-gu / 광진구) 华克山庄路 (Walkerhill-ro / 워커힐로) 177号
  • 地铁: 5号线 广渡口站 (Gwangnaru Station / 광나루역) → 出租车5分钟
  • 特点: 优雅的宴会厅，非常适合剧中的背光场景
  • 周边餐厅: 华克山庄酒店 (Walkerhill Hotel / 워커힐 호텔) 内有多种餐饮选择
  • 如何拍出剧中效果: 在窗边以首尔夜景为背景。采用三分法构图，将人物置于侧面，能很好地表达剧中的情感线

日月树木园 (Ilwolsupmokwon / 일월수목원) (京畿道 (Gyeonggi-do / 경기도) 水原 (Suwon / 수원))

  • 角色: 洪海仁 (Hong Hae-in / 홍해인) (金智媛 (Kim Ji-won / 김지원) 饰) 试图自杀的森林 (剧集初期)
  • 位置: 京畿道 (Gyeonggi-do / 경기도) 水原市 (Suwon-si / 수원시) 长安区 (Jangan-gu / 장안구) 日月路 (Ilwol-ro / 일월로) 61号
  • 地铁: 1号线 水原站 (Suwon Station / 수원역) → 出租车20分钟
  • 特点: 茂密的自然森林，营造出剧中戏剧性的场景
  • 参观提示: 不同季节提供不同的树木景观 (推荐春季樱花，秋季枫叶)
  • 如何拍出剧中效果: 利用树木间的阴影和光线形成明暗对比。建议使用智能手机的人像模式，应用背景虚化效果

忠州乾芝村 (Chungju Geonji Maeul / 충주 건지마을) (忠清北道 (Chungcheongbuk-do / 충북) 忠州市 (Chungju-si / 충주시))

  • 角色: 剧集初期乡村场景的拍摄地
  • 位置: 忠清北道 (Chungcheongbuk-do / 충북) 忠州市 (Chungju-si / 충주시) 东良面 (Dongnyang-myeon / 동량면) 乾芝村 (Geonji Maeul / 건지마을)
  • 交通: 首尔 (Seoul / 서울) ↔ 忠州 (Chungju / 충주) 无穷花号 (Mugunghwa-ho / 무궁화호) 约1小时50分钟 (春川线 (Chuncheon Line / 춘천선))
  • 特点: 典型的韩国农村风光，表现了剧集初期的对比
  • 如何拍出剧中效果: 以低角度拍摄乡村小路，人物置于前景。日落时分 (傍晚) 更具感性

2. 《背着善宰跑》 (2024) — 时空穿越浪漫，在过去相遇

剧情背景: 讲述往返于2024年和2008年，展开一段奇特爱情故事

📍 主要拍摄地

城北川余蔚桥 (Seongbukcheon Yeouldari / 성북천 여울다리) (首尔 (Seoul / 서울) 城北区 (Seongbuk-gu / 성북구))

  • 角色: 任率 (Im Sol / 임솔) (金惠奫 (Kim Hye-yoon / 김혜윤) 饰) 掉落手表穿越回过去的边界 (剧中所有时间移动的舞台)
  • 位置: 首尔市 (Seoul / 서울시) 城北区 (Seongbuk-gu / 성북구) 城北洞2街 (Seongbuk-dong 2-ga / 성북동 2가) 一带
  • 地铁: 4号线 诚信女大入口站 (Sungshin Women's University Station / 성신여대입구역) 1号出口 → 步行5分钟
  • 特点: 舒适的散步道，氛围宁静，是剧迷的朝圣地
  • 周边咖啡馆: 诚信女大入口站 (Sungshin Women's University Station / 성신여대입구역) 附近咖啡街 (Montede等众多咖啡馆)
  • 参观提示: 早上尽早前往，可在不拥挤的余蔚桥 (Yeouldari / 여울다리) 独享拍摄
  • 如何拍出剧中效果: 靠在桥栏杆上，正面拍摄。智能手机竖屏模式，将背景的水和树木一同纳入画面

东大门设计广场 (DDP) (Dongdaemun Design Plaza / DDP) (首尔 (Seoul / 서울) 中区 (Jung-gu / 중구))

  • 角色: 2024年任率 (Im Sol / 임솔) 观看偶像 Eclipse (善宰 (Seon-jae / 선재) 饰) 演出的场所 (剧中现代时间舞台)
  • 位置: 首尔市 (Seoul / 서울시) 中区 (Jung-gu / 중구) 乙支路 (Eulji-ro / 을지로) 45号
  • 地铁: 2号线 东大门站 (Dongdaemun Station / 동대문역)、东大门历史文化公园站 (Dongdaemun History & Culture Park Station / 동대문역사문화공원역) 附近
  • 特点: 未来主义建筑，展现2024年现代首尔 (Seoul / 서울)
  • 门票: 内部演出/展览需另付费，外部拍摄免费
  • 参观提示: 夜景最美 (晚上18:00~20:00 (6~8 PM))
  • 如何拍出剧中效果: 广角拍摄建筑的曲线。将天空一同纳入画面，强调DDP的宏伟

首尔中央高等学校 (Seoul Jungang High School / 서울 중앙고등학교) (首尔 (Seoul / 서울) 广津区 (Gwangjin-gu / 광진구))

  • 角色: 2008年学校场景拍摄地
  • 位置: 首尔市 (Seoul / 서울시) 广津区 (Gwangjin-gu / 광진구) 阿嵯山路 (Achasan-ro / 아차산로) 408号
  • 地铁: 7号线 广渡口站 (Gwangnaru Station / 광나루역) → 步行10分钟
  • 特点: 重温学生时代感性
  • 参观提示: 学校正在运营中，只能在外部拍摄 (围墙附近)
  • 如何拍出剧中效果: 以学校正门或围墙为背景，与穿着校服的朋友们一起拍摄，营造出电视剧般的氛围

水原行宫洞 (Suwon Haenggung-dong / 수원 행궁동) (京畿道 (Gyeonggi-do / 경기도) 水原市 (Suwon-si / 수원시))

  • 角色: 任率 (Im Sol / 임솔) 家门前的街道，现在咖啡馆“Montede”所在的胡同 (剧中人物的日常生活舞台)
  • 位置: 京畿道 (Gyeonggi-do / 경기도) 水原市 (Suwon-si / 수원시) 八达区 (Paldal-gu / 팔달구) 行宫路 (Haenggung-ro / 행궁로) 127号一带
  • 地铁: 1号线 水原站 (Suwon Station / 수원역) → 出租车10分钟或乘坐公交车
  • 特点: 韩屋 (Hanok / 한옥) 村落与现代咖啡馆交织的感性街道
  • 周边咖啡馆: Montede (剧中任率 (Im Sol / 임솔) 的家)、水原行宫洞 (Suwon Haenggung-dong / 수원 행궁동) 咖啡街
  • 参观提示: 下午14:00~16:00 (2~4 PM) 阳光恰好洒满胡同
  • 如何拍出剧中效果: 利用胡同狭窄的道路，近距离正面拍摄人物。背景的韩屋 (Hanok / 한옥) 会自然形成散景效果

3. 《鬼怪》 (2016, 经典永恒) — 永恒的爱情故事

剧情背景: 讲述活了400年的鬼怪金信 (Kim Shin / 김신) 和阴间使者，以及爱上他们的女人们的奇幻浪漫故事

📍 主要拍摄地

江陵注文津海边 (Gangneung Jumunjin Beach / 강릉 영진해변) (江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시))

  • 角色: 池恩倬 (Ji Eun-tak / 지은탁) (金高银 (Kim Go-eun / 김고은) 饰) 首次召唤鬼怪金信 (Kim Shin / 김신) (孔刘 (Gong Yoo / 공유) 饰) 的命运之地 (剧中核心相遇的舞台)
  • 位置: 江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시) 江东面 (Gangdong-myeon / 강동면) 正东津里 (Jeongdongjin-ri / 정동진리) 一带
  • 交通: 首尔 (Seoul / 서울) 清凉里站 (Cheongnyangni Station / 청량리역) ↔ 江陵站 (Gangneung Station / 강릉역) 无穷花号 (Mugunghwa-ho / 무궁화호) 约3小时30分钟，从江陵站 (Gangneung Station / 강릉역) 乘坐出租车20分钟
  • 特点: 湛蓝的东海 (Donghae / 동해) 象征永恒，是剧迷的朝圣地
  • 周边咖啡馆/餐厅: 正东津站 (Jeongdongjin Station / 정동진역) 附近咖啡馆，海边餐厅街
  • 参观提示: 在日出时分 (凌晨05:00~06:00 (5~6 AM)) 或日落时分 (傍晚18:00~19:00 (6~7 PM)) 参观，可重现剧中神秘氛围
  • 如何拍出剧中效果: 以大海为背景，利用逆光。强调人物剪影，可增加剧中的神秘感

江陵镜浦台 (Gangneung Gyeongpodae / 강릉 경포대) (江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시))

  • 角色: 金信 (Kim Shin / 김신) 和阴间使者 (李栋旭 (Lee Dong-wook / 이동욱) 饰) 一同散步的楼阁 (友谊的舞台)
  • 位置: 江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시) 永东 (Yeongdong / 영동) 一带
  • 交通: 从江陵站 (Gangneung Station / 강릉역) 乘坐出租车15分钟
  • 特点: 拥有600多年历史的韩国楼阁建筑精髓，也是著名的拍照打卡点
  • 特别之处: 电视剧播出后，成为韩国旅游的热门景点
  • 参观提示: 强烈推荐春季樱花季 (4月) 或秋季枫叶季 (10月)
  • 如何拍出剧中效果: 利用楼阁的柱子和栏杆作为框架。将背景的山和湖泊按照三分法构图进行 배치

江陵月花街 (Gangneung Wolhwa Street / 강릉 월화거리) (江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시))

  • 角色: 金信 (Kim Shin / 김신) 和池恩倬 (Ji Eun-tak / 지은탁) 约会的街道，沿着旧铁轨延伸的咖啡馆和精品店
  • 位置: 江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시) 浦南洞 (Ponam-dong / 포남동) 一带 (旧铁轨)
  • 特点: 充满复古情调的咖啡街，有许多适合拍照的地点
  • 周边咖啡馆: 月花街 (Wolhwa Street / 월화거리) 咖啡馆密集，约30~40家
  • 参观提示: 下午15:00~16:00 (3~4 PM) 橱窗灯亮起时氛围极佳
  • 如何拍出剧中效果: 在咖啡馆入口处以整条街道为背景进行广角拍摄。或者拍摄咖啡馆窗户中映出的人物，营造电影感

江陵中央市场 (Gangneung Jungang Market / 강릉 중앙시장) (江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시))

  • 角色: 金信 (Kim Shin / 김신) 和池恩倬 (Ji Eun-tak / 지은탁) 一同买菜的日常生活舞台
  • 位置: 江原道 (Gangwon-do / 강원도) 江陵市 (Gangneung-si / 강릉시) 竹轩 (Jukheon / 죽헌) 一带
  • 特点: 典型的韩国市场，充满生机，可体验本土饮食文化
  • 推荐菜单: 鱿鱼汤 (Ojing-eo Guk / 오징어 국)、炖菜 (Jjim / 찜)、山菜拌饭 (Sanchae Bibimbap / 산채 비빔밥)
  • 参观提示: 早上尽早 (08:00~10:00 (8~10 AM)) 参观，可捕捉市场充满活力的景象

仁川白达里旧书店胡同 (Incheon Baedari Old Bookstore Alley / 인천 배다리 헌책방 골목) (仁川市 (Incheon / 인천시) 中区 (Jung-gu / 중구))

  • 角色: 《鬼怪》某一场景的拍摄地，铅笔和书籍交织的命运之地
  • 位置: 仁川市 (Incheon / 인천시) 中区 (Jung-gu / 중구) 金谷洞 (Geumgok-dong / 금곡동) 白达里旧书店胡同 (Baedari Heonchaekbang Golmok / 배다리 헌책방 골목)
  • 地铁: 1号线 仁川站 (Incheon Station / 인천역) → 步行15分钟
  • 特点: 池恩倬 (Ji Eun-tak / 지은탁) (金高银 (Kim Go-eun / 김고은) 饰) 凭直觉感受到的瞬间背景，韩美书店 (Hanmi Bookstore / 한미서점) 前
  • 参观提示: 上午10:00~12:00 (10 AM~12 PM) 阳光最温暖
  • 如何拍出剧中效果: 突出狭窄胡同的深度感进行拍摄。将书堆置于前景，将焦点向后拉，营造电影感

4. 《梨泰院Class》 (2020, 近期再受关注的电视剧) — 复仇与爱情的夜生活

剧情背景: 以梨泰院 (Itaewon / 이태원) 布帐马车 (Pocha / 포차) (韩式路边摊) 街为舞台，展开一场痛快的复仇剧和浪漫故事
