📺 分剧集拍摄地指南

1. 眼泪女王 (Nunmurui Yeowang / 눈물의 여왕, 2024)——爱情与背叛的梦幻豪宅

剧情背景：讲述富家女怀疑丈夫外遇、又寻找真爱的心理剧

📍 主要拍摄地

我们的老石头博物馆 (Uri Yetdol Museum / 우리옛돌박물관)（首尔城北区）

  • 剧中角色：Queens集团会长朴根友的宅邸（金秀贤 (Kim Soo-hyun / 김수현)、金智媛 (Kim Ji-won / 김지원) 的宅邸场景）
  • 地址：首尔市城北区大使馆路13街66
  • 地铁：4号线汉城大入口站→打车或步行15分钟
  • 特点：韩屋与现代建筑结合，营造剧中的奢华氛围
  • 参观提示：现为博物馆运营，拍摄地参观需提前确认
  • 同款拍摄法：利用庭院内随时段变化的阳光。下午3~4点逆光最具戏剧效果

华克山庄酒店 Aston House (Walkerhill Hotel Aston House / 워커힐 호텔 애스톤 하우스)（首尔广津区）

  • 剧中角色：朴根友与尹海英的婚礼场景（第4集）
  • 地址：首尔市广津区华克山路177
  • 地铁：5号线广渡站→打车5分钟
  • 特点：优雅的宴会厅，是剧中逆光场景的理想选择
  • 周边餐厅：华克山庄酒店内多种餐饮选择
  • 同款拍摄法：以窗边位置为背景，取首尔夜景。人物侧置于三分构图，可更好呈现剧中的情感线

日月树木园 (Ilwol Arboretum / 일월수목원)（京畿道水原市）

  • 剧中角色：裴多情（金智媛）在森林中试图自杀的场景（剧集前段）
  • 地址：京畿道水原市长安区日月路61
  • 地铁：1号线水原站→打车20分钟
  • 特点：茂密的自然树林，将设定中的戏剧性场景生动呈现
  • 参观提示：不同季节呈现不同林景（推荐春季樱花、秋季红叶）
  • 同款拍摄法：利用树间的光影明暗对比。建议使用手机人像模式实现背景虚化效果

忠州建池村 (Chungju Geonji Village / 충주 건지마을)（忠北忠州市）

  • 剧中角色：剧集前段乡村场景拍摄地
  • 地址：忠北忠州市东良面建池村
  • 交通：首尔↔忠州无穷花号列车约1小时50分钟（春川线）
  • 特点：典型的韩国农村风景，呈现剧集前段的对比效果
  • 同款拍摄法：以低角度拍摄乡间小路，人物置于前景。日落时段（黄昏）最具感染力

2. 背着善宰跑 (Seonjae Eopgo Twieo / 선재 업고 튀어, 2024)——穿越时空的浪漫，在过去相遇

剧情背景：往返于2024年与2008年之间展开的独特爱情故事

📍 主要拍摄地

城北川余温桥 (Seongbukcheon Yeoul Bridge / 성북천 여울다리)（首尔城北区）

  • 剧中角色：林率（金慧允 (Kim Hye-yoon / 김혜윤)）掉落手表回到过去的分界点（剧中所有时空穿越的舞台）
  • 地址：首尔市城北区城北洞2街一带
  • 地铁：4号线成信女大站1号出口→步行5分钟
  • 特点：宁静的散步小径，是剧迷的朝圣之地
  • 周边咖啡馆：成信女大站附近咖啡街（Monte D等多家咖啡馆）
  • 参观提示：清晨到访人少，可独享余温桥拍摄
  • 同款拍摄法：以倚靠桥栏的姿势正面拍摄。手机竖屏模式同时收入背景的水与树木

东大门设计广场 (Dongdaemun Design Plaza·DDP / 동대문 디자인 플라자)（首尔中区）

  • 剧中角色：2024年林率观看偶像Eclipse（善宰饰）演出的场地（剧集现在时空舞台）
  • 地址：首尔市中区乙支路45
  • 地铁：2号线东大门站、东大门历史文化公园站附近
  • 特点：未来感建筑，呈现2024年的现代首尔
  • 门票：内部演出/展览需另购票，外部拍摄免费
  • 参观提示：夜景最美（傍晚6~8点）
  • 同款拍摄法：以广角拍摄建筑曲线，天空一并入镜以突出DDP的宏伟

首尔中央高中 (Seoul Jungang High School / 서울 중앙고등학교)（首尔广津区）

  • 剧中角色：2008年校园场景拍摄地
  • 地址：首尔市广津区峨嵯山路408
  • 地铁：7号线广渡站→步行10分钟
  • 特点：唤起学生时代的情怀
  • 参观提示：学校正常运营中，仅可在外部拍摄（围墙附近）
  • 同款拍摄法：以校门或围墙为背景，与穿校服的朋友一同拍摄更具剧感

水原行宫洞 (Suwon Haenggung-dong / 수원 행궁동)（京畿道水原市）

  • 剧中角色：林率曾居住的家门前街道，现为咖啡馆"Monte D"所在的小巷（剧中人物的日常舞台）
  • 地址：京畿道水原市八达区行宫路127一带
  • 地铁：1号线水原站→打车10分钟或乘公交
  • 特点：韩屋村与现代咖啡馆交融的情调街区
  • 周边咖啡馆：Monte D（剧中林率的家）、水原行宫洞咖啡街
  • 参观提示：下午2~4点阳光恰好照亮小巷
  • 同款拍摄法：利用狭窄的小巷正面近距离拍摄人物。背景的韩屋会自然形成虚化效果

3. 鬼怪 (Dokkaebi / 도깨비, 2016，长青经典)——永恒之爱的故事

剧情背景：活了400年的鬼怪金信与冥王使者，以及爱上他们的女人们的奇幻爱情故事

📍 主要拍摄地

江陵永津海滩 (Gangneung Yeongjin Beach / 강릉 영진해변)（江原道江陵市）

  • 剧中角色：池恩倬（金高银 (Kim Go-eun / 김고은)）首次召唤鬼怪金信（孔刘 (Gong Yoo / 공유)）命运相遇之地（剧中核心相遇舞台）
  • 地址：江原道江陵市江东面正东津里一带
  • 交通：首尔清凉里站↔江陵站无穷花号约3小时30分钟，江陵站打车20分钟
  • 特点：碧蓝的东海象征永恒，是剧迷的朝圣地
  • 周边咖啡馆/餐厅：正东津站附近咖啡馆、海边餐饮街
  • 参观提示：日出时段（凌晨5~6点）或日落时段（傍晚6~7点）到访，可再现剧中神秘氛围
  • 同款拍摄法：以大海为背景善用逆光，突出人物剪影更添剧中神秘感

江陵镜浦台 (Gangneung Gyeongpodae / 강릉 경포대)（江原道江陵市）

  • 剧中角色：金信与冥王使者（李东旭 (Lee Dong-wook / 이동욱)）散步的楼阁（友情舞台）
  • 地址：江原道江陵市永东一带
  • 交通：江陵站打车15分钟
  • 特点：拥有600余年历史的韩国楼阁建筑精粹，也是著名拍照点
  • 特别之处：剧集播出后成为韩国观光名胜
  • 参观提示：强烈推荐春季樱花季（4月）或秋季红叶（10月）
  • 同款拍摄法：以楼阁的立柱与栏杆作画框。背景的山与湖依三分构图排布

江陵月花街 (Gangneung Wolhwa Street / 강릉 월화거리)（江原道江陵市）

  • 剧中角色：金信与池恩倬约会的街道，沿旧铁路延展的咖啡馆与杂货店
  • 地址：江原道江陵市浦南洞一带（旧铁路）
  • 特点：满溢复古情调的咖啡街，拍照点众多
  • 周边咖啡馆：月花街咖啡馆30~40家聚集
  • 参观提示：下午3~4点橱窗灯光亮起时氛围最佳
  • 同款拍摄法：站在咖啡馆入口以广角拍下整条街道。或拍摄映在咖啡馆窗户上的人物，营造电影感

江陵中央市场 (Gangneung Jungang Market / 강릉 중앙시장)（江原道江陵市）

  • 剧中角色：金信与池恩倬一同采买的日常舞台
  • 地址：江原道江陵市竹轩一带
  • 特点：典型韩国市场的生动氛围，可体验乡土饮食文化
  • 推荐菜品：鱿鱼汤、炖菜、山菜拌饭
  • 参观提示：清晨（8~10点）到访可拍下市场最有活力的一面

仁川培栽旧书店街 (Incheon Baedari Used Bookstore Alley / 인천 배다리 헌책방 골목)（仁川市中区）

  • 剧中角色：《鬼怪》一幕拍摄地，铅笔与书本交织的命运之地
  • 地址：仁川市中区金谷洞培栽旧书店街
  • 地铁：1号线仁川站→步行15分钟
  • 特点：池恩倬凭直觉感应到瞬间的背景，韩美书店门前
  • 参观提示：上午10~12点阳光最温暖
  • 同款拍摄法：善用狭窄小巷的纵深感拍摄。将书堆置于前景、焦点放在后方，更具电影感

4. 梨泰院Class (Itaewon Class / 이태원 클라쓰, 2020，近期重新翻红剧)——复仇与爱情的夜生活

剧情背景：以梨泰院大排档街为舞台展开的爽快复仇剧与爱情故事

📍 主要拍摄地

绿莎坪站天桥 (Noksapyeong Station Pedestrian Bridge / 녹사평역 육교)（首尔龙山区）

  • 剧中角色：剧集的标志性舞台，朴世路（朴叙俊 (Park Seo-joon / 박서준)）诉说心声的那座天桥（几乎所有主要场景在此拍摄）
  • 地址：首尔市龙山区绿莎坪路一带
  • 地铁：6号线绿莎坪站3号出口正前方
  • 特点：俯瞰整个梨泰院的最佳拍摄点，剧迷必访路线
  • 周边大排档：丹夜大排档周边、绿莎坪站大排档小巷
  • 参观提示：傍晚7~9点天桥夜景最美
  • 同款拍摄法：倚靠天桥栏杆正面拍摄。背景的梨泰院街道虚化处理，可表现剧中的情感

南山白凡广场 (Namsan Baekbeom Plaza / 남산 백범광장)（首尔龙山区）

  • 剧中角色：朴世路每日散步的小路，冥想与回忆的舞台
  • 地址：首尔市龙山区南山一带
  • 地铁：3号线忠武路站或4号线明洞站
  • 特点：与首尔城墙路相连的户外冥想空间，四季景致各异
  • 参观提示：清晨（6~8点）或傍晚（5~7点）一缕阳光最具戏剧感
  • 同款拍摄法：以低角度拍下台阶或小路，背景收入首尔夜景

梨泰院街（绿莎坪站一带） (Itaewon Street / 이태원 거리)（首尔龙山区）

  • 剧中角色：《梨泰院Class》的主舞台，大排档街与餐饮街全域
  • 地址：首尔市龙山区梨泰院路一带（绿莎坪站半径1.5公里）
  • 地铁：6号线绿莎坪站
  • 特点：多国文化交融的首尔热门去处
  • 周边餐厅/咖啡馆：梨泰院大排档、酒吧、韩餐厅、咖啡馆数百家
  • 参观提示：傍晚7点后街道灯光亮起。周五至周日夜晚氛围最佳
  • 同款拍摄法：将街道霓虹灯与人流一同收入镜头，呈现律动感十足的氛围

5. 爱的迫降 (Sarangui Bulsichak / 사랑의 불시착, 2019，经典重访)——朝鲜与韩国，命运的相遇

剧情背景：讲述因滑翔伞事故意外降落朝鲜的财阀千金，与朝鲜哨所军官之间的爱情故事

📍 主要拍摄地（首尔场景）

首尔江南高端商圈 (Gangnam luxury shopping street / 강남 고급 매장가)（首尔江南区）

  • 剧中角色：尹世丽（孙艺珍 (Son Ye-jin / 손예진)）奢华日常的舞台，名品购物与公司场景
  • 地址：首尔市江南区狎鸥亭路、论岘路一带（新沙洞街道树街、江南站周边）
  • 地铁：2号线江南站、新沙站
  • 特点：首尔顶级奢华街区，象征剧中世丽的富裕
  • 推荐咖啡馆/餐厅：狎鸥亭Rodeo街咖啡馆群
  • 参观提示：下午2~4点橱窗灯光最清晰
  • 同款拍摄法：在名品店门前以精致姿态取景。避开背景中的韩文招牌，仅保留英文/奢华风背景

首尔艺术殿堂 (Seoul Arts Center / 서울 예술의전당)（首尔瑞草区）

  • 剧中角色：世丽的公司及舞台背景
  • 地址：首尔市瑞草区南部循环路2406（瑞草洞）
  • 地铁：3号线南部客运站、2号线教大站
  • 特点：韩国最大综合艺术设施，建筑美感出众
  • 门票：内部演出/展览需另购票，外部拍摄免费
  • 参观提示：夜景最美（傍晚6~8点）
  • 同款拍摄法：以建筑的几何线条作画框，夜间灯光凸显宏伟感

🚴 自助游推荐路线

📌 路线A：江南·瑞草剧迷之旅（3小时）

适合对象：奢华剧粉丝 | 购物与情调小巷交织的路线

行程顺序：

1. 起点：江南站（2号线）

  • 江南站名品街漫步（《眼泪女王》《爱的迫降》拍摄地）
  • 所需时间：30分钟

2. 接下来：新沙站→狎鸥亭Rodeo街

  • 咖啡馆"狎鸥亭"及街道树街拍摄（步行10分钟）
  • 所需时间：40分钟

3. 午餐：狎鸥亭韩餐厅或咖啡馆

  • 所需时间：50分钟

4. 终点：南部客运站→艺术殿堂

  • 建议打车10分钟
  • 提前准备夜景（建议傍晚5点左右到达）
  • 所需时间：40分钟

总时长：3小时

交通：地铁2号线、3号线

最佳拍摄时间：下午2~6点（阳光与夜景兼得）

📌 路线B：钟路·北村古装+现代剧路线（4小时）

适合对象：想同时享受韩屋村与剧感的游客

行程顺序：

1. 起点：安国站（3号线）

  • 北村韩屋村漫步
  • 甘古堂街（《背着善宰跑》拍摄地）
  • 所需时间：1小时

2. 接下来：钟路3街站（1号线）

  • 校南洞小巷徒步
  • 钟路首尔城墙路（《屋塔房王世子》拍摄地）
  • 所需时间：1小时30分钟

3. 午餐或小吃：北村/钟路韩定食或咖啡馆

  • 所需时间：1小时

4. 终点：成信女大站（4号线）

  • 城北川余温桥（《背着善宰跑》剧中核心场所）
  • 所需时间：30分钟

总时长：4小时

交通：地铁3号线、1号线、4号线（同一路线易于串联）

最佳拍摄时间：上午9点~下午4点（韩屋建筑细节最清晰）

📌 路线C：江陵·仁川一日游剧迷之旅（6小时或1泊2日）

适合对象：想深度体验《鬼怪》与《梨泰院Class》的朝圣客

第1天（江陵）：首尔↔江陵一日路线

行程顺序：

1. 出发：首尔清凉里站（凌晨6:00乘无穷花号）

  • 江陵站抵达：约9:30

2. 第一站拍摄地：江陵永津海滩

  • 江陵站打车20分钟（约15,000韩元）
  • 强烈推荐日出或日落时段到访
  • 所需时间：1小时

3. 第二站拍摄地：江陵镜浦台

  • 永津海滩打车5分钟
  • 楼阁内部游览+湖畔散步道
  • 所需时间：50分钟

4. 午餐：江陵中央市场

  • 镜浦台打车10分钟
  • 推荐鱿鱼汤、炖菜、山菜拌饭（10,000~15,000韩元档）
  • 所需时间：1小时

5. 第三站拍摄地：江陵月花街

  • 中央市场步行15分钟或打车5分钟
  • 咖啡馆参观及街道拍摄
  • 所需时间：1小时

📸 剧集拍摄地拍照方法

🎬 基本构图3种

1. 三分构图法（黄金分割）

  • 定义：将画面分为3×3网格，在交叉点上安排被摄主体的技巧
  • 手机设置：相机App→设置→开启"网格"或"Grid"
  • 适用场景：所有拍摄地中最基本、最稳定的构图
  • 示例：
  • 演员置于左侧1/3线，背景（建筑/自然）置于右侧2/3
  • 面部置于上方1/3，身体置于下方2/3

2. 善用逆光（Backlighting）

  • 定义：从光源对面拍摄，将被摄主体呈现为剪影
  • 时机：日出（凌晨5~6点）或日落（傍晚5~7点）
  • 效果：最大化剧中的神秘感、宿命感与情绪
  • 适用场景：海滩拍摄地（永津海滩、月花街）、夜景（绿莎坪站天桥）
  • 提示：脸部略微侧转呈侧脸，让光线掠过发丝

3. 取景框构图（善用背景）

  • 定义：利用窗户、建筑、树木等自然框架突出人物
  • 适用场景：北村韩屋村（窗户/墙壁）、月花街（咖啡馆入口）、培栽旧书店街（书堆）
  • 技巧：调整位置，使背景的线条与形态自然环绕人物

⚠️ 需避免的5种失误

1. 截断关节：截断脚踝、膝盖、腰部、脖子会显得别扭。应取全身或膝盖以上

2. 与背景重叠：调整位置，避免柱子或树枝穿过头部或脖子

3. 过度变焦：手机数码变焦会降低画质，应靠双脚移动接近

4. 平面化构图：以前景-中景-背景三层排布制造景深

5. 不自然的姿势：比起勉强的伸展动作，更推荐自然的坐姿或倚靠

🎫 实用贴士与礼仪

拍摄地参观注意事项

1. 尊重私人场所

  • 部分拍摄地是普通商铺、住宅、学校（并非公开建筑）
  • 例如：学校仅可在外部拍摄，住宅小巷需保持安静，营业中的咖啡馆需消费方可入内
  • 礼仪：比起拍完照立刻离开，更应保持"作为游客的礼貌"

2. 确认时间限制

  • 博物馆、艺术殿堂等需另购门票并确认运营时间
  • 居民区应在上午10点~下午5点安静参观

3. 部分拍摄地可能限制进入

  • 根据剧集人气，部分场所可能限制拍照或暂停运营
  • 参观前务必通过官方网站或博客确认最新信息

🌟 最后贴士：带着剧中情感拍摄

照片不仅是单纯的记录，更是定格"成为那一幕主角瞬间"的方式。

情感代入3步骤：

1. 回忆剧集场景（2分钟）

  • 拍摄前通过YouTube或流媒体App重温该剧场景
  • 记住演员的情绪、配乐、天气、灯光

2. 重现那份情感（1分钟）

  • 用自己的身体重现演员的表情、姿态
  • 一边想着"此刻若是演员会是什么表情"一边拍摄

3. 在照片中注入故事

  • 在照片文案中加入剧中台词或场景说明
  • 分享至粉丝社区时一并写下情感解读
