📺 按剧目划分的取景地指南

1. 《泪之女王 (Tears of the Queen / 눈물의 여왕)》(2024) — 爱恨交织的梦幻豪宅

剧情背景：富豪妻子怀疑丈夫出轨，在寻找真爱过程中展开的心理剧

📍 主要取景地

我们旧石博物馆 (Uri Yet Dol Bangmulgwan / 우리옛돌박물관) (首尔 城北区 (Seongbuk-gu / 성북구))

  • 剧中角色：皇后集团会长朴根宇的豪宅 (金秀贤 (Kim Soo-hyun / 김수현)、金智媛 (Kim Ji-won / 김지원) 的豪宅场景)
  • 地址：首尔市 城北区 (Seongbuk-gu / 성북구) 大使馆路13街 (Daesagwan-ro 13-gil / 대사관로13길) 66号
  • 地铁：4号线 汉城大入口站 (Hanseongdaeyeok / 한성대입구역) → 打车或步行约15分钟
  • 特色：韩屋 (Hanok / 한옥，传统韩式建筑，类似中国四合院的历史建筑) 与现代建筑相结合，呈现剧中奢华氛围
  • 参观提示：目前作为博物馆对外开放，参观取景地前请务必提前确认
  • 如何拍出剧中感：在豪宅庭院中利用随时段变化的阳光，下午15:00～16:00的逆光效果最具戏剧感

沃克山庄酒店阿斯顿别馆 (Walker Hill Hotel Aston House / 워커힐 호텔 애스톤 하우스) (首尔 广津区 (Gwangjin-gu / 광진구))

  • 剧中角色：朴根宇与尹海英婚礼场景 (第4集)
  • 地址：首尔市 广津区 (Gwangjin-gu / 광진구) 沃克山庄路 (Workerhill-ro / 워커힐로) 177号
  • 地铁：5号线 广渡口站 (Gwangnaru-yeok / 광나루역) → 打车约5分钟
  • 特色：典雅宴会厅，非常适合剧中背光场景再现
  • 周边餐厅：沃克山庄酒店内多种餐饮选择
  • 如何拍出剧中感：在窗边以首尔夜景为背景，采用三分法将人物置于侧面，可充分表现剧中情感线

日月树木园 (Irwol Arboretum / 일월수목원) (京畿道 水原市 (Suwon / 수원))

  • 剧中角色：裴多贞 (Kim Ji-won / 김지원 饰) 企图自杀的森林场景 (剧集前期)
  • 地址：京畿道 水原市 长安区 (Jangan-gu / 장안구) 日月路 (Irwol-ro / 일월로) 61号
  • 地铁：1号线 水原站 (Suwon-yeok / 수원역) → 打车约20分钟
  • 特色：郁郁葱葱的天然林，完美呈现剧中戏剧性场景
  • 参观提示：不同季节呈现不同树木景观 (推荐春季樱花、秋季红叶)
  • 如何拍出剧中感：利用树木间光影对比，建议使用智能手机人像模式开启背景虚化效果

忠州建池村 (Chunju Geonji Village / 충주 건지마을) (忠北 忠州市 (Chungju / 충주))

  • 剧中角色：剧集前期农村场景拍摄地
  • 地址：忠北 忠州市 东梁面 (Dongnyang-myeon / 동량면) 建池村 (Geonji Village / 건지마을)
  • 交通：首尔 ↔ 忠州 (Chungju / 충주) 无穷花号列车约1小时50分钟 (春川线)
  • 特色：典型韩国农村风貌，呈现剧集开头的强烈对比感
  • 如何拍出剧中感：以低角度拍摄乡间小路，将人物置于前景。日落时分 (黄昏)氛围最佳

2. 《背着善宰跑 (Lovely Runner / 선재 업고 튀어)》(2024) — 时空穿越爱情，在过去相遇

剧情背景：在2024年与2008年之间来回穿梭，展开的奇特爱情故事

📍 主要取景地

城北川浅滩桥 (Seongbukcheon Yeouldari Bridge / 성북천 여울다리) (首尔 城北区 (Seongbuk-gu / 성북구))

  • 剧中角色：任率 (Kim Hye-yun / 김혜윤 饰) 手表落入水中、穿越至过去的时空分界线 (剧中所有时间移动的舞台)
  • 地址：首尔市 城北区 (Seongbuk-gu / 성북구) 城北洞2街 (Seongbuk-dong 2-ga / 성북동 2가) 一带
  • 地铁：4号线 成均女大站 (Sungshin Women's University Station / 성신여대역) 1号出口 → 步行约5分钟
  • 特色：舒适步行道，氛围静谧，是追剧粉丝的圣地
  • 周边咖啡馆：成均女大站 (Sungshin Women's University Station / 성신여대역) 附近咖啡街 (蒙特德 (Montede / 몽테드) 等多家咖啡馆)
  • 参观提示：清晨早到可独享未受打扰的浅滩桥拍摄体验
  • 如何拍出剧中感：倚靠桥栏正面拍摄，使用智能手机竖屏模式将背景中的水面与树木一并收入画面

东大门设计广场 (DDP / 동대문 디자인 플라자) (首尔 中区 (Jung-gu / 중구))

  • 剧中角色：2024年任率观看偶像 Eclipse (善宰饰)演出的地点 (剧中现代时间线舞台)
  • 地址：首尔市 中区 (Jung-gu / 중구) 乙支路 (Euljiro / 을지로) 45号
  • 地铁：2号线 东大门站 (Dongdaemun-yeok / 동대문역)、东大门历史文化公园站 (Dongdaemun History & Culture Park Station / 동대문역사문화공원역) 附近
  • 特色：未来感十足的建筑，完美呈现2024年现代首尔气息
  • 票价：内部演出场/展览需另行购票，室外拍摄免费
  • 参观提示：夜景最为迷人 (18:00～20:00)
  • 如何拍出剧中感：利用建筑曲线进行广角拍摄，将天空纳入画面，强调DDP的磅礴气势

首尔中央高中 (Seoul Jungang High School / 서울 중앙고등학교) (首尔 广津区 (Gwangjin-gu / 광진구))

  • 剧中角色：2008年学校场景拍摄地
  • 地址：首尔市 广津区 (Gwangjin-gu / 광진구) 峨嵯山路 (Achasan-ro / 아차산로) 408号
  • 地铁：7号线 广渡口站 (Gwangnaru-yeok / 광나루역) → 步行约10分钟
  • 特色：重现青春校园气息
  • 参观提示：学校正常运营中，仅可在外部拍摄 (围墙附近)
  • 如何拍出剧中感：以校门或围墙为背景，穿着校服与朋友合影，即可营造出剧中的青春氛围

水原行宫洞 (Suwon Haenggung-dong / 수원 행궁동) (京畿道 水原市 (Suwon / 수원))

  • 剧中角色：任率家门前街道，现有咖啡馆蒙特德 (Montede / 몽테드) 所在的小巷 (剧中人物日常生活舞台)
  • 注：골목 (小巷)= 小胡同 (比中国的胡同更窄小的街道小巷)
  • 地址：京畿道 水原市 八达区 (Paldal-gu / 팔달구) 行宫路 (Haenggung-ro / 행궁로) 127号一带
  • 地铁：1号线 水原站 (Suwon-yeok / 수원역) → 打车约10分钟或乘公交
  • 特色：韩屋 (Hanok / 한옥) 村与现代咖啡馆融合的文艺街道
  • 周边咖啡馆：蒙特德 (Montede / 몽테드) (剧中任率的家)、水原行宫洞咖啡街
  • 参观提示：下午14:00～16:00阳光恰好照入小巷
  • 如何拍出剧中感：利用小巷狭窄的通道近距离正面拍摄人物，后方韩屋 (Hanok / 한옥) 自然形成背景虚化效果

3. 《鬼怪 (Goblin / 도깨비)》(2016，经典永流传) — 永恒爱情的故事

剧情背景：活了400年的鬼怪金信与死神，以及爱上他们的女人们之间的奇幻爱情

📍 主要取景地

江陵 荧津海滩 (Gangneung Yeongjin Beach / 강릉 영진해변) (江原道 江陵市 (Gangneung / 강릉))

  • 剧中角色：池恩倬 (Kim Go-eun / 김고은 饰) 第一次召唤鬼怪金信 (Gong Yoo / 공유 饰) 的命运之地 (剧中核心相遇舞台)
  • 地址：江原道 江陵市 江东面 (Gangdong-myeon / 강동면) 正东津里 (Jeongdongjin-ri / 정동진리) 一带
  • 交通：首尔 清凉里站 (Cheongnyangni Station / 청량리역) ↔ 江陵站 (Gangneung Station / 강릉역) 无穷花号约3小时30分钟，江陵站打车约20分钟
  • 特色：蔚蓝东海象征永恒，是追剧粉丝的圣地
  • 周边咖啡馆/餐厅：正东津站 (Jeongdongjin Station / 정동진역) 附近咖啡馆、海滨餐饮区
  • 参观提示：日出时分 (05:00～06:00)或黄昏 (18:00～19:00)到访，可还原剧中神秘氛围
  • 如何拍出剧中感：以大海为背景利用逆光，强调人物剪影，进一步增添剧中神秘感

江陵 镜浦台 (Gangneung Gyeongpodae / 강릉 경포대) (江原道 江陵市 (Gangneung / 강릉))

  • 剧中角色：金信与死神 (Lee Dong-wook / 이동욱 饰) 一起散步的楼阁 (友情舞台)
  • 地址：江原道 江陵市 岭东 (Yeongdong / 영동) 一带
  • 交通：从江陵站 (Gangneung Station / 강릉역) 打车约15分钟
  • 特色：拥有600年以上历史的韩国楼阁建筑精髓，同时也是著名打卡胜地
  • 亮点：剧播出后已成为韩国热门旅游景点
  • 参观提示：强烈推荐春季樱花期 (4月)或秋季红叶期 (10月)
  • 如何拍出剧中感：以楼阁立柱与栏杆为框架，将背景中的山脉与湖泊按三分法构图

江陵 月华街 (Gangneung Wolhwa Street / 강릉 월화거리) (江原道 江陵市 (Gangneung / 강릉))

  • 剧中角色：金信与池恩倬约会的街道，沿旧铁轨延伸的咖啡馆与小物件店
  • 地址：江原道 江陵市 浦南洞 (Ponam-dong / 포남동) 一带 (旧铁路沿线)
  • 特色：充满复古情调的咖啡街，拍照好去处众多
  • 周边咖啡馆：月华街咖啡馆约30～40家密集
  • 参观提示：下午15:00～16:00橱窗灯光亮起，氛围最佳
  • 如何拍出剧中感：在咖啡馆入口处以整条街道为背景进行广角拍摄，或拍摄映在咖啡馆玻璃窗上的人物倒影，营造电影感

江陵 中央市场 (Gangneung Jungang Market / 강릉 중앙시장) (江原道 江陵市 (Gangneung / 강릉))

  • 剧中角色：金信与池恩倬一起逛市场的日常舞台
  • 地址：江原道 江陵市 竹轩 (Jukheun / 죽헌) 一带
  • 特色：展现典型韩国市场的生动活力，可体验地道饮食文化
  • 推荐菜单：鱿鱼汤、炖菜、山野菜拌饭
  • 参观提示：清晨 (08:00～10:00)到访可感受市场最热闹的氛围

仁川 培达里二手书店胡同 (Incheon Baedari Used Bookstore Alley / 인천 배다리 헌책방 골목) (仁川市 中区 (Jung-gu / 중구))

  • 剧中角色：《鬼怪》某场景取景地，铅笔与书籍交织的命运之地
  • 地址：仁川市 中区 (Jung-gu / 중구) 金谷洞 (Geumgok-dong / 금곡동) 培达里二手书店胡同 (Baedari Bookstore Alley / 배다리 헌책방 골목)
  • 地铁：1号线 仁川站 (Incheon-yeok / 인천역) → 步行约15分钟
  • 特色：池恩倬 (Kim Go-eun / 김고은 饰) 凭直觉感应到的场景背景，汉美书店 (Hanmi Bookstore / 한미서점) 门前
  • 参观提示：上午10:00～12:00阳光最为温暖
  • 如何拍出剧中感：利用窄巷的纵深感构图，将书堆置于前景、焦点向后拉，营造电影感

4. 《梨泰院 Class (Itaewon Class / 이태원 클라쓰)》(2020，近期重获关注) — 复仇与爱情的夜生活

剧情背景：以梨泰院 (Itaewon / 이태원) 路边摊街道为舞台，展开的爽快复仇与浪漫爱情

  • 注：포차 (路边摊小酒馆)= 路边排档 (类似中国夜市摊，但以饮酒为主的韩式小酒摊)

📍 主要取景地

绿莎坪站天桥 (Nokseopyeong Station Overpass / 녹사평역 육교) (首尔 龙山区 (Yongsan-gu / 용산구))

  • 剧中角色：剧中标志性舞台，朴世路 (Park Seo-joon / 박서준 饰) 说话的那座天桥 (所有主要场景均在此拍摄)
  • 地址：首尔市 龙山区 (Yongsan-gu / 용산구) 绿莎坪路 (Nokseopyeong-ro / 녹사평로) 一带
  • 地铁：6号线 绿莎坪站 (Nokseopyeong-yeok / 녹사평역) 3号出口正前方
  • 特色：俯瞰梨泰院全景的最佳拍摄地，追剧粉丝必打卡
  • 周边路边摊：单棒路边摊 (Danbam Pocha / 단밤 포차) 周边、绿莎坪站路边摊小巷
  • 参观提示：傍晚19:00～21:00天桥夜景最为迷人
  • 如何拍出剧中感：倚靠天桥栏杆正面拍摄，将身后的梨泰院街道虚化为背景，可表现剧中情感

南山 白凡广场 (Namsan Baekbeom Plaza / 남산 백범광장) (首尔 龙山区 (Yongsan-gu / 용산구))

  • 剧中角色：朴世路每日散步的路线，冥想与回忆的舞台
  • 地址：首尔市 龙山区 (Yongsan-gu / 용산구) 南山 (Namsan / 남산) 一带
  • 地铁：3号线 忠武路站 (Chungmuro-yeok / 충무로역) 或4号线 明洞站 (Myeongdong-yeok / 명동역)
  • 特色：与首尔城廓路相连的室外静心空间，四季景观各异
  • 参观提示：清晨 (06:00～08:00)或黄昏 (17:00～19:00)一束阳光最为戏剧感
  • 如何拍出剧中感：以低角度拍摄台阶或小路，将首尔夜景纳入背景

梨泰院街道 (绿莎坪站一带)(Itaewon Street / 梨泰院 (Itaewon / 이태원) 거리) (首尔 龙山区 (Yongsan-gu / 용산구))

  • 剧中角色：《梨泰院 Class》主舞台，路边摊街与餐饮区全境
  • 地址：首尔市 龙山区 (Yongsan-gu / 용산구) 梨泰院路 (Itaewon-ro / 이태원로) 一带 (绿莎坪站半径1.5km)
  • 地铁：6号线 绿莎坪站 (Nokseopyeong-yeok / 녹사평역)
  • 特色：汇聚多国文化的首尔热门胜地
  • 周边餐厅/咖啡馆：梨泰院路边摊、酒吧、韩食餐厅、咖啡馆数百家
  • 参观提示：傍晚19:00后街道灯光亮起，周五、六、日晚氛围最佳
  • 如何拍出剧中感：将街道霓虹灯与人流一并纳入画面，呈现充满活力的氛围

5. 《爱的迫降 (Crash Landing on You / 사랑의 불시착)》(2019，经典重温) — 南北韩，命运相遇

剧情背景：财阀千金因滑翔伞事故迫降朝鲜，与朝鲜哨所少尉军官之间的浪漫爱情

📍 主要取景地 (首尔场景)

首尔 江南高档商圈 (Seoul Gangnam Luxury District / 서울 강남 고급 매장가) (首尔 江南区 (Gangnam-gu / 강남구))

  • 剧中角色：尹世理 (Son Ye-jin / 손예진 饰) 奢华日常舞台，名品购物与公司场景
  • 地址：首尔市 江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로)、论岘路 (Nonhyeon-ro / 논현로) 一带 (新沙洞林荫路 (Garosu-gil / 가로수길)、江南站周边)
  • 地铁：2号线 江南站 (Gangnam-yeok / 강남역)、新沙站 (Sinsa-yeok / 신사역)
  • 特色：首尔顶级奢华街道，象征剧中世理的富裕生活
  • 推荐咖啡馆/餐厅：狎鸥亭罗德欧街 (Apgujeong Rodeo Street / 압구정 로데오거리) 咖啡馆
  • 参观提示：下午14:00～16:00橱窗灯光最为清晰
  • 如何拍出剧中感：在名品门店入口处以时尚姿态拍摄，背景只保留英文/奢华元素

首尔 艺术殿堂 (Seoul Arts Center / 서울 예술의전당) (首尔 瑞草区 (Seocho-gu / 서초구))

  • 剧中角色：世理公司及舞台背景
  • 地址：首尔市 瑞草区 (Seocho-gu / 서초구) 南部循环路 (Nambusunhwan-ro / 남부순환로) 2406号 (瑞草洞 (Seocho-dong / 서초동))
  • 地铁：3号线 南部客运站 (Nambu Terminal Station / 남부터미널역)、2号线 教大站 (Gyodae-yeok / 교대역)
  • 特色：韩国最大综合艺术设施，建筑美感出众
  • 票价：内部演出/展览需另行购票，室外拍摄免费
  • 参观提示：夜景最为迷人 (18:00～20:00)
  • 如何拍出剧中感：以建筑几何线条为框架，利用夜间灯光呈现磅礴气势

🚴 自助游推荐路线

📌 路线A：江南·瑞草 Drama Tour (约3小时)

目标群体：奢华剧粉丝 | 购物与文艺小巷完美结合的路线

行程顺序：

1. 出发点：江南站 (Gangnam-yeok / 강남역) (2号线)

  • 江南站名品街漫步 (《泪之女王》、《爱的迫降》取景地)
  • 所需时间：30分钟

2. 下一站：新沙站 (Sinsa-yeok / 신사역) → 狎鸥亭罗德欧街 (Apgujeong Rodeo Street / 압구정 로데오거리)

  • 咖啡馆"狎鸥亭"及林荫路 (Garosu-gil / 가로수길) 拍摄 (步行10分钟)
  • 所需时间：40分钟

3. 午餐：狎鸥亭韩食餐厅或咖啡馆

  • 所需时间：50分钟

4. 最后一站：南部客运站 (Nambu Terminal Station / 남부터미널역) → 艺术殿堂 (Arts Center / 예술의전당)

  • 建议打车约10分钟
  • 准备欣赏夜景 (推荐17:00左右抵达)
  • 所需时间：40分钟

总用时：约3小时

交通：地铁2号线、3号线

最佳拍摄时间：下午14:00～18:00 (阳光 + 夜景均可利用)

📌 路线B：钟路·北村 古装+现代Drama Tour (约4小时)

  • 教南洞小巷 (Gyonam-dong Alley / 교남동 골목길) 漫步
  • 钟路首尔城廓路 (《屋塔房王世子 (Rooftop Prince / 옥탑방 왕세자)》取景地)
  • 所需时间：1小时30分钟

3. 午餐或下午茶：北村/钟路 韩
