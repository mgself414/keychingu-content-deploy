⚠ 外国游客常犯的3个错误

1. "钟路 = 韩食·宫殿" — 跳过咖啡馆

外国人动线中最常见的误区。把钟路仅当作景福宫·昌德宫·北村观光地，错过安国·益善洞·钟路一带19家以上咖啡馆。事实上，钟路是韩国咖啡馆文化第1位区域 — 韩屋 (Hanok，即传统韩式建筑改造的咖啡馆，类似中国的四合院改造体验) 咖啡馆、画廊咖啡馆、现代招牌咖啡馆、烘焙咖啡馆集中在同一条动线上。宫殿 + 咖啡馆休息1~2小时 = 最具外国游客感的钟路行程。

2. 以为安国·益善洞·北村是彼此独立的街区

外国人常只看景福宫，再去江南·弘大找咖啡馆，但实际上安国站 (Anguk Station) + 益善洞 + 北村 = 咖啡馆首选动线。安国站步行10分钟内聚集10家以上咖啡馆。益善洞韩屋胡同 (골목，即传统小巷) 30分钟漫步 + 1家咖啡馆 = 最佳组合。无需去江南·弘大，钟路区域内即可解决。

3. 忽略营业时间·休息日

热门咖啡馆 (又来屋安国·阿布咖啡·首尔咖啡益善本店) 周末排队1~2小时为常态。平日14:00~17:00人少最佳 — 上午 (宫殿参观时段) 或17:00后亦可。部分门店周一·周二休息 — 请提前查阅Instagram或Naver地图确认。韩屋咖啡馆座位较少，优先选择工作日前往。

钟路·安国·北村·益善洞咖啡馆风景

钟路区域自2010年代中期起确立为韩国咖啡馆文化第1位区域。与江南 (时尚·现代)、弘大 (独立·潮流)、圣水 (编辑店·潮流) 不同，钟路风格鲜明：韩屋·画廊·静谧。

安国 (Anguk) 是钟路咖啡馆第1位街区 — 安国站步行5~10分钟内，韩屋咖啡馆·现代咖啡馆·烘焙咖啡馆10家以上密集分布。又来屋安国·阿布咖啡·爱慕那不勒斯安国店等均为外国人首选。Instagram热门打卡地。

益善洞 (Ikseon-dong) 是韩屋胡同咖啡馆区域 — 益善洞韩屋村内多家韩屋改建为咖啡馆。首尔咖啡益善本店·温知心等韩屋氛围首屈一指，是外国游客拍照热点。

北村 (Bukchon) 以韩屋 + 画廊咖啡馆为特色 — 北村韩屋村 + 画廊小巷分布有延庆堂等氛围出众的门店。画廊漫步 + 咖啡馆组合路线绝佳。

钟路本区 (Jongno Core) 主打现代·招牌咖啡馆 — 钟阁 (Jonggak)·钟路3街 (Jongno 3-ga) 一带聚集现代咖啡馆 + CBD咖啡馆。雨报彩虹·燃烧首尔·小河盐田等时尚现代门店均在此区。

花园氛围: 橡果花园安国店。

Q4. 平日 vs 周末，哪个更好？

A. 平日 (周三~周五) 最佳: 14:00~17:00人少 + 门店正常营业 + 出片效果好。周末: 11:00~14:00韩国本地潮流客云集，排队1~2小时。周一·周二: 部分门店休息。优先选择平日前往。

Q5. 宫殿·观光 + 咖啡馆组合动线如何规划？

A. 景福宫路线: 09:00景福宫 → 11:00又来屋安国早午餐 → 12:30阿布咖啡招牌 → 14:00北村 → 15:30延庆堂休息。

昌德宫路线: 09:00昌德宫 → 11:00益善洞 → 12:00首尔咖啡益善本店 → 14:00钟路散步。

北村路线: 10:00北村韩屋村 → 12:00延庆堂 → 14:00爱慕那不勒斯安国店。

Q6. 按价格区间推荐哪些门店？

A. ₩5,000~10,000 (~¥35~70 RMB，轻度饮品): 又来屋安国·首尔咖啡·橡果花园·爱慕那不勒斯安国店。

₩10,000~15,000 (~¥70~105 RMB，招牌 + 甜点): 阿布咖啡·温知心·雨报彩虹·阿必波蕾·小河盐田。

Q7. 适合多人聚会的门店有哪些？

A. 4~6人团体: 橡果花园安国店·爱慕那不勒斯安国店·延庆堂 — 座位充裕。

2~3人 (大部分门店): 又来屋安国·阿布咖啡·首尔咖啡益善本店等 — 以小型座位为主。

韩屋咖啡馆座位较少 — 优先选择平日前往。
