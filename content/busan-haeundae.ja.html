釜山 海雲台・広安里12か所 — ビーチ・海辺列車・展望台・ドローンショー、時間と料金

サブタイトル: 釜山に初めて行く旅行者のために、海雲台、冬柏島、広安里の3エリア12か所をまとめた。海雲台海水浴場は砂浜1.5km、広安里海水浴場は1.4kmだ。海辺列車は尾浦~松亭の4.8kmを片道約25分で走り、スカイカプセルは1台ごとの料金で乗る。広安里Mドローンライトショーは冬の土曜日19:00と21:00に開かれる。料金は2026-11-24に確認した大人の定価だ。

🎯 だれのための、なぜこの12か所なのか

釜山に初めて行く外国人旅行者に合わせたリストです。ソウルから1日か2日を割いて、釜山の東の海辺を見るときに使います。ビーチ2か所を中心に置き、その周辺に徒歩または都市鉄道2号線で行ける場所を足しました。

3つのエリアに分けました。

  • 海雲台エリア(6か所): 海雲台海水浴場、海雲台ブルーラインパーク、タルマジキル ムーンタンロード、釜山エックス・ザ・スカイ、SEA LIFE釜山アクアリウム、海雲台伝統市場。
  • 冬柏島エリア(3か所): 冬柏島海岸散策路、ヌリマルAPECハウス、ザ・ベイ101。
  • 広安里エリア(3か所): 広安里海水浴場、広安里Mドローンライトショー、二妓台海岸散策路。

2026-11-24現在、今は11月です。海水浴の季節ではありません。そのためこの号は、水遊びではなく、歩く・乗る・眺める・夜の見どころを中心に書きました。海辺列車とスカイカプセルは11~2月の冬季ダイヤで動き、ドローンショーも冬の時刻で開かれます。

12か所のうち4か所は、韓国観光公社の「名所発掘100×100」国民投票で票を得た場所です。該当の項目に得票を1行ずつ書きました。

⚠ 表記の原則: 時間、料金、距離、行き方は2026-11-24に閲覧した値です。出典は、海雲台ブルーラインパーク、釜山エックス・ザ・スカイ、SEA LIFE釜山アクアリウムの運営会社のサイトと、釜山市、海雲台区庁、水営区、Visit Busan、韓国観光公社です。料金は大人の定価です。ザ・ベイ101と海雲台伝統市場の住所・営業時間、そして一部の駅からの徒歩時間はカカオマップの値で、該当の行に「カカオマップ」と明記しました。運営時間、料金、バスの路線は変わることがあります。

✈ まず、金海空港から海雲台へ

釜山市の英語のお知らせ(2026-11-24閲覧)によると、空港リムジンの海雲台路線は2026-01-05の始発から改編されました。料金は大人9,500ウォン、青少年7,600ウォン、子ども4,800ウォンです。

  • 萇山 (Jangsan / 장산)–海雲台–空港路線: 所要90分。空港を出る始発は07:10、最終は16:50です。萇山を出る便は05:30~19:00に走ります。萇山方面の運行間隔は20~60分です。
  • 機張 (Gijang / 기장)–海雲台–空港路線: 所要110分。空港を出る始発は10:10、最終は21:40です。
  • 降りる場所: 停留所の名前が「海雲台海水浴場 (Haeundae Beach / 해운대해수욕장)(09116)」に変わりました。

空港を出る萇山路線の最終は16:50です。それより遅く着いたら、21:40まである機張路線に乗ります。2つの路線は所要時間が20分違います。

🚦 歩く前に — 共通の安全とマナー

  • 11月は海水浴の季節ではありません。 11月の海雲台と広安里は、砂浜を歩いて海を眺める場所です。
  • 天気が悪ければ日程を変えます。 海辺列車は雨でも通常どおり運行しますが、豪雨と台風のときは走りません。ドローンショーは天候や技術上の問題で中止や遅れが出ることがあります。
  • 二妓台海岸散策路には上り坂の区間があります。 4.7kmで約2時間30分かかる道です。運動靴をはいて、水を持っていきます。
  • 冬柏島の入口には傾斜があります。 韓国観光公社のアクセシビリティ案内には、散策路の入口に傾斜10度前後の区間があると書かれています。
  • 事故や緊急のときは119、犯罪の通報は112に電話します。

① 海雲台エリア — 6か所

都市鉄道2号線の海雲台駅と中洞駅を使うエリアです。ビーチ、水族館、市場は海雲台駅から歩いて行きます。展望台は中洞駅から歩き、ムーンタンロードは海雲台駅からマウルバスに乗り換えます。海辺列車とスカイカプセルは尾浦停車場から乗ります。

海雲台海水浴場 (Haeundae Beach / 해운대해수욕장)

  • 大きさ: 海雲台区庁は砂浜を長さ1.5km、幅70~90m、面積120,000㎡と書いています。端から端まで往復すると3kmです。
  • 夜: 海雲台区庁の案内では、ライトアップは通年、毎日日没後から24:00まで点灯します。海水浴シーズンは02:00までです。
  • 季節: 11月は海水浴の季節ではありません。砂浜の散歩と海の眺めで日程を組みます。
  • 行き方: カカオマップの経路検索では、都市鉄道2号線 海雲台駅5番出口から歩いて11分(688m)です。
  • 空港から: 空港リムジン海雲台路線の停留所名が「海雲台海水浴場(09116)」です。

海雲台ブルーラインパーク — 海辺列車・スカイカプセル

海辺の線路沿いを走る乗り物が2つあります。海辺列車は尾浦から松亭 (Songjeong / 송정)まで、スカイカプセルは尾浦から青沙浦 (Cheongsapo / 청사포)まで行きます。以下の値は、ブルーラインパークの公式サイトの2026-11-24の表記です。

海辺列車 (Beach Train / 해변열차)

  • 区間: 尾浦~青沙浦~松亭の4.8kmを往復します。平均時速15kmで走り、片道約25分かかります。1時間に3回走ります。
  • 停車場(公式サイトの累積距離): 尾浦 (0.3km、終点) → タルマジトンネル (Dalmaji Tunnel / 달맞이터널) (0.8km) → 海月展望台 (Haewol Observatory / 해월전망대) (1.1km) → 青沙浦 (2.3km) → タリットル展望台 (Daritdol Observatory / 다릿돌전망대) (2.9km) → 九徳浦 (Gudeokpo / 구덕포) (3.4km) → 松亭 (4.8km、終点)。
  • 運行時間: 11月(冬季、11~2月)は09:00~19:00です。尾浦と松亭を出る最終列車が19:00です。間期(3・4・10月)は09:00~19:30、繁忙期(5・6・9月)は09:00~20:30、最繁忙期(7・8月)は09:00~21:30です。
  • 天気: 雨でも通常どおり運行します。豪雨と台風のときは運行しません。

スカイカプセル (Sky Capsule / 스카이캡슐)

  • 区間: 尾浦~青沙浦の2.0km。高さ7~10mのレールの上を平均時速4kmで進みます。片道約30分です。4人乗りのカプセル80台が走ります。
  • 運行時間: 冬季は08:30~18:00。間期は08:30~18:30、繁忙期は08:30~19:30、最繁忙期は08:30~20:30です。

タルマジキル ムーンタンロード (Dalmaji-gil Moontan Road / 달맞이길 문탠로드)

  • 国民投票: 「海雲台 タルマジキル」は、韓国観光公社「名所発掘100×100」のランニングコースのテーマの国民投票で130票・16位でした。
  • 2つの道を区別します:
  • タルマジキル: 海雲台区庁は、海雲台海水浴場から松亭海水浴場へ向かう途中、臥牛山 (Waosan / 와우산)の中腹を通る8kmのドライブコースとして紹介しています。15回以上曲がるので15曲道とも呼ばれます。頂上にタルマジ丘 (Dalmaji Hill / 달맞이동산)、海月亭 (Haewoljeong / 해월정)(1997)、新千年記念時計塔 (Sae Cheonnyeon Memorial Clock Tower / 새천년기념시계탑)(2000)があります。
  • ムーンタンロード: 歩く道です。Visit Busanは、全長2.2kmの周回コースで、一周に余裕をみて1時間と書いています。
  • ライトアップ: ムーンタンロードのライトは、日没後から23時まで、そして早朝5時から日の出まで点灯します。
  • 行き方(Visit Busanの案内):
  • 2号線 海雲台駅1番出口からマウルバス 海雲台区2または海雲台区10に乗り、「海月亭入口・ヒルサイドスーパー (Haewoljeong Ipgu Hillside Supeo / 해월정입구.힐사이드 슈퍼)」で降りて歩いて7分。

  • 入口の住所: 釜山 海雲台区 タルマジキル 190 (Dalmaji-gil 190 / 달맞이길 190)。

  • 傾斜: 韓国観光公社のアクセシビリティ案内では、散策路の入口に傾斜10度前後の区間があり、休憩スペースと展望デッキのスロープは5~9度です。
  • 利用時間・料金: 常時開放、年中無休で、入場料はありません。
  • 行き方: 2号線 冬柏駅1番出口から出ます。Visit Busanは、1番出口から歩いて17分と書いています。バスは1003番に乗り、「冬柏島」で降ります。
  • 施設: トイレがあります。釜山市のヌリマルの案内は、冬柏公園別館駐車場は有料で、冬柏島の周辺は駐車スペースが狭く週末と祝日は満車になるとして、公共交通機関を勧めています。

ヌリマルAPECハウス (Nurimaru APEC House / 누리마루 APEC하우스)

  • 運営時間: 09:00~18:00。入場は閉館1時間前に締め切ります。17:00前に着かないと入れません。
  • 休みの日: 毎月第1月曜日。
  • 料金: 無料。
  • 行き方: 2号線 冬柏駅1番出口、またはバス1003番「冬柏島」停留所。冬柏島海岸散策路の終わりで出会います。
  • 問い合わせ: 051-743-1974~5。

ザ・ベイ101 (The Bay 101 / 더베이101)

  • 場所(カカオマップの登録値、2026-11-24): 釜山 海雲台区 トンベンロ 52 (Dongbaek-ro 52 / 동백로 52)。
  • 営業時間(カカオマップの登録値、2026-11-24): 毎日 08:00~24:00。
  • 行き方: カカオマップの経路検索では、2号線 冬柏駅1番出口から歩いて13分(751m)です。
  • 組み合わせ方: 冬柏島と同じ駅、同じ出口を使います。ヌリマル(18:00閉館)と散策路を先に見て、夕方に立ち寄ります。営業時間24:00はカカオマップの登録値です。

③ 広安里エリア — 3か所

このエリアは、広安里海水浴場、広安里Mドローンライトショー、二妓台海岸散策路です。二妓台海岸散策路は広安里の南、釜山の南区側の海岸です。駅も違います。広安里は錦連山駅・広安駅、二妓台は慶星大・釜慶大駅からバスに乗り換えます。

広安里海水浴場 (Gwangalli Beach / 광안리해수욕장)

  • 国民投票: 広安里海水浴場は、韓国観光公社「名所発掘100×100」のランニングコースのテーマの国民投票で148票・4位でした。
  • 大きさ: 釜山市は「総面積82,000㎡、砂浜の長さ1.4km、砂浜の幅は25~110m」と書いています。端から端まで往復すると2.8kmです。
  • 利用時間・料金: Visit Busanは、常時開放、年中無休、無料と書いています。ビーチのテーマ通りで散歩や自転車を楽しめ、夏には公演が開かれると紹介しています。
  • 夜: Visit Busanは、広安大橋 (Gwangandaegyo Bridge / 광안대교)のライトが毎秒色を変えると書いています。
  • 季節: 11月は海水浴の季節ではありません。
  • 行き方: 機関ごとに出口の案内が違います。
  • 水営区の案内: 都市鉄道2号線 錦連山駅3番出口から歩いて5分、広安駅3番出口から歩いて10分。
  • Visit Busanの案内: 2号線 広安駅5番出口から歩いて約13分。
  • バス: 水営区は41・49・38・42・51・62・83・83-1・108-1番に乗り、「広安里海水浴場」で降りて3分と書いています。Visit Busanは42・62番を挙げています。
  • 住所: 釜山 水営区 広安海辺路 219一帯(広安洞) (Gwangan Haebyeon-ro 219 / 광안해변로 219)。
  • 駐車: Visit Busanは「近くの公営駐車場」を案内しています。
  • 周辺: Visit Busanは、隣の見どころとして広安大橋の夜景、民楽刺身通り (Millak Hoetjip Geori / 민락횟집거리)、水辺公園 (Subyeon Park / 수변공원)、南川洞 (Namcheon-dong / 남천동)の桜並木を挙げています。

広安里Mドローンライトショー (Gwangalli M Drone Light Show / 광안리 M 드론라이트쇼)

  • いつ: 釜山市の案内では、毎週土曜日に定期公演があります。10~2月の冬季は19:00と21:00の2回です。
  • 中止の条件: 天候または技術上の問題で、中止や遅れが出ることがあります。
  • 曜日: 平日と日曜日には定期公演がありません。釜山の日程に土曜日が入っているか、先に確認します。
  • 行き方: 広安里海水浴場を基準に、錦連山駅3番出口から歩いて5分(水営区の案内)です。
  • 時間の合わせ方: 19:00の公演を見るなら、海辺列車の冬季最終(19:00)と重なります。ブルーラインパークは昼に乗り、夕方に広安里へ移ります。

二妓台海岸散策路 (Igidae Coastal Trail / 이기대 해안산책로)

  • 国民投票: 「釜山 二妓台海岸散策路」は、韓国観光公社「名所発掘100×100」のトレイルランニングコースのテーマの国民投票で125票・2位でした。
  • 場所: 広安里の南の海岸です。行政区域は釜山の南区です。
  • 区間・距離: Visit Busanは、トンセンマル (Dongsaengmal / 동생말)からオウルマダン (Oullmadang / 어울마당)、ノンバウィ (Nongbawi / 농바위)を経て五六島 (Oryukdo Islets / 오륙도)の船着き場まで、全長4.7km、歩いて約2時間30分と書いています。
  • 道の性格: 上り坂の区間があります。砂浜の散歩より時間と体力がかかる道として考えます。
  • 利用時間・料金: 常時開放で無料です。
  • 行き方: 都市鉄道2号線 慶星大・釜慶大駅からバスに乗り換えます。バスは20・22・24・27・39・131番、マウルバスは南区2・南区8です。
  • 駐車: 二妓台公営駐車場があり、有料です。
  • 計画: 一方の端から入って、もう一方の端に出る道です。広安里と組み合わせるなら、半日を別に取って昼に歩き、夕方に広安里へ戻ります。

🗺 動線 — 半日・1日

順番は、各所の開場・閉場の時刻に合わせて組みました。機関が示した所要の値は、カプセル約30分、列車片道約25分、ムーンタンロード余裕をみて1時間、二妓台約2時間30分です。

半日 A — 海雲台の昼 (曜日を問わない)

  1. 2号線 海雲台駅5番出口 → 海雲台海水浴場(カカオマップの経路検索で歩いて11分)。砂浜1.5kmを歩きます。
  2. 10:00に開くSEA LIFE釜山アクアリウムか釜山エックス・ザ・スカイのどちらか1か所。
  3. 尾浦停車場 → スカイカプセルで青沙浦まで(約30分)。
  4. 青沙浦 → 海辺列車で尾浦または松亭まで。青沙浦発の1回券は8,000ウォンです。
  5. 海雲台駅の方へ戻って、海雲台伝統市場(カカオマップの登録値で22:00まで)。

冬季はスカイカプセルが18:00まで、海辺列車は尾浦・松亭を19:00に最後に出ます。3番と4番を午後遅くに回さないようにします。

半日 B — 冬柏島から広安里の夕方 (土曜日)

  1. 2号線 冬柏駅1番出口 → 冬柏島海岸散策路 約950m。
  2. ヌリマルAPECハウス。17:00前に入ります。第1月曜日は休みです。
  3. 冬柏駅 → 2号線 錦連山駅3番出口 → 広安里海水浴場(歩いて5分)。
  4. 19:00 広安里Mドローンライトショー。見逃しても21:00の公演がもう1回あります。

土曜日でなければ4番を抜いて、3番の代わりにザ・ベイ101(カカオマップの登録値で24:00まで)に変えてもかまいません。

時間帯 場所 合わせる時間

⚠ よくある失敗3つ

  1. スカイカプセルの料金を1人の料金と思う — スカイカプセルはカプセル1台の料金です。2人乗り50,000ウォン、3人乗り55,000ウォン、4人乗り60,000ウォンです。4人で乗れば1人15,000ウォンあたりですが、2人なら25,000ウォンあたりです。海辺列車の1回券も降りると再乗車できないので、途中の停車場で降りてまた乗るなら、全駅券(16,000ウォン)を買います。
  2. ドローンショーをどの日の夕方でも見られると思って行く — 定期公演は土曜日で、冬季は19:00と21:00の2回です。天候や技術上の問題で中止や遅れが出ることがあります。土曜日の夜に、ほかの予約を重ねません。
  3. 二妓台を広安里のそばの短い散歩と思う — 二妓台海岸散策路は広安里の南の南区の海岸で、4.7kmに約2時間30分かかります。上り坂もあります。駅からバスに乗り換えないと着きません。タルマジキルも似ています。タルマジキル自体は8kmのドライブコースで、歩く道は2.2kmの周回コースのムーンタンロードです。

⚙ FAQ 3つ

  1. 11月でも海雲台に行く価値はある? — 11月は海水浴の季節ではないので、海に入る日程は組みません。その代わり、屋内施設と乗り物は冬季の時間で開いています。SEA LIFE釜山アクアリウムは月~金19:00、土・日20:00まで、釜山エックス・ザ・スカイは毎日21:00までです。海辺列車とスカイカプセルは冬季ダイヤ(19:00、18:00まで)で走ります。海雲台海水浴場のライトアップは日没後から24:00まで点灯し、広安里海水浴場は常時開放です。
  2. 表で料金が書いてある所と無料と書いてある所は? — 料金がかかるのは、釜山エックス・ザ・スカイ(大人29,000ウォン)、海雲台ブルーラインパーク(海辺列車1回券8,000~10,000ウォン、スカイカプセル1台50,000~60,000ウォン)、SEA LIFE釜山アクアリウムです。無料または入場料がないのは、広安里海水浴場、冬柏島海岸散策路、ヌリマルAPECハウス、二妓台海岸散策路です。料金はすべて2026-11-24に確認した値です。
  3. 金海空港から海雲台へはどう行く? — 空港リムジンの海雲台路線があります。大人9,500ウォンで、「海雲台海水浴場(09116)」停留所で降ります。2026-01-05に路線が改編され、萇山方面(所要90分、空港発07:10~16:50)と機張方面(所要110分、空港発10:10~21:40)の2系統で走ります。
