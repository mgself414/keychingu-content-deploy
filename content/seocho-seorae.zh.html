🎯 为什么瑞草·瑞来村 (Seocho·Seorae Maeul / 서초·서래마을) 值得单独推荐

瑞草 (Seocho / 서초)·瑞来 (Seorae / 서래) 是瑞草区 (Seocho-gu / 서초구) 外国人居住的首选地·韩国中产阶级热门区域 — 尤其是瑞来村 (Seorae Maeul / 서래마을) (盘浦4洞 / Banpo 4-dong / 盘浦 (Banpo / 반포)4동) 是韩国最大的法国人社区，LFS (Lycée Français de Séoul, 首尔法国学校 / 서울 프랑스 학교, 1974年建校) 坐落于此，是外国人居住的首选地。MAILLET (메이에)·fincafe (핀카페) 等法国传统面包店、法式糕点店和法式餐厅密集分布于小巷 (golmok / 골목) 之间，被称为“首尔的小巴黎”。

与江南 (Gangnam / 강남)·梨泰院 (Itaewon / 이태원)·弘大 (Hongdae / 홍대) 相比，瑞草 (Seocho / 서초)·瑞来 (Seorae / 서래) 更具外国人居住、家庭和中产阶级特色。虽然在外国游客的行程中常被明洞 (Myeongdong / 명동)·江南 (Gangnam / 강남)·梨泰院 (Itaewon / 이태원) 掩盖，但了解并前往的外国游客会将其评为“韩国最对外国人友好的社区”。教大 (Gyodae / 교대)·法曹城 (Beopjo Town / 법조타운) (瑞草 (Seocho / 서초) 主要区域) + 盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) + 江南客运站 (Gangnam Terminal / 강남터미널) 免税店 + 良才市民之林 (Yangjae Citizens' Forest / 양재 시민의숲) 等适合家庭的景点也十分丰富。

特别是瑞来村 (Seorae Maeul / 서래마eul) 的 MAILLET (메이에)，这家1995年创立的韩国传统法式糕点店 — 为世宗路新罗酒店 (Sejong-ro Hotel Shilla / 세종로 호텔 신라)·首尔新罗酒店 (Seoul Shilla Hotel / 서울 신라 호텔) 供货，是韩国首屈一指的法式面包店。它是外国人深度体验韩国居住生活的首选。继#138 弘大 (Hongdae / 홍대)·#142 江南 (Gangnam / 강남)·#144 梨泰院 (Itaewon / 이태원)·#156 延禧洞 (Yeonhui-dong / 연희동)·#169 汝矣岛 (Yeouido / 여의도)·#170 大学路 (Daehangno / 대학로)·#171 新村 (Sinchon / 신촌)·#172 DDP东大门设计广场 (DDP Dongdaemun Design Plaza / DDP) (东大门设计广场 / Dongdaemun Design Plaza) 之后，作为ISSUE 03的第⑭篇加入 — KeyChinGu (키친구) 首次进入瑞草区 (Seocho-gu / 서초구) (利用84个集群数据)。

⚠ 外国人常犯的3个错误

1. “瑞草 (Seocho / 서초) = 和江南 (Gangnam / 강남) 是同一个地方” — 未考虑瑞来村 (Seorae Maeul / 서래마을) 是外国人居住首选地

这是外国游客行程中最常见的错误。瑞草 (Seocho / 서초)·瑞来 (Seorae / 서래) 虽然与江南区 (Gangnam-gu / 강남구) 相邻，常被误认为“属于江南 (Gangnam / 강남)”，但实际上，瑞来村 (Seorae Maeul / 서래마을) 是韩国最大的法国人社区 + 外国人学校·外国人居住首选地 = 与江南 (Gangnam / 강남) (奢华·购物) 风格迥异。MAILLET (메이에)·fincafe (핀카페) 等法式面包店集群是外国人深度体验韩国居住生活的首选。

2. “教大 (Gyodae / 교대) = 只有法曹城 (Beopjo Town / 법조타운)” — 未了解韩餐·平壤冷面 (Pyeongyang Naengmyeon / 평양 냉면) 集群

外国人常将教大 (Gyodae / 교대) 仅视为“法律界人士的社区”，但实际上，这里是The Jinmi Pyeongnaeng (더진미평냉)·Seocho Myeonok (서초면옥)·Gyodae Yichungjip (교대이층집) 等韩餐传统餐厅密集的韩国中产阶级·法律界人士午餐首选地。平壤冷面 (Pyeongyang Naengmyeon / 평양 냉면) (朝鲜半岛北部传统冷面) 是外国人体验韩国传统冷面料理的首选 — The Jinmi Pyeongnaeng (더진미평냉) 是瑞草 (Seocho / 서초) 传统平壤冷面 (Pyeongyang Naengmyeon / 평양 냉면) 的代表。

3. “盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) = 只是汉江 (Hangang / 한강)” — 未了解潜水桥 (Jamsugyo / 잠수교)·月光彩虹喷泉 (Dalbit Mujigae Fountain / 달빛무지개분수)

盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) 拥有潜水桥 (Jamsugyo / 잠수교) (单层桥梁，下雨时会被水淹没) + 月光彩虹喷泉 (Dalbit Mujigae Fountain / 달빛무지개분수) (盘浦大桥 (Banpodaegyo / 반포대교) 桥身喷射彩虹水柱) = 外国人Instagram (인스타그램) 拍照打卡首选。夏季4~10月 + 夜间 (20:00·20:20·20:40·21:00·21:20) 的喷泉表演 + 潜水桥 (Jamsugyo / 잠수교) 散步 = 外国人约会·家庭出游的首选。

瑞草 (Seocho / 서초)·瑞来 (Seorae / 서래) 风景

瑞草 (Seocho / 서초)·瑞来 (Seorae / 서래) 位于瑞草区 (Seocho-gu / 서초구) 中心，是外国人居住 + 韩国中产阶级融合区域 — 随着1970~80年代江南 (Gangnam / 강남) 开发而形成的韩国中产阶级社区 + 1985年LFS (法国学校 / Lycée Français de Séoul) 成立后，瑞来村 (Seorae Maeul / 서래마을) 成为韩国最大的法国人社区。

瑞来村 (Seorae Maeul / 서래마을) (盘浦4洞 / Banpo 4-dong / 盘浦 (Banpo / 반포)4동) 子区域以瑞来路 (Seorae-ro / 서래로)·瑞来村广场 (Seorae Maeul Plaza / 서래마을 광장) 为中心 — 法国学校 LFS (Lycée Français de Séoul / 서울 프랑스 학교) + 法式面包店·糕点店·法式餐厅50多家密集分布。步行30分钟即可逛完整个紧凑的社区。从7号线·9号线盘浦站 (Banpo Station / 반포역)·高速客运站 (Express Bus Terminal Station / 고속터미널역) 步行10~15分钟。

教大 (Gyodae / 교대)·法曹城 (Beopjo Town / 법조타운) 子区域位于教大站 (Gyodae Station / 교대역) (2号线·3号线) 附近 — 韩餐·法律界人士午餐·中产阶级餐厅。韩国传统韩餐店密集。

盘浦 (Banpo / 반포)·汉江公园 (Hangang Park / 한강공원) 子区域是盘浦大桥 (Banpodaegyo / 반포대교)·潜水桥 (Jamsugyo / 잠수교)·月光彩虹喷泉 (Dalbit Mujigae Fountain / 달빛무지개분수) 所在的汉江 (Hangang / 한강) 核心景点。汉江 (Hangang / 한강) 自行车道 + 散步 + 夜间喷泉表演。

江南高速客运站 (Gangnam Express Bus Terminal / 강남고속버스터미널) 子区域有湖南线 KTX (Honam Line KTX / 호남선 KTX) + 新世界江南免税店 (Shinsegae Gangnam Duty Free / 신세계 강남 면세) + 江南客运站地下街 (外国人购物首选)。

良才 (Yangjae / 양재)·梅轩 (Maeheon / 매헌) 子区域有良才市民之林 (Yangjae Citizens' Forest / 양재 시민의숲)·良才川 (Yangjaecheon / 양재천) + 适合外国人家庭的餐厅。9号线梅轩站 (Maeheon Station / 매헌역)·新论岘站 (Sinnonhyeon Station / 신논현역)。

交通: 7号线盘浦站 (Banpo Station / 반포역) (瑞来村 / Seorae Maeul / 서래마을) / 2·3号线教大站 (Gyodae Station / 교대역) / 9号线梅轩站 (Maeheon Station / 매헌역)·新论岘站 (Sinnonhyeon Station / 신논현역) / 3·7·9号线高速客运站 (Express Bus Terminal Station / 고속터미널역)。建议使用Kakao Taxi (카카오 택시)。Ttareungi (따릉이) (首尔共享单车) 可用。

⚙ 常见问题 (8个)

Q1. 瑞来村 (Seorae Maeul / 서래마을) 为什么是法国人居住首选地？

1974年LFS (Lycée Français de Séoul / 서울 프랑스 학교) 成立 — 作为首尔法国外交官·企业家的子女学校而开始。学校附近形成了法国学生家长的居住区 → 1990年代起法式面包店·糕点店·餐厅密集分布于小巷 (golmok / 골목) 之间 → 形成了韩国最大的法国人社区。目前约有3,000~5,000名法国人 + 外国人居住。

Q2. 如何前往MAILLET (메이에)·是否需要预约？

瑞来村 (Seorae Maeul / 서래마을) 步行5分钟 (盘浦站 (Banpo Station / 반포역) 或新盘浦站 (Sinbanpo Station / 신반포역) 步行10~15分钟) — 无需预约，可直接前往，但节日·季节限定糕点建议提前预订。由于是热门地点，午餐·周末可能会排队。平日14:00~17:00 (下午2点~5点) 比较清闲。

Q3. 月光彩虹喷泉 (Dalbit Mujigae Fountain / 달빛무지개분수) 的时间·季节？

夏季4~10月夜间: 20:00·20:20·20:40·21:00·21:20 (每20分钟一次) — 平日4次·周末5次。免费。盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) 潜水桥 (Jamsugyo / 잠수교) 附近观景台是首选。下雨时停止运营。

Q4. 瑞来村 (Seorae Maeul / 서래마을) 对外国人友好的餐厅有哪些？

MAILLET (메이에)·fincafe (핀카페)·瑞来村 (Seorae Maeul / 서래마ul) 法式餐厅提供英文·法文菜单 + 信用卡支付 + 对外国人友好的标准服务。The Jinmi Pyeongnaeng (더진미평냉)·Seocho Myeonok (서초면옥) 主要提供韩文菜单，但有图片菜单·店员友好服务。

Q5. 江南客运站地下街从哪里开始？

3·7·9号线高速客运站 (Express Bus Terminal Station / 고속터미널역) 8号出口直达。GOTO Mall (GOTO몰) (韩国服装批发·零售首选地下街) + Central City (CENTRAL CITY) (新世界江南免税店 (Shinsegae Gangnam Duty Free / 신세계 강남 면세) + 湖南线 KTX (Honam Line KTX / 호남선 KTX) 售票处)。批发价格50~70%。

Q6. 潜水桥 (Jamsugyo / 잠수교) 可以骑自行车·散步吗？

可以 — 步行·骑自行车均可。下雨时会被水淹没并管制 (韩国唯一的单层桥梁)。盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) 自行车道 + 潜水桥 (Jamsugyo / 잠수교) → 铜雀大桥 (Dongjakdaegyo / 동작대교) → 汉南大桥 (Hannamdaegyo / 한남대교) → 东湖大桥 (Donghodaegyo / 동호대교) = 约8公里汉江 (Hangang / 한강) 自行车路线。

Q7. 良才市民之林 (Yangjae Citizens' Forest / 양재 시민의숲) 外国人散步的最佳时间？

上午10:00~12:00 (上午10点~中午12点) + 下午14:00~16:00 (下午2点~4点) 最佳 — 韩国家庭 + 外国人居住散步。春季4月樱花 + 秋季10~11月枫叶是首选。9号线梅轩站 (Maeheon Station / 매헌역) 步行5分钟 + 梅轩尹奉吉义士纪念馆 (Maeheon Yun Bong-gil Memorial Hall / 매헌 윤봉길 의사 기념관) 免费入场。

Q8. 瑞草 (Seocho / 서초) + 江南 (Gangnam / 강남) + 汉江 (Hangang / 한강) 的连接路线？

可以 — 瑞草 (Seocho / 서초)·瑞来村 (Seorae Maeul / 서래마을) → 江南 (Gangnam / 강남) (地铁7号线·9号线2~3站) → 盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) (步行15分钟) → 蚕室 (Jamsil / 잠실) 或汝矣岛 (Yeouido / 여의도) (自行车30分钟~1小时)。可以安排一日全天行程。
