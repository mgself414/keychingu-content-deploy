🎯 왜 떡 4채널 비교 가이드인가

[#855 떡류 6종 매트릭스](#855) + [#856 워크플로우](#856) 알아도 — 채널 선택이 다음 결정. 한국 떡 채널 = (1) 전통 떡집 (광장시장·인사동 노포)·(2) 시장 떡복이·시장 떡 (광장·통인 시장)·(3) MZ 카페 (인절미 토스트·찰떡볶이)·(4) 면세점·온라인 (진공 포장) 4가지. 가격 5,000원 → 80,000원, 분위기 정통 → 시장 → MZ → 면세 차이. 본 가이드는 4채널 직접 비교 + segment(혼자·커플·가족·MZ·예산형)별 1순위. 회·BBQ·국밥·분식·면류·치킨·디저트·김치·보양식·술·한정식·전통음료·야식·김밥·발효·고기 반찬 cluster 패턴 적용.

🏯 4채널 deep dive

🏯 전통 떡집 (Traditional Tteokjip)

핵심 가치: 정통 6종 + 노포 + 명절·잔치 #1.

  • 추천 매장 (서울):
  • 광장시장 떡집 cluster — 외국인 vlog 1번지
  • 인사동 전통 떡집 — 한옥
  • 남대문 시장 떡집 — 가성비
  • 추천 매장 (지방):
  • 전주 한옥마을 떡집 — 정통
  • 메뉴: 가래떡·송편 (시즌)·인절미·백설기·경단
  • 가격 anchor: 5,000~30,000원 (1관 잔치 30~80k)
  • 외국인 친화도: ★★★★ (영문 일부)

🛒 시장 떡 (Market)

핵심 가치: 가성비 + 시장 vibe + 외국인 vlog 1번지.

  • 추천 시장:
  • 광장시장 떡볶이·떡 골목 — 외국인 vlog #1
  • 통인시장 도시락 떡 — 통인 도시락 정통
  • 남대문 시장 — 가성비
  • 노량진 시장 — 분식 cluster
  • 메뉴: 정통 6종 + 떡볶이 + 시장 변형
  • 가격 anchor: 3,000~10,000원 (시장 가성비)
  • 외국인 친화도: ★★★★ (광장 vlog ★)

☕ MZ 카페 (MZ Korean Cafe)

핵심 가치: 트렌디 + 인절미 토스트·찰떡볶이·MZ 트렌드 #1.

  • 추천 영역 (서울):
  • 홍대·연남 MZ 카페 cluster
  • 강남·역삼 — 직장인 MZ
  • 성수동 — 트렌드 (블루보틀 + 인절미)
  • 이태원 — 외국인 친화
  • 메뉴: 인절미 토스트·인절미 빙수·인절미 라떼·찰떡볶이·MZ 송편
  • 가격 anchor: 6,000~15,000원
  • 외국인 친화도: ★★★★★ (영문·키오스크·MZ)

✈️ 면세점·온라인 (Duty-Free·Online)

핵심 가치: 진공 포장 + 귀국 선물 #1 + VAT 환급.

  • 추천 매장:
  • 인천공항 면세점 — 진공 포장 6종 (귀국 직전 픽업)
  • 김해·제주공항 면세점 — 지방
  • 온라인 (쿠팡·11번가) — 시내 픽업·해외 배송
  • 메뉴: 진공 포장 가래떡·송편·인절미·백설기·경단
  • 가격 anchor: 15,000~30,000원/관 (면세점 프리미엄)
  • 외국인 친화도: ★★★★★ (영어·1순위·면세)
  • VAT 환급: 가능

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가격·분위기·시기 완전 다름. 정통 = 전통 떡집 / 가성비 = 시장 / 트렌디 = MZ / 면세 = 면세점.

2. "광장시장 = 떡볶이만": 광장시장 = 6종 떡 + 떡볶이 + 시장 분식 풀세트.

3. "MZ 카페 = 트렌드만": MZ 카페 = 인절미 정통 + 트렌드 변형 (인절미 토스트는 정통+모던).

4. "면세점 = 비싸기만": 면세점 진공 포장 = VAT 환급 + 프리미엄 = 일반 가격 + 환급 절감.

5. "잔치용 떡 = 어디나": 백설기 1관 (30,000~80,000원) = 전통 떡집·잔치 매장 사전 주문.

⚙ FAQ 8개

1. 첫 떡 = 어떤 채널: 시장 (광장·통인) 1순위 (가성비 + 분위기) → MZ 카페 (트렌디).

2. 인스타·vlog: 광장시장 떡 골목 #1·MZ 인절미 토스트·인사동 전통 떡집.

3. 데이트·기념일: 시장 떡 (광장 데이트) + MZ 카페 (트렌디).

4. 가족 동반: 전통 떡집 (잔치·돌) + 시장 떡 (가성비).

5. MZ 트렌드: MZ 카페 인절미 토스트·찰떡볶이·MZ 송편.

6. 알레르기·임신: [#855·#856 disclaimer](#855) 참조.

7. 결제·팁: 떡집·면세점·MZ = 카드 OK / 시장 = 현금 / 팁 X.

8. VAT 환급: 면세점 떡 = 환급 가능 / 일반 = 환급 X.

⚠ 의료·안전·식이 disclaimer

떡 4채널 모두 일반 음식. 질식 위험 (가래떡·인절미 = 어린이·노인 작게 잘라서). 임신부 = 콩고물·견과류 적당량. 알레르기 (콩·깨·견과류·꿀) 사전 고지. 질식·식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 동물 재료 X = OK (꿀 함유 확인).
  • 채식·비건: 6종 모두 채식 OK (꿀 함유 시 비건 X).
  • 글루텐 free: 6종 모두 쌀 100% = 글루텐 free OK.
