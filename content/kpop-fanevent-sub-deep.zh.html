🎯 本指南的使用方法

清晨六点半，在汝矣岛 (Yeouido / 여의도) KBS新馆公开厅 (Sinkwan Gonggaeholl / 신관 공개홀) 门前，手里攥着护照，等着叫到自己的号码。音乐节目预录就是这样开始的(CORTIS官方公告 2026-04-24)。有些活动像演唱会一样买票就行，但K-pop粉丝活动大多要按经纪公司公告上写的规则申请、中签、通过身份核对才能进场。

本文整理来韩国的外国粉丝可以参加的五大类活动。日期和人数每一期都会变，所以我们用经纪公司公告原文来展示公告要求什么。这里引用的公告全部是已经结束的期次。

📺 音乐节目观众席 — 通过粉丝俱乐部公告申请

在电视台网站上，我们没有找到面向外国人的观众席申请窗口。实际申请是由出演艺人的经纪公司通过给粉丝俱乐部的公告开启的。每份公告都包含下列项目。

  • 资格: TXT的KBS2 Music Bank (Music Bank / 뮤직뱅크，2026-07-17)·SBS Inkigayo (Inkigayo / 인기가요) 预录(2026-07-19)公告写明，只有MOA Membership会员才能申请。年龄限制为韩国·美国满15岁以上，其他国家·地区满16岁以上，即使有监护人陪同，未达标准者也不能进场(TXT官方公告)
  • 申请窗口: 在节目播出前一天开放30分钟。Music Bank是7月16日 13:30~14:00，Inkigayo是7月18日 10:30~11:00(KST)(TXT官方公告)
  • 人数: Music Bank正式直播按先到先得选出5人和候补3人，Inkigayo预录选出120人和候补5人(TXT官方公告)。每一期差别很大
  • 专辑·认证: CORTIS的Music Bank预录(2026-04-24)除了COER Membership之外，还要求在Weverse Global购买3张以上专辑或1个套装，并提交Melon下载记录的打印件。不接受手机屏幕截图(CORTIS官方公告)
  • 地点: 人数核对在汝矣岛 (Yeouido / 여의도) KBS新馆公开厅 (Sinkwan Gonggaeholl / 신관 공개홀) 门前(首尔永登浦区 (Yeongdeungpo-gu / 영등포구) 汝矣公园路 (Yeoui-gongwon-ro / 여의공원로) 13)(CORTIS官方公告)，以及登村洞 (Deungchon-dong / 등촌동) SBS公开厅 (Gonggaeholl / 공개홀) 门前(TXT官方公告)进行
  • 外国人身份证件: 护照或外国人登录证。申请时如果用英文填写了姓名，则只用护照核对。学生证·照片·打印件都不行(CORTIS官方公告)
  • 现场规则: 禁止在摄影棚内拍摄·录像·录音，弄丢领到的手环将限制入场，禁止擅自排队。中签后缺席的话，该专辑活动期间不能参加公开录制活动(TXT官方公告)

各电视台的节目日程，请接着看K-pop音乐节目。

✍ 签售会·视频通话 — 一张专辑一次应征

签售会不卖票。在指定销售处买专辑，买几张就应征几次，通过抽签选出。

  • Weverse Shop (Weverse Shop / 위버스샵) 方式(TXT 正规4辑，2025年6~7月) — 应征期间，按在Weverse Global的Weverse Shop (Weverse Shop / 위버스샵) 下单的专辑总数量自动应征。套装商品按里面包含的唱片数计算。用购买时的同一个ID，在Weverse应征页面填写必填信息。中签公布在7月21日 20:00(KST)(TXT官方公告)
  • Ktown4u (Ktown4u / 케이타운포유) 方式(TREASURE，2025年3月) — 应征销售处是Ktown4u线上商城的KR·EN·CN。即使分成多笔订单购买，也按合计数量应征。中签者通过Ktown4u (Ktown4u / 케이타운포유) 官网公告公布，3月15日的活动规模为50人(TREASURE官方公告)
  • 外国人规则 — 应征时填写的英文姓名必须与证件上的英文姓名一致，不能用韩文姓名应征(TXT官方公告)。外国人只承认护照·外国人登录证实物，不接受照片(TREASURE官方公告)
  • 取消·转让 — 把为应征购买的商品全部取消，应征也会自动取消，中签公布后，应征专用商品不能取消支付·退款。中签资格不能代领·转让·买卖(TXT官方公告)

视频通话的进行方式，请看K-pop签售·视频通话。

🎂 生日咖啡厅 — 粉丝举办的非官方活动

生日咖啡厅不是经纪公司办的，而是粉丝把普通咖啡厅租几天举办的活动。没有官方公告，所以不推荐地点。只写找法与礼仪。

  • 找法: 在X·Instagram上，把艺人名字和「生咖」(Saengka / 생카)·「生日咖啡厅」(Saengil Kape / 생일카페) 一起搜索。在主办粉丝账号的公告里确认期间、营业时间、点饮品的条件、特典数量
  • 礼仪: 那里是正在营业的咖啡厅。要点饮品，排队按主办方的指引来。特典发完了也不要和咖啡厅员工争执。不要挡住其他顾客和邻近店铺的门口
  • 注意: 主办者是个人，所以日程可能突然改变

详细流程见偶像生日咖啡厅。

🛍 官方快闪·体验空间 — 无需预约就能进的地方

  • 光野@首尔 (Kwangya@Seoul / 광야@서울，KWANGYA@SEOUL) — 首尔城东区 (Seongdong-gu / 성동구) 往十里路 (Wangsimni-ro / 왕십리로) 83-21 地下1层，水仁盆唐线首尔林站 (Seoulsup-yeok / 서울숲역) 5号出口73m。每天 10:30~20:00，春节 (Seollal / 설날)·中秋 (Chuseok / 추석) 休息(Instagram公告)。电话 +82-2-6233-6729。网站为韩语(VisitSeoul)
  • Ktown4u COEX (Ktown4u COEX / 케이타운포유 코엑스) — 首尔江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513 COEX 2~4层，2号线三成站 (Samseong-yeok / 삼성역) 6号出口162m。2层的SQUARE是常设门店(11:00~20:00)，4层的SPACE是艺人与粉丝见面的快闪空间。网站支持韩·英·日·中(简体·繁体)·俄·马来语(VisitSeoul)
  • 便利店快闪 — CU配合RIIZE迷你专辑发行，于2026年6月20日~7月5日在圣水甜点公园店 (Seongsu Dessert Park-jeom / 성수디저트파크점) 开设了快闪店(BGF Retail新闻稿 2026-06-15)。这是已经结束的活动

🎫 演唱会订票 — 使用面向外国人的网站

  • NOL World(world.nol.com) — 英文页面上有K-POP·Concert门票菜单、住宿预订，以及演出加住宿的捆绑产品「Play&Stay」(NOL World官方)。支付方式说明，我们在打开的页面中没能确认
  • Melon Ticket Global(tkglobal.melon.com) — 设有英文·中文·日文菜单的面向外国人的网站。运营方是Kakao Entertainment(Melon Ticket Global官方)。购买指南页面没能打开
  • 演出场馆 KSPO DOME — 奥林匹克公园 (Ollimpik Gongwon / 올림픽공원) 内的体操竞技场，共15,000席。截至10月21日，奥林匹克公园官方网站上挂有公告，称因游泳池·KSPO DOME等施工，部分区域限制使用(KSPO&CO 奥林匹克公园官方)

🧰 粉丝活动实用信息 — 独自、预约、支付、交通

  • 独自: 观众席·签售会以个人为单位申请，只有本人可以进场。禁止代为申请·转让(TXT·CORTIS官方公告)
  • 预约: 来之前先注册好粉丝俱乐部会员和Weverse账号。观众席的申请窗口曾只在节目播出前一天开放30分钟(TXT官方公告)
  • 支付: 外国人韩国支付系统深度探索
  • 交通: 要赶上清晨的人数核对，住在公开厅附近比较好。交通卡见韩国交通卡3种选择，零慌张手册 — 按我的行程原样挑卡

⚠ 常见错误4

1. 「在电视台网站上买观众席票」 — 从公告来看，观众席不是售票，而是粉丝俱乐部会员的先到先得申请，申请是由经纪公司通过公告开启的(TXT官方公告)

2. 「用韩文姓名应征也可以」 — 外国人只能用与证件相同的英文姓名应征(TXT官方公告)

3. 「用手机里的照片出示证件」 — 只承认实物护照·外国人登录证(CORTIS·TREASURE官方公告)

4. 「中签了，专辑可以取消」 — 中签公布后，应征专用商品不能取消支付·退款(TXT官方公告)
