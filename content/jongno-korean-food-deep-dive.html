외국인 종로 한식 deep dive

> 600년 조선 도성 — 인사동 한정식·광장시장 국밥·을지로 노포·궁중 한식 15곳 매트릭스

종로는 600년 조선 한양 도성. 경복궁·창덕궁·창경궁 3대 궁궐 사이 권역으로 한국 한식의 메카. 광장시장 (한국 最古 시장 1905년)·인사동 (한정식 cluster)·을지로 (노포 cluster)·창덕궁 인근 궁중 한식까지 — 외국 segment·foodie·history buff 페르소나에게 한식 deep dive 1순위. 본 가이드는 4권역 한식 15곳 + 1일 동선 매트릭스 + 한식 etiquette.

1. 종로 한식 풍경 (외국인 fit fact)

600년 한식 역사

  • 1392년 조선 한양 천도 → 종로 = 도성 중심
  • 궁중 한식·반가 한식·서민 한식 모두 종로에 cluster
  • 광장시장 1905년 개장 = 한국 最古 상설 시장
  • 인사동 = 조선 후기 양반 거주 → 한정식 cluster
  • 을지로 = 일제강점기·해방 이후 노포 cluster

한식 4 유형 (종로에 모두 있음)

  • 궁중 한식: 신선로·구절판·잡채·갈비찜 (조선 왕실)
  • 반가 한식: 한정식 12-20첩 (양반가)
  • 서민 한식: 국밥·국수·찌개·비빔밥 (시장)
  • 컨템포러리 한식: 미쉐린 매장 (모던 reinterpretation)

2. 인사동·삼청동 (한정식·궁중 한식)

1. 한국의 집 (인사동)

  • 위치: 종로구 필동
  • 시그니처: 궁중 한식 정통·외국인 1순위
  • 외국인 fit: ★★★ (영문 fluent·외국인 단골 50년)
  • 가격: 코스 ₩90,000~150,000
  • 특징: 한복 체험 + 전통 공연 + 한식 패키지

2. 온지움 (효자동)

  • 시그니처: 1 star·궁중 한식 reconstruction (cf. #1109)
  • 외국인 fit: ★★★
  • 가격: 디너 ₩280,000~360,000

3. 인사동 한정식 골목

  • 인사동 한정식 5-7곳: 12첩 한정식 표준
  • 가격: ₩40,000~80,000/인
  • 외국인 fit: ★★ (영문 메뉴 일부)

4. 삼청동 한정식

  • 북촌 인접: 한옥 + 한정식 (#1097 참조)

3. 광장시장 (서민 한식·시장 1905년~)

5. 광장시장 박가네 빈대떡 (★ Bib Gourmand)

  • 위치: 종로 4가 광장시장
  • 시그니처: 빈대떡 (한국 전통 부침개)
  • 외국인 fit: ★★★ (CNN·뉴욕타임스 추천·picture menu)
  • 가격: ₩8,000~15,000

6. 광장시장 마약김밥

  • 시그니처: 작은 김밥 + 단무지·고추냉이
  • 외국인 fit: ★★★ (외국인 unique·SNS top)
  • 가격: ₩3,000~5,000

7. 광장시장 육회

  • 시그니처: 생 소고기·시각 unique (외국인 도전)
  • 가격: ₩15,000~25,000

8. 광장시장 전·국밥 cluster

  • 다수 노점·노포: 빈대떡·전·국밥
  • 외국인 fit: ★★ (시장 분위기·picture menu·번역 앱)

6. 1일 표준 동선 (3 패턴)

Pattern A: 한식 deep dive 1일 (★ 외국인 1순위)

  • 09:00 경복궁
  • 11:00 토속촌 삼계탕 (점심·이열치열)
  • 13:30 인사동 한정식 골목 산책
  • 15:00 광장시장 (빈대떡·마약김밥·전)
  • 17:00 광장시장 → 을지로 노가리 골목
  • 19:00 우래옥 평양냉면 (저녁)
  • 21:00 인사동 전통차 + 디저트 마무리

Pattern B: 궁중·한정식 (special occasion)

  • 11:00 창덕궁 (오전 산책)
  • 13:30 한국의 집 (궁중 코스 + 공연)
  • 16:00 인사동 산책 + 갤러리
  • 18:30 온지움 (1 star 궁중 한식 디너)
  • 21:00 인사동 전통차

Pattern C: 시장 + 노포 (foodie·서민·로컬)

  • 10:00 광장시장 (아침 식사 + 산책)
  • 12:30 우래옥 (평양냉면 점심)
  • 14:00 을지로 노가리 골목 (낮맥)
  • 16:00 광장시장 (오후 시장 음식 hop)
  • 19:00 을지로 곰탕 노포 (저녁)
  • 21:00 광장시장 야시장 (소주 + 안주)

7. 외국인 fit Tips

영문 가능성

  • 상위: 한국의 집·온지움·토속촌·우래옥·박가네 빈대떡 (영문 메뉴·외국인 단골)
  • 중상: 인사동 한정식 (영문 메뉴 일부)
  • 로컬: 광장시장 노점·을지로 노포 (picture menu·번역 앱)

예산 (1인 1일)

  • Pattern A 한식 deep: ₩80,000~150,000 (다양한 매장 hop)
  • Pattern B 궁중·한정식: ₩200,000~400,000 (한국의 집 + 온지움)
  • Pattern C 시장·노포: ₩50,000~100,000

페르소나별

  • 미국 페르소나: Pattern A (1일 다 가능)
  • 유럽 페르소나: Pattern B (궁중·art·역사)
  • foodie·로컬: Pattern C (시장·노포 deep)
  • anniversary·special: 온지움 + 한국의 집
  • K-drama 팬: 광장시장·인사동 (다수 촬영지)

시즌별

  • 봄 (4-5월): 인사동·광장시장 + 궁궐 산책
  • 여름 (6-8월): 토속촌 삼계탕·평양냉면·콩국수
  • 가을 (10-11월): 한정식 (가을 식재료·송이·전어)
  • 겨울 (12-2월): 국밥·곰탕·전골 (을지로 노포)

8. 한식 etiquette (외국인 fit 안내)

Do

  • 어른·연장자 먼저 식사 시작
  • 두 손으로 음료 받기·드리기
  • 밥그릇 들지 X (한식 = 그릇 두고 식사)
  • 젓가락 + 숟가락 동시 사용 (밥·국은 숟가락)
  • 반찬 share OK·다 먹어도 OK (대부분 무료 리필)
  • 한정식: 첩 수 의미 (12첩 = 양반·5첩 = 서민)

Don't

  • 코 풀기 X (식탁에서)
  • 젓가락을 밥 위에 꽂기 X (제사 의미)
  • 음식 남기는 게 미덕 X (한국은 다 먹는 게 좋음)
  • 술 따를 때 한 손 X (두 손 권장)

결제·tip

  • 한국은 tip 문화 없음 (계산서 100% 결제)
  • 매장 한 명이 결제하는 게 일반 (각자 X)
  • 카드 + 현금 다수 OK·시장은 현금 권장
