＃韓国ハンジョンシクの予約、ドレスコード、マナーの流れ — 新羅嶺、1～2週間前の予約から6ステップコースまで

> 字幕: 外国人観光客のための 5 ステップのワークフロー + キャッチテーブルの予約、ドレスコード、ロイヤル マナー、支払いのヒント

問題 03 · #838 · 2026-06-09

🎯 韓国料理を選ぶ理由 韓国料理ワークフローガイド

[#831 ハンジョンシク6ステップマトリックス](#831)を知っていても、予約、マナー、支払いプロセスは別です。韓国の伝統料理は、 (a) 予約制 (1～2週間前までにキャッチテーブル、ネイバー、電話) (b) ドレスコード (ホテル=スマートカジュアル / 仁寺洞=無料) (c) 6段階コースの提供順序とマナー (お粥→ジョン→メインディッシュ→スープ→ライス→デザート) (d) 副菜おかわり自由 (e) サービス料10%+付加価値税10% （ホテル）。外国人の場合: (1) 予約システムは韓国語のみです。 (2) ドレスコードが不明。 (3) コースの順序がわかりにくい。 (4) 支払い時に驚くべきサービス料。このガイドは 5 ステップ + マナー マトリックス + 英語の話し方 + 本格的なホテルのヒントです。

★ 5 ステップのワークフローの概要

ステップ アクション 時間 外国人向けのポイント
1️⃣ 店舗選択 + 予約 キャッチテーブル・ネイバー・フォン・ホテルコンシェルジュ 1～2 週間前 新羅レヨン・三清閣 = 1～2週間前までに必要
2️⃣ ドレスコード + 到着 ホテル = スマートカジュアル / 仁寺洞 = フリーダム 変動 5分前に到着/予約名を確認
3️⃣ 席とメニューの情報 韓国料理コース選択・オプション 5～10分 英語メニュー・コース料金を確認する
4️⃣ 6 コース料理 お粥 → ジョン → メインディッシュ → スープ → ご飯 → デザート 1.5~3時間 おかずおかわり自由
5️⃣ お支払い カード + 10% サービス料 + 10% VAT (ホテル) 1~3分 一般 = カード OK / チップ X

> 合計所要時間: 仁寺洞/全州の韓国料理 = 1.5~2時間 / ホテルの伝統料理 = 2~3時間

🍽6ステップのコースマナー

1️⃣ ジュークのマナー

  • 注文: 最初に提供します (食欲をそそります)
  • マナー: 小鉢 = 一口ずつ食べる / 胡椒は足したり引いたりできます。

2️⃣ チョンのマナー

  • シーケンス: 2 番目 (前菜と副菜から始まります)
  • マナー: 指

3️⃣ 十頼 (主菜) のマナー

  • オーダー：ミドル・メイン（1～3品）
  • マナー: カルビチム・プルコギ = 箸 + ナイフ/フォークの一部 / クジョルパン = 9 スペース盛り合わせ

4️⃣ 唐のマナー

  • 注文: メインディッシュの後またはご飯と一緒に
  • マナー: 辛仙路(王家鍋) = 従業員が料理を茹でます → 一人ずつ食べます。

5️⃣ バップマナー

  • 注文: もうすぐ終わり（食事の終わり）
  • マナー: 12種類以上のおかず = 均等に提供 / キムチと大根はおかわり自由 (「キムチをもっとください」)

6️⃣ デザート（フーシク）のマナー

  • 注文: 最後
  • マナー: ヤクァ、スジョングァ、シッケ、ティーペアリング

🙏 韓国料理の 7 つの重要なエチケット

韓国の食事マナー（伝統）

1. 大人が最初に開始します: 大人が最初にスプーンを上げることから始めます。

2. スプーンの使用: 箸 + スプーン (韓国式)

3. 丼を持ち上げないでください: 丼 = テーブルに置いたまま食べます (韓国の古典)

4. **サウンド

5. ご飯・スープ = スプーン: ご飯・スープ = スプーンを使用してください

6. バンチャン、チョン、焼き物 = 箸: サイド = 箸

7. 乾杯時のグラス＝大人より低い：お酒のマナー（#829）

外国人による英語スピーチのサンプル

  • 「(名前) を予約しています」 = 「(名前) を予約しています」
  • "限定コース1" = "One hanjeongsik course, please"
  • "おかずもう少しください" = "More side dishes, please"
  • "これは辛いですか？" = "Is this spicy?"
  • "カードですか？" = "Card accepted?"
  • "包装可能ですか？" = "Can I take leftover home?"

💰決済ワークフロー

ホテル限定式

1. カード決済（ルームチャージOR個別）

2. サービス料10% + 税10% 自動追加

3. 総価格=メニュー+ 20%

4. チップX（韓国=チップ文化なし）

一般限定式 (仁寺洞・全州・老舗)

1. カード決済 OR一部の現金

2. サービス料X(一般店舗)

3. 付加税 = メニュー付き (別途X)

4. チップX

お支払いの分離

  • ホテル：一人支払い→ルームチャージOR送金
  • 一般: 一人決済 → カカオペー・トス送金

＃＃⚠外国人の頻繁なミス7つ

1. "予約 X = OK": 新羅ラヨン・サムチョンガク = 1～2週間前必須予約。

2. "ドレスコードX": ホテル= smart casual (ジーンズ・ノースリーブ・ショーツX)。

3. 「ステップ6 =一緒に出る」：ステップ6 = 順番にサービング（1.5〜3h）。

4. "サービス料=チップ": 韓国=チップX. ホテルサービス料10% =自動請求。

5. "おかず= 1回": 無料無制限リフィル ("もっとお願いします"要求)。

6. 「ボウル持ち上げ」: 韓国正統＝ボウル＝食卓に置いてスプーン・箸使用。

7. "包装 = X": 一部の店舗 = 包装可能 ("包装です")。ホテル=一般的にX。

⚙ よくある質問8件

1. 初回限定式=どこ: 仁寺洞・全州限定式(コソンビ入門)→ホテルラヨン(ラグジュアリー)。

2. インスタ・vlog：新羅ラヨン（ミシュラン3スター）・三清閣・仁寺洞韓屋限定式。

3. デート・記念日: 新羅ラヨン・ロッテホテル・三清閣。

4. 予約方法：キャッチテーブル（韓国#1アプリ）>ネイバー予約>ホテルコンシェルジュ>電話。

5. ドレスコード: ホテル = smart casual / 仁寺洞 = 自由。

6. アレルギー・妊娠: [#831 disclaimer](#831)参照。シーフード・ナッツ・蜂蜜の事前告知。

7. ベジタリアン・ハラール・コーシャ: [#800査察食品](#800) 限定式 OR ベジタリアン限定食 事前要請。

8. VATの払い戻し: 飲食の一般的な払い戻しX /ホテル=サービス料10% +税10%。

⚠医療・安全・食事ダイエット

限定式＝6段階コース食事（1.5～3h）。妊婦・免疫低下＝煮込んだメニュー推奨（回・刺身コース回避）。アレルギー（シーフード・牛・豚・卵・ナッツ・蜂蜜）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗情報免責：ホテル韓食堂・仁寺洞限定食運営・価格・メニュー変動 - 訪問前NAVER/Kakao mapまたは公式サイト確認。

食事制限 fallback:

  • ハラール・コーシャー：一般限定式＝ビハラル。 →査察食品限定式[#800]。
  • ベジタリアン・ビーガン: 査察料理 OR ベジタリアン限定食 事前リクエスト(雑菜・前・チゲベジタリアンオプション)。
  • グルテンフリー: 限定食味付け（醤油・コチュジャン）多。事前店舗確認。
