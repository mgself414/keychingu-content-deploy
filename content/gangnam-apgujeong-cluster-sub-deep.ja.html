狎鴎亭・蚕院 半日ガイド — 狎鴎亭ロデオ通り (アックジョン ロデオトリ / 압구정 로데오거리)・現代百貨店 狎鴎亭本店 (ヒョンデペクファジョム アックジョンボンジョム / 현대백화점 압구정본점)・ギャラリア名品館 (ギャルロリア ミョンプムグァン / 갤러리아 명품관)・蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원) の4か所(2026年10月確認)

サブタイトル: 現代百貨店 狎鴎亭本店 (ヒョンデペクファジョム アックジョンボンジョム / 현대백화점 압구정본점) は狎鴎亭駅 (アックジョンヨク / 압구정역) 6番出口とそのままつながり、3階でその場で免税の払い戻しをしてくれる(現代百貨店公式) · ギャラリア名品館 (ギャルロリア ミョンプムグァン / 갤러리아 명품관) はWEST・EASTの2館で、月~木10:30~20:00・金~日10:30~20:30(ギャラリア公式) · 蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원) は狎鴎亭駅6番出口から歩いて約15~20分(漢江公園公式) · 蚕院プール (チャモン スヨンジャン / 잠원 수영장) は改装工事で閉鎖中で、2028年に再オープンの予定(漢江公園公式) — 2026-10-22時点

ISSUE 03 · #713 · 2026-06-02

🎯 このガイドの使い方

狎鴎亭駅 (アックジョンヨク / 압구정역) 6番出口を出るとすぐデパートの正面玄関で、そのまま北へ15分ちょっと歩くと、漢南大橋 (ハンナムテギョ / 한남대교) の下から川風が吹いてくる。このガイドが扱うのは狎鴎亭洞 (アックジョンドン / 압구정동) のひとつの街だけだ。昼はロデオ通り (ロデオトリ / 로데오거리) と2つのデパートを回り、日が傾くころ蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원) へ下りていく、半日の動線である。江南 (カンナム / 강남) に初めて来て狎鴎亭がどんな街かつかみたい人、名品館を見ながら免税の払い戻しまで一度に済ませたい人が読めばよい。

江南駅・COEX (コエックス / 코엑스)(#301)、清潭 (チョンダム / 청담) の名品通り・ギャラリー(#296)、盤浦 (パンポ / 반포) 漢江公園・セビッソム (セビッソム / 세빛섬)(#712)は、下の🔗関連コンテンツの各編で扱う。時間・住所・料金はすべて公式ページで直接開いて確認した値で、開けなかった値はそのとおり記した。

🛍 狎鴎亭ロデオ通り (アックジョン ロデオトリ / 압구정 로데오거리) — 歩く街

  • 狎鴎亭ロデオ通り (アックジョン ロデオトリ / 압구정 로데오거리) — ソウル江南区 (カンナムグ / 강남구) 狎鴎亭洞 (アックジョンドン / 압구정동) 一帯。常時開放、年中無休、ベビーカーのレンタルはない(VisitKorea)。VisitKoreaは、この通りが90年代初めにファッションの中心街として定着し、今はショッピングだけでなくグルメや見どころも多い場所だと紹介している
  • K-Star Road(カンナムドル / 강남돌) — 狎鴎亭ロデオ駅 (アックジョンロデオヨク / 압구정로데오역) 2番出口から清潭交差点 (チョンダムサゴリ / 청담사거리) まで約1kmの道に、K-popグループのイメージをまとったクマのぬいぐるみ型オブジェ「カンナムドル (カンナムドル / 강남돌)」が並んでいる。ギャラリアデパート (ギャルロリアペクファジョム / 갤러리아백화점) の前には高さ3mのサイのカンナムドルがあり、そのほかにさらに17体ある(VisitSeoul、2024年6月修正の記事)。今も全部そのままあるかどうかは確認できなかった
  • ロデオ通り (ロデオトリ / 로데오거리) の個々の店の営業時間は店ごとに異なるため、このガイドには載せなかった。清潭 (チョンダム / 청담) 側の名品フラッグシップ通りは清潭洞を歩く — ルイ・ヴィトンメゾンとハウスオブディオールの建築、ソンウン・エスパスルイ・ヴィトン・アトリエエルメスのギャラリー、トサン公園、新沙 (シンサ / 신사) のカロスキル (カロスキル / 가로수길) は#295

🏬 現代百貨店 狎鴎亭本店 (ヒョンデペクファジョム アックジョンボンジョム / 현대백화점 압구정본점) — 駅とつながるデパート

  • 住所: ソウル江南区 (カンナムグ / 강남구) 狎鴎亭路 (アックジョンロ / 압구정로) 165。代表電話1588-3650(現代百貨店公式)
  • 営業時間: 月~木10:30~20:00、金~日10:30~20:30、レストラン街11:00~22:00(現代百貨店公式 店舗ページ)。休館日は毎月、店舗ページのカレンダーに載る。VisitKoreaの入店テナント情報には「名節、月1回」休みと書かれている
  • 行き方: 地下鉄3号線 狎鴎亭駅 (アックジョンヨク / 압구정역) 6番出口の内側の通路がデパート地下2階の入口につながっていて、6番出口の外に出るとデパートの正面玄関だ。空港バス6006番が狎鴎亭駅のバス停に停まる(現代百貨店公式)
  • 外国人サービス(現代百貨店公式 サービス施設ページ)
  • Tax Refund(免税払い戻し) — 3階、02-3449-5207。外国人のお客様が買った商品の免税額を、デパートでその場で払い戻してくれる
  • 手荷物預かり所 — 地下1階、02-3449-5550

💎 ギャラリア名品館 (ギャルロリア ミョンプムグァン / 갤러리아 명품관) — 道の両側の2館

  • 住所: WEST ソウル江南区 (カンナムグ / 강남구) 狎鴎亭路 (アックジョンロ / 압구정로) 343、EAST ソウル江南区 (カンナムグ / 강남구) 狎鴎亭路 (アックジョンロ / 압구정로) 407。代表電話1544-6600(ギャラリア公式)
  • 営業時間: 月~木10:30~20:00、金~日10:30~20:30。食品館のグルメ494 (グルメ494 / 고메이494) も同じ時間で、ラストオーダーは閉店30分前だ。2026年10月の営業情報では「休館日なし」と出ている。翌月の情報は毎月最終週に変わる(ギャラリア公式)。VisitKoreaには「月1回休館」と書かれている
  • 建物: 道路をはさんでWEST館とEAST館に分かれる。WEST館の魚のうろこ模様の外観は、夜になると色が変わる(VisitKorea)
  • 外国人サービス(ギャラリア公式 お客様向け便利施設ページ)
  • 外国人サービスセンター — WEST 5階、02-3449-4151 / 02-3449-4411
  • コンシェルジュデスク — WEST 1階、02-3449-4020
  • 払い戻し方法: WEST館は即時払い戻し・事後払い戻しのどちらも可能(VisitKorea観光情報)
  • 2つのデパートのブランド構成と江南の名品ショッピング全体は#771、ソウルのデパート比較は#449

🌊 蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원) — 狎鴎亭から歩いて下りる漢江

  • 基本情報: ソウル瑞草区 (ソチョグ / 서초구) 蚕院路 (チャモンロ / 잠원로) 221-124。永東大橋 (ヨンドンデギョ / 영동대교) 南端から潜水橋 (チャムスギョ / 잠수교、盤浦大橋) 上流までの長さ5.4km、面積474,213㎡。案内センター02-3780-0531~3、行政業務は09:00~18:00(漢江公園公式)。公園は常時開放・年中無休(VisitKorea)
  • 行き方(漢江公園公式「お越しの方法」)
  • 3号線 狎鴎亭駅 (アックジョンヨク / 압구정역) 6番出口 → 現代高校 (ヒョンデコギョ / 현대고등학교) 方面へ徒歩約15~20分(狎鴎亭ナドゥルモク (アックジョンナドゥルモク / 압구정나들목))
  • 3号線 新沙駅 (シンサヨク / 신사역) 5番出口 → 新沙中学校 (シンサチュンハッキョ / 신사중학교) 方面へ徒歩約15~20分(新沙ナドゥルモク (シンサナドゥルモク / 신사나들목))
  • 3号線 蚕院駅 (チャモンヨク / 잠원역) 4番出口 → 蚕院ハンシンアパート (チャモンハンシンアパトゥ / 잠원한신아파트) 方面へ徒歩約15分(蚕院ナドゥルモク (チャモンナドゥルモク / 잠원나들목))
  • 漢江バス (ハンガンボス / 한강버스) を狎鴎亭船着き場 (アックジョンソンチャクチャン / 압구정 선착장) で降りると、公園につながる
  • 見どころ・やること: 川沿いの自転車道5.4km。自転車レンタル店は漢南大橋 (ハンナムテギョ / 한남대교) 南端の上流、蚕院第2号売店 (チャモンチェイホメジョム / 잠원제2호매점) の前にある。公式ページが挙げる名所は、蚕院グラス庭園 (チャモングラスジョンウォン / 잠원 그라스정원) のピンクミューリー、蚕院ミツバチの森 (チャモンクルボルスプ / 잠원 꿀벌숲)、蚕の体験学習場 (ヌエチェホムハクスプチャン / 누에체험학습장) だ。水上スキーやウェイクボードのようなウォーターレジャーと、船上カフェ・レストランの施設もある(漢江公園公式)
  • 漢江循環観覧車(ヘチカー / 해치카): 銅雀駅 (トンジャクヨク / 동작역) 2番出口 → 盤浦漢江公園 (パンポハンガンコンウォン / 반포한강공원、セビッソム / 세빛섬) → 蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원、ソウルウェーブ / 서울웨이브) を回る無料の循環車。2026年の運行期間は4月4日~11月30日で、20分間隔。月~金14:00~20:00、週末・祝日11:00~20:00で、16:00~17:00は運行しない(漢江公園公式)。盤浦 (パンポ / 반포) 側の動線は#712
  • プール: 蚕院漢江公園プール (チャモンハンガンコンウォン スヨンジャン / 잠원 한강공원 수영장) は改装工事で閉鎖中で、2028年に再オープンの予定だ。ソウル市は、纛島 (トゥクソム / 뚝섬)・汝矣島 (ヨイド / 여의도) の漢江公園のプールを代わりに使うよう案内している。漢江公園のプールは2026年の運営をすべて終え、2027年の日程はまだ告知されていない(漢江公園公式)
  • そり場: 2025~2026シーズンは蚕院プールの敷地で、2025年12月31日~2026年2月18日に運営し、入場料は年齢に関係なく6,000ウォンだった(漢江公園公式)。プールが工事中のため、2026~2027年の冬に蚕院 (チャモン / 잠원) で再びそり場を開くかどうかは、まだ告知されていない
  • 便利施設: コンビニ3か所、トイレ9か所。駐車場6か所722台分、06:00~24:00(漢江公園公式)
  • ソウルの漢江公園全体の比較は#706

🧰 狎鴎亭の実用情報 — ひとり、予約、決済、払い戻し、移動

  • ひとり: 4か所とも予約なしでひとりで入れる。デパートのレストラン街でひとりで食べやすい店は#348 Seoul Solo Diner Map
  • 決済・払い戻し: パスポートを持っていく。現代百貨店 (ヒョンデペクファジョム / 현대백화점) は3階のTax Refundカウンターでその場で払い戻し(現代百貨店公式)、ギャラリアWEST館 (ギャルロリアウェストグァン / 갤러리아 WEST관) は即時払い戻し・事後払い戻しの両方ができる(VisitKorea)。条件と空港での手順は#1231 免税払い戻しガイドと#1304 空港キオスク手順版。カードとスマホ決済は#527
  • 移動: 3号線 狎鴎亭駅 (アックジョンヨク / 압구정역) ひとつで、現代百貨店 (ヒョンデペクファジョム / 현대백화점) と蚕院漢江公園 (チャモンハンガンコンウォン / 잠원한강공원) のどちらにも行ける。交通カードは#1298。週末・祝日は漢江公園の周辺が渋滞するので公共交通を使うようにと、公式ページが案内している
  • 漢江のマナー: ゴミは持ち帰らなければならず、違反すると過料100,000ウォン、指定場所以外に駐車すると過料50,000ウォンだ。公園内は禁煙で、炊事もできない(漢江公園公式)

⚠ よくある間違い4つ

1. 「夏は蚕院のプール」 — 改装で閉鎖中で、2028年再オープンの予定だ。夏に泳ぐなら、纛島 (トゥクソム / 뚝섬)・汝矣島 (ヨイド / 여의도) の漢江公園のプールへ行く(漢江公園公式)

2. 「デパートは毎日同じ時間に閉まる」 — 2つのデパートとも、金~日は20:30、月~木は20:00に閉まる(それぞれの公式ページ)

3. 「免税の払い戻しは空港でしかできない」 — 現代百貨店 狎鴎亭本店 (ヒョンデペクファジョム アックジョンボンジョム / 현대백화점 압구정본점) の3階では即時払い戻しをしている(現代百貨店公式)

4. 「狎鴎亭駅から漢江はすぐ目の前」 — 6番出口から歩いて約15~20分かかり、狎鴎亭ナドゥルモク(압구정나들목)を通って漢江公園に入る(漢江公園公式)
