📍 扇子·出版 — 全州扇子文化馆·完板本文化馆·全州木版书画体验馆

全州扇子文化馆 (Jeonju Buchae Munhwagwan / 전주부채문화관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Gyeonggijeon-gil 93，丰南洞3街 (Pungnam-dong 3-ga / 풍남동3가)，☎ 063-231-1774）2011年开馆。据韩国观光公社介绍，设有全罗监营 (Jeolla Gamyeong / 전라감영) 的全州曾有制作和管理扇子的扇子厅 (Seonjacheong / 선자청)，文化馆由策划展厅 (Jiseonsil / 지선실)、常设展出60余件扇子文物的Cheongpung室 (Cheongpungsil / 청풍실) 以及体验室组成。可以体验绘制团扇 (Danseon / 단선)·折扇 (Jeopseon / 접선)，在Baram商店 (Baram Gage / 바람가게) 出售全州扇子匠人的扇子和纪念品。

  • 开放时间：10:00~20:00。
  • 休息日：每周一、1月1日、春节·中秋节当天。

完板本文化馆 (Wanpanbon Munhwagwan / 완판본문화관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Jeonjucheondong-ro 24，校洞 (Gyo-dong / 교동)，☎ 063-231-2212）2011年10月18日开馆。据韩国观光公社介绍，"完板本"指在全州旧称完山 (Wansan / 완산) 刊印的古书及其版本，展厅可以看到韩国古典小说书册、完板本制作过程和复刻的书版。设有木版印刷体验、韩纸明信片体验、制作古书等体验项目。

  • 开放时间：冬季（12~2月）10:00~17:00，3~5月·11月 10:00~18:00，夏季（6~10月）10:00~20:00。
  • 休息日：每周一。
  • 门票：免费。体验项目按项目收费。

全州木版书画体验馆 (Jeonju Mokpan Seohwa Cheheomgwan / 전주목판서화체험관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Jeonjucheondong-ro 46，校洞 (Gyo-dong / 교동)，☎ 063-231-5694）据韩国观光公社介绍，是用木版复原龙飞御天歌 (Yongbieocheonga / 용비어천가) 木版和刊行本、完板本古典小说的地方。设有木版画韩纸挂饰上色、木版画明信片信封、制作古书等体验。

  • 开放时间：冬季 10:00~17:00，夏季 10:00~18:00（观光公社登记信息中写明时间可能有变动）。
  • 休息日：每周一、春节·中秋节。
  • 停车：可以。

📍 酒·工艺 — 全州传统酒博物馆·全州工艺品展览馆

全州传统酒博物馆 (Jeonju Jeontongsul Bangmulgwan / 전주 전통술박물관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Hanji-gil 74，☎ 063-287-6305）是展示韩国传统酒的公立博物馆。据韩国观光公社介绍，馆内委托销售当地传统酒，并开设传统酒教育项目。

  • 开放时间：周二~周日 10:00~18:00，6~10月开放到20:00。Sueul画廊 (Sueul Gallery / 수을갤러리) 运营时间为周二~周五 14:00~17:00，周六·周日 10:00~18:00，午休 12:00~13:00。
  • 休息日：每周一、1月1日、春节·中秋节当天。
  • 门票：免费。

全州工艺品展览馆 (Jeonju Gongyepum Jeonsigwan / 전주공예품전시관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Taejo-ro 15，☎ 063-281-1610）据韩国观光公社介绍，由展览馆·体验馆·销售馆组成，从全北特别自治道 (Jeonbuk Special Self-Governing Province / 전북특별자치도) 有形文化遗产的传统作品到新锐作家的工艺品都可以欣赏。设有制作工艺品的体验项目。

  • 开放时间：10:00~18:00。
  • 休息日：每周一、1月1日、春节·中秋节当天。
  • 门票：免费（体验另收费）。

📍 历史 — 全州韩屋村历史馆·全州乡校

全州韩屋村历史馆 (Jeonju Hanok Maeul Yeoksagwan / 전주한옥마을역사관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Choemyeonghui-gil 17-10，丰南洞3街 (Pungnam-dong 3-ga / 풍남동3가)，☎ 063-286-5125）修缮2栋韩屋，于2018年开馆。据韩国观光公社介绍，在常设展厅可以通过年表了解韩屋村的变迁史，还能观看居民采访影像和体验虚拟现实。周末有带领参观各展厅的定期讲解。

  • 开放时间：10:00~18:00（截止入场 17:45）。
  • 休息日：每周一。
  • 门票：免费。

全州乡校 (Jeonju Hyanggyo / 전주향교)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Hyanggyo-gil 139，校洞 (Gyo-dong / 교동)，☎ 063-288-4548）是高丽·朝鲜时代的国立教育机构乡校，设有大成殿 (Daeseongjeon / 대성전)、明伦堂 (Myeongnyundang / 명륜당) 等。据韩国观光公社介绍，大成殿于孝宗 (Hyojong / 효종) 4年（1653）重建，大成殿前院有400多年的银杏树，并作为《云画的月光》(Gureumi Geurin Dalbit / 구르미 그린 달빛)、《成均馆绯闻》(Seonggyungwan Seukaendeul / 성균관 스캔들) 等电视剧的取景地而闻名。

  • 开放时间：冬季（11~2月）10:00~17:00，夏季（3~10月）09:00~18:00。
  • 休息日：每周一（周一为公共假日则顺延至次日）。
  • 停车：可以。

📍 街头演出 — 全州韩屋村传统演艺游行《Nosang Noriya》

传统演艺游行《Nosang Noriya》(Nosang Noriya / 노상놀이야) 于2026年4月18日~10月31日每周六 15:00~16:00在全州韩屋村太祖路 (Taejo-ro) （南川桥 (Namcheongyo / 남천교)~庆基殿 (Gyeonggijeon / 경기전)）已举办（已结束）（☎ 063-236-1577）。据观光公社登记信息，游行从南川桥出发，龙旗在前，农乐 (Pungmul / 풍물) 队伍行进，展开庭院戏 (Madangnori / 마당놀이) 和传统演艺，在庆基殿前以全州旗接游戏 (Jeonju Gijeopnori / 전주기접놀이) 龙旗表演收尾。免费，任何人都可以加入队伍。

⚠ 提前要知道的3点

  1. 7处全部周一休息 — 参观时请避开周一（全州乡校在周一为公共假日时顺延至次日休息）。
  2. 闭馆时间随季节而异 — 完板本文化馆6~10月到20:00，12~2月到17:00闭馆。传统酒博物馆6~10月开放到20:00。全州乡校（11~2月）和木版书画体验馆（冬季）17:00闭馆。
  3. 完板本文化馆·工艺品展览馆的体验另收费 — 完板本文化馆登记为按项目收费，工艺品展览馆登记为体验另收费。

⚙ FAQ 2

Q. 可以亲手制作的体验有哪些？

A. 据观光公社登记信息，可以在全州扇子文化馆（绘制扇子）、完板本文化馆（木版印刷·韩纸明信片·制作古书）、全州木版书画体验馆（木版画上色·制作古书）、全州工艺品展览馆（制作工艺品）体验。

Q. 哪些地方免费？

A. 完板本文化馆、全州传统酒博物馆、全州工艺品展览馆、全州韩屋村历史馆登记为免费。体验费用仅登记了完板本文化馆（按项目）和全州工艺品展览馆（体验另收费）。
