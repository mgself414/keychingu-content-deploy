🎯 このガイドの使い方

小さな器が一つずつ膳に置かれ、気がつけば膳の端まで埋まっている — 全州では一つの膳におかずが30品ほど並びます(VisitKorea)。このガイドでは韓定食(hanjeongsik / 한정식)を四つに分けます。ソウルのミシュラン韓食コース3軒(ミングルス・羅宴・温知音)、全州の韓定食、安東のホッチェサッパプ、寺刹料理です。等級・住所・時間は、ミシュランガイド ソウル&釜山2026とVisitKorea・全州市・国家遺産庁の公式ページで読み取った値だけを載せ、価格や時間が掲載されていない店はその旨を書きます。韓国のコース料理を一度はきちんと味わいたい人、ソウルを離れて全州・安東まで一日かける人のための版です。

以前のガイドにあった「韓国No.1」・価格帯(羅宴は1人30~50万ウォンなど)・「一か月」には出典がありませんでした。「仙才僧(Seonjae / 선재) = Chef's Table」は誤りで(出演者は白羊寺の浄観僧、VisitKorea)、国家無形遺産に指定されたのは眞寛寺の寺刹料理ではなく、眞寛寺の水陸斎(仏教儀礼、2013年指定、国家遺産庁)です。

🍽 ソウル — ミシュラン2026 韓食コース3軒

ミシュランガイド ソウル&釜山2026の公式ページの値(2026-10-07閲覧)。全16軒は#1109 Seoul Michelin Guide 2026。

  • ミングルス (Mingles / 밍글스) — 3つ星(2年連続、ソウルで唯一)。住所は Gangnam-gu, Dosan-daero 67-gil 19, 2F(ソウル江南区)。シェフはカン・ミング(Kang Min-gu / 강민구)。ランチは火~土 12:00~15:00、月・日休み(ミシュランのページ、ディナーは公式サイトで確認)。予約は公式サイト restaurant-mingles.com・電話 +82-2-515-7306。カード払い可
  • 羅宴 (La Yeon / 라연) — 2つ星。住所は Jung-gu, Dongho-ro 249, 新羅ホテル23階(ソウル中区)。ランチは毎日 12:00~14:30(ミシュランのページ)。予約は新羅ホテル公式サイト・NAVER予約・電話 +82-2-2230-3367。車いすで入れる
  • 温知音 (Onjium / 온지음) — 1つ星。住所は Jongno-gu, Hyoja-ro 49, 4F(ソウル鍾路区)。朝鮮の宮廷料理を伝統技法と現代技法で再解釈。ランチは火~金 12:00~15:00(ミシュランのページ)。予約は電話 +82-2-6952-0024。ミシュランのページに「現金のみ」と表記
  • 3軒とも価格はミシュランの記号₩₩₩₩だけです — ウォンの金額は予約時に確認します

🍚 全州の韓定食

  • 特徴: 一つの膳におかずが30品ほど並び、全州の郷吏(地方役人)が楽しんだ「白飯の大膳」が商業化して定着しました(VisitKorea)
  • ユネスコ: 全州は2012年にユネスコ創造都市ネットワークの食分野の加盟都市になりました(unesco.org)
  • 韓定食店3軒(VisitKoreaの記事に掲載): 韓碧楼 (Hanbyeokru / 한벽루) 063-280-7003(完山区 Jeonjucheon-dong-ro) · 宮 (Gung / 궁) 063-227-0844(完山区 Eunhaeng-ro) · 全羅会館 (Jeolla Hoegwan / 전라회관) 063-228-3033(完山区 Anhaeng 4-gil)。記事に詳しい住所・営業時間・価格はありません — 電話で確認します
  • ビビンバ(全州市公式観光サイトに掲載): 校洞石カルビ (Gyodong Seokgalbi / 교동석갈비)(Taejo-ro 26) · 満月 (Manwol / 만월)(Choe Myeong-hui-gil 3、ユッケビビンバ) · 豊南門ビビンバ (Pungnammun Bibimbap / 풍남문비빔밥)(Pungnammun 2-gil 53) · 大釜 (Keun Gama / 큰가마)(Nosong-gwangjang-ro 46)。営業時間・価格は未掲載
  • 行き方: ソウル→全州のKTXの所要時間は公式値を開けませんでした — KORAILアプリで調べます。全州の一日ルートは#384 Jeonju Travel Map

🐟 安東のホッチェサッパプ

  • 特徴: 先祖の祭祀料理から着想を得た安東の郷土料理(heotjesabap / 헛제삿밥)。安東の人が「おいしいものを食べたい口実」として「にせの祭祀料理」と名づけました。ごはんに大根・豆腐・肉のスープ、焼きサバなどが付きます(VisitKorea)
  • カチグモンチプ (Kkachigumeong-jip / 까치구멍집): Andong-si, Seokju-ro 203(慶尚北道安東市)、11:00~20:00、旧正月・秋夕の当日休み(VisitKorea)。価格は未掲載
  • 味50年 (Mat 50 Nyeon / 맛50년): Andong-si, Seokju-ro 201(慶尚北道安東市)、11:00~20:00、旧正月・秋夕の当日休み(VisitKorea)。価格は未掲載
  • 合わせて訪ねる所: 河回・良洞の歴史村は2010年にユネスコ世界遺産に登録されました(国家遺産庁の英語ページ)

🪷 寺刹料理

  • 特徴: 仏教寺院から伝わった料理の伝統(VisitKorea)。白羊寺 (Baekyangsa / 백양사) の浄観僧 (Jeonggwan / 정관) はジェームズ・ビアード賞を受けた寺刹料理の名匠で、Netflixの「Chef's Table」(2017)に出演しました(VisitKorea)
  • 韓国寺刹料理センター (Korea Temple Food Center / 한국사찰음식센터): VisitKoreaは Jongno-gu, Yulgok-ro 39 安国ビル2階、センター公式サイト(koreatemplefood.com)は Jongno-gu, Ujeongguk-ro 56 と書いていて住所が異なります — 行く前に電話 02-733-4650 で確認します。通常の営業時間は掲載されておらず、プログラムは回ごとの予約制です
  • 眞寛寺 (Jingwansa / 진관사): Eunpyeong-gu, Jinwan-gil 73(ソウル恩平区)、09:00~18:00、年中無休(VisitKorea)。国家無形遺産に指定されたのは「眞寛寺の水陸斎」(仏教儀礼、2013-12-31指定、国家遺産庁)です

🥗 食事制限

  • 価格帯: このガイドで公式に掲載されているウォン価格はありません。ミシュラン3軒は₩₩₩₩の記号、全州・安東の掲載ページには価格欄がありません
  • ベジタリアン: 白菜キムチの薬味にはたいてい塩辛・魚醤が入ります(VisitKorea) — 韓定食の膳のキムチやナムルも注文前に尋ねます。寺刹料理の食材は予約時に確認します
  • ハラル: ソウルのKMF認証の韓食店は1軒(Eid / 이드、VisitSeoul)です。このガイドの韓定食店にハラル表記はありません
  • 見せるカードは#1300 食事リクエスト・マニュアル

🧰 韓定食の実用情報 — 一人、予約、支払い、注文、移動

  • 一人: 韓定食の膳は2人以上から受ける店があるかもしれません — まず電話で尋ねます。一人でも座りやすい食堂の地図は#348 Seoul Solo Diner Map
  • 予約: 海外からは電話やホテルのコンシェルジュが確実です。キャッチテーブルは韓国のアプリで、海外の番号で登録できるかは確認できませんでした(#1109)
  • 支払い: 温知音はミシュランのページに「現金のみ」、ミングルスはカード可 — カード・スマホ決済は#527 韓国の決済システム・#431 決済・SIMマップ
  • 注文: おかずと水のおかわりは無料、チップは不要です(VisitKorea) — 言葉が通じないときは#1339 注文エチケット
  • 移動: 全州・安東は#1297 高速・市外バス・マニュアルも合わせて見ます。交通カードは#1298 交通カード3種の選び方

⚠ よくある間違い4つ

1. 「仙才僧(Seonjae / 선재)がChef's Tableに出た」 — 出演者は白羊寺の浄観僧です(VisitKorea)。仙才僧は別の方です

2. 「眞寛寺の寺刹料理は国家無形文化財」 — 指定されたのは眞寛寺の水陸斎という仏教儀礼です(国家遺産庁)

3. 「月曜のランチでミシュラン韓食」 — ミングルスは月・日休み、温知音のランチは火~金です。月曜は毎日ランチを出す羅宴を見ます

4. 「ミシュランの韓食店は価格が公開されている」 — ミシュランのページには₩₩₩₩の記号しかありません。金額は予約時に尋ねます
