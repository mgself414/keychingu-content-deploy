外国游客常犯的5个错误

1. 到得太早

灯光节在日落后才亮灯 (17:30~18:00)。16:00到达的话，亮灯前一片昏暗。17:00~18:00到达 + 亮灯后黄金1小时是最佳选择。

2. 小看寒冷

首尔冬季 = -5~5°C，风力强劲。厚羽绒服 + 手套 + 帽子 + 暖宝宝缺一不可。暖宝宝可在便利店或大创 (Daiso / 다이소) 购买，₩1,000~2,000。

3. 只去跨年倒计时

只知道12月31日普信阁 (Bosingak / 보신각) 跨年倒计时，到了现场会被人潮困住 (50万人+)。DDP·清溪川·新村·乐天塔的灯光点亮季节可持续1~2个月，可以更从容地游览。

4. 误以为所有景点都免费

乐天塔 (Lotte Tower / 롯데타워) 观景台 ₩31,000 / N首尔塔 (N Seoul Tower / N서울타워) ₩21,000 = 收费。光化门 (Gwanghwamun / 광화문)·清溪川 (Cheonggyecheon / 청계천)·DDP 室外区域均为免费。

5. 将韩国圣诞节与日本·西方混为一谈

韩国圣诞节 = 12/24·25为公共假日，以情侣·朋友约会氛围为主。家庭传统节日是春节 (正月, 2月)。外国游客须注意年末年初酒店·餐厅预订爆满。

FAQ

Q1. 能用英语沟通吗？

DDP·乐天塔·N首尔塔·明洞大圣堂 = 提供英文指引。清溪川·光化门提供英文标识·二维码。

Q2. 跨年倒计时推荐哪里？

普信阁撞钟 (市厅·钟阁 / Sijeong·Jonggak / 시청·종각) = 韩国正宗体验，但人潮达50万+。外国游客建议选择乐天塔观景台或酒店天台酒吧，更为安全。

Q3. 适合家庭出行吗？

DDP·乐天塔·N首尔塔 = 家庭友好。明洞大圣堂 = 携带儿童OK。

Q4. 只有一天时间怎么安排？

DDP (下午) → 清溪川 (傍晚) → 明洞 (夜晚) = 步行 + 地铁一日完整游览。

Q5. 担心花费太高？

6处免费景点 (DDP·清溪川·光化门·新村·弘大·汝矣岛·明洞) — 只需 ₩5,000 一杯热巧克力即可。

Q6. 下雨或下雪怎么办？

乐天塔观景台 (室内) + 明洞大圣堂 (室内) + 咖啡馆夜景 = 雨雪天备选方案。
