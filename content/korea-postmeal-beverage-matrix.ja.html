🎯 なぜ韓国食後の締めドリンク完全ガイドなのか

外国人観光客が韓国の飲み物に対して抱く最大の悩み — 「食事中に飲むドリンクとお酒しか知らなくて、食後に何を飲めばいいのか分からない」。韓国の食後の締めドリンク = 韓定食コースの最後の一杯 + 家庭料理のデザートドリンク + 二日酔い対策の定番。英語ではどれも"Korean traditional beverage"とひとくくりにされがちだが、シッケ (식혜 / Sik-hye、甘い・韓定食の締めNo.1)、シケ (식해 / Sik-hae、魚の発酵・江原道 (강원 / Gangwon-do) の伝統)、スジョングァ (수정과 / Sujeong-gwa、シナモン・生姜・干し柿)、トンドンジュ (동동주 / Dong-dong-ju、食事のお酒でもありドリンクでもある)、メシルチャ (매실차 / Maesil-cha、二日酔い対策・消化促進)、ヘジャンス (해장수 / Haejang-su、豆もやしの二日酔い対策スープ) と、それぞれ役割やファン層が異なる。伝統飲料シリーズ (#840) との違いは = 「食後の締めドリンク」という切り口(韓定食・家庭料理の最後の一杯 + 翌日の二日酔い対策)。多くの外国人観光客は(a)シッケとシケが全く別の飲み物であること、(b)韓定食には決まった締めドリンクがあること、(c)トンドンジュがソフトドリンクのように見えて実はお酒であること、(d)ヘジャンスが二日酔い対策シリーズの一部であること、を知らない。本ガイドでは6種完全ガイド・締めドリンク・二日酔い対策を紹介する。

🍹 6種を徹底解説

🍚 シッケ (식혜 / Sik-hye) — 韓定食締めNo.1

  • 特徴：韓定食コースの締めNo.1・甘い・伝統的
  • 材料：米飯 + 麦芽(엿기름) + 砂糖(米粒が浮いている)
  • 観光客への親しみやすさ：★★★★★(初心者に一番おすすめ、甘くて世界共通で親しみやすい)
  • おすすめの場所：
  • 韓定食レストラン (#837) — 締めNo.1
  • 新羅ホテルのラヨン (라연 / La Yeon)、サムチョンガク (삼청각 / Samcheonggak)、インサドン (인사동 / Insadong) — 伝統的な店
  • スーパー・コンビニ(24時間営業の便利な店) — 缶・ペットボトル
  • 温度：冷たい(氷入り)
  • 価格：韓定食に含まれる / スーパー1缶 = 2,000~5,000ウォン(約220~550円)

🐟 シケ (식해 / Sik-hae) — 江原道の伝統

  • 特徴：江原道 (강원 / Gangwon-do) の伝統・魚の発酵 + 米、ファンの多い一品(名前は似ているがシッケとは別物)
  • 材料：スケトウダラ・ハタハタ・カレイ + 米・唐辛子粉・大根(発酵)
  • 観光客への親しみやすさ：★★★(発酵の風味が強く、発酵好き向け)
  • おすすめの場所：江原道の老舗(노포、ノポ、30年以上続く伝統的な食堂)・市場
  • 季節：通年・江原道の定番
  • 価格：市場 = 10,000~25,000ウォン/パック(約1,100~2,750円)
  • 注意：シッケ = 甘い飲み物(米飯+麦芽) / シケ = 発酵おかず(江原道のファンに人気) — 名前は似ているが全く別の食べ物

🍂 スジョングァ (수정과 / Sujeong-gwa) — 冬の定番

  • 特徴：冬の定番・シナモンと生姜のパンチ + 干し柿・松の実
  • 材料：シナモン・生姜 + 干し柿 + 松の実(飾り)
  • 観光客への親しみやすさ：★★★★(冬の定番、スパイシーで甘い)
  • おすすめの場所：韓定食コース・伝統茶房・MZ世代(MZ、韓国の若いトレンド世代)カフェ・スーパー
  • 温度：冷たい(夏)・温かい(冬)
  • 季節：冬No.1・通年提供
  • 価格：韓定食に含まれる / スーパー1缶 = 3,000~7,000ウォン(約330~770円)

🍶 トンドンジュ (동동주 / Dong-dong-ju) — 伝統酒・食事のお酒

  • 特徴：食事のお酒・伝統的なマッコリ系・濁った発酵酒
  • 材料：米 + 麹(누룩、発酵のもと)、発酵させたもの(米粒が浮いている、「トンドン」は「浮かぶ」の意味)
  • 観光客への親しみやすさ：★★★★(MZ世代のマッコリ (막걸리 / makgeolli、米の醸造酒、6~8度) ブームに乗る・伝統的)
  • おすすめの場所：韓定食レストラン・伝統酒場・MZ世代のマッコリエリア
  • 季節：通年・食事のお酒
  • アルコール度数：6~8%
  • 価格：5,000~15,000ウォン/本(約550~1,650円)

🌿 メシルチャ (매실차 / Maesil-cha) — 二日酔い対策・消化促進

  • 特徴：二日酔い対策・消化促進・韓国の伝統的な薬膳ドリンク
  • 材料：梅シロップ + 水(温かい・冷たい)
  • 観光客への親しみやすさ：★★★★(消化促進・二日酔い対策は世界共通で理解されやすい)
  • おすすめの場所：家庭料理・伝統茶房・スーパー・コンビニ
  • 温度：温かい(消化促進)・冷たい(夏)
  • 季節：通年
  • 価格：家庭料理に含まれる / スーパー = 2,000~5,000ウォン(約220~550円)

🍵 ヘジャンス・豆もやしスープ (해장수 / Haejang-su) — 翌日の二日酔い対策

  • 特徴：二日酔い対策シリーズにまたがる・翌日用・豆もやしスープ
  • 材料：豆もやし + 大根・ねぎ・唐辛子・しょうゆ
  • 観光客への親しみやすさ：★★★(二日酔い対策ファンに人気)
  • おすすめの場所：24時間営業のポンジュク (본죽 / Bonjuk、お粥チェーン店)・クッパ (국밥 / gukbap) の店・二日酔い対策シリーズ
  • 季節：飲酒翌日の早朝・二日酔い対策
  • 価格：家庭料理・クッパの店 = 8,000~15,000ウォン(約880~1,650円)
  • 詳しくは：クッパ (국밥 / gukbap) シリーズ (#807) へ

🍽 韓定食の締め + 家庭料理のデザート + 二日酔い対策の定番

韓定食コースの締め (#837)

  • 6品コースの最後 = シッケ + スジョングァ(デザートの段階)
  • 新羅ホテルのラヨン (라연 / La Yeon)、サムチョンガク (삼청각 / Samcheonggak)、インサドン (인사동 / Insadong) — 伝統的な店
  • 無料で含まれる

家庭料理のデザートドリンク

  • シッケ・メシルチャ = 家庭料理後の無料デザートドリンク
  • ペクパンチプ(백반집、家庭式定食店)・MZ世代の韓食レストラン — コスパ良し

翌日の二日酔い対策シリーズ

  • メシルチャ + ヘジャンス = 翌日の二日酔い対策の定番コンビ
  • 24時間営業のポンジュク・クッパの店 — 二日酔い対策ファンの店

伝統酒場・MZ世代のマッコリブーム

  • トンドンジュ・マッコリ (막걸리 / makgeolli) = 伝統酒シリーズ (#840)
  • 広蔵市場 (광장시장 / Gwangjang Market)・インサドンの伝統酒場 — 伝統的な店

⚠ 外国人観光客がよくする5つの勘違い

1. 「シッケ = シケ」：シッケ = 甘い飲み物(米飯+麦芽) / シケ = 発酵おかず(江原道の伝統) — 名前は似ているが全く別の食べ物。

2. 「トンドンジュ = 普通のドリンク」：トンドンジュ = アルコール度数6~8%のお酒(食事のお酒)。

3. 「スジョングァ = お茶」：スジョングァ = シナモン・生姜・柿のパンチ(お茶ではなく果実系ドリンク)。

4. 「韓定食のドリンクは別料金」：韓定食の締めドリンク = 無料で含まれる(シッケ・スジョングァ)。

5. 「メシルチャ = 普通のお茶」：メシルチャ = 薬膳系ドリンク(消化促進・二日酔い対策ファンに人気)。

⚙ よくある質問8選

1. 外国人観光客の入門順：シッケ(韓定食の締め) + スジョングァ(冬の定番) → メシルチャ(消化促進)。

2. インスタ・vlog映え：韓定食締めNo.1のシッケ、干し柿を添えたスジョングァ、伝統的なトンドンジュ。

3. MZ世代のトレンド：MZ世代カフェのシッケアレンジドリンク、トンドンジュ、梅の炭酸ドリンク。

4. 消化促進・二日酔い対策向け：メシルチャ + ヘジャンス。

5. アレルギー：ナッツ(松の実)について事前に伝えること。

6. アルコール：トンドンジュ = 6~8% — 妊婦・運転者は不可。

7. 支払い・チップ：韓定食・家庭料理 = カードOK / チップ不要。

8. VAT還付：飲食は基本的に還付対象外。

⚠ 医療・安全・食事に関する注意事項

食後の締めドリンクは日常的な飲み物。妊婦・子ども = シッケ、スジョングァ、メシルチャはOK(トンドンジュ = NG、アルコールを含む)。アレルギー(ナッツ、生姜)は事前に申告すること。食中毒が疑われる場合は ☎ 1339(医療、英語対応)へ。本ガイドは一般的な情報であり、医療アドバイスではない。

食事制限への対応：

  • ハラール・コーシャ：シッケ、スジョングァ、メシルチャ、ヘジャンス、シケ(地域による) = OK / トンドンジュ = NG、アルコールを含む。
  • ベジタリアン・ヴィーガン：6種中5種 = OK / シケ = 魚の発酵(非菜食)。
  • グルテンフリー：6種すべてOK(しょうゆを含む場合はたまり醤油で代用可)。
