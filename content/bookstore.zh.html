⚠ 外国游客常犯的3个错误

1. 误以为所有大型连锁都有丰富的英文书

教保 (Kyobo / 교보)·永丰 (Youngpoong / 영풍)·阿拉丁 (Aladdin / 알라딘) 都有英文专区，但主体是韩文书。英文精选压倒性地集中在梨泰院书店 (Itaewon Books / 이태원 북스) / 世和 (Sehwa / 세화) / 储藏室 (Storage / 스토리지) 这3家。一般连锁的英文区以畅销书为主，小众书·二手书·摄影集可能会令人失望。

2. 不查休息日导致白跑一趟

世和英语书店 (Sehwa's English Bookstore / 세화 영어서점) 周五休息 (较少见)，梨泰院书店 (Itaewon Books / 이태원 북스) 周三休息，书库 (Seoul Book Repository / 책보고) 周一休息，大五书店 (Daeo Bookstore / 대오서점) 不定期休息。营业时间和每周休息日都必须提前确认。

3. 把星野图书馆 (Starfield Library / 별마당도서관) 误以为是"可借阅的图书馆"

免费入场，但不能借阅，仅限现场阅览。可以自由拍照，但书籍不能带出馆外。仅适合作为打卡景点 + 30分钟至1小时休息之用。

韩国书店风景

首尔拥有230万册旗舰店教保 (Kyobo / 교보)、50年英文二手书店梨泰院书店 (Itaewon Books / 이태원 북스)、1953年老字号大五书店 (Daeo Bookstore / 대오서점)、13米书架打卡热点星野图书馆 (Starfield Library / 별마당도서관)、文案人策展精选书崔仁雅书房 (Choi Ina's Bookshop / 최인아 책방) ——单一品类中并存四种风格。

外国游客应提前明确意图：(a) 购买韩语入门书·翻译小说，(b) 用英文二手书平价填满书单，(c) 寻找摄影集·艺术书，(d) 将书店作为打卡·观光景点——提前确定这4种意图之一，路线才能高效。

四大维度映射

  • ① 大型连锁 — 韩国书籍入门: 教保文库 (Kyobo Bookcentre / 교보문고)·永丰文库 (Youngpoong Bookstore / 영풍문고)·阿拉丁江南 (Aladdin Gangnam / 알라딘 강남)。韩语畅销书·旅行书·翻译小说品类最全。
  • ② 英文专门 — 英文书寻宝: 梨泰院书店 (Itaewon Books / 이태원 북스)·世和英语书店 (Sehwa's English Bookstore / 세화 영어서점)·储藏室书与电影 (Storage Book and Film / 스토리지 북앤필름)。英文比重80%以上，含小众书·摄影集·艺术书。
  • ③ 老字号·精选 — 时间与品味: 大五书店 (Daeo Bookstore / 대오서점)·谢谢书店 (THANKS BOOKS / 땡스북스)·崔仁雅书房 (Choi Ina's Bookshop / 최인아 책방)。从1953年老字号到策展人精选·画廊·文案人策展。
  • ④ 打卡地标·体验 — 拍照·行程: 星野图书馆 (Starfield Library / 별마당도서관)·书库 (Seoul Book Repository / 책보고)·ARC·N·BOOK (아크앤북)·汉阳文库 (Hanyang Bookstore / 한양문고)。打卡景点 + 大型购物中心组合。

① 大型连锁 — 韩国书籍入门 (3家)

教保文库光化门 (Kyobo Bookcentre Gwanghwamun / 교보문고 광화문)

韩国最大书店连锁教保 (Kyobo / 교보)的旗舰店。位于光化门广场旁教保生命大厦地下1层，9,000㎡规模，230万册。韩语畅销书·人文·旅行·漫画全品类 + 英文·中文·日文外文书专区。馆内设星巴克 + 充足休息空间，是逛完光化门顺道歇脚的好去处。

  • 地址: 钟路区 (Jongno-gu / 종로구) 钟路 (Jongno / 종로) 1, B1F (光化门 / Gwanghwamun / 광화문)
  • 营业时间: 每天 09:30–22:00
  • 亮点: 230万册 + 4国外文书专区 + 星巴克
  • 推荐理由: 自然融入光化门 (Gwanghwamun / 광화문)·景福宫 (Gyeongbokgung / 경복궁) 行程。韩语入门书 + 英文畅销书一站解决。

永丰文库钟路本店 (Youngpoong Bookstore Jongno / 영풍문고 종로 본점)

韩国第二大书店连锁。清溪川旁钟路本店 10,600㎡，35万册。B1书籍·B2"Stylish Gift Mall"(文具·电子·礼品·品牌店)。设数字检索自助机和活动空间，一次搞定书籍 + 生活方式礼品。

  • 地址: 钟路区 (Jongno-gu / 종로구) 清溪川路 (Cheonggyecheon-ro / 청계천로) 41 (钟路本店 / Jongno / 종로)
  • 营业时间: 每天 10:00–22:00
  • 亮点: 35万册 + B2生活方式礼品馆
  • 推荐理由: 清溪川 (Cheonggyecheon / 청계천) 散步 + 书籍+礼品一次搞定。路线比教保更轻松。

阿拉丁二手书江南店 (Aladdin Used Books Gangnam / 阿拉丁二手书店江南店 (Aladin Used Bookstore Gangnam / 알라딘 중고 강남점))

韩国最大二手书连锁。位于江南大路旁地下1层，独特卖场设计 + 品类丰富。以韩文二手书为主，亦有英文书·CD·文具。适合想控制书本预算的背包客·长期居留者。

  • 地址: 瑞草区 (Seocho-gu / 서초구) 江南大路 (Gangnam-daero / 강남대로) 381, 地下1层 (江南 / Gangnam / 강남)
  • 营业时间: 每天 09:30–22:00
  • 亮点: 韩文二手书 + 部分英文 + 高性价比
  • 推荐理由: 江南站 (Gangnam Station / 강남역) 步行5分钟。推荐给想控制书本预算的背包客。

② 英文专门 — 英文书寻宝 (3家)

梨泰院书店 (Itaewon Books / 이태원 북스，旧称 Itaewon Foreign Bookstore)

首尔历史最悠久的英文二手书专门书店，50年以上历史。在未经整理的书堆中淘宝 — 经典文学·非虚构·奇幻·历史·艺术书应有尽有。价格跨度大 (₩3,000起)。

  • 地址: 龙山区 (Yongsan-gu / 용산구) 绿莎坪大路 (Noksapyeong-daero / 녹사평대로) 208, 1层 (梨泰院 / Itaewon / 이태원)
  • 营业时间: 周一·五·六 11:00–19:30 / 周二·四·日 14:00–19:30 / 周三休息
  • 亮点: 50年英文专门 + 淘宝乐趣
  • 推荐理由: 位于梨泰院 (Itaewon / 이태원) 外国人街中心。英文二手书价格跨度最大。

世和英语书店 (Sehwa's English Bookstore / 세화 영어서점)

位于吉音站 (Gireum Station / 길음역) 附近的极简英文专门书店。衬线字体招牌 + 绿植装饰。新书·二手英文书 + 韩国小说英文译本精选是一大亮点。店主是位亲切的女士，深受外国常客喜爱。

  • 地址: 城北区 (Seongbuk-gu / 성북구) 三洋路 (Samyang-ro / 삼양로) 15-2 (吉音 / Gireum / 길음)
  • 营业时间: 周一至四·六 11:00–21:00 / 周日 13:00–21:00 / 周五休息
  • 亮点: 韩国小说英文译本精选策展
  • 推荐理由: 梨泰院 (Itaewon / 이태원) 之外的英文书第二站。街区氛围 + 店主推荐。

储藏室书与电影 (Storage Book and Film / 스토리지 북앤필름)

藏于梨泰院·汉南洞 (Hannamdong / 한남동) 巷弄中的摄影集·艺术书专门店。以国内外摄影师·插画艺术家作品为主。店面虽小，小众收藏深度十足。

  • 地址: 龙山区 (Yongsan-gu / 용산구) 汉南洞 (Hannamdong / 한남동) 一带 (梨泰院·汉南 / Itaewon·Hannam / 이태원·한남)
  • 营业时间: 周二至日 12:00–20:00 / 周一休息 (随季节调整)
  • 亮点: 摄影集·艺术书小众精选
  • 推荐理由: 距梨泰院书店 (Itaewon Books / 이태원 북스) 步行10分钟。英文书之旅收尾 + 摄影集·插画淘宝。

③ 老字号·精选 — 时间与品味 (3家)

大五书店 (Daeo Bookstore / 대오서점)

1953年创立，韩国历史最悠久的书店之一。位于紫霞门路 (Jahamun-ro / 자하문로) 7街韩屋巷弄内。以老韩文小说·诗集·二手书为主。古朴的韩屋 (Hanok / 한옥) 形态令其成为打卡热点，也曾多次作为韩剧·电影拍摄地。

  • 地址: 钟路区 (Jongno-gu / 종로구) 紫霞门路 7街 (Jahamun-ro 7-gil / 자하문로 7길) 55 (西村 / Seochon / 서촌)
  • 营业时间: 不定期 (通常平日上午至下午，休息较频繁 — 建议提前确认)
  • 亮点: 70年老字号 + 韩屋巷弄
  • 推荐理由: 西村 (Seochon / 서촌)·景福宫 (Gyeongbokgung / 경복궁) 行程 + 感受时光停驻的韩国书店氛围。适合拍照·散步。

谢谢书店 (THANKS BOOKS / 땡스북스)

位于弘大 (Hongdae / 홍대) 杨花路 (Yanghwa-ro / 양화로) 6街巷弄。书店+咖啡+画廊三合一。1层韩文图书·杂志(设计·艺术为主)，2层画廊·研讨会空间。每本书都附有店员手写便条 — 策展魅力无可比拟。

  • 地址: 麻浦区 (Mapo-gu / 마포구) 杨花路 6街 (Yanghwa-ro 6-gil / 양화로 6길) 57-6 (弘大 / Hongdae / 홍대)
  • 营业时间: 每天 12:00–21:00
  • 亮点: 手写便条策展 + 设计·艺术精选
  • 推荐理由: 弘大 (Hongdae / 홍대) 设计景点散步 + 以文字感受策展人的书籍推荐。

崔仁雅书房 (Choi Ina's Bookshop / 최인아 책방)

位于三成洞 (Samseon-dong / 삼성동)·宣陵站 (Seolleung Station / 선릉역) 附近。由广告文案人出身的崔仁雅 (Choi Ina / 최인아) 代表亲自策展的精选书店。书 + 咖啡结合。以商业·人文·随笔为主。店内音乐亦经精心策展。

  • 地址: 江南区 (Gangnam-gu / 강남구) 宣陵路 (Seolleung-ro / 선릉로) 521 (宣陵/三成 / Seolleung/Samseong / 선릉/삼성)
  • 营业时间: 每天 11:00–22:00 (随季节调整)
  • 亮点: 文案人策展 + 音乐策展
  • 推荐理由: 宣陵 (Seolleung / 선릉)·COEX行程 + 对韩国广告/营销有兴趣的商务旅行者。

④ 打卡地标·体验 — 拍照·行程 (4家)

星野图书馆 (Starfield Library / 별마당도서관)

COEX购物中心中央13米高书架 + 5万册免费阅览。2017年开馆后跃居打卡景点榜首。以时尚·旅行·艺术杂志为主 (学术书较少)。外国游客必访之地。

  • 地址: 江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513, COEX购物中心 B1·1F
  • 营业时间: 每天 10:30–22:00
  • 亮点: 13米书架 + 5万册免费阅览
  • 推荐理由: 自然融入COEX水族馆·SM Town·Megabox行程。拍照30分钟 + 休息1小时。

书库 (Seoul Book Repository / 책보고)

位于松坡 (Songpa / 송파) 蚕室 (Jamsil / 잠실) 一带。将废弃·捐赠的13万册图书再利用的公共型旧书店。位于新川站 (Sincheon Station / 신천역) 附近，采用集装箱室内设计。免费入场。以韩文为主，部分英文·日文。

  • 地址: 松坡区 (Songpa-gu / 송파구) 梧琴路 (Ogeum-ro / 오금로) 1, 新川洞 (Sincheon-dong / 신천동) (蚕室 / Jamsil / 잠실)
  • 营业时间: 周二至日 10:00–21:00 / 周一休息
  • 亮点: 13万册废弃图书再利用 + 集装箱室内设计
  • 推荐理由: 蚕室乐天塔 (Lotte World Tower Jamsil / 잠실 롯데타워) 行程 + 环保理念 + 打卡。书籍可购买，价格约₩2,000–5,000。

ARC·N·BOOK乐天世界购物中心 (ARC·N·BOOK Lotte World Mall / 아크앤북 롯데월드몰)

位于蚕室 (Jamsil / 잠실) 乐天世界购物中心4层。MZ生活方式精选书店。书 + 小物件 + 咖啡融合。设计·旅行·生活方式杂志阵容强大。室内设计适合打卡。成水 (Seongsu / 성수)·乙支路 (Euljiro / 을지로) 设有分店，路线灵活。

  • 地址: 松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Olympic-ro / 올림픽로) 300, 4层 (乐天世界购物中心 / Lotte World Mall / 롯데월드몰)
  • 营业时间: 每天 10:30–22:00
  • 亮点: MZ生活方式精选 + 打卡室内设计
  • 推荐理由: 乐天世界购物中心·蚕室 (Jamsil / 잠실) 行程的一部分。分店众多，路线灵活。

汉阳文库 (Hanyang Bookstore & Cafe / 한양문고)

位于明洞 (Myeongdong / 명동) Noon Square (누스퀘어) B2层。现代设计书咖。以韩文图书为主 + 英文专区 (以韩国小说译本为中心) + 配饰·礼品。

  • 地址: 中区 (Jung-gu / 중구) 明洞街 (Myeongdong-gil / 명동길) 14, Noon Square B2 (明洞 / Myeongdong / 명동)
  • 营业时间: 每天 11:00–21:00
  • 亮点: 明洞地下现代书咖 + 饮品评价高
  • 推荐理由: 明洞购物·观光后30分钟休息。书 + 咖啡 + 礼品一站搞定。

⚙ 常见问题 8个

Q1. 只想找英文书，从哪里开始？

梨泰院书店 (Itaewon Books / 이태원 북스) → 储藏室书与电影 (Storage Book and Film / 스토리지 북앤필름) 步行10分钟路线。世和英语书店 (Sehwa's English Bookstore / 세화 영어서점) 位于吉音 (Gireum / 길음)，需单独安排行程。教保 (Kyobo / 교보)·永丰 (Youngpoong / 영풍)·阿拉丁 (Aladdin / 알라딘) 英文区以畅销书为主，小众·二手英文书较少。

Q2. 韩语入门书 / 韩语学习书在哪里买？

教保文库光化门 (Kyobo Bookcentre Gwanghwamun / 교보문고 광화문) B1外语学习区，或永丰文库钟路本店 (Youngpoong Bookstore Jongno / 영풍문고 종로 본점)。K-pop·韩剧相关英文指南也很丰富。韩语单词书约₩10,000以内。

Q3. 摄影集·艺术书在哪里找？

储藏室书与电影 (Storage Book and Film / 스토리지 북앤필름) (梨泰院 / Itaewon / 이태원)→ 谢谢书店 (THANKS BOOKS / 땡스북스) (弘大设计·艺术 / Hongdae / 홍대)两家是核心。星野图书馆 (Starfield Library / 별마당도서관) 时尚·艺术杂志丰富，但只能阅览，不能购买。

Q4. 最适合打卡的书店是哪里？

星野图书馆 (Starfield Library / 별마당도서관) (13米书架)→ 大五书店 (Daeo Bookstore / 대오서점) (韩屋巷弄)→ 书库 (Seoul Book Repository / 책보고) (集装箱)— 前三名。星野图书馆免费，大五书店拍照请先征得店主同意，书库可自由拍摄。

Q5. 哪些书店需要注意休息日？

  • 世和英语书店 (Sehwa's English Bookstore / 세화 영어서점): 周五 休息
  • 梨泰院书店 (Itaewon Books / 이태원 북스): 周三 休息
  • 书库 (Seoul Book Repository / 책보고): 周一 休息
  • 储藏室书与电影 (Storage Book and Film / 스토리지 북앤필름): 周一 休息 (随季节调整)
  • 大五书店 (Daeo Bookstore / 대오서점): 不定期 (建议前往前查看Instagram或致电确认)

Q6. K-pop·韩剧相关英文周边在哪里？

教保文库光化门 (Kyobo Bookcentre Gwanghwamun / 교보문고 광화문) B1 + 永丰文库钟路 (Youngpoong Bookstore Jongno / 영풍문고 종로) B2礼品馆。ARC·N·BOOK (아크앤북) 生活方式周边阵容也很强。K-pop写真书含部分英文说明。

Q7. 性价比最好的书在哪里买？

二手书 = 阿拉丁江南 (Aladdin Gangnam / 알라딘 강남) / 梨泰院书店 (Itaewon Books / 이태원 북스) / 书库 (Seoul Book Repository / 책보고)。新书 = 教保文库 (Kyobo Bookcentre / 교보문고) (会员折扣5%)/ 永丰文库 (Youngpoong Bookstore / 영풍문고) (时常有10%左右折扣活动)。外文书约贵30% (进口成本)。
