외국인 한국 진주 유등축제 — 한국 #1 등불 축제·10월·매니아 매트릭스 #1

부제: 외국인 관광객용 진주 유등축제 (10월 1-2주)·한국 #1 등불 축제·남강 + 촉석루 + 진주성 매트릭스

ISSUE 04 · #1067 · 2026-06-13

🎯 왜 진주 유등축제 가이드인가

진주 유등축제 (Jinju Lantern Festival) = 한국 #1 등불 축제·2000년 시작·25년+·매년 10월 1-2주·남강 + 촉석루 + 진주성 매트릭스. 외국인 페인포인트 = (a) 한국 매니아 매트릭스 #1·연 280만+ 방문 (b) 남강 유등 + 인스타 매트릭스 1번지·MZ + 매니아 #1 (c) 촉석루 (#1055 cross)·진주성·임진왜란 1592 매트릭스 (d) 무료 + 일부 유료 (10,000원)·예산형 매니아 매트릭스 (e) 다국어·영문 풀세트.

본 가이드는 5축 12 시그니처 + 유등축제 매트릭스 + 진주 cross.

★ 한눈에 5축 12 시그니처

매니아: 유등 + 부산 (#1021) cross 풀세트

🏛 5축 deep dive

① 남강 유등 (메인·매니아 #1)

  • 시그니처: 남강 + 유등 매트릭스 #1·연 280만+ 매니아·19:00~22:00 야경 매트릭스
  • 외국인 친화도: ★★★★★ (인스타·MZ + 가족 매니아 매트릭스 #1)
  • 시간: 09:00~22:00·무료·일부 유료 (보트 10,000~20,000원)
  • 추천: 야경 + 유등 보트 + 인스타 매트릭스 #1

② 촉석루 + 진주성 (#1055 cross)

  • 시그니처: 영남 #1 누각·임진왜란 1592 진주대첩 매트릭스·의기 논개 매니아
  • 외국인 친화도: ★★★★ (영문 시그너·역사 매니아)
  • 시간: 09:00~18:00·촉석루 2,000원·진주성 + 박물관 5,000원

③ 진주냉면 + 헛제사밥

  • 시그니처: 한국 #1 진주냉면 시그너·헛제사밥 진주 시그너 매트릭스
  • 외국인 친화도: ★★★★ (안 매콤·외국인 입문)
  • 가격: 진주냉면 = 12,000~18,000원·헛제사밥 = 15,000~25,000원

④ 시즌 매트릭스

  • 2026 진주 유등축제: 10월 1일 (목)~10월 12일 (월)·12일간 예상
  • 외국인 매니아: 1-2개월 사전 예약 권장
  • 무료 + 일부 유료: 야경 매트릭스 = 매니아 매트릭스 #1

⑤ 교통

  • 시그니처: KTX 진주역 3시간 30분 (서울)·부산 + 진주 cross (KTX 1시간)
  • 1박 권장: 야경 매트릭스 + 다음 날 촉석루

⚠ 외국인 자주 실수 5가지

1. "진주 유등 = 일반 축제": 한국 #1 등불 축제·연 280만+ 매니아 매트릭스 #1.

2. "진주 = 멀다": KTX 3시간 30분·부산 KTX 1시간 cross 풀세트 매트릭스.

3. "유등 = 낮": 19:00~22:00 야경 매트릭스 #1·인스타 1번지.

4. "진주냉면 = 평양과 동일": 한국 #1 진주 시그너 매트릭스·해물·갈비 + 매콤 매트릭스.

5. "부산 + 진주 X": KTX 1시간 cross·1박 풀세트 매니아 매트릭스 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: 남강 유등 + 촉석루 + 진주냉면 = 1박.

2. 2026 일정: 10월 1일~10월 12일·12일간 예상.

3. 무료: 유등 + 진주성 일부 무료·보트 10,000~20,000원.

4. 호텔: 1-2개월 사전 예약 권장.

5. 부산 cross: KTX 1시간·유등 + 부산 = 매니아 풀세트.

6. 추천 페르소나: 가족·시니어 = 촉석루 + 진주냉면 / MZ·인스타 = 유등 + 야경 + 보트 / 매니아 = 1박 + 부산 cross.
