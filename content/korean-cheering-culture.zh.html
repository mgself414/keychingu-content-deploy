韩国应援·合唱文化 — 为什么韩国人一聚在一起就齐声呐喊？

> KBO 应援队长·选手专属应援歌曲·充气棒·合唱·应援棒·炸鸡啤酒·兴 (heung / 흥) — 为外国人准备的韩国应援文化解说。不仅仅是“嘈杂的赛场”，更是“为什么·是什么·怎么做”。

第一次去韩国棒球场的外国人，几乎都会受到同样的冲击。无论比赛是 0:0 还是我们队落后，9 局比赛中，看台上的歌声、口号和掌声从未停止。舞台上，一位应援队长 (eungwondan-jang / 응원단장) (cheer captain, 负责带领观众应援的指挥者) 吹着哨子指挥着数千人，每当击球手更换时，专属于那位选手的应援歌曲 (eungwonga / 응원가) (cheering song, 为每位选手定制的专属歌曲) 就会再次响起。演唱会现场也是如此。当 K-pop 歌手将麦克风递向观众时，数万人会合唱 (ttae-chang / 떼창) (singalong, 全体观众一起大声唱歌) 完整歌词。外国人通常只会将这种集体热情简单地归结为“韩国人真是太兴奋了”，但其背后是贯穿棒球、足球、演唱会的韩国特有的“一起呐喊的文化”。本文并非探讨“哪个体育场好” (→ 另文讨论)，而是深入解析这种集体热情从何而来，以及外国人如何融入其中。这是韩国文化解说系列第 31 篇。

★ 一目了然 — 韩国应援，激情何处爆发？

舞台 核心 一句话总结
⚾ 棒球 (KBO) 应援队长 + 选手专属应援歌曲 + 充气棒 9 局比赛不间断的“应援演唱会”。全球独一无二
⚽ 足球 (街头) 红魔 (Red Devils / 붉은악마) + “大~韩民国” 2002 年世界杯广场应援创造的全国性合唱
🎤 演唱会 (K-pop) 合唱 + 粉丝应援口号 + 应援棒 观众成为“第二舞台”的参与式应援
🎵 合唱 所有人一起唱歌 与练歌房 (noraebang / 노래방) (KTV, 韩国特有的卡拉OK包厢文化)·公司聚餐 (hoe-sik / 회식) (company dinner, 韩国公司文化中常见的集体聚餐活动) 一脉相承 — 聚在一起就用歌声释放
🔥 兴 (heung / 흥)·神明 (sinmyeong / 신명) 集体狂欢 “为什么聚在一起呐喊”的真正引擎 (见下文 ⑤)

> 核心: 韩国应援的本质不是“嘈杂”，而是“大家一起合为一体的兴 (heung / 흥)”。棒球场是体验这种文化的最佳入口 (见下文 ⑥)。

⚠️ 外国人常有的 3 种误解

1. “只有我们队赢的时候才会应援吧” ❌ — KBO 应援与比分·胜负无关。无论是 0:0 还是落后 5 分，应援队长都会在 9 局比赛中全程带领应援。美国职业棒球大联盟 (MLB) 在攻守转换时应援会减弱，但韩国棒球场是比赛全程“应援绝不停止”的结构。洛杉矶道奇 (LA Dodgers) 的教练也曾称这种文化“非常新颖 (very refreshing)”。

2. “韩国式应援很难模仿吧” ❌ — 相反，这是全球最容易融入的应援方式。舞台上的应援队长会实时展示动作，应援歌曲结构简短且重复，外国人只需 1~2 局就能敲打充气棒跟着模仿。即使不懂歌词，只要跟着手势做就行。

3. “这不就是吵闹吗？” ❌ — 这不是无序的噪音，而是高度组织化的集体表演。每个球队都有官方应援团、专属颜色的充气棒、选手专属应援歌曲，数千人以相同的节奏行动。其根源在于韩国特有的“一起狂欢”的情绪 (见下文 ⑤)。

① “韩国式应援”是什么 — 观众就是选手

韩国应援的核心是一个词：“参与 (participation)”。如果说其他国家的体育迷主要是“观看并反应”，那么韩国观众则是从头到尾积极创造的主体。

  • 有领导者: 棒球场有应援队长和啦啦队，演唱会有粉丝团的粉丝应援口号 (fanchant) 指南，将数千至数万人的应援汇聚成一个方向。
  • 有规则: 选手专属应援歌曲、球队专属应援棒·充气棒、固定的口号 (“大~韩民国”五次拍手等) — 这不是即兴的，而是共享的“剧本”。
  • 坚持到底: 即使胜负已定也不会停止。因为应援本身就是目的。

因此，外国人来到韩国赛场，感受到的不是“A 队对阵 B 队”，而是“置身于一场盛大的合唱庆典”。VisitKorea (韩国旅游发展局) 官方内容也介绍，即使对棒球不感兴趣，也能感受到参与一场盛大庆典的氛围。

② 棒球应援 (KBO) — 全球独一无二的“应援演唱会”

韩国应援文化的巅峰，也是最推荐外国人体验的入口，就是韩国职业棒球 (KBO 联赛, 1982 年成立)。2024 年，一个赛季的观众人数达到约 1,088 万人，首次突破 1 千万，创下 KBO 历史新高 — 足见其在日常文化中的深厚根基。

应援队长 & 啦啦队 — 舞台上的应援队长用哨子和口号指挥观众 9 局比赛不间断，啦啦队则根据信号带领舞蹈。美国职业棒球大联盟 (MLB) 和日本棒球都没有完全相同的形式，这是韩国特有的结构。(1982 年成立初期是即兴的掌声和歌声，有组织的官方应援团是在 1990 年代后才逐渐形成。)

★ 选手专属应援歌曲 — 韩国棒球最独特的场景。每位击球手都有专属的应援歌曲。当选手站上打击区时，就会响起他的专属歌曲，全体观众会喊着他的名字一起合唱。很多歌曲都是将熟悉的流行歌曲或韩国流行歌曲改编成易于跟唱的形式。(据了解，球队单位的选手专属应援歌曲是在 2000 年代后期由乐天巨人 (Lotte Giants) 等球队开始普及的。) 这种文化甚至传到了海外，曾在 KBO 联赛效力的外国击球手埃里克·泰姆斯 (Eric Thames) 在 2017 年转战美国职业棒球大联盟 (MLB) 后，他 KBO 时期的应援歌曲也跟着传过去，成为美国球迷热议的话题。

充气棒 (thunder sticks) — 两个相互敲击发出声音的细长应援工具。据记载，LG 双子 (LG Twins) 在 1994 年韩国系列赛中首次引入，是全球首创。此后普及到所有球队，每个球队都有专属颜色 (红、蓝、白、黄等)。看台被一种颜色染成一片，形成壮观的景象。

炸鸡啤酒 (chimaek / 치맥) — “炸鸡+啤酒”。这是与棒球场密不可分的组合。观众可以点炸鸡送到座位上边吃边应援，部分球场甚至允许自带炸鸡。这就是为什么外国导游将“棒球场炸鸡啤酒 = 韩国必体验”的原因。

③ 足球街头应援 — 2002 年创造的“广场合唱”

如果说棒球场是“赛场内”的应援，那么足球则是“涌上街头”应援的象征。其起点是2002 韩日世界杯 (2002 FIFA World Cup Korea/Japan)。

  • 2002 年，韩国队闯入世界杯四强 (半决赛)。 这是亚洲球队首次也是迄今为止唯一的记录。他们在 16 强赛中击败意大利，8 强赛中击败西班牙，半决赛以 0:1 负于德国，在三四名决赛中输给土耳其，最终以第四名结束了比赛。(教练是荷兰籍的古斯·希丁克 (Guus Hiddink)。)
  • 红魔 (Red Devils / 붉은악마) — 韩国足球国家队的支持者。成立于 1990 年代后期，在 2002 年世界杯的契机下，其影响力爆发至全国范围。身穿红色 T 恤的应援将广场染成一片鲜红。
  • 广场合唱 — 在首尔市厅广场 (Seoul City Hall Plaza)、光化门 (Gwanghwamun / 광화문)、新村 (Sinchon / 신촌)、釜山广安里 (Busan Gwangalli / 부산 광안리) 等全国各地同时举行街头应援，比赛期间累计参与人数达到约700 万人 (约占成年人口的 20%)。这不是一个城市，而是整个国家同时进行合唱。
  • “大~韩民国” + 拍手 — “大~韩民国”口号后接五次拍手 (짝짝짝-짝짝) 的节奏。经过 2002 年，这成为所有韩国体育应援的基本形式。

这次经历并非昙花一现。2022 年卡塔尔世界杯 (Qatar World Cup) 期间，为了观看韩国对巴西的 16 强赛，约 3.3 万人在零下气温的凌晨时分聚集在光化门 (Gwanghwamun / 광화문) 粉丝区。“大赛 = 聚集在广场一起应援”的公式是 2002 年留下的文化遗产。

④ 演唱会合唱·K-pop 粉丝团 — 观众是“第二个舞台”

第一次去 K-pop 演唱会的外国人，惊讶的不是舞台，而是观众席。因为观众不是单纯的旁观者，而是表演的一部分。

  • 合唱 — 当歌手将麦克风转向观众席时，数万人会合唱完整的歌词。有时，观众全体合唱一段抒情歌曲的瞬间会成为演出的高潮。
  • 粉丝应援口号 (fanchant) — 在特定歌词时机，全体一致喊出成员名字或固定口号的“约定应援”。每个组合都会发布官方指南，粉丝们会提前背诵。因此，即使是第一次来的人，只要跟着旁边的人做，很快就能融入 (多语言指南也降低了外国人的入门门槛)。
  • 应援棒 (light stick) — 每个粉丝团都有独特设计的应援棒 (如 BTS 的“阿米棒 (Army Bomb)”)。现在的型号可以通过蓝牙连接，让整个演唱会现场的应援棒随着音乐改变颜色并形成波浪。观众席本身就变成了一场巨大的灯光表演。

这里的核心也是一样的。舞台和观众席的界限模糊，观众是积极的参与者 — 这与棒球场的合唱有着完全相同的 DNA。

⑤ 为什么聚在一起齐声呐喊 — 兴 (heung / 흥)·神明 (sinmyeong / 신명)·合为一体

这是本文的核心。棒球、足球、演唱会的合唱只是表面现象，其背后蕴含着韩国特有的情感。

兴 (heung / 흥) — 愉悦、开心的瞬间涌现的积极情绪。它并非英语中的“excitement”或“joy”所能完全表达，而是在韩国文化中孕育出的一种特定情感。当兴 (heung / 흥) 达到高潮时，人们会情不自禁地唱歌跳舞 — 棒球场·演唱会的集体狂欢正是这种兴 (heung / 흥) 的体现。

神明 (sinmyeong / 신명) — 在文化心理学中，神明 (sinmyeong / 신명) 被解释为“当受损的自我价值感恢复时涌现的积极情绪”。有趣的是，这与韩国情感的另一个支柱恨 (han / 한) (deep-seated resentment, 韩国文化中压抑在心底的郁结情绪) 恰好相反。也就是说，一起呐喊唱歌的行为，是将郁结转化为神明 (sinmyeong / 신명) 的集体释放。韩国自古以来就有在古代祭天仪式上大家一起吃喝、唱歌跳舞的集体仪式传统，现代的应援·练歌房 (noraebang / 노래방)·公司聚餐 (hoe-sik / 회식) 被认为是其后裔。

情 (jeong / 정)·我们 (woori / 우리) — 韩国拥有将“我”置于“我们” (我们队·我们国家·我们家人) 之前的语言和情感 (→ [#1135 情文化](1135_korean_jeong_culture.md))。一起呐喊、一起跳舞的经历本身就是建立情 (jeong / 정) 的途径。就像吃饭·练歌房 (noraebang / 노래방)·公司聚餐 (hoe-sik / 회식) 一样，应援最终也是“通过共同参与而合为一体”的社会机制。

> 一句话总结: 韩国应援是“一起制造兴 (heung / 흥)，从而成为我们 (woori / 우리)” — 目的不是为了赢而呐喊，而是在呐喊的那一刻合为一体。

⑥ 外国人参与棒球场应援 — 最简单的“韩国人体验”

在众多韩国应援方式中，外国人最容易、最安全融入的舞台就是棒球场。几乎没有语言障碍，容易模仿，氛围友好。

> 价格·运营以 2026 年为准估算，并根据球场·比赛有所不同 — 建议访问前确认。

  • 地点: 以首尔为例，蚕室棒球场 (Jamsil Yagujang / 잠실야구장) (LG 双子 (LG Twins)·斗山熊 (Doosan Bears) 主场，地铁蚕室站 (Jamsil-yeok / 잠실역)，室外) 和高尺天空巨蛋 (Gocheok Sky Dome / 고척 스카이돔) (Kiwoom (키움) 英雄队主场，韩国首个巨蛋球场·2015 年开放，不受天气影响) 交通便利。外野应援区应援密度最高，体验感最佳。
  • 门票: 外国人可通过 Ticketlink Global·Interpark Global 等支持英文的网站使用海外信用卡预订。现场售票处也可凭护照购买，平日比赛通常可以当天购买。票价根据座位不同，约为8,000~53,000 韩元 (约 $6~40 美元 / 约 40~280 人民币 / 约 900~6,000 日元)。
  • 应援工具: 充气棒可在入场时领取或在球场周边·便利店 (pyeon-ui-jeom / 편의점) 购买。只需跟着应援队长的动作敲打即可。
  • 炸鸡啤酒 (chimaek / 치맥): 可送至座位或在球场外购买后享用。但请注意，巨蛋球场 (如高尺天空巨蛋 (Gocheok Sky Dome / 고척 스카이돔)) 可能限制罐装·酒类饮品带入，请提前确认。蚕室棒球场 (Jamsil Yagujang / 잠실야구장) 等室外球场相对自由。
  • 礼仪: 主队/客队应援区是分开的，选择一个球队并坐在其应援区，就能自然融入氛围。不懂歌词也没关系 — 只要跟着手势和充气棒，1~2 局内你就能成为一名“韩国棒球球迷”。

❓ 外国人常见问题 (FAQ)

  • 不懂棒球规则也能玩得开心吗？ — 完全可以。韩国棒球场一半的乐趣在于应援·合唱·炸鸡啤酒 (chimaek / 치맥) 的庆典氛围。VisitKorea (韩国旅游发展局) 也介绍说“即使不懂棒球，也能感受到参与一场盛大庆典的氛围”。
  • 不懂应援歌曲歌词也能加入吗？ — 可以。应援队长会实时展示动作，副歌部分简短重复，只要跟着手势和充气棒，就能自然融入。
  • 一个人去会尴尬吗？ — 韩国棒球场即使是不认识的人，只要是同一球队，也会一起呐喊，所以一个人也能玩得很开心。外野应援区尤其如此。
  • 演唱会合唱·粉丝应援口号 (fanchant) 如何提前准备？ — 各组合会通过视频·粉丝咖啡厅发布官方粉丝应援口号 (fanchant) 指南。很多也有外国人用的多语言指南，提前熟悉副歌部分即可。
  • 现在还能看到像 2002 年那样的街头应援吗？ — 平时不会，但在世界杯·奥运会等大型国际赛事期间，光化门 (Gwanghwamun / 광화문) 等地会设立粉丝区，重现街头应援 (2022 年也曾举行)。如果能赶上时机，就能体验到。
