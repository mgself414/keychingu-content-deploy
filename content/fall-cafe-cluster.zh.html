首尔看得到红叶的咖啡馆9家 — 仁王山林间路、宫殿屋顶、南山脚下的窗边

副标题: 仁王山·付岩洞山脚的三家咖啡馆，北村·宗庙·德寿宫·城北洞的四家韩屋茶馆和宫殿景观咖啡馆，再加南山和首尔林旁的两家。在窗外或院子外能看到树的地方里，只选了在Kakao地图 (Kakao Map / 카카오맵)上显示营业中、并且2026年秋天有到访评价的9家，分成3个区域。能找出非红叶季也值得去的理由的地方，各写了一句。

ISSUE 06 · #742 · 2026-11-24 · 首尔红叶咖啡馆

🎯 适合谁，为什么是这9家

这份清单是给想看红叶、又不想在山里走太久的游客准备的。首尔的红叶咖啡馆有三类。在仁王山·北岳山山脚，能同时看到森林和市区。在宫殿·韩屋街区，能隔着瓦屋顶看到古宫的树。在南山·首尔林一带，能俯瞰公园的树林。

选择标准有三个。Kakao地图的店铺信息必须是"营业中"。2026年10~11月必须有博客评价或Kakao地图评论。评价里必须提到森林·古宫·公园景观。

红叶的时间每年都不一样。按韩国气象厅常年值(1991~2020)，北汉山红叶10月15日前后开始，10月28日前后到最盛。年末的尾声取决于天气。2026-11-19的博客评价写道，几天的雨加上高考寒潮，德寿宫·贞洞路的红叶季快要结束了。

⚠ 标注原则: 营业时间·休息日·菜单价格是店主在Kakao地图上登记的值(2026-11-24确认)。价格只写了菜品登记日期在2年以内的。贞洞展望台的夜间·公共假日运营是首尔市官方页面的值(2026-11-24查阅)。饮食提示是从菜品名称·Kakao地图介绍里能读出来的内容，以及一般的做法为准。食材·过敏请在点餐前问店员。离车站远或在山坡上的地方，把博客评价里写的路线连同日期一起搬了过来。

① 仁王山·付岩洞 — 3家

三家都离地铁站太远，而且有坡。要坐公交或村庄巴士上去。山拐角和喜作在白石洞路 (Baekseok-dong-gil / 백석동길)上挨在一起，可以一次串起来。

  • 森林哨所书店 (Deosup Chosochaekbang / 더숲초소책방) — 把仁王山半山腰的旧哨所改建成的书咖啡馆。2026-11-20的博客评价写道，隔着落地玻璃能看到首尔市区和红叶。登记价是咖啡摩卡6,500韩元、燕麦拿铁6,500韩元、菊花茶5,500韩元、豆奶5,000韩元。每天08:00~22:00营业，全年无休。地址是钟路区 (Inwangsan-ro 172 / 인왕산로 172)。同一篇评价里给出了三条去的路。第一，从景福宫站 (Gyeongbokgung Station / 경복궁역)坐村庄巴士09路，在水声洞溪谷 (Suseong-dong Valley / 수성동계곡)下车，往上走690m。第二，从水声洞溪谷走山路约25分钟。第三，从景福宫站坐村庄巴士到尹东柱文学馆 (Yun Dong-ju Literary Museum / 윤동주문학관)，再走887m。停车场非常小。红叶季之外也值得去: 营业到22:00，适合去看市区夜景(2026-11-21的博客标题写着"夜景名所")。饮食提示: 有燕麦拿铁和豆奶，可以不加牛奶来喝。拿铁·摩卡含牛奶，咖啡含咖啡因。
  • 山拐角 (Sanmotungi / 산모퉁이) — 付岩洞山坡上的咖啡馆。2026-11-22的博客评价介绍说这里是电视剧《咖啡王子1号店》的取景地。2026-11-17的博客标题也写着"首尔红叶咖啡馆"。登记价是美式咖啡8,000韩元、地瓜拿铁9,000韩元、Almond Breeze 9,000韩元、手工柚子茶10,000韩元。每天11:00~18:50营业。地址是钟路区 (Baekseok-dong-gil 153 / 백석동길 153)。2026-11-22的评价说坡相当陡，建议坐村庄巴士(钟路05路等)过去再步行。红叶季之外也值得去: 2026-05的Kakao地图评论写道，座位多，有户外座位，景观很好。饮食提示: Almond Breeze如其名，是杏仁(坚果)饮料。地瓜拿铁·咖啡拿铁含牛奶。登记的菜单只有饮品。
  • 喜作 (Huijak / 희작) — 在山拐角旁边那栋楼地下1层的咖啡馆。2026-11-16的博客评价写了仁王山落地窗景观和周末的排队。登记价是美式咖啡6,800韩元、拿铁7,800韩元、巴斯克芝士蛋糕9,800韩元、布朗尼9,500韩元。周三至周一11:00~18:30营业，周二休息。地址是钟路区 (Baekseok-dong-gil 155 B1 / 백석동길 155 지하1층)。同一篇评价里给出了路线。从景福宫站3号出口坐7022路公交，在"紫霞门隘口·尹东柱文学馆" (Jahamun Pass·Yun Dong-ju Literary Museum / 자하문고개.윤동주문학관)下车，步行约16分钟。红叶季之外也值得去: 2026-11-17的评价写道，阴天仁王山的风景也很好。饮食提示: 自制柠檬水上面放着用爱尔兰威士忌做的冰沙(Kakao地图店主介绍)。避酒的话不要选。巴斯克芝士蛋糕含芝士(乳制品)，通常也含鸡蛋。

② 宫殿·韩屋街区 — 4家

北村一家，宗庙西边的西巡罗路一家，德寿宫旁市厅别馆一家，城北洞一家。茶庭周二休息，寿砚山房周一·周二休息。阁楼咖啡馆平日13:30开门。

  • 品茶庭院茶庭 (Chamasineun Tteul Chatteul / 차마시는뜰 차뜰) — 北村山坡上的韩屋传统茶馆。2026-11-22的博客评价写道，顺便看红叶来了这里。菜单上同时登记了英文名。登记价是双和汤10,000韩元、大枣汤10,000韩元、艾草茶12,000韩元、南瓜蒸糕11,000韩元、韩果5,000韩元(2025-12-31登记)。周三至周一10:00~19:00营业，周二休息。地址是钟路区 (Bukchon-ro 11na-gil 26 / 북촌로11나길 26)，最近的站是安国站 (Anguk Station / 안국역)(3号线)2号出口，步行15分钟。2026-07的Kakao地图评论写道，去的路相当难找。红叶季之外也值得去: 2026-11-18的博客评价里有五味子刨冰和传统弦乐演出的内容。饮食提示: 除了绿茶，大枣·艾草·菊花·五味子之类都是用花·果·药材做的茶，所以没有咖啡。南瓜蒸糕上桌要花约20分钟(店主介绍)。双和汤是用中药材熬的茶。
  • 咖啡馆View (Cafe View / 카페뷰) — 钟路3街西巡罗路一栋楼4层的咖啡馆。Kakao地图标签里有屋顶。2026-11-19的博客评价介绍说是能一览无余地看到宗庙的咖啡馆。登记价是美式咖啡6,000韩元、咖啡拿铁7,000韩元、View Royal奶茶9,000韩元、草莓奶油蛋糕8,000韩元。每天12:00~23:00营业。地址是钟路区 (Seosunra-gil 27-5 4F / 서순라길 27-5 4층)，最近的站是钟路3街站 (Jongno 3-ga Station / 종로3가역)(1·3·5号线)8号出口，步行4分钟。红叶季之外也值得去: 营业到23:00，适合傍晚去。2026-11-15的博客评价写道，下雨天去看宗庙景观。饮食提示: 奶茶·拿铁含牛奶。草莓奶油蛋糕通常用草莓、奶油和海绵蛋糕(面粉·鸡蛋)做成。
  • 阁楼咖啡馆 (Cafe Darak / 카페 다락)，贞洞展望台 (Jeongdong Observatory / 정동전망대) — 首尔市厅西小门办公楼13层贞洞展望台里的咖啡馆。透过落地窗俯瞰德寿宫屋顶和贞洞一带。2026-11-19的博客评价上传了上周拍的德寿宫秋景，并写道几天来的雨和寒潮让红叶快结束了。登记价是美式咖啡(HOT)3,000韩元、咖啡拿铁(HOT)3,500韩元、焦糖奥地利咖啡5,000韩元、洋甘菊茶2,500韩元(2025-05登记)。咖啡馆时间是Kakao地图登记值，平日13:30~17:30，周六·周日09:00~17:00。贞洞展望台周五·周六晚上也开放(冬季到21:00，首尔市官方)。这是展望台的运营时间，不是咖啡馆的营业时间。贞洞展望台公共假日不开放(首尔市官方)。地址是中区 (Deoksugung-gil 15 13F / 덕수궁길 15 13층)，最近的站是市厅站 (City Hall Station / 시청역)(1·2号线)12号出口，步行5分钟。红叶季之外也值得去: 展望台不收门票(2026-11-22博客)，参观德寿宫前后很适合歇一个小时。饮食提示: 奥地利咖啡上面放奶油(乳制品)。花草茶不含咖啡因。
  • 寿砚山房 (Suyeon Sanbang / 수연산방) — 城北洞的韩屋传统茶馆。是小说家李泰俊住过的房子(尚虚李泰俊故居)。2026-10-23的博客评价(10月到访)写道，看着树木茂密的庭院享受了秋日情致。登记价是大枣双和茶15,500韩元、南瓜刨冰16,000韩元(2025-10-25登记)。价位偏高。时间是周三至周五11:30~17:50，周六·周日11:30~19:50，周一·周二休息。最后点单是周三至周五17:00，周六·周日19:00。地址是城北区 (Seongbuk-ro 26-gil 8 / 성북로26길 8)。同一篇评价里给出了路线。从汉城大入口站 (Hansung Univ. Station / 한성대입구역)(4号线)换乘1111·1112·2112路公交，在城北区立美术馆 (Seongbuk Museum of Art / 성북구립미술관)下车，步行不到5分钟。红叶季之外也值得去: 2026-06的Kakao地图评论称赞了南瓜刨冰和有历史的空间的韵味。饮食提示: 大枣双和茶里有大枣和松子(坚果)(Kakao地图AI摘要)。南瓜刨冰是牛奶刨冰上放红豆和年糕(Kakao地图AI摘要)。

③ 南山·首尔林 — 2家

南山西边后岩洞山坡上一家，圣水洞首尔林旁一家。Comfortable南山营业到22:00，Forest首尔林只有周五·周六营业到22:00。

  • Comfortable南山 (Comfortable Namsan / 콤포타블 남산) — 后岩洞大圆精舍别馆4层的咖啡馆。2026-11-21的博客评价写道，两侧的落地窗能俯瞰南山风景和街区。登记价是美式咖啡(M)4,500韩元、拿铁(M)5,000韩元、坚果奶油拿铁6,500韩元、宇治抹茶拿铁6,500韩元。每天10:00~22:00营业。地址是龙山区 (Duteobawi-ro 60-gil 49 4F / 두텁바위로60길 49 4층)。同一篇评价里给出了路线。从淑大入口站 (Sookmyung Women's Univ. Station / 숙대입구역)步行约25分钟，或者坐村庄巴士02路约10分钟，下车后步行7分钟。停车第1小时免费(Kakao地图AI摘要)。红叶季之外也值得去: 2026-11-12的Kakao地图评论写道，适合看夕阳。饮食提示: 意式浓缩马天尼(12,000韩元)是含酒的鸡尾酒。印度茶拿铁·奶茶·抹茶拿铁含牛奶。
  • Forest首尔林 (Forest Seoul Forest / 포레스트 서울숲) — 首尔林旁咖啡街的甜点咖啡馆。从地下1层到上面几层都在使用。2026-11-06的博客评价写道，有俯瞰首尔林公园的屋顶。菜单登记了，但一个价格都没有登记，所以要看店里的菜单。时间是周一至周四·周日10:00~21:00，周五10:00~22:00，周六11:00~22:00。地址是城东区 (Seoulsup 2-gil 20-12 / 서울숲2길 20-12)，最近的站是纛岛站 (Ttukseom Station / 뚝섬역)(2号线)8号出口，步行10分钟。不能停车。红叶季之外也值得去: 轮换推出应季水果甜点。Kakao地图菜单里有草莓刨冰等冬季限定菜单。饮食提示: 刨冰是牛奶冰(Kakao地图AI摘要)。可颂华夫饼是黄油·面粉面团。提拉米苏通常含马斯卡彭芝士和鸡蛋。

🗺 动线 — 两条半日路线

A. 从付岩洞下仁王山 (周二除外)

  1. 白天 从景福宫站3号出口坐7022路公交到"紫霞门隘口·尹东柱文学馆" (Jahamun Pass·Yun Dong-ju Literary Museum / 자하문고개.윤동주문학관)。步行去喜作 (Huijak / 희작)(11:00起)或山拐角 (Sanmotungi / 산모퉁이)(11:00起)
  2. 下午 回到尹东柱文学馆一侧，再去森林哨所书店 (Deosup Chosochaekbang / 더숲초소책방)。2026-11-20的博客写的是从尹东柱文学馆站点887m
  3. 日落前 在哨所书店看市区风景，走下去到水声洞溪谷站点(690m)，坐村庄巴士09路回景福宫站

周二喜作休息，就去山拐角 (Sanmotungi / 산모퉁이)。

B. 从北村到宗庙 (周二除外)

  1. 上午 山坡上的品茶庭院茶庭 (Chamasineun Tteul Chatteul / 차마시는뜰 차뜰)(10:00起)喝传统茶
  2. 下午 市厅站一带的阁楼咖啡馆 (Cafe Darak / 카페 다락)(平日13:30~17:30，周六·周日09:00~17:00)看德寿宫风景。和德寿宫参观串在一起
  3. 傍晚 钟路3街站一带的咖啡馆View (Cafe View / 카페뷰)(~23:00)看宗庙一侧的风景

公共假日贞洞展望台休息，去掉第2站。城北洞的寿砚山房 (Suyeon Sanbang / 수연산방)在周三至周日另外排半天。

⚠ 常见失误3个

  1. 不看星期几就去 — 茶庭 (Chatteul / 차뜰)和喜作 (Huijak / 희작)周二休息，寿砚山房 (Suyeon Sanbang / 수연산방)周一·周二休息。贞洞展望台公共假日不开放(首尔市官方)。
  2. 想从地铁站走过去 — 森林哨所书店 (Deosup Chosochaekbang / 더숲초소책방)、山拐角 (Sanmotungi / 산모퉁이)、喜作 (Huijak / 희작)、Comfortable南山 (Comfortable Namsan / 콤포타블 남산)都在山坡上。坐公交或村庄巴士过去再步行。穿防滑的运动鞋。
  3. 把红叶日期定死 — 红叶每年会前后移动几天。韩国气象厅常年值是30年平均。遇到雨或寒潮，几天就结束了。

⚙ 常见问题3个

  1. 红叶看得最清楚的时期是什么时候？ — 按韩国气象厅常年值，北汉山红叶10月15日前后开始，10月28日前后到最盛(1991~2020平均)。每年前后移动。
  2. 晚上能去的地方有哪些？ — 按登记时间，咖啡馆View (Cafe View / 카페뷰)营业到23:00，森林哨所书店 (Deosup Chosochaekbang / 더숲초소책방)和Comfortable南山 (Comfortable Namsan / 콤포타블 남산)营业到22:00。Forest首尔林 (Forest Seoul Forest / 포레스트 서울숲)周五·周六营业到22:00。
  3. 下雨天呢？ — 隔着落地玻璃看的阁楼咖啡馆 (Cafe Darak / 카페 다락)(德寿宫)、咖啡馆View (Cafe View / 카페뷰)(宗庙)、喜作 (Huijak / 희작)(仁王山)比较稳妥。
