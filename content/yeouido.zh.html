🎯 为什么汝矣岛 (Yeouido / 여의도) 要单独出指南？

汝矣岛 (Yeouido / 여의도) 是首尔 (Seoul / 서울) 永登浦区 (Yeongdeungpo-gu / 영등포구) 韩国金融·媒体第一区，也是外国游客的热门景点 — 国会 (Gukhoe / 국회)、KBS、MBC、金融公司总部、汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원)、63大厦 (63 Building / 63 빌딩)、首尔现代百货 (The Hyundai Seoul / 더현대 서울)、IFC购物中心 (IFC Mall / IFC몰) 集中在一片区域，堪称“首尔的曼哈顿”。在外国游客的行程中，汝矣岛 (Yeouido / 여의도) 可能会被明洞 (Myeongdong / 명동) 和江南 (Gangnam / 강남) 掩盖，但只有了解它的人才能在此邂逅春季轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃)、汉江夜景 (Hangang yagyeong / 한강 야경) 和高层景观餐厅。

与弘大 (Hongdae / 홍대) (MZ一代 (MZ)·独立文化)、江南 (Gangnam / 강남) (奢华·购物) 和梨泰院 (Itaewon / 이태원) (国际化) 相比，汝矣岛 (Yeouido / 여의도) 具有金融·都市·地标的特质。对于计划4-5天首尔 (Seoul / 서울) 之旅的外国游客来说，春季4月轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃) 季或傍晚汉江夜景 (Hangang yagyeong / 한강 야경) + E-Cruise游船 (E-Cruise / 이크루즈) 是首选行程。首尔现代百货 (The Hyundai Seoul / 더현대 서울) 和IFC购物中心 (IFC Mall / IFC몰) 也非常适合外国游客购物 + 即时退税。

继#138弘大 (Hongdae / 홍대)、#142江南 (Gangnam / 강남)、#144梨泰院 (Itaewon / 이태원) 和#156延禧洞 (Yeonhui-dong / 연희동) 之后，汝矣岛 (Yeouido / 여의도) 作为ISSUE 03第⑩篇加入 — 进入首尔“外国游客最想去的5大区域”系列。这也是KeyChinGu (키친구) 首次深入永登浦区 (Yeongdeungpo-gu / 영등포구)·汝矣岛 (Yeouido / 여의도)。

⚠ 外国游客常犯的3个错误

1. “明洞 (Myeongdong / 명동)·江南 (Gangnam / 강남) 是主要目的地” — 跳过汝矣岛 (Yeouido / 여의도)

这是外国游客行程中最常见的错误。汝矣岛 (Yeouido / 여의도) 被明洞 (Myeongdong / 명동)·江南 (Gangnam / 강남) 掩盖，常被误认为是“商业区”，但实际上，春季轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃) + 汉江夜景 (Hangang yagyeong / 한강 야경) + E-Cruise游船 (E-Cruise / 이크루즈) + 首尔现代百货 (The Hyundai Seoul / 더현대 서울) 等首尔 (Seoul / 서울) 5大热门景点都集中在此区域。特别是4月第一周至第二周的轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃)，每年都是韩国Instagram和外国游客Vlog上的#1热门景点。一条路线即可实现“白天赏樱 + 傍晚游船 + 夜晚现代百货” = 完美的1日游。

2. “汝矣岛 (Yeouido / 여의도) 午餐 = 上班族太多吃不到” — 未考虑避开11:30~13:30高峰期

汝矣岛 (Yeouido / 여의도) 的午餐时间高峰期是11:30~13:30 — Solsot (솔솥)·Neungrado (능라도)·伦敦贝果博物馆 (London Bagel Museum / 런던베이글뮤지엄) 等热门餐厅排队时间可能超过30分钟。建议外国游客下午14:00以后或晚上18:00以后 + 汉江 (Hangang / 한강) 散步路线。春季·秋季在汉江 (Hangang / 한강) 野餐 + 附近面包店外带是最佳选择。节假日·周末因上班族不在 → 任何时间都可以。

3. “汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원) = 只是汉江 (Hangang / 한강) 所以跳过”

汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한江公园) 是3个季节性热门景点汇聚的区域：

  • 春季4月: 轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃) 1.7公里 — 韩国·外国游客#1 Instagram热门景点
  • 夏季6~8月: 夜间汉江 (Hangang / 한강) + 绿光广场 (Pulbit Gwangjang / 풀빛광장) 夜市 + E-Cruise游船 (E-Cruise / 이크루즈)
  • 秋季10月: 首尔烟花节 (Seoul Fireworks Festival / 서울불꽃축제) (10月第一周，吸引100万外国游客)

外国游客可能不了解季节性特色而直接跳过 — 这是最值得与季节匹配的区域。

汝矣岛 (Yeouido / 여의도) 风景

汝矣岛 (Yeouido / 여의도) 是位于汉江 (Hangang / 한강) 中央的人工岛型行政区 — 1968年汉江 (Hangang / 한강) 填海造地后，被建设成为金融·媒体核心区域，目前国会 (Gukhoe / 국회)·KBS·MBC·SBS·金融公司总部·63大厦 (63 Building / 63 빌딩)·汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원) 集中于此，是首尔 (Seoul / 서울) 的“曼哈顿”第一区。

汝矣大路 (Yeouidae-ro / 여의대로) 是主干道 — 从国会 (Gukhoe / 국회) → 首尔现代百货 (The Hyundai Seoul / 더현대 서울) → IFC购物中心 (IFC Mall / IFC몰) → 63大厦 (63 Building / 63 빌딩) 一线。步行30~40分钟即可散步。地铁5号线汝矣岛站 (Yeouido Station / 여의도역)·汝矣渡口站 (Yeouinaru Station / 여의나루역) + 9号线鹭得路站 (Nodeul-ro Station / 노들로역)·国会议事堂站 (National Assembly Station / 국회의사당역) 4个地铁站覆盖该区域。

国际金融路 (Gukjegeumyung-ro / 국제금융로) 是IFC·金融大厦街 — 金融公司总部 + 外国游客餐厅 + 咖啡馆密集。平日午餐时间是上班族的热门区域。

汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원) 沿汉江 (Hangang / 한강) 1.7公里 — 轮中路樱花道 (Yunjung-ro beotkkot-gil / 윤중로 벚꽃길) + 汉江景观咖啡馆 + E-Cruise游船 (E-Cruise / 이크루즈) 售票处 + 自行车道。是春季樱花、夏季夜景、秋季烟花节的热门景点。

首尔现代百货 (The Hyundai Seoul / 더현대 서울) (2021年开业) 是韩国最大的百货公司·外国游客即时免税退税 + 伦敦贝果博物馆 (London Bagel Museum / 런던베이글뮤지엄) 贝果·众多餐饮店。IFC购物中心 (IFC Mall / IFC몰) 毗邻康莱德酒店 (Conrad Hotel / 콘래드 호텔) + 外国游客友好的餐饮品牌。

交通: 地铁5号线汝矣岛站 (Yeouido Station / 여의도역) (步行2分钟 - IFC购物中心 (IFC Mall / IFC몰)) 或汝矣渡口站 (Yeouinaru Station / 여의나루역) (汉江公园 (Hangang Park / 한강공원))。推荐使用Kakao Taxi (카카오 택시)。Ttareungi (따릉이) (首尔公共自行车) 租赁OK (汉江公园 (Hangang Park / 한강공원) 1.7公里路线)。

⚙ 常见问题 (8个)

Q1. 汝矣岛 (Yeouido / 여의도) 午餐什么时候去不用排队？

平日14:00以后或11:30以前。12:00~13:30是上班族午餐高峰，Solsot (솔솥)·伦敦贝果博物馆 (London Bagel Museum / 런던베이글뮤지엄)·Neungrado (능라도) 都需要排队30分钟~1小时。周末·节假日因上班族不在 → 任何时间都可以直接入座。

Q2. 轮中路樱花 (Yunjung-ro beotkkot / 윤중로 벚꽃) 季具体是什么时候？

每年4月第一周至第二周 (3月底~4月中旬之间会有变动)。务必提前确认首尔市 (Seoul City / 서울시) 官方“汝矣岛春花节 (Yeouido bomkkotchukje / 여의도 봄꽃축제)”日程。平日09:00~10:00或18:00以后人较少 — 周末白天人潮爆满。

Q3. 汉江公园 (Hangang Park / 한강공원) 怎么租自行车？

Ttareungi (따릉이) (首尔市 (Seoul City / 서울시) 公共自行车) 是标准选择 — 下载App + 外国游客信用卡注册OK。1小时1,000韩元 (₩)，汉江公园 (Hangang Park / 한강공원) 各处都有租赁点。或者汉江公园 (Hangang Park / 한강공원) 内的私人租赁点 (可租4~6人家庭自行车)。

Q4. E-Cruise游船 (E-Cruise / 이크루즈) 晚餐游船需要预约吗？

4月春花·10月烟花节期间需要提前1周预约。平时可以直接购票，但建议提前1个月在售票处预约。晚餐游船约90,000韩元 (₩) /人。

Q5. 首尔现代百货 (The Hyundai Seoul / 더현대 서울) 的即时免税退税怎么办理？

30,000韩元 (₩) 以上 + 外国人护照 + 带有Global Blue标志的店铺 = 结账时即时退税。向店员要求“Tax Free Refund”。免税柜台在B2层 (地下2层)。

Q6. 汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원) 可以吃炸鸡配啤酒吗？

可以 — 汉江公园 (Hangang Park / 한江公园) 内便利店·外卖App OK。但饮酒仅限指定区域 (市民公园内部分区域限制饮酒)。春季樱花·夏季夜景季节是韩国人的热门景点。推荐外国游客体验韩国外卖App (Baedal Minjok / 배달의민족)。

Q7. 汝矣岛站 (Yeouido Station / 여의도역)·汝矣渡口站 (Yeouinaru Station / 여의나루역)·63大厦 (63 Building / 63 빌딩) 路线怎么走？

5号线汝矣岛站 (Yeouido Station / 여의도역) (IFC购物中心 (IFC Mall / IFC몰)·国会 (Gukhoe / 국회)) → 5号线汝矣渡口站 (Yeouinaru Station / 여의나루역) (汉江公园 (Hangang Park / 한강공원)) → 9号线鹭得路站 (Nodeul-ro Station / 노들로역) (63大厦 (63 Building / 63 빌딩)) 一线。步行15~20分钟即可散步。汉江公园 (Hangang Park / 한강공원) Ttareungi (따릉이) (首尔公共自行车) 10分钟。

Q8. 外国游客友好的午餐餐厅有哪些？

首尔现代百货 (The Hyundai Seoul / 더현대 서울) 美食广场 + IFC购物中心 (IFC Mall / IFC몰) 餐厅 + Mad for Garlic (매드포갈릭)·Traga (트라가)·Rakhuian (락희안) = 英文菜单 + 信用卡支付 + 外国游客友好传统。Solsot (솔솥)·Neungrado (능라도) 等传统韩餐也提供英文菜单。
