외국인 전라도 1일 메타 가이드 — 전주·여수·순천·목포 4축

> 부제: 외국인 관광객용 전라도 4축 시그니처 12선 + 1일 풀데이 + 한국 #1 한식 본가 + 외국인 영문

ISSUE 04 · #1046 · 2026-06-08

🎯 왜 전라도 가이드인가

전라도 (Jeolla-do) = 한국 #1 한식 본가 (광주·전주)·#1 자연 도·전주 한옥마을 (한국 #1·800+ 한옥)·여수 (해상케이블카·밤바다)·순천 (순천만 한국 #1 국가정원)·목포 (유달산·근대문화). 외국인 페인포인트 = (a) "전라도 = 안 알려짐" 잘못된 인식 (b) 전주 = 한국 #1 한옥마을·비빔밥 본가 (c) 여수 = 밤바다 + 해상케이블카 매트릭스 (d) 순천 = 순천만 한국 #1 국가정원 (2015 지정) (e) 목포 = 유달산·근대문화거리·홍어 시그너.

본 가이드는 4축 12 시그니처 + 1일 풀데이 + 한국 #1 한식 본가 + 외국인 영문.

★ 한눈에 4축 12 시그니처

# 매장·동선 4축 시그니처
1 전주 한옥마을 (한국 #1·800+ 한옥) ① 전주 한국 #1 한옥마을
2 전주 + 비빔밥·한정식 ① 전주 비빔밥 본가·한국 #1 한식
3 전주 + 한복 대여 + 인스타 ① 전주 MZ + 인스타 매트릭스
4 여수 해상케이블카 (1.5km) ② 여수 한국 #1 해상케이블카
5 여수 밤바다 ② 여수 야경 매트릭스 #1
6 여수 + 향일암 + 회·해산물 ② 여수 일출 + 회
7 순천만 국가정원 (한국 #1) ③ 순천 2015·92만m²
8 순천만 습지 + 갈대밭 ③ 순천 가을 갈대 매트릭스
9 순천 + 낙안읍성 (조선) ③ 순천 조선 읍성 매트릭스
10 목포 유달산 + 근대문화 ④ 목포 일제 + 근대사 매트릭스
11 목포 + 홍어 (한국 #1 시그너) ④ 목포 홍어 매니아 매트릭스
12 목포 + 갓바위 + 1박 ④ 목포 매니아 풀세트

> 외국인 1순위: 전주 + 여수 + 순천 = 1박 권장

> 매니아: 목포 홍어 + 1박 풀세트

🏛 4축 deep dive

① 전주 (한국 #1 한옥마을)

  • 시그니처: 한국 #1 한옥마을 (800+ 한옥)·비빔밥 본가·한국 #1 한식 매니아 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문 풀세트·MZ + 가족·인스타)

② 여수 (해상케이블카 + 밤바다)

  • 시그니처: 한국 #1 해상케이블카 (1.5km)·여수 밤바다 야경 매트릭스 #1·향일암 일출
  • 외국인 친화도: ★★★★★ (영문·MZ + 매니아)

③ 순천 (한국 #1 국가정원)

  • 시그니처: 2015 한국 #1 국가정원·92만m²·순천만 습지·낙안읍성 조선
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족)

④ 목포 (유달산 + 근대 + 홍어)

  • 시그니처: 유달산·근대문화거리·홍어 한국 #1 시그너 매트릭스
  • 외국인 친화도: ★★★ (홍어 호불호·매니아)

⚠ 외국인 자주 실수 5가지

1. "전라도 = 안 알려짐": 한국 #1 한식 본가·전주·여수·순천·목포 매트릭스.

2. "전주 한옥마을 = 작은 마을": 한국 #1·800+ 한옥·비빔밥 본가.

3. "여수 케이블카 = 일반 케이블카": 한국 #1 해상케이블카 1.5km·밤바다 매트릭스 #1.

4. "순천만 = 일반 정원": 한국 #1 국가정원 2015·92만m².

5. "목포 홍어 = 외국인 X": 한국 #1 시그너·매니아 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 전주 한옥마을 + 비빔밥 + 여수 케이블카 = 1일.

2. 전주 비빔밥: 한국 #1 본가·비빔밥 + 한정식 + 콩나물국밥 매트릭스.

3. 여수 밤바다: 야경 매트릭스 #1·MZ + 인스타.

4. 순천만 시즌: 가을 (10-11월 갈대 매트릭스 #1)·연중 OK.

5. 시즌: 봄·가을 베스트·여름·겨울.

6. 추천 페르소나: 가족·시니어 = 전주 + 순천 / MZ·인스타 = 전주 + 여수 / 매니아 = 목포 홍어 + 1박.

⚠ 의료·안전·식이 disclaimer

전라도 = 안전·외국인 친화. 홍어 = 호불호·강한 냄새·외국인 매니아 매트릭스. 응급 ☎ 1339·1330.

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (KTX/항공 + 시내 핵심 4축 풀세트)
  • 예산: 100,000~180,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)·400,000~800,000원/4인 (1박)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
