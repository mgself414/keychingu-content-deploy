⚠ 외국인 자주 실수 5가지

1. "김치 = 1 종류": 김치 = 12 종류 이상 (배추·깍두기·물김치·백김치·갓김치 etc.) + 지역별 특색 + 계절별 김치 + 외국인 매니아 1번지.

2. "김치 = 너무 매움": 매운맛 X = 백김치 + 물김치·동치미 + 외국인 어린이·환자식 + #502·#400 통합. 매니아면 갓김치·전라도 김치.

3. "고추장 = 매운맛만": 고추장 = 단맛 + 매운맛 + 깊은맛 + 비빔밥·떡볶이·삼겹살 페어링 + UNESCO + 외국인 매니아 #1.

4. "김장 = 외국인 못 함": 김장 체험 = 11월 외국인 영어 OK + 서울·전라도 워크숍 + UNESCO 인류무형문화유산 + 외국인 1순위 + #502 통합.

5. "발효 = 김치만": 발효 = 김치 + 장 (고추장·된장·간장) + 젓갈 + 식초 + 전통 양조장 + 한식 80% 기반 + 외국인 매니아.
