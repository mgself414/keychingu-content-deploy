🎯 なぜブランドで読むのか

韓国のコンビニ・スーパーのお菓子棚は、5大製菓メーカー(農心・オリオン・ロッテウェルフード (롯데웰푸드)・ヘテ・クラウン)が事実上寡占する構造。商品を一つずつ覚えるより、ブランドロゴ5つを読むほうがはるかに早い — ブランドごとに持ち味(ポテトチップスの名門・チョコの名門・元祖の物語)が違うからだ。既存のコンビニクラスター(#26 入門18選・#1261 4社比較・#1262 カテゴリー総まとめ)が「どこで何を買うか」だったのに対し、本編は「誰が作り、なぜヒットしたか」 — 袋の裏の製造元まで読むマニア軸。

⚠️ データ注意: シーズン限定・コラボ新商品は寿命が短い — 個別商品の販売有無・価格は訪問時点の棚基準。クラシック15選は数十年のロングセラーなのでいつでも買える。

⚠ 外国人がよくやる勘違い3つ

1. 「チョコパイは全部同じ会社」: 韓国にはオリオンのチョコパイ情とロッテのチョコパイという2つの系譜が別々に存在 — 元祖の物語はオリオン(1974)。ベトナム・ロシア・中国で国民的おやつになったのもオリオンのライン。ギフト用なら箱の「情」ロゴを確認。

2. 「ペペロ = ポッキー」: 形は似ているが、ペペロは11月11日「ペペロデー」という国民的記念日を作った韓国の文化現象 — その日はコンビニ棚の半分がペペロのギフトボックスに変わる。アーモンド・クランキーなど韓国限定ラインナップもより多彩。

3. 「コンビニ定価が標準」: 同じお菓子でも大型スーパー・ダイソー (다이소)が20~30%安い。バラの味見はコンビニ(1+1キャンペーンをチェック)、お土産ボックスのまとめ買いはスーパー・ダイソーが正解。#48 必須購入・#579 スーパー地図参照。

① 農心 (Nongshim) — スナックの元祖名門

1. セウカン (Saeukkang) ★ 韓国初のスナック

  • 1971年発売 — 韓国スナック史の出発点。生エビをすり込んだ香ばしくて塩気のある味わい
  • ヒットの理由: 「ソニガヨ ソニガ (손이 가요 손이 가)」のCMソングを全国民が歌える — カモメへのセウカン餌やり(漢江 (한강)・仁川 (인천)フェリー)で観光ミームにまで拡張
  • バリエーション: メウンセウカン (매운새우깡)・サルセウカン (쌀새우깡) — 元祖の赤い袋がデフォルト

2. バナナキック (Banana Kick)

  • ふんわり溶けるバナナ味コーンスナック — バナナ味牛乳(#1262)と並ぶ「韓国バナナ味」アイコンペア
  • ヒットの理由: 子供時代のノスタルジー刺激 + 牛乳ペアの作法

3. クルクァベギ (Kkul Kkwabaegi)

  • アカシア蜂蜜をまとったツイスト型スナック — 甘じょっぱさの教科書
  • ヒント: 農心 = 辛ラーメン (신라면)のあの会社。ラーメンのdeep diveは#833 ラーメンペアリング編へ

② オリオン (Orion) — チョコパイ情とグローバル逆輸入

4. チョコパイ情 (Choco Pie) ★ 国民的おやつの伝説

  • 1974年発売 — マシュマロサンドのチョコケーキ。「情(ジョン)」の一文字マーケティングで韓国人の分かち合いの情緒を象徴
  • ヒットの理由: 軍隊で通貨のように流通するというミーム + ベトナムの祭壇・ロシアの国民的おやつになった輸出神話
  • ギフトの作法: 箱ごと買って配るお菓子 — 個包装なのでスーツケースでも安全

5. コブクチップ (Kkobuk Chip / Turtle Chips) ★ 海外逆輸入の代表

  • 4層レイヤー食感のコーンチップ — 特にチョコチュロス味がアメリカのコストコ・アマゾンで逆輸入の話題に
  • ヒットの理由: 「層ごとに砕ける食感」チャレンジ動画 + 海外セレブの言及 — いま外国人の買い物カゴ1位のお菓子
  • ヒント: オリジナル(コーンスープ味)とチョコチュロスの2袋比較が定石

6. ポカチップ (Poca Chip)

  • 韓国ポテトチップス売上1位のロングセラー — 薄くて淡白なオリジナル・オニオン味
  • ヒットの理由: 派手ではないが「失敗しないデフォルト」ポジション — ビールのお供(#843 夜食の作法)

③ ロッテウェルフード (Lotte Wellfood) — 記念日を作ったブランド

7. ペペロ (Pepero) ★ お菓子が作った国民的記念日

  • 1983年発売のチョコスティック — 11月11日ペペロデー(数字の1が4つ = スティック4本)の主人公
  • ヒットの理由: 恋人・友達・同僚同士で贈り合うシーズン文化に昇格 — 11月初旬はコンビニ・スーパーがペペロ特設棚に変身
  • ラインナップ: オリジナル・アーモンド・クランキー・ヌード(チョコ入り) — ギフトボックスセットはシーズン限定

8. コッカルコーン (Kkokkal Corn)

  • 三角帽子型のコーンスナック — 指10本にはめて食べる国民的作法がSNS投稿フォーマット
  • ヒットの理由: 遊び+お菓子の融合の元祖 — 子供も外国人もみんな夢中に

9. チクチョク (Chic Choc)

  • しっとりソフトなチョコチップクッキー — コーヒーのお供のロングセラー
  • ヒント: ロッテはガーナチョコレート (가나초콜릿)・ワールドコーン (월드콘)(#1265 アイス)までポートフォリオが最も広い総合製菓

④ ヘテ (Haitai) — シンドローム製造機

10. ハニーバターチップ (Honey Butter Chip) ★ 2014品切れシンドローム

  • ポテトチップスに蜂蜜+バターの甘じょっぱいコーティング — 2014年発売直後、全国品切れ・中古プレミア取引・1人1袋制限まで起きた韓国お菓子史最大のシンドローム
  • ヒットの理由: 「手に入らないからこそ気になる」希少性マーケティングの教科書事例 — 今はどこでも買えるので、その物語を知って食べると二倍楽しい
  • ヒント: 類似の後続商品(ハニーバターシリーズ全般)の元祖がこの袋

11. ホームランボール (Home Run Ball)

  • 一口シューの中にチョコクリーム — 世代を問わずパーティー・集まりの1位
  • ヒットの理由: 気軽な甘さ + シェアの作法 — カフェデザートの代わりにも

12. マッドンサン (Matdongsan)

  • 1975年発売のピーナッツ揚げ菓子 — 「マッドンサン食べて楽しいパーティー」CMソングのロングセラー
  • ヒットの理由: 韓菓(ヤックァ (약과))と洋菓子の中間の味わい — 伝統おやつ入門の架け橋 (#1218 ヤックァトレンドとペア)

⑤ クラウン (Crown) — レトロ感性の名門

13. ジョリポン (Jolly Pong)

  • 小麦ポン菓子のシリアル型お菓子 — 牛乳に浸して食べる韓国式シリアルの元祖
  • ヒットの理由: カフェがジョリポンラテ・かき氷トッピングで再召喚 — レトロデザートトレンドの定番素材

14. コンチプ (Corn Chip)

  • 1970年代生まれの韓国式コーンチップの元祖 — 香ばしくて固いトウモロコシの味わい
  • ヒットの理由: ビールのつまみのロングセラー + 「元祖論争」の主人公

15. ビッグパイ (Big Pie)

  • いちごジャムサンドパイ — 文房具屋前の思い出の代表
  • ヒットの理由: レトロパッケージそのまま — ニュートロ感性の映えショット小物

🔥 いま来ている流れ — 2026トレンド4

1. ドバイチョコレート派生: カダイフ+ピスタチオの文法がチョコレートを超えてクッキー・パイ・スナックへ拡散 — 5大ブランドすべてが派生ライン実験中。棚で「ピスタチオ」の文字を見たらその系列。

2. チキン・外食ブランドコラボチップス: 実際のチキンメニューの味を再現したコラボポテトチップス系 — コンビニ限定発売が多く、コンビニ棚が1次ハンティング場。

3. 輸出逆輸入: コブクチップのチョコチュロス・ペペロ・チョコパイが海外で先に話題 → 韓国旅行で「本場バージョン」を買う作法が定着。

4. ゼロ・低糖ライン: ゼロキャンディ・低糖チョコなど健康軸の拡張 — 糖分が気になる旅行者の代替軸。

⚙ FAQ 6つ

1. どこで買うのが一番安い?: 大型スーパー(イーマート (이마트)・ホームプラス (홈플러스)) > ダイソー > コンビニの順に安い。コンビニは1+1・2+1キャンペーンを狙えば逆転 (#1261)。

2. スーツケースの容量問題: 袋菓子は体積の割に軽くて割れやすい — 箱型(チョコパイ・ペペロ・ホームランボール)が運搬安全。袋型は機内持ち込みバッグへ。

3. ハラール・ヴィーガンは可能?: 韓国のお菓子はほとんどハラール認証なし — 成分表の豚由来ゼラチン・乳製品の確認が必要。セウカンはエビ(甲殻類)含有。

4. シーズン限定はいつ?: 11月ペペロデー(最大シーズン)・夏のアイスペア・名節ギフトボックスシーズン(1~2月・9月)。

5. ギフトボックスのおすすめ組み合わせ: チョコパイ1箱 + ペペロ3種 + コブクチップチョコチュロス + ハニーバターチップ + ジョリポン = 約2万ウォン台の「K-スナックブランドサンプラー」。

6. 製造元はどう確認?: 袋の裏面下部の製造元表記 — ロゴを覚えるだけで棚でブランドの系統が見えてくる。

🗺 実購入コース3つ

A. スーパーお土産ボックス (1時間)

  • 大型スーパーのお菓子コーナー → ブランド別シグネチャー1つずつ15選をスキャン → 箱型中心にカゴへ → 会計前にキャンペーンシール確認 (#579 スーパー地図)

B. コンビニブランドビンゴ (30分)

  • コンビニ1軒で5大ブランド各1つずつ選んで5マスビンゴ完成 — バラで味見・夜食ペア (#26・#1262)

C. ダイソー+スーパーコスパコンボ (半日)

  • ダイソーのお菓子コーナー(小分け・低価格) → スーパーの大容量 → ホテルで試食会 — 味を検証してから帰国直前に空港近くのスーパーで最終ボックス

🌸 シーズン5

11月ペペロデー特設棚 (年間最大) / ソルラル・チュソクのギフトボックスシーズン / 夏のチョコ類は溶け注意 (機内持ち込み推奨) / 春・秋はコラボ新商品の集中発売 / 年末パーティーシーズンはホームランボール・コッカルコーン大容量
