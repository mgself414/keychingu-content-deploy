📍 首尔·果川 — 首尔书法博物馆·秋史博物馆

首尔书法博物馆 (Seoul Seoye Bangmulgwan / 서울서예박물관)位于瑞草区 (Nambusunhwan-ro 2406 / 남부순환로 2406) 艺术殿堂 (Yesurui Jeondang / 예술의전당)内，☎ 0507-1382-1656。它是1988年与艺术殿堂音乐厅同时开馆的书法展览场馆，2002年3月成为书法专门博物馆。收藏《槿域书画史 (Geunyeok Seohwasa / 근역서화사)》等近现代书画史资料和东亚现代书法作品1,300余件。除1988年开始的韩国书法史特别展 (Hanguk Seoyesa Teukbyeoljeon / 한국서예사특별전)外，书法·书画展览一直持续举办。

  • 开放时间:10:00~19:00。休息日:每周一。
  • 费用:视展览而定。

秋史博物馆 (Chusa Bangmulgwan / 추사박물관)位于果川市 (Chusa-ro 78 / 추사로 78)，☎ 02-2150-3650。这里是研究·展示·体验朝鲜 (Joseon / 조선)后期学者秋史金正喜 (Chusa Gim Jeong-hui / 추사 김정희)的生平、学问与艺术的博物馆，2013年6月3日开馆。常设展厅共3处: 2层为秋史的生平，1层为秋史的学艺，地下1层为捐赠室 (Fujitsuka Gijeungsil / 후지쓰카 기증실)。地下1层设有企划展厅、常设体验室、儿童图书馆和博物馆商店，户外有复原的 Dok-umul 古井 (Dok-umul / 독우물)、瓜地草堂 (Gwajichodang / 과지초당)和秋史广场 (Chusa Madang / 추사마당)。每年举办1~2次特别企划展。

  • 开放时间:09:00~18:00(入场截止 17:00)。休息日:每周一(周一为公休日则顺延至次日)，1月1日，春节·中秋节假期，果川市市长 (Gwacheon-si Sijang / 과천시장) 指定的休馆日。
  • 费用:个人成人2,000韩元，初中·高中生·军人1,000韩元，小学生500韩元。20人以上团体成人1,000韩元，初中·高中生·军人500韩元，小学生300韩元。6岁以下·65岁以上免费。

📍 地方书艺馆 — 全州Gangam·麟蹄如初·天安Chwimukheon·礼山碑林

Gangam书艺馆 (Gangam Seoyegwan / 강암서예관)位于全州市 (Wansan-gu Jeonjucheon-dong-ro 74 / 완산구 전주천동로 74)，☎ 063-285-7442。这是一座书法专门博物馆，由书法家 (Song Seong-yong / 송성용)怀着把一生收集的藏品和财产回馈社会的心愿而开馆。收藏书画、书籍、文房四宝 (Munbang Sau / 문방사우)等1,300余件，位于全州韩屋村 (Jeonju Hanok Maeul / 전주 한옥마을)。建筑为地下1层、地上2层。

  • 开放时间:09:00~18:00。休息日:每周日，春节·中秋节当天。
  • 费用:免费。停车:免费。

如初书艺馆 (Yeocho Seoyegwan / 여초서예관)位于麟蹄郡 (Bukmyeon Manhae-ro 154 / 북면 만해로 154)，☎ 033-461-4081。这是纪念书法家如初金膺显 (Yeocho Gim Eung-hyeon / 여초 김응현)的书法专门博物馆，位于麟蹄郡北面龙垈里 (Bukmyeon Yongdae-ri / 북면 용대리)。据观光公社介绍，这是韩国全国最大规模的书法专门博物馆。收藏金膺显的作品和遗物、韩国国内外书法资料、书籍等6千余件。建筑师 (Lee Seong-kwan / 이성관)把周围的松林引入设计，用底层架空 (Pilloti / 필로티)把展示设施抬高一层，并保留原本流经此地的溪水建成池塘。

  • 开放时间:09:00~18:00(入场截止 17:30)。休息日:每周一，1月1日，春节·中秋节当天。
  • 费用:免费。停车:免费。

Chwimukheon书艺馆 (Chwimukheon Seoyegwan / 취묵헌서예관)位于天安市 (Dongnam-gu Mokcheon-eup Jonghap-hyuyangji 1-gil 3 / 동남구 목천읍 종합휴양지1길 3)，☎ 文化政策组 (Munhwa Jeongchaektim / 문화정책팀) 041-521-5167。这是改建天安综合休养观光园区管理事务所 (Cheonan Jonghap Hyuyang Gwangwang Danji Gwalli Samuso / 천안종합휴양관광단지 관리사무소) 的建筑而开馆的书艺馆。展示出生于忠南牙山 (Chungnam Asan / 충남 아산)、从事创作约50年的书法家 (In Yeong-seon / 인영선) 的书法、档案和影像。

  • 开放时间:10:00~18:00(入场截止 17:30)。休息日:每周一(周一为公休日则顺延至次日)，1月1日，春节·中秋节当天。展览筹备期间临时休馆。
  • 费用:免费。停车:免费。

韩国书艺碑林博物馆 (Hanguk Seoye Birim Bangmulgwan / 한국서예비림박물관)位于礼山郡 (Sinyang-myeon Nokmunbaksalmi-gil 7 / 신양면 녹문박살미길 7)，☎ 0507-1414-8610。这里展示近现代书画家的书法和四君子 (Sagunja / 사군자)，以阴刻·阳刻镌刻在石头上的作品700余件。可以欣赏篆书 (Jeonseo / 전서)、隶书 (Yeseo / 예서)、楷书 (Haeseo / 해서)、行书 (Haengseo / 행서)、草书 (Choseo / 초서)和韩文书法 (Hangeul Seoye / 한글 서예)作品。

  • 开放时间:09:30~17:00。休息日:全年无休。
  • 费用:免费。

📍 春川·济州 — 毛笔故事博物馆·济州秋史馆

毛笔故事博物馆 (Butiyagi Bangmulgwan / 붓이야기박물관)位于春川市 (Seo-myeon Baksa-ro 906 / 서면 박사로 906)，☎ 033-255-0580。这是为推广传统毛笔而于2017年建成的毛笔博物馆。据观光公社介绍，这是韩国国内唯一的毛笔专门博物馆。这里展示江原特别自治道 (Gangwon Teukbyeol Jachido / 강원특별자치도) 非物质遗产春川笔匠 (Chuncheon Piljang / 춘천필장) 传承人、馆长 (Bak Gyeong-su / 박경수) 和多位作家的作品。在1层可以观看一支毛笔要经过工匠之手100多次的制作过程，在2层可以体验制作书法作品和制作专属于自己的毛笔。在毛笔工坊 (But Gongbang / 붓 공방)可以看到工匠制作毛笔的样子。

  • 开放时间:10:00~18:00(入场截止 17:30)。休息日:每周一，春节·中秋节当天。
  • 费用:免费。参观时间:约1小时。停车:免费。

济州秋史馆 (Jeju Chusagwan / 제주추사관)位于西归浦市 (Daejeong-eup Chusa-ro 44 / 대정읍 추사로 44)，☎ 064-710-6865。这是为纪念秋史金正喜 (Chusa Gim Jeong-hui / 추사 김정희)的生平、学问与艺术，于2010年12月建成的展馆。2007年10月秋史流放地 (Chusa Yubaeji / 추사유배지) 成为国家指定遗产后，重建了1984年建成的秋史遗物展示馆 (Chusa Yumul Jeonsigwan / 추사유물전시관)。设有秋史纪念厅 (Chusa Ginyeomhol / 추사기념홀)、展厅3处和教育室，展示「礼山金正喜宗家遗物一括 (Yesan Gim Jeong-hui Jongga Yumul Ilgwal / 예산김정희종가유물일괄)」、秋史匾额书法和秋史书信书法。

  • 开放时间:09:00~18:00(入场截止 17:30)。休息日:每周一(周一为公休日则顺延至之后第一个非公休日)，1月1日，春节·中秋节当天。
  • 费用:免费。

  2. 登记了费用的地方是秋史博物馆 — 成人2,000韩元，首尔书法博物馆视展览而定。其余6处免费。

⚙ FAQ 2

Q. 在哪里可以制作毛笔或体验书法?

A. 按观光公社登记信息，在春川毛笔故事博物馆 (Chuncheon Butiyagi Bangmulgwan / 춘천 붓이야기박물관) 2层可以体验制作书法作品和制作专属于自己的毛笔(免费入场，周一休馆)。果川秋史博物馆 (Gwacheon Chusa Bangmulgwan / 과천 추사박물관) 设有常设体验室。

Q. 首尔和果川有哪些书法博物馆?

A. 瑞草区艺术殿堂 (Yesurui Jeondang / 예술의전당) 内的首尔书法博物馆 (Seoul Seoye Bangmulgwan / 서울서예박물관)(10:00~19:00，周一休馆)和果川秋史博物馆 (Gwacheon Chusa Bangmulgwan / 과천 추사박물관)(09:00~18:00，周一休馆)。
