丽水指南——夜海浪漫布帐马车街·梧桐岛·丽水水族馆·向日庵，2026官方信息（岛屿博览会 9/5~11/4 举办中）

副标题：梧桐岛免费·山茶花小火车 1,000韩元 / 丽水水族馆 09:30~19:00·成人 37,900韩元 / 浪漫布帐马车街 18:00~01:00·每月第一个周三休息 / 哈梅尔灯塔免费 / 海上缆车官方网站无法访问，票价未核实 / 镇南馆 2025年5月重新开放——以2026-10-08丽水市文化观光及运营方官方页面为准

🎯 本指南使用方法

丽水的主角是夜晚——突山大桥的灯光、龟船大桥下的浪漫布帐马车街、海面上的缆车。白天去梧桐岛的山茶花林和丽水水族馆，再远一点就是向日庵。下面的时间·票价·地址，只写了2026-10-08在丽水市文化观光页面和丽水水族馆官方网站上读到的数值。海上缆车官方网站因证书错误打不开，所以不写票价和时间（不收录二手来源的数字）。现在正值丽水世界岛屿博览会2026 (2026 Yeosu Segye Seom Bangnamhoe / 2026 여수세계섬박람회)（9/5~11/4），住宿和交通比平时更拥挤。旧版指南里“韩国第一夜海”“访韩外国人5%+”“人均8万~50万韩元”之类的数字，以及2012年世博会设施介绍，因没有出处或目前是否运营无法确认，已删除。

🌃 夜晚——浪漫布帐马车街·哈梅尔灯塔·突山大桥

  • 浪漫布帐马车街 (Nangman Pocha Geori / 낭만포차 거리)（哈梅尔路102号）：位于龟船大桥 (Geobukseon Daegyo / 거북선대교) 下，布帐马车18家，18:00~01:00，可刷卡（丽水市官方）。每月第一个周三休息——但4~6月·8~10月和连休假期不休息。恶劣天气停业。二手来源所说的“冬季17~24点”与官方不符，故不收录。
  • 哈梅尔灯塔 (Hamel Deungdae / 하멜등대)（哈梅尔路96号）：免费，全年开放。从布帐马车街步行即可。
  • 突山大桥 (Dolsan Daegyo / 돌산대교)：夜间灯光约50色（官方）。点灯时间未公布。

🌳 白天——梧桐岛·丽水水族馆

  • 梧桐岛 (Odongdo / 오동도)：免费，户外24小时。从停车场沿防波堤步行约15分钟，或乘山茶花小火车单程1,000韩元（3~10月 09:30~18:00·11~2月 ~17:00，12~13点休息）。从市区开车约10分钟（官方）。从丽水世博站 (Yeosu Expo / 여수엑스포역) 步行所需时间，官方未公布。
  • 丽水水族馆 (Aqua Planet Yeosu / 아쿠아플라넷 여수)（梧桐岛路61-11号）：每天 09:30~19:00，售票截止18:00，全年无休。成人37,900·青少年/老人34,900·儿童32,900韩元（官方）。

🚡 缆车·镇南馆·向日庵——没能核实的内容

  • 丽水海上缆车 (Yeosu Haesang Cable Car / 여수해상케이블카)：突山公园 (Dolsan Gongwon / 돌산공원) ↔ 紫山公园 (Jasan Gongwon / 자산공원) 1.5km，车厢50台（普通35·水晶15）这些内容为丽水市官方信息。运营方网站打不开，时间·票价·休息日未核实——请到现场售票处或打电话向运营方确认。
  • 镇南馆 (Jinnamgwan / 진남관)（国宝第304号，东门路11号）：修缮后2025-05-30重新开放来自新闻报道。时间·票价官方未公布。
  • 向日庵 (Hyangilam / 향일암)：突山南端的日出寺庙。市内公交111·111-1·116（官方）。时间·票价未公布。

🏝 丽水世界岛屿博览会2026——9/5~11/4

  • 官方日程为2026-09-05~11-04（丽水市）。这段时间请先订好住宿，周末的布帐马车街要做好排队的准备。

🚄 交通

  • KTX 龙山站 (Yongsan / 용산역) → 丽水世博站 (Yeosu Expo / 여수엑스포역)（不是首尔站）。所需时间·票价因打不开韩国铁路公社官方页面而未写（二手来源约3小时）。
  • 丽水机场·巨文岛·白岛这次没能打开官方页面，故省略。
  • 旅游咨询电话 1330（24小时，韩·英·日语）。

⚠ 常见的5个失误

1. 第一个周三晚上去布帐马车街——休息（4~6月·8~10月·连休假期除外）。

2. 相信博客上的缆车票价——官方未核实，请到现场确认。

3. 在首尔站找KTX——从龙山站出发。

4. 博览会期间当天找住宿——9/5~11/4请提前预订。

5. 开车进梧桐岛——只能开到停车场。步行15分钟或乘山茶花小火车。

⚙ FAQ 6

1. 一天怎么玩？——下午梧桐岛（免费）→ 丽水水族馆 → 晚上浪漫布帐马车街 → 哈梅尔灯塔·突山大桥夜景。

2. 布帐马车几点营业？——18:00~01:00。

3. 丽水水族馆多少钱？——成人37,900韩元，18:00停止售票。

4. 缆车呢？——突山↔紫山 1.5km。票价·时间官方未核实。

5. 怎么去向日庵？——市内公交111·111-1·116。

6. 需要外语帮助怎么办？——1330（24小时韩·英·日语）。
