한국 회 주문·시장·횟집·매운탕 워크플로우 — 자갈치부터 노량진까지

> 부제: 외국인 관광객용 5-step 워크플로우 + 시장·횟집·매운탕 코스·영어 발화

ISSUE 03 · #865 · 2026-06-09

🎯 왜 한국 회 워크플로우 가이드인가

[#864 회 6종 매트릭스](#864) 알아도 — 주문·시장·횟집·매운탕은 별개. 한국 회는 (a) 시장 정통 (노량진·자갈치·통영·소래포구 즉살 활어) (b) 횟집 (강남·홍대·이태원 정통 한 상) (c) 참치·연어 무한리필 (MZ 가성비) (d) 한정식 회 코스 (정통). 외국인은 (1) 시장 1층 (회판) vs 2층 (식당) 구분 모름 (2) 초장 vs 와사비 매너 모름 (3) 매운탕 코스 = 마지막 모름 (4) 활어 가격 협상 모름. 본 가이드는 5-step + 시장·횟집 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 시장 / 횟집 / 무한리필 / 한정식 즉시 가성비·정통·MZ·럭셔리 목적
2️⃣ 메뉴 주문 활어 1kg / 1관 (2~3인) / 1인분 5~15분 시장 = kg 단위
3️⃣ 받기·세팅 회 + 초장·쌈채소·마늘·매운탕 (옵션) 10~20분 초장·쌈 매너
4️⃣ 먹기·페어 초장 + 쌈 + 소주·맥주 30~90분 매운탕 = 마지막 코스
5️⃣ 결제 카드 OK / 시장 = 현금 일부 / 팁 X 1~5분 시장 = 가격 협상 가능

> 총 소요 시간: 시장 = 1~2h / 횟집 = 1.5~3h / 무한리필 = 1~2h / 한정식 = 2~3h

🐟 채널별 워크플로우

Type A — 시장 (노량진·자갈치·통영·소래포구·구룡포)

  • 시그니처: 활어 즉살 정통·가성비·1층 회판 + 2층 식당
  • 시간대: 시장별 (노량진 = 새벽 도매·일반 09:00~22:00)
  • 가격: 활어 1kg = 20,000~60,000원 + 식당 차림비 5,000~15,000원/인
  • 메뉴: 활어 1kg (광어·방어·도미·전어 등) + 쌈채소·매운탕
  • 외국인 친화도: ★★★★★ (영문 메뉴·관광객 친화)
  • 노량진: ([#587](#587)) — 새벽 도매·일반 식당
  • 자갈치: ([#590](#590)) — 부산 #1·방어 정통

Type B — 횟집 (강남·홍대·이태원)

  • 시그니처: 정통 한 상·중급 가격대
  • 시간대: 17:00~24:00
  • 가격: 50,000~150,000원/1인 (정통 한 상)
  • 메뉴: 회 + 초장 + 쌈채소 + 매운탕 + 술
  • 외국인 친화도: ★★★★ (영문 메뉴)

Type C — 참치·연어 무한리필 (MZ·가성비)

  • 시그니처: MZ 인스타·가성비 #1·홍대·강남·신촌
  • 시간대: 11:30~24:00
  • 가격: 25,000~50,000원/1인
  • 메뉴: 참치 toro·붉은살 / 연어 회 + 쌈채소·우동·매운탕
  • 외국인 친화도: ★★★★★ (글로벌 MZ #1)

Type D — 한정식 회 코스 (정통)

  • 시그니처: 한정식 6단계 1~2단계 ([#837](#837))·정통 럭셔리
  • 시간대: 11:30~22:00
  • 가격: 한정식 코스 40,000~150,000원
  • 메뉴: 회 (도미·광어) + 코스
  • 외국인 친화도: ★★★★

🌶 초장 vs 와사비·쌈·매운탕 매너

초장 (Chojang·고추장)

  • 구성: 고추장 + 식초 + 설탕
  • 용도: 활어 정통 회·한국식
  • 외국인: "Spicy red sauce"·매콤·달콤

와사비 (Wasabi)

  • 용도: 참치·연어·숙성 회·일본식
  • 외국인: "Japanese horseradish"·연하게

쌈 싸 먹기 (활어 회 정통)

1. 쌈채소 (상추·깻잎·배추) 손바닥 위

2. 회 + 마늘 + 초장 + 된장 (선택)

3. 손으로 싸서 한입에

4. 입 다물고 씹기 (한국 매너)

매운탕 (Mae-untang) 마지막 코스

  • 순서: 회 → 매운탕 (마지막)
  • 재료: 회 손질 부산물 + 매콤 양념 + 두부·콩나물
  • 외국인: "Spicy fish stew finale"·정통

🌶 외국인 영어 발화 샘플

  • "활어 광어 1kg" = "1kg of live olive flounder, please"
  • "방어 정통" = "Yellowtail, the winter specialty"
  • "매운탕 코스" = "Spicy fish stew finale, please"
  • "안 맵게" = "Less spicy, please (초장)"
  • "1/N" = "Split the bill, please"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "시장 1층 = 식사": 시장 1층 = 회판 (raw fish counter) / 2층 = 식당 (eating area) — 분리.

2. "활어 = 비싸다": 시장 활어 1kg = 20,000~60,000원 (가성비 #1).

3. "초장 = 와사비": 초장 = 고추장 (한국 정통) / 와사비 = 일본식 — 다른 양념.

4. "매운탕 = 별도 식사": 매운탕 = 회 마지막 코스 (회 → 매운탕 순서).

5. "가격 협상 X": 시장 활어 = 가격 협상 일부 가능 (kg 단위·신선도별).

6. "임신부 OK": 임신부 = 회 X (CDC 권고) — 익힌 매운탕은 OK.

7. "무한리필 = 활어": 무한리필 = 참치·연어 숙성·냉동 (활어 X).

⚙ FAQ 8개

1. 첫 회 = 어떤 채널: 참치·연어 무한리필 (MZ·가성비) → 시장 광어 (정통).

2. 인스타·vlog: 노량진 새벽·자갈치 방어·참치 toro 인스타.

3. MZ 트렌드: 연어·참치 무한리필·MZ 횟집.

4. 소주 매니아: 회 + 매운탕 + 소주 = 정통.

5. 시장 시간대: 노량진 = 새벽 도매·일반 09:00~22:00.

6. 알레르기·임신: [#864 disclaimer](#864) 참조 (임신부 회 X).

7. 결제·팁: 시장 = 현금·카드 / 횟집 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

회 = 생선 익히지 않음·식중독 주의. 임신부 = 회 X (CDC 권고)·매운탕 = OK. 어린이 = 한정 (5세 이상 익힌 것 권장). 알레르기 (생선·갑각류·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 회 6종 모두 어류 = 할랄 OK / 코셔 비늘+지느러미 = OK.
  • 채식·비건: 회 = 비채식 / 채식 = 비빔밥·사찰음식.
  • 글루텐 free: 회 자체 OK / 간장·초장 = 글루텐 일부 (Tamari 대체).
