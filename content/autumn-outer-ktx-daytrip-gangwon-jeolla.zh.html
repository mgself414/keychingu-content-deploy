⚠ 外国游客常见 3 大误区

1. "红叶 = 哪里时间都一样" — Gangwon 与 Jeolla = 相差 2 周

外国游客多数 = "Korea autumn = late October"。实际 = Gangwon 10 月中~10 月末(Seoraksan·Jeongdongjin·Donghae 高峰)/ Jeolla Naejangsan 11 月初~11 月中(全国红叶最后)(KMA·KNPS 평년)。10 月最后一周 = Gangwon 高峰 / 11 月第 1~2 周 = Jeolla 高峰。外国游客 11 月中到达韩国,Gangwon 红叶虽然结束,Jeolla Naejangsan 仍处高峰。规则 = 红叶季节 = 10 月 25 日~11 月 15 日 黄金 3 周(Gangwon → 首尔 → Jeolla 顺序)。

2. "KTX = 贵" — KORAIL PASS = 外国游客专用无限

30%+ 外国游客 = "KTX 太贵 → 当日放弃"。实际 KORAIL PASS = 外国游客专用无限通票(3 日·5 日·7 日) · 外国专用价格(比韩国人便宜) · 3 日通票 约 ₩121,000(3 日 KTX·새마을·무궁화 全运行) · 5 日通票 约 ₩159,000 · 3 日 = Gangwon 1 晚 + Jeolla 1 晚 + 首尔 1day = 韩国秋季红叶全套游。外国专用信息 = visitkorea·KORAIL 英文官网。

3. "Naejangsan 缆车 = 直达山顶" — 实际只到 Yeonjabong 燕子峰

外国游客多数 = "缆车 → 轻松到山顶"。实际 Naejangsan 缆车 = 参观中心 ↔ Yeonjabong 연자봉(海拔 460 m) · Yeonjabong → Sinseonbong 신선봉(763 m)山顶 = 步行需另加约 1 小时登山。挑战山顶 = 体力 2~3。仅缆车 = Yeonjabong 红叶 view + 入门 OK。规则 = Naejangsan 缆车 = 入门红叶 view OK / 挑战山顶 = 额外 1 小时。
