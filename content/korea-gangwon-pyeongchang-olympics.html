🎯 왜 평창 가이드인가

평창 (Pyeongchang) = 2018 평창 동계 올림픽·대관령 = 한국 #1 고원 (해발 800m+)·양떼목장·메밀 + 막국수·한국 #1 스키 매니아 매트릭스. 외국인 페인포인트 = (a) "평창 = 올림픽만" 잘못된 인식 (b) 2018 올림픽 + 대관령 + 양떼목장 = 연중 매트릭스 (c) 대관령 = 한국 #1 고원·가족 매트릭스 (d) 메밀 + 막국수 = 강원도 시그너 (e) 스키 매니아 매트릭스 #1 (용평·휘닉스·알펜시아) (f) KTX 진부역 1시간 30분.

🏛 5축 deep dive

① 2018 평창 동계 올림픽

  • 시그니처: 2018년 2월 9-25일·매니아 매트릭스·알펜시아·휘닉스·용평 시설 cluster
  • 외국인 친화도: ★★★★ (영문·매니아)
  • 추천: 올림픽 박물관 + 알펜시아·휘닉스 자유 산책

② 대관령 (해발 800m+·한국 #1 고원)

  • 시그니처: 한국 #1 고원·대관령 + 풍력발전기·가족 매니아 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족·인스타)
  • 추천: 대관령 + 풍력 + 양떼목장 = 풀세트

③ 양떼목장 (가족 매니아 #1)

  • 시그니처: 대관령 양떼목장·가족 + 어린이 매니아 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족)
  • 가격: 입장 = 5,000~10,000원/인

④ 평창 메밀 + 막국수

  • 시그니처: 강원도 시그너 음식·메밀·막국수·산채
  • 외국인 친화도: ★★★★★ (안 매콤·외국인 입문)
  • 가격: 막국수 = 9,000~14,000원·메밀전 = 8,000~12,000원

⑤ 평창 스키 (한국 #1 매니아 매트릭스)

  • 시그니처: 용평·휘닉스·알펜시아 = 한국 #1 스키 매니아·12-2월
  • 외국인 친화도: ★★★★ (영문·MZ + 매니아)
  • 가격: 리프트 1일권 = 50,000~120,000원/인·스키 대여 + 강습 + 호텔 패키지 매트릭스

⚠ 외국인 자주 실수 5가지

1. "평창 = 올림픽만": 2018 + 대관령 + 양떼목장 + 메밀·연중 매트릭스.

2. "대관령 = 일반 고원": 한국 #1 고원 800m+·가족 매니아 매트릭스 #1.

3. "양떼목장 = 어린이만": 가족 + MZ + 인스타 매트릭스.

4. "메밀 = 어디서나 동일": 평창 = 강원도 메밀 본가·시그너 매트릭스.

5. "스키 = 매니아만": 외국인 매니아 매트릭스 #1·영문 + 강습 풀세트.

⚙ FAQ 6개

1. 외국인 입문 1순위: 양떼목장 + 메밀·막국수 + 대관령 = 1일.

2. 양떼목장 시즌: 봄·여름·가을 = 양 +산책·겨울 = 폐장 일부.

3. 스키 시즌: 12월 중순~3월 초·용평·휘닉스·알펜시아 매트릭스.

4. 알레르기: 메밀 = 메밀 알레르기 사전 고지 필수·경고 #1.

5. 시즌: 봄·여름·가을 = 양떼 + 자연·겨울 = 스키 매트릭스.

6. 추천 페르소나: 가족·어린이 = 양떼 + 메밀 / MZ·인스타 = 대관령 + 양떼 / 매니아 = 스키 1박 + 풀세트.
