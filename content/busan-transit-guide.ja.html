釜山交通の文法 — 二本の線だけ読めばいい街

サブタイトル: 釜山の地下鉄路線図はソウルよりずっとシンプルだ——南北に走る1号線、海岸をなぞる2号線、この二本の線が観光動線の90%をカバーする。問題は最初の関門:金海空港には空港鉄道がない。軽電鉄の乗り換え一つで解ける空港アクセスから、交通でありながら観光でもある海辺列車、サンボクドロ (Sanbok-doro / 산복도로) のバス文法まで——釜山で移動に戸惑わないコツ。

ISSUE · #1325 · 2026-08-23

🎯 釜山移動の全体像

釜山は東西に長く横たわる海岸都市だ。移動の文法は三行に要約できる:

1. 1号線(南北軸) — 釜山駅・ナンポ (Nampo / 남포)・チャガルチ (Jagalchi / 자갈치)・ソミョン (Seomyeon / 서면)・トンネ (Dongnae / 동래)・オンチョンジャン (Oncheonjang / 온천장) を貫く観光の大動脈。

2. 2号線(海岸軸) — ソミョンで折れてキョンソンデ (Gyeongseongdae / 경성대)・クァンアン (Gwangan / 광안)・ヘウンデ (Haeundae / 해운대)・センタム (Centum / 센텀) をつなぐ。

3. 残りは補助線:3号線(マンドク (Mandeok / 만덕) 方面)、東海線広域電鉄(キジャン (Gijang / 기장)・オシリア (Osiria / 오시리아))、釜山金海軽電鉄(空港)。

ソウルのように9つの路線を覚える必要はない——ソミョンがすべての乗り換えの中心だということだけ覚えればいい。

① 空港アクセス — 最初の戸惑いポイント

金海空港にはソウルのような空港鉄道がない。選択肢は三つ:

手段 方法 感覚
軽電鉄+地下鉄 釜山金海軽電鉄でササン駅 (Sasang / 사상역) まで3駅(約7~10分) → 2号線に乗り換え ソミョン・クァンアン・ヘウンデ方面の標準ルート
空港リムジン ソミョン・プジョン (Bujeon / 부전) 行き / ヘウンデ・キジャン行きの二路線(2026年4月運行再開) 荷物が多いとき。ヘウンデ直行の感覚
タクシー カカオTで配車 深夜到着・同行者3人以上なら合理的
  • 料金負担は減った:釜山・金海・梁山間の広域乗り換え運賃が廃止されて(2025.9~)交通カード基準で1区間1,600ウォン・2区間1,800ウォンなら乗り換えまで完結する。
  • 交通カードはT-money/Cashbeeと互換——ソウルで使っていたカードがそのまま使える。空港のコンビニでチャージ可能。

② 地下鉄の文法 — 観光地を路線で読む

  • 1号線:釜山駅(KTX到着、#1114) → ナンポ(クァンボンノ (Gwangbok-ro / 광복로)・BIFF広場) → チャガルチ(#244) → ソミョン → トンネ(#269 温泉・#1323 ベースコーヒー・#1324 ペクパッチプ) → オンチョンジャン。南の終点はタデポ海水浴場 (Dadaepo Beach / 다대포해수욕장)(#272)まで。
  • 2号線:ソミョン → キョンソンデ・プギョンデ (Bukyeongdae / 부경대) → クァンアン(#243) → ヘウンデ → センタムシティ。海岸観光はこの線の上にある。
  • 3号線:マンドク方面 — K-POP巡礼(#1323)のレゴマウル (Lego Maeul / 레고마을) 軸。
  • 東海線:キジャン・オシリア(#270) — ヨングンサ (Yonggungsa / 용궁사)・ロッテワールド釜山方面は地下鉄ではなくこの広域電鉄。
  • 運行間隔はソウルより少し長い——乗り換えを含む移動はGoogleマップよりカカオマップ/ネイバーマップが正確だ。

③ 海辺列車 — 交通であり観光でもある

ヘウンデ・ブルーラインパーク:ミポ (Mipo / 미포) → チョンサポ (Cheongsapo / 청사포)(#1324 オーシャンビューカフェベルト) → ソンジョン (Songjeong / 송정) をつなぐ海辺の観光列車。1時間に約3本、片道約30分。かつての東海南部線の廃線跡を走り、海をずっと横に見る路線そのものが観光だ。

  • ⚠ 交通カードでは乗れない——別途チケット(オンライン予約可能)。スカイカプセル(2~4人カプセル型)は人気時間帯の売り切れが多い。
  • チョンサポで降りてカフェ → ソンジョンまで歩く海岸散策路の組み合わせが定番。

④ バス・タクシーの文法 — 坂の街

  • カムチョン文化村 (Gamcheon Culture Village / 감천문화마을)(#245)・サンボクドロはバスの領域だ——地下鉄駅からマウルバスに乗り換える構造。傾斜が急で徒歩でのアクセスはおすすめしない。
  • タクシーはカカオTで配車が標準。近距離乗車拒否の心配より配車の方が速い。
  • 市内バスは降車ベル+後方ドアから降車、交通カードをタッチ。現金乗車は事実上なくなりつつある流れなので、カードを基本に。

⚠ 戸惑いポイント5行

1. 空港鉄道がない——軽電鉄でササンに乗り換えるかリムジンを利用。

2. ソミョンの乗り換えは混雑する——通勤時間帯(8~9時・18~19時)は避ける。

3. 海辺列車は交通カードが使えない——別途チケット。

4. オシリア・ヨングンサは地下鉄ではなく東海線——路線図では別途表示される。

5. カムチョンは駅から遠い——マウルバスへの乗り換えまでが一セット。
