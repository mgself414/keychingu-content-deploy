🏮 包袋街 (Ssamziegil / 쌈지길) — 仁寺洞 (Insadong / 인사동) 标志性购物中心

安国站 (Anguk Station / 안국역) 6号出口步行3分钟 · 每日 10:00~21:00

包袋街 (Ssamziegil / 쌈지길) 是一座围绕中庭螺旋上升的开放式画廊购物中心，是仁寺洞 (Insadong / 인사동) 最受外国游客欢迎的地标。

🍵 传统茶馆 (Traditional Tea House / 전통찻집) — 茶文化体验

仁寺洞 (Insadong / 인사동) 小巷里分布着众多席地而坐的茶馆 (찻집)。坐在榻榻米地板 (좌식 / Jwasik) 上、用陶瓷茶具 (다기 / Dagi) 品茶，是外国游客最喜爱的体验之一。

⚠ 外国游客须知3条

1. 不可砍价: 仁寺洞 (Insadong / 인사동) 商店均为明码标价 — 讨价还价视为失礼。

2. 周末正午12~14时最拥挤: 建议12时前或平日前往，体验更从容。

3. 禁止携带外食: 包袋街 (Ssamziegil / 쌈지길) 部分咖啡馆不允许携带外部食品入内。

❓ 常见问题

Q1. 仁寺洞 (Insadong / 인사동) 必去哪里?

包袋街 (Ssamziegil / 쌈지길) (螺旋型工艺购物中心) 和一家传统茶馆 (찻집)。仅这两处便可轻松消磨2小时。

Q2. 包袋街 (Ssamziegil / 쌈지길) 需要门票吗?

免费入场。内有24家以上工坊、咖啡馆和画廊 — 只需为购物付费。

Q3. 茶馆 (찻집) 需要预约吗?

无需预约。周末下午预计等候10~20分钟。建议平日上午前往。

Q4. 仁寺洞 (Insadong / 인사동) 需要花多长时间?

购物 + 品茶 + 包袋街 (Ssamziegil / 쌈지길) = 最少3小时。加上韩式套餐 (한정식 / Hanjeongsik) 需4~5小时。

Q5. 韩纸 (Hanji / 한지) 或工艺品可以国际邮寄吗?

部分商店提供国际邮寄服务 — 请提前咨询。小件物品建议自行随行李携带。

Q6. 仁寺洞 (Insadong / 인사동) 最佳游览时间是?

周末上午 10:00~12:00 (摊位开放，人流相对较少)。正午至14时人流最多。

Q7. 仁寺洞 (Insadong / 인사동) 可以和北村 (Bukchon / 북촌) 一起游览吗?

可以。北村 (Bukchon / 북촌) 距安国站 (Anguk Station / 안국역) 步行约10分钟。仁寺洞 (Insadong / 인사동) 上午 + 北村 (Bukchon / 북촌) 下午 = 外国游客传统文化一日经典路线。

Q8. 包袋街 (Ssamziegil / 쌈지길) 有手工艺体验项目吗?

有 — 陶瓷拉坯 (물레 / Mullae)、韩纸 (Hanji / 한지) 染色、绳结 (매듭) 编织等课程可现场报名或预约 (₩15,000~30,000)。请咨询1~2层工坊。
