首尔夜店7家 — 梨泰院Techno·House 4家，弘大嘻哈·现场演出2家，清潭EDM 1家

副标题: 沿着绿莎坪到梨泰院的梨泰院路排开的Techno·House夜店4家，上水站前的嘻哈夜店和现场演出夜店2家，清潭岛山大路的大型EDM夜店1家。每家店都标了入场费、营业的日子和时间、音乐类型，以及在门口要确认的事。进夜店的年龄和身份证规定，还有饮品·回家·失物的安全守则也一并整理了。

#777 · 2026-11-24 修订 · 首尔夜店

🎯 适合这样的人

适合想在首尔听着DJ音乐跳一整夜舞的游客。按音乐类型选最简单。Techno·House在梨泰院，嘻哈·K-pop和乐队演出在弘大，大舞台的EDM在清潭。只留下在Kakao地图 (Kakao Map / 카카오맵) 上确认为营业中(status Y)、并且有2026年发布的到访评价或活动公告的店。

① 绿莎坪~梨泰院 — Techno·House 4家

四家都在绿莎坪站和梨泰院站之间的梨泰院路一带。从Cakeshop到Volnost是311m(步行4分钟)，从Volnost到FAUST是471m(6分钟)，从FAUST到Soap是392m(5分钟)。Techno·House夜店最看重当天是谁来放，所以各家夜店都会提前把DJ阵容发在Instagram和Resident Advisor(RA)上。

小型夜店 (Cakeshop / 케이크샵)

在绿莎坪站一带地下的小型夜店，有时会有海外DJ来韩演出。Kakao地图登记的时间是周五·周六22:00~05:00。按2026-11-03发布的到访评价，作者在RA上以₩22,500预订了2026-07-04海外DJ演出的票，里面一杯饮品大约₩10,000。同一作者的另一篇评价(2026-11-02)以早鸟价约₩20,000预订了1月30日的演出，并写到有知名嘉宾的日子不能重新入场。音乐类型随活动在Techno·House·Bass之间切换(博客2026-09-12)。有评价说，大牌嘉宾来的日子，主DJ到凌晨2点左右才上场(Kakao评价2026-02-03)。同一条评价还说里面会非常热，外套要寄存。地址是龙山区 (Yongsan-gu / 용산구) 梨泰院路134 地下1层 (Itaewon-ro 134 / 이태원로 134)，从绿莎坪站(6号线)3号出口步行6分钟。

  • 在门口: 大牌嘉宾来的日子，RA预售有时会先售罄，所以先确认好票再去。

Techno夜店 (Volnost / 볼노스트)

专注于昏暗灯光和厚重Techno的夜店。店名在捷克语里是'自由'的意思。Kakao地图登记的时间是周四20:00~02:00，周五·周六23:00~06:00，周日至周三休息。The Edit博客(2026-10-14)里写的入场费是₩14,000，音乐类型是暗黑·实验Techno，并写到拍摄受限。同一篇文章说，入口在楼与楼之间的窄通道深处。2026-01-25的Kakao地图评价里提到，储物柜取出一次东西就要重新付费。地址是龙山区 (Yongsan-gu / 용산구) 梨泰院路142 (Itaewon-ro 142 / 이태원로 142)，从绿莎坪站3号出口走6分钟。

  • 在门口: 这是要循着声音而不是招牌去找的地方。东西放进储物柜后，最好到结束都不要取出。

三层夜店 (FAUST / 파우스트)

主舞池放Techno，旁边的'舞蹈吧 (Tanz Bar / 탄츠바)'放House的3层夜店(到访评价2026-03-24)。Kakao地图上只登记了周五·周六23点~，没有结束时间。2026-10-24(周六)海外Techno二人组的演出公告是23:00~次日05:00(博客2026-10-20)。按2026-03-24的评价，入场费₩15,000，寄存₩2,000。按FAUST官方House Rules，看起来像未成年人时可能被要求出示身份证，拿不出任何身份证就不能入场。穿西装·制服·衬衫的男性可能被拒绝入场。全男性团体、单身派对这类破坏气氛的团体，以及不了解当天节目的客人，入场可能受到限制。室内拍摄如果是商业目的则禁止，并建议把手机收起来。地址是龙山区 (Yongsan-gu / 용산구) 普光路60街7 3层 (Bogwang-ro 60-gil 7 / 보광로60길 7 3층)，从梨泰院站(6号线)3号出口走2分钟。

  • 在门口: 欢迎随性的打扮。至少要知道当天DJ的名字再去。

House夜店 (Soap Seoul / 소프 서울)

2026年搬到现在这个位置的House·电子音乐夜店(博客2026-11-20)。官方网站上的地址是龙山区 (Yongsan-gu / 용산구) 梨泰院路217 地下2层 (Itaewon-ro 217 / 이태원로 217)。Kakao地图上没有时间，所以没能确认日常营业的日子。日常营业的日子请在Soap的Instagram(@soapseoul)上确认。作为活动示例，2026-11-20(周五)的活动公告是22:00~05:00，现场售票₩20,000(含1杯饮品)，仅限2007年及以前出生者入场。2026-09-25的到访评价里入场费也是₩20,000(以当天活动为准)，并写到室内禁烟(仅限电子烟)，早些时候放的是很有律动感的R&B·House。2026-09-12的Kakao地图评价也说室内不能吸烟，每位DJ放的音乐都不一样。从梨泰院站2号出口走6分钟。

  • 在门口: 每场活动都会公告出生年份条件。带上身份证实物。

② 上水站 — 嘻哈和现场演出2家

两家相距149m(步行2分钟)。两家都是离上水站(6号线)比离弘大入口站更近。

嘻哈夜店 (Club NB2 / 클럽 NB2)

从1999年延续至今的弘大嘻哈夜店(评价2026-01-20 'since 1999')。Kakao地图登记的时间是周一至周五22:00~06:00，周六·周日21:30~07:00，每天都开。按2025-07-08的到访评价，在门口付₩10,000会给手环和一张免费饮品券，放嘻哈和K-pop，外国游客很多。2026-01-20的评价(凌晨时段到访)里入场费也是₩10,000。入场费可能随时段·星期几而变。在桌位点整瓶的话，一瓶龙舌兰是₩99,000(评价2025-10-06)。地址是麻浦区 (Mapo-gu / 마포구) 卧牛山路72 地下1~2层 (Wausan-ro 72 / 와우산로 72)，从上水站2号出口走6分钟。

  • 在门口: 这是本篇里门槛最低的一家。工作日也开，容易安排行程。

现场演出夜店 (Club FF / 클럽 FF)

同时做乐队演出和舞蹈派对的地下夜店。官方博客介绍为'Live & Dance Club'，并写到演出场地容纳站席160人。Kakao地图登记的时间是周三至周日19:00~06:00。有演出的日子，傍晚先是乐队舞台(评价2026-08-28)。按2026-08-28的到访评价，有4支乐队的那天入场费是₩40,000(现场银行转账)，门口检查了身份证。Kakao地图菜单登记价(2025-06-11)是鸡尾酒₩8,000，汽水₩3,000，洋酒一瓶₩60,000。地址是麻浦区 (Mapo-gu / 마포구) 卧牛山路17街12 地下1层 (Wausan-ro 17-gil 12 / 와우산로17길 12), 从上水站1号出口走6分钟。

  • 在门口: 评价里写的是在现场用银行转账付款。付款方式和当天价格请看Club FF的Instagram公告。没有韩国银行账户的话，访问前先问好付款方式。

③ 清潭 — 大型EDM 1家

大型EDM夜店 (LION SUPER CLUB / 라이언슈퍼클럽)

2026年初开业的大型EDM夜店。Kakao地图和官方网站都写的是周五·周六23:00~06:00。按2026-02-21的到访评价(2026-02-25发布)，入场费随活动不同，有₩80,000·₩30,000·₩10,000·免费等，网上预订(dumbs应用)和现场购买都可以。同一条评价写到了像音乐节一样布置的灯光·屏幕，Tech House·EDM的演出，以及闻不到烟味的室内。官方网站上有'失物招领'菜单。地址是江南区 (Gangnam-gu / 강남구) 岛山大路535 (Dosan-daero 535 / 도산대로 535)，从清潭站(7号线)13号出口走12分钟，所以坐公交或打车更方便。

  • 在门口: 每场活动的入场费差别很大，在@lionseoul上看当天的价格。

  1. 19:00~ 进入Club FF(周三至周日营业)。看Instagram公告确认是不是乐队演出日
  2. 23:00左右 转到NB2，用嘻哈·K-pop接着玩
  3. 地铁停运后，坐下面'安全与回家'里的夜猫子巴士或出租车回去

🛡 安全与回家

  • 饮品: 不要喝不知道成分的酒或饮料。去跳舞或去洗手间时也要端着杯子走，或者重新拿一杯。突然头脑发昏或记忆中断时就要怀疑，不要丢掉喝过的杯子，拨打112报警。可以通过警方做血液·尿液检测(仁川广域市预防药物性犯罪守则，2024-12-19)。在韩国报警电话是112，救护车是119(英国政府海外旅行指南)。
  • 翻译: 韩国观光公社旅游翻译咨询电话1330支持英语，07:00~24:00还可以三方通话翻译(英国政府海外旅行指南)。
  • 回家: 首尔市夜猫子巴士(深夜巴士)有14条线路在23:00~06:00运行，刷卡票价₩2,500(首尔市交通网站，2026-03-20修改)。站点和线路要在上车的地方提前确认。出租车要走到大路上去拦。
  • 失物: 在公交·出租车上丢的东西，到首尔市'公共交通综合失物中心'找。运营机构保管7天后移交警察局，之后在警察厅失物综合门户(lost112.go.kr)查找。也可以问120茶山呼叫中心(首尔市交通网站，2025-04-16修改)。寄存在夜店寄存处的包，有的店像FAUST的House Rules那样不负责贵重物品丢失，所以护照·钱包要随身带着。

⚠ 3个常见失误

  1. 把梨泰院夜店安排在周日到周三 — Kakao地图登记的营业日是Cakeshop·FAUST周五·周六，Volnost周四~周六。Soap没能确认日常营业的日子。工作日晚上的话，每天开的NB2和从周三开始营业的Club FF比较现实。
  2. 把入场费当成固定值 — 同一家夜店也会因活动不同从免费到₩80,000不等(LION SUPER CLUB评价2026-02-25)。海外DJ演出有时要在RA上提前预订(Cakeshop评价2026-11-03)。
  3. 只带身份证照片就去 — 有的店在门口不接受手机照片·复印件。外国人要带护照原件。夜店在门口确认年龄，FAUST的House Rules也写了可能被要求出示身份证。

⚙ 3个常见问题

  1. 几岁开始可以进夜店？ — 青少年保护法把未满19岁视为青少年，但到了满19岁那一年的1月1日之后就不再算青少年。与生日无关，按出生年份计算，所以2026年出生于2007年或更早的人可以买酒。同一部法律规定不得向青少年卖酒，卖方有义务确认年龄和本人身份。Soap Seoul的2026-11-20活动也公告为'2007年生及以前出生者入场'。各家夜店可以设比这更严格的自己的标准，即使夜店自己的规定是18岁，也以韩国法律的出生年份标准为准。
  2. 有着装要求吗？ — 确认过官方规定的只有FAUST。欢迎随性大胆的打扮，并写到穿西装·制服·衬衫的男性可能被拒绝入场。其余夜店没能确认固定规定。Techno夜店要站很久，穿舒服的鞋比较好。
  3. 需要预约吗？ — 海外DJ来的日子，Cakeshop有RA预售(评价2026-11-03)，LION SUPER CLUB可以用dumbs应用预订也可以现场购买(评价2026-02-25)。NB2和Volnost没能确认预订信息。去之前看各家夜店的Instagram。
