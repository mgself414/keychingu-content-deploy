🎯 このガイドの使い方

このガイドは、ソウルと京畿道広州市にあるユネスコ世界遺産のうち、朝鮮王陵3か所と南漢山城をまとめたものです。江南区の宣陵と靖陵、蘆原区の泰陵と康陵、瑞草区の献陵と仁陵、そして南漢山城の守禦将台と城郭の探訪路です。王陵3か所はどれも月曜日が休みで(泰陵・康陵と献陵・仁陵は月曜日が祝日なら開き、そのあとの最初の平日に休みます)、入場料は3か所とも1,000ウォンと登録されています。南漢山城の行宮と南漢山城一帯は#1418 京畿広州日帰りガイドにもあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 江南区の王陵 — 宣陵と靖陵

ソウル 宣陵と靖陵 (Seolleung-gwa Jeongneung / 선릉과 정릉)、江南区 Seolleung-ro 100-gil 1 (선릉로100길 1)、☎ 02-568-1291 は、朝鮮の第9代 成宗と、チョンヒョン王后 (Jeonghyeon Wanghu / 정현왕후)の宣陵、第11代 中宗の靖陵がある場所です。宣陵は一つの丁字閣 (Jeongjagak / 정자각)を置き、それぞれ別の丘に陵をつくった同原異岡陵 (Dongwonigangneung / 동원이강릉)の形式で、丁字閣の前から見て左の丘が成宗、右の丘がチョンヒョン王后の陵です。成宗の陵は1495年に、チョンヒョン王后の陵は1530年に東の丘に造られました。

靖陵は1545年に初めは別の場所に造られましたが、1562年に3番目の王妃である文定王后が今の場所に移しました。中宗のそばに葬られることを望んでいた文定王后は、移した靖陵が低地で雨が降るとたびたび水に浸かったため、亡くなったあと、靖陵ではなく蘆原区の泰陵に葬られました。宣陵と靖陵は、1592年の壬辰倭乱のとき、陵が掘り返される被害を受けました。

  • 開く時間: 06:00~21:00(入場締切 20:00)。休み: 毎週月曜日。
  • 料金: 大人・外国人 1,000ウォン、地域住民 500ウォン。満24歳以下、満65歳以上、障害のある方、功労者は無料。
  • 駐車: 可能。

📍 蘆原区と瑞草区の王陵 — 泰陵と康陵・献陵と仁陵

ソウル 泰陵と康陵 (Taereung-gwa Gangneung / 태릉과 강릉)、蘆原区 Hwarang-ro 681 (화랑로 681)、☎ 02-972-0370 は、中宗の3番目の王妃 文定王后の泰陵と、第13代 明宗とインスン王后 (Insun Wanghu / 인순왕후)の康陵です。泰陵は1565年に造られました。墳丘に屏風石と欄干石をめぐらせ、屏風石に雲の文様と十二支神を刻みました。韓国観光公社の紹介によると、石造物がほかの朝鮮王陵より大きく立てられていて、文石人 (Munseogin / 문석인)と武石人 (Museogin / 무석인)の耳たぶにイヤリングの穴があるのが珍しいです。丁字閣は韓国戦争で焼けたものを1994年に復元しました。康陵は一つの曲牆 (Gokjang / 곡장)の中に墳丘を二つ並べた雙陵 (Ssangneung / 쌍릉)で、1567年に泰陵の東の丘に造られました。

  • 開く時間: 2~5月・9~10月 09:00~18:00(入場締切 17:00)、6~8月 09:00~18:30(入場締切 17:30)、11~1月 09:00~17:30(入場締切 16:30)。
  • 休み: 毎週月曜日。月曜日が祝日なら開き、そのあとの最初の平日に休みます。
  • 料金: 個人 1,000ウォン、10人以上の団体 800ウォン。駐車: 可能。

ソウル 献陵と仁陵 (Heolleung-gwa Illeung / 헌릉과 인릉)、瑞草区 Heonilleung-gil 34 (헌인릉길 34)、☎ 02-445-0347 は、朝鮮の第3代 太宗とウォンギョン王后 (Wongyeong Wanghu / 원경왕후)の献陵、第23代 純祖とスヌォン皇后 (Sunwon Hwanghu / 순원황후)の仁陵です。献陵は雙陵の形式で、1420年にウォンギョン王后の陵を先に造り、1422年に太宗の陵をその西に造りました。文石人、武石人、石馬 (Seongma / 석마)、石羊 (Seogyang / 석양)、石虎 (Seokho / 석호)がほかの王陵の2倍の数で配置されています。仁陵は一つの墳丘に王と王妃をともに祀った合葬陵 (Hapjangneung / 합장릉)の形式です。初めは坡州の交河に造られ、のちに今の場所へ移されましたが、移すとき、セジョン (Sejong / 세종)の旧 ヨンヌン (Yeongneung / 영릉)の石造物と、チャンギョン王后 (Janggyeong Wanghu / 장경왕후)の旧 ヒルン (Huireung / 희릉)の石造物をもう一度掘り出して使いました。

  • 開く時間: 2~5月・9~10月 09:00~18:00(入場締切 17:00)、6~8月 09:00~18:30(入場締切 17:30)、11~1月 09:00~17:30(入場締切 16:30)。
  • 休み: 毎週月曜日。月曜日が祝日なら開き、そのあとの最初の平日に休みます。
  • 料金: 個人 1,000ウォン、10人以上の団体 800ウォン。駐車: 無料。クレジットカード: 可能。

📍 山城 — 南漢山城 守禦将台・探訪路

南漢山城 守禦将台 (Namhansanseong Sueojangdae / 남한산성 수어장대)、京畿道 広州市 南漢山城面 山城里 (Namhansanseong-myeon Sanseong-ri / 남한산성면 산성리)、☎ 南漢山城世界遺産センター (Namhansanseong Segyeyusan Senteo / 남한산성세계유산센터) 031-8008-5155 は、指揮と観測のために建てた楼閣です。南漢山城にあった将台5か所のうち、唯一残っています。チョンニャンサン (Cheongnyangsan / 청량산)の頂上(海抜482m)にある2階建ての楼閣で、ヨンジョ (Yeongjo / 영조)27年の1751年に2階に増築しました。外側に「守禦将台 (Sueojangdae / 수어장대)」、内側に「ムマンヌ (Mumangnu / 무망루)」の扁額があります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。
  • 駐車: 二輪車と1,000cc未満の乗用車は平日 1,500ウォン、週末・祝日 2,500ウォン。1,000cc以上の乗用車、15人乗り以下の小型乗合車、1トン以下の小型貨物車は平日 3,000ウォン、週末・祝日 5,000ウォン。中・大型乗合車と貨物車は平日 6,000ウォンで、週末・祝日は駐車できません。

南漢山城 探訪路 (Namhansanseong Tambangno / 남한산성 탐방로)、京畿道 広州市 南漢山城面 山城里 (Namhansanseong-myeon Sanseong-ri / 남한산성면 산성리)、☎ 031-8008-5155 は、南漢山城の城郭に沿って歩く5つのコースです。

  • 1コース 将帥の道 (Jangsu-ui Gil / 장수의 길): 約3.8km、1時間20分。道がなだらかだと紹介されていて、北門・西門・南門と暗門、守禦将台を通ります。
  • 2コース 国王の道 (Gugwang-ui Gil / 국왕의 길): 約3km、1時間。行宮から始まり、チムグェジョン (Chimgwaejeong / 침괘정)と西門を通ります。
  • 3コース 僧兵の道 (Seungbyeong-ui Gil / 승병의 길): 約5.7km、2時間。チャンギョンサ (Janggyeongsa / 장경사)とマンウォルサ (Manwolsa / 망월사)、外城のポンアムソン (Bongamseong / 봉암성)を通ります。
  • 4コース オンソンの道 (Ongseong-ui Gil / 옹성의 길): 約3.8km、1時間20分。第1・第2・第3南オンソン (Nam-ongseong / 남옹성)を通ります。
  • 5コース 山城の道 (Sanseong-ui Gil / 산성의 길): 約7.7km、3時間20分。城壁と暗門、チソン (Chiseong / 치성)をくまなく通り、ソンナム・ハナム・広州の景色がすべて見えます。
  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 可能。

⚠ 前もって知っておきたい3つのこと

  1. 王陵3か所は月曜日が休みです — 泰陵・康陵と献陵・仁陵は、月曜日が祝日なら開き、そのあとの最初の平日に休みます。
  2. 宣陵と靖陵は21:00まで開きます — 泰陵・康陵と献陵・仁陵は、冬(11~1月)は17:30に閉まります。
  3. 守禦将台の駐車料金は週末・祝日のほうが高くなります — 1,000cc以上の乗用車は平日 3,000ウォン、週末・祝日 5,000ウォンで、中・大型乗合車と貨物車は週末・祝日に駐車できません。

⚙ FAQ 2

Q. 外国人の入場料は?

A. 韓国観光公社の登録情報では、宣陵と靖陵が大人・外国人 1,000ウォンで、泰陵・康陵と献陵・仁陵は「個人 1,000ウォン」と登録されています。

Q. 南漢山城探訪路の5コースのうち、いちばん短いコースは?

A. 2コース 国王の道で、約3kmで1時間かかると登録されています。
