韩国公共交通礼仪 — 在韩国地铁不当“反派 (villain / 빌런)”的方法

> 关怀座 (Baeryeoseok / 배려석) · 安静的车厢 · 背包礼仪 · 上下车 · 扶梯 · T-money — 为外国人解读韩国 (Korea / 한국) 公共交通礼仪。不是“规则清单”，而是“为什么、是什么、怎么做”。

外国人第一次乘坐首尔 (Seoul / 서울) 地铁时，最先感受到的有两点。一是“为什么这么安静？” — 即使是上下班高峰的满员列车，大家也都把手机调成静音看，或戴着耳机，几乎没有人大声打电话。二是“为什么那个座位空着？” — 车厢两端粉色或颜色不同的座位，即使有人站着也空着。比起法律明文规定，韩国公共交通有更多“相互约定的礼仪” (seoro yaksokhan maeneo / 서로 약속한 매너)。如果不懂这些礼仪，自己无意中做的行为 (坐关怀座、大声打电话、背着大背包) 在周围人看来就成了“碍事的反派” (minpye villain / 민폐 빌런)。本文不是讲“哪个站好”(那是地点指南)，而是以外国人的视角，解读那些礼仪背后的思维方式 (体谅·眼力见儿·公共道德) (baeryeo·nunchi·gongjungdodeok / 배려·눈치·공중도덕) 与实战 (T-money·换乘·上下车) (siljeon / 실전)。韩国 (Korea / 한국) 文化解读系列第37篇。

⚠️ 外国人常有的3个误解

1. “空着嘛，坐一会儿应该没关系吧” ❌ — 车厢两端的老弱病残孕座 (gyotongyakjaseok / 교통약자석) 和粉色的孕妇关怀座 (imsanbu baeryeoseok / 임산부 배려석)，按韩式原则即使拥挤也要空着 (biwoduneun geot / 비워두는 것)。不像其他国家“先坐着，有需要的人来了再让”，这里是从一开始就不坐 (cheoeumbuteo an anneunda / 처음부터 안 앉는다)。尤其是孕妇关怀座，“即使看不到需要的人也空着”的意识很强。

2. “打一通电话应该没关系吧” ❌ — 韩国地铁安静是默认 (joyongham-i default / 조용함이 디폴트)。大声对话、笑声、通话都会招来侧目。通话本身不是禁止，但简短轻声 (jjalkko jakge / 짧고 작게) 才是礼仪。大多数人用短信、耳机音乐来解决。

3. “背包就那么背着不就行了” ❌ — 背着大背包挤上满员列车，每次转身都会撞到旁边的人。拥挤时背在前面或放在脚下 (apeuro megeona balmiteul naeryeoduneun / 앞으로 메거나 발밑에 내려두는) 是基本礼仪。外国游客的大背包尤其显眼。

① 韩国公共交通礼仪是什么 — 比法律更多“约定”的空间

韩国地铁、公交虽有明文规定的法律 (如禁止逃票)，但实际主导氛围的是市民相互约定的非正式礼仪 (biyoungsik maeneo / 비공식 매너)。空出关怀座、安静乘车，大多是没有处罚条款的“默契” (ammukjeok hapui / 암묵적 합의)，所以外国人不容易察觉。

  • 根源有两个 — 体谅 (相互谦让) (baeryeo / 배려) 和“不给人添麻烦 (公共道德)” (pye kkichiji anki / 폐 끼치지 않기)。这是一种把共用空间的平静置于个人便利之上的感觉。
  • 所以在韩国，“有礼貌的乘客”是不引人注意的乘客 (nune an ttineun seunggaek / 눈에 안 띄는 승객)。安静、不占地方、不挡流向的人。相反，“反派”是吵闹、挡路、占用大量空间、独自显眼的人 (honja twineun saram / 혼자 튀는 사람)。

理解了这种感觉，下面的规则就不再是要背的清单，而是凝聚成一个原理 (hana-ui wonri / 하나의 원리)。

② 关怀座 — 空着的座位 (老弱病残孕座、孕妇关怀座)

这是最重要、外国人最常出错的部分。韩国地铁车厢两端 (yang kkeut / 양 끝) 有两种特殊座位。

  • 老弱病残孕座 (gyotongyakjaseok / 교통약자석)：1980年首尔地铁开通时以“老弱座 (noyakjaseok / 노약자석)”引入，从2005年起更名为“交通弱者座” (gyotongyakjaseok / 교통약자석)。这是为行动不便者 (idongi eoryeoun saram / 이동이 어려운 사람) — 老人、残障人士、孕妇、携带婴幼儿者、伤者等 — 设置的座位。通常在车厢两端，颜色不同。
  • 孕妇关怀座 (imsanbu baeryeoseok / 임산부 배려석，粉色)：2013年在首尔地铁单独引入的粉色座位 (bunhongsaek jwaseok / 분홍색 좌석)。因从外表难以判断是否怀孕、孕妇得不到让座，为解决这一问题而设。始终空着 (hangsang biwoduneun geot / 항상 비워두는 것) 已成为原则。孕妇可在车站客服中心领取粉色徽章 (bunhongsaek baeji / 분홍색 배지) 佩戴，向周围示意“我可能需要座位”。

> 外国人实战：在韩国，坐到交通弱者专座也没有罚款之类的处罚 (gwataeryo gateun cheobeoleun eopda / 과태료 같은 처벌은 없다)(与部分国家不同)。但不坐才是社会原则 (an anneun geot-i sahoejeok wonchik / 앉지 않는 것이 사회적 원칙)。即使普通座位坐满，也要空出交通弱者座、孕妇关怀座。韩国人自己也把“交通弱者座有需要的人来就让”和“孕妇关怀座干脆空着”视为不同 — 但外国人两个都不坐才安全 (둘 다 안 앉는 쪽이 안전 / dul da an anneun jjogi anjeon)。

③ 安静的车厢 — 通话与大声 (安静车厢之国)

韩国地铁的安静是外国人印象最深的特征。虽然不是完全无声 (wanjeon mueum-eun anijiman / 완전 무음은 아니지만)(能听到列车声、广播)，但比同等规模的海外城市地铁明显安静 (hwagyeonhi joyonghada / 확연히 조용하다)。

  • 通话 (tonghwa / 통화)：不是禁止，但简短轻声 (jjalkko jakge / 짧고 작게)。又长又大声的通话会招来侧目。多数乘客用短信、耳机音乐 (munja·ieopon eumak / 문자·이어폰 음악) 处理。
  • 对话 (daehwa / 대화)：与同行者的对话也要低声 (najeun moksori / 낮은 목소리)。避免大笑、高声。
  • 漏音的耳机 (sori saeneun ieopon / 소리 새는 이어폰)：戴耳机时音量太大导致漏音，也是给人添麻烦。音量适中。
  • 安静车厢标识 (Quiet Car pyosi / Quiet Car 표시)：部分线路、车厢贴有提示克制通话、大声交谈 (tonghwa·keun daehwa jajae / 통화·큰 대화 자제) 的安静车厢标识。

这种安静是“不侵犯彼此空间”这一公共道德 (gongjungdodeok / 공중도덕) 的直接体现。对外国人来说，记成“在这里把音量调低一档”就容易了。

④ 背包、上下车 — 空间与流向的礼仪

在满员列车上最常 (字面意义上) 碰撞的两件事。

背包礼仪 (baekpaek maeneo / 백팩 매너)

  • 把大包背在背后 (deunge men chae / 등에 멘 채)，转身时每次都会撞到旁边的人。拥挤时背在前面、拿在手上、或放在脚下 (apeuro megeona, sone deulgeona, balmiteul naeryeodugi / 앞으로 메거나, 손에 들거나, 발밑에 내려두기)。
  • 在韩国，“拥挤时背包背前面”是连地铁礼仪广告都会出现的成熟规范。背着大旅行包的外国游客尤其显眼，人多起来时就自然地把包转到前面。

上下车礼仪 — 先下后上 (seunghacha maeneo — naeril saram meonjeo / 승하차 매너 — 내릴 사람 먼저)

  • 韩国地铁最基本中的基本 (gajang gibon jung-ui gibon / 가장 기본 중의 기본)：门一开，等下车的人都下完后再上 (naerineun saram-i da naerin dwie / 내리는 사람이 다 내린 뒤에)。因为是同一扇门上下车。
  • 门开之前，在门旁退一步 (mun yeopeuro han bal mulleona / 문 옆으로 한 발 물러나)，让出下车人的路。然后排队一个一个上。
  • 站台地面很多地方画有排队标线 (jul seogi pyosiseon / 줄 서기 표시선)。沿线排队就不会出现“门前人堵”。
  • 守住这两点，即使满员列车流向也顺畅 — 挡住流向的人就是“反派”。

⑤ 扶梯 — 从“站一列”到“站两列”(转变中)

这是外国人最容易混淆的部分，所以要准确点明。韩国扶梯文化正处于转型期 (jigeum jeonhwangi / 지금 전환기)。

  • 过去 (2000年代~)：始于1990年代后期的市民运动，以2002世界杯为契机“站一列” (han jul seogi / 한 줄 서기) 普及开来。站在右侧，左侧空出给行走或奔跑的人 — 至今仍是许多人养成的习惯 (mome baen seupgwan / 몸에 밴 습관)。
  • 现行推荐 (安全) (hyeonjae gwonjang / 현재 권장)：站一列存在行走、奔跑摔倒的事故 (geotda·ttwida neomeojineun sago / 걷다·뛰다 넘어지는 사고) 和单侧受力导致设备故障的较大问题。因此政府、电梯安全公团开始正式推荐“不行走、不奔跑，握扶手站立使用” (geotgeona ttwiji malgo, sonjabireul japgo seoseo iyong / 걷거나 뛰지 말고, 손잡이를 잡고 서서 이용)，并在2026年再次开始官方推荐“站两列” (du jul seogi / 두 줄 서기)(时隔11年重启)。因为从安全数据看，扶梯重大事故的多数被统计为“行走或奔跑使用者的过失”。

> 整理 (防混淆)：不是“站一列错了”，而是习惯仍是站一列，但推荐正转向站两列 (站立使用) (du jul seogi-ro bakkwineun jung / 두 줄 서기로 바뀌는 중)。外国人只要简单记住“在扶梯上不行走、不奔跑，握扶手站着走” (geotgeona ttwiji malgo, sonjabi japgo seoseo gagi / 걷거나 뛰지 말고, 손잡이 잡고 서서 가기)，无论哪种都既安全又合乎礼仪。赶时间就用旁边的楼梯。

⑥ 交通卡、换乘实战 — 一张 T-money 搞定

和礼仪一样重要的是实战支付 (siljeon gyeolje / 실전 결제)。外国人问得最多的部分。

  • T-money 卡：地铁、公交乃至出租车都能用的充值式交通卡。在 CU、GS25、7-Eleven 等便利店 (pyeonuijeom / 편의점) 以约3,000韩元 (won / 원) 的卡费购买。韩国大部分地区通用。
  • 充值 (chungjeon / 충전)：在便利店、车站充值机。注意 — 充值通常只收现金 (chungjeon-eun botong hyeongeumman doenda / 충전은 보통 현금만 된다)(很多地方不能用信用卡/借记卡)。请提前备好现金。
  • ★ 上车+下车都要刷 (tal ttae+naeril ttae modu tag / 탈 때+내릴 때 모두 태그)：韩国交通的核心。上车刷一次，下车刷一次 (tal ttae han beon, naeril ttae han beon / 탈 때 한 번, 내릴 때 한 번)。下车不刷换乘折扣就消失 (naeril ttae an jjigeumyeon hwanseunghalin-i sarajigo / 내릴 때 안 찍으면 환승할인이 사라지고)，里程计费也会出错。公交也一样 — 下车时务必在终端刷卡。
  • 换乘折扣 (hwanseunghalin / 환승할인)：用同一张卡刷，下车后30分钟内 (hacha hu 30bun inae / 하차 후 30분 이내)(晚9点~凌晨7点为60分钟)公交↔地铁换乘享折扣。最多4次换乘 (共乘坐5次)。这是韩国公共交通便宜的原因之一。
  • 外国人专用选项 (oegugin-yong option / 외국인용 옵션)：短期旅行者也可选择气候同行卡 (gihudonghaengkadeu / 기후동행카드，Climate Card)(首尔公交、地铁、Ttareungi 共享单车等一定期间无限次) 或 Mpass 等外国人专属卡。若是几天集中出行，定额票可能更划算。
  • App (앱 / aep)：用地铁 App (jihacheol app / 지하철 앱)(或 Naver 地图、KakaoMap) 提前确认地铁线路、换乘，就不会迷路。支持英文。

⑦ 为什么这么安静、这么体谅 — 眼力见儿与公共道德

最后，把这一切礼仪凝聚为一体的“为什么”。

  • 眼力见儿 (nunchi / 눈치)：韩国人不用说也能读懂氛围和他人的状态 (bunwigiwa tain-ui sangtaereul ikneunda / 분위기와 타인의 상태를 읽는다)(→ #1145)。在地铁里，不断察看“我现在吵吗？占地方太多了吗？那位需要座位吗？”就是眼力见儿 (nunchi / 눈치)。空出关怀座、调低音量，归根结底都是眼力见儿的体现 (nunchi-ui pyohyeon / 눈치의 표현)。
  • 公共道德 (不添麻烦) (gongjungdodeok / 공중도덕)：韩国社会把在公共空间不给别人添麻烦 (民弊) (namege pye kkichiji anneun geot / 남에게 폐 끼치지 않는 것) 视为重要美德。这是一种把共用空间的平静 (hamkke sseuneun gonggan-ui pyeongon / 함께 쓰는 공간의 평온) 置于个人自由之上的感觉。地铁是这种感觉最浓缩地显现的舞台。
  • 体谅 (baeryeo / 배려)：给弱者 (老人、孕妇、残障人士) 让座，与其说是明文规则，不如说是社会期待 (sahoejeok gidae / 사회적 기대)。所以即使没有处罚也能运作。

也就是说，韩国地铁的安静、秩序、体谅，不是因为惧怕规则，而是读懂彼此 (眼力见儿)、不愿添麻烦 (公共道德) 的文化 (seororeul ikko pye kkichiji aneuryeoneun munhwa / 서로를 읽고 폐 끼치지 않으려는 문화) 化为空间的体现。懂了这一点，“为什么要做到这种地步？”就变成“啊，原来如此”。

❓ 外国人常见问题 (FAQ)

  • 关怀座 (배려석) 真的一次都不能坐吗？ — 没有处罚，但即使普通座位坐满，空着也是韩国原则 (biwoduneun ge hanguk wonchik / 비워두는 게 한국 원칙)。尤其是粉色孕妇关怀座 (임산부 배려석)，空着也不坐的意识很强。外国人不坐才安全。
  • 来了紧急电话怎么办？ — 接也可以，但简短轻声 (jjalkko jakge / 짧고 작게)。觉得会长就在下一站下车通话，或发短信“在地铁，待会儿打” — 这才是礼仪。
  • 可以在扶梯上走上去吗？ — 习惯性行走的人仍很多，但安全上推荐“站着使用” (anjeonsang gwonjang-eun seoseo iyong / 안전상 권장은 서서 이용)(正转向站两列)。赶时间就用旁边的楼梯。至少别奔跑 (ttwiji-neun anki / 뛰지는 않기)。
  • 下车时也一定要刷卡吗？ — 是的，必须 (ne, bandeusi / 네, 반드시)。 不刷换乘折扣会消失，还可能加收车费。公交下车时也要刷。
  • 可以吃东西吗？ — 气味强烈或容易洒的食物在车厢内要克制。水、简单饮料尚可。
  • 背包一定要一直背在前面吗？ — 空时无所谓。人多起来时 (saram-i manajimyeon / 사람이 많아지면) 转到前面或放脚下即可 — 核心是“拥挤时的空间体谅”。
