弘大咖啡·甜点89家指南 — 外国游客专属精选

> 副标题: 弘大 (Hongdae / 홍대)·延南 (Yeonnam / 연남)·合井 (Hapjeong / 합정)·望远 (Mangwon / 망원) 咖啡·甜点分类精选 — #158综合指南的咖啡·甜点深度专题

ISSUE 03 · #160 · 2026-05-14

🎯 外国游客必读5要点

1. 延南 (Yeonnam / 연남)·合井 (Hapjeong / 합정)·望远 (Mangwon / 망원) = 弘大 (Hongdae / 홍대) 同一动线: 弘大入口站 (Hongdae Ipgu Station / 홍대입구역) 步行10~15分钟内4个子区域密集分布，一条动线串联可高效打卡5家以上。

2. 工作日14:00~17:00黄金时段: 周末及深夜排队1小时以上。外国友好型店铺在工作日下午14:00~17:00人少，英语服务最佳。

3. 吧台座位·预约: 日式小店以吧台座位为主。工作日19:00前后为黄金时段。支持英语的店铺可通过 Naver 预约或 KakaoTalk 频道预订。

4. 多数门店支持境外卡: 弘大区是外国游客首选动线，支持境外卡·Samsung Pay·KakaoPay (간편결제 — 韩国主流移动支付，类似支付宝/微信支付) 的店铺众多。老字号 (노포 — 30年以上的传统店) 及小店建议备好现金约₩30,000 (~$22 / ~160 RMB / ~3,200 JPY)。

5. ins打卡·拍照动线: 区内有大量韩屋街巷 (한옥 골목 — 韩式传统建筑小巷，类似北京胡同风格)、画廊、复古装潢及主题咖啡馆。追求最佳拍摄效果，推荐上午11:00或19:00以后人少时段前往。

2. 咖啡·甜点 — 89家

🍰 甜点 — 一口改变心情的地方 (10家)

可丽饼、招牌蛋糕、香气馥郁的咖啡——这里是「甜点即主角」的咖啡馆。

  • 熔化 (Melting Of / 멜팅오브) — 入口即化的招牌甜点
  • 咖啡公鸣 (Cafe Gongmyeong / 카페 공명) — 烘焙·甜点品类扎实完善
  • 已来咖啡 (Imi Coffee / 이미커피) — 以咖啡为本业的甜点咖啡馆
  • 托拉比 (Torabi / 토라비) — 蛋糕·甜点品类丰富
  • 人生可丽饼 (Inssaeng Crepe / 인생크레페) — 名副其实的可丽饼专门店
  • Just单比可丽饼 (Just Danbi Crepe / 저스트단비 크레페) — 专注一款可丽饼决胜负
  • Met Lounge (멧라운지) — 休闲格调的沉静甜点空间
  • 胡里根 (Hooligan / 훌리건) — 概念强烈的甜点酒吧
  • 一莲烘焙师 (Ilryeon Roasters / 일련 로스터스) — 自家烘焙咖啡实力强劲
  • Turn Down Service TokTok (턴다운서비스톡톡) — 酒店式概念甜点馆

🥞 舒芙蕾·厚松饼 — 蓬松口感的极致 (10家)

等待出餐20分钟也值得的那种质感。

  • 拉赫勒厨房 (Rahel's Kitchen / 라헬의부엌) — 蓬松舒芙蕾厚松饼代表
  • 莓悦 (Berry Bliss / 베리블리스) — 莓果配料招牌款
  • Thinkfruit (띵크프룻) — 以水果为主角的甜点
  • 部落 (Tribe / 트라이브) — 摩登舒芙蕾咖啡馆
  • 小果糖 (Sogwadang / 소과당) — 小而精致的舒芙蕾专门店
  • 野餐 (Picnic / 피크니크) — 野餐概念甜点馆
  • CLC (씨엘씨) — 一盘简洁舒芙蕾
  • 伊戈舒芙蕾 (Igo Souffle / 이고 수플레) — 专注一款舒芙蕾决胜负
  • 诚实厚松饼 (Honest Pancake / 어니스트팬케이크) — 实诚厚度的松饼
  • 月亮阶梯 (Moon Stairs / 달의계단) — 氛围感同样加分的甜点空间

> TIP — 舒芙蕾须趁出炉即刻享用才能体现真正价值，不建议打包带走。

🎂 蛋糕 — 生日·纪念日首选 (10家)

从当天可取整个蛋糕的名店，到适合两人分享迷你尺寸的地方，一应俱全。

  • 也许蛋糕 (Maybe Cake / 메이비케이크) — 极简设计蛋糕
  • 托拉比 (Torabi / 토라비) — 蛋糕品类宽泛 (与甜点分类重复)
  • 咖啡生日 (Coffee Birthday / 커피 벌스데이) — 名副其实的生日主题咖啡馆
  • 菲洛烘焙 (Filo Bakery / 필로베이커리) — 烘焙+蛋糕兼营
  • 张老师咖啡 (Cafe Jangssaem / 카페 장쌤) — 张老师招牌蛋糕
  • 甜蜜谎言 (Sweet Lie / 달콤한거짓말) — 颜值十足的甜点咖啡馆
  • 贝妮蛋糕 (Beni Cake / 베니케이크) — 色彩缤纷的视觉系蛋糕
  • 芍药花 (Peony / 피오니) — 芍药主题的优雅蛋糕店
  • 蓬蓬涅特 (Pomponnette / 퐁포네뜨) — 草莓满满的招牌蛋糕

🥖 烘焙面包 — 面包朝圣的圣地 (19家)

弘大就是面包之城。百吉饼、吐司、奶油面包、乡村面包、日式烘焙——同一街区全都有。

有明确招牌的店

  • 可疑百吉饼 (Suspicious Bagel / 수상한베이글) — 百吉饼专门店，视觉冲击力强
  • 青鸟 (Aoi Tori / 아오이토리) — 日式红豆包·菠萝包正统出品
  • 哈哈奶油包 (Puhaha Cream Bread / 푸하하크림빵) — 奶油包常态售罄
  • 金振焕糕点店 (Kim Jin-hwan Confectionery / 김진환 제과점) — 口味温和、质朴有嚼劲的正统面包坊
  • 摩典 (Modyeon / 모뎐) — 摩登概念烘焙坊
  • 395面包店 (395 Bakery / 395빵집) — 街坊正统面包坊气息

吐司·乡村面包·硬质面包系列

  • 黄油烘焙 (Butter Bakery / 버터베이커리) — 黄油香浓郁的起酥点心
  • 面包树 (Bread Tree / 빵나무) — 品类数量惊人
  • 熊穴烘焙 (Bear's Den Bakery / 베어스덴베이커리) — 星野食吐司·蒜香法棍人气高
  • 烟囱公馆 (Chimney Mansion / 침니맨션) — 烟囱装潢是最大特色
  • 栗子树制面包 (Kurinoki Bakery / 쿠리노키제빵) — 日式烘焙

甜点面包·小食面包

  • 菲洛烘焙 (Filo Bakery / 필로베이커리) — 蛋糕·甜点面包兼营
  • TYTD (티와이티디) — 摩登烘焙坊
  • 波波面包 (Popo Bread / 포포브레드) — 以吐司·餐食面包为主
  • 菲普里 (Filipree / 필프리) — 休闲烘焙坊
  • 理由烘焙坊 (Iyu Bake Shop / 이유 베이크샵) — 烘焙+蛋糕
  • 恐龙面包工厂 (Dinosaur Bread Factory / 공룡빵공장) — 恐龙造型面包视觉出圈
  • WON (더블유오앤) — 大型烘焙咖啡馆
  • 古老糕点铺 (Gguul Gwajajeom / 꾸울과자점) — 复古老式糕点铺风格

> #### 🎯 深度精选 — 金振焕糕点店 (Kim Jin-hwan Confectionery / 김진환 제과점)

> 在新村 (Sinchon / 신촌)·弘大 (Hongdae / 홍대) 一带面包爱好者中长期口耳相传的正统街坊面包坊。品类数量压倒性地多，且可以试吃，光是绕一圈就已乐趣十足。核心评价在于口味温和不刺激、嚼劲十足且清爽的质感——凭借每天吃都不腻的面包味道积累了一批忠实常客，而非靠华丽外观。店门口会标示刚出炉时间，建议掐准时间前往。距离山鸣1992 (Sanulrim 1992 / 산울림1992) 很近，可串联成一条打卡路线。

>

> #### 🎯 深度精选 — 青鸟 (Aoi Tori / 아오이토리)

> 店名取自「青い鳥 (青鸟)」，正如其名，以日式红豆包·菠萝包等日本面包的正统工艺烘焙。在 Diningcode 等大数据餐饮排名中，长期稳居弘大烘焙TOP5。店面狭小，排队频繁，工作日上午前往最为从容。

>

> #### 🎯 深度精选 — 哈哈奶油包 (Puhaha Cream Bread / 푸하하크림빵)

> 店名已完整道出招牌身份的奶油包专门店。以牛奶奶油为基底，按季节推出伯爵红茶、玉米、开心果等不同口味。开店30分钟~1小时内常态售罄，前往必须提前确认开店时间。

按颜色选也好，按夹心选也好，各有千秋。

  • Sweet Doph (스윗도프) — 视觉感强烈的马卡龙
  • 幻想 (Fantazyt / 판타지트) — 梦幻色彩马卡龙阵容
  • 蓬蓬涅特 (Pomponnette / 퐁포네뜨) — 马卡龙+草莓蛋糕兼营
  • 西桥洞那家咖啡馆 (Seogyo-dong The Cafe / 서교동 그 카페) — 如名字般的街坊隐秘小店
  • 一点五楼 (Iljeom-o Floor / 일점오플로어) — 1.5层概念的小型马卡龙店
  • 咖啡县 (Cafe County / 카페카운티) — 复古咖啡馆风格
  • 贪吃汤姆 (Greedy Tom / 그리디톰) — 角色主题马卡龙
  • 24小时咖啡101 (24h Coffee 101 / 24시커피101) — 24小时营业，深夜常客首选
  • 小大胜利 (Little Big Victory / 리틀빅토리) — 小而强的马卡龙店
  • 莲特 (Lente / 렌테) — 简洁利落的马卡龙·甜点

🎭 特色主题咖啡馆 — 概念即内容 (10家)

主题本身就是店铺身份认同的地方。

  • 冬天驻留的家 (Winter House / 겨울이머무는집) — 四季皆冬的主题空间
  • 感谢自然咖啡 (Thanks Nature Cafe / 땡스네이쳐카페) — 自然·宠物友好概念
  • 943国王十字 (943 King's Cross / 943 킹스크로스) — 哈利·波特9¾站台英伦风
  • 相谈 (Dorandoran / 도란도란) — 旧式韩屋 (한옥 — 韩式传统木构建筑，类似日式町家风格) 格调
  • 奥尔塔宅邸 (Olta Mansion / 오르타 저택) — 欧式宅邸概念打卡圣地
  • A桌 (Table A / 테이블에이) — 兼具照相馆·体验的复合型咖啡馆
  • 见光 (See the Light / 씨더라이트) — 以「光」为概念的氛围咖啡馆
  • 卢西法大宅 (Lucifer Mansion / 루치펠 대저택) — 哥特式宅邸氛围
  • 萌萌喵女仆咖啡 (Moe Moe Kyun Maid Cafe / 모에모에큥 메이드카페) — 日式女仆咖啡馆
  • Oh My女仆咖啡 (Oh My Maid Cafe / 오마이 메이드카페) — 另一家女仆咖啡馆备选

> #### 🎯 深度精选 — 943国王十字 (943 King's Cross / 943 킹스크로스)

> 店名「943」源自哈利·波特的9¾站台。完整还原英国国王十字车站霍格沃茨特快列车概念的英伦风咖啡馆，复古行李箱与学生宿舍装潢、英式甜点 (司康·茶)是核心亮点。哈利·波特粉丝必去。难得的是，作为主题咖啡馆，饮品品质同样扎实，不仅仅是拍照打卡，实际停留体验也很值得。

踏进门的瞬间就忍不住掏出手机的咖啡馆。

  • 可疑百吉饼 (Suspicious Bagel / 수상한베이글) — 百吉饼+感性室内设计
  • 阿贝罗普 (Abelop / 아벨롭) — 氛围感强烈的打卡圣地
  • 空美学 (Gong Mihak / 공미학) — 如名字般的美学空间
  • 哔哔 (Bbip Bbip / 삡삡) — 奇趣风格引爆SNS
  • 玉桂狗甜蜜 (Cinnamoroll Sweet / 시나모롤스위트) — Sanrio玉桂狗主题
  • 贝妮蛋糕 (Beni Cake / 베니케이크) — 蛋糕+氛围感双双入镜
  • Offer咖啡 (Offer Cafe / 오퍼 카페) — 摩登打卡风格
  • 快乐熊日 (Happy Bear Day / 해피베어데이) — 小熊角色主题
  • 屋顶猫咪 (Roofcat / 루프캣이) — 猫咪主题咖啡馆
  • 拉赫勒厨房 (Rahel's Kitchen / 라헬의부엌) — 舒芙蕾+氛围感双重打卡

☕ 大型咖啡馆 — 无需担心座位，尽情久坐 (10家)

工作、开会、长聊——坐上两三个小时也不用看人脸色的地方。

  • 神怡岛家 (Sinidoga / 신이도가) — 韩屋概念大型咖啡馆
  • WON (더블유오앤) — 大型烘焙+咖啡馆
  • 某咖啡 (Meossi Coffee / 머씨커피) — 自家烘焙大型咖啡馆
  • 咖啡公鸣 (Cafe Gongmyeong / 카페 공명) — 烘焙·甜点扎实的大型咖啡馆
  • 咖啡逗号 (Cafe Kkoma / 카페꼼마) — 文学村出版社运营的书+咖啡
  • PITC — 工业风装潢大型咖啡馆
  • 极光咖啡 (Cafe Aurora / 카페 오로라) — 梦幻氛围感突出
  • 8810咖啡公司 (8810 Coffee Company / 8810 커피컴퍼니) — 自家烘焙咖啡专门店
  • 哼铃贝拉 (Humming Bella / 허밍벨라) — 花园·植物概念大型咖啡馆
  • 椰子盒子 (Coconut Box / 코코넛박스) — 咖啡馆+展览复合空间

> #### 🎯 深度精选 — 咖啡逗号 (Cafe Kkoma / 카페꼼마)

> 出版社文学村 (Munhakdongne / 문학동네) 运营的书+咖啡馆。店名「逗号 (comma)」意如其字——为爱书之人提供一个稍作停顿的空间。店内各处陈列着经过精心策展的书籍，可自由取阅。座位充裕，天花板高挑，也是笔记本电脑办公的绝佳场所。弘大虽有许多「书+咖啡」咖啡馆，但论概念深度与运营积累，咖啡逗号最为稳健。
