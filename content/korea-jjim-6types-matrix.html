한국 찜 6종 매트릭스 — 닭찜·갈비찜·아구찜·해물찜·메기찜·찜닭 풀세트

> 부제: 외국인 관광객용 매콤 찜 + 한정식 정통 + MZ 트렌드

ISSUE 03 · #894 · 2026-06-09

🎯 왜 한국 찜 매트릭스인가

외국인 한국 찜 페인포인트 = "찜닭만 알고 다른 찜 모름". 한국 찜 = 한정식 정통 + 매콤 매니아 + MZ 트렌드. 같은 "Korean steamed/braised dish"라도 닭찜 (안동찜닭 정통 #1)·갈비찜 (한정식·궁중 정통)·아구찜 (매콤 #1·MZ 인스타)·해물찜 (회 cluster cross)·메기찜 (전라 정통)·동그랑땡찜 (명절 정통). 외국인은 (a) 안동찜닭 = 전국 #1 매니아 모름 (b) 갈비찜 = 한정식 정통 모름 (c) 아구찜 = 매콤 #1 모름 (d) 메기찜 = 전라 정통 모름. 본 가이드는 6종 매트릭스 + 정통 + 매콤 매니아.

> 한정식 정통 = 갈비찜

> 전라 정통 = 메기찜

🥘 6종 deep dive

🐔 안동찜닭 (Andong-jjimdak) — 정통 #1

  • 시그니처: 안동 정통 #1·간장 매콤·당면·전국 #1
  • 재료: 닭 + 간장·매콤 양념 + 당면·감자·양파·당근
  • 추천 매장: 안동 정통·전국 안동찜닭 cluster·MZ 한식당
  • 가격: 25,000~50,000원/1관 (2~3인)
  • 외국인 친화도: ★★★★★ (#1 정통)

🥩 갈비찜 (Galbi-jjim) — 한정식 #1

  • 시그니처: 한정식 정통·궁중·간장 양념
  • 재료: 소갈비 + 간장·배·당근·표고버섯·잣
  • 추천 매장: 한정식 ([#837](#837))·신라호텔 라연·삼청각
  • 가격: 한정식 코스 40,000~150,000원 (포함) / 단품 30,000~60,000원
  • 외국인 친화도: ★★★★★ (한정식 #1)

🐟 아구찜 (Agu-jjim) — 매콤 #1

  • 시그니처: 매콤 #1·MZ 인스타·콩나물
  • 재료: 아구 (monkfish) + 콩나물·매콤 양념
  • 추천 매장: 마산 정통·서울 노포·MZ 한식당
  • 가격: 25,000~50,000원/1관 (2~3인)
  • 외국인 친화도: ★★★★ (매콤 매니아)

🦀 해물찜 (Haemul-jjim) — 해산물

  • 시그니처: 해산물 cross·매콤
  • 재료: 오징어·새우·조개·콩나물 + 매콤 양념
  • 추천 매장: 자갈치·통영·해물 전문점
  • 가격: 30,000~80,000원/1관 (2~3인)
  • 외국인 친화도: ★★★

🐠 메기찜 (Megi-jjim) — 전라 정통

  • 시그니처: 전라 정통·매콤·노포
  • 재료: 메기 (catfish) + 시래기·매콤 양념
  • 추천 매장: 전라 노포·강원 정통
  • 가격: 20,000~40,000원/1관
  • 외국인 친화도: ★★

🥩 LA갈비찜 (LA-style) — 글로벌

  • 시그니처: 글로벌·MZ 트렌드·미국식
  • 재료: LA 갈비 (얇음) + 간장·배 양념
  • 추천 매장: MZ 한식당·글로벌 매장
  • 가격: 25,000~50,000원/1관
  • 외국인 친화도: ★★★★ (글로벌)

⚠ 외국인 자주 실수 5가지

1. "찜 = 한 가지": 찜 = 6종 매트릭스.

2. "안동찜닭 = 일반": 안동찜닭 = 전국 정통 #1·간장 매콤.

3. "갈비찜 = 비싸기만": 갈비찜 = 한정식 정통·궁중 cluster.

4. "아구찜 = 가벼움": 아구찜 = 매콤 #1 (한국에서 가장 매콤 한 메뉴 중 하나).

5. "메기찜 = 일반": 메기찜 = 전라 정통·노포.

⚙ FAQ 8개

1. 외국인 입문 1순위: 안동찜닭 + 갈비찜.

2. 인스타·vlog: 아구찜 (매콤 #1)·안동찜닭.

3. MZ 트렌드: 아구찜·LA갈비찜.

4. 매콤 매니아: 아구찜 (#1).

5. 한정식 정통: 갈비찜.

6. 알레르기: 해산물·간장 글루텐 사전 고지.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

찜 = 일반 음식·매콤 일부. 임신부·어린이 = OK (매콤 조절). 알레르기 (해산물·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339.

식이 제한 fallback: 할랄·코셔 = 닭·소·해산물 OK·돼지 함유 X / 채식·비건 = 비채식 / 글루텐 free = Tamari.
