🎯 왜 한국 고기 반찬류 매트릭스인가

외국인 한국 고기 반찬 페인포인트 = "BBQ만 알고 있다". 한국 고기 반찬류 = 한정식 주요리 #1 + 글로벌 인지도 불고기·잡채 K-food 트렌드. 같은 "Korean meat side dish"라도 갈비찜 (한정식 메인·기념일)·잡채 (당면 + 야채·정통 #1)·제육볶음 (매콤 돼지·MZ 트렌드)·불고기 (글로벌 K-food)·장조림 (간장 조림 정통)·나물볶음 (들기름·산채 정통) 각자 다른 조리법·페어링. 외국인은 (a) 갈비찜 = 한국 vs 일본 차이 모름 (b) 잡채 = 면류로 오인 (c) 제육 vs 불고기 차이 모름 (d) 장조림 = 일본 츠쿠다니 유사 모름. 본 가이드는 6종 매트릭스 + 한정식 주요리 매니아 + 외국인 입문 우선순위.

> MZ 트렌드 = 제육볶음 + 잡채 + 불고기

🍖 6종 deep dive

🍖 갈비찜 (Galbi-jjim) — 한정식 #1

  • 시그니처: 한정식 메인 #1·기념일·명절 정통
  • 재료: 소갈비 + 간장 + 배 + 마늘 + 양파 + 표고버섯 + 대추·잣
  • 특징: 5~8h 조림·달콤·부드러움·뼈 통째
  • 외국인 친화도: ★★★★★ (한정식 정통)
  • 추천 매장: 한정식집·호텔 한식당·전주 한정식·궁중요리 매장
  • 계절: 연중 (명절 #1)
  • 차이 vs 일본 갈비: 한국 갈비찜 = 조림 정통 / 일본 갈비 = 구이 BBQ

🍜 잡채 (Japchae) — 외국인 입문 #1

  • 시그니처: 정통 한식 #1·글로벌 인지도·한정식 반찬
  • 재료: 당면 (고구마 전분) + 시금치 + 당근 + 양파 + 소고기 + 간장 + 참기름
  • 특징: 달콤·짭짤·고소·면+야채 조합
  • 외국인 친화도: ★★★★★ (글로벌·면류 인지)
  • 종류:
  • 소고기 잡채 (정통)
  • 해물 잡채 (variant)
  • 궁중 잡채 (간장 베이스 정통)
  • MZ 비건 잡채 (고기 X·채식 OK)
  • 추천 매장: 한정식집·가정식·MZ 카페·도시락
  • 계절: 연중 (명절 #1)

🌶 제육볶음 (Jeyuk-bokkeum) — MZ #1

  • 시그니처: 매콤 돼지·직장인 점심 #1·MZ 트렌드
  • 재료: 돼지 (목살·앞다리) + 고추장 + 고춧가루 + 마늘·양파
  • 특징: 매콤·달콤·밥 페어 #1
  • 외국인 친화도: ★★★★★ (MZ·매콤 입문)
  • 추천 매장: 가정식·체인 (제육 전문)·MZ 카페
  • 종류:
  • 정통 제육볶음
  • 간장 제육 (덜 매움)
  • 고추 제육 (매우 매움)
  • 계절: 연중 (점심 #1)

🥩 불고기 (Bulgogi) — 글로벌 #1

  • 시그니처: 글로벌 K-food 인지도 #1 + 외국인 입문 정통
  • 재료: 소고기 (얇게 슬라이스) + 간장 + 배 + 마늘·생강·양파 + 참기름
  • 특징: 달콤·짭짤·연함·BBQ 인지
  • 외국인 친화도: ★★★★★ (글로벌·달콤 입문)
  • 종류:
  • 서울 불고기 (정통·국물 있음·당면 추가)
  • 광양 불고기 (전남·구이형·간장 베이스)
  • 언양 불고기 (울산·다진 고기·매운맛)
  • 궁중 불고기 (간장 정통)
  • 계절: 연중 (입문 #1)

🟫 장조림 (Jangjorim)

  • 시그니처: 간장 조림 정통·도시락·반찬 #1
  • 재료: 소고기 (홍두깨살)·계란·꽈리고추 + 간장 + 마늘·양파
  • 특징: 짭짤·달콤·길게 보관 가능·도시락 정통
  • 외국인 친화도: ★★★★ (일본 츠쿠다니 인지)
  • 추천 매장: 가정식·도시락 매장·한정식 반찬
  • 차이 vs 일본 츠쿠다니: 한국 장조림 = 소고기·계란 중심·짭짤 / 일본 츠쿠다니 = 해산물·달콤. 다른 음식.

🌱 나물볶음 (Namul)

  • 시그니처: 한식 반찬 정통·사찰음식·채식 정통
  • 종류:
  • 시래기 (Siraegi, 무청 말림): 정통·구수
  • 고사리 (Gosari, fern): 산채 정통
  • 콩나물 (Kongnamul, bean sprout): 가성비·아삭
  • 시금치 (Sigeumchi, spinach): 정통
  • 도라지 (Doraji, balloon flower root): 산채
  • 고사리 합 (산채 mix): 사찰
  • 재료: 나물 + 들기름·간장·마늘·참깨
  • 특징: 한식 정통·채식 OK·사찰음식 메인
  • 외국인 친화도: ★★★★ (채식 매니아·사찰 매니아)

한정식·식당 가격 anchor (1인)

  • 가정식 (반찬 5~7종) = 8,000~15,000원
  • 일반 한식당 = 12,000~25,000원
  • 한정식집 (코스) = 40,000~150,000원
  • 호텔 한식당 = 100,000~500,000원

⚠ 외국인 자주 실수 5가지

1. "한국 갈비 = BBQ 갈비": 갈비찜 = 조림·달콤·부드러움. BBQ 갈비 = 구이·매콤·쫄깃. 다른 메뉴.

2. "잡채 = 면류": 잡채 = 당면 + 야채 + 고기 풀세트. 면류 단품 X.

3. "제육 = 불고기": 제육 = 매콤 돼지 / 불고기 = 달콤 소고기. 다른 메뉴.

4. "불고기 = 정통 BBQ": 불고기 = 양념 + 국물·당면 정통. BBQ = 구이 정통.

5. "나물 = 한 종류": 나물 = 6+종 (시래기·고사리·콩나물 등) 각자 다른 식감·맛.

⚙ FAQ 8개

1. 외국인 입문 1순위: 불고기 (글로벌) + 잡채 (정통) → 갈비찜 (한정식) 단계.

2. 인스타·vlog: 갈비찜 한정식·잡채 MZ vlog·제육볶음 매니아.

3. MZ 트렌드: 제육볶음·트러플 잡채·궁중 불고기.

4. 글로벌 트렌드: 불고기 K-food #1·잡채 MZ vlog 글로벌.

5. 채식·할랄·코셔: 나물볶음 = 채식 #1 (사찰음식)·MZ 비건 잡채 일부 / 갈비찜·불고기·제육 = 비채식.

6. 알레르기: 콩 (간장)·해산물 (해물 잡채)·견과류 (잣) 사전 고지.

7. 결제·팁: 카드 OK 多 / 가정식 = 가성비 / 한정식 = 봉사료 10% (호텔) / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

고기 반찬류 = 일반 한식. 임신부 = 갈비찜·불고기 충분히 익혀서 OK. 어린이 = 매운 제육 가감·갈비찜 (뼈) 어린이 주의. 알레르기 (콩·해산물·견과류) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 = 비할랄 (돼지·일반 양념). → 나물볶음·사찰음식 채식 OK / 이태원 할랄 한식 매장 일부.
  • 채식·비건: 나물볶음·MZ 비건 잡채 (고기 X) = OK / 사찰음식 한정식 = #1.
  • 글루텐 free: 간장 (밀) 多. 사전 매장 확인 OR 글루텐 free 간장.
