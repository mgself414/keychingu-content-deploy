韩国紧急电话1330，零慌张指南 — 遇到麻烦第一个要拨的号码

🎯 本指南阅读方法 — 标记规则

韩国是个安全的国家，但记住一个号码会让人安心不少。这篇只专注讲这一个号码。

  • 拨号按钮用方括号：[ 1 ] [ 3 ] [ 3 ] [ 0 ]
  • 客服·机构的应答用「」标注：「这里是Korea Travel Hotline」
  • 用手完成的动作用加粗标注：调成扬声器模式递过去
  • 要原样展示的危急文句用代码格式：请帮帮我 (dowajuseyo 도와주세요)

① 比报警电话更该先记住的号码 — "有麻烦就打1330"

在记住警察(112)或消防(119)之前，先存好这个号码：1330。真正的问题不是危险本身，而是语言障碍——受伤或丢东西时不知道该怎么用韩语报案，才是大多数人慌张的真正原因。1330正是消除这道障碍的窗口。只要记住"不管什么情况，先打1330"，这篇文章的目的就达到了。

② 1330是什么 — 旅游热线档案

项目 内容
运营方 韩国旅游发展局(KTO)旅游咨询·翻译热线
号码 无需区号，直接拨1330
时间 24小时全年无休
语言 韩语 + 8种外语(英语·日语·中文·俄语·越南语·泰语·马来语)
费用 免费(只收通话费)
渠道 电话 + 实时短信聊天

③ 3个号码 — 什么时候打哪个

号码 负责范围 什么时候打
1330 旅游咨询·翻译·各种困难情况 不知道该打哪个号码，先打这个准没错
112 警察 犯罪·丢失物品·事故报案 — 也可经1330转接
119 消防/急救 火灾·急症患者 — 也可经1330转接
  • 直接拨112·119当然也可以，但韩语不通的话很容易在中途卡住。先打1330，转接过去时翻译员会一直跟着。

④ 核心功能 — 112/119三方翻译桥接

1330真正的价值不在于咨询，而在于这项功能。不挂断电话，按下面的顺序走就行。

1. 拨打[ 1 ] [ 3 ] [ 3 ] [ 0 ] → 接线员用英语应答：「这里是Korea Travel Hotline，请问需要什么帮助？」原文 (Korea Travel Hotline입니다, 무엇을 도와드릴까요?)

2. 用英语说明情况("My wallet was stolen near the subway station.")

3. 接线员判断后会把112或119接入三方通话 — 别挂电话，就这样等着

4. 接线员和警察·急救队用韩语沟通的同时，会一直用英语给我做同步翻译

5. 直到报案·出动受理完成为止，接线员会一直保持翻译

也就是说，我只要说英语，从打报案电话到翻译，接线员会全部替我处理。

情况 第一优先应对
身体不适(轻症：感冒·头痛等) 先用药店·便利店常备药 — 详情见#1278药店使用指南
身体不适(重症：高烧·外伤·呼吸困难) 拨打1330 → "It's serious, I need a hospital" → 要求接入119桥接

被宰·服务态度差等旅游投诉 直接向1330反映 — 它也承担旅游不满投诉窗口的角色
迷路了·预约出问题了 不一定是报案情况才能打 — 1330也支持日常翻译咨询

⑥ 拨号 — 画面原样记录

  • 无需区号，输入[ 1 ] [ 3 ] [ 3 ] [ 0 ]后按拨号键
  • 用韩国SIM卡或漫游套餐的话到这一步就结束了。如果是境外漫游状态连不上，加上国家代码，用+82-2-1330的格式重试
  • 还是不行的话，别再浪费时间反复尝试，直接请酒店前台代打电话是最快的办法(参考⑩)

⑦ 觉得打电话有压力的话 — 短信聊天

如果开口说话让人有压力，也可以不打电话，改用1330实时短信聊天。用英语打字说明情况，不用担心发音或周围噪音。不过像三方翻译桥接那种需要立刻转接112/119的紧急情况，还是打电话更快 — 聊天功能更适合不紧急的咨询·翻译请求。

⑨ 慌张场景 — 实际会发生的事和应对

1. 在急诊室但语言不通 — 只要拨通1330，用扬声器模式对着挂号窗口或医护人员就行。接线员会从症状说明到后续指引全程帮忙翻译。

2. 警察来了但沟通不了 — 同样拨打1330，用扬声器模式和警察一起听。从报案受理到笔录陈述，接线员会在中间全程翻译。

这两种情况的关键都是：就算我不会韩语，流程也不会卡住。

⑩ 备用方案 — 连1330都不方便时

  • 酒店前台：很多情况下工作人员可以代打电话或帮忙说明情况。如果住处就在附近，这是最快的办法。
  • Papago翻译画面：把情况用英语输入，把翻译出来的画面直接给对方看的方法 — App安装参考#1230必备App指南。
