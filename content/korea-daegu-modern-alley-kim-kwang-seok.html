🎯 왜 대구 근대골목 + 김광석 거리 가이드인가

대구 근대골목 = 1900년대 한국 근대사 walking 1번지. 청라언덕 (1893년 선교사 사택)·계산성당 (1902년 한국 #2 로마네스크 양식)·3·1만세운동길·김광석 거리 (1964-1996 한국 #1 포크 가수 추모) 4 cluster. 외국인 페인포인트 = (a) 한국 근대사 (1876년 강화도조약~1945년 광복) 인지도 낮음 (b) 김광석 = K-pop 이전 한국 #1 포크 가수·매년 10월 다시부르기 콘서트 (c) 골목투어 영문 시그너 풀세트 (d) 1.5h 코스 = 외국인 입문 fit (e) 카페·MZ 매장 cluster.

본 가이드는 4 cluster 시그니처 + 김광석 매니아 매트릭스 + 1.5h 코스 + 영문 시그너.

🏛 4 cluster deep dive

① 청라언덕 (1893년 선교사 사택)

  • 시그니처: 1893년~ 미국 선교사 사택 cluster·한국 근대 의료 시작
  • 매장: 동산병원 (1899년~·현재 동산의료원 박물관)·선교사 사택 박물관
  • 외국인 친화도: ★★★★ (영문 시그너·교육적)
  • 시간: 09:00~18:00·휴관 월요일·무료

② 계산성당 + 3·1만세운동길

  • 시그니처: 계산성당 (1902년·한국 #2 로마네스크)·3·1만세운동길 (1919년)
  • 계산성당: 김수환 추기경 (1922-2009·한국 가톨릭 매니아 #1) 출신 성당
  • 3·1만세운동길: 1919년 대구 3·1 운동 100주년 (2019년) 재조명
  • 외국인 친화도: ★★★★★ (가톨릭 + 근대사 매니아)

③ 김광석 거리 + 방천시장

  • 시그니처: 김광석 (1964-1996) = 한국 #1 포크 가수·K-pop 이전 시대 거장
  • 김광석 시그니처 곡: "거리에서"·"이등병의 편지"·"너의 결혼식"·"흐린 가을 하늘에 편지를 써"
  • 거리: 김광석 다시그리기 거리 (방천시장 인근)·전체 350m·벽화 + 동상 + 카페
  • 매년 10월 김광석 다시부르기 콘서트 (K-pop 이전 매니아 #1 매트릭스)
  • 외국인 친화도: ★★★★★ (K-pop fit·MZ 매니아·인스타 1번지)

④ 근대골목 카페 cluster

  • 시그니처: 1900년대 양옥 카페 cluster·MZ 매니아·인스타 fit
  • 추천 매니아: 카페 김광석·카페 청라언덕·카페 계산성당
  • 외국인 친화도: ★★★★ (영문 메뉴 일부·결제 카드·픽업 OK)
  • 가격: 커피·디저트 1세트 = 8,000~16,000원/인

🚶 외국인 1.5h 골목투어 코스

시간 동선 활동
10:00~10:30 청라언덕 + 동산병원 박물관 1893년~ 한국 근대 의료 시작
10:30~11:00 계산성당 + 3·1만세운동길 1902년 한국 #2 로마네스크 + 1919년 3·1 운동
11:00~11:30 카페 청라언덕 또는 카페 김광석 커피 + 디저트 (10,000원/인)
11:30~12:00 김광석 거리 + 방천시장 벽화 + 동상 + 인스타

총 소요: 1.5시간·총 비용 = 15,000~25,000원/인 (카페·체험)·박물관 무료

공식 골목투어 (영문): 1.5h·5,000~10,000원/인·매주 토·일·예약 권장

⚠ 외국인 자주 실수 5가지

1. "청라언덕 = 그냥 언덕": 1893년~ 선교사 사택·한국 근대 의료 시작 (동산병원). 박물관 영문 풀세트.

2. "계산성당 = 일반 성당": 1902년 한국 #2 로마네스크 양식·김수환 추기경 출신. 가톨릭 매니아 매트릭스 #1.

3. "김광석 = 잘 모름": K-pop 이전 한국 #1 포크 가수 (1964-1996)·"거리에서"·"이등병의 편지" = 한국인 90% 인지도. MZ K-pop fit.

4. "근대골목 = 단순 산책": 4 cluster 풀세트 = 1.5h 코스·외국인 영문 시그너·골목투어 매니아 매트릭스.

5. "카페 cluster = 일반 카페": 1900년대 양옥 + 김광석 시그니처 = 인스타 1번지 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 청라언덕 + 계산성당 + 김광석 거리 = 1.5h 코스.

2. 공식 골목투어: 매주 토·일·1.5h·5,000~10,000원/인·영문 시그너 + 영문 안내 풀세트.

3. 김광석 매니아 시즌: 매년 10월 김광석 다시부르기 콘서트 (방천시장 일대·외국인 #1 매니아).

4. 카페 추천: 카페 김광석·카페 청라언덕·카페 계산성당 = 인스타 1번지·외국인 친화 영문 메뉴 多.

5. 시즌: 봄 (4~5월)·가을 (10월 김광석 콘서트) = 외국인 #1. 여름·겨울 = 폭염·영하 추위 주의.

6. 추천 페르소나: 가족·시니어·문화 매니아 = 청라언덕 + 계산성당 / MZ·K-pop 매니아 = 김광석 거리 + 카페 cluster.

⚠ 의료·안전 disclaimer

청라언덕·계산성당·김광석 거리 = 무료·안전·평지 walking. 임신부·시니어·휠체어 = 일부 가파른 골목 주의. 카페 = 알레르기 (땅콩·우유·계란·밀가루) 사전 고지. 의료 응급 ☎ 1339 (영문) / ☎ 1330 (관광 통역).
