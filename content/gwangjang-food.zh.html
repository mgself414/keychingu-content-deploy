外国游客常犯的5个错误

1. 午餐高峰 (12:00~13:30) 首次前往

广藏市场 (Gwangjang Sijang / 광장시장) 会在同一时间段内涌入韩国 (Hanguk / 한국) 上班族 + 韩国 (Hanguk / 한국) 游客 + 外国游客。绿豆饼 (bindaetteok / 빈대떡) 巷的座位在 12:30~13:30 最为拥挤。如果是首次访问，建议 11:00 入场 → 12:00 找空位 或 14:30 以后享用晚午餐。

2. 误以为“绿豆饼 (bindaetteok / 빈대떡) 都差不多”

广藏市场 (Gwangjang Sijang / 광장시장) 的绿豆饼 (bindaetteok / 빈대떡) 每家店的 大小、厚度、绿豆比例、油的种类、是否有座位 都不同。元祖顺熙家 (Wonjo Sunhuine / 원조순희네) 经过传统验证，朴家 (Bakgane / 박가네) 有现场煎制的视觉乐趣，通大姐家 (Tongkeunnuiine / 통큰누이네) 则以大小和性价比取胜 — 即使都花 ₩7,000，体验也大相径庭。请参考正文 §绿豆饼3巨头 (bindaetteok 3daejang / 빈대떡 3대장) 部分。

3. 对生拌牛肉 (yukhoe / 육회) 过于自信 — 肠胃不适者请跳过

广藏 (Gwangjang / 광장) 的生拌牛肉 (yukhoe / 육회) 是韩国 (Hanguk / 한국) 生拌牛肉 (yukhoe / 육회) 的发源地，但 30%的外国游客表示肠胃不适。如果平时不常吃生食 (如寿司等)，首次访问时请跳过。若要尝试，请将 香油·大蒜·蛋黄 全部拌匀食用，并搭配米酒 (makgeolli / 막걸리) 或啤酒。

4. 只带卡而无法支付

绿豆饼 (bindaetteok / 빈대떡) 老字号 (nopo / 노포) + 米酒 (makgeolli / 막걸리) + 麻药紫菜包饭 (mayak gimbap / 마약김밥) 60%需现金支付。即使是可刷卡的店铺，也常出现刷卡机故障或通讯中断。请携带 ₩30,000 以上现金 + 银行卡。可利用钟路5街站 (Jongno 5-ga Station / 종로5가역) 1号出口的 GS25·CU 便利店 (pyeonuijeom / 편의점) ATM。

5. 携带大件行李箱或背包

绿豆饼 (bindaetteok / 빈대떡) 巷的通道宽度仅 1.5米。拖着行李箱进入会碰到两旁的顾客，店主也会提醒“请把行李放在外面”。请将大件行李寄存在 住宿处或车站储物柜 (钟路5街站 (Jongno 5-ga Station / 종로5가역) 投币储物柜 ₩2,000~5,000)，只带小包前往。

  • 建议携带肠胃药 (旅行中身体状况多变)

④ 米肠 (Sundae / 순대)·辣炒年糕 (Tteokbokki / 떡볶이)

位置: 美食街辣炒年糕 (tteokbokki / 떡볶이) 巷 (入口附近)

价格: 米肠 (sundae / 순대) ₩5,000~8,000 / 辣炒年糕 (tteokbokki / 떡볶이) ₩5,000~8,000

特点: 粉丝米肠 (dangmyeon sundae / 당면 순대) (Q弹), 什锦米肠 (modum sundae / 모둠 순대) (含内脏)。辣炒年糕 (tteokbokki / 떡볶이) 可要求调整辣度 (“덜 매워요” = “deol mae-wo-yo” = “少辣”)。

⑤ 宴会面 (Janchi Guksu / 잔치국수)·刀削面 (Kalguksu / 칼국su)

位置: 美食街尽头

价格: 宴会面 (janchi guksu / 잔치국su) ₩3,000~5,000 / 刀削面 (kalguksu / 칼국수) ₩6,000~7,000

特点:

  • ₩3,000~₩4,000 的宴会面 (janchi guksu / 잔치국수) 店可无限续碗 (不用担心份量不足)
  • 刀削面 (kalguksu / 칼국수) 为手工刀削面 (son kalguksu / 손칼국수)，汤头浓郁

⑥ 糖饼 (Hotteok / 호떡)·麻花 (Kkwabaegi / 꽈배기)·甜甜圈 (Donut / 도넛)

位置: 美食街出口处 (甜点街)

价格: ₩1,500~3,000/个

特点: 刚炸好的麻花 (kkwabaegi / 꽈배기)，糖浆丰富的糖饼 (hotteok / 호떡)。适合作为甜点收尾。

⑦ 米酒 (Makgeolli / 막걸리)·传统酒 (Jeontongju / 전통주) — 绿豆饼 (bindaetteok / 빈대떡) 的绝配饮品

价格: 米酒 (makgeolli / 막걸리) 1瓶 ₩4,000~5,000 / 传统酒 (jeontongju / 전통ju) ₩6,000~10,000

特点:

  • 绿豆饼 (bindaetteok / 빈대떡) + 米酒 (makgeolli / 막걸리) 是韩国 (Hanguk / 한국) 上班族的标准搭配 (尤其是在下雨天)
  • 绿豆饼 (bindaetteok / 빈대떡) 巷的所有店铺都出售米酒 (makgeolli / 막걸리)
  • 酒精度6%，口感清淡 — 外国游客负担较小

⑧ 夜间布帐马车 (Yagan Pocha / 야간 포차) (晚上7点以后)

位置: 美食街旁的露天摊位 (yajan / 야장) 街

价格: 人均 ₩20,000~40,000

特点:

  • 晚上7点以后，路边帐篷摊位 (pocha / 포차) 展开的街道
  • 鸡爪 (dakbal / 닭발)·牛肠 (gopchang / 곱창)·煎饼 (jeon / 전)·海鲜葱饼 (haemul pajeon / 해물파전)·烧酒 (soju / 소주)
  • 外国游客团体请避免深夜单独前往 — 以韩国 (Hanguk / 한국) 老顾客 + 饮酒氛围为主

广藏 (Gwangjang / 광장) 体验5选 (非餐饮)

1. 逛韩服 (hanbok / 한복) 面料市场 (1楼西侧)

批发销售韩国 (Hanguk / 한국) 传统韩服 (hanbok / 한복) 面料。即使只是逛逛，也能感受到丰富的色彩和刺绣细节。也有部分外国游客会直接定制韩服 (hanbok / 한복)。

2. 2楼旧货市场淘宝 (相关话题 #50)

美食市场头顶的2楼是进口旧货 (guje / 구제) 复古商品的天堂。淘宝后在1楼享用午餐是广藏 (Gwangjang / 광장) 的一大特色。详细内容请参考 #50 广藏市场 (Gwangjang Sijang / 광장시장) 旧货市场 (Guje Sanga / 구제상가)。

3. 市场小巷拍照点

狭窄的通道、五颜六色的招牌、现场煎制 (jeon / 전) 的场景。广藏 (Gwangjang / 광장) 是首尔 (Seoul / 서울) 最适合拍照的市场。但请注意，未经允许请勿拍摄商贩面部。

4. 米酒 (makgeolli / 막걸리) + 绿豆饼 (bindaetteok / 빈대떡) 搭配 (当地人模式)

1张绿豆饼 (bindaetteok / 빈대떡) + 1瓶米酒 (makgeolli / 막걸리) + 1盘麻药紫菜包饭 (mayak gimbap / 마약김밥) = ₩15,000，即可完成韩国 (Hanguk / 한국) 上班族的午餐酒局。下雨天 前往更具韩国 (Hanguk / 한국) 风情。

5. 凌晨市场 (当地人模式)

凌晨4点~6点可观察到韩服 (hanbok / 한복)·被褥的批发交易场景。但一般外国游客不推荐，拍照需征得同意。

外国游客注意事项10条 (清单)

✅ 卫生 — 新鲜度判断

  • 顾客络绎不绝的店铺 = 新鲜。空荡荡的店铺 = 避开
  • 生拌牛肉 (yukhoe / 육회)·生蚝在当天午餐时间最安全

✅ 防止被宰

  • 只进入菜单上标有价格的店铺
  • 如果无菜单的老字号 (nopo / 노포) 叫价超过 ₩20,000，请离开

✅ 狭窄巷道礼仪

  • 站着吃 OK (韩国 (Hanguk / 한국) 市场文化)
  • 行李放在脚边，不要堵塞通道
  • 不要为了拍照站在队伍中间

✅ 拍照礼仪

  • 食物·招牌·市场风景 OK
  • 商贩面部·其他顾客 × (需征得同意)

✅ 支付·ATM

  • 携带 ₩30,000 以上现金
  • ATM: 钟路5街站 (Jongno 5-ga Station / 종로5가역) 1号出口 GS25/CU 便利店 (pyeonuijeom / 편의점)，市场入口农协 (Nonghyup / 농협) ATM

✅ 过敏·猪肉·辣度

  • 不吃猪肉 → 绿豆饼 (bindaetteok / 빈대떡) (只标明绿豆), 麻药紫菜包饭 (mayak gimbap / 마약김밥), 宴会面 (janchi guksu / 잔치국수) OK
  • 不吃牛肉 → 生拌牛肉 (yukhoe / 육회)·牛骨汤 (so sagol guk / 소 사골 국) ×
  • 不太能吃辣 → 说“덜 매워요 (deol mae-wo-yo)” (少辣) 或跳过辣炒年糕 (tteokbokki / 떡볶이)

✅ 饮酒礼仪

  • 倒米酒 (makgeolli / 막걸리) 时双手，接酒时双手 (韩国 (Hanguk / 한국) 饮酒礼仪)
  • 在杯子空之前再次斟满是韩式 (Hansik / 한식) 习惯
  • 街头酩酊大醉·喧哗在韩国 (Hanguk / 한국) 也不受欢迎

✅ 洗手间·纸巾

  • 市场内有1~2个公共洗手间，钟路5街站 (Jongno 5-ga Station / 종로5가역) 洗手间更干净
  • 请自备纸巾 — 多数路边摊没有纸巾

✅ 周日·节假日休息

  • 绿豆饼 (bindaetteok / 빈대떡) 巷·美食街几乎全年无休
  • 韩服 (hanbok / 한복) 面料·2楼旧货市场 (guje / 구제) 约50%的店铺周日休息

✅ 扒窃·行李

  • 韩国 (Hanguk / 한국) 的安全水平在OECD国家中最低。但狭窄巷道·人潮拥挤 = 包包背在前面
  • 大件行李箱·背包请寄存在住宿处或车站投币储物柜

常见问题解答 (FAQ)

Q1. 会说英语吗？

绿豆饼 (bindaetteok / 빈대떡) 巷·麻药紫菜包饭 (mayak gimbap / 마약김밥) 店铺很多会说英语 (因为外国游客多)。元祖顺熙家 (Wonjo Sunhuine / 원조순희네) 有4国语言菜单。深入的老字号 (nopo / 노포) 主要说韩语 (Hangugeo / 한국어)，但指着菜单点餐即可。

Q2. 可以刷卡吗？

60% 的店铺可以。但刷卡机常故障，所以必须备好 ₩30,000 现金。

Q3. 如果只有1小时时间怎么办？

11:00 入场 → 元祖顺熙家 (Wonjo Sunhuine / 원조순희네) 绿豆饼 (bindaetteok / 빈대떡) 1张 + 米酒 (makgeolli / 막걸리) (20分钟) → 母女紫菜包饭 (Monyeo Gimbap / 모녀김밥) 麻药紫菜包饭 (mayak gimbap / 마약김밥) 一盘 (15分钟) → 糖饼 (hotteok / 호떡) 甜点 (15分钟) → 12:00 离场。可以快速品尝美食。

Q4. 素食者可以吃什么？

绿豆饼 (bindaetteok / 빈대떡) (只选绿豆，确认不含肉类·海鲜的菜单) / 宴会面 (janchi guksu / 잔치국su) (不含肉汤的店铺) / 糖饼 (hotteok / 호떡)·麻花 (kkwabaegi / 꽈배기) / 年糕 (tteok / 떡) 类。但韩国 (Hanguk / 한국) 的素食很难100%验证 — 汤底·油 可能含有动物成分，请务必注明。

Q5. 可以带小孩去吗？

除了午餐高峰期，其他时间都可以。狭窄的通道 + 热腾腾的煎饼旁 = 婴儿车 ×，背带 OK。儿童菜单推荐麻药紫菜包饭 (mayak gimbap / 마약김밥)·宴会面 (janchi guksu / 잔치국su)·糖饼 (hotteok / 호떡)。

Q6. 和家人 (父母) 同行呢？

元祖顺熙家 (Wonjo Sunhuine / 원조순희네) 是家庭同行的首选 — 有座位，菜单多国语言，价格明确。朴家 (Bakgane / 박가네) 可能因站着吃而不太方便。

季节性注意事项

春季 (3~5月)

  • 外国游客激增季节。建议平日上午前往
  • 绿豆饼 (bindaetteok / 빈대떡) 巷会扩大户外座位区

夏季 (6~8月)

  • 市场内非常炎热 (部分有空调)。绿豆饼 (bindaetteok / 빈대떡) + 米酒 (makgeolli / 막걸리) 依然受欢迎
  • 生拌牛肉 (yukhoe / 육회) 优先考虑新鲜度 — 午餐时间尝试，晚餐时间避免

秋季 (9~11月)

  • 广藏 (Gwangjang / 광장) 最佳季节 — 天气 + 绿豆饼 (bindaetteok / 빈대떡)·米酒 (makgeolli / 막걸리) 组合最完美
  • 10月平日上午是黄金时段

冬季 (12~2月)

  • 绿豆饼 (bindaetteok / 빈대떡) + 米酒 (makgeolli / 막걸리) 季节。温暖的宴会面 (janchi guksu / 잔치국수) 也受欢迎
  • 露天摊位 (yajan / 야장) 会使用电暖炉取暖。外国游客建议在11月·3月尝试露天摊位 (yajan / 야장)
