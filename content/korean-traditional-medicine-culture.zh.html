韩国韩医·韩药文化 — 补药·针·灸，调理身体的韩国式医学

> 韩医院 (Hanuiwon / 한의원，与西医分立的体系) · 针 · 灸 · 拔罐 · 韩药 (Hanyak / 한약) · 补药 (Boyak / 보약) · 四象体质医学 · 东医宝鉴 (Donguibogam / 동의보감) — 为外国人解读韩国韩医·韩药文化。这并非“韩药对身体好”，而是“为什么韩国在医院之外另设韩医院 (Hanuiwon / 한의원)，为什么韩国人想用‘平衡’来调理身体，以及它如何与现代医学并行”。

在韩国街头漫步时，有一种招牌会让外国人歪头不解。在普通医院 (医院 / 의원) 旁边，同样进行诊疗，却挂着另一块写有韩医院 (Hanuiwon / 한의원) 的招牌。走进去，会看到身穿白大褂的医生在把脉，在身上扎针 (Ch'im / 침)，点燃艾草做灸 (Tteum / 뜸)，并开苦涩的韩药 (Hanyak / 한약)。外国人的第一个问题几乎都一样——“这是医院，还是民间疗法？”

答案是两者都不是。 韩国的韩医学 (Hanuihak / 한의학，Korean traditional medicine) 是与西医在法律上对等、但相互独立的医疗体系。韩医师 (Hanuisa / 한의사) 是修完六年制大学并通过国家考试的持照医疗人员，韩医院 (Hanuiwon / 한의원) 则是适用医疗保险的体制内医疗机构。本文并非介绍“哪家韩方医院好”(→ 那是地点指南)，而是解读韩国人为什么把身体看作‘平衡’，韩医学治什么、怎么治，以及它如何与现代医学并行。我们不会武断地断定疗效，而是诚实地传达传统认知与研究现状。这是韩国文化解读系列第74篇。

★ 一目了然 — 韩方四大疗法

疗法 韩语/英语 做什么 传统上用于
针 针 (鍼，Ch'im / 침) · acupuncture 将细针扎入经穴 (Gyeonghyeol / 경혈) 以调节气 (Gi / 기) 的运行 疼痛·肌肉骨骼·僵硬等
灸 灸 (Tteum / 뜸) · moxibustion 点燃晒干的艾草 (mugwort) 温热刺激经穴 寒症·消化·慢性疲劳等
拔罐 拔罐 (附缸，Buhang / 부항) · cupping 将罐内抽成真空贴于皮肤以刺激循环 肩·背僵硬、酸痛等
韩药 韩药 (韓藥，Hanyak / 한약) · herbal medicine 将药草煎成汤药·丸·粉末服用 (含补药) 按体质·症状进行补 (Bo / 보) 与治 (Chi / 치)

> 上述“传统上用于”指的是传统认知与临床中所应用的领域，并不意味着所有疗效都已被现代科学同等证实(参见第⑥节)。具体疾患建议咨询韩医师·医师。

⚠️ 外国人常有的3种误解

1. “韩医院 (Hanuiwon / 한의원) = 非体制内的民间疗法 (folk remedy)” ❌ — 韩医学在韩国是与西医对等的持照医疗。韩医师 (Hanuisa / 한의사) 须毕业于六年制韩医科大学 (或韩医学专门大学院) 并通过国家考试，韩医院 (Hanuiwon / 한의원) 是适用医疗保险的正规医疗机构。这与街头无照施术不同。

2. “韩药是‘天然’的，所以肯定绝对安全” ❌ — ‘天然’并不等于‘无害’。韩药 (Hanyak / 한약) 也可能存在体质·与其他药物相互作用·肝脏负担的可能，因此若正在服用西药，同时告知韩医师与医师两方才安全。孕妇·慢性病患者尤其建议咨询后再服用。

3. “韩医学 vs 西医 — 必须二选一” ❌ — 多数韩国人是两者同时·交替使用。急性疾病·手术·检查走西医，慢性疼痛·恢复·体质管理走韩医，这样并行很常见。实际情况不是对立，而是并用 (Byeongyong / 병용)。

① 韩医学是什么 — 不是“杀死疾病”，而是“调和身体”的医学

韩医学的出发点与西医不同。如果说西医通常着眼于找出并清除病原体·病变，那么韩医学则认为，当身体整体的平衡 (均衡，Gyunhyeong / 균형) 被打破时，疾病便会到来。解释这种平衡的核心概念是阴阳 (Eumyang / 음양) 和气 (Gi / 기)。

  • 阴阳 (Eumyang / 음양): 将身体看作冷/热、内/外、虚 (Heo / 허) / 实 (Sil / 실) 等对立对的平衡。一旦偏向某一方，便成为疾病。
  • 气 (Gi / 기): 在身体中运行的生命能量。当气受阻或虚弱时，被认为会以疼痛·疲劳·消化不良等症状显现。

因此，即使是同样的‘头痛’，韩医师 (Hanuisa / 한의사) 也会观察患者的体质·气色·脉象·生活，因人而异地施治。其核心在于，不是“一个病名配一种药”，而是看“这个人的什么失衡了”。这种思维也延伸为药食同源 (Yaksik-dongwon / 약식동원) — “药与食同根” — 与韩国人通过日常饮食调理身体的补养 (Boyang / 보양) 文化相通 (→ 补养的代表根源参见 #1198)。

> ※ 阴阳·气是韩医学的理论框架 (说明模型)，与现代生物学测量概念不同。在此以“韩国人如何看待身体”这一文化视角来介绍。

② 针·灸·拔罐 — 外国人最先接触的韩方

这是在K-剧或古装剧里多少都见过一次的场景。这三者都是不靠服药、而在身体表面给予刺激的疗法。

  • 针 (鍼，Ch'im / 침，acupuncture): 将细如发丝的针扎入身体特定的点位，即经穴 (Gyeonghyeol / 경혈)，被认为可以调节气的运行。传统上多用于疼痛·肌肉骨骼系统·僵硬等。它也是全球范围内研究·应用最广的韩方疗法。
  • 灸 (灸，Tteum / 뜸，moxibustion): 将晒干的艾草 (쑥，Ssuk / 쑥，mugwort) 揉成团点燃，温热刺激经穴。可贴近皮肤直接施灸 (直接灸)，或间接施灸 (间接灸)。传统上用于寒症·消化·慢性疲劳等。
  • 拔罐 (附缸，Buhang / 부항，cupping): 将玻璃·塑料罐内抽成真空贴于皮肤，刺激该部位的循环。取下后会留下圆形印记，因运动员贴于肩·背而为国外所知。传统上用于肩·背僵硬、酸痛。

这些施术原则上应在有资质的韩医院 (Hanuiwon / 한의원) 卫生地接受。是否使用一次性灭菌针等，在正规医疗机构都会得到遵守。

> 实战: 外国人若初次体验韩方，针·拔罐的入门门槛较低。多用于疼痛·旅途疲劳·僵硬。但若有出血·孕娠·皮肤疾病等情况，务必事先告知。

③ 韩药与补药 — 一包苦涩汤药中蕴含的补养文化

提到韩方，便会想到又苦又浓的褐色汤药。韩药 (Hanyak / 한약) 是按处方将多种药草煎制而成，形态有汤药 (Tangyak / 탕약，煎出的药液)·丸 (Hwan / 환，药丸)·粉末等。通常以一次服用量装袋的贴药 (Cheopyak / 첩약) 形态领取。

韩药之中，韩国人最熟悉的便是补药 (Boyak / 보약)。补药与其说是直接攻击疾病，不如说是着眼于补 (Bo / 보) 益气力、恢复身体的处方。代表性的有使用人参·茯苓 (Bokryeong / 복령)·蜂蜜等的琼玉膏 (Kyungokgo / 경옥고) 这类补养处方，自朝鲜 (Joseon / 조선) 时代流传至今。韩国人尤其在气力下降的换季、大考·考生、产后恢复、酷暑的夏天有寻求补药的文化——夏天补养食·补药消费增加，是出于“补 (Bo / 보) 益被暑热耗损的身体”的认知 (夏季补养·伏日 (Boknal / 복날) 文化与 #1198 人参·红参 explainer 一起看更佳)。

> ※ 补药·韩药的疗效基于传统认知与临床经验，个别处方的科学证实程度因处方·症状而异。其核心不是“吃了就一定会好”，而是由韩医师根据体质·状态开方并观察经过。若有正在服用的药·宿疾，务必告知。

④ 四象体质医学 — “每个人体质各异”这一韩国独有的医学

即便在韩医学之内，韩国独立发展出的理论便是四象体质医学 (四象体质医学，Sasang-chejil-uihak / 사상체질의학，即四象医学，Sasang-uihak / 사상의학)。朝鲜末期的医学家李济马 (Lee Je-ma / 이제마) 在著作《东医寿世保元 (Donguisusebowon / 동의수세보원)》(1894年著述，1901年出版) 中将其体系化。

核心是“人天生的体质分为四种，每种体质的身体强弱·性格·相宜的食物与药各不相同”。因此认为，应该针对同一种病配以适合体质的处方，而非同一种药。

  • 太阳人 (Taeyangin / 태양인) · 少阳人 (Soyangin / 소양인) · 太阴人 (Taeumin / 태음인) · 少阴人 (Soeumin / 소음인) — 分为四种体质。
  • 据说韩国人太阴人 (Taeumin / 태음인) 的比例最高。
  • 认为应依体质而异其生活·饮食摄生 (Seopsaeng / 섭생) 这一点，很好地体现了韩医学“审视整个身体”的哲学。

四象医学因比起“标准化的单一治疗”更早强调个人定制 (personalized) 而被有趣地接受，但体质分类的客观标准·诊断的可重现性仍是学界持续研究·讨论的主题。对外国人而言，建议以“韩国有一种把人看作四种类型的传统医学理论”这样的文化趣味来接触。

⑤ 东医宝鉴与药令市 — 韩方的‘书’与‘市场’

韩方文化有两个象征性的支柱。一个是书，一个是市场。

  • 东医宝鉴 (东医宝鉴，Donguibogam / 동의보감): 御医许浚 (Heo Jun / 허준) 于1610年完成、1613年刊行的朝鲜最高医学书。它将当时为止的医学理论与处方以独创的分类体系集大成，被评价为东亚医学史上屈指可数的著作。2009年随着列入联合国教科文组织世界记录遗产 (UNESCO Memory of the World)，其价值获得国际认可。也曾多次被搬上电视剧·电影，为韩国人所熟悉。
  • 首尔药令市 (庆东市场) (首尔药令市·庆东市场，Seoul Yangnyeongsi · Gyeongdong Market / 서울약령시·경동시장): 形成于首尔东大门区祭基洞 (Jegi-dong / 제기동) 一带的国内最大韩药材专门市场。1960年以庆东市场起步，1995年正式命名为“首尔药令市”，据说承担着全国韩药材流通的很大份额。如山堆积着各种药草的巷子、药材的香气、煎制并打包贴药 (Cheopyak / 첩약) 的药铺鳞次栉比。首尔韩方振兴中心·韩医药博物馆也在此，是亲眼观看并学习韩方的好去处。

> 实战: 外国人若想‘观赏’韩方氛围，首尔药令市 (祭基洞) 的漫步是不错的选择。比起出于好奇随便买来吃，建议以眼·香来体验，服用则经过韩医院 (Hanuiwon / 한의원) 咨询。

⑥ 与现代医学的并行，以及关于科学依据的争议 (客观地)

这是本文必须最诚实对待的部分。韩医学虽是受欢迎且已制度化的医疗，但其疗效并非全部都被现代科学同等证实。 让我们平衡地看待两方面。

在体制内并行这一事实

  • 韩国是医疗二元化 (Iwonhwa / 이원화) 体系。西医与韩医师各持执照，韩医院 (Hanuiwon / 한의원)·韩方医院是适用医疗保险的体制内医疗机构 (1951年国民医疗法奠定了二元体系的法律基础)。
  • 因此韩国人将韩方与西方作为选项而非对立来运用——检查·手术·急救走西方，慢性疼痛·恢复·体质管理走韩方。

然而科学依据因领域而异

  • 关于针·灸等的临床研究很多，但韩国国内的多数研究被指出存在样本数不足·对照组设计·追踪观察的局限等方法论弱点，因此系统性文献综述的共同评价是有许多领域难以明确得出“有效/无效”的结论。
  • 在部分疼痛·症状上有暗示其可能性的研究，而在某些领域也有结果显示缺乏有说服力的依据。也就是说，“一直以来传统使用”与“科学上已证实”是两回事。
  • 学界认为，需要更严谨的研究与整合医学 (integrative medicine) 路径。

那么所谓平衡的态度便是

  • 既不盲信韩医学 (过度断定疗效)，也不贬低它 (整体当作迷信对待)。把它在韩国社会实际运作的体制内医疗这一事实，与疗效证实因领域而异、仍在进行中这一事实一并接受，才是准确的。

> 为外国人准备的安全原则: 可以体验韩方，但 ① 在有资质的韩医院 (Hanuiwon / 한의원) 接受，② 务必告知正在服用的药·宿疾·孕娠，③ 急性·严重症状以西方诊疗为先。把韩方看作与西方一同并行的选项，而非替代西方，才是最安全的。

⑦ 外国人的韩方体验 — 该如何接触为好

韩方在韩国旅行中可以成为一种独特的文化体验。只是，比起期待‘治疗’，以文化·养生 (wellness) 体验的方式来接触会更轻松。

  • 轻松入门: 为旅途疲劳·僵硬·疼痛而尝试针·拔罐的韩医院 (Hanuiwon / 한의원) 之行。韩方茶 (Hanbangcha / 한방차)·韩方水疗 (汗蒸) 这类养生型体验入门门槛也很低 (韩方茶与 #1192 传统茶 explainer 相连)。
  • 观赏·学习: 在首尔药令市·韩医药博物馆亲眼观看韩药材与韩方的历史。以观看·闻香的体验为主，而非买来吃。
  • 务必遵守: ① 在正规韩医院，② 确认是否可提供翻译·英语，③ 事先告知过敏·所服药物·孕娠·宿疾，④ 警惕断定疗效的夸大广告。

> 实战: 若把韩方期待成“神秘的包治百病”，容易失望；若当作“迷信”而无视，则会错过韩国文化的一道纹理。“体验把身体看作平衡的韩国式思维” 这样的心态最为契合。

❓ 外国人常见问题 (FAQ)

  • 韩医院与普通医院有什么不同？ — 韩医院 (Hanuiwon / 한의원) 是以针·灸·拔罐·韩药调理身体平衡的韩医学医疗机构，普通医院/医院则是现代西医机构。在韩国两者都是适用执照·医疗保险的体制内医疗，许多韩国人并行使用两者。
  • 韩药安全吗？ — ‘天然’并不意味着绝对安全。可能存在体质·与其他药物相互作用·肝脏负担的可能，因此把正在服用的药·宿疾·孕娠告知韩医师 (Hanuisa / 한의사)·医师才安全。处方·管理是关键。
  • 针痛吗？ — 针非常细，据说通常强烈的疼痛较少。不过因人·因部位感受各异，若是初次，请事先与韩医师商量能否安心接受。
  • 韩方真的有效吗？ — 因领域而异。部分疼痛·症状上有暗示其可能性的研究，但科学证实不充分或仍在进行中的领域也很多。请记住“一直以来传统使用”与“已证实”是两回事，严重症状以西方诊疗为先才安全。
  • 外国人也能接受韩方吗？ — 可以。事先确认可提供英语·翻译的韩医院 (Hanuiwon / 한의원)，并告知过敏·所服药物·宿疾即可。针·拔罐·韩方茶体验作为入门较为稳妥。
