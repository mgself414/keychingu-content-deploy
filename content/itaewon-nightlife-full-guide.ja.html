外国人イテウォンナイトライフフルガイド

ウイスキー・カクテル・クラブ・ライブ — 外国 hub 5タイプ 25ヶ所 + タイムゾーン hop マトリックス

梨泰院は1945年米軍基地時代から80年外国人nightlife hub。米軍基地平沢移転（2017）以降も漢南・解放村と連携してソウル外国人nightlife 1順位維持。ウイスキーバー・カクテルダイニング・クラブ・ライブ音楽・インディーパブまで5タイプ25ヶ所 + 外国人fitタイムゾーン hopマトリックス + 安全・予算・dress codeマトリックス。

1. 梨泰院・ハンナム nightlife 風景

外国人の割合

  • 梨泰院（イテウォン）日平均訪問外国人約1万人（ソウル市統計2024）
  • 週末夕方外国人比率30-40%(韓国平均1.5%の20倍)
  • 英語fluent店舗多数・多様な国籍（アメリカ・ヨーロッパ・中東・東南アジア）

タイムゾーン

  • 17-19時：ダイニング・ハッピーアワー（安い）
  • 19-22時：ディナー+カクテル
  • 22-02時：ウイスキー・クラブ・ライブ
  • 02-06時：クラブ・深夜パブ・24時食堂

権力 sub-cluster

  • 梨泰院メイン：クラブ・ダイニングバー密度top
  • 経理短路: インディーパブ・路地・MZ
  • ハンナム：ウイスキーバー・ラグジュアリー・ギャラリー隣接
  • 解放村: 丘 cafe + インディーパブ・サンセット

8. 外国人のfit Tips

英語の可能性

  • 上位: コムダビチュード・サウスサイドパーラー・エスコンディド・Volnost・ホテル lounge (英語 fluent・外国人定番)
  • 中上: ジャクソンピザ・Made・Sound (英語メニュー・basic英語)
  • ローカル: ノガリ路地・伝統酒パブ (picture menu・翻訳アプリ)

Dress code

  • クラブ (Volnost・Made・Sound): smart casual・sneaker OK・ショーツ・スリッパ X
  • ウイスキー bar: smart casual~formal (入ったビチュード・キャスク)
  • ホテル lounge: formal・ジャケット推奨
  • インディーパブ・ライブ: casual OK

予算（1名1泊）

  • Pattern Aウイスキーdeep：￥150,000～400,000（ディナー＋ウイスキー）
  • Pattern Bクラブ: ¥80,000～200,000 (入場+ドリンク)
  • Pattern Cライブ: ¥60,000～150,000
  • Pattern D 韓国 unique: ¥50,000～120,000

ペルソナ星

  • アメリカヒップスター: Pattern B (梨泰院クラブ・DJ)
  • ヨーロッパ sophisticate: Pattern A (ハンナムウイスキー)
  • 音楽 lover: Pattern C (ライブ)
  • foodie + パブ: Pattern D (韓国 unique)
  • special occasion: ホテルラウンジ+ハンナムウイスキー
  • LGBTQ+ friendly: ケーキショップ・梨泰院メインstrip (多数店舗)

安全ガイド

  • 梨泰院は安全圏域: 外国のhub・24時間人派
  • 飲酒後帰り：タクシー（カカオT）または地下鉄（24時夜明けX・5時初回）
  • 現金+カード: クラブ・バーはカードOK / 露店・伝統酒パブ現金
  • drink spiking 注意: 飲み物無防備に置かないX (グローバル nightlife 一般推奨)
  • 6号線梨泰院駅：夜明け0時終止→タクシーを推奨
  • 外国人安全:韓国nightlifeはグローバル平均より安全(低い暴力犯罪率)

シーズン別

  • 春(4-5月): 梨泰院・ハンナム outdoor ダイニングバー
  • 夏（6-8月）：解放村サンセットライブ+漢江屋外
  • 秋（10-11月）：ウイスキー・シガー lounge peak season
  • 冬（12-2月）：屋内ウイスキーバー+ホテルラウンジ（ウォーム）

9. 韓国 nightlife etiquette (外国人 fit)

Do

  • 両手で飲み物を受ける・従う（特に韓国人と酒席）
  • 尖山X（杯を空にして従う・韓国伝統）
  • 酒拒絶OK（運転・妊娠・宗教明示）
  • カラオケオプション（韓国 unique・外国人不思議）

Don't

  • 飲み物の片手でフォローX（延長者に）
  • 飲みながら正面で飲むX（横に回して飲む・伝統）
  • tip X (韓国 tip 文化なし)
  • 路上飲酒 - 韓国は合法ですが、マナーを推奨
