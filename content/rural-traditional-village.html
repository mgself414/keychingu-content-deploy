⚠ 외국인 자주 실수 5가지

1. "전통 마을 = 박물관만": 전통 마을 = 북촌·전주·안동·경주 한옥마을 + 한국민속촌 + WWOOF 농촌 체험 + 외국인 정통 매니아 1번지 풀세트 + #379·#509·#529 통합.

2. "한옥 stay = 비쌈": 한옥 stay = 북촌·전주·경주 한옥 게스트하우스 (10~30만원) + 외국인 영어 OK + 외국인 정통 매니아 1번지 + #379·#509·#252 통합.

3. "농촌 체험 = 한국인만": WWOOF Korea = 외국인 영어 OK + 한국어 학원 (#403) + 외국인 매니아 1번지 + 1~3개월 풀세트 + #529·#403·#252 통합.

4. "민속촌 = 가짜": 한국민속촌 = 실제 250년+ 전통 가옥 80+ 동 + 외국인 영어 가이드 + 외국인 가족 매니아 1번지 + #143·#440·#533 통합.

5. "안동 하회 = 멀음": 안동 = KTX 2시간 + UNESCO + 외국인 정통 매니아 1번지 + #534·#509·#379 통합.
