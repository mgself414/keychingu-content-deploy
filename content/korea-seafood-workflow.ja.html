🎯 なぜ韓国海鮮ワークフローガイドが必要なのか

海鮮6種ガイドを知っていても——注文・調理法・ペアリングは別物です。韓国の海鮮は (a) 市場の本格派(統営 (トンヨン, 통영)・チャガルチ (자갈치)・ソレポグ (소래포구)・モクポ (목포)、1階は活魚売り場 + 2階は食堂)(b) 刺身専門店(ソウルのカンナム (강남)・ホンデ (홍대))(c) カンジャンケジャン (간장게장、醤油漬けカニ) 専門店(マポ (마포)・カンナム)(d) MZ世代トレンドのセウジャン (새우장、醤油漬けエビ)・コッケタン (꽃게탕、ワタリガニ鍋) に分けられます。調理法は生・蒸し・焼き・スープ・醤油漬けの5種類。外国人は (1) サンナクチ (산낙지、活タコ) はゆっくり噛むべきだと知らない (2) 生牡蠣と加熱した牡蠣の違いを知らない (3) カンジャンケジャンは手で食べるものだと知らない (4) コッケタンが秋の本格的な料理だと知らない、といった問題があります。本ガイドでは、5ステップ + 調理法 + 英語フレーズをご案内します。

  • 「コッケタン、辛めで」 = "Spicy blue crab stew, please"

  • 「カード使えますか？」 = "Card accepted?"

⚠ 外国人がよくする7つの間違い

1. 「牡蠣は一年中OK」：牡蠣 = 冬12～3月がナンバーワン・生牡蠣は春・夏は食中毒リスクが高い。

2. 「サンナクチ = 普通の刺身」：サンナクチ (산낙지) = 生きたまま細かく切って、ゆっくり食べる(窒息リスクあり)。

3. 「ワタリガニは一年中OK」：ワタリガニ = 秋9～11月がナンバーワン(カンジャンケジャンの本格的な旬)。

4. 「カンジャンケジャン = 箸で食べる」：カンジャンケジャン = 手で殻を割って食べる・ケジャンビビンバもおすすめ。

5. 「セウジャン = にんにく味」：セウジャン = 醤油漬け(にんにく味のエビとは別物)。

6. 「統営の牡蠣は特に普通」：統営の牡蠣 = 南海の本格派ナンバーワン(生食、12～3月)。

7. 「コッケタン = 辛いだけ」：コッケタン = 辛口・あっさりの両方OK。

⚙ よくある質問8選

1. 初めての海鮮 = どのチャンネル：カンジャンケジャン専門店(マニアに一番人気) → 統営の牡蠣(冬)。

2. インスタ・vlog：マポのカンジャンケジャン・統営の牡蠣・西海のワタリガニ・モクポのサンナクチ。

3. MZ世代トレンド：セウジャン・MZ風コッケタン・ミニカンジャンケジャン。

4. カンジャンケジャンマニア向け：マポのケジャン通り・カンナムの本格派。

5. 妊婦の場合：生牡蠣・サンナクチはNG・加熱したものはOK。

6. アレルギー：甲殻類・軟体動物は事前に申告してください。

7. 支払い・チップ：カードOK / 市場 = 現金一部 / チップ不要。

8. VAT還付：飲食料品は一般的に還付対象外です。

⚠ 医療・安全・食事に関する免責事項

海鮮 = 食中毒に注意(特に春・夏の生牡蠣)・サンナクチ = 窒息リスクあり。妊婦 = 加熱したものはOK・生牡蠣とサンナクチはNG。子供 = 5歳以上で加熱したものを推奨。アレルギー(甲殻類・軟体動物・醤油のグルテン)は事前に申告してください。食中毒の疑いがある場合は ☎ 1339 (医療、英語対応) へ。本ガイドは一般的な情報であり、医療アドバイスではありません。

食事制限の代替案：

  • ハラール・コーシャ：甲殻類・軟体動物 = ハラールは一部OK(店舗による)/ コーシャはNG。
  • 菜食・ヴィーガン：6種すべて非菜食 / 菜食の場合はビビンバ・精進料理を。
  • グルテンフリー：刺身・焼き物はOK / 醤油漬け = グルテンを含む(タマリ醤油で代用可)。
