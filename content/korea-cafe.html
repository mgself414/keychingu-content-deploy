외국인이 자주 하는 실수 5가지

1. "한국 카페는 다 똑같다"는 오해

한국 카페 체인은 저가(메가 ₩1,500) → 중가(스타벅스 ₩4,500) → 프리미엄(블루보틀 ₩7,000) 3단계 가격대가 명확. 같은 아메리카노 한 잔에 ₩1,500~7,000까지 5배 차이가 나는 이유는 매장 분위기·로스팅·원두 등급. 본문 §저가 3대장 비교 참고.

2. 메가커피 "1L 메가 사이즈"의 양 오해

메가커피 시그니처 메가 사이즈(1L, ₩4,000~)는 일반 카페 라지 컵의 약 2배. 외국인이 처음에 주문하면 "왜 이렇게 커?"라고 놀람. 1인 + 1잔 + 갈증 = 메가, 2~3인 공유 = 메가 사이즈가 정답.

3. 사이렌 오더(스타벅스 모바일 앱)을 안 쓰는 것

한국 스타벅스의 사이렌 오더는 외국인도 한국 휴대폰 번호 + 외국 카드로 가입 가능. 매장 줄 안 서고 픽업 — 카페 줄 가장 긴 평일 점심·주말 오후엔 사이렌 오더가 정답. 영어 UI 지원.

4. 한국식 "디저트 카페" vs "커피 전문점" 구분 못 함

투썸플레이스·뚜레쥬르·파리바게뜨 같은 곳은 사실 디저트·케이크 메인 + 커피는 보조. 진짜 커피 마시러 가면 블루보틀·테라로사·폴바셋·어니언 같은 스페셜티가 정답. 첫 방문에 둘 구분 못 하면 "한국 커피 별로네"라는 잘못된 인상.

5. 한국 카페 = 24시간이라는 오해

한국 카페 24시간은 강남·홍대·이태원 핵심 상권의 일부 매장만. 일반 동네 매장은 22~23시 마감. 새벽 카페가 필요하면 24시간 김밥천국 + 편의점 커피가 더 안정적.

★ 한국 저가 카페 체인 3대장 — 이디야 vs 메가커피 vs 빽다방

서울 시내에서 외국인이 1km 반경 내에 가장 자주 마주치는 카페 체인. 가격이 ₩1,500~2,500으로 비슷해 보여도 시그니처·매장 분위기·외국인 친화·24시간 운영이 모두 다릅니다.

1️⃣ 이디야 커피 (Ediya Coffee) — 매장 수 1위, 한국 어디든

브랜드 메시지: "더 좋은 커피를 더 많은 사람에게" — 매장 수 1위(4,000+), 가성비 + 안정성

대표 메뉴: 토피넛 라떼, 티라미수 라떼, 콜드브루, 한정 시즌 음료

가격대 (2026-04~05 기준):

  • 아메리카노: ₩2,500 (Ice ₩2,800)
  • 토피넛 라떼: ₩4,000~4,500 (시그니처)
  • 티라미수 라떼: ₩4,500
  • 콜드브루: ₩4,000
  • 디저트(베이글·머핀): ₩2,500~4,000

매장 특징:

  • 전국 4,000+ 매장 = 한국 1위 — 어느 동네에서나 도보 5분 내
  • 좌석 평균 8~15개, 매장 식사·노트북 작업 OK
  • 영문 메뉴 일부 매장 (사진 메뉴 + 픽토그램 위주)
  • 결제: 카드+현금+모바일+키오스크 모두

한 줄 평가: "한국 어디든 가성비 안정적인 카페 정답" — 매장 수 + 가격 + 외국인 친화 균형 1순위

추천 대상: 첫 방문 / 호텔 주변 + 평일 점심 / 노트북 작업 / "어느 카페 가지?"의 default 답

2️⃣ 메가커피 (Mega MGC Coffee) — 1L 메가 사이즈 가성비 1위

브랜드 메시지: "Mega Size, Mega Value" — 사이즈가 곧 가성비

대표 메뉴: 1L 메가 사이즈 (모든 메뉴 가능), 메가 라떼, 시즌 한정 (밤·고구마·딸기)

가격대:

  • 아메리카노 (Hot/Ice): ₩1,500 / ₩2,000 (3대장 중 가장 저렴)
  • 메가 사이즈 (1L) 아메리카노: ₩4,000~4,500 (직경 ~25cm 컵)
  • 메가 라떼: ₩2,500
  • 메가 사이즈 라떼: ₩5,500
  • 디저트: ₩2,500~3,500

매장 특징:

  • 전국 2,500+ 매장 — 신상 체인 중 가장 빠른 성장
  • 테이크아웃 위주 매장 다수 (좌석 적음 — 평균 5~10석)
  • 영문 메뉴 한정, 사진 + 픽토그램 위주
  • 결제: 카드+모바일 (현금 일부 매장만)

한 줄 평가: "₩1,500 아메리카노 + 메가 사이즈 = 가성비 1위"

추천 대상: 가성비 우선 / 2~3인 그룹 (메가 사이즈 공유) / 테이크아웃 + 산책 / 한국 길거리 카페 인증샷

3️⃣ 빽다방 (Paik's Coffee) — 백종원 브랜드, 푸짐함과 맛

브랜드 메시지: 한국 음식 전문가 백종원이 만든 카페 — 푸짐함과 맛 균형

대표 메뉴: 백사이즈 (1L), 빽크림라떼, 흑임자라떼, 시즌 한정 음료

가격대:

  • 아메리카노: ₩1,500~2,000 (메가커피와 동급)
  • 빽크림라떼: ₩3,500~4,000 (시그니처)
  • 백사이즈 (1L) 아메리카노: ₩4,500~5,000
  • 흑임자라떼: ₩4,000 (한국 전통 재료)
  • 디저트(쿠키·머핀·베이글): ₩2,500~4,000

매장 특징:

  • 전국 1,500+ 매장 — 중가 신생 체인 중 가장 빠른 성장
  • 매장 분위기 깔끔, 노트북 작업 OK 좌석 평균 10~20개
  • 한국 전통 재료(흑임자·인절미·미숫가루) 활용 메뉴 — 외국인 한국 맛 체험에 적합
  • 결제: 카드+모바일+키오스크

한 줄 평가: "백종원의 푸짐함 + 한국 전통 재료 라떼 = 가성비 + 한국 체험"

추천 대상: 한국 전통 재료 음료 시도 (흑임자·인절미) / 노트북 작업 / 디저트 + 커피 동시

④ 스타벅스 (Starbucks) — 글로벌 안정성·외국인 친화 1위

위치: 전국 1,800+ 매장 (서울 600+)

가격: 아메리카노 톨 ₩4,500 / 그란데 ₩5,000 / 벤티 ₩5,500

핵심:

  • 사이렌 오더(모바일 앱) 영어 지원 — 줄 서지 않고 픽업
  • 한국 한정 메뉴 (자몽 허니 블랙 티, 돌체 라떼 등) 외국인 인기
  • 한국 디자인 한정 머그컵·텀블러 (월별·시즌별) — 기념품 1순위
  • 매장 분위기 글로벌 표준, 영어 메뉴 100%

한 줄: "외국인 친화도·머그컵 컬렉션·시그니처 메뉴 균형의 default"

⑤ 투썸플레이스 (A Twosome Place) — CJ 계열·디저트·케이크

위치: 전국 1,500+ 매장

가격: 아메리카노 ₩4,500 / 케이크 1조각 ₩6,500~9,000

핵심:

  • 케이크 + 디저트 강세 — 생일·기념일 케이크 1순위
  • 카페 분위기보다 디저트 카페 정체성
  • 매장 평균 30~50석, 데이트·미팅 자리

한 줄: "커피보다 케이크 + 디저트가 메인인 카페"

⑥ 컴포즈커피 (Compose Coffee) — 신생 급성장 가성비 체인

위치: 전국 2,400+ 매장 (2024년 폭발적 성장)

가격: 아메리카노 ₩2,500~3,000 / 시그니처 ₩4,000~5,000

핵심:

  • 이디야와 메가 사이의 중저가 포지션
  • 좌석 평균 15~25석 — 매장 작업 환경 양호
  • 한국 MZ 세대 신생 체인 인지도 1순위

한 줄: "이디야와 메가 사이 — MZ 신상 가성비 체인"

⑦ 블루보틀 (Blue Bottle) — 미국 프리미엄, 한국 진출

위치: 강남·삼청동·청담·성수 등 단독 매장 ~10개

가격: 아메리카노 ₩6,000~7,000 / 라떼 ₩7,500~8,500

핵심:

  • 미국 캘리포니아 출신 스페셜티 커피 본가
  • 매장 디자인 미니멀, 인증샷 명소 — 외국인 인스타 1순위
  • 한국 한정 콜라보 굿즈

한 줄: "한국에서 가장 사진 잘 나오는 미국 스페셜티 카페"

⑧ 어니언 (Onion) / 폴바셋 / 테라로사 — 한국 스페셜티 단독 카페

위치: 어니언(성수·안국)·폴바셋(강남 1호점)·테라로사(강릉 본점·서울 분점)

가격: 아메리카노 ₩5,000~7,000 / 시그니처 ₩7,000~12,000

핵심:

  • 어니언 안국점 = 한옥 리노베이션 + 카페 = 외국인 인스타 1순위
  • 폴바셋 = 호주 출신 바리스타 챔피언 매튜 폴 바셋
  • 테라로사 = 강원도 강릉 본점 한국 1세대 스페셜티
  • 직접 로스팅 / 핸드드립 / 시즌 원두

한 줄: "한국 스페셜티 커피 본가 — 진짜 커피 마시러 가는 곳"

✅ 사이즈 명칭 차이

  • 한국 카페 사이즈: Tall(R) / Grande(L) / Venti / Mega(1L)
  • 메가 사이즈는 메가커피·빽다방 시그니처 — 1인 너무 큼

✅ 결제 방식

  • 카드+모바일 거의 100%
  • 현금만 받는 카페 거의 없음 — 카드 없으면 모바일 결제 (Naver Pay·Kakao Pay)
  • 외국 카드 거부되는 일부 매장은 키오스크에서 시도

✅ 알레르기·식이

  • 우유 → 두유·오트밀크 옵션 (스타벅스·블루보틀 OK)
  • 비건 → 어니언·블루보틀 등 스페셜티에 옵션
  • 카페인 → 디카페인 + 옵션 (모든 체인 가능)

✅ 매장 작업 (노트북·미팅)

  • 이디야·빽다방·컴포즈·스타벅스 = 작업 OK
  • 메가·블루보틀 = 좌석 적어 작업 비추
  • WiFi: 한국 카페 100% 무료 WiFi (체인 ID + 비번)

✅ 24시간 매장

  • 강남·홍대·이태원 핵심 상권 일부만
  • 일반 동네 = 22~23시 마감
  • 새벽 카페 → 김밥천국 + 편의점 커피가 안정

✅ 머그컵·텀블러 기념품

  • 스타벅스 한국 한정 텀블러·머그컵 = 외국인 기념품 1순위
  • 시즌별·월별 출시 — 인천공항 면세점에 제한적 입고
  • 블루보틀 한국 굿즈도 인기

✅ 카페 매너

  • 매장 음료만 가지고 들어오기 (외부 음료 X)
  • 좌석에 노트북 + 짐 + 자리 비우기 = OK (한국 카페 문화)
  • 통화는 작은 목소리, 영상 통화는 이어폰 필수

FAQ

Q1. 영어 통하나요?

스타벅스·블루보틀·이디야 영어 메뉴 보편. 메가커피·빽다방·컴포즈는 사진 메뉴 위주이지만 손가락으로 가리키면 OK.

Q2. 디카페인 있나요?

모든 체인 가능. "디카페인 (decaf)"이라고 말하면 OK. 추가 비용 ₩300~500.

Q3. 두유·오트밀크 옵션은?

스타벅스·블루보틀·어니언·폴바셋 = 두유·오트밀크 옵션 보편. 이디야·메가·빽다방 = 일부 매장만, 사전 확인 필요.

Q4. 노트북 작업 가능한가요?

이디야·빽다방·컴포즈·스타벅스·투썸 = 작업 OK (콘센트·WiFi·좌석 양호). 메가·블루보틀 = 좌석 적어 비추. 2시간 이상 머무르면 한 잔 더 주문이 한국 카페 매너.

Q5. 카드 안 받으면 어떻게?

거의 없지만 발생 시 모바일 결제(Naver Pay·Kakao Pay) 또는 현금. 외국 카드 거부 시 키오스크에서 재시도.

Q6. 한국 한정 머그컵·텀블러는?

스타벅스 한국 한정 = 시즌별·월별 출시. 인천공항 면세점에서 일부 라인 살 수 있음. 가격은 매장과 비슷 — 기념품 1순위.

A. 저가 3대장 풀 세트 (1시간·강남 또는 홍대)

  • 예산: ₩9,500

B. 한국 카페 풀 스펙트럼 (반나절·강남)

  • 10:00 메가커피 (가성비) ₩1,500
  • 11:00 스타벅스 (글로벌·머그컵 쇼핑) ₩4,500
  • 12:30 어니언 안국점 (한옥 스페셜티) ₩6,000
  • 14:00 블루보틀 청담 (인스타 1순위) ₩7,000

C. 한국 전통 카페 + 빵집 (반나절·종로 동선)

  • 폴바셋 강남 1호점 (호주 바리스타 챔피언)
  • 어니언 안국점 (한옥 + 스페셜티)
  • 예산: ₩15,000~20,000

  • 어니언 성수점 (정원 카페)
  • 블루보틀 성수점 (미니멀 디자인)
  • 단독 스페셜티 카페 (성수·연남 추천)
  • 예산: ₩20,000~30,000
