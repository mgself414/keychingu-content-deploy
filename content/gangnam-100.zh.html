🎯 本指南的使用方法

从江南站 (Gangnam Station / 강남역) 11号出口走出地面，心形雕塑后方的大型媒体墙会不停播放K-pop视频 (VisitGangnam)。江南 (Gangnam / 강남) 不是一个单独的街区。这篇文章是一张地图，写给第一次来江南、要决定在哪一站下车、先看哪里的旅行者。我们把它分成五个区域：江南站 (Gangnam Station / 강남역)，新论岘 (Sinnonhyeon / 신논현)，三成 (Samseong / 삼성) (COEX，奉恩寺)，新沙洞林荫道 (Garosu-gil / 가로수길)，狎鸥亭 (Apgujeong / 압구정)，清潭 (Cheongdam / 청담)，道山公园 (Dosan Park / 도산공원)。每个区域各挑出1~3处在江南区旅游官方网站 (VisitGangnam)、首尔旅游财团 (VisitSeoul)、VisitKorea旅游信息上登载的地方，地铁站和出口也只照抄这些页面上写的数值。想深入了解咖啡馆、购物、餐厅，请点各区域附带的链接。

🌃 江南站 (Gangnam Station / 강남역)，新论岘 (Sinnonhyeon / 신논현) — 2处

  • 江南广场 (Gangnam Square / 강남스퀘어 광장) — 首尔江南区 (Gangnam-gu / 강남구) 江南大道 (Gangnam-daero / 강남대로) 396号，位于江南站 (Gangnam Station / 강남역) 11号至12号出口之间。地铁2号线和新盆唐线 (Shinbundang Line / 신분당선) 江南站。这里有播放K-POP视频的大型媒体墙、常设演出场地，还有'I L♡VE GANGNAM style'心形雕塑。从江南站 (Gangnam Station / 강남역) 到新论岘站 (Sinnonhyeon Station / 신논현역) 约760m的路段上，排列着18根三面LED灯柱(媒体灯柱'G-LIGHT')，适合傍晚散步 (VisitGangnam)
  • 江南站地下购物中心 (Gangnam Station Underground Shopping Center / 강남역지하쇼핑센터) — 首尔江南区 (Gangnam-gu / 강남구) 江南大道 (Gangnam-daero / 강남대로) 地下396号。10:00~23:00，电话02-553-1898。与2号线江南站 (Gangnam Station / 강남역) 直接相连，有200多家店铺。介绍称这里的衣服、化妆品、电子产品、小物件卖得比较便宜 (VisitGangnam)
  • 这个区域的咖啡馆见#142 江南咖啡馆篇，安排一天预算见#310 江南预算篇

🏛 三成 (Samseong / 삼성) — COEX，星空图书馆，奉恩寺 3处

  • 星空COEX商场 (Starfield COEX Mall / 스타필드 코엑스몰) — 首尔江南区 (Gangnam-gu / 강남구) 永东大道 (Yeongdong-daero / 영동대로) 513号。与2号线三成站 (Samseong Station / 삼성역) 5，6号出口、9号线奉恩寺站 (Bongeunsa Station / 봉은사역) 7号出口直接相连。全年无休，各店营业时间不同 (VisitSeoul)。VisitGangnam写的COEX商场 (COEX Mall / 코엑스몰) 营业时间是10:30~22:00。COEX会展中心 (COEX / 코엑스) 是1979年3月开业的展览和会议设施 (VisitKorea)。商场内的储物柜有3处(ZARA服装店 (Zara / 자라) F109对面，TOPTEN服装店 (Topten / 탑텐) F115旁，高哇花店 (Gowa Flower / 고와플라워) N101旁，2025年为准，VisitSeoul)
  • 星空图书馆 (Starfield Library / 별마당 도서관) — 星空COEX商场 (Starfield COEX Mall / 스타필드 코엑스몰) B1。每天10:30~22:00，全年无休，免费。距三成站 (Samseong Station / 삼성역) 5号出口353m，距奉恩寺站 (Bongeunsa Station / 봉은사역) 7号出口328m (VisitSeoul)。13m高的书架上约有70,000册书，包括外国杂志在内的杂志约600种。电话02-6002-3031 (VisitGangnam)
  • 奉恩寺 (Bongeunsa / 봉은사) — 首尔江南区 (Gangnam-gu / 강남구) 奉恩寺路 (Bongeunsa-ro / 봉은사로) 531号。距9号线奉恩寺站 (Bongeunsa Station / 봉은사역) 1号出口135m。这座寺庙于794年新罗 (Silla / 신라) 时期建立，提供寺院住宿体验(Templestay)，以及凌晨礼佛、参禅、茶道等体验。每年5月佛诞日，附近的三成洞 (Samseong-dong / 삼성동) 会举办燃灯活动 (VisitSeoul)。开放时间各出处不同：VisitGangnam是05:00~22:00，VisitKorea是09:00~18:00，VisitSeoul写的是"随法会 (Beophoe / 법회) 日程而不同"。如果要晚到，请先打电话02-3218-4800确认
  • 百货商店和购物中心比较见#449 首尔百货商店、购物中心篇

🌳 新沙洞林荫道 (Garosu-gil / 가로수길) — 2处

  • 新沙洞林荫道 (Garosu-gil / 가로수길) — 距3号线和新盆唐线 (Shinbundang Line / 신분당선) 新沙站 (Sinsa Station / 신사역) 8号出口454m，3号线狎鸥亭站 (Apgujeong Station / 압구정역) 4号出口也很近 (VisitSeoul)。这条路从现代高中 (Hyundai High School / 현대고등학교) 前的十字路口，延伸到新沙站 (Sinsa Station / 신사역) 东侧道山大道 (Dosan-daero / 도산대로) 三岔路口。如今时尚、美妆店和快闪店聚集在这里。各家店营业时间不同，不能停车 (VisitKorea)
  • 湖林博物馆新沙分馆 (Horim Museum Sinsa Branch / 호림박물관 신사분관) — 首尔江南区 (Gangnam-gu / 강남구) 道山大道 (Dosan-daero / 도산대로) 317号。周二至周六10:30~18:00，周一、周日闭馆。离新沙站 (Sinsa Station / 신사역) 很近。2009年6月开馆，在陶瓷造型的博物馆大楼2~4层，每年举办3~4次特别展。电话02-541-3525 (VisitGangnam)。页面上没有门票价格，我们未能确认
  • 想在林荫道 (Garosu-gil / 가로수길) 逛一整天，请看#295 林荫道篇和#30 林荫道购物路线

💎 狎鸥亭 (Apgujeong / 압구정)，清潭 (Cheongdam / 청담) — 2处

  • 韩流明星之路 (K-Star Road / 케이스타 로드) — 这是一条在清潭洞 (Cheongdam-dong / 청담동)、新沙洞 (Sinsa-dong / 신사동)、论岘洞 (Nonhyeon-dong / 논현동) 一带，跟随韩流明星的常去店铺和经纪公司行走的路线。分为A区(道山公园 (Dosan Park / 도산공원) 十字路口到新沙站 (Sinsa Station / 신사역) 十字路口)，B区(道山公园 (Dosan Park / 도산공원) 十字路口到鹤洞 (Hakdong / 학동) 十字路口)，C区(鹤洞 (Hakdong / 학동) 十字路口到清潭 (Cheongdam / 청담) 十字路口)，D区(清潭 (Cheongdam / 청담) 十字路口到永东大桥 (Yeongdong Bridge / 영동대교) 南端) (VisitGangnam)。从水仁盆唐线 (Suin-Bundang Line / 수인분당선) 狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 2号出口步行3分钟 (VisitSeoul，2022年修改的页面)
  • 江南医疗旅游中心 (Gangnam Medical Tourism Center / 강남메디컬투어센터) (旅游咨询处) — 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 161号。工作日10:00~18:00，周末和公休日休息。从3号线狎鸥亭站 (Apgujeong Station / 압구정역) 6号出口步行3分钟。负责多语种旅游咨询、地图和指南手册、寄存行李、退税。电话1661-2230 (VisitGangnam)
  • 狎鸥亭罗德奥 (Apgujeong Rodeo / 압구정 로데오)、百货商店、蚕院 (Jamwon / 잠원) 汉江请看#713狎鸥亭、蚕院篇(最下方相关内容)，清潭 (Cheongdam / 청담) 步行请看漫步清潭洞：路易威登之家与迪奥之家建筑，松隐、路易威登艺术空间、爱马仕工作室画廊，岛山公园，名牌购物请看#771 江南奢华购物篇

🌲 道山公园 (Dosan Park / 도산공원) — 2处

  • 道山公园 (Dosan Park / 도산공원) — 首尔江南区 (Gangnam-gu / 강남구) 道山大道45街 (Dosan-daero 45-gil / 도산대로45길) 20号。全天开放，全年无休。1973年11月10日开园。咨询：江南区厅公园绿地科 (Gangnam-gu Office Parks and Green Spaces Division / 강남구청 공원녹지과) 02-3423-6244 (VisitKorea)。距3号线狎鸥亭站 (Apgujeong Station / 압구정역) 2，3号出口882m (VisitSeoul)。这座公园是为纪念独立运动家岛山安昌浩 (Dosan Ahn Chang-ho / 도산 안창호) 而建，有铜像、纪念馆，以及他与夫人李惠练 (Lee Hye-ryeon / 이혜련) 女士合葬的墓地 (VisitKorea)
  • 岛山安昌浩纪念馆 (Dosan Ahn Chang-ho Memorial Hall / 도산안창호기념관) — 在道山公园 (Dosan Park / 도산공원) 内。免费，电话02-541-1800 (VisitKorea)。开放时间各出处不同：VisitKorea是10:00~18:00(17:30停止入场，1月1日和春节 (Seollal / 설)、中秋 (Chuseok / 추석) 假期闭馆)，VisitSeoul是10:00~18:00(周日、春节 (Seollal / 설)、中秋 (Chuseok / 추석)、圣诞节闭馆)，VisitGangnam是10:00~17:00。如果打算周日去，请先打电话确认
  • 公园周边的高级餐饮见#22 江南高级餐饮篇

🧰 江南第一天实用信息——独自出行，行李，支付，交通

  • 交通(只写线路事实)：江南站 (Gangnam Station / 강남역) 和三成站 (Samseong Station / 삼성역) 都是2号线。江南站 (Gangnam Station / 강남역) 和新沙站 (Sinsa Station / 신사역) 由新盆唐线 (Shinbundang Line / 신분당선) 相连。新沙站 (Sinsa Station / 신사역) 和狎鸥亭站 (Apgujeong Station / 압구정역) 是3号线。狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 是水仁盆唐线 (Suin-Bundang Line / 수인분당선)，奉恩寺站 (Bongeunsa Station / 봉은사역) 是9号线(VisitGangnam，VisitSeoul各页面)。各区间所需时间没有官方数值，所以没有写。交通卡见#1298 三种交通卡的选择
  • 行李：工作日用江南医疗旅游中心 (Gangnam Medical Tourism Center / 강남메디컬투어센터) 的行李寄存 (VisitGangnam)，周末用COEX商场 (COEX Mall / 코엑스몰) 的3处储物柜 (VisitSeoul)
  • 支付与退税：退税也可以在江南医疗旅游中心 (Gangnam Medical Tourism Center / 강남메디컬투어센터) 咨询 (VisitGangnam)。银行卡和移动支付见#527 韩国支付系统
  • 独自出行：星空图书馆 (Starfield Library / 별마당 도서관)、奉恩寺 (Bongeunsa / 봉은사)、道山公园 (Dosan Park / 도산공원) 是适合一个人安静散步的免费空间(各官方页面标注免费、全天开放)。一个人吃饭见#348 Seoul Solo Diner Map
  • 语言不通时：旅游咨询电话1330 (VisitSeoul)

⚠ 常见的4个误区

1. "江南 = 江南站" — 江南区的旅游介绍也把狎鸥亭罗德奥 (Apgujeong Rodeo / 압구정 로데오) 和清潭 (Cheongdam / 청담) 的买手店、江南站 (Gangnam Station / 강남역) 的美食店、林荫道 (Garosu-gil / 가로수길) 的K-beauty、COEX会展中心 (COEX / 코엑스) 分开列出 (VisitKorea)。第一天只选两三个区域

2. "旅游咨询处周末也开" — 江南医疗旅游中心 (Gangnam Medical Tourism Center / 강남메디컬투어센터) 周末和公休日休息 (VisitGangnam)

3. "公园晚上会关门" — 道山公园 (Dosan Park / 도산공원) 全天开放 (VisitKorea，VisitSeoul)

4. "奉恩寺 (Bongeunsa / 봉은사) 任何时候开放时间都一样" — 三个官方出处写的时间各不相同。会随法会 (Beophoe / 법회) 日程而变化 (VisitSeoul)
