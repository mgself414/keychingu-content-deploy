漢江 (ハンガン) チメク (チキンとビール) ピクニックガイド (3-2)

ソウルのアイコン体験

> この体験は、ソウルで必ずやるべきバケットリストです。

> 漢江 (ハンガン) でチキンにビールを飲むこと = ソウルのアイコンを直接体験すること

ステップ1. 配達アプリの設定 (海外の電話番号利用者向け)

ペミン (配達の民族) (배달의 민족) - おすすめ ⭐⭐⭐

長所:

  • 海外の携帯電話番号で会員登録が可能 (アメリカ、ヨーロッパ、日本などすべて可能)
  • 海外発行のクレジットカード (VISA、Mastercard) で決済可能
  • 漢江 (ハンガン) 配達ゾーンで最も活発に運営されているアプリ
  • 配達員と通話可能 (配達位置の確認)

アプリ設定方法 (モバイル)

1. ペミン (배민) アプリをダウンロード (App Store / Google Play)

2. 会員登録を選択 → 「非会員で続ける」 (本人認証をスキップ可能)

3. 携帯電話認証 → ご自身の海外の電話番号を入力 (例: +81-90-XXXX-XXXX)

4. パスワード設定 (自由)

5. クレジットカード登録

  • 決済 → クレジットカードを追加
  • 海外発行のVISA/Mastercardを入力
  • CVV/有効期限を確認

6. 配送先住所を保存 → 漢江 (ハンガン) 公園名 + 具体的な位置を記入 (下記参照)

ヨギヨ (Yogiyo) - サブアプリ

注意: 海外の電話番号では通信会社の本人認証ができない場合が多いです。ペミン (배민) の主使用をおすすめします。

クーパンイーツ (쿠팡이츠) - 代替アプリ

長所:

  • 英語アプリ対応可能
  • クレジットカード決済が簡単

短所:

  • 漢江 (ハンガン) 配達ゾーンのカバー範囲が狭い
  • 価格が少し高め

ステップ2. 漢江公園 (ハンガンゴンウォン) の配達住所を設定する

✨ 最も重要なヒント ✨

配達アプリの住所設定が正確でないと、配達員が漢江公園 (ハンガンゴンウォン) の入口で迷ってしまいます。

以下の各公園ごとに正確な住所 + ランドマークを保存しておきましょう。

汝矣島漢江公園 (ヨイドハンガンゴンウォン) (여의도한강공원) (最も人気) ⭐⭐⭐

配達ゾーンの位置 3か所:

1. 第2駐車場前 (最も広く + コンビニが近い)

2. 汝矣島 (ヨイド) ナドゥルモク (나들목) 前

3. 水光広場 (ムルピッカンジャン) 進入路横

ペミン (배민) 住所登録例:

```

여의도한강공원 제2주차장 앞 배달존

ソウル市 永登浦区 (ヨンドゥンポグ) 汝矣島洞 (ヨイドドン) / サジクロ (사직로) 165

```

配達員に伝える言葉: 「汝矣島漢江公園 (ヨイドハンガンゴンウォン) 第2駐車場前の配達ゾーンで待っています」

おすすめの理由:

  • 漢江 (ハンガン) の絶景が最高
  • コンビニ (GS25) のすぐ隣 (酒、追加のおつまみ購入可能)
  • 進入路が明確で配達員が見つけやすい
  • 夕日を眺めながら酔いしれるのに最高の角度

盤浦漢江公園 (パンポハンガンゴンウォン) (반포한강공원) (月光レインボー噴水ビュー) ⭐⭐

配達ゾーンの位置:

  • 盤浦 (パンポ) 一帯 (正確な配達ゾーンの地図は [ソウル市漢江本部](https://hangang.seoul.go.kr) を参照)

ペミン (배민) 住所登録例:

```

반포한강공원 (달빛무지개분수 근처)

ソウル市 瑞草区 (ソチョグ) 新盤浦路 (シンバンポロ) 11ギル (길) 40

```

配達員に伝える言葉: 「盤浦漢江公園 (パンポハンガンゴンウォン) 月光レインボー噴水 (タルピッムジゲブンス) の舞台前の芝生にいます。待っている人を見たら電話ください」

おすすめの理由:

  • 19:30から噴水ショー (無料！シーズンによって回数が異なります)
  • ソウルの夜景 + 噴水 = 最高の写真スポット
  • 外国人観光客が最も感動する瞬間

纛島漢江公園 (トゥクソムハンガンゴンウォン) (뚝섬한강공원) (ローカル感性) ⭐

配達ゾーンの位置 2か所:

1. 纛島 (トゥクソム) ナドゥルモク (나들목) 前

2. 纛島 (トゥクソム) 案内センター前

ペミン (배민) 住所登録例:

```

뚝섬한강공원 배달존

ソウル市 広津区 (クァンジング) 纛島路 (トゥクソムロ) 地域

```

配達員に伝える言葉: 「纛島 (トゥクソム) 案内センター前の配達ゾーンで待っています」

おすすめの理由:

  • ソウルの森 (ソウルスプ) とつながっている (昼に森を散歩 + 夜にチメク (チキンとビール) の組み合わせが可能)
  • 聖水洞 (ソンスドン) のカフェ/ホットプレイスの近く (事前に観光してから訪問可能)
  • 地元の人々が多い真のローカルな雰囲気

望遠漢江公園 (マンウォンハンガンゴンウォン) (망원한강공원) (静かな雰囲気) ⭐

配達ゾーン:

  • 望遠 (マンウォン) 一帯 (配達ゾーンの範囲確認: [漢江本部地図](https://hangang.seoul.go.kr/www/facility/map.tab))

おすすめの理由:

  • 週末でも比較的混雑が少ない
  • 望遠洞 (マンウォンドン) には感性的なカフェ/レストランが多い
  • 静かなピクニックの雰囲気を求めるならここ

ステップ3. チキンを注文する

ペミン (배민) での注文の流れ

1. 検索 → 「チキン」 と入力

2. 配達ゾーンの住所が設定されていることを確認

3. 店を選択 (下記の推奨ブランドを参照)

4. メニューを選択 (辛い味 vs マイルドな味)

5. 数量を決定 (2～3名 = 1羽、4名以上 = 2羽)

6. リクエスト事項 → 「漢江 (ハンガン) 配達ゾーンに置いてください」

7. クレジットカード決済 → 完了！

注文のヒント

  • 時間設定: 注文から通常25～40分で到着 (漢江 (ハンガン) 配達ゾーンは専属の配達員がいます)
  • 天気確認: 雨が降ると配達が遅れる可能性があります (傘の準備を！)
  • ピーク時間を避ける: 金曜日の17:00～19:00は最も混雑します。可能であれば避けてください。

🚫 注意事項

漢江公園 (ハンガンゴンウォン) では調理が禁止されています。 (ラーメンを煮る、焼くなど)

→ コンビニ (편의점) で調理済みの食べ物のみ可能です。

使い捨て配達容器の持ち込み制限: ソウル市は2025年から漢江公園 (ハンガンゴンウォン) 全域で使い捨て容器の配達飲食物の持ち込みを段階的に制限しています。再利用可能な容器での配達、または現場の売店利用を推奨します。訪問前に最新の政策を確認してください。

ステップ5. 漢江公園 (ハンガンゴンウォン) で場所を確保する

到着前の準備

1. 配達アプリで「配達員の現在位置」を確認 (リアルタイム地図)

2. 配達員が配達ゾーン付近に到着したら電話 (電話番号はペミン (배민) で提供)

3. レジャーシートを広げて場所を確保 (配達ゾーンから5～10m離れた芝生)

最高の場所を選ぶヒント (汝矣島 (ヨイド) 基準)

絶景の場所 (最も良い):

  • 漢江 (ハンガン) を正面に見渡せる場所
  • 夕日が見える方向
  • 他の人々に挟まれていない場所 (プライベート空間の確保)

避けるべき場所:

  • 配達ゾーンのすぐ隣 (配達員の出入りによる騒音)
  • 日よけのすぐ下 (日差しがなく、雰囲気が損なわれる)
  • 木の枝がある場所 (鳥が通り抜けやすい)

マナーエチケット

必ず守ること:

1. ゴミの分別 (黒いゴミ袋 + 黄色の生ごみ (음식물 쓰레기) 袋)

2. 食べ残しの放置禁止 (カラス、ネズミが寄ってくる)

3. 騒がしい音楽を流さない (Bluetoothスピーカーの音量に注意)

4. 23:00以降は自粛 (夜間騒音規制があります)

ステップ6. チメク (チキンとビール) を楽しむ

提供順序

1. ビールを注ぐ: 泡が落ち着くまで待ってから飲む

2. チキンを開けて食べる: ウェットティッシュを多めに準備

3. 一口チキン + 一口ビール = 韓国式チメク (チキンとビール) の定番

撮影のヒント (Instagram/SNS用)

良いショットのために:

  • 夕焼けの時間帯 (夏の19:00～20:00、春/秋の18:00～19:00)
  • 漢江 (ハンガン) と漢江大橋 (ハンガンデギョ) を背景に入れる
  • ビールグラス + チキン + 芝生の組み合わせを撮影
  • 遠くからワイドショットを1枚 (全体の雰囲気を捉える)

ゴールデンアワーのタイミング:

  • 夏: 6月～8月 = 18:30～20:00
  • 春/初秋: 4月、5月、9月 = 17:30～19:00
  • 冬: 避ける (暗くなるのが早すぎるため)

  • 纛島 (トゥクソム)/汝矣島 (ヨイド)/盤浦 (パンポ) 一帯で自転車レンタル (1時間あたり ₩5,000、約550円)
  • チメク (チキンとビール) の後、23:00までに返却すれば負担が少ない

ソウルの森 (ソウルスプ) (서울숲) (纛島 (トゥクソム)) 連携旅行

  • 昼: ソウルの森 (ソウルスプ) 散策 (カフェ & 公園)
  • 夜: 纛島漢江公園 (トゥクソムハンガンゴンウォン) でチメク (チキンとビール)
  • 夜景: 聖水洞 (ソンスドン) カフェ通り夜景ツアー

最後: ゴミ処理 & 出発

必須チェックリスト

  • [ ] ビニール袋に生ごみ (음식물 쓰레기) を入れる (黄色の袋を使用)
  • [ ] 缶/瓶を分別する (黒い袋)
  • [ ] レジャーシートを水で拭いて乾かす
  • [ ] 周囲にゴミがないか確認 (周りの人への配慮)
  • [ ] 持ち物を確認 (携帯電話、財布、モバイルバッテリーなど)
  • [ ] 配達容器を回収する (ペミン (배민) は通常配達員が回収)

ゴミを捨てる場所

  • 漢江公園 (ハンガンゴンウォン) のあちこちに分別回収箱があります
  • 食べ残しは黄色の生ごみ (음식물 쓰레기) 専用袋に
  • 缶/瓶は金属分別回収箱に

よくある質問 (FAQ)

Q. 海外の電話番号でもペミン (배민) は本当に使えますか？

A. はい、使えます。海外のクレジットカード決済まですべて可能です。ただし、本人認証 (通信会社認証) はスキップして「非会員」で進めてください。

Q. 夜遅くも配達されますか？

A. 漢江 (ハンガン) 配達ゾーンは23:00まで運営されます。それ以降は配達員が出ないため注意してください。

Q. 雨の日も配達されますか？

A. 技術的には可能ですが、20～30分遅れる可能性があります。傘を用意して出かけましょう。

Q. 漢江 (ハンガン) でお酒を飲んでも大丈夫ですか？

A. はい、漢江公園 (ハンガンゴンウォン) は屋外での飲酒が許可されている数少ない公共の場所です。法的に問題ありません。

Q. ピクニックの場所は予約できますか？

A. いいえ、先着順です。週末の17:00以降は場所がすぐに埋まるので、早めに行くのがおすすめです。

Q. 漢江 (ハンガン) でラーメンを煮て食べてもいいですか？

A. いいえ、調理は禁止です。コンビニ (편의점) で調理済みの食べ物のみ可能です。
