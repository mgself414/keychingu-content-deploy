ハンガン チメク ピクニックガイド (3-2)

ソウル アイコン 体験

> この体験は、ソウルで必ずやるべきバケットリストです。

> ハンガン (漢江) でチキンとビールを楽しむこと = ソウルのアイコンを直接体験すること

ステップ 0. 持ち物チェックリスト

ハンガン チメク (치맥) は手軽に見えますが、準備が肝心です。このチェックリストを確認してから出かけましょう。

必須の持ち物

アイテム 購入場所 価格帯 備考
レジャーシート GS25、CU、편의점 (コンビニ) ₩3,000〜5,000 (~290〜480 JPY) 折りたたみ可能な防水タイプ推奨
ウェットティッシュ コンビニ ₩2,000〜3,000 油っぽい手を拭くのに必須！

モバイルバッテリー GS25、薬局 ₩15,000〜25,000 スマホ省電力モード ON
虫除け/日焼け止め コンビニ ₩5,000 季節によって必須 (夏・初秋)

> 💡 편의점 (コンビニ) とは、韓国のコンビニのこと。日本のコンビニと同様に24時間営業で、GS25・CU・セブンイレブンなどが主要チェーン。ハンガン公園のすぐそばにも複数あります。

あると便利なもの

  • 大きいビニール袋 (生ゴミ入れ用)
  • 手指消毒液
  • 小さなタオルやハンドタオル
  • スマホスタンド (写真撮影用)

ステップ 1. デリバリーアプリの設定 (海外番号ユーザー向け)

Baemin (ベミン / Baedal Minjok) — 推奨 ⭐⭐⭐

メリット:

  • 海外携帯番号で会員登録可能 (米国・欧州・日本など全対応)
  • 海外クレジットカード (VISA、Mastercard) 決済可能
  • ハンガン デリバリーゾーンで最も活発に稼働しているアプリ
  • ライダーと通話可能 (配達位置の確認)

アプリ設定方法 (モバイル)

1. Baemin アプリをダウンロード (App Store / Google Play)

2. 会員登録 → "비회원으로 계속 (ゲストとして続ける)" を選択 (本人認証スキップ可)

3. 電話番号認証 → 海外番号を入力 (例: +81-XX-XXXX-XXXX)

4. パスワードを設定 (任意)

5. クレジットカードを登録

  • 決済 → クレジットカードを追加
  • 海外 VISA/Mastercard を入力
  • CVV / 有効期限を確認

6. 配送先住所を保存 → ハンガン公園名 + 具体的な位置を入力 (下記参照)

Yogiyo (ヨギヨ) — サブアプリ

注意: 海外番号では通信会社による本人認証ができない場合が多いです。Baemin をメインに使うことを推奨します。

クーパンイーツ (Coupang Eats) — 代替手段

メリット:

  • 英語アプリ対応可能
  • クレジットカード決済が簡単

デメリット:

  • ハンガン デリバリーゾーンのカバー範囲が狭い
  • 価格がやや高め

ステップ 2. ハンガン公園の配達先住所を設定する

✨ 最重要ポイント ✨

デリバリーアプリの住所設定が不正確だと、ライダーがハンガン公園の入口で迷ってしまいます。

各公園の正確な住所 + ランドマークを事前に保存しておきましょう。

Yeouido Hangang Park / ヨイド ハンガン公園 (Yeouido Hangang Gongwon / 여의도한강공원) — 最人気 ⭐⭐⭐

デリバリーゾーン 3か所:

1. 第2駐車場前 (最大規模 + コンビニ近く)

2. Yeouido Nadeulmok (여의도 나들목) 前

3. Mulbit Gwangjang (물빛광장) 入口横

Baemin 住所登録例:

```

여의도한강공원 제2주차장 앞 배달존

서울시 영등포구 여의도동 / 사직로 165

(Yeouido Hangang Park, 2nd Parking Lot, Delivery Zone)

```

ライダーへの伝言: "여의도한강공원 제2주차장 앞 배달존 내가 기다리고 있음"

→ 「Yeouido Hangang Park 第2駐車場前のデリバリーゾーンで待っています」

なぜ推奨?

  • ハンガンの絶景が最高
  • コンビニ (GS25) がすぐそば (お酒・おつまみの追加購入が可能)
  • 入口が明確でライダーを見つけやすい
  • 夕日を正面に見ながら楽しめるベストアングル

Banpo Hangang Park / バンポ ハンガン公園 (Banpo Hangang Gongwon / 반포한강공원) — 달빛무지개분수 (ダルビット ムジゲ ブンス) ビュー ⭐⭐

デリバリーゾーンの位置:

  • バンポ周辺 (正確なデリバリーゾーン地図は [ソウル市 ハンガン本部](https://hangang.seoul.go.kr) 参照)

Baemin 住所登録例:

```

반포한강공원 (달빛무지개분수 근처)

서울시 서초구 신반포로11길 40

(Banpo Hangang Park, near Moonlight Rainbow Fountain)

```

ライダーへの伝言: "반포한강공원 달빛무지개분수 무대 앞 잔디밭에 있음. 기다리는 사람 봤으면 전화줘"

→ 「Banpo Hangang Park のムーンライトレインボーファウンテン舞台前の芝生にいます。見かけたら電話ください」

なぜ推奨?

  • 毎夕 19:30 から噴水ショー (無料！シーズンにより回数が異なる)
  • ソウルの夜景 + 噴水 = 最高の写真スポット
  • 外国人観光客が最も感動する瞬間

Ttukseom Hangang Park / トゥクソム ハンガン公園 (Ttukseom Hangang Gongwon / 뚝섬한강공원) — ローカル感 ⭐

デリバリーゾーン 2か所:

1. Ttukseom Nadeulmok (뚝섬 나들목) 前

2. Ttukseom 案内センター (뚝섬 안내센터) 前

Baemin 住所登録例:

```

뚝섬한강공원 배달존

서울시 광진구 뚝섬로 지역

(Ttukseom Hangang Park, Delivery Zone)

```

ライダーへの伝言: "뚝섬 안내센터 앞 배달존에서 기다리고 있음"

→ 「Ttukseom 案内センター前のデリバリーゾーンで待っています」

なぜ推奨?

  • Seoul Forest (ソウルの森) と連結 (昼は森を散策 + 夜にチメク)
  • Seongsu-dong (성수동) カフェ・ホットスポット近く
  • 地元の人が多い、本物のローカル雰囲気

Mangwon Hangang Park / マンウォン ハンガン公園 (Mangwon Hangang Gongwon / 망원한강공원) — 静かな雰囲気 ⭐

デリバリーゾーン:

  • マンウォン周辺 (デリバリーゾーン範囲確認: [ハンガン本部マップ](https://hangang.seoul.go.kr/www/facility/map.tab))

なぜ推奨?

  • 週末も比較的混まない
  • Mangwon-dong (망원동) のおしゃれなカフェ・飲食店が充実
  • 静かなピクニック雰囲気を求めるならここ

ステップ 3. チキンを注文する

Baemin での注文フロー

1. 検索 → "치킨 (チキン)" と入力

2. デリバリーゾーンの住所が設定されていることを確認

3. 店舗を選択 (下記推奨ブランド参照)

4. メニューを選択 (辛め vs 辛さ控えめ)

5. 数量を決める (2〜3人 = 1羽、4人以上 = 2羽)

6. 要望欄 → "한강 배달존에 놔주세요 (ハンガン デリバリーゾーンに置いてください)"

7. クレジットカードで決済 → 完了！

注文のコツ

  • 所要時間: 注文後、通常 25〜40 分以内に到着 (ハンガン デリバリーゾーン専任ライダーあり)
  • 天気を確認: 雨の場合は配達が遅れることがあります (傘を準備！)
  • ピーク時間を避ける: 金曜 17:00〜19:00 (5PM〜7PM) が最も混雑。できれば外しましょう

ステップ 4. ビール + おつまみを準備する

コンビニで購入する (デリバリー + 直接購入の組み合わせ)

ハンガン近くのコンビニで ビール + おつまみ を買って、チキンが届く前に準備しておきましょう。

ビールのおすすめ

国産メジャーブランド

  • カス (Cass): 最もスタンダード、安価 (₩4,500/缶 ~430 JPY)
  • テラ (Terra): まろやかな味、カスよりやや高め (₩4,800/缶)
  • クラウド (Kloud): 軽くてすっきり (₩4,700/缶)

輸入ビール (コンビニに常時あるもの)

  • コロナ (Corona) (メキシコ): さわやかなラガー、外国人に大人気 (₩6,500)
  • ギネス (Guinness) (アイルランド): 黒ビール、ハロウィンシーズン人気 (₩7,000)
  • ハイネケン (Heineken) (オランダ): ヨーロッパスタイル、すっきり (₩6,000)

コンビニおつまみの組み合わせ (予算別)

A. コスパセット (約 ₩5,000〜7,000 / ~480〜670 JPY)

  • チーズスティック 1〜2本
  • 塩味スナック 1袋
  • 乾燥イカ / キュポ (쥐포 / 甘辛干しカレイ)
  • アイスクリーム

B. ミドルセット (約 ₩10,000 / ~960 JPY)

  • 계란말이 (ケランマリ / だし巻き卵) + 주먹밥 (チュモクパプ / おにぎり)
  • チョコパイまたはポッキー
  • ソーセージ / チーズボール
  • ビタ500 ドリンク

C. ガッツリセット (約 ₩15,000 / ~1,440 JPY)

  • 김밥 (キンパ / 韓国風のり巻き) 1本
  • 계란말이 (ケランマリ) 1パック
  • ミートボールまたはフランクソーセージ
  • ラーメン (調理すればさらにおいしいが → ハンガン公園は炊事禁止なので注意！)
  • お菓子類 + ドリンク

🚫 注意事項

ハンガン公園では炊事が禁止されています。 (ラーメンを茹でる、焼くなど)

→ コンビニで調理済みの食品のみ可能です。

使い捨て容器のデリバリー食品持ち込み制限: ソウル市は 2025 年からハンガン公園全域で使い捨て容器のデリバリー食品持ち込みを段階的に制限しています。繰り返し使える容器でのデリバリー、または現地売店の利用を推奨します。訪問前に最新の方針をご確認ください。

ステップ 5. ハンガン公園で場所を確保する

到着前の準備

1. デリバリーアプリで "ライダーの現在地" を確認 (リアルタイムマップ)

2. ライダーがデリバリーゾーン近くに到着したら電話 (番号は Baemin から提供)

3. レジャーシートを広げて場所を確保 (デリバリーゾーンから 5〜10m 離れた芝生)

最高の場所選びのコツ (Yeouido / ヨイド 基準)

絶景スポット (最もおすすめ):

  • ハンガンを正面に見渡せる場所
  • 夕日が見える方角
  • 周囲の人に囲まれすぎていない場所 (個人スペース確保)

避けるべき場所:

  • デリバリーゾーンのすぐ横 (ライダーの出入りによる騒音)
  • サンシェードの真下 (日光がなく雰囲気が落ちる)
  • 木の枝がある場所 (鳥が頭上を通りやすい)

マナーとエチケット

必ず守るべきこと:

1. ゴミの分別 (黒: 一般ゴミ / 黄色: 生ゴミ)

2. 食べ残しの放置禁止 (カラスやネズミを引き寄せる)

3. 大音量の音楽を流さない (Bluetoothスピーカーの音量に注意)

4. 23:00 (11PM) 以降は自粛 (夜間騒音規制あり)

ステップ 6. チメクを楽しむ

食べ方の流れ

1. ビールを注ぐ: 泡が落ち着くのを待ってから飲む

2. チキンをほぐして食べる: ウェットティッシュを多めに用意

3. チキンをひと口 + ビールをひと口 = 韓国式チメクの正解

撮影のコツ (Instagram / SNS 用)

良いショットのために:

  • 夕暮れ時間帯 (夏の夜 19:00〜20:00 / 春・秋は 18:00〜19:00)
  • ハンガンとハンガン大橋を背景に入れる
  • ビールグラス + チキン + 芝生の組み合わせで撮影
  • 遠くからワイドショット 1枚 (全体の雰囲気を収める)

GOLDEN HOUR タイミング:

  • 夏: 6月〜8月 = 18:30〜20:00 (6:30PM〜8PM)
  • 春・初秋: 4月・5月・9月 = 17:30〜19:00 (5:30PM〜7PM)
  • 冬: 避けるのが無難 (暗くなるのが早すぎる)

ステップ 7. オプション: ハンガン公園のその他の楽しみ方

Banpo Hangang Park — ムーンライトレインボーファウンテン (無料！)

  • 公演時間: 毎日 19:30 / 20:00 / 20:30 / 21:00 (各 20 分、シーズンにより異なる)

  • コツ: 第 1 回 (19:30) が最も混雑。余裕を持って 19:00 に場所を確保

ハンガン ナイトサイクリングツアー

  • Ttukseom / Yeouido / Banpo 周辺でのレンタサイクル (1時間 ₩5,000 ~480 JPY)

  • 夕方: Ttukseom Hangang Park でチメク
  • 夜景: Seongsu-dong (성수동) カフェ通りの夜景ツアー

最後: ゴミ処理 & 出発

必須チェックリスト

  • [ ] 缶・瓶を分別 (黒い袋)

  • 生ゴミは 黄色い生ゴミ専用袋 へ
  • 缶・瓶は 金属分別回収ボックス へ

よくある質問 (FAQ)

Q. 海外番号でも Baemin は本当に使えますか?

A. はい、使えます。海外クレジットカードでの決済も含めてすべて可能です。ただし、本人認証 (通信会社認証) はスキップして "ゲスト" として進めてください。

Q. 深夜でも配達してもらえますか?

A. ハンガン デリバリーゾーンは 23:00 (11PM) まで運営しています。それ以降はライダーが来ないのでご注意ください。

Q. 雨の日でも配達されますか?

A. 技術的には可能ですが、20〜30 分遅れることがあります。傘を持って備えておきましょう。

Q. ハンガンでお酒を飲んでも大丈夫ですか?

A. はい、ハンガン公園は 屋外での飲酒が許可されている 数少ない公共の場です。法的に問題ありません。

Q. ピクニックの場所は予約できますか?

A. いいえ、先着順です。週末の 17:00 (5PM) 以降は場所がすぐに埋まるため、早めに行くことをおすすめします。

Q. ハンガンでラーメンを作って食べてもいいですか?

A. いいえ、炊事は禁止です。コンビニで調理済みの食品のみ可能です。
