🎯 このガイドの使い方

全州旅行の中心は韓屋村(24時間開放)で、慶基殿・殿洞聖堂・梧木台・郷校・南部市場はいずれも歩いて回れます。以下の時間・料金・住所は、2026-10-08に全州市文化観光(tour.jeonju.go.kr)と韓屋村公式(hanok.jeonju.go.kr)のページで確認した値だけを載せており、公式に記載のない料金・時間は「未掲示」としています。ビビンバのお店は、全州市公式のビビンバページに載っている8軒だけを紹介し、価格は記していません。以前のガイドにあった「700以上の韓屋」「訪韓外国人の8%」「KTX 1.5時間」「豊南門・豊沛之館をひとまとめにした表記」「1339医療ホットライン」などは公式の情報と異なるため外しました(1339は感染症相談の番号で、観光通訳は1330です)。

🏘 韓屋村 — 24時間、車は外に

  • 公式の開放時間は年中無休の24時間です。公営駐車場は6カ所で、第1〜第3駐車場は30分 1,200ウォン(15分追加ごとに600ウォン、1日最大14,400ウォン)、第4駐車場と国立無形遺産院の平面駐車場は無料です(公式)。第4駐車場と太祖路駅 (Taejo-ro / 태조로역)(慈満壁画村 (Jaman Byeokhwa Maeul / 자만벽화마을)経由)を結ぶ無料シャトルは平日 10:00〜18:30に運行しています。
  • 観光案内所4カ所は 09:00〜18:00(昼に休憩)で、通訳と荷物預かりに対応しています。韓服体験は公式メニューにありますが、業者・料金は未掲示です。
  • 夜はライトアップされた路地と、梧木台の夕方の景観が楽しめます。案内所や聖堂は17〜18時に閉まるので、日中に回って夜は散策にあてましょう。

🏛 慶基殿・殿洞聖堂・梧木台 — 歩いてひと回り

  • 慶基殿(太祖の御真): 季節ごとに 09:00〜18〜20:00、大人 3,000ウォン、最終水曜日は無料・最終土曜日は半額(公式)。太祖路44。
  • 殿洞聖堂: 通りの向かい側です。09:00〜17:00(本堂の行事で変動)、1908〜1914年建立(公式)。ミサ中の見学制限の有無は未掲示です。
  • 梧木台・梨木台: 麒麟大路55、夕方の景観スポット(公式) — 以前のガイドの「展望台」という表現は公式にはありません。
  • 全州郷校: 3〜10月は09〜18時、11〜2月は10〜17時、月曜日は休館です。

🍚 ビビンバ・豆もやしクッパ — 公式ページのお店

  • 全州市公式のビビンバページ: 材料は30種類以上、紹介されているお店は甲基会館 (Gapgi Hoegwan / 갑기회관)・古宮 (Gogung / 고궁)・家族会館 (Gajok Hoegwan / 가족회관)・キワ (Giwa / 기와)・コッタムチプ (Kkotdamjip / 꽃담집)・成美堂 (Seongmidang / 성미당)・韓国家 (Hangukjip / 한국집)・白松会館 (Baeksong Hoegwan / 백송회관)の8軒です(価格は未掲示)。以前のガイドにあったウェンイジプ・サムベクジプは公式ページにありません。
  • ビビンバ (Bibimbap / 비빔밥)のほか、豆もやしクッパ (Kongnamul-gukbap / 콩나물국밥)(トリョム式)とピスンデは南部市場の方にあります(#642)。

🎎 韓紙・伝統文化 — 少し離れた2カ所

  • 全州韓紙博物館(八福路59): 09:00〜17:00、日・月曜日・祝日は休館、無料(体験を含む)。韓屋村から離れているので、タクシーかバスで行きます。
  • 韓国伝統文化殿堂(玄武1路20): 韓屋村から徒歩5分(公式)。時間・体験料は未掲示です。

🚄 行き方

  • KTX 龍山 → 全州 約1時間40分(全州市公式。ソウル駅より龍山駅 (Yongsan / 용산역)発をおすすめします)。到着駅は全州駅 (Jeonju / 전주역)です。
  • 全州駅から韓屋村へのバスの番号・時間は公式に未掲示です — 地図アプリで「全州韓屋村」を検索してください。
  • 観光通訳は1330。第4駐車場の無料シャトル(平日)で太祖路駅まで行けます。

📅 今年の祭りは終わりました

  • 全州国際映画祭 2026 4/29〜5/8 · 全州世界ソリ祭り 2026 8/12〜16 — いずれも終了しました。2027年の日程は上半期に公式で確認してください。

⚠ よくある間違い5つ

1. ソウル駅からKTXに乗る — 龍山駅発のほうがおすすめです(公式)。

2. 月曜日に郷校・韓紙博物館へ行く — どちらも休館です(韓紙博物館は日曜日も休み)。

3. 慶基殿の料金を知らずに通り過ぎる — 最終水曜日は無料です。

4. 豊南門と豊沛之館を同じ場所だと思う — 別の場所です。豊南門は南部市場の隣にあります。

5. 1339に電話する — 感染症相談の番号です。観光は1330です。

⚙ FAQ 6つ

1. 1日で回るなら? — 朝は慶基殿・殿洞聖堂 → 昼はビビンバ(公式の8軒) → 午後は韓屋村・梧木台 → 夜は南部市場(金・土は夜市)。

2. 車で行くなら? — 第4駐車場は無料で、平日は無料シャトルもあります。

3. 韓服は? — 公式メニューには体験の項目があるだけで、料金・業者は未掲示です。案内所で尋ねてください。

4. 荷物は? — 観光案内所で荷物を預かってくれます(公式)。

5. 夜に見るものは? — 梧木台の夕方の景観、韓屋村の路地、金・土の夜市です。

6. 英語は? — 観光案内所の通訳(公式)と1330が使えます。
