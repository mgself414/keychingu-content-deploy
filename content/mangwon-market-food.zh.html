🎯 为什么望远市场值得单独出一篇攻略

望远市场 (Mangwon Market / 망원시장) 位于麻浦区望远洞 (Mangwon-dong / 망원동)，是一处本地街坊市场——本地居民真正来买菜购物的地方。与广藏市场 (Gwangjang Market / 광장시장)（游客景点）不同，望远市场的核心是不宰客的明码实价、清静的气氛、浓浓的生活气息。

外国游客中想要"体验街坊氛围而非游客景点"的群体，这里是首选路线。望远市场 + 望里团街咖啡馆 + 望远汉江公园 = 街坊深度游一日路线。ISSUE 02 #25 v2 全文补充（2K → 7K字）。

⚠ 外国游客常犯的3个错误

1. 以为和广藏市场差不多

广藏市场（游客景点·外国游客动线·有宰客现象）和望远市场（本地·不宰客·清静）完全不是一回事。市场美食深度体验广藏市场是首选，但氛围与街坊体验望远市场更地道。对比这两个市场是理解韩国市场文化的第一步。

2. 现金不够——结账失败

望远市场约60%摊位只收现金。比广藏市场更需要备现金——建议提前取₩20,000~30,000。望远站1号出口附近有ATM。

3. 没有和望里团街·汉江联动

只逛望远市场1小时就结束了。望里团街咖啡馆 + 望远汉江公园野餐联动才是真正的望远深度游路线。外国游客的Instagram热门打卡点很多。

望远市场风景

望远市场位于麻浦区望远洞416-46——1986年开业，是本地街坊市场。与广藏市场（1905年·游客景点）·南大门市场（服装）·东大门市场（夜间服装）不同，望远市场的特色是本地·街坊·明码实价。

市场氛围：清静、温馨、不宰客。很少遇到游客，本地居住的外国人和潮流外国人常来这里。

望里团街：望远市场旁边的咖啡馆·美食街。和合井 (Hapjeong / 합정)·延南洞 (Yeonnam-dong / 연남동) 氛围不同的街坊小巷——Instagram热门打卡地。

望远汉江公园：从市场步行到汉江只要10分钟。打包市场美食 → 汉江边野餐 = 韩式街坊约会的精髓。

交通：6号线望远站 (Mangwon Station / 망원역) 1号出口步行3分钟。

8个类别深度解析

1. 辣炒年糕小巷

  • 招牌：市场辣炒年糕 + 鱼糕套餐。韩国市场辣炒年糕的精髓——比广藏市场更清静。
  • 价格：₩4,000~6,000 / 鱼糕汤免费续
  • 推荐：辣炒年糕 + 鱼糕 + 炸物套餐

2. 血肠·鱼糕小巷

  • 招牌：粉丝血肠 + 鱼糕汤。热汤搭配。
  • 价格：₩4,000~7,000

3. 望远市场热狗

  • 招牌：Q弹面衣热狗。韩式路边热狗的精髓——外国游客也熟悉。
  • 价格：₩2,000~4,000

4. 鲜榨果汁摊位

  • 招牌：当季水果现榨。春天草莓·夏天西瓜·秋天苹果·冬天橘子。
  • 价格：₩3,000~5,000（超便宜！）

5. 炸猪排·炸物小巷

  • 招牌：韩式炸猪排 + 市场炸物。适合多人分享。
  • 价格：₩5,000~9,000

6. 包子·馒头小巷

  • 招牌：现蒸包子·馒头。韩式红豆馒头 + 泡菜包子。
  • 价格：₩3,000~6,000

7. 望里团街早午餐咖啡馆

  • 位置：麻浦区圃隐路一带（望远市场步行3分钟）
  • 招牌：望远市场附近的文艺咖啡馆·早午餐。外国游客Instagram热门打卡地。
  • 价格：₩12,000~18,000（一人份早午餐）
  • 外国游客友好度：★★★★ — 有英文菜单，可刷卡

8. 望远汉江公园

  • 位置：麻浦区望远汉江公园（望远市场步行10分钟）
  • 招牌：汉江边野餐。打包市场美食 + 汉江景观。
  • 价格：免费入场 (野餐垫租赁₩2,000~5,000)
  • 推荐：市场辣炒年糕 + 热狗 + 汉江野餐套餐

⚙ 常见问题 (FAQ)

Q1. 有英文菜单吗？怎么付款？

A. 几乎没有英文菜单。可以指着照片或陈列的食物点餐。付款现金占60%／刷卡占40%——建议提前取₩20,000~30,000现金。

Q2. 必备韩语表达是什么？

A. "Tteokbokki hana juseyo" (떡볶이 하나 주세요) → 请给我一份辣炒年糕 ／ "Maepji aneun geo isseoyo?" (맵지 않은 거 있어요?) → 有不辣的吗？／ "Pojanghae juseyo" (포장해주세요) → 请帮我打包，汉江野餐专用 ／ "Igeo eolmayeyo?" (이거 얼마예요?) → 这个多少钱？

Q3. 望远市场和广藏市场怎么比较？

A. 广藏市场 (#24)：1905年开业·游客景点第一名·外国游客知名度高·部分宰客·媒体曝光度第一。

望远市场 (#25)：本地街坊市场·不宰客·清静·真正的韩国街坊氛围。

两个都值得逛——风格完全不同。

Q4. 一日动线路线是？

A. 11点望远站1号出口 → 11:10望远市场热狗·鱼糕 → 11:30辣炒年糕·炸物 → 12点鲜榨果汁 → 12:30望里团街咖啡馆 → 14点望远汉江公园野餐 → 16点咖啡馆收尾。

Q5. 按时间段推荐是？

A. 平日上午10~12点：最清静，食物最新鲜。平日下午14~17点：望里团街咖啡馆时间。周末上午11~13点：本地人买菜高峰——最有活力。

Q6. 怎么联动汉江野餐？

A. 在市场打包美食 → 步行10分钟到望远汉江公园。入口小卖部可租野餐垫₩2K~5K。春秋最佳。夏天建议日落后，冬天不建议。

Q7. 刷卡和付款方式？

A. 辣炒年糕·热狗摊位：只收现金。大型店铺（炸猪排·包子）：可刷卡。望里团街咖啡馆：可刷卡·可用Samsung Pay。汉江公园小卖部：只收现金。

Q8. 望里团街咖啡馆推荐？

A. 望远站·望远市场附近咖啡馆（参考#160弘大咖啡馆·甜品89家／#139弘大咖啡馆攻略）。望远热门咖啡馆：Urban Plant合井店、Hippo Brunch House、Alive214等。

10点望远市场 → 12点望里团街 → 14点合井站步行 → 16点延南洞 (联动#156延禧洞) → 18点晚餐 (联动#140弘大酒吧)

[C] 望远咖啡馆·甜品巡礼 (下午4小时)

14点望里团街咖啡馆 → 15:30望远热门咖啡馆 (联动#160) → 17点望远市场甜品 → 18点汉江夜景

🌸 季节·时段小贴士5条

春天 (3~5月)：汉江樱花 + 望远市场 + 望里团街。4月平日上午最佳。

夏天 (6~8月)：市场要早去 + 汉江夜间野餐。7~8月晚上19点后汉江最佳。

秋天 (9~11月)：枫叶 + 市场 + 汉江。10~11月平日是黄金季节。

冬天 (12~2月)：市场热食 + 望里团街暖咖啡馆。汉江可以跳过。

平日上午黄金时段：10~12点——清静、新鲜、出片。
