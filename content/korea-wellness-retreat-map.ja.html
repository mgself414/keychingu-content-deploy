🎯 このガイドの使い方

江南のビル街のど真ん中なのに、門を一つ越えるとお茶一杯と座布団が待っている — 奉恩寺 (ボンウンサ / 봉은사) は火曜日ごとにテンプルステイ館を開けておき、仏教を知らなくてもただ来て座って帰ればいいと案内している(テンプルステイ公式サイト)。このガイドは数日ほど体と頭を休ませたい旅行者向けの号である。系統は3つ: テンプルステイ(ソウルで外国語で予約できる寺3か所)、韓方(薬材博物館・足湯と韓方スパ2か所)、瞑想・森のステイ(江原2か所)。テンプルステイは公式予約サイト templestay.com、それ以外は文化体育観光部・韓国観光公社の「優秀ウェルネス観光地88選」に選ばれた所だけを選んだ。価格が公式ページにない所は、そう書いた。

🪷 テンプルステイ — ソウル3か所

テンプルステイ公式サイト(templestay.com)は3つの寺すべてを「Temple for foreigner」と表示し、英語の予約画面を用意している。共通の問い合わせ先はテンプルステイ総合情報センター(ソウル鍾路区 郵政局路 (ウジョングンノ / 우정국로) 56、4階、02-2031-2000)。

  • 奉恩寺 (ボンウンサ / 봉은사) — ソウル江南区 奉恩寺路 (ボンウンサロ / 봉은사로) 531、02-3218-4846。794年、新羅の時代に建てられた寺だ。英語プログラム(テンプルステイ公式サイト):
  • BONG-PASS — 毎週火曜 10:00~16:00、テンプルステイ館を自由に出入りしてお茶・瞑想・休憩(特別行事日を除く、2026-03-01~12-31掲載)
  • Regular Templestay [土~日] — 1泊2日(2026-12-27まで掲載)
  • Temple tour & Tea [木] · Buddhist Culture [木] — 日帰り型(2026-12-24まで)
  • Twilight Resonance — 日曜夕方の鐘つき・夕方の礼拝体験(2026-12-27まで)
  • Five Elements Yin Yoga Night — 陰ヨガのプログラム、掲載期間 2026-07-24~10-23。次の回は確認できなかった
  • 金仙寺 (クムソンサ / 금선사) — ソウル鍾路区 九基洞 (クギドン / 구기동) 196-2、02-395-9955、急ぎの問い合わせはWhatsApp +82 10-2685-9913。北漢山国立公園の麓にある約600年の寺だ。Relaxational Templestay(1泊2日)と、団体向けの日帰り型(11:00~14:00、金・土は団体の問い合わせ)。持ち物として、マイタンブラー・洗面用具・タオル・着替え・スニーカーを案内している(テンプルステイ公式サイト)
  • 妙覚寺 (ミョガクサ / 묘각사) — ソウル鍾路区 鍾路63ガギル (チョンノ63ガギル / 종로63가길) 31、02-763-3109。日帰り型の「Where is your mind?」(10:00~14:00)と1泊2日型を運営し、予約日は普通1か月前に開くと書いている(テンプルステイ公式サイト)
  • 価格: 3つの寺ともプログラム一覧に価格がない — 日付を選んで予約画面で確認する
  • 地方の山寺に行きたければ、88選にともに選ばれた海南の大興寺 (テフンサ / 대흥사)と釜山の梵魚寺 (ポモサ / 범어사)がある(優秀ウェルネス観光地88選、VisitKorea)。この2つの寺のテンプルステイ日程は今回開いていない

🌿 韓方 — ソウル2か所

  • ソウル韓方振興センター (ソウルハンバンチンフンセンター / 서울한방진흥센터) — ソウル東大門区 薬令中央路 (ヤンニョンジュンアンノ / 약령중앙로) 26(VisitKorea)。地下鉄1号線 祭基洞駅 (チェギドンヨク / 제기동역) 2番出口から徒歩約5分。3~10月 10:00~18:00、11~2月 10:00~17:00、毎週月曜休館(ソウル市「私の手の中のソウル」、2026-10-12)。2階にソウル薬令市韓医薬博物館 (ソウルヤンニョンシ ハンイヤク パンムルグァン / 서울약령시한의약박물관)、屋外の庭に薬草足湯、普済院 (ポジェウォン / 보제원) の診療がある。足湯は売り切れる日があり、週末は早めに行くほうがいいとソウル市の記事は書いている。韓屋の屋根を載せた韓方複合文化施設で、朝鮮時代の救護機関「普済院」の跡地に建てられた(VisitKorea)。体験料金の公式な値は確認できなかった
  • ヨヨングク韓方スパ (ヨヨングク ハンバンスパ / 여용국 한방스파) — ソウル松坡区 石村湖水路12ギル (ソクチョンホスロ12ギル / 석촌호수로12길) 60、2階(VisitKorea)。まず体質と肌の状態を分析してから、韓方の材料・アロマ・マッサージを合わせる。公式サイトに英語・日本語の画面がある(ヨヨングク公式サイト)。営業時間・価格は公式ページで確認できなかった — 予約画面か電話で尋ねる
  • 韓医院の診療(鍼・韓方薬)はウェルネスではなく医療だ。診療が目的なら韓方・韓医院12選

🌲 瞑想・森のステイ — 江原2か所

  • ミュージアムSAN瞑想館 (ミュジオムサン ミョンサングァン / 뮤지엄산 명상관) — 江原原州市 智正面 オークバレー2ギル (オクバルリ2ギル / 오크밸리2길) 260(VisitKorea)。安藤忠雄が設計して2013年5月に開館したミュージアムの中、ストーンガーデンの隣の瞑想館で、アロマの香りとシンギングボウルの音に集中する瞑想をする(VisitKorea)。瞑想の回・料金は、公式サイト(museumsan.org)がスクリプトでしか描画されず確認できなかった
  • ヒリアンス・ソンマウル (ヒリオンス ソンマウル / 힐리언스 선마을) — 江原洪川郡 鍾子山路 (チョンジャサンギル / 종자산길) 122(VisitKorea)。精神科医の李時炯博士が共同で作ったウェルエイジングのヒーリングリゾートで、鍾子山の中腹に客室92室とスパ・チムジルバン・セラピーセンター・黄土の道を備えている。ペット同伴可の客室もある(VisitKorea)。料金・プログラム日程は確認できなかった

🧰 ウェルネス実務 — ひとりで、予約、決済、移動

  • ひとりで: テンプルステイは個人予約が基本だ。金仙寺の日帰り型のように団体専用のプログラムは、タイトルに「Group」が付く(テンプルステイ公式サイト)
  • 予約: テンプルステイは templestay.com の英語画面で、日付→プログラムの順に選ぶ。妙覚寺は予約日が普通1か月前に開く。ソウル韓方振興センターの足湯は当日売り切れがある(ソウル市)
  • 服・持ち物: 金仙寺の案内ではタンブラー・洗面用具・タオル・着替え・スニーカー(テンプルステイ公式サイト)。初めてならテンプルステイ初心者ガイド
  • 食事: テンプルステイでは寺で供養(食事) (コンヤン / 공양) を一緒にとる。鉢供養 (パルウコンヤン / 발우공양) は食べ物を残さない伝統的な食事作法だ(テンプルステイ公式サイト)。アレルギー・食事リクエストは予約のときに前もって書き、口頭で伝えるカードは韓国の食事リクエスト・辛さ調整、パニックゼロマニュアル — 見せるカードで解決
  • 決済: 外国人 韓国決済システム ディープダイブ
  • 移動: ソウル3か所・韓方2か所は地下鉄で行く — 韓国交通カード3種選び、パニックゼロマニュアル — 自分の日程に合うカードをそのまま選ぶ。原州・洪川は韓国高速・市外バスターミナル、マニュアルそのまま — アプリからして全く違うということ

⚠ よくある間違い4つ

1. 「テンプルステイは仏教徒だけ」 — 奉恩寺は、仏教を知らなくても、瞑想ができなくてもいいと案内している(テンプルステイ公式サイト)

2. 「テンプルステイは必ず一晩泊まらなければならない」 — 奉恩寺の木曜日帰り型・火曜BONG-PASS、妙覚寺の10:00~14:00のように日帰り型がある(テンプルステイ公式サイト)

3. 「月曜に薬令市へ行けば全部見られる」 — ソウル韓方振興センターは月曜休館だ(ソウル市)

4. 「韓方スパ = 韓医院の診療」 — ヨヨングクは体質に合わせた美容・ケアのスパだ。診療は韓医院で別に受ける
