釜山大众交通语法 — 只需读懂两条线的城市

副标题: 釜山地铁线路图远比首尔单纯——南北纵贯的1号线、沿海岸线运行的2号线,这两条线覆盖了游客动线的90%。问题出在第一关:金海机场 (Gimhae Airport / 김해공항) 没有机场铁路。从只需掌握一次轻轨换乘就能解决的机场进城,到本身就是观光项目的海边列车,再到山腰路 (Sanbok-doro / 산복도로) 一带的公交语法——这是在釜山移动不慌乱的方法。

ISSUE · #1325 · 2026-08-23

🎯 釜山出行的整体框架

釜山是一座东西狭长的海岸城市,出行语法可以浓缩为三条线:

1. 1号线(南北轴) — 串联釜山站 (Busan / 부산역)、南浦 (Nampo / 남포)、札嘎其 (Jagalchi / 자갈치)、西面 (Seomyeon / 서면)、东莱 (Dongnae / 동래)、温泉场 (Oncheonjang / 온천장) 的观光大动脉。

2. 2号线(海岸轴) — 从西面转向后,串联庆星大 (Kyungsung / 경성대)、广安 (Gwangan / 광안)、海云台 (Haeundae / 해운대)、森坦 (Centum / 센텀)。

3. 其余是辅助线:3号线(万德 (Mandeok / 만덕) 方向)、东海线广域电铁(机张 (Gijang / 기장)·奥西利亚 (Osiria / 오시리아))、釜山金海轻轨(机场方向)。

不必像首尔那样背下9条线路——只要记住西面是所有换乘的中心就够了。

① 机场进城 — 第一个慌乱点

金海机场没有像首尔那样的机场铁路。可选方案有三种:

交通方式 方法 使用感受
轻轨+地铁 乘坐釜山金海轻轨 (Busan-Gimhae LRT / 부산김해경전철) 到沙上站 (Sasang / 사상역) 3站(约7~10分钟) → 换乘2号线 前往西面·广安·海云台方向的标准路线
机场大巴 西面·釜田 (Bujeon / 부전) 方向 / 海云台·机张方向两条线路(2026年4月恢复运行) 行李多时适用。感觉像直达海云台
出租车 呼叫Kakao T(카카오T) 深夜抵达或3人以上同行时更划算
  • 费用负担减轻了:釜山·金海·梁山 (Yangsan / 양산) 三地之间的广域换乘运费已取消(2025年9月起),使用交通卡的话,1区间1,600韩元、2区间1,800韩元就能完成含换乘的全程。
  • 交通卡与T-money(티머니)/Cashbee(캐시비)通用——在首尔用过的卡可以直接沿用。机场便利店可以充值。

② 地铁语法 — 把景点读成路线

  • 1号线:釜山站(KTX抵达站,#1114)→ 南浦(光复路 (Gwangbok-ro / 광복로)·BIFF广场 (BIFF Square / BIFF광장))→ 札嘎其(#244)→ 西面 → 东莱(#269温泉·#1323BASECOFFEE·#1324白家红豆铺)→ 温泉场。南端一直延伸到多大浦海水浴场 (Dadaepo Beach / 다대포해수욕장)(#272)。
  • 2号线:西面 → 庆星大·釜庆大 (Pukyong National University / 부경대) → 广安(#243)→ 海云台 → 森坦城 (Centum City / 센텀시티)。沿海观光都在这条线上。
  • 3号线:万德方向——K-pop巡礼(#1323)中乐高村 (Lego Village / 레고마을) 轴线所在。
  • 东海线:机张·奥西利亚(#270)——龙宫寺 (Yonggungsa / 용궁사)、乐天世界釜山 (Lotte World Busan / 롯데월드 부산) 方向不是地铁,而要靠这条广域电铁。
  • 发车间隔比首尔略长——涉及换乘的路线,比起谷歌地图,Kakao地图 (Kakao Map / 카카오맵)/Naver地图 (Naver Map / 네이버맵) 更准确。

③ 海边列车 — 既是交通也是观光

海云台蓝线公园 (Haeundae Blue Line Park / 해운대 블루라인파크):串联尾浦 (Mipo / 미포) → 青沙浦(#1324海景咖啡馆聚集带)→ 松亭 (Songjeong / 송정) 的海边观光列车。每小时约3班,单程约30分钟。列车行驶在废弃的东海南部线 (Donghae Nambu Line / 동해남부선) 旧铁轨上,让大海始终相伴左右,路线本身就是一场观光。

  • ⚠ 不能刷交通卡乘坐——需另购车票(可在线预约)。天空胶囊 (Sky Capsule / 스카이캡슐)(2~4人舱型)在热门时段常常售罄。
  • 在青沙浦下车逛咖啡馆 → 再步行到松亭的海岸散步路线组合是标准玩法。

④ 公交·出租车语法 — 山坡之城

  • 甘川文化村 (Gamcheon Culture Village / 감천문화마을)(#245)、山腰路是公交的地盘——需要从地铁站换乘社区巴士才能抵达。坡度陡峭,不建议步行进入。
  • 出租车以呼叫Kakao T为标准做法。比起担心短途拒载,叫车反而更快。
  • 市内公交采用按下车铃+后门下车的方式,交通卡刷卡即可。现金乘车实际上正在消失,建议以交通卡为基本手段。

⚠ 五条慌乱要点

1. 没有机场铁路——轻轨沙上换乘,或搭乘机场大巴。

2. 西面换乘很拥挤——尽量避开上下班高峰时段(8~9点、18~19点)。

3. 海边列车不能刷交通卡——需另购车票。

4. 奥西利亚、龙宫寺不是地铁而是东海线——在路线图上单独标注。

5. 甘川文化村离地铁站较远——换乘社区巴士才算走完全程。
