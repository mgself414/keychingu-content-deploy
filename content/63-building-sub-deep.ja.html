63ビル・汝矣島 — 63スカイピクニック・ポンピドゥーセンター・ハンファ・漢江12選（2026リニューアル基準）

🎯 2026年6月、63ビルがまるごと生まれ変わった

63ビル (63 Building / 63빌딩) は2026年6月4日に全面リニューアルを終えました。別館にポンピドゥーセンター・ハンファがオープンし、60階の展望台は63スカイピクニックとして再オープン(63階の屋上ルーフトップを含む)、低層の商業施設には飲食店・カフェ・ショップ25店が新しく入りました。一方、地下のアクアプラネット63は2024年6月30日に営業を終了しました — 古いブログや以前の割引券の情報を信じて行くと無駄足になります。以下の運営情報は、2026-10-07時点の各公式サイト(63skypicnic.com・centrepompidou-hanwha.kr・aquaplanet.co.kr)とハンファのプレスリリース(2026-06-01)に基づきます。

63ビル・汝矣島12選

1. 63ビル — 1985年、63階・約250m

  • 漢江の南、汝矣島の東端に立つ金色のガラスの建物。1985年に開業し、ソウルのスカイラインの象徴であり続けてきたため、漢江のどの橋から見ても目を引く。
  • 今は美術館・展望台・レストランが集まる複合文化空間。住所: ソウル永登浦区63路50 (Seoul Yeongdeungpo-gu 63-ro 50 / 서울 영등포구 63로 50)。

2. 63スカイピクニック — 60階展望台 + 63階ルーフトップ

  • 高さ250mから漢江と都心を360度見渡せる。60階は、鏡で囲まれたメイン展望台スカイ・インフィニティ、5面スクリーンの没入型上映館スカイ・ボヤージュ・シアター、ホログラム展示スカイ・ステージに分かれ、63階の屋上ヘリパッドがルーフトップとして開放されている(約16年ぶりの屋上開放)。スターバックス63スカイピクニック店が館内にある。
  • 運営: 毎日10:00〜22:00、発券09:50〜21:30、定休日なし(貸切日を除く)。
  • 料金: 大人(13〜64歳)27,000ウォン · 子ども(36か月〜12歳)23,000ウォン · 65歳以上23,000ウォン · 36か月未満は無料(保護者同伴)。
  • 注意: 入場時に渡されるシューズカバーの着用が必須で、スティレットヒール・ワークブーツ・鋲付きの靴は入場不可。大きな荷物・外部の飲食物は持ち込み不可。車椅子は展望エリアに入れず、ベビーカーは屋内持ち込み不可(公式案内)。

3. ポンピドゥーセンター・ハンファ — 別館の美術館

  • パリのポンピドゥーセンターとハンファ文化財団のパートナーシップにより、2026年6月4日に開館。建築家ジャン=ミシェル・ビルモットが設計した「光の箱」コンセプトの別館に、大型展示室を2つ設けた。
  • 観覧: 火・木・金・日 10:00〜18:00(入場17:30) · 水・土 10:00〜21:00(入場20:30) · 月曜・1月1日・旧正月・秋夕は休館。
  • 料金: 大人28,000ウォンから(子ども・青少年・シニア割引あり)。当日の展覧会チケットがあれば、63ビル地下駐車場が平日1時間・週末2時間無料。
  • 現在の展覧会: 〈ガーデン・プロジェクト: 刻まれるもの〉 2026-09-06 ~ 2027-03-07。開館記念展〈キュビスト: 視覚の革新者たち〉は10月4日に終了した。無料講演は14:00(180席)、有料ドーセントツアーは11:30・16:30に事前予約。

4. 63アウドルフ・ガーデン — ビルの足元の庭

  • ニューヨークのハイラインやシカゴのルーリー・ガーデンを手がけた造園家ピート・アウドルフによる庭。種・新芽・花・枯れた茎まで、植物の一年をそのまま残す設計なので、秋・冬も見どころがある。展望台から降りて漢江公園へ向かう途中に通る。

5. 食事 — リニューアルで入った飲食店・カフェ

  • ハンファのプレスリリースによる新規入店: ミシュランガイド掲載の平壌冷麺ソリョン (Seoryeong / 서령)、東京・食べログ1位のラーメンラーメンヤ シマ (Ramenya Shima / 라멘야 시마)の韓国1号店、カロスキルの韓国料理ダイニングビストロ サンホ (Bistro Sanho / 비스트로 산호)、タイ料理カーポム (Kkapom / 까폼)、日本料理コヒョン (Gohyeon / 고현)、ハワイのコーヒー・アサイーボウルアイランド・ヴィンテージ・コーヒー (Island Vintage Coffee / 아일랜드 빈티지 커피)、ナポリ式窯焼きサンドイッチパジャク (Pajak / 파작)、アイスクリームベンソン (Benson / 벤슨)。
  • 営業時間・価格は店ごとに異なるので現地で確認する。63ビュッフェは「63ビュッフェ パビリオン・ザ・プレミアム (63 Buffet Pavilion The Premium / 63뷔페 파빌리온 더 프리미엄)」として、ワインダイニング「CESTONE」は年末オープンと発表された(6月のプレスリリース基準 — 訪問前に要確認)。

6. 63ビル夜間LED — 外から見る無料の夜景

  • 日が暮れると金色の外壁に照明が灯る。汝矣島漢江公園や元曉大橋 (Wonhyo Bridge / 원효대교) 側から見ると、漢江に映る姿まで一枚に収まる。お金はかからない。

7. 汝矣島漢江公園

  • 63ビルから漢江側へ降りるとすぐ公園。春の桜、秋の花火祭りの舞台で、普段はレジャーシート・自転車・チメク(チキン+ビール)の公園(#700)。

8. 漢江遊覧船 (#704)

  • 汝矣島の船着き場からE.Landの遊覧船が出る。63ビルの夜景を川の上から見る最も手軽な方法。運航時間・料金は#704。

9. IFCモール + The Hyundai Seoul

  • 汝矣島駅 (Yeouido Station / 여의도역)、5号線 側のショッピングモール2か所。63ビルとはバスか徒歩で結ぶ。雨の日の代案。

10. ショップ — リニューアルで入ったセレクトショップ

  • 北欧ライフスタイルのROOMING&HAY、サブカルチャーのセレクトショップロパ・ソウル (Ropa Seoul / 로파 서울)、ギフトキュレーションプレゼントモーメント ホホ (Present Moment Hoho / 프레젠트모멘트 호호)、アーティストのポストカードポセット (Poset / 포셋)(ハンファのプレスリリース基準)。展望台のお土産の代わりに立ち寄る価値がある。

11. 4月 — 汝矣島の桜

  • 4月上旬の汝矣島・尹仲路 (Yunjungno / 윤중로) の桜並木と漢江公園。63ビルを背景に桜を撮れるスポットが多い(#753)。

12. 10月 — ソウル世界花火祭り

  • ハンファが開く花火祭り。毎年10月初めの土曜の夜、汝矣島漢江公園一帯で開催、観覧無料(日付は毎年の告知を確認)。63ビル側の河川敷が特等席なので、昼から場所取りをする。

FAQ 6

Q1. 以前の統合入場券(アクア + 展望台 + アート 13,500ウォン)は? A. なくなりました。 アクアプラネット63が2024-06-30に営業を終了し、63アートはポンピドゥーセンター・ハンファに変わりました。今は63スカイピクニック(27,000ウォン)とポンピドゥーセンター・ハンファ(28,000ウォン〜)をそれぞれ予約します。

Q2. 63スカイピクニックの営業時間は? A. 毎日10:00〜22:00、発券09:50〜21:30。定休日なし(貸切日を除く)。夜景は日没後22時まで楽しめます。

Q3. ポンピドゥーセンター・ハンファはいつ開いていますか? A. 月曜休館。 火・木・金・日は10:00〜18:00、水・土は21:00まで。1月1日・旧正月・秋夕も休みです。2027年3月7日まで〈ガーデン・プロジェクト: 刻まれるもの〉。

Q4. 63ビルへの行き方は? A. 5号線汝矣ナル駅 (Yeouinaru Station / 여의나루역) 1番出口からバス5634・5633・261 → 「63ビル」停留所 / 5号線汝矣島駅5番出口から11番 / 9号線セッガン駅 (Saetgang Station / 샛강역) 3番出口から5633・5634。平日は大方駅 (Daebang Station / 대방역)、1号線・汝矣ナル駅・汝矣島駅・セッガン駅から無料シャトルが運行(週末はなし)。汝矣ナル駅から漢江公園沿いに歩いても行けます。

Q5. 花火祭りはいつ? A. 毎年10月初めの土曜の夜、汝矣島漢江公園。観覧無料。日付・交通規制はその年の告知を確認してください。

Q6. アクアプラネット63は? A. 2024年6月30日に営業終了(アクアプラネット公式案内)。ソウルで水族館に行くなら、ロッテワールド・アクアリウム (Lotte World Aquarium / 롯데월드 아쿠아리움)、#198かCOEXアクアリウム (COEX Aquarium / 코엑스 아쿠아리움)、#440へ。

フルデーコース3

A. 美術館 + 展望台 (昼)

  • 10:00 ポンピドゥーセンター・ハンファ (1〜1.5時間)
  • 12:00 昼食 — 63ビル内のレストラン(ソリョン・ラーメンヤ シマ・ビストロ サンホから1つ選ぶ)
  • 14:00 63スカイピクニック (60階 → 63階ルーフトップ)
  • 16:00 63アウドルフ・ガーデン → 汝矣島漢江公園を散策
  • ※ 水・土なら順番を入れ替え、展望台を先に、ポンピドゥーは夜(21時まで)にする。

B. 夜景 + 遊覧船

  • 17:00 63スカイピクニック — 日没から夜景まで一か所で
  • 19:00 E.Land遊覧船 (#704) — 川の上から63ビルのLED
  • 20:30 汝矣島漢江公園でチメク → 盤浦虹の噴水 (Banpo Rainbow Fountain / 반포 무지개분수)、#702へ移動も可能

C. 10月の花火祭り (当日)

  • 12:00 汝矣島漢江公園に到着、63ビル側の河川敷に場所取り
  • 15:00 63ビル内で食事・トイレを済ませる(祭り当日は混雑)
  • 夜 ソウル世界花火祭り
  • ※ 終了後は地下鉄駅が規制・混雑 — 一駅分歩いて出るほうが早い

Tip 5

1. 統合券はない — スカイピクニックとポンピドゥーをそれぞれ予約。両方見るなら一日空ける。

2. 水・土はポンピドゥーが21時まで — 展望台を昼、美術館を夜の順にすると楽。

3. スカイピクニックの服装 — シューズカバー着用、ヒール・ワークブーツ不可。ベビーカーは屋内持ち込み不可、車椅子は展望エリアに入れない。子ども連れ・保護者は事前に計画を。

4. 駐車 — スカイピクニック・ポンピドゥーとも平日1時間・週末2時間無料(チケット所持)、以降は有料。

5. 花火祭りの日は63ビル内の施設も混雑 — 予約・食事は早めに。
