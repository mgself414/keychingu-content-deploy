釜山站前的一小时——草梁唐人街,饺子与华侨中餐馆9家

副标题: 从KTX下车,穿过车站广场,就能看到红柱子的上海门。门内就是1884年从清朝领事馆起步的釜山华侨街——上海街。有从1951年起包饺子的店,有出现在电影《老男孩》里的煎饺店,有盖着煎蛋的干炸酱面,还有小巷尽头的乌兹别克斯坦餐厅——按火车时间来吃的方法

🎯 为什么说"釜山站前的一小时"

坐KTX来釜山的人,几乎都会经过釜山站 (Busan Station / 부산역)。到达时一次,离开时一次。可这一小时通常在站内的连锁店或便利店里就过去了。

车站广场对面的小巷则不一样。1884年这里设立了清朝领事馆,华侨 (Huaqiao / 화교)们就在周围安顿下来,这一带就是草梁 (Choryang / 초량) 唐人街。韩国战争之后,做美军生意的店铺聚集在这里,得名得克萨斯街 (Texas Street / 텍사스거리),1980年代末起俄罗斯船员和商人也开始出入。1993年釜山与上海结为友好城市,入口处立起了上海门 (Shanghai Gate / 상해문),街名也成了上海街 (Shanghai Street / 상해거리)。2007年被指定为国内唯一的唐人街特区。

所以这条小巷的饮食有三层。华侨一直包下来的饺子、最接近韩式中餐馆原型的炸酱面·韩式海鲜辣汤面·五香酱肉,以及得克萨斯街一侧的俄罗斯·中亚菜。全都可以从车站步行到达。

⚠ 有效期: 以2026年9月30日确认为准。9家店铺均已通过Naver地区搜索确认存续与道路名地址。营业时间·休息日·菜单价格是直接打开DiningCode店铺页面确认的数值,各来源不一致的地方在表中单独标注。价格是菜单标价,可能会变。

顺序是从车站一侧的入口(上海门)到小巷深处。大瀛路243番街 (Daeyeong-ro 243beon-gil / 대영로243번길) 是一条单行的小巷,店与店之间不远——从入口处的Sinbalwon (신발원) 到最里面的Rakcheongak (락천각),直线距离约220米。

🥟 饺子四家——从入口开始

Sinbalwon 是1951年开门的饺子店,穿过上海门最先遇到的就是这家。肉饺 (Gogi Mandu / 고기만두) 4个4,800韩元,煎饺 (Gunmandu / 군만두) 4个5,500韩元,虾饺 (Saeu Mandu / 새우만두) 4个6,500韩元,各卖一盘。点把三种各装两个的肉煎虾三拼 (Gogunsae / 고군새)(8,500韩元),一次就能比较。除了饺子,还有豆汤和豆汤点心 (Kongguk and Kongguk-gwaja / 콩국과 콩국과자)(4,500韩元)、功夫面 (Kungfu-myeon / 쿵푸면)(5,900韩元)。周二休息。

Maga Mandu 离Sinbalwon 约37米,几乎就是隔壁。煎饺·蒸饺 (Jjinmandu / 찐만두)·水饺 (Mulmandu / 물만두) 各8,000韩元,也有麻婆豆腐、虾仁炒饭之类的正餐。周三休息,但是每周还是隔周因来源而异,所以周三去的话要先确认。Sinbalwon 门前排长队时,这家是最近的替代。

Jangseonghyang 是从1984年开始营业的店。据韩国政府门户网站korea.net在2019年的报道,2003年电影《老男孩》(Oldboy, 2003) 里主人公吴大秀被关15年吃的煎饺就是这家的。煎饺(小份)9,000韩元,炸酱面 (Jjajangmyeon / 짜장면) 7,000韩元,干炸酱面 (Ganjjajang / 간짜장) 9,000韩元。只吃饺子的话去Sinbalwon,饺子和炸酱面一起吃就选Jangseonghyang 更方便。

Ilpumhyang 蒸饺·水饺9,000韩元,炸饺 (Twigim Mandu / 튀김만두) 10,000韩元,五香酱肉、辣子鸡 (Rajogi / 라조기) 之类的菜也很丰盛。周日休息,15~17点休息时间。

🍜 华侨老店的主菜——炸酱面、韩式海鲜辣汤面、五香酱肉

只吃饺子就出来,这条小巷只看了一半。华侨中餐馆的主菜在别处。

Wonhyangjae 与Sinbalwon 同在1951年开门,门牌号也紧挨着(60号)。招牌是盖着煎蛋的干炸酱面 (Ganjjajang / 간짜장)(10,000韩元)和五香酱肉 (Ohyang Jangyuk / 오향장육, 猪肉)——菜单上列为"70年传统酱肉"(36,000韩元)。休息时间15:00~16:50很长,休息日因来源而异,出发前需要确认。

Hongseongbang 是1971年开门的店,在小巷旁边一条的中央大路179番街。三鲜韩式海鲜辣汤面 (Samseon Jjamppong / 삼선짬뽕)(小份9,000韩元)和水饺(小份8,000韩元)较有名,还有午间特选套餐(18,000~20,000韩元)。最后点单是20:30。

Jangchunbang 有五香酱肉(小份23,000韩元)、地三鲜 (Jisamseon / 지삼선)(20,000韩元)、炸茄子(13,000韩元)等,菜品的范围很宽。适合几个人去,点两三个菜分着吃。10:40开门,是这条小巷里最早的。

🍢 羊肉串与中亚——小巷深处

Rakcheongak 在小巷最里面。华侨中餐馆的菜单(炸酱面 7,000韩元·煎饺 8,000韩元)之外,还加上了羊肉串 (Yangkkochi / 양꼬치)(5串10,000韩元)和茄子丸子(20,000韩元)。营业到22:00,适合很晚才到的火车。周一休息。

Samarkand 是乌兹别克斯坦餐厅。是这条小巷还被称作得克萨斯街的年代延续下来的俄罗斯·中亚一面。有罗宋汤(俄式甜菜汤,18,000韩元)、炸羊肉(21,000韩元)、鸡肉卡巴布 (Dak Kebab / 닭케밥)(7,000韩元)、馕 (Naan / 난)(6,000韩元)。11:00~23:00,营业到最晚。饮食相关标注另写在下面的预算与饮食一项。

🕐 按火车时间的路线

所有路线都从釜山站1号出口 → 上海门出发。

30分钟——一盘饺子

Sinbalwon(周二休息)或Maga Mandu(周三休息)。两家相距约37米。一边排长队就去另一边。点一盘Gogunsae 就能把三种饺子都尝到。

1小时——饺子 + 一碗炸酱面

一盘饺子之后,去隔壁Wonhyangjae 吃干炸酱面(注意休息时间15:00~16:50),或者在Jangseonghyang 一处吃到煎饺和炸酱面。想吃韩式海鲜辣汤面就去Hongseongbang。

2小时——分着吃菜的晚餐

在Jangchunbang 或Ilpumhyang 几个人分吃五香酱肉·糖醋肉之类的菜,最后以Rakcheongak 的羊肉串收尾。好奇俄罗斯·中亚一侧的话,去Samarkand 吃罗宋汤和馕。

如果下午3~5点到达——不设休息时间营业的有Sinbalwon·Jangseonghyang·Jangchunbang·Rakcheongak·Samarkand(以各店标注为准)。Maga Mandu 16:00重新开门。

💰 预算与饮食——能避开什么

价格分三层。 以下金额是菜单价格(DiningCode标注,2026-09-30确认)。

  • 1万韩元以下——饺子·面一碗: Sinbalwon 肉饺4,800韩元·Gogunsae 8,500韩元,炸酱面7,000韩元(Jangseonghyang·Hongseongbang·Jangchunbang·Rakcheongak),一盘饺子8,000~9,000韩元,Samarkand 鸡肉卡巴布7,000韩元。
  • 1万~2万韩元——干炸酱面·韩式海鲜辣汤面·套餐: Wonhyangjae 干炸酱面·海鲜辣汤面各10,000韩元,Jangseonghyang 三鲜韩式海鲜辣汤面15,000韩元,Hongseongbang 午间特选套餐18,000~20,000韩元,Samarkand 罗宋汤18,000韩元。
  • 2万韩元以上——分着吃的菜: Jangchunbang 五香酱肉(小份)23,000韩元,糖醋肉28,000韩元(Jangseonghyang·Wonhyangjae),Ilpumhyang 五香酱肉33,000韩元,Wonhyangjae 70年传统酱肉36,000韩元。

饮食——选择很窄。只写有的。

  • 猪肉 — 肉饺·煎饺的馅、炸酱、五香酱肉基本都是猪肉。这条小巷的代表菜大部分都在此列。
  • 羊·鸡 — Rakcheongak 的羊肉串,Samarkand 的羊肉·鸡肉菜。Rakcheongak 没有清真标注。
  • 清真 — Samarkand 的DiningCode介绍中写有"清真认证"字样,而且不卖酒(据说可以自带外带酒水)。是否认证以介绍文字为准,如果严格遵守,请在店里直接确认认证证书。
  • 素食 — 实际上很难。虾饺或茄子菜的馅·高汤·油里也可能有肉,麻婆豆腐通常会放肉末。以点餐前先询问为前提。

⚠ 常见错误3条

1. 周二把Sinbalwon 当目标去 — Sinbalwon 周二休息。休息日分散在各个星期——周一(Rakcheongak,Jangchunbang 为第1·3·5个周)、周二(Sinbalwon)、周三(Maga Mandu,Wonhyangjae 因来源不同为周三或周一)、周日(Ilpumhyang)。目标店休息,同一条小巷里也有替代,先看表上当天营业的店。

2. 下午3点到,先去老店 — Wonhyangjae·Ilpumhyang·Hongseongbang 在15:00~17:00前后关门。这个时间去没有休息时间的Sinbalwon·Jangseonghyang·Jangchunbang·Rakcheongak。

3. 只吃饺子就出来 — 1950~70年代开业的华侨老店,名气在于干炸酱面·三鲜韩式海鲜辣汤面·五香酱肉。两个人以上的话,分成一家吃饺子 + 一家吃正餐。

⚙ 常见问题解答(FAQ)3个

Q. 为什么把釜山唐人街叫作"上海街"?

1993年釜山与上海结为友好城市,街名定为上海街,并在入口处立起上海门。华侨街本身比这早得多,1884年清朝领事馆入驻之后形成。

Q. 《老男孩》里的煎饺是哪家的?

据korea.net(2019),电影里的煎饺是这条小巷里Jangseonghyang 的。Jangseonghyang 现在仍在卖煎饺(小份9,000韩元)。

Q. 带着行李可以去吗?

小巷很窄,店也很小。要逛好几家的话,减少行李会更方便。只去一家的30分钟路线,从车站广场只隔一条马路的距离。
