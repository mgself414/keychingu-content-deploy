⚠ 初めての外国人がよくやる3つのミス

1. 「江南 (강남) =ショッピング」という認識だけで、韓食の本拠地と知らない

江南区 (강남구) は 韓国ミシュラン韓食の本拠地 — チョンシクダン (정식당) (3スター)、ミングルス (밍글스) (2スター)、ホテル韓食まで揃う。外国人は韓食＝インサドン (인사동)·鍾路 (종로) というイメージが強いが、江南 (강남) こそミシュラン·モダン韓食の頂点。

2. ミシュランは高いだけと思っている

チョンシクダン (정식당)·ミングルス (밍글스) のランチコース ₩100,000〜150,000 は、外国人が慣れたミシュランの ¥/$/€ 換算と比べると割安。ディナー ₩250,000〜 フルコースも外国人目線では十分リーズナブル。予約は1〜2週間前が必須。

3. 老舗韓食をインサドン (인사동)·鍾路 (종로) だけで探す

ボンピャン テチ店 (봉피양 대치점)·ドルサン トンデジプ (돌산등대집) など 江南 (강남) の老舗韓食が正統のトーンを維持。インサドン (인사동) より落ち着いた雰囲気で外国人フレンドリー度も高い。

江南 (강남) エリアの韓食シーン

江南区 (강남구) は 韓国韓食のラグジュアリーな頂点。チョンダム (청담) (ミシュラン·モダン)·ノンヒョン (논현) (コース·正統)·テチ (대치) (平壌式老舗)·カンナム駅 (강남역) (チェーン·一般) — サブエリアごとに韓食のトーンが明確。ミシュランから老舗まで価格帯 ₩30,000〜250,000 と幅広い。

① ミシュラン (2店)

チョンシクダン (정식당) / Jungsik

チョンダム (청담) 発 韓国初ミシュラン3スターモダン韓食 (NY·ソウル両都市で営業)。韓食の精髄 + モダンプレーティング + ワインペアリング。シェフ イム・ジョンシク (임정식)。外国人ミシュランファン第1候補。

  • 住所: 江南区 (강남구) ドサン大路 (도산대로) (チョンダム (청담))
  • 営業: 火〜日 18:00〜22:00、ランチ 12:00〜14:30 (要予約)
  • メニュー: ディナーコース ₩250,000〜 / ワインペアリング ₩150,000〜
  • シグネチャー: ミシュラン3スター + モダン韓食 + NY本店
  • おすすめ理由: 江南 (강남) 韓食の頂点。外国人ミシュランファン + ビジネスディナーに最適。

ミングルス (밍글스) / Mingles

チョンダム (청담) 発 ミシュラン2スターモダン韓食。シェフ カン・ミング (강민구)。韓食素材 + グローバル技法 + 自家製発酵醤活用。コスパミシュランとして外国人評価が高い。

  • 住所: 江南区 (강남구) ドサン大路 (도산대로) (チョンダム (청담))
  • 営業: 火〜日 18:00〜22:00、一部ランチあり
  • メニュー: ディナーコース ₩200,000〜 / ペアリング ₩100,000〜
  • シグネチャー: ミシュラン2スター + 自家製発酵醤
  • おすすめ理由: チョンシクダン (정식당) の代替または、ミシュラン入門として最適。コスパ + 韓食の精髄。

② ホテル正統 (2店)

チョソン パレス イタニック ガーデン (조선 팰리스 이타닉 가든) / Itanic Garden, Chosun Palace

江南 (강남) チョソンパレスホテル (조선 팰리스) 内の 5つ星韓食堂。★4.4 + 英語レビュー5件。韓食コース·季節メニュー。ホテルサービス + 正統韓食。

  • 住所: 江南区 (강남구) テヘランロ (테헤란로) (カンナム (강남))
  • 営業: 毎日 06:00〜22:00 (ホテルレストラン)
  • メニュー: 韓食コース·ビュッフェ·アラカルト
  • シグネチャー: 5つ星ホテル正統韓食
  • おすすめ理由: 外国人ビジネス客 + 安心·高級オプション。ホテル宿泊者に最適。

コボンダン ノンヒョン駅店 (고봉당 논현역점) / Gobongdang Nonhyeon

ノンヒョン駅 (논현역) 周辺の 韓定食コース本店。★5.0 + 英語レビュー5件。韓定食正統 — チョン (전·チヂミ)·プルゴギ (불고기·焼き)·チゲ (찌개·鍋)·バンチャン (반찬·小鉢) フルセット。ランチコースのコスパが光る。

  • 住所: 江南区 (강남구) ノンヒョン洞 (논현동) (ノンヒョン駅 (논현역))
  • 営業: 毎日 11:30〜22:00
  • メニュー: 韓定食ランチコース ₩30,000〜 / ディナー ₩50,000〜
  • シグネチャー: 韓定食コース本店
  • おすすめ理由: 正統韓定食コース入門。ランチコスパ最良。

③ 老舗正統 (2店)

ボンピャン テチ店 (봉피양 대치점) / Bongpiyang Daechi

テチ洞 (대치동) の 平壌式老舗本家 (#129 ネンミョン (냉면·冷麺) ガイド掲載店)。ピョンヤンネンミョン (평양냉면·平壌冷麺)·マンドゥ (만두·餃子)·ノクドゥジョン (녹두전·緑豆チヂミ)。創業60年以上の老舗。外国人向け平壌料理正統入門コース。

  • 住所: 江南区 (강남구) テチ洞 (대치동)

  • シグネチャー: 平壌式老舗本家
  • おすすめ理由: 江南 (강남) で平壌料理の正統体験。老舗 + 平壌式フルセット。

ドルサン トンデジプ (돌산등대집) / Dolsan Etdaejip

  • シグネチャー: 江南老舗韓食
  • おすすめ理由: ボンピャン (봉피양) とは異なるトーンの老舗。本格的な韓食全般。

⚙ FAQ 8問

Q1. ミシュラン韓食の予約は？

チョンシクダン (정식당)·ミングルス (밍글스) ともに1〜2週間前の予約が必須。チョンシクダン (정식당) 公式サイト + Tabling または The Catch (一部英語インターフェース)。ミシュランガイドサイトも利用可。

Q2. 外国人フレンドリー度が高いのは？

チョソンパレス (조선 팰리스) / コボンダン (고봉당) / ドンファ コオク (동화고옥) / コタバイデオン (코타바이뎐) — 英語メニュー·サービスが充実。チョンシクダン (정식당)·ミングルス (밍글스) も英語対応可 (シェフのグローバルキャリアによる)。

Q3. 価格帯の分布は？

ミシュラン ₩200,000〜350,000 / ホテル ₩40,000〜120,000 / 老舗韓食 ₩15,000〜30,000 / モダン韓食 ₩30,000〜80,000。

Q4. ランチ vs ディナー？

ランチコース がコスパ最良 (チョンシクダン (정식당) ₩120,000 vs ディナー ₩250,000)。ホテル·モダン韓食もランチは30%割安。ディナーはワインペアリングフルセット向き。

Q5. ベジタリアン·ハラール·コーシャは？

ミングルス (밍글스) / チョンシクダン (정식당) — 事前リクエストでベジタリアンコース対応可。ホテル韓食 (チョソンパレス (조선 팰리스)) — ハラール·コーシャは事前協議。

Q6. 平壌料理の外国人入門は？

ボンピャン (봉피양) が正統 (創業60年以上の老舗)。ピョンヤンネンミョン (평양냉면·平壌冷麺) は韓国料理の精髄のひとつ — 冷たいスープ·そば麺·肉トッピング。初回はランチがおすすめ。

Q7. 車椅子アクセスは？

チョソンパレス (조선 팰리스)·コボンダン (고봉당)·ドンファ コオク (동화고옥)·コタバイデオン (코타바이뎐) — フラットな動線·エレベーター完備。チョンシクダン (정식당)·ミングルス (밍글스)·ボンピャン (봉피양)·ドルサン トンデジプ (돌산등대집) は店舗により通路が狭い場合あり。

Q8. ドレスコードは？

チョンシクダン (정식당)·ミングルス (밍글스) — スマートカジュアル推奨 (短パン·サンダル不可)。チョソンパレスホテル (조선 팰리스) — ビジネスカジュアル。老舗·モダン韓食 — 自由。
