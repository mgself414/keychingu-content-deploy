⚠ 외국인 자주 실수 5가지

1. "김치 cluster 어디부터?": #836 본 가이드 → #822 매트릭스 → #831 식당 동선 순서. segment 정해서 4~5편만 선택.

2. "매니아 매트릭스 모름": MZ·매콤 매니아 = #835 (김치찌개 노포)·돼지국밥 (#834)·김치찜 (#835·#12)·#833 (신라면+묵은지).

3. "가족·어린이 매트릭스 모름": 가족 = #834 (삼계탕·설렁탕)·#835 (김치만두·김치보쌈·김치볶음밥) = 안 매움.

4. "예산형 매트릭스 모름": 예산형 = 식당 무료 김치 (#831) + 편의점 라면+김치 콤보 (#832·#833) = 1일 15,000~25,000원.

5. "시즌·시간 매트릭스 모름": 시즌·시간·예산 매트릭스 = 본 가이드 참조. 여름 = 김치말이국수·삼계탕·겨울 = 김치만둣국·김치찜.

⚙ FAQ 6개

1. 첫 한국 방문·시작 추천: 본 가이드 → #822 매트릭스 → #831 식당 동선 → segment별 5편 = 총 6편 (1~2시간 읽기).

2. segment별 시간 투자: 혼자·MZ = 5~6편 (1~2h) / 커플·가족 = 3~4편 (1h) / 예산형 = 3편 (1h).

3. 시즌 매니아 1순위: 여름 = 김치말이국수 (#835·#7)·겨울 = 김치만둣국 (#835·#11)·가을 = 김치전+막걸리 (#835·#9).

4. 김장 체험 (#751 cross): 11월 (가을)·북촌·전주·서울 김치 박물관·30,000~80,000원/인.

5. 알레르기·식이 제한 풀세트: #822 + 각 가이드 disclaimer 섹션 참조. 할랄·코셔·채식·글루텐 free fallback 명시.

6. 김치 cluster 미래 확장: 김장 deep (#751·계획)·김치 박물관 deep·김치 건강 효과 (발효·#523) = 향후 추가 후보.
