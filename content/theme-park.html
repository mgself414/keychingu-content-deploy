⚠ 외국인 자주 실수 5가지

1. "한국 테마파크 = 한국인만": 한국 테마파크 = 롯데월드·에버랜드 외국인 매니아 1번지 + 영어 OK + Klook·KKday 외국인 패키지 + #210 가족·#211 통합.

2. "롯데월드 = 비쌈": 롯데월드 = 56K·외국인 가성비 1번지 (일본 60%·미국 30% 저렴) + Klook 외국인 패키지 30~50K + 외국인 매니아 풀세트.

3. "에버랜드 = 너무 멀어": 에버랜드 = 용인 1.5h·외국인 셔틀 (Klook·KKday)·외곽 1박2일 매니아 + #210 가족 매니아·KTO 인증.

4. "캐리비안베이 = 여름만": 캐리비안베이 = #385 여름 #1 + 외국인 매니아 1번지 + 외국인 가족·데이트 매니아·KTO 인증.

5. "외국인 아쿠아리움 = 어디나": 아쿠아리움 = 63 빌딩 (여의도)·코엑스 (#142·#366)·롯데월드 (#198) + 외국인 매니아 1번지·#366 통합.
