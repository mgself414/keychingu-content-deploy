한국 술 주문·페어링 워크플로우 — 소맥 만들기부터 막걸리 흔들기까지

> 부제: 외국인 관광객용 5-step 워크플로우 + 음주 매너·소맥 비율·강요 거부·결제 팁

ISSUE 03 · #829 · 2026-06-08

🎯 왜 한국 술 워크플로우 가이드인가

[#828 한국 술 6종 매트릭스](#828) 알아도 — 주문·먹는·매너는 별개. 한국 술 문화는 (a) 소맥 (Soju+Beer) 비율·만들기 매너 (b) 막걸리 흔들기 침전물 + 두 손 따르기 (c) 어른 앞 고개 돌려 마시기 정통 매너 (d) 회식 강요 거부 매너 (e) 계산 패턴 한 명 계산 후 송금 (카카오페이·토스). 외국인은 (1) 소맥 비율 모르고 (2) 막걸리 흔들기 안 하고 (3) 강요 거부 매너 모르고 (4) 음주 한도 미준수 등 페인포인트. 본 가이드는 5-step + 매너 매트릭스 + 영어 발화 + 음주 안전 팁.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 매장 선택 + 좌석 치킨집 / 횟집 / BBQ / 포차 / 막걸리집 / 이자카야 / 하이볼 바 즉시 음식 + 술 페어링
2️⃣ 주문 술 + 안주 동시 주문 2~5분 "이거 무엇 페어해요?" 직원 추천 OK
3️⃣ 받기 + 매너 세팅 술병·잔·기본 안주 5~10분 두 손 따르기·받기 매너
4️⃣ 마시기 + 페어링 건배·페어링·소맥·매너 1~3h 외국인 페이스 조절
5️⃣ 결제 한 명 결제 → 카카오페이·토스 송금 1~3분 "더치페이" 가능 매장 일부

> 총 소요 시간: 1~3h (식사 + 술 페어링)

🍶 소맥 (Soju+Beer) 만들기 매너

소맥 정의 & 비율

  • 소맥 = 소주 (Soju) + 맥주 (Beer) = 한국 회식 #1 클래식 페어
  • 표준 비율: 1:3 (소주 1 : 맥주 3) 또는 1:2.5 (소주 비중 ↑)
  • 1:2 비율 = 소주 과다 → 빨리 취함 (외국인 비추)

소맥 만들기 단계

1. 맥주잔 (350~500ml) 준비

2. 맥주 70% 따르기 (잔 70% 채움)

3. 소주잔 (45ml) 1잔 준비

4. 소주 1잔 맥주에 부어 넣기

5. 흔들기 OR 젓가락으로 가볍게 휘젓기

6. 건배 후 마시기

외국인 매니아 팁

  • 소맥 = 짧게: 30초~1분 내 마시기 (소주 알코올 휘발 방지)
  • 소맥 = 누적 ↑: 1잔 = 표준잔 1.5~2, 2잔 = 3 표준잔 = 빠른 취함
  • 소맥 강요 거부 OK: "I don't drink shots" 또는 손바닥 위 잔

🍯 막걸리 마시는 법

막걸리 흔들기·따르기

1. 흔들기: 그릇 바닥 침전물 (효모) + 위쪽 맑은 부분 = 흔들어서 풀기

  • 막걸리병 위아래 천천히 5~10회 흔들기

2. 잔 따르기: 어른에게 두 손으로 따르기

3. 받기: 어른이 따라줄 때 두 손으로 잔 받기

4. 건배: "건배!" 또는 "위하여!"

5. 마시기 (어른 앞): 고개 돌려 마시기 (정통 매너)

6. 첫 잔: 한 입 또는 통째 (개인 취향)

막걸리 페어링 매니아

  • 김치전 + 막걸리 = 비 오는 날 #1
  • 해물파전 + 막걸리 = 정통 한정식
  • 녹두전 + 막걸리 = 막걸리집 정통
  • 보쌈 + 막걸리 = 정통 회식
  • MZ 트렌드: 우유 막걸리·복숭아 막걸리·딸기 막걸리

🙏 음주 매너 핵심 7가지

한국 술 매너 (전통)

1. 두 손 따르기: 어른에게 술 따를 때 두 손으로

2. 두 손 받기: 어른이 따라줄 때 두 손으로 잔 받기

3. 고개 돌려 마시기: 어른 앞에서 옆으로 고개 돌려 마시기 (정통)

4. 잔 비우기: 어른 따라줄 잔 = 비우기 권장 (현대 = 강요 X)

5. 건배 시: 잔 위치 = 어른보다 약간 낮게 (전통)

6. 자기 잔 채우기 금물: 다른 사람이 따라주기

7. 첫 잔 = 어른 먼저: 어른이 먼저 따른 후 본인

강요 거부 매너 (현대)

  • "I don't drink" = 직접적 거부 OK
  • "한 잔만" = 1잔 시도 후 거부
  • 손바닥 위 컵 들기 = 비언어적 거부 신호
  • 약 복용 = "약 먹어요" (의료 사유)
  • 운전 = "운전해요" (운전 사유)

> 현대 한국 회식 문화 = 강요 거부 일반화. 거부해도 매너 위반 아님.

🌶 외국인 영어 발화 샘플

  • "소맥 한 잔" = "One somaek, please"
  • "막걸리 한 병" = "One makgeolli, please"
  • "청주 한 병" = "One cheongju (Korean sake), please"
  • "하이볼" = "Highball"
  • "건배!" = "Cheers!"
  • "I don't drink" = 한국어 = "안 마실래요"
  • "한 잔만" = "Just one shot, please"
  • "카드 돼요?" = "Card accepted?"
  • "카카오페이 송금" = "Send via KakaoPay"

💰 결제 워크플로우

한국식 결제 패턴

1. 한 명이 카드 결제 (보통 회식 호스트)

2. 카카오페이·토스로 송금 (참석자별 정산)

3. 금액 = 인당 평균 ÷ N등분 (균등 분배)

더치페이 (Dutch pay) 매장

  • MZ 매장: 더치페이 시스템 多 (개별 결제)
  • 일반 회식 매장: 더치페이 X (한 명 결제)
  • 편의점·카페: 카드 개별 결제 OK

⚠ 외국인 자주 실수 7가지

1. "소주 = 보드카처럼 강함": 소주 16~17% (보드카 40% 절반 이하). 부드럽지만 누적 ↑.

2. "막걸리 = 흔들기 X": 반드시 흔들기 (침전물 + 맑은 부분 섞기).

3. "소맥 = 자유 비율": 표준 1:3 또는 1:2.5. 1:2는 소주 과다.

4. "어른 앞 = 정면 마시기": 정통 매너 = 고개 돌려 마시기.

5. "강요 거부 = 매너 위반": 현대 한국 = 강요 거부 OK.

6. "음주운전 = 가벼움": 0.03% BAC = 면허정지 (한국 단속 강력).

7. "결제 = 더치페이 표준": 한국식 = 한 명 결제 → 송금 패턴 多.

⚙ FAQ 8개

1. 첫 술 = 어떤 매니아: 맥주 (입문) → 막걸리 (전통) → 소주 (글로벌) → 소맥 (회식) 단계.

2. 인스타·vlog: 막걸리 흔들기·소맥 만들기·하이볼 바 MZ vlog.

3. MZ 트렌드: 과일 소주·우유 막걸리·하이볼 바·저도수 소주.

4. 회식·접대: 소주·맥주 (일반)·청주·전통주 (정통).

5. 음주 매너: 두 손 따르기·받기·고개 돌려 마시기 (어른 앞).

6. 음주운전: 0.03% BAC 면허정지 + 형사처벌.

7. 알레르기: 글루텐 (맥주)·콩 (막걸리·청주)·과일 (과일 소주) 사전 고지.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·법률 disclaimer

한국 술 = 알코올 (도수 4~45%). 음주운전 0.03% BAC 면허정지 + 벌금 + 형사처벌. 임신부·약물 복용자 = 음주 금지. 19세 미만 = 법적 음주 금지. 알레르기 (글루텐·콩·과일·견과류) 사전 고지. 식중독·과음 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

음주 한도 (개인별 다름):

  • 표준잔 = 14g 알코올 (소주 1잔·맥주 1잔·와인 1잔)
  • 외국인 매니아 = 표준잔 2~3개 권장 (1~2h 식사 + 술)
  • 누적 ↑ 주의: 소맥 1잔 = 표준잔 1.5~2

식이 제한 fallback:

  • 할랄·코셔: 알코올 = 비할랄·비코셔. → 무알콜 옵션 (식혜·수정과·무알콜 맥주).
  • 무알콜: 식혜·수정과·국화차 (전통) OR 무알콜 맥주·무알콜 청주.

💰 Essential Tourist Tips

  • 1병/잔 평균 비용 (2026년 6월 기준):
  • 소주 = 4,000~6,000원/병 (식당)
  • 맥주 = 4,000~8,000원/병 / 생맥주 5,000~8,000원/잔
  • 막걸리 = 5,000~10,000원/병
  • 청주 = 8,000~25,000원/병
  • 전통주 = 15,000~80,000원/병
  • 하이볼 = 8,000~15,000원/잔
  • 결제: 카드 OK / 노포 일부 현금 / 팁 X / 카카오페이·토스 송금
  • 음주 규제: 0.03% BAC 면허정지 / 0.08% 형사처벌
  • 응급: ☎ 1339 (의료, 영문) / ☎ 1330 (관광 통역)
