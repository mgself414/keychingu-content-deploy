休息日各不相同。切头山殉教圣地周一休息，杨花津外国人传教士墓园和杨花津Hall展览馆周日休息。

📍 Mangwon-dong市场 — Mangwon市场·Mangwon世界杯市场

Mangwon市场(Mangwon Sijang / 망원시장)，麻浦区(Poeun-ro 6-gil 27 / 포은로6길 27)，☎ 02-335-3591，是售卖街头小吃、农畜产品、水果和生活用品的传统市场。位于地铁6号线Mangwon站(Mangwon-yeok / 망원역)附近，与Mangridan-gil(Mangridan-gil / 망리단길)一起为人所知。

  • 开放时间·休息日:各店铺不同。停车:可以。

Mangwon世界杯市场(Mangwon Worldcup Sijang / 망원월드컵시장)，麻浦区Mangwon-dong(Mangwon-dong / 망원동)，☎ 02-322-6656，是1975年开业的传统市场，2006年改建为拱廊式的现代化市场。约50家店铺出售农水产品、畜产品、小吃和生活杂货，以批发为主的店铺较多。从Mangwon站步行约10分钟。

  • 开放时间:10:00~22:00。休息日:全年无休。停车:可以。

📍 凉亭与体育公园 — Mangwonjeong旧址·Mangwon蓄水池体育公园

Mangwonjeong旧址(Mangwonjeong Teo / 망원정 터)，麻浦区(Donggyo-ro 8an-gil 23 / 동교로8안길 23)，☎ 麻浦区厅(Mapo-gucheong / 마포구청) 02-3153-8372，是位于Hapjeong-dong的凉亭，为首尔市纪念物。世宗6年的1424年，孝宁大君建了别墅，次年世宗到访时降下甘霖，据说因此取名“Huiujeong(Huiujeong / 희우정)”。成宗15年的1484年，月山大君大规模修缮后称为Mangwonjeong(Mangwonjeong / 망원정)。它曾因1925年的大洪水和汉江开发而消失，1989年10月复原。Mangwon-dong这个洞名就来自这座凉亭。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

Mangwon蓄水池体育公园(Mangwon Yusuji Cheyuk Gongwon / 망원유수지체육공원)，麻浦区(Worldcup-ro 25-gil 190 / 월드컵로25길 190)，☎ 麻浦区厅体育振兴科(Cheyuk Jinheung-gwa / 체육진흥과) 02-3153-9873，是整治防洪蓄水池后于2004年开放的体育公园。有足球场、足球排球场(Jokgu-jang / 족구장)、篮球场、轮滑练习场、多功能跑道和门球场，并设有夜间照明。

  • 开放时间:全天开放。下雨或发布气象特报时限制使用。
  • 休息日:全年无休。停车:可以。

📍 圣地与墓园 — 切头山殉教圣地·杨花津外国人传教士墓园·杨花津Hall展览馆

切头山殉教圣地(Jeoldusan Sungyo Seongji / 절두산 순교성지)，麻浦区(Tojeong-ro 6 / 토정로 6)，☎ 02-3142-4434，是1866年丙寅迫害时许多天主教徒被处决的地方。这里原本因形似蚕头而称为Jamdubong(Jamdubong / 잠두봉)，那件事之后得名“砍了头”之意的切头山(Jeoldusan / 절두산)。韩国天主教会为纪念殉教100周年，于1967年10月开设了殉教纪念馆。圣地内有韩国天主教会史料与遗物·遗品展览馆、安放28位圣人遗骸的遗骸室、朝圣堂和户外展览馆。

  • 开放时间:09:30~17:00。休息日:每周一。
  • 费用:免费。登记有朝圣者自愿捐献。停车:可以。

杨花津外国人传教士墓园(Yanghwajin Oegugin Seongyosa Myowon / 양화진외국인선교사묘원)，麻浦区(Yanghwajin-gil 46 / 양화진길 46)，☎ 02-332-9174，安葬着来自南非、新西兰、丹麦、德国、美国等15个国家的417名传教士。他们创办医院和学校，对韩国社会产生了影响，其中有Bethell(Bethell / 배설)、Hulbert(Hulbert / 헐버트)、Underwood(Underwood / 언더우드)、Appenzeller(Appenzeller / 아펜젤러)等。由韩国基督教100周年纪念教会(Hanguk Gidokgyo 100-junyeon Ginyeom Gyohoe / 한국기독교100주년기념교회)管理。

  • 开放时间:周一~周六 10:00~17:00。休息日:每周日。费用:免费。
  • 导览讲解:周一~周五 10:00、11:30、14:00。周六 10:00、11:30、13:30、15:00。1月1日、春节假期、中秋假期和圣诞节没有导览。登记要求在导览开始前15分钟到达。
  • 导览预约:在官网从6个月前至到访前一天晚上9点预约。不能当天预约。需要外语导览时，在申请时写在其他事项中。
  • 外语导览:英语、日语、中文。也可使用外语导览手册上二维码的视频。
  • 停车:可以。登记要求大型巴士使用Mangwon第1停车场(Mangwon Je1 Jucha-jang / 망원 제1주차장)。

杨花津Hall展览馆(Yanghwajin Hall Jeonsigwan / 양화진홀 전시관)(同一地址，☎ 02-332-9174)是墓园内的展览馆。通过分主题的资料展示传教士们是怎样的人、为什么来到朝鲜、做了哪些活动。

  • 开放时间:10:00~15:30。休息日:每周日。费用:免费。

⚠ 行前须知 3 点

  1. 切头山殉教圣地周一休息，杨花津墓园和展览馆周日休息 — 按登记值，三处都开放的日子是周二~周六。
  2. 杨花津墓园的导览讲解须在前一天晚上9点前预约 — 不能当天预约。
  3. 杨花津Hall展览馆15:30闭馆 — 墓园开放到17:00。

⚙ FAQ 2

Q. 在杨花津墓园能接受外语导览吗?

A. 按观光公社登记信息，可提供英语、日语、中文导览。在官网预约时，在其他事项中写明需要外语导览。

Q. 开到晚上的市场是哪里?

A. Mangwon世界杯市场(Mangwon Worldcup Sijang / 망원월드컵시장)登记为10:00~22:00，全年无休。Mangwon市场(Mangwon Sijang / 망원시장)各店铺不同。
