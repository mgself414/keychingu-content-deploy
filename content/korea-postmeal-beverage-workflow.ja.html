🎯 なぜ韓国食事締めの飲み物段階別ガイドが必要か

#870 食事締めの飲み物6種ガイド を知っていても——ペアリング・タイミング・二日酔い対策は別問題。韓国の食事締めの飲み物は (a) 韓定食 (ハンジョンシク (한정식), 韓国式コース料理) の最後 (シッケ (식혜) + スジョングァ (수정과)・無料) (b) 家庭食 (カジョンシク (가정식), 家庭料理) の後のデザート (シッケ・メシルチャ (매실차)) (c) 二日酔いの翌日 (メシルチャ + ヘジャンス (해장수)) (d) 伝統酒場 (ドンドンジュ (동동주)・食事のお供の酒) に分かれる。外国人観光客は (1) 韓定食コースの最後にシッケが出ることを知らない (2) ドンドンジュが酒なのか飲み物なのか分からない (3) メシルチャは季節によって温冷が変わることを知らない (4) ヘジャンスが二日酔い対策の常連客に人気の翌朝の一杯だと知らない、というケースが多い。本ガイドは5ステップ・ペアリング・英語フレーズをまとめる。

🌶 外国人観光客向け英語フレーズ例

  • 「シッケを1杯」注文する時："One Sik-hye (sweet rice drink), please"
  • 韓定食の締めの飲み物を尋ねる時："The final drinks (rice sweet drink + cinnamon punch)"
  • ドンドンジュが酒だと確認する時："Dong-dong-ju is a traditional rice wine (6~8% alcohol)"
  • メシルチャを温かくお願いする時："Plum tea, hot, please"
  • ヘジャンスについて尋ねる時："Hangover cleansing soup-drink for the next morning"
  • カード払いできるか尋ねる時："Card accepted?"

⚠ 外国人観光客がよくする7つの勘違い

1. 「シッケ = シケ」：シッケ = 飲み物(甘い) / シケ (식해) = おかず(魚の発酵食品) — 全く違う食べ物。

2. 「ドンドンジュ = 普通の飲み物」：ドンドンジュ = アルコール度数6〜8%の酒(伝統的な食事のお供)。

3. 「韓定食の飲み物は別料金」：韓定食の締めの飲み物 = 無料込み。

4. 「スジョングァ = お茶」：スジョングァ = シナモン・生姜・干し柿のパンチ(お茶ではない)。

5. 「メシルチャ = 普通のお茶」：メシルチャ = 薬膳風の飲み物(消化促進・二日酔い対策)。

6. 「ヘジャンス = 普通のスープ」：ヘジャンス = 翌朝専用の豆もやしスープ、二日酔い対策の常連客に人気。

7. 「スーパーの飲み物は高い」：スーパーの缶飲料 = 2,000〜7,000ウォン (~220〜800円)(韓定食に無料の飲み物が含まれていれば不要)。

⚙ よくある質問8つ

1. 最初の締めの飲み物はどこで試す？：韓定食コースの最後(無料のシッケ+スジョングァが1番人気)→ 次に家庭食のデザート。

2. インスタ・vlog映え：韓定食1番人気のシッケ、干し柿を添えたスジョングァ、伝統的なドンドンジュ。

3. MZトレンド：MZ世代のカフェのシッケアレンジ飲料、ドンドンジュ、梅のスパークリング飲料。

4. 消化・二日酔い対策：メシルチャ(消化)+ ヘジャンス(翌朝)。

5. アルコール・妊娠：ドンドンジュ = アルコール度数6〜8%——妊婦・運転者は避ける。

6. アレルギー・妊娠：#870の注意事項 参照。

7. 支払い・チップ：韓定食・家庭食 = カードOK / チップ不要。

8. VAT還付：飲食は原則として還付対象外。

⚠ 医療・安全・食事制限に関する注意事項

食事締めの飲み物は日常的な食べ物。妊婦・子供 = シッケ、スジョングァ、メシルチャ、ヘジャンスはOK(ドンドンジュ = NG、アルコール含有)。アレルギー(松の実・生姜)は事前に申告を。運転者・妊婦 = ドンドンジュNG。食中毒が疑われる場合は ☎ 1339 へ。本ガイドは一般情報であり、医療アドバイスではありません。

食事制限への対応：

  • ハラール・コーシャ：シッケ、スジョングァ、メシルチャ、ヘジャンス = OK / ドンドンジュ = NG、アルコール含有(ハラールではない) / シケ = 魚類なのでOK。
  • ベジタリアン・ヴィーガン：6種中5種 = OK / シケ = ベジタリアン不可。
  • グルテンフリー：6種すべてOK(醤油使用時はたまり醤油で代用可)。
