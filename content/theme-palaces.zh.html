为何用地铁游五大宫 — 把散落的朝鲜王朝串成一线

首尔的五大宫是朝鲜王朝500年的心脏 — 景福宫(正宫)·昌德宫(联合国教科文组织世界遗产)·昌庆宫(与昌德宫仅一墙之隔)·德寿宫(近代·石造殿 (Seokjojeon / 석조전))·庆熙宫(西阙)。问题在于它们散落于市区北部。但全部都在地铁站步行5分钟内,一张T-money便可一日串游。

本指南是与线路篇(#1241~#1249)·枢纽篇(#1250~#1254)正交的第三条轴。"穿梭多条线路,将五大宫串为一体" — 以主题为核心,编排先游哪座宫、按何顺序、在哪一站下车、如何步行。是地铁线路系列(Phase 2·主题行程)的第一篇。

五大宫 × 地铁接驳 — 在哪一站下车

🏯 景福宫 — 正宫·守门将换岗仪式

  • 🚇 接驳: 3号线景福宫站 (Gyeongbokgung Station / 경복궁역) 5号出口即达 · 5号线光化门站 (Gwanghwamun Station / 광화문역) 步行10分钟
  • ✨ 亮点: 勤政殿 (Geunjeongjeon / 근정전)·庆会楼 (Gyeonghoeru / 경회루)·香远亭 (Hyangwonjeong / 향원정) · 守门将换岗仪式(光化门,每日2次) · 邻近国立故宫博物馆 (National Palace Museum / 국립고궁박물관)·国立民俗博物馆 (National Folk Museum / 국립민속박물관)
  • ⏱ 耗时: 1.5~2小时(面积大)
  • cross-ref: #37 景福宫指南 · #1242 3号线

🌳 昌德宫 + 昌庆宫 — 后苑·一墙之隔

  • 🚇 接驳: 3号线安国站 (Anguk Station / 안국역) 3号出口步行5分钟 · 两宫以宫墙相连
  • ✨ 亮点: 昌德宫后苑 (Changdeokgung Huwon / 창덕궁 후원)(秘苑 (Biwon / 비원),联合国教科文组织世界遗产·分时段入场) · 仁政殿 (Injeongjeon / 인정전) · 昌庆宫(大温室 (Daeonsil / 대온실)·春塘池 (Chundangji / 춘당지)) · 夜间开放(月光纪行 (Dalbit Gihaeng / 달빛기행) 时节)
  • ⏱ 耗时: 昌德宫 1.5小时(含后苑 2小时)·昌庆宫 1小时
  • cross-ref: #18 北村 · #1254 钟路3街枢纽

🏛 德寿宫 — 近代·石造殿·石墙路

  • 🚇 接驳: 1·2号线市厅站 (City Hall Station / 시청역) 2号出口即达 · 5号线光化门站 步行8分钟
  • ✨ 亮点: 石造殿(西洋式近代建筑) · 中和殿 (Junghwajeon / 중화전) · 德寿宫石墙路 (Deoksugung Doldam-gil / 덕수궁 돌담길) 散步 · 守门将换岗仪式 · 贞洞 (Jeongdong / 정동) 近代街
  • ⏱ 耗时: 1~1.5小时
  • cross-ref: #40 南山 (Namsan / 남산)·明洞 (Myeongdong / 명동) 夜景(市区邻近)

🍂 庆熙宫 — 免费·静谧的西阙

  • 🚇 接驳: 5号线西大门站 (Seodaemun Station / 서대문역)/光化门站 步行7分钟
  • ✨ 亮点: 免费入场(五大宫中唯一) · 崇政殿 (Sungjeongjeon / 숭정전) · 邻近首尔历史博物馆 (Seoul Museum of History / 서울역사박물관) · 人少的疗愈之宫
  • ⏱ 耗时: 40分钟~1小时
  • cross-ref: #284 免费入场 spot

🎯 五大宫综合游览贴士 — 出发之前

  • 🎫 综合观览券: 四大宫(景福·昌德+后苑·昌庆·德寿) + 宗庙 (Jongmyo / 종묘) 综合券(约10,000韩元·3个月有效) — 比单独购买划算。价格·构成请查阅官方。
  • 👘 韩服免费入场: 身着韩服可四大宫免费入场。安国·景福宫附近韩服租赁店众多(#379·#33)。
  • 🚫 休息日注意: 各宫休息日不同(景福宫·昌德/昌庆/德寿各异)。一日纵游前请务必确认各宫休息日。
  • 💡 动线贴士: 3号线(景福宫·安国)覆盖五大宫中的3座(景福·昌德·昌庆) — 以3号线为轴 + 仅需移动至市厅(德寿)·西大门(庆熙)。

五大宫地铁纵游路线 3

路线1. 半日精华(2宫·3号线)

  • 景福宫站(景福宫·守门将换岗仪式) → 3号线安国站(昌德宫·后苑) → 益善洞 (Ikseon-dong / 익선동) 午餐(#1254)
  • fit: 时间紧·只玩精华。正宫+世界遗产。

路线2. 一日纵游(四大宫·韩服)

  • 景福宫(上午·守门将) → 安国 昌德+昌庆(后苑) → 市厅 德寿宫(石造殿·石墙路) → 贞洞近代街
  • fit: 着韩服玩一天。综合券回本。纵游朝鲜王朝。

路线3. 静谧之宫·近代(庆熙·德寿)

  • 西大门 庆熙宫(免费·清静) → 首尔历史博物馆 → 市厅 德寿宫(石造殿·石墙路) → 贞洞
  • fit: 人少疗愈·近代建筑。避开拥挤的宫。

换乘·使用贴士 5 — 五大宫地铁纵游200%活用

Tip 1. 以3号线为轴

景福宫·安国(昌德·昌庆)在3号线。五大宫中3座在3号线一线上。剩下的德寿(市厅)·庆熙(西大门)只需加接。

Tip 2. 着韩服免费入场

身着韩服四大宫免费。在安国·景福宫附近租赁店租借,穿一整天(#379·#33)。

Tip 3. 用综合观览券打包

四大宫+宗庙综合券(约10,000韩元)比单独购买划算。一日纵游必备。价格请查阅官方。

Tip 4. 对准守门将换岗仪式时间

景福宫·德寿宫的守门将换岗仪式每日约2次。掐准时间到达即是免费看点。

Tip 5. 先确认休息日

各宫休息日不同,一日纵游时可能有一座闭馆。出发前请务必查阅各宫官方。

FAQ 6 — 外国人常问的五大宫地铁纵游问题

Q1. 五大宫能在一天内全部游完吗?

  • 核心四大宫一天可行(景福·昌德·昌庆·德寿)。若加上昌德后苑会略赶 — 建议半日2宫 or 一日4宫。

Q2. 与线路篇·枢纽篇有何不同?

  • 线路篇="单线纵向",枢纽="一站放射",本篇则是"穿梭多条线路、以五大宫主题串联" = 第三条轴。

Q3. 如何用地铁串联?

  • 3号线覆盖景福宫·安国(昌德·昌庆)3座。仅需加上德寿(1·2号线市厅)·庆熙(5号线西大门)。一张T-money。

Q4. 穿韩服真的免费吗?

  • 是的。身着韩服四大宫免费入场。安国·景福宫租赁店众多(#379)。

Q5. 综合观览券划算吗?

  • 四大宫+宗庙综合券(约10,000韩元)比单独购买便宜。一日纵游必备。价格请查阅官方。

Q6. 哪座宫较不拥挤?

  • 庆熙宫(免费·清静)·昌庆宫相对安静。景福宫·昌德宫最为拥挤。
