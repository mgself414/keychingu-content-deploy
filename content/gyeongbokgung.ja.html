景福宮 (경복궁) ガイド — 外国人観光客のための総合ガイド

ISSUE 02 · #37 · 2026-05-15 (SERP再編成 2026-06-27)

🎯 なぜ景福宮なのか

景福宮 (경복궁) は朝鮮王朝最大の宮殿 (1395年建立) — 外国人観光客の韓国歴史体験No.1。ソウル都心の北端、光化門広場 (Gwanghwamun Square) の裏手にある。

景福宮は何で有名か — ① 守門将交代式 (Changing of the Guard) (1日2回・無料) ② 韓服 (한복) 無料入場 (韓服を着れば入場料が免除) ③ 勤政殿 (근정전)・慶会楼 (경회루) など5大見どころ ④ 無料英語ガイドツアー ⑤ 北村 (북촌)・三清洞 (삼청동)・青瓦台 (Blue House) へ徒歩で接続。

★ 一目で — 核心情報

項目 内容

無料英語ガイドツアー 11:00 · 13:30 · 15:30 (光化門案内所集合、約1時間)

🚇 到着・ルート

  • 景福宮駅 (Gyeongbokgung Station) 3号線5番出口 → 国立古宮博物館 → 興礼門 (Heungnyemun) (正門に最も近い入口)
  • 光化門駅 (Gwanghwamun Station) 5号線2番出口 → 光化門広場 → 光化門 (광화문) (交代式の観覧に最適)
  • おすすめ動線: 光化門 (交代式) → 勤政殿 (근정전) → 慶会楼 (경회루) → 香遠亭 (향원정) → 国立民俗博物館 → 北村 (북촌)・三清洞 (삼청동) (徒歩5分)

💂 守門将交代式 (Changing of the Guard) — 見逃さないで

景福宮最高の無料の見どころ。1日2回 (10:00 · 14:00) 光化門前で朝鮮時代の王宮守門将の交代を再現 — 伝統楽隊・色とりどりの軍服・行進。約15~20分、無料。

  • 時間: 10:00 · 14:00 (各約20分) — 火曜休館、雨天時は中止の可能性あり
  • 特等席: 開始10~15分前に到着して光化門正面の場所を確保。横からも良い写真が撮れる
  • ヒント: 14:00の回は午前より空いている。交代式の直後にそのまま入場動線へ。

👘 韓服 (한복) 無料入場

韓服 (伝統的な韓国の衣装) を着れば景福宮の入場料が無料。韓服を着て宮殿で撮る写真は外国人人気No.1の体験。

  • 無料入場の条件: 上衣+下衣の揃った正式な韓服 (公式ガイドライン)
  • レンタル: 景福宮近くに韓服レンタル店が多数 (徒歩5分)、一式₩15,000~35,000・2~4時間単位。#33 韓服 (한복) ガイド参照
  • ヒント: 韓服 + 春の桜/秋の紅葉 = 最高の写真。レンタル店は午前早めの予約がおすすめ。

🏯 5大見どころ

# 見どころ シグニチャー
1 光化門 (광화문) (正門) 守門将交代式・景福宮の顔
2 勤政殿 (근정전) (正殿) 朝鮮王朝の即位式・黄金の玉座
3 慶会楼 (경회루) 池の上の楼閣・写真No.1
4 香遠亭 (향원정) 小さな亭・インスタ映え
5 国立民俗博物館・国立古宮博物館 (National Folk & Palace Museum) 無料入場・朝鮮の遺物を深掘り

徒歩5分で接続: 北村韓屋村 (Bukchon Hanok Village)・三清洞 (삼청동)・青瓦台 (Blue House) (現在一般公開)。

⚠ 外国人がよくやる失敗3つ

1. 火曜休館を無視 — 景福宮は毎週火曜休館。到着前に必ず確認。

2. 韓服無料入場を活用できない — 韓服着用で入場料無料。レンタル代以上に写真+無料入場の価値が大きい。

3. 交代式の時間に間に合わない — 10:00 · 14:00ちょうど (火曜休館)。15分前到着がおすすめ。

⚙ FAQ

Q1. 入場料・予約は？

入場料₩3,000、韓服着用で無料。無料英語ガイドツアー (11:00 · 13:30 · 15:30、1日3回)。予約なしのウォークインOK。

Q2. 無料英語ガイドツアーは？

無料英語ガイド: 11:00 / 13:30 / 15:30 (火曜休館)。約1時間。光化門案内所集合。

Q3. 韓服との組み合わせは？

景福宮近くの韓服レンタル店 (徒歩5分)。#33 韓服ガイド参照。

Q4. シーズン別おすすめは？

春 (4月の桜): 景福宮の桜 + 韓服、No.1。秋 (11月の紅葉): 慶会楼の紅葉 + 韓服。冬 (12~2月): 空いている + 韓服 + 防寒。

Q5. 1日結合コースは？

10時 景福宮 → 14時 守門将交代式 → 15時 北村韓屋村 → 17時 三清洞カフェ → 19時 韓国料理ディナー。

Q6. 景福宮は行く価値がある？(Is Gyeongbokgung worth visiting?)

韓国五大宮殿の中で最大・最も代表的。守門将交代式 + 韓服体験はソウル必須コース。半日で十分楽しめる。

Q7. どのくらいかかる？(How long do you need?)

核心 (交代式 + 5大見どころ) で2~3時間。博物館・北村・三清洞まで合わせると半日~1日。

Q8. 夜間開放は？(Night opening?)

春・秋に特別夜間開放の期間がある (要予約・売り切れが早い)。日程は国家遺産庁 (Korea Heritage Service) の告知を確認。

🗺 結合コース3つ

[A] 景福宮 + 北村 (1日6時間) — 10時 景福宮 + 韓服 → 14時 交代式 → 15時 北村韓屋村 → 17時 三清洞カフェ

[B] 景福宮 + 仁寺洞 (半日) — 10時 景福宮 → 13時 仁寺洞ランチ + 伝統工芸ショッピング

[C] 景福宮 + 青瓦台 + 光化門広場 (1日) — 景福宮 → 青瓦台 (一般公開) → 光化門広場を散策
