本地人推荐 ⑧ 首尔 — 韩国观众点名的29家饭馆，观光路线之外的首尔

副标题：KeyChinGu的首尔报道早已按街区做得很密——这一篇正好相反。韩国观众在YouTube评论区写下的29家首尔饭馆，散落在仓洞、面牧洞、葛岘洞、兰谷这类游客几乎不去的16个区的住宅区里，KeyChinGu只用Naver核实了是否存在、地址和行业类别。市中心·西北9家→东北首尔5家→江南·松坡8家→西南首尔7家，每组配一个车站名和一条外国游客提示。无论是出处还是街区，都与钟路·光化门公务员饭馆篇(#1191)不重合。

ISSUE 06 · #1389 · 2026-09-18 · 本地人推荐 ⑧

🎯 为什么以"网友评论推荐"为标准

这个专栏只有一个出处。一家韩国YouTube频道上传了"全国美食"视频，观众在评论区留言写下自家附近的饭馆，其中按地区整理得最系统的评论被汇总成一张217家店铺的表格。因为这是韩国人推荐给韩国人的名单，外国人评价几乎为零。本专栏的标准与局限在第①篇(#1382)中说明过。

KeyChinGu只用Naver本地搜索确认了店名、地址、行业类别是否真实存在(2026-09-17)。首尔30家店中，29家得到确认；无法确认的1家(惠化洞)被剔除。没有探店评价、排名或星级评分，也没有营业时间和价格。

首尔是这个专栏里最难处理的区域。光是KeyChinGu自己就已经有几百篇首尔相关的文章，街区级指南也早已做得很密。但把整理表里的29家首尔店铺标在地图上后发现，它们散落在16个区，大部分都在观光路线之外——仓洞、佛岩山、面牧洞、葛岘洞、兰谷、月谷、新吉洞。没有明洞，也没有弘大。这一篇原样照搬这个分布。有两家店与已发布的篇目重叠，具体说明写在验证笔记里。

⚠ 标注原则：每条店铺信息按 店名(罗马字) · 道路名地址 · Naver分类 · 交通 的顺序排列。交通仅记录已确认的车站，车站有分歧或找不到的地方标注为"未确认"。步行分钟数仅在已确认时标注——其余一律只写到"步行可达"为止。营业时间、休息日、价格全部未收集——请当天在Naver Place确认。

① 市中心·西北 — 9家，就在景点旁边却不上观光榜单

钟路、中区、麻浦、龙山、恩平。这是坐地铁最容易到达的一组，因此也最容易排进行程。

  • 合川猪骨汤饭(Hapcheon Dwaeji Gukbap / 합천돼지국밥) · 钟路区三一大路418-3号 (418-3 Samil-daero, Jongno-gu / 종로구 삼일대로 418-3) · 韩餐·汤饭 · 钟路3街站·1/3/5号线，步行可达，副站名是塔谷公园

猪骨汤饭(Dwaeji Gukbap / 돼지국밥)通常被认为是釜山·庆南的食物(#1320、#1382)，但整理表里有一家打着这个名号的店，就开在首尔市中心。

  • 辣猪蹄(Maeun Jokbal / 매운족발) · 钟路区钟路51街23号 (23 Jongno 51-gil, Jongno-gu / 종로구 종로51길 23) · 韩餐·猪蹄/白切肉 · 东大门站·1/4号线，步行约2分钟。店址在昌信洞，但比起昌信站，东大门站更近

猪蹄(Jokbal / 족발)是把猪前腿用酱油炖煮后切片端出的料理。这家是辣味调味版。这是同一家也出现在KeyChinGu 4号线·6号线站点篇(#1243、#1245)里的店。

  • 曼娜手工刀切面(Manna Son Kalguksu / 만나손칼국수) · 中区西厓路1街11号 (11 Seoae-ro 1-gil, Jung-gu / 중구 서애로1길 11) · 韩餐·面条 · 忠武路站·3/4号线，步行可达

忠武路是印刷厂和老电影公司聚集的街区，顺路去南山时很方便。

  • 鸡肉馆(Gyegogijip / 계고기집) · 麻浦区白凡路24街1号 (1 Baekbeom-ro 24-gil, Mapo-gu / 마포구 백범로24길 1) · 韩餐·鸡肉料理 · 孔德站·5/6号线、机场铁路、京义中央线，步行可达

因为机场铁路在这一站停靠，从仁川机场可以直接过来，是抵达当天吃第一顿饭很现实的选择。

  • 艺江牛骨汤(Yegang Seolnongtang / 예강설농탕) · 麻浦区新村路12街30号 (30 Sinchon-ro 12-gil, Mapo-gu / 마포구 신촌로12길 30) · 韩餐·牛骨浓汤 · 新村站·2号线，步行约6分钟

牛骨浓汤(Seolnongtang / 설농탕)是用牛骨长时间熬出的乳白色汤底，盐和葱要自己加进去调味。

  • 肉汁场(Yukjeupteo / 육즙터) · 麻浦区三介路5街8号 (8 Samgae-ro 5-gil, Mapo-gu / 마포구 삼개로5길 8) · 韩餐·烤猪肉 · 麻浦三介路——最近的车站未确认，候选是麻浦站(Mapo Station / 마포역)、孔德站。先在Naver地图上查好路线
  • 正林食堂(Jeongnim Sikdang / 정림식당) · 龙山区白凡路87街48-9号 (48-9 Baekbeom-ro 87-gil, Yongsan-gu / 용산구 백범로87길 48-9) · 餐馆·韩餐 · 南营站·1号线，步行可达，与淑大入口站同属一个商圈
  • 民俗炭火烤排骨(Minsok Sutbul Galbi / 민속숯불갈비) · 恩平区延曙路303-12号 (303-12 Yeonseo-ro, Eunpyeong-gu / 은평구 연서로 303-12) · 韩餐·肉类料理 · 佛光洞/延新内一带——两站中哪个更近未确认
  • 奶奶辣炒年糕(Halmeoni Tteokbokki / 할머니떡볶이) · 恩平区统一路87街8-1号 (8-1 Tongil-ro 87-gil, Eunpyeong-gu / 은평구 통일로87길 8-1) · 小吃·辣炒年糕 · 葛岘洞，延新内站·3/6号线一带

这个名字很常见——它和新堂洞那家著名的即席辣炒年糕元祖店(#810)是不同的两家店。

外国游客提示——汤饭、牛骨浓汤、刀切面可以一人份点餐，排骨和烤肉一般从两人份起。牛骨浓汤店桌上的盐、胡椒、葱是留给客人自己加的。

② 东北首尔 — 5家，地铁线末端的街区

城东、城北、道峰、芦原、中浪。除了2号线的圣水，这些区游客几乎不去。

  • 麦本(Milbon / 밀본) · 城东区峨嵯山路7街4号 (4 Achasan-ro 7-gil, Seongdong-gu / 성동구 아차산로7길 4) · 韩餐·刀切面/饺子 · 圣水站·2号线一带

圣水洞是KeyChinGu多次报道过的街区(#01)，但这家不是咖啡馆或快闪店，而是一家刀切面店。

  • 深山生菜包饭(Dumesangol Ssambap / 두메산골쌈밥) · 城北区花郎路119-9号 (119-9 Hwarang-ro, Seongbuk-gu / 성북구 화랑로 119-9) · 餐馆·韩餐 · 月谷站·6号线一带

生菜包饭(Ssambap / 쌈밥)是用生菜、紫苏叶把米饭和肉包起来吃的一种餐桌形式。

  • 钟路酒幕(Jongno Jumak / 종로주막) · 道峰区麻得路11街15号 (15 Madeul-ro 11ga-gil, Dobong-gu / 도봉구 마들로11가길 15) · 餐馆·韩餐 · 仓洞站·1/4号线，步行可达

店名里带"钟路"两个字，但其实开在道峰区仓洞。因为是1/4号线换乘站，反而很好到达。

  • 土种韩牛生肉村(Tojong Hanu Saenggogi Maeul / 토종한우생고기마을) · 芦原区德陵路812号 (812 Deokneung-ro, Nowon-gu / 노원구 덕릉로 812) · Naver分类是肉铺 · 佛岩山站·4号线

很可能是"肉铺食堂"(정육식당)那种在肉铺买肉、当场烤来吃的形式，但这一篇只写已确认的内容——分类就是肉铺。去之前先打电话确认能不能用餐。

  • 扎扎鲁(Jjajjaru / 짜짜루) · 中浪区龙马山路89街3号 (3 Yongmasan-ro 89-gil, Jungnang-gu / 중랑구 용마산로89길 3) · 中餐·中餐馆 · 面牧洞，龙马山站·7号线一带——车站在高地，实际步行时间可能比看起来更长

外国游客提示——这五家全都在住宅区。晚上去的话满眼都是本地居民，很可能没有英文菜单。用手机拍照翻译菜单，或者直接指邻桌的菜，是最快的办法。

③ 江南·松坡 — 8家(7店)，写字楼区与住宅区之间

江南、瑞草、松坡。这几个区和观光路线重叠，但榜单里的店大多面向上班族和居民。

  • 福豚大铁锅血肠汤(Bokdoni Gamasot Sundaeguk / 복돈이 가마솥순대국) · 江南区德黑兰路37街22号1楼 (22 Teheran-ro 37-gil, 1F, Gangnam-gu / 강남구 테헤란로37길 22 1층) · 韩餐·血肠/血肠汤 · 驿三站·2号线，步行约8分钟
  • 驿三拉面(Yeoksam Ramen / 역삼라멘) · 江南区彦州路107街38号1楼 (38 Eonju-ro 107-gil, 1F, Gangnam-gu / 강남구 언주로107길 38 1층) · 日餐·日式拉面 · 彦州站·9号线，步行可达

德黑兰路写字楼区的两家午餐店，工作日中午前后排队会比较长。

  • 新麦德(Sinmaekdeok / 신맥덕) · 瑞草区方背路83-14号地下1楼 (83-14 Bangbae-ro, B1F, Seocho-gu / 서초구 방배로 83-14 지하1층) · 酒馆·啤酒 · 方背站·2号线，近在咫尺

啤酒馆(Hof / 호프)是韩式说法，指卖生啤和下酒菜的酒馆，属于晚间菜单。

  • 中华小馆(China Bistro / 차이나비스트로) · 瑞草区盘浦大路3街20号 (20 Banpo-daero 3-gil, Seocho-gu / 서초구 반포대로3길 20) · 中餐·中餐馆 · 瑞草站和教大站两站都步行可达——两站离得很近，很难断定是哪一个
  • 支石墓(Goindol / 고인돌) · 松坡区可乐路18街4-1号 (4-1 Garak-ro 18-gil, Songpa-gu / 송파구 가락로18길 4-1) · 日餐·炸猪排 · 松坡站·8号线，步行约4-5分钟

炸猪排(Donkkaseu / 돈가스)在韩国已经成了"轻洋食"简餐的代表菜。这个名字很常见，容易和其他地区的同名店混淆。

  • 丰年猪骨醒酒汤(Pungnyeon Ppyeodagwi Haejangguk / 풍년뼈다귀해장국) · 松坡区可乐路94号 (94 Garak-ro, Songpa-gu / 송파구 가락로 94) · 韩餐·醒酒汤 · 同一条可乐路，松坡站一带

猪骨醒酒汤(Ppyeodagwi Haejangguk / 뼈다귀해장국)是放猪脊骨熬煮的汤，和土豆汤(감자탕)属于同一系列。

  • 柳潭田饭·多温斋(Yudamdeulbap Daonjae / 유담들밥 다온재) · 松坡区百济古坟路135号1楼101室 (135 Baekjegobun-ro, 1F Unit 101, Songpa-gu / 송파구 백제고분로 135 1층 101호) · 韩餐·韩定食 · 三田站·2号线附近

整理表里"柳潭田饭"和"多温斋"分开列了两条，但地址完全一样。核实后发现，两者在多个平台上都是以"柳潭田饭·多温斋"这一个店名登记的——是同一家店。这也是KeyChinGu韩定食全指南(#234)蚕室条目里的同一家店。

外国游客提示——血肠汤、醒酒汤、炸猪排可以一人份点餐，韩定食一般要两人以上。江南写字楼区工作日12点到1点最挤，只要错开30分钟就轻松很多。

④ 西南首尔 — 7家，冠岳与永登浦

冠岳、永登浦。这两个区是首尔外国游客最少的区域之一，也正因如此，这一组最能体现整理表的本色。

  • 惊魂大血肠(Gijeolchopung Wang Sundae / 기절초풍 왕순대) · 冠岳区奉天路62街2号 (2 Bongcheon-ro 62-gil, Gwanak-gu / 관악구 봉천로62길 2) · 韩餐·血肠/血肠汤 · 落星垈站·2号线，步行可达

血肠(Sundae / 순대)是把粉条和蔬菜填进猪肠蒸熟的食物。落星垈这个地名，来自高丽名将姜邯赞的出生地传说。

  • 味林小吃(Mirim Bunsik / 미림분식) · 冠岳区湖岩路553号 (553 Hoam-ro, Gwanak-gu / 관악구 호암로 553) · 小吃·辣炒年糕 · 湖岩路，首尔大创业园站·新林线一带

新林线(Sillim Line / 신림선)是2022年开通的轻轨，是一条通往首尔大学方向的短线。

  • 米安(Mian / 미안) · 冠岳区兰谷路65街6号1楼 (6 Nangok-ro 65-gil, 1F, Gwanak-gu / 관악구 난곡로65길 6 1층) · 餐馆·越南菜 · 兰谷路——最近的车站未确认，坐公交更现实。不标注步行分钟数
  • 开城刀切面(Gaeseong Kalguksu / 개성칼국수) · 永登浦区63路45号 (45 63-ro, Yeongdeungpo-gu / 영등포구 63로 45) · 韩餐·刀切面/饺子 · 汝矣岛，汝矣渡口站·5号线一带

开城(Gaeseong / 개성)是朝鲜的一座城市名，常被用在店名里，表示北朝鲜式的饺子、刀切面。

  • 高京浩黄牛烤肠(Gogyeongho Hwangso Gopchang / 고경호황소곱창) · 永登浦区永信路36号1楼 (36 Yeongsin-ro, 1F, Yeongdeungpo-gu / 영등포구 영신로 36 1층) · 韩餐·烤肠 · 永登浦站·1号线一带
  • 托顺伊家(Ttosunine / 또순이네) · 永登浦区仙游路47街16号1-2楼 (16 Seonyu-ro 47-gil, 1-2F, Yeongdeungpo-gu / 영등포구 선유로47길 16 1~2층) · 韩餐·烤牛肉 · 仙游岛站·9号线、堂山站一带
  • 湖水参鸡汤(Hosu Samgyetang / 호수삼계탕) · 永登浦区道林路276号 (276 Dorim-ro, Yeongdeungpo-gu / 영등포구 도림로 276) · 韩餐·白熟鸡/参鸡汤 · 道林路——大林站(Daerim Station / 대림역)和新吉站(Singil Station / 신길역)哪个更近未确认

参鸡汤(Samgyetang / 삼계탕)是整只鸡加人参、糯米炖煮的滋补食物。一整只就是一人份，是少数适合一个人吃的肉类料理。

外国游客提示——烤肠、烤牛肉一般从两人份起，血肠、辣炒年糕、刀切面、参鸡汤可以一人份点餐。冠岳、永登浦有些店要在地铁站再转乘一次公交，出发前先查好路线。

🚄 如何排进首尔行程

  • 抵达当天 — 孔德站有机场铁路停靠。①组里的鸡肉馆，是唯一一个可以从仁川机场拖着行李直接抵达的地方。
  • 只想选与观光路线重叠的店 — 钟路3街(合川猪骨汤饭)、东大门(辣猪蹄)、忠武路(曼娜手工刀切面)、新村(艺江牛骨汤)、圣水(麦本)。其余都是需要专程去的地方。
  • 写字楼区午餐 — 驿三、彦州、瑞草、教大在工作日中午很拥挤，错开30分钟即可。
  • 搭配街区篇一起看 — 圣水#01、芦原#179，以及永登浦·汝矣岛、冠岳街区指南都已单独发布。这一篇补上那些篇目没有覆盖到的店。
  • 前往首都圈 — 仁川·京畿西北见#1390，京畿东南见#1391。

⚠ 3个常见误区

1. 仅凭名字就以为是同一家店 — 恩平的奶奶辣炒年糕和新堂洞的元祖店(#810)不是一家，松坡的支石墓在其他地方也有好几家同名店。要靠地址核实。

2. 对住宅区餐馆抱有英文菜单的期待 — ②、④两组大多是街区食堂。翻译App加上手指，是最快的办法。

3. 在这一篇里找"步行X分钟" — 除了已确认的五家，其余一律只写到"步行可达"为止。准确的分钟数，请在Naver地图上当场查看。

⚙ 3个常见问题

1. 这份名单是谁选的？ — 这是一张韩国YouTube观众在评论区留言推荐的地方饭馆整理表。KeyChinGu只确认了是否存在、地址和行业类别，没有做排名。

2. 和钟路·光化门本地人推荐(#1191)有什么不同？ — #1191仅限钟路、光化门，依据公务员和上班族的到店数据挑选。这一篇的出处是YouTube评论，范围是首尔16个区，两篇的店铺完全不重合。

3. 可以一个人去吗？ — 汤饭、血肠汤、刀切面、辣炒年糕、参鸡汤、炸猪排、拉面可以一人份点餐。排骨、烤肠、烤牛肉、韩定食一般要两人以上。
