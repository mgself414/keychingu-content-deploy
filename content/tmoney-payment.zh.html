🎯 为什么需要韩国 T-money 完整指南

外国游客入境韩国的首要痛点 = 支付·交通卡。本指南整合了韩国 T-money、Cashbee (Cashbee / 캐시비)、移动支付、信用卡以及外国人友好支付方式 (Visa·Master·JCB·UnionPay·American Express)。这是外国游客抵达后 30 分钟内需要解决的首要问题。

1 T-money 卡 ★ 韩国首选 交通卡 ₩4,000 (~$3 / ~21 RMB / ~420 JPY)·便利店·车站·外国人首选
2 Cashbee (Cashbee / 캐시비) 交通卡 T-money 替代方案·乐天·BC卡整合

⚠ 外国人常犯 5 种错误

1. “T-money = 只有充值卡”: T-money 有 3 种 — (1) 一次性卡 (车站售票机) (2) 充值卡 (便利店 (convenience store / 편의점)) (3) 移动 T-money (NFC)。充值卡是外国人首选 (₩4,000 + 充值)。

2. “换钱 = 哪里都行”: 韩国换钱首选 = 明洞 (Myeongdong / 명동)·仁川机场 (Incheon Airport / 인천공항)·弘大 (Hongdae / 홍대)·钟阁 (Jonggak / 종각)·梨泰院 (Itaewon / 이태원) + 银行 (Korea Exchange Bank (Korea Exchange Bank / 외환은행)·Woori Bank (Woori Bank / 우리은행)·Hana Bank (Hana Bank / 하나은행)·KB Kookmin Bank (KB Kookmin Bank / 국민은행))。明洞 (Myeongdong / 명동) = 汇率最好 (私人换钱所首选)。仁川机场 (Incheon Airport / 인천공항) = 汇率最差。

3. “信用卡 = 哪里都 OK”: 韩国信用卡普遍可用 (Visa·Master·JCB·UnionPay·American Express) + 部分小店 = 只收现金。建议携带 T-money + 信用卡 + 约 ₩50,000 (~$37 / ~270 RMB / ~5,300 JPY) 现金。

4. “外国人退税 = 自动”: 免税退款 (Tax Refund) = 事后退款 (提交收据 + 退税卡)。₩30,000 以上 + 需外国人护照 + 仁川机场 (Incheon Airport / 인천공항)·金浦机场 (Gimpo Airport / 김포공항)·弘大 (Hongdae / 홍대) 是退税首选地。

5. “WOWPASS = 和韩国 T-money 一样”: WOWPASS = 外国人专用 + 外币兑换 + 支付整合 (2022)。它具备 T-money 功能 + 外国人友好首选。是外国人入境的首选卡。

① 交通卡 (4)

1. T-money 卡 ★ 韩国首选

  • 外国人 ★: ◎◎ — 韩国首选交通卡
  • 办理: 便利店 (CU (CU / 씨유)·GS25 (GS25 / 지에스25)·7-Eleven (7-Eleven / 세븐일레븐)·Emart24 (Emart24 / 이마트24)·Ministop (Ministop / 미니스톱)) ₩4,000 + 充值
  • 换乘: 30 分钟内换乘不同线路·巴士免费 (最多 4 次换乘)
  • 余额退款: ₩500 押金不予退还

2. Cashbee (Cashbee / 캐시비)

  • 外国人 ★: ◎ — T-money 替代方案 + 乐天·BC卡整合
  • 办理: 便利店 + 可像普通卡一样使用

3. RailPlus (RailPlus / 레일플러스)

  • 外国人 ★: ◎ — KTX·SRT + 普通地铁·巴士整合
  • 办理: KORAIL (KORAIL / 코레일) 车站 + 外国 KTX 爱好者首选

4. WOWPASS ★ 外国人专用

  • 外国人 ★: ◎◎ — 外国人专用卡 + 外币兑换 + T-money + 支付
  • 办理: 明洞 (Myeongdong / 명동)·仁川机场 (Incheon Airport / 인천공항)·弘大 (Hongdae / 홍대) WOWPASS 自助机 + 可兑换美元·日元·人民币·欧元 + 即时办理

② 外国人卡 (1)

5. Korea Tour Card

  • 外国人 ★: ◎ — 外国人专用卡 + 免税·景点折扣
  • 办理: 仁川机场 (Incheon Airport / 인천공항) + 明洞 (Myeongdong / 명동) + 官网

③ 移动支付 (3)

6. 移动 T-money (安卓 NFC)

  • 外国人 ★: ◎ — 安卓 NFC + Naver Pay·Toss·KakaoPay 支付 (2024 年扩展)
  • 不支持 iPhone

7. Samsung Pay (Samsung Pay / 삼성페이) + Apple Pay

  • 外国人 ★: ◎ — 可绑定外国信用卡 (Visa·Master) + 店内支付
  • 韩国 90%+ 商店支持

8. 信用卡直接支付

  • 外国人 ★: ◎ — 2024 年扩展 + 地铁·巴士部分车站可直接支付
  • Visa·Master·JCB·UnionPay·American Express 可用

④ 出租车·车辆 (2)

9. KakaoT Taxi (KakaoT Taxi / 카카오T 택시)

  • 外国人 ★: ◎◎ — 韩国首选出租车 App + 英文界面可用 + 信用卡支付

10. Uber Korea + Tada + UT

  • 外国人 ★: ◎ — Uber 全球·UT 日本整合·Tada 韩国本土化

⑤ 外国人退税 (2 + 额外 4)

11. 信用卡返现·退税

  • ₩30,000 以上免税退款 (Tax Refund) + 外国人护照 + 仁川机场 (Incheon Airport / 인천공항)·金浦机场 (Gimpo Airport / 김포공항) 退税

12. 外国人换钱 + 外币 ATM

  • 明洞 (Myeongdong / 명동)·仁川机场 (Incheon Airport / 인천공항)·弘大 (Hongdae / 홍대)·钟阁 (Jonggak / 종각) 换钱所·银行 + Citibank (Citibank / 씨티은행)·Standard Chartered Bank (Standard Chartered Bank / 스탠다드차타드은행)·Hana Bank (Hana Bank / 하나은행)·Shinhan Bank (Shinhan Bank / 신한은행) 外币 ATM

+ 额外 4 项

  • T-money 换乘规则: 30 分钟内换乘不同线路·巴士免费 (最多 4 次换乘)
  • 海外终端支付: 韩国商店普遍可用 + 终端可识别外国卡 (少数例外)
  • 外国人 SIM 卡: 仁川机场 (Incheon Airport / 인천공항) + 明洞 (Myeongdong / 명동) + 弘大 (Hongdae / 홍대) 外国人 SIM 卡 (KT (KT / 케이티)·SK (SK / 에스케이)·LG U+ (LG U+ / 엘지유플러스)) + eSIM 扩展
  • 外国人友好 ATM: 仁川机场 (Incheon Airport / 인천공항)·明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 24 小时外币 ATM (Citibank (Citibank / 씨티은행)·Standard Chartered Bank (Standard Chartered Bank / 스탠다드차타드은행)·Hana Bank (Hana Bank / 하나은행)·Shinhan Bank (Shinhan Bank / 신한은행))

⚙ 常见问题 8 个

1. 外国人 T-money 办理首选: 仁川机场 (Incheon Airport / 인천공항) + 便利店 + WOWPASS (外国人专用 + 换钱整合)。

2. 移动 T-money 使用: 安卓 NFC + Naver Pay·KakaoPay·Toss 支付。不支持 iPhone。

3. 换钱首选: 明洞 (Myeongdong / 명동) 私人换钱所 (汇率最好) → 银行 (Korea Exchange Bank (Korea Exchange Bank / 외환은행)·Woori Bank (Woori Bank / 우리은행)·Hana Bank (Hana Bank / 하나은행)·KB Kookmin Bank (KB Kookmin Bank / 국민은행)) → 仁川机场 (Incheon Airport / 인천공항) (汇率最差)。

4. 信用卡支付: 韩国 90%+ 商店可用 (Visa·Master·JCB·UnionPay·American Express)。部分小店只收现金 + 建议携带 ₩50,000 现金。

5. 外国人退税 (Tax Refund): ₩30,000 以上 + 外国人护照 + 提交收据 + 仁川机场 (Incheon Airport / 인천공항)·金浦机场 (Gimpo Airport / 김포공항) 退税柜台 (离境前预留 90 分钟)。

6. KakaoT (KakaoT / 카카오T) 外国人使用: 英文界面可用 + 可绑定信用卡 (Visa·Master) + 可提供英文收据。

7. 外国人 SIM 卡·eSIM: 仁川机场 (Incheon Airport / 인천공항) + 明洞 (Myeongdong / 명동) + 弘大 (Hongdae / 홍대) + KT (KT / 케이티)·SK (SK / 에스케이)·LG U+ (LG U+ / 엘지유플러스) + eSIM (Airalo·Holafly 全球可用)。

8. 外币 ATM 24 小时: 仁川机场 (Incheon Airport / 인천공항)·明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대)·市厅 (City Hall / 시청) Citibank (Citibank / 씨티은행)·Standard Chartered Bank (Standard Chartered Bank / 스탠다드차타드은행)·Hana Bank (Hana Bank / 하나은행)·Shinhan Bank (Shinhan Bank / 신한은행)。

🗺 外国人全天行程 4 个

A. 抵达仁川机场 (Incheon Airport / 인천공항) 后立即办理 (外国人抵达前 30 分钟)

  • 入境 → 换钱 (仁川机场 (Incheon Airport / 인천공항) 或抵达明洞 (Myeongdong / 명동) 后) → 办理 T-money 或 WOWPASS → 机场铁路 → 酒店

B. 外国人支付一日全套方案

  • 09:00 明洞 (Myeongdong / 명동) 换钱所 → 10:00 T-money 充值 → 13:00 地铁·巴士免费换乘 → 17:00 商店信用卡支付 → 20:00 KakaoT Taxi (KakaoT Taxi / 카카오T 택시)

C. 外国人免税退款 (离境前)

  • 08:00 酒店退房 → 10:00 明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 整理收据 → 11:00 仁川机场 (Incheon Airport / 인천공항) 退税柜台 (离境前预留 90 分钟) → 免税退款

D. 外国人郊区一日游 (广域 + 多样支付)

  • 09:00 T-money → 广域 9号线 (Line 9 / 9호선) → 江南 (Gangnam / 강남) 信用卡支付 → KakaoT Taxi (KakaoT Taxi / 카카오T 택시) → 郊区移动支付

🌸 季节·时间段 5

  • 全年: T-money 24 小时 + 便利店充值可用
  • 仁川机场 (Incheon Airport / 인천공항) 19:00~22:00 抵达: 换钱柜台人较少 (抵达外国人较少)
  • 明洞 (Myeongdong / 명동) 换钱所: 09:00~21:00 (可直接外币支付) + 汇率实时变动
  • 移动 T-money 使用量: 2024 年扩展 + Naver Pay·KakaoPay·Toss 外国人支付
  • 外国人退税: 节假日 (农历新年 (Seollal / 설날)·中秋节 (Chuseok / 추석)) 仁川机场 (Incheon Airport / 인천공항) 退税柜台人潮汹涌 → 离境前务必预留 2 小时
