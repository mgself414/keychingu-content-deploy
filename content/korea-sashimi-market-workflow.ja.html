🎯 なぜ韓国の刺身ワークフローガイドが必要なのか

「[#864 韓国の刺身6種ガイド](864_korean_hoe_6_types_matrix.md)」を読んでも、注文・市場・専門店・メウンタン (辛い魚の鍋) は別物です。韓国の刺身は (a) 市場の本格派 (鷺梁津 (ノリャンジン)・チャガルチ (チャガルチ)・統営 (トンヨン)・ソレポグ (ソレポグ) などでの活魚即殺) (b) 刺身専門店 (江南 (カンナム)・弘大 (ホンデ)・梨泰院 (イテウォン) の本格的な一式) (c) マグロ (チャムチ)・サーモン (ヨノ) 食べ放題 (MZ世代 (ミレニアル世代とZ世代) 向けのコスパ重視) (d) 韓定食 (ハンジョンシク) の刺身コース (伝統的) に分けられます。外国人は (1) 市場の1階 (刺身売り場) と2階 (食堂) の区別が分からない (2) チョジャン (コチュジャンベースの甘辛いタレ) とワサビの使い分けが分からない (3) メウンタン (辛い魚の鍋) が最後のコースだと知らない (4) 活魚の値段交渉ができない、といった問題があります。本ガイドでは、5ステップ + 市場・専門店 + 英語フレーズをご案内します。

★ 一目でわかる5ステップワークフロー

Step 動作 時間 外国人向け重要ポイント
1️⃣ チャンネル選択 市場 / 刺身専門店 / 食べ放題 / 韓定食 即時 コスパ・本格派・MZ世代・高級など目的に合わせて
2️⃣ メニュー注文 活魚 1kg / 1貫 (2～3人前) / 1人前 5～15分 市場 = kg単位
3️⃣ 受け取り・セッティング 刺身 + チョジャン (コチュジャンベースの甘辛いタレ)・サムチェソ (包み野菜)・ニンニク・メウンタン (辛い魚の鍋) (オプション) 10～20分 チョジャン・サムチェソのマナー
4️⃣ 食べる・ペアリング チョジャン (コチュジャンベースの甘辛いタレ) + サム (包み) + ソジュ (韓国焼酎)・メクチュ (ビール) 30～90分 メウンタン (辛い魚の鍋) = 最後のコース

> 合計所要時間: 市場 = 1～2時間 / 刺身専門店 = 1.5～3時間 / 食べ放題 = 1～2時間 / 韓定食 = 2～3時間

  • メニュー: 活魚 1kg (ヒラメ (クァンオ)・ブリ (パンオ)・タイ (トミ)・コノシロ (チョノ) など) + サムチェソ (包み野菜)・メウンタン (辛い魚の鍋)
  • 外国人フレンドリー度: ★★★★★ (英語メニュー・観光客向け)
  • 鷺梁津 (ノリャンジン): ([#587 鷺梁津水産市場のディープダイブ](587_noryangjin_fish_market_deep_dive.md)) — 早朝卸売・一般食堂
  • チャガルチ (チャガルチ): ([#590 チャガルチ市場のディープダイブ](590_jagalchi_fish_market_deep_dive.md)) — 釜山 (プサン) ナンバーワン・ブリ (パンオ) の本格派

Type B — 刺身専門店 (江南 (カンナム)・弘大 (ホンデ)・梨泰院 (イテウォン))

  • 外国人フレンドリー度: ★★★★ (英語メニュー)

  • 外国人フレンドリー度: ★★★★★ (グローバルMZ世代ナンバーワン)

  • 外国人フレンドリー度: ★★★★

🌶 チョジャン (コチュジャンベースの甘辛いタレ) vs ワサビ・サム (包み)・メウンタン (辛い魚の鍋) のマナー

チョジャン (Chojang・コチュジャン)

  • 構成: コチュジャン (唐辛子味噌) + 食酢 + 砂糖
  • 用途: 活魚の本格的な刺身・韓国式
  • 外国人向け: 「Spicy red sauce」・甘辛い

ワサビ (Wasabi)

  • 用途: マグロ (チャムチ)・サーモン (ヨノ)・熟成刺身・日本式
  • 外国人向け: 「Japanese horseradish」・薄めに

サム (包み) で食べる (活魚の刺身の本格派)

1. サムチェソ (包み野菜) (サンチュ (レタス)・ケンニプ (エゴマの葉)・ペチュ (白菜)) を手のひらに乗せる

2. 刺身 + ニンニク + チョジャン (コチュジャンベースの甘辛いタレ) + テンジャン (韓国味噌) (選択)

3. 手で包んで一口で食べる

4. 口を閉じて噛む (韓国のマナー)

メウンタン (Mae-untang) 最後のコース

  • 順序: 刺身 → メウンタン (辛い魚の鍋) (最後)
  • 材料: 刺身をさばいた後のアラ + 辛い味付け + 豆腐・もやし
  • 外国人向け: 「Spicy fish stew finale」・本格派

🌶 外国人向け英語フレーズ例

  • 「活魚のヒラメ (クァンオ) 1kg」 = "1kg of live olive flounder, please"
  • 「ブリ (パンオ) の本格派」 = "Yellowtail, the winter specialty"
  • 「メウンタン (辛い魚の鍋) コース」 = "Spicy fish stew finale, please"
  • 「辛さ控えめに」 = "Less spicy, please (チョジャン (コチュジャンベースの甘辛いタレ))"
  • 「割り勘で」 = "Split the bill, please"
  • 「カード使えますか？」 = "Card accepted?"

⚠ 外国人がよくする7つの間違い

1. 「市場1階 = 食事」: 市場1階 = 刺身売り場 (raw fish counter) / 2階 = 食堂 (eating area) — 分かれています。

2. 「活魚 = 高い」: 市場の活魚 1kg = ₩20,000 (~2,000 JPY)～₩60,000 (~6,000 JPY) (コスパ重視ナンバーワン)。

3. 「チョジャン (コチュジャンベースの甘辛いタレ) = ワサビ」: チョジャン (コチュジャンベースの甘辛いタレ) = コチュジャン (唐辛子味噌) (韓国の本格派) / ワサビ = 日本式 — 異なる調味料です。

4. 「メウンタン (辛い魚の鍋) = 別々の食事」: メウンタン (辛い魚の鍋) = 刺身の最後のコース (刺身 → メウンタン (辛い魚の鍋) の順)。

5. 「価格交渉X」: 市場の活魚 = 価格交渉が一部可能 (kg単位・鮮度別)。

6. 「妊婦OK」: 妊婦 = 刺身X (CDC推奨) — 火を通したメウンタン (辛い魚の鍋) はOK。

7. 「食べ放題 = 活魚」: 食べ放題 = マグロ (チャムチ)・サーモン (ヨノ) の熟成・冷凍 (活魚X)。

⚙ FAQ 8選

1. 初めての刺身 = どのチャンネル: マグロ (チャムチ)・サーモン (ヨノ) 食べ放題 (MZ世代・コスパ) → 市場のヒラメ (クァンオ) (本格派)。

2. インスタ・vlog: 鷺梁津 (ノリャンジン) の早朝・チャガルチ (チャガルチ) のブリ (パンオ)・マグロ (チャムチ) のトロ (トロ) はインスタ映えします。

3. MZ世代トレンド: サーモン (ヨノ)・マグロ (チャムチ) の食べ放題・MZ世代向けの刺身専門店。

4. ソジュ (韓国焼酎) マニア: 刺身 + メウンタン (辛い魚の鍋) + ソジュ (韓国焼酎) = 本格派。

5. 市場の時間帯: 鷺梁津 (ノリャンジン) = 早朝卸売・一般 09:00～22:00。

6. アレルギー・妊娠: 「[#864 韓国の刺身6種ガイド](864_korean_hoe_6_types_matrix.md)」の免責事項を参照 (妊婦は刺身X)。

7. 支払い・チップ: 市場 = 現金・カード / 刺身専門店 = カードOK / チップX。

8. VAT還付: 飲食料品は一般的に還付対象外です。

⚠ 医療・安全・食事に関する免責事項

刺身 = 生魚・食中毒に注意。妊婦 = 刺身X (CDC推奨)・メウンタン (辛い魚の鍋) = OK。子供 = 制限あり (5歳以上で加熱調理されたものが推奨)。アレルギー (魚・甲殻類・カンジャン (醤油) のグルテン) は事前に申告してください。食中毒の疑いがある場合は ☎ 1339 (医療、英語対応) へ。本ガイドは一般的な情報であり、医療アドバイスではありません。

食事制限の代替案:

  • ハラール・コーシャ: 刺身6種すべて魚類 = ハラールOK / コーシャは鱗とヒレがあればOK。
  • 菜食・ヴィーガン: 刺身 = 非菜食 / 菜食 = ビビンバ (ビビンバ)・サチャルウムシク (精進料理)。
  • グルテンフリー: 刺身自体はOK / カンジャン (醤油)・チョジャン (コチュジャンベースの甘辛いタレ) = グルテン一部含有 (タマリ醤油で代替)。
