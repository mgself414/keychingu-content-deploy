外国游客常犯的5个错误

1. 只去一家橄榄杨 (Olive Young / 올리브영)

明洞共有橄榄杨5家门店 — 明洞中央店 (Myeongdong Central / 명동중앙점)、明洞城店 (Myeongdong Town / 명동타운점)、乐天Young Plaza店 (Lotte Young Plaza / 롯데영플라자점) 等。明洞中央店是规模最大的旗舰店，配备外国人专属导购，各门店价格无差异。

2. 没有申请即时退税

收据 ₩30,000 以上 + 外国护照 = 即时享受9~10%抵扣。在收银台出示护照即可自动办理，无需额外手续。比机场退税更快更便捷。

3. 不知道外国人限定套装

悦诗风吟 (Innisfree / 이니스프리)、伊蒂之屋 (Etude / 에뛰드)、兰芝 (Laneige / 라네즈) 明洞旗舰店均设有外国人限定礼盒 (英文指南 + 迷你套装 + 礼品袋)，普通门店不提供 — 仅限明洞旗舰店专属。

4. 只买面膜

面膜性价比高，但韩国独家产品线 (芮谜 (rom&nd / 롬앤)、迪亚达利亚 (Dear Dahlia / 디어달리아)、悦诗风吟绿茶系列) 才是外国游客的真正价值所在。100片面膜不如1套招牌护肤品更具韩国特色。

5. 不保留收据

即使已申请即时退税，收据和凭证仍须妥善保管。出境时部分需核验，同时可防止重复退税，退换货时也需要用到。

FAQ

Q1. 可以说英语吗？

100% 可以。明洞门店是韩国接待外国游客经验最丰富的区域。

Q2. 即时退税与机场退税有何区别？

即时退税: 收银台自动抵扣 / 机场退税: 在出境柜台办理 + 信用卡退款 (需1~2周)。即时退税更快更便捷。

Q3. 外国人可以注册会员吗？

橄榄杨 (Olive Young / 올리브영)·悦诗风吟 (Innisfree / 이니스프리)·伊蒂之屋 (Etude / 에뛰드) = 外国手机号 + 邮箱即可注册，享受额外5~10%折扣。

Q4. 退税金额是多少？

9~10% (单张收据 ₩30,000+)，部分门店最高可达11%。

Q5. 韩国限定产品线在哪里买？

悦诗风吟·兰芝·雪花秀明洞旗舰店 (Innisfree·Laneige·Sulwhasoo Myeongdong / 이니스프리·라네즈·설화수 명동본점) = 限定礼盒。橄榄杨 (Olive Young / 올리브영) = 季节限定款。

Q6. 乘飞机带回去有什么限制？

液体类100ml限制 → 建议在机场免税店取货或托运行李携带。
