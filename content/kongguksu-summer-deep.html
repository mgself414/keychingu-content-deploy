외국인 한국 여름 매니아 1번지 = 콩국수 deep dive (#510 빙수·#502 밥상·#400 외국인 친화 식당 후속). 콩국수 = 한국 여름 보양식 #1 + 비건 친화 + 외국인 영어 OK + 평양·진주·서울 매니아 풀세트.

📜 콩국수 유래와 역사

조선시대 양반 보양식

  • 17세기 조선 — 콩 = "장수 식품"으로 동의보감 기록 (#546 UNESCO 2009)
  • 양반 가문 여름 보양식 — 콩 갈아 두유 + 면 조합
  • 계층 확산 — 일제강점기 평양·진주 등 지역으로 확산
  • 현대 정립 — 1950년대 서울 진주회관·진주집이 표준화

한국 콩국수 4 유파

유파 특징 대표 매장
평양식 진한 콩물·면 굵음·소금 간 피양콩할머니·강산옥
진주식 깔끔한 콩물·면 가늠·고소함 진주회관·진주집
서울식 부드러운 콩물·고명 풍부 명동교자·맛자랑
노포식 100년 전통·가족 비법 황금콩밭·서민준

❄ 왜 여름에 콩국수를 먹어야 하는가 5가지

1. 단백질 보충 — 콩 100g = 단백질 36g (식물성 #1)·여름 더위로 떨어진 체력 회복

2. 체온 조절 — 차가운 콩물 4~8℃·시원한 청량감·#510 빙수와 함께 여름 매니아 1번지

3. 소화 흡수 — 콩단백질 + 면 탄수화물 = 영양 균형·소화 부담 적음

4. 비건·할랄 친화 — 100% 식물성 + #521 비건 할랄 매니아 1번지 + 무슬림 OK

5. 다이어트 + 보양 — 칼로리 낮음 (1그릇 400kcal) + 단백질 풍부 = 다이어트 + 여름 보양 동시

⚠ 외국인 자주 실수 5가지

1. "콩국수 = 두유": 콩국수 = 갈아 만든 신선 콩물 + 면 + 소금 간 + 오이·토마토 고명. 두유·우유 다름 + 외국인 매니아 1번지.

2. "여름에만 먹음": 콩국수 = 여름 1순위 (6~8월) + 봄·가을 매니아 + 일부 노포 365일 제공 + #510 빙수와 함께.

3. "맛 = 심심함": 외국인 매니아 1번지 = 소금 (전통 진주식) + 설탕 (서울식 일부) + 김치 곁들임 (#523) + 외국인 정통 매니아 + #502·#523 통합.

4. "외국인 못 먹음": 외국인 매니아 = 명동교자·진주회관 (영어 메뉴) + 사진 메뉴 + 외국인 친화 식당 (#400) 풀세트 + #400·#178 통합.

5. "비건 = 안됨": 비건 = 100% 식물성 + #521 비건 할랄 매니아 1번지 + 무슬림 OK + 채식 매니아 + #521 통합.
