🎯 为什么需要首尔地铁完整指南

外国游客入境韩国的首要痛点 = 地铁 (Jìtiě / 지하철)。首尔地铁拥有 24条线路·750多个车站，是世界一流的公共交通系统。它提供外国人友好的英语、中文、日语指引，并支持 T-money 卡全天候使用。本指南将为您提供完整的出行路线指引。

⚠ 外国游客常犯的5个错误

1. “换乘 (Huancheung / 환승) = 不同线路 = 重新支付”: T-money 卡在30分钟内换乘免费。最多可换乘4次。必须使用同一张卡刷卡。

2. “机场铁路 = 只有直达列车”: 机场铁路有2种 — 直达列车 (Express, ₩9,500 (~50 RMB)·43分钟) + 普通列车 (Pǔtōng Lièchē / 일반) (₩4,250 (~23 RMB)·58分钟)。MZ世代 (MZ Shìdài / MZ) (指20-35岁的年轻一代) 和预算有限的游客可选择普通列车。携带14公斤以上行李的游客建议选择直达列车。

3. “末班车 (Mobanche / 막차) = 午夜”: 末班车时间为23:30~00:30 (因线路·车站而异)。假设凌晨1点仍有车会很危险。务必在末班车发车前30分钟抵达。

4. “9号线 = 只有普通列车”: 9号线有急行 (Jíxíng / 급행) / 普通 (Pǔtōng / 일반) 2种。急行从金浦机场 (Gimpo Airport / 김포공항) 到蚕室 (Jamsil / 잠실) 需25分钟 / 普通列车需50分钟。对于外国人来说，如果行程较长，急行是首选。但急行列车会在部分车站不停靠。

5. “外国人购票 = 困难”: 一次性 T-money 购票机支持英文操作 + 退还500韩元押金。可充值 T-money 卡 (在便利店 (Biànlìdiàn / 편의점)·车站) 对外国人友好。移动 T-money (支持 Naver Pay·Toss·KakaoPay 支付，2024年已扩展)。

⚙ 8个常见问题

1. 外国人 T-money 办理: 在便利店 (Biànlìdiàn / 편의점) (CU·GS25·7-Eleven·Emart24) 购买 ₩4,000 (~21.5 RMB) 的卡 + 充值。退款时，卡内余额和500韩元押金不予退还。

2. 移动 T-money: 安卓 NFC + 支持 Naver Pay·KakaoPay·Toss 支付 (2024年已扩展)。iPhone 不支持。

3. 换乘 (Huancheung / 환승) 规则: T-money 刷卡后30分钟内换乘 (Huancheung / 환승) 其他线路·巴士免费 (最多4次换乘)。同一线路再次进入算1次。

4. 票价: 基本票价 ₩1,400 (~7.5 RMB) (10公里以内) + 每5公里加收100韩元。外国人普通线路票价为 ₩1,400~₩2,400 (~7.5~13 RMB)。

5. 运营时间: 通常 05:30~24:00。末班车 (Mobanche / 막차) 时间因线路·车站而异 — 务必实时查看 Naver 地图 (Naver Jido / 네이버 지도)·Kakao 地图 (Kakao Maep / 카카오맵)。

6. 外国人友好: 1·2·4·5·6·9号线·机场铁路 = 提供英·中·日·韩 4种语言的完整指引。外围线路仅提供韩语·英语。

7. 刷卡支付: 部分车站支持信用卡 (海外发行的 Visa·Master·JCB 卡均可) 直接支付 (2024年已扩展)。推荐使用 T-money。

8. 拍照·录音: 地铁内部拍照可以 (个人使用)·不建议直播 (优先考虑列车安全)。
