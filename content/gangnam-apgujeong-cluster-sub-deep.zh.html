狎鸥亭·蚕院半日游指南 — 狎鸥亭罗德奥街 (Apgujeong Rodeo-geori / 압구정 로데오거리)、现代百货狎鸥亭本店 (Hyundai Department Store Apgujeong Main Store / 현대백화점 압구정본점)、Galleria名品馆 (Galleria Luxury Hall / 갤러리아 명품관)、蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원) 共4处，2026年10月确认

副标题：现代百货狎鸥亭本店 (Hyundai Department Store Apgujeong Main Store / 현대백화점 압구정본점) 与狎鸥亭站 (Apgujeong Station / 압구정역) 6号出口直接相连，3层可当场办理退税(现代百货官方) · Galleria名品馆 (Galleria Luxury Hall / 갤러리아 명품관) 分WEST、EAST两馆，周一至周四10:30~20:00，周五至周日10:30~20:30(Galleria官方) · 蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원) 从狎鸥亭站6号出口步行约15~20分钟(汉江公园官方) · 蚕院游泳池 (Jamwon Suyeongjang / 잠원 수영장) 因改建工程关闭，预计2028年重新开放(汉江公园官方) — 截至2026-10-22

ISSUE 03 · #713 · 2026-06-02

🎯 本指南的使用方法

走出狎鸥亭站 (Apgujeong Station / 압구정역) 6号出口就是百货公司正门，再向北走十五分钟出头，汉南大桥 (Hannam Bridge / 한남대교) 下就有江风吹来。本指南只讲狎鸥亭洞 (Apgujeong-dong / 압구정동) 这一个街区。白天逛罗德奥街 (Rodeo-geori / 로데오거리) 和两家百货公司，日落时分走到蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원)，是一条半日路线。第一次来江南 (Gangnam / 강남) 想了解狎鸥亭是什么样的街区的人，想一边逛名品馆一边把退税一并办完的人，都适合阅读。

江南站·COEX (COEX / 코엑스)，#301，、清潭 (Cheongdam / 청담) 名品街·画廊，#296，、盘浦 (Banpo / 반포) 汉江公园·世光岛 (Sebitseom / 세빛섬)，#712，请看下面🔗相关内容中的各篇。时间、地址、费用都是在官方页面直接打开确认的数值，没能打开的数值，我们也如实写明了。

🛍 狎鸥亭罗德奥街 (Apgujeong Rodeo-geori / 압구정 로데오거리) — 适合步行的街区

  • 狎鸥亭罗德奥街 (Apgujeong Rodeo-geori / 압구정 로데오거리) — 位于首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭洞 (Apgujeong-dong / 압구정동) 一带。全天开放、全年无休，没有婴儿车租借(VisitKorea)。VisitKorea介绍说，这条街在90年代初成为时尚中心，如今不只是购物，美食和景点也很多
  • K-Star Road，即强南偶像 (Gangnamdol / 강남돌) — 从狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 2号出口到清潭十字路口 (Cheongdam Sagori / 청담사거리) 约1km的路上，摆放着披上K-pop组合形象的熊玩偶雕塑“强南偶像 (Gangnamdol / 강남돌)”。Galleria百货 (Galleria Department Store / 갤러리아백화점) 前面有一座高3m的鸟叔强南偶像，另外还有17座(VisitSeoul，2024年6月修改的文章)。现在是否全部还在原处，我们没能确认
  • 罗德奥街 (Rodeo-geori / 로데오거리) 各家店铺的营业时间因店而异，本指南没有列出。清潭 (Cheongdam / 청담) 一侧的名品旗舰店街请看漫步清潭洞：路易威登之家与迪奥之家建筑，松隐、路易威登艺术空间、爱马仕工作室画廊，岛山公园，新沙 (Sinsa / 신사) 的林荫道 (Garosu-gil / 가로수길) 请看#295

🏬 现代百货狎鸥亭本店 (Hyundai Department Store Apgujeong Main Store / 현대백화점 압구정본점) — 与地铁站相连的百货公司

  • 地址：首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 165。总机1588-3650(现代百货官方)
  • 营业时间：周一至周四10:30~20:00，周五至周日10:30~20:30，餐厅街11:00~22:00(现代百货官方分店页面)。休息日每月都会登在分店页面的日历上。VisitKorea的入驻店铺信息里写的是“节假日、每月1次”休息
  • 交通：地铁3号线狎鸥亭站 (Apgujeong Station / 압구정역) 6号出口里面的通道连到百货公司地下2层入口，走出6号出口就是百货公司正门。机场巴士6006路停靠狎鸥亭站站点(现代百货官方)
  • 外国人服务(现代百货官方服务设施页面)
  • 退税 Tax Refund — 3层，02-3449-5207。外国顾客所购商品的免税金额，百货公司当场退还
  • 行李寄存处 — 地下1层，02-3449-5550

💎 Galleria名品馆 (Galleria Luxury Hall / 갤러리아 명품관) — 马路两边的两座馆

  • 地址：WEST 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 343，EAST 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 407。总机1544-6600(Galleria官方)
  • 营业时间：周一至周四10:30~20:00，周五至周日10:30~20:30。美食馆美食494 (Gourmet 494 / 고메이494) 时间相同，最后点餐时间是打烊前30分钟。2026年10月的营业信息显示“无休息日”。下个月的信息每月最后一周更新(Galleria官方)。VisitKorea写的是“每月休息1次”
  • 建筑：两座馆WEST、EAST隔着马路相对。WEST馆鱼鳞形状的外墙到了夜晚会变色(VisitKorea)
  • 外国人服务(Galleria官方顾客便利设施页面)
  • 外国人服务中心 — WEST 5层，02-3449-4151 / 02-3449-4411
  • 礼宾台 — WEST 1层，02-3449-4020
  • 退税方式：WEST馆即时退税、事后退税都可以办理(VisitKorea旅游信息)
  • 两家百货公司的品牌构成和江南名品购物的整体情况请看#771，首尔百货公司的比较请看#449

🌊 蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원) — 从狎鸥亭走下去的汉江

  • 基本信息：首尔瑞草区 (Seocho-gu / 서초구) 蚕院路 (Jamwon-ro / 잠원로) 221-124。从永东大桥 (Yeongdong Bridge / 영동대교) 南端到潜水桥 (Jamsugyo / 잠수교) 上游，该桥即盘浦大桥，长5.4km，面积474,213㎡。服务中心02-3780-0531~3，行政业务时间09:00~18:00(汉江公园官方)。公园全天开放、全年无休(VisitKorea)
  • 交通(汉江公园官方“交通”页面)
  • 3号线狎鸥亭站 (Apgujeong Station / 압구정역) 6号出口 → 向现代高中 (Hyundai High School / 현대고등학교) 方向步行约15~20分钟(狎鸥亭出入口 (Apgujeong Nadeulmok / 압구정나들목))
  • 3号线新沙站 (Sinsa Station / 신사역) 5号出口 → 向新沙初中 (Sinsa Middle School / 신사중학교) 方向步行约15~20分钟(新沙出入口 (Sinsa Nadeulmok / 신사나들목))
  • 3号线蚕院站 (Jamwon Station / 잠원역) 4号出口 → 向蚕院韩信公寓 (Jamwon Hansin Apartment / 잠원한신아파트) 方向步行约15分钟(蚕院出入口 (Jamwon Nadeulmok / 잠원나들목))
  • 乘汉江巴士 (Hangang Bus / 한강버스) 在狎鸥亭码头 (Apgujeong Seonchakjang / 압구정 선착장) 下船，即可连到公园
  • 景点·玩法：沿江自行车道5.4km。自行车租赁点在汉南大桥 (Hannam Bridge / 한남대교) 南端上游、蚕院第2号小卖部 (Jamwon Je2-ho Maejeom / 잠원제2호매점) 前面。官方页面推荐的景点有蚕院草园 (Jamwon Grass Garden / 잠원 그라스정원) 的粉黛乱子草、蚕院蜜蜂林 (Jamwon Kkulbeolsup / 잠원 꿀벌숲)、蚕宝宝体验学习场 (Nuae Cheheom Hakseupjang / 누에체험학습장)。还有滑水、尾波板等水上休闲项目，以及船上咖啡厅和餐厅设施(汉江公园官方)
  • 汉江环行观光车，即獬豸号 (Haechi-ka / 해치카)：从铜雀站 (Dongjak Station / 동작역) 2号出口 → 盘浦汉江公园 (Banpo Hangang Park / 반포한강공원) 和世光岛 (Sebitseom / 세빛섬) → 蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원) 和首尔波浪 (Seoul Wave / 서울웨이브) 循环行驶的免费环行车。2026年运行期间为4月4日~11月30日，每20分钟一班。周一至周五14:00~20:00，周末和公休日11:00~20:00，16:00~17:00不运行(汉江公园官方)。盘浦 (Banpo / 반포) 一侧的路线请看#712
  • 游泳池：蚕院汉江公园游泳池 (Jamwon Hangang Gongwon Suyeongjang / 잠원 한강공원 수영장) 因改建工程关闭，预计2028年重新开放。首尔市建议改用纛岛 (Ttukseom / 뚝섬)、汝矣岛 (Yeouido / 여의도) 汉江公园的游泳池。汉江公园游泳池已全部结束2026年运营，2027年日程尚未公布(汉江公园官方)
  • 雪橇场：2025~2026雪季在蚕院游泳池场地于2025年12月31日~2026年2月18日运营，门票不分年龄均为6,000韩元(汉江公园官方)。因为游泳池在施工，2026~2027年冬天蚕院 (Jamwon / 잠원) 是否再开，尚未公布
  • 便利设施：便利店3家，卫生间9处。停车场6处722个车位，06:00~24:00(汉江公园官方)
  • 首尔汉江公园整体比较请看#706

🧰 狎鸥亭实用信息 — 独自出行、预约、支付、退税、移动

  • 独自出行：四处都无需预约，一个人也能进去。百货公司餐厅街里适合一个人吃饭的地方请看#348 首尔单人餐厅地图
  • 支付·退税：请带好护照。现代百货 (Hyundai Department Store / 현대백화점) 在3层退税柜台当场退税(现代百货官方)，Galleria WEST馆 (Galleria WEST-gwan / 갤러리아 WEST관) 即时、事后退税都可以办理(VisitKorea)。条件和机场流程请看#1231 退税指南和#1304 机场自助机流程版。银行卡和移动支付请看#527
  • 移动：只靠3号线狎鸥亭站 (Apgujeong Station / 압구정역) 一站，就能到现代百货 (Hyundai Department Store / 현대백화점) 和蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원)。交通卡请看#1298。官方页面提醒，周末和公休日汉江公园周边会堵车，请乘坐公共交通
  • 汉江礼仪：垃圾必须自己带走，违者罚款100,000韩元，在非指定地点停车罚款50,000韩元。公园内禁烟，也不能做饭(汉江公园官方)

⚠ 常见的4个错误

1. “夏天去蚕院游泳池” — 因改建已关闭，预计2028年重新开放。夏天游泳请去纛岛 (Ttukseom / 뚝섬)、汝矣岛 (Yeouido / 여의도) 汉江公园的游泳池(汉江公园官方)

2. “百货公司每天同一时间关门” — 两家百货公司都是周五至周日20:30关门，周一至周四20:00关门(各自官方页面)

3. “退税只能在机场办” — 现代百货狎鸥亭本店 (Hyundai Department Store Apgujeong Main Store / 현대백화점 압구정본점) 3层当场退税(现代百货官方)

4. “从狎鸥亭站出来汉江就在眼前” — 从6号出口步行约15~20分钟，要经过狎鸥亭出入口(압구정나들목)才能进入汉江公园(汉江公园官方)
