외국인이 자주 하는 실수 3가지

1. "야장 = 야시장(night market)" 오해

한국 "야장(野場)"은 야시장이 아닌 "야외 좌석 + 새벽 영업" 매장. 영문으로 "outdoor seating bar/restaurant" 가까움. 광장시장·남대문 야시장과 다른 culture — 개별 매장의 야외 테이블·심야 영업이 핵심. 16:00~새벽 2:00 영업이 가장 흔함.

2. "야장 = 거리 위 무허가" 오해

서울 시내 야장은 합법 야외 좌석 + 매장 부설. 우성갈비·전곱·서울집시 모두 정식 매장에 야외 테이블. 외국인 영어 리뷰(우성갈비): "Foods good, service is great, they speak Chinese so that helped me, my group was struggling with cutting the meat and the owner helped us" — 직원이 외국인 도와줌. 단순 길거리 포장마차와 다름.

3. "심야 영업 = 위험" 인식

서울 새벽 시간은 일본·유럽 대비 안전. 야장 cluster(서순라길·돈화문·계동·동호로)는 종로구·중구 중심 — 지하철 막차 후에도 택시·카카오T로 안전 귀가. 외국인 일본어 리뷰(서울집시 한남점): "4th time here at Seoul Gypsy and i must say, it's my fav beer spots in Seoul" — 외국인 재방문 빈도 높음.

  • 카테고리: 피자 야장 (성북 동소문 동리단길)
  • 위치: 서울 성북구 동소문로2길 85 1층 (한성대입구역 도보 5분)
  • 외국인 신호: 외국어 리뷰 0건 — 트렌디 MZ 매장 (외국인 미커버)
  • 시그니처: 동리단길 cluster 시그니처 피자 + 야외 좌석 (보헤미안 분위기)
  • 외국인 어드밴티지: 동리단길 산책 후 자연 동선 / 1인·커플·소그룹 OK
  • 외국인 핵심 팁: 화~일 영업, 월 휴무. 동리단길 골목 cluster에 다른 카페·바 다수 — 한 area 한바퀴 가능.
  • 운영시간: 화~일 10:00 ~ 22:00 / 월 정기 휴무
  • 예산: 피자 + 음료 = 1인 ₩20,000~₩30,000

3. FAQ — 외국인이 자주 묻는 6가지

Q1. 새벽 영업 야장 — 안전한가요?

  • 종로·중구·용산은 24/7 안전. 새벽에도 카카오T 또는 일반 택시 호출 가능.
  • 도봉(방학동)은 외곽이라 지하철 막차 후엔 택시 필수.
  • 영어 가능 매장(가가바·서울집시·팔계집)은 안내 친절.

Q2. 결제 — WeChat Pay·Alipay 가능한가요?

매장 카드 카카오페이·삼성페이 WeChat Pay / Alipay 현금
팔계집 ✓ ✓ 일부 가능 (매장 확인) OK
가가바 ✓ ✓ 일부 가능 (매장 확인) OK
서울집시 ✓ ✓ 일부 가능 (매장 확인) OK
동리단길피자 ✓ ✓ 미확인 (2026-05) OK
우성갈비 ✓ 부분 미확인 권장 병행
전곱 ✓ 부분 미확인 권장 병행
세전주식당 ✓ 부분 미확인 권장 병행
쌍미곱창 ✓ ✓ 미확인 OK

방학동포차마을 매장마다 상이 매장마다 상이 미확인 현금 지참 권장

> 팁: 노포·포차 계열은 현금 ₩50,000권 이상 지참 권장. 카카오페이·삼성페이는 한국 내 계정이 필요하므로 외국인은 국제 카드(Visa/Mastercard) 우선.

Q3. 영어 메뉴 있나요?

  • 팔계집 (House of 8 Grill) / 가가바 / 서울집시: 영어 메뉴 ✓ + 영어 가능 직원
  • 우성갈비: 영어 메뉴 일부 + 직원 중국어 가능 + 영어 부분
  • 신미식당 / 동리단길피자 / 쌍미곱창: 영어 메뉴 부분 (사진 메뉴)
  • 세전주식당 / 전곱 / 방학동포차마을: 한국어 위주 (직원에게 추천 요청·사진 가리키기)

Q4. 1인 방문 가능한가요?

  • 8 매장 모두 1인 OK. 야장 culture는 1인·소그룹 자연.
  • 방학동포차마을·세전주식당은 동네 단골 cluster — 한국인 친구 동반 시 더 자연.

Q5. 비건·할랄·종교 식이 가능한가요?

  • 비건: 동리단길피자(피자 일부) / 서울집시 음료 / 가가바 일부. 갈비·곱창 매장은 비건 불가.
  • 할랄: 인증 매장 없음. 음료만 권장 (서울집시 크래프트 비어).

Q6. 어린이 동반 가능한가요?

  • 팔계집·동리단길피자·신미식당·쌍미곱창: 어린이 동반 OK
  • 가가바·서울집시·우성갈비·전곱·방학동포차마을·세전주식당: 술 위주 → 어린이 비추천
