🎯 왜 제주 해변 가이드인가

제주 해변 = 한국 #1 해변 매트릭스·협재 (서쪽·에메랄드)·함덕 (북쪽·MZ)·중문 (남쪽·5성 호텔)·이호테우 (북쪽·말 등대)·MZ + 인스타 매트릭스 #1. 외국인 페인포인트 = (a) "제주 해변 = 일반 해변" 잘못된 인식 (b) 협재 = 에메랄드 색·인스타 #1 (c) 함덕 = MZ + 카페 cluster + 인스타 (d) 중문 = 5성 호텔 + 매니아 매트릭스 (e) 이호테우 = 말 등대 인스타 매트릭스 #1.

본 가이드는 5축 12 시그니처 + 4 해변 + MZ + 인스타.

🏛 5축 deep dive

① 협재 해변 (서쪽·에메랄드)

  • 시그니처: 에메랄드 색·인스타 #1·비양도 cluster·평지 + 모래
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족·인스타)
  • 시간: 24h·무료

② 함덕 해변 (북쪽·MZ)

  • 시그니처: MZ + 카페 cluster + 인스타·SUP·해변
  • 외국인 친화도: ★★★★★ (영문·MZ + 매니아)
  • 추천: 카페 + SUP + 인스타 = 매트릭스

③ 중문 해변 (남쪽·5성 호텔)

  • 시그니처: 5성 호텔 cluster·외국인 매니아 매트릭스·관광단지
  • 외국인 친화도: ★★★★★ (영문 + 매니아)
  • 가격: 5성 호텔 1박 = 200,000~600,000원

④ 이호테우 (북쪽·말 등대)

  • 시그니처: 말 등대 인스타 매트릭스 #1·일몰 매트릭스
  • 외국인 친화도: ★★★★★ (인스타 + MZ)
  • 시간: 24h·무료

⑤ 추가 해변 (금능·김녕·서쪽)

  • 시그니처: 매니아 매트릭스·금능 = 협재 옆
  • 외국인 친화도: ★★★★ (MZ + 매니아)

⚠ 외국인 자주 실수 5가지

1. "제주 해변 = 다 같음": 협재 (에메랄드)·함덕 (MZ)·중문 (5성)·이호테우 (말 등대) = 완전 다른 매트릭스.

2. "협재 = 작은 해변": 에메랄드 색·한국 #1 인스타 해변.

3. "함덕 = 일반 해변": MZ + 카페 cluster + 인스타 매트릭스.

4. "중문 = 일반 해변": 5성 호텔 cluster + 외국인 매니아 매트릭스.

5. "이호테우 = 일반 해변": 말 등대 인스타 매트릭스 #1·일몰.

⚙ FAQ 6개

1. 외국인 입문 1순위: 협재 + 함덕 + 중문 = 1일.

2. 수영 시즌: 여름 (6-8월)·연중 산책 OK.

3. SUP·서핑: 함덕 = MZ 매니아 매트릭스 #1·30,000~80,000원/시간.

4. 호텔: 중문 = 5성 호텔 cluster·외국인 매니아 매트릭스.

5. 이호테우 일몰: 매니아 매트릭스 #1·연중 OK.

6. 추천 페르소나: 가족·시니어 = 협재 + 중문 / MZ·인스타 = 함덕 + 이호테우 / 매니아 = 1박 + 풀세트.

⚠ 의료·안전 disclaimer

해변 = 안전·MZ 친화. SUP·서핑 = 안전 장비. 여름 폭염 + 자외선 차단. 응급 ☎ 1339·1330·119.
