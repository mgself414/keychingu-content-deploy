🎫 票价——孩子的年龄就是票价

首尔地铁(首尔交通公社票价说明)

  • 幼儿: 未满6周岁免费。每位监护人最多带3名，从第4个孩子起，每人按儿童票价付费
  • 儿童: 满6周岁以上、未满13周岁(小学生)。基本票价550韩元，交通卡和一次性交通卡金额相同
  • 青少年: 满13周岁以上、18周岁以下。交通卡基本票价900韩元。一次性交通卡适用成人票价(1,650韩元)
  • 成人: 交通卡基本票价1,550韩元(10km以内)
  • 想享受优惠: 儿童·青少年票价要先买交通卡，并登记为儿童·青少年卡后才适用(首尔市交通指南)

韩国铁道公社列车(含KTX)(韩国铁道公社常见问题)

  • 未满6周岁: 可免费乘坐。若单独指定座位，票价可享75%折扣
  • 未满13周岁: 票价5折(50%折扣)
  • 官方也介绍了多子女、“妈妈安心KTX”等优惠产品，但外国游客能否享受，未能确认

景福宫 (Gyeongbokgung / 경복궁): 外国成人(满19~64周岁)3,000韩元(宫陵遗迹本部 / Gungneung Yujeok Bonbu / 궁능유적본부)。儿童票价在这次打开的票价表中未能确认

🧸 亲子去处——5处

  • 国立中央博物馆儿童博物馆 (Gungnip Jungang Bangmulgwan Eorini Bangmulgwan / 국립중앙박물관 어린이박물관) — 首尔龙山区西冰库路137号 (Seobinggo-ro / 서빙고로)(国立中央博物馆)。09:30~17:20，每天5场(每场80分钟)，入场免费。实行线上预约制，参观日14天前00点开放预约，一次最多5张。不提供现场售票。展厅主要面向5~9岁，“滚滚游乐场 (Degulgugul Nori-teo / 데굴데굴놀이터)”是36个月以下婴幼儿的空间。休馆日为1月1日·春节·中秋，2026年剩余的休馆日是12月7日(周一)(国立中央博物馆儿童博物馆网站)。咨询电话 02-2077-9647
  • 国立民俗博物馆儿童博物馆 (Gungnip Minsok Bangmulgwan Eorini Bangmulgwan / 국립민속박물관 어린이박물관) — 首尔钟路区三清路37号 (Samcheong-ro / 삼청로)，国立民俗博物馆内(国立民俗博物馆)。1~12月 09:30~16:50，入场免费，须先在网站预约后参观。休馆日为1月1日·春节当天·中秋当天。馆内没有停车场，需使用景福宫停车场(收费)。从地铁3号线安国站 (Anguk-yeok / 안국역) 1号出口步行约15分钟(国立民俗博物馆网站)
  • 首尔想象国 (Seoul Sangsangnara / 서울상상나라) — 首尔广津区能洞路216号 (Neungdong-ro / 능동로)，首尔儿童大公园正门停车场旁(首尔想象国)。10:00~18:00(截止入场17:00)，每周一休馆，1月1日·春节·中秋连休期间也休息。满36个月的儿童和成人一律4,000韩元，未满36个月免费(凭户籍誊本·健康保险证·婴儿手册其中之一确认)。从地铁7号线儿童大公园站 (Eorinidaegongwon-yeok / 어린이대공원역) 1号出口步行5分钟(首尔想象国网站)
  • 首尔儿童大公园 (Seoul Eorini Daegongwon / 서울어린이대공원) — 首尔广津区能洞路216号 (Neungdong-ro / 능동로)(首尔市设施公团 / Seoul-si Seolbi Gongdan / 서울시설공단)。公园全年无休 05:00~22:00，免费入场。动物园开放时间为10:00~17:00。植物园自2026年5月27日起停止运营至2027年下半年(预定)(首尔市设施公团儿童大公园网站)。很适合和首尔想象国安排在同一趟
  • 国立果川科学馆 (Gungnip Gwacheon Gwahakgwan / 국립과천과학관) — 京畿道果川。常设展览成人(20~64岁)4,000韩元，青少年·儿童(7~19岁)2,000韩元，未满7岁免费。常设展馆无需提前预约，每月最后一周的周三个人票价5折(50%折扣)(国立果川科学馆票价说明)。开放时间和休馆日因官方页面只由脚本绘制，未能确认——咨询电话 02-3677-1500

🍼 婴儿车·哺乳室——设施公布的位置

  • 国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관): 哺乳室在常设展厅1层纪念品商店对面，婴儿车租借处在常设展厅1层入口与寄存处之间，所有洗手间都有尿布更换台。儿童博物馆入口还有为感官刺激过度而疲惫的孩子准备的心理安定室“心灵呵护所 (Maeum Boduemso / 마음보듬소)”(国立中央博物馆无障碍说明)
  • 首尔想象国 (Seoul Sangsangnara / 서울상상나라): 自带的婴儿车可以寄存在1层售票处后面，但不提供租借。哺乳室在2层中央·婴儿游乐场内侧和3层中央。3层家庭休息区(10:00~17:00)可以吃自带的零食和便当，但不提供热水，杯面和外卖不可带入(首尔想象国设施说明)
  • 景福宫 (Gyeongbokgung / 경복궁): 宫陵遗迹本部参观说明里的设施列表中，另外标注了婴儿车租借处和哺乳室，也介绍了“轮椅·婴儿车可通行的路线”(宫陵遗迹本部 / Gungneung Yujeok Bonbu / 궁능유적본부)。租借条件未能确认

🧰 带孩子的实用事项——预约、付款、用餐、交通、生病时

  • 预约: 国立中央博物馆儿童博物馆在14天前00点开放预约，场次开始30分钟后仍未入场，预约会自动取消。不取消而不来的话，60天内限制参观(国立中央博物馆预约说明)。国立民俗博物馆儿童博物馆同样要先在网站预约
  • 付款: 外国人韩国支付系统深度探索
  • 用餐: 博物馆展厅内不能吃东西(国立中央博物馆·国立民俗博物馆)。适合孩子口味的菜单请看 怕辣也能吃 — 不辣的韩餐地图：写给孩子·长辈·辣度新手的20道菜与点单用语，过敏卡请看 韩国饮食需求·辣度调节，零慌张手册 — 靠展示卡片就能搞定
  • 交通: 挑选交通卡请看 韩国交通卡3种选择，零慌张手册 — 按我的行程原样挑卡。去首尔以外请看 韩国高速·城际巴士客运站，流程原样照搬 — App从一开始就完全不同
  • 孩子生病时: 急诊室·夜间门诊请看 外国人急救·医院·安全指南，社区诊所挂号请看 韩国看病，零慌张流程表 — 凭一本护照从挂号走到药房，退烧药等请看 韩国药店使用零慌张手册 — 症状卡片直接出示。首尔想象国在2层设有可做简单急救的医务室(首尔想象国)

⚠ 常见失误4条

1. “周一把儿童博物馆一口气逛完” — 首尔想象国每周一休馆(首尔想象国)。国立中央博物馆儿童博物馆2026年12月7日(周一)也是休馆日(国立中央博物馆)

2. “国立中央博物馆儿童博物馆到了现场买票就行” — 实行线上预约制，不提供现场售票(国立中央博物馆)

3. “儿童票价到十二岁在哪里都一样” — 地铁的儿童是未满13周岁，国立果川科学馆则把7~19岁合为一档票价。各设施的标准不同(首尔交通公社·国立果川科学馆)

4. “在首尔想象国租婴儿车就行” — 只能寄存，不提供租借(首尔想象国)
