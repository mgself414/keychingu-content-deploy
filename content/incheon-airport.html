외국인이 자주 하는 실수 5가지

1. T1과 T2 공항을 헷갈리는 것

인천공항은 2개의 터미널 — T1·T2가 셔틀버스 15분 거리. 항공권 확인 필수. 잘못 가면 셔틀 + 30분 추가. T2는 대한항공·델타·KLM·에어프랑스, T1은 그 외.

2. 환전을 공항에서 하는 것

공항 환전 환율 명동·시내보다 2~3% 나쁨. 공항에서는 ₩50,000 정도 소액 환전(택시·교통카드용)만 하고, 시내 가서 본격 환전. 명동 노상 환전소(#63 참조) 환율 1순위.

3. AREX 직통 vs 일반 구분 못 함

AREX 직통열차 = 서울역 직행 43분 ₩11,000 (예약 필수, 06:00~22:00)

AREX 일반열차 = 정류장 11개 정차 1시간 ₩4,500 (24시간, 예약 X)

같은 노선이지만 시간·가격 차이 명확. 짐 적으면 일반, 시간 우선이면 직통.

4. SIM·환전 같이 못 받는 것

공항 안에서 SIM 카드 + ₩50,000 환전 한 번에 처리하면 시간 절약. 공항 출구 직전 SK텔레콤·KT 부스 + 환전소 옆에 위치.

5. 택시 호객·미터 안 켜는 택시 주의

공항 출구 호객 택시 = 불법 (정식 택시는 줄 서서 픽업). 일반 택시는 미터기 켜는지 확인 + 영수증 받기. 카카오T 영문 앱이 안전.

★ 인천공항 첫 6시간 풀가이드

Step 1: 비행기 도착 → 입국 심사 (15~30분)

  • K-ETA(한국 전자여행허가) — 사전 신청 필수 (90개국 비자면제 입국 시) https://www.k-eta.go.kr
  • 입국신고서 비행기 내 작성 (영어 OK)
  • 외국인 줄 = 일반 외국인 / K-ETA 보유 = 패스트트랙
  • 평일 새벽·주말 폭증 시 30분~1시간 대기 가능

Step 2: 짐 찾기 (10~30분)

  • 항공편 도착 표지판 확인
  • 짐 분실 시 항공사 카운터 (영어 응대) 신고
  • 카트 무료

Step 3: 세관 통과 (5분)

  • 신고할 것 없음 = 녹색 라인 (외국인 대부분)
  • 면세 한도: ₩800,000 + 술 1L + 담배 200개비
  • 초과 시 빨간 라인

Step 4: 환전 + SIM (15~20분)

  • 환전소 = 공항 출구 다수 (₩50,000 소액만 추천)
  • SIM 카드 부스 (SK·KT·LG U+) — 1일·5일·10일·30일 옵션 ₩5,000~50,000
  • e-SIM 옵션 — 휴대폰 호환 시 더 편리
  • 외국인 한국 휴대폰 번호 → 카카오T·배달 앱 등록 가능

Step 5: 도심 이동 (1~1.5시간)

① AREX 직통열차 (Express) — 시간 우선

노선: 인천공항 T1·T2 → 서울역 직행 (정차 X)

가격: ₩11,000 (어른) / 경차표 ₩4,500

소요: 43분 (T2 출발) / 51분 (T1 출발)

운행: 06:00~22:00 (30분 간격)

예약: 공항철도 영문 앱·홈페이지 / 현장 발권 OK

핵심:

  • 좌석 지정 + 짐 보관 좌석 옆 OK
  • WiFi·전원 콘센트 완비
  • 서울역 도착 후 지하철 환승 + KTX 환승 즉시
  • 시간 우선 + 1~2인 짐에 적합

한 줄: "43분 직행 = 외국인 시간 우선 1순위"

② AREX 일반열차 — 가성비

노선: 인천공항 T1·T2 → 서울역 (11개 정류장 정차)

가격: ₩4,500

소요: 1시간 (T2) / 1시간 7분 (T1)

운행: 24시간 (5분~10분 간격)

예약: X (현장 카드 결제 OK)

핵심:

  • 일반 지하철과 동일 좌석 — 짐 두기 약간 불편
  • 김포공항·홍대입구·서울역 정차 → 지하철 환승 OK
  • 새벽 비행기 도착 시 24시간 운영 강점
  • 가성비 ₩4,500 = 외국인 1순위

한 줄: "₩4,500 + 24시간 = 가성비·새벽 도착 정답"

③ 공항버스 (Limousine) — 호텔 직행 편의

대표 노선:

  • 6001번: T1·T2 → 잠실·강남
  • 6015번: T1·T2 → 명동·서울역
  • 6021번: T1·T2 → 홍대·신촌
  • 6101번: T1·T2 → 강남·압구정
  • 그 외 동대문·이태원·여의도 등 30+ 노선

가격: ₩15,000~17,000

소요: 1~1.5시간 (도로 상황)

운행: 05:00~23:00 (15분~30분 간격)

예약: 공항 1층 매표소 + 영문 앱(KOBUS, EZL)

핵심:

  • 호텔 또는 호텔 인근 정차 = 짐 끌고 환승 X
  • 짐칸 별도 = 캐리어 큰 가족 1순위
  • 영어 안내 방송
  • 호텔 동행 가족·노인 1순위

한 줄: "호텔 직행 + 짐칸 = 가족·캐리어 큰 사람 정답"

④ 카카오T 택시 — 편의 + 그룹

가격: ₩60,000~80,000 (T1·T2 → 강남·홍대·명동)

소요: 1~1.5시간

운행: 24시간

예약: 카카오T 영문 앱 (외국 휴대폰 + 외국 카드 OK)

핵심:

  • 3~4인 그룹 = 1인 ₩15,000~20,000 (공항버스와 비슷)
  • 새벽 도착 + 짐 많음 = 1순위
  • 도어투도어 = 호텔 입구까지
  • 영어 가능 기사 일부 (앱에서 영어 요청)

한 줄: "그룹·새벽·도어투도어 = 카카오T 정답"

FAQ

Q1. 영어 통하나요?

100%. 인천공항은 한국에서 외국인 응대 가장 익숙. 안내·표지·앱 모두 영문.

Q2. 새벽 비행기 도착하면?

AREX 일반열차 24시간 = ₩4,500. 또는 카카오T 택시 24시간. 새벽 환전·SIM도 가능.

Q3. K-ETA 발급 못 받으면?

한국 도착 후 재신청 가능 (1시간 내 결과). 단, 거부 시 입국 거부 가능 → 사전 신청 강력 권장.

Q4. 비자 필요한 국가?

한국 비자면제 90개국 (미국·일본·EU·호주 등 K-ETA만). 그 외 비자 필요 — 한국 영사관 사전 발급.

Q5. 면세 한도 초과하면?

세관 신고 → 관세 납부. 술 1L·담배 200개비·기념품 ₩800,000 한도.

Q6. 분실물·신고?

T1·T2 분실물센터 (1층) + 영어 응대 OK. 항공편 분실은 항공사 카운터.
