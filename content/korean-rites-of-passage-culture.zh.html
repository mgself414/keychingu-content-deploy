韩国的成人礼文化 — 为什么韩国人如此重视周岁和花甲之年

百日 (Baegil / 백일)、周岁 (Dol / 돌)、抓周 (Doljabi / 돌잡이)、花甲 (Hwangap / 환갑)、六十甲子 (Yukssipgapja / 육십갑자)、冠婚丧祭 (Gwanhonsangje / 관혼상제) — 为外国人解读韩国的成人礼。这不是“生日派对”，而是“为什么、是什么、怎么做”。

在韩国朋友的社交媒体上，经常会出现这样的场景：一个穿着韩服 (Hanbok / 한복) 的周岁宝宝面前摆放着线、钱和铅笔，全家人屏息以待，看宝宝会抓起什么。有时，朋友又会说“这个周末爷爷花甲 (Hwangap / 환갑)”，亲戚们都会聚在一起。在外国人看来，这可能只是“first birthday party”或“60th birthday party”，但韩国人对此的重视程度与西方的生日派对截然不同。在韩国，百日 (Baegil / 백일)、周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑) 不仅仅是生日，更是人生“里程碑”式的通关仪式 (rite of passage)。为什么偏偏是第100天、第一年和60岁呢？这背后有婴儿死亡率高企时期的生存渴望、东方历法中六十年一轮回的周期以及以家庭为中心的社会观念等原因。本文将从外国人的视角，解读这些仪式为何成为重要的里程碑。这是韩国文化解读系列文章的第13篇。

★ 一目了然 — 人生的四大里程碑

仪式 时间点 内容 为何是里程碑 (传统意义)
百日 (Baegil / 백일) 出生100天 感谢三神、祈求健康 在婴儿死亡率高企的年代，度过最危险关头的“生存庆祝”
周岁 (Dol / 돌) 第一个生日 (满1岁) 周岁宴 (Dolsang / 돌상)、抓周 (Doljabi / 돌잡이)、韩服 (Hanbok / 한복) 平安度过第一年 + 通过抓周 (Doljabi / 돌잡이) 预测孩子未来
花甲 (Hwangap / 환갑) 满60岁 子女为父母举办的盛大宴会 六十甲子 (Yukssipgapja / 육십갑자) 轮回一周，回到出生年份 = 长寿的象征
古稀 (Gohui / 고희)·七旬 (Chilsun / 칠순) 满70岁 取代花甲的盛大宴会 随着平均寿命延长，重心转移到70岁和80岁

核心: 韩国的通关仪式是一条从出生 (百日 (Baegil / 백일)·周岁 (Dol / 돌)) → 成人 (冠礼 (Gwallye / 관례)·婚礼 (Honrye / 혼례)) → 衰老 (花甲 (Hwangap / 환갑)·七旬 (Chilsun / 칠순)) → 死亡·追悼 (丧礼 (Sangnye / 상례)·祭礼 (Jerye / 제례)) 的连贯流程。其大框架就是下面第④点的冠婚丧祭 (Gwanhonsangje / 관혼상제)。

⚠️ 外国人常有的3个误解

1. “周岁 (Dol / 돌)·花甲 (Hwangap / 환갑) = 只是大型生日派对” ❌ — 如果说西方生日是“庆祝”，那么韩国的通关仪式则与生存、福气、孝道 (孝) 紧密相连。百日 (Baegil / 백일) 和周岁 (Dol / 돌) 是“平安度过这个危险关头”的安心仪式，而花甲 (Hwangap / 환갑) 则是子女为父母祈求长寿的孝道舞台。它不仅仅是切蛋糕的场合。

2. “抓周 (Doljabi / 돌잡이) = 迷信算命” ❌ — 抓周 (Doljabi / 돌잡이) 是一种通过孩子抓取物品来“预测”未来 (点卦) 的游戏，但大多数韩国人将其视为家庭祝福和玩乐，而非严肃的预言。他们并不会真心相信“今天我们孩子注定要成为法官”——这是一种大家一起欢笑、拍照留念的通关仪式。

3. “花甲 (Hwangap / 환갑) 是最盛大的宴会” ❌ — 以前是这样。在平均寿命较短的时代，60岁是长寿的顶点。但现在，平均寿命已超过80岁，花甲 (Hwangap / 환갑) 往往只是一顿简单的家庭生日餐，盛大宴会的重心已转移到古稀 (Gohui / 고희) (70岁)·八旬 (Palsun / 팔순) (80岁)。

① 什么是通关仪式 — 标志人生“里程碑”的仪式

通关仪式 (通過儀禮, rite of passage) 是指一个人从出生到死亡，在人生重要关口所经历的仪式。它标志着出生、成年、结婚、死亡等“阶段的转换”，由家庭和社区共同进行。

韩国的通关仪式之所以特别发达，有两大背景：

  • 家庭·社区中心性: 韩国传统上以家庭 (家) 为单位生活。因此，一个人的里程碑也成为整个家庭的盛事——这就是周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑) 亲戚们都会齐聚一堂的原因。
  • 儒教秩序: 在朝鲜时代，仪式不仅仅是风俗，更是维持社会秩序的规范，其大框架冠婚丧祭 (Gwanhonsangje / 관혼상제) 甚至被写入法典 (《经国大典 (Gyeonggukdaejeon / 경국대전)》) (→ ④)。

也就是说，百日 (Baegil / 백일)、周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑) 并非“生日庆祝”，而是在人生既定的里程碑上，家人齐聚一堂，赋予其意义的文化装置。

② 百日 (Baegil / 백일) 和 周岁 (Dol / 돌) — 出生的两个关口

百日 (Baegil / 백일) — “度过这个难关了”

这是婴儿出生第100天举行的仪式。为什么偏偏是100天呢？

传统上，在没有近代医学的时代，韩国的婴儿死亡率非常高。在寒冷的冬天、潮湿的夏天以及卫生医疗条件有限的情况下，新生儿能度过最初几个月本身就是一个巨大的难关。因此，如果能平安度过100天，人们就会认为“现在度过了一个难关”，向三神 (三神, Samshin / 삼신) (掌管生育和育儿的神灵) 表示感谢，并祈求孩子的健康。传统上会分享白色白雪糕 (Baekseolgi / 백설기) (米糕)，白色被认为是纯洁和长寿的象征。

百日 (Baegil / 백일) 是“生存的第一个里程碑”——仪式的起点源于婴儿死亡率这一残酷现实，这是其核心。

周岁 (Dol / 돌) — 第一年的里程碑

周岁 (Dol / 돌) 是婴儿的第一个生日 (满1岁)。“돌”意为“十二个月转了一圈”，而周岁宴 (Doljanchi / 돌잔치) (周岁+宴会) 则是庆祝平安度过第一年的宴会。据说这一传统从朝鲜前期就已延续至今。

  • 周岁宴 (Dolsang / 돌상): 摆在婴儿面前的桌子。传统上会摆放米、水果、面条、年糕等。面条和线象征长寿，米象征富饶。
  • 韩服 (Hanbok / 한복): 给婴儿穿上彩色韩服 (Hanbok / 한복)，家人也会盛装打扮。
  • 如果说百日 (Baegil / 백일) 是“生存”，那么周岁 (Dol / 돌) 则是“第一个里程碑 + 预测未来的场合”。预测未来就是接下来的抓周 (Doljabi / 돌잡이)。

③ 抓周 (Doljabi / 돌잡이) — 孩子抓取的物品预测未来

周岁宴 (Doljanchi / 돌잔치) 的高潮是抓周 (Doljabi / 돌잡이)。在周岁宴 (Dolsang / 돌상) 前摆放各种象征性物品，让孩子自由抓取，然后根据孩子最初抓取的物品来预测其未来的仪式。

传统上，每件物品都有其象征意义：

抓取的物品 象征的未来 (传统解读)
书·笔·墨·纸 学问·聪明 (旧时指科举及第·官职)
钱 富裕·财运
米 丰饶·食禄
弓·箭 武艺·勇猛
线·面条 长寿 (長壽) — 绵延不绝
针·尺 手巧·持家能力

现代社会职业多样化，还会增加听诊器 (医生)·麦克风 (艺人)·鼠标 (IT)·高尔夫球·法槌等物品。无论时代如何变迁，“孩子会成为什么样的人”这种家人共同想象的形式依然保留。

避免误解: 抓周 (Doljabi / 돌잡이) 并非像八字 (Saju / 사주) 那样精确的预言体系，它更像是家人齐聚一堂，互道祝福的通关仪式游戏。很少有人会把结果当作严肃的命运来相信——但它与取名 (作名) 或八字 (Saju / 사ju) 等韩国特有的“预想孩子未来”的情感是共通的 (→ [#1133_korean_saju_fortune_telling_culture](1133_korean_saju_fortune_telling_culture.md) 八字·运势)。

④ 冠婚丧祭 (Gwanhonsangje / 관혼상제) — 通关仪式的大框架

要理解百日 (Baegil / 백일)、周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑)，最好先了解其上层的传统框架——冠婚丧祭 (Gwanhonsangje / 관혼상제)。这是将一个人一生中经历的四种核心仪式捆绑在一起的说法。

  • 冠 (冠) — 冠礼 (Gwallye / 관례): 社会承认一个人已成年的成人礼。传统上，男子会束发戴冠 (冠)。今天的“成人节”就是其遗迹。
  • 婚 (婚) — 婚礼 (Honrye / 혼례): 两人结为夫妻的结婚仪式。传统上被认为是最大的喜事。
  • 丧 (喪) — 丧礼 (Sangnye / 상례): 人去世时举行的葬礼。
  • 祭 (祭) — 祭礼 (Jerye / 제례): 追悼已故祖先的祭祀。节日里的茶礼 (Charye / 차례) 就源于此 (→ [#1136_korean_holiday_culture](1136_korean_holiday_culture.md) 节日)。

在朝鲜时代，冠婚丧祭 (Gwanhonsangje / 관혼상제) 不仅仅是风俗，更是儒教社会秩序的根本，是家庭礼仪的核心规范。有趣的是，百日 (Baegil / 백일)、周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑) 并不正式属于这“四大礼仪”——但它们共享“家人共同标志人生里程碑”的通关仪式精神，共同构成了韩国人一生的礼仪体系。

⑤ 花甲 (Hwangap / 환갑) 和 六十甲子 (Yukssipgapja / 육십갑자) — 为什么偏偏是“60岁”这个里程碑

在韩国的通关仪式中，老年阶段的重要里程碑是花甲 (Hwangap / 환갑)——满60岁的生日。也称回甲 (Hoegap / 회갑)。为什么是60岁呢？答案在于东方的历法体系——六十甲子 (Yukssipgapja / 육십갑자)。

什么是六十甲子 (Yukssipgapja / 육십갑자)

东亚传统历法在给年份命名时，会把10个天干 (Cheongan / 천간) 和12个地支 (Jiji / 지지) (12生肖) 搭配使用。

  • 天干10 × 地支12 组合起来，正好有60种年份名称 (甲子年·乙丑年…)。
  • 因此，60年之后，才会再次回到自己出生的那个干支。
  • “花甲 (Hwangap / 환갑)” = 回到甲 (甲, 干支) 的意思。即人生的历法完成了一次轮回，回到了起点。

为什么会举办宴会

传统上，在平均寿命较短的时代 (停留在40-50岁)，能完整度过六十甲子 (Yukssipgapja / 육십갑자) 一周本身就是一种罕见的长寿。因此，当人们迎来花甲 (Hwangap / 환갑) 之年时，子女和亲友会齐聚一堂，举办盛大的宴会 (花甲宴 (Hwangapjanchi / 환갑잔치))，为父母祈求长寿，表达孝道 (孝)。花甲 (Hwangap / 환갑) 不仅仅是生日，更是“完成了一生”的人生总结，也是孝道的舞台。

顺便一提，其后还有古稀 (Gohui / 고희)·七旬 (Chilsun / 칠순) (70岁)、喜寿 (Huisu / 희수) (77岁)、八旬 (Palsun / 팔순) (80岁)、九旬 (Gusun / 구순) (90岁) 等老年仪式。

⑥ 为什么如此隆重 — 生存·福气·家庭

将百日 (Baegil / 백일)、周岁 (Dol / 돌) 和花甲 (Hwangap / 환갑) 在韩国成为重要仪式的理由归纳起来有三点：

1. 生存 (生存) 在当时并非理所当然 — 百日 (Baegil / 백일)·周岁 (Dol / 돌) 源于婴儿死亡率，花甲 (Hwangap / 환갑) 源于平均寿命短的现实。“平安走到这里”的安心和感谢是仪式的根源。危险越大，度过难关的里程碑就越值得隆重纪念。

2. 祈求福气 (福) 的心愿 — 通过抓周 (Doljabi / 돌잡이) 预测孩子的未来，通过花甲宴 (Hwangapjanchi / 환갑잔치) 祈求老父母余生的福气。预测未来、祈求好运的情感也与取名 (作名)·八字 (Saju / 사주) 相通 (→ [#1133_korean_saju_fortune_telling_culture](1133_korean_saju_fortune_telling_culture.md))。

3. 家庭中心性与孝道 (孝) — 韩国的仪式并非个人行为，而是整个家庭的盛事。周岁 (Dol / 돌) 是父母·祖父母为孩子举办，花甲 (Hwangap / 환갑) 是子女为父母举办。在每个里程碑全家人齐聚一堂本身就是核心。这种家庭中心性与节日亲戚团聚的文化一脉相承 (→ [#1136_korean_holiday_culture](1136_korean_holiday_culture.md))。

总结来说：韩国的通关仪式是“家人共同”纪念“度过危险关口的生存”并祈求“美好福气”的——以生存、家庭、福气为三大支柱的仪式。

⑦ 现代的变化 — 商业化与寿命延长

传统仪式在今天发生了两大方向的巨大变化。

周岁宴 (Doljanchi / 돌잔치) — 商业化·高端化

随着低生育率导致“对唯一的孩子倾尽所有”的情感 (所谓的“黄金孩子 (Gold Kids / 골드키즈)”) 蔓延，周岁宴 (Doljanchi / 돌잔치) 变得越来越华丽。

  • 场地: 从家里 → 酒店·专业周岁宴会厅·摄影棚。特级酒店的周岁宴套餐根据规模从数百万至1千万韩元 (₩) (例如，1千万韩元约合7300美元 / 52000人民币 / 110万日元) 不等，部分最高级的甚至更高，据报道提前一年预订都需抢位。
  • 周岁宴 (Dolsang / 돌상): 传统周岁宴 (Dolsang / 돌상) (米·水果·面条) → 现代周岁宴 (Dolsang / 돌상) (蛋糕·气球·手办)。还出现了包含快照拍摄·发型化妆·韩服 (Hanbok / 한복) 租赁的套餐。
  • 尽管如此，抓周 (Doljabi / 돌잡이)·韩服 (Hanbok / 한복)·周岁宴 (Dolsang / 돌상) 这些核心形式依然保留——形式现代化，但仪式的骨架得以维持。

花甲 (Hwangap / 환갑) → 重心转向七旬 (Chilsun / 칠순)·八旬 (Palsun / 팔순)

传统上，60岁是长寿的顶点，但随着平均寿命从60·70岁延长到80岁以上，“人生从60岁开始”的说法应运而生。现在，花甲 (Hwangap / 환갑) 往往只是家人之间一顿简单的生日餐，盛大宴会的重心已转移到古稀 (Gohui / 고희) (70岁)·八旬 (Palsun / 팔순) (80岁)。甚至出现了“90岁是新的60岁”的说法——同样的通关仪式也随着时代的平均寿命而改变了其位置。

⑧ 如果外国人被邀请参加周岁 (Dol / 돌)·花甲 (Hwangap / 환갑) 宴会

越来越多的外国人被韩国朋友·同事邀请参加周岁宴 (Doljanchi / 돌잔치) 或花甲 (Hwangap / 환갑)·七旬 (Chilsun / 칠순) 宴会。以下是一些需要了解的注意事项。

  • 礼物: 周岁宴 (Doljanchi / 돌잔치) 送婴儿礼物 (衣服·金戒指 (Geumbanji / 금반지) 是传统，但现金·礼金 (Chuigyeum / 축의금) 也常见)，花甲 (Hwangap / 환갑)·七旬 (Chilsun / 칠순) 宴送礼金 (Chuigyeum / 축의금) 或长辈礼物。通常装在信封里递上。
  • 观看抓周 (Doljabi / 돌잡이): 在孩子抓取物品的瞬间，一起欢呼·鼓掌即可。无论孩子抓到什么，都是一个互道祝福的场合。
  • 服装·照片: 视为正式场合，穿着得体。这是家庭活动，如果邀请你一起拍合照，请欣然接受。
  • 食物: 周岁 (Dol / 돌)·花甲 (Hwangap / 환갑) 宴上会准备年糕 (Tteok / 떡)·杂菜 (Japchae / 잡채)·排骨 (Galbi / 갈비) 等丰盛的宴会食物——尽情享用推荐的食物也是一种礼仪。

被邀请参加这样的场合，意味着这个家庭把你当作“像家人一样的人”——这是亲身体验韩国通关仪式家庭中心性的机会。

❓ 外国人常见问题 (FAQ)

  • 抓周 (Doljabi / 돌잡이) 时孩子抓到奇怪的东西怎么办？ — 不用担心。抓周 (Doljabi / 돌잡이) 并非严肃的预言，而是家人共同享受的玩乐。无论抓到什么，都会以美好的寓意来解读，大家一起欢笑。
  • 百日 (Baegil / 백일)·周岁 (Dol / 돌)·花甲 (Hwangap / 환갑) 是按农历算吗？ — 百日 (Baegil / 백일)·周岁 (Dol / 돌) 通常按公历标准计算100天·1年。花甲 (Hwangap / 환갑) 传统上与干支 (60甲子) 相关联，旧时按虚岁 (Seneun-nai / 세는나이) 计算，但现在多按满60岁生日庆祝。
  • 花甲宴 (Hwangapjanchi / 환갑잔치) 现在还办得很隆重吗？ — 比以前规模小了。随着平均寿命延长，花甲 (Hwangap / 환갑) 多为家庭生日餐，盛大宴会已转移到七旬 (Chilsun / 칠순)·八旬 (Palsun / 팔순)。但具体情况因地区·家庭而异。
  • 送金戒指 (Geumbanji / 금반ji) 作为礼物感觉有负担？ — 传统上周岁 (Dol / 돌) 会送金戒指 (Geumbanji / 금반지)，但现在现金·礼金 (Chuigyeum / 축의금) 更常见也更稳妥。不必有负担。
  • 有宗教信仰也可以参加这些仪式吗？ — 百日 (Baegil / 백일)·周岁 (Dol / 돌)·花甲 (Hwangap / 환갑) 并非宗教仪式，而是家庭文化·通关仪式。任何人都可以轻松参与。
