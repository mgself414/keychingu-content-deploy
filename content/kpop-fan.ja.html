K-POP 推し活 (オタ活) 完全ガイド — 事務所・グッズショップ・ファンカフェから音楽番組まで

ハルリュウ (韓流) ファン必訪のソウル K-POP 聖地巡礼 完全マップ

ひと目でわかる概要

項目 情報
主要エリア カンナム (강남) (HYBE·YG) · カンソ (강서) (SM·JYP) · ホンデ (홍대) (カフェ·ファンショップ)
所要時間 半日 (3時間) 〜 1日 (6時間)
出発点 カンナム駅 (강남역) または カンソ駅 (강서역)
おすすめ時期 平日午後 (空いている) · 週末 (にぎやか)
混雑度 平日は低め、週末・公演日は高め
費用目安 グッズ ₩10,000〜₩100,000+ (~900〜9,000 JPY)、ファンサイン会 無料〜₩100,000

K-POP 推し活の3つの柱

韓国での K-POP 体験は大きく3つに分かれます。

柱 内容 おすすめ度 難易度
事務所ツアー 芸能事務所の外観見学 + 写真撮影 ⭐⭐⭐⭐⭐ 低 (誰でも可)
グッズショッピング 公式グッズショップ・ファンショップ巡り ⭐⭐⭐⭐ 中 (事前情報が必要)
ファンイベント ファンサイン会・音楽番組観覧 ⭐⭐⭐⭐⭐ 高 (事前登録必須)

Part 1: 4大芸能事務所 ツアー

1. HYBE (ハイブ) — BTS·アイリット·ル・セラフィム·NEWJEANS など

所在地: ソウル カンナム区 テヘランロ 133 (カンナム駅 (강남역) 周辺)

特徴:

  • K-POP 最大手事務所 (BTS のホーム)
  • 建物外観のみ見学可 (社屋内部ツアー不可)
  • 常にファンが集まっている
  • 絶好の写真スポット

アクセス:

```

カンナム駅 (강남역) 2番出口 → 徒歩5分 → テヘランロ方向 → 高層ビルが見えたら到着

```

ファン必訪コース:

  • HYBE ビル外観で写真 (BTS ファンの聖地)
  • 近くのカフェで一息 (静かに感慨にふける)
  • 近くのコンビニ (편의점 — 日本のコンビニと同様だが24h営業でフードが充実) でファンと軽く交流

周辺スポット:

  • HYBE 近くのカフェ街 (ファンの憩いの場)
  • カンナム駅地下街 (時間つぶしに最適)

2. SM エンターテインメント (エスエム) — EXO·Red Velvet·NCT など

所在地: カンナム駅近く または アヒョン駅 (아현역) 近く (複数オフィスあり)

主要オフィス:

  • カンナム オフィス: ソウル カンナム区 ノニョンロ 38ギル (カンナム駅から徒歩10分)
  • アヒョン オフィス: ソウル カンソ区 ワールドカップロ8ギル 62-6

特徴:

  • HYBE より静か
  • 建物は目立たない (ファンが少なめ)
  • 内部ツアー不可 (外観のみ)

アクセス:

```

カンナム駅 (강남역) またはアヒョン駅 (아현역) 出発 → 住所検索 (ネイバーマップ) → 到着

```

ファン必訪コース:

  • 事務所外観で写真撮影
  • 周辺のレストラン/カフェで休憩
  • 「ここで EXO が働いている」という感慨を楽しむ

3. JYP エンターテインメント (ジェイワイピー) — TWICE·DAY6·ITZY·Stray Kids など

所在地: ソウル カンナム区 テヘランロ 1411 (カンナム駅近く)

特徴:

  • スタイリッシュな外観のオフィス
  • HYBE·YG とともにカンナムにトライアングル状に分布
  • ファンのツアーコースの定番

アクセス:

```

カンナム駅 (강남역) → 徒歩15分 (またはバス) → テヘランロ方向

```

ファン必訪コース:

  • 事務所外観で写真撮影
  • 「TWICE が練習したあの場所」と思いを馳せる
  • カンナム駅に戻り他の事務所もツアー

4. YG エンターテインメント (ワイジー) — BLACKPINK·WINNER·TREASURE·BABYMONSTER など

所在地: ソウル カンナム区 ノニョンロ 119 (カンナム駅から最も近い)

特徴:

  • 4大事務所の中で最も静かなエリア (ファンが少なめ)
  • BLACKPINK の本拠地 (最高人気 = セキュリティ厳重)
  • 周辺は飲食店街で観光地とは雰囲気が異なる

アクセス:

```

カンナム駅 (강남역) 3番出口 → ノニョンロ方向 徒歩10分 → 到着

```

ファン必訪コース:

  • 事務所外観で写真 (BLACKPINK ファン必訪)
  • 周辺のレストランでランチ
  • 速やかに次へ (観光地的雰囲気ではないため)

事務所ツアー タイムスケジュール (半日)

```

14:00 - HYBE 事務所ツアー + 写真 (30分)

14:30 - カンナム駅地下街またはカフェで休憩 (30分)

15:00 - JYP 事務所ツアー + 写真 (30分)

15:30 - バス/地下鉄で移動 (15分)

15:45 - YG 事務所ツアー + 写真 (30分)

16:15 - SM 事務所ツアー (または翌日) (30分)

```

おすすめ: すべての事務所を1日で回ると非常に慌ただしい。2日に分けるか、気になる事務所2〜3か所だけに絞るのがベスト。

Part 2: グッズショッピング — 公式ショップ & ファンショップ

公式グッズショップ

1. シンナラ レコード (SHINARA)

所在地: ミョンドン (명동) (7店舗)、カンナム、ホンデ など

  • K-POP 最大手アルバム販売店
  • 全アイドルのアルバムを取り扱い
  • 公式グッズ (ポスター・フォトカードなど) も充実
  • ファンの聖地

カンナム店住所: ソウル カンナム区 カンナムテロ 96 (カンナム駅から徒歩10分)

特徴:

  • 新作アルバム当日購入可
  • ファンが常に集まる (情報交換の場)
  • 現金・カードどちらも可

2. ホットトラックス (HOTTRACKS)

所在地: カンナム、ホンデ、ミョンドン など (カンナム店おすすめ)

  • アルバム + グッズ + 電子機器 (幅広いラインナップ)
  • シンナラよりも空いている
  • 価格比較・割引あり

カンナム店: ソウル カンナム区 テヘランロ 15 (カンナム駅地下街近く)

3. ヨングディスク (YOUNG DISC)

所在地: カンナム駅、ミョンドン など

  • 小規模だが清潔感あり
  • 新作アルバムの入荷が早い
  • スタッフが親切

ファンショップ (Fan Shops) — ファンが運営するグッズショップ

どんな場所? ファンが自ら海外からグッズを輸入して販売。各アイドルグループ別のファンショップあり。

主要ファンショップ集積エリア

ホンデ (홍대):

  • ホンデ入口駅 (홍대입구역) 6番出口周辺の ゴルモク (골목 — 路地裏のこと。日本の横丁に似た細い小道)
  • 「ホンデ ファンショップ通り」として有名
  • 歩けば BTS、BLACKPINK、STRAY KIDS、ル・セラフィムなど全グループのファンショップに出会える

カンナム (강남):

  • カンナム駅地下街
  • シンナラ近くの路地

ファンショップの特徴

特徴 説明
グッズ種類 公式グッズ + ファン制作グッズ (名刺、ファンタブなど)
価格 公式より高い場合もあり (輸入費 + マージン)
限定品 海外限定グッズのみ購入可能
カスタム制作 ファン向けカスタムグッズ制作 (発送に時間が必要)
ファン文化 ファン同士の情報交換スポット

ホンデ ファンショップ ツアー (1時間)

```

ホンデ入口駅 (홍대입구역) 6番出口 → 路地へ入る → ファンショップを散策 →

お気に入りのアイドルのファンショップへ → グッズショッピング →

近くのカフェで休憩

```

ヒント:

  • 現金を用意 (ファンショップは現金払い推奨)
  • 時間に余裕を持って (1店舗に30分〜1時間)
  • ファンと仲良くなるチャンス (推し活情報を交換しよう)

公式マーチャンダイズ オンラインショッピング

各事務所/アイドル 公式ショッピングモール:

グループ 公式グッズ購入先
BTS Weverse Shop (Weverse アプリ)
BLACKPINK The Pink Studio (公式ショッピングモール)
Stray Kids MyMusicTaste (ファン資金調達プラットフォーム)
TWICE Twice Official Store (オンライン)
NewJeans WEVERSE SHOP (HYBE 公式)

Part 3: ファンイベント — ファンサイン会・音楽番組・ファンミーティング

1. ファンサイン会 (Fan Sign)

どんなイベント? アイドルが直接サインをしてくれ、短く挨拶できるイベント。日本のアーティストの握手会に近いが、より間近で話しかけられる。

ファンサイン会情報の探し方

1. 公式チャンネル: 各事務所の公式 SNS (Twitter/Instagram)

2. ファンコミュニティ: ファン掲示板 (各グループ別)

3. チケット販売サイト: インターパーク (Interpark)、Yes24 (韓国チケット予約サイト)

ファンサイン会への参加方法

1. アルバム購入 (必須): シンナラ またはホットトラックスで購入

2. 予約サイトにアクセス: インターパークまたは予約サイトで予約

3. 参加: 指定日時・場所に行き番号を受け取る → 待機 → アイドルと対面

ファンサイン会のエチケット

ルール 説明
サイン時間 非常に短い (1人5〜10秒)。言いたいことは事前に準備
撮影 ほぼ禁止。公式撮影チームのみ撮影可
プレゼント 禁止 (セキュリティ上)。事務所によって異なる
言語 英語も可能だが、韓国語のひとことで好印象
待ち時間 6〜12時間の場合も (人気グループはさらに長い)

2. 音楽番組 (Music Shows) 観覧

どんな体験? ソウルで毎週放送される K-POP 音楽番組に、観客として参加して生で見られる。日本の音楽番組公開収録と同様のシステム。

主要音楽番組

番組 放送局 放送日 収容人数 観覧難易度
ミュージックバンク (뮤직뱅크) KBS 金曜日 17:00 (5:00 PM) 〜500名 中 (事前申請)
ミュージックショー チャンピオン (뮤직쇼 챔피언) MBC 火〜水曜日 〜500名 高 (人気曲のみ)
インギガヨ (인기가요) SBS 日曜日 15:40 (3:40 PM) 〜200名 非常に高 (最も人気)
ショー チャンピオン (쇼 챔피언) Mnet 木曜日 17:00 (5:00 PM) 〜1,000名 中

音楽番組 観覧申請方法

1. 事前申請: 放送局公式 SNS で申請 (通常1週間前)

2. 先着順: 申請締め切り後に当選者発表 (ほぼ満席)

3. 入場: 指定時間に到着 (2時間前到着を推奨)

音楽番組へのアクセス

ミュージックバンク (KBS ホンヌン センター):

```

地下鉄4号線 スユ駅 (수유역) または 1号線 チェギドン駅 (제기동역) → 徒歩15分 → KBS ホンヌン センター

```

インギガヨ (ソウル カンナム):

```

地下鉄3号線 トゴク駅 (도곡역) → 徒歩5分 → SBS タワー

```

3. ファンミーティング (Fan Meeting) & 特別イベント

どんなイベント? ファンとアイドルがインタラクションする特別イベント (ボードゲーム、Q&A、ゲームなど)。日本のファンミーティングと同じ感覚で楽しめる。

ファンミーティングの特徴

特徴 説明
人数 ほぼ少人数 (100〜500名)
時間 1時間30分〜2時間
価格 非常に高め (₩150,000〜₩300,000 / ~13,500〜27,000 JPY)
チケット 競争率が非常に高い (数秒で完売)
体験 ファンサイン会より遥かに充実 (会話できる)

Part 4: K-POP カフェ & コミュニティ

ホンデ K-POP カフェ通り

特徴: K-POP ファンが集まるカフェ群。各グループ専用カフェもあり。

おすすめカフェ

カフェ 特徴 おすすめ度

  • 同じアイドルのファンと出会う

K-POP 推し活 必需品リスト

持ち物 理由

韓国ファン vs 外国人ファンの違い

要素 韓国ファン 外国人ファン
情報へのアクセス SNS リアルタイム韓国語 英語ファンコミュニティ依存
アルバム購入 店舗に直接訪問 オンライン海外配送
ファンサイン会 韓国語で会話 英語または制限あり
ライブ参加 非常に頻繁に参加 旅行期間中のみ可能
グッズ 国内ファンショップ利用 オンラインショッピング利用

言語の壁を乗り越える方法

状況 解決策
ファンサイン会申請 インターパーク/Yes24 の韓国語 + Google 翻訳を活用
音楽番組申請 各事務所 SNS の英語/日本語バージョンを確認
ファンカフェ (팬카페) 加入 Papago/Google 翻訳でコンテンツを翻訳
カフェ/ファンショップ 指さし + Google 翻訳
ファンとの交流 英語対応のアイドルファンアカウントを見つけてフォロー

最終ヒント

1. ソウル滞在日程のうち2〜3日のうち1日は K-POP 推し活に充てよう

2. 韓国ファンと仲良くなると、より多くの情報とファン文化が体験できる

3. 事務所を外から眺めるだけでも価値あり (アイドルの「ホーム」を肌で感じる)

4. ファンミーティング/音楽番組は運次第 (チケット争奪戦なので事前に計画を)

5. ホンデ (홍대) ファンショップ通り = K-POP 推し活の最高の拠点
