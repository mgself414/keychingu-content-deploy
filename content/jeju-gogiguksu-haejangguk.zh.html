只有在济州才能吃到的四种汤——猪肉汤面·海螺刀切面·解酒汤·蕨菜牛肉汤

副标题: 说到济州美食,人们首先想到黑猪肉和生鱼片(#1060),但济州人每天吃的其实是汤和面。在猪骨汤里放入中粗面的猪肉汤面 (Gogi Guksu / 고기국수)只有济州才有;螺 (Bomal / 보말) 是济州方言里的海螺;济州的解酒汤 (Haejangguk / 해장국) 早上6点就开门。把这四样安排进一日三餐的方法——抵达当天早上喝解酒汤,中午吃猪肉汤面,转去西归浦再吃海螺刀切面

🎯 为什么是"四种汤"

济州美食攻略大多把十样东西一句话带过:黑猪肉、带鱼、海鲜锅、猪肉汤面……但偏偏没告诉你哪一餐该吃什么。这一篇反其道而行之:只留下汤和面四样,再把它们放进一天的行程里。

选这四样的理由很明确。猪肉汤面在济州以外的地方买不到。在炖煮猪肉的乳白色汤里放入粗中粗面、再铺上白切猪肉 (Dombe Gogi / 돔베고기,切片水煮肉) 的这种面,只有济州岛才有。螺 (Bomal / 보말) 在济州方言里指海螺——标准韩语菜单上没有这个词。济州的解酒汤和内陆不同,不是喝酒第二天才吃的东西,而是早餐。所以代表性的店铺清晨6点就开门。还有蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장),是把济州手摘的蕨菜与荞麦粉一起长时间熬煮,与其说是汤,不如说稠得像粥。

还有一个共同点:四样都是早上或午饭早段最强,下午很多店就关门。在济州,"晚上再去吃"这种说法对这些食物行不通。所以用餐安排是本篇的核心。

🥩 以猪肉为底 — 清真与素食旅客请先看这里

四种当中有三种以猪肉为底。 猪肉汤面 (Gogi Guksu / 고기국수) 用猪骨与猪肉熬汤，蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장) 同样用猪肉，马尾藻汤 (Mom-guk / 몸국) 则是在猪肉高汤里加入马尾藻。解酒汤 (Haejangguk / 해장국) 因店而异 — 恩熙家解酒汤 (Eunhuine Haejangguk / 은희네해장국) 属牛肉与血肠一类，而又珍解酒汤 (Ujin Haejangguk / 우진해장국) 的招牌正是含猪肉的蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장)。

若必须避开猪肉，答案是海螺刀切面 (Bomal Kalguksu / 보말칼국수)。 它以海螺配海带与鹿角菜 (tot / 톳) 熬汤，是本篇唯一以海鲜为底的菜。但同一家店多半也卖猪肉菜色，很难期待厨具分开 — 若严格遵守清真，寻找认证餐厅比本清单更稳妥。素食更难。四种菜的核心都是高汤，去掉汤，这道菜就不成立了。

不必担心一个人吃饭。面食与解酒汤 (Haejangguk / 해장국) 基本是一人一碗，独自进店很自然，表中店家翻桌也快。

🍜 猪肉汤面 (Gogi Guksu / 고기국수)——济州以外买不到

用长时间炖煮猪骨和猪肉的汤,放入粗中粗面,再铺上切片的白切猪肉 (Dombe Gogi / 돔베고기)。汤色乳白浓郁,如果你期待的是清淡的面汤,第一口会惊讶于它的厚重。价格大体在8,000~10,000韩元上下(加时阿爸面馆 (Gasi Abang Guksu / 가시아방국수) 8,000韩元,姐妹面馆 (Jamae Guksu / 자매국수) 10,000韩元)。

济州市有一条这种面店扎堆的面条街。位于一徒2洞三星路一带,表中的三代面馆会馆总店(三星路41号 / 삼성로 41)和面条广场总店(三星路65号 / 삼성로 65)就在这条街上。对旅行者来说重要的理由只有一个——一家排队太久或食材卖完了,可以步行换到隔壁一家。在济州只锁定一家店结果白跑一趟的事很常见,而面条街这种风险很低。

按路线分类如下。

  • 抵达·离开机场的那一餐 → 三无面馆 (Sammu Guksu / 삼무국수)(三无路3街46-1号 / 삼무로3길 46-1)。离机场近。
  • 济州市区吃一顿 → 面条街(三代面馆会馆·面条广场)。三代面馆会馆营业到凌晨2点,晚一点的饭点也可以。
  • 只选一碗的话 → 姐妹面馆 (Jamae Guksu / 자매국수)(项谷南路46号 / 항골남길 46)。有休息时段(14:20~16:10),午饭末尾去会碰上关门。
  • 东部(城山日出峰·涉地可支)行程 → 加时阿爸面馆 (Gasi Abang Guksu / 가시아방국수)(涉地可支路10号 / 섭지코지로 10)。四种里唯一营业到晚上的。

🐚 海螺刀切面 (Bomal Kalguksu / 보말칼국수)——螺是济州方言里的海螺

螺 (Bomal / 보말) 是济州方言里对海螺的叫法。放进去煮刀切面就是海螺刀切面,熬成粥就是海螺粥 (Bomal Juk / 보말죽)。汤偏清,海螺的甜味与海带·羊栖菜的海洋香气交织。如果说猪肉汤面偏厚重,海螺刀切面就是它的反面。

要知道的是每家的汤底不同。有的店同时用海带和淡菜,有的店放羊栖菜。所以"吃过海螺刀切面"不会一家就结束。

  • 西归浦·中文行程 → 中文水斗里海螺刀切面 (Jungmun Sudu-ri Bomal Kalguksu / 중문수두리보말칼국수)(天帝渊路192号 / 천제연로 192)。08:00~15:30,周二休息——下午去会碰上关门。安排在看天帝渊瀑布·中文一带那天的午饭最自然。
  • 济州市·东门市场行程 → 济州海螺刀切面 (Jeju Bomal Kalguksu / 제주보말칼국수)(观德路8街40号 / 관덕로8길 40)。与东门市场(#634)在同一范围内,可与逛市场串联。
  • 住新济州 → 新济州海螺刀切面总店 (Sinjeju Bomal Kalguksu / 신제주보말칼국수)(善德路5街19号 / 선덕로5길 19)。

🍲 解酒汤 (Haejangguk / 해장국)——在济州是早餐

在内陆,解酒汤是前一天喝了酒的人吃的东西。在济州不一样。一天从解酒汤开始。所以代表性的店铺清晨6点开门,下午2~3点关门。如果第一天坐早班飞机抵达济州,这个时间表反而正合适。

  • 又珍解酒汤 (Ujin Haejangguk / 우진해장국)(西沙路11号 / 서사로 11)——06:00~22:00,全年无休。四家里时间限制最少。不过这家以基本排队1~2小时闻名,踩着开门时间去更好。招牌写的是解酒汤,但真正的招牌菜是后面要说的蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장)。
  • 恩熙家解酒汤总店 (Eunhuine Haejangguk / 은희네해장국)(高麻路13街8号 / 고마로13길 8)——工作日 06:00~15:00 / 周末 06:00~14:00,周四休息。接近牛肉·牛血块类的单一菜单。周四去看到关着的门是常见失误。
  • 山地解酒汤总店 (Sanji Haejangguk / 산지해장국)(临港路34号 / 임항로 34)——在济州港一侧。济州岛内有多家分店(城山·细花·咸德·中文·西归浦·大静),按路线选合适的分店即可。

🌿 蕨菜牛肉汤与马尾藻汤——光听名字猜不出的两样

蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장) 是把济州长出的蕨菜手摘后与猪肉一起,加入荞麦粉,熬到蕨菜完全化开为止。成品与其说是汤,不如说稠得接近粥。如果期待内陆的牛肉汤 (Yukgaejang / 육개장)(牛肉·大葱·辣汤),端上来的会是完全不同的东西。

蕨菜为什么成了济州料理的食材,用节气就能解释。济州有个说法叫蕨菜雨季 (Gosari Jangma / 고사리장마)——4月中旬到5月初,持续下适合蕨菜生长的雨的时期。这时摘下晾干的蕨菜,会用到一整年的料理里。

马尾藻汤 (Mom-guk / 몸국) 是把马尾藻(济州方言叫"Mom / 몸")放进猪骨高汤里煮的汤。它是办喜事和大事时架起大锅煮的食物,与其说是游客菜单,不如说是家族仪式食物走进了餐厅。

两样都能在又珍解酒汤 (Ujin Haejangguk / 우진해장국)(西沙路11号 / 서사로 11) 一家解决——蕨菜牛肉汤·马尾藻汤·牛骨解酒汤各10,000韩元。在一家店同时点两种济州汤分着吃,效率最高。

🗓 用餐安排——一天最多三顿

济州的店铺分散在济州市和西归浦,不存在步行就能连起来的路线。所以改用餐次来安排。以下以租车为前提;没有车的话请一并参考#1212(不租车徒步)·#1402(出租车游)。

抵达日(以济州市为中心)

1. 早上 06:00~08:00 — 在又珍解酒汤 (Ujin Haejangguk / 우진해장국)(西沙路11号 / 서사로 11)吃蕨菜牛肉汤 + 马尾藻汤。踩着开门时间去,排队短。

2. 中午 — 前往面条街(三星路 / 삼성로)吃猪肉汤面。三代面馆会馆或面条广场。一家不行就换隔壁。

3. 下午 — 逛东门市场(#634)。也可以在这个时段把市场附近的济州海螺刀切面 (Jeju Bomal Kalguksu / 제주보말칼국수)(观德路8街40号 / 관덕로8길 40)排进去。

转去西归浦的日子

1. 早上 — 恩熙家解酒汤总店 (Eunhuine Haejangguk / 은희네해장국)(高麻路13街8号 / 고마로13길 8),只要不是周四。

2. 中午(以到达中文为准) — 中文水斗里海螺刀切面 (Jungmun Sudu-ri Bomal Kalguksu / 중문수두리보말칼국수)(天帝渊路192号 / 천제연로 192)。15:30关门且周二休息——这两个条件决定行程。

有东部(城山·涉地可支)行程的日子

  • 加时阿爸面馆 (Gasi Abang Guksu / 가시아방국수)(涉地可支路10号 / 섭지코지로 10)营业到20:30,即使很晚才看完城山日出峰出来也能吃上饭。只避开周三。

⚠ 常见错误3条

1. "下午去就行了" — 这一篇的食物都是早上·中午的生意。恩熙家解酒汤下午3点(周末2点)关门,中文水斗里海螺刀切面3点半关门。营业到晚上的只有又珍解酒汤 (Ujin Haejangguk / 우진해장국)(22:00)·三代面馆会馆 (Samdae Guksu Hoegwan / 삼대국수회관)(02:00)·加时阿爸面馆 (Gasi Abang Guksu / 가시아방국수)(20:30)。

2. 不看休息日就去 — 中文水斗里海螺刀切面是周二,恩熙家解酒汤总店是周四,姐妹面馆·加时阿爸面馆是周三休息。济州的餐厅很多不是周末休息,而是工作日的某一天休息。

3. 把分店当成总店 — 山地解酒汤·恩熙家解酒汤·翰林刀切面·美风解酒汤在济州岛内有多家分店,每家分店营业时间不同。搜索时不要只输入店名,要确认到分店名。

⚙ 常见问题解答(FAQ)3个

Q. 猪肉汤面在济州以外也能吃到吗?

首尔等地有一些店做济州式猪肉汤面,但作为一种食物真正扎根的只有济州。在济州吃是默认选项,济州市甚至有一条只卖这种面的街(面条街)。

Q. 辣吗?

四样默认都不辣。猪肉汤面·海螺刀切面·马尾藻汤是清汤或乳白汤,蕨菜牛肉汤虽然稠,但和靠辣椒粉撑场的内陆牛肉汤不同。即使有不能吃辣的同伴,这份清单大体上也是安全的。

Q. 在Naver地图上搜什么?

用韩文名称搜索更准确——猪肉汤面 (Gogi Guksu / 고기국수)、海螺刀切面 (Bomal Kalguksu / 보말칼국수)、解酒汤 (Haejangguk / 해장국)、蕨菜牛肉汤 (Gosari Yukgaejang / 고사리육개장)。用英文搜索结果会大幅减少。也可以把表中的道路名地址直接粘贴进去。
