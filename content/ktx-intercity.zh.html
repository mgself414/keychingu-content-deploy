🎯 为什么是 KTX·城际交通全攻略

外国游客来韩城际出行首要痛点 = 长途交通。KTX (2004) + SRT (2016) + 高速巴士 + 国内航班 + 租车 + 渡轮全套。首尔 (Seoul / 서울) → 釜山 (Busan / 부산) KTX 2小时30分钟 = 外国游客1晚2天·1周深度游的必备伴侣。

⚠ 外国游客常犯的5个错误

1. “KTX = 只有普通座”: KTX 有3种 — (1) 普通座 (Economy) (2) 特等座 (Premium) (3) 优等座 (Plus)。外国游客普通座 = 外国游客首选高性价比。特等座 = 外国游客深度游 + 贵30%以上。

2. “KTX 预订 = 当天也行”: KTX 外国游客深度游首选 = 必须提前预订 (韩国首选节假日·周末票务紧张)。韩国铁道公社 (KORAIL Talk·KORAIL English) + Klook·Trip.com 英文预订均可。

3. “高速巴士 = 只有廉价票”: 高速巴士分为优等座 + 高级座 + 普通座3种。优等座 (KTX 70%的价格) + 外国游客深度游首选。分散在东首尔巴士客运站 (Dongseoul Beoseu Teominol / 동서울)·首尔高速巴士客运站 (Seoul Goseok Beoseu Teominol / 서울고속)·首尔南部巴士客运站 (Seoul Nambu Beoseu Teominol / 서울남부) 3个客运站。

4. “国内航班 = 贵”: 韩国国内航班 (济州航空 (Jeju Air / 제주항공)·德威航空 (T'way Air / 티웨이)·易斯达航空 (Eastar Jet / 이스타)·真航空 (Jin Air / 진에어)·Aero K LCC) = 金浦 (Gimpo / 김포)→济州 (Jeju / 제주) ₩30,000~80,000 (~$22-59 / ~160-430 RMB / ~3,100-8,400 JPY) (相较于外国游客 KTX 釜山 (Busan / 부산) ₩70,000 可能更便宜)。济州 (Jeju / 제주)·丽水 (Yeosu / 여수) 首选LCC。

5. “城际渡轮 = 对外国游客不友好”: 韩国渡轮 (济州 (Jeju / 제주)·莞岛 (Wando / 완도)·红岛 (Hongdo / 홍도)·郁陵 (Ulleung / 울릉)) 对外国游客友好 OK + 仁川 (Incheon / 인천)·木浦 (Mokpo / 목po)·丽水 (Yeosu / 여수)·浦项 (Pohang / 포항)渡轮码头提供英文指引 + 韩国首选城际深度游。

⚙ 常见问题8个

1. KTX 外国游客预订: KORAIL English·KORAIL Talk + Klook·Trip.com 英文预订均可 + 节假日·周末必须提前预订。

2. KTX 外国游客通票 (Korail Pass): 外国游客专用3日·5日·7日·10日通票。外国游客 KTX 深度游首选 + 必须持有外国游客护照。

3. 高速巴士 vs KTX: KTX 速度快 (首尔 (Seoul / 서울)→釜山 (Busan / 부산) 2.5小时 ₩60,000 (~$44 / ~320 RMB / ~6,300 JPY)) / 优等高速巴士 (4.5小时 ₩35,000 (~$26 / ~190 RMB / ~3,700 JPY)) + 外国游客深度游首选。

4. 国内航班 LCC: 金浦 (Gimpo / 김포)→济州 (Jeju / 제주) ₩30,000~80,000 + 济州 (Jeju / 제주)·丽水 (Yeosu / 여수)·蔚山 (Ulsan / 울산)·釜山 (Busan / 부산) LCC 深度游 OK。

5. 租车 外国游客: 国际驾驶许可证 (IDP) + 外国游客护照 + 本国驾照原件必备。21岁以上 + 驾龄不满1年者不可租车。

6. 城际渡轮: 仁川 (Incheon / 인천)·木浦 (Mokpo / 목포)·丽水 (Yeosu / 여수)·浦项 (Pohang / 포항)渡轮码头提供英文指引 + 外国游客深度游每周 OK + 部分城际渡轮欢迎外国游客。

7. 机场豪华巴士: 仁川机场 (Incheon Gonghang / 인천공항)·首尔 (Seoul / 서울)市中心酒店 ₩18,000·1小时30分钟 + 外国游客深度游首选。

8. 外国游客城际1晚2天推荐: KTX 釜山 (Busan / 부산) ([#243~#247_series](243_busan_travel_series.md))·KTX 江陵 (Gangneung / 강릉) ([#231_ski](231_winter_ski_guide.md))·KTX 光州 (Gwangju / 광주)·丽水 (Yeosu / 여수)。
