宗庙大祭观览指南——5月春享·11月秋享一年两次,2026秋享大祭11月7日免费入场,平时宗庙英语讲解时间一并整理(2026年10月官方数据)

副标题: 宗庙祭礼每年在5月第一个周日和11月第一个周六举行(宫陵遗迹本部 (Gungneung Yujeok Bonbu / 궁능유적본부)) · 2026秋享大祭11月7日(周六)永宁殿 (Yeongnyeongjeon / 영녕전) 10:00、正殿 (Jeongjeon / 정전) 14:00,无需提前预约,免费(宗庙 (Jongmyo / 종묘) 公告) · 5月大祭通过Ticketlink (티켓링크) 提前预约(国家遗产振兴院 (Gukga Yusan Jinheungwon / 국가유산진흥원)) · 平时宗庙周二闭馆,英语讲解10:00、12:00、14:00、16:00(宫陵遗迹本部) — 截至2026-10-21

🎯 本指南的使用方法

正殿月台 (Woldae / 월대) 上,编钟 (Pyeonjong / 편종) 与编磬 (Pyeongyeong / 편경) 奏响,排成行列的舞员 (Muwon / 무원) 缓缓抬起手臂——颂扬文德的文舞 (Munmu / 문무) 宁静柔和,颂扬武功的武舞 (Mumu / 무무) 雄健有力(宫陵遗迹本部)。本指南写给想亲眼看朝鲜王室祭祀宗庙大祭 (Jongmyo Daeje / 종묘대제)的旅行者,只依据官方公告的数值,整理什么时候举行、怎么进场、平时的宗庙怎么参观。

旧版指南把宗庙大祭写成“5月第一个周日,每年1次”。宫陵遗迹本部表明宗庙祭礼 (Jongmyo Jerye / 종묘제례) 在每年5月第一个周日和11月第一个周六举行,2026年秋季祭礼(秋享大祭 (Chuhyang Daeje / 추향대제))公告为11月7日。“朝鲜王室600年(1392~)”“正殿长101m,世界最长”之类的句子也已改正——宗庙创建于1395年(太祖 (Taejo / 태조) 4年),正殿长度和世界排名在官方页面上没有。

📅 两次大祭——2026年举行情况与下次日程

  • 2026春享宗庙大祭(5月3日,周日): 顺序为10:00永宁殿祭享 → 11:00光化门 (Gwanghwamun / 광화문) 出发的御驾行列 (Eoga Haengnyeol / 어가행렬),12:00抵达宗庙 → 14:00~16:30正殿祭享 → 16:30~17:30参观神室 (Sinsil / 신실)(国家遗产振兴院活动页面)。当天下了雨,但按照雨天也不取消照常举行的原则进行了(国家遗产振兴院公告·政策记者团 (Jeongchaek Gijadan / 정책기자단) 报道 [二手资料])。参观人数等结果数值在官方页面上没能确认
  • 2026秋享大祭(11月7日,周六): 永宁殿祭享10:00~12:00,正殿祭享14:00~16:30。作为一般参观,无需提前预约,免费入场,当天没有外语讲解。咨询宗庙秋享大祭奉行委员会 (Jongmyo Chuhyang Daeje Bonghaeng Wiwonhoe / 종묘추향대제봉행위원회) 02-765-2124(宗庙公告,2026-10-21发布)
  • 2027年日程: 春享、秋享都尚未公布。按惯例是5月第一个周日、11月第一个周六,但日期和订票日程请等待国家遗产振兴院、宫陵遗迹本部的公告
  • 1969年重新开始举行,从1971年起春季祭礼日定为5月第一个周日(宫陵遗迹本部宗庙历史)

🎟 5月大祭订票与当天——2026年公告基准

  • 订票: 免费,在Ticketlink上每人最多2张。2026年于4月17日14:00开放。公告写明原则是“100%提前预约,不现场售票”(国家遗产振兴院)
  • 年龄: 7岁以上才能进入祭享空间。学龄儿童和青少年须由监护人陪同(国家遗产振兴院)
  • 验票: 宗庙外大门 (Oedaemun / 외대문) 前的订票确认处,以正殿祭享为准13:00~13:40。携带订票者本人的身份证件原件和订票号——外国人带护照。13:50前入场(国家遗产振兴院)
  • 当天宗庙免费开放(国家遗产振兴院)。没有票也能进入园区
  • 拍摄: 禁止携带闪光灯、三脚架和食物入场(国家遗产振兴院)

🏛 平时的宗庙——参观正殿·永宁殿

  • 正殿与永宁殿: 正殿19间,永宁殿16间(宫陵遗迹本部)。1995年列入世界遗产。宗庙祭礼和宗庙祭礼乐于2001年被选为“人类口头和非物质遗产代表作”,2008年列入人类非物质文化遗产代表作名录(UNESCO)
  • 地址·路线: 首尔 (Seoul / 서울) 钟路区 (Jongno-gu / 종로구) 钟路 (Jongno / 종로) 157号。从钟路3街站 (Jongno 3-ga / 종로3가) 11号、8号出口步行5分钟。没有专用停车场(宫陵遗迹本部)
  • 时间: 11~1月09:00~17:30,2~5月、9~10月09:00~18:00,6~8月09:00~18:30,入场截止于闭馆前1小时。周二闭馆(遇公休日则开放,之后的第一个工作日闭馆)(宫陵遗迹本部)
  • 参观方式: 周一、周四、周五是在规定时间入场、与讲解员一同游览约50分钟的限时参观。英语10:00、12:00、14:00、16:00,日语09:40、11:40、13:40、15:40,汉语11:00、15:00。不满10人可免预约现场购票。周六、周日、公休日、文化日 (Munhwa-ga Itneun Nal / 문화가 있는 날) 为自由参观(宫陵遗迹本部)
  • 票价: 外国人19~64岁1,000韩元。穿着上衣加裙子或裤子齐全的韩服 (Hanbok / 한복) 则免费(宫陵遗迹本部)
  • 秋季活动期间: 2026-10-29~11-15韩国大型庆典 (Korea Grand Festival / 코리아 그랜드 페스티벌) 期间,宗庙入场免费,讲解场次减少——英语10:00、14:00(宗庙公告)

🎶 宗庙祭礼乐——听什么

  • 这是兼备乐器、歌唱、舞蹈的音乐。使用编钟、编磬、柷 (Chuk / 축)、敔 (Eo / 어)、拍 (Bak / 박)、牙筝 (Ajaeng / 아쟁)、杖鼓 (Janggu / 장구)、节鼓 (Jeolgo / 절고),歌曲有保太平 (Botaepyeong / 보태평) 11曲、定大业 (Jeongdaeop / 정대업) 11曲,舞蹈分为文舞和武舞。1463年(世祖 (Sejo / 세조) 9年)开始正式使用(宫陵遗迹本部)
  • 祭享时每个环节的乐曲与舞蹈都会更换:迎神时是保太平之乐 (Botaepyeong ji Ak / 보태평지악)·保太平之舞 (Botaepyeong ji Mu / 보태평지무),献第二杯、第三杯时是定大业之乐 (Jeongdaeop ji Ak / 정대업지악)·定大业之舞 (Jeongdaeop ji Mu / 정대업지무)(国家遗产振兴院2026节目)
  • 即使不是大祭日,春季也有宗庙祭礼乐夜间演出(20:00~21:00)(国家遗产振兴院)。想多听国乐的话,见#686 传统音乐·国乐

🚶 与宗庙一起串联的地方

  • 昌庆宫 (Changgyeonggung / 창경궁) 一侧的北神门 (Bukshinmun / 북신문): 周六、周日、公休日、文化日,宗庙栗谷路 (Yulgok-ro / 율곡로) 一侧的北神门会开放(宫陵遗迹本部)
  • 昌德宫 (Changdeokgung / 창덕궁): 首尔钟路区栗谷路99号,周一闭馆,从安国站 (Anguk / 안국) 3号出口步行5分钟。后苑须在6天前10点起线上先到先得预订(宫陵遗迹本部)。适合安排在宗庙休息的周二
  • 社稷坛 (Sajikdan / 사직단): 与宗庙成对的国家祭坛。全天开放,免费(宫陵遗迹本部)
  • 一天串起宫殿的顺序见#1255 首尔五大宫完全攻略,韩国世界遗产完整路线见一天一处串联韩国17处世界遗产的方法——首尔·近郊·庆州·安东·百济·济州,闭馆日与预订

🥗 饮食

  • 祭祀食品不是给游客的: 宗庙祭礼的祭品有牛、羊、猪肉,稻米、高粱、糯黍,年糕,腌制品,水果(宫陵遗迹本部)。活动现场不能带入食物(国家遗产振兴院)
  • 素食: 周边的韩餐馆,从泡菜调味料开始就常含有腌虾酱、鱼露或肉类高汤(VisitKorea)
  • 清真: VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的伊德 (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌萨丹路10街 (Usadan-ro 10-gil / 우사단로10길) 15号,每天12:00~21:00)是少数被韩国伊斯兰教中央会 (Hanguk Iseullamgyo Jungangheo / 한국이슬람교중앙회,KMF) 认定为清真的餐厅。认证可能变动,到访前请先确认
  • 出示卡片见#1300 饮食需求手册,钟路美食见#141 钟路·广藏市场 (Gwangjang Market / 광장시장) 指南

🧰 宗庙大祭实用信息——一个人、预订、支付、交通

  • 一个人: 可以一个人订票(每人最多2张)。平时的限时参观,一个人现场购票也能进入(宫陵遗迹本部)
  • 预订: 5月大祭不要错过4月中旬Ticketlink的订票。咨询宫陵活用节目电话咨询室 (Gungneung Hwaryong Program Jeonhwa Sangdamsil / 궁능 활용프로그램 전화상담실) 1522-2295,票务1588-7890(国家遗产振兴院)
  • 轮椅: 活动前2天之前拨打1522-2295告知的话,会引导走单独路线(国家遗产振兴院)
  • 支付: 平时门票1,000韩元——银行卡与移动支付见#527 韩国支付系统
  • 交通: 钟路3街站是1号线、3号线、5号线——#1298 三种交通卡怎么选,语言不通时看#1339 点餐礼仪

⚠ 常犯的4个错误

1. “宗庙大祭一年一次,只在5月” — 11月第一个周六也会举行(宫陵遗迹本部)。2026年是11月7日

2. “5月大祭在现场买票” — 2026年的公告是100%提前预约、不现场售票。不过那天宗庙入场免费(国家遗产振兴院)

3. “英语讲解必须提前预约” — 不满10人的话,不用预约,按时间到场即可(宫陵遗迹本部)

4. “周二去宗庙” — 宗庙周二休息。这天去昌德宫(宫陵遗迹本部)
