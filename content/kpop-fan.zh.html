Part 1：四大经纪公司大楼巡游

1. HYBE (하이브 / Hybe) — BTS·ILLIT·LE SSERAFIM·NEWJEANS 等

地址： 首尔 江南区 (Gangnam-gu / 강남구) 德黑兰路 133 (Teheran-ro / 테헤란로) (江南站附近)

特点：

  • K-POP 最大经纪公司 (BTS 的家)
  • 仅可参观大楼外观 (内部不开放参观)
  • 周边随时聚集着大批粉丝
  • 热门拍照打卡地

前往方式：

```

江南站 (Gangnam-yeok / 강남역) 2号出口 → 步行5分钟 → 沿德黑兰路方向 → 看到高层建筑 → 到达

```

粉丝必游路线：

  • HYBE 大楼外观拍照 (BTS 粉丝圣地)
  • 在附近咖啡厅短暂歇息
  • 附近便利店 (便利店 / 편의점，在韩国24小时营业，种类齐全，类似国内的全家/罗森) 与粉丝短暂交流

周边可看：

  • HYBE 附近咖啡一条街 (粉丝的休息场所)
  • 江南站地下商街 (消磨时间的好去处)

2. SM 娱乐 (SM Entertainment / 에스엠) — EXO·Red Velvet·NCT 等

地址： 江南站附近 或 阿岘站 (Ahyeon-yeok / 아현역) 附近 (多处办公室)

主要办公室：

  • 江南办公室：首尔 江南区 (Gangnam-gu / 강남구) 论峴路38街 (Nonhyeon-ro 38-gil / 논현로38길) (江南站步行10分钟)
  • 阿岘办公室：首尔 江西区 (Gangseo-gu / 강서구) 世界杯路8街 62-6 (Worldcup-ro 8-gil / 월드컵로8길)

特点：

  • 比 HYBE 安静
  • 大楼不显眼 (粉丝较少)
  • 不开放内部参观 (仅外观)

前往方式：

```

从江南站 (Gangnam-yeok / 강남역) 或阿岘站 (Ahyeon-yeok / 아현역) 出发 → 搜索地址 (使用 Naver Map) → 到达

```

粉丝必游路线：

  • 大楼外观拍照
  • 在附近餐厅/咖啡厅休息
  • 感受"EXO 就在这里工作"的心跳时刻

3. JYP 娱乐 (JYP Entertainment / 제이와이피) — TWICE·DAY6·ITZY·Stray Kids 等

地址： 首尔 江南区 (Gangnam-gu / 강남구) 德黑兰路 1411 (Teheran-ro / 테헤란로) (江南站附近)

特点：

  • 高档写字楼 (外观时尚)
  • 与 HYBE·YG 在江南形成三角分布
  • 粉丝巡游路线之一

前往方式：

```

江南站 (Gangnam-yeok / 강남역) → 步行15分钟 (或乘公交) → 沿德黑兰路 (Teheran-ro / 테헤란로) 方向

```

粉丝必游路线：

  • 大楼外观拍照
  • 遐想"TWICE 曾在这里练习"
  • 返回江南站继续其他大楼巡游

4. YG 娱乐 (YG Entertainment / 와이지) — BLACKPINK·WINNER·TREASURE·BABYMONSTER 等

地址： 首尔 江南区 (Gangnam-gu / 강남구) 论峴路 119 (Nonhyeon-ro / 논현로) (距江南站最近)

特点：

  • 四大经纪公司中位置相对偏僻 (粉丝较少)
  • 但这是 BLACKPINK 的大楼 (超高人气 = 保安严格)
  • 周边娱乐场所较多，氛围有所不同

前往方式：

```

江南站 (Gangnam-yeok / 강남역) 3号出口 → 沿论峴路 (Nonhyeon-ro / 논현로) 步行10分钟 → 到达

```

粉丝必游路线：

  • 大楼外观拍照 (BLACKPINK 粉丝必到)
  • 附近餐厅用午餐
  • 游览完毕后尽快离开 (周边环境非观光区)

大楼巡游时间表 (半天)

```

14:00 - HYBE 大楼巡游 + 拍照 (30分钟)

14:30 - 江南站地下商街或咖啡厅休息 (30分钟)

15:00 - JYP 大楼巡游 + 拍照 (30分钟)

15:30 - 乘公交/地铁移动 (15分钟)

15:45 - YG 大楼巡游 + 拍照 (30分钟)

16:15 - SM 大楼巡游 (或次日安排) (30分钟)

```

建议： 若想在一天内游览所有大楼，时间会非常紧张。建议分两天进行，或只选择 2~3 家感兴趣的公司参观。

Part 2：周边购物 — 官方及粉丝店

官方周边店

1. 新罗唱片 (SHINARA / 신나라 레코드)

地址： 明洞 (Myeongdong / 명동)(7处分店)、江南 (Gangnam / 강남)、弘大 (Hongdae / 홍대) 等

  • K-POP 最顶尖的唱片销售店
  • 备齐所有偶像专辑
  • 也有官方周边 (海报、照片卡等)
  • 粉丝圣地

江南店地址： 首尔 江南区 (Gangnam-gu / 강남구) 江南大路 96 (Gangnam-daero / 강남대로) (江南站步行10分钟)

特点：

  • 新专辑当日即可购买
  • 粉丝常聚于此 (信息交流场所)
  • 现金/刷卡均可

2. HOTTRACKS (핫트랙스)

地址： 江南 (Gangnam / 강남)、弘大 (Hongdae / 홍대)、明洞 (Myeongdong / 명동) 等 (推荐江南店)

  • 专辑 + 周边 + 电子产品 (品类丰富)
  • 比新罗唱片人少
  • 可比价，有折扣活动

江南店： 首尔 江南区 (Gangnam-gu / 강남구) 德黑兰路 15 (Teheran-ro / 테헤란로) (江南站地下商街附近)

3. 青年碟行 (YOUNG DISC / 영디스크)

地址： 江南站 (Gangnam-yeok / 강남역)、明洞 (Myeongdong / 명동) 等

  • 规模较小但整洁
  • 新专辑上架速度快
  • 店员服务热情

粉丝店 (Fan Shops) — 粉丝自营周边店

是什么？ 粉丝自行从海外进口周边并销售，针对各偶像团体分别设有专属粉丝店。

主要粉丝店集中区域

弘大 (Hongdae / 홍대)：

  • 弘大入口站 (Hongdae-ipgu-yeok / 홍대입구역) 6号出口附近的小巷 (골목，即小巷子，类似国内的弄堂或胡同)
  • 以"弘大粉丝店街"著称
  • 沿街步行即可遇到 BTS、BLACKPINK、STRAY KIDS、LE SSERAFIM 等各团粉丝店

江南 (Gangnam / 강남)：

  • 江南站地下商街
  • 新罗唱片附近小巷

粉丝店特点

特点 说明
周边种类 官方周边 + 粉丝定制周边 (名片、应援牌等)
价格 部分比官方贵 (含进口费及利润)
限定款 可购买海外限定周边
定制品 粉丝自定义周边制作 (需要一定等待时间)
粉丝文化 粉丝之间交流信息的场所

弘大粉丝店巡游 (1小时)

```

弘大入口站 (Hongdae-ipgu-yeok / 홍대입구역) 6号出口 → 进入小巷 → 漫步各粉丝店 →

分别前往喜欢的偶像粉丝店 → 购买周边 →

在附近咖啡厅休息

```

小贴士：

  • 准备好现金 (粉丝店偏好现金，建议准备 ₩50,000+ / ~350 RMB+)
  • 预留充足时间 (一家店可能逛30分钟~1小时)
  • 与粉丝交流的好机会 (交换追星信息)

官方周边线上购物

各经纪公司/偶像官方商城：

团体 官方周边购买渠道

Part 3：粉丝活动 — 签售会·音乐节目·粉丝见面会

1. 粉丝签售会 (Fan Sign / 팬사인회)

是什么？ 偶像亲自签名并与粉丝短暂互动的活动

查找签售会信息的方法

1. 官方渠道： 各经纪公司官方 SNS (Twitter/Instagram)

2. 粉丝社区： 粉丝论坛 (各团专属)

3. 票务平台： 英特帕克 (Interpark / 인터파크)、Yes24 (韩国票务网站)

参加签售会的流程

1. 购买专辑 (必须)：在新罗唱片 (SHINARA / 신나라 레코드) 或 HOTTRACKS (핫트랙스) 购买

2. 进入预约网站：在英特帕克 (Interpark / 인터파크) 或相关票务平台预约

3. 参与活动：在指定时间·地点到场取号 → 等待 → 与偶像会面

签售会礼仪

规则 说明
签名时间 极短 (每人约5~10秒)，请提前想好想说的话
拍摄 大部分禁止，仅官方摄影团队可拍摄
礼物 禁止 (出于安保考虑，各公司规定有所不同)
语言 英语可沟通，但说一句韩语会留下好印象
等待时间 可能长达6~12小时 (热门团体可能更长)

2. 音乐节目 (Music Shows / 음악방송) 观看

是什么？ 首尔每周播出的 K-POP 音乐节目，可以作为现场观众亲身参与

主要音乐节目

节目 电视台 播出时间 容纳人数 入场难度
音乐银行 (Music Bank / 뮤직뱅크) KBS 周五 17:00 ~500人 中等 (需提前申请)
音乐节目冠军 (Show! Music Core / 뮤직쇼 챔피언) MBC 周二~周三 ~500人 较高 (仅热门曲目)
人气歌谣 (Inkigayo / 인기가요) SBS 周日 15:40 ~200人 非常高 (最受欢迎)
秀冠军 (Show Champion / 쇼 챔피언) Mnet 周四 17:00 ~1,000人 中等

申请观看音乐节目

1. 提前申请：在电视台官方 SNS 上申请 (通常提前1周)

2. 先到先得：申请截止后公布中签者 (大部分名额极快抢完)

3. 入场：在指定时间到达 (建议提前2小时到场)

前往音乐节目场地的方式

音乐银行 (Music Bank / 뮤직뱅크，KBS 洪陵中心 / KBS Hongneung Center / KBS 홍릉 센터)：

```

地铁4号线 水踰站 (Suyu-yeok / 수유역) 或 1号线 祭基洞站 (Jegiдong-yeok / 제기동역) → 步行15分钟 → KBS 洪陵中心 (KBS Hongneung Center / KBS 홍릉 센터)

```

人气歌谣 (Inkigayo / 인기가요，首尔江南)：

```

地铁3号线 道谷站 (Dogok-yeok / 도곡역) → 步行5分钟 → SBS 塔楼 (SBS Tower / SBS 타워)

```

3. 粉丝见面会 (Fan Meeting / 팬미팅) 及特别活动

是什么？ 粉丝与偶像进行互动的特别活动 (桌游、Q&A、游戏等)

粉丝见面会特点

特点 说明
人数 大多为小规模 (100~500人)
时长 1.5~2小时
价格 费用较高 (₩150,000~₩300,000 / ~1,050~2,100 RMB)
预约 竞争极为激烈 (数秒内售罄)
体验 比签售会更有意义 (可以交谈互动)

Part 5：实战完整指南 — 1日 K-POP 追星行程

半天路线 (3小时)

```

14:00 - 抵达江南站 (Gangnam-yeok / 강남역)

14:15 - HYBE 大楼巡游 (30分钟)

14:45 - 新罗唱片江南店 (SHINARA Gangnam / 신나라 레코드 강남점) (45分钟，购买专辑·周边)

15:30 - 江南站咖啡厅休息 (30分钟)

16:00 - 乘地铁前往弘大 (Hongdae / 홍대) (30分钟)

16:30 - 弘大粉丝店巡游 (1小时)

17:30 - 返回驻地

```

全天路线 (6小时)

```

10:00 - 抵达江南站 (Gangnam-yeok / 강남역)

10:15 - HYBE 大楼巡游 (30分钟)

10:45 - 新罗唱片江南店 (SHINARA Gangnam / 신나라 레코드 강남점) (45分钟)

11:30 - 咖啡厅休息 (30分钟)

12:00 - 午餐 (江南餐厅，1小时)

13:00 - JYP·YG 大楼巡游 (1小时)

14:00 - 乘地铁前往弘大 (Hongdae / 홍대) (30分钟)

14:30 - 弘大粉丝店街巡游 (1.5小时)

16:00 - 弘大 K-POP 咖啡厅 (1小时)

17:00 - 晚餐 (弘大，1小时)

18:00 - 购物或夜间活动

```

K-POP 追星必备物品

物品 原因
现金 粉丝店·咖啡厅偏好现金 (建议备 ₩50,000+ / ~350 RMB+)
银行卡 购买专辑及大额消费时使用
智能手机 地图·预约·粉丝资讯
背包 装周边·专辑用
护照 非必须 (身份证亦可)
舒适的鞋子 可能需要长时间站立
记事本 与粉丝交换信息时使用

韩国粉丝 vs 外国粉丝的差异

要素 韩国粉丝 外国粉丝
信息获取 韩语 SNS 实时获取 依赖英语粉丝社区
购买专辑 直接到实体店购买 线上海外代购
签售会 用韩语交流 英语或受语言限制
线下演出 非常频繁参与 仅旅行期间可参与
周边购买 偏好国内粉丝店 偏好线上购物

语言障碍的克服方法

场景 解决方案
申请签售会 将英特帕克 (Interpark / 인터파크)/Yes24 韩文页面配合谷歌翻译使用
申请音乐节目 查看经纪公司 SNS 的英语/日语版公告
加入粉丝咖啡厅 (Fan Cafe / 팬카페) 使用 Papago 或谷歌翻译内容
咖啡厅/粉丝店 手指指认 + 谷歌翻译
与粉丝沟通 找到英语偶像粉丝账号并关注

最终贴士

1. 首尔行程中预留2~3天，其中1天专门用于 K-POP 追星

2. 与韩国粉丝交朋友，可获取更多信息并体验粉丝文化

3. 仅参观公司大楼也很有意义 (感受偶像生活的地方)

4. 粉丝见面会/音乐节目靠运气 (抢票大战，需提前规划)

5. 弘大粉丝店街 (Hongdae / 홍대) = K-POP 追星最佳据点
