⚠ 외국인 자주 실수 5가지

1. "노포 = 비쌈": 이문설농탕 8K·우래옥 17K·하동관 17K = 외국인 가성비 + 100년 노포 정통 + 외국인 매니아 1번지·#380 시장 통합.

2. "이문설농탕 = 일반 식당": 이문설농탕 = 1902 한국 #1 노포 + 종로 견지동 (1·3·5호선 종각·종로3가) + 외국인 정통 vlog 1번지 + 4대째 (백씨 가문).

3. "우래옥 = 평양냉면 같은 곳": 우래옥 = 1946 평양냉면 한국 #1 + 을지로 4가 (#11) + 17K + 외국인 정통 매니아 + 평양식 vs 함흥식.

4. "태극당 = 빵집": 태극당 = 1946 한국 #1 베이커리 노포 (#361) + 장충 본점 1946 + 외국인 vlog 1번지 + 카스테라·옥수수빵·외국인 매니아.

5. "광장시장·남대문 = 시장만": 광장 1905·남대문 1414 = 한국 #1 노포 + 시장 통합 (#380) + 외국인 vlog 1번지 + 외국인 정통 매니아.
