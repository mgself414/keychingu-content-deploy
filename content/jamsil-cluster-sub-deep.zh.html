蚕室指南 — 乐天世界探险乐园·乐天世界塔首尔天空·乐天世界水族馆，石村湖·松理团路，奥林匹克公园·SOMA美术馆·汉城百济博物馆

副标题:乐天世界探险乐园(全年无休) · 首尔天空(118层，周日~周四 10:30~22:00) · 乐天世界水族馆(成人35,000韩元) · 石村湖(全天开放) · 松理团路 · 奥林匹克公园(05:00~22:00) · SOMA美术馆(成人5,000韩元) · 汉城百济博物馆(免费入场) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了在首尔松坡区 (Songpa-gu / 송파구) 蚕室及其周边可以顺路去的地方。共有乐天世界一带3处，石村湖一带2处，奥林匹克公园一带3处。登记了费用的是乐天世界水族馆 (Lotte World Akuarium / 롯데월드 아쿠아리움) 和SOMA美术馆 (Soma Misulgwan / 소마미술관)，汉城百济博物馆 (Hanseong Baekje Bangmulgwan / 한성백제박물관) 登记为免费。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 乐天世界 — 探险乐园·首尔天空·水族馆

乐天世界探险乐园 (Lotte World Eodeubencheo / 롯데월드 어드벤처)位于松坡区 (Ollimpik-ro 240 / 올림픽로 240)，☎ 1661-2000，是乐天集团 (Lotte Geurup / 롯데그룹) 运营的城市型综合休闲空间。由室内主题公园探险乐园和石村湖上的户外主题公园魔幻岛 (Maejik Aillaendeu / 매직아일랜드) 组成，购物中心·民俗博物馆 (Minsok Bangmulgwan / 민속박물관)·溜冰场·酒店·百货商店也在一起。有游乐设施、巡游、激光秀和演出，主舞台花园舞台 (Gadeun Seuteiji / 가든스테이지) 按季节上演音乐剧表演。民俗博物馆设有历史展示馆 (Yeoksa Jeonsigwan / 역사전시관)、模型村 (Mohyeongchon / 모형촌)、集市街 (Jeojatgeori / 저잣거리)。

  • 开放时间:周一~周四·周日 10:00~21:00(停止入场 20:00)，周五~周六 10:00~22:00(停止入场 21:00)。
  • 休息日:全年无休。视天气情况，魔幻岛部分游乐设施可能停运，也可能因现场情况停运或检修。
  • 停车:可以(约5,400辆)。

乐天世界塔首尔天空 (Lotte World Tawo Seoul Seukai / 롯데월드타워 서울스카이)位于松坡区 (Ollimpik-ro 300 / 올림픽로 300)，☎ 1661-2000，是在乐天世界塔最高处的观景台。据观光公社介绍，这是韩国国内最高的观景台，可360度俯瞰首尔。有500m高空的体验设施，还有展览、咖啡和纪念品。乘坐天空穿梭梯 (Seukai Syeoteul / 스카이셔틀)，从地下1层到118层只需1分钟。据观光公社介绍，天空穿梭梯在世界上首次在天花板和三面墙壁上装了显示屏。在媒体桌可以看到以3D再现的朝鲜时代首尔。

  • 开放时间:周日~周四 10:30~22:00(停止入场 21:00)，周五~周六 10:30~23:00(停止入场 22:00)。休息日:全年无休。
  • 停车:可以。

乐天世界水族馆 (Lotte World Akuarium / 롯데월드 아쿠아리움)(同一地址，☎ 1661-2000)是在13个主题区观看海洋生物的水族馆。沿着从江河到沿岸、再到大海的生态系统走下去。据观光公社介绍，25米规模的水槽为韩国国内最大，14种体验教育项目为韩国国内最多。

  • 开放时间:10:00~20:00(停止入场 19:00)。休息日:全年无休。
  • 费用:成人·青少年35,000韩元，儿童·老年人31,000韩元。
  • 停车:持水族馆门票每10分钟200韩元(最多4小时)，之后每10分钟200韩元。

📍 石村湖一带 — 石村湖·松理团路

石村湖 (Seokchon Hosu / 석촌호수)位于松坡区蚕室洞 (Jamsil-dong / 잠실동)，☎ 松坡区厅公园绿地科 (Songpa-gucheong Gongwon Nokjigwa / 송파구청 공원녹지과) 02-2147-3380，是1969年填埋汉江支流时留下一部分作为湖，到1980年代初建成的公园。隔着松坡大道 (Songpa-daero / 송파대로) 分为东湖和西湖，设有慢跑路线和散步道。西湖有首尔游戏场 (Seoul Nori Madang / 서울놀이마당) 和乐天世界魔幻岛 (Maejik Aillaendeu / 매직아일랜드)。春天樱花盛开时，日夜都有很多人。距地铁9号线石村古坟站 (Seokchon Gobun-yeok / 석촌고분역) 2号出口560m。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

松理团路 (Songridan-gil / 송리단길)位于松坡区 (Baekjegobun-ro 43-gil 23 / 백제고분로43길 23)，☎ 松坡观光信息中心 (Songpa Gwangwang Jeongbo Senteo / 송파관광정보센터) 02-2147-2109，是从石村湖东湖通往松坡渡口站 (Songpa Naru-yeok / 송파나루역) 的街道。韩餐·日餐·中餐·西餐餐厅、甜品咖啡馆、杂货店、书店遍布每条小巷。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 奥林匹克公园一带 — 奥林匹克公园·SOMA美术馆·汉城百济博物馆

奥林匹克公园 (Ollimpik Gongwon / 올림픽공원)位于松坡区 (Ollimpik-ro 424 / 올림픽로 424)，☎ 02-410-1114，是为86年亚运会和88年首尔奥运会于1986年建成的公园，由国民体育振兴公团 (Gungmin Cheyuk Jinheung Gongdan / 국민체육진흥공단) 运营。以中央复原的百济遗址梦村土城 (Mongchon Toseong / 몽촌토성) 为中心，6个体育场呈半圆形排列。43万坪的面积内有草坪、梦村护城河 (Mongchon Haeja / 몽촌해자)、和平广场 (Pyeonghwaui Gwangjang / 평화의 광장)、奥运纪念雕塑和户外雕刻，还有KSPO DOME、Ticketlink Live Arena、奥林匹克厅 (Ollimpik Hol / 올림픽홀)、Woori Financial艺术厅 (Uri Geumyung Ateuhol / 우리금융아트홀)、Muse Live演出厅 (Myujeu Raibeu / 뮤즈라이브) 等演出场馆。

  • 开放时间:步行·自行车 05:00~22:00(广场区域 24:00)，车辆 06:00~22:00。深夜活动时会调整出入口开放。
  • 休息日:全年无休。停车:可以。

SOMA美术馆 (Soma Misulgwan / 소마미술관)(同一地址，☎ 02-425-1077)是奥林匹克公园雕塑公园内的美术馆。从美术馆可通往雕塑公园的黄土路 (Hwangtogil / 황톳길)，设有配备室内展览空间的1馆和与地铁9号线相连的2馆。

  • 开放时间:10:00~18:00(停止入场 17:30)。休息日:每周一，1月1日，春节 (Seol / 설)·中秋节 (Chuseok / 추석) 当天。
  • 费用:个人成人(满25~64岁)5,000韩元，青少年(满13~24岁)4,000韩元，儿童(满7~12岁)3,000韩元。20人以上团体成人2,500韩元，青少年2,000韩元，儿童1,500韩元。团体的基准人数可能因展览而异。1馆·2馆各自适用，特别展另行定价。
  • 停车:每10分钟600韩元。付费参观5,000韩元以上时免费1小时(须在服务台登记入场车辆)。

汉城百济博物馆 (Hanseong Baekje Bangmulgwan / 한성백제박물관)位于松坡区 (Wiryeseong-daero 71 / 위례성대로 71)，☎ 02-2152-5800，是保护·管理百济王都遗址并进行调查·研究·展示的博物馆。大厅里有把风纳土城 (Pungnap Toseong / 풍납토성) 城墙剖面薄薄切下的象征性展品。第1展室介绍汉江流域的旧石器·新石器·青铜器·初期铁器文化，第2展室介绍百济在今天的首尔建国并成长的汉城都邑期493年，第3展室介绍围绕汉江的百济·高句丽·新罗的角逐以及汉城陷落之后的百济。

  • 开放时间:夏季(3~10月)平日·周末 09:00~19:00，冬季(11~2月)平日 09:00~19:00·周末 09:00~18:00。周五 09:00~21:00。
  • 休息日:每周一(周一为公休日则开馆)，1月1日，市长指定的休馆日。
  • 费用:免费。特别企划展可能收费。

⚠ 行前须知 3 点

  1. SOMA美术馆·汉城百济博物馆周一休息 — SOMA美术馆每周一·1月1日·春节 (Seol / 설)·中秋节 (Chuseok / 추석) 当天休息，汉城百济博物馆每周一(周一为公休日则开馆)·1月1日休息。其余地方全年无休。
  2. 周五·周六有些地方开到很晚 — 乐天世界探险乐园周五~周六到22:00，首尔天空周五~周六到23:00，汉城百济博物馆周五到21:00。
  3. 乐天世界魔幻岛看天气 — 因为是户外主题公园，视天气情况部分游乐设施可能停运。

⚙ FAQ 2

Q. 哪里可以免费参观?

A. 按观光公社登记信息，汉城百济博物馆 (Hanseong Baekje Bangmulgwan / 한성백제박물관) 免费(特别企划展可能收费)。石村湖 (Seokchon Hosu / 석촌호수)、松理团路 (Songridan-gil / 송리단길)、奥林匹克公园 (Ollimpik Gongwon / 올림픽공원) 全天开放。

Q. 哪里开到很晚?

A. 首尔天空周五~周六到23:00(停止入场 22:00)，乐天世界探险乐园周五~周六到22:00(停止入场 21:00)，奥林匹克公园步行出入到22:00(广场区域 24:00)。
