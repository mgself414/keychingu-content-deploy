ソウル南山ガイド — 南山公園・南山ソウルタワー・八角亭、南山ドゥルレギル・南山国恥の道、南山野外植物園、南山谷韓屋村、南山烽燧儀式

サブタイトル: 南山公園(常時開放) · 南山ソウルタワー(平日10:00~22:30、週末10:00~23:00) · 南山八角亭(常時開放) · 南山ドゥルレギル(7.3km、約2時間30分) · 南山国恥の道(約1.7km) · 南山野外植物園(常時開放) · 南山谷韓屋村(11~3月09:00~20:00、月曜休館) · 南山烽燧儀式(11:00~15:40、無料) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルの真ん中にある南山で行ける場所をまとめたものです。南山公園と頂上の南山ソウルタワー・八角亭、歩く道二つ、野外植物園、北側のふもとにある南山谷韓屋村、南山の烽燧台の行事です。南山谷韓屋村は月曜日が休みで、公園・タワー・道・植物園は年中無休で登録されています。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 南山公園・南山ソウルタワー・南山八角亭

南山公園、中区 Samil-daero 231 (삼일대로 231)、☎ 02-3783-5900 の正式名称は南山都市自然公園 (Namsan Dosi Jayeon Gongwon / 남산도시자연공원)です。もとの名前はインギョン山 (Ingyeongsan / 인경산)で、朝鮮の太祖が都を開城からソウルへ移したあと、南にある山なので南山と呼ばれました。1991年から8年間、「南山の元の姿を取り戻す事業」(Namsan Jemoseup Gakkugi / 남산제모습 가꾸기)で、公園内の施設89棟を移し、野外植物園をつくりました。2005年5月1日から、公園には一般の乗用車とタクシーが入れません。南山ソウルタワーまでは、明洞 (Myeongdong / 명동)、忠武路 (Chungmuro / 충무로)、東大入口駅 (Dongdaeipgu-yeok / 동대입구역)から循環バスや南山ケーブルカー (Namsan Keibeulka / 남산케이블카)に乗るか、歩いて登ります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

南山ソウルタワー、龍山区 Namsan Gongwon-gil 105 (남산공원길 105)、☎ 02-756-2486 は、放送電波の送受信と観光展望の機能を兼ねた塔です。観光公社の紹介によると、韓国国内初の総合電波塔です。バラエティやドラマの撮影地としても知られています。塔の展望台へ上がる道に「愛の南京錠」がかかっています。

  • 開く時間: 平日10:00~22:30、週末10:00~23:00。休み: 年中無休。
  • 駐車: 可能。

南山八角亭、中区 Yejang-dong 8-1 (예장동 8-1)、☎ 南山公園 02-3783-5900 は、南山の頂上にあるあずまやで、ソウル市内と夜景が見下ろせます。歩いて登るか、南山循環バスや南山ケーブルカーで上がれます。

  • 開く時間: 常時開放。休み: 年中無休。

📍 歩く道 — 南山ドゥルレギル・南山国恥の道

南山ドゥルレギル、中区 Namsan Gongwon-gil 609 (남산공원길 609)、☎ 南山公園 02-3783-5900 は、ソウルタワーを起点に南山を一周する道で、全長7.3km、2時間30分ほどかかります。北側循環路 (Bukcheuk Sunhwanno / 북측순환로)、歴史文化の道 (Yeoksa Munhwagil / 역사문화길)、自然生態の道 (Jayeon Saengtaegil / 자연생태길)、野生花園の道 (Yasaenghwawongil / 야생화원길)、山林の森の道 (Sallim Supgil / 산림숲길)へとつながります。

  • 北側循環路: 南山ケーブルカー入口から国立劇場 (Gungnip Geukjang / 국립극장)まで3.4km。自動車と自転車は通れず、道の真ん中に点字ブロックがあります。車いすやベビーカーの利用者、視覚障害のある人が歩きやすいバリアフリーの散歩道に選ばれました。
  • 道から見える所: 安重根義士記念館 (An Junggeun Uisa Ginyeomgwan / 안중근 의사 기념관)、蚕頭峰フォトアイランド (Jamdubong Poto Aillaendeu / 잠두봉 포토아일랜드)、愛の南京錠、南山ソウルタワー。
  • 開く時間: 常時開放。休み: 年中無休。

南山国恥の道、中区 チュジャ洞 (Juja-dong / 주자동)、☎ 明洞観光案内所 (Myeongdong Gwangwang Annaeso / 명동관광안내소) 02-774-3238 は、南山イェジャン麓 (Yejang Jarak / 예장자락)の約1.7kmの歴史探訪の道です。1910年の庚戌国恥など国権喪失の現場を記憶しようという意味で、ソウル市がつくりました。日韓併合条約が結ばれた韓国統監官邸 (Hanguk Tonggam Gwanjeo / 한국통감관저)の跡にあった南山イェジャン公園 (Namsan Yejang Gongwon / 남산예장공원)から始まり、地面にあるハングルのギヨク (giyeok / ㄱ)形のロゴに沿って、韓国統監府 (Hanguk Tonggambu / 한국통감부)跡、乃木神社 (Nogi Sinsa / 노기신사)跡、日清戦争の勝利後に日本が建てたカボヨク記念碑 (Gabo Yeok Ginyeombi / 갑오역기념비)、京城神社 (Gyeongseong Sinsa / 경성신사)跡を通り、朝鮮神宮 (Joseon Singung / 조선신궁)跡へ続きます。道の終わりにソウル日本軍「慰安婦」被害者を記憶する碑 (Seoul Ilbongun Wianbu Pihaeja Girimbi / 서울 일본군 '위안부' 피해자 기림비)があります。

  • 開く時間: 常時開放。休み: 年中無休。

📍 南山野外植物園・南山谷韓屋村

南山野外植物園、龍山区 イテウォン洞 (Itaewon-dong / 이태원동)、☎ 02-798-3771 は、「南山の元の姿を取り戻す事業」で撤去された漢南洞 (Hannam-dong / 한남동)の外国人住宅の跡地につくられ、1997年2月18日に開園しました。散策路に沿って、季節ごとに変わる花と木が見られます。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

南山谷韓屋村、中区 Toegye-ro 34-gil 28 (퇴계로34길 28)、☎ 伝統家屋運営事務室 (Jeontong Gaok Unyeong Samusil / 전통가옥 운영사무실) 02-6358-5533、文化観光解説 02-2133-6269 は、1998年に南山の北側、旧首都防衛司令部 (Sudo Bangwi Saryeongbu / 수도방위사령부)の跡地79,934㎡につくられました。ソウルの各地にあった韓屋5棟を移築または復元し、伝統工芸館 (Jeontong Gongyegwan / 전통공예관)、チョヌ閣 (Cheonugak / 천우각)、伝統庭園、ソウル南山国楽堂 (Seoul Namsan Gugakdang / 서울남산국악당)、ソウル千年タイムカプセル (Seoul Cheonnyeon Taimkaepsyul / 서울천년타임캡슐)広場があります。

  • 体験: 韓服 (Hanbok / 한복)を着る、韓紙 (Hanji / 한지)を折る、ハングル (Hangeul / 한글)を書く、伝統茶を飲む、伝統礼節学校、韓方体験。土・日曜日には伝統婚礼が実際に行われ、伝統婚礼の体験もできます。ピグム亭 (Pigeumjeong / 피금정)の庭でチェギチャギ (Jegichagi / 제기차기)、ユンノリ (Yutnori / 윷놀이)、ピソクチギ (Biseokchigi / 비석치기)ができ、伝統文化遺産解説士が常駐しています。
  • 開く時間: 4~10月09:00~21:00、11~3月09:00~20:00。
  • 休み: 毎週月曜日。月曜日が祝日の場合は翌日が休みです。
  • 駐車: 可能。ベビーカー貸出: 可能。

📍 行事 — 南山烽燧儀式などの伝統文化行事

南山烽燧儀式などの伝統文化行事、南山烽燧台 (Namsan Bongsudae / 남산 봉수대)と普信閣 (Bosingak / 보신각)、☎ 行事会場 02-319-1220、運営会社 02-737-6444 は、朝鮮時代の通信手段だった烽燧 (Bongsu / 봉수)を再現するソウル市の行事です。南山烽燧台は、全国の烽火台から上がってきた烽火を集めて都城に知らせた場所です。2026年は1月1日~12月31日、11:00~15:40に開かれ、料金は無料です。

  • プログラム: 南山烽燧台での烽火儀式と歴史解説、毎日正午の普信閣での市民常設打鐘、南山タワー八角亭広場でのサムルノリ (Samulnori / 사물놀이)公演と伝統武芸のデモンストレーション、一日ポンスックン (Bongsukkun / 봉수꾼) の体験。

⚠ 事前に知っておきたい3つのこと

  1. 南山公園には一般の乗用車とタクシーが入れません — 循環バス、南山ケーブルカー、徒歩で登ります。
  2. 南山谷韓屋村は月曜日が休みです — 11~3月は20:00に閉まります。
  3. 南山烽燧儀式の登録期間は2026年12月31日までです — 11:00~15:40、無料です。

⚙ FAQ 2

Q. 南山ソウルタワーにはどうやって登りますか?

A. 韓国観光公社の登録情報では、明洞、忠武路、東大入口駅から循環バスや南山ケーブルカーに乗るか、歩いて登ります。一般の乗用車とタクシーは公園に入れません。

Q. 歩くのが大変な人でも行ける道はありますか?

A. 南山ドゥルレギルの北側循環路(南山ケーブルカー入口~国立劇場3.4km)です。バリアフリーの散歩道に選ばれていて、自動車と自転車は通れません。
