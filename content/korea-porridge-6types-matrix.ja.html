サブタイトル：外国人観光客向けアワビ・カボチャ・干し明太・ごま・松の実・緑豆の6種ガイド + ホテル朝食・迎え酒・各種マニア情報

ISSUE 03・#858・2026-06-09

🎯 なぜ韓国粥の総合ガイドが必要か

外国人観光客の韓国粥(죽)に対するペインポイント = 「アワビ粥 (전복죽) しか知らない」。韓国粥 = ホテル朝食#1 + 迎え酒(ヘジャン、해장、二日酔いを癒す韓国式食事)の定番 + 韓定食(ハンジョンシク、한정식、韓国式コース料理)の口開け一品。同じ「Korean porridge」でも、アワビ粥(済州 (제주) ・高級#1)・カボチャ粥 (호박죽)(秋・温かい)・干し明太粥 (황태죽)(迎え酒の正統)・ごま粥 (참깨죽)(韓定食コース第一品)・松の実粥 (잣죽)(宮中の正統)・緑豆粥 (녹두죽)(デトックス・夏)と、それぞれ食材・季節・マニア層が異なる。外国人観光客は(a)アワビ粥と日本のお粥の違いを知らない(b)干し明太粥が迎え酒食であることを知らない(c)ホテル朝食の粥の定番構成を知らない(d)韓定食の粥がコース第一品であることを知らない、というケースが多い。本ガイドは6種の総合比較 + ホテル朝食・迎え酒・韓定食 + 外国人観光客向け入門優先順位を扱う。

🍚 6種 深掘り

🦪 アワビ粥 (전복죽) — 高級#1

  • シグネチャー：済州 (제주) の正統・ホテル朝食#1・高級入門
  • 材料：アワビ + 米 + ごま油 + 海苔(キム、김)+ 卵・塩
  • 外国人親和度：★★★★★(世界的に高級料理として認識され、日本のお粥とよく比較される)
  • おすすめ店：
  • 済州アワビ粥専門店 — 正統#1
  • 新羅ホテル (신라호텔)・ロッテホテル (롯데호텔) の朝食 — 高級
  • 粥チェーン(ポンジュク (본죽)・チュギヤギ (죽이야기)) — チェーンでコスパ良し
  • 価格：専門店12,000〜25,000ウォン(約1,300〜2,800円)／ ホテル30,000〜50,000ウォン(約3,300〜5,600円)

🎃 カボチャ粥 (호박죽) — 秋

  • シグネチャー：秋の代表・温かい・甘い
  • 材料：甘いカボチャ + 米粉 + はちみつ・松の実
  • 外国人親和度：★★★★(カボチャは世界的に馴染みがあり、甘い味わい)
  • 季節：秋(9〜11月)
  • おすすめ店：粥専門店・伝統食堂・MZ(MZ世代、韓国のミレニアル+Z世代)カフェ
  • 価格：8,000〜15,000ウォン(約900〜1,700円)

🐟 干し明太粥 (황태죽) — 迎え酒#1

  • シグネチャー：江原道 (강원) の正統・飲んだ翌日の迎え酒#1・温かい
  • 材料：干し明太(ファンテ、황태)+ 米 + ごま油 + 海苔 + 卵
  • 外国人親和度：★★★★★(迎え酒の正統食、#1マニア)
  • おすすめ店：
  • 江原道の干し明太村(麟蹄 (인제)・平昌 (평창)) — 正統
  • ソウル (서울) の干し明太粥老舗(ノポ、노포、30年以上続く伝統店) — 鍾路 (종로)・江南 (강남)
  • 粥チェーン(ポンジュク) — チェーンでコスパ良し
  • 季節：通年(冬が#1)
  • 価格：10,000〜18,000ウォン(約1,100〜2,000円)

⚪ ごま粥 (참깨죽) — 韓定食の正統

  • シグネチャー：韓定食コース第一品・正統
  • 材料：黒ごま・白ごま + 米 + はちみつ

  • 材料：松の実 + 米 + はちみつ

  • 新羅ホテルのラヨン (라연)・三清閣 (삼청각)・仁寺洞 (인사동) の韓定食 — 正統店

⚠ 外国人観光客がよくする5つの勘違い

1. 「韓国粥＝日本のお粥」：韓国粥はごま油・海苔・卵が正統的な特徴、日本のお粥は梅干しと共に食べる。両者は別の料理。

2. 「干し明太粥＝普通の粥」：干し明太粥 = 迎え酒1位 + 江原道の正統。

3. 「松の実粥＝普通のナッツ粥」：松の実粥 = 宮中の正統・高級料理。

4. 「アワビ粥＝ありふれた料理」：アワビ粥 = 済州の正統 + ホテル朝食の高級品。

5. 「粥＝病人食」：粥は韓国の伝統的な主食(病人食・朝食・迎え酒・韓定食すべてに登場)。

⚙ よくある質問8件

1. 外国人観光客の入門1位：アワビ粥(高級)+ カボチャ粥(秋・温かい)→ 干し明太粥(迎え酒)。

2. インスタ・vlog向け：ホテル朝食のアワビ粥・江原道の干し明太村・韓定食の松の実粥。

3. MZトレンド：MZカフェのカボチャラテ・アワビ粥のかき氷など、アレンジも人気。

4. 迎え酒マニア：干し明太粥#1(江原道)+ 緑豆粥(夏)。

5. ホテル朝食：新羅・ロッテ・ウェスティン(1人60,000〜120,000ウォン、約6,700〜13,300円)。

6. アレルギー：魚介(アワビ)・ナッツ(松の実)・卵・はちみつは事前申告を。

7. 決済・チップ：ホテル＝サービス料10%＋付加価値税10% ／ 一般店＝カードOK ／ チップ不要。

8. VAT還付：飲食は基本的に還付対象外。

⚠ 医療・安全・食事に関する免責事項

粥＝ごく普通の消化に優しい食べ物。妊婦＝OK。子ども＝OK(熱さに注意)。アレルギー(魚介・ナッツ・卵・はちみつ)は事前申告を。食中毒が疑われる場合は☎ 1339(医療相談、英語対応あり)へ。本ガイドは一般情報であり、医療的助言ではない。

食事制限がある場合の代替案：

  • ハラール・コーシャー：アワビ粥(一部の魚介はOK)・松の実粥・ごま粥・カボチャ粥・緑豆粥＝OK ／ 干し明太粥＝魚由来(一部ハラール対応可)。
  • ベジタリアン・ヴィーガン：カボチャ粥・ごま粥・松の実粥・緑豆粥＝ベジタリアンOK(はちみつが入るとヴィーガン不可)／ アワビ粥・干し明太粥＝ベジタリアン不可。
  • グルテンフリー：6種すべて米100%＝グルテンフリーOK。
