🎯 だれのために、なぜこの8か所か

釜山に初めて行く外国人旅行者に合わせたリストです。海辺ではない釜山の都心でショッピングとカフェ通りを歩き、東萊で温泉と博物館を見るときに使います。

2つのエリアに分けました。

  • 西面エリア(4か所): 西面地下商店街(西面モール・釜田モール)、田浦カフェ通り、ロッテ百貨店釜山本店、釜田市場。
  • 東萊エリア(4か所): 虚心庁、東萊温泉露天足湯、福泉博物館、東萊邑城歴史館。

西面エリアは、都市鉄道の西面駅 (Seomyeon / 서면)、田浦駅 (Jeonpo / 전포)、釜田駅 (Bujeon / 부전) から歩いて行きます。東萊エリアは、温泉2か所は1号線の温泉場駅 (Oncheonjang / 온천장) から、博物館2か所は福泉博物館を基準に4号線の水安駅 (Suan / 수안) から歩いて行きます。そのためこの号は、場所ごとに「どの駅の何番出口から何分か」を先に書きました。

休みの曜日が場所ごとに違うので、下に別の表でまとめました。

⚠ 表記の原則: 時間、料金、行き方は2026-11-25に閲覧した値です。出典は、釜山施設公団、韓国観光公社、Visit Busan、釜山鎮区庁、ロッテ百貨店の公式サイト、ホテル農心の公式サイト、東萊区庁、釜山市、韓国空港公社、釜山交通公社です。料金は大人の定価です。住所の一部と、駅から歩く時間・距離はカカオマップの値で、該当の行に「カカオマップ」と明記しました。カカオマップの営業時間は2026-11-25から7日分を読んだ値なので、曜日と休みはその週が基準です。運営時間、料金、バスの時刻は変わることがあります。

✈ 金海空港から西面へ、そしてエリア内の駅

  • 空港リムジン2が西面に停まります。 釜山市の英語のお知らせ(2026-01-05施行)によると、リムジン2は釜田~西面~金海空港の15.7kmを走ります。停留所は、釜田駅、釜田市場、西面駅(ロッテ百貨店)、東義大駅 (Dong-eui Univ. / 동의대)、周礼駅 (Jurye / 주례)、金海空港です。
  • 料金: 大人6,000ウォン、青少年4,800ウォン、子ども3,000ウォンです。2026-01-05から、大人が7,500ウォンから6,000ウォンに下がりました。
  • 始発と終バス: 釜田発は始発06:00、終バス20:00です。空港発は始発07:20、終バス21:30です。運行間隔は約60~80分です。1本逃すと1時間以上待つことがあるので、時刻を先に合わせます。
  • 都市鉄道で行く道: 韓国空港公社の金海空港案内には、空港駅から釜山金海軽電鉄に乗り、沙上駅 (Sasang / 사상) で都市鉄道2号線に、大渚駅 (Daejeo / 대저) で3号線に乗り換えると書かれています。沙上駅で2号線に乗ると西面駅に着きます。
  • 都市鉄道の運賃: 釜山交通公社の運賃案内(2026-11-25閲覧)で、大人は交通カード・モバイルの場合、1区間1,600ウォン、2区間1,800ウォンです。QR乗車券は1区間1,700ウォン、2区間1,900ウォンです。
  • 駅は場所ごとに違います。 西面駅は1号線と2号線が出会う乗り換え駅です。田浦駅は2号線、釜田駅と温泉場駅は1号線、水安駅は4号線です。釜山駅も1号線の駅です(カカオマップ)。西面駅、釜田駅、温泉場駅は同じ1号線の上にあります。

🚦 歩く前に — 共通の安全とマナー

  • 田浦カフェ通りのカフェは、ほとんどが個人経営の小さな店です。 韓国観光公社がそう紹介しています。休みの曜日と閉まる時刻が店ごとに違うので、1か所だけ見て行くと閉まっていることがあります。
  • 露天足湯は天気が悪いと休みます。 東萊区庁の温泉案内は、悪天候と祝日、夏(7~8月)を休場日と書いています。
  • 事故や緊急のときは119、犯罪の通報は112に電話します。

① 西面エリア — 4か所

都市鉄道1号線と2号線が出会う西面駅の周りです。地下商店街と百貨店は西面駅から、カフェ通りは田浦駅から、市場は釜田駅から歩いて行きます。開く時刻が場所ごとに違います。釜田市場はVisit Busanの案内基準で07:00~19:00、西面モールは10:00から、ロッテ百貨店は10:30からです。

西面地下商店街 — 西面モール・釜田モール (Seomyeon Underground Shopping Center / 서면 지하도상가)

  • どんな所: 西面駅とつながる地下道に店が並ぶ商店街です。区間によって西面モールと釜田モールに名前が分かれます。釜山施設公団が運営を案内しています。

  • 西面モールの行き方: カカオマップ経路案内の基準で、西面駅2番出口から徒歩5分(283m)です。
  • 釜田モール: カカオマップ登録値(2026-11-25)で10:00~22:00です。カカオマップ経路案内の基準で、西面駅12番出口から徒歩4分(226m)です。

田浦カフェ通り (Jeonpo Cafe Street / 전포카페거리)

  • どんな所: 韓国観光公社は、西面1番街 (Seomyeon 1-beon-ga / 서면 1번가) の向かいにカフェ30軒ほどが集まった通りと紹介しています。2010年以降、工具や金物を売る商店街に小さなカフェが一つ二つと入ってきて知られるようになり、ほとんどが個人経営の小規模なカフェです。
  • 利用時間: 韓国観光公社の公式案内で常時開放で、休みはありません。通りそのものの話で、カフェは店ごとに時間が違います。
  • 行き方: Visit Busanの公式案内で、都市鉄道2号線の田浦駅7番出口から徒歩6分です。カカオマップ経路案内も、田浦駅7番出口から徒歩6分(382m)で同じです。
  • 入口の探し方: Visit Busanは、ノリマル (Nolimaru / 놀이마루)(学校の建物と運動場)の隣の建物が通りの入口の目印と書いています。代表住所は案内機関ごとに違って登録されているので、住所を入力するより、田浦駅7番出口から徒歩6分(382m)を基準にして、ノリマルの隣の建物を入口の目印にします。
  • 問い合わせ: 釜山鎮区庁 経済観光課 051-605-4522。

② 東萊エリア — 4か所

東萊区にある4か所です。温泉2か所は1号線の温泉場駅から、博物館2か所は福泉博物館を基準に4号線の水安駅から歩いて行きます。駅が互いに違うので、温泉の側と博物館の側を別々にまとめて動きます。東萊区庁は、東萊温泉の水を食塩泉、弱アルカリ性と紹介しています。

🗺 動線 — 半日・1日

順番は、各場所の開く時刻・閉まる時刻に合わせて組みました。

半日 A — 西面の昼 (毎月第1週の火曜日は避ける)

  1. 1号線 釜田駅1番出口 → 釜田市場(徒歩3分)。Visit Busanの案内の時間は07:00~19:00です。
  2. 西面駅に移って西面モール(西面駅2番出口からカカオマップ経路案内の基準で徒歩5分)。10:00から開きます。
  3. ロッテ百貨店釜山本店(西面駅7番出口から徒歩5分)。10:30から開きます。
  4. 2号線 田浦駅7番出口 → 田浦カフェ通り(徒歩6分)。紹介記事に出たカフェ4軒は11:00~12:00に開きます。
  5. カフェ通りに沿って上り、大きな道路を渡って田浦工具通り。

半日 B — 東萊 (祝日ではない水曜日~日曜日)

  1. 4号線 水安駅5番出口 → 福泉博物館(徒歩約18分)。09:00から開きます。
  2. 東萊邑城歴史館(福泉博物館から約100m)。
  3. 1号線 温泉場駅5番出口 → 東萊温泉露天足湯(カカオマップ経路案内の基準で徒歩11分)。11~2月は11:00~16:00です。
  4. 温泉場駅1番出口の方の虚心庁(出口から徒歩10分)。入場は21:30までです。

博物館2か所は水安駅、温泉2か所は温泉場駅なので、2番と3番の間で駅を移ります。火曜日は3番の足湯を外し、月曜日は4番の虚心庁だけが残ります。

1日 — 東萊の午前・昼、西面の夜 (祝日ではない水曜日~日曜日)

温泉場駅と西面駅は、どちらも1号線の駅です。西面では、閉まる時刻が早い順に、ロッテ百貨店(20:00)、西面モール(22:00)、田浦のカフェの順に置きます。

2日あるなら、1日は西面エリア、1日は東萊エリアに分けます。東萊の日は月曜日と火曜日、祝日を避け、西面の日は毎月第1週の火曜日を避けます。

⚠ 紛らわしい点3つ

  1. ロッテ百貨店釜山本店は10:00ではなく10:30に開きます。 通常営業は10:30~20:00です。10:00に開くのは地下商店街の西面モールで、西面モールは22:00まで開きますが、毎月第1週の火曜日に休みます。朝は地下商店街を先に、夜は百貨店を先に置きます。
  2. 田浦カフェ通りは、西面駅ではなく2号線の田浦駅7番出口から徒歩6分です。 韓国観光公社が書いている規模は、カフェ30軒ほどです。通りは常時開放ですが、カフェは店ごとに休みの曜日が違い、Visit Busanの紹介記事に出た4軒だけを見ても、火曜日に1軒、水曜日に2軒が休みます(カカオマップ登録値、2026-11-25)。
  3. 東萊の温泉2か所は、開く時間が大きく違います。 虚心庁は05:30~22:00で年中無休、料金がかかります。露天足湯は水~日曜日だけ開き、11~2月は11:00~16:00で、祝日と夏(7~8月)、天気が悪い日にも休みます(東萊区庁の温泉案内基準)。出口も違い、虚心庁は温泉場駅1番、足湯は5番出口です。

⚙ FAQ 3つ

  1. 料金がかかる所と無料の所は? — 料金がかかるのは虚心庁です。大人(中学生以上)の温泉料金が平日15,000ウォン、土・日・祝日18,000ウォンで、チムジルバン施設を使うと4,000ウォンを追加で払います。利用時間の上限を超えると1時間につき2,000ウォンが加わります。無料なのは福泉博物館と東萊邑城歴史館です。田浦カフェ通りは、通りを歩くのにお金はかかりません。虚心庁の料金は、2026-11-25にホテル農心の公式サイトで見た値です。
  2. 金海空港から西面へはどう行く? — 空港リムジン2が西面駅(ロッテ百貨店)と釜田市場、釜田駅に停まります。大人6,000ウォンで、2026-01-05に7,500ウォンから下がりました。空港発の始発は07:20、終バスは21:30で、釜田から空港へ行く始発は06:00、終バスは20:00です。運行間隔が約60~80分なので、時刻が合わなければ都市鉄道を使います。韓国空港公社の案内のとおり、釜山金海軽電鉄に乗り、沙上駅で2号線に乗り換えて西面駅で降ります。
  3. 月曜日に行ける所は? — 西面モールは第1週の火曜日だけ休み、田浦のカフェ4軒のうち月曜日に休む所はありません(カカオマップ登録値、2026-11-25)。東萊エリアは、福泉博物館、東萊邑城歴史館、露天足湯が月曜日に休むので、虚心庁だけが残ります。月曜日は西面モールと田浦を歩き、東萊は虚心庁だけに行く形で組みます。
