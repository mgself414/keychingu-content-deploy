🎯 왜 장생포 고래 + 반구대 암각화 가이드인가

울산 장생포 = 한국 #1 고래잡이 본거지 (1986년 IWC 모라토리엄 전)·장생포 고래 박물관 (1986년~). 반구대 암각화 (Bangudae Petroglyphs) = 7000년 전 신석기·UNESCO 잠정 등록 (2010년)·고래·사슴·호랑이 그림. 외국인 페인포인트 = (a) "고래 박물관 = 작은 박물관" 잘못된 인식·한국 #1 고래 박물관 (b) 장생포 = 1986년 모라토리엄 전 한국 #1 고래잡이 (c) 반구대 = 인류 최초 고래 사냥 기록 (7000년 전) (d) UNESCO 잠정 등록 (2010년·정식 등록 후보) (e) 영문 풀세트·외국인 매니아 매트릭스.

본 가이드는 5축 12 시그니처 + 박물관 + UNESCO 후보 + 외국인 영문 발화.

  • 시그니처: 1986년 IWC 모라토리엄 전·고래잡이 본거지·어부 집 + 옛 시그너
  • 외국인 친화도: ★★★★ (영문 시그너·문화 매니아)

  • 시그니처: 7000년 전 신석기 암각화·UNESCO 잠정 등록 (2010년)·바위 + 고래·사슴·호랑이 그림 200+
  • 시즌: 가을·겨울 = 수위 낮음 → 암각화 노출·여름 우기 = 침수 (관람 X)
  • 외국인 친화도: ★★★★ (영문 시그너·박물관 풀세트)

⚠ 외국인 자주 실수 5가지

1. "고래 박물관 = 작은 박물관": 한국 #1 고래 박물관 1986년~·영문 풀세트.

2. "장생포 = 일반 어촌": 1986년 IWC 모라토리엄 전 한국 #1 고래잡이 본거지.

3. "반구대 = 그냥 바위": 7000년 전 신석기 암각화·UNESCO 잠정 등록 (2010년)·인류 최초 고래 사냥 기록.

4. "반구대 = 연중 OK": 여름 우기 = 침수 (관람 X)·가을·겨울 = 수위 낮음 → 암각화 노출.

5. "고래잡이 = 현재도 진행": 한국 = 1986년 IWC 모라토리엄 이후 고래잡이 금지·박물관 + 문화 매트릭스만.

⚙ FAQ 6개

1. 외국인 입문 1순위: 박물관 + 마을 + 반구대 암각화 = 3-4시간.

2. 반구대 시즌: 가을·겨울 (수위 낮음 → 노출)·여름 우기 침수·확인 후 방문.

3. 고래 박물관 시간: 09:00~18:00·휴관 월요일·가족 매트릭스 #1.

4. 어시장 회: 신선한 회·해산물·시그너 매트릭스 + 가성비.

5. 알레르기: 회·해산물 = 갑각류·생선 알레르기·사전 고지 필수.

6. 추천 페르소나: 가족·어린이 = 박물관 + 모형 / MZ·인스타 = 마을 + 어부 집 / 매니아·문화 = 반구대 + 천전리.

⚠ 의료·안전·식이 disclaimer

박물관·마을·반구대 = 안전·외국인 친화 매트릭스. 어시장 회 = 알레르기 (갑각류·생선) 사전 고지·신선도 확인. 응급 ☎ 1339 (영문).
