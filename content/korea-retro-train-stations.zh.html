韩国复古火车站·废站指南 — 文化站首尔284·Hwarangdae铁路公园·京春线森林路，Gimyujeong站·正东津站·Chujeon站，直到Hwabon站·Seomjingang火车村，共16处

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“感性火车站”主题入选的地方中的16处 · 首尔有文化站首尔284(免费)·Hwarangdae铁路公园(24小时)·京春线森林路(全天开放) · 登记了门票·乘车费的有Seomjingang火车村(成人5,000韩元)·Wolmi Bada列车(工作日普通11,000韩元)两处(Neungnae自行车租赁·Hwarangdae停车另收费) · 登记为周一休息的有文化站首尔284·Gimyujeong废站(室外空间除外)·Wolmi Bada列车·Hwarangdae站舍展览馆·Hwarangdae铁路公园有轨电车图书馆·群山Impi站舍·Gomo站复合文化空间 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“感性火车站”主题入选的100处中，在韩国观光公社旅游信息里确认了运营信息的16处。表中的排名和得票数就是这次投票的结果。投票名称与韩国观光公社旅游信息的名称不同的地方，用地址作了对应。例如投票的“昌原 Gyeonghwa站小站 (Changwon Gyeonghwayeok Ganiyeok / 창원 경화역 간이역)”对应“Gyeonghwa站公园 (Gyeonghwayeok Gongwon / 경화역공원)”，“Wolmi Bada站 (Wolmi Bada Station / 월미바다역)”对应“Wolmi Bada列车 (Wolmi Bada Yeolcha / 월미바다열차)”，“Neungnae废站 (Neungnaeyeok Pyeyeok / 능내역 폐역)”对应“Neungnae站舍文化公园 (Neungnae Yeoksa Munhwa Gongwon / 능내역사문화공원)”。Hwarangdae站把“Hwarangdae铁路公园 (Hwarangdae Cheoldo Gongwon / 화랑대 철도공원)”和“Hwarangdae站舍展览馆 (Hwarangdae Yeoksa Jeonsigwan / 화랑대역사 전시관)”两条信息合并为一项。

大部分是把停运的旧车站(废站)改造成公园·展览馆·文化空间的地方。正东津站被介绍为有观光列车往来的车站。Wolmi Bada列车登记的不是车站，而是环绕月尾岛的观光单轨列车。

登记了门票·乘车费的只有Seomjingang火车村和Wolmi Bada列车两处。其余的登记为免费，或没有费用登记值。Neungnae站舍文化公园的自行车租赁和Hwarangdae铁路公园的停车(超过2小时的部分)另外收费。运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。

📍 首尔 — 文化站首尔284·Hwarangdae铁路公园·京春线森林路

文化站首尔284 (Munhwayeok Seoul 284 / 문화역서울284)(中区 (Tongil-ro 1 / 통일로 1)，☎ 02-3407-3500)是复原旧首尔站舍的复合文化空间。1900年从Namdaemun停车场 (Namdaemun Jeongchajang / 남대문정차장)开始，经过Gyeongseong站 (Gyeongseong Station / 경성역)成为首尔站，2004年旧站舍关闭后，于2011年8月11日开放。建筑外观是复原的1925年Gyeongseong站。有展览·演出·工作坊和空间导览项目。

  • 开放时间:周二、周四至周日 10:00~18:00(入场截止 17:30)，周三 10:00~19:00(入场截止 18:30)。
  • 休息日:每周一。展览准备期间不运营，登记为请确认展览日期后再去。
  • 费用:免费。登记为外国人也无需另行预约。停车:不可以。

Hwarangdae铁路公园 (Hwarangdae Cheoldo Gongwon / 화랑대 철도공원)(Nowon区 (Hwarang-ro 608 / 화랑로 608)，☎ Nowon区厅休闲城市科 (Nowon-gucheong Yeogadosi-gwa / 노원구청 여가도시과) 02-2116-0668)是把旧Hwarangdae站一带建成公园的地方。韩国观光公社的介绍中，这座车站既被写作“首尔最后的小站”，也被写作“京春线最后的小站”。1939年京春线开通后，2010年停运的铁轨没有被拆除而是保留了下来。展出1950年代的Mika列车 (Mika Yeolcha / 미카열차)和窄轨列车，以及捷克和日本广岛的有轨电车。

  • 开放时间:24小时运营。有轨电车图书馆 (Teuraem Doseogwan / 트램도서관) 10:00~19:00，咖啡馆 11:00~21:00。
  • 休息日:全年无休(有轨电车图书馆每周一休息)。费用:免费。停车:2小时免费，之后每5分钟150韩元。

Hwarangdae站舍展览馆 (Hwarangdae Yeoksa Jeonsigwan / 화랑대역사 전시관)(Nowon区 (Hwarang-ro 610 / 화랑로 610)，☎ 070-4179-3777)是改造旧Hwarangdae站，展示京春线历史和铁路资料的地方。

  • 开放时间:10:00~18:00。休息日:每周一，公休日的次日，1月1日，Seol·Chuseok连休。费用:免费。

京春线森林路 (Gyeongchunseon Sup-gil / 경춘선숲길)(Nowon区 (Hagye-dong 107-2 / 하계동 107-2)，☎ 京春线森林路游客中心 (Gyeongchunseon Sup-gil Bangmunja Center / 경춘선숲길 방문자센터) 02-3783-5977)是把旧京春线铁路改成公园的道路。京春线于1939年7月25日作为私营铁路开通，2010年12月20日运行了最后一班列车，2013年起分阶段变成公园。

  • 开放时间:全天开放。休息日:全年无休。

📍 Gyeonggi·仁川 — Neungnae站舍文化公园·Wolmi Bada列车

Neungnae站舍文化公园 (Neungnae Yeoksa Munhwa Gongwon / 능내역사문화공원)(南杨州市 (Joan-myeon Dasan-ro 566-5 / 조안면 다산로 566-5)，☎ 南杨州市政府文化观光科 (Namyangju Sicheong Munhwagwangwang-gwa / 남양주시청 문화관광과) 031-590-4783)是把2008年12月关闭的Neungnae站改造成展览馆的地方。候车室和铁道得到保存，有木椅·售票处·照片等小物件。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。
  • 自行车租赁:单人 1小时5,000韩元，双人 1小时8,000韩元。

Wolmi Bada列车 (Wolmi Bada Yeolcha / 월미바다열차)(仁川 Jemulpo区 (Jemullyang-ro 269 / 제물량로 269)，☎ 032-450-7600)是环绕月尾岛一圈的观光单轨列车。总运行距离为6.1km，绕一圈约需42分钟。轨道位于离地7~18m的高度。

  • 开放时间:旺季(4~10月)工作日(周二至周四) 10:00~18:00，周末(周五至周日·公休日) 10:00~19:00。淡季(11~3月) 10:00~18:00。
  • 休息日:每周一。
  • 费用:工作日普通11,000韩元，老人·青少年8,000韩元，儿童7,000韩元。周末普通14,000韩元，老人·青少年10,000韩元，儿童8,000韩元。
  • 乘车方式:登记为首次乘坐时只能在Wolmi Bada站上车，再次乘坐时4个车站都可以上车。

📍 Gangwon — Gimyujeong废站·正东津站·太白 Chujeon站·原州 Bangok站

Gimyujeong废站 (Gimyujeong Pyeyeok / 김유정역 폐역)(春川市 (Sindong-myeon Gimyujeong-ro 1435 / 신동면 김유정로 1435)，☎ 033-261-7780)1939年以Sinnam站 (Sinnam Station / 신남역)之名开业，2004年改名为Gimyujeong站。据韩国观光公社介绍，是韩国火车站中第一个使用人名的车站。2010年新站舍落成，旧站随之关闭。铁轨上留有旧Mugunghwa号列车 (Mugunghwaho / 무궁화호)，车厢里改成了书咖啡馆和旅游咨询中心。

  • 开放时间:全天开放。休息日:每周一(室外空间全年无休)。开放时间一栏的“全天开放”和休息日一栏的“周一”同时登记。
  • 费用:免费。停车:免费。

正东津站 (Jeongdongjin Station / 정동진역)(江陵市 (Gangdong-myeon Jeongdongyeok-gil 17 / 강동면 정동역길 17)，☎ 沙漏旅游咨询中心 (Morasigye Gwangwang Annae Center / 모래시계관광안내센터) 033-640-4536)据韩国观光公社介绍，是全国离大海最近的车站。1962年作为普通站开始营业，1995年成为电视剧《沙漏》的背景，作为日出名胜而为人所知。

  • 开放时间:登记为各线路不同。休息日:全年无休。停车:可以。

太白 Chujeon站 (Taebaek Chujeon Station / 태백 추전역)(太白市 (Ssaribat-gil 47-63 / 싸리밭길 47-63)，☎ 033-553-8550)位于海拔855m。据韩国观光公社介绍，是韩国位置最高的火车站。1973年开业，曾是运送煤炭的车站。休息室里有站长·站务员的制服和帽子，可以体验站务员。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

原州 Bangok站 (Wonju Bangok Station / 원주 반곡역)(原州市 (Dalmajung 3-gil 30 / 달마중3길 30)，☎ 原州市政府观光科 (Wonju Sicheong Gwangwang-gwa / 원주시청 관광과) 033-733-1330)是1941年开始营业的Jungang线站舍。2005年登记为登记文化遗产，2021年Jungang线新线路开通后成为废站。春天车站周围樱花盛开。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 大邱 — Hwabon站·Gomo站复合文化空间

Hwabon站 (Hwabon Station / 화본역)(军威郡 (Sanseong-myeon Sanseonggaeum-ro 711-9 / 산성면 산성가음로 711-9)，☎ 军威郡政府文化观光科 (Gunwi Guncheong Munhwagwangwang-gwa / 군위군청 문화관광과) 054-380-6065)于1938年12月1日作为Jungang线普通站开始营业。2024年12月Jungang线废线，成为废站。站舍建筑建于1936年，留有高25m的给水塔。候车室里展出车站的历史照片和站务员帽子等。

  • 开放时间:09:00~17:00。休息日:全年无休。费用:免费。

Gomo站复合文化空间 (Gomoyeok Bokhap Munhwa Gonggan / 고모역복합문화공간)(Suseong区 (Gomo-ro 208 / 고모로 208)，☎ 053-791-3334)是把停运的Gomo站改造成文化空间的地方。有分为站史馆和文化馆的Gomo博物馆 (Gomo Museum / 고모뮤지엄)，还有花园和步道。

  • 开放时间:4~11月 10:00~18:00，12~3月 10:00~17:30。
  • 休息日:每周一，1月1日，Seol·Chuseok当天。费用:免费。登记为团体参观必须在官网预约。

📍 釜山 — Songjeong旧站

Songjeong旧站 (Songjeong Yeok Gu / 송정역 구)(Haeundae区 (Songjeongjungang-ro 8beon-gil 60 / 송정중앙로8번길 60)，☎ Haeundae Blueline Park (Haeundae Blueline Park / 해운대 블루라인파크) 051-701-5548)是Donghae Nambu线 (Donghae Nambuseon / 동해남부선)的车站。1934年作为小站开始营业，1941年成为普通站。登记为登记文化遗产。现在是利用Donghae Nambu线旧铁路的Haeundae海滨列车 (Haeundae Haebyeon Yeolcha / 해운대 해변열차)的始发站和终点站。

  • 开放时间:09:30~22:00(可能视情况变动)。休息日:全年无休。停车:免费。

📍 Jeonbuk — 群山 Impi站舍·旧Seodo站

群山 Impi站舍 (Gunsan Impi Yeoksa / 군산 임피역사)(群山市 (Impi-myeon Seowonseokgok-ro 37 / 임피면 서원석곡로 37)，☎ 063-454-3923)是1936年左右作为群山线站舍建成的建筑。韩国观光公社的介绍中写道，日本殖民统治时期，群山线是把Jeolla南北道 (Jeolla Nambuk-do / 전라남북도)的农产品经群山港运往日本的通路。现在设有客车展览馆和公园，并结合本地出身的小说家Chae Man-sik (Chae Man-sik / 채만식)的作品故事来介绍。

  • 开放时间:10:00~18:00。休息日:每周一。费用:免费。

旧Seodo站 (Gu Seodo Station / 구 서도역)(南原市 (Samae-myeon Seodo-gil 32 / 사매면 서도길 32)，☎ 南原市政府地区活力科 (Namwon Sicheong Jiyeok Hwallyeok-gwa / 남원시청 지역활력과) 063-620-6684)建于1932年，据韩国观光公社介绍，是韩国最古老的木造建筑废站。2004年停止办理客运。是Choi Myeong-hui (Choi Myeong-hui / 최명희)的长篇大河小说《Honbul》 (Honbul / 혼불)的主要舞台。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 Jeonnam·Gyeongnam — Seomjingang火车村·Gyeonghwa站公园

Seomjingang火车村 (Seomjingang Gichamaeul / 섬진강기차마을)(谷城郡 (Ogok-myeon Gichamaeul-ro 232 / 오곡면 기차마을로 232)，☎ 061-362-7461)位于旧谷城站 (Gokseong Station / 곡성역)。介绍称，复原旧蒸汽机车模样的列车从旧谷城站(Seomjingang火车村)到Gajeong站 (Gajeong Station / 가정역)，往返10km的区间。

  • 开放时间:09:00~20:00(入场截止 18:00)。休息日:全年无休。
  • 门票(个人):成人5,000韩元，儿童·敬老优待者4,500韩元。详情登记为请通过官网和电话确认。

Gyeonghwa站公园 (Gyeonghwayeok Gongwon / 경화역공원)(昌原市 镇海区 (Jinhae-daero 649 / 진해대로 649)，☎ 055-548-4000)是以停运的Gyeonghwa站为中心建成的公园。春天沿着铁路形成樱花隧道。

  • 开放时间:全天开放。休息日:全年无休。

⚠ 行前须知 3 点

  1. 周一休息的地方很多 — 文化站首尔284、Gimyujeong废站(室外空间除外)、Wolmi Bada列车、Hwarangdae站舍展览馆、Hwarangdae铁路公园有轨电车图书馆、群山Impi站舍、Gomo站复合文化空间登记为周一休息。
  2. 文化站首尔284在展览准备期间关门 — 登记为请确认展览日期后再去。
  3. Wolmi Bada列车首次乘坐要在Wolmi Bada站上车 — 工作日和周末的费用不同。

⚙ FAQ 3

Q. 从首尔能去的地方有哪些?

A. 文化站首尔284(复原旧首尔站舍的复合文化空间)、Hwarangdae铁路公园·Hwarangdae站舍展览馆、京春线森林路。门票登记为免费，或没有登记值。

Q. 哪些地方可以乘坐列车?

A. 介绍有列车运行的地方是正东津站(观光列车)、Songjeong旧站(Haeundae海滨列车的始发站·终点站)、Seomjingang火车村(观光用列车往返到Gajeong站)、Wolmi Bada列车(观光单轨列车)。正东津站的运行时间登记为各线路不同。

Q. 哪些地方要花钱?

A. Seomjingang火车村(成人5,000韩元)和Wolmi Bada列车(工作日普通11,000韩元，周末普通14,000韩元)。Neungnae站舍文化公园的自行车租赁是单人 1小时5,000韩元，双人 1小时8,000韩元，Hwarangdae铁路公园停车是2小时免费后每5分钟150韩元。
