🎯 如何使用这份指南

点了一碗饭，小碟子一个接一个摆上来，吃完泡菜碟，会悄悄放上新的一碟。本指南讲的就是小菜 (Banchan / 반찬) 本身：小菜如何上桌、如何续加、小菜摆满桌的白饭套餐店·出租车司机食堂、可以买回家的小菜市场、泡菜。韩定食套餐、米其林韩餐、寺院料理交给 #478 韩定食指南。地址、时间只写在VisitKorea、VisitSeoul、UNESCO读到的数值。适合不想吃昂贵套餐，想在街坊饭馆好好吃一顿小菜的人。

旧版指南把宗家 (Jonggajip / 종갓집)、班家 (Banga / 반가)、宫廷、寺院料理都归在小菜里，还写了"真观寺寺院料理 = 国家非物质文化遗产"、"善哉法师 (Seonjae / 선재) 上过Chef's Table"。两者都错了 — 被指定的是真观寺水陆斋 (Jingwansa Suryukjae / 진관사 수륙재，佛教仪式)，上Chef's Table的是白羊寺 (Baegyangsa / 백양사) 的净观法师 (Jeonggwan / 정관)(更正依据在#478)。"通仁市场便当5,000韩元"之类的价格也没有官方出处，已删除。

🍚 小菜如何上桌 — 续加规则

  • 免费续加，没有小费：韩国餐厅不需要给小费，要求多加水或小菜也不会加收费用(VisitKorea)
  • 自助小菜：自己取水和小菜的自助方式，以及使用无人点餐机的餐厅在增加(VisitKorea)
  • 叫服务员时：想多点或有事要问，就喊"呦嘎哟 (Yeogiyo / 여기요)!"(意思是"这里！")(VisitKorea)
  • 小菜为什么这么多，见 #1132 韩国小菜文化

🥢 白饭套餐·出租车司机食堂 — 小菜摆满桌的街坊饭馆

  • 柿子树之家出租车司机食堂 (Gamnamujip Gisasikdang / 감나무집기사식당)：首尔麻浦区延南路 (Yeonnam-ro / 연남로) 25号。招牌猪肉烤肉，小菜丰盛。24小时，全年无休。02-325-8727。靠近京义线林荫道(VisitKorea)
  • 普光出租车司机食堂 (Bogwang Gisasikdang / 보광기사식당)：首尔龙山区长门路 (Jangmun-ro / 장문로) 6街 97号(东冰库洞)。猪肉白饭套餐、辣炒猪肉。可单人点餐，水、饭、小菜自助，剩下食物要额外收费。08:00~22:00，周日休息。0507-1402-8579(VisitKorea)
  • 石山白饭套餐 (Dolsan Baekban / 돌산백반)：全南丽水市江南8街 (Gangnam 8-gil / 강남8길) 13号。石山白饭套餐每天9种不同的小菜，烤鱼2人份起。06:30~20:00(休息 15:00~17:00)，周日休息。0507-1333-7374(VisitKorea)
  • 日老集市白饭套餐 (Illo Jangteo Baekban / 일로장터백반)：全南务安郡市场路 (Sijang-gil / 시장길) 17-12。菜单只有白饭套餐一种 — 酱菜、小葱泡菜等全罗道式小菜。09:30~16:00，周一休息。061-282-8074(VisitKorea)
  • 小菜食堂 (Banchan Sikdang / 반찬식당)：大田中区宝门山公园路 (Bomunsan Gongwon-ro / 보문산공원로) 484号。专营大麦饭，蔬菜、野菜、泡菜、炖锅摆满一桌。07:00~20:00(平日休息 14:30~16:00)，周一休息，可刷卡。042-253-2794(VisitKorea)
  • 五家都未公布价格

🛒 卖小菜的市场 — 买回家的小菜

  • 通仁市场 (Tongin Sijang / 통인시장)：首尔钟路区紫霞门路 (Jahamun-ro / 자하문로) 15街 18号。约70家店铺中，餐馆、小菜店之类的餐饮店最多。自2012年起经营便当咖啡馆"通 (Tong / 통)"。店铺 07:00~21:00，便当咖啡馆 11:00~15:00，休息日各店不同。0507-1378-0940(VisitKorea)。铜钱便当路线见 #589 通仁市场指南
  • 延曙市场 (Yeonseo Sijang / 연서시장)：首尔恩平区统一路 (Tongil-ro / 통일로) 850号(延新内站附近)。卖农产品、水产品、肉类、小菜。时间、休息日各店不同。02-355-1272(VisitKorea)
  • 江陵东部市场 (Gangneung Dongbu Sijang / 강릉 동부시장)：江陵市玉川路 (Okcheon-ro / 옥천로) 48号。卖祭祀食物之类的小菜食材，以及腌海鲜、泡菜。06:00~23:00(各店不同)，可刷卡，免费停车1小时。033-647-7999(VisitKorea)

🥬 泡菜 — 博物馆与腌泡菜体验

  • 腌越冬泡菜 (Kimjang / 김장)：泡菜是用调料和腌海鲜拌制的蔬菜储存食品。腌越冬泡菜(腌制并分享泡菜)2013年列入联合国教科文组织人类非物质文化遗产代表作名录(UNESCO)
  • 泡菜间博物馆 (Museum Kimchikan / 뮤지엄 김치간)：首尔钟路区仁寺洞路 (Insadong-gil / 인사동길) 35-4 仁寺洞Maru (Insadong Maru / 인사동마루) 主楼4~6层。10:00~18:00(17:30最后入场)，周一、1月1日、春节·中秋假期、12月25日休馆。体验"It's Kimchi"、"Kimchi Basic"、"Kimchi Master"(收费)和泡菜学校(免费)，必须提前预约，6岁以上。02-2088-8531(VisitKorea)。费用请在官方网站kimchikan.com确认
  • 泡菜学校釜山分店 (Kimchi School Busan / 김치스쿨 부산지점)：釜山机张郡机张邑东釜山观光9路 (Dongbusan Gwanggwang 9-ro / 동부산관광9로) 15号2层。腌泡菜体验、销售。09:30~16:00，可刷卡(VisitKorea)
  • 济州泡菜学校 (Jeju Kimchi School / 제주김치스쿨)：济州市西海岸路 (Seohaean-ro / 서해안로) 136号。腌泡菜体验、销售。08:00~17:00，可刷卡。064-712-9688(VisitKorea)
  • 海南泡菜村 (Haenam Kimchi Maeul / 해남김치마을)：全南海南郡北平面东海路 (Donghae-gil / 동해길) 97号。按季节安排体验的村庄，随时开放、全年无休。0507-1326-1743(VisitKorea)
  • 腌越冬泡菜体验的季节信息见 #751 腌越冬泡菜体验

🥗 饮食

  • 价格区间：本指南中没有官方公布的韩元价格。白饭套餐店、市场、泡菜体验的价格栏都是空的
  • 素食：泡菜用腌海鲜拌制(UNESCO)— 小菜里的泡菜、野菜、酱菜是否加了腌海鲜或肉汤，点餐前先问。不含肉的需求请使用 #1300 饮食需求手册 的出示卡片
  • 清真：VisitSeoul介绍梨泰院的Eid (Eid / 이드)是少数获韩国伊斯兰教中央会(KMF)认可的清真餐厅之一(龙山区 Usadan-ro 10-gil 15号，每天12:00–21:00)。认证可能变更，前往前请先确认。本指南的白饭套餐店没有清真标示，其中两家以猪肉烤肉为招牌
  • 过敏：泡菜中用腌海鲜(虾、凤尾鱼等海产)(UNESCO)。甲壳类过敏要事先说明

🧰 小菜实用信息 — 独自、预约、支付、点餐、交通

  • 独自：普光出租车司机食堂 (Bogwang Gisasikdang / 보광기사식당) 可单人点餐(VisitKorea)。石山白饭套餐 (Dolsan Baekban / 돌산백반) 的烤鱼2人份起。适合一个人坐的餐馆见 #348 Seoul Solo Diner Map
  • 预约：白饭套餐店没有预约说明。泡菜间博物馆 (Museum Kimchikan / 뮤지엄 김치간) 的体验必须提前预约(VisitKorea)
  • 支付：小菜食堂 (Banchan Sikdang / 반찬식당)、江陵东部市场 (Gangneung Dongbu Sijang / 강릉 동부시장)、两家泡菜学校可刷卡(VisitKorea)— 其余见 #527 韩国支付系统
  • 点餐：想多要小菜时喊"呦嘎哟 (Yeogiyo / 여기요)!"(VisitKorea)。语言不通时见 #1339 点餐礼仪
  • 交通：丽水、务安、大田见 #1297 高速·城际巴士手册，首尔市内见 #1298 三种交通卡选择

⚠ 常见错误4则

1. "多要小菜要加钱" — 加水、加小菜免费(VisitKorea)

2. "剩下也无所谓" — 普光出租车司机食堂 (Bogwang Gisasikdang / 보광기사식당) 剩下食物要额外收费(VisitKorea)。自助小菜只盛吃得完的量

3. "留下小费再走" — 韩国餐厅没有小费(VisitKorea)

4. "周一去泡菜博物馆" — 泡菜间博物馆 (Museum Kimchikan / 뮤지엄 김치간) 周一休馆(VisitKorea)
