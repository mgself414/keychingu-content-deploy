ISSUE 03 · #137 · 2026-05-11

🎯 왜 홍대인가

Reddit r/koreatravel 외국인 demand-side 신호 분석에서 홍대 8회 mention으로 강남(4회)·명동(3회)을 앞선 1순위 area. 외국인 관광객이 "Honest thoughts on Seoul from a Brit", "Spontaneous solo trip" 등에서 가장 자주 언급하는 곳. 인디 음악·디자인·MZ 라이프스타일이 한 동네에 압축된, 명동(쇼핑)·강남(럭셔리)과 분명히 다른 톤.

★ 한눈에 비교 (8곳)

# 매장 지역 4축 외국인 친화 시그니처
1 롤링홀 (Rolling Hall) 홍대 음악·라이브 ◎ 1세대 라이브하우스, K-인디 본진
2 클럽 FF (Club FF) 홍대 음악·라이브 ◎ DJ·인디 클럽, 외국인 클러버 다수
3 상상마당 (KT&G Sangsangmadang) 홍대 디자인·아트 ○ 인디 영화·갤러리·디자인숍 종합
4 땡스북스 (THANKS BOOKS) 홍대 디자인·아트 ○ 디자인·아트 셀렉트북 + 갤러리
5 OBJECT (오브젝트) 홍대·합정 디자인·아트 ○ K-인디 일러스트·라이프스타일 굿즈
6 홍대 곱창골목 홍대 먹거리·노포 △ 야간 곱창·막창 노포 골목
7 망원시장 (Mangwon Market) 망원 먹거리·노포 ◎ 외국인 시장 체험·길거리 음식
8 홍대 놀이터 (Hongdae Playground) 홍대 거리·체험 ◎ 외국인 거리공연·인스타 스폿

⚠ 처음 가는 외국인이 자주 하는 실수 3가지

1. 홍대=홍익대 학교 정문만 본다

외국인 관광 홍대는 학교 정문보다 홍대입구역(2호선) 9번 출구 ~ 어울마당로 ~ 와우산로 일대. 거리 공연·클럽·디자인숍이 밀집된 곳은 학교 자체가 아닌 인근 거리. 정문 사진 한 컷 찍고 거리로 나오는 게 정답.

2. 클럽·라이브하우스가 항상 외국인 ID 받는다고 착각

롤링홀·KT&G 상상마당 같은 라이브하우스는 여권 ID 무조건 필요 (만 19세 이상 한국 규정). 외국인이라도 ID 없으면 입장 거절. DJ 클럽은 입장료 ₩20,000~30,000 + 드링크 1잔 포함.

3. 홍대만 보고 망원·연남을 놓침

외국인은 홍대 단독 방문이 흔하지만, 도보 10분 내 망원시장 (시장 체험) + 연남동 (트렌디 카페 골목) + 합정 (OBJECT 메인 매장)이 같은 일대. 동선 묶으면 하루 알찬 코스.

홍대권 (Hongdae & Around) 풍경

홍대는 마포구 서교동·동교동·연남동·합정·망원을 묶는 'Greater Hongdae' 구역. 외국인은 보통 홍대입구역(2·6호선·공항철도)에서 시작 → 어울마당로 거리 → 클럽·라이브하우스 → 망원시장 또는 연남동 카페골목으로 종일 동선. 명동·강남과 달리 MZ·인디·언더그라운드 톤이 압도적.

외국인 관광객 4가지 의도:

1. K-인디·라이브 음악 체험 (롤링홀·클럽 FF)

2. 디자인·아트·서브컬처 쇼핑 (OBJECT·땡스북스·상상마당)

3. K-MZ 카페·바 인스타 코스 (연남·합정)

4. 시장·노포 먹거리 (망원시장·곱창골목)

4축 매핑

  • ① 음악·라이브 (2): 롤링홀·클럽 FF — 라이브하우스 + DJ 클럽
  • ② 디자인·아트 (3): 상상마당·땡스북스·OBJECT — 종합 아트·셀렉트 + 굿즈
  • ③ 먹거리·노포 (2): 홍대 곱창골목·망원시장 — 야간 노포 + 시장 체험
  • ④ 거리·체험 (1): 홍대 놀이터 — 외국인 거리공연 인스타 스폿

① 음악·라이브 (2곳)

롤링홀 (Rolling Hall)

1995년 오픈, 한국 1세대 라이브하우스. 한국 인디·록 씬의 본진으로 잔나비·혁오·국카스텐 등 셀 수 없는 밴드의 출발점. 200~300석 규모로 가까운 거리감. 외국인 관광객은 K-인디 셋리스트 사전 확인 후 티켓 예매 권장.

  • 주소: 마포구 어울마당로 6길 18, B1
  • 영업: 공연 일정에 따라 (보통 19:00 도어 / 20:00 시작)
  • 티켓: ₩40,000~₩77,000 (밴드 따라)
  • 시그니처: K-인디 1세대 라이브하우스
  • 왜: 한국 인디 음악을 경험하는 정통 코스. 영어 안내·티켓 사이트 일부 지원.

클럽 FF (Club FF, Funky Funky)

홍대 DJ 인디 클럽 대표주자. 매주 금·토 라이브 + DJ 셋. 외국인 클러버 비중 높음 — 일렉트로니카·하우스·테크노. 입장료에 음료 1잔 포함이 일반적.

  • 주소: 마포구 어울마당로 6길 5-23, B1 (서교동)
  • 영업: 금·토 22:00~05:00 (시즌 변동)
  • 입장료: ₩20,000~₩30,000 (음료 1잔 포함)
  • 시그니처: 외국인 친화 DJ 클럽
  • 왜: 영어 안내 OK. ID(여권) 필수, 만 19세 이상.

② 디자인·아트 (3곳)

KT&G 상상마당 홍대 (KT&G Sangsangmadang)

KT&G 후원 인디 종합문화공간. 1F 디자인숍·2F 카페·3~4F 갤러리·B1 인디 영화관. 디자인 굿즈 + 인디 전시 + 영화 한 곳에서. 외국인 관광객 인기 코스.

  • 주소: 마포구 어울마당로 65 (서교동)
  • 영업: 매일 11:00~22:00 (영화관 별도)
  • 시그니처: 디자인 굿즈·갤러리·인디 영화 종합
  • 왜: 한국 디자인·인디 문화 1시간 압축 체험. 외국인 다수 방문, 영어 안내 가능.

땡스북스 (THANKS BOOKS) — #135 연결

서점+카페+갤러리 3-in-1. 1F 한국 디자인·아트 셀렉트북 (각 책에 직원 손글씨 쪽지), 2F 갤러리·세미나. 외국인은 디자인북·아트 매거진 한국 시각을 보고 싶을 때 best.

  • 주소: 마포구 양화로 6길 57-6 (홍대)
  • 영업: 매일 12:00–21:00
  • 시그니처: 손글씨 쪽지 큐레이션 + 디자인·아트 셀렉트
  • 왜: #135 서점 가이드에서 노포·큐레이션 축. 홍대 코스에서 30~60분 휴식 + 굿즈 쇼핑.

OBJECT (오브젝트)

홍대·합정 일대 K-인디 라이프스타일 굿즈숍. 한국 일러스트·디자인 작가 콜라보 제품 위주 (스티커·노트·에코백·머그). 외국인 관광객 기념품·선물 1순위.

  • 주소: 마포구 와우산로 35길 13 (홍대) — 합정·서교 분점 있음
  • 영업: 매일 12:00~21:00
  • 시그니처: K-인디 일러스트·디자인 굿즈
  • 왜: 단순 기념품 아닌 한국 작가 콜라보. 가격대 ₩3,000~₩30,000.

③ 먹거리·노포 (2곳)

홍대 곱창골목 (Hongdae Gopchang Alley)

홍대 어울마당로 5길 일대 야간 곱창·막창 노포 골목. 외국인보다 한국인 MZ 비중 큰 동네 노포지만, 외국인이 노포 야장 분위기 경험하기에 좋은 코스.

  • 주소: 마포구 어울마당로 5길 일대 (서교동)
  • 영업: 매장별 / 보통 17:00~02:00
  • 메뉴: 곱창·막창·대창 1인분 ₩15,000~₩25,000
  • 시그니처: 야간 노포 곱창 골목
  • 왜: 한국식 야간 술자리 분위기. 김치찌개·라면 사이드 + 소주·맥주.

망원시장 (Mangwon Market)

홍대에서 도보 15분 또는 6호선 한 정거장. 외국인 관광객 시장 체험 1순위. 떡볶이·튀김·전·국밥 길거리 음식 + 청과·생선 시장 분위기. 광장시장보다 작지만 로컬 색이 강함.

  • 주소: 마포구 망원로 22 (망원)
  • 영업: 매일 09:00~22:00 (휴무 매장별 다름)
  • 시그니처: 외국인 친화 로컬 시장 + 길거리 음식
  • 왜: 광장시장이 너무 관광지화돼서 부담스러우면 망원시장으로. ₩5,000~₩10,000 내외 길거리 음식 다양.

④ 거리·체험 (1곳)

홍대 놀이터 (Hongdae Playground, 정식: 어울마당)

홍대입구역 9번 출구 도보 3분. 외국인 관광객의 인스타 스폿 + 거리공연(버스킹) 1순위. 주말 저녁 K-pop 댄스 커버·인디 밴드 라이브 매일 다른 공연. 무료 관람.

  • 주소: 마포구 어울마당로 (서교동)
  • 영업: 24시간 (공연은 보통 18:00~22:00)
  • 시그니처: 외국인 버스킹·K-pop 댄스 인스타 스폿
  • 왜: 홍대 시작점. 30분 산책 + 인스타 사진. 주말 저녁이 절정.

⚙ FAQ 8개

Q1. 홍대 첫 방문 코스는?

홍대입구역 9번 출구 → 홍대 놀이터 (버스킹 30분) → 상상마당 (1시간 디자인숍·갤러리) → OBJECT (30분 굿즈) → 어울마당로 식당 점심 → 땡스북스 (1시간 책방) → 저녁 롤링홀 또는 클럽 FF.

Q2. 외국인 클럽 ID 정책은?

여권 ID 무조건 필요. 만 19세 이상 (한국 음주 가능 연령). 클럽 입구 stamp + 음료 1잔 무료가 일반.

Q3. 라이브 음악 티켓 어디서?

롤링홀 공식 사이트 또는 인터파크·예스24. 영어 인터페이스 일부 지원. 인기 밴드는 1~2주 전 매진.

Q4. 망원시장 vs 광장시장은?

광장시장: 종로, 관광지화 됨, 마약김밥·빈대떡 등 시그니처. 망원시장: 마포, 로컬색 강함, 떡볶이·튀김·전. 외국인이 흐름에 휩쓸리기 싫으면 망원, 시그니처 코스를 노리면 광장.

Q5. 곱창 처음인 외국인이 시도해도 될까?

대창이 가장 부담 없음 (지방 적고 식감 좋음). 곱창·막창은 향이 강해서 호불호. 깻잎·마늘·고추로 향 잡기. 김치찌개·라면을 사이드로 시키면 안전.

Q6. 비 오는 날 홍대 코스?

실내 위주 — 상상마당 (4층 종합) + 땡스북스 (실내 책방) + OBJECT (굿즈) + 어울마당로 카페. 클럽·라이브하우스는 밤이라 비와 무관.

Q7. K-pop 굿즈는 어디?

홍대는 K-pop보다 인디·디자인 굿즈가 메인. K-pop 굿즈는 명동 K-Star Road 또는 강남 SM Town COEX가 더 풍부. 홍대 OBJECT는 작가 콜라보 라이프스타일 위주.

Q8. 휠체어 / 유모차 접근?

홍대 놀이터·상상마당·OBJECT 합정점·망원시장은 평탄 동선. 롤링홀·클럽 FF·땡스북스·홍대 곱창골목은 좁은 골목·계단 다수로 접근 어려움.

🗺 추천 1일 코스 3가지

A코스 — "홍대 첫 방문 종일" (외국인 초보, 8시간)

홍대입구역 9번 출구 11:00 → 홍대 놀이터 (30분 버스킹) → 어울마당로 점심 → 상상마당 (1.5시간) → OBJECT (30분) → 땡스북스 (1시간) → 저녁 (어울마당로 식당) → 롤링홀 공연 (20:00~)

B코스 — "K-인디 음악 deep dive" (음악 팬, 6시간)

홍대 14:00 → 상상마당 갤러리 + 디자인숍 → OBJECT → 인디 카페 (연남동) → 저녁 곱창골목 → 클럽 FF 22:00~ (춤 + DJ 셋) → 새벽 1~2시 종료

C코스 — "홍대+망원 시장 풀스택" (시장 체험형, 7시간)

홍대입구 12:00 → 홍대 놀이터 → 어울마당로 점심 → 땡스북스 → OBJECT → 도보 또는 한 정거장 → 망원시장 (16:00 길거리 음식·시장 체험 2시간) → 합정 카페·바 → 저녁

🌸 시즌·시간대 훅 5개

1. 금·토 야간 클럽 피크: 클럽 FF는 22:00~02:00가 절정. 일찍 가면 한산.

2. 주말 저녁 버스킹: 홍대 놀이터 17:00~22:00, K-pop 댄스 커버·인디 밴드 매일 다른 공연.

3. 여름 야시장 (7~8월): 망원시장 야간 운영 + 합정 야시장 비정기. 외국인 관광객 피크.

4. 가을 인디 페스티벌: 9~10월 KT&G 상상마당 인디 영화제 + 홍대 거리 페스티벌.

5. 겨울 따뜻한 노포: 12~2월 홍대 곱창골목 + 막걸리 노포 (#136 막걸리 가이드 연결).
