ソウルの夜食9軒 — 夜10時半まで開いているトッポッキ・ノガリ・タッカンマリ・カムジャタン・サムギョプサル

サブタイトル: ウルチロのノガリ(干し小スケトウダラ)ホフ2軒、トンデムンのタッカンマリ、シンダンドンの24時間トッポッキ、ヤクスのクムトゥェジ食堂まで、ウルチロ・トンデムン・シンダン・ヤクスのあたりの5軒と、ヨンサンのヘジャンクク、ソンブクのカムジャタン、キョデのサムギョプサル、プアムドンのチキンの4軒。カカオマップにオーナーが登録した平日の閉店時間が22:30、またはそれより遅い店だけを選んだ。閉店時間は22:30から05:00までで、24時間営業の店も1軒ある。日曜は早く閉まる店があるので別に記した。粉食全般は#471、焼肉店全般は#479にある。

#780 · 2026-11-24 改訂 · ソウルの夜食

🎯 こんな人に

夕方の予定が遅くに終わって夜10時を過ぎてからごはんを探す旅行者や、宿の近くでビールと一緒におつまみを楽しみたい人に向いています。選定基準はひとつだけです。カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した平日の閉店時間が22:30、またはそれより遅い店だけを残しました。名の知れたコムタン (Gomtang / 곰탕)・冷麺 (Naengmyeon / 냉면)・サムゲタン (Samgyetang / 삼계탕)の店も候補に入れましたが、16:00~22:00に閉まるので外しました。

⚠ 表記の原則: 営業時間・定休日・メニュー価格は、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した値です(2026-11-24確認)。価格はメニューごとの登録日が2年以内のものだけを記載し、それより古いメニューは「カカオマップで当日確認」としました。食事面のヒントはメニュー名・オーナーの説明から読み取れるものだけを書きました。材料・アレルギーは注文前にスタッフに確認してください。最寄り駅はカカオマップの道案内に出る駅・出口・距離です。

① ウルチロ・トンデムン・シンダン・ヤクス — 5軒

ウルチロサムガ駅 (Euljiro-samga / 을지로3가역)とシンダン駅 (Sindang / 신당역)は2号線でつながっています。トンデムンのタッカンマリはトンデムン駅 (Dongdaemun / 동대문역)(1・4号線)から、クムトゥェジ食堂はヤクス駅 (Yaksu / 약수역)(3・6号線)から歩くので、駅ごとに乗り換えが必要です。ノガリホフから始めて、タッカンマリ、トッポッキ (Tteokbokki / 떡볶이)へと移る順番が無理がありません。

ウォンジョ マンソンホフ ノガリチェーン本店 (Wonjo Manseon Hof Nogari Chain Main / 원조만선호프 노가리체인본점)

ウルチロのノガリ横丁 (Nogari-golmok / 노가리골목)にあるホフ (Hof / 호프、ビアホール)です。毎日 12:00~05:00に開いていて、この回では24時間営業の店を除くと最も遅く閉まります。登録価格(2025-10-30)はノガリ (Nogari / 노가리)が₩2,000、海鮮ラーメン (Haemul-ramyeon / 해물라면)が₩13,000、スープトッポッキ (Gukmul-tteokbokki / 국물떡볶이)が₩13,000、鶏の砂肝揚げ (Dakttongjip-twigim / 닭똥집튀김)が₩15,000、半乾燥イカ (Bangeonjo-ojingeo / 반건조오징어)が₩16,000です。チキンのメニューは価格が登録されていません。住所は中区 (Jung-gu / 중구)のウルチロ13番街19 (Euljiro 13-gil 19 / 을지로13길 19) 1階2号、ウルチロサムガ駅(2・3号線)3番出口から150mです。横丁の中に「ウォンジョ マンソンホフ (Wonjo Manseon Hof / 원조만선호프 2)」「マンソンホフ (Manseon Hof / 만선호프)」「マンソン (Manseon / 만선3)」という名前の店がありますので、住所で探してください。

  • 食事面のヒント: ノガリは干した小さなスケトウダラ(魚)です。イカ・海鮮ラーメンは海産物、鶏の砂肝 (Dakttongjip / 닭똥집)は鶏の砂肝です。手作りとんかつ (Sujae-donkkaseu / 수제돈까스)は豚肉です。ホフなのでお酒が中心です。ベジタリアン向けと読み取れる登録メニューはありません。

ウルジOBベア (Eulji OB Bear / 을지OB베어)

ウルチロサムガ駅9番出口のすぐ前にあるホフで、カカオマップのタグに老舗 (Nopo / 노포)が付いています。月~土 15:00~23:30、日曜は 15:00~22:00です。登録価格はオリジナルノガリ&干しスケトウダラ (Orijinal Nogari&Hwangtae / 오리지널 노가리&황태)が₩6,000(2026-07-22)、干しカワハギ (Jwipo / 쥐포)が₩10,000、蚕のさなぎ (Beondegi / 번데기)が₩11,000、骨なしフライドチキン (Sungol Fried Chicken / 순살 후라이드 치킨)が₩16,000、骨なしヤンニョムチキン (Sungol Yangnyeom Chicken / 순살 양념치킨)が₩17,000(2026-11-04)、チーズプルダック (Chijeu-bulgak / 치즈불닭)が₩23,000です。住所は中区 (Jung-gu / 중구)のチュンムロ49-2 トンジュビル (Chungmu-ro 49-2 Dongju Building / 충무로 49-2 동주빌딩) 1階、ウルチロサムガ駅9番出口から56mです。

  • 食事面のヒント: ノガリ・干しスケトウダラ・干しカワハギは魚を干したおつまみです。ポンデギ (Beondegi / 번데기)は蚕のさなぎです。ジョンソンビルソーセージ (Johnsonville Sausage / 존슨빌 소시지)は豚肉です。チキンは鶏肉で、衣には普通小麦粉が使われます。お酒が中心です。

チノクファハルメ ウォンジョ タッカンマリ 本店 (Jinokhwa Halmae Wonjo Dakhanmari Main / 진옥화할매원조닭한마리 본점)

トンデムンのタッカンマリ横丁 (Dakhanmari-golmok / 닭한마리 골목)にある食堂です。毎日 10:30~01:00、年中無休です。登録メニューはタッカンマリ (Dakhanmari / 닭한마리)が₩33,000(2025-11-28)のひとつだけです。住所は鍾路区 (Jongno-gu / 종로구)の鍾路40ガ番街18 (Jong-ro 40ga-gil 18 / 종로40가길 18) 1~3階、トンデムン駅(1・4号線)10番出口から332mです。近くに名前の似たタッカンマリの店がいくつかあるので、住所で探してください。

  • 食事面のヒント: 鶏を一羽丸ごと鍋で煮て食べる料理なので、鶏肉が中心です。カルグクスのサリ (Kalguksu-sari / 칼국수 사리、追加の麺)を足す店が多く、サリは小麦粉の麺です。サリ・薬味の価格はカカオマップにないので、注文のときに聞いてください。

アイラブシンダンドン (I Love Sindang-dong / 아이러브신당동)

シンダンドンのトッポッキ横丁 (Sindang-dong Tteokbokki-golmok / 신당동 떡볶이 골목)にある即席トッポッキ (Jeuksok-tteokbokki / 즉석 떡볶이)の店です。24時間営業で登録されています。登録価格はシンダンドントッポッキ (Sindang-dong Tteokbokki / 신당동 떡볶이)が3人前 ₩23,000・4人前 ₩28,000、チーズ・海鮮・涙 (Nunmul / 눈물)・アイラブトッポッキ (I Love Tteokbokki / 아이러브 떡볶이)が(中) ₩27,000・(大) ₩32,000、ジャージャートッポッキ (Jjajang-tteokbokki / 짜장 떡볶이)が(中、マイルド) ₩23,000です(2025-08登録)。2人前と(小)サイズは登録日が2年を超えているので、カカオマップで当日確認してください。住所は中区 (Jung-gu / 중구)のトェゲロ76番街50 ソンファンビル (Toegye-ro 76-gil 50 Seonghwan Building / 퇴계로76길 50 성환빌딩) 1階、シンダン駅(2・6号線)8番出口から259mです。

  • 食事面のヒント: コチュジャン味のトッポッキなので辛いです。メニュー名に「涙 (Nunmul / 눈물)」が付くものは、より辛いほうと読めます。海鮮トッポッキは海産物、チーズトッポッキは乳製品が入ります。即席トッポッキにはオムク (Eomuk / 어묵、魚の加工品)がよく入るので、ベジタリアンの方は注文のときに聞いてください。ジャージャートッポッキは材料を確認してください。

クムトゥェジ食堂 (Geumdwaeji Sikdang / 금돼지식당)

ヤクス駅のあたりにある豚肉の焼肉店です。カカオマップのタグに「ソウルミシク100選 (Seoul Misik 100-seon / 서울미식100선)」が付いています。毎日 11:30~23:00ですが、オーナーの説明によると23:00まで開いているのは1階で、2・3階は22:00に閉まります。登録価格は雪花豚トロ (Nunkkot-moksal / 눈꽃목살)150gが₩23,000、豚の首肉 (Deung-moksal / 등목살)150gが₩24,000、豚のカシラ肉 (Hangjeongsal / 항정살)120gが₩25,000、丸ごと豚キムチチゲ (Tongdwaeji Kimchi-jjigae / 통돼지김치찌개)(小)が₩8,000、サントリーハイボール (Suntory Highball / 산토리하이볼)が₩10,000です(2026登録)。本サムギョプサル (Bon-samgyeopsal / 본삼겹)は登録日が2年を超えているので、カカオマップで当日確認してください。住所は中区 (Jung-gu / 중구)のタサンロ149 (Dasan-ro 149 / 다산로 149)、ヤクス駅(3・6号線)2番出口から237mです。

  • 食事面のヒント: ほとんどが豚肉です。豚肉を避ける場合は、韓牛のアンチャンサル (Hanu Anchangsal / 한우 안창살)120gが₩65,000、韓牛ユッケ (Hanu Yukhoe / 한우육회)120gが₩36,000あります。ユッケは生の牛肉です。ハイボールなどのお酒のメニューがいくつか登録されています。

  • 食事面のヒント: どのメニューにも「国産背骨 (Gukssan Deungppyeo / 국산등뼈)」と書かれています。カムジャタンは豚の背骨の料理なので、豚肉を避ける場合は合いません。おからのカムジャタン (Kongbiji Gamjatang / 콩비지 감자탕)には大豆が入ります。

ケヨルサ (Gyeyeolsa / 계열사)

プアムドンのチキンの店です。火~土 12:00~22:30、日曜・祝日は 12:00~22:00、月曜定休です。登録価格はフライドチキン (Fried Chicken / 후라이드치킨)が₩24,000(2026-04-04)、辛い骨なし鶏足 (Maekom Ppyeo-eomneun Dakbal / 매콤 뼈없는 닭발)が₩18,000(2025-04-25)です。タットリタン (Dakdoritang / 닭도리탕)・ゴルベンイそうめん (Golbaengi-somyeon / 골뱅이소면)などそのほかは、登録日が2年を超えているので、カカオマップで当日確認してください。住所は鍾路区 (Jongno-gu / 종로구)のペクソクトンギル7 (Baekseok-dong-gil 7 / 백석동길 7) 1階です。カカオマップの道案内には最寄りの地下鉄駅の情報がないので、バスかタクシーで行きます。同じ道の61番地に同じ名前の別の場所があるので、7番地で探してください。

  • 食事面のヒント: チキンは鶏肉で、衣には普通小麦粉が使われます。オムクタン (Eomuk-tang / 어묵탕)・サンマキムチチゲ (Kkongchi Kimchi-jjigae / 꽁치김치찌개)・ハンチ (Hanchi / 한치)・ミョクテ (Meoktae / 먹태)・ゴルベンイ (Golbaengi / 골뱅이)・クァメギ (Gwamegi / 과메기)は海産物で、ポンデギタン (Beondegi-tang / 번데기탕)は蚕のさなぎです。登録メニューの中にベジタリアン向けと読み取れるものはありません。

🗺 動線 — 2つのコース

A. ウルチロ → トンデムン → シンダン (夕方~深夜)

  1. 18:00ごろ ウルジOBベア (Eulji OB Bear / 을지OB베어)でノガリとビール(15:00~)
  2. 20:00ごろ チノクファハルメ ウォンジョ タッカンマリ (Jinokhwa Halmae Wonjo Dakhanmari / 진옥화할매원조닭한마리)(~01:00)へ移動。トンデムン駅のあたりです
  3. 23:00以降 シンダン駅のアイラブシンダンドン (I Love Sindang-dong / 아이러브신당동)でトッポッキ(24時間)。もっと遅くにビールが必要なら、ウルチロのウォンジョ マンソンホフ (Wonjo Manseon Hof / 원조만선호프)(~05:00)に戻ります

B. ヤクス → シンダン (肉 + トッポッキ)

  1. 21:00前 クムトゥェジ食堂 (Geumdwaeji Sikdang / 금돼지식당)に入る。23:00まで開いているのは1階だけです
  2. 食後 シンダン駅に移動してアイラブシンダンドン (I Love Sindang-dong / 아이러브신당동)へ

店と店の間にかかる時間は、カカオマップの道案内でその日に確認してください。

⚠ よくある失敗3つ

  1. 日曜の夜にヨンムンヘジャンクク (Yongmun Haejangguk / 용문해장국)へ行く — 日曜は15:00に閉まります。ウルジOBベア (Eulji OB Bear / 을지OB베어)も日曜は22:00に閉まります。
  2. 月曜にケヨルサ (Gyeyeolsa / 계열사)を予定する — 月曜は定休日です。同じ名前の別の場所(ペクソクトンギル61)に道案内が向かわないよう、住所を入力してください。
  3. 22時を過ぎてクムトゥェジ食堂 (Geumdwaeji Sikdang / 금돼지식당)に着いて2階に案内される — 2・3階は22:00に閉まります。遅く行くと1階の席しか残っていないと考えて、早めに入ってください。

⚙ よくある質問3つ

  1. 深夜1時を過ぎて行ける店は？ — 登録時間では、アイラブシンダンドン (I Love Sindang-dong / 아이러브신당동)(24時間)とウォンジョ マンソンホフ (Wonjo Manseon Hof / 원조만선호프)(~05:00)の2軒です。チノクファハルメ ウォンジョ タッカンマリ (Jinokhwa Halmae Wonjo Dakhanmari / 진옥화할매원조닭한마리)は01:00に閉まります。
  2. 豚肉を食べないなら？ — タッカンマリ (チノクファ)、チキン (ケヨルサ・ウルジOBベア)、ノガリのおつまみ (ウルチロの2軒)、トッポッキ (アイラブシンダンドン)を選んでください。カムジャタン・ヘジャンクク・サムギョプサルの店は豚肉が中心です。
  3. ひとりでも行ける？ — トッポッキは3人前から登録価格があり、2人前は当日確認です。カムジャタン・タッカンマリ・チョンゴルは鍋単位です。ひとりなら、ノガリホフや肉の1人前を注文できるか、入る前に聞いてください。
