🎯 왜 성산일출봉 가이드인가

성산일출봉 (Seongsan Ilchulbong) = UNESCO 자연유산 2007·제주 일출 매트릭스 #1·5,000년 전 화산 분화. 외국인 페인포인트 = (a) "일출봉 = 일반 봉우리" 잘못된 인식 (b) UNESCO 2007 자연유산 (c) 5,000년 전 화산 분화·182m 분화구 (d) 일출 매트릭스 #1·새해 1/1 매니아 매트릭스 (간절곶 #1019 다음) (e) 우도 (소섬·동쪽 매트릭스 #1) (f) 영문 풀세트.

본 가이드는 5축 12 시그니처 + 일출봉 + UNESCO + 우도.

🏛 5축 deep dive

① 성산일출봉 (UNESCO 2007·5,000년 화산)

  • 시그니처: UNESCO 자연유산 2007·5,000년 전 화산 분화·182m 분화구·제주 일출 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문·다국어 풀세트)
  • 시간: 04:00~20:00 (계절별)·5,000원

② 정상 (182m·30분 등산)

  • 시그니처: 30분 등산·외국인 매트릭스 매니아 매트릭스·분화구 매트릭스
  • 외국인 친화도: ★★★★★ (영문 + 가족)

③ 우도 (소섬·동쪽)

  • 시그니처: MZ + 인스타 매트릭스·자전거·전동스쿠터·해변·카페
  • 외국인 친화도: ★★★★★ (영문·MZ + 매니아)
  • 가격: 우도 왕복 = 5,500원·1박 매트릭스

④ 해변 + 광치기 + 해녀

  • 시그니처: 광치기 해변 (일출 매트릭스)·해녀 시연 (매주 토 + 일)
  • 외국인 친화도: ★★★★★ (영문·매니아)

⑤ 1박 매니아 (펜션·호텔)

  • 시그니처: 일출 + 1박 = 외국인 매니아 매트릭스 #1
  • 가격: 1박 = 80,000~300,000원/박

⚠ 외국인 자주 실수 5가지

1. "성산일출봉 = 일반 봉우리": UNESCO 2007·5,000년 화산·182m 분화구.

2. "일출 = 어디서나 동일": 제주 일출 매트릭스 #1·새해 매니아 매트릭스.

3. "정상 등산 = 매니아": 30분 + 평지 매트릭스·외국인 가족 매트릭스 #1.

4. "우도 = 작은 섬": MZ + 인스타 매트릭스 + 자전거 매니아.

5. "해녀 = 옛 일": 유네스코 무형문화유산 2016·시연 매트릭스 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: 성산일출봉 + 우도 + 광치기 = 1일.

2. 일출 시간: 월별 다름·1월 = 07:30·6월 = 05:10·30분 전 도착 권장.

3. 우도: 왕복 5,500원·자전거·전동스쿠터 = 1.5h 매트릭스 #1.

4. 해녀 시연: 주말 14:00·무료·해녀 박물관 매트릭스.

5. 시즌: 봄·가을 베스트·여름·겨울 = 새해 매트릭스 #1.

6. 추천 페르소나: 가족·시니어 = 성산 + 광치기 / MZ·인스타 = 우도 + 자전거 / 매니아 = 새해 일출 + 1박.

⚠ 의료·안전 disclaimer

성산일출봉 = 안전·평지·외국인 친화. 새해 일출 = 새벽 추위·방한복. 우도 자전거 = 안전 헬멧. 응급 ☎ 1339·1330·119.

✈️ 외국인 페인포인트 #1 — UNESCO + 일출 매트릭스

  • UNESCO 2007: 성산일출봉 + 한라산 + 거문오름 = UNESCO 풀세트
  • 일출 매트릭스 #1: 제주 = UNESCO + 일출 + 분화구 + 해변 매트릭스
  • 외국인 매니아 매트릭스: MZ + 가족 + 매니아 매트릭스 #1
  • K-드라마 매트릭스: 다수 K-드라마 촬영지·외국인 매니아 fit
