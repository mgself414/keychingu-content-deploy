한국 BBQ 테이블 워크플로우 — 자리에서 결제까지 7-step

부제: 외국인 관광객용 직원 굽기 vs 셀프 차이 + 쌈·반찬·추가 주문 + 결제 팁

ISSUE 03 · #805 · 2026-06-07

🎯 왜 한국 BBQ 테이블 워크플로우 가이드인가

외국인 한국 BBQ 페인포인트 #2 = "메뉴 시켰는데 그 다음은?". [#804 부위·등급](804_외국인_한국_BBQ_부위_등급_매트릭스_가이드.md) 알아도 + 테이블 진행 흐름은 별개 학습 필요. 한국 BBQ는 (a) 직원이 굽는 매장 (b) 셀프 굽는 매장 (c) 반자동(직원이 가위질만)으로 3 type. 외국인은 (1) 굽기 타이밍 놓치고 태우거나 (2) 추가 주문 방식 모르고 종업원 호출 못하거나 (3) 쌈·반찬·후식 시스템 모르거나 (4) 결제 단계서 봉사료·세금 혼동. 본 가이드는 7-step 워크플로우 + 매장 type별 차이 + 외국인 친화 팁.

★ 한눈에 7-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 자리 잡기 입장 + 인원 안내 + 테이블 배정 1~5분 4인 이상 = 좌식 OR 의자 선택 가능. 환기 좋은 자리 요청 OK
2️⃣ 메뉴 선택 메뉴판 + 부위·인분·세트 결정 5~10분 1인 1.5~2인분 기본. 처음엔 2종 부위 + 양념 1종 추천
3️⃣ 굽기 직원 굽기 / 셀프 / 반자동 부위별 직원 굽기 = 그릴 매니아 / 셀프 = 자유도 ↑ / 반자동 = 가위질만
4️⃣ 쌈 + 반찬 쌈채소·마늘·고추·반찬 5~10종 무제한 모든 반찬 = 무료 리필. "반찬 좀 더 주세요" = "Banchan more, please"
5️⃣ 추가 주문 부위 추가 + 술·음료 + 후식 5~10분 종업원 벨 OR "여기요!" (excuse me) 호출. 추가 메뉴 = 별도 청구
6️⃣ 후식 (식사) 냉면·된장찌개·볶음밥·공깃밥 10~15분 한국식 = 회식 마무리 = 식사 코스. 1인 5,000~10,000원
7️⃣ 결제 카드 OR 현금 + 영수증 3~5분 카운터 결제 多 / 일부 테이블 결제 / 봉사료 호텔 외 보통 X

총 소요 시간 (2인 기준): 1~1.5h (가성비 매장) ~ 2~3h (고급·회식)

🔥 매장 type별 굽기 시스템 비교

Type A — 직원 굽기 (가장 친화적)

  • 특징: 종업원이 처음부터 끝까지 굽기·잘라주기. 외국인 1순위 추천.
  • 추천 매장 (서울): 강남·청담·롯데월드·신라호텔 일식·한식당
  • 장점: 굽기 실패 X / 영어 안내 가능 / 부위별 굽기 시간 자동
  • 단점: 비싼 매장 多 / 인당 3,000~5,000원 또는 테이블당 5,000~10,000원 그릴 매니아 비용 별도 있을 수 있음
  • 외국인 친화도: ★★★★★

Type B — 셀프 굽기 (가성비)

  • 특징: 본인이 직접 굽기. 가위질도 직접.
  • 추천 매장 (서울): 홍대·신촌·강남 가성비 BBQ / 골목 노포
  • 장점: 가격 ↓ (인당 25,000~50,000원) / 자유도 ↑ / 로컬 분위기
  • 단점: 굽기 실패 risk (특히 닭·돼지) / 가위질 숙련도 필요
  • 외국인 친화도: ★★★ (영문 메뉴 없는 곳 多)

Type C — 반자동 (가위질만 직원)

  • 특징: 본인이 굽고 종업원이 가위로 잘라주기. 중간 형태.
  • 추천 매장: 의정부·길동 정육식당 / 일반 BBQ 전문점 多
  • 장점: 가위질 안전 + 굽기 자유도 / 가성비 ★
  • 단점: 굽기는 본인 책임
  • 외국인 친화도: ★★★★

외국인 입문 = Type A 또는 C 우선 (B는 한국 BBQ 익숙해진 후)

🍃 쌈 + 반찬 시스템 (Banchan System)

기본 제공 무료 (Free Refill)

  • 쌈채소 (Ssam vegetables): 상추 (Lettuce)·깻잎 (Perilla)·치커리·청경채
  • 마늘·고추·쌈장 (Garlic·Pepper·Ssamjang dipping sauce)
  • 김치 3종: 배추김치 (Cabbage)·깍두기 (Radish)·열무 (Young radish)
  • 반찬 5~7종: 시금치나물·콩나물·잡채·두부조림 등

어떻게 먹나? — 쌈 만들기

1. 쌈채소 1장 손바닥에 펴기

2. 잘 구운 고기 1~2 조각 올리기

3. 마늘 1~2 조각 + 쌈장 1/2 티스푼

4. 김치·고추 약간 + 밥 (선택)

5. 한 입에 넣기 (한국식 표준 = 한 입 통째)

외국인 자주 실수: 쌈을 입에 다 못 넣고 절반씩 베어 먹기. 한국식 권장 = 한 입 통째 (절반 베어 먹기는 어색해 보일 수 있음, 위반은 아님). 작게 만들어서 한 입에 넣기 권장.

추가 주문 시스템

  • "반찬 좀 더 주세요" (Banchan more, please) — 무료 무제한
  • "고기 추가요" (Meat more, please) — 별도 청구
  • "공기밥 하나요" (Rice one, please) — 1,000~2,000원
  • "이거 새 거 주세요" (This one is burnt, can I get a new one?) — 셀프 매장 굽기 실패 시 OK
  • "따로 계산할 수 있어요?" (Can I pay separately?) — 분리 결제 (매장별 정책 다름)
  • "환기 좀 더 강하게 해주세요" (Stronger ventilation, please) — 매장에 요청 OK

🍷 음료·술 페어링

한국 BBQ 술 매트릭스

술 종류 가격 (병/잔) 페어링
소주 (Soju) 4,000~6,000원 모든 부위 OK. 회식 기본. 알코올 16~17%
맥주 (Beer) 4,000~8,000원 시원함·가벼움. 매운 양념 페어링 ★
소맥 (Soju+Beer) 매장 가격 한국 회식 1순위. 외국인 호기심 ★. 비율 1:3 또는 1:2.5 (1:2는 소주 과다)
막걸리 (Makgeolli) 5,000~8,000원 전통주·달콤. 비 오는 날 + 매운 닭갈비 ★
하이볼 (Highball) 8,000~12,000원 일식·고급 BBQ. 부드러움 + 시트러스
와인 (Wine) 30,000~100,000원 한우 1++·럭셔리 BBQ. 미디엄 바디 레드

페어링 추천

  • 삼겹살 + 소주 = 한국 BBQ 클래식
  • 차돌박이 + 맥주 = 가벼움 페어링
  • 한우 꽃등심 + 와인 = 럭셔리 페어링
  • 닭갈비 + 막걸리 = 매운맛 진정

외국인 주의: 소주 1병 알코올 = 와인 1잔 ~ 1.5잔. 1인 2병 이상 위험.

⚠ 외국인 자주 실수 7가지

1. "메뉴판 1인분 = 1인 충분": 보통 1인분 = 100~150g. 1인 1.5~2인분이 표준 양.

2. "반찬 = 1회 제공": 무제한 무료 리필. "반찬 좀 더 주세요" 호출.

3. "쌈 = 잘라 먹기": 한국식 권장 = 한 입 통째. 절반씩 베어 먹기는 어색해 보일 수 있음 (위반은 아님). 쌈 작게 만들기 권장.

4. "종업원 = 자동 호출": 한국 식당은 본인이 호출. 벨 OR "여기요!" (excuse me) 발화.

5. "고기 = 메인이고 끝": 한국 회식 = 고기 → 후식 (냉면·찌개·볶음밥) 코스. 후식 별도 주문.

6. "카드 결제 = 테이블": 매장 따라 다름. 카운터 결제 多 (한국식). 일부 테이블 카드.

7. "굽기 실패 시 = 그냥 먹기": 셀프 매장에서 너무 태우면 종업원에게 "이거 새 거 주세요" 요청 가능 (서비스 매장 多).

⚙ FAQ 8개

1. 첫 BBQ = 어떤 매장?: Type A (직원 굽기) 1순위. 강남·청담·신라호텔 일식 BBQ 추천.

2. 1인 BBQ 가능?: 일부 매장 (혼밥·1인 BBQ 전문점) 가능. 일반은 최소 2인 권장.

3. 굽기 안전 시간: 돼지 well-done (3~5분 양면) / 소 medium (2~3분) / 닭 well-done (5~7분 철판)

4. 점심 vs 저녁: 점심 특선 (lunch course) = 30~50% 할인. 1차 회식은 저녁

5. 외국인 영어 매장 추천: 강남·이태원·홍대·청담 = 영문 메뉴 多. 지방·골목 = 한국어 기본

6. 소맥 강요 거부: "I don't drink soju" 또는 손바닥 위 컵 들기 = 거부 신호. 한국인 대부분 존중

7. 알레르기: 사전 고지 필수. 한식 양념 = 마늘·간장·꿀·고추장 + 글루텐 (간장에 밀)

8. 결제 분리: 일행과 개별 결제 = "더치페이 가능?" 일부 매장 OK / 일부 매장 X. 한국식 패턴 = 한 사람이 결제 후 나중에 송금 (카카오페이·토스 송금이 보편적)

⚠ 의료·안전·식이 disclaimer

BBQ 직접 조리 = 화상 위험 (그릴 250~350°C). 어린이 동반 시 가족 좌석 사전 요청 + 그릴 멀리. 돼지·닭 well-done 필수 (식중독·살모넬라·E.coli). 임신부·면역저하 = 더 익혀서. 알레르기 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback: 일반 BBQ 매장 = 할랄·코셔·채식 메뉴 X. 이태원·강남 일부 할랄 BBQ 매장 (Eid·Makan·Halal BBQ Korea 등) 사전 검색 권장. 채식·비건 = [#799 채식](799_외국인_한국_채식_비건_매트릭스_12선_deep_dive.md) 별도 가이드 참조 OR 다른 매장 분리.

💰 Essential Tourist Tips

  • 소요 시간 (2인 기준):
  • 가성비 BBQ = 1~1.5h
  • 일반 = 1.5~2h
  • 회식·고급 = 2~3h
  • 1인 평균 예산 (2026년 6월 기준, 시세 변동 가능):
  • 가성비 = 30,000~50,000원 + 소주 1병
  • 일반 = 50,000~80,000원 + 술 2병
  • 고급 = 100,000~200,000원 + 와인
  • 점심 특선: 평일 11:30~14:00, 30~50% 할인
  • 결제 패턴:
  • 카운터 결제 = 80% (한국식)
  • 테이블 결제 = 20% (영어 매장 多)
  • 봉사료: 호텔 일식·고급 BBQ 일부 10% / 일반 매장 X
  • VAT 환급: 식음료 일반 환급 대상 아님
