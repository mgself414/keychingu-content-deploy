⚠ 외국인 자주 실수 5가지

1. "한국 음악 = K-pop만": 한국 음악 = K-pop + 인디 (잔나비·IU·악동뮤지션) + 재즈 (올댓재즈 1976) + 외국인 글로벌 매니아 + #387·#138 통합.

2. "홍대 라이브 = 그냥 클럽": 홍대 라이브 = KT&G 상상마당 (1500석 한국 #1)·롤링홀 (500석)·라이브존·외국인 매니아 1번지 + 인디·#138·#366 통합.

3. "외국인 영어 OK 라이브 = 없음": 외국인 영어 OK = KT&G 상상마당·롤링홀·올댓재즈·외국인 매니아 1번지 + Klook·KKday·KTO 패키지·#387 통합.

4. "올댓재즈 = 한국인만": 올댓재즈 (이태원) = 1976 한국 #1 재즈 + 외국인 매니아 1번지 + #144 외국인 거주·#252 통합.
