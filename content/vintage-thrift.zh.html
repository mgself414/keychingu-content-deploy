⚠ 外国游客常犯的3个错误

1. “复古 = 只有东庙 (Dongmyo / 동묘)”: 韩国复古有4大支柱 — 市场复古 (东庙 (Dongmyo / 동묘)·广藏 (Gwangjang / 광장)2楼·风物 (Pungmul / 풍물)) + MZ世代热门区域 (延禧 (Yeonhui / 연희)·弘大 (Hongdae / 홍대)·圣水 (Seongsu / 성수)·梨泰院 (Itaewon / 이태원)·益善 (Ikseon / 익선)) + 二手图书·App (阿拉丁 (Aladdin / 알라딘)·闪电市集 (Beongaejangteo / 번개장터)) + 批发·奥特莱斯 (江南客运站 (Gangnam Teomineol / 강남터미널)·加山 (Gasan / 가산))。

2. “东庙 (Dongmyo / 동묘) = 太大”: 东庙 (Dongmyo / 동묘)是9号线·1·6号线东庙前站 (Dongmyoap-yeok / 동묘앞역)直达 + 1公里长的复古街。步行30分钟即可逛完。梨泰院 (Itaewon / 이태원)LCT·延禧 (Yeonhui / 연희)TTA建议结合深度探访一家店。

3. “二手 = 不可信”: 韩国二手市场 = 闪电市集 (Beongaejangteo / 번개장터)·二手国家 (Junggonara / 중고나라)App (韩国第一二手交易平台) + 阿拉丁 (Aladdin / 알라딘) (图书)·奥特莱斯 (连锁品牌保证)。外国游客友好，可议价。
