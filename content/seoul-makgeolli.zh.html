外国人常犯的3大误区

1. "马格利 (Makgeolli) = 简单米酒"的误解

韩国马格利 (Makgeolli) 按地区·度数·发酵方式细分，种类多达50种以上 — 平昌 (Pyeongchang / 평창) 南瓜马格利·济州 (Jeju / 제주) 牛岛 (Udo / 우도) 花生马格利·首尔7.8度马格利等。外国人英文评价："Wide variety of makgeolli from all over the peninsula" — 在7.8马格利 (7.8 Makgeolli) 1号店可一次品鉴来自朝鲜半岛各地的马格利。初次到访，建议优先要求"多种类品鉴 (sampling)"。

2. "传统酒 = 度数低"的误解

  • 马格利 (Makgeolli)：6~8度 (略高于啤酒)
  • 药酒 (Yakju)·清酒 (Cheongju)：13~17度 (相当于葡萄酒)
  • 烧酒 (Soju)：16~25度 (蒸馏酒)
  • 传统蒸馏烧酒 (安东烧酒 / Andong Soju 등)：40~50度 (相当于威士忌)

在传统酒画廊 (Korean Traditional Liquor Gallery / 전통주갤러리) · 福顺都家 (Boksoondoga / 복순도가) 品鉴时，4种合计约等于1杯葡萄酒的酒精量。外国人日文评价 (福顺都家 / Boksoondoga / 복순도가)："試飲もさせてくれます。繊細な口当たりのマッコリが本当に美味しい" — 口感柔和，但请务必准确认知度数。

3. "酿造厂 = 工厂参观"的误解

首尔市区酿造厂 (宝石酿造 / Boseok Brewery / 보석양조 · 乙支麦屋 / Euljiro Brewing Seoul / 을지맥옥 等) 采用饮酒空间即酿造空间的模式 — 在发酵罐旁直接品鉴刚酿好的酒，属于微型精酿 (microbrewery) 模式。外国人日文评价 (乙支麦屋 / Euljiro Brewing Seoul / 을지맥옥)："乙支路はレトロの聖地ですもんね。ビールは相変わらず美味しいです" — 乙支路 (Euljiro / 을지로) 复古集群的核心资产。

3. FAQ — 外国人常见6大问题

  • 福顺都家首尔站店 (Boksoondoga Seoul Station / 복순도가 서울역점) · 传统酒画廊 (Korean Traditional Liquor Gallery / 전통주갤러리) · A4俱乐部 (Ace Four Club / 에이스포클럽) 位于外国人动线，支持多种支付方式。
  • 酿造厂 (宝石酿造 / Boseok Brewery / 보석양조) · 韩屋门店部分建议携带现金。

Q2. 有英文菜单吗？

  • 福顺都家 (Boksoondoga / 복순도가) / 传统酒画廊 (Korean Traditional Liquor Gallery / 전통주갤러리) / A4俱乐部 (Ace Four Club / 에이스포클럽) / 于野斋 (Uyajae / 우야재) / 乙支韩屋 (Eulji Haok / 을지하옥)：英文菜单 ✓ (店员英语OK)

  • 宝石酿造 (Boseok Brewery / 보석양조)：以韩语为主 (可请店员推荐)

Q3. 可以单人前往吗？

  • 8家店铺均可单人到访。韩国饮酒文化天然适合独自前往。
  • 于野斋 (Uyajae / 우야재) · 乙支韩屋 (Eulji Haok / 을지하옥) 座位较少，建议提前预约。

Q4. 支持纯素·清真饮食吗？

  • 马格利 (Makgeolli) · 药酒 (Yakju) · 清酒 (Cheongju) 均为谷物发酵酒，属纯素 (不含蛋·奶)。但小菜使用动物性食材。
  • 无清真认证门店。酒本身属伊斯兰教禁忌 → 仅餐食可选的场所另行参考 (超出本指南范围)。

Q5. 可以带孩子吗？

  • 本指南以酒为核心 → 不推荐携带儿童。
  • 但于野斋 (Uyajae / 우야재) · 乙支韩屋 (Eulji Haok / 을지하옥) 也有以餐食为主的套餐，儿童可用餐。传统酒画廊 (Korean Traditional Liquor Gallery / 전통주갤러리) 除品鉴外，画廊参观部分可供家庭游览。

Q6. 登机行李·伴手礼 — 哪里购买？
