なぜK-dramaマニア1泊なのか

K-drama撮影地巡礼は、外国人訪問客の観光動機で1~2位を争います。Netflix・Disney+のグローバル展開以降、トッケビ(Dokkaebi / 도깨비)・パラサイト・梨泰院クラス・イカゲーム・冬のソナタのファン層が20~40代の海外MZ世代へと急速に広がりました。1泊構成の強みは、都心の撮影地(日帰り)+郊外の撮影地(1泊後、早朝移動) を一つの流れでつなげられる点です。

ソウルだけでもパラサイト — チャハムン(Jahamun / 자하문)・チョンウンドン(Cheongun-dong / 청운동)、梨泰院クラス(イテウォン)、雲が描いた月明り(景福宮・昌徳宮)をすべてカバーでき、KTXを利用すれば日帰りでチョンドンジン(Jeongdongjin / 정동진) — トッケビ、カンヌン(Gangneung / 강릉)、全州(Jeonju / 전주)韓屋村 — 雲が描いた月明りまで足を延ばせます。1泊の予算を40~50万ウォン程度に見ておけば、宿泊・交通・入場料・食費をすべてカバーできます。

⚠️ 外国人がよくやるミス3

1. 撮影地=映画そのままの空間だと勘違いする

パラサイトの階段(チャハムントンネル上のチョンウンドンの階段)は、映画に描かれた半地下の町とは距離があります。撮影地は特定の外観・路地のシーンだけを撮った場合が多く、内部や周辺環境は映画と異なることがあります。現地を訪れる前にOTTで該当シーンを確認しておくと、がっかりせずに済みます。

2. ナミソム(Nami Island / 남이섬)とチョンドンジンを日帰りで一緒に回ろうとする

ナミソムのあるカピョン(Gapyeong / 가평)と、チョンドンジンのあるカンヌンは、ソウルから見て方向が異なります。両方を1日で回ろうとすると移動時間だけで6~7時間かかります。1泊の日程では、1日目にナミソム、2日目にチョンドンジン(KTX)というように分けるか、どちらか一方を選びましょう。

3. 景福宮・昌徳宮を午後遅くに訪れる

両宮とも閉門が早いです(景福宮18:00、昌徳宮後苑ツアーは予約必須)。ハンボックのレンタル時間(通常17:30返却)と入場締切を混同し、ハンボックを着たまま入場できないケースがよくあります。午前10時前の入場をおすすめします。

1. インチョン(Incheon / 인천) ヨンジョンド(Yeongjongdo / 영종도) — トッケビ撮影地(#743)

場所: 仁川広域市中区ヨンジョンド一帯(空港鉄道ヨンジョン駅下車)

作品: tvNドラマ「トッケビ」(2016~2017年、コン・ユ、キム・ゴウン主演)。ヨンジョンドの海岸道路と防波堤一帯が、トッケビとチウンタクのカナダ・ケベックのシーンの代役として撮影されました。実際のカナダロケーションの代わりに仁川ヨンジョンドの海岸が使われたもので、夕暮れ時の海岸風景が劇中の雰囲気とよく合っています。

アクセス: 仁川国際空港第1ターミナルから空港リムジン・タクシーで30分前後。空港鉄道ヨンジョン駅下車後タクシー利用。ソウルのホンデ・シンチョンから直行リムジンバスの利用も可能。

入場: 海岸の公共エリアは無料。近隣のウルワンリ・ワンサン海水浴場も無料。

外国人fit: 仁川空港到着後の最初の訪問地にしたり、帰国前日の最後のコースに設定しやすいです。英語の案内板は限られているため、Naver Mapを英語設定にしてから移動することを推奨します。

タイミング: 日没1時間前(季節により変動)がゴールデンタイムです。夏の日没は19:30~20:00、冬は17:30~18:00。

マナー: 地元住民の居住地域と海岸観光エリアが混在しているため、大声や夜間の照明撮影は控えましょう。

2. カンヌン チョンドンジン — トッケビ・世界的日の出名所(#743)

場所: 江原特別自治道カンヌン市チョンドンジン路17(チョンドンジン駅徒歩1分)

作品: tvN「トッケビ」(2016~2017年)。劇中のトッケビ(コン・ユ)と死神(イ・ドンウク)のビーチシーン、チウンタクが一人で朝日を見るシーンの多くがチョンドンジンの浜辺で撮影されました。チョンドンジン駅は世界で海に最も近い鉄道駅としてギネスに登録されたことがあり(確認推奨)、それ自体が外国人観光地でもあります。

アクセス: ソウルのチョンニャンニ駅 → KTX/ITX-セマウルでチョンドンジン駅(約2時間~2時間30分)。カンヌン駅でムグンファ号に乗り換え可能。レンタカーはヨンドン高速道路カンヌンICを利用。

入場: 浜辺・駅前広場は無料。近隣のチョンドンジン時間博物館は有料(大人料金は確認推奨)。

外国人fit: 英語案内は部分的に提供。駅舎内に英語表示あり。日の出時間に到着することが鍵となるため、前日カンヌンに宿泊して早朝移動するのが現実的です。

タイミング: 日の出30分前到着が必須。夏の日の出は05:00~05:30、冬は07:30~08:00(季節ごとにリアルタイム確認が必要)。

マナー: 早朝の訪問客が多いため静かに移動しましょう。砂浜での炊事・飲酒は禁止(カンヌン市海水浴場条例)。

3. インチョン ソンド(Songdo / 송도) — ミスター・サンシャイン・BTS DNA(#743・#727・#732)

場所: 仁川広域市延寿区ソンドドン一帯(仁川地下鉄1号線セントラルパーク駅)

作品: tvN「ミスター・サンシャイン」(2018年、イ・ビョンホン主演)。仁川ソンド国際都市のセントラルパーク水辺エリアと一部の近代建築の外観が撮影に使われました。BTSの「DNA」MVもソンド一帯で撮影されています([#732] cross-ref)。

アクセス: ソウル2号線ホンデイック → 空港鉄道 → ケヤン駅乗り換え → 仁川1号線セントラルパーク駅(約1時間)。直行座席バス(ソウルのヨイド・カンナム圏発)利用時は1時間20分前後。

入場: セントラルパークは無料。トライボウル(屋外公演場・広場)は無料。テーマ体験施設の一部は有料。

外国人fit: 英語案内が比較的整った新都市です。近隣にカフェ・コンビニ・英語メニューのレストランが密集。夜景も良く、K-popファンとドラマファンが重なるスポットです。

タイミング: 夕方の夜景(19:00~22:00)または午前の散歩。週末の午後は混雑します。

マナー: 公園内の自転車専用道路の区分を確認。水上ボートは一部エリアへの進入禁止。

4. チャハムン・チョンウンドン — パラサイト アカデミー撮影地(#743)

場所: ソウル特別市鍾路区チョンウンドン・チャハムン路一帯(チャハムントンネルの上、オギンドン方面)

作品: ポン・ジュノ監督の映画「パラサイト 半地下の家族」(2019年、アカデミー賞4冠)。キテク一家(ソン・ガンホ)が雨の夜に階段を降りるシーン、半地下の路地一帯が、チョンウンドン・オギンドンの実際の路地で撮影されました。ただし半地下の内部はセットであり、実在の場所ではありません。

アクセス: 地下鉄3号線景福宮駅3番出口 → 徒歩15~20分(上り坂)。バス1020・7022番チャハムントンネル停留所下車。タクシー利用推奨(狭い路地への進入のため)。

入場: 路地・階段ともに無料(公道)。ただし住宅地のため、私有地への進入は禁止。

外国人fit: 英語案内なし。パラサイト撮影地案内アプリ(visitkoreaのパラサイトコース)や関連ブログの地図を事前にダウンロードすることを推奨します。近隣の青瓦台開放(2022年~)と組み合わせた動線を組むことも可能です。

タイミング: 昼間の訪問を推奨。夜間は住宅エリアを静かに通過する必要があります。

マナー: 実際に住民が暮らす地域です。写真撮影時に民家の窓・室内を無断で撮らないこと。ゴミの不法投棄禁止。

5. 梨泰院クラス撮影地(#710・#743)

場所: ソウル特別市龍山区イテウォン洞一帯(地下鉄6号線イテウォン駅)

作品: JTBCドラマ「梨泰院クラス」(2020年、パク・ソジュン、キム・ダミ主演)。主人公パク・セロイの屋台「タンバム」がイテウォンに設定されており、イテウォン駅1番出口付近の世界飲食通り・キョンリダン通りが主な背景です。実際の屋台セットは放送局のセットでしたが、イテウォン一帯の複数の路地で撮影されました。

アクセス: 地下鉄6号線イテウォン駅1番出口すぐ。ソウル中心部から30分以内。

入場: 通り・路地は無料。個別の飲食店・バー利用時は個別会計。

外国人fit: 英語案内は最高レベル。イテウォンはソウル内で外国人が最も密集するエリアで、英語メニュー対応率ほぼ100%の飲食店が集まっています。現金なしでカード決済がすべて可能。ハラール料理店・ベジタリアンメニューが集中するエリアでもあり、多様な食事制限に対応できます。

タイミング: 夕方~夜間(18:00~23:00)がイテウォンの街の雰囲気がドラマの感じに最も近いです。週末の夜は非常に混雑します。

マナー: イテウォンはソウルの主要な外国人居住エリアです。飲酒後の大声や住宅エリアへの立ち入りは控えましょう。ハンガンジン駅側のキョンリダン通りは住宅+商業が混在しています。

6. クァンジャン市場(Gwangjang Market / 광장시장) — イカゲーム・屋台グルメ(#743・#776)

場所: ソウル特別市鍾路区チャンギョングン路88(地下鉄1・2号線シチョン駅・チョンガク駅、または5号線クァンファムン駅から徒歩15分)

作品: Netflix「イカゲーム」(2021年)の一部シーンの背景として言及される場所であり、それ以前から韓国のモッパン(グルメ)コンテンツや複数のK-dramaの背景として頻繁に登場します(確認推奨 — イカゲームの具体的な撮影場所は公式資料での再確認が必要)。ピンデトック(緑豆チヂミ)・マヤックキンパ・ユッケビビンバが外国人の必須体験グルメとして知られています。

アクセス: 地下鉄1号線チョンガク駅11番出口 → 徒歩10分。または5号線チョンノサムガ駅12番出口 → 徒歩5分。

入場: 市場自体は無料。料理は1人前あたり3,000~15,000ウォン。

外国人fit: 英語案内は部分的。市場の商人たちは指差し・写真での注文に慣れています。Naver地図の英語レビューが充実しているため、事前に何を食べるか決めてから訪れることを推奨します。

タイミング: 午前10時~午後6時(店舗ごとに異なる)。昼(11:30~13:30)が最も混みます。午後3~5時は列が短めです。

マナー: 試食後の購入強要はありませんが、椅子に座って食べる場合は注文が前提です。写真撮影前に商人に一言断りましょう。

7. 景福宮・昌徳宮 — 雲が描いた月明り・太陽を抱いた月(#379・#743)

場所:

  • 景福宮: ソウル特別市鍾路区社稷路161(地下鉄3号線景福宮駅5番出口)
  • 昌徳宮: ソウル特別市鍾路区栗谷路99(地下鉄3号線安国駅3番出口、徒歩5分)

作品: tvN「雲が描いた月明り」(2016年、パク・ボゴム、キム・ユジョン主演)・MBC「太陽を抱いた月」(2012年)など多数の時代劇。景福宮の勤政殿・慶会楼一帯、昌徳宮の仁政殿・後苑(秘苑)が代表的な時代劇の背景です。

アクセス: 両宮とも地下鉄で直接アクセス可能。景福宮 → 昌徳宮は徒歩20分またはバス利用。

入場:

  • 景福宮: 大人3,000ウォン。外国人も同一料金。月曜休宮。
  • 昌徳宮: 大人3,000ウォン(後苑込み5,000ウォン)。後苑は予約必須(文化財庁サイト・事前予約は完売しやすい)。月曜休宮。

外国人fit: 英語・日本語・中国語の音声ガイドをレンタル可能(景福宮正門)。外国語解説ツアー(文化財庁予約、無料または少額 — 確認推奨)。ハンボックレンタルは景福宮近隣のデハンノ・プクチョン韓屋村のレンタル店を利用(3時間基準で15,000~30,000ウォン程度)。

タイミング: 午前10時前の入場が最も快適です。ハンボックレンタル後に入場する場合は17:30前の返却を考慮しましょう。夜間開場(春・秋の期間限定)は別途予約が必要です。

マナー: ハンボック着用時は入場料免除(一部時期は確認が必要)。文化財への接触・よじ登りは厳禁。

8. 全州韓屋村 — 雲が描いた月明り・史劇の背景(#743・#723)

場所: 全羅北道全州市完山区キリン大路99一帯(全州韓屋村インフォメーションセンター)

作品: tvN「雲が描いた月明り」(2016年)の撮影地として知られる全州韓屋村。700棟あまりの伝統韓屋が保存された国内最大の韓屋群であり、複数の時代劇・ドラマの背景として使われました。

アクセス: ソウル → 全州駅までKTXで1時間40分~2時間。全州駅から市内バス・タクシーで20分。スソ駅発KTX(旧SRT、2026年9月1日統合)も利用可能。

入場: 村内の通りは無料。個別体験(ハンボック、韓紙工芸、伝統料理)は有料(5,000~30,000ウォン程度)。

外国人fit: インフォメーションセンターで英語案内可能。英語メニュー対応の飲食店が増加傾向。全州ビビンバ・豆もやしスープごはんが外国人の必須体験グルメです。村内にはハンボックレンタル業者が多数あります。

タイミング: 午前9時~午後2時が空いています。週末・連休の午後は非常に混雑します。日帰りはKTX基準でソウルから半日日程が可能です。

マナー: 韓屋村内には実際に住む住民がいます。早朝・夜間の騒音・飲酒は控えましょう。私有地である韓屋の庭への無断立ち入りは禁止。

9. ナミソム — 冬のソナタ(#743・#739)

場所: 江原特別自治道春川市ナムサン面ナミソム通り1(カピョン駅から船便利用)

作品: KBS2「冬のソナタ」(2002年、ペ・ヨンジュン、チェ・ジウ主演)。ナミソムのシラカバの道・イチョウの道・芝生広場がドラマの象徴的な背景で、日本・中国・東南アジアのファン層にとって第1世代韓流の聖地です。現在も外国人訪問客の比率は約40%を維持(韓国観光公社資料 — 確認推奨)。

アクセス: ソウルのヨンサン・チョンニャンニ駅 → ITX-青春でカピョン駅(約1時間~1時間10分) → カピョン船着場 → ナミナラ共和国(ナミソム)まで船便5分。またはソウルのサンボン・東ソウルターミナルからバス(約1時間30分) → カピョンターミナル → タクシーで船着場へ移動。

入場: 大人基準13,000ウォン(船便込み・ナミナラ入場込み — リアルタイムの料金確認を推奨)。

外国人fit: 英語・日本語・中国語の案内板が全域に設置されています。英語メニューの飲食店・英語案内のシャトル。年間30ヶ国以上から訪問客が訪れ、スタッフの多言語対応レベルが高いです。

タイミング: 午前9時の始発便以降の訪問。紅葉シーズン(10月中旬~11月初め)・雪の降る冬(12月~2月)が「冬のソナタ」の雰囲気に最も近いです。桜のシーズン(4月初め)も人気です。

マナー: 自転車レンタル可能(島内移動)。一部エリアはペット同伴不可。島内のゴミは持ち帰りが原則です。

10. 多言語案内インフラ — KOCCA・KTO・visitkorea

K-drama撮影地を外国人が自力で訪問するための公式サポート体制。

  • visitkorea(英語版): https://english.visitkorea.or.kr — 地域別撮影地おすすめコース、英語地図PDFダウンロード
  • ソウル観光財団(英語版): https://english.visitseoul.net — パラサイト・イテウォン・トッケビのソウル撮影地コース提供
  • KOCCA 韓流観光情報: K-drama撮影地DB提供(確認推奨)
  • KTO 1330観光通訳: 24時間、英語・日本語・中国語・ロシア語の電話通訳サービス

FAQ 3~5

Q1. 初めて訪れるマニアに1日だけ与えるならまずどこ?

イテウォン(#5)。英語案内100%、ドラマの背景となった路地そのものが観光地で、食事・買い物も一通り解決できます。午後2時到着→夕方クァンジャン市場(#6)の組み合わせが日帰り最効率です。

Q2. 多言語ガイドはどこで手に入る?

visitkoreaの英語サイトで地域別音声ガイドPDFがダウンロードできます。景福宮・昌徳宮は現地で音声ガイドをレンタル可能。1330に電話すればリアルタイム通訳。

Q3. 費用はどれくらい準備すべき?

最低限の日帰りコース: 100,000ウォン(交通+入場+食費)。1泊カップルフルセット: 300,000~500,000ウォン。ナミソム・チョンドンジンなど郊外を追加する場合、交通費が80,000~120,000ウォン追加になります。

Q4. K-popファンも一緒に楽しめる?

BTS DNA撮影地のソンド(#3)、ミュージックバンク・人気歌謡の公開収録(KBS・MBC・SBS・別途申込必要)などと組み合わせ可能です。[#387・#732] cross-ref。

Q5. Netflixで事前に見ておくべきドラマのおすすめ順は?

①トッケビ(ヨンジョンド・チョンドンジン)②パラサイト(チョンウンドン)③梨泰院クラス(イテウォン)④冬のソナタ(ナミソム)⑤雲が描いた月明り(景福宮・全州)。OTTサービスごとの配信有無はリアルタイムで確認してください。
