🎯 如何使用这份指南

这份指南介绍的是地方温泉地区和温泉设施共19处。首尔和近郊的汗蒸房、Icheon Termeden、Busan Heosimcheong 在#749 韩国冬季汗蒸温泉9选中介绍过，大田 Yuseong 和釜山 Dongnae 则各有单独一篇。#749 里也简单提到了德邱温泉·温阳温泉·水安堡温泉·牙山 Spavis，但确认日期不同，数值可能不一样。例如德邱温泉 Spa World 旺季费用，#749(2026-10-12 确认)写的是 36,000韩元，本篇(2026-11-19 确认)写的是普通 38,000韩元。

这些地方按两个标准挑选。一个是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“我的汗蒸房·水疗”主题入选的温泉中挑选的地方，表中写了投票排名和得票数。白岩温泉旅游特区本身在投票中排第34名。另一个是虽然没有以地区为单位入选投票、但在观光公社登记为旅游景点的温泉地区·设施(温阳温泉地区·水安堡温泉旅游特区·水安堡温泉足浴路·釜谷温泉旅游特区)，表中写作“区域单位未入选投票”。

投票名称与观光公社名称不同的地方(例如投票名“庆州 The K Hotel Gyeongju Spa 温泉”=观光公社名“The K Hotel 庆州”)，以地址和观光公社编号对应。本篇并没有收入投票中入选的全部温泉，襄阳 Seolhaewon·Yesan Splas Resom 等地方没有收入本指南。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值，没有登记值的栏写作“无登记值”。观光公社介绍文里的疾病疗效表述不是医学依据，所以没有照录。

📍 温泉地区 — 温阳温泉·水安堡温泉·釜谷温泉·白岩温泉

温阳温泉地区 (Onyang Oncheon Jigu / 온양온천지구)的地址是牙山市 (Oncheon-dong / 온천동)，☎ 温阳温泉站游客咨询处 (Onyang Oncheon-yeok Gwangwang Annaeso / 온양온천역 관광안내소) 041-540-2517。这是一个历史悠久的温泉地区，据韩国观光公社介绍，朝鲜时代有多位国王建温宫并在此停留的记录留存至今。这里温泉浴场和住宿设施集中，还有 Sinjeongbi 和 Yeonggoedae 等文化遗产。同一地区的温阳观光酒店大温泉浴场在投票中排第67名(82票)，但观光公社没有运营信息，所以没有单独收录。

  • 开放时间·休息日·费用:登记为因温泉而异。

Paradise Spa 道高 (Dogo / 도고)的地址是牙山市 (Dogo-myeon Dogoncheon-ro 176 / 도고면 도고온천로 176)，☎ 041-537-7100。据韩国观光公社介绍，这是行政安全部指定的国民保养温泉 (Gungmin Boyang Oncheon / 국민보양온천)中的Chungcheong-do 第1号，是一处大型温泉度假设施。总面积24,622㎡，有 Bade Pool 和硫磺温泉水温泉大浴场、戏水设施，冬季介绍说会运营五加皮汤·生姜汤·橘皮汤等。

  • 开放时间·费用:登记为因季节而异。休息日:全年无休。

牙山 (Asan / 아산) Spavis的地址是牙山市 (Eumbong-myeon Asanoncheon-ro 157beon-gil 67 / 음봉면 아산온천로157번길 67)，☎ 041-539-2000。这是使用牙山温泉水的综合温泉设施。有室内 Bade Pool、室外温泉池、温泉场，以及75m造浪池和滑道。

  • 开放时间:09:00~18:00。休息日:全年无休(每年3月中休馆2周)。费用:登记为设施使用费 50,000韩元。

水安堡温泉旅游特区 (Suanbo Oncheon Gwangwangteukgu / 수안보온천 관광특구)的地址是忠州市 (Suanbo-myeon Jujeongsan-ro 12 / 수안보면 주정산로 12)，☎ 043-846-3605。这是一处历史悠久的温泉度假地。据韩国观光公社介绍，这里是从地下250m涌出的弱碱性温泉，由忠州市直接管理温泉水。大多数人住在地区内的酒店·汽车旅馆里泡温泉，中心有温泉水流过的 Multang 公园。登记有游客咨询处备有英语·中文·日语地图。同一地区的 Suanbo Oncheon Land 在投票中排第44名(94票)，但观光公社没有运营信息，所以没有单独收录。

  • 开放时间:常年开放。休息日:全年无休。费用:免费(旅游特区本身)。

水安堡温泉足浴路 (Suanbo Oncheon Jokyokgil / 수안보온천 족욕길)的地址是忠州市 (Suanbo-myeon Jujeongsan-ro 35 / 수안보면 주정산로 35)，☎ Suanbo 游客咨询处 (Suanbo Gwangwang Annaeso / 수안보관광안내소) 043-845-7829。这是用水安堡温泉水泡脚的足浴设施。据韩国观光公社介绍，朝鲜王朝实录 (Joseon Wangjo Sillok / 조선왕조실록)里有太祖李成桂 (Taejo Yi Seong-gye / 태조 이성계)使用水安堡温泉的记录。

  • 开放时间:3~11月 12:00~20:00，12~2月 12:00~17:00。
  • 休息日:每周一，冬季每周一·周二。费用:免费。

Suanbo Park Hotel的地址是忠州市 (Suanbo-myeon Tapgol 1-gil 36 / 수안보면 탑골1길 36)，☎ 043-846-2331。这是一家设有露天温泉池、天然温泉和室内游泳池的酒店。客房共111间。

  • 入住:15:00，退房:11:00。温泉使用时间·费用为无登记值。

釜谷温泉旅游特区 (Bugok Oncheon Gwangwangteukgu / 부곡온천 관광특구)的地址是昌宁郡 (Bugok-myeon Geomun-ri / 부곡면 거문리)，☎ 昌宁郡厅温泉科 (Changnyeong Gunscheong Oncheon-tim / 창녕군청 온천팀) 055-530-1591。1981年被指定为旅游特区。据韩国观光公社介绍，因形似大铁锅而被称为釜谷 (Bugok / 부곡)，这里集中了酒店·度假公寓·温泉浴场。有两处足浴场(Hanul Park·Small Park)。

  • 足浴场:周六·周日·公共假日 14:00~18:00。7~8月，1月1日，春节·中秋节当天休息。足浴场费用为无登记值。
  • 住宿·温泉浴场:登记为因设施而异。

白岩温泉旅游特区 (Baegam Oncheon Gwangwangteukgu / 백암온천 관광특구)的地址是蔚珍郡 (Onjeong-myeon Oncheon-ro 5 / 온정면 온천로 5)，☎ 054-789-5480。1979年被指定为旅游特区。据韩国观光公社介绍，这是从新罗 (Silla / 신라)时代起就为人所知的温泉，可以同时看到白头大干 (Baekdudaegan / 백두대간)的山势和东海。温泉水无色无味。

  • 开放时间·休息日:登记为因设施而异。

📍 山麓·度假村温泉 — 德邱温泉·五色·Cheoksan·鹤驾山·Solsaem

德邱温泉 (Deokgu Oncheon / 덕구온천) Spa World的地址是蔚珍郡 (Buk-myeon Deokguoncheon-ro 924 / 북면 덕구온천로 924)，☎ 054-782-0677。据韩国观光公社介绍，这是行政自治部(现行政安全部)认定的Gyeongsangbuk-do 第1号国民保养温泉，是位于应峰山 (Eungbongsan / 응봉산)半山腰的自然涌出温泉。介绍说温泉水不加热也不冷却。登记有英语·日语指引。

  • 开放时间:大温泉场 06:00~22:00，Spa World 工作日 10:00~19:00·周末 10:00~20:00。休息日:全年无休。
  • 费用(设施使用费):淡季工作日普通 26,000韩元，淡季周末普通 32,000韩元，旺季普通 38,000韩元。

五色碳酸温泉 (Osaek Tansan Oncheon / 오색탄산온천)的地址是襄阳郡 (Seo-myeon Daecheongbong-gil 34 / 서면 대청봉길 34)，☎ 033-670-0880。这是位于海拔647m的 Osaek Greenyard Hotel 内的温泉。据韩国观光公社介绍，这是南雪岳山国立公园内唯一的复合温泉酒店。

  • 开放时间:工作日 06:00~22:00，周末 06:00~23:00。休息日:全年无休。
  • 费用:成人 18,000韩元，儿童(8~13岁) 13,000韩元。登记有可能变动。

Cheoksan 温泉度假村 (Cheoksan Oncheon Hyuyangchon / 척산온천휴양촌)的地址是束草市 (Gwangwang-ro 327 / 관광로 327)。这是1985年开业的温泉住宿设施。据韩国观光公社介绍，这里涌出53℃的温泉水，客房里有温泉水按摩浴缸，住客可免费使用大众温泉1次。还有汗蒸房、金刚松散步道和雪岳山 (Seoraksan / 설악산)山脊瞭望台。

  • 开放时间·休息日·费用:无登记值。

安东鹤驾山温泉 (Andong Hakgasan Oncheon / 안동 학가산온천)的地址是安东市 (Seohu-myeon Hakgasanoncheon-gil 14 / 서후면 학가산온천길 14)，☎ 054-850-4690。据韩国观光公社介绍，位于鹤驾山东南侧，是从地下690~940m岩层涌出的碱性温泉，可同时容纳1,200余人。屋顶有可眺望鹤驾山·Cheondeungsan 的观景设施。

  • 开放时间:06:00~20:00。休息日:每月第一个·第三个周一，春节·中秋节当天。
  • 费用:成人普通 6,500韩元，儿童(4~6岁)·老人(65岁以上) 5,000韩元。登记有可能变动。

Sonobel 青松 Solsaem 温泉 (Sonobel Cheongsong Solsaem Oncheon / 소노벨 청송 솔샘온천)的地址是青松郡 (Juwangsan-myeon Sono-ro 38 / 주왕산면 소노로 38)的 Sonobel 青松 (Sonobel Cheongsong / 소노벨 청송)地下3层，☎ 1588-4888。这是度假村内的温泉。有 Hinoki 桧木浴池和水中按摩设施。

  • 开放时间:07:00~21:00(休息时间 13:00~14:00)。休息日:全年无休。
  • 费用:成人 20,000韩元，儿童 15,000韩元。

📍 南部温泉 — 庆州·昌原·巨济·高敞

The K Hotel 庆州 (The K Hotel Gyeongju / 더케이호텔 경주)的地址是庆州市 (Expo-ro 45 / 엑스포로 45)，☎ 054-745-8100。这是位于普门园区 (Bomun Danji / 보문단지)的酒店，据韩国观光公社介绍，可以同时游览遗迹和泡温泉。有温泉桑拿和室内外游泳池，客房共267间。投票时的名称是“庆州 The K Hotel Gyeongju Spa 温泉”。

  • 入住:15:00，退房:11:00。温泉使用时间·费用为无登记值。

昌原马金山温泉 (Changwon Mageumsan Wontang / 창원 마금산원탕)的地址是昌原市 (Uichang-gu Bungmyeon Cheonju-ro 1167 / 의창구 북면 천주로 1167)，☎ 055-298-4400。也叫 Bungmyeon 温泉。据韩国观光公社介绍，这是水温55℃以上的弱碱性温泉，东国舆地胜览 (Dongguk Yeoji Seungnam / 동국여지승람)里有温泉水的记载。有2人使用的家庭浴池。观光公社信息的最后修改日期是2025年3月，所以费用·时间可能已经变动。

  • 开放时间:温泉 05:00~21:00，家庭浴池24小时。休息日:全年无休。
  • 费用:大众汤成人 8,000韩元，家庭浴池(包时)2小时2人 25,000韩元。登记为大众汤禁止满4岁以上混浴。

巨济岛海水保养温泉 (Geojedo Haesu Boyang Oncheon / 거제도해수보양온천)的地址是巨济市 (Suyang-ro 507 / 수양로 507)，☎ 0507-1432-3011。据韩国观光公社介绍，这是行政安全部指定的国内第10号国民保养温泉。这是从地下800m岩层涌出的弱碱性弱食盐泉，有室内温泉·家庭温泉·汗蒸房·游泳池。

  • 开放时间:05:00~22:30。休息日:每月第二个周五。
  • 费用:普通 10,000韩元，家庭浴池普通 40,000韩元。登记为只有家庭温泉可以预约。

Oreve Hot Spring & Spa的地址是西归浦市 (Taepyeong-ro 152 / 태평로 152)，☎ 064-901-3300。据韩国观光公社介绍，这是济州唯一被行政安全部指定为保养温泉的温泉水疗设施。使用从地下2,003m涌出的碳酸温泉水，有8个露天池和室外无边泳池。
