한국 전 6종 매트릭스 — 녹두빈대떡·파전·해물파전·감자전·김치전·동그랑땡 풀세트

부제: 외국인 관광객용 광장시장·포장마차·명절·핫바 막걸리 페어 정통

ISSUE 03 · #882 · 2026-06-09

🎯 왜 한국 전 매트릭스인가

외국인 한국 전 페인포인트 = "파전만 알고 다른 전 모름". 한국 전 = 광장시장 vlog #1 + 비 오는 날 막걸리 페어 + 명절 정통. 같은 "Korean savory pancake"라도 녹두빈대떡 (광장 vlog #1·녹두 정통)·파전 (글로벌 #1·대파 정통)·해물파전 (회 cluster cross·해산물)·감자전 (강원 정통·강원 막걸리 페어)·김치전 (해장·MZ 인스타)·동그랑땡 (명절·제사 정통) 각자 다른 재료·매니아. 외국인은 (a) 광장시장 vlog 빈대떡 모름 (b) 비 오는 날 막걸리 페어 모름 (c) 명절 동그랑땡 정통 모름 (d) 감자전 = 강원 정통 모름. 본 가이드는 6종 매트릭스 + 광장 vlog + 막걸리 페어.

강원 정통 = 감자전 + 강원 막걸리

명절 정통 = 동그랑땡 (설날·추석)

🥞 6종 deep dive

🥒 녹두빈대떡 (Nokdu-bindaetteok) — 광장 vlog #1

  • 시그니처: 광장시장 vlog #1·녹두 정통·옛 정통 음식
  • 재료: 녹두 (갈아서) + 돼지고기 + 숙주·고사리·김치
  • 외국인 친화도: ★★★★★ (#1 광장 vlog)
  • 추천 매장:
  • 광장시장 빈대떡 골목 — vlog #1 정통
  • 남대문 빈대떡 — 정통
  • 시기: 사계절
  • 가격: 광장시장 = 5,000~12,000원/1개

🌿 파전 (Pajeon) — 비 오는 날 #1

  • 시그니처: 글로벌 #1·비 오는 날 막걸리 페어 #1
  • 재료: 대파 (Green onion) + 밀가루·계란
  • 외국인 친화도: ★★★★★ (글로벌 #1)
  • 추천 매장: 한정식·전통주점·MZ 한식당·광장시장
  • 시기: 사계절·비 오는 날 #1 (한국 문화)
  • 가격: 8,000~20,000원/1접시

🦐 해물파전 (Haemul-pajeon) — 부산 정통

  • 시그니처: 부산 정통·해산물 cross
  • 재료: 대파 + 오징어·새우·조개·해산물 + 밀가루
  • 외국인 친화도: ★★★★ (해산물 매니아)
  • 추천 매장: 부산 정통·자갈치·MZ 한식당
  • 가격: 15,000~30,000원/1접시

🥔 감자전 (Gamja-jeon) — 강원 정통

  • 시그니처: 강원 정통·얇음·강원 막걸리 페어
  • 재료: 감자 (갈아서·얇게) + 밀가루 적게
  • 외국인 친화도: ★★★★ (강원 정통)
  • 추천 매장: 강원 노포·평창·정선·MZ 한식당
  • 가격: 8,000~15,000원/1접시

🌶 김치전 (Kimchi-jeon) — 해장·MZ

  • 시그니처: 해장·MZ 인스타·가성비
  • 재료: 김치 + 밀가루·계란
  • 외국인 친화도: ★★★★ (가성비)
  • 추천 매장: 가정식·MZ 한식당·체인
  • 가격: 7,000~15,000원/1접시

🥩 동그랑땡 (Donggeurang-ttaeng) — 명절·제사

  • 시그니처: 명절·제사 정통 #1·설날·추석
  • 재료: 다진 고기 (돼지·소) + 두부·당근·양파 + 계란 옷
  • 외국인 친화도: ★★★ (명절 정통)
  • 추천 매장: 한정식·가정식 명절 정통
  • 시기: 음력 설날·추석 (#846)·명절 식사
  • 가격: 한정식 무료 / 시장 = 10,000~20,000원/팩

🍶 비 오는 날 막걸리 페어 (한국 문화)

☔ "비 오는 날 = 파전 + 막걸리" 정통

  • 한국 문화: 비 오는 날 = 파전·빈대떡 + 막걸리 페어
  • 이유: 빗소리 + 파전 부치는 소리 + 막걸리 = 한국 정통 분위기
  • MZ 트렌드: SNS·인스타 비 오는 날 파전 인증 #1
  • 추천 매장: 광장시장 빈대떡·전통주점·MZ 한식당

  • 가격: 2,000~5,000원/1개

⚠ 외국인 자주 실수 5가지

1. "전 = 파전만": 전 = 6종 매트릭스 (녹두·파·해물·감자·김치·동그랑땡).

2. "비 오는 날 = 우연": 비 오는 날 = 파전 + 막걸리 #1 한국 문화 (정통).

3. "녹두 = 콩": 녹두 (mung bean) = 빈대떡 정통·콩과 다름.

4. "광장시장 빈대떡 = 일반": 광장시장 빈대떡 = vlog #1 정통.

5. "동그랑땡 = 일반 미트볼": 동그랑땡 = 명절·제사 정통·계란 옷 정통.

⚙ FAQ 8개

1. 외국인 입문 1순위: 파전 + 김치전 (글로벌) → 녹두빈대떡 (광장 vlog).

2. 인스타·vlog: 광장 녹두빈대떡 (#1)·비 오는 날 파전·강원 감자전.

3. MZ 트렌드: 김치전·MZ 한식당·핫바.

4. 막걸리 매니아: 파전 + 막걸리 (#1 비 오는 날).

5. 명절 매니아: 동그랑땡 (설날·추석 정통).

6. 알레르기: 밀가루 글루텐·해산물 (해물파전)·돼지·계란·녹두 사전 고지.

7. 결제·팁: 시장 = 현금·카드 / 한식당 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

전 = 일반 음식·기름 사용. 임신부·어린이 = OK. 알레르기 (밀가루 글루텐·해산물·돼지·계란·녹두) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 파전 채식·감자전·김치전 = OK (돼지·갑각류 함유 일부 매장 사전 확인).
  • 채식·비건: 파전·감자전·김치전 채식 OK (계란 옵션) / 녹두빈대떡·해물파전·동그랑땡 = 비채식.
  • 글루텐 free: 밀가루 함유 → 글루텐 free 어려움·감자전 = 밀가루 적음 (사전 확인).
