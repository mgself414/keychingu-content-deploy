韩国发酵·酱 (Jang) 文化 — 为什么韩国美食的味道源于“时间”而非香料

> 大酱 (Doenjang)、酱油 (Ganjang)、辣椒酱 (Gochujang)、清麴酱 (Cheonggukjang)、酱块 (Meju)、酱缸台 (Jangdokdae) — 为外国人准备的韩国发酵文化解读。不是“介绍泡菜种类”，而是“为什么·是什么·如何”。

在韩国餐厅，外国人舀起一勺大酱汤 (Doenjang-jjigae / 된장찌개) 时，最常问的问题是：“这种深邃的味道到底是从哪里来的？明明没有放肉啊。” 答案不是香料，而是时间。韩国美食的基底几乎总是酱 (Jang / 장) — 由发酵大豆制成的大酱 (Doenjang / 된장)、酱油 (Ganjang / 간장)、辣椒酱 (Gochujang / 고추장)、清麴酱 (Cheonggukjang / 청국장) — 而这些酱是经过数月乃至数年，有些家族甚至传承了数百年的发酵成果。外国人通常只想到泡菜 (Kimchi / 김치) 这一种韩国发酵食品，但泡菜只是冰山一角。真正的根源在于制酱。这项传统有多深厚呢？2024年12月，联合国教科文组织 (UNESCO) 将“韩国制酱文化”列入人类非物质文化遗产名录 (制作泡菜的“越冬泡菜文化 (Gimjang / 김장)”已于2013年入选)。本文并非“在哪里购买” (→ 参见交叉链接)，而是从外国人的视角，解读为什么韩国美食以发酵为核心，以及其中蕴含的思维方式、历史和哲学。这是韩国文化解读系列第三篇。

★ 一目了然 — 韩国的四大酱 (Jang)

酱 (Jang / 장) 是什么 发酵方式 一句话总结
大酱 (Doenjang / 된장) 大豆发酵酱 酱块 (Meju / 메주) + 盐水，数月至数年 韩式汤和炖菜的“深邃味道”基底。比日本味噌 (Miso) 更粗糙浓郁
酱油 (Ganjang / 간장) 大豆发酵液 (酱汁) 与大酱 (Doenjang / 된장) 在同一缸中分离 所有菜肴的咸味·鲜味。越陈越珍贵
辣椒酱 (Gochujang / 고추장) 辛辣·甜味发酵酱 酱块粉 + 糯米 + 辣椒粉 + 麦芽糖 拌饭 (Bibimbap / 비빔밥)·炒年糕 (Tteokbokki / 떡볶이) 的红色。韩国独有 (世界无同类)
清麴酱 (Cheonggukjang / 청국장) 快速发酵大豆 煮熟的大豆 2~3天短期发酵 气味浓烈·粘稠。日本纳豆 (Natto) 的近亲

> 核心: 大酱 (Doenjang / 된장) 和酱油 (Ganjang / 간장) 是从相同原料 (酱块 (Meju / 메주)) 分离出来的兄弟。辣椒酱 (Gochujang / 고추장) 是韩国独有的发酵辣椒酱，清麴酱 (Cheonggukjang / 청국장) 的发酵时间最短。这四种酱统称为酱 (Jang / 장)。

⚠️ 外国人常有的3个误解

1. “韩国发酵 = 泡菜 (Kimchi / 김치)” ❌ — 泡菜只是蔬菜发酵。韩国发酵文化的真正支柱是豆类发酵，即酱 (Jang / 장)。几乎所有韩式汤、炖菜和调味料的基底都离不开大酱 (Doenjang / 된장)、酱油 (Ganjang / 간장)、辣椒酱 (Gochujang / 고추장)。联合国教科文组织 (UNESCO) 将越冬泡菜文化 (Gimjang / 김장) (2013年) 和制酱文化 (2024年) 分别列入人类非物质文化遗产 — 这足以说明两者是独立的巨大传统。

2. “发酵 = 只是放久了·变质了” ❌ — 发酵并非放任不管，而是驯服微生物的精密控制。大豆蛋白质在微生物 (霉菌·细菌) 的作用下分解成氨基酸，从而产生鲜味 (umami)。这就是不添加味精也能产生浓郁味道的原因。

3. “大酱 (Doenjang / 된장) = 日本味噌 (Miso)” ❌ — 相似但不同。味噌通常使用米曲 (koji)，口感细腻偏甜；而大酱 (Doenjang / 된장) 是将整块酱块 (Meju / 메주) 放入盐水中浸泡，因此更粗糙、浓郁、香醇。最重要的是，大酱 (Doenjang / 된장) 具有与酱油 (Ganjang / 간장) 在同一缸中分离出来的独特制作方法 (见下文③)。

① 为什么是发酵 — 寒冷半岛发现的“时间储存法”

对韩国人来说，发酵在成为一种偏好之前，首先是生存技术。在漫长冬季的朝鲜半岛，没有冰箱的时代，要全年吃到蛋白质和蔬菜，“储存”是必需的，而发酵就是答案。

  • 盐 + 时间 = 保存: 将煮熟的大豆与盐一起发酵，既能防止腐败，又能使味道和营养更加深厚 (泡菜 (Kimchi / 김치) 也是同样的原理)。
  • 物尽其用: 从同一锅大豆中同时获得大酱 (Doenjang / 된장) 和酱油 (Ganjang / 간장) 的制作方法 (③) 是一种充分利用资源的智慧。
  • “时间是食材”: 韩国发酵的核心哲学。好的酱无法快速制成。熟成即是美味，在韩国有句俗语：“酱味好，菜味才好” — 因为所有菜肴的起点都是酱。

也就是说，韩国发酵并非“异国风味”，而是为了度过漫长冬季而磨砺出的韩式料理基本设施。

② 四种酱 (Jang / 장) — 大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장)·辣椒酱 (Gochujang / 고추장)·清麴酱 (Cheonggukjang / 청국장)

大酱 (Doenjang / 된장) — 深邃味道的基底

将煮熟的大豆发酵制成的酱块 (Meju / 메주) 放入盐水中，经过数月至数年发酵而成的棕色大豆酱。它是大酱汤 (Doenjang-jjigae / 된장찌개)·大酱锅 (Doenjang-guk / 된장국) 的基底，韩式料理中“香醇浓郁的深邃味道”几乎都源于此。煮得越久越浓郁，陈年越久越珍贵。

酱油 (Ganjang / 간장) — 同一缸中分离出的兄弟

在制作大酱 (Doenjang / 된장) 的同一个缸中，将酱块 (Meju / 메주) 渗出的咸味液体捞出，单独熟成而成的就是酱油 (Ganjang / 간장)。也就是说，大酱 (Doenjang / 된장) 和酱油 (Ganjang / 간장) 同根同源 (这个分离过程称为“分酱 (Jang Gareugi / 장 가르기)” → ③)。酱油 (Ganjang / 간장) 分为国酱油 (Gukganjang / 국간장)·陈年酱油 (Jinganjang / 진간장) 等，陈年越久颜色越深，咸味减淡，鲜味 (umami) 更加突出。

辣椒酱 (Gochujang / 고추장) — 世界独有的发酵辣椒酱

将酱块粉 + 糯米 (或大麦) + 辣椒粉 + 麦芽糖混合发酵而成的辛辣、甜美、鲜味十足的红色酱。它是拌饭 (Bibimbap / 비빔밥)·炒年糕 (Tteokbokki / 떡볶이)·烤鱼调味料的红色来源。它不仅仅是简单的“辣酱”，而是发酵而成的复合调味料，这是决定性的区别 — 因此，辣味之后伴随着甜味和深度。全罗北道 (Jeollabuk-do / 전라북도) 淳昌 (Sunchang / 순창) 以辣椒酱 (Gochujang / 고추장) 产地闻名。

清麴酱 (Cheonggukjang / 청국장) — 最快的发酵

与前三种不同，清麴酱 (Cheonggukjang / 청국장)不使用酱块 (Meju / 메주)，而是将煮熟的大豆在温暖处 (约40°C) 仅短期发酵2~3天。其特点是粘稠的拉丝和浓烈的气味 (与日本纳豆 (Natto) 类似)。气味浓烈对外国人来说可能是一个门槛，但它作为发酵食品，深受健康饮食爱好者的喜爱。

③ 酱块 (Meju / 메주) 和酱缸台 (Jangdokdae / 장독대) — 发酵的“引擎”和“家”

酱块 (Meju / 메ju) — 所有酱的起点

大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장)·辣椒酱 (Gochujang / 고추장) 几乎都始于酱块 (Meju / 메주)。将煮熟的大豆捣碎，塑成砖块状，然后悬挂在温暖处使其长出霉菌，这就是酱块 (Meju / 메주)。此时，大豆上会附着天然微生物 (如曲霉 Aspergillus、枯草芽孢杆菌 Bacillus 等)，这些微生物随后会分解大豆蛋白质，产生鲜味 (umami) 和香气。因此，“酱块 (Meju / 메주) 决定酱的味道” — 酱块 (Meju / 메주) 就是发酵的引擎。

> 分酱 (Jang Gareugi / 장 가르기): 将发酵好的酱块 (Meju / 메주) 放入盐水中浸泡约两个月，就会分离出上层的清澈酱油 (Ganjang / 간장) 和沉淀的大酱 (Doenjang / 된장) 渣。将两者分开的过程就是“分酱 (Jang Gareugi / 장 가르기)”。从一锅大豆中得到两种酱，是韩国发酵最优雅的瞬间。

酱缸台 (Jangdokdae / 장독대) — 瓮器 (Onggi / 옹기) 呼吸的地方

发酵好的酱会装入瓮器 (Onggi / 옹기) (陶罐) 中，在酱缸台 (Jangdokdae / 장독대) — 家中阳光充足、集中放置陶罐的地方 — 进行熟成。瓮器 (Onggi / 옹기) 不仅仅是容器。

  • 会呼吸的器皿: 瓮器 (Onggi / 옹기) 的陶壁上有微小的孔隙，可以让空气流通。这种微小的空气交换为发酵微生物创造了理想的环境 — 这是塑料或玻璃容器无法模仿的。
  • 阳光与呵护: 晴天打开盖子晒太阳，下雨时盖上，日常的照看和打理成就了酱的味道。酱缸台 (Jangdokdae / 장독대) 不仅仅是储存室，更是家庭生活的中心，也是母亲·祖母的领域。

④ 联合国教科文组织 (UNESCO) 与历史 — “制酱行为”本身成为遗产

韩国的制酱文化超越了简单的烹饪方法，被认定为社区文化。

  • 2024年12月3日，在巴拉圭 (Paraguay) 亚松森 (Asunción) 举行的第19届非物质文化遗产保护公约政府间委员会会议上，“韩国制酱文化 (Knowledge, beliefs and practices related to jang-making)” 被列入联合国教科文组织 (UNESCO)人类非物质文化遗产代表作名录。
  • 这是继越冬泡菜文化 (Gimjang / 김장) (2013年入选) 之后，第二个入选的饮食领域遗产。两项传统分别获得认可的事实本身，就展现了韩国发酵文化的广度和深度。
  • 联合国教科文组织 (UNESCO) 关注的不是“最终的味道”，而是“共同制作和分享的行为”。家人聚在一起制作酱块 (Meju / 메주)、分酱 (Jang Gareugi / 장 가르기)，以及制酱技术从母亲传给女儿·儿媳的过程，培养了社区的和平与团结。

> 参考: 大豆发酵本身是东亚的共同传统，但将整块酱块 (Meju / 메ju) 发酵，并在同一缸中分离出大酱 (Doenjang / 된장) 和酱油 (Ganjang / 간장) 的制作方法，以及辣椒酱 (Gochujang / 고추장) 这种发酵辣椒酱，被认为是韩国独有的特点。

⑤ “酱味 = 家族的身份” — 种酱油 (Ssiganjang / 씨간장) 这一活生生的族谱

韩国发酵文化中最令人印象深刻的概念是种酱油 (Ssiganjang / 씨간장)。

  • 种酱油 (Ssiganjang / 씨간장) = 从熟成的酱油中挑选出最好的，像种子一样保留下来世代相传的酱油。每年制作新酱油时，舀一勺陈年种酱油 (Ssiganjang / 씨간장) 加入 (这称为添酱 (Deotjang / 덧장))，其中的有益微生物和风味就会转移到新酱中 — 这种方式就像不让火种熄灭一样传承味道。
  • 因此，名门望族的种酱油 (Ssiganjang / 씨간장) 短则传承100年，长则数百年 (有报道称，一些宗家 (Jongga / 종가) 的酱油已有350~370年历史 — 具体年数因家族说法而异，建议核实)。每家每户的微生物构成不同，味道也不同，所以种酱油 (Ssiganjang / 씨iganjang) 实际上就是“味道的族谱”。
  • 酱油 (Ganjang / 간장) 也根据陈年程度而有不同的名称 — 刚酿造的新酱油 (Haetganjang / 햇간장)，陈年数年的中间酱油 (Jungganjang / 중간장)，以及陈年5年以上、颜色深黑、鲜味 (umami) 盖过咸味的陈年酱油 (Jinganjang / 진간장)。时间成为了等级。

这个概念清晰地展现了韩国发酵的哲学：酱味并非某一个人的手艺，而是一个家族世代相传的微生物生态系统和身份认同。

⑥ 现代的酱 (Jang / 장) — 市售与传统，以及如何享用

如今，大多数韩国人会在超市购买工厂生产的酱。这是传统手艺和工业生产并存的景象。

  • 市售酱: 标准化、价格低廉、方便，占据了日常烹饪的大部分。由于发酵时间短或酿造方式不同，其风味深度可能与传统酱有所差异。
  • 传统 (土法) 酱: 从酱块 (Meju / 메주) 开始制作，在瓮器 (Onggi / 옹기) 中长时间熟成的酱。由名匠、宗家 (Jongga / 종가)、寺庙、农家传承，被视为高端产品。对外国人来说，品尝这种“土法酱”才是真正的发酵体验。
  • 享用方法: 大酱汤 (Doenjang-jjigae / 된장찌개)·浓大酱 (Gangdoenjang / 강된장) (大酱 (Doenjang / 된장))、拌饭 (Bibimbap / 비빔밥)·炒年糕 (Tteokbokki / 떡볶이) (辣椒酱 (Gochujang / 고추장))、凉拌菜·炖菜 (酱油 (Ganjang / 간장))，几乎所有韩式料理中都能见到它们。在餐厅里，一句“这是自家酿的酱吗？” 就能让店主自豪地为你讲解。

⑦ 外国人视角 — 作为素食·健康食品的酱 (Jang / 장)

酱 (Jang / 장) 出乎意料地适合外国人的餐桌。特别是对素食·纯素食旅行者来说，优势巨大。

  • 天然鲜味 (无需味精): 发酵将大豆蛋白质转化为氨基酸，自然产生鲜味 (umami)。这是无需人工调味料也能产生浓郁味道的秘诀，对追求纯净风味的外国人很有吸引力。
  • 基本为植物性: 传统大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장) 仅由大豆·水·盐制成，本身就是纯素 (辣椒酱 (Gochujang / 고추장) 也大多是植物性)。它成为素食料理中无需动物性食材也能获得深邃味道的核心武器。
  • 寺庙饮食 (Sachal-eumsik / 사찰음식) 的基础: 韩国寺庙在不使用大蒜·葱的情况下，需要做出深邃的味道，因此酱 (Jang / 장) 的发酵鲜味 (umami) 至关重要。这也是寺庙直接制作大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장)·辣椒酱 (Gochujang / 고추장) 的原因 (→ [#800 寺庙饮食](800_temple_food.md))。
  • 肠道健康: 作为发酵食品，它含有益生菌，对关注健康饮食·肠道健康的人群也有吸引力 (功效的具体数值避免夸大，避免医学断言)。

> 外国人初次尝试推荐: 大酱汤 (Doenjang-jjigae / 된장찌개) (最温和普遍) → 拌饭 (Bibimbap / 비빔밥) 中的辣椒酱 (Gochujang / 고추장) (辛辣·甜味入门) → 习惯气味后尝试清麴酱 (Cheonggukjang / 청국장)。如果是素食旅行者，一桌寺庙饮食 (Sachal-eumsik / 사찰음식) 最能展现酱 (Jang / 장) 的真正价值。

❓ 外国人常见问题 (FAQ)

  • 大酱 (Doenjang / 된장) 和日本味噌 (Miso) 有什么不同？ — 味噌使用米曲 (koji)，口感细腻偏甜；大酱 (Doenjang / 된장) 是将整块酱块 (Meju / 메주) 放入盐水中浸泡，因此更粗糙、浓郁。最重要的是，大酱 (Doenjang / 된장) 具有与酱油 (Ganjang / 간장) 在同一缸中分离出来的独特制作方法。
  • 辣椒酱 (Gochujang / 고추장) 不就是普通的辣酱吗？ — 不是。它是发酵而成的复合调味料，辣味之后伴随着甜味·鲜味 (umami)。世界上没有相同的发酵辣椒酱 (Gochujang / 고추장)。
  • 清麴酱 (Cheonggukjang / 청국장) 为什么气味浓烈？ — 因为它不使用酱块 (Meju / 메주)，而是将大豆在高温下短期发酵2~3天。它与纳豆 (Natto) 类似，气味浓烈但作为健康食品深受喜爱。初次尝试建议从大酱 (Doenjang / 된장) 开始。
  • 我是素食者，可以吃韩式发酵酱吗？ — 传统大酱 (Doenjang / 된장)·酱油 (Ganjang / 간장) 仅含大豆·水·盐，通常是纯素的。但市售产品可能添加凤尾鱼·海带，建议查看标签。寺庙饮食 (Sachal-eumsik / 사찰음식) 餐厅可以放心享用。
  • 在哪里可以买到好的酱 (Jang / 장)？ — 本文是关于发酵·酱 (Jang / 장) 的“为什么·是什么” 的解读，购买地点请参考其他指南 (→ 参见下方交叉链接)。如果作为礼物，传统土法酱·名匠酱 (Jang / 장) 更具意义。
