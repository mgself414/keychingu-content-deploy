韩国发酵与发酵文化——为什么韩国菜的味道来自“时间”？

黄豆酱、酱油、辣椒酱、清国酱、豆酱、大酱 — 为外国人讲解韩国发酵文化。不是“泡菜类型介绍”，而是“为什么、什么以及如何”。

有一个问题是外国人在韩国餐馆吃完一勺大酱后最常问的问题。 “这浓浓的味道到底是从哪里来的？里面没有肉。”答案不是香料，而是时间。韩国食物几乎总是覆盖着由大豆发酵制成的大酱（酱油、酱油、红辣椒酱和清谷酱），而这种酱是经过数月或数年发酵的结果，在一些家庭中，甚至是数百年。当外国人想到韩国发酵时，只想到泡菜，但泡菜只是冰山一角。真正的根源是打酱油。这一传统如此深厚，以至于2024年12月，联合国教科文组织将“韩国大酱制作文化”登记为人类非物质文化遗产（制作泡菜的“泡酱文化”已于2013年被列入）。本文不是关于“哪里买”（→交叉链接），而是从外国人的角度解释为什么韩国食品注重发酵，以及其中蕴含的思维方式、历史和哲学。韩国文化讲解系列第 3 部分**。

⚠️外国人常误解的3件事

1. “韩国发酵=泡菜” ❌ — 泡菜只是蔬菜发酵。韩国发酵文化的真正支柱是大豆发酵，或者说是豆酱。几乎所有韩国汤、炖菜和调味品的底部都有大酱、酱油和红辣椒酱。联合国教科文组织还分别将Kimjang（2013）和Jang-making（2024）添加到人类非物质文化遗产中——它们是两个巨大的、独立的传统。

2. “发酵=只是放置了很长时间的东西或变质的东西” ❌ — 发酵不是忽视，而是驯服微生物的精确控制。 鲜味是微生物（真菌和细菌）将大豆蛋白分解为氨基酸时产生的。这就是为什么即使不加味精也有浓郁的味道。

3. “味噌 = 与日本味噌相同” ❌ — 相似但不同。味噌通常细腻而甜，因为它使用米曲（曲），而豆酱则更粗糙、更浓郁、更美味，因为它是通过将整颗大豆浸泡在盐水中制成的。最重要的是，大酱具有独特的制作方法与酱油同罐（下图③）。

① 为什么要发酵？寒冷半岛发现的一种“节省时间的方法”。

在发酵成为韩国人的口味之前，它是一种生存技术。在朝鲜半岛没有冰箱的时代，冬天很长，一年四季吃蛋白质和蔬菜都必须储存，而发酵就是答案。

  • 盐+时间=保存：煮豆子并用盐发酵可以防止腐败并加深味道和营养（泡菜的原理相同）。
  • 什么都不扔：从同一锅豆子中获取大酱和酱油的方法（③）是一种将资源利用到底的智慧。
  • “时间是一种成分”：韩国发酵的核心理念。好的篇章不可能一蹴而就。 成熟等于味道，韩国有句俗话““酱好饭好”*——因为所有菜肴的起点都是肠子。

换句话说，韩国发酵并不是一种“异域美食”，而是韩国食品为度过漫长冬季而精炼的基础设施。

② 4种酱料——大酱、酱油、辣椒酱、清国酱

大酱 (Doenjang / 된장) — 浓郁风味的底料

把煮熟的黄豆捣碎、发酵制成的酱曲 (Meju / 메주)泡入盐水，经数月到数年发酵而成的棕色黄豆酱糊。大酱汤、大酱锅的底味几乎都来自它，韩餐"浓香醇厚"的味道多半由此而来。煮得越久越浓郁，存放越久越珍贵。

酱油 (Ganjang / 간장) — 同缸分出的兄弟

在制作大酱的同一口缸里，把酱曲泡出的咸味液体舀出另行熟成，就是酱油。也就是说大酱与酱油同根同源——这道分离工序叫分酱 (Jang-gareugi / 장 가르기)，详见下文③。依熟成年份分为国酱油、陈酱油等，存放越久颜色越深，鲜味也越盖过咸味。

辣椒酱 (Gochujang / 고추장) — 世界上独一无二的发酵辣酱

用酱曲粉 + 糯米(或大麦) + 辣椒粉 + 麦芽糖浆混合发酵而成，辛辣、香甜又鲜美的红酱。拌饭、炒年糕、烤鱼调味料上的那抹红色正是它。它不是简单的"辣酱"，关键区别在于它是发酵而成的复合调味料——所以辣味之后紧跟着甘甜与深度。全罗北道淳昌 (Sunchang / 순창)以辣椒酱闻名。

清麹酱 (Cheonggukjang / 청국장) — 发酵最快的酱

与前三者不同，它不使用酱曲，而是把煮熟的黄豆放在温暖处(约40°C)只短期发酵2~3天。黏丝与浓烈气味是它的特征(是日本纳豆的近亲)。气味较重，对外国人来说是个门槛，但在发酵食品中因健康功效备受喜爱。

③ 酱曲与酱缸台 — 发酵的"引擎"与"家"

酱曲 (Meju / 메주) — 一切酱的起点

大酱、酱油、辣椒酱几乎都从酱曲开始。把煮熟的黄豆捣碎、捏成砖块状，挂在温暖处发霉发酵，就成了酱曲。这时黄豆上会附着天然微生物(曲霉菌 Aspergillus、枯草杆菌 Bacillus 等)，这些微生物之后分解黄豆蛋白，生成鲜味与香气。所以有句话说"酱曲决定酱味"——酱曲正是发酵的引擎。

分酱：把发酵好的酱曲泡在盐水里放置两个月左右，就会分成上层澄清的酱油和沉淀的大酱渣。把这两者分别舀出的工序，就叫"分酱"。一锅黄豆分出两种酱，是韩国发酵最优雅的瞬间。

酱缸台 (Jangdokdae / 장독대) — 陶缸呼吸的地方

发酵好的酱装进陶缸 (Onggi / 옹기)，放在酱缸台——院子里向阳处摆满陶缸的空间——继续熟成。陶缸可不只是普通容器。

  • 会呼吸的容器：陶缸的土壁上布满肉眼难见的细孔，空气得以进出。这种细微的空气交换为发酵微生物营造出理想环境——塑料、玻璃容器都模仿不来。
  • 阳光与照料：晴天开盖晒太阳，下雨盖上盖子，日复一日的照看才成就酱的味道。酱缸台不只是储藏处，而是家务的中心，也是母亲、祖母的领地。

④ 联合国教科文组织与历史 — "制酱"本身成为遗产

韩国的制酱早已超越单纯的烹饪方法，被认定为社区共有的文化。

  • 2024年12月3日，在巴拉圭亚松森举行的第19届保护非物质文化遗产政府间委员会会议上，"韩国制酱文化 (Knowledge, beliefs and practices related to jang-making)"被列入联合国教科文组织人类非物质文化遗产代表作名录。
  • 这是继泡菜文化 (2013年列入) 之后，饮食领域第二个入选项目。两项传统分别获得认可，本身就说明了韩国发酵文化的广度与深度。
  • 联合国教科文组织看重的不是"完成的味道"，而是"一起制作、一起分享的行为"。一家人聚在一起蒸酱曲、分酱，技艺从母亲传给女儿、儿媳，这个过程被认为培育了社区的和睦与纽带。

参考：黄豆发酵本身是东亚共通的传统，但将整块酱曲泡好后从同一缸中分出大酱与酱油的制法，以及辣椒酱这种发酵辣酱，都被视为韩国独有的特征。

⑤ "酱味 = 家族身份" — 种酱油这部活的族谱

韩国发酵文化中最令人印象深刻的概念，是种酱油 (Ssi-ganjang / 씨간장)。

  • 种酱油 = 从熟成得最好的酱油中挑出最优的一份，像种子一样留存、代代相传的酱油。每年腌新酱油时舀入一勺陈年种酱油——这道工序叫添酱 (Deot-jang / 덧장)——其中的有益微生物与风味便会移植到新酱里，就像不让火种熄灭一样，把味道延续下去。
  • 因此名门世家的种酱油短则百年，长则数百年传承不断(据报道，有的宗家酱已有350~370年历史——具体年数因各家说法而异，建议核实)。每户人家的微生物构成不同、味道各异，种酱油实际上就是一份"味道的族谱"。
  • 酱油还按陈放年份区分等级——刚腌好的新酱油、放了几年的中年酱油，以及陈放5年以上、颜色深黑、鲜味压过咸味的陈酱油。时间本身就是等级。

这一概念清楚地展现出韩国发酵的哲学：酱味不是一个人的手艺，而是一个家族世代培育出的微生物生态系统与身份认同。

⑥ 现代的酱 — 市售 vs 传统，以及该怎么享用

如今大多数韩国人都在超市购买工厂量产的酱。手艺传统与工业化生产在这里并存。

  • 市售酱：标准化、价格实惠、方便，占据日常烹饪的大部分。发酵周期较短或酿造方式不同，风味深度可能与传统酱有差距。
  • 传统（传统）黄豆酱：用豆酱制成的黄豆酱，在陶器中经过长时间陈化。它被传承给大师、本家、寺庙和农场，并受到优待。对于外国人来说，品尝这种“传统酱料”是一次真正的发酵体验。
  • 如何享用：大酱炖菜、浓酱（大酱）、拌饭、炒年糕（红辣椒酱）、调味炖菜（酱油）几乎在所有韩国菜中都有。在餐厅里，只要问“这个酱是你自己做的吗？”，你就能听到老板自豪的解释。

⑦ 外国人视角——素食/健康食品

张在外国人的餐桌上出奇地适合。特别是，它对于素食主义者和纯素食旅行者具有巨大的优势。

  • 天然鲜味（不含味精）：发酵将大豆蛋白转化为氨基酸，自然产生鲜味。这就是不添加人工调味，味道浓郁的秘诀，对于追求干净味道的外国人来说很有吸引力。
  • 基本上以植物为基础：传统的豆酱和酱油仅由大豆、水和盐制成，并且最初是纯素食的**（辣椒酱也主要以植物为基础）。它是素食菜肴中想要创造出不含动物成分的浓郁风味的关键武器。
  • 寺庙食物的基础：韩国寺庙需要味道浓郁，不使用大蒜或大葱，所以肠子的发酵味道至关重要**。这就是为什么大酱、酱油和红辣椒酱都是直接在寺庙制作的（→#800寺庙食品）。
  • 肠道健康：作为一种发酵食品，含有有益菌，因此也吸引了那些对健康饮食和肠道健康感兴趣的人（具体功效数字不夸张，避免医学结论）。

推荐给外国人的第一步：大酱炖（最温和、最常见的）→ 拌饭用辣椒酱（辣甜的介绍）→ 一旦习惯了香味，清国酱。如果你是素食旅行者，一盘寺庙食物最能体现寺庙的真正价值。

❓ 外国人常见问题解答（FAQ）

  • 豆酱与日本味噌有何不同？ — 味噌是由米曲（曲）制成的，使其细腻而甜，而豆酱则是由整个豆酱（meju）浸泡在盐水中制成，使其变得更粗糙和更丰富。最重要的是，黄豆酱的独特之处在于它与酱油在同一个罐子里分开制作**。
  • 红辣椒酱不就是一种辣酱吗？ — 不是。因为它是一种发酵的复杂调味料，所以辣味之后就是甜味和鲜味。世界上任何地方都没有像这样的发酵红辣椒酱。
  • 为什么清谷酱有很重的气味？ — 因为大豆是在没有豆酱的情况下在高温下短时间发酵2-3天的。纳豆的表亲味道很浓，但作为健康食品而受到人们的喜爱。如果这是您第一次尝试，我建议您从豆酱开始。
  • 我是素食主义者，但我可以吃韩国发酵酱吗？ — 传统的豆酱和酱油通常是纯素的，因为它们只含有大豆、水和盐。然而，商业产品中可能会添加凤尾鱼和海带，因此建议检查标签。您可以放心享用寺庙餐厅。
  • 我在哪里可以购买橱柜？ — 本文是关于“为什么和什么”的解释，因此请参阅单独的指南了解购买地点（→ 下面的交叉链接）。当谈到礼物时，传统或大师工艺是有意义的。
