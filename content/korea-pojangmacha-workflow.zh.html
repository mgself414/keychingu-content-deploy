🎯 为什么选择韩国 Pocha 工作流程指南

【#843 6种夜宵零食矩阵】(#843) 即使你知道—— 点餐、搭配、礼仪是分开的。韩国Pocha有 (a) 帐篷/室内的区别（乙支路胡同=街头野加里 vs 钟路=帐篷） (b) 同时点零食+酒（小麦、烧酒、啤酒、马格利酒） (c) 公司聚餐的第二礼节（拒绝压力，控制节奏） (d) 付款方式（一人付款+Kakao Pay转账） (e) 迟到夜间礼仪（安静、考虑邻居）。外国人（1）不知道巷子里的小店和帐篷的区别，（2）不知道每种零食的酒精搭配，（3）不知道拒绝胁迫的礼仪，（4）不知道酒后驾驶0.03％BAC的限制。本指南为5步+配对+英语口语+安全礼仪。

★ 5 步工作流程概览

步骤 行动 时间 外国人的要点
1️⃣ 选择店铺类型 乙支路胡同 / 钟路 Pocha / 江南希望 / Gopchang 餐厅 立即 根据时区和伴侣量身定制
2️⃣ 座位+菜单+饮料点 零食+酒同时吃 5-10 分钟 “推荐零食+酒” 工作人员还可以
3️⃣ 接收+开始配对 小吃+第一杯饮料+吐司 5-10 分钟 野加里+啤酒·全麦+马格利酒·牛肠+烧酒
4️⃣ 公司聚餐礼节+饮酒 拒绝强迫、节奏控制、深夜礼仪 1~3小时 控制节奏、拒绝强行OK
5️⃣ 付款 一人支付→Kakao Pay/Toss汇款 1~3分钟 一些 Dutch Pay 商店

所需总时间：Hop = 1~2h / Pocha晚餐第二轮 = 2~3h / Late Night Mania = 清晨~

🌃 按商店类型划分的工作流程

A型——乙支路野加里胡同（外国人vlog#1）

  • 系统：街边摊+室内酒花集群（Manseon Hof、Munich Hof等）
  • 菜单：Nogari、jeon、串烧、生啤酒
  • 价格：每人15,000~25,000韩元
  • 时间：17:00~02:00
  • 付款：卡和现金混合
  • 外国人友善度：★★★★（vlog 1号，部分英文）

B型——钟路·清溪Pocha（深夜帐篷）

  • 系统：夜间帐篷街头酒吧
  • 菜单：Nogari、jeon、乌冬面、拉面、牛肚、串烧
  • 价格：每人15,000~25,000韩元
  • 时间：18:00~02:00（或凌晨）
  • 付款：现金/卡
  • 外国人友好度：★★（韩国菜单，深夜氛围）

C型——江南·驿三希望（上班族）

  • 系统：室内啤酒花 + 晚餐第二次狂热
  • 菜单：全套铁板、牛肚、田、野加里
  • 价格：每人25,000~40,000韩元
  • 时间：17:00~24:00
  • 付款：刷卡即可
  • 外国人友好度：★★★（部分英文）

D型 — 马场洞·往十里牛肠店（Mania）

  • 系统：牛肠专卖店+烧酒展
  • 菜单：全套牛肚、猪肚、麻张
  • 价格：每人25,000~50,000韩元
  • 时间：17:00~24:00
  • 付款：刷卡即可
  • 外国人友好度：★★★（部分英文）

🙏 韩国公司聚餐的7大礼仪

公司晚宴/pocha礼仪

1. 干杯=玻璃位置：略低于成人（传统）

2. **给自己的杯子倒满酒

3. 用双手倒/接：成人的地道礼仪

4. 转头喝：在大人面前正宗（现代=强迫

5. 节奏：建议每 1-2 小时喝 2-3 杯。

6. 强行拒绝OK：现代韩国公司聚餐=强行拒绝并不违反礼仪。

7. 深夜礼仪：22:00之后=安静+体谅邻居

外国人英语演讲样本

  • “Nogari + 生啤酒” =“Nogari 和生啤酒，请”
  • “马格利 + 海鲜煎饼” = “请马格利加海鲜煎饼”
  • “一瓶烧酒” =“请来一瓶烧酒”
  • “我不想喝酒” =“我不喝酒，谢谢”
  • “只需一枪” =“请只射击一枪”
  • “卡已接受？” =“卡已接受？”
  • “KakaoPay汇款” =“通过KakaoPay发送”

⚠ 外国人常犯的7个错误

1. “Pocha = 肮脏”：乙支路胡同/钟路Pocha = 定期检查旅游景点的商店，良好的卫生习惯。

2. “Nogari = 只有鱼”：Nogari = 明太鱼干·盐·咸= 啤酒博览会正品#1。

3. “Gopchang = Japanese motsu”：韩国牛肚 = 调味料 + 烧烤 = 其他食物。马场洞简介。

4. “紫菜鳗鱼=普通鳗鱼”：紫菜鳗鱼= 用釜山辣调味料烤（与淡水鳗鱼不同）。

5. “拒绝武力=违反礼仪”：现代韩国=拒绝武力可以。直接拒绝：“我不喝酒。”

6. “酒后驾驶=轻度”：韩国0.03% BAC = 吊销驾照（强力打击）。

7. “深夜礼仪=自由”：22:00之后=安静并体贴邻居。

⚙ 8 个常见问题解答

1. 第一Pocha=地点：乙支路Nogari胡同第一名（外国人vlog#1）。

2. Insta·vlog：乙支路野里胡同、广藏市场展览+马格利酒、釜山海鳗。

3. MZ趋势：Euljiro Nogari Alley MZ vlog·配对Instagram。

4. 饮酒晚餐第二狂热：Nogari Hope + Gopchang House + Teppan Hope。

5. 饮酒礼仪：拒绝压力即可·节奏控制·深夜22:00安静礼仪。

6. 酒后驾驶：0.03% BAC驾照被吊销，19岁以下禁止合法饮酒。

7. 过敏：海鲜、豆类、鸡蛋、坚果、辛辣调味料，需提前告知。

8. 付款/小费：卡OK / Pocha = 部分现金 / Kakao Pay/Toss 转账 / 小费

⚠ 医疗/安全/法律免责声明

夜宵/零食=夜间膳食（影响消化和睡眠）。孕妇=酒精儿童=夜Pocha X（饮酒气氛）。过敏（海鲜、豆类、鸡蛋、坚果）需提前通知。 醉酒驾驶0.03% BAC驾照吊销+刑事处罚（韩国严厉打击）。 19岁以下=禁止合法饮酒。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

长期店铺/商店信息免责声明：Pocha/Nogari Alley 营业时间/菜单变更 — 访问前请查看 NAVER/Kakao 地图或官方网站。

饮食限制后备：

  • 清真/犹太洁食：普通零食=非清真。 → 梨泰院的一些清真商店或素食开胃菜和水果小吃。
  • 素食·纯素：绿豆饼、南瓜饼、泡菜饼（不包括鱼饼）=素食可选。
  • 无麸质：许多煎饼和调味料（酱油）。提前检查商店。
