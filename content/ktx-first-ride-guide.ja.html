韓国KTXに初めて乗る、手順どおりに — 改札のない駅で迷わない方法

> 副題: 予約3ルート(コレイルトークアプリ・公式ウェブ・駅発券機)・コレイルトーク予約マスターフロー・「改札がない」カルチャーショックに正面から向き合う・電光掲示板の読み方(乗り場は15分前に公開)・ソウル駅の規模感・座席の探し方(逆向き座席)・サバイバル単語12・パニックシナリオ3

🎯 この記事の読み方 — 表記のルール

画面表記のルールは#1270で定めたものをそのまま使用する。

  • 画面内のボタンは角括弧: [ 決済する (결제하기) ]
  • 画面タイトル・案内文はかぎ括弧: 「出発駅検索 (출발역 검색)」
  • 手で行う動作は太字: カードを奥まで挿入

この記事は予約方法ではなく、「駅に着いてから列車に座るまで」の間の手順の空白を埋める。KTX自体の紹介(料金・座席クラス・他の交通手段との比較)は#239を先に見よう。

① 予約3ルート — どこで、どうやって買うか

方法 どこで 海外カード 備考
コレイルトークアプリ (Korail Talk) アプリストア/Google Play ★ ウェブよりはるかに通りやすい 出発30日前に予約オープン、座席を直接選択
公式ウェブ (letskorail.com) PC/モバイルブラウザ 拒否頻度が高い(VANインフラの特性) アプリ未インストール時のバックアップ用
駅発券機 ソウル駅など主要駅ロビー 外国カード対応機が別途存在(カード会社ロゴで確認) 現地即時発券、言語切替ボタン有

韓国の決済網は国際EMV標準を一部しかサポートしておらず、ウェブでは海外カードがよく拒否される(仕組みは#527参照)。コレイルトークアプリが最優先ルートだ — 出国前にあらかじめインストールしておこう(#1230必須アプリ編参照)。

② コレイルトーク予約マスターフロー — 画面そのまま

1. 「出発駅 (출발역)」検索窓 → 英語で駅名を入力(例: Seoul) → リストからタッチ

2. 「到着駅 (도착역)」も同じ方式で英語検索

3. 日付・時間をカレンダーで選択 → [ 検索 (조회) ]

4. 列車リスト(KTX/ムグンファ/SRTの表示が混在 — KTXかどうか確認) → 希望の時間で [ 選択 (선택) ]

5. 座席配置図で希望の席を直接タッチ(窓側/通路側) → [ 次へ (다음) ]

6. 決済画面 → カード情報を入力 → [ 決済する (결제하기) ]

予約が完了するとアプリ画面そのものが乗車券になる。紙で発券する必要はない — アプリを削除したりログアウトしたりすると切符を失うことになるので、列車が到着するまでそのままにしておく。

③ 「改札がない」 — 最大のカルチャーショック

地下鉄(#1281)と違い、KTXのプラットホーム入口には改札口・ゲートがない。切符がなくても物理的にはそのまま歩いて入れる。これは抜け穴ではなく無検札の信頼システムだ — 乗客が有効な切符を持っているという前提で設計されている。

  • 検札員が車内を不定期に巡回して確認する
  • スクリーンショットは証明として認められない — コレイルトークアプリにログインした状態の実際の予約画面のみ有効
  • 不正乗車が発覚すると罰金(運賃の倍数)が科される

「検札の人が見当たらないな」で安心しないこと — 切符は常にアプリにアクセスできる状態で携帯していなければならない。

④ 電光掲示板の読み方 — 乗り場(プラットホーム)の探し方

駅の待合室の電光掲示板には「列車番号・目的地・出発時刻・乗り場」が表示される。核心の落とし穴: 乗り場(プラットホーム番号)は出発の約15分前になってようやく公開される。事前には表示されないので、空欄でも正常だ。

列車番号 目的地 出発 乗り場
KTX 401 釜山 Busan 09:15 7
KTX 105 大田 Daejeon 09:20 — (未公開)

予約画面の列車番号で電光掲示板の該当行を探す。目的地・時刻が似た列車が複数ある場合、列車番号が唯一の識別子になる。

⑤ ソウル駅の規模感 — いつ、どこへ動くか

ソウル駅のKTXプラットホームは3~14番の範囲で、地下に広く広がっている。出発20~30分前の駅到着を推奨 — ゲートがないので歩くこと自体に制約はないが、駅舎自体が大きいため、待合室→電光掲示板確認→エスカレーター・階段移動に実際の徒歩時間がかかる。

動線: 待合室に入る → 電光掲示板で乗り場を確認(15分前) → 該当番号の方向へ階段/エスカレーターで下る → プラットホーム。

⑥ 座席の探し方 — 号車・座席番号、逆向き座席

列車の出入口の横に号車番号が表示されている。予約画面の号車と照らし合わせて合っているドアから乗車する。座席は番号(列)+アルファベット(左右)で構成される。注意点: 一部の座席は進行方向と逆(逆向き)に配置されている — 予約時に向きの選択オプションがない場合、ランダムに割り当てられることがある。気になる場合は乗車前に窓口やアプリの再選択画面で席を変える。

⑦ 車内マナー一段落

通話は客室間の通路スペースで静かに。弁当などの飲食物の持ち込み・飲食は許可されている(カート販売もよくある)。荷物置き場は大型キャリーケース用の棚が出入口側に別に設けられている — 座席横の通路に立てて置くと他の乗客の移動を妨げる。

⑨ パニックシナリオ3

1. 電光掲示板に乗り場が表示されない — 15分前公開のルールを知らないと慌ててしまう。対応: 待合室で15分前まで電光掲示板の近くで待機する。

2. 列車に乗り遅れた — KTXは座席指定制のため、次の列車に自動的に乗車できるわけではない。窓口やコレイルトークの「乗車券管理 (승차권 관리)」で変更・払戻手続きを行う。

3. 間違った号車に乗ってしまった — 無検札構造のためその場で止められることはない。停車するまでに通路を移動して正しい号車・座席を探せばいい。

⑩ プランB — それでも詰まったら

駅員にコレイルトークの画面(予約内容)を見せればたいてい解決する。複数の都市を巡るリピーター旅行者は、外国人専用の周遊券Korail Passも検討する価値がある。
