庆州秋季节庆周——从9月中旬起的三周,夜间活动层层叠加而来

副标题: 从大陵苑 (Daereungwon / 대릉원) 媒体艺术(~9/27)、国家遗产夜行 (Gukga Yusan Yahaeng / 국가유산야행)(9/18~20),到新罗文化祭 (Silla Munhwaje / 신라문화제)(10/9~11)——把2026年秋季庆州 (Gyeongju / 경주) 的限时活动层,叠加在夜景动线(#1366)之上的方法

🎯 为什么是"节庆周"

庆州的夜晚才是正片(#1366),这是常态——东宫月池 (Donggung-Wolji / 동궁과 월지)、月精桥 (Woljeonggyo / 월정교)、瞻星台 (Cheomseongdae / 첨성대) 的夜景,不管什么时候去都在。但2026年9月中旬~10月中旬的这三周,会在这层常态之上叠加一层限时活动:千年古坟变成媒体立面投影屏幕,月精桥到校村 (Gyochon / 교촌)、邑城一带亮灯至夜里11点,最后一个周末还有无人机与烟花升空。这正是庆州本地策展类账号从9月起集体发布这份日程的原因。这篇攻略,就是那层限时活动的日历——只要能把庆州行程安排在这段时间里,同一条夜景动线会呈现出完全不同的密度。(和釜山烟花节#1365同一个原理的"挑日子去"篇。)

⚠ 有效期: 本文提到的活动均为2026年限定日程。各活动结束后,请通过官方渠道确认次年公告。

🌌 大陵苑媒体艺术——古坟变成投影屏幕的24天(~9/27)

以"大陵苑,永远(永遠)"为主题,在味邹王陵 (Michu Wangneung / 미추왕릉)、皇南大冢 (Hwangnam Daechong / 황남대총)、天马冢 (Cheonmachong / 천마총)、90号坟 (90-ho Bun / 90호분) 这4座古坟上投射大型媒体立面投影的夜间展览——每天19:30~21:30,从9月4日持续到27日。从入口通往中央广场的步道,会被布置成加入萤火虫灯光、激光、雾效的"光之森林",夜间导览团也常态运营。这是两个本地账号交叉报道过的这段时期代表性看点——和白天的大陵苑(#256)完全是不同的画面。如果是9/27之后到访,这一节可以跳过,直接看#1366的常设夜景动线。

🏮 国家遗产夜行——从月精桥到邑城,亮灯至夜里11点(9/18~20)

一年一次,月精桥~校村韩屋村~庆州邑城 (Gyeongjueupseong / 경주읍성)这段路线,会连续三天变成亮灯至夜里11点、跟着灯笼徒步的节庆区域。开幕日(18日)18点,月精桥前的特设舞台上,预告了空军特技飞行队黑鹰特技飞行队 (Black Eagles / 블랙이글스) 飞行表演,以及艺术家涂鸦先生 (Mr. Doodle / 미스터 두들) 的现场绘画表演——飞行表演在日落前进行,如果选在开幕日到访,下午就该在月精桥占好位置。街头表演、夜市、小吃摊会铺满整个区域,如果三天里只能安排一天,把晚餐放在校村解决、再跟着灯笼动线走的安排最有效率。

🌾 瞻星台粉黛乱子草——白天的层(9月末~10月初)

瞻星台一带的粉黛乱子草会在9月末~10月初盛开——和首尔的芒草季(#1313)同一个原理,粉黛乱子草的巅峰在逆光的日落时分。这段时期的庆州,夜间活动都集中在傍晚,"日落粉黛乱子草→傍晚媒体艺术/夜行"的白天与夜晚两层,自然而然就衔接了起来。

🎆 新罗文化祭——三周的压轴(10/9~11)

迎来第53届的庆州最大秋季庆典。核心是和白祭典 (Hwabaek Jejeon / 화백제전)——在月精桥舞台上结合水中表演、烟花、无人机秀的演出,只在10/9(周五)、10(周六)19:00~19:30举行(11日没有——想看压轴表演,必须选周五或周六去)。凤凰台 (Bonghwangdae / 봉황대) 的月光夜市 (Dalbit Nanjang / 달빛난장)是三天全程15:00~22:00开放的夜市型活动,10日17点还有一场在内南十字路口 (Naenam Negeori / 내남네거리) 以古坟为舞台背景的花郎嘻哈音乐节 (Hwarang Hiphop Festa / 화랑힙합페스타)(免费入场)。在王陵前办嘻哈演出,这种组合本身,就是这座城市对待遗产方式的一个缩影。

⚠ 常见错误3条

1. "以为10月还能看到媒体艺术"——大陵苑媒体艺术9/27就结束了。和新罗文化祭(10月)的档期并不重叠——想两个都看,得去两次。

2. "以为新罗文化祭周日也有无人机秀"——和白祭典只在周五、周六举行。周日到访的人,就只剩月光夜市可看。

3. "当天再订住宿"——庆典周末的庆州住宿会提前订满(和釜山烟花节#1365同一个模式)。皇里团街 (Hwangridan-gil / 황리단길) 步行圈的住处尤其抢手——日期一确定,第一件事就是先订住宿。

⚙ FAQ 3个

1. 三天都待不了,只能选一天的话? — 9月到访的话,周五、周六晚上的夜行(9/18~19)是把飞行表演+灯笼+媒体艺术(大陵苑,同一晚就能看)打包进一天的最优解。10月到访的话就选10/10(周六)——和白祭典的无人机秀+月光夜市+花郎嘻哈音乐节,当天全部重叠。

2. 门票怎么算? — 夜行、花郎嘻哈音乐节都是以免费为基调的开放型庆典。大陵苑媒体艺术和各个别设施的入场,请以现场公告为准(活动构成上仍有变动空间)。

3. 和常设夜景有什么不同? — 东宫月池、月精桥的夜景(#1366)不在这段时期也照样存在。这篇里的这些活动,是叠加在那之上的限时内容——也就是说,就算日期没赶上,庆州的夜晚本身依然成立。
