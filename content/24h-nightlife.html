⚠ 외국인 자주 실수 5가지

1. "한국 24h = 편의점만": 한국 24h = 편의점 + 한식 + 분식 + BBQ + 카페 + 노래방 + 한강 치맥 + 야시장 + 외국인 매니아 1번지·#05·#06·#208 통합.

2. "심야 = 위험": 심야 한국 = 외국인 매니아 1번지 + 명동·강남·홍대 24h 안전 + #405 안전 풀세트·#208 시차 적응 매니아.

3. "24h 한식 = 비쌈": 24h 한식 = 해장국·국밥 8~12K + 분식 3~10K + 외국인 가성비 1번지 + 외국인 매니아·#05·#15 통합.

4. "심야 코인노래방 = 못 함": 코인노래방 = 24h + 외국인 매니아 1번지 + #422 통합 + 외국인 야간 K-pop 매니아.

5. "한강 치맥 = 여름만": 한강 치맥 = 여름 #1 + 봄·가을 외국인 매니아 + 24h 한강 11공원 + 외국인 매니아 1번지·#06·#308 통합.
