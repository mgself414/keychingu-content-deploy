한국 궁중떡·다식·정통 디저트 12선

1. 다식 (茶食·궁중 정통 후식)

  • 차별: 미숫가루 + 꿀 → 다식판 압축·매화·국화·연꽃 무늬·고려시대부터·다도 + 한정식 후식
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·기념품 인기

2. 약과 (정통 궁중 과자)

  • 차별: 밀가루 + 꿀 + 참기름 + 생강 정통 과자·조선 왕실 정통·MZ 매니아 2024 부활
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아·MZ 1순위

3. 한과 (정통 풀세트)

  • 차별: 유과·강정·다식·산자 풀세트·한국 정통 디저트 풀세트·기념품 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN 기념품 1순위·해외 반입 OK

4. 궁중떡 (절편·인절미·송편 풀세트)

  • 차별: 궁중 정통 떡·절편·인절미·송편·약식·계절별 시그니처
  • 시그니처: 인사동·낙원동·종로 정통 떡집
  • 외국인 fit: ★★★★ EN·JP·CN 매니아

5. 약식 (정통 + 견과·대추)

  • 차별: 찹쌀 + 대추 + 잣 + 밤 + 꿀·한국 정통 + 정월 시그니처·기념품 1순위
  • 외국인 fit: ★★★★ EN·JP·CN 매니아

6. 화전 (꽃 떡·계절 시그니처)

  • 차별: 꽃 + 찹쌀 + 꿀 정통 떡·진달래 (봄)·국화 (가을)·매화 (겨울)·SNS 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아·SNS 1순위

7. 인사동·낙원동 떡집 cluster

  • 차별: 인사동·낙원동·종로 정통 떡집 5+·호떡·약과·다식·인절미 풀세트·MZ 매니아 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아 1순위

8. 떡카페 + 정통 디저트 cluster

  • 차별: 인사동·익선동·북촌 떡카페·전통 + 모던 fusion·MZ 매니아 1순위
  • 시그니처: 떡 + 차 + 다식 풀세트
  • 외국인 fit: ★★★★ MZ EN·JP·CN 매니아·SNS 1순위

9. 호떡 + 붕어빵 (정통 길거리 디저트)

  • 차별: 호떡 (계절 견과 + 꿀)·붕어빵 (팥·슈크림)·한국 #1 길거리 디저트·MZ 매니아
  • 시그니처: 명동·인사동·홍대·광장
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아 1순위

10. 떡볶이 + 정통 한식 디저트 cluster

  • 차별: 신당동 떡볶이·통인시장 엽전 떡볶이·한국 #1 매콤 디저트·MZ 매니아 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아 1순위

11. 궁중 디저트 + 다도 풀세트 매장

  • 차별: 궁중 떡 + 다식 + 약차 풀세트·Rakkojae·전통다원 패키지·EN 가이드
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아·#680 cross

12. 떡·한과 면세 + 기념품 (인천공항)

  • 차별: 인천공항 면세 한과 매장·해외 반입 OK·약과·다식·인절미 풀세트 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN 기념품 1순위

FAQ 6

Q1. 떡·한과 가격대? A. 떡 한 개 1-3K·한과 풀세트 30K-100K·약과 5K-20K.

Q2. 약과 + MZ? A. 2024 약과 MZ 매니아 부활·SNS + 카페 + 면세·전통 + 모던 fusion.

Q3. 인사동·낙원동 떡집? A. 인사동 + 낙원동 + 종로 정통 떡집 cluster·호떡·약과·다식·인절미 풀세트.

Q4. 떡카페 추천? A. 인사동·익선동·북촌 떡카페·전통 + 모던 fusion·MZ 매니아 1순위.

Q5. 면세 기념품? A. 약과·한과 풀세트·인절미·다식·해외 반입 OK.

Q6. 화전 (꽃 떡) 시기? A. 봄 진달래·가을 국화·겨울 매화·계절 시그니처 SNS 1순위.
