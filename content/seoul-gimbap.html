외국인이 자주 하는 실수 5가지

1. "김밥은 다 똑같다"는 오해

한국 김밥은 시장 노포 / 프리미엄 체인 / 트렌디 체인 / 편의점에 따라 식재료·가격·맛이 완전히 다릅니다. 광장시장 마약김밥 ₩4,000과 리김밥 키토 ₩5,800은 같은 김밥이지만 다른 음식. 본문 §체인 3대장 비교 참고.

2. 광장 마약김밥에 겨자 안 묻히기

광장시장 마약김밥은 겨자+간장 소스가 핵심입니다. 안 묻히면 맛 절반 손실. 외국인이 "그냥 미니 김밥이네"라고 평가하는 이유는 십중팔구 소스를 안 묻혔기 때문.

3. 새벽 편의점 김밥 = 양호하지 않다는 편견

한국 편의점 김밥(CU 양반김밥, GS25 김혜자김밥, 세븐일레븐)은 24시간 신선 회전이고 외국인 만족도 매우 높음. 새벽 비행기 + 첫날 호텔 도착 시 ₩3,500 김혜자김밥 + 컵라면이 한국 첫끼 정답.

4. 충무김밥을 일반 김밥처럼 주문

충무김밥(통영 출신 지역 특산)은 김밥 + 무김치 + 오징어무침이 별도 접시로 나옵니다. "김밥만 시켜야지"가 아니라 세트 주문(₩7,000~10,000). 미니 김밥에 무김치·오징어무침 곁들이는 게 정통.

5. 키토김밥·비건 옵션 모르고 그냥 시키기

한국 김밥은 밥 빼고 계란말이로 대체한 키토김밥, 고기·해물 빼고 야채만 쓴 비건 김밥까지 옵션이 다양해졌습니다. 글루텐·저탄수·비건 식이라면 리김밥 키토 / 바르다김선생 야채김밥부터 점검하세요.

외국인 주의사항 8가지 (체크리스트)

✅ 알레르기 점검

  • 흔한 재료: 참치·계란·시금치·당근·우엉·단무지
  • 특이 재료: 명란(생선알), 멸치(작은 생선), 어묵(생선 가공)
  • 알레르기 시 "○○ 빼주세요(○○ ppae-ju-se-yo)"

✅ 비건 옵션 검증

  • 야채김밥조차 참치액·계란이 들어갈 수 있음
  • 비건 100% = 매장에서 "비건이에요(vegan-ieyo)" 명시 + 메뉴 직접 확인
  • 안전 옵션: 바르다김선생 야채(고기 빼달라 요청 가능), 리김밥 키토 변형

✅ 매콤 정도

  • 매콤참치마요·매콤제육·매콤소시지 = 한국식 매콤(중간)
  • 못 먹으면 야채·치즈·참치마요(non-spicy) 권장
  • "덜 매워요(deol mae-wo-yo)" 통하는 체인은 일부

✅ 단무지·우엉의 특유 향

  • 단무지(노란 절임 무) + 우엉(rolled burdock root) = 호불호 갈림
  • 익숙해지는 데 1~2회 필요. 첫 방문이면 야채 빼고 참치·치즈 위주

✅ 김밥 자르기

  • 한 줄 = 8~10조각으로 잘라 나옴 (시장 마약김밥은 10조각 미니 사이즈)
  • 통째로 안 자른 김밥은 거의 없음 — "조각으로 주세요" 별도 요청 X

✅ 결제

  • 체인 100% 카드 OK / 시장 노포 일부 현금 / 편의점 카드+모바일 100%
  • 시장 김밥 = ₩10,000 현금 백업

✅ 테이크아웃 (포장)

  • 모든 체인·시장·편의점 포장 무료 (체인은 포장백 ₩100~200 일부 매장)
  • "포장이요(po-jang-i-yo)" 또는 "to go please"

✅ 시간 제약

  • 체인 일부는 7시 이전 일부 메뉴 미준비 (오전 김밥 종류 한정)
  • 김밥천국·편의점은 24시간 가능
  • 광장 마약김밥은 오전 9시부터

FAQ

Q1. 영어 통하나요?

바르다김선생·리김밥·김밥천국·편의점은 영어 메뉴·사진 메뉴 보편. 광장 마약김밥·충무김밥은 한국어 위주지만 손가락으로 가리키면 OK.

Q2. 비건 김밥 있나요?

완전 비건은 어렵지만 야채김밥(계란 빼달라 요청) / 리김밥 키토 변형이 가장 가까움. 매장 직원에게 "vegan, no egg, no meat"이라고 명시 + 메뉴 직접 확인.

Q3. 매워요?

야채·참치·치즈·돈까스 김밥은 안 매움. 매콤·제육·매운참치마요·매콤소시지가 들어가면 매콤(중간 한국 매운맛). 못 먹으면 안전 메뉴 위주로.

Q4. 김밥과 스시(초밥)는 뭐가 다른가요?

김밥은 밥에 식초 안 넣음(초밥은 식초 밥), 김 바깥, 익힌 재료 위주(스시는 생선 위주). 외국인이 처음에 "스시랑 비슷하지?" 묻지만 사실 다른 음식 카테고리. 일본 마키(maki)가 더 가까움.

Q5. 새벽·심야 어디서 먹나요?

24시간 김밥천국 매장 + 모든 편의점. CU·GS25·세븐일레븐 김밥은 24시간 신선 회전. 호텔 도착 새벽 = 편의점 김혜자김밥 + 컵라면 정답.

Q6. 어린이 데려가도 되나요?

바르다김선생·리김밥·김밥천국은 가족 친화. 매콤 메뉴만 빼고 야채·참치·치즈 권장. 광장시장·충무김밥은 좁고 시끄러워 어린이에는 비추.
