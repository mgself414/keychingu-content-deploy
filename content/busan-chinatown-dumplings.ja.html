釜山駅前の1時間 — 草梁チャイナタウン、餃子と華僑の中華料理店9軒

副題: KTXを降りて駅前広場を渡ると、赤い柱の上海門が見えてくる。その中が、1884年に清国領事館が置かれたことから始まった釜山の華僑の通り、上海街だ。1951年から餃子を包み続ける店、映画『オールド・ボーイ』の焼き餃子を出した店、目玉焼きをのせたカンチャジャン、そして路地の突き当たりにあるウズベキスタン料理店まで — 列車の時間に合わせて食べる方法

🎯 なぜ「釜山駅前の1時間」なのか

KTXで釜山に来る人は、ほぼ全員が釜山駅 (Busan Station / 부산역)を通る。到着時に一度、出発時に一度。ところがその1時間は、たいてい駅ビルの中のチェーン店やコンビニで終わってしまう。

駅前広場の向かいの路地は事情が違う。1884年にここに清国領事館が置かれ、その周辺に華僑 (Hwagyo / 화교)が根を下ろした。朝鮮戦争のあとは米軍相手の店が集まってテキサス通り (Texas Street / 텍사스거리)という名前がつき、1980年代の終わりからはロシアの船員や商人が出入りするようになった。1993年に釜山と上海が姉妹都市になったことで入口に上海門 (Shanghai Gate / 상해문)が立ち、通りの名前も上海街 (Shanghai Street / 상해거리)になった。2007年には国内唯一のチャイナタウン特区に指定された。

だからこの路地の食べ物は三層になっている。華僑が作り続けてきた餃子、韓国式中華料理店の原型に近いチャジャンミョン・チャンポン・オヒャンジャンユク、そしてテキサス通り側のロシア・中央アジア料理。すべて駅から歩いて行ける。

⚠ 有効期限: 2026年9月30日確認時点。9軒すべてについてNAVER地域検索で存在と道路名住所を確認した。営業時間・定休日・メニュー価格はDiningCodeの店舗ページを直接開いて確認した値で、出典によって食い違う店は表に別に記した。価格はメニュー表の表記で、変わることがある。

★ 一目でわかる — 9軒

駅側の入口(上海門)から路地の奥へ向かう順番だ。大瀛路243番ギル (대영로243번길)は一本の細い路地なので、店と店の間は遠くない — 入口のシンバルウォンから一番奥のラクチョンガクまで、直線で約220mだ。

🥟 餃子の4軒 — 入口から順に

シンバルウォンは1951年に開店した餃子の店で、上海門を過ぎて最初に出会う店だ。肉餃子(4個 4,800ウォン)、焼き餃子(4個 5,500ウォン)、エビ餃子(4個 6,500ウォン)を一皿ずつ売っているが、三つを2個ずつ盛り合わせたゴグンセ (Gogunsae / 고군새)(8,500ウォン)を頼めば一度に食べ比べられる。餃子のほかにコンクク(豆乳スープ)とコングァジャ(豆菓子)(4,500ウォン)、カンフー麺(5,900ウォン)がある。火曜日は休み。

マガマンドゥはシンバルウォンから約37m、事実上のお隣さんだ。焼き餃子・蒸し餃子・水餃子が各8,000ウォンで、麻婆豆腐やエビチャーハンのような食事メニューもある。水曜定休だが、毎週なのか隔週なのかは出典ごとに違うので、水曜に行くなら確認してから行く。シンバルウォンの前に長い行列ができていたら、この店が一番近い代わりの選択肢だ。

チャンソンヒャンは1984年から営業している店だ。2003年の映画『オールド・ボーイ』で主人公オ・デスが15年間閉じ込められて食べた焼き餃子がこの店のものだと、韓国政府のポータルkorea.netが2019年の記事で伝えた。焼き餃子(小)9,000ウォン、チャジャンミョン (Jajangmyeon / 짜장면)7,000ウォン、カンチャジャン (Ganjajang / 간짜장)9,000ウォン。餃子だけならシンバルウォン、餃子とチャジャンミョンを一緒に食べるならチャンソンヒャンが便利だ。

イルプムヒャンは蒸し餃子・水餃子が9,000ウォン、揚げ餃子が10,000ウォンで、オヒャンジャンユクやラジョギ (Lajogi / 라조기)のような料理が分厚い。日曜は休みで、15~17時に休憩時間がある。

🍜 華僑の老舗の本領 — ジャジャン、チャンポン、オヒャンジャンユク

餃子だけ食べて出てくると、この路地の半分しか見ていないことになる。華僑の中華料理店の本領は別にある。

ウォンヒャンジェはシンバルウォンと同じ1951年に開店し、番地もすぐ隣(60番)だ。代表メニューは目玉焼きをのせたカンチャジャン(10,000ウォン)とオヒャンジャンユク (Ohyangjangyuk / 오향장육)(五香醤肉・豚肉)である — メニュー表には「70年伝統のジャンユク」(36,000ウォン)として載っている。休憩時間が15:00~16:50と長く、定休日は出典ごとに違うため、訪問前の確認が必要だ。

ホンソンバンは1971年に開店した店で、路地を一本隔てた中央大路179番ギルにある。サムソンチャンポン (Samseon Jjamppong / 삼선짬뽕)(小 9,000ウォン)と水餃子(小 8,000ウォン)が知られていて、ランチ特選セット(18,000~20,000ウォン)がある。LOは20:30だ。

チャンチュンバンは、オヒャンジャンユク(小 23,000ウォン)・チサムソン (Jisamseon / 지삼선)(20,000ウォン)・ナスの揚げ物(13,000ウォン)のように料理メニューの幅が広い。何人かで行って料理を2、3品分け合うのによい。10:40に開くので、この路地でいちばん早い。

🍢 羊肉串と中央アジア — 路地の奥

ラクチョンガクは路地のいちばん奥にある。華僑の中華料理店のメニュー(チャジャンミョン 7,000ウォン・焼き餃子 8,000ウォン)に、羊肉串 (양꼬치)(5本 10,000ウォン)とナスの肉団子(20,000ウォン)が加わる。22:00まで開いているので、夜遅く着く列車に合う。月曜は休み。

サマルカンドはウズベキスタン料理店だ。この路地がテキサス通りと呼ばれていた時代から続くロシア・中央アジア側の顔である。ボルシチ (Borscht / 보르쉬)(ロシア式のビーツのスープ、18,000ウォン)、羊肉の揚げ物(21,000ウォン)、チキンケバブ(7,000ウォン)、ナン(6,000ウォン)。11:00~23:00で、いちばん遅くまで開いている。食事制限に関する表記は、下の「予算と食事制限」に別に書いた。

🕐 列車の時間別コース

どのコースも釜山駅1番出口 → 上海門から始まる。

30分 — 餃子を一皿

シンバルウォン(火曜休み)またはマガマンドゥ(水曜休み)。二軒は約37m離れている。片方に行列があれば、もう片方へ行く。ゴグンセを一皿頼めば、三種類の餃子をすべて食べられる。

1時間 — 餃子 + チャジャンミョン一杯

餃子を一皿食べたあと、すぐ隣のウォンヒャンジェでカンチャジャン(休憩15:00~16:50に注意)、またはチャンソンヒャンで焼き餃子とチャジャンミョンを同じ席で。チャンポンが食べたければホンソンバン。

2時間 — 料理を分け合う夕食

チャンチュンバンかイルプムヒャンでオヒャンジャンユクやタンスユク(酢豚)のような料理をみんなで分け合い、ラクチョンガクの羊肉串で締める。ロシア・中央アジア側が気になるなら、サマルカンドのボルシチとナン。

午後3~5時に着いたなら — 休憩なしで開いているのは、シンバルウォン・チャンソンヒャン・チャンチュンバン・ラクチョンガク・サマルカンドだ(各店の表記基準)。マガマンドゥは16:00に再開する。

💰 予算と食事制限 — 何を避けられるか

価格帯は三層ある。 下の金額はメニュー表の価格(DiningCode表記、2026-09-30確認)だ。

  • 1万ウォン以下 — 餃子・麺一杯: シンバルウォンの肉餃子 4,800ウォン・ゴグンセ 8,500ウォン、チャジャンミョン 7,000ウォン(チャンソンヒャン・ホンソンバン・チャンチュンバン・ラクチョンガク)、餃子一皿 8,000~9,000ウォン、サマルカンドのチキンケバブ 7,000ウォン。
  • 1万~2万ウォン — カンチャジャン・チャンポン・セット: ウォンヒャンジェのカンチャジャン・海鮮チャンポン各 10,000ウォン、チャンソンヒャンのサムソンチャンポン 15,000ウォン、ホンソンバンのランチ特選 18,000~20,000ウォン、サマルカンドのボルシチ 18,000ウォン。
  • 2万ウォン以上 — 分け合う料理: チャンチュンバンのオヒャンジャンユク(小)23,000ウォン、タンスユク 28,000ウォン(チャンソンヒャン・ウォンヒャンジェ)、イルプムヒャンのオヒャンジャンユク 33,000ウォン、ウォンヒャンジェの70年伝統ジャンユク 36,000ウォン。

食事制限 — 選択肢は狭い。あるものだけを書く。

  • 豚 — 肉餃子・焼き餃子の具、ジャジャンソース、オヒャンジャンユクは豚肉が基本だ。この路地の代表的な料理の大半がここに入る。
  • 羊・鶏 — ラクチョンガクの羊肉串、サマルカンドの羊肉・鶏料理。ラクチョンガクにハラルの表記はない。
  • ハラル — サマルカンドはDiningCodeの紹介文に「ハラール認証」とあり、お酒は出さない(持ち込みは可能と書かれている)。認証の有無は紹介文が根拠なので、厳格に守るなら店で認証書を直接確認する。
  • ベジタリアン — 事実上難しい。エビ餃子やナス料理でも、具・だし・油に肉が入ることがあり、麻婆豆腐には普通ひき肉が入る。注文前に尋ねることを前提にする。

⚠ よくある間違い3つ

1. 火曜にシンバルウォンを目指して行く — シンバルウォンは火曜日に休む。定休日は曜日がばらばらだ — 月(ラクチョンガク、チャンチュンバンは第1・3・5週)、火(シンバルウォン)、水(マガマンドゥ、ウォンヒャンジェは出典により水または月)、日(イルプムヒャン)。目当ての店が休みでも同じ路地に代わりの店があるので、表でその日開いている店を先に見る。

2. 午後3時に着いて老舗から行く — ウォンヒャンジェ・イルプムヒャン・ホンソンバンは15:00~17:00前後に閉まる。 この時間帯は、休憩のないシンバルウォン・チャンソンヒャン・チャンチュンバン・ラクチョンガクへ行く。

3. 餃子だけ食べて出てくる — 1950~70年代に開店した華僑の老舗の真価は、カンチャジャン・サムソンチャンポン・オヒャンジャンユクにある。二人以上なら、餃子の店一軒 + 食事の店一軒に分ける。

⚙ FAQ 3つ

Q. なぜ釜山のチャイナタウンを「上海街」と呼ぶのですか?

1993年に釜山と上海が姉妹都市になったことで、通りの名前を上海街と定め、入口に上海門を立てた。華僑の通りそのものはそれよりずっと古く、1884年に清国領事館が置かれたあとに形成された。

Q. 『オールド・ボーイ』の焼き餃子はどこのものですか?

korea.net(2019)によると、映画の中の焼き餃子はこの路地のチャンソンヒャンのものだ。チャンソンヒャンは今も焼き餃子(小 9,000ウォン)を売っている。

Q. 荷物があっても持って行っていいですか?

路地が狭く、店も小さい。何軒も回るなら荷物は少なくしたほうが楽だ。一軒だけ立ち寄る30分コースなら、駅前広場から道を一本渡る距離である。
