#380韓国伝統市場フルガイド(12cluster)で満席・全州南部・光州良洞・大邱薬令市をカバー。本#618 sub-deepは地方伝統市場マニア単独マトリックス＝ソウル外の外国人マニア＋本場cultureフルセット。

ソウル広蔵市場・南大門が「入門」なら、地方伝統市場は「本場ローカル」です。KTX・高速バスのアクセスが良くなり、2024~2026年基準で江陵・全州・光州・大邱の地方市場は外国人訪問客が目に見えて増えました。ソウルから1~2時間以内で到達できる市場がほとんどで、現地の物価はソウル比20~30%安いです。

軸1：江原・江陵(3選)

1. 江陵中央市場

位置: 江原特別自治道江陵市城南洞(江陵駅徒歩15分／タクシー7分)

営業時間(2026年基準)

  • 常設店舗: 09:00~18:00(月~日)。一部店舗月曜休業。
  • 5日市併行: 毎月2・7・12・17・22・27日(約徒歩30分圏内の露天市場拡張)

外国人fit

江陵中央市場の核心はタッカンジョンと東海水産です。すでにSNSで外国人旅行者コミュニティ(Reddit r/korea、TripAdvisor)で「Gangneung chicken candy」として知られています。タッカンジョン横丁には複数の店舗が密集しており、ほとんどが現金+カードどちらも利用可能。英語メニュー表は少ないですが、「タッカンジョン one box」のような単純注文は指差しで可能です。

価格(₩、2026年)

  • タッカンジョン小箱: ₩9,000~12,000
  • 東海イカ(活イカ1匹処理): ₩6,000~10,000
  • ムルフェ(Mulhoe / 물회)1人前: ₩12,000~15,000
  • 焼きとうもろこし: ₩2,000~3,000

アクセス

  • ソウル清涼里駅 → KTX-Eum江陵駅: 約2時間、料金₩27,600~34,200
  • 江陵駅 → 市場: 徒歩15分または市内バス202番(₩1,300)

英語対応: 部分(タッカンジョンなど人気店舗は基本注文英語OK、深い会話は翻訳アプリ活用)

タイミング: 午前10時~午後1時(新鮮な水産+タッカンジョン当日焼きの最初のタイム)。5日市の日に訪問すると露店の見応えが2倍。

外国人の失敗

  • タッカンジョンの店は複数あるが「元祖」はない — 横丁全体が競争構図。行列が長い店が実証済みの店。
  • 東海水産はkg単位販売が基本。1人分の少量購入は「少しだけ」+指で欲しい量を示す。

2. 束草中央市場

位置: 江原特別自治道束草市中央路147番地(束草高速バスターミナル徒歩15分／束草市外バスターミナル徒歩10分)

営業時間(2026年基準)

  • 常設: 08:00~21:00(一部水産店舗06:00~)
  • 夜市: 夏季(6~8月)18:00~23:00運営(時期により変動 — 訪問前確認推奨)

外国人fit

束草中央市場はイカスンデとタッカンジョンの全国元祖論争がある場所です。外国人にはこの二つが視覚的にインパクトが大きいです。イカスンデはすでにYouTube食べ歩きチャンネルで何度も紹介され、2024~2025年基準で日本人・中国人団体観光客が着実に訪れています。市場内部は狭い横丁構造 — ピーク時間(10~12時)は混雑します。

価格(₩、2026年)

  • イカスンデ1匹分: ₩10,000~15,000
  • タッカンジョン小箱: ₩10,000~13,000
  • アバイスンデ(Abai-sundae / 아바이순대)1人前: ₩7,000~9,000
  • 焼き魚1人前: ₩10,000~12,000

アクセス

  • ソウル東ソウルターミナル → 束草: 約2時間30分、₩17,600(高速バス)
  • ソウル上鳳ターミナル → 束草: 約2時間、₩15,000~18,000(料金変動あり)
  • 江陵 → 束草: 市外バス約1時間、₩4,500

英語対応: 部分(イカスンデ・タッカンジョンの主要店舗は基本注文OK)

タイミング: 午前9~12時(昼食前の鮮度+待ち列が短い)。夏季夜市目的なら18時以降。

3. 襄陽・三陟5日市

位置

  • 襄陽市: 江原特別自治道襄陽郡襄陽邑(KTXなし — 江陵または束草経由バス移動)
  • 三陟五日市: 江原特別自治道三陟市(江陵駅からバス約1時間)

営業時間: 5日市 — 襄陽毎月1・6・11・16・21・26日／三陟毎月4・9・14・19・24・29日。午前06:00~午後13:00(市日のみ)

外国人fit

この二つの市場は外国人マニアのための場所です。英語対応はほぼなく、公共交通アクセスも不便です。しかし本場の江原農産物とローカル生活市場の体験を求める旅行者には代替不可。翻訳アプリ必須。レンタカー移動推奨。

価格(₩、2026年参考)

  • ローカル山菜類: ₩3,000~8,000/束
  • じゃがいも・とうもろこし: ₩5,000~10,000/袋
  • スンデ・チヂミ類: ₩3,000~6,000/人前

外国人の失敗: 5日市はその日にしか開かれません。日付確認なしに訪問すると空っぽの広場だけを見ることになります。

軸2：全北・全州南部(3選)

4. 全州南部市場

位置: 全北特別自治道全州市完山区豊南門広場路(全州駅バス20分／KTX全州駅下車)

営業時間(2026年基準)

  • 常設店舗: 08:00~18:00(日~金)。月曜一部休業。
  • 青年モール夜市: 金・土曜日18:00~22:00(季節により17:00オープンに変動 — 訪問前確認推奨)

外国人fit

全州南部市場の青年モール夜市は外国人旅行者にすでに実証された名所です。全国夜市の中で最もアクセスが良く、韓服レンタル通り(韓屋村)と徒歩20分の距離で組み合わせ動線が自然です。夜市＝金曜日・土曜日訪問必須。

市場の昼間(常設)にはコンナムルクッパ(Kongnamul-gukbap / 콩나물국밥)が代表料理です。全州のコンナムルクッパは全国で最も有名で、南部市場周辺の食堂がその起源の一つです。

価格(₩、2026年)

  • 夜市グルメ1個: ₩3,000~8,000(串・チヂミ・トッポッキ・飲み物)
  • コンナムルクッパ1人前: ₩8,000~10,000
  • 韓定食セット(周辺食堂): ₩15,000~25,000
  • 夜市の手工芸みやげ: ₩5,000~20,000

アクセス

  • ソウル龍山駅 → KTX全州駅: 約1時間40分、₩38,400~48,000
  • 全州駅 → 南部市場: 市内バス約20分(119番など)またはタクシー₩8,000~10,000

英語対応: 部分(夜市の若手商人は基本英語可能、常設老舗は翻訳アプリ必須)

タイミング: 夜市目的なら金~土17:30入場(人気店舗の行列形成前)。昼訪問なら午前9~11時コンナムルクッパ+市場ツアー。

外国人の失敗

  • 夜市は金・土曜日のみです。日~木訪問時は夜市がありません。
  • 韓屋村から歩いてくると20分以上 — 荷物があればタクシー利用。

5. 全州韓紙・韓服cluster

位置: 全北特別自治道全州市完山区韓屋村一帯(南部市場徒歩20分／慶基殿近隣)

営業時間: 韓服レンタル店09:00~18:00(大部分)。韓紙工芸体験は工房ごとに異なる。

外国人fit

全州韓屋村隣接cluster。韓服レンタルは外国人訪問客の中で非常に高い需要を見せており、特に中国・日本・東南アジアの旅行者に人気です。韓紙工芸体験は予約なしで当日現地受付可能な場所が多いです。

価格(₩、2026年参考)

  • 韓服レンタル(2~3時間): ₩15,000~25,000(業者により異なる)
  • 韓紙工芸体験: ₩10,000~20,000(扇子・ノート作りなど)
  • 韓菓・伝統茶菓セット: ₩8,000~15,000

外国人の失敗: 韓服レンタル後に屋外写真を撮ると、慶基殿の内部入場時に着替え前の列待ちが発生 — 韓服着用状態での慶基殿入場推奨(境内韓服着用無料入場特典あり、現地確認推奨)。

6. 益山・群山近代通り市場

位置

  • 群山: 全北特別自治道群山市(全州からバス約1時間)
  • 益山: 全北特別自治道益山市(全州からバス約30分)

営業時間: 群山公設市場08:00~18:00。近代歴史博物館・広津家屋など周辺名所は09:00~18:00(月曜休館)。

外国人fit

群山は市場自体よりも日本統治期の近代建築物と市場の複合観光地として外国人の魅力が大きいです。ジェボ船着場・旧市庁舎・日本式家屋(広津家屋)と伝統在来市場が徒歩圏内にあります。群山のイソンダン(Iseongdang / 이성당)パン屋は韓国で最も古いパン屋の一つです(現地で行列予想 — 開店直後の訪問推奨、確認推奨)。

価格(₩、2026年参考)

  • イソンダンのあんぱん・野菜パン: ₩1,500~2,500/個(価格変動あり — 現地確認)
  • 群山のコッケジャン(Kkotgejang / 꽃게장)定食: ₩30,000~50,000
  • 市場の粉食類: ₩3,000~7,000

アクセス

  • 全州 → 群山: 高速バス約55分、₩4,500~5,500
  • ソウル → 群山: 高速バス約2時間30分、₩16,000~19,000

軸3：光州・全南(3選)

7. 光州良洞市場

位置: 光州広域市西区良洞(光州地下鉄1号線良洞市場駅下車徒歩5分)

営業時間(2026年基準)

  • 常設卸売・小売: 04:00~18:00(早朝卸売04:00~06:00、小売07:00~18:00)
  • 一部店舗日曜休業

外国人fit

湖南最大の伝統市場。ソウル京東市場と比較される規模ですが観光化は進んでいません。外国人よりローカル住民の比率が圧倒的に高く本物の地方市場体験を求める旅行者に適します。英語案内はほぼありません。

代表的な見どころ: 惣菜横丁(全羅道式塩辛・キムチ・山菜類)、水産横丁、乾物横丁。規模が大きいため道に迷いやすい — 地下鉄駅出口基準で動線を組むこと。

価格(₩、2026年参考)

  • 全羅道式惣菜類(少量購入): ₩3,000~10,000
  • 水産・乾物: 相場により変動大(現地確認)
  • クッパ・スンデクッパ1人前: ₩8,000~10,000

英語対応: ほぼなし。翻訳アプリ必須。

タイミング: 午前9~12時(新鮮な食材見学+昼食連携)。早朝卸売タイムは一般観光客には非効率的。

外国人の失敗: 規模が大きい＝駐車なしの公共交通推奨。地下鉄1号線良洞市場駅で降りればすぐ正門前。

8. 光州大仁芸術市場

位置: 光州広域市東区大仁洞(光州地下鉄1号線文化殿堂駅徒歩10分／国立アジア文化殿堂近隣)

営業時間(2026年基準)

  • 常設店舗: 09:00~18:00
  • 夜市(土曜日): 土曜日17:00~21:00(季節により変動 — 訪問前確認推奨)

外国人fit

光州大仁芸術市場は2008年光州ビエンナーレ以降、芸術家が入居し伝統市場+現代芸術複合空間へと変貌しました。土曜夜市は地域の芸術家・独立系商人・グルメが結合したイベントで、光州を訪れる外国人旅行者への推奨度が高いです。英語対応可能な商人比率が良洞市場より高いです(芸術関連の商人)。

価格(₩、2026年参考)

  • 夜市グルメ: ₩3,000~8,000
  • 独立作家の小物・みやげ: ₩10,000~50,000
  • カフェドリンク: ₩4,500~7,000

タイミング: 土曜夜市が外国人fit最高点。昼訪問は常設の芸術工房中心。

9. 木浦・麗水水産市場

位置

  • 木浦自由市場・水産市場: 全南木浦市(木浦駅徒歩15分)
  • 麗水西市場・中央市場: 全南麗水市(麗水エキスポ駅バス20分)

営業時間: 06:00~18:00(水産区域は早朝オープン)。一部日曜短縮。

外国人fit

木浦はホンオで有名です。ホンオは発酵させたものが伝統的な方式で、強い香りのため好き嫌いが分かれます — 外国人旅行者には「チャレンジ料理」として紹介されます。木浦水産市場ではホンオサムハプ(Hongeo-samhap / 홍어삼합)(ホンオ+豚肉+熟成キムチ)セットを少量注文可能です。

麗水は巨文島(Geomundo / 거문도)・突山(Dolsan / 돌산)カッキムチ(Gat-kimchi / 갓김치)と南海の水産物が強みです。麗水夜の海観光と連携した市場訪問動線が効率的です。

価格(₩、2026年参考)

  • ホンオサムハプ1人前: ₩15,000~25,000
  • カッキムチ小分け: ₩10,000~20,000
  • 麗水の岩だこ(小): ₩15,000~20,000

アクセス

  • ソウル → 木浦: KTX約2時間30分、₩48,000~59,000
  • ソウル → 麗水エキスポ駅: KTX約2時間50分、₩52,000~64,000

軸4：大邱・慶北(3選)

10. 大邱西門市場

位置: 大邱広域市中区大新洞(大邱地下鉄3号線西門市場駅下車徒歩5分)

営業時間(2026年基準)

  • 常設: 09:00~18:00(一部区域08:00~)
  • 夜市: 水・金・土・日18:00~23:00(時期により変動 — 訪問前確認推奨)

外国人fit

大邱西門市場の夜市は全国夜市の中で外国人人気TOP3水準です。規模が大きく、大邱十味(大邱の10の味)のグルメを一か所で味わえます。ナプチャクマンドゥ(Napjak-mandu / 납작만두)・モンティギ(Mungtigi / 뭉티기)・蒸しパン・カルグクス(Kalguksu / 칼국수)が代表的で、夜市区域は英語メニュー表を備えた店舗もあります。

昼間は反物・韓服生地・布団類の卸売が特徴 — 外国人観光目的なら夜市タイムのほうがはるかに効率的です。

価格(₩、2026年)

  • ナプチャクマンドゥ1皿: ₩3,000~5,000
  • 蒸しパン1袋: ₩3,000~5,000
  • モンティギ(生肉小)1人前: ₩15,000~20,000
  • 夜市の串類: ₩2,000~5,000

アクセス

  • ソウル東大邱駅: KTX約1時間40分、₩49,100~61,000
  • 東大邱駅 → 西門市場: 地下鉄1号線+3号線乗換約30分、₩1,400

英語対応: 部分(夜市の人気店舗は基本注文英語OK)

タイミング: 夜市開始30分前(約17:30)入場 — 行列なしで人気店舗を確保可能。

外国人の失敗

  • 夜市は天候に影響を受けます(豪雨時は短縮・一時中断の可能性)。天気確認推奨。
  • 市場の入口は複数箇所 — 地下鉄西門市場駅で降りれば夜市区域へ直行可能。

11. 大邱薬令市

位置: 大邱広域市中区達城路(大邱地下鉄1号線薬田横丁駅徒歩5分／西門市場から徒歩15分)

営業時間(2026年基準)

  • 薬令市商店街: 09:00~18:00(土曜短縮、日曜一部休業)
  • 大邱薬令市韓医薬博物館: 09:00~18:00、月曜休館。入場料₩1,000~3,000(確認推奨)

外国人fit

350年の歴史を持つ韓方薬通り。韓薬材の原物を見学し韓医薬博物館で韓医学文化を体験できます。博物館内部は英文案内板があり外国人アクセス性があります。韓薬材購入目的ではなく文化体験目的なら博物館中心の訪問が効率的です。

韓薬材の直接購入は処方箋なしで一部補助食品類が可能ですが、専門的な薬材購入には専門知識が必要です。

価格(₩、2026年参考)

  • 博物館入場料: ₩1,000~3,000(年齢・居住地により異なる — 現地確認)
  • コンジンダン(Gongjindan / 공진단)などの韓医薬製品: ₩30,000~100,000+(店舗により差が大きい)
  • サンファタン(Ssanghwatang / 쌍화탕)・韓方ドリンク: ₩3,000~8,000

タイミング: 平日午前10~12時(韓医院・商店の通常営業)。西門市場夜市と当日組み合わせ動線可能。

両都市とも歴史観光地と市場が徒歩圏内にあり歴史ツアー+市場体験の組み合わせ動線が自然です。

1. 5日市の日付未確認: 地方伝統市場の半分は5日市併行運営です。日付を確認せず訪問すると平日の小規模営業だけを見ることになります。訪問前に該当市場の公式SNSまたは観光庁ホームページで日付確認必須。

3. 現金未準備: 地方伝統市場の老舗・屋台はカード端末がない場合がソウルより多いです。最低₩50,000~100,000の現金準備を推奨。

FAQ 5

Q1. ソウルの市場と地方市場、違いは?

ソウル広蔵市場・南大門は観光化が進んでいる一方、地方市場はローカル生活市場の比率が高いです。価格は地方が10~30%安い傾向があり、英語対応はより少ないです。「本物の韓国市場」を求めるなら地方、便利な観光体験を求めるならソウルが良いです。

Q2. 1泊2日の地方市場ツアー、どこが最も効率的か?

全州を最も推奨します。KTX1時間40分+夜市(金・土)・韓屋村・ビビンバ・韓服レンタルを1日にまとめられます。予算が中上級以上なら大邱1泊(西門市場夜市+薬令市+近郊ツアー)。水産・海産物目的なら江陵・束草1泊。

Q3. 地方市場訪問時、現金はいくら準備すべきか?

市場グルメ・ショッピング合算基準₩50,000~100,000の現金を推奨。夜市は70~80%カード対応可能ですが、常設の老舗・屋台は現金専用が多いです。ホテル近くのコンビニATMで少額ずつ引き出す方法が便利です。

Q4. 市場グルメのアレルギー・ベジタリアン対応は可能か?

ほとんどの地方市場はアレルギー・ベジタリアン対応が難しいです。スープ系料理(クッパ・チゲ)には大抵煮干し・豚骨の出汁が使われます。ベジタリアン(ビーガン/ハラル)旅行者は事前にメニューを確認するか、1330通訳コールセンターを通じて問い合わせてから訪問することを推奨します。
