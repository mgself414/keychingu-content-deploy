🎯 为什么是外国游客5日游？

外国游客赴韩均衡行程 = 4晚5天 (长途游客首选·MZ世代 (MZ / 엠제트))。首尔 (Seoul / 서울) 3天 + 釜山 (Busan / 부산) 1晚2日，或首尔 (Seoul / 서울) 5日深度游全套。

★ 5日全套行程矩阵

方案 A — 首尔 (Seoul / 서울) 3天 + 釜山 (Busan / 부산) 1晚2日 (外国游客最爱首选)

Day 1 — 抵达 + 明洞 (Myeongdong / 명동)·N首尔塔 (N Seoul Tower / N서울타워)

  • 仁川机场 (Incheon Airport / 인천공항) → 机场铁路 (Airport Railroad / 공항철도) → 明洞 (Myeongdong / 명동)·N首尔塔 (N Seoul Tower / N서울타워)·免税店

Day 2 — 宫殿·韩屋 (Hanok / 한옥)·弘大 (Hongdae / 홍대)

  • 景福宫 (Gyeongbokgung Palace / 경복궁)·韩服 (Hanbok / 한복)·北村 (Bukchon / 북촌)·益善洞 (Ikseondong / 익선동)·弘大 (Hongdae / 홍대)

Day 3 — KTX 首尔 (Seoul / 서울)→釜山 (Busan / 부산)→海云台 (Haeundae / 해운대)

  • 09:00 KTX 首尔 (Seoul / 서울)→釜山 (Busan / 부산) (#239) → 海云台 (Haeundae / 해운대) (#243) + 广安里 (Gwangalli / 광안리) 夜景 → 釜山 (Busan / 부산) 1晚

Day 4 — 釜山 (Busan / 부산) 札嘎其 (Jagalchi / 자갈치)·甘川 (Gamcheon / 감천)·返回

  • 札嘎其 (Jagalchi / 자갈치) (#244) + 甘川 (Gamcheon / 감천) (#245) → KTX 釜山 (Busan / 부산)→首尔 (Seoul / 서울) → 蚕室 (Jamsil / 잠실) (#82)

Day 5 — 江南 (Gangnam / 강남)·汉江 (Hangang / 한강)·出境

  • 江南 (Gangnam / 강남)·HYBE·盘浦汉江 (Banpo Hangang / 반포 한강)·仁川机场 (Incheon Airport / 인천공항)

方案 B — 首尔 (Seoul / 서울) 5日深度游 (城市爱好者)

  • Day 1 明洞 (Myeongdong / 명동)·N首尔塔 (N Seoul Tower / N서울타워) / Day 2 宫殿·韩屋 (Hanok / 한옥) / Day 3 江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대) / Day 4 圣水 (Seongsu / 성수)·梨泰院 (Itaewon / 이태원) / Day 5 汉江 (Hangang / 한강)·出境

⚠ 外国游客5日游常犯的3个错误

1. "5天 = 去不了釜山 (Busan / 부산)": 5天 = 可以去釜山 (Busan / 부산) 1晚2日 (KTX 2.5小时) + 外国游客最爱首选。

2. "5天 = K-pop不够多样": 5天 K-pop = HYBE·SM·YG·KARTS·外国游客最爱首选全套。

3. "5天 = 太紧凑": 5天 = 釜山 (Busan / 부산) + 外国游客最爱首选全套 + 休息也OK。
