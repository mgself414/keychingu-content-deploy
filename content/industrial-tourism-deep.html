⚠ 외국인 자주 실수 5가지

1. "산업관광 = 없음": 한국 산업관광 = 삼성·SK 반도체 + 현대·기아 자동차 + 한화·HD 현대 조선 + POSCO 철강 + 외국인 매니아 1번지 풀세트 + #143·#534·#535 통합.

2. "공장 견학 = 한국인만": 영어 OK = 삼성전자·현대자동차·HD 현대 조선·POSCO + KOTRA 통역 + 외국인 비즈니스 1번지 + #178·#535·#554 통합.

3. "반도체 = 못 봄": 반도체 = 삼성 평택 (세계 #1) + SK 이천 (DRAM #1) + 외국인 영어 OK 견학 + 외국인 매니아 1번지 + #143·#534·#535 통합.
