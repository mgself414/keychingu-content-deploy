ISSUE 03 · #810 · 2026-06-07

🎯 왜 한국 분식 매트릭스인가

외국인 한국 분식 페인포인트 = "길거리 음식 종류가 너무 많다". 분식 = 가성비 + 가벼움 + 길거리·뗙뗙이 + 외국인 인스타 1번지. 같은 떡볶이도 신당동 vs 명동 vs 부산 다름, 김밥도 마약김밥·꼬마김밥·참치김밥 다양. 외국인은 (a) 메뉴판 종류 너무 많아 선택 어려움 (b) 매운맛 가감 모름 (c) 가격이 1,500원~5,000원으로 너무 저렴해 의심 (d) 어떻게 먹는지 모름. 본 가이드는 8종 매트릭스 + 지역별 시그니처 + 외국인 입문 우선순위.

🍢 분식 8종 deep dive

🌶 떡볶이 (Tteokbokki) — 외국인 #1

  • 시그니처: 신당동 마복림 (1953 즉석떡볶이 발상) / 명동 떡볶이 골목
  • 종류:
  • 국물떡볶이 (Spicy soupy): 가장 일반적
  • 즉석떡볶이 (Cooked at table): 신당동식
  • 궁중떡볶이 (Royal court): 간장 양념·궁중 정통
  • 로제떡볶이 (Rose tteokbokki): MZ 트렌드 (크림 + 매운맛)
  • 맛 단계: 안 매움 → 살짝 매움 → 매움 → 매우 매움. "안 맵게 해주세요" = "Less spicy, please"
  • 가격: 3,500~6,000원 / 즉석 = 4인 30,000원~

🍙 김밥 (Gimbap) — 외국인 입문 #1

  • 시그니처: 광장시장 마약김밥 (Mayak Gimbap, "addictive" 별명) / 천국김밥 (체인 #1)
  • 종류:
  • 참치김밥 (Tuna) — 외국인 1순위 (실패 확률 #1 낮음)
  • 마약김밥 (Mayak, 미니 사이즈) — 광장시장 1번지
  • 꼬마김밥 (Mini) — 1bite size, 어린이 OK
  • 돈가스김밥 (Pork cutlet)·치즈김밥 (Cheese) — MZ 트렌드
  • 외국인 친화도: ★★★★★ (영문 메뉴 多, 사진 메뉴, 한국식 sushi 인지)
  • 가격: 3,000~5,000원

🩸 순대 (Sundae)

  • 시그니처: 광장시장 순대골목 / 신림동 순대타운
  • 외국인 진입 장벽: 순대 = blood sausage. 첫 한국 음식엔 비추, 호기심 매니아용
  • 추천 토핑: 떡볶이 국물·다대기·들깨가루
  • 가격: 4,000~7,000원

🍤 튀김 (Twigim) — 분식 매니아

  • 종류: 오징어튀김·새우튀김·고구마튀김·김말이튀김·만두튀김·야채튀김
  • 추천 페어링: 떡볶이 국물에 찍어 먹기 (가장 일반적)
  • 가격: 1,000~3,000원/개
  • 외국인 친화도: ★★★★ (일본 tempura 유사)

🥟 만두 (Mandu)

  • 시그니처: 명동교자 (1966 — 칼국수+만두 노포, 외국인 인지도 상위) / 광장시장 만두
  • 종류:
  • 고기만두 (Meat): 돼지·쇠고기
  • 김치만두 (Kimchi): 매콤
  • 당면만두 (Glass noodle): 잡채 만두
  • 물만두 (Boiled)·찐만두 (Steamed)·군만두 (Pan-fried)
  • 외국인 친화도: ★★★★★ (중국 dim sum 인지·일본 gyoza 유사)
  • 가격: 4,000~7,000원

🍜 라볶이 (Rabokki)

  • 시그니처: 라면 + 떡볶이 + 어묵 + 만두 합체. MZ 매니아 1순위
  • 종류: 신라면 라볶이·삼양 라볶이·크림 로제 라볶이
  • 외국인 친화도: ★★★★ (라면 인지)
  • 가격: 5,000~8,000원

🍢 어묵 (Eomuk) — 겨울 매니아

  • 시그니처: 부산 삼진어묵 (1953 한국 #1) / 길거리 어묵 (꼬치 형태)
  • 종류:
  • 꼬치 어묵 (1,000원/개): 길거리 매니아
  • 부산 어묵 (다양한 모양·맛): 부산 어묵 1번지
  • 어묵국 (우동 국물 + 어묵): 추운 날 1순위
  • 외국인 친화도: ★★★★ (일본 oden 유사)
  • 가격: 1,000~2,000원/개

🌭 핫도그 (Korean Hot Dog) — 외국인 vlog #1

  • 시그니처: 명동·홍대·강남 핫도그 매장 cluster
  • 종류:
  • 모짜렐라 치즈 핫도그 (Cheese melting): 외국인 vlog 1번지
  • 감자 핫도그 (Potato): MZ 트렌드
  • 설탕 핫도그 (Sugar coated): 클래식
  • 외국인 친화도: ★★★★★ (외국인 인스타·vlog 1번지)
  • 가격: 3,000~5,000원

🔥 매운맛 가감 가이드

분식 매운맛 단계 외국인 가감
떡볶이 중-매운맛 "안 맵게 해주세요" (Less spicy) → 궁중떡볶이 추천
라볶이 중-매운맛 크림 로제 라볶이 = 매운맛 ↓
김치만두 매운맛 고기만두·당면만두 대체
김밥·핫도그·만두 (고기) 안 매움 외국인 입문
순대·튀김·어묵 안 매움 다대기 가감

> 외국인 매운맛 입문: 떡볶이 안 매운맛 → 살짝 매운맛 → 매운맛 단계적

⚠ 외국인 자주 실수 5가지

1. "분식 = 다 매움": 매운 분식 = 떡볶이·라볶이·김치만두만. 김밥·만두·핫도그·튀김 = 안 매움.

2. "가격이 너무 저렴 = 의심": 분식 가격 3,000~7,000원 = 정상. 한국 분식 가성비 ★★★★★.

3. "순대 = 일반 sausage": 순대 = blood sausage. 첫 한국 음식엔 비추.

4. "마약김밥 = 마약 들어감": "마약" = 별명 ("addictive" 의미). 2021년 식약처·관계부처 합동 "마약 단어 사용 자제 권고" → 대체 표기 (꼬마김밥·Mini Gimbap). 단 광장시장 현장 간판은 "마약김밥" 多, 외국인 검색 키워드 통용 = "Mayak Gimbap".

5. "신당동 떡볶이 = 한 매장": 신당동 = 떡볶이 골목 cluster (마복림 외 多 매장). 즉석떡볶이 발상지.

⚙ FAQ 8개

1. 외국인 입문 1순위: 떡볶이 (안 매운맛) + 참치김밥 + 명동교자 만두 3종.

2. 인스타·vlog 1순위: 모짜렐라 치즈 핫도그 + 광장시장 마약김밥.

3. MZ 트렌드: 로제떡볶이·크림 라볶이·치즈 핫도그.

4. 분식 매니아 1번지: 신당동 떡볶이·광장시장 김밥·부산 어묵·명동교자 만두·인사동 호떡.

5. 알레르기: 글루텐(밀·간장)·해산물(어묵·튀김)·콩(된장 양념) 사전 고지.

6. 채식·할랄·코셔: 김밥 (참치·치즈 제외) = 채식 OK / 떡볶이는 어묵·다시 국물(멸치·가다랑어) 기본 포함 = 비채식, "어묵·다시 빼주세요" 요청 필수 / 핫도그·만두·순대·어묵 = 비채식.

7. 결제·팁: 카드 OK 多 / 시장 분식 = 현금 권장 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

분식 = 길거리·시장 매장 多. 위생 = 매대 회전율·청결도 직접 확인. 어린이 = 매운 떡볶이·라볶이 비추, 안 매운 김밥·만두·핫도그 권장. 임신부 = 새우젓·다대기·순대 (혈분) 주의. 알레르기 (해산물·글루텐·콩·견과류) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 떡볶이·김밥·만두·핫도그 = 비할랄 (양념·고기). → 이태원 할랄 분식 매장 일부.
  • 채식·비건: 김밥 (참치 제외)·치즈 김밥 = 채식 가능. 떡볶이 = 어묵 빼고 가능. → [#799 채식·비건](799_외국인_한국_채식_비건_매트릭스_12선_deep_dive.md).
  • 글루텐 free: 떡볶이 양념·라볶이·만두 = 글루텐 多. 튀김 = 밀가루·해산물 사전 확인.
