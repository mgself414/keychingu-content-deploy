韓国春の花祭りガイド — 光陽メファマウル、求礼・利川サンシュユ花祭り、鎮海軍港祭、新安チューリップ公園、青南台ヨンチュンジェ、丹陽・栄州小白山チョルチュク祭り

サブタイトル: 光陽メファマウル(3月、常時開放) · 求礼サンシュユマウル(常時開放) · 2026 求礼サンシュユ花祭り(3月14~22日) · 2026 利川ペクササンシュユ花祭り(4月3~5日) · 2026 鎮海軍港祭(3月27日~4月5日) · 新安チューリップ公園(月曜休み) · 2026 青南台ヨンチュンジェ(4月24日~5月6日、有料) · 2026 小白山チョルチュク祭り(丹陽5月22~24日、栄州5月23~24日) — 2026年の祭りはすべて終了、2027年の日程はまだ登録前 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、韓国の春の花祭りと花の名所を、咲く順にまとめたものです。3月の梅とサンシュユ、3~4月の桜、春のチューリップと4~5月の青南台の春の花、5月の小白山チョルチュク(ツツジの仲間)です。

2026年の祭りはすべて終わりました。 このガイドを書いた2026年11月16日の時点で、韓国観光公社の観光情報には2027年の日程がまだ登録されていません。以下の祭りの情報は2026年の登録値で、参考用です。光陽メファマウルと求礼サンシュユマウルは常時開放、新安チューリップ公園は月曜日を除く開園時間に、祭りと関係なく行ける場所として登録されています。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 3月の梅 — 光陽メファマウル

光陽メファマウル (Gwangyang Maehwa Maeul / 광양 매화마을)、光陽市 ダアプ面 (Daap-myeon / 다압면) モッキル34-2 (Mokgil 34-2 / 목길 34-2)、☎ 061-797-3333 は、蟾津江下流の白雲山のふもとにある村で、毎年3月に梅が咲きます。光陽梅祭りは、大韓民国食品名人のホン・サンニ (Hong Ssang-ri / 홍쌍리)さんが営むチョンメシルノンウォン (Cheongmaesil Nongwon / 청매실농원)とその周辺を開いて春の行楽客を迎える行事です。農園が場所を出し、村の住民が祭りの料理を用意します。梅の下で梅マッコリ (Maesil Makgeolli / 매실막걸리)とニラチヂミ (Buchu-jeon / 부추전)を味わえます。

  • 開く時間: 常時開放。休み: 年中無休。
  • 駐車: 可能(無料)。

📍 3~4月のサンシュユ — 求礼サンシュユマウル・求礼サンシュユ花祭り・利川ペクササンシュユ花祭り

求礼サンシュユマウル (Gurye Sansuyu Maeul / 구례 산수유마을)、求礼郡 サンドン面 (Sandong-myeon / 산동면) ウィアン里 (Wian-ri / 위안리)、☎ 061-783-1039 は、毎年3月にサンシュユが黄色く咲く山村のエコ村です。韓国観光公社の紹介によると、ここのサンシュユは全国の70%以上を占めます。春にはサンシュユ祭り、秋にはサンシュユの実の祭りが開かれ、智異山 (Jirisan / 지리산)トゥルレギル (Dulle-gil / 둘레길)7区間に近い場所です。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

2026 求礼サンシュユ花祭り (Gurye Sansuyu Kkot Chukje / 구례산수유꽃축제)、登録住所 求礼郡 サンドン面 サングァン1キル45 (Sangwan 1-gil 45 / 상관1길 45)、行事場所は求礼サンシュユ花祭りの会場またはサンシュユ文化館 (Sansuyu Munhwagwan / 산수유문화관)、☎ 061-780-2390 は、智異山のふもとのサンドン面一帯で毎年3月に開きます。韓国観光公社の紹介によると、全国最大のサンシュユの群落を背景にしています。2026年は3月14~22日、09:00~18:00に開かれ、料金は無料でした。

  • 登録された2026年のプログラム: 豊年祈願祭 (Pungnyeon Giwonje / 풍년기원제)、開幕公演、サンシュユの実むき大会、サンシュユのお餅つき体験、子ども向けキャラクター・キーリング作り、サンシュユ花道ウォーキング、バスキング。

2026 利川ペクササンシュユ花祭り (Icheon Baeksa Sansuyu Kkot Chukje / 이천백사 산수유꽃축제)、利川市 ペクサ面 (Baeksa-myeon / 백사면) ウォンジョンノ775番キル12 (Wonjeok-ro 775beon-gil 12 / 원적로775번길 12)、☎ 利川市 (Icheon-si / 이천시) 031-631-2104 の登録行事場所は利川サンシュユマウル (Icheon Sansuyu Maeul / 이천산수유마을)です。ウォンジョク山 (Wonjeoksan / 원적산)のふもとのトリプ里 (Dorip-ri / 도립리)・ソンマル里 (Songmal-ri / 송말리)・キョンサ里 (Gyeongsa-ri / 경사리)一帯がサンシュユの産地で、村全体がサンシュユの木に覆われたトリプ里をはじめ、樹齢100年を超える木が群落をなしています。2026年は4月3~5日、10:00~17:00に開かれました。入場は無料で、一部の体験は有料でした。

  • 登録された2026年のプログラム: 地元ののど自慢大会、祝賀公演、サンシュユ型のクッキー・木製フォト小物作り、伝統遊び(ブランコ・板跳び・投壺)、サンシュユの韓菓 (Hangwa / 한과)・マッコリ (Makgeolli / 막걸리)・ネギチヂミ (Pajeon / 파전)などの食べ物。

📍 3~4月の桜 — 鎮海軍港祭

2026 鎮海軍港祭 (Jinhae Gunhangje / 진해군항제)、昌原市 鎮海区一帯 (Changwon-si Jinhae-gu Ilwon / 창원시 진해구 일원)、☎ 055-546-4310 は、1952年4月13日にブグォン・ロータリー (Bukwon Rotary / 북원로터리)に李舜臣将軍の銅像を建てて追悼祭を行ったことに始まり、1963年から鎮海軍港祭の名前で開かれています。韓国観光公社の紹介によると、祭りの期間に国内外の観光客200万人以上が訪れ、鎮海には桜の木 (Wangbeot-namu / 왕벚나무)が36万本あります。2026年は3月27日~4月5日に開かれました。料金は無料で、チェリーブロッサム音楽祭は有料でした。

  • 登録された2026年のプログラム: 開幕式、軍楽儀仗フェスティバル (Gunak Uijang Peseutibeol / 군악의장페스티벌)、李忠武公追悼大祭・勝利の行列 (I Chungmugong Chudo Daeje·Seungjeon Haengcha / 이충무공 추모대제·승전행차)、ブラックイーグルスの航空ショー、チェリーブロッサム音楽祭 (Cherry Blossom Music Festival / 체리블라썸뮤직페스티벌)、軍部隊の開放行事、ヨジャチョンの星明かり祭り (Yeojwacheon Byeolbit Chukje / 여좌천 별빛축제)、チンヘルのマルチメディア花火ショー (Jinhaeru Multimedia Bulkkot Syo / 진해루 멀티미디어 불꽃쇼)。
  • 桜の名所(登録された紹介): ネスミョン生態公園 (Naesumyeon Saengtae Gongwon / 내수면 생태공원)、ヨジャチョン (Yeojwacheon / 여좌천)、キョンファ駅 (Gyeonghwa-yeok / 경화역)、鎮海塔 (Jinhae-tap / 진해탑)、チンヘル (Jinhaeru / 진해루)。チェファン山 (Jehwangsan / 제황산)のモノレールで鎮海塔に上れます。
  • 軍部隊の開放: 普段は自由に出入りできない海軍士官学校 (Haegun Sagwan Hakgyo / 해군사관학교)と海軍鎮海基地司令部 (Haegun Jinhae Gijisaryeongbu / 해군진해기지사령부)が、軍港祭の期間に開くと紹介されています。

📍 春のチューリップ・4~5月の春の花 — 新安チューリップ公園・青南台ヨンチュンジェ

新安チューリップ公園 (Sinan Tulip Park / 신안튤립공원)、新安郡 イムジャ面 (Imja-myeon / 임자면) テギ里 (Daegi-ri / 대기리)、☎ 061-240-4041 は、テグァン海水浴場 (Daegwang Haesuyokjang / 대광해수욕장)の隣にある公園で、チューリップと春の花を海と一緒に見られます。チューリップ20品種あまり300万本を植えてあり、暖かい春に咲くと紹介されています。風車展望台、ガラス温室(多肉植物展示館・亜熱帯植物展示館)、水辺の庭園があります。

  • 開く時間: 3~10月 09:00~18:00、11~2月 09:00~17:00。
  • 休み: 毎週月曜日。駐車: 可能。ベビーカー貸出: なし。

2026 青南台 春の花祭り ヨンチュンジェ (Cheongnamdae Bomkkot Chukje Yeongchunje / 청남대 봄꽃축제 영춘제)、清州市 サンダン区 (Sangdang-gu / 상당구) ムニ面 (Munui-myeon / 문의면) チョンナムデキル646 (Cheongnamdae-gil 646 / 청남대길 646)、☎ 043-250-5080 は、2003年に青南台 (Cheongnamdae / 청남대)が開放されてから毎年開く忠北の春の祭りです。2026年は4月24日~5月6日、09:00~18:00に、祭りの期間は休館なしで開かれました。

  • 入場料(2026年の登録値): 一般6,000ウォン、青少年・軍人4,000ウォン、子ども・高齢者3,000ウォン。団体(20人以上)・忠清圏の住民は1,000ウォン割引。モノレールは一般(14~64歳)5,000ウォン、そのほか3,000ウォン。未就学児と同伴1人、妊婦、障害3級までと同伴1人は無料と登録されています。
  • 登録された2026年のプログラム: 毎日13:00~15:00の常設公演、野生花の作品展示、国立公園の写真展、環境にやさしい体験・漢方体験、ワイナリー体験、特別企画展。

📍 5月のチョルチュク — 丹陽・栄州 小白山チョルチュク祭り

2026 丹陽 小白山チョルチュク祭り (Danyang Sobaeksan Cheoljjuk Je / 단양 소백산 철쭉제)、丹陽 サンサンの通り (Sangsang-ui Geori / 상상의거리)・丹陽水辺ステージ (Danyang Subyeon Mudae / 단양수변무대)・小白山一帯、☎ 043-423-0701 は、毎年5月に小白山の頂上のチョルチュクに合わせて開きます。2026年は5月22~24日、10:00~22:00に開かれました。料金は無料で、一部の体験は1,000~20,000ウォンでした。

  • 登録された2026年のプログラム: 開幕コンサート、花火、小白山山神祭、チョルチュク・野生花テーマ館、丹陽方言コンテスト、バスキング、プンムル市場。

2026 栄州 小白山チョルチュク祭り (Yeongju Sobaeksan Cheoljjuk Je / 영주 소백산 철쭉제)、栄州市 小白山一帯・プンギ高麗人参文化ポップアップ公園 (Punggi Insam Munhwa Paeop Gongwon / 풍기인삼문화팝업공원)、☎ 栄州市 (Yeongju-si / 영주시) 054-630-8703 は、小白山を舞台にした山岳型の祭りで、チョルチュクの開花に合わせてトレッキングと生態解説を行います。2026年は5月23~24日、10:00~21:00に開かれ、料金は無料でした。

  • 登録された2026年のプログラム: 小白山トレッキング・山岳大会、チュンニョン旧道 (Jungnyeong Yetgil / 죽령옛길)ウォーク、森のコンサート、地元の農特産物の販売所。

⚙ FAQ 2

Q. 祭りの期間でなくても行ける花の名所は?

A. 韓国観光公社の登録情報では、光陽メファマウルと求礼サンシュユマウルが常時開放、年中無休です(両方とも3月に開花)。新安チューリップ公園は月曜日を除いて開きます。

Q. 2026年の春の花祭りはいつ開かれましたか?

A. 求礼サンシュユ花祭りは3月14~22日、鎮海軍港祭は3月27日~4月5日、利川ペクササンシュユ花祭りは4月3~5日、青南台ヨンチュンジェは4月24日~5月6日、小白山チョルチュク祭りは丹陽が5月22~24日、栄州が5月23~24日に開かれました。
