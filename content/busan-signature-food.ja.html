釜山でしか食べられない三品 — テジクッパ・ミルミョン・フェ、注文の作法まで

サブタイトル: ソウルで「釜山 (Busan)スタイル」を真似ることはできても、本物は釜山 (Busan)にしかない。テジクッパ (Dwaeji-gukbap / 돼지국밥)の白濁/澄んだ二系統、冷麺とはまったく違うミルミョン (Milmyeon / 밀면)、市場のフェ (Hoe / 회)のチョジャンチプ (Chojang-jip / 초장집)文化 — 釜山 (Busan)シグネチャー3大巨頭をテーブルで戸惑わない注文ワークフローとともにまとめた。釜山 (Busan)地域ガイド10編(#243~272)のグルメ総論編。

ISSUE · #1320 · 2026-08-23

🎯 なぜこの三品なのか

釜山 (Busan)旅行の検索の半分は「何を食べるか」だ。だが既存ガイドは地域(海雲台 (Haeundae)・チャガルチ (Jagalchi))別に分かれていて、どんな系統があり、テーブルで何をどうするかという料理そのものの文法はばらばらに散らばっていた。この編はその文法をまとめる。ローカルキュレーションアカウントでも釜山 (Busan)の保存物の大半はグルメ関連のシグナルで、『黒白料理人』出演シェフたちが「今のグルメの聖地」として釜山 (Busan)を挙げる流れとも重なる(ソウル版シェフ巡礼は#1317)。

① テジクッパ (Dwaeji-gukbap) — 釜山 (Busan)のソウルフード、まず二系統を選ぶ

スープが二種類あるということから

釜山 (Busan)市の公式分類があるほど確立された区分だ:

  • 白濁スープ(ミルキースタイル) — 牛骨ベース、濃厚でどっしり。初めてなら「想像していたあの味」に近いのはこちら。
  • 澄んだスープ(クリアスタイル) — 肉スープ中心であっさり。二日酔い覚まし・朝食の軸。

テーブルワークフロー(外国人が戸惑うポイント順)

1. セウジョッ (Saeujeot) — 塩の代わりにこれで味を調える。まずは半さじから。

2. ニラ和え (Jeongguji) — クッパに入れるのが基本。最初は半分だけ。

3. ダデギ (Dadegi) — 辛さの調整用。まずスープの味を確認してから入れること。

4. ご飯を入れる — タロクッパ (Ttaro-gukbap / 따로국밥)(ご飯別盛り)でなければ、ご飯は最初から入っている。別盛りにしたいなら注文時に「タロクッパ (Ttaro-gukbap)」と伝える。

5. スユクベッパン (Suyuk-baekban / 수육백반) = クッパ + ゆで豚のセット。2人ならクッパ1 + スユクベッパン1が効率的。

どこで — 検証済みアンカー

  • 釜山駅 (Busan Station)前エリア: シンチャンクッパ (Sinchang-gukbap / 신창국밥)・ポンジョンテジクッパ (Bonjeon-dwaeji-gukbap / 본전돼지국밥) — KTX到着直後の最初の一食として最適(#1114 KTX 2泊3日と連携)。
  • チョバンアプ(ポミルドン) (Jobang-ap, Beomil-dong)のクッパ横丁: ハプチョンシクタン (Hapcheon-sikdang / 합천식당)系列が有名 — 市場の商人たちが「おばあちゃんの店」と「娘の店」と呼ぶ2軒が並ぶ横丁自体が見どころ。
  • ソミョン (Seomyeon): 深夜まで営業するクッパ店が多く、ナイトライフ(#246)の締めくくりの軸。

② ミルミョン (Milmyeon) — 冷麺ではない

何が違うのか

  • 麺: そば粉(冷麺)ではなく小麦粉+でん粉 — もちもちしてコシが強い。
  • スープ: 漢方の香りが漂う冷たいスープ — 冷麺のスープより甘くて濃い。
  • 歴史: 朝鮮戦争の避難時代、釜山 (Busan)で冷麺を小麦粉で再現して生まれた釜山 (Busan)固有の料理。ソウルではほとんど出会えない。

注文の作法

  • ムルミルミョン (Mul-milmyeon) vs ピビムミルミョン (Bibim-milmyeon) — 初訪問はムルミルミョン (Mul-milmyeon)(スープがアイデンティティ)。
  • コッペギ (Gopbaegi)(大盛り)は気前よく盛ってくれる店が多い。夏の繁忙期は行列が基本。
  • 酢・辛子は冷麺と同じ要領で好みに応じて。

どこで — 検証済みアンカー

  • ケグムミルミョン (Gaegeum-milmyeon / 개금밀면)(釜山鎮区 (Busanjin-gu) ケグムドン (Gaegeum-dong)、ケグム市場 (Gaegeum Market)入口) — ミルミョン (Milmyeon)系統を代表する老舗。改装で規模が大きくなり見つけやすい。
  • ⚠ 古いリストに頻出する一部の老舗は休業・廃業状態だ — 訪問前に地図アプリで営業確認が必須のカテゴリー。

③ フェ (Hoe) — 市場方式で食べる

  • 釜山 (Busan)のフェ (Hoe)文化の核心はチョジャンチプ (Chojang-jip)システム: 市場でフェ (Hoe)をさばいてもらい、2階や近くのチョジャンチプ (Chojang-jip)で場所代を払って食べる。チャガルチ (Jagalchi)12選(#590)に市場別の動線がある。
  • ソウルと違うポイント: チョゴチュジャン (Cho-gochujang)・テンジャン (Doenjang)・ニンニクの組み合わせが基本で、チャボフェ (Japeo-hoe)・コムジャンオ (Kkomjangeo)・鯨肉といった釜山 (Busan)ならではの軸が別にある。
  • クァンアルリ (Gwangalli)・ミルラクドン (Millak-dong)のフェセンター (Hoe Center)は海の眺め + フェ (Hoe)の組み合わせ — クァンアン大橋 (Gwangan Bridge)の夜景(#243)と組む夕方の動線。
