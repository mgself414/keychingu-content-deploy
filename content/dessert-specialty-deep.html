⚠ 외국인 자주 실수 5가지

1. "한국 디저트 = 빙수만": 한국 디저트 = 전통 떡 UNESCO + 약과·한과 + 호떡·붕어빵 + 빙수 + K-디저트 카페 + 외국인 매니아 1번지 풀세트 + #510·#381·#502 통합.

2. "전통 떡 = 모름": 전통 떡 = UNESCO 2018 + 광장·통인 시장 + 외국인 정통 매니아 1번지 + #380·#502·#523 통합.

3. "K-디저트 카페 = 비쌈": K-디저트 = 누데이크·런던베이글·노티드·성수·서촌·익선동·평점 4.8 + 외국인 MZ 1번지 + #138·#381·#142 통합.

4. "베이커리 = 파리바게뜨만": 베이커리 = 성심당·이성당 (#388 노포 100년) + 파리바게뜨·뚜레쥬르 + 외국인 매니아 풀세트 + #388·#534·#178 통합.
