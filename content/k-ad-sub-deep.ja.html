外国人がよくやりがちな勘違い3つ

1.「事務所ビル=自由に入場できる」という誤解

HYBE・SM・YG・JYPの事務所ビルは、外観の撮影スポットは自由に利用できますが、内部は有料展示施設(HYBE INSIGHT)か、そもそも入場不可です。HYBE INSIGHTはNaver予約での事前確保が必須——当日窓口購入は週末ほぼ売り切れが常態化しています。

2.「CFロケ地=いつでもオープン」という誤解

北村韓屋村 (Bukchon Hanok Maeul / 북촌한옥마을) — サムスンや現代自動車のCFの定番背景 — は、午前10時前が最もCFらしい雰囲気に近い時間帯です。週末の昼間は観光客が密集し、「CFの中の静かな路地」の空気を再現するのは難しくなります。

3.「広告看板・OOH=いつ行っても見られる」という誤解

江南 (Gangnam / 강남) のK-POP SQUARE(SM外壁)や弘大 (Hongdae / 홍대) 周辺のOOH広告は、アイドルのカムバックシーズンに集中します。ファンダムによる自主広告(誕生日広告・応援広告)は入れ替わりが頻繁なため、訪問前にX(旧Twitter)で「#カンナム広告」「#コエックス広告」といったハッシュタグを検索し、掲出スケジュールを事前に確認するのが現実的です。

12選4軸 — スポット・体験ガイド

軸1: K広告ミュージアム・事務所体験スペース(3選)

1. HYBE INSIGHT

  • 場所: ソウル特別市龍山区 (Yongsan-gu / 용산구) 漢江大路42(龍山駅から徒歩5分)
  • 入場料: 大人₩29,000 / オンライン予約で₩2,000割引
  • 営業時間: 火〜日10:00〜19:00(月曜休館、最終入場18:00)
  • 見どころ: BTS・SEVENTEEN・NewJeansなどHYBE所属アーティストのアルバムアートワーク・CF撮影の舞台裏・ミュージックビデオ制作過程を展示。広告キャンペーンのオリジナル小道具(衣装・小物・ポスター原画)を実物展示しています。
  • 外国人向け度: 展示全体に英語・日本語・中国語の案内あり。オーディオガイドアプリも提供。Googleマップのレビュー言語分布から見て外国人比率は60%以上と推定されます。
  • 予約: Naver予約またはhybe.comから。週末・祝日は2週間前に完売することが多いため、平日午前枠を優先して押さえるのがおすすめです。

2. SMタウン コエックスアティウム(SMTown @ COEX Artium)

  • 場所: ソウル特別市江南区永東大路513 コエックスアティウム(三成駅から徒歩5分)
  • 入場料: 1〜3階は入場無料 / グッズショップ・フォトブースは有料
  • 営業時間: 11:00〜22:00(年中無休)
  • 見どころ: SM公式のポップアップ・展示・グッズショップ。外壁のK-POP SQUARE大型LEDスクリーンは江南OOH広告の代表的ランドマークです。EXO・aespa・NCT・SHINeeのCF撮影裏側グッズを常設展示。
  • 外国人向け度: 三成駅直結のコエックスモール内という立地なのでアクセスしやすく、外国人比率も高めです。
  • ヒント: K-POP SQUAREの広告はSM公式広告とファンダム自主広告が交互に掲出されます。推しアイドルの広告掲出スケジュールは、X(旧Twitter)で「K-POP SQUARE 広告」のキーワード検索による事前確認がおすすめです。

3. YG事務所外観 + 弘大YGストリート

  • 場所: YG事務所は合井駅から徒歩10分 / YGストリートは弘大入口駅から徒歩5分
  • 入場料: 無料(外観見学のみ)
  • 見どころ: YGストリートはBLACKPINK・BIGBANGのファンダムグッズショップやカフェが密集するエリア。公式スペースではありませんが、ファンダム経済圏を最も肌で感じられるブロックです。
  • ヒント: YG事務所の外観撮影スポットは自由に訪問可能ですが、内部への立ち入りは許可されていません。BLACKPINK×Chanelコラボの広告オブジェは、公式ポップアップイベント期間中のみ展示されます。

軸2: CFロケ地巡礼(3選)

4. 北村韓屋村 — サムスン・現代自動車・Kビューティー CFの舞台

  • 場所: ソウル特別市鍾路区桂洞キル・北村路一帯(安国駅から徒歩5分)
  • 入場料: 無料
  • ベスト訪問時間: 午前9:00〜10:00(観光客が密集する前)
  • CFとのつながり: サムスンのGalaxy Sシリーズ、現代自動車のIONIQ、雪花秀、イニスフリーなどが北村の路地を背景に撮影されています。「北村八景」の階段ビューは国内外の広告に繰り返し登場する定番構図です。
  • 外国人向け度: 英語・中国語・日本語の案内板あり。韓服をレンタルしてCFのワンシーンを再現した撮影も可能(1人₩15,000〜₩30,000)。住民が暮らす地域のため、午前10時前は静かに訪問することが必須です。

5. DDP — 東大門デザインプラザ (Dongdaemun Design Plaza / 동대문디자인플라자) — K広告・メディアアートの拠点

  • 場所: ソウル特別市中区乙支路281(東大門歴史文化公園駅から徒歩1分)
  • 入場料: 外観・広場は無料 / 企画展は₩5,000〜₩15,000
  • 営業時間: 外観は24時間開放 / 展示館10:00〜20:00
  • CFとのつながり: NewJeans×Coca-Cola、aespa×Gentle Monsterなど、K-popブランドコラボのポップアップ展示が繰り返し開催されています。メディアアートファサード(外壁LED)は夜8時以降が最も鮮やかです。
  • 外国人向け度: 英語案内が充実。ザハ・ハディド設計の外観は国際的な建築ランドマークです。企画展のスケジュールはddp.or.krで事前確認を。

6. 光化門広場 (Gwanghwamun Gwangjang / 광화문광장) + 世宗大路OOH広告ストリート

  • 場所: ソウル特別市鍾路区世宗大路172(光化門駅から徒歩1分)
  • 入場料: 無料
  • CFとのつながり: 新製品ローンチや国家イベントの広告キャンペーンによる大型垂れ幕・バスシェルター広告が集中するエリア。サムスン・LG・現代自動車のグローバルキャンペーンが英語+韓国語の併記で掲出されます。
  • 外国人向け度: ソウル外国人観光の定番No.1スポット。世宗大王像・景福宮を背景に大型OOH広告を1フレームに収める構図の写真がSNSで繰り返しシェアされています。
  • ヒント: 国家的行事(三一節・光復節)の前後は大型キャンペーン広告の切り替え時期にあたり、OOH密度が最も高くなります。

8. 弘大前K-popストリート + ファンダム広告

  • 場所: ソウル特別市麻浦区弘益路(弘大入口駅から徒歩2分)
  • 入場料: 無料
  • 見どころ: ファンダム広告(地下鉄ホームドア・バスシェルター・電光掲示板)が密集するエリア。BTS・SEVENTEEN・NewJeansのファンダム広告が弘大入口駅のホームドアに定期的に掲出されます。

  • ヒント: ホームドア広告は1日単位で入れ替わります。アイドルのカムバック当日に訪れると公式カムバック広告に出会える確率が最も高くなります。カムバックのスケジュールは公式SNSで2週間前に告知されます。

9. 梨泰院 (Itaewon / 이태원) ・漢南洞 (Hannam-dong / 한남동) ラグジュアリーK-ADストリート(BTS×LV / BLACKPINK×Chanel)

  • 場所: ソウル特別市龍山区梨泰院路・漢南大路一帯(梨泰院駅・漢南駅から徒歩5〜10分)
  • 入場料: 通り自体は無料 / ポップアップイベントは別途(無料〜₩10,000程度)
  • 見どころ: BTS×LV、BLACKPINK×Chanelといったグローバルラグジュアリーブランドとのコラボポップアップ展示が、漢南・梨泰院のフラッグシップストア周辺を中心に開催されます。アンバサダー交代のタイミングごとに外壁の大型広告が掲出されます。
  • 外国人向け度: 漢南洞はソウルの中でも外国人居住者・訪問者比率が最も高いエリアの一つ。英語での意思疎通も問題なく、LV・Dior・Gucciのフラッグシップ店舗が集中しています。
  • ヒント: ポップアップは事前予約が必要なケースが多いです。ブランドの韓国公式SNSのフォローがおすすめ。ポップアップ開催期間外でも、フラッグシップ店舗の外観は撮影スポットとして訪れる価値があります。

10. K-popファン広告ツアー(自主コース)

  • 方法: 専用チケットは不要。ファンダムコミュニティ(X・ファンカフェ)で広告掲出スケジュールを集めたうえで、主要拠点を自分で巡ります。
  • 主要拠点: 江南K-POP SQUARE / 弘大入口駅ホームドア / コエックスモール電光掲示板 / 新村Uプレックス外壁 / 蚕室ロッテタワー周辺
  • 費用: 1日地下鉄フリーパス₩5,000で全拠点をカバー可能。
  • 外国人向け度: 日本・東南アジア・中東のK-popファンが「推し活広告ツアー」のために訪韓する事例がSNS上で急増中。Xでは「#広告ツアー #ソウル」のような日韓英混在タグで感想がよくシェアされています。
  • ヒント: ファンダム広告は午前7〜9時と帰宅時間帯(18〜20時)の照明が最も鮮やかに見えます。

11. K広告ポップアップカフェ・グッズツアー

  • 方法: HYBE・SM・JYP・YGが不定期に運営する公式ポップアップカフェ。カムバックやアルバムリリースのシーズンに弘大・江南・聖水エリアのポップアップスペースを借り上げて開催されます。
  • 費用: ドリンク₩6,000〜₩12,000 / 限定グッズ₩3,000〜₩30,000
  • 外国人向け度: ポップアップ内部にはCFやミュージックビデオの舞台裏写真・小道具が展示され、「広告のセットそのもの」といった雰囲気。公式フォトカードや限定グッズも購入できます。
  • 情報収集: HYBE・SM・JYP・YGの公式Xアカウント / Weverseアプリの告知をチェック。ポップアップは開催の1週間前に告知されるパターンが多いです。初日・週末は2〜3時間待ちが発生するため、平日オープン直後(11:00〜12:00)の訪問がおすすめです。

12. 韓国広告博物館 + TVCFオンラインアーカイブ

  • 韓国広告博物館: 果川に所在。韓国広告の歴史を1900年代から現在まで展示。入場料無料(2026年6月時点、訪問前に再確認を推奨)。ソウル中心部から地下鉄で40分 → 果川国立現代美術館と組み合わせた半日コースがおすすめです。
  • TVCF.co.kr: 韓国広告のデータベースサイト。BTS・BLACKPINKの広告オリジナル映像を無料で閲覧可能。外国人も会員登録なしでアクセスできます。検索窓にアイドル名を入力すると関連CFが自動検索されます。
  • 外国人向け度: 広告映像そのものが言語の壁が低いコンテンツです。館内の英語案内は限定的ですが、映像鑑賞が中心のため英語なしでも十分楽しめます。

FAQ — 外国人からよくある質問5つ

Q1. HYBE INSIGHTの予約が満席の場合の代替案は?

平日のオープン直後にキャンセル分が出るパターンがあります。Naver予約アプリの通知設定がおすすめです。代替案として、SMコエックスアティウム(無料)+DDP企画展を組み合わせれば、同じくらい濃い内容の1日コースが組めます。

Q2. BTS×LVコラボ広告を実際に見るには?

BTSのカムバックシーズンに、漢南のLV店舗外壁、江南K-POP SQUARE、新門路の大型外壁広告板に掲出されます。常時掲出されているわけではないため、BTS公式Xアカウント(@BTS_twt)またはLV韓国公式Instagramで掲出スケジュールを確認することが必須です。

Q3. 事務所ビル巡りを1日でまとめてできる?

HYBE(龍山)→SMコエックス(江南)→YG弘大周辺(麻浦)→JYP清潭(江南)の順に、地下鉄+徒歩で半日〜1日で回れます。内部に正式入場できるのはHYBE INSIGHTのみの有料施設で、それ以外は外観の撮影スポットです。

Q4. ファンダム広告ツアーのスケジュールはどこで確認できる?

X(旧Twitter)で「#[アイドル名] 広告」「#ソウル広告」と検索するのが一番早い方法です。英語ツイートも多く、外国人でも追跡しやすくなっています。広告掲出の1〜2日前に告知されるのが一般的です。

Q5. 子供連れでも訪問できる場所は?

HYBE INSIGHT・DDP・光化門広場・北村韓屋村・SMコエックスアティウムは子供連れでも問題ありません。弘大・梨泰院の夜間広告ツアーは混雑と夜間という点であまりおすすめできません。
