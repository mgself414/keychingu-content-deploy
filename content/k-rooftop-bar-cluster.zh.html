首尔屋顶酒吧7家 — 看得到南山的会贤·解放村，汉南·弘大15层、圣水、江南17层的屋顶

副标题: 看得到南山的会贤·解放村2家和汉南1家，弘大·上水2家，圣水1家，江南彦州的酒店17层1家。只选了在Kakao地图 (Kakao Map / 카카오맵)上营业中(2026-11-24确认)、并且最近两个月内有到访照片或博客评价的屋顶酒吧。7家都在晚上11点或更晚关门。鸡尾酒1杯的登记价，以登记了价格的三家为准，从13,000韩元(上水 屋顶都市海滩)到18,000韩元(卡布奇诺酒店)。在韩国按出生年份算，满19岁那年起就能买酒，所以要带护照。夏天的户外屋顶见#1236，鸡尾酒吧整体见#1166。

🔞 年龄规定 — 7家共通

《青少年保护法》把青少年定为"未满19周岁"。不过到了满19岁那一年的1月1日，就不再算青少年。也就是说看的是出生年份，不是生日(衿川区厅青少年保护说明，Geumcheon-gu Office / 금천구청)。2026年，2007年出生的人可以点酒。Side Note Club在酒店官方页面上写着"仅限满19岁以上使用"。其余6家没有另外登记年龄规定。但因为是卖酒的地方，入场或点单时可能会被要求出示身份证。外国人的身份证就是护照。

① 会贤·解放村·汉南 — 3家

Nelbosco和日落情调的店主介绍里提到了南山。Seventy Eight Two在Kakao地图座位信息里有屋顶。Nelbosco从白天开门，日落情调和Seventy Eight Two在日落时分开门。彼此之间走路连起来太远，坐出租车换地方更好。

Nelbosco屋顶酒廊&酒吧 (Nelbosco Rooftop Lounge & Bar / 넬보스코 루프탑라운지&바)

会贤站1号出口附近一栋楼屋顶(R5层)的酒廊酒吧。店主介绍是"能看到南山、像休憩花园一样的酒吧"。每天11:30~23:00，所以白天卖咖啡和早午餐，晚上卖酒。登记价是低糖长滩岛冰茶15,000韩元、爱尔兰咖啡12,000韩元(2026-11-19)、布拉塔奶酪玛格丽特披萨22,500韩元、地中海海鲜炖菜39,000韩元、美式咖啡4,700韩元(2026登记)。地址是中区 (Toegye-ro 8-gil 16 R5 / 퇴계로8길 16 R5층)，距会贤站 (Hoehyeon Station / 회현역)(4号线)1号出口106m。

  • 饮食提示: 萨尔西恰橄榄披萨和萨尔西恰奶油意面里的萨尔西恰是意大利香肠。卡布里乔萨披萨上放火腿。海鲜炖菜·虾仁意面·炸鱿鱼圈(小鱿鱼)是海鲜。玛格丽特·卡蒙贝尔披萨和卡普雷塞沙拉以奶酪为主。店主写明爱尔兰咖啡可以选含酒精或无酒精。

日落情调 (Sunset Mood / 선셋무드)

解放村4层的葡萄酒吧。店主介绍是"南山景观屋顶葡萄酒吧"，预约通过Catch Table接受。每天17:30~02:00。葡萄酒·饮品价格没有登记。取而代之的是，店主登记了请求"每桌点1瓶酒或3杯以上"(2026-07-25)。下酒菜登记价是烤箱烤土豆16,000韩元、蓝莓奶油芝士&薄脆饼17,000韩元、蜂蜜烤布里芝士18,000韩元、浓汤味噌酱奶油意面18,000韩元、泡菜饼&肉丸饼19,000韩元、猪排骨酱烤23,000韩元(2026-09~10)。地址是龙山区 (Hoenamu-ro 41 4F / 회나무로 41 4층)，距鹿沙坪站 (Noksapyeong Station / 녹사평역)(6号线)2号出口778m。

  • 饮食提示: 烤猪排骨是猪肉，肉丸饼含肉。浓汤通常是用虾·蟹之类甲壳类做的酱汁。奶酪·奶油类下酒菜很多，避开乳制品的话不好选。不喝酒的话，因为点单条件不太合适。

Seventy Eight Two酒吧 (Seventy Eight Two / 세븐티에잇투)

汉南洞大使馆路3~4层的鸡尾酒吧。Kakao地图座位信息里有屋顶·包间。周日至周四18:00~02:00，周五·周六18:00~03:00，是这一篇里最晚关门的。鸡尾酒价格没有登记。下酒菜登记价是玉米片13,000韩元、烤布里芝士15,000韩元、蒜香虾23,000韩元、玫瑰年糕25,000韩元、什锦香肠套餐25,000韩元、夏威夷炒牛肉28,000韩元、芝士&水果33,000韩元(2026-10-12)。地址是龙山区 (Daesagwan-ro 77 3~4F / 대사관로 77 3~4층)，距汉南站 (Hannam Station / 한남역)(京义中央线)1号出口555m。没有自己的停车场。

  • 饮食提示: 香肠和哈密瓜生火腿(风干火腿)通常是猪肉。蒜香虾是虾的菜。菜名里没有肉·海鲜的下酒菜是玉米片、烤布里芝士、芝士&水果。玫瑰年糕是加了奶油的炒年糕。

② 弘大·上水 — 2家

弘大入口站和上水站走路就能连起来。屋顶都市海滩17:00先开门，Side Note Club营业到02:00。

Ryse酒店Side Note Club (Ryse Hotel Side Note Club / 라이즈호텔 사이드노트클럽)

弘大Ryse酒店15层的鸡尾酒吧。酒店介绍说是"屋顶社交酒廊"。店主介绍是"能一眼收进弘大夜街的鸡尾酒吧"。时间按酒店官方页面是每天17:00~02:00(2026-11-24确认)。Kakao地图上的登记不一样，是12:00~01:00，最后点单00:30。晚上去的话两者有几个小时重叠。官方页面写着仅限满19岁以上，并且所有价格含服务费和增值税。Kakao地图的鸡尾酒登记价是2023~2024年的，所以没有写。地址是麻浦区 (Yanghwa-ro 130 15F / 양화로 130 15층)，距弘大入口站 (Hongik Univ. Station / 홍대입구역)(2号线·京义中央线·机场铁路)9号出口288m。预约通过酒店页面的预约链接或邮件。

  • 饮食提示: Kakao地图登记的菜单(2023~2024)里有用花生波本、马格利冰淇淋、五味子糖浆之类材料做的鸡尾酒。可能和现在的菜单不同，所以有坚果过敏的话，点单时说一声。

屋顶都市海滩 (Rooftop Urban Beach / 루프탑어반비치)

上水站一侧一栋楼6层的鸡尾酒吧。Kakao地图标签里有屋顶·异国风情。周日至周四17:00~24:00，周五·周六17:00~00:20。登记价是蜜桃碎冰13,000韩元(2025-04-15)、卡鲁哇牛奶13,000韩元(2026-06-26)、3杯套餐20,000韩元(2025-04-15)。下酒菜是墨西哥芝士玉米片17,000韩元、枫糖薯条18,000韩元、法式吐司19,000韩元、开胃小点19,000韩元、肉丸21,000韩元、橙子鸡26,000韩元(2025-04)。地址是麻浦区 (Dokmak-ro 9-gil 38 DE Building 6F / 독막로9길 38 DE빌딩 6층)，距上水站 (Sangsu Station / 상수역)(6号线)1号出口497m。

  • 饮食提示: 卡鲁哇牛奶含牛奶。橙子鸡是鸡肉。肉丸没有写是什么肉，要问一下。法式吐司通常用鸡蛋和牛奶。菜名里没有肉的下酒菜是薯条和玉米片(配料请点单前问)。

③ 圣水·江南 — 2家

两家隔着汉江。选离住处近的一边。

Archive Seoul (Archive Seoul / 아카이브 서울)

首尔林附近一栋楼5层的葡萄酒吧。Kakao地图标签里有屋顶·首尔林。周一至周五18:00~01:00，周六·周日17:00~01:00。登记的菜单全是2022~2024年的，所以没有写价格。请在店里的菜单上看。地址是城东区 (Wangsimni-ro 4-gil 26-7 5F / 왕십리로4길 26-7 5층)，距纛岛站 (Ttukseom Station / 뚝섬역)(2号线)7号出口70m，是这一篇里离站最近的。预约的话，Kakao地图上挂着Catch Table链接。

  • 饮食提示: 登记的菜单里有虾仁蒜香意面(虾)、奇米丘里烤牛小排、水牛城鸡翅(鸡肉)、冷切拼盘(腌制肉类)、卡普雷塞(奶酪)。现在是否还在卖，请在店里问。

卡布奇诺酒店屋顶酒吧 (Hotel Cappuccino Rooftop Bar / 호텔카푸치노 루프탑바)

彦州站前卡布奇诺酒店17层的鸡尾酒吧。每天17:30~23:00，最后点单22:00。Kakao地图店主公告里写着"屋顶酒吧室内空间全年无休"，所以有单独的室内座位。登记价是金汤力·内格罗尼·古典鸡尾酒·阿佩罗气泡酒这类鸡尾酒都是18,000韩元。秀兰·邓波(无酒精)也是18,000韩元。无限畅饮生啤只在平日17:30~20:00，19,000韩元(2026-04~06登记)。下酒菜是腌橄榄17,000韩元、玉米片和松露薯条20,000韩元、冷切拼盘39,000韩元。地址是江南区 (Bongeunsa-ro 155 17F / 봉은사로 155 17층)，距彦州站 (Eonju Station / 언주역)(9号线)1号出口154m。只能用酒店代客泊车。

  • 饮食提示: 章鱼·小鱿鱼·虎虾·蛤蜊菜品是海鲜。冷切拼盘是腌制肉类。菜名里没有肉·海鲜的是番茄扁面(26,000韩元)、布拉塔奶酪沙拉(28,000韩元)、青柠冰沙和柠檬意式冰淇淋(15,000韩元)。不喝酒的话选秀兰·邓波。

🗺 动线 — 两条路线

A. 会贤·解放村·汉南 (下午到深夜)

  1. 日落前 在Nelbosco (Nelbosco / 넬보스코)(11:30~23:00)一边看南山一边喝第一杯。距会贤站1号出口106m
  2. 17:30以后 坐出租车换到解放村的日落情调 (Sunset Mood / 선셋무드)。两人以上的话，一瓶酒正合适
  3. 午夜前后 汉南的Seventy Eight Two (Seventy Eight Two / 세븐티에잇투)(周五·周六到03:00)

B. 弘大·上水 (傍晚到凌晨2点)

  1. 17:00 在屋顶都市海滩 (Rooftop Urban Beach / 루프탑어반비치)用13,000韩元的鸡尾酒开始
  2. 21:00以后 换到弘大入口站一侧Side Note Club (Side Note Club / 사이드노트클럽)的15层(到02:00)

日落时间每个季节都不一样，所以按当天的日落时间来选第一家店。店与店之间的移动时间，用Kakao地图导航确认。

⚠ 常见失误3个

  1. 在日落情调 (Sunset Mood / 선셋무드)只点一杯 — 店主登记了请求每桌点1瓶酒或3杯以上。一个人想轻松喝一杯的话，别的地方更合适。
  2. 白天去Side Note Club (Side Note Club / 사이드노트클럽) — Kakao地图上显示12:00开门，但酒店官方时间从17:00开始。晚上去。
  3. 周末指望卡布奇诺的无限畅饮生啤 — 19,000韩元的无限畅饮生啤只在平日17:30~20:00有。

⚙ 常见问题3个

  1. 不喝酒也值得去的地方有哪些？ — Nelbosco (Nelbosco / 넬보스코)有咖啡·茶·果汁，爱尔兰咖啡可以选无酒精。卡布奇诺酒店 (Hotel Cappuccino / 호텔카푸치노)有无酒精鸡尾酒秀兰·邓波(18,000韩元)。日落情调 (Sunset Mood / 선셋무드)有点酒条件，不合适。
  2. 开到凌晨的地方有哪些？ — 按登记时间，是Seventy Eight Two (Seventy Eight Two / 세븐티에잇투)(周五·周六03:00)、日落情调 (Sunset Mood / 선셋무드)(02:00)、Side Note Club (Side Note Club / 사이드노트클럽)(酒店官方02:00)。Nelbosco (Nelbosco / 넬보스코)和卡布奇诺酒店 (Hotel Cappuccino / 호텔카푸치노)23:00关门。
  3. 冬天也能去吗？ — 7家都登记了2026-11-24看到的每周营业时间。店主另外写了冬季运营的只有卡布奇诺酒店一家，告知室内空间全年无休。其余6家的冬季户外座位运营，没有登记的说明。
