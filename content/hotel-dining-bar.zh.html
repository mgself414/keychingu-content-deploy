⚠ 外国游客常犯的5个错误

1. “酒店餐饮 = 只有贵”: 罗宴 (La Yeon / 라연) 20万~50万韩元 (₩200,000~500,000 / ~150-375 USD / ~1080-2700 RMB / ~22,000-55,000 JPY) + 米其林三星·碧彩娜 (Bicena / 비채나) 10万~30万韩元 (₩100,000~300,000 / ~75-225 USD / ~540-1620 RMB / ~11,000-33,000 JPY) + 午餐套餐 (定食 / 套餐) 性价比高 (6万~10万韩元 / ₩60,000~100,000 / ~45-75 USD / ~320-540 RMB / ~6,600-11,000 JPY) + 外国爱好者首选。

2. “酒店酒吧 = 仅限住客”: 乐天世界塔西格尼尔酒店 (Signiel / 시그니엘) BAR 81·悦榕庄 (Banyan Tree / 반얀트리) 月光酒吧 (Moon Bar / 문 바)·康莱德37 (Conrad 37 / 콘래드 37)·JW万豪酒店 (JW Marriott / JW메리어트) 格里芬酒吧 (Griffin Bar / 그리핀 바) = 外部客人也可使用 + 建议提前预订 (特别是周末夜景)。

3. “米其林 = 只有韩餐”: 罗宴 (La Yeon / 라연) (韩餐)·碧彩娜 (Bicena / 비채나) (高级韩餐)·喻园 (Yu Yuan / 유유안) (中餐)·悦榕庄 (Banyan Tree / 반얀트리) Festa (四种)·乐天酒店 (Lotte Hotel / 롯데호텔) 桃山 (Momoyama / 모모야마) (日餐) 外国爱好者选择多样。

4. “BAR 81 = 很贵”: BAR 81 81楼·555米高空景观 = 鸡尾酒 2.5万~4万韩元 (₩25,000~40,000 / ~19-30 USD / ~135-215 RMB / ~2,700-4,400 JPY) + 外国爱好者首选 + 夜景 (必须提前预订)。
