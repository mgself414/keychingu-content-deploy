高丽青瓷·月壶 —— 用泥土塑成的韩国之美

> 高丽青瓷 (Goryeo cheongja / 고려청자，翡色·象嵌) · 朝鲜白瓷 (Joseon baekja / 조선백자) · 月壶 (dal-hangari / 달항아리) · 粉青沙器 (buncheong-sagi / 분청사기) · 壬辰倭乱陶工 · 螺钿漆器 (najeon-chilgi / 나전칠기)·结艺 (maedeup / 매듭) · 利川 (Icheon / 이천) 陶艺村 —— 为外国人讲解韩国陶瓷与工艺。不是"哪座博物馆里有什么"，而是"为什么韩国陶瓷不华丽，世界却如此痴迷，泥土里又寄托了怎样的美学"。

外国人在韩国博物馆里常说一句话："挺好看的……可是不是有点素吗？" 对习惯了中国陶瓷精巧纹样、日本陶瓷绚丽彩绘的眼睛来说，韩国陶瓷或许显得平淡。然而正是那份"平淡"，才是世界各大美术馆觊觎韩国陶瓷的理由。高丽青瓷 (Goryeo cheongja / 고려청자) 那神秘的青蓝，朝鲜白瓷 (Joseon baekja / 조선백자) 那一尘不染的白，扭曲却又完美的月壶 (dal-hangari / 달항아리) —— 韩国陶瓷以不张扬来张扬。

这篇文章不是"哪座博物馆好"（→ 那是地点指南），而是讲解韩国陶瓷与工艺中所蕴含的"为什么"与"美学" —— 泥土、火、手相遇，千年间打磨出的克制·自然·留白 (jeolje·jayeon·yeobaek / 절제·자연·여백) 之美。韩国文化讲解系列第69篇。

⚠️ 外国人常误解的3件事

1. "青瓷·白瓷不过是旧时的器皿" ❌ —— 高丽青瓷的翡色 (bisaek / 비색) 与象嵌技法 (sanggam / 상감)，是当时连中国都追不上的世界顶级技术，宋朝人将它推为天下第一。它不是简单的食器，而是尖端工艺的顶点。

2. "韩国陶瓷大概是中国·日本的仿品吧" ❌ —— 象嵌青瓷 (sanggam-cheongja / 상감청자)（在泥上刻挖、填入异色泥土的技法）与月壶 (dal-hangari / 달항아리)，是中国·日本所没有的韩国独有发明。反倒是壬辰倭乱 (Imjin-waeran / 임진왜란) 时被掳走的朝鲜陶工，成了日本陶瓷（有田·萨摩）的根源。

3. "纹样又少、只有白色，太单调" ❌ —— 朝鲜白瓷的"空"不是技术不足，而是刻意留空的美学。克制华丽，选择留白·自然 (yeobaek·jayeonseureoum / 여백·자연스러움) —— 等于把极简主义提前实践了600年。

① 韩国陶瓷是什么 —— 泥·火·手塑成的千年之美

陶瓷 (dojagi / 도자기，陶瓷器) 是塑泥而以火烧成的器皿。朝鲜半岛很早就发达了优质的泥，即胎土 (taeto / 태토)，以及窑炉技术，历经统一新罗·高丽，造出了世界顶级的瓷器 (jagi / 자기，磁器)。瓷器在1,200~1,300℃的高火中烧成，坚硬而发清亮之声，在当时是尖端的高科技产品。

韩国陶瓷史大致分三股脉络。

  • 高丽青瓷 (cheongja / 청자) —— 青蓝色的贵族之美（高丽，~14世纪）
  • 粉青沙器 (buncheong-sagi / 분청사기) —— 从青瓷过渡到白瓷的过渡期朴素之趣（丽末鲜初~16世纪）
  • 朝鲜白瓷 (baekja / 백자) —— 白色的克制品格（朝鲜全期）

从华丽的青瓷走向留空的白瓷，这一脉络本身，原原本本地承载着从高丽（佛教·贵族）转向朝鲜（儒教·士人）的时代精神之变。看陶瓷，便能看见那个时代的人以何为美。

② 高丽青瓷 —— 翡色与象嵌，宋朝推为天下第一

高丽青瓷 (Goryeo cheongja / 고려청자) 是韩国陶瓷的第一座顶点。青瓷技术本身来自中国，但高丽把它提升到了独属于自己的境界。

  • 翡色之神秘 (bisaek / 비색，翡色) —— 高丽青瓷的核心是它的青蓝。在窑内隔绝氧气烧制的还原焰中，呈现出如翡翠玉般清澈深邃的青绿。12世纪前期做出了几乎不见冰裂（细纹）的成熟翡色釉，宋朝使臣徐兢将这颜色称为"翡色 (bisaek / 비색)" 并推为天下第一。
  • 象嵌 —— 韩国的发明 (sanggam / 상감，象嵌) —— 12世纪中叶，高丽完成了象嵌青瓷 (sanggam-cheongja / 상감청자) 这一独创技法。在干燥的器表把纹样刻挖出来，于其处填入白泥·黑泥，再施釉烧成。于是在清澈的青绿釉里，浮现出鹤·云·莲花·杨柳 (hak·gureum / 학·구름) 般的图画。这精巧的技法连中国都几乎没有，是高丽独有的，是在青瓷上"种"画的韩国陶瓷之骄傲。
  • 象征文物 —— 镶嵌着鹤与云的青瓷象嵌云鹤纹梅瓶 (cheongja sanggam unhangmun maebyeong / 청자 상감운학문 매병，梅甁) 是高丽青瓷的代表作，肩宽而向下纤细流泻的优美曲线，与翡色·象嵌相得益彰。

> 含义：高丽青瓷是"色（翡色）与纹（象嵌）兼具的" 华丽而贵族的美。佛教兴盛、贵族文化绽放的高丽那份精致品味，原原本本地寄寓其中。

③ 朝鲜白瓷与月壶 —— 留空之美，扭曲却完美

朝鲜建立之后，陶瓷的美感180度转变。取代华丽的青瓷，一尘不染的白白瓷 (baekja / 백자，白瓷) 成了主角。

  • 为何是白色 —— 新儒学的精神 —— 朝鲜的统治理念性理学（新儒学）(seongnihak·sinyuhak / 성리학·신유학，性理學) 把俭朴·克制·清廉奉为士人的德目。白色正是纯粹·节俭·正直的象征。因此朝鲜士人把无纹的纯白瓷 (sunbaekja / 순백자，純白瓷) 视为最有品格的器皿。白瓷的"空"不是技术不足，而是思想所选择的美学。
  • 月壶 (dal-hangari / 달항아리) —— 朝鲜白瓷的顶点，是17世纪末~18世纪中叶造出的浑圆白瓷大壶，月壶。因为太大，要把上下分别塑好再黏合，在烧制过程中会略微扭曲、不对称。然而那细微的错位，反倒生出像不是满月、而是渐盈之月般自然的韵味 —— "不对称之对称 (bidaeching-ui daeching / 비대칭의 대칭)"。从每个角度看去表情各异，这份不完美正是完成。现存的朝鲜月壶全世界仅约30件，是珍贵的宝物。
  • 名字出于现代 —— 金焕基 —— "月壶"这名字并非自古就有。它本来被称为白瓷大壶 (baekja daeho / 백자대호，白瓷大壺)，是画家金焕基 (Kim Hwan-gi / 김환기，1913~1974) 爱画它、并称其为"月壶 (dal-hangari / 달항아리)"，把它抬升到了艺术品的行列。
  • 世界所爱的白瓷 —— 月壶如今为大英博物馆·V&A·大都会艺术博物馆所收藏，又因BTS的RM (Kim Nam-jun / 김남준) 以朝鲜白瓷爱好者闻名，重新受到全球粉丝的瞩目。它是在拍卖会上以数百万美元成交的当代偶像。

> 含义：白瓷·月壶是"以减损来充盈" 的美。比起完美的对称更取自然的错位，比起华丽的纹样更取纯白的留白 —— 这是韩国美学的精髓。

④ 粉青沙器与陶瓷战争 —— 朴素之趣，以及被掳往日本的陶工

在从青瓷过渡到白瓷之间，以及壬辰倭乱这场悲剧之中，韩国陶瓷又留下了另一段故事。

  • 粉青沙器 (buncheong-sagi / 분청사기，粉靑沙器) —— 从高丽末由象嵌青瓷分化而来、一直造到16世纪的陶瓷。灰青底子上施白土 (baekto / 백토)，于其上加纹样；既不像青瓷那般精巧，也不像白瓷那般端整，特征是自由奔放而朴素之趣。把鱼·草·花毫不迟疑地一挥而就的抽象纹样，是现代陶艺家·设计师最爱的韩国陶瓷之颜。
  • 壬辰倭乱 = "陶瓷战争" —— 1592年的壬辰倭乱 (Imjin-waeran / 임진왜란)，在日本被称为"陶瓷战争 (dojagi jeonjaeng / 도자기 전쟁，陶磁器戦争)"。因为丰臣秀吉甚至专门编组部队，大举掳走了朝鲜的陶工。当时日本造不出瓷器，朝鲜陶工的技术就是财富与权力。
  • 成了日本陶瓷之根的朝鲜陶工 —— 被掳走的陶工李参平 (Yi Sam-pyeong / 이삼평) 在佐贺县有田找到白土矿，烧出了日本最早的白瓷，被尊为日本陶瓷的始祖陶祖 (dojo / 도조，陶祖)。从南原被掳走的沈当吉 (Sim Dang-gil / 심당길) 等人，在鹿儿岛开创了萨摩烧 (Sasseumayaki / 사쓰마야키，薩摩燒)。这种日本瓷器在17世纪大量出口欧洲，甚至影响到欧洲陶瓷（迈森等）。韩国陶瓷技术经由悲剧而散播到了世界。

> 含义：粉青沙器展现"不加修饰的自由" 之美，陶瓷战争则表明"韩国陶瓷技术正是世界所觊觎的尖端"。

⑤ 传统工艺 —— 螺钿漆器·结艺，指尖的美学

还有一门与陶瓷一样深厚的韩国工艺。它不亚于泥土（陶瓷），是处理螺钿·线·木·纸的指尖艺术。

  • 螺钿漆器 (najeon-chilgi / 나전칠기，螺鈿漆器) —— 意为"以螺（螺）装饰（鈿）、上了漆（漆）的器（器）"。把鲍鱼·海螺壳磨得像头发一样薄，做成螺钿 (jagae / 자개)，作为纹样贴在木面上，再反复上漆 (otchil / 옻칠) 收尾。随光线角度，螺钿会虹彩般晶莹地闪烁。有把螺钿切成线状做几何纹样的断切法 (kkeuneumjil / 끊음질)，也有用锯切出梅花·竹·龟纹的锯切法 (jureumjil / 줄음질) 等技法。它在高丽时成就了独立样式并延续到朝鲜，庆南统营 (Tongyeong / 통영) 为名产地。1966年被指定为国家无形遗产螺钿匠 (najeonjang / 나전장) 加以保护。
  • 结艺·刺绣 (maedeup·jasu / 매듭·자수) —— 把一根绳左右对称编结，做出菊花·蜻蜓·蝴蝶 (gukhwa·jamjari·nabi / 국화·잠자리·나비) 形状的传统结艺 (maedeup / 매듭)，以及一针一线用彩线绣成的刺绣 (jasu / 자수)，是装饰佩饰 (norigae / 노리개)·包袱布 (bojagi / 보자기)·服饰的细腻闺房工艺。
  • 其他工艺 —— 从韩纸工艺 (hanji / 한지)（以楮树纸制作匣盒·小物），到漆艺 (otchil / 옻칠)（以天然涂料保护·装饰器物·家具），再到木工艺 (mokgongye / 목공예)（不用钉子拼接的榫卯家具）—— 韩国工艺始终共享着活用自然材料、不事张扬地收尾的克制之美。

> 含义：传统工艺是"慢慢地、用手、活用自然" 做成的。在快速量产的时代，这份价值反而愈发珍贵。

⑥ 利川陶艺村与体验 —— 亲手塑泥试试

有一个地方，能让你不止于"看"陶瓷，而亲手去塑。

  • 利川 —— 陶瓷之城 (Icheon / 이천，利川) —— 京畿道利川是约300余座窑·工坊 (gama·gongbang / 가마·공방) 聚集的韩国代表陶艺村，被指定为联合国教科文组织创意城市（工艺·民俗艺术领域）。新屯面一带的艺斯帕克 (Yeseupakeu / 예스파크，陶瓷艺术村)·砂器幕谷陶艺村 (Sagimakgol / 사기막골) 工坊密集。
  • 利川陶瓷节 —— 每年春季（4月底~5月初） 举办的韩国最大陶瓷节。拉坯成型体验（专业陶艺家在旁指导，烧成后领取成品）、陶瓷直销（最大折扣销售）、表演·展览交织其间。免门票·免停车，外国人也好玩。
  • 陶艺体验 —— 利川之外，首尔·庆州等地的工坊也常有拉坯体验·手捏成型 (haendeubilding / 핸드빌딩)·绘画之类的一日课。泥在手中旋转、形状渐成的触感，是隔着博物馆玻璃柜感受不到的韩国陶瓷的另一重魅力。

> 实战：陶艺体验从塑形 → 干燥 → 入窑烧成通常要2~4周，成品建议以快递领取，或在行程有余裕时再做。也有当场上釉烧成的简易课程，请提前向工坊咨询。

⑦ 陶瓷里的韩国美学 —— 克制·自然·留白

贯穿韩国陶瓷·工艺的美感，一言以蔽之就是"减损之美"。与他国陶瓷一比，便格外分明。

  • 克制 (jeolje / 절제，節制) —— 刻意减少华丽。朝鲜白瓷把纹样留空，不是因为没技术，而是因为视俭朴为德的士人精神 (seonbi jeongsin / 선비 정신)。把本可填满之处留空的勇气 —— 那就是克制之美。
  • 自然 (jayeon / 자연，自然) —— 比起人工的完美，更珍视自然的错位。如同扭曲的月壶、粉青那毫不迟疑的挥洒笔触，把人手与泥·火的偶然相遇所生的表情原样留存。这被称作"无为之美 (muwi-ui mi / 무위의 미，無爲)" —— 不强行修饰的自然。
  • 留白 (yeobaek / 여백，餘白) —— 留空的白底并非单纯的空，而是"可以填充的可能性" 的空间。白瓷的留白即是心的留白 —— 留给观者以想象去填的位置。

这份克制·自然·留白的美学，不只在陶瓷里。从五方色 (obangsaek / 오방색) 那含蓄的配色（#1147），到韩服 (hanbok / 한복) 那流动的线与面（#1189），再到韩屋 (hanok / 한옥) 那留空的庭院与屋檐（#1197）—— 韩国之美始终汇成同一种哲学："与其填满不如留空，与其修饰不如活用自然"。陶瓷正是把那哲学用泥土塑成的结晶。

❓ 外国人常问的问题（FAQ）

  • 青瓷和白瓷有什么不同？ —— 青瓷 (cheongja / 청자) 是青蓝（翡色）陶瓷，代表高丽的华丽·贵族之美；白瓷 (baekja / 백자) 是白色陶瓷，代表朝鲜的克制·俭朴之美。青瓷的核心是象嵌纹样 (sanggam / 상감)，白瓷的核心是纯白的留空。
  • 月壶为什么那么有名？ —— 浑圆纯白而略带扭曲的"不对称之对称"，被推为韩国美学的精髓，画家金焕基又把它格升为艺术品。现存仅约30件因而稀有，BTS的RM等当代名人也喜爱它，于是成了世界级的偶像。
  • 韩国陶瓷在哪里能看？ —— 首尔的国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관) 陶瓷工艺室，是能在一处看遍青瓷·白瓷·粉青的最佳之地。想亲手塑造，则推荐利川陶艺村·陶瓷节（春）。
  • 螺钿漆器是什么？ —— 把贝壳螺钿 (jagae / 자개) 作为纹样贴上、再以漆 (otchil / 옻칠) 收尾的韩国传统工艺。随光线晶莹闪烁，统营 (Tongyeong / 통영) 为名产地。小首饰盒·镜子等也很受外国人欢迎，可作礼物。
  • 壬辰倭乱跟陶瓷有什么关系？ —— 日本把壬辰倭乱称为"陶瓷战争"。因为当时大举掳走朝鲜陶工，他们成了日本陶瓷（有田·萨摩）的始祖。这正是韩国陶瓷技术领先到何种程度的证据。
