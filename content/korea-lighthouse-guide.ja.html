韓国灯台旅行ガイド — イホテウ馬灯台・梧桐島・虎尾串・ウルギ灯台、束草・注文津・墨湖、オイド赤灯台まで灯台20か所と国立灯台博物館

サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「灯台守の秘密の地図」(灯台)テーマで選ばれた場所のうち21か所 · 入場料が登録された場所はすべて無料 · 月曜日に休む場所は梧桐島灯台・ウルギ灯台・影島灯台・ファアムチュ灯台・ヌエソム灯台展望台・国立灯台博物館 · 五六島灯台は2018年から一般に開放しておらず、加徳島灯台は見学申請を受け付けないと登録されています — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「灯台守の秘密の地図 (Deungdaejigi-ui Bimil Jido / 등대지기의 비밀 지도)」(灯台)テーマで選ばれた76か所のうち、観光公社の観光情報で運営情報を確認できた灯台20か所と国立灯台博物館を扱います。表の順位と得票数は、その投票結果です。

入場料が登録された場所はすべて無料です(梧桐島灯台・オイド赤灯台・馬羅島灯台は入場料の登録値がありません)。ただし開く時間と休みは灯台ごとに違います。6か所が月曜日に休みます。イホテウ馬灯台・虎尾串灯台・スルド灯台・チェブド灯台は常時開放、ソンデマル灯台は灯台だけ常時開放(展示館 09:00~18:00)として登録されています。

一般開放や見学が制限されていると登録された場所もあります。五六島灯台は2018年から無人化されて一般の人に開放しておらず(開く時間の欄には「常時開放」とも書かれています)、加徳島灯台は出入りが制限されていて、軍部隊の保安上、当面は見学申請を受け付けないと書かれています。運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。

📍 キョンギ — オイド赤灯台・チェブド灯台・ヌエソム灯台展望台

オイド赤灯台、始興市 オイドロ 170 (Oido-ro 170 / 오이도로 170)、☎ 031-310-2901~4 は、2005年に漁村体験観光村の造成事業で建てた施設です。1階の展示館で始興の文化・観光・歴史情報を見られ、展望台からはシファ工業団地、ベゴッ新都市、インチョン (Incheon / 인천) ソンド新都市 (Songdo Sin Dosi / 송도 신도시)が見えます。1階とつながった「シフンクムサンフェ (Siheung Kkum Sanghoe / 시흥꿈상회)」で記念品を売っています。

  • 開く時間: 10:30~17:30。休み: 年中無休。駐車: 可能。

チェブド灯台、華城市 ソシン面 (Seosin-myeon / 서신면) ヘアンギル 421-17 (Haean-gil 421-17 / 해안길 421-17)、☎ チェブド管理事務所 (Jebudo Gwalli Samuso / 제부도 관리사무소) 031-355-3924 は、チェブド海岸の赤い灯台です。隣に船着き場と、海へつながる展望デッキがあり、灯台から始まる散策路が海岸沿いにチェブド海水浴場まで続いています。チェブドは1日に2回、海の道が開く島です。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

ヌエソム灯台展望台、安山市 ダンウォン区 (Danwon-gu / 단원구) ソンガムドン (Seonggam-dong / 선감동)、☎ アンサンオチョンミンソクパンムルグァン (Ansan Eochon Minsok Bangmulgwan / 안산어촌민속박물관) 031-440-8310 は、タンドハン (Tando-hang / 탄도항)近くの無人島、ヌエソムにあります。ヌエソムは引き潮のとき1日に2回、4時間ずつ干潟が現れて歩いて入れます。1・2階は展示スペースで、3階に展望台と灯台があります。

  • 開く時間: 3~10月 10:00~18:00, 11~2月 10:00~17:00。運営時間は満ち潮・引き潮の時間によって変わるので、訪問前に観覧時間表を確認するようにと登録されています。
  • 休み: 毎週月曜日, 1月1日, 旧正月・秋夕の連休。料金: 無料。

📍 カンウォン — 束草灯台展望台・注文津灯台・墨湖灯台・テジン灯台

束草灯台展望台、束草市 ヨングムジョンロ 5ギル 8-28 (Yeonggeumjeong-ro 5-gil 8-28 / 영금정로5길 8-28)、☎ 束草航路標識管理所 (Sokcho Hangnopyoji Gwalliso / 속초항로표지관리소) 033-633-3406 は、1957年に初めて灯をともした灯台で、今は展望台としても開放しています。竹林の間の木のデッキの探訪路を上ると展望台に着きます。展望台から東海、チョンチョホ (Cheongchoho / 청초호)、ソラクサン (Seoraksan / 설악산)が見えます。すぐ隣にヨングムジョン (Yeonggeumjeong / 영금정)があります。

  • 開く時間: 展望台 09:00~17:00, 屋外スペース 09:00~18:00。休み: 年中無休。料金: 無料。

注文津灯台、江陵市 注文津邑 イェットゥンデギル 24-7 (Yet-deungdae-gil 24-7 / 옛등대길 24-7)、☎ 033-662-2131 は、1918年3月20日に建てられ、観光公社の紹介によると、今はカンウォン特別自治道で一番古い灯台です。レンガを積んだ高さ10mの灯塔に白い石灰モルタルを塗りました。韓国戦争のとき破損し、1951年に復旧されました。

  • 開く時間: 屋外スペース 09:00~18:00, 屋内施設 09:00~17:00。夜間の出入りは禁止です。
  • 休み: 年中無休。料金: 無料。駐車: 無料。

墨湖灯台、東海市 ヘマジギル 289 (Haemaji-gil 289 / 해맞이길 289)、☎ 墨湖航路標識管理所 (Mukho Hangnopyoji Gwalliso / 묵호항로표지관리소) 033-531-3258 は、1963年6月8日に墨湖港の近くに建てられ、海抜67mの場所にあります。夜は色が変わるLED照明をともします。小さな公園が一緒にあります。

  • 開く時間: 09:00~17:00。休み: 年中無休。料金: 無料。

テジン灯台、高城郡 ヒョンネ面 (Hyeonnae-myeon / 현내면) ハンナルロ 4ギル 16-38 (Hannaru-ro 4-gil 16-38 / 한나루로4길 16-38)、☎ 033-682-0172 は、コジン港 (Geojin-hang / 거진항)とマチャジン (Machajin / 마차진)の間の岬にある八角形のコンクリートの灯塔です。灯塔の上の展望台から東海が見え、観光公社の紹介によると、見晴らしのよい日にはヘグムガン (Haegeumgang / 해금강)や北朝鮮地域まで見えます。

  • 開く時間・休み: 電話で問い合わせるようにと登録されています。料金: 無料。

📍 キョンブク — 虎尾串灯台・国立灯台博物館・竹辺灯台・ソンデマル灯台

虎尾串灯台、浦項市 ナム区 (Nam-gu / 남구) 虎尾串面 ホミゴッキル 99 (Homigot-gil 99 / 호미곶길 99)、☎ 054-284-9814 は、1908年12月20日に灯をともしました。観光公社の紹介には、韓国で一番高い灯台と書かれています。1982年にキョンサンブクト (Gyeongsangbuk-do / 경상북도)の記念物に指定されました。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

国立灯台博物館、浦項市 ナム区 虎尾串面 ヘマジロ 150ボンギル 20 (Haemaji-ro 150beon-gil 20 / 해맞이로150번길 20)、☎ 054-284-4857 は、1985年2月に開館し、観光公社の紹介によると、国内唯一の灯台専門の博物館です。灯台をはじめとする航路標識の施設と装備を保存・展示しています。

  • 開く時間: 09:00~18:00(入場締切 17:30)。
  • 休み: 毎週月曜日(祝日ならその次の最初の平日)、旧正月・秋夕の当日。料金: 無料。

竹辺灯台、蔚珍郡 竹辺面 トゥンデギル 52 (Deungdae-gil 52 / 등대길 52)、☎ 054-783-7104 は、1910年11月に蔚珍地域に初めて建てられた灯台です。八角形のコンクリートの4階建ての塔で、高さは15.6mです。韓国戦争中の爆撃で機能を失い、1951年10月に復旧されました。

  • 開く時間: 09:00~18:00。休み: 年中無休。料金: 無料。

ソンデマル灯台、慶州市 カムポ邑 (Gampo-eup / 감포읍) チョクサギル 18-94 (Cheoksa-gil 18-94 / 척사길 18-94)、☎ 054-744-3233 は、カムポ港 (Gampo-hang / 감포항)の北にあります。古い灯台は今は使われておらず、隣にカムンサジ (Gameunsaji / 감은사지)石塔をかたどった5階建ての灯台の建物を新しく建てました。1・2階は光の体験展示館で、3~5階が灯台の役目をします。樹齢300~400年ほどの海松林が灯台を囲んでいます。

  • 開く時間: ソンデマル灯台 常時開放, 灯台展示館 09:00~18:00。休み: 年中無休。料金: 無料。

📍 蔚山 — ウルギ灯台・スルド灯台・ファアムチュ灯台

ウルギ灯台、ドン区 (Dong-gu / 동구) トゥンデロ 155 (Deungdae-ro 155 / 등대로 155)、☎ 052-251-2125 は、大王岩公園の中にあります。灯台へ向かう600mの道ばたに野生の花が咲き、4月にはオウシュウザクラのトンネルが満開になります。灯台を過ぎて階段を下りると大王岩に着きます。

  • 開く時間: 4~9月 09:00~18:00, 10~3月 09:00~17:00。
  • 休み: 毎週月曜日(祝日なら次の非祝日)。料金: 無料。駐車: 無料。

スルド灯台、ドン区 ソンクッキル 122 (Seongkkeut-gil 122 / 성끝길 122)、☎ パンオドン行政福祉センター (Bangeo-dong Haengjeong Bokji Senteo / 방어동행정복지센터) 052-209-4177 は、アーチ形のスルド橋を渡ると着きます。周辺に「子をおぶったクジラ (Saekki Eobeun Gorae / 새끼 업은 고래)」の銅像があり、入口のソリ体験館 (Sori Cheheomgwan / 소리체험관)でクジラと海の音を聞けます。観光公社の紹介には、東海では珍しい夕焼けの名所と書かれています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 無料。

ファアムチュ灯台、ドン区 ファアムトゥンデギル 50 (Hwaam-deungdae-gil 50 / 화암등대길 50)、☎ 052-201-2602 は、1994年12月に建てた亀の形の灯台です。エレベーターで展望台に上ると、蔚山港と産業団地が見えます。

  • 開く時間: 09:00~17:00。休み: 毎週月曜日。料金: 無料。

📍 釜山 — 五六島灯台・影島灯台・加徳島灯台

五六島灯台、ナム区 オリュクトロ 130 (Oryukdo-ro 130 / 오륙도로 130)、☎ ヘパランギル 釜山観光案内所 (Haeparangil Busan Gwangwang Annaeso / 해파랑길 부산관광안내소) 051-607-6395 は、五六島の6つの島のうち、陸から一番遠い灯台島にあります。2018年から無人化されて一般の人に開放していないと登録されていて、影島灯台から遠隔で制御します。開く時間の欄には「常時開放」とも書かれていて、登録値どうしが食い違っています。ヘパランギルの観光案内所で五六島灯台の観光情報を得られます。

  • 休み: 年中無休。料金: 無料。駐車: 可能。

影島灯台、影島区 チョンマンロ 181 (Jeonmang-ro 181 / 전망로 181)、☎ 051-405-1201 は、1906年12月に初めて灯をともしました。2004年8月にリモデリングを終えて、海洋図書室とギャラリーを備えた海洋文化スペースになりました。

  • 開く時間: 10:00~17:00。
  • 休み: 毎週月曜日, 1月1日, 旧正月・秋夕の連休。詳しくは電話で問い合わせるようにと登録されています。料金: 無料。駐車: 不可能。

加徳島灯台、カンソ区 ウェヤンポロ 10 (Oeyangpo-ro 10 / 외양포로 10)、☎ 051-971-9710 は、1909年12月に点灯した灯台で、2003年に釜山広域市の有形文化遺産に指定されました。出入口の上の扁額にスモモの花の紋様が刻まれています。

  • 入る方法: 軍事地域の中なので出入りが制限されていて、軍部隊の保安上、当面は見学申請を受け付けないと登録されています。訪問前に問い合わせます。料金: 無料。

📍 チョンナム 麗水 — 梧桐島灯台

梧桐島灯台、麗水市 オドンドロ 238-32 (Odongdo-ro 238-32 / 오동도로 238-32)、☎ 061-662-3999 は、梧桐島の頂上にあります。1952年5月12日に初めて灯をともし、2002年に高さ27mの八角形の灯塔に建て直しました。外に展望台用のエレベーターがあり、事務棟の2階に展示室があります。灯台へ上る道はツバキの木がトンネルをなし、11月ごろにつぼみがほころんで3月ごろに見ごろを迎えると紹介されています。

  • 開く時間: 4~9月 09:00~18:00, 10~3月 09:00~17:00。休み: 毎週月曜日。駐車: 可能。

📍 済州 — イホテウ馬灯台・サンジ灯台・馬羅島灯台

イホテウ馬灯台、済州市 ソヘアンロ 58 (Seohaean-ro 58 / 서해안로 58)、☎ 済州観光情報センター (Jeju Gwangwang Jeongbo Senteo / 제주관광정보센터) 064-740-6000 は、イホテウビーチ (Ihoteu Bichi / 이호테우해변)にある、済州のポニー (Jorangmal / 조랑말)の形の灯台です。高さ12mの赤い馬灯台と白い馬灯台が、内側の防波堤と外側の防波堤に1つずつ立っています。観光公社の紹介には、済州空港に近いと書かれています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 無料。

サンジ灯台、済州市 サラボントンギル 108-1 (Sarabongdong-gil 108-1 / 사라봉동길 108-1)、☎ 064-740-6000 は、サラボン (Sarabong / 사라봉)の北の斜面にあります。1916年10月に無人灯台として初めて設置され、1999年12月に灯塔を新しく建てました。カフェとギャラリーがあります。

  • 開く時間: 夏季 09:00~19:30, 冬季 09:00~18:00。休み: 年中無休。料金: 無料。駐車: 小型10台。

馬羅島灯台、西帰浦市 テジョン邑 (Daejeong-eup / 대정읍) マラロ 165 (Mara-ro 165 / 마라로 165)、☎ 064-792-8507 は、国土最南端の馬羅島にあります。1915年3月に初めて建て、1987年3月に建て直した高さ16mの白い八角形の灯台です。灯台の前に世界の有名な灯台の模型があります。

  • 行き方: ウンジン港 (Unjin-hang / 운진항)の旅客ターミナルやサニスドン港 (Sanisudong-hang / 산이수동항)から旅客船に乗ります。事前の電話での問い合わせが必須と登録されています。
  • 開く時間: 馬羅島灯台 09:00~18:00。ウンジン港旅客ターミナル 09:40~15:50, サニスドン港の旅客船 09:20~16:10。
  • 旅客船の料金: 大人(成人) 21,000ウォン, 中・高校生 20,800ウォン, 小学生 10,500ウォン, 未就学児 10,000ウォン, 敬老(満65歳以上) 16,000ウォン。

⚙ FAQ 3

Q. 展望台や展示スペースがある灯台は?

A. 登録情報に展望台や展示スペースが書かれているのは、オイド赤灯台(展示館・展望台)、ヌエソム灯台展望台、束草灯台展望台、梧桐島灯台(エレベーター・展示室)、ファアムチュ灯台(エレベーター・展望台)、テジン灯台(展望台)、ソンデマル灯台(展示館)、影島灯台(図書室・ギャラリー)、チェブド灯台(展望台)、サンジ灯台(ギャラリー)、国立灯台博物館(展示)です。

Q. 常時開放として登録された灯台は?

A. イホテウ馬灯台、虎尾串灯台、スルド灯台、チェブド灯台、ソンデマル灯台(灯台だけで、展示館は 09:00~18:00)です。五六島灯台も「常時開放」と書かれていますが、一般に開放していないとも一緒に登録されています。

Q. 一番古い灯台は?

A. このガイドの灯台のうち、登録された点灯・建立の時期が一番早いのは影島灯台(1906年12月点灯)です。その次が虎尾串灯台(1908年12月20日点灯)、加徳島灯台(1909年12月点灯)、竹辺灯台(1910年11月建立)です。
