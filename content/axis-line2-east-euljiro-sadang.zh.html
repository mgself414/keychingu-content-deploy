首尔东西轴④ 地铁2号线东半环，从乙支路到舍堂——高架跨江的车窗路线

副标题：南北轴坐140路，东西轴坐720路——这条轴没有巴士，串联乙支路、圣水、建大、跨江到蚕室、三成、江南、教大、舍堂的只有地铁2号线：汉阳大到蚕室渡口七站地上，蚕室铁桥跨江，约2小时，建大入口下车一次。

ISSUE · #1359 · 2026-09-07

🎯 定调——没有巴士的话，地铁就是轴

首尔南北轴(#1353)乘一辆巴士穿过江南大路，东西轴首篇(#1356)乘一辆巴士穿过钟路。这一篇的据点——乙支路入口站 (Euljiro 1-ga Station / 을지로입구역)、圣水 (Seongsu / 성수)、建大入口站 (Konkuk University Station / 건대입구역)、蚕室 (Jamsil / 잠실)、三成站 (Samseong Station / 삼성역)、江南站 (Gangnam Station / 강남역)、教大站 (Seoul Nat'l Univ. of Education Station / 교대역)、舍堂站 (Sadang Station / 사당역)——没有一辆巴士能一线串联。取而代之的是地铁2号线。绕首尔一圈的环线，东半部分正是按这个顺序运行。

而且2号线的东半部分，是环线中唯一升上地面、跨过汉江的区间。从汉阳大站 (Hanyang University Station / 한양대역) 到蚕室渡口 (Jamsillaru / 잠실나루) 连续七站是地上，在江边站 (Gangbyeon Station / 강변역) 和蚕室渡口之间，列车经蚕室铁桥 (Jamsil Railway Bridge / 잠실철교) 跨过汉江。地铁变成车窗路线的罕见区间。圣水、蚕室、江南站只在车窗外看。下车只有建大入口站一次——是为了引导换乘7号线两站之外的君子 (Gunja / 군자)(#1360)支线。

  • 总耗时：约2小时(乘车约45~50分钟(估计) + 建大入口下车15分钟 + 余裕)
  • 推荐时段：工作日上午10点出发——早高峰结束后有右侧窗边座位，中午前抵达舍堂。晚高峰(17~19点)2号线江南区段是首尔最拥挤的
  • 坡度：无——步行区间只有平地15分钟

为何是2号线东半环——环线唯一跨过汉江的地方

2号线于1980年10月31日以新设洞~综合运动场区间起步，1982年通到综合运动场~教大，1983年乙支路入口~圣水和教大~首尔大入口，最后1984年5月22日首尔大入口~乙支路入口接通，成为环线。绕一圈约需1小时30分钟。顺时针运行的列车叫内环线 (inner circle line / 내선순환)，反方向叫外环线 (outer circle line / 외선순환)——这一篇乘的是内环线。

📖 故事1——为何只有这段是地上：修建环线时，需要跨过中浪川 (Jungnangcheon / 중랑천) 和汉江的东侧，没有挖地下，而是架了高架。所以汉阳大、纛岛 (Ttukseom / 뚝섬)、圣水、建大入口、九宜 (Guui / 구의)、江边、蚕室渡口七站连续是地上站，圣水和九宜之间的高架下，至今仍有一条双向6车道公路。江边和蚕室渡口之间的蚕室铁桥，是公路1979年10月、铁路1980年10月竣工、韩国首座铁路公路合建的桥。2006年起，部分公路改成了自行车道和人行道，人也能从这座桥跨过汉江。

🚶 路线——按车窗外的顺序

起点是2号线乙支路入口站。在内环线(顺时针，圣水·蚕室方向)站台乘车。到圣水为止是地下——车窗外的风景从汉阳大开始。

① 乙支路入口 → 东大门历史文化公园 → 往十里 → 汉阳大 (🚇 约12分钟·地下→地上)

  • 经过乙支路3街·4街批发商圈(#1346)和DDP(#1252)下方，穿过新堂、上往十里、往十里 (Wangsimni / 왕십리)。汉阳大站列车驶出地面——开往圣水方向的站台是地上，从这里开始车窗变亮。
  • 这段地上街区的详细介绍由#1250往十里枢纽负责。这里只呈现车窗由暗转亮的瞬间。

② 纛岛 → 圣水 → 建大入口下车 (🚇 约3分钟·高架)

  • 在高架上，左侧是纛岛、首尔林方向，右侧俯瞰圣水洞的红砖屋顶群(#1342)。圣水站只经过不下车——圣水有#001·#145·#1342。
  • 在建大入口站下车。这一篇唯一的下车站。

③ 建大入口迷你漫步15分钟——顺带君子支线 (🚶 约15分钟)

  • 绕站周边一圈。只尝一尝高架下建大小巷的白天风景——建大、纛岛详情见#178。
  • 支线：在同一站换乘7号线，到儿童大公园站、君子站只有两站，短暂离开这条轴线，就有免费公园和烤大肠小巷的街区。那条清晨路线是#1360。要继续走这条轴线，就回到2号线内环线。

④ 九宜 → 江边 → 蚕室铁桥 → 蚕室渡口 (🚇 约10分钟·车窗高潮)

  • 江边站右侧是东首尔客运站 (Dong Seoul Bus Terminal / 동서울터미널)(1990)和Technomart。列车驶出车站，建筑消失，汉江展开——就在蚕室铁桥上。左侧上游方向是广津桥和峨嵯山 (Achasan / 아차산)，右侧下游方向是奥林匹克大桥，正面南岸远处乐天世界塔 (Lotte World Tower / 롯데월드타워)(555m，2017年)渐渐靠近。
  • 📖 故事2——桥上的地铁：地铁在江面上奔驰的一分钟左右，是这一篇的高潮。南北轴乘巴士过汉南大桥，东西轴乘列车过蚕室铁桥。桥边的人行道也能徒步跨过——步行版本交给#1256·#308。
  • 过了蚕室渡口站，列车再次钻入地下。

⑤ 蚕室 → 蚕室新内 → 综合运动场 → 三成 (🚇 约5分钟·不下车)

  • 蚕室站：就在乐天世界塔下方。不下车——蚕室有#82·#300·#707。蚕室新内 (Jamsilsaenae / 잠실새내) 是2016年底从"新川"改名而来的车站。过了综合运动场站 (Sports Complex Station / 종합운동장역)，到三成站——5、6号出口直接连到COEX (COEX / 코엑스)(#366·#449)。同样只是路过。

⑥ 宣陵 (Seolleung / 선릉) → 驿三 (Yeoksam / 역삼) → 江南 (🚇 约6分钟·不下车)

  • 在德黑兰路 (Teheran-ro / 테헤란로) 地下奔驰。若是地面，会是一整排玻璃写字楼。江南站——首尔最拥挤的车站之一，也是南北轴(#1353)车窗曾经掠过的那个交叉点。两条轴线在这里十字相交。不下车(#301·#1355)。

⑦ 教大 → 方背 → 舍堂 (🚇 约7分钟)

  • 教大站10、11号出口上方是首尔中央地方法院 (Seoul Central District Court / 서울중앙지방법원)——瑞草洞法曹街。过了方背 (Bangbae / 방배)，在舍堂站下车。2号线东半环的终点。

⑧ 舍堂站收尾 (🚶 约3分钟)

  • 14个出口，冠岳、铜雀、瑞草三个区交汇的地方。开往京畿南部的广域巴士排队而立的黄昏风景，以及冠岳山入口，由#1361另行讲述。这一篇到此结束。

🚇 乘车方法·座位贴士5

1. 乘内环线：在乙支路入口站台看"圣水·蚕室方向"(顺时针)。坐反方向(外环)会绕去市厅、弘大方向。

2. 右侧靠窗：坐在行进方向右侧(南侧)，蚕室铁桥的下游、乐天世界塔，以及江边站的客运站都会映入眼帘。左侧是上游和峨嵯山。

3. 到汉阳大之前不用在意座位：是地下区间。到往十里附近再挪到靠窗座。

4. 换乘优惠：在建大入口出站后30分钟内再上车，可享换乘票价。7号线君子支线是站内换乘，不另收费。

5. 没有更快的替代方案：这段区间2号线最快。只是要避开高峰时段——上午10点以后。

🙏 地铁礼仪——这条路线的核心

  • 拍车窗照片时坐着拍，别让其他乘客入镜。通话声音放低。
  • 孕妇专座、老弱病残专座请留空。2号线江南区段白天也有很多人站着。
  • 大件行李箱放在门边空间——尤其在建大入口、蚕室、江南上下车的人多。

💡 容易懵的点

  • 方向容易搞错：2号线两个方向都叫"环线"。要确认指示牌上"内环线·圣水·蚕室"方向。
  • 车窗风景只有汉阳大到蚕室渡口这一段：前后都是地下。约15分钟的地上区间是这一篇的全部，别错过。
  • 建大入口换乘通道很长：要换乘7号线支线，得沿指示牌走几分钟。
  • 舍堂站有14个出口：下车后先确定出口再出站——参见#1361。

FAQ 6

Q1. 为什么这次不是巴士?

  • 没有一辆市内公交能把这八个据点串成一条线。360路虽然经过蚕室→三成→江南站，但之后会拐去论岘、高速巴士客运站。2号线是唯一的轴线。

Q2. 和#1241 2号线篇有什么不同?

  • #1241是围绕观光核心8站，逐站讲"下车后做什么"的攻略。这一篇不下车，按顺序通过，看的是车窗和高架区间的故事。想找下车地点就去看#1241。

Q3. 能看到汉江的区间有多长?

  • 蚕室铁桥上一分钟左右。加上前后的高架区间，车窗明亮的时间合计约15分钟。

Q4. 想在蚕室、江南下车怎么办?

  • 可以下车。这一篇以通过为原则，那些街区的攻略请看各篇(#82·#300·#301·#366)。30分钟内同方向再上车可享换乘优惠。

Q5. 带孩子、带行李也可以吗?

  • 可以。步行区间只有15分钟。只是要避开高峰时段，行李箱放在门边。

Q6. 怎么和南北轴衔接?

  • 两条轴线在江南站交叉。可以把这一篇坐到舍堂，再换乘4号线返回，或者在江南站下车，换乘南北轴140路巴士(#1353)，就能把首尔读成一个十字。
