🎯 #1 按细分市场推荐

👤 独行旅行者（独奏）

  • 第一名：街头tttu - 1至3种品尝，每人5,000至10,000韩元，站立
  • 第二名：广藏市场小吃（单独步行即可）
  • 第三名：MZ 商店（1 人售货亭可以）
  • 避免：Pocha（仅适用于独自夜间饮酒爱好者）

💑 情侣

  • 第一名：MZ 商店（弘大/江南） — Insta 约会 + 玫瑰奶酪热狗
  • 第二名：广藏市场小吃（本地日期，外国人vlog★）
  • 第三优先：Pocha（晚餐饮酒约会）
  • 避免：平日白天街道（氛围↓）

👨‍👩‍👧 家庭

  • 第一优先：MZ店 — 儿童菜单/安全/店铺★，辣度可调节
  • 第二名：市场分析（白天）——家庭走进
  • 第三优先：街道垃圾（安全和卫生预防措施）
  • 避免：Pocha（儿童夜间饮酒

🎨 MZ 趋势 (MZ)

  • 第一名：MZ 店（弘大、延南、圣水） — 玫瑰炒年糕、奶油拉博基、马苏里拉奶酪热狗
  • 第二名：Insta Gwangjang Market（Myak Gimbap、Mozzarella Tteokbokki）
  • 第三名：Pocha（MZ 夜间酒吧）
  • 避免：一般市场/街道（流行↓）

🎒 背包客·预算

  • 第一名：街头tttu — 5,000~10,000韩元/人，3~4种可供品尝
  • 第二名：广藏市场休闲食品（性价比+氛围）
  • 第三名：工作日市场小吃（便宜+品种丰富）
  • 避免：MZ 商店（超出预算）

🍢 4 通道深度挖掘

🍢 路边摊

核心价值：性价比★★★★★+即时+站立。韩国第一街头美食爱好者。

  • 推荐区域（首尔）：
  • 弘大·延南街 — MZ Trend + Tttugi
  • 明洞街 — 外国人第一旅游胜地
  • 江南站街 — 上班族，MZ
  • 钟路/梨泰院街 — 适合外国人
  • 菜单：炒年糕、热狗、油炸食品、鱼饼（4种）
  • 价格：1,500~6,000韩元
  • 系统：即时站立+站立+1~3分钟接待
  • 外国人友好度：★★★（几乎没有英文菜单/很多照片菜单）
  • 付款：建议现金（大柜台刷卡即可）

🛒 市场欺诈（市场欺诈）

核心价值：本地+拼座+免费小菜+国外vlog★。广藏市场=韩国#1市场零食爱好者。

  • 推荐市场：
  • 广藏市场（钟路） — 外国视频博客第一名，药紫菜包饭，红豆年糕，绿豆煎饼，炒年糕
  • 东大门清晨小吃 — 有些全天 24 小时营业
  • 全州韩屋村小吃 — 豆芽汤+紫菜包饭搭配
  • 仁寺洞小吃 — 传统（hotteok、菊花面包、饺子）
  • 釜山札嘎其市场小吃 — 鱼饼+炒年糕
  • 菜单：全部 8 道菜 + 马格利/烧酒搭配 OK
  • 价格: 8,000~15,000韩元
  • 外国人友好性：广场 ★★★★★ / 仁寺洞 ★★★★ / 釜山 ★★★★ / 东大门 ★★★
  • 付款：现金/卡混合使用

🍦 MZ 店（潮流）

核心价值观：时尚+ Instagram + Kiosk + 英文菜单。 MZ No.1休闲食品爱好者。

  • 推荐区域（首尔）：
  • 弘大·延南 — MZ 炒年糕·热狗集群
  • 江南·驿三 — 上班族 MZ
  • Seongsu — MZ Trend（毗邻 Blue Bottle 集群）
  • 梨泰院 — 外国人 MZ
  • 菜单：玫瑰炒年糕、奶油拉博基、马苏里拉奶酪热狗、土豆热狗、炸薯条热狗、玫瑰拉博基
  • 价格：10,000~20,000韩元
  • 系统：自助终端点餐、餐桌用餐、Instagram 氛围
  • 外国人友好度：★★★★（多种英文菜单，多语言服务亭）
  • 付款：自助服务终端+刷卡即可
  • Insta·照片：★★★★★（当马苏里拉奶酪膨胀时，Instagram 排名第一）

🏮 Pojangmacha — 夜间酒吧

核心价值观：夜晚+帐篷+酒精搭配+公司晚宴后的第二次聚会。韩国夜饮文化的精髓。

  • 推荐区域（首尔）：
  • 钟路清溪川Pocha集群 — 外国视频博客第一名
  • 乙支路诺加里胡同 — MZ Pocha
  • 江南·驿三宝茶 — 第二轮上班族公司聚餐
  • 清凉里Pocha — 当地狂热
  • 菜单：炒年糕、田园菜、乌冬面、拉面、牛肚、黑鳗鱼+烧酒、啤酒、马格利酒
  • 价格: 零食 4,000~8,000 韩元 + 酒类 4,000~8,000 韩元 = 15,000~30,000 韩元/人
  • 营业时间：18:00~02:00（或凌晨）
  • 外国人友好度：★★（韩国菜单，深夜氛围）
  • 付款：现金/卡混合使用

⚠ 外国人常犯的5个错误

1. “4个频道=相似”：完全不同的系统、价格、气氛和时区。街头=性价比/市场=本土/MZ=潮流/Pocha=夜饮。

2. “Pocha = 正宗韩国餐厅”：Pocha = 夜间帐篷酒吧（小吃+酒精搭配）。推荐家庭和白天使用。

3. “MZ店=贵”：MZ店性价比=氛围+英文菜单+自助终端+潮流菜单套餐。

4. “广藏市场 = 仅小吃”：广藏市场 = 小吃 + Bindaetteok + Yukhoe + 药物紫菜包饭全套。停留时间可以超过 6 小时。

5. **“街道=卫生 每个摊位之间可能会存在差异 - 直接检查清洁度。

⚙ 8 个常见问题解答

1. 第一道小吃=哪个渠道：MZ店（C型）第一名（英文菜单·Kiosk·潮流）。

2. 没有。 Instagram/vlog 上排名第一：广藏市场（药物紫菜包饭）+ MZ 商店（马苏里拉奶酪热狗）。

3. 酒会/第一场后的第二场：Pocha（夜间饮酒+零食搭配）。

4. 家庭友好：MZ Store No.1（安全和许多儿童菜单）。夜间避开炮车和街道。

5. 每人预算10,000韩元以下：街头小吃（3-4种品尝）或广藏市场的小吃。

6. 过敏·怀孕：参见[#810·#811医疗免责声明](#810)。

7. 付款/小费：MZ = 卡/信息亭/市场/街道 = 建议使用现金/小费 X。

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

这4种休闲食品渠道在街头、市场、商店都可以买到。卫生 = 直接检查营业额和清洁度。儿童 = MZ 商店/Pocha/深夜街头过敏（海鲜、麸质、大豆、坚果）提前通知第一名。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

商店信息免责声明：街边小摊、市场商店和 Pocha 营业时间和菜单经常变化 - 建议在访问前使用 NAVER/Kakao 地图或本地搜索。

饮食限制后备：

  • 清真/犹太洁食：一般零食店=非清真/非犹太洁食。 → 提前搜索梨泰院的一些清真商店。
  • 素食/纯素食：紫菜包饭（不包括金枪鱼和奶酪）=素食OK/炒年糕包括鱼饼和高汤（非素食标准）- 需要请求“请移除鱼饼和高汤”。
  • 无麸质：炒年糕调味料、拉博基、饺子、油炸食品 = 大量麸质。
