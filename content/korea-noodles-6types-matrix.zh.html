🎯 为什么选择韩国面条矩阵？

韩国面条对于外国人的痛点=“我只知道拉面”。韩国面条= 全球认可的#1拉面+韩国中餐（炸酱面，炸酱面）+韩国传统食品（冷面，刀削面，炸鸡面） 3类全套。即使是同样的“面”，拉面、炸酱面、辣海鲜、冷面、刀切、宴会小面都是完全不同的食物。外国人 (a) 只知道国际拉面，没有韩式拉面经验 (b) 炸酱面 ≠ 不知道中国炸酱面 (c) 冷面 = 平壤风味与咸兴风味的区别 (d) 加减辣度。本指南由6种矩阵+区域特征+外国人优先事项组成。

🍜 6种面条深度探究

🍜 拉面 — 全球 #1

  • 签名产品：
  • Shin Ramyeon (Shin Ramyeon, Nongshim 1986) — 韩国 #1 全球拉面，辣
  • Chapagetti (Chapagetti, Nongshim) — Jjajang 拉面，电影《寄生虫》的效果
  • Buldak Bokkeum Ramen (Buldak, Samyang 2012) — 非常辣，全球挑战
  • 三养拉面 (三养1963) — 韩国 #1 老字号拉面
  • 外国人友好度：★★★★★（全球认可，许多是英语）
  • 如何吃：
  • 便利店·超市：即时（1,500~3,500韩元）
  • 餐厅：水煮（4,000~8,000韩元，额外菜单）
  • 零食店：拉博基 (KRW 5,000~8,000)
  • 额外配料：鸡蛋、奶酪、饺子、年糕

🥢 炸酱面 (Jajangmyeon) — 韩国中餐#1

  • 签名：仁川唐人街（韩国炸酱面的发源地，1905恭花春）/明洞/江南韩式中餐厅集群
  • 类型：
  • Gan-jjajang (Gan-jjajang)：分开的面条和jjajang（传统餐）
  • Samseon Jjajang（Samseon）：添加海鲜（虾、鱿鱼、章鱼）
  • Yuni Jjajang (Yuni)：添加肉末
  • Jjajang将军：最常见
  • 外国人友好度：★★★★★（很多英文菜单，韩文中文签名）
  • 差异：中国炸酱面与韩国炸酱面 = 不同的食物（韩国炸酱面更甜，颜色更黑）
  • 价格: 7,000~12,000韩元

🌶 Jjamppong — 辣味简介

  • 签名：韩国中餐厅集群·炸酱面和一对
  • 类型：
  • 普通Jjamppong：辣+海鲜+蔬菜
  • Samseon Jjamppong（Samseon）：海鲜丰富
  • Baek-jjamppong：不辣的白汤
  • Gochu-jjamppong：非常辣
  • 外国人友好度：★★★★（推荐刚接触辣味的人）
  • 推荐配对：Jjajangmyeon + Jjamppong = 韩国中国经典组合
  • 价格: 8,000~13,000韩元

🧊 冷面 (Naengmyeon) — 夏天 #1

  • 平壤风格与咸兴风格：
  • 平壤冷面（平壤）：荞麦面+清牛骨汤+萝卜，梨，鸡蛋。普通（推荐给外国人）
  • 咸兴冷面（咸兴）：红薯粉条 + 辣调味料 + 生鱼（比目鱼、鳐鱼）。耐嚼又辣。 拌饭冷面 = 一般咸兴风格表达
  • 推荐商店：
  • 平壤风格：Wooraeok（1946年在平壤创立，1953年在首尔重新开业）、Pildong Myeonok和Eulmildae
  • 咸兴风格：Ojang-dong 的 Heungnam House (1953)
  • 釜山Milmyeon：釜山Milmyeon集群（Hamheung Naengmyeon变体）
  • 外国人友好度：★★★★（特别是夏季狂热★★★★★）
  • 价格: 12,000~18,000韩元

🔪 刀削面 — 韩国传统

  • 签名：明洞饺子（1966） — 老牌韩国#1刀削面+Mandu餐厅
  • 类型：
  • Bajirak Kalguksu（Bajirak）：凤尾鱼+蛤蜊汤（Coast Mania）
  • 鸡肉刀削面 (Dak-kalguksu)：鸡汤（秋季/冬季）
  • 蘑菇刀削面 (Beoseot)：素食选项
  • 外国人友好度：★★★★（在正宗的韩国餐厅体验）
  • 价格: 8,000~13,000韩元

🎉 Janchi-guksu — 韩国传统盛宴

  • 招牌：韩国传统婚礼/宴会食品/市场小吃
  • 材料：薄素面 + 凤尾鱼汤 + 蛋壳 + 海藻，葱，胡萝卜
  • 外国人友好度：★★★（性价比+轻便）
  • 价格：6,000~10,000韩元

⚠ 外国人常犯的5个错误

1. “仅拉面 = 韩国面条”：拉面 = 方便面。韩国面条=全套炸酱面、炸酱面、冷面、刀削面、炸汁面。

2. “韩国炸酱面=中国炸酱面”：韩国炸酱面=起源于韩国（1905年仁川）·更甜·黑色调味料。中国炸酱面≠韩国炸酱面。

3. “冷面=都一样”：平壤风味=清淡/咸兴风味=辣。第一次尝试=推荐平壤风格（Eulmildae、Wooraeok）。

4. “鸡肉拉面=中辣”：全球挑战食品。非常辣，如果外国人尝试的话，用牛奶和奶酪调制。

5. “刀削面 = 日本乌冬面”：韩国刀削面 = 凤尾鱼、蛤蜊汤、咸味鱼。日本乌冬面=鲣鱼、高汤、甜。不同的食物。

⚙ 8 个常见问题解答

1. 没有。外国人1：炸酱面（仁川唐人街）+ 2种辛拉面（便利店/餐厅）。

2. 夏季第一名：平壤冷面（乙未台、友来）或咸兴冷面（兴南地、五藏洞）。

3. 辣介绍：微辣辛拉面→标准辛拉面→Jjamppong→Buldak。

4. Insta·vlog：辣鸡面挑战+平壤冷面剪刀（剪刀剪的礼仪）。

5. 过敏：麸质（小麦）、海鲜（jjamppong、kalguksu）、大豆（chunjang）、鸡蛋请提前告知。

6. 素食·清真·犹太：蘑菇刀切=素食OK/炸酱面·拉面·Jjamppong =非素食（调味料·海鲜）。

7. 付款/小费：刷卡即可/部分老店推荐现金/小费X。

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

面条=90~100°C的热汤（冷面除外）。小心烫伤。 鸡肉拉面=很辣，为外国人准备牛奶和奶酪。孕妇=小心辛辣的拉面和Jjamppong。儿童=推荐不辣的炸酱面、炸酱面、刀削面。过敏（麸质、海鲜、大豆、鸡蛋、荞麦（冷面原料））需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

历史悠久的商店信息免责声明：商店营业时间、菜单和付款政策可能会发生变化——建议访问前查看NAVER/Kakao地图或官方网站。

饮食限制后备：

  • Halal/Kosher：6种类型中，获得认证的商店很少。 → 预先搜索梨泰院和江南的一些经过认证的商店。
  • 素食·纯素：蘑菇刀削面·蔬菜宴席面=提供素食（要求不含凤尾鱼汤）。拉面/炸酱面 = 基本的非素食食品。
  • 无麸质：所有 6 种小麦粉面条（不包括冷面、荞麦 + 淀粉）。几乎没有无麸质的选择。
