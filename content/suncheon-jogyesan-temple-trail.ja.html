順天 曹渓山 千年仏心の道、秋 — 仙巌寺から松広寺へ、二つの大寺を山でつなぐ順番

副題: 順天の庭園と市場を見たなら(#1049・#1368)、残るは山だ。曹渓山の両側にユネスコ山寺・仙巌寺と僧宝寺刹・松広寺が向き合い、間の古道が「千年仏心の道」。順天駅からバスで仙巌寺へ、峠の麦飯屋で昼食、松広寺からバスで戻る一日 — 徒歩4〜5時間、約9時間。紅葉は10月末〜11月初め。

ISSUE · #1371 · 2026-09-10

🎯 フレーム — 二つの寺の間を歩く

順天には大きな寺が二つあります。東の昇州邑 (Seungju-eup / 승주읍) にある仙巌寺 (Seonamsa / 선암사) は2018年にユネスコ世界遺産となった「山寺、韓国の山地僧院」(Sansa / 산사, 한국의 산지승원)七ヶ所の一つで、西の松光面 (Songgwang-myeon / 송광면) にある松広寺 (Songgwangsa / 송광사) は韓国仏教が「三宝寺刹」(Three Jewel Temples / 삼보사찰)と呼ぶ三寺のうち、僧の寺 — 僧宝 (Sangha Jewel / 승보) にあたります。二つの寺は同じ山、曹渓山 (Jogyesan / 조계산) の両側の麓にあります。順天市はこの二寺の間の山道を「南道三百里の道 第9コース」(Namdo Sambaengni-gil Course 9 / 남도삼백리길 9코스)・千年仏心の道 (Cheonnyeon Bulsim-gil / 천년불심길) として整備しました — 仙巌寺から野生茶体験館 (Wild Tea Experience Center / 야생차체험관)、生態体験場 (Ecology Experience Site / 생태체험장)、大クルモク峠 (Keun-Gulmokjae / 큰굴목재) を経て松広寺に至る道です。

この回はその道を秋に、一方向で歩く順番です。寺は両方とも訪れますが、店のリストはありません。昼食は峠の上の麦飯屋一軒、それがこのコースの全てです。

  • 総所要時間: 順天駅 (Suncheon Station / 순천역) 基準で約9時間(バス片道50分 + 仙巌寺40分 + 徒歩4〜5時間 + 昼食 + 松広寺40分 + バス片道1時間25分) — 徒歩区間の分数は全て推定
  • おすすめ時間帯: 平日、順天駅発の朝一番のバス — 麦飯屋が16時30分に閉まり、11月は17時台に日が沈みます。紅葉は南部山地基準で10月末〜11月初め(年によって変動)
  • 傾斜: あり — 仙巌寺から大クルモク峠までは上り、松広寺側は下りです。運動靴以上の靴、水1L、現金

なぜ千年仏心の道なのか — 山寺一つと僧宝寺刹一つ

韓国の山寺七ヶ所(通度寺・浮石寺・鳳停寺・法住寺・麻谷寺・仙巌寺・大興寺)が2018年6月にユネスコ世界遺産となりました。仙巌寺はその一つです。松広寺はそのリストにありません — その代わり、仏・法・僧の三宝寺刹のうち「僧宝」、つまり高僧を数多く輩出した寺という別の重みを持っています。ユネスコ山寺と僧宝寺刹が一つの山の両側にあり、その間を一日で歩いてつなぐコースは韓国でここだけです。

距離はよく「約12km」と紹介されますが、資料によって8.7kmから12kmまで幅があり、順天市の公式ページには距離の記載がありません。確かなのは所要時間です — 昼食を含めゆったり5時間。山頂の将軍峰 (Janggunbong / 장군봉) に登る登山コースとは別の道なので、登山アプリの「曹渓山縦走」の記録とは混同しないでください。

📖 物語1 — 僧侶たちが越えた峠: 大クルモク峠は二つの寺の僧侶が互いに行き来した峠です。峠の上の麦飯屋はその道筋に長く根を下ろしており、今は歩く人にとって唯一の中間売店であり昼食の場です。寺から寺へ向かう道の途中に食事処が一軒 — このコースの構造そのものが物語です。

🚶 順番 — 仙巌寺から松広寺へ

起点は順天駅(KTX・1号線ではなく — 地方鉄道駅)です。駅前のバス停から市内バス1番(1日12回、間隔約80分)が仙巌寺まで約50分。16番(1日3回)も走ります。運賃1,400ウォン — 交通カード (T-money / 티머니) — 降車後60分以内に乗り換えれば無料乗り換えです。始発時刻は当日の順天市バス情報で確認してください。

① 順天駅 → 仙巌寺(🚌 約50分・1番)

  • 昇州邑の山道を上り、終点で降ります。切符売り場はありますが入場料はありません(文化財観覧料の廃止以降、無料)。参道が長く — 森の道1kmほどを歩いて寺に着きます。

② 仙巌寺(滞在約40分)

  • 谷を渡る虹橋、昇仙橋 (Seungseongyo / 승선교)(宝物)が最初の見どころです。寺はユネスコ山寺らしく大きく手を加えられていません — 丹青の色褪せた建物、狭い境内。
  • 二つだけ探します。八相殿 (Palsangjeon / 팔상전) 横の通路にある仙巌梅 (Seonammae / 선암매)(天然記念物、樹齢約600年 — 花は春ですが木は秋もそこにあります)と、「韓国で最も美しいトイレ」と呼ばれる古い解憂所 (haeuso / 해우소)(今も使われています)。
  • 寺の上手で千年仏心の道の道標を探します。野生茶体験館方向です。

③ 仙巌寺 → 野生茶体験館 → 生態体験場 → 大クルモク峠(🚶 約2時間・推定)

  • コースの上りは全てここにあります。茶畑とヒノキ林を抜けて峠まで。水は寺で補給します — 峠までは売店がありません。
  • 📖 物語2 — 二つの寺は性格が違う: 仙巌寺は小さく古びて静かです。松広寺は大きく新しい建物が多く、車も多く入ります — 外国人のGoogleレビューにも「美しい周回散策路」と「朝鮮時代の寺というより人が暮らす区域のようだ」が並んで書かれています。峠を越えると寺の顔つきが変わります。その対比を見に歩くのです。

④ 大クルモク峠の麦飯屋 — 昼食(滞在約40分)

  • 峠の下の曹渓山の麦飯屋 (Jogyesan barley-rice house / 조계산 보리밥집)。麦飯に山菜と味噌汁、チヂミを添えます(麦飯9,000ウォン前後)。10時〜16時30分、月・火曜定休、現金・振込のみ — 変動の可能性があるので出発前に確認してください。このコース唯一の実名級スポットですが、店名は一般名詞のまま扱います。
  • ここまで来ればコースの半分を超えています。この店が休みの日(月・火)は弁当を用意してください。

⑤ 麦飯屋 → 松広寺(🚶 約1時間30分・推定)

  • 下りです。谷沿いに松広寺の境内へ入ります。切符売り場が見えたら到着 — 寺院の入場自体は無料化されたとされており、境内の聖宝博物館 (Seongbo Museum / 성보박물관) は別途有料(3,000ウォン)の場合があるので現地の表示を確認してください。

⑥ 松広寺 → 順天駅(滞在約40分 + 🚌 約1時間25分・111番)

  • 僧宝寺刹の規模を一巡します。時間と体力が残っていれば、切符売り場から清涼閣 (Cheongnyanggak / 청량각) を過ぎて左の道へ仏日庵 (Bulliram / 불일암) — 法頂(ポプチョン)僧 (Ven. Beopjeong / 법정 스님) が暮らした庵 — 急な「無所有の道 (Musoyu-gil / 무소유길)」約30分です。
  • 締めくくり: 松広寺のバス停から111番(1日17回、間隔約60分)で順天駅まで約1時間25分。63番(1日4回)もあります。最終便の時刻は公式時刻表になく当日確認 — これがこのコースで最も重要な数字です。松広寺側のバスが仙巌寺側(1番12回)より多いので、この方向で歩きます。

🙏 このコースのマナー — 寺と山

  • 法堂の中は撮影・靴・帽子禁止です。僧侶とすれ違ったら道を譲ります。
  • 山道は一列で。前の人を追い越すときは声をかけます。音楽はイヤホンで。
  • 麦飯屋は回転の速い山小屋です — 食べ終えたら席を空けます。現金を用意してください。
  • ゴミは持ち帰ります。山にも寺にもゴミ箱は少ないです。
  • 喫煙は山全体で禁止です。秋は山火事のシーズンです。

💡 戸惑いポイント

  • 距離を信じず、時間を信じる: 「12km」は資料によって違います(8.7〜12km)。昼食を含め5時間を見込みます。
  • 秋の山火事警戒期間と重なる: 全国基準で10月20日〜12月15日(2025年基準、毎年告示)。曹渓山道立公園の個別入山規制の有無は出発前に順天市・道立公園の告知で確認してください — 紅葉の見頃と規制が同じ時期です。
  • 最終便: 111番の最終便時刻は公式ページにありません。松広寺に16時前到着を目標にします。
  • 麦飯屋は月・火定休・現金のみ: カードは使えません。定休日は中間の売店が全くなくなります。
  • 松広寺はユネスコ山寺ではありません: 登録は仙巌寺のみです。二つの寺をひとまとめに「ユネスコ二ヶ所」と書く記事が多いので注意してください。
  • 完州松広寺とは別です: テンプルステイの予約サイトで「松広寺」を検索すると完州松広寺 (Wanju Songgwangsa / 완주 송광사) も一緒に出てきます。「順天松広寺」で選んでください。

FAQ 6

Q1. 逆方向(松広寺→仙巌寺)は?

  • 可能です。ただし仙巌寺側のバス(1番)が1日12回しかなく、締めくくりが厳しくなります。上りを後に回したいなら逆も可能ですが、最終便はこちらの方向が有利です。

Q2. 体力が心配です。

  • 山頂に登らない峠道です。平地歩き4〜5時間ができれば大丈夫です。上りは③区間に集中しています。

Q3. 国家庭園と同じ日に回れますか?

  • 無理です。このコースだけで順天駅基準9時間です。庭園・湿地は別の日(#1049)、市場・邑城は#1368です。

Q4. 寺に泊まりたい場合は?

  • 仙巌寺・順天松広寺どちらもテンプルステイ (Templestay / 템플스테이) を運営しています(templestay.comで予約、#332)。仙巌寺に泊まって朝出発すると、このコースが最も楽になります。

Q5. 紅葉はいつですか?

  • 南部山地基準で10月末〜11月初め。年によって違うので山林庁 (Korea Forest Service / 산림청) の紅葉予測を確認します。同じ時期が山火事警戒期間なので規制の告知も一緒に確認してください。

Q6. タクシーで行くと?

  • 順天市の観光タクシーパッケージがあります(3時間80,000ウォン・5時間120,000ウォン、市の予約制)。片道のメーター料金は確認できませんでした。市内バスが正直な選択です。
