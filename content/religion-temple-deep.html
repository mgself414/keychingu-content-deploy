⚠ 외국인 자주 실수 5가지

1. "한국 = 종교 없음": 한국 종교 = 불교 (조계종 #1) + 천주교 (명동성당) + 기독교 (개신교) + 이슬람 (이태원) + 유교 + 외국인 매니아 1번지 풀세트 + #509·#369 통합.

2. "미사·예배 = 한국어만": 영어 OK = 명동성당 (천주교) + 온누리 사랑의 국제교회 (기독교) + 외국인 매니아 1번지 + #142·#138·#13 통합.

3. "사찰 = 외국인 어려움": 사찰 = 조계사·봉은사·불국사 영어 OK + 템플스테이 (#509) + 사찰음식 (#357) + 외국인 매니아 1번지 + #509·#357 통합.

4. "이슬람 = 한국 없음": 이슬람 = 용산 이태원 중앙 성원 (#144) + 외국인 무슬림 1번지 + 기도실 (인천공항·명동) + #521 비건 할랄 + #369·#398·#521 통합.

5. "유교 = 박물관만": 유교 = 성균관 + 향교 + 9개 서원 UNESCO + 외국인 정통 매니아 1번지 + #379·#377·#509 통합.
