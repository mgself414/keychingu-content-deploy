⚠ Health 실수 3가지

1. "의료관광=비싸다" — 글로벌 가성비 #1 미인지: 미국·일본 동일 가격 가정. 실제로는 한국 의료관광 미국·일본 1/2~1/3 + 영문 + 5성 호텔급 시설. 임플란트·라식·성형 가성비 글로벌 #1.

2. "성형=청담만" — 압구정 cluster 풀체험 미인지: 청담만 인식. 실제로는 압구정·청담·신사·강남 성형 cluster 50+ + 외국인 매니아 영문 응대. 1주+ 체류면 시술 + 회복 + 사후 관리 풀체험.

3. "한방=한국어만" — 영문 한방 cluster 미인지: 한국어 응대만 인식. 실제로는 이태원·강남·명동 영문 한방 클리닉 cluster + KMF 한방·동의보감 영문 인증.

동선 추천

[A] 의료관광 1주 풀패키지

  • D1: 인천 → 5성 호텔 + 의료관광 패키지
  • D2: 삼성서울병원 건강검진 (1일 종합)
  • D3: 압구정 성형외과 상담·시술 (1일)
  • D4: 회복 + 호텔 SPA
  • D5: 강남 치과 임플란트 또는 안과 라식
  • D6: 한방 침·뜸 + 휴식
  • D7: 출국

[B] 건강검진 매니아 2박

  • D1: 삼성서울 또는 아산 건강검진
  • D2: 결과 분석 + 한방 보강

[C] K-beauty 시술 매니아 3박

  • D1: 압구정 피부과
  • D2: 시술 회복
  • D3: 헤어·메이크업
