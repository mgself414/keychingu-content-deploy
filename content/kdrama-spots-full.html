⚠ 외국인 자주 실수 3가지

1. "드라마 무대 = 다 같은 area": 각 드라마 area 명확:

  • 청춘 로맨스 = 연세대·고려대·홍대·이태원
  • 직장인 = 노량진·종로·여의도
  • 판타지·고급 = DDP·롯데타워·청담동

2. "촬영지 = 가도 못 알아봄": 키친구 가이드별 K-drama 무대 표기 + 인스타 핫스팟. #181 노량진 고시촌 = 미생·이태원클라쓰 단골 명확.

3. "K-drama 매니아 = 일본·중국만": K-drama 외국인 매니아 글로벌 풀세트 — 미국·유럽·중동·남미. Netflix 효과로 매년 증가.

⚙ FAQ 6개

1. K-drama 무대 1번지: 이태원·연세대·노량진·DDP·북촌.

2. K-drama 촬영지 영문 안내: 인천관광공사·서울관광 영문 가이드 OK.

3. 외국인 K-drama 투어: 클룩·트립닷컴 K-drama 투어 패키지.

4. Netflix K-drama 매니아: 사랑의 불시착·도깨비·이태원 클라쓰·스카이 캐슬·오징어 게임.

5. K-drama 카페·콜라보: HYBE·SM 외 일부 K-drama 콜라보 카페 시즌 한정.

6. K-drama + K-pop 매니아 동선: HYBE 인사이트 → 이태원 → 연세대 → 명동 → DDP.

🗺 1일 코스

A. K-drama 단골 무대 풀데이: 10:00 노량진 고시촌 (미생·이태원클라쓰) → 13:00 이태원 거리 → 16:00 연세대 백양로 → 19:00 DDP 야간 (호텔 델 루나)
