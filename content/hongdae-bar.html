⚠ 외국인이 자주 하는 실수 3가지

1. "홍대=클럽"만 본다 — 술집 옵션 무시

외국인 인식에 홍대는 클럽 위주(롤링홀·클럽 FF). 실제 홍대권 술집·바 18개+ 매장이 영어 review ★5.0 평점 받음. 클럽보다 조용히 마시고 싶을 때 술집·바가 정답.

2. 외국인=맥주만 시킨다 — 한국 전통주 미경험

막걸리·청주·소주가 한국 술 정수. 느린마을 양조장(막걸리 직영)·책바(한국 전통주 큐레이션)에서 외국인 입문 가능. 막걸리 ₩6,000~12,000 / 청주 ₩15,000~.

3. 혼술 = 어색하다고 회피

한국 MZ는 혼술 보편화. 혼술 전문 바 (내잔·혼술바 고도·블렌딩바) 1인 좌석·1인 메뉴 갖춤. 외국인 단독 여행자 입문 best.

홍대권 술집·바 풍경

홍대·연남·합정·망원은 클럽 외 술집 문화도 풍부 — 라이브 음악(롤링홀)·DJ 클럽(클럽 FF)과 별개 트랙. 2020년대 후반부터 3-wave 술집(craft beer·전통주·시그니처 cocktail)이 합정·연남에 밀집.

외국인 관광객 4가지 의도:

1. 루프탑·뷰 — 야경 + 1잔 (L7 호텔·더뷰)

2. 한국 전통주 입문 — 막걸리·청주·소주 (느린마을·책바)

3. 친숙한 펍·맥주 — 수제맥주·피자 (에일크루·블렌딩바)

4. 혼술 친화 — 1인 좌석·1인 메뉴 (내잔·혼술바 고도)

4축 매핑

  • ① 루프탑·뷰 (2): L7 루프탑바 + 더뷰 — 호텔·야경 1잔
  • ② 전통주·시그니처 (2): 느린마을 양조장 + 책바 — 막걸리·청주·위스키 콘셉트
  • ③ 외국인 펍·맥주 (2): 에일크루 피자펍 + 블렌딩바 — 수제맥주·칵테일 친화
  • ④ 혼술·트렌디 (2): 내잔 망원 + 혼술바 고도 연남 — 1인 좌석·MZ 혼술

① 루프탑·뷰 (2곳)

L7 홍대 루프탑바 플로팅 (Floating at L7 Hongdae)

홍대 L7 호텔(롯데 호텔 그룹) 옥상 루프탑바. 도심 야경 + 칵테일·와인. 4성급 호텔 시설로 외국인 친화도 high — 영어 서비스·메뉴 완비. 가격대 ₩15,000~25,000(드링크).

  • 주소: 마포구 양화로 141, L7 홍대 호텔 옥상 (홍대)
  • 영업: 매일 18:00–01:00 (시즌별 변동)
  • 시그니처: 호텔 루프탑 + 도심 야경
  • 왜: 외국인 첫 홍대 술집 코스. 영어 안내 + 4성 호텔 시설.

더뷰 (The View)

홍대 일대 한강·서울 view 술집. 통창 인테리어 + 야경 sat (앉을 자리). 와인·칵테일·식사 메뉴. 평점 ★5.0 외국인 review 다수.

  • 주소: 마포구 일대 (홍대)
  • 영업: 매일 17:00–01:00 (매장별)
  • 시그니처: 한강·도심 view + 통창 인테리어
  • 왜: 루프탑 외 view 술집 best. 데이트·소그룹 모임.

② 전통주·시그니처 (2곳)

느린마을 양조장 홍대점 (Slow Village Makgeolli Brewery)

한국 막걸리 양조장 직영 술집. 양조장에서 매일 신선한 막걸리·청주·과일 막걸리 공급. 외국인이 한국 전통주 입문하기 가장 안전한 매장. 영어 메뉴 + 시즌별 한정.

  • 주소: 마포구 어울마당로 일대 (홍대)
  • 영업: 매일 17:00–01:00 (시즌 변동)
  • 메뉴: 막걸리 1병 ₩6,000~12,000 / 청주 ₩15,000~
  • 시그니처: 양조장 직영 + 시즌 한정 막걸리
  • 왜: 한국 전통주 입문 1순위. 외국인 가족·연인 부담 없는 가격.

책바 (Chaek Bar / Book Bar)

책+술 시그니처 콘셉트 바 — 매장 벽에 책 가득, 위스키·와인·전통주 큐레이션. 영국 잉글리시 펍 + 한국 책방 hybrid. 외국인 인스타 + 책 매니아 코스. 음악 작은 소리.

  • 주소: 마포구 와우산로 일대 (홍대)
  • 영업: 매일 19:00–02:00 (월 휴무)
  • 메뉴: 위스키 ₩10,000~20,000 (1잔) / 와인 ₩9,000~ / 전통주
  • 시그니처: 책+위스키·와인 콘셉트 + 큐레이션
  • 왜: 조용한 분위기 + 한국 + 외국 술 동시 입문. 인스타 사진 best.

③ 외국인 펍·맥주 (2곳)

에일크루 피자펍 홍대점 (Ale Crew Pizza Pub)

홍대 일대 수제맥주(craft beer) + NY 스타일 피자 펍. 영어 메뉴·외국인 직원 다수. 평점 ★5.0 with 5+ EN reviews. 그룹 모임·외국인 친화 매장.

  • 주소: 마포구 와우산로 일대 (홍대)
  • 영업: 매일 17:00–02:00
  • 메뉴: craft beer 1잔 ₩7,000~10,000 / 피자 ₩18,000~25,000
  • 시그니처: 수제맥주 + NY 피자
  • 왜: 외국인 그룹 모임 best. 영어 친화도 최고.

블렌딩바 서울혼술바 연남점 (Blending Bar Yeonnam)

연남동 일대 혼술 친화 칵테일 바. ★5.0 외국인 review. 1인 좌석·1인 메뉴 풍부 + 시그니처 칵테일 큐레이션. 외국인 솔로 트래블러 코스.

  • 주소: 마포구 연남동 일대 (연남)
  • 영업: 매일 18:00–02:00 (월 휴무)
  • 메뉴: 칵테일 ₩12,000~18,000
  • 시그니처: 혼술 친화 + 시그니처 칵테일
  • 왜: 연남 코스 + 혼술 입문 + 외국인 친화.

④ 혼술·트렌디 (2곳)

내잔 서울혼술바 망원점 (Naejan Solo-Drink Bar Mangwon)

망원 일대 혼술 전문 바 — 매장 컨셉이 1인 좌석 + 1인 메뉴 중심. 외국인 솔로 트래블러 최적 코스. 직원 영어 가능, 분위기 조용.

  • 주소: 마포구 망원동 일대 (망원)
  • 영업: 매일 18:00–01:00 (시즌 변동)
  • 메뉴: 위스키·소주 cocktail ₩8,000~15,000
  • 시그니처: 1인 좌석·혼술 전문
  • 왜: 망원시장 후 마무리 코스. 솔로 트래블러 best.

혼술바 고도 연남점 (Honsulbar Godo Yeonnam)

연남동 일대 MZ 혼술·소형 바. ★4.6 평점, 작은 매장이지만 큐레이션 음악·소소한 메뉴. 외국인 솔로·MZ 코스.

  • 주소: 마포구 연남동 일대 (연남)
  • 영업: 매일 19:00–02:00
  • 메뉴: 칵테일 ₩10,000~15,000 / 위스키 1잔 ₩9,000~
  • 시그니처: MZ 혼술 + 음악 큐레이션
  • 왜: 블렌딩바와 다른 톤의 혼술 코스. 작은 매장 분위기.

⚙ FAQ 8개

Q1. 외국인 첫 홍대 술집 코스?

저녁 19:00 L7 루프탑바 (1시간 야경 칵테일) → 느린마을 양조장 (1시간 막걸리 입문) → 에일크루 피자펍 (저녁 + 맥주, 1.5시간).

Q2. 한국 전통주 입문 best?

느린마을 양조장이 1순위 (양조장 직영, 막걸리 본질) → 책바가 큐레이션 다양성. 막걸리 입문 후 청주·소주로 확장.

Q3. 영어 메뉴·서비스는?

L7 루프탑바 / 에일크루 / 블렌딩바 / 책바 — 영어 친화도 high. 느린마을·내잔·혼술바 고도는 영어 일부 (메뉴는 영문 있지만 직원 영어 한정).

Q4. 혼술 외국인 입문 어디?

내잔 망원 (1인 좌석 전문) → 블렌딩바 연남 (혼술 + 칵테일) → 혼술바 고도 (MZ 분위기). 솔로 트래블러 안전.

Q5. 가격대는?

호텔 루프탑 ₩15,000~25,000 / 일반 술집 칵테일 ₩10,000~18,000 / 막걸리 ₩6,000~12,000(병) / 수제맥주 ₩7,000~10,000(잔). 외국인 1인 평균 ₩30,000~50,000.

Q6. 비 오는 날·실내 추천?

책바 (실내 책+술 분위기) → 느린마을 양조장 (양조장 직영) → 에일크루 피자펍 (그룹 친화). 루프탑은 비 오면 X.

Q7. 안전·연령·신분증?

한국 음주 연령 만 19세 이상. 외국인은 여권 ID 무조건 필요. 신분증 안 갖고 가면 입장 거절 가능.

Q8. 휠체어·접근?

L7 루프탑바·에일크루 — 호텔·일반 매장 평탄 동선. 느린마을·책바·내잔·혼술바 고도는 좁은 골목·계단으로 접근 어려움.

🌸 시즌·시간대 훅 5개

1. 여름 (6~8월) 루프탑 야경: L7 루프탑바·더뷰가 절정 시즌. 야간 야경 + 칵테일.

2. 가을 (9~11월) 막걸리 시즌: 느린마을 양조장 가을 한정 막걸리 + 책바 wine.

3. 겨울 (12~2월) 따뜻한 펍: 에일크루 피자펍·내잔 (실내 따뜻한 칵테일).

4. 금·토 야간 피크 (22:00~02:00): L7·블렌딩바·혼술바 피크 시간. 평일 또는 19~21시 한산.

5. MZ 트렌디 (월간): 책바·혼술바 고도가 인스타 명소 시즌별 변화.
