⚠️ 外国人常犯的3个错误

错误1 — 把BIFF季节和BIFF广场混为一谈

BIFF广场（南浦洞街区）全年免费开放。即使不在电影节期间（每年10月初约10天）,也能看到手印纪念碑和露天展览。很多外国人误以为只能在10月前往,结果在其他季节错过。

错误2 — 不知道龙头山公园有扶梯,徒步爬楼梯

龙头山公园入口（光复洞一侧）设有免费扶梯。不少游客不知道这一点,选择沿陡峭的台阶往上爬。扶梯入口位于光复路一侧的地下入口（乐天百货光复店方向）。

错误3 — 周一造访国际市场

国际市场部分店铺周一休息,或中午过后才开门。国际市场美食街的餐馆大多在周二至周日营业。周一前往时,糖饼小吃街仍开放,但商店街整体缩减营业。

轴1：国际市场（3选）— 1948正统

1. 国际市场本馆街

位置：釜山中区新仓洞4街 / 地铁1号线札嘎其站7号出口步行7分钟,或南浦站5号出口步行5分钟。

免费/收费：入场免费。仅购物·用餐产生费用。

外国人适配度：这是韩战结束后1948年避难民形成的市场,本身就是釜山的历史。服装·生活用品·饰品·旅游纪念品混杂在一起,每条巷子氛围各异。设有英文指示牌,大多数店铺可刷卡结算。

交通及动线：南浦站5号出口 → 光复路 → 国际市场入口（步行5分钟）。或札嘎其站7号出口 → 步行7分钟。市场内部按棋盘式巷道划分,不易迷路。

最佳时段：上午10点至下午6点最热闹。晚上7点后约80%的店铺关门。美食街则营业至傍晚。

BIFF季节联动：10月BIFF期间,国际市场一带会增设电影相关快闪摊位和露天放映。部分商户会看准电影节商机延长营业至深夜。

实用提示：国际市场素有"跳蚤市场"(Dotteugi Sijang / 도떼기시장)之称,意为杂乱喧闹的市场。没有标价的地方可以砍价。用英语说"How much?"完全行得通。

2. 国际市场美食街（糖饼·鱼糕）

位置：国际市场内部5号门方向巷道 / 鱼糕街位于光复洞入口处。

免费/收费：糖饼1个约1,500韩元,鱼糕串1~2串1,000~2,000韩元。

外国人适配度：釜山两大代表性街头小吃都集中在这里。糖饼（内馅塞满葵花籽·花生等坚果）和首尔的糖饼口味不同,釜山鱼糕(Eomuk / 오뎅)走的是正宗路线,许多路边摊连汤都免费提供。排队的店就是好吃的标志。

交通：从国际市场正门（新仓洞4街入口）直走50米,就能看到糖饼摊位。

最佳时段：上午11点至晚上9点。午饭刚过（下午1~3点）排队最长。

麸质·过敏提示：鱼糕含有面粉,麸质敏感者需注意。糖饼需确认坚果过敏情况。

3. 国际市场1948街（历史探访区）

位置：国际市场中心部历史指示牌区域。市场内导览图上标注为"1948街"。

免费/收费：免费。指示牌·壁画探访。

外国人适配度：与韩战（1950~1953）避难民历史相连的故事层。设有英·日·中文指示牌,可自助探访。对历史感兴趣的外国人（尤其是对韩国近现代史感兴趣的日本·美国游客）特别合适。

最佳时段：白天时段前往更方便阅读指示牌。

轴2：BIFF·电影（3选）

4. BIFF广场（釜山国际电影节广场）

位置：釜山中区南浦洞5街 / 地铁1号线南浦站6号出口步行2分钟。

免费/收费：露天广场免费。电影节期间的放映项目收费（需另购票）。

外国人适配度：亚洲最大电影节之一的釜山国际电影节（BIFF）自1996年起在此地举办。广场地面铺有100多位韩国·亚洲·世界影人的手印纪念碑。即使不在电影节期间,这些纪念碑也可全年参观。喜欢电影的外国人可以在此寻找自己喜爱的导演·演员的手印,别有乐趣。

交通：从南浦站6号出口出来即可看到BIFF广场招牌,步行不到2分钟。

最佳时段：全年均可露天参观。夜间也有照明,可以探访手印。10月BIFF期间人潮暴增,建议上午早些时候前往。

BIFF季节（10月）注意事项：每年10月初举办约10天。国内外电影放映300部以上,举行红毯活动·露天放映·知名导演/演员GV（观众见面会）。门票须提前在线预订（BIFF官网：biff.kr）。现场售票很快售罄。

实用提示：BIFF广场附近是南浦洞时尚街,电影节期间常能偶遇导演·演员。时尚街的咖啡厅·餐厅在BIFF期间会延长营业至凌晨12点。

5. BIFF街及南浦洞电影文化街

位置：BIFF广场周边南浦洞5街·6街一带。从广场延伸至札嘎其方向约300米区间。

免费/收费：免费探访。

外国人适配度：这条街上连绵着韩国电影海报壁画·电影相关造型物·独立影院招牌。对关注韩国电影（《寄生虫》《老男孩》《釜山行》等）的外国人尤其有意义。南浦洞附近有2~3家小型独立影院,偶尔提供英文字幕放映场次。

最佳时段：白天适合街区探访,夜晚灯光氛围更佳。

6. 釜山影像委员会及电影取景地探访

位置：釜山海云台区（影像委员会总部）,但取景地分散在南浦洞·中区一带。

外国人适配度：釜山是《釜山行》《犯罪都市》等韩国电影的主要取景地。影像委员会官网（bfc.or.kr）免费提供取景地地图,还有英文版,影迷可据此自行规划取景地徒步之旅。取景地主要集中在南浦洞·影岛·札嘎其附近。

实用提示：无需另请导游即可进行取景地之旅。建议提前下载英文取景地地图PDF,徒步探访。

轴3：龙头山·釜山塔（3选）

7. 龙头山公园

位置：釜山中区光复洞2街 / 地铁1号线南浦站7号出口步行5分钟,或搭乘扶梯。

免费/收费：公园免费,24小时开放。

外国人适配度：海拔49米,是俯瞰釜山原都心（南浦洞·光复洞·札嘎其·龙头山）的最佳地点。天气晴朗时可将影岛与釜山港尽收眼底。公园内有花钟（1983年设立）·李舜臣将军铜像·八角亭。适合家庭和情侣。

交通：南浦站7号出口 → 光复路 → 扶梯入口（地下）。乘扶梯约3分钟即可到达山顶。步行走楼梯也只需10分钟。

最佳时段：夜景（晚上7点以后）最美。春季（3~4月）是赏花季节,较为拥挤;10月BIFF期间,与广场联动前来的游客较多。清晨6~8点只有散步的本地人,较为安静。

扶梯位置：乐天百货光复店方向有通往地下的入口。地面沿指示牌走即可。

8. 釜山塔

位置：龙头山公园山顶 / 从龙头山公园扶梯出口步行1分钟。

免费/收费：收费。成人12,000韩元,青少年9,000韩元,儿童6,000韩元（截至2025年）。可刷卡。

营业时间：10:00~22:00（全年无休）。

外国人适配度：120米高的360度旋转瞭望台。可从四面八方俯瞰釜山原都心·釜山港·影岛。天气晴朗时,有时甚至能看到对马岛（日本）。部分观景台地板铺设强化玻璃,可俯瞰脚下。英·日·中文导览齐全。

最佳时段推荐：日落前后（下午6~8点）前往,可同时欣赏白天景色和夜景。晚上10点前才入场会导致游览时间过短,建议至少提前1小时入场。

BIFF季节注意事项：10月BIFF期间,塔身照明有时会更换为电影节主题。

9. 龙头山公园花钟及Ins打卡点

位置：龙头山公园山顶广场 / 釜山塔旁。

免费/收费：免费。

外国人适配度：1983年设立的大型花钟,可以釜山原都心为背景拍照。这是一座实际运转的时钟,花卉设计随季节更换。作为Ins拍照打卡点,尤其受日本·中国游客欢迎。

最佳时段：白天拍照花卉与背景清晰鲜明,夜晚则在灯光映衬下呈现另一番氛围。

轴4：周边cross（3选）

10. 札嘎其市场（#590 cross）

位置：从龙头山公园·BIFF广场步行10~15分钟 / 札嘎其站10号出口。

联动要点：#590详细介绍的釜山头号水产市场。参观完国际市场·BIFF广场后,午餐或晚餐时段移步札嘎其是最高效的动线。以札嘎其站为基准,国际市场（7号出口步行7分钟）·BIFF广场（南浦站6号出口步行5分钟）均为地铁1站距离。

实用提示：札嘎其市场早上5点开门,札嘎其2楼餐厅从早上8点开始营业。午饭前先去札嘎其 → 下午国际市场·BIFF → 傍晚龙头山夜景,是最佳顺序。

11. 影岛大桥及影岛开桥活动

位置：从南浦洞步行10分钟 / 影岛大桥上。

免费/收费：免费。

外国人适配度：影岛大桥是韩战时期避难民相会的场所,具有历史意义。如今每天下午2点举行开桥活动。桥身开启约15分钟,可以看到船只通过的场景。对本地人来说司空见惯,但对外国人来说是新奇的一幕。

最佳时段：开桥时间为下午2:00整。提前10~15分钟到达可以占到好位置。夜间影岛大桥的灯光也值得一看。

12. 白岭文化村（影岛）

位置：釜山影岛区影仙洞 / 从南浦洞乘66路市内公交约20分钟,或打车10分钟。

免费/收费：村庄探访免费。

外国人适配度：这是在影岛悬崖上形成的避难民村落,狭窄的巷子和海景独具特色。也是电影《与犯罪的战争》的取景地。村内有小型画廊·咖啡厅·工坊,并设有英文指示牌。虽不如甘川文化村知名,但更安静,本地生活气息也更浓。

最佳时段：上午10点至下午5点前往较合适。部分咖啡厅·工坊下午6点前打烊。

实用信息（交通·KTX·语言）

前往釜山的方法

KTX：从首尔站或水西站到釜山站约需2小时15~40分钟。自2026年9月1日起,水西发SRT也已并入KTX,App统一为Korail+。票价一般座54,400韩元（合并后下调）起。在线订票：letskorail.com（支持英文）。外国人可凭护照购票。三段车票参见#1374。

从釜山站到南浦洞：地铁1号线釜山站 → 南浦站4站约10分钟。单程票/交通卡1,500韩元。T-money·Cashbee交通卡可在便利店购买。

从金海机场到南浦洞：轻轨金海机场站 → 沙上站换乘 → 1号线南浦站。约40分钟,2,400韩元。

南浦洞内部交通

南浦洞集群的4个景点（国际市场·BIFF广场·龙头山公园·札嘎其）均在步行15分钟范围内。若搭乘地铁,可以札嘎其站（10号·7号出口）和南浦站（5号·6号·7号出口）为据点。

札嘎其站各出口指南：

  • 7号出口 → 国际市场（步行7分钟）
  • 10号出口 → 札嘎其市场（步行3分钟）

南浦站各出口指南：

  • 5号出口 → 国际市场（步行5分钟）
  • 6号出口 → BIFF广场（步行2分钟）
  • 7号出口 → 龙头山公园扶梯（步行5分钟）

语言指南

国际市场·BIFF广场·釜山塔均设有英·日·中文指示牌。釜山塔内部提供3种语言的自动语音导览。国际市场部分商户懂英语·日语。若沟通困难,可使用翻译App（Naver Papago·谷歌翻译）。

旅游翻译热线：1330（韩国观光公社,24小时,支持英·日·中·俄语）。

交通卡与支付

  • T-money卡：可在釜山站·地铁站·便利店购买,卡费3,000韩元。充值后可用于地铁·公交。
  • 国际市场店铺：大多可刷卡。路边摊（糖饼·鱼糕）更倾向现金,部分支持二维码支付。
  • 釜山塔：刷卡·现金均可。

常见问题5

Q1. 不在BIFF期间,BIFF广场也值得去吗?

值得。BIFF广场全年免费露天开放。100多座手印纪念碑即使不在10月也能观赏。反而在非旺季游客较少,可以从容探访。

Q2. 龙头山公园的入园方式——扶梯要收费吗?

免费。从南浦站7号出口沿光复路走5分钟,就能看到"龙头山公园扶梯"入口指示牌。下到地下乘扶梯即可直达公园山顶。

Q3. 釜山塔 vs. 海云台Centum瞭望台——哪个更好?

若想俯瞰南浦洞·札嘎其·BIFF广场一带,选釜山塔。若想看海云台·广安里,选海云台Centum瞭望台或黄岭山。按动线来说,若一天内游览南浦洞集群,首选釜山塔。

Q4. 在国际市场一定要吃什么?

糖饼（坚果糖饼,1,500韩元）和鱼糕串（1,000~2,000韩元）。两者合计3,000韩元,即可完成釜山代表性街头小吃体验。

Q5. 10月BIFF季节首次到访釜山,有什么注意事项?

BIFF期间（通常10月初10天）,南浦洞·BIFF广场·札嘎其一带住宿费比平时上涨2~3倍,人潮暴增。住宿务必提前2~3个月预订。BIFF电影票通常在开幕前2~3周于biff.kr开放预订,热门场次几分钟内售罄。

全天路线3

路线1. 南浦洞全套（1日）

抵达札嘎其站 → 札嘎其市场（#10,上午8~10点） → 国际市场美食街糖饼·鱼糕（#2,上午10~11点） → 国际市场本馆探访（#1,上午11~12点） → 午餐国际市场韩食 → BIFF广场手印探访（#4,下午1~2点） → 影岛大桥开桥活动（#11,下午2点整） → 龙头山公园散步·花钟（#7·#9,下午3~5点） → 釜山塔日落+夜景（#8,下午6~8点）

预估花费:糖饼1,500韩元 + 鱼糕2,000韩元 + 午餐10,000~15,000韩元 + 釜山塔12,000韩元 + 购物自选。

路线2. BIFF十月狂热路线

BIFF广场（#4,上午早些时候） → BIFF街探访（#5） → 红毯观赏点等候（下午） → 露天放映夜场。间隙可逛国际市场购物。若釜山塔换上BIFF照明主题,可夜间前往。

BIFF门票须提前购买（biff.kr）。现场购票名额极少。

路线3. 釜山1晚集群

第1天上午:札嘎其 → 国际市场 → BIFF广场 → 龙头山夜景。第2天上午:影岛白岭文化村（#12） → 影岛大桥开桥活动（#11） → 下午海云台·广安里（#243 cross）或甘川文化村（#245 cross）。

外国人实用5大提示

1. 札嘎其站7号出口或南浦站5·6·7号出口 ——南浦洞集群的两大据点。

2. 龙头山公园扶梯 ——免费,无需爬楼梯,沿地下入口指示牌走即可。

3. 釜山塔门票12,000韩元 ——想同时看日落和夜景,建议下午6点入场。

4. BIFF广场全年免费 ——即使不在10月,也能探访手印纪念碑。

5. 影岛大桥开桥下午2点整 ——免费,建议提前10分钟到达。
