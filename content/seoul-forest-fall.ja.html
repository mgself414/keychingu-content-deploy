ソウル北東部 森・公園ガイド — ソウル子供大公園、峨嵯山・峨嵯山城・高句麗亭、ソウルドゥルレギル5コース、龍馬滝公園・龍馬山スカイウォーク

サブタイトル: ソウル子供大公園(公園05:00~22:00) · 峨嵯山(295.7m、常時開放) · 峨嵯山城(常時開放) · 峨嵯山 高句麗亭(常時開放) · ソウルドゥルレギル5コース 峨嵯山コース(4.6km、約2時間10分) · 龍馬滝公園(常時開放) · 龍馬山スカイウォーク(約160m、常時開放) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウル北東部の広津区・中浪区にある公園と山をまとめたものです。広津区のソウル子供大公園、三国時代の遺跡がある峨嵯山と歩く道、中浪区の龍馬山にある人工滝の公園と展望デッキです。七か所すべて年中無休で登録されています。ソウルの森・聖水は#701 ソウルの森・聖水ガイドにあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 広津 — ソウル子供大公園

ソウル子供大公園、広津区 Neungdong-ro 216 (능동로 216)、☎ 02-450-9311 は、1973年5月5日のこどもの日に開園した536,094.50㎡の公園です。動物園、遊戯施設、教養施設があります。2009年5月5日の再開園で、シロクマとアザラシが見られる海洋動物館、ちびっこ動物村 (Kkoma Dongmul Maeul / 꼬마동물마을)、オウム村 (Aengmu Maeul / 앵무마을)、音楽噴水を新しく開きました。公園の真ん中には8,000席の野外公演場ヌンドン 森の中の舞台 (Neungdong Supsogui Mudae / 능동 숲속의 무대)があり、八角堂 (Palgakdang / 팔각당)に子ども向けの室内遊び場があります。

  • 開く時間: 公園05:00~22:00。動物園10:00~17:00。遊園地は平日10:00~18:30、週末10:00~19:30。
  • 休み: 年中無休。駐車: 可能。

📍 峨嵯山 — 峨嵯山・峨嵯山城・高句麗亭・ソウルドゥルレギル5コース

峨嵯山、広津区 Gingorang-ro 213 (긴고랑로 213)、☎ 峨嵯山管理事務所 (Achasan Gwalli Samuso / 아차산관리사무소) 02-450-1655 は、ソウルと九里市 (Guri-si / 구리시)にまたがる海抜295.7mの山です。登山道で約40分登ると、頂上から蚕室、南山、北漢山、道峰山までソウルが一望できます。山の険しさはありません。三国時代に百済が高句麗を防ぐ軍事拠点にして、百済・新羅・高句麗が漢江をめぐって争った場所として知られています。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

峨嵯山城、広津区 Gwangjang-dong (광장동)、☎ 広津区庁 文化芸術課 (Gwangjin-gucheong Munhwa Yesul-gwa / 광진구청 문화예술과) 02-450-7593 は、百済が高句麗の侵入を防ぐために築いた城です。高句麗の長寿王が百済の蓋鹵王をここへ連れてきて殺したといい、高句麗の温達将軍が新羅軍の矢に当たって戦死した場所だともいわれます。発掘で高句麗の城壁・建物跡・池跡、2015年からは新羅の排水施設や高句麗の土器などが出ました。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 不可。
  • 峨嵯山城の登録情報には峨嵯山の高さが海抜285mと書かれていて、峨嵯山の項目の295.7mと登録値が食い違っています。

峨嵯山 高句麗亭、広津区 Guui-dong (구의동)、☎ 広津区庁 公園緑地課 (Gwangjin-gucheong Gongwon Nokji-gwa / 광진구청 공원녹지과) 02-450-7776 は、1984年に建てたコンクリートの八角亭が傾いて2008年1月に撤去された後、歴史学者の考証を経て2009年7月に建て直した東屋です。名前を八角亭 (Palgakjeong / 팔각정)から高句麗亭に変えました。漢江とソウルが見下ろせます。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

ソウルドゥルレギル5コース 峨嵯山コース、中浪区 Myeonmok-dong (면목동)、☎ 02-779-7902~4 は、総延長156.5km、21コースでソウルを一周するソウルドゥルレギルのうち、「人と歴史をつなぐ道」をテーマにしたコースです。峨嵯山生態公園 (Achasan Saengtae Gongwon / 아차산 생태공원)が見どころとして紹介されていて、地下鉄サガジョン駅 (Sagajeong-yeok / 사가정역)、クァンナル駅 (Gwangnaru-yeok / 광나루역)に近いです。

  • 長さ・時間: 総延長4.6km、約2時間10分。開く時間: 常時開放。

📍 龍馬山 — 龍馬滝公園・龍馬山スカイウォーク

龍馬滝公園、中浪区 Yongmasan-ro 250-12 (용마산로 250-12)、☎ 管理事務所 (Gwalli Samuso / 관리사무소) 02-2094-2965 は、骨材採取場だった龍馬山の岩壁を生かして1993年5月に開園した公園です。人工の滝が三つあります。中央の龍馬滝は2段で高さ51.4m、左の青龍滝 (Cheongnyong Pokpo / 청룡폭포)が21m、右の白馬滝 (Baengma Pokpo / 백마폭포)が21.4mです。サッカー場、クライミング競技場、バスケットコート、ジョック (Jokgu / 족구)場、子どもの遊び場があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

龍馬山スカイウォーク、中浪区 Myeonmok-dong San 1-3 (면목동 산1-3)、☎ 02-2094-2382 は、2025年11月にソウルドゥルレギル2.0事業で龍馬山の頂上付近に造った、長さ約160m、最大高さ10mの木製デッキの散策路です。南山ソウルタワーから烽火山 (Bonghwasan / 봉화산)、道峰山、北漢山まで見え、日没と夜景も楽しめます。ソウルドゥルレギル4コース (Mangu·Yongmasan / 망우·용마산)に属し、サガジョン公園 (Sagajeong Gongwon / 사가정공원)から始まるバリアフリーの散策路 龍馬山ドンヘンギル (Yongmasan Donghaenggil / 용마산 동행길)とつながっています。傾斜を緩やかにしたので、車いすやベビーカーでも展望台まで上がれます。観光公社の紹介によると、2026年2月の1か月だけで約23万人が訪れました。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 不可。

⚠ 事前に知っておきたい3つのこと

  1. ソウル子供大公園の動物園は10:00~17:00に開きます — 公園は05:00~22:00、遊園地は平日18:30、週末19:30までです。
  2. 峨嵯山城と龍馬山スカイウォークは駐車できません — 峨嵯山・高句麗亭・龍馬滝公園は駐車できます。
  3. ソウルドゥルレギル5コースは約2時間10分かかります — 総延長4.6kmで、サガジョン駅・クァンナル駅に近いです。

⚙ FAQ 2

Q. 車いすで行ける展望台はありますか?

A. 韓国観光公社の登録情報では、龍馬山スカイウォークは傾斜を緩やかにしたデッキなので、車いすやベビーカーで展望台まで上がれます。常時開放です。

Q. 峨嵯山の頂上までどのくらいかかりますか?

A. 登山道で約40分です。海抜295.7m(峨嵯山城の項目には285mと登録)で、山の険しさはないと紹介されています。
