韓国BBQテーブルワークフロー - 席から支払いまで7ステップ

サブ: 外国人観光客向け職員焼き vs セルフ違い+サム・おかず・追加注文+決済のヒント

ISSUE 03・#805・2026-06-07

🎯 なぜ韓国BBQテーブルワークフローガイドなのか

外国人韓国BBQペインポイント#2 = "メニューさせましたが、次は？"。 #804部位・等級 知っても+ テーブル進行フローは別途学習必要。韓国BBQは（a）職員が焼く店舗（b）セルフ焼く店舗（c）半自動（職員がはさみのみ）で3タイプ。外国人は、（1）燃焼タイミングを逃して燃やしたり、（2）追加注文方法を知らず、従業員に電話をかけたり、（3）サム・おかず・厚食システムを知らなかったり（4）決済段階でサービス料・税混乱。このガイドは7-stepワークフロー+店舗タイプ別の違い+外国人にやさしいヒント。

★一目で7ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣席をつかむ 入場＋人員案内＋テーブル割当 1～5分4人以上=左式OR椅子選択可能。換気の良い席をリクエストOK
2️⃣メニューを選択 メニューパネル+部位・人前・セット決定5〜10分
3️⃣焼く スタッフの書き込み/セルフ/半自動 部位別スタッフの書き込み=グリルマニア/セルフ=自由度↑/半自動=はさみのみ
4️⃣サム+おかず サム菜、ニンニク、唐辛子、おかず5〜10種無制限すべてのおかず=無料詰め替え。 「おかずもう少しください」 = "Banchan more, please"
5️⃣追加注文 部位追加＋お酒・飲み物＋厚食 5〜10分 従業員ベルOR「ここよ！」 (excuse me) 呼び出し。追加メニュー=別途請求
6️⃣フシック（食事） 冷麺・味噌チゲ・炒め炒め・お菓子10〜15分 韓国式＝会食仕上げ＝食事コース。 1人5,000〜10,000ウォン
7️⃣決済 カードまたは現金+領収書

総所要時間（2人基準）：1～1.5h（苛性費売場）～2～3h（高級・会食）

🔥 店舗タイプ別燃焼システム比較

Type A — 従業員の書き込み（最もフレンドリー）

  • 特徴: 従業員が最初から最後まで焼く・切る。外国人1位推薦。
  • おすすめ店(ソウル):江南・清潭・ロッテワールド・新羅ホテル和食・韓国料理店
  • メリット: 燃焼失敗X / 英語案内可能 / 部位別燃焼時間自動
  • デメリット: 高価な店舗多/人当たり3,000～5,000ウォンまたはテーブルあたり5,000～10,000ウォングリルマニアコスト別途あります
  • 外国人親和性: ★★★★★

Type B — セルフベーキング (コスト比)

  • 特徴: 本人が直接焼く。はさみも直接。
  • おすすめ店舗(ソウル):弘大・新村・江南苛性比BBQ /路地老舗
  • メリット：価格↓（1人あたり25,000〜50,000ウォン）/自由度↑/ローカル雰囲気
  • 短所: 焼き付け失敗 risk (特に鶏・豚) / はさみ熟練も必要
  • 外国人親和性: ★★★ (英語メニューのないところ多)

Type C — 半自動（ハサミのみスタッフ）

  • 特徴: 本人が焼き、従業員がはさみで切る。中型。
  • おすすめ店舗: ウィジョンブ・ギルドン精肉食堂 / 一般BBQ専門店
  • 利点: はさみの安全+燃焼の自由度/コスパ比★
  • デメリット: 燃焼は本人の責任
  • 外国人親和性: ★★★★

外国人入門=Type AまたはC優先(Bは韓国BBQ慣れた後)

🍃サム+おかずシステム（バンチャンシステム）

組み込み無料(フリーリフィル)

  • サム野菜 (Ssam vegetables): レタス（Lettuce）・カメ葉（Perilla）・チコリ・青慶菜
  • ニンニク・ピーマン・サムジャン (Garlic・Pepper・Ssamjang dipping sauce)
  • キムチ3種: 白菜キムチ(Cabbage)・カクドゥギ(Radish)・熱霧(Young radish)
  • おかず5～7種：ほうれん草・もやし・雑菜・豆腐煮など

どうやって食べるの？ — サム作り

1.サム野菜1枚手のひらに伸ばす

2. よく焼き肉1～2個を上げる

3. ニンニク1～2個＋サムジャン1/2ティースプーン

4.キムチ・唐辛子少し＋ご飯（選択）

5. 一口に入れる（韓国式標準＝一口丸め）

外国人頻繁に間違い: サムを口に入れないで半分ずつ斬り食べる。 韓国式推奨=一口丸め（半分のベアを食べることはぎこちないように見えることがあり、違反ではない）。小さく作って一口に入れることをおすすめ。

追加注文システム

  • "おかずをもっとください" (Banchan more, please) — 無料 無制限
  • "肉を追加" (Meat more, please) — 別途請求
  • "空ギバブハナヨ" (Rice one, please) — 1,000～2,000ウォン
  • "これを新しくしてください" (This one is burnt, can I get a new one?) — セルフストアの書き込みが失敗した場合
  • "別々に計算できますか?" (Can I pay separately?) — 分離決済 (店舗別ポリシー異なる)
  • 「換気をもっと強くしてください」（Stronger ventilation、please） - 店舗にリクエストOK

外国人注意：焼酎1本アルコール=ワイン1杯〜1.5杯。 1人2本以上の危険。

⚠外国人の頻繁なミス7つ

1. "メニュー版1人前= 1人十分": 通常1人前= 100〜150g。 1人1.5～2人分が標準量。

2. "おかず= 1回提供": 無制限の無料詰め替え。 「おかずもう少しください」呼び出し。

3. "サム=カット食べる": 韓国式推奨= 一口丸。半分ずつ食べるのはぎこちないように見えるかもしれません（違反ではありません）。安く小さくすることをお勧めします。

4. "従業員 = 自動呼び出し": 韓国レストランは本人が呼び出し。ベルOR「ここです！」 (excuse me) 発火。

5. "肉=メインで終わり": 韓国会食=肉→フシク(冷麺・チゲ・チャーハン)コース。フード別注文。

6. "カード決済=テーブル":店舗によって異なります。 カウンター決済多（韓国式）。いくつかのテーブルカード。

7. 「焼き付け失敗時＝ただ食べる」: セルフ店で焼きすぎると従業員に「これを新しくお願いします」要請可能（サービス店舗多）。

⚙ よくある質問8件

1. 最初のBBQ =どの店舗?: Type A (従業員のベーキング) 1位。江南・清潭・新羅ホテル和食BBQおすすめ。

2. 1人BBQ可能?: 一部店舗(本飯・1人BBQ専門店)可能。一般は最低2人推奨。

3. 焼く安全時間: 豚のウェルドン(3～5分両面) / ウシ medium (2～3分) / チキンウェルドン(5～7分鉄板)

4. ランチvsディナー: ランチ特選(lunch course) = 30～50%割引。一次会食は夕方

5. 外国人英語店舗おすすめ：江南・梨泰院・弘大・清潭＝英語メニュー多。地方・路地＝韓国語基本

6. 小麦の強制拒否: 「I don't drink soju」か手のひらの上のカップ持ち上がる=拒否の信号。韓国人の大部分尊重

7. アレルギー: 事前通知必須。韓国料理の味付け＝ニンニク・醤油・蜂蜜・コチュジャン＋グルテン（醤油に小麦）

8. お支払いの分離: 一行と個別のお支払い = 「ダッチペイ可能？」一部店舗OK / 一部店舗X. 韓国式パターン=一人が決済後後に送金

⚠医療・安全・食事ダイエット

BBQダイレクト調理= 画像の危険（グリル250〜350℃）。子供同伴時の家族の座席事前リクエスト+グリルから離れて。 豚・鶏 well-done必須 (食中毒・サルモネラ・E.coli)。妊婦・免疫低下＝もっと身につけて。アレルギーの予告。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

食事制限fallback: 一般BBQ店舗=ハラール・コーシャ・ベジタリアンメニューX. 梨泰院・江南一部ハラールBBQ店舗(Eid・Makan・Halal BBQ Koreaなど) 事前検索をおすすめ。ベジタリアン・ビーガン= #799ベジタリアン 別途ガイド参照 OR 他店舗分離。

💰 Essential Tourist Tips

  • 所要時間（2名あたり）：
  • コスパ比BBQ = 1〜1.5h
  • 一般 = 1.5~2h
  • 会食・高級＝2～3h
  • 1人の平均予算（2026年6月現在、相場変動可能）：
  • コスパ = 30,000〜50,000ウォン+焼酎1本
  • 一般 = 50,000～80,000ウォン + 酒2本
  • 高級＝100,000～200,000ウォン＋ワイン
  • ランチ特選：平日11:30～14:00、30～50%割引
  • お支払いパターン：
  • カウンター決済 = 80% (韓国式)
  • テーブル決済＝20％（英語店舗多）
  • サービス料：ホテル日食・高級BBQ一部10％/一般店舗X
  • VATの払い戻し：飲食の一般還付対象ではない
