37_景福宫3小时全程攻略

一句话简介

Gyeongbokgung in 3 hours: the essential Joseon palace route, nothing missed.

3小时内游遍景福宫 (Gyeongbokgung / 경복궁) 所有核心看点，动线合理，体力不浪费。

推荐对象

  • 行程紧凑的旅行者、首尔只有一天的旅行者
  • 第一次造访景福宫 (Gyeongbokgung / 경복궁) 的所有游客

主要景点/活动

名称 位置 所需时间 特色
光化门 (Gwanghwamun / 광화문) 景福宫正门 10分钟 三重结构正门，王都的起点
兴礼门 (Heungnyemun / 흥례문) 光化门后方 5分钟 第二道门，穿越永济桥 (Yeongjegyo / 영제교) 石桥
勤政殿 (Geunjeongjeon / 근정전) 景福宫中心 20分钟 国王即位与外交场所，拍照圣地No.1
思政殿 (Sajeongjeon / 사정전) 勤政殿后方 10分钟 国王日常办公处
庆会楼 (Gyeonghoeru / 경회루) 西侧池塘 20分钟 池塘上两层楼阁，拍照圣地No.2
香远亭 (Hyangwonjeong / 향원정) 北侧 15分钟 小岛上的亭台，国王休憩之所
国立民俗博物馆 (Gungnim Minsok Bangmulgwan / 국립민속박물관) 景福宫东侧 30分钟 免费入场，韩国传统生活方式展示
集玉斋 (Jibokjae / 집옥재) 景福宫东北侧 10分钟 高宗书斋，中式建筑风格

推荐路线 (3小时)

1. 09:30 景福宫站 (Gyeongbokgung Station / 경복궁역) 5号出口 → 光化门 (Gwanghwamun / 광화문) 前拍照 (10分钟)

2. 09:40 入场：用 T-money 或银行卡支付 ₩3,000 (~约15元人民币 / ~350日元)；穿韩服 (Hanbok / 한복) 免费入场

3. 09:45 兴礼门 (Heungnyemun / 흥례문) → 永济桥 (Yeongjegyo / 영제교) (5分钟)：站在石桥上远眺勤政殿 (Geunjeongjeon / 근정전)

4. 09:50 勤政殿 (Geunjeongjeon / 근정전) (20分钟)：细看王座、凤凰纹饰与月台 (Woldae / 월대)，正面侧面多角度拍照

5. 10:10 思政殿 (Sajeongjeon / 사정전) (10分钟)：国王办公空间，观看室内陈列品

6. 10:20 庆会楼 (Gyeonghoeru / 경회루) (20分钟)：环池散步，桥上拍照，欣赏四季花卉

7. 10:40 香远亭 (Hyangwonjeong / 향원정) (15分钟)：穿越醉香桥 (Chwihyanggyo / 취향교) (已修缮完成)，以亭台为背景拍照

8. 11:00 国立民俗博物馆 (Gungnim Minsok Bangmulgwan / 국립민속박물관) (30分钟)：韩国人日常生活史展示，免费参观

9. 11:30 集玉斋 (Jibokjae / 집옥재) (10分钟)：中式砖砌建筑，相对清静的拍照好地点

10. 11:40 出场 + 前往三清洞 (Samcheong-dong / 삼청동)：可走北门神武门 (Sinmumun / 신무문) 或东门建春门 (Geonchunmun / 건춘문) 方向

外国游客贴士

  • 实用韩语表达
  • "입장권 주세요" (一张门票，谢谢 / One ticket, please)
  • "영어 오디오 가이드 있어요?" (有英语语音导览吗？/ Is there an English audio guide?)
  • "화장실 어디예요?" (洗手间在哪里？/ Where is the restroom?)
  • 文化注意事项：遵守建筑内部禁止进入区域的标识，请勿触摸展出的文物。
  • 付款方式：门票现金或刷卡均可。穿韩服 (Hanbok / 한복) 免费入场。
  • 免费英语导览：每日 11:00 (AM) 出发 (英语解说约1小时)，集合地点在光化门 (Gwanghwamun / 광화문) 内侧。

英语简介 (Simple English Summary)

Gyeongbokgung is the main palace of the Joseon Dynasty (built 1395), located in central Seoul. Admission is ₩3,000 (~约15元人民币) — free if wearing hanbok. The must-see highlights are Geunjeongjeon (throne hall, best photo), Gyeonghoeru (pavilion over a pond), and the National Folk Museum (free, inside the palace grounds). A free English-language guided tour departs daily at 11:00 (AM) from just inside the main gate. The palace is closed on Tuesdays. Plan about 3 hours for a thorough visit.

预计总费用

  • 节省型：₩3,000 (仅门票，步行参观，~约15元人民币)
  • 标准型：₩15,000 (门票 + 韩服 (Hanbok / 한복) 租借 + 语音导览，~约75元人民币)
  • 豪华型：₩50,000 (高级韩服租借 + 庆会楼 (Gyeonghoeru / 경회루) 特别参观 + 三清洞 (Samcheong-dong / 삼청동) 早午餐，~约250元人民币)
