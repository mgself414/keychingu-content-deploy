한국 국밥 주문·먹는 워크플로우 — 자리에서 마지막 한 숟갈까지

> 부제: 외국인 관광객용 6-step 워크플로우 + 양념 가감·반찬 세팅·추가 주문·결제 팁

ISSUE 03 · #808 · 2026-06-07

🎯 왜 국밥 워크플로우 가이드인가

[#807 국밥 6종 매트릭스](807_외국인_한국_국밥_6종_매트릭스_가이드.md) 알아도 — 주문·먹는 과정은 별개 학습. 한국 국밥은 (a) 노포 = 한국어 메뉴만 (b) 설렁탕·곰탕 = 간 안 되어 나옴 (소금·후추 본인이 추가) (c) 콩나물국밥 = 수란 풀기·새우젓 가감 (d) 돼지국밥 = 부추·다대기 옵션 등 각자 다른 워크플로우. 외국인은 (1) 주문 시 한국어 메뉴 (2) 양념 추가 타이밍 (3) 반찬 세팅 무료·무제한 시스템 (4) 결제 카드 vs 현금 노포 차이에서 혼란. 본 가이드는 6-step 워크플로우 + 종류별 양념 가감 + 외국인 영어 발화 샘플.

★ 한눈에 6-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 자리 잡기 입장 + 인원 안내 + 식탁 배정 1~3분 노포 = 합석 가능, 다른 손님과 한 테이블 OK
2️⃣ 메뉴 주문 메뉴판 보고 종류 선택 1~2분 한국어 메뉴 多 → 사진·번역 앱 활용
3️⃣ 국밥 + 반찬 세팅 김치·깍두기·다대기·간장·새우젓 등 즉시 모두 무료 무제한 리필
4️⃣ 간 조절 (양념 가감) 소금·후추·다대기·새우젓 본인 조정 30초~1분 전통 노포 = 간 약하게 나옴, 본인 추가 일반적
5️⃣ 먹기 밥을 국물에 말기 OR 따로 먹기 15~25분 따로국밥 (대구) = 밥과 국 분리 / 일반 = 말아 먹기
6️⃣ 결제 카운터 OR 테이블 + 영수증 1~3분 노포 多 = 카운터 결제·현금 권장 / 신생 = 카드 OK

> 총 소요 시간 (1인 기준): 15~25분 (혼자) / 30~45분 (2인+ 수육 코스)

🍲 국밥 종류별 간 조절 매트릭스

🐮 설렁탕·곰탕 — 전통 노포 多 간 약하게 나옴

1. 그릇 받자마자 소금 1티스푼 (또는 1/2티스푼, 취향)

2. 후추 약간 (2~3회 흔들기)

3. 다진 양념 (대파+양념장) 추가 (선택)

4. 송송 썬 파 1티스푼

5. 김치·깍두기와 함께

> 외국인 핵심: 처음 한 숟갈 떠보고 무미하다면 = 간 안 했음 = 본인이 추가. 절대 "맛이 없다"고 식당 불만하지 말기 (정통 노포 매너).

🐷 돼지국밥 — 부추 + 다대기

1. 그릇 받자마자 부추 듬뿍 1접시 분량 (밀양식은 부추 별도)

2. 다대기 (매운 양념) 1티스푼 (취향)

3. 새우젓 1/2티스푼 (부산식 필수)

4. 마늘 다진 것 (선택)

5. 깍두기와 함께

> 밀양식 vs 부산식: 밀양 = 맑은 국물 + 새우젓 / 부산 = 진한 국물 + 부추 + 다대기

🌱 콩나물국밥 — 수란 풀기 + 새우젓

1. 수란 (poached egg) 국물에 깨뜨려 풀기

2. 새우젓 1티스푼

3. 고춧가루 가감 (전주 옛집 = 적게 / 삼백집 = 많이)

4. 김 가루 토핑

5. 밥은 따로 먹거나 말아 먹기 (취향)

🌶 육개장 — 매운맛 가감

1. 기본 매운맛 (중-매운맛) — 매운맛 더 원하면 고춧가루 추가

2. 다진 마늘·파 추가 (취향)

3. 밥 말아 먹기

4. 김치·깍두기와 함께

🩸 순대국밥 — 들깨가루 + 다대기

1. 들깨가루 (perilla powder) 듬뿍 (구수함 +)

2. 다대기 가감 (평안식 = 적게 / 전라식 = 많이)

3. 새우젓 1/2티스푼

4. 김치와 함께

🥣 반찬·세팅 시스템 (Banchan System)

기본 제공 무료 (Free Refill)

  • 김치 3종: 배추김치·깍두기·총각무
  • 양념 매트릭스: 소금·후추·다진 양념·새우젓·고춧가루
  • 추가 토핑: 들깨가루·김가루·파·마늘·부추

추가 주문 (별도 청구)

  • 수육 (Boiled meat): 15,000~25,000원 — 설렁탕·곰탕 매장 시그니처
  • 밥 추가 (Extra rice): 1,000~2,000원
  • 공기밥 (Bowl of rice): 1,000원~
  • 계란: 1,000~2,000원
  • 국물 추가 (Extra broth): 일부 매장 무료 / 일부 1,000원

외국인 영어 발화 샘플

  • "소금 어디 있어요?" = "Where's the salt?"
  • "이거 매워요?" = "Is this spicy?"
  • "수육 추가요" = "Extra boiled meat, please"
  • "국물 더 주세요" = "More broth, please"
  • "포장 가능해요?" = "Can I take it to go?"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "설렁탕 = 처음부터 간 있음": 전통 노포 = 간 약하게 나옴. 소금·후추 본인이 추가하는 것이 일반적. 무미하다면 양념 추가.

2. "노포 = 영어 메뉴": 100년 노포 = 한국어 메뉴만 多. 사진·번역 앱·손가락 가리키기 활용.

3. "밥 = 항상 말아 먹기": 대구 따로국밥 = 밥과 국 분리. 본인 취향에 따라.

4. "반찬 = 1회": 무료 무제한 리필. "김치 좀 더 주세요" (Kimchi more, please).

5. "카운터 결제 = 한 사람": 일행 분리 결제 = "따로 계산할 수 있어요?" (Pay separately?). 노포 多 = 1명만 가능.

6. "수란 = 그냥 먹기": 콩나물국밥 수란 = 국물에 깨뜨려 풀기. 빵 같이 먹지 않음.

7. "맛없다 = 식당 탓": 간 안 된 국물 = 본인이 추가. 노포 매너 = "직접 간 조절" 문화.

⚙ FAQ 8개

1. 첫 국밥 = 어떤 매장: 시내 관광지 가까운 노포 (이문설농탕·하동관). 영문 메뉴 매장은 사전 검색 권장.

2. 합석 매너: 노포·시장 매장 = 다른 손님과 한 테이블 OK. 인사 + 묵묵히 먹기.

3. 새벽·24h 매장: 일부 노포 새벽 영업 (이문설농탕 06:00~) — 해장 매니아 1순위.

4. 1인 가능?: 모든 매장 1인 walk-in OK. 국밥은 한국 #1 1인 식사.

5. 알레르기·임신: [#807 disclaimer](807_외국인_한국_국밥_6종_매트릭스_가이드.md) 참조. 임신부 = 새우젓 염분 주의.

6. 결제·팁: 카드 OK / 노포 일부 현금 권장 / 팁 X.

7. 포장 가능?: 대부분 OK. "포장이요" 또는 "to-go please".

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

노포 정보 면책: 매장 영업시간·메뉴·결제 정책은 변동 가능 — 방문 전 NAVER/Kakao map 또는 공식 사이트 확인 권장.

국밥 = 90~100°C 뜨거운 국물. 화상 주의 (어린이 그릇 멀리·식힌 후). 임신부 = 새우젓·다대기 염분 과다 주의. 어린이 = 매운맛 (육개장·돼지국밥) 가감 또는 흰 국물 (설렁탕·곰탕) 권장. 알레르기 (소·돼지·콩·달걀·새우젓 + 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 중 인증 매장 거의 없음. → 이태원·강남 일부 인증 매장 사전 검색.
  • 채식·비건: 모든 국밥에 동물 재료. → [#799 채식·비건](799_외국인_한국_채식_비건_매트릭스_12선_deep_dive.md) OR [#800 사찰음식](800_외국인_한국_사찰_음식_정통_풀세트_12선_deep_dive.md) 별도 매장.
  • 글루텐 free: 다대기·양념장에 간장(밀) 多 — "양념 빼고" 요청 또는 흰 국물만.

💰 Essential Tourist Tips

  • 1인 평균 비용 (2026년 6월 기준):
  • 시장·골목 = 8,000~12,000원
  • 노포 = 13,000~18,000원
  • 소요 시간: 15~25분 (혼자) / 30~45분 (2인+ 수육)
  • 결제: 카드 OK / 노포 일부 현금 / 팁 X
  • VAT 환급 X: 식음료 일반
  • 응급: ☎ 1339 (의료, 영문) / ☎ 1330 (관광 통역)

🌏 지역별 현지인 패턴 차이

지역 현지인 1순위 패턴 외국인 관광 포인트
서울 점심 = 설렁탕·곰탕 / 회식 후 해장 = 콩나물국밥 명동·종로 노포 (이문설농탕·하동관)
부산 아침·점심·저녁 = 돼지국밥 (1일 1식 매니아 多) 자갈치·서면 노포 cluster, 24h 매장 多
전주 콩나물국밥 = 아침 해장 1번지 풍남문 옛집·삼백집, 비빔밥과 페어링
대구 따로국밥 = 점심 매니아 동인동 cluster, 따로국밥 → 시그니처
광주·전라 순대국밥 + 콩나물국밥 듀얼 전라식 (구수·진함)
