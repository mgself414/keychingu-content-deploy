韩国年糕指南 — 年糕博物馆 (Tteok Museum / 떡박물관)、乐园洞年糕街 (Nagwon-dong Tteok-jeon-geori / 낙원동 떡전거리)、江陵初堂糯米糕 (Gangneung Chodang Chaltteok / 강릉 초당찰떡)，11家年糕店与体验馆及节日年糕 (2026年10月官方数据)

副标题："制作年糕" (Tteok Mandeulgi / 떡 만들기) 自2021-11-01起被指定为国家非物质遗产(国家遗产厅)· 年糕博物馆 (Tteok Museum / 떡박물관) 周一至周六 10:00~18:00，成人 3,000韩元(VisitKorea)· 2027年春节 (Seollal / 설날) 2/6~2/8，中秋 (Chuseok / 추석) 9/14~9/16(韩国天文研究院)· 春节吃年糕汤，中秋吃松糕(国家遗产厅)— 截至2026-10-21

ISSUE 03 · #473 · 2026-05-27

🎯 如何使用这份指南

年糕槌 (Tteokme / 떡메) 每次砸向糯米饭，都会发出沉闷的声响，手上的黄豆粉落在裤子上。在襄阳松川年糕村 (Songcheon Tteok Maeul / 송천떡마을)，至今仍用柴火蒸米，用年糕槌捶打，再用手捏成型(VisitKorea)。本指南把年糕分成三类：年糕博物馆与年糕制作体验、节日年糕(春节年糕汤、中秋松糕、冬至、元宵)、年糕店(首尔乐园洞年糕街、江陵初堂)。地址、时间、价格只写在VisitKorea、国家遗产厅、韩国天文研究院读到的数值。适合想吃"年糕本身"而不只是炒年糕的人，以及节日期间正好在韩国的人。

旧版指南写的是"制作年糕 = 联合国教科文组织人类非物质文化遗产(2018)"。这是错的。制作年糕于2021年11月1日被指定为国家非物质遗产(国家遗产厅)，并不是联合国教科文组织的列入项目。旧版指南里名为"哈阳水 (Hayangsu / 하이양수)"的年糕、"丹阳年糕 (Danyang Tteok / 단양 떡)"以及老店排名，都找不到官方出处，已删除。

🏛 年糕博物馆与年糕制作体验

  • 年糕是什么：把谷物粉放进蒸笼蒸熟，或蒸后捶打，或水煮，或油煎，或捏好后再蒸的食物。周岁、婚礼、花甲、祭礼等人生礼仪和各个节令都会摆上年糕(国家遗产厅)
  • 国家非物质遗产"制作年糕" (Tteok Mandeulgi / 떡 만들기)：2021-11-01指定，分类为传统生活习俗·饮食生活(国家遗产厅)。没有持有者或持有团体，只指定了项目
  • 年糕博物馆 (Tteok Museum / 떡박물관)：首尔钟路区敦化门路 (Donhwamun-ro / 돈화문로) 71号。周一至周六 10:00~18:00(17:30停止入场)，周日、春节、中秋休馆。成人 3,000韩元，36个月~未满19岁 2,000韩元，未满36个月和65岁以上免费。咨询电话 02-741-5447。按节气、人生礼仪、制作方法分类展示年糕，并开设制作体验(VisitKorea)
  • 松松年糕工坊 (Songalsongal Tteokgongbang / 송알송알 떡공방)：京畿道金浦市高村邑水器路 (Sugi-ro / 수기로) 39-15 现代Hillstate商铺栋 B103号。面向外国人的一日课程(风糕、水果蒸糕蛋糕、花松糕)。周一·三·五 10:30~17:30，周二·四 09:00~17:30，周六 10:00~16:00，周日及法定节假日休息。咨询电话 0507-1315-3034(VisitKorea)。介绍中说离金浦机场很近
  • 襄阳松川年糕村 (Songcheon Tteok Maeul / 송천떡마을)：江原道襄阳郡西面年糕村路 (Tteok Maeul-gil / 떡마을길) 107号。制作糯米糕、印切米糕，体验捶打年糕。08:00~18:00(年糕售完即结束)，全年无休。咨询电话 033-673-8977(VisitKorea)
  • 咸阳水车年糕村 (Mullebanga Tteok Maeul / 물레방아떡마을)：庆南咸阳郡安义面新安路 (Sinan-gil / 신안길) 53号。制作传统印切米糕、年糕蛋糕。09:00~17:00，全年无休。咨询电话 055-963-6649(VisitKorea)
  • 除年糕博物馆外，官方页面上没有体验费用 — 预约时询问

🏮 节日年糕 — 春节·元宵·中秋·冬至

  • 春节 (Seollal / 설날) = 年糕汤：正月初一吃年糕汤，就被认为长了一岁(国家遗产厅)。2027年春节假期为2月6日~8日，替代假日为2月9日(韩国天文研究院)
  • 正月十五 (Jeongwol Daeboreum / 정월대보름) = 药饭：元宵节吃药饭 (Yakbap / 약식)(国家遗产厅)。2027年正月十五是2月21日(韩国天文研究院)
  • 中秋 (Chuseok / 추석) = 松糕：用新收的谷物捏成，供奉在祭桌和坟前的节日年糕。各地不同，如土豆松糕、萝卜松糕、苎麻叶松糕(国家遗产厅)。2027年中秋假期为9月14日~16日(韩国天文研究院)
  • 冬至 (Dongji / 동지) = 红豆粥，有时是红豆蒸糕：冬至落在农历十一月上旬(小冬至，Aedongji / 애동지)或中旬(中冬至，Jungdongji / 중동지)时，有不喝红豆粥而做红豆蒸糕吃的习俗(国立民俗博物馆)。2026年冬至是12月22日(韩国天文研究院)
  • 新春年糕汤面 (Saebom Tteokguk Guksu / 새봄떡국국수)：首尔中区世宗大路 (Saemunan-ro / 새문안로) 24号。13种年糕汤(海苔藻牡蛎年糕汤 (Maeseng-i Gul Tteokguk / 매생이 굴 떡국)、活鲍鱼年糕汤 (Hwaljeonbok Tteokguk / 활전복 떡국) 等)。平日 09:00~20:30(20:00停止点餐)，周末 09:00~19:30，全年无休。咨询电话 02-739-0661(VisitKorea)。价格未公布
  • 卖松糕的地方：江陵山野院松香故乡年糕店 (Sanyatteul Solhyang Gohyang Tteokjip / 산야뜰솔향고향떡집)(松糕、印切米糕、发酵蒸糕 (Gijeongddeok / 기정떡))、平昌青春咖啡年糕坊 (Cheongchun Cafe & Tteokbang / 청춘카페&떡방)(栗子松糕)、松松年糕工坊 (Songalsongal Tteokgongbang / 송알송알 떡공방)(花松糕课程)— 详见下方和上方各节(VisitKorea)

🏪 年糕店 — 乐园洞年糕街与江陵初堂

  • 乐园年糕店 (Nagwon Tteokjip / 낙원떡집)：首尔钟路乐园洞年糕街上的年糕店。学过宫廷年糕的第一代，1910年起在苑西洞 (Wonseo-dong / 원서동) 一带卖年糕，现在已是第四代(韩国民族文化大百科，韩国学中央研究院)。地址、营业时间、价格在官方页面上无法确认
  • 江陵初堂糯米糕 (Gangneung Chodang Chaltteok / 강릉 초당찰떡)：江陵市初堂豆腐路 (Chodangsundubu-gil / 초당순두부길) 77番街 20号。用清晨煮好的饭捶打做成的糯米糕(黑芝麻 (Heugimja / 흑임자)、印切米糕 (Injeolmi / 인절미))、烤糯米糕。09:00~18:00，全年无休，当天制作当天销售，可能很早售完。0507-1361-1205(VisitKorea)
  • 江原屋糯米糕 (Gangwonok Chapssal-tteok / 강원옥 찹쌀떡)：江陵市初堂豆腐路 89-8。加入初堂嫩豆腐的糯米糕。09:30~18:30，全年无休。0507-1449-0599(VisitKorea)
  • 江陵师任堂印切米糕 (Gangneung Saimdang Injeolmi / 강릉사임당인절미)：江陵市沧海路 (Changhae-ro / 창해로) 349-2。黄豆粉、咖啡、黑芝麻印切米糕。09:00~21:00，全年无休(VisitKorea)
  • 山野院松香故乡年糕店 (Sanyatteul Solhyang Gohyang Tteokjip / 산야뜰솔향고향떡집)：江陵市时英路 (Siyeong-gil / 시영길) 21-6。糯米糕、印切米糕、松糕、发酵蒸糕。07:00~19:00，全年无休，电话预约 033-647-0451(VisitKorea)
  • 青春咖啡年糕坊 (Cheongchun Cafe & Tteokbang / 청춘카페&떡방)：江原道平昌郡珍富面珍富市场后路 (Jinbusijang-dwitgil / 진부시장뒷길) 15号。由平昌老年人俱乐部的老人们经营的年糕咖啡馆，每天年糕种类不同。周一至周五 10:00~17:00(五日集市开市的周末营业)，0507-1413-7714(VisitKorea)
  • 这五家在VisitKorea页面上都没有价格栏

🥗 饮食

  • 价格区间：官方公布的韩元价格只有年糕博物馆门票(成人 3,000韩元)。年糕店和体验馆未公布价格
  • 素食：年糕以谷物粉为基础(国家遗产厅)，但年糕汤的汤底每家不同 — 新春年糕汤面 (Saebom Tteokguk Guksu / 새봄떡국국수) 的菜单上有牡蛎、鲍鱼年糕汤(VisitKorea)。点餐前先问清汤底材料
  • 过敏：印切米糕的外裹是黄豆(黄豆粉印切米糕，VisitKorea)，江原屋糯米糕 (Gangwonok Chapssal-tteok / 강원옥 찹쌀떡) 里加了嫩豆腐、鲜奶油、奶油奶酪(VisitKorea)。对大豆、牛奶过敏者请避开
  • 清真：VisitSeoul介绍梨泰院的Eid (Eid / 이드)是少数获韩国伊斯兰教中央会(KMF)认可的清真餐厅之一(龙山区 Usadan-ro 10-gil 15号，每天12:00–21:00)。认证可能变更，前往前请先确认。本指南中的年糕店没有清真标示
  • 出示用卡片见 #1300 饮食需求手册

⚠ 常见错误4则

1. "制作年糕是联合国教科文组织人类非物质遗产" — 它是国家非物质遗产(2021-11-01指定)(国家遗产厅)

2. "周日去年糕博物馆" — 周日及春节、中秋休馆(VisitKorea)

3. "冬至一定喝红豆粥" — 小冬至、中冬至也有做红豆蒸糕吃的习俗(国立民俗博物馆)

4. "节日当天巡礼年糕店" — 年糕博物馆春节、中秋休馆，年糕店的休息日每家不同。2027年春节假期(2/6~2/8)、中秋假期(9/14~9/16)要先打电话确认
