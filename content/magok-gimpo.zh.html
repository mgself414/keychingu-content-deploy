🎯 为何单独推出马谷·金浦机场指南

马谷 (Magok / 마곡)·金浦机场 (Gimpo Airport / 김포공항) 是江西区 (Gangseo-gu / 강서구) 的外国游客换乘·入境首选地·新城 — 金浦国际机场 (Gimpo International Airport, GMP / 김포국제공항) (1958年开港，国际航线 + 国内航线) + 马谷新城 (Magok New City / 마곡 신도시) (2014年建成，韩国高科技规划城市) + 首尔植物园 (Seoul Botanic Park / 서울식물원) (2019年开园，韩国最大植物园) 浓缩于此区域。外国游客首次入境韩国 + 深度探索马谷新城 = “首尔的西部门户”。

与弘大 (Hongdae / 홍대) (MZ世代 (Millennials and Gen Z / 20-35岁年轻人)·独立文化)、江南 (Gangnam / 강남) (奢华)、梨泰院 (Itaewon / 이태원) (国际化) 相比，马谷·金浦机场以换乘·新城·自然为特色。外国游客在行程中常以仁川机场 (Incheon Airport / 인천공항) 为主，从而错过马谷·金浦机场 — 实际上，金浦机场 (Gimpo Airport / 김포공항) → 日本·东南亚短途航线 + 马谷新城 (Magok New City / 마곡 신도시) + 首尔植物园 (Seoul Botanic Park / 서울식물원) + LG艺术中心 (LG Arts Center / LG 아트센터) 是外国游客入境·换乘的首选热门区域。

特别是首尔植物园 (Seoul Botanic Park / 서울식물원) (2019年开园)，是韩国最大的植物园 + 外国游客家庭·散步的首选。金浦机场 (Gimpo Airport / 김포공항) 免税店·乐天购物中心 (Lotte Mall / 롯데몰) 也是除仁川机场 (Incheon Airport / 인천공항) 外，换乘·退税的首选。马谷新城 (Magok New City / 마곡 신도시) 是2014年建成的韩国尖端新城 (LG·Kolon·E-Land等全球企业入驻) — 深度探索韩国未来都市。继 [#138 弘大](138_hongdae_guide.md)·[#142 江南](142_gangnam_guide.md)·[#170 大学路](170_daehangno_guide.md)·[#171 新村](171_sinchon_guide.md)·[#172 DDP东大门设计广场 (DDP Dongdaemun Design Plaza / DDP)](172_ddp_guide.md)·[#173 瑞草](173_seocho_guide.md)·[#174 首尔大](174_seoul_national_university_guide.md) 之后，ISSUE 03 第⑯篇 — KeyChinGu (키친구) 首次进入江西区 (Gangseo-gu / 강서구) (共31个集群)。

⚠ 外国游客常犯的3个错误

1. “机场 = 只有仁川机场 (Incheon Airport / 인천공항)” — 未认识到金浦机场 (Gimpo Airport / 김포공항) 的价值

外国游客常将韩国机场仅视为仁川机场 (Incheon Airport / 인천공항)，但金浦机场 (Gimpo Airport / 김포공항) 是韩国首个机场 (1958年开港) + 日本·东南亚短途航线枢纽 (东京羽田·大阪·福冈·台北·上海等) + 国内航线热门地。金浦机场 (Gimpo Airport / 김포공항) → 江南 (Gangnam / 강남) 30分钟 / 弘大 (Hongdae / 홍대) 25分钟 (地铁)。短途外国游客换乘 + 韩国国内出差首选。

2. “马谷 (Magok / 마곡) = 新城 (New City / 신도시) = 没什么可看” — 未认识到首尔植物园 (Seoul Botanic Park / 서울식물원)·LG艺术中心 (LG Arts Center / LG 아트센터)

马谷新城 (Magok New City / 마곡 신도시) (2014年建成) 是韩国首个新城 + 全球企业入驻 (LG科学园 (LG Science Park / LG 사이언스파크) 2018年·LG艺术中心 (LG Arts Center / LG 아트센터) 2022年·Kolon·E-Land等)。首尔植物园 (Seoul Botanic Park / 서울식물원) (2019年开园，韩国最大植物园，整合5个植物博物馆) + LG艺术中心 (LG Arts Center / LG 아트센터) (韩国首个演出场所，从江南 (Gangnam / 강남) 迁至马谷 (Magok / 마곡)) = 外国游客家庭·文化深度探索的首选。

3. “金浦机场 (Gimpo Airport / 김포공항) 免税店 = 比仁川机场 (Incheon Airport / 인천공항) 少”

金浦机场 (Gimpo Airport / 김포공항) 免税店·乐天购物中心 (Lotte Mall / 롯데몰) 虽然比仁川机场 (Incheon Airport / 인천공항) 小，但对外籍游客友好 + 免税 + 退税热门地。特别是乐天购物中心金浦机场店 (Lotte Mall Gimpo Airport / 롯데몰 김포공항점) 是外籍游客即时退税标准 + 韩式餐饮·咖啡馆全套服务。短途出境旅客换乘·免税首选 (仁川机场 (Incheon Airport / 인천공항) 以外的选择)。

马谷·金浦机场风光

马谷 (Magok / 마곡)·金浦机场 (Gimpo Airport / 김포공항) 位于江西区 (Gangseo-gu / 강서구) 东·西部，是外国游客换乘 + 新城 (New City / 신도시) 结合区域 — 1958年金浦机场 (Gimpo Airport / 김포공항) 开港后成为韩国首个机场 + 2014年马谷新城 (Magok New City / 마곡 신도시) 建成 + 2019年首尔植物园 (Seoul Botanic Park / 서울식물원) 开园 + 2022年LG艺术中心 (LG Arts Center / LG 아트센터) 迁入，使其成为深度探索韩国未来都市的热门区域。

金浦国际机场 (Gimpo International Airport, GMP / 김포국제공항) 子区域与5号线·9号线·机场铁路金浦机场站 (Gimpo Airport Station / 김포공항역) 直连 — 国际航站楼 (日本·东南亚) + 国内航站楼 (济州·釜山·光州等) + 乐天购物中心金浦机场店 (Lotte Mall Gimpo Airport / 롯데몰 김포공항점) + 免税店。

马谷新城 (Magok New City / 마곡 신도시) 子区域位于5号线·9号线·机场铁路马谷站 (Magok Station / 마곡역)·马谷渡口站 (Magoknaru Station / 마곡나루역)·钵山站 (Balsan Station / 발산역) 一带 — LG科学园 (LG Science Park / LG 사이언스파크) + LG艺术中心 (LG Arts Center / LG 아트센터) + Kolon·E-Land入驻。外国商务人士首选。

首尔植物园 (Seoul Botanic Park / 서울식물원) 子区域距离马谷渡口站 (Magoknaru Station / 마곡나루역) 步行5分钟 — 韩国最大植物园 (50万坪) + 5个植物博物馆 + 湖水庭园 + 外国游客家庭·散步首选。

LG艺术中心 (LG Arts Center / LG 아트센터) 子区域位于马谷 (Magok / 마곡) LG科学园 (LG Science Park / LG 사이언스파크) 附近 — 2022年从江南 (Gangnam / 강남) 迁至马谷 (Magok / 마곡) 的韩国首个演出场所。部分演出提供英文字幕。

交通: 5号线·9号线·机场铁路金浦机场站 (Gimpo Airport Station / 김포공항역) / 5号线·9号线马谷站 (Magok Station / 마곡역)·马谷渡口站 (Magoknaru Station / 마곡나루역)·钵山站 (Balsan Station / 발산역)。仁川机场 (Incheon Airport / 인천공항) → 金浦机场 (Gimpo Airport / 김포공항) 机场铁路18分钟 (韩国首个换乘线路)。

⚙ 常见问题 (8个)

Q1. 金浦机场 (Gimpo Airport / 김포공항) vs 仁川机场 (Incheon Airport / 인천공항) 的区别?

金浦机场 (Gimpo Airport / 김포공항): 市区交通便利 (江南 (Gangnam / 강남) 30分钟)，日本·东南亚短途国际航线 + 国内航线。仁川机场 (Incheon Airport / 인천공항): 韩国首个国际机场，美洲·欧洲·中东长途航线枢纽。对日本·东南亚外国游客来说，金浦机场 (Gimpo Airport / 김포공항) 更友好。

Q2. 首尔植物园 (Seoul Botanic Park / 서울식물원) 门票·时间?

植物园主馆 (5个植物博物馆) 5,000韩元 / 湖水庭园·散步道免费。09:30-18:00 (上午09:30至下午06:00) (周一休息)。提供英文导览。距离马谷渡口站 (Magoknaru Station / 마곡나루역) 步行5分钟。

Q3. LG艺术中心 (LG Arts Center / LG 아트센터) 演出外国游客可以观看吗?

可以 — 部分演出提供英文字幕 (音乐剧·话剧·芭蕾)。Interpark (인터파크) 英文UI + 外国游客座位预订可以。韩国首个演出场所，深度探索。

Q4. 金浦机场 (Gimpo Airport / 김포공항) 换乘·免税如何操作?

金浦机场 (Gimpo Airport / 김포공항) 国际航站楼 → 免税店·乐天购物中心金浦机场店 (Lotte Mall Gimpo Airport / 롯데몰 김포공항점) 直连。外国游客即时免税退税 标准 (30,000韩元以上 + 护照)。仁川机场 (Incheon Airport / 인천공항) 以外的换乘首选。

Q5. 马谷 (Magok / 마곡) 对外国游客友好的店铺有哪些?

孔明咖啡 (Cafe Gongmyeong / 카페 공명)·咖啡里盛放花朵 (Coffee with Flowers / 커피에꽃을담다)·Don Gumeong (돈구멍)·Cozy House (코지하우스) 提供英文菜单 + 银行卡支付 + 对外国游客友好。作为新城 (New City / 신도시)，外国商务基础设施丰富。

Q6. 马谷 (Magok / 마곡) + 金浦机场 (Gimpo Airport / 김포공항) 一日游可以吗?

可以 — 马谷新城 (Magok New City / 마곡 신도시) (首尔植物园 (Seoul Botanic Park / 서울식물원)·LG艺术中心 (LG Arts Center / LG 아트센터)·咖啡馆·餐饮) + 金浦机场 (Gimpo Airport / 김포공항) (免税·换乘) = 一日全天。5号线·9号线·机场铁路直连。

Q7. 马谷 (Magok / 마곡) → 江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대) 路线?

马谷站 (Magok Station / 마곡역) (5号线·9号线·机场铁路) → 江南 (Gangnam / 강남) (地铁35分钟) / 弘大 (Hongdae / 홍대) (机场铁路15分钟 + 9号线5分钟)。相邻区域。外国游客换乘可以。

Q8. 首尔植物园 (Seoul Botanic Park / 서울식물원) 最佳季节?

春季4月樱花 + 秋季10-11月枫叶首选。夏季6-8月湖水庭园 + 灯光秀 (季节限定)。冬季12-2月温室深度探索 (热带馆·地中海馆温暖宜人)。
