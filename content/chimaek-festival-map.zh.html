大邱炸鸡啤酒指南 — 夏季大邱炸鸡啤酒节(斗流公园)与全年营业的鸡店5家(平和市场鸡胗胡同的三亚统鸡·东城路元州统鸡) (2026年10月官方数据)

🎯 本指南的使用方法

不裹面衣炸出来的鸡胗嚼起来嘎嘣脆,冰啤酒冲掉油腻 — 大邱平和市场鸡胗胡同 (Pyeonghwa Sijang Dakddongjip Golmok / 평화시장 닭똥집골목) 把不裹面衣炸的“裸鸡胗 (누드똥집)”列为元祖菜品(胡同官方网站)。本指南把在大邱一起吃炸鸡和啤酒的方法分成两类。一类是每年夏天在斗流公园举办的大邱炸鸡啤酒节 (Daegu Chimaek Peseutibeol / 대구치맥페스티벌)(“치맥 (chimaek)”是炸鸡+啤酒),另一类是没有节庆的月份也营业的炸鸡胡同和老字号统鸡店。

2026年的节庆已经结束,2027年的日程还没有公布。无论是围绕节庆安排旅行的人,还是随时路过大邱想吃一顿炸鸡配啤酒的人,这一版都适用。

🎪 大邱炸鸡啤酒节 — 夏季,斗流公园

  • 2026年第14届: 7月1日(周三)~5日(周日)，大邱市斗流公园 (Duryu Gongwon / 두류공원) 一带,18:00起。主办方为(社)韩国炸鸡啤酒产业协会 (Hanguk Chimaek Saneop Hyeophoe / 한국치맥산업협회),承办方为大邱炸鸡啤酒节组委会 (Daegu Chimaek Peseutibeol Jojikwiwonhoe / 대구치맥페스티벌 조직위원회),赞助方有文化体育观光部·农林畜产食品部·大邱广域市·韩国观光公社等(节庆官方)。VisitKorea节庆信息也登载了同样的日期。咨询电话 053-248-9998(VisitKorea)
  • 2027年: 日程尚未公布(以2026-10-21节庆官方网站·VisitKorea为准)。节庆官方网站公布了入选2026-2027“大韩民国本土100 (Daehanmin-guk Rokeol 100 / 대한민국 로컬100)”
  • 往届日期每年都不同: 2025年第13届 7/2~7/6，2024年第12届 7/3~7/7，2023年第11届在8/30~9/3举办(节庆官方历史)。首届是在2013年
  • 2026年分区: 2·28自由广场 (2·28 Jayu Gwangjang / 2·28 자유광장) 的“大Frica水上乐园 (Daeprika Wotapia / 대프리카 워터피아)”(边淋水边看的演出·水上EDM),2·28纪念塔停车场 (2·28 Ginyeomtap Jucha-jang / 2·28기념탑주차장) 的“炸鸡啤酒大合唱俱乐部 (Chimaek Ttemchang Keulleop / 치맥 떼창 클럽)”,斗流公园路 (Duryu Gongwon-ro / 두류공원로) 一带的“K-炸鸡啤酒街 (K-Chimaek Seuteuriteu / K-치맥 스트리트)”,可隆露天音乐堂 (Kolon Yaoe Eumak-dang / 코오롱야외음악당) 的“炸鸡乐园EGG岛 (Chisang Nakwon EGG Seom / 치상낙원 EGG섬)”。7/4(周六)20点日程表里有E-World焰火表演(节庆官方详细日程)
  • 炸鸡摊位: 2026年参与商家有现炸炸鸡 (Gatteuigin Hurai-deu / 갓튀긴후라이드)·鸡冬卡里 (Dakdonggari / 닭동가리)·满鸡花 (Mangyehwa / 만계화)·通宵鸡 (Bamsaeuneun Dak / 밤새우는닭)·Smof炸鸡 (Seumopeu Chikin / 스모프치킨)·创造炸鸡 (Changjo Chikin / 창조치킨)·蒸了鸡通了鸡 (Jjimhaetdak Tonghaetdak / 찜했닭통했닭)·Han&Dul炸鸡 (Haen-dul Chikin / 한앤둘치킨),赞助方有教村炸鸡 (Gyochon Chikin / 교촌치킨)·Cass (Kaeseu / 카스)等(节庆官方)。各商家的菜品·价格以7/1公告附件PDF的形式公布,本版未能打开查看

🍗 平和市场鸡胗胡同 — 全年,4家

鸡胗 (Dakddongjip / 닭똥집) 就是鸡的沙囊(胡同官方)。据VisitKorea介绍,1972年三亚统鸡 (Samah Tongdak / 삼아통닭) 把剩下的鸡胗炸了,作为米酒下酒菜卖给劳务市场的工人,这就是胡同的开端,2000年代出现了酱油鸡胗和蒜香鸡胗。胡同官方网站把菜品介绍为裸鸡胗(不裹面衣炸的元祖)、炸鸡胗 (똥집튀김)、香辣鸡胗(1980年代研发)、酱油鸡胗、蒜香鸡胗。每家店都自己调制酱料,所以味道各不相同。

  • 三亚统鸡 (Samah Tongdak / 삼아통닭) — 大邱东区 (Dong-gu / 동구) 牙阳路9街 (Ayang-ro 9-gil / 아양로9길) 10(新岩洞 (Sinam-dong / 신암동))。电话 053-952-3650(胡同官方)。被介绍为胡同的第一家店(VisitKorea)
  • 平和统鸡 (Pyeonghwa Tongdak / 평화통닭) — 大邱东区 (Dong-gu / 동구) 牙阳路9街 (Ayang-ro 9-gil / 아양로9길) 6-6(新岩洞 (Sinam-dong / 신암동))。电话 053-958-0816(胡同官方)
  • 大邱统鸡 (Daegu Tongdak / 대구통닭) — 大邱东区 (Dong-gu / 동구) 牙阳路9街 (Ayang-ro 9-gil / 아양로9길) 6-6(新岩洞 (Sinam-dong / 신암동))。电话 053-941-9871(胡同官方)
  • 真味统鸡 (Jinmi Tongdak / 진미통닭) — 大邱东区 (Dong-gu / 동구) 牙阳路9街 (Ayang-ro 9-gil / 아양로9길) 10(新岩洞 (Sinam-dong / 신암동))。电话 053-954-6580(胡同官方)
  • 四家的营业时间都未能确认。胡同地图上有标注“现在店铺歇业中 (현재 가게는 휴업 중)”的店,去之前请打电话确认(胡同官方)
  • 胡同商会公告称2026年也自行举办了“平和市场炸鸡啤酒节 (Pyeonghwa Sijang Chimaek Peseutibeol / 평화시장 치맥페스티벌)”(2026-06-12发布,胡同官方)。日期在公告正文中未能确认

🐔 东城路老字号统鸡 — 1家

  • 元州统鸡 (Wonju Tongdak / 원주통닭) — 大邱中区 (Jung-gu / 중구) 东城路6街 (Dongseong-ro 6-gil / 동성로6길) 42-6。1978年在东城路开业并营业至今的鸡肉料理专门店。用国产鸡肉,卖外皮酥脆的炸统鸡 (튀김통닭)、甜咸的香辣统鸡 (양념통닭)、微辣的蔬菜炖鸡 (야채찜닭)(VisitKorea)。营业时间未能确认
  • 大邱市区的其他美食请看大邱西门市场夜市

🥗 饮食须知

  • 价格带: 5家店都没有找到官方公布的价格。价格未公布 — 请打电话或看店内菜单确认。节庆摊位的价格在节庆官方公告的附件PDF中
  • 内脏: 鸡胗(沙囊)是鸡的内脏部位(胡同官方)。不吃内脏的话,请选择统鸡·无骨鸡
  • 过敏原·麸质: 炸鸡胗·统鸡的面衣通常含有小麦粉。裸鸡胗是不裹面衣炸的(胡同官方) — 是否使用同一锅油请询问店家。香辣·酱油酱料可能含有大豆·小麦
  • 酒: 啤酒是含酒精饮料。不喝酒的话,请另外点饮料
  • 清真(Halal): VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的伊德 (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙丹路10街 (Usadan-ro 10-gil / 우사단로10길) 15,每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF, 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。本指南中的店铺和节庆摊位未能确认清真标识
  • 出示用卡片请看#1300 饮食需求手册

🧰 炸鸡啤酒实用信息 — 独自一人、预约、支付、点单、交通

  • 独自一人: 统鸡很多是整只出售,一个人吃可能会太多 — 点单前请问清楚能不能点半只。适合独自去的地点地图请看首尔单人用餐地图 — 外国人1人餐厅·酒吧·咖啡馆12个招牌
  • 去节庆的方法: 在地铁2号线斗流站 (Duryu-yeok / 두류역) 下车。节庆官方指引是从斗流站15号出口到斗流公园棒球场约700m(步行约15分钟),从东大邱站·大邱站出发则在1号线半月堂站 (Banwoldang-yeok / 반월당역) 换乘2号线,从斗流站14·19号出口出站。节庆当天人流极其拥挤,会把车辆引导到外部停车场,因此建议乘坐公共交通(节庆官方)
  • 去平和市场的方法: VisitKorea介绍说离东大邱站很近,交通便利。城际移动请看韩国KTX初次搭乘,跟着流程走 — 在没有闸机的车站不迷路的方法·韩国高速·城际巴士客运站,流程原样照搬 — App从一开始就完全不同
  • 支付: 银行卡·移动支付请看外国人韩国支付系统深度探索
  • 点单: 炸鸡店的点单流程请看韩国炸鸡点餐配送流程。语言不通时请看语言不通时的礼仪 — 翻译App与自助点餐机时代的点餐礼仪

⚠ 常见的4个错误

1. “炸鸡啤酒节每年7月同一天举办” — 2023年第11届在8/30~9/3举办(节庆官方历史)。2027年日程尚未公布,请等待节庆官方网站的公告

2. “节庆结束后大邱就没有炸鸡啤酒了” — 平和市场鸡胗胡同和东城路元州统鸡 (Wonju Tongdak / 원주통닭) 都是与节庆无关、全年营业的店铺(VisitKorea·胡同官方)

3. “鸡胗 (Dakddongjip / 닭똥집) 是鸡的粪便” — 它是鸡的沙囊(砂囊)(胡同官方)

4. “炸鸡啤酒节只有大邱有” — VisitKorea节庆信息中还登载了2026年浦项炸鸡啤酒节 (Pohang Chimaek Peseutibeol / 포항치맥페스티벌)(8/21~8/22)。在首尔,人们在汉江公园吃炸鸡配啤酒 — 汉江炸鸡啤酒野餐攻略
