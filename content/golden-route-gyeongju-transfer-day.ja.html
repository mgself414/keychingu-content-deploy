韓国ゴールデンルート② 慶州の乗り換え日 — 慶州駅から皇理団キルへ、荷物と一緒に一泊、釜山へは列車かバスか

副題: ソウルと釜山の間にある慶州は「立ち寄る」街だから難しいです。KTX駅は市街地の外20km、宿は市街地にあり、翌日は釜山へ発ちます。今回は観光コースではなく、荷物をどこに置き、夜に何を見て、朝は列車かバスかで釜山へ向かうかという一日の順序です。日帰り論争も正直に扱います。

ISSUE · #1373 · 2026-09-10

🎯 フレーム — 慶州は通過駅ではなく乗り換え日だ

ゴールデンルート(#1372)において慶州はソウルと釜山の間の一泊です。ですが、この一泊が三都市の中で最も難しいです。理由は地理です — KTX慶州駅 (Gyeongju Station / 경주역)は市街地から約20km離れた乾川邑 (Geoncheon-eup / 건천읍)にあります。降りてさらに30分進んでようやく宿に着き、翌日釜山へ行くにはまたその30分を出るか、市街地のターミナルからバスに乗る必要があります。ソウルと釜山では起きない「駅から市街地まで」という問題が、慶州だけで起きます。

だからこの回は慶州の見どころを扱いません。それは#1115(一泊二日フルガイド)・#1366(夜景)・#1369・#1370が担当します。この回は到着から出発までの一日の順序 — 荷物、バス、宿の位置、そして釜山行きの手段です。

  • 時間構成: 午後2時台到着 → 市街地移動30分 → チェックイン・荷物 → 夜の夜景 → 一泊 → 午前出発(二泊なら仏国寺を一日追加)
  • 核心の決定3つ: 一泊か日帰りか / 宿をどこに / 釜山行きは列車かバスか
  • 観光の実名: 大陵苑 (Daereungwon / 대릉원)ひとつ(夜景は#1366に委任)

なぜ一泊なのか — 三つの立場を並べて

この問いには三つの立場があり、Redditではどれも根強いです。

1. 「泊まっていけ」: 訪れた人の回顧は概ね「午後に着いて一泊し、翌朝出発しろ」に集約されます。根拠は夜です — 古墳と瞻星台 (Cheomseongdae / 첨성대)に照明が灯る夕方こそ慶州の本編だという話です(#1366)。

2. 「みんな釜山から日帰りしている」: 慶州在住者からの反論があります — 釜山から日帰りで来る観光客が大半だが、それでは慶州を見られない。慶州市の面積はソウルの三倍を超えるという話とともに。

3. 「日帰りでも十分だった」: 実際に釜山から一日で行ってきたというレポートが多く、満足したという投稿も多いです。

このルートでは一泊です。根拠は三つ — どのみちソウルから釜山へ向かう途中にあるので往復移動が生じない、荷物を宿に置いて夜を歩ける、翌日午前便で釜山へ行けば釜山初日が丸ごと使える。仏国寺・石窟庵まで見るなら二泊に伸ばします(市街地からバス40分の距離なので半日かかります)。

日帰りを選ぶなら基準を変えます — 釜山にベースを置き荷物は釜山に、朝のKTXで慶州駅まで30分、市街地往復バス1時間を見込んで午前10時前に市街地に入ります。その判断は#1114釜山編に付きます。

📖 物語1 — 駅が市街地を避けた理由: 2010年に京釜高速線 (Gyeongbu High-Speed Line / 경부고속선)が慶州を通ることになったとき、線路は市街地を通りませんでした。新羅の古墳と寺跡が市街地全体に広がっていたため文化財を避けて西の乾川へ迂回し、駅は新慶州駅 (Singyeongju Station / 신경주역)という名前で市街地の外に置かれました。2021年末に市街地の旧慶州駅が閉じ、2023年にこの駅はただの慶州駅になりました。だから今日のこの回の「30分」は、文化財を守るために生まれた30分です。

🚶 順序 — 到着から出発まで

起点は慶州駅(KTX、旧新慶州駅)。ソウル駅 (Seoul Station / 서울역)・水西駅 (Suseo Station / 수서역)から約2時間(#1372)。

① 慶州駅到着 → 市内バス → 皇理団キル (🚌 約30分)

  • 駅前のバス停から市街地行き50・51・70番(約30分、10~15分間隔)または座席バス700番台。運賃は交通カードで(#1298)。路線・時刻は慶州市バス情報で当日確認 — 700番台は甘浦 (Gampo / 감포)(東海岸)方面行きもあるので行き先表示を見ます。
  • タクシーは約20km、1万ウォン台後半。二人ならタクシーとバスで大差ありません。
  • 駅構内に私設の荷物預かりサービスがありますが公式ロッカーではありません。荷物は宿まで持っていきます。

② 皇理団キル宿 — チェックインと荷物 (滞在約30分)

  • 宿は大陵苑隣の皇理団キル (Hwangnidan-gil / 황리단길)・皇南洞 (Hwangnam-dong / 황남동)に取ります。夜景スポットへ徒歩で届く唯一の軸で、市外バスターミナルも市街地西側なので遠くありません。韓屋の宿はチェックインが遅いところがあるので、予約時に「荷物を先に預けられるか」を聞きます。
  • 大きな鞄はここで止めます。この回の核心 — 慶州で鞄を引いて歩く時間は、駅↔宿の30分だけであるべきです。

③ 大陵苑 → 夕方・夜景 (🚶 約10分・委任)

  • 宿から歩いて大陵苑へ。日没前後に入り、照明が灯る古墳の間を歩きます。その先の夕方・夜景の動線は#1366が正本です — この回は「歩いて行く」とだけ記します。

④ [一泊] → (二泊なら) 仏国寺・石窟庵 (🚌 約40分片道)

  • 二泊を選んだ場合、二日目は市内バス10・11番で仏国寺(約35~45分、20分間隔)、仏国寺から石窟庵へは12番シャトル。一日かかります。一泊なら、この段落は飛ばします。

⑤ 出発 — 釜山行き列車 vs バス (🚌 約50分 / 🚄 30分+駅アクセス30分)

  • 市外バス: 市街地西側の慶州市外バスターミナル (Gyeongju Intercity Bus Terminal / 경주시외버스터미널) — 江辺路 (Gangbyeon-ro / 강변로) — から釜山老圃総合ターミナル行きが一日50便前後、約50分、7,700ウォン(深夜9,200ウォン)。宿が市街地ならドアからドアまでこちらが速いです。予約はBusTago (버스타고)・T-money GO (티머니GO) — 高速バスアプリのKobus (코버스)には出ません(#1297)。
  • KTX: 市内バスで慶州駅まで30分出てKTX約30分、釜山駅到着。釜山の宿が釜山駅・南浦 (Nampo / 남포)寄りか、KTX切符をすでに買っているならこちら。
  • 判断: 釜山西面・海雲台の宿+荷物 → 老圃行き市外バスから地下鉄1号線。釜山駅近くの宿 → KTX。どちらでも午前10時前出発なら釜山の昼食に間に合います。

📖 物語2 — 皇南洞が宿の軸になった理由: 慶州の宿はもともと普門湖 (Bomun Lake / 보문호)リゾート団地に集まっていました。バスなしでは市街地に出られない場所です。2010年代後半、大陵苑の塀の隣の皇南洞の韓屋路地にカフェとゲストハウスが入り、皇理団キルになりました。今では歩いて夜景を見て、歩いてターミナル方面へ出られる唯一の軸になりました。乗り換え日の宿がここであるべき理由は、景色ではなく歩く距離です。

🙏 マナー — 韓屋の宿と古墳の間で

  • 韓屋の路地には住民が暮らしています。キャリーバッグの車輪の音は夜10時以降は立てないようにします。
  • 大陵苑の古墳は王の墓です。登りません。芝生の内側は立入禁止。
  • 夜間照明の下で三脚・フラッシュで他の人の視界を遮らないようにします。
  • 市内バスは後ろ扉から降車、交通カードは二回タッチ(乗り換え割引)。

💡 戸惑いポイント

  • 慶州駅 ≠ 市街地: 駅前は乾川邑です。「駅近くの宿」を取ると夜景もターミナルも遠くなります。
  • 駅の名前: 2023年より前の資料には「新慶州駅」。同じ駅です。市街地の旧慶州駅は2021年末に廃駅 — 地図アプリで「慶州駅」が二つ出たらKTX側を見ます。
  • 700番台バス: 皇理団キル直行がありますが甘浦行きも700番台なので行き先を確認します。
  • 市外バスは高速バスアプリにない: 慶州–釜山は市外路線なのでBusTago・T-money GO。Kobusで見つからないのが正常です。
  • 祝祭日: 秋夕・旧正月前後にKTXが完売した場合、市外バスが生きています(#1374)。
  • 韓屋チェックイン: 午後3~4時からのところが多いです。午後2時台到着なら荷物だけ先に預けます。

FAQ 6

Q1. 日帰りと一泊、決め手をひとつだけ挙げると?

  • 夜景を見るなら一泊。見るつもりがなく釜山の宿を動かしたくなければ日帰り。

Q2. 仏国寺・石窟庵は必ず見るべきか?

  • 時間があれば二泊目に。一泊なら市街地 — 大陵苑・瞻星台・月精橋 (Woljeonggyo / 월정교) — だけで慶州の半分は見られます(#1366)。

Q3. 荷物の預け先は?

  • 駅構内の私設サービスはありますが公式ロッカーではありません。宿に預けるのが正解です。釜山駅は地下鉄1号線の駅に公式のコインロッカーがあります。

Q4. 釜山行きの切符は事前に?

  • KTXはKorail Plusアプリ (코레일+)で当日でも大抵可能(祝祭日を除く)。市外バスは一日50便なので現地発券もできます。

Q5. ソウルから先に釜山へ行き、慶州を後に入れると?

  • 釜山→慶州→ソウルの順も可能です。慶州駅からソウル行きKTXが午後・夕方にあります。ただし荷物を持って市街地に入る構造は同じです。

Q6. レンタカーは?

  • 慶州の中では便利ですが三都市ルートには合いません。この回は公共交通機関基準です。
