한국 한정식 예약·드레스코드·매너 워크플로우 — 신라 라연 1~2주 전 예약부터 6단계 코스까지

부제: 외국인 관광객용 5-step 워크플로우 + 캐치테이블 예약·드레스코드·궁중 매너·결제 팁

ISSUE 03 · #838 · 2026-06-09

🎯 왜 한국 한정식 워크플로우 가이드인가

#831 한정식 6단계 매트릭스 알아도 — 예약·매너·결제 과정은 별개. 한국 한정식은 (a) 예약 시스템 (캐치테이블·네이버·전화 1~2주 전) (b) 드레스코드 (호텔 = smart casual / 인사동 = 자유) (c) 6단계 코스 서빙 순서·매너 (죽 → 전 → 주요리 → 탕 → 밥 → 후식) (d) 반찬 무료 무제한 리필 (e) 봉사료 10% + 부가세 10% (호텔). 외국인은 (1) 예약 시스템 한국어만 (2) 드레스코드 모름 (3) 코스 순서 헷갈림 (4) 결제 시 봉사료 놀람. 본 가이드는 5-step + 매너 매트릭스 + 영어 발화 + 호텔 정통 팁.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 매장 선택 + 예약 캐치테이블·네이버·전화·호텔 컨시어지 1~2주 전 신라 라연·삼청각 = 1~2주 전 필수
2️⃣ 드레스코드 + 도착 호텔 = smart casual / 인사동 = 자유 변동 5분 전 도착·예약 이름 확인
3️⃣ 자리 + 메뉴 안내 한정식 코스 선택·옵션 5~10분 영문 메뉴·코스 가격 확인
4️⃣ 6단계 코스 식사 죽 → 전 → 주요리 → 탕 → 밥 → 후식 1.5~3h 반찬 무료 무제한 리필
5️⃣ 결제 카드 + 봉사료 10% + 부가세 10% (호텔) 1~3분 일반 = 카드 OK / 팁 X

총 소요 시간: 인사동·전주 한정식 = 1.5~2h / 호텔 정통 = 2~3h

📱 예약 시스템 매트릭스

🥇 캐치테이블 (CatchTable) — 한국 #1 프리미엄 레스토랑 예약 앱

  • 특징: 한국 #1 프리미엄 식당 예약 앱·미슐랭 多·영문 일부 지원
  • 시스템:

1. 앱 다운로드 (한국 전화번호 SMS 인증)

2. 식당 검색 ("신라 라연"·"삼청각"·"용수산")

3. 날짜·시간·인원 선택

4. 예약금 결제 (일부 매장 = 30,000~100,000원 보증금)

5. 예약 확정·SMS 알림

  • 외국인 친화도: ★★★★ (영문 일부)

🥈 네이버 예약 (Naver Booking)

  • 특징: 한국 #1 검색·예약 통합·일반 한정식 매장 多
  • 시스템: 네이버 검색 → 매장 선택 → 예약 → 결제
  • 외국인 친화도: ★★★ (한국어 多·영문 일부)

🥉 호텔 컨시어지 (Hotel Concierge) — 외국인 1순위

  • 특징: 호텔 프런트 영어 응대·1순위 채널
  • 장점: 영어 OK·예약 대행·드레스코드 안내·교통 안내
  • 외국인 친화도: ★★★★★ (1순위)

🏛 전화 예약 (Phone Reservation)

  • 특징: 노포·전통 한정식집 多
  • 시스템: 전화 → 이름·인원·날짜 → 예약 확정
  • 외국인 친화도: ★★ (한국어·번역 앱)

🍽 6단계 코스 매너

1️⃣ 죽 (Juk) 매너

  • 순서: 가장 먼저 서빙 (입맛 돋움)
  • 매너: 작은 그릇 = 한 입씩 떠 먹기 / 후추 가감 가능

2️⃣ 전 (Jeon) 매너

  • 순서: 두 번째 (전채·반찬 시작)
  • 매너: 손가락 X (젓가락) / 막걸리·청주와 페어링

3️⃣ 주요리 (Juyori, 主菜) 매너

  • 순서: 중간·메인 (1~3 코스)
  • 매너: 갈비찜·불고기 = 젓가락 + 칼·포크 일부 / 구절판 = 9 칸 모듬 선택

4️⃣ 탕 (Tang) 매너

  • 순서: 주요리 후 또는 밥 동반
  • 매너: 신선로 (royal hot pot) = 직원이 끓이기 → 한 칸씩 떠 먹기

5️⃣ 밥 (Bap) 매너

  • 순서: 거의 마지막 (식사 마무리)
  • 매너: 반찬 12+종 = 골고루 / 김치·깍두기 무료 무제한 리필 ("김치 좀 더 주세요")

6️⃣ 후식 (Husik) 매너

  • 순서: 마지막
  • 매너: 약과·수정과·식혜·차 페어링

🙏 한정식 매너 핵심 7가지

한국 식사 매너 (전통)

1. 어른 먼저 시작: 어른이 먼저 수저 들면 시작

2. 수저 사용: 젓가락 + 숟가락 (한국식)

3. 그릇 들지 않기: 그릇 = 식탁에 두고 먹기 (한국 정통)

4. 소리 X: 후루룩·쩝쩝 소리 회피 (정통 격식)

5. 밥·국 = 숟가락: 밥·국 = 숟가락 사용

6. 반찬·전·구이 = 젓가락: 사이드 = 젓가락

7. 건배 시 잔 = 어른보다 낮게: 술 매너 (#829)

외국인 영어 발화 샘플

  • "예약했어요 (이름)" = "I have a reservation (name)"
  • "한정식 코스 하나" = "One hanjeongsik course, please"
  • "반찬 좀 더 주세요" = "More side dishes, please"
  • "이거 매워요?" = "Is this spicy?"
  • "카드 돼요?" = "Card accepted?"
  • "포장 가능해요?" = "Can I take leftover home?"

💰 결제 워크플로우

호텔 한정식

1. 카드 결제 (룸 차지 OR 개별)

2. 봉사료 10% + 부가세 10% 자동 추가

3. 총 가격 = 메뉴 + 20%

4. 팁 X (한국 = 팁 문화 없음)

일반 한정식 (인사동·전주·노포)

1. 카드 결제 OR 일부 현금

2. 봉사료 X (일반 매장)

3. 부가세 = 메뉴 포함 (별도 X)

4. 팁 X

결제 분리

  • 호텔: 한 명 결제 → 룸 차지 OR 송금
  • 일반: 한 명 결제 → 카카오페이·토스 송금

⚠ 외국인 자주 실수 7가지

1. "예약 X = OK": 신라 라연·삼청각 = 1~2주 전 필수 예약.

2. "드레스코드 X": 호텔 = smart casual (청바지·민소매·반바지 X).

3. "6단계 = 같이 나옴": 6단계 = 순서대로 서빙 (1.5~3h).

4. "봉사료 = 팁": 한국 = 팁 X. 호텔 봉사료 10% = 자동 청구.

5. "반찬 = 1회": 무료 무제한 리필 ("더 주세요" 요청).

6. "그릇 들기": 한국 정통 = 그릇 = 식탁에 두고 숟가락·젓가락 사용.

7. "포장 = X": 일부 매장 = 포장 가능 ("포장이요"). 호텔 = 일반적으로 X.

⚙ FAQ 8개

1. 첫 한정식 = 어디: 인사동·전주 한정식 (가성비 입문) → 호텔 라연 (럭셔리).

2. 인스타·vlog: 신라 라연 (미슐랭 3스타)·삼청각·인사동 한옥 한정식.

3. 데이트·기념일: 신라 라연·롯데호텔·삼청각.

4. 예약 방법: 캐치테이블 (한국 #1 앱) > 네이버 예약 > 호텔 컨시어지 > 전화.

5. 드레스코드: 호텔 = smart casual / 인사동 = 자유.

6. 알레르기·임신: #831 disclaimer 참조. 해산물·견과류·꿀 사전 고지.

7. 채식·할랄·코셔: #800 사찰음식 한정식 OR 채식 한정식 사전 요청.

8. VAT 환급: 식음료 일반 환급 X / 호텔 = 봉사료 10% + 부가세 10%.

⚠ 의료·안전·식이 disclaimer

한정식 = 6단계 코스 식사 (1.5~3h). 임신부·면역저하 = 익힌 메뉴 권장 (회·생선회 코스 회피). 알레르기 (해산물·소·돼지·계란·견과류·꿀) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

매장 정보 면책: 호텔 한식당·인사동 한정식 운영·가격·메뉴 변동 — 방문 전 NAVER/Kakao map 또는 공식 사이트 확인.

식이 제한 fallback:

  • 할랄·코셔: 일반 한정식 = 비할랄. → 사찰음식 한정식 [#800].
  • 채식·비건: 사찰음식 OR 채식 한정식 사전 요청 (잡채·전·찌개 채식 옵션).
  • 글루텐 free: 한정식 양념 (간장·고추장) 多. 사전 매장 확인.

💰 Essential Tourist Tips

  • 1인 평균 비용 (2026년 6월 기준):
  • 인사동·전주 한정식 = 40,000~80,000원
  • 사대부 한정식 = 60,000~150,000원
  • 사찰음식 한정식 = 30,000~100,000원
  • 호텔 한식당 = 100,000~500,000원 (+ 봉사료 10% + 부가세 10%)
  • 예약: 1~2주 전 (호텔·정통)
  • 드레스코드: 호텔 = smart casual / 일반 = 자유
  • 결제·팁: 한국 = 팁 X / 호텔 = 봉사료 10% + 부가세 10%
  • 응급: ☎ 1339 (의료, 영문) / ☎ 1330 (관광 통역)
