韩国节日·茶礼·祭祀文化 — 为什么全家人要聚在一起准备食物并行跪拜礼？

> 春节 (Seollal / 설날)·中秋节 (Chuseok / 추석)·茶礼 (Charye / 차례)·祭祀 (Jesa / 제사)·岁拜 (Sebae / 세배)·省墓 (Seongmyo / 성묘)·孝道 (Hyo / 효) — 为外国人解读韩国节日和祖先祭祀仪式的说明。重点不是“节日去哪里玩”，而是“为什么、做什么、有什么意义”。

在韩国生活或观看韩剧 (K-Drama) 时，你会发现一年中有两次，整个城市变得空荡荡的奇特景象。首尔 (Seoul / 서울) 的一半餐厅关门，高速公路 (Gosokdoro / 고속도로) 堵车超过10小时，全家人驾车驶向故乡。抵达后，厨房里一整天都在炸煎饼 (Jeon / 전) 和做年糕 (Tteok / 떡)，早上则摆满一桌食物，向祖先行两次跪拜礼 (bow)。外国人通常将其翻译为“韩国感恩节 (Korean Thanksgiving)”，但这只说对了一半。韩国两大节日春节 (Seollal / 설날)·中秋节 (Chuseok / 추석) 不仅仅是简单的假期，更是将已故祖先请回家中一同用餐，并让在世家人齐聚一堂的仪式。本文并非介绍“节日去哪里玩” (→ 参见相关链接)，而是从外国人的视角，解读为什么韩国人每年都要重复这种辛苦的仪式 — 其背后的家庭·祖先·孝道 (Hyo / 효) 思想。这是韩国文化解说系列第五篇。

⚠️ 外国人常有的3个误解

1. “中秋节 (Chuseok / 추석) = 美国感恩节 (Thanksgiving)” ❌ — 两者都庆祝秋季丰收，但有决定性差异。如果说感恩节是“在世家人·朋友的盛宴”，那么中秋节则是用新谷物向已故祖先举行茶礼 (Charye / 차례)，并前往墓地省墓 (Seongmyo / 성묘)，是一个以祖先为中心的节日。“感恩节 + 追思祖先”更为准确。

2. “茶礼 (Charye / 차례)·祭祀 (Jesa / 제사) = 宗教仪式 (礼拜)” ❌ — 虽然行跪拜礼并献上食物，看起来像宗教，但对大多数韩国人来说，这不是向神灵的礼拜，而是“缅怀和供奉已故父母·祖父母的家庭仪式”。基督教信徒家庭有时会以追悼礼拜代替茶礼 (Charye / 차례) — 形式因家庭而异。

3. “节日期间整个韩国都关门，游客无处可去” ❌ — 社区 (Dongne / 동네) 的小商店·餐厅确实会关门很多，但明洞 (Myeongdong / 명동)·仁寺洞 (Insadong / 인사동)·弘大 (Hongdae / 홍대)·宫殿 (Gunggwol / 궁궐)·百货商店·便利店 (Pyeonijeom / 편의점) (类似24小时杂货店)·主题公园通常会营业。相反，古宫 (Gogung / 고궁) 在节日期间往往免费开放并举办传统表演 (见下文⑧)。

① 春节 (Seollal / 설날) 和中秋节 (Chuseok / 추석) — 韩国的两大节日

韩国有许多纪念日，但“节日”通常指春节 (Seollal / 설날) 和中秋节 (Chuseok / 추석)。两者都遵循农历 (Yinli / 음력)，因此阳历日期每年都会变化。

  • 春节 (Seollal / 설날) (农历正月初一) — 农历新年的第一天。与家人一同迎接新的一年，吃年糕汤 (Tteokguk / 떡국)，行岁拜 (Sebae / 세배)，并举行茶礼 (Charye / 차례)。2026年是2月17日 (周二) 前后三天假期。
  • 中秋节 (Chuseok / 추석) (农历八月十五) — 秋季满月最圆的日子。这是一个感谢祖先一年丰收的节日，也被称为“韩佳慰 (Hangawi / 한가위)”。其起源可追溯到新罗时代，历史悠久。人们用新谷物做松糕 (Songpyeon / 송편) 并前往省墓 (Seongmyo / 성묘)。2026年是9月25日 (周五) 前后三天假期。

这两个节日的共同核心是归省 (Gwiseong / 귀성) — 散居各地的家人回到故乡老家团聚。因此，节日是韩国“全家人齐聚一堂的几乎唯一时间”。

② 茶礼 (Charye / 차례) vs 祭祀 (Jesa / 제사) — 最重要的区分

不仅外国人，连韩国年轻一代也容易混淆。两者都是向祖先献上食物并跪拜的仪式，但举行的时间和目的不同。

茶礼 (Charye / 차례) 祭祀 (Jesa / 제사, 忌祭祀)
何时 节日 (春节 (Seollal / 설날)·中秋节 (Chuseok / 추석)) 逝者的忌日 (逝世之日)
时间 节日当天早上 (白天) 传统上是晚上 (子时 (午夜11点至凌晨1点)) — 如今有时会提前到晚上
目的 向祖先告知节日到来 迎接逝者灵魂，款待食物
礼仪 简略 — 一杯酒，茶礼桌 (Charyesang / 차례상) 摆设 正式且隆重 — 食物种类繁多
对象 通常是多代祖先一同 通常是一位逝者 (忌日的主角)

> 名称的由来：茶礼 (Charye / 차례) 中的“茶”原本是指献茶的仪式。这在传统意义上表明它比祭祀 (Jesa / 제사) 更为简朴。实际上，传统茶礼 (Charye / 차례) 仅需一杯酒、一杯茶、一盘水果即可，并且常常省略祝文 (宣读祭文的程序)。

此外，还有省墓 (Seongmyo / 성묘) — 前往祖先墓地行跪拜礼并打理墓地，以及时祭 (Sije / 시제)·墓祭 (Myoje / 묘제) — 在远祖或墓地举行的季节性祭祀仪式。外国人在节日期间最常遇到的是茶礼 (Charye / 차례) (家中) 和省墓 (Seongmyo / 성묘) (墓地)。

③ 茶礼桌 (Charyesang / 차례상) 和食物 — “规则”实际上家家不同

提到节日，就会想到茶礼桌 (Charyesang / 차례상) (祭祀桌) — 摆放着鱼、煎饼 (Jeon / 전)、凉拌蔬菜 (Namul / 나물) (免费的韩式配菜)、水果、年糕 (Tteok / 떡) 的整齐桌子。网上流传着红东白西 (Hongdongbaekseo / 홍동백서) (红色水果放东边·白色水果放西边)、枣栗梨柿 (Joyullisi / 조율이시) (从左到右依次为大枣·栗子·梨·柿子) 等“规则”。但外国人必须了解一个真相。

  • 这些规则并非绝对法则。 韩国有一个古老的原则：家家礼 (Gagarye / 가가례) — “每家有每家的礼节”。“不要对别人的祭祀指手画脚”这句俗语就源于此。
  • 学术界和媒体也指出，红东白西 (Hongdongbaekseo / 홍동백서)·枣栗梨柿 (Joyullisi / 조율이시) 等说法实际上是近代以后才固定的，朝鲜时代的士大夫们甚至闻所未闻。也就是说，它们更接近后来的习俗，而非“正统规则”。
  • 韩国儒教传统的发源地成均馆 (Sungkyunkwan / 성균관) 近期也提出建议：“无需繁文缛节，以家庭和睦的方式，从简举行”即可。茶礼桌 (Charyesang / 차례상) 的摆放·食物种类因地域·家族而异，切勿断言“这是唯一正解” (如有疑问，建议向家中长辈确认)。

核心在于不是摆设的规则，而是缅怀祖先、家人团聚的心意，这是当今的趋势。顺带一提，外国人照片中看到的“堆积如山的茶礼桌 (Charyesang / 차례상)”通常是宗家或讲究礼仪的家族的景象 (王室正餐水剌床 (Surasang / 수라상) 的礼仪对士大夫的祭祀桌产生了影响 → 参见“深度了解” #690)，普通家庭的摆设要简单得多。

节日代表性的两种食物

  • 年糕汤 (Tteokguk / 떡국) (春节 (Seollal / 설날)) — 新年第一天吃的白色年糕汤 (Tteokguk / 떡국)。有句话说“吃一碗年糕汤 (Tteokguk / 떡국) 就长一岁”。在韩国传统的“虚岁 (在万岁之前的计算方法)”中，新年到来时所有人都会长一岁，年糕汤 (Tteokguk / 떡국) 就是其象征。古文献中也称年糕汤 (Tteokguk / 떡국) 为添岁饼 (Cheomsebyeong / 첨세병) (即“添岁数的年糕”)。白色象征着新开始的纯洁，长长的条状年糕 (Garaetteok / 가래떡) 则寓意长寿和财富。
  • 松糕 (Songpyeon / 송편) (中秋节 (Chuseok / 추석)) — 半月形，用松针蒸制的年糕 (Tteok / 떡)。用当年新收获的谷物 (新米·芝麻·豆子·红豆) 制成，寓意分享丰收的喜悦，并感谢祖先。全家人围坐一起做松糕 (Songpyeon / 송편) 本身就是中秋节 (Chuseok / 추석) 的代表性景象。

④ 岁拜 (Sebae / 세배)·省墓 (Seongmyo / 성묘)·归省 (Gwiseong / 귀성) — 活生生的节日习俗

如果说祖先祭祀仪式是节日的“庄严一半”，那么另一半则是在世家人之间的温馨习俗。

  • 岁拜 (Sebae / 세배) — 主要在春节 (Seollal / 설날)，孩子和年轻人向家中长辈行大礼，拜年。接受跪拜的长辈会送上“新年多福”等德谈 (Deokdam / 덕담) (祝福语)，并给孩子们压岁钱 (Sebae-don / 세뱃돈) (零花钱)。这是韩剧 (K-Drama) 春节 (Seollal / 설날) 场景的常客，也是外国人被邀请到韩国家庭时印象最深刻的时刻。
  • 省墓 (Seongmyo / 성묘) — 主要在中秋节 (Chuseok / 추석) (春节 (Seollal / 설날) 也会)，前往祖先墓地行跪拜礼并打理墓地周围。中秋节 (Chuseok / 추석) 前会提前为墓地除草伐草 (Beolcho / 벌초)。这是全家人一同登山，缅怀祖先的时光。
  • 归省 (Gwiseong / 귀성) = 民族大迁徙 — 节日前后，数千万人会返回故乡。因此，节日是韩国最大的交通拥堵季节 — KTX (韩国高速列车)·高速巴士车票提前几周售罄，平时4~5小时的路程可能需要10小时以上。如果外国游客计划在节日期间在韩国国内移动，就必须提早预订火车票 (见下文⑧)。

⑤ 为什么要做这一切 — 儒教和孝道 (Hyo / 효) 的根源

节日仪式的根源，用一个字概括就是孝道 (Hyo / 효, filial piety)。孝道是尊敬父母和祖先，报答其恩情 — 儒教 (Confucianism) 深植于韩国社会的核心价值观。

  • 在儒教世界观中，家庭不会因死亡而断裂。已故的祖先仍然是家庭的一员，后代若精心供奉，便会以阴德 (Eumdeok / 음덕) (祖先的庇佑) 庇佑后代。茶礼 (Charye / 차례)·祭祀 (Jesa / 제사) 就是“在世家人与已故家人一同用餐”的场合。
  • 因此，仪式的核心动作是两次深鞠躬 (再拜) — 向在世的人行一次，向已故的人行两次，这是传统。这是对祖先的尊敬和思念的表达。
  • 有趣的是：学者们认为这种祖先祭祀仪式不仅是儒教 (孝道 (Hyo / 효)) 的产物，也与朝鲜半岛此前存在的祖先神·巫俗信仰 (Gut / 굿) 紧密相连。也就是说，“祖先庇佑后代”的情感在儒教传入之前就已在韩国文化中流传。

总而言之，节日期间全家人聚在一起准备食物并跪拜的原因是 — “记住我们从何而来 (根源)，报答其恩情，并确认家庭血脉的延续”。

⑥ 现代的变化 — 简化·节日综合症 (Myeongjeoljeunghugun / 명절증후군)·“旅行的节日”

节日文化正在快速变化。外国人了解这些，可以更立体地理解韩国社会。

  • 茶礼 (Charye / 차례) 简化·省略 — 大幅减少食物，男女共同分担，甚至完全不举行茶礼 (Charye / 차례) 的家庭越来越多。成均馆 (Sungkyunkwan / 성균馆) 的简化建议也与这一趋势相符。
  • 节日综合症 (Myeongjeoljeunghugun / 명절증후군) (指因节日劳动·长途移动·家庭矛盾而产生的压力) — 韩国特有的词汇，指因节日劳动、长途移动和家庭矛盾而产生的压力。尤其是儿媳一代的厨房劳动负担、超过10小时的归省 (Gwiseong / 귀성) 路程、亲戚的唠叨 (“结婚了吗？”“找到工作了吗？”)是主要原因。这也是韩国社会“简化”节日的原因之一。
  • “旅行的节日” — 简化或跳过茶礼 (Charye / 차례)，利用假期在国内外出游的家庭越来越多。仁川机场每逢节日挤满出境人潮，已成为新景象。也就是说，“所有韩国人都在节日期间举行茶礼 (Charye / 차례)”已不再是事实 — 坚守传统的家庭、简化的家庭、出游的家庭并存。

这种变化本身就是韩国社会的一个缩影 — 传统 (孝道 (Hyo / 효)·家庭) 与个人主义·实用主义碰撞，正在寻找妥协点。

⑦ 外国游客在节日期间来到韩国 — 会看到什么

> 节日假期对外国游客来说优缺点明显。“紧闭的门”背后蕴藏着意想不到的机会。

  • 关闭的场所：社区 (Dongne / 동ne) 的小餐厅·商店·理发店·小型美术馆等，在节日当天 (尤其是中秋节 (Chuseok / 추석)·春节 (Seollal / 설날) 当天)会有1~3天关闭。如果是首次韩国旅行，市中心·旅游区住宿比郊区住宅区更安全。
  • 开放的场所：明洞 (Myeongdong / 명동)·仁寺洞 (Insadong / 인사동)·弘大 (Hongdae / 홍대)·北村 (Bukchon / 북촌)·江南 (Gangnam / 강남)·宫殿 (Gunggwol / 궁궐) 一带以及釜山 (Busan / 부산)·庆州 (Gyeongju / 경주)·济州 (Jeju / 제주) 的主要景点通常正常运营。便利店 (Pyeonijeom / 편의점) (CU·GS25·7-Eleven·E-mart24) 24小时营业不变 — 即使社区 (Dongne / 동ne) 餐厅关门，也能解决用餐问题。百货商店·主题公园·展望台也大多营业。
  • 节日福利：首尔 (Seoul / 서울) 的古宫 (Gogung / 고궁) (景福宫 (Gyeongbokgung / 경복궁)·昌德宫 (Changdeokgung / 창덕궁) 等) 在节日期间通常免费开放并举办传统表演·体验活动。在空旷的市中心穿着韩服 (Hanbok / 한복) 游览古宫 (Gogung / 고궁)，是节日期间才能享受的特别体验。
  • 交通注意：KTX (韩国高速列车)·国内航班提前几周就已售罄。如果计划在节日期间从首尔 (Seoul / 서울) 前往釜山 (Busan / 부산)·庆州 (Gyeongju / 경주)·济州 (Jeju / 제주) 等地，必须提早订票。相反，节日当天首尔 (Seoul / 서울) 市内会很清静，可以悠闲地享受平时人潮拥挤的地方。

> 所有价格·运营·开放信息每年·各机构均有不同，2026年为估算 — 建议访问前确认官方渠道 (VisitKorea·各景点)。

❓ 外国人常见问题 (FAQ)

  • 中秋节 (Chuseok / 추석) 和美国感恩节 (Thanksgiving) 完全一样吗？ — 有相似之处 (秋季丰收·家庭聚会·丰盛食物)，但中秋节 (Chuseok / 추석) 的核心区别在于它是以祖先为中心，向祖先举行茶礼 (Charye / 차례) 并前往墓地省墓 (Seongmyo / 성묘) 的节日。请理解为“感恩节 + 追思祖先”。
  • 茶礼 (Charye / 차례)·祭祀 (Jesa / 제사) 是宗教吗？ — 对大多数韩国人来说，它们不是宗教礼拜，而是家庭仪式·传统文化。但基督教家庭会以追悼礼拜代替茶礼 (Charye / 차례) 等，形式因家庭而异。
  • 茶礼桌 (Charyesang / 차례상) 必须按照规定摆放吗？ — 尽管有红东白西 (Hongdongbaekseo / 홍동백서)·枣栗梨柿 (Joyullisi / 조율이시) 等“规则”，但它们并非绝对，因地域·家族而异 (家家礼 (Gagarye / 가가례))。成均馆 (Sungkyunkwan / 成均馆) 也建议简化。请勿认为只有一个“正确答案”。
  • 节日期间去韩国旅行可以吗？ — 市中心·旅游区·古宫 (Gogung / 고궁)·便利店 (Pyeonijeom / 편의점) 通常开放，所以没问题。但社区 (Dongne / 동ne) 小店可能会关门，前往地方的火车票会提早售罄，建议选择市中心住宿 + 提早预订。
  • 外国人也能体验茶礼 (Charye / 차례) 或岁拜 (Sebae / 세배) 吗？ — 如果被邀请到韩国家庭，可以直接看到岁拜 (Sebae / 세배)·茶礼 (Charye / 차례)。在节日假期古宫 (Gogung / 고궁) 的传统体验活动中，也可以轻松体验跪拜礼·游戏·食物等节日文化。
