🍱 4채널 deep dive

🍱 한정식 무한 리필 (Hanjeongsik Refill)

핵심 가치: 반찬 무료 무한 리필 #1 + 장아찌 풀세트.

  • 추천 매장:
  • 신라호텔 라연 (미슐랭 3스타) — 정통
  • 삼청각 — 정통
  • 인사동 한정식 — 가성비 정통
  • 가격 anchor: 한정식 코스 40,000~150,000원 (장아찌 무료 포함)
  • 시간: 11:30~22:00
  • 외국인 친화도: ★★★★

🍚 가정식 백반 (Korean Home-style Set)

핵심 가치: 홈스타일 가성비 + 장아찌 2~3종 + 풀세트.

  • 추천 매장:
  • 종로·강남·명동 백반집 — 가성비
  • MZ 백반집 — 가정식
  • 체인 (한솥·본도시락) ([#854](#854)) — 가성비
  • 가격 anchor: 8,000~15,000원/1인 (장아찌 포함)
  • 시간: 11:00~22:00
  • 외국인 친화도: ★★★★ (가성비)

🛒 시장 노포 (Market Specialty)

핵심 가치: 노포 + 1년 숙성 정통 + 시식 OK.

  • 추천 시장:
  • 광장시장 장아찌 골목 — 노포 정통
  • 남대문 시장 반찬가게 — 가성비 정통
  • 전주 한옥마을 — 1년 숙성 정통
  • 가격 anchor: 1팩 5,000~20,000원
  • 시간: 09:00~22:00
  • 외국인 친화도: ★★★ (노포)

🛍 마트·면세점 (Mart·Duty-free)

핵심 가치: 진공 포장 + 통관 OK + 귀국 선물 #1.

  • 추천 매장:
  • 이마트·롯데마트·홈플러스 — 진공 포장
  • 인천공항·김해공항 면세점 — 단무지·오이장아찌 (소량)
  • 가격 anchor: 1팩 3,000~10,000원
  • 시간: 마트 = 10:00~22:00 / 면세점 = 06:00~22:00
  • 외국인 친화도: ★★★★★ (진공·영문 일부)
  • 귀국 통관: 1L 미만 OK / 액체류 100ml 룰

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가격·매니아·귀국 완전 다름. 무료 = 한정식 / 가성비 = 가정식 / 노포 = 시장 / 귀국 = 마트.

2. "한정식 반찬 = 비용": 한정식 반찬 = 무료 무한 리필 (장아찌 포함).

3. "시장 노포 = 영어 OK": 시장 노포 = 한국어 정통·번역 앱 필요.

4. "진공 = 통관 X": 진공 = 통관 OK (1L 미만·액체류 100ml 룰).

5. "VAT 환급 = 안 됨": 마트 = VAT 환급 가능 (5만 원 이상 즉시 환급).

⚙ FAQ 8개

1. 첫 장아찌 채널 = 어디: 한정식 무한 리필 (#1 무료) → 마트 (귀국 선물).

2. 인스타·vlog: 한정식 반찬 풀세트 (#1)·광장 장아찌 골목.

3. MZ 트렌드: 한정식 가성비 (#1)·MZ 카페 장아찌 fusion.

4. 데이트·기념일: 한정식 무한 리필 (정통).

5. 가족 동반: 가정식 백반 + 한정식.

6. 알레르기·임신: [#867 disclaimer](#867) 참조.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 마트 = 가능 (5만 원 이상 즉시 환급).

⚠ 의료·안전·식이 disclaimer

장아찌 4채널 모두 일반 음식. 임신부·어린이 = OK (매콤 조절). 알레르기 (간장 글루텐·고추) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 4채널 모두 채식 = OK.
  • 채식·비건: 4채널 모두 채식 = OK.
  • 글루텐 free: 간장 = 글루텐 함유 → Tamari 대체 OK.
