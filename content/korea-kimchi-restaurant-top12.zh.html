泡菜指南——外国人在首尔学泡菜、看泡菜、吃泡菜的方法：泡菜间博物馆·腌泡菜大庆典·广藏市场·泡菜种类与饮食禁忌（2026年10月官方信息）

副标题：泡菜间博物馆（仁寺洞）周二至周日10~18点·周一闭馆（官方） · 大韩民国腌泡菜大庆典 2025年11/22 aT中心（2026年未公告） · 光州泡菜节第33届（官方，2026年日期为二手信息10/23~25） · 广藏市场小吃街每日09~23（VisitSeoul） · 白菜泡菜用鱼露调味，多数泡菜调料含腌海鲜（VisitKorea） · 腌泡菜文化 UNESCO 2013——截至2026-10-08。米其林2026没有泡菜招牌餐厅，因此不列餐厅名

🎯 本指南使用方法

旧版指南中的“泡菜餐厅12选”写的是“广藏·钟路老字号”“仁寺洞分店”这类没有店名的泛称，或者根本没有出处，价格区间、“每年1,750万人”、“MZ世代58%”、“英文菜单65%”、清真·犹太洁食（Kosher）章节也全部没有依据（甚至把平壤面屋误写成了猪蹄店）。2026-10-08打开米其林首尔2026必比登推介名单查看，其中没有泡菜·菜包肉·猪蹄的招牌餐厅——因此本指南不写餐厅名。取而代之的是，我们写通过官方页面（泡菜间博物馆·首尔市·光州市·VisitSeoul·VisitKorea·UNESCO）确认过的“学泡菜、看泡菜、买泡菜的地方”，以及饮食事实（腌海鲜）。餐厅请在广藏市场小吃街按地图App的评论数来挑选。

🥬 泡菜种类与饮食禁忌——VisitKorea官方

  • 该页面列出的五种：白菜泡菜 (Baechu Kimchi / 배추김치)、萝卜块泡菜 (Kkakdugi / 깍두기)、萝卜片水泡菜 (Nabak Kimchi / 나박김치)（水泡菜，不辣）、黄瓜泡菜 (Oi Sobagi / 오이소박이)、萝卜缨泡菜 (Yeolmu Kimchi / 열무김치)。白菜泡菜 (Baechu Kimchi / 배추김치) 用辣椒粉·大蒜·鱼露调味后发酵。
  • 素食提示（VisitKorea）：“泡菜调料大多含有腌海鲜·鱼露·肉汤”。地方泡菜中还会用到鲍鱼·带鱼·猪肉。→ 素食者·纯素者点餐前先问清楚。白泡菜 (Baek Kimchi / 백김치)·冬泡菜 (Dongchimi / 동치미)·小萝卜泡菜 (Chonggak Kimchi / 총각김치) 是否为纯素，官方页面没有写，因此不下结论。
  • 旧版指南中的清真·犹太洁食章节和“寺院料理泡菜”没有出处——首尔通过韩国伊斯兰教中央会（KMF）认证的韩餐厅只有1家（Eid，#337）。
  • 腌泡菜文化 (Kimjang / 김장) 是 UNESCO 人类非物质文化遗产 2013（官方）。

🏛 泡菜间博物馆——仁寺洞

  • 周二至周日10~18（入场至17:30），周一·1/1·春节·中秋·12/25闭馆，电话02-2088-8531（官方）。有泡菜历史、腌制过程的影像与展览（VisitKorea）。体验项目在官方网站上只有菜单，看不到名称和价格 → 预约前先咨询。网站有英文切换，但英文页面打不开。
  • 2024年泡菜日 (Kimchi Day / 김치의 날)（11/22）免费入场（首尔市）。2026年是否重复未确认。

🎪 两个腌泡菜庆典——11月首尔·10月光州

  • 大韩民国腌泡菜大庆典 (Korea Kimjang Festival / 대한민국 김장대축제)（首尔）：2025年11/22在aT中心举行，有与名人一起腌泡菜的体验、UNESCO展览、生产者直销，约100名多元文化家庭和外国人名誉市民参加（首尔市·报道）。2026年日程尚未公布——请在11月初确认首尔市公告。与旧名称“首尔腌泡菜文化节”（市厅广场）不同。
  • 光州泡菜节 (Gwangju Kimchi Festival / 광주김치축제)：官方网站挂出了第33届，但没有日期。二手出处为2026-10-23~25。2025年第32届为10/31~11/2，5.7万人。入选2026~27年文化观光节庆（报道）。场地出处不一，故不写。

🍲 为什么没有餐厅

  • 米其林首尔2026必比登新增名单中没有泡菜·菜包肉·猪蹄店，其他官方出处也没有指定具体餐厅。泡菜汤·泡菜饼·菜包肉请在广藏市场 (Gwangjang Market / 광장시장) 小吃街（每日09~23）按地图App评论数和当天营业情况来挑选。“免费无限续添”·“30年老店=自己腌制”·“陈年泡菜6个月以上”同样没有出处，已删除。

⚠ 常见错误5条

1. 周一去泡菜间博物馆 (Museum Kimchikan / 뮤지엄김치간)——闭馆。

2. 把泡菜当素食——多数含腌海鲜·鱼露（VisitKorea）。点餐前确认。

3. 断定11月首尔腌泡菜庆典的日期——2026年未公告。2025年是11/22。

4. 把光州泡菜节当作官方日期——官方网站没有日期（二手10/23~25）。

5. 相信旧版的价格区间和餐厅——全部没有出处。

⚙ FAQ 6条

1. 想学泡菜怎么办？——参观泡菜间博物馆 (Museum Kimchikan / 뮤지엄김치간)展览（周二至周日），体验项目需咨询。课程只有二手出处。

2. 腌泡菜庆典是什么时候？——首尔2025年11/22（2026年未公告）· 光州2026年10/23~25（二手）。

3. 有纯素泡菜吗？——官方页面没有写。白菜泡菜 (Baechu Kimchi / 배추김치) 用鱼露调味。

4. 泡菜餐厅有哪些？——本指南没有。广藏市场小吃街 + 地图App。

5. 门票多少钱？——泡菜间博物馆官方未公布（二手5,000）。泡菜日 (Kimchi Day / 김치의 날) 免费（2024年）。

6. 腌泡菜文化是UNESCO遗产吗？——2013年列入（官方）。
