🎯 왜 한라산 가이드인가

한라산 (Hallasan) = 한국 #1 산·1947m·UNESCO 자연유산 2007·백록담 (정상 분화구 호수). 외국인 페인포인트 = (a) "한라산 = 일반 산" 잘못된 인식 (b) 한국 #1·1947m·UNESCO (c) 백록담 = 정상 분화구 호수 매트릭스 #1 (d) 4 등산 코스 매트릭스 (윗세오름·영실·성판악·관음사) (e) 봄 (4-5월 진달래)·가을 (10-11월 단풍)·겨울 (12-2월 백록담 매트릭스 #1) (f) 영문 풀세트.

본 가이드는 5축 12 시그니처 + 백록담 + 4 코스 + 시즌.

⚠ 외국인 자주 실수 5가지

1. "한라산 = 일반 산": 한국 #1·1947m·UNESCO.

2. "백록담 = 일반 호수": 정상 분화구 호수 매트릭스 #1·겨울 매니아 매트릭스 #1.

3. "윗세오름 = 정상": 윗세오름 = 1700m + 매트릭스·정상 1947m = 매니아 매트릭스.

4. "겨울 hiking = 매니아만": 겨울 백록담 = 매니아 매트릭스 #1·아이젠 필수.

5. "4 코스 = 다 같음": 영실·윗세오름·성판악·관음사 = 완전 다른 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 영실·윗세오름 = 4-5h 매트릭스 #1.

2. 정상 (백록담): 성판악·관음사 = 8-10h·매니아 매트릭스.

3. 겨울 (12-2월): 아이젠 필수·방한복·매니아 매트릭스 #1.

4. 사전 예약: 정상 코스 = 인터넷 사전 예약 필수·1-2주 전.

5. 시즌: 봄 (진달래)·가을 (단풍)·겨울 (백록담) 매트릭스 #1.

6. 추천 페르소나: 가족·시니어 = 영실 + 윗세오름 / MZ·매니아 = 정상 + 사진 / 매니아·hiking = 정상 + 1박.

한라산 hiking = 임신부·심장 환자·고혈압 의사 상담·겨울 아이젠 + 방한복 필수. 어린이 = 영실·윗세오름 OK·정상 X 권장. 응급 ☎ 1339·1330·119.
