⚠ 외국인 자주 실수 5가지

1. "송도 = 해운대 다음": 송도 = 한국 1번지 해수욕장 1913 + 외국인 매니아 + 한국 #1 해상 케이블카.

2. "송도 케이블카 = 어디나": 송도 케이블카 = 1.62km 한국 1번지 해상 케이블카 + 외국인 인스타 1번지.

3. "영도 = 작은 섬": 영도 = 부산 인스타 1번지 + 흰여울 + 태종대 + 깡깡이 예술마을 통합.

4. "흰여울 = 사진만": 흰여울 = 외국인 vlog 1번지 + 카페 + 외국인 매니아 1번지.

5. "태종대 = 못 감": 태종대 = 부산 1번지 자연 + 절벽·달뜨는 자리 + 외국인 매니아 1번지.

⚙ FAQ 6개

1. 외국인 송도 동선: KTX 부산역 → 자갈치역 (지하철 1호선) → 마을버스·택시 송도.

3. 외국인 영도 흰여울: 외국인 vlog 1번지 + 카페 + 외국인 매니아 1번지.

4. 외국인 태종대: 부산 1번지 자연 + 절벽·달뜨는 자리.
