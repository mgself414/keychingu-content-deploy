타겟 비건 / 할랄 (이슬람) / 코셔 (유대교) / 채식·종교 식이 외국인

외국인이 자주 하는 실수 5가지

1. "비건=한국에 없다"는 오해

한국 비건 식당은 2020년 이후 폭발적 증가 — 이태원·한남·홍대·연남·성수에 100+ 비건 식당. 사찰음식·채식 라인업까지 포함하면 외국인 비건 1주일 식사 OK.

2. 사찰음식 = 비건이라는 단순 가정

사찰음식은 고기·해산물 X + 5신채(파·마늘·부추·달래·흥거) X. 일반 비건과 다른 카테고리. 한국 사찰음식 식당은 매우 한정적이지만 정통 한국 비건 1순위.

3. 한국 식당 "비건" 메뉴 100% 신뢰

한국 일반 식당의 "비건 가능"은 육수·기름·발효 양념 안 검증 빈번. 진짜 비건이면 인증 비건 식당 또는 외국인 비건 식당으로.

4. 할랄 = 이태원만 있는 줄 아는 것

할랄 식당은 이태원 이슬람 사원 거리 + 강남·명동·홍대 일부 매장. 동남아·중동·터키 식당이 핵심. 한국 사원 인증 매장은 한국이슬람중앙회(KMF) 사이트 검색 가능.

5. 알레르기 표기 의존

한국 식당의 알레르기 표기는 일부만 영문. 글루텐·견과류·갑각류·계란·우유·콩 알레르기는 영문 메뉴 + 직원 직접 확인 + 사진 필수.

★ 식이별 풀가이드

1️⃣ 비건 (Vegan) — 동물성 일체 X

한국 비건 식당 분포:

  • 이태원·한남: 외국인 친화 비건 카페·브런치 30+
  • 연남·성수·홍대: MZ 비건 트렌디 식당 20+
  • 인사동·종로: 사찰음식 정통 5+

검증된 한국 비건 라인업 (참고):

  • 플랜티 (Planty): 비건 한식 (한남·이태원)
  • 러쉬 비건 카페: 비건 브런치 (홍대)
  • 바티드 (Vatted): 비건 양식 (성수·연남)
  • Whole Foods Market (한국 일부 매장): 비건 식재료
  • 선재 (Seonjae): 사찰음식 정통 (인사동)

비건 한식 메뉴 추천:

  • 비빔밥 (고기·계란 빼달라 요청 + 고추장 비건 확인)
  • 김밥 (계란·햄·참치 빼달라 요청)
  • 잔치국수 (멸치·고기 다시 빼달라 요청 — 어려움)
  • 사찰음식: 두부·산채·잡곡밥 100% 비건

확인 키워드:

  • "비건이에요 (Vegan-ieyo)" = "I'm vegan"
  • "고기·생선·계란·우유·꿀 다 빼주세요"

2️⃣ 할랄 (Halal) — 이슬람 식이

한국 할랄 식당 분포:

  • 이태원 이슬람 사원 거리: 메인 할랄 골목 (이태원역 도보 5~10분)
  • 강남·명동·홍대 일부 매장: 인도·터키·말레이시아·인도네시아 식당

검증된 한국 할랄 라인업 (참고):

  • 이태원 이슬람 사원 거리: 터키·파키스탄·이집트·말레이시아·인도네시아 식당 20+
  • 이드 (Eid) 할랄 식당: 한국식 할랄 (서울 일부)
  • 인도 식당 (이태원·강남): Bombay Curry·Saffron 등

한국 사원 인증 매장:

  • KMF (한국이슬람중앙회) 인증 매장 검색 = official site
  • 매장 입구에 "Halal Certified" 표지

할랄 한식 옵션 (제한적):

  • 한국 갈비·삼겹살 = 돼지·소 도축 비할랄 빈번 → 할랄 인증 한식당 사전 확인
  • 한국 닭갈비·해물 = 일부 매장 할랄 가능
  • 한국 비빔밥·잔치국수 = 육수·고기 빼달라 요청 (사실상 비건)

3️⃣ 글루텐 프리 (Gluten-Free)

한국 글루텐 프리 식당 (제한적):

  • 한국 음식의 간장·고추장은 밀 함유 다수 → 직접 확인
  • 한남·압구정·강남 글루텐 프리 카페·식당 10+
  • 쌀 베이스 한식 (밥·잡곡·떡)은 글루텐 프리 가능

확인 키워드:

  • "글루텐 알레르기예요 (Gluten allergy-ieyo)"
  • "밀가루·간장 빼주세요" — 간장은 한국 음식 핵심이라 어려움

4️⃣ 코셔 (Kosher) — 유대교 식이

한국 코셔 식당 (매우 제한적):

  • 이태원 일부 매장에서 코셔 옵션 제공
  • 이스라엘·중동 식당 일부에서 가능
  • 공식 코셔 인증 매장은 한국에 거의 없음 → 자체 조리 또는 비건 옵션 활용

FAQ

Q1. 영어 통하나요?

비건 카페·할랄 식당 95% 영어 가능. 사찰음식·한국 정통은 영문 메뉴 일부.

Q2. 비건·할랄 인증 어디서 확인?

  • 할랄: KMF (한국이슬람중앙회) 공식 사이트 / 매장 입구 표지
  • 비건: 한국비건협회 사이트 / Happy Cow 앱

Q3. 한국 일반 식당 "비건 가능"?

확인 필요. 육수·기름·발효 양념·생선소스가 들어갈 수 있음. 비건 100% 보장은 인증 매장만.

Q4. 가족 비건·할랄?

이태원·한남·홍대 = 가족 친화 비건·할랄 매장 다수. 영문 메뉴 + 알레르기 표기 + 어린이 의자 보편.

Q5. 한국 음식 베이스로 비건·할랄?

  • 비건: 사찰음식·비빔밥(고기·계란 빼기)·두부 한식
  • 할랄: 할랄 인증 한식당 (제한적) → 한식 + 인증 확인

Q6. 편의점 비건·할랄?

한국비건협회 인증 편의점 라인 (CU·GS25·세븐일레븐 일부 매장 — 비건 김밥·도시락·과자). 할랄은 거의 없음 → 과일·견과류·생수.
