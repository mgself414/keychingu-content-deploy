한국 회 6종 매트릭스 — 활어 vs 숙성·광어·방어·참치·연어·도미·전어 풀세트

> 부제: 외국인 관광객용 한국 회 활어·숙성 차이 + 6종 매트릭스 + 일본 sushi와 차이

ISSUE 03 · #864 · 2026-06-09

🎯 왜 한국 회 매트릭스인가

외국인 한국 회 페인포인트 = "일본 sushi와 같다"고 생각. 한국 회 = 활어 (live fish) 정통 + 초장·쌈 문화 + 노량진·자갈치 시장. 일본 sushi = 숙성+밥+간장 / 한국 회 = 활어+초장+쌈. 같은 "Korean sashimi"라도 광어 (활어 #1)·방어 (겨울 정통·자갈치)·참치 뱃살 (지방 #1)·연어 (글로벌)·도미 (한정식)·전어 (가을 정통) 각자 다른 시기·매니아. 외국인은 (a) 활어 vs 숙성 차이 모름 (b) 초장 vs 와사비 차이 모름 (c) 쌈 문화 모름 (d) 매운탕 코스 모름. 본 가이드는 6종 매트릭스 + 활어·숙성 + 한국식 회 한 상.

🐟 활어 vs 숙성 — 한국 회 vs 일본 sushi

🔄 핵심 차이 매트릭스

축 🇰🇷 한국 회 (활어) 🇯🇵 일본 sushi (숙성)
상태 활어 (live fish·즉살) 숙성 (aged·1~3일)
식감 쫄깃·탄력 강함 부드러움·감칠맛
양념 초장 (gochujang)·쌈·마늘 간장 (shoyu)·와사비·생강
곁들임 쌈채소·매운탕·소주 밥 (sushi rice)·미소된장국
분위기 시장 정통·노포 술집 정통 sushi-ya·omakase
가격 시장 = 가성비 / 횟집 = 중급 정통 omakase = 럭셔리

🎯 외국인 핵심 포인트

  • 한국 회 = 활어 = "쫄깃함"·즉살 정통
  • 일본 sushi = 숙성 = "감칠맛"·1~3일 aged
  • 참치·연어 = 한국에서도 숙성 (cold 보관)
  • 방어·광어·도미·전어 = 활어 정통

🐠 6종 deep dive

🐠 광어회 (Gwang-eo) — 입문 #1

  • 시그니처: 활어 정통·사계절·횟집 #1
  • 재료: 광어 (olive flounder) 활어 + 초장·쌈채소
  • 외국인 친화도: ★★★★★ (#1 입문·글로벌 인지)
  • 추천 시장·횟집:
  • 노량진수산시장 — 사계절·#1
  • 자갈치시장 (부산) — 정통
  • 횟집 cluster (강남·홍대)
  • 계절: 1월 정통 (한겨울 살)
  • 가격: 시장 = 20,000~40,000원/1kg / 횟집 = 50,000~120,000원/1인

🐟 방어회 (Bang-eo) — 겨울 #1

  • 시그니처: 겨울 정통 #1·자갈치·노량진 #1·지방 풍부
  • 재료: 방어 (yellowtail) 활어 + 초장·쌈채소
  • 외국인 친화도: ★★★★★ (겨울 정통)
  • 추천 시장·횟집:
  • 자갈치시장 (부산) — #1 정통
  • 노량진수산시장 — 정통
  • 삼척·구룡포 — 동해 정통
  • 계절: 12~2월 (한겨울 #1)
  • 가격: 시장 = 30,000~60,000원/1kg / 횟집 = 60,000~150,000원/1인

🍣 참치 뱃살 (Chamchi-Otoro) — 지방 #1

  • 시그니처: 지방 #1·toro 등급·MZ 인스타·6월 매니아
  • 재료: 참치 (tuna) 뱃살 toro·붉은살 akami + 와사비·간장
  • 외국인 친화도: ★★★★★ (글로벌 toro·인스타 #1)
  • 추천 매장:
  • 참치 전문점 (강남·압구정·홍대) — 정통
  • 참치 무한리필 — 가성비
  • 노량진수산시장 — 새벽 도매
  • 계절: 6월 정통·사계절 (냉동)
  • 가격: 참치 정통 = 80,000~200,000원/1인 / 무한리필 = 30,000~50,000원

🟠 연어회 (Yeon-eo) — 글로벌 친화

  • 시그니처: 글로벌 친화·MZ 인스타·사계절
  • 재료: 연어 (salmon·노르웨이·칠레 수입) + 와사비·간장
  • 외국인 친화도: ★★★★ (글로벌 #1)
  • 추천 매장:
  • 연어 무한리필 (홍대·강남·신촌) — 가성비 #1
  • 연어 전문점 — 정통
  • 계절: 사계절 (숙성)
  • 가격: 연어 무한리필 = 25,000~40,000원/1인 / 연어 정통 = 40,000~80,000원

🐡 도미회 (Do-mi) — 한정식 정통

  • 시그니처: 한정식 코스·정통·1월·12월
  • 재료: 도미 (sea bream) 활어 + 초장·쌈채소
  • 외국인 친화도: ★★★★ (정통·한정식)
  • 추천 매장: 한정식 코스 ([#837](#837))·강남 횟집·자갈치시장
  • 계절: 봄 (4월)·겨울 (1월·12월)
  • 가격: 50,000~120,000원/1인

🐠 전어회 (Jeon-eo) — 가을 정통

  • 시그니처: "가을 전어 굽는 냄새 며느리도 돌아온다"·9~10월 정통
  • 재료: 전어 (gizzard shad) 활어 + 초장·쌈채소
  • 외국인 친화도: ★★★★ (가을 정통)
  • 추천 시장·횟집:
  • 강화 전어 마을 — 가을 정통 #1
  • 소래포구 (인천) — 가을 매니아
  • 자갈치시장 — 정통
  • 계절: 9~10월 (가을 #1)
  • 가격: 시장 = 15,000~30,000원/1kg / 횟집 = 30,000~60,000원/1인

🍽 한국식 회 한 상 (Korean Hwoe Set)

한국식 회 한 상 풀세트

1. 회 (Hoe) — 메인 (광어·방어·도미 등)

2. 초장 (Chojang) — 고추장 + 식초 (한국 정통)

3. 와사비 (Wasabi) — 일본식 옵션

4. 쌈채소 — 상추·깻잎·배추 (쌈 싸 먹기)

5. 마늘·고추·된장 — 부재료

6. 매운탕 (Mae-untang) — 회 마지막 + 매콤 생선탕

7. 소주·맥주·소맥 — 술 페어 (선택)

8. 공기밥 — 마지막 마무리

한정식 회 코스 (정통)

  • 한정식 6단계 코스 ([#837](#837)) 1~2단계에 회 포함
  • 신라호텔 라연 (미슐랭 3스타)·삼청각·인사동 한정식

⚠ 외국인 자주 실수 5가지

1. "한국 회 = 일본 sushi": 한국 회 = 활어 정통·초장·쌈 / 일본 sushi = 숙성·간장·밥. 다른 음식.

2. "활어 = 신선도만 좋음": 활어 = 쫄깃함·즉살 정통 / 숙성 = 감칠맛.

3. "방어 = 사계절": 방어 = 겨울 12~2월 #1 (다른 계절 = 양식/냉동).

4. "전어 = 일반 회": 전어 = 가을 9~10월 #1 ("가을 전어" 속담).

5. "회만 먹고 끝": 한국식 = 회 + 매운탕 코스 (마지막 매콤 생선탕).

⚙ FAQ 8개

1. 외국인 입문 1순위: 광어 + 연어 (글로벌) → 방어 (겨울) → 참치 (지방).

2. 인스타·vlog: 자갈치 방어·노량진 새벽·참치 toro 인스타.

3. MZ 트렌드: 연어 무한리필·참치 toro·MZ 횟집.

4. 겨울 매니아: 방어 (#1) + 광어 + 도미.

5. 가을 매니아: 전어 (#1) + 강화·소래포구.

6. 알레르기: 생선·갑각류 교차오염 사전 고지.

7. 결제·팁: 시장 = 현금·카드 혼용 / 횟집 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

회 = 생선 익히지 않음·식중독 주의. 임신부 = 회 X (CDC 권고). 어린이 = 한정 (5세 이상 익힌 것). 알레르기 (생선·갑각류·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 = 어류 = 할랄 OK (저자별 의견 차이 있음·매장 확인) / 코셔 = 비늘+지느러미 = 광어·방어·도미·연어·참치·전어 모두 OK.
  • 채식·비건: 6종 모두 비채식 / 채식 = 비빔밥·사찰음식.
  • 글루텐 free: 회 자체 OK / 간장 = 글루텐 함유 (Tamari 대체).
