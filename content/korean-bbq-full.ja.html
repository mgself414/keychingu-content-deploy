🎯 なぜ韓国式BBQ完全ガイドなのか

韓国式BBQは、外国人にとって韓国料理体験の不動の1位です (外国人VlogやK-ドラマの定番)。韓牛 (牛肉・最高級グレード)・サムギョプサル・ヤンニョムカルビ (味付けカルビ)・羊串・ホルモンBBQが韓国BBQの5つの柱です。#130 ソウル焼肉店・#62 韓国鶏料理に加え、韓国BBQのフルセットを徹底解説します。

⚠ 外国人がよく間違える3つのこと

1. 「韓国BBQ = サムギョプサルだけ」: 韓国BBQは5つの柱 (韓牛・サムギョプサル・ヤンニョムカルビ・羊串・ホルモン) — 韓牛1++グレード、サムギョプサル、LAカルビ (LA갈비)、マクチャン (막창、牛や豚の直腸)、コプチャン (곱창、牛や豚の小腸)、羊串のフルセットに挑戦してみましょう。

2. 「韓牛の価格が高すぎる」: 韓牛1++グレード (₩60,000 (~6,600 JPY / ~$44 / ~320 RMB)〜120,000 (~13,200 JPY / ~$88 / ~640 RMB)/人) + 韓牛ランチコース (₩30,000 (~3,300 JPY / ~$22 / ~160 RMB)〜とお手頃)

3. 「羊串 = 韓国料理」: 羊串は中国新疆ウイグル発祥 + 韓国アレンジ (1990年代に華僑 (中国系住民)・東南アジア居住者の増加により)。九老 (クロ)・大林 (テリム) の華僑通りが一番です。

⚙ よくある質問6選

1. 韓国BBQのマナー: 年長者優先 + 両手でお酒を注ぐ (目上の人へ敬意を示す) + 靴を脱ぐ (一部の伝統的な店舗)

2. 韓牛の等級システム: 1++ → 1+ → 1 → 2 → 3 (1++が最高)

3. 外国人向けフレンドリーな店舗: ダラム (다람)・ハナムテジチプ (하남돼지집)・88カルビ (88갈비)・コンデコギクンヌンノム (건대 고기굽는놈)

4. 食べ放題 vs 伝統店: 食べ放題 (コスパ重視) vs 伝統の老舗 (노포、30年以上の伝統店) (クオリティ重視)

5. 羊串はどこで食べられる？: 九老 (クロ)・大林 (テリム) の華僑通り (#180) が一番です。

6. 馬場畜産物市場 (マジャンチュクサンムルシジャン) での価格交渉: OKです。その場で刺身や焼き肉を卸売価格で30〜50%安く購入できます。
