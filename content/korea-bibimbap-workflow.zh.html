韩式拌饭点餐/拌饭/配对工作流程 — 从全州经典到石锅焦饭

> 副标题：外国游客5步+搓揉礼仪+加减调料+英语口语

第03期·#880·2026-06-09

🎯 为什么选择韩国拌饭工作流程指南

即使你知道[#879 5种拌饭矩阵](#879) — 顺序、拌饭和配对是分开的。韩国拌饭是 (a) 全州韩屋村正宗 (5种颜色，宫殿，联合国教科文组织) (b) 石锅拌饭 (热、脆) (c) 自制拌饭 (MZ DIY) (d) 野菜、寺庙食品 (素食、清真) (e) 海鲜拌饭 (生鱼片串交叉)。老外（1）不懂搅拌的方式=搅拌均匀（2）不懂加减辣椒酱和香油的方式（3）石锅烧饭=不懂传统的方式（4）自己=不懂DIY的方式。本教程为5步+拓印+英语口语。

★ 5 步工作流程概览

步骤 行动 时间 外国人的要点
1️⃣ 频道选择 全州/石索/自助/野菜/海鲜 立即 正宗、脆皮、MZ、素食、海鲜
2️⃣ 菜单点菜 1份/自选 1~5分钟 全州 = 正宗#1·石索 = 全球#1
3️⃣ 接收·设置 5色蔬菜+鸡蛋+红辣椒酱和香油 5-10 分钟 Dolsot = 非常热
4️⃣擦·吃 添加或减去红辣椒酱和芝麻油+混合+食用 30~60分钟 混合方式均匀
5️⃣ 付款 卡 OK / 提示 X 1~3分钟 自助=预付

> 总时间：全州 = 1~1.5h / 石锅 = 30~50 分钟 / 自助 = 1~1.5h / 野菜 = 1.5~2h / 海鲜 = 1~1.5h

🍚 按渠道划分的工作流程

A 型 — 全州韩屋村正宗

  • 签名：5 种颜色，皇家宫廷，联合国教科文组织非物质遗产
  • 时间：11:00~22:00
  • 价格: 12,000~25,000韩元 (全州) / 8,000~20,000韩元 (首尔)
  • 菜单：全州拌饭、宫廷菜、牛肉（可选）
  • 外国人友好度：★★★★★（联合国教科文组织正品）

B型——石锅拌饭

  • 招牌：热脆皮
  • 时间：11:00~22:00
  • 价格：10,000~22,000韩元
  • 菜单：Dolso、脆皮 Nurungji、素食还可以
  • 外国人友好度：★★★★★（全球#1）
  • 注意：非常热·使用板架

C型——自助拌饭（DIY）

  • 签名：MZ DIY、Instagram、材料选择
  • 时间：11:00~22:00
  • 价格：8,000~18,000韩元（无限量自行充值）
  • 菜单：自由选择 8 至 12 种食材
  • 外国人友好度：★★★★ (MZ #1)

D 型 — 野菜和寺庙食品

  • 签名：寺庙食物群·素食#1·春天野菜
  • 时间：午餐和晚餐（预订）
  • 价格: 野生采摘 10,000~25,000 韩元 / 寺庙套餐 25,000~80,000 韩元
  • 菜单：春季野菜+大酱调料
  • 外国人友善度：★★★★（素食#1）

E型——海鲜拌饭

  • 招牌：生鱼片、海鲜十字、扎嘎其、统营
  • 时间：11:30~22:00
  • 价格: 15,000~40,000韩元/人
  • 菜单：5种颜色+生鱼、海鲜（比目鱼、鲍鱼、虾）
  • 外国人友好度：★★★（海鲜狂热）

🥄 混合和调味方式矩阵

摩擦礼仪（必填）

1. 加减辣椒酱和香油：辣还是清淡，自己掌握

2. 搅拌均匀：全套5色+鸡蛋+红辣椒酱+香油

3. 勺子：混合后，将所有 5 种颜色添加到一把勺子中。

4. Dolsot：搅拌前将烧焦的纸充分除去（脆）

5. 自我：蹭=自己的责任

添加或减少红辣椒酱

  • 大量红辣椒酱 = 辣/正宗（韩式）
  • 少点红辣椒酱=简单，老外介绍
  • Gochujang X = 素食/清真/外国人（酱油调味备用）

添加或减少芝麻油

  • 芝麻油 = 韩国正宗/辣
  • 少点芝麻油 = 负担 ↓

  • “请少点 gochujang（红辣椒酱）” =“请少点 gochujang（红辣椒酱）”

⚠ 外国人常犯的7个错误

1. “拌饭=不搅拌”：拌饭=搅拌均匀的方式（不搅拌则为X）。

2. “Gochujang = 添加所有内容”：Gochujang = 自己添加或减去（调整辣度与清淡）。

3. “石锅=普通碗”：石锅=很热·小心烫伤。

4. “脆皮Nurungji = 扔掉”：Nurungji = 正宗狂热#1（小心撕下食用）。

5. “自我=性价比”：自我=MZ趋势#1·全套素材。

6. **“野菜=素食流行

7. 《海鲜拌饭=生鱼片》：海鲜拌饭=5色+海鲜十字·其他食物。

⚙ 8 个常见问题解答

1. 第一个石锅拌饭=哪个频道：石板（#1全球）→全州（东正教）。

2. Insta·vlog：全州韩屋村，热石锅，自助DIY。

3. MZ趋势：自我(#1)·多尔索特。

4. 素食·清真：野生蔬菜（#1）+寺庙食品+全州（不包括牛肉）。

5. 使用石锅注意：非常热。小心儿童。

6. 过敏·怀孕：参见[#879免责声明](#879)。

7. 付款/小费：卡OK/小费X。

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

拌饭=普通食物。孕妇和儿童=可以（小心石锅烫伤）。过敏（鸡蛋、海鲜、大蒜、酱油、麸质、牛肉）需提前通知。小心石锅烧伤。如果怀疑食物中毒☎ 1339。本指南是一般信息，并非医疗建议。

饮食限制后备：

  • 清真/犹太洁食：野菜 = #1 / 全州/石竹 = 不包括牛肉 / 海鲜 = 甲壳类动物
  • 素食·纯素：野菜=#1/鸡蛋可选。
  • 无麸质：酱油·辣椒酱 = 麸质（取代酱油）。
