🎯 なぜ韓国肉のおかずマトリックスなのか

外国人韓国肉おかずペインポイント＝「BBQだけ知っている」。韓国肉おかず類 ＊＊＊韓定食主義#1 + グローバル認知焼肉・雑菜K-foodトレンド**。同じ「Korean meat side dish」でもカルビ蒸し（韓食式メイン・記念日）・雑菜（当面＋野菜・本物#1）・育て炒め（スパイシーな豚・MZトレンド）・焼肉（グローバルK-food）・長蔵（しょうゆ）正統）それぞれ異なるレシピ・ペアリング。外国人は(a)カルビチム=韓国vs日本差分知(b)雑債=麺類で誤認(c)除育vs焼肉差分知らない(d)長茂林=日本つくだニ様知らない。本ガイドは6種マトリックス+限定式主義マニア+外国人入門優先順位。

🍖 6種 deep dive

🍖 カルビチム (Galbi-jjim) — 限定式 #1

  • シグネチャー: 限定式メイン#1・記念日・祝祭正統
  • 材料: 牛カルビ+醤油+梨+ニンニク+玉ねぎ+しいたけ+ナツメ・松
  • 特徴: 5～8h煮込み・甘み・柔らかさ・骨丸め
  • 外国人親和性: ★★★★★ (限定式本物)
  • おすすめ店舗: 限定食集・ホテル韓食堂・全州限定食・宮中料理店
  • 季節: 年中（祝日#1）
  • 差vs日本カルビ: 韓国カルビ蒸し = 煮込み本格 /日本カルビ = 焼きBBQ

🍜 雑債 (Japchae) — 外国人入門 #1

  • シグネチャー：本物の韓国料理#1・グローバル認知度・韓国料理のおかず
  • 材料: 当面(さつまいも澱粉)+ほうれん草+ニンジン+玉ねぎ+牛肉+醤油+ごま油
  • 特徴: 甘い・塩辛・苦笑・麺＋野菜の組み合わせ
  • 外国人親和性: ★★★★★ (グローバル・麺類認知)
  • 種類:
  • 牛の雑菜（本物）
  • シーフードチャット(variant)
  • 宮中雑菜（醤油ベース本格）
  • MZビーガン雑菜（肉X・菜食OK）
  • おすすめ店: 限定食集・家庭式・MZカフェ・お弁当
  • 季節: 年中 (名節#1)

🌶 生育炒め (Jeyuk-bokkeum) — MZ #1

  • シグネチャー: スパイシーな豚・会社員ランチ#1・MZトレンド
  • 材料: 豚（牧草・前足）＋コチュジャン＋コチョウ粉＋ニンニク・玉ねぎ
  • 特徴: マコム・甘味・ご飯フェア #1
  • 外国人親和性: ★★★★★ (MZ・スパイシー入門)
  • おすすめ店: 家庭食・チェーン（除育専門）・MZカフェ
  • 種類:
  • 本物の製肉炒め
  • 醤油除肉(あまり辛さ)
  • 唐辛子除肉（非常にスパイシー）
  • 季節: 年中（ランチ#1）

🥩 ブルゴギ (Bulgogi) — グローバル #1

  • シグネチャー: グローバルK-food認知度 #1 + 外国人入門本格
  • 材料：牛肉（薄くスライス）+醤油+梨+ニンニク・生姜・玉ねぎ+ごま油
  • 特徴: 甘・塩辛・年さ・BBQ認知
  • 外国人親和性: ★★★★★ (グローバル・甘い入門)
  • 種類:
  • ソウル焼肉（本物・スープあり・当面追加）
  • 光陽焼肉（全南・焼き型・醤油ベース）
  • オンヤン焼肉（蔚山・みじん切り肉・辛味）
  • 宮中焼肉（醤油本物）
  • 季節：年中（入門#1）

🟫 ジャンジョリム (Jangjorim)

  • シグネチャー：醤油煮込み本格・お弁当・おかず#1
  • 材料：牛肉（ホンドゥケゴルサル）・卵・プレッツェル+醤油+ニンニク・玉ねぎ
  • 特徴: 塩辛・甘・長く保管可能・お弁当本格
  • 外国人親和性: ★★★★（日本のつくだに認知）
  • おすすめ店: 家庭食・弁当店・限定食のおかず
  • チャイvs日本ツクダニ: 韓国長煮林 = 牛肉・卵中心・ちゃんちゃん / 日本ツクダニ = シーフード・甘い。他の食べ物。

＃＃⚠外国人の頻繁な誤り5つ

1. "韓国リブ = BBQ リブ": リブ蒸し = 煮込み・甘さ・柔らかさ。 BBQリブ = 焼き・マコム・チョッギット。他のメニュー。

2. 「雑菜=麺類」: 雑菜=当面+野菜+肉フルセット。麺類単品X。

3. 「除肉=焼肉」: 除肉=辛い豚/焼肉=甘い牛。他のメニュー。

4. 「焼肉=本物BBQ」: 焼肉=味付け＋スープ・当面本物。 BBQ =焼き本物。

5. "ハーブ=一種類":ハーブ=6+種(シラギ・シダ・もやしなど) それぞれ異なる食感・味。

⚙ よくある質問8件

1. 外国人入門1順位: 焼肉(グローバル)+雑菜(正統)→カルビチム(限定式)段階。

2. インスタ・vlog: カルビ蒸し限定食・雑菜MZ vlog・育て炒めマニア。

3. MZトレンド：除肉炒め・トリュフ雑菜・宮中焼肉。

4. グローバルトレンド: 焼肉K-food #1・雑債 MZ vlogグローバル。

5. ベジタリアン・ハラール・コーシャ: ハーブ炒め = ベジタリアン #1 (査察料理)・MZビーガン雑菜一部 / カルビ蒸し・焼肉・製肉 = 非菜食。

6. アレルギー: 豆(醤油)・シーフード(シーフード雑菜)・ナッツ(松)の事前告知。

7. 決済・チップ：カードOK多/家庭式=コスパ/限定式=サービス料10%(ホテル)/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

肉のおかず＝一般的な韓国料理。妊婦＝カルビ蒸し・焼肉十分に煮てOK。子ども＝辛い除育加減・肋骨（骨）こどもの注意。アレルギー（大豆・シーフード・ナッツ）の事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：一般＝ビハラル（豚・一般調味料）。 →ハーブ炒め・査察料理ベジタリアンOK / 梨泰院ハラール韓国料理店の一部。
  • ベジタリアン・ビーガン：ハーブ炒め・MZビーガン雑菜(肉X) = OK / 査察食品限定式 = #1。
  • グルテンフリー：醤油（小麦）多。事前店舗確認ORグルテンフリー醤油。
