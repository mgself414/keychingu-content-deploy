한국 덮밥 주문·페어 워크플로우 — 한솥부터 명란 MZ까지

> 부제: 외국인 관광객용 5-step + 4채널 + 점심 매니아 + 영어 발화

ISSUE 03 · #892 · 2026-06-09

🎯 왜 덮밥 워크플로우 가이드인가

[#891 덮밥 6종 매트릭스](#891) 알아도 — 주문·페어는 별개. 한국 덮밥은 (a) 체인 도시락 (한솥·본도시락 가성비) (b) MZ 한식당 (명란·연어 인스타) (c) 가정식 백반 (제육·고등어 ([#854](#854))) (d) 한정식 cross (소고기). 외국인은 (1) 한솥·본도시락 = 가성비 #1 모름 (2) 명란덮밥 = MZ 인스타 모름 (3) 점심 = 덮밥 cluster #1 모름. 본 가이드는 5-step + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 체인 도시락 / MZ 한식당 / 가정식 / 한정식 즉시 가성비·MZ·정통·럭셔리
2️⃣ 메뉴 주문 6종 + 사이드 1~5분 점심 cluster #1
3️⃣ 받기·세팅 덮밥 + 국·반찬·계란 5~15분 안 비비기 (밥 위 메인)
4️⃣ 먹기·페어 덮밥 + 국 + 김치 15~30분 한국 정통
5️⃣ 결제 카드 OK / 도시락 = 키오스크 / 팁 X 1~3분 키오스크 영문 OK

> 총 소요 시간: 체인 = 15~30분 / MZ = 30~60분 / 가정식 = 30~60분 / 한정식 = 1~2h

🍚 채널별 워크플로우

Type A — 체인 도시락 (한솥·본도시락)

  • 시그니처: 가성비 #1·즉시·키오스크
  • 시간: 10:00~22:00
  • 가격: 6,000~12,000원
  • 메뉴: 제육·고등어·임연수·소불고기 도시락
  • 외국인 친화도: ★★★★★ (키오스크 영문)

Type B — MZ 한식당 (명란·연어)

  • 시그니처: MZ 트렌드·인스타 #1
  • 시간: 11:00~22:00
  • 가격: 12,000~25,000원
  • 메뉴: 명란덮밥·연어덮밥·MZ 변형
  • 추천 매장: 홍대·강남·이태원·성수
  • 외국인 친화도: ★★★★★ (MZ #1)

Type C — 가정식 백반 ([#854](#854))

  • 시그니처: 홈스타일·가성비
  • 시간: 11:00~22:00
  • 가격: 8,000~15,000원
  • 메뉴: 제육·고등어·임연수 + 국·반찬
  • 외국인 친화도: ★★★★ (가성비)

Type D — 한정식·럭셔리

  • 시그니처: 소고기덮밥 정통
  • 시간: 11:30~22:00
  • 가격: 15,000~35,000원
  • 메뉴: 소고기·궁중 정통
  • 외국인 친화도: ★★★★

🌶 외국인 영어 발화 샘플

  • "제육덮밥 1인" = "1 Jeyuk-deopbap (spicy pork rice bowl)"
  • "명란덮밥" = "Myeongran-deopbap (pollock roe rice bowl - MZ #1)"
  • "안 매콤하게" = "Less spicy, please"
  • "키오스크 영문" = "Kiosk has English option"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "비빔밥 = 덮밥": 비빔밥 = 비비기 / 덮밥 = 안 비빔.

2. "제육 = 일반": 제육 = 가성비 #1.

3. "명란 = 단가": 명란 = MZ 인스타 #1.

4. "한솥·본도시락 = 패스트": 한솥 = 한식 cluster 정통.

5. "점심 = 비빔밥만": 점심 = 덮밥 cluster #1.

6. "키오스크 = 한국어": 키오스크 = 영문 OK.

7. "안 비빔": 덮밥 = 밥 위에 메인 그대로.

⚙ FAQ 8개

1. 첫 덮밥 = 어떤 채널: 체인 한솥·본도시락 (가성비 #1) → MZ (#1 트렌드).

2. 인스타·vlog: 명란 (#1).

3. MZ 트렌드: 명란·연어.

4. 가성비: 한솥·본도시락 (#1).

5. 럭셔리: 한정식 소고기.

6. 알레르기·임신: [#891 disclaimer](#891) 참조.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

덮밥 = 일반 음식. 임신부·어린이 = OK (명란 짠맛 주의). 알레르기 (어란·해산물·계란·간장) 사전 고지. 식중독 의심 시 ☎ 1339.

식이 제한 fallback: 할랄·코셔 = 어류·해산물 OK·돼지 X / 채식 = 비채식 / 글루텐 free = Tamari.
