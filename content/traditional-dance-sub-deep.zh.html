📍 首尔 — 国立贞洞剧场

国立贞洞剧场 (Gungnip Jeongdong Geukjang / 국립정동극장)(中区 (Jeongdong-gil 43 / 정동길 43)，☎ 02-751-1500)取承接韩国首座近代式剧场圆觉社 (Wongaksa / 원각사) 之意，1995年以“贞洞剧场 (Jeongdong Geukjang / 정동극장)”之名开幕。自2000年起全年举办传统常设演出，之后改名为“国立贞洞剧场 (Gungnip Jeongdong Geukjang / 국립정동극장)”。除多种类型的演出外，还承担发掘并培育创作初期作品的二次制作剧场角色。

  • 开放时间:09:00~18:00。因演出而异。休息日:每周一。因演出而异。
  • 费用:因演出而异。

📍 假面舞 — 河回假面戏传授馆·安东国际假面舞节·杨州别山台游戏·殷栗假面舞

假面戏传授馆 (Talnori Jeonsugwan / 탈놀이전수관)(安东市 (Pungcheon-myeon Hahoejongga-gil 3-15 / 풍천면 하회종가길 3-15)，☎ 河回别神祭假面戏保存会 (Hahoe Byeolsingut Talnori Bojonhoe / 하회별신굿탈놀이보존회) 054-854-3664)是传承在河回村 (Hahoe Maeul / 하회마을) 延续800余年的河回别神祭假面戏 (Hahoe Byeolsingut Talnori / 하회별신굿탈놀이) 的地方。河回别神祭假面戏是自12世纪中叶起在河回村流传的国家非物质遗产假面剧，戴河回假面 (Hahoetal / 하회탈) 的角色与农乐 (Pungmul / 풍물)、小锣、舞蹈交融，讽刺当时的社会。由非物质遗产保持者等传承人演出。

  • 常设演出:3~12月周二至周日 14:00~15:00，1~2月周六至周日 14:00~15:00。可能因演出而异。休息日:3~12月每周一，1~2月每周一至周五。
  • 费用:常设演出免费观看。体验项目为1晚2天体验营50,000韩元，制作假面 (Tal / 탈) 10,000韩元，跟学假面舞 (Talchum / 탈춤) 10,000韩元。

2026安东国际假面舞节 (2026 Andong Gukje Talchum Peseutibeol / 2026 안동국제탈춤페스티벌)(安东市 (Yuksa-ro 239 / 육사로 239)，☎ 054-840-3400)是已列入联合国教科文组织人类非物质文化遗产的韩国假面舞与世界各国假面舞一起欣赏的庆典。2026年于9月24日~10月4日在中央线 1942 安东站 (Jungangseon 1942 Andongyeok / 중앙선 1942 안동역)、假面舞公园 (Talchum Gongwon / 탈춤공원)、老城区 (Wondosim / 원도심) 一带举办，时间为10:00~22:00。主办方为韩国精神文化财团 (Hanguk Jeongsin Munhwa Jaedan / 한국정신문화재단)。

  • 费用:免费。部分体验项目和假面舞演出场 (Talchum Gongyeonjang / 탈춤공연장) 的演出收费。
  • 活动:举办了国内外假面舞演出、马当剧 (Madanggeuk / 마당극)·创作剧、世界假面戏竞演大会 (Segye Talnori Gyeongyeon Daehoe / 세계탈놀이경연대회)、大同乱场 (Daedong Nanjang / 대동난장)、街头游行、制作假面·跟学假面舞体验等。

杨州别山台游戏传授教育馆 (Yangju Byeolsandae Nori Jeonsu Gyoyukgwan / 양주별산대놀이전수교육관)(杨州市 (Buheung-ro 1399beon-gil 47 / 부흥로1399번길 47)，☎ 031-840-9986)是传承杨州别山台游戏 (Yangju Byeolsandae Nori / 양주별산대놀이) 的地方。杨州别山台游戏是首尔·京畿地区山台都监剧 (Sandae Dogamgeuk / 산대도감극) 的一个分支，约300年前起在杨州扎根的假面舞。由8场8景构成，以舞蹈、哑剧、诙谐和祝福之词讽刺两班 (Yangban / 양반) 社会的矛盾与平民的生活。登场人物有破戒僧、两班、巫堂 (Mudang / 무당)、仆人等。1964年被指定为国家非物质遗产，2022年被列入联合国教科文组织人类非物质文化遗产代表作名录。

  • 开放时间:09:00~20:30。休息日:法定节假日。
  • 费用:免费。观看时间:1小时。停车:免费。

殷栗假面舞传授馆 (Eunyul Talchum Jeonsugwan / 은율탈춤전수관)(仁川弥邹忽区 (Subongan-gil 78 / 수봉안길 78)，☎ 0507-1340-7823)是为保存和宣传殷栗假面舞 (Eunyul Talchum / 은율탈춤) 而建的传授馆。殷栗假面舞是源自黄海道 (Hwanghae-do / 황해도) 殷栗地区的假面舞，1978年2月被指定为国家非物质遗产。6·25战争时，黄海道的假面舞艺人南下，在韩国南部扎下根来，之后将仁川定为传承地。1983年在弥邹忽区 (Michuhol-gu / 미추홀구) 崇义洞 (Sungui-dong / 숭의동) 的Subong公园 (Subong Gongwon / 수봉공원) 内设立了传授教育场。户外演出场举办邀请殷栗假面舞和其他地方假面舞传承人的免费演出。

  • 开放时间:09:00~18:00。休息日:每周一。
  • 费用:免费。

📍 强羌水越来 — 海南强羌水越来传授馆

强羌水越来传授馆 (Ganggangsullae Jeonsugwan / 강강술래 전수관)(海南郡 (Munnae-myeon Gwangwang Leojeo-ro 12 / 문내면 관광레저로 12)，☎ 061-532-8810)是位于海南右水营观光地 (Usuyeong Gwangwangji / 우수영관광지) 内的体验宣传馆。国家非物质遗产强羌水越来是在中秋 (Chuseok / 추석) 前后月明之夜，女性们聚在一起唱歌跳舞的集体民俗游戏，以全罗南道的沿海村庄为中心流传。在传授馆可以了解强羌水越来的由来和传承过程，并体验学习强羌水越来和妇女农谣 (Bunyeo Nongyo / 부녀농요)。体验须提前向社团法人海南右水营强羌水越来振兴保存会 (Haenam Usuyeong Ganggangsullae Jinheung Bojonhoe / 해남우수영강강술래진흥보존회) 预约。传授馆一带有强羌水越来纪念碑。

  • 开放时间·休息日·费用:无登记值。
  • 停车:免费。

⚠ 行前须知 3 点

  1. 河回假面戏常设演出在1~2月只在周末举行 — 3~12月为周二至周日，1~2月为周六至周日 14:00~15:00。
  2. 强羌水越来体验须提前预约 — 向海南右水营强羌水越来振兴保存会 (Haenam Usuyeong Ganggangsullae Jinheung Bojonhoe / 해남우수영강강술래진흥보존회) 预约。
  3. 2026安东国际假面舞节已经结束 — 于9月24日~10月4日举办。

⚙ FAQ 2

Q. 在哪里可以免费观看假面舞演出?

A. 按观光公社登记信息，河回假面戏传授馆 (Hahoe Talnori Jeonsugwan / 하회 탈놀이전수관) 的常设演出(3~12月周二至周日 14:00，1~2月周六·周日 14:00)免费。殷栗假面舞传授馆 (Eunyul Talchum Jeonsugwan / 은율탈춤전수관) 在户外演出场举办免费演出。

Q. 在哪里可以亲自学习假面舞?

A. 在河回假面戏传授馆 (Hahoe Talnori Jeonsugwan / 하회 탈놀이전수관) 可以体验跟学假面舞(10,000韩元)、制作假面(10,000韩元)、1晚2天体验营(50,000韩元)。
