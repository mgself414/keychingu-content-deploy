盘索里指南——外国人2026年秋冬真正能看到的演出与五大曲目（官方日程）

副标题：国立国乐院周六名品 每周六15:00(~12/26) · 国立剧场完唱盘索里 11/14《沈清歌》300分钟 20,000韩元，唱剧《俄狄浦斯》11/26~12/5，送年盘索里 12/26 · 首尔敦化门国乐堂免费完唱 11/11《沈清歌》360分钟·11/21《沈清歌》260分钟 · 预订·付款·接驳车方法 — 以2026-10-29各官方网站为准。盘索里于2003年被UNESCO宣布、2008年列入代表作名录

🎯 本指南使用方法

当鼓槌“咚”地敲在鼓身上，观众席某处飞来一声助兴吆喝“好哇” (Eolssigu / 얼씨구)，歌者只凭一把扇子，就能画出大海与宫殿。盘索里既不是歌剧也不是音乐剧，是由一位歌者和一面鼓把一个故事从头唱到尾的叙事音乐。第一次看的话，可以先在周六下午去国立国乐院包含盘索里的国乐综合演出周六名品 (Toyo Myeongpum / 토요명품)(含盘索里，80分钟，20,000~30,000韩元)尝个鲜，看入迷了再去国立剧场的完唱盘索里 (Wanchang Pansori / 완창판소리)(11/14《沈清歌》，20,000韩元)或首尔敦化门国乐堂的免费完唱(11/11·11/21《沈清歌》)把一整部曲目听完。11/26~12/5，国立唱剧团 (Gungnip Changgeukdan / 국립창극단) 的《俄狄浦斯》将以唱剧形式登场。座位是一个一个单独预订的，一个人去也不会尴尬；演出前在国立国乐院免费的国乐博物馆 (Gugak Bangmulgwan / 국악박물관)，或敦化门国乐堂对面的昌德宫敦化门前拍张照再进场，一天就串成了一个完整的场景。

盘索里 (Pansori / 판소리) 是由一名歌者搭配一名鼓手 (Gosu / 고수)（打鼓者），连续演唱数小时的叙事音乐。把一部曲目从头唱到尾的完唱 (Wanchang / 완창)，视歌者和曲目而定需要3~8小时（这次确认的演出为170分钟和300分钟）；改编成舞台剧的唱剧 (Changgeuk / 창극) 通常约2小时。外国人想“看盘索里”，现实中有三种选择——① 国立国乐院 (Gungnip Gugagwon / 국립국악원) 的周六名品 (Toyo Myeongpum / 토요명품)（每周六举行，是国乐综合演出，并非只有盘索里）；② 国立剧场 (Gungnip Geukjang / 국립극장) 的完唱盘索里和唱剧；③ 首尔敦化门国乐堂 (Seoul Donhwamun Gugakdang / 서울돈화문국악당) 与首尔南山国乐堂 (Seoul Namsan Gugakdang / 서울남산국악당) 的单场演出。下文的日程·票价·地址·预订方法，只写了2026-10-29在各官方网站和官方售票处 (NOL票务) 读到的数值，所有官方页面都没有标注英文字幕，因此未核实。

🏛 4处演出场地

国立国乐院——周六名品

  • 瑞草区南部循环路2364。乘3号线南部客运站站 (Nambu Terminal / 남부터미널역) 步行前往（出口编号官方未核实）。
  • 周六名品：2026-01-03~12-26每周六15:00~16:20，牛眠堂。A席30,000·B席20,000韩元。有些场次会包含一段盘索里，但并不是盘索里单独演出——请在官方页面查看各场次的节目。
  • 预订(官方)：线上登录国立国乐院官网并完成实名认证后，选择日期·座位；电话02-580-3300不能刷卡，只能转账；现场请到风流舍廊房 (Pungnyu Sarangbang / 풍류사랑방) 客户服务处，周一至周六09:00~18:00(周日·公休日休息)。预订截止为演出前一天18:00。7岁以上可观看。
  • 国乐博物馆(免费)：位于国立国乐院内，10:00~18:00(17:30前入场)，周一·1/1闭馆，个人无需预约即可入场(官方)。周六名品之前先来逛一圈，把鼓和伽倻琴看熟，舞台会变得不一样。

国立剧场——完唱盘索里·唱剧

  • 中区奖忠坛路59。从3号线东大入口站 (Dongdaeipgu / 동대입구역) 6号出口的南山循环巴士 (Namsan Sunhwan Beoseu / 남산순환버스) 站点前乘接驳车(演出前1小时~20分钟，每10分钟一班)，或步行10~15分钟。演出结束后，接驳车从日升剧场前开往东大入口站1号出口和东大门历史文化公园站 (Dongdaemun Yeoksa Munhwa Gongwon / 동대문역사문화공원역) (官方英文交通指引)。
  • 完唱盘索里：由一位名唱把一部曲目从头唱到尾。11/14(周六)15:00 徐珍姬《沈清歌 (Simcheongga / 심청가)》(300分钟，含20分钟休息)，全席20,000韩元，小学生以上，月升剧场(官方·NOL票务)。10/24《兴甫歌 (Heungboga / 흥보가)》(170分钟)已经结束，12月没有场次。
  • 唱剧：国立唱剧团的舞台剧。11/26~12/5《俄狄浦斯》周二至周五19:30·周六·周日15:00，120分钟，R席50,000·S席35,000·A席20,000韩元，初中生以上(NOL票务)。12/26(周六)15:00送年盘索里《笑谈》90分钟，全席30,000韩元。
  • 预订·付款(官方英文指南)：在英文网站注册会员后可在线·手机预订，电话+82-2-2280-4114(工作日09:00~18:00·周末10:00~18:00，12:00~13:00午休)。付款方式为刷卡·转账·KakaoPay·PAYCO。在线预订于演出前一天17:00截止，前一天18:00之后不能取消·更改。海外发行的银行卡是否可用，未标注。取票请在演出前30分钟之前到日升剧场1F客户中心。预订处(国立剧场·NOL票务)不同，开放的座位也不同。

🗣 语言·字幕

  • 没有任何一家演出场地在官方页面上写明是否提供英文字幕（未核实）。唱剧常使用字幕屏幕，但请逐场在预订页面确认。
  • 盘索里即使听不懂唱词(歌词)，也能凭歌者的表情和鼓手的助兴吆喝跟上——先从笑点多的《兴甫歌》开始。
  • 一个人·付款：座位是一个一个单独预订的，一个人看也没有限制。国立剧场可刷卡·转账·KakaoPay·PAYCO，国立国乐院电话预订只能转账(两者均为官方)。海外发行的银行卡，两处都没有标注——如果不行，请到现场售票处再试一次刷卡。
  • 拍照：演出中禁止拍摄是基本规则。照片请在演出前后拍——国乐博物馆的展览、敦化门国乐堂前的昌德宫敦化门；国立剧场位于南山脚下，回程可以不坐接驳车，沿着奖忠坛公园方向走下来，边走边拍。

⚠ 常见失误5条

1. 把周六名品当成盘索里演出——它是国乐综合演出。只想看盘索里，请选国立剧场的完唱。

2. 以为完唱只有2小时——实际是170~300分钟。中场休息·离席的规定请在演出场地确认。

3. 想去赶秋天的全州声音节——2026年已在8月结束。

4. 从东大入口站走路上去——6号出口南山循环巴士站点前的接驳车，演出前1小时起每10分钟一班(官方)。

5. 想当然认为有英文字幕——官方未标注。预订前请确认。

⚙ FAQ 6

1. 第一次看怎么选？——先看唱剧《俄狄浦斯》(11/26~12/5，120分钟，20,000韩元起)，或敦化门的免费完唱(11/11·11/21《沈清歌》)。如果300分钟的完唱有负担，就选80分钟的周六名品。

2. 只想简单尝个鲜？——国立国乐院周六名品80分钟（包含盘索里段落的场次）。

3. 多少钱？——国立剧场完唱20,000韩元，周六名品20,000~30,000韩元，唱剧20,000~50,000韩元，敦化门11月的盘索里租借场地演出免费(官方)。

4. 穿韩服有优惠吗？——周六名品穿韩服50%折扣仅限10/24场次(已结束)。穿好韩服进宫殿免费——请查看#460 独行女性指南中的条件。

5. 想在全州看？——声音节在8月。国立无形遗产院的日程未核实。

6. UNESCO是什么时候？——2003年宣布，2008年列入人类非物质文化遗产代表作名录。
