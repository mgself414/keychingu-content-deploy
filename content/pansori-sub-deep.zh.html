🎯 本指南使用方法

盘索里 (Pansori / 판소리) 是由一名歌者搭配一名鼓手 (Gosu / 고수)（打鼓者），连续演唱数小时的叙事音乐。把一部曲目从头唱到尾的完唱 (Wanchang / 완창)，视歌者和曲目而定需要3~8小时（这次确认的演出为170分钟和300分钟）；改编成舞台剧的唱剧 (Changgeuk / 창극) 通常约2小时。外国人想“看盘索里”，现实中有三种选择——① 国立国乐院 (Gungnip Gugagwon / 국립국악원) 的周六名品 (Toyo Myeongpum / 토요명품)（每周六举行，是国乐综合演出，并非只有盘索里）；② 国立剧场 (Gungnip Geukjang / 국립극장) 的完唱盘索里和唱剧；③ 首尔敦化门国乐堂 (Seoul Donhwamun Gugakdang / 서울돈화문국악당) 与首尔南山国乐堂 (Seoul Namsan Gugakdang / 서울남산국악당) 的单场演出。下文的日程·票价·地址，只写了2026-10-07在各官方网站上读到的数值，所有官方页面都没有标注英文字幕，因此未核实。旧版指南中的“国立国乐院每周盘索里·英/日文字幕·5千~5万韩元”“秋季全国盘索里庆典高潮”“韩国之家10万~30万韩元”或无出处或有误，已删除。

🏛 4处演出场地

国立国乐院——周六名品

  • 瑞草区南部循环路2364。乘3号线南部客运站站 (Nambu Terminal / 남부터미널역) 步行前往（出口编号官方未核实）。
  • 周六名品：2026-01-03~12-26每周六15:00~16:20，牛眠堂。A席30,000·B席20,000韩元。有些场次会包含一段盘索里，但并不是盘索里单独演出——请在官方页面查看各场次的节目。

国立剧场——完唱盘索里·唱剧

  • 中区奖忠坛路59。从3号线东大入口站 (Dongdaeipgu / 동대입구역) 6号出口乘接驳车（演出前1小时~20分钟，每10~15分钟一班），或步行10~15分钟（官方）。
  • 完唱盘索里：由一位名唱把一部曲目从头唱到尾。10/24李光福《兴甫歌 (Heungboga / 흥보가)》（170分钟），11/14徐珍姬《沈清歌 (Simcheongga / 심청가)》（300分钟），均为20,000韩元，在月升剧场。
  • 唱剧：国立唱剧团的舞台剧。11/26~12/5《俄狄浦斯》（50,000/35,000/20,000韩元）。12/26送年盘索里《笑谈》30,000韩元。

首尔敦化门国乐堂

  • 钟路区栗谷路102（昌德宫敦化门前）。10/25罗允英 万正制 春香歌。票价和交通指引官方页面未公布——请在预订页面确认。

首尔南山国乐堂

  • 中区退溪路34街28（南山谷韩屋村内）。10/10~11长短游戏庆典。除此之外的盘索里单独日程，截至10/7在官方页面上没有读到。

全州——国立无形遗产院 (Gungnip Muhyeong Yusanwon / 국립무형유산원)·声音节

  • 国立无形遗产院（全州）的演出节目在官方页面上没有读到。全州世界声音节2026已于8/12~16结束（编排了盘索里五大曲目·青年盘索里五大曲目），2027年日程请留意上半年公告。

⚠ 常见失误5条

1. 把周六名品当成盘索里演出——它是国乐综合演出。只想看盘索里，请选国立剧场的完唱。

2. 以为完唱只有2小时——实际是170~300分钟。中场休息·离席的规定请在演出场地确认。

3. 想去赶秋天的全州声音节——2026年已在8月结束。

4. 从东大入口站走路上去——6号出口有接驳车。

5. 想当然认为有英文字幕——官方未标注。预订前请确认。

⚙ FAQ 6

1. 第一次看怎么选？——10/24国立剧场完唱《兴甫歌》（170分钟，20,000韩元），或唱剧《俄狄浦斯》（11/26起）。

2. 只想简单尝个鲜？——国立国乐院周六名品80分钟（包含盘索里段落的场次）。

3. 多少钱？——完唱20,000韩元，周六名品20,000~30,000韩元，唱剧20,000~50,000韩元（官方）。

4. 穿韩服有优惠吗？——10/24周六名品5折（官方）。

5. 想在全州看？——声音节在8月。国立无形遗产院的日程未核实。

6. UNESCO是什么时候？——2003年宣布，2008年列入人类非物质文化遗产代表作名录。
