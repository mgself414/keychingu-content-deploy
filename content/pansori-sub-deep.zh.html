📍 高敞 — 申在孝盘索里博物馆·申在孝故居·申在孝盘索里公园

高敞申在孝盘索里博物馆 (Gochang Sin Jae-hyo Pansori Bakmulgwan / 고창 신재효판소리박물관)(高敞郡高敞邑 (Dongni-ro 100 / 동리로 100)，☎ 063-560-8061)，是纪念盘索里理论家、改编者和赞助人桐里申在孝 (Sin Jae-hyo / 신재효)，以及陈彩仙 (Jin Chae-seon / 진채선)、金素姬 (Kim So-hui / 김소희) 等多位名唱的博物馆。建在申在孝故居旧址上，距高敞市外客运站500m。圆形展厅“名誉殿堂”设有名唱们的照片展板。设有重新构建盘索里艺术世界的唱场 (Sori-madang / 소리마당)，介绍申在孝和高敞唱家的说白场 (Aniri-madang / 아니리마당)，以及通过数字影像体验盘索里的魂场 (Hon-madang / 혼마당)。

  • 开放时间:夏季 09:00~18:00，冬季 09:00~17:00。闭馆前30分钟停止入场。休息日:每周一，1月1日，春节·中秋节当天。
  • 费用:免费。

高敞申在孝故居 (Gochang Sin Jae-hyo Gotaek / 고창신재효고택)(同一地址，☎ 高敞邑城游客咨询处 063-560-8055)，是集盘索里之大成的申在孝 (Sin Jae-hyo / 신재효)(1812~1884)居住过的房子。据观光公社介绍，推测建于哲宗1年(1850)，据悉光武3年(1899)由其子重建。原本是朴素的草屋舍廊，在被指定为国家民俗文化遗产之前一直用作高敞警察署的附属建筑，此后由国家管理并复原了旧貌。是正面6间、侧面2间的“一”字形草屋，由厨房1间、房间2间、大厅1间和合并的房间1间构成。

  • 开放时间:09:00~18:00。休息日:全年无休。
  • 停车:可以。

申在孝盘索里公园 (Sin Jae-hyo Pansori Gongwon / 신재효판소리공원)(高敞郡高敞邑 (Jung-geori-dangsan-ro 148 / 중거리당산로 148)，☎ 063-560-8035)，是建在高敞邑城城郭路旁的盘索里空间。这里是纪念出身高敞衙前、集盘索里之大成的申在孝 (Sin Jae-hyo / 신재효) 的地方，有韩屋3栋，总建筑面积614㎡。设有用于盘索里教育和体验的研讨室、盘索里体验室、盘索里练声室和户外演出场。

  • 开放时间:09:00~17:00(休息时间 12:00~13:00)。休息日:每周六~周日。
  • 体验:在盘索里学院，可以接受盘索里专业教授的理论讲座和名唱的盘索里传承教育。10人以上可以提前申请演出，内容有盘索里讲解、欣赏和学唱一段。据观光公社介绍，周末在户外场地还会举办观众与学员共同参与的演出。登记的休息日为周六~周日。
  • 停车:可以。

📍 东便制 — 求礼东便制盘索里传授馆·南原东便制诞生地

东便制盘索里传授馆 (Dongpyeonje Pansori Jeonsugwan / 동편제 판소리전수관)(求礼郡求礼邑 (Dongpyeonje-gil 53 / 동편제길 53)，☎ 061-782-6868)，是为纪念求礼出身的东便制 (Dongpyeonje / 동편제) 名唱宋万甲 (Song Man-gap / 송만갑)、培养盘索里人才，于2000年建在求礼邑Baengnyeon-ri (백련리) 宋万甲故居一带的传授馆。盘索里以蟾津江 (Seomjingang / 섬진강) 为中心分为东便制 (Dongpyeonje / 동편제) 和西便制 (Seopyeonje / 서편제)。据观光公社介绍，求礼的唱腔以韩末国唱宋万甲 (Song Man-gap / 송만갑) 为顶点，保存着东便制盘索里的原型。开设盘索里传授教育和国乐班，并举办名唱宋万甲追思全国盘索里比赛。附近有2001年11月3日开馆的东便制盘索里纪念馆、宋万甲故居，以及名唱宋万甲、Bak Bong-rae (박봉래)、朴奉述 (Bak Bong-sul / 박봉술) 的追思碑。

  • 开放时间:全天开放。休息日:全年无休。
  • 费用:免费。停车:免费。宠物:不可。

东便制诞生地 (Dongpyeonje Taetjari / 동편제탯자리)(南原市云峰邑 (Bijeon-gil 7 / 비전길 7)，☎ 063-634-7535)，是创立东便制 (Dongpyeonje / 동편제) 盘索里的歌王宋兴禄 (Song Heung-nok / 송흥록) 出生的云峰邑 (Unbong-eup / 운봉읍) Bijeon-maeul (비전마을)。这里也是女名唱朴初月 (Bak Cho-wol / 박초월) 的唱腔故乡。宋兴禄 (Song Heung-nok / 송흥록) 把民俗音乐中最慢的真阳调 (Jinyangjo / 진양조) 运用到盘索里中，拓宽了盘索里的表现领域。春香歌 (Chunhyangga / 춘향가) 狱中歌的鬼哭声(鬼的哭声)被公认为他所创的唱法。东便制由其弟宋光禄 (Song Gwang-nok / 송광록) 和孙子宋万甲 (Song Man-gap / 송만갑) 传承。2000年起，随着 Bijeon-maeul (비전마을) 国乐圣地的建设，宋兴禄 (Song Heung-nok / 송흥록) 故居和朴初月 (Bak Cho-wol / 박초월) 古宅得以复原。

  • 开放时间:09:00~18:00。休息日:全年无休。

📍 西便制 — 宝城盘索里圣地

盘索里圣地 (Pansori Seongji / 판소리성지)(宝城郡会泉面 (Yeongcheon-gil 17-8 / 영천길 17-8)，☎ 061-852-5206)，是纪念创立西便制 (Seopyeonje / 서편제) 的朝鲜时代名唱江山朴裕全 (Bak Yu-jeon / 박유전)，以及Jeong Jae-geun (정재근)、郑应珉 (Jeong Eung-min / 정응민)、Jo Sang-hyeon (조상현) 等延续西便制谱系的名唱们的地方。会泉面 (Hoecheon-myeon / 회천면) Yeongcheon-ri (영천리) Dogang-maeul (도강마을) 一带，有朴裕全 (Bak Yu-jeon / 박유전) 纪念碑、郑应珉 (Jeong Eung-min / 정응민) 故居和得音亭 (Deukeumjeong / 득음정)。朴裕全 (Bak Yu-jeon / 박유전) 出生于全北淳昌，1852年迁到宝城Gangsan-maeul (강산마을) 创立了西便制，此后还创立了调和东便制与西便制优点的江山制 (Gangsanje / 강산제)。开设盘索里体验班和教育项目。

  • 开放时间:09:00~18:00。9~12月每周六 14:00 有常设演出。休息日:每周一。
  • 团体:30人以上的团体游客，可以免费观看名唱的盘索里·民谣演出。

📍 公州 — 朴东镇盘索里传授馆

朴东镇盘索里传授馆 (Park Dong-jin Pansori Jeonsugwan / 박동진판소리전수관)(公州市 (Murung-jungmal-gil 22-14 / 무릉중말길 22-14)，☎ 041-858-0045)，是建在国家无形文化遗产赤壁歌 (Jeokbyeokga / 적벽가) 技艺保持者朴东镇 (Park Dong-jin / 박동진) 出生地公州武陵洞 (Murung-dong / 무릉동) 的传授馆。教授盘索里五大唱段、圣经盘索里、短歌和南道民谣，在培养名唱的同时，还面向市民开展盘索里体验和文化教育。

  • 开放时间:09:00~18:00。休息日:每周日~周一，法定节假日，春节·中秋节假期。
  • 费用:免费。

⚠ 行前须知 3 点

  1. 休息日各不相同 — 申在孝盘索里公园周六~周日休息，朴东镇盘索里传授馆周日~周一休息，申在孝盘索里博物馆和盘索里圣地周一休息。高敞申在孝故居、东便制盘索里传授馆、东便制诞生地全年无休。
  2. 高敞三处都在高敞邑城文化体验街 (Gochangeupseong Munhwa Cheheom Geori / 고창읍성 문화체험거리) 一带 — 申在孝盘索里博物馆和高敞申在孝故居地址相同，申在孝盘索里公园在高敞邑城城郭路旁。
  3. 宝城常设演出只在9~12月举行 — 每周六 14:00。

⚙ FAQ 2

Q. 在哪里可以观看盘索里演出?

A. 按观光公社登记信息，有宝城盘索里圣地 (Pansori Seongji / 판소리성지) 的常设演出(9~12月每周六 14:00)。申在孝盘索里公园10人以上可以提前申请演出，盘索里圣地对30人以上的团体免费提供演出。

Q. 在哪里可以亲自学习盘索里?

A. 有申在孝盘索里公园 (Sin Jae-hyo Pansori Gongwon / 신재효판소리공원)(盘索里学院，学唱盘索里一段)、朴东镇盘索里传授馆 (Park Dong-jin Pansori Jeonsugwan / 박동진판소리전수관)(面向市民的盘索里体验)、盘索里圣地 (Pansori Seongji / 판소리성지)(盘索里体验班)、东便制盘索里传授馆 (Dongpyeonje Pansori Jeonsugwan / 동편제 판소리전수관)(国乐班)。
