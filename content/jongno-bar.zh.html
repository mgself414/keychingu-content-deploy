⚠ 外国游客常犯的3个错误

1. "韩国酒 = 只有烧酒"的误解

外国游客动线中最常见的误区。韩国酒除烧酒外，还有马格利 (makgeolli / 막걸리) (米发酵酒，约6~8度)·药酒 (yakju / 약주) (清澈发酵酒)·清酒 (cheongju / 청주) (高级发酵酒)·传统果实酒等多种选择。钟路韩食酒馆 (好先生殿·我们酒馆松鼠·校洞煎先生)是体验传统酒综合菜单的首选 — 马格利 (米发酵，6~8度，类似中国米酒但更浓郁)·药酒 (澄清发酵酒，口感接近日本清酒)·清酒 (高级发酵酒)三种对比体验。

2. 益善洞红酒吧 = 普通红酒吧的误解

益善洞 (Ikseon-dong / 익선동) 红酒吧 (候鸟巢穴·拉益善·伍兹鲸鱼)并非普通红酒吧，而是韩屋氛围 + 韩国 fusion 下酒菜 + 红酒搭配的独特体验。韩国设计师精选葡萄酒 + 韩式 fusion 下酒菜是真正精髓。益善洞韩屋小巷 (골목，类似中国胡同的传统小巷) 散步后来一杯红酒，是最具外国游客风格的路线。

3. 摊位 vs 居酒屋 vs 酒馆傻傻分不清

  • 摊位·포차 (Pocha / 포차) (乐园摊位·纽约摊位)：韩式室内外小摊，类似大排档，休闲、下酒菜丰富、适合团体。
  • 居酒屋 (Izakaya / 이자카야) (配水寺)：日式小酒馆，以吧台座位为主，适合1~3人。
  • 酒馆 (Jujeom / 주점) (好先生殿·我们酒馆)：韩式正统酒馆，韩食下酒菜 + 传统酒，适合团体。
  • 料理酒馆 (Yori Jujeom / 요리주점) (博学多识·咕噜屋)：料理 + 酒，休闲 + 可当正餐。

钟路·益善洞·钟阁酒吧风貌

钟路片区是韩国传统酒 + 益善洞韩屋红酒吧的大本营。与江南 (豪华)、弘大 (独立·休闲)、梨泰院 (Itaewon / 이태원) (全球酒吧)形成差异化的传统·老字号 (30年以上传统店)·益善洞韩屋气质。

钟路本区·钟阁是韩食酒馆 + 摊位 + 啤酒区域 — 好先生殿·我们酒馆松鼠·乐园摊位·首尔88啤酒等正统店铺密集。钟路3街站 (Jongno 3-ga Station / 종로3가역)·钟阁站 (Jonggak Station / 종각역) 步行5分钟内。

钟路区厅·仁寺洞 (Insadong / 인사동) 一带汇集传统酒正统店铺 — 校洞煎先生·伍兹鲸鱼等传统酒馆 + 现代红酒吧结合。仁寺洞散步 + 传统酒馆路线最佳。

煎饼·马格利搭配：校洞煎先生钟路区厅店 (Gyodong Jeon Seonsaeng / 교동전선생)。

韩食下酒菜 + 酒：好先生殿 (Ho Seonsaengjeon / 호선생전)。

外国游客路线：我们酒馆松鼠一轮 → 好先生殿二轮。

Q3. 益善洞韩屋红酒吧路线怎么走？

A. 17:00 益善洞 (Ikseon-dong / 익선동) 韩屋小巷散步 → 18:30 候鸟巢穴益善洞本店 (Gireogi Dungji / 기러기둥지) → 20:00 拉益善 (La Ikseon / 라익선) → 21:30 伍兹鲸鱼 (Woods Whale / 우즈 웨일) 收尾。益善洞韩屋 + 红酒深度体验最佳路线。

Q4. 摊位·居酒屋·酒馆有什么区别？

A. 摊位·포차 (Pocha / 포차) (乐园·纽约)：韩式室内外小摊，团体 OK，下酒菜丰富。

居酒屋 (Izakaya / 이자카야) (配水寺)：日式，以吧台为主，适合1~3人。

酒馆 (Jujeom / 주점) (好先生殿·我们酒馆)：韩式正统，团体 OK。

料理酒馆 (Yori Jujeom / 요리주점) (博学多识·咕噜屋)：料理 + 酒，休闲风格。

Q5. 按价格带推荐？

A. ₩15K~30K (休闲)：乐园摊位·首尔88啤酒·咕噜屋。

₩25K~45K (正统)：好先生殿·校洞煎先生·博学多识·纽约摊位。

₩35K~70K (红酒)：候鸟巢穴·拉益善·伍兹鲸鱼·配水寺。

Q6. 带外国朋友推荐哪家？

A. 4~6人团体：好先生殿·乐园摊位·首尔88啤酒·博学多识。

情侣·小团体：候鸟巢穴·拉益选·伍兹鲸鱼·配水寺。

1~3人：我们酒馆松鼠·配水寺·校洞煎先生。

Q7. 营业时间·休息日？

A. 营业：平日 18:00~24:00，周末 17:00~翌日01:00 为标准。最后点单：23:00~24:00。最佳时段：平日 18:00~21:00 人少。周末 19:00~22:00 为高峰。

Q8. 钟路 + 其他路线结合？

A. 钟路咖啡馆 + 酒吧 (#157 + #163)：14:00 咖啡馆巡游 → 18:00 酒吧晚餐。

景福宫 (Gyeongbokgung / 경복궁) 观光 + 钟路酒吧：09:00 景福宫 → 18:00 好先生殿晚餐。

益善洞深度游：14:00 韩屋散步 → 17:00 益善洞咖啡馆 → 19:00 候鸟巢穴红酒吧。
