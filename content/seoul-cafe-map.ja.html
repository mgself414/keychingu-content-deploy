ソウルカフェガイド — コーヒーと空間14か所(学林・乙支茶房・インザマス・哨所書店) ロースタリー・古い茶房・倉庫・眺望編 (2026年10月公式値)

サブタイトル: 学林 (ハンニム / 학림) 1956年から営業・豆を自家焙煎(VisitKorea) · 乙支茶房 (ウルチタバン / 을지다방) 1985年開業、月~土06:00オープン(VisitKorea) · インザマス馬場 (インザマス マジャン / 인더매스 마장) 馬場の古い倉庫で焙煎の過程を公開(VisitKorea) · 仁王山 哨所書店 (チョソチェクパン / 초소책방) 元警察の哨所、08:00~22:00(VisitKorea) · 価格は14か所すべて未掲載 — 2026-10-21時点

ISSUE 03 · #913 · 2026-05-27

🎯 このガイドの使い方

2階への木の階段を上ると、焙煎した豆の香りが先に迎えてくれて、窓の外は付岩洞の路地です(クラブエスプレッソ (클럽에스프레소)、VisitKorea)。このガイドはコーヒーの味と空間そのものが目的になるソウルのカフェだけを扱います。ジャンルは4つ:自家焙煎のコーヒー店、古い茶房、倉庫・古い建物を生かしたカフェ、山・川の眺望カフェ。お店はすべて韓国観光公社の観光情報(VisitKorea、TourAPI)に登録されている所で、住所・営業時間・休業日はその登録値をそのまま写しました。ケーキやパンが主役のお店は #914 スイーツ店ガイド に分けました。

旧ガイドはブルーボトル・アンスラサイト・フリッツに「世界最高」「韓国最高」といった順位をつけていましたが、根拠がないので削りました。有名ブランドのカフェやエリア別のリストは 外国人向けソウルカフェ総合ガイド で見てください。この版は、VisitKoreaに空間の由来が書かれている店を中心にしています。

☕ 自家焙煎のコーヒー店 — 4か所

  • 学林 (ハンニム / 학림) — ソウル特別市鍾路区 大学路 (テハンノ / 대학로) 119 2階。10:00~23:00(ラストオーダー22:00)、旧正月 (ソル / 설) と秋夕 (チュソク / 추석) は休み。1956年から営業するカフェで、豆を店内で自家焙煎し、ハンドドリップコーヒーを出します。看板メニューはウィンナーコーヒー(ホイップクリームをのせたコーヒー)で、クリームチーズケーキやパフェもあります。クラシック音楽が流れます。電話 02-742-2877(VisitKorea)
  • クラブエスプレッソ (클럽에스프레소) — ソウル特別市鍾路区 彰義門路 (チャンウィムンノ / 창의문로) 132(付岩洞 (プアムドン / 부암동))。09:00~19:00(ラストオーダー18:50)、年中無休。1990年に大学路で開店し、2001年に付岩洞へ移りました。1階は焙煎の作業場のような注文カウンター、2階は木で飾った座席です。豆やコーヒー器具も売っています。近くに尹東柱文学館 (ユンドンジュムナッカン / 윤동주문학관) があります。電話 02-764-8719(VisitKorea)
  • コーヒーチング (커피친구) — ソウル特別市鍾路区 三峰路 (サンボンノ / 삼봉로) 81(寿松洞 (スソンドン / 수송동))。平日10:00~20:30、土12:00~17:30、日曜休み。2005年開業のハンドドリップ専門店で、毎日自家焙煎した豆を使います。メニューはエルサルバドル・ケニア・ルワンダ・コロンビアなど産地名で並んでいて、デカフェコーヒーもあります。電話 02-725-0179(VisitKorea)
  • ホ・ヒョンマンの狎鷗亭コーヒー店 (허형만의 압구정커피집) — ソウル特別市江南区 狎鷗亭路 (アックジョンノ / 압구정로) 151 新現代商店街2棟107号。月~金09:00~18:00、土09:00~17:00、日・法定祝日・旧正月と秋夕の連休は休み。2001年7月開業。ロースター兼講師のホ・ヒョンマンさんが毎日焙煎したコーヒーを出し、コーヒー講座も開きます。看板メニューは狎鷗亭コーヒーです。電話 0507-1367-5078(VisitKorea)

🕰 古い茶房 — 3か所

  • 乙支茶房 (ウルチタバン / 을지다방) — ソウル特別市中区 乙支路 (ウルチロ / 을지로) 124-1 2階(乙支路3街 (ウルチロサムガ / 을지로3가))。月~土06:00~21:00、日09:00~20:00、年中無休。1985年開業。卵の黄身をのせた双和茶 (サンファチャ / 쌍화차、漢方茶) が看板メニューで、アイスコーヒーや生フルーツジュースもあります。再開発で今の場所に移りました。電話 02-2272-1886(VisitKorea)
  • トバンネ (터방내) — ソウル特別市銅雀区 黒石路 (フクソンノ / 흑석로) 101-7。12:00~23:00、日曜休み。1983年に開いた音楽茶房の雰囲気をそのまま残しています。コーヒーはサイフォンで淹れます。角砂糖にウイスキーを注いで火をつける「カフェロワイヤル (카페 로열)」と、アイスクリームを浮かべたコーヒーフロートが人気です。電話 02-813-4434(VisitKorea)
  • ジェビ茶房 (제비다방) — ソウル特別市麻浦区 臥牛山路 (ワウサンノ / 와우산로) 24(上水駅 (サンスヨク / 상수역) の近く)。11:30~02:00、年中無休。作家の李箱 (イ・サン / 이상) がかつて開いた茶房の名前にちなみます。コーヒーのほか、トラジ茶(キキョウの根のお茶)や紅茶、おやつにカレトク (가래떡、棒状の餅) を出します。地下1階にインディーバンドのステージがあります。電話 02-325-1969(VisitKorea)

🏭 倉庫・古い建物を生かしたカフェ — 3か所

  • インザマス馬場 (인더매스 마장) — ソウル特別市城東区 馬場路 (マジャンロ / 마장로) 270 京東倉庫 (キョンドンチャンゴ / 경동창고)(馬場駅 (マジャンヨク / 마장역) 4番出口方面)。09:00~21:30(ラストオーダー21:00)、年中無休。古い倉庫を改装しました。天井が高く、焙煎の過程とバリスタ教育の様子を店内で見られます。豆を選んでその場で味わえ、ペット同伴もできます。電話 0507-1489-9031(VisitKorea)
  • コーヒー韓薬房 (커피한약방) — ソウル特別市中区 三一大路12街 (サミルデロ12キル / 삼일대로12길) 16-6(乙支路2街 (ウルチロイガ / 을지로2가))。1階は平日10:00~22:00、週末11:00~22:00(ラストオーダー21:00)、2・3階は10:00~21:30、年中無休。VisitKoreaは、朝鮮時代の医療機関・恵民署 (ヘミンソ / 혜민서) の跡地を直したカフェとして紹介しています。古い小物や骨董をそのまま置き、手で焙煎したコーヒーとフィルターコーヒーが看板です。路地が狭くて見つけにくいです。電話 070-4148-4242(VisitKorea)
  • ビーンブラザーズ合井 (빈브라더스 합정) — ソウル特別市麻浦区 土亭路 (トジョンノ / 토정로) 35-1(合井駅 (ハプチョンヨク / 합정역) 7番出口方面)。10:00~22:00(ラストオーダー21:30)、年中無休。天井の高い一戸建てにインダストリアルなインテリア、店の中央のバーでバリスタがコーヒーを淹れます。看板メニューはドリップコーヒーです。電話 0507-1428-2001(VisitKorea)

⛰ 山・川の眺望カフェ — 4か所

  • 仁王山 トスプ 哨所書店 (인왕산 더숲 초소책방) — ソウル特別市鍾路区 仁王山路 (インワンサンノ / 인왕산로) 172(仁王山の中腹)。08:00~22:00(ラストオーダー21:30)、年中無休。1968年から50年以上使われた警察の哨所を直した書店兼カフェで、哨所の外壁の一部と鉄の扉を残しました。大きなガラス窓の向こうにNソウルタワーが見えます。電話 02-735-0206(VisitKorea)
  • 銅雀ノウルカフェ (동작노을카페) — ソウル特別市銅雀区 銅雀大路 (トンジャクテロ / 동작대로) 335(4号線銅雀駅 (トンジャクヨク / 동작역)、銅雀大橋の南端)。月~木10:00~23:00、金~日10:00~01:00、年中無休。2階は汝矣島側、3階は盤浦側の席、4階はルーフトップです。橋の反対側の1番出口方面には同じ形のクルムカフェ (구름카페) があります。電話 0507-1324-7279(VisitKorea)
  • サンモトゥンイ (산모퉁이) — ソウル特別市鍾路区 白石洞路 (ペクソクトンギル / 백석동길) 153(付岩洞)。11:00~18:50(ラストオーダー18:20)、年中無休。MBCドラマの撮影場所で、2階に撮影の小道具や写真を置いています。窓の外にソウル市内と北漢山が見えます。電話 02-391-4737(VisitKorea)
  • 韓屋カフェ 善雲閣 (한옥카페 선운각) — ソウル特別市江北区 三陽路173街 (サミャンノ173キル / 삼양로173길) 223(牛耳洞 (ウイドン / 우이동))。11:00~19:00(ラストオーダー18:00)、水曜休み。北漢山のふもとの韓屋 (ハノク / 한옥) です。VisitKoreaの紹介文は、故・鄭周永 (チョン・ジュヨン / 정주영) 会長が建て、宮殿を除けばソウルで一番大きな民間の韓屋だと「いわれている」と伝聞として書いています。韓屋ウェディングや撮影地としてだけ使われていましたが、カフェとして開きました。牛耳新設線の北漢山牛耳駅 (プッカンサンウイヨク / 북한산우이역) から徒歩約20分、駐車は有料です。電話 0507-1399-1105(VisitKorea)

🥗 食事制限

  • 価格帯: 14か所とも、VisitKoreaの登録値に価格がありません。価格は未掲載 — メニュー表を見て選ぶか、電話で確認してください
  • ミルクの代替: アーモンドドリンクのメニューが登録されているのは、哨所書店(アーモンドブリーズラテ)とサンモトゥンイ(アーモンドブリーズコーヒー)です(VisitKorea)。ほかの店はオーツミルクや豆乳に変えられるか、注文時に聞いてください
  • カフェイン: デカフェコーヒーが登録されているのはコーヒーチング(VisitKorea)。乙支茶房の双和茶はコーヒーではなく漢方茶です
  • 卵・アルコール: 乙支茶房の双和茶には卵の黄身がのります。トバンネの「カフェロワイヤル」にはウイスキーが入ります(VisitKorea) — ベジタリアンやハラールの旅行者は抜いてもらうか、別のメニューを選んでください
  • ハラール: VisitSeoulは、梨泰院のイード (Eid / 이드)(龍山区 ウサダンノ10キル (우사단로10길) 15、毎日12:00~21:00)を、韓国イスラム教中央会(KMF)がハラールと認めた数少ない飲食店として紹介しています。認証は変わることがあるので、訪問前に確認してください。このガイドのカフェにはハラール表示がありません
  • 見せるカードは #1300 食事リクエストマニュアル

🧰 カフェの実務 — ひとり、予約、支払い、注文、移動

  • ひとり: カフェは1人注文が基本なので、ひとりでも行きやすいです。ひとりごはん・ひとりカフェの地図は #348 Seoul Solo Diner Map
  • 予約: 14か所とも、VisitKoreaの登録値に予約の案内がありません。並ぶか、そのまま入ります
  • 支払い: カード・スマホ決済は #527 韓国の決済システム
  • 注文: レジで注文して呼び出しベルを受け取る店が多いです — #1288 カフェ呼び出しベルマニュアル。マグカップ・返却台・席取りは #1378 カフェ店内利用ルール。言葉が通じないときは #1339 注文エチケット
  • 移動: 地下鉄・バスは #1298 交通カード3種の選び方。哨所書店・サンモトゥンイ・善雲閣は山の斜面にあるので、歩く時間を多めに見てください

⚠ よくある間違い4つ

1. 「古い茶房はもうなくなった」 — 乙支茶房(1985年)とトバンネ(1983年)は、今もVisitKoreaに営業中として登録されています

2. 「カフェはどの曜日も開いている」 — コーヒーチングとトバンネは日曜、ホ・ヒョンマンの狎鷗亭コーヒー店は日曜と祝日、善雲閣は水曜に休みます(VisitKorea)

3. 「カフェは遅くまで開いている」 — クラブエスプレッソは19:00、サンモトゥンイは18:50、善雲閣は19:00に閉まります。遅い夜はジェビ茶房(02:00)や銅雀ノウルカフェ(金~日01:00)を選びます(VisitKorea)

4. 「眺望カフェは登山しないと行けない」 — 銅雀ノウルカフェは4号線銅雀駅の出口からそのまま続いています(VisitKorea)
