🎯 なぜソウル 自転車・サイクリング ガイドなのか

ソウル 漢江 (ハンガン) 自転車道路 130km は世界都市の中でも屈指の自転車インフラ — 江西 (カンソ) の幸州大橋 (ヘンジュデギョ) から江東 (カンドン) まで、漢江両岸に沿って全線接続。90%以上が自転車専用道路。タルンイ (Ttareungi, ソウル公共シェア自転車) の会員数は330万人以上、外国人も英語アプリで登録可能。Reddit r/koreatravel では "Han River bike"・"Seoul cycling" キーワードが頻出。Activity シリーズ #5 — #146 ランニング / #147 夜間ランニング / #148 登山 / #151 キャンプ・BBQ / #149 自転車。

⚠ 外国人がよくやる失敗 3つ

1. タルンイ (Ttareungi) 登録には韓国の携帯番号が必須

タルンイアプリ (英語対応) — 韓国携帯番号による SMS 認証が必要。外国人 SIM・通信会社加入 + カード が必須。短期渡航者はホテル・韓国人の友人のサポート、または民間自転車レンタル (1577-0190 漢江デリバリー + 自転車レンタルサービス ₩3,000/時間 (~¥330)) を推奨。外国人 e-SIM の一部は使用可能。

2. 自転車道路と歩行者道路の区別が分からない

漢江自転車道路は緑色の標識、歩行者道路はグレー。一部区間 (バンポ・ヨイド) では自転車と歩行者が混用 — スピードを落とすこと。漢江大橋・東湖大橋などの橋の上には自転車道路が別途設置されている。

3. 夏の 11:00〜16:00 直射日光・熱中症

漢江自転車道路は日陰が少ない — 夏は早朝 06:00〜09:00、または夕方 19:00〜22:00 を推奨。11:00〜16:00 の直射日光は避けること。ヘルメット・水・日焼け止めは必携。

ソウル 自転車インフラ

ソウルの自転車 culture・インフラ:

  • 漢江自転車道路 130km = 江西 ヘンジュデギョ (행주대교) ↔ 江東 (漢江両岸)
  • 自転車専用道路 90%+ — 都市自転車安全度 最上位
  • タルンイ (Ttareungi) = ソウル公共シェア自転車、会員数 330万人以上、1時間 ₩1,000 (~¥110)
  • 民間自転車レンタル = 漢江公園の売店・バンポ・ヨイド周辺 ₩3,000〜₩5,000/時間
  • 自転車専用橋 = チャムスギョ (잠수교, バンポ)・東湖・チャムシル (잠실)・クァンナル (광나루) など
  • 自転車 + 地下鉄 = 自転車持ち込み可能 (一部時間帯 + 9号線の後部1両 (平日 OK))

外国人の4つのニーズ:

1. 入門・短いコース — バンポ・ヨイド 6〜8km (1時間)

2. 夜景・インスタ映え — 漢江夜景 13km (タルンイ 1位) + ノドゥル 9km (2位)

3. 一周・縦走 — 50km 一周 / 130km 縦走

4. 郊外・都心 — タンチョン・チョンゲチョン (多彩なトーン)

① 入門 (2コース)

1. バンポ (반포) 漢江公園コース

外国人サイクリング入門 第1選択 — バンポ漢江 8km ループ。バンポデギョ (반포대교) 南端からスタート、チャムスギョ (잠수교) → 漢江南岸 → チャムスギョ 帰着 8km。タルンイまたは民間レンタル ₩3,000/時間。ダルビッムジゲ噴水シーズン (4〜10月) 19:30〜21:30 の夜間コースが best。

  • スタート地点: 9号線 シンバンポ駅 (신반포역) 1番出口 徒歩5分
  • 距離/時間: 8km / 約45〜60分
  • 難易度: 入門 (平坦・自転車道路 100%)
  • シグネチャー: ダルビッムジゲ噴水・チャムスギョ・漢江 view
  • レンタル: タルンイ または 民間 ₩3,000/時間
  • おすすめポイント: 外国人の漢江初サイクリングに最適。景色・インフラ・レンタルすべて揃い。

2. ヨイド (여의도) 漢江公園コース

ヨイド一周 6km — ユンジュンロ (윤중로) + 63ビル view。5号線 ヨイナル駅 (여의나루역) 徒歩3分。春 (3〜4月) ユンジュンロの桜シーズンが最高潮。Runner's Station 無料ロッカー利用可。

  • スタート地点: 5号線 ヨイナル駅 (여의나루역) 4番出口
  • 距離/時間: 6km / 約35〜50分
  • 難易度: 入門 (平坦)
  • シグネチャー: ユンジュンロ桜・63ビル・漢江鉄橋
  • レンタル: タルンイ + Runner's Station 民間レンタル
  • おすすめポイント: 春の桜シーズン 第1選択。Runner's Station 施設との組み合わせ最適。

② 夜景・タルンイ人気 (2コース)

3. 漢江夜景 13km (タルンイ 1位)

ソウル市民が直接選んだタルンイ道 1位 — トゥクソム (뚝섬) → 東湖大橋 → バンポデギョ → ノドゥルソム (노들섬) 13km。漢江夜景の名所を一度に体験。自転車専用道路の整備が最も優れており、初心者〜上級者まで快適。

  • スタート地点: 7号線 トゥクソムユウォンジ駅 (뚝섬유원지역)
  • 距離/時間: 13km / 約70〜90分
  • 難易度: 中級 (平坦・中距離)
  • シグネチャー: トゥクソム夜景 → 東湖 → バンポ噴水 → ノドゥルソム 360°
  • 推奨時間: 日没 17:00〜20:00 (噴水シーズンなら 21:00〜22:00)
  • おすすめポイント: 外国人自転車夜景コース 第1選択。タルンイ市民投票 best。

4. ノドゥル (노들) ～ヨイド～セッガン (샛강) ～ヤンファ (양화) 9km (タルンイ 2位)

自転車道路 90% — 安全性 best 9km。ノドゥル駅 → ヨイド水辺広場 → セッガン生態公園 → ヤンファ漢江公園。外国人ファミリー・初心者 best (交通事故の心配なし)。

  • スタート地点: 9号線 ノドゥル駅 (노들역)
  • 距離/時間: 9km / 約50〜70分
  • 難易度: 入門 (自転車道路 90%、最高の安全性)
  • シグネチャー: セッガン生態公園・ヨイド水辺・ヤンファ漢江
  • 推奨時間: 春・秋 午前 09:00〜11:00
  • おすすめポイント: 外国人ファミリー・初心者 best。安全性 No.1。

③ 一周・縦走 (2コース)

5. チャムスギョ (잠수교) ～ヘンジュデギョ (행주대교) 南北周回 50km

漢江両岸を一周 — チャムスギョスタート、ヘンジュデギョ折り返し、チャムスギョ帰着。漢江南岸・北岸を両方体験。春・秋シーズンが best。マニア入門コース。

  • スタート地点: バンポ チャムスギョ (9号線 シンバンポ駅 (신반포역))
  • 距離/時間: 50km / 約3.5〜5時間
  • 難易度: 中上級 (平坦だが距離が長い)
  • シグネチャー: 漢江両岸・バンポ噴水・ヨイド・チャムシル・ヘンジュデギョ
  • 持ち物: ヘルメット・水 2L・軽食・工具 (チューブパンク対策など)
  • おすすめポイント: 漢江一周マニアコース。1日コースとして十分。

6. 漢江縦走 130km

漢江自転車道全線縦走 — 江西 ヘンジュデギョ (행주대교) ↔ 江東 パルダン (팔당)。漢江全線。14〜16時間 (1日 または 1泊2日)。国土縦走認定パス発行可能。

  • スタート地点: 江西 ヘンジュデギョ または チャムシル (ソウル端)
  • 距離/時間: 130km / 約14〜16時間 (1日) または 1泊2日
  • 難易度: 上級 (長距離)
  • シグネチャー: 漢江全線・国土縦走認定
  • 持ち物: ヘルメット・水 4L・軽食・工具・予備チューブ・ライト (夜間走行対応)
  • おすすめポイント: 漢江縦走マニアチャレンジ。外国人自転車マニア 第1選択の挑戦コース。

④ 郊外・都心 (2コース)

7. タンチョン (탄천)・ヤンジェチョン (양재천) 江南郊外

江南郊外のんびりコース 15〜25km。ヤンジェシミネスップ駅 (양재시민의숲역) からスタート、タンチョンに沿って漢江まで。漢江自転車道路より静かで自然の風景が豊か。江南在住外国人の通勤 + ライディング組み合わせにも最適。

  • スタート地点: シンブンダン線 ヤンジェシミネスップ駅 (양재시민의숲역)
  • 距離/時間: 15〜25km / 約1.5〜2時間
  • 難易度: 中級 (平坦・静か)
  • シグネチャー: タンチョン・ヤンジェチョン・江南郊外の自然
  • 推奨時間: 秋の紅葉・春の桜
  • おすすめポイント: 漢江以外のオプション。江南コース + 自転車の組み合わせ。

8. チョンゲチョン (청계천) 都心自転車

クァンファムン (광화문) → チョンゲチョン LED → トンデムン (동대문) → DDP 8km。都心ど真ん中のサイクリング。自転車道路一部 + 歩行者道路混用。夜間 LED 照明が best。

  • スタート地点: 5号線 クァンファムン駅 (광화문역) または チョンガク駅 (종각역)
  • 距離/時間: 8km / 約50〜60分
  • 難易度: 入門 (平坦・都心)
  • シグネチャー: チョンゲチョン LED・クァンファムン・DDP 夜景
  • 推奨時間: 夜間 19:00〜22:00 (LED 照明点灯)
  • おすすめポイント: 都心自転車。チョンノ (종로)・DDP 観光 + ライディング組み合わせ。

⚙ FAQ 8項目

Q1. 外国人のタルンイ (Ttareungi) 登録は?

韓国の携帯番号 + 韓国カード が必須。外国人登録証・パスポートのみでは直接登録不可。ホテル・韓国人の友人のサポート、または民間レンタル (バンポ・ヨイドの売店 ₩3,000/時間) を推奨。外国人 e-SIM の一部は使用可能。

Q2. 民間自転車レンタルはどこで?

  • バンポ (반포) 漢江公園 — 売店 in-site レンタル ₩3,000〜₩5,000/時間
  • ヨイド (여의도) 漢江公園 — Runner's Station 近辺 + 民間レンタル
  • トゥクソム (뚝섬) 漢江公園 — 売店 + 自転車保管所
  • チャムシル (잠실) 漢江公園 — 民間レンタル豊富
  • ノドゥルソム (노들섬) — 入口レンタル

Q3. ヘルメット・装備はどこで?

ほとんどの民間レンタル売店でヘルメット込み (義務ではないが強く推奨)。本格マニアはデカトロン (江南・チャムシル) でヘルメット ₩30,000〜₩80,000 を購入。

Q4. ベストな時間帯は?

  • 春・秋: 午前 08:00〜11:00 (空いている) または 日没 16:00〜19:00
  • 夏 (7〜8月): 早朝 06:00〜09:00 (猛暑回避) または 夕方 19:00〜22:00
  • 冬 (12〜2月): 昼 11:00〜14:00 (最も暖かい)

Q5. 雨の日の代替案は?

雨の漢江自転車 = 危険 (滑り・事故)。雨予報の場合の代替案:

  • 博物館・DDP・インサドン (인사동) 徒歩観光
  • ホテルのジム (室内自転車)

Q6. 外国人ライディングクルーは?

Seoul Cycling Club (Facebook + Strava) — 外国人メイン の weekly ライディング。Han River Foreign Cyclists (Instagram グループ)。英語 OK。

Q7. 自転車 + 地下鉄は?

ソウル地下鉄への自転車持ち込み可能 — 一部時間帯 (週末・祝日) または 9号線後部1両 (平日 OK)。漢江ライディング後に遠方へ移動する際に活用。

Q8. ライディング後の締め (食事・チムジルバン)?

  • 漢江チメク (치맥, フライドチキン+ビール) — 1577-0190 漢江デリバリー (ライディング後のシグネチャー)
  • カフェ・クッパプ (국밥, 骨スープご飯) — ライディング終点に応じて (#142 江南カフェ・#133 クッパプ)
  • チムジルバン (찜질방, 韓国式サウナ銭湯 — 日本のスーパー銭湯に近い) — ヤンジェ・チャムシル (#7 チムジルバンガイド)

🗺 おすすめ1日自転車コース 3パターン

🌸 シーズン・時間帯 フック 5つ

1. 春 (4〜5月) ユンジュンロ (윤중로) 桜ライディング: ヨイド 6km + ユンジュンロ桜が最高潮。外国人インスタ映え 第1選択。

2. 夏 (7〜8月) 早朝・夜間: 猛暑回避。早朝 06:00〜09:00 または 夕方 19:00〜22:00。

3. 秋 (10〜11月) 紅葉ライディング: 漢江両岸 + タンチョン紅葉シーズン。絶景。

4. 噴水シーズン (4〜10月) バンポ夜景: ダルビッムジゲ噴水 19:30〜21:30 + バンポ 8km ライディング。

5. 冬 (12〜2月) 空いている漢江: 氷点下は危険 — グランピング/室内へ切り替え。ライディングは気温 4°C 以上の日を推奨。
