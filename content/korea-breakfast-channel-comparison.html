🍳 4채널 deep dive

🏨 호텔 조식 (Hotel Breakfast)

핵심 가치: 5성급 풀세트 + 영어 1순위 + 럭셔리.

  • 추천: 신라호텔·롯데호텔·웨스틴 조선·포시즌스·반얀트리
  • 가격: 60,000~120,000원 (+봉사료 10% + 부가세 10%)
  • 외국인 친화도: ★★★★★

🥐 MZ 브런치 (MZ Brunch)

핵심 가치: MZ 인스타 #1 + 한식·서양 fusion.

  • 추천: 홍대·강남·이태원·성수·연남 MZ 카페
  • 가격: 15,000~30,000원
  • 외국인 친화도: ★★★★★

🍲 해장국 (Haejang-guk)

핵심 가치: 24h + 다음날 매니아 #1.

  • 추천: 본죽·전주 콩나물·서울 황태·강원 정통
  • 가격: 8,000~15,000원
  • 외국인 친화도: ★★★★

🥪 편의점·체인 (Convenience·Chain)

핵심 가치: 24h 가성비 #1 + 즉시.

  • 추천: CU·GS25·세븐일레븐·이마트24·본죽·죽이야기·김가네
  • 가격: 2,500~12,000원
  • 외국인 친화도: ★★★★

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 시간·가격·매니아 완전 다름. 럭셔리 = 호텔 / 트렌드 = MZ / 해장 = 해장국 / 24h = 편의점.

2. "호텔 조식 = 시간 자유": 06:30~10:00 한정·예약 필요.

3. "MZ 브런치 = 즉시": MZ = 웨이팅 30분~2h·테이블링 앱.

4. "해장국 = 매콤만": 콩나물국밥·황태해장 = 담백 외국인 OK.

5. "편의점 = 신선도 X": 편의점 = 24h 신선·MZ 차밀 풀세트.

1. 첫 아침 채널 = 어디: 호텔 조식 (럭셔리 #1) + MZ 브런치 (#1 트렌드).

2. 인스타·vlog: MZ 브런치 (#1).

3. MZ 트렌드: MZ 브런치 (#1).

4. 해장 매니아: 해장국 (#807 cross).

5. 24h 가성비: 편의점 (#1).

8. VAT 환급: 식음료 일반 환급 X.
