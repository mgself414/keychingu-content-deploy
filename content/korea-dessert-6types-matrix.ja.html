🎯 なぜ韓国のデザートマトリックスなのか

外国人韓国デザートペインポイント= "K-dramaイカゲームダルゴナ外円知らない"。韓国デザート＝ 伝統的な通り（ホトク・フナパン・菊パン）＋宮中・伝統（薬科・韓菓）＋モダン（かき氷・ダルゴナカフェ） 3カテゴリーフルセット。同じ「Korean dessert」でもホトク（1900年代通り）・ダルゴナ（1970年代学校前→イカゲーム2021グローバル）・フナパン（1930年代）・菊パン・薬科（朝鮮宮中）・氷水（1900年代日帝）それぞれ異なる歴史・材料外国人は（a）甘くしか知らない他のデザート未経験（b）餅≠日本のホトケーキ（c）かき氷＝シングルメニューで誤解（d）薬と＝漢と一部など混同。本ガイドは6種マトリックス+季節別+外国人入門優先順位。

🥞デザート6種deep dive

🥞 ホトク (Hotteok) — 外国人入門 #1

  • シグネチャー: 旧韓末(1880年代) 清国華僑流入と共に韓国定着 (語源:胡=清国,餠=餅)
  • 種類:
  • 種子餅 (Seed): ナッツ・ヒマワリ種子（釜山1番地）
  • 蜂蜜ホトック（Honey）：黒砂糖+蜂蜜
  • 緑茶ホトック（グリーンティー）：MZトレンド
  • チーズホトック（Cheese）：モッツァレラ（MZトレンド）
  • おすすめストア:
  • 釜山BIFF広場ホトック - 釜山シグネチャー（種子ホトック韓国#1）
  • 明洞・弘大・鍾路通り — 外国人マニア
  • 仁寺洞韓屋ホトククラスタ
  • 外国人親和性: ★★★★★ (英語メニュー 多・インスタ★)
  • 価格：2,000〜4,000ウォン
  • 季節: 冬1位 (暖かさ)

🍯 ダルゴナ (Dalgona) — グローバル認知度 ★

  • シグネチャー: 1960年代後半～70年代学校の前の通り + イカゲーム（2021）グローバル爆発
  • 種類:
  • 星・三角形・傘の形（Honeycomb shape）：イカゲーム本物
  • ダルゴナラテ（Dalgona Latte）：インスタカフェ#1トレンド
  • ダルゴナマフィン・スイーツ：MZカフェ
  • おすすめストア:
  • 仁寺洞・鍾路通り - 本格イカゲーム体験（1,000～2,000ウォン）
  • MZカフェ (ソウル全域) — ダルゴナ・ラテ・マフィン
  • 外国人親和性: ★★★★★ (グローバル認知度#1)
  • 価格：1,000〜3,000ウォン（通り）/ 6,000〜9,000ウォン（ラテ）
  • 季節: 年中

🐟 フンパン (Bungeoppang) — 冬の街並み

  • シグネチャー: 1930年代日帝強占期日本 タイ焼き(鯛焼き, Taiyaki) 流入 → 韓国小豆本格変形
  • 種類:
  • 小豆のパン (Red bean): 基本
  • シュークリームパンパン（Custard cream）：MZトレンド
  • ピザパンパン（Pizza）：バリエーション
  • おすすめ店舗: 路上売り場（冬シーズン11月～3月）
  • 外国人親和性: ★★★★ (インスタ型★)
  • 価格：1,000〜2,000ウォン/個（3個5,000ウォン一般）
  • 季節: 冬限定 (11月～3月)

🌼 菊のパン (Gukhwappang) — パンのいとこ

  • シグネチャー：韓国戦争の前後の通りの定着 - 菊の形
  • 種類：小豆菊パン（基本）/クリーム菊パン（トレンド）
  • おすすめ店舗：仁寺洞・鍾路伝統売場
  • 外国人にやさしい: ★★★（インスタ型★）
  • 価格：1,000〜2,000ウォン/個
  • 季節: 秋～冬

🌾 薬科 (Yakgwa) — 宮中正統 + MZ トレンド

  • シグネチャー：朝鮮宮殿デザート（蜂蜜+ごま油+小麦粉）
  • 種類:
  • 伝統薬科：仁寺洞・伝統韓菓屋
  • MZ薬科：薬とラテ・薬とクロワッサン（弘大・江南カフェ）
  • 薬とアイスクリーム: 雪氷・MZカフェ
  • おすすめストア:
  • 仁寺洞伝統酒屋（本格）
  • MZカフェ（弘大・聖水・江南） — 薬とラテ・薬とパン（インスタ1番地）
  • 外国人にやさしい: ★★★★（MZトレンド★★★★★）
  • 価格：1,500〜5,000ウォン/個
  • 季節: 年中 (秋・冬 ↑)

🍧 かき氷 (Bingsu) — 夏 #1

  • シグネチャー: 1920年代日帝強占期カーキゴリ(かき氷)影響+朝鮮時代の石ビンゴ氷と伝統結合→小豆水正統化
  • 種類:
  • 小豆水 (Red bean): 本物
  • マンゴー氷水 (Mango): MZ トレンド

  • 緑茶氷水 (Green tea matcha): MZ

  • おすすめストア:
  • インストール（チェーン） - 韓国#1かき氷チェーン（コスパ）
  • 新羅ホテルかき氷 - ラグジュアリー（50,000～80,000ウォン）
  • 弘大・江南・梨泰院MZかき氷カフェ
  • 外国人親和性: ★★★★★ （夏マニア#1・インスタ★）
  • 価格：8,000〜25,000ウォン（一般）/ 40,000〜80,000ウォン（ホテル）
  • 季節: 夏1位 (6～9月)

⚠外国人の頻繁な誤り5つ

1. 「韓国デザート＝ダルゴナマン」：6種フルセット+カフェcluster。ホトック（冬#1）＋かき氷（夏#1）マニア。

2. "ホトク=日本ホトケーキ": 韓国ホトク= 黒砂糖+ナッツ+暖かい通り(1900年代)。日本のホットケーキ=他の食べ物。

3. "かき氷=シングルメニュー": かき氷=6+種類(小豆・マンゴー・イチゴ・緑茶・ホテルラグジュアリー)。ホテルのかき氷＝40,000～80,000ウォンのラグジュアリー。

4. 「ダルゴナ＝作りづらい」：韓国仁寺洞・鍾路通り = 1,000～2,000ウォン即席体験。イカゲーム本格体験。

5. 「フンパン＝四季」：フンパン＝冬限定（11月～3月）。夏には路上毎代ほとんど無い。

⚙ よくある質問8件

1. 外国人入門1位: ホトク(冬)/かき氷(夏)/ダルゴナ(年中)。

2. インスタ・vlog 1ランク: ダルゴナラテ・ヤクとラテ・ホテルかき氷・仁寺洞韓屋カフェ。

3. MZ トレンド: ダルゴナラテ・薬とクロワッサン・インストール・ブルーボトル+薬科。

4. ラグジュアリー・接待：新羅・ロッテ・ウェスティンホテルかき氷（40,000～80,000ウォン）。

5. 季節マニア: 春=薬科/夏=氷水/秋=ホトッ・菊パン/冬=ホトック・フナパン・ダルゴナ。

6. アレルギー：グルテン（小麦）・ナッツ（ホトク種子）・牛乳（かき氷）・卵（薬科）・蜂蜜（薬科）事前告知。

7. 決済・チップ: 通り = 現金推奨 / カフェ・チェーン = カードOK / ホテル = サービス料10% / チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

ホトック・フナパン・菊パン＝ 熱いデザート（90～100℃） — 火傷注意（特に子供）。かき氷＝寒さ（ミルクアレルギー・糖分↑）注意。妊婦＝ナッツ・蜂蜜適正量。アレルギー（グルテン・ナッツ・ミルク・卵・蜂蜜・豆）事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗情報免責：路上売り場・季節限定店舗変動頻繁 — 訪問前NAVER/Kakao mapまたは現地検索をおすすめ。

食事制限 fallback:

  • ハラール・コーシャー: 6種のうち認証店舗ほとんどない。 →薬科・ダルゴナ＝動物材料なし（ハラール・コーシャ可能一部）。餅・フナパン・かき氷＝牛乳・豚油可能（確認が必要）。
  • ベジタリアン・ビーガン: 薬科・ダルゴナ = ベジタリアンOK (蜂蜜・牛乳確認) / ホトッ・フンパン・かき氷 = 牛乳・卵多→ビーガンカフェ別途。
  • グルテンフリー: 6種すべて小麦粉多。かき氷のみオプション可能（小麦粉のトッピングを除く）。
