韩式凉拌菜 (namul / 나물) 6种综合指南 — 菠菜、桔梗、豆芽、蕨菜、东风菜、水芹全套

🎯 为什么需要一份韩式凉拌菜综合指南

外国游客对韩式凉拌菜 (namul / 나물) 的痛点 = "只知道凉拌菜=素菜"，不知道其忠实粉丝群。韩式凉拌菜 = 韩定食 (hanjeongsik / 한정식，韩式套餐料理) 小菜 (banchan / 반찬，免费的韩式配菜) 标配 + 寺庙料理正统 + 拌饭 (bibimbap / 비빔밥) 5色全套 + 全球素食友好。同样叫"Korean vegetable side"，菠菜拌菜(全国#1·拌饭必备)·桔梗拌菜(山野菜#1·人参同类根茎)·豆芽(解酒 (haejang / 해장，韩式醒酒暖食) #1·与#807关联)·蕨菜拌菜(山野菜正统·蕨菜汤 (고사리탕))·东风菜拌菜(春季山野菜#1)·水芹拌菜(春季香草·排毒)各自食材、时令、粉丝群不同。外国游客通常不知道：(a) 拌饭是5色凉拌菜全套 (b) 寺庙料理全部由凉拌菜系列构成 (c) 豆芽与解酒汤关联 (d) 山野菜是春季正统食材。本指南提供6种综合对比 + 素食·清真友好重点说明。

🌿 6种深度解析

🥬 菠菜拌菜 (Sigeumchi-namul / 시금치나물) — 入门#1

  • 代表性：四季皆宜·拌饭5色正统必备#1·全球熟悉
  • 食材：菠菜 + 香油·蒜末·酱油·盐
  • 外国游客亲和度：★★★★★(#1入门，全球熟悉的菠菜)
  • 推荐店铺：韩定食(#837)·家常菜·全州拌饭·MZ咖啡馆
  • 季节：四季皆宜·冬季正统
  • 价格：韩定食(可续加免费) / 家常菜免费 / 市场3,000~6,000韩元(约16~32元人民币)

🌱 桔梗拌菜 (Doraji-namul / 도라지나물) — 春季山野菜·韩定食

  • 代表性：春季山野菜#1·人参同类根茎·药材·韩定食正统
  • 食材：桔梗 (doraji / 도라지，干制或鲜制) + 调味料
  • 外国游客亲和度：★★★★(韩定食正统，全球公认的药用根茎)
  • 推荐店铺：正统韩定食餐厅·江原道 (Gangwon / 강원) 山野菜老字号 (nopo / 노포，经营30年以上的传统老店)
  • 季节：春季(3~5月)·干货全年供应
  • 价格：韩定食免费 / 市场每袋5,000~15,000韩元(约26~79元人民币)

🌿 豆芽 (Kongnamul / 콩나물) — 解酒#1

  • 代表性：解酒#1·与#807汤饭 (gukbap / 국밥) 系列关联·豆芽汤饭 (콩나물국밥)
  • 食材：豆芽 + 香油·盐·酱油(简单)
  • 外国游客亲和度：★★★★★(#1，全球熟悉的豆芽)
  • 推荐店铺：韩定食·家常菜·全州豆芽汤饭·解酒系列
  • 季节：四季皆宜
  • 价格：韩定食免费 / 市场2,000~4,000韩元(约11~21元人民币)

🍂 蕨菜拌菜 (Gosari-namul / 고사리나물) — 春季·祭祀正统

  • 代表性：春季山野菜·祭祀食物#1·正统面食配菜
  • 食材：蕨菜 (gosari / 고사리，干制) + 紫苏油·酱油·蒜末
  • 外国游客亲和度：★★★(山野菜爱好者喜爱)
  • 推荐店铺：正统韩定食餐厅·祭祀料理·江原道老字号
  • 时令：春季·祭祀(农历传统节日(#846))
  • 价格：韩定食免费 / 市场每袋(干货)10,000~25,000韩元(约53~132元人民币)

🌳 东风菜拌菜 (Chwi-namul / 취나물) — 春季香气正统

  • 代表性：春季4~5月#1·香气·山野菜
  • 食材：东风菜(春季山野菜) + 调味料
  • 外国游客亲和度：★★★★(春季正统，香气受全球喜爱)
  • 推荐店铺：正统韩定食餐厅·江原道·全罗道 (Jeolla / 전라) 春季正统
  • 季节：春季4~5月#1
  • 价格：韩定食免费 / 市场每袋8,000~20,000韩元(约42~105元人民币)

💧 水芹拌菜 (Minari-namul / 미나리나물) — 春季香气·排毒

  • 代表性：春季3~4月#1·排毒·香气·韩定食
  • 食材：水芹 (minari / 미나리) + 调味料
  • 外国游客亲和度：★★★(春季香草爱好者，因美国电影《米纳里》(2020年)而全球知名)
  • 推荐店铺：韩定食餐厅·清道 (Cheongdo / 청도) 水芹(大邱 (Daegu / 대구) 正统)·MZ(MZ世代，韩国千禧一代+Z世代)韩餐厅
  • 季节：春季3~4月#1
  • 价格：韩定食免费 / 市场每袋8,000~15,000韩元(约42~79元人民币)

🍽 韩定食·寺庙料理·拌饭代表菜品

韩定食 (hanjeongsik / 한정식) 小菜全套 (#837)

  • 5道套餐 = 凉拌菜4~6种 + 泡菜·腌菜
  • 新罗酒店 (Shilla Hotel / 신라호텔) 罗宴 (La Yeon / 라연)、三清阁 (Samcheonggak / 삼청각)、仁寺洞 (Insadong / 인사동) — 正统店铺
  • 无限续加免费

寺庙料理 (사찰음식，Temple Cuisine)

  • 寺庙料理 = 凉拌菜6种全系列#1·传统素食
  • 推荐店铺：
  • 津宽寺 (Jingwansa / 진관사)(首尔) — 寺庙料理正统
  • 曹溪寺 (Jogyesa / 조계사) — 寺庙料理系列
  • 奉恩寺 (Bongeunsa / 봉은사)·冠岳山 (Gwanaksan / 관악산) — 寺庙料理爱好者聚集地
  • 清真·犹太洁食·素食 = 可食用(不含肉类及五辛素 (osinchae / 오신채，寺庙料理禁用的五种辛辣蔬菜：大蒜、洋葱、韭菜、葱、阿魏))

拌饭 (bibimbap / 비빔밥) 5色正统 (#856)

  • 5色 = 菠菜(绿)·胡萝卜(红)·豆芽(白)·蕨菜(棕)·桔梗(白) + 鸡蛋(黄)
  • 全州拌饭 = 正统#1·宫廷拌饭系列

祭祀食物 (제사음식，Ancestral Rites Food)

  • 蕨菜·桔梗·菠菜 = 祭祀食物前3大凉拌菜
  • 春节 (Seollal / 설날)·中秋节 (Chuseok / 추석)(#846) — 正统

⚠ 外国游客常见的5个误区

1. "凉拌菜=素菜"：凉拌菜 = 韩定食小菜正统·拥有忠实粉丝的美食·全球素食友好。

2. "拌饭=只是主食"：拌饭 = 5色凉拌菜全套(菠菜、胡萝卜、豆芽、蕨菜、桔梗)。

3. "寺庙料理=只有素菜"：寺庙料理 = 凉拌菜6种系列 + 豆腐·蘑菇·传统素食料理。

4. "豆芽=只用于解酒"：豆芽 = 韩定食、解酒、家常菜都会用到。

5. "山野菜=四季皆宜"：山野菜(桔梗、东风菜、水芹、蕨菜) = 春季3~5月#1。

⚙ 常见问题8个

1. 外国游客入门首选：菠菜拌菜(全球熟悉)+ 豆芽(全球熟悉)→ 桔梗拌菜(韩定食正统)。

2. Ins·vlog打卡：韩定食小菜全套·全州拌饭·寺庙料理。

3. MZ潮流：MZ韩餐厅春季凉拌菜·全州拌饭·寺庙料理正统。

4. 解酒爱好者：豆芽(#1)+ 解酒汤(#870·#807)。

5. 春季山野菜：桔梗、东风菜、水芹、蕨菜(3~5月)。

6. 清真·素食·纯素：6种均可食用(若含五辛素大蒜则不适用于寺庙料理)。

7. 过敏提示：大蒜·酱油麸质需提前告知。

8. 付款·小费：韩定食·家常菜 = 可刷卡 / 无需小费。

⚠ 医疗·安全·饮食免责声明

凉拌菜属于普通的植物性食物。孕妇·儿童 = 可食用(可调整辣度)。过敏(大蒜·酱油麸质·桔梗药材)需提前告知。如怀疑食物中毒，请拨打☎ 1339(医疗咨询，提供英文服务)。本指南仅为一般信息，不构成医疗建议。

饮食限制替代方案：

  • 清真·犹太洁食：6种均可食用(植物性食材)。
  • 素食·纯素：6种均可食用(#1素食正统)。
  • 无麸质：酱油调味料含麸质(可用溜酱油替代)。
  • 寺庙料理(不含五辛素)：去除大蒜调味后6种均可食用。
