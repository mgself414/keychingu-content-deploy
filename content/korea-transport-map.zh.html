💳 卡·通票——游客能买的和买不了的

种类 1日 2日 3日 5日 7日
价格 5,000韩元 8,000韩元 10,000韩元 15,000韩元 20,000韩元
  • 实体卡另收3,000韩元。在1~8号线车站的新型交通卡售卖机购买，自2026-03-17起也可用海外发行的信用卡·借记卡支付。手机端(Mobile Tmoney·三星钱包，安卓12以上)也可使用。不能在海外提前购买。

  • 自2026-10-01起的范围：首尔地铁，首尔市许可的市内·村庄·深夜·循环公交，仁川机场T1·T2仅限下车(不可上车)。新盆唐线 (Sinbundang / 신분당선)·GTX·首尔以外的车站·广域公交·机场巴士·其他地区的公交均不可用。首尔公共自行车·汉江巴士 (Hangang Bus / 한강버스)·出租车也不包含在内。

T-money旅行卡 — 4,000韩元。在便利店和仁川机场巴士售票处购买(Tmoney)。可在全国公共交通·出租车使用。充值见#238，退款流程见#1298 ⑥ 退款。

WOWPASS — 外国人专用预付卡。可用银行卡·e-钱包·现金充值，使用时支付手续费为0韩元，取现每次1,000韩元(每次最多10万韩元)(WOWPASS)。充值手续费页面上没有说明，请在App中确认。交通使用T-money功能。

KORAIL PASS Plus (外国人专用，成人，KORAIL 2025-12-29新闻稿) — 2日131,000韩元 · 3日186,000韩元 · 4日234,000韩元 · 5日275,000韩元。加上交通卡功能需另加8,000韩元。退款·变更条件请在购买画面确认。

不是为游客准备的 — K-Pass(公共交通返还)据首尔市英文说明，注册需要外国人登录号，气候同行通票 (Gihu Donghaeng Pass / 기후동행패스)(30日月票的后续产品)是以首尔居民为对象的产品。短期来访的旅行者基本无法使用。

✈ 机场——直达还是普通

  • 机场铁路直达列车 (AREX Express / 공항철도 직통열차)：首尔站↔仁川机场 (Incheon / 인천공항) T1 43分钟，T2 51分钟，T1↔T2 8分钟(机场铁路官方)。在首尔站·T1·T2地下自动售票机和线上·App购买，可用海外发行的信用卡(Visa·万事达·JCB·美国运通·银联等)支付。直达列车票价可能变动，请以预订画面的数值为准——各站下车指南见#1249。
  • 机场铁路普通列车：起步10km基本票价1,550韩元，10~50km每5km加收100韩元，是按距离计费的票价(机场铁路票价说明)。气候同行短期券只能在仁川机场T1·T2站下车时使用。
  • 机场巴士比较见#87，机场利木津巴士·深夜机场巴士·换乘见#1015·#1395。金浦机场 (Gimpo / 김포공항)站位于首尔市内，属于短期券范围。

🌙 夜间·出租车·自行车

  • 猫头鹰巴士 (Olppaemi Bus / 올빼미버스)(N巴士)：14条线路，23:00~06:00，2,500韩元(首尔市)。各线路末班车约在03:10~04:10，凌晨5点可能已没有车(首尔市线路表)——#1395。
  • 出租车：首尔中型车起步价4,800韩元，22~23时·02~04时加价20%，23~02时加价40%(首尔市，2023-02实施的费表)。费表·宰客应对见#501，App叫车见#1273。
  • 首尔公共自行车 (Ttareungi / 따릉이)：首尔市公共自行车。非会员日票1小时1,000韩元 · 2小时2,000韩元 · 3小时3,000韩元，支付画面上有外国人专用的‘Discover Pass’选项，可选择英语·中文·日语(首尔公共自行车官方)。客服中心1599-0120。气候同行短期券不包含在内。

⚠ 常见的5个错误

1. 用短期券乘坐新盆唐线·机场巴士·广域公交 — 超出范围。只限首尔地铁和首尔许可的公交(+仁川机场T1·T2下车)。

2. 出发前一天提前给短期券充值 — 充值当天就是开始日。在开始使用的那天早上购买。

3. 用短期券在仁川机场站上车 — 只能下车。去机场时用T-money或直达列车票。

4. “外国人也能申请K-Pass返还” — 注册需要外国人登录号，短期访客很难满足条件。

5. 三张卡全都买 — 大多数人有一张T-money就够了，只有在首尔停留几天、大量乘地铁时才加上短期券(#1298)。

⚙ FAQ 4个

Q1. 每天要乘几次地铁，短期券才划算？

按交通卡基本票价1,550韩元(2025-06涨价报道值，不含距离加价)计算，1日券5,000韩元每天要乘4次才回本，而且另付卡费3,000韩元，几乎没有结余。加上卡费3,000韩元后，2日券每天乘4次，3·5·7日券每天乘3次左右开始划算。如果已有实体卡，则扣除卡费再计算。1,550韩元与机场铁路票价说明中的首都圈基本票价相同，准确票价以售票机·App画面为准。

Q2. 能在海外提前购买短期券吗？

不能。海外发行的卡自2026-03-17起可在1~8号线车站的新型售票机使用(首尔市FAQ)。便利店付款方面，首尔市说明中没有提到海外卡，请准备好现金。

Q3. KORAIL PASS Plus和普通KTX车票，哪个便宜？

以2日131,000韩元为基准，如果行程是两天内往返乘坐KTX一次以上，值得比较一下。票价以KORAIL画面为准，退款·变更条件请在购买前阅读。盈亏计算见#1374。

Q4. 可以打电话咨询的地方？

KORAIL 1599-7777(英文网站标注，08:00~20:00)，首尔公共自行车 1599-0120，机场铁路 1599-7788，旅游综合咨询 1330(#1299)。
