1. ナムルの女王 (눈물의 여왕 / Nulmului Yeowang, 2024) — 愛と裏切りのファンタスティックな邸宅

ドラマのあらすじ: 富豪の妻の夫の浮気疑惑と、本当の愛を探していく心理ドラマ

📍 主要撮影地

ウリイェッドルパンムルグァン (우리옛돌박물관 / Uri Yetdol Museum) (ソウル ソンブク区 / 성북구)

  • 役割: クイーンズグループ会長 パク・グヌの邸宅 (キム・スヒョン、キム・ジウォンの邸宅シーン)
  • 住所: ソウル市 ソンブク区 テサグァンロ13ギル 66 (성북구 대사관로13길 66)
  • 地下鉄: 4号線 ハンソンデイックヨク (한성대입구역 / Hansung Univ. Stn.) → タクシーまたは徒歩15分
  • 特徴: ハノク (한옥 / 韓国の伝統家屋。日本の古民家に近いイメージ) と現代建築を融合した、劇中のラグジュアリーな雰囲気を演出
  • 訪問ヒント: 博物館として運営中。撮影地訪問の際は事前確認必須
  • このシーンのように撮るコツ: 邸宅の庭で時間帯によって変わる日差しを活用。午後15:00〜16:00の逆光が最もドラマティック

ウォカヒル ホテル アストン ハウス (워커힐 호텔 애스톤 하우스 / Walkerhill Hotel Aston House) (ソウル クァンジン区 / 광진구)

  • 役割: パク・グヌ〜ユン・ヘヨン結婚式シーン (エピソード4)
  • 住所: ソウル市 クァンジン区 ウォカヒルロ 177 (광진구 워커힐로 177)
  • 地下鉄: 5号線 クァンナルヨク (광나루역 / Gwangnaru Stn.) → タクシー5分
  • 特徴: 優雅な宴会場で、ドラマのバックライトシーンに最適
  • 周辺グルメ: ウォカヒルホテル内の多彩なダイニング
  • このシーンのように撮るコツ: 窓際からソウルの夜景を背景に。三分割構図で人物を側面に置くと、劇中の感情ラインをうまく表現できる

イルォルスモクウォン (일월수목원 / Irwol Arboretum) (京畿道 スウォン / 수원)

  • 役割: ペ・ダジョン(キム・ジウォン)が自殺を図る森のシーン (序盤エピソード)
  • 住所: 京畿道 スウォン市 チャンアン区 イルォルロ 61 (장안구 일월로 61)
  • 地下鉄: 1号線 スウォンヨク (수원역 / Suwon Stn.) → タクシー20分
  • 特徴: 鬱蒼とした自然林で演出された、ドラマティックな設定の表現
  • 訪問ヒント: 季節ごとに異なる樹木の景観 (春の桜、秋の紅葉がおすすめ)
  • このシーンのように撮るコツ: 木々の間の影と光を活かしたコントラスト。スマートフォンのポートレートモードで背景ぼかし効果を適用するのがおすすめ

チュンジュ コンジマウル (충주 건지마을 / Chungju Geonji Village) (忠清北道 チュンジュ / 충주)

  • 役割: 序盤の農村エピソード撮影地
  • 住所: 忠清北道 チュンジュ市 トンニャンミョン コンジマウル (동량면 건지마을)
  • 交通: ソウル ↔ チュンジュ ムグンファ号 (무궁화호 / 韓国の普通列車。日本のJR普通列車に相当) 約1時間50分
  • 特徴: 典型的な韓国農村の風景で、序盤のコントラストを表現
  • このシーンのように撮るコツ: 低いアングルから田舎道を撮り、人物を前景に配置。夕暮れ時がエモーショナル

2. ソンジェを抱きしめて (선재 업고 튀어 / Seonjae Eobgo Twieeo, 2024) — タイムスリップロマンス、過去で出会う

ドラマのあらすじ: 2024年と2008年を行き来する不思議な愛の物語

📍 主要撮影地

ソンブクチョン ヨウルタリ (성북천 여울다리 / Seongbuk Stream Yeouldari Bridge) (ソウル ソンブク区 / 성북구)

  • 役割: イム・ソル (キム・ヘユン) が時計を落として過去へ渡る境界 (ドラマ全タイムスリップの舞台)
  • 住所: ソウル市 ソンブク区 ソンブクドン 2ガ 一帯 (성북동 2가 일대)
  • 地下鉄: 4号線 ソンシニョデヨク (성신여대역 / Sungshin Women's Univ. Stn.) 1番出口 → 徒歩5分
  • 特徴: 穏やかな散歩道で静かな雰囲気。ドラマファンの聖地巡礼スポット
  • 周辺カフェ: ソンシニョデヨク近くのカフェ通り (モンテドゥ / 몽테드 ほか複数のカフェ)
  • 訪問ヒント: 早朝訪問で混雑前の橋を独占撮影できる
  • このシーンのように撮るコツ: 橋の欄干にもたれた正面撮影。スマートフォン縦モードで背景の水と木を一緒に収める

トンデムン デザイン プラザ (동대문 디자인 플라자 / DDP) (ソウル チュン区 / 중구)

  • 役割: 2024年のイム・ソルがアイドル「エクリプス (선재 役)」のライブを見る会場 (ドラマ現在時間の舞台)
  • 住所: ソウル市 チュン区 ウルジロ 45 (중구 을지로 45)。ウルジロ (을지로 / Euljiro) はソウル中心部のレトロ×最先端が混在するストリート
  • 地下鉄: 2号線 トンデムンヨク (동대문역 / Dongdaemun Stn.)、トンデムン ヨクサムンファコンウォンヨク (동대문역사문화공원역 / Dongdaemun History & Culture Park Stn.) 近く
  • 特徴: 未来志向の建築物で、2024年の現代ソウルを表現
  • 入場料: 内部公演場・展示は別途料金。外部撮影は無料
  • 訪問ヒント: 夜景が最も美しい (18:00〜20:00)
  • このシーンのように撮るコツ: 建物の曲線を活かした広角撮影。空も一緒に入れてDDPの壮大さを強調

ソウル チュンアンコドゥンハッキョ (서울 중앙고등학교 / Seoul Jungang High School) (ソウル クァンジン区 / 광진구)

  • 役割: 2008年の学校シーン撮影地
  • 住所: ソウル市 クァンジン区 アチャサンロ 408 (광진구 아차산로 408)
  • 地下鉄: 7号線 クァンナルヨク (광나루역 / Gwangnaru Stn.) → 徒歩10分
  • 特徴: 学生時代の感性を呼び起こす
  • 訪問ヒント: 現役の学校のため、外部のみ撮影 (塀の近くで)
  • このシーンのように撮るコツ: 正門や塀を背景に、制服姿の友人たちと撮るとドラマのような雰囲気に

スウォン ヘングンドン (수원 행궁동 / Suwon Haenggungdong) (京畿道 スウォン市 / 수원)

  • 役割: イム・ソルが住んでいた家の前の通り。現在カフェ「モンテドゥ (몽테드 / Monted)」が位置するコルモク (골목 / 골목は細い路地・裏路地のこと。日本の「横丁」に近いニュアンス) (登場人物の日常の舞台)
  • 住所: 京畿道 スウォン市 パルダル区 ヘングンロ 127 一帯 (팔달구 행궁로 127 일대)
  • 地下鉄: 1号線 スウォンヨク (수원역 / Suwon Stn.) → タクシー10分またはバス
  • 特徴: ハノク (한옥 / 韓国伝統家屋) と現代カフェが共存するエモーショナルなストリート
  • 周辺カフェ: モンテドゥ (드라마 속 임솔이 집 / ドラマ内のイム・ソルの家)、スウォン ヘングンドン カフェ通り
  • 訪問ヒント: 14:00〜16:00の日差しが路地を程よく照らす
  • このシーンのように撮るコツ: 路地の細さを活かして人物を正面近くで撮影。背後のハノクが自然なボケ効果になる

3. トッケビ (도깨비 / Goblin, 2016, エバーグリーン・クラシック) — 永遠の愛の物語

ドラマのあらすじ: 400年を生きたトッケビ (도깨비 / 韓国の妖怪・神様的存在) キム・シンと死神、そして彼らを愛した女性たちのファンタジーロマンス

📍 主要撮影地

カンヌン ヨンジンヘビョン (강릉 영진해변 / Gangreung Yeongjin Beach) (江原道 カンヌン / 강릉)

  • 役割: チ・ウンタク (キム・ゴウン) が初めてトッケビ キム・シン (コン・ユ) を召喚する運命の場所 (ドラマの核心的な出会いの舞台)
  • 住所: 江原道 カンヌン市 カンドンミョン チョンドンジンリ 一帯 (강동면 정동진리 일대)
  • 交通: ソウル チョンニャンニヨク (청량리역 / Cheongnyangni Stn.) ↔ カンヌンヨク (강릉역 / Gangneung Stn.) ムグンファ号 約3時間30分。カンヌン駅からタクシー20分
  • 特徴: 青い東海の海が永遠を象徴。ドラマファンの聖地
  • 周辺カフェ/食堂: チョンドンジンヨク (정동진역 / Jeongdongjin Stn.) 近くのカフェ、海辺の食堂街
  • 訪問ヒント: 日の出時間帯 (05:00〜06:00) または夕暮れ (18:00〜19:00) に訪れると、劇中の神秘的な雰囲気を再現できる
  • このシーンのように撮るコツ: 海を背景に逆光を活用。人物のシルエットを強調すると、劇中の神秘さが増す

カンヌン キョンポデ (강릉 경포대 / Gangneung Gyeongpodae) (江原道 カンヌン / 강릉)

  • 役割: キム・シンと死神 (イ・ドンウク) が共に散策した楼閣 (友情の舞台)
  • 住所: 江原道 カンヌン市 ヨンドン 一帯 (영동 일대)
  • 交通: カンヌン駅からタクシー15分
  • 特徴: 600年以上の歴史を持つ韓国楼閣建築の真髄。フォトスポットとしても有名
  • 特記事項: ドラマ放映後、韓国観光の名所として注目度上昇
  • 訪問ヒント: 春の桜シーズン (4月) または秋の紅葉 (10月) を強くおすすめ
  • このシーンのように撮るコツ: 楼閣の柱と欄干をフレームとして活用。背景の山と湖を三分割構図に合わせて配置

カンヌン ウォルファコリ (강릉 월화거리 / Gangneung Wolhwa Street) (江原道 カンヌン / 강릉)

  • 役割: キム・シンとチ・ウンタクがデートした通り。旧鉄道跡に広がるカフェと雑貨ショップ
  • 住所: 江原道 カンヌン市 ポナムドン 一帯 (포남동 일대 / 旧鉄路)
  • 特徴: レトロな雰囲気あふれるカフェ通り。写真映えするスポットが豊富
  • 周辺カフェ: ウォルファコリにカフェ30〜40軒集中
  • 訪問ヒント: 15:00〜16:00にショーウィンドウの照明が灯り始め、雰囲気が増す
  • このシーンのように撮るコツ: カフェ入口から通り全体を背景に広角撮影。またはカフェの窓に映り込んだ人物を撮って映画的な効果を演出

カンヌン チュンアンシジャン (강릉 중앙시장 / Gangneung Jungang Market) (江原道 カンヌン / 강릉)

  • 役割: キム・シンとチ・ウンタクが一緒に買い物した日常の舞台
  • 住所: 江原道 カンヌン市 チュクホン 一帯 (죽헌 일대)
  • 特徴: 典型的な韓国市場の生き生きとした空気。土着の食文化を体験できる
  • おすすめメニュー: イカスープ、チム (찜 / 蒸し料理)、サンチェ ビビムバプ (산채 비빔밥 / 山菜混ぜご飯)
  • 訪問ヒント: 早朝 (08:00〜10:00) の市場の活気あふれる様子を収められる

インチョン ペダリ ホンチェクパン コルモク (인천 배다리 헌책방 골목 / Incheon Baedari Used Bookstore Alley) (仁川市 チュン区 / 인천시 중구)

  • 役割: トッケビのワンシーン撮影地。鉛筆と本が交わる運命的な場所
  • 住所: 仁川市 チュン区 クムゴクドン ペダリ ホンチェクパン コルモク (중구 금곡동 배다리 헌책방 골목)
  • 地下鉄: 1号線 インチョンヨク (인천역 / Incheon Stn.) → 徒歩15分
  • 特徴: チ・ウンタク (キム・ゴウン) が直感で感じた瞬間の背景。ハンミソジョム (한미서점 / Hanmi Bookstore) 前
  • 訪問ヒント: 10:00〜12:00の日差しが最も温かい
  • このシーンのように撮るコツ: 狭い路地の奥行きを活かして撮影。本の山を前景に置いてピントを後ろに外すと映画的に

4. イテウォン・クラス (이태원 클라쓰 / Itaewon Class, 2020, 最近再注目のドラマ) — 復讐と愛のナイトライフ

ドラマのあらすじ: イテウォン (이태원 / Itaewon) のポチャ (포차 / 屋台バー。日本の「屋台居酒屋」に近い、路上や軒先で飲み食いできるカジュアルな店) 通りを舞台にしたスカッと爽快な復讐劇とロマンス

📍 主要撮影地

ノクサピョンヨク ユッキョ (녹사평역 육교 / Noksapyeong Station Overpass) (ソウル ヨンサン区 / 용산구)

  • 役割: ドラマを象徴する舞台。パク・セロイ (パク・ソジュン) が語りかけるあの歩道橋 (主要シーンのほぼすべてが撮影された場所)
  • 住所: ソウル市 ヨンサン区 ノクサピョンロ 一帯 (용산구 녹사평로 일대)
  • 地下鉄: 6号線 ノクサピョンヨク (녹사평역 / Noksapyeong Stn.) 3番出口 すぐ前
  • 特徴: イテウォン全体を見渡す最高の撮影スポット。ドラマファン必訪コース
  • 周辺ポチャ: タンバム ポチャ (단밤 포차 / Danbam Pocha) 周辺、ノクサピョンヨク ポチャ コルモク
  • 訪問ヒント: 19:00〜21:00の夜景が最も美しい
  • このシーンのように撮るコツ: 橋の欄干にもたれた正面撮影。背後のイテウォン通りをボケで処理すると、劇中の感情を表現できる

ナムサン ペクポム クァンジャン (남산 백범광장 / Namsan Baekbeom Square) (ソウル ヨンサン区 / 용산구)

  • 役割: パク・セロイが毎日散歩した道。瞑想と回想の舞台
  • 住所: ソウル市 ヨンサン区 ナムサン 一帯 (용산구 남산 일대)
  • 地下鉄: 3号線 チュンムロヨク (충무로역 / Chungmuro Stn.) または4号線 ミョンドンヨク (명동역 / Myeongdong Stn.)
  • 特徴: ソウル城郭道と連なる屋外瞑想空間。四季折々の景観
  • 訪問ヒント: 早朝 (06:00〜08:00) または夕暮れ (17:00〜19:00) の一筋の光が劇的
  • このシーンのように撮るコツ: 低いアングルから階段や道を撮り、背景にソウルの夜景を入れる

イテウォン コリ (ノクサピョンヨク 一帯) (이태원 거리 / Itaewon Street) (ソウル ヨンサン区 / 용산구)

  • 役割: イテウォン・クラスのメイン舞台。ポチャ通りと飲食店街全体
  • 住所: ソウル市 ヨンサン区 イテウォンロ 一帯 (용산구 이태원로 일대 / ノクサピョンヨク半径1.5km)
  • 地下鉄: 6号線 ノクサピョンヨク (녹사평역 / Noksapyeong Stn.)
  • 特徴: 多国籍文化が交差するソウルのホットプレイス
  • 周辺飲食店/カフェ: イテウォン ポチャ、パブ、韓食堂、カフェ数百軒
  • 訪問ヒント: 19:00以降に街の照明が灯る。金・土・日の夜が最も雰囲気◎
  • このシーンのように撮るコツ: 通りのネオンサインと人の流れを一緒に収め、ダイナミックな雰囲気を表現

5. 愛の不時着 (사랑의 불시착 / Crash Landing on You, 2019, 名作再訪) — 北と南、運命の出会い

ドラマのあらすじ: グライダー事故で北朝鮮に不時着した財閥の娘と、北朝鮮の将校のロマンス

📍 主要撮影地 (ソウル場面)

ソウル カンナム コグプ メジャンガ (서울 강남 고급 매장가 / Seoul Gangnam Luxury Shopping Area) (ソウル カンナム区 / 강남구)

  • 役割: ユン・セリ (ソン・イェジン) のラグジュアリーな日常の舞台。ブランドショッピングと会社シーン
  • 住所: ソウル市 カンナム区 アックジョンロ、ノンヒョンロ 一帯 (강남구 압구정로·논현로 일대 / シンサドン カロスキル、カンナムヨク周辺)
  • 地下鉄: 2号線 カンナムヨク (강남역 / Gangnam Stn.)、シンサヨク (신사역 / Sinsa Stn.)
  • 特徴: ソウル随一のラグジュアリーストリート。劇中のセリの富裕さを象徴
  • おすすめカフェ/食堂: アックジョン ロデオコリ (압구정 로데오거리 / Apgujeong Rodeo Street) のカフェ群
  • 訪問ヒント: 14:00〜16:00にショーウィンドウの照明が鮮明になる
  • このシーンのように撮るコツ: ブランドショップの入口前でスタイリッシュなポジションで。背後のハングル看板は避け、英文/ラグジュアリーな背景のみ入れると◎

ソウル イェスルイ チョンダン (서울 예술의전당 / Seoul Arts Center) (ソウル ソチョ区 / 서초구)

  • 役割: セリの会社と舞台の背景
  • 住所: ソウル市 ソチョ区 ナンブスンファンロ 2406 (서초구 남부순환로 2406 / ソチョドン)
  • 地下鉄: 3号線 ナンブトミナルヨク (남부터미널역 / Express Bus Terminal Stn.)、2号線 キョデヨク (교대역 / Gyodae Stn.)
  • 特徴: 韓国最大の総合芸術施設。建築美が際立つ
  • 入場料: 内部公演・展示は別途料金。外部撮影は無料
  • 訪問ヒント: 夜景が最も美しい (18:00〜20:00)
  • このシーンのように撮るコツ: 建物の幾何学的なラインをフレームとして活用。夜のライトアップで壮大さを表現
