🎯 왜 한국 면안주 매트릭스인가

외국인 한국 술안주 페인포인트 = "치킨·삼겹살만 알고 있다". 한국 면안주 = 소주·막걸리 페어 #1 + 외국인 매니아 #1 + 한정식 코스 일부. 같은 "Korean pub food"라도 수육 (한정식·전문점)·족발 (장수동 정통)·보쌈 (광장시장 vlog #1)·골뱅이무침 (소주안주 #1)·홍어삼합 (전라 정통·3합)·제육볶음 (가성비 #1) 각자 다른 재료·매니아·페어. 외국인은 (a) 면안주 = 술안주 모름 (b) 족발 vs 보쌈 차이 모름 (c) 골뱅이무침 = 소주 페어 모름 (d) 홍어삼합 = 발효 음식 모름. 본 가이드는 6종 매트릭스 + 술 페어 + 외국인 입문 우선순위.

⚠ 외국인 자주 실수 5가지

1. "족발 = 보쌈": 족발 = 발 부분 (장수동 정통) / 보쌈 = 삶은 고기 + 김치 쌈 (광장 vlog) = 다른 음식.

2. "홍어삼합 = 일반 안주": 홍어삼합 = 발효 매니아 음식·암모니아 향 강함·전라 정통 (외국인 회피 가능).

3. "제육볶음 = 비싸다": 제육볶음 = 가성비 #1 (8,000~18,000원/1인 도시락).

4. "수육 = 한정식만": 수육 = 전문점·웨딩·한정식 모두 (가성비 OK).

5. "골뱅이 = 안 친숙": 골뱅이 = whelk (글로벌 인지)·소주 페어 #1.

⚙ FAQ 8개

1. 외국인 입문 1순위: 수육 + 보쌈 (담백·글로벌) → 족발 (장수동) → 골뱅이무침 (소주).

2. 인스타·vlog: 광장시장 보쌈·장수동 족발·종로 포장마차.

3. MZ 트렌드: 광장 보쌈·MZ 족발 체인 (대박)·제육 도시락.

4. 소주 매니아: 골뱅이무침 #1 + 족발 + 제육.

5. 장수동 족발 시간대: 17:00~03:00 (야식 매니아).

6. 알레르기: 돼지고기·해산물 (골뱅이·홍어) 사전 고지.

7. 결제·팁: 카드 OK / 시장·노포 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

면안주 = 일반 음식. 임신부 = 한정 OK (홍어 발효 X·돼지고기 적당량). 알레르기 (돼지고기·해산물·고추) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

  • 채식·비건: 6종 모두 비채식 (할랄 fallback = 비빔밥·잡채 → #854).
