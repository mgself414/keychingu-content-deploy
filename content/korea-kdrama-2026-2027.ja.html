① 2026年にすでに配信された6本

  • レディ・ドゥア (Redi Dua / 레이디 두아) (Netflix) — シン・ヘソン (Shin Hye-sun / 신혜선) がサラ・キム (Sara Kim / 사라킴)、イ・ジュニョク (Lee Jun-hyuk / 이준혁) がその行方を追う刑事ムギョン (Mugyeong / 무경) を演じるNetflixシリーズです。Sports Kyunghyangは2026-02-06の記事で「13日にNetflixで配信される」と報じました。配信日は2026-02-13です。
  • メイド・イン・コリア シーズン2 (Meideu in Korea Sijeun2 / 메이드 인 코리아 시즌2) (Disney+) — ヒョンビン (Hyun Bin / 현빈) (ペク・ギテ (Baek Gi-tae / 백기태)) とチョン・ウソン (Jung Woo-sung / 정우성) (チャン・ゴニョン (Jang Geon-young / 장건영)) が再びぶつかる時代劇の第2シーズンです。ウ・ドファン (Woo Do-hwan / 우도환) (ペク・ギヒョン (Baek Gi-hyeon / 백기현))、ソ・ウンス (Seo Eun-soo / 서은수)、ウォン・ジアン (Won Ji-an / 원지안)、チョン・ソンイル (Jung Sung-il / 정성일)、ノ・ジェウォン (Noh Jae-won / 노재원) も出演します。2026-09-09から毎週水曜に2話ずつ、全6話が配信されました (Sports Kyunghyang 2026-08-04)。シーズン1から9年後の物語なので、先にシーズン1を観ます (Sports Kyunghyang 2026-08-04)。
  • 私を充電して (Nareul Chungjeonhaejwo / 나를 충전해줘) (Netflix) — 電気の能力を持つドラマ作家と、人工心臓のバッテリーが切れた財閥3世が「充電」のために契約恋愛をするラブコメディです。キム・ヨングァン (Kim Young-kwang / 김영광) とチェ・スビン (Chae Soo-bin / 채수빈) が主演し、パク・スウォン (Park Su-won / 박수원) 監督が演出しました。同名のウェブ小説が原作です。配信日は2026-10-09です (Netflix公式発表 2026-09-10)。気軽に観られるロマンスを探している人に合います。
  • 再婚皇后 (Jaehon Hwanghu / 재혼 황후) (Disney+) — グローバル累計閲覧数29億7000万回 (原作ウェブトゥーン基準、Ilgan Sports 2026-08-26) のウェブトゥーンを映像化した宮廷ロマンスファンタジーです。シン・ミナ (Shin Min-a / 신민아) が皇后ナビエ (Navier / 나비에)、チュ・ジフン (Joo Ji-hoon / 주지훈) が皇帝ソビエシュ (Sovieshu / 소비에슈)、イ・セヨン (Lee Se-young / 이세영) がラスタ (Rastah / 라스타)、イ・ジョンソク (Lee Jong-suk / 이종석) が西王国の王子ハインリ (Heinley / 하인리) を演じます。Disney+オリジナルで、配信日は2026-11-04です (同じ記事)。原作ウェブトゥーンを読んだファンなら、俳優たちのキャラクター解釈を比べながら観る楽しみがあります。
  • 青い道 (Pureun-gil / 푸른길) (Netflix) — 手足がねじ曲がった遺体と謎のメッセージ、国境を越えて続く連続殺人を、ソウルと東京の2人の刑事が追います。ソン・ソック (Son Suk-ku / 손석구) がソウル警察庁の刑事キム・ソク (Kim Seok / 김석)、永山瑛太 (Eita Nagayama / 나가야마 에이타) が警視庁の刑事イノセ (Inose / 이노세) を演じます。キム・シンロク (Kim Sin-rok / 김신록)、チェ・ソンウン (Choi Seong-eun / 최성은)、チョン・ジェヨン (Jung Jae-young / 정재영) も出演します。監督はハン・ジュニ (Han Jun-hee / 한준희) です。Netflixは2026-11-05の発表で、2026-11-20 (金) の配信を告げました。韓国と日本の2人の刑事が国境を越えて協力する捜査ものです。
  • 代理受験 (Daeri Suneung / 대리수능) (TVING) — 名門自律型私立高の3年生たちが、修能 (大学修学能力試験) を前に絡み合い、犯罪へと突き進むスリラーです。ペ・ヒョンソン (Bae Hyun-sung / 배현성) が、表向きは完璧に見える模範生ナム・ジェヨプ (Nam Jae-yeop / 남재엽) を演じます。2026-11-23にTVING (Tving / 티빙) で独占配信されました (Ilgan Sports 2026-11-04)。NetflixやDisney+ではなく、TVINGのアプリで観ます。

② 配信を控えた5本 (2026年12月~2027年)

  • ゆっくり強烈に (Cheoncheonhi Gangryeolhage / 천천히 강렬하게) (Netflix、2026-12-11) — 何も持たないまま音楽業界で成功を追う人々の物語です (1960~80年代が舞台)。ソン・ヘギョ (Song Hye-kyo / 송혜교)、コン・ユ (Gong Yoo / 공유)、キム・ソルヒョン (Kim Seol-hyun / 김설현)、チャ・スンウォン (Cha Seung-won / 차승원)、イ・ハニ (Lee Ha-nee / 이하늬) が出演します。脚本はノ・ヒギョン (Roh Hee-kyung / 노희경)、演出はイ・ユンジョン (Lee Yoon-jung / 이윤정) です。Netflixは2026-10-22の公式発表で、2026-12-11 (金) 午後5時の配信を告げました。同じ発表文に、全世界に配信されると書かれています。英語タイトルは Tantara です。全22話を3回に分け、12月11日・18日・25日に配信します (What's on Netflix 2026-11-23)。12月に韓国にいるなら、毎週金曜の配信に合わせて観る方法もあります。
  • フルカウント (Pulkaunteu / 풀카운트) (SBS、2027年2月) — 野球コーチたちの物語を描くSBSの新しい金土ドラマです。キム・レウォン (Kim Rae-won / 김래원) が監督代行兼バッテリーコーチのファン・ジンホ (Hwang Jin-ho / 황진호)、パク・フン (Park Hoon / 박훈) が次期監督候補と目される投手コーチのチョ・ドンヒ (Jo Dong-hui / 조동희) を演じます。SBSが2027年2月の編成を確定しました (Ilgan Sports 2026-10-19)。
  • 悪夢 (Akmong / 악몽) (SBS、2027年) — 法で罰せない犯罪者に、刑務所の代わりに悪夢を設計してあげる物語です。キム・ナムギル (Kim Nam-gil / 김남길) が、長い潜入捜査を終えて南部署 (Nambu-seo / 남부서) に戻った刑事キム・テイ (Kim Tae-i / 김태이) を演じます。イ・ユミ (Lee Yu-mi / 이유미) は、被害者支援の警察官から「夢の設計者」になるチャン・ギュウン (Jang Gyu-eun / 장규은) を演じます。Ilgan Sportsは2026-03-18の記事で「2027年に初放送される」と報じました。
  • 偉大なパン・オクスク (Widaehan Bang Ok-suk / 위대한 방옥숙) (tvN、2027年上半期) — 住宅価格を守りたいマンションの婦人会と、再開発の利益を狙う組合長が対決する物語で、「おばさんノワール」と紹介されました。チョン・ドヨン (Jeon Do-yeon / 전도연) が婦人会の実力者パン・オクスク (Bang Ok-suk / 방옥숙)、パク・ヘス (Park Hae-soo / 박해수) が再開発組合長ユン・テウン (Yun Tae-ung / 윤태웅) を演じます。キム・ソニョン (Kim Sun-young / 김선영)、キム・グムスン (Kim Geum-sun / 김금순)、キム・グッキ (Kim Guk-hee / 김국희)、ペク・ヒョンジン (Baek Hyun-jin / 백현진) らも出演します。演出はキム・ヒョンシク (Kim Hyung-sik / 김형식)、脚本はイ・ギチョル (Lee Gi-cheol / 이기철) です。「2027年上半期に初放送」と報じられました (Ilgan Sports 2026-09-10)。
  • コリアンズ (Korieonjeu / 코리언즈) (Disney+、2027年) — アメリカのFXドラマ『ジ・アメリカンズ』を1990年のソウルのマンション団地に移したスパイドラマです。イ・ビョンホン (Lee Byung-hun / 이병헌) が韓国で10年暮らした北朝鮮の工作員キム・ミョンジュン (Kim Myeong-jun / 김명준)、ハン・ジミン (Han Ji-min / 한지민) が偽装夫婦であり一緒に南へ来た工作員ユン・ファギョン (Yun Hwa-gyeong / 윤화경) を演じます。隣に引っ越してきた強行犯係出身の対共捜査課の刑事チャ・ギソク (Cha Gi-seok / 차기석) は、イ・ヒジュン (Lee Hee-joon / 이희준) が演じます。演出はアン・ギルホ (Ahn Gil-ho / 안길호)、脚本はパク・ウンギョ (Park Eun-gyo / 박은교) です。Disney+が2027年の独占配信を公式に発表しました (Sports Kyunghyang 2026-03-25)。正確な月はまだ出ていません。
