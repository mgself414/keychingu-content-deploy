韓国丼注文・フェアワークフロー — ハン釜から明太子MZまで

ISSUE 03・#892・2026-06-09

🎯 なぜ丼ワークフローガイドなのか

[#891丼6種マトリックス](#891) 知っていても — 注文・ペアは別個。韓国丼は(a) チェーン弁当 (韓鍋・本弁当苗性比)外国人は（1）ハン釜・本弁当＝苛性雨 #1 わからない（2）明太丼＝MZインスタ モール（3）ランチ＝丼cluster #1 わからない。本ガイドは5-step+英語発話。

★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣チャンネル選択 チェーン弁当 / MZ韓国料理店 / 家庭料理 / 韓国料理即時
2️⃣メニュー注文 6種+サイド 1～5分ランチクラスター#1
3️⃣受信・設定 丼+局・おかず・卵5〜15分 アンビビギ（ボブウィメイン）
4️⃣食べる・ペア 丼+局+キムチ 15〜30分 韓国本物
5️⃣決済 カードOK /弁当=キオスク/チップX

総所要時間：チェーン＝15～30分／MZ＝30～60分／仮定式＝30～60分／限定式＝1～2h

🍚チャンネル別ワークフロー

Type A — チェーン弁当 (ハン釜・本弁当)

  • シグネチャー: コスパ #1・即時・キオスク
  • 時間: 10:00～22:00
  • 価格：6,000〜12,000ウォン
  • メニュー: 除肉・サバ・イムヨンス・小焼肉弁当
  • 外国人親和性: ★★★★★ (キオスク英語)

Type B — MZ 韓国料理レストラン（明太子・サーモン）

  • シグネチャー: MZトレンド・インスタ #1
  • 時間: 11:00～22:00
  • 価格：12,000〜25,000ウォン
  • メニュー：明太丼・サーモン丼・MZ変形
  • おすすめ店：弘大・江南・梨泰院・ソンス
  • 外国人親和性: ★★★★★ (MZ #1)

Type C — 仮定式白斑 ([#854](#854))

  • シグネチャー：ホームスタイル・コスパ
  • 時間: 11:00～22:00
  • 価格：8,000〜15,000ウォン
  • メニュー: 除肉・サバ・イムヨンス+国・おかず
  • 外国人親和性: ★★★★（コスパ）

Type D — 限定式・高級

  • シグネチャー：牛丼本物
  • 時間: 11:30～22:00
  • 価格：15,000〜35,000ウォン
  • メニュー: 牛肉・宮中本格
  • 外国人親和性: ★★★★

🌶外国人英語発話サンプル

  • "お肉丼1人" = "1 Jeyuk-deopbap (spicy pork rice bowl)"
  • "明陽丼" = "Myeongran-deopbap (pollock roe rice bowl - MZ#1)"
  • "スパイシー" = "Less spicy, please"
  • "キオスク英語" = "Kiosk has English option"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁なミス7つ

1. "ビビンバ=丼": ビビンバ=ビビギ/丼=アンビビン。

2. 「製育=一般」: 製育=苛性比#1。

3. 「明るさ=単価」：明るさ= MZインスタ#1。

4. "ハン釜・本弁当=ファースト":ハン釜=韓国料理cluster本物。

5. "ランチ=ビビンバのみ": ランチ=丼cluster#1。

6. "キオスク=韓国語": キオスク=英語 OK。

7. "アンビビン": 丼 = ご飯の上にメインそのまま。

⚙ よくある質問8件

1. 最初の丼=どんなチャンネル: チェーンハン釜・本弁当（コスパ比#1）→MZ（#1トレンド）。

2. インスタ・vlog：明太子（#1）。

3. MZ トレンド: 明太子・サーモン。

4. 苛性比: ハン釜・本弁当（#1）。

5. 高級: 限定式の牛肉。

6. アレルギー・妊娠: [#891 disclaimer](#891)参照。

7. 決済・チップ: カードOK/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

丼＝一般食品。妊婦・子ども＝OK（明るい塩味注意）。アレルギー（魚卵・シーフード・卵・醤油）事前告知。食中毒の疑いがある場合☎1339。

食事制限fallback：ハラール・コーシャ＝魚類・シーフードOK・豚X/ベジタリアン=非菜食/グルテン free=Tamari。
