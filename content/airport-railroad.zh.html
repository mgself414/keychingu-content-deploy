为什么是机场铁路 — 在韩国最先乘坐的列车

在仁川机场落地的外国人，大多数最先乘坐的公共交通就是机场铁路。从仁川机场T1·T2到首尔站 (Seoul Station / 서울역)，直达列车 (Express / 직통열차)约43~51分钟不停站直达，普通列车 (All-stop / 일반열차)则经停金浦机场 (Gimpo Airport / 김포공항)·弘大入口站 (Hongik Univ. Station / 홍대입구역)等站。这个第一选择，决定了入境第一天的动线。

本指南不做沿线观光，而是特化于入境第一天动线。① 直达 vs 普通，该坐哪个 ② 按住宿位置该在哪一站下车 ③ 下了车之后 T-money·SIM卡·行李怎么办 — 从到达闸口到住宿办理入住，一篇搞定。

直达 vs 普通 — 第一个选择

区分 直达列车 (Express / 직통열차) 普通列车 (All-stop / 일반열차)
区间 仁川机场 ⇄ 首尔站 不停站 每站停车
时间 约43~51分钟 约59~66分钟
票价 约₩11,000 (~$8)上下 约₩4,000~4,750 (~$3)左右
座位 全车指定席(有行李箱空间) 地铁式车厢·站席混杂
推荐 首尔站方向·行李多·求舒适 弘大 (Hongdae / 홍대)·孔德 (Gongdeok / 공덕)·金浦机场下车·高性价比

判断标准: 住宿在弘大·麻浦 (Mapo / 마포)一带，坐普通列车在弘大入口·孔德下车才是正解(直达只到首尔站)。住宿在首尔站·明洞 (Myeongdong / 명동)·市厅 (City Hall / 시청)圈则直达更省心。※票价·时间可能变动 — 乘车前请确认。

各站下车指南 — 在这里下车

✈️ #1. 仁川机场T1·T2 (Incheon Airport Terminals / 인천공항 T1·T2) — 出发点实务

  • 到达后顺序: 入境审查 → 提取行李 → T1 在B1交通中心 / T2 在地下交通中心乘坐 AREX
  • 离开机场前办妥: SIM卡/eSIM(#414 到达层柜台) · T-money 购买·充值(便利店) · 换钱/银行卡(#435 ATM) · 申请行李配送(#1232 柜台 — 先把行李寄到住宿，空手观光)
  • 🍜 吃: 机场美食广场·便利店(在韩国的第一碗杯面)
  • 外国人 tip: 直达列车车票在交通中心的售票机/柜台购买。普通列车刷 T-money 直接进站。

✈️ #2. 金浦机场站 (Gimpo Airport Station / 김포공항역) — 国内线·9号线急行换乘

  • 下车就是: 乐天购物中心金浦机场店 (Lotte Mall Gimpo Airport / 롯데몰 김포공항) — 购物·超市 · 国内线航站楼 — 转机济州 (Jeju / 제주)·釜山 (Busan / 부산)
  • 🔁 换乘: 9号线急行(#1247) — 快速前往汝矣岛 (Yeouido / 여의도)·江南 (Gangnam / 강남)·蚕室 (Jamsil / 잠실) · 5号线(#1244) · 金浦黄金线 (Gimpo Goldline / 김포골드라인)
  • 适合谁: 住宿在江南·蚕室(换乘9号线急行是捷径) · 国内线转机旅客

入境第一天动线场景 3

场景 1. 弘大住宿 (外国人最多)

  • 仁川机场乘普通列车 → 弘大入口下车(约50~55分钟) → 从3号出口去住宿办入住 → 京义线林荫道散步 + 延南吃晚餐
  • 要点: 别坐直达(会直接开到首尔站)。普通列车才是正解。

场景 2. 明洞·市中心住宿

  • 仁川机场乘直达列车 → 首尔站(43~51分钟·指定席) → 行李配送 or 乘4号线去明洞(#1243) → 办入住 → 明洞晚餐
  • 要点: 行李多的话，直达+首尔站行李配送的组合最轻松。

场景 3. 江南·蚕室住宿

  • 仁川机场乘普通列车 → 金浦机场下车 → 换乘9号线急行(#1247) → 新论岘 (Sinnonhyeon / 신논현)/奉恩寺 (Bongeunsa / 봉은사)/石村 (Seokchon / 석촌) → 办入住
  • 要点: 与其绕道首尔站，金浦机场换9号线急行才是捷径。

入境实务贴士 5 — 第一个小时内全部搞定

Tip 1. SIM卡/eSIM 在机场办好

到达层运营商柜台(#414)。eSIM 也可以在出发前在线购买。没有数据流量就用不了地图APP。

Tip 2. 一张 T-money 全搞定

在便利店购买·充值。机场铁路普通列车·地铁·公交全都用它。只有直达列车需要另外购票。

Tip 3. 行李先寄出去

在机场行李配送柜台(#1232)把行李寄到住宿，第一天就能空手观光。到达首尔站的话用首尔站柜台。

Tip 4. 直达/普通站台不同

在仁川机场交通中心，直达(橙色)和普通(蓝色)站台是分开的。认准指示牌。

Tip 5. 住宿位置决定坐哪趟车

弘大·麻浦=普通，首尔站·明洞=直达，江南=普通+金浦机场9号线急行。参考上面的3个场景。

FAQ 6 — 外国人常问的机场铁路问题

Q1. 直达和普通，该坐哪个?

  • 住宿位置说了算。弘大·麻浦=普通(弘大入口·孔德下车)，首尔站·明洞=直达，江南=普通+金浦机场9号线急行。参考上面的表格·场景。

Q2. 票价多少?

  • 直达约₩11,000 (~$8)·全车指定席 / 普通约₩4,000档 (~$3)·T-money。※可能变动 — 乘车前确认。

Q3. T-money 在哪买?

  • 在机场便利店购买·充值。普通列车·地铁·公交全部可用(#237)。只有直达列车需要另外购票。

Q4. 行李很多怎么办?

  • 用机场行李配送(#1232)先寄到住宿，或者坐直达列车(有行李箱空间·指定席)+首尔站行李配送。

Q5. 住弘大能坐直达吗?

  • 不推荐 — 直达一路不停直奔首尔站，弘大入口不停车。请坐普通列车。

Q6. 深夜到达怎么办?

  • 确认机场铁路末班车(午夜前后)。错过就坐深夜巴士(N6001等)·出租车。提前用地图APP查好时间。
