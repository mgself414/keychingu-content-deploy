외국인 광주 1일 메타 가이드 — ACC·무등산·5·18민주광장·송정역 4축

> 부제: 외국인 관광객용 광주 4축 시그니처 12선 + 1일 풀데이 + KTX 광주송정역 + 외국인 영문 발화

ISSUE 04 · #1026 · 2026-06-08

🎯 왜 광주 가이드인가

광주 (Gwangju) = 한국 #5 광역시·인구 145만·민주화 운동 1980 + ACC (국립아시아문화전당) 2014 + 무등산 1187m + 한식 1번지. 외국인 페인포인트 = (a) "광주 = 안 알려짐" 잘못된 인식 (b) 5·18 민주화 운동 (1980·전두환 군부) = 한국 민주주의 매트릭스 (c) ACC (2014~) = 아시아 #1 문화복합·외국인 매니아 매트릭스 (d) 무등산 = 1187m·국립공원·외국인 hiking (e) 한정식 한국 #1 매트릭스 (전라도 = 한국 #1 한식 본가) (f) KTX 광주송정역 1시간 30분.

본 가이드는 4축 12 시그니처 + 1일 풀데이 + 외국인 영문 발화·교통·결제.

🏛 4축 deep dive

① ACC (국립아시아문화전당·2014~)

  • 시그니처: 2014년~ 아시아 #1 문화복합·11.3만m²·아시아 문화·미술·공연 매트릭스
  • 외국인 친화도: ★★★★★ (영문 풀세트·MZ + 가족 매니아)
  • 시간: 09:00~18:00·휴관 월요일·무료 또는 5,000원 (특별전)
  • 추천: 어린이문화원 + 옛 도청 + 공연 = 2-3시간

② 무등산 (1187m·국립공원)

  • 시그니처: 광주 매니아 hiking·1187m·국립공원·서석대·입석대 주상절리
  • 외국인 친화도: ★★★ (영문 시그너·hiking 매니아)
  • 추천: 증심사 → 서석대 = 3-4h·매니아 코스 5-6h

③ 5·18 민주화 운동 매트릭스 (1980)

  • 시그니처: 1980년 5·18 민주화 운동·전두환 군부·한국 민주주의 매트릭스 #1
  • 장소: 5·18 민주광장 (옛 도청)·5·18 기념공원·박물관
  • 외국인 친화도: ★★★★★ (영문 풀세트·교육적·역사 매니아 #1)
  • 추천: 박물관 + 공원 + 광장 = 2-3시간·한국 매니아 매트릭스 필수

④ 한정식·시장 cluster (광주 = 한국 #1 한식 본가)

  • 시그니처: 광주 한정식·전라도 한정식 한국 #1 매트릭스·송정역시장·충장로
  • 외국인 친화도: ★★★★★ (영문 메뉴 일부·결제 카드)
  • 가격: 한정식 (1인) = 25,000~80,000원

⚠ 외국인 자주 실수 5가지

1. "광주 = 안 알려짐": 한국 #5 광역시·민주화 1980·ACC 2014·무등산·한정식 1번지.

2. "5·18 = 옛 일": 1980 민주화 운동 = 한국 민주주의 매트릭스 #1·외국인 매니아 필수.

3. "ACC = 일반 박물관": 아시아 #1 문화복합 2014~·11.3만m².

4. "한정식 = 어디서나 동일": 광주 = 한국 #1 한식 본가·전라도 한정식 매트릭스.

5. "무등산 = 일반 산": 1187m·국립공원·서석대·입석대 주상절리 = 한국 매트릭스 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: ACC + 5·18 + 한정식 + 양림동 = 1일 매트릭스.

2. 5·18 박물관 영문: 영문 풀세트·외국인 매니아 매트릭스 #1·교육적.

3. 광주 한정식: 5~7가지 반찬·전라도 한국 #1 매트릭스·25,000~80,000원/인.

4. 무등산 등산: 증심사 → 서석대 = 3-4h·매니아 코스 5-6h·영문 시그너 일부.

5. 시즌: 봄·가을 베스트·여름 폭염·겨울 영하 추위.

6. 추천 페르소나: 가족·시니어 = ACC + 한정식 / MZ·인스타 = 양림동 + 펭귄마을 / 매니아·역사 = 5·18 + 무등산.

⚠ 의료·안전·식이 disclaimer

ACC + 5·18 = 안전·평지·외국인 친화. 무등산 = 등산 + 가파른 경사·임신부·시니어·심장 환자 주의. 응급 ☎ 1339·1330·119.

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (KTX/항공 + 시내 핵심 4축 풀세트)
  • 예산: 100,000~180,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)·400,000~800,000원/4인 (1박)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
