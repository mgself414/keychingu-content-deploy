⚠ 외국인 자주 실수 5가지

1. "한국 스포츠 = 야구만": 한국 스포츠 = KBO 야구 (잠실) + K리그 축구 (FC서울) + e스포츠 LCK (#443) + 손흥민·이강인 글로벌 + 외국인 매니아 1번지.

2. "잠실 야구장 = 한국인만": 잠실 야구장 = 두산·LG 외국인 영어 OK + Klook·KKday 외국인 매니아 1번지 + #198·#356·#402 통합.

3. "K리그 = 인기 없음": K리그 = FC서울·수원·울산·전북 + 손흥민·이강인 매니아 (해외 리그) + 외국인 글로벌 매니아·#404 통합.

4. "외국인 응원 = 어려움": 한국 응원 = 외국인 매니아 1번지 + 응원 단가·치맥·외국인 친화 + #06 한강·#356 호텔 통합.

5. "외국인 스포츠 패키지 = 없음": 외국인 스포츠 = Klook·KKday·KTO 인증 + 영어 OK + 외국인 글로벌 매니아 풀세트 + #404·#387 통합.
