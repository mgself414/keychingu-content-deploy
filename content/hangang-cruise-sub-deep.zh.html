📍 汝矣岛游船 — E-Land Cruise·Seoul Cruise

E-Land Cruise 游轮 (이랜드크루즈) 汉江游船 (Hangang Yuramseon / 한강유람선)(永登浦区 (Yeoui-dong-ro 280 / 여의동로 280)，☎ 02-6291-6900)，是1986年10月26日首次通航的汉江游船。现在由E-Land Cruise Co., Ltd. 有限公司 (㈜이랜드크루즈) 运营汝矣岛和蚕室 (Jamsil / 잠실) 两个码头。有欣赏白天景色的 Story Cruise 故事游轮 (스토리크루즈)，欣赏夜景和盘浦大桥月光彩虹喷泉 (Banpo Daegyo Dalbit Mujigae Bunsu / 반포대교 달빛무지개분수) 的 Music Cruise 音乐游轮 (뮤직크루즈)，以及夜景加爵士乐演出的 Moonlight Cruise 月光游轮 (달빛크루즈)，还有船上自助餐 Lunch Buffet Cruise 午餐自助游轮 (런치 뷔페크루즈) 和 Dinner Buffet Cruise 晚餐自助游轮 (디너 뷔페크루즈)。

  • 开放时间:周一 15:00~22:00，周二~周日 11:00~22:00。须在出航前20分钟到达售票处。休息日:全年无休。
  • 观看年龄:全年龄。停车:可以。

Seoul Cruise 首尔游轮 (서울크루즈)(永登浦区 (Yeouido Hangang Gongwon-gil 231 / 여의도한강공원길 231)，☎ 1551-1132)，是1983年成立的现代游船 (Hyundai Yuramseon / 현대유람선) 在汝矣岛建设新码头后改名的游船公司。据观光公社介绍，它是韩国国内最早的海洋观光游船运营商，也是经阿拉船闸 (Ara Gapmun / 아라갑문) 连接汉江与阿拉水路 (Arabaetgil / 아라뱃길)、从汉江一路通航到西海 (Seohae / 서해) 的唯一客运·游船公司。运营汝矣岛游船码头 (Yeouido Yuramseon Teomineol / 여의도유람선터미널) 和阿拉金浦客运码头 (Ara Gimpo Yeogaek Teomineol / 아라김포여객터미널)。除了欣赏汉江景色的产品，周末还有经阿拉水路前往金浦 (Gimpo / 김포) 观赏烟花的 Dinner Fireworks Cruise 晚餐烟花游轮 (디너 불꽃 크루즈)。

  • 开放时间:视产品而定。休息日:全年无休。
  • 容纳人数:约800人。观看年龄:全年龄。停车:不可。

📍 盘浦 — Some Sevit·Some Sevit Tubester

Some Sevit 漂浮岛 (Sebitseom / 세빛섬)(瑞草区 (Olympic-daero 2085-14 / 올림픽대로 2085-14)，☎ 1566-3433)，是建在汉江上的综合文化空间。据观光公社介绍，它是在浮在水面的浮体上建造建筑物的世界首个漂浮建筑。由三座岛 Chaebit 岛 (채빛)·Solbit 岛 (솔빛)·Gabit 岛 (가빛)，以及放映影像·内容的媒体艺术画廊 Yebit 媒体艺术馆 (예빛) 组成。

  • 开放时间·休息日:视设施而定。停车:可以。

Some Sevit Tubester 水上项目 (Sebitseom Tubeuseuteo / 세빛섬 튜브스터)(同一地址，☎ 02-790-7090)，是在 Some Sevit 漂浮岛 (Sebitseom / 세빛섬) 乘坐游泳圈和小艇在水上玩耍的水上休闲项目。Tubester 水上项目 (튜브스터) 内有圆桌、LED灯和遮阳伞。

  • 开放时间:3~4月平日 15:00~23:00，周末·公休日 13:00~23:00。5~10月平日 16:00~24:00，周末·公休日 14:00~24:00。
  • 休息日:全年无休。天气恶劣时休息。

📍 游艇 — Sailing Paradise(汝矣岛)·现代游艇首尔店(盘浦)

汉江游艇之旅 (Hangang Yoteu Tueo / 한강요트투어) Sailing Paradise 帆船游艇 (세일링파라다이스)(永登浦区 (Yeoui-dong-ro 252 / 여의동로 252)，☎ 02-761-0120)，是在汉江乘坐帆船游艇的地方。与专业航海师同乘，可以欣赏都市夜景和自然风光。实行提前预约制，配有救生衣等安全设备。

  • 开放时间:10:00~22:00。休息日:全年无休。
  • 使用年龄:2岁以上。

现代游艇首尔店 (Hyundai Yoteu Seoul Jijeom / 현대요트 서울지점)(瑞草区 (Dongjak-daero 350 Banpo Hangang Gongwon The River / 동작대로 350 반포한강공원 더리버)，☎ 0507-1360-1976)，是体验游艇、小帆艇 (Dingi Yoteu / 딩기요트，没有引擎和船舱的1~3人用小型帆艇)、皮划艇等水上运动的地方。有游艇 Black Cat 游艇 (블랙캣) 和 Blue Jean 游艇 (블루진)，黄昏时分可以在水上观赏汉江和首尔楼群的日落。

  • 开放时间:12:00~21:00。休息日:每周一。
  • 停车:最初30分钟1,000韩元，每10分钟加收200韩元。

⚠ 行前须知 3 点

  1. 没有登记费用 — 六处都没有登记费用信息。
  2. E-Land Cruise 游轮 (이랜드크루즈) 周一较晚开始 — 周一从15:00，周二~周日从11:00开始，且须在出航前20分钟到达售票处。

⚙ FAQ 2

Q. 有夜景·演出的游船有哪些?

A. 按观光公社登记信息，有 E-Land Cruise 游轮 (이랜드크루즈) 的 Music Cruise 音乐游轮 (뮤직크루즈)(夜景·盘浦大桥月光彩虹喷泉) 和 Moonlight Cruise 月光游轮 (달빛크루즈)(夜景·爵士乐演出)。Seoul Cruise 首尔游轮 (서울크루즈) 周末有经阿拉水路前往金浦观赏烟花的 Dinner Fireworks Cruise 晚餐烟花游轮 (디너 불꽃 크루즈)。

Q. 可以乘船或体验水上休闲的地方有哪些?

A. Sailing Paradise 帆船游艇 (세일링파라다이스)(与专业航海师同乘帆船游艇，2岁以上，提前预约)、现代游艇首尔店 (Hyundai Yoteu Seoul Jijeom / 현대요트 서울지점)(游艇·小帆艇·皮划艇)、Some Sevit Tubester 水上项目 (Sebitseom Tubeuseuteo / 세빛섬 튜브스터)(游泳圈·小艇)。
