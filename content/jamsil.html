외국인이 자주 하는 실수 5가지

1. 롯데월드 + 롯데타워 같은 곳이라는 오해

롯데월드 = 테마파크 (어드벤처·매직아일랜드) / 롯데타워 = 123층 빌딩 (전망대·면세점) / 롯데월드몰 = 쇼핑몰. 셋 다 잠실역에 인접하지만 별도 입장료. 풀세트 ₩80,000~120,000.

2. 롯데월드 어드벤처 + 매직아일랜드 구분 못 함

  • 어드벤처 = 실내 + 일부 실외 (날씨 영향 적음)
  • 매직아일랜드 = 석촌호수 위 야외 (롯데월드 안에 포함)
  • 자유이용권 ₩66,000~ = 둘 다 OK / 어드벤처 단독 ₩59,000

3. 롯데타워 전망대 시간 잘못 잡는 것

Seoul Sky 전망대 (117~123층) = ₩31,000. 일몰 시간 ±30분이 베스트 — 낮 풍경 + 야경 모두 가능. 평일 오후 4~6시 방문 권장.

4. 석촌호수 무료라는 걸 모름

석촌호수 산책 = 무료. 봄 벚꽃, 가을 단풍, 일루미네이션 모두 무료. 롯데월드 입장 안 해도 야외 + 호수 풍경만으로도 1순위.

5. 잠실 외 동선 연결 안 짜는 것

잠실은 강남 동쪽 끝 — 강남·명동까지 지하철 30분~1시간. 잠실 1일 풀데이 후 다른 동네 X. 잠실 단독 또는 가락시장·올림픽공원 등 인접만.

FAQ

Q1. 영어 통하나요?

롯데월드·롯데타워·롯데월드몰 = 영어·중국어·일본어 가이드. 가락시장·송리단길은 한국어 위주이지만 사진 메뉴 OK.

Q2. 가족·어린이?

롯데월드·석촌호수·롯데월드몰 = 가족 1순위. 휠체어·유모차 대여·놀이방·기저귀 교환실 모두 완비.

Q3. 시간 1일뿐?

롯데월드 (10~17시) + 석촌호수 (17~18시) + 롯데타워 (19~21시) = 풀데이 정답.

Q4. 가격 부담?

석촌호수 무료 + 롯데월드몰 무료 + 야간 롯데월드 ₩47,000 = 가성비.

Q5. 비·눈 오면?

롯데월드 어드벤처 (실내) + 롯데월드몰 + 롯데타워 (실내) = 비·눈 영향 없음.

Q6. 다른 동네 연결?

잠실 = 동쪽 끝. 가락시장·올림픽공원 (도보·지하철 10분) OK. 강남·명동은 지하철 30분~1시간.
