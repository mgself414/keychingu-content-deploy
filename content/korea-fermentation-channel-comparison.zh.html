🎯 #1 按细分市场推荐

  • 第二优先：免税店（含回礼）
  • 第三名：工厂参观（体验/MZ）
  • 避免：Martman（气氛↓）

  • 第三优先：免税店（含回礼）

🏺 4 通道深度挖掘

🏺 藏德台村体验（遗产村）

核心价值观：正统+经验/教育+外国人Instagram第一视频博客。

  • 推荐村庄：
  • 顺昌长流村（全北）——传统红辣椒酱的故乡（地理标志、传统食品大师）
  • 潭阳长德台（全罗南道）— 东正教
  • 昌德宫（首尔）——朝鲜王朝的正宗宫廷美食（国家级非物质文化遗产第38号）
  • 体验菜单：制作大酱、制作豆酱、品尝、购买
  • 体验费：20,000~80,000韩元/人（1~3小时）
  • 外国人友善度：★★★（专注韩语，体验vlog）
  • 交通：距离全州（淳昌）、首尔市中心（昌德宫）1小时车程

🏢 张工厂·品牌直营

核心价值观：品牌信任+工厂参观+外国人英语OK。

  • 推荐品牌：
  • CJ CheilJedang Haechandle — 韩国#1市场份额和全球扩张
  • 目标忠清原·淳昌 — 韩国#2市场份额
  • Sempio — 酱油专卖店（1946 年老店）
  • Dongwon — 酱油和炖菜
  • 菜单：6 件全套/高级系列
  • 价格锚：KRW 12,000~30,000/kg
  • 外国人友好度：★★★★（CJ Global，英语）
  • 付款：刷卡即可
  • 营业：09:00~18:00（直营分店）

🛒 玛特·超市

核心价值：性价比+品牌多样+日常购物。

  • 推荐商店：
  • 易买得 — 韩国#1市场份额
  • 乐天玛特 — 韩国 #2
  • Homeplus — 成本效益
  • Nonghyup Hanaro Mart - 来自生产商的真实、直接交易
  • 菜单：6种不同品牌+自有PB
  • 价格锚：KRW 8,000~25,000/kg
  • 外国人友好度：★★★（针对外国人的部分信息）
  • 付款：刷卡即可
  • 运营：10:00~22:00

✈️免税店·机场

核心价值观：回礼#1+增值税退税+英文+真空包装。

  • 推荐免税店：
  • 仁川机场免税店 — 供在韩国的外国人使用#1
  • 金海机场/济州机场免税店 — 地区
  • 市中心免税店（乐天、新罗、新世界）— 市中心提货/机场提货
  • 菜单：6种高级/真空包装（返校礼物）
  • 价格锚：KRW 15,000~50,000/kg（免税+保费）
  • 外国人友好性：★★★★★（英语，第一优先，免税）
  • 付款：卡 + 增值税退税 + 免税
  • 运营：24小时（机场）/城市=营业时间
  • 托运行李：真空包装可以（液体分类/随身携带 X）

⚠ 外国人常犯的5个错误

1. “4个渠道=类似”：价格、体验、增值税完全不同。性价比=超市/正品=章德台/品牌=工厂/免税=免税店。

2. “藏德台村 = 仅限韩国人”：纯昌·潭阳 = 欢迎外国人（vlog #1）。一些英文说明。

3. “免税店=正价”：免税店=退税+保费。正常价格+折扣节省。

4. **》Mart=老外性价比★。

5. “真空包装=随处可见”：真空包装店= 免税店、部分超市、章德台村（提前确认）。

⚙ 8 个常见问题解答

1. 第一次发酵食品=任何渠道：免税店（回国前） 第一名（简单，退税）。

2. Insta·vlog：纯昌长流村#1·昌德宫长高·CJ全球趋势。

3. 与家人一起：长德台村体验（儿童教育）+超市（性价比高）。

4. MZ趋势：Jangdokdae Village Instagram、CJ Global、松露辣椒酱。

5. 增值税退税：免税店 = 可退税 / 杂货店 = 退税 X.

6. 过敏·怀孕：参见#849·#850免责声明。

7. 付款/小费：卡可以很多/ Jangdokdae Village =一些现金/小费

8. 随身携带：行李=液体·仅限托运行李。提前检查您所在国家/地区的规定。

⚠ 医疗/安全/饮食免责声明

发酵食品=普通食品。 谨防高盐（黄豆酱、辣椒酱、酱油、咸鱼）——高血压、肾病患者慎用。孕妇=适量清酒酱和强发酵食品。儿童=清国酱和咸鱼爱好者请注意进入市场。过敏（大豆、海鲜、水果）需提前通知。食物中毒/食物报告=☎1399（食品药品安全部）/医疗紧急情况=☎1339（医疗、英语）。本指南是一般信息，并非医疗建议。

长期存在的商店/商店信息的免责声明：Jangdokdae村、工厂、超市和免税店的运营变化 - 访问前请检查NAVER/Kakao地图或官方网站。

随身携带/随身携带：长度=仅液体/托运行李。提前检查您所在国家/地区的法规（澳大利亚/新西兰=食品进口限制）。

饮食限制后备：

  • 清真/犹太洁食：豆酱、红辣椒酱、酱油、醋 = 可以 / Jeotgal = 非清真 / Cheonggukjang = 可以（仅限大豆）。
  • 素食/纯素食：豆酱、红辣椒酱、酱油、醋、清国酱 = OK / Jeotgal = 非素食。
  • 不含麸质：普通酱油/红辣椒酱 = 麸质 X / 酿造酱油 = 含有小麦（需要确认）。
