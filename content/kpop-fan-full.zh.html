K-pop粉丝完整指南 — 外国BTS·BLACKPINK粉丝深度探索12大景点

🎯 为什么是K-pop粉丝完整指南

K-pop粉丝入境游是韩国第一大旅游类别。BTS、BLACKPINK、NewJeans、IVE等全球粉丝深度探索的首选。#19 K-pop追星后续整合完整指南。

★ 12大景点一览

⚠ 外国游客常犯的3个错误

1. “K-pop商店=只有明洞”: 除了明洞 (Myeongdong / 명동)，龙山 (Yongsan / 용산) HYBE·江南 (Gangnam / 江南) SM Town·合井 (Hapjeong / 합정) YG·江东 (Gangdong / 강동) JYP四大总部完整套餐才是真正的深度探索。

2. “总部=不能进去”: HYBE INSIGHT (Yongsan / 龙山)·SM Town COEX Artium (Gangnam / 江南) = 外国游客自由入场 + 周边商品店 + 咖啡馆。总部大楼外观是绝佳的拍照点。

3. “演唱会=很贵”: 除了演唱会，K-pop舞蹈课 (弘大 (Hongdae / 홍대) 1MILLION等)·K-pop咖啡馆 (YG·SM合作)·KARTS韩国第一K-pop培养机构参观也OK。

① 总部·经纪公司 (5)

1. HYBE总部 (Yongsan / 龙山) ★ BTS第一总部

  • 地址: 龙山区 (Yongsan-gu / 용산구) 汉江大路 (Hangang-daero / 한강대로) 42号 (#187 龙山 (Yongsan / 용산))
  • 外国游客推荐指数: ◎◎ — BTS·NewJeans·LE SSERAFIM·SEVENTEEN·TXT
  • 特色: HYBE INSIGHT (地下周边商品店 + 外国游客自由入场) + 总部外观拍照点
  • 营业时间: INSIGHT 10:30~20:00 (10:30 AM to 8:00 PM)

2. SM Town COEX Artium (Gangnam / 江南)

  • 地址: 江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513号 COEX (2号线 三成站 (Samseong Station / 삼성역))
  • 外国游客推荐指数: ◎◎ — aespa·EXO·NCT·Red Velvet·SHINee
  • 特色: 6楼SM整合 + 周边商品店 + 现场全息模拟器 + SM咖啡馆·博物馆

3. YG Entertainment总部 (Mapo / 麻浦·Hapjeong / 合井)

  • 地址: 麻浦区 (Mapo-gu / 마포구) 杨花路 (Yanghwa-ro / 양화로) 16号 (2号线 合井站 (Hapjeong Station / 합정역)) (#188 麻浦 (Mapo / 마포) 姐妹)
  • 外国游客推荐指数: ◎ — BLACKPINK·BIGBANG·iKON·TREASURE
  • 特色: 总部外观拍照点 + YG The Same Café邻近

4. JYP Entertainment总部 (Gangdong / 江东)

  • 地址: 江东区 (Gangdong-gu / 강동구) (8号线 江一站 (Gangil Station / 강일역) 附近)
  • 外国游客推荐指数: ◎ — TWICE·Stray Kids·ITZY·DAY6
  • 特色: 总部外观 + 外国粉丝拍照点

5. KARTS (韩国艺术综合学校, Seokgwan / 石串)

  • 地址: 城北区 (Seongbuk-gu / 성북구) 石串 (Seokgwan / 석관) (4号线 石溪站 (Seokgye Station / 석계역))
  • 外国游客推荐指数: ○ — 韩国第一K-pop·艺术培养机构
  • 特色: 韩国第一国立艺术学校 + 培养众多K-pop偶像 + 毕业公演

② 商店·活动 (4)

6. COEX K-pop广场 (Gangnam / 江南)

  • 地址: 江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513号 COEX Mall
  • 外国游客推荐指数: ◎◎ — SM·LCT·LINE FRIENDS·SMTOWN整合
  • 特色: COEX综合K-pop商店街 + 现场活动 + 签名会

7. LINE FRIENDS 明洞·弘大

  • 地址: 中区 (Jung-gu / 중구) 明洞 (Myeongdong / 명동) + 麻浦区 (Mapo-gu / 마포구) 弘大 (Hongdae / 홍대)
  • 外国游客推荐指数: ◎ — BT21 (BTS) + LINE FRIENDS
  • 特色: 韩国第一卡通形象店 + 外国游客Instagram打卡首选

8. Kakao Friends 江南·弘大

  • 地址: 江南 (Gangnam / 江南)·弘大 (Hongdae / 홍대) 店
  • 外国游客推荐指数: ◎ — Ryan·Apeach·Tube·Muzi
  • 特色: 韩国第一Kakao卡通形象店

9. HYBE INSIGHT (Yongsan / 龙山) ★ BTS粉丝第一站

  • 地址: 龙山区 (Yongsan-gu / 용산구) 汉江大路 (Hangang-daero / 한강대로) 42号 HYBE总部地下
  • 外国游客推荐指数: ◎◎ — BTS·HYBE周边商品第一站
  • 特色: BTS·NewJeans·LE SSERAFIM·SEVENTEEN·TXT综合周边商品店

③ 咖啡馆·主题 (3)

10. YG The Same Café (Hongdae / 弘大 Hapjeong / 合井)

  • 外国游客推荐指数: ◎ — BLACKPINK主题
  • 特色: YG偶像主题咖啡馆 + 周边商品结合

11. SM SUM Café & Artium (Gangnam / 江南)

  • 外国游客推荐指数: ◎ — SM偶像咖啡馆整合
  • 特色: 江南 (Gangnam / 江南) SM Town内部 + 周边商品结合

12. MUSINSA Standard 明洞

  • 外国游客推荐指数: ◎ — 韩国第一K-pop·MZ时尚第一站
  • 特色: K-pop偶像造型师合作服装

④ 额外4个景点

  • COEX水族馆 + 星空图书馆 (Starfield Library / 별마당 도서관) (Gangnam / 江南)
  • DDP音乐厅 (#172) — K-pop新歌发布舞台
  • 奥林匹克公园 (Olympic Park / 올림픽공원) K-pop演唱会 (#82) — 88首尔奥运会体操竞技场 (88 Seoul Olympics Gymnastics Arena / 88서울올림픽 체조경기장) = 韩国第一演唱会场
  • INSPIRE K-pop音乐节 (Yeongjongdo / 永宗岛, 2023~) — 韩国第一K-pop音乐节

⚙ 6个常见问题

1. 四大总部外国游客入场: HYBE INSIGHT·SM Town COEX = 自由入场 + 免费。YG·JYP总部外观拍照点。

2. K-pop演唱会预订: Interpark (인터파크)·YES24 (예스24) (英文UI)。外国游客支付OK。

3. K-pop舞蹈课: 弘大 (Hongdae / 홍대) 1MILLION Dance Studio + 江南 (Gangnam / 江南) 舞蹈学院 (外国游客OK)。

4. 周边商品店推荐: HYBE INSIGHT + SM Town + LINE FRIENDS·Kakao Friends 明洞 (Myeongdong / 명동)。

5. K-pop咖啡馆季节限定: SM·YG·HYBE新歌主题咖啡馆季节限定运营。

6. 外国粉丝一日游路线: HYBE INSIGHT (Yongsan / 龙山) → SM Town COEX (Gangnam / 江南) → COEX K-pop广场。

🗺 一日游路线

A. K-pop总部全天游: 10:00 HYBE INSIGHT (Yongsan / 龙山) → 13:00 SM Town COEX (Gangnam / 江南) → 16:00 YG总部 (Hapjeong / 合井) → 19:00 LINE FRIENDS 弘大 (Hongdae / 홍대)
