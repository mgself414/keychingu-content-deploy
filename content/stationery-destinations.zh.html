外国游客常犯的3个错误

1. 误以为“去大创 (Daiso / 다이소) 就够了”

大创 (Daiso / 다이소) 确实性价比第一，但日记本种类仅限30~50种。而10x10 (Tenbyten / 텐바이텐)、教保文库 (Kyobo Mungo / 교보문고)、永丰文库 (Youngpoong Mungo / 영풍문고)拥有200多种韩国设计日记本，对于真正的设计爱好者来说，只去大创 (Daiso / 다이소) 是远远不够的。

2. 错过日记本季 (10~12月)

韩国的9月~12月是日记本新品上市 + 限量版季节。1~2月时，热门日记本和笔几乎售罄。如果专程来韩国购买日记本，秋季是最佳时机。

3. 误以为仁寺洞 (Insadong / 인사동) 是所有传统文具的答案

仁寺洞 (Insadong / 인사동) 的优势在于传统韩纸 (Hanji / 한지)、毛笔、书法工具，但日记本、笔类、设计文创则相对较弱。如果只去仁寺洞 (Insadong / 인사동) 购买日记本或钢笔，可能会白跑一趟 — 光化门 (Gwanghwamun / 광화문) 的教保文库 (Kyobo Mungo / 교보문고) 或江南 (Gangnam / 강남) 的永丰文库 (Youngpoong Mungo / 영풍문고) 和莫里斯 (Morris / 모리스) 才是正确选择。

① 教保文库 光化门店 (Kyobo Mungo Gwanghwamun / 교보문고 광화문점) — 韩国日记本·笔类的综合大本营

位置: 首尔 钟路区 (Jongno-gu / 종로구) 钟路 (Jongno / 종로) 1号，教保生命大厦 (Kyobo Life Building / 교보생명빌딩) B1 — 地铁5号线 光化门站 (Gwanghwamun Station / 광화문역) 4号出口直达

为何选择这里:

  • 韩国最大的书店，光化门店 (Gwanghwamun / 광화문점) B1整层都是书籍+文具
  • 200多种日记本+ / 1,000多种笔类可供一站式比较
  • 店内设有笔墨坊 (Pen Showroom / 글방) — 可试写钢笔、走珠笔、墨水

必购品类 (2026年4月为准):

  • 韩国设计日记本: 莫特莫特 (Motemote / 모트모트)·靛蓝 (Indigo / 인디고)·阿尔特 (Arte / 아르테) (₩15,000~30,000)
  • 书法笔: 樱花 (Sakura / 사쿠라)·海豚 (Dolphins / 돌핀스) (₩2,000~10,000/支)
  • 英文版韩国设计笔记本: 莫特莫特 (Motemote / 모트모트) 英文系列 (₩12,000~25,000)
  • K-Book英文译本: 韩国文学·小说英文版 (₩15,000~25,000)
  • 韩纸 (Hanji / 한지) 卡片 + 书签: ₩2,000~8,000

小贴士:

  • 营业时间: 09:30~22:00
  • 办理外国人会员卡 → 5% 折扣 + 积分
  • 深入B1，有限量版·作家联名专区
  • 单笔收据金额 ₩30,000+ 可在店内即时办理退税

② 永丰文库 钟阁钟路总店 (Youngpoong Mungo Jonggak Jongno / 영풍문고 종각종로본점) — 进口文具的强者

位置: 首尔 钟路区 (Jongno-gu / 종로구) 清溪川路 (Cheonggyecheon-ro / 청계천로) 41号 永丰大厦 (Youngpoong Building / 영풍빌딩) B1~B2 — 地铁1号线 钟阁站 (Jonggak Station / 종각역) 4号出口步行1分钟

为何选择这里:

  • 如果说教保文库 (Kyobo Mungo / 교보문고) 强项是韩国日记本，那么永丰文库 (Youngpoong Mungo / 영풍문고) 则是进口文具的强者 — 日本无印良品 (MUJI / 무인양품)·Midori (미도리)·Kokuyo (코쿠요)·LIFE (라이프)，德国Lamy (라미)·Faber-Castell (파버카스텔)
  • B1~B2两层空间。B2是文具·笔记本区
  • 外国游客熟悉的国际品牌 + 韩国限定联名款

必购品类:

  • Midori (미도리) 旅行者笔记本 (含韩国限定颜色): ₩30,000~80,000
  • Lamy (라미) Safari (사파리) 钢笔: ₩40,000~70,000 (许多情况下比海外便宜)
  • 德国Leuchtturm1917点阵笔记本: ₩28,000~35,000
  • 日本Kokuyo (코쿠요) Campus (캠퍼스) 笔记本 (韩国限定设计): ₩3,000~8,000
  • 日常日记本英文版: ₩15,000~30,000

小贴士:

  • 营业时间: 10:00~22:00
  • 江南 (Gangnam / 강남) COEX店 (코엑스점) 规模相当 — 如果行程在江南 (Gangnam / 강남)，推荐COEX店 (코엑스점)
  • 进口文具新品每年仅上架一次 (秋季·春季) — 错过季节需等待下次上架

③ 10x10 弘大店 (Tenbyten Hongdae / 텐바이텐 홍대) — 设计文创集合店首选

位置: 首尔 麻浦区 (Mapo-gu / 마포구) 弘大 (Hongdae / 홍대) 偶来广场路 (Eoulmadang-ro / 어울마당로) 138号 — 地铁2号线 弘大入口站 (Hongik University Station / 홍대입구역) 8号出口步行5分钟 (大学路店 (Daehangno / 대학로점) 也有运营)

为何选择这里:

  • 韩国设计集合店的鼻祖 — 1999年线上起步，线下门店是外国游客的首选
  • 韩国插画师·设计师联名笔记本种类繁多
  • 卡通 (Kuromi / 쿠로미·Chiikawa / 치이카와·My Melody / 마이멜로디 韩国限定联名) + 设计日记本兼具

必购品类:

  • 韩国设计师联名笔记本: ₩8,000~20,000
  • 卡通日记本 (韩国限定): ₩15,000~30,000
  • 插画便签·贴纸套装: ₩3,000~10,000
  • 旅行·日记本为主的便携尺寸: ₩10,000~20,000
  • 环保纸笔记本 (韩国设计): ₩8,000~15,000

小贴士:

  • 营业时间: 11:00~22:00 (弘大店 / Hongdae / 홍대점)
  • 与大创 (Daiso / 다이소) 比较: 大创 (Daiso / 다이소) 卡通产品 ₩1,000~3,000 / 10x10 (Tenbyten / 텐바이텐) 设计产品 ₩8,000~20,000 — 价格与设计策展的权衡
  • 店内畅销区可快速找到韩国Instagram (인스타) 热门日记本

④ ARTBOX 明洞店 (ARTBOX Myeongdong / 아트박스 명동점) — 艺术·文具·杂货综合

位置: 首尔 中区 (Jung-gu / 중구) 明洞街 (Myeongdong-gil / 명동길) 14号 — 地铁4号线 明洞站 (Myeongdong Station / 명동역) 6号出口步行2分钟

为何选择这里:

  • 韩国本土设计杂货连锁店。明洞店 (Myeongdong / 명동점) 的外国游客销售额占比高
  • 艺术周边 + 文具 + 卡通 + 家居饰品一店尽有
  • 价格介于大创 (Daiso / 다이소) (低) 和10x10 (Tenbyten / 텐바이텐) (中) 之间 — 价格适中且有设计感

必购品类:

  • 韩国插画笔记本·日记本: ₩5,000~18,000
  • 卡通钥匙扣·贴纸: ₩3,000~8,000
  • 生活方式杂货 (包·收纳袋): ₩10,000~30,000
  • 韩国设计和纸胶带: ₩2,000~5,000
  • 迷你艺术海报: ₩5,000~15,000

小贴士:

  • 明洞店 (Myeongdong / 명동점)·弘大店 (Hongdae / 홍대점)·江南店 (Gangnam / 강남점) 产品线基本相同。可根据行程选择
  • 日记本季 (10~12月) 会有限定版策展专区

⑤ 莫里斯 江南店 (Morris Gangnam / 모리스 강남) — 钢笔·专业笔类圣地

位置: 首尔 江南区 (Gangnam-gu / 강남구) 一带 江南站 (Gangnam Station / 강남역) 一带 (建议在官方网站或Naver地图 (네이버 지도) 搜索准确店铺信息)

为何选择这里:

  • 韩国钢笔爱好者的麦加。Lamy (라미)·Pelikan (펠리칸)·Pilot (파일럿)·Sailor (세일러) 等全球钢笔综合店
  • 设有试写台 — 可直接蘸墨试写后购买
  • 韩国拥有最多种钢笔墨水颜色 (300+ SKU)

必购品类:

  • Lamy (라미) Safari (사파리)·AL-star (알스타): ₩40,000~80,000
  • Pilot (파일럿) Kakuno (카쿠노)·Metropolitan (메트로폴리탄): ₩30,000~60,000
  • Pelikan (펠리칸) Classic M200·M205: ₩200,000+

  • 墨水样品5ml套装: ₩5,000~15,000

  • 韩国墨水品牌 — WAESL (와사라)、Forever Pen — 仅在韩国有售的颜色
  • 建议试写后购买。钢笔选择适合手感的笔尖很重要

⑥ 湖美画房 仁寺洞 (Homi Hwabang Insadong / 호미화방 인사동) — 传统画材店 + 书法

位置: 首尔 钟路区 (Jongno-gu / 종로구) 仁寺洞 (Insadong / 인사동) 一带 — 地铁3号线 安国站 (Anguk Station / 안국역) 6号出口步行5分钟

  • 传统毛笔·墨·韩纸 (Hanji / 한지)·颜料·书法工具一站式购齐

  • 韩国传统毛笔 (虎笔 (Hopil / 호필)·狼毫笔 (Nanghopil / 낭호필)): ₩5,000~80,000
  • 墨·墨汁·砚滴套装: ₩10,000~50,000
  • 韩纸 (Hanji / 한지) (多种颜色·厚度): ₩1,000~10,000/张
  • 书法用宣纸捆: ₩15,000~40,000

外国游客常见问题

Q1. 什么时候去买日记本最好？

10月中旬~12月中旬。9月开始部分新品上架，10月中旬开始限量版正式发售，12月中旬前热门款会售罄。1~2月很遗憾几乎都已售罄。

Q2. 在国外买不到韩国日记本吗？

部分品牌 (莫特莫特 (Motemote / 모트모트)·Midori (미도리)) 提供全球邮寄，但限量版仅限韩国门店购买。此外，退换货不便，亲自购买更稳妥。

Q3. 第一次买钢笔，从哪里开始？

在莫里斯 江南店 (Morris Gangnam / 모리스 강남) 试写台从Lamy (라미) Safari (사파리) (₩40,000) 或Pilot (파일럿) Kakuno (카쿠노) (₩30,000) 开始。太便宜的墨水流动不稳定，太贵的 (₩200,000+) 作为第一支钢笔负担较大。

Q4. 韩纸 (Hanji / 한지)·毛笔带回本国会有问题吗？

韩纸 (Hanji / 한지)·毛笔在飞机托运/随身携带都OK。但墨汁 (墨水) 属于液体 — 只能托运。书法用的大瓶墨水需做好安全包装。

Q5. 哪些门店可以用英语结账·咨询？

教保文库 光化门 (Kyobo Mungo Gwanghwamun / 교보문고 광화문) / 永丰文库 (Youngpoong Mungo / 영풍문고) / 10x10 弘大 (Tenbyten Hongdae / 텐바이텐 홍대) / ARTBOX (아트박스) / 无印良品 (MUJI / 무인양품): 英语OK。湖美画房 (Homi Hwabang / 호미화방)·钟路文具街 (Jongno Mungu Street / 종로 문방구 거리): 主要使用韩语。

Q6. 日记本有英文印刷版吗？

莫特莫特 (Motemote / 모트모트)·靛蓝 (Indigo / 인디고) 运营英文系列。可在教保文库 光化门 (Kyobo Mungo Gwanghwamun / 교보문고 광화문) 确认库存。国际品牌 (Midori (미도리)·Leuchtturm) 均为英文。

Q7. 大创 (Daiso / 다이소) vs 10x10 (Tenbyten / 텐바이텐) vs ARTBOX (아트박스) 有何不同？

  • 大创 (Daiso / 다이소): ₩1,000~3,000 / 卡通·纪念品用 / 参照 #52
  • ARTBOX (아트박스): ₩5,000~18,000 / 设计+卡通 / 价格·设计均衡
  • 10x10 (Tenbyten / 텐바이텐): ₩8,000~25,000 / 韩国新锐设计师联名 / Instagram (인스타) 热门
  • 如果真心喜欢日记本，选10x10 (Tenbyten / 텐바이텐) 或教保文库 (Kyobo Mungo / 교보문고)；如果追求性价比，选大创 (Daiso / 다이소)。

Q8. 在哪里可以办理退税？

教保文库 (Kyobo Mungo / 교보문고)·永丰文库 (Youngpoong Mungo / 영풍문고)·ARTBOX (아트박스)·10x10 (Tenbyten / 텐바이텐)·无印良品 (MUJI / 무인양품): 店内即时退税。莫里斯 (Morris / 모리스)·湖美画房 (Homi Hwabang / 호미화방)·钟路4街 (Jongno 4-ga / 종로4가): 根据门店情况可能有所变动 — 结账前请确认。

季节性注意事项

春季 (3~5月)

  • 进口文具春季新品上架 (永丰文库 (Youngpoong Mungo / 영풍문고)·教保文库 (Kyobo Mungo / 교보문고)) — 4月最佳
  • 新学期韩国学生文具批发街人潮涌动

夏季 (6~8月)

  • 日记本淡季 — 几乎没有新品
  • 门店人少，是试写·体验的好时机

秋季 (9~11月)

  • 日记本新品大量发布 (10月中旬开始)
  • 教保文库 (Kyobo Mungo / 교보문고)·10x10 (Tenbyten / 텐바이텐) 限量版策展专区
  • 外国日记本爱好者首选季节

冬季 (12~2月)

  • 12月中旬前仍可购买最后批次的限量版
  • 1~2月等待下一季 — 此时钢笔·书法工具是不错的选择
