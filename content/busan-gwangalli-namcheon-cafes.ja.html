釜山クァンアルリ・ナムチョン・スヨンのカフェ12軒 — 外国人レビューが三言語で先に残った店だけ

サブタイトル: チョンポ(#246・#1321)とヨンド(#1321)、デザートロード(#1324)が空けておいた軸——クァンアン大橋の裏路地・ナムチョン海辺通り・スヨンの路地・ミルラクの水辺・ファンリョンサンの夜景。Naverマップに英語・日本語・中国語のレビューがそろって残るカフェだけを12軒選び、4エリアにまとめて半日の動線でつないだ。店内ルール(席取り・マグカップ・返却台)は#1378。

ISSUE 06 · #1381 · 2026-09-17 · 釜山カフェシリーズ 第4弾

🎯 なぜ「三言語レビュー」が基準なのか

釜山のカフェ編はすでに三本あります——チョンポカフェ通り (Jeonpo / 전포카페거리, #246)、『チャンピオンの街でコーヒーを飲む方法』(#1321)、『小豆からジェラートまで』(#1324)。ところが外国人レビューのデータをもう一度洗い直すと、釜山のカフェ81軒のうち72軒がどの回にも登場しておらず、その半数近くがスヨン区 (Suyeong District / 수영구)——クァンアルリ (Gwangalli / 광안리)・ナムチョン (Namcheon / 남천)・スヨン (Suyeong / 수영)・ミルラク (Millak / 민락)——に集中していました。今回はその空白を埋める回です。

選定基準はひとつだけです——Naverマップに英語・日本語・中国語のレビューがそろって残るカフェ。韓国人の人気ランキングではなく、すでに外国人が訪れて三言語で足跡を残した場所こそ、次の外国人旅行者にとって最も安全な選択だという判断です。レビュー数は2026年9月時点のスナップショットで、この回では店ごとにその数を記載しました。

⚠ 表記の原則：営業時間・定休日・メニューは公開情報源で確認できたものだけを記載し、未確認の項目は「Instagramで確認」としました。駅からの徒歩時間はエリア単位の徒歩圏のみを記載しています——個別の店までの分数は、その場でNaverマップの徒歩案内を見るほうが正確です。カフェ利用ルール(席取り・マグカップ・返却台)は#1378。

① クァンアルリ裏路地 — 4軒

クァンアルリのビーチロードから一本入ると路地になります。地下鉄クァンアン駅 (Gwangan Station / 광안역)・クムニョンサン駅 (Geumnyeonsan Station / 금련산역)(2号線)の徒歩圏です。

  • ノアブルワーズ — フィルターコーヒー専門のロースタリーです。ノアブレンドとエチオピアのシングルオリジン、ロングブラックが看板メニュー。三言語のレビューが5・5・5と均等に残る唯一の店で、コーヒーそのものを目当てに来る外国人が多いことを示しています。営業時間はInstagramで確認してください。
  • シーオッターズパイ — パイが10種類前後(ミートパイ・エスカルゴパイ・アップルパイ)。コーヒーよりパイが主役なので、ランチ代わりに使いやすい店です。11:30~20:00、火曜定休。
  • カフェピクニック — アールグレイミルクジャムトースト、柴犬2匹(ジャック・マルコ)がいる店です。11:00~20:00。犬が目当てなら昼間に。
  • イルギジャン — フィナンシェ・マドレーヌの焼き菓子ベーカリーです。外国語レビューは英語2件のみですが、このエリアの「持ち帰りデザート」枠として収録しました。営業時間はInstagramで確認してください。

② ナムチョン海辺通り — 3軒

ナムチョン洞はクァンアン大橋を正面に見る海辺通りのラインです。ナムチョン駅 (Namcheon Station / 남천역)(2号線)の徒歩圏で、クァンアルリから海沿いを歩いて来ることもできます。

  • カフェイプル — ペット同伴カフェ+デザート。10:00~24:00、年中無休(休業はInstagramで告知)。このエリアで外国語レビューが最も多い店です(5・4・4)。
  • BCBL coffee roasters — ロースタリーで、2階はクァンアン大橋ビュー。アメリカーノ・ブラックオレンジが看板。火~日10:00~21:00(ラストオーダー20:30)、月11:00~21:00。英語レビュー5件と英語圏の比率が高めです。
  • シンギコーヒー ナムチョン — 季節のトッピングパンケーキ(秋はいちじく・冬はいちご)、ドリップバッグとクッキー。ヨンド (Yeongdo / 영도) 店とInstagramを共用しているようなので、ナムチョン店の営業時間はそのアカウントで確認してください。

③ スヨン・ミルラク路地 — 4軒

スヨン駅 (Suyeong Station / 수영역)(2・3号線)の裏路地とミルラクの水辺です。クァンアルリ側より静かで、朝カフェが1軒あります。

  • デイリーラッキー — パン中心、ギリシャヨーグルト+ライ麦パンプレート、ドリップコーヒー。07:00オープン——この回で最も早く開く店なので、朝はここから始めると動線がうまく回ります。閉店時間はInstagramで確認してください。
  • ディープスリープコーヒー — スヨン駅10番出口徒歩1分。パウンドケーキと濃いラテ、毎月入れ替わる地元作家の展示。10:00~19:00。12軒の中で駅からのアクセスが確認できた唯一の店なので、雨の日の最初の目的地に。
  • イルインサムソ — 毎月デザインが変わるあんこ菓子です。月~土12:00~18:00、日曜定休。三言語レビューは3・3・3。
  • アイライクイット — コーヒー+家具・雑貨コラボ空間「イットゥム (Itteum / 잇틈)」、ミニマル・ヴィンテージな空間です。ミルラクの水辺側にあります。営業時間はInstagramで確認してください。

④ ファンリョンサンビュー — 1軒

  • ブルーバン ファンリョンサン店 — 釜山の夜景カフェです。ファンリョンサンはちみつ茶₩8,000・カフェラテ₩7,000・バニラビーンラテ₩7,500・コールドブリュー₩6,000。11:00~翌02:00(ラストオーダー01:30)。地下鉄ではアクセスできず、ファンリョンサン展望休憩所の駐車場側にあります——タクシーが答えです。半日の動線とは分けて、夜だけの別コースにしてください。

🗺 半日の動線 — クァンアルリ → ナムチョン → スヨン・ミルラク

1. 朝 スヨン駅 → デイリーラッキー(07:00~)でパンプレート → ディープスリープコーヒー(10:00~、スヨン駅10番出口1分)

2. 昼 2号線でひと駅ナムチョン駅へ → カフェイプル → BCBL 2階でクァンアン大橋ビュー(→ シンギコーヒーのパンケーキは任意)

3. 午後 ナムチョンから海沿いをクァンアルリ裏路地まで徒歩(約15~20分) → ノアブルワーズのフィルターコーヒー → シーオッターズパイのパイ → カフェピクニックかイルギジャンのどちらか

4. 夜は別枠 タクシーでファンリョンサンのブルーバンへ夜景を見に(翌02:00まで)

5. ミルラクエリア(イルインサムソ・アイライクイット)はスヨン駅~クァンアルリの間に組み込むか、正午以降に開くイルインサムソに合わせて昼間に。

席取り・マグカップ・返却台のルールはどの店も同じです——初めてなら先に#1378を読んでください。犬同伴が可能なのはカフェイプルとカフェピクニックだけです。

⚠ よくある失敗3つ

1. 日曜にイルインサムソ・火曜にシーオッターズパイ — どちらも定休日です。まず曜日を確認しましょう。

2. ファンリョンサンのブルーバンを徒歩コースに入れる — 地下鉄ではアクセスできません。タクシーで別に向かいましょう。

3. 「Instagramで確認」を飛ばす — この回で営業時間が未記載の店は、その日の答えがInstagramプロフィールの営業告知に載っています。

⚙ よくある質問3つ

1. ひとつだけ選ぶなら？ — コーヒーはノアブルワーズ(三言語レビュー5・5・5)、ビューはBCBL 2階(クァンアン大橋)、夜景はブルーバン。

2. なぜチョンポが出てこないのか？ — チョンポカフェ通りはすでに#246・#1321で扱っています。今回はチョンポの外側、外国人レビューが集中するスヨン区だけを扱いました。

3. 支払い・注文は？ — 12軒すべて通常のカード決済カフェです。注文・受け取り・返却の手順は#1288・#1378、カードが登録できないときは#1301を参照してください。
