韓国の祝日、ターン、祭司文化 - なぜ家族全員が集まって食べ物を食べて寺をするのですか

雪・秋夕・順番・祭祀・世倍・聖墓・孝 — 外国人のための韓国名節・祖先儀礼 explainer。 「名節にどこに行くか」ではなく、「なぜ・何を・ある意味で」。

韓国に住んだり、K-ドラマを見ると、年に2度、都市が丸ごと雨が降る不思議な風景に出会う。ソウルの食堂の半分が休業し、高速道路は10時間以上閉まり、家族全員が車に乗って故郷に向かう。到着したら台所で一日中前をあげて餅を借りて、朝には賞をいっぱいにして祖先に節(bow)を2回する。外国人はこれを通常「Korean Thanksgiving（韓国感謝祭）」ほどに翻訳するが、それは半分だけ合う言葉だ。韓国の二大祭り「旧正月・秋夕」は単なる休日ではなく、「帰ってきた祖先を家に祀って一緒に食事し、生きている家族が一堂に会する儀礼」だ。この文は「名節に行くところ」（→cross-link）ではなく、なぜ韓国人が毎年この告知された意識を繰り返すのか―その後の家族・祖先・孝思考方式を外国人の目の高さで解く。韓国文化explainerシリーズ5編。

核心区分: ターン=名節(雪・秋夕)に過ごす儀礼 / 祭司=故人の期日(帰った日)に過ごす儀礼。外国人が最も混乱する地点である（下記②）。 2026年：雪2/17(火)・秋夕9/25(金)前後 - 正確な連休は毎年旧暦基準で変動、訪問前の確認を推奨。

⚠️外国人がよく誤解する3つのこと

1. 「チュソク＝アメリカの感謝祭（Thanksgiving）」 ❌ - どちらも秋の収穫を記念していますが、決定的に異なります。感謝祭が「生きている家族・友人の晩餐」であれば、秋夕は帰ってきた祖先に日焼け式で順番を過ごして酸素を求めて聖墓する、「祖先中心**」の名節だ。 「Thanksgiving+先祖の追悼」がより正確です。

2. 「ターン・祭祀＝宗教意識（礼拝）」 ❌ — お寺をして食べ物を上げると宗教のように見えるが、韓国人のほとんどにこれは神に向けた礼拝ではなく、「帰ってきた親・祖父母を覚えて祀る家族儀礼」だ。キリスト教の信者の家庭は、代わりに追悼礼拝をささげることもあります - 形態は家庭によって異なります。

3. 「名節には韓国全体が閉まって観光客は行くことができない」 ❌ — 近所の小さなお店・食堂はたくさん閉じるが、明洞・仁寺洞・弘大・宮殿・百貨店・コンビニ・テーマパークは概ね開かれる。むしろ故宮は祝祭に無料開放+伝統公演をすることが多い(下⑧)。

①お正月と秋夕 — 韓国の二大祭り

韓国には数多くの記念日があるが、「名節」といえば普通正月と秋夕の両方を指す。両方とも暁暦に従うので揚力日は毎年変わる。

  • 旧正月（旧暦1月1日） - 旧暦新年初日。一年の始まりを家族と一緒に迎え、餅を食べて世倍をしてターンを過ごす。 2026年は2月17日(火)戦後3日連休。
  • チュソク（旧暦8月15日） - 秋の満月が最も丸い日。一年農業の収穫を先祖に感謝する名節で、「ハンガウィ」とも呼ばれる。新羅時代まで起源が遡る長い伝統だ。 日焼け式でソンピョンを借りて聖墓を行く。 2026年は9月25日(金)前後三日連休。

二つの祭りの共通の核心は、帰省 — 散らばって暮らしていた家族が故郷本家に集まるという点だ。だから祝日は韓国から'家族全員が一堂に会するほぼ唯一の時間'である。

②ターンvs祭司 - 最も重要な分類

外国人はもちろん、韓国の若い世代でも混同しやすい部分だ。どちらも先祖に食べ物を供えて拝礼する儀礼だが、いつ・なぜ行うかが違う。

ターン (茶禮) 祭司 (祭祀・忌祭祀)
いつ 名節(旧正月・秋夕)に 故人の忌日(亡くなった日)に
時間 名節当日の朝(昼) 伝統的には夜(子の刻) — 最近は夕方に前倒しすることも
目的 名節が来たことを先祖に知らせる 故人の霊を迎えて食事をもてなす
格式 簡略 — 酒一杯、ターン膳を用意 格式高く手厚い — 料理の品数が多い
対象 通常複数代の先祖まとめて 通常その一人(忌日の主人公)

名前の由来: ターン(茶禮)の「茶」はもともと茶を捧げる儀礼という意味だ。それだけ祭司より簡素な儀礼だというのが伝統的な意味である。実際、伝統的なターンは酒一杯・茶一杯・果物一皿程度と簡略で、祝文(文を読み上げる手順)も省略することが多かった。

このほか聖墓(省墓) — 先祖の墓を訪ねて拝礼し手入れをすること、時祭・墓祭 — 遠い先祖や墓所で行う季節の儀礼もある。外国人が名節に最も頻繁に出会うのはターン(家)と聖墓(墓)だ。

③ ターン膳と料理 — 「ルール」は実は家ごとに違う

名節と聞いて思い浮かぶのがターン膳(祭祀膳) — 魚・チヂミ・ナムル・果物・餅を列に並べて整えた膳だ。ネット上にはホンドンベクソ(紅東白西 / Hongdongbaekseo / 홍동백서、赤い果物は東・白い果物は西)、チョユリシ(棗栗梨柿 / Joyulisi / 조율이시、左からナツメ・栗・梨・柿)といった「ルール」が出回っている。だが外国人がぜひ知っておくべき事実がある。

  • これらのルールは絶対的な決まりではない。 韓国にはガガレ(家家禮 / Gagarye / 가가례) — 「家ごとに礼法が違う」という古くからの原則がある。「他人の祭祀に栗を置け梨を置けと口出しするな」ということわざはまさにここから生まれた。
  • ホンドンベクソ・チョユリシのような用語は実は近代以降に固まったもので、朝鮮時代の儒学者たちも知らなかったという指摘も学界・メディアにある。つまり「正統なルール」というより後代の慣習に近い。
  • 韓国儒教の総本山であるソンギュングァン(成均館 / Seonggyungwan / 성균관)さえも最近「虚礼虚飾なく、家族が和合する形で簡素に」行えばよいという勧告を出した。ターン膳の配置・料理の品数は地方・家門ごとに違うので、「これが正解」と決めつけないこと(迷ったらその家の年長者に確認するのが望ましい)。

大事なのは膳立てのルールではなく、先祖を偲び家族が共に過ごす気持ちだというのが今日の流れだ。ちなみに外国人が写真で目にする「山のように積まれたターン膳」は大抵宗家や格式を重んじる家の姿であり(王室の正餐であるスラ膳の格式が両班の祭祀膳に影響を与えた → 「もっと深く」#690)、普通の家庭はそれよりずっと簡素である。

名節を代表する二つの料理

  • トックク (Tteokguk / 떡국、旧正月) — 新年最初の日に食べる白い餅スープ。「トッククを一杯食べると歳を一つ取る」という言葉がある。韓国の伝統的な「数え年」の数え方では、新年になると誰もが一歳年を取ったとされ、その象徴がトッククだ。古い文献ではトッククをチョムセビョン(添歳餅 / Cheomsebyeong / 첨세병、「歳を加える餅」)と呼ぶこともあった。白い色は新たな出発の清らかさを、長い棒状の餅(カレトク)は長寿と財運を意味する。
  • ソンピョン (Songpyeon / 송편、秋夕) — 半月形に作って松葉の上で蒸し上げる餅。その年に新しく収穫した穀物(新米・ごま・豆・小豆)で作り、収穫の喜びを分かち合い先祖に感謝する意味を込める。家族全員が輪になって座りソンピョンを作ること自体が秋夕を代表する光景だ。

④ 世倍・聖墓・帰省 — 名節の生きた風習

先祖儀礼が名節の「厳粛な半分」だとすれば、残りの半分は生きている家族どうしの温かい風習である。

  • 世倍(歳拝) — 主に旧正月に、子供や若い世代が家の年長者に深く一礼して新年の挨拶をする。一礼を受けた年長者は「新年、福をたくさん受けなさい」のような徳談(祝福の言葉)をかけ、子供たちにお年玉(sebaetdon / 세뱃돈)を渡す。K-ドラマの旧正月シーンの定番で、外国人が韓国の家庭に招かれた際に最も印象に残る瞬間でもある。
  • 聖墓(省墓) — 主に秋夕(旧正月にも)、先祖の墓を訪ねて拝礼し、墓の周りを手入れする。秋夕の前にはあらかじめ墓の草を刈るボルチョ(伐草 / Beolcho / 벌초)を行う。家族揃って山に登り先祖を偲ぶ時間だ。
  • 帰省 = 民族大移動 — 名節の前後には数千万人が故郷へ移動する。そのため名節は韓国最大の交通渋滞シーズンとなる — KTX・高速バスの切符は数週間前に売り切れ、普段4~5時間の距離が10時間を超えることもある。外国人観光客が名節に韓国国内の移動を計画するなら列車の切符を早めに予約するべき理由だ(下記⑧)。

⑤ なぜこれをすべて行うのか — 儒教と孝の根

名節儀礼の根を一文字で表せば孝(hyo, filial piety)だ。孝とは両親と先祖を敬い、その恩に報いること — 儒教(Confucianism)が韓国社会に深く根付かせた核心的な価値観である。

  • 儒教的な世界観では、家族は死によって途切れない。 亡くなった先祖も依然として家族の一員であり、子孫が真心を込めて祀ればウムドク(陰徳 / Eumdeok / 음덕、先祖の加護)として子孫を見守ってくれると信じられてきた。ターン・祭司は、その「生きている家族と亡くなった家族が共に食事をする」場というわけだ。
  • そのため儀礼の核心となる動作が二度の深い礼(再拝)である — 生きている人には一度、亡くなった方には二度拝礼するのが伝統だ。これは先祖への敬意と懐かしさを表す所作である。
  • 興味深い点として、学者たちはこの先祖儀礼が儒教(孝)だけの産物ではなく、それ以前から朝鮮半島にあった祖霊信仰・シャーマニズム的な信仰とも深く絡み合っていると見る。つまり「先祖が子孫を見守る」という感覚は、儒教が入ってくる前から韓国文化に流れていたものだ。

まとめると、名節に家族全員が集まって料理を用意し拝礼する理由は — 「自分たちがどこから来たのか(ルーツ)を思い出し、その恩に報い、家族が途切れずつながっていることを確かめる行為」だからである。

⑥ 現代の変化 — 簡素化・名節症候群・「旅行に行く名節」

名節文化は今、急速に変わりつつある。外国人が知っておくと韓国社会をより立体的に理解できる部分だ。

  • ターンの簡素化・省略 — 料理を大幅に減らしたり、男女で一緒に分担したり、そもそもターンを行わない家庭が増えている。ソンギュングァンの簡素化勧告もこの流れと重なる。
  • 名節症候群 (Myeongjeol Jeunghugun / 명절증후군) — 名節の労働・長距離移動・家族間の葛藤によるストレスを指す韓国特有の言葉。特に嫁世代の台所労働の負担、10時間を超える帰省の道のり、親戚からの小言(「結婚は?」「就職は?」)が代表的な原因として挙げられる。韓国社会が名節を「簡素化」する背景でもある。
  • 「旅行に行く名節」 — ターンを簡素化したり飛ばしたりして、連休を利用して国内外へ旅行に出かける家族が増えている。仁川空港が名節のたびに出国する人々で混雑するのは新しい光景だ。つまり「すべての韓国人が名節にターンを行う」というのはもはや事実ではない — 伝統を守る家、簡素化する家、旅行に行く家が共存している。

この変化自体が韓国社会の断面である — 伝統(孝・家族)と個人主義・実用主義がぶつかり合いながら、折り合いを探っている最中なのだ。

⑦ 外国人が名節に韓国に来ると — 何を目にするか

名節連休は外国人観光客にとって長所と短所がはっきり分かれる。「閉まった扉」の裏に意外なチャンスがある。

  • 閉まるもの: 近所の小さな食堂・商店・美容室・小規模な美術館などは名節当日(特に秋夕・旧正月当日)に1~3日閉まる所が多い。初めての韓国旅行なら郊外の住宅街より都心・観光地の宿が安全だ。
  • 開いているもの: 明洞・仁寺洞・弘大・北村・江南・宮殿一帯や釜山・慶州・済州の主要スポットは概ね通常営業。コンビニ(CU・GS25・セブンイレブン・イーマート24)は24時間そのまま — 近所の食堂が閉まっていても食事に困らない。百貨店・テーマパーク・展望台も大抵営業している。
  • 名節ボーナス: ソウルの古宮(景福宮・昌徳宮など)は名節に無料開放 + 伝統公演・体験を行うことが多い。がらんとした都心で韓服を着て古宮を楽しめるのは名節だけの特別な体験だ。
  • 交通の注意: KTX・国内線航空便は数週間前から売り切れる。名節にソウル→釜山・慶州・済州など地方への移動を計画するなら早めに切符を確保すべきだ。逆に名節当日のソウル市内は閑散としているので、普段混雑している場所をゆったり楽しめる。

すべての料金・営業・開放情報は年度・機関ごとに異なり、2026年基準の推定 — 訪問前に公式チャンネル(VisitKorea・各名所)での確認を推奨する。

❓ 外国人がよく聞く質問 (FAQ)

  • 秋夕は正確にアメリカの感謝祭と同じですか? — 似ている点(秋の収穫・家族の集まり・豊かな食事)もありますが、秋夕は先祖にターンを行い墓に聖墓する先祖中心の名節だというのが核心的な違いです。「Thanksgiving + 先祖供養」として理解してください。
  • ターン・祭司は宗教ですか? — ほとんどの韓国人にとっては宗教礼拝ではなく家族儀礼・伝統文化です。ただしキリスト教の家庭ではターンの代わりに追悼礼拝を捧げるなど、形は家庭によって異なります。
  • ターン膳は決まったルール通りに用意しなければなりませんか? — ホンドンベクソ・チョユリシのような「ルール」はありますが、絶対的なものではなく地方・家ごとに異なります(ガガレ)。ソンギュングァンも簡素化を勧めています。「正解」が一つだと思わないでください。
  • 名節に韓国旅行に行っても大丈夫ですか? — 都心・観光地・宮殿・コンビニは概ね開いているので大丈夫です。ただし近所の小さな店は閉まることがあり、地方行きの列車の切符は早めに売り切れるので、都心の宿+早期予約をお勧めします。
  • 外国人もターンや世倍を体験できますか? — 韓国の家庭に招かれれば世倍・ターンを直接見ることができます。名節連休中の古宮の伝統体験イベントでも、拝礼・遊び・料理など名節文化を気軽に味わえます。
