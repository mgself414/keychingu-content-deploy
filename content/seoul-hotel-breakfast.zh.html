⚠ 外国人常犯的5个错误

1. “酒店早餐 = 仅限住客”: 部分酒店早餐对外部客人开放 (乐天世界塔西格尼尔 (Signiel) STAY·新罗 (Shilla) The Parkview·JW万豪 (JW Marriott) Griffin 60~80K韩元 (~$44-59 / ~300-400 RMB / ~6,300-8,300 JPY))。需提前预订。

2. “下午茶 = 仅英式”: 韩国酒店下午茶 = 韩国传统韩果 (Hangwa / 한과)·传统茶 (Jeontongcha / 전통차) + 英式融合 (乐天世界塔西格尼尔 (Signiel) BAR 81·新罗 (Shilla) The Library·四季 (Four Seasons) Maru) + 外国人爱好者 Instagram (인스타그램) 打卡首选。韩果 (Hangwa / 한과) 是指韩国传统糕点和糖果，传统茶 (Jeontongcha / 전통차) 则是韩国传统的各种茶饮。

3. “行政酒廊 = 昂贵”: 俱乐部客房 (Club Room) 1晚 +50~100K韩元 (~$37-74 / ~250-500 RMB / ~5,200-10,400 JPY) → 早餐·下午茶·欢乐时光 (Happy Hour / 해피아워) (酒水无限畅饮)·单独办理入住 完整套餐 = 性价比 (Gaseongbi / 가성비) 爱好者首选。性价比 (Gaseongbi / 가성비) 是指性能价格比，即物有所值。

4. “酒店早餐 = 仅西式”: 韩国5星级酒店早餐 = 西式 (Yangssik / 양식) + 韩式 (Hansik / 한식) + 日式 (Ilssik / 일식) + 中式 (Jungsik / 중식) + 印度式 (Indossik / 인도식) + 素食区 (Bigeon keoneo / 비건 코너) 完整套餐 + 外国人友好的多国籍选择。

5. “性价比 (Gaseongbi / 가성비) = 不怎么样”: L7弘大 (L7 Hongdae) (15K韩元 (~$11 / ~80 RMB / ~1,600 JPY))·诺富特东大门 (Novotel Dongdaemun) (20K韩元 (~$15 / ~100 RMB / ~2,100 JPY)) 早餐 = 外国人爱好者性价比 (Gaseongbi / 가성비) 首选 + 韩式 (Hansik / 한식)·西式 (Yangssik / 양식) 多样。
