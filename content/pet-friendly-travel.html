⚠ 외국인 자주 실수 5가지

1. "한국 = 펫 못 데려옴": 한국 반입 = 광견병 항체 (혈청 검사) + 마이크로칩 + 검역 신고 + 인천공항 검역소 (외국인 영어 OK) + #398 통합.

2. "펫프렌들리 = 없음": 펫프렌들리 = 호텔 (강남·홍대 50+) + 펜션·풀빌라 (가평·양평) + 카페 (#442) + 레스토랑·#400 + 외국인 매니아.

3. "펫 응급 = 영어 안됨": 영어 OK = 강남 24시 펫 병원 + 외국인 의료관광 (#401) + #405 응급 + 외국인 매니아 1순위.

4. "펫 day-trip = 안됨": 펫 day-trip = 가평·양평·파주·제주·강원 + #430·#439 렌터카 + 펫 동반 카페·식당 + 외국인 가족 매니아.

5. "펫 비행기 = 비쌈": 비행기 = 케이지 in-cabin (5kg 이하) vs 화물 (5kg+) + 항공사별 정책 (Korean Air·Asiana 외국인 영어 OK) + 검역 서류 풀세트.
