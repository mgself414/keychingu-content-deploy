왜 크리스마스 마켓인가 — 외국인 매니아 1순위·12월 풀세트

서울 크리스마스 마켓 = 12월 풀세트·신세계·롯데월드·DDP·홍대·강남·외국인 매니아 인스타 1순위. 일루미네이션 (#745)과 동시·12/1~12/25 절정·다국어 풀 cover.

본 매트릭스는 도심 마켓 3선 + 테마파크 마켓 3선 + 외곽·MZ 마켓 3선 + 외국인 인프라·시즌 3선 = 12선 4축.

12선 4축

축 1: 도심 마켓 (3선)

1. 신세계 본점 크리스마스 마켓 — 한국 #1

  • 차별: 신세계 본점·한국 #1 럭셔리 크리스마스 마켓 + 미디어 파사드 (#745)·외국인 매니아 인스타 1순위
  • 운영: 11/15~12/25·무료 (외부)·내부 식음료 별도
  • 외국인 fit: ★★★★★ EN·JP·CN MZ + 럭셔리 매니아 1순위
  • 교통: 명동역·회현역 (4호선)

2. 광화문 광장 크리스마스 마켓

  • 차별: 광화문 광장 + 시청 + 청계천 광장 + 명동 풀세트·외국인 도심 매니아 1순위
  • 운영: 12/1~12/31·무료
  • 외국인 fit: ★★★★★ EN·JP·CN + 매니아 1순위
  • 교통: 광화문역·시청역 (1·5호선)

3. DDP 크리스마스 마켓 + 동대문

  • 차별: DDP (자하 하디드) + 동대문 시장 + 청계천 + 광화문 풀세트·외국인 매니아 1순위
  • 운영: 12/1~1/15·무료
  • 외국인 fit: ★★★★★ MZ + 쇼핑 매니아
  • 교통: 동대문역사문화공원역 (2·4·5호선)

축 2: 테마파크 마켓 (3선)

4. 롯데월드 크리스마스 마켓 + 일루미

  • 차별: 롯데월드 + 매직 아일랜드 + 석촌호수 + 마켓 풀세트·외국인 매니아 1순위
  • 운영: 11/15~1/15·입장 60,000원
  • 외국인 fit: ★★★★ EN·JP·CN 가족 + 매니아·유료 60,000원
  • 교통: 잠실역 (2·8호선)

5. 에버랜드 크리스마스 마켓

  • 차별: 에버랜드 크리스마스 판타지 + 마켓 풀세트·한국 #1 테마파크
  • 운영: 11/15~12/25·입장 60,000원
  • 외국인 fit: ★★★★ 가족 매니아·유료 60,000원
  • 교통: 강남역 셔틀

6. 서울숲 + 성수 크리스마스 마켓 (#740 cross)

  • 차별: 서울숲 + 성수 MZ 핫플 크리스마스 마켓·MZ 매니아 1순위
  • 운영: 12/1~12/31·무료 (대부분)
  • 외국인 fit: ★★★★★ MZ + 인스타 1순위
  • 교통: 서울숲역 (수인분당선)

축 3: 외곽·MZ 마켓 (3선)

7. 홍대 크리스마스 마켓 + 합정·망원

  • 차별: 홍대 + 합정 + 망원 MZ + 인디 크리스마스 마켓·외국인 청년 매니아
  • 운영: 12/1~12/31·무료
  • 외국인 fit: ★★★★ MZ + 청년 매니아
  • 교통: 홍대입구역 (2호선)

8. 강남 가로수길 크리스마스 마켓 (#745 cross)

  • 차별: 강남 가로수길 + 청담동 + 압구정 럭셔리 매니아·외국인 럭셔리 1순위
  • 운영: 12/1~1/15·무료
  • 외국인 fit: ★★★★ MZ + 럭셔리 매니아
  • 교통: 신사역·압구정역 (3호선)

9. 가평·양평 외곽 크리스마스 마켓 (#739·#745 cross)

  • 차별: 가평 쁘띠 프랑스 + 양평 외곽 크리스마스 마켓·외국인 day-trip 풀세트
  • 운영: 12/1~12/31·입장 별도 (12,000원~)
  • 외국인 fit: ★★★★ 1박 매니아
  • 교통: ITX (1시간)

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (당일 + 시내 핵심 풀세트)
  • 예산: 80,000~150,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
