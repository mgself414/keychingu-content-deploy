韩国“情 (Jeong)”文化 — 为什么第一次见面的人会请你吃饭？

情 (Jeong) · 厌恶之情 (Miunjeong) · 美好之情 (Gounjeong) · 我们 (Woori) · 分享 (Nanum) — 为外国人解读的韩国情感。解释“affection”一词无法完全涵盖的韩式情谊的“为什么”和“如何”。

首尔 (Seoul / 서울) 某条小巷 (golmok / 골목) 里的餐厅。一位外国人独自进去，只点了一份拌饭 (bibimbap / 비빔밥)，但店主阿姨 (ajumeoni / 아주머니) 却不问自加了一份煎蛋 (gyeranpeurai / 계란프라이)，并说着 “多吃点，多吃点” 又添了一份小菜 (banchan / 반찬)。坐上出租车 (taeksi / 택시)，司机大叔 (ajeossi / 아저씨) 在前往目的地的路上不停地问你从哪里来、吃饭了吗，下车时还说声 "韩国很棒吧？再来玩哦"。旁边桌的爷爷突然说 “我来付钱” 想要买单。许多外国人会将这一刻总结为“Korean people are SO nice”，但韩国人并不会用“亲切 (kindness)”这个词来形容。他们用的词是 情 (Jeong / 정)。任何试图将其翻译成英文的尝试都以失败告终 — 无论是affection、attachment、bond，都无法完全涵盖其含义。本文并非“如何在韩国获得友善对待”的指南，而是以外国游客的视角，解释 这些行为背后情感的运作原理。同时，我们也会坦诚地看待情 (Jeong) 温暖的一面和令人感到负担的一面。这是韩国文化解读系列文章的第四篇。

★ 一目了然 — “情 (Jeong)”的6个核心概念

概念 是什么 一句话总结
情 (Jeong / 정) 随着时间积累而形成的情感纽带 融合了爱、依恋、怜悯、义气，无法翻译的韩式深厚情谊
厌恶之情 (Miunjeong / 미운정) 即使讨厌也产生的情谊 共同经历冲突和不适后反而加深的情谊
美好之情 (Gounjeong / 고운정) 美好积累的情谊 通过愉快和温暖的经历积累的情谊
我们 (Woori / 우리) “我”而非“我们” 我们的家、我们的公司、我们的妈妈 — 以集体而非个人为单位思考
分享 (Nanum / 나눔) 关照并给予更多 多给小菜、劝人吃饭、抢着买单 = 表达情 (Jeong) 的行为
断情 (Jeong tteda / 정 떼다) 斩断情谊 为了分手而故意切断情谊。这表明情 (Jeong) 是会“产生”的

核心: 情 (Jeong) 与其说是“情感 (emotion)”，不如说更接近于 “维系关系的方式 (OS)”。韩国人常说 "情 (Jeong) 产生了 / 情 (Jeong) 投入了" — 这意味着情 (Jeong) 并非一瞬间产生，而是 随着时间慢慢“产生” 的。

⚠️ 外国人常有的3种误解

1. “他们这么亲切，是不是想推销什么？(推销)” ❌ — 餐厅多给小菜或阿姨 (ajumeoni / 아주머니) 关心你，通常是无偿的情 (Jeong) 的表达。在没有小费文化 (xiaofei wenhua / 소피문화) 的韩国，这并非销售策略，而更接近于“希望你吃好”的心意。不过，旅游景点的拉客 (hoggaek / 호객) (类似“拉客仔 (ppikki / 삐끼)”) 是另一回事 — 那是推销而非情 (Jeong)，需要区分。

2. “为什么第一次见面就问年龄、婚姻、工资？这不是没礼貌吗？” ❌(部分) — 问及私人问题与其说是没礼貌，不如说很多时候是 "想把你纳入我们之中" 的 关心表现。当然，以外国人的标准来看，这可能确实有些过度 — 这正是情 (Jeong) 令人感到负担的一面 (见下文⑤)。如果感到不适，可以笑着带过或轻松回答。

3. “情 (Jeong) = 只是韩式亲切/好客 (hospitality)” ❌ — 情 (Jeong) 并非一次性的亲切，而是 随着时间积累而加深的纽带。在常去的餐厅 (dangol sikdang / 단골 식당)、同一个社区的邻居、相处已久的朋友之间，才会真正“产生”情 (Jeong)。因此，韩国人不仅在美好的关系中谈情 (Jeong)，也会在 "厌恶之情 (miunjeong / 미운정) 和美好之情 (gounjeong / 고운정) 都产生了" 这样 即使争吵、摩擦过的关系中 谈情 (Jeong)。

① 情 (Jeong) 是什么 — 为什么无法翻译

情 (Jeong / 정) 类似于爱 (love)，但更广泛、更紧密。韩国语和心理学研究者将情 (Jeong) 概括为 "对包括人在内的万事万物的心意运用或表现"，但韩国人自己却说 "情 (Jeong) 无法用言语解释，只能去感受"。英语世界的解释者在翻译情 (Jeong) 时，会同时使用 feeling·love·sympathy·attachment·bond·affection，但任何一个词都无法完全表达，所以通常会将其介绍为 “untranslatable Korean emotion”。

情 (Jeong) 最大的特点是时间。

  • 情 (Jeong) 不会一蹴而就。它需要 共同度过的时间和经验积累 才能产生。因此，人们会说 "情 (Jeong) 产生了 / 情 (Jeong) 投入了" (不是“产生”，而是“投入”)。
  • 因此，一旦产生的情 (Jeong) 也难以割舍。甚至有“为了断情 (jeong tteda / 정 떼다) 而故意冷淡”的说法。
  • 对象也很广泛。不仅对人，对 住了很久的社区、旧物、常去的店 也会产生情 (Jeong)。

韩国人常自评 "韩国是情 (Jeong) 的社会" — 这是他们认为社会是由 情 (Jeong) 维系的纽带 而非个人间的契约和距离感支撑的自我认知。(由于难以给出确切定义，理解为“人们常这样说”会更稳妥。)

② 厌恶之情 (Miunjeong) · 美好之情 (Gounjeong) — 不仅因为喜欢才产生

外国人最感到新奇的概念是 厌恶之情 (Miunjeong / 미운정)。英语中没有对应的词。

  • 美好之情 (Gounjeong / 고운정) = 通过愉快和温暖的经历美好地积累的情谊。
  • 厌恶之情 (Miunjeong / 미운정) = 共同经历冲突、厌恶和不适后，反而加深 的情谊。也有人解释为 "从不愉快的经历中产生的一种奇妙的、令人愉悦的情谊"。

韩国人形容真正深厚的关系时，会说 "厌恶之情 (miunjeong / 미운정) 和美好之情 (gounjeong / 고운정) 都产生了"。长久相处，共同经历过好事、坏事、甚至争吵，却依然无法离开 — 这就是韩式 “真正亲密的关系”。也就是说，情 (Jeong) 甚至将 承受冲突的时间 也视为一种财富。这与西方“喜欢就一起，不喜欢就分开”的理念有所不同。

外国人友好提示: 如果你曾与室友或同事经历过一番摩擦后产生感情，那便接近于厌恶之情 (miunjeong / 미운정)。它与 "爱恨交织 (love-hate)" 相似，但厌恶之情 (miunjeong / 미unjeong) 的核心在于 将负面情感也纳入情谊的一部分。

③ “我们 (Woori)”文化 — 情 (Jeong) 滋长的土壤

为什么情 (Jeong) 在韩国表现得如此强烈？其背景是 “我们 (Woori / 우리)” 这一思维单位。

  • 韩国人在日常生活中，会用“我们 (Woori / 우리) 的 ~”而非“我的 ~” — 我们的家、我们的公司、我们的国家，甚至 我们的妈妈、我们的丈夫 (明明是我的妈妈、我的丈夫！)。这是一种将 集体作为基本单位 而非个人为基本单位的语言习惯。
  • 从学术角度看，韩国文化也可用 集体主义 (collectivism) + 我们 (Woori / 우리) 情感来解释。这是一种将个人融入“我们”之中以获得归属感的结构。
  • 情 (Jeong) 在将某人纳入“我们”的界限内时开始运作。当你成为常客 (dangol / 단골)、邻居、一起吃饭的朋友 — 你就逐渐成为 “我们” 的一员，那时，关照 (=情 (Jeong)) 便开始了。

也就是说，餐厅阿姨 (ajumeoni / 아주머니) 多给小菜 (banchan / 반찬)，更像是将你暂时视为 “我们的客人” 的信号。

④ 日常生活中的情 (Jeong) — 外国人实际遇到的场景

情 (Jeong) 并非抽象概念，而是通过具体行动表现出来。外国游客旅行中常遇到的例子：

  • 餐厅小菜 (banchan / 반찬) · 服务: 不问自添小菜 (免费续添)，并说着 "多吃点这个" 加上煎蛋 (gyeranpeurai / 계란프라이) 或汤。如果用韩语 (Hangugeo / 한국어) 磕磕绊绊地打个招呼，小菜 (banchan / 반찬) 可能会更多 — 因为 "努力的样子很可爱"。(→ #1132 韩国小菜文化: 分享·免费续添的根源)
  • 阿姨 (ajumeoni / 아주머니) · 奶奶的关照: 市场 (sijang / 시장) 或老字号 (nopo / 노포) 的阿姨 (ajumeoni / 아주머니) 连声说着 "多吃点"，还会直接给迷路的外国人 "尝尝这个" 劝食。在韩居住的外国人表示，即使 生活了几十年也对此感到惊讶。
  • 陌生人的好意: 地铁 (jihacheol / 지하철) 上帮人提重物，老人一路送你到目的地，或邻桌客人说 "我来付钱" 想要买单。
  • 出租车 (taeksi / 택시) · 店主: 问你从哪里来、吃饭了吗，最后以 "韩国很棒吧？再来玩哦" 结束。私人问题是拉近距离的 关心方式。
  • 常客 (dangol / 단골) 的情 (Jeong): 几次光顾同一家咖啡馆 (kape / 카페) 或餐厅 (sikdang / 식당) 后，店主会认出你，并赠送小礼物或搭话。情 (Jeong) 在 重复和时间 中加深。

提示: 面对这种好意，与其冷脸拒绝，不如 笑着说声“谢谢 (gamsahamnida / 감사합니다)” 就足够了。不必非要以同等价值回报 — 情 (Jeong) 是一种流动而非交易。

⑤ 情 (Jeong) 的两面性 — 温暖与负担是硬币的两面

如果只把情 (Jeong) 描绘成 "无条件的好事"，那就只看到了一半。同样的情感也可能表现为 负担·干涉。了解这种平衡才能准确理解韩国。

温暖的一面 (款待·关照) 令人感到负担的一面 (干涉·界限模糊)
多给小菜、劝人吃饭 “吃不下了”的拒绝往往无效
关心你从哪里来 年龄、婚姻、年薪等私人问题突然袭来
纳入“我们”后会深切关照 “我们”之外则距离遥远，之内则隐私界限模糊
情 (Jeong) 维系的紧密共同体 个人必须适应集体的压力

从学术角度看，“我们 (Woori / 우리)”情感也可能与 个人隐私·自主性发生冲突。由于“我们 (Woori / 우리) vs 陌生人 (nam / 남)”的界限很强，一旦进入“我们”就会像家人一样被关照 — 但这种界限本身也可能让外国人·外来者感到 隔阂。此外，个人适应集体的压力也与韩国特有的火病 (hwabyung / 화병) 等情绪压力讨论相关联。韩国人也了解这种两面性 — 常见的自嘲是 "因为情 (Jeong) 离不开情 (Jeong)，但又因为情 (Jeong) 而感到疲惫"。

外国人总结: 如果私人问题或过度关照让你感到不适，与其断定为无礼，不如将其视为情 (Jeong) 的表达方式，这样会让你心情更放松。同时，如果感到不适，笑着划清界限也无妨 — 这并非失礼。

⑥ 情 (Jeong) 会改变吗 — 城市化·MZ世代的情 (Jeong)

情 (Jeong) 会一直像以前一样吗？变化是显而易见的。

  • 城市·一人家庭: 随着公寓 (apateu / 아파트) 和一人家庭的增加，邻里间紧密的情 (Jeong) 比起以前的乡村·小巷 (golmok / 골목) 社区淡化了许多。例如，有人自嘲 "现在连隔壁住着谁都不知道"。
  • MZ世代 (MZ sedae / MZ세대) 的距离感: 年轻一代普遍认为，过度的私人问题·集体压力令人 感到负担，他们更倾向于重视个人界限。诸如 "请不要越界 (seon neomji maseyo / 선 넘지 마세요)" 等表达的日常化就是信号。
  • 情 (Jeong) 依然存在: 尽管如此，餐厅小菜 (banchan / 반찬) 的慷慨、对常客 (dangol / 단골) 的关照、危机时团结的共同体情感依然强烈地运作着。普遍观点认为，形式可能变得更轻盈，但情 (Jeong) 本身并未消失。

总结: 外国游客在旅行中遇到的“情 (Jeong)”依然是鲜活的当下。然而，与其概括为 "韩国人都是这样的"，不如理解为根据世代、城市、关系的不同，其浓度也有所差异，这样会更准确。

❓ 外国人常见问题 (FAQ)

  • 餐厅多给小菜 (banchan / 반찬)，需要额外付费吗？ — 通常是免费的。这是情 (Jeong) 的表达，也是韩国餐厅的基本人情 (小菜续添)。不必感到负担，说声 "谢谢 (gamsahamnida / 감사합니다)" 就足够了。(→ #1132 韩国小菜文化)
  • 陌生人想要买单，我该怎么办？ — 接受这份好意，并礼貌地表示感谢即可。不一定非要拒绝，但如果感到负担，轻轻地说声 "我来付钱 (jega naelgeyo / 제가 낼게요)" 婉拒也并非失礼。
  • 年龄、婚姻等私人问题，我需要回答吗？ — 没有义务。这是关心的表现，所以可以笑着轻松回答或适当地敷衍过去。如果感到不适，转移话题也并非无礼。
  • “情 (Jeong)”用一个英文单词怎么说？ — 没有。 它融合了affection + attachment + bond + 怜悯等概念，所以在英语世界中，通常直接使用 jeong 并加以解释。
  • 外国人也能和韩国人产生“情 (Jeong)”吗？ — 当然可以。情 (Jeong) 的核心是时间·重复，所以经常光顾同一家店、在同一个社区居住，情 (Jeong) 就会产生。即使是短期旅行，只要培养一个常去的餐厅，也能体验到情 (Jeong) 的一小部分。
