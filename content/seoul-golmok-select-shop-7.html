⚠ 외국인 자주 실수 3가지

1. "서울 쇼핑 = 명동·동대문만": 골목 편집샵 = 외국인 매니아 매트릭스 #1 디자이너 큐레이션. 안국·익선·연남·삼청·인사·서촌·성수 = 7대 골목 cluster + 외국인 매니아 fit.

2. "편집샵 = 너무 비싸": 7개 편집샵 = 가격 매트릭스 다양. 인사 (5) = entry-level (5,000~30,000원). 연남·익선 = 중간 (20,000~80,000원). 안국·삼청·서촌·성수 = 디자이너 (50,000~200,000원). 외국인 매니아 = 가격 매트릭스 선택.

3. "편집샵 = 영어 안 통하나": 7개 편집샵 = 영어 직원·영어 가이드 매트릭스 #1. 안국·이태원·연남·성수 = 외국인 매니아 fit. 익선·삼청·인사·서촌 = 영어 OK.

⚙ FAQ 4개

1. 외국인 골목 편집샵 best 동선: Day 1: 안국 (1) → 삼청 (2) → 익선 (3) → 인사 (5) (북촌·익선·인사 cluster cross). Day 2: 서촌 (6) → 경복궁·창덕궁. Day 3: 연남 (4) → 경의선(#1082) cross. Day 4: 성수 (7) + 부티크 호텔(#1077) cross.

2. 외국인 편집샵 큐레이션 매트릭스: (a) K-디자인·라이프스타일 = 안국·서촌·성수 매트릭스 #1 (b) K-패션 = 익선·연남·성수 (c) 전통 + 모던 fusion = 익선·인사 (d) 인디·zine = 연남·삼청. 외국인 매니아 = 카테고리 선택.

3. 편집샵 etiquette (외국인 시각): (a) 입구 = 영어 인사 OK (b) 가격표 = 한국어 + 영어 부분 매트릭스 (c) 결제 = 카드·현금 OK + tax-free 매트릭스 일부 (d) 사진 = 일부 제한 매트릭스 (e) 영어 직원 = 안국·이태원·연남·성수 매트릭스.

4. 외국인 편집샵 tax-free 매트릭스: (a) 30,000원+ 결제 = tax-free 매트릭스 가능 (b) 외국인 매니아 = 여권 + 카드 결제 + tax-free 환급 매트릭스 (c) 인천공항 tax-free 카운터 = 외국인 매니아 fit (d) 안국·삼청·연남·성수 = tax-free 매장 多.
