🎯 なぜ「済州 車なし旅」ガイドなのか

済州島 (チェジュ島 / 제주도) 旅行で外国人最大の悩みがレンタカーです。韓国はレンタル時に国際運転免許証 (IDP·International Driving Permit) を求められることが多く、IDPを持たない外国人・運転しない人・一人旅の人は「車なしで済州は回れる?」で行き詰まります。Reddit の r/koreatravel・r/jeju で "4 nights in Jeju without a car — where to stay and what's realistic by bus?" という質問が繰り返し上がるのはそのためです(実測された需要シグナル)。

結論から: 済州は2017年の公共交通改革以降、バス網が密です。急行(赤)・幹線(青)・支線(緑)バス + 観光地循環バス 810/820 (Sightseeing Loop / 관광지 순환버스) + KakaoT (카카오T) タクシーを組み合わせれば、レンタカーなしでも 3泊4日で核心の12選を回れます。カギは宿泊ベース選びとルートを東/西に分けることです。

本ガイドは 車なし12選 + 3泊4日バスルート + 宿泊ベース戦略 + リアルタイムアプリ設定。

🚌 車なし4大交通ツール Deep Dive

① 急行バス (Express / 급행버스, 赤·100番台)

  • シグネチャー: 空港·主要拠点最少停車·済州–西帰浦最速
  • 外国人フレンドリー度: ★★★★☆ (KakaoMap (카카오맵) の路線は英語対応)
  • コツ: 101/102 = 海岸循環急行·空港から西帰浦/城山方面が最速

② 幹線バス (Trunk / 간선버스, 青·200~300番台)

  • シグネチャー: 主要スポットをつなぐ主力·201(東海岸)·202(西海岸)·281(漢拏山縦断)
  • 外国人フレンドリー度: ★★★★☆
  • 運賃: 交通カードで基本 ₩1,150~1,200 (~$0.85 / ~120 JPY)·長距離は区間加算

③ 観光地循環バス 810/820 (Sightseeing Loop / 관광지 순환버스)

  • シグネチャー: 810 = 東部(大川–城山·拒文岳など)·820 = 西部(中文–オソルロク·和順など) — スポットのみ循環
  • 外国人フレンドリー度: ★★★★★ (車なし最適化·定額 ₩1,150)
  • コツ: 1日で複数スポットをホッピング·東/西日帰りルートの骨格

④ KakaoT タクシー (카카오T)

  • シグネチャー: 幹線の隙間·深夜·荷物が多い時のラストマイル
  • 外国人フレンドリー度: ★★★★☆ (英語アプリ·カード登録)
  • コツ: 済州のタクシーは中心部の外だと配車が遅い → 時間に余裕を·目的地はハングルで保存

⚠ 外国人が車なしでやりがちな失敗5つ

1. 「済州は車がないと無理」: 改革後の網 + 循環バス 810/820 + KakaoT で核心12選をカバー。この思い込みは間違い。

2. 「宿はどこでもいい」: 車なし旅はベースが8割。一つに固定を: 済州市(空港·バスハブ近く) か 西帰浦(中文·オルレ)。郊外のペンションはバス砂漠地獄。

3. 「東西を1日で」: 済州は広い(往復3時間+)。東部·西部は別の日に分けるのが現実的。

4. 「終バスを無視」: 支線·循環バスは終バスが早い(18~20時)。日没後の移動はKakaoT予備。

5. 「牛島·城山の日帰り往復はタイト」: 城山+牛島は丸1日確保を。フェリーの時刻表を事前確認。

⚙ FAQ 6つ

1. 本当にレンタカー不要?: 核心スポットはバスでOK。ただし内陸奥のオルム(oreum, 火山丘)·夜間移動はKakaoT併用。

2. 循環バス 810/820 の乗り方?: 東=810、西=820。定額 ₩1,150·主要スポット循環。KakaoMapでリアルタイム確認。

3. 城山日出峰の日の出: 04:00~20:00開場·入場 ₩5,000 (~$3.7 / ~550円)·日の出は季節で約05~07時。

4. 牛島への行き方: 城山港からフェリー約15分·往復約 ₩10,500·牛島内は循環バス/電動バイク。

5. 漢拏山 車なし: バスで城板岳 (ソンパナク / 성판악, 幹線 281)·御里牧 (オリモク / 어리목, 240) 登山口まで可。頂上の白鹿潭 (ペンノクタム / 백록담) は事前予約制。

6. おすすめペルソナ: 一人·運転しない = 済州市ベース + 東/西日帰り / カップル = 西帰浦 + 牛島 / 予算型 = バス+無料自然(挟才·オソルロク茶畑)。

⚠ 医療·安全·食事 disclaimer

漢拏山登山 = 妊婦·心臓疾患の方は医師に相談·冬はアイゼン·城板岳頂上は事前予約。タチウオの刺身·アワビ = 甲殻類·魚アレルギー注意。長時間のバス移動は酔い止め準備を。緊急 ☎ 1339·1330·119。
