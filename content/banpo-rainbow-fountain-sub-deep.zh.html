🎯 如何使用这份指南

这份指南汇集了首尔盘浦大桥的月光彩虹喷泉及其周边盘浦汉江公园里值得一去的地方。包括一座喷泉、公园内的一个广场和一座人工岛、水上文化空间Sebit岛和一处水上休闲项目、2026年秋季举办的两场庆典。

喷泉11月到3月14日不运行。 以撰写这份指南的2026年11月15日为准，喷泉正处于休息期，下次运行从3月15日开始。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 盘浦大桥月光彩虹喷泉

盘浦大桥月光彩虹喷泉(Banpo Daegyo Dalbit Mujigae Bunsu / 반포대교 달빛무지개분수)，瑞草区盘浦洞(Banpo-dong / 반포동)，☎ 彩虹喷泉运营办公室(Mujigae Bunsu Unyeong Samusil / 무지개분수 운영사무실) 02-3780-0578~9，是设置在盘浦大桥上的桥梁喷泉。2007年6月启动项目，2009年4月举行了开幕仪式。为了演绎约700m宽的整个汉江江面，在盘浦大桥上游一侧和下游一侧1,140m的区间安装了380个喷嘴，把抽上来的汉江水从约20m高处洒向水面。据观光公社介绍，2008年11月7日作为“世界上最长的桥梁喷泉”被收录进吉尼斯世界纪录。

白天喷出仿照柳枝和柳叶形状等100余种造型的水柱，夜晚借助200盏灯光变成彩虹色喷泉。喷泉随背景音乐舞动。

  • 运行时间:3月15日~6月、9~10月 12:00、19:30、20:00、20:30、21:00。7~8月增加21:30。每场运行20分钟。2026年自6月1日起为节能只在19:30、20:00、20:30运行3场(首尔市公告)。
  • 休息期:1月~3月14日，11~12月。可能因天气停止运行。
  • 停车:可以(669辆)。

📍 盘浦汉江公园 — 月光广场·Seorae岛

盘浦汉江公园月光广场(Banpo Hangang Gongwon Dalbit Gwangjang / 반포한강공원 달빛광장)，瑞草区盘浦洞(Banpo-dong / 반포동)，☎ 02-3780-0541~4，是位于盘浦大桥和潜水桥(Jamsugyo / 잠수교)南端、盘浦汉江公园正中央的广场，仿照月亮的形状建成。以潜水桥为界，东侧有2个、西侧有3个月牙形观景台(Choseungmaru / 초승마루)。周边有设在盘浦大桥两侧的月光彩虹喷泉，以及改建为以行人为主的潜水桥。可以看到Sebit岛(Sebitseom / 세빛섬)和江边高楼的夜景。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。信用卡:可以。

盘浦Seorae岛(Banpo Seoraeseom / 반포 서래섬)，瑞草区盘浦洞(Banpo-dong / 반포동)，☎ 首尔市厅公园休闲科(Seoulsicheong Gongwon-yuga-gwa / 서울시청 공원여가과) 02-3780-0838，是位于盘浦大桥和铜雀大桥之间的人工岛。1982~1986年修建奥林匹克大路和汉江综合开发时建成，通过3座Seorae桥(Seoraegyo / 서래교)与盘浦汉江公园相连。每个季节种植油菜花和荞麦，春天举办油菜花庆典，秋天举办荞麦花庆典。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 水上 — Sebit岛·Tubester

Sebit岛(Sebitseom / 세빛섬)，瑞草区奥林匹克大路2085-14(Ollimpik-daero 2085-14 / 올림픽대로 2085-14)，☎ 1566-3433，是汉江上的综合文化空间。据观光公社介绍，这是在浮在水上的浮体上建造建筑的大型浮动建筑。由Chaebit岛(Chaebit / 채빛)、Solbit岛(Solbit / 솔빛)、Gabit岛(Gabit / 가빛)三座岛，以及放映影像和内容的Yebit媒体艺术画廊(Yebit / 예빛)组成。

  • 开放时间·休息日:各设施不同。
  • 停车:可以。

水上休闲项目Tubester(Sebitseom Tubester / 세빛섬 튜브스터)(同一地址，☎ 02-790-7090)是在Sebit岛乘坐浮圈和船的水上休闲项目。Tubester内有圆桌、LED灯光和遮阳伞。

  • 开放时间:3~4月工作日15:00~23:00，周末·节假日13:00~23:00。5~10月工作日16:00~24:00，周末·节假日14:00~24:00。11~2月时间无登记值。
  • 休息日:全年无休。天气恶劣时停业。

📍 2026年秋季庆典 — 潜水桥Ttubeokttubeok庆典·Seorae岛野餐音乐会

2026年无车潜水桥Ttubeokttubeok庆典(2026 Cha Eomneun Jamsugyo Ttubeokttubeok Chukje / 2026 차 없는 잠수교 뚜벅뚜벅축제)，潜水桥和盘浦汉江公园一带，☎ 首尔市未来汉江本部(Seoulsi Miraehangang Bonbu / 서울시 미래한강본부) 02-6401-9717，是由首尔市未来汉江本部举办的免费街头庆典。2026年于9月6日~10月25日举办，时间为14:00~22:00。部分节目收费。

  • 常设节目:月光游乐场(Dalbit Noriteo / 달빛 놀이터)、月光餐厅(Dalbit Sikdang / 달빛 식당，各国美食)、月光商店(Dalbit Sangjeom / 달빛 상점)、月光休息处(Dalbit Swimteo / 달빛 쉼터)、月光工坊(Dalbit Gongbang / 달빛 공방)、月光画廊(Dalbit Gaelleori / 달빛 갤러리)、嘟嘟驼峰画布(Ttuttu Nakdabong Kaenbeoseu / 뚜뚜낙타봉 캔버스)。
  • 特别节目:每周都不同。举办了水枪庆典潜水桥Water Wars、潜水桥秋季运动会、月光中秋大联欢、潜水桥美食之路、月光潜水桥等。

2026年汉江Seorae岛野餐音乐会“秋日浪漫”(2026 Hangang Seoraeseom Pikeunik Konseoteu Gaeul Nangman / 2026 한강 서래섬 피크닉 콘서트 가을낭만)，盘浦汉江公园Seorae岛1桥野餐场(Banpo Hangang Gongwon Seoraeseom 1-gyo Pikeunik-jang / 반포한강공원 서래섬 1교 피크닉장)，☎ 02-120，于2026年10月9~11日举办。时间为13:00~19:00(体验到18:00)，设有音乐演出、体验节目和休息处。演出·体验·休息处免费，野餐美食市集等部分收费。

⚠ 行前须知 3 点

  1. 月光彩虹喷泉11月~3月14日不运行 — 3月15日起再次运行，可能因天气停止。
  2. 喷泉每场只运行20分钟 — 12:00、19:30、20:00、20:30、21:00，7~8月增加21:30。
  3. 2026年潜水桥Ttubeokttubeok庆典和Seorae岛野餐音乐会已经结束 — 分别于9月6日~10月25日、10月9~11日举办了。

⚙ FAQ 2

Q. 什么时候可以看到彩虹喷泉?

A. 按观光公社登记信息，3月15日~6月和9~10月的12:00、19:30、20:00、20:30、21:00，7~8月到21:30为止，每天运行6场。每场20分钟。11月~3月14日不运行。2026年自6月1日起为节能只在19:30、20:00、20:30运行3场(首尔市公告)。

Q. 喷泉周边有可以休息的地方吗?

A. 盘浦大桥和潜水桥南端有盘浦汉江公园月光广场(Banpo Hangang Gongwon Dalbit Gwangjang / 반포한강공원 달빛광장)。据观光公社介绍，周边有设在盘浦大桥两侧的月光彩虹喷泉。广场全天开放。
