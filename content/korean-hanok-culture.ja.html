韓国のハノク文化 — マダン・大庁・オンドル、自然を取り込んだ韓国式の家

ハノク (한옥)・マダン (마당)・大庁マル (대청마루)・サランチェ (사랑채)・チョマ (처마)・背山臨水 (배산임수) — 外国人向け韓国伝統家屋の解説。「きれいな瓦屋根の家」ではなく、「なぜこう建てたのか・何が込められているのか・どのように自然を取り込んだのか」。

北村 (북촌) や全州ハノク村 (전주 한옥마을) の路地を歩いていると、外国人はほぼ同じ反応をします — 曲線を描いて空へわずかに反り上がった瓦屋根 (기와지붕)、障子紙を貼った格子の戸、そして家に入るとマルが敷かれた涼しい床と、ど真ん中にぽっかり空いた中庭 (마당)。多くの人はこれを「きれいな伝統的ハノク (한옥)」程度に写真に収めて通り過ぎます。ところがハノクは単なる「古くて素敵な家」ではありません。一つの部屋、一枚のマル、一筋の軒先、中庭の位置まで — ほぼすべての要素が韓国の自然・気候・生活哲学に従って設計された産物なのです。

核心はこれです。ハノク (한옥) は、夏も冬も過酷な朝鮮半島の気候を一軒の家で同時に耐え抜くために作られた建築です。だから、冬に足元から温めるオンドル (온돌)（→ #1141）と、夏に風が通る木のマル（大庁 (대청)）が一軒に共存します。また自然に逆らわず、山を背にして水を望む場所（背山臨水 (배산임수)）に、木・土・石・韓紙 (한지)といった自然素材で建てられ、「呼吸する家」と呼ばれます。この記事は「どのハノク村がきれいか」（→ 場所ガイド）ではなく、ハノクの空間構成・自然哲学・なぜこう建てたのかを外国人の目線で解きほぐします。韓国文化解説シリーズ第65弾。

オンドル（#1141）との違い：オンドル (온돌) は「床を温める暖房技術」一つを扱います。ハノクはそのオンドルを内包する家・空間・建築全体 — 中庭・大庁・サランチェ・軒先・風水まで — を扱います。両者は部分と全体の関係です。

核心：ハノクのアイデンティティは「瓦屋根」ではなく、「マダン (마당、空の中心) + マル (마루、夏) + オンドル (온돌、冬) + チョマ (처마、光の調節)」の組み合わせです。この四つが、半島の四季を一軒で耐え抜かせます（下記 ②③④）。

⚠️ 外国人がよく誤解する3つ

1. 「ハノク (한옥) = ただのきれいな瓦屋根の家」 ❌ — 瓦屋根はハノクの見た目にすぎません。本質は空間配置（アンチェ・サランチェ・マダン）と自然親和の設計（チョマ・チャンホ・背山臨水）。同じ瓦屋根でも、部屋・マル・中庭の関係がハノクをハノクたらしめます。

2. 「マダン (마당) はただの庭」 ❌ — ハノクのマダンは花と芝で埋めた西洋式の庭ではなく、わざと空けておいた土の地面です。光を反射して部屋を明るくし、風を引き込み、婚礼・祭祀・農作業といった家の行事が繰り広げられる舞台です。「空けること」が機能なのです。

3. 「ハノクは暖房が弱く寒い昔の家」 ❌ — ハノクは冬のオンドル（暖かい部屋）+ 夏の大庁マル（涼しいマル）という季節の二重システムを備えた家です。一軒の中で冬の空間と夏の空間が分かれており、むしろ半島の気候に精緻に合わせられています。

① ハノク (한옥) とは何か — 「家」ではなく「自然を取り込んだ構造」

ハノク (韓屋 / 한옥) は文字どおり「韓国の家」、すなわち韓国の伝統家屋を指します。最大の特徴は、家を自然から切り離さないという点です。

  • 素材が自然そのもの：柱や梁は木、壁は土（黄土 (황토)、オークル色の粘土）、礎石と基壇は石、戸と窓は韓紙 (한지) を貼ります。すべて自然から来て自然へ還る素材です。だからハノクは英語圏で「breathing house（呼吸する家）」と紹介されます — 土壁と韓紙が湿気を含んでは吐き出し、室内の空気を調節するからです。
  • 内と外の境界が曖昧：部屋 → トェンマル (툇마루) → 大庁 (대청) → マダン (마당) → 自然へと、室内から外へ段階的につながります。戸（チャンホ (창호)）を持ち上げて軒先に掛ければ、部屋と中庭が一つの空間のように開け放たれます。「壁で塞がれた箱」ではなく「自然とつながる層」です。
  • 目的は人と自然の調和：ハノクのあらゆる仕掛け（軒の角度・中庭の位置・家の向き）は、光・風・水・山に逆らわず取り込んだり遮ったりするためのものです。これがハノクを単なる建物ではなく「自然哲学の込もった構造物」にしています。

② 空間構成 — アンチェ・サランチェ・大庁・マダン

ハノク、特に規模のある両班 (양반、貴族) の家は、一つの大きな建物ではなく、複数の棟 (dong) が中庭をはさんで集まった構造です。棟ごとに役割が違います。

  • アンチェ (內舍 / 안채)：家の最も奥、女主人をはじめとする女性の生活空間。母屋・向かいの部屋・台所が集まり、外部の視線が届かない私的領域です。
  • サランチェ (舍廊 / 사랑채)：外側に置いた主人（男性）の空間であり、客の接待・書斎の領域。儒教文化が根づくにつれ、サランチェを大きく立派に建てる流れが生まれ、高いマルであるヌマル (누마루、樓마루) が付くこともありました。
  • ヘンナンチェ (行廊 / 행랑채)：門のそばの付属空間。使用人が住んだり、倉庫・馬屋として使われたりしました。
  • 大庁マル (大廳 / 대청마루)：アンチェの真ん中に置かれた最も広い木のマル。母屋と向かいの部屋、部屋と中庭をつなぐ動線のハブであり緩衝空間です。暑くなれば食事・就寝・余暇がすべて大庁で行われ、空けておけば接客・宴会の場になります（下記 ④ で再述）。
  • マダン (中庭 / 마당)：棟と棟に囲まれた空の土の庭。棟ごとに内庭 (an-madang / 안마당) とサラン庭 (sarang-madang / 사랑마당) に分かれることもあります。穀物を干し、婚礼と祭祀を行い、光と風が出入りする家の心臓です。

核心は「分離と連結」です。男/女（サランチェ/アンチェ）、内/外（部屋/マダン）、私的/公的な空間が、棟と中庭で分かれながらも動線でつながります。一軒の家に韓国社会の秩序と生活のリズムがそのまま込められています。

③ 自然素材・通風・採光 — 「呼吸する家」の秘密

ハノクが自然親和の建築と呼ばれる理由は、素材と空気の流れにあります。

  • 韓紙のチャンホ (한지 窓戶)：ハノクの戸と窓はガラスではなく韓紙 (한지、楮の紙) を貼ります。韓紙は世界的にも丈夫で中性の紙で、ガラスより断熱効果が高いうえ、微細な孔から新鮮な空気を通して自然換気します。冬は暖かい空気を閉じ込め、光は柔らかく濾して入れます。「閉じているのに呼吸する」窓です。
  • 黄土の土壁 (황토)：土壁は湿気が多ければ含み、乾けば吐き出して室内の湿度を自ら調節します。夏は涼しく冬は温もりを抱え込みます。
  • 通風の設計：大庁マルは前後に開けて通り抜けの風（通風）が通るようにします。夏は中庭の暑い空気と家の裏の日陰の冷たい空気の温度差で、自然の風が家を通り抜けます。エアコンなしで暑さを冷ます構造です。
  • 採光の設計：中庭の明るい土の地面が日差しを反射して、部屋の奥深くまで光を入れます。マダンは単なる空き地ではなく、「光の反射板」の役割を果たします。

つまりハノクは、木・土・石・韓紙という自然素材と、マダン・大庁・チャンホをつなぐ空気・光の道を通じて、機械なしで気候を治める家なのです。

④ オンドル + マル — 冬と夏を一軒の家で

ハノクを理解する最も重要な鍵は、一軒の中に「冬の空間」と「夏の空間」が別々にあるという点です。

オンドル部屋 (온돌방)（冬） 大庁マル (대청마루)（夏）
床 石・土を温めるオンドル (온돌)（→ #1141） 涼しい木のマル
原理 焚き口（アグンイ (아궁이)）の火で床を温める（輻射暖房） 前後に開けて風が通る（通風）
用途 冬の就寝・生活 夏の食事・休息・接客
感覚 足元から暖かい 足の裏から涼しい
  • オンドル (溫突 / 온돌)：床下に火の熱を通して床を温める韓国固有の輻射暖房。冬の厳寒に耐えるための仕掛けです。（作動原理・歴史・座式生活は → #1141 オンドル文化 を参照）
  • 大庁マル (大廳 / 대청마루)：地面から浮かせて作った木のマルで、床下を風が通り抜けるため夏に涼しいです。暑さが来ると、家族の生活がオンドル部屋から大庁へ移ります。

朝鮮半島は夏が暑く湿気が多く、冬は長く寒い — 二つの極端な気候です。普通、他の国の伝統家屋はどちらか一方（寒さか暑さ）に合わせて建てられますが、ハノクはオンドル（冬）+ マル（夏）を一軒に共に収め、両極端を同時に解決しました。これがハノクの空間設計の最も賢いところです。

⑤ 背山臨水・風水 — 家を「どこに」置くか

ハノクは家を建てる前に立地から見ます。その原理が風水（プンス (풍수、風水)）であり、その核心が背山臨水（ペサンイムス (배산임수、背山臨水)）です。

  • 背山臨水 (배산임수)：文字どおり「山を背にして（背山）水に臨む（臨水）」。後ろに山が遮り、前に川・小川が流れ、家は南向きを見る場所が理想です。
  • なぜそうするのか — 自然科学的にも合理的：
  • 山が後ろに → 冷たい北西風を遮って冬の保温、山から下りてくる水・薪を確保。
  • 水が前に → 農作と飲み水、視界が開けて採光・通風が優れる。
  • 南向き → 冬の日差しを深く入れ、夏の日差しは軒先で遮る。
  • 明堂（ミョンダン (명당、明堂)）：こうした場所を風水で「明堂 (명당、吉地)」と呼びます。単なる迷信ではなく、日照・通風・排水・防風が良い、健康に暮らしやすい自然条件を選んだ結果です。
  • チョマ (처마) の角度も同じ哲学の延長です。軒先は夏の日（高く昇る）は遮り冬の日（低く昇る）は入れるよう、長さを計算して張り出します。同じ窓なのに夏は日陰、冬は日差しが入ります。

つまりハノクは、一つの建物のデザインではなく「土・山・水・日・風」まで含めた風景の設計です。家を自然の中に「据える」考え方なのです。

⑥ 地域差と現代のハノク — 北村からハノクステイまで

① 地域によって形が違う。 朝鮮半島は南北で気候差が大きく、ハノクの平面（上から見た形）も地域ごとに違います。

地域 平面の形 特徴
南部（開放型） 一（イル）字形 部屋・大庁が一列に開ける。暑さ対策の開放・通風が中心
中部 ㄱ（キヨク）字形 母屋と向かいの部屋の間に大庁。南部・北部の折衷
北部（閉鎖型） ㅁ（ミウム）字形 建物が中庭を四方から囲む。寒風を遮り温もりを保存

暖かい南ほど開いた一字形、寒い北ほど閉じたㅁ字形。同じハノクでも気候に応じて身を伸ばしたり縮めたりします — 自然に合わせて形が変わるわけです。

② 現代でハノクは再びよみがえっている。 ハノクは博物館の中の遺物ではありません。

  • 北村ハノク村 (북촌 한옥마을、ソウル)：景福宮（キョンボックン (경복궁)）と昌徳宮（チャンドックン (창덕궁)）の間、都市の真ん中で生き残った都市型ハノクの密集地。実際に住民が暮らす村であり、代表的な散歩コースです。
  • 全州ハノク村 (전주 한옥마을)・安東河回村 (안동 하회마을)：全州は700余りの家が集まった代表的なハノク群落、安東河回村は昔の氏族村の形を保存したユネスコ世界遺産（韓国の歴史村）です。
  • ハノクステイ / ハノクホテル (한옥스테이)：ハノクで一晩泊まる宿泊。マルに座って中庭を眺め、オンドル部屋で眠る体験が外国人観光客に人気です。
  • 新ハノク（シンハノク (신한옥、新韓屋)）・生活ハノク：伝統の木造構造と軒先・中庭の美学は生かしつつ、断熱・配管・台所などは現代技術で補った新しいハノク。都市に建てる「今日のハノク」です。

⑦ 外国人ハノク体験ガイド — どう楽しむか

営業・料金は店舗・季節により異なる — 訪問前に公式チャンネルの確認を推奨。

  • 歩く：北村（ソウル）・全州ハノク村・安東河回村が代表的な散歩地。北村は実際に人が住む村なので、静かに・写真のマナーを守ることが大切です（早朝は人が少なく写真向き）。
  • 一晩泊まる（ハノクステイ）：マル・中庭・オンドルを直に体験するなら、ハノクのゲストハウス/ハノクホテルが最高です。オンドル部屋で靴を脱いで床に寝る経験は、ハノクの核心を体で知ることになります。
  • こう見ると深い：
  • 屋根ではなくマダンの位置と大庁の開いた方向を見てください — 光・風の道が見えてきます。
  • 軒先の端 (처마) を見てください — 夏の日を遮る角度に計算されています。
  • チャンホ（韓紙の戸）に触れてみてください — 閉じていても光がにじむのが、ハノクの感覚です。
  • マナー：人が住むハノク・伝統家屋は私有地のことが多いです。むやみに入ったり窓をのぞいたりしないこと。靴はマル・部屋の前で脱ぎます。

❓ 外国人がよく尋ねる質問（FAQ）

  • ハノクとオンドルは同じものですか？ — いいえ。オンドル (온돌、#1141) は「床を温める暖房技術」で、ハノク (한옥) はそのオンドルを含む家全体（マダン・大庁・サランチェ・チョマ・風水）です。オンドルはハノクを構成する一部分です。
  • マダンはなぜ空いているのですか？ — わざと空けています。光の反射・通風・家の行事（婚礼・祭祀・農作業）の舞台だからです。西洋式の芝の庭とは目的が違います。
  • ハノクで寝ると寒いですか？ — 冬はオンドル部屋が暖かく、夏は大庁マルが涼しいです。季節に合った空間を使うよう設計されているので、むしろ快適です。
  • ハノクはすべて両班（貴族）の家ですか？ — いいえ。規模の大きな両班の家は複数の棟（アンチェ・サランチェ）に分かれますが、庶民のハノク（草葺き・小さな瓦の家）もマル・オンドル・マダンの基本原理は同じです。
  • ソウルでハノクを見るには？ — 北村ハノク村・西村（ソチョン (서촌)）が代表的。都心の都市型ハノクなのでアクセスが容易です。奥深い田舎のハノクは全州・安東河回村へ。
