🎯 为什么需要这份韩式生鱼片指南

外国游客对韩式生鱼片最大的误解，就是觉得"跟日本寿司一样"。其实完全不同。韩式生鱼片以活鱼 (Hwaleo / 활어) 为正宗——现场宰杀后立即上桌，搭配醋辣酱 (Chojang / 초장) 与包菜 (Ssam / 쌈) 的包食文化，扎根于鹭梁津 (Noryangjin / 노량진)、札嘎其 (Jagalchi / 자갈치) 等市场文化。日本寿司则是熟成 (Sukseong / 숙성) + 米饭 + 酱油的组合；韩式生鱼片 = 活鱼 + 醋辣酱 + 包菜。同样叫"Korean sashimi"，牙鲆鱼 (Gwang-eo / 광어，活鱼#1)、鰤鱼 (Bang-eo / 방어，冬季正宗·札嘎其)、金枪鱼腩 (Chamchi-Otoro / 참치 뱃살，油脂#1)、三文鱼 (Yeon-eo / 연어，全球人气)、鲷鱼 (Do-mi / 도미，韩定食)、斑鰶鱼 (Jeon-eo / 전어，秋季正宗) 各自有不同的时令与拥趸。外国游客通常不知道：(a) 活鱼与熟成的区别 (b) 醋辣酱与山葵 (Wasabi / 와사비) 的区别 (c) 包菜文化 (d) 辣鱼汤 (Maeuntang / 매운탕) 收尾这道流程。本指南将介绍6种鱼全解析、活鱼与熟成对比，以及韩式生鱼片全席。

  • 韩式生鱼片 = 活鱼 = "弹牙口感"，现场宰杀
  • 日本寿司 = 熟成 = "鲜味"，熟成1~3天

⚠ 外国游客常见的5个误区

1. "韩式生鱼片=日本寿司"：韩式生鱼片以活鱼为正宗，搭配醋辣酱、包菜；日本寿司以熟成为主，搭配酱油、米饭。是完全不同的两种料理。

2. "活鱼只是代表新鲜"：活鱼带来的是弹牙口感，现场宰杀正宗；熟成带来的是鲜味。

3. "鰤鱼四季都吃得到"：鰤鱼冬季12~2月#1才是正宗 (其他季节多为养殖或冷冻)。

4. "斑鰶鱼是普通生鱼片"：斑鰶鱼秋季9~10月#1正宗 (韩国俗语"秋天斑鰶鱼"即由此而来)。

5. "只吃生鱼片就结束"：韩式吃法是生鱼片+辣鱼汤套餐 (最后以辣鱼汤收尾)。

⚙ 常见问题8则

1. 外国游客入门首选：牙鲆鱼+三文鱼 (全球熟悉) → 鰤鱼 (冬季) → 金枪鱼 (油脂爱好者)。

2. 拍照·vlog推荐：札嘎其鰤鱼、鹭梁津凌晨市场、金枪鱼toro。

3. MZ世代趋势：三文鱼自助、金枪鱼toro、MZ人气生鱼片店。

4. 冬季拥趸：鰤鱼 (#1) +牙鲆鱼+鲷鱼。

5. 秋季拥趸：斑鰶鱼 (#1) +江华·苏来浦口。

6. 过敏：鱼类·甲壳类交叉污染需事先告知店家。

7. 结账·小费：市场=现金卡皆可 / 生鱼片店=可刷卡 / 无需小费。

8. 退税：餐饮一般不适用退税。

⚠ 医疗·安全·饮食须知

生鱼片是未经加热的生鱼，需注意食物中毒风险。孕妇建议避免食用生鱼片 (依CDC建议)。儿童仅建议食用熟食 (5岁以上)。过敏 (鱼类·甲壳类·酱油中的麸质) 需事先告知。若怀疑食物中毒，请拨打 1339 (医疗咨询，提供英语服务)。本指南仅为一般信息，非医疗建议。

饮食限制替代方案：

  • 清真·犹太洁食：6种鱼类一般视为清真可食 (各权威机构意见不一，建议向店家确认)；犹太洁食方面，牙鲆鱼·鰤鱼·鲷鱼·三文鱼·金枪鱼·斑鰶鱼因带鳍带鳞，均符合规定。
  • 素食·纯素：6种鱼类皆非素食；素食可选拌饭或寺庙料理。
  • 无麸质：生鱼片本身无麸质；酱油含麸质 (可要求替换为溜酱油tamari)。
