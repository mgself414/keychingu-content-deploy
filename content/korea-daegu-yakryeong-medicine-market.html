ISSUE 04 · #1002 · 2026-06-08

🎯 왜 대구 약령시 가이드인가

대구 약령시 (Yakryeong) = 한국 #1 한약 거리·1658년 (조선 효종 9년) 개시·350년+ 역사. UNESCO 인류무형문화유산 후보 (한약 전통). 외국인 페인포인트 = (a) "한약 = 쓴맛만" 잘못된 인식 (b) 한방차 시음·카페 매트릭스 모름 (c) 약재 비빔밥 = 약령시 특화 K-food (d) 매년 5월 약령시 축제 (한방·한복·전통 음악) (e) 박물관 영문 풀세트 cover (f) 한방 알레르기 사전 고지 모름.

본 가이드는 약령시 5축 시그니처 12선 + 한방차 매트릭스 + 5월 축제 + 외국인 영문 발화.

🏛 5축 deep dive

① 한약 거리 + 약전골목 (메인)

  • 시그니처: 한국 #1 한약 거리·1658년 (조선 효종 9년)~·350년+ 역사
  • 위치: 대구도시철도 1호선 중앙로역
  • 외국인 친화도: ★★★★ (한방 매니아·웰니스 fit)
  • 추천 매니아: 약전골목 산책 (1-2h) + 노포 한약 store 매니아

② 약령시 박물관 + 한국 한의학 박물관

  • 시그니처: 약령시 역사 cover·영문 안내 풀세트
  • 외국인 친화도: ★★★★★ (영문 ON·교육적)
  • 시간: 09:00~18:00·휴관 월요일·무료 (일부 특별전 5,000원)
  • 추천: 1시간 30분~2시간 코스

③ 약재 K-food (약재 비빔밥·죽·차)

  • 시그니처: 약재 비빔밥 (당귀·인삼·산약·도라지)·약재 죽·약재 떡
  • 외국인 페인포인트: 약재 알레르기 사전 고지 필수
  • 외국인 친화도: ★★★★ (안 매콤·웰니스 fit)
  • 가격: 12,000~25,000원/그릇

④ 한방차 카페 (전통 + 현대 fusion)

  • 시그니처: 약전골목 노포 (전통) + 카페 약령시 (MZ fusion) 2 cluster
  • 외국인 친화도: ★★★★★ (담백·매콤 X·인스타 fit)
  • 가격: 한방차 1잔 5,000~10,000원

⑤ 5월 약령시 축제 (매년 5월)

  • 시그니처: 매년 5월 첫 주~중순 5일간·한방·한복·전통 음악·체험
  • 추천: 약령시 한방차 무료 시음·한복 대여·전통 공연
  • 외국인 친화도: ★★★★★ (외국인 #1 매니아·문화 fit)

⚠ 외국인 자주 실수 5가지

1. "한약 = 쓴맛만": 쌍화차·유자차·생강차·대추차 = 안 쓴맛·달콤 매트릭스. 입문 1순위.

2. "약령시 = 한약 매장만": 한방차 카페 + 약재 K-food + 박물관 + 5월 축제 + 한방 마사지 5축 풀세트.

3. "한방 알레르기 X": 한약·약재 = 약초 알레르기 가능 (인삼·당귀·갈근 등). 사전 고지 + 한방의 사전 상담 권장.

4. "5월 축제 = 그냥 시장 축제": 5월 약령시 축제 = 한방·한복·전통 음악·5일간 풀세트. 외국인 #1 매니아·문화 fit.

5. "박물관 = 영문 X": 약령시 박물관·한국 한의학 박물관 = 영문 안내 풀세트·외국인 매니아 매트릭스 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: 박물관 (영문) + 한방차 카페 + 약재 비빔밥 = 2시간 코스.

2. 시즌: 매년 5월 약령시 축제 시즌 = 외국인 #1 매니아. 비축제 시기 = 박물관 + 카페 + 노포 매니아.

3. 한방 약재 구매: 외국인 = 한약재 처방 시 한방의 사전 상담 권장. 단순 한방차 (쌍화차·유자차) = 자유 구매 OK.

4. 귀국 선물: 진공 포장 한방차 (쌍화차·유자차·생강차) = 위탁 수하물 OK. 한약재 = 일부 국가 반입 제한 확인 필수.

5. 알레르기: 인삼·당귀·갈근·계피·꿀 = 일반 알레르겐. 사전 한방의 상담 + 알레르기 사전 고지 필수.

6. 추천 페르소나: 웰니스 매니아·시니어·여성 = #1 / MZ·인스타 매니아 = 카페 약령시 + 한복 대여 / 가족·어린이 = 박물관 + 차 시음.

⚠ 의료·안전·식이 disclaimer

한약·약재 = 약물 상호작용 (와파린·당뇨 약·고혈압 약 등). 임신부 = 한방 약재 일부 금기 (당귀·홍화 등). 어린이 = 약재 비빔밥 일부 매콤·약초 알레르기 주의. 식중독·복통 ☎ 1339.

식이 제한 fallback:

  • 할랄·코셔: 약재 비빔밥 채식 옵션 = 할랄 가능 / 한방차 = 대부분 OK
  • 채식·비건: 약재 비빔밥 (채식 옵션 OK)·한방차 (꿀 제외 시 비건 OK)
  • 글루텐 free: 한방차 OK·약재 비빔밥 (간장 빼면 OK)

✈️ 외국인 페인포인트 #1 — 한방차 귀국 선물

  • 추천: 진공 포장 쌍화차·유자차·생강차·대추차 = 위탁 수하물 OK
  • 가격: 쌍화차 100g 5,000~10,000원·유자차 1kg 15,000~25,000원
  • 구매처: 약전골목 노포·약령시 박물관 매장·이마트 트레이더스
  • 국가별 반입 제한: 호주·뉴질랜드·미국 일부 = 약초·한약재 반입 제한 — 자국 규정 사전 확인 필수
  • 유통기한: 진공 포장 한방차 = 6개월~1년 (밀봉)·개봉 후 3개월
