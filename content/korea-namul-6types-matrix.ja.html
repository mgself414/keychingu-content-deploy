韓国ナムル (나물) 6種総合ガイド — ほうれん草・桔梗・豆もやし・わらび・山菜・セリのフルセット

サブタイトル：外国人観光客向け韓定食おかず + 寺院料理 + ビビンバ正統6種ナムルガイド

ISSUE 03・#876・2026-06-09

🎯 なぜ韓国ナムルの総合ガイドが必要か

外国人観光客の韓国ナムル(나물)に対するペインポイント = 「ナムル＝草」としか知らず、マニア層の存在を知らない。韓国ナムル = 韓定食(ハンジョンシク、한정식、韓国式コース料理)のおかず(バンチャン、반찬、無料の付け合わせ)の定番 + 寺院料理の正統 + ビビンバ(비빔밥)5色フルセット + 世界的にベジタリアンに優しい。同じ「Korean vegetable side」でも、ほうれん草ナムル(全国#1・ビビンバ必須)・桔梗ナムル(山菜#1・高麗人参の同類根)・豆もやし(迎え酒(ヘジャン、해장、二日酔いを癒す韓国式食事)#1・#807との関連)・わらびナムル(山菜の正統・わらび湯(고사리탕))・チュィナムル(春の山菜#1)・セリナムル(春の香り野菜・デトックス)と、それぞれ材料・季節・マニア層が異なる。外国人観光客は(a)ビビンバが5色ナムルフルセットであること(b)寺院料理がすべてナムル系列で構成されていること(c)豆もやしが迎え酒スープと関連すること(d)山菜が春の正統食材であることを、知らないケースが多い。本ガイドは6種の総合比較 + ベジタリアン・ハラール対応の強調を扱う。

🍽 韓定食・寺院料理・ビビンバのシグネチャー

韓定食(한정식)おかずフルセット(#837)

  • 5品コース = ナムル4〜6種 + キムチ・漬物
  • 新羅ホテル(신라호텔)のラヨン(라연)、三清閣(삼청각)、仁寺洞(인사동) — 正統店
  • おかわり無料

寺院料理(사찰음식、Temple Cuisine)

  • 寺院料理 = ナムル6種系列の#1・伝統的なベジタリアン料理
  • おすすめ店：
  • 眞寛寺(진관사)(ソウル) — 寺院料理の正統
  • 曹渓寺(조계사) — 寺院料理系列
  • 奉恩寺(봉은사)・冠岳山(관악산) — 寺院料理マニアが集まる場所
  • ハラール・コーシャー・ベジタリアン＝OK(肉類・五辛菜(オシンチェ、오신채、寺院料理で禁じられる5種の刺激的野菜：にんにく・玉ねぎ・にら・ねぎ・アサフェティダ)不使用)

ビビンバ(비빔밥)5色の正統(#856)

  • 5色 = ほうれん草(緑)・にんじん(赤)・豆もやし(白)・わらび(茶)・桔梗(白)+ 卵(黄)
  • 全州ビビンバ = 正統#1・宮中ビビンバ系列

法事料理(제사음식、Ancestral Rites Food)

  • わらび・桔梗・ほうれん草 = 法事料理の代表ナムル3種
  • 旧正月(ソルラル、설날)・秋夕(チュソク、추석)(#846) — 正統

⚠ 外国人観光客がよくする5つの勘違い

1. 「ナムル＝草」：ナムル = 韓定食おかずの正統・マニアがいる料理・世界的にベジタリアンに優しい。

2. 「ビビンバ＝メインだけ」：ビビンバ = 5色ナムルフルセット(ほうれん草・にんじん・豆もやし・わらび・桔梗)。

3. 「寺院料理＝草だけ」：寺院料理 = ナムル6種系列 + 豆腐・きのこ・伝統的なベジタリアン料理。

4. 「豆もやし＝迎え酒だけ」：豆もやし = 韓定食・迎え酒・家庭料理すべてに登場。

5. 「山菜＝通年」：山菜(桔梗・チュィナムル・セリ・わらび) = 春3〜5月#1。

⚠ 医療・安全・食事に関する免責事項

ナムル＝ごく普通の植物性食品。妊婦・子ども＝OK(辛さは調整可能)。アレルギー(にんにく・醤油のグルテン・桔梗の薬用成分)は事前申告を。食中毒が疑われる場合は☎ 1339(医療相談、英語対応あり)へ。本ガイドは一般情報であり、医療的助言ではない。

食事制限がある場合の代替案：

  • ハラール・コーシャー：6種すべてOK(植物性食材)。
  • ベジタリアン・ヴィーガン：6種すべてOK(#1ベジタリアンの正統)。
  • グルテンフリー：醤油の調味料にはグルテンが含まれる(たまり醤油で代替可)。
  • 寺院料理(五辛菜不使用)：にんにく調味料を除けば6種すべてOK。
