韓国レトロ鉄道駅・廃駅ガイド — 文化駅ソウル284・ファランデ鉄道公園・京春線スプギル、キムユジョン駅・正東津駅・チュジョン駅、ファボン駅・ソムジンガンキチャマウルまで16か所

サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「感性鉄道駅」テーマで選ばれた場所のうち16か所 · ソウルは文化駅ソウル284(無料)・ファランデ鉄道公園(24時間)・京春線スプギル(常時開放) · 入場料・乗車料が登録された場所はソムジンガンキチャマウル(大人 5,000ウォン)・ウォルミバダ列車(平日 一般 11,000ウォン)の2か所(ヌンネの自転車レンタル・ファランデの駐車は別料金) · 月曜日休みと登録された場所は文化駅ソウル284・キムユジョン廃駅(屋外スペースを除く)・ウォルミバダ列車・ファランデ駅舎展示館・ファランデ鉄道公園トラム図書館・群山イムピ駅舎・コモ駅複合文化空間 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「感性鉄道駅 (Gamseong Gichayeok / 감성 기차역)」テーマで選ばれた100か所のうち、観光公社の観光情報で運営情報を確認できた16か所を扱います。表の順位と得票数は、その投票結果です。投票の名称と観光公社の観光情報の名称が違う場所は、住所で対応させました(例: 投票の「昌原 キョンファ駅 簡易駅 (Changwon Gyeonghwayeok Ganiyeok / 창원 경화역 간이역)」→「キョンファ駅公園 (Gyeonghwayeok Gongwon / 경화역공원)」、「ウォルミバダ駅 (Wolmi Bada-yeok / 월미바다역)」→「ウォルミバダ列車 (Wolmi Bada Yeolcha / 월미바다열차)」、「ヌンネ駅 廃駅 (Neungnae-yeok Pyeyeok / 능내역 폐역)」→「ヌンネ駅舎文化公園 (Neungnae Yeoksa Munhwa Gongwon / 능내역사문화공원)」)。ファランデ駅は「ファランデ鉄道公園 (Hwarangdae Cheoldo Gongwon / 화랑대 철도공원)」と「ファランデ駅舎展示館 (Hwarangdae Yeoksa Jeonsigwan / 화랑대역사 전시관)」の2つの情報を1項目にまとめました。

大部分は、営業をやめた昔の駅(廃駅)を公園・展示館・文化スペースに変えた場所です。正東津駅は観光列車が行き来する駅として紹介されています。ウォルミバダ列車は駅ではなく、月尾島をめぐる観光モノレールとして登録されています。

入場料・乗車料が登録された場所はソムジンガンキチャマウルとウォルミバダ列車の2か所です。残りは無料と登録されているか、料金の登録値がありません。ヌンネ駅舎文化公園の自転車レンタルとファランデ鉄道公園の駐車(2時間を超えた分)は、別に料金があります。運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。

📍 ソウル — 文化駅ソウル284・ファランデ鉄道公園・京春線スプギル

文化駅ソウル284、チュン区 (Jung-gu / 중구) トンイルロ 1 (Tongil-ro 1 / 통일로 1)、☎ 02-3407-3500 は、昔のソウル駅舎を復元した複合文化スペースです。1900年に南大門停車場として始まり、京城駅を経てソウル駅になり、2004年に旧駅舎が閉鎖された後、2011年8月11日に開館しました。建物の外観は1925年の京城駅を復元したものです。展示・公演・ワークショップと、スペースツアーのプログラムがあります。

  • 開く時間: 火曜日・木~日曜日 10:00~18:00(入場締切 17:30), 水曜日 10:00~19:00(入場締切 18:30)。
  • 休み: 毎週月曜日。展示準備期間は運営しないので、展示期間を確認してから行くようにと登録されています。
  • 料金: 無料。外国人も別途の予約は不要と登録されています。駐車: 不可能。

ファランデ鉄道公園、ノウォン区 (Nowon-gu / 노원구) ファランロ 608 (Hwarang-ro 608 / 화랑로 608)、☎ ノウォン区庁 ヨガドシ課 (Nowon-gu Cheong Yeoga Dosi-gwa / 노원구청 여가도시과) 02-2116-0668 は、昔のファランデ駅一帯を公園にした場所です。観光公社の紹介には、この駅が「ソウルの最後の簡易駅」とも「京春線の最後の簡易駅」とも書かれています。1939年の京春線開通の後、2010年に運行が止まった線路を撤去せずに生かしました。1950年代のミカ型列車と狭軌列車、チェコと日本の広島の路面電車が展示されています。

  • 開く時間: 24時間運営。トラム図書館 10:00~19:00, カフェ 11:00~21:00。
  • 休み: 年中無休(トラム図書館は毎週月曜日休み)。料金: 無料。駐車: 2時間無料、その後は5分あたり150ウォン。

ファランデ駅舎展示館、ノウォン区 ファランロ 610 (Hwarang-ro 610 / 화랑로 610)、☎ 070-4179-3777 は、昔のファランデ駅を改装して、京春線の歴史と鉄道資料を展示する場所です。

  • 開く時間: 10:00~18:00。休み: 毎週月曜日, 祝日の翌日, 1月1日, 旧正月・秋夕の連休。料金: 無料。

京春線スプギル、ノウォン区 ハゲドン (Hagye-dong / 하계동) 107-2、☎ 京春線スプギル ビジターセンター (Gyeongchunseon Supgil Bijiteo Senteo / 경춘선숲길 방문자센터) 02-3783-5977 は、昔の京春線の線路を公園に変えた道です。京春線は1939年7月25日に私設鉄道として開通し、2010年12月20日に最後の列車を運行しました。2013年から段階的に公園になりました。

  • 開く時間: 常時開放。休み: 年中無休。

📍 キョンギ・仁川 — ヌンネ駅舎文化公園・ウォルミバダ列車

ヌンネ駅舎文化公園、南楊州市 ジョアン面 (Joan-myeon / 조안면) タサンロ 566-5 (Dasan-ro 566-5 / 다산로 566-5)、☎ 南楊州市役所 文化観光課 (Namyangju Siyeokso Munhwa Gwangwang-gwa / 남양주시청 문화관광과) 031-590-4783 は、2008年12月に営業をやめたヌンネ駅を展示館に改装した場所です。待合室と線路が保存されていて、木の椅子・切符売り場・写真などの小物があります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。
  • 自転車レンタル: 1人用 1時間 5,000ウォン, 2人用 1時間 8,000ウォン。

ウォルミバダ列車、仁川 チェムルポ区 (Jemulpo-gu / 제물포구) チェムルリャンロ 269 (Jemullyang-ro 269 / 제물량로 269)、☎ 032-450-7600 は、月尾島を1周する観光モノレールです。総運行距離は6.1kmで、1周に約42分かかります。軌道は地上7~18mの高さにあります。

  • 開く時間: 繁忙期(4~10月)の平日(火~木) 10:00~18:00, 週末(金~日・祝日) 10:00~19:00。閑散期(11~3月) 10:00~18:00。
  • 休み: 毎週月曜日。
  • 料金: 平日 一般 11,000ウォン, 高齢者・青少年 8,000ウォン, 子ども 7,000ウォン。週末 一般 14,000ウォン, 高齢者・青少年 10,000ウォン, 子ども 8,000ウォン。
  • 乗り方: 初めて乗るときはウォルミバダ駅からしか乗れず、再び乗るときは4つの駅すべてから乗れると登録されています。

📍 カンウォン — キムユジョン廃駅・正東津駅・太白チュジョン駅・原州パンゴク駅

キムユジョン廃駅、春川市 シンドン面 (Sindong-myeon / 신동면) キムユジョンロ 1435 (Gimyujeong-ro 1435 / 김유정로 1435)、☎ 033-261-7780 は、1939年にシンナム駅 (Sinnam-yeok / 신남역)として開業し、2004年にキムユジョン駅へ名前を変えました。観光公社の紹介によると、韓国の鉄道駅の中で初めて人の名前を使った駅です。2010年に新しい駅舎ができて、旧駅は営業をやめました。線路に昔のムグンファ号の列車が残っていて、車内はブックカフェと観光案内センターに変わりました。

  • 開く時間: 常時開放。休み: 毎週月曜日(屋外スペースは年中無休)。開く時間の欄の「常時開放」と休みの欄の「月曜日」が一緒に登録されています。
  • 料金: 無料。駐車: 無料。

正東津駅、江陵市 カンドン面 (Gangdong-myeon / 강동면) チョンドンヨクキル 17 (Jeongdongyeok-gil 17 / 정동역길 17)、☎ 砂時計観光案内センター (Moraesigye Gwangwang Annae Senteo / 모래시계관광안내센터) 033-640-4536 は、観光公社の紹介によると、全国で海にいちばん近い駅です。1962年に普通駅として営業を始め、1995年にドラマ『砂時計』の舞台になって、日の出の名所として知られるようになりました。

  • 開く時間: 路線ごとに異なると登録されています。休み: 年中無休。駐車: 可能。

太白チュジョン駅、太白市 サリバッキル 47-63 (Ssaribat-gil 47-63 / 싸리밭길 47-63)、☎ 033-553-8550 は、海抜855mにあります。観光公社の紹介によると、韓国でいちばん高い場所にある鉄道駅です。1973年に開業し、石炭を運ぶ駅でした。休憩所に駅長・駅員の制服と帽子があり、駅員体験ができます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

原州パンゴク駅、原州市 タルマジュン3ギル 30 (Dalmajung 3-gil 30 / 달마중3길 30)、☎ 原州市役所 観光課 (Wonju Siyeokso Gwangwang-gwa / 원주시청 관광과) 033-733-1330 は、1941年に営業を始めた中央線の駅舎です。2005年に登録文化遺産に登録され、2021年の中央線の新路線開通の後、廃駅になりました。春には駅舎の周りに桜が咲きます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 大邱 — ファボン駅・コモ駅複合文化空間

ファボン駅、軍威郡 サンソン面 (Sanseong-myeon / 산성면) サンソンガウムロ 711-9 (Sanseonggaeum-ro 711-9 / 산성가음로 711-9)、☎ 軍威郡庁 文化観光課 (Gunwi Guncheong Munhwa Gwangwang-gwa / 군위군청 문화관광과) 054-380-6065 は、1938年12月1日に中央線の普通駅として営業を始めました。2024年12月に中央線が廃線になって廃駅になりました。駅舎の建物は1936年に建てられ、高さ25mの給水塔が残っています。待合室に駅の歴史の写真や駅員の帽子などを展示しています。

  • 開く時間: 09:00~17:00。休み: 年中無休。料金: 無料。

コモ駅複合文化空間、スソン区 (Suseong-gu / 수성구) コモロ 208 (Gomo-ro 208 / 고모로 208)、☎ 053-791-3334 は、営業をやめたコモ駅を文化スペースに変えた場所です。駅舎館と文化館に分かれたコモミュージアム、ガーデンと散策路があります。

  • 開く時間: 4~11月 10:00~18:00, 12~3月 10:00~17:30。
  • 休み: 毎週月曜日, 1月1日, 旧正月・秋夕の当日。料金: 無料。団体見学はホームページでの予約が必須と登録されています。

📍 釜山 — ソンジョン駅(旧)

ソンジョン駅(旧)、ヘウンデ区 (Haeundae-gu / 해운대구) ソンジョンチュンアンロ8ボンギル 60 (Songjeongjungang-ro 8beon-gil 60 / 송정중앙로8번길 60)、☎ ヘウンデ ブルーラインパーク (Haeundae Beullurain Pakeu / 해운대 블루라인파크) 051-701-5548 は、東海南部線の駅です。1934年に簡易駅として営業を始め、1941年に普通駅になりました。登録文化遺産に登録されています。今は東海南部線の古い線路を使うヘウンデ海辺列車 (Haeundae Haebyeon Yeolcha / 해운대 해변열차)の始発駅であり終着駅です。

  • 開く時間: 09:30~22:00(状況によって変わることがあります)。休み: 年中無休。駐車: 無料。

📍 チョンブク — 群山イムピ駅舎・旧ソド駅

群山イムピ駅舎、群山市 イムピ面 (Impi-myeon / 임피면) ソウォンソッコンロ 37 (Seowonseokgok-ro 37 / 서원석곡로 37)、☎ 063-454-3923 は、1936年ごろに群山線の駅舎として建てた建物です。観光公社の紹介には、日本統治時代の群山線が全羅南北道の農産物を群山港を通じて日本へ送り出す道だったと書かれています。今は客車展示館と公園を備え、この地域出身の小説家チェ・マンシク (Chae Mansik / 채만식)の作品の話とあわせて紹介しています。

  • 開く時間: 10:00~18:00。休み: 毎週月曜日。料金: 無料。

旧ソド駅、南原市 サメ面 (Same-myeon / 사매면) ソドギル 32 (Seodo-gil 32 / 서도길 32)、☎ 南原市役所 地域活力課 (Namwon Siyeokso Jiyeok Hwallyeok-gwa / 남원시청 지역활력과) 063-620-6684 は、1932年に建てられ、観光公社の紹介によると、韓国でいちばん古い木造建物の廃駅です。2004年に旅客の取り扱いをやめました。チェ・ミョンヒ (Choe Myeonghui / 최명희)の大河小説『ホンブル』の主な舞台です。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 チョンナム・キョンナム — ソムジンガンキチャマウル・キョンファ駅公園

ソムジンガンキチャマウル、谷城郡 オゴク面 (Ogok-myeon / 오곡면) キチャマウルロ 232 (Gichamaeul-ro 232 / 기차마을로 232)、☎ 061-362-7461 は、旧谷城駅にあります。昔の蒸気機関車の姿を復元した列車が、旧谷城駅(ソムジンガンキチャマウル)からカジョン駅 (Gajeong-yeok / 가정역)まで10kmの区間を往復すると紹介されています。

  • 開く時間: 09:00~20:00(入場締切 18:00)。休み: 年中無休。
  • 入場料(個人): 大人 5,000ウォン, 小人・敬老優待者 4,500ウォン。詳しくはホームページと電話で確認するようにと登録されています。

キョンファ駅公園、昌原市 鎮海区 (Jinhae-gu / 진해구) チンヘデロ 649 (Jinhae-daero 649 / 진해대로 649)、☎ 055-548-4000 は、営業をやめたキョンファ駅を中心に作った公園です。春には線路沿いに桜のトンネルができます。

  • 開く時間: 常時開放。休み: 年中無休。

⚙ FAQ 3

Q. ソウルから行ける場所は?

A. 文化駅ソウル284(昔のソウル駅舎を復元した複合文化スペース)、ファランデ鉄道公園・ファランデ駅舎展示館、京春線スプギルです。入場料は無料と登録されているか、登録値がありません。

Q. 列車に乗れる場所は?

A. 列車の運行が紹介されているのは、正東津駅(観光列車)、ソンジョン駅(旧)(ヘウンデ海辺列車の始発駅・終着駅)、ソムジンガンキチャマウル(観光用の列車がカジョン駅まで往復)、ウォルミバダ列車(観光モノレール)です。正東津駅の運行時間は路線ごとに異なると登録されています。

Q. お金がかかる場所は?

A. ソムジンガンキチャマウル(大人 5,000ウォン)とウォルミバダ列車(平日 一般 11,000ウォン, 週末 一般 14,000ウォン)です。ヌンネ駅舎文化公園の自転車レンタルは1人用 1時間 5,000ウォン、2人用 1時間 8,000ウォンで、ファランデ鉄道公園の駐車は2時間無料の後、5分あたり150ウォンです。
