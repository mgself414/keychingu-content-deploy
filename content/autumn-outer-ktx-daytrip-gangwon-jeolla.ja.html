⚠ 外国人観光客がよくやる失敗 3

1. 「紅葉 = どこでも同じ時期」 — 江原 vs 全羅 = 2週間の差

外国人多数 = 「Korea autumn = late October」。実際 = 江原 10月中旬〜10月末(Seoraksan・Jeongdongjin・Donghae ピーク)/ 全羅 Naejangsan 11月初〜11月中(全国紅葉最後)(KMA・KNPS 平年値)。10月最終週 = 江原ピーク / 11月第1〜2週 = 全羅ピーク。外国人が 11月中旬に韓国に到着しても、江原の紅葉は終わっていても 全羅 Naejangsan はピーク が可能。ルール = 紅葉シーズン = 10月25日〜11月15日 ゴールデン3週(江原 → ソウル → 全羅 の順)。

2. 「KTX = 高い」 — KORAIL PASS = 外国人専用無制限

外国人の 30%+ = 「KTX は高すぎる → 当日諦め」。実際 KORAIL PASS = 外国人専用無制限パス(3日・5日・7日) · 外国人専用価格(韓国人より安い) · 3日パス 約 121,000ウォン(3日 KTX・セマウル・ムグンファ フル運行) · 5日パス 約 159,000ウォン · 3日 = 江原 1泊 + 全羅 1泊 + ソウル 1day = 韓国秋紅葉フルツアー。外国人専用情報 = visitkorea・KORAIL 英語サイト。

3. 「Naejangsan ケーブルカー = 山頂まで」 — 実は Yeonjabong まで

外国人多数 = 「ケーブルカー → 楽に山頂まで」。実際 Naejangsan ケーブルカー = ビジターセンター ↔ Yeonjabong(海抜 460m) · Yeonjabong → Sinseonbong(763m) 山頂 = 徒歩で約 1時間の追加登山 が必要。山頂チャレンジ = 体力 2〜3。ケーブルカーのみ = Yeonjabong 紅葉 view + 入門 OK。ルール = Naejangsan ケーブルカー = 入門紅葉 view OK / 山頂チャレンジ = +1時間。
