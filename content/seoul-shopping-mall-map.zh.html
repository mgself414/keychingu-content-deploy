🎯 本指南的使用方法

推开旋转门走进去，一楼先扑来香水味，地下一层则是烤面包的香气。本指南按分店整理了首尔及近郊的百货商店·综合购物中心·奥特莱斯共12处。地址、营业时间、休息日、外国游客服务，只采用今天直接从VisitKorea旅游信息(TourAPI)和各公司官方门店页面读到的数值。免税店请看#915 免税店指南，超市和便利店请看#916 超市·便利店指南。

旧版指南把骊州·始兴的奥特莱斯写成"现代奥特莱斯"，但VisitKorea上登记的这两处正式名称是新世界西蒙 (Sinsegye Saimon / 신세계사이먼) Premium Outlets。"韩国最好的百货商店"、"名牌折扣30~70%"之类的说法没有出处，已删除。

🏬 百货商店 — 4处

  • 乐天百货本店 (Lotte Baekhwajeom Bonjeom / 롯데백화점 본점) — 首尔中区 (Jung-gu / 중구) 南大门路 (Namdaemun-ro / 남대문로) 81号(VisitKorea)。正常营业 10:30~20:00，延长营业 10:30~20:30，餐饮区 10:30~21:00。每月休息1天(已公告2026年10月12日·11月9日 — 都是第二个周一)。之后的日期请在官方页面确认。艾维纽尔 (Avenuel / 에비뉴엘) 的营业时间与百货商店相同。总机 1577-0001(乐天百货官方门店页面)。主馆和艾维纽尔地下一层服务台旁有自动换汇机(乐天百货英文官方网站)。退税方式 即时+事后(VisitKorea旅游信息)
  • 新世界百货本店 (Sinsegye Baekhwajeom Bonjeom / 신세계백화점 본점) — 首尔中区 (Jung-gu / 중구) 小公路 (Sogong-ro / 소공로) 63号。旧馆于1930年10月24日开业(VisitKorea)。正常营业 10:30~20:00，延长营业 10:30~20:30，餐饮区 11:00~21:30，每月休息1天(2026年10月公告为25日周日 — 星期并不固定)。去之前请在官方页面确认当月日期。总机 1588-1234(新世界百货官方门店页面)。同一栋楼的8~12层是新世界免税店明洞店 (Sinsegye Myeondaejeom Myeongdongjeom / 신세계면세점 명동점)(新世界免税店官方网站)
  • THE HYUNDAI SEOUL (现代首尔 / Deo Hyeondae Seoul / 더현대 서울) — 首尔永登浦区 (Yeongdeungpo-gu / 영등포구) 汝矣大路 (Yeoui-daero / 여의대로) 108号。2021年2月26日开业。周一~周四 10:30~20:00，周五~周日 10:30~20:30，餐饮区 10:30~22:00。休息日每月不同，请查看官网。5层有室内花园"声音森林 (Sounds Forest / 사운즈 포레스트)"，1层有人工瀑布"瀑布花园 (Waterfall Garden / 워터폴 가든)"。电话 1588-3650(VisitKorea)
  • 加乐利亚百货名品馆 (Galleria Baekhwajeom Myeongpumgwan / 갤러리아백화점 명품관) — 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 343号。隔着一条马路分为EAST和WEST两馆。每月休息1次，电话 1544-6600(VisitKorea)。今日营业时间 10:30~20:00(加乐利亚官方网站，2026-10-21查阅)。WEST馆退税方式 即时+事后(VisitKorea旅游信息)

🛍 综合购物中心 — 4处

  • 星空COEX商场 (Seutapildeu Koekseumol / 스타필드 코엑스몰) — 首尔江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513号。10:00~22:00，全年无休。电话 02-6002-5300。店铺约320家，餐厅·咖啡厅约100处，中央有"星空图书馆 (Byeolmadang Library / 별마당 도서관)"(VisitKorea)
  • 乐天世界商场 (Lotte Woldeumol / 롯데월드몰) — 首尔松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Ollimpik-ro / 올림픽로) 300号。营业时间·休息日因店铺而异。咨询电话 02-3213-5000(VisitKorea)。同一园区内的乐天免税店世界塔店 (Lotte Myeonsejeom Woldeutawojeom / 롯데면세점 월드타워점) 为 10:30~19:30(乐天免税店官方网站)，乐天玛特世界塔店 (Lotte Mateu Woldeutawojeom / 롯데마트 월드타워점) 为 10:00~23:00(乐天玛特官方门店查询)
  • IFC商场 (IFC Mol / IFC몰) — 首尔永登浦区 (Yeongdeungpo-gu / 영등포구) 国际金融路 (Gukjegeumyung-ro / 국제금융로) 10号。10:00~22:00，全年无休。电话 02-6137-5000(VisitKorea)。与THE HYUNDAI SEOUL同在汝矣岛 (Yeouido / 여의도)，很容易安排在一天里
  • 星空河南 (Seutapildeu Hanam / 스타필드 하남) — 京畿道河南市 (Hanam-si / 하남시) 渼沙大路 (Misa-daero / 미사대로) 750号。10:00~22:00，全年无休。电话 1833-9001(VisitKorea)。新世界百货·易买得Traders (Imateu Teureideoseu / 이마트 트레이더스)·Aqua Field (Akwa Pildeu / 아쿠아필드) 在同一栋建筑里(VisitKorea介绍文)

🏷 奥特莱斯 — 4处

  • 乐天奥特莱斯首尔站店 (Lotte Auteullet Seoul-yeokjeom / 롯데아울렛 서울역점) — 首尔龙山区 (Yongsan-gu / 용산구) 汉江大路 (Hangang-daero / 한강대로) 405号。10:30~21:00，休息日为1月1日·传统节日 (Myeongjeol / 명절)。可用现金·信用卡·三星支付·KakaoPay·支付宝·微信支付·Apple Pay，退税 即时+事后(VisitKorea旅游信息)。2层的"Global Service Room"提供英语·汉语购物指引，2层正门(耐克旁)有自动换汇机(乐天百货英文官方网站)。紧邻首尔站 (Seoul-yeok / 서울역)，适合出境前一天顺路来逛
  • 新世界西蒙骊州Premium Outlets (Sinsegye Saimon Yeoju Peurimieom Auteullet / 신세계사이먼 여주 프리미엄 아울렛) — 京畿道骊州市 (Yeoju-si / 여주시) 名品路 (Myeongpum-ro / 명품로) 360号。2007年6月28日开业。夏季(5~10月)普通店铺 10:30~21:00 / 冬季(11~4月)周一~周四 10:30~20:30，周五~周日·公休日 10:30~21:00，餐饮区 11:00~21:00。春节·中秋当天休息。电话 1644-4001(VisitKorea)
  • 新世界西蒙坡州Premium Outlets (Sinsegye Saimon Paju Peurimieom Auteullet / 신세계사이먼 파주 프리미엄 아울렛) — 京畿道坡州市 (Paju-si / 파주시) 炭县面 (Tanhyeon-myeon / 탄현면) 必胜路 (Pilseung-ro / 필승로) 200号。夏季 10:30~21:00 / 冬季周一~周四 10:30~20:30，周五~周日 10:30~21:00。休息日请查看官网。电话 1644-4001(VisitKorea)
  • 乐天Premium Outlets坡州店 (Lotte Peurimieom Auteullet Pajujeom / 롯데프리미엄아울렛 파주점) — 京畿道坡州市 (Paju-si / 파주시) 会洞路 (Hoedong-gil / 회동길) 390号。2011年12月2日开业。10:30~21:00，全年无休。4层有乐天影院 (Lotte Sinema / 롯데시네마)(VisitKorea)
  • 釜山的百货商店·奥特莱斯请看#1327 釜山购物指南，低价时装地下商街请看#1220 地下商街购物指南

🥗 饮食 — 在食品馆·餐饮区

  • 素食: VisitKorea介绍，购物时分辨纯素产品最简单的方法是看"纯素认证标志"。它还写道，泡菜调料大多含有咸鱼酱 (Jeotgal / 젓갈)·鱼露·肉汤(VisitKorea素食旅行提示)。在食品馆买小菜 (Banchan / 반찬) 和泡菜时，先看原料标签
  • 清真: 本指南12处的官方页面上，没有确认到清真认证餐厅的标注。VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的Eid (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15号，每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF / 한국이슬람교중앙회) 认定的少数清真餐厅之一。认证可能变动，访问前请先确认
  • 展示用卡片请看#1300 饮食需求手册

🧰 购物实用信息 — 独自·预约·支付·退税·交通

  • 独自·预约: 进店不需要预约。新世界本店餐饮区在打烊前30分钟接受最后点单，食材用完会提前关门(新世界百货官方门店页面)
  • 支付: 乐天百货接受VISA·Mastercard·UnionPay·JCB·AMEX，以及支付宝·微信支付·Apple Pay·LINE Pay(乐天百货英文官方网站)。银行卡·移动支付的整体介绍请看#527 支付系统
  • 退税: 以乐天百货为准，购物金额超过15,000韩元，购买日起3个月内出境，在韩停留不满6个月的外国人。需要护照和收据(乐天百货英文官方网站)。流程请看#1231 退税指南和#1304 机场自助机流程版
  • 行李: 乐天百货提供当日物品寄存。不接收贵重物品·现金·笔记本电脑·平板电脑·易碎物品(乐天百货英文官方网站)。其他方法请看#1232 行李寄存指南
  • 交通: 地铁·公交请看#1298 三种交通卡怎么选

⚠ 常见的4个错误

1. "百货商店每天营业" — 每月休息1天，日期因门店和月份而异(2026年10月举例: 乐天本店12日·新世界本店25日，各官方页面)。去之前先确认当月休息日

2. "骊州奥特莱斯是现代奥特莱斯" — VisitKorea登记的名称是新世界西蒙骊州Premium Outlets

3. "奥特莱斯全年营业时间相同" — 新世界西蒙骊州·坡州从11月起进入冬季，周一~周四 20:30 关门(VisitKorea)

4. "周末也是20:00关门" — 乐天本店·THE HYUNDAI SEOUL周五~周日营业到20:30(官方页面·VisitKorea)
