外国人常犯的3个错误

1. 认为韩国饺子 = 中国饺子

韩国饺子 (Mandu / 만두) 是以开城 (Gaeseong / 개성)·平壤 (Pyeongyang / 평양) 等北方出身的做法 + 韩式改良为根基，与中国的包子·饺子有着不同的身份特征。平壤饺子 (Pyeongyang Mandu / 평양만두) 的特点是薄荞麦皮 + 豆腐·猪肉·泡菜馅。饺子皮、馅料、汤底全都是韩式。

2. 饺子汤与只点饺子

韩国饺子分为单点饺子 (蒸·煎) + 饺子汤 (Mandu-guk / 만두국) (饺子 + 年糕 + 汤) 两个类别。外国人常常只点单品，而韩国美食家则把饺子 + 饺子汤 (Mandut-guk / 만둣국) 套餐视为标准吃法。尤其冬季不喝饺子汤 (Mandu-guk / 만두국)，就等于错过了50%的韩式饺子体验。

3. 分不清平壤饺子与泡菜饺子

平壤饺子 (Pyeongyang Mandu / 평양만두) 的正宗做法是清淡的豆腐·猪肉·泡菜馅 + 荞麦皮。泡菜饺子 (Kimchi Mandu / 김치만두) 则是以泡菜为主的微辣馅料。初次到访的话，平壤饺子 (Pyeongyang Mandu / 평양만두) → 泡菜饺子 (Kimchi Mandu / 김치만두) → 排骨饺子 (Galbi Mandu / 갈비만두) 的顺序最稳妥 (让味蕾逐步适应)。

2. 8处名店 (4轴均衡)

2-1. 平壤式老店2家 — 韩式饺子的精髓

① 紫霞孙饺子 (Jahasonmandu / 자하손만두) — 釜岩洞 (Buam-dong / 부암동)

1980年代起 釜岩洞 (Buam-dong / 부암동) 平壤手工饺子老字号第一名。从景福宫站 (Gyeongbokgung Station / 경복궁역) 乘公交7分钟或步行25分钟 (釜岩洞路线)。人均 ₩15,000~₩18,000。薄荞麦皮 + 豆腐·猪肉·泡菜馅 + 手工捏制 — 韩国平壤手工饺子的正宗。饺子汤 (Mandu-guk / 만두국) + 烤肉饼 (Tteokgalbi / 떡갈비) 套餐是招牌。一人OK，外国美食家的第一名。有英文菜单，可刷卡。

② 开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) — 明洞 (Myeongdong / 명동)

1970年代起 开城式饺子老字号的代表。从明洞站 (Myeongdong Station / 명동역) 6号出口步行5分钟。人均 ₩13,000~₩16,000。开城式比平壤式饺子略大，馅料多样。饺子 + 饺子汤 (Mandut-guk / 만둣국) + 绿豆煎饼 (Bindaetteok / 빈대떡) 三件套。熟悉接待外国人，有英文菜单。

2-2. 钟路老字号2家 — 性价比 + 正宗

③ 北村手工饺子 (Bukchon Sonmandu / 북촌손만두) — 钟路 北村 (Bukchon / 북촌)

1990年代起 北村韩屋村 (Bukchon Hanok Village / 북촌 한옥마을) 路线上的饺子老字号。从安国站 (Anguk Station / 안국역) 步行7分钟。人均 ₩10,000~₩14,000。手工艺手捏饺子 + 北村韩屋 (Hanok / 한옥) 漫步路线。外国游客路线第一名，有英文·中文菜单。一人OK，工作日午餐要排30分钟队。

④ 聚天楼 (Chwicheonru / 취천루) — 钟路 (Jongno / 종로)

1960年代起 钟路饺子老字号的性价比路线。从钟阁站 (Jonggak Station / 종각역) 步行5分钟。人均 ₩9,000~₩12,000。大饺子 (Wang Mandu / 왕만두) + 水饺 (Mul Mandu / 물만두) + 饺子汤 (Mandu-guk / 만두국) 全套 — 韩国上班族午餐的常客。部分有英文菜单，另有图片菜单。

2-3. MZ潮流2家 — SNS上很火

⑤ 都卜伊 (Ddobogi / 또복이) — 江南 (Gangnam / 강남)

MZ新生代潮流饺子店。从江南站 (Gangnam Station / 강남역) 11号出口步行4分钟。人均 ₩10,000~₩14,000。排骨饺子 (Galbi Mandu / 갈비만두) + 泡菜饺子 (Kimchi Mandu / 김치만두) + 松露饺子全套 — 在SNS·Instagram上的曝光频率高。可以大量产出Instagram照片，也是MZ约会路线。周末建议预约，一人OK。

⑥ 朝鲜饺子 (Joseon Mandu / 조선만두) — 弘大 (Hongdae / 홍대)

弘大MZ潮流饺子店。从弘大入口站 (Hongik Univ. Station / 홍대입구역) 9号出口步行7分钟。人均 ₩11,000~₩15,000。泡菜饺子 (Kimchi Mandu / 김치만두) + 饺子汤 (Mandu-guk / 만두국) + 玛格利酒 (Makgeolli / 막걸리) 套餐。K-偶像·K-剧的曝光频率高，是外国MZ的常客。有英文·中文·日文菜单。

2-4. 连锁·饺子汤2家 — 性价比 + 对外国人友好

⑦ 安东炖鸡本家 (Andong Jjimdak Bonga / 안동찜닭본가) 饺子菜单 — 全国连锁

炖鸡本家的饺子菜单 (并非饺子专门店，属于加分项)。全国30多家分店。人均 ₩9,000~₩13,000。泡菜饺子 (Kimchi Mandu / 김치만두) + 饺子汤 (Mandu-guk / 만두국) 作为配菜。安东炖鸡 (Andong Jjimdak / 안동찜닭) 加饺子的组合套餐性价比出色。对外国人的友好度高。

⑧ 元祖釜山海鸥 (Wonjo Busan Galmaegi / 원조부산갈매기) 饺子汤 — 江南 (Gangnam / 강남)

釜山式饺子汤 + 釜山海鸥肉 (Galmaegisal / 갈매기살) 结合的门店。从江南站 (Gangnam Station / 강남역) 步行5分钟。人均 ₩12,000~₩15,000。釜山式饺子汤 (Mandu-guk / 만두국) (鳀鱼·海带汤底) + 海鸥肉 (Galmaegisal / 갈매기살) 配菜 — 饺子汤与韩式烧烤的结合。有英文菜单。

4. FAQ 8问

Q1. 韩国饺子与中国饺子有什么区别？

A. 韩国平壤饺子 (Pyeongyang Mandu / 평양만두) = 薄荞麦皮 + 豆腐·猪肉·泡菜馅。中国饺子 = 面粉皮 + 以肉末为主。韩国饺子的身份特征是泡菜·豆腐为底。

Q2. 正宗的平壤饺子店在哪里？

A. 紫霞孙饺子 (Jahasonmandu / 자하손만두) (釜岩洞) + 开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) (明洞) 是两大代表。想要平壤式的正宗清淡选紫霞孙饺子 (Jahasonmandu / 자하손만두)，想要更多样的馅料选开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁)。

Q3. 饺子汤 (Mandu-guk / 만두국) 与 Mandut-guk (만둣국) 有什么区别？

A. 是同一种食物 (饺子汤 (Mandut-guk / 만둣국) 只是在饺子 + 汤 (Mandu + guk / 만두 + 국) 之间加了间隔音 (Sai-siot / 사이시옷) 的书写形式)。是饺子 + 年糕 + 牛肉汤 + 紫菜 + 鸡蛋的正餐。

Q4. 一个人可以去吗？

A. 8家门店全部一人OK。韩国饺子对一人套餐很友好 — 饺子汤 (Mandu-guk / 만두국) + 单点饺子一人份的菜单很多。

Q5. 有英文菜单和英语接待吗？

A. 紫霞孙饺子 (Jahasonmandu / 자하손만두)·北村手工饺子 (Bukchon Sonmandu / 북촌손만두)·都卜伊 (Ddobogi / 또복이)·朝鲜饺子 (Joseon Mandu / 조선만두) 最为熟悉。钟路老字号聚天楼 (Chwicheonru / 취천루) 则是图片菜单 + 比手画脚。

Q6. 可以刷卡吗？

A. 8家门店全部可刷卡·使用移动支付。老字号 (紫霞孙 (Jahason / 자하손)·聚天楼 (Chwicheonru / 취천루)) 也有刷卡机。

Q7. 饺子与饮品怎么搭配？

A. 平壤饺子 (Pyeongyang Mandu / 평양만두) + 玛格利酒 (Makgeolli / 막걸리) (正宗)。泡菜饺子 (Kimchi Mandu / 김치만두) + 烧酒 (Soju / 소주) (MZ微辣)。饺子汤 (Mandu-guk / 만두국) + 热茶 (冬季套餐)。

Q8. 可以吃素或清真吗？

A. 韩国饺子几乎都以猪肉·牛肉为底，吃素很难。泡菜饺子 (Kimchi Mandu / 김치만두) 的部分门店有素食选项 (仅豆腐·蔬菜)，可单独点餐。几乎没有清真的韩国饺子店。
