🎯 为什么以"三语评论"为标准

选择标准只有一个。只选Naver地图上同时留有英语·日语·中文评论的餐厅。不看韩国人的人气排行，而是选外国人已经找去并用三种语言留下痕迹的地方。我们认为这样的地方对下一位外国游客也更不陌生。9家全部都有三种语言的评论。不过餐厅 (Deoije / 더이제)和烤肉店 (Naeng325 / 냉325)每种语言只有1条，合计仅3条，所以依据偏薄。评论数以2026-11为准，每家店都标出来。这一篇9家里，没有出现在KeyChinGu其他篇的店。

① 钟路·安国 — 2家

安国站一带1家，钟路3街站一带1家。餐厅 (Hanil Sikdang / 한일식당)07:00开门，可以吃早餐。披萨店 (Plop Anguk / 플롭 안국)15:30~17:00休息。

  • 披萨店 (Plop Anguk / 플롭 안국) — 距安国站 (Anguk / 안국역)2号出口约120m的披萨店。Kakao地图上的店名是披萨店 (Plop Anguk-jeom / 플롭 안국점)，Kakao地图摘要里写着韩屋内部装修，用半半披萨·四分之一披萨可以选多种口味。登记价是Too Much Pepperoni披萨(S)₩19,000，烤肉洋葱塔可披萨(S)₩21,000，疯狂芝士球鸡肉披萨(S)₩21,000，培根蘑菇土豆披萨(S)₩22,000，蒜香虾披萨(S)₩22,000，大葱奶油开放式意面₩13,500。披萨价格以S尺寸为准。时间是每天11:30~21:30，休息时间15:30~17:00，最后点单21:00，没有登记休息日。地址是钟路区 (Bukchon-ro 2-gil 5 / 북촌로2길 5) 1层，附近的站是安国站 (Anguk / 안국역)(3号线)2号出口。没有停车场。外语评论10条(5·3·2)，按语言的评分三种都是5.0。Kakao地图评分3.3(151条)偏低，和外语评论评分有差距。饮食提示: 意式辣香肠·培根含猪肉，烤肉含牛肉，蒜香虾含虾(甲壳类)。疯狂芝士球鸡肉在Kakao地图摘要里是辣味韩式鸡肉加芝士，可能会辣。披萨基本含芝士(乳制品)和面粉面团。没有肉类名称的菜单有甜玉米披萨·蒜香罗勒奶油芝士披萨，但配料食材点单时询问。Kakao地图标签上有"披萨配啤酒"，但没有登记酒类菜单。
  • 餐厅 (Hanil Sikdang / 한일식당) — 钟路3街官水洞巷子里的烤鱼老店。Kakao地图标签上有老店·早餐·一人用餐。登记价是烤带鱼₩15,000，烤青花鱼₩14,000，烤鲅鱼₩14,000，烤黄太鱼₩14,000，烤黄花鱼₩14,000，烤秋刀鱼₩14,000。Kakao地图摘要里写着用煤球炭火烤，附带锅饭和基本小菜·大酱汤，但店主没有在菜单上写说明。每天07:00~22:00营业，最后点单20:30。地址是钟路区 (Supyo-ro 20-gil 16-17 / 수표로20길 16-17) 1层，附近的站是钟路3街站 (Jongno 3-ga / 종로3가역)15号出口。外语评论15条(5·5·5)，这一篇9家里三种语言都满上限(5条)的只有这一家。饮食提示: 菜单全是烤鱼，所以含海鲜，没有生鱼菜单。菜名里没有辣的菜。没有登记猪肉·牛肉菜单。Kakao地图摘要里写着中午上班族多，里面不大，想从容用餐的话，早上或下午晚些去。

② 弘大·麻浦 — 3家

弘大入口站前1家，大兴站一带的新水洞1家，距望远站约900m的城山洞1家。三家彼此离得远，一餐选一家。餐厅 (Falachili / 팔라칠리)和餐厅 (Deoije / 더이제)周一休息。

  • 中东餐厅 (Falachili / 팔라칠리) — 弘大入口站前东桥洞的中东式炸豆丸子·辣豆酱店。登记价和店主写的菜单说明如下。炸豆丸子拼盘₩13,000(炸豆丸子·皮塔饼·鹰嘴豆泥·蔬菜·薯条，自制芝麻酱和哈里萨辣酱)，炸豆丸子三明治₩11,000(皮塔饼夹鹰嘴豆炸丸子和蔬菜)，芝士辣豆酱卷饼₩11,000(自制墨西哥辣豆酱·蔬菜·芝士·酸奶油)，辣豆酱拼盘₩14,000(辣豆酱·玉米饼·香肠·蔬菜·薯条)。时间是周二至周五17:00~24:00，周六12:00~24:00，周日12:00~22:00，周一休息。平日只有晚上营业。地址是麻浦区 (Yanghwa-ro 23-gil 10-8 / 양화로23길 10-8) 1层，附近的站是弘大入口站 (Hongik Univ. / 홍대입구역)3号出口。外语评论11条(5·3·3)，按语言的评分三种都是5.0。饮食提示: 炸豆丸子是鹰嘴豆炸丸子，芝麻酱(Tahini)是芝麻酱料，哈里萨(Harissa)是辣椒酱。墨西哥辣豆酱是含肉的辣豆酱，辣豆酱拼盘里有香肠。芝士辣豆酱卷饼含芝士·酸奶油(乳制品)。皮塔饼·玉米饼是面粉做的饼。Kakao地图摘要里写着有多种纯素菜单，但因为是AI摘要，纯素食者点单时询问哪些菜单是纯素。Kakao地图摘要里写着用平板点单。

  • 中餐厅 (Deoije / 더이제) — 城山洞的中餐厅。距望远站 (Mangwon / 망원역)1号出口约900m，所以先用Kakao地图导航查好路线。登记价是虾吐司(4pcs)₩20,000，海鲜炒码汤₩26,000，干烧虾仁₩27,000，鱼香茄子虾₩32,000，海鲜锅巴汤₩39,000，麻辣扇贝₩55,000。高档菜里还有7万~8万韩元档的。以几个人分食的菜为主，不是一个人一碗，所以两三个人一起去更合适。时间是周二至周日11:30~21:30，休息时间15:00~17:00，最后点单21:00，周一休息。地址是麻浦区 (Seongmisan-ro 73 / 성미산로 73) 1层。外语评论3条(1·1·1)，是这一篇里偏少的。三种语言各留了1条，评分都是5.0，但条数少，依据比其他店薄。饮食提示: 海鲜菜单很多(虾·扇贝·牡蛎等)，但因为是中餐，高汤·酱汁里可能用到肉。虾吐司是在吐司之间夹虾肉油炸的菜，所以含面粉。麻辣扇贝和鱼香类菜可能会辣。

集中在江南站·驿三站·论岘站一带。午餐是餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)·荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)，晚餐是烤肉店 (Naeng325 / 냉325)·鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)。鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)要到17:00才开门，餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)周末休息，荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)周日休息。

  • 烤肉店 (Naeng325 / 냉325) — 驿三洞的冷冻五花肉烤肉店。Kakao地图标签上有室外餐厅·午间特餐。登记价是纯冷冻五花肉套餐(推荐2-3人)₩49,000，丰盛套餐(推荐2-3人)₩54,000，高级济州黑猪五花肉(150g)₩18,000，辣炒猪肉包饭套餐(2人以上)₩12,000，生牛肉拌饭₩9,500，血蚶拌饭₩9,500。套餐里有什么，店主没有写在菜单说明里。Kakao地图摘要里写着纯冷冻五花肉套餐有冷冻五花肉·猪颈肉和生牛肉或血蚶拌菜，还有蒸蛋，所以点单时询问构成。时间是周一至周五11:00~24:00，周六15:00~24:00，周日16:00~24:00，最后点单23:00，没有登记休息日。地址是江南区 (Eonju-ro 81-gil 8 / 언주로81길 8) 1层，附近的站是驿三站 (Yeoksam / 역삼역)(2号线)1号出口，距离约680m(Kakao地图标注步行10分钟)。外语评论3条(1·1·1)，偏少。Kakao地图评论也只有3条，用评论判断的依据偏薄。饮食提示: 五花肉·猪颈肉·辣炒猪肉是猪肉。辣炒猪肉包饭套餐的辣炒猪肉大多是辣的。生牛肉是生的牛肉，避开生食的话，要去掉生牛肉拌饭和套餐里的生牛肉选项。血蚶是贝类。Kakao地图摘要里写着基本小菜有酱蟹和酱油虾。两者都是用调料腌的生海鲜，避开生食或甲壳类的话要提前说。
  • 鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점) — 江南站一带的鸡爪专卖店。使用1~2层。登记价是辣酱浓稠鸡爪(1人)₩12,900，[当季]辣炒小章鱼鸡爪₩16,900，鸡蛋汤₩5,900，2人套餐₩38,500。2人套餐在店主说明里是辣酱浓稠鸡爪(2人)·酥脆土豆饼·鸡蛋汤·蛋黄酱·萝卜咸菜。每天17:00~24:00营业，最后点单23:00。中午不营业。地址是江南区 (Teheran-ro 1-gil 28-3 / 테헤란로1길 28-3)，附近的站是江南站 (Gangnam / 강남역)(2号线)11号出口。外语评论13条(3·5·5)，日语·中文各满5条。饮食提示: 鸡爪是鸡的脚。鸡爪菜单大多是辣的。Kakao地图摘要里写着可以调节辣度，所以点单时询问辣度。辣炒小章鱼鸡爪里有小章鱼(海鲜)。鸡蛋汤·蛋黄酱含鸡蛋。Kakao地图摘要里是昏暗的大排档氛围，酒类价格没有登记。如果配酒，韩国的法定饮酒年龄是按年龄算19岁(以当年1月1日为准，青少年保护法第2条)。
  • 餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점) — 驿三站附近的烤肉兼午间家常饭老店。Kakao地图标签上有老店·午餐·一人用餐。登记价是生猪颈肉烧烤(200g)₩18,000，生猪颈肉(150g)₩20,000，砂锅烤肉₩13,000，辣炒猪肉₩12,000，乡村饭桌₩12,000，烤鱼₩15,000。代表菜单生五花肉和泡菜汤·部队锅·辣酱五花肉炒的价格登记超过2年，所以价格以Kakao地图当日确认为准。泡菜汤·部队锅这类锅类登记为2人以上点单。时间是周一至周五11:00~21:30，休息时间15:00~17:00，周六·周日休息。地址是江南区 (Nonhyeon-ro 85-gil 23 / 논현로85길 23) 1层，附近的站是驿三站 (Yeoksam / 역삼역)(2号线)3号出口。外语评论9条(5·2·2)，其中英语有5条。饮食提示: 猪颈肉·猪项肉·五花肉·辣炒猪肉是猪肉，砂锅烤肉是牛肉，烤鱼是鱼。辣炒猪肉·泡菜汤·辣酱五花肉炒是辣味调料菜单。部队锅通常含火腿·香肠。Kakao地图摘要里写着午间家常饭很受欢迎，所以一个人的话，平日中午点乡村饭桌或烤鱼就行。
  • 荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점) — 距论岘站 (Nonhyeon / 논현역)3号出口约300m的江南大路上的荞麦面店。Kakao地图标签上有一人用餐。登记价是冷荞麦面₩11,000，里脊猪排₩11,000，紫苏油荞麦面₩12,000，辣椒荞麦面₩12,000，辣味牛五花热荞麦面₩13,000，艾草年糕豆浆面₩14,000。时间是周一至周六10:00~20:30，休息时间15:00~16:00，最后点单20:00，周日休息。地址是江南区 (Gangnam-daero 506 / 강남대로 506) 1层，附近的站是论岘站 (Nonhyeon / 논현역)(7号线·新盆唐线)3号出口。外语评论10条(4·3·3)，按语言的评分三种都是5.0。饮食提示: 面是荞麦做的，有荞麦过敏的话要避开。艾草年糕豆浆面是豆浆配艾草年糕的菜单，所以含大豆(Kakao地图摘要)。辣椒(땡초)是辣的青辣椒，所以辣椒荞麦面是辣的，辣味牛五花热荞麦面也如其名是辣的并且含牛肉(牛五花)。里脊猪排是猪肉炸物。没有肉类名称的菜单有冷荞麦面·紫苏油荞麦面，但汤底食材点单时询问。

🗺 动线 — 一天三条路线

首尔可以坐地铁在区域之间移动，所以午餐和晚餐在不同区域吃也可以。不过在一个区域里连着吃两餐的路线移动更少。店与店之间的移动和所需时间，当天用Kakao地图导航确认。

A. 钟路·安国一天

  1. 早晨 钟路3街 餐厅 (Hanil Sikdang / 한일식당)烤鱼(07:00~)
  2. 中午或较早的晚餐 安国 披萨店 (Plop Anguk / 플롭 안국)披萨(11:30~15:30，17:00~21:30)。15:30~17:00是休息时间

B. 弘大·麻浦一天 (周二至周日)

  1. 中午 新水洞 披萨店 (Pizzeria Ducky / 피제리아 더키)(11:00~)或城山洞 中餐厅 (Deoije / 더이제)(11:30~15:00，多人同去时)
  2. 晚上 弘大入口 中东餐厅 (Falachili / 팔라칠리)(周二至周五17:00~，周六·周日12:00~)

C. 江南·驿三·论岘一天

  1. 中午 平日的话驿三 餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)家常饭(周一至周五，15:00前)，周六的话论岘 荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)(周一至周六，15:00前)
  2. 晚上 江南站 鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)(17:00~24:00)或驿三 烤肉店 (Naeng325 / 냉325)烤肉(~24:00)

周日餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)和荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)休息，烤肉店 (Naeng325 / 냉325)16:00开门，鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)17:00开门。周日这4家里没有可以吃午餐的地方，所以午餐在A或B路线吃，晚上再来江南。

周一中东餐厅 (Falachili / 팔라칠리)·中餐厅 (Deoije / 더이제)休息。周六·周日餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)休息，周日荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)也休息。鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)17:00前不开门。

⚠ 3个常见失误

  1. 不看星期几就去 — 餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)周六·周日休息，荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)周日休息。周末安排江南午餐的话，周六只剩荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)，周日烤肉店 (Naeng325 / 냉325)(16:00~)·鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)(17:00~)也只在晚上营业，江南4家里没有可以吃午餐的地方。周一中东餐厅 (Falachili / 팔라칠리)·中餐厅 (Deoije / 더이제)休息，弘大·麻浦路线只剩披萨店 (Pizzeria Ducky / 피제리아 더키)。中东餐厅 (Falachili / 팔라칠리)平日要到17:00才开门。
  2. 在休息时间到达 — 披萨店 (Plop Anguk / 플롭 안국)是15:30~17:00，中餐厅 (Deoije / 더이제)和餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)是15:00~17:00，荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)是15:00~16:00休息。较晚的午餐要在15:00前入座。
  3. 去了名字相同的其他店或其他分店 — 餐厅 (Hanil Sikdang / 한일식당)和餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)在济州另有同名的店。荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)另有驿三店(Teheran-ro 25-gil)，鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)另有论岘店。Kakao地图上的店名也和这一篇的写法不同。披萨店 (Plop Anguk / 플롭 안국)显示为披萨店 (Plop Anguk-jeom / 플롭 안국점)，披萨店 (Pizzeria Ducky / 피제리아 더키)显示为披萨店 (Pizzeria Ducky / 피제리아더키)。在地图应用里不要搜店名，用这一篇的道路名地址找。

⚙ 3个常见问题

  1. 只能选一家？ — 三种语言评论都满5条的只有餐厅 (Hanil Sikdang / 한일식당)(15条，5·5·5)这一家。07:00~22:00营业，没有登记休息日，容易排进行程。晚上的话是日语·中文评论各留5条的鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)(13条)。
  2. 不吃肉或避开生食的话？ — 吃鱼的话，餐厅 (Hanil Sikdang / 한일식당)的菜单全是烤鱼。中东餐厅 (Falachili / 팔라칠리)的炸豆丸子是鹰嘴豆炸丸子。Kakao地图摘要里写着中东餐厅 (Falachili / 팔라칠리)有多种纯素菜单，但因为是AI摘要，每个菜单的食材和荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)冷荞麦面·紫苏油荞麦面的汤底食材，点单时询问。避开生食的话，要注意烤肉店 (Naeng325 / 냉325)的生牛肉和基本小菜(Kakao地图摘要里有酱蟹·酱油虾)。
  3. 适合一个人吃的地方？ — Kakao地图上有一人用餐标签的是餐厅 (Hanil Sikdang / 한일식당)·餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)·荞麦面店 (Mereumil Jinmijip Nonhyeon / 메르밀진미집 논현직영점)。不过餐厅 (Namho Sikdang Yeoksam Main / 남호식당 역삼본점)的锅类登记为2人以上点单，一个人的话选乡村饭桌·烤鱼这类1人菜单。鸡爪店 (Jippul Dakbal Gangnam / 짚뿔닭발 강남점)登记了1人鸡爪(₩12,900)。中餐厅 (Deoije / 더이제)和烤肉店 (Naeng325 / 냉325)的套餐是多人分食的菜单，两人以上比一个人更合适。
