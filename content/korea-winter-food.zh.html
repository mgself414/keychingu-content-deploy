韩国冬天吃什么——冷的时候按情景挑一碗：早上雪浓汤·醒酒汤，中午刀切面·汤饭，晚上什锦锅·炖锅，路上鲷鱼烧·糖饼，冬至红豆粥与春节假期休息确认，附细分篇链接与饮食标注

副标题: 早上 6~8 点开门的汤饭·醒酒汤老店 · 多人围坐的豆腐火锅·泡菜锅 · 冬季小吃(12~2月)的摊位位置不固定，价格以现场为准 · 冬至 2026-12-22 红豆粥 · 春节 2027-02-07(暂定，月历要项公布前的资料) · 确认为牛肉汤底的只有雪浓汤·牛肉清汤，其余要问汤底 · 各店与时间详见汤饭 #477·炖锅 #486·面 #480·小吃 #476·滋补餐 #827

🎯 这份指南怎么用

寒冷的早晨，走出住处一路走，最想要的就是一碗热汤。但用“韩国冬季美食”去搜，只会列出菜名，现在这个时间哪里开着、想避开猪肉汤底该选什么，都没有告诉你。这份指南是按情景回答的枢纽篇。它不讲解菜单，而是按你现在的情景(早上·中午·晚上·走路中·特定日期)选出对应的分支，再把店名·营业时间·休息日已在官方页面确认过的细分篇送到你面前。

本篇直接写出的数字，是韩国天文研究院的日历资料(冬至·春节日期)，以及细分篇在2026年10月通过 VisitKorea·米其林页面确认的营业时间·开业年份·备料量，只有少数几个。各细分篇里没有任何一家以韩元公布食物价格，所以不写金额——有米其林价格符号的店全都是 ₩(最低一档)(#477·#480·#486)。其余的，点单前问一句才是老实的答案。

🍲 汤饭·汤——老店早上开门，备多少卖多少

  • 冬天早上最有用的是早开门的老店。钟路清津屋 (Cheongjinok / 청진옥)06:00~22:00(最后点单 21:30)全年无休，在大骨汤底 (Sagol / 사골)里放血块和牛内脏，做成血块醒酒汤 (Yangseonji Haejangguk / 양선지 해장국)；市厅后面的武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집)工作日 07:00~20:00·周末 07:00~15:00 全年无休，只卖明太鱼干醒酒汤 (Bugeo Haejangguk / 북어해장국)一个品项(#486，VisitKorea 2026-10 确认)。明洞河东馆 (Hadongwan / 하동관)周一至周六 07:00~16:00(周日休息)卖牛肉清汤 (Gomtang / 곰탕)，当天备的量卖完就关门(#477，米其林 2026-10 确认)。
  • “下午去就关门了”是老店的默认状态。像河东馆下午4点结束、像合井屋 (Hapjeong-ok / 합정옥)一天约 100 人份卖完就打烊的店都有(#477)，所以早上·中午去最稳妥。首尔 8 家·釜山 3 家的时间·休息日·菜单在 #477；汤饭六种类型的差别见 #807，坐下来该做什么、怎么做见 #808。
  • 汤底因店而异。#477 写为牛骨·牛肉汤底的是雪浓汤·牛肉清汤，猪肉汤饭 (Dwaeji Gukbap / 돼지국밥)就如其名是猪肉。醒酒汤要么是大骨汤底加血块·牛内脏(清津屋)，要么是明太鱼干(明太鱼汤店)。需要避开某种食材时，不要问菜名，要问汤底——见下方 🥗。

🍜 刀切面·什锦锅——多人围坐的冬天

  • 一个人的话，刀切面最快。明洞明洞饺子 (Myeongdong Gyoja / 명동교자)每天 10:30~21:00，1966年起由家族经营，菜单只有四种，好选。北村黄生家刀切面 (Hwangsaengga Kalguksu / 황생가 칼국수，大骨汤底)·瑞草任炳柱山东刀切面 (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수，蛤蜊清汤底)的时间·休息日也在同一篇(#480，米其林 2026-10 确认)。
  • 人多的话，什锦锅·炖锅是冬天晚餐的基本款。麻浦黄金豆田 (Hwanggeum Kongbat / 황금콩밭)用国产豆子自己做的豆腐煮豆腐火锅(周一至周五 11:30~21:00·周六、周日 11:00~21:00)，防山市场 (Bangsan Sijang / 방산시장)银珠亭 (Eunjujeong / 은주정)是用来包着吃的泡菜锅，11:30~22:00(最后点单 21:30)，周日·春节·中秋假期休息(#486，VisitKorea·米其林 2026-10 确认)。作为放了火腿·香肠的部队锅 (Budae-jjigae / 부대찌개)元祖获得认证的是议政府的鱼糕食堂 (Odeng Sikdang / 오뎅식당)，在首尔，驿三的大宇部队锅 (Daewoo Budae Jjigae / 대우부대찌개)在同一篇里。
  • 什锦锅·炖锅是在桌上煮着、大家分着吃的菜。1人用餐的话，炖锅套餐或刀切面比较方便。

🐟 街头小吃——摊位会换地方，价格在现场看

  • 鲷鱼烧·烤红薯·烤栗子·鸡蛋糕 (Gyeranppang / 계란빵)·糖饼是12~2月冬季小吃的基本款。摊位位置不固定，写不出“在哪里”，价格也没有在官方页面公布过。所以细分篇 #476只收录了销售处类型(路边摊·便利店·地铁站内)，以及官方登记的固定店铺(平昌鲷鱼与鱼饼 (Bungeorang Odeng / 붕어랑 오뎅)，群山·清州·釜山的糖饼店，济州东门市场糖饼巷)。
  • VisitKorea 介绍的摊位聚集处是明洞站美食街 (Myeongdong-yeok Food Street / 명동역 푸드 스트리트)(4号线明洞站6号出口向左直走)(#476)。
  • 烤栗子·烤红薯现在便利店或地铁站内也有卖，馒头·大饺子冬天在便利店很容易买到(VisitKorea，#476)。找不到摊位时可以用这个替代。
  • 糖饼馅里有坚果，鸡蛋糕里整颗放入鸡蛋。面糊里是否有牛奶·鸡蛋，官方页面没有写，有过敏的话买之前先问(#476 🥗)。

🥣 冬至红豆粥 (Patjuk / 팥죽)——2026年12月22日

  • 2026年冬至是12月22日(周二)05:50(韩国天文研究院 天文宇宙知识信息 2026 日历资料；官方公布为月历要项 (Wollyeok Yohang / 월력요항))。这是夜晚最长的一天，据说吃了红豆粥就长一岁，还把红豆粥洒在大门上驱邪(国立民俗博物馆，#476)。
  • 红豆粥专门店不是只在冬至当天开门。首尔新堂洞千红豆粥 (Sindangdong Cheon Patjuk / 신당동천팥죽，10:30~20:00·周日休息)，全州老式红豆粥店 (Yetnal Patjukjip / 옛날팥죽집，10:00~20:00·全年无休)，杨平文湖里红豆粥 (Munhori Patjuk / 문호리팥죽，11:00~19:20·周一休息)等五家的地址·时间在 #476，五家的价格全部未公布。
  • 红豆粥汤里是否用肉汤底，店家官方页面没有写。吃素的话点单前先问(#476 🥗)。

🍗 参鸡汤与滋补餐——伏天吃得多，但老店标注全年无休

  • 参鸡汤是在嫩鸡里填入人参·红枣·糯米·坚果煮成的汤(VisitKorea，#827)，被认为是夏天伏天的食物，但钟路土俗村 (Tosokchon / 토속촌)参鸡汤标注 10:00~22:00(最后点单 21:00)·全年无休，明洞高峰参鸡汤 (Gobong Samgyetang / 고봉삼계탕)·百济参鸡汤 (Baekje Samgyetang / 백제삼계탕)标注每天 09:00~22:00(#827，VisitKorea 2026-10 确认)。三家的价格都未公布。坚果过敏见下方 🥗。
  • 想用韩方茶暖身的话，见 #681 韩方茶与药令市——首尔韩方振兴中心和京东市场在同一篇里。

🧧 春节假期——2027年2月6~9日(暂定)，先看休息标注

  • 2027年春节是2月7日(周日)，假期是2月6日(周六)~2月8日(周一)，2月9日(周二)是补休公休日(韩国天文研究院 2027 日历资料)。不过这个页面说明这是通过宇宙航空厅 (Uju Hanggongcheong / 우주항공청)正式公布月历要项之前的资料，所以是暂定值——出发前再确认一次公休日。
  • 细分篇里有标注为春节·中秋休息的店——银珠亭(春节·中秋假期休息，#486)，黄生家刀切面(春节·中秋当天休息，#480)，济州城邑老式红豆粥 (Jeju Seongeup Yetnal Patjuk / 제주 성읍 옛날팥죽)(周一及春节·中秋假期休息，#476)。如果假期打算去老店，先看细分篇的休息标注，再打电话确认。
  • 春节的饮食·习俗在 #752 春节指南中介绍。

🥗 饮食——有要避开的食材，要问的不是“菜单”而是“汤底”

  • 不吃猪肉：细分篇中确认为牛骨·牛肉汤底的是雪浓汤·牛肉清汤(#477)。猪肉汤饭·血肠汤 (Sundaeguk / 순대국)是猪肉，泡菜锅·部队锅里常常有猪肉。其他的汤·炖锅·刀切面因店而异，要问“是牛肉汤底，还是猪肉汤底？”。泡菜调料大多用到腌海鲜酱·鱼露或肉汤底(#477·#486)。
  • 海鲜过敏：鱼糕是鱼肉做的，蛤蜊刀切面(任炳柱)·明太鱼干醒酒汤本身就是海鲜。嫩豆腐锅·炖豆腐大多放腌虾酱(#486)，泡菜里也用腌海鲜酱·鱼露，所以要问“有放腌海鲜酱吗？”。
  • 素食：这一分支里没有确认为完全素食的店。豆腐火锅·大酱锅·红豆粥·糖饼·鲷鱼烧是候选，但汤底·腌海鲜酱·面糊的材料官方页面都没有公布，点单前要确认(#486 把“豆腐锅是素食”这种猜测列为常见错误)。出示用的卡片见 #1300 饮食需求手册。
  • 其他过敏：刀切面·小麦面 (Milmyeon / 밀면)含小麦(#480)，豆腐·大酱·清曲酱 (Cheonggukjang / 청국장)含大豆(#486)，糖饼馅里有坚果，鸡蛋糕里有鸡蛋(#476)，参鸡汤里有坚果(#827)。
  • 清真：本篇收录的店的官方页面上都没有清真标注。细分篇五篇共同写到的清真餐厅是梨泰院的 伊德 (Eid / 이드)(龙山区牛沙坛路10街 (Usadan-ro 10-gil 15 / 우사단로10길 15)，每天 12:00~21:00，韩国伊斯兰教中央会认可——VisitSeoul，#476)，按国籍分的清真4分类见 #192 东南亚穆斯林旅行者指南。
  • 价格：细分篇里没有任何一家官方公布韩元价格。有米其林价格符号的店全部是 ₩(最低一档)(#477 11家·#480 12家·#486 黄金豆田)。街头小吃看现场价目表，餐厅看门口的菜单。

⚠ 常犯的 4 个错误

  1. “老店晚上去也行”——河东馆 16:00 结束，明太鱼汤店周末 15:00 结束，合井屋 100 人份卖完就关门。早上·中午去(🍲)。
  2. “鲷鱼烧·糖饼的面糊都差不多”——糖饼馅里有坚果，鸡蛋糕里整颗放入鸡蛋(VisitKorea)。有过敏的话买之前先问(🐟)。
  3. “豆腐菜是素食”——嫩豆腐锅·炖豆腐大多放腌虾酱(#486)。要问汤底和腌海鲜酱(🥗)。
  4. “春节假期市场总会开吧”——有标注春节·中秋休息的店(银珠亭·黄生家·济州老式红豆粥)。2027年2月6~9日(暂定)来的话，先看休息标注(🧧)。

⚙ FAQ 4 个

Q1. 早上 7 点有开门的汤店吗？

有。钟路清津屋(06:00~)、市厅后面的武桥洞明太鱼汤店(07:00~)、明洞河东馆(周一至周六 07:00~)，地址·休息日都在 #486·#477。如果在住处附近，就在地图应用里搜索「醒酒汤 (Haejangguk / 해장국)」，再确认营业时间。

Q2. 我不吃猪肉，能吃汤饭吗？

雪浓汤·牛肉清汤已确认是牛骨·牛肉汤底(#477)。猪肉汤饭·血肠汤是猪肉。醒酒汤的汤底因店而异，要问“是牛肉汤底，还是猪肉汤底？”(🥗)。不要只看菜名来选。

Q3. 鲷鱼烧多少钱？

官方页面没有公布价格，每个摊位也不同。看现场价目表，带点现金会比较稳妥(#476 的固定店铺中也有刷卡标示为“无”的)。

Q4. 冬至是什么，那天吃什么？

2026年12月22日，是夜晚最长的一天。有吃红豆粥的习俗，五家红豆粥专门店的时间·休息日在 #476。
