小巷漫步⑥ 城北洞——料亭变寺庙的巷子，经过诗人故居走向城郭村

副标题：城北洞巷子故事层层叠加：博物馆馆长故居、料亭变身的吉祥寺、诗人韩龙云晚年的寻牛庄，直到暗门外的城郭村北井村——汉城大入口站出发，约2小时30分钟文人巷路线。Seoul Alley Walks扩展3号。

ISSUE · #1345 · 2026-09-02

🎯 定调——文人的社区

城北洞 (Seongbuk-dong / 성북동) 是韩国近现代文人、艺术家聚居的社区。这里紧邻都城之外的山脚，安静，而这份安静召唤了写作的人。这条路线按上坡顺序，串起那些痕迹——故居、寺庙、城郭村。终点处，从汉阳都城城郭俯瞰整个社区。

  • 总耗时：约2小时30分钟(含室内参观为3小时)·推荐时段：下午1~2点出发→以城郭观景收尾
  • 坡度：中——平缓的上坡持续，到北井村 (Bukjeong-maeul / 북정마을) 路段变陡。

🚶 路线——按行走顺序

① 汉城大入口站 (Hansung Univ. Station / 한성대입구역) 6号出口 → 崔淳雨故居 (Choi Sun-u Old House / 최순우 옛집) (步行约7分钟)

  • 曾任国立中央博物馆馆长的兮谷崔淳雨 (Choi Sun-u / 최순우)(1916~1984)生前居住的韩屋。就是写下《倚靠无量寿殿卷杀柱》一文的那位——不愧是用文字讲述韩国美学的人的家，庭院与窗棂的纹理堪称教科书。

② 崔淳雨故居 → 先蚕坛址 (Seonjamdanji / 선잠단지) → 吉祥寺 (Gilsangsa / 길상사) (步行约20分钟，上坡)

  • 经过朝鲜王妃向蚕神献祭的先蚕坛址，沿巷子往上走就是吉祥寺。
  • 📖 叙事1——料亭变寺庙的故事：吉祥寺所在地，原本是首尔有名的高级料亭大苑阁 (Daewongak / 대원각)。业主晚年将整片土地和建筑全部布施给法顶法师 (Beopjeong Sunim / 법정 스님)，1997年重生为寺庙——因"无所有"的法师与料亭主人的因缘而广为流传，是首尔用途转换最戏剧性的空间。料亭别馆的建筑结构仍保留着，因此与一般寺庙的气质不同。

③ 吉祥寺 → 寻牛庄 (Simujang / 심우장) (步行约15分钟)

  • 诗人兼独立运动家万海韩龙云 (Han Yong-un / 한용운) 晚年居住的房子。因不愿正对朝鲜总督府 (Government-General of Joseon / 조선총독부) 而特意朝北而建的轶事，是这栋房子的身份认同。免费参观(以09:00~18:00为准——请参观前确认)。

④ 寻牛庄 → 北井村 (步行约10分钟，陡上坡)

  • 📖 叙事2——城郭下的村庄：这是汉阳都城暗门(应急出入门)外坡地上，聚集着数百栋1960~70年代所建小瓦房的城郭村。在首尔，还留有这种景象的地方如今屈指可数——巷子狭窄且全是住宅，安静通过是这一段该有的礼貌。

⑤ 北井村 → 汉阳都城暗门 → 城郭观景收尾 (步行约10分钟)

  • 穿过暗门，站上城郭内侧小径，城北洞山谷和走过的巷子尽收眼底。这条路线的结尾。
  • 收尾选项：沿城郭路往惠化门 (Hyehwamun / 혜화문) 方向下山(接#1239历史路线)，或原路返回，在城北洞咖啡馆巷子休息。

🙏 小巷礼仪

  • 吉祥寺是修行中的寺庙——禁止拍摄法堂内部，请保持安静。寺内着装要端庄。
  • 北井村百分之百是住宅区——禁止拍摄大门、院子，不要成群站立，声音尽量放低。
  • 寻牛庄、崔淳雨故居都有开放时间——若从下午较晚时段出发，请把室内参观排在前面。

💡 避坑提醒

  • 这条路线几乎全程上坡——请在地图App预估时间基础上多加20%。
  • 吉祥寺的免费循环巴士运行日、法会活动日，寺内会比较拥挤——最好避开浴佛节前后，才符合这条安静路线的调性。
  • 城郭暗门有开放时间(存在夜间封闭路段)——请在天黑前通过。
