韩国饺子指南 — 开城·朝鲜式饺子汤与中式饺子8家 — 开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁)、紫霞孙饺子 (Jaha Son Mandu / 자하손만두)、饺子馆 (Mandujip / 만두집)、新发园 (Sinbalwon / 신발원)，首尔·釜山 (2026年10月官方数据)

副标题: 开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) 1970年起，第三代经营 (VisitKorea) · 紫霞孙饺子 (Jaha Son Mandu / 자하손만두) 1993年起在付岩洞 (Buam-dong / 부암동)，周一休息 (VisitKorea·米其林页面) · 首尔饺子必比登推介4家 (开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁)、紫霞孙饺子 (Jaha Son Mandu / 자하 손만두)、饺子馆 (Mandujip / 만두집)、美笔谭 (Mipildam / 미필담)) · 釜山平壤家 (Pyeongyangjip / 평양집) 为必比登推介，周一至周六 10:30~15:30 (米其林页面) · 新发园 (Sinbalwon / 신발원) 距釜山站5号出口90米 (VisitKorea) — 截至2026-10-21

ISSUE 03 · #481 · 2026-05-27

🎯 如何使用本指南

用发酵三小时的面皮包成的大饺子，漂在清澈的肉汤里端上来 — 这是仁寺洞 (Insa-dong / 인사동) 韩屋 (Hanok / 한옥) 里开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) 的饺子汤 (Mandutguk / 만둣국) (米其林页面)。本指南只介绍以饺子 (Mandu / 만두) 为主角的店。分三类：韩屋饺子馆 (开城式·付岩洞)、朝鲜式饺子汤、中式饺子。刀切面、冷面店里作为配菜的饺子 (明洞饺子 (Myeongdong Gyoja / 명동교자)、黄生家刀切面 (Hwangsaengga Kalguksu / 황생가 칼국수)、正仁面屋 (Jeongin Myeonok / 정인면옥) 等)只收录在 #480 面条指南 里。店家只选了米其林指南官网和VisitKorea旅游信息上列出的。写给需要一碗清淡汤的人，以及想比较各家饺子的人。

旧版指南把紫霞孙饺子 (Jaha Son Mandu / 자하손만두) 写成"城北洞 (Seongbuk-dong / 성북동) 传承宫廷饺子"。官方页面上的紫霞孙饺子在钟路区付岩洞 (Buam-dong / 부암동) (白石洞路 (Baekseok-dong-gil / 백석동길) 12号)，老板朴慧敬 (Park Hye-gyeong / 박혜경) 女士用从祖母和母亲那里传下来的手艺，自1993年起卖饺子汤 (米其林页面·VisitKorea)。"宫廷饺子"这个说法没有依据。"付岩平壤饺子店"在官方页面上也找不到，因此删除。

🏠 韩屋饺子馆 — 首尔2家

  • 开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) — 首尔钟路区仁寺洞10街 (Insadong 10-gil / 인사동10길) 11-3。工作日 11:30~21:30 (备料时间 15:00~16:00，最后点单 20:50)，周六 11:30~21:30，周日 11:30~20:00，全年无休 (VisitKorea)。1970年由开城 (Gaeseong / 개성) 出身的祖母创办，第三代经营。馅料里放足白菜和绿豆芽，牛腩汤底。肉饺火锅 (Gogi-mandu-jeongol / 고기만두전골)、泡菜饺子火锅 (Kimchi-mandu-jeongol / 김치만두전골)、小茧形年糕饺子汤 (Jorengi-tteok Mandutguk / 조랭이떡 만둣국)。改造自韩屋的空间。电话 02-733-9240 (VisitKorea·米其林页面，必比登推介)
  • 紫霞孙饺子 (Jaha Son Mandu / 자하손만두) — 首尔钟路区白石洞路 (Baekseok-dong-gil / 백석동길) 12 (付岩洞 (Buam-dong / 부암동))。11:00~21:00 (最后点单 20:15)，每周一及春节 (Seol / 설)、中秋 (Chuseok / 추석) 当天休息 (VisitKorea)。1993年起。不加化学调味料，用自家腌制的朝鲜酱油调味的清澈汤底，饺子皮用国产面粉。饺子汤、年糕饺子汤 (Tteok-mandutguk / 떡만둣국)、饺子火锅 (Mandu-jeongol / 만두전골)、方皮饺子 (Pyeonsu / 편수)。有能看到仁王山 (Inwangsan / 인왕산) 的露台和需要脱鞋的座位。电话 02-379-2648 (米其林页面，必比登推介)。米其林价格符号为 ₩₩，是本指南里唯一高一档的

🥟 朝鲜式饺子汤 — 首尔3家·釜山1家

  • 饺子馆 (Mandujip / 만두집) — 首尔江南区狎鸥亭路 (Apgujeong-ro / 압구정로) 338。周一至周六 12:00~20:00，周日休息。在清潭洞 (Cheongdam-dong / 청담동) 营业30多年。招牌是牛腩汤里放手工饺子的平安道式 (Pyeongando-sik / 평안도식) 饺子汤，可以要求做得不那么辣。也有绿豆煎饼 (Nokdu-jeon / 녹두전)、辣椒煎饼 (Gochu-jeon / 고추전)。电话 +82 2-544-3710 (米其林页面，必比登推介)
  • 美笔谭 (Mipildam / 미필담) — 首尔麻浦区圣地3街 (Seongji 3-gil / 성지3길) 22 (合井洞 (Hapjeong-dong / 합정동) 小巷)。周三至周日 11:30~14:30·17:30~20:30，周一、周二休息。夫妇二人按黄海道 (Hwanghae-do / 황해도) 出身的外祖母的做法煮的朝鲜式手工饺子汤。有适合一个人用餐的座位，吧台座位。电话 +82 10-5455-5041 (米其林页面，必比登推介)
  • 朝鲜饺子 (Ibuk Mandu / 이북만두) — 首尔中区武桥路 (Mugyo-ro / 무교로) 17-13 (首尔市厅后巷)。工作日 11:00~21:00 (备料时间 14:30~16:30)，周末 10:30~20:00，全年无休。不是牛骨汤而是清汤，只放大饺子、大葱和胡椒的朝鲜饺子汤 (Ibuk Mandu-guk / 이북만두국)，夏天有泡菜汤泡饭 (Kimchi-mari-bap / 김치말이밥)。电话 02-776-7361，全店禁烟 (VisitKorea)
  • 平壤家 (Pyeongyangjip / 평양집) (釜山) — 釜山北区金谷大路20街 (Geumgok-daero 20beon-gil / 금곡대로20번길) 21。周一至周六 10:30~15:30，周日休息。用泡菜、粉丝、豆腐、蔬菜包成的朝鲜式手工饺子，放在牛腩、牛腱汤里端上。可在泡菜饺子 (Kimchi-mandu / 김치만두) 和豆腐饺子 (Dubu-mandu / 두부만두) 中选一种，也有绿豆煎饼 (Nokdu-jeon / 녹두전)。电话 +82 51-331-5445 (米其林页面，必比登推介)

🥢 中式饺子 — 釜山·首尔2家

  • 新发园 (Sinbalwon / 신발원) — 釜山东区大荣路243街 (Daeyeong-ro 243beon-gil / 대영로243번길) 62 (草梁洞 (Choryang-dong / 초량동))。11:00~21:00 (最后点单 20:20)，每周二休息。距釜山站5号出口90米。肉饺 (Gogi-mandu / 고기만두)、煎饺 (Gun-mandu / 군만두)、虾饺 (Saeu-mandu / 새우만두)、韭菜粉丝饺 (Buchu-dangmyeon-mandu / 부추당면만두)，还有豆浆汤 (Kongguk / 콩국) 和豆子点心 (Kong-gwaja / 콩과자)。可打包。电话 0507-1440-0195 (VisitKorea)。整个草梁唐人街见 #1409 釜山站前的一小时
  • 九福饺子 (Gubok Mandu / 구복만두) — 首尔龙山区厚岩路 (Duteopbawi-ro / 두텁바위로) 7。韩国丈夫和中国妻子经营的小型点心 (Dim Sum / 딤섬) 店，菜单只有四种。招牌是平底锅煎的猪肉泡菜"九福泡菜饺子 (Gubok Kimchi-mandu / 구복 김치만두)"，点单后才做，要稍等。电话 +82 2-797-8656 (米其林页面，无米其林推介、必比登标识)。米其林页面按星期列出的营业时间只显示了一个星期几，因此未能确认营业时间 — 请电话确认

🥗 饮食

  • 价格区间: 没有官方公布的韩元价格。按米其林符号，紫霞孙饺子 (Jaha Son Mandu / 자하손만두) 是 ₩₩，其余米其林收录的5家是 ₩ (米其林页面)
  • 素食: 饺子馅大多放猪肉 (开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁)、九福饺子 (Gubok Mandu / 구복만두) 的米其林页面)，饺子汤的汤底用牛腩、牛腱熬成 (饺子馆 (Mandujip / 만두집)、平壤家 (Pyeongyangjip / 평양집)、开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁))。米其林照片说明提到开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁) 有蘑菇饺子 (Beoseot-mandu / 버섯만두)，但汤底和馅料的材料未能确认。平壤家 (Pyeongyangjip / 평양집) 的豆腐饺子也是放在肉汤里。VisitKorea写道泡菜的调料大多含有腌制海鲜、鱼露 — 可以认为泡菜饺子不是素食
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00) 是少数获韩国伊斯兰教中央会 (KMF) 认证为清真的餐厅之一。本指南里的饺子店没有清真标识
  • 过敏: 小麦 (饺子皮)、大豆·豆腐 (豆腐饺子、新发园 (Sinbalwon / 신발원) 的豆浆汤)、虾 (新发园 (Sinbalwon / 신발원) 的虾饺)
  • 出示用的卡片见 #1300 饮食需求手册

🧰 饺子实用信息 — 独自用餐、预约、付款、点餐、交通

  • 独自用餐: 饺子汤是一人一碗，很适合一个人去。美笔谭 (Mipildam / 미필담) 被米其林标注有单人用餐座位。火锅 (开城饺子宫 (Gaeseong Mandu Gung / 개성만두 궁)、紫霞孙饺子 (Jaha Son Mandu / 자하손만두))人多时再选。单人用餐地图见 #348 Seoul Solo Diner Map
  • 预约: 官方页面都只写"直接打电话给餐厅"
  • 付款: 米其林收录的6家可刷信用卡 (米其林页面)。刷卡和移动支付见 #527 韩国支付系统
  • 点餐: 新发园 (Sinbalwon / 신발원) 可以打包 (VisitKorea) — 适合在釜山站上火车前买了带走。语言不通时见 #1339 点餐礼仪
  • 交通: 首尔地铁和公交见 #1298 三种交通卡怎么选，釜山见 #1325 釜山公共交通语法

⚠ 常见的4个误区

1. "紫霞孙饺子是城北洞的宫廷饺子店" — 在付岩洞，传承的是祖母和母亲的家常饺子 (米其林页面·VisitKorea)

2. "周一去付岩洞吃饺子" — 紫霞孙饺子 (Jaha Son Mandu / 자하손만두) 每周一休息 (VisitKorea·米其林页面)。美笔谭 (Mipildam / 미필담) 周一、周二也休息

3. "晚上去釜山平壤家" — 平壤家 (Pyeongyangjip / 평양집) 只在 10:30~15:30营业 (米其林页面)

4. "新发园每天营业" — 每周二休息 (VisitKorea)
