한국 전 주문·막걸리 페어 워크플로우 — 광장 빈대떡부터 비 오는 날 파전까지

> 부제: 외국인 관광객용 5-step + 막걸리 페어 + 명절 매너 + 영어 발화

ISSUE 03 · #883 · 2026-06-09

🎯 왜 한국 전 워크플로우 가이드인가

[#882 전 6종 매트릭스](#882) 알아도 — 주문·페어·매너는 별개. 한국 전은 (a) 광장시장 빈대떡 골목 (vlog #1) (b) 전통주점·MZ 한식당 (비 오는 날 파전 + 막걸리) (c) 포장마차 (소주·맥주 페어) (d) 한정식·명절 (동그랑땡 정통). 외국인은 (1) 비 오는 날 = 파전 + 막걸리 한국 문화 모름 (2) 광장 빈대떡 = 즉석 부치기 모름 (3) 막걸리 vs 소주 페어 모름 (4) 명절 동그랑땡 = 손님 매너 모름. 본 가이드는 5-step + 막걸리 페어 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 광장시장 / 전통주점 / 포장마차 / 한정식 즉시 vlog·비 오는 날·소주·명절
2️⃣ 메뉴 주문 6종 + 막걸리·소주 1~5분 광장 = 즉석 부치기
3️⃣ 받기·세팅 전 + 간장 양념·고추·마늘 5~15분 즉석 전 따끈따끈
4️⃣ 먹기·페어 전 + 막걸리·소주 30~90분 비 오는 날 막걸리 #1
5️⃣ 결제 카드 OK / 시장 = 현금 일부 / 팁 X 1~5분 1/N 더치 OK

> 총 소요 시간: 광장시장 = 30분~1.5h / 전통주점 = 1~3h / 포장마차 = 1~3h / 한정식 = 1.5~2.5h

🥞 채널별 워크플로우

Type A — 광장시장 빈대떡 골목 (vlog #1)

  • 시그니처: vlog #1·즉석 부치기·노포
  • 시간: 09:00~22:00
  • 가격: 5,000~15,000원/1개
  • 메뉴: 녹두빈대떡·고기빈대떡·김치빈대떡·마약김밥 cross
  • 외국인 친화도: ★★★★★ (vlog #1)

Type B — 전통주점·MZ 한식당 (비 오는 날 막걸리)

  • 시그니처: 비 오는 날 파전 + 막걸리 #1·한국 문화 정통
  • 시간: 17:00~24:00
  • 가격: 파전 8~20k + 막걸리 5~10k
  • 메뉴: 파전·해물파전·감자전·김치전·녹두빈대떡 + 막걸리
  • 외국인 친화도: ★★★★ (한국 정통 문화)

Type C — 포장마차 (소주안주)

  • 시그니처: 소주안주·길거리·노포
  • 시간: 18:00~02:00
  • 가격: 김치전·핫바 5~12k
  • 메뉴: 김치전·동그랑땡 핫바·골뱅이무침 cross ([#862](#862))
  • 외국인 친화도: ★★★ (한국어 정통)

Type D — 한정식·명절 (동그랑땡 정통)

  • 시그니처: 한정식 코스·명절·제사 정통 ([#846](#846))
  • 시간: 11:30~22:00
  • 가격: 한정식 코스 40~150k (동그랑땡 포함)
  • 메뉴: 동그랑땡·산적·나물 (명절 정통)
  • 외국인 친화도: ★★★★ (영문 일부)

🍶 막걸리·페어 매트릭스

☔ 비 오는 날 매니아 (한국 문화 #1)

  • 시그니처: 비 오는 날 + 파전 + 막걸리 = 한국 정통 분위기
  • 이유: 빗소리 + 파전 부치는 소리 = 한국 정통
  • MZ 트렌드: SNS 인스타 #1 인증

🌶 외국인 영어 발화 샘플

  • "파전 + 막걸리" = "Korean savory pancake with Makgeolli rice wine"
  • "비 오는 날 정통" = "Rainy day tradition (Pajeon + Makgeolli)"
  • "광장 빈대떡 정통" = "Gwangjang market mung bean pancake (vlog #1)"
  • "강원 감자전" = "Gangwon potato pancake (regional specialty)"
  • "명절 동그랑땡" = "Holiday meatball pancake (Lunar New Year·Chuseok)"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "전 = 파전만": 전 = 6종·다양.

2. "비 오는 날 = 우연": 비 오는 날 = 막걸리 페어 #1 한국 문화.

3. "광장 = 일반 시장": 광장 빈대떡 = vlog #1 즉석 부치기 정통.

4. "막걸리 = 1종": 막걸리 = 6종 (장수·국순당·지평·강원·MZ 변형).

5. "명절 = 일반 식사": 명절 = 동그랑땡·산적·나물 정통 ([#846](#846)).

6. "녹두 = 콩": 녹두 (mung bean) = 빈대떡 정통·콩과 다름.

7. "감자전 = 일반": 감자전 = 강원 정통 얇음·감자 100%.

⚙ FAQ 8개

1. 첫 전 = 어떤 채널: 광장시장 녹두빈대떡 (#1 vlog) → 전통주점 파전.

2. 인스타·vlog: 광장 빈대떡 (#1)·비 오는 날 파전·강원 감자전.

3. MZ 트렌드: 김치전·핫바·MZ 막걸리 페어.

4. 막걸리 매니아: 파전 + 막걸리 (#1).

5. 명절 매니아: 동그랑땡 (설날·추석).

6. 알레르기·임신: [#882 disclaimer](#882) 참조.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

전 = 일반 음식·기름 사용. 임신부·어린이 = OK (막걸리 X). 알레르기 (밀가루 글루텐·해산물·돼지·계란·녹두) 사전 고지. 막걸리 = 6~8% 알코올·임신부·운전 X. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 파전·감자전·김치전 = OK (돼지·갑각류 일부 확인) / 막걸리 = 알코올 X (할랄 X).
  • 채식·비건: 파전·감자전·김치전 채식 OK (계란 옵션) / 비채식 = 녹두빈대떡·해물파전·동그랑땡.
  • 글루텐 free: 밀가루 함유 → 어려움·감자전 = 적음 (사전 확인).
