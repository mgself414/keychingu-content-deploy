百済文化祭ガイド — 第72回 2026 公州・扶余（10/3～10/11）、公式プログラム・料金・アクセス

サブタイトル: 公州の錦江新官公園・公山城と、扶余の定林寺址・石塔路・官北里 — 二つの都市で同じ日程に別々に開催されます。2026-10-07時点の公式サイト基準 · 熊津ファンタジア 10/7～10 21:00 · 公山城メディアアート 毎日19:30～22:00 · 扶余 歴史文化行列 10/9 · ナイトパレードと落火遊び 10/10 · 閉幕 10/11

ISSUE 04 · #1068 · 2026-06-13

🎯 このガイドの使い方

百済文化祭 (Baekje Munhwaje / 백제문화제) は、公州 (Gongju / 공주) と扶余 (Buyeo / 부여) が同じ期間にそれぞれ開く二つの行事です。公式サイトも二つ（公州 gongju.baekje.org / 扶余 baekjeculturalfestival.kr）あり、プログラムも会場も異なります。古いガイドにある「クドゥレのメイン舞台」や「公山城の百済行列 11時」は、公式日程にはありません。以下は2026-10-07に二つの公式サイトで確認した第72回（2026-10-03～10-11、9日間）の内容で、10/7以降に残っている日程だけを載せています。毎年9～10月に開催され、翌年の日程は通常、上半期に公式サイトで公開されます。

🏯 公州 — 錦江新官公園 + 公山城

  • テーマは「青銅の鏡、1500年の百済の光を映す」。メイン会場は錦江新官公園（錦江の河川敷）、夜のメディアアートは公山城（ユネスコ）です。
  • 料金（公式掲示分）：錦江の上のミル島 (Mireuseom / 미르섬)・船橋 (Baedari / 배다리) の入場券は大人7,000ウォン・青少年6,000ウォン — 百済服着用者・65歳以上・小学生・公州市民は無料で、入場券には3,000ウォンのクーポンが含まれます。舞台公演・メディアアートは料金の掲示がないため、有料か無料かは断定しません。
  • 公山城そのものは祭りとは別に、大人3,000ウォン・09:00～18:00（#1043）。武寧王陵 (Muryeong-wangneung / 무령왕릉) と王陵園の共通券は6,000ウォンです。
  • アクセス（公式の「お越しの方法」）：KTX・SRTの公州駅 (Gongju-yeok / 공주역)（龍山から約1.5時間）→ 市内バス・タクシー / 車の場合は公州IC。駐車場・シャトルの案内は画像でしか掲載されておらず読めませんでした — 現地の案内に従ってください。
  • 英語メニューは、公州サイトのトップページでは見つかりませんでした（未確認）。

🪷 扶余 — 定林寺址 + 石塔路 + 官北里

  • テーマは「美しい百済、輝く泗沘」。会場は定林寺址 (Jeongnimsaji / 정림사지)・石塔路 (Seoktap-ro / 석탑로)・官北里 (Gwanbuk-ri / 관북리) の遺跡です。クドゥレは落火遊びとコスモス畑の場所です。
  • 英語サイトあり：baekjeculturalfestival.kr/en。
  • 残りの見どころ：10/9 百済歴史文化行列 15:30 · 10/10 ナイトパレード 19:30 + 落火遊び 19:00 クドゥレの河川敷 · 10/11 閉幕。
  • 遺跡の料金は祭りとは別です：定林寺址（博物館は無料）・扶蘇山城 (Busosanseong / 부소산성) 2,000ウォン・国立扶余博物館 (Gungnip Buyeo Bakmulgwan / 국립부여박물관) 無料（月曜休館）・百済文化団地 (Baekje Munhwa Danji / 백제문화단지) 6,000ウォン（月曜休館）— #1041。
  • アクセス：扶余には鉄道がありません。ソウル南部ターミナルからの高速バス、または公州からの路線バス（所要時間は予約サイトで確認）。シャトル・駐車ページは画像のため未確認です。

🚶 公州 + 扶余 1泊（残り日程基準）

  • 10/9（金）：午後 扶余の歴史文化行列 15:30 → 夜 韓・中・日公演 19:00 → 扶余に宿泊。
  • 10/10（土）：昼 定林寺址・扶蘇山城 → 夜はどちらか一つ：扶余のナイトパレード 19:30 + 落火遊び 19:00（同じ夜）または公州の熊津ファンタジア 21:00 + 公山城メディアアート。夜に二つの都市を行き来しません。
  • 10/11（日）：公州の武寧王陵・国立公州博物館 (Gungnip Gongju Bakmulgwan / 국립공주박물관) → 閉幕式 19:00。

⚠ よくある間違い5つ

1. 一つの祭りだと思って片方だけ見る — 公州と扶余ではプログラムが違います。公式サイトも二つです。

2. 古いリンク baekje.kr — 開きません。gongju.baekje.org / baekjeculturalfestival.kr を使ってください。

3. 実景公演・熊津城パレードを見に行く — 10/4～5に終わりました。

4. 夜に二つの都市を行き来する — 公州↔扶余をバスで移動すると公演を見逃します。夜は一つの都市で。

5. 「全部無料」と決めつける — ミル島・船橋は有料（7,000ウォン）で、それ以外は料金が掲示されていません。

⚙ FAQ 6

1. 2026年の日程は？ — 10/3（土）～10/11（日）、9日間、第72回（公式）。

2. 夜に見られるものは？ — 公州のメディアアート 19:30～22:00（毎日）+ 熊津ファンタジア 21:00（～10/10） / 扶余は10/10のナイトパレード・落火遊び。

3. 韓服を着ると？ — 百済服を着ていると、公州のミル島・船橋に無料で入場できます（公式）。

4. 英語の情報は？ — 扶余のサイトに英語版があります。公州は未確認です。

5. 来年は？ — 通常9～10月。上半期に公式サイトで確認してください。

6. 宿は？ — 公州の韓屋村（#1043）・扶余の市内。祭りの週末は早く埋まります。
