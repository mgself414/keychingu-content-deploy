🎯 왜 "Seoul Food Map" 통합 메타인가

방한 외국인 1,210만+ 풀 중 식도락 동기 비중 75%+ (segment 평균) — 한국 방문 핵심 동기 #1. 그러나 기존 키친구 콘텐츠는 area dive(#170 대학로·#171 신촌 등)·카테고리 dive(#129 냉면·#130 BBQ·#132 분식 등) 위주 — 외국인 첫 방문 풀 식도락 통합 메타 가이드 부재.

본 가이드는 8 카테고리 풀체험 (한식·국제·시장·미슐랭·길거리·BBQ·카페·디저트) × 2 시그니처 매장 = 16 시그니처 통합 매트릭스. 1주·3박 코스 매니아 패턴 + 1일 풀 hopping 시그니처. 키친구 첫 카테고리 메타 가이드 시리즈 1편.

⚠ 외국인이 자주 하는 실수 3가지

1. "한식 = 떡볶이·치킨·BBQ만" — 미슐랭·발효·시즌 한식 미인지: 첫 방문 외국인이 한식을 길거리·BBQ로만 인식. 실제로는 미슐랭 3 stars 밍글스 + 1 star 한식공간·온지음 + 한식 발효(김치·된장·고추장)·시즌(봄나물·여름팥빙수·가을 곶감·겨울 떡국) 다채로움. 1주+ 체류면 미슐랭 1회 + 시장 + BBQ + 거리음식 4축 풀체험 권장.

2. "식도락 = 명동·홍대만" — 8 카테고리 풀체험 미활용: 명동·홍대에 머무르며 한식 BBQ만 반복 패턴. 실제로는 이태원(국제·할랄) + 광장·노량진(시장) + 청담(미슐랭) + 종로3가(포장마차) + 노원(가성비 BBQ #179) 등 area별 카테고리 시그니처. 1주 코스 = area + 카테고리 매트릭스 풀체험.

3. "식도락 = 1인 패스" — 동행·시간대 시그니처 미인지: 한식 BBQ·한정식은 2~4인 시그니처(혼밥 비추) + 광장시장·노량진은 점심·새벽 시간대 시그니처(저녁 X) + 미슐랭은 사전 예약 1~3개월 전 필수. 시간대·동행 매트릭스 사전 인지 권장.

Seoul Food Map 풍경

서울은 OECD 국가 수도 중 식도락 동선 다양성 #1 — 한식 5천년 + 일본·중국·동남아·서양·중동·인도 다국적 + 미슐랭 3 stars 2개·1·2 stars 30+ + 광장·통인·노량진 시장 풀세트 + K-BBQ 시그니처 + 거리음식 + 카페·베이커리·디저트 풍부. 1주 체류로도 풀체험 어려움 — 1년 4계절 반복 방문 권장.

한식 5천년: 김치·된장·고추장·발효 + 시즌 (봄나물·여름팥빙수·가을 곶감·겨울 떡국) + 지역 시그니처 (전주 한정식·강원도 막국수·부산 돼지국밥·제주 흑돼지) + 한식 파인 다이닝 미슐랭.

다국적 풀세트: 이태원·한남·해방촌 USFK·미국·멕시코·인도·중동·아프리카 + 한남·청담·강남 양식·이탈리아·프랑스·일본 + 동대문 중앙아·동남아 + 마곡 LG·외국인 거주지 다양.

미슐랭 풀: 한국 미슐랭 가이드 2024 — 3 stars 2개(밍글스·라연) + 1·2 stars 30+. 한식 파인 다이닝 + 양식 + 일식 + 한식 발효·시즌 + 디저트 cluster.

시장 풀세트: 광장시장(외국인 #1·낮·저녁) + 노량진 수산시장(새벽 02~06) + 동대문 새벽 시장(22~04 의류+거리음식) + 통인 도시락 카페(11~17) + 남대문(상품·식자재) + 마장 축산물시장(고기 도매).

K-BBQ 시그니처: 새마을식당·하남돼지집·놀부보쌈·왕피그·중계고기파티(#179) + 갈비·삼겹·차돌·LA갈비·우삼겹. 외국인 1인 25,000~50,000원 가성비.

거리음식·포차: 명동 거리음식 18~24시(호떡·붕어빵·꼬치) + 종로3가 포장마차 거리(전·국수·꼬치 + 소주·막걸리, K-drama 풍경) + 을지로 노가리골목(노가리 + 생맥주 야장).

카페·디저트: 런던베이글뮤지엄(작년 938억) + 카페 어니언(1920s 한옥) + 삼청동·북촌·서촌 한옥 카페 + 성수·홍대 MZ 트렌드 + 한국 디저트(빵·떡·과자·과일).

T6.6 cluster signal mining에서 Seoul Food Map 16 시그니처 review_count 평균 7,500+ + 외국인 review 빈도 25%+ — 외국인 demand-supply gap 추정 850+ (Top 1 메타 카테고리). 콘텐츠 cov 60% (area·카테고리별 cover 있지만 통합 메타 부재).

Seoul Food Map의 진짜 차별점: area별 cover·카테고리별 cover 있지만 외국인 첫 방문 풀체험 통합 매트릭스 가이드 부재. 8 카테고리 × 2 시그니처 = 16 풀체험 + 1주 코스 + 1일 hopping = 외국인 풀 식도락 정답.
