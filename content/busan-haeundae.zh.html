釜山海云台·广安里12处 — 海滩·海岸列车·展望台·无人机秀，时间和票价

副标题: 为第一次去釜山的旅行者，把海云台、冬柏岛、广安里三个片区的12处整理在一起。海云台海水浴场沙滩长1.5km，广安里海水浴场长1.4km。海岸列车走尾浦到松亭之间的4.8km，单程约25分钟；天空胶囊列车按1台收费。广安里M无人机灯光秀在冬季的周六19:00和21:00举行。票价是2026-11-24查阅到的成人标准票价。

ISSUE 06 · #243 · 2026-11-24 · 부산 해운대·광안리

🎯 适合谁，为什么是这12处

这份清单是为第一次去釜山的外国旅行者准备的。从首尔抽出一两天看釜山东边海岸时可以用。以两片海滩为中心，再加上从周边步行或乘城市铁路2号线就能到的地方。

分成三个片区。

  • 海云台片区(6处): 海云台海水浴场 (Haeundae Haesuyokjang / 해운대해수욕장)、海云台蓝线公园 (Haeundae Blueline Park / 해운대블루라인파크)、迎月路 Moontan Road (Dalmaji-gil Moontan Road / 달맞이길 문탠로드)、釜山X the SKY (Busan X the Sky / 부산엑스더스카이)、SEA LIFE釜山水族馆 (SEA LIFE Busan Aquarium / SEA LIFE 부산아쿠아리움)、海云台传统市场 (Haeundae Jeontong Sijang / 해운대전통시장)。
  • 冬柏岛片区(3处): 冬柏岛海岸散步路 (Dongbaekseom Haean Sanchaekro / 동백섬 해안산책로)、世峰楼APEC会议厅 (Nurimaru APEC House / 누리마루 APEC하우스)、The Bay 101 (더베이101)。
  • 广安里片区(3处): 广安里海水浴场 (Gwangalli Haesuyokjang / 광안리해수욕장)、广安里M无人机灯光秀 (Gwangalli M Drone Light Show / 광안리 M 드론라이트쇼)、二妓台海岸散步路 (Igidae Haean Sanchaekro / 이기대 해안산책로)。

截至2026-11-24，现在是11月。不是海水浴的季节。所以这一篇不写玩水，而是以步行、乘坐、展望、夜间景点为主。海岸列车和天空胶囊列车按11~2月的冬季时间表运行，无人机秀也按冬季时间举行。

12处当中有四处，在韩国观光公社 (Korea Tourism Organization / 한국관광공사)"名胜发掘100×100"国民投票中获得了票数。相应条目里各写了一行得票。

⚠ 标注原则: 时间、票价、距离、交通方式，是2026-11-24查阅到的值。出处是海云台蓝线公园、釜山X the SKY、SEA LIFE釜山水族馆的运营方网站，以及釜山市、海云台区厅、水营区、Visit Busan、韩国观光公社。票价是成人标准票价。The Bay 101和海云台传统市场的地址·营业时间，以及从几个站出发的步行时间是Kakao Map的值，相应的行里注明了"Kakao Map"。运营时间、票价、公交线路可能变动。

✈ 先从金海机场到海云台

据釜山市英文公告(2026-11-24查阅)，机场大巴海云台线路从2026-01-05首班车起改版。票价是成人9,500韩元，青少年7,600韩元，儿童4,800韩元。

  • 萇山–海云台–机场线路: 用时90分钟。从机场发车的首班车是07:10，末班车是16:50。从萇山 (Jangsan / 장산)发车的车在05:30~19:00运行。开往萇山方向的发车间隔是20~60分钟。
  • 机张 (Gijang / 기장)–海云台–机场线路: 用时110分钟。从机场发车的首班车是10:10，末班车是21:40。
  • 下车地点: 站名改成了"海云台海水浴场 (Haeundae Haesuyokjang / 해운대해수욕장)"，站点编号09116。

从机场发车的萇山线路末班车是16:50。比这更晚到的话，就乘开到21:40的机张线路。两条线路的用时相差20分钟。

🚦 走路之前 — 共同的安全和礼仪

  • 11月不是海水浴的季节。 11月的海云台和广安里是在沙滩上散步、看海的地方。
  • 天气不好就改行程。 海岸列车下雨也正常运行，但暴雨和台风时不运行。无人机秀可能因气象或技术问题取消或延迟。
  • 二妓台海岸散步路有上坡路段。 这是一条4.7km、约需2小时30分钟的路。穿运动鞋，带上水。
  • 冬柏岛入口有坡度。 韩国观光公社无障碍说明写道，散步路入口有坡度10度左右的路段。
  • 遇到事故或紧急情况拨打119，报案拨打112。

① 海云台片区 — 6处

这是使用城市铁路2号线海云台站和中洞站的片区。海滩、水族馆、市场从海云台站步行去。展望台从中洞站步行，Moontan Road要从海云台站换乘社区巴士。海岸列车和天空胶囊列车在尾浦站 (Mipo / 미포정거장)乘坐。

海云台海水浴场 (Haeundae Haesuyokjang / 해운대해수욕장)

  • 大小: 海云台区厅写的沙滩长度1.5km，宽70~90m，面积120,000㎡。从一头走到另一头再回来是3km。
  • 夜晚: 据海云台区厅说明，景观灯全年每天从日落后亮到24:00。海水浴季亮到02:00。
  • 季节: 11月不是海水浴的季节。行程按沙滩散步和看海来安排。
  • 交通方式: 按Kakao Map路线，从城市铁路2号线海云台站5号出口步行11分(688m)。
  • 从机场出发: 机场大巴海云台线路的站名是"海云台海水浴场 (Haeundae Haesuyokjang / 해운대해수욕장)"，站点编号09116。

海云台蓝线公园 — 海岸列车·天空胶囊列车 (Haeundae Blueline Park / 해운대블루라인파크)

这是沿着海边铁路运行的两种交通工具。海岸列车从尾浦到松亭，天空胶囊列车从尾浦到青沙浦。下面的数值是蓝线公园官方网站2026-11-24的标注。

海岸列车 (Haebyeon Yeolcha / 해변열차)

  • 区间: 往返尾浦~青沙浦~松亭4.8km。平均时速15km，单程约25分钟。每小时3班。
  • 停靠站(官方网站累计距离): 尾浦 (Mipo / 미포)(0.3km，终点站) → 迎月隧道 (Dalmaji Tunnel / 달맞이터널)(0.8km) → 海月展望台 (Haewol Observatory / 해월전망대)(1.1km) → 青沙浦 (Cheongsapo / 청사포)(2.3km) → 踏石展望台 (Daritdol Observatory / 다릿돌전망대)(2.9km) → 九德浦 (Gudeokpo / 구덕포)(3.4km) → 松亭 (Songjeong / 송정)(4.8km，终点站)。
  • 运行时间: 11月(冬季，11~2月)是09:00~19:00。从尾浦和松亭发车的末班列车是19:00。过渡季(3·4·10月)是09:00~19:30，旺季(5·6·9月)是09:00~20:30，超旺季(7·8月)是09:00~21:30。
  • 天气: 下雨也正常运行。暴雨和台风时不运行。

天空胶囊列车 (Sky Capsule / 스카이캡슐)

  • 区间: 尾浦~青沙浦2.0km。在7~10m高的轨道上以平均时速4km行驶。单程约30分钟。有80台4人座胶囊在运行。
  • 运行时间: 冬季08:30~18:00。过渡季08:30~18:30，旺季08:30~19:30，超旺季08:30~20:30。

迎月路 Moontan Road (Dalmaji-gil Moontan Road / 달맞이길 문탠로드)

  • 国民投票: "海云台迎月路"在韩国观光公社名胜发掘100×100跑步路线主题国民投票中得130票，第16名。
  • 区分两条路:
  • 迎月路 (Dalmaji-gil / 달맞이길): 海云台区厅介绍为从海云台海水浴场通往松亭海水浴场的路段、卧牛山 (Wausan / 와우산)山腰上8km的兜风路线。弯道超过15个，也叫15曲道。山顶有迎月园 (Dalmaji Dongsan / 달맞이동산)、海月亭 (Haewoljeong / 해월정)(1997)、新千年纪念钟楼 (Saecheonnyeon Gineum Sigyetap / 새천년기념시계탑)(2000)。

  • 入口地址: 釜山海云台区 (Dalmaji-gil 190 / 달맞이길 190)。

② 冬柏岛片区 — 3处

三处都从城市铁路2号线冬柏站1号出口出站。沿散步路走一圈，世峰楼APEC会议厅就出现在路上。

冬柏岛海岸散步路 (Dongbaekseom Haean Sanchaekro / 동백섬 해안산책로)

  • 国民投票: 冬柏岛在韩国观光公社名胜发掘100×100跑步路线主题国民投票中得136票，第10名。

  • 使用时间·费用: 全天开放，全年无休，免门票。
  • 交通方式: 从2号线冬柏站1号出口出站。Visit Busan写的是从1号出口步行17分。公交车乘1003路，在"冬柏岛站 (Dongbaekseom / 동백섬)"下车。
  • 设施: 有洗手间。釜山市世峰楼说明写道，冬柏公园别馆停车场收费，冬柏岛周边停车位窄，周末和节假日会停满，建议乘公共交通。

世峰楼APEC会议厅 (Nurimaru APEC House / 누리마루 APEC하우스)

  • 运营时间: 09:00~18:00。入场在关门前1小时截止。必须在17:00前到达才能入场。
  • 休息日: 每月第一个周一。
  • 票价: 免费。
  • 交通方式: 2号线冬柏站1号出口，或公交车1003路"冬柏岛站"。在冬柏岛海岸散步路的尽头相遇。
  • 咨询: 051-743-1974~5。

The Bay 101 (더베이101)

  • 位置(Kakao Map登记值，2026-11-24): 釜山海云台区 (Dongbaek-ro 52 / 동백로 52)。
  • 营业时间(Kakao Map登记值，2026-11-24): 每天08:00~24:00。
  • 交通方式: 按Kakao Map路线，从2号线冬柏站1号出口步行13分(751m)。
  • 组合方法: 和冬柏岛用同一个站、同一个出口。先看世峰楼(18:00闭馆)和散步路，晚上再来。营业时间24:00是Kakao Map登记值。

③ 广安里片区 — 3处

这个片区是广安里海水浴场、广安里M无人机灯光秀、二妓台海岸散步路。二妓台海岸散步路在广安里的南边，是釜山南区一侧的海岸。站也不同。广安里用金莲山站·广安站，二妓台要从景星大学·釜庆大学站换乘公交车。

广安里海水浴场 (Gwangalli Haesuyokjang / 광안리해수욕장)

  • 国民投票: 广安里海水浴场在韩国观光公社名胜发掘100×100跑步路线主题国民投票中得148票，第4名。
  • 大小: 釜山市写的是"总面积82,000㎡，沙滩长度1.4㎞，沙滩宽度25~110m"。从一头走到另一头再回来是2.8km。
  • 使用时间·费用: Visit Busan写的是全天开放，全年无休，免费。介绍说在海边主题街可以散步和骑自行车，夏季有演出。
  • 夜晚: Visit Busan写道，广安大桥 (Gwangandaegyo Bridge / 광안대교)的灯光每秒变换颜色。
  • 季节: 11月不是海水浴的季节。
  • 交通方式: 各机构的出口说明不同。
  • 水营区说明: 城市铁路2号线金莲山站3号出口步行5分钟，广安站3号出口步行10分钟。
  • Visit Busan说明: 2号线广安站5号出口步行约13分钟。
  • 公交车: 水营区写的是乘41·49·38·42·51·62·83·83-1·108-1路，在"广安里海水浴场站 (Gwangalli Haesuyokjang / 광안리해수욕장)"下车后3分钟。Visit Busan写的是42·62路。
  • 地址: 釜山水营区 (Gwanganhaebyeon-ro 219 ilwon, Gwangan-dong / 광안해변로 219 일원, 광안동)。
  • 停车: Visit Busan介绍"附近公营停车场"。
  • 周边: Visit Busan列出的旁边景点有广安大桥夜景、民乐生鱼片店街 (Millak Hoetjip-geori / 민락횟집거리)、水边公园 (Subyeon Gongwon / 수변공원)、南川洞樱花街 (Namcheon-dong Beotkkot-geori / 남천동 벚꽃거리)。

广安里M无人机灯光秀 (Gwangalli M Drone Light Show / 광안리 M 드론라이트쇼)

  • 何时: 据釜山市说明，每周六举行定期演出。10~2月的冬季是19:00和21:00两场。
  • 取消条件: 可能因气象或技术问题取消或延迟。
  • 星期: 工作日和周日没有定期演出。先看看釜山行程里是否包含周六。
  • 交通方式: 以广安里海水浴场为准，从金莲山站3号出口步行5分钟(水营区说明)。
  • 配合时间: 想看19:00的演出，会和海岸列车冬季末班车(19:00)冲突。蓝线公园白天乘坐，晚上再过来广安里。

二妓台海岸散步路 (Igidae Haean Sanchaekro / 이기대 해안산책로)

  • 国民投票: "釜山二妓台海岸散步路"在韩国观光公社名胜发掘100×100越野跑路线主题国民投票中得125票，第2名。
  • 位置: 广安里的南侧海岸。行政区划是釜山南区。
  • 区间·距离: Visit Busan写的是从Dongsaengmal (동생말)经Eoullimadang (어울마당)、Nongbawi (농바위)到五六岛码头 (Oryukdo Seonchakjang / 오륙도선착장)，全长4.7km，步行约2小时30分钟。
  • 路的性质: 有上坡路段。比沙滩散步更费时间和体力，按这个来安排。
  • 使用时间·费用: 全天开放，免费。
  • 交通方式: 从城市铁路2号线景星大学·釜庆大学站换乘公交车。公交车是20·22·24·27·39·131路，社区巴士是南区2路 (Nam-gu 2 / 남구2)、南区8路 (Nam-gu 8 / 남구8)。
  • 停车: 有二妓台公营停车场，收费。
  • 计划: 这是从一头进、从另一头出的路。和广安里组合的话，单独留出半天，白天走，晚上回广安里。

🗺 路线 — 半天·一天

顺序是按各处的开门·关门时间安排的。机构写的所需时间是胶囊约30分钟、列车单程约25分钟、Moontan Road宽裕地1小时、二妓台约2小时30分钟。

半天A — 海云台白天 (不限星期)

  1. 2号线海云台站5号出口 → 海云台海水浴场(按Kakao Map路线步行11分)。走沙滩1.5km。
  2. 10:00开门的SEA LIFE釜山水族馆或釜山X the SKY中选一处。
  3. 尾浦站 → 乘天空胶囊列车到青沙浦(约30分钟)。
  4. 青沙浦 → 乘海岸列车到尾浦或松亭。青沙浦出发的单程票是8,000韩元。
  5. 回到海云台站一侧，去海云台传统市场(Kakao Map登记值到22:00)。

冬季天空胶囊列车到18:00，海岸列车在尾浦·松亭19:00最后发车。不要把第3和第4项推到傍晚。

半天B — 从冬柏岛到广安里的傍晚 (周六)

  1. 2号线冬柏站1号出口 → 冬柏岛海岸散步路约950m。
  2. 世峰楼APEC会议厅。17:00前进去。第一个周一休息。
  3. 冬柏站 → 2号线金莲山站3号出口 → 广安里海水浴场(步行5分钟)。
  4. 19:00广安里M无人机灯光秀。错过的话，21:00还有一场。

不是周六的话去掉第4项，也可以把第3项换成The Bay 101(Kakao Map登记值到24:00)。

白天 海云台蓝线公园(天空胶囊列车 + 海岸列车) 冬季天空胶囊列车到18:00，海岸列车到19:00。胶囊约30分钟，列车单程约25分钟

⚠ 3个常见失误

  1. 把天空胶囊列车的票价当成每人的价格 — 天空胶囊列车是1台胶囊的价格。2人座50,000韩元，3人座55,000韩元，4人座60,000韩元。四个人乘的话约每人15,000韩元，两个人则约每人25,000韩元。海岸列车单程票下车后也不能再乘，所以想在中途站下车后接着乘，就买全站票(16,000韩元)。
  2. 随便哪天晚上去看无人机秀 — 定期演出是周六，冬季是19:00和21:00两场。可能因气象或技术问题取消或延迟。周六晚上不要再叠加别的预约。
  3. 把二妓台当成广安里旁边的短途散步 — 二妓台海岸散步路在广安里南边的南区海岸，4.7km要走约2小时30分钟。还有上坡。要从站换乘公交车才能到。迎月路也类似。迎月路本身是8km的兜风路线，步行的路是2.2km环形路线的Moontan Road。

⚙ 3个常见问题

  1. 11月去海云台值得吗？ — 11月不是海水浴的季节，所以不安排下海的行程。不过室内景点和乘坐设施按冬季时间开放。SEA LIFE釜山水族馆周一~周五到19:00，周六·周日到20:00，釜山X the SKY每天到21:00。海岸列车和天空胶囊列车按冬季时间表(分别到19:00、18:00)运行。海云台海水浴场的景观灯从日落后亮到24:00，广安里海水浴场全天开放。
  2. 表中写了票价的地方和写了免费的地方是哪些？ — 收费的地方是釜山X the SKY(成人29,000韩元)、海云台蓝线公园(海岸列车单程票8,000~10,000韩元，天空胶囊列车1台50,000~60,000韩元)、SEA LIFE釜山水族馆。免费或免门票的地方是广安里海水浴场、冬柏岛海岸散步路、世峰楼APEC会议厅、二妓台海岸散步路。票价都是2026-11-24查阅到的值。
  3. 从金海机场怎么去海云台？ — 有机场大巴海云台线路。成人9,500韩元，在"海云台海水浴场 (Haeundae Haesuyokjang / 해운대해수욕장)"站下车，站点编号09116。2026-01-05线路改版，分成开往萇山方向(用时90分钟，机场发车07:10~16:50)和开往机张方向(用时110分钟，机场发车10:10~21:40)两路运行。
