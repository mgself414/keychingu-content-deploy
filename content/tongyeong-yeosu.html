⚠ 외국인 자주 실수 5가지

1. "통영 = 어디나": 통영 = 한국 1번지 어업 도시 (Korea's #1 fishery town) + 동피랑 벽화마을·강구안·중앙시장 + 외국인 인스타 1순위.

2. "여수 = KTX 끝": 여수 = KTX 호남선 종착 (3시간) + 한국 1번지 밤바다 + 2012 여수 엑스포 + 외국인 매니아 1번지.

3. "남해 = 작은 섬": 남해 = 한국 #2 면적 섬 + 다랭이마을·보리암·금산 + 외국인 매니아 1번지 + 노을 1번지.

4. "거제 = 못 감": 거제 = 한국 #1 면적 섬 (제주 다음) + 외도·매미산 + 외국인 매니아.

5. "진주 = 가깝지 않음": 진주 = 남해안 진입 거점 + 진주성·진주 남강 야경 + 외국인 매니아 1번지.
