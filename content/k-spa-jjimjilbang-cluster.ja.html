① ソウル — 4軒

24時間営業しているのは、江辺スパランド・スパレックス トンミョ店・スパレイの3軒です。森の漢方ランドは22:00に閉まります。

江辺スパランド (Riverside Spa Land / 강변스파랜드)

カンビョン駅 (Gangbyeon / 강변역)前の商業ビル地下にある大型チムジルバンです。オーナーの紹介に、松の薪を使う火窯が書かれています。公式サイトによると365日24時間営業で、昼間(05~20時)と夜間(20~05時)で料金が違います。サウナは昼間13,000ウォン、チムジルバンは昼間15,000ウォン、夜間17,000ウォンです(7歳以下は9,000・11,000・13,000ウォン)。チムジルバンは入室15時間、サウナは6時間を超えると1時間ごとに1,000ウォンが加算されます。住所は広津区 (Guui-gangbyeon-ro 45 / 구의강변로 45) ソンジンプラザ (Seongjin Plaza / 성진프라자) 地下1~2階で、カンビョン駅 (Gangbyeon / 강변역)(2号線)4番出口から412mです。

  • 規定(公式): 法定保護者のいない19歳未満は22:00~05:00の入場が制限され、身分証の確認を求められることがあります。満4歳以上の男の子は女湯に入れません。外部からの食べ物の持ち込みは禁止で、利用中に外出すると再入場できません。

B. 牙山の日帰り: 1号線のオニャンオンチョン駅 (Onyang Oncheon / 온양온천역)で降りて、午前にウォンタン シンチョンタン (Wontang Sincheontang / 원탕신천탕)(05:00~18:00)、午後に温陽観光ホテル 大温泉浴場 (Onyang Tourist Hotel Daeoncheontang / 온양관광호텔 대온천탕)(平日19:00入場締切)をつなぎます。二つは同じ通りに並んでいます。火曜は大温泉浴場が休みかどうかを先に確認してください。公式ページの表記も二つに分かれています。

⚠ よくある間違い3

  1. どこでも夜を明かそうとする — この回で夜通し滞在できるのは、江辺スパランド (Riverside Spa Land / 강변스파랜드)・スパレックス トンミョ店 (Sparex Dongmyo / 스파렉스 동묘점)・スパレイ (Spalei / 스파레이)の3軒です。アクアフィールド ハナム (Aquafield Hanam / 아쿠아필드 하남)・スパランド センタム (Spaland Centum / 스파랜드 센텀)には時間制限(6時間・4時間)があり、夜は閉まります。
  2. 青少年といっしょに夜通しの計画を立てる — 江辺スパランド (Riverside Spa Land / 강변스파랜드)は保護者のいない19歳未満を22:00~05:00に受け入れず、スパレックス トンミョ店 (Sparex Dongmyo / 스파렉스 동묘점)は青少年の宿泊を保護者同伴のときだけ受け入れます。
  3. ナビアプリの時間だけ見てテルメデンに行く — 施設ごと・シーズンごとに時間が違い、12/1から変わります。公式サイトのその週の時間表を見てください。

⚙ FAQ 3

  1. タトゥーがあったら? — この回で開いた公式ページ・カカオマップ登録値のうち、タトゥーの規定を書いているのは虚心庁 (Hurshimchung / 허심청)の1軒だけで、入場禁止です。ほかは規定が書かれていないので、チケット売り場で先に聞いてください。
  2. 水着が必要なところは? — アクアフィールド ハナム (Aquafield Hanam / 아쿠아필드 하남)のウォーターパーク(水着素材の服)、雪岳ウォーターピア (Seorak Waterpia / 설악워터피아)(水着必須、レンタル10,000ウォン)です。
  3. 子どもと行けるところは? — 水遊びも兼ねるなら、子どもの料金が公式に出ているアクアフィールド ハナム (Aquafield Hanam / 아쿠아필드 하남)・テルメデン (Termeden / 테르메덴)・雪岳ウォーターピア (Seorak Waterpia / 설악워터피아)が合います。スパランド センタム (Spaland Centum / 스파랜드 센텀)は小学生からしか入れません。虚心庁 (Hurshimchung / 허심청)は小学生11,000ウォン(土・日・祝日12,000ウォン)、子ども(12か月~未就学)7,000ウォンが公式料金です。冬はテルメデンのウォータープレイゾーン・キッズスライダー(3/1までシーズン終了)と、雪岳ウォーターピアの屋外の遊び場の一部が休みなので、屋内・温泉中心で組みます。
