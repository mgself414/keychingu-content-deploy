ソウル10月キャラクターポップアップ・展示カレンダー2026 — クレヨンしんちゃん・ポケモン・あたしンち・HUNTER×HUNTER、終了日順10選

サブタイトル: 2026年10月にソウルで実際に開催されるキャラクターポップアップ・体験型展示9件と常設グッズスポット2件を終了日順に — ポケモン30周年ハイカーグラウンド(~10/11)・あたしンち(~10/18)・HUNTER×HUNTERコラボカフェ(~10/18)・クレヨンしんちゃん体験展(10/17開幕~2027/1/24)。ヨンサン・アイパークモール一棟と地下鉄2号線(ホンデ→コンデ→ソンス)一本でほぼ全部つながる

🎯 なぜ「10月キャラクターポップアップカレンダー」なのか

ソウルのキャラクターグッズ店自体には常設ガイド(#1350 キャラクターグッズ店ツアー)があります。ところがポップアップは性格が違います — 2~4週間だけ開いて消えます。 2026年10月は特に日本・中華圏のファン層が厚いIPが一気に重なります — ポケモン30周年メガフェスタ、トゥーニバース世代のあたしンち、HUNTER×HUNTERコラボカフェ、そして海外で先に話題になったクレヨンしんちゃん体験型展示の国内初開幕。外国人旅行者にとって問いは「どこがキャラクターの聖地か」ではなく、「自分がソウルにいるその週にどのポップアップが開催中か」です。

この回はその問いだけに答えます — 日付・場所・営業時間・予約方法だけを表に落とし込みます。ソウルのインスタローカルアカウントが9月下旬に一斉に上げたポップアップ告知を集めた後、公式チャンネル・報道で相互確認しました。

⚠ 有効期間: 2026年10月限定のカレンダーです。日程は2026-09-29確認基準で、ポップアップは早期終了・延長が頻繁にあります。「Instagram告知ベース」と表記した項目は運営会社の公式チャンネルや報道で確認できず、Instagramの告知のみに基づいています — 訪問前に該当アカウントの最新告知を確認してください。「未確認」は公式情報がなく現地確認が必要な値です。

🅰 10月11日より前に終わるもの — ポケモン・TWIMI・ハリー・ポッター・サンリオ文房具・タイニービル

  • ポケモン「ピカチュウの秋のお出かけ」(~10/11): ポケモンコリア・韓国観光公社・空港鉄道が共同で開く30周年メガフェスタ。会場のハイカーグラウンド (HiKR Ground / 하이커그라운드)は韓国観光公社が運営する外国人観光客向け複合スペース(チョンゲチョン (Cheonggyecheon / 청계천)のすぐ前)で、このリストの中で外国人の動線に最も合っています。1~3階はメディアアート・体験展示、5階がポップアップストアでハンボク姿のピカチュウグッズやガチャガチャを販売します。期間中はポケモンGOでオレンジ色のハンボクピカチュウを捕まえられ、Pokémon HOME訪問記念メダルは現地NFCスキャン(1日1回)。空港鉄道(AREX)にはポケモンラッピング列車が走っています — 空港ターミナル内に別途展示場が立つという根拠はないため、メイン会場はハイカーグラウンド一箇所と考えればよいです。
  • TWIMIポップアップ (~10/4): TWS公式キャラクターの森の宝探しコンセプトポップアップ、ソンス (Seongsu / 성수)のP&Rソンス。予約はWeverse — 海外のK-popファンが既に使っているグローバルアプリなのでネイバー予約より外国人のアクセスが良いです(韓国の電話番号が必要かは未確認)。10月第1週にソウルにいるファンのみ該当します。
  • 魔法処(ハリー・ポッター)ポップアップ (~10/11): ヨンサン・アイパークモール (Yongsan I'Park Mall / 용산 아이파크몰) リビングパーク3階ドーパミンステーション。同じ階にちいかわショップがあり一度に二か所回れます(下記🅳)。
  • サンリオキャラクターズ文房具 (~10/11、Instagram告知ベース): ホンデ (Hongdae / 홍대)のAKプラザ2階、ダイアリー・ステッカー中心の文房具ポップアップ。告知上入場時に実物の身分証を確認します — 外国人はパスポートを持参してください(パスポートが認められるかは未確認、同じ建物4階の9月ポップアップも身分証必須でした)。
  • タイニービル (~10/11、Instagram告知ベース): 新世界江南店地下1階デザートホール「スイートパーク」内のキャラクター雑貨ポップアップ(スポンジ・ボブのクリッカーなど、ヒットガチャ・くじ引き機)。高速ターミナル駅直結でカンナムのショッピング動線に組み込みやすいですが、運営会社の公式チャンネルでは確認できていません — 行く前にInstagram告知を確認してください。

🅱 10月第3~4週まで — あたしンち・HUNTER×HUNTER・ウサハナ

  • あたしンち (~10/18): ホンデのKT&Gサンサンマダン デザインスクエア2階。アニメの中のあたしンちのリビングをまるごと再現しており、ダイアリー・メガネスタンド・キーリングなどの生活雑貨グッズが中心です。日本原作(あたしンち)なので日本人旅行者にも嬉しいIPです。週末(土・日)16~18時限定でクジ(くじ引き)を1回2,300ウォン・1日200名限定で販売します(Instagram告知ベース) — クジが目当てなら週末午後に合わせてください。11~21時と遅くまで開いています。
  • HUNTER×HUNTERポップアップ&コラボカフェ (~10/18): コンデイック (Konkuk Univ. Station / 건대입구)のロッテシネマ3階Vスクエア。キャラクターテーブルで能力名を付けたコラボメニューを食べるカフェ+グッズゾーン。オープン初期はネイバー予約者優先で、その後ウォークインに切り替わる方式なので、10月第2週以降は現地入場できる可能性が高いです(切り替え時期は未確認)。今年の春にハプジョン・プサンで開催されたアニプラスコラボとは別のイベントなので、古い情報と混同しないでください。
  • ウサハナ (Usahana / 우사하나) 初の単独ポップアップ (~10/27、Instagram告知ベース): サンリオキャラクター「ウサハナ」の国内初の単独ポップアップ、ヨンサン・アイパークモール リビングパーク6階(キャラクターポップアップが入れ替わる階)。ローカルアカウント3か所が同じ日程・時間を告知していますが、サンリオ公式チャンネルでの確認はできていません。ネイバー事前予約制 — 予約が取れなければ平日午前の現地待機を試してください。

🅲 10月17日開幕 — クレヨンしんちゃん体験展は冬まで

  • クレヨンしんちゃん! 遊ぼう! 時空間大冒険 (10/17~2027/1/24): 海外巡回で先に話題になったクレヨンしんちゃんのインタラクティブ体験展の国内初開幕、ソンスのヨンムジャン5キル。見るだけの展示ではなく、ミニゲーム・体験型の構成です。予約は制作会社独自プラットフォームのbemillが基本で、第1次アーリーバード(9/28~10/2、20%割引)・第2次(10/3~10/6、10%割引)があります — 一般価格は23,000ウォンと告知されています(Instagram基準)。外国人にとって重要な点は、KKdayにもチケット商品が出ており海外カードで予約できる道があることです(価格・言語は未確認)。冬まで開催するので10月17日より前の旅行者だけが見逃します。番地は投稿ごとに異なるため(9-13 / 9-29)、訪問前に予約ページの住所を確認してください。

🅳 常設 — ヨンサン・アイパークモール一棟、そして国際電子センター

  • ヨンサン・アイパークモール リビングパーク: 今回の10月カレンダーで最も効率の良い一棟です。3階ドーパミンステーションに公式ちいかわショップ ヨンサン店(2026年2月オープン、常設)とハリー・ポッター魔法処ポップアップ(~10/11)、6階にウサハナポップアップ(~10/27)と常設マーベルストア。ヨンサン駅直結でKTX・空港鉄道の乗り換え前後1~2時間で回れます。ドーパミンステーションは22時まで開いています。
  • 国際電子センター (Gukje Jeonja Center / 국제전자센터) (ソチョ、ナムブトミナル (Nambu Terminal / 남부터미널)): ちいかわ劇場版公開以降、ローカルファンが「討伐マップ」を作るほど2~9階の各所にちいかわのぬいぐるみ・グッズ・ガチャ店が点在するフィギュア・ガチャ商店街。公式店舗ではなく複数の店の集合体なので、公式ショップにない在庫を探す場所です。10~20時、毎月第1・3日曜休み(Instagram告知ベース) — 日曜日に行くなら日付から確認してください。

🗓 二日間コース — ヨンサン一棟+2号線一本

Day 1・ヨンサン → チョンゲチョン: 午前ヨンサン・アイパークモール(3階ちいかわショップ・ハリー・ポッター → 6階ウサハナ・マーベル) → 1号線でチョンガク (Jonggak / 종각)駅へ → 午後ハイカーグラウンドのポケモン(~10/11) → チョンゲチョン散策。10/11以降ならハイカーグラウンドの代わりにナムブトミナルの国際電子センター(3号線)に変えます。

Day 2・2号線 ホンデ → コンデ → ソンス: 午前ホンデ サンサンマダンのあたしンち(11時オープン)+AKプラザのサンリオ文房具(~10/11) → 2号線一本でコンデイックのHUNTER×HUNTERコラボカフェでランチ → さらに二駅先のソンスでTWIMI(~10/4)またはクレヨンしんちゃん体験展(10/17~)。3つとも2号線上なので乗り換えがありません。

週末クジの切り替え: あたしンちのクジは土・日16~18時限定で販売します — 週末ならDay 2の順番を逆にしてソンス・コンデを先に回り、16時にホンデに入ります。

⚠ よくある失敗3つ

1. 9月の投稿を信じて訪ねる — チャムシルのレベルツーキッザルトポップアップ(~9/30)・ホンデのイヌヤシャポップアップ(~9/22)はすでに終了しています。ポップアップは保存しておいた投稿より終了日が優先します。この表も終了日順で見てください。

2. ネイバー予約が当然できると思い込む — ウサハナ・サンリオ文房具はネイバー事前予約中心なので、韓国の携帯番号がないと詰まる可能性があります。予約チャネルがWeverse(TWIMI)・KKday(クレヨンしんちゃん)の場所、自由入場の場所(ちいかわショップ・国際電子センター・ハイカーグラウンド5階ポップアップ)を先に組み込むとリスクが減ります。

3. 身分証を持たずに行く — AKプラザホンデのポップアップは実物身分証確認が告知されています。スマホの中のパスポート写真ではなく、実物のパスポートを持って行ってください。

⚙ FAQ3つ

1. 一つだけ選ぶなら? — 10/11より前ならハイカーグラウンドのポケモン: 外国人観光客向けの空間で、入場料の言及がなく、ポケモンGO限定のハンボクピカチュウまで押さえられます。10/11以降ならヨンサン・アイパークモール(ちいかわショップ+ウサハナ+マーベル、一棟)。

2. 韓国の電話番号なしで予約できる場所は? — TWIMIはWeverse、クレヨンしんちゃん体験展はKKdayに商品があります。HUNTER×HUNTERカフェは初期予約期間が過ぎればウォークイン。残りのネイバー予約ポップアップは平日午前の現地待機が現実的な代案です。

3. 何時に行けば混雑が少ないですか? — ポップアップは週末のオープン時間に列が最も長くなります。アイパークモールのドーパミンステーション(22時まで)・あたしンち(21時まで)は平日の夕方が余裕があります。
