🎯 本指南使用方法

全州之旅的中心是韩屋村（24小时开放），庆基殿、殿洞圣堂、梧木台、乡校、南部市场都可以步行到达。下文的时间、票价、地址只收录2026-10-08在全州市文化观光（tour.jeonju.go.kr）和韩屋村官方（hanok.jeonju.go.kr）页面上确认过的数值，官方没有的票价和时间一律写作“未公布”。拌饭店只收录全州市官方拌饭页面上列出的8家，不标注价格。旧版指南中的“700+栋韩屋”“访韩外国人8%”“KTX 1.5小时”“丰南门·丰沛之馆合并介绍”“1339医疗热线”等内容与官方不符，已删除（1339是传染病咨询电话，旅游翻译服务请拨1330）。

🏘 韩屋村——24小时开放，车停在村外

  • 官方称全年24小时开放。公营停车场6处：第1~3停车场30分钟1,200韩元（每增加15分钟600韩元，每日最高14,400韩元），第4停车场和国立无形遗产院平面停车场免费（官方）。第4停车场 ↔ 太祖路站 (Taejo-ro / 태조로역)（途经慈满壁画村 (Jaman Byeokhwa Maeul / 자만벽화마을)）有免费接驳车，工作日 10:00~18:30。
  • 游客咨询中心4处 09:00~18:00（午间休息），提供翻译和行李寄存。官方菜单中有韩服体验，但商家和价格未公布。
  • 夜晚可以逛亮灯的小巷，也可以看梧木台的傍晚景观。咨询中心和圣堂在17~18点关门，建议白天游览，晚上散步。

🏛 庆基殿·殿洞圣堂·梧木台——步行一圈

  • 庆基殿 (Gyeonggijeon / 경기전)（太祖御真）：按季节 09:00~18~20:00，成人3,000韩元，最后一个周三免费·最后一个周六半价（官方）。太祖路44。
  • 殿洞圣堂 (Jeondong Seongdang / 전동성당)：过条马路就到。09:00~17:00（正殿安排有变动），1908~1914年建成（官方）。弥撒期间是否限制参观未公布。
  • 梧木台·梨木台 (Omokdae·Imokdae / 오목대·이목대)：麒麟大路55，傍晚景观名所（官方）——旧版指南中的“观景台”说法官方并无记载。
  • 全州乡校 (Jeonju Hyanggyo / 전주향교)：3~10月 09~18点，11~2月 10~17点，周一休馆。

🍚 拌饭·豆芽汤饭——官方页面上的店家

  • 全州市官方拌饭页面：食材30种以上，列出的店家为 甲基会馆 (Gapgi Hoegwan / 갑기회관)、古宫 (Gogung / 고궁)、家族会馆 (Gajok Hoegwan / 가족회관)、瓦 (Giwa / 기와)、花墙家 (Kkotdamjip / 꽃담집)、成美堂 (Seongmidang / 성미당)、韩国家 (Hangukjip / 한국집)、白松会馆 (Baeksong Hoegwan / 백송회관) 共8家（价格未公布）。旧版指南中的王伊家（Waengi-jip）、三百家（Sambaek-jip）不在官方页面上。
  • 豆芽汤饭 (Kongnamul-gukbap / 콩나물국밥)（反复浇汤式）和血肠在南部市场一带（#642）。

🎎 韩纸·传统文化——稍远的两处

  • 全州韩纸博物馆 (Jeonju Hanji Bangmulgwan / 전주한지박물관)（八福路59）：09:00~17:00，周日·周一·公休日休馆，免费（含体验）。离韩屋村较远，需乘出租车或公交。
  • 韩国传统文化殿堂 (Hanguk Jeontong Munhwa Jeondang / 한국전통문화전당)（玄武1路20）：距韩屋村步行5分钟（官方）。时间·体验费未公布。

🚄 交通

  • KTX 龙山 → 全州站 (Jeonju / 전주역) 约1小时40分钟（全州市官方；比起首尔站，建议从龙山站 (Yongsan / 용산역)出发）。
  • 全州站 → 韩屋村的公交车号和时间官方未公布——请用地图App搜索“全州韩屋村”。
  • 旅游翻译热线 1330。可乘第4停车场免费接驳车（工作日）到太祖路站。

📅 今年的节庆已经结束

  • 全州国际电影节 2026年4/29~5/8 · 全州世界声音节 2026年8/12~16——均已结束。2027年日程请于上半年到官方确认。

⚠ 常见失误5条

1. 从首尔站坐KTX——从龙山站出发更好（官方）。

2. 周一去乡校·韩纸博物馆——两处都休馆（韩纸博物馆周日也休馆）。

3. 不知道庆基殿票价而错过——最后一个周三免费。

4. 把丰南门和丰沛之馆当成一个地方——是两处不同的地方。丰南门在南部市场旁边。

5. 拨打1339——那是传染病咨询电话。旅游咨询请拨1330。

⚙ FAQ 6

1. 只有一天怎么玩？——上午庆基殿·殿洞圣堂 → 中午拌饭（官方8家）→ 下午韩屋村·梧木台 → 晚上南部市场（周五·周六有夜市）。

2. 自驾怎么办？——停第4停车场免费 + 工作日免费接驳车。

3. 韩服怎么租？——官方菜单里只有体验项目，价格和商家未公布。请到咨询中心询问。

4. 行李怎么办？——游客咨询中心提供行李寄存（官方）。

5. 晚上看什么？——梧木台傍晚景观、韩屋村小巷、周五·周六夜市。

6. 英语能沟通吗？——游客咨询中心有翻译（官方）+ 1330。
