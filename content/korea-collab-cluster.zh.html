🎯 本指南的使用方法

走出圣水站 (Seongsu-yeok / 성수역) 4号出口，被偶像面孔包裹的粉色建筑前排着长队 — 这是VisitSeoul描绘的圣水快闪店风景(VisitSeoul圣水潮流文章)。偶像·电视剧·角色与品牌携手的联名商品，几周内就出现又消失。所以本指南不列现在在售的商品清单，而是整理常年摆放联名的门店、快闪店轮换的空间、率先公布新品的官方渠道。

如果想了解哪个品牌和哪位偶像合作，这类案例本身请看外国人韩国品牌联名深度探索。这篇文章讲的是在首尔寻找并购买这些商品。

🎤 K-pop周边与联名 — 3家常设门店

  • 光野@首尔 (KWANGYA@SEOUL / 광야@서울) — 首尔城东区往十里路83-21 (Wangsimni-ro / 왕십리로 83-21) 地下1层。距水仁盆唐线首尔林站 (Seoulsup-yeok / 서울숲역) 5号出口73m。每天10:30~20:00，春节·中秋休息(Instagram公告)。免费入场。电话+82-2-6233-6729(VisitSeoul)。VisitSeoul介绍它是“K-POP粉丝与艺人见面的文化体验空间”，有媒体区·AR留言簿·四格照片相框。网站语言为韩语(VisitSeoul)
  • K-POP广场弘大 (K-Pop Square Hongdae / 케이팝 스퀘어 홍대) — 首尔麻浦区杨花路141号 (Yanghwa-ro / 양화로 141)。距2号线·机场铁路·京义中央线弘大入口站 (Hongik Univ. Station / 홍대입구역) 1号出口145m。每天11:00~22:00。电话+82-2-322-9631(VisitSeoul)。在原LINE FRIENDS弘大旗舰店的位置重新开业，摆出艺人快闪·展览和限定周边(VisitSeoul)
  • Ktown4u COEX (Ktown4u COEX / 케이타운포유 코엑스) — 首尔江南区永东大路513号 (Yeongdong-daero / 영동대로 513) COEX 2~4层。距2号线三成站 (Samseong-yeok / 삼성역) 6号出口162m。免费入场(VisitSeoul)
  • 2层SQUARE：出售最新K-pop专辑·周边·杂志以及美妆·时尚商品的常设门店，11:00~20:00
  • 3层Academy：K-pop舞蹈·声乐一日课程，12:00~22:00。仅限学员·咨询顾客进入
  • 4层SPACE：举办艺人回归活动等主题快闪的空间，11:00~20:00
  • 提供外语服务，网站有韩·英·日·中(简体·繁体)·俄·马来语(VisitSeoul)

💄 美妆联名 — Olive Young两处

  • Olive Young明洞旗舰店 (Olive Young Myeongdong Flagship / 올리브영 명동 플래그십) — 首尔中区明洞街53号 (Myeongdong-gil / 명동길 53)。距4号线明洞站 (Myeongdong-yeok / 명동역) 8号出口356m。每天10:00~22:30。电话1577-4887(VisitSeoul)。VisitSeoul介绍它是韩国最大的美妆门店，并写道门店分为14个主题区。香水吧·美容护理·身体护理区很受欢迎(VisitSeoul)

📣 快闪店和新品在哪里最先出现

  • 空间的官方渠道：光野@首尔 (KWANGYA@SEOUL / 광야@서울) 通过Instagram公布休息日(VisitSeoul)。像K-POP广场弘大 (K-Pop Square Hongdae / 케이팝 스퀘어 홍대)、Ktown4u COEX (Ktown4u COEX / 케이타운포유 코엑스) 4层这样快闪轮换的地方，请到各门店官方渠道查看下一次日程
  • 经纪公司官方线上商店：Weverse Shop (Weverse Shop / 위버스숍) 自称“面向全球粉丝的官方周边商店”，出售艺人官方粉丝俱乐部会员资格和Weverse Shop独家商品。部分商品由第三方卖家销售，WEVERSE COMPANY只负责中介(Weverse Shop官方)。支持语言·配送地区在主页上没有确认到

⚠ 常见的4个错误

1. “经纪公司空间门票很贵” — 光野@首尔和Ktown4u COEX免费入场(VisitSeoul)

2. “LINE FRIENDS弘大门店” — 那个位置已经换成了K-POP广场弘大 (K-Pop Square Hongdae / 케이팝 스퀘어 홍대)(VisitSeoul)

3. “明洞的Olive Young不开到很晚” — 明洞旗舰店每天开到22:30(VisitSeoul)

4. “照着博客上看到的联名商品去找” — 联名商品是限定期间的，文章发出来时往往已经结束。请到常设门店和官方渠道确认现在正在摆的商品
