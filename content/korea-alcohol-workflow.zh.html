🍶 烧酒+啤酒的制作礼仪

小麦的定义和比例

  • Somaek=烧酒+啤酒=韩国公司晚宴#1经典博览会
  • 标准比例：1:3（1烧酒：3啤酒）或1:2.5（烧酒比例↑）
  • 1:2 比例 = 太多烧酒 → 很快就会醉（不推荐外国人）

制作小麦的步骤

1.准备啤酒杯（350-500ml）

2. 倒入70%的啤酒（装满玻璃杯70%）

3. 准备 1 烧酒杯 (45ml)

4. 1杯烧酒 倒入啤酒中

5. 摇匀 或 用筷子轻轻搅拌

6. 干杯后喝

外国狂热秘诀

  • Somaek = Short：在30秒到1分钟内喝完（防止烧酒酒精挥发）
  • Somaek = 累积↑：1 杯 = 1.5~2 标准杯，2 杯 = 3 标准杯 = 快速醉酒
  • 拒绝强迫喝酒可以：“我不喝酒”或将玻璃杯放在手掌上

🍯 如何喝马格利酒

摇晃并倒入马格利

1. 摇匀：碗底沉淀物（酵母）+顶部透明部分=摇匀。

  • 马格利酒瓶 缓慢地上下摇动 5 至 10 次

2. 倒一杯：成人用双手倒

3. 接：成人倒酒时用双手接住玻璃杯

4. 干杯：“干杯！”或“为了！”

5. 喝酒（在大人面前）：转头喝（传统礼仪）

6. 第一杯：一口或整口（个人喜好）

马格利配对狂热

  • 泡菜煎饼+马格利酒 = 雨天#1
  • 海鲜葱饼+马格利酒 = 正宗韩国料理
  • Mungdu Pancake + Makgeolli = 正宗的Makgeolli餐厅
  • Bossam + Makgeolli = 正宗的公司晚餐
  • MZ Trend：牛奶马格利、桃子马格利、草莓马格利

🙏 七大饮酒礼仪

###韩国饮酒礼仪（传统）

1. 用双手倒酒：为成人倒酒时，请使用双手。

2. 双手接酒：大人给你倒酒时，用双手接酒杯。

3. 转头喝：把头转向一边，在大人面前喝（传统）

4. 清空玻璃杯：供成人倒出的玻璃杯 = 建议清空（现代 = 必需

5. 敬酒时：酒杯位置=略低于成人（传统）

6. 不要给自己倒杯子：让别人帮你倒

7. 第一杯=成人优先：成人先倒，然后是你。

拒绝胁迫的礼仪（现代）

  • “我不喝酒” = 直接拒绝 OK
  • “仅喝一杯” = 尝试喝 1 杯后被拒绝
  • 将杯子放在手掌中 = 非语言拒绝信号
  • 服药 =“服药”（医疗原因）
  • 驾驶 =“我正在驾驶”（驾驶的原因）

> 现代韩国公司聚餐文化=拒绝胁迫的普遍化。拒绝并不违反礼仪。

💰 付款流程

韩国支付模式

1. 一人刷卡支付（通常是公司聚餐主持人）

2. 通过Kakao Pay/Toss转账（按参与者结算）

3. 金额=每人平均数÷N等份（均等分配）

荷兰支付商店

  • MZ Store：多个荷兰支付系统（个人支付）
  • 一般公司晚餐店：Dutch Pay
  • 便利店/咖啡馆：个人卡支付可以

⚠ 外国人常犯的7个错误

1. “烧酒 = 像伏特加一样浓烈”：烧酒 16-17%（不到伏特加 40% 的一半）。平滑但累积↑。

2. **“马格利=摇匀

3. “小麦=自由比例”：标准1:3或1:2.5。 1:2 烧酒太多了。

4. “在大人面前=从前面喝酒”：正宗的礼仪=转头喝酒。

5. “拒绝武力=违反礼仪”：现代韩国=拒绝武力可以。

6. “酒后驾驶=轻度”：0.03% BAC = 吊销驾照（韩国严厉打击）。

7. “支付方式=荷兰支付标准”：韩式=一人支付→汇款多种模式。

⚙ 8 个常见问题解答

1. 第一杯=任何爱好者：啤酒（入门）→ 马格利（传统）→ 烧酒（全球）→ Somaek（晚宴）阶段。

2. Insta·vlog：摇晃马格利酒·制作somaek·高球酒吧MZ vlog。

3. MZ趋势：水果烧酒、牛奶马格利酒、高球酒吧、低度烧酒。

4. 同伴晚餐/娱乐：烧酒、啤酒（常规）、清酒、传统酒（传统）。

5. 饮用礼仪：双手倒、接、转头饮用（在成人面前）。

6. 醉酒驾驶：0.03% BAC驾照吊销+刑事处罚。

7. 过敏：麸质（啤酒）、大豆（马格利酒、米酒）、水果（水果烧酒），需提前通知。

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/法律免责声明

韩国酒=酒精（4-45% ABV）。 醉酒驾驶0.03% BAC驾照吊销+罚款+刑事处罚。孕妇/吸毒者=禁止饮酒。 19岁以下=禁止合法饮酒。过敏（麸质、大豆、水果、坚果）需提前通知。如果怀疑食物中毒或过量饮酒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

饮酒限制（因人而异）：

  • 标准杯=14克酒精（1杯烧酒、1杯啤酒、1杯葡萄酒）
  • 外国爱好者=推荐2~3标准杯（1~2小时餐+酒精）
  • 累计↑注：1杯小麦=1.5~2标准杯

饮食限制后备：

  • 清真/犹太洁食：酒精=非清真/非犹太洁食。 → 不含酒精的选择（sikhye、sujeonggwa、不含酒精的啤酒）。
  • 无酒精：Sikhye、Sujeonggwa、菊花茶（传统）或无酒精啤酒、无酒精清州啤酒。
