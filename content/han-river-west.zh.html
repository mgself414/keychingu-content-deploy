⚠ 外国游客常犯的3个错误

1. “汉江 = 只有盘浦 (Banpo / 반포)”: 汉江 = 11个公园 (Hangang 11 Gongwon / 한강 11공원) (西部·中部·核心·东部 4个区域)。

2. “江西·兰芝 = 很远”: 江西汉江 = 毗邻金浦机场 (Gimpo Gonghang / 김포공항) (#175) 的外国游客狂热者聚集地。

3. “天空公园 = 去不了”: 天空公园 (Haneul Gongwon / 하늘공원) (兰芝) = 外国游客狂热者首选的自然风光。

⚙ 4个常见问题

1. 外国游客汉江西部首选: 江西 (Gangseo / 강서)·兰芝 (Nanji / 난지)·望远 (Mangwon / 망원)·杨花 (Yanghwa / 양화) 4个公园。

2. 外国游客骑行首选地: 望远 (Mangwon / 망원)·江西 (Gangseo / 강서) (#149)。

3. 外国游客露营·烧烤: 江西 (Gangseo / 강서)·兰芝 (Nanji / 난지) (外国游客友好)。

4. 外国游客夜景: 杨花汉江大桥。
