黄色首尔 — 银杏路散步指南，与红叶不同的11月色彩

副标题：如果说红叶(#229)属于山野，那黄色银杏就属于城市 — 从400年历史的成均馆银杏树 (Sungkyunkwan Ginkgo / 성균관 은행나무) 到德寿宫石墙路 (Deoksugung Stone Wall Road / 덕수궁 돌담길)、街道树路 (Garosu-gil / 가로수길) 等6处名所 + 花期预测法 + 气味与落叶实战贴士 + 出行前准备清单。

ISSUE 04 · #1314 · 2026-08-20

🎯 为何把"银杏"单独拿出来讲

首尔秋天的最后一幕不是红色，而是黄色。银杏树(ginkgo)是首尔行道树的代表树种，所以不用像看红叶那样专程上山，市中心整片会直接变成一片金黄。花期比红叶更晚，在10月末~11月初 — 是错过红叶的深秋旅行者手里剩下的最后一张季节牌。

区分 红叶(#229) 银杏(本篇)
颜色 红色系 单一黄色
舞台 山野·宫廷庭院 市中心街道·行道树
花期 10月中~下旬 10月末 ~ 11月初
体力 常伴随登山 全程平地散步

① 银杏名所6处

1. 成均馆文庙银杏树 (Sungkyunkwan Ginkgo / 성균관 문묘 은행나무) — 首尔银杏之王

  • 朝鲜最高学府成均馆 (Sungkyunkwan / 성균관) 明伦堂 (Myeongnyundang / 명륜당) 前的树龄400年以上、被指定为天然纪念物 (Natural Monument / 천연기념물, 韩国官方认定的遗产树木保护制度) 的巨树。全树染黄那一刻的规模，压倒首尔其他所有银杏。
  • 惠化站 (Hyehwa Station / 혜화역) 步行10分钟。可与大学路 (Daehangno / 대학로)·骆山公园 (Naksan Park / 낙산공원, #1308) 组成半日游路线。花期周末拍照人潮多 — 平日上午是正解。

2. 德寿宫石墙路 (Deoksugung Stone Wall Road / 덕수궁 돌담길)·贞洞路 (Jeongdong-gil / 정동길) — 最具首尔气质的黄色小路

  • 宫墙+银杏行道树的组合。市厅站 (City Hall Station / 시청역) 直达 — 可达性第一。如果行程正好赶上落叶不清扫的时段(往年落叶节惯例)，连脚下都是一片金黄。
  • 与近代建筑(贞洞教堂 (Jeongdong Church / 정동교회)·旧俄罗斯公使馆 (Former Russian Legation / 구 러시아공사관) 方向)结合的历史散步路线。

3. 新沙洞街道树路 (Garosu-gil / 신사동 가로수길) — 名字本身就是"银杏行道树"

  • 街道树路(Garosu-gil，意为"林荫大道")的那些行道树正是银杏树。购物商圈与金黄隧道的组合 — 11月初下午是最高潮。

4. 三清洞路 (Samcheong-dong-gil / 삼청동길)·感古堂路 (Gamgodang-gil / 감고당길) — 画廊与银杏

  • 沿景福宫 (Gyeongbokgung / 경복궁) 东侧宫墙，画廊·咖啡馆小巷里连绵着银杏。自然衔接北村 (Bukchon / 북촌, #38) 行程的路线。

5. 松坡奥林匹克公园 (Songpa Olympic Park / 송파 올림픽공원) 外围 + 石村湖 (Seokchon Lake / 석촌호수)，蚕室 (Jamsil / 잠실) — 东南首尔选项

  • 继芒草季(粉黛乱子草)之后，深秋时节湖边会出现一圈金黄小路 — 可与蚕室行程连接。

6. 杨平龙门寺银杏树 (Yongmunsa Ginkgo / 양평 용문사 은행나무) — 近郊远征的巅峰

  • 树龄约1,100年，东亚最大级银杏树(天然纪念物)。搭京义中央线 (Gyeongui-Jungang Line / 경의중앙선) 可当天往返 — 与加平 (Gapyeong / 가평)·杨平 (Yangpyeong / 양평) 一日游指南#739结合，一天行程就完整了。
  • 11月初高潮周，会有人从全国各地专程来看这一棵银杏树 — 它值得这份专程。

+7. 西村·景福宫石墙扩展路线 — 本地账号的实走顺序

北村本地向导账号每年秋天实地打卡发布的景福宫西侧石墙银杏路线。是比上面6处名所名单更深一层的加分路线(全程免费·平地)。

  • 国立古宫博物馆 (National Palace Museum of Korea / 국립고궁박물관) 银杏休息区(孝子路12 / 효자로 12)— 紧邻景福宫西侧入口，带长椅的银杏树荫。夏天是休息区，秋天变身黄色打卡点。
  • 通义洞村庄广场 (Tongui-dong Village Square / 통의동 마을마당)(通义洞7-3 / 통의동 7-3)— 藏在西村小巷里的小空地银杏树。几乎没有游客。
  • 紫霞门路6街 (Jahamun-ro 6-gil / 자하문로6길)·西村石墙路 — 沿景福宫西墙走的银杏+石墙组合。接上青瓦台路 (Cheongwadae-ro / 청와대로)、望向神武门 (Sinmumun / 신무문)，就是西村半日行程。
  • 尹潽善路 (Yun Posun-gil / 윤보선길)·开放松岘绿地广场 (Songhyeon Green Plaza / 열린송현 녹지광장) — 从感古堂路(6处名所第4处)自然延伸的扩展路段。
  • 白麟济家屋 (Baek In-je House / 백인제가옥)(北村)— 韩屋庭院里的红叶+银杏组合。本地账号反响最热烈的北村秋景画面。

② 花期预测法 — 银杏比红叶更敏感

  • 首尔市中心银杏花期大致在10月最后一周~11月第一周。不过每年都会浮动几天 — 出发前在Instagram上查#은행나무最新标签，是最准确的实时情报。
  • 一场雨就能结束 — 盛期的金黄叶片一场强风强雨就会落尽。花期周若有降雨预报，下雨前一天就当作今年的最后一天来安排行程。
  • 落叶后1~2天的黄色地毯本身也是绝景 — 别因为"来晚了"就放弃。

🧳 出行前准备清单

  • [ ] 确认出行周 — 是否落在10月末~11月初这个窗口内。太早改看芒草季，太晚改看首波灯光节
  • [ ] 预留上午时段 — 成均馆·德寿宫平日上午人流最少
  • [ ] 做好气味心理准备 — 银杏果(雌株)踩到味道很重。落果路段要留意脚下 — 回住处前先检查鞋底
  • [ ] 打开天气App提醒 — 花期周出现降雨预报 = 提前行程的信号
