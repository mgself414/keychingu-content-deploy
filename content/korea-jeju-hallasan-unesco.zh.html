汉拿山探访路7条 — 各路线的距离和时间、各季节入山截止、登顶预约、乘公交车去的方法

副标题: 为第一次走汉拿山的旅行者，把7条探访路整理在一起。分别是城板岳、观音寺、御里牧、灵室、顿乃克、御乘生岳、石窟庵。去山顶白鹿潭的路只有城板岳和观音寺两条，这两条路线的登顶区间需要预约。10~3月，城板岳和观音寺要在11:30之前通过入口，御里牧和灵室要在12:00之前通过管制所，顿乃克要在10:00之前通过。预约时要选择入山时间段(05:00~08:00，08:01~11:30)。入山从05:00开始。下个月的预约在每月第一个工作日09:00开放。去城板岳，从济州巴士客运站乘281路，从济州国际机场乘急行181路。去御里牧和灵室乘240路。想走短一点的路，御乘生岳是1.3km，单程约30分钟。数值是2026-11-25查阅到的。

🎯 适合谁，为什么是这7条

这一篇面向想在济州岛走一天汉拿山的外国旅行者。即使不懂韩语，也能在出发前对好路线、时刻、预约和公交车。

汉拿山不是由国立公园公团 (Korea National Park Service / 국립공원공단) 管理，而是由济州特别自治道 (Jeju Special Self-Governing Province / 제주특별자치도) 管理。所以预约官网和入山时间表都是单独的。探访路有7条。

  • 去山顶(白鹿潭 (Baengnokdam / 백록담))的路: 城板岳 (Seongpanak / 성판악)、观音寺 (Gwaneumsa / 관음사)。登顶区间需要预约。
  • 去威势岳 (Witse Oreum / 윗세오름) 和南壁分岔点 (Nambyeok Junction / 남벽분기점) 的路: 御里牧 (Eorimok / 어리목)、灵室 (Yeongsil / 영실)。无需预约即可走。
  • 去南壁分岔点的路: 顿乃克 (Donnaeko / 돈내코)。无需预约即可走。
  • 1小时以内走完的短路: 御乘生岳 (Eoseungsaengak / 어승생악)、石窟庵 (Seokguram / 석굴암)。无需预约即可走。

汉拿山不是什么时候都能进。每条探访路都有必须通过入口的时刻，也有必须开始下山的时刻。冬季这些时刻会提前。所以这一篇对每条路线都先写"要在几点之前通过入口"。

⚠ 标注原则: 距离、时间、管制时刻、票价、交通方式是2026-11-25查阅到的值。出处是济州特别自治道汉拿山探访预约官网 (Hallasan Trail Reservation Website / 한라산 탐방 예약 누리집)(visithalla.jeju.go.kr)和济州特别自治道汉拿山国立公园官网 (Hallasan National Park Website / 한라산국립공원 누리집)(jeju.go.kr/hallasan)。汉拿山把10~3月标为冬季，4~9月标为夏季。11月属于冬季。所以先写冬季的值，夏季的值一并放在表里。管制时刻、预约规则、票价、公交车运行可能变动。

📋 先定好的3件事

1. 要不要登顶

去山顶白鹿潭的路有城板岳路线和观音寺路线两条。据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)，城板岳往返9小时，观音寺往返10小时。是要花一整天的登山。

其余5条路线去不了山顶。御里牧和灵室经过威势岳，到南壁分岔点。顿乃克也到南壁分岔点。官网把灵室写作"去不了白鹿潭(山顶)的探访路"。

如果目的不是登顶，就从灵室或御里牧走到威势岳。如果只有1小时，就走御乘生岳。这是本篇的建议。

2. 几点之前能通过入口

冬季和夏季，入山都是从05:00开始。超过下面的时刻，就不能经过那个地点继续上山。开始下山的时刻也是固定的。

3. 预约了吗

需要预约的是两个区间。城板岳路线的杜鹃花田~白鹿潭区间，和观音寺路线的三角峰~白鹿潭区间。预约时要选择入山时间段。有05:00~08:00和08:01~11:30两个时间段。要在预约的时间段内通过入口。去不了的话，在那个时间段结束之前取消。预约方法写在下面的"登顶预约方法"一节里。

汉拿山探访预约官网的英文公告(2025-05-12)写着，御里牧、灵室、顿乃克、石窟庵、御乘生岳无需预约即可开放。

① 城板岳路线 (Seongpanak Trail / 성판악 코스)

  • 有什么不同: 是去山顶的两条路之一。据济州特别自治道汉拿山国立公园官网(2026-11-25查阅)，城板岳管理办事处 (Seongpanak Management Office / 성판악 관리사무소) 位于海拔750m。
  • 距离和时间: 据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)是9.6km。到山顶单程4小时30分钟，往返9小时。到杜鹃花田单程3小时。汉拿山国立公园官网把同一条路到山顶写作5小时。
  • 难度: 探访咨询处 (Visitor Center / 탐방안내소)~Saraak泉 (Saraaksaem Spring / 사라악샘) 为C(容易)，Saraak泉~杜鹃花田为B(普通)，杜鹃花田~白鹿潭为A(困难)。
  • 路上的设施: Sokbat避难所 (Sokbat Shelter / 속밭대피소) 无人值守，杜鹃花田避难所有人值守。厕所在城板岳办事处、Sokbat避难所、杜鹃花田避难所。全程没有小卖部。沙罗岳观景台 (Sara Oreum Observatory / 사라오름전망대) 在探访路5.8km处往里走600m的地方。
  • 冬季(10~3月)管制时刻: 要在11:30之前通过探访路入口和杜鹃花田。在山顶(东陵顶峰)13:30开始下山，在杜鹃花田15:30开始下山。
  • 夏季(4~9月)管制时刻: 探访路入口和杜鹃花田到12:30。在山顶(东陵顶峰)14:30开始下山，在杜鹃花田16:30开始下山。
  • 预约时间段: 登顶区间的预约要选择入山时间段(05:00~08:00，08:01~11:30)。要在预约的时间段内通过入口。去不了的话，在那个时间段结束之前取消。
  • 公交车: 从济州巴士客运站 (Jeju Bus Terminal / 제주버스터미널) 乘281路。181路是从济州国际机场 (Jeju International Airport / 제주국제공항) 出发的急行，以机场站点为准约35分钟(汉拿山探访预约官网公告 2026-06-05)。281路从济州巴士客运站约45分钟，从西归浦巴士客运站 (Seogwipo Bus Terminal / 서귀포버스터미널) 约50分钟。首班车06:00，末班车22:00(汉拿山探访预约官网公告 2026-06-05)。地址是济州市 (Jocheon-eup 516-ro 1865 / 조천읍 516로 1865)。
  • 停车: 城板岳停车场最多156辆。可以把车停在济州国际大学 (Jeju International University / 제주국제대학교) 附近的免费换乘停车场(199辆)，再乘281路。路边停车属于取缔对象(汉拿山探访预约官网公告 2026-06-05)。
  • 几点出发: 往返9小时，冬季入口截止是11:30。281路首班车是06:00，所以05:00入山没法靠公交车赶上。乘公交车去的话，预约08:01~11:30时间段。这是本篇的建议。
  • 咨询: 城板岳支所 (Seongpanak Branch Office / 성판악지소) 064-725-9950。

② 观音寺路线 (Gwaneumsa Trail / 관음사 코스)

  • 有什么不同: 是去山顶的两条路中的另一条。比城板岳距离短，但花的时间更长。
  • 距离和时间: 据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)是8.7km。观音寺地区露营场 (Gwaneumsa Campground / 관음사지구 야영장) 到三角峰避难所是6km，三角峰避难所到山顶(东陵顶峰)是2.7km。到三角峰避难所单程3小时20分钟，到山顶单程5小时，往返10小时。
  • 冬季(10~3月)管制时刻: 要在11:30之前通过探访路入口和三角峰。在山顶(东陵顶峰)13:30开始下山，在三角峰避难所15:30开始下山。
  • 夏季(4~9月)管制时刻: 探访路入口和三角峰到12:30。在山顶(东陵顶峰)14:30开始下山，在三角峰避难所16:30开始下山。
  • 预约时间段: 登顶区间的预约要选择入山时间段(05:00~08:00，08:01~11:30)。要在预约的时间段内通过入口。去不了的话，在那个时间段结束之前取消。
  • 公交车: 据汉拿山国立公园官网(2026-11-25查阅)，在济州市市外巴士客运站 (Jeju Intercity Bus Terminal / 제주시 시외버스터미널) 乘281路，在"济州大学 (Jeju National University / 제주대학교)"下车。换乘475路，约15分钟后在"观音寺登山路入口 (Gwaneumsa Hiking Trail Entrance / 관음사 등산로 입구)"下车。地址是济州市 (Sanrokbuk-ro 588 / 산록북로 588)。
  • 露营和做饭: 在汉拿山能露营和做饭的地方是观音寺地区露营场。
  • 几点出发: 往返10小时，冬季入口截止是11:30。因为要换乘一次公交车，所以比城板岳更早离开住处。这是本篇的建议。
  • 咨询: 观音寺支所 (Gwaneumsa Branch Office / 관음사지소) 064-756-9950。

③ 御里牧路线 (Eorimok Trail / 어리목 코스)

  • 有什么不同: 是无需预约就能走到威势岳和南壁分岔点的路。去不了山顶。据济州特别自治道汉拿山国立公园官网(2026-11-25查阅)，入口海拔970m，威势岳避难所 (Witse Oreum Shelter / 윗세오름대피소) 海拔1,700m。
  • 距离和时间: 据汉拿山国立公园官网全长6.8km。御里牧到威势岳4.7km，威势岳到南壁分岔点2.1km。到威势岳2小时，到南壁分岔点单程3小时。
  • 难度: 探访咨询处~御里牧溪谷 (Eorimok Valley / 어리목계곡) 为C(容易)，御里牧溪谷~Sajebi东山 (Sajebi Dongsan / 사제비동산) 为A(困难)，Sajebi东山~万岁东山 (Manse Dongsan / 만세동산) 为B(普通)，万岁东山~威势岳避难所为C，威势岳避难所~南壁分岔点为C。
  • 路上的海拔: Sajebi东山海拔1,423m，万岁东山1,606m，南壁分岔点1,600m。
  • 路上的设施: 威势岳避难所有人值守。全程没有小卖部。入口的自动售货机卖水和饮料。厕所在御里牧广场 (Eorimok Plaza / 어리목광장) 和威势岳避难所。Sajebi泉 (Sajebisaem Spring / 사제비샘) 干旱时可能干涸。
  • 冬季(10~3月)管制时刻: 要在12:00之前通过探访路管制所。从威势岳往南壁方向要在13:00之前通过。在南壁分岔点14:00开始下山，在威势岳15:00开始下山。
  • 夏季(4~9月)管制时刻: 探访路管制所15:00，从威势岳往南壁方向14:00。在南壁分岔点15:00开始下山，在威势岳17:00开始下山。
  • 公交车: 据汉拿山国立公园官网乘240路。从济州市市外巴士客运站约35分钟，从中文路口 (Jungmun Rotary / 중문로터리) 约50分钟。在"御里牧入口 (Eorimok Entrance / 어리목 입구)"下车步行。步行时间，同一官网的交通指南画面写约10分钟，御里牧路线画面写15分钟左右。地址是济州市 (1100-ro 2070-61, Haean-dong San 220-13 / 1100로 2070-61, 해안동 산 220-13)。
  • 咨询: 汉拿山国立公园御里牧本所 (Eorimok Main Office / 어리목본소) 064-713-9950~1。

④ 灵室路线 (Yeongsil Trail / 영실 코스)

  • 有什么不同: 是去威势岳的路中，步行时间较短的一条。汉拿山探访预约官网把灵室写作"去不了白鹿潭(山顶)的探访路"。
  • 距离和时间: 据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)全长5.8km。灵室到威势岳3.7km，威势岳到南壁分岔点2.1km。到威势岳1小时30分钟，到南壁分岔点2小时30分钟。
  • 入口处还要再走一段: 灵室管理办事处 (Yeongsil Management Office / 영실관리사무소)(海拔1,000m)到灵室休息区 (Yeongsil Rest Area / 영실휴게소)(海拔1,280m)的2.4km是和车道并行的区间。官网写着，从灵室管理办事处出发单程3小时15分钟，从灵室休息区出发单程2小时30分钟。
  • 冬季(10~3月)管制时刻: 要在12:00之前通过探访路管制所。从威势岳往南壁方向要在13:00之前通过。在南壁分岔点14:00开始下山，在威势岳15:00开始下山。
  • 夏季(4~9月)管制时刻: 探访路管制所15:00，从威势岳往南壁方向14:00。在南壁分岔点15:00开始下山，在威势岳17:00开始下山。
  • 公交车: 据济州特别自治道汉拿山国立公园官网(2026-11-25查阅)乘240路。从济州市市外巴士客运站约50分钟，从中文路口约30分钟。地址是西归浦市 (Hawon-dong San 1-1 / 하원동 산 1-1)。
  • 咨询: 灵室支所 (Yeongsil Branch Office / 영실지소) 064-747-9950。

⑤ 顿乃克路线 (Donnaeko Trail / 돈내코 코스)

  • 有什么不同: 是从西归浦 (Seogwipo / 서귀포) 一侧爬向南壁分岔点的路。入山截止在7条路线中最早。冬季是10:00。
  • 距离和时间: 7km。顿乃克探访咨询处到平轨避难所 (Pyeonggwe Shelter / 평궤대피소) 5.3km，平轨避难所到南壁分岔点1.7km。所需时间，汉拿山探访预约官网写作单程约3小时30分钟，济州特别自治道汉拿山国立公园官网写作到南壁分岔点3小时50分钟。
  • 难度: 据汉拿山国立公园官网(2026-11-25查阅)，探访咨询处~平轨避难所为B(普通)，平轨避难所~南壁分岔点为B。
  • 路上的设施: 平轨避难所无人值守。全程没有小卖部和泉水。要带好饮用水。厕所在探访咨询处。
  • 冬季(10~3月)管制时刻: 要在10:00之前通过入口。
  • 夏季(4~9月)管制时刻: 要在11:00之前通过入口。
  • 公交车: 汉拿山国立公园官网写着，乘281路，在"西归浦产业科学高中前 (Seogwipo Industrial Science High School / 서귀포산업과학고등학교 앞)"下车，换乘611路或612路，在"忠魂墓地广场 (Chunghon Cemetery Plaza / 충혼묘지광장)"下车，再步行约20分钟。汉拿山探访预约官网写着，在"西归浦科学高中入口 (Seogwipo Gwahakgodeunghakgyo Entrance / 서귀포과학고등학교입구)"下车，步行约1小时。地址是西归浦市 (Sanghyo-dong San 1-2 / 상효동 산 1-2)。
  • 咨询: 顿乃克地区咨询处 (Donnaeko District Information Center / 돈내코지구안내소) 064-710-6920。

⑥ 御乘生岳路线 (Eoseungsaengak Trail / 어승생악 코스)

  • 有什么不同: 是7条路线中最短的。不去汉拿山山顶，而是登上御乘生岳山顶。
  • 距离和时间: 据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)，到御乘生岳山顶1.3km，单程约30分钟。
  • 入口: 入口在御里牧探访咨询处旁边。
  • 管制时刻: 冬季和夏季都要在17:00之前通过入口。
  • 公交车: 济州特别自治道汉拿山国立公园官网(2026-11-25查阅)介绍的是240路。
  • 什么时候走: 适合因为航班时间只剩半天的日子。走完御里牧路线下来之后，也可以接着走。这是本篇的建议。

⑦ 石窟庵路线 (Seokguram Trail / 석굴암 코스)

  • 有什么不同: 是无需预约就能走的短路。是去济州市老衡洞 (Nohyeong-dong / 노형동) 汉拿山一侧石窟庵庵堂的路。和庆州 (Gyeongju / 경주) 的石窟庵不是同一个地方。
  • 距离和时间: 据汉拿山探访预约官网的官方路线指南(2026-11-25查阅)，到石窟庵庵堂单程1.5km，50分钟。
  • 入口: 探访路从停车场开始，这个停车场要从1100公路 (1100-doro / 1100도로) 边的天王寺 (Cheonwangsa Temple / 천왕사) 入口，沿着柳杉林路走10多分钟才到。官网把这个停车场写作国立济州护国院 (National Jeju Hogukwon / 국립제주호국원) 停车场，也写作忠魂墓地停车场 (Chunghon Cemetery Parking Lot / 충혼묘지 주차장)。
  • 管制时刻: 冬季和夏季都要在17:00之前通过入口。
  • 公交车: 汉拿山国立公园官网介绍的是240路。

🎫 登顶预约方法

下面的值是济州特别自治道汉拿山探访预约官网(visithalla.jeju.go.kr)官方指南在2026-11-25的标注。

  • 预约的区间: 城板岳路线的杜鹃花田~白鹿潭区间，和观音寺路线的三角峰~白鹿潭区间。
  • 开放日: 每月第一个工作日09:00起受理下个月的使用。可以预约到下个月月底的日期。预约开放的那天，访问的人很多，要排队等候。等候期间日期可能被订满(官网公告 2026-06-05)。
  • 入山时间段: 预约时要选择入山时间段。有05:00~08:00和08:01~11:30两个时间段，要在预约的时间段内通过入口。各时间段的名额，城板岳是800人和200人，观音寺是400人和100人(汉拿山探访预约官网公告 2025-10-24，2025-12-01起施行)。取消要在预约的时间段结束之前进行。不取消又不入山的话，会在预约上受到不利处理。
  • 人数: 一次最多预约4人。每人每周预约一次。按去的日期来算。
  • 外语页面: 官网有英语、日语、中文页面。
  • 外国人本人认证: 官网公告(2020-01-23)写着，外国人在外语页面里进行SNS认证或电子邮件认证。
  • 要把预约完成: 没有完成的预约会在1天后自动取消。
  • 当天: 每个人出示1个二维码和身份证件。护照也可以当身份证件用。
  • 预约了却不去的话: 不取消又不去的话，1次3个月、2次1年内不能预约。去不了的话，在预约的时间段结束之前取消。
  • 候补预约: 没有。
  • 咨询: 汉拿山探访预约官网 064-713-9953。电话咨询是工作日09:00~17:30。

旅行日期定下来之后，先把那个月预约开放的日子记下来。这是本篇的建议。

🚫 禁止行为和冬季准备

下面是济州特别自治道汉拿山国立公园官网(2026-11-25查阅)写的内容。

  • 饮酒和吸烟: 汉拿山国立公园禁止饮酒和吸烟。
  • 露营和做饭: 只能在观音寺地区露营场进行。
  • 采集: 包括带走植物、昆虫、泥土和石头在内，破坏自然的所有行为都被禁止。
  • 道路: 只走指定的探访路。
  • 一个人登山: 官网建议，登顶时避免一个人登山，要和多人一起去。
  • 便当和火器: 据汉拿山探访预约官网的预约指南，禁止携带一次性便当和火器。紫菜包饭和汉堡可以带。
  • 不能探访的日子: 据同一份指南，春节和中秋节不能探访。
  • 小卖部: 探访路上没有小卖部。水和吃的在上山之前准备好。
  • 冬季准备物品: 官网写着，冬季要准备防寒服、冰爪、手套、热水、手电筒。要穿登山鞋。雨衣也要提前准备。
  • 因天气管制: 发布大雨、台风、大雪注意报时，探访路部分管制。发布警报时全面管制，并让山上的人下山。大风警报也是全面管制对象。因雾能见度在20m以内，或积雪超过30cm看不清路的时候，也会管制。
  • 出发当天早上: 打开汉拿山国立公园官网的"实时探访路信息"画面(jeju.go.kr/hallasan/info/info/realtime.htm)。遇到事故或紧急情况，拨打119。

⚠ 常见失误6点

  1. 没有预约就去山顶。 城板岳的杜鹃花田~白鹿潭区间和观音寺的三角峰~白鹿潭区间要预约。下个月的预约在每月第一个工作日09:00开放。要在预约时选的入山时间段(05:00~08:00，08:01~11:30)内通过入口。
  2. 冬季出发得晚。 10~3月，城板岳和观音寺要在11:30之前通过入口。御里牧和灵室是12:00，顿乃克是10:00。
  3. 想从灵室或御里牧去山顶。 这两条路线经过威势岳，只到南壁分岔点。去山顶的路只有城板岳和观音寺。
  4. 预约了却不取消、不去。 1次3个月、2次1年内不能预约。去不了的话，在预约的时间段结束之前取消。
  5. 开车去城板岳，去得晚。 城板岳停车场最多156辆。路边停车属于取缔对象。可以把车停在济州国际大学附近的免费换乘停车场(199辆)，再乘281路。
  6. 想在山上买水和吃的。 探访路上没有小卖部。顿乃克全程也没有泉水。

⚙ 7个常见问题

  1. 没有爬过山。哪里比较轻松？ — 御乘生岳是1.3km，单程约30分钟。石窟庵路线是1.5km，单程50分钟。两条路都无需预约，冬季也只要在17:00之前通过入口。想再多走一点的话，走灵室路线到威势岳要1小时30分钟。
  2. 没有租车也能去吗？ — 能去。城板岳从济州巴士客运站和西归浦巴士客运站有281路。从济州国际机场有急行181路。281路首班车是06:00。御里牧和灵室有240路。观音寺乘281路在"济州大学"换乘475路。时刻表在济州公交信息系统(bus.jeju.go.kr)上看。
  3. 只想走到威势岳的话，走哪条路线？ — 灵室和御里牧。灵室到威势岳3.7km，1小时30分钟。御里牧是4.7km，2小时。两条路线都有240路公交车。冬季要在12:00之前通过管制所，在威势岳15:00开始下山。
  4. 下雪或下雨能去吗？ — 发布大雨、台风、大雪注意报时，探访路部分管制。发布警报时全面管制。大风警报也是全面管制对象。因雾能见度在20m以内，或积雪超过30cm看不清路的时候，也会管制。出发当天早上打开汉拿山国立公园官网的实时探访路信息画面。
  5. 能拿到登上山顶的证书吗？ — 能拿到。2026-09-01起新增了在预约官网自己申请并以PDF领取的方法。在山顶输入预约号码并上传照片，然后在预约查询里点"登顶证书 (Summit Certificate / 등정인증서)"。原来在入口无人终端机领取的方法也可以用。无论哪种方法，都要在探访的当天申请，当天领取(官网公告 2026-08-27)。
  6. 停车费是多少？ — 小型车最初1小时1,000韩元，之后每20分钟500韩元，一天最高13,000韩元。中·大型车是2,000韩元、800韩元、最高20,000韩元。
  7. 怎么预约登顶？ — 在汉拿山探访预约官网进行。每月第一个工作日09:00开放下个月的使用。预约时要选择入山时间段(05:00~08:00，08:01~11:30)。要在预约的时间段内通过入口。去不了的话，在那个时间段结束之前取消。
