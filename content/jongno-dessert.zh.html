⚠ 外国游客常犯的3个错误

1. 以为钟路·北村只有宫殿 + 韩屋村，跳过咖啡馆·甜品

外国游客行程中最常见的失误。游完景福宫 (Gyeongbokgung)·昌德宫 (Changdeokgung)·北村韩屋村 (Bukchon Hanok Village) 后，去江南 (Gangnam) 或弘大 (Hongdae) 找咖啡馆。实际上钟路·北村才是韩国画廊咖啡馆·老字号面包店的大本营 — 国立现代美术馆 (National Museum of Modern and Contemporary Art)·画廊现代 (Gallery Hyundai)·蓝瓶三清等「艺术 + 咖啡」组合是钟路区独有的特色。

2. 把三清洞·益善洞·西村当成同一个地方

三处都有韩屋氛围，但风格截然不同：三清洞 (Samcheong-dong) (北村韩屋村 + 美术馆 + 全球咖啡品牌)≠ 益善洞 (Ikseondong) (MZ世代韩屋胡同 + 新兴咖啡馆·酒吧)≠ 西村 (Seochon) (景福宫西侧 + 60年老字号·传统)。要规划完整路线，必须区分各子区域的风格。建议按时段分开安排，不要强行并入同一动线。

3. 忽略面包店·甜品店11:00~19:00的营业时限

钟路区大部分甜品·面包店营业至19:00或20:00 (连锁咖啡馆除外)。安排晚间行程的外国游客最容易错过。尤其是西村·三清洞老字号面包店 (西村金赏可乐饼 (Seochon Geumsang Croquette)·皇后面包坊三清 (Queen's Bakery Samcheong))下午就可能售罄。建议上午至下午15:00之间前往。

钟路·北村甜品风景 — 美术馆 + 韩屋 + 老字号

钟路区是韩国画廊·美术馆 + 咖啡馆融合文化的发源地。国立现代美术馆 (National Museum of Modern and Contemporary Art, 三清)·画廊现代 (Gallery Hyundai, 三清)·学古斋 (Hakgojae, 三清)·PKM画廊 (PKM Gallery) 等韩国当代艺术重镇密集分布于三清·北村一带 — 在其内部或周边，泰拉罗萨国立现代 (Terarosa MMCA)·蓝瓶三清 (Blue Bottle Samcheong)·苏妍画廊咖啡馆 (Gallery Soyeon Cafe) 等画廊 + 咖啡馆结合型店铺应运而生，是外国游客美术馆·画廊游览 + 咖啡体验路线的核心动线。

此外，钟路区也是韩国老字号 (老字号，30年以上传统店铺) 面包店的聚集地。西村紫霞门路 (Jahamun-ro) 的西村金赏可乐饼 (Seochon Geumsang Croquette) (★4.85)位居钟路区面包店评分榜首。三清洞·益善洞·钟阁的街坊面包店·甜品店在外国游客中的知名度也与日俱增。T6.6板块分析显示，画廊咖啡馆·钟路 + 面包店·钟路 + 咖啡馆·钟路合计需求达1,200分 — 仅次于弘大 (Hongdae)，是外国游客咖啡·甜品需求第二强的区域。

① 美术馆·画廊咖啡馆 (2家)

1. 泰拉罗萨国立现代美术馆首尔店 (Terarosa MMCA Seoul / 테라로사 국립현대미술관서울점)

  • 地址: 首尔市钟路区三清路 (Samcheong-ro / 삼청로) 30号，国立现代美术馆内
  • 招牌: 韩国第三波精品咖啡品牌 (江原道江陵 (Gangneung) 总店)+ 国立现代美术馆内驻场咖啡馆
  • 外国游客友好度: ★★★★☆ — 随美术馆参观自然动线，提供英语菜单
  • 推荐菜单: 手冲精品咖啡、招牌拿铁
  • 贴士: 无需购买美术馆门票，可单独使用咖啡馆。推荐工作日上午前往 (周末美术馆人流密集)。

2. 苏妍画廊咖啡馆 (Gallery Soyeon Cafe / 갤러리소연카페) ★4.58

  • 地址: 首尔市钟路区西巡罗街 (Seosunaragi / 서순라길) 149号
  • 招牌: 钟路西巡罗街画廊空间 + 咖啡馆融合。钟路区画廊咖啡馆评分最高。
  • 外国游客友好度: ★★★☆☆ — 以韩语为主，但画廊 + 咖啡馆概念直观易懂
  • 推荐菜单: 招牌饮品 + 同步欣赏画廊展览
  • 贴士: 西巡罗街 (Seosunaragi) 位于钟路区外围胡同，游览益善洞·钟路后作散步路线很合适。画廊展览不定期举办 — 建议提前查看Instagram确认。

② 韩屋·胡同咖啡馆·面包店 (2家)

3. 阿宫面包坊 (Bakery Agung / 베이커리 아궁)

  • 地址: 首尔市钟路区邮政局路 (Ujeonguk-ro / 우정국로) 6号

  • 贴士: 距钟阁站 (Jongak Station) 步行5分钟。午餐后作甜品搭配很合适。店内空间较小 — 建议外带。

4. 蒙布朗绒 益善洞咖啡馆 (Mont Blanc Som Ikseondong / 몽블랑솜 익선동카페)

  • 地址: 首尔市钟路区水标路28街 (Supyo-ro 28-gil / 수표로28길) 33号
  • 招牌: 益善洞韩屋胡同内咖啡馆·甜品店。益善洞MZ世代咖啡馆氛围的代表。
  • 外国游客友好度: ★★★★☆ — 益善洞本身是外国游客韩屋胡同体验第一选择
  • 推荐菜单: 招牌甜品、韩屋风格特调饮品
  • 贴士: 距钟路3街站 (Jongno 3-ga Station) 6号出口步行3分钟。建议与益善洞整条胡同散步路线结合。周末14:00~17:00为高峰期 — 推荐工作日上午前往。
