🎯 为什么要做这份手册

"带3岁小孩去首尔推婴儿车方便吗"、"婴儿车还是背带"、"从机场到东大门怎么带着婴儿车和行李箱走"——这类问题从2011年到2026年一直在日本旅行社区反复出现(光一个帖子就被浏览超过3000次)，Reddit的r/koreatravel上也有"电梯·婴儿车无障碍"、"带8个月大婴儿逛首尔"这样的帖子。之前的家庭指南(#232)只用一行带过了租借点。先说结论：推婴儿车完全走得通，只是要挑对街区，再备一条背带。

★ 4种交通方式——规定和坑

方式 能做到什么 坑在哪
地铁 首尔交通公社 (Seoul Transportation Corporation / 서울교통공사)旗下车站(1~8号线)已实现一站一无障碍动线 (1역 1동선)100%覆盖——从地面到站台全程可以只靠电梯移动(2026年4月公布) 电梯不是每个出口都有——先在车站导览图上找带电梯的出口。像舍堂 (Sadang / 사당)、教大 (Kyodae / 교대)这种换乘通道很长的车站，要多留时间。9号线、新盆唐线等其他运营商的线路不算在这个比例里，要逐站确认
市内公交 低地板公交(无台阶)比例73%(2024年4月数据)——婴儿车不用折叠，直接停在轮椅专用空间 村镇巴士很少是低地板的。对司机说一句"Yu-mo-cha-yo (유모차요)" (婴儿车！)通常就能得到坡板帮助(参考#1271坐公交攻略)
出租车 法律规定6岁以下要用安全座椅(罚款6万韩元)，但出租车和公交因结构上装不了而不在实际执法范围内——没有安全座椅也能坐 装了安全座椅的出租车几乎不存在(只有个别服务)。折叠婴儿车能放进后备箱。担心安全的话就用背带抱着孩子坐后座
机场→市区 仁川机场 (Incheon Airport / 인천공항)问询处免费出借婴儿车·机场大巴折叠款可以放进后备箱 不能折叠的大型婴儿车可能会被大巴拒载。AREX机场铁路每站都有电梯，但具体路线要看车站导览图

🍼 找哺乳室和换尿布台

  • 哺乳室信息通 (Sooyusil.com / 수유정보알리미)——收录首尔登记在册的510处哺乳室，有"查找附近哺乳设施"的地图功能。界面不是英文，但地图图标一看就懂。
  • 各地铁站有没有哺乳室不一样——尽量围绕大型换乘站、连着百货商店的车站来安排行程。
  • 洗手间本身参考#1277公共洗手间手册(地铁站·百货商店·便利店这三个地方最靠谱)。

🗺 婴儿车难走的4个街区·好走的6个街区

该换成背带的地方

1. 北村韩屋村 (Bukchon Hanok Village / 북촌 한옥마을)——坡道和台阶多

2. 益善洞 (Ikseondong / 익선동)——巷子窄、人多

3. 梨泰院经理团街 (Itaewon's Gyeongnidan-gil / 경리단길)——坡度陡

4. 明洞 (Myeongdong / 명동)——地面是平的，但下午人流太密，婴儿车挤不动

婴儿车好走的地方：汉江公园(汝矣岛 (Yeouido / 여의도)、纛岛 (Ttukseom / 뚝섬))·首尔林 (Seoul Forest / 서울숲)·奥林匹克公园 (Olympic Park / 올림픽공원)·DDP·COEX·汝矣岛——全是平地、人行道宽、到处有电梯。和Reddit的r/koreatravel上"哪个街区才是真正对婴儿车友好"这个帖子的结论一致。

🍽 餐厅·咖啡厅——无儿童区这个变量

  • 韩国有无儿童区 (No Kids Zone / 노키즈존)——不让带孩子进的店。在政府掌握的无儿童区商户里，咖啡厅·面包店占76%，餐厅占18%。2025年10月的调查显示66%的成年人赞成——虽然一直有争议，但并没有消失的迹象。
  • 实战解法：烤肉店·家常饭馆·汤饭店·购物中心美食广场默认欢迎带娃，儿童椅也很常见。咖啡厅要先看门口有没有"No Kids Zone"的标识。
  • 常用说法："A-gi ui-ja it-na-yo (아기 의자 있나요?)" ("有儿童椅吗？")/ "Yu-mo-cha deu-reo-ga-do dwae-yo (유모차 들어가도 돼요?)" ("婴儿车可以进去吗？")。担心辣的话看#1398不辣韩食地图。

📅 婴儿车一日行程示例(全程平地·全程电梯)

汝矣岛汉江公园(上午——草坪、洗手间、便利店)→5号线汝矣渡口 (Yeouinaru / 여의나루)站电梯→DDP(室内——哺乳室、展览)→2号线→COEX(星空图书馆、水族馆、婴儿车租借、美食广场)→晚饭就在COEX里解决。换乘最少，台阶为零。

⚙ FAQ 3条

1. 婴儿车还是背带？——两个都要备。移动、吃饭、逛商场用婴儿车，上面提到的4个街区和上下班高峰的地铁用背带。轻便可折叠的婴儿车是最优解(方便放大巴和出租车后备箱)。

2. 怎么找电梯？——看车站导览图上的电梯图标，或者地图App里的出口信息。大站往往只有1~2个带电梯的出口，所以提前查好出口编号。

3. 出租车没有安全座椅没关系吗？——法律规定6岁以下要用安全座椅，但出租车不在实际执法范围内，所以不装座椅上车本身没问题。安全是另一回事——尽量只坐短途，用背带抱着孩子坐后座。
