⚠ 외국인 자주 실수 5가지

1. "한의원 = 한국인만": 강남·이태원·한남 외국인 친화 한의원 = 영어·중문·일문 풀세트 + 외국인 매니아 1순위.

2. "한약 = 비쌈만": 경동시장 한약재 = g 단위 가성비 + 외국인 vlog 1번지 + 약령시 (대구·전주) 외곽 매니아.

3. "한방 = 효과 없음": 한국 한방 = 국가 면허 한의사 + 보험 적용 + 자생한방 (척추·관절 한국 1번지) + K-Medical (#242) 통합.

4. "경동시장 = 일반 시장": 경동시장 = 한국 #1 한약재 거리 (청량리) + 약전·약초·인삼·생강·대추 풀세트 + 외국인 vlog 1번지.

5. "한방차 = 차 카페와 다름": 한방차 = #359 차·다도 결합 + 쌍화탕·십전대보탕·생강차·대추차·인삼차 외국인 매니아.

① 한의원·한방병원 (4)

1. 경희대학교한방병원 ★ 한국 #1 한방 종합병원

  • 주소: 동대문구 회기동 (1호선 청량리역 인접)
  • 외국인 ★: ◎◎ — 한국 #1 한방 종합병원·영어 OK
  • 시그니처: 한방 종합·외국인 매니아 1번지

2. 자생한방병원 (강남)

  • 주소: 강남구 신사동 (#142)

  • 시그니처: 외국인 매니아 K-Medical 통합

3. 외국인 친화 한의원

  • 매장: 강남·이태원·한남·강남 (#142·#144·#252)
  • 외국인 ★: ◎◎ — 영어·중문·일문 풀세트
  • 시그니처: 외국인 거주 1번지 + K-Medical (#242) 통합

4. 국립한의학연구원 (대전 #320)

  • 외국인 ★: ◎ — 한국 한방 R&D 1번지
  • 시그니처: 학술·외국인 매니아 외곽

⚙ FAQ 6개

1. 외국인 한의원 1순위: 경희 한방병원·자생 (강남)·외국인 친화 한의원 (강남·이태원·한남).

2. 외국인 한약 매니아: 경동시장 (청량리)·약령시 (대구 350년)·전주.

3. 외국인 한방 SPA: 청담·이태원·드래곤힐 (#227·#364).

4. 외국인 한방차: 대추·생강·인삼·쌍화탕·십전대보탕 + #359 결합.

5. 외국인 침술: 강남·이태원 외국인 친화 한의원.

6. 외국인 wellness 풀세트: K-Medical (#242) + 사찰음식 (#357) + 차·다도 (#359) + 한방 (#365) + 정통주 (#362).

🗺 외국인 풀데이 코스 3개

A. 청량리 한방 1일 (경동시장·경희 한방)

  • 09:00 경희 한방병원 → 11:00 경동시장 한약재 거리 → 13:00 한방 음식 (삼계탕) → 15:00 약령시 박물관

B. 외국인 wellness 풀세트 1박2일

  • Day 1: 강남 자생 한방 → 청담 한방 SPA → 신라호텔 (#356·#358) 1박
  • Day 2: 신라 게란디 SPA (#364) → 인사동 차·다도 (#359·#297) → 사찰음식 (#357 발우공양)

C. 외곽 한방 매니아 1박2일 (대구·전주)

  • Day 1: KTX 서울→대구 (#317) → 약령시 350년 → 대구 1박
  • Day 2: KTX 대구→전주 (#255) → 전주 약령시·한옥마을·정통 한방

🌸 시즌 5

  • 봄 3~5월: 신선 한약재 시즌 + 외국인 매니아
  • 여름 6~8월: 삼복 삼계탕 (#279) + 보양식 + 한방차
  • 가을 9~11월: 인삼·뿌리채소 + 외국인 매니아 1순위
  • 겨울 12~2월: 쌍화탕·십전대보탕·따뜻한 한방차 + 외국인 매니아
  • 연중: 경동시장·약령시·외국인 친화 한의원·청담 한방 SPA
