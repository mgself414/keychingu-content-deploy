地元の名店 ② 大邱・慶北 — 韓国の視聴者がコメントで挙げた食堂22軒、Naverで確認だけ残した

サブタイトル：大邱一日コース(#1001)、慶州KTX(#1115)、安東河回村(#1053)が触れなかった軸——韓国の視聴者がYouTubeのコメント欄で薦めた全国の食堂リストから大邱・慶北の22軒だけを選び、Naverローカル検索で存在・住所・業種を確認し、評価はしませんでした。大邱9軒→大慶線軸の倭館・亀尾5軒→慶州・浦項・安東・聞慶・清道8軒。亀尾・倭館・聞慶・清道はKeyChinGu初登場の都市です。

ISSUE 06 · #1383 · 2026-09-18 · 地元の名店 ②

🎯 なぜ「コメント推薦」が基準なのか

この回のソースはひとつだけです。韓国のあるYouTubeチャンネルが上げた「全国の食堂」動画に視聴者がコメントで自分の地元の食堂を書き込み、地域ごとに最も体系的にまとめられたコメントを表にしたものが217軒あります。韓国人が韓国人に薦めたリストなので外国人レビューはほとんどなく、観光リストに載らない町の食堂が多いです。この回の基準と限界は①編(#1382)に書きました。

KeyChinGuはNaverローカル検索で店名・住所・業種が実在するかだけを確認しました(2026-09-17)。大邱・慶北24軒のうち22軒が確認でき、確認できなかった2軒(亀尾・慶州各1軒)は本文から外しました。訪問評価・ランキング・星評価はなく、営業時間・価格もありません——行く当日にNaverプレイスで確認してください。

この回が①編と違うのは鉄道です。2024年12月に開通した大慶線 (Daegyeong Line / 대경선)が亀尾–倭館–大邱–慶山を電車でつなぎ、同じ年の11月には中部内陸線KTX-Eum (Jungbu Naeryuk Line KTX-Eum / 중부내륙선 KTX-이음)が板橋から聞慶まで約90分で結びました。22軒のうち半分はこの2路線の上にあります。

⚠ 表記の原則：各店の行は店名 (ローマ字) · 道路名住所 · Naverカテゴリー · アクセスの順です。アクセスは公式または2つ以上の情報源で確認できた駅・バスだけを記載し、確認できない区間は「Naverマップで確認」としました。営業時間・定休日・価格はすべて未収集です——当日Naverプレイスで確認してください。タクシーの運転手にはハングルの住所をそのまま見せれば大丈夫です。

① 大邱 — 9軒、地下鉄1・2・3号線

大邱一日コース(#1001)と八公山(#1005)が観光の動線だとすれば、この9軒は視聴者が書き込んだ地元の食堂です。コムタン・クッパ・ビンデトク・生肉・中華・屋台料理——大邱の人が平日に食べているものです。

  • オヌルドビンデトク (Oneuldo Bindaetteok / 오늘도빈대떡) · 大邱中区達句伐大路446ギル7-16 (7-16 Dalgubeol-daero 446-gil, Jung-gu / 대구 중구 달구벌대로446길 7-16) · 韓食・チヂミ/ビンデトク · 防川市場の本店——慶北大病院駅(2号線) 3番出口、徒歩約500m

防川市場はキム・グァンソク通りに隣接しています。ビンデトク(nokdujeon、녹두전とも呼ばれる緑豆チヂミ)は市場グルメの代表格で、マッコリと一緒に頼むのが定番です。

  • プンジンコムタン (Pungjin Gomtang / 풍진곰탕) · 大邱南区鳳徳路1ギル11 (11 Bongdeok-ro 1-gil, Nam-gu / 남구 봉덕로1길 11) · 韓食・コムタン/ソルロンタン · ゴンドゥルバウィ駅(3号線)近く、730番バスで鳳徳洞へ

コムタンは牛骨と肉を長時間煮込んだ澄んだスープです。塩とネギで自分好みに味を調えます(#1191のコムタンのコツと同じです)。

  • ナムサネ (Namsane / 남산에) · 大邱中区中央大路66ギル20 (20 Jungang-daero 66-gil, Jung-gu / 중구 중앙대로66길 20) · 日本料理店 · 都心の中央大路——最寄り駅はNaverマップの徒歩案内で確認

中央路と半月堂の間、都心にある日本料理店です。大邱の都心は半月堂駅 (Banwoldang Station / 반월당역)を基準に動くと分かりやすく、1・2号線が交わります。

  • フェンソントゥッペギ (Hoengseong Ttukbaegi / 횡성뚝배기) · 大邱東区安心路624 (624 Ansim-ro, Dong-gu / 동구 안심로 624) · 韓食・クッパ · 安心駅(1号線)

1号線東の終点、安心エリアのクッパ店です。トゥッペギ(ttukbaegi)はクッパが盛られて出てくる厚手の陶器の名前です。

  • ウガセンゴギ (Uga Saenggogi / 우가생고기) · 大邱寿城区達句伐大路641ギル17-4 (17-4 Dalgubeol-daero 641-gil, Suseong-gu / 수성구 달구벌대로641길 17-4) · 韓食・生肉料理 · 寿城区東部——駅・バスはNaverマップで確認

生肉、大邱ではmungtigi (뭉티기)とも呼ばれるこの料理は、大邱でよく知られた生の牛肉料理です。火を通していない牛肉なので、苦手な人は事前に知っておくといいでしょう。

  • プチュチャプチェ (Buchu Japchae / 부추잡채) · 大邱寿城区チボム路290 (290 Jibeom-ro, Suseong-gu / 수성구 지범로 290) · 韓食 · 寿城区南東部の住宅街——駅からバス・タクシー(Naverマップで確認)

店名がそのままメニューです。プチュチャプチェはニラと肉を炒めた中華風のおかずで、ご飯と一緒に食べます。

  • タルゴトッポッキ (Dalgo Tteokbokki / 달고떡볶이) · 大邱達西区野外音楽堂路39ギル54 (54 Yaoeeumakdang-ro 39-gil, Dalseo-gu / 달서구 야외음악당로39길 54) · 屋台料理・総合屋台料理 · 斗流公園——斗流駅(2号線) 14番出口

斗流公園とEワールドの隣にある屋台料理店です。トッポッキ・揚げ物(twigim、튀김)・スンデ(sundae、순대)・キンパ(gimbap、김밥)が屋台料理の基本セットです。

  • オボクパンジョム (Obok Banjeom / 오복반점) · 大邱達城郡花園邑明川路146 (146 Myeongcheon-ro, Hwawon-eup, Dalseong-gun / 달성군 화원읍 명천로 146) · 中華・中華料理店 · 花園駅(1号線) 2番出口徒歩圏

1号線南の終点、花園にある中華料理店です。パンジョム(banjeom)は中華料理店を指す昔ながらの呼び方です。

  • ウォンジョイバンアジメ (Wonjo Ibang Ajimae / 원조이방아지매) · 大邱達城郡玄風邑玄風路6ギル5常設市場洞 (5 Hyeonpung-ro 6-gil, Hyeonpung-eup, Dalseong-gun, Sangseol Market area / 달성군 현풍읍 현풍로6길 5 상설시장동) · 韓食 · 雪花鳴谷駅(1号線終点)からバス乗り換え(路線・所要時間はNaverマップで確認)

玄風は大邱の南西端、玄風市場の中にある食堂です。アジメ(ajimae)は「おばさん」を意味する慶尚道の方言です。

外国人向けのポイント — 大邱の地下鉄は1・2・3号線の3本で、都心の乗り換えは半月堂駅(1・2号線)です。コムタン・クッパは一人でも注文でき、生肉も基本は一人前単位ですが、生の牛肉だという点だけ確認してから座りましょう。

② 大慶線軸 — 倭館2 · 亀尾3

大慶線は2024年12月14日に開通した通勤電車で、亀尾–サゴク–プクサム(2026年2月28日追加)–倭館–西大邱–大邱–東大邱–慶山を結びます。ラッシュ時は約19分間隔、通常時は約30分間隔です。亀尾から大邱までは約30分なので、大邱を拠点に半日で倭館・亀尾を回れます。

  • マルリグン (Malligung / 만리궁) · 七谷郡倭館邑石田路12ギル7 (7 Seokjeon-ro 12-gil, Waegwan-eup, Chilgok-gun / 칠곡군 왜관읍 석전로12길 7) · 中華・中華料理店 · 大慶線倭館駅
  • ッカックリチャンポン (Kkakkuri Jjamppong / 까꾸리짬뽕) · 七谷郡倭館邑平章ギル21-10 (21-10 Pyeongjang-gil, Waegwan-eup, Chilgok-gun / 칠곡군 왜관읍 평장길 21-10) · 中華・中華料理店 · 大慶線倭館駅

倭館邑の中華料理店2軒です。チャンポン(jjamppong、짬뽕)は辛い海鮮麺で、ジャージャー麺と並ぶ韓国式中華の二本柱です。どちらも倭館駅から町の中に入ったところにあり、徒歩の分数はNaverマップで確認してください。

  • キムテジュソンサンコプチャン (Kim Tae-ju Seonsan Gopchang / 김태주선산곱창) · 亀尾市松院西路77 (77 Songwonseo-ro, Gumi-si / 구미시 송원서로 77) · 韓食・コプチャン · 亀尾駅(大慶線・KTX)周辺——徒歩・バスはNaverマップで確認
  • デハンシクタン (Daehan Sikdang / 대한식당)、Daehan Gopchang · 亀尾市善山邑南門路44 (44 Nammun-ro, Seonsan-eup, Gumi-si / 구미시 선산읍 남문로 44) · 韓食・コプチャン · 亀尾駅↔善山ターミナル170番バス(171-1・171-4も補完)

亀尾のコプチャン店2軒です。ソンサンコプチャンは亀尾・善山邑発祥の牛の小腸炒めの名前で、市内店と善山の本家格の2軒がそろってリストに入りました。

  • チョクトングクス (Jeokdong Guksu / 적동국수) · 亀尾市山東邑江東路1039 (1039 Gangdong-ro, Sandong-eup, Gumi-si / 구미시 산동읍 강동로 1039) · 韓食・麺類 · 山東邑——亀尾駅・ターミナルからのバス路線は確認要、タクシーが現実的

亀尾東側、山東邑の麺料理店です。ここでのグクス(guksu)はほぼチャンチグクス(janchi guksu、잔치국수)、カタクチイワシだしの麺料理を指します。

外国人向けのポイント — コプチャンは牛の内臓を炒めた料理なので好みが分かれます。2人前からの注文になる店が多く、締めにチャーハンを頼むのが地元流です。麺類・中華は一人での注文もできます。

太宗路にある韓食店とタイ料理店です。太宗路は慶州の都心を東西に貫く通りです。慶州の観光動線(#1115、#1366)は皇理団ギル (Hwangnidan-gil / 황리단길)・大陵苑エリアで、太宗路はその西側の生活圏です。

  • アーモンドチキン (Almond Chicken / 아몬드치킨) · 慶州市陽南面ナア2ギル5-1 (5-1 Naa 2-gil, Yangnam-myeon, Gyeongju-si / 경주시 양남면 나아2길 5-1) · チキン · 慶州高速バスターミナルから150番(陽南方面)、約1時間20分、ほぼ1時間おき

慶州南東の海沿い、陽南面のチキン店です。陽南の柱状節理(jusangjeolli、주상절리)と同じ道沿いにあるので、同じ日にセットで回るのが自然です。

  • イッカデト (Ikkadaeto / 이까대토) · 浦項市南区九龍浦邑九龍浦ギル148 (148 Guryongpo-gil, Guryongpo-eup, Nam-gu, Pohang-si / 포항시 남구 구룡포읍 구룡포길 148) · 韓食 · 浦項駅から九龍浦1番バス(始発07:00、終発18:30、約40分間隔)

九龍浦はグァメギ(gwamegi、과메기、干しサンマ)と日本式家屋通りで知られる港町です。終発が18:30なので、夕食での訪問は厳しいです。

  • トンアッコルクムジェガーデン (Dongakgol Geumjae Garden / 동악골금재가든) · 安東市臥龍面東岳谷ギル166 (166 Dongakgol-gil, Waryong-myeon, Andong-si / 안동시 와룡면 동악골길 166) · 韓食・タッボックムタン · 安東駅(KTX-Eum) → 臥龍面方面510・511~514番バス

河回村(#1053)の反対側、臥龍面にあるタッボックムタン(辛い鶏の煮込み)店です。ガーデン(가든)は韓国で郊外の大型食堂によく使われる屋号の付け方です。

  • ヨンスンシクタン (Yeongsun Sikdang / 영순식당) · 聞慶市永順面永順路269 (269 Yeongsun-ro, Yeongsun-myeon, Mungyeong-si / 문경시 영순면 영순로 269) · 韓食・白飯定食 · 聞慶駅(中部内陸線KTX-Eum、板橋から約90分、1日8往復) → 永順面までタクシー、確認要
  • ソルバッシクタン (Solbat Sikdang / 솔밭식당) · 聞慶市中央6ギル6 (6 Jungang 6-gil, Mungyeong-si / 문경시 중앙6길 6) · 韓食 · 聞慶市内——駅・ターミナルからのアクセスは確認要

聞慶は2024年11月30日にKTX-Eumが通じるまでバスでしか行けない町でした。ペクパン(baekban、백반)はご飯・スープ・おかずが揃った定食のことで、ヨンスンシクタンはそのペクパンの店です。

  • タムボクミナリガーデン (Tambok Minari Garden / 탐복미나리가든) · 清道郡清道邑ハンジェ路382 (382 Hanjae-ro, Cheongdo-eup, Cheongdo-gun / 청도군 청도읍 한재로 382) · 韓食 · 清道駅(ムグンファ号)向かいのターミナル → ハンジェ方面バス・タクシー(路線は確認要)

ハンジェは清道のミナリ(minari、미나리、セリ)の産地で、春(2~4月)にミナリとサムギョプサル(samgyeopsal、삼겹살)を一緒に食べるのが地元の習慣です。旬が短いので時期は要確認です。

外国人向けのポイント — 慶州駅・安東駅・聞慶駅・浦項駅はいずれも都心の外か旧市街から離れています。駅から歩いてすぐではなく、バスかタクシーにもう一度乗る前提で時間を見ておきましょう。タクシーにはハングルの住所を見せれば大丈夫です。

🚄 地方の動線への組み込み方

  • 大邱を拠点に大慶線 — 大邱の9軒は地下鉄、倭館・亀尾の5軒は大慶線で。亀尾駅まで約30分なので、1日で倭館ランチ・亀尾ディナーが組めます。
  • 慶州(#1115)の1泊に組み込む — 太宗路の2軒は都心寄り、陽南のアーモンドチキンは柱状節理方面の半日コースに合います。慶州駅が都心の外(旧新慶州駅)にあることは#1372~1374で詳しく扱っています。
  • ソウル→聞慶を日帰りで — 板橋からKTX-Eumで約90分。1日8往復しかないので、まず時刻表を確認しましょう。
  • 安東(#1053) — KTX-Eumの安東駅を起点に、河回村は西、臥龍面は東です。同じ日に両方は慌ただしくなります。
  • 浦項九龍浦 — 浦項駅からバス40分間隔、終発18:30。ランチ訪問が前提です。
  • 昌寧・居昌(#1382) — このルートは大邱西部バスターミナル発が中心なので、この回の大邱の予定に組み込む方が自然です。

⚠ よくある失敗3つ

1. 慶州駅から歩いて都心へ向かう — 慶州駅は旧新慶州駅で、都心の外にあります。バスかタクシーを1本使いましょう。

2. 九龍浦を夕方に訪ねる — 浦項駅発の九龍浦1番バスの終発は18:30です。ランチの時間帯に組みましょう。

3. 大慶線をKTXの時刻表感覚で考える — 通常時30分間隔の通勤電車です。倭館・亀尾は交通カードでそのまま乗れます。

⚙ よくある質問3つ

1. このリストは誰が選んだのですか？ — 韓国のYouTube視聴者がコメント欄に書き込んだ地元の食堂をまとめた表です。KeyChinGuは存在・住所・業種を確認しただけで、順位はつけていません。

2. 邑・面の食堂でカードは使えますか？ — 使える店は増えていますが、現金・口座振込の方がまだスムーズな文化です。現金の準備は#1301を参照してください。

3. 大邱がなぜ9軒もあるのですか？ — 整理された表の中で大邱・慶北はソウルに次いで多く、そのうち9軒が大邱市内にあります。大邱の観光動線は#1001~1005を参照してください。
