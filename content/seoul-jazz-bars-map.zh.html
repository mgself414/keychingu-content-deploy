首尔爵士酒吧指南——梨泰院·弘大·城北·广津6家(All That Jazz、Boogie Woogie、Evans、延南5701、Jazz Story、Dido Jazz Lounge)(2026年10月官方数据)

副标题: All That Jazz (All That Jazz / 올댓재즈) 全年无休,周一至周四免门票只需点饮品(VisitSeoul) · Evans (Evans / 에반스) 门票15,000韩元(VisitSeoul) · Jazz Story (Jazz Story / 째즈스토리) 演出费5,000韩元,现场演奏20:00~23:00(VisitSeoul) · Dido Jazz Lounge (Dido Jazz Lounge / 디도 재즈 라운지) 观演费12,000韩元(VisitSeoul) · 饮酒从满19岁那年的1月1日起(生活法令易查网) — 截至2026-10-21

ISSUE 03 · #470 · 2026-05-27

🎯 本指南的使用方法

走下地下,白炽灯的昏黄灯光下铺开现场爵士——Jazz Story 被介绍为"与其说是边喝酒边看演出的地方,不如说是听音乐的屋子"(VisitSeoul)。本指南写给想在首尔边喝一杯边听现场爵士的旅行者。分为三类:梨泰院·经理团路、弘大·延南、另收演出费的街区爵士酒吧(城北·广津)。店家只挑选了在首尔官方旅游网站VisitSeoul上被介绍为爵士酒吧,且信息于2026年修订过的地方。

旧版指南写了Once in a Blue Moon (Once in a Blue Moon / 원스인어블루문)、Janus (Janus / 야누스)、千年东岛 (Cheonnyeon Dongan-do / 천년동안도)、Awesome Ground (Awesome Ground / 어썸그라운드)、SEOB's (SEOB's / SEOB's)、Sound Dog (Sound Dog / 사운드독),并附有时间和价格。这次在官方页面上未能确认它们目前的营业信息,所以全部删除。"韩国三大爵士俱乐部""亚洲最深厚的爵士圈"之类的说法也没有出处。旧版指南断定为1976年的All That Jazz 开业年份,VisitSeoul韩文版写1976年、英文版写1978年,两者不一致。

🎷 梨泰院·经理团路——2家

  • All That Jazz — 首尔龙山区 (Yongsan-gu / 용산구) 梨泰院路216号 (Itaewon-ro / 이태원로)(汉南洞 (Hannam-dong / 한남동))。周日至周四18:00~24:00,周五、周六18:00~01:00,全年无休。被介绍为华裔美国人马明德 (Ma Myeong-deok / 마명덕) 在梨泰院开设的韩国第一家爵士俱乐部,藏有LP 2000多张、CD 600多张。周一至周四不另收门票,只需点一杯5,000韩元左右的饮品。价位2万韩元左右。从最初的位置搬到了汉密尔顿酒店附近。距梨泰院站 (Itaewon-yeok / 이태원역) 3号出口333米。电话02-795-5701(VisitSeoul韩文版)
  • Boogie Woogie — 首尔龙山区 (Yongsan-gu / 용산구) 桧木路21号 (Hoenamu-ro / 회나무로)(梨泰院洞 (Itaewon-dong / 이태원동)) 2层。周一至周四18:30~01:30,周五至周日及公休日17:30~00:30。可以听到节奏强劲而快速的钢琴与爵士的现场酒吧。预约的话有套餐折扣和热门座位优先安排。距绿莎坪站 (Noksapyeong-yeok / 녹사평역) 2号出口549米。电话0507-1490-3061(VisitSeoul韩文版)

🎹 弘大·延南——2家

  • Evans — 首尔麻浦区 (Mapo-gu / 마포구) 卧牛山路63号 (Wausan-ro / 와우산로)(西桥洞 (Seogyo-dong / 서교동))。使用时间19:00~22:10,节日休息。弘大 (Hongdae / 홍대) 一带最老的俱乐部之一,每天节目不同,每月更换乐手。每人门票15,000韩元(饮品另付)。写明乐队现场演奏要到晚上9点以后才开始。距上水站 (Sangsu-yeok / 상수역) 1号出口279米。电话02-337-8361(VisitSeoul韩文版)
  • 延南5701 (Yeonnam 5701 / 연남 5701) — 首尔麻浦区 (Mapo-gu / 마포구) 东桥路23街64号 (Donggyo-ro 23-gil / 동교로23길)(延南洞 (Yeonnam-dong / 연남동)) 地下。周四至周一18:30~23:00,周二、周三休息。有专心看演出的座位,也有边吃饭边看的座位。有餐食和葡萄酒。演出阵容发布在Instagram和Facebook上。距弘大入口站 (Hongik Daeipgu-yeok / 홍대입구역) 1号出口600米。电话010-2129-8161(VisitSeoul韩文版)

🎺 城北·广津——另收演出费的2家

  • Jazz Story — 首尔城北区 (Seongbuk-gu / 성북구) 惠化路88号 (Hyehwa-ro / 혜화로)(城北洞 (Seongbuk-dong / 성북동))。周二至周日17:00至次日01:00,周一休息。现场演奏20:00~23:00,演出费每天5,000韩元。从三清洞 (Samcheong-dong / 삼청동) 搬到了城北洞 (Seongbuk-dong / 성북동),地下空间由白炽灯照亮。距汉城大入口站 (Hanseongdae Ipgu-yeok / 한성대입구역) 5号出口862米。电话02-747-6537(VisitSeoul韩文版,2026-07-06登录)
  • Dido Jazz Lounge — 首尔广津区 (Gwangjin-gu / 광진구) 紫阳路18街56号 (Jayang-ro 18-gil / 자양로18길)(九宜洞 (Guui-dong / 구의동),巨松大厦 (Geosong Building / 거송빌딩))。周三至周日及公休日19:00~24:00,周一、周二休息。观演费12,000韩元。每天都有现场演奏,阵容发布在Instagram上。同时供应餐食和葡萄酒。距九宜站 (Guui-yeok / 구의역) 2号出口111米。电话0507-1354-2815(VisitSeoul韩文版)

🥗 饮食

  • 餐食:延南5701 (Yeonnam 5701 / 연남 5701) 和Dido Jazz Lounge 供应餐食和葡萄酒(VisitSeoul)。六家都没有标注素食菜单——点餐前先问食材
  • 清真:VisitSeoul将梨泰院 (Itaewon / 이태원) 的Eid(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街15号 (Usadan-ro 10-gil / 우사단로10길),每天12:00~21:00)介绍为韩国伊斯兰教中央会(KMF)认定为清真的少数餐厅之一。认定可能变动,到访前请先确认。本指南中的爵士酒吧全部都卖酒
  • 不喝酒的话:All That Jazz 周一至周四点一杯饮品即可(VisitSeoul)。有没有无酒精饮品请问店家
  • 价位:官方公布的只有门票、演出费(5,000~15,000韩元)和"2万韩元左右"(All That Jazz、Evans)(VisitSeoul韩文版)。餐食、酒水价格未公布
  • 展示卡请见#1300 饮食需求手册

🧰 爵士酒吧实用信息——年龄、独自入场、预约、支付、演出时间、交通

  • 年龄:韩国法律中的"青少年"是未满19岁的人,到了满19岁那年1月1日的人除外(生活法令易查网)。请带好护照
  • 独自入场:官方页面没有写是否接待单人。设有专门演出席的延南5701 (Yeonnam 5701 / 연남 5701),或"听音乐的屋子"Jazz Story,一个人听比较合适(依据VisitSeoul的介绍)
  • 预约:Boogie Woogie 预约有套餐折扣和座位优先安排(VisitSeoul)。其余的官方页面没有预约途径,请打电话或通过Instagram询问
  • 演出时间:Evans 21点以后,Jazz Story 20:00~23:00(VisitSeoul)。阵容请在Dido和延南5701的Instagram上查看
  • 支付:银行卡·移动支付请见#527 韩国支付系统。语言不通请见#1339 点餐礼仪
  • 交通:Boogie Woogie(01:30)、All That Jazz 周末(01:00)、Jazz Story(01:00) 在地铁末班车之后才关门。#1395 错过末班车怎么办

⚠ 常见的4个错误

1. "爵士酒吧不收门票"——Evans 15,000韩元,Dido (Dido / 디도) 12,000韩元,Jazz Story 5,000韩元。只有All That Jazz 周一至周四免门票,点饮品即可(VisitSeoul)

2. "爵士酒吧每天营业"——Dido 周一、周二休息,延南5701 (Yeonnam 5701 / 연남 5701) 周二、周三休息,Jazz Story 周一休息(VisitSeoul)

3. "All That Jazz确定是1976年开业"——VisitSeoul韩文版写1976年,英文版写1978年

4. "过了满19岁的生日才能进"——标准是满19岁那年的1月1日(生活法令易查网)
