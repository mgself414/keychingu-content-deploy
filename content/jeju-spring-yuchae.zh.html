济州油菜花指南 — 城山日出峰油菜花田·Joltti油菜花田·油菜花种植园区，Gasi里Noksan路油菜花道·西归浦油菜花节，山房山油菜花田，中文Eongdeongmul溪谷

副标题:日出峰油菜花田(12~3月，全天开放) · Joltti油菜花田(11月中旬~3月中旬 09:00~18:00) · 油菜花种植园区(全天开放) · Noksan路油菜花道(约10km，全天开放) · 山房山油菜花田(10:00~18:00，拍摄费) · Eongdeongmul溪谷(全天开放) · 2026西归浦油菜花节(4/4~5，已结束) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了济州西归浦可以看到油菜花的地方。分别是城山日出峰周边的三处油菜花田、Gasi里的Noksan路油菜花道和花节、山房山油菜花田、中文的Eongdeongmul溪谷。

按观光公社登记的数值，也有冬天可以看的油菜花田。日出峰油菜花田在12~3月开放，Joltti油菜花田在11月中旬~3月中旬开放。其余的主要以春季为中心介绍。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 城山 — 日出峰油菜花田·Joltti油菜花田·油菜花种植园区

日出峰油菜花田(Ilchulbong Yuchaebat / 일출봉유채밭)，西归浦市城山邑Seongsan里(Seongsan-ri / 성산리)，☎ 济州旅游信息中心(Jeju Gwanggwang Jeongbo Senteo / 제주관광정보센터) 064-740-6000，是城山日出峰(Seongsan Ilchulbong / 성산일출봉)与Gwangchigi海边(Gwangchigi Haebyeon / 광치기해변)之间的油菜花田。油菜花通常在12月到3月开放，花田对面可以看到大海和汉拿山(Hallasan / 한라산)。开花时期每年不同。全天开放，但观光公社的介绍建议想看油菜花要在日落前前往。

  • 使用季节:12~3月。开放时间:全天开放。休息日:全年无休。
  • 停车:可以。

Joltti油菜花田(Joltti Yuchaebat / 졸띠유채밭)，西归浦市城山邑(Dongnyuam-ro 8 / 동류암로 8)，☎ 咨询 064-757-2076，是城山日出峰附近的油菜花田，可以同时看到城山日出峰、牛岛(Udo / 우도)和芦苇田。也可以体验环绕油菜花田的骑马。据观光公社介绍，以前的开花时期是3~5月，但由于品种改良和播种时期调节，现在11月~5月都可以看到，最盛的时候是3月。可以拍下城山日出峰落入心形结构中的照片。

  • 开放时间:11月中旬~3月中旬 09:00~18:00。
  • 休息期间:每年3月底~11月初。停车:可以。
  • 登记的数值互相矛盾。花期介绍是11月~5月(最盛3月)，但开放时间登记到3月中旬为止，休息期间则从3月底开始。

油菜花种植园区(Yuchaekkot Jaebae Danji / 유채꽃재배단지)，西归浦市城山邑Goseong里(Goseong-ri / 고성리)，☎ 济州Olle旅行者中心(Jeju Olle Yeohaengja Senteo / 제주올레여행자센터) 064-762-2167，是位于一块狭长土地上的油菜花田，这里原本是大海，沙子和泥土堆积后与城山日出峰相连。花田两侧展开大海。附近有开往牛岛的客轮出发的Seongsanpo港(Seongsanpo-hang / 성산포항)、Seopjikoji(Seopjikoji / 섭지코지)、Ojo浦口(Ojopogu / 오조포구)。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 Gasi里 — Noksan路油菜花道·西归浦油菜花节

Noksan路油菜花道(Noksanro Yuchaekkot Doro / 녹산로 유채꽃도로)，西归浦市表善面(Gasiro 565beon-gil 20 / 가시로565번길 20)，☎ 西归浦综合旅游咨询处(Seogwipo Jonghap Gwanggwang Annaeso / 서귀포종합관광안내소) 064-732-1330，是从Gasi里(Gasi-ri / 가시리)村庄入口起约10km路段油菜花与樱花同时盛开的兜风路。入选韩国最美道路100选。途经朝鲜时代曾是牧马场的Noksanjang牧场(Noksanjang / 녹산장)和Gapmajang牧场(Gapmajang / 갑마장)，可以看到汉拿山和Gasi里风力发电园区(Gasi-ri Pungnyeok Baljeon Danji / 가시리 풍력발전단지)。附近有矮种马体验公园(Jorangmal Cheheom Gongwon / 조랑말체험공원)和Gapseoni Oreum(갑선이오름)。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:不可以。

2026西归浦油菜花节(Seogwipo Yuchaekkot Chukje / 서귀포유채꽃축제)，表善面Gasi里矮种马体验公园(Jorangmal Cheheom Gongwon / 조랑말체험공원)一带，☎ 西归浦市(Seogwipo-si / 서귀포시) 064-760-3942，于2026年4月4~5日，10:00~20:00举办。费用为免费。这是在Noksan路一带10万㎡油菜花田中漫步的花节，登记的主要活动是夜间开放和跑步活动，附带活动有一日课堂、村庄特色活动和街头表演等。

📍 西部·中文 — 山房山油菜花田·Eongdeongmul溪谷

山房山油菜花田(Sanbangsan Yuchaekkotbat / 산방산유채꽃밭)，西归浦市安德面Sagye里(Sagye-ri / 사계리)，☎ 济州Olle旅行者中心(Jeju Olle Yeohaengja Senteo / 제주올레여행자센터) 0507-1435-2179，是从山房山Land(Sanbangsan Raendeu / 산방산랜드)前的公共停车场可以前往的油菜花田。有好几处以山房山(Sanbangsan / 산방산)为背景的花田，从中挑选一处进入。因为是个人打理的私有土地，所以收取拍照费。通常3月花开得最盛。附近有山房山、龙头海岸(Yongmeori Haean / 용머리해안)、Sagye海岸(Sagye Haean / 사계해안)。

  • 开放时间:10:00~18:00。休息日:全年无休。
  • 费用:拍照费(金额无登记值)。停车:可以。

Eongdeongmul溪谷(Eongdeongmul Gyegok / 엉덩물계곡)，西归浦市Saekdal洞，☎ 济州旅游信息中心 064-740-6000，是中文旅游园区(Jungmun Gwanggwang Danji / 중문관광단지)Lotte Hotel东侧的溪谷。名字来自这样的说法:岩石又大又险，寻水的野兽也无法靠近，只把屁股探进去解决一下就回去了。春天溪谷的山坡上开满油菜花。属于Olle 8路线(Olle 8-Koseu / 올레 8코스)，也叫中文月光漫步公园(Jungmun Dalbit Geotgi Gongwon / 중문달빛걷기공원)。把车停在中文海水浴场(Jungmun Haesuyokjang / 중문해수욕장)停车场后步行前往。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

⚠ 行前须知 3 点

  1. Joltti油菜花田在3月底~11月初休息 — 11月中旬~3月中旬 09:00~18:00开放。
  2. 山房山油菜花田是私有土地，收取拍照费 — 10:00~18:00开放。
  3. Noksan路油菜花道不可以停车 — 未登记为可以停车。

⚙ FAQ 2

Q. 冬天也能看到济州油菜花吗?

A. 按观光公社登记信息，日出峰油菜花田(Ilchulbong Yuchaebat / 일출봉유채밭)在12~3月开放，Joltti油菜花田(Joltti Yuchaebat / 졸띠유채밭)登记为11月中旬~3月中旬 09:00~18:00运营。

Q. 哪里可以同时看到油菜花和樱花?

A. Gasi里的Noksan路油菜花道(Noksanro Yuchaekkot Doro / 녹산로 유채꽃도로)。约10km路段油菜花与樱花同时盛开，全天开放。不可以停车。
