🎯 如何使用这份指南

连纸袋一起接过来的烤红薯暖着手心，咬一口刚煎好的糖饼 (Hotteok / 호떡)，红糖糖浆就流了出来。本指南把12~2月的韩国冬季小吃分成四类：鲷鱼烧 (Bungeoppang / 붕어빵)·烤红薯等路边摊小吃、糖饼、冬至红豆粥、草莓甜点。路边摊位置时常变动，所以不指具体摊位，只根据VisitKorea、Korea.net的官方报道写"一般在哪里卖"。位置固定的糖饼店、红豆粥店，只搬运VisitKorea收录页面上的地址和时间。适合冬天来韩国、要挑街头买什么吃的人。

旧版指南的"鲷鱼烧 1,000~2,000韩元"、"酒店草莓 13~15万韩元"、"釜山南浦洞籽糖饼 (Ssiat Hotteok / 씨앗호떡) 最好吃"的口碑，找不到官方出处，已删除。旧版还把草莓节当作冬季活动，但2026年论山、完州参礼、晋州草莓节都在3~4月举行(VisitKorea)。

🐟 路边摊小吃 — 鲷鱼烧·烤红薯·烤栗子·鸡蛋糕

路边摊位置会变，所以只根据官方报道搬运售卖处类型。

  • 鲷鱼烧 (Bungeoppang / 붕어빵)：鱼形的小面包(VisitKorea，2025-11)。以前主要在帐篷小吃摊卖，现在卖的摊子减少了，也通过外送、超市(微波炉用)销售(Korea.net Monthly KOREA，2020-03)。同一篇报道写着"十年前1,000韩元5~10个，现在2~3个" — 这是2020年的数据，现价到现场确认
  • 烤栗子·烤红薯：连皮放在炉子上烤。以前在街上很常见，现在便利店或地铁站内也有卖(VisitKorea，2025-11)
  • 蒸包·大饺子：冬天在便利店很容易买到(VisitKorea，2025-11)
  • 鸡蛋糕 (Gyeran-ppang / 계란빵)：整颗鸡蛋放在上面的面包(VisitKorea，2025-11)。没有售卖处的说明
  • 聚集的地方：明洞站美食街(4号线明洞站6号出口向左直走，VisitKorea)
  • 鲷鱼烧店(固定店铺)：鲷鱼与鱼饼 (Bungeorang Odeng / 붕어랑 오뎅) — 江原道平昌郡平昌邑百五路 (Baego-ro / 백오로) 73号。招牌品项鲷鱼烧、鱼饼。10:00~19:00，周日休息，033-333-0118(VisitKorea)。价格未公布

🥞 糖饼

糖饼是包着红糖、肉桂、坚果的软糯煎饼(VisitKorea，2025-11)。

  • 群山中洞糖饼 (Gunsan Jungdong Hotteok / 군산중동호떡)：全北群山市西来路 (Seorae-ro / 서래로) 52号。第三代，不用油煎的糖饼(馅：白糯麦、黑豆、黑米、黑芝麻)。周一至周六 10:00~19:00，周日 13:00~18:00，全年无休。063-445-0849。建议打包后1小时内吃完(VisitKorea)
  • 滋滋糖饼 (Jjoljjol Hotteok / 쫄쫄호떡)：忠北清州市上党区上党路 (Sangdang-ro / 상당로) 55番街 40-1。10:50~19:30(19:00停止点餐)，全年无休(周三只提供糖饼、炒年糕外带)。043-221-2208。刷卡标示为"无"(VisitKorea)
  • 申家糖饼紫菜包饭炒年糕 (Shingane Hotteok Gimbap Tteokbokki / 신가네 호떡 김밥 떡볶이)：釜山东莱区忠烈大路 (Chungnyeol-daero / 충렬대로) 249番街 61号。点单后现煎的糯米糖饼。06:00~22:00，每月第二、第四个周二休息，可刷卡。051-552-2644(VisitKorea)
  • 济州东门市场糖饼巷 (Jeju Dongmun Sijang Hotteok Golmok / 제주 동문시장 호떡골목)：济州市东门路 (Dongmun-ro / 동문로) 16号，东门传统市场1号门向左。一排店铺卖荞麦卷饼 (Bingtteok / 빙떡)、艾草糖饼、杂菜糖饼。营业时间各店不同(VisitKorea)

🥣 冬至红豆粥

  • 冬至 (Dongji / 동지)：二十四节气中的第22个，夜晚最长的一天。吃冬至红豆粥就被认为长了一岁，还把红豆粥洒在大门和围墙上驱邪(国立民俗博物馆)。2026年冬至是12月22日 05:50(韩国天文研究院)
  • 小冬至 (Aedongji / 애동지)、中冬至 (Jungdongji / 중동지) 时，也有不喝红豆粥而做红豆蒸糕吃的习俗(国立民俗博物馆)
  • 新堂洞千红豆粥 (Sindangdong Cheon Patjuk / 신당동천팥죽)：首尔中区茶山路 (Dasan-ro / 다산로) 44街 33号。红豆粥、红豆刀削面。10:30~20:00(19:30停止点餐)，周日休息，可刷卡。02-2237-6385(VisitKorea)
  • 老式红豆粥店 (Yetnal Patjukjip / 옛날팥죽집)：全北全州市完山区百济大路 (Baekje-daero / 백제대로) 276号。汤圆红豆粥、红豆刀削面、南瓜粥。10:00~20:00，全年无休，可刷卡。063-226-2022(VisitKorea)
  • 文湖里红豆粥 (Munhori Patjuk / 문호리팥죽)：京畿道杨平郡西宗面北汉江路 (Bukhangang-ro / 북한강로) 641号。不加淀粉只煮红豆，不调味端上桌。11:00~19:20(休息 14:50~16:00)，周一休息。031-774-5969(VisitKorea)
  • 老式红豆粥 (Yetnal Patjuk / 옛날팥죽，济州)：济州西归浦市城邑民俗路 (Seongeupminsok-ro / 성읍민속로) 130号，城邑民俗村旁。汤圆红豆粥2人份起。10:00~17:00，周一及春节、中秋假期休息。064-787-3479(VisitKorea)
  • 奶奶红豆刨冰甜红豆粥 (Halmae Patbingsu Danpatjuk / 할매팥빙수단팥죽)：釜山南区龙湖路 (Yongho-ro / 용호로) 90番街 24号。获百年老店认证，甜红豆粥、红豆刨冰。09:00~22:00，全年无休(VisitKorea)
  • 五家都未公布价格 — 打电话确认

🍓 草莓甜点 — 季节公告前

  • 酒店草莓甜点·自助餐：没有找到2026-27季的官方公告(2026-10-21)。只有媒体报道说上一季的公告在12月前后发布[二手资料] — 日期、价格要等各酒店官方网站公告发布后再确认
  • 草莓节在春天：2026年完州参礼草莓大节 (Wanju Samnye Ttalgi Daejeukje / 완주삼례딸기대축제) 3/6~3/8，论山草莓节 (Nonsan Ttalgi Chukje / 논산딸기축제) 3/26~3/29，晋州草莓节 (Jinju Ttalgi Chukje / 진주딸기축제) 4/10~4/12(VisitKorea)。2027年日程未公布

🥗 饮食

  • 价格区间：本指南中没有官方公布的韩元价格。Korea.net的鲷鱼烧价格是2020年的报道
  • 素食：鲷鱼烧、糖饼面糊的材料(是否含牛奶、鸡蛋)官方页面上没有。红豆粥的汤底是否用肉汤也没有公布 — 点餐前先问
  • 过敏：糖饼馅里有坚果(VisitKorea)。群山中洞糖饼 (Gunsan Jungdong Hotteok / 군산중동호떡) 的馅里有黑豆、黑芝麻，鸡蛋糕整颗放入鸡蛋(VisitKorea)。对坚果、大豆、芝麻、鸡蛋过敏要事先说明
  • 清真：VisitSeoul介绍梨泰院的Eid (Eid / 이드)是少数获韩国伊斯兰教中央会(KMF)认可的清真餐厅之一(龙山区 Usadan-ro 10-gil 15号，每天12:00–21:00)。认证可能变更，前往前请先确认。本指南的店铺没有清真标示
  • 出示用卡片见 #1300 饮食需求手册

🧰 冬季小吃实用信息 — 独自、预约、支付、点餐、交通

  • 独自：路边摊、糖饼店以外带为主，一个人也容易买。不过济州老式红豆粥 (Yetnal Patjuk / 옛날팥죽) 的汤圆红豆粥2人份起(VisitKorea)。想一个人坐下来吃见 #348 Seoul Solo Diner Map
  • 预约：本指南的店铺没有预约说明。酒店草莓商品在公告发布后到酒店网站预约
  • 支付：滋滋糖饼 (Jjoljjol Hotteok / 쫄쫄호떡) 刷卡标示为"无"，新堂洞千红豆粥 (Sindangdong Cheon Patjuk / 신당동천팥죽)、老式红豆粥店 (Yetnal Patjukjip / 옛날팥죽집)、申家 (Shingane / 신가네) 可刷卡(VisitKorea)。路边摊的支付方式官方上无法确认 — #527 韩国支付系统
  • 点餐：语言不通时见 #1339 点餐礼仪
  • 交通：群山、清州、全州见 #1297 高速·城际巴士手册，首尔市内见 #1298 三种交通卡选择。群山一日路线见 #1108 群山KTX两天一夜

⚠ 常见错误4则

1. "冬天去草莓节" — 2026年三个草莓节都在3~4月举行(VisitKorea)

2. "烤红薯只能在路边摊买" — 现在便利店、地铁站内也有卖(VisitKorea)

3. "鲷鱼烧1,000韩元一袋" — 2020年就已经是1,000韩元2~3个(Korea.net)。现价到现场看

4. "周一去杨平、城邑喝红豆粥" — 文湖里红豆粥 (Munhori Patjuk / 문호리팥죽) 和济州老式红豆粥 (Yetnal Patjuk / 옛날팥죽) 周一休息(VisitKorea)
