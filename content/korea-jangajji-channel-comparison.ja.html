🍱 4チャンネル徹底解説

🍱 韓定食おかわり無料 (한정식 무한 리필)

コアバリュー：おかずのおかわり無料が一番人気 + チャンアッチフルセット。

  • おすすめの店：
  • 新羅ホテルのラヨン (La Yeon / 라연)(ミシュラン三つ星) — 伝統的
  • サムチョンガク (Samcheonggak / 삼청각) — 伝統的
  • インサドン (Insadong / 인사동) の韓定食レストラン — コスパ良く伝統的
  • 価格の目安：韓定食コース40,000~150,000ウォン(約4,400~16,700円)(チャンアッチ無料込み)
  • 営業時間：11:30~22:00
  • 観光客への親しみやすさ：★★★★

🍚 カジョンシク・ペクパン (가정식 백반、家庭料理定食)

コアバリュー：家庭の味のコスパ良さ + チャンアッチ2~3種 + フルセット。

  • おすすめの店：
  • チョンノ (Jongno / 종로)・カンナム (Gangnam / 강남)・ミョンドン (Myeongdong / 명동) のペクパン店 — コスパ良し
  • MZ世代向けのペクパン店 — 家庭の味
  • チェーン店(ハンソッ (Hansot / 한솥)・ポンドシラク (Bon Dosirak / 본도시락)) (#854) — コスパ良し
  • 価格の目安：8,000~15,000ウォン/1人(約880~1,650円)(チャンアッチ込み)
  • 営業時間：11:00~22:00
  • 観光客への親しみやすさ：★★★★(コスパ良し)

🛒 市場の老舗 (시장 노포)

コアバリュー：老舗(ノポ、노포、30年以上続く伝統的な食堂)の伝統 + 1年熟成の本場の味 + 試食OK。

  • おすすめ市場：
  • 広蔵市場 (Gwangjang Market / 광장시장) のチャンアッチ横丁 — 老舗の本場の味
  • 南大門市場 (Namdaemun Market / 남대문 시장) のおかず専門店 — コスパ良く本場の味
  • 全州韓屋村 (Jeonju Hanok Village / 전주 한옥마을、韓屋(ハノク、한옥)は韓国の伝統家屋) — 1年熟成の本場の味
  • 価格の目安：1パック5,000~20,000ウォン(約550~2,200円)
  • 営業時間：09:00~22:00
  • 観光客への親しみやすさ：★★★(老舗の雰囲気)

🛍 スーパー・免税店 (마트·면세점)

コアバリュー：真空パック + 通関も安心 + 帰国のお土産で一番人気。

  • おすすめの店：
  • イーマート (E-Mart)、ロッテマート (Lotte Mart)、ホームプラス (Homeplus) — 真空パック
  • 仁川空港 (Incheon Airport / 인천공항)、金海空港 (Gimhae Airport / 김해공항) の免税店 — タンムジ (danmuji / 단무지)、きゅうりのチャンアッチ (오이장아찌)(少量パック)
  • 価格の目安：1パック3,000~10,000ウォン(約330~1,100円)
  • 営業時間：スーパー = 10:00~22:00 / 免税店 = 06:00~22:00
  • 観光客への親しみやすさ：★★★★★(真空パック、一部英語表記あり)
  • 帰国時の通関：1リットル未満OK / 液体100ml規定あり

⚠ 外国人観光客がよくする5つの勘違い

1. 「4チャンネルはだいたい同じ」：価格・マニア度・持ち帰りやすさは全く異なる。無料 = 韓定食 / コスパ良し = カジョンシク・ペクパン / 老舗伝統 = 市場 / お土産 = スーパー。

2. 「韓定食のおかずは別料金」：韓定食のおかずはおかわり無料(チャンアッチ込み)。

3. 「市場の老舗は英語が通じる」：市場の老舗は韓国語のみ・伝統的——翻訳アプリを用意しておこう。

4. 「真空パックは通関できない」：真空パックは通関できる(1リットル未満、液体100ml規定に従う)。

5. 「VAT還付は受けられない」：スーパーでの買い物はVAT還付の対象(5万ウォン以上で即時還付)。

⚙ よくある質問8選

1. 最初に買うべきチャンアッチのチャンネル：韓定食おかわり無料(1位、無料) → スーパー(お土産)。

2. インスタ・vlog映え：韓定食のおかずフルセット(1位)・広蔵市場のチャンアッチ横丁。

3. MZトレンド：コスパ良い韓定食(1位)・MZ世代カフェのチャンアッチアレンジ料理。

4. デート・記念日：韓定食おかわり無料(伝統的)。

5. 家族連れ：カジョンシク・ペクパン + 韓定食。

6. アレルギー・妊娠中：「チャンアッチ6種完全ガイド」(#867) の注意事項を参照。

7. 支払い・チップ：カードOK / 市場 = 一部現金のみ / チップ不要。

8. VAT還付：スーパー = 対象(5万ウォン以上で即時還付)。

⚠ 医療・安全・食事に関する注意事項

4チャンネルのチャンアッチはいずれも日常的な食べ物。妊婦・子ども = OK(辛さは控えめに調整可能)。アレルギー(しょうゆのグルテン・唐辛子)は事前に申告すること。食中毒が疑われる場合は☎ 1339(医療相談、英語対応あり)へ。本ガイドは一般的な情報であり、医療アドバイスではない。

食事制限への対応：

  • ハラール・コーシャ：4チャンネルとも植物性食材 = OK。
  • ベジタリアン・ヴィーガン：4チャンネルとも植物性食材 = OK。
  • グルテンフリー：しょうゆにはグルテンが含まれる → たまり醤油で代用可。
