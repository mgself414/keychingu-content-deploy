⚠ 외국인 자주 실수 5가지

1. "한방 = 한국인만": 한방 = 외국인 영어 OK 한방병원 (자생·경희대·함소아) + 외국인 의료관광 1번지 + #401 통합 풀세트 + #528·#401 통합.

2. "침 = 위험": 침 = 외국인 영어 OK + KAOM (한의학회) 인증 + 무균 1회용 + 외국인 매니아 1번지 + #401·#405 통합.

3. "한약 = 비쌈": 한약 = 첩약 (1주 10~30만원) + 녹용·인삼 (외국인 럭셔리 #406) + 외국인 매니아 1번지 + #406·#142 통합.

4. "동의보감 = 박물관만": 동의보감 = UNESCO 세계기록유산 (2009) + 외국인 정통 매니아 1번지 + 한의학 풀세트 + #377·#509·#534 통합.

5. "한방 보험 = 안됨": NHIS = 한방 일부 적용 (외국인 거주) + 외국인 의료관광 매니아 1번지 + 사상의학·체질 검사 + #528·#252·#538 통합.
