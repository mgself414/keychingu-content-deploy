🍽チャンネル別ワークフロー

Type A — MZ 韓国料理カフェ・明太子プレミアム

  • シグネチャー：即時・MZインスタ#1
  • 時間: 11:00～22:00
  • 価格：12,000〜30,000ウォン/ 1人
  • メニュー：明太子パスタ・トースト・MZビビンバ・デザート
  • おすすめ店: ソンス・江南・梨泰院・弘大MZカフェ
  • 外国人親和性: ★★★★★ (MZ #1・テーブルリングアプリ)

Type B — ニューウェーブ韓国料理 (Bib Gourmand)

  • シグネチャー: 伝統的なfusion・モダンplating・ミシュランおすすめ
  • 時間: ランチ・ディナー（予約推奨）
  • 価格：50,000〜120,000ウォン/ 1人
  • 外国人親和性: ★★★★★ (グローバル)

Type C — ミシュランファインダイニング（1～3スター）

  • シグネチャー: ラグジュアリー・ミシュラン・グローバル #1
  • 時間: ランチ・ディナー（1～3ヶ月前予約必須）
  • 価格: 100,000~250,000ウォン/1人(コース) / lunch 50,000~80,000ウォン
  • おすすめ: ミングルス(2スター)・正式堂(1スター)・ラヨン(3スター)・クォン・スクス・コード・オンジウム・インプレッション・一日
  • 外国人親和性: ★★★★★ (英語・グローバル正統)
  • ドレスコード：スマートカジュアル以上

Type D — MZ 修飾式モダン

  • シグネチャー：伝統的な本物の+モダンな plating
  • 時間: ランチ・ディナー（予約推奨）
  • 価格：60,000〜150,000ウォン/ 1人（コース）
  • 外国人親和性: ★★★★

🌟 ミシュラン予約・マナーマトリックス

ミシュラン予約（1〜3ヶ月前）

  • 方法:
  • 公式サイト予約（英語OK）
  • ホテルコンシェルジュ（5つ星） — 事前登録OK
  • MZ予約アプリ（キャッチテーブル・テーブルリング・OpenTable）
  • 事前期間:
  • ラヨン（3スター）= 2〜3ヶ月
  • ミングルズ・正式堂(1～2スター) = 1～2ヶ月
  • Bib Gourmand = 2～4週

###ミシュランマナー

  • ドレスコード：スマートカジュアル以上（ショートパンツ・スリッパX）
  • 携帯電話: 無音・フラッシュX (写真OK)
  • 無料試食: 一部店舗事前メニュー試食
  • サービス料: 10%一部(韓国ミシュラン=サービス料+税込)

Lunch vs Dinner コスパ

  • Lunch: 50,000～80,000ウォン（コスパ）
  • Dinner：100,000〜250,000ウォン（フルコース）

⚠外国人の頻繁なミス7つ

1. 「ミシュラン=即時」: ミシュラン=1～3ヶ月の事前予約必須。

2. "ドレスコードX": ミシュラン= スマートカジュアル以上・ショートパンツ・スリッパX。

3. "lunch = 一般": ミシュラン lunch = 50,000～80,000ウォンのコスパ比。

4. 「明るさ＝コスパ」：明太子プレミアム＝MZ#1・パスタ・トースト。

5. "MZカフェ=インスタント": MZカフェ=テーブル化アプリの事前推奨。

6. "限定式=本物": MZの限定式のモダン= 伝統+モダンplating。

7. "サービス料 X": ミシュラン = サービス料 10% 一部・計算書確認。
