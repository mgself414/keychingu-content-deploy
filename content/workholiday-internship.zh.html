🎯 为什么是外国人打工度假·实习完美指南？

对于在韩国长期停留的外国爱好者来说，20~35岁间隔年 (gap-year)·职业转型 (career change) 的首要痛点就是F-2-2 打工度假 (Working Holiday) 和 D-10-3 实习 (Internship)。本篇是 #248 外国人签证 (Visa) 深度解析的后续篇章 — 专为打工度假和实习定制的完整攻略。

⚠ 外国人常犯的5种错误

1. "K-ETA (韩国电子旅行授权) = 可以工作": K-ETA (Korea Electronic Travel Authorization)·免签 (Visa-free) 90天 = 仅限旅游·短期停留。若要工作，则需要F-2-2·E-2·E-7·E-9·D-10-3等单独签证 (Visa)。

2. "F-2-2 打工度假 (Working Holiday) = 所有人都可以": F-2-2 = 18~30岁 + 27个符合资格的国家 + 每年一次大使馆 (Embassy) 抽签 + 外国爱好者首选 (美国1,000名·加拿大4,000名·澳大利亚1,500名配额 (Quota))。

3. "D-10-3 实习 (Internship) = 符合资格": D-10-3 = D-2 (留学) 毕业后3~6个月实习 + 外国爱好者在韩国IT·企业实践的首选。

4. "外国人 = 免除税金 (Tax)·社会保险 (Social Insurance)": 外国人 = 所得税源泉征收 (Withholding Tax) + 6个月以上健康保险 (Health Insurance) 强制加入 + 外国爱好者首要关注 (不履行时签证 (Visa) 更新将被拒绝)。

5. "非法职业介绍 (Illegal job placement) = 常见": 韩国首要保护外国人 = 非法职业介绍 (Illegal job placement)·虚假TEFL (Fake TEFL)·签证逾期滞留 (Visa overstay) 将受到处罚 + 可向 Hi Korea 1345·KCTU 外国人支部举报。

① F-2-2 打工度假签证 (Visa) (4)

1. F-2-2 打工度假签证 (Visa) ★ 韩国首选

  • 外国人 ★: ◎◎ — 18~30岁·1~2年·非专业工作可
  • 资格: 18~30岁 (部分国家35岁) + 本国居住 + 一定资金 (建议USD $2,000+)
  • 申请: 本国韩国大使馆 (Embassy)·每年一次抽签·外国人爱好者首选

2. F-2-2 27个符合资格的国家

  • 外国人 ★: ◎◎ — 美·加·澳·新·欧盟·日·台湾·香港·以色列等
  • 爱好者: 澳大利亚1,500名·加拿大4,000名·美国1,000名·日本10,000名 (配额 (Quota))

3. F-2-2 申请 (大使馆 (Embassy)·每年一次抽签)

  • 外国人 ★: ◎◎ — 本国大使馆 (Embassy) + 每年1~3月抽签
  • 外国爱好者提前准备的首选

4. F-2-2 持有后的活动

  • 外国人 ★: ◎◎ — 英语讲师·服务业·外国人友好店铺
  • 1~2年自由活动 + 外国爱好者长期停留的首选

② D-10-3 实习签证 (Visa) (2)

5. D-10-3 实习 (Internship)·实践签证 (Visa) ★ 韩国首选

  • 外国人 ★: ◎◎ — 毕业后3~6个月实践·外国人爱好者
  • 对象: 韩国D-2 (留学) 毕业生 + 外国爱好者首要关注

6. D-10-3 与 D-10-1 的区别

  • D-10-1 = 求职签证 (Visa) 6个月~2年 (#248)
  • D-10-3 = 实习 (Internship)·实践 3~6个月 + 企业·研究所爱好者

③ 签证 (Visa) 扩展·转换 (2)

7. 外国人交换学生 (Exchange Student)·D-4 语言研修 (Language Study)

  • 外国人 ★: ◎ — 韩国语言学校 6个月~2年
  • 外国爱好者D-2 (留学) 升学前阶段

8. 签证 (Visa) 转换

  • 外国人 ★: ◎◎ — K-ETA (韩国电子旅行授权)→C-3→E-2 (英语讲师)·D-2→E-7 (专业人士)·F-2-2→F-6 (婚姻) 首选

④ 税金 (Tax)·社会保险 (Social Insurance)·劳动 (4 + 额外4项)

9. 外国人税金 (Tax) (所得税·劳动所得税源泉征收 (Withholding Tax))

  • 外国人 ★: ◎◎ — 外国爱好者首要关注
  • 所得税: 本国与韩国的避免双重征税协定 (Double Taxation Agreement) (DTA·美·加·澳·日·欧盟等)

10. 外国人社会保险 (Social Insurance)

  • 外国人 ★: ◎◎ — 停留6个月以上时强制加入
  • 健康保险 (Health Insurance) (国民健康保险公团 (National Health Insurance Service))·国民年金 (National Pension) (外国人参保者在韩国居住的爱好者)

11. 外国人劳动法 (Labor Law)

  • 外国人 ★: ◎◎ — 最低工资 (Minimum Wage) 9,860韩元 (₩9,860, 约$7.2 / 52 RMB / 1,080 JPY) (2024) + 每周52小时 (52-hour work week) + 保护外国人爱好者
  • 外国爱好者首要权利

12. 外国人防诈骗

  • 外国人 ★: ◎◎ — 非法职业介绍 (Illegal job placement)·虚假TEFL (Fake TEFL)·签证逾期滞留 (Visa overstay) 将受到处罚
  • 外国人安全首要举报: Hi Korea 1345·KCTU 外国人支部

+ 额外4项

  • Hi Korea 1345 外国人综合指南 — 英·中·日·阿拉伯·俄语 24小时 (24h) 外国爱好者友好
  • 外国人劳动组合 (KCTU 外国人支部) — 韩国首要保护外国人
  • 外国人IT实习 (Internship) (#326 印度IT·#278 数字游民) — 板桥 (Pangyo / 판교)·江南 (Gangnam / 강남) 爱好者
  • 外国人英语讲师爱好者 (TEFL·TESOL #322 英语圈) — E-2 与 F-2-2 的区别
