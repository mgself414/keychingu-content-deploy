한국 고기 반찬 주문·식사 워크플로우 — 가정식 한 상부터 한정식 주요리까지

> 부제: 외국인 관광객용 5-step 워크플로우 + 반찬 무료 무제한 + 한식 매너·페어링 팁

ISSUE 03 · #853 · 2026-06-09

🎯 왜 한국 고기 반찬 워크플로우 가이드인가

[#852 고기 반찬류 6종 매트릭스](#852) 알아도 — 주문·식사·매너는 별개. 한국 고기 반찬은 (a) 가정식 한 상 (반찬 5~7종 풀세트 = 가성비 #1) (b) 한정식 주요리 (6단계 코스 = 격식) (c) 체인 (제육·불고기 전문) (d) MZ 카페 (트렌디 변형). 외국인은 (1) 반찬 무료 무제한 모름 (2) 한 상 차림 페어링 모름 (3) 한식 매너 (그릇 들지 않기) 모름 (4) 갈비찜 뼈 처리 모름. 본 가이드는 5-step + 매너 매트릭스 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 매장 type 선택 가정식 / 한정식 / 체인 / MZ 카페 즉시 가성비·정통·트렌디 목적
2️⃣ 메뉴 주문 단품 OR 한 상 차림 + 밥 2~5분 "안 맵게" 요청 가능
3️⃣ 받기·반찬 세팅 메인 + 반찬 5~7종 + 밥 + 국 5~10분 반찬 무료 무제한 리필
4️⃣ 식사·매너 메인 + 반찬 페어 + 한식 매너 30~60분 그릇 식탁 두기·소리 X
5️⃣ 결제 카드 OK / 호텔 = 봉사료 10% / 팁 X 1~3분 카카오페이·삼성페이 OK

> 총 소요 시간: 가정식 = 30~45분 / 한정식 = 1.5~2.5h

🍱 메뉴별 페어링 + 한 상 차림

가정식 한 상 (반찬 5~7종 풀세트)

메인 정통 반찬 페어
갈비찜 잡채 + 장조림 + 나물 (시래기·고사리·콩나물) + 김치 + 깍두기 + 밥 + 국
불고기 잡채 + 나물 + 김치 + 쌈채소 + 밥 + 된장찌개
제육볶음 잡채 + 김치 + 상추쌈 + 된장찌개 + 밥
잡채 (단품) 김치 + 깍두기 + 밥 (가성비 점심)

한정식 6단계 코스 ([#831 한정식](#831) 참고)

1. 죽 (입맛 돋움)

2. 전 (전채)

3. 주요리 = 갈비찜·불고기 (메인)

4. 탕 (국)

5. 밥 + 반찬 12+종

6. 후식 (약과·수정과)

🌶 매운맛 가감 가이드

메뉴 매운맛 단계 외국인 가감
갈비찜 안 매움 입문 #1
잡채 안 매움 입문 #1
불고기 안 매움 입문 #1
장조림 안 매움 (꽈리고추 약간) 입문 OK
나물볶음 안 매움 입문 OK
제육볶음 중-매움 "안 맵게" 요청 가능

외국인 영어 발화 샘플

  • "갈비찜 하나" = "One galbi-jjim, please"
  • "불고기 + 밥" = "Bulgogi with rice, please"
  • "잡채 (덜 달게)" = "Japchae, less sweet, please"
  • "제육 안 맵게" = "Less spicy jeyuk, please"
  • "반찬 더 주세요" = "More side dishes, please"
  • "갈비찜 뼈 어떻게 먹어요?" = "How do I eat the rib bones?"
  • "카드 돼요?" = "Card accepted?"

🙏 한식 매너 핵심 7가지

한국 식사 매너 (전통)

1. 어른 먼저: 어른이 수저 들면 시작

2. 수저 사용: 젓가락 (반찬) + 숟가락 (밥·국)

3. 그릇 들지 않기: 그릇 = 식탁에 두고 먹기

4. 소리 X: 후루룩·쩝쩝 회피

5. 밥·국 = 숟가락

6. 반찬·전 = 젓가락

7. 갈비찜 뼈: 손으로 잡고 먹기 OK (정통)

반찬 시스템

  • 모든 한식당 = 무료 무제한 리필 ("더 주세요" 요청 OK)
  • 종류: 김치 3종·잡채·나물·장조림·전·구이 등
  • MZ 매장 = 키오스크 + 셀프 코너도 있음

⚠ 외국인 자주 실수 7가지

1. "반찬 = 1회": 무료 무제한 리필. 요청 OK.

2. "그릇 들기 = OK": 한식 = 그릇 식탁에 두고 숟가락·젓가락 사용.

3. "갈비찜 뼈 = 젓가락": 갈비찜 뼈 = 손으로 잡고 먹기 (정통).

4. "잡채 = 면류 단품": 잡채 = 당면 + 야채 + 고기 풀세트.

5. "제육 = 불고기 같음": 제육 = 매콤 돼지 / 불고기 = 달콤 소고기.

6. "안 매운맛 X": 제육·매운 메뉴 = "안 맵게" 요청 OK.

7. "한정식 = 비싸기만": 가정식·한식당 한 상 차림 = 12,000~25,000원 가성비.

⚙ FAQ 8개

1. 첫 한식 = 어떤 메뉴: 불고기 + 잡채 (글로벌 + 정통).

2. 인스타·vlog: 한정식 갈비찜·잡채 MZ vlog·제육볶음 매니아.

3. MZ 트렌드: 제육볶음·트러플 잡채·궁중 불고기.

4. 가족 동반: 가정식 한 상 차림·잡채·갈비찜.

5. 채식·할랄·코셔: 나물볶음 (#1) + 사찰음식·MZ 비건 잡채.

6. 알레르기: 콩·해산물·견과류 사전 고지.

7. 결제·팁: 카드 OK / 호텔 = 봉사료 10% + 부가세 10% / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

고기 반찬류 = 일반 한식. 임신부 = 충분히 익혀서 OK. 어린이 = 매운 제육 가감·갈비찜 뼈 주의. 알레르기 (콩·해산물·견과류) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 = 비할랄. → 나물볶음·사찰음식·이태원 할랄 한식 매장.
  • 채식·비건: 나물볶음·MZ 비건 잡채 = OK / 사찰음식 한정식 = #1.
  • 글루텐 free: 간장 (밀) 多. 사전 매장 확인.
