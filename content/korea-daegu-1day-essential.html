🎯 왜 대구 가이드인가

대구 (Daegu) = 한국 4대 광역시·인구 240만·섬유·약령시·근대 역사 1번지. 외국인 페인포인트 = (a) "대구 = 안 들러도 됨" 잘못된 인식 (서울·부산·제주 다음 후순위) (b) KTX 1시간 50분 서울→대구 (당일 가능 X·1박 권장) (c) 약령시 350년 한약 거리·UNESCO 후보 (d) 근대골목 골목투어 (1900년대 청라언덕·계산성당) (e) 서문시장 야시장 (한국 #3 야시장) (f) 팔공산 갓바위 (한국 기도 1번지·외국인 영적 매니아 #1).

본 가이드는 4축 12 시그니처 + 1일 풀데이 코스 + 외국인 영어 발화 + 결제·언어·교통.

🏛 4축 deep dive

① 약령시 한약 거리 (350년)

  • 시그니처: 한국 #1 한약 거리 (1658년~)·UNESCO 인류무형문화유산 후보 (한약 전통)
  • 매장: 약령시·약전골목·약령시 박물관·한방차 카페
  • 외국인 친화도: ★★★★ (한방 매니아·웰니스 fit)
  • 추천 매니아: 한방차 시음·약재 비빔밥·한방 체험
  • 시기: 매년 5월 약령시 축제 (한방차·한복·전통 음악)

② 근대골목 (1900년대 역사 walking)

  • 시그니처: 청라언덕·계산성당·3·1만세운동길·김광석 거리 4 cluster
  • 김광석 거리: 가수 김광석 (1964-1996) 추모 거리·매년 10월 김광석 다시부르기 콘서트
  • 외국인 친화도: ★★★★★ (외국인 영문 시그너·골목투어)
  • 추천 매니아: 골목투어 (1.5h·5,000~10,000원/인)
  • 시기: 연중 (봄·가을 베스트)

③ 서문시장 (한국 #3 전통시장)

  • 시그니처: 한국 #3 야시장·100년+·칼국수·납작만두·갈비찜 시그니처
  • 야시장: 매일 19:00-23:30·외국인 #1 야간 매니아
  • 외국인 친화도: ★★★★★ (영문 메뉴 일부·결제 카드·픽업 OK)
  • 추천 매니아: 야시장 코스 (3-4시간·30,000~50,000원/인)

④ 팔공산 갓바위 (한국 #1 기도)

  • 시그니처: 팔공산 (1192m)·갓바위 (대좌불·한국 #1 기도)
  • 매니아: 1년 1소원 기도 1번지 (수능·취업·결혼·건강)
  • 외국인 친화도: ★★★ (영적·MZ 매니아·기도 체험)
  • 이동: 대구 동대구역·KTX 종점·시내버스 30분
  • 시기: 봄·가을 베스트·겨울 영하 추위 주의

🚄 외국인 교통 + 결제 + 언어 가이드

교통

  • 서울→대구: KTX 동대구역 1시간 50분 (44,000원·왕복 88,000원)
  • 대구 시내: 대구도시철도 1·2·3호선·시내버스
  • 약령시: 대구도시철도 1호선 중앙로역
  • 서문시장: 대구도시철도 3호선 서문시장역
  • 팔공산 갓바위: 시내버스 401번 (동대구역에서 40분)

결제

  • 카드 OK: 대부분 한식당·체인·시장 일부
  • 현금 사용: 약령시 노포·시장 일부
  • VAT 환급: 면세 매장 일부 (Tax Refund 표시)
  • 팁 X: 한국 전국 표준

언어

  • 영문 메뉴: 동성로·근대골목 외국인 친화 매장 多
  • 영문 안내: 약령시 박물관·계산성당·서문시장 야시장 일부
  • 응급: ☎ 1339 (의료, 영문) / ☎ 1330 (관광 통역)

⚠ 외국인 자주 실수 5가지

1. "대구 = 안 가도 됨": KTX 1시간 50분·당일 OR 1박 매니아 코스. 한국 4대 광역시 #1 매니아 매트릭스 누락 시 한식·전통 시그니처 누락.

2. "약령시 = 한약만": 약령시 = 한방차 + 약재 비빔밥 + 한방 카페 + 매년 5월 축제 + 박물관. 한방 매니아 + 웰니스 fit.

3. "근대골목 = 단순 산책": 청라언덕 1900년대 선교사 사택·계산성당 1902년 로마네스크·김광석 거리 매니아 K-pop fit.

4. "서문시장 야시장 = 다른 야시장과 동일": 서문시장 = 한국 #3 야시장·매일 19:00-23:30·납작만두·칼국수·갈비찜 시그니처.

5. "팔공산 갓바위 = 그냥 산": 갓바위 = 한국 #1 기도 1번지·1년 1소원 매트릭스 (수능·취업·결혼·건강)·영적 매니아.

⚙ FAQ 6개

1. 외국인 입문 1순위: 1일 코스 = 약령시 + 서문시장 야시장 + 근대골목 + 김광석 거리.

2. KTX vs SRT: KTX 동대구역 1시간 50분·SRT 동대구역 1시간 45분·요금 비슷·서울역 시작 vs 수서역 시작.

3. 숙박: 동대구역·동성로 호텔 1순위 (외국인 친화). 한옥 스테이 = 약령시·근대골목 인근 일부.

4. 시즌: 봄 (4~5월 약령시 축제) + 가을 (10월 김광석 다시부르기 콘서트) = 외국인 매니아 1순위.

5. 알레르기: 약령시 한약·약재 비빔밥 = 약초 알레르기 사전 고지 + 한방의 사전 상담 권장.

6. 추천 페르소나: 가족·문화 매니아 = 근대골목 + 약령시 / MZ·매콤 매니아 = 서문시장 야시장 + 동성로 / 영적·시니어 매니아 = 팔공산 갓바위.

⚠ 의료·안전·식이 disclaimer

약령시 한약·약재 = 일부 약물 상호작용 (와파린·당뇨 약 등) — 사전 의사 상담. 임신부 = 한방 약재 일부 금기. 알레르기 (약초·견과류·새우젓·고춧가루) 사전 고지. 식중독·복통 ☎ 1339.

식이 제한 fallback:

  • 할랄·코셔: 서문시장 야시장 일부 비할랄 (돼지) → 약령시 한방차·약재 비빔밥 (채식 옵션) = 할랄 가능
  • 채식·비건: 약령시 한방차·약재 비빔밥 = 채식 OK / 서문시장 = 비채식 多
  • 글루텐 free: 약령시 한약·서문시장 일부 OK·칼국수·납작만두 = 글루텐 함유

✈️ 외국인 페인포인트 #1 — 1박 vs 당일

  • 당일: KTX 1시간 50분 × 2 = 3시간 40분 왕복·실질 매장 6-8시간·핵심 4축 cover 가능
  • 1박: 약령시·근대골목 골목투어·서문시장 야시장 풀세트·팔공산 갓바위 다음 날·매니아 매트릭스 풀
  • 추천 시작: 당일 → 매니아 시 1박 (2번째 방문 매니아·재방문 단골 노하우)
  • 숙박: 동성로·동대구역 호텔 60,000~150,000원/박 (3-4성)
