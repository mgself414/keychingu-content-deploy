⚠ 外国游客常犯的5个错误

1. “统营 (Tongyeong / 통영) = 哪里都一样”: 统营 (Tongyeong / 통영) = 韩国第一渔业城市 (Korea's #1 fishery town) + 东陂浪壁画村 (Dongpirang Mural Village / 동피랑 벽화마을)·江口湾 (Gangguan / 강구안)·中央市场 (Jungang Market / 중앙시장) + 外国游客Instagram首选。

2. “丽水 (Yeosu / 여수) = KTX终点”: 丽水 (Yeosu / 여수) = KTX湖南线终点站 (3小时) + 韩国第一夜海 + 2012丽水世博会 + 外国游客爱好者第一地。

3. “南海 (Namhae / 남해) = 小岛”: 南海 (Namhae / 남해) = 韩国第二大岛屿 + 多来伊村 (Daraengi Village / 다랭이마을)·菩提庵 (Boriam / 보리암)·锦山 (Geumsan / 금산) + 外国游客爱好者第一地 + 落日第一地。

4. “巨济 (Geoje / 거제) = 无法前往”: 巨济 (Geoje / 거제) = 韩国第一大岛屿 (仅次于济州 (Jeju / 제주)) + 外岛 (Oedo / 외도)·蝉鸣山 (Maemisan / 매미산) + 外国游客爱好者。

5. “晋州 (Jinju / 진주) = 不近”: 晋州 (Jinju / 진주) = 南海海岸入口枢纽 + 晋州城 (Jinju Fortress / 진주성)·晋州南江 (Namgang / 남강) 夜景 + 外国游客爱好者第一地。
