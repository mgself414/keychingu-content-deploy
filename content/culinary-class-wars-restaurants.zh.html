在网飞看到的那位主厨的餐厅 — 黑白厨师首尔巡礼指南

副标题：看过《黑白厨师：料理阶级大战》(Culinary Class Wars) 第1·2季，就能在首尔亲口吃到那些料理。从冠军"那不勒斯黑手党"的维苏威 (Vesuvio / 베수비오)，到圣水洞 (Seongsu / 성수동)·道山 (Dosan / 도산) 集群动线全覆盖 — 但首先要搞懂韩式订位大战。含订位App·酒水政策·禁止拍摄规则解说。

ISSUE · #1317 · 2026-08-22

🎯 为什么是"主厨餐厅巡礼"

如果说K-Drama取景地巡礼 (#222) 追的是"画面里的那个地方"，这一篇追的就是"在那位主厨的厨房里，吃到画面里的那道料理"。《黑白厨师》是一档横扫网飞全球排行榜的韩国生存综艺 — 继第1季 (2024) 之后又推出第2季，出演主厨们的餐厅由此成为韩国美食之旅的新坐标。节目播出后订位难度暴涨的店不在少数，"提前做功课"和"临时上门"之间的差距，在这个类别里最大。

① 先打赢订位战 — 韩式高端餐饮订位3大铁律

1. 订位App认准CatchTable — 人气主厨餐厅大多只通过这一个App开放订位。每月固定一天开放下个月的预约，热门店以分钟为单位售罄。有Global版App (Catch Table Global)，外国信用卡也能注册。

2. 提前看清酒水·押金政策 — 像冠军餐厅维苏威 (Vesuvio / 베수비오) 这样强制点酒水(周末·公休日强制整瓶)的店确实存在。防止放鸽子的订位押金也很常见。

3. 确认拍摄规则 — 越来越多餐厅禁止商业拍摄(用于YouTube·Reels变现)。个人留念用照片大多没问题，但店内有告示就要遵守。

订位·排队文化的全貌，#1274《韩国美食店排队·订位零慌乱手册》会按App界面逐屏解说。

② 首尔巡礼清单 — 已核实的8家锚点

1. 维苏威 (Vesuvio / 베수비오) — 权成俊 主厨 · "那不勒斯黑手党" · 第1季冠军

  • 第1季冠军的那不勒斯料理。从圣水洞 (Seongsu / 성수동) 的"Via Toledo"扩大搬迁至若水洞 (Yaksu / 약수동)，套餐结构也随之升级。
  • 首尔订位难度顶级 — CatchTable一开放即刻秒罄。强制点酒水(平日可单杯·周末须整瓶)。未成年人不可单独结伴入场，禁止商业拍摄。
  • 行程弹性不大就别硬约 — 下面的休闲路线是替代方案。

2. 崔点 & 中央减速机 (崔铉硕)

  • 坐镇评委席的那位主厨。崔点 (Choi.Dot / 쵸이닷)(道山大路 / Dosan-daero / 도산대로)是他的招牌Fine Dining，中央减速机 (Jungang Gamsokgi / 중앙감속기)(圣水洞)则是厂房改造的休闲店 — 同一位主厨的两种面貌，可以任选其一。

3. 甜蜜蜜 (Tian Mimi / 티엔미미) (郑智善)

  • "点心女王"的中餐。走的是与韩式中华料理 (#1214) 不同的正统点心路线。

4. 弘报阁 (Hongbogak / 홍보각) (余庆来)

  • 新论岘 (Sinnonhyeon / 신논현) 高端中餐。是韩国中餐主厨谱系的顶点 — 适合带父母同行·正式场合的选择。

5. 特里德 (TRID / 트리드) (姜承元 · "三星" / Triple Star)

  • 节目里话题度最高的绰号之一。走当代餐饮 (Contemporary Dining) 路线。

6. 内基莱夫 (Negi Live / 네기라이브) (张浩俊)

  • 位于圣水洞。现场吧台形式 — 独自旅行也能自在坐吧台。

7. 埃维特 EVETT (约瑟夫·利泽伍德 / Joseph Lidgerwood)

  • 澳大利亚出身的主厨用韩国食材(酱·发酵)做的Fine Dining — 因为是"外国人眼中的韩国味道"这种反向视角，反而更容易和外国游客对上话。位于新沙洞 (Sinsa / 신사동)。

8. 圣水小菜铺 (Banchan-gage / 반찬가게) (宋夏斯兰 · "小菜主厨")

  • 靠节目走红的小菜主厨在圣水洞开的店。不是Fine Dining，而是走韩国日常饮食(小菜)体验路线 — 是不用担心预算、可以先从这里开始巡礼的入口。

③ 集群动线 — 一天怎么串

  • 圣水洞轴线：中央减速机 → 宋夏斯兰小菜 → 内基莱夫。中间空档用#263 圣水洞50选里的咖啡馆·选品店来填。
  • 道山·新沙轴线：崔点 → 埃维特。和道山公园散步、#1111 约会路线的江南片区动线重合。
  • 中餐轴线：甜蜜蜜 → 弘报阁。配合#1214 韩式中华料理篇一起吃，"韩式 vs 正统"能一次理清。

④ 预算矩阵

档位 店 人均感觉
入门 (₩1万~) 圣水小菜铺 无需订位·日常餐
休闲 (₩3~6万) 中央减速机·内基莱夫 当天~一周内可订
Fine Dining (₩10万~) 崔点·特里德·埃维特·甜蜜蜜·弘报阁 提前2~4周订位
顶级难度 维苏威 开抢即秒罄 + 强制点酒水

价格会随套餐改版变动 — 以订位时CatchTable上的标示为准。

⑤ 首尔之外的单点 — 主厨们的地方据点

  • 江陵 (Gangneung / 강릉)：南正锡主厨(白匙组)离开首尔后落脚的城市 — 适合和江陵旅行 (#264 江陵·平昌) 串在一起。
  • 釜山：出演主厨们公认"当下的美食圣地" — 可衔接釜山系列 (#255~)。
  • 沃川 (Okcheon / 옥천)：宋夏斯兰主厨的故乡 — 目前还不在外国游客的动线上，但会是本地美食之旅的下一个候选地。

🧳 提前准备清单(出发前3~4周)

1. 安装CatchTable Global App + 注册信用卡

2. 确认目标餐厅的订位开放日(店铺IG公告最快)

3. 为首选落空做准备 — 把同一集群的休闲店设为备选

4. 确认酒水政策·着装要求·未成年同行规定

5. 截图保存订位确认短信/App画面(入场时出示)
