한국 죽 주문·해장 워크플로우 — 호텔 조식부터 24h 해장 본죽까지

부제: 외국인 관광객용 5-step 워크플로우 + 해장 매너·페어링·시간대 팁

ISSUE 03 · #859 · 2026-06-09

🎯 왜 한국 죽 워크플로우 가이드인가

#858 죽 6종 매트릭스 알아도 — 주문·해장·페어링은 별개. 한국 죽은 (a) 호텔 조식 (5성급 죽 풀세트) (b) 24h 해장 (본죽·죽이야기 새벽) (c) 한정식 코스 1단계 (잣죽·참깨죽) (d) MZ 카페 (호박 라떼·전복 변형). 외국인은 (1) 호텔 조식 시간대 모름 (2) 해장 = 술 다음날 모름 (3) 한정식 죽 코스 모름 (4) 죽 토핑 (참기름·김·소금) 매너 모름. 본 가이드는 5-step + 해장 매너 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 호텔 조식 / 24h 본죽 / 한정식 / 죽 전문점 즉시 시간대·해장·럭셔리 목적
2️⃣ 메뉴 주문 6종 + 단품 / 코스 1~5분 영문 메뉴·추천 OK
3️⃣ 받기·토핑 죽 + 참기름·김·소금·계란 5~10분 토핑 본인 추가
4️⃣ 먹기·페어링 김치·반찬·차 페어 15~30분 죽 + 김치 정통 페어
5️⃣ 결제 카드 OK / 호텔 = 봉사료 10% / 팁 X 1~3분 카카오페이·삼성페이 OK

총 소요 시간: 호텔 조식 = 1~2h / 24h 본죽 = 15~30분 / 한정식 = 1.5~2.5h

🍚 채널별 워크플로우

Type A — 호텔 조식 (5성급)

  • 시그니처: 신라·롯데·웨스틴·포시즌스 = 죽 6종 풀세트 + 양식 + 일식 + 한식
  • 시간대: 06:30~10:00 (호텔별)
  • 가격: 60,000~120,000원/인
  • 죽 종류: 전복죽·황태죽·잣죽 등 풀세트
  • 외국인 친화도: ★★★★★ (영어·1순위)

Type B — 24h 해장 죽 (본죽·죽이야기)

  • 시그니처: 24h 영업·해장 매니아·체인 가성비
  • 시간대: 24h (일부 매장)
  • 가격: 8,000~18,000원/인
  • 죽 종류: 전복·호박·황태·녹두 등 다양
  • 외국인 친화도: ★★★★ (영문 메뉴·체인)
  • 해장 매니아: 술 다음날 #1

Type C — 한정식 코스

  • 시그니처: 잣죽·참깨죽 = 한정식 6단계 코스 1단계 (입맛 돋움)
  • 시간대: 11:30~22:00 (점심·저녁)
  • 가격: 한정식 코스 (40,000~150,000원)
  • 외국인 친화도: ★★★★ (영문 메뉴 일부)

Type D — 죽 전문점·MZ 카페

  • 시그니처: 전복죽·호박 라떼·MZ 변형
  • 시간대: 10:00~22:00
  • 가격: 12,000~25,000원
  • 외국인 친화도: ★★★★ (영문·MZ)

🍯 토핑·페어링 매트릭스

죽 + 토핑 본인 추가

죽 정통 토핑 외국인 입문
전복죽 참기름·김·소금·계란 정통
호박죽 꿀·잣 (옵션) 달콤
황태죽 참기름·김·계란·소금 정통 해장
참깨죽 꿀 (옵션) 정통
잣죽 꿀 (옵션) 궁중 정통
녹두죽 김·소금 정통

죽 + 반찬·음료 페어

  • 전복죽 + 김치·깍두기 = 한국 정통
  • 호박죽 + 단호박 칩 = MZ 변형
  • 황태죽 + 무국 + 김치 = 강원 해장
  • 한정식 죽 + 한정식 후식 (#831)

🌶 외국인 영어 발화 샘플

  • "전복죽 하나" = "One abalone porridge, please"
  • "황태죽 + 해장" = "Hwangtae porridge for hangover"
  • "호텔 조식 죽" = "Hotel breakfast porridge"
  • "참기름 + 김" = "Sesame oil and seaweed, please"
  • "안 짜게" = "Less salty, please"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "죽 = 환자식": 죽 = 한국 정통 음식 (아침·해장·한정식·럭셔리 모두).

2. "토핑 = 다 들어감": 토핑 (참기름·김·소금) = 본인 추가.

3. "호텔 조식 시간 자유": 호텔 조식 = 06:30~10:00 한정.

4. "24h 본죽 = 한 매장": 24h 본죽 = 체인 매장.

5. "황태죽 = 일반 죽": 황태죽 = 해장 매니아 #1.

6. "한정식 죽 = 단품": 한정식 죽 = 6단계 코스 1단계 (입맛 돋움).

7. "전복죽 = 어디나": 전복죽 = 제주 정통 또는 호텔 럭셔리.

⚙ FAQ 8개

1. 첫 죽 = 어떤 채널: 호텔 조식 (5성급 럭셔리) + 본죽 (해장).

2. 인스타·vlog: 호텔 조식 전복죽·강원 황태죽·한정식 잣죽.

3. MZ 트렌드: MZ 카페 호박 라떼·전복죽 변형.

4. 해장 매니아: 황태죽 (#1) + 본죽 (24h) + 녹두죽 (여름).

5. 호텔 조식 시간대: 06:30~10:00 (호텔별).

6. 알레르기·임신: #858 disclaimer 참조.

7. 결제·팁: 카드 OK / 호텔 = 봉사료 10% / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

죽 = 일반 음식·소화 친화. 임신부·어린이 = OK (뜨거움 주의). 알레르기 (해산물·견과류·계란·꿀) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 잣죽·참깨죽·호박죽·녹두죽 = OK / 전복죽·황태죽 = 어류 (할랄 일부 OK).
  • 채식·비건: 호박죽·참깨죽·잣죽·녹두죽 = 채식 OK / 전복죽·황태죽 = 비채식.
  • 글루텐 free: 6종 모두 쌀 100% = 글루텐 free OK.
