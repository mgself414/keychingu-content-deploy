🎯 왜 UNESCO 풀세트 인덱스인가

한국 UNESCO 풀세트 = 세계유산 15 + 무형문화유산 22 + 세계기록유산 18 + 세계지질공원 5 = 60+ 시그너·외국인 매니아 매트릭스 #1. 외국인 페인포인트 = (a) "한국 UNESCO = 경복궁만" 잘못된 인식 (b) 한국 = 세계 UNESCO 매트릭스 상위 10·매니아 매트릭스 #1 (c) 시그너 + 시즌 + 도시 cross 풀세트 (d) 전국 60편 cluster cross (#1001~#1060) (e) UNESCO + 한복 + 매니아 매트릭스 #1.

🗺 외국인 5 Segment 동선 추천

Segment 1 — 입문 (3박)

  • 서울 + 경주 풀세트: 종묘·창덕궁·불국사·석굴암 = UNESCO 4 시그너
  • 예산: 500,000~800,000원/인

Segment 2 — 매니아 (1주)

  • 서울 + 경주 + 안동 + 공주·부여 = 7 시그너
  • 예산: 1,200,000~2,000,000원/인

Segment 3 — 글로벌 매니아 (2주)

  • 전국 UNESCO 풀세트 + 무형문화유산 시즌: 15+ 시그너
  • 예산: 2,500,000~4,500,000원/인

Segment 4 — 시즌 매니아 (매니아·시즌별)

  • 봄: 연등회 (#1061·4월 매니아 매트릭스 #1)
  • 여름: 강릉 단오제 (#1065·6월)
  • 가을: BIFF + 백제문화제 (10월) + 무형문화유산 매트릭스
  • 겨울: 김장 (#751) + 강원 빙어·송어 매트릭스

Segment 5 — 자연 매니아

  • 제주 화산섬·용암동굴 (#1057·#1058)·한국의 갯벌·한국의 서원 + 산사

  • 세계지질공원 (5): 제주 (#1058)·청송·무등산·한탄강·전북 서해안

⚠ 외국인 자주 실수 5가지

1. "한국 UNESCO = 경복궁": 경복궁 = UNESCO X·창덕궁 = UNESCO·한국 UNESCO 풀세트 60+ 시그너.

2. "UNESCO = 옛 것": 외국인 매니아 매트릭스 #1·MZ + 인스타 매니아.

3. "시즌 = 연중 동일": 무형문화유산 = 시즌 매트릭스 (연등 4-5월·단오 6월·김장 11-12월).

4. "풀세트 = 1박": 2주+ 권장·시그너 매트릭스 매니아 매트릭스 #1.

5. "입문 = X": 3박 = 서울 + 경주 풀세트 = 4 시그너 매트릭스 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: 종묘·창덕궁 + 경주 (불국사·석굴암) = 3박.

2. 매니아 풀세트: 서울 + 경주 + 안동 + 공주·부여 = 7 시그너·1주.

3. 시즌 매트릭스: 연등회 (4-5월)·단오제 (6월)·BIFF·백제 (10월)·김장 (11-12월).

4. 무형문화유산: 시즌 매트릭스 + 사전 일정 확인·매니아 매트릭스 #1.

5. 세계지질공원: 제주 (#1058)·청송·무등산·한탄강 등 5개·자연 매트릭스.

6. 추천 페르소나: 가족 = 서울 + 경주 / MZ = 한복 + 한옥 / 매니아 = 전국 풀세트 + 시즌.
