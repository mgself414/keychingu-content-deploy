韓国粥の注文・二日酔い解消ワークフロー — ホテル朝食から24時間営業のヘジャンチュクまで

副題：外国人観光客向け5ステップワークフロー + ヘジャン(해장 / haejang, 二日酔い解消食)のマナー・ペアリング・時間帯のコツ

ISSUE 03 · #859 · 2026-06-09

🎯 なぜ韓国粥ワークフローガイドが必要か

《韓国粥6種概観》を知っていても、注文・ヘジャン・ペアリングはまた別の話です。韓国粥(죽 / 粥 / juk)は四つのまったく異なる場面に登場します：(a) ホテル朝食(5つ星ホテルの粥フルラインナップ) (b) 24時間営業のヘジャンチュク(ポンジュク(본죽 / Bonjuk)、チュギヤギ(죽이야기 / Juk Iyagi)など明け方まで営業するヘジャンの名店) (c) 韓定食(한정식 / ハンジョンシク)コースの最初の一品(松の実粥、ごま粥) (d) MZ世代(MZ, 韓国でミレニアル世代+Z世代を指す呼び方)カフェ(カボチャ粥ラテ、アワビ粥のアレンジ)。外国人観光客はたいてい(1)ホテル朝食の時間帯を知らない (2)ヘジャン(二日酔い解消食)が「飲んだ翌日に食べるもの」だと知らない (3)韓定食に粥のコースがあることを知らない (4)粥のトッピング(ごま油·海苔·塩)のマナーを知らない、という状況です。本ガイドでは5ステップワークフロー、ヘジャンのマナー、便利な英語フレーズを紹介します。

★ ひと目でわかる5ステップワークフロー

ステップ 動作 時間 外国人観光客向けポイント
1️⃣ チャネルを選ぶ ホテル朝食 / 24時間営業のポンジュク / 韓定食 / 粥専門店 即時 時間帯・ヘジャン需要・贅沢志向に合わせて選ぶ
2️⃣ 注文する 6種 + 単品 / コース 1~5分 英語メニューあり、スタッフのおすすめもOK
3️⃣ 受け取り·トッピング 粥 + ごま油·海苔·塩·卵 5~10分 トッピングは自分で加える
4️⃣ 食べる·ペアリング キムチ·おかず·お茶と合わせる 15~30分 粥 + キムチが定番の組み合わせ
5️⃣ 会計 カードOK / ホテルはサービス料10% / チップ不要 1~3分 カカオペイ(카카오페이)、Samsung Pay OK

所要時間の目安：ホテル朝食 = 1~2時間 / 24時間営業のポンジュク = 15~30分 / 韓定食 = 1.5~2.5時間

🍚 チャネル別ワークフロー

タイプA — ホテル朝食(5つ星)

  • 特徴：シラホテル(신라)、ロッテ(롯데)、ウェスティン、フォーシーズンズがいずれも粥6種のフルラインナップ + 洋食 + 和食 + 韓国料理を提供
  • 時間帯：06:30~10:00(午前6:30~10:00、ホテルにより異なる)
  • 価格：₩60,000~120,000(約6,500~13,000円) / 1人
  • 粥の種類：アワビ粥(전복죽)、ホンテジュク(황태죽、干し明太魚粥)、松の実粥(잣죽)などフルラインナップ
  • 外国人観光客への親切度：★★★★★(英語対応、まず選びたい一軒)

タイプB — 24時間営業のヘジャンチュク(ポンジュク、チュギヤギ)

  • 特徴：24時間営業、ヘジャン愛好家に人気、チェーン店でコスパも良い
  • 時間帯：24時間(一部店舗)
  • 価格：₩8,000~18,000 / 1人
  • 粥の種類：アワビ、カボチャ(호박죽)、ホンテ、緑豆(녹두죽)など多彩
  • 外国人観光客への親切度：★★★★(英語メニュー、チェーン店で安心)
  • ヘジャン愛好家イチオシ：飲んだ翌日の定番No.1

タイプC — 韓定食コース

  • 特徴：松の実粥・ごま粥は韓定食6コースの最初の一品(食欲を引き出す役割)
  • 時間帯：11:30~22:00(午前11:30~午後10:00、ランチ·ディナー)
  • 価格：韓定食コースに含まれる(₩40,000~150,000)
  • 外国人観光客への親切度：★★★★(一部英語メニューあり)

タイプD — 粥専門店·MZカフェ

  • 特徴：アワビ粥、カボチャ粥ラテ、MZ世代風アレンジ
  • 時間帯：10:00~22:00(午前10:00~午後10:00)
  • 価格：₩12,000~25,000
  • 外国人観光客への親切度：★★★★(英語メニュー、MZ世代トレンド)

⚠ 外国人観光客がよくする7つの勘違い

1. 「粥 = 病人食」：韓国では、粥は朝食·ヘジャン·韓定食·高級ホテルまで幅広く登場する、れっきとした日常食です。

2. 「トッピングは最初から入っている」：トッピング(ごま油·海苔·塩)は自分で加えるもので、最初から混ぜてあるわけではありません。

3. 「ホテル朝食の粥はいつでも食べられる」：ホテル朝食は06:30~10:00限定です。

4. 「24時間営業のポンジュクは1店舗だけ」：実際は全国チェーンです。

5. 「ホンテジュクはただの粥」：実際はヘジャンの定番No.1です。

6. 「韓定食の粥は単品メニュー」：実際は韓定食6コースの最初の一品です(食欲を引き出す役割)。

7. 「アワビ粥はどこでも同じ」：伝統的には済州島にゆかりが深く、ホテルでは高級料理として出されます。

⚙ よくある質問8選

1. 最初に食べるならどのチャネル：ホテル朝食(5つ星の贅沢体験) + ポンジュク(ヘジャン体験)。

2. インスタ·vlog向け：ホテル朝食のアワビ粥、江原道風ホンテジュク、韓定食の松の実粥。

3. MZ世代のトレンド：MZカフェのカボチャ粥ラテ、アワビ粥アレンジ。

4. ヘジャン愛好家おすすめ：ホンテジュク(No.1) + ポンジュク(24時間営業) + 緑豆粥(夏向け)。

5. ホテル朝食の時間帯：06:30~10:00(ホテルにより異なる)。

6. アレルギー·妊娠中の注意点：《韓国粥6種概観》の免責事項を参照。

7. 会計·チップ：カードOK / ホテルはサービス料10% / チップ不要。

8. VAT還付：飲食は基本的に還付対象外。

⚠ 医療·安全·食事に関する免責事項

粥は日常的で消化に優しい食べ物です。妊婦や子どもでも問題ありません(熱さには注意)。アレルギー(魚介類·ナッツ·卵·はちみつ)がある場合は事前に伝えてください。食中毒が疑われる場合は ☎ 1339(医療相談、英語対応可)へ。本ガイドは一般的な情報提供のみを目的とし、医療アドバイスではありません。

食事制限への対応：

  • ハラール·コーシャ：松の実粥·ごま粥·カボチャ粥·緑豆粥はOK / アワビ粥·ホンテジュクは魚介類使用(一部ハラール対応店あり)。
  • ベジタリアン·ビーガン：カボチャ粥·ごま粥·松の実粥·緑豆粥はベジタリアン対応 / アワビ粥·ホンテジュクは非対応。
  • グルテンフリー：6種すべて米100%でグルテンフリーOK。
