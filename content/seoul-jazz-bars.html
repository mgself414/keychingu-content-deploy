⚠ 외국인 자주 실수 5가지

1. "재즈 = 한국에 별로 없음": 서울 재즈 = 아시아 가장 깊은 재즈 신 (1976~2026 50년) + 1세대 노포 3 (야누스·천년동안도·올댓재즈) + 트렌디 라운지 (디도·SEOB's) + 외국인 매니아 1번지.

2. "공연 중 박수 = 곡 끝나면": 재즈 박수 = 각 연주자의 즉흥 솔로 끝나는 순간 (곡 시작·끝 X)·모르면 옆 손님 따라 하기·외국인 매니아 매너.

3. "예약 = 전화만": 한국 재즈 바 예약 = 인스타그램 DM 가장 빠름 + SNS 영어 응대 더 자연스러움 + 캐치테이블 영문 (디도)·LINE 영문 (어썸그라운드)·외국인 매니아.

4. "드레스 코드 = 다 정장": 드레스 코드 = 청담 (원스인어블루문) 스마트 캐주얼 + 그 외 (부기우기·SEOB's) 청바지 후드 OK + 외국인 매니아 풀세트.

5. "노포 재즈 = 카드 OK": 노포 재즈 (천년동안도·사운드독) = 카드 단말기 없을 수 있음·현금 5만원 지참 권장 + 외국인 매니아 필수 (#421 통합).
