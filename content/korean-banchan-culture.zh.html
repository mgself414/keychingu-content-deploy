韩国小菜文化 — 为什么一顿饭会有这么多小菜？

> 韩式整桌上菜 (han-sang-cha-rim / 한상차림) · 碟数饭床 (cheop ban-sang / 첩 반상) · 发酵 · 分享 — 为外国游客解读韩国餐桌文化。本文不关注“去哪里吃”，而是“为什么会有、如何形成”。

第一次在韩国餐厅用餐的外国游客最常问的一个问题是：“我没点这些小碟子，为什么会摆满一桌？这些……是免费的吗？” 泡菜 (Kimchi / 김치)、豆芽 (Kongnamul / 콩나물)、菠菜拌菜 (Sigeumchi-muchim / 시금치무침)、鸡蛋卷 (Gyeran-mari / 계란말이)、土豆炖菜 (Gamja-jorim / 감자조림)、炒小银鱼 (Myeolchi-bokkeum / 멸치볶음)……明明只点了一道主菜，餐桌却被小碗碟摆得满满当当。这就是小菜 (banchan / 반찬) 文化。小菜是免费的韩式配菜，通常与主食一同上桌，可以无限续添。本文不探讨“哪家餐厅的小菜好吃” (→ 请参考下方交叉链接的指南)，而是从外国人的视角，深入解读这些小碟子背后蕴含的600多年历史、哲学和情 (jeong / 정)。这是深入了解韩国文化的“韩国文化”系列第一篇。

★ 一目了然 — 6个核心概念

概念 一句话解释
小菜 (banchan / 반찬) 与米饭一同食用的配菜。不是开胃菜 (appetizer)，而是贯穿整餐
韩式整桌上菜 (han-sang-cha-rim / 한상차림) 米饭、汤、小菜一次性全部上齐的用餐方式。不是西式套餐 (course)
碟数饭床 (cheop ban-sang / 첩 반상) 根据小菜碟数区分餐桌等级的传统 (3、5、7、9、12碟)
免费续添 大部分餐厅的小菜免费且可无限续添
发酵 (fermentation) 泡菜、酱料、腌海鲜、酱菜 — 应对严酷冬季的保存智慧
素食友好 大部分小菜是植物性食材 → 对素食者和清真游客意外有用

⚠️ 外国人常有的3个误解

1. “小菜 = 开胃菜” ❌ — 它不像西式套餐那样“先上”。小菜与米饭、汤同时上桌，并伴随整顿饭。也没有固定的食用顺序。

2. “这真的是免费的吗？之后会收费吗？” — 几乎所有韩式餐厅、韩式家常饭店 (baekban / 백반) 和烤肉店的小菜都免费，吃完后只需说一句“请再添些小菜” (ban-chan deo ju-se-yo / 반찬 더 주세요) 即可免费续添 (部分高级餐厅或特殊小菜除外)。

3. “小菜 = 泡菜” ❌ — 泡菜只是小菜的一部分。小菜有数十种，包括拌菜、炖菜、炒菜、煎饼、酱菜、腌海鲜、凉拌菜等，因地区、季节和家庭而异。

① 为什么这么多 — “韩式整桌上菜”的结构

如果说西式餐点是开胃菜 → 主菜 → 甜点按时间顺序 (套餐)上菜，那么韩国的传统餐桌则是米饭、汤、小菜一次性全部上齐。这被称为韩式整桌上菜 (han-sang-cha-rim / 한상차림)。

  • 米饭是中心 (主食)，小菜则是帮助米饭吃得更美味、更均衡的配角。
  • 食用顺序自由。一勺汤，一口饭，一块泡菜，再一块拌菜 — 随心所欲地搭配。
  • 所以餐桌上看起来碗碟很多，但实际上是数百年来“如何让一碗米饭吃得更美味”的思考结果。

② 历史·起源 — 从三国时代到宫廷

小菜和共享餐食的根源可以追溯到三国时代 (公元前57年~公元668年)。

  • 佛教的影响: 三国时代中期佛教传入后，王室开始节制肉食，蔬菜类料理因此发展起来。拌菜 (namul / 나물)、酱菜 (jangajji / 장아찌) 等蔬菜小菜成为韩餐中心菜肴的背景 (这也与寺庙饮食 (sachal eumsik / 사찰음식) 传统相关 — 这是韩国文化系列下一篇的候选主题)。
  • 朝鲜时代 (1392~1910): 小菜的数量直接代表身份和等级。平民只有几样，两班 (yangban / 양반) 贵族则更多，宫廷则会摆上12种以上。
  • 储存的智慧: 在寒冷冬季难以获取蔬菜的朝鲜半岛气候下，通过发酵、腌制来保存蔬菜的农耕智慧，丰富了小菜文化。

③ 碟数饭床体系 — 从小菜数量看餐桌等级

朝鲜时代，小菜碟 (jaengcheop / 쟁첩) 的数量区分了餐桌的等级。这里的“碟 (cheop / 첩)”是指不包括米饭、汤、泡菜、炖菜 (jochi / 조치) 和酱油等小碟 (jangnyu / 장류)，而是盛放在쟁첩中的小菜数量。

碟数 等级 / 身份 备注
3碟 平民的日常饭桌 最基本
5碟 富裕的两班 (ban-ga / 반가) 家庭
7碟 两班 (ban-ga / 반가) ~ 士大夫 (sa-dae-bu / 사대부) “7碟饭床配双炖菜” (7cheop bansang-e ssangjochi / 7첩 반상에 쌍조치) 一说，足见其讲究
9碟 士大夫 (sa-dae-bu / 사대부) 家庭的豪华餐桌 两班 (yangban / 양반) 允许的最高等级
12碟 御膳 (surasang / 수라상) — 君王的饭桌 只有君王才能享用的最高等级
  • 称呼也随身份而异: 对下级称饭桌 (bapsang / 밥상)，对长辈称进膳 (jinji-sang / 진지상)，对君王称御膳 (surasang / 수라상)。
  • 有史料记载: 19世纪末的文献《是议全书 (Siui Jeonseo / 시의전서)》中，以“饭床式图 (Bansang Sikdo / 반상식도)”为题，描绘了9碟、7碟、5碟饭床的菜肴构成和摆放图。
  • 外国游客小贴士: 如今的普通餐厅不再讲究碟数。如果想亲自体验讲究的传统餐桌 (包括12碟御膳 (surasang / 수라상))，可以前往韩定食 (hanjeongsik / 한정식) 店或宫廷料理 (gungjung yori / 궁중요리) 专门店 (→ 请参考下方交叉链接)。

④ 为什么如此多样 — “均衡”的哲学

小菜多的真正原因不仅仅是“丰盛”，更是为了均衡。

  • 五方色 (Obangsaek / 오방색): 红、黄、绿、白、黑五种颜色均衡搭配 — 追求视觉和营养的和谐。
  • 五味 (Omi / 오미): 甜、酸、咸、苦、辣五种味道的平衡。
  • 药食同源 (Yak-sik-dong-won / 약식동원): “食物即是药” — 认为通过时令食材调理身体。
  • 待客之道与情 (jeong / 정): 小菜越多，越被认为是心意。为客人多准备一道菜的心情，正是韩国的情 (jeong / 정) 文化。情 (jeong / 정) 是韩国特有的情感联结和人情味，强调人与人之间的深厚感情和互相照顾。餐厅慷慨地免费提供小菜，也是这种情 (jeong / 정) 情感的延续。

⑤ 发酵 — 小菜的心脏

韩国小菜的深层风味大多源于发酵。

  • 四大发酵支柱: 泡菜 (Kimchi / 김치)、酱 (jang / 장) (大酱 (doenjang / 된장)·酱油 (ganjang / 간장)·辣椒酱 (gochujang / 고추장))、腌海鲜 (jeotgal / 젓갈)、酱菜 (jangajji / 장아찌)。
  • 腌制泡菜 (Kimjang / 김장): 为了过冬，深秋时节全家老少和邻里聚在一起大量腌制泡菜的习俗。其文化价值得到认可，于2013年被列入联合国教科文组织 (UNESCO) 人类非物质文化遗产。
  • 酱缸台 (Jangdokdae / 장독대): 院子一角摆放着陶罐 (dok / 독) 熟成酱料的空间 — 每家每户的“自家酱味”就是其食物的特色。

⑦ 分享与续添 — 餐桌上的情 (jeong / 정)

小菜文化的核心情感是“共同分享”。

  • 共享餐食: 小菜摆在餐桌中央，大家一起夹取食用。与西式各自分盘不同，共享同一个碗碟会产生情 (jeong / 정) 这种情感联结。
  • 免费续添的由来: 以前餐厅续添米饭 (大米) 成本较高，但相对便宜的小菜则可以多提供，让客人吃饱。这个习惯在战争、重建和经济危机时期扎根，深深影响了韩国的餐饮文化。
  • 小菜店 (Banchan-gage / 반찬가게): 制作繁琐的小菜，可以在小菜专门店 (banchan jeonmunjeom / 반찬 전문점) 购买，每个社区都有 — 这是忙碌的现代韩国人解决“家常饭”的方案。

⑧ 外国游客实用指南 — 享受韩式餐桌

  • 礼仪: 小菜可以用自己的筷子夹取，但如果有公用勺子 (serving spoon)，最好使用公用勺子。小菜没吃完剩下也并非失礼 (文化上很自然)。
  • 素食·清真游客: 拌菜 (namul / 나물)·酱菜 (jangajji / 장ajji)·泡菜 (Kimchi / 김치) 等植物性小菜意外地多。但请注意，泡菜或凉拌菜中可能会加入腌海鲜 (jeotgal / 젓갈)·鱼露 (aekjeot / 액젓)·虾酱 (saeu-jeot / 새우젓)，务必询问“我是素食者 (I'm vegetarian)”或“里面有海鲜吗？”。
  • 担心辣味: 不辣的小菜也很多 — 豆芽 (Kongnamul / 콩나물)·菠菜拌菜 (Sigeumchi-namul / 시금치나물)·鸡蛋卷 (Gyeran-mari / 계란말이)·土豆炖菜 (Gamja-jorim / 감자조림)·莲藕炖菜 (Yeongeun-jorim / 연근조림) 等。只需避开辣泡菜即可。
  • 续添一句: “请再添些小菜” (ban-chan deo ju-se-yo / 반찬 더 주세요)。会免费续添。
