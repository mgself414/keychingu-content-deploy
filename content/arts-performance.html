⚠ 외국인 자주 실수 3가지

1. "공연 = 한국어만": 한국 1번지 공연장 = 영문 자막 일부 공연 (LG 아트센터·예술의전당). 인디 뮤지컬·재즈·댄스 = 비언어 OK.

2. "대학로 공연 = 한국어": 대학로 50+ 소극장 = 한국어 인디 위주이지만 시즌별 영문 작품 + 댄스·뮤지컬 비언어 작품 OK.

3. "한국 영화제 = 부산만": BIFF (부산) + BFFC (부천) + JIFF (전주) + 서울 환경영화제·서울국제프라이드영화제 등 연중 5+ 국제영화제.

① 종합 공연장 (3)

1. 예술의전당 (Seoul Arts Center) ★ 한국 1번지 공연장

  • 주소: 서초구 남부순환로 2406 (3호선 남부터미널역) (#173)
  • 외국인 ★: ◎◎ — 한국 1번지 종합 공연 + 한가람미술관·서예박물관·오페라하우스·콘서트홀
  • 시그니처: 1988 개관 + 콘서트홀(2,500석)·오페라하우스(2,300석)·자유소극장·한가람미술관
  • 예약: 예매처 영문 UI (#206 자매)

2. LG 아트센터 (마곡)

  • 주소: 강서구 마곡중앙로 136 (#175)
  • 외국인 ★: ◎ — 2022 강남 → 마곡 이전 한국 1번지 공연장
  • 시그니처: 콘서트·뮤지컬·연극·발레 + 영문 자막 일부
  • 자세히: #175 마곡·김포공항 자매

3. 세종문화회관 (광화문)

  • 시그니처: 1978 개관·콘서트홀·대극장 + 광화문 광장 인접

⚙ FAQ 6개

1. 예약: 예매처 영문 UI (인터파크·예스24·티켓링크). 외국인 결제 OK.

2. 영문 자막: LG 아트센터·예술의전당·세종 종합 공연 일부.

3. 대학로 인디 무대: 한국어 위주지만 비언어 댄스·재즈 OK.

4. 영화관 외국인 가능: 거의 모든 영화관 영문 자막 OK.

5. 국제영화제: BIFF (10월 부산)·BFFC (7월 부천)·JIFF (4~5월 전주).

6. 한국 1번지 공연·영화 매니아 1일: 예술의전당 한가람미술관 + 공연 + LG 아트센터·CGV IMAX 결합.
