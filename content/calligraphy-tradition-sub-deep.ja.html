📍 ソウル・果川 — ソウル書道博物館・秋史博物館

ソウル書道博物館 (Seoul Seoye Bangmulgwan / 서울서예박물관) (瑞草区 Nambusunhwan-ro 2406 (남부순환로 2406) 芸術の殿堂 (Yesuruijeondang / 예술의전당)、☎ 0507-1382-1656) は、1988年に芸術の殿堂の音楽堂と一緒に開館した書道の展示場で、2002年3月に書道専門博物館になりました。「槿域書画史 (Geunyeok Seohwasa / 근역서화사)」のような近現代の書画史の資料と、東アジアの現代書道作品1,300点余りを所蔵しています。1988年に始まった韓国書芸史特別展 (Hanguk Seoyesa Teukbyeoljeon / 한국서예사특별전) をはじめ、書道・書画の展示を続けてきました。

  • 開く時間: 10:00~19:00。休み: 毎週月曜日。
  • 料金: 展示ごとに異なります。

秋史博物館 (Chusa Bangmulgwan / 추사박물관) (果川市 Chusa-ro 78 (추사로 78)、☎ 02-2150-3650) は、朝鮮後期の学者 秋史 金正喜 (Chusa Kim Jeong-hui / 추사 김정희) の生涯と学問、芸術を研究・展示・体験する博物館で、2013年6月3日に開館しました。常設展示室は、2階の秋史の生涯、1階の秋史の学芸、地下1階の藤塚 (Fujitsuka / 후지쓰카) 寄贈室の3か所です。地下1階には企画展示室、常設体験室、子ども図書館、ミュージアムショップがあり、野外には復元した トグムル (Dokumul / 독우물) と瓜地草堂 (Gwaji Chodang / 과지초당)、チュサマダン (Chusamadang / 추사마당) があります。毎年1~2回、特別企画展を開きます。

  • 開く時間: 09:00~18:00(入場締切 17:00)。休み: 毎週月曜日(月曜日が祝日の場合は翌日)、1月1日、旧正月・秋夕の連休、果川市長が定める休館日。
  • 料金: 個人 大人 2,000ウォン、中・高校生・軍人 1,000ウォン、小学生 500ウォン。20人以上の団体は大人 1,000ウォン、中・高校生・軍人 500ウォン、小学生 300ウォン。6歳以下・65歳以上は無料。

📍 地方の書芸館 — 全州 カンアム・麟蹄 如初・天安 チュィムコン・礼山 碑林

カンアム書芸館 (Gangam Seoyegwan / 강암서예관) (全州市 完山区 Jeonjucheon-dong-ro 74 (전주천동로 74)、☎ 063-285-7442) は、書道家 カンアム ソン・ソンヨン (Gangam Song Seong-yong / 강암 송성용) が生涯をかけて集めた所蔵品と財産を社会に還元しようという思いで開館した、書道専門の博物館です。書画、書籍、文房四宝などを1,300点余り所蔵し、全州韓屋村にあります。地下1階、地上2階の建物です。

  • 開く時間: 09:00~18:00。休み: 毎週日曜日、旧正月・秋夕の当日。
  • 料金: 無料。駐車: 無料。

如初書芸館 (Yeocho Seoyegwan / 여초서예관) (麟蹄郡 北面 Manhae-ro 154 (만해로 154)、☎ 033-461-4081) は、書道家 如初 金膺顯 (Yeocho Kim Eung-hyeon / 여초 김응현) を顕彰する、麟蹄郡 北面 龍垈里 (Yongdae-ri / 용대리) にある書道専門の博物館です。観光公社の紹介によると、韓国最大規模の書道専門博物館です。金膺顯の作品と遺品、韓国内外の書法資料、書籍など6千点余りを所蔵しています。建築家 イ・ソングァン (Lee Seong-kwan / 이성관) が周りの松林を取り込んで設計し、ピロティで展示施設を一層分持ち上げ、もともと流れていた小川の水を生かして池を作りました。

  • 開く時間: 09:00~18:00(入場締切 17:30)。休み: 毎週月曜日、1月1日、旧正月・秋夕の当日。
  • 料金: 無料。駐車: 無料。

チュィムコン書芸館 (Chwimukheon Seoyegwan / 취묵헌서예관) (天安市 東南区 木川邑 Jonghap-hyuyangji 1-gil 3 (종합휴양지1길 3)、☎ 文化政策チーム 041-521-5167) は、天安総合休養観光団地の管理事務所の建物を改修して開館した書芸館です。忠南 牙山で生まれ、約50年間作品活動を続けたチュィムコン イン・ヨンソン (In Yeong-seon / 인영선) の書とアーカイブ、映像を展示しています。

  • 開く時間: 10:00~18:00(入場締切 17:30)。休み: 毎週月曜日(月曜日が祝日の場合は翌日)、1月1日、旧正月・秋夕の当日。展示準備期間は臨時休館します。
  • 料金: 無料。駐車: 無料。

韓国書芸碑林博物館 (Hanguk Seoye Birim Bangmulgwan / 한국서예비림박물관) (礼山郡 新陽面 Nokmunbaksalmi-gil 7 (녹문박살미길 7)、☎ 0507-1414-8610) は、近現代の書画家たちの書道と四君子を石に陰刻・陽刻で刻んだ作品700点余りを展示する場所です。篆書、隷書、楷書、行書、草書、ハングル書道の作品を見ることができます。

  • 開く時間: 09:30~17:00。休み: 年中無休。
  • 料金: 無料。

📍 春川・済州 — 筆物語博物館・済州秋史館

筆物語博物館 (Butiyagi Bangmulgwan / 붓이야기박물관) (春川市 西面 Baksa-ro 906 (박사로 906)、☎ 033-255-0580) は、伝統的な筆を広めようと2017年に建てられた筆の博物館です。観光公社の紹介によると、韓国国内唯一の筆専門博物館です。江原特別自治道の無形遺産 春川筆匠の保有者 パク・キョンス (Bak Gyeong-su / 박경수) 館長と、多くの作家の作品を展示しています。1階では筆1本に100回以上も職人の手が入る制作過程を見て、2階ではカリグラフィー作品作りと自分だけの筆作りを体験します。筆の工房では、職人が筆を作る様子を見ることができます。

  • 開く時間: 10:00~18:00(入場締切 17:30)。休み: 毎週月曜日、旧正月・秋夕の当日。
  • 料金: 無料。見学時間: 約1時間。駐車: 無料。

済州秋史館 (Jeju Chusagwan / 제주추사관) (西帰浦市 大静邑 Chusa-ro 44 (추사로 44)、☎ 064-710-6865) は、秋史 金正喜の生涯と学問、芸術を顕彰するため、2010年12月に建てられた展示館です。1984年に建てた秋史遺物展示館を、2007年10月に秋史の流刑地が国家指定遺産になったのを機に新しく建て直しました。秋史記念ホールと展示室3か所、教育室があり、「礼山 金正喜 宗家 遺物一括 (Yesan Kim Jeong-hui Jongga Yumul Ilgwal / 예산김정희종가유물일괄)」、秋史の扁額の書、秋史の手紙の書を展示しています。

  • 開く時間: 09:00~18:00(入場締切 17:30)。休み: 毎週月曜日(月曜日が祝日の場合はその次の最初の非祝日)、1月1日、旧正月・秋夕の当日。
  • 料金: 無料。

⚠ 事前に知っておきたい3つのこと

  1. ほとんどが月曜日に休む — カンアム書芸館は日曜日に休み、韓国書芸碑林博物館は年中無休です。残りの6か所は毎週月曜日に休みます。
  2. 料金が登録されているのは秋史博物館 — 大人 2,000ウォンで、ソウル書道博物館は展示ごとに異なります。残りの6か所は無料です。
  3. 秋史 金正喜を扱う場所は2か所 — 果川の秋史博物館と、西帰浦の済州秋史館です。

⚙ FAQ 2

Q. 筆を作ったり、カリグラフィーを体験したりできる場所は?

A. 観光公社の登録情報では、春川の筆物語博物館の2階で、カリグラフィー作品作りと自分だけの筆作りを体験できます(入場無料、月曜日休館)。果川の秋史博物館には常設体験室があります。

Q. ソウルと果川にある書道の博物館は?

A. 瑞草区の芸術の殿堂の中にあるソウル書道博物館(10:00~19:00、月曜日休館)と、果川の秋史博物館(09:00~18:00、月曜日休館)です。
