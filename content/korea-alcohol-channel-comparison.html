🍻 4채널 deep dive

🍻 한국 주점·포차 (Korean Pub·Pojangmacha)

핵심 가치: 소주·맥주·소맥 + BBQ 안주 + 한국 회식 1순위.

  • 추천 영역 (서울):
  • 종로 청계천 포차 cluster — 외국인 vlog 1번지
  • 을지로 노가리 골목 — MZ 포차
  • 강남·역삼 호프 cluster — 직장인 회식
  • 홍대·이태원 — 외국인 친화
  • 건대·신촌 — 대학생 cluster
  • 메뉴: 소주·맥주·소맥 + BBQ 안주 (삼겹살·치킨·전·우동·라면·곱창)
  • 가격 anchor: 1인 15,000~30,000원 (술 + 안주)
  • 외국인 친화도: ★★★ (한국어 메뉴 多, 홍대·이태원 ★★★★)
  • 운영 시간: 17:00~02:00 (야간)

🍯 막걸리집·전통주점 (Makgeolli Hanok)

핵심 가치: 전통 막걸리 + 전 + 한옥 정통.

  • 추천 영역 (서울):
  • 인사동 막걸리집 cluster — 전통 한옥
  • 익선동 한옥 막걸리집 — MZ 한옥
  • 북촌 한옥 막걸리집
  • 종로·종묘 정통 매장
  • 추천 매장 (지방):
  • 전주 한옥마을 막걸리집 — 전주 모주 정통
  • 안동 막걸리집 — 안동소주 정통
  • 메뉴: 막걸리 (장수·국순당·MZ 트렌드) + 청주·전통주 + 전 (김치·해물파·녹두) + 보쌈·녹두전
  • 가격 anchor: 1인 15,000~30,000원
  • 외국인 친화도: ★★★ (전통 매니아·한옥 vlog ★)
  • 운영 시간: 17:00~24:00

🍶 일식 이자카야 (Japanese Izakaya)

핵심 가치: 사케·하이볼 + 꼬치·회·사시미 정통 일본.

  • 추천 영역 (서울):
  • 강남·청담 일식 이자카야 cluster — 정통
  • 이태원·홍대 외국인 친화 이자카야
  • 신라호텔 일식당 — 럭셔리
  • 메뉴: 사케 + 하이볼 + 꼬치 (야끼토리)·회 (사시미)·우동·라멘
  • 가격 anchor: 1인 30,000~80,000원
  • 외국인 친화도: ★★★★ (영문 메뉴·일본 인지)
  • 운영 시간: 17:00~02:00
  • 결제: 카드 OK + 봉사료 일부 (호텔)

🥃 MZ 바·하이볼 바 (MZ Bar·Highball Bar)

핵심 가치: 위스키·하이볼·칵테일 + 인스타·MZ 트렌드 1번지.

  • 추천 영역 (서울):
  • 홍대·연남 하이볼 바 cluster — 인스타 1번지
  • 강남·역삼 위스키 바 — 직장인 MZ
  • 이태원 칵테일 바 — 외국인 친화
  • 성수동 MZ 바 — 트렌디
  • 메뉴: 위스키 (산토리·잭다니엘·시바스) + 하이볼 + 칵테일 + MZ 안주 (감자튀김·치즈)
  • 가격 anchor: 1인 25,000~80,000원
  • 외국인 친화도: ★★★★★ (영문 메뉴 多·MZ 트렌드)
  • 운영 시간: 17:00~02:00
  • 결제: 카드 OK

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 분위기·메뉴·가격 완전 다름. 회식 = 주점 / 전통 = 막걸리 / 일본 = 이자카야 / MZ = 바.

2. "한국 주점 = 외국인 X": 홍대·이태원 한국 주점 = 외국인 친화 매장 多. 영문 메뉴 일부.

3. "막걸리집 = 전통만": 인사동·익선동 한옥 막걸리집 = 전통 + MZ 융합 (우유·복숭아 막걸리).

4. "이자카야 = 일본만": 한국 이자카야 = 한국 셰프·재료 多 + 일본 스타일 (한국 내 일식).

5. "MZ 바 = 비싸기만": 하이볼 바 1인 25,000원~ = 영문 메뉴·트렌디·인스타 풀세트 가성비.

⚙ FAQ 8개

1. 첫 술 매장 = 어떤 채널: MZ 바·하이볼 바 1순위 (영문·트렌디). 한국 정통 = 막걸리집.

2. 인스타·vlog: MZ 바 (하이볼)·막걸리집 (한옥 vlog)·이자카야 (일본 정통).

3. 회식·접대: 한국 주점·포차 (1차) + 일식 이자카야 (정통 접대) + 호텔 이자카야 (럭셔리).

4. 데이트·기념일: 막걸리집 한옥 (전통) + MZ 바 (트렌디) + 이자카야 (격식).

5. 가족 동반: 한국 주점 가족 호프 매장 + 일식 이자카야 lunch.

6. 알레르기·임신: [#828·#829 disclaimer](#828) 참조. 임신부 = 음주 금지.

7. 결제·팁: 한국 = 팁 X / 호텔 = 봉사료 일부 / 카드 OK / 카카오페이·토스 송금.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·법률 disclaimer

한국 술 = 알코올. 음주운전 0.03% BAC 면허정지 + 형사처벌. 임신부·약물 복용자 = 음주 금지. 19세 미만 = 법적 음주 금지. 알레르기 (글루텐·콩·과일·견과류) 사전 고지. 식중독·과음 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

노포·매장 정보 면책: 매장 영업시간·메뉴 변동 — 방문 전 NAVER/Kakao map 또는 공식 사이트 확인.

식이 제한 fallback:

  • 할랄·코셔: 알코올 = 비할랄·비코셔. → 무알콜 옵션 (식혜·수정과·무알콜 맥주).
  • 무알콜: 식혜·수정과·국화차 + 무알콜 맥주·무알콜 청주 + MZ 바 무알콜 칵테일.
