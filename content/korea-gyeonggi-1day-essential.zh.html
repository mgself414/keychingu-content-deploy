从首尔出发的京畿道一日游13处 — 水原·龙仁·坡州DMZ·加平杨平，冬天走的四条一日路线

副标题: 水原华城·华城行宫和两家炸鸡店，龙仁的爱宝乐园·韩国民俗村，从坡州临津阁出发的DMZ和平观光与和平缆车，加平的南怡岛·晨静树木园星光庭园，杨平的两水头·洗美园。按从首尔乘公共交通一天能往返的路线，分成四条。时间·票价是2026-11-25亲自打开运营方官方页面或Kakao地图登记值后写下的，每个数值都标明了出处。

ISSUE 04 · #1031 · 2026-11-25 · 京畿道一日游

🎯 适合谁，为什么分四条路线

京畿道环绕着首尔，所以"京畿道一天"其实是选方向。南边(水原·龙仁)、北边(坡州DMZ)、东边(加平·杨平)的线路各不相同，一天只选一个方向。

这是写给住在首尔、想拿一天去京畿道的旅行者的。冬天休息或时间有变的地方都做了标记(没能确认的地方，如实写明)。各个地方的详细介绍在#1032·#1033·#1034·#1035，这里只整理了方向·组合·关门时间。

⚠ 标注原则: 时间·票价是运营方官方网站或Kakao地图登记值(均为2026-11-25确认)。出处写在数值旁边。移动时间只照抄官方说明里写明的，其余的当天用Kakao地图导航确认。

① 水原 — 绕城墙一圈和炸鸡街

从华城行宫到城墙和炸鸡街，全部步行就能到。

  • 水原华城 — 朝鲜正祖(Jeongjo / 정조)时修筑的城墙，现在是环绕市中心的散步路。水原文化财团参观指南写着"1月~12月全天，全年无休，免费"，因为是开放式，夜里也能走(2026-11-25确认)。财团推荐的路线有1~3小时的。西将台 (Seojangdae / 서장대)一带是上坡路。
  • 华城行宫 — 国王驻留水原时用的宫殿。09:00~18:00，入场到关门前1小时为止，全年无休。成人₩2,000，青少年₩1,500。华城行宫·水原华城博物馆 (Suwon Hwaseong Museum / 수원화성박물관)·水原博物馆 (Suwon Museum / 수원박물관)联票成人₩4,000(均为水原文化财团，2026-11-25)。穿韩服 (Hanbok / 한복)(包括改良韩服)被列为免费·减免对象(官方表格中没有区分免费和减免)。每月最后一个周三免费。夜间开放是2026-05-01~11-01期间，所以冬天没有。地址是八达区 (Jeongjo-ro 825 / 정조로 825)。
  • 炸鸡店 (Jinmi Tongdak / 진미통닭) — 炸鸡街 (Jeongjo-ro 800beon-gil / 정조로800번길)上的炸鸡店。周二~周日 11:00~23:00，周一休息，春节(Seollal)·中秋(Chuseok)假期也休息。登记价格是炸鸡·整只鸡₩21,000，调味·半半₩22,000，咖喱炸鸡·辣海鲜面炸鸡₩25,000，生啤500cc ₩4,500(Kakao地图业主登记，菜单登记2026-05~06，2026-11-25确认)。地址是八达区 (Jeongjo-ro 800beon-gil 21, 2F / 정조로800번길 21 2층)。饮食提示: 是炸鸡，所以面衣里可能有面粉。没有登记猪肉菜品。调味酱是甜味和辣味混合的酱。也卖生啤和Jim Beam威士忌套餐。
  • 炸鸡店 (Yongseong Tongdak Main Branch / 용성통닭 본점) — 同一条巷子往前几家。Kakao地图登记时间是11:00~23:00，但12月1日(周二)标为休息。没有登记固定休息日，去之前先在Kakao地图确认。登记价格是炸鸡·乡村炸鸡₩21,000，调味·半半₩22,000，大排骨₩24,000(Kakao地图业主登记，菜单登记2026-08-07，2026-11-25确认)。地址是八达区 (Jeongjo-ro 800beon-gil 15 / 정조로800번길 15)。饮食提示: 是炸鸡，面衣里可能有面粉。大排骨没有登记菜品说明。没有登记酒类菜单。

交通 (水原文化财团"主要地点交通方式"，2026-11-25): 在江南站 (Gangnam / 강남)乘直达巴士3000路，在八达门 (Paldalmun / 팔달문)下车，步行约5分钟到行宫。从蚕室站 (Jamsil / 잠실)乘1007路(在华城行宫·丽民阁 (Hwaseong Haenggung / Yeomingak / 화성행궁·여민각)下车)。乘地铁的话，在1号线·水仁盆唐线水原站 (Suwon / 수원) 4号出口的Novotel站乘11·13路巴士，在华城行宫·水原圣地 (Hwaseong Haenggung / Suwon Seongji / 화성행궁·수원성지)下车。

② 龙仁 — 爱宝乐园还是韩国民俗村

两处都要花一整天，所以只选一个。

  • 爱宝乐园 — 有游乐设施和野生动物园的主题公园。Kakao地图登记时间是11/25~12/1每天10:00~22:00(2026-11-25确认)。12月2日以后的时间在官方App按日期查看。全天票按日期等级定价。从2026-10-06起各涨了₩3,000，成人最高₩71,000，旺季₩65,000，平时·淡季₩55,000(Money Today 2026-09-07)。涨价前12月是₩52,000(CEO Score Daily 2026-09-24)，所以12月推测为₩55,000左右。实际票价在支付页面确认。地址是处仁区 (Pogok-eup Everland-ro 199 / 포곡읍 에버랜드로 199)。
  • 韩国民俗村 — 再现朝鲜时代村庄的户外民俗村。Kakao地图登记时间是周一~周四 10:00~19:00，周五~周日 10:00~20:00，官方主页显示"11月25日 10:00~19:00"(2026-11-25)。12~2月的时间在官方没能确认(公告说会随季节·天气变化)。全天票成人工作日₩37,000，周末₩39,000。外国人出示护照或外国人登记证是₩22,000(官方使用票价，"适用至2026年"，2026-11-25确认)。12~3月周末下午2点入场票成人₩25,000。地址是器兴区 (Minsokchon-ro 90 / 민속촌로 90)。

交通: 去爱宝乐园，江南方向有5002路直达巴士，从2026-08-01起有从首尔站 (Seoul Station / 서울역)换乘中心经明洞 (Myeong-dong / 명동)·梨泰院 (Itaewon / 이태원)的4105路(约1小时，Korea Times 2026-07-30报道)。去韩国民俗村，有新论岘站 (Sinnonhyeon / 신논현) 5001-1路，江南站1560路，首尔站4101路。也可以在水原站4号出口换乘37路·10-5路巴士(韩国民俗村官方交通说明，2026-11-25)。

③ 坡州 — 从临津阁出发的DMZ

个人旅行者可以在临津阁 (Imjingak / 임진각)乘坡州市DMZ和平观光巴士到DMZ附近。外国人必须有护照或外国人登记证原件(复印件·截图·过期证件不可)，周一不运营。

  • DMZ和平观光 — 在临津阁售票处买票，乘接驳巴士依次游览第3隧道→都罗展望台→统一村，再回到临津阁(约3小时)。现场售票·预约取票是09:00~14:30，同行的人全部到齐才出票。很多天会提早售罄。也有在线预约菜单，但官方没写外国人能不能用。每周一，工作日的公休日，春节(Seollal)·中秋(Chuseok)当天休息，所以12/25·1/1(工作日)是否运营要提前确认。成人票价单轨列车路线₩12,200，徒步路线₩9,200。没有外国人优惠·免费。周二~周五巴士从09:20到14:40发车10班，周六·周日12班。单轨列车停运时路线改为徒步，也可能因安保·天气原因取消(坡州市DMZ和平观光官方英文页面，2026-11-25。英文服务在准备中，可能与韩文说明不同)。有都罗展望台道路管制公告(2026-10-23)，路线可能变动，去之前向坡州市(031-940-4114)确认。
  • 临津阁和平公园 — 有和平之钟和宽阔草坡的户外公园。免费入场，停车收费(小型车₩2,000)，停车场 08:00~20:00运营(京畿道英文旅游页面，2026-11-25)。等和平观光巴士时逛一逛。
  • 和平缆车 — 横跨临津江的缆车。每天09:00~18:00，全年无休，但12月7日(周一)因安全检查休息。普通车厢成人₩12,000。没有身份证件不能乘坐，外国人护照是否被认可，官方没有写(和平缆车官方，2026-11-25)。

交通 (DMZ和平观光官方英文说明，2026-11-25): 从京义中央线临津江站 (Imjingang / 임진강)步行约20分钟。临津江站也有058A·058B接驳巴士。为了赶上14:30售票截止，要从首尔一大早出发。

④ 加平·杨平 — 沿江向东

加平(京春线)和杨平(京义中央线)线路不同，一天只在两者中选一个。

  • 南怡岛 — 北汉江上的岛。地址是江原道春川，但船在加平码头乘。船每天从08:00开，最后入岛21:00·离岛21:05。大约需要5分钟(2026年公告)。成人门票含往返船票₩19,000(南怡岛官方，2026-11-25确认)。从加平站 (Gapyeong / 가평)到码头步行约20分钟，乘10-4路巴士或出租车约5分钟。每天也有首尔直达接驳巴士(弘大入口站 (Hongik Univ. / 홍대입구) 09:00出发，南怡岛16:30出发。指定公司Ktourstory预约)。
  • 晨静树木园 — 加平的私人树木园。到12/3为止是08:30~19:00(入场截止18:00)。12/4~2027-03-14的五彩星光庭园展 (Five-Color Starlight Garden Festival / 오색별빛정원전)期间是10:00~21:00，只有周六到23:00(树木园官方使用说明use01.php，2026-11-25)。17:00开始点灯(Kakao地图登记)。庭园展期间的入场截止和票价是否与平时相同，官方没有写。平时成人₩11,000，门票只能在现场售票处购买。从清平站 (Cheongpyeong / 청평)·清平客运站 (Cheongpyeong Terminal / 청평터미널)乘30-6路巴士到终点。清平客运站发往树木园的末班是19:30，树木园发往清平客运站的末班是20:00。想看到21:00，回程要打车(到清平市区约20分钟，官方交通说明)。
  • 两水头 — 南汉江和北汉江交汇的江边散步路。没有门票，全年无休(Kakao地图登记，2026-11-25)。
  • 洗美园 — 两水头旁边的水与花的庭园。09:00~18:00，入场截止17:30。12~3月每周一闭馆(遇公休日则顺延一天)。成人₩7,000(洗美园官方参观指南，2026-11-25确认)。从京义中央线阳水站 (Yangsu / 양수)步行700m，江边站 (Gangbyeon / 강변) 2000-1路，蚕室站2000-2路巴士也有(工作日限量运行)。

交通: 加平站乘ITX-青春 (ITX-Cheongchun / ITX-청춘)从龙山 (Yongsan / 용산)约60分钟，从青凉里 (Cheongnyangni / 청량리)约42分钟。乘京春线电车从上凤 (Sangbong / 상봉)约50分钟(南怡岛官方交通说明，2026-11-25)。

🗺 动线 — 冬天一日示例

A. 水原 (每天，但炸鸡店 (Jinmi Tongdak / 진미통닭)周一休息)

  1. 上午: 华城行宫(09:00~)。穿韩服是免费·减免对象
  2. 午后: 登上行宫后面的西将台，朝华西门 (Hwaseomun / 화서문)·长安门 (Janganmun / 장안문)方向走城墙
  3. 晚上: 在炸鸡街吃炸鸡。炸鸡店 (Jinmi / 진미)周一休息，炸鸡店 (Yongseong / 용성)先在Kakao地图确认休息日

B. 加平的白天和夜晚 (12/4以后)

  1. 上午: 乘ITX-青春到加平站，步行到南怡岛码头
  2. 下午: 绕岛一圈后回到加平站，乘京春线往首尔方向在清平站下车。乘30-6路巴士去晨静树木园
  3. 晚上: 五彩星光庭园展(17:00~点灯)。30-6路树木园发车的末班是20:00，之后打车去清平(约20分钟)

C. DMZ (周二~周日)

  1. 一大早: 乘京义中央线到临津江站，临津阁售票处(09:00~)
  2. 上午~中午: 和平观光巴士(约3小时)
  3. 下午: 在和平公园散步，有时间的话去和平缆车(~18:00)

⚠ 常见错误3

  1. 周一去DMZ — DMZ和平观光每周一休息。同一个周一，洗美园(12~3月)和炸鸡店 (Jinmi Tongdak / 진미통닭)也休息。周一选水原城墙，爱宝乐园，南怡岛，晨静树木园这类登记为全年无休的地方。
  2. 只带护照照片·复印件 — DMZ和平观光要求外国人出示护照或外国人登记证原件，不接受复印件·截图·过期护照。和平缆车没有身份证件也不能乘坐。韩国民俗村外国人票价(₩22,000)也要出示护照或外国人登记证。
  3. 一天安排两个方向 — 水原和加平，坡州和龙仁要横穿首尔。一天只选一条路线，DMZ那天要在14:30售票截止前到达。

⚙ FAQ 3

  1. 第一次来而且只有一天? — 喜欢走路就选水原(城墙免费，行宫₩2,000)。想看分断现场就周二~周日去DMZ。带孩子就去爱宝乐园或韩国民俗村。
  2. 也能去板门店 (Panmunjeom / 판문점)(JSA)吗? — 这一篇的动线没有放进去。2026-11-25没能确认到运营一般外国人参观的官方公告。
  3. 冬天晚上有什么可看的地方? — 晨静树木园五彩星光庭园展(12/4~，17:00点灯，到21:00·周六到23:00)和爱宝乐园(Kakao地图登记到22:00)。水原华城城墙夜里也开放，但华城行宫的夜间开放已在11/1结束。
