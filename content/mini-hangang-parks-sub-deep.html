미니 한강공원 12선

1. 망원 한강공원 (MZ 트렌디 #1)

  • 차별: MZ 트렌디 1순위 한강공원·망원시장 + 망원동 카페 cluster·MZ 인스타 1순위·합정역 도보·6호선 망원역
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아 1순위·MZ #1

2. 망원시장 + 망원동 카페 cluster

  • 차별: 망원시장 한국 #1 MZ 트렌디 시장·골목 카페·디저트·길거리 음식·가성비 1순위·MZ 인스타 #1
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아·가성비

3. 양화 한강공원 (선유도 + 합정)

  • 차별: 선유도 공원 (인공섬·생태·미니 식물원)·1978 폐 정수장 → 2002 공원 재생·MZ + 가족 매니아·양화나루역
  • 외국인 fit: ★★★★ EN·JP·CN MZ 매니아·도시재생

4. 선유도 공원 (인공섬 + 생태)

  • 차별: 양화대교 인공섬·1978 폐 정수장 재생·MZ + 가족 매니아 1순위·무료·24시간·SNS 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN MZ·SNS 1순위

5. 난지 한강공원 (월드컵공원 cluster)

  • 차별: 월드컵공원 + 평화공원 + 하늘공원 + 노을공원 cluster·2002 FIFA 월드컵 본거지·디지털미디어시티역 6호선
  • 외국인 fit: ★★★★★ EN·JP·CN MZ·가을 1순위

6. 하늘공원 가을 억새축제 (10-11월)

  • 차별: 하늘공원 억새축제 10-11월·한국 #1 억새 spot·SNS 1순위·무료·가을 매니아 1순위
  • 외국인 fit: ★★★★★ EN·JP·CN MZ·가을 #1·SNS 1순위

7. 광나루 한강공원 (동쪽 끝·자연)

  • 차별: 서울 동쪽 끝 한강공원·광진·강동 cluster·가족 + 자연 매니아·광나루역 5호선·조용한 분위기
  • 외국인 fit: ★★★★ EN·JP·CN 가족·자연 매니아

8. 이촌 한강공원 (용산 + 한강 미니)

  • 차별: 용산 + 한강 미니 공원·산책 + 자전거 + 조용한 분위기·이촌역 4호선·1호선·이태원역 cluster
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·조용

9. 잠원 한강공원 + 한강 해치카 2026

  • 차별: 잠원 한강공원·잠실보다 조용한 분위기·잠원역 3호선·2026 한강 해치카 운행 1순위
  • 외국인 fit: ★★★★ EN·JP·CN MZ·2026 신규

10. 강서 한강공원 (서쪽 끝·생태)

  • 차별: 서울 서쪽 끝 한강공원·강서습지 생태 + 새·김포공항 인접·가족 + 자연 매니아·9호선 신방화역
  • 외국인 fit: ★★★ EN·JP·CN 자연 매니아

11. 미니 한강공원 cluster 1일 (망원 + 양화 + 난지)

  • 차별: 망원 + 양화 + 난지 cluster 1일 풀세트·MZ + 가족 + 가을 풀세트·6호선 + 9호선 cluster
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아·MZ 1순위

12. 미니 한강공원 + 한강 자전거 종주

  • 차별: 광나루 → 잠실 → 뚝섬 → 잠원 → 반포 → 이촌 → 여의도 → 양화 → 망원 → 난지 → 강서 11 한강공원 자전거 41.5km·따릉이 OK
  • 외국인 fit: ★★★★ EN·JP·CN MZ 매니아·자전거 1순위·#697·#706 cross

FAQ 6

Q1. 망원 vs 양화 vs 난지 MZ? A. 망원 = MZ #1 (시장 + 카페)·양화 = 도시재생 + 선유도·난지 = 가을 억새 #1.

Q2. 하늘공원 억새 시기? A. 10-11월 절정·한국 #1 억새 spot·무료·SNS 1순위.

Q3. 선유도 공원? A. 양화대교 인공섬·1978 정수장 → 2002 공원 재생·MZ + 가족 SNS·무료 24시간.

Q4. 가족 매니아? A. 광나루 (자연)·양화 (선유도)·이촌 (조용)·강서 (생태).

Q5. 한강 해치카 2026 신규? A. 반포·잠원·난지 운행·MZ + 가족 매니아·2026 한국 #1 신규 이벤트.

Q6. 11 한강공원 자전거 종주? A. 41.5km 풀·따릉이 1일권 1,000원·광나루 → 강서 → 11 공원·MZ 매니아 1순위.
