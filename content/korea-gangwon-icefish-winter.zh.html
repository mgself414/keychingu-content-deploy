江原冰钓节 — 华川山鳟鱼·平昌鳟鱼，冬季一晚实战指南

副标题：现在能去的节日只有华川山鳟鱼节和平昌鳟鱼节两处（麟蹄胡瓜鱼节2024~2026年连续3年取消）· 1月旺季 · 日期和费用每年都会变 · 保暖·安全·交通实战

第04期·#1069·2026-06-13（2026-10-20修订）

🎯 为什么要看江原冰钓节指南

冻得结结实实的江面上，一排排冰洞整齐开着，握着钓线的手套指尖很快就冻得发麻。江原道冬季冰钓节，就是为了看这一幕而去的旅行。目前外国游客能够规划的大型节日有两处：华川山鳟鱼节 (Hwacheon Sancheoneo Ice Festival / 화천 산천어축제) 和 平昌鳟鱼节 (Pyeongchang Trout Festival / 평창 송어축제)。

以前的介绍里曾把 麟蹄胡瓜鱼节 (Inje Smelt Festival / 인제 빙어축제) 一并列入，但该节因昭阳江大坝 (Soyanggang Dam / 소양강댐) 水位问题，江面不结冰，2024·2025·2026年连续3年取消。2027年是否举办也尚未确定。如果想把麟蹄排进行程，请先确认当年的官方公告。

★ 一目了然 — 两个节日

华川山鳟鱼节 (Hwacheon Sancheoneo Ice Festival / 화천 산천어축제) 平昌鳟鱼节 (Pyeongchang Trout Festival / 평창 송어축제)
地点 华川郡 (Hwacheon County / 화천군) 华川川 (Hwacheoncheon Stream / 화천천) 一带 平昌郡 (Pyeongchang County / 평창군) 津富面 (Jinbu-myeon / 진부면) 五台川 (Odaecheon Stream / 오대천) 一带

2027 未公布（宣传网站上的1/9~1/31为暂定标注） 未公布
特点 规模最大的节日。华川郡主打“CNN评选的冬季七大奇观” (2011) KTX津富（五台山）站 (Jinbu-Odaesan Station / 진부·오대산역) 就在附近，从首尔坐火车去很方便。适合与平昌冬奥会地区组合游览

两个节日都可能因天气暖和而推迟开幕或调整部分项目。 日期和费用每年都不同，出发前请再次到官方网站确认。

🏛 各节日深度解读

① 华川山鳟鱼节 (Hwacheon Sancheoneo Ice Festival / 화천 산천어축제)

  • 以在冰上钓鱼区钓山鳟鱼为核心。钓到的鱼可以在现场处理后烤着吃。
  • 2026年的做法是把部分使用费以当地商品券·兑换券的形式返还。2027年正在审议同时提高使用费和返还规模的方案（2026-10-02 MTN 报道，尚未确定）。
  • 当天往返也可以，但从首尔坐巴士往返路上耗时较长，住一晚更轻松。

② 平昌鳟鱼节 (Pyeongchang Trout Festival / 평창 송어축제)

  • 以五台川 (Odaecheon Stream / 오대천) 冰面上钓鳟鱼为核心。2026年是20周年，1月9日~2月9日共举办32天，官方日程结束后，放流鳟鱼的自由垂钓又持续了约一周（2026报道）。
  • 可以乘坐KTX到津富（五台山）站 (Jinbu-Odaesan Station / 진부·오대산역)，适合坐火车的旅行者。适合与平昌羊群牧场 (Pyeongchang Sheep Ranch / 평창 양떼목장)·滑雪场·大关岭 (Daegwallyeong / 대관령) 行程组合（#1039）。

③ 麟蹄胡瓜鱼节 (Inje Smelt Festival / 인제 빙어축제)（目前休办）

  • 2024~2026年连续3年因无法结冰而取消。官方网站的举办时间标注为“待定”（2026-10-13确认）。
  • 恢复举办后会再次介绍。在此之前，请在行程中去掉它。

🧰 出发前 — 实用检查

  • 日期·费用：到官方网站确认当年公告。不要直接相信往年的日期。
  • 保暖：在冰面上要长时间站着或坐着。请带上厚羽绒服·防水靴·备用手套·暖宝宝·防滑冰爪。现场是否提供租借及费用因节日而异，请到现场确认。
  • 交通：去华川多是从首尔坐城际巴士，去平昌多是坐KTX到津富（五台山）站 (Jinbu-Odaesan Station / 진부·오대산역)。前往节日会场的接驳车是否运行，每年另行公告。
  • 住宿：与周末·春节假期重叠时，江原道的住宿很快订满。日期一确定就马上预订。
  • 支付：很多地方可以刷卡，但小摊位有时用现金更方便。
  • 急救：☎ 119 · 翻译·旅游咨询 ☎ 1330

⚠ 外国游客常犯的4个错误

1. 按往年日期预订 — 节日日期每年都会变，暖冬时开幕还会推迟。等官方公告发布后再确定交通和住宿。

2. 把麟蹄胡瓜鱼节排进行程 — 2024~2026年连续3年取消。在确认当年举办公告之前不要排入。

3. 穿城市冬装去 — 冰面上没有任何挡风的地方。防水靴和备用手套会带来很大差别。

4. 在冰面上随意走动 — 只在节日负责安全管理的区域内活动。不要进入警戒线之外的冰面。

⚙ FAQ

1. 第一次去先去哪里？ — 坐巴士旅行选华川，坐火车旅行选平昌（KTX津富（五台山）站 (Jinbu-Odaesan Station / 진부·오대산역)）比较方便。

2. 2027年日程呢？ — 截至2026年10月，两个节日都尚未公布。请查看官方网站公告。

3. 麟蹄胡瓜鱼节呢？ — 2024~2026年连续3年取消。2027年是否举办未定。

4. 费用呢？ — 华川2026年使用费15,000韩元（部分返还），2027年正在审议上调方案。平昌请确认当年公告。

5. 可以带孩子去吗？ — 家庭游客很多。保暖和防滑要比大人准备得更周全。

⚠ 医疗·安全免责声明

冰面活动只在节日管理的区域内进行。长时间暴露在寒冷中要小心手脚·耳朵冻伤，一旦开始发抖就进入室内休息处。急救 ☎ 119，旅游翻译 ☎ 1330。
