済州のカフェ13軒 — 外国人レビューが先に残った店だけ

サブタイトル: 済州東部のパン屋ひと言(#1407)、地元の人の名店と五日市場(#1348)、済州の食堂14軒(#1437)に続く軸——空港近くのロースタリー、旧市街の英語メニューのロースティングルーム、ギョレのガーデンカフェ、ウォルジョン・キムニョンの海岸カフェ、アウォルのサワードウ、ソギポのパン屋。Naverマップに外国語レビューが先に残ったカフェだけを13軒選び、4エリアにまとめて宿泊エリア別に選びやすくした。席取り・マグカップ・返却台のようなカフェ店内のルールは#1378

ISSUE 06 · #1438 · 2026-11-23 · 済州のカフェ

🎯 なぜ「三言語レビュー」が基準なのか

店を選んだ済州のパン・カフェ編はすでにあります——済州東部のパン屋ひと言(#1407)。今回の13軒のうち#1407に出てきた店はありません。ただし、ウォルジョン里 (Woljeong-ri / 월정리)のカフェクハルグ (Cafe Guhalgu / 카페구할구)は、#1407に出てきたウォルジョン里の店(オヌルドファチャン (Oneul Dohwachang / 오늘도화창))と同じ路地(ウォルジョン5ギル (Woljeong 5-gil / 월정5길))で、キムニョン (Gimnyeong / 김녕)のカフェモアルボアル (Cafe Moalboal / 카페모알보알)は#1407のキムニョンの6軒と同じ町なので、その日の動線にいっしょに入れられます。

選定基準はひとつだけです——Naverマップに英語・日本語・中国語のレビューがいっしょに残るカフェ。韓国人の人気ランキングではなく、すでに外国人が訪れて三言語で足跡を残した場所のほうが、次の外国人にとって馴染みやすい選択だという判断です。レビュー数は2026-11時点で、店ごとに記載しました。例外は2つです——ママロン (Mamarong / 마마롱)とチャンムルギョル (Janmulgyeol / 잔물결)は中国語レビューがありませんが(どちらも5・1・0)、アウォル中山間のケーキデザートのカフェ、クムヌンのハンドドリップのロースタリーで、西部エリアの色合いが異なる2軒なので入れました。

⚠ 表記の原則: 営業時間・定休日・メニュー価格は、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した値です(2026-11-23確認)。価格はドリンク1杯・デザート1個の登録価格を記載します。価格が登録されていない店や、メニューの登録が2年以上前の店は「カカオマップで当日確認」としました。食事面のヒントはメニュー名とオーナーのメニュー説明から読み取れるものだけを書きました——材料・アレルギーは注文前にスタッフに確認してください。済州は広いので、エリア間の移動は車かバスです。この回では移動時間を書きません——その日にカカオマップの道案内で確認してください。

① 済州市 (空港・旧市街) — 2軒

済州空港周辺と旧市街です。2軒とも09:00に開きます——13軒のうちシスターフィールドとともに最も早い時間です。到着日の最初の一杯か、出発日の最後の一杯をここに入れられます。

  • ユドンコーヒー ソグムコンジャン店 — 済州空港周辺、ヨンダムサムドン (Yongdam-samdong / 용담삼동)のロースタリーカフェ。アメリカーノ ₩5,500、カフェラテ ₩5,500、コールドブルー ₩5,000、スクトクラテ (Ssuk Tteok Latte / 쑥떡라떼)(ヨモギ餅のラテ) ₩6,000、ツナミ ヘウンデコーヒー (Tsunami Haeundae Coffee / 쓰나미 해운대커피) ₩6,500。アメリカーノは豆4種から選べます(オーナー説明)。パン・デザートは価格が登録されていないので、店頭で見てください。外国語レビュー合計が15件でこの回で最も多く、英・日・中が5件ずつ残っているのはここだけです。毎日 09:00~18:00(ラストオーダー 17:30)、定休日は旧正月・秋夕の当日。済州市 (Jeju-si / 제주시)のヨンマソ1ギル30 (Yongmaseo 1-gil 30 / 용마서1길 30)。カカオマップに無料駐車・車椅子のタグがあります。食事面のヒント：ラテ類は牛乳が入ります。スクトクラテは名前のとおり餅が入るので、材料を聞いてください。コーヒーメニューはカフェインがあります。

④ ソギポ・南部 — 4軒

ソギポ (Seogwipo / 서귀포)のソホ洞 (Seoho-dong / 서호동)・カンジョン洞 (Gangjeong-dong / 강정동)(西側)・ハヒョ洞 (Hahyo-dong / 하효동)、アンドク (Andeok / 안덕)のトクス里 (Deoksu-ri / 덕수리)。チェジョムソクはソホ洞、シスターフィールドはカンジョン洞、スナオコヒはハヒョ洞、オーマイサロンはアンドクで、4軒が散らばっているので、地図アプリで位置を先に見てください。

  • チェジョムソク ベーカリー — ソギポ ソホ洞のベーカリー。マドレーヌ・揚げソボロパン (Twigim Soboro / 튀김소보루)・イカ墨クリームチーズ (Ojing-eo Meokmul Cream Cheese / 오징어먹물크림치즈)・クルミバスク (Hodu Basque / 호두바스크)・オリーブチャバタがありますが、価格の登録が2019~2023年の値なので、今の価格はカカオマップで当日確認。ドリンクは登録されていません。毎日 10:00~22:00で13軒のうち最も遅くまで登録されていますが、オーナーの文言に「用意したパンが売り切れたら早めに閉店」があります。ソギポのソホナム路32ボンギル29 (Seohonam-ro 32beon-gil 29 / 서호남로32번길 29)(カカオマップの店名は「チェジョムソクベーカリー ポンジョム (Chaejeomseok Bakery Bonjeom / 채점석베이커리 본점)」)。予約・持ち帰り可のタグ。外国語レビュー11件(5・3・3)でこのエリアで最も多いです。食事面のヒント：パンは小麦粉なのでグルテンが入ります。イカ墨クリームチーズはイカ墨(海鮮)とクリームチーズ(乳製品)が入ります。クルミバスクは名前の「バスク」が普通バスクチーズケーキを指すので、クリームチーズ・卵・乳製品が入っている可能性があり、クルミ(ナッツ)も入ります。マドレーヌは卵・バターがよく使われます——アレルギーがあればスタッフに聞いてください。
  • シスターフィールド — ソギポ カンジョン洞のベーカリー(カカオマップの店名は「シスターフィールドベーカリー (Sisterfield Bakery / 시스터필드베이커리)」)。オリーブカンパーニュ (Olive Campagne / 올리브 깜빠뉴) ₩4,500(2025-12登録)。ミルクティーパウンド・レモンジンジャーパウンド・バタースコーン・グリーンオリーブペストリーは2019~2021年の登録価格なのでカカオマップで当日確認。パウンドの2つのメニュー名に英語の「(1 piece)」が併記されています。ドリンクは登録されていません。毎日 09:00~18:00。ソギポのウォルドゥコプ路8 (Worldcup-ro 8 / 월드컵로 8)——同じ名前の別の屋号(コンサルティング・税務)があるので、住所で探します。予約・持ち帰り可のタグ。外国語レビュー9件(5・2・2)。食事面のヒント：バタースコーンはバター(乳製品)、ミルクティーパウンドは名前のとおりミルクティーが入ります。カンパーニュ・ペストリーは小麦粉のパンなのでグルテンが入り、オリーブのメニューはオリーブが入ります。
  • スナオコヒ — ハヒョ洞のロースティング・ハンドドリップのカフェ。アメリカーノ A・Bタイプ、カフェラテ、ミルクティー、抹茶ラテ、デザート「緑茶の味 (Nokcha-ui Mat / 녹차의 맛)」・「figue」があります——価格の登録が2023~2024年の値なのでカカオマップで当日確認。オーナーが書いた豆の味の説明は、アメリカーノAがシナモン・ストロベリー・ハニー、Bがチョコレート・ビスケットで、シロップのような材料が別に入るかは注文のときに聞いてください。毎日 11:00~18:00。ソギポのハシンサン路9ボンギル2 (Hasinsang-ro 9beon-gil 2 / 하신상로9번길 2)。外国語レビュー6件(2・2・2)。食事面のヒント：ラテ・ミルクティーは牛乳が入ります。デザートの「figue」はフランス語でイチジクで、「緑茶の味」は名前に緑茶があります。コーヒー・抹茶・緑茶はカフェインがあります。
  • オーマイサロン — アンドク面 (Andeok-myeon / 안덕면)トクス里のコーヒー・デザートのカフェ。カカオマップの登録メニューは国産の栗を自分で煮た栗の甘露煮ひとつで、価格の登録が2023-05の値なので、今の価格とドリンクの価格はカカオマップで当日確認。月~土 12:00~17:00(ラストオーダー 16:30)、日曜定休。 アンドク面のトクスフェグァン路74ボンギル32 (Deoksuhoegwan-ro 74beon-gil 32 / 덕수회관로74번길 32)。愛犬同伴・車椅子・予約可のタグ。外国語レビュー6件のうち英語が4件。食事面のヒント：栗の甘露煮は栗が入ります。ドリンクメニューは登録されていないので、店頭で見てください。

🗺 動線 — 宿泊エリア別に選ぶ

済州はエリア間が車・バスの距離なので、1日に複数のエリアを詰め込んで回る動線は向いていません。泊まる場所とその日の行程に合わせて、エリアをひとつ選びます。

A. 済州市に泊まるとき (空港・旧市街)

  1. 到着日・出発日 空港周辺のユドンコーヒー ソグムコンジャン店(09:00~18:00、ラストオーダー 17:30)
  2. 旧市街を歩く日 キエキ ロースティングルーム(09:00~18:00)——駐車場がないので、歩いて行く日に入れます

B. 東の行程 (ギョレ・ウォルジョン・キムニョン)

  1. 中山間へ行く日 ギョレのカフェマルロ(11:00~18:00)
  2. ウォルジョンのビーチへ行く日 カフェクハルグ(10:00~19:30)——同じ路地の#1407のパン屋とまとめます
  3. キムニョンの海岸へ行く日 カフェモアルボアル(10:30~18:30)——ノーキッズゾーンなので、子ども連れならウォルジョン側に変えます

C. 西の行程 (アウォル・ハンリム)

  1. 月~木 アウォルのマムピのパン(11:00~17:00) → ハンリムのチェジュシチャ(12:00~17:00)またはクムヌンのチャンムルギョル(11:00~18:00)
  2. 金~日 マムピが休みなので、アウォルのママロンのケーキ(10:00~18:00) → クムヌンのチャンムルギョル
  3. 月曜 ママロンが休みです——マムピ・チェジュシチャ・チャンムルギョル側で組みます

D. ソギポ・ジュンムン (Jungmun / 중문)に泊まるとき

  1. 朝 カンジョン洞のシスターフィールド(09:00~)——パウンドは1切れ単位
  2. 午前~昼過ぎ ソホ洞のチェジョムソク ベーカリー——パンがなくなると早く閉まるので急いで行きます
  3. ソギポ東のハヒョ洞側へ行く日 スナオコヒ(11:00~18:00)
  4. アンドク側へ行く日(月~土) オーマイサロン(12:00~17:00)

月曜はママロン、金・土・日はマムピ、日曜はオーマイサロンが休みです。ユドンコーヒーは旧正月・秋夕の当日に休みます。バスで回るなら、出発前にカカオマップの道案内で終バスを確認してください。済州の食堂は同じ型の#1437。

⚠ よくある失敗3つ

  1. 営業する曜日・時間が短い店に午後遅く行く — マムピは月~木 11:00~17:00にだけ開き、金・土・日は休みです。チェジュシチャは毎日 12:00~17:00、オーマイサロンは月~土 12:00~17:00(ラストオーダー 16:30)です。ママロンは月曜に休みます。西を回って17時を過ぎてから寄ると、3軒はもう閉まっています。
  2. 「22:00まで」という登録時間だけを信じて夕方にパンを買いに行く — チェジョムソク ベーカリーは10:00~22:00で登録されていますが、オーナーの文言に「用意したパンが売り切れたら早めに閉店」があります。パンが目的なら早い時間に行ってください。
  3. 名前が似た別の店に行く — チャンムルギョルには済州市にチャンムルギョル シティロースターズ(ノヒョン)・チャンムルギョル コーヒーハウス(イド)が別にあります。カフェマルロはカカオマップに「マル」、シスターフィールドは「シスターフィールドベーカリー」、チェジョムソクは「チェジョムソクベーカリー ポンジョム」で登録されています。地図アプリでは店名ではなく、この回の道路名住所で探してください。

⚙ よくある質問3つ

  1. ひとつだけ選ぶなら？ — 外国語レビュー合計が最も多く、英・日・中が5件ずつ残っているのはユドンコーヒー ソグムコンジャン店(15件、5・5・5)ひとつです。済州空港周辺なので、到着日や出発日の行程に入れられます。パンが目的なら、レビュー11件(5・3・3)のチェジョムソク ベーカリーかシスターフィールド(価格はカカオマップで当日確認)。
  2. カカオマップのメニュー名が英語の店は？ — カカオマップのメニュー名を英語で登録している店はキエキ ロースティングルーム(12個のうち大半)です。シスターフィールドはパウンドの2つのメニュー名に「(1 piece)」が付いています。ほかは英語メニューがあるかどうかわかっていないので、翻訳アプリを用意しましょう。
  3. 済州のパン屋とカフェの使い方をもっと知りたいなら？ — 済州東部のパン屋とキムニョンの6軒は#1407。席取り・マグカップ・返却台のような韓国のカフェ店内のルールは#1378。済州の食堂は同じ型の#1437、五日市場は#1348。
