한국 떡 주문·명절 워크플로우 — 설날 떡국부터 추석 송편 만들기까지

> 부제: 외국인 관광객용 5-step 워크플로우 + 명절 음식 매너·체험·결제 팁

ISSUE 03 · #856 · 2026-06-09

🎯 왜 한국 떡 워크플로우 가이드인가

[#855 떡류 6종 매트릭스](#855) 알아도 — 주문·명절·체험은 별개. 한국 떡은 (a) 전통 떡집 (광장시장·인사동 노포) (b) 명절 시즌 (설·추석 = 가족 모임 떡 #1) (c) MZ 카페 (인절미 토스트·찰떡볶이) (d) 돌·결혼식 주문 (백설기·인절미 1관 단위). 외국인은 (1) 명절 시기·의미 모름 (2) 송편 만들기 체험 모름 (3) 떡국 먹는 법 모름 (4) 진공 포장 귀국 선물 모름. 본 가이드는 5-step + 명절 매너 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 떡집 / 마트 / MZ 카페 / 체험 매장 즉시 시기·목적에 맞춤
2️⃣ 메뉴·상품 선택 떡 + 명절 시즌 + 진공 포장 2~5분 시즌 한정 메뉴 확인
3️⃣ 받기·시식 매장 시식 / 떡집 픽업 / 체험 변동 송편 만들기 = 1~2h 체험
4️⃣ 먹기·페어링 차·국·반찬 페어 15~60분 떡국·송편·인절미 정통 페어
5️⃣ 구매·결제 매장·면세점·온라인 1~5분 진공 포장 = 귀국 선물 OK

> 총 소요 시간: 떡집 = 10~30분 / 매장 식사 = 30~60분 / 송편 체험 = 1~2h

🗓 명절 시즌 워크플로우

설날 (음력 1/1) 워크플로우

1. 떡국 준비: 가래떡 슬라이스 + 소고기 육수·만두·계란·김

2. 새해 인사: 어른에게 세배·"새해 복 많이 받으세요"

3. 떡국 먹기: 한 그릇 = 한 살 더 먹기 의미

4. 세뱃돈: 어른이 어린이에게 (현금)

5. 2026 설날: 양력 2/17 (음력 1/1)

추석 (음력 8/15) 워크플로우

1. 송편 만들기 체험 (가족 또는 체험 매장)

2. 차례·성묘: 가족 모임

3. 송편 먹기: 깨·콩·밤 소

4. 2026 추석: 양력 9/25 (음력 8/15)

외국인 체험 추천

  • 북촌 한옥마을 송편 만들기 체험 (가을 9~10월) — 외국인 #1
  • 전주 한옥마을 떡 만들기 체험
  • 인사동 전통 떡집 시식 투어

🍽 떡 + 음료 페어링 매트릭스

떡 + 한국 전통 음료 페어

떡 베스트 페어 음료 외국인 입문
떡국 식혜·수정과 설날 정통
송편 녹차·국화차 추석 정통
인절미 식혜·녹차 MZ 인절미 라떼
백설기 식혜·수정과 잔치 정통
경단 녹차·식혜 간식 페어
찰떡볶이 음료 없이 OR 사이다 MZ 분식

MZ 트렌드 페어

  • 인절미 토스트 + 라떼 = MZ 카페 #1
  • 송편 + 녹차 라떼 = 한옥 카페 MZ
  • 찰떡볶이 + 막걸리 = MZ 분식 야식

🌶 외국인 영어 발화 샘플

  • "떡국 하나" = "One tteokguk, please"
  • "송편 10개" = "Ten songpyeon, please"
  • "인절미 작게 잘라주세요" = "Cut injeolmi small, please" (어린이 질식 주의)
  • "송편 만들기 체험" = "Songpyeon making experience"
  • "진공 포장 사고 싶어요" = "I want vacuum-packed rice cake, please"
  • "새해 복 많이 받으세요" (Sebae) = "Happy New Year (Lunar)"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "떡 = 떡볶이만": 6종 풀세트 + 명절·잔치 정통.

2. "설날·추석 = 양력": 한국 명절 = 음력 (설 1/1·추석 8/15) → 양력 매년 다름.

3. "송편 = 사계절": 송편 = 추석 한정 (9~10월).

4. "가래떡 = 일반 떡": 가래떡 = 설날 떡국 정통 원기둥 모양.

5. "인절미 = 일반 간식": 인절미 = 잔치·결혼식 정통 콩고물.

6. "백설기 = 일반 떡": 백설기 = 돌·기념일 정통 (1관 30,000원~).

7. "떡 = 질식 X": 가래떡·인절미 = 질식 위험 ↑ (어린이·노인 작게).

⚙ FAQ 8개

1. 첫 떡 = 어떤 메뉴: 떡국 (설날 정통) → 송편 (추석) → 인절미 단계.

2. 인스타·vlog: 추석 송편 만들기·MZ 인절미 토스트·인사동 전통 떡집.

3. MZ 트렌드: 찰떡볶이·인절미 토스트·인절미 빙수·MZ 송편.

4. 체험 추천: 북촌·전주 송편 만들기 체험 (가을 9~10월).

5. 선물·면세점: 진공 포장 떡 = 귀국 선물 가능 (15,000~30,000원).

6. 알레르기: 콩·깨·견과류·꿀 사전 고지.

7. 결제·팁: 떡집·면세점 = 카드 OK / 시장 = 현금 / 팁 X.

8. VAT 환급: 식음료 X / 면세점 떡 = 환급 가능.

⚠ 의료·안전·식이 disclaimer

떡 = 일반 음식. 질식 위험 (가래떡·인절미 = 어린이·노인 작게 잘라서). 임신부 = 콩고물·견과류 적당량. 어린이 = 질식 주의 #1. 알레르기 (콩·깨·견과류·꿀) 사전 고지. 질식·식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 동물 재료 X = OK (꿀 함유 확인).
  • 채식·비건: 6종 모두 채식 OK (꿀 함유 시 비건 X).
  • 글루텐 free: 6종 모두 쌀 100% = 글루텐 free OK.

💰 Essential Tourist Tips

  • 1관 평균 비용 (2026년 6월 기준):
  • 가래떡 500g = 5,000~10,000원
  • 떡국 1인 = 8,000~15,000원
  • 송편 10개 = 5,000~10,000원
  • 인절미 500g = 5,000~10,000원
  • 백설기 1관 = 30,000~80,000원 (잔치용)
  • 체험비: 송편 만들기 = 30,000~80,000원/인 (북촌·전주)
  • 면세점 진공 포장 = 귀국 선물 (15,000~30,000원)
  • 결제·팁: 카드 OK 多 / 시장 = 현금 / 팁 X
