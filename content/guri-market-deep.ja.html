九里ガイド — 九里農水産物卸売市場、東九陵(ユネスコ世界遺産)、九里タワー、九里漢江市民公園、九里ドゥルレギル1~3コース、九里子ども天文台・九里トピョン家族キャンプ場

サブタイトル: 九里農水産物卸売市場(夜・夜明け前の卸取引) · 東九陵(11~1月 06:30~17:30、月曜日休み、祝日・振替休日と重なれば開放でその次の最初の祝日でない日に休み、1,000ウォン) · 九里タワー(09:00~23:00、無料) · 九里漢江市民公園(常時開放、無料) · 九里ドゥルレギル1~3コース(7.8~7.9km) · 九里子ども天文台(15:00~23:00) · 九里トピョン家族キャンプ場 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、京畿道の九里市で行く場所をまとめたものです。卸売市場、朝鮮王陵9基が集まる東九陵、九里資源回収施設の煙突を展望台に使った九里タワー、花畑のある漢江の公園、峨嵯山から王宿川まで続く周遊路です。東九陵は月曜日が休みですが、月曜日が祝日・振替休日なら開き、その次の最初の祝日でない日に休みます。峨嵯山は#740 ソウル北東部の森・公園ガイドにもあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 卸売市場 — 九里農水産物卸売市場

九里農水産物卸売市場、九里市 Domaesijang-ro 68 (도매시장로 68)、☎ 031-560-5100 は、韓国観光公社の紹介によると、ガラク洞 (Garak-dong / 가락동)の農水産物卸売市場に次いで韓国で2番目に大きい卸売市場です。九里市とソウル市が共同で1997年6月に建てました。年間の最大取扱量は836,000トンで、野菜・青果棟と水産棟、水産2棟があります。

取引は夜と夜明け前に卸で行われます。入荷した量の90%は競りで売られ、残りは仲卸業者の店舗に移されて卸売商と小売商に売られます。白菜、大根、キノコ、スイカ、リンゴ、トマトのような青果物162品目と、サバ、タチウオ、サルボウガイ、ワタリガニ、スケトウダラ、カキのような水産物110品目を扱います。

  • 開く時間・休み: 店舗ごとに異なります。駐車: 可能。

📍 朝鮮王陵 — 東九陵

東九陵、九里市 Donggureung-ro 197 (동구릉로 197)、☎ 031-579-4900 は、「東にある9基の陵」という意味です。約450年のあいだに王7人と王妃10人が葬られ、韓国観光公社の紹介によると、朝鮮最大の王陵群です。1408年に太祖の健元陵 (Geonwonneung / 건원릉)がまず造られ、続いてムンジョン (Munjong / 문종)・ソンジョ (Seonjo / 선조)・ヒョンジョン (Hyeonjong / 현종)・ヨンジョ (Yeongjo / 영조)・ホンジョン (Heonjong / 헌종)などの陵が順に造られました。王または王后一人だけを祀る単陵、並べて祀る双陵、王と王后を一緒に祀る合葬陵、王と二人の王后を並べて祀る三連陵など、さまざまな形が集まっています。

  • 開く時間: 11~1月 06:30~17:30(入場締切 16:30)。2~5月・9~10月 06:00~18:00(入場締切 17:00)、6~8月 06:00~18:30(入場締切 17:30)。
  • 休み: 毎週月曜日。月曜日が祝日・振替休日なら開き、その次の最初の祝日でない日に休みます。
  • 料金: 個人1,000ウォン、10人以上の団体800ウォン。駐車: 可能。

📍 展望台と川辺 — 九里タワー・九里漢江市民公園

九里タワー、九里市 Wangsukcheon-ro 49 (왕숙천로 49)、☎ 031-550-2880 は、九里市の資源回収施設の煙突を展望台に使った塔です。地上100mの展望台から、48角のガラス窓ごしに九里とソウルを見下ろします。展望台のハヌルギャラリー (Haneul Gaelleori / 하늘갤러리)で、地域の芸術家の作品を展示しています。

  • 開く時間: 09:00~23:00。休み: 年中無休。料金: 無料。駐車: 可能。

九里漢江市民公園、九里市 Koseumoseu-gil 14beon-gil 249 (코스모스길14번길 249)、☎ 九里市庁 公園緑地課 031-550-2472 は、コスモス公園 (Koseumoseu Gongwon / 코스모스공원)とも呼ばれます。ツルアジサイのトンネル、菜の花・コスモスの園、ファミリー・ヒーリング・キャンプ場、自然学習場、散策路があります。5月には菜の花祭り、秋にはコスモス祭りが開かれると紹介されています。ファミリー・ヒーリング・キャンプ場は日陰とトイレ、水飲み場がありますが、野営と炊事はできず、先着順で使います。

  • 開く時間: 公園は常時開放。ファミリー・ヒーリング・キャンプ場は1~5月 10:00~18:00、6~9月 09:00~21:00、10~12月 10:00~18:00。
  • 休み: 年中無休。料金: 無料。
  • 駐車: 約800台。最初の10分は無料、30分以内は1,000ウォン、その後は10分ごとに200ウォン、1日の上限は10,000ウォン。

📍 歩く道 — 九里ドゥルレギル1~3コース

九里ドゥルレギルは、峨嵯山 (Achasan / 아차산)、漢江、王宿川 (Wangsukcheon / 왕숙천)をつなぐ道で、4コースで合計約32kmです。韓国観光公社の観光情報には1~3コースが登録されています(☎ 九里市 公園緑地課 031-550-2909)。

  • 1コース(歴史と自然が生きている道): 峨嵯山からマンウ山 (Mangusan / 망우산)まで7.9km、約4時間。出発点のコグリョデジャンガンマウル (Goguryeo Daejanggan Maeul / 고구려대장간마을)は、ドラマ「テワンサシンギ (Taewang Sasingi / 태왕사신기)」と「ソンドクヨワン (Seondeok Yeowang / 선덕여왕)」の撮影地です。峨嵯山の堡塁群(史跡)を過ぎ、マンヘ・ハン・ヨンウン (Manhae Han Yongun / 만해 한용운)とチュクサン・チョ・ボンアム (Juksan Jo Bongam / 죽산 조봉암)の墓があるマンウ墓地 (Mangu Myoyeok / 망우 묘역)とマンウ歴史公園 (Mangu Yeoksa Gongwon / 망우역사공원)で終わります。険しい区間が比較的少ないと紹介されています。
  • 2コース(クルンサンとカルメマウルをつなぐ道): 2コースの説明が1コースの終点と書くタルギウォン (Ttalgiwon / 딸기원)入口から始まり、1コースの説明は終点をマンウ歴史公園と書いていて二つの値が食い違っています。東九陵を囲むクルンサン (Gureungsan / 구릉산)とカルメ川 (Galmaecheon / 갈매천)に沿って進みます。7.8km、約3時間30分。
  • 3コース(王宿川と都心生活公園が調和する道): サノ・インターチェンジ (Sano Nadeulmok / 사노 나들목)からワンスク体育公園 (Wangsuk Cheyuk Gongwon / 왕숙체육공원)、九里農水産物卸売市場、王宿川生態湿地 (Wangsukcheon Saengtae Seupji / 왕숙천 생태습지)を過ぎて九里資源回収施設まで行きます。7.8km、約2時間30分。王宿川の自転車道と同じ道です。

📍 星とキャンプ — 九里子ども天文台・九里トピョン家族キャンプ場

九里子ども天文台、九里市 Donggureung-ro 427 (동구릉로 427)、3階、☎ 031-523-3245 は、2020年に開いた子ども向けの天文台です。3階で天文教室の授業を、4階の観測所で天体望遠鏡の観測を行います。講義室4室、ドーム、屋上観測所があり、望遠鏡を11台そろえています。

  • 開く時間: 15:00~23:00。休み: 毎週日曜日・月曜日、祝日。料金: プログラムごとに異なります。

九里トピョン家族キャンプ場、九里市 Wangsukcheon-ro 11-140 (왕숙천로 11-140)、☎ 031-550-3788 は、漢江と王宿川が出会うトピョン洞 (Topyeong-dong / 토평동)にあるキャンプ場です。共用のトイレ、シャワー室、食器洗い場、電気設備があります。愛犬を連れての入場は不可能と登録されています。

  • 開く時間: チェックイン 14:00、チェックアウト 11:00。休み: 年中無休。

⚠ 前もって知っておきたい3つのこと

  1. 東九陵は月曜日が休みで、祝日・振替休日と重なればその次の最初の祝日でない日に休みます — 冬(11~1月)は06:30~17:30に開き、16:30に入場を締め切ります。
  2. 卸売市場の取引は夜と夜明け前に行われます — 店舗ごとに開く時間が異なると登録されています。
  3. 九里子ども天文台は日曜日・月曜日と祝日が休みです — 15:00~23:00に開きます。

⚙ FAQ 2

Q. 東九陵の入場料は?

A. 韓国観光公社の登録情報では、個人1,000ウォン、10人以上の団体800ウォンです。
