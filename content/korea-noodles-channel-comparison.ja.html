🎯 segment別1位おすすめ

👤 ソロ旅行者 (Solo)

  • 1順位: 韓国中食堂(ちょっとしたら) — 1人 walk-in OK, チャジャン + チャンポンコスパ9,000ウォン～
  • 2順位: ラーメンチェーン（コンビニ＋食堂） — 1人5,000～10,000ウォン
  • 3順位: 分食(ごちそう麺・カルグクス) 1人 walk-in
  • 回避：冷麺老舗夕方（一人で雰囲気適応困難）

💑 カップル (Couple)

  • 1順位: 冷麺老舗（ウレオク・ピルドンミョンオク） — 本格的な雰囲気、デートコース、1人18,000ウォン
  • 2順位: 韓国中華レストラン
  • 3順位: 分食(市場雰囲気デート)
  • 回避：平日の昼間のラーメンチェーン（雰囲気↓）

👨‍👩‍👧 ファミリー (Family)

  • 1順位: 韓国中食堂(チャジャンミョン+タンスユク+チャンポン) — 子供チャムジャンミョン #1, 4人 50,000~80,000ウォン
  • 2順位：冷麺老舗（淡白平壌冷麺＋餃子子供OK）
  • 3順位: 分食
  • 回避：火鶏ラーメンチェーン（辛味）

🎨 MZ トレンド(MZ)

  • 1ランキング: ラーメンチェーン（フワフワチャレンジ・チーズラーメン・トレンドメニュー） — インスタ・vlog 1番地
  • 2ランク：平壌冷麺老舗（vlogマニア）
  • 3順位: MZ分食ラポキ
  • 回避：一般韓国中食堂（トレンディ↓）

🎒 バックパッカー・予算型 (Budget)

  • 1ランク: ラーメンチェーン+コンビニ — 1人1,500～10,000ウォン
  • 2順位: 韓国中食堂 チャジャンミョン単品 (7,000ウォン～)
  • 3順位: 分食ごちそう(6,000ウォン~)
  • 回避：冷麺老舗（15,000ウォン+）

🍜 4チャンネル deep dive

🥢 韓国中華レストラン (Korean-Chinese)

コアバリュー: チャジャン綿+チャンポン+湯たんぽクラシック。韓国式中華（1900年代初頭仁川発想）本格。

  • おすすめ店（ソウル）：
  • 仁川チャイナタウン — 韓国チャジャン面発祥の地・共和春 (1908)
  • 明洞中華レストランcluster - 外国人にやさしい★
  • 江南・駅三韓国中食堂 - 会社員ランチ1ランク
  • おすすめ店舗（地方）：仁川チャイナタウンcluster
  • メニュー: ジャジャンミョン・チャンポン・チャンチャミョン・タンスユク・カンプンギ・グンマンドゥ・チャーハン
  • 価格 anchor: チャジャンミョン 7,000~10,000ウォン / チャンポン 8,000~13,000ウォン / 湯 25,000~40,000ウォン
  • 外国人親和性: ★★★★ (英語メニュー 多・韓国中華シグネチャー)
  • 決済：カードOK /老舗一部現金

🧊 冷麺老舗 (Naengmyeon Heritage)

核心価値: 平壌式vs咸興式本物+両班家+100年老舗。韓国の麺類本格1番地。

  • おすすめ店（ソウル）：
  • ウレオク (1946 平壌創業, ソウル再開店 1953) — 平壌冷麺本場
  • 必洞面玉 — 平壌式老舗
  • 乙密隊（麻浦・駅三） — 平壌式マニア #1
  • オジャンドン興南店（1953） - 咸興冷麺本場
  • 推奨店舗（脂肪）：
  • 釜山プルミョン cluster — 咸興冷麺変形
  • メニュー：平壌冷麺・咸興冷麺・餃子（ペア）
  • 価格anchor：12,000〜18,000ウォン+餃子8,000〜12,000ウォン
  • 外国人親和性: ★★★★ (vlog ★、老舗雰囲気)
  • 決済：カウンター多（老舗=現金推奨/新生=カードOK）
  • 予約: ランチ(12:00~13:30) =ジュラ

🍜 ラーメンチェーン (Ramyeon Chain)

核心価値: グローバルラーメン認知度+トレンド+チャレンジメニュー。外国人MZマニア1番地。

  • おすすめストア:
  • コンビニエンスストア（CU・GS25・セブンイレブン）：即席沸騰（1,500～3,500ウォン）
  • チェーンラーメン店舗: 新ラーメンカフェ・チャパゲティ店舗・焼肉チャレンジ店舗
  • MZ分食店: ラポキ・チーズラーメン
  • シグネチャー製品：
  • 新ラーメン — 韓国 #1 グローバル
  • チャパゲティ — 映画「寄生虫」効果
  • 火鶏炒め面 — グローバルチャレンジ
  • サムヤンラーメン — 韓国 #1 老舗 (1963)
  • 価格 anchor: コンビニエンスストア 1,500～3,500ウォン / レストラン 4,000～10,000ウォン
  • 外国人親和性: ★★★★★ (グローバル認知・英語メニュー多)
  • お支払い：カード+キオスクOK

🛒 分食・市場 (Bunsik・Market)

核心価値: ごちそう麺・カル麺＋市場雰囲気＋苛性比。韓国の伝統的な麺マニア。

  • おすすめ店（ソウル）：
  • 明洞餃子（1966） - カルグクス+餃子老舗
  • 広場市場分食 — ごちそう麺・カルグクス・ラポッキ
  • 仁寺洞の分食 — 伝統メニュー
  • 鍾路カルグクス路地
  • 推奨店舗（脂肪）：
  • 春川・紅川マクグクス cluster (江原)
  • 全州韓屋村ごちそう麺
  • メニュー：ごちそう麺・刀麺・幕麺・ラポッキ
  • 価格 anchor: 6,000~12,000ウォン
  • 外国人親和性: ★★★ (韓国語メニュー多・写真メニュー活用)
  • 決済: 現金・カード混用

⚠外国人の頻繁な誤り5つ

1. 「4チャンネル＝似ている」：メニュー・価格・雰囲気全く違う。織り=中華/冷麺=老舗/ラーメン=チェーン/ごちそう麺・刀麺=分食。

2. 「韓国中食堂=中国集」: 韓国中食= 韓国発想 (1900年代初頭仁川)。中国子ジャンミエン≠韓国チャジャンミョン。

3. 「ラーメン＝コンビニのみ」：チェーンラーメン店舗・MZ分食・食堂ラーメンもフルセット。

4. 「冷麺＝夏のみ」：冷麺老舗＝年中営業。ただ夏マニア1ランク。

5. 「分食=ストリートのみ」: 明洞餃子(1966)のような老舗分食カテゴリー。正統饗宴麺・刀麺。

⚙ よくある質問8件

1. 最初の麺類 = どこ: 韓国の中華料理店(チャジャンミョン+チャンチャミョン) 1ランク。グローバル認知度＋外国人入門#1。

2. インスタ・vlog 1順位: 火鶏炒め面チャレンジ+平壌冷麺ハサミ。

3. 夏1順位: 平壌冷麺老舗(ウレオク・ピルドンミョンオク) — 涼園・正統。

4. 会食・接待 1順位: 冷麺老舗(正統) — 正統両班家の雰囲気。

5. MZ トレンド: 火鶏チャレンジ・チーズラーメン・チャパゲティ（寄生虫効果）。

6. アレルギー・妊娠: [#813・#814 disclaimer](#813)参照。そば（buckwheat）＝平壌冷麺注意。

7. 決済・チップ: カードOK/老舗 一部現金/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

麺類4チャンネルとも90～100℃の熱いスープ（冷麺を除く）。やけど注意。火鶏チャレンジ＝牛乳・チーズ準備。妊婦=辛味+そば（buckwheat）アレルギー。子ども＝チャジャン麺・ごちそう麺・刀麺推奨。アレルギー（グルテン・シーフード・豆・卵・そば・甲殻類）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

老舗情報免責：店舗の営業時間・メニュー・決済方針は変動可

食事制限 fallback:

  • ハラール・コーシャー: 6種のうち認証店舗ほとんどない。 →梨泰院・江南一部認証店舗事前検索。
  • ベジタリアン・ビーガン: きのこ刀麺・野菜ごちそうができます（アンチョビスープ除外要請）。ジャジャンミョン・ラーメン・チャンポン＝非菜食。
  • グルテンフリー：6種ともに小麦粉麺（冷麺＝そば・澱粉） — オプションほとんど無し。
