汉江公园指南 — 北岸兰芝·望远·二村，南岸江西·杨花·盘浦·蚕院·蚕室·广津汉江公园共9处

副标题:汉江公园9处全天开放·全年无休 · 盘浦(月光彩虹喷泉，停车669辆) · 蚕院(停车722辆) · 兰芝(江边戏水场最大水深80厘米) · 广津(饮用水源保护区) · 杨花(5月蔷薇) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南把首尔沿汉江而建的汉江公园9处分为江北3处(兰芝·望远·二村)、江南6处(江西·杨花·盘浦·蚕院·蚕室·广津)。9处均登记为全天开放、全年无休，没有登记的费用。汝矣岛汉江公园收录在 #705 指南，纛岛汉江公园收录在 #709 指南。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 江北 — 兰芝·望远·二村汉江公园

兰芝汉江公园 (Nanji Hangang Gongwon / 난지한강공원)，地址为麻浦区 (Mapo-gu Hangang Nanji-ro 162 / 마포구 한강난지로 162)，☎ 02-3780-0611~3，位于Hongjecheon大桥 (Hongjecheon-gyo / 홍제천교) 与Nanjicheon大桥 (Nanjicheon-gyo / 난지천교) 之间。设有与Noeul公园 (Noeul Gongwon / 노을공원)·Haneul公园 (Haneul Gongwon / 하늘공원) 相连的中央连接桥 (Jungang Yeongyeol Beuriji / 중앙연결브릿지)、和平公园连接桥 (Pyeonghwa-ui Gongwon Yeongyeol Beuriji / 평화의 공원 연결브릿지)和复合连接通道。和平公园连接桥前的镜面喷泉 (Geoul Bunsu / 거울분수) 是这座公园的地标。夏天可以使用最大水深80厘米的江边戏水场，在生态湿地园步行连接桥 (Saengtae Seupjiwon Bohaeng Yeongyeol Beuriji / 생태습지원 보행연결브릿지) 上可以观察生活在水边的动物。附近的兰芝露营场 (Nanji Camping-jang / 난지캠핑장) 可以烧烤和露营。自行车道向东通往纛岛公园 (Ttukseom Gongwon / 뚝섬공원)，向西通往高阳市幸州大桥 (Haengju Daegyo / 행주대교) 南端以及Noeul公园·Haneul公园。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(618辆)。

望远汉江公园 (Mangwon Hangang Gongwon / 망원한강공원)，地址为麻浦区 (Mapo-gu Mapo Naru-gil 467 / 마포구 마포나루길 467)，☎ 02-3780-0601，位于Wonhyo大桥 (Wonhyo Daegyo / 원효대교) 与城山大桥 (Seongsan Daegyo / 성산대교) 之间的江北。河滩上有草坪、散步道、运动设施和自行车道，水面上可以进行帆板·滑水·摩托艇等水上休闲。周边有望远亭 (Mangwonjeong / 망원정) 和切头山圣地 (Jeoldusan Seongji / 절두산 성지) 等古迹。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

二村汉江公园 (Ichon Hangang Gongwon / 이촌한강공원)，地址为龙山区 (Yongsan-gu Ichon-ro 72-gil 62 / 용산구 이촌로72길 62)，☎ 02-3780-0551~4，位于Geumho洞 (Geumho-dong / 금호동) Jungnangcheon大桥 (Jungnangcheon-gyo / 중랑천교) 与二村洞 (Ichon-dong / 이촌동) Wonhyo大桥 (Wonhyo Daegyo / 원효대교) 之间的江北。秋天沿着护岸盛开芦苇·芒草·波斯菊。设有青少年广场 (Cheongsonyeon Gwangjang / 청소년광장)、X-Game场 (X-Game-jang / X-게임장)、国际规模的轮滑场、篮球场、网球场、门球场，汉江渡江体验场 (Hangang Dohyang Cheheomjang / 한강도하체험장) 被用作团体团队合作训练场。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(371辆)。

📍 江南西部 — 江西·杨花汉江公园

江西汉江公园 (Gangseo Hangang Gongwon / 강서한강공원)，地址为江西区 (Gangseo-gu Yangcheon-ro 27-gil 279-23 / 강서구 양천로27길 279-23)，☎ 02-3780-0621~3，是从加阳大桥延伸到首尔·金浦市界的公园。由湿地生态公园和体育公园合并而成，被选为首尔市30处生态旅游名所之一。江西湿地生态公园 (Gangseo Seupji Saengtae Gongwon / 강서습지생태공원) 复原了河中岛 (Hajungdo / 하중도)、自然观察路和湿草地。在傍花大桥 (Banghwa Daegyo / 방화대교) 下、家庭野餐场前、幸州大桥 (Haengju Daegyo / 행주대교) 下设有健身器材。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

杨花汉江公园 (Yanghwa Hangang Gongwon / 양화한강공원)，地址为永登浦区 (Yeongdeungpo-gu Nodeul-ro 221 / 영등포구 노들로 221)，☎ 02-3780-0581~3，位于从汝矣岛Saetgang河口 (Yeouido Saetgang / 여의도 샛강) 到加阳大桥的江南。河滩上有宽阔的草坪，自行车道从Saetgang河口延伸到加阳大桥。Seonyu桥 (Seonyu-gyo / 선유교) 下自行车道旁从5月开始盛开蔷薇。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(501辆)。婴儿车:可以。

📍 江南中东部 — 盘浦·蚕院·蚕室·广津汉江公园

盘浦汉江公园 (Banpo Hangang Gongwon / 반포한강공원)，地址为瑞草区 (Seocho-gu Sinbanpo-ro 11-gil 40 / 서초구 신반포로11길 40)，☎ 02-3780-0541~4，以盘浦大桥 (Banpo Daegyo / 반포대교 · Jamsugyo / 잠수교) 为中心，位于汉南大桥与铜雀大桥之间的江南。设在盘浦大桥两侧的月光彩虹喷泉 (Dalbit Mujigae Bunsu / 달빛무지개분수) 总长1,140m，据观光公社介绍，2008年作为世界最长的桥梁喷泉载入吉尼斯纪录。夜晚伴着200多盏灯光喷水。在铜雀大桥南端的瞭望台Noeul咖啡 (Noeul Cafe / 노을카페) 和Gureum咖啡 (Gureum Cafe / 구름카페) 可以眺望汉江。与公园相连的人工岛瑞来岛 (Seoraeseom / 서래섬) 每个季节都种植油菜花·荞麦，春天举办瑞来岛蝴蝶·油菜花庆典 (Seoraeseom Nabi·Yuchaekkot Chukje / 서래섬 나비·유채꽃 축제)。还有水滴游乐场 (Mulbangul Noliteo / 물방울놀이터)、轮滑专用跑道、足球场、篮球场、划船场和野餐场。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(669辆)。

蚕院汉江公园 (Jamwon Hangang Gongwon / 잠원한강공원)，地址为瑞草区 (Seocho-gu Jamwon-ro 221-124 / 서초구 잠원로 221-124)，☎ 02-3780-0531~3，位于从Yeongdong大桥 (Yeongdong Daegyo / 영동대교) 经东湖大桥 (Dongho Daegyo / 동호대교)、汉南大桥到盘浦大桥的江南，长度为5.4公里。设有田径场、足球场、排球场、游泳池、网球场、健身场，还有沿江自行车道。设有养蚕体验学习场 (Nuye Cheheom Hakseupjang / 누에체험학습장) 和自然生态学习场，夏天有很多人在户外游泳池游泳、玩帆板和摩托艇。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(722辆)。

蚕室汉江公园 (Jamsil Hangang Gongwon / 잠실한강공원)，地址为松坡区 (Songpa-gu Hangaram-ro 65 / 송파구 한가람로 65)，☎ 02-3780-0511~4 未来汉江本部蚕室咨询中心 (Mirae Hangang Bonbu Jamsil Annae Senteo / 미래한강본부 잠실안내센터)，位于Jamsil铁桥 (Jamsil Cheolgyo / 잠실철교) 与Yeongdong大桥 (Yeongdong Daegyo / 영동대교) 之间的江南。离蚕室综合运动场 (Jamsil Jonghap Undongjang / 잠실종합운동장)、乐天世界 (Lotte World / 롯데월드)、奥林匹克公园 (Olympic Gongwon / 올림픽공원) 很近。设有种植花卉·野花·农作物的自然学习场，并在蚕室水中堰 (Jamsil Sujungbo / 잠실 수중보) 的鱼道 (Eodo / 어도) 举办生态项目。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

广津汉江公园 (Gwangnaru Hangang Gongwon / 광나루한강공원)，地址为江东区 (Gangdong-gu Seonsa-ro 83-106 / 강동구 선사로 83-106)，☎ 02-3780-0501~4，位于江东大桥与Jamsil铁桥 (Jamsil Cheolgyo / 잠실철교) 之间。有上游冲来的泥土堆积而成的沙洲和大片芦苇群落。据观光公社介绍，这里是首尔市唯一的饮用水源保护区，因此禁止划船和水上·休闲活动。河滩上有长达2公里的芦苇丛，栖息着候鸟。附近有岩寺洞史前居住地 (Amsa-dong Seonsa Jujuji / 암사동 선사주거지) 等古迹。

  • 开放时间:全天开放。休息日:全年无休。停车:可以(389辆)。

⚠ 行前须知 3 点

  1. 广津汉江公园不能进行划船和水上·休闲活动 — 因为是饮用水源保护区，这些活动被禁止。
  2. 登记有帆板·滑水·摩托艇的地方是望远·蚕院 — 望远登记有帆板·滑水·摩托艇，蚕院登记有夏季帆板·摩托艇。
  3. 兰芝江边戏水场是夏季设施 — 最大水深80厘米。蚕院夏天使用户外游泳池的人很多。

⚙ FAQ 2

Q. 可以露营或烧烤的汉江公园是哪里?

A. 按观光公社登记信息，兰芝汉江公园 (Nanji Hangang Gongwon / 난지한강공원) 附近的兰芝露营场 (Nanji Camping-jang / 난지캠핑장) 可以烧烤和露营。

Q. 登记有开花时期的汉江公园是哪里?

A. 杨花汉江公园 (Yanghwa Hangang Gongwon / 양화한강공원) 从5月开始Seonyu桥 (Seonyu-gyo / 선유교) 下盛开蔷薇，盘浦汉江公园 (Banpo Hangang Gongwon / 반포한강공원) 的瑞来岛 (Seoraeseom / 서래섬) 春天盛开油菜花，二村汉江公园 (Ichon Hangang Gongwon / 이촌한강공원) 秋天盛开芦苇·芒草·波斯菊。
