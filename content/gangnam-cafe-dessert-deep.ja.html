江南カフェ・デザート 深掘りガイド

狎鴎亭・島山・清潭・新沙 ラグジュアリー cluster — デザイン cafe・specialty・ミシュランデザート15ヶ所

江南 (Gangnam / 강남) は韓国のラグジュアリー・デザインの頂点。狎鴎亭ロデオ (Apgujeong Rodeo / 압구정 로데오)・島山公園 (Dosan Park / 도산공원)・清潭洞 (Cheongdam-dong / 청담동)・新沙洞 (Sinsa-dong / 신사동) の街路樹通り (Garosu-gil / 가로수길) に、specialty cafe・ラグジュアリーデザート・デザイン cafe・ミシュランデザートが dense。本ガイドは、外国人 segment・special occasion・MZ ペルソナに fit した15ヶ所 + 1日動線マトリックス。

1. 江南カフェ分布

江南区は、地下鉄3・7・9号線と水仁盆唐線 (Suin-Bundang Line / 수인분당선) が交差する構造。カフェ・デザート cluster は大きく6つのエリアに分かれる。

  • 狎鴎亭ロデオ: 3号線 狎鴎亭駅 (Apgujeong Station / 압구정역) 徒歩5分。トレンディ・MZ・デザート。店舗密度は江南で最上位。
  • 島山公園・島山大路: 3号線 狎鴎亭駅 徒歩10分、または新沙駅 (Sinsa Station / 신사역) 徒歩15分。デザイン cafe・warehouse・ミシュラン cluster。静かで散策 fit。
  • 清潭洞: 7号線 清潭駅 (Cheongdam Station / 청담역) 徒歩5分。ラグジュアリー・special occasion・ホテル lounge。狎鴎亭から徒歩20分の距離。
  • 新沙 街路樹通り: 3号線 新沙駅 徒歩3分。インディー・トレンディ・中級。2010年代初めのホットスポットで、今も外国人観光客に人気のエリア。
  • 三成 (Samseong / 삼성)・駅三: 2号線。ビジネス街。specialty カフェが hidden。
  • 蚕室 シグニエル: 2・8号線 蚕室駅 (Jamsil Station / 잠실역) 直結。555m の展望 + ラグジュアリー lounge。江南エリアからタクシーで20分の距離で、別途訪問を推奨。

移動のヒント: 狎鴎亭–島山–清潭は徒歩圏。蚕室は別の半日として分けて計画することを推奨。

2. デザイン・ラグジュアリー (狎鴎亭・島山)

1. ヌデイク 島山 (Nudake Dosan / 누데이크 도산)

  • 位置: 江南区 島山大路54ギル (Dosan-daero 54-gil / 도산대로54길) (3号線 狎鴎亭駅 徒歩10分)
  • シグネチャーメニュー: シグネチャーケーキ (季節で変動)、クッキーボックス、アートケーキ
  • 価格: ケーキ1切れ ₩12,000~18,000 / ドリンク ₩8,000~12,000
  • 営業時間: 11:00~22:00 (月曜休み — 確認推奨)
  • 外国人 fit: ★★★。デザイン page・SNS シグネチャー店舗。英語メニューあり。行列が長ければ待ちアプリを使う。
  • 注意: 週末午後は1~2時間の待ちが発生。午前11時~12時か平日の訪問を推奨。
  • 写真 tip: 1階のショーケース・2階のテラス。自然光が最適な時間帯は午前11時~午後2時。
  • 公式: https://www.nudake.com/

2. ブルーボトル 狎鴎亭 (Blue Bottle Apgujeong / 블루보틀 압구정)

  • 位置: 江南区 島山大路13ギル (Dosan-daero 13-gil / 도산대로13길) (狎鴎亭ロデオ付近)
  • シグネチャーメニュー: New Orleans Iced Coffee、シングルオリジン ハンドドリップ
  • 価格: ₩7,500~12,000
  • 営業時間: 07:30~20:00 (平日)、08:00~20:00 (週末)
  • 外国人 fit: ★★★。アメリカの specialty ブランド。英語 fluent なスタッフが常駐。アメリカ・ヨーロッパの旅行者にとって「なじみのある出発点」。
  • 注意: 韓国のブルーボトルは、メニューの一部がアメリカ本店と異なる。現地限定メニューに注目。
  • アクセス: 狎鴎亭駅3番出口 徒歩7分。

3. カフェ ママス (Café Mamas / 카페 마마스、狎鴎亭)

  • 位置: 江南区 狎鴎亭路 (Apgujeong-ro / 압구정로) (狎鴎亭ロデオ付近)
  • シグネチャーメニュー: ブランチプレート、ケーキ、シーズンデザート
  • 価格: ブランチ ₩18,000~28,000 / デザート ₩10,000~16,000
  • 外国人 fit: ★★。英語メニューあり。ブランチとデザートを1ヶ所で済ませられる。店内インテリアが写真 fit。
  • 注意: ピーク時間 (週末12~14時) は待ちが発生。ウェイティングか予約を推奨。

4. テラロッサ 江南店 (Terarosa Gangnam / 테라로사 강남점)

  • 位置: 江南区 島山大路 (島山公園付近)
  • シグネチャーメニュー: シングルオリジン ドリップ、エスプレッソ、ベーカリー
  • 価格: ドリンク ₩7,000~13,000 / ベーカリー ₩4,000~9,000
  • 営業時間: 08:00~22:00
  • 外国人 fit: ★★★。江陵 (Gangneung / 강릉) 発の韓国 specialty 第1世代ブランド。英語メニュー完備。空間が広く会話 fit。
  • 注意: 江南店は江陵の本店より座席に余裕があるが、週末午後は混雑。

5. 島山ベーカリー cluster

  • エリア: 島山大路 + 島山大路54ギル一帯の半径500m
  • 特性: 独立系ベーカリー5~7軒が密集。個別店舗はオープン・移転が頻繁 — 訪問前に Naver Map での検索を推奨。
  • 共通価格帯: パン ₩4,000~9,000 / ドリンク ₩6,000~10,000
  • 外国人 fit: ★★★。写真 fit が高い。行列のできる店 = トレンドのシグナル。
  • ヒント: 店名よりも「島山公園 ベーカリー」で Naver Map を検索し、レビューを新しい順に確認。

3. ラグジュアリーデザート (清潭・シグニエル)

6. シグニエル ソウル ラウンジ 蚕室 (Signiel Seoul Lounge / 시그니엘 서울 라운지)

  • 位置: 蚕室 ロッテワールドタワー81F (2・8号線 蚕室駅直結)
  • シグネチャーメニュー: アフタヌーンティーセット (サンドイッチ・スコーン・ケーキ)、シグネチャーカクテル
  • 価格: アフタヌーンティー ₩75,000~100,000 (2名基準、確認推奨)
  • 営業時間: 10:00~22:00 (ラストオーダー 21:00)
  • 予約: catchtable またはホテル公式サイトでの事前予約を強く推奨 (週末は1~2週間前)
  • 外国人 fit: ★★★。英語サービスが fluent。高さ555m から漢江・江南の panorama 眺望。夜景は18:30以降。
  • ドレスコード: スマートカジュアル以上 (スリッパ・短パン不可 — 入場を断られた事例あり)
  • ヒント: 昼の時間帯 (12~14時) よりも、sunset (17~19時) か夜景 (20時~) の時間帯のほうが view の満足度が高い。
  • 公式: https://www.lottehotel.com/seoul-signiel/

7. 清潭ホテルラウンジ

  • 対象ホテル: JW マリオット 東大門スクエア (JW Marriott Dongdaemun Square / JW 메리어트 동대문 스퀘어) (東大門、江南エリアへ移動30分)、インターコンチネンタル ソウル COEX (InterContinental Seoul COEX / 인터컨티넨탈 서울 코엑스) (江南区 三成洞に直接)、インペリアル パレス ソウル (Imperial Palace Seoul / 임페리얼 팰리스 서울) (江南区 彦州路 / Eonju-ro / 언주로)
  • シグネチャーメニュー: ハイティーセット、ケーキプレート、シーズンビュッフェ (店舗ごとに異なる)
  • 価格: ハイティー ₩40,000~70,000 (1名基準、ドリンクが含まれるかは店舗ごとに異なる)
  • 外国人 fit: ★★★。英語サービスが基本。大型ホテルラウンジの特性上、外国人の比率が高い。
  • 注意: 各ホテルのメニュー・価格は季節ごとに変動。訪問前にホテル公式サイトでの確認が必須。
  • 予約: ホテルレストランの予約リンクか catchtable。

8. ミシュランコース デザート (チョンシクダン・スワニエのコース)

  • チョンシクダン (Jungsik / 정식당): 江南区 江南大路 (Gangnam-daero / 강남대로) (街路樹通り付近)。韓国ファインダイニング第1号のミシュラン。コース内のデザート + ワインペアリング。
  • スワニエ (Soigné / 스와니예): 江南大路652 新沙スクエア (Sinsa Square / 신사스퀘어) 2階 — ミシュラン2スター(2026)のコンテンポラリーコース。予約は公式サイト soigneseoul.com。
  • 価格: コース ₩150,000~300,000 (ディナー)。別途ワインペアリング ₩80,000~150,000 追加。
  • 予約: catchtable・公式サイトが必須。週末は2~4週間前に先行予約。
  • 外国人 fit: ★★★。英語メニュー・英語で説明できるスタッフをほとんどの店が擁する。(#1109 ミシュランガイド参照)

4. トレンディ・MZ (狎鴎亭・街路樹通り)

9. 狎鴎亭ロデオ カフェ・デザート cluster

  • エリア: 3号線 狎鴎亭駅 → 狎鴎亭ロデオ通り 徒歩5~10分
  • 特性: トレンディな独立系カフェ・デザート店が10~15軒密集。店舗の入れ替わりが早い。
  • 共通価格: ₩6,000~12,000
  • 外国人 fit: ★★★。若い層の SNS シグネチャーエリア。英語メニューがなくても picture menu・指さし注文が可能。
  • 時間帯: 午後1~5時が最適。人出が多いほどトレンディなシグナル。
  • ヒント: Naver Map で「狎鴎亭ロデオ カフェ」を検索 → 最新レビューの確認で、今ホットな店舗を把握。

10. 街路樹通り カフェ cluster (新沙)

  • エリア: 3号線 新沙駅 → 街路樹通り 徒歩3分
  • 特性: インディー・トレンディ・中級。メインの街路樹通り + セロス通り (Sero-su-gil / 세로수길) (路地) に分かれる。セロス通りのほうがローカル feel。
  • 共通価格: ₩6,000~15,000
  • 外国人 fit: ★★。ソウル観光の「クラシックコース」。店舗の多様性は高いが、最近のトレンドの中心は狎鴎亭に移った。
  • おすすめの方法: メインの街路樹通りはショッピング + ブランチを兼ねる。セロス通りは独立系カフェの探訪。

11. ノッティド ドーナツ (江南)

  • 位置: 江南区内の複数店舗 (島山・街路樹通り付近 — Naver Map で「ノッティド」を検索して最新店舗を確認)
  • シグネチャーメニュー: クリームドーナツ (イチゴ・バニラ・チョコ)、シーズン限定ドーナツ
  • 価格: ドーナツ1個 ₩4,500~6,500 / ドリンク ₩6,000~9,000
  • 外国人 fit: ★★★。行列のできる店 = 韓国デザートトレンドの体験。英語メニューあり。sweet tooth な外国人の第1候補。
  • 注意: 人気メニューは sold out が早い。オープン直後か平日の訪問を推奨。

5. コンテンポラリー・specialty (良才・駅三)

12. フリッツ 良才店 (Fritz Yangjae / 프릳츠 양재점)

  • 位置: 瑞草区 (Seocho-gu / 서초구) 良才洞 (Yangjae-dong / 양재동) / 新盆唐線 (Sinbundang Line / 신분당선) 良才市民の森駅 (Yangjae Citizen's Forest Station / 양재시민의숲역) 徒歩5分
  • シグネチャーメニュー: シングルオリジン ドリップ、エスプレッソ、クロワッサン・ベーカリー
  • 価格: ドリンク ₩7,000~13,000 / ベーカリー ₩3,500~8,000
  • 営業時間: 08:00~22:00 (店舗ごとに異なる — 確認推奨)
  • 外国人 fit: ★★★。韓国 specialty 第1世代ブランド。コーヒーマニア・ブロガーの外国人の必訪スポット。英語メニュー。
  • 注意: 江南の中心から地下鉄で15分の距離。specialty マニアにだけ、別途の訪問を推奨。

5-1. 百貨店デザート専門館 — 高速ターミナル (2026 補強)

13. 新世界江南 スイートパーク (Sweet Park、地下1階)

  • 位置・交通: 瑞草区 新盤浦路 (Sinbanpo-ro / 신반포로) 176、新世界百貨店 江南店 地下1階。3・7・9号線 高速ターミナル駅が食品フロアとそのままつながっている (百貨店公式案内)。盤浦漢江公園 (Banpo Hangang Park / 반포한강공원)・ゴトゥモール (Go to Mall / 고투몰)・地下商店街 とまとめやすい。
  • どんな場所か: 2024年2月15日にオープンした百貨店のデザート専門館。約1,600坪に、パン・ケーキ・チョコレート・伝統菓子のブランド30ヶ所あまりが集まり、初年度の来場者が1,200万人を超えた。出典: イートゥデイ (Etoday / 이투데이) 2025-02。日本語圏の旅行メディア、コネスト (Konest / 코네스트) が2026年9月に「今いちばん熱いデパ地下」として紹介した。
  • 営業時間: 百貨店基準で10:30~20:00 (延長営業日は20:30)。休業日は百貨店のお知らせを確認。
  • 2026年に入った店 (報道で確認):
  • ポンポンプリン ベーカリーカフェ (Pompompurin Bakery Cafe / 폼폼푸린 베이커리 카페) — サンリオのキャラクター、ポムポムプリンの30周年を迎えて開いた国内初の店舗 (2026年7月)。キャラクターの顔の形をした栗パン・カスタードパン、グッズ約100種 (日本直輸入・韓国限定)。出典: アジア経済 (Asia Economy / 아시아경제) 2026-07-29。
  • ヴァンルーウェン (Van Leeuwen / 밴루엔) — ニューヨークのプレミアムアイスクリームの百貨店初出店 (2026-07-23)。シングル 5,500ウォン~、江南店限定のベビーサイズ ミルクシェイク (バニラ・イチゴ・チョコ)。出典: サタデー経済 (Saturday Economy / 새터데이경제) 2026-07-23。
  • チャジ (CHAGEE / 차지) — 中国のミルクティーブランド。アジア経済 2026-07-29 の記事で、スイートパークの出店ブランドとして言及。
  • それ以前からある人気店:
  • プチャンジェグァ (Buchang Jegwa / 부창제과) — 俳優イ・ジャンウ (Lee Jang-woo / 이장우) と FG が復活させた60年の伝統のクルミ菓子。2024年10月の江南店オープン時は、待ち時間が4時間を超えた。店内で焼いて販売する。出典: インサイト (Insight / 인사이트) 2025-05。
  • コネスト 9/17の投稿が一緒に挙げた店: ベトン (Beton / 베통) (塩パン)、スコフ SCOFF (Scoff / 스코프) (西村のスコーン)、スタンダードブレッド (Standard Bread / 스탠다드 브레드) (食パン・フレンチトースト、テイクアウト)、ゴディバ クレープ (Godiva Crepe / 고디바 크레페)、食品館の朝鮮ホテル キムチ (Chosun Hotel Kimchi / 조선호텔 김치)。この5つは報道での確認前のため、メディアの投稿を基準に記載する。
  • 価格: アイスクリーム シングル 5,500ウォン~。パン・焼き菓子は店舗ごとに現場で確認。
  • 外国人 fit: ★★★。地下鉄直結・屋内・テイクアウト中心なので、雨の日やショッピングの合間に立ち寄りやすい。ポンポンプリン・ゴディバはお土産用。
  • 注意: 週末午後は行列が長い。テイクアウト専門店には座る場所がない。漢江へつなげるなら、高速ターミナル駅から盤浦漢江公園方面へ (#1308・#586)。

7. 外国人のミス TOP 3

ミス 1: 週末午後に予約なしで訪問

状況: ヌデイク・シグニエル・ホテルラウンジに予約なしで土曜午後に訪問 → 1~2時間の待ちか入場不可。

解決: シグニエル・ホテルラウンジ・ミシュラン店舗は、catchtable か公式サイトで1~2週間前に予約。ヌデイクは午前11時~12時か平日に訪問。

ミス 2: シグニエルのドレスコードを無視

状況: スリッパ・短パンでシグニエル81Fへの入場を試みる → 入口で断られる。

解決: スマートカジュアル以上が必須。ジーンズ + きれいめのトップスは可。スリッパ・トレーニングウェアは不可。

ミス 3: 江南 ≠ 1つのエリアと勘違い

状況: 「江南カフェ hop を1日で全部回る」 → 狎鴎亭から蚕室シグニエルまでタクシー20分 + 料金 ₩15,000~25,000 追加。

解決: 蚕室シグニエルは別の半日として分ける。徒歩圏 (狎鴎亭・島山・清潭) だけを1日にまとめることを推奨。

9. FAQ

Q1. 江南のカフェを1日で全部回れる?

不可能。エリアが広く、店舗間の移動時間がある。1日1エリアが原則: 島山・狎鴎亭・清潭のまとめ、または蚕室単独。2日以上に分散を推奨。

Q2. どのエリアがインスタグラムの写真に最も向いている?

ヌデイク 島山 (ケーキ + インテリア)、狎鴎亭ロデオ cluster (通り + 店舗の外観)、シグニエル81F (夜景)。3つとも照明・構図が異なるので、目的に応じて選ぶ。

Q3. 1人で行っても大丈夫な店舗は?

ブルーボトル・テラロッサ・フリッツは1人客が多い。ホテルのハイティー・シグニエルのアフタヌーンティーは2名基準のセットが多く、1人で訪問する場合は価格の確認が必要。

Q4. ベジタリアン・ハラールのオプションはある?

ブルーボトル (乳製品を使わないミルク代替が可能)、テラロッサ (ベーカリーにベジタリアン対応が一部あり)、ヌデイク (事前の問い合わせを推奨)。ハラール認証のカフェは江南内では珍しい — 訪問前に店舗へ直接確認することを推奨。

Q5. 冬におすすめのオプションは?

シグニエル ラウンジの夜景 (室内の warmth + view)、清潭ホテルラウンジ (温かいお茶)、ヌデイクのシーズンケーキ。屋内中心の動線である Pattern A が冬に最適。
