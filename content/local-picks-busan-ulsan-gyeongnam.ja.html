🎯 なぜ「コメント推薦」が基準なのか

KeyChinGuの地方グルメ編はこれまで二つのシグナルで作ってきた——外国人レビューが先に残った場所(#1381)、そして都市の代表メニュー(#1320)。この連載は三つ目のシグナルだ。ある韓国のYouTubeチャンネルが上げた「全国グルメ」動画に、視聴者がコメントで自分の地元の食堂を書き込み、その中でも地域別に最も体系的に整理されたコメントを表に落とし込んだまとめが217軒ある。韓国人が韓国人に薦めたリストなので外国人レビューはほとんどなく、Instagramには出てこない老舗・町場の食堂が多い。

KeyChinGuがやったことはひとつだけ——Naverローカル検索で店名・住所・業種が実際に存在するかを確認した(2026-09-17)。217軒のうち192軒が確認でき、釜山・蔚山・慶南は16軒のうち15軒だった。確認できなかった1軒は除いた。訪問レビュー・ランキング・星評価はない。営業時間と価格もこの回にはない——それは訪れる当日のNaver Placeが答えだ。

⚠ 表記の原則：店の行は店名 (ローマ字) · 道路名住所 · Naver業種 · アクセスの順。アクセスは公式または2つ以上の情報源で確認できた駅・バスだけを記載し、確認できない区間は「Naverマップで確認」とした。営業時間・定休日・価格はすべて未収集——Naver Placeで当日確認を。タクシー運転手にはハングルの住所をそのまま見せればいい。

① 釜山 — 7軒、地下鉄と東海線で行ける店

釜山の代表メニュー三つ——テジクッパ (dwaeji gukbap / 돼지국밥)・ミルミョン・刺身——は、注文の仕方まで#1320で扱った。この七軒はそのリストの外で韓国の視聴者が書き込んだ地元の食堂だ——クッパが二軒、そして観光リストにはあまり載らないタットリタン・ドルソッビビンバ・マンドゥ・チュクの四軒。

  • ヨンサンタットリタン (Yeonsan Dakdoritang / 연산닭도리탕) · 釜山 蓮堤区 果亭路 236 (236 Gwajeong-ro, Yeonje-gu / 부산 연제구 과정로 236) · 韓食 · ダッポックムタン (dakbokkeumtang / 닭볶음탕) · ヨンサン駅、1・3号線、徒歩圏

ダッポックムタン(タットリタン / 닭도리탕)は鶏一羽をじゃがいも・玉ねぎと一緒に辛いスープで煮込んだ鍋料理だ。一羽単位なので2~3人前が基本になる。

  • ウジョンドルソッビビンバ (Ujeong Dolsot Bibimbap / 우정돌솥비빔밥) · 釜山鎮区 東川路85番ギル 3 (3 Dongcheon-ro 85beon-gil, Busanjin-gu / 부산진구 동천로85번길 3) · 韓食 · ビビンバ (bibimbap / 비빔밥) · ソミョン駅、1・2号線、トンチョンノ方面へ徒歩圏

ドルソッビビンバ (dolsot bibimbap / 돌솥비빔밥) は熱々の石鍋にご飯を盛ったビビンバ——底のおこげが決め手だ。ソミョンのど真ん中にあるので、15軒の中で#1114の動線にいちばん組み込みやすい。

  • ウィリョンシクタン (Uiryeong Sikdang / 의령식당) · 海雲台区 牛洞1路50番ギル 15 (15 Udong 1-ro 50beon-gil, Haeundae-gu / 해운대구 우동1로50번길 15) · 韓食 · クッパ · ヘウンデ駅、2号線、4番出口徒歩3~4分

ヘウンデ駅の裏、旧鉄道沿いの路地、ヘリダンギル (Haeridan-gil / 해리단길) にあるクッパの店。ヘウンデビーチに行く前後の一食にちょうどいい。

  • ハプチョンクッパ (Hapcheon Gukbap / 합천국밥) · 南区 龍湖路 235 (235 Yongho-ro, Nam-gu / 남구 용호로 235) · 韓食 · クッパ · チゲゴル駅、2号線からバス24番・27番、キョンソンデ・プギョンデ駅 (Gyeongseongdae-Bukyeongdae / 경성대·부경대역) での乗り換えも可

ヨンホドンは地下鉄が直接届かない住宅街だ。イギデやオリュクドに行く日に組み合わせるのが自然だ。

  • ポクソンマンドゥ (Bokseong Mandu / 복성만두) · 影島区 大平路34番ギル 5-8 (5-8 Daepyeong-ro 34beon-gil, Yeongdo-gu / 영도구 대평로34번길 5-8) · 軽食 · マンドゥ · ヨンドには地下鉄がない——ナンポ駅、1号線からヨンド行きバス

ヨンドのコーヒー(#1321)やフィンヨウル村 (Huinnyeoul Village / 흰여울마을) に向かう途中にあるマンドゥの店。マンドゥは持ち帰りができるメニューなので、移動中のおやつにもなる。

  • ソンウォンシクタン (Songwon Sikdang / 송원식당) · 西区 城山ギル 23 (23 Seongsan-gil, Seo-gu / 서구 성산길 23) · 韓食 · トソン駅、1号線、6番出口→釜山大病院バス停で村バスに乗り換え(サハ1-1・ソグ2・ソグ2-2)

甘川文化村 (Gamcheon Culture Village / 감천문화마을) のすぐ隣、住宅街にある韓食店。村の見学と同じバスで行ける。

  • クッチプ (Kkeutjip / 끝집) キジャンクッチプ イルグァン店 · 機張郡 日光邑 日光路 293 (293 Ilgwang-ro, Ilgwang-eup, Gijang-gun / 기장군 일광읍 일광로 293) · 韓食 · チュク · 東海線広域電鉄 イルグァン駅、徒歩圏

チュク(お粥)専門店。イルグァン海水浴場 (Ilgwang Beach / 일광해수욕장) が駅から歩ける距離にあるので、ビーチと同じ半日に組み込める。

外国人向けヒント — 釜山のクッパ店では席に着くと、セウジョッ (saeujeot / 새우젓)・刻み薬味・ニラ(チョングジ / jeongguji / 정구지)が別皿で出てくる。スープに入れて自分で味を調えるのが地元流で、「辛くしないで」は刻み薬味を抜けばいい。注文フレーズ・ミルミョン・刺身は#1320。

② 蔚山 — 1軒、太和江のそば

  • テバッコルテジクッパ (Daebatgol Dwaeji Gukbap / 대밭골돼지국밥) · 蔚山 中区 太和江国家庭園ギル 229-2 (229-2 Taehwagang-gukgajeongwon-gil, Jung-gu / 울산 중구 태화강국가정원길 229-2) · 韓食 · クッパ · テファガン駅、東海線からタクシーで約15分(バスは約40分・本数が少ない)——KTXウルサン駅からは5001番リムジンバスで約49分、かなり遠い

太和江国家庭園 (Taehwagang National Garden / 태화강국가정원、シムニ竹林 / 십리대숲) のすぐ隣。釜山から来る人はKTXよりも東海線電鉄でテファガン駅のほうが庭園に近く、ソウルからKTXで来る人はウルサン駅 (Ulsan / 울산역) が都心の西側の外れにあることを先に知っておくべきだ。

外国人向けヒント — テジクッパは釜山・蔚山共通の朝食メニューだ。早くから開く店が多く、その分、材料がなくなれば午後早くに閉まることもある。時間はNaver Placeで確認を。

③ 慶南 — 7軒、昌原・晋州・梁山・昌寧・居昌

慶南の五つの都市は、KTX・SRTが届く場所(昌原マサン・昌原ジュンアン・晋州)と、バスでしか行けない場所(昌寧イバン・居昌)に分かれる。釜山2号線の終点が梁山だということも、このリストでは役に立つ。

  • ピョンヤンネンミョン (Pyeongyang Naengmyeon / 평양냉면) · 昌原市 馬山会原区 陽徳イェッ2ギル 73 (73 Yangdeokyet 2-gil, Masanhoewon-gu / 창원시 마산회원구 양덕옛2길 73) · 韓食 · ネンミョン · マサン駅一帯(KTX全列車停車)——駅からのバス・タクシーはNaverマップで確認

店名がそのままメニュー名だ。平壌式冷麺はあっさりしたスープが特徴で、テーブルの酢・辛子で各自味を調える。

  • ジョナンジャン (Jeonangjang / 전앙장) · 昌原市 馬山合浦区 3・15大路 116 (116 3·15-daero, Masanhappo-gu / 창원시 마산합포구 3·15대로 116) · 中華 · 中華料理店 · マサン旧市街——マサン駅からバス乗り換え(路線はNaverマップで確認)

マサン旧市街の中華料理店。韓国式中華料理の定番はジャジャンミョン (jjajangmyeon / 짜장면)・チャンポン (jjamppong / 짬뽕)・タンスユク (tangsuyuk / 탕수육) で、いずれも1人前から注文できる。

  • プタオク (Butaok / 부타옥) · 昌原市 城山区 龍池路 225 (225 Yongji-ro, Seongsan-gu / 창원시 성산구 용지로 225) · 韓食 · チャンウォンジュンアン駅、KTXからバス

昌原新市街(サンナムドン / 상남동・龍池路)側の韓食店。チャンウォンジュンアン駅はKTX・ITX-セマウル・ムグンファが停まる駅だ。

  • チェイルシクタン (Jeil Sikdang / 제일식당) · 晋州市 中央市場ギル 37-8 (37-8 Jungangsijang-gil, Jinju-si / 진주시 중앙시장길 37-8) · 韓食 · チンジュ駅、KTX・SRTから市内バスまたはタクシー(路線はNaverマップで確認)

晋州中央市場 (Jinju Central Market / 진주중앙시장) の中にある食堂。晋州はビビンバと冷麺の街として知られていて、市場の中の食堂もその文法をそのまま踏襲している。

  • ヘヤンサンクッパ (Haeyangsan Gukbap / 해양산국밥) · 梁山市 三成6ギル 10 (10 Samseong 6-gil, Yangsan-si / 양산시 삼성6길 10) · 韓食 · クッパ · ヤンサン駅一帯、釜山2号線の終点——駅からの徒歩・バスはNaverマップで確認

釜山の地下鉄で行ける慶南のクッパ店。2号線を終点まで乗ればヤンサンだ。

  • イバンシクタン (Ibang Sikdang / 이방식당) スグレクッパ · 昌寧郡 梨房面 玉野ギル 1 (1 Ogya-gil, Ibang-myeon / 창녕군 이방면 옥야길 1) · 韓食 · クッパ · 昌寧市外バスターミナル(昌寧邑 / 창녕읍)から郡内バスまたはタクシー——イバン面直通かどうかは確認

スグレ (sugure / 수구레) とは牛の皮の内側の肉を指す。スグレクッパは昌寧イバン市場 (Ibang Market / 이방장) の郷土メニューで、このリストの中でいちばん「地元」寄りの名前だ。ウポ湿地 (Upo Wetland / 우포늪) と同じ方向にある。

  • チュンチョンセムトチャムスットダッカルビ (Chuncheon Saemto Chamsut Dakgalbi / 춘천샘토참숯닭갈비) · 居昌郡 居昌邑 公需坪4ギル 17 (17 Gongsudeul 4-gil, Geochang-eup / 거창군 거창읍 공수들4길 17) · 韓食 · タッカルビ · 居昌市外バスターミナル(大邱西部バスターミナル / 대구서부정류장 発の路線が中心)、徒歩圏

居昌は大邱の生活圏にあるので、釜山よりも大邱からのバスの本数が多い。タッカルビは鶏肉・キャベツ・餅を鉄板で炒める料理で、2人前からの注文が基本だ。

外国人向けヒント — 邑・面レベルの食堂や市場の中の店もカード払いができるところが増えたが、現金・口座振込のほうが今も落ち着く文化だ。現金が必要な場面は#1301全般を参照。クッパ・ネンミョンは1人前から注文できるが、タットリタン・タッカルビは2人前以上が基本になる。

🚄 地方の動線に組み込む方法

  • 釜山2泊3日(#1114)に組み込む — ソミョン(ウジョンドルソッビビンバ)・ヘリダンギル(ウィリョンシクタン)・キジャンのイルグァン(クッチプ)は、既存の動線の駅からそのまま行ける。ヨンド(ポクソンマンドゥ)・カムチョン(ソンウォンシクタン)はそれぞれナンポ駅・トソン駅で降りてからバスが必要なので、半日単位で組む。
  • 釜山 → 蔚山 — 東海線電鉄でテファガン駅へ。太和江国家庭園とテバッコルテジクッパを一度にまわれる。
  • ソウル → 晋州・昌原 — KTX・SRTでチンジュ駅、KTXでマサン駅・チャンウォンジュンアン駅へ。晋州中央市場(チェイルシクタン)はチンジュ駅からさらに市内へ入る必要がある。
  • ゴールデンルート(#1372~1374)の変形 — 慶州から釜山へ下りてきて一日を慶南に使う人は、マサンか晋州のどちらか一つに絞るのが現実的だ。
  • バスでしか行けない場所 — 昌寧イバン・居昌。大邱西部バスターミナル発の路線が中心なので、大邱・慶北編(#1383)と組み合わせたほうがいい。

⚠ よくある間違い3つ

1. KTXウルサン駅から太和江庭園へ直接行こうとする — ウルサン駅は都心の西側の外れにあり、リムジンバスで約49分かかる。釜山側から来るなら東海線のテファガン駅が正解だ。

2. クッパ店を夕方に訪ねる — クッパ店は朝・昼中心で、材料がなくなると早く閉める店もある。時間はNaver Placeで当日確認を。

3. 一人でタットリタン・タッカルビを注文する — 鶏一羽・2人前単位だ。一人なら、クッパ・ネンミョン・マンドゥ・チュクのほうが合っている。

⚙ FAQ3つ

1. このリストは誰が選んだのか？ — 韓国のYouTube視聴者がコメント欄に書き込んだ地方グルメをまとめた表だ。KeyChinGuは存在・住所・業種だけを確認し、順位はつけていない。

2. 韓国語ができなくても注文できるか？ — クッパ・ネンミョン・マンドゥはメニュー表を指させばいい。「イゴ ハナ ジュセヨ」(이거 하나 주세요、「これ一つください」)で十分で、細かい注文表現は#1320を参照。

3. 予約はできるか？ — この手の食堂は大半が予約なしで並ぶ仕組みだ。団体なら電話が必要で、その番号はNaver Placeに載っている。
