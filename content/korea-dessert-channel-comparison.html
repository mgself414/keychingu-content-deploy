🎯 왜 디저트 4채널 비교 가이드인가

#819 디저트 6종 매트릭스 + #820 워크플로우 알아도 — 채널 선택이 다음 결정. 한국 디저트 채널 = (1) 길거리 매대 (호떡·붕어빵·달고나)·(2) MZ 카페 (약과 라떼·달고나 라떼·빙수)·(3) 호텔 빙수·라운지 (럭셔리 40~80k)·(4) 한옥 카페 (인사동·익선동·북촌 전통) 4가지. 가격 1,000원 → 80,000원, 분위기 길거리 → 트렌디 → 럭셔리 → 전통. 본 가이드는 4채널 직접 비교 + segment(혼자·커플·가족·MZ·예산형)별 1순위. 회·BBQ·국밥·분식·면류·치킨 cluster 패턴 적용 디저트 버전.

🥞 4채널 deep dive

🥞 길거리 매대 (Street Stall)

핵심 가치: 가성비 ★★★★★ + 길거리 분위기 + 인스타 vibe. 한국 디저트 전통 매니아 1번지.

  • 추천 영역 (서울):
  • 명동·홍대·종로 길거리 — 외국인 관광지 1번지
  • 인사동 전통 디저트 길거리
  • 광장시장·동대문 시장 디저트
  • 부산 BIFF 광장 (씨앗 호떡 1번지)
  • 메뉴: 호떡·붕어빵·국화빵·달고나·꿀타래·뻥튀기
  • 가격: 1,000~4,000원/개 (2~3종 = 5,000~10,000원)
  • 외국인 친화도: ★★★ (영문 메뉴 거의 없음·사진 메뉴 활용)
  • 결제: 현금 권장 (큰 매대 일부 카드)

☕ MZ 카페 (Trendy Cafe)

핵심 가치: 트렌디 + 인스타 + 키오스크 + 영문 메뉴. MZ 디저트 매니아 1번지.

  • 추천 영역 (서울):
  • 홍대·연남 — MZ 디저트 카페 cluster
  • 성수동 — 블루보틀 + 약과 카페 cluster (#576 sub)
  • 강남·역삼 — 직장인 MZ
  • 이태원 — 외국인 친화 카페
  • 시그니처: 약과 라떼·달고나 라떼·약과 크루아상·녹차 빙수
  • 가격: 12,000~20,000원 (1인)
  • 시스템: 키오스크 주문 + 카드 + 테이블 식사
  • 외국인 친화도: ★★★★ (영문 메뉴 多)
  • 결제: 카드 + 키오스크
  • 운영: 10:00~22:00

🏨 호텔 빙수·라운지 (Hotel Premium)

핵심 가치: 럭셔리 + 시그니처 빙수 + 접대·기념일. 한국 호텔 빙수 = 글로벌 트렌드.

  • 추천 호텔 (서울):
  • 신라호텔 (The Shilla) — 라연·더 라이브러리 빙수 (40,000~80,000원)
  • 롯데호텔 — 시그니처 빙수
  • 웨스틴 조선 서울 — 럭셔리 디저트
  • 포시즌스·반얀트리 — 글로벌 럭셔리
  • 메뉴: 호텔 시그니처 빙수 (망고·딸기·녹차·팥) + 럭셔리 디저트
  • 가격 anchor: 25,000~80,000원 (2~3인 공유 표준)
  • 외국인 친화도: ★★★★★ (영어·예약·1순위)
  • 예약: 시즌 (5~9월) = 1~2주 전 필수 (네이버 예약·전화·컨시어지)
  • 결제: 룸 차지 + 카드 + 봉사료 10% + 부가세 10%
  • 운영: 10:00~22:00 (호텔 영업)

🏯 한옥 카페 (Hanok Traditional Cafe)

핵심 가치: 전통 한옥 분위기 + 인스타 1번지 + 정통 + 모던 페어링.

  • 추천 영역 (서울):
  • 인사동 — 전통 한과·약과 한옥 카페 cluster
  • 익선동 — MZ 한옥 카페 cluster (#570 sub)
  • 북촌 한옥마을 — 정통 한옥
  • 삼청동 — 한옥 + 모던 융합
  • 추천 매장 (지방):
  • 전주 한옥마을 — 전통 한과·약과
  • 경주 한옥 카페 — 전통
  • 메뉴: 전통 약과·한과·녹차·국화차 + 모던 약과 라떼·빙수
  • 가격: 15,000~25,000원
  • 외국인 친화도: ★★★★ (한옥 vlog 1번지)
  • 결제: 카드 OK
  • 운영: 10:00~21:00

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 분위기·가격·시스템 완전 다름. 가성비 = 길거리 / 트렌디 = MZ / 럭셔리 = 호텔 / 정통 = 한옥.

2. "길거리 = 위생 X": 광장시장·인사동·명동 = 관광지 매대 정기 점검. 매대별 편차 가능.

3. "호텔 빙수 = 무조건 비쌈": 신라호텔 빙수 80,000원 = 2~3인 공유 = 1인 30,000원 수준. 가성비 OK.

4. "한옥 카페 = 전통 음식만": 인사동·익선동 한옥 카페 = 전통 + MZ 모던 페어링 (한옥 + 약과 라떼).

5. "MZ 카페 = 매장 따라 다름": 홍대·성수·강남 = 영문 메뉴·키오스크 표준. 동네 MZ 카페 = 한국어 多.

⚙ FAQ 8개

1. 첫 디저트 = 어떤 채널: MZ 카페 1순위 (영어·키오스크·인스타). 가성비 = 길거리.

2. 인스타·vlog 1순위: MZ 카페 (홍대·성수) + 한옥 카페 (인사동·익선동) + 호텔 빙수.

3. 데이트·기념일: 한옥 카페 (전통) + 호텔 빙수 (럭셔리).

4. 회식·접대: 호텔 빙수·라운지 (5성급) + 한옥 카페 (전통).

5. 호텔 빙수 예약: 신라·롯데·웨스틴 = 시즌 (5~9월) 1~2주 전 필수.

6. 알레르기·임신: #819·#820 disclaimer 참조.

7. 결제·팁: 길거리 = 현금 / MZ·한옥 = 카드 / 호텔 = 봉사료 10% / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.
