🎯 なぜボブワークフローガイドなのか

[#897ご飯6種マトリックス](#897) 知っていても — ご注文・マナーは別個。韓国ご飯は（a）食堂・チェーン（魚墨鉄板・苛性雨）（b）MZ韓国料理店（明太子・チーズチャーハン）（c）韓国料理（釜飯・栄養飯）外国人は、（1）エアバップ＝別途費用不明（2）明太子ボブ＝MZインスタモール（3）釜飯＝限定式本物の知らない。本ガイドは5-step+英語発話。

★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣チャンネル選択 分食/MZ/限定式/家庭式 即時 コ・ソンビ・MZ・本格・ホームスタイル
2️⃣メニュー注文 6種+サイド 1～5分エアギャップ=別途費用
3️⃣受信・設定 米+局・おかず・メイン 5〜15分 釜飯の熱さ

総所要時間: 分式 = 15～30分 / MZ = 30～60分 / 限定式 = 1.5～2.5h / 仮定式 = 30～60分

🍚チャンネル別ワークフロー

Type A — 分食店・チェーン (魚墨鉄板)

  • シグネチャー: コスパ #1・#1 分食
  • 時間: 11:00～22:00
  • 価格：7,000〜12,000ウォン
  • メニュー: 魚墨鉄板・ラーメン・餃子cluster cross
  • 外国人親和性: ★★★★

Type B — MZ韓国料理店(明太子・チーズチャーハン)

  • シグネチャー：MZインスタ#1・トレンド
  • 時間: 11:00～22:00
  • 価格：10,000〜20,000ウォン
  • おすすめ：弘大・江南・梨泰院・ソンス
  • 外国人親和性: ★★★★★

Type C — 限定式 (釜飯・栄養飯)

  • シグネチャー: 限定式本格・5色cluster
  • 時間: 11:30～22:00
  • 価格: 限定式コース 40～150k
  • おすすめ：新羅ホテルラヨン、サムチョンガク、仁寺洞
  • 外国人親和性: ★★★★

Type D — 家庭用白斑

  • シグネチャー: ホームスタイル・エアギャップ無料
  • 時間: 11:00～22:00
  • 価格：8,000〜15,000ウォン
  • 外国人親和性: ★★★★

🌶外国人英語発話サンプル

  • "エアギャップ1個" = "One bowl of rice (Gonggi-bap)"
  • "ミョンランバプ1人" = "1 Myeongran-bap (MZ trend)"
  • "釜飯" = "Sot-bap (Pot rice - traditional)"
  • "チーズチャーハン" = "Cheese fried rice (MZ global #1)"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁な誤り5つ

1. 「エアギャップ＝無料」：エアバップ＝1,000～3,000ウォン別途（限定式・家庭式無料含む）。

2. 「明るさ=単価」：明るさ= MZ #1・10～18k。

3. "釜飯=一般": 釜飯=限定食本物・熱さ。

4. "チーズチャーハン=外国": チーズチャーハン=韓国MZ fusion。

5. "分食=子供": 分食=MZトレンドOK。

⚙ よくある質問8件

1. 最初の米=どのチャネル: 分食(苛性比) → MZ (#1)。

2. インスタ: 明太子・チーズチャーハン。

3. MZ: 明太子(#1)・チーズチャーハン。

4. 苛性比: 魚墨鉄板(#1)。

5. 限定食: 釜飯・栄養ご飯。

6. アレルギー・妊娠: [#897](#897)参照。

7. お支払い: カード OK。

8. VAT: 払い戻しX。

⚠医療・安全・食事ダイエット

ボブ＝一般食品。アレルギー（魚卵・シーフード・乳製品・ナッツ・醤油）事前告知。 ☎1339。

食事制限fallback:ハラール・コーシャ=一部OK/ベジタリアン=空気・釜・栄養OK/グルテン free=Tamari.
