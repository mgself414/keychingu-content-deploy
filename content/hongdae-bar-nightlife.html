외국인 홍대 술집·nightlife

> 인디·라이브·클럽·로컬 4유형 20곳 — 상수·홍대·합정·연남 매트릭스

홍대는 한국 인디·언더그라운드 음악의 메카. 이태원이 다국적 nightlife hub라면, 홍대는 인디·라이브·MZ·로컬 한국인 + 외국인 mix가 특징. 상수 라이브 펍·홍대 클럽·합정 와인 바·연남 인디 펍까지 4 sub-cluster 20곳 + 시간대 hop 매트릭스.

1. 홍대 nightlife 풍경 vs 이태원

항목 홍대 이태원
분위기 인디·MZ·한국인 + 외국인 다국적·외국 hub
음악 인디·라이브·hip-hop 글로벌 EDM·테크노
가격 합리적 (₩50,000~150,000/1박) 중상 (₩100,000~300,000)

7. 외국인 fit Tips

영문 가능성

  • 상위: FF·NB Hongdae·Strange Fruit·익스첼 (영문 fluent·외국인 단골)
  • 중상: 합정 와인·연남 칵테일 (영문 메뉴)
  • 로컬: 골목 펍·치맥·포장마차 (picture·번역 앱)

예산 (1인 1박)

  • Pattern A 라이브: ₩50,000~150,000
  • Pattern B 클럽: ₩80,000~200,000
  • Pattern C 와인: ₩60,000~150,000
  • Pattern D 한국 unique: ₩30,000~80,000 (★ 가성비)

페르소나별

  • 인디 음악 lover: Pattern A (라이브)
  • MZ·클러버: Pattern B (NB·EDM)
  • 유럽 sophisticate: Pattern C (와인)
  • foodie + 펍: Pattern D (한국 unique)
  • 첫 방문 외국인: Pattern D (가성비 + 한국 unique)
