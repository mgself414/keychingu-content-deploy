韩国韩屋文化 —— 庭院、大厅、温突，引自然入室的韩式住宅

韩屋 (Hanok / 한옥)、庭院 (Madang / 마당)、大厅地板 (Daecheong-maru / 대청마루)、舍廊房 (Sarangchae / 사랑채)、屋檐 (Cheoma / 처마)、背山临水 (Baesan-imsu / 배산임수) —— 为外国人讲解韩国传统住宅。不是"漂亮的瓦房"，而是"为什么这样建、它承载了什么、如何把自然引进来"。

走在北村 (Bukchon / 북촌) 或全州韩屋村 (Jeonju Hanok Village / 전주 한옥마을) 的巷子里，外国人几乎都会有相同的反应 —— 那微微向天空翘起的曲线瓦屋顶 (giwa-jibung / 기와지붕)、糊着窗户纸的格子门，以及一走进屋里就铺着地板的清凉地面和正中央那片空荡荡的庭院 (Madang / 마당)。大多数人只把它当成一座"漂亮的传统韩屋 (Hanok / 한옥)"拍张照就走了。然而韩屋绝不只是一座"古老而有韵味的房子"。从一间房、一格地板、一道屋檐，到庭院的位置 —— 几乎每一个要素都是依照韩国的自然、气候与生活哲学设计出来的产物。

核心在于此。韩屋 (Hanok / 한옥) 是为了在一座房子里同时抵御朝鲜半岛严酷的夏天与冬天而建造的建筑。因此，冬天从脚开始取暖的温突 (Ondol / 온돌)（→ #1141）与夏天让风穿堂而过的木地板大厅 (Daecheong / 대청)共存于一座房中。而且它不违逆自然，建在背靠山、面朝水的位置 (Baesan-imsu / 배산임수)，并以木、土、石、韩纸 (Hanji / 한지)这样的天然材料建成，因此被称为"会呼吸的房子"。这篇文章不是讲"哪座韩屋村最漂亮"（→ 地点指南），而是从外国人的视角讲解韩屋的空间构成、自然哲学，以及为什么这样建。韩国文化讲解系列第65篇。

与温突（#1141）的区别：温突 (Ondol / 온돌) 只讲一件事 —— "把地板加热的取暖技术"。而韩屋讲的是容纳这个温突的整座房子、空间与建筑 —— 庭院、大厅、舍廊房、屋檐乃至风水。二者是部分与整体的关系。

核心：韩屋的身份不是"瓦屋顶"，而是"庭院 (Madang / 마당，留空的中心) + 地板 (Maru / 마루，夏季) + 温突 (Ondol / 온돌，冬季) + 屋檐 (Cheoma / 처마，调光)"的组合。正是这四者，让一座房子撑过半岛的四季（见下文 ②③④）。

⚠️ 外国人常误解的3件事

1. "韩屋 (Hanok / 한옥) = 只是漂亮的瓦房" ❌ —— 瓦屋顶只是韩屋的外表。它的本质是空间布局（内宅·舍廊房·庭院）与亲近自然的设计（屋檐·窗户·背山临水）。即便是同样的瓦房，也是房、地板、庭院之间的关系，让韩屋成为韩屋。

2. "庭院 (Madang / 마당) 只是花园" ❌ —— 韩屋的庭院不是用花草坪铺满的西式花园，而是特意留空的土地。它反射光线照亮房间，引入风，并且是家中活动——婚礼、祭祀、农事——上演的舞台。"留空"本身就是功能。

3. "韩屋是取暖差、寒冷的旧房子" ❌ —— 韩屋是具备冬季温突（暖房）+ 夏季大厅地板（凉爽地板）这种季节双系统的房子。在一座房中冬季空间与夏季空间是分开的，反而精密地契合了半岛的气候。

① 韩屋 (Hanok / 한옥) 是什么 —— 不是"房子"而是"引自然入室的结构"

韩屋 (韓屋 / Hanok / 한옥) 字面意思就是"韩国的房子"，即韩国的传统住宅。它最大的特征，是从不把房子与自然割裂开。

  • 材料皆取自然：柱子和横梁是木，墙是土（黄土 (Hwangto / 황토)，赭石黏土），础石与台基是石，门窗糊上韩纸 (Hanji / 한지)。全都是取自自然、归于自然的材料。因此韩屋在英语圈常被介绍为"会呼吸的房子"——因为土墙和韩纸会吸入并呼出湿气，调节室内空气。
  • 内与外的界线模糊：从房间 → 退厅地板 (Toenmaru / 툇마루) → 大厅 (Daecheong / 대청) → 庭院 (Madang / 마당) → 自然，由室内向室外层层相连。把门（窗户 (Changho / 창호)）抬起挂到屋檐上，房间与庭院便如同一个空间般敞开。它不是"被墙封闭的箱子"，而是"与自然相连的层"。
  • 目的是人与自然的和谐：韩屋的一切装置（屋檐角度·庭院位置·房屋朝向）都是为了不违逆光、风、水、山而把它们引进或挡住。这正是让韩屋不只是一座建筑，而成为"承载自然哲学的结构物"的原因。

② 空间构成 —— 内宅、舍廊房、大厅与庭院

韩屋，尤其是有规模的两班 (Yangban / 양반，贵族) 宅邸，不是一座大建筑，而是数座房舍（棟 / dong）围着庭院聚在一起的结构。每座房舍各司其职。

  • 内宅 (內舍 / Anchae / 안채)：房子最里侧，是女主人等女性的生活空间。正房、对屋、厨房集中于此，是外人目光触及不到的私密领域。
  • 舍廊房 (舍廊 / Sarangchae / 사랑채)：置于外侧的男主人（男性）的空间，也是接待客人·书房的领域。随着儒家文化扎根，兴起了把舍廊房建得宽大美观的潮流，有时还附带一处高地板叫楼台地板 (Numaru / 누마루，樓마루)。
  • 行廊房 (行廊 / Haengnangchae / 행랑채)：大门旁的附属空间。供仆人居住，或用作仓库、马厩。
  • 大厅地板 (大廳 / Daecheong-maru / 대청마루)：置于内宅正中央的最宽木地板。它是连接正房、对屋与庭院的动线枢纽与缓冲空间。天一热，吃饭、就寝、休闲全在大厅进行；留空时则成为接待、宴会的场所（下文 ④ 再述）。
  • 庭院 (中庭 / Madang / 마당)：被各房舍环绕的空土院。也可按房舍分为内庭院 (an-madang / 안마당) 与舍廊庭院 (sarang-madang / 사랑마당)。它是房子的心脏——晾晒谷物，举办婚礼与祭祀，光与风在此进出。

核心是"分离与连接"。男/女（舍廊房/内宅）、内/外（房间/庭院）、私密/公共空间，以房舍和庭院划分，却又以动线相连。一座房子原原本本地承载着韩国社会的秩序与生活节奏。

③ 天然材料·通风·采光 —— "会呼吸的房子"的秘密

韩屋被称为亲近自然的建筑，原因在于材料与空气的流动。

  • 韩纸窗户 (한지 窓戶 / Hanji Changho)：韩屋的门窗糊的不是玻璃，而是韩纸 (Hanji / 한지，楮树纸)。韩纸是世界级的坚韧而中性的纸，隔热效果比玻璃好，同时让新鲜空气透过细微的孔隙实现自然换气。冬天关住暖空气，又把光柔和地过滤进来。这是一扇"关着却在呼吸"的窗。
  • 黄土土墙 (황토 / Hwangto)：土墙湿气多时吸纳、干燥时呼出，自行调节室内湿度。夏凉、冬保温。
  • 通风设计：大厅地板前后通透，让对流风（通风）穿过。夏天，庭院的热空气与房后阴凉的冷空气之间的温差，使自然风穿过房子。这是一种无需空调就能消暑的结构。
  • 采光设计：庭院明亮的土地反射阳光，把光引入房间深处。庭院不是单纯的空地，而起到"光的反射板"的作用。

也就是说，韩屋是一座不靠机械便能驾驭气候的房子——通过木、土、石、韩纸这些天然材料，以及连接庭院、大厅、窗户的空气与光之路径。

④ 温突 + 地板 —— 冬与夏共处一屋

理解韩屋最重要的钥匙，是一座房中另设"冬季空间"与"夏季空间"这一点。

温突房 (Ondol-bang / 온돌방)（冬） 大厅地板 (Daecheong-maru / 대청마루)（夏）
地板 加热石、土的温突 (Ondol / 온돌)（→ #1141） 清凉的木地板
原理 以灶口 (Agungi / 아궁이) 之火加热地板（辐射取暖） 前后通透让风穿过（通风）
用途 冬季就寝·生活 夏季吃饭·休息·待客
感觉 从脚开始暖 从脚底开始凉
  • 温突 (溫突 / Ondol / 온돌)：让火的热气从地板下穿过以加热地板的韩国固有辐射取暖。是抵御冬季严寒的装置。（作动原理·历史·席地生活 → 参见 #1141 温突文化）
  • 大厅地板 (大廳 / Daecheong-maru / 대청마루)：架离地面建造的木地板，地板下有风穿过，因此夏天凉爽。暑气一来，家人的生活便从温突房移到大厅。

朝鲜半岛夏热而湿、冬长而冷——是两个极端的气候。其他国家的传统住宅通常只针对其中之一（寒或暑）来建，而韩屋把温突（冬）+ 地板（夏）一并纳入一座房中，同时解决两个极端。这正是韩屋空间设计最聪明之处。

⑤ 背山临水·风水 —— 该把房子放"在哪里"

韩屋在建房之前先看地势。其原理就是风水 (Pungsu / 풍수，風水)，而其核心是背山临水 (Baesan-imsu / 배산임수，背山臨水)。

  • 背山临水 (Baesan-imsu / 배산임수)：字面意思是"背靠山（背山）、面朝水（臨水）"。后有山为屏，前有江河流淌，房子以朝南为理想之位。
  • 为何如此 —— 从自然科学看也合理：
  • 山在身后 → 挡住寒冷的西北风以冬季保温，并取得从山上流下的水与柴薪。
  • 水在身前 → 供农耕与饮水，视野开阔，采光·通风优良。
  • 朝南 → 把冬日阳光深深引入，而夏日阳光由屋檐挡住。
  • 明堂 (Myeongdang / 명당)：风水中把这样的位置称为"明堂 (myeongdang / 명당，吉地)"。这并非单纯迷信，而是挑选日照、通风、排水、防风俱佳、适合健康生活的自然条件的结果。
  • 屋檐 (Cheoma / 처마) 的角度也是同一哲学的延伸。屋檐的长度经过计算，使其挡住夏日的太阳（高悬）、纳入冬日的太阳（低斜）。同一扇窗，夏天成荫、冬天进阳。

也就是说，韩屋不是一座建筑的设计，而是连"地·山·水·日·风"都包含在内的风景设计。这是一种把房子"安坐"于自然之中的思维方式。

⑥ 地域差异与现代韩屋 —— 从北村到韩屋住宿

① 形态因地域而异。 朝鲜半岛南北气候差异大，因此韩屋的平面（从上方看的形状）也因地而异。

地域 平面形态 特征
南部（开放型） 一字形 房与大厅排成一列敞开。以应对暑热的开放·通风为中心
中部 ㄱ（基役）字形 正房与对屋之间设大厅。南部与北部的折中
北部（封闭型） ㅁ（米音）字形 建筑从四面环绕庭院。挡住寒风、保存暖气

越往暖和的南方越是敞开的一字形，越往寒冷的北方越是封闭的ㅁ字形。即便是同样的韩屋，也会随气候舒展或蜷缩——形态顺应自然而变。

② 现代里，韩屋正重新焕发生机。 韩屋不是博物馆里的文物。

  • 北村韩屋村 (Bukchon Hanok Village / 북촌 한옥마을，首尔)：位于景福宫 (Gyeongbokgung / 경복궁) 与昌德宫 (Changdeokgung / 창덕궁) 之间，是在城市正中央存活下来的城市型韩屋密集区。它既是真有居民居住的村落，也是代表性的散步路线。
  • 全州韩屋村 (Jeonju Hanok Village / 전주 한옥마을)·安东河回村 (Andong Hahoe Village / 안동 하회마을)：全州是约700座房聚集的代表性韩屋群落，安东河回村保存了昔日氏族村落的形态，是联合国教科文组织世界遗产（韩国历史村落）。
  • 韩屋住宿 / 韩屋酒店 (Hanok-stay / 한옥스테이)：在韩屋住一晚的住宿。坐在地板上眺望庭院，在温突房里入睡的体验，深受外国游客喜爱。
  • 新韩屋 (Sinhanok / 신한옥，新韓屋)·生活韩屋：保留传统木结构与屋檐、庭院之美学，而把隔热、管道、厨房等以现代技术加以补强的新韩屋。是建在城市里的"今日之韩屋"。

⑦ 外国人韩屋体验指南 —— 怎么玩

营业·收费因门店与季节而异 —— 建议出行前确认官方渠道。

  • 散步：北村（首尔）·全州韩屋村·安东河回村是代表性散步地。北村是有人实际居住的村落，因此保持安静·注意拍照礼仪很重要（清晨人少、利于拍照）。
  • 住一晚（韩屋住宿）：想亲身体验地板、庭院、温突，韩屋民宿/韩屋酒店最佳。在温突房里脱鞋、睡在地板上的经历，能让你用身体读懂韩屋的核心。
  • 这样看才更有深度：
  • 别看屋顶，而看庭院的位置与大厅敞开的方向——光与风之路便会显现。
  • 看屋檐的末端 (Cheoma / 처마)——它是按挡住夏日太阳的角度计算出来的。
  • 摸一摸窗户（韩纸门）——即便关着也透光，正是韩屋的感觉。
  • 礼仪：有人居住的韩屋·传统住宅多为私有地。切勿擅自进入或窥探窗内。鞋要在地板、房间前脱下。

❓ 外国人常问的问题（FAQ）

  • 韩屋和温突是一回事吗？ —— 不是。温突 (Ondol / 온돌，#1141) 是"把地板加热的取暖技术"，而韩屋 (Hanok / 한옥) 是包含那个温突在内的整座房子（庭院·大厅·舍廊房·屋檐·风水）。温突是构成韩屋的一个部分。
  • 庭院为什么是空的？ —— 是特意留空的。因为它是反射光·通风·家中活动（婚礼·祭祀·农事）的舞台。其目的与西式草坪花园不同。
  • 在韩屋睡觉冷吗？ —— 冬天温突房暖和，夏天大厅地板凉爽。它的设计让人按季节使用相应空间，反而舒适。
  • 韩屋都是两班（贵族）的房子吗？ —— 不是。有规模的两班宅邸分成数座房舍（内宅·舍廊房），但平民的韩屋（草房、小瓦房）在地板、温突、庭院的基本原理上是相同的。
  • 在首尔想看韩屋去哪？ —— 北村韩屋村·西村 (Seochon / 서촌) 最具代表性。是市中心里的城市型韩屋，交通方便。要看深处乡村的韩屋，则去全州·安东河回村。
