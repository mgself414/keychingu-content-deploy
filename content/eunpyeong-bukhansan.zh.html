恩平·北汉山7处 — 北汉山城路线·韩屋村·津宽寺·西五陵，公交车号码和关门时间

副标题: 为乘坐地铁3号线来到恩平的旅行者，把北汉山2处、津宽洞韩屋村一带4处、恩平旁边的西五陵1处整理在一起。北汉山实行入山时间指定制，12~2月从16:00、3~11月从17:00起管制登山道入口(11月·3月按16:00算)。北汉山城路线从北汉山城探访支援中心到白云台是3.4km，2小时40分钟，难度"中"。在Gupabal站乘704路公交车，在"北汉山城入口"下车。恩平历史韩屋博物馆09:00~18:00开放，周一休息，普通票1,000韩元。津宽寺的寺院饮食体验是80,000韩元，只用韩语进行。西五陵在京畿道高阳市，11~1月07:00~17:30开放，周一休息。数值是2026-11-25查阅到的。

🎯 适合谁，为什么是这7处

这份清单面向乘坐地铁3号线来到恩平的外国旅行者。在恩平区北端爬山、走环山路，看韩屋村、寺庙和王陵时用。

分成三组。

  • 北汉山(2处): 北汉山城路线、北汉山环山路恩平区间(第7~10区间)。
  • 津宽洞韩屋村一带(4处): 恩平韩屋村、恩平历史韩屋博物馆、三角山黔岩美术馆、津宽寺。
  • 恩平旁边(1处): 西五陵。

西五陵的地址不在首尔恩平区，而是京畿道高阳市德阳区。紧挨着恩平，去的公交车从3号线Nokbeon站 (Nokbeon / 녹번) 和Hongje站 (Hongje / 홍제)、6号线Yeokchon站 (Yeokchon / 역촌) 和Gusan站 (Gusan / 구산) 发车，所以放在这一篇里一起介绍。

这一篇的七处都是从地铁站换乘公交车去的。所以这一篇对每一处都先写"从哪个站乘几路公交车，在哪个站点下车"。关门时间也是每处各不相同，有的会随季节变化，所以另外整理。

⚠ 标注原则: 时间、票价、交通方式是2026-11-25查阅到的值。出处是国立公园公团、恩平区厅(恩平历史韩屋博物馆·恩平文化观光)、津宽寺官网、寺院寄宿(Templestay)预约网站(templestay.com)、国家遗产厅宫陵遗迹本部、GTX-A运营方官网。恩平韩屋村建设时期的一行是首尔市首尔韩屋门户的值，相应的行里注明了。部分地址和部分营业时间是Kakao Map值，相应的行里注明了"Kakao Map登记值(2026-11-25)"。票价为成人标准价。国立公园公团的交通指南和环山路区间指南没有标注更新日期。公交车号码和站点名称，出发前在地图应用上再确认一次。运营时间和票价可能变动。

⚠ 容易搞混的3点

  1. 北汉山不是什么时候都能进。 国立公园公团官方指南(2026-11-25查阅)中的北汉山表格，冬季(12~2月)写的是入山04:00、管制16:00。夏季(3~11月)是入山04:00、管制17:00。过了管制时间，就不能从登山道入口上去。同一个公团表格的说明文字写的是冬季为11~3月、夏季为4~10月，与表头(12~2月/3~11月)不同。11月和3月按16:00之前通过入口来安排。
  2. 西五陵不是从Gupabal站去的地方。 宫陵遗迹本部官方指南(2026-11-25查阅)的公共交通一行里没有Gupabal站。在3号线Hongje站2号出口中央公交站，或者Nokbeon站4号出口(恩平区厅方向)乘702A·702B·707路，在"西五陵入口 (Seooreung Entrance / 서오릉입구)"下车。地址也是京畿道高阳市德阳区。
  3. 恩平韩屋村不是旅游设施，而是有人居住的房子。 首尔韩屋门户把这里介绍为"新韩屋专用居住区"。每户都有人居住。有固定关门时间的是村里的博物馆和美术馆。博物馆18:00关门，入场17:00结束。

① 北汉山 — 2处

据国立公园公团官方介绍(2026-11-25查阅)，北汉山国立公园1983年被指定为韩国第15座国立公园。面积76.922㎢。以牛耳岭 (Uiryeong / 우이령) 为界，北边是道峰山 (Dobongsan / 도봉산) 地区，南边是北汉山地区。公团介绍说有"拥有2,000年历史的北汉山城"和"100多座寺庙、庵堂"。在恩平一侧，北汉山城探访支援中心是山路的出发点，山脚下有环山路经过。

北汉山城路线 — 从北汉山城探访支援中心到白云台 (Bukhansanseong Course / 북한산성 코스)

  • 区间: 国立公园公团官方路线指南(2026-11-25查阅)为北汉山城探访支援中心~大西门~菩提寺~白云台。
  • 距离: 3.4km。
  • 所需时间: 2小时40分钟。行程写的是"当天"。
  • 难度: 中。
  • 读时间的方法: 公团指南的区间是从中心到白云台的单方向。公团指南没有标明单程·往返。本篇把2小时40分钟按上山的值来理解。下山的时间要另外加上。
  • 入山时间: 国立公园公团官方入山时间指定制指南(2026-11-25查阅)，北汉山城入口~Wimun (위문) 区间冬季(12~2月)是04:00~16:00，夏季(3~11月)是04:00~17:00(11月·3月按16:00算)。16:00和17:00是管制入口的时刻。
  • 出发点地址: 北汉山城探访支援中心，首尔市恩平区 (Daeseomun-gil 45 / 대서문길 45)。
  • 交通方式: 国立公园公团官方交通指南(2026-11-25查阅)，在3号线Gupabal站乘704路公交车，在"北汉山城入口 (Bukhansanseong Entrance / 북한산성입구)"下车。环山路第10区间的指南写的是，同一趟704路在Gupabal站1号出口乘。
  • 停车: 北汉山城第1·2停车场(首尔市恩平区津宽洞 280、278)。
  • 咨询: 北汉山国立公园事务所 (Bukhansan National Park Office / 북한산국립공원사무소) 02-909-0497。
  • 安排时间: 12~2月要在16:00之前通过入口。在按上山值理解的2小时40分钟之上加下山的时间，冬季上午从中心出发。这是本篇的建议。

② 津宽洞韩屋村一带 — 4处

韩屋村、博物馆、美术馆、寺庙都集中在津宽洞一处。乘坐的公交车号码也重叠。恩平历史韩屋博物馆官方指南(2026-11-25查阅)的站点名称是"Hana高中·津宽寺·三千寺入口 (Hanago, Jingwansa, Samcheonsa Entrance / 하나고, 진관사, 삼천사 입구)"。

恩平韩屋村 (Eunpyeong Hanok Village / 은평한옥마을)

  • 是什么样的地方: 据恩平区厅官方指南(2026-11-25查阅)，是Hana高中 (Hana Academy Seoul / 하나고등학교) 对面的韩屋指定区域。面积65,500㎡，建设规模是韩屋156块地。房子盖在2层以下。土地由SH公社 (SH Corporation / SH공사) 供应。
  • 建设时期: 据恩平区厅官方指南，2010年11月审议了建设计划，2012年10月首尔市指定为特别建筑区域。土地出让从2012年9月到2014年11月。首尔市首尔韩屋门户写的是2014年12月建成。
  • 有人居住这一点: 是居民实际居住的房子。小巷可以走，但看不到房子里面。安静地走，不拍大门里面。这是本篇的建议。
  • 地址(Kakao Map登记值，2026-11-25): 首尔恩平区 (Yeonseo-ro 50-gil 7-10 / 연서로50길 7-10)。
  • 交通方式: 按恩平历史韩屋博物馆官方指南，乘701·709·7723·7211路公交车，在"Hana高中·津宽寺·三千寺入口 (Hanago, Jingwansa, Samcheonsa Entrance / 하나고, 진관사, 삼천사 입구)"下车。在Yeonsinnae站(3·6号线)3号出口乘701·709·7211路约15分钟。在Gupabal站换乘中心(4号出口)乘7723路约10分钟。在Gupabal站2号出口乘7211路也是约10分钟。
  • 周边: 首尔韩屋门户介绍说，这一带有恩平历史韩屋博物馆、津宽寺、三角山黔岩美术馆，容易前往北汉山环山路第9区间。

是恩平区厅运营的博物馆。以下值是博物馆官方使用指南2026-11-25的标注。恩平区厅官方指南写的开馆时间是2014年10月。

  • 安排时间: 入场17:00结束。比津宽寺和韩屋村小巷先进去。

三角山黔岩美术馆 (Samgaksan Geumam Art Museum / 삼각산금암미술관)

  • 是什么样的地方: 据恩平区厅官方指南(2026-11-25查阅)，是把试验韩屋 (Siheom Hanok / 시험한옥) 改造后开设的文化复合空间。展出从古家具到当代作品。2018年4月开馆。
  • 地址: 首尔市恩平区 (Jingwan-gil 21-2 / 진관길 21-2)。电话 02-351-8554。
  • 开放时间: 周二~周日 10:00~18:00，12:00~13:00是休息时间(Kakao Map登记值，2026-11-25)。周一登记为休息日。
  • 交通方式: Kakao Map登记地址是首尔恩平区 (Jingwan-gil 21-2 / 진관길 21-2)。在恩平韩屋村内，走韩屋村时顺路去。
  • 安排时间: 博物馆09:00开门，美术馆10:00开门。先看博物馆再去美术馆。避开12:00~13:00。

津宽寺 (Jinkwansa Temple / 진관사)

  • 是什么样的地方: 津宽寺官方沿革(2026-11-25查阅)写的是，高丽第8代显宗为津宽大师 (Jingwan Daesa / 진관대사) 在1011年创建。工程1011年秋天开始，1012年秋天结束。在6·25战争中被轰炸成废墟，后来修复。津宽寺官方介绍把这座寺庙列为"首尔近郊四大名刹"中西边的寺庙。
  • 地址: 首尔恩平区 (Jingwan-gil 73 / 진관길 73)。电话 02-359-8410。
  • 寺院饮食体验: 寺院寄宿(Templestay)预约网站(templestay.com)官方指南(2026-11-25查阅)中有一日项目"寺院饮食体验"。进行钵盂供养 (Baru Gongyang / 발우공양)。10:30起到达，14:00结束。
  • 体验票价和语言: 80,000韩元，只用韩语进行。预约网站(templestay.com)指南说明这个项目是韩语进行、面向韩国人参加者。
  • 预约: 开始前3天之前预约。申请人不足15人可能会取消。日程会随寺庙情况变动。
  • 交通方式: 津宽寺官网写的是，在Yeonsinnae站乘7211·701路，在Gupabal站乘7211·7723路，在"Hana高中 (Hanago / 하나고)"下车。寺院寄宿(Templestay)预约网站写的是，在Gupabal站4号出口乘704路，在"津宽寺前 (Jingwansa Front / 진관사 앞)"下车，步行10分钟。
  • 安排时间: 寺院饮食体验10:30开始，所以那天先去津宽寺。体验14:00结束，博物馆入场17:00截止。

③ 恩平旁边 — 1处

西五陵 (Seooreung Royal Tombs, Goyang / 서오릉)

是五座朝鲜王陵聚集的地方。紧挨着恩平区，但地址在京畿道。以下值是国家遗产厅宫陵遗迹本部官方指南2026-11-25的标注。

  • 地址: 京畿道高阳市德阳区 (Seooreung-ro 334-32 / 서오릉로 334-32)。咨询 朝鲜王陵西部地区管理所 (Joseon Wangneung Seobu Jigu Gwalliso / 조선왕릉서부지구관리소) 02-359-0090。
  • 五座陵: 敬陵 (Gyeongneung / 경릉)(追尊德宗和昭惠王后)，昌陵 (Changneung / 창릉)(第8代睿宗和安顺王后)，明陵 (Myeongneung / 명릉)(第19代肃宗和仁显王后·仁元王后)，翼陵 (Ingneung / 익릉)(肃宗的王后仁敬王后)，弘陵 (Hongneung / 홍릉)(第21代英祖的王后贞圣王后)。
  • 世界遗产: 朝鲜王陵40座于2009年6月30日列入联合国教科文组织世界遗产。西五陵的五座陵在其中。

按季节的参观时间

月份 参观时间 停止入场
2~5月，9~10月 07:00~18:00 17:00
6~8月 07:00~18:30 17:30

  • 离场时间: 关门前30分钟开始引导离场。根据机构情况，时间可能缩短或变更。
  • 休息日: 周一。周一是公休日或补休日的话开门，之后第一个非公休日休息。
  • 票价: 成人个人1,000韩元。本国人和外国人相同。成人年龄外国人是满19~64岁，本国人是满25~64岁。
  • 交通方式: 站点名称是"西五陵入口 (Seooreung Entrance / 서오릉입구)"。在3号线Hongje站2号出口中央公交站，或者Nokbeon站4号出口(恩平区厅方向)乘702A·702B·707路。在3号线Wondang站3号出口、6号线Yeokchon站2号出口、Gusan站1号出口乘707路。
  • 讲解: 王陵现场讲解在周二~周日10:30、13:00、15:00进行。在综合导览牌前集合，约需1小时。

❄ 冬季(12~2月)的变化

  • 北汉山入口管制提前到16:00。 12~2月的管制时刻是16:00。3~11月是17:00(11月·3月按16:00算)。
  • 西五陵早关门。 11~1月17:30关门，16:30入场结束。2月18:00关门，17:00入场结束。
  • 博物馆的时间只有一种。 恩平历史韩屋博物馆官方使用指南的时间是09:00~18:00，停止入场是17:00。1月1日和春节假期休息。
  • 管制区间看公告。 2026-11-25看到的国立公园公团官方管制信息列表里，没有封闭北汉山城路线的公告。管制会随公告变动，所以出发当天早上打开管制信息页面。
  • 路会结冰。 这是本篇的建议。下雪之后岩石和台阶很滑。冬季比起去山顶的路线，难度"低"的环山路第9·10区间更好走。

⚙ 3个常见问题

  1. 第一次爬山的话走哪里好？ — 选环山路第9区间串门路(1.5km，约45分钟，难度低)和第10区间内侍墓域路(3.5km，约1小时45分钟，难度低)。国立公园公团把环山路介绍为低地水平散步路。北汉山城路线是3.4km、2小时40分钟，难度"中"。第一次的话先走环山路。这是本篇的建议。
  2. 从Gupabal站能去到哪里？ — 乘704路，会停靠北汉山城路线的"北汉山城入口 (Bukhansanseong Entrance / 북한산성입구)"和环山路的"Ipgok Samgeori (입곡삼거리)"、"Hyojadong Maeul Geumgo (효자동마을금고)"。换乘中心(4号出口)的7723路和2号出口的7211路，约10分钟到达韩屋村和博物馆前的站点。去西五陵不是在Gupabal站，而是在Nokbeon站、Hongje站、Yeokchon站、Gusan站、Wondang站乘公交车。
  3. 周一能去哪里？ — 恩平历史韩屋博物馆和西五陵周一休息。周一是公休日的话，博物馆周二休息，西五陵之后第一个非公休日休息。北汉山城路线、环山路、韩屋村小巷不分星期都可以走。

🗺 路线 — 半天·一天

顺序是按各处的开门和关门时间安排的。

半天A — 津宽洞韩屋村一带 (避开周一)

  1. Gupabal站换乘中心(4号出口)乘7723路 → "Hana高中·津宽寺·三千寺入口 (Hanago, Jingwansa, Samcheonsa Entrance / 하나고, 진관사, 삼천사 입구)"(约10分钟)。
  2. 恩平历史韩屋博物馆(从站点步行3分钟)。09:00起开放。普通票1,000韩元。
  3. 三角山黔岩美术馆。按Kakao Map登记值(2026-11-25)，10:00起开放。12:00~13:00休息。
  4. 恩平韩屋村小巷。安静地走。
  5. 津宽寺(Jingwan-gil 73 / 진관길 73)。
  6. 回程的站点在地图应用上看。

半天B — 环山路第9区间和第10区间

  1. Yeonsinnae站3号出口乘7211路 → "津宽寺入口 (Jingwansa Entrance / 진관사입구)"(环山路指南中的名称) → 津宽生态桥 (Jingwan Eco Bridge / 진관생태다리) 前(从站点步行15分钟)。
  2. 第9区间串门路 1.5km，约45分钟。
  3. 在Bangpae Gyoyukdae (방패교육대) 前接第10区间内侍墓域路 3.5km，约1小时45分钟。
  4. 在Hyojadong公设墓地 (Hyojadong Public Cemetery / 효자동공설묘지) 结束。回程的站点在地图应用上看。

一天 — 北汉山城路线 (上午出发)

时段 要做的事 要对好的时间
上午 从Gupabal站乘704路 → "北汉山城入口" → 北汉山城探访支援中心 04:00起可入山
上午~中午 中心 → 大西门 → 菩提寺 → 白云台 3.4km，2小时40分钟，难度中
中午~下午 沿同一条路下山 天黑之前到达中心(本篇的建议)
傍晚 经Gupabal站去3号线Yeonsinnae站 回程的站点在地图应用上看

半天C — 西五陵 (避开周一)

  1. 3号线Nokbeon站4号出口(恩平区厅方向)乘702A·702B·707路 → "西五陵入口 (Seooreung Entrance / 서오릉입구)"。
  2. 配合10:30的现场讲解，去综合导览牌前。约需1小时。
  3. 走五座陵。11~1月17:30关门。
  4. 回程的站点在地图应用上看。

如果有两天，一天走北汉山城路线，另一天上午去西五陵、下午去韩屋村一带。第二天避开周一。
