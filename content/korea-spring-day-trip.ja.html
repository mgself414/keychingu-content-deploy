加平・楊平 日帰りガイド — 南怡島・アチムゴヨ樹木園・プチフランス、ドゥムルモリ・洗美苑・楊平サンスユ村・龍門寺のイチョウ

サブタイトル: 南怡島(08:00~21:00) · アチムゴヨ樹木園(08:30~19:00) · プチフランス(09:00~18:00) · ドゥムルモリ(常時開放) · 洗美苑(09:00~18:00、11~3月月曜休館) · 楊平サンスユ村(3~4月開花、常時開放) · 龍門寺・イチョウ(常時開放) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルの東にある京畿道の加平・楊平で、一日で行ける場所をまとめたものです。加平の三か所(南怡島の船着場・アチムゴヨ樹木園・プチフランス)と楊平の四か所(ドゥムルモリ・洗美苑・サンスユ村・龍門寺)です。洗美苑だけが11~3月の月曜日に休み、ほかは年中無休で登録されています。

春には、楊平サンスユ村が3~4月に黄色く染まります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 加平 — 南怡島・アチムゴヨ樹木園・プチフランス

南怡島、春川市 Namiseom-gil 1 (남이섬길 1)、☎ 031-580-8114 は、「童話の国、歌の島」をコンセプトに、文化行事、コンサート、展示を開く島です。江原道の春川に属しますが、入るには京畿道の加平にある南怡島の船着場へ行きます。ドラマ「冬のソナタ (Gyeoul Yeonga / 겨울연가)」のロケ地として知られています。歌の博物館、絵本の遊び場、ユニセフラウンジ、自転車、分かち合い列車、ホテルのチョングァンル (Jeonggwanru / 정관루)があります。

  • 開く時間: 08:00~21:00。船の運航時間は別に運営されます。
  • 休み: 年中無休。駐車: 可能(約600台)。
  • 体験: ガラス・陶磁器の工芸、石窯ピザ作りなど。

アチムゴヨ樹木園、加平郡 サン面 Sumokwon-ro 432 (수목원로 432)、☎ 1544-6703 は、チュクリョン山 (Chukryeongsan / 축령산)を背景にした園芸の樹木園で、1996年5月に開園しました。テーマの違う庭園が20か所あり、韓半島の地形の形に整えたサンクンガーデンのハギョン庭園 (Hagyeong Jeongwon / 하경정원)があります。白頭山 (Baekdusan / 백두산)の植物300種余りを含め、5,000種余りの植物があります。冬には照明で五色星光庭園展 (Osaek Byeolbit Jeongwonjeon / 오색별빛정원전)を開くと紹介されています。多くのドラマやバラエティのロケ地です。

  • 開く時間: 08:30~19:00(入場締切 18:00)。休み: 年中無休。
  • 駐車: 可能。体験: 苔・フラワーテラリウム、ドローイングポットなど。

プチフランス、加平郡 清平面 Hoban-ro 1063 (호반로 1063)、☎ 031-584-8200 は、清平ダム (Cheongpyeong Dam / 청평댐)から南怡島方面へ湖畔の道を約10kmの所にあるフランス文化村で、コンセプトは「花と星、そして星の王子さま」です。サン=テグジュペリ記念館、200年前のオルゴールが聴けるオルゴールハウス、フランス伝統住宅の展示館、骨董品の展示館があります。多くのドラマのロケ地です。

  • 開く時間: 09:00~18:00。季節と天気によって閉まる時間が変わります。夜間の開場時間は別に案内されます。
  • 休み: 年中無休。駐車: 可能。体験: 星の王子さま体験・石膏体験、そり場体験など。

📍 楊平 — ドゥムルモリ・洗美苑

楊平ドゥムルモリ、楊平郡 ヤンソ面 Dumulmeori-gil 145 (두물머리길 145)、☎ ドゥムルモリ観光案内所 (Dumulmeori Gwangwang Annaeso / 두물머리 관광안내소) 031-775-8700 は、北漢江 (Bukhangang / 북한강)と南漢江 (Namhangang / 남한강)の二つの水が合わさる所で、漢江の始まりです。早朝の川霧と日の出、黄布帆船、400年を超えるケヤキがあります。韓国観光100選に選ばれ、謙斎鄭敾 (Gyeomjae Jeong Seon / 겸재 정선)などの作品にも残っています。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

洗美苑、楊平郡 ヤンソ面 Yangsu-ro 93 (양수로 93)、☎ 031-775-1835 は、三方をパルダン湖 (Paldang-ho / 팔당호)に囲まれた水と花の庭園で、水生植物など約270種の植物があります。2019年6月に京畿道の第1号地方庭園に指定されました。丁若鏞 (Jeong Yak-yong / 정약용)が南漢江に舟橋を架けた場所として知られています。蓮の花博物館、スイレン温室、ソクチャン苑 (Seokchangwon / 석창원)、サンチュン苑 (Sangchunwon / 상춘원)があります。

  • 開く時間: 09:00~18:00。入場券は閉まる30分前まで販売します。蓮の花祭りの期間は時間が別に運営されます。
  • 休み: 4~10月は年中無休、11~3月は毎週月曜日(月曜日が祝日なら翌日が振替休館)。
  • 駐車: 可能。体験: 水生植物体験教室、蓮の花の団扇作り、天然ハンカチ染めなど。

📍 楊平 — サンスユ村・龍門寺

楊平サンスユ村、楊平郡 ケグン面 (Gaegun-myeon / 개군면) Sansuyu 1-gil 1 (산수유1길 1)、☎ 031-772-2257 には、100年を超えるサンシュユの木7千本余りが集まっています。毎年3~4月には村が黄色く染まり、秋には赤い実がなります。毎年4月上旬ごろ、サンシュユの花をテーマにサンスユ韓牛祭り (Sansuyu Hanu Chukje / 산수유한우축제)を開き、農村体験ができます。サンシュユの実と花で作った食べ物とお茶、ケグン面の特産品である在来韓牛を味わえると紹介されています。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

龍門寺、楊平郡 ヨンムン面 Yongmunsan-ro 782 (용문산로 782)、☎ 031-773-3797 は、龍門山 (Yongmunsan / 용문산)のふもとにある大韓仏教曹渓宗 (Daehan Bulgyo Jogyejong / 대한불교조계종)の寺で、新羅の神徳王 (Sindeok-wang / 신덕왕)2年(913)にテギョン大師 (Daegyeong Daesa / 대경대사)が建てたと伝わります。大雄殿 (Daeungjeon / 대웅전)、サンニョン閣 (Sanryeonggak / 산령각)、チルソン閣 (Chilseonggak / 칠성각)、テンプルステイの修練館があり、テンプルステイは休息型と体験型から選べます。寺から谷沿いに2km登るとヨンガク岩 (Yonggak Bawi / 용각바위)、さらに1km行くとマダン岩 (Madang Bawi / 마당바위)があります。

  • 龍門寺のイチョウ (Yongmunsa Eunhaengnamu / 용문사 은행나무)、☎ 龍門山観光団地案内事務所 (Yongmunsan Gwangwangdanji Annaesamusil / 용문산 관광단지 안내사무소) 031-773-0088: 樹齢約1,100年、高さ42mと推定される天然記念物です。韓国観光公社の観光情報に載る国家遺産庁の資料によると、韓国のイチョウの中で樹齢と高さが最も高い記録を持っています。麻衣太子 (Maui Taeja / 마의태자)が植えたという伝説と、義湘大師 (Uisang Daesa / 의상대사)の杖が育ったという伝説が伝わります。
  • 開く時間: 常時開放。休み: 年中無休。
  • 駐車: 可能(約700台)。軽自動車1,500ウォン、小型車3,000ウォン、中・大型車5,000ウォン。

⚠ 事前に知っておきたい3つのこと

  1. 南怡島は春川に属しますが、加平の船着場から入ります — 08:00~21:00に開き、船の運航は別に運営されます。
  2. 洗美苑は11~3月の月曜日が休みです — 4~10月は年中無休です。
  3. アチムゴヨ樹木園は18:00に入場を締め切ります — 08:30~19:00に開いています。

⚙ FAQ 2

Q. 春に花を見に行くのによい場所は?

A. 観光公社の登録情報では、楊平サンスユ村が3~4月にサンシュユで黄色く染まり、4月上旬ごろにサンスユ韓牛祭りを開くと紹介されています。常時開放です。

Q. 南怡島はどこから入りますか?

A. 南怡島は江原道の春川に属しますが、京畿道の加平にある南怡島の船着場へ行って入ります。船の運航時間は別に運営されます。
