⚠ 外国人常犯的 3 个错误

1. "K-电影 = 只有《寄生虫 (Gisaengchung / 기생충)》": K-电影还有许多其他经典作品，如《老男孩 (Oldeuboi / 올드보이)》·《釜山行 (Busanhaeng / 부산행)》·《出租车司机 (Taeksi Unjeonsa / 택시운전사)》·《国际市场 (Gukje Sijang / 국제시장)》等。

2. "BIFF (釜山国际电影节 / 부산국제영화제) = 只有 10 月": 除了 10 月的 BIFF (釜山国际电影节 / 부산국제영화제)，还有5 月的 JIFF (全州国际电影节 / Jeonju Gukje Yeonghwaje) 和 7 月的 BFFC (富川国际奇幻电影节 / Bucheon Gukje Panjeong Yeonghwaje)，深受外国影迷喜爱。

3. "《寄生虫 (Gisaengchung / 기생충)》取景地 = 无法前往": 《寄生虫 (Gisaengchung / 기생충)》的取景地包括阿岘 (Ahyeon / 아현)·西大门 (Seodaemun / 서대문) (贫民区) + 城北 (Seongbuk / 성북) (朴社长家 (Bak Sajang Jip / 박 사장 집) 外观)，是外国人 Vlog 的热门地点。

⚙ 4 个常见问题

1. 外国人 K-电影首选: 《寄生虫 (Gisaengchung / 기생충)》·《老男孩 (Oldeuboi / 올드보이)》·《釜山行 (Busanhaeng / 부산행)》·《出租车司机 (Taeksi Unjeonsa / 택시운전사)》。

2. 外国人电影节: BIFF (釜山国际电影节 / 부산국제영화제) (10 月 釜山 (Busan / 부산))·JIFF (全州国际电影节 / Jeonju Gukje Yeonghwaje) (5 月 全州 (Jeonju / 전주))·BFFC (富川国际奇幻电影节 / Bucheon Gukje Panjeong Yeonghwaje) (7 月 富川 (Bucheon / 부천))。

3. 外国人导演影迷: 奉俊昊 (Bong Joon-ho / 봉준호)·朴赞郁 (Park Chan-wook / 박찬욱)·李沧东 (Lee Chang-dong / 이창동)。
