中浪川·安养川指南 — 中浪玫瑰公园，安养川堤坝樱花路·四季主题园·家庭花园·戏水场，首尔环城步道13·14路线

副标题:中浪玫瑰公园(全天开放，5月玫瑰节) · 安养川堤坝樱花路(全天开放) · 安养川四季主题园(全天开放) · 安养川家庭花园(全天开放) · 安养川戏水场(10:00~18:00，周一休息) · 首尔环城步道13路线(8km)·14路线(10.2km) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了沿着首尔东北部的中浪川和西南部的安养川可以去的地方，分别是中浪区的一处玫瑰公园、安养川永登浦·阳川·九老区间的樱花路·花园·戏水场共四处，以及沿安养川步行的两条首尔环城步道路线。除戏水场外全部全天开放。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 中浪川 — 中浪玫瑰公园

中浪玫瑰公园(Jungnang Jangmi Gongwon / 중랑장미공원)，中浪区(Mukdong / 묵동)，☎ 中浪区厅公园绿地科(Jungnangucheong Gongwon Nokji-gwa / 중랑구청 공원녹지과) 02-2094-2372，是沿着中浪川(Jungnangcheon / 중랑천)路按区域种植了多个品种玫瑰的公园。玫瑰盛开的5月举办玫瑰节。据观光公社介绍，每年有超过200万人前来参加庆典，沿中浪川堤坝而建的5.4km玫瑰隧道是韩国国内最大规模。有Angela(안젤라)、Pink Perfume(핑크 퍼퓸)、Goldpasade(골드파사데)等品种，设有俯瞰中浪川的观景栈道、拍照区和夜间灯光。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:不可以。

📍 安养川 — 堤坝樱花路·四季主题园·家庭花园·戏水场

安养川堤坝樱花路(Anyangcheon Jebang Beotkkotgil / 안양천제방벚꽃길)，永登浦区(Yangpyeong-dong 1-ga / 양평동1가)，☎ 永登浦区厅园林城市科(Yeongdeungpogucheong Jeongwon Dosi-gwa / 영등포구청 정원도시과) 02-2670-3772，是沿着安养川(Anyangcheon / 안양천)堤坝从永登浦区延伸到光明市(Gwangmyeong-si / 광명시)的樱花路。据观光公社介绍，这是首尔最长的樱花路。堤坝和河川周边设有花圃、生态公园、体育设施、休息处、四季主题园(玫瑰园、观赏草园等)和拍照区。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

安养川四季主题园(Anyangcheon Sagyejeol Temawon / 안양천 사계절 테마원)，阳川区(Sinjeong-dong / 신정동)，☎ 阳川区厅公园绿地科(Yangcheongucheong Gongwon Nokji-gwa / 양천구청 공원녹지과) 02-2620-3592，是位于沿安养川绵延的安养川生态公园(Anyangcheon Saengtae Gongwon / 안양천생태공원)内的花园。在玫瑰园、观赏草园、香草园可以随季节赏花，不收门票。夏季在玫瑰园旁开放儿童戏水场。距地铁2号线道林川站(Dorimcheon-yeok / 도림천역) 2号出口750m。

  • 开放时间:全天开放。休息日:全年无休。
  • 费用:免费。停车:可以。婴儿车租借:无。

安养川家庭花园(Anyangcheon Gajok Jeongwon / 안양천가족정원)，阳川区(Anyangcheon-ro 812 / 안양천로 812)，☎ 阳川区厅公园绿地科(Yangcheongucheong Gongwon Nokji-gwa / 양천구청 공원녹지과) 02-2620-3592，是在梧木桥(Omokgyo / 오목교)下方，通过安养川下游整治工程把废弃的河滩地改造而成的水边公园。有264m的小溪流过，设有花草园、草坪广场、观赏草园、玫瑰花园。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

安养川戏水场(Anyangcheon Mullorijang / 안양천 물놀이장)，九老区(Sindorim-dong 285-34 / 신도림동 285-34)，☎ 九老区厅体育振兴科(Gurogucheong Cheyuk Jinheung-gwa / 구로구청 체육진흥과) 02-860-2547，是夏季开放的戏水场。按安全水深设计，安全员常驻。周边设有遮阳棚和长椅、自行车道和步道。

  • 开放时间:10:00~18:00。每小时运营50分钟，休息10分钟。12:00~13:00是休息·清扫时间。
  • 休息日:每周一、雨天。

📍 沿安养川步行的路 — 首尔环城步道13·14路线

首尔环城步道(Seoul Dullegil / 서울둘레길)是全长156.5km、共21条路线环绕首尔一周的步行道。其中13·14路线沿着安养川延伸。两条路线晚上也可以步行(咨询 ☎ 02-779-7902~4)。

13路线 安养川上游线路(Seoul Dullegil 13-Koseu Anyangcheon Sangnyu Koseu / 서울둘레길 13코스 안양천 상류코스)，安养市(Manan-gu Gyeongsu-daero 1431 / 만안구 경수대로 1431)，主题是“沿铁路步行的樱花路”。春天樱花盛开。路程略长，但沿途各处都有地铁站。

  • 长度·时间:共8km，约2小时5分钟。开放时间:全天开放。

14路线 安养川下游线路(Seoul Dullegil 14-Koseu Anyangcheon Haryu Koseu / 서울둘레길 14코스 안양천 하류코스)，九老区(Guro-dong / 구로동)，主题是“安养川旧时回忆路”，与大部分为林间路的其他路线不同，沿着河川和汉江步行。沿途各处有运动设施、步道、便民设施和休息处。

  • 长度·时间:共10.2km，约2小时25分钟。开放时间:全天开放。

⚠ 行前须知 3 点

  1. 中浪玫瑰公园不能停车 — 玫瑰节在玫瑰盛开的5月举办。
  2. 安养川戏水场周一和雨天休息 — 12:00~13:00是休息·清扫时间。
  3. 首尔环城步道13路线以安养市地址登记 — 地址是安养市(Manan-gu Gyeongsu-daero 1431 / 만안구 경수대로 1431)。

⚙ FAQ 2

Q. 首尔樱花路最长的地方是?

A. 据观光公社介绍，是安养川堤坝樱花路(Anyangcheon Jebang Beotkkotgil / 안양천제방벚꽃길)。从永登浦区延伸到光明市，全天开放。

Q. 想看玫瑰什么时候去?

A. 中浪玫瑰公园(Jungnang Jangmi Gongwon / 중랑장미공원)在玫瑰盛开的5月举办玫瑰节。公园全天开放。
