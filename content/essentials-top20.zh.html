一句话简介

在韩国，外国人该买的不是"韩国人买的畅销TOP 100"，而是"本国没有或贵30~50%的好物"。中国游客以K-美妆、红参、婴幼儿用品拿下人均消费第一(免税销售额占比35%，药业新闻2024)；日本游客爱买方便单独分装的可爱包装；欧美游客则选Reddit验证过的成分功效 + Etsy手工艺叙事感单品。本指南将TOP 20压缩为5大品类 + 额外2个彩蛋，并整理出哪里最便宜、退税攻略以及各国优先级清单。

推荐对象

  • 3~7天短期游客 — 可享受市内即时退税(₩30,000+单张收据享8%直减，约¥160以上即可申请)
  • 中国游客 — 美妆·红参·婴幼儿用品人均消费₩300,000~₩700,000(约¥1,600~¥3,700)
  • 日本游客 — 公司·学校10~20人"散发(ばらまき)"伴手礼需求
  • 欧美游客 — 韩国原创品类(气垫·蜗牛精华·面膜贴)在本国售价为1.3~2倍
  • K-pop·K-剧入坑粉丝 — Rom&nd (롬앤 / Rom&nd)、Beauty of Joseon (美好朝鲜 / 어달리 조선)、COSRX (可思露 / 코스알엑스)等SNS打卡款猎购
  • 首次·再次访韩游客 — 心愿单精选 + 新晋热门单品
  • 大量采购伴手礼者 — 父母·同事·朋友5~10人分装套餐

4. 即时退税(VAT Refund)攻略

  • 适用对象: 外国短期游客(入境韩国6个月内·非居民)，需持护照
  • 市内即时退税: 单张收据 ₩30,000~₩299,999 → 结账时立即扣减7~8%。付款前出示护照并说"tax-free, please"
  • 机场退税 (仁川机场 (인천공항 / Incheon Airport) 4楼自助退税机): 单张收据 ₩300,000+ → 退税率7~13%(略高于即时退税)。可选择信用卡自动退款(回国后2~4周)或现场领取KRW/USD/JPY/CNY 4种货币现金
  • 可退税门店: Olive Young (올리브영 / Olive Young) / Daiso (다이소 / Daiso) / 百货商店 / 免税店 / 韩国旅游名品店 / Seoul My Soul (서울 마이 소울 / Seoul My Soul) / 仁寺洞 (인사동 / Insadong)·南大门 (남대문 / Namdaemun) 标有退税标志的门店
  • 不可退税: 普通便利店·市场摊贩·餐厅·咖啡馆
  • 小贴士: 收据丢失可在30天内到门店补开。建议在行李箱内单独存放收据
