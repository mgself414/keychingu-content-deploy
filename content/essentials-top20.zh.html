一句话介绍

外国人在韩国必买的，不是“韩国人购买的畅销榜 100”，而是“本国没有或贵 30%~50% 的商品”。中国 (CN) 游客以 K-Beauty (K-Beauty / K-뷰티)·红参·婴幼儿用品的客单价位居第一 (免税销售额占比 35%，药业新闻 2024)，日本 (JP) 游客偏爱可分装的可爱包装，欧美 (EN) 游客则购买 Reddit 验证过的功效产品和 Etsy 手工制作的故事。本指南将 TOP 20 压缩为 5 个类别 + 2 个额外推荐，并整理出哪里最便宜、免税退税政策以及各国优先购买清单。

推荐对象

  • 3~7 天短期停留的外国人 — 可利用免税即时退税 (₩30,000 (~$22 / ~167 RMB / ~3,300 JPY) 以上收据可扣除 8%)
  • 中国 (CN) 游客 — 化妆品·红参·婴幼儿用品客单价在 ₩300,000~₩700,000 区间
  • 日本 (JP) 游客 — 公司·学校 10~20 人分发用的“ばらまき (Baramaki / 散装)”礼物需求
  • 欧美 (EN) 西方游客 — 韩国发明品类 (气垫粉底·蜗牛精华·面膜) 在本国价格高出 1.3~2 倍
  • K-pop (K-pop / K-pop)·K-Drama (K-Drama / K-드라마) 入坑者 — 购买 Rom&nd (Rom&nd / 롬앤)、朝鲜王朝美人 (Beauty of Joseon / 뷰티 오브 조선)、COSRX (COSRX / 코스알엑스) 等社交媒体认证热门商品
  • 首次访韩者 + 再访者 — 愿望清单精选 + 新趋势热门商品补充
  • 礼品大批量购买者 — 为父母·同事·朋友准备 5~10 份的组合礼包

4. 免税即时退税 (VAT Refund) 使用方法

  • 对象: 外国短期停留者 (入境韩国后 6 个月以内·非居住者)，需持有护照
  • 即时退税 (市内): 单笔收据 ₩30,000 (~$22 / ~167 RMB / ~3,300 JPY)~₩299,999 → 结账时即时扣除 7~8%。结账前请告知“tax-free, please”并出示护照
  • 机场退税 (仁川 (Incheon / 인천) 4 层自助机): 单笔收据 ₩300,000 (~$222 / ~1,667 RMB / ~33,300 JPY)+ → 退税率 7~13% (略高于即时退税)。可选择信用卡自动退税 (回国后 2~4 周) 或韩元 (KRW)/美元 (USD)/日元 (JPY)/人民币 (CNY) 4 种现金即时退税
  • 可退税商店: 欧利芙洋 (Olive Young / 올리브영) / 大创 (Daiso / 다이소) / 百货商店 / 免税店 (Myeonsejeom / 면세jeom) / 韩国旅游名品店 (Hanguk Gwanwang Myeongpumjeom / 한국관광명품점) / Seoul My Soul (Seoul My Soul / 서울 마이 소울) / 仁寺洞 (Insadong / 인사동)·南大门 (Namdaemun / 남대문) 带有免税标志的商店
  • 不可退税: 普通便利店 (Convenience Store / 편의점)·市场路边摊·餐厅·咖啡馆
  • 小贴士: 收据丢失可在 30 天内向商店重新开具。建议单独保管在行李箱内。

7. 常见问题 (FAQ)

Q1. 哪里提供最好的礼品包装服务？

百货商店食品区·免税店 (Myeonsejeom / 면세jeom) (购买 ₩30,000+ 可免费提供韩纸 (Hanji / 한지) 包装) > 欧利芙洋 (Olive Young / 올리브영) 付费 ₩2,000~5,000 > Seoul My Soul Shop (Seoul My Soul Shop / 서울 마이 소울 샵) 自主设计免费包装。

Q2. 分开开收据会退更多税吗？

以单笔收据 ₩30,000 (~$22 / ~167 RMB / ~3,300 JPY) 以上为准，因此禁止分开开收据。累计低于 ₩30,000 则无法退税。退税时间：即时退税 = 结账时即时，机场信用卡退税 = 回国后 2~4 周。

Q3. 如果食品在本国入境时被没收怎么办？

申报后被没收不会罚款。未申报被查处会罚款 (美国 $300+，澳大利亚 AUD $2,664+，日本 ¥1,000,000)。泡菜 (Kimchi / 김치)·发酵食品建议真空包装 + 申报。

Q4. K-Beauty (K-Beauty / K-뷰티) 正品与假货如何区分？

欧利芙洋 (Olive Young / 올리브영)·大创 (Daiso / 다이소)·百货商店·正规免税店 (Myeonsejeom / 면세jeom) 100% 正品。南大门 (Namdaemun / 남대문)·东大门 (Dongdaemun / 동대문) 路边摊，明洞 (Myeongdong / 明洞) 街边摊 假货比例 30%~50% — 不建议在正规商店以外购买。
