🎯 왜 K-content 풀세트 통합 인덱스인가

K-content 풀세트 = 외국인 매니아 매트릭스 #1 글로벌 한국 콘텐츠 + 팬 + 체험 매트릭스. 외국인 관광객 페인포인트 = (a) "K-content = K-pop만" 잘못된 인식 — K-drama + 웹툰 + K-pop MV + 방탈출 + 굿즈 = 5축 매트릭스 #1 (b) 키친구 G축 K-content = 7편 풀세트 cluster 완결 (#378·#507·#565·#1085·#1089·#1101·#1102) (c) 외국인 매니아 = K-content 팬 → 한국 방문 매트릭스 #1 (Netflix 글로벌 200+ 국가·BTS 글로벌 ARMY·Disney+·Hulu K-drama 카테고리) (d) 서울·전국·외곽 cross + 1박2일·3박4일·1주일 풀세트 매트릭스 (e) K-content + 한복(#1081)·한옥스테이(#1076)·지방 미식(#1078)·체험 액티비티(#1083·#1084·#1085) cross.

본 가이드는 외국인 시각 K-content 7편 통합 인덱스 + 5축 매트릭스 + 동선 풀세트.

⚠ 외국인 자주 실수 3가지

1. "K-content = K-pop만": K-content = 5축 매트릭스 #1 = K-drama (글로벌 #1 Netflix) + K-pop MV (BTS 글로벌) + 웹툰 (Solo Leveling 글로벌) + K-방탈출 (K-drama 팬 cross) + 굿즈 (tax-free 매트릭스). 외국인 매니아 = 5축 cross 매트릭스 fit.

2. "K-drama 촬영지 = 서울만": K-drama 풀세트 = 서울 (#1101 12선) + 외곽 (#1102 9선) + 전국 (#378 12선) = 33+선 매트릭스. 외국인 매니아 = 1박2일·3박4일·1주일·5박6일 풀세트 매트릭스 fit.

3. "K-content 매니아 = 너무 비싸": K-content 매트릭스 = 가격 다양. 무료 (#1101 서울·#1102 지방 촬영지 입장 free) + entry-level (#1085 방탈출 25,000~40,000원) + 중간 (#1089 굿즈 K-stationery 1,000~30,000원) + 디자이너 (#1089 BTS 콘서트 굿즈 50,000~200,000원). 외국인 매니아 = 카테고리 매트릭스 선택.

⚙ FAQ 4개

1. 외국인 K-content 풀세트 동선 (1주일 5박6일): Day 1-2 서울 K-drama 풀세트 (#1101): 경복궁·북촌·청계·N서울·한강·이태원 + #1085 K-방탈출 (홍대·이태원) + #1089 굿즈 (명동). Day 3 강릉 도깨비 (#1102): KTX → 주문진·안목해변 BTS 정류장. Day 4 부산 K-drama (#1102): KTX → 광안대교·감천 문화마을·해운대 (#1078 미식 페어). Day 5 전주 한옥+사극 (#1102): KTX → 전주 한옥마을 + 옷소매 붉은 끝동. Day 6 제주 매트릭스 (#1102): 비행기 → 한라산·태양의 후예.

2. 외국인 K-content 카테고리 매니아 매트릭스: (a) K-drama 팬 = #378·#1101·#1102 풀세트 (33+선) + #1085 방탈출 cross (b) K-pop 팬 = #565 MV + #1089 굿즈 (BTS 하이브·NCT SM) (c) 웹툰 팬 = #507 deep dive + #1089 K-stationery cross (d) K-beauty 팬 = #1089 올리브영·아모레 (e) K-stationery 팬 = #1089 텐바이텐·아트박스.

3. K-content etiquette (외국인 시각): (a) 촬영지 photo = 다른 팬 매너 + 거주민 매너 매트릭스 (b) 굿즈 = tax-free 매트릭스 (30,000원+ 결제 = 환급) (c) 방탈출 = klook·trazy 영어 예약 (d) K-drama 정보 = Netflix·Disney+·Hulu (글로벌 200+ 국가) + 자막 영어 OK (e) 한복 + K-drama photogenic = 경복궁·북촌·전주 한옥 매니아 매트릭스.

4. 외국인 K-content 시즌 best: 봄꽃 (4월 한강·여의도·전주·강릉 벚꽃·N서울타워) = 외국인 매니아 #1. 여름 (6~8월 부산 해운대·강릉 안목해변·제주 한라산·서울 한강 야장 #1071). 가을 단풍 (10월 북촌·전주·강릉·양평 단풍) = K-drama photo best. 겨울 (12~2월 강릉 일출·N서울타워 야경·부산 회·제주 눈) = 매트릭스 매니아.
