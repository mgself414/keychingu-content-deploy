🏯 北村八景 (Bukchon 8 Views / 북촌 8경) — 代表拍照胜地

北村八景 (Bukchon 8 Views / 북촌 8경) 是首尔市官方指定的拍照胜地。嘉会洞 (Gahoe-dong / 가회동) 11号下坡小巷最为著名。

❓ 常见问题

Q1. 北村八景 (북촌 8경) 中最著名的是哪里?

嘉会洞11号全景 (가회동 11번지 / 第3景) — 从下坡处俯瞰瓦片屋顶。首尔旅游照第1位。平日上午9时前到达可避开人群拍摄。

Q2. 穿韩服 (Hanbok / 한복) 真的可以免费进入景福宫 (경복궁) 吗?

是的。包括租借韩服 (Hanbok / 한복) 在内均可享受四大宫殿免票。入口处工作人员现场检查。

Q3. 去哪里租韩服 (Hanbok / 한복)?

三清洞 (삼청동) 主街及安国站 (Anguk Station / 안국역) 周边有30家以上租借店。在Naver地图 (네이버 지도) 搜索"삼청동 한복 대여"并查看评价。

Q4. 北村 (Bukchon / 북촌) 最佳游览时间是?

平日上午9~11时最佳。周末下午1~3时最拥挤 — 拍照困难且影响居民生活。

Q5. 守门将换岗仪式 (수문장 교대식) 时间和地点?

景福宫 (경복궁) 兴礼门 (Heungnyemun / 흥례문) 广场 — 每日10:00及14:00举行(40分钟，周一及雨天停办)。免费观看。着韩服 (Hanbok / 한복) 可免费入场。

Q6. 北村 (Bukchon / 북촌) 和仁寺洞 (Insadong / 인사동) 可以一起游览吗?

可以。仁寺洞 (인사동) 距安国站 (Anguk Station / 안국역) 步行5分钟，三清洞 (삼청동) 步行10分钟。北村 (Bukchon / 북촌) 上午 + 仁寺洞 (Insadong / 인사동) 下午 = 外国游客钟路 (Jongno-gu / 종로구) 传统文化经典半日线路。

Q7. 下雨天去北村 (Bukchon / 북촌) 值得吗?

值得 — 游客较少，照片更好看。租借店提供雨伞或雨衣。雨打韩屋 (Hanok / 한옥) 瓦片的声音别有韵味。

Q8. 昌德宫 (창덕궁) 秘苑 (후원) 如何预约?

可在昌德宫 (창덕궁) 官网提前预约，或当日现场登记(名额有限，₩5,000额外费用)。限时导览入场 — 旺季建议提前预约。
