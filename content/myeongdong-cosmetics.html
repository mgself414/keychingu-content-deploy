외국인이 자주 하는 실수 5가지

1. 올리브영 1매장만 가는 것

명동에는 올리브영 5개 매장 — 명동중앙점·명동타운점·롯데영플라자점 등. 명동중앙점이 가장 큰 본점 + 외국인 매장 직원 보편. 다른 매장과 가격 차이 없음.

2. 즉시 환급 안 받는 것

₩30,000 이상 영수증 + 외국 여권 = 즉시 9~10% 차감. 매장 계산대에서 여권 보여주면 자동. 별도 절차 X. 공항 환급보다 빠르고 편리.

3. 외국인 한정 패키지를 모름

이니스프리·에뛰드·라네즈 명동본점에 외국인 한정 박스(영문 가이드 + 미니 사이즈 세트 + 선물 봉투). 일반 매장에 없음 — 명동 본점만의 한정 라인.

4. 마스크팩만 사가는 것

마스크팩은 가성비지만 한국 단독 라인 (롬앤·디어달리아·이니스프리 그린티 라인)이 외국인 진짜 가치. 마스크팩 100장보다 시그니처 스킨케어 1세트가 더 한국적.

5. 영수증 안 챙기는 것

즉시 환급 받았어도 영수증·바우처 보관 필수. 공항 출국 시 일부 검증 + 이중 환급 방지 + 분실·교환 시 필요.

FAQ

Q1. 영어 통하나요?

100%. 명동 매장은 한국에서 외국인 응대 가장 익숙.

Q2. 즉시 환급 vs 공항 환급 차이?

즉시 환급: 매장 계산대 자동 차감 / 공항 환급: 출국 카운터 + 카드 환급 (1~2주). 즉시가 빠르고 편리.

Q3. 멤버십 가입 외국인 가능?

올영·이니스프리·에뛰드 = 외국 휴대폰 + 이메일 OK. 추가 5~10% 할인.

Q4. 환급액 얼마?

9~10% (단일 영수증 ₩30,000+). 일부 매장 11% 가능.

Q5. 한국 한정 라인 어디?

이니스프리·라네즈·설화수 명동본점 = 한정 박스. 올리브영 = 시즌 한정.

Q6. 비행기 수하물?

액체류 100ml 제한 → 공항 면세점에서 픽업 또는 항공편 위탁 수하물 권장.
