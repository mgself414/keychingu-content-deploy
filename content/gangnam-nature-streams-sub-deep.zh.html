🎯 如何使用这份指南

📍 良才川 — 良才川近邻公园·Maeheon市民之林

良才川近邻公园(Yangjaecheon Geunrin Gongwon / 양재천 근린공원)，瑞草区(Yangjae-dong / 양재동)，☎ 瑞草区厅园林休闲科(Seochogucheong Jeongwon-yuga-gwa / 서초구청 정원여가과) 02-2155-7148，是位于良才市民之林站(Yangjae Simin-ui Sup-yeok / 양재시민의숲역)附近的都市自然公园。步道沿良才川绵延，步行道和自行车道分开，适合步行或骑自行车。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。

Maeheon市民之林(Maeheon Simin-ui Sup / 매헌시민의 숲)，瑞草区(Maeheon-ro 99 / 매헌로 99)，☎ 02-575-3895，是为迎接86亚运会和88奥运会，整治当时作为首尔门户的良才收费站(Yangjae Tolgeiteu / 양재 톨게이트)周边环境，于1986年11月建成的公园。据观光公社介绍，这是韩国国内首个引入森林概念的公园。种有松树、榉树、枫树、七叶树、红松等70种25万棵树木。

  • 北区:梅轩尹奉吉义士纪念馆(Maeheon Yun Bonggil Uisa Ginyeomgwan / 매헌윤봉길의사기념관)、地面喷泉、儿童游乐场。
  • 南区:游击白马部队忠魂塔(Yugyeok Baengma Budae Chunghontap / 유격 백마부대 충혼탑)、大韩航空858航班慰灵塔(Daehan Hanggong 858-pyeon Wiryeongtap / 대한항공 858편 위령탑)、三丰百货店坍塌遇难者慰灵塔(Sampung Baekhwajeom Bunggoe Huisaengja Wiryeongtap / 삼풍백화점 붕괴 희생자 위령탑)、牛眠山山体滑坡遇难者追悼碑(Umyeonsan Sansatae Huisaengja Chumobi / 우면산 산사태 희생자 추모비)。
  • 第3区:瑞草区(Seocho-gu / 서초구)打造成文化艺术公园的区域，有游戏广场(Nori Madang / 놀이마당)、户外演出场、企划展示馆、雕塑公园、相聚广场(Mannam-ui Gwangjang / 만남의 광장)。
  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 良才川春季庆典 — 良才川樱花灯节

第8届良才川樱花灯节(Je-8-hoe Yangjaecheon Beotkkot Deung Chukje / 제8회 양재천 벚꽃 등 축제)，良才川樱花路永东1桥~永东2桥区间(Yeongdong 1-gyo~Yeongdong 2-gyo / 영동1교~영동2교)，☎ 瑞草文化院(Seocho Munhwawon / 서초문화원) 02-2155-8607，是由瑞草文化院主办的春季文化艺术活动。配合樱花盛开的时节，呈现了融合自然景观与灯光演出的夜景。2026年于3月30日~4月19日举办，时间为13:00~20:00，费用免费。

  • 开幕式:4月3日(周五) 18:30，良才川水边舞台(Yangjaecheon Subyeon Mudae / 양재천 수변무대)，瑞草区(Yangjae-dong 261-23 / 양재동 261-23)。
  • 舞台节目:4月3日良才川风流音乐会，4月4日儿童音乐剧和歌剧盛典音乐会，4月5日樱花野餐音乐会和户外电影。
  • 附带节目:樱花 & AI智能体验区、美食区、4月4~5日瑞草文化足迹(Seocho Munhwa Balgeoreum / 서초문화발걸음)。

📍 炭川 — 首尔环城步道8路线 Jangji·炭川线路(松坡)·炭川淡水鱼湿地生态园(城南)

首尔环城步道8路线 Jangji·炭川线路(Seoul Dullegil 8-Koseu Jangji·Tancheon Koseu / 서울둘레길 8코스 장지·탄천코스)，松坡区(Bangi-dong / 방이동)，☎ 02-779-7902~4，是在全长156.5km、共21条路线环绕首尔一周的首尔环城步道(Seoul Dullegil / 서울둘레길)中，以“自然生态得到恢复的城市河川路”为主题的路线。可以一边观赏来到河川的生物和自然环境一边步行。靠近地铁奥林匹克公园站(Ollimpik Gongwon-yeok / 올림픽공원역)和水西站(Suseo-yeok / 수서역)。

  • 长度·时间:共8.6km，约2小时35分钟。
  • 开放时间:全天开放。休息日:全年无休。

炭川淡水鱼湿地生态园(Tancheon Minmulgogi Seupji Saengtaewon / 탄천민물고기습지생태원)，城南市(Sujeong-gu Taepyeong-dong / 수정구 태평동)，☎ 城南市厅环境政策科(Seongnamsicheong Hwangyeong Jeongchaek-gwa / 성남시청 환경정책과) 031-729-3153，是为恢复因城市化和炭川污染而濒临灭绝的淡水鱼等生物，于2009年建成的生态园。恢复了淡水鱼、蜻蜓·青蛙、水生昆虫等5处栖息地。设有踏石浅滩、淡水鱼体验场、观察栈道、生态探访路，随季节可以看到油菜花、波斯菊、大麦、本土小麦。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:不可以。

⚠ 行前须知 3 点

  1. 2026年良才川樱花灯节已经结束 — 于3月30日~4月19日举办了。
  2. 炭川淡水鱼湿地生态园不能停车 — 位于城南市寿井区。
  3. 首尔环城步道8路线约需2小时35分钟 — 全长8.6km，靠近奥林匹克公园站·水西站。

⚙ FAQ 2

Q. 在良才川可以骑自行车吗?

A. 按观光公社登记信息，良才川近邻公园(Yangjaecheon Geunrin Gongwon / 양재천 근린공원)的步道分为步行道和自行车道，适合骑自行车。全天开放。

Q. 有沿着炭川步行的路线吗?

A. 有，首尔环城步道8路线 Jangji·炭川线路(Seoul Dullegil 8-Koseu Jangji·Tancheon Koseu / 서울둘레길 8코스 장지·탄천코스)，位于松坡区。共8.6km，约2小时35分钟，全天开放。
