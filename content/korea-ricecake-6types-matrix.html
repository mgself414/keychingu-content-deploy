🎯 왜 한국 떡류 매트릭스인가

외국인 한국 떡 페인포인트 = "떡볶이만 알고 있다". 한국 떡 = 한국 명절·돌·결혼식·장치 정통 #1 + 한국 문화 1번지. 같은 "Korean rice cake"이라도 가래떡 (설날 떡국 시그니처)·송편 (추석 시그니처)·인절미 (잔치·콩고물 정통)·백설기 (돌·기념일 흰떡)·경단 (꼬치 형태·간식)·찰떡볶이 (MZ 트렌드 분식) 각자 다른 명절·재료·문화. 외국인은 (a) 떡볶이만 알고 다른 떡 미경험 (b) 송편 = 추석 시그니처 모름 (c) 떡국 = 설날 정통 모름 (d) 인절미 = 콩고물·잔치 음식 모름. 본 가이드는 6종 매트릭스 + 명절·잔치 정통 + 외국인 입문 우선순위.

🥢 6종 deep dive

🥢 가래떡 (Garaetteok) — 설날 #1

  • 시그니처: 설날 떡국 정통·"나이 한 살 더 먹기" 의미
  • 재료: 멥쌀 (찹쌀 X)·기다란 원기둥 모양
  • 떡국 (Tteokguk):
  • 재료: 가래떡 슬라이스 + 소고기·만두·계란·김·파
  • 의미: 설날 정통·새해 시작
  • 외국인 친화도: ★★★★★ (글로벌 명절 음식)
  • 추천 매장: 설날 시즌 (1~2월) 한식당·전통 떡집·마트
  • 가격: 가래떡 500g = 5,000~10,000원 / 떡국 1인 = 8,000~15,000원

🌙 송편 (Songpyeon) — 추석 #1

  • 시그니처: 추석 정통·반달 모양·풍요 의미
  • 재료: 쌀가루 + 깨·콩·밤·대추 소
  • 종류:
  • 깨송편 (Kkae songpyeon): 검은깨 (정통)
  • 콩송편 (Kong songpyeon): 콩 소
  • 밤송편 (Bam songpyeon): 밤 소
  • MZ 송편: 초콜릿·치즈·딸기 (MZ 트렌드)
  • 외국인 친화도: ★★★★★ (추석 vlog 1번지)
  • 추천 매장: 추석 시즌 (9~10월) 전통 떡집·마트
  • 가격: 송편 10개 = 5,000~10,000원

🟤 인절미 (Injeolmi) — 잔치 정통

  • 시그니처: 잔치·결혼식·복 의미·콩고물 정통
  • 재료: 찹쌀 + 콩고물 (콩가루·깨)
  • 외국인 친화도: ★★★★ (콩고물 인스타)
  • 추천 매장: 전통 떡집·시장·MZ 카페 (변형)
  • 가격: 인절미 500g = 5,000~10,000원
  • MZ 트렌드: 인절미 토스트·인절미 빙수·인절미 라떼

⚪ 백설기 (Baekseolgi) — 돌·기념일

  • 시그니처: 돌·기념일·복 의미·흰색 순수
  • 재료: 쌀가루 + 설탕 (단순)
  • 외국인 친화도: ★★★★ (돌 정통)
  • 추천 매장: 전통 떡집·돌잔치 주문
  • 가격: 백설기 1관 = 30,000~80,000원 (잔치용)

🍡 경단 (Gyeongdan) — 간식·인스타

  • 시그니처: 미니 떡·콩고물·인스타 매니아
  • 재료: 찹쌀 + 콩고물·깨·꿀
  • 종류:
  • 콩고물 경단 (정통)
  • 깨 경단
  • MZ 경단 (초콜릿·치즈)
  • 외국인 친화도: ★★★★ (인스타 매니아·간식)
  • 가격: 경단 10개 = 5,000~10,000원

🌶 찰떡볶이 (Charteok-bokki) — MZ 트렌드

  • 시그니처: 찰떡 + 트렌드 양념 (로제·크림·치즈)
  • 분식 cluster 연결: [#810 분식](#810) 떡볶이 cluster + 변형
  • 외국인 친화도: ★★★★★ (MZ vlog 1번지)
  • 가격: 5,000~10,000원
  • 추천 매장: 홍대·강남·성수 MZ 카페

⚠ 외국인 자주 실수 5가지

1. "한국 떡 = 떡볶이만": 6종 풀세트 + 명절·잔치·돌 정통.

2. "가래떡 = 일반 떡": 가래떡 = 설날 떡국 정통 + 기다란 원기둥 모양.

3. "송편 = 사계절": 송편 = 추석 한정 (9~10월). 다른 시기엔 적음.

4. "인절미 = 일반 떡": 인절미 = 콩고물 + 잔치·결혼식 정통.

5. "백설기 = 일반 흰떡": 백설기 = 돌·기념일 정통 (1관 30,000원~ 잔치용).

⚙ FAQ 8개

1. 외국인 입문 1순위: 가래떡 (설날 떡국) → 송편 (추석) → 인절미 (잔치) 단계.

2. 인스타·vlog: 추석 송편 만들기·인절미 토스트·MZ 찰떡볶이.

3. MZ 트렌드: 찰떡볶이·인절미 토스트·인절미 빙수·MZ 송편.

4. 명절 시기: 설날 (음력 1/1·2026 = 양력 2/17)·추석 (음력 8/15·2026 = 양력 9/25).

5. 돌잔치 떡: 백설기·수수경단·무지개떡 (1관 30,000~80,000원).

6. 알레르기: 콩·깨·견과류 (밤·잣)·꿀 사전 고지.

7. 결제·팁: 떡집 = 카드 OK / 시장 = 현금 권장 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X / 면세점 떡 = 환급 가능.

⚠ 의료·안전·식이 disclaimer

떡 = 일반 음식. 질식 위험 (특히 가래떡·인절미 = 단단·끈끈, 어린이·노인 잘 씹어서). 임신부 = 콩고물·견과류 적당량. 어린이 = 질식 주의 #1 (가래떡·인절미 작게 잘라서). 알레르기 (콩·깨·견과류·꿀) 사전 고지. 식중독·질식 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 동물 재료 X = OK (꿀 함유 확인).
  • 채식·비건: 6종 모두 채식 OK (꿀 함유 시 비건 X).
  • 글루텐 free: 6종 모두 쌀 100% = 글루텐 free OK.
