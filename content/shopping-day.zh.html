最优路线分析：按什么顺序走？

路线 A：明洞 (Myeongdong / 명동) → 江南 (Gangnam / 강남) → 圣水 (Seongsu / 성수) → 弘大 (Hongdae / 홍대) (推荐 ⭐⭐⭐⭐⭐)

优点：

  • 从早到晚体力管理良好
  • 购物强度可弹性调节 (明洞高强度 → 江南悠闲 → 圣水·弘大轻松)
  • 晚上可体验弘大夜生活
  • 全天节奏流畅自然

时间表：

```

12:00~13:00 - 移动 + 午餐 (明洞站 (Myeongdong Station / 명동역) → 江南站 (Gangnam Station / 강남역)，地铁约20分钟)

13:00~15:30 - 江南 (Gangnam / 강남) (2.5小时，悠闲购物)

16:00~18:00 - 圣水 (Seongsu / 성수) (2小时，快闪店/潮流购物)

18:00~18:30 - 移动 + 晚餐 (圣水 (Seongsu / 성수) → 弘大 (Hongdae / 홍대)，地铁约30分钟)

18:30~21:00 - 弘大 (Hongdae / 홍대) (2.5小时，夜间购物+文化体验)

```

路线 B：明洞 (Myeongdong / 명동) → 圣水 (Seongsu / 성수) → 江南 (Gangnam / 강남) → 弘大 (Hongdae / 홍대) (次选)

优点：

  • 可在下午前半段 (光线最好时)游览圣水 (Seongsu / 성수)
  • 可在江南 (Gangnam / 강남) 高峰时段 (下午 15:00~17:00)感受人气

缺点：

  • 移动距离增加
  • 傍晚在江南徘徊 (容易疲惫)

路线 C：弘大 (Hongdae / 홍대) → 圣水 (Seongsu / 성수) → 江南 (Gangnam / 강남) → 明洞 (Myeongdong / 명동) (傍晚型)

优点：

  • 可从下午才开始 (早上可以悠闲休息)
  • 明洞 (Myeongdong / 명동) 可购物至 23:00

缺点：

  • 弘大 (Hongdae / 홍대) 从下午到夜晚才开始热闹 (白天相对安静)
  • 体力消耗大

退税 & 免税完全指南

退税 (Tax Refund)

什么是退税？ 外国人在韩国购物后可申请退还增值税 (10%)

如何申请退税

1. 最低单笔消费：单店最低消费 ₩30,000 以上

2. 累计金额：同一天累计最低消费 ₩50,000 以上

3. 保留收据：务必保存所有购物收据

4. 前往退税点：机场或明洞 (Myeongdong / 명동) 退税处办理
