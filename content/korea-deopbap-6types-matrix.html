ISSUE 03 · #891 · 2026-06-09

🎯 왜 한국 덮밥 매트릭스인가

외국인 한국 덮밥 페인포인트 = "비빔밥만 알고 덮밥 모름". 한국 덮밥 (Deop-bap) = 점심 MZ #1 + 가정식·체인 가성비. 같은 "Korean rice bowl"이라도 제육덮밥 (가성비 #1·매콤)·고등어자반덮밥 (한식 정통)·명란덮밥 (MZ 트렌드 #1)·임연수덮밥 (정통 fish)·연어덮밥 (글로벌 fusion·MZ)·소고기덮밥 (한정식 cross). 외국인은 (a) 비빔밥 vs 덮밥 차이 모름 (b) 제육 = 가성비 매니아 모름 (c) 명란 = MZ 인스타 #1 모름 (d) 한솥·본도시락 가성비 모름. 본 가이드는 6종 매트릭스 + 점심 cluster.

🍚 6종 deep dive

🐷 제육덮밥 (Jeyuk-deopbap) — 가성비 #1

  • 시그니처: 가성비 #1·매콤·MZ 도시락
  • 재료: 돼지고기 + 고추장 + 양파·당근 + 밥
  • 추천 매장: 한솥·본도시락 ([#854](#854))·MZ 한식당·가정식
  • 가격: 6,000~12,000원/1인
  • 외국인 친화도: ★★★★★ (#1 가성비)

🐟 고등어자반덮밥 (Godeungeo-jaban) — 정통

  • 시그니처: 한식 정통·짠맛·노포
  • 재료: 고등어자반 (소금 절임) + 무국·반찬 + 밥
  • 추천 매장: 노포·가정식
  • 가격: 8,000~15,000원/1인
  • 외국인 친화도: ★★★★ (정통)

🥚 명란덮밥 (Myeongran-deopbap) — MZ #1

  • 시그니처: MZ 인스타 #1·트렌드·짠맛
  • 재료: 명란 (pollock roe) + 계란·김 + 밥
  • 추천 매장: MZ 한식당·홍대·강남·이태원
  • 가격: 12,000~22,000원/1인
  • 외국인 친화도: ★★★★★ (MZ #1)

🐠 임연수덮밥 (Imyeonsu) — 정통

  • 시그니처: 정통·체인·짠맛
  • 재료: 임연수 (Atka mackerel) + 무국·반찬 + 밥
  • 추천 매장: 한솥·본도시락·체인 한식당
  • 가격: 8,000~15,000원/1인
  • 외국인 친화도: ★★★★ (정통)

🟠 연어덮밥 (Yeon-eo-deopbap) — 글로벌

  • 시그니처: 글로벌 fusion·MZ·일본식 영향
  • 재료: 연어 (salmon·생 또는 익힘) + 와사비·간장 + 밥
  • 추천 매장: MZ 한식당·연어 무한리필 ([#864](#864) cross)
  • 가격: 12,000~25,000원/1인
  • 외국인 친화도: ★★★★ (글로벌)

🥩 소고기덮밥 (Sogogi-deopbap) — 럭셔리

  • 시그니처: 한정식 cross·럭셔리·소고기
  • 재료: 소고기 (불고기·갈비) + 양파·당근·간장 양념 + 밥
  • 추천 매장: 한정식·MZ 한식당·소고기 전문점
  • 가격: 15,000~35,000원/1인
  • 외국인 친화도: ★★★★ (럭셔리)

⚠ 외국인 자주 실수 5가지

1. "비빔밥 = 덮밥": 비빔밥 = 나물 5색 + 비비기 / 덮밥 = 밥 위에 메인 + 안 비빔.

2. "제육 = 일반": 제육 = 가성비 #1·MZ 도시락.

3. "명란 = 단가": 명란 = MZ 인스타 #1·12,000~22,000원.

4. "고등어자반 = 짠맛만": 고등어자반 = 한식 정통 + 무국 페어.

5. "덮밥 = 패스트푸드": 덮밥 = 한솥·본도시락 정통 가성비 (한식 cluster).

⚙ FAQ 8개

1. 외국인 입문 1순위: 제육 (가성비) + 명란 (MZ).

2. 인스타·vlog: 명란 (#1).

3. MZ 트렌드: 명란 (#1)·연어.

4. 가성비: 제육 (#1)·고등어·임연수.

5. 럭셔리: 소고기.

6. 알레르기: 어란·해산물 사전 고지.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

덮밥 = 일반 음식. 임신부·어린이 = OK (명란 = 짠맛 주의). 알레르기 (어란·해산물·계란·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback: 할랄·코셔 = 어류·해산물 OK·돼지 X·연어 OK / 채식·비건 = 비채식 / 글루텐 free = Tamari 대체.
