韩国酒指南 — 传统酒画廊与酿酒厂参观12处(春风酿酒厂 (Chunpung Yangjojang / 춘풍양조장)、金井山城马格利 (Geumjeongsanseong Makgeolli / 금정산성 막걸리)、名人安东烧酒 (Myeongin Andong Soju / 명인안동소주)、喜鹊酿酒厂 (Magpie Brewery / 맥파이 브루어리))与全州马格利巷 (2026年10月官方数据)

副标题：传统酒画廊 (Jeontongju Gallery / 전통주갤러리) 钟路区北村路 (Bukchon-ro / 북촌로) 18号，10:00~19:00，外国人项目提供英、日、中文(VisitKorea、传统酒网站 (The Sool.com / 더술닷컴))· 首尔春风酿酒厂 (Chunpung Yangjojang / 춘풍양조장) 参观 11:00、15:00、17:00，年满19周岁以上(VisitKorea)· 安东烧酒 (Andong Soju / 안동소주) 45度，庆尚北道非物质文化遗产(VisitKorea)· 从年满19岁那年的1月1日起才可饮酒(便捷生活法令 (Chatgi Swiun Saenghwal Beopnyeong / 찾기쉬운 생활법령))— 截至2026-10-21

🎯 如何使用本指南

推开酿酒厂的门，最先扑鼻而来的是蒸米的热气和酒曲 (Nuruk / 누룩) 的气味。本指南把韩国酒 (Sool / 술) 归在酿造和挑选的地方，而不是去喝酒的地方。分四类：在首尔品尝和挑选、马格利 (Makgeolli / 막걸리，米酿浊酒) 酿酒厂和酒巷、蒸馏酒与名酒、精酿啤酒厂。地点、时间、年龄限制只采用VisitKorea、传统酒网站 (The Sool.com / 더술닷컴)、便捷生活法令 (Chatgi Swiun Saenghwal Beopnyeong / 찾기쉬운 생활법령) 上的数据。体验费用哪里都没有公布。

这是写给买酒前想先看看酒是怎么酿的人，以及想在旅行路线里加入一家酿酒厂的人。在酒馆点单、斟酒的礼仪，请看 #829 韩国酒点单·搭配流程。

旧版指南有两处错误。传统酒画廊 (Jeontongju Gallery / 전통주갤러리) 不在"仁寺洞 (Insa-dong / 인사동)"，官方地址是钟路区北村路 (Bukchon-ro / 북촌로) 18号(传统酒网站 (The Sool.com / 더술닷컴))；安东烧酒 (Andong Soju / 안동소주) 也不是"联合国教科文组织传统酒"，VisitKorea写的是庆尚北道非物质文化遗产第12号。"麴醇堂 (Kooksoondang / 국순당) 家酿酒体验(首尔)"、"马格利五大酿酒厂"、烧酒价格没有官方依据，已删除。

🍶 在首尔品尝和挑选

  • 传统酒画廊 (Jeontongju Gallery / 전통주갤러리) — 首尔钟路区北村路 (Bukchon-ro / 북촌로) 18。由农林畜产食品部和韩国农水产食品流通公社设立的传统酒空间，展示并出售食品名人 (Myeongin / 명인) 的酒和韩国酒品评会获奖作品，每月选出"本月试饮酒 (Idal-ui Siumju / 이달의 시음주)"并举办试饮活动。外国人项目提供英语、日语、中文(传统酒网站 (The Sool.com / 더술닷컴))。10:00~19:00，02-555-2283，预约通过Naver预约链接(VisitKorea)。休馆日、费用未公布
  • 春风酿酒厂 (Chunpung Yangjojang / 춘풍양조장) — 首尔中区茶山路 (Dasan-ro / 다산로) 101-3(新堂洞 (Sindang-dong / 신당동))。酿造马格利 (Makgeolli / 막걸리) 的酿酒厂，面向海外游客提供参观和试饮。营业 11:00~19:00，参观 11:00 / 15:00 / 17:00，每周日、周一休息，年满19周岁以上，1899-8876，不可停车(VisitKorea)。费用未公布
  • 首尔马格利入门见 #136 首尔马格利·传统酒入门

🌾 马格利酿酒厂和酒巷

  • 金井山城马格利 (Geumjeongsanseong Makgeolli / 금정산성 막걸리) — 釜山金井区山城路 (Sanseong-ro / 산성로) 453，海拔400m的金井山山脚。由韩国马格利领域第一位食品名人 (Myeongin / 명인) 酿造，VisitKorea写"全国马格利中唯一被指定为乡土民俗酒"。08:30~18:00，全年无休，051-517-0202。5人以上团体预约可参观并体验踩酒曲、酿马格利、过滤(VisitKorea)。费用未公布
  • 金风酿酒厂 (Geumpung Yangjojang / 금풍양조장) — 仁川江华郡三郎城路 (Samnangseong-gil / 삼랑성길) 8。2021年成为江华岛首家获得地区特产酒(浊酒 (Takju / 탁주)、药酒 (Yakju / 약주))牌照的酿酒厂。周一至周四 10:30~17:30，周五至周日 10:30~18:00，全年无休，访问前必须联系，0507-1374-1931，可刷卡(VisitKorea)。费用未公布
  • 全州传统酒博物馆 (Jeonju Jeontongsul Bangmulgwan / 전주 전통술박물관) — 全北全州市完山区韩纸路 (Hanji-gil / 한지길) 74，韩屋村内。公立2类博物馆，免费参观。周二至周日 10:00~18:00(6~10月到20:00)，每周一、1月1日、春节 (Seollal / 설)、中秋 (Chuseok / 추석) 当天闭馆，063-287-6305。寄售当地传统酒(VisitKorea)
  • 三川洞马格利巷 (Samcheon-dong Makgeolli Golmok / 삼천동 막걸리골목)(全州) — 全州市完山区三川洞1街 (Samcheon-dong 1-ga / 삼천동1가)，居马山路 (Geomasan-ro / 거마산로) 200多米。点一壶马格利，就会附送烤鱼、煎饼 (Jeon / 전)、炖锅、三合 (Samhap / 삼합) 等20多种下酒菜。全州未来遗产(VisitKorea)。有几十家店，营业时间各店不同。全州路线见 #384 全州旅行地图

🔥 蒸馏酒与名酒

  • 名人安东烧酒 (Myeongin Andong Soju / 명인안동소주) — 庆北安东市丰山邑产业园区6街 (Saneopdanji 6-gil / 산업단지6길) 6。朴载书 (Bak Jae-seo / 박재서) 名人(传统食品名人第6号)。安东烧酒是45度的纯谷物蒸馏酒(VisitKorea)。试饮、展馆、制作酒曲、酿传统酒体验，09:00~18:00，必须提前预约，每周六、周日休息，054-856-6903(VisitKorea)。费用未公布
  • 安东烧酒传统饮食博物馆 (Andong Soju Jeontong Eumsik Bangmulgwan / 안동소주전통음식박물관) — 庆北安东市江南路 (Gangnam-ro / 강남로) 71-1。1995年设立，免费参观，09:00~17:00，全年无休，054-858-4541。有演示场、试饮场和销售场(VisitKorea)。VisitKorea写安东烧酒为"庆尚北道非物质文化遗产第12号、传统食品名人第20号"
  • 韩山小曲酒酿酒厂 (Hansan Sogokju Yangjojang / 한산소곡주 양조장) — 忠南舒川郡韩山面忠节路 (Chungjeol-ro / 충절로) 1118。禹喜烈 (U Hui-yeol / 우희열) 名人的酿酒厂，试饮常年可以，酿造和演示提前公告。营业时间写"请电话咨询"，041-951-0290，使用韩山苎麻馆 (Hansan Mosigwan / 한산모시관) 停车场(VisitKorea)

🥗 饮食须知

  • 价位：本指南的体验、参观费用没有官方公布的数据。确认免费的只有全州传统酒博物馆和安东烧酒传统饮食博物馆的参观(VisitKorea)
  • 素食：问题不在酒本身，而在下酒菜。三川洞马格利巷 (Samcheon-dong Makgeolli Golmok / 삼천동 막걸리골목) 默认摆上烤鱼、三合等下酒菜(VisitKorea)— 请另外要求只上蔬菜类下酒菜
  • 清真·无酒精：所有地点都经营酒类。济州泉酒 (Jeju Saemju / 제주샘주) 的发酵米饮 (Swindari / 쉰다리) 体验是否含酒精未公布 — 预约时询问。首尔KMF认证的韩餐厅有伊德 (Eid / 이드) — 龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00(VisitSeoul)
  • 过敏：原料(大米、小麦酒曲、麦芽、水果)因酒而异，请查看瓶身标签
  • 出示给店员看的卡片见 #1300 饮食需求说明手册

🧰 韩国酒实用信息 — 独自饮酒、预约、付款、点单、交通

  • 年龄：韩国法律中的"青少年"是指未满19岁的人，但已迎来年满19岁那年1月1日的人除外。向青少年卖酒，处2年以下有期徒刑或2000万韩元以下罚款，销售者必须核实年龄和是否本人(便捷生活法令 (Chatgi Swiun Saenghwal Beopnyeong / 찾기쉬운 생활법령))。请带好护照
  • 独自饮酒：金井山城体验(5人以上)和韩国精酿酿酒厂 (Korea Craft Brewery / 코리아 크래프트 브류어리)(15人以上)有团体条件(VisitKorea)。适合一个人喝酒的店见 #348 首尔独食餐厅地图
  • 预约：名人安东烧酒 (Myeongin Andong Soju / 명인안동소주) 必须提前预约，金风酿酒厂 (Geumpung Yangjojang / 금풍양조장) 访问前必须联系(VisitKorea)。传统酒画廊 (Jeontongju Gallery / 전통주갤러리) 使用Naver预约
  • 付款：金风酿酒厂 (Geumpung Yangjojang / 금풍양조장) 可刷卡(VisitKorea)。其余没有标注 — #527 韩国支付系统
  • 点单：在酒馆点单和斟酒的方法见 #829 韩国酒点单·搭配流程，语言不通时见 #1339 点餐礼仪
  • 交通：酿酒厂大多在市郊 — 喝酒后不要开车。安东、舒川、阴城见 #1297 高速·城际巴士手册，交通卡见 #1298 三种交通卡怎么选

⚠ 常见的4个误区

1. "传统酒画廊在仁寺洞" — 官方地址是钟路区北村路 18号(传统酒网站 (The Sool.com / 더술닷컴)、VisitKorea)

2. "安东烧酒是联合国教科文组织遗产" — VisitKorea写的是庆尚北道非物质文化遗产第12号。没有找到教科文组织列入的依据

3. "按韩国虚岁20岁就能喝 / 要等到满19周岁生日才能喝" — 标准是年满19岁那年的1月1日(便捷生活法令 (Chatgi Swiun Saenghwal Beopnyeong / 찾기쉬운 생활법령))

4. "酿酒厂什么时候都能去" — 春风酿酒厂 (Chunpung Yangjojang / 춘풍양조장) 周日、周一休息，喜鹊酿酒厂 (Magpie Brewery / 맥파이 브루어리) 和济州啤酒 (Jeju Maekju / 제주맥주) 周一、周二休息，名人安东烧酒 (Myeongin Andong Soju / 명인안동소주) 周末休息(VisitKorea)
