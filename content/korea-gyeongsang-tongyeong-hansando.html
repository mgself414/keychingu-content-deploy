🎯 왜 통영 가이드인가

통영 (Tongyeong) = 한국 #1 해상국립공원·한산도 (이순신 1597년 한산도대첩)·동피랑·통영 시그너 음식. 외국인 페인포인트 = (a) "통영 = 안 알려짐" 잘못된 인식 (b) 한산도 = 이순신 (1545-1598) 1597년 한산도대첩 매트릭스 #1 (c) 한국 #1 해상국립공원 (1968년 지정) (d) 동피랑 = 벽화 마을 + MZ 인스타 (감천 #1024 다음) (e) 통영 우동·통영 충무김밥 시그너.

본 가이드는 5축 12 시그니처 + 한산도 + 해상국립공원 + 동피랑.

★ 한눈에 5축 12 시그니처

🏛 5축 deep dive

① 한산도 (이순신 1597 한산도대첩)

  • 시그니처: 1597년 한산도대첩 (이순신 한국 #1 매니아 매트릭스 #1)·박물관·충무공 동상
  • 외국인 친화도: ★★★★★ (영문·문화 + 역사 매니아)
  • 시간: 09:00~18:00·4,000원 (배편 별도 30,000원)

② 해상국립공원 (한국 #1·1968~)

  • 시그니처: 1968년 지정·한국 #1 해상국립공원·400+ 섬·매물도·홍도·욕지도 cluster
  • 외국인 친화도: ★★★★ (영문·매니아)
  • 보트 투어: 30,000~80,000원/인 (반나절~1일)

③ 동피랑 (벽화 마을)

  • 시그니처: 벽화 + 마을·MZ + 인스타 매니아·감천 (#1024) 다음 매트릭스
  • 외국인 친화도: ★★★★★ (영문·MZ + 인스타)
  • 시간: 24h·무료

④ 통영 음식 (충무김밥·우동·시락국)

  • 시그니처: 충무김밥 한국 #1 시그너·통영 우동·꿀빵·시락국 (생선국)
  • 외국인 친화도: ★★★★ (안 매콤·시그너)
  • 가격: 충무김밥 = 8,000~15,000원/인

⑤ 1박 (펜션·호텔)

  • 시그니처: 통영 1박 매니아·해상국립공원 + 한산도 풀세트
  • 가격: 1박 = 80,000~300,000원

⚠ 외국인 자주 실수 5가지

1. "통영 = 안 알려짐": 한국 #1 해상국립공원·한산도·동피랑·시그너 음식 매트릭스.

2. "한산도 = 작은 섬": 이순신 1597년 한산도대첩 매트릭스 #1.

3. "해상국립공원 = 일반 공원": 한국 #1·1968년·400+ 섬.

4. "동피랑 = 감천 복제": 통영 매트릭스·감천 (#1024) 다음 한국 #2 벽화마을.

5. "충무김밥 = 일반 김밥": 통영 시그너 한국 #1 매트릭스·이순신 충무공 명명.

⚙ FAQ 6개

1. 외국인 입문 1순위: 한산도 + 동피랑 + 충무김밥 = 1일.

2. 한산도 배편: 통영항 → 한산도 20-30분·왕복 30,000원/인.

3. 해상국립공원 보트: 반나절 = 30,000~50,000원·1일 = 50,000~80,000원/인.

4. 동피랑 vs 감천: 통영 #1054 vs 부산 #1024·비교 매트릭스.

5. 알레르기: 회·해산물 사전 고지.

6. 추천 페르소나: 가족·시니어 = 한산도 + 충무김밥 / MZ·인스타 = 동피랑 + 카페 / 매니아 = 해상국립공원 보트 + 1박.
