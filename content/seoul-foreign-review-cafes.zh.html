首尔咖啡馆10家 — 只选外国评论率先留下的地方

副标题: 弘大·望远的烘焙咖啡馆和汉江码头咖啡馆，圣水的面包·冰淇淋·刨冰咖啡馆，解放村的舒芙蕾松饼和手冲咖啡馆，汉南洞的露台咖啡馆，再到三角地的意式浓缩咖啡吧。只选Naver地图上外语评论率先留下的咖啡馆，共10家，分成3个区域。首尔可以坐地铁在区域之间移动，所以动线设计成三条半日路线。占座·马克杯·归还台这类咖啡馆内的规则见#1378

🎯 为什么以"三语评论"为标准

选择标准只有一个。只选Naver地图上同时留有英语·日语·中文评论的咖啡馆。不看韩国人的人气排行，而是选外国人已经找去并用三种语言留下痕迹的地方。我们认为这样的地方对下一位外国游客也更不陌生。10家全部都有三种语言的评论。评论数以2026-11为准，每家店都标出来。这一篇10家里，没有出现在KeyChinGu其他篇的店。

① 弘大·麻浦 — 3家

西桥洞 (Seogyo-dong / 서교동)1家，望远洞 (Mangwon-dong / 망원동)2家。咖啡馆 (Analog Garden / 아날로그가든)周末08:00开门，按登记时间是10家里最早的。咖啡馆 (Newcase / 뉴케이스)开到22:00。咖啡馆 (KOMAME / 코마메)周一休息。

  • 咖啡馆 (Analog Garden / 아날로그가든) — 西桥洞 (Seogyo-dong / 서교동)的烘焙·早午餐咖啡馆。Kakao地图标签上有烘焙专门·澳式早午餐。登记菜单是双份浓缩·长黑·Flat white·拿铁·卡布奇诺5种，价格登记全部超过2年，所以现在的价格要以Kakao地图当日确认为准。没有登记餐食菜单，到店里看。时间是周一至周五09:00~18:00，周六·周日08:00~18:00，没有登记休息日。地址是麻浦区 (Donggyo-ro 145 / 동교로 145)，附近的站是合井站 (Hapjeong / 합정역)·弘大入口站 (Hongik Univ. / 홍대입구역)(2号线)和上水站 (Sangsu / 상수역)(6号线)。没有停车场。外语评论15条(5·5·5)。饮食提示: 拿铁·卡布奇诺·Flat white含牛奶，咖啡类含咖啡因。Kakao地图上有"纯素食物"标签，但没有登记对应的菜单，所以点单时询问是哪个菜单。
  • 咖啡馆 (Newcase / 뉴케이스) — 位于汉江巴士 (Hangang Bus / 한강버스)望远码头 (Mangwon / 망원선착장)大楼3层的江景咖啡馆。Kakao地图上的店名是咖啡馆 (Newcase Mangwon Main / 뉴케이스 망원본점)，博客评价里提到桌游和聆听图书馆。登记价是美式咖啡₩5,000，拿铁咖啡₩5,500，Newcase拿铁₩6,000，香草拿铁₩6,500，抹茶拿铁₩7,500，牛油果香蕉拿铁₩8,500，柚子黑咖₩8,500，芝士蛋糕₩6,500，Newcase芝士蛋糕₩8,500，Peace & Cheese₩12,000。每天10:00~22:00营业。地址是麻浦区 (Mapo-naru-gil 420 / 마포나루길 420)，附近的站是望远站 (Mangwon / 망원역)(6号线)·合井站 (Hapjeong / 합정역)(6号线)。离站较远，所以先用导航查路线。有可携带宠物标签。没有停车场，附近的望远汉江公园公共停车场收费。外语评论12条(4·4·4)。饮食提示: 拿铁类含牛奶。牛油果香蕉拿铁如其名含牛油果和香蕉。两种芝士蛋糕是含奶酪(乳制品)的甜点。Peace & Cheese在Kakao地图摘要里是含开心果和奶酪的蛋糕，有坚果过敏的话要避开。抹茶和咖啡含咖啡因。
  • 咖啡馆 (KOMAME / 코마메) — 望远洞 (Mangwon-dong / 망원동)的三明治·咖啡店。Kakao地图上的店名是咖啡馆 (Komame / 코마메)。登记了火腿黄油法棍·鹰嘴豆泥三明治·吐司·鲜虾奶油可乐饼·美式咖啡·拿铁咖啡·低因咖啡，但一个价格都没有登记，所以要以Kakao地图当日确认为准。周一休息，周二至周四·周日09:30~18:00，周五·周六09:30~19:00。地址是麻浦区 (Worldcup-ro 23-gil 20 / 월드컵로23길 20)，附近的站是望远站 (Mangwon / 망원역)·麻浦区厅站 (Mapo-gu Office / 마포구청역)(6号线)。不能停车。外语评论8条中英语有5条。饮食提示: 火腿黄油法棍是在法棍里放猪肉火腿(Jambon)和墨西哥辣椒蛋黄酱的三明治(Kakao地图介绍)。蛋黄酱含鸡蛋，因为是墨西哥辣椒所以可能会辣。Beurre是法语的黄油。鹰嘴豆泥是在鹰嘴豆里通常拌入芝麻酱(Tahini)做成的。鲜虾奶油可乐饼含虾和奶油，面衣通常用面粉·鸡蛋。三明治·吐司是面包，含面粉。咖啡另有低因的。

② 圣水 — 3家

集中在圣水站 (Seongsu / 성수역)·纛岛站 (Ttukseom / 뚝섬역)·首尔林站 (Seoul Forest / 서울숲역)一带。面包店、冰淇淋店、刨冰店各一家。刨冰咖啡馆 (Gidaelbing / 기댈빙)开到23:00，按登记时间是这个区域三家里最晚打烊的。

  • 面包咖啡馆 (CAT&F / 캣앤에프) — 位于圣水的面包咖啡馆。Kakao地图上的店名是面包咖啡馆 (Bakery Cafe CAT&F / 베이커리카페 CAT&F)。登记菜单只有Bungnyangi面包 (붕냥이빵)一个，价格登记超过2年，所以现在的价格要以Kakao地图当日确认为准。其他面包和饮品到店里看。营业时间只登记了公休日09:00~22:00，各星期几的时间是空白。平日·周末去的时候，用Kakao地图当日确认时间。地址是城东区 (Yeonmujang-gil 29-9 / 연무장길 29-9)，附近的站是圣水站 (Seongsu / 성수역)·纛岛站 (Ttukseom / 뚝섬역)(2号线)。没有停车场。外语评论15条(5·5·5)。饮食提示: Bungnyangi面包按店主说明是放糯玉米·整颗红豆沙·核桃烤制的。有核桃(坚果)过敏的话要避开。其他面包和饮品的食材点单时询问。
  • 冰淇淋店 (Beurre Beurre Seongsu / 뵈르뵈르 성수) — 圣水的冰淇淋·拿铁店。Kakao地图上的行业是冰淇淋。登记了美式咖啡·拿铁·草莓拿铁·抹茶拿铁·巧克力拿铁·奶昔，但没有登记价格，所以要以Kakao地图当日确认为准。每天11:00~22:00营业。地址是城东区 (Seongsu-iro 7ga-gil 22 / 성수이로7가길 22)，附近的站是圣水站 (Seongsu / 성수역)·纛岛站 (Ttukseom / 뚝섬역)(2号线)。同名的分店在首尔有好几处(梨泰院·大学路·建大等)，所以用地址找。外语评论13条(5·4·4)。饮食提示: 拿铁类和奶昔含牛奶。草莓拿铁的菜名里有草莓，巧克力拿铁的菜名里有巧克力。抹茶和咖啡含咖啡因。
  • 刨冰咖啡馆 (Gidaelbing / 기댈빙) — 首尔林 (Seoul Forest / 서울숲)一侧巷子里的刨冰甜点咖啡馆。使用1~2层。登记菜单只有Kkamang-sogeumi (까망소금이)₩2,900一个，也没有说明是什么菜单。不要当作刨冰价格来看，刨冰·饮品价格要以Kakao地图当日确认为准。每天11:00~23:00营业。地址是城东区 (Seoul Forest 2-gil 24-8 / 서울숲2길 24-8)(以Kakao地图为准)，附近的站是首尔林站 (Seoul Forest / 서울숲역)(水仁盆唐线)·纛岛站 (Ttukseom / 뚝섬역)(2号线)。外语评论11条(5·3·3)。饮食提示: 登记菜单只有一个，从菜名读不出任何提示。刨冰里放什么，点单时询问。

③ 龙山 (解放村·汉南洞·三角地) — 4家

解放村 (Haebangchon / 해방촌)2家，汉南洞 (Hannam-dong / 한남동)1家，还有三角地站 (Samgakji / 삼각지역)一带的龙里团路 (Yongridan-gil / 용리단길)1家。Kakao地图标签上标为龙里团路。咖啡馆 (MOTHER Offline / 마더오프라인)开到09:00~24:00，按登记时间是10家里开得最晚的。解放村的两家12:00以后才开门。

  • 甜点咖啡馆 (Tortus / 토터스) — 解放村新兴路的麻薯舒芙蕾松饼甜点咖啡馆。使用1~2层。登记价是草莓麻薯舒芙蕾₩18,000，紫薯麻薯舒芙蕾₩16,000，迪拜巧克力麻薯舒芙蕾₩21,000，抹茶提拉米苏麻薯舒芙蕾松饼₩15,000，Puffle (푸플레)₩11,000，卡仕达布丁₩6,000，美式咖啡₩5,000，拿铁₩5,500，Flat white₩5,500。过滤咖啡价格没有登记。每天12:00~21:20营业。最后点单请在Kakao地图确认。地址是龙山区 (Sinheung-ro 81 / 신흥로 81)，附近的站是绿莎坪站 (Noksapyeong / 녹사평역)(6号线)·淑大入口站 (Sookmyung Women's Univ. / 숙대입구역)(4号线)。离站较远，所以先用地图应用看路线。Kakao地图摘要里有周末停车困难的内容和禁止儿童入内的标示。外语评论15条(5·5·5)。饮食提示: 舒芙蕾松饼含鸡蛋·乳制品，可能是面粉面糊。布丁是含鸡蛋·乳制品的甜点。麻薯用糯米做，但可能含面粉，担心麸质的话要询问。迪拜巧克力通常用开心果(坚果)·卡达伊夫面(小麦)·芝麻酱(芝麻)。Puffle是什么菜单，点单时询问。拿铁·Flat white含牛奶。抹茶和咖啡含咖啡因。
  • 咖啡馆 (Cafe Tajagi / 카페 타자기) — 解放村新兴路大楼2层的手冲咖啡馆。Kakao地图标签上有复古·露台。登记价是Chokotajagi (초코타자기)₩7,000，Chokojeongbok (초코정복)₩7,000，美式咖啡₩5,500，咖啡拿铁₩6,000，香蕉面包₩7,000。每个星期几的时间不同。周一·周二·周五至周日是12:00~22:00，周三是13:00~21:00，周四是12:00~21:00。地址是龙山区 (Sinheung-ro 97-5 / 신흥로 97-5)，附近的站是绿莎坪站 (Noksapyeong / 녹사평역)(6号线)·淑大入口站 (Sookmyung Women's Univ. / 숙대입구역)(4号线)。离站较远，所以先用地图应用看路线。不能停车。外语评论12条(4·4·4)。饮食提示: 香蕉面包在Kakao地图摘要里出现了黄油·肉桂，是面包，含面粉。Chokotajagi是摩卡底的冰咖啡，含咖啡因，Chokojeongbok是可可饮品。咖啡拿铁含牛奶，咖啡含咖啡因。
  • 咖啡馆 (MOTHER Offline / 마더오프라인) — 汉南洞的露台咖啡馆。Kakao地图上的店名是咖啡馆 (Mother Offline / 마더오프라인)。登记价是美式咖啡₩7,000，咖啡拿铁₩7,500，Flat white₩7,500，抹茶拿铁₩9,000，柠檬磅蛋糕₩7,000，布朗尼&香草冰淇淋₩9,000，巴斯克芝士蛋糕₩10,000，火腿奶酪三明治₩10,000，酸奶燕麦碗₩5,000。美式咖啡在登记了价格的五家里₩7,000是最贵的。每天09:00~24:00营业。地址是龙山区 (Itaewon-ro 55na-gil 6 / 이태원로55나길 6)，附近的站是汉江镇站 (Hangangjin / 한강진역)·梨泰院站 (Itaewon / 이태원역)(6号线)。有代客泊车·收费停车，有可携带宠物标签。外语评论11条(5·3·3)。饮食提示: 拿铁·Flat white含牛奶。布朗尼&香草冰淇淋里的冰淇淋是乳制品，布朗尼通常含鸡蛋·面粉。巴斯克芝士蛋糕通常含奶油奶酪·鸡蛋。火腿奶酪三明治含猪肉火腿和奶酪，以及面粉面包。酸奶燕麦碗的酸奶是乳制品，燕麦里是否放坚果要询问。柠檬磅蛋糕是通常含面粉·鸡蛋的蛋糕。抹茶和咖啡含咖啡因。Kakao地图上还登记了葡萄酒·鸡尾酒·啤酒等酒类菜单，所以晚上会变成卖酒的地方。
  • 咖啡馆 (Fjord / 피요르드) — 三角地站 (Samgakji / 삼각지역)一带龙里团路 (Yongridan-gil / 용리단길)的意式浓缩咖啡吧·甜点咖啡馆。登记价是浓缩咖啡₩4,800，美式咖啡₩5,500，拿铁₩5,800，卡布奇诺₩5,800，黑巧克力₩7,000，阿芙佳朵₩7,500，Gold Rush意式浓缩₩9,500。Freddo意式浓缩和棉花糖拿铁的价格登记超过2年，要以Kakao地图当日确认为准。时间是周一·周二10:00~19:00，周三至周日10:00~21:30。地址是龙山区 (Hangang-daero 53-gil 2-7 / 한강대로53길 2-7)，附近的站是三角地站 (Samgakji / 삼각지역)(4·6号线)·新龙山站 (Sinyongsan / 신용산역)(4号线)。没有停车场，有可携带宠物标签。外语评论9条(5·2·2)。饮食提示: 拿铁·卡布奇诺含牛奶。阿芙佳朵是把意式浓缩浇在冰淇淋(乳制品)上吃的菜单。棉花糖拿铁如其名含棉花糖。OJ美式咖啡是在橙汁·气泡水里混入意式浓缩的饮品(店主说明)。咖啡类菜单全部含咖啡因。

🗺 动线 — 三条半日路线

首尔可以坐地铁在区域之间移动，所以一天连着走两个区域也可以。不过在一个区域里逛两三家咖啡馆的半日路线更没有负担。店与店之间的移动和所需时间，当天用Kakao地图导航确认。

A. 弘大·望远半日 (周二至周日)

  1. 早晨 西桥洞 (Seogyo-dong / 서교동)的咖啡馆 (Analog Garden / 아날로그가든)(平日09:00~，周末08:00~)
  2. 中午 望远的咖啡馆 (KOMAME / 코마메)三明治(周二至周四·周日~18:00，周五·周六~19:00)。周一休息
  3. 下午到晚上 汉江码头的咖啡馆 (Newcase / 뉴케이스)(~22:00)

B. 圣水半日

  1. 白天 在面包咖啡馆 (CAT&F / 캣앤에프)吃面包。没有登记各星期几的时间，出发前用Kakao地图当日确认
  2. 下午 在冰淇淋店 (Beurre Beurre Seongsu / 뵈르뵈르 성수)吃冰淇淋或喝拿铁(11:00~22:00)
  3. 晚上 首尔林一侧的刨冰咖啡馆 (Gidaelbing / 기댈빙)刨冰(~23:00)

C. 三角地·解放村·汉南洞半日

  1. 上午 三角地站一带的咖啡馆 (Fjord / 피요르드)意式浓缩(10:00~)
  2. 中午过后 解放村的甜点咖啡馆 (Tortus / 토터스)舒芙蕾松饼(12:00~)或咖啡馆 (Cafe Tajagi / 카페 타자기)(只有周三13:00~)
  3. 晚上 汉南洞的咖啡馆 (MOTHER Offline / 마더오프라인)(~24:00)

周一咖啡馆 (KOMAME / 코마메)休息。咖啡馆 (Fjord / 피요르드)周一·周二19:00打烊。解放村的两家12:00之前不开门。韩国咖啡馆的占座·马克杯·归还台规则见#1378。

⚠ 3个常见失误

  1. 周一安排望远路线 — 咖啡馆 (KOMAME / 코마메)周一休息。周一去望远的话，只能把咖啡馆 (Analog Garden / 아날로그가든)和咖啡馆 (Newcase / 뉴케이스)连起来。同样是周一·周二，咖啡馆 (Fjord / 피요르드)也在19:00打烊，所以不要放进晚上的路线。咖啡馆 (Cafe Tajagi / 카페 타자기)只有周三13:00开门。
  2. 凭猜测去面包咖啡馆 (CAT&F / 캣앤에프) — Kakao地图上只登记了公休日09:00~22:00，平日·周末的时间是空白。去之前用Kakao地图当日确认时间。
  3. 去了名字相近的店或其他分店 — 咖啡馆 (Analog Garden / 아날로그가든)另有名字相近的咖啡馆 (Analog Chimpanzee Garden / 아날로그침팬지가든)(Poeun-ro 42 / 포은로 42)和金浦店 (Gimpo / 김포)。冰淇淋店 (Beurre Beurre / 뵈르뵈르)在首尔有好几处同名分店(梨泰院·大学路·建大等)。Kakao地图上的店名也和这一篇的写法不同。咖啡馆 (KOMAME / 코마메)显示为咖啡馆 (Komame / 코마메)，咖啡馆 (MOTHER Offline / 마더오프라인)显示为咖啡馆 (Mother Offline / 마더오프라인)，面包咖啡馆 (CAT&F / 캣앤에프)显示为面包咖啡馆 (Bakery Cafe CAT&F / 베이커리카페 CAT&F)，咖啡馆 (Newcase / 뉴케이스)显示为咖啡馆 (Newcase Mangwon Main / 뉴케이스 망원본점)，咖啡馆 (Cafe Tajagi / 카페 타자기)显示为咖啡馆 (Tajagi / 타자기)。在地图应用里不要搜店名，用这一篇的道路名地址找。

⚙ 3个常见问题

  1. 只能选一家？ — 外语评论15条(5·5·5)的有三家，每个区域一家。弘大·麻浦是咖啡馆 (Analog Garden / 아날로그가든)(周末08:00开门)，圣水是面包咖啡馆 (CAT&F / 캣앤에프)(时间以Kakao地图当日确认为准)，龙山 (解放村·汉南洞·三角地)是甜点咖啡馆 (Tortus / 토터스)(12:00~21:20)。选离住处近的区域。
  2. 晚上能去到很晚的店有哪些？ — 按登记时间，咖啡馆 (MOTHER Offline / 마더오프라인)开到24:00，刨冰咖啡馆 (Gidaelbing / 기댈빙)开到23:00。其次是咖啡馆 (Newcase / 뉴케이스)·冰淇淋店 (Beurre Beurre Seongsu / 뵈르뵈르 성수)(每天22:00)和咖啡馆 (Cafe Tajagi / 카페 타자기)(周一·周二·周五至周日22:00)。
  3. 想更多了解咖啡馆的使用方法？ — 占座·马克杯·归还台这类韩国咖啡馆内的规则见#1378。济州咖啡馆见同一框架的#1438。
