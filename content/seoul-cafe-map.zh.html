首尔咖啡馆指南 — 咖啡与空间14处(鹤林·乙支茶房·In the Mass·哨所书店) 烘焙坊·老茶房·仓库·景观篇 (2026年10月官方数据)

副标题: 鹤林 (Hakrim / 학림) 自1956年营业·自家烘焙咖啡豆(VisitKorea) · 乙支茶房 (Eulji Dabang / 을지다방) 1985年开业,周一至周六06:00开门(VisitKorea) · In the Mass 马场 (In the Mass Majang / 인더매스 마장) 在马场旧仓库里展示烘焙过程(VisitKorea) · 仁王山哨所书店 (Chuso Chaekbang / 초소책방) 前身为警察哨所,08:00~22:00(VisitKorea) · 14处全部未公布价格 — 截至2026-10-21

🎯 如何使用这份指南

爬上二楼的木楼梯,烘焙咖啡豆的香味先一步迎上来,窗外是付岩洞的小巷(俱乐部浓缩咖啡 (Club Espresso / 클럽에스프레소),VisitKorea)。这份指南只收录以咖啡味道和空间本身为理由的首尔咖啡馆。分为四类:自家烘焙的咖啡馆、老茶房、用仓库或老建筑改造的咖啡馆、山景和江景咖啡馆。所有店家都是韩国观光公社旅游信息(VisitKorea、TourAPI)中登记的店,地址、营业时间、休息日照搬登记信息。以蛋糕、面包为主角的店归入 #914 甜品店指南。

旧版指南给蓝瓶、Anthracite、Fritz 加了"世界最佳""韩国最佳"之类的排名,因没有依据已删除。知名品牌咖啡馆和按街区分类的清单请看 外国人首尔咖啡馆总览指南。这一版以VisitKorea上写有空间来历的店为主。

☕ 自家烘焙咖啡馆 — 4处

  • 鹤林 (Hakrim / 학림) — 首尔钟路区大学路 (Daehak-ro / 대학로) 119号2层。10:00~23:00(最后点单22:00),春节 (Seollal / 설) 和中秋 (Chuseok / 추석) 休息。自1956年营业的咖啡馆,在店内自己烘焙咖啡豆并供应手冲咖啡。招牌是维也纳咖啡(顶着鲜奶油的咖啡),还有奶油芝士蛋糕和帕菲。店里播放古典音乐。电话 02-742-2877(VisitKorea)
  • 俱乐部浓缩咖啡 (Club Espresso / 클럽에스프레소) — 首尔钟路区彰义门路 (Changuimun-ro / 창의문로) 132号(付岩洞 (Buam-dong / 부암동))。09:00~19:00(最后点单18:50),全年无休。1990年在大学路开业,2001年搬到付岩洞。一层是像烘焙工作室一样的点单台,二层是木质装饰的座位。也卖咖啡豆和咖啡器具。附近有尹东柱文学馆 (Yun Dong-ju Munhakgwan / 윤동주문학관)。电话 02-764-8719(VisitKorea)
  • 咖啡朋友 (Coffee Chingu / 커피친구) — 首尔钟路区三峰路 (Sambong-ro / 삼봉로) 81号(水松洞 (Susong-dong / 수송동))。工作日10:00~20:30,周六12:00~17:30,周日休息。2005年开业的手冲专门店,使用每天现烘的咖啡豆。菜单按萨尔瓦多、肯尼亚、卢旺达、哥伦比亚等产地名称排列,也有低因咖啡。电话 02-725-0179(VisitKorea)
  • 许亨万的狎鸥亭咖啡屋 (Heo Hyeong-man-ui Apgujeong Coffee House / 허형만의 압구정커피집) — 首尔江南区狎鸥亭路 (Apgujeong-ro / 압구정로) 151号 新现代商街2栋107号。周一至周五09:00~18:00,周六09:00~17:00,周日、法定公休日、春节、中秋假期休息。2001年7月开业。烘焙师兼讲师许亨万先生供应每天烘焙的咖啡,还开设咖啡课程。招牌是狎鸥亭咖啡。电话 0507-1367-5078(VisitKorea)

🕰 老茶房 — 3处

  • 乙支茶房 (Eulji Dabang / 을지다방) — 首尔中区乙支路 (Eulji-ro / 을지로) 124-1号2层(乙支路3街 (Euljiro 3-ga / 을지로3가))。周一至周六06:00~21:00,周日09:00~20:00,全年无休。1985年开业。招牌是放了蛋黄的双和茶 (Ssanghwa-cha / 쌍화차,一种韩方茶),也有冰咖啡和鲜榨果汁。因重新开发搬到了现在的位置。电话 02-2272-1886(VisitKorea)
  • 特邦奈 (Teobangnae / 터방내) — 首尔铜雀区黑石路 (Heukseok-ro / 흑석로) 101-7号。12:00~23:00,周日休息。保留了1983年开业的音乐茶房的样子。咖啡用虹吸壶冲泡。人气菜单是在方糖上倒威士忌点火的"皇家咖啡 (Café Royal / 카페 로열)",以及漂着冰淇淋的咖啡漂浮。电话 02-813-4434(VisitKorea)
  • 燕子茶房 (Jebi Dabang / 제비다방) — 首尔麻浦区卧牛山路 (Wausan-ro / 와우산로) 24号(上水站 (Sangsu-yeok / 상수역) 附近)。11:30~02:00,全年无休。取自作家李箱 (Yi Sang / 이상) 曾经开过的茶房的名字。除了咖啡,还供应桔梗茶和红茶,点心有年糕条 (Garaetteok / 가래떡)。地下一层有独立乐队舞台。电话 02-325-1969(VisitKorea)

🏭 用仓库·老建筑改造的咖啡馆 — 3处

  • In the Mass 马场 (In the Mass Majang / 인더매스 마장) — 首尔城东区马场路 (Majang-ro / 마장로) 270号 京东仓库 (Gyeongdong Changgo / 경동창고)(马场站 (Majang-yeok / 마장역) 4号出口一带)。09:00~21:30(最后点单21:00),全年无休。改造自老仓库。天花板很高,在店里能看到烘焙过程和咖啡师培训的场景。可以挑咖啡豆当场品尝,可携带宠物。电话 0507-1489-9031(VisitKorea)
  • 咖啡药房 (Coffee Hanyakbang / 커피한약방) — 首尔中区三一大路12街 (Samil-daero 12-gil / 삼일대로12길) 16-6号(乙支路2街 (Euljiro 2-ga / 을지로2가))。1层工作日10:00~22:00,周末11:00~22:00(最后点单21:00),2、3层10:00~21:30,全年无休。VisitKorea将这里介绍为在朝鲜医疗机构惠民署 (Hyeminseo / 혜민서) 旧址上改造的咖啡馆。老物件和古董原样保留,招牌是手工烘焙的咖啡和过滤咖啡。巷子很窄,不好找。电话 070-4148-4242(VisitKorea)
  • Bean Brothers 合井 (Bean Brothers Hapjeong / 빈브라더스 합정) — 首尔麻浦区土亭路 (Tojeong-ro / 토정로) 35-1号(合井站 (Hapjeong-yeok / 합정역) 7号出口一带)。10:00~22:00(最后点单21:30),全年无休。天花板高的独栋建筑,工业风内饰,咖啡师在店中央的吧台冲咖啡。招牌是滴滤咖啡。电话 0507-1428-2001(VisitKorea)

⛰ 山景·江景咖啡馆 — 4处

  • 仁王山 更森 哨所书店 (Inwangsan Deosup Chuso Chaekbang / 인왕산 더숲 초소책방) — 首尔钟路区仁王山路 (Inwangsan-ro / 인왕산로) 172号(仁王山半山腰)。08:00~22:00(最后点单21:30),全年无休。由1968年起使用了50多年的警察哨所改造的书店兼咖啡馆,保留了哨所部分外墙和铁门。透过落地玻璃窗能看到南山塔。电话 02-735-0206(VisitKorea)
  • 铜雀晚霞咖啡馆 (Dongjak Noeul Cafe / 동작노을카페) — 首尔铜雀区铜雀大路 (Dongjak-daero / 동작대로) 335号(4号线铜雀站 (Dongjak-yeok / 동작역),铜雀大桥南端)。周一至周四10:00~23:00,周五至周日10:00~01:00,全年无休。二层是朝向汝矣岛的座位,三层是朝向盘浦的座位,四层是露台。大桥对面1号出口一带有同样造型的云咖啡馆 (Gureum Cafe / 구름카페)。电话 0507-1324-7279(VisitKorea)
  • 山拐角 (Sanmotung-i / 산모퉁이) — 首尔钟路区白石洞路 (Baekseok-dong-gil / 백석동길) 153号(付岩洞)。11:00~18:50(最后点单18:20),全年无休。曾是MBC电视剧的拍摄地,二层陈列着拍摄道具和照片。窗外可以看到首尔市区和北汉山。电话 02-391-4737(VisitKorea)
  • 韩屋咖啡馆 善云阁 (Hanok Cafe Seonungak / 한옥카페 선운각) — 首尔江北区三阳路173街 (Samyang-ro 173-gil / 삼양로173길) 223号(牛耳洞 (Ui-dong / 우이동))。11:00~19:00(最后点单18:00),周三休息。北汉山脚下的韩屋 (Hanok / 한옥)。VisitKorea的介绍文写的是已故郑周永会长所建 (Jeong Ju-yeong / 정주영),据说是除宫殿外首尔最大的民间韩屋,用的是传闻口吻。此前只作为韩屋婚礼和拍摄场地使用,后来开成了咖啡馆。从牛耳新设线北汉山牛耳站 (Bukhansan Ui-yeok / 북한산우이역) 步行约20分钟,停车收费。电话 0507-1399-1105(VisitKorea)

🥗 饮食

  • 价格带: 14处在VisitKorea登记信息中都没有价格。价格未公布 — 看菜单选择或打电话确认
  • 牛奶替代: 登记了杏仁饮品菜单的店是哨所书店(Almond Breeze 拿铁)和山拐角(Almond Breeze 咖啡)(VisitKorea)。其他店点单时请询问能否换成燕麦奶或豆奶
  • 咖啡因: 登记了低因咖啡的店是咖啡朋友(VisitKorea)。乙支茶房的双和茶是韩方茶,不是咖啡
  • 鸡蛋·酒精: 乙支茶房的双和茶上放有蛋黄。特邦奈的"皇家咖啡"里加了威士忌(VisitKorea) — 素食和清真旅行者请让店家去掉,或选择其他菜单
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区乌沙团路10街 (Usadan-ro 10-gil / 우사단로10길) 15号,每天12:00~21:00)是韩国伊斯兰教中央会 (Korea Muslim Federation, KMF / 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。这份指南里的咖啡馆都没有清真标注
  • 出示用卡片请看 #1300 饮食需求手册

🧰 咖啡馆实用信息 — 独自、预约、支付、点单、交通

  • 独自: 咖啡馆以一人点单为基本,一个人去很容易。独自用餐、独自喝咖啡的地图请看 #348 Seoul Solo Diner Map
  • 预约: 14处在VisitKorea登记信息中都没有预约说明。排队或直接进去即可
  • 支付: 银行卡和移动支付请看 #527 韩国支付系统
  • 点单: 很多店是在收银台点单后领一个震动呼叫器 — #1288 咖啡馆震动呼叫器手册。马克杯、归还台、占座请看 #1378 咖啡馆店内使用规则。语言不通时请看 #1339 点单礼仪
  • 交通: 地铁和公交请看 #1298 三种交通卡怎么选。哨所书店、山拐角、善云阁位于山坡上,请多留些步行时间

⚠ 常见的4个误区

1. "老茶房都消失了" — 乙支茶房(1985年)和特邦奈(1983年)至今仍在VisitKorea上登记为营业中

2. "咖啡馆每天都开" — 咖啡朋友、特邦奈周日休息,许亨万的狎鸥亭咖啡屋周日和公休日休息,善云阁周三休息(VisitKorea)

3. "咖啡馆营业到很晚" — 俱乐部浓缩咖啡19:00、山拐角18:50、善云阁19:00打烊。深夜请选燕子茶房(02:00)和铜雀晚霞咖啡馆(周五至周日01:00)(VisitKorea)

4. "景观咖啡馆得爬山才能到" — 铜雀晚霞咖啡馆与4号线铜雀站出口直接相连(VisitKorea)
