🎯 segment別1位おすすめ

👤 ソロ旅行者 (Solo)

  • 1順位: 会集1人メニュー (弘大・江南1人回集) — 1人回 + マウンタンセット 35,000～55,000ウォン、お酒追加OK
  • 2順位: 市場
  • 3ランキング: 和食屋ランチコース
  • 回避: 和食屋本物のおまかせ

💑 カップル (Couple)

  • 1順位: 和食屋 おまかせ (1周年・記念日・ロマンチック) — 1人100,000～150,000ウォン、写真 ★★★★★
  • 2順位: 会集(仮性費デート) - 1人55,000ウォン+酒
  • 3順位: 市場(ローカルデート、[#590チャガルチ](590_外国人_韓国_チャガルチ_市場_12線_deep_dive.md) 2階夜景)
  • 回避：平日の昼市場（雰囲気不足）

👨‍👩‍👧 ファミリー (Family)

  • 1順位: 会集 (家族型) — 4人フルセット 200,000～280,000ウォン, 子供メニュー多（天ぷら・ドンガス別）
  • 2順位: 市場（チャガルチ本館2階ファミリールーム・キッズゾーン一部） — コスパ・体験
  • 3ランキング：和食屋（ランチコース、子供には静すぎる）
  • 回避：おまかせ（子供が適応しにくい）

💼 ビジネス・接待 (Business)

  • 1順位: 和食屋本格おまかせ (江南・清潭・新羅ホテル和食堂) — 1人150,000～300,000ウォン、格式 ★★★★★
  • 2順位：高級会集（韓国正統、両班雰囲気） - 1人80,000〜120,000ウォン
  • 3ランク：市場（快適な雰囲気が欲しいときのみ）
  • 回避：市場の売り上げ（格式不足）

🎒 バックパッカー・予算型 (Budget)

  • 1順位: 市場(露梁陣平日昼) — 1人25,000～35,000ウォン、酒無制限30,000ウォン追加
  • 2順位: 会集ランチ特選 (lunch only, 25,000～40,000ウォン)
  • 3順位：市場（ソラポグ平日・週末ともにコスパ）
  • 回避：おまかせ（予算超過）

🎯 3チャンネル deep dive

🐟 会集(韓国式回集)

コアバリュー: 活力 + ワン賞フルセット + マウンテンコース。韓国会の本格的な経験。

  • おすすめ店舗(ソウル):江南・清潭・汝矣島高級回集/弘大・新村苛性費/蚕室・東大門家族型
  • おすすめ店（地方）：釜山ジャガルチ・海雲台回集街/江陵・束草/統営ダチ集
  • メニューパターン: 会(1~2種) + 会舞針 + マウンタン + サム野菜 + おかず 5~10種 + ご飯
  • 価格anchor：ランチ30,000〜50,000ウォン/夕方50,000〜80,000ウォン/高級100,000ウォン+
  • 予約：週末・記念日の1～2日前に推奨。英語予約が難しい店舗→ホテルコンシェルジュを活用
  • 外国人親和性：江南・清潭・弘大= ★★★★ / 地方 = ★★~★★★（英語メニュー少ない）
  • 外国人おすすめ魚種：狂魚・ウルク・ドミ（mild 白身）

🍣 和食集

核心価値: 熟成会 + コース + 職人技。日本刺身スタイル＋韓国シェフ・国内シーフード多数。

  • 種類:
  • おまかせ（お任せ）：シェフ1：1、8～15コース、1人100,000～300,000ウォン
  • 本物の和食：刺身・ニギリ・うどん・揚げメニュー単品
  • チェーン（寿司チョイス・ミジン・寿司明神など）：コスパ30,000～50,000ウォン
  • おすすめ店(ソウル): 清潭・狎鴎亭一帯大間瀬/江南日食路地/新羅・ロッテホテル和食堂(ホテルは付加税10%+サービス料10%別途多)
  • メニューパターン(おまかせ): つけもの→刺身 5～7 → ニギリ 8～12 → 煮込み・焼き → みそしら → デザート
  • 価格 anchor: チェーン 30,000～50,000ウォン / 正統 80,000～150,000ウォン / オマカセ 150,000～300,000ウォン
  • 予約: 正統・おまかせ = 1～2週間前必須 (キャッチテーブル・オープンテーブルアプリ)。 清潭級トップオマカセは1〜3ヶ月wait一般
  • 外国人フレンドリー: ★★★★ — メニュー 英語 多, 日本人観光客適応OK
  • 特異点: わさび・しょうゆ＝無料、追加酒・清酒のコスパ（病堂30,000～80,000ウォン）

＃＃＃🛒市場（1階売り+ 2階上り）

核心価値: コスパ ★★★★★ + 活気鮮度 + ローカル雰囲気。フルワークフローは[#790](790_外国人_回_市場_上車林_ワークフロー_ガイド.md)参照。

  • おすすめ市場5ヶ所：チャガルチ（釜山）/ノリャンジン（ソウル）/統営中央活魚（慶南）/ソラポグ（仁川）/九龍浦（慶北）
  • メニューパターン: 回（売り切れ選択） + 上茶林（2階食堂） + 辛い湯（回して残った骨）
  • 価格 anchor: 市場方式 1人 25,000~50,000ウォン + 商車林費 + 辛運湯費 = 合計 40,000~70,000ウォン
  • 予約: 平日 walk-in / 週末・シーズン (12月防御・9月電語) 事前電話推奨
  • 外国人親和性: チャガルチ ★★★★★ / ノリャンジン ★★★★ / 統営 ★★★★ / 歌 ★★★ / 九龍浦 ★★
  • ワークフロー: [#790 4-stepガイド](790_外国人_会_市場_上車林_ワークフロー_ガイド.md)参照

＃＃⚠外国人の頻繁な誤り5つ

1. 「会集=和食集」: 韓国式会集+和食和食集=他のカテゴリ。メニュー・価格・雰囲気が違う。

2. 「おまかせ＝高価な刺身のみ」：おまかせ＝シェフ8～15コース（刺身は一部）。価格にはコース全体込み。

3. 「市場 = 常に安い」: 市場回数自体は安価であっても 上り林費 + マウンタンビ 別途 合算時の会集と似ている可能性がある (ただし自由度 ↑)。

4. "平日低多非効率": ランチ特選 (lunch course) = 会集・和食集ともに30～50%割引。コスパ比#1。

5. 「記念日には無条件おまかせ」: 韓国会正統経験 = 高級会集（一賞姿）。外国人には和食＜会本場が新鮮な経験。

⚙ よくある質問8件

1. 初回挑戦=どこ?: 会集 1位(韓国本物の経験)。和食屋は日本経験ある外国人おすすめ。

2. 外国人1位メニュー: 会集=光魚・ウルク白身/和食集=刺身+ニギリ/市場=シーズン魚種([#789]

3. ランチ対夕食: ランチ特選 30~50%安い。会集・和食店おすすめ。市場はランチの雰囲気↓

4. アレルギー事前通知: 会集 = マウンテンタン エビ交差汚染 / 和食屋 = つけものアレルギー可能 / 市場 = 共通釜 issue

5. 雰囲気・ドレスコード: おまかせ = smart casual / 高級会集 = casual / 市場・チェーン = 自由

6. カード決済: 和食集・会集 = カードOK / 市場売り場 = 現金推奨 / 商車林家 = カードOK

7. 回入門者魚種推薦：狂語・ウルク・ドミ（mild 白身）。青い魚（サバ・アジ）の非推奨。

8. VAT還付: レストラン・市場ともにタックスリファン対象ではない (飲食一般)。免税ショッピングの払い戻しは別途。

⚠医療・安全 disclaimer

活魚会＝生殖。 妊婦・免疫低下・甲殻類アレルギー患者は事前医療相談を推奨。マウンテン共通の鍋エビ交差汚染可能 - アレルギー患者は別途沸騰要求または回避。食中毒の疑いがある場合☎ 1339（医療コールセンター、英語）。 3歳未満の乳幼児生会非推奨長（学会ガイド）。このガイドは一般的な情報であり、医療助言ではありません。

食事制限fallback: 回＝源泉 ビハラル（生物・屠殺未認証）。ハラール・コーシャ・ベジタリアン同行者 → 和食屋 野菜 コース・うどん・揚げメニュー 別途OR市場付近の一般食堂に分離。会集・和食店メニューパネル別 vegetarian 表示 ほとんどなし — 事前電話・翻訳アプリで確認。
