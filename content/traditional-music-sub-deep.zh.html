📍 首尔 — 首尔南山国乐堂·首尔敦化门国乐堂·国乐公演 Jinyeon

首尔南山国乐堂 (Seoul Namsan Gugakdang / 서울남산국악당)，中区 (Toegye-ro 34-gil 28, Pil-dong 2-ga / 퇴계로34길 28, 필동2가)，☎ 02-6358-5500，是2007年建成的国乐专业演出场馆。地上1层是韩屋建筑，演出厅设在其下的地下。与地下1层演出厅大厅相连的下沉花园“Chimsangwon (침상원)”，是再现景福宫交泰殿韵味的阶梯式庭院，虽是地下演出厅，却有自然光照进来。

  • 开放时间:09:00~21:00。有演出的日子，会配合演出结束时间闭馆。休息日:每周一。
  • 费用:因演出而异。座位:300席。

首尔敦化门国乐堂 (Seoul Donhwamun Gugakdang / 서울돈화문국악당)，钟路区 (Yulgok-ro 102, Waryong-dong / 율곡로 102, 와룡동)，☎ 0507-1413-7001，是取昌德宫敦化门之名的国乐专业演出场馆。由首尔市买下昌德宫对面的加油站用地建成。融合了传统韩屋与现代建筑样式，设有以自然音响欣赏国乐的室内演出厅，以及用于户外演出的国乐广场。

  • 开放时间:09:00~18:00。运营时间因是否有演出而异。休息日:每周一。
  • 费用:因演出而异。座位:140人。

国乐公演 Jinyeon (Gugak Gongyeon Jinyeon / 국악공연 진연)，钟路区 (Insadong 5-gil 10 / 인사동5길 10)，☎ 02-953-0515，是在韩屋概念演出场馆举办的60分钟传统艺术演出。可以欣赏演奏并与艺术家交流，用传统乐器演奏韩国音乐·K-pop·古典乐·世界民谣。把演奏、唱腔、乐器体验结合在了一起。登记的日程为2026年1月1日~12月31日。

  • 演出时间:每天 11:00，14:00，16:00。法定节假日无演出。观看年龄:全年龄。
  • 费用:普通票 65,000韩元，残疾人优惠50%，不满24个月免费。
  • 构成:第1部 Gilje (길제，供上井华水，祈愿观众平安)，第2部 Jinyeon (진연，宫廷传统演出·正乐 (Jeongak / 정악)·散调 (Sanjo / 산조))，第3部 Hwahap (화합，用传统乐器演奏多国音乐)。

📍 地方国立国乐院 — 珍岛·南原·釜山

国立南道国乐院 (Gungnip Namdo Gugagwon / 국립남도국악원)，珍岛郡 (Jindo-daero 3818 / 진도대로 3818)，☎ 061-540-4031，位于珍岛，这里有丰富的传统艺术，如盘索里 (Pansori / 판소리)·Sinawi (시나위)·散调 (Sanjo / 산조)，以及珍岛阿里郎 (Jindo Arirang / 진도아리랑)·强羌水越来 (Ganggangsullae / 강강술래)·Namdo Deulnorae (남도들노래)·Jindo Ssitgimgut (진도씻김굿)·Jindo Bukchum (진도북춤)。每周六 15:00 有常设演出。设有520多席规模的国乐专用剧场 Jinakdang (진악당)、采用 庭院剧 (Madangnori / 마당놀이) 形式的户外演出场 Dalbitmadang (달빛마당)、小规模户外演出场 Byeolbitmadang (별빛마당)。

  • 开放时间:09:00~18:00。休息日:每周日·周一。
  • 费用:因体验项目而异。体验:上门教室音乐会、南道国乐体验 Bobaeseom Gugak Nadeuli (보배섬 국악나들이) 等。

国立民俗国乐院 (Gungnip Minsok Gugagwon / 국립민속국악원)，南原市 (Yangnim-gil 54 / 양림길 54)，☎ 063-620-2329，是1992年在盘索里的故乡南原开馆的国家音乐机构，以盘索里和唱剧为中心传承·普及民俗乐。设有 Yewondang (예원당)、Yeeumheon (예음헌)、国乐展览馆、民俗乐资料室，举办周六常设演出和盘索里场等定期演出，以及重新创作盘索里五场的唱剧演出。

  • 开放时间:国乐展览馆 09:00~18:00。演出场馆因演出而异。休息日:国乐展览馆全年无休。
  • 费用:因演出而异。座位:680席。

国立釜山国乐院 (Gungnip Busan Gugagwon / 국립부산국악원)，釜山镇区 (Gugak-ro 2 / 국악로 2)，☎ 051-811-0114，是为传承釜山·岭南地区的传统表演艺术，于2008年10月28日开馆的国立文化艺术机构。演出、教育、研究并行。

  • 开放时间·休息日·费用:因演出而异。

📍 国乐博物馆 — 国乐圣地(南原)·Nangye 国乐博物馆(永同)

国乐圣地 (Gugagui Seongji / 국악의 성지)，南原市 (Bijeon-gil 69, Unbong-eup / 비전길 69, 운봉읍)，☎ 063-620-5740~2，是在智异山脚下的云峰邑 (Unbong-eup / 운봉읍)建成的国乐博物馆兼展览馆。设有集东便制 (Dongpyeonje / 동편제) 之大成、被称为歌王的宋兴禄 (Song Heungnok / 송흥록) 的故居，以及国乐展览体验馆、Dokgongsil (독공실)、户外演出场、国乐人的墓地和祠堂。展出器乐·正乐 (Jeongak / 정악) 资料和名唱们捐赠的文物。

  • 开放时间:09:00~18:00。休息日:每周一，1月1日，春节，中秋节。
  • 体验:Hansam舞蹈 (Hansam / 한삼) 体验，跟着盘索里学唱，制作迷你国乐器，国乐演出等。
  • 停车:可(免费)。

Nangye 国乐博物馆 (Nangye Gugak Museum / 난계국악박물관)，永同郡 (Gugak-ro 9, Simcheon-myeon / 국악로 9, 심천면)，☎ 043-740-3886，是2000年开馆的国乐专业博物馆。在影像室和 Nangye 室 (난계실) 介绍出生于永同的朝鲜初期音乐家兰溪朴堧 (Nangye Bak Yeon / 난계 박연) 的生平与业绩。据观光公社介绍，朴堧 (Bak Yeon / 박연) 与高句丽的 王山岳 (Wang Sanak / 왕산악)、新罗的 于勒 (Ureuk / 우륵) 并称韩国三大乐圣。国乐室里有大笒 (Daegeum / 대금)·伽倻琴 (Gayageum / 가야금)·奚琴 (Haegeum / 해금)·编钟 (Pyeonjong / 편종) 等80多件国乐器和世界民俗乐器。

  • 开放时间:09:00~18:00。休息日:每周一，1月1日，春节·中秋节连休，法定节假日的次日。Nangye 国乐节期间开馆。
  • 费用:成人 2,000韩元，青少年·儿童·军人·永同郡居民 1,500韩元。30人以上团体，成人 1,500韩元，青少年·儿童·军人·永同郡居民 1,000韩元。

⚠ 提前须知3点

  1. 演出场馆的费用因演出而异 — 首尔南山国乐堂、首尔敦化门国乐堂、国立民俗国乐院、国立釜山国乐院没有登记固定费用。
  2. 很多地方周一休息 — 首尔南山国乐堂、首尔敦化门国乐堂、国立南道国乐院、国乐圣地、Nangye 国乐博物馆周一休息。国立南道国乐院周日也休息。
  3. Jinyeon 在法定节假日不演出 — 其他日子每天演出3场。

⚙ FAQ 2

Q. 有固定时间可以观看的国乐演出是?

A. 根据观光公社登记信息，是国乐公演 Jinyeon(每天 11:00·14:00·16:00，法定节假日除外)和国立南道国乐院常设演出(每周六 15:00)。国立民俗国乐院也举办周六常设演出。

Q. 可以亲自体验国乐的地方是?

A. 国乐圣地(Hansam舞蹈、跟着盘索里学唱、制作迷你国乐器)、国乐公演 Jinyeon(包含乐器体验的演出)，以及国立南道国乐院的体验项目(上门教室音乐会、南道国乐体验 Bobaeseom Gugak Nadeuli (보배섬 국악나들이))。
