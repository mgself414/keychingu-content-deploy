🍶 小脈(Soju+Beer) 作成マナー

小脈定義 & 比率

  • 小麦 = 焼酎(Soju) + ビール(Beer) = 韓国会食#1 クラシックフェア
  • 標準比率：1：3（焼酎1：ビール3）または1：2.5（焼酎比重↑）
  • 1:2 比率 = 焼酎の過剰 → 早くとる(外国人の照り)

###小麦を作るステップ

1. ビールカップ（350～500ml）の準備

2. ビール 70% 注ぐ (杯 70% 満ちる)

3. 焼酎杯(45ml) 1杯準備

4. 焼酎1杯 ビールに注ぐ

5. 振る OR 箸で軽くたたく

6. 乾杯後飲む

###外国人愛好家のヒント

  • 小麦 = 短く: 30秒～1分以内に飲む（焼酎アルコール揮発防止）
  • 小麦 = 累積 ↑: 1杯 = 標準杯 1.5～2, 2杯 = 3標準杯 = クイック取る
  • 小麦強制拒否OK：「I don't drink shots」または手のひらの上のカップ

＃＃🍯マッコリを飲む方法

マッコリを振る・追いつく

1. 振る: ボウルの底の沈殿物（酵母） + 上の澄んだ部分 = 振って解く

  • マッコリ病の上下にゆっくり5〜10回振る

2. カップに従う：大人に両手でフォローする

3. 受け取る: 大人がフォローするとき 両手でグラスを受け取る

4. 乾杯: 「乾杯！」または「ために！」

5. 飲む（大人の前）：頭を回して飲む（本物のマナー）

6. 最初のガラス: 一口または丸ごと（個人的な好み）

###マッコリペアリングマニア

  • キムチジョン+マッコリ =雨の日#1
  • シーフード破戦+マッコリ =本物の限定式
  • 緑豆展+マッコリ =マッコリハウス本物
  • ボッサム+マッコリ =本格的な会食
  • MZトレンド：牛乳マッコリ・桃マッコリ・イチゴマッコリ

＃＃🙏飲酒マナーコア7つ

###韓国酒マナー(伝統)

1. 両手に従う: 大人に酒を飲むとき両手で

2. 両手を受け取る: 大人が従うときに両手でカップを受け取る

3. 頭を回して飲む：大人の前で横に首を回して飲む（本物）

4. グラスを空に：大人に沿ってライングラス=空にすることをお勧めします（現代=強要X）

5. 乾杯時: グラス位置 = 大人よりやや低く(伝統)

6。

7. 最初のグラス=大人の最初: 大人が先に従った後、本人

###強制拒否マナー(現代)

  • "I don't drink" = 直接拒否 OK
  • 「1杯」 = 1杯試してから拒否
  • 手のひらの上のカップを持ち上げる =非言語的拒否信号
  • 薬を服用 = "薬を食べる"（医療理由）
  • 運転 = "運転しています"（運転理由）

> 現代韓国の飲食文化=強制拒否の一般化。拒否してもマナー違反ではない。

💰決済ワークフロー

###韓国式決済パターン

1. 1名がカード決済（通常の会食ホスト）

2. カカオペイ・トスロ送金 (参加者別決済)

3. 金額＝一人当たり平均÷N等分（均等分配）

###ダッチペイ店舗

  • MZ店舗：ダッチペイシステム多（個別決済）
  • 一般会食店：ダッチペイX（一人支払い）
  • コンビニ・カフェ：カード個別決済OK

＃＃⚠外国人の頻繁なミス7つ

1. 「焼酎＝ウォッカのように強い」：焼酎16～17％（ボドカ40％半分以下）。柔らかいが累積↑。

2. "マッコリ=振るX": 必ず振る（沈殿物+透明部分を混ぜる）。

3. 「小麦 = 自由率」：標準1：3または1：2.5。 1:2は焼酎の過剰です。

4. "大人の前 = 前面を飲む": 本物のマナー = 頭を回して飲む。

5. "強制拒否 = マナー違反": 現代韓国 = 強制拒否 OK。

6. "飲酒運転 = 軽さ": 0.03% BAC = 免許停止 (韓国取り締まり強力)。

7. "決済=ダッチペイ標準":韓国式=一人決済→送金パターン多。

⚙ よくある質問8件

1. 最初の酒=任意の愛好家: ビール（入門）→マッコリ（伝統）→焼酎（グローバル）→小麦（飲み物）段階。

2. インスタ・vlog: マッコリ揺れ・小麦作り・ハイボールバー MZ vlog。

3. MZトレンド：フルーツ焼酎・牛乳マッコリ・ハイボールバー・低度水焼酎。

4. 会食・接待：焼酎・ビール（一般）・清酒・伝統酒（正統）。

5. 飲酒マナー: 両手注ぎ・受け取り・頭を回して飲む（大人前）。

6. 飲酒運転: 0.03% BAC免許停止+刑事処罰。

7. アレルギー：グルテン（ビール）・豆（マッコリ・清酒）・フルーツ（フルーツ焼酎）事前告知。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・法律 disclaimer

韓国酒＝アルコール（度数4～45％）。 飲酒運転0.03％BAC免許停止+罰金+刑事処罰。妊婦・薬物服用者＝飲酒禁止。 19歳未満=法的飲酒禁止。アレルギー（グルテン・豆・果物・ナッツ類）事前告知。食中毒・過飲疑疑時☎1339（医療、英文）。本ガイドは一般情報、医療助言ではない。

飲酒制限（個人別）：

  • 標準杯＝14gアルコール（焼酎1杯・ビール1杯・ワイン1杯）
  • 外国人マニア＝標準杯2～3個推奨（1～2h食事＋酒）
  • 累積↑注意：小麦1杯＝標準杯1.5～2

食事制限 fallback:

  • ハラール・コーシャー: アルコール＝ビハラル・ビコーシャー。 →無アルコールオプション（食恵・水晶課・無アルコールビール）。
  • 無アルコール: 食恵・水晶科・菊茶（伝統）OR 無アルコールビール・無アルコール清酒。
