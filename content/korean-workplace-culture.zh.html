韩国职场文化 — 加班·午餐·咖啡，读懂韩国公司生活的纹理

> 等级 (wigye / 위계) · 职级与称谓 · 加班 (yageun / 야근) · 每周52小时制 · 午餐 · 饭后咖啡 · 聚餐 (hoesik / 회식) · 眼力见儿 (nunchi / 눈치) · MZ世代工作与生活平衡 — 为外国人解读韩国 (Korea / 한국) 职场文化。不是“如何进韩国公司工作”，而是“韩国公司生活为什么是这个样子”。

看韩剧时，韩国公司的场景经常出现。部长 (bujang / 부장) 不下班，你就不能离开座位；一到午餐时间，部门的人就成群结队一起出去吃饭；饭后大家又各自端着一杯美式咖啡 (měishì kāfēi) 回来。新人称呼上司为“部长님 (bujangnim / 부장님)”，称呼前辈为“金代理님 (Kim daerinim / 김 대리님)”，在聚餐场合连倒酒的顺序都有讲究。在外国人眼中，这些场景陌生、有时甚至令人感到憋闷，但其中其实浓缩着韩国 (Korea / 한국) 社会的骨架 — 等级、集体、勤勉。游客几乎没有机会亲自在韩国公司工作，但职场是电视剧、电影、综艺的背景，也是韩国人日常生活的一半。本文不讲“如何在韩国求职”，而是以外国人的视角解读公司生活为什么是这个样子 — 以及它如今正如何飞速变化。像聚餐、眼力见儿 (nunchi / 눈치)、称谓这类更深入的单独主题，会以独立篇章连接 (→ cross-link)。韩国 (Korea / 한국) 文化解读系列第56篇。

★ 一目了然 — 韩国职场文化的7条脉络

脉络 是什么 一句话
等级 (wigye / 위계) 垂直序列 由年龄、职级、入职顺序决定的上下秩序。源自儒家
职级·称谓 部长·科长·敬称 (nim / 님) 职员→代理→科长→部长… 用职级而非姓名称呼
加班 (yageun / 야근) 工作到很晚 韩国长期闻名的长工时 (jang-gongsi / 장시간 노동)。如今正在★减少

> 核心一句话：韩国职场的所有习俗，过去都建立在“集体先于个人、上级先于下级、勤勉先于效率”的传统之上 — 而如今，这一前提正在飞速动摇 (见下文⑥)。

⚠️ 外国人常有的3种误解

1. “韩国公司 = 一定加班·职场霸凌” ❌ — 长工时曾是事实，但更接近旧印象。随着2018年每周52小时制的引入和MZ世代对工作与生活平衡的诉求，景象正在飞速改变。越来越多的公司，“准时下班”变得理直气壮。电视剧为了戏剧效果，也倾向于把旧面貌描绘得更浓重。

2. “用职级称呼是权威主义” ❌ — 不用姓名而称呼“部长님 (bujangnim / 부장님)”·“金代理님 (Kim daerinim / 김 대리님)”，并非无礼，而是韩式的尊重礼节。反倒是直呼上级的姓名才是大失礼 (→ #1150)。不过，就连这一点，越来越多的公司也改用“○○-nim (○○님)”·“pro”·“manager”这类扁平化称谓。

3. “一起吃午餐·聚餐 = 侵犯私生活” ❌ — 在韩国 (Korea / 한국)，一起吃饭不只是用餐，而是积累关系与信息的社交 (→ “情”文化 #1135)。强迫减少了，但通过“一起吃”而成为同事的感觉，依然是韩国职场情感的核心。

① 韩国职场是什么 — 一句话概括

韩国职场文化可以概括为儒家等级 + 集体主义 + 勤勉伦理的结合。

  • 等级：依据年龄、职级、入职年限的上下秩序，渗透在日常的方方面面。会议上谁先发言、聚餐时谁来倒酒、办公室里谁最后下班 — 都是序列显现的场景。
  • 集体主义：相比个人的业绩，更优先团队·部门的和谐。比起出风头，“一起走”的态度长期被视为美德。
  • 勤勉：在压缩式增长的时代，“长时间·拼命工作”本身确立为一种价值。这正是加班一度成为奉献证明的背景。

这三条轴线，体现为午餐、称谓、聚餐、加班等具体习俗。而正是这三条轴线，如今正因MZ世代·制度变化而被重新协商。

② 等级·职级·称谓 — 用“部长님 (bujangnim / 부장님)”代替姓名

在韩国公司，最先映入眼帘的就是几乎不叫名字这一点。取而代之的是用职级 (jikgeup / 직급) 称呼。

具有代表性的一般职职级顺序 (因公司而异)：

> 职员 (sawon / 사원) → 主任 (juim / 주임) → 代理 (daeri / 대리) → 科长 (gwajang / 과장) → 次长 (chajang / 차장) → 部长 (bujang / 부장) → (高管：理事·常务·专务·副社长·社长…)

  • 对上级·前辈使用“姓 + 职级 + 님 (nim / 님)” — 例如：“金代理님 (Kim daerinim / 김 대리님)”、“朴科长님 (Park gwajangnim / 박 과장님)”。职级后几乎总是加上“님 (nim / 님)”。
  • 直呼其名只在同期·后辈之间可行，直呼上级的姓名则是失礼。
  • 这套称谓体系，甚至决定了谁对谁使用敬语 (jondaenmal / 존댓말)、谁先打招呼、谁先发表意见。韩语的敬语结构与职场等级是相互咬合的。
  • 想更深入了解称谓的纹理 → #1150 韩国称谓文化 (姐姐·阿姨·社长님)。本文聚焦于那套等级在“职场”这一整个系统中如何运作。

> ★ 变化要点：为了实现扁平化沟通，舍弃职级称谓的公司正在飞速增多。用职务·中立称谓如“○○-nim (○○님)”·“pro”·“manager”·“lead”·“担当 (damdang / 담당)”代替职级的，以IT·初创公司为代表 (见下文⑥)。

③ 加班与每周52小时制 — 韩国职场最大的转折点

韩国长期以长工时闻名。加班 (yageun / 야근) 不只是单纯的超时工作，一度被视为“诚实与奉献的证明”。曾有一种潜在的氛围：“不能比上司先下班”，管理者干脆把加班作为前提来安排工作量也很常见。

把这股潮流用法律改变的分水岭，就是每周52小时工作制。

  • 是什么：把每周工时限制为法定40小时 + 延长12小时 = 最长52小时的制度。
  • 何时：2018年7月从300人以上的大企业·公共机构开始施行 → 此后分阶段扩大适用至5人以上的事业单位。
  • 意义：正如“有晚上的生活” (jeonyeogi inneun salm / 저녁이 있는 삶) 这句话所象征的，它是把重心从以工作为中心转向个人生活的制度性信号弹。

> ★ 工时 — 建议核实：在国际比较中，韩国的年工时被报告为长于OECD平均水平 (某资料以2022年为准，给出韩国约1,901小时 vs OECD平均约1,752小时)。不过统计因基准·年份而异，建议核实最新的OECD/统计厅数据。方向是明确的 — 依然长，但正在快速减少。

随着加班减少，越来越多的公司里，“我下班了” (toegeunhagetseumnida / 퇴근하겠습니다) 不再是一句让人看脸色的话 — 这是韩国职场变化中最能切身感受到的部分。

④ 午餐·咖啡·沟通 — 韩国职场的社交节奏

外国人觉得新奇的韩国公司场景之一，就是午餐。

  • 一起吃的午餐：一到午餐时间，就以部门·团队为单位成群结队地去餐厅。比起独自吃，与人约好一起吃更接近默认值。午餐不只是一顿饭，而是积累关系、分享信息的社交时间。
  • ★ 饭后美式咖啡：吃完饭后，几乎像仪式一样全员一起移动到咖啡馆，每人端一杯咖啡 — 尤其是美式咖啡。“饭后一杯咖啡” (bap meokgo keopi hanjan / 밥 먹고 커피 한잔) 本身就是韩国上班族的午餐流程 (这也与韩国为何是“咖啡共和国”相关 → #1158)。
  • 沟通的纹理：在会议上，比起直截了当地抛出意见，更常见的是察看上司·氛围而绕着说或等待时机。这种“不说也能读懂”的感知，正是眼力见儿 (nunchi / 눈치) (→ #1145)。

> ★ 变化要点：“独食 (honbap / 혼밥，独自吃午餐)”不再奇怪 (→ #1159)，强制午餐·强制同席减少了。不过，通过“一起吃”而成为团队的情感，依然鲜活地存在着。

⑤ 聚餐与眼力见儿 — 工作结束后仍延续的关系

在韩国职场文化中，聚餐 (hoesik / 회식) 与眼力见儿 (nunchi / 눈치) 不可或缺。两者都是深主题，会以单独篇章处理，这里只点明它们在“职场系统”中的位置：

  • 聚餐 (hoesik / 회식)：工作结束后，部门一起吃喝以增进团结的场合。倒酒的顺序、干杯、一摊·二摊这类礼节与等级相互咬合。它曾是巩固奉献·归属感的装置，但如今强迫大幅减少，趋向于以“午餐聚餐·文化聚餐”的形式变得轻松。详情 → #1140 韩国聚餐·饮酒文化。
  • 眼力见儿 (nunchi / 눈치)：即使没有明确指示，也能读懂上司与团队氛围来行动的感知力。在韩国职场，“没有眼力见儿” (nunchiga eopda / 눈치가 없다) 算是相当大的缺点。过于直接地反驳或读不懂氛围，就会成为“没眼力见儿的人”。详情 → #1145 韩国眼力见儿文化。

这两者是等级·集体主义延伸到工作时间之外 (聚餐)·言语之外 (眼力见儿) 的例子。所以对外国人而言，韩国职场会让人感觉像是“工作之外的某种东西”。

⑥ ★★ 变化 — MZ世代·工作与生活平衡·扁平化

这里是本文最重要的部分。上文描绘的“僵硬的韩国职场”正飞速成为旧面貌。 韩国职场文化如今正处在世代·制度共同推动的大转变之中。

  • 工作与生活平衡 (wora-bael / 워라밸)：2015年前后开始在求职社区中使用，经过每周52小时制的讨论 (2017~2018)，成为主流话题。多项调查显示，MZ世代择业的第一要素被报告为“工作与生活平衡”，有时甚至排在薪资·退休保障之前 (数值因调查而异 — 建议核实)。
  • 扁平化：企业把扁平化沟通作为组织文化目标提出，舍弃职级称谓而引入“○○-nim (○○님)”·“pro”式称谓、简化汇报·审批的潮流随之扩散。
  • 居家·弹性办公：经历新冠疫情，居家办公 (jaetaek geunmu / 재택근무) 急剧增加 (某政府调查报告称，与疫情前相比大幅增长)。此后与回归办公室 (重返办公室) 的趋势交织，错时上下班·选择工时 (seontaek geunro / 선택근로) 这类弹性办公在越来越多的公司落地。
  • 安静离职 (Quiet Quitting)：不离开公司，但只做“恰好分内的那些”工作、收回过度奉献的态度。与把加班·奉献视为美德的过去截然相反的价值观，如今在韩国上班族中频频被提及。
  • 跳槽普遍化：“终身职场” (pyeongsaeng jikjang / 평생직장) 这个说法日渐淡化，为寻求更好的条件而跳槽 (ijik / 이직) 成了自然的职业策略。

> 均衡的图景：韩国职场依然残留等级·集体的色彩 — 因公司·行业·世代不同，差异很大。保守的大企业·制造业，与扁平·灵活的IT·初创公司，景象相当不同。核心在于它“正朝一个方向飞速变化”：上下级 → 扁平、加班 → 工作与生活平衡、终身职场 → 跳槽。

⑦ 外国人了解这种文化的好处

游客几乎没有机会亲自进入韩国公司。但即便如此，了解职场文化，韩国 (Korea / 한국) 会变得清晰得多。

  • 看懂电视剧·电影：以办公室为背景的韩剧 (上司·新人·聚餐·加班) 的张力与幽默，一旦明白为什么会这样就能理解。懂得等级·眼力见儿 (nunchi / 눈치)·准时下班的含义，场景看起来就不一样了。
  • 韩国社会的“钥匙”：职场文化是等级·集体·勤勉这一韩国社会整体代码被浓缩的地方。餐厅·商店的称谓、排队、快快 (ppalli-ppalli) 的纹理 (→ #1143)，都源自同一根脉。
  • 如果是商务访客：若有与韩国伙伴的会面·用餐场合，了解递接名片 (双手)、长者·职级高者优先、饭桌的意义，会大有帮助。
  • 看见“当下的韩国”：变化中的职场文化，正是展现韩国青年世代价值观 (工作与生活平衡·个人·公平) 的一扇窗。

❓ 外国人常见问题 (FAQ)

  • 韩国公司真的加班那么多吗？ — 过去如此，如今因行业·公司差异仍很大，但自2018年每周52小时制以来，整体呈减少趋势。越来越多的公司“准时下班”理直气壮。电视剧里的样子也有夸张成分。
  • 为什么用职级而不是名字称呼同事？ — 这是韩式的尊重礼节。直呼上级的名字是失礼。不过，越来越多的公司改用扁平称谓 (“○○-nim (○○님)”·“pro”) (→ #1150)。
  • 午餐·聚餐一定要参加吗？ — 强迫已大为减少。不过，了解“一起吃”是韩式社交、能积累关系这一点后就会明白，参加不只是单纯的义务，而是成为同事的过程。
  • 韩国职场和国外差别很大吗？ — 在等级·集体·勤勉很强这一点上，曾与西方的个人·扁平文化差异巨大。但随着MZ世代·制度变化，差距正在快速缩小。
  • “眼力见儿 (nunchi / 눈치)”是什么？在职场为什么重要？ — 是不用言明也能读懂上司·团队氛围的感知力。作为在等级社会中让关系变顺畅的核心技能，“没有眼力见儿”是相当扎心的评价 (→ #1145)。
