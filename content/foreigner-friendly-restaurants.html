⚠ 외국인 자주 실수 5가지

1. "한식 = 영어 메뉴 없음": 한국 식당 = 외국인 영어 메뉴 (이태원·명동·강남) + Naver Map 영어 + Klook 인증 + KTO 인증 + 외국인 영어 OK 1번지.

2. "외국인 친화 = 비쌈": 외국인 친화 = 광장시장 빈대떡 5K + 이문설농탕 8K + 분식 3~10K + 한식 8~25K + 외국인 가성비 1번지·#388 노포 통합.

3. "외국인 vlog #1 = 시내만": 외국인 vlog 1번지 = 광장시장 (#380 1905)·이문설농탕 (1902)·우래옥 (1946)·태극당 (1946) + 외곽 자갈치 (#244) + 외국인 매니아.

4. "외국인 영어 OK = 강남만": 외국인 영어 OK = 이태원 (#155·#144) + 명동 (#13) + 강남 (#142·#143) + 홍대 (#138) + 한남 (#293) 5 cluster + 외국인 거주 통합.

5. "외국인 영어 쿠킹 = 없음": 외국인 영어 쿠킹 = Klook 한식 쿠킹 50~150K + KKday + 발우공양 (#357 향적세계) + 외국인 매니아 1번지.
