🎯 왜 목포 가이드인가

목포 (Mokpo) = 전라남도 항구도시·일제 + 근대사 매트릭스·유달산·근대문화거리·홍어 한국 #1 시그너. 외국인 페인포인트 = (a) "목포 = 안 알려짐" 잘못된 인식 (b) 유달산 (228m) = 도심 산악·일출·일몰 매트릭스 (c) 근대문화거리 = 일제 (1897년 개항)·근대 건물 cluster (d) 홍어 = 한국 #1 시그너 매트릭스·강한 냄새·매니아 (e) KTX 2시간 30분.

본 가이드는 5축 12 시그니처 + 유달산 + 근대문화 + 홍어.

🏛 5축 deep dive

① 유달산 (228m·도심 산악)

  • 시그니처: 도심 산악 228m·일출·일몰 매트릭스·이순신 동상
  • 외국인 친화도: ★★★★ (영문 시그너·hiking + 가족)
  • 시간: 24h·무료

② 근대문화거리 (1897년 개항)

  • 시그니처: 목포 1897년 개항·일제 + 근대사 매트릭스·근대 건축 cluster
  • 외국인 친화도: ★★★★ (영문 시그너·문화 매니아)

③ 목포 홍어 (한국 #1 시그너)

  • 시그니처: 한국 #1 홍어 시그너·홍어 3합 (홍어 + 묵은지 + 돼지) 매트릭스
  • 외국인 친화도: ★★★ (호불호·매니아 매트릭스)
  • 가격: 홍어 3합 = 60,000~120,000원/2-3인용

④ 목포 해변 + 회·해산물 (남해)

  • 시그니처: 남해 신선·여수 (#1048)와 비교 매트릭스
  • 외국인 친화도: ★★★★ (영문 일부)

⑤ 1박 + 흑산도·홍도 (섬 매니아)

  • 시그니처: 흑산도·홍도 매니아 매트릭스 #1·한국 #1 섬 매니아
  • 외국인 친화도: ★★★ (매니아·1박+ 권장)

⚠ 외국인 자주 실수 5가지

1. "목포 = 안 알려짐": 항구도시·일제 + 근대사·유달산·홍어 매트릭스.

2. "유달산 = 일반 산": 도심 산악 228m·일출·일몰 매트릭스.

3. "근대문화거리 = 일반 거리": 1897년 개항·일제 + 근대사 매트릭스·매니아.

4. "홍어 = 외국인 X": 한국 #1 시그너 매니아 매트릭스·강한 냄새 호불호.

5. "흑산도·홍도 = 작은 섬": 한국 #1 섬 매니아 매트릭스·1박+ 권장.

⚙ FAQ 6개

1. 외국인 입문 1순위: 유달산 + 근대문화거리 + 회·해산물 = 1일.

2. 홍어 3합: 매니아 매트릭스·호불호 (강한 냄새)·도전 매니아.

3. 흑산도·홍도: 매니아 매트릭스·1박+ 권장·여객선 1-2시간.

4. 유달산 일출: 도심 일출 매트릭스·연중 OK.

5. 알레르기: 회·홍어·갑각류 사전 고지.

6. 추천 페르소나: 가족·시니어 = 유달산 + 근대 / MZ·인스타 = 근대 + 카페 / 매니아 = 홍어 + 흑산도 + 1박.

⚠ 의료·안전·식이 disclaimer

목포 = 안전. 홍어 = 강한 냄새 + 알레르기 가능·외국인 호불호 매트릭스. 응급 ☎ 1339·1330.
