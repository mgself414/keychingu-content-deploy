🏯 4채널 deep dive

🏯 한옥 차집 (Hanok Tea House)

핵심 가치: 전통 한옥 + 정통 차·디저트 + 인스타 1번지.

  • 추천 영역 (서울):
  • 인사동 — 전통 한과·약과 한옥 차집 cluster
  • 익선동 — MZ 한옥 차집
  • 북촌 한옥마을 — 정통 한옥
  • 삼청동 — 한옥 + 모던 융합
  • 추천 매장 (지방):
  • 전주 한옥마을 — 전통 한과·약과 차집
  • 경주 — 신라 정통 차집
  • 메뉴: 녹차·식혜·수정과·국화차·오미자·대추차 + 약과 페어
  • 가격 anchor: 5,000~12,000원
  • 외국인 친화도: ★★★★ (영문 일부)

🪷 사찰 차실 (Buddhist Temple Tea Room)

핵심 가치: 사찰 정적 + 정통 한방 차 + 할랄·코셔 #1.

  • 추천 사찰:
  • 진관사 (서울 은평구) — 외국인 친화 사찰 차실
  • 해인사 (경남 합천) — 매니아 1번지
  • 통도사 (경남 양산) — 매니아
  • 봉은사 (서울 강남) — 도심 사찰
  • 메뉴: 사찰 정통 차 (녹차·국화차·대추차) + 사찰음식 페어
  • 가격 anchor: 3,000~8,000원 (템플스테이 별도 50,000~200,000원/1박)
  • 외국인 친화도: ★★★★ (할랄·코셔·채식 #1)
  • 운영: 사찰 시간 (10:00~17:00) — 일부 외국인 일반 방문 가능 (사전 확인)

☕ MZ 한식 카페 (MZ Korean Cafe)

핵심 가치: 트렌디 + 식혜 라떼·약과 라떼·말차 라떼 + 인스타 1번지.

  • 추천 영역 (서울):
  • 홍대·연남 — MZ 한식 카페 cluster
  • 강남·역삼 — 직장인 MZ
  • 성수동 — MZ 트렌드 (블루보틀 + 약과)
  • 이태원 — 외국인 친화
  • 메뉴: 식혜 라떼·약과 라떼·말차 라떼·약과 크루아상·수정과 빙수
  • 가격 anchor: 6,000~15,000원
  • 외국인 친화도: ★★★★★ (영문·키오스크)

🏨 호텔 한식당 (Hotel Korean)

핵심 가치: 한정식 후식 + 럭셔리 + 영어 1순위.

  • 추천 호텔 (서울):
  • 신라호텔 라연 (미슐랭 3스타) — 한정식 후식 차
  • 롯데호텔 한식당 — 정통
  • 웨스틴 조선 — 럭셔리
  • 메뉴: 한정식 후식 = 녹차·식혜·수정과·약과 페어 (코스 포함)
  • 가격 anchor: 한정식 코스 포함 (100,000~500,000원)
  • 외국인 친화도: ★★★★★ (영어·예약·1순위)
  • 결제: 봉사료 10% + 부가세 10%

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 분위기·가격·체험 완전 다름. 정통 = 한옥 / 매니아 = 사찰 / 트렌디 = MZ / 럭셔리 = 호텔.

2. "한옥 차집 = 비싸기만": 인사동 한옥 차집 = 1잔 5,000원~ 가성비.

3. "사찰 차실 = 템플스테이만": 일부 사찰 = 외국인 단순 차 음용 가능 (진관사·봉은사 등). 사전 확인.

4. "MZ 카페 = 전통 X": MZ 한식 카페 = 전통 + MZ 융합 (식혜 라떼·약과 라떼).

5. "호텔 = 한정식 코스만": 호텔 후식 = 차 + 약과 + 식혜 + 수정과 풀세트 포함.

⚙ FAQ 8개

1. 첫 전통음료 = 어떤 채널: 한옥 차집 (인사동·익선동) 1순위 (가성비 + 정통).

2. 인스타·vlog: 한옥 차집 (인사동 #1)·MZ 식혜 라떼·사찰 차실 (정적).

3. 데이트·기념일: 한옥 차집 (북촌·익선동) + 호텔 한식당 (신라 라연).

4. 할랄·코셔·채식: 사찰 차실 #1 + 한옥 차집 (꿀 확인) + MZ 카페 (우유 확인).

5. 체험·교육: 사찰 템플스테이 (한방 차도) + 한옥 다도 체험 (인사동).

6. 알레르기·임신: [#840·#841 disclaimer](#840) 참조.

7. 결제·팁: 한옥·MZ = 카드 / 사찰 = 일부 현금 / 호텔 = 봉사료 10% / 팁 X.
