韩国面条指南 — 平壤冷面、荞麦面、刀切面、釜山小麦面12家 — 又来屋 (Uraeok / 우래옥)、笔洞面屋 (Pildong Myeonok / 필동면옥)、美珍 (Mijin / 미진)、明洞饺子 (Myeongdong Gyoja / 명동교자)、内湖冷面 (Naeho Naengmyeon / 내호냉면) (2026年10月官方数据)

副标题: 又来屋 (Uraeok / 우래옥) 1946年开业，周二至周日 11:30~21:00·周一休息 (米其林页面·VisitKorea) · 美珍 (Mijin / 미진) 1952年，每天 10:30~21:00 (米其林页面) · 明洞饺子 (Myeongdong Gyoja / 명동교자) 1966年，菜单只有四种 (米其林页面) · 釜山小麦面起源于难民用配给面粉做的面条 (VisitKorea) · 首尔冷面·荞麦面·刀切面必比登推介8家 — 截至2026-10-21

ISSUE 03 · #480 · 2026-05-27

🎯 如何使用本指南

接到订单之后才开始压荞麦面团，刚压出来的面条直接盛进碗里 — 米其林写道瑞草洞 (Seocho-dong / 서초동) 的襄阳荞麦拌面 (Yangyang Memil Makguksu / 양양 메밀 막국수) 就是这样做的。本指南把韩国面条分为四类：平壤冷面 (Pyeongyang Naengmyeon / 평양냉면)、荞麦面·荞麦拌面 (Makguksu / 막국수)、刀切面 (Kalguksu / 칼국수)、釜山小麦面 (Milmyeon / 밀면)·冷面。店家只选了米其林指南官网和VisitKorea旅游信息上列出的。写给想用一碗面轻松解决一顿饭的旅行者，以及第一次尝试冷面的人。

旧版指南里的"乌德基 (Udeugi / 우드기)"冷面店和"晋州冷面 (Jinju Naengmyeon / 진주냉면) 乘KTX 4.5小时"无法确认，"又来屋 (Uraeok / 우래옥) 10,000韩元"也没有出处 (2017年VisitKorea文章写的是13,000韩元 — 并非现价)。"拉面·部队锅"不是面馆，因此本期删除。部队锅在 #486 里。

🍜 平壤冷面 — 首尔3家

  • 又来屋 (Uraeok / 우래옥) — 首尔中区昌庆宫路 (Changgyeonggung-ro / 창경궁로) 62-29。周二至周日 11:30~21:00 (最后点单 20:20)，每周一及1月1日休息 (VisitKorea·米其林页面)。1946年开业。用韩牛牛腱 (Arong-sat'ae / 아롱사태) 熬成的汤底，只用盐和酱油调味。有拌冷面 (Bibim-naengmyeon / 비빔냉면)、温面 (On-myeon / 온면)、泡菜汤冷面 (Kimchi-mari Naengmyeon / 김치말이냉면)，不少人会配烤牛肉 (Bulgogi / 불고기)。电话 02-2265-0151，可停车·代客泊车 (米其林页面，必比登推介)
  • 笔洞面屋 (Pildong Myeonok / 필동면옥) — 首尔中区西涯路 (Seoae-ro / 서애로) 26 (南山谷韩屋村 (Namsangol Hanok Maeul / 남산골 한옥마을) 附近)。11:00~20:20，备料时间 16:00~17:00，每周日休息 (VisitKorea)。清爽的肉汤，猪肉白煮肉片 (Suyuk / 수육) 是招牌配菜。被介绍为适合一个人吃饭的地方。电话 02-2266-2611 (米其林页面，必比登推介)
  • 正仁面屋 (Jeongin Myeonok / 정인면옥) — 首尔永登浦区国会大路76街 (Gukhoe-daero 76-gil / 국회대로76길) 10。周一至周五 11:00~15:00·17:00~21:15，周六、周日 11:00~15:30·17:00~21:00。不加面粉、纯荞麦压制的面条，韩牛汤底配放了3年以上的天日盐。也有牛腱白煮肉片 (Arong-sat'ae Suyuk / 아롱사태 수육)、饺子 (Mandu / 만두)。可无障碍轮椅进入 (米其林页面，必比登推介)
  • 首尔冷面店完整名单见 #1130 外国人冷面索引

🌾 荞麦面·荞麦拌面 — 首尔3家

  • 美珍 (Mijin / 미진) — 首尔钟路区钟路 (Jong-ro / 종로) 19，Lemeilleur钟路城 (Lemeilleur Jongno Town / 르메이에르 종로타운) 116-2号。每天 10:30~21:00 (最后点单 20:30)，全年无休 (VisitKorea·米其林页面)。1952年开业。冷荞麦面的酱油汤底比日本荞麦面的蘸汁更浓，汤和面条在地下工厂制作。放了豆芽、豆腐、泡菜、猪肉的荞麦煎饼 (Memil-jeonbyeong / 메밀전병) 可以点半盘。电话 02-730-6198 (米其林页面，必比登推介)
  • 柳林面 (Yurimmyeon / 유림면) — 首尔中区西小门路 (Seosomun-ro / 서소문로) 139-1。周一至周六 11:00~20:00，周日休息。在西小门 (Seosomun / 서소문) 经营50多年，1980年搬到现在的位置，第三代经营。只用蓬坪 (Bongpyeong / 봉평) 荞麦和新安飞禽岛 (Bigeumdo / 비금도) 的盐压制的面条。招牌是拌荞麦面 (Bibim Memil-guksu / 비빔 메밀국수) 和放鱼糕的乌冬式粗面 (Garak-guksu / 가락국수)。吧台座位 (米其林页面，必比登推介)
  • 襄阳荞麦拌面 (Yangyang Memil Makguksu / 양양 메밀 막국수) — 首尔瑞草区东光路15街 (Donggwang-ro 15-gil / 동광로15길) 10。每天 11:00~15:00·17:00~21:00，11月腌泡菜季 (Gimjang / 김장) 会休息十天左右。100%纯荞麦，点单后才压面。荞麦拌面 (Memil Makguksu / 메밀 막국수) 和用自家泡菜做的泡菜拌面 (Kimchi Bibim-guksu / 김치 비빔국수) (米其林页面，必比登推介)

🔪 刀切面 — 首尔3家

  • 明洞饺子 (Myeongdong Gyoja / 명동교자) — 首尔中区明洞10街 (Myeongdong 10-gil / 명동10길) 29。每天 10:30~21:00。1966年起由家族经营，菜单只有四种。以刀切面和饺子 (Mandu / 만두) 闻名。经常排队。电话 +82 2-776-5348 (米其林页面，无米其林推介、必比登标识)。VisitKorea旅游信息里还列有退溪路 (Toegye-ro / 퇴계로) 129号分店，菜单是刀切面、饺子、拌面 (Bibim-guksu / 비빔국수)、豆浆面 (Kongguksu / 콩국수)
  • 黄生家刀切面 (Hwangsaengga Kalguksu / 황생가 칼국수) — 首尔钟路区北村路5街 (Bukchon-ro 5-gil / 북촌로5길) 78。11:00~21:30 (最后点单 20:30)，春节 (Seol / 설)、中秋 (Chuseok / 추석) 当天休息 (VisitKorea)。2001年以"北村刀切面 (Bukchon Kalguksu / 북촌칼국수)"开业，2014年改名。牛骨汤刀切面，每天早上在入口处现包的大饺子 (Wang-mandu / 왕만두)，以及夏季限定的豆浆面 (米其林页面，必比登推介)
  • 任炳柱山东刀切面 (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수) — 首尔瑞草区江南大路37街 (Gangnam-daero 37-gil / 강남대로37길) 65。周二至周五 11:00~21:30，周六、周日 11:00~21:00，周一休息。1988年开业，每天手擀面条，清澈的汤里放足蛤蜊。也有平壤式大饺子 (Wang-mandu / 왕만두) 和豆浆面 (Kongguksu / 콩국수)。仅收现金，可一个人用餐 (米其林页面，必比登推介)

🌊 釜山小麦面·冷面 — 3家

  • 釜山内湖冷面 (Busan Naeho Naengmyeon / 부산 내호냉면) — 釜山南区牛岩繁荣路26街 (Uam-beonyeong-ro 26beon-gil / 우암번영로26번길) 17 (牛岩市场 (Uam Sijang / 우암시장) 小巷)。10:30~19:00 (最后点单 18:30)，全年无休。水冷面 (Mul-naengmyeon / 물냉면)、拌冷面 (Bibim-naengmyeon / 비빔냉면)、拌小麦面 (Bibim-milmyeon / 비빔밀면)。朝鲜战争时难民用配给的面粉做成的面条是釜山小麦面的起点，现在由第四代传承。电话 0507-1333-6195 (VisitKorea)
  • 开琴小麦面 (Gaegeum Milmyeon / 개금밀면) — 釜山釜山镇区伽倻大路482街 (Gaya-daero 482beon-gil / 가야대로482번길) 9-4 (开琴洞 (Gaegeum-dong / 개금동))。11:00~19:40，全年无休。水小麦面 (Mul-milmyeon / 물밀면)、拌小麦面 (Bibim-milmyeon / 비빔밀면)。这是自助式餐厅：先在入口点单付款，号码机响了就自己去取。汤里放甘草、当归、肉桂之类的药材。电话 051-892-3466 (VisitKorea)
  • 佛陀面屋 (Buda Myeonok / 부다면옥) — 釜山海云台区中洞1路 (Jungdong 1-ro / 중동1로) 36，2楼。100%纯荞麦平壤冷面，韩牛汤底中混入蔬菜高汤。也推荐牛尾牛肉清汤 (Sokkori Gomtang / 소꼬리 곰탕)。2021年从半如洞 (Banyeo-dong / 반여동) 搬来。电话 +82 51-746-8872 (米其林页面，必比登推介)。米其林页面按星期列出的营业时间只显示了一个星期几，因此未能确认营业时间 — 请电话确认
  • 釜山美食总览见 #1320 只在釜山吃的三样

🥗 饮食

  • 价格区间: 12家都没有官方公布的韩元价格。米其林页面上只有 ₩ 符号 (最低一档)
  • 素食: 冷面汤底用牛肉熬 (又来屋 (Uraeok / 우래옥)、正仁面屋 (Jeongin Myeonok / 정인면옥)、佛陀面屋 (Buda Myeonok / 부다면옥))，刀切面用牛骨 (黄生家 (Hwangsaengga / 황생가)) 或蛤蜊 (任炳柱 (Im Byeong-ju / 임병주)) 熬汤 (米其林页面)。小麦面的汤底也是鸡骨、牛骨、猪骨 (VisitKorea)。VisitKorea把豆浆面列为适合素食的食物，但写明可能会放鸡蛋作配料 — 黄生家 (Hwangsaengga / 황생가) 和任炳柱 (Im Byeong-ju / 임병주) 的豆浆面是夏季菜单
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00) 是少数获韩国伊斯兰教中央会 (KMF) 认证为清真的餐厅之一。本指南里的面馆没有清真标识
  • 过敏: 荞麦 (美珍 (Mijin / 미진)、柳林面 (Yurimmyeon / 유림면)、襄阳 (Yangyang / 양양)、平壤冷面店)、小麦 (刀切面、小麦面)、贝类 (任炳柱 (Im Byeong-ju / 임병주) 的蛤蜊)、大豆 (豆浆面)
  • 出示用的卡片见 #1300 饮食需求手册

🧰 面条实用信息 — 独自用餐、预约、付款、点餐、交通

  • 独自用餐: 面条是一人一碗，很适合一个人去。米其林把笔洞面屋 (Pildong Myeonok / 필동면옥) 和任炳柱山东刀切面 (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수) 标为适合独自用餐，柳林面 (Yurimmyeon / 유림면) 设有吧台座位。单人用餐地图见 #348 Seoul Solo Diner Map
  • 预约: 官方页面都只写"直接打电话给餐厅"。午餐时间要做好排队的准备 (正仁面屋 (Jeongin Myeonok / 정인면옥)、明洞饺子 (Myeongdong Gyoja / 명동교자)，米其林页面)
  • 付款: 任炳柱山东刀切面 (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수) 仅收现金 (米其林页面)。开琴小麦面 (Gaegeum Milmyeon / 개금밀면) 在入口先付款 (VisitKorea)。刷卡和移动支付见 #527 韩国支付系统
  • 点餐: 冷面要在水 (Mul / 물，带汤) 和拌 (Bibim / 비빔) 之间选一种。吃面方法见 #814 韩国面类点餐·吃法流程，语言不通时见 #1339 点餐礼仪
  • 交通: 首尔见 #1298 三种交通卡怎么选，釜山见 #1325 釜山公共交通语法

⚠ 常见的4个误区

1. "周一去又来屋" — 又来屋 (Uraeok / 우래옥) 每周一休息 (VisitKorea·米其林页面)。笔洞面屋 (Pildong Myeonok / 필동면옥) 和柳林面 (Yurimmyeon / 유림면) 周日休息

2. "豆浆面一直都有" — 黄生家刀切面 (Hwangsaengga Kalguksu / 황생가 칼국수) 的豆浆面 (Kongguksu / 콩국수) 仅限夏季 (米其林页面)

3. "哪里都能刷卡" — 任炳柱山东刀切面 (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수) 只收现金 (米其林页面)

4. "小麦面和冷面一样" — 小麦面用面粉和淀粉制成，比冷面更软，是用放了药材的汤底的釜山乡土面条 (VisitKorea)
