外国游客常犯的 3 个错误

1. 认为小吃 (Bunsik / 분식) = 辣炒年糕

韩国小吃 (Bunsik / 분식) 的意思是"在小吃店售卖的轻食合集"，辣炒年糕 (Tteokbokki / 떡볶이)·紫菜包饭 (Gimbap / 김밥)·顺大 (Sundae / 순대)·辣炒年糕面 (Rabokki / 라볶이)·炸物 (Twigim / 튀김)·鱼糕 (Eomuk / 어묵) 全部包含。只吃辣炒年糕等于错过小吃体验的 50%。初次到访推荐辣炒年糕 + 紫菜包饭 + 鱼糕汤这三件套正统组合。

2. 担心广藏市场 (Gwangjang Sijang / 광장시장) 摊位对外国人有差别待遇

这是误解。广藏市场摊位早已习惯接待外国游客，并备有英文菜单。不过由于排队 + 现金结账的摊位较多，建议提前准备约 ₩30,000 现金。并非拒绝刷卡，而是部分摊位没有刷卡设备。

3. 点辣炒年糕前未确认辣度

韩国辣炒年糕的平均辣度对外国游客来说接近极限。乔斯辣炒年糕 (Joseu Tteokbokki / 鲨鱼 (Joseu / 죠스떡볶이))·国大辣炒年糕 (Gukdae Tteokbokki / 国队 (Gukdae / 국대떡볶이)) 可调节辣度 (不辣/普通/辣)。广藏市场·新堂洞老字号的酱料浓度固定，建议先在一家试吃后再决定下一家。

2. 精选 8 处 (4轴均衡)

2-1. 市场老字号 3 处 — 小吃的发源地

① 马福林辣炒年糕 (Mabokrim Tteokbokki / 马卜林 (Mabokrim / 마복림 떡볶이)) — 新堂洞 (Sindangdong / 신당동)

1953 年创业，韩国辣炒年糕发源地首选。新堂站 (Sindang Station / 신당역) 1 号出口步行 3 分钟。人均 ₩6,000~₩8,000。新堂洞即席辣炒年糕街 (Sindangdong Jeukseok Tteokbokki Street / 신당동 즉석 떡볶이 거리) 本家 — 即席辣炒年糕是在食客面前当场加入蔬菜·拉面·芝士煮制的形式。推荐 4 人以上 (最低 2 人份起点)。适合外国家庭·MZ 团体。备有英文菜单 + 部分员工会英语。

② 广藏市场麻药紫菜包饭 (Gwangjang Mayak Gimbap / 广藏市场迷你紫菜包饭 (Gwangjang Mayak Gimbap / 광장시장 마약김밥)) — 广藏市场 (Gwangjang Sijang / 광장시장)

外国游客知名度第 1 的小吃。钟路五街站 (Jongno 5-ga Station / 종로5가역) 8 号出口步行 3 分钟。人均 ₩4,000~₩6,000 (麻药紫菜包饭 1 卷 + 鱼糕)。麻药紫菜包饭 (一口小紫菜包饭) + 绿豆煎饼 (Bindaetteok / 빈대떡) + 生拌牛肉 (Yukhoe / 육회) 三件套是广藏市场小吃的精髓。摊位形式 + 拼桌自然。一人 OK，工作日排队约 30 分钟 / 周末 1~2 小时。备有英文菜单，优先现金 (建议携带 ₩30,000)。

③ 顺姬家绿豆煎饼 (Sunhuine Bindaetteok / 顺姬家 (Sunhuine / 순희네 빈대떡)) — 广藏市场 (Gwangjang Sijang / 광장시장)

1970 年代起营业，广藏市场绿豆煎饼老字号。钟路五街站 (Jongno 5-ga Station / 종로5가역) 8 号出口步行 4 分钟。人均 ₩7,000~₩10,000 (绿豆煎饼 1 张 + 米酒 (Makgeolli / 막걸리))。100% 绿豆煎饼 + 米酒组合是韩国美食爱好者的首选。虽属小吃但适合搭配酒类享用，适合夜间行程。部分英文菜单，可刷卡。

2-2. MZ 潮流 2 处 — SNS 人气

④ 乔斯辣炒年糕 (Joseu Tteokbokki / 죠스떡볶이) — 全国连锁

MZ 世代 + 外国游客知名度高的辣炒年糕连锁。明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남) 等 80+ 门店。人均 ₩5,000~₩9,000。辣度 4 级可调 + 杯装辣炒年糕 (外带 OK)。在 K-idol·K-剧中曝光频率↑。备有英文菜单，员工英语熟练。一人 OK，无需预约。外国游客辣炒年糕初体验 + 高性价比首选。

⑤ 国大辣炒年糕 (Gukdae Tteokbokki / 국대떡볶이) — 全国连锁

MZ 世代·青年人气辣炒年糕连锁。弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남)·新村 (Sinchon / 신촌) 等 100+ 门店。人均 ₩6,000~₩10,000。国大即席辣炒年糕 + 辣炒年糕面 + 多样配菜。辣度略强于乔斯，辣度可调 OK。是 SNS·Instagram 曝光最频繁的辣炒年糕连锁之一。一人 OK。

2-3. 连锁高性价比 2 处 — 24h + 外国人友好

⑥ 紫菜包饭天国 (Gimbap Cheonguk / 김밥천국) — 全国连锁

24 小时紫菜包饭 + 综合小吃连锁。全国 1,500+ 门店，明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남) 均有。人均 ₩4,000~₩7,000。紫菜包饭 + 辣炒年糕 + 拉面 + 顺大 + 炸物一应俱全的综合小吃店。外国游客知名度↑，部分门店有英文菜单。适合深夜聚餐收尾 + 夜间观光客 + 留学生高性价比路线。

⑦ 高峰民紫菜包饭 (Gobongmin Gimbap / 高峰民 (Gobongmin / 고봉민김밥인)) — 全国连锁

紫菜包饭高端连锁 (价位比紫菜包饭天国高一档)。江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대)·梨泰院 (Itaewon / 이태원) 等 200+ 门店。人均 ₩6,000~₩9,000。食材新鲜度 + 厚实紫菜包饭为招牌。外国美食爱好者比起紫菜包饭天国更推荐此处 — 食材差异明显。一人 OK，备有英文菜单。

2-4. 特色新兴 1 处 — MZ 潮流辣炒年糕面

⑧ 宴宴庆 (Anjanjanchi / 안잔잔치)辣炒年糕面 (Anjanjanchi Rabokki / 宴宴庆 (Anjanjanchi / 안잔잔치 라볶이)) — 江南 (Gangnam / 강남)

辣炒年糕面专门新兴店铺 (虚拟名称，代表江南·弘大潮流店) (Anjanjanchi Rabokki / 안잔잔치 라볶이)。江南站 (Gangnam Station / 강남역) 步行 5 分钟。人均 ₩10,000~₩14,000。辣炒年糕 + 拉面 + 芝士 + 饺子辣炒年糕面全套。Instagram·Reels 曝光频率↑，MZ 世代辣炒年糕面首选。一人 OK，周末建议预约。

4. FAQ 8 问

Q1. 广藏市场 (Gwangjang Sijang / 광장시장) 外国人可以单独前往吗？

A. 可以，非常友好。麻药紫菜包饭摊位习惯接待外国游客 + 英文菜单 + 图片菜单。拼桌自然，单人外国游客众多。但工作日午餐·周末排队需 30 分钟~2 小时，请留出充裕时间。

Q2. 辣炒年糕可以调节辣度吗？

A. 连锁店可调 4 个辣度等级 (乔斯·国大·紫菜包饭天国)。广藏市场·新堂洞老字号辣度固定。辣度偏低推荐乔斯·国大，想体验正宗辣度请选马福林·新堂洞街。

Q3. 广藏市场 (Gwangjang Sijang / 광장시장) 可以刷卡吗？

A. 麻药紫菜包饭·绿豆煎饼摊位优先现金 (部分摊位无刷卡设备)。建议携带约 ₩30,000 现金。新堂洞·连锁店刷卡·移动支付 OK。

Q4. 有英文菜单 + 英语服务吗？

A. 所有精选店铺均备有英文菜单。英语服务以连锁店 (乔斯·国大·紫菜包饭天国·高峰民) 最为熟练。广藏市场摊位以韩语为主，配合图片菜单 + 手势肢体语言完全够用。

Q5. 哪些店铺可以一人前往？

A. 8 家店铺均可一人到访。小吃的核心 — 分量小·用餐快，单人友好。广藏市场麻药紫菜包饭通过拼桌一人入座很自然。

Q6. 小吃 + 饮料搭配推荐？

A. 广藏绿豆煎饼 + 米酒 (Makgeolli / 막걸리) (传统)。辣炒年糕 + 可乐或雪碧 (MZ 正统)。紫菜包饭 + 鱼糕汤 (高性价比 + 精髓)。辣辣炒年糕 + 牛奶 (缓解辣味)。

Q7. 有纯素·清真选项吗？

A. 部分紫菜包饭种类可素食 (去掉金枪鱼·鸡蛋即可)。辣炒年糕含鱼糕·肉类，纯素较难。高峰民紫菜包饭 (Gobongmin Gimbap / 고봉민김밥인) 提供素食紫菜包饭选项，可单独点餐。清真认证在韩国小吃店几乎没有。

Q8. 小吃的分量如何？

A. 一人小吃全套 = 辣炒年糕 + 紫菜包饭 1 卷 + 鱼糕 = 约 ₩12,000，分量充足。辣炒年糕面分量大，1 人份 ≈ 1.5 人分量 (常有剩余，单人建议点 2/3 份)。
