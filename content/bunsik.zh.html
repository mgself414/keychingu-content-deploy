首尔小吃店（粉食）指南——炒年糕·紫菜包饭·血肠·饺子去哪吃：5条小吃街与6家收录名店（2026年10月官方信息）

副标题: 新堂洞炒年糕城（马福林炒年糕 1953年起，工作日09~23时·每月第二、四个周一休息）· 广藏市场 小吃街每天09~23时（钟路5街站 8号口）· 新林洞血肠城（新林站 3·1号口168m，标价1万韩元左右）· 明洞饺子（米其林必比登推介，每天10:30~21时）· 饺子家（狎鸥亭，米其林）· 新沙市场炒年糕（二手信息）——以2026-10-08 VisitSeoul·米其林为准。连锁店的门店数量和价目表没有官方出处，已删去

🎯 本指南使用方法

旧版“8选”把马福林写成“韩国炒年糕发祥地第一名”（VisitSeoul只说是“新堂洞炒年糕城的元祖”），还收了并不存在的店（“Anjanjanchi 拉炒年糕”——旧版正文自己写明是虚构名称），而“新堂站1号口3分钟”“人均6,000~8,000韩元”、连锁店门店数（Jaws 80+、Kimbap Cheonguk 1,500+等）和价目表全都没有出处。这次只写2026-10-08亲自打开VisitSeoul和米其林页面确认过的店，Time Out标为“二手信息”。价格只写页面上登载的。

🍜 什么是粉食——5种

  • 炒年糕 (Tteokbokki / 떡볶이)（条形年糕+辣椒酱调味）· 紫菜包饭 (Gimbap / 김밥)（把米饭和蔬菜·火腿用紫菜卷起来，广藏市场卖的是迷你的麻药紫菜包饭 (Mayak Gimbap / 마약김밥)）· 血肠 (Sundae / 순대)（猪肠里灌冬粉和猪血，新林是炒着吃）· 炸物·炸紫菜卷 (Gimmari / 김말이) · 饺子·刀切面（明洞饺子 (Myeongdong Kyoja / 명동교자)和饺子家 (Mandujip / 만두집)比起小吃店更像餐馆）。辣度和食材每家不同，点餐前先问一下。连锁店（Jaws·Gukdae·Kimbap Cheonguk·Gobongmin）的门店数和素食选项没有找到官方出处，所以不写。

🗺 两条路线

  • A 市场半日游: 钟路5街站 (Jongno 5-ga / 종로5가역) 8号口 广藏市场 (Gwangjang Market / 광장시장) 小吃街（麻药紫菜包饭 (Mayak Gimbap / 마약김밥)·绿豆煎饼 (Bindaetteok / 빈대떡)）→ 乙支路方向 → 明洞饺子 (Myeongdong Kyoja / 명동교자)（21时前）。
  • B 炒年糕对比: 新堂洞炒年糕城 (Sindang-dong Tteokbokki Town / 신당동 떡볶이 타운) 马福林炒年糕 (Maboklim / 마복림 떡볶이)（工作日，避开第二、四个周一）→ 晚上去新林洞血肠城 (Sillim-dong Sundae Town / 신림동 순대타운)（新林站 (Sillim / 신림역) 3号口）。

⚠ 常见失误5条

1. 第二、四个周一去马福林——休息。

2. 周日去广藏主市场——休息。小吃街营业。

3. 周日去饺子家——休息。

4. 轻信旧价目表——官方标价只有新林1万韩元左右、BBQ等少数几处。

5. 找“Anjanjanchi 拉炒年糕”——并不存在。

⚙ FAQ 6条

1. 炒年糕的元祖？——新堂洞炒年糕城的元祖马福林炒年糕 (Maboklim / 마복림 떡볶이)（1953年起，VisitSeoul）。

2. 紫菜包饭呢？——广藏市场 (Gwangjang Market / 광장시장) 小吃街的麻药紫菜包饭 (Mayak Gimbap / 마약김밥)（VisitSeoul）。

3. 米其林小吃？——明洞饺子 (Myeongdong Kyoja / 명동교자)（必比登推介，每天10:30~21时）。

4. 血肠呢？——新林洞血肠城 (Sillim-dong Sundae Town / 신림동 순대타운)，新林站 (Sillim / 신림역) 3·1号口168m。

5. 要花多少钱？——页面上标价的只有新林1万韩元左右和新沙市场炒年糕3,000韩元（二手信息）。

6. 不能吃辣怎么办？——点餐前确认辣度。刀切面和饺子比较稳妥。
