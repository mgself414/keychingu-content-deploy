한국 국밥 6종 매트릭스 — 해장의 정수와 서민의 한 그릇

> 부제: 외국인 관광객용 순대·설렁탕·곰탕·돼지국밥·육개장·콩나물국밥 + 지역별 특색 + 외국인 추천

ISSUE 03 · #807 · 2026-06-07

🎯 왜 한국 국밥 매트릭스인가

외국인 한국 국밥 페인포인트 = "국+밥인데 왜 종류가 이렇게 많아?". 한국 국밥은 단순 "soup with rice"가 아닌 재료·지역·시간대·계절에 따라 6종 이상 차별화. 같은 "국밥"이라도 순대국밥 (평안·전라 차이) / 설렁탕 (서울 양반 가문 시그니처) / 곰탕 (명동 노포) / 돼지국밥 (부산 1번지) / 육개장 (매운 해장) / 콩나물국밥 (전주 해장 1번지). 외국인은 (a) 메뉴판 단어 못 읽거나 (b) 어떤 게 매운지 모르거나 (c) 부속고기·내장 거부감 (d) 양념 가감 모름. 본 가이드는 6종 매트릭스 + 외국인 입문 우선순위 + 지역별 매장 시그니처.

🍲 국밥 deep dive 6 섹션

🩸 순대국밥 (Sundae-gukbap)

  • 시그니처: 광장시장 순대골목 (종로) / 신림동 순대타운 (관악) / 평양식 (실향민) vs 전라식 (구수)
  • 외국인 진입 장벽: 순대 = blood sausage (돼지 피·당면·찹쌀). 첫 한국 음식으론 비추
  • 추천 토핑: 양념장 (다대기) + 새우젓 + 들깨가루
  • 양 가감: "다대기 적게" (less spicy paste) / "들깨 많이" (more perilla powder)

🐮 설렁탕 (Seolleongtang) — 외국인 입문 1순위

  • 시그니처: 명동 이문설농탕 (1907 한국 #1 노포) / 종로 신선설농탕
  • 외국인 입문도 ★★★★★: 흰 국물·맵지 않음·소금/후추로 양념 조절
  • 먹는 법:

1. 그릇 받자마자 소금 1티스푼 + 후추 (간 안 되어 나옴)

2. 송송 썬 파 + 다진 양념 추가

3. 깍두기·김치와 함께 (모든 노포에 무료 제공)

4. 밥은 말아 먹기 OR 따로 먹기

  • 가격 anchor: 12,000~18,000원 + 수육 옵션 (15,000원~)

🍖 곰탕 (Gomtang)

  • 시그니처: 종로 하동관 (1939 한국 #2 노포) / 광화문 황생가
  • 설렁탕과 차이: 맑은 국물 + 진한 소고기 맛 (vs 설렁탕 뽀얀 국물)
  • 추천 매장: 하동관 곰탕 = 서울 노포 정통, 외국인 매니아 #1 노포 체험
  • 가격: 13,000~18,000원 (수육 추가 10,000원)

🐷 돼지국밥 (Dwaeji-gukbap) — 부산 1번지

  • 시그니처: 자갈치·부평·서면 노포 cluster
  • 밀양식 vs 부산식:
  • 밀양식 = 맑은 국물, 새우젓
  • 부산식 = 진한 국물, 부추·고추 양념
  • 추천 매장: 부산 서면·자갈치 노포 cluster (개별 매장명은 NAVER/Kakao map 사전 확인 권장 — 이전·재개점 빈번)
  • 외국인 친화도: ★★★★ (부산 관광 1순위 음식, 영문 메뉴 多)
  • 가격: 10,000~14,000원

🌶 육개장 (Yukgaejang)

  • 시그니처: 대구 동인동 cluster (따로국밥 시작) / 광화문 효자동 노포
  • 매운맛: 고춧가루 + 다대기. 외국인 매운맛 입문 추천
  • 재료: 소고기·고사리·대파·달걀 (장례식 한국 정통 음식)
  • 추천: 더운 여름 = 이열치열 / 겨울 = 해장
  • 가격: 11,000~16,000원

🌱 콩나물국밥 (Kongnamul-gukbap) — 전주 해장 1번지

  • 시그니처: 전주 풍남문 옛집 (전주 비빔밥과 함께 한국 #1 cluster) — 비빔밥 가이드 cross-link
  • 삼백집 vs 옛집: 삼백집 = 매운 다대기 / 옛집 = 새우젓 + 김치
  • 외국인 친화도: ★★★★ (가성비 + 가벼움 + 해장 효과)
  • 재료: 콩나물 + 달걀 (수란) + 새우젓 + 고춧가루
  • 먹는 법:

1. 수란 (poached egg)을 국물에 깨뜨려 풀기

2. 새우젓 1티스푼 추가

3. 김 가루 + 고춧가루 가감

  • 가격: 8,000~12,000원 (전주 현지 = 7,000원~)

🍶 술 + 국밥 페어링 (해장의 정수)

국밥 페어링 술 효과
설렁탕·곰탕 소주·약주 담백 페어링
돼지국밥 소주·맥주 부산 1번지 클래식
콩나물국밥 콩나물국 (술 없음) 해장 1순위 다음날 해장
육개장 소주 (매운맛 진정) 매운 페어링
순대국밥 소주 평안 정통

> 한국식 패턴: 1차 BBQ·회 + 술 → 2차 → 해장으로 콩나물국밥·설렁탕 (다음 날 아침)

⚠ 외국인 자주 실수 5가지

1. "국밥 = 다 비슷": 6종 모두 재료·맛·지역·매장 완전 다름. 메뉴판 한국어 읽기 어려우면 사진 메뉴·번역 앱 활용.

2. "설렁탕 = 처음부터 간 있음": 설렁탕·곰탕은 간 안 되어 나옴. 본인이 소금·후추·다진 양념 추가. (외국인이 자주 무미하다고 느낌)

3. "순대 = 일반 sausage": 순대 = blood sausage (돼지 피·당면·찹쌀). 첫 한국 음식엔 비추, 호기심 매니아용.

4. "콩나물국밥 = 가벼우니 식사 끝": 해장 음식. 전주·광주 매장은 김 가루·새우젓·고춧가루 세팅 활용.

5. "육개장 = 모든 매운맛 동급": 육개장 = 중-매운맛 (입문 추천). 김치찌개·낙지볶음보다 약함.

⚙ FAQ 8개

1. 외국인 입문 1순위: 설렁탕 또는 곰탕 (흰/맑은 국물, 맵지 않음, 양반 정통).

2. 해장 1순위: 콩나물국밥 (전주). 가벼움 + 새우젓 효과.

3. 매운맛 입문: 육개장 (중-매운맛). 김치찌개보다 약함.

4. 지역 매니아 1번지: 부산 = 돼지국밥 / 전주 = 콩나물국밥 / 대구 = 따로국밥 / 명동 = 설렁탕.

5. 알레르기: 소·돼지·콩·달걀·새우젓 + 글루텐(다대기에 간장) 사전 고지.

6. 채식·할랄·코셔: 6종 중 채식 X. → [#799 채식·비건 매트릭스](799_외국인_한국_채식_비건_매트릭스_12선_deep_dive.md) 참조.

7. 결제·팁: 카드 OK / 노포 일부 현금 권장 / 팁 문화 없음.

8. 시간대: 점심·저녁 동일 가격 (할인 없음). 해장은 다음날 아침 06:00~10:00 노포 매니아.

⚠ 의료·안전·식이 disclaimer

국밥 = 뜨거운 국물 (90~100°C). 화상 주의 (특히 어린이 — 그릇 멀리, 식힌 후 제공). 임신부 = 새우젓·다대기 염분 과다 주의 (콩나물국밥·돼지국밥). 면역저하 = 충분 익힌 국물 OK. 어린이 = 매운맛 (육개장·돼지국밥) 가감 또는 흰 국물 (설렁탕·곰탕) 권장. 알레르기 (소·돼지·콩·달걀·새우젓 + 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.
