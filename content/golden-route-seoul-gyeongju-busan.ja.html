韓国ゴールデンルート① ソウル→慶州→釜山、どの順番で何泊ずつ — ソウルを削り、慶州で泊まる

副題: 初めての韓国旅行はソウル・慶州・釜山の三都市が定番です。Redditには毎週「日程表を見て」が上がり、質問は同じ — 順番・泊数・慶州は寄る価値があるか。答えは一方向 — ソウルからKTXで南下し慶州で一泊、釜山で三泊、再びソウルへ。7・8・10日の配分表です。

ISSUE · #1372 · 2026-09-10

🎯 フレーム — 一方向に南下する

韓国を初めて訪れる人の日程表は、たいてい三都市に収束します。首都ソウル、新羅千年の慶州、海の釜山。三都市は一本の線の上にあります — 京釜高速線 (Gyeongbu High-Speed Line / 경부고속선)がソウルから釜山まで南下し、その線上に慶州駅 (Gyeongju Station / 경주역)があります。だから順番に迷う余地はありません。ソウル→慶州→釜山、そして釜山からKTXでソウルに戻り、飛行機に乗ります。

Redditでこのルートについて聞く投稿の三つに一つは「日程表を見てほしい」という形式です。返信はいつも似た方向に収束します — ソウルに詰め込みすぎ、釜山は一日二ヶ所で十分、慶州は日帰りせず泊まれ。今回はその収束値を一枚にまとめたものです。

  • 全体構成: ソウル3〜5泊 → 🚄 約2時間 → 慶州1〜2泊 → 🚄 約30分 → 釜山3泊 → 🚄 約2時間40分 → ソウル(仁川出国)
  • 運賃(2026-09-01統合値下げ基準): ソウル–釜山一般室54,400ウォン、ソウル–慶州4万ウォン台、慶州–釜山1万ウォン前後 — 三枚合わせて10万ウォン前後
  • 総日数: 7日・8日・10日の三案(下記📅)
  • 下車する場所: 駅三ヶ所のみ。観光地は都市別の回(#1115・#1366・#1114など)が担当

なぜこの順番なのか — 地理、荷物、時刻表

地理。 慶州駅と釜山駅はKTXで30分あまりです。ソウルから慶州までが2時間なので、慶州は釜山への「途中」にあるわけです。釜山を先に行くと、慶州を見てから釜山方面に戻ってソウルへ上るか、慶州からソウルへ直接上るしかありません — どちらにしても一区間が無駄になります。Redditのあるコメントがその混乱を的確に突いています。"geographically speaking, gyeongju then busan would make more sense."

荷物。 このルートで一番よく出る実務上の悩みは、観光ではなく鞄です。"I'll have a heavy suitcase, so I'd prefer fewer hotel changes" — ソウルで買い物をすると荷物が増えます。だからソウルを前に置くと膨らんだ荷物を持って慶州・釜山を回ることになり、ソウルを後に置くと最後に買います。どちらも答えになります。今回はソウルを前に置きつつ、買い物は最後のソウル半日か釜山で済ませる配分にします。慶州の一泊は身軽な荷物で — 大きな鞄は宿に預けて動く日です(#1373)。

時刻表。 ソウル→慶州のKTXは午前便が多く、釜山→ソウルは夕方便が多いです。朝に南下し夕方に上る方向が時刻表と噛み合います。逆方向(釜山入国→ソウル出国)も可能です — 金海国際空港 (Gimhae / 김해공항)に日本・中国・東南アジアの国際線があるので、そちらから来る人は釜山in・ソウルoutに逆転させればよいです。今回は仁川国際空港 (Incheon / 인천공항)in/out基準です。

📖 物語1 — 慶州は後から割り込んだ: 1905年に敷かれた京釜線 (Gyeongbu Line / 경부선)鉄道はソウルと釜山を結ぶ線で、2004年のKTXもその線を走りました。慶州がこの線に乗ったのは2010年11月、京釜高速線の2段階開通で旧新慶州駅 (former Singyeongju Station / 구 신경주역)ができてからです。駅は市街地ではなく西の乾川邑 (Geoncheon-eup / 건천읍)に置かれました — 市街地を通せば新羅の古墳と寺跡に触れるため、文化財を避けて迂回した路線です。そのため慶州は「駅から市街地まで30分」という乗り換えがついて回る街になりました(#1373)。2023年、この駅はただの慶州駅になり、市街地にあった旧慶州駅は2021年末に閉じました。

🚶 コース — 駅三ヶ所、下車三回

起点はソウル駅 (Seoul Station / 서울역)または水西駅 (Suseo Station / 수서역) — どちらもKTXです。2026年9月1日から水西発SRTがKTXに統合され、アプリ一つ — Korail Plus アプリ (코레일+) — で済みます(#1374)。仁川国際空港からソウル駅までは空港鉄道 AREX (공항철도)です。

① ソウル駅→慶州駅 (🚄 約2時間)

  • 朝の便に乗ります。慶州駅は市街地西の乾川邑にあります — 降りたら市街地までさらに移動が必要です。表記は「慶州駅(旧新慶州駅)」。地図アプリに旧名のまま残っていても同じ駅です。

② 慶州駅→皇理団キル (🚌 約30分・1〜2泊)

  • 市内バス50・51・70番または座席バス700番台が市街地に入ります(約30分、慶州市バス情報で当日確認)。タクシーは約20km、1万ウォン台後半。宿は大陵苑 (Daereungwon / 대릉원)隣の皇理団キル (Hwangnidan-gil / 황리단길)・皇南洞 (Hwangnam-dong / 황남동) — 夜景(#1366)と市街地移動が徒歩でこなせる唯一の軸です。
  • 1泊が基本、仏国寺 (Bulguksa / 불국사)・石窟庵 (Seokguram / 석굴암)まで見るなら2泊(#1373で決定)。

③ 皇理団キル→慶州駅→釜山駅 (🚌 約30分+🚄 約30分)

  • 再びバスで駅に出てKTX30分。または市街地の慶州市外バスターミナル (Gyeongju Intercity Bus Terminal / 경주 시외버스터미널)から釜山老圃バスターミナル (Nopo / 노포)行き市外バス約50分(1日50便前後、7,700ウォン) — 宿が市街地なら市外バスの方が楽です。両者の比較は#1373。

④ 釜山駅→西面 (🚇 約10分・3泊)

  • 釜山駅 (Busan Station / 부산역)から釜山地下鉄1号線で西面 (Seomyeon / 서면)へ。釜山3泊は1日2ヶ所の原則(#1114・#1325)。大きな鞄を持って市内バスに乗らないこと — 地下鉄・タクシーを使います。

⑤ 釜山駅→ソウル駅 (🚄 約2時間40分) — 締めくくり

  • 夕方便で上りソウルで最後の夜。翌日は空港鉄道 AREXで仁川へ。釜山から直接出国(金海)する逆方向案はFAQ5。

📖 物語2 — なぜみんなソウルに7泊入れるのか: 旅を終えた人たちの回顧は一方向です — ソウルは思ったより毎日が似ていて、慶州と釜山は思ったより短かった。ソウルは「見るもの」ではなく「暮らすもの」なので、一週間入れても残るものが少ない。だから今回はソウルから一日を削って慶州に回します。新羅 (Silla / 신라)の古墳の間を夜に歩く一日は、ソウルの六つ目のカフェ横丁より長く記憶に残ります。

📅 何泊ずつ — 7・8・10日の三案

Redditの日程表で実際に使われた配分を集めると、ソウル5〜7泊・慶州1〜3泊・釜山3〜4泊が多いです。ほとんどが「ソウルが長い」という返信を受けます。以下がその収束値です。

日数 ソウル 慶州 釜山 ソウル(締め) 備考
7日 3泊 1泊 2泊 0〜1泊 最終日に釜山→ソウル→仁川直行ならソウル0泊
8日 3泊 1〜2泊 3泊 1泊 標準。慶州2泊なら仏国寺・石窟庵込み
10日 4泊 2泊 3泊 1泊 ソウル4泊に近郊1日(#1104)可能
  • 慶州1泊: 午後到着→夜景→翌朝出発。2泊: 仏国寺・石窟庵(市街地からバス40分)を1日追加。
  • 釜山3泊: 海雲台 (Haeundae / 해운대)・広安里 (Gwangalli / 광안리)で1日、旧市街・チャガルチ (Jagalchi / 자갈치)で1日、余裕の1日。1日2ヶ所(#1114)。
  • ソウルは削る方が正解です。7日なら3泊で十分(#228はソウル専用7日 — 今回とは別の案)。

🙏 マナー — 列車と宿

  • KTXの座席は指定席。大きな鞄は車両端の荷物置き場に、通路には置きません。
  • 韓屋の宿(慶州)はチェックイン時刻が遅い所が多いです。事前に荷物を預けられるか問い合わせます。
  • 車内の通話・動画視聴はイヤホン。「静かな車両」という概念がなくてもみんな静かです。
  • 駅のプラットホームで並ぶ位置は床の表示通りに。

💡 戸惑いポイント

  • 慶州駅は市街地ではない: 降りてさらに30分かかります。「駅前の宿」を取ると観光がつらくなります — 皇理団キルへ。
  • 慶州駅の名前が二つある: 2023年より前は旧新慶州駅。古い記事・地図に旧名のまま残っていても同じ駅です。市街地の旧慶州駅はなくなりました。
  • 釜山1日2ヶ所: 海雲台と甘川文化村 (Gamcheon / 감천마을)を1日に入れると移動で終わります。Redditの返信の満場一致です。
  • 鞄を持った市内バス: 釜山駅→広安里を市内バスで鞄を持ったまま行き、後悔したという報告が多いです。地下鉄・タクシーを。
  • 祝祭日: 秋夕 (Chuseok / 추석)・旧正月 (Seollal / 설)の前後はKTXが売り切れます。市外バスが代案(#1374)。
  • 慶州→釜山KTX30分に油断: 慶州駅まで出る30分を忘れがちです。市街地の宿なら市外バスの方がドアからドアまで速いことがあります。

FAQ 6

Q1. 逆順(釜山→慶州→ソウル)はできない?

  • できます。釜山から入国する場合や、ソウルでの買い物を最後にまとめたい場合は逆転させます。慶州が真ん中なのは同じです。

Q2. 慶州を釜山から日帰りしたら?

  • 可能で、実際に多くの人がします。ただ夜景が見られず、往復移動に2時間使います。このルートでは1泊を勧めます — 根拠は#1373。

Q3. 7日しかない。

  • ソウル3・慶州1・釜山2。ソウルをさらに削ってもかまいません。

Q4. 済州をつなげるなら?

  • 釜山から国内線で済州 (Jeju / 제주)、済州からソウルへ上る案が多いです。今回の3都市に2日以上プラスでかかります。

Q5. 釜山から直接出国したら?

  • 金海国際空港に日本・中国・東南アジアの国際線があります。その路線に乗ればソウル復帰区間が省けます。欧州・米州は大半が仁川発着です。

Q6. 切符は前もって買うべき?

  • KTXは通常当日でも買えますが、週末・祝祭日は事前に。3区間の切符とパスの損益は#1374。
