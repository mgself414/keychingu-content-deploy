サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「トレイルランニング」テーマで選ばれた場所のうち、投票コースと合う観光公社の登録情報が見つかった20か所 · コースの長さと所要時間が登録された場所は北漢山 トゥルレギル(3.1~5.2㎞)・ソウルトゥルレギル 5コース アチャサンコース(4.6㎞)・南海 パレギル 11コース(13.6㎞)・大関嶺 旧道(13.4㎞)・ヨンドク ブルーロード 3コース(17.6㎞)など · 慶州 南山・徳裕山 香積峰・無等山は利用時間帯が登録されています — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「トレイルランニング (Teureil Reoning / 트레일 러닝)」テーマで選ばれた100か所のうち、韓国観光公社の観光情報で投票コースと合う登録情報が見つかった20か所を扱います。表の順位と得票数は、その投票結果です。観光公社の登録が投票コースと合うか確かでない場所(ソウル ナムサン トゥルレギル (Seoul Namsan Dullegil / 서울 남산 둘레길)・ナムハンサンソン トゥルレギル (Namhansanseong Dullegil / 남한산성 둘레길)・チアクサン トゥルレギル (Chiaksan Dullegil / 치악산 둘레길)・チョンプンホ チャドゥラクギル (Cheongpungho Jadeurak-gil / 청풍호 자드락길)など)と、登録情報が見つからなかった場所(済州オルレ 10コース (Jeju Olle 10-gose / 제주올레 10코스)・ハルラサン 探訪路 (Hallasan Tambangno / 한라산 탐방로)など)は入れていません。森道が中心のサリョニ森道 (Saryeoni Supgil / 사려니숲길)・西帰浦 癒しの森 (Seogwipo Chiyuui Sup / 서귀포 치유의 숲)・済州チョルムル自然休養林 (Jeju Jeolmul Jayeon Hyuyangnim / 제주절물자연휴양림)は#1427 韓国の森ぼんやり・水ぼんやり・裸足ウォーキングガイドで、セビョルオルム (Saebyeol Oreum / 새별오름)・ヨンヌニオルム (Yongnuni Oreum / 용눈이오름)は#1423 済州オルム ガイドで扱ったので、ここでは外しました。

トレイルランニングは、山道のように舗装されていない道を走る運動です。本文のコースの長さと所要時間は、観光公社に登録されたウォーキング基準の値です。走るのに向いているかどうかの説明は観光公社の情報になく、表の順位は投票結果にすぎません。

運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。登録値がない欄は「登録値なし」と書きました。投票名簿の名前や住所が観光公社の登録と違う場所は、本文に別に書きました。

📍 ソウル都心から行く山道 — 漢陽都城 スンソンギル・北漢山 トゥルレギル・アチャサン・冠岳山

ソウル 漢陽都城 スンソンギル、観光公社の登録住所は鍾路区 (Jongno-gu / 종로구) ヌサン洞 (Nusang-dong / 누상동) 山1-29で、プガクサン・インワンサン・ナクサン・ナムサンをつなぐ18.6㎞のソウル城郭の周りを歩く道です。ペガク区間(チャンウィムン~ヘファムン)、ナクサン区間(ヘファムン~フンインジムン)、ナムサン(モンミョクサン)区間(チャンチュン体育館~ペクポム広場)、インワン区間(トニムン跡~チャンウィムン)の四つのコースに分かれています。投票名簿には、住所が中区 (Jung-gu / 중구) シンダン洞 (Sindang-dong / 신당동) 229-41と載っています。

  • 開く時間・休み・料金: 登録値なし。

北漢山 トゥルレギルは、北漢山のふもとをなだらかに歩けるよう既存の脇道をつないで作った、低地の水平な散策路です。全体で71.5㎞に21の区間があります。投票には三つの区間が別々に載りました。

  • 10区間 ネシミョヨクギル (Naesimyoyeok-gil / 내시묘역길)、恩平区 (Eunpyeong-gu / 은평구) チングァン洞 (Jingwan-dong / 진관동)、パンペ教育隊前~ヒョジャ洞公設墓地: 3.5㎞、約1時間45分。高さ8mのトゥルレ橋があります。
  • 1区間 ソナム森道 (Sonamu Supgil / 소나무숲길)、カンブク区 (Gangbuk-gu / 강북구) ウイ洞 (Ui-dong / 우이동)、ウイリョンギル入口~ソルバッ近隣公園上部: 3.1㎞、約1時間30分。広くてなだらかで、一部の区間はウイ渓谷に沿っていきます。
  • 8区間 クルムジョンウォンギル (Gureumjeongwon-gil / 구름정원길)、恩平区 プルグァン洞 (Bulgwang-dong / 불광동)、北漢山生態公園上部~チングァン生態橋前: 5.2㎞、約2時間30分。クギトンネルの上の渓谷を横切る、長さ60mのデッキ道(スカイウォーク)があります。
  • 開く時間・休み・料金: 三つの区間すべて登録値なし。

アチャサン、広津区 (Gwangjin-gu / 광진구) キンゴランロ 213 (Gingorang-ro 213 / 긴고랑로 213)、☎ アチャサン管理事務所 (Achasan Gwanrisamuso / 아차산관리사무소) 02-450-1655 は、海抜295.7mで、観光公社の紹介によると、登山路で約40分で頂上に着きます。頂上からは、チャムシル・ナムサン・北漢山・トボンサンまで、ソウルの景色が360度に広がります。ソウルトゥルレギル 5コース アチャサンコース(カルタッコゲ休憩所~クァンナル駅)は4.6㎞、約2時間10分です。投票名簿には「アチャサン 頂上道コース (Achasan Jeongsanggil Koseu / 아차산 정상길코스)」という名前で載っていますが、ソウルトゥルレギル 5コースと同じ道かどうかは登録情報からはわかりません。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

冠岳山、冠岳区 (Gwanak-gu / 관악구) テハク洞 (Daehak-dong / 대학동) 一帯、☎ 冠岳区 余暇都市課 (Gwanak-gu Yeogadosigwa / 관악구 여가도시과) 02-879-6552 は、高さ632.2mで、ソウル大学の入口から始まる登山路が代表的で、クァチョン中学校の裏手から登る道もあります。冠岳山のすべての登山路は、崖の上のヨンジュデに集まると紹介されています。投票名簿には、住所がキョンギ (Gyeonggi / 경기) 果川市 (Gwacheon-si / 과천시) 中央洞 (Jungang-dong / 중앙동)と載っています。

  • 開く時間・料金: 登録値なし。休み: 年中無休。

📍 海を望んで歩く海岸道 — イギデ・済州オルレ 7コース・南海 パレギル

イギデ海岸散策路、釜山 南区 (Nam-gu / 남구) ヨンホ洞 (Yongho-dong / 용호동) 山25 は、釜山国家地質公園に属し、釜山の海岸道ガルメッキル (Galmaet-gil / 갈맷길) 2コースの区間でもあります。トンセンマル・オウルマダン・ノンバウィを通り、オリュクト ヘマジ公園まで、岩壁・雲の橋・デッキでつながっています。海雲台・クァンアン大橋・マリンシティを眺めながら歩くことができ、終わりのヘマジ公園にオリュクト スカイウォークがあります。

  • 開く時間・休み・料金: 登録値なし。

済州オルレ 7コース(出発: 西帰浦市 (Seogwipo-si / 서귀포시) チュンジョンロ 22 (Jungjung-ro 22 / 중정로 22) 済州オルレ旅行者センター、☎ 064-762-2190)は、旅行者センターからポプァンポグ (Beophwan Pogu / 법환포구)を通ってウォルピョンまで続く、海沿いのオルレです。ウェドルゲと、オルレジギのキム・スボンさんがシャベルとつるはしで作った道「スボンロ (Subongno / 수봉로)」を通ります。済州オルレ全体は27コース 437kmです。

  • 開く時間: 常時開放。休み: 年中無休。料金: 登録値なし。

南海 パレギル 11コース タランイチゲッギル、南海郡 (Namhae-gun / 남해군) 南面 (Nam-myeon / 남면)、カチョン タランイ村~南海 パレギル 小さな美術館は、カチョン タランイ村からサチョン海岸を経てピョンサン港まで、海岸を歩く道です。13.6㎞、5時間30分かかります。「パレ (Barae / 바래)」は、南海の人々が潮時に合わせて干潟・磯で必要な分だけ海産物を採っていたことを指すと紹介されています。投票名簿には、住所がイムポ里 (Impo-ri / 임포리) 1193と載っています。

  • 開く時間・休み・料金: 登録値なし。

📍 山岳コース — 伽智山・ウルサンバウィ・香積峰・無等山・太白山・鶏龍山・慶州 南山

伽智山(観光公社の登録: 伽智山道立公園、密陽市 サンネ面 (Sannae-myeon / 산내면)、☎ 密陽市庁 山林緑地課 055-359-5297)は、密陽・蔚山 ウルジュ郡 (Ulju-gun / 울주군)・清道の境にある山です。観光公社の紹介によると、「嶺南アルプス」と呼ばれる山群のなかでいちばん高く、稜線に沿ってウンムンサンまで縦走できます。秋にはソンナム峠から頂上までススキの草原が広がります。投票名簿には、住所が蔚山 ウルジュ郡 サンブク面 (Sangbuk-myeon / 상북면)と載っています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。詳しくは電話で問い合わせるよう登録されています。

雪岳山 ウルサンバウィ、束草市 ソラクサンロ 1140-115 (Seoraksan-ro 1140-115 / 설악산로 1140-115)、☎ 雪岳山国立公園 033-801-0900 は、海抜900m近く、屏風のように立ち並ぶ六つの峰の岩山で、周囲は4㎞に及びます。小公園から出発し、シンフンサとフンドゥルバウィを経て登ります。

  • 開く時間: 常時開放(詳しくは電話で問い合わせるよう登録)。休み: 年中無休。料金: 無料。

徳裕山 香積峰、茂朱郡 ソルチョン面 (Seolcheon-myeon / 설천면)、☎ 徳裕山国立公園事務所 063-322-3174 は、海抜1,614mで、観光公社の紹介によると、南韓で四番目に高い峰です。ゴンドラで登る、ソルチョンボン~香積峰の区間が、短いコースとして人気があります。第1コースは0.6㎞、第2コースは8.5㎞で、南徳裕山まで約14.8㎞の縦走もできます。投票名簿には、住所が茂朱郡 アンソン面 (Anseong-myeon / 안성면) トクサン里 (Deoksan-ri / 덕산리) 山1と載っています。

  • 開く時間(登録値): 4~10月 04:00~15:00, 11~3月 05:00~14:00。天気によって入山が規制されることがあります。
  • 休み: 年中無休。料金: 無料。

無等山国立公園、光州 東区 (Dong-gu / 동구) トンサンギル7ボンギル 5 (Dongsan-gil 7beon-gil 5 / 동산길7번길 5)、☎ 無等山国立公園事務所 062-227-1187 は、2013年に国立公園に指定されました。最高峰のチョンワンボンは海抜1,187mで、ソソクテ・イプソクテ・クァンソクテの柱状節理帯がいちばんの特徴として紹介されています。投票名簿には、住所がプク区 (Buk-gu / 북구) ムドゥンサン チョンワンボンギル 460 (Mudeungsan Cheonwangbong-gil 460 / 무등산천왕봉길 460)と載っています。

  • 開く時間(登録値): 3~11月 04:00~17:00, 12~2月 04:00~16:00。3~11月の閉まる時間は、登録表記「04:00~1700」を17:00と読んだものです。
  • 休み: 年中無休。料金: 無料。

太白山国立公園、太白市 ポニョンロ 59 (Beonyeong-ro 59 / 번영로 59)、☎ 033-550-0013 は、チョンジェダンがあるヨンボン(1,560m)を中心に、チャングンボン(1,567m)・ムンスボン(1,517m)・プスェボン(1,546m)が続き、最高峰はハンベクサン(1,572m)です。頂上付近はイチイの群落地として知られています。投票名簿には、住所が太白市 ヒョル洞 (Hyeol-dong / 혈동)と載っています。

  • 開く時間: 区間ごとに異なるのでホームページを参照するよう登録されています。休み: 年中無休。料金: 無料。

鶏龍山国立公園、公州市 パンポ面 (Banpo-myeon / 반포면) トンハクサ1ロ 327-6 (Donghaksa 1-ro 327-6 / 동학사1로 327-6)、☎ 鶏龍山国立公園事務所 042-820-3100 は、1968年に韓国で二番目の国立公園に指定されました。頂上のチョナンボン(847m)を中心に、峰が16、渓谷が約10あります。

  • 開く時間・休み: 気象条件により規制されるのでホームページを参照するよう登録されています。

慶州 南山、慶州市 ペ洞 (Bae-dong / 배동)、☎ 慶州南山研究所 054-777-7142 は、クモボン(468m)とコウィボン(494m)から流れ下る40あまりの谷でできた山です。寺跡100か所あまり、石仏80体あまり、石塔60基あまりが点在していて、露天博物館として紹介されています。

  • 開く時間(登録値): 4~10月 04:00~16:00, 11~3月 05:00~15:00。休み: 年中無休。料金: 無料。駐車: 不可と登録。

📍 森道・旧道など — ソルマルギル・大関嶺 旧道・五台山 ソンジェギル・サンマギ旧道・モチェワッ森道・ヨンドク ブルーロード

ソルマルギル、蔚山 南区 トルジルロ 233 (Doljil-ro 233 / 돋질로 233)は、松が生い茂る尾根をつなぐ登山道です。観光公社の紹介によると、「都心の中の60里の名品散策路」として知られていて、全区間に公園灯があり、夜も利用されます。遅い時間には公園灯を消します。投票名簿には「ソルマルギル ナムサンコース (Solmarugil Namsan Koseu / 솔마루길 남산코스)」という名前と、南区 シンジョン洞 (Sinjeong-dong / 신정동) 山107-2の住所で載っています。

  • 開く時間・休み・料金: 登録値なし。

大関嶺 旧道(江陵 パウギル (Bau-gil / 바우길) 2区間、出発: 平昌郡 テグァルリョン面 (Daegwallyeong-myeon / 대관령면) キョンガンロ 5754 (Gyeonggang-ro 5754 / 경강로 5754))は、大関嶺の頂上の新再生エネルギー展示館前から、江陵市 ソンサン面 (Seonsang-myeon / 선상면) ポグァン里 (Bogwang-ri / 보광리)(登録表記のまま)まで行く13.4㎞、6~7時間の中級コースです。嶺東と嶺西をつないでいた道で、2010年に名勝に指定されました。投票名簿には、住所が江陵市 ソンサン面 オフル里 (Eoheul-ri / 어흘리)と載っています。

  • 開く時間・休み・料金: 登録値なし。

五台山 ソンジェギル(平昌郡 チンブ面 (Jinbu-myeon / 진부면)、ウォルジョンサ~サンウォンサ)は、ウォルジョンサからサンウォンサまで約9㎞続く森道です。ほとんどが平地で歩きやすいと紹介されています。1960年代末に道路ができる前から、僧侶と信徒が行き来していた旧道です。投票名簿には、住所がオデサンロ 713-77 (Odaesan-ro 713-77 / 오대산로 713-77)と載っています。

  • 開く時間・休み・料金: 登録値なし。

サンマギ旧道、槐山郡 (Goesan-gun / 괴산군) チルソン面 (Chilseong-myeon / 칠성면) ミョンテジェロウェサ4ギル 1 (Myeongtaejaero-oesa 4-gil 1 / 명태재로외사4길 1)は、サオラン村からサンマギ村まで続いていた旧道を復元した散策路です。区間の大部分がデッキで、槐山ダム湖に沿っていきます。コースは二つです。

  • 開く時間・休み・料金: 登録値なし。

モチェワッ森道、西帰浦市 ナモン邑 (Namwon-eup / 남원읍) ソソンロ 755 (Seoseong-ro 755 / 서성로 755)は、牧場・草原と原生林をいっしょに歩く森道です。観光公社の紹介によると、「モチェ」は石が積まれ雑木が茂る所、「ワッ」は畑を意味する済州語です。石垣に沿って始まり、ヒノキの群落地とソジュンチョン展望台を通ります。解説員といっしょに歩くこともできます。

  • 開く時間・休み・料金: 登録値なし。

ヨンドク ブルーロード 3コース 風の丘、ヨンドク郡 (Yeongdeok-gun / 영덕군) カング面 (Ganggu-myeon / 강구면)、カング テゲ通り~チャンポマル灯台、☎ ヨンドク郡庁 文化観光課 054-730-6349 は、全長17.6㎞、片道約4時間55分のコースで、観光公社の紹介によると、ヨンドクの山林観光名所をつなぐテーマ旅行コースです。カング テゲ通りから、日の出登山路入口・クムジン 雲の橋・コブルボン入口を通ってチャンポマル灯台まで行きます。投票名簿には、コース番号なしで「ヨンドク ブルーロード」と載っています。

  • 開く時間: 常時開放。休み: 年中無休。

⚙ FAQ 3

Q. ソウルにあるコースは?

A. 漢陽都城 スンソンギル、北漢山 トゥルレギル 1・8・10区間、アチャサン、冠岳山です。登録された長さでは、北漢山 トゥルレギル 1区間(3.1㎞)がいちばん短いです。

Q. 海を望んで歩くコースとして登録された場所は?

A. 釜山 イギデ海岸散策路、済州オルレ 7コース、南海 パレギル 11コースです。ヨンドク ブルーロード 3コースは、観光公社の紹介に山林観光名所をつなぐコースと書かれています。

Q. 投票1位は?

A. 伽智山(145票)です。観光公社の紹介によると、「嶺南アルプス」の山群でいちばん高い山です。2位は釜山 イギデ海岸散策路(125票)です。
