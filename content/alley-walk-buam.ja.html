路地散策⑤ プアムドン (Buam-dong / 부암동) — 城門の外の最初の町、路地の果てに隠れた渓谷

副題: 景福宮からバス10分、ソウルは突然山里になる。文学館からチャンウィムンを過ぎ、路地の果てのペクサシル渓谷まで約3時間。サンショウウオが暮らす渓谷が都心に残る理由とともに歩く。Seoul Alley Walks 拡張2号。

ISSUE · #1344 · 2026-09-02

🎯 フレーム — 都城外の最初の町

プアムドンは、漢陽都城 (Hanyangdoseong / 한양도성) の北西の城門チャンウィムン (Changuimun / 창의문) のすぐ外側にある最初の町だ。都城内(景福宮 (Gyeongbokgung / 경복궁) ・ソチョン (Seochon / 서촌))の賑わいが、城門ひとつを境に路地と山裾の風景へと変わる — そしてその路地の果てには、朝鮮時代の士大夫の別荘跡が残る渓谷が隠れている。このコースはシリーズの中で最も「自然に近い路地」だ。

  • 総所要時間: 約3時間(展示・カフェ込み) · おすすめ時間帯: 午前10〜11時スタート — 渓谷区間を明るいうちに、午後はカフェで締めくくり
  • 傾斜: 中〜上 — 山裾の町+渓谷の下り。運動靴必須、雨の後は渓谷道が滑りやすい。
  • アクセス: 地下鉄駅のない町だ — キョンボックン駅 (Gyeongbokgung Station / 경복궁역) 3番出口 → バス(チャハムンコゲ (Jahamun-gogae / 자하문고개) 方面)約10分が標準のアクセスルートだ。

🚶 コース — 歩く順番そのままに

① キョンボックン駅 3番出口 → バス → チャハムンコゲ停留所 (約10分)

  • バスが峠を上る瞬間からコースが始まる — 車窓の風景が都心から山里へと変わっていく。

② チャハムンコゲ → ユン・ドンジュ文学館 (Yun Dong-ju Literature Museum / 윤동주문학관) (徒歩約2分)

  • 旧・水道加圧場を改装した小さな文学館。詩人ユン・ドンジュ (Yun Dong-ju / 윤동주) の原稿と井戸をモチーフにした展示空間 — 規模は小さいが密度が高い。

③ 文学館 → チャンウィムン (徒歩約3分)

  • 📖 物語1 — 城門ひとつの境界: チャンウィムンは漢陽都城の四小門のうち北西の門だ。この門の内側が王の都であり、外側がプアムドンだった — 城門の外の最初の町という立地が、この町の静けさを数百年守ってきたわけだ。門楼の下を実際にくぐることができる。

④ チャンウィムン → プアムドン路地 (徒歩約15分)

  • カフェと小さな商店が山裾の路地にぽつぽつと — 塀の向こうにブガクサン (Bugaksan / 북악산) とインワンサン (Inwangsan / 인왕산) が交互に見え隠れする。丘の上の路地なので数歩ごとに眺めが変わるのが、この区間の面白さだ。

⑤ プアムドン路地 → ペクサシル渓谷 (Baeksasil-gyegok / 백사실계곡)・ペクソクドンチョン (Baekseokdongcheon / 백석동천) (徒歩約15分、下り)

  • 住宅街の路地が途切れる地点で、突然森と渓谷が開ける。
  • 📖 物語2 — 秘密の渓谷の正体: ペクソクドンチョンは、朝鮮時代の士大夫の別荘(別邸)跡が残る名勝指定地であり、ソウル市の生態・景観保全地域でもある — サンショウウオとサワガニが暮らす一級の生態系が都心のすぐ隣に保全されている、稀な場所だ。池の跡や礎石の上に立つと、「ソウルの中」だという事実がしばらく信じられなくなる。

⑥ 渓谷 → セゴムジョン (Segeomjeong / 세검정) 方面下山 → 締めくくり (徒歩約15分)

  • 渓谷沿いに下ると、セゴムジョンの亭が見える — ホンジェチョン (Hongjecheon / 홍제천) の水辺でコースが終わる。バスでキョンボックン駅へ戻るか、ソチョン(#014)へ歩き続けるのもいい。

🙏 路地・渓谷マナー

  • ペクサシル渓谷は保全地域だ — 水に入らない、石をひっくり返さない(サンショウウオの生息地)、飲食・ゴミ捨て禁止。
  • プアムドンの路地は静かな住宅地 — 塀の中の撮影禁止、声は低めに。
  • 渓谷区間は暗くなったら歩かない — 照明がない。

💡 戸惑いポイント

  • 駅がない — 地図アプリが徒歩30分ルートを提案しても、正解はバスだ。降車停留所は「チャハムンコゲ・ユン・ドンジュ文学館」。
  • 渓谷の入り口は路地の間にあるため、最初は見つけにくい — ペクサシル渓谷の案内板の矢印をたどること。
  • 飲食店・コンビニが少ない — 水と軽食は入る前に。
