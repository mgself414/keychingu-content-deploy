サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「Kミステリー旅行地」テーマで選ばれた場所のうち、観光公社の紹介に伝説や不思議な現象が書かれた20か所 · 入場料が登録された場所は馬耳山塔寺(大人 3,000ウォン)・落花岩(大人 2,000ウォン)・正房瀑布(大人 2,000ウォン)・聖留窟(大人 5,000ウォン) · 月曜日休みの場所はヨノランとセオニョ テーマ公園 クィビゴと聖留窟 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「Kミステリー旅行地 (K-Miseuteori Yeohaengji / K-미스테리 여행지)」テーマで選ばれた100か所のうち、観光公社の観光情報の紹介文に伝説や不思議な現象が書かれている20か所を扱います。表の順位と得票数は、その投票結果です。

伝説は、観光公社の紹介に書かれた話だけを写しました。歴史の記録と言い伝えが混ざっているので、本文で「〜と伝わる」「〜という話がある」と書いた部分は、事実ではなく伝説として読んでください。

入場料が登録された場所は4か所で、残りは無料と登録されているか、料金の登録値がありません。運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。

📍 龍になった王と龍の伝説 — 文武大王陵・感恩寺址・テワンアム公園・龍頭岩・浮石寺

慶州 文武大王陵、慶州市 ムンムデワン面 (Munmudaewang-myeon / 문무대왕면) ポンギル里 (Bonggil-ri / 봉길리) 30-1、☎ 054-779-8166 は、新羅第30代の文武王(在位 661~681年)の水中陵です。ポンギル里の沖合200mの地点にあります。観光公社の紹介によると、三国を統一した文武王は、自分が龍になって倭寇を防ぐと言い、遺体を火葬して遺骨を東海に埋めてほしいと遺言し、その遺志どおりに葬られました。この岩をテワンアム (Daewangam / 대왕암)と呼びます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

慶州 感恩寺址、慶州市 ムンムデワン面 ヨンダン里 (Yongdang-ri / 용당리) 17、☎ 054-772-9289 は、文武王が倭寇を防ぐために建て始め、息子の神文王が682年に完成させた寺の跡です。今は三層石塔2基と建物の跡だけが残っています。伝説によると、金堂の下の排水施設を通って、海の龍になった文武王が行き来したと伝わります。金堂の前の2つの塔は、観光公社の観光情報に載っている国家遺産庁の紹介文に、韓国の石塔の中でいちばん大きいと書かれています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 無料。

テワンアム公園、蔚山 トン区 (Dong-gu / 동구) トゥンデロ 95 (Deungdae-ro 95 / 등대로 95)、☎ 052-209-3738 には、文武大王の王妃が亡くなったあと護国の龍になり、蔚山の東海の岩の下に沈んだという伝説が伝わっていると紹介されています。入口からウルギ灯台 (Ulgi Deungdae / 울기등대)まで600mの松林の道が続き、公園には吊り橋とウルギ灯台があります。

  • 開く時間: 常時開放。休み: 年中無休。

龍頭岩、済州市 ヨンドゥアムギル 15 (Yongduam-gil 15 / 용두암길 15)、☎ 064-740-6000 は、波と風に削られて龍の頭に似た形になった岩です。伝説によると、漢拏山 (Hallasan / 한라산)の神霊の玉を盗んで逃げた龍を、神霊が弓で射て海辺に落とし、そのまま固まらせたと伝わります。龍になって天に昇ろうとした白馬が将軍に捕まって岩になったという伝説もあります。英語・中国語・日本語の案内サービスがあると登録されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

浮石寺、栄州市 プソク面 (Buseok-myeon / 부석면) プソクサロ 345 (Buseoksa-ro 345 / 부석사로 345)、☎ 054-633-3464 は、676年に義湘大師が創建した寺で、ユネスコ世界遺産です。仏殿の西側の大きな岩が下の岩とくっつかずに浮いているので、「浮き石 (Buseok / 부석)」という名前が付いたといいます。無量寿殿 (Muryangsujeon / 무량수전)の西側の井戸には、義湘大師の護法の龍が住んでいたという話が伝わります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 説明しにくい現象 — 密陽 オルムゴル・表忠碑・万魚寺、フンドゥルバウィ、珍島 神秘の海の道

観光公社の紹介によると、密陽のオルムゴル・表忠碑・万魚山のキョンソク (原文: Eosan Bulyeong Gyeongseok / 어산불영경석)は「密陽の三大不思議」と呼ばれています。

密陽 オルムゴル、密陽市 サンネ面 (Sannae-myeon / 산내면) サンネロ 1647 (Sannae-ro 1647 / 산내로 1647)、☎ 055-356-5640 は、チェヤク山 (Jaeyaksan / 재약산)北側の中腹にある谷です。3月上旬ごろから岩の隙間に氷ができ始め、たいてい7月中旬まで続くとされますが、近ごろは雨の日が多く、氷が残っている期間は昔ほど長くないと紹介されています。冬にはむしろ岩の隙間から暖かい湯気が上がります。氷ができる岩の隙間の夏の平均気温は摂氏0.2℃ほどです。

  • 開く時間: 電話で問い合わせ。休み: 年中無休。料金: 無料。

表忠碑、密陽市 ムアン面 (Muan-myeon / 무안면) トンブドンアンギル 4 (Dongbudongan-gil 4 / 동부동안길 4)、☎ 055-359-5640 は、1742年に四溟大師の忠節をたたえて建てた碑です。国に大きな出来事があるたびに石碑から汗が流れたという話から、「汗を流す表忠碑」として知られていると紹介されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

万魚寺、密陽市 サムランジン邑 (Samnangjin-eup / 삼랑진읍) マノロ 776 (Maneo-ro 776 / 만어로 776)、☎ 055-356-2010 は、海抜674mの万魚山にある寺です。三国遺事 (Samgungnyusa / 삼국유사)に伝わる話によると、仏の説法に感化された東海の数多くの魚と龍が山に集まって石になり、その石から磬の音がしたといいます。今も寺の前の石をたたくと澄んだ音がするので、チョンソク (Jongseok / 종석)とも呼ばれ、慶尚南道記念物に指定されています。

  • 開く時間: 08:00~18:00。休み: 年中無休。

ソラク フンドゥルバウィ、束草市 ソラクサンロ 1140-200 (Seoraksan-ro 1140-200 / 설악산로 1140-200)、☎ 雪岳山国立公園事務所 (Seoraksan Gungnip Gongwon Samuso / 설악산국립공원사무소) 033-801-0900 は、ケジョアム (Gyejoam / 계조암)の入口の広い岩の上にある丸い岩です。軽く触れただけで倒れそうに見えますが、1人で押しても大勢で押しても揺れ方が同じくらいだと紹介されています。雪岳山の小公園から約1時間かかります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

珍島 神秘の海の道、珍島郡 コグン面 (Gogun-myeon / 고군면) シンビエバダッキル 148 (Sinbiui Badatgil 148 / 신비의바닷길 148)、☎ 珍島郡庁 観光課 (Jindo Guncheong Gwangwangwa / 진도군청 관광과) 061-540-3407 は、コグン面のフェドン村 (Hoedong Maeul / 회동마을)とウィシン面 (Uisin-myeon / 의신면)のモドの間に、幅30~40m、長さ2.8kmの海の道が開く場所です。海の道は約1時間現れてから閉じます。伝説によると、虎を避けてモドへ渡った村人たちが置いてきてしまったポンハルモニ (Ppong Halmoni / 뽕할머니)が龍王に祈ると海の道が開き、家族に会えたものの、そのまま息を引き取り、その後、村人たちは毎年祭祀を行うようになったと伝わります。1975年に駐韓フランス大使がこの現象を「モーセの奇跡」と紹介して広く知られるようになったと書かれています。体験館があり、海の道が開く時期に関係なく体験できます。

  • 開く時間・休み・料金: 登録値なし。実際に海の道が開く日付は観光公社の情報にありません(伝説の中の「旧暦2月の末日」は開放日程ではありません)。

📍 建国神話と昔の話 — 慶州 鶏林・ヨノランとセオニョ・温達山城・落花岩

慶州 鶏林、慶州市 キョドン (Gyo-dong / 교동)、☎ 054-779-8585 は、チョムソンデ (Cheomseongdae / 첨성대)とウォルソン (Wolseong / 월성)の間にある森です。慶州金氏の始祖アルジ (Alji / 알지)が生まれたという伝説があります。新羅の脱解王の時代に森で鶏の鳴く声を聞いて行ってみると、木の枝に光り輝く金の箱が掛かっていて、その中から男の子が出てきたといいます。敷地内の碑は1803年に建てられ、キム・アルジ (Gim Alji / 김알지)の誕生の記録が刻まれています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

ヨノランとセオニョ テーマ公園 クィビゴ、浦項市 ナム区 (Nam-gu / 남구) トンヘ面 (Donghae-myeon / 동해면) ホミロ 3012 (Homi-ro 3012 / 호미로 3012)、☎ 054-289-7955 は、三国遺事に載っているヨノランとセオニョの話を扱った場所です。東海の海辺に住んでいたヨノ (Yeono / 연오)とセオ (Seo / 세오)の夫婦が日本へ渡ると新羅の太陽と月が光を失い、セオが織った絹で祭祀を行うと光を取り戻したという内容です。観光公社の紹介には、韓国で唯一の日月神話と書かれています。展示館のクィビゴ (Gwibigo / 귀비고)は、アニメーション・VR・メディア体験で説話を見せてくれます。

  • 開く時間: 公園 常時開放, クィビゴ展示館・新羅村 10:00~18:00(入場締切 17:30)。
  • 休み: 毎週月曜日(祝日ならその次の最初の平日), 1月1日, 旧正月・秋夕の当日。料金: 無料。

丹陽 温達山城、丹陽郡 ヨンチュン面 (Yeongchun-myeon / 영춘면) ハリ (Ha-ri / 하리)、☎ オンダル観光地 (Ondal Gwangwangji / 온달관광지) 043-423-8820 は、海抜427mのソン山 (Seongsan / 성산)に築いた半月形の石城です。高句麗の平原王の婿のオンダルが、新羅軍が攻めてきたときにこの城を築いて戦い、戦死したと三国史記 (Samguksagi / 삼국사기)に記録されていると紹介されています。愚か者のオンダルとピョンガン公主 (Pyeonggang Gongju / 평강공주)の話が伝わる場所です。

  • 開く時間: 常時開放。遭難と安全のため、16時以降は登山を禁止しています。休み: 年中無休。

落花岩、扶余郡 扶余邑 (Buyeo-eup / 부여읍) サンブク里 (Ssangbuk-ri / 쌍북리)、☎ 041-830-2884 は、プソ山 (Buso-san / 부소산)の北側にある白馬江 (Baengmagang / 백마강)に面した断崖です。三国遺事には、百済が滅亡するとき、宮女たちがここから身を投げたという話が伝わります。宮女たちを散る花にたとえて、落花岩と呼ぶようになったといいます。岩壁にはソン・シヨル (Song Siyeol / 송시열)が書いた「落花岩」の文字が刻まれています。

  • 開く時間: 3~10月 09:00~18:00, 11~2月 09:00~17:00。休み: 1月1日, 旧正月・秋夕の当日。
  • 料金(個人): 大人 2,000ウォン, 青少年・軍人・警察 1,100ウォン, 子ども 1,000ウォン。プソサンソン (Busosanseong / 부소산성)とコランサ (Goransa / 고란사)が含まれます。

📍 人と自然にまつわる話 — 馬耳山塔寺・龍門寺・黄池・コッチ海水浴場・正房瀑布・聖留窟

馬耳山塔寺、鎮安郡 マリョン面 (Maryeong-myeon / 마령면) マイサンナムロ 367 (Maisannam-ro 367 / 마이산남로 367)、☎ 063-433-0012 は、イ・ガプリョン (I Gapryong / 이갑룡)処士が積んだ80あまりの石塔で知られる場所です。イ・ガプリョンは25歳で馬耳山に入り、98歳で亡くなるまで塔を積み続けたと伝わります。観光公社の紹介には、大雄殿の裏のチョンジ塔 (Cheonjitap / 천지탑)一対がいちばん大きいと書かれています。

龍門寺、楊平郡 ヨンムン面 (Yongmun-myeon / 용문면) ヨンムンサンロ 782 (Yongmunsan-ro 782 / 용문산로 782)、☎ 031-773-3797 には、樹齢約1,100年と推定される高さ42mのイチョウの木があり、天然記念物です。この木は、新羅の敬順王の息子の麻衣太子が金剛山へ向かう途中で植えたという伝説と、義湘大師が突いていた杖を挿しておいたものが育ったという伝説が伝わります。テンプルステイを運営しています。

黄池、太白市 ファンジヨンモッキル 12 (Hwangji Yeonmot-gil 12 / 황지연못길 12)、☎ 太白市 観光案内所 (Taebaek-si Gwangwang Annaeso / 태백시 관광안내소) 033-550-2828 は、洛東江 (Nakdonggang / 낙동강)の源流です。ここに住んでいた黄長者が、施しを求めた老僧に肥やしを投げ与えると、天地が揺れて屋敷の跡が池になったという伝説があると紹介されています。1日に約5,000トンの水が湧き出ます。

聖留窟、蔚珍郡 ソンニュグルロ 221 (Seongnyugul-ro 221 / 성류굴로 221)、☎ 054-789-5404 は、長さ915m(水中区間を含む)の石灰岩の洞窟です。もともとは仙人たちが遊んだ場所という意味でソニュグル (Seonyugul / 선유굴)と呼ばれ、新羅の神文王の息子のポチョン太子 (Bocheon Taeja / 보천태자)が洞窟の中に寺を建てたときにソンニュサ (Seongnyusa / 성류사)と名付け、岩壁に小さな穴があるので聖留窟と呼んだと紹介されています。壬辰倭乱 (Imjin Waeran / 임진왜란)のとき、住民500人あまりが洞窟に避難したところ、倭兵が入口をふさいで全員が餓死したという話も伝わります。

⚙ FAQ 3

Q. 龍の話がある場所は?

A. 文武大王陵、感恩寺址、テワンアム公園(護国の龍)、龍頭岩、浮石寺(護法の龍が住んでいたという井戸)、万魚寺(魚と龍が石になったという話)です。慶州ムンムデワン面の文武大王陵と感恩寺址は、同じ話でつながっています。

Q. お金がかかる場所は?

A. 馬耳山塔寺(大人 3,000ウォン)、落花岩(大人 2,000ウォン, プソサンソンとコランサを含む)、正房瀑布(大人 2,000ウォン)、聖留窟(大人 5,000ウォン)です。

Q. 密陽の「三大不思議」は?

A. オルムゴル、表忠碑、万魚山のキョンソクです。観光公社の紹介によると、この3つが「密陽の三大不思議」と呼ばれています。3か所はそれぞれサンネ面・ムアン面・サムランジン邑にあります。
