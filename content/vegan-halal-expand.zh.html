🎯 为什么是纯素·清真·无麸质拓展指南

访问韩国的外国游客中，有饮食限制 (纯素 (Vegan)·清真 (Halal)·无麸质 (Gluten-Free)·洁食 (Kosher)·乳糖不耐症 (Lactose Intolerance)) 的游客逐年增加 (特别是在又来屋 (Itaewon / 이태원)·瑞来村 (Seoraemaeul / 서래마을)·延禧洞 (Yeonhui-dong / 연희동) 等外国人居住区域)。#69 纯素·清真完整指南后续 — 又来屋 (Itaewon / 이태원)·瑞来 (Seorae / 서래)·延禧 (Yeonhui / 연희)·弘大 (Hongdae / 홍대) 外国人居住区域的纯素·清真·多元文化饮食店铺全套。

⚠ 外国人常犯的 3 个错误

1. “韩食 = 纯素难寻”: 韩国寺庙饮食 (Sachal-eumsik / 사찰음식) (素食，遵循佛教戒律的韩式料理)·拌菜 (凉拌野菜)·豆类传统是世界一流的纯素饮食 — 津宽寺 (Jingwansa / 진관사) (#182) 寺院寄宿 (Templestay / 템플스테이) (在寺庙体验佛教文化和生活) + 拌饭 (Bibimbap / 비빔밥)·山野菜 (Sannamul / 산나물)·豆腐 (Dubu / 두부) 等。

2. “清真 = 只有又来屋 (Itaewon / 이태원)”: 又来屋 (Itaewon / 이태원) + 延禧洞 (Yeonhui-dong / 연희동)·瑞来 (Seorae / 서래)·弘大 (Hongdae / 홍대) 外国人居住区域都有清真店铺 + 超市。

3. “韩国无麸质 = 没有”: 韩国传统韩食大多无麸质 — 米饭·汤·炖菜·烤肉·炖菜·煎饼 (Jeon / 전) (不含面粉)。但拌面 (Bibim-guksu / 비빔국수)·拉面 (Ramyeon / 라면)·炸酱面 (Jjajangmyeon / 짜장면)·煎饼 (Jeon / 전)·炸物 (Twigim / 튀김) 则含有麸质。

⚙ 6 个常见问题

1. 又来屋 (Itaewon / 이태원) 清真超市？: 又来屋清真寺 (Itaewon Mosque / 이태원 모스크) 附近 + 多家清真超市 (马来西亚·印度·土耳其食品)。

2. 纯素认证店铺？: Plant (Plant / 플랜트)·Loving Hut (Loving Hut / 러빙헛)·你的蔬菜看得见 (Veggie / 너의 채소가 보여) 等已认证。

3. 韩食纯素安全店铺？: 寺庙饮食 (津宽寺 (Jingwansa / 진관사)) + 韩国传统拌菜·豆类店铺。

4. 无麸质韩食？: 米饭·汤·炖菜·烤肉·炖菜·煎饼 (Jeon / 전) 大部分 OK。拉面 (Ramyeon / 라면)·面条·炸物 (Twigim / 튀김) X。

5. 如何寻找外国人饮食限制店铺？: Happy Cow (纯素) + Crescent Rating (清真) 应用。

6. 延禧洞 (Yeonhui-dong / 연희동)·瑞来村 (Seoraemaeul / 서래마을) 清真？: 瑞来村外国人居住 (#173) + 延禧洞 (#156) 部分清真店铺。
