한국 밥 주문·매너 워크플로우 — 분식점부터 MZ 명란까지

> 부제: 외국인 관광객용 5-step + 공기밥 매너 + 영어 발화

ISSUE 03 · #898 · 2026-06-09

🎯 왜 밥 워크플로우 가이드인가

[#897 밥 6종 매트릭스](#897) 알아도 — 주문·매너는 별개. 한국 밥은 (a) 분식점·체인 (어묵철판·가성비) (b) MZ 한식당 (명란·치즈볶음밥) (c) 한정식 (솥밥·영양밥) (d) 가정식 백반 (공기밥 포함). 외국인은 (1) 공기밥 = 별도 비용 모름 (2) 명란밥 = MZ 인스타 모름 (3) 솥밥 = 한정식 정통 모름. 본 가이드는 5-step + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 분식 / MZ / 한정식 / 가정식 즉시 가성비·MZ·정통·홈스타일
2️⃣ 메뉴 주문 6종 + 사이드 1~5분 공기밥 = 별도 비용
3️⃣ 받기·세팅 밥 + 국·반찬·메인 5~15분 솥밥 뜨거움
4️⃣ 먹기·페어 밥 + 메인 + 김치 15~30분 한국 정통
5️⃣ 결제 카드 OK / 팁 X 1~3분 키오스크 영문

> 총 소요 시간: 분식 = 15~30분 / MZ = 30~60분 / 한정식 = 1.5~2.5h / 가정식 = 30~60분

🍚 채널별 워크플로우

Type A — 분식점·체인 (어묵철판)

  • 시그니처: 가성비 #1·#1 분식
  • 시간: 11:00~22:00
  • 가격: 7,000~12,000원
  • 메뉴: 어묵철판·라면·만두 cluster cross
  • 외국인 친화도: ★★★★

Type B — MZ 한식당 (명란·치즈볶음밥)

  • 시그니처: MZ 인스타 #1·트렌드
  • 시간: 11:00~22:00
  • 가격: 10,000~20,000원
  • 추천: 홍대·강남·이태원·성수
  • 외국인 친화도: ★★★★★

Type C — 한정식 (솥밥·영양밥)

  • 시그니처: 한정식 정통·5색 cluster
  • 시간: 11:30~22:00
  • 가격: 한정식 코스 40~150k
  • 추천: 신라호텔 라연·삼청각·인사동
  • 외국인 친화도: ★★★★

Type D — 가정식 백반 (공기밥 포함)

  • 시그니처: 홈스타일·공기밥 무료
  • 시간: 11:00~22:00
  • 가격: 8,000~15,000원
  • 외국인 친화도: ★★★★

🌶 외국인 영어 발화 샘플

  • "공기밥 1개" = "One bowl of rice (Gonggi-bap)"
  • "명란밥 1인" = "1 Myeongran-bap (MZ trend)"
  • "솥밥" = "Sot-bap (Pot rice - traditional)"
  • "치즈볶음밥" = "Cheese fried rice (MZ global #1)"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 5가지

1. "공기밥 = 무료": 공기밥 = 1,000~3,000원 별도 (한정식·가정식 무료 포함).

2. "명란 = 단가": 명란 = MZ #1·10~18k.

3. "솥밥 = 일반": 솥밥 = 한정식 정통·뜨거움.

4. "치즈볶음밥 = 외국": 치즈볶음밥 = 한국 MZ fusion.

5. "분식 = 어린이": 분식 = MZ 트렌드 OK.

⚙ FAQ 8개

1. 첫 밥 = 어떤 채널: 분식 (가성비) → MZ (#1).

2. 인스타: 명란·치즈볶음밥.

3. MZ: 명란 (#1)·치즈볶음밥.

4. 가성비: 어묵철판 (#1).

5. 한정식: 솥밥·영양밥.

6. 알레르기·임신: [#897](#897) 참조.

7. 결제: 카드 OK.

8. VAT: 환급 X.

⚠ 의료·안전·식이 disclaimer

밥 = 일반 음식. 알레르기 (어란·해산물·유제품·견과류·간장) 사전 고지. ☎ 1339.

식이 제한 fallback: 할랄·코셔 = 일부 OK / 채식 = 공기·솥·영양 OK / 글루텐 free = Tamari.
