🎯 このガイドの使い方

以前のガイドには「遊覧船22,000~30,000ウォン」(公式は16,000~22,000ウォン)、「個人が30年かけて育てた島」(公式では1969年から李昌鎬・崔好淑夫妻)と書かれていました。また巨済植物園を古県・玉浦エリアに(実際は巨済面 (Geoje-myeon / 거제면))、鶴洞モンドル海岸を南部面に(実際は東部面 (Dongbu-myeon / 동부면))置いており、レンタカー・ペンション・牡蠣の価格や「釜山から巨加大橋で1時間」には出典がありませんでした。今回は2026-10-08に巨済市の文化観光ページ、外島ボタニア、巨済植物園の公式ページで読み取った値だけを載せています。公式ページにない値(風の丘の料金、捕虜収容所の時間、巨加大橋の通行料、釜山のバス)は「掲示なし・未確認」としています。

⛴ 外島への行き方 — 乗り場は6カ所、料金は2つを足します

  • 遊覧船の料金 + 外島の入場料11,000ウォンは別々です。例: 長承浦の週末・大人 22,000 + 11,000 = 33,000ウォン。以前の「22,000~30,000」には入場料が含まれていませんでした。
  • 乗り場: 長承浦 (Jangseungpo / 장승포)(チャンスンロ138、055-681-6565) · 知世浦 (Jisepo / 지세포)(一雲面 知世浦海岸路72、055-682-5577) · 臥峴 (Wahyeon / 와현)(臥峴海辺キル46、055-681-2211) · 旧助羅 (Gujora / 구조라)(旧助羅里81-2、055-681-1188) · 海金剛 (Haegeumgang / 해금강)(南部面 海金剛路270、055-633-1352) · 道章浦 (Dojangpo / 도장포)(道章浦1キル53、055-632-8787)。コースは外島上陸 + 海金剛の船上観覧で、天候によっては欠航します。
  • 外島は1969年から李昌鎬・崔好淑夫妻が手入れしてきた島です(公式)。夏季08~19時・冬季08:30~17時。

🏛 古県 — 捕虜収容所・モノレール

  • 巨済捕虜収容所遺跡公園 (Geoje POW Camp Historic Park / 거제포로수용소유적공원) 7,000ウォン(公式料金表)。時間と休館日は巨済市のページに載っていません(二次情報: 09~18時・火曜休館)ので、訪問前に電話で確認してください。
  • 巨済観光モノレール (Geoje Tourist Monorail / 거제 관광모노레일) 09~18時(最終16時)、年中無休、昼18,000ウォン(公園観覧込み)・夜23,000ウォン(公式)。公園とモノレールを組み合わせるなら、モノレールのチケット1枚で済みます。

🌴 巨済面 — ジャングルドーム

  • 09:30~18時(入場17時まで)、水曜休館、1/1・旧正月・秋夕も休み。5,000ウォン、6歳以下・65歳以上は無料、当日現地購入のみ(公式)。以前の「国内最大のドーム」は未確認で、二次情報の「月曜休館・ネイバー予約」は公式と異なります。住所は古県ではなく巨済面 (Geoje-myeon / 거제면) の巨済南西路3595です。

🌊 南部・東部 — 風の丘・鶴洞・梅美城

  • 巨済市の公式ページには住所と電話しかなく、料金・時間はありません — 風の丘 (Windy Hill / 바람의언덕)・神仙台 (Sinseondae / 신선대)(南部面 葛串里)、鶴洞黒真珠モンドル海岸 (Hakdong Mongdol Beach / 학동 흑진주 몽돌해변)(東部面 (Dongbu-myeon / 동부면))、梅美城 (Maemiseong / 매미성)(長木面 (Jangmok-myeon / 장목면))。無料と決めつけないでください。

3. 風の丘を無料と決めつける — 公式に表記がありません。

4. 捕虜収容所の時間を信じる — 公式に表記がありません。電話で確認を。

5. 島花祭りの日程を組む — 2026年は未掲示で、中止報道も未確認です。

⚙ FAQ 6つ

1. 外島の総費用は? — 遊覧船16,000~22,000 + 入場11,000(大人)。長承浦の週末は33,000ウォン。

2. どの乗り場? — 6カ所。長承浦 (Jangseungpo / 장승포) は10/8に09:30・13:30出航(公式)。

3. ジャングルドームの予約は? — 当日現地購入のみ、水曜休館。

4. 捕虜収容所 + モノレールは? — モノレール18,000ウォンに公園が含まれます。

5. 釜山からはどう行く? — バスの料金・時間は未確認。統合予約サイトで確認してください。

6. 毎勿島は? — 巨済市のページには運航会社へのリンクのみ。未確認です。
