路地散策② ヘバンチョン (Haebangchon / 해방촌) — 108段の階段を上ると、もう一つのソウルがある

副題: 梨泰院隣の丘の町ヘバンチョンを歩く順に綴った。ノクサピョン駅→108段の階段→新興市場→アレンマウル→南山ソウォルギルまで約2時間。名前の由来と市場の物語も添えた。Seoul Alley Walks パイロット2。

ISSUE · #1341 · 2026-09-02

🎯 フレーム — 名前からして歴史だ

解放村という名前は、1945年の解放直後に北から下ってきた人々、海外からの帰国者、そして朝鮮戦争の避難民たちが南山 (Namsan / 남산) の裾野に集まって村をつくったことに由来する。丘の上のこの町は、その後ニット(編み物)産業で生計を立て、今ではソウルで最も多国籍な路地の一つになった。既存ガイド(#79 梨泰院・漢南・ヘバンチョン1日)が「どこへ行くか」だったとすれば、この回は「どの順番で歩いて上るか」だ。

  • 所要時間: 約2時間(カフェ休憩込みで2時間30分) · おすすめ時間帯: 午後4時スタート → ソウォルギル (Sowol-gil / 소월길) で日暮れフィナーレ。よりロマンチックな選択肢は逆コース(ソウォルギルから始めて夜景の市場へ下山)
  • 傾斜: 上 — このコースは上り坂が本体だ。歩きやすい靴、夏は水分補給を。

🚶 コース — 歩く順番そのままに

① ノクサピョン駅 (Noksapyeong Station / 녹사평역) 2番出口 → ヘバンチョン五差路 (Haebangchon Ogeori / 해방촌 오거리) (徒歩約10分、緩やかな上り坂)

  • 梨泰院の喧騒が静まり、丘の町の表情が始まる区間。五差路はこの町のへそ — 五本の路地が交わる小さな広場だ。

② 五差路 → 108段の階段 (108 Gyedan / 108계단) (徒歩約5分)

  • 📖 物語1 — 階段の正体: この急な108段の階段は、日本統治時代に神社へ上るための階段がそのまま路地になったものだ。2018年、住民のために傾斜型エレベーターが設置された — 階段脇のレールを上り下りする小さなエレベーター自体が、この町の名物になった。膝が心配ならエレベーターを、脚に自信があれば階段を。

③ 108段の階段の上 → 新興市場 (Sinheung Market / 신흥시장) (徒歩約5分)

  • 古びたトタン屋根の下、狭い通路の市場 — 昼は静かで、夕方になると小さな店々が灯りをともす。
  • 📖 物語2 — ニットの市場: 新興市場は、避難民たちの生計基盤だった縫製・編み物(ニット)産業とともに大きくなった。ヘバンチョンの主力産業だったニットが衰退すると市場も陰りを見せたが、都市再生を経て古い構造物の中にカフェ・バー・小さな商店が入った — 古さを消したのではなく、古さの上に載せた再生だからこそ、路地の表情が生きている。

④ 新興市場 → アレンマウル (Araenmaeul / 아랫마을) 路地 (徒歩約10分、下り坂)

  • 新興市場まで上らなくてもいいと言われる、あの「アレンマウル」— 最近ヘバンチョンで最も活気のあるカフェ・ベーカリー街だ。丘の中腹にあるため、窓の外に南山タワーが見える席が多い。
  • 店の名前がしょっちゅう変わる町だ — 特定の店より路地そのものを歩こう。気に入った窓が見えたら、それが今日のカフェだ。

⑤ アレンマウル → ソウォルギル (Sowol-gil / 소월길) ビューポイント → 締めくくり (徒歩約15分、上り坂)

  • 南山の中腹を巡るソウォルギルに合流すると、龍山 (Yongsan / 용산) 方面の視界が開ける。日暮れ時なら、このコースのエンドクレジットだ。
  • 締めくくりの選択肢: ソウォルギル沿いに南山散策を延長するか、下山して梨泰院・キョンニダン (Gyeongnidan / 경리단) で夕食(#79)。

🙏 路地マナー — 強化版

  • ヘバンチョンは住居密集地だ。路地の写真は人や家の中が写り込まないように、会話は小声で — 特に夕方早めの時間以降。
  • 108段の階段のエレベーターは住民の移動施設が優先だ。お年寄りが待っていたら譲ること。
  • ゴミは全部持ち帰ること(#1276)— 路地にゴミ箱がないのが普通だ。

💡 戸惑いポイント

  • 地図アプリの徒歩案内は階段・傾斜を過小評価する — 表示時間に上り坂の余裕+20%を見ておこう。
  • 新興市場は昼間「閉まっているように」見えることがある — 夕方型の路地だ。昼のコースなら、市場は構造を見る場所、消費はアレンマウルで。
  • 夜の下山路は照明が暗い区間がある — 日が沈んだ後はシンフンノ (Sinheung-ro / 신흥로) など大通り中心に。
