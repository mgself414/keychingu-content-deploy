⚠ 外国人常犯的3个错误

1. “甜点 = 只有韩国现代咖啡馆”: 韩国甜点有四大类别 — 街头小吃 (鲫鱼饼 (Bungeoppang / 붕어빵)·糖饼 (Hotteok / 호떡)) + 传统美食 (药果 (Yakgwa / 약과)·打糕 (Injeolmi / 인절미)) + 现代潮流 (Knotted·LBM·MAILLET) + 奢华体验 (新罗酒店 (Shilla Hotel / 신라호텔))。建议体验所有四种类型。

2. “鲫鱼饼 (Bungeoppang / 붕어빵) = 全年供应”: 鲫鱼饼 (Bungeoppang / 붕어빵) 是11月至次年3月的冬季限定。4月至10月通常看不到。是外国人冬季访韩必尝的街头小吃首选。

3. “刨冰 (Bingsu / 빙수) = 只有夏季”: 刨冰 (Bingsu / 빙수) 在韩国是四季皆宜 (冬天也很受欢迎)。雪冰 (Sulbing / 설빙) 总店 ([#171 雪冰梨大店韩国刨冰总店](171_sulbing_ewha_main.md)) 是外国人首选。

① 街头·传统 (3)

1. 鲫鱼饼 (Bungeoppang / 붕어빵) ★ 街头小吃首选

  • 时期: 11月至次年3月 (冬季限定)
  • 价格: 约₩1,000~2,000 (~$0.75~$1.5 / ~5~10 RMB / ~110~220 JPY) / 3个
  • 外国人 ★: ◎◎ — K-vlog冬季街头小吃首选
  • 特色: 红豆馅 (Pat / 팥)·奶油馅 (Choux Cream / 슈크림)·芝士 (Cheese / 치즈)·红薯 (Goguma / 고구마)

2. 糖饼 (Hotteok / 호떡)

  • 时期: 11月至次年3月 (冬季) + 部分全年供应
  • 价格: 约₩1,500~3,000 (~$1.1~$2.25 / ~8~15 RMB / ~160~330 JPY)
  • 外国人 ★: ◎ — 明洞 (Myeongdong / 명동)·仁寺洞 (Insadong / 인사동) 街头小吃

3. 鸡蛋面包 (Gyeran-ppang / 계란빵)

  • 价格: 约₩2,000~3,000 (~$1.5~$2.25 / ~10~15 RMB / ~220~330 JPY)
  • 外国人 ★: ◎ — 明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 街头小吃·鸡蛋+面包的组合

② 传统·韩式点心 (2)

4. 药果 (Yakgwa / 약과) ★ 外国人伴手礼首选

  • 特色: 韩国传统韩式点心 (Hangwa / 한과)·蜂蜜 (Kkul / 꿀)·香油 (Chamgireum / 참기름)·外国人伴手礼
  • 季节: 节日 + 全年
  • 详情: [#48 韩国必买TOP20](48_korea_must_buy_top20.md)

5. 打糕·松饼·糯米糕 (Injeolmi·Songpyeon·Chaltteok / 인절미·송편·찰떡)

  • 店铺: 떡함지 (Tteokhamji / 糕点盒) 蚕室 (Jamsil / 잠실) 店 ([#82](82_content_slug.md))·미아사거리 钟路 (Jongno / 종로)떡집 (Miasageori Jongno Tteokjip / 弥阿十字路口钟路糕点店) ([#186](186_content_slug.md))·민설기 (Minseolgi / 珉雪糕) ([#186](186_content_slug.md))
  • 外国人 ★: ◎ — 深入了解韩国传统糕点 (Tteok / 떡)

③ 现代·MZ (4)

6. 刨冰 (Bingsu / 빙수) ★ 雪冰 (Sulbing / 설빙) 总店

  • 店铺: 雪冰 (Sulbing / 설빙) 梨大 (Edae / 이대) 店 ([#171 雪冰梨大店韩国刨冰总店](171_sulbing_ewha_main.md))·韩国所有咖啡馆·酒店
  • 外国人 ★: ◎◎ — 韩国刨冰的标志性总店
  • 特色: 打糕刨冰 (Injeolmi Bingsu / 인절미 빙수)·红豆刨冰 (Patbingsu / 팥빙수)·芒果刨冰 (Mango Bingsu / 망고 빙수)·绿茶刨冰 (Nokcha Bingsu / 녹차 빙수)
  • 价格: 约₩9,000~15,000 (~$6.75~$11.25 / ~45~75 RMB / ~990~1,650 JPY)

7. 现代药果 (Lifestyle Yakgwa / 라이프스타일 약과)

  • 店铺: 仁寺洞 (Insadong / 인사동)·益善洞 (Ikseon-dong / 익선동) 现代药果咖啡馆
  • 外国人 ★: ◎ — 传统药果 (Yakgwa / 약과) → 结合现代咖啡馆

8. Knotted 甜甜圈 (Knotted / 노티드) ★ 韩国甜甜圈第一品牌

  • 店铺: 安国 (Anguk / 안국)·江南 (Gangnam / 강남)·蚕室 (Jamsil / 잠실)·加山 (Gasan / 가산) ([#82](82_content_slug.md)·[#180](180_content_slug.md)·[#225 咖啡馆](225_cafes.md))
  • 特色: 榛子 (Hazelnut / 헤이즐넛)·香草奶油 (Vanilla Cream / 바닐라 크림)·卡通甜甜圈

9. London Bagel Museum (LBM) ★ 韩国贝果第一品牌

  • 店铺: 安国 (Anguk / 안국)·汝矣岛 (Yeouido / 여의도)·蚕室 (Jamsil / 잠실)·加山 (Gasan / 가산) ([#169](169_content_slug.md)·[#82](82_content_slug.md)·[#180](180_content_slug.md))
  • 特色: 蒜香贝果 (Garlic Bagel / 갈릭 베이글)·印度奶茶 (Chai Latte / 차이라떼)·纽约风格12种

10. MAILLET 法式糕点

  • 店铺: 瑞来村 (Seoraemaeul / 서래마을) ([#173](173_content_slug.md)·[#225 咖啡馆](225_cafes.md))
  • 特色: 马卡龙 (Macaron / 마카롱)·羊角面包 (Croissant / 크루아상)·巧克力面包 (Pain au Chocolat / 뺑오쇼콜라)·闪电泡芙 (Éclair / 에클레르)·新罗酒店 (Shilla Hotel / 신라호텔) 供货

④ 奢华·体验 (2 + 额外4)

11. 新罗酒店 (Shilla Hotel / 신라호텔) 糕点·甜点

  • 店铺: 奖忠洞 (Jangchung-dong / 장충동) 新罗酒店 (Shilla Hotel / 신라호텔) ([#13 南山姐妹](13_namsan_sister.md))
  • 外国人 ★: ◎ — 韩国第一酒店甜点 + 外国人奢华体验首选
  • 特色: 酒店酒廊 + 法式 + 韩国传统

12. 金玉堂 (Geumokdang / 금옥당)·传统韩式点心 (延禧)

  • 店铺: 延禧洞 (Yeonhui-dong / 연희동) ([#156](156_content_slug.md))
  • 外国人 ★: ◎ — 韩国传统韩式点心 (Hangwa / 한과) + 结合茶道
  • 特色: 韩国传统韩式点心 (Hangwa / 한과)·药果 (Yakgwa / 약과)·打糕 (Injeolmi / 인절미)

+ 额外4

  • 蜂蜜糯米糕 (Kkultteok / 꿀떡) — 蜂蜜 (Kkul / 꿀) + 糯米糕 (Tteok / 떡) 结合的节日美食
