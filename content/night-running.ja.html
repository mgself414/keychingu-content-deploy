ソウルの夜間ランニング — 日が沈んだあとに走れる場所、閉まる時間と冬に止まるもの

サブタイトル: 日が沈んだあとにソウルで走りたい人が先に知っておくことは三つだ。どこが何時に閉まるか、冬に何が止まるか、走ったあとにどこで体を洗い荷物を取り出すかである。オリンピック公園は22:00に園内への入場が終わり、汝矣島漢江公園のシャワー室も22:00に閉まる。地下鉄駅のランナー支援スペースは23:00までだ。盤浦の月光レインボー噴水は3月15日から10月までしか稼働しないので、11月から翌年3月14日までは見られない。国民投票に上がったソウルのランニングコースのうち、夜に関する機関の案内がある7か所を選び、機関が示した値を中心に整理した。

ISSUE 06 · #147 · 2026-11-24 · ソウルの夜間ランニング

🎯 だれのための、なぜこの7か所なのか

昼は観光をして、夕方や夜に1時間ほど走りたい旅行者に向けた記事です。昼に走るときは長さと行き方だけ知っていれば足りますが、夜は考えることが増えます。公園が閉まる時間、荷物を預けた場所が閉まる時間、季節によって消える施設です。

選んだ基準は二つです。第一に、韓国観光公社「名所発掘100×100」 (Korea Tourism Organization "100×100 Spot Discovery" / 한국관광공사 명소발굴 100×100)のランニングコース国民投票に上がったソウルのコースであること。第二に、管理機関やソウル市が夜に関する内容 (閉まる時間、照明、夜に使う施設)を示していること。この二つの条件を満たしたコースのうち、この記事は7か所を扱います。汝矣島漢江公園 (Yeouido Hangang Park / 여의도한강공원)、盤浦漢江公園 (Banpo Hangang Park / 반포한강공원)、ソウルの森 (Seoul Forest / 서울숲)、清渓川 (Cheonggyecheon Stream / 청계천)、オリンピック公園 (Olympic Park / 올림픽공원)、京義線森の道 (Gyeongui Line Forest Park / 경의선숲길)、南山北側循環路 (Namsan Northern Circular Road / 남산 북측순환로)です。

同じ投票で9位 (136票)のトゥクソム漢江公園 (Ttukseom Hangang Park / 뚝섬한강공원)をはじめ、昼のコース全体の長さと行き方は#146にまとめました。この記事は、#146と重なる場所の紹介を減らし、夜に必要な情報だけを集めました。

⚠ 表記の原則: 利用時間、料金、施設、行き方は、ソウル市未来漢江本部 (Seoul Metropolitan Government Hangang Project Headquarters / 서울시 미래한강본부) (漢江公園)、ソウル施設公団 (Seoul Facilities Corporation / 서울시설공단) (清渓川)、韓国体育産業開発 (Hanguk Cheyuk Saneop Gaebal / 한국체육산업개발) (オリンピック公園)、ソウルの公園 (Seoul Parks / 서울의공원) (京義線森の道)、ソウル市の発表で2026-11-24に閲覧した値です。機関が示していない項目は書いていません。そのため、照明がつく時刻と消える時刻、日没の時刻、走るのにかかる時間は、この記事にありません。清渓広場 (Cheonggye Plaza / 청계광장)まで歩く時間はカカオマップの経路検索の値です (2026-11-24)。得票と順位は、韓国観光公社「名所発掘100×100」ランニングコース国民投票の値です。運営時間と出入りの方法は変わることがあります。

🚦 夜に走る前に — 共通の安全とマナー

7か所とも、ランニング専用の道ではありません。散歩する人、自転車、観光客と一緒に使います。機関が決めたルールと、大勢で使う道で守る一般的なマナーに分けて書きます。

機関が決めたルール

  • 漢江公園の自転車ルール。 ソウル市未来漢江本部の案内によると、漢江公園では自転車は自転車道だけを走り、時速20km以下で走行し、右側通行を守って一列で行きます。夜はライトをつけます。
  • 清渓川。 自転車とインラインスケートに乗れず、動物を連れて入ることもできません (障害者補助犬は除く)。喫煙と飲酒も禁止リストにあります。走ることはこのリストにありません。
  • オリンピック公園。 22時以降は公園の中に入れません。土城の中の散策路は歩行者優先の区間で、ペットの犬はリードをつけます。
  • 漢江公園。 禁煙です。犬のリードをつけないと過料5万ウォン、ごみを置いていくと過料10万ウォンです。

夜道のマナー

以下は規定ではなく、一緒に使う道でのマナーです。

  • 走る人は自転車道に入らない。 自転車は自転車道だけを走ることになっているので、走る人が歩行路を使えば、ぶつかることが減ります。盤浦漢江公園の紹介は、自転車道と散策路が分かれていると書いています。
  • 明るい色の服や反射素材を着る。 暗い色の服は、自転車やほかの歩行者の目に遅く入ります。
  • イヤホンの音量を下げる。 後ろから来る自転車のベルの音や案内放送が聞こえなければなりません。清渓川のまわりに雨が降っていなくても、避難の案内放送が流れることがあります。
  • 狭い道では速度を落とす。 清渓川と京義線森の道の延南洞 (Yeonnam-dong / 연남동)区間は観光地のど真ん中です。人が集まった区間では歩きます。

急なとき

  • 事故や緊急時は119、犯罪の通報は112です。
  • 清渓川で急に降った雨で取り残されたら、清渓川総合状況室 02-2290-7111~3に電話します。

① 漢江 — 2か所

汝矣島・盤浦漢江公園へのアクセス案内には、案内センターの取り締まり勤務が00:00~24:00、行政業務が09:00~18:00と書かれています。

汝矣島漢江公園 (Yeouido Hangang Park / 여의도한강공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 162票·2位。
  • 夜に使う施設: 走ったあとに体を洗えるオープン型シャワー室が、公園の案内センター1階にあります。毎日06:30~22:00に開きます。5号線 汝矣ナル駅の中には、更衣室とロッカーを備えたランナーステーションがあります。二つの施設の詳しい値は、下の「体を洗って荷物を預ける場所」に書きました。
  • 閉まる時間: シャワー室は22:00に閉まります。シャワーは20分以内に終えることになっているので、ランニングを終える時刻は22:00よりゆとりをもって前に置きます。
  • 行き方:
  • 5号線 汝矣ナル駅 2・3番出口: 歩いて1分、公園の中心部。エレベーターは2番出口の近くにあります。
  • 9号線 国会議事堂駅 (Gukhoeuisadang Station / 국회의사당역) 1番出口: 歩いて1分、国会の裏側。
  • 冬に止まるもの: ムルビッ広場 (Mulbit Plaza / 물빛광장)の噴水は4~10月だけ稼働します。

盤浦漢江公園 (Banpo Hangang Park / 반포한강공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 143票·6位。
  • 月光レインボー噴水 (Banpo Moonlight Rainbow Fountain / 반포 달빛무지개분수): 盤浦大橋に設置した噴水で、全長1,140mです。ソウル市未来漢江本部は、夜は景観照明を使って夜景を演出すると紹介しています。観覧は無料で、予約なしに現地で見ます。
  • 運営期間: 3月15日から10月までです。11月から翌年3月14日までは稼働しません。11月~3月14日に盤浦を走るなら、噴水のない川辺を走ることになります。
  • 回(毎回20分): 3月15日~5月と10月は12:00、19:30、20:00、20:30、21:00です。6~9月はここに21:30が加わります。平日と週末の区別はありません。夕方の回だけ見れば、19:30から30分間隔です。
  • 稼働を止めるとき: 風速が秒速7m以上のとき、稼働時間に雨の予報があるとき、漢江の濁度が15NTU以上のときです。イベントがあると時間が変わることがあります。問い合わせ 02-3780-0578~9。
  • 潜水橋 (Jamsugyo Bridge / 잠수교): 公園の紹介によると、潜水橋は車道を減らして歩道を広げ、自転車専用の車線があります。
  • 行き方:
  • 9号線 新盤浦駅 1番出口: 盤浦ナドゥルモク (Banpo Nadeulmok / 반포나들목)から入って、歩いて約15分。
  • 3・7・9号線 高速ターミナル駅 (Express Bus Terminal Station / 고속터미널역) 8-1・8-2番出口 (またはゴトゥモールG1): 盤浦大橋の方向へ歩いて約15分。
  • 4・9号線 銅雀駅 (Dongjak Station / 동작역) 1・2番出口: 漢江沿いに西来島 (Seoraeseom Island / 서래섬)の方向へ歩きます。
  • どの駅からでも公園まで歩く時間があります。噴水の回に合わせるなら、この時間を足して出ます。
  • 冬に止まるもの: 月光レインボー噴水 (11月~3月14日)。公園の中の漢江循環観覧車、ヘチカー (Haechi Car / 해치카)は5~11月に運営し、運行は20時までです (月~金 14~20時、週末 11~20時、16~17時は休み)。

② 公園・森の道 — 3か所

3か所は夜の事情がそれぞれ違います。ソウル市はソウルの森が夜も開いていると発表し、オリンピック公園は22:00に園内への入場が終わります。京義線森の道は、ソウルの公園の案内に出ている公園のトイレが2か所で、そのうち1か所が夕方に閉まります。

ソウルの森 (Seoul Forest / 서울숲)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 130票·15位。
  • 利用時間: ソウル市の発表 (2026-10-30)は、ソウルの森が年中無休で24時間開いていると書きました。生態の森など一部の施設は、時間が別にあります。
  • 夜: ソウル市の2026-10-30の記事は、退勤後に照明に沿って歩く秋の夜の庭の散歩を紹介しました。
  • 公園道: ソウル市の発表によると、ソウルの森の中の主な公園道の合計22,747.6mは歩行者専用道なので、自転車は押して行きます。
  • 行き方: 水仁盆唐線 ソウルの森駅 4番出口から公園まで歩いて約2分です。

オリンピック公園 (Olympic Park / 올림픽공원)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 118票·24位。
  • 閉まる時間: 公園の中への入場が終わる時刻を示したのは、7か所のうちここだけです。
  • 徒歩と自転車の出入りは05:00~22:00です。
  • 広場地域は24:00までです。
  • 22時以降は公園の中に入れません。
  • 夢村土城 (Mongchontoseong Fortress / 몽촌토성)の区域は、文化財を守るため、利用時間外は中への出入りを止めます。
  • 深夜のイベントがある日は、出入口を開け閉めする時間が調整されることがあります。
  • 料金: 公園の利用は無料で、駐車は別に料金を払います。
  • 夜に選ぶコース: 公園を運営する韓国体育産業開発が「散歩/ジョギングコース」として案内している道は5本です。一周の距離が決まっているので、22:00前に終えられる長さを選びやすいです。
  • 湖畔の道 1,302m、土城の道 2,210m、若さの道 (Jeoleumui-gil / 젊음의 길) 3,150m、思い出の道 3,350m、恋人の道 4,290mです。コースごとの経路は#146に書きました。
  • 土城の道、思い出の道、恋人の道は夢村土城の区域を通ります。この区域は利用時間外の出入りを止めるので、遅い時間は避けます。
  • 若さの道は自転車の環状道路です。自転車に気をつけて走ります。
  • 行き方: 駅が3つあり、路線が違います。
  • 8号線 夢村土城駅 1番出口
  • 5号線・9号線 オリンピック公園駅 (Olympic Park Station / 올림픽공원역) 3・4番出口
  • 9号線 漢城百済駅 (Hanseong Baekje Station / 한성백제역) 2番出口
  • 公園の案内は、東1門をオリンピック公園駅の側、南4門と平和の門広場 (Peace Gate Plaza / 평화의문광장)を夢村土城駅・漢城百済駅の側にまとめて書いています。

京義線森の道 (Gyeongui Line Forest Park / 경의선숲길)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 104票·33位。
  • 夜に考えること — トイレ: ソウルの公園の案内に出ている公園のトイレは二つです。管理事務所のトイレは平日09:00~18:00だけ開き、塩里洞のトイレは24時間開いています。夕方6時以降に使える公園のトイレは、塩里洞の1か所です。走る前に駅のトイレに先に寄ります。
  • 長さ: ソウルの公園の案内は、全体を約6.3kmと書いています。延南洞区間は約1.2kmです。区間を一つ選んで往復します。
  • 行き方: 区間ごとに駅が違います。
  • 延南洞区間: 弘大入口駅 (2号線・空港鉄道・京義中央線)、加佐駅 (Gajwa Station / 가좌역) (京義中央線)。ソウル市の発表 (2025-03)は、弘大入口駅 3番出口から438mと書きました。
  • 臥牛橋区間: 弘大入口駅、西江大駅 (Sogang Univ. Station / 서강대역) (京義中央線)
  • 新水・大興・塩里洞区間: 6号線 孔徳駅 (Gongdeok Station / 공덕역)、6号線 大興駅 (Daeheung Station / 대흥역)
  • セチャンゴゲ・孝昌路区間: 6号線 孝昌公園前駅 (Hyochang Park Station / 효창공원앞역)

③ 都心 — 2か所

清渓川 (Cheonggyecheon Stream / 청계천)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 128票·18位。
  • 夜: ソウル施設公団は、清渓川の照明を10,419灯と書いています。
  • 長さ: ソウル施設公団は、全長を8.12km、復元した区間を5.84kmと書いています。
  • 行き方: カカオマップの経路検索では、5号線 光化門駅 5番出口から清渓広場まで歩いて3分 (約120m)です。光化門駅の中には、23:00まで開くランナー支援スペース (Runner Support Space / 러너지원공간)があります。
  • 雨が降ると閉まる: 清渓川は時間ではなく天気で閉まる場所です。
  • 雨で水門が開くと予想されると、立ち入りを止めます。
  • 清渓川のまわりに雨が降っていなくても、避難の案内放送が流れたら、すぐ川の外に出ます。上流に降った雨でも水かさが増します。
  • 水位が上がったら、案内放送と安全要員の案内に従って、近い出入口から上がります。
  • 橋の下で雨宿りをしません。雨が降ると水門が急に開いて、橋の下は危険です。
  • 急に降った雨で取り残された人のための非常用のはしごが39か所にあります。
  • できないこと: 自転車とインラインスケートの利用、動物を連れての出入り (障害者補助犬は除く)、釣り、水泳、野営・炊事、喫煙・飲酒です。ペットの犬と一緒に走る予定なら、ほかの場所を選びます。

南山北側循環路 (Namsan Northern Circular Road / 남산 북측순환로)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 85票·59位。
  • 夜: ソウル市の記事 (2018-08)は、この道について、夜になると照明が一つずつつき、城郭道の趣が深まると書きました。
  • 車と自転車: ソウル市は、この道を、車と自転車の通行が全面禁止で歩行者だけが通る散策路と紹介しました。車両の全面規制は1996年6月に始まりました。
  • 区間と距離: ソウル市の記事は、教育科学院から国立中央劇場まで約3.3kmと書きました。往復すると約6.6kmです。地図アプリでは、二つのうち宿から近い方を目的地に設定します。
  • 南側循環路と混同しない: ソウル市の記事 (2025-06)によると、南側循環路 (Namsan Southern Circular Road / 남측순환로)は歩行者と車が共用する道路で、車両と自転車が一方通行で通ります。南側循環路は車と自転車が一方通行で通る道路なので、この記事は北側だけを扱います。

🚿 体を洗って荷物を預ける場所

夜に走ると、宿に寄らずにそのまま出ることが多くなります。荷物を預けて着替えられる場所と、体を洗える場所を、閉まる時間とともに書きます。

  • 地下鉄駅のランナー支援スペース3か所: ソウル市が2025年10月に発表しました。光化門駅 (5号線)・会賢駅 (Hoehyeon Station / 회현역) (4号線)・ワールドカップ競技場駅 (World Cup Stadium Station / 월드컵경기장역) (6号線)の3か所です。毎日05:30~23:00に開き、地下鉄の運行時間に合わせて運営します。出入りに別の利用料金はないと、ソウル市が発表しました。出入りはNaver QRまたはカカオトーク認証で行います。男女別の更衣室、個人用ロッカー、パウダールーム、ランニング用品の自動販売機があります。清渓広場から出発するなら、光化門駅のものがあります。
  • 汝矣島漢江公園のオープン型シャワー室: 毎日06:30~22:00に開きます。08:30~09:30と15:30~16:30は清掃の時間です。無料で、タオルと洗面用具は各自で用意します。入場はNaverアプリのQRコード認証で行います。男女のシャワーブースが5つずつあり、ロッカー13個、更衣室2室があります。シャワーは20分以内に終え、洗濯はできません。問い合わせは汝矣島案内センター 02-3780-0563です。
  • 汝矣ナル駅のランナーステーション: ソウル市が2024年5月に発表した施設です。5号線 汝矣ナル駅の中のB1~M1階にあります。更衣室、パウダールーム、ロッカー58個 (M1階42個、B1階16個)があります。

ランナー支援スペースはNaver QRまたはカカオトーク認証、シャワー室はNaverアプリのQR認証で入ります。使う日の前に、自分のスマートフォンで認証画面が開くかどうかを先に見ます。認証ができないときを考えて、宿で着替えて出る計画も一緒に立てておきます。

⚠ よくある間違い3

  1. 冬に噴水を見に盤浦へ行く — 月光レインボー噴水は3月15日から10月までしか稼働しません。11月から翌年3月14日までは、夕方に行っても噴水は出ません。汝矣島のムルビッ広場の噴水も4~10月しか稼働しません。
  2. オリンピック公園を夜遅くに走る場所にする — 徒歩の出入りは22:00までで、その後は公園の中に入れません。広場地域だけ24:00までです。夕方に走るなら、22:00前に出られるように時間を決めます。
  3. 荷物を預けた場所が閉まる時間を過ぎる — 地下鉄駅のランナー支援スペースは23:00、汝矣島漢江公園のシャワー室は22:00に閉まります。ランニングを終えて戻ってくる時間まで入れて計算します。シャワー室は20分の利用制限があるので、22:00の直前に着くと洗う時間が足りません。

⚙ FAQ 3

  1. 夜遅くまで開いている所はどこ? — ソウルの森は年中無休で24時間開いているとソウル市が発表しました。オリンピック公園は徒歩の出入りが22:00までで、広場地域だけ24:00までです。汝矣島・盤浦の案内センターの取り締まり勤務は00:00~24:00です。清渓川は、雨で水門が開くと予想されると、立ち入りを止めます。
  2. 冬に止まる施設は? — 盤浦の月光レインボー噴水 (3月15日~10月稼働)、汝矣島のムルビッ広場の噴水 (4~10月稼働)、盤浦漢江公園の漢江循環観覧車 (5~11月運営)です。
  3. 走ったあとに体を洗える所はある? — 汝矣島漢江公園の案内センター1階にオープン型シャワー室があります。毎日06:30~22:00、無料で、NaverアプリのQRコード認証で入ります。タオルと洗面用具は持っていきます。地下鉄駅のランナー支援スペース3か所は、更衣室と個人用ロッカーを使う所です。
