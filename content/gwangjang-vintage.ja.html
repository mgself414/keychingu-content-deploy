広蔵市場 (광장시장) 古着ゾーン、なぜ行くべき?

「食のマーケットの真上に隠れたパターン・レディース古着の聖地」

広蔵市場 (광장시장) は世界的に知られた韓国を代表する食のマーケットです。ピンデトク (빈대떡・緑豆チヂミ)・マヤッキンパプ (마약김밥・中毒性キンパ)・ユッケを食べようと外国人が行列を作る1階の光景は、SNSに最も多く登場する風景のひとつです。

ところが、その真上の2階はまったく別の世界。1980年代から続く輸入ヴィンテージ古着ゾーン (구제상가)に約200〜300店舗が軒を連ね、韓国の10〜20代ヴィンテージ好きにとってのもう一つの聖地となっています。外国人観光客はほとんど来ないため、韓国のファッション好きたちの「秘密のディグスポット」とも呼ばれています。

キチング (키친구) が広蔵市場 (광장시장) の古着ゾーンを トンミョ (동묘) とは別に推す4つの理由:

1. レディースパターン・ワンピース特化 — トンミョ (동묘) は混合の古着の山が中心ですが、広蔵2階はパターンワンピース・レトロブラウス・ツイードジャケットが主力。秋冬アウター (청재킷・야상・코트 / デニムジャケット・フィールドジャケット・コート) も豊富

2. ハンガー陳列型ディグ — 古着の山なし — すべての衣類がハンガーにかかっており、サイズ・アイテム別に整理されている。トンミョ (동묘) の路上販売より難易度が大幅に低い

3. 食のマーケットまで徒歩1分 — ディグ後に1階へ降りればすぐマヤッキンパプ (마약김밥)・ピンデトク (빈대떡)・ジャンチグクス (잔치국수・そうめん風温麺)。動線の効率は広蔵が圧倒

4. チョンノオガ (종로5가) = 韓国観光公社100選 — 1階の食事＋2階の古着＋近隣のトンデムン (동대문)・ナクォンサンガ (낙원상가) まで徒歩30分圏内。外国人が迷いにくい古着入門コース

広蔵市場 (광장시장) の3層構造を理解する

広蔵市場 (광장시장) はシンプルな1階建て市場ではありません。フロア・棟ごとにまったく異なる市場が重なっています。

フロア エリア メインカテゴリ 外国人視点
1階 東側 フードストリート (먹자골목) ピンデトク・マヤッキンパプ・ユッケ・ジャンチグクス 広蔵のシグネチャー。並んで食べる場所
1階 西側 ハンボク (한복)・布団・反物 韓服・伝統生地・布団 外国人ほぼなし、興味深いエリア
2階 西側 輸入ヴィンテージ古着ゾーン (구제상가) ヴィンテージ衣類 今回のコンテンツのメイン
2階 東側 アクセサリー・雑貨 バッグ・時計・靴 卸売中心、一般観光客には不向き

8番出口を出て直進 → フードストリート通過 → マンナムの広場 (만남의 광장) 골목 (골목・路地、日本語の「横丁」に近い概念) → ビル2階の階段が古着ゾーンへの標準ルートです。

古着ゾーンの品目 — 広蔵の4つの強み

強み 1 — パターンワンピース (韓国ヴィンテージの真髄)

1970〜90年代の韓国ファッションが誇る華やかなパターン (花柄・幾何学・ペイズリー) が生きたワンピースが最も多いのがここ。トンミョ (동묘) ではほとんど見かけないカテゴリです。

  • 価格: ₩10,000〜40,000 (~1,060〜4,240 JPY)
  • サイズ: 韓国式表記 (小さめ) — 「55」は日本S、「66」はMに相当
  • おすすめの使い方: インスタ映え、韓国風の春・秋ピクニックルック

強み 2 — レトロブラウス + スカートセットアップ

90年代に日本・香港から輸入されたツイード、シャツブラウス、Aラインスカートが豊富。セットアップとしてコーディネートを提案している店舗も多数。

  • 価格: セットアップ1セット ₩30,000〜80,000 (~3,180〜8,480 JPY)
  • おすすめシーズン: 春・秋

強み 3 — 秋冬アウター (デニムジャケット・フィールドジャケット・コート)

広蔵古着ゾーンの真の強みは秋冬アウター。日本・アメリカ・ヨーロッパから輸入された卸売アウターは、トンミョ (동묘) よりもキュレーションの質が高め。

  • デニムジャケット (청재킷): ₩15,000〜40,000
  • フィールドジャケット ヤサン (야상 / M-65スタイルなど): ₩30,000〜60,000
  • コート (ウール・カシミヤ混): ₩50,000〜150,000
  • ブランドヴィンテージコート (Burberry、Maxmara など): ₩100,000〜500,000

強み 4 — ブランドヴィンテージ専門店 (Burberry、YSL、Aquascutum など)

広蔵2階の奥深くに隠れた一部の店舗はブランドヴィンテージ専門。トンミョ (동묘) のサロン・ド・ボン (살롱드봉) と近いポジションですが、店舗数はより多め。

  • 価格: ₩50,000〜200,000 (状態の良いブランドコート1点)
  • ヒント: 「사장님 명품 있어요? (sajangnim, myeongpum isseoyo? / オーナーさん、ブランドものありますか?)」のひと言で奥の在庫を出してくれることが多い

ディグ6ステップ — トンミョ (동묘) との違い

ステップ 1 — 時間を選ぶ

  • 平日 10:00〜12:00: キチング (키친구) 推奨 #1。新着入荷直後＋空いている＋スタッフも親切。ゆっくりサイズ・状態確認が可能
  • 平日 14:00〜16:00: 1階の食事客が2階にも影響。ディグ自体はできるが狭い通路が圧迫感あり
  • 週末: 1階の行列＋2階の古着客で同時に混雑爆発。非推奨
  • 日曜日: 店舗の50%以上が休業。行かないこと

ステップ 2 — 8番出口 → 2階へ

  • チョンノオガヨク (종로5가역) 8番出口 → 直進 約100m → 広蔵市場 (광장시장) 西側入口 (ハンボク・布団通り)
  • 入口で 「구제상가 어디예요? (gujesangga eodieyo? / 古着ゾーンはどこですか?)」 と聞くと案内してもらえる
  • マンナムの広場 (만남의 광장) の골목 (골목・路地) → ビル2階の階段

ステップ 3 — 1周して相場を把握

最初は買わずに2階全体を1周して相場感をつかむことが先決。所要約30分。パターンワンピースは₩10,000〜40,000が平均。

ステップ 4 — 店舗へ (グジェ vs ボセの見分け方)

広蔵2階の重要な注意点: すべての服がヴィンテージではありません。2種類が混在しています。

種類 特徴 価格
輸入グジェ (구제・本物の中古ヴィンテージ) 本物の中古ヴィンテージ。日本・欧州・米国から輸入 ₩10,000〜200,000
ボセ新品 (보세・無名ブランド新品) 東大門 (동대문) 卸から仕入れた新品。ヴィンテージデザインだが新品 ₩10,000〜50,000
偽ブランド品 Burberry・LVなどの偽造ラベル 定価を装った ₩50,000〜200,000

見分けヒント:

  • ラベル確認: 韓国語ラベルならボセ (보세)、日本語・英語・イタリア語ラベルなら輸入グジェ (구제) の可能性が高い
  • 服のコンディション: 微妙な使用感 (衿ラベルのわずかな摩耗、ボタンの跡) があれば本物のグジェ (구제)。あまりにも新品すぎればボセ (보세)
  • 迷ったら「구제예요 보세예요? (gujeyeyo, boseyeyo? / ヴィンテージですか、新品ですか?)」と聞く — 正直なオーナーはちゃんと答えてくれる

ステップ 5 — 交渉 + 支払い

  • 広蔵2階は店舗の定価制が強め。値引き幅はトンミョ (동묘) より少ない (10〜20%)
  • まとめ買い (2〜3点以上) の場合は割引交渉が可能
  • カード決済できる店舗の割合はトンミョ (동묘) より高め — 約70%
  • ただし少額 (₩10,000以下) は現金推奨 — 店舗の負担軽減のため

ステップ 6 — 1階フードコーナーでランチ

ディグが終わったら1階東側へ降り、広蔵シグネチャーフードでフィニッシュ。ディグ＋食事がワンセットで楽しめるのが広蔵の最大の強みです。

広蔵市場 (광장시장) の食事コンテンツは別途 ([ストリートフードの聖地](#15_street_food_mecca.md) 参照) で詳しく紹介しているため、ここでは古着ディグ直後に最も近い5選のみ簡単に。

  • トンミョ (동묘) と同様の価格帯。広蔵フードストリート内にも同様の店あり

4. ユッケ (육회) (チャメジプ (자매집)、ブチョンユッケ (부촌육회) など)

  • 価格: 1人前 ₩15,000〜25,000 (~1,590〜2,650 JPY)

  • 価格: 1個 ₩1,500〜3,000 (~159〜318 JPY)

外国人がよく聞く質問

Q1. 英語は通じますか?

1階フードストリートのオーナーは英語・日本語・中国語が話せる方が多いです (外国人客が多いため)。2階古着ゾーンはほぼ韓国語のみ。サイズや価格は数字で通じます。

Q2. 日曜日に行っても大丈夫ですか?

非推奨。1階フードストリートは営業していますが、2階古着店舗の50%以上は休業。ディグが目的なら平日または土曜日に。

Q3. ボセ (보세) とグジェ (구제) の区別がつかない場合は?

オーナーに直接聞く＋ラベルを1度確認＋あまりにも新品っぽければ疑う。₩30,000以上の店舗で疑わしい場合は別の店舗を推奨。

Q4. 偽ブランド品を買っても大丈夫ですか?

韓国では偽ブランド品の購入自体は違法ではありませんが、母国へ持ち帰る際に税関で没収される可能性があります (国によって異なります)。ブランドラベルには慎重に。

Q5. サイズの試着はできますか?

店舗内に簡易試着スペースがある場合や、上から重ね着して確認する場合もあります。期待値はトンミョ (동묘) と同程度 — 鏡のない店舗の方が多め。

Q6. トンミョ (동묘) と同じ日に行けますか?

可能です。広蔵 (광장시장) 10:00〜12:00 ディグ → 広蔵1階ランチ → 1号線2駅でトンミョアプヨク (동묘앞역) → トンミョ (동묘) 午後ディグというコースがヴィンテージ丸1日コースとして人気です。
