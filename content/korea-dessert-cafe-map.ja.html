韓国スイーツ店ガイド — ケーキ・ドーナツ・クッキー・老舗ベーカリー10か所(パッション5・マイエ・ドーナツ・ジョンス・太極堂・コロンバン製菓店) (2026年10月公式値)

サブタイトル: パッション5 (패션5) ベーカリー07:30~22:00・スイーツ300~400種余り(VisitKorea) · マイエ (마얘) 西来村のフレンチスイーツ、ミルフィーユバニラとマカロン(VisitKorea) · ドーナツ・ジョンス (도넛정수) 開城のチュアクから着想した韓国式ドーナツ(VisitKorea) · 太極堂 (태극당) 1945年開業、08:00~21:00(VisitKorea) · 価格は10か所すべて未掲載 — 2026-10-21時点

🎯 このガイドの使い方

ショーケースのガラスに鼻を近づけるとバターの香りが先に届き、店員がケーキをナイフで切ってお皿に出してくれます(カムコッタン (감꽃당) ではフォークとナイフの代わりに店員が切って出してくれます、VisitKorea)。このガイドは、コーヒーよりもケーキ・ドーナツ・クッキー・パンが主役のお店だけを扱います。ジャンルは3つ:ケーキ・パティスリー、ドーナツ・クッキー、老舗ベーカリー。お店はすべて韓国観光公社の観光情報(VisitKorea、TourAPI)に登録されている所です。コーヒーと空間が主役のカフェは #913 ソウルカフェガイド、秋の食材のスイーツは #475 秋のスイーツガイド に分けました。

旧ガイドは群山の李盛堂 (イソンダン / 이성당) を全州の行程に入れていましたが、VisitKoreaの李盛堂は全羅北道群山市 中央路 (チュンアンノ / 중앙로) 177にあります。ロンドンベーグルミュージアム (런던베이글뮤지엄) も「クロワッサンの店」と書かれていましたが、VisitKoreaはベーグル専門店として紹介しています。「韓国一のマカロン」「外国人人気1位」のような順位の表現は、出典がないので削りました。

🎂 ケーキ・パティスリー — ソウル4か所

  • パッション5 (패션5、Passion 5) — ソウル特別市龍山区 梨泰院路 (イテウォンノ / 이태원로) 272(漢南洞 (ハンナムドン / 한남동))。ベーカリー07:30~22:00、ジェラートカフェ11:00~20:00、年中無休。ケーキ・手作りチョコレート・クッキー・プリンから各国のベーカリーまで300~400種余りを並べ、ギャラリーのように見て回りながら選びます。看板メニューはオーサムアップルパイで、エクレア・クロワッサン・カヌレもあります。購入レシートがあれば駐車1時間無料。電話 0507-1416-9505(VisitKorea)
  • マイエ (마얘、MAILLET) — ソウル特別市瑞草区 沙坪大路22街 (サピョンデロ22キル / 사평대로22길) 14(盤浦洞 (パンポドン / 반포동) 西来村 (ソレマウル / 서래마을))。11:00~21:30、年中無休。フランス伝統のスイーツ店で、ミルフィーユバニラ (밀푀유바니)・タクトバニラ (딱뜨바니)・フランス式マカロンが看板メニューです。テイクアウト可。電話 02-749-1411(VisitKorea)
  • ルモンブラン (르몽블랑) — ソウル特別市龍山区 新興路 (シンフンノ / 신흥로) 99-4(解放村 (ヘバンチョン / 해방촌))。火~木12:00~19:00、金・土12:00~20:00、月曜休み。20年間ニット工場だった建物を直しました。そのため毛糸のムースやニットTシャツケーキが看板です。1階は製造室とショーケース、2階は座席、3階はルーフトップ。電話 070-8887-8200(VisitKorea)
  • カムコッタン (감꽃당) — ソウル特別市鍾路区 敦化門路11タ街 (トンファムンノ11タギル / 돈화문로11다길) 38。10:30~22:00、年中無休。古い柿の木を生かした韓屋 (ハノク / 한옥) カフェです。りんごで作るアップルパイ、発酵バターのスコーン、エッグタルトが看板メニュー。フォークとナイフは出さず、店員が切ってからおしぼりを出します。電話 02-747-3999(VisitKorea)

🍩 ドーナツ・クッキー — ソウル3か所

  • ドーナツ・ジョンス (도넛정수) — ソウル特別市鍾路区 昌信12街 (チャンシン12キル / 창신12길) 40。11:30~21:00(ラストオーダー20:30)、年中無休。もち米を油で揚げた開城の伝統菓子「チュアク (주악)」から着想した韓国式ドーナツの店で、全国の特産物で作ったドーナツを9種類出します。タラク (타락、牛乳)・抹茶・レモンヨーグルトのドーナツなど。座敷席と椅子席があり、窓の外にソウルの景色が見えます。電話 0507-1386-5775(VisitKorea)
  • オーバードーズドーナツ&コーヒー (오버도즈도넛앤커피) — ソウル特別市城東区 往十里路10街 (ワンシムニロ10キル / 왕십리로10길) 19(纛島駅 (トゥクソムヨク / 뚝섬역) 7番出口から約110m)。11:30~20:30、月曜休み。毎日明け方にカスタードを煮て、クリームは当日生産、売れ残ったドーナツはその日のうちに捨てます。看板メニューはピスタチオ&ラズベリードーナツ、アールグレイクリームドーナツ。店は1.5階にあります。電話 0507-1319-7369(VisitKorea)
  • ジョンエクッキー (정애쿠키) — ソウル特別市麻浦区 東橋路46街 (トンギョロ46キル / 동교로46길) 33(延南洞 (ヨンナムドン / 연남동))。11:00~19:00、年中無休。おばあさんの店主がバターなしで国産全粒粉のクッキーを焼きます。看板メニューは唐辛子クッキー、ジョンエクッキーとチョコチップクッキーもあります。テイクアウト可。電話 02-747-0178(VisitKorea)

🏛 老舗ベーカリー — ソウル・木浦・鎮海の3か所

  • 太極堂 (テグクタン / 태극당) — ソウル特別市中区 東湖路24街 (トンホロ24キル / 동호로24길) 7(奨忠洞2街 (チャンチュンドンイガ / 장충동2가))。08:00~21:00、年中無休。VisitKoreaの紹介文は、1945年の光復のころに開いたソウルで一番古いパン屋として紹介しており、3代目が受け継いでいます。看板メニューは60年代から売ってきた牛乳味アイスクリームモナカ(あんをはさんだ最中)で、あんパン・バターパン・クリームパン・昔ながらのバターケーキもあります。電話 02-2279-3152(VisitKorea)
  • コロンバン製菓店 (코롬방제과점) — 全羅南道木浦市 霊山路75番街 (ヨンサンノ75ボンギル / 영산로75번길) 7(務安洞 (ムアンドン / 무안동))。08:00~21:00、休業日は未掲載。クリームチーズバゲットとえびバゲットが看板メニューです。電話 061-244-0885(VisitKorea)
  • ミジン菓子店 (미진과자점) — 慶尚南道昌原市鎮海区 忠壮路130番街 (チュンジャンノ130ボンギル / 충장로130번길) 4。07:00~22:00、年中無休、カード可、テイクアウト可。鎮海で一番古いパン屋として知られ、鎮海製菓 (チンヘジェグァ / 진해제과) と一緒に桜パン・桜ロール・桜はちみつマドレーヌを開発しました。桜パンの主原料は桜のエキスとピンクの桜あんです。VisitKoreaの登録名には「百年店 (ペンニョンカゲ / 백년가게)」の表示がついています。電話 055-545-3133(VisitKorea)
  • 群山の李盛堂・大田の聖心堂 (ソンシムダン / 성심당) は別に扱いました — 外国人向け群山KTX 1泊2日フルガイド · 大田 聖心堂ベーカリー

🥗 食事制限

  • 価格帯: 10か所とも、VisitKoreaの登録値に価格がありません。価格は未掲載 — ショーケースの値札を見るか、電話で確認してください
  • ベジタリアン: ケーキ・ドーナツ・クッキーは、たいていバター・牛乳・卵が入ります。ジョンエクッキーはバターを使わないと紹介されていますが(VisitKorea)、卵・牛乳の有無は確認できませんでした — ヴィーガンの方は直接聞いてください
  • グルテン: ジョンエクッキーは国産全粒粉を使います(VisitKorea) — 小麦粉のスイーツです。米粉のスイーツは #475 秋のスイーツガイド の米スイーツの店を見てください
  • ナッツ・乳製品: オーバードーズの看板ドーナツにはピスタチオが、太極堂のモナカには牛乳味アイスクリームが入ります(VisitKorea)
  • ハラール: VisitSeoulは、梨泰院のイード (Eid / 이드)(龍山区 ウサダンノ10キル (우사단로10길) 15、毎日12:00~21:00)を、韓国イスラム教中央会(KMF)がハラールと認めた数少ない飲食店として紹介しています。認証は変わることがあるので、訪問前に確認してください。このガイドのスイーツ店にはハラール表示がありません。ムースやゼリー類のゼラチン、ケーキシロップの洋酒は店ごとに違うので、注文前に聞いてください
  • 見せるカードは #1300 食事リクエストマニュアル

🧰 スイーツ店の実務 — ひとり、予約、支払い、注文、移動

  • ひとり: ショーケースから1~2個選んで持ち帰れば、ひとりでも気楽です。テイクアウト可が登録されているのはマイエ・ジョンエクッキー・ミジン菓子店(VisitKorea)。ひとりで行ける場所の地図は #348 Seoul Solo Diner Map
  • 予約: 10か所とも予約の案内は登録されていません。パンの行列・順番待ちのコツは 韓国パン購入・順番待ちワークフロー
  • 支払い: カード可が登録されているのはミジン菓子店(VisitKorea)。カード・スマホ決済全般は #527 韓国の決済システム
  • 注文: ショーケースを指さして個数を言えば大丈夫です。呼び出しベルは #1288 カフェ呼び出しベルマニュアル、言葉が通じないときは #1339 注文エチケット
  • 移動: ソウルは #1298 交通カード3種の選び方。木浦・鎮海は #1287 KTX初めて乗る・#1297 高速・市外バスマニュアル

⚠ よくある間違い4つ

1. 「李盛堂は全州のパン屋」 — VisitKoreaの李盛堂の住所は全羅北道群山市中央路177です

2. 「ロンドンベーグルミュージアムはクロワッサンの店」 — VisitKoreaはベーグル専門店として紹介しています

3. 「スイーツ店は毎日遅くまで開いている」 — ルモンブランは月曜が休みで火~木は19:00、ジョンエクッキーは19:00に閉まります。オーバードーズドーナツ&コーヒーは月曜休みです(VisitKorea)

4. 「ケーキはフォークで自分で食べる」 — カムコッタンはフォークとナイフの代わりに店員が切って出してくれます(VisitKorea)
