韓国の分食の注文・食べるワークフロー

ISSUE 03・#811・2026-06-07

🎯 なぜ分食ワークフローガイドなのか

[#810分食8種マトリックス](#810) 知っていても — 注文・食べる過程は別個。韓国の分食は、（a）ストリートラブリー=即席+現金（b）市場の分食=合石+無料のおかず（c）MZストア=キオスク+カード。分別別のペアリングも核心：トッポッキ→天ぷら・スンデダンク/キンバプ→ダンムジ/オムク→うどんスープ。外国人は（1）メニューが多すぎて決めにくく（2）辛い加減がわからない（3）テイクアウトvs店舗比較わからない（4）決済（カードvs現金）混乱。本ガイドは5ステップ+分食別ペアリング+英語発話+店舗タイプ別差。

★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣店舗タイプを選択 エプニットvs市場vs MZストアvs砲車 即時
2️⃣メニュー注文 メニューパネルを見て1〜3種類を選ぶ 2〜5分 写真メニューの活用・辛さ加減要請
3️⃣を受け取る+ペアリング 即席の調理を受ける＋ペアリング（トッポッキ＋フライなど） 5〜15分 餅炒めスープに天ぷら・スンデダンク=コア
4️⃣食べる 店内/ストリートスタンドアップ/テイクアウト 10〜25分
5️⃣決済 カード/現金/キオスク

> 総所要時間: 通り・テイクアウト = 10～15分 / 店舗内 = 20～30分

🔥 分別別ペアリングガイド

🌶 トッポッキペアリング — 韓国の分食クラシック

1. 揚げダンク: イカ・サツマイモ・エビ揚げをトッポッキのスープにつけて食べる（#1）

2. スンデダンク:スンデをトッポッキスープに撮って食べる(ソウルクラシック)

3. キムバプ添え: キンバプをトッポッキスープに軽く湿らせて

4. 飲み物: サイダー・コーラ（辛味鎮静）

> 外国人の核心: トッポッキ = スープに撮って食べることが本質。ちょうど餅だけ食べないでください。天ぷら・スンデ・キンバップペアリング必須。

🍙 キンバップペアリング

1. ダンブジ (Yellow pickled radish): 組み込み、口元

2. ラーメンペアリング: キンバップ+ラーメン=韓国分食#1コンボ

3. トッポッキが添え: 辛味 ↔ キンバプ 柔らかさバランス

🍢 オオカミペアリング

1. うどんスープ: オムク斜面スープ無料提供

2. 醤油加減: 魚鉢売り醤油 1～2 dip

3. 串の形の通り: stand-up + 暖かいスープ

🌭ホットドッグペアリング

1. ケチャップ・マスタード・砂糖加減：本人追加

2. ドリンク: コーラ・サイダー (外国人 vlog パターン)

3. モッツァレラ=写真1番地: チーズ増える瞬間=インスタ1番地

🥟 餃子ペアリング

1. 醤油dipping (Soy sauce dipping): 基本

2. 唐辛子オイル (Spicy chili oil): 辛味

3. 餃子+餃子:明洞餃子シグネチャー

🏪 店舗タイプ別システム比較

Type A — ストリートエプニップ (Tteokbokki street stall)

  • 特徴:即席調理・1～3分受け取・現金多
  • おすすめ店：弘大・江南・明洞・梨泰院の通り・鍾路広場市場
  • 価格: 1,500～6,000ウォン (価格比 ★★★★★)
  • メニュー: トッポッキ・フライ・ホットドッグ・オムク
  • お支払い：現金をお勧めします（大きな売り手はカードOK）
  • 外国人親和性: ★★★ (英語メニューほとんど無し・写真メニュー活用)

Type B — 市場分食 (Market 分食)

  • 特徴: 合席可能・無料おかず・毎代別差別
  • おすすめ店舗：広場市場分食cluster・東大門夜明け分食・全州韓屋村分食・仁寺洞
  • 価格：3,000〜10,000ウォン
  • メニュー：6種～10種+マッコリ・焼酎ペアリング可能
  • 決済: 現金・カード混用
  • 外国人親和性: ★★★★ (広場市場 ★★★★★)

Type C — MZ 分食店 (MZ trendy 分食)

  • 特徴: キオスク注文・カード決済・インスタ雰囲気
  • おすすめ店：弘大・江南・延南・ソンス MZ トッポッキ・ホットドッグ店
  • 価格：5,000〜15,000ウォン（トレンド価格↑）
  • メニュー: ロゼトッポッキ・クリームラボッキ・チーズホットドッグ・トレンドメニュー
  • お支払い：キオスク+カードOK
  • 外国人親和性: ★★★★ (英語メニュー・写真メニュー多)

Type D — 砲車の分食 (Pojangmacha)

  • 特徴: 夜間・深夜・酒＋分食・通りのテント
  • おすすめ店舗: 鍾路・乙支路・江南・清涼里砲車cluster
  • 価格：分食4,000〜8,000ウォン+酒4,000〜8,000ウォン
  • メニュー: トッポッキ・スンデ・オムク・チョン・ウドン・ラーメン
  • 決済: 現金・カード混用
  • 外国人親和性: ★★ (韓国語メニュー・深夜の雰囲気)

🌶辛い加減ガイド

韓国風のスパイシーな段階

1. 中スパイシー (No spicy): 子供・辛い味わえない外国人

2. 軽くスパイシー (Mild): 最初のスパイシーな試み

3. 中-スパム (Medium): 韓国標準

4. スパイ (Spicy): 韓国マニア

5. 非常にスパイシー (Very spicy): 韓国人マニア (Buldak・ブルチックシリーズ)

###外国人英語発話サンプル

  • "私をマップしないでください" = "Less spicy, please"
  • "辛い味を外してください" = "No spicy, please"
  • "これは辛いですか？" = "Is this spicy?"
  • "揚げ物追加" = "More twigim, please"
  • "包装です" = "To go, please"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁な誤り5つ

1. "トッポッキ=ちょうど餅だけ食べる": トッポッキ= スープに天ぷら・スンデダンクが本質。ペアリングなしで餅だけ食べれば韓国分食経験50％だけ。

2. "ストリート売り場=衛生X": 回転率の高い売り場=衛生良好。ただし、清潔度も直接確認することをお勧めします。

3. "スパイシーフェーズ=標準":韓国標準=外国人にはとても辛い。 「しっかり」または「ほんのりスパイス」リクエストをお勧め。

4. 「分食店時間=一般食堂」: 分食店= 15分～ 食事時間短い（1次後2次ORまたは速い食事）。一般食堂＝1～1.5h。

5. "カード = すべてOK": 通り・市場売り場 = 現金推奨。 MZ店舗＝カード・キオスクOK。

⚙ よくある質問8件

1. 最初の分食=ある店舗: MZ店舗(Type C) — 英語メニュー・キオスク・トレンディ。慣れれば市場・通り。

2. 餅炒めないようにOK？：可能。 「内部にくい」または「宮中餅」の注文。

3. テイクアウトvs店舗違い:価格同じ。テイクアウト＝ワンタイムボウル・ストリートスタンドアップ。

4. 分食+酒ペアリング: 砲車(Type D) =分食+焼酎・マッコリ。市場分食も酒可能。

5. MZトレンドメニュー: ロゼトッポッキ・クリーム ラポッキ・チーズホットドッグ・ジャガイモホットドッグ。

6. アレルギー・妊娠: [#810 disclaimer](#810)参照。シーフード・グルテン・大豆注意。

7. 決済・チップ：カードOK多（MZ・市場大売り）/路上=現金推奨/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

分食＝街路・市場・売代多。衛生＝回転率・清潔も直接確認。子ども＝辛いトッポッキ・ラポッキの照り、辛いキンバップ・餃子・ホットドッグ推奨。妊娠中の女性=エビの箸、多大気、通りの食品衛生主義。アレルギー（シーフード・グルテン・豆・ナッツ類）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗情報免責: 路上売り場・市場店舗営業時間・メニューは変動頻度 — 訪問前 NAVER/Kakao map または現地検索を推奨。

食事制限 fallback:

  • ハラール・コーシャー: 一般分食店=ビハラル・ビコシャー。 → 梨泰院 一部ハラール店の事前検索。
  • ベジタリアン・ビーガン：キンバプ（マグロ・チーズを除く） = ベジタリアンOK / トッポッキは、オムク・再スープを含む（非ベジタリアン基本）→「魚ムック・再取り除いてください」要求必須/ホットドッグ・餃子・スンデ・オムク=非菜食。
  • グルテンフリー: トッポッキ味付け・ラポッキ・餃子・揚げ＝グルテン多。

💰 Essential Tourist Tips

  • 1人の平均費用（2026年6月現在）：
  • 通り = 5,000～10,000ウォン (3～4種試食)
  • 市場 = 8,000～15,000ウォン
  • MZ店舗＝10,000～20,000ウォン
  • 砲車＝15,000～30,000ウォン（酒含む）
  • 決済・チップ：カードOK 多 / 市場・路上
  • 緊急：☎1339（医療、英語）/☎1330（観光通訳）
  • VAT払い戻しX：飲食一般
