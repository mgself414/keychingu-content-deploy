束草的美食是从北方南下的——阿爸村与失乡民之味18家

副标题: 束草通常被介绍为雪岳山的大本营,美食往往只用一句甜辣炸鸡 (Dakgangjeong / 닭강정)就打发了。但束草美食的谱系指向的不是南方,而是北方。韩国战争时从咸镜道 (Hamgyeong / 함경도)逃难而来的人们在青湖洞 (Cheongho-dong / 청호동) 海边建起的阿爸村 (Abai Village / 아바이마을)、在那里传到第三代的阿爸血肠 (Abai Sundae / 아바이순대)、1951年开门的咸兴冷面店。从用手拉铁索过河的摆渡船 (Gaetbae / 갯배),到鹤沙坪 (Haksapyeong / 학사평) 嫩豆腐村——把束草当作一顿饭来读的方法

🎯 为什么说"从北方南下"

介绍束草美食的文章,大多从甜辣炸鸡开始,又在甜辣炸鸡结束。那是好吃的东西,也的确是束草名物。但走在束草市区,菜单上会看到陌生的名字:阿爸血肠 (Abai Sundae / 아바이순대)、鱿鱼血肠 (Ojingeo Sundae / 오징어순대)、明太鱼生冷面 (Myeongtae-hoe Naengmyeon / 명태회냉면)——这些名字在首尔不常见。再把束草的咸兴冷面 (Hamhung Naengmyeon / 함흥냉면) 也并排摆出来,

这些名字指向同一个方向。咸镜道 (Hamgyeong / 함경도)。

韩国战争中1·4后撤 (1·4 Hutoe / 1·4후퇴)(1951年1月)前后,有一批咸镜道人跟随国军南下。战争结束后回乡的路也被堵住了,他们就在离停战线不远的海边盖起了房子。这就是束草市青湖洞 (Cheongho-dong / 청호동),如今的阿爸村 (Abai Village / 아바이마을)。村名来自咸镜道方言——"阿爸 (Abai / 아바이)"指上了年纪的男人,逃难者中老人很多,据说这个词就成了村名。

所以束草的美食是失乡民 (Silhyangmin / 실향민)的美食。阿爸血肠是他们带来的血肠,咸兴冷面是咸镜南道咸兴 (Hamhung / 함흥) 的冷面,明太鱼生冷面则是把东海捕到的明太鱼放到那种做法上。它不是爬雪岳山之前随便吃的一餐,而是本身就能成为一篇文章的食物。

此外还加上了束草的地形造就的食物。港口的烤鱼和凉拌生鱼片汤 (Mulhoe / 물회)、雪岳山入口鹤沙坪的嫩豆腐 (Sundubu / 순두부),以及拿在手里吃的甜辣炸鸡。

🛶 阿爸村——乘摆渡船渡过的50米

阿爸村在青草湖 (Cheongchoho / 청초호) 出海水道的对岸。水道宽度只有50米左右,但开车绕过去要很久。于是村里人做出了摆渡船 (Gaetbae / 갯배)。

摆渡船没有发动机。水道上拉着铁索,船上的人用钩子把那根索拉过来,船就动了。游客上船时也会让你亲手拉一拉。失乡民为自己往来而造的装置,就这样原样成了束草的名物。

过去之后,阿爸村路 (Abaimaeul-gil / 아바이마을길)一条路上聚集着饭店。

  • 端川食堂 (Dancheon Sikdang / 단천식당)(阿爸村路17号 / 아바이마을길 17)——是以阿爸血肠闻名的店。战后在阿爸村定居的一家人,从母亲传到儿子再到孙子,共3代,经营了40多年。店名端川 (Dancheon / 단천)与咸镜南道的地名相同。菜单涵盖了这一篇的核心——阿爸血肠、鱿鱼血肠、阿爸血肠汤饭 (Abai Sundae Gukbap / 아바이순대국밥)、明太鱼生冷面。 08:30~19:00(最后点单 18:30),全年无休,是时间限制最少的一家。
  • 新多新 (Sindasin / 신다신)(阿爸村路22号 / 아바이마을길 22)——离端川食堂步行1分钟,同一条路。
  • 阿爸生鱼片面 (Abai Hoe-guksu / 아바이회국수)(青湖路115-12号 / 청호로 115-12)——生鱼片面 (Hoe-guksu / 회국수) 是把酸辣拌好的生鱼片盖在面上的食物。

鱿鱼血肠需要解释一下。它不是猪肠,而是把馅塞进鱿鱼身体蒸熟后切片端上来。在东海鱿鱼常见的地方,血肠的外皮就这样换了。

🍜 失乡民带来的面

咸兴冷面屋 (Hamheung Naengmyeonok / 함흥냉면옥)(青草湖畔路299号 / 청초호반로 299)1951年开门。在战争正酣的那一年开业,已有70多年,凭这段经历2018年入选中小风险企业部的"百年老店 (Baengnyeon Gage / 백년가게)"。10:30~20:30,周三休息。

咸兴冷面与平壤冷面不同。平壤冷面是荞麦面配清汤,咸兴冷面则是细而韧的面条拌上调料来吃,汤另外喝。再放上明太鱼生 (Myeongtae-hoe / 명태회),就成了束草式的明太鱼生冷面 (Myeongtae-hoe Naengmyeon / 명태회냉면)——咸镜道的做法上放了东海的鱼。

荞麦凉面 (Makguksu / 막국수) 属于另一个系列。是江原道的荞麦面,这一篇放进了两家荞麦凉面店,以及同在高城的一家冷面店。

  • 白村荞麦凉面 (Baekchon Makguksu / 백촌막국수)(高城郡土城面白村1街10号 / 고성군 토성면 백촌1길 10)——以荞麦面这一样闻名的店。10:00~17:00(休息时间 13:55~14:10),周三休息(部分来源写周二也休息)——出发前先确认星期几。
  • 南庆荞麦凉面总店 (Namgyeong Makguksu / 남경막국수)(束草市大浦港希望路47号 / 속초시 대포항희망길 47)——在大浦港 (Daepo Port / 대포항) 一侧,所以会和港口行程串在一起。
  • 三代同堂传统五味冷面 (Samdaega Hamkkehaneun Jeontong Omi Naengmyeon / 3대가 함께하는 전통 오미냉면)(高城郡土城面阿也津海边路73号 / 고성군 토성면 아야진해변길 73)——在高城阿也津 (Ayajin / 아야진) 海边一带。

🐟 港口的一餐

束草有好几个港口。东溟港 (Dongmyeong Port / 동명항)·大浦港·凤浦 (Bongpo / 봉포)·长沙港 (Jangsa Port / 장사항) 各在不同的方向,所以选离住处近的港口是窍门。

  • 东溟港鱿鱼露天摊 (Dongmyeonghang Ojingeo Najeon / 동명항 오징어난전)(雪岳金刚大桥路228号 / 설악금강대교로 228)——露天摊 (Najeon / 난전) 指摆在地上的摊位。是在港口直接购买的方式。
  • 88烤鱼 (88 Saengseon-gui / 88생선구이)(中央码头路71号 / 중앙부두길 71)——烤鱼是把多种鱼放在一桌上端来。
  • 青草水凉拌生鱼片汤束草本店 (Cheongchosu Mulhoe / 청초수물회)(世博路12-36号 / 엑스포로 12-36)——凉拌生鱼片汤 (Mulhoe / 물회)是在生鱼片上浇冰凉的调味汤汁来吃的食物。虽被认为是夏季食物,但在束草一年四季都卖。
  • 凤浦潜水员家 (Bongpo Meoguri-jip / 봉포머구리집)(永郎海岸路223号 / 영랑해안길 223)——潜水员 (Meoguri / 머구리)是指潜水员的词。

🥘 鹤沙坪嫩豆腐村——1965年起,海水豆腐

雪岳山入口的鹤沙坪 (Haksapyeong / 학사평)聚集着嫩豆腐店。其中金英爱奶奶嫩豆腐不用卤水,而用海水凝固豆腐。

  • 金英爱奶奶嫩豆腐总店 (Kim Yeongae Halmeoni Sundubu / 김영애할머니순두부)(院岩鹤沙坪路183号 / 원암학사평길 183)——1965年开业。用国产大豆和海水做豆腐。07:00~14:00,周二休息——下午2点关门。是配合爬雪岳山之前的早餐的时间表。
  • 窗岩食堂 (Changbawi Sikdang / 창바위식당)(高城郡土城面院岩鹤沙坪路28号 / 고성군 토성면 원암학사평길 28)——在同一条院岩鹤沙坪路上。属于白斩鸡·参鸡汤一类。
  • 柿子树家土豆面团汤 (Gamnamujip Gamja Ongsimi / 감나무집 감자옹심이)(束草市中央市场路110-8号 / 속초시 중앙시장로 110-8)——不在鹤沙坪而在中央市场一带,但属于同一系列的江原道食物。土豆面团汤 (Gamja Ongsimi / 감자옹심이)是把磨碎的土豆做成的面团揪下来放进汤里的汤。

🍗 拿在手里吃的束草

  • 万石甜辣炸鸡总店 (Manseok Dakgangjeong / 만석닭강정)(青草湖畔路72号 / 청초호반로 72)——在束草30年只做甜辣炸鸡的店。10:00~20:00,全年无休。甜辣炸鸡 (Dakgangjeong / 닭강정) 是在炸鸡上裹上调料,做成凉了味道也不变,很多人打包后在火车上吃。
  • 束草玉米盐面包 (Sokcho Oksusu Sogeumppang / 속초옥수수소금빵)(收复路187街1号 / 수복로187번길 1)——放了玉米的盐面包。
  • 江原道马格利酒蒸糕 (Gangwondo Makgeolli Sulppang / 강원도막걸리술빵)(中央市场路6街14号,54号摊位 / 중앙시장로6길 14, 54번)——在中央市场里的54号位置。酒蒸糕 (Sulppang / 술빵) 是用马格利酒 (Makgeolli / 막걸리) 发酵的蒸包。

☕ 造船厂变成了咖啡厅

七星造船厂 (Chilseong Joseonso / 칠성조선소)(中央路46街45号 / 중앙로46번길 45)是把原本造船的造船厂旧址原样保留下来的咖啡厅。能看到青草湖,作为咖啡厅同时像小型博物馆·历史文化空间一样运营。11:00开门。打烊(19:00·20:00)与休息日(周三休息·全年无休)因来源而异,出发前确认。

束草曾是渔业城市这一事实留存在建筑里,所以和阿爸村放在同一条轴线上读,一天就串起来了。

💰 预算与饮食 — 能避开肉吗

价格分三层。 以下金额不是菜单价，而是레빗가이드 (Revit Guide) 用户的人均消费金额——所以面包店也会超过1万韩元：因为不是买一个，而是买好几个。只用来区分层级。

  • 1万韩元档以下 (5,000~13,600韩元) — 江原道马格利酒蒸包 (Gangwondo Makgeolli Sulppang / 강원도막걸리술빵) 约5,000韩元，七星造船所 (Chilsung Boatyard / 칠성조선소) 约10,700韩元，五味冷面 (Omi Naengmyeon / 오미냉면) 约11,300韩元，咸兴冷面屋 (Hamhung Naengmyeon-ok / 함흥냉면옥) 与阿爸生鱼片面 (Abai Hoe Guksu / 아바이회국수) 约12,000韩元，金英爱奶奶嫩豆腐 (Kim Youngae Halmeoni Sundubu / 김영애할머니순두부) 约13,000韩元，束草玉米盐面包 (Sokcho Oksusu Sogeumppang / 속초옥수수소금빵) 约13,600韩元(按买多个计)。
  • 2万韩元上下 (19,900~22,000韩元) — 端川食堂 (Dancheon Sikdang / 단천식당) 约19,900韩元，88烤鱼 (88 Saengseon Gui / 88생선구이) 与峰浦潜水员之家 (Bongpo Moguri-jip / 봉포머구리집) 约20,000韩元，南庆荞麦凉面 (Namgyeong Makguksu / 남경막국수) 约20,300韩元，万石甜辣炸鸡 (Mansuk Dakgangjeong / 만석닭강정) 约20,000~22,000韩元(打包一桶)，新达新 (Sindasin / 신다신) 约13,000~20,000韩元。
  • 2万5千韩元以上 — 青草水凉拌生鱼片汤 (Cheongchosu Mulhoe / 청초수물회) 约25,500韩元，白村荞麦凉面 (Baekchon Makguksu / 백촌막국수) 约26,100韩元(含片肉等配菜)，东明港鱿鱼摊 (Dongmyeong Port Squid Nanjeon / 동명항 오징어난전) 约29,000韩元(买了带走的价)，昌岩食堂 (Changbawi Sikdang / 창바위식당) 约67,500韩元(整只白熟鸡分食的价)。

能避开肉吗——分成三条线。

  • 猪肉 — 阿爸血肠与阿爸血肠汤饭 (Abai Sundae Gukbap / 아바이순대국밥)，在端川食堂 (Dancheon Sikdang / 단천식당)。本篇的代表菜偏偏是猪肉。
  • 海鲜 — 凉拌生鱼片汤 (Mulhoe / 물회)、烤鱼、鱿鱼血肠、潜水员之家。若要避开猪肉，这条线最宽。
  • 豆·荞麦·土豆 — 嫩豆腐 (Sundubu / 순두부)(金英爱奶奶嫩豆腐用国产黄豆与海水)、荞麦凉面 (Makguksu / 막국수)(白村·南庆)、土豆面团汤 (Gamja Ongsimi / 감자옹심이)(柿子树家 / 감나무집)。这是本篇最接近素食的一条。

不过嫩豆腐与荞麦凉面的高汤或调料里也可能有肉或海鲜。表中没有一家是纯素专门店或清真认证店——若严格遵守，请把点餐前询问高汤当作前提。

🚗 路线——步行区段与开车区段是分开的

束草的阿爸村·中央市场一带步行,鹤沙坪·港口·高城则开车移动。没有车的话可以参考#1212的公交移动方式,但鹤沙坪·高城班次很少。

第一天——步行区段

1. 早上 08:30 — 乘摆渡船渡到阿爸村 → 在端川食堂(阿爸村路17号 / 아바이마을길 17)吃阿爸血肠。新多新步行1分钟。

2. 午餐 — 回市区,在咸兴冷面屋(青草湖畔路299号 / 청초호반로 299)吃咸兴冷面或明太鱼生冷面。周三休息。

3. 下午 — 步行逛中央市场(土豆面团汤·马格利酒蒸糕·玉米盐面包)一圈。万石甜辣炸鸡总店(青草湖畔路72号 / 청초호반로 72)在市场以南约1.7公里处,步行路线上需要另外绕过去。

4. 晚饭前 — 在七星造船厂(中央路46街45号 / 중앙로46번길 45)看青草湖。休息日因来源而异,出发前确认。

第二天——顺路雪岳山

1. 早上 07:00~09:00 — 金英爱奶奶嫩豆腐(院岩鹤沙坪路183号 / 원암학사평길 183)。14:00关门,周二休息。是雪岳山入口,配合爬山前的一餐。

2. 雪岳山行程结束后去港口 — 东溟港或大浦港(南庆荞麦凉面)。

加上高城的变化路线: 从束草向北上去,白村荞麦凉面(土城面)→ 阿也津(五味冷面)→ 巨津 (Geojin / 거진) 一带。白村荞麦凉面周二·周三休息、17:00结束,所以日期和时间决定行程。

⚠ 常见错误3条

1. 周三安排市区行程 — 咸兴冷面屋周三休息,高城白村荞麦凉面也是周三休息(七星造船厂也有周三休息的说法,但来源不一)。周三改去阿爸村(端川食堂全年无休)和港口一带比较稳妥。

2. 想中午吃嫩豆腐 — 金英爱奶奶嫩豆腐14:00关门。07:00开门,与雪岳山行程搭在一起就对,悠闲出门中午去的话已经关门了。周二休息也会撞上。

3. 只把阿爸村当作"摆渡船体验" — 摆渡船5分钟就过去了。这个村子的内容在过去之后——阿爸村路上的饭店和那些菜单上的名字。只坐摆渡船就回来,等于没看一半。

⚙ 常见问题解答(FAQ)3个

Q. 阿爸血肠和鱿鱼血肠有什么不同?

阿爸血肠 (Abai Sundae / 아바이순대)是咸镜道式血肠,把馅塞进猪大肠,做得比较粗。鱿鱼血肠 (Ojingeo Sundae / 오징어순대)的外皮不同——不是猪肠,而是把馅塞进鱿鱼身体蒸熟后切片端上来。在东海鱿鱼常见的地方,材料就这样换了。端川食堂两种都有。

Q. 咸兴冷面辣吗?

因为是拌着吃,会放调料——如果期待平壤冷面那样的清汤,就不一样了。不过以韩国食物的标准来看不算极辣,汤是另外给的,可以混合来调节。明太鱼生冷面 (Myeongtae-hoe Naengmyeon / 명태회냉면)在此基础上放了发酵的明太鱼生,增添酸味。

Q. 束草需要几天?

只看美食的话,两天一夜可以吃到这份清单的一半。第一天走步行区段(阿爸村·市区·中央市场),第二天鹤沙坪·港口。若想好好看雪岳山需要再多一天,如果连高城都去,三天两夜比较从容。
