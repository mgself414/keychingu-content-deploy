🎯 왜 편의점 PB 김치 가이드인가

외국인 관광객 한국 편의점 = 24h·전국 5만 점포·여행 식사 인프라 #1. 한국 편의점 PB (Private Brand·자체 브랜드) 김치 = 최근 5년 폭발 성장 (CU 헤이루 김치·GS25 우리동네 김치·세븐일레븐 PB·이마트24 노브랜드 익스프레스). 가격 무료 X (식당 김치) → 1,500~5,000원 (편의점 PB) → 8,000~30,000원 (마트·면세점). 외국인은 (a) 편의점 김치 존재 자체 모르고 (b) PB 브랜드 5종 차이 모르고 (c) 가격·용량·매운맛 매트릭스 모르고 (d) 숙소 보관·진공 포장 노하우 모르고 (e) 라면+김치 콤보 구매 (#833 cross) 모름.

본 가이드는 5채널 비교 매트릭스 + 가격대별 추천 + 외국인 시나리오 (호텔·게스트하우스·에어비앤비)별 매니아 동선 + 구매 시 영어 발화 + 귀국 선물 진공 포장.

⚠ 외국인 자주 실수 5가지

1. "편의점 김치 = 식당 김치보다 별로": PB 김치 ↑ 발효·국산 배추·전통 방식. 가성비 매우 ↑.

2. "PB 5채널 다 같음": 가격 (1,500 vs 2,500)·용량 (200g vs 500g)·매운맛 단계·매장 접근성 차이.

3. "편의점 PB 진공 포장 = 위탁 수하물 OK": 편의점 PB = 일반 포장 (1~2일 보관). 귀국 선물 = 마트·면세점 진공 포장 별도.

4. "백김치 (안 매움) 모든 편의점 OK": 백김치 = CU·노브랜드 = 안정 비축. GS25·이마트24·세븐일레븐 = 일부 매장만 (큰 매장 OK·작은 매장 X).

5. "호텔 미니바 김치 보관 = 1주 OK": 호텔 미니바 4°C 일반 냉장고 X (드링크 cooler). 1~2일 보관·진공 포장 시 3~5일.

⚙ FAQ 6개

1. 첫 구매 추천: GS25 You Us 배추김치 200g (1,500원) — 가성비 #1·전국 접근성.

2. 매운맛 가감: 백김치 (안 매움) = CU 헤이루·노브랜드 안정 비축. GS25·이마트24 = 큰 매장만.

3. 라면+김치 콤보: 신라면·진라면 + PB 배추김치 = 매니아 #1 콤보 ([#833](#833) 자세히).

4. 위탁 수하물: 편의점 PB = 일반 포장 (위탁 수하물 비추) → 마트·면세점 진공 포장 별도 구매.

5. 알레르기: 새우젓 (갑각류)·멸치액젓·마늘·고춧가루 = PB 김치 표준 함유. 포장 영문 라벨 확인 (수입 OK).

6. VAT 환급: 편의점 식음료 = 환급 X (일반 마트·식당·편의점 식음료 환급 X).

⚠ 의료·안전·식이 disclaimer

편의점 PB 김치 = 일반 김치 (염분 ↑·매운맛). 보관 4°C / 개봉 후 1~3일. 알레르기 (새우젓·멸치액젓·마늘·고춧가루) 포장 라벨 확인 필수. 식중독 의심 시 ☎ 1339 (의료, 영문).

식이 제한 fallback:

  • 할랄·코셔: 편의점 PB = 비할랄·비코셔 (새우젓 표준 함유). → 사찰음식 김치 별도
  • 채식·비건: 편의점 PB = 비채식 (액젓 함유). → 비건 김치 (간장 기반·일부 마트 별도)
  • 글루텐 free: PB 김치 = 간장 안 들어가면 OK (라벨 확인)

✈️ 외국인 페인포인트 #1 — 귀국 선물 가이드

  • 편의점 PB ≠ 귀국 선물용: 일반 포장·1~2일 보관 = 귀국 선물 부적합
  • 귀국 선물 = 마트·면세점 진공 포장: 인천공항 면세점·이마트·롯데마트
  • 위탁 수하물 OK: 김치 = 액체 분류 (>100ml 액체) = 위탁만, 기내 휴대 X
  • 국가별 반입 제한: 호주·뉴질랜드·미국 일부 = 김치 (발효·식물) 반입 제한 — 자국 규정 사전 확인 필수
  • 유통기한: 진공 포장 김치 = 30~90일 (밀봉)·개봉 후 1~3일
