⚠ 외국인 자주 실수 5가지

1. "한국 = 비건 못 먹음": 한국 비건 = 비건 인사·소이로움·발우공양 (#357 미쉐린) + 강남·홍대 비건 식당 + 사찰음식 (5 오신채 미사용) + 외국인 매니아 1번지.

2. "할랄 = 이태원만": 할랄 = 이태원 할랄 cluster (#144 한국 #1) + 인천공항·명동·강남 기도실 + 무슬림 거주 #252 + 외국인 매니아·#369 중동.

3. "사찰음식 = 비건 아님": 사찰음식 = 5 오신채 미사용 (마늘·파·부추·달래·흥거) + 실질적 비건 + 발우공양 (#357 미쉐린)·#291·#502 통합.

4. "비건 화장품 = 없음": 비건 K-Beauty = 올리브영 비건 라인 + 이니스프리·비건 브랜드 + #384·#389 통합 + 외국인 매니아.

5. "기도실 = 못 찾음": 무슬림 기도실 = 인천공항 1·2 터미널 + 명동·강남·홍대 기도실 + HalalTrip 어플 + #369·#398 통합 + 외국인 매니아.
