🎯 なぜソウル登山ガイドなのか

ソウルは世界で都心と山の距離が最も近い都市のひとつ — 市庁 (시청) から半径10km圏内に8座以上の山。外国人観光客にとっての韓国定番アクティビティ: 漢陽都城 (한양도성, UNESCO暫定登録) ・北漢山国立公園 (북한산국립공원)・仁王山 (인왕산) 山頂からのビュー。Reddit r/koreatravel で "Bukhansan hike" ・ "Seoul hiking" キーワードが頻出し、YouTube外国人vlogger動画も多数 (再生数5M+)。Activityシリーズ #3 — #146 ランニング / #147 夜間ランニング / #148 登山の3部作。

⚠ 外国人がよくやる3つのミス

1. スニーカーで本格山登り (北漢山・道峰山)

南山・駱山はスニーカーOK。北漢山・道峰山はトレッキングシューズ必須 — 岩稜・渓谷・落ち葉で滑落の危険あり。レンタルはないため、ミョンドン (명동)・イテウォン (이태원) のデカトロン・ノースフェイス店舗で₩100,000~ (~¥10,000 / ~$75) 購入可。

2. 水・軽食の未準備

南山・駱山は売店が多くOK。北漢山・冠岳山は山頂まで売店ゼロ — 水1L + キンパプ (김밥, 韓国式のり巻き) ・チョコレート持参必須。ソウル登山カルチャー: キンパプ・マッコリ (막걸리, 米の醸造酒, アルコール度数6~8度)・茹で卵が山頂の定番。

3. 北岳山の入山証・漢陽都城を知らない

北岳山の一部区間 (青瓦台裏) は入山証の発行が必要 (現場登録OK、身分証必携)。漢陽都城 (한양도성) はUNESCO暫定登録の18.6km城壁で、6区間の認証スタンプ集めが外国人マニアに大人気。

ソウル登山の魅力

外国人に刺さる理由:

  • 都心から山まで < 10km — 地下鉄から30分以内に登山スタート
  • 漢陽都城 18.6km — UNESCO暫定登録、600年の歴史を持つ城壁
  • 北漢山国立公園 — 韓国初の都市型国立公園、標高837m
  • 安全な登山道 — 一部夜間登山OK (南山・駱山)、本格的な山は06:00~17:00
  • シグネチャー山頂グルメ — キンパプ・マッコリ・茹で卵・ラーメン (韓国登山カルチャーの真髄)
  • 全山無料入場 — 北漢山国立公園を含む全山、入場料0円

外国人の4つの目的別:

1. 都心 + 夜景 (南山・駱山) — 1~2時間、夜景best

2. 歴史・漢陽都城 (仁王山・北岳山) — 2~3時間、韓国の真髄

3. 本格名山 (北漢山・道峰山) — 4~6時間、マニアへのチャレンジ

4. 郊外 + コスパ (冠岳山・清渓山) — 3~4時間、江南近接

4軸マッピング

① 都心入門 (2山)

1. 南山 (Namsan, 262m)

外国人の韓国登山No.1 — ソウルタワー・ケーブルカー・ソウルパノラマ。ミョンドン (명동) から徒歩10分でスタート → 1~2時間で山頂制覇 (階段中心) → ソウルタワー (남산타워) からのビュー。ケーブルカーという選択肢も (₩14,000 往復, ~¥1,400 / ~$10)。夜間もOK (照明・CCTV完備)。

  • スタート地点: 4号線 ミョンドン (명동) 駅・チュンムロ (충무로) 駅 徒歩10分 (北側循環路入口)
  • 距離/時間: 登山道2km / 約1~2時間
  • 難易度: 入門 (階段中心、スニーカーOK)
  • シグネチャー: ソウルタワー + ソウル360°パノラマ + ケーブルカー
  • おすすめ時間: 日の出 05:00~07:00 または日没 18:00~20:00
  • 理由: 外国人の初登山No.1。ケーブルカーで登山ゼロ負担のオプションも。

2. 駱山 (Naksan, 125m)

ソウルで最も低い山 — 1時間の都心散歩 + 漢陽都城東側・夜景。ヘファ (혜화) 駅から徒歩10分でスタート、駱山公園 (낙산공원) 山頂まで漢陽都城に沿って登山。山頂からソウル東側パノラマ。夜景スポットとして定評あり。

  • スタート地点: 4号線 ヘファ (혜화) 駅 1番出口 徒歩10分
  • 距離/時間: 1.5km / 約1時間
  • 難易度: 入門 (最も簡単、スニーカー・ヒールでもOK)
  • シグネチャー: 漢陽都城東側 + 駱山公園夜景
  • おすすめ時間: 日没 + 夜景 18:00~21:00
  • 理由: ソウル最短登山。外国人ファミリー・カップル + 夜景鑑賞に最適。

② 漢陽都城・歴史 (2山)

3. 仁王山 (Inwangsan, 338m)

漢陽都城の真髄 + 岩石絶景 + クァンファムン (광화문)・キョンボックン (경복궁) ビュー。トンニンムン (독립문) 駅またはキョンボックン (경복궁) 駅からスタート → 漢陽都城に沿って登山 → 山頂の岩 (ソンバウィ 선바위・頂上岩) からのビュー。外国人の韓国歴史・自然マニアに人気。

  • スタート地点: 3号線 トンニンムン (독립문) 駅 または キョンボックン (경복궁) 駅
  • 距離/時間: 4km / 約2~3時間
  • 難易度: 中級 (岩場あり、スニーカー・トレッキングシューズ)
  • シグネチャー: 漢陽都城 + 岩石絶景 + 景福宮ビュー
  • おすすめ時間: 午前 09:00~12:00 (日の出 + 空いている)
  • 理由: 韓国らしさ全開の山。UNESCO漢陽都城の核心区間。

4. 北岳山 (Bukaksan, 342m)

青瓦台裏・UNESCO漢陽都城・一部要入山証。チャハムン (자하문) またはマルバウィ (말바위) 入口からスタート。青瓦台裏の区間は身分証登録が必要 (現場で入山証発行、外国人はパスポート)。漢陽都城北側区間の絶景。

  • スタート地点: チャハムン (자하문) 案内所 または マルバウィ (말바위) 案内所 (3号線 アングク (안국) 駅から徒歩30分)
  • 距離/時間: 4.7km / 約2~3時間
  • 難易度: 中級
  • シグネチャー: 青瓦台裏 + UNESCO漢陽都城北側
  • おすすめ時間: 09:00~16:00 (入山可能時間)
  • 理由: 青瓦台裏という韓国ならではの体験 + 漢陽都城核心区間を同時に。

③ 本格名山 (2山)

5. 北漢山 (Bukhansan, ペグンデ 백운대 837m)

韓国初の都市型国立公園 — 標高837m山頂ペグンデ (백운대)。多彩なコース (北漢山城 (북한산성)・ウイ (우이)・チョンルン (정릉)・クパバル (구파발) など10コース以上)。山頂ペグンデの岩稜 + 山城・渓谷・寺院。外国人本格登山No.1。トレッキングシューズ必須。

  • スタート地点: 北漢山城入口 (クパバル (구파발) 駅からバス) または ウイドン (우이동) 入口 (4号線・ウイシンソル線 (우이신설선))
  • 距離/時間: 往復8~10km / 約4~6時間
  • 難易度: 上級 (岩稜、トレッキングシューズ必須)
  • シグネチャー: ペグンデ山頂・山城・渓谷
  • おすすめ時間: 06:00~12:00 出発 (日の出を山頂で迎えるオプションも)
  • 理由: 韓国都市型国立公園の本格登山の真髄。外国人登山マニアNo.1。

6. 道峰山 (Dobongsan, チャウンボン 자운봉 740m)

北漢山の隣の岩稜絶景 — チャウンボン (자운봉)・マンジャンボン (만장봉)。トボンサン (도봉산) 駅から徒歩5分でスタート。北漢山より険しい岩稜・岩石コース。外国人マニア・中上級登山者に最適。

  • スタート地点: 1号線・7号線 トボンサン (도봉산) 駅
  • 距離/時間: 往復6~8km / 約4~5時間
  • 難易度: 上級 (岩稜・岩場、トレッキングシューズ必須)
  • シグネチャー: チャウンボン・マンジャンボン絶景
  • おすすめ時間: 06:00~12:00
  • 理由: 北漢山と異なるテイストの本格山。岩稜マニア向け。

④ 郊外マニア (2山)

7. 冠岳山 (Gwanaksan, ヨンジュデ 연주대 632m)

ソウル大学裏・ヨンジュデ (연주대) 絶景。ソウルデイプグ (서울대입구) 駅からスタート、ヨンジュデ (お堂 + 山頂) を目指す。春のツツジ・秋の紅葉シーズンが絶頂。外国人の江南エリア観光 + 登山の組み合わせに好評。

  • スタート地点: 2号線 ソウルデイプグ (서울대입구) 駅 徒歩 + バス
  • 距離/時間: 7~9km / 約3~4時間
  • 難易度: 中上級 (一部岩稜あり)
  • シグネチャー: ヨンジュデ + ソウル大学 + 春のツツジ
  • おすすめ時間: 春・秋の午前中
  • 理由: 江南近接 + 山頂絶景。江南観光 + 登山の組み合わせに最適。

8. 清渓山 (Cheonggyesan, 618m)

メボン (매봉)・オンニョボン (옥녀봉)・江南近接。ヤンジェシミンのスプ (양재시민의숲) 駅からスタート、メボン (582m)・オンニョボン (376m) など多彩なコース。ファミリー・入門者向け (冠岳山より緩やか)。江南コース + 登山の組み合わせに最適。

  • スタート地点: 新盆唐線 ヤンジェシミンのスプ (양재시민의숲) 駅
  • 距離/時間: 5~7km / 約3~4時間
  • 難易度: 中級 (緩やか、スニーカー・トレッキングシューズ)
  • シグネチャー: メボン・オンニョボン・江南パノラマ
  • おすすめ時間: 午前 09:00~12:00
  • 理由: 江南ファミリー・入門者向け。冠岳山より緩やかな郊外の山。

⚙ FAQ 8問

Q1. 外国人の登山に身分証は必要?

北岳山 (青瓦台裏区間) — パスポート必須。現場登録OK。北漢山国立公園・道峰山 — 無料、身分証不要。その他の山も身分証不要。漢陽都城認証スタンプを集める一部マニアコースでは身分証が役立つ場合あり。

Q2. トレッキングシューズ・登山用品はどこで?

  • デカトロン (Decathlon) (カンナム 강남・チャムシル 잠실) — コスパ登山靴 ₩50,000~₩100,000 (~¥5,000~10,000)
  • ノースフェイス・コルピン (콜핑)・ブラックヤク (블랙야크) (ミョンドン 명동・イテウォン 이태원) — 本格登山靴 ₩150,000~₩300,000
  • ホテル貸し出し — 外国人フレンドリーな一部ホテルのみ
  • ダイソー (다이소) — 登山ソックス・小型リュック コスパ商品あり

Q3. おすすめの時間帯は?

  • 春・秋: 午前 08:00~10:00 (日の出 + 空いている)
  • 夏 (7~8月): 早朝 05:00~07:00 (猛暑回避)
  • 冬 (12~2月): 10:00~14:00 (最も暖かく登山安全)
  • 北岳山 — 09:00~16:00 の入山時間厳守

Q4. 韓国の山頂グルメカルチャーとは?

  • キンパプ (김밥) (₩4,000~₩6,000, ~¥400~600) — 登山No.1フード、山頂到着後に食べるのが定番
  • マッコリ (막걸리) + 茹で卵 — 韓国登山カルチャーの真髄 (山頂でマッコリ一杯)。マッコリは日本の甘酒に近いが米の醸造酒でアルコール6~8度。
  • カップラーメン — 売店で₩3,000~₩4,000 (北漢山一部山頂売店)
  • チョコレート・バナナ — 登山中の行動食

Q5. 雨天・悪天候時は?

南山・駱山 — 傘でもOK。仁王山・北岳山 — 傘は可能だが岩場の滑落に注意。北漢山・道峰山・冠岳山 — 絶対NG (落雷・滑落・落ち葉による危険)。雨予報時は博物館・DDP (동대문디자인플라자) に切り替えを。

Q6. 外国人向け登山クルーは?

Seoul Hash House Harriers (毎週土曜日) + Korea Hiking Club (Facebookグループ)。英語対応可。北漢山・道峰山の本格コースをガイドと一緒に楽しめる。

Q7. 漢陽都城18.6kmを一気に歩ける?

漢陽都城18.6kmは4~6区間に分割がおすすめ (北岳山・仁王山・駱山・南山など)。一気に歩くと12~14時間 — マニア専用。プクチョンマウル (북정마을) 認証センターでスタンプ取得 (外国人マニアに人気)。

Q8. 登山後の締めくくり (グルメ・温泉・チムジルバン)?

  • 北漢山城・ウイドン (우이동) — マッコリ・パジョン (파전, ネギチヂミ) の老舗 (老舗 = 30年以上の伝統店) 多数
  • 南山 — ミョンドン (명동) カルグクス (칼국수, 手打ちうどん)・王マンドゥ (#134 餃子ガイド)
  • 仁王山 — クァンファムン (광화문) クッパプ (국밥, 一杯飯) (#133 ガイド)
  • チムジルバン (찜질방) — 韓国式サウナ施設。日本のスーパー銭湯に近いが、汗蒸幕や仮眠室が充実。ヤンジェ (양재)・チャムシル (잠실)・ホンデ (홍대) で登山後の締めくくりとして定番 (#7 チムジルバンガイド)

08:00 → 仁王山 (인왕산) 2.5時間 (トンニンムン (독립문) 出発 → 山頂 → 漢陽都城沿いにチャハムン (자하문) 案内所へ) → 北岳山 (북악산) へ接続 2時間 (青瓦台裏区間) → チャハムン (자하문) → クァンファムン (광화문) でランチ → 漢陽都城スタンプ認証

Cコース — 「北漢山本格」(登山マニア、フルデイ 8時間)

06:00 → 北漢山城 (북한산성) 入口 → 北漢山ペグンデ (북한산 백운대) 往復5時間 (山頂で日の出オプションも) → 山城 + 渓谷 → ウイドン (우이동) でマッコリ締め → ホテルへ

🌸 シーズン・時間帯別フック 5選

1. 春 (4~5月) ツツジ・桜: 仁王山・冠岳山のツツジが絶頂。4月末~5月初旬。

2. 夏 (7~8月) 早朝日の出: 猛暑回避 + 日の出ビュー。南山・仁王山・北漢山の早朝 05:00~07:00。

3. 秋 (10~11月) 紅葉: 北漢山・道峰山・清渓山の紅葉が絶頂。10月末~11月中旬。フォトシーズンbest。

4. 冬 (12~2月) 雪山登山: 北漢山・道峰山の雪景色が絶景。トレッキングシューズ・アイゼン必須。

5. 四季の夜景: 南山・駱山の夜景は24時間OK (照明・CCTV完備)。外国人夜間登山も安全。
