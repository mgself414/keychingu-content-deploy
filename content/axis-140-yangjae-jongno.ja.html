ソウル南北軸① バス140番、良才 (Yangjae / 양재) から鍾路 (Jongno / 종로) まで — 車窓を流れるソウルの50年

副題: 地下鉄は街を島に見せる。この回は地上を行く。良才からバス140番で江南大路・漢南大橋・南山1号トンネルを抜け鍾路へ。橋とトンネルが結んだ直線を約2時間半で貫く。江南・新沙は車窓のみ。Seoul N-S Axis 1回目。

ISSUE · #1353 · 2026-09-07

🎯 フレーム — ソウルを縦に一度に読む方法

ソウル観光はたいてい点(點)でできている。明洞、江南、景福宮、弘大 — 地下鉄で瞬間移動するように移り歩けば、街ごとに切り離された島のように感じられる。その間に何があるのか、なぜ江南が江南になったのかは、地下からは見えない。

このコースはその間を見る。ソウル南端の良才を出発し、江南大路 (Gangnam-daero / 강남대로) を北へ走り、漢江を渡り、南山を貫き、旧市街・鍾路に着く市内バス一台 — 140番だ。車窓には江南のガラスビル、漢江の川幅、南山の暗闇、鍾路の低い屋根が順に流れていく。降車は漢南大橋北端でただ一度。あとは座ったまま見る。

  • 総所要時間: 約2時間~2時間30分(バス乗車約1時間+漢南下車15分+余裕)
  • おすすめ時間帯: 平日午前10~11時出発 — 通勤ラッシュが終わった後で席が空き、昼頃に鍾路に着く。夕方ラッシュ(17~19時)の江南大路は「バスも渋滞する」
  • 傾斜: なし — 歩く区間は平地15分のみ。荷物があっても大丈夫

なぜ140番なのか — 橋・トンネル・道路をひとつの路線が全て通る

ソウル市内バスのうち、江南大路を南端から北端まで走り、漢南大橋と南山1号トンネルを通過して鍾路・大学路までつながる路線は140番だけだ。道峰山から良才花市場まで往復58kmを行き来する幹線バスで、南山1号トンネルから良才の区間は470番・741番と重なるが、鍾路・大学路まで一本でつなぐのは140番のみ。

📖 物語1 — 一本の橋が江南を作った: 1969年12月25日、漢南洞と新沙洞の間に漢南大橋 (Hannam Bridge / 한남대교)(当時の名称は第3漢江橋、約919m)が架けられた。それ以前、漢江南側のこの一帯は田畑だった。橋が架かって8ヶ月後の1970年8月15日、南山1号トンネル (Namsan 1st Tunnel / 남산1호터널)が開通し、旧市街(鍾路・乙支路)から南山を貫いて漢江を渡り、南へまっすぐ下る直線が完成した。橋の南に伸びる道は1972年に「永東1路」に指定され、1976年6月に「江南大路」という名前を得る。今このバスが走る道こそが、江南が生まれた順序そのものだ。

🚶 コース — 車窓の順番そのままに

起点は新盆唐線・良才市民の森駅。140番はここから一停留所の距離にある「AT-センター・良才花市場停留所」が終点なので、空車に座って出発できる。

① 良才市民の森駅 (Yangjae Citizens' Forest Station / 양재시민의숲역) 4番出口 → AT-センター・良才花市場停留所 (AT Center·Yangjae Flower Market / AT센터.양재꽃시장) (🚶 約7分)

  • 4番出口を出ると江南大路沿いだ。aTセンター建物を過ぎ、停留所まで大通りに沿って直進。時間があれば、この一帯(花市場・梅軒市民の森)を先に歩く朝のコースが#1355にある。
  • 停留所名「AT-センター・良才花市場停留所」 — 140番の終点であり起点。道峰山方面行きの車両に乗る。

② 塩谷交差点 (Yeomgok-sageori / 염곡사거리)・良才駅 → 江南駅 (Gangnam Station / 강남역) 停留所 (🚌 約15分・降車なし)

  • バスは出発直後、塩谷交差点を通過する。ここが江南大路6.9kmの0km地点だ。良才駅を過ぎると、道の両側に自社ビルとオフィスビルが密集してくる — 江南大路南側区間の顔。
  • 江南駅停留所は中央バス専用車線の真ん中に島のように浮いている。ソウルで最も混雑する停留所のひとつ。車窓には地下商店街の入口と大型電光掲示板が流れる。この回では降りない — 江南駅そのものは#301・#1220などがすでに十分に扱っている。

③ 新論峴・論峴 → 新沙駅 (Sinsa Station / 신사역) 停留所 (🚌 約8分・降車なし)

  • 江南駅を過ぎると街路樹が太くなり、建物の高さが少し低くなる。新沙駅停留所の西側一ブロックがカロスキル (Garosu-gil / 가로수길) — 車窓から路地の入口だけを確認する(カロスキルは#295・#30)。
  • この区間で右側(東側)の窓側席なら、間もなく現れる漢江が先に見える。

④ 漢南大橋 (Hannam Bridge / 한남대교) (🚌 約5分・車窓のクライマックス)

  • 新沙駅を過ぎるとすぐ道路がわずかに持ち上がり、建物が消えて漢江が開ける。約919mの橋の上から、西に銅雀大橋・汝矣島方面、東に聖水・蚕室方面のスカイラインが同時に見える。
  • ここで江南大路は終わる(漢南大橋南端が江南大路の終点)。橋を渡ると漢南大路 (Hannam-daero / 한남대로) — 名前が変わる。

⑤ 順天郷大学病院停留所 (Soonchunhyang University Hospital / 순천향대학병원) 下車 → 漢南大橋北端ミニウォーク (🚶 約15分)

  • 橋を渡って最初の停留所「順天郷大学病院」で降りる(道峰山方面基準。反対方向は「漢南五叉路 (Hannam-ogeori / 한남오거리)」)。漢南大路が南山側へ上り坂を始める地点だ。
  • 15分だけ歩く: 停留所裏手の路地に入ると、漢南大路の大きな騒音が突然消え、低い住宅街とカフェの路地が現れる。橋の南側のガラスビルと対比されるスケールが、この軸の要点だ。漢南洞をきちんと歩く夕暮れコースは#1354に別にある — ここでは味見だけする。
  • 同じ停留所から再び道峰山方面の140番に乗る(5~8分間隔、平日基準)。

⑥ 南山1号トンネル (Namsan 1st Tunnel / 남산1호터널) → 都心 (🚌 約8分・降車なし)

  • 📖 物語2 — バスはトンネル料金を知らない: 漢南大路の上り坂の終わりで、バスは南山1号トンネルに入る。1970年8月の開通当時は有料トンネルで、1996年からは都心の混雑を減らすための「混雑通行料」区間になった — 2024年1月15日からは都心方向に入る乗用車のみ2,000ウォンを払う。バス乗客は払う必要がない。約1.5kmの暗闇の後に都心の光が現れれば、そこが旧ソウルだ。
  • トンネルを出ると明洞・乙支路 (Euljiro / 을지로) 方面 — 乙支路の昼と夜は#1346・#1309が扱う。

⑦ 鍾路3街・タプコル公園停留所 (Jongno 3-ga·Tapgol Park / 종로3가.탑골공원) 下車 (🚌 約10分)

  • 都心区間を過ぎ、「鍾路3街・タプコル公園」で降りる。鍾路はこの軸の北の終着だ。南端の花市場からここまでバス一台。
  • さらに行けば鍾路4街(宗廟)・鍾路5街(広蔵市場)・大学路まで続くが、この回のソウル縦断はここで終わる。

⑧ 締めくくり — 鍾路3街ハブへの接続 (🚶 約5分)

  • 停留所から5分以内に地下鉄1・3・5号線鍾路3街駅 (Jongno 3-ga Station / 종로3가역)、益善洞 (Ikseon-dong / 익선동)の路地、タプコル公園が全てある。昼食とその後の動線は#1254 鍾路3街乗り換えハブ完全攻略にバトンを渡す。

🚌 乗り方・座席のコツ5

1. カード一枚: T-moneyまたは海外コンタクトレスカード(市内バス対応可否は#1298)。乗るときタッチ、降りるときもタッチ — 乗り換え割引のため、降車タッチを忘れない。

2. 座席は前方右側: 道峰山方面基準で右側(東側)の窓側に座ると、漢江と南山の上り坂が正面に入ってくる。

3. 降車ベルは停留所ひとつ前: 案内放送は韓国語・英語で流れる。「順天郷大学病院」の放送が出たらベルを押す。

4. 速い代案: 時間がなければ良才→江南→新沙は新盆唐線(2022年5月新沙延伸)で12分以内に抜け、新沙駅停留所で140番に乗ってもいい。ただし江南大路区間の車窓は逃す。

5. 逆方向もできる: 鍾路から乗れば、夕方の漢南大橋の夜景を渡って良才へ下る — シリーズ拡張候補。

🙏 バスマナー — このコースの核心

  • 中央バス専用車線の停留所は道路の真ん中にある。横断歩道の信号でのみ渡る — 無断横断は危険で罰金の対象。
  • 車窓の写真はいいが、隣の乗客がフレームに入らないように。通話は小声で。
  • 前方の座席の一部は交通弱者席 — 混雑時は空けておく。大きなキャリーバッグは後ろ扉付近のスペースに。

💡 戸惑いポイント

  • 停留所名が方向ごとに違う: 漢南大橋北端は道峰山方面「順天郷大学病院」、良才方面「漢南五叉路」。アプリで方向を確認してからベルを押す。
  • 夕方ラッシュは避ける: 江南大路は17~19時にバス専用車線さえ渋滞する。コースが3時間を超えて延びる。
  • トンネル内では電波が弱くなる: 地図アプリはトンネル進入前に次の停留所を確認しておく。
  • 終点で乗ると待つことがある: 起点停留所では出発待機中の車両がドアを閉めていることがある — ドアが開いている車両に乗る。

FAQ 6

Q1. 観光バスではなく一般の市内バスだが大丈夫か?

  • それがこのコースの要点だ。料金は一般市内バスの料金で、ソウルの人々と同じ車両に乗る。シティツアーバスと違って決まった解説はないが、車窓が解説だ。

Q2. なぜ地下鉄で行かないのか?

  • 地下鉄は良才→新沙までしか一本でつながっておらず、漢江以北は路線を乗り換える必要がある。何より地下では漢江も南山も見えない。この回は「見える移動」が目的だ。

Q3. 全部で何停留所、何分か?

  • 良才花市場から鍾路3街までバス乗車約50~60分(平日昼基準・推定)。停留所は20カ所前後。時間帯によって大きく変わる。

Q4. 江南駅・カロスキルで降りたいなら?

  • 降りてもいい — ただしこの回は通過が原則なので、その街の案内は各回(#301・#295)を見る。降りてから同方向の140番に再び乗れば、乗り換え割引が適用される(30分以内)。

Q5. 荷物が多くても大丈夫か?

  • 大丈夫だ。歩く区間は平地15分だけで、バス後方扉横のスペースにキャリーバッグを置ける。ただしラッシュアワーは避ける。

Q6. 夜に乗ってもいいか?

  • 大丈夫だ。漢南大橋の夜景は夜のほうがいい。ただしこの回の設計は、昼の江南大路と南山の上り坂が見える時間帯が基準だ。夜間の逆方向は拡張回で扱う。
