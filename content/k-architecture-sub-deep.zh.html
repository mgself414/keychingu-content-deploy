📍 现代建筑 — DDP·本态博物馆

东大门设计广场，中区 (Eulji-ro 281, Euljiro 7-ga / 을지로 281, 을지로7가)，☎ 02-2153-0000，是2014年3月21日开业的复合文化空间，由建筑师扎哈·哈迪德设计。分为Alimteo展馆 (Alimteo / 알림터)、Baeumteo展馆 (Baeumteo / 배움터)、Sallimteo展馆 (Sallimteo / 살림터)、DDP设计博物馆 (DDP Design Museum / DDP 디자인 뮤지엄)、设计市场 (Design Market / 디자인 장터)，以及汇聚广场 (Eoullim Plaza / 어울림 광장)、东大门历史文化公园 (Dongdaemun History and Culture Park / 동대문 역사 문화공원)。据韩国观光公社介绍，扎哈·哈迪德关注东大门的活力，用由曲线与曲面、斜线与斜面构成的建筑语言营造空间，黄昏灯光亮起后，曲线的动感便显现出来。拍摄夜景照片的好位置，推荐的是汇聚广场入口通道。

  • 开放时间:10:00~20:00。根据活动安排，部分空间弹性运营。
  • 休息日:1月1日，春节·中秋节当天。登记为各设施不同。
  • 停车:可以。

DDP建筑导览，☎ 02-2153-0310, 0311，12:00~13:00午休，是首尔特别市·首尔设计财团主办的讲解导览，与讲解员一起参观扎哈·哈迪德设计的建筑和东大门一带的历史。在60分钟的正规路线中，会经过汇聚广场的空间框架结构、二间水门 (Igansumun / 이간수문)、汉阳都城 (Hanyangdoseong / 한양도성)·照明塔、外墙铝板、螺旋形造型楼梯等。

  • 运营:2026年1月1日~12月31日，周二至周日。每天3场(韩语2场，英语1场)，屋顶导览运营期间每天2场。休息日:每周一，1月1日，春节·中秋节当天。
  • 集合地点:DDP博物馆1层导览服务台。所需时间:约60分钟。
  • 费用:成人10,000韩元，国家有功者·军人·残疾人·青少年团体8,000韩元，儿童5,000韩元。
  • 参加:满13岁(初中生)以上，未满13岁须有监护人陪同。在线预约，或在导览开始前10分钟起现场受理剩余名额。英语导览只有外国人或与外国人同行的韩国人可以报名。中途不能加入，未提前取消而缺席的，之后的预约会受到限制。提供接收器和耳机。

本态博物馆，西归浦市安德面 (Sanrok-nam-ro 762beon-gil 69 / 산록남로762번길 69)，☎ 064-792-8108，名字意为“本来的样子”，由建筑师安藤忠雄设计。据韩国观光公社介绍，在安藤忠雄标志性的清水混凝土中，将光与水引入作为建筑元素，以“顺应济州岛大地的传统与现代”为概念设计。空间分为两处，展出传统工艺品和现代艺术品(毕加索、草间弥生、白南准、达利等)。

  • 开放时间:10:00~18:00 (停止入场 17:00)。休息日:全年无休。
  • 费用(常设展):成人30,000韩元，青少年20,000韩元，儿童10,000韩元。
  • 停车:免费。信用卡:可以。

📍 韩屋村 — 北村·恩平

北村韩屋村，钟路区 (Gyedong-gil 37, Gye-dong / 계동길 37, 계동)，☎ 北村村庄导览所 (Bukchon Maeul Annaeso / 북촌마을안내소) 02-2148-4161，是景福宫·昌德宫·宗庙之间传统韩屋聚集的居住区，嘉会洞 (Gahoe-dong / 가회동)·松岘洞 (Songhyeon-dong / 송현동)·安国洞 (Anguk-dong / 안국동)·三清洞 (Samcheong-dong / 삼청동) 等都属于这里。据韩国观光公社介绍，这里是首尔具有代表性的传统居住区，史迹和文化遗产众多，被称为“都市中的街道博物馆”。观光公社的介绍提到了相连的屋檐线和胡同。

  • 参观时间:10:00~17:00。17:00~次日10:00为限制参观时间(特别管理区域-红区)。休息日:全年无休。
  • 礼仪:禁止擅自闯入·擅自拍摄·乱扔垃圾·随地小便·喧哗，遵守参观时间。
  • 停车:不可以。

恩平韩屋村，恩平区 (Yeonseo-ro 50-gil 7-10, Jingwan-dong / 연서로50길 7-10, 진관동)，☎ 02-351-6114，是继北村·西村 (Seochon / 서촌) 之后新建的现代式韩屋村，与北汉山 (Bukhansan / 북한산) 和津宽寺 (Jingwansa / 진관사) 相融合。据韩国观光公社介绍，土地被分割出售，只能建造韩屋，所以按照业主的喜好，每栋韩屋的形状和木材颜色各不相同。这里是居民生活的地方，所以看不到韩屋内部，部分房屋经业主允许可以参观内部。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。

📍 联合国教科文组织世界遗产 — 宗庙·昌德宫和后苑·河回村·良洞村

宗庙，钟路区 (Jong-ro 157, Hunjeong-dong / 종로 157, 훈정동)，☎ 02-765-0195，是供奉朝鲜和大韩帝国的国王与王后、皇帝与皇后神主的国家祠堂，1395年(太祖4年)建在现在的位置。起初只有正殿，随着供奉的神主增多，几次扩建，成为现在的正殿19间、永宁殿16间。院内有望庙楼 (Mangmyoru / 망묘루)·香大厅 (Hyangdaecheong / 향대청)·斋宫 (Jaegung / 재궁)·典祀厅 (Jeonsacheong / 전사청) 等附属建筑。

  • 开放时间:2~5月·9~10月 09:00~18:00 (停止入场 17:00)，6~8月 09:00~18:30 (停止入场 17:30)，11~1月 09:00~17:30 (停止入场 16:30)。
  • 休息日:每周二。周二是公休日时开放，在之后第一个工作日休息。
  • 停车:可以。

昌德宫和后苑，钟路区 (Yulgok-ro 99, Waryong-dong / 율곡로 99, 와룡동)，☎ 02-3668-2300，其中的昌德宫于1405年(太宗5年)作为景福宫的离宫建成，在壬辰倭乱中被烧毁后，于1610年(光海君2年)在宫殿中最先得到重建。据韩国观光公社介绍，它不拘泥于人为的结构，与周边地形相协调而建，被评价为最具韩国特色的宫殿，1997年被列入联合国教科文组织世界遗产。后苑利用自然地形，在每个山谷里建造亭子，4个山谷中有芙蓉池 (Buyongji / 부용지)·爱莲池 (Aeryeonji / 애련지)·观览池 (Gwallamji / 관람지)·玉流川 (Ongnyucheon / 옥류천) 区域。

  • 开放时间:2~5月·9~10月 09:00~18:00 (停止入场 17:00)，6~8月 09:00~18:30 (停止入场 17:30)，11~1月 09:00~17:30 (停止入场 16:30)。
  • 休息日:每周一。周一是公休日时开放，在之后第一个工作日休息。
  • 停车:不可以。

安东河回村，安东市丰川面 (Jeonseo-ro 186-8 / 전서로 186-8)，☎ 综合服务中心 (Jonghap Annaeso / 종합안내소) 054-840-3795，是丰山柳氏 (Pungsan Ryu / 풍산 류씨) 世代居住的聚居村。据韩国观光公社介绍，洛东江 (Nakdonggang / 낙동강) 呈S形环绕村庄流过，因此得名“河回”，房屋以低矮的丘陵为中心朝向低处而建，所以房屋的朝向并不一致。村子中心是柳氏家族的大瓦房，周围是很好地保存了原貌的草房。2010年7月31日，与庆州良洞村一起以“韩国的历史村落”列入联合国教科文组织世界遗产，并将河回别神假面舞 (Hahoe Byeolsingut Talnori / 하회별신굿탈놀이) 作为常设演出。

  • 开放时间:4~9月 09:00~18:00 (停止入场 17:30)，10~3月 09:00~17:00 (停止入场 16:30)。休息日:全年无休。
  • 体验:传统婚礼体验、岁时风俗、书院小确幸 (Seowon Sohwakhaeng / 서원소확행)、书写家训体验等。
  • 停车:免费。

庆州良洞村，庆州市江东面 (Yangdongmaeul-gil 93 / 양동마을길 93)，☎ 054-762-2630，是月城孙氏 (Wolseong Son / 월성 손씨) 和骊江李氏 (Yeogang Yi / 여강 이씨) 形成的聚居村，整个村庄被指定为国家民俗文化遗产。据韩国观光公社介绍，这里是韩国规模最大的聚居村，保存了200年以上的古宅54户，可以一眼看到朝鲜中期以后的传统房屋结构。

  • 开放时间:4~9月 09:00~19:00 (停止入场 18:00)，10~3月 09:00~18:00 (停止入场 17:00)。休息日:全年无休。
  • 房屋出入:未经主人允许不得进入房屋。宝物·重要民俗资料等指定房屋只开放除内院之外的外部空间。
  • 体验:打年糕、制作药果、学习传统礼仪、书堂体验等。
  • 停车:可以。

A. 根据观光公社登记信息，DDP建筑导览设有英语场次。只有外国人或与外国人同行的韩国人可以报名。

A. 根据观光公社登记信息，本态博物馆、北村韩屋村、恩平韩屋村、安东河回村、庆州良洞村全年无休。
