为什么选9号线 — 从金浦机场到江南乘急行

9号线(金色)的武器就是"急行"。 从金浦机场 (Gimpo Airport / 김포공항) 到汝矣岛 (Yeouido / 여의도)·高速客运站 (Express Bus Terminal / 고속터미널)·江南 (Gangnam / 강남)·蚕室 (Jamsil / 잠실)，急行列车只快速通过主要车站。在仁川机场 (Incheon Airport / 인천공항) 乘机场铁路 (AREX / 공항철도) 在金浦机场下车、再搭9号线急行，到江南转眼即到。再加上鹭梁津水产市场 (Noryangjin Fish Market / 노량진 수산시장)·奉恩寺 (Bongeunsa / 봉은사)·石村湖 (Seokchon Lake / 석촌호수) 这些9号线独有的名胜。

本指南按车站整理9号线观光核心 8座车站。将汉江 (Hangang / 한강)·水产市场·寺庙·湖泊名胜(衔接既有deep dive) + 从积累数据中按各站最近邻映射选出的美食搭配在一起。这是地铁分线系列第七篇，也是新获取坐标后新增的线路。

线路贴士 5 — 9号线200%活用

Tip 1. 9号线的核心是"急行"

急行列车只停靠主要车站，速度快(金浦机场·汝矣岛·高速客运站·新论岘·奉恩寺 等)。注意区分与普通列车的站台。用急行节省机场~江南的移动时间。

Tip 2. 入境动线的捷径

仁川机场 → 机场铁路 → 金浦机场 → 9号线急行 → 江南。常常比机场巴士更快。

Tip 3. 鹭梁津水产市场是9号线的美味

挑好海鲜到醋辣酱店做成生鱼片。凌晨拍卖也是看点。杯饭街是便宜的街头小吃。

Tip 4. 奉恩寺=都市中的传统

COEX(#1240)对面的1200年古刹。寺院寄宿体验(#509)·寺院斋饭。现代(COEX)与传统(奉恩寺)相望。

Tip 5. 一张交通卡搞定

一张T-money卡搞定9号线急行·换乘·巴士。通过机场铁路(金浦机场)连接，入境动线也搞定。

FAQ 6 — 外国人常问的9号线问题

Q1. 9号线的强项是?

  • 急行。快速串联金浦机场~汝矣岛~高速客运站~江南~蚕室。对入境(连接机场铁路)·江南移动有利。

Q2. 急行怎么乘?

  • 站台有急行/普通区分标示。急行只停主要车站(有不停靠的车站)。在地图app确认是否急行。

Q3. 鹭梁津水产市场?

  • 鹭梁津站。挑好海鲜到醋辣酱店吃生鱼片。凌晨拍卖·杯饭街也值得。9号线的代表美食。

Q4. 奉恩寺·COEX?

  • 奉恩寺站。1200年古刹(#509)与COEX(水族馆·星空图书馆·#1240)相望。传统+现代。

Q5. 美食信息准确吗?

  • 基于naver地图爬取，仅供参考。到访前务必用地图app再确认。

Q6. 入境后怎么去江南?

  • 仁川机场 → 机场铁路 → 金浦机场 → 9号线急行。行李寄送(#1232)·手机SIM卡(#414)在金浦机场·首尔站 (Seoul Station / 서울역) 办理。
