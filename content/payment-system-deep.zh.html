在韩国怎么付钱 — 外国信用卡·ATM·换钱·预付交通卡·移动支付·退税，按情况来选

副标题: 整理了短期游客在韩国结账时选择的顺序。外国信用卡能用的范围和用不了的地方，找得到接受外国信用卡的ATM以及手续费怎么叠加，机场·银行·换钱所，T-money·WOWPASS·NAMANE·CHECK iN SEOUL这类预付卡，Alipay+·微信支付·KakaoPay·Naver Pay，不收现金的公交车和无人收银台，直到门店即时退税的额度。每一项都以“这种时候用这个”结尾。

ISSUE 03 · #527 · 2026-11-25

🎯 适合哪些人

这一篇写给在韩国停留几天到几周的游客。我们假设你没有韩国银行账户，也没有韩国手机号。这一篇不会把每种支付方式逐个深挖，它是一张决定在什么情况下掏出什么的地图。单张卡的详细步骤另有专文，所以在每一节末尾用链接指过去。

⚠ 标注原则: 手续费·额度·价格旁边都附上了出处和确认日期。“官方”只用于直接打开运营机构或公司网站原文得到的数值。只在一篇报道里出现的内容标为“需确认”。支付条件经常变动，涉及大额时，请当天再到App和网站上确认一次。哪家店收什么因店而异，结账前先问一句更快。

① 外国信用卡 — 大部分能用，但有的店不收

韩国观光公社 (Korea Tourism Organization / 한국관광공사) 英文网站写道，韩国大部分商户接受信用卡，在大型酒店·百货商店·一般商店可以使用Visa·MasterCard·American Express。同一篇文章里也有一句：有的店不收卡，购买前要先确认(VisitKorea官方, 页面标注日期2023-03-27, 2026-11-25查阅)。

  • 银联 (UnionPay): 银联国际网站写道，韩国大部分商户接受签名式银联卡，接受PIN式的有超过300万 (300만) 家(银联官方)。这是银联公司自己的发布，没能用其他出处确认。也有不收的店。中国大陆发行的卡如何开通境外使用，写在#1333里。
  • JCB: 没有找到说明JCB在韩国商户范围的官方资料(2026-11-25)。不要只带一张JCB来，再带一张其他品牌的卡。
  • 结算货币选韩元 (KRW): 刷卡终端或收据上如果出现问你是否按本国货币扣款的画面，请选韩元。用当地货币以外的货币结算，会多发生一次换汇，扣款金额就会升高(KB国民卡 (KB Kookmin Card / KB국민카드) 境外使用说明, 官方)。这份说明讲的是在国外使用韩国卡的情形，同样的原理适用于外国卡，是这一篇的推测。

这种时候用这个

  • 卡被拒绝 → 换一张其他品牌的卡。还是不行就用预付卡(④)或现金。
  • 市场·路边摊这类看不到刷卡机的地方 → 先问能不能付现金或二维码。需要现金的地方汇总在#1301里。

② 用外国信用卡在ATM取钱 — 选接受外国信用卡的机器

  • 不是随便哪台机器都行: 据说韩国的ATM里有不接受外国发行卡的机器。同一家银行的几台ATM里可能只有部分能用，也据说有的银行一台接受外国卡的机器都没有。有时会用贴纸或标识告知，没有标识时看菜单是否会问发卡国家。只出现国内卡菜单的话，据说那台机器不能用(基础科学研究院 (Institute for Basic Science / 기초과학연구원) 外国人生活指南, 推测约2019年撰写, 2026-11-25查阅)。
  • 各银行的支持范围: 没有找到银行自己公布的、说明哪家银行的ATM接受外国卡的官方名单(需确认)。银联网站写道，在韩国可以用银联卡取韩元的ATM超过7万 (7만) 台(银联官方, 公司自己的数字)。
  • 手续费可能分两层: 花旗银行 (Citibank Korea / 씨티은행) 和KB国民卡 (KB Kookmin Card / KB국민카드) 的说明讲的是在国外ATM使用韩国卡的情形。那里的当地ATM使用费由ATM运营商决定，每台机器不同(花旗银行境外ATM说明, 官方)，发卡行另外收国际品牌费和每笔手续费。例如KB国民卡 (KB Kookmin Card / KB국민카드) 的借记卡，Visa品牌费1.0~1.1%、Mastercard 1.0%，再加每笔3美元(以韩国KB卡为例, KB国民卡官方)。用外国卡在韩国ATM取钱时，韩国ATM手续费和自己发卡行的手续费也会叠加两层，是这一篇的推测。实际金额请在#1286和自己发卡行的说明中确认。
  • 用信用卡取钱可能变成现金预借: 在境外ATM上，信用卡会同时出现现金取款和现金预借(短期贷款)菜单，所以要准确选择想要的菜单(花旗银行官方)。KB国民卡 (KB Kookmin Card / KB국민카드) 说明其信用卡不能境外取现，只能现金预借(KB国民卡官方)。两者都是在国外使用韩国卡的说明。自己的信用卡如何处理，请向发卡行确认。

这种时候用这个

  • 机器画面只有韩语的国内卡菜单 → 换一台机器。
  • 画面显示手续费并问你是否确认 → 看过金额后继续或取消。如果出现选择货币的画面，按韩元 (KRW)。
  • 一个画面一个画面照着操作的步骤，以及卡吐不出来时怎么办，请看#1286。

③ 换钱 — 机场、银行、正规换钱所

韩国观光公社 (Korea Tourism Organization / 한국관광공사) 建议在银行或正规换钱所换钱，并写道对大多数游客来说机场换钱所最方便(VisitKorea FAQ, 官方, 2026-11-25查阅)。

地点 时间 (出处) 备注
仁川机场 (Incheon Airport / 인천공항) 换钱所 标准06:00~22:00，部分24小时营业 (VisitKorea官方, 2026-09-11更新) 一到就可以换
仁川机场 (Incheon Airport / 인천공항) 银行网点 (KB国民 (KB Kookmin / KB국민)、Hana (하나)、Woori (우리)) 工作日09:00~16:00，周末·公休日休息 (同一页面) 第1·第2航站楼都有

  • 有些地方不兑换旧纸币(VisitKorea官方)。
  • 也有把外币现金直接充进预付卡的办法。WOWPASS写道现金充值接受16种货币(WOWPASS官方)。CHECK iN SEOUL自助终端也接受16种外币，但据说每台终端的币种可能不同(乐天卡 (Lotte Card / 롯데카드) 官方, 2026-11-22查阅)。

这种时候用这个

  • 深夜才到 → 机场换钱所的基本营业时间是06:00~22:00，24小时营业的只有一部分。22点以后，先靠刷卡或接受外国信用卡的ATM撑过去，第二天再换。机场银行网点工作日16:00关门。
  • 带大笔现金入境，或离开时把剩下的韩元换回去 → 申报标准和换回的方法在#435里。

⑤ 移动支付 — 你的App能不能用，由收银台的二维码决定

  • Alipay+合作钱包: 韩国观光公社 (Korea Tourism Organization / 한국관광공사) 推广的Zero Pay标准二维码，与支付宝·微信支付等17个海外移动支付连通，所以不用安装韩国的App，用自己国家的App就能付款(korea.net, 2024-11-29。2024-11的资料，没有商户数)。Korea Times列举了在韩国通过Alipay+付款的钱包：支付宝(中国大陆)、AlipayHK、Touch 'n Go(马来西亚)、PayPay(日本)、MPay(澳门)、GCash(菲律宾)(2025-12-09报道, 需确认)。自己的钱包能不能用，请在钱包App的海外支付说明里看。
  • 微信支付: 它在上面Zero Pay标准二维码连通的名单里(korea.net, 2024-11-29)。没有那个二维码的门店能不能用，因店而异。
  • KakaoPay: KakaoPay表示2025年9月起，在韩国国内的KakaoPay线下商户开始受理日本PayPay付款(Herald Business (헤럴드경제) 2025-09-24报道, 没有给出商户数, 需确认)。外国人直接注册KakaoPay App、用外国信用卡的条件，没有找到官方说明(需确认)。
  • Naver Pay·Naver地图: Naver在2026年6月4日引入了护照认证。持海外护照的外国人，没有韩国手机号也可以使用Naver地图的预约·点单·支付(Naver官方新闻稿, 2026-06-09)。新闻稿里没有写能否用外国信用卡付款。在Naver Pay里登记海外发行信用卡的功能，只在2025年5月报道为“预定推出”，没能用官方原文确认(亚洲经济 (Asia Economy / 아시아경제) 2025-05-16, 需确认)。

这种时候用这个

  • 收银台有二维码标识 → 看有没有自己钱包的图标，并问一句“QR gyeolje dwaeyo? (QR 결제 돼요?)”(能用二维码付款吗？)。
  • 没有标识 → 用信用卡或预付卡付款。
  • 同时使用支付宝·微信支付·银联的华语圈游客的顺序，整理在#1333里。

⑥ 无人自助机，不收现金的地方

  • 无现金公交: 首尔市 (Seoul / 서울시) 在其交通网站上公布了截至2026年1月的“无现金公交”运营线路名单(首尔市官方)。南山循环巴士01A·01B也不收现金(首尔市媒体中心 (Seoul Media Hub / 서울시 미디어허브) 2024-11-28)。首尔市表示，没有交通卡的乘客先让上车，再通过账户转账或手机T-money付车费，并为外国乘客制作了英语·汉语·日语的告示(2024-02-15)。Korea Times报道，截至2026年4月，首尔394条公交线路中有180条不收现金(2026-11-11, 需确认)。
  • 无现金门店: 也有不收现金的门店和银行网点。韩国银行 (Bank of Korea / 한국은행) 在报告中写道，需要出台扩大现金受理的政策(Korea Times 2026-11-11报道)。哪家店不收现金因店而异，所以这一篇不列名单。
  • 自助机: 餐厅·咖啡店的点单自助机和自助收银台是否接受外国信用卡，没有找到概括性的官方资料(需确认)。卡读不出来就去人工收银台。

这种时候用这个

  • 要坐公交 → 上车前先给交通卡充好余额(④)。
  • 自助机画面只有韩语 → 按画面顺序操作的方法见#1270，自助收银台·夜间无人便利店见#1306。

⑦ 退税 — 门店即时退税、市内退税、机场退税

方式 条件 (出处)
共同条件 在韩国停留不满6个月的外国人，购买金额15,000韩元以上，全新商品(未拆封·未使用)，自购买日起3个月内出境 (VisitKorea官方, 2025-10-21更新)
门店即时退税 单次付款15,000韩元以上、不满100万韩元 (100만 원)，整个旅行合计500万韩元 (500만 원) 以下 (VisitKorea官方 · 《关于外国游客等的增值税及个别消费税特例规定》(외국인관광객 등에 대한 부가가치세 및 개별소비세 특례규정) 第6条 ②, 国家法令信息中心 (Korea Law Information Center / 국가법령정보센터))
市内退税窗口 只处理运营该窗口的退税公司的收据。每张收据600万韩元 (600만 원) 以下。用海外信用卡(包括支付宝·微信支付)领取，或当场领现金 (VisitKorea官方)
机场·港口退税 接受所有退税公司的收据。停留期间的购买没有额度限制。现金在安检后的免税区领取。用海外信用卡·支付宝·微信支付领取，需要1~2个月才到账。窗口不存在或已关闭时，在收据上写明领取方式，投入指定的箱子。流程因机场·港口而异，请向现场工作人员确认 (VisitKorea官方)

这种时候用这个

  • 在一家店买不满100万韩元 (100만 원) → 结账时出示护照，办理即时退税。
  • 在市内窗口没能领到 → 机场·港口窗口接受所有公司的收据。要在三种方式中选哪种适合自己的购物，见#1231。机场自助终端的画面顺序见#1304。免税店购物见#775。

⚠ 常见错误3

  1. 在支付画面选自己国家的货币 — 刷卡终端或ATM问货币时，选韩元 (KRW)。选了别的货币，会多换汇一次(KB国民卡 (KB Kookmin Card / KB국민카드) 官方说明的原理，适用于外国卡是这一篇的推测)。
  2. 在不接受外国信用卡的ATM上一直试 — 同一家银行的ATM里，也有专门接受外国卡的机器。只看到国内卡菜单，就换一台机器(基础科学研究院 (Institute for Basic Science / 기초과학연구원) 生活指南, 推测约2019年撰写)。
  3. 不带交通卡就坐公交 — 首尔有不收现金的公交线路(首尔市官方)。出机场前先买好带交通功能的卡并充值。

⚙ FAQ 3

  1. 要带多少现金？ — 看行程。需要现金的地方，以及一天带多少合适，汇总在#1301里。
  2. 要给小费吗？在哪里结账？ — 在柜台结账的方法和小费习惯，请看#1275。
  3. 打车用什么付？ — Kakao T App里无法登记信用卡时，直接付给司机的方法在#1273里。
