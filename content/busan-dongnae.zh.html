⚠ 外国游客常犯的 5 个错误

1. “东莱 (Dongnae / 동래) 温泉 = 哪里都一样”: 东莱 (Dongnae / 동래) = 韩国第一 2000年温泉 (新罗时代有记载) + 外国游客首选地。

2. “温泉 = 只有老年人”: 东莱 (Dongnae / 동래) 温泉 = 外国游客首选地 + 外国游客友好度第一 + 用户评价第一。

3. “东莱 (Dongnae / 동래) = 小城市”: 东莱 (Dongnae / 동래) = 釜山 (Busan / 부산) 市区第一区域 + 毗邻西面 (Seomyeon / 서면)·社稷 (Sajik / 사직)·海云台 (Haeundae / 해운대) + 外国游客首选地。

4. “东莱 (Dongnae / 동래) = 只有韩食”: 东莱 (Dongnae / 동래) = 温泉 + 韩定食 (Han-jeongsik / 한정식) (套餐) + 历史·文化遗产 + 外国游客首选地 全套。

Explanation for 韩定食 (Han-jeongsik / 한정식): 韩定食 (Han-jeongsik / 한定食) 是一种套餐形式，通常包含多道小菜和主食，丰盛而精致。

5. “东莱邑城 (Dongnaeeupseong / 동래읍성) = 无法前往”: 东莱邑城 (Dongnaeeupseong / 동래읍성) = 壬辰倭乱 1592 历史 + 外国游客首选地 + 英文导览无障碍。

⚙ 6 个常见问题

1. 外国游客东莱 (Dongnae / 동래) 路线: KTX 釜山站 (Busan Station / 부산역) → 东莱站 (Dongnae Station / 동래역) (地铁 1·4号线) → 温泉场 (Oncheonjang / 온천장)。

2. 外国游客东莱 (Dongnae / 동래) 温泉首选: 虚心厅 (Heosimcheong / 허심청) (韩国第一) + 农心酒店 (Nongshim Hotel / 농심 호텔) + 外国游客友好。

3. 外国游客东莱 (Dongnae / 동래) 韩定食 (Han-jeongsik / 한정식): 釜山 (Busan / 부산) 传统韩食 + 外国游客首选地。

4. 外国游客东莱 (Dongnae / 동래) 历史: 东莱邑城 (Dongnaeeupseong / 동래읍성)·忠烈祠 (Chungnyeolsa / 충렬사)·东莱鹤舞 (Dongnae Hakchum / 동래학춤) + 外国游客文化首选地。

5. 外国游客东莱 (Dongnae / 동래) 1晚2天: Day 1 社稷 (Sajik / 사직) (参考 [#268 釜山 (Busan / 부산) 社稷 (Sajik / 사직)](268_busan_sajik_guide.md)) 棒球 + 东莱 (Dongnae / 동래) 温泉 1晚 / Day 2 海云台 (Haeundae / 해운대) (参考 [#243 釜山 (Busan / 부산) 海云台 (Haeundae / 해운대)](243_busan_haeundae_guide.md)) + KTX。
