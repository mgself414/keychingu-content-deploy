韩国灯塔旅行指南 — Iho Tewoo马灯塔·梧桐岛·虎尾串·Ulgi灯塔，束草·注文津·墨湖，直到Oido红灯塔，共20座灯塔和国立灯塔博物馆

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“灯塔看守人的秘密地图”(灯塔)主题入选的地方中的21处 · 登记了门票的地方全部免费 · 周一休息的有梧桐岛灯塔·Ulgi灯塔·影岛灯塔·Hwaamchu灯塔·Nueseom灯塔观景台·国立灯塔博物馆 · 五六岛灯塔自2018年起不对一般游客开放，加德岛灯塔登记为不接受参观申请 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“灯塔看守人的秘密地图”(灯塔)主题入选的76处中，在韩国观光公社旅游信息里确认了运营信息的20座灯塔和国立灯塔博物馆。表中的排名和得票数就是这次投票的结果。

登记了门票的地方全部免费(梧桐岛灯塔·Oido红灯塔·马罗岛灯塔没有登记门票值)。不过开放时间和休息日每座灯塔各不相同。有六处周一休息。Iho Tewoo马灯塔·虎尾串灯塔·Seuldo灯塔·Jebudo灯塔登记为全天开放，Songdaemal灯塔登记为只有灯塔全天开放(展示馆 09:00~18:00)。

也有登记为一般开放或参观受限的地方。五六岛灯塔自2018年起无人化，不对一般游客开放(开放时间一栏里也写着“全天开放”)，加德岛灯塔出入受限，登记为出于军队保安暂时不接受参观申请。运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。

📍 Gyeonggi — Oido红灯塔·Jebudo灯塔·Nueseom灯塔观景台

Oido红灯塔 (Oido Ppalgang Deungdae / 오이도 빨강등대)(始兴市 (Oido-ro 170 / 오이도로 170)，☎ 031-310-2901~4)是2005年作为渔村体验观光村建设项目建成的设施。在一楼展示馆可以看到始兴的文化·观光·历史信息，从观景台能看到Sihwa工业园区 (Sihwa Gongdan / 시화공단)、Baegot新城 (Baegot Sindosi / 배곧 신도시)和Incheon Songdo新城 (Incheon Songdo Sindosi / 인천 송도 신도시)。与一楼相连的商店 Siheung Kkumsanghoe (Siheung Kkumsanghoe / 시흥꿈상회) 出售纪念品。

  • 开放时间:10:30~17:30。休息日:全年无休。停车:可以。

Jebudo灯塔 (Jebudo Deungdae / 제부도등대)(华城市 (Seosin-myeon Haean-gil 421-17 / 서신면 해안길 421-17)，☎ Jebudo管理事务所 (Jebudo Gwallisamuso / 제부도 관리사무소) 031-355-3924)是Jebudo海岸的红色灯塔。旁边有码头和通向大海的观景栈道，从灯塔出发的步道沿着海岸一直通到Jebudo海水浴场 (Jebudo Haesuyokjang / 제부도 해수욕장)。Jebudo是一天两次海路开通的岛。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Nueseom灯塔观景台 (Nueseom Deungdae Jeonmangdae / 누에섬 등대전망대)(安山市 (Danwon-gu Seon-gam-dong / 단원구 선감동)，☎ 安山渔村民俗博物馆 (Ansan Eochon Minsok Bangmulgwan / 안산어촌민속박물관) 031-440-8310)位于Tando港 (Tando-hang / 탄도항)附近的无人岛Nueseom (Nueseom / 누에섬)上。退潮时每天两次，每次4小时滩涂露出，可以步行进入。一·二层是展示空间，三层有观景台和灯塔。

  • 开放时间:3~10月 10:00~18:00，11~2月 10:00~17:00。登记为运营时间随涨潮·退潮时间变化，出发前请确认参观时间表。
  • 休息日:每周一，1月1日，Seol·Chuseok连休。费用:免费。

📍 Gangwon — 束草灯塔观景台·注文津灯塔·墨湖灯塔·Daejin灯塔

束草灯塔观景台 (Sokcho Deungdae Jeonmangdae / 속초등대전망대)(束草市 (Yeonggeumjeong-ro 5-gil 8-28 / 영금정로5길 8-28)，☎ 束草航路标志管理所 (Sokcho Hangnopyojigwalliso / 속초항로표지관리소) 033-633-3406)是1957年首次亮灯的灯塔，现在也作为观景台开放。沿着竹林间的木栈道步道上去就到观景台。从观景台可以看到东海、Cheongchoho (Cheongchoho / 청초호)和Seoraksan (Seoraksan / 설악산)。紧邻的就是Yeonggeumjeong (Yeonggeumjeong / 영금정)。

  • 开放时间:观景台 09:00~17:00，室外空间 09:00~18:00。休息日:全年无休。费用:免费。

注文津灯塔 (Jumunjin Deungdae / 주문진 등대)(江陵市 (Jumunjin-eup Yetdeungdae-gil 24-7 / 주문진읍 옛등대길 24-7)，☎ 033-662-2131)建于1918年3月20日，据韩国观光公社介绍，是现在Gangwon特别自治道 (Gangwon Teukbyeol Jachido / 강원특별자치도)最古老的灯塔。用砖砌成的高10m的塔身上抹了白色石灰砂浆。朝鲜战争时受损，1951年修复。

  • 开放时间:室外空间 09:00~18:00，室内设施 09:00~17:00。禁止夜间出入。
  • 休息日:全年无休。费用:免费。停车:免费。

墨湖灯塔 (Mukho Deungdae / 묵호등대)(东海市 (Haemaji-gil 289 / 해맞이길 289)，☎ 墨湖航路标志管理所 (Mukho Hangnopyojigwalliso / 묵호항로표지관리소) 033-531-3258)于1963年6月8日建在墨湖港附近，位于海拔67m处。夜间会亮起发出多种颜色的LED灯。还有一座小公园。

  • 开放时间:09:00~17:00。休息日:全年无休。费用:免费。

Daejin灯塔 (Daejin Deungdae / 대진등대)(高城郡 (Hyeonnae-myeon Hannaru-ro 4-gil 16-38 / 현내면 한나루로4길 16-38)，☎ 033-682-0172)是位于Geojin港 (Geojin-hang / 거진항)与Machajin (Machajin / 마차진)之间岬角上的八角形混凝土灯塔。塔顶的观景台可以看到东海，据韩国观光公社介绍，视野好的日子甚至能看到Haegeumgang (Haegeumgang / 해금강)和朝鲜地区。

  • 开放时间·休息日:登记为请电话咨询。费用:免费。

📍 Gyeongbuk — 虎尾串灯塔·国立灯塔博物馆·竹边灯塔·Songdaemal灯塔

虎尾串灯塔 (Homigot Deungdae / 호미곶 등대)(浦项市 (Nam-gu Homigot-myeon Homigot-gil 99 / 남구 호미곶면 호미곶길 99)，☎ 054-284-9814)于1908年12月20日亮灯。韩国观光公社的介绍中写道，它是韩国最高的灯塔。1982年被指定为Gyeongsangbuk-do (Gyeongsangbuk-do / 경상북도)纪念物。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

国立灯塔博物馆 (Gungnip Deungdae Bangmulgwan / 국립등대박물관)(浦项市 (Nam-gu Homigot-myeon Haemaji-ro 150beon-gil 20 / 남구 호미곶면 해맞이로150번길 20)，☎ 054-284-4857)于1985年2月开馆，据韩国观光公社介绍，是国内唯一的灯塔专门博物馆。保存并展示灯塔等航路标志设施和设备。

  • 开放时间:09:00~18:00(入场截止 17:30)。
  • 休息日:每周一(遇公休日则顺延至下一个工作日)，Seol·Chuseok当天。费用:免费。

竹边灯塔 (Jukbyeon Deungdae / 죽변등대)(蔚珍郡 (Jukbyeon-myeon Deungdae-gil 52 / 죽변면 등대길 52)，☎ 054-783-7104)是1910年11月在蔚珍地区首次建起的灯塔。为八角形混凝土四层塔，高15.6m。朝鲜战争期间因轰炸失去功能，1951年10月修复。

  • 开放时间:09:00~18:00。休息日:全年无休。费用:免费。

Songdaemal灯塔 (Songdaemal Deungdae / 송대말 등대)(庆州市 (Gampo-eup Cheoksa-gil 18-94 / 감포읍 척사길 18-94)，☎ 054-744-3233)位于Gampo港 (Gampo-hang / 감포항)北侧。旧灯塔现在不再使用，旁边新建了仿Gameunsaji石塔 (Gameunsaji Seoktap / 감은사지 석탑)的五层灯塔建筑。一·二层是光体验展示馆，三到五层起灯塔的作用。树龄300~400年左右的海松林环绕着灯塔。

  • 开放时间:Songdaemal灯塔全天开放，灯塔展示馆 09:00~18:00。休息日:全年无休。费用:免费。

📍 蔚山 — Ulgi灯塔·Seuldo灯塔·Hwaamchu灯塔

Ulgi灯塔 (Ulgi Deungdae / 울기등대)(蔚山 (Dong-gu Deungdae-ro 155 / 동구 등대로 155)，☎ 052-251-2125)位于大王岩公园 (Daewangam Gongwon / 대왕암공원)内。通往灯塔的600m路边开着野花，4月王樱花树隧道盛开。过了灯塔沿台阶下去就是大王岩。

  • 开放时间:4~9月 09:00~18:00，10~3月 09:00~17:00。
  • 休息日:每周一(遇公休日则顺延至下一个非公休日)。费用:免费。停车:免费。

Seuldo灯塔 (Seuldo Deungdae / 슬도등대)(蔚山 (Dong-gu Seongkkeut-gil 122 / 동구 성끝길 122)，☎ Bangeo-dong居民中心 (Bangeo-dong Haengjeong Bokji Center / 방어동행정복지센터) 052-209-4177)过了拱形的Seuldo桥 (Seuldogyo / 슬도교)就到。周边有“背着幼崽的鲸鱼”雕像，入口处的声音体验馆 (Sori Cheheomgwan / 소리체험관)可以听到鲸鱼和大海的声音。据韩国观光公社介绍，这里是东海少见的落日名胜。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

Hwaamchu灯塔 (Hwaamchu Deungdae / 화암추 등대)(蔚山 (Dong-gu Hwaamdeungdae-gil 50 / 동구 화암등대길 50)，☎ 052-201-2602)是1994年12月建成的乌龟形灯塔。乘电梯上到观景台可以看到蔚山港和产业园区。

  • 开放时间:09:00~17:00。休息日:每周一。费用:免费。

📍 釜山 — 五六岛灯塔·影岛灯塔·加德岛灯塔

五六岛灯塔 (Oryukdo Deungdae / 오륙도 등대)(釜山 (Nam-gu Oryukdo-ro 130 / 남구 오륙도로 130)，☎ Haeparang-gil釜山旅游咨询处 (Haeparanggil Busan Gwangwang Annaeso / 해파랑길 부산관광안내소) 051-607-6395)位于五六岛六座岛中离陆地最远的灯塔岛上。登记为自2018年起无人化，不对一般游客开放，由影岛灯塔远程控制。开放时间一栏里也写着“全天开放”，登记值相互矛盾。在Haeparang-gil旅游咨询处可以获得五六岛灯塔的观光信息。

  • 休息日:全年无休。费用:免费。停车:可以。

影岛灯塔 (Yeongdo Deungdae / 영도 등대)(釜山 (Yeongdo-gu Jeonmang-ro 181 / 영도구 전망로 181)，☎ 051-405-1201)于1906年12月首次亮灯。2004年8月完成改造，成为设有海洋图书室和画廊的海洋文化空间。

  • 开放时间:10:00~17:00。
  • 休息日:每周一，1月1日，Seol·Chuseok连休。详情登记为请电话咨询。费用:免费。停车:不可以。

加德岛灯塔 (Gadeokdo Deungdae / 가덕도 등대)(釜山 (Gangseo-gu Oeyangpo-ro 10 / 강서구 외양포로 10)，☎ 051-971-9710)是1909年12月点灯的灯塔，2003年被指定为釜山广域市有形文化遗产。入口上方的匾额上刻有李花纹样。

  • 进入方式:位于军事区域内，出入受限，登记为出于军队保安暂时不接受参观申请。出发前先咨询。费用:免费。

📍 Jeonnam 丽水 — 梧桐岛灯塔

梧桐岛灯塔 (Odongdo Deungdae / 오동도 등대)(丽水市 (Odongdo-ro 238-32 / 오동도로 238-32)，☎ 061-662-3999)位于梧桐岛山顶。1952年5月12日首次亮灯，2002年作为高27m的八角形灯塔重建。外侧有观景电梯，办公楼二层有展示室。通往灯塔的路上山茶树形成隧道，介绍称11月左右花苞绽放，3月左右达到盛期。

  • 开放时间:4~9月 09:00~18:00，10~3月 09:00~17:00。休息日:每周一。停车:可以。

📍 济州 — Iho Tewoo马灯塔·Sanji灯塔·马罗岛灯塔

Iho Tewoo马灯塔 (Iho Tewoo Mal Deungdae / 이호테우 말 등대)(济州市 (Seohaean-ro 58 / 서해안로 58)，☎ 济州旅游信息中心 (Jeju Gwangwang Jeongbo Center / 제주관광정보센터) 064-740-6000)是位于Iho Tewoo海滩 (Iho Tewoo Haebyeon / 이호테우해변)的济州矮种马造型灯塔。高12m的红马灯塔和白马灯塔分别立在内侧防波堤和外侧防波堤上。据韩国观光公社介绍，离济州机场很近。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

Sanji灯塔 (Sanji Deungdae / 산지 등대)(济州市 (Sarabong-dong-gil 108-1 / 사라봉동길 108-1)，☎ 064-740-6000)位于Sarabong (Sarabong / 사라봉)北侧山坡。1916年10月作为无人灯塔首次设置，1999年12月新建了塔身。有咖啡馆和画廊。

  • 开放时间:夏季 09:00~19:30，冬季 09:00~18:00。休息日:全年无休。费用:免费。停车:小型车10辆。

马罗岛灯塔 (Marado Deungdae / 마라도 등대)(西归浦市 (Daejeong-eup Mara-ro 165 / 대정읍 마라로 165)，☎ 064-792-8507)位于国土最南端的马罗岛。是1915年3月首次建成、1987年3月重建的高16m的白色八角形灯塔。灯塔前有世界著名灯塔的模型。

  • 前往方式:从Unjin港客运码头 (Unjin-hang Yeogaek Teominal / 운진항 여객터미널)或San-isudong港 (Sanisudong-hang / 산이수동항)乘客轮。登记为必须事先电话咨询。
  • 开放时间:马罗岛灯塔 09:00~18:00。Unjin港客运码头 09:40~15:50，San-isudong港客轮 09:20~16:10。
  • 客轮费用:成人21,000韩元，初高中生20,800韩元，小学生10,500韩元，学龄前儿童10,000韩元，老人(满65岁以上)16,000韩元。

⚠ 行前须知 3 点

  1. 五六岛灯塔和加德岛灯塔登记为一般开放·参观受限 — 五六岛灯塔自2018年起不对一般游客开放，加德岛灯塔出入受限，暂时不接受参观申请。出发前先咨询。
  2. 周一休息的有六处 — 梧桐岛灯塔、Ulgi灯塔、影岛灯塔、Hwaamchu灯塔、Nueseom灯塔观景台、国立灯塔博物馆。
  3. Nueseom灯塔观景台要先看潮汐 — 退潮时可以步行进入，运营时间随涨潮·退潮时间变化。

⚙ FAQ 3

Q. 哪些灯塔有观景台或展示空间?

A. 登记信息中写有观景台或展示空间的地方是Oido红灯塔(展示馆·观景台)、Nueseom灯塔观景台、束草灯塔观景台、梧桐岛灯塔(电梯·展示室)、Hwaamchu灯塔(电梯·观景台)、Daejin灯塔(观景台)、Songdaemal灯塔(展示馆)、影岛灯塔(图书室·画廊)、Jebudo灯塔(观景台)、Sanji灯塔(画廊)、国立灯塔博物馆(展示)。

Q. 哪些灯塔登记为全天开放?

A. Iho Tewoo马灯塔、虎尾串灯塔、Seuldo灯塔、Jebudo灯塔、Songdaemal灯塔(仅灯塔，展示馆为 09:00~18:00)。五六岛灯塔也写着“全天开放”，但同时登记为不对一般游客开放。

Q. 最古老的灯塔是哪座?

A. 这份指南的灯塔中，登记的点灯·建造时间最早的是影岛灯塔(1906年12月点灯)。其次是虎尾串灯塔(1908年12月20日点灯)、加德岛灯塔(1909年12月点灯)、竹边灯塔(1910年11月建造)。
