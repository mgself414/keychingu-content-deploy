⚠ 처음 가는 외국인이 자주 하는 실수 3가지

1. "종로=경복궁만 본다" — 동네 코스 모름

외국인 인식상 종로는 경복궁(궁궐) + 청계천만. 실제로는 광화문(다운타운) + 인사동(전통) + 익선동(한옥 골목) + 북촌(한옥마을) + 종각(영업) 5개 sub-area. 한 동선으로 모두 도보 가능 (지하철 1·3호선 안)인데, sub-area 구분 안 하면 한 곳만 보고 끝남.

2. 인사동·익선동을 같은 동네로 착각

둘 다 한옥 분위기지만 인사동(전통식품·문화·기념품 중심) ≠ 익선동(MZ 카페·바·인스타). 익선동은 2010년대 후반 재생된 신생 핫스팟. 처음에는 인사동 → 익선동 도보 7분 코스로 묶기.

3. 삼계탕·전통식품을 "광화문에서만" 찾음

60년 노포 장수삼계탕은 광화문 인근, 인사동·익선동에는 더 모던한 한식 매장(도마·솔솥)이 인기. sub-area별 음식 톤이 다름 — 무엇을 먹을지 정하고 sub-area 선택.

⚙ FAQ 8개

Q1. 종로구 첫 방문 1일 코스?

경복궁 10:00 → 장수삼계탕 점심 (12:00) → 광화문 광장 → 스탠다드번 휴식 → 한과미의식 + 도마 인사동 코스 (15:00) → 익선동 도보 → 한옥랑솜 + 솔솥 저녁 → 호선생전 야간 마무리

Q2. 인사동 vs 익선동 어디?

인사동: 전통식품·기념품·정통 한식 (한과·도마). 익선동: MZ 카페·바·한옥 인스타 (한옥랑솜·솔솥·호선생전). 외국인 성향에 따라 — 전통 = 인사동 / MZ + 인스타 = 익선동.

Q3. 영어 메뉴·서비스는?

질할브로스 / 스탠다드번 / 한과미의식 / 도마 — 영어 친화도 high. 솔솥 / 호선생전은 영어 일부. 장수삼계탕은 노포라 한국어 위주.

Q4. 노포·정통 vs 모던 한식?

노포 정통: 장수삼계탕 (60년) / 도마 인사동 (정통). 모던 한식: 솔솥 익선 (가마솥) / 한과미의식 (모던 plating). 외국인 입문은 모던, 노포는 매니아.

Q5. 익선동 한옥 카페 best 시간?

평일 오전 (11~13시) 자리 여유. 주말 14~17시 대기 30분+. 한옥 분위기 사진은 자연광 좋은 13~15시.

Q6. 가격대는?

양식 (질할브로스) ₩15,000~30,000 / 한식 (도마·솔솥) ₩15,000~25,000 / 카페·디저트 ₩7,000~12,000 / 한과 ₩15,000~30,000 / 삼계탕 ₩18,000~25,000.

Q7. 휴무일·영업시간 주의?

대부분 매일 영업. 장수삼계탕은 명절 휴무. 호선생전은 일부 월 휴무. 한과미의식은 시즌별 변동. 방문 전 확인.

Q8. 휠체어·유모차 접근?

질할브로스 / 스탠다드번 / 도마 — 평탄 동선. 한옥랑솜·솔솥·호선생전·익선동 골목은 좁고 계단·문턱 다수.

Q9. 광장시장 뭐가 유명해요? (What is Gwangjang Market famous for?)

빈대떡(Bindaetteok)·마약김밥·육회 3종이 외국인 1순위. 즉석 조리 철판 빈대떡 + 엄지 크기 마약김밥이 SNS 바이럴. 서울 최초 근대시장(1905년) 실내 먹거리 골목.

Q10. 광장시장 가볼 만해요? (Is Gwangjang Market worth visiting?)

강력 추천. 현금 ₩30,000~40,000으로 빈대떡·마약김밥·육회 모두 경험 가능. 2시간이면 충분. 종로5가역(Jongno 5-ga Station)에서 도보 2분.

Q11. 종로 하루 코스에서 광장시장 언제?

점심 시간대(11:30~13:00) — 경복궁 or 인사동 오전 코스 → 광장시장 점심 → 익선동 오후가 종로 최적 1일 동선.

🗺 추천 1일 코스 3가지

A코스 — "종로 첫 방문 완전 코스" (외국인 초보, 10시간)

경복궁 10:00 → 장수삼계탕 점심 (12:00, 1시간) → 🏪 광장시장 빈대떡·마약김밥 (13:00, 1시간) → 광화문 광장 산책 → 스탠다드번 휴식 (30분) → 한과미의식 + 도마 인사동 (16:00, 2시간) → 익선동 도보 → 한옥랑솜 카페 (1시간) → 솔솥 익선 저녁 (1.5시간) → 호선생전 야간 (1시간)

B코스 — "전통문화 deep dive" (한국 전통 매니아, 6시간)

경복궁 09:00 → 창덕궁 → 장수삼계탕 점심 → 한과미의식 + 도마 인사동 (전통 한식+한과 코스, 3시간) → 통인시장 산책

C코스 — "MZ + 인스타 (익선동 풀)" (MZ 외국인, 5시간)

종로3가역 12:00 → 한옥랑솜 익선동 카페 (1.5시간 인스타) → 솔솥 익선 점심 (1시간) → 익선동 한옥 골목 산책 → 호선생전 저녁 (1.5시간 요리주점)

🌸 시즌·시간대 훅 5개

1. 봄 (3~5월) 경복궁 벚꽃: 경복궁 + 장수삼계탕 + 인사동 코스 — 한국 봄 정수.

2. 여름 (6~8월) 삼복: 장수삼계탕이 절정 시즌. 외국인도 한국 보양식 경험.

3. 가을 (9~11월) 익선동 단풍: 한옥랑솜·솔솥 익선 한옥 골목 단풍 시즌.

4. 겨울 (12~2월) 호선생전 요리주점: 따뜻한 요리주점 + 막걸리 코스.

5. 이른 아침 (08~10시): 광화문·경복궁 한산. 장수삼계탕 11시 오픈 후 점심 한산.
