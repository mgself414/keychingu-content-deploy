한국 키오스크 주문, 당황 제로 매뉴얼 — 화면 그대로 따라하기

> 부제: 한국 식당·카페 셀프 주문 기계(키오스크) 완전정복 — 3유형 구분 · 공통 6단계 화면 플로우 · 한국어-only 화면 생존 단어 15 · 해외카드 거절 대응 · 맥도날드/롯데리아/메가커피 실전 워크스루

ISSUE 04 · #1270 · 2026-08-13 · korea-first-timer 시리즈 ①

🎯 이 매뉴얼을 읽는 법 — 화면 표기 규약

이 글은 "무엇을 하라"가 아니라 "화면에 무엇이 보이고, 어느 버튼을, 어떤 순서로 누르는지"를 그대로 적는다. 출국 전 침대에서 한 번 읽으면, 기계 앞에서 처음 보는 화면이 아니게 된다.

  • 화면 속 버튼은 대괄호로: [ 포장 (Takeout) ]
  • 화면 제목·안내 문구는 낫표로: 「주문 방법 선택」
  • 손으로 하는 동작은 굵게: "카드를 아래 투입구에 끝까지 삽입"

① 왜 한국 식당엔 점원 대신 기계가 있나

한국 외식업은 인건비 상승과 비대면 선호가 겹치며 주문 자동화가 매우 빠르게 진행됐다. 맥도날드·롯데리아·버거킹 등 주요 패스트푸드 체인은 대부분 매장에서 키오스크가 기본 주문 창구이고, 저가 커피 체인(메가커피·컴포즈커피 등)은 아예 키오스크 없이는 주문 접수 자체를 안 하는 매장도 흔하다. 고깃집·분식집은 테이블 위 태블릿으로 옮겨가는 중이다.

즉 "기계가 있다 = 불친절"이 아니라 "기계가 곧 카운터"다. 이 구조를 알고 가면 절반은 끝난다. 나머지 절반이 이 매뉴얼이다.

② 키오스크 3유형 — 내 앞의 기계는 어느 쪽인가

유형 어디서 만나나 언어 난이도
A. 글로벌 패스트푸드형 맥도날드 McDonald's·버거킹 Burger King·KFC 🇺🇸🇨🇳🇯🇵 국기 버튼으로 전환 가능 ★☆☆
B. 국산 카페·버거형 메가커피 Mega Coffee·컴포즈커피 Compose Coffee·롯데리아 Lotteria·맘스터치 Mom's Touch 한국어 전용이 많음 (영어 버튼이 있어도 일부만 번역) ★★★
C. 테이블오더 태블릿형 고깃집·김밥천국 Kimbap Heaven·호프집 — 테이블 위 태블릿 매장마다 다름, 사진 큼 ★★☆
참고 편의점 셀프 계산대는 별도 → #1219 무인매장 편
  • A유형: 화면 구석의 국기 아이콘 또는 [ English ] 버튼부터 찾아라. 있으면 이 글의 절반은 필요 없다.
  • B유형: 이 매뉴얼의 주 타깃. 아래 ④ 생존 단어 15로 돌파한다.
  • C유형: 앉은 자리에서 천천히 눌러도 되니 심리 부담이 가장 적다. 마지막에 [ 주문하기 ]를 눌러야 주방에 전송된다는 것만 기억.

③ 공통 6단계 마스터 플로우 — 어떤 기계든 이 순서

한국 키오스크는 브랜드가 달라도 아래 6단계에서 벗어나지 않는다.

단계 화면에 보이는 것 누를 버튼 함정
1 「매장에서 드시나요?」 [ 매장 ] 또는 [ 포장 ] 이 화면을 건너뛰는 기계도 있음(마지막에 물음)
2 메뉴 사진 격자 + 왼쪽 카테고리 탭 원하는 메뉴 사진 터치 사진이 곧 언어 — 글자를 몰라도 사진으로 고른다
3 「옵션 선택」 팝업 (세트/사이즈/샷·시럽) [ 단품 ] vs [ 세트 ], 옵션 후 [ 선택 완료 ] 옵션 팝업을 닫아야 다음으로 감 — 멈췄다면 십중팔구 이 화면
4 「장바구니」 (담은 목록 + 합계) 추가 주문 or [ 결제하기 ] [ 결제하기 ]가 화면 맨 아래 큰 버튼
5 「적립/쿠폰」 팝업 [ 건너뛰기 ] / [ 아니오 ] 관광객은 100% 건너뛰기 — 한국 전화번호 입력 화면이므로
6 「결제 수단 선택」 → 카드 투입 [ 카드 결제 ] → 카드를 IC칩 위쪽으로 끝까지 삽입 진동 없이 몇 초 대기. 뽑으라는 소리("삑")가 나면 뽑기

끝나면 영수증에 번호가 찍힌다. 벽 모니터에 그 번호가 뜨면 픽업대에서 받는다. 이게 전부다.

④ 한국어-only 화면 생존 단어 15 — "이 글자가 보이면 이 뜻"

B유형(한국어 전용) 기계에서 실제로 마주치는 글자만 추렸다. 스크린샷 찍어 가거나 이 페이지를 저장해 두자.

화면의 한국어 읽기 뜻 = 해야 할 것
매장 maejang Eat in — 먹고 갈 때
포장 pojang Takeout — 가져갈 때
담기 damgi Add to cart
장바구니 jangbaguni Cart — 담은 목록
단품 danpum Item only (세트 아님)
세트 seteu Combo/set
옵션 opsyeon Options 팝업
선택 완료 seontaek wallyo Done/Confirm — 팝업 닫기
결제하기 gyeoljehagi Pay — 가장 중요한 버튼
적립 jeongnip Points — 관광객은 무관
건너뛰기 geonneottwigi Skip — 적립 화면 탈출
품절 pumjeol Sold out — 회색 처리된 메뉴
영수증 yeongsujeung Receipt — 번호표 겸용
처음으로 cheoeumeuro Start over — 잘못 눌렀을 때 리셋
호출 hochul Call staff — 직원 부르기

> 팁: 15개를 다 외울 필요 없다. 결제하기(진행) · 건너뛰기(탈출) · 처음으로(리셋) 세 개가 핵심 동사다.

⑤ 결제 분기 — 해외카드가 거절될 때가 진짜 본편

한국 결제망(VAN)은 독자 규격이라 국제 EMV 표준을 지원하는 단말이 소수다. 그래서 같은 Visa/Mastercard여도 기계에서는 거절, 카운터에서는 승인되는 일이 흔하다. 이건 당신 카드 문제가 아니라 한국 인프라 특성이다.

상황 대응
키오스크가 카드를 뱉음 탭(컨택리스) 대신 삽입으로 재시도 1회 → 안 되면 미련 없이 카운터로
카운터가 없는 무인 매장 다른 카드(발급사 다른 것) → 현금 겸용 기계인지 확인(지폐 투입구)
반복 여행자라면 WOWPASS(외국인용 선불카드, 주요 역·공항 발급기) 또는 티머니 잔액 결제를 미리 준비 → 상세는 결제 심층편 #527
현금만 있는데 카드 전용 기계 직원 호출([ 호출 ] 버튼 또는 카운터) — 대부분 수동 결제 처리해 줌
  • 삼성페이·애플페이: 애플페이는 되는 매장이 늘고 있지만 아직 복불복. 물리 카드 2장(발급사 다른)이 가장 안전한 조합.
  • 현금 예비 3~5만 원을 항상 지니고 다니면 어떤 거절에도 평정심이 유지된다.

⑥ 체인별 실전 워크스루 — 그 매장 화면 그대로

🍔 맥도날드 (A유형, 영어 됨)

1. 첫 화면 하단 국기 아이콘 → [ English ]

2. 「Eat In or Take Out?」 → 선택

3. 메뉴 → 버거 터치 → 「Meal or Item only?」 → 옵션(감자·음료 변경 가능)

4. [ Checkout ] → 포인트 화면 [ Skip ] → 카드 삽입

  • 특징: 번역 완성도가 가장 높다. 첫 키오스크 경험은 맥도날드로 예행연습하는 게 최적.

🍔 롯데리아 (B유형에 가까움, 영어 버튼은 있으나 부분 번역)

1. 언어 버튼이 있으면 전환 — 단, 메뉴명 일부는 한국어로 남는다

2. 「매장/포장」 → 메뉴 사진 터치 → [ 단품 ] / [ 세트 ] 선택이 필수 팝업

3. [ 결제하기 ] → 적립 팝업 [ 건너뛰기 ] → 카드 삽입

  • 특징: 세트 옵션 팝업이 맥도날드보다 단계가 많다. 멈추면 화면 어딘가의 [ 선택 완료 ]를 찾아라.

☕ 메가커피 (B유형, 한국어 전용 다수)

1. 언어 버튼이 없는 매장이 많다 — ④ 생존 단어로 정면 돌파

2. 「매장/포장」 → 커피 사진 터치 → 옵션 팝업: HOT / ICE, 사이즈, 샷 추가

3. [ 담기 ] → [ 결제하기 ] → 적립 전화번호 화면 [ 건너뛰기 ] → 카드

  • 특징: 저가 커피 체인(컴포즈·빽다방도 동일 구조)은 화면 흐름이 거의 같다. 하나를 익히면 전부 통한다.

⑦ 당황 시나리오 3 — 실제로 벌어지는 일과 심리 대처

1. 뒤에 줄이 길다 — 한국인도 평균 1~2분 걸린다. 뒤에서 재촉하는 문화가 아니니 심호흡. 정 부담되면 일단 비켜서서 이 페이지 ③플로우를 다시 보고 재도전해도 아무도 뭐라 하지 않는다.

2. 잘못 눌러서 이상한 화면 — 만능 해결: [ 처음으로 ] 또는 좌상단 [ ← ]. 키오스크는 결제 전까지 아무것도 확정되지 않는다.

3. 가만히 있었더니 첫 화면으로 돌아감 — 30초~1분 무입력 시 자동 리셋되는 기계가 많다. 고장이 아니다. 처음부터 다시 누르면 된다.

⑧ 플랜B — 기계가 정 안 되면

  • 카운터 주문 가능 판별: 카운터에 직원이 상주하고 POS 단말이 보이면 대부분 구두 주문을 받아준다. 키오스크 옆 「카운터 주문 가능」 안내가 있는 곳도 있다.
  • 직원 호출 한 문장: "도와주세요 (dowajuseyo)" — 이 한마디 + 키오스크를 가리키면 끝. 한국 직원들은 키오스크 헬프 요청에 익숙하다.
  • 화면을 보여주는 방법: 파파고/구글 번역에 "I'd like to order this. Card payment doesn't work."를 한국어로 번역해 화면째 보여주기 → 앱 셋업은 필수앱 편 #1230.
  • 동행 시뮬레이션: 일행 중 한 명이 이 페이지 ③표를 읽어주며 다른 한 명이 누르면 첫 실전이 가장 편하다.
