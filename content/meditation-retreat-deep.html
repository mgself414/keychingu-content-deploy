⚠ 외국인 자주 실수 5가지

1. "명상 = 사찰만": 명상 = 사찰 + 요가 스튜디오 + 비파사나·MBSR + 한방 명상 + 도심 명상센터 풀세트 + #509·#448·#546 통합.

2. "리트리트 = 비쌈": 리트리트 = 제주·강원 1박 20~50만원 + 외국인 매니아 1순위 + Klook 30% 할인 + #534·#525 통합.

3. "외국인 = 영어 안됨": 영어 OK = 조계사·길상사·#509 템플스테이 + 외국인 비파사나·MBSR + 외국인 매니아 1번지 + #178·#540 통합.

4. "비파사나 = 10일만": 비파사나·위빠사나 = 3일·7일·10일 풀세트 + 외국인 영어 OK + 외국인 매니아 1번지 + #178·#509 통합.
