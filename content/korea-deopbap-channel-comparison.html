⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 완전 다름. 가성비 = 체인 / MZ = MZ / 가족 = 가정식 / 럭셔리 = 한정식.

2. "체인 = 패스트": 체인 = 한식 정통 가성비.

3. "MZ = 즉시": MZ = 웨이팅 있음.

4. "가정식 = 비싸기만": 가정식 = 8~15k 가성비.

5. "한정식 = 비빔밥": 한정식 = 소고기덮밥 코스 가능.
