🎯 왜 K-드라마 지방·외곽 deep dive인가

지방·외곽 K-드라마 촬영지 = 외국인 매니아 매트릭스 #1 서울 외 한국 깊이 + KTX·1박2일 풀세트. 외국인 관광객 페인포인트 = (a) "K-드라마 = 서울만" 잘못된 인식 — 부산·전주·강원·인천·경기·제주 = 6대 지방 cluster 매트릭스 #1 (b) #1101 서울 12선과 페어 — 서울 1박2일 + 지방 1박2일 = 2박3일·3박4일 풀세트 외국인 매니아 fit (c) 도깨비 강릉 주문진·기생충 부산·이태원 클라스 부산 광안리·낭만닥터 강원 = 명작 + 2024-2026 신작 매트릭스 (d) KTX 1~2시간 30분 = 외국인 매니아 1박2일 매트릭스 cross + 1078 페어 (e) K-drama 지방 + 한옥스테이(#1076)·지방 미식 1박2일(#1078)·#1101 서울 K-drama cross.

본 가이드는 외국인 시각 지방·외곽 6 도시 9선 + KTX·동선·1박2일 매트릭스 + 매니아 풀세트.

★ 한눈에 K-드라마 지방·외곽 9선 매트릭스

# 도시·spot K-드라마 시그너 (2024-2026 신작 ★) 동선·교통 외국인 매니아 포인트
1 강원 강릉 주문진(Jumunjin) 방파제 ★ 도깨비 (공유 등장 명장면)·뭐든지 물어보살 서울→강릉 KTX 1시간 50분 + 버스 30분 도깨비 글로벌 #1 spot + 외국인 매니아 매트릭스 #1
2 강원 강릉 안목해변·BTS 정류장 도깨비·BTS Spring Day MV 서울→강릉 KTX + 안목해변 BTS 팬 매니아 + photogenic
3 부산 광안대교·광안리 해수욕장 ★ 이태원 클라스 (광안리 야경)·기상청 사람들·경성크리처 ★ 서울→부산 KTX 2시간 30분 + 광안역 부산 야경 매트릭스 #1 + 이태원 클라스 cross
4 부산 감천문화마을 (Gamcheon Culture Village) 재벌집 막내아들 ★·태양의 후예 (가짜 그리스 마을) 부산역 + 버스 + 도보 부산 photogenic 매트릭스 #1 + 외국인 매니아 + #1078 페어
5 부산 해운대·동백섬 친구·해운대 (영화)·대도시의 사랑법 ★ 부산 KTX + 해운대역 해운대 + 동백섬 산책 + 외국인 매니아 매트릭스
6 전주 한옥마을(Jeonju Hanok Village) ★ 너의 목소리가 들려·연인 (2023)·옷소매 붉은 끝동 서울→전주 KTX 1시간 30분 + 버스 전주 한옥 + K-사극 매트릭스 #1 + 한복 + #1076 한옥스테이 cross
7 경기 양평·청평·가평 도깨비·선재업고튀어 ★ (양평 카페)·우영우 (양평 펜션) 서울→가평 ITX 50분 / 양평 광역버스 수도권 외곽 매트릭스 + 외국인 매니아 1박2일
8 인천 송도·차이나타운 도깨비 (송도 라이프타워)·낭만닥터 김사부 시즌3 ★ 서울→인천 1호선 1시간 외국인 입국 시 cross + 인천공항 페어
9 제주(Jeju) 한라산·우도 태양의 후예 (제주 항공편)·기적의 형제 (2025) ★·연인 서울→제주 비행기 1시간 (김포·인천) 제주 K-drama + 외국인 매니아 풀세트 매트릭스

⚠ 외국인 자주 실수 3가지

1. "K-드라마 지방 = 너무 멀어서 못 가": KTX 매트릭스 = 서울→부산 2시간 30분·서울→강릉 1시간 50분·서울→전주 1시간 30분·서울→가평 ITX 50분·서울→인천 1호선 1시간·서울→제주 비행기 1시간. 1박2일 풀세트 매트릭스 + #1078 페어. 외국인 매니아 = KORAIL Pass (외국인 전용 3·5·7·10일) 매트릭스 #1.

2. "강릉 주문진 = 도깨비만": 강릉 = 도깨비 풀세트 (주문진 방파제 + 안목해변 BTS 정류장 + 안목 커피거리) + 강원도 자연 (경포대·정동진 일출·오죽헌). 외국인 매니아 = 강릉 1박2일 = 도깨비 풀세트 + 강원 매니아.

3. "부산 = 회·해운대만": 부산 K-drama = 광안대교 야경 (이태원 클라스)·감천 문화마을 (재벌집 막내아들)·해운대 (친구·대도시의 사랑법) cluster. 외국인 매니아 = 부산 1박2일 = K-drama + 회 + 야경 풀세트 (#1078 페어).

⚙ FAQ 4개

1. 외국인 서울 + 지방 풀세트 2박3일 K-drama 동선: Day 1 서울 K-drama (#1101 페어): 경복궁 + 북촌 + 청계천 + N서울타워. Day 2-3 지방 K-drama 선택: (a) 강릉 도깨비 1박2일 = KTX → 주문진 방파제 → 안목해변 BTS 정류장 → 안목 커피 → 정동진 일출 (b) 부산 K-drama 1박2일 = KTX → 광안대교 야경 → 감천 문화마을 → 해운대 + 회 (#1078 페어) (c) 전주 한옥 1박2일 = KTX → 전주 한옥마을 + 비빔밥 + 옷소매 붉은 끝동 (#1078 페어).

2. 외국인 K-drama 1주일 풀세트 5박6일: Day 1-2 서울 (#1101 12선) → Day 3 강릉 (1·2 도깨비·BTS) → Day 4 부산 (3·4·5 광안대교·감천·해운대) → Day 5 전주 (6 한옥 사극) → Day 6 제주 (9 한라산·태양의 후예). 외국인 매니아 = KORAIL Pass 7일·10일 매트릭스 + 1078 페어.

3. K-drama 외곽 etiquette (외국인 시각): (a) KTX 예약 = KORAIL 영어 사이트 + 코레일톡 앱 + KORAIL Pass (외국인 전용) 매트릭스 #1 (b) 강릉 BTS 정류장 = 사진 OK + 다른 팬 매너 (c) 감천 문화마을 = 거주민 거주지 + 조용 photo etiquette (d) 전주 한옥마을 = 한복 + 한옥 photogenic + 거주민 매너 (e) 제주 = 비행기 1시간 + 렌트카 추천.

4. 외국인 K-drama 외곽 best 시즌: 봄꽃 (4월 전주 한옥·강릉 벚꽃·부산 봄꽃) = 외국인 매니아 #1. 여름 (6~8월 부산 해운대·강릉 안목해변·제주 한라산) = 해변 K-drama. 가을 (10월 전주 단풍·강릉 단풍·양평·가평) = 단풍 매트릭스. 겨울 (12~2월 강릉 일출·부산 회·제주 한라산 눈) = 매트릭스 매니아.
