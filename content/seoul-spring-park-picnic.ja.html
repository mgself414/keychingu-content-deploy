ソウル公園散策ガイド — 北ソウル夢の森、京義線スプキル、駱山公園、ソウル植物園・湖水公園、西ソウル湖水公園、果川ソウル大公園・森林浴場

サブタイトル: 北ソウル夢の森(常時開放) · 京義線スプキル(約6.3km、常時開放) · 駱山公園(常時開放) · ソウル植物園(主題園は月曜休館) · 西ソウル湖水公園(常時開放) · ソウル大公園(11~2月 09:00~17:00) · ソウル大公園 森林浴場(約2時間30分) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルとすぐ隣の果川で歩いたり休んだりしやすい公園をまとめたものです。江北の北ソウル夢の森、古い線路の京義線スプキル、漢陽都城に沿う駱山公園、江西のソウル植物園、陽川の西ソウル湖水公園、果川のソウル大公園です。ソウル植物園の主題園(温室)だけが月曜休みで、ほかは年中無休で登録されています。西側の大きな公園は#741 ソウル西部公園ガイドにあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 江北 — 北ソウル夢の森

北ソウル夢の森、江北区 Wolgye-ro 173 (월계로 173)、☎ 02-2289-4000 は、元ドリームランド (Deurimraendeu / 드림랜드)の跡地68万余㎡につくった公園で、2009年10月17日に開園しました。観光公社の紹介によると、ワールドカップ公園とオリンピック公園に次いでソウルで3番目に大きな公園です。ビョゴ山 (Byeogosan / 벽오산)とオペ山 (Opaesan / 오패산)に囲まれ、桜並木、紅葉の森、池ウォリョンジ (Woryeongji / 월영지)とウォルグァンの滝 (Wolgwang Pokpo / 월광폭포)、北漢山・道峰山・水落山が見える49.7mの展望台、夢の森アートセンター (Kkumui Sup Art Center / 꿈의숲아트센터)があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能(386台)。

📍 都心 — 京義線スプキル・駱山公園

京義線スプキル、麻浦区 ヨンナム洞 (Yeonnam-dong / 연남동)、☎ 京義線スプキル公園コミュニティセンター (Gyeongui-seon Supgil Gongwon Community Center / 경의선숲길공원 커뮤니티센터) 02-719-8830 は、1900年代初めに龍山 (Yongsan / 용산)と新義州 (Sinuiju / 신의주)をつないだ京義線の線路のうち、地下に移った龍山線区間の地上の線路を、2016年に森の道に変えた場所です。孝昌公園前駅 (Hyochanggongwon-ap-yeok / 효창공원앞역)から加佐駅 (Gajwa-yeok / 가좌역)まで約6.3kmです。麻浦区の区間は、孔徳洞 (Gongdeok-dong / 공덕동)から塩里洞 (Yeomni-dong / 염리동)・大興洞 (Daeheung-dong / 대흥동)、京義線ブックストリート (Gyeongui-seon Chaek-geori / 경의선 책거리)があるワウ橋 (Waugyo / 와우교)区間を過ぎ、「ヨントラルパーク (Yeontral Park / 연트럴파크)」と呼ばれるヨンナム洞区間まで続きます。

  • 開く時間: 常時開放。休み: 年中無休。

駱山公園、鍾路区 Naksan-gil 41 (낙산길 41)、☎ 02-743-7985~6 は、大学路 (Daehangno / 대학로)と東大門 (Dongdaemun / 동대문)からつながる公園で、2002年に公園として開園しました。地形がラクダの背に似ていて駱駝山 (Naktasan / 낙타산)、宮廷に牛乳を納める王室の牧場があって駝酪山 (Taraksan / 타락산)とも呼ばれました。中央広場には、駱山の由来と漢陽都城の資料を展示する駱山展示館 (Naksan Jeonsigwan / 낙산전시관)と中央ステージがあり、東屋のナクサンジョン (Naksanjeong / 낙산정)からソウルを見下ろせます。週末には駱山とソウル漢陽都城 (Seoul Hanyang Doseong / 서울한양도성)についての無料プログラムがあります。観光公社の紹介によると、ソウルで最も美しい夜景を見られる場所に挙げられています。Netflixアニメ『KPop Demon Hunters (케이팝 데몬 헌터스)』に登場した場所の一つです。

  • 歩く道: 梨花洞壁画村 (Ihwa-dong Byeokhwa Maeul / 이화동 벽화마을)、興仁之門 (Heunginjimun / 흥인지문)・漢陽都城路 (Hanyang Doseong-gil / 한양도성길)へ向かう東大門コース、漢城大入口 (Hanseongdaeipgu / 한성대입구)方面コース。
  • 開く時間: 常時開放。駱山展示館 09:00~17:00。休み: 年中無休。
  • 駐車: 可能(29台)。

📍 西側 — ソウル植物園・湖水公園・西ソウル湖水公園

ソウル植物園、江西区 Magok-dong-ro 161 (마곡동로 161)、☎ 02-2104-9716 は、2019年5月に麻谷 (Magok / 마곡)で開園した植物園兼公園で、面積はサッカー場70個分です。開かれた森 (Yeolin Sup / 열린숲)、湖水園 (Hosuwon / 호수원)、湿地園 (Seupjiwon / 습지원)、主題園 (Jujewon / 주제원)の四つの区域に分かれています。主題園の展示温室には、熱帯・地中海12都市の自生植物があります。観光公社の紹介によると、展示温室は世界で唯一のくぼんだ皿の形の温室です。

  • 開く時間: 主題園(温室・主題庭園) 3~10月 09:30~18:00(入場締切 17:00)、11~2月 09:30~17:00(入場締切 16:00)。
  • 休み: 主題園 毎週月曜日。開かれた森・湖水園・湿地園は年中無休。このほかの休館日も別にあると登録されています。
  • 駐車: 可能。ベビーカー貸出: 可能。

ソウル植物園 湖水公園(同じ住所、☎ 02-2104-9716)は、ソウル植物園とつながった「公園の中の公園」です。湖に沿って散策路と水辺の観察デッキがあり、湖を渡る歩行者橋、子ども用遊び場、水遊び場があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

西ソウル湖水公園、陽川区 Nambusunhwan-ro 64-gil 20 (남부순환로64길 20)、☎ 02-2604-3004 は、1959年に金浦浄水場 (Gimpo Jeongsujang / 김포정수장)として始まった旧新月浄水場 (Sinwol Jeongsujang / 신월정수장)の跡地に、「水」と「再生」をテーマにつくって2009年10月に開園した公園です。面積は217,946㎡です。開かれた芝生、100人の食卓 (Baek-inui Siktak / 100인의 식탁)、再生庭園 (Jaesaeng Jeongwon / 재생정원)、モンドリアン庭園 (Mondrian Jeongwon / 몬드리안정원)、中央湖、音の噴水 (Sori Bunsu / 소리분수)、屋上庭園 (Oksang Jeongwon / 옥상정원)があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

📍 果川 — ソウル大公園・森林浴場

ソウル大公園、果川市 Daegongwon-gwangjang-ro 102 (대공원광장로 102)、☎ 02-500-7335 は、1984年に開園したテーマパークで、ソウル動物園 (Seoul Dongmulwon / 서울동물원)、1,600余種の植物園、清溪山 (Cheonggyesan / 청계산)のふもとの癒やしの森 (Chiyuui Sup / 치유의 숲)、森林浴場、キャンプ場があります。観光公社の紹介によると、ソウル大公園の植物園は国内初の公立樹木園です。ソウルランド (Seoul Land / 서울랜드)と国立現代美術館 (Gungnip Hyeondae Misulgwan / 국립현대미술관)が隣にあります。

  • 開く時間: 3~4月・9~10月 09:00~18:00(入場締切 17:00)、5~8月 09:00~19:00(入場締切 18:00)、11~2月 09:00~17:00(入場締切 16:00)。展示温室 10:00~17:00(入場締切 16:30)。
  • 休み: 年中無休。駐車: 可能。
  • 体験: 森林ヒーリングプログラム、ゾウ列車 (Kokkiri Yeolcha / 코끼리 열차)、動物教室 (Dongmul Gyosil / 동물교실)など。

ソウル大公園 森林浴場、果川市 マッケ洞 (Maggye-dong / 막계동)、☎ ソウル大公園 造景課 (Jogyeong-gwa / 조경과) 02-500-7541 は、動物園のオーストラリア館 (Hojugwan / 호주관)の入口か北門 (Bungmun / 북문)から入る森の道で、テーマの森12か所を通ります。約2時間30分かかり、南米館 (Nammigwan / 남미관)・貯水池 (Jeosuji / 저수지)・猛獣舎 (Maengsusa / 맹수사)の3か所の脇道で1時間前後に短縮できます。デッキの休憩所6か所にピクニックテーブルがあります。長さは登録情報の中で7kmと8kmの二通りに書かれていて、一致しません。

  • 開く時間: ソウル大公園と同じ(11~2月 09:00~17:00、入場締切 16:00)。天候によって立ち入りを止めることがあります。
  • 休み: 年中無休。駐車: 可能。

⚠ 事前に知っておきたい3点

  1. ソウル植物園の主題園(温室)は月曜休み — 11~2月は16:00に入場を締め切ります。
  2. ソウル大公園は京畿道果川市にあります — 11~2月は09:00~17:00に開き、16:00に入場を締め切ります。
  3. 駱山展示館は09:00~17:00に開きます — 駱山公園そのものは常時開放です。

⚙ FAQ 2

Q. 冬でも室内で植物を見られますか?

A. 観光公社の登録情報では、ソウル植物園の主題園温室が11~2月 09:30~17:00(月曜休館)、ソウル大公園の展示温室が季節の区別なく10:00~17:00(入場締切 16:30)に開くと登録されています。

Q. 古い線路を歩く公園は?

A. 京義線スプキル (Gyeongui-seon Supgil / 경의선숲길)です。孝昌公園前駅 (Hyochanggongwon-ap-yeok / 효창공원앞역)から加佐駅 (Gajwa-yeok / 가좌역)まで約6.3kmで、常時開放です。
