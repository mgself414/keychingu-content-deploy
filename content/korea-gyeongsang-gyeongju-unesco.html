외국인 경상도 경주 — UNESCO 1995·불국사·석굴암·신라 천년고도

> 부제: 외국인 관광객용 경주 UNESCO 1995 + 불국사 751년 + 석굴암 + 천마총 + 신라 천년고도 BC 57

ISSUE 04 · #1052 · 2026-06-08

🎯 왜 경주 가이드인가

경주 (Gyeongju) = UNESCO 세계문화유산 1995·신라 천년고도 (BC 57~AD 935)·불국사 + 석굴암 (UNESCO)·천마총·국립경주박물관. 외국인 페인포인트 = (a) "경주 = 일반 도시" 잘못된 인식 (b) UNESCO 1995 = 한국 #1 매니아 매트릭스 (c) 불국사 (751년)·석굴암 = UNESCO 시그너 #1 (d) 신라 천년고도 = 천마총·안압지·첨성대 매트릭스 (e) 영문 풀세트·외국인 매니아 매트릭스 (f) KTX 신경주역 2시간.

본 가이드는 5축 12 시그니처 + UNESCO + 신라 + 천마총.

★ 한눈에 5축 12 시그니처

🏛 5축 deep dive

① 불국사 (UNESCO 1995·751년)

  • 시그니처: 751년 (신라 경덕왕)·UNESCO 1995·한국 #1 사찰 매트릭스
  • 외국인 친화도: ★★★★★ (영문·다국어 풀세트)
  • 시간: 09:00~18:00·6,000원

② 석굴암 (UNESCO 1995)

  • 시그니처: 751년·석굴 + 본존불·UNESCO 시그너 #1
  • 외국인 친화도: ★★★★★ (영문·매니아 매트릭스 #1)
  • 시간: 09:00~17:00·6,000원

③ 천마총 + 국립경주박물관

  • 시그니처: 1973년 발견 천마총 (155호 고분)·영문 풀세트
  • 외국인 친화도: ★★★★★ (영문·매니아 매트릭스)
  • 가격: 천마총 = 3,000원·박물관 = 무료

④ 신라 천년고도 (안압지·첨성대)

  • 시그니처: 안압지 (674년·인공 호수)·첨성대 (한국 #1 천문대 매트릭스)
  • 외국인 친화도: ★★★★★ (영문·인스타 + MZ)

⑤ 경주 음식 + 1박 매니아

  • 시그니처: 경주 한정식·황남빵 시그너·한옥 게스트하우스
  • 외국인 친화도: ★★★★★ (영문 + 결제)

⚠ 외국인 자주 실수 5가지

1. "경주 = 일반 도시": UNESCO 1995 + 신라 천년고도 + 매니아 매트릭스 #1.

2. "불국사 = 일반 사찰": 751년·UNESCO·한국 #1 사찰 매트릭스.

3. "석굴암 = 작은 동굴": UNESCO 시그너 #1·석굴 + 본존불.

4. "천마총 = 일반 무덤": 1973년 발견 신라 매트릭스·완전한 형태.

5. "첨성대 = 일반 탑": 한국 #1 천문대 매트릭스·신라.

⚙ FAQ 6개

1. 외국인 입문 1순위: 불국사 + 석굴암 + 천마총 + 안압지 = 1일.

2. 불국사 + 석굴암: UNESCO 1995·외국인 매니아 매트릭스 #1.

3. 국립경주박물관: 무료·신라 매트릭스·영문 풀세트.

4. 부산 + 경주: KTX 30분·1박 매니아 매트릭스.

5. 시즌: 봄·가을 베스트.

6. 추천 페르소나: 가족·시니어 = UNESCO + 박물관 / MZ·인스타 = 안압지 야경 + 카페 / 매니아 = 1박 + 풀세트.
