只有釜山才有的三样 — 猪肉汤饭·小麦冷面·生鱼片,点餐方法一次讲清

副标题：首尔可以模仿出"釜山风味",但原版只在釜山。猪肉汤饭的浓白/清汤两大流派、和冷面完全不同的小麦冷面、市场生鱼片的醋辣酱文化 — 釜山三大招牌美食,配上餐桌上不慌乱的点餐流程一起整理。釜山地区指南10篇(#243~272)的美食总论篇。

ISSUE · #1320 · 2026-08-23

🎯 为什么是这三样

釜山旅行搜索里,一半都是"吃什么"。但现有的攻略按地区(海云台·札嘎其)分开写,食物本身的规则 — 有哪些流派、在餐桌上该怎么做 — 反而是散落的。这一篇把这套规则集中整理。本地策展账号收藏的釜山内容里,大多数也是美食信号,这和《黑白厨师》出演主厨们把釜山称为"当下的美食圣地"的趋势也重合(首尔版主厨巡礼见#1317)。

① 猪肉汤饭 (Dwaeji-gukbap / 돼지국밥) — 釜山的灵魂美食,先选流派

汤底分两种

连釜山市官方都有专门分类,是一套确立已久的区分:

  • 浓白汤(奶白风格) — 牛骨底汤,浓郁厚重。第一次吃的话,这种更接近"想象中的那个味道"。
  • 清汤(清爽风格) — 以肉汤为主,清爽。是解酒·早餐的路线。

餐桌流程(按外国游客最容易慌的顺序)

1. 虾酱 (Saeujeot / 새우젓) — 用它代替盐来调味,从半勺开始加。

2. 韭菜拌菜 (Jeongguji / 정구지) — 拌进汤饭里是标配,第一次先加一半试试。

3. 辣椒酱 (Dadagi / 다대기) — 用来调辣度,先尝一口原味汤再加。

4. 拌饭 — 如果不是"分开装" (ttaro-gukbap / 따로국밥),米饭其实已经泡在汤里了;想要米饭分开,点餐时说这个词就行。

5. 白切肉套餐 (Suyuk-baekban / 수육백반) = 汤饭 + 白切肉套餐。两人同行的话,点1份汤饭+1份白切肉套餐更划算。

去哪吃 — 已验证的锚点

  • 釜山站前一带:新昌汤饭 (Sinchang-gukbap / 신창국밥)·本田猪肉汤饭 (Bonjeon-dwaejigukbap / 본전돼지국밥) — 是KTX抵达后第一餐的最佳动线(与#1114 KTX两天三夜行程衔接)。
  • 朝坊前(凡一洞)汤饭一条街:陕川食堂 (Hapcheon-sikdang / 합천식당) 系列最有名 — 市场商人们分别称为"奶奶家"和"女儿家"的两家店并排开着,这条巷子本身就值得一逛。
  • 西面 (Seomyeon / 서면):很多汤饭店营业到深夜,是夜生活(#246)之后收尾的动线。

② 小麦冷面 (Milmyeon / 밀면) — 不是冷面

差别在哪

  • 面条:不是荞麦(冷面用),而是面粉+淀粉 — 更筋道、弹性更强。
  • 汤底:带中药材香气的清凉汤底 — 比冷面汤底更甜更浓。
  • 历史:朝鲜战争避难时期,人们在釜山用面粉复刻冷面而诞生的釜山本地美食。在首尔几乎吃不到。

点餐要点

  • 汤面 vs 拌面 — 第一次来建议点汤面(汤底才是它的灵魂)。
  • 加量给得比较大方,夏季旺季基本要排队。
  • 醋·芥末的用法和冷面一样,按个人口味添加。

去哪吃 — 已验证的锚点

  • 开琴小麦冷面 (Gaegeum-milmyeon / 개금밀면)(釜山镇区开琴洞,开琴市场入口) — 小麦冷面谱系的代表老店。经过翻新扩建后规模变大,很好找。
  • ⚠ 旧攻略里常出现的一些老店其实已经歇业或倒闭 — 这个品类出发前必须在地图App上确认是否还在营业。

③ 生鱼片 (Hoe / 회) — 市场吃法

  • 釜山生鱼片文化的核心是醋辣酱屋系统 (Chojang-jip / 초장집):在市场里现切生鱼片,再到楼上或附近的醋辣酱屋交摆桌费吃。#590 札嘎其12选里有各市场的具体动线。
  • 和首尔不同的地方:标配是醋辣椒酱·大酱·大蒜的组合,还有杂鱼生鱼片、鳗鱼、鲸鱼肉这类釜山特有的品类。
  • 广安里 (Gwangalli / 광안리)·民乐洞 (Millak-dong / 민락동) 生鱼片中心是海景 + 生鱼片的组合 — 是能和广安大桥夜景(#243)串在一起的晚间动线。

🗺 一日动线示例

时间 动线
早上 抵达釜山站 → 在新昌·本田一带吃猪肉汤饭(清汤,吃得清爽)
中午 在开琴或西面吃小麦冷面
晚上 札嘎其·民乐洞醋辣酱屋吃生鱼片 → 广安大桥夜景

各地区细节见sub-area系列10篇(#243~272),完整行程见#1021(1天)·#1114(两天三夜)。
