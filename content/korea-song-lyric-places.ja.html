歌の中のあの場所ガイド — 「クァンファムン ヨンガ」の徳寿宮・光化門、「ヨス パムバダ」の麗水、「トラワヨ プサンハンエ」のトンベクソム、「モクポエ ヌンムル」の儒達山まで20か所

サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「歌詞の中のあの場所」テーマで選ばれた場所のうち、観光公社に運営情報が登録された場所を地域別に選んだ20か所 · 歌と場所のつながりは投票の推薦理由に書かれた曲名が基準(歌詞は載せていません) · 入場料が登録された場所は徳寿宮(個人 1,000ウォン)と光化門の項目(成人 3,000ウォン) · 徳寿宮は月曜休み、光化門の項目の登録値は火曜休み · 七甲山は一部コースが規制(2026.10.20~12.15) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「歌詞の中のあの場所 (Gasa Sok Geugot / 가사 속 그곳)」テーマで選ばれた100か所のうち、韓国観光公社の観光情報に運営情報が登録された場所のうち20か所を扱います。表の順位と得票数は、その投票結果です。観光公社の情報がつながった場所すべてではなく、順位と地域の分布を考えて選びました。麗水 イ・スンシン広場・ソクチョン湖・海雲台・オリュクトなども投票に載りましたが、入れていません。

どの歌とつながるかは、投票の推薦理由に書かれた曲名と歌手名を写したものです。歌詞は著作権のため載せていません。観光公社の紹介にも歌が書かれている場所(キム・グァンソク タシクリギギル・ファゲジャント・儒達山・七甲山など)は、その事実を別に書きました。

運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。登録値がない欄は「登録値なし」と書きました。投票名簿の住所が観光公社の登録と違う場所は、本文に書きました。

📍 ソウル — 徳寿宮・光化門・マロニエ公園・清渓川・ソチョン マウル・仙遊島公園

徳寿宮、中区 (Jung-gu / 중구) セジョンデロ 99、☎ 02-771-9951は、1897年に宣布された大韓帝国の皇宮です。昔の名前はキョンウングン (Gyeongungung / 경운궁)で、伝統建築と西洋式の建築が一緒にあります。投票の推薦理由には、イ・ムンセ (Lee Moon-sae / 이문세)の「クァンファムン ヨンガ (광화문 연가)」に出てくる徳寿宮の石垣道とチョンドン教会 (Jeongdong Gyohoe / 정동교회)が挙げられています。

  • 開く時間: 09:00~21:00(入場締め切り 20:00)。ソクチョジョン (Seokjojeon / 석조전)・トンドンジョン (Dondeokjeon / 돈덕전)・チュンミョンジョン (Jungmyeongjeon / 중명전)の展示館は時間が別にあります。
  • 休み: 毎週月曜日(祝日・振替休日と重なると開き、その次の最初の非祝日に休みます)。料金: 個人 1,000ウォン。徳寿宮美術館は観覧券を別に買います。

光化門、鍾路区 (Jongno-gu / 종로구) サジクロ 161、☎ 02-3700-3901は、キョンボックン (Gyeongbokgung / 경복궁)の正門です。観光公社の紹介によると、基壇にアーチ形の門を三つ設けた、最も格式の高い宮殿の門で、2010年8月15日に復元工事を終えました。投票の推薦理由には、「クァンファムン ヨンガ」に登場するソウルの象徴と書かれています。投票名簿には、住所がヒョジャロ 12 国立古宮博物館 (Gungnip Gogung Bangmulgwan / 국립고궁박물관)として載っています。

  • 以下の時間・休み・料金は、観光公社の光化門の項目に登録された値です。門そのものがいつ開き、料金を取るかは登録値に別になく、料金欄には「詳しくは電話でお問い合わせください」が併記されています。
  • 開く時間: 1~2・11~12月 09:00~17:00, 3~5・9~10月 09:00~18:00, 6~8月 09:00~18:30。入場締め切りはそれぞれ1時間前です。
  • 休み: 毎週火曜日(祝日・振替休日と重なると開き、その次の最初の非祝日に休みます)。料金: 成人(満25~64歳)3,000ウォン、外国人(満19~64歳)3,000ウォン。駐車: 可能(約240台)。

マロニエ公園、鍾路区 テハンノ 104、☎ 02-2148-4158は、旧ソウル大学校の文理学部・法学部の跡地にある公園です。1929年に植えたマロニエの木から名前を取り、野外ステージで公演や文化行事が開かれます。投票の推薦理由には、歌「カクテル サラン (칵테일 사랑)」とつながる大学路の名所と書かれています。

  • 開く時間: 常時開放。休み: 年中無休。

清渓川、鍾路区 チャンシン洞 (Changsin-dong / 창신동)、☎ ソウル施設公団 (Seoul Siseol Gongdan / 서울시설공단) 02-2290-6114は、鍾路区と中区の間を流れる10.84㎞の河川です。2003年から2005年まで5.84㎞の区間を復元し、橋を22本架けました。投票の推薦理由には、RMのソロ曲「Seoul」に出てくる場所と書かれています。

  • 開く時間: 常時開放。雨が降ると安全のため出入りが規制されることがあります。休み: 年中無休。料金: 無料。

ソチョン マウル、鍾路区 ピルンデロ 45、☎ プクチョン マウル案内所 (Bukchon Maeul Annaeso / 북촌마을안내소) 02-2148-4161は、景福宮の西側の町を指す呼び名です。古い店と韓屋、路地の壁画があり、観光公社の紹介によると、映画・ドラマ・ミュージックビデオの撮影地として人気があります。投票の推薦理由には、IU (아이유)のアルバム「コッカルピ (꽃갈피)」の雰囲気が感じられる路地と書かれています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

仙遊島公園、永登浦区 (Yeongdeungpo-gu / 영등포구) ソニュロ 343、☎ 02-2631-9367~8は、1978年から2000年まで浄水場として使っていた島を2002年に生態公園に変えた場所です。コンクリートの柱だけを残した「緑色の柱の庭 (Noksaek Gidung-ui Jeongwon / 녹색기둥의 정원)」と、歩行者橋のソニュ橋 (Seonyugyo / 선유교)があります。投票の推薦理由には、RMのソロ曲「Seoul」に出てくる場所と書かれています。

  • 開く時間: 06:00~24:00。休み: 年中無休。料金: 無料。駐車: 不可能と登録。

📍 麗水 — 麗水海上ケーブルカー・突山大橋・ナンマンポチャ通り

投票の「歌詞の中のあの場所」テーマには、バスカー バスカー (Busker Busker / 버스커버스커)の「ヨス パムバダ (여수 밤바다)」を推薦理由に挙げた麗水の名所が複数載りました。

麗水海上ケーブルカー、麗水市 トルサン邑 (Dolsan-eup / 돌산읍) トルサンロ 3600-1は、海の上でトルサンとチャサン (Jasan / 자산)をつなぐケーブルカーです。観光公社の紹介によると、アジアで四番目に海の上を通る海上ケーブルカーで、床が強化ガラスのクリスタルキャビン15台と一般キャビン35台を運行しています。

  • 開く時間・休み・料金: 登録値なし。

突山大橋、麗水市 トルサン邑 トルサンロ 3617-7、☎ 麗水市庁 (Yeosusicheong / 여수시청) 1899-2012は、トルサンを陸地とつなぐ橋です。2000年10月から50色あまりを演出する景観照明を点けています。投票の推薦理由には、「ヨス パムバダ」と似合う夜景の名所と書かれています(歌手の記載はなし)。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

麗水 ナンマンポチャ通り、麗水市 ハメルロ 102は、コブクソン大橋 (Geobukseon Daegyo / 거북선대교)の下の広場にある屋台通りです。ポチャ18棟が営業し、麗水の夜景とバスキング公演を一緒に楽しめると紹介されています。

  • 開く時間・休み・料金: 登録値なし。

📍 島 — ヒョプチェ海水浴場・鬱陵島

📍 昔の歌のふるさと — キム・グァンソク タシクリギギル・ファゲジャント・サンジュ ウンモレビチ・儒達山・月出山・七甲山

キム・グァンソク タシクリギギル、大邱 中区 タルグボルデロ 2238、☎ 大邱観光情報センター (Daegu Gwangwang Jeongbo Senteo / 대구관광정보센터) 053-627-1337は、キム・グァンソク (Kim Gwang-seok / 김광석)が住んでいたテボン洞 (Daebong-dong / 대봉동)のパンチョン市場 (Bangcheon Sijang / 방천시장)の隣の路地に、彼の人生と音楽をテーマに飾った壁画通りです。観光公社の紹介によると、2010年に造成を始め、350mの壁面にキム・グァンソクの造形物と壁画があります。毎年秋に「キム・グァンソク歌唱コンテスト (Kim Gwang-seok Norae Bureugi Gyeongyeon Daehoe / 김광석 노래 부르기 경연대회)」が開かれます。投票名簿には、住所がテボン洞 6-11として載っています。

河東 ファゲジャント、河東郡 ファゲ面 (Hwagae-myeon / 화개면) サンゲロ 15、☎ 055-883-5722は、蟾津江とファゲ川が出会う場所の伝統市場です。観光公社の紹介によると、嶺南と湖南の人々が行き来した市場で、キム・ドンニ (Kim Dong-ni / 김동리)の小説「ヨンマ (역마)」の舞台であり、歌「ファゲジャント」としても広く知られました。2001年に再び開いた常設市場です。投票の推薦理由には、チョ・ヨンナム (Cho Yeong-nam / 조영남)の「ファゲジャント」が挙げられています。投票名簿には、住所がファゲ面 タプリ (Tap-ri / 탑리)として載っています。

  • 開く時間・休み: 店舗ごとに異なると登録されています。

南海 サンジュ ウンモレビチ、南海郡 サンジュ面 (Sangju-myeon / 상주면) サンジュロ 17、☎ 南海郡庁 海洋レジャーチーム (Namhae Gunchung Haeyang Rejeo Tim / 남해군청 해양레저팀) 055-860-3073は、クムサン (Geumsan / 금산)を屏風のように囲む2㎞の半月形の砂浜です。傾斜がなだらかで、夏のフェスティバルと冬の初日の出祭りが開かれます。投票の推薦理由には、トゥルダソッ (Dul Daseot / 둘다섯)の「パムベ (밤배)」の舞台と書かれています。投票名簿には、住所がサンジュロ 17-4として載っています。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 無料。シャワー室 大人 2,000ウォン。

木浦 儒達山、木浦市 チュッキョ洞 (Jukgyo-dong / 죽교동) 山27-3、☎ 061-270-8411は、ノリョン山脈の最後の峰として紹介された山です。東屋が五つあり、頂上から多島海が見えます。観光公社の紹介によると、山のふもとにイ・ナニョン (Lee Nan-young / 이난영)が歌った「モクポエ ヌンムル (목포의 눈물)」の記念碑があります。

青陽 七甲山道立公園、青陽郡 テチ面 (Daechi-myeon / 대치면) チャンゴッキル 241、☎ 041-940-2721は、海抜561mの山で、1973年に道立公園に指定されました。登山路が9つあり、ハンティ峠 (Hanti Gogae / 한티고개)からチャンゴクサ (Janggoksa / 장곡사)へ下るコースがいちばん多く訪れる道で、約3時間かかります。観光公社の紹介によると、チルガプ山荘 (Chilgapsanjang / 칠갑산장)一帯にチルガプサン歌碑 (Chilgapsan Norabi / 칠갑산노래비)があります。投票の推薦理由には、チュ・ビョンソン (Ju Byeong-seon / 주병선)の「チルガプサン (칠갑산)」が挙げられています。

  • 開く時間: 気象条件により出入りが規制されることがあります。
  • 休み: 一部コースが2026.10.20~12.15に規制されると登録されています。料金: 無料。駐車: 無料。

⚙ FAQ 3

Q. 「クァンファムン ヨンガ」とつながる場所は?

A. 徳寿宮(投票1位)と光化門(2位)です。投票の推薦理由には、徳寿宮の石垣道とチョンドン教会が一緒に挙げられています。

Q. 「ヨス パムバダ」の中の風景を見るには?

A. このガイドに載せた麗水の場所は、麗水海上ケーブルカー、突山大橋、麗水 ナンマンポチャ通りです。突山大橋は2000年から景観照明を点けています。

Q. 入場料がある場所は?

A. 入場料が登録された場所は、徳寿宮(個人 1,000ウォン)と光化門の項目(成人 3,000ウォン)です。麗水海上ケーブルカー・麗水 ナンマンポチャ通り・マロニエ公園・河東 ファゲジャント・南海 サンジュ ウンモレビチは、入場料の登録値がありません(サンジュ ウンモレビチはシャワー室の料金だけ登録)。
