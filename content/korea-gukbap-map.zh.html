韩国汤饭指南 — 雪浓汤、牛肉清汤、猪肉汤饭11家 — 以文雪浓汤 (Imun Seolnongtang / 이문설농탕)、河东馆 (Hadongwan / 하동관)、麻浦屋 (Mapo-ok / 마포옥)、玉东食 (Okdongsik / 옥동식)、陕川汤饭店 (Hapcheon Gukbapjip / 합천국밥집)，首尔·釜山 (2026年10月官方数据)

副标题：以文雪浓汤 (Imun Seolnongtang / 이문설농탕) 08:00开门、全年无休(VisitKorea)· 河东馆 (Hadongwan / 하동관) 1939年创业，周一至周六 07:00~16:00(米其林页面)· 麻浦屋 (Mapo-ok / 마포옥) 1949年创业，每天 07:00开门(米其林页面)· 首尔猪肉汤饭必比登推介2家(玉东食 (Okdongsik / 옥동식)、安岩 (Anam / 안암))· 釜山灶间 (Jeongjitgan / 정짓간) 24小时营业(VisitKorea)— 截至2026-10-21

ISSUE 03 · #477 · 2026-05-27

🎯 如何使用本指南

石锅(陶钵 (Ttukbaegi / 뚝배기))里热气升腾，滚烫的汤汁早已渗进饭粒之间 — 这就是"淋汤温饭"(Toryeom / 토렴)，把饭反复浇上热汤再倒出，让饭粒烫热(麻浦屋 (Mapo-ok / 마포옥)、合井屋 (Hapjeong-ok / 합정옥)、玉东食 (Okdongsik / 옥동식) 的米其林页面)。本指南只介绍把饭泡在汤里端上来的汤饭 (Gukbap / 국밥)。分四类：雪浓汤 (Seolleongtang / 설렁탕)·牛膝软骨汤 (Doganitang / 도가니탕)、牛肉清汤 (Gomtang / 곰탕)、首尔猪肉汤饭、釜山猪肉汤饭。整锅煮的炖菜和醒酒汤另归入 #486 炖锅与醒酒汤指南。店家只选了米其林指南官网和VisitKorea旅游信息上列出的，写给想一大早用一碗热汤开启一天的旅行者。

旧版指南把河东馆 (Hadongwan / 하동관) 写成"江南韩牛排骨汤"，但米其林页面上的河东馆是明洞的牛肉清汤店(中区明洞9街 (Myeongdong 9-gil / 명동9길) 12号)。"外国人人气排行"、"50年以上老店5大名店"、"刷卡率99%"这类说法没有出处，已删除。

🥣 雪浓汤·牛膝软骨汤 — 首尔3家

  • 以文雪浓汤 (Imun Seolnongtang / 이문설농탕) — 首尔钟路区友政局路 (Ujeongguk-ro / 우정국로) 38-13。周一至周六 08:00~21:00，周日 08:00~20:00，备料时间 15:00~16:30，全年无休，食材售完则提前打烊。招牌菜是雪浓汤 (Seolnongtang / 설농탕)，也有牛膝软骨汤 (Doganitang / 도가니탕)、牛头肉汤 (Meoritang / 머리탕)、白煮肉片 (Suyuk / 수육)。电话 02-733-6526(VisitKorea)。牛腿骨熬约17小时，并撇去浮油。米其林介绍它为"首尔市许可第1号"餐厅(米其林页面，无米其林推介、必比登标识)。创业年份两处说法不同：VisitKorea旅游信息写1907年，VisitKorea文章(2017年撰写)写1904年
  • 麻浦屋 (Mapo-ok / 마포옥) — 麻浦区土亭路 (Tojeong-ro / 토정로) 312。周一至周五 07:00~21:00，周六、周日 07:00~17:00。1949年创业。用牛腩、牛胸腹肉 (Chadol / 차돌) 和牛骨熬成清澈汤底，上面堆满牛腩。也推荐牛胸腹肉汤 (Chadoltang / 차돌탕)。电话 +82 2-716-6661，可刷卡(米其林页面，必比登推介)
  • 大成家 (Daeseongjip / 대성집) — 钟路区社稷路 (Sajik-ro / 사직로) 5。周一至周五 10:30~14:30·17:00~20:00，周六 10:30~14:00·17:00~19:00，周日休息。牛膝软骨 (Doga / 도가니)、牛筋 (Seuji / 스지)、牛腱 (Sat'ae / 사태) 盛在乳白色汤里端上。电话 +82 2-735-4259(米其林页面，必比登推介)
  • 价格：米其林页面上只有 ₩ 符号。2017年VisitKorea文章写以文雪浓汤 (Imun Seolnongtang / 이문설농탕) 的雪浓汤 (Seolleongtang / 설렁탕) 为9,000韩元，但现在的价格未能确认

🍲 牛肉清汤 — 首尔3家

  • 河东馆 (Hadongwan / 하동관) — 中区明洞9街 (Myeongdong 9-gil / 명동9길) 12。周一至周六 07:00~16:00，周日休息。1939年创业。汤里放牛腩、内脏 (Naepo / 내포) 和牛胃 (Yang / 양)，配首尔式萝卜块泡菜 (Kkakdugi / 깍두기)。先付款，早餐和午餐时要排队并拼桌。当天备的量卖完就关门。电话 +82 2-776-5656(米其林页面，无米其林推介、必比登标识)
  • 合井屋 (Hapjeong-ok / 합정옥) — 麻浦区杨花路1街 (Yanghwa-ro 1-gil / 양화로1길) 21，2楼。周一至周六 11:00~22:00，周日休息。每天只备约100人份的汤，卖完即打烊。牛肉清汤 (Gomtang / 곰탕)、白煮肉片 (Suyuk / 수육)、白菜心大酱汤 (Sokdaetguk / 속댓국)。电话 +82 2-322-4822(米其林页面，必比登推介)
  • 陵洞水芹 (Neungdong Minari / 능동미나리) — 龙山区汉江大路40街 (Hangang-daero 40-gil / 한강대로40길) 28。周一至周五 10:00~23:00，周六、周日 09:30~23:00。清澈的韩牛牛肉清汤 (Gomtang / 곰탕) 上放满水芹 (Minari / 미나리)。可通过Naver预约(米其林页面，必比登推介)

🐖 首尔猪肉汤饭 — 2家

  • 玉东食 (Okdongsik / 옥동식) — 麻浦区杨花路7街 (Yanghwa-ro 7-gil / 양화로7길) 44-10。周一至周五 11:00~15:00·17:00~22:00，周六、周日 11:00~20:30。用智异山黑猪 (Jirisan Heukdwaeji / 지리산 흑돼지) 前后腿肉熬出清澈汤底，配淋汤温饭 (Toryeom / 토렴) 的米饭和薄切肉片。约10个座位，每天限量100碗。吧台座位(米其林页面，必比登推介)
  • 安岩 (Anam / 안암) — 钟路区北村路5街 (Bukchon-ro 5-gil / 북촌로5길) 10。周一至周三 11:30~15:00·17:00~21:00，周四至周日 11:30~21:00。清澈汤底配青阳辣椒 (Cheongyang Gochu / 청양고추) 和羽衣甘蓝油，肉用西班牙杜洛克猪的肋排和颈肉。分量有"普通"和"多肉"，香菜可按需另加。吧台座位，可刷卡(米其林页面，必比登推介)

🌊 釜山猪肉汤饭 — 3家

  • 陕川汤饭店 (Hapcheon Gukbapjip / 합천국밥집) — 釜山南区龙湖路 (Yongho-ro / 용호로) 235。09:30~20:00，备料时间 14:00~14:30，全年无休。招牌菜是汤饭分开上的分盛汤饭 (Ttaro-gukbap / 따로국밥)，也有白煮肉套餐 (Suyuk Baekban / 수육백반)、混合肉分盛汤饭 (Seokkeo Ttaro-gukbap / 섞어따로국밥)(VisitKorea)。11:00~13:00不接待单人客。白煮肉 (Suyuk / 수육) 数量有限，去晚了会卖完(米其林页面，必比登推介)
  • 安木 (Anmok / 안목) — 釜山水营区广南路22街 (Gwangnam-ro 22beon-gil / 광남로22번길) 3。每天 11:00~21:00。米其林建议先尝汤，再加入辣酱 (Dadaegi / 다대기) 或腌虾 (Saeujeot / 새우젓)。被介绍为适合一个人吃饭的地方。吧台座位(米其林页面，必比登推介)
  • 灶间 (Jeongjitgan / 정짓간) 新平总店 — 釜山沙下区飞凤路 (Bibong-ro / 비봉로) 6，1楼。24小时营业，"周二12点结束营业"(照原文标注 — 是中午还是午夜请电话确认)，全年无休。除猪肉汤饭外还有血肠汤饭 (Sundae-gukbap / 순대국밥)、内脏汤饭 (Naejang-gukbap / 내장국밥)(VisitKorea)。2011年创业，可通过Naver预约(米其林页面，必比登推介)。米其林页面按星期列出的营业时间空白很多，因此这里写的是VisitKorea的数据
  • 釜山美食总览见 #1320 只在釜山吃的三样

🥗 饮食

  • 价格区间：本指南的11家在米其林页面上价格符号全部是 ₩(最低一档)。没有官方公布的韩元金额 — 2017年VisitKorea文章的数据(以文雪浓汤 (Imun Seolnongtang / 이문설농탕) 9,000韩元、河东馆 (Hadongwan / 하동관) 12,000韩元)并非现价
  • 素食：汤饭的汤底用牛骨、牛肉(雪浓汤、牛肉清汤)或猪肉(猪肉汤饭)熬成(各家米其林页面)。可以认为没有能换成素汤底的店。VisitKorea写道，泡菜的调料也大多含有腌制海鲜、鱼露或肉汤
  • 清真：VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00)是少数获韩国伊斯兰教中央会 (KMF) 认证为清真的餐厅之一。本指南里的汤饭店没有清真标识，猪肉汤饭本身就是猪肉料理
  • 过敏：牛肉清汤、雪浓汤里可能混有牛胃 (Yang / 양)、内脏 (Naepo / 내포) 等杂碎(河东馆 (Hadongwan / 하동관)、大成家 (Daeseongjip / 대성집) 的米其林页面)— 请提前说明不要放
  • 出示用的卡片见 #1300 饮食需求手册

🧰 汤饭实用信息 — 独自用餐、预约、付款、点餐、交通

  • 独自用餐：汤饭是一人一碗，很适合一个人去。不过陕川汤饭店 (Hapcheon Gukbapjip / 합천국밥집) 在 11:00~13:00不接待单人客(米其林页面)。单人用餐地图见 #348 Seoul Solo Diner Map
  • 预约：大部分店不用预约，直接排队。开放Naver预约的是陵洞水芹 (Neungdong Minari / 능동미나리) 和灶间 (Jeongjitgan / 정짓간)(米其林页面)
  • 付款：河东馆 (Hadongwan / 하동관) 先付款(米其林页面)。刷卡和移动支付见 #527 韩国支付系统
  • 点餐：像河东馆 (Hadongwan / 하동관)、合井屋 (Hapjeong-ok / 합정옥) 这样备料用完就早关门的店，午饭前去。语言不通时见 #1339 点餐礼仪
  • 交通：首尔地铁和公交见 #1298 三种交通卡怎么选，釜山见 #1325 釜山公共交通语法

⚠ 常见的4个误区

1. "河东馆是江南排骨汤店" — 米其林页面上的河东馆 (Hadongwan / 하동관) 是明洞的牛肉清汤店。周日休息，16:00打烊

2. "老字号汤饭店营业到深夜" — 河东馆 (Hadongwan / 하동관) 16:00、大成家 (Daeseongjip / 대성집) 周六19:00、麻浦屋 (Mapo-ok / 마포옥) 周末17:00打烊(米其林页面)。深夜喝汤饭，大概只有24小时营业的釜山灶间 (Jeongjitgan / 정짓간)(VisitKorea)

3. "猪肉汤饭只有釜山有" — 首尔也有两家米其林必比登推介的猪肉汤饭店(玉东食 (Okdongsik / 옥동식)、安岩 (Anam / 안암))

4. "汤饭价格到处一样" — 没有官方公布的价格。点餐前先拍下菜单
