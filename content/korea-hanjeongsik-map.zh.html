韩国韩定食指南 — 首尔米其林韩餐套餐3家（明格斯·罗宴·温知音）·全州韩定食·安东虚祭饭·寺院饮食（2026年10月官方数据）

🎯 如何使用这份指南

小碟一个接一个摆上桌，不知不觉就摆满了整张桌子——在全州，一桌能上30多种小菜（VisitKorea）。本指南把韩定食分成四类：首尔米其林韩餐套餐3家（明格斯·罗宴·温知音）、全州韩定食、安东虚祭饭、寺院饮食。星级、地址、营业时间只写在米其林指南首尔&釜山2026，以及VisitKorea、全州市、国家遗产厅官方页面上读到的内容；价格或时间没有公布的地方，我们就如实写明没有公布。这份指南写给想认真吃一次韩国套餐料理的人，以及愿意为全州、安东这类首尔以外的地方专门留出一天的人。

旧版指南中的“韩国第一”、价格区间（罗宴每人30~50万韩元等）和“一个月”都没有出处。“善哉法师 = Chef's Table”是错的（出演者是白羊寺正观法师，VisitKorea）；被指定为国家非物质遗产的也不是真宽寺的寺院饮食，而是真宽寺水陆斋（佛教仪式，2013年指定，国家遗产厅）。

🍽 首尔 — 米其林2026韩餐套餐3家

以下为米其林指南首尔&釜山2026官方页面的内容（2026-10-07查阅）。全部16家见 #1109 Seoul Michelin Guide 2026。

  • 明格斯 (Mingles / 밍글스) — 3星（连续两年，首尔唯一）。地址：Seoul Gangnam-gu Dosan-daero 67-gil 19, 2F。主厨姜敏求（Kang Mingoo）。午餐周二至周六 12:00~15:00，周一、周日休息（米其林页面，晚餐请查官方网站）。预订请通过官方网站 restaurant-mingles.com 或电话 +82-2-515-7306。可刷卡
  • 罗宴 (La Yeon / 라연) — 2星。地址：Seoul Jung-gu Dongho-ro 249, 新罗酒店23层。午餐每天 12:00~14:30（米其林页面）。预订请通过新罗酒店官方网站、Naver预约或电话 +82-2-2230-3367。可轮椅进入
  • 温知音 (Onjium / 온지음) — 1星。地址：Seoul Jongno-gu Hyoja-ro 49, 4F。以传统与现代手法重新诠释朝鲜宫廷料理。午餐周二至周五 12:00~15:00（米其林页面）。预订请打电话 +82-2-6952-0024。米其林页面标注“仅限现金”
  • 三家的价格都只有米其林的₩₩₩₩符号——韩元金额请在预订时确认

🍚 全州韩定食

  • 是什么：一桌上30多种小菜，由全州乡吏们享用的“白饭大桌”商业化后逐渐成形（VisitKorea）
  • 联合国教科文组织：全州于2012年成为教科文组织创意城市网络美食类成员（unesco.org）
  • 韩定食店3家（VisitKorea 文章收录）：翰碧楼 (Hanbyeokru / 한벽루) 063-280-7003（Wansan-gu Jeonjucheon-dong-ro）· 宫 (Gung / 궁) 063-227-0844（Wansan-gu Eunhaeng-ro）· 全罗会馆 (Jeolla Hoegwan / 전라회관) 063-228-3033（Wansan-gu Anhaeng 4-gil）。文章里没有详细地址、营业时间和价格——请打电话确认
  • 拌饭（全州市官方旅游网站收录）：校洞排骨 (Gyodong Seokgalbi)（Taejo-ro 26）· 满月 (Manwol)（Choe Myeonghui-gil 3，生牛肉拌饭）· 丰南门拌饭 (Pungnammun Bibimbap)（Pungnammun 2-gil 53）· 大锅 (Keungamasot)（Nosong Gwangjang-ro 46）。营业时间、价格未公布
  • 交通：首尔→全州 KTX 所需时间没能打开官方数据——请在 Korail 应用中查询。全州一日路线见 #384 Jeonju Travel Map

🐟 安东虚祭饭

  • 是什么：由祖先祭祀食物衍生出的安东乡土饮食。安东人为了找个借口吃好吃的，给它起名叫“假祭祀食物”。米饭配萝卜、豆腐、肉汤和烤青花鱼等（VisitKorea）
  • 虚祭饭 喜鹊洞屋 (Kkachigumeong-jip / 까치구멍집)：Gyeongbuk Andong-si Seokju-ro 203，11:00~20:00，春节、中秋当天休息（VisitKorea）。价格未公布
  • 虚祭饭 味50年 (Mat 50 Nyeon / 맛50년)：Gyeongbuk Andong-si Seokju-ro 201，11:00~20:00，春节、中秋当天休息（VisitKorea）。价格未公布
  • 顺路可去：河回村和良洞村历史村落于2010年列入联合国教科文组织世界遗产（国家遗产厅英文页面）

🪷 寺院饮食

  • 是什么：从佛教寺院传下来的饮食传统（VisitKorea）。白羊寺 (Baekyangsa / 백양사) 的正观法师是获得詹姆斯·比尔德奖的寺院饮食大师，曾出演Netflix的《Chef's Table》（2017）（VisitKorea）
  • 韩国寺院饮食中心 (Korea Temple Food Center / 한국사찰음식센터)：VisitKorea写的是 Jongno-gu Yulgok-ro 39 安国大厦2层，而中心官方网站（koreatemplefood.com）写的是 Jongno-gu Ujeongguk-ro 56，两处地址不同——去之前请打电话 02-733-4650 确认。没有公布日常营业时间，课程按场次预约
  • 真宽寺 (Jingwansa / 진관사)：Seoul Eunpyeong-gu Jingwan-gil 73，09:00~18:00，全年无休（VisitKorea）。被指定为国家非物质遗产的是“真宽寺水陆斋”（佛教仪式，2013-12-31指定，国家遗产厅）

🥗 饮食需求

  • 价格区间：这份指南里没有官方公布的韩元价格。米其林3家只有₩₩₩₩符号，全州、安东的收录页面上没有价格栏
  • 素食：白菜泡菜的调味料大多放了咸鱼酱或鱼露（VisitKorea）——韩定食桌上的泡菜和凉拌菜点餐前也要问清楚。寺院饮食的食材请在预订时确认
  • 清真：VisitSeoul介绍梨泰院的Eid (Eid / 이드)是少数获韩国伊斯兰教中央会(KMF)认可的清真餐厅之一(龙山区 Usadan-ro 10-gil 15号，每天12:00–21:00)。认证可能变更，前往前请先确认。这份指南里的韩定食店都没有清真标示
  • 出示用的卡片见 #1300 饮食需求手册

🧰 韩定食实用信息 — 一个人、预订、支付、点餐、交通

  • 一个人：有的店可能要2人以上才接韩定食的桌——请先打电话问。适合一个人坐的餐厅地图见 #348 Seoul Solo Diner Map
  • 预订：在海外，打电话或找酒店礼宾部最稳妥。Catch Table是韩国应用，用海外号码能否注册我们没能确认（#1109）
  • 支付：米其林页面上温知音标注“仅限现金”，明格斯可刷卡——刷卡和移动支付见 #527 韩国支付系统·#431 支付·SIM地图
  • 点餐：加小菜和水免费，没有小费（VisitKorea）——语言不通时见 #1339 点餐礼仪
  • 交通：去全州、安东，也请一并看 #1297 高速·城际巴士手册。交通卡见 #1298 三种交通卡怎么选

⚠ 常见的4个错误

1. “善哉法师出演了Chef's Table” — 出演者是白羊寺正观法师（VisitKorea）。善哉法师是另一位

2. “真宽寺寺院饮食是国家非物质文化遗产” — 被指定的是真宽寺水陆斋这一佛教仪式（国家遗产厅）

3. “周一中午去米其林韩餐” — 明格斯周一、周日休息，温知音午餐是周二至周五。周一请选每天都供应午餐的罗宴

4. “米其林韩餐厅的价格是公开的” — 米其林页面上只有₩₩₩₩符号。金额请在预订时询问
