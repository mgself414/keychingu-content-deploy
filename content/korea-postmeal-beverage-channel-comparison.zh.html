🎯 各类游客首选推荐

👤 单人旅行者(Solo)

  • 首选：超市·便利店(24小时·高性价比·单罐即可)
  • 第二选择：MZ咖啡厅(适合单人拍照)
  • 第三选择：家常菜午餐(单人甜品)
  • 不推荐：韩定食(单人吃略显正式感不足)

💑 情侣(Couple)

  • 首选：韩定食收尾(正宗约会收尾)
  • 第二选择：MZ咖啡厅(甜米露创意款约会)
  • 第三选择：家常菜(高性价比约会)
  • 不推荐：超市(氛围感不足)

👨‍👩‍👧 家庭(Family)

  • 首选：家常菜甜品(家庭首选·家常风味)
  • 第二选择：韩定食收尾(正宗家庭聚餐)
  • 第三选择：超市(家庭高性价比)
  • 不推荐：MZ咖啡厅(不太适合家庭时光)

🎨 MZ潮流(MZ)

  • 首选：MZ咖啡厅(#1潮流·拍照热门)
  • 第二选择：韩定食(#1正宗拍照)
  • 第三选择：超市(便利店高性价比)
  • 不推荐：家常菜(不太MZ)

🎒 背包客·预算型(Budget)

  • 首选：超市·便利店(#1高性价比·24小时)
  • 第二选择：家常菜(免费甜品)
  • 第三选择：韩定食午餐(免费)
  • 不推荐：MZ咖啡厅(预算偏高)

🍱 4大场所深度解析

🍱 韩定食收尾 (Hanjeongsik Final Drinks)

核心价值：6道套餐的最后一道 + 甜米露·水正果免费，No.1。

  • 推荐去处：
  • 新罗酒店罗宴 (La Yeon / 라연)(米其林三星)——正宗
  • 三清阁 (Samcheonggak / 삼청각)、仁寺洞 (Insadong / 인사동) 韩定食餐厅——正宗
  • 参考价格：韩定食套餐内含免费(全套40,000~150,000韩元，约211~790元人民币)
  • 营业时间：11:30~22:00
  • 外国游客友好度：★★★★

🍚 家常菜甜品 (Home-style Post-meal)

核心价值：家常免费甜品 + 甜米露·梅子茶 + 亲子友好。

  • 推荐去处：
  • 钟路 (Jongno / 종로)、江南 (Gangnam / 강남)、明洞 (Myeongdong / 명동) 白饭套餐店 (baekban-jip / 백반집，韩式家常套餐店)——高性价比
  • 韩笥 (Hansot / 한솥)、本便当 (Bon Dosirak / 본도시락)(便当连锁店)——高性价比([详见#854](#854))
  • 参考价格：家常白饭套餐内含免费(8,000~15,000韩元，约42~79元人民币)
  • 营业时间：11:00~22:00
  • 外国游客友好度：★★★★(高性价比)

☕ MZ咖啡厅·潮流 (MZ Cafe Trend)

核心价值：MZ潮流·甜米露创意款·梅子气泡饮·东东酒热潮。

  • 推荐去处：
  • MZ韩式咖啡厅(圣水 (Seongsu / 성수)、弘大 (Hongdae / 홍대)、江南)——潮流
  • 传统茶馆(北村 (Bukchon / 북촌)、仁寺洞)——正宗+MZ
  • 参考价格：5,000~10,000韩元(约26~53元人民币)/杯
  • 营业时间：10:00~22:00
  • 外国游客友好度：★★★★★(MZ·英文·拍照)

🛒 超市·便利店 (Mart·Convenience Store)

核心价值：24小时可及 + 罐装瓶装高性价比No.1。

  • 推荐去处：
  • 便利店(CU、GS25、7-Eleven (세븐일레븐)、Emart24 (이마트24))——24小时
  • E-mart (이마트)、乐天玛特 (Lotte Mart / 롯데마트)、Homeplus (홈플러스)——大型超市
  • 参考价格：2,000~7,000韩元(约11~37元人民币)/罐或瓶
  • 营业时间：24小时(便利店)
  • 外国游客友好度：★★★★★(24h·罐装·英文)

⚠ 外国游客常见的5个误区

1. "4大场所差不多"：价格·粉丝群·潮流度完全不同。免费=韩定食·家常菜 / 潮流=MZ / 24h=超市。

2. "韩定食·家常菜的饮品要收费"：韩定食·家常菜的收尾饮品 = 免费内含。

3. "MZ咖啡厅只有茶"：MZ咖啡厅 = 甜米露创意款·梅子气泡饮(潮流饮品)。

4. "超市选择单一"：超市·便利店 = 24小时可及·高性价比·12种以上选择。

5. "东东酒是咖啡厅饮品"：东东酒 = 6~8%酒精度的酒，MZ咖啡厅也作为酒精饮品供应。

⚙ 常见问题8则

1. 首选收尾饮品场所：韩定食套餐最后一道(#1免费) → 超市(高性价比)。

2. 拍照·vlog推荐：韩定食甜米露(#1)·MZ咖啡厅甜米露创意款。

3. MZ潮流：MZ咖啡厅(#1)甜米露创意款·梅子气泡饮。

4. 助消化·醒酒：梅子茶(超市·家常菜)。

5. 酒精·孕妇：东东酒 = 孕妇、司机不宜。

6. 过敏·孕妇：详见[#870过敏提示](#870)。

7. 付款·小费：可刷卡 / 无需小费。

8. 退税：餐饮一般不在退税范围内。

⚠ 医疗·安全·饮食注意事项

4大餐后收尾饮品场所均属日常饮食。孕妇、儿童 = 甜米露、水正果、梅子茶没问题(东东酒 = 不可以，含酒精)。请提前告知过敏情况(松子、姜)。如怀疑食物中毒，请拨打 ☎ 1339(医疗热线，提供英语服务)。本指南仅为一般信息，不构成医疗建议。

饮食限制应对方案：

  • 清真·犹太洁食：甜米露、水正果、梅子茶 = 没问题 / 东东酒 = 不可以，含酒精。
  • 素食·纯素：5种可素食。
  • 无麸质：6种都没问题。
