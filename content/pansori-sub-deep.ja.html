📍 高敞 — 申在孝パンソリ博物館・申在孝古宅・申在孝パンソリ公園

高敞 申在孝パンソリ博物館 (Gochang Sinjaehyo Pansori Bangmulgwan / 고창 신재효판소리박물관) (高敞郡 高敞邑 Dongni-ro 100 (동리로 100)、☎ 063-560-8061) は、パンソリの理論家であり改作者、後援者でもあった桐里 申在孝(シン・ジェヒョ)と、チン・チェソン (Jin Chaeseon / 진채선)、キム・ソヒ (Gim Sohui / 김소희) ら多くの名唱を記念する博物館です。申在孝の古宅の跡地に建てられ、高敞市外バスターミナルから500mの距離にあります。円形の展示室「名誉の殿堂 (Myeongyeui Jeondang / 명예의 전당)」には、名唱たちの写真パネルがあります。パンソリの芸術世界を再構成して見るソリマダン (Sorimadang / 소리마당)、申在孝と高敞の唱い手たちを紹介するアニリマダン (Anirimadang / 아니리마당)、デジタル映像でパンソリを体験するホンマダン (Honmadang / 혼마당) があります。

  • 開く時間: 夏季 09:00~18:00、冬季 09:00~17:00。入場は閉館の30分前まで。休み: 毎週月曜日、1月1日、旧正月・秋夕の当日。
  • 料金: 無料。

高敞 申在孝古宅 (Gochang Sinjaehyo Gotaek / 고창신재효고택) (同じ住所、☎ 高敞邑城 観光案内所 063-560-8055) は、パンソリを集大成した申在孝(1812~1884)が住んでいた家です。観光公社の紹介によると、哲宗1年(1850)に建てられたと推定され、光武3年(1899)に息子が建て直したとされています。もとは質素な草葺きのサランチェ (Sarangchae / 사랑채) で、国家民俗文化遺産に指定されるまで高敞警察署の付属建物として使われ、その後は国が管理して昔の姿を復元しました。正面6間、側面2間の「一」字形の草葺きの家で、台所1間、部屋2間、大庁1間、統合された部屋1間でできています。

  • 開く時間: 09:00~18:00。休み: 年中無休。
  • 駐車: できます。

申在孝パンソリ公園 (Sinjaehyo Pansori Gongwon / 신재효판소리공원) (高敞郡 高敞邑 Jung-georidangsan-ro 148 (중거리당산로 148)、☎ 063-560-8035) は、高敞邑城の城壁沿いの道のそばにつくられたパンソリの空間です。高敞の衙前 (Ajeon / 아전) 出身でパンソリを集大成した申在孝を記憶する場所で、韓屋3棟、延べ面積614㎡の規模です。パンソリの教育と体験のためのセミナー室、パンソリ体験室、パンソリ得音室、野外公演場があります。

  • 開く時間: 09:00~17:00(休憩時間 12:00~13:00)。休み: 毎週土曜日~日曜日。
  • 体験: パンソリアカデミーで、パンソリ専攻の教授による理論講義と、名唱によるパンソリの伝承教育を受けられます。10人以上なら事前に公演を申し込むことができ、パンソリの解説・鑑賞・一場面を習うプログラムがあります。観光公社の紹介によると、週末の野外広場では観覧客と研修生がともに行う公演も開かれます。登録されている休みは土曜日~日曜日です。
  • 駐車: できます。

📍 東便制 — 求礼 東便制パンソリ伝授館・南原 東便制テッジャリ

東便制パンソリ伝授館 (Dongpyeonje Pansori Jeonsugwan / 동편제 판소리전수관) (求礼郡 求礼邑 Dongpyeonje-gil 53 (동편제길 53)、☎ 061-782-6868) は、求礼出身の東便制の名唱 宋万甲(ソン・マンガプ)を称えてパンソリの人材を育てるため、2000年に求礼邑 白蓮里 (Baengnyeon-ri / 백련리) の宋万甲の生家一帯に建てられた伝授館です。パンソリは、蟾津江を中心に東便制と西便制に分かれます。観光公社の紹介によると、求礼の唱は旧韓末の国唱 (Gukchang / 국창) 宋万甲を頂点として、東便制パンソリの原型を保存しています。パンソリの伝授教育と国楽教室を運営し、名唱 宋万甲追慕 全国パンソリ競演大会を開きます。近くに、2001年11月3日に開館した東便制パンソリ記念館、宋万甲の生家、名唱 宋万甲・パク・ボンネ (Bak Bongnae / 박봉래)・パク・ボンスル (Bak Bongsul / 박봉술) の追慕碑があります。

  • 開く時間: 常時開放。休み: 年中無休。
  • 料金: 無料。駐車: 無料。ペット: 不可。

東便制テッジャリ(生誕の地) (Dongpyeonje Taetjari / 동편제탯자리) (南原市 雲峰邑 Bijeon-gil 7 (비전길 7)、☎ 063-634-7535) は、東便制パンソリを創始した歌王 宋興禄(ソン・フンノク)が生まれた雲峰邑 ピジョン村 (Bijeon Maeul / 비전마을) です。女流名唱 パク・チョウォル (Bak Chowol / 박초월) の唱の故郷でもあります。宋興禄は、民俗音楽のなかで最もゆっくりとしたチニャンジョ (Jinyangjo / 진양조) をパンソリに応用してパンソリの表現領域を広げました。「春香歌」の獄中歌のクィゴクソン (Gwigokseong / 귀곡성)(幽霊の泣き声)は、彼が創作した唱法として認められています。東便制は、弟のソン・グァンノク (Song Gwangnok / 송광록) と孫の宋万甲が受け継ぎました。2000年からピジョン村に国楽の聖地がつくられ、宋興禄の生家とパク・チョウォルの古宅が復元されました。

  • 開く時間: 09:00~18:00。休み: 年中無休。

📍 西便制 — 宝城 パンソリの聖地

パンソリの聖地 (Pansori Seongji / 판소리성지) (宝城郡 会泉面 Yeongcheon-gil 17-8 (영천길 17-8)、☎ 061-852-5206) は、西便制を創始した朝鮮時代の名唱 江山 朴裕全(パク・ユジョン)と、チョン・ジェグン (Jeong Jaegeun / 정재근)・チョン・ウンミン (Jeong Eungmin / 정응민)・チョ・サンヒョン (Jo Sanghyeon / 조상현) ら西便制の系譜を受け継いだ名唱たちを称える場所です。会泉面 Yeongcheon-ri (영천리) トガン村 (Dogang Maeul / 도강마을) 一帯に、朴裕全の記念碑、チョン・ウンミンの生家、得音亭 (Deugeumjeong / 득음정) があります。朴裕全は全北 淳昌で生まれ、1852年に宝城の江山村に移って西便制を創始し、その後、東便制と西便制の長所を調和させた江山制 (Gangsanje / 강산제) もつくりました。パンソリ体験教室と教育プログラムを運営しています。

  • 開く時間: 09:00~18:00。9~12月には毎週土曜日 14:00に土曜常設公演が開かれます。休み: 毎週月曜日。
  • 団体: 30人以上の団体観覧客は、名唱によるパンソリ・民謡の公演を無料で見られます。

📍 公州 — 朴東鎮パンソリ伝授館

朴東鎮パンソリ伝授館 (Bak Dongjin Pansori Jeonsugwan / 박동진판소리전수관) (公州市 Mureung Jungmal-gil 22-14 (무릉중말길 22-14)、☎ 041-858-0045) は、国家無形文化遺産 赤壁歌の芸能保有者 朴東鎮(パク・トンジン)の出生地である公州 武陵洞 (Mureung-dong / 무릉동) に建てられた伝授館です。パンソリ5演目と聖書パンソリ、短歌 (Danga / 단가)、南道民謡を教え、名唱の養成とともに、市民向けのパンソリ体験と文化教育を運営しています。

  • 開く時間: 09:00~18:00。休み: 毎週日曜日~月曜日、祝日、旧正月・秋夕の連休。
  • 料金: 無料。

⚠ 事前に知っておきたい3つのこと

  1. 休みの日がまちまち — 申在孝パンソリ公園は土曜日~日曜日、朴東鎮パンソリ伝授館は日曜日~月曜日、申在孝パンソリ博物館とパンソリの聖地は月曜日に休みます。高敞 申在孝古宅、東便制パンソリ伝授館、東便制テッジャリは年中無休です。
  2. 高敞の3か所は高敞邑城文化体験通りに集まっている — 申在孝パンソリ博物館と高敞 申在孝古宅は住所が同じで、申在孝パンソリ公園は高敞邑城の城壁沿いの道のそばにあります。
  3. 宝城の土曜常設公演は9~12月だけ — 毎週土曜日 14:00です。

⚙ FAQ 2

Q. パンソリの公演を見られる場所は?

A. 観光公社の登録情報では、宝城 パンソリの聖地の土曜常設公演(9~12月 毎週土曜日 14:00)です。申在孝パンソリ公園は10人以上なら事前に公演を申し込むことができ、パンソリの聖地は30人以上の団体に公演を無料で見せています。

Q. パンソリを実際に習える場所は?

A. 申在孝パンソリ公園(パンソリアカデミー、パンソリの一場面を習う)、朴東鎮パンソリ伝授館(市民向けパンソリ体験)、パンソリの聖地(パンソリ体験教室)、東便制パンソリ伝授館(国楽教室)です。
