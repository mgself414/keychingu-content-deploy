パンソリガイド — 外国人が2026年の秋・冬に実際に観られる公演と五つの演目 (公式日程)

🎯 このガイドの使い方

パンソリ (Pansori / 판소리) は、歌い手(ソリクン)が一人で 鼓手 (Gosu / 고수)(太鼓の奏者)一人とともに、何時間も続けて歌う物語音楽です。一つの演目を最後まで歌い通す 完唱 (Wanchang / 완창) は、歌い手と演目によって3~8時間(今回確認した公演は170分・300分)、舞台劇に仕立てた 唱劇 (Changgeuk / 창극) はふつう2時間前後です。外国人が「パンソリを観る」なら、現実的には次の三つのどれかです — ① 国立国楽院 (Gungnip Gugagwon / 국립국악원) の 土曜名品 (Toyo Myeongpum / 토요명품)(毎週土曜日、パンソリだけでなく国楽の総合公演) ② 国立劇場 (Gungnip Geukjang / 국립극장) の完唱パンソリ・唱劇 ③ ソウル敦化門国楽堂 (Seoul Donhwamun Gugakdang / 서울돈화문국악당) と ソウル南山国楽堂 (Seoul Namsan Gugakdang / 서울남산국악당) の単発公演。以下の日程・料金・住所は、2026-10-07に各公式サイトで読み取った値だけを記載しています。英語字幕は、どの公式ページにも表記がないため未確認です。以前のガイドにあった「国立国楽院で毎週パンソリ・EN/JP字幕・5千~5万ウォン」「秋は全国でパンソリ祭りが最盛期」「韓国の家(ハングゥギチプ)10万~30万ウォン」は、出典がないか誤りだったため削除しました。

🏛 公演会場4カ所

国立国楽院 — 土曜名品

  • 瑞草区 南部循環路 2364。3号線の 南部ターミナル駅 (Nambu Terminal / 남부터미널역) から歩きます(出口番号は公式に未確認)。
  • 土曜名品: 2026-01-03~12-26の毎週土曜日 15:00~16:20、ウミョン堂。A席 30,000・B席 20,000ウォン。パンソリの一場面が入る回はありますが、パンソリだけの公演ではありません — 回ごとのプログラムは公式ページで確認してください。

国立劇場 — 完唱パンソリ・唱劇

  • 中区 チャンチュンダン路 59。3号線 東大入口駅 (Dongdaeipgu / 동대입구역) 6番出口からシャトル(公演の1時間前~20分前、10~15分間隔)または徒歩10~15分(公式)。
  • 完唱パンソリ: 一人の名唱が一つの演目を最後まで。10/24 イ・グァンボク 興甫歌(170分)、11/14 ソ・ジンヒ 沈清歌(300分)、各20,000ウォン、タロルム劇場。
  • 唱劇: 国立唱劇団の舞台劇。11/26~12/5『オイディプス』(50,000/35,000/20,000ウォン)。12/26 年末パンソリ『ソリジョンダム』30,000ウォン。

ソウル敦化門国楽堂

  • 鍾路区 栗谷路 102(昌徳宮 敦化門の前)。10/25 ナ・ユニョン マンジョン制 春香歌。料金・アクセスは公式ページに未掲示 — 予約ページで確認してください。

ソウル南山国楽堂

  • 中区 退渓路34ギル 28(南山谷ハノク村の中)。10/10~11 チャンダンユヒ フェスティバル。そのほかのパンソリ単独の日程は、10/7時点で公式ページから読み取れませんでした。

全州 — 国立無形遺産院・ソリ祭り

  • 国立無形遺産院 (Gungnip Muhyeong Yusanwon / 국립무형유산원)(全州)の公演プログラムは、公式ページから読み取れませんでした。全州世界ソリ祭り2026は8/12~16で終了しており(パンソリ五演目・若手パンソリ五演目の編成)、2027年の日程は上半期の発表を待ちます。

🎼 五つの演目 — 何を聴くことになるか

演目 物語を一行で 初めて観る外国人には
春香歌 (Chunhyangga / 춘향가) 妓生の娘・春香と両班・李夢龍の恋、卞学道の無理な要求と暗行御史 いちばん一般的。唱劇としてもよく上演される
沈清歌 (Simcheongga / 심청가) 目の見えない父のために海に身を投げた沈清 悲しい場面が長い — 11/14の完唱は300分
興甫歌 (Heungboga / 흥보가) 貧しい興甫と欲深い兄・ノルボ、ツバメの恩返し 笑いが多く最初に向いている — 10/24の完唱は170分
水宮歌 (Sugungga / 수궁가) 竜王の病を治すため、ウサギの肝を求めに行ったスッポン 動物の風刺、子どもと一緒に
赤壁歌 (Jeokbyeokga / 적벽가) 三国志の赤壁の戦いをパンソリで 男性的で語りが長い、マニア向け
  • 長さは演目や歌い手ごとに違います。以前のガイドにあった「春香歌 約8時間」のような固定の数値は記載しません。

🗣 言語・字幕

  • どの会場も、公式ページに英語字幕の有無を記載していません(未確認)。唱劇は字幕画面を使うことが多いですが、公演ごとに予約ページで確認してください。
  • パンソリは、語り(歌詞)が聞き取れなくても、歌い手の表情や鼓手の掛け声(合いの手)で追えます — 興甫歌のように笑いの多い演目から始めましょう。

⚠ よくある失敗5つ

1. 土曜名品をパンソリ公演だと思い込む — 国楽の総合公演です。パンソリだけを観るなら国立劇場の完唱へ。

2. 完唱を2時間ほどだと思い込む — 170~300分です。途中休憩や離席のルールは会場で確認しましょう。

3. 秋の全州ソリ祭りを狙う — 2026年は8月に終わりました。

4. 東大入口駅から歩いて上る — 6番出口にシャトルがあります。

5. 英語字幕があるのは当然と考える — 公式には未表記です。予約前に確認しましょう。

⚙ FAQ 6

1. 初めてなら? — 10/24 国立劇場の完唱 興甫歌(170分、20,000ウォン)または唱劇『オイディプス』(11/26~)。

2. 短くさわりだけ? — 国立国楽院の土曜名品 80分(パンソリの一場面が入る回)。

3. いくら? — 完唱 20,000ウォン、土曜名品 20,000~30,000ウォン、唱劇 20,000~50,000ウォン（公式）。

4. 韓服を着ると? — 10/24の土曜名品は50%割引（公式）。

5. 全州では? — ソリ祭りは8月。国立無形遺産院の日程は未確認。

6. UNESCOはいつ? — 2003年に宣言、2008年に人類無形文化遺産の代表リストへ記載。
