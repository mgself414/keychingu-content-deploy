🎯 为什么是“奶油年糕”攻略

奶油年糕 (Butter Tteok / 버터 떡) = 在传统糯米年糕上淋上温热融化的黄油的创新甜点，是2026年上半年韩国搜索量最高的甜点关键词。“外酥里糯 (Geotbasokjjon / 겉바속쫀)”是其核心特点，它延续了迪拜耐嚼曲奇 (Dubai Chewy Cookie / 두쫀쿠) 的热潮，在Instagram (인스타) 和TikTok (틱톡) 上刷屏。外国游客最大的痛点是：(a) “年糕=老式零食”的误解 — 实际上它是时尚的新品甜点 (b) 在哪里购买 (延南 (Yeonnam / 연남)·圣水 (Seongsu / 성수) 特定店铺) (c) 下午售罄 — 知名店铺上午必须抢购开门 (“奶油跑” (Butter-run / 버터런)) (d) 种类和价格。Reddit (레딧) 和YouTube (유튜브) 上“首尔奶油年糕 / 奶油年糕美食店 (butter rice cake Seoul / 버터떡 맛집)”的搜索量激增。

本攻略将提供奶油年糕招牌店铺·种类 + 抢购开门策略 + 区域 (延南 (Yeonnam / 연남)·圣水 (Seongsu / 성수)) + 种类矩阵 + 常见问题解答 (FAQ)。

⚠ 外国游客常犯的5个错误

1. “年糕是老式零食”: 奶油年糕 (Butter Tteok / 버터 떡) 是2026年最新潮流甜点·潮流地新品。

2. “随时去都有”: 知名店铺下午售罄·上午“奶油跑” (Butter-run / 버터런) 必不可少。

3. “凉了也没关系”: 奶油年糕 (Butter Tteok / 버터 떡) 温热时黄油香气·口感最佳。

4. “年糕=麸质”: 大部分以米为基础，不含面粉·但需根据店铺确认 (部分可能使用面粉)。

5. “和迪拜耐嚼曲奇一样”: 迪拜耐嚼曲奇 (Dubai Chewy Cookie / 두쫀쿠) (曲奇) ≠ 奶油年糕 (Butter Tteok / 버터 떡) (糯米年糕)·许多店铺同时销售两者。
