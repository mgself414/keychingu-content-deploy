🎯 为什么是秋季枫叶全攻略

韩国秋季枫叶 (10~11月) = 外国游客入境首选季节。这是继 [#89 韩国秋季枫叶TOP 8](89_korea_autumn_foliage_top8.md) 之后的更新，整合了按区域划分的枫叶景点全攻略。与春季樱花一同，每年都是外国游客Instagram和Vlog中雷打不动的第一名。

⚠ 外国游客常犯的3个错误

1. “枫叶 = 只有山”: 枫叶有4大类别 — 山 (北汉山·冠岳山·道峰山·阿且山) + 都市公园 (奥林匹克公园·首尔林·良才市民之林) + 宫殿 (昌德宫后苑·宗庙) + 山·观景台 (骆山·仁王山·鹰峰山)。

2. “枫叶季 = 10月”: 枫叶季节多样：

  • 10月第一~第二周: 江原道 (Gangwon-do / 강원도) 雪岳山·五台山
  • 10月第三~第四周: 北汉山·冠岳山·道峰山·阿且山
  • 11月第一~第二周: 都市公园·宫殿 (首尔林·奥林匹克公园·昌德宫后苑)
  • 11月第三周: 鹰峰山·骆山·仁王山等都市区域

3. “昌德宫后苑 = 普通入场”: 昌德宫后苑 (秘苑) = 必须提前预约 + 导览游 (每日4~5次) + 1小时30分钟行程 + 额外5,000韩元 (~$3.6 / ~26 RMB / ~570 JPY) 入场费。提供英文导览。

⚙ 常见问题6个

1. 外国游客枫叶首选: 北汉山 ([#182 北汉山](182_bukhansan.md))·昌德宫后苑 (联合国教科文组织)·奥林匹克公园·鹰峰山。

2. 外国游客英文导览: 昌德宫后苑·宗庙·其他宫殿 + 外国游客可提前预约。

3. 枫叶广域比较: 江原道 (10月第一~第三周) → 首尔山区 (10月第三~第四周) → 首尔都市公园·宫殿 (11月第一~第二周) → 首尔鹰峰山·骆山 (11月第二~第三周)。

4. 枫叶 + 韩服 (Hanbok / 한복): 昌德宫·宗庙·其他宫殿 (穿韩服可免费入场 [#207 寺庙·宫殿](207_temples_palaces.md))。

5. 韩剧枫叶取景地: 昌德宫后苑·北村 (Bukchon / 북촌)·奥林匹克公园·首尔林。

6. 枫叶 + KTX 1晚2天: 内藏山·雪岳山·智异山等外围景点可结合KTX·高速巴士进行。

🗺 秋季枫叶全日行程4个

A. 韩国第一山区枫叶 (10月第三周)

  • 09:00 AM 北汉山 ([#182 恩平](182_eunpyeong.md)) → 13:00 PM 午餐 + 津宽寺 (Jingwansa / 진관사) → 16:00 PM 冠岳山 ([#174 冠岳山](174_gwanaksan.md))

B. 都市公园枫叶 (11月第一~第二周)

  • 10:00 AM 奥林匹克公园 ([#82 奥林匹克公园](82_olympic_park.md)) → 13:00 PM 首尔林 ([#01 首尔林](01_seoul_forest.md)) → 16:00 PM 良才市民之林 ([#173 良才市民之林](173_yangjae_citizens_forest.md))

C. 宫殿·传统枫叶 (11月第二~第三周)

  • 10:00 AM 昌德宫 (Changdeokgung / 창덕궁) + 后苑 (提前预约) → 13:00 PM 宗庙 (联合国教科文组织) → 16:00 PM 北村韩屋村 (Bukchon Hanok Maeul / 북촌 한옥마을) → 18:00 PM 鹰峰山夜景

D. 外围1晚2天 (10月第三周~11月第一周)

  • Day 1: 内藏山 (KTX 4小时) — 韩国第一外围枫叶
  • Day 2: 结合全州韩屋村 ([#226 韩屋 (全州·安东)](226_hanok_jeonju_andong.md))

🌸 季节·时间段5个亮点

  • 10月第一~第三周: 江原道雪岳山·五台山 (结合KTX)
  • 10月第三~第四周: 首尔北汉山·冠岳山·道峰山·阿且山 (都市山区)
  • 11月第一~第二周: 首尔林·奥林匹克公园·良才市民之林·南山 + 宗庙
  • 11月第二~第三周: 昌德宫后苑 (联合国教科文组织)·骆山·仁王山·鹰峰山等都市区域
  • 11月第三~第四周: 都市最后枫叶 + 结合冬季灯光节 ([#231 冬季灯光节](231_winter_illumination.md))
