首尔公园12处 — 按关门时间、收费设施、最近车站来选

副标题: 为想在首尔安排半天公园行程的旅行者，把12处按关门时间整理在一起。首尔儿童大公园不是24小时开放，而是05:00~22:00开放。奥林匹克公园步行可在05:00~22:00进入，只有广场区域开到24:00。世界杯公园06:00开门，10~3月21:00关门。首尔植物园只有设有温室的主题园收费，成人5,000韩元，冬季(11~2月)16:00停止入场。南山不允许普通乘用车和出租车上山，要乘坐绿色循环巴士01A·01B。盘浦汉江公园月光彩虹喷泉只在3月15日到10月运行，冬季休息。时间和票价是2026-11-25查阅到的值，票价为成人标准价。

ISSUE 06 · #205 · 2026-11-25 · 서울 공원

🎯 适合谁，为什么是这12处

这份清单面向想在首尔的公园里度过半天的外国旅行者。这12处中，运营机构指南上写有门票的只有首尔植物园主题园。关门时间和收费设施每处各不相同。所以这一篇对每一处都先写"几点关门、哪里要花钱、哪个站几号出口"。

分成三组。

  • 有关门时间的地方(5处): 奥林匹克公园、首尔儿童大公园、世界杯公园(天空公园)、仙游岛公园、首尔植物园。
  • 始终开放的地方(5处): 首尔林、骆山公园、首尔菖蒲园、北首尔梦之林、南山公园。公园虽然开放，园内的设施有关门时间。首尔林按Kakao Map登记值。
  • 汉江公园(2处): 汝矣岛汉江公园、盘浦汉江公园。喷泉运行期间是固定的。

其中首尔林、骆山公园、仙游岛公园、首尔菖蒲园，是韩国观光公社"名胜发掘100×100"自然公园部门国民投票中入选的地方。首尔林以398票排第9，骆山公园以302票排第30，仙游岛公园以260票排第48，首尔菖蒲园以202票排第85(spot100x100.kr，2026-11-16接收)。

⚠ 标注原则: 时间、票价、交通方式是2026-11-25查阅到的值。出处是首尔市"首尔的公园"、首尔设施公团、韩国体育产业开发奥林匹克公园官网、首尔植物园官网、首尔市汉江公园官网、首尔自行车Ttareungi官网、国立公园公团。票价为成人标准价。运营机构指南中没有的几行是Kakao Map值，相应的行里注明了"Kakao Map"。票价栏的"—"表示运营机构指南中没有另写门票的地方。运营时间和票价可能变动。

⚠ 容易搞混的4点

  1. 首尔儿童大公园不是24小时开放。 首尔设施公团官方指南(2026-11-25查阅)写的是全年无休 05:00~22:00。动物园是10:00~17:00。车站也容易搞混。正门是7号线儿童大公园站1号出口，坐5号线的话，从Achasan站 (Achasan / 아차산) 4号出口出来，从后门进。
  2. 首尔植物园要付费的只有主题园。 首尔植物园官方指南(2026-11-25查阅)写明，门票只有温室和主题花园有，开放林、湖水园、湿地园是全天免费开放。冬季(11~2月)主题园17:00关门，入场16:00结束。周一主题园休息。
  3. 南山不允许乘用车和出租车上山。 首尔市指南写的是，自2005年5月1日起禁止普通乘用车和出租车通行，自2021年8月起禁止大型巴士(旅游大巴)通行。乘坐绿色循环巴士01A·01B，或者步行上山。
  4. 世界杯公园夜里不能进入。 首尔市官方指南(2026-11-25查阅)写的是"夜间为保护生物物种而管制出入"。10~12月和1~3月21:00关门。仙游岛公园也有06:00~24:00的关门时间。

① 有关门时间的地方 — 5处

晚上去的话，先看关门时间。五处中整个公园开到24:00的只有仙游岛公园(奥林匹克公园只有广场区域到24:00)。设施结束得早的是首尔植物园主题园(冬季17:00)和首尔儿童大公园动物园(17:00)。

奥林匹克公园 (Olympic Park / 올림픽공원)

以下值是韩国体育产业开发奥林匹克公园官网的官方指南(2026-11-25查阅)。

  • 使用期间: 全年无休。
  • 进入时间: 步行或骑自行车是05:00~22:00。广场区域到24:00。车辆是06:00~22:00。
  • 22点以后: 为了设施安全、保护游客人身安全、保护梦村土城 (Mongchontoseong Earthen Fortress / 몽촌토성) 文物，22点以后禁止进入公园内部(官方指南)。有深夜活动的日子，出入口的开放会有调整。
  • 票价: 使用费免费。停车收费。
  • 地址: 首尔特别市松坡区 (Olympic-ro 424 / 올림픽로 424)。
  • 交通方式: 5号线奥林匹克公园站3·4号出口，8号线梦村土城站1号出口，9号线奥林匹克公园站3·4号出口，9号线汉城百济站2号出口。
  • 服务中心: 在和平广场 (Pyeonghwa Square / 평화의광장) 和相会广场 (Mannam Square / 만남의광장)。09:00~19:00开放，12:00~13:00休息。押身份证可免费借轮椅3小时。
  • 玫瑰广场 (Rose Plaza / 장미광장): 全年无休开放。花期是5~6月和9~10月。
  • 注意事项: 是禁烟公园。不能做饭。宠物狗要拴绳，不能进入草坪。禁止无人机和电动滑板车。土城步道行人优先。
  • 安排时间: 天黑以后散步的话，22:00之前从公园内部出来。想待得晚一些，就去开到24:00的广场区域。

首尔儿童大公园 (Seoul Children's Grand Park / 서울어린이대공원)

以下值是首尔设施公团的官方指南(2026-11-25查阅)。

  • 公园开放: 全年无休，05:00~22:00。
  • 票价: 公园入场免费，公园内的收费游乐设施另有运营机构的价目表。
  • 动物园参观时间: 动物园 10:00~17:00(只运营户外动物园，鸟类馆不开放)。
  • 地址: 首尔市广津区 (Neungdong-ro 216 / 능동로 216)。
  • 交通方式: 从7号线儿童大公园站1号出口出来是正门。从5号线Achasan站 (Achasan / 아차산) 4号出口出来是后门。
  • 规模: 1973年5月5日开园。面积536,094.50㎡，周长4km。
  • 植物园: 2026年5月27日起到2027年下半年(预定)停止运营。
  • 安排时间: 动物园17:00结束，先看动物园，把公园散步放在后面。公园开到22:00。

世界杯公园 — 天空公园 (World Cup Park · Haneul Park / 월드컵공원 · 하늘공원)

以下值是首尔市"首尔的公园"官方指南(2026-11-25查阅)。Kakao Map值每行都注明了。首尔市没有按公园分别列时间，而是只给世界杯公园列了一张时间表。

  • 开园: 全年06:00。
  • 闭园: 1~3月21:00，4~9月22:00，10~12月21:00。
  • 夜间出入: 写明"开放时间以外不能出入"。
  • 地址: 首尔特别市麻浦区 (World Cup-ro 243-60 / 월드컵로 243-60)(城山洞 390-1)。咨询 02-300-5500，使用时间咨询 02-300-5501。
  • 交通方式: 按Kakao Map路线，从6号线世界杯体育场站1号出口步行到兰芝川公园的Maengkkongi电动车售票处14分钟(857m)。天空公园山顶要从这个售票处乘1号线电动车上去。
  • 开园时间: 2002年5月1日。
  • 萤火虫生态馆: 周二~周六 10:00~17:00，周一和周日闭馆，免费。
  • 停车: 乘用车每5分钟150韩元。

仙游岛公园 (Seonyudo Park / 선유도공원)

以下值是首尔市"首尔的公园"官方指南(2026-11-25查阅)。Kakao Map值每行都注明了。

  • 公园开放: 06:00~24:00。
  • 故事馆 (Story Hall / 이야기관): 09:00~18:00。冬季是09:00~17:00。每周一休息。
  • 地址: 首尔永登浦区 (Seonyu-ro 343 / 선유로 343)。咨询 02-2631-9367。
  • 交通方式: 从9号线仙游岛站步行约10分钟。从2号线·9号线堂山站步行约15分钟。按Kakao Map路线是从仙游岛站2号出口步行18分钟(1,077m)。
  • 停车: 只有残疾人车辆可以停。普通车辆停在杨花汉江公园 (Yanghwa Hangang Park / 양화한강공원) 第3停车场。
  • 安排时间: 五处中整个公园开到24:00的地方。按Kakao Map路线从仙游岛站2号出口要走18分钟，要留出这些时间。想看故事馆，避开周一，安排在白天。

首尔植物园 (Seoul Botanic Park / 서울식물원)

公园本身没有关门时间。不过展览馆、展望台、植物园这些园内设施有时间，而且很多在周一休息。

首尔林 (Seoul Forest / 서울숲)

以下值是首尔市"首尔的公园"首尔林官方指南(2026-11-25查阅)。Kakao Map值每行都注明了。

  • 参观时间: 官方指南的文字是"全年无休(部分设施周一闭馆)"。Kakao Map登记值(2026-11-25)是24小时，免费入场。
  • 生态林(鹿苑·步行天桥): 05:30~21:30。是生态保护区。鹿的饲料自2020年1月1日起不再出售。
  • 昆虫植物园 (Insect Garden / 곤충식물원): 3~10月是10:00~17:00。11~2月是10:00~16:00，15:30前入场。周一休息。
  • 蝴蝶庭园 (Butterfly Garden / 나비정원): 5~10月10:00~17:00开放，周一休息。11月到4月是闭馆期。
  • 游客中心: 09:00~18:00。押身份证可免费借轮椅和婴儿车2小时。
  • 喷泉: 地面喷泉5~9月运行，周一检修。之后休息。湖水喷泉3~10月在12点、13点、18点运行。
  • 地址: 首尔城东区 (Ttukseom-ro 273 / 뚝섬로 273)。咨询 02-460-2905。
  • 规模: 2005年6月18日开园。面积480,994㎡。

⚙ 4个常见问题

  1. 哪里收费，哪里免费？ — 这12处中，运营机构指南写有门票的只有首尔植物园主题园。成人5,000韩元，青少年3,000韩元，儿童2,000韩元。世界杯公园的Maengkkongi电动车普通单程2,000韩元，往返3,000韩元。首尔儿童大公园公园门票免费，奥林匹克公园使用费也免费。首尔植物园的开放林、湖水园、湿地园和月光彩虹喷泉观赏也免费。全部是2026-11-25在运营机构官网看到的值。
  2. 南山和冠岳山是国立公园吗？ — 不是。首尔的国立公园是北汉山。南山和冠岳山不在国立公园公团的国立公园24处名单里(国立公园公团官方指南，2026-11-25查阅)。
  3. Ttareungi多少钱，外国人怎么付款？ — 首尔自行车Ttareungi官方票价指南(2026-11-25查阅)显示，一日券是1小时券1,000韩元、2小时券2,000韩元、3小时券3,000韩元。一日券从第一次租借起到第二天同一时刻都可以使用，1·2·3小时券是一次租借可以骑的基本时间。超出的话每5分钟加收200韩元(首尔自行车官方指南)。在时间内归还再重新租借，没有额外费用。租借后4小时不归还会被视为被盗。付款方式名单里有外国人专用的"Discover Pass"。
  4. 周一去的话什么休息？ — 首尔植物园主题园、首尔林昆虫植物园和蝴蝶庭园、北首尔梦之林展望台和展览馆、仙游岛公园故事馆、世界杯公园萤火虫生态馆在周一休息。汝矣岛水光广场喷泉周一也不运行。公园本身周一也开放。周一选目的是散步而不是设施的骆山公园、首尔菖蒲园、南山公园、奥林匹克公园。
