1. 「漢江公園 (ハンガンゴンウォン) = どれも同じ」 — 11の漢江公園 (ハンガンゴンウォン) の個性を知らない

Q1. 漢江公園 (ハンガンゴンウォン) 11箇所の中で外国人1位は？

春4月: 汝矣島 (ヨイド) (輪中路 (ユンジュンノ) の桜) / 夏: トゥクソム (Ttukseom) (アクティビティ・BBQ) / 年間夜景: 盤浦 (パンポ) (潜水橋 (チャムスギョ)・月光虹噴水 (タルピッムジゲブンス))。一度に推薦するなら = トゥクソム (Ttukseom) (多様性最強)。

Q2. 漢江公園 (ハンガンゴンウォン) でのサイクリングは？

タルンイ (ソウル市公共自転車) — 1時間 ₩1,000 (約110円)。広津 (クァンナル) → 蚕室 (チャムシル) → トゥクソム (Ttukseom) → 盤浦 (パンポ) → 汝矣島 (ヨイド) 30kmコース (韓国一のサイクリングコース)。外国人クレジットカードOK。

Q3. 漢江 (ハンガン) BBQ指定区域は？

トゥクソム (Ttukseom)・盤浦 (パンポ)・蚕室 (チャムシル)・汝矣島 (ヨイド) 漢江公園 (ハンガンゴンウォン) の一部指定区域。事前予約 (ソウル市漢江公園ホームページ、英語OK)。1区域 ₩30,000/4人 (約3,300円)。5〜10月が1位。

Q4. 子供大公園 (オリニデゴンウォン) は無料ですか？

無料 + 24時間 (動物園は10:00〜18:00)。外国人家族連れ1位。5号線 子供大公園駅 (オリニデゴンウォンヨク)。

Q5. ソウルの森 (ソウルスプ) + 漢江公園 (ハンガンゴンウォン) の動線は？

ソウルの森 (ソウルスプ) (盆唐線 ソウルの森駅 (ソウルスプヨク)) → 徒歩5分 → トゥクソム漢江公園 (トゥクソムハンガンゴンウォン)。韓国一の「森 + 漢江 (ハンガン)」結合1位の動線。

Q6. 北漢山 (プッカンサン)・冠岳山 (クァナクサン)・南山 (ナムサン) の中で登山初心者向けは？

南山 (ナムサン) (265m, 30分〜1時間) → 冠岳山 (クァナクサン) トレッキングコース → 北漢山 (プッカンサン) トレッキングコース。すべてトレッキングコースは登山初心者・家族OK。

Q7. 春の桜公園TOP3は？

1位 汝矣島 (ヨイド) 輪中路 (ユンジュンノ) (#169) + 2位 ソウルの森 (ソウルスプ) 春の花 + 3位 良才市民の森 (ヤンジェシミニムスプ)・盤浦漢江公園 (パンポハンガンゴンウォン)・オリンピック公園 (Olympic Park)。4月第1週〜第2週がピーク。

Q8. 秋の紅葉公園TOP3は？

1位 北漢山 (プッカンサン) (836m・#182) + 2位 オリンピック公園 (Olympic Park) (#82) + 3位 良才市民の森 (ヤンジェシミニムスプ)・冠岳山 (クァナクサン)・南山 (ナムサン)。10〜11月がピーク。
