#韩国拌饭5种矩阵——全套全州、石锅、自助、野菜、海鲜

> 副标题：外国游客的5色正宗美食+全州韩屋村、石锅、自制拌饭、野菜、海鲜（联合国教科文组织非遗集群）

第03期·#879·2026-06-09

🎯 为什么选择韩式拌饭矩阵？

老外的韩国拌饭痛点= 知道“拌饭=一件事”，并认为它们都是一样的。韩式拌饭 = 5 种颜色的 Namul + 5 种变化狂热。即使是同一个“韩式拌饭”，全州（正宗#1·宫中·联合国教科文组织）·石锅（热·脆）·自己（MZ·DIY）·野菜（寺庙食品簇）·海鲜（生鱼簇交叉）各有不同的变化和狂热。外国人不知道 (a) 全套5色蔬菜 (b) Dolsot = 热 + 脆 不知道 (c) 自制拌饭 = MZ 不知道 (d) 野菜 = 素食#1 不知道 (e) 全州 = 联合国教科文组织非物质文化遗产 不知道。本指南适用于 5 种矩阵 + 5 种颜色 + 变换狂热。

🥬 5 种深度潜水

🥬 全州拌饭 — 正宗#1

  • 签名：5色正统·宫廷+联合国教科文组织非物质遗产·韩屋村
  • 材料：5色蔬菜（菠菜、胡萝卜、豆芽、蕨菜、桔梗）+鸡蛋+红辣椒酱+麻油、牛肉（可选）
  • 外国人友好度：★★★★★（#1东正教/联合国教科文组织）
  • 推荐商店：
  • 全州韩屋村拌饭餐厅 — 正宗#1
  • 首尔全州风格拌饭餐厅（江南、弘大）— 性价比
  • 时间：四个季节，真实
  • 价格: 全州韩屋村 = 12,000~25,000 韩元 / 首尔 = 8,000~20,000 韩元
  • 联合国教科文组织非物质遗产：皇家美食集群注册（2023年）

🍲 Dolsot 石锅拌饭 — 全球#1

  • 签名：热+脆Nurungji（下）·冷天狂热
  • 材料：5色蔬菜+鸡蛋+红辣椒酱+石锅·脆皮锅巴（下）
  • 外国人友好度：★★★★★（全球#1·热门人气）
  • 推荐商店：Hanjeongsik、MZ Korean Restaurant、连锁店（Hansot等）
  • 时间：四季，冬季#1
  • 价格：10,000~22,000韩元
  • 注意：石锅= 非常热（小心，使用盘子架）

🥄自制拌饭·DIY — MZ #1

  • 签名：DIY·MZ Instagram#1·选择材料
  • 材料：米饭+8~12种蔬菜（可选）+调味料、鸡蛋、肉（可选）
  • 外国人友善度：★★★★（MZ#1·DIY）
  • 推荐商店：
  • MZ自助拌饭店（弘大、江南、圣水） — 趋势
  • 自助韩式自助餐 — 性价比
  • 价格：8,000~18,000韩元/人（无限量自行补充）

🌳 山菜拌饭 — 素食 #1

  • 签名：寺庙食物集群十字·春天野菜·素食·清真#1
  • 材料：山野菜5至8种（猕猴桃、蕨菜、桔梗、水芹等）+鸡蛋（可选）+大酱调料
  • 外国人友善程度：★★★★（素食·清真#1）
  • 推荐商店：
  • 净碗萨 ([#876](#876)) — 正宗寺庙食品#1
  • 江原道·全罗山菜拌饭餐厅 — Spring Authentic
  • 时间：春季3月至5月#1·全年无休
  • 价格：寺庙美食套餐 25,000~80,000 韩元 / 山地采摘餐厅 10,000~25,000 韩元

🦐 海鲜拌饭 (Haemul Bibimbap) — 海鲜拌饭

  • 招牌：生鱼片、海鲜串串、札嘎其、统营正宗
  • 材料：5色蔬菜+生鱼、海鲜（比目鱼、鲍鱼、虾、扇贝）+红辣椒酱、鸡蛋
  • 外国人友好度：★★★（海鲜狂热）
  • 推荐商店：札嘎其店、统营店、江南生鱼店、MZ韩国餐厅

⚠ 外国人常犯的5个错误

1. “拌饭=一件事”：拌饭= 5种变化（全州、石锅、自助、野菜、海鲜）。

2. “全州=将军”：全州=联合国教科文组织非物质遗产正品（5种颜色，皇家宫廷）。

3. “石勒索 = 普通碗”：石勒索 = 很热 · 脆皮锅巴（下）。

4. “自我=性价比”：自我= MZ Instagram#1·全套食材。

5. “野菜=素食”：野菜=寺庙食物集群+春季野菜·正宗。

⚙ 8 个常见问题解答

1. 没有。外国人1：全州（东正教）+石索（全球）→ 自我（MZ）。

2. Insta·vlog：全州韩屋村·Dolstot热门vlog·自我DIY。

3. MZ潮流：自制拌饭(#1)·石锅拌饭。

4. 素食·清真：野菜拌饭(#1) + 寺庙食品。

5. 石锅注意事项：非常热，请使用盘架，小心儿童。

6. 过敏：鸡蛋、海鲜、大蒜、酱油和麸质。事先通知。

7. 付款/小费：卡OK/小费X。

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

拌饭=普通食物。孕妇小孩=OK（小心热石锅）。过敏（鸡蛋、海鲜、大蒜、酱油、麸质）需提前通知。小心石锅烧伤。如果怀疑食物中毒☎ 1339。本指南是一般信息，并非医疗建议。

饮食限制后备：

  • 清真/犹太洁食：野菜/全州 = 还可以（不包括牛肉）/海鲜 = 甲壳类动物
  • 素食/纯素食：野菜 = #1 / 5 种颜色 = 鸡蛋选项 / 海鲜 = 非素食。
  • 无麸质：酱油和红辣椒酱调味料 = 麸质（代替酱油）。
