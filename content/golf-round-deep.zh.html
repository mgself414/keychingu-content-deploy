🎯 本指南使用方法

旧版“12选”有五处位置写错（把杰克·尼克劳斯写成永宗岛 (Yeongjongdo / 영종도)，把东谷写成龙仁，把派恩克里克写成广州，把湖畔写成高阳 (Goyang / 고양)，把熊溪写成龙仁），果岭费也全部低于实际官方价格（“18洞120~170K”“球童每人2~2.5万韩元”“9洞60K无球童”）。这次只写2026-10-08亲自打开官方价目表的4家球场的数字，其余一律标注“官方未确认”。果岭费按月份、时段变动，所以派恩克里克的价格以“10月为准”。营业时间和开球时间在任何官方页面上都找不到，所以不写。1330口译、VAT退税、球童小费等旧版说法没有官方依据，已删除。

💰 费用结构——果岭费按人，球童·球车按队

  • 果岭费每人 + 球童每队150,000~170,000（4人则每人约40,000）+ 球车每队100,000~120,000（每人25,000~30,000）。4人平日公众制（派恩克里克第2轮215,000）每人合计约280,000韩元。旧版“球童每人2万韩元”是把每队的价格误写成了每人的价格。
  • 周末·公休日比平日高50,000~100,000。替代公休日也按周末价（派恩克里克10/5全时段220,000）。
  • 按月变动：派恩克里克11月的价目表也已公布。预约前请重新查看官方价目表。
  • 恶劣天气按洞结算（东谷果岭费×已打洞数/18，杰克·尼克劳斯遇天灾时按洞结算）。

📍 位置更正5处

  • 杰克·尼克劳斯高尔夫俱乐部在松岛 (Songdo / 송도)（不是永宗岛 (Yeongjongdo / 영종도)——“直通仁川机场 (Incheon Airport / 인천공항)”也没有依据）· 东谷在广州昆池岩 (Gwangju Gonjiam / 광주 곤지암)（不是龙仁）· 派恩克里克在安城 (Anseong / 안성)（不是广州）· 湖畔在龙仁处仁区 (Yongin Cheoin-gu / 용인 처인구)（不是高阳 (Goyang / 고양)）· 熊溪在抱川 (Pocheon / 포천)·春川 (Chuncheon / 춘천)（不是龙仁）。蓝鹭在骊州 (Yeoju / 여주)（二手）。

🗓 预约·语言

  • 4家都可在官方网站实时/网络预约（多数需会员登录）+ 总机电话。杰克·尼克劳斯价目表里有“外语优秀球童”一项（220,000）。东谷有ENG链接，海斯利有英文网站，但内容未确认。
  • Kakao高尔夫预约·XGOLF·kimcaddie的页面打不开，所以删除了旧版“国内第一平台·实时果岭费”的说法。

⚠ 常见错误5条

1. 按旧版“18洞120~170K”做预算——公众制平日也要180,000~215,000。

2. 计算时漏掉球童·球车——每队另加250,000~290,000。

3. 把杰克·尼克劳斯当成机场旁边——在松岛。

4. 11月中旬去熊溪抱川——11/16起停业。

5. 断言模拟高尔夫价格——官方未公布。

⚙ FAQ 6条

1. 最便宜的18洞是哪里？——官方确认的有派恩克里克10月平日第1轮180,000（7:30前）· 湖畔东南球场199,000。

2. 4人每人总价？——平日公众制约280,000（果岭费215,000 + 球童·球车分摊）。

3. 有英语球童吗？——杰克·尼克劳斯外语优秀球童220,000（官方）。其余未确认。

4. 非会员能打会员制球场吗？——东谷·杰克·尼克劳斯·湖畔西球场公布了非会员价格。海斯利未公布。

5. 只打9洞便宜吗？——韩国公众二手75,000~95,000，官方未确认。

6. 时间·季节呢？——营业·开球时间官方页面上没有。请根据按月价目表判断。
