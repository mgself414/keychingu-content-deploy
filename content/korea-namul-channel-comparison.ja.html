＃＃⚠外国人の頻繁な誤り5つ

1. "4チャンネル=類似": 価格・菜食・マニア完全相違。無料＝限定食・家庭食／ベジタリアン＝査察料理／MZ＝全州ビビンバ。

2. 「限定食＝ベジタリアン」： 限定食 おかず＝ アンチョビのごろ一部含有可能（査察食品#1）。

3. "査察食品=プルマン": 査察食品=ハーブ+豆腐・きのこ・山菜・フルセット。

4. "全州ビビンバ=一般": 全州ビビンバ=5色本格#1・宮中ビビンバcluster。

5. "仮定式=高価のみ": 家庭式=8,000～15,000ウォン コスパ #1 (ハーブ無料含む)。

⚠医療・安全・食事ダイエット

ハーブ4チャンネルすべて一般食品・植物基盤。妊婦・子ども＝OK。アレルギー（ニンニク・醤油グルテン・虎の薬材・アンチョビ液の一部） 事前告知。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー: 査察食品 = #1 本物 / 限定式 = アンチョビのご飯確認 / ビビンバ = 菜食・卵 / 家庭食 = 確認が必要。
  • ベジタリアン・ビーガン: 査察食品 = #1 / 他のチャンネル = アンチョビ液煮事前確認。
  • グルテンフリー: 醤油味付け=グルテン(タマリ代替)。
