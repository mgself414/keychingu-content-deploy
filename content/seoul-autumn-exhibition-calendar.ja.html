ソウル秋の展覧会カレンダー2026 — カウス・ソ・ドホ・ガウディ・マーティン・パー、10月から初冬まで日付が刻まれた10選

サブタイトル: カウス個展(~12/27)・ソ・ドホ展(~2027/2/9)・ガウディ没後100年展(~10/31)・マーティン・パー回顧展(~10/18、無料)+アジア初個展3件 — 2026年9月下旬~11月、終了日順にまとめた展覧会10選。雨の日の屋内代案で、祭りの週末の合間に挟む午後半日コースです。

🎯 なぜ「秋の展覧会カレンダー」なのか

ソウルの美術館・ギャラリー自体には常設ガイド(#350 Seoul Art Map・#1258 地下鉄で回る美術館ライン)があります。ところが2026年の秋は展覧会のラインナップが際立って厚い季節です — ブルックリン出身の作家カウス (KAWS / 카우스)の韓国美術館初個展、テートモダンを経て来たソ・ドホ (Seo Do-ho / 서도호)の国内最大規模の個展、ガウディ (Gaudí / 가우디)没後100年の公式巡回展、そしてアモーレパシフィック美術館・リウム・ソウル市立美術館がそれぞれ掲げる「アジア初個展」が一つの季節に重なっています。外国人旅行者にとっては「どの美術館がいいか」ではなく、「自分がソウルにいるその週に何が開催中か」が問いになります。

この回はその問いだけに答えます — 常設コレクションの説明は常設ガイドに任せ、日付・場所・料金・夜間開館・予約チャネルだけを表に落とし込みます。10月第1週の祭り(#1375)が雨で崩れたら、この表が屋内の代案になります。

⚠ 有効期間: 2026年限定のカレンダーです。観覧時間・休館日・料金は公式サイト基準(2026-09-17確認)で、秋夕(チュソク、10/3~5)・臨時休館は訪問前に各館の告知を確認してください。「未確認」と表記した値は公式ページに明記がなく、現地確認が必要です。

🅰 10月中に終わるものから — マーティン・パー・ガウディ・ソンウン

  • マーティン・パー (Martin Parr / 마틴 파) (~10/18、無料): イギリスのドキュメンタリー写真家マーティン・パーの50年を14シリーズ・写真500点余り・写真集90冊で展開する回顧展で、ソウル市立写真美術館全館を使います。無料という点が決め手です — 道峰区チャンドン (Changdong / 창동)まで行く時間だけが唯一のコストです。1号線・4号線チャンドン駅基準で都心から40分前後、平日は20時まで開いているので夕方でも間に合います。海外の写真愛好家なら、この秋のソウルで最もコスパの良い一場面です。
  • ガウディ (~10/31、27,000ウォン): ガウディ財団公式ワールドツアーのソウル編で、シンサドン (Sinsa-dong / 신사동)のシンサハウスで毎日20時まで開いています。料金はこのリストで最も高いですが、Feverアプリが英語・海外カード決済を受け付ける唯一の予約チャネルなので、外国人にはむしろ一番便利です。予約後、現地で実物チケットに引き換え、QRオーディオガイドが付きます。秋夕当日の9/25は休館です。
  • ソンウン (~10/10、無料): チョンダム (Cheongdam / 청담)・島山大路 (Dosan-daero / 도산대로)のソンウン美術大賞25周年記念グループ展 — 韓国の現代作家179人を一つの建物でまとめて見る形式なので、「最近の韓国の若手美術」を手早く見たいときに向いています。日曜・祝日休館で18:30に閉まるので、平日の昼間に狎鴎亭ロデオ (Apgujeong Rodeo / 압구정로데오)・チョンダムのショッピング(#1088)と組み合わせるといいです。

🅱 12月まで — カウス・グ・ジョンア・イ・ガンソ、そして原画展

  • カウス (~12/27、12,000ウォン): ブルックリン出身の作家KAWSの韓国美術館初個展。マゴク (Magok / 마곡)のスペースK ソウルで、大型絵画・彫刻の新作を含む20点。火~日10~18時、月休館。マゴクは5号線・9号線マゴクナル寄りの郊外なので、金浦空港の離着陸前後(#1285)に組み込みやすく、キャラクター・ストリートアートのファンならこれ一つでマゴク行きが正当化されます。
  • グ・ジョンア (Koo Jeong A / 구정아) (~12/27): ハンナムドン (Hannam-dong / 한남동)のリウム美術館M2、1990年代初期作からリウム・コミッションの新作まで35点。予約が観覧日の14日前に開く方式なので、旅程が決まり次第ticket.leeum.orgを確認してください — 週末はすぐに埋まります。月・旧正月・秋夕休館、18時締め(発券17:30)。
  • イ・ガンソ (Lee Kang-so / 이강소) (~11/1、20,000ウォン): チャムシル (Jamsil / 잠실)のロッテワールドタワーにあるロッテミュージアム。韓国実験美術第1世代の作家による大規模個展で、チャムシルのショッピング・ロッテワールド(#1088・#586チャムシルの夜景)と同じ建物群にあるため移動コストがゼロです。18:30入場締切。
  • グラウンドシーソー・イースト原画展 (~11/29): クァンジン区イーストポール2階、イラストレーターのイ・ギフン (Lee Gi-hun / 이기훈)とチョ・ウン (Jo Eun / 조은)の原画展示。テキスト解説が韓国語中心の可能性があり、英語案内は未確認 — 絵そのものを見に行く場所として期待値を合わせておくといいです。料金はインターパークNOLの商品ページ基準。

🅲 冬まで続く大型3展 — ソ・ドホ・ジョナス・ウッド・リン・ハーシュマン・リーソン

  • ソ・ドホ (~2027/2/9、8,000ウォン): サムチョンドン (Samcheong-dong / 삼청동)の国立現代美術館ソウル。テートモダン巡回を経た国内最大規模の個展で、料金8,000ウォンに水・土21時までの夜間開館 — このリストで夜間・価格・規模の3軸が同時に良い唯一の展覧会です。ソウルボックス区間は12/18に別途開くので、12月訪問者は両区間とも見られます。プクチョン (Bukchon / 북촌)のギャラリー・韓屋ダイニング(#908)と徒歩でつながります。
  • ジョナス・ウッド (~2027/2/28、18,000ウォン): ヨンサン (Yongsan / 용산)のアモーレパシフィック美術館(APMA)、LA出身の作家によるアジア初個展であり20年余りの回顧展。予約がAPMA自体のサイトでのみ可能で、月休館・17:30発券締切のため「通りすがりに立ち寄る」ことはできません — 日付を決めて行く必要があります。建物(チッパーフィールド設計)自体が見どころで、#1258のラインと重なります。
  • リン・ハーシュマン・リーソン (10/21~2027/2/21): ソソムン (Seosomun / 서소문)にあるソウル市立美術館西小門本館。メディア・AI・アイデンティティを60年にわたって扱ってきたアメリカ人作家のアジア初の美術館個展。10月第3週以降にしか見られず、金曜日は21時まで開いています。料金・英語案内は開幕後の告知を確認してください。

🗓 二日間コース — 美術館は二つの軸に集まっている

Day 1・北の都心軸(水または土推奨): 午後サムチョンドンの国立現代美術館 ソ・ドホ → プクチョンの路地・ギャラリー散策(#908) → 夕方ソソムンのソウル市立美術館(10/21以降はリン・ハーシュマン・リーソン展。金曜なら21時まで)。ソ・ドホ展は水・土21時までなので、順番を入れ替えてソソムンを先に行ってもいいです。

Day 2・南の川岸軸: 午前ハンナムドンのリウム グ・ジョンア展(予約必須) → 徒歩・バスで一停留所のヨンサンAPMA ジョナス・ウッド → 夕方シンサドンのガウディ(20時まで、10/31終了)。ハンナムの夜バー(#1073)で締めくくり。

別立ての半日2つ: ①西 — マゴクのカウス + チャンドンのマーティン・パー(どちらも郊外、1日にまとめると移動だけで2時間前後になるので別々に) ②東 — チャムシルのロッテミュージアム イ・ガンソ + クァンジンのグラウンドシーソー原画展(2号線チャムシル↔建大入口)。

雨の日の切り替え: 10/3~4の祭りウィーク(#1375)が雨天なら、Day 1軸(サムチョンドン・ソソムン)をそのまま屋内の代案として使えます。

⚠ よくある失敗3つ

1. 月曜日に美術館へ行く — マーティン・パー・カウス・グ・ジョンア・ジョナス・ウッド・リン・ハーシュマン・リーソン全部月休館。月曜日はガウディ(毎日)・ロッテミュージアム・グラウンドシーソー・ソンウン(日曜休館なので月は開館)で。

2. 現地窓口購入を当てにする — リウムは14日前予約制、APMAは自社サイト単独予約。週末は現地購入ができない、または売り切れの可能性があります。ガウディは逆にアプリ(Fever)予約が外国人には一番簡単です。

3. 10月第3週の前にソソムンへ行く — リン・ハーシュマン・リーソンは10/21開幕。それより前に西小門本館へ行くと、この展覧会はありません。

⚙ FAQ3つ

1. 一つだけ選ぶなら? — 初めてのソウル旅行者基準でソ・ドホ(サムチョンドン): 8,000ウォン・水・土21時まで・国内最大規模、プクチョンと隣接。写真・ドキュメンタリー好きなら無料のマーティン・パー(10/18まで)。

2. 予約アプリが韓国語しかない場合は? — ガウディのFeverは英語・海外カード対応が確認できています。それ以外の美術館サイトは国内カード・ネイバーペイ中心で、海外発行カードでの決済は未確認 — 無料展示(ソンウン・マーティン・パー)と現地購入ができる場所(MMCA・スペースK)を優先すればリスクが減ります。

3. 連休だからどれくらい混む? — MMCAソウル水・土21時、SeMA西小門金21時(火~木20時)、ガウディ毎日20時、マーティン・パー平日20時。それ以外は18~19時締めです。
