外国人常犯的5个错误

1. 误解“紫菜包饭 (Gimbap / 김밥) 都一样”

韩国 (Korea / 한국) 紫菜包饭 (Gimbap / 김밥) 根据市场老字号 (Nopo / 노포) (拥有30年以上历史的传统老店) / 高端连锁 / 潮流连锁 / 便利店 (Pyeonuijeom / 편의점)，其食材·价格·味道完全不同。广藏市场 (Gwangjang Sijang / 광장시장) 麻药紫菜包饭 (Mayak Gimbap / 마약김밥) ₩4,000 (~21 RMB) 和 Lee Gimbap (리김밥) 生酮 (Keto / 키토) 紫菜包饭 (Gimbap / 김밥) ₩5,800 (~31 RMB) 都是紫菜包饭 (Gimbap / 김밥)，但却是不同的食物。请参考正文“连锁三大巨头对比”部分。

2. 广藏 (Gwangjang / 광장) 麻药紫菜包饭 (Mayak Gimbap / 마약김밥) 不蘸芥末

广藏市场 (Gwangjang Sijang / 광장시장) 麻药紫菜包饭 (Mayak Gimbap / 마약김밥) 的核心是芥末+酱油酱汁。不蘸酱汁会损失一半风味。外国人评价“就是普通的迷你紫菜包饭 (Gimbap / 김밥)”十有八九是因为没有蘸酱汁。

3. 对凌晨便利店 (Pyeonuijeom / 편의점) 紫菜包饭 (Gimbap / 김밥) 质量不佳的偏见

韩国 (Korea / 한국) 便利店 (Pyeonuijeom / 편의점) 紫菜包饭 (Gimbap / 김밥) (CU / CU 两班紫菜包饭 (Yangban Gimbap / 양반김밥)，GS25 / GS25 金惠子紫菜包饭 (Kim Hye-ja Gimbap / 김혜자김밥)，7-Eleven / 세븐일레븐) 24小时新鲜周转，外国游客满意度非常高。凌晨抵达航班 + 第一天入住酒店时，₩3,500 (~19 RMB) 金惠子紫菜包饭 (Kim Hye-ja Gimbap / 김혜자김밥) + 杯面是韩国 (Korea / 한국) 第一餐的正确选择。

4. 将忠武紫菜包饭 (Chungmu Gimbap / 충무김밥) 当作普通紫菜包饭 (Gimbap / 김밥) 订购

忠武紫菜包饭 (Chungmu Gimbap / 충무김밥) (源自统营 (Tongyeong / 통영) 的地方特产) 是紫菜包饭 (Gimbap / 김밥) + 萝卜泡菜 + 鱿鱼拌菜分开装盘的。不是“只点紫菜包饭 (Gimbap / 김밥)”，而是点套餐 (₩7,000 (~37 RMB)~₩10,000 (~53 RMB))。搭配迷你紫菜包饭 (Gimbap / 김밥) 和萝卜泡菜·鱿鱼拌菜是正宗吃法。

5. 不了解生酮 (Keto / 키토) 紫菜包饭 (Gimbap / 김밥)·素食选项就随便点

韩国 (Korea / 한국) 紫菜包饭 (Gimbap / 김밥) 的选项变得多样，包括用鸡蛋卷代替米饭的生酮紫菜包饭 (Keto Gimbap / 키토김밥)，以及不含肉类·海鲜只用蔬菜的素食紫菜包饭 (Vegan Gimbap / 비건김밥)。如果您是无麸质·低碳水·素食者，请先查看 Lee Gimbap (리김밥) 生酮 (Keto / 키토) 紫菜包饭 (Gimbap / 김밥) / Barda Kim Seonsaeng (바르다김선생) 蔬菜紫菜包饭 (Yachae Gimbap / 야채김밥)。

常见问题解答 (FAQ)

Q1. 能说英语吗？

Barda Kim Seonsaeng (바르다김선생)·Lee Gimbap (리김밥)·紫菜包饭天国 (Gimbap Cheonguk / 김밥천국)·便利店 (Pyeonuijeom / 편의점) 普遍有英文菜单·图片菜单。广藏 (Gwangjang / 광장) 麻药紫菜包饭 (Mayak Gimbap / 마약김밥)·忠武紫菜包饭 (Chungmu Gimbap / 충무김밥) 主要以韩语为主，但用手指指点即可。

Q2. 有素食紫菜包饭 (Gimbap / 김밥) 吗？

完全素食较难，但蔬菜紫菜包饭 (Yachae Gimbap / 야채김밥) (可要求不放鸡蛋) / Lee Gimbap (리김밥) 生酮 (Keto / 키토) 变体是最接近的。请向店员明确说明“vegan, no egg, no meat” + 亲自确认菜单。

Q3. 辣吗？

蔬菜·金枪鱼·芝士·猪排紫菜包饭 (Gimbap / 김밥) 不辣。如果含有辣味·猪肉·辣味金枪鱼蛋黄酱·辣味香肠，则为辣味 (中等韩式辣味)。不能吃辣的话，选择安全菜单为主。

Q4. 紫菜包饭 (Gimbap / 김밥) 和寿司 (Sushi / 초밥) 有什么不同？

紫菜包饭 (Gimbap / 김밥) 的米饭不加醋 (寿司 (Sushi / 초밥) 米饭加醋)，海苔在外，主要使用熟食食材 (寿司 (Sushi / 초밥) 主要使用生鱼片)。外国人最初会问“和寿司 (Sushi / 초밥) 差不多吗？”，但实际上是不同的食物类别。更接近日本 (Japan / 일본) 的 Maki (maki / 마키)。

Q5. 凌晨·深夜在哪里吃？

24小时紫菜包饭天国 (Gimbap Cheonguk / 김밥천국) 门店 + 所有便利店 (Pyeonuijeom / 편의점)。CU / CU·GS25 / GS25·7-Eleven (세븐일레븐) 紫菜包饭 (Gimbap / 김밥) 24小时新鲜周转。酒店凌晨抵达 = 便利店 (Pyeonuijeom / 편의점) 金惠子紫菜包饭 (Kim Hye-ja Gimbap / 김혜자김밥) + 杯面是正确选择。

Q6. 可以带小孩去吗？

Barda Kim Seonsaeng (바르다김선생)·Lee Gimbap (리김밥)·紫菜包饭天国 (Gimbap Cheonguk / 김밥천국) 适合家庭。除了辣味菜单，推荐蔬菜·金枪鱼·芝士。广藏市场 (Gwangjang Sijang / 광장시장)·忠武紫菜包饭 (Chungmu Gimbap / 충무김밥) 地方狭窄且嘈杂，不推荐带小孩。

  • 广藏市场 (Gwangjang Sijang / 광장시장) 麻药紫菜包饭 (Mayak Gimbap / 마약김밥) 在炎热天气下需快速周转才能保持新鲜

秋季 (9~11月)

  • 紫菜包饭 (Gimbap / 김밥) 最佳季节 — 户外野餐 (汉江 (Hangang / 한강)·南山 (Namsan / 남산)) + 紫菜包饭 (Gimbap / 김밥) 是绝配
  • 季节限定菜单 (栗子·红薯·松露) 上市

冬季 (12~2月)

  • 热腾腾的拉面+紫菜包饭 (Gimbap / 김밥) 套餐受欢迎 (紫菜包饭天国 (Gimbap Cheonguk / 김밥천국)·Barda Kim Seonsaeng (바르다김선생))
  • 凌晨便利店 (Pyeonuijeom / 편의점) 紫菜包饭 (Gimbap / 김밥) + 杯面 = 韩国 (Korea / 한국) 冬季夜间正解
