ISSUE 03 · #831 · 2026-06-08

🎯 왜 식당 김치 입문 동선 가이드인가

#822 김치 6종 매트릭스가 한국 김치 시그니처 perspective라면, 외국인 관광객 페인포인트는 "식당에서 실제로 어떤 김치를 언제 만나고 어떻게 다뤄야 하나" 동선 perspective다. 외국인 99%가 한국 도착 첫날 한식당에 가지만 — (a) 기본 반찬으로 깔리는 김치 1~4종을 구분 못 하고 (b) "리필 무료" 사인을 못 읽고 (c) 매장별 김치 차이 (한식 노포 vs 분식 vs BBQ vs 국밥집)를 모르고 (d) 메뉴 주문 시 김치 페어링 우선순위를 모르고 (e) 재방문 시 "단골 김치" 요청 노하우를 모른다.

본 가이드는 식당 입장 → 반찬 받기 → 리필 요청 → 재방문 4단계 + 매장 유형별 김치 매트릭스 + 메뉴-김치 페어링 표 + 영어 발화 키트.

★ 한눈에 식당 동선 4단계

Step 동작 김치 종류 외국인 핵심
1️⃣ 입장 + 자리 안내 + 메뉴판 + 물 + 기본 반찬 깔림 배추김치 + 깍두기 (한식 표준 2종) 김치 = 자동 무료 반찬 (요청 X)
2️⃣ 메뉴 + 김치 페어링 음식 주문 + 김치 매칭 음식 따라 김치 가감 (국밥+깍두기 등) "안 매운 김치 있어요?" 요청 OK
3️⃣ 무료 무제한 리필 김치 다 먹으면 추가 요청 같은 김치 보충 "김치 좀 더 주세요" = 모든 식당 무료
4️⃣ 재방문 + 단골 노하우 사장님 인사 + 김치 선호 메모 김치 시즌·발효 단계 요청 묵은지 매니아 → "묵은지로 주세요"

총 소요: 식사 시간 내 (별도 시간 X) / 재방문 = 2회 이상 같은 식당

외국인 첫 식당 1순위: 국밥집 (깍두기 단순) → BBQ (김치 풍부) → 한정식 (다양)

🚪 Step 1 — 입장 + 자리 (김치 = 자동 무료 반찬)

입장 시 외국인 핵심 5가지

1. "몇 분이세요?" = How many people? — 손가락으로 표시 OK

2. "여기 앉으세요" = This way please — 자리 안내

3. 기본 반찬 자동 깔림 = 김치 1~5종이 자동으로 옴 — 별도 요청 X·무료

4. 물·물수건 자동 = 별도 청구 X

5. 메뉴판 영문 = 명동·이태원·홍대·강남·종로 主 식당 영문 OK

자리 앉자마자 깔리는 김치 (매장별)

  • 국밥집: 깍두기 1종·배추김치 1종 = 2개 그릇
  • BBQ: 배추김치·깍두기·쌈장·상추 = 4~6개 그릇
  • 한정식: 배추김치·백김치·동치미·깍두기·총각김치 = 5종 풀세트
  • 분식: 단무지·배추김치 = 2개 그릇
  • 카페: 김치 X (예외 = 김치 베이커리·김치 토스트)

영어 발화 키트 (Step 1)

  • "Is the kimchi free?" → 김치 무료인가요? = YES (모든 한식당)
  • "Can I get more kimchi?" → 김치 더 받을 수 있나요? = YES·무제한
  • "Which kimchi is least spicy?" → 가장 안 매운 김치는? = 백김치·동치미 요청

🍲 Step 2 — 메뉴 + 김치 페어링 (음식별 김치 매칭)

음식별 김치 페어링 매트릭스

음식 1순위 김치 2순위 외국인 팁
설렁탕·곰탕 깍두기 #1 배추김치 깍두기 = 국밥 표준
돼지국밥·해장국 깍두기 #1 배추김치·총각 매콤 가감 = 백김치 가능
김치찌개 배추김치·총각·깍두기 (모두) - 묵은지 = 매니아 1순위

외국인 매니아 추천: 묵은지 김치찌개 = 한국 #1 매콤 매니아 (백김치 + 묵은지 = 매콤·시큼 매트릭스)

안 매운 김치 요청 영어

  • "Do you have white kimchi?" → 백김치 있어요? (안 매움)
  • "Do you have water kimchi?" → 물김치 (동치미·나박) 있어요? (안 매움)
  • "Mild kimchi please" → 안 매운 김치로 부탁드려요

🔄 Step 3 — 무료 무제한 리필 (모든 식당)

리필 요청 표준 절차

1. 김치 그릇이 비면 = 자동 리필 신호

2. "김치 좀 더 주세요" = Can I get more kimchi? — 사장님·종업원 호출

3. 추가 그릇 = 5초~1분 내 도착

4. 무료·무제한 = 모든 한식당 (한정식·국밥·BBQ·분식 모두)

5. 예외 매장 X = 한국 어디서나 무료 (체인·노포·고급 모두)

리필 못 받는 케이스 (드물지만)

  • 뷔페·셀프 매장 = 사용자가 직접 가서 가져옴
  • 체인 무한리필 매장 = 시간 제한 (1시간 30분 등)
  • 공항·기차역 매장 = 일부 1회 제공 (드물지만)

리필 빈도 (외국인 vs 한국인)

  • 한국인 평균: 1식사당 1~2회 리필
  • 외국인 평균: 1회 또는 0회 (요청 모름)
  • 외국인 매니아: 3~4회 (한국인 수준)

영어 발화 키트 (Step 3)

  • "More kimchi please" = 김치 더 주세요
  • "Different kimchi?" = 다른 종류 김치도 있나요? (한정식·다종 매장)
  • "Same kimchi" = 같은 김치 (요청 시)

🎯 Step 4 — 재방문 + 단골 노하우

재방문 시 김치 노하우

1. 사장님 인사 = 한국 노포 = 사장님이 김치 직접 담그는 매장 多

2. "사장님 김치 맛있어요" = This kimchi is really good — 사장님 자랑·서비스 김치 OK

3. 김치 시즌 요청 = 봄(열무 시작)·여름(열무·나박)·가을(김장 준비)·겨울(김장·동치미) 매장별 시그니처 다름

4. 발효 단계 요청 = "묵은지로 주세요" / "겉절이로 주세요" — 단골 매트릭스

5. 사장님 김치 가르침 = 재방문 단골 = 사장님이 김치 비법·재료·시즌 정보 share

단골 매니아 김치 매트릭스

1st 방문 자동 김치 (요청 X) 표준 응대
2nd 방문 "어제 김치 더 주세요" 사장님 기억·서비스 김치

외국인 재방문 ROI

  • 재방문 = 김치 페어링 무료 업그레이드 (서비스 김치·묵은지·시즌 김치 무료)
  • 재방문 = 사장님 한국 문화·동네 추천 (현지 매니아 #1)
  • 재방문 = 한국 친구 관계 시작 (사장님 = 동네 정보 hub)

⚠ 외국인 자주 실수 5가지

1. "김치 = 별도 요청·유료": 한식당 김치 = 자동 무료 반찬·무제한 리필. 별도 주문 X.

2. "김치 리필 미요청 (조용히 끝)": 한국 표준 = 리필 요청 = 정상. "More kimchi please" 자연스러움. 한국인 평균 1식사 1~2회 리필.

3. "국밥집에 다양 김치 기대": 국밥집 = 깍두기 1종 (특화 매장). 다양 김치 = 한정식·가정식.

4. "BBQ에서 김치 페어링 모름": BBQ 익은 김치 = 기름 jus 매트릭스. 일본인 #1·중국인 #1 매니아.

5. "분식·치킨에 김치 없다고 생각": 분식 = 단무지+배추김치. 치킨 = 치킨무+배추김치. 김치 = 한식당 표준.

⚙ FAQ 6개

1. 외국인 첫 한식당 추천: 국밥집 (깍두기 단순·국물 따뜻) → BBQ (김치 풍부) → 한정식 (다양). 첫 방문 = 국밥집.

2. "김치 무료 무제한" 신호: 메뉴판·간판 X·당연한 한국 식당 표준. 매장 입장 = 자동 적용.

3. 리필 빈도: 한국인 = 1~2회·외국인 매니아 = 3~4회·외국인 신규 = 0~1회. 매니아 = 매장 단골.

4. 묵은지 매장: 노포·30년+ 가정식·김치찌개 전문 매장 = 묵은지 비축. 체인 = 묵은지 X 多.

5. 시즌 김치 매장: 봄 (열무 시작 4~5월)·여름 (나박·열무 6~8월)·가을 (김장 준비 10~11월)·겨울 (김장·동치미 11~2월) — 가정식·노포 시그니처.

6. 알레르기: 새우젓 (갑각류)·멸치액젓·마늘·고춧가루·콩 (간장) 사전 고지. 백김치·동치미 = 매콤 X + 일부 알레르겐 X 옵션.

⚠ 의료·안전·식이 disclaimer

김치 = 발효 음식 (염분 ↑·매운맛 多). 임신부·고혈압·신장 환자 = 염분 주의. 어린이 = 백김치·동치미 (안 매움) 권장. 알레르기 (새우젓·멸치액젓·갑각류·마늘·고춧가루) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문).

식이 제한 fallback:

  • 할랄·코셔: 일반 김치 = 비할랄·비코셔 (새우젓 포함). → 사찰음식 김치 = 채식·할랄·코셔 가능
  • 채식·비건: 일반 김치 = 비채식 (새우젓·멸치액젓). → 사찰음식 또는 비건 김치 (간장 기반) 별도 매장
  • 글루텐 free: 간장 빼면 OK. 백김치·동치미 = 간장 X = OK

✈️ 외국인 페인포인트 #1 — 식당 김치 vs 마트 김치 차이

  • 식당 김치 = 사장님 직접 담금 (노포) 또는 김치 공장 납품 (체인) — 신선·계절·매장 시그니처
  • 마트 김치 = 김치 공장 대량 (종가집·풀무원·CJ 등) — 표준·진공·장기 보관
  • 체험 차이: 식당 = 신선·시즌 변화 / 마트 = 표준 일관성
  • 귀국 선물: 마트 진공 포장 김치 = 위탁 수하물 OK (액체 분류·100ml+) — 기내 휴대 X
  • 추천 구매처: 인천공항 면세점 (진공 포장)·이마트·롯데마트 (가성비)
