⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가격·예약·드레스 완전 다름. MZ = 카페 / Bib = 뉴웨이브 / 미슐랭 = 파인다이닝 / 한정식 모던 = MZ 한정식.

2. "미슐랭 = 즉시": 1~3개월 사전 예약 필수.

3. "미슐랭 = 비싸기만": Lunch = 50~80k 가성비 OK.

4. "드레스 코드 X": 미슐랭 = 스마트 캐주얼 이상.

5. "MZ 카페 = 가성비": MZ 카페 = 12~30k MZ 트렌드·인스타 #1.
