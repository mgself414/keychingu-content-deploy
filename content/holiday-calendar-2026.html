⚠ 외국인 자주 실수 5가지

1. "한국 명절 = 설·추석만": 한국 명절 = 설 + 추석 + 단오 (UNESCO) + 한글날 + 부처님 오신 날 + 정월대보름 + 동지 + 삼일절 + 광복절 + 개천절 풀세트 + 외국인 매니아 1번지.

2. "설날 = 한국인만": 설날 = 외국인 매니아 1번지 + 한복 (#379) + 떡국 + 세배 + 차례상 체험 + #502 통합·KTO 인증·외국인 정통 매니아.

3. "단오 = 옛날만": 단오 = UNESCO (강릉 단오제) + 외국인 정통 매니아 1번지 + 그네·씨름·창포물·#404 통합.

4. "한글날 = 휴일만": 한글날 = 한국 #1 문화 명절 (10월 9일·세종대왕·1446 훈민정음 반포) + 외국인 문화 매니아 1번지 + #502·#403 통합.

5. "명절 = 매장 휴무": 명절 = 설·추석 3일 연휴 (대부분 매장 휴무)·BUT 명동·강남·인사동 일부 영업 + 외국인 매니아·KakaoMap 영업 시간 확인.
