⚠ 외국인 자주 실수 5가지

1. "환전 = 공항만": 환전 = 명동 시내 (환율 #1) + KEB하나·신한·우리 + 인천공항 + 사설 환전소 + 외국인 가성비 1번지 (시내 vs 공항 5~10% 차이).

2. "외국인 신용카드 = 한국에서 안 됨": 외국인 신용카드 = Visa·Master·Amex 90%+ 매장 + 외국인 매니아 1번지 + 외국인 영어 OK + 외국인 가성비.

3. "KakaoPay·Naver Pay = 한국인만": KakaoPay·Naver Pay = 외국인 신용카드 등록 OK + 외국인 영어 OK + 외국인 매니아 1번지·#398 통합.

4. "ATM = 한국인만": 외국인 ATM = Citibank·KEB하나·외환은행·24h + 외국인 신용카드 출금 + 외국인 매니아 1번지·KTO 인증.

5. "외국인 트래블 카드 = 어려움": Wise·Revolut = 외국인 글로벌 매니아 1번지 + 환율 자동 + 외국인 가성비 1번지 + 외국인 영어 OK 풀세트.
