🎯 なぜ餅4チャンネル比較ガイドが必要か

餅6種まとめ(#855)や餅の注文・祝祭ワークフロー(#856)を知っていても、チャンネル選びが次の課題になる。韓国の餅は4チャンネルに分かれる：(1)伝統餅屋(전통 떡집)— 広蔵市場(Gwangjang Market / 광장시장)・仁寺洞(インサドン / 인사동)の老舗(老舗 / 노포、30年以上続く伝統店)、(2)市場餅(시장 떡)— 広蔵市場・通仁市場(通仁市場 / 통인시장)、(3)MZカフェ(MZ 카페、韓国のミレニアル+Z世代を指す言葉)— インジョルミ(인절미)トースト・チャプサルトッポッキ(찰떡볶이)、(4)免税店・オンライン(면세점·온라인)— 真空パック詰め合わせ。価格は₩5,000から₩80,000まで幅があり、雰囲気は伝統→市場→トレンディ→免税の順で変わる。本ガイドは4チャンネルを直接比較し、ソロ・カップル・ファミリー・MZ・予算重視の5タイプ別にベストピックを紹介する。刺身、焼肉、クッパ、粉食、麺類、チキン、デザート、キムチ、薬膳料理、酒、韓定食、伝統飲料、夜食、キンパ、発酵食品、肉のおかずシリーズと同じ比較フォーマットを採用。

🏯 4チャンネル深掘り

🏯 伝統餅屋(전통 떡집)

コアバリュー：定番6種 + 老舗の伝統 + 祝祭・お祝い事人気No.1。

  • おすすめ店舗(ソウル)：
  • 広蔵市場(광장시장)の餅屋エリア — 外国人vlogger人気No.1
  • 仁寺洞(인사동)の伝統餅屋 — 韓屋(韓屋 / 한옥、韓国伝統の木造家屋)の雰囲気
  • 南大門市場(南大門市場 / 남대문시장)の餅屋 — コスパが良い
  • おすすめ店舗(地方)：
  • 全州韓屋村(全州韓屋村 / 전주 한옥마을)の餅屋 — 本格的
  • メニュー：ガレトク・ソンピョン(季節限定)・インジョルミ・ペクソルギ・キョンダン
  • 価格の目安：₩5,000~30,000(お祝い用1カン：₩30,000~80,000)
  • 外国人フレンドリー度：★★★★(一部英語)

🛒 市場餅(시장 떡)

コアバリュー：コスパの良さ + 市場の雰囲気 + 外国人vlogger人気No.1。

  • おすすめ市場：
  • 広蔵市場のトッポッキ・餅通り — 外国人vlogger人気No.1
  • 通仁市場(通仁市場 / 통인시장)の弁当餅 — 通仁名物の自分で選ぶ弁当
  • 南大門市場 — コスパが良い
  • 鷺梁津市場(鷺梁津市場 / 노량진시장) — 粉食(粉食 / 분식、韓国の軽食)の屋台エリア
  • メニュー：定番6種 + トッポッキ + 市場ならではのアレンジ
  • 価格の目安：₩3,000~10,000(市場価格でコスパ良し)
  • 外国人フレンドリー度：★★★★(広蔵市場のvlogで人気)

☕ MZカフェ(MZ 카페)

コアバリュー：トレンディ感 + インジョルミトースト・チャプサルトッポッキ・MZトレンド人気No.1。

  • おすすめエリア(ソウル)：
  • ホンデ(ホンデ / 홍대)・ヨンナム(ヨンナム / 연남) — MZカフェの集まるエリア
  • カンナム(カンナム / 강남)・ヨクサム(ヨクサム / 역삼) — MZ世代の会社員に人気
  • ソンスドン(ソンスドン / 성수동) — トレンドの中心地(ブルーボトル + インジョルミ)
  • イテウォン(イテウォン / 이태원) — 外国人にフレンドリー
  • メニュー：インジョルミトースト・インジョルミかき氷・インジョルミラテ・チャプサルトッポッキ・MZ風ソンピョン
  • 価格の目安：₩6,000~15,000
  • 外国人フレンドリー度：★★★★★(英語・キオスク・MZ層)

✈️ 免税店・オンライン(면세점·온라인)

コアバリュー：真空パック + 帰国土産人気No.1 + VAT還付。

  • おすすめ店舗：
  • 仁川空港(仁川空港 / 인천공항)の免税店 — 真空パック6種セット(帰国直前に受け取り)
  • 金海(金海 / 김해)・済州(済州 / 제주)空港の免税店 — 地方
  • オンライン — クーパン(クーパン / 쿠팡)、11番街(11番街 / 11번가) — 市内受け取りまたは海外配送
  • メニュー：真空パックのガレトク・ソンピョン・インジョルミ・ペクソルギ・キョンダン
  • 価格の目安：₩15,000~30,000/カン(免税店価格)
  • 外国人フレンドリー度：★★★★★(英語・イチオシ・免税)
  • VAT還付：可能

⚠ 外国人がよくやる勘違い5つ

1. 「4チャンネルはどれも同じ」：価格・雰囲気・タイミングはまったく違う。本格的＝伝統餅屋／コスパ＝市場／トレンディ＝MZカフェ／免税＝免税店。

2. 「広蔵市場＝トッポッキだけ」：広蔵市場は定番6種の餅 + トッポッキ + 市場グルメのフルセットが揃う。

3. 「MZカフェ＝トレンドだけ」：MZカフェは本格的なインジョルミ + トレンドアレンジの両方を提供する(インジョルミトーストは伝統的でもありモダンでもある)。

4. 「免税店＝高いだけ」：免税店の真空パック餅はVAT還付 + プレミアム品質 = 通常価格＋還付分のお得感。

5. 「お祝い用の餅はどこでも買える」：ペクソルギ1カン(₩30,000~80,000)は伝統餅屋やお祝い専門店への事前注文が必要。

⚙ よくある質問8つ

1. 最初の餅＝どのチャンネル：市場(広蔵・通仁)が1位(コスパ＋雰囲気)→ MZカフェ(トレンディ)。

2. インスタ・vlog向け：広蔵市場の餅通りNo.1、MZのインジョルミトースト、仁寺洞の伝統餅屋。

3. デート・記念日：市場餅(広蔵市場デート)+ MZカフェ(トレンディ)。

4. 家族連れ：伝統餅屋(お祝い・トル)+ 市場餅(コスパ)。

5. MZトレンド：MZカフェのインジョルミトースト・チャプサルトッポッキ・MZ風ソンピョン。

6. アレルギー・妊娠中：#855・#856の免責事項を参照。

7. 支払い・チップ：餅屋・免税店・MZカフェ＝カードOK／市場＝現金／チップ不要。

8. VAT還付：免税店の餅＝還付可能／通常購入＝還付不可。

⚠ 医療・安全・食事に関する免責事項

4チャンネルの餅はすべて一般的な食品。窒息リスク：ガレトクやインジョルミは子供や高齢者向けに小さく切ること。妊娠中の方はコングムル(コングムル / 콩고물、きなこ)やナッツを適量に。アレルギー(大豆・ごま・ナッツ・はちみつ)は事前にスタッフへ申告を。窒息や食中毒が疑われる場合は☎ 1339(医療、英語対応)へ連絡。本ガイドは一般的な情報提供であり、医療アドバイスではない。

食事制限の代替案：

  • ハラール・コーシャ：6種とも動物性原料を含まないためOK(はちみつの有無は要確認)。
  • ベジタリアン・ヴィーガン：6種ともベジタリアン対応(はちみつ入りの場合はヴィーガン不可)。
  • グルテンフリー：6種とも100%米製なのでグルテンフリーOK。
