首尔K-街头服饰门店8家 — 弘大·圣水·汉南·新沙的旗舰店和买手店

副标题: 弘大·合井有MUSINSA STANDARD·thisisneverthat·SAN SAN GEAR，圣水有MUSINSA EMPTY·Matin Kim·IMMIS，汉南洞有Mardi Mercredi，新沙洞有ADERERROR。只选了在Kakao地图上显示营业中、并且2026年下半年有到访评价的韩国品牌门店和买手店共8家，分成4个区域。每家店都连同日期写上了代表单品的价格、尺码标注和营业时间。

ISSUE 06 · #531 · 2026-11-24 · 首尔街头服饰购物

🎯 适合谁，为什么是这8家

这份清单是为想在店里亲自试穿、现场购买韩国品牌服装的游客准备的。首尔的街头服饰门店集中在弘大·合井 (Hongdae·Hapjeong / 홍대·합정)、圣水 (Seongsu / 성수)、汉南 (Hannam / 한남)、新沙·狎鸥亭 (Sinsa·Apgujeong / 신사·압구정)四个街区。这一篇把范围缩小到四个街区。既有品牌直营的旗舰店，也有聚集多个品牌的买手店。旧衣和古着店在古着篇#772里单独介绍。

选择标准有两个。Kakao地图 (Kakao Map / 카카오맵)的店铺信息必须是"营业中"，并且2026年下半年有博客评价或照片。动态停在2026年上半年以前的店都排除了。

⚠ 标注原则: 营业时间是店主在Kakao地图上登记的值(2026-11-24确认)。价格优先写2026-11-24在品牌官方网店打开时看到的值。官方网店页面打不开的品牌，就把博客评价里写的门店价格连同日期一起抄了下来。退税只写了到访评价里提到收银台旁有退税柜台的Matin Kim圣水店(2026-10-24评价)。附近的站和出口是Kakao地图导航的值。

退税的通用规则(适用金额、即时退税、机场手续)整理在免税购物篇#775里。结账时请出示护照。

① 弘大·合井 — 3家

弘大入口站 (Hongik Univ. / 홍대입구역)前一家大型店，合井站 (Hapjeong / 합정역)3号出口后面的Jandari-ro (잔다리로)上两家。MUSINSA STANDARD开到23:00，适合排在晚上的最后一站。Jandari-ro上的两家步行只要几分钟。

  • MUSINSA STANDARD弘大店 (MUSINSA STANDARD Hongdae / 무신사 스탠다드 홍대점) — 线上买手店Musinsa自有品牌的门店。衬衫·针织衫·西裤·西装外套这类基础款很多。Kakao地图上写着2025-11-27翻新后重新开业。官方网店上，轻薄宽松基础西装外套原价81,900韩元。2026-11-24降价60%，卖32,690韩元。折扣幅度每个时期都不一样。官方网店的尺码选项是M·L·XL·2XL。2026-11-22的博客评价写道用自助收银台结了账。每天11:00~23:00营业。地址是麻浦区 (Yanghwa-ro 144 / 양화로 144)地下1~2层，最近的站是弘大入口站 (Hongik Univ. / 홍대입구역)(2号线·机场铁路·京义中央线)9号出口，步行2分钟。圣水还有一家店，在Yeonmujang-gil 83 (연무장길 83)，每天11:00~22:00营业(Kakao地图，2026-11-24)。
  • thisisneverthat (thisisneverthat / 디스이즈네버댓) — 街头休闲品牌的弘大门店。2026-02-15的博客评价写道，弘大店翻新后重新开业。2026-10-28的博客评价(到访约在一个月前)写道，作者在店里看到T-Logo SEOUL连帽衫，价格105,000韩元。作者要了L和XL，L合身。还写道试衣间和大镜子都准备得很好。每天11:00~21:00营业。地址是麻浦区 (Jandari-ro 32 / 잔다리로 32)1层101号，最近的站是合井站 (Hapjeong / 합정역)(2·6号线)3号出口，步行7分钟。
  • SAN SAN GEAR合井旗舰店 (SAN SAN GEAR Flagship Hapjeong / 산산기어 플래그십 합정) — 卖户外风服装和包的品牌旗舰店，评价里称它是"像改造过的住宅一样的店"。2026-11-22的博客评价(11-15到访)里有REQUIEM棒球帽58,000韩元、VOID工装裤209,000韩元。只在旗舰店卖的电脑包是88,000韩元。下装尺码分为01~04。同一篇评价里，店员说01大约相当于S，02是M，03是L，04是XL。每天12:00~21:00营业。地址是麻浦区 (Jandari-ro 36 / 잔다리로 36)，最近的站是合井站 (Hapjeong / 합정역)(2·6号线)3号出口，步行7分钟。汉南洞的Itaewon-ro 55-gil 37-10 (이태원로55길 37-10)也有旗舰店(周一至周四11:00~20:00，周五至周日11:00~21:00，Kakao地图2026-11-24)。

② 圣水 — 3家

三家都在圣水站 (Seongsu / 성수역)3·4号出口步行10分钟以内。可以沿着Yeonmujang-gil (연무장길)一次逛完。IMMIS最晚，12:00才开门。

  • MUSINSA EMPTY圣水店 (MUSINSA EMPTY Seongsu / 무신사 엠프티 성수) — Musinsa运营的1~4层买手店。韩国和海外的设计师品牌、运动鞋、快闪店混在一起。2026-03的Kakao地图评论写道，有很多在韩国国内很难见到的品牌，经常办快闪。2026-11的博客评价里出现了Brooks Brothers × Eastlogue (Eastlogue / 이스트로그)快闪。官方网店的新品列表(2026-11-24)上同时有9090 logo连帽衫154,000韩元、Ohos (Ohos / 오호스)牛仔夹克188,000韩元、UNDERCOVER夹克300万韩元(特价240万韩元)。每天11:00~22:00营业。地址是城东区 (Seongsu-i-ro 97 / 성수이로 97)1~4层，最近的站是圣水站 (Seongsu / 성수역)(2号线)3号出口，步行2分钟。Kakao地图上登记了收费停车和轮椅可用。
  • Matin Kim圣水旗舰店 (Matin Kim Seongsu Flagship Store / 마뗑킴 성수 플래그십 스토어) — 卖衣服和包·钱包的品牌旗舰店。官方网店上，WASHED RIB牛仔裤是188,000韩元(2026-11-24)。尺码是S~XL。2026-11-20的博客评价里有钱包价签88,000韩元·138,000韩元·148,000韩元，还有户外咖啡厅。2026-10-24的博客评价说收银台旁有退税柜台，提示牌先写英文。每天11:00~21:00营业。地址是城东区 (Yeonmujang 3-gil 9 / 연무장3길 9)1层，最近的站是圣水站 (Seongsu / 성수역)(2号线)4号出口，步行7分钟。
  • IMMIS圣水旗舰店 (IMMIS Seongsu Flagship Store / 이미스 성수 플래그십 스토어) — 主要卖棒球帽和包的品牌的小店。有评价说帽子按颜色挂着，很好挑(2026-10-09)。官方网店上，爱心刺绣棒球帽是49,000韩元，尺码是均码。2026-11-24打折，卖39,200韩元。2026-07-14的博客评价里，大部分帽子是49,000韩元，豹纹环保袋是32,000韩元。时间是周一至周四12:00~19:30，周五至周日12:00~20:00。2024-07的Kakao地图评论里有人写道，闭店前10分钟去了，没能进去。要避开临近闭店的时间。地址是城东区 (Yeonmujang-gil 29-17 / 연무장길 29-17)1层，最近的站是圣水站 (Seongsu / 성수역)(2号线)4号出口，步行6分钟。

③ 汉南 — 1家

汉江镇站 (Hangangjin / 한강진역)一侧小巷里的店。19:00就关门，所以下午去。

  • Mardi Mercredi 1 (Mardi Mercredi 1 / 마르디 메크르디 1) — 卖带花朵图案的卫衣·针织衫的品牌在汉南洞的门店。官方网店上，LA FLEUR插肩袖卫衣是128,000韩元，尺码只有S·M两种(2026-11-24)。2026-10-15的博客评价介绍了成人服装和宠物狗服装，宠物狗服装在45,000~49,000韩元区间。Kakao地图的时间是周二至周日12:00~19:00，11/30(周一)登记为休息。2026-11-11的博客评价写道每月最后一个周一休息。同一篇评价还告知，旗舰店4号的地址不同，是Daesagwan-ro 5-gil 28 (대사관로5길 28)。地址是龙山区 (Itaewon-ro 54-gil 58 / 이태원로54길 58)1层，最近的站是汉江镇站 (Hangangjin / 한강진역)(6号线)3号出口，步行8分钟。

④ 新沙 — 1家

从林荫树路 (Garosu-gil / 가로수길)一侧的新沙站 (Sinsa / 신사역)步行前往的店。开到21:00。

  • ADERERROR新沙空间 (ADERERROR Sinsa Space / 아더에러 신사 스페이스) — 整栋楼都用上的设计师休闲品牌门店。2026-10-07的博客评价写道，作者9月初花159,000韩元买了一件短袖T恤。2026-09-13的评价里有26FW系列的单肩包，价格63万韩元。同一个品牌，T恤和包的价格差距很大。每天11:00~21:00营业。地址是江南区 (Dosan-daero 11-gil 31 / 도산대로11길 31)，最近的站是新沙站 (Sinsa / 신사역)(3号线·新盆唐线)8号出口，步行7分钟。圣水的Seongsu-i-ro 82 (성수이로 82)还有ADERERROR圣水空间(每天11:00~21:00，Kakao地图2026-11-24)。

每个区域的街区相距较远，所以一天只排一两个区域。

  1. 12:00以后 圣水站4号出口一侧的IMMIS (IMMIS / 이미스)(12:00起)
  2. 下午 Matin Kim圣水旗舰店 (Matin Kim Seongsu / 마뗑킴 성수)(到21:00)。在户外咖啡厅歇一会儿
  3. 晚上 圣水站3号出口前的MUSINSA EMPTY圣水店 (MUSINSA EMPTY Seongsu / 무신사 엠프티 성수)(到22:00)

  1. 下午 合井站3号出口后面的SAN SAN GEAR (SAN SAN GEAR / 산산기어)(12:00起)和thisisneverthat (thisisneverthat / 디스이즈네버댓)(到21:00)
  2. 晚上 弘大入口站9号出口的MUSINSA STANDARD弘大店 (MUSINSA STANDARD Hongdae / 무신사 스탠다드 홍대점)(到23:00)

汉南和新沙隔着汉江。先看Mardi Mercredi (Mardi Mercredi / 마르디 메크르디)(到19:00)，再转到ADERERROR新沙空间 (ADERERROR Sinsa Space / 아더에러 신사 스페이스)(到21:00)，这个顺序和营业时间对得上。

⚠ 3个常见失误

  1. 晚上去汉南 — Mardi Mercredi 1 (Mardi Mercredi 1 / 마르디 메크르디 1)19:00关门，11/30(周一)登记为休息。有评价说每月最后一个周一休息。汉南要排在下午。
  2. 把尺码数字当成腰围 — 店员说SAN SAN GEAR下装的01~04接近S~XL(评价2026-11-22)。Mardi Mercredi的卫衣只有S·M两种，IMMIS棒球帽是均码。同样是L，每个品牌的大小也不一样，一定要试穿。
  3. 不带护照去结账 — 退税需要在结账时出示护照。Matin Kim圣水店 (Matin Kim Seongsu / 마뗑킴 성수)在2026-10-24的到访评价里写着收银台旁有退税柜台。规则在#775里。

  1. 第一次来只去一家的话？ — 想一次看很多品牌，选MUSINSA EMPTY圣水店 (MUSINSA EMPTY Seongsu / 무신사 엠프티 성수)；想看基础款，选MUSINSA STANDARD弘大店 (MUSINSA STANDARD Hongdae / 무신사 스탠다드 홍대점)(每天到23:00)。一件西装外套的特价是32,690韩元(官方网店2026-11-24)。
  2. 晚上能去的店有哪些？ — 按登记时间，MUSINSA STANDARD弘大店 (MUSINSA STANDARD Hongdae / 무신사 스탠다드 홍대점)到23:00，MUSINSA EMPTY圣水店 (MUSINSA EMPTY Seongsu / 무신사 엠프티 성수)到22:00，thisisneverthat (thisisneverthat / 디스이즈네버댓)·SAN SAN GEAR合井店 (SAN SAN GEAR Hapjeong / 산산기어 합정)·Matin Kim圣水店 (Matin Kim Seongsu / 마뗑킴 성수)·ADERERROR新沙空间 (ADERERROR Sinsa Space / 아더에러 신사 스페이스)到21:00。
  3. 5万韩元左右的礼物？ — IMMIS棒球帽官方网店原价49,000韩元(2026-11-24)。SAN SAN GEAR棒球帽是58,000韩元(评价2026-11-22，写道很多商品已售罄)。
