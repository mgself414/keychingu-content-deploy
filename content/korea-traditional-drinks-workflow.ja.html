＃＃🍵茶道マナー6段階

韓国車道本物

1. お茶を注ぐ (Pouring): お茶ポット→グラス（小量・複数杯）

  • 両手：車の電子=両手（本物）

2. 香（Aroma）：チャザンコの近く＝香を楽しむ（5秒）

3. 味 (Taste): 最初の募金 = 口の中でしばらく留まる (舌全体の味を確認)

4. ペアリング(Pairing): お茶＋軽食（薬科・薬科・菊・松）

5. 余韻(Aftertaste): お茶を飲んだ後、香の余韻を楽しむ

6. 整理(Closing): 空のグラス = 両手で受け取る

外国人コアマナー

  • チャザン=両手: 受け取り・置きとも両手（本物）
  • サウンドX：フルルック・ジャンジャン回避（本格格式）
  • チャザンいっぱいX：お茶= 70%塗りつぶし（余白本物）

＃＃⚠外国人の頻繁なミス7つ

1. "チャザン=片手": 韓国チャド= 両手をつかむ・置く (正統)。

2. 「茶いっぱい」: 茶= 70%満ちる (余白本物)。

3. "サウンド=OK":フルルック・ジャンジャン=本物の格式回避。

4. "シクヘ=酒": シクヘ= 無アルコール発酵甘い飲み物。子ども・妊婦OK。

5. "茶=デザート後": 韓国正統=茶+薬と同時ペア(茶後デザートX)。

6. "査察車室=テンプルステイマン": 一部査察=外国人訪問者 簡単車飲用可。事前店舗確認。

7. "妊婦=すべてのお茶OK": 緑茶カフェイン・オミザ子宮収縮・ショウガ多量 注意。食恵・ナツメチャOK。

⚙ よくある質問8件

1. 初の伝統飲料=どこ:韓屋カフェ(仁寺洞・益善洞) 1順位(雰囲気+正統)。

2. インスタ・vlog：韓屋カフェ（仁寺洞vlog#1）＋寺院車室（静的）＋MZ食恵ラテ。

3. MZ トレンド: 食恵 ラテ・薬とラテ・抹茶 ラテ・修正とかき氷。

4. 妊婦: 食恵・ナツメチャ(ムカフェインOK) / 緑茶 = カフェイン適量(≤300mg/日) / オミザ・ショウガ多量 = 医療スタッフ相談。

5. ハラール・コーシャ・ベジタリアン：6種すべてアルコールX・動物材料 X = ハラル・コーシャ・ベジタリアンOK（蜂蜜含有確認）。

6. アレルギー: ナッツ・松の実・蜂蜜・シナモン・菊・オミザ事前告知。

7. 決済・チップ：韓屋・MZカフェ＝カードOK／査察＝一部現金／チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX/車の商品免税店=払い戻し可能。

⚠医療・安全・食事ダイエット

伝統的な飲み物=一般食品（医薬品X）。 妊婦カフェインガイド（WHO・KFDA）：1日≦200～300mg / 緑茶1杯約25～35mg / ナツメ茶・食恵 = ムカフェインOK / ジンジャー・シナモン・漢方財多量飲料（修正科・大秋茶）子ども＝食恵・ナツメ茶・緑茶 OK / 蜂蜜＝12ヶ月未満の乳児禁止（ボツリヌス）。食恵・糖尿病患者＝高糖分注意。アレルギー（ナッツ、松、蜂蜜、シナモン、菊、オミザ）の事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗情報免責：韓屋・査察・MZ・ホテル店舗運営変動 - 訪問前NAVER/Kakao mapまたは公式サイトを確認。
