🎯 なぜ韓国のキムバップワークフローガイドなのか

🌃 店舗タイプ別ワークフロー

Type A — コンビニエンスストア (CU・GS25・セブンイレブン・イマート24)

  • システム: ピックアップ・即席加熱(電子レンジOK)
  • メニュー: マグロ・キムチ・牛肉・MZトレンド
  • 価格：1,500〜3,500ウォン/ライン
  • 時間: 5～10分（選択＋決済）
  • 外国人親和性: ★★★★ (24h・多言語一部)

Type B — キムバップチェーン

  • システム: 店舗の食事・ピックアップ・配達
  • メニュー: マグロ・キムチ・ドンガス・製育・チーズなど多様
  • 価格：3,500〜5,500ウォン/ライン
  • 時間: 10～20分（店舗食事＋ラーメンフェア）
  • 外国人フレンドリー: ★★★★（英語メニューの一部）

Type C — 広場市場麻薬キムバプ (外国人 vlog #1)

  • システム: walk-in・売り行き・即席作り
  • メニュー: 麻薬キンバプ(ミニ) + 餃子・小キムバプ
  • 価格：2,000〜3,500ウォン/ジュール（ミニ5〜8個）
  • 時間: ジュール = 5～10分 / 食事 = 10～20分
  • 外国人親和性: ★★★★★ (vlog 1番地・インスタ)
  • お支払い：現金を推奨（小売りの一部）

Type D — 統営忠武キムバプ(本格)

  • システム: 店舗の食事・セットメニュー
  • メニュー：忠武キムバプ（簡潔）+カクドゥ+イカ無針フルセット
  • 価格：5,000〜10,000ウォン（セット）
  • 時間: 30～60分（本格的な食事）
  • 外国人親和性: ★★★★ (地域 vlog)

Type E — MZカフェ (弘大・江南・聖水)

  • システム: キオスク注文・テーブル食事
  • メニュー: チーズ・ドンガス・アボカド・卵が
  • 価格：5,000〜8,000ウォン
  • 時間: 30～60分
  • 外国人親和性: ★★★★★ (英語・MZ)

＃＃🌶外国人英語発話サンプル

  • "マグロキンバップワン" = "One tuna gimbap, please"
  • "キンバップ+ラーメンフェア" ="Gimbap and ramyeon set, please"
  • "麻薬キンバップ2行" = "Two Mayak gimbap (mini), please"
  • "もっと無駄にしてください" = "More pickled radish, please"
  • "包装です" = "To go, please"
  • "カードですか？" = "Card accepted?"

＃＃⚠外国人の頻繁なミス7つ

1. "キンバプ=日本 sushi": キンバプ=韓国正統(米+金+野菜+肉)。日本sushi（酢寿司+魚）≠。

2. "薬物=実際の薬物": 薬物=別名 ("addictive" 意味)。韓国政府の勧告=「Mayak Gimbap」の音訳。

3. 「団無地=1回」: 団無地=無料無制限リフィル(「もっとお願いします」リクエスト)。

4. "キンバプ=暖かさ": キンバプ = 冷たい食べ物 (即席キンバプはミオン)。ラーメンフェアで暖かさを補強。

5. 「広場市場=高価だけ」: 広場市場麻薬キンバップ=2,000ウォン～。コスパ ★＋インスタ。

6. 「コンビニ=味なし」: コンビニ キンバプ = コスパ+ 24h +多様。外国人入門可能。

7. "忠武キムバプ=一般キンバプ": 忠武キムバプ=統営シグネチャーセット(キンバプ+カクドゥギ+イカ無針別途)。

⚙ よくある質問8件

1. 初めてのキムバプ=どこ: コンビニ(コスパ・24h) 1順位→ 広場市場麻薬キムバップ(インスタ)。

2. インスタ・vlog: 広場市場麻薬キンバップ #1・統営忠武キムバップ・MZチーズ・ドンガスキンバプ。

3. MZ トレンド: チーズキンバップ・ドンガスキムバップ・アボカドキンバップ・卵焼きキムバプ。

4. クラシックフェア: キンバプ+ラーメン=韓国#1コンボ。

5. 苛性比：コンビニエンスストア1,500～3,500ウォン・チェーン3,500～5,500ウォン・広場2,000～3,500ウォン。

6. アレルギー: シーフード・卵・豆・ナッツ類事前告知。

7. 決済・チップ：コンビニ・チェーン・MZ = カードOK / 広場市場 = 現金 / チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

キンバプ＝即席食品（当日の摂取を推奨）。 夏＝食中毒risk↑（マヨネーズ・魚速腐敗）。妊婦・免疫低下＝即座に作ったキンバップ推奨（コンビニ＝賞味期限確認）。子供＝辛いキムチ・除育加減。アレルギー（シーフード・卵・大豆・ナッツ類）事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗・チェーン情報免責：キンバップチェーン・専門店店舗変動 — 訪問前NAVER/Kakao mapまたは公式サイト確認。

食事制限 fallback:

  • ハラール・コーシャー: 一般キンバプ=ビハラル（マグロマヨ・ブタ）。 →ベジタリアンキンバップORイテウォンの一部。
  • ベジタリアン・ビーガン：ベジタリアンキンバプ（卵・肉X）・アボカド（ビーガンOK）。マヨネーズ=ビーガンX。
  • グルテンフリー: 味付け（醤油）多。事前店舗確認。
