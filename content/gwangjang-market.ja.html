🎯 なぜ広蔵市場 (クァンジャンシジャン) 単独ガイドなのか

広蔵市場 (クァンジャンシジャン) (1905年開業) は、ソウル最古にして最大の伝統市場です。外国人観光客の動線上、韓国の市場グルメ文化を体験するのに最適な場所であり、Netflixの「ストリートフード: アジア」など多くのグローバルメディアで紹介され、外国人認知度No.1の韓国市場です。

ピンデトク (緑豆チヂミ)、マヤクキンパ (麻薬キンパ)、ユッケ (韓国風生肉)、スンデ (韓国式ソーセージ)、韓服 (ハンボク) 生地、雑貨、ヴィンテージ品など、一つの場所で深く楽しめます。外国人観光客が韓国の食文化と市場体験を一度に経験できるコースです。ISSUE 02 #24 v2 全面改訂 (2K → 7K、外国人向け情報追加)。

⚠ 外国人がよくする間違い 3つ

1. カードだけ持っていく — 決済失敗

広蔵市場 (クァンジャンシジャン) の屋台の60%以上は現金のみです。カードが使える屋台も増えていますが、信頼性は低いです。現金 ₩30,000~50,000 (約3,000~5,000円) を事前に引き出しておくことが必須です。市場入口のATMまたは鍾路5街駅 (チョンノオガヨク) 付近の銀行ATMをご利用ください。

2. ユッケ (韓国風生肉) の衛生確認をせずに注文

ユッケ (韓国風生肉) は生韓牛を使用するため、鮮度が非常に重要です。賑わっている店 (行列のできる店) を選びましょう。衛生面に不安がある外国人は、加熱調理されたメニュー (ピンデトク、スンデ、マンドゥ (餃子)) に変更することをおすすめします。夏期 (7~8月) のユッケは特に慎重に。

3. 週末のピーク時間 (12:00~14:00) に訪問

週末の12:00~14:00は、外国人観光客と韓国人家族連れでピークとなり、席が不足し、30分以上の待ち時間が発生します。平日の午前11:00~12:00または午後16:00~18:00が、比較的空いていておすすめです。

広蔵市場 (クァンジャンシジャン) の風景

広蔵市場 (クァンジャンシジャン) は、1905年に韓国初の常設市場として開業しました。日本統治時代に韓国人商人が日本人市場に対抗して作った、自主的な市場です。鍾路区 (チョンノグ) 礼智洞 (イェジドン) と鍾路5街 (チョンノオガ) に位置し、5,000以上の店舗が一つの空間に密集しています。

1階はグルメストリートで、ピンデトク (緑豆チヂミ)、マヤクキンパ (麻薬キンパ)、ユッケ (韓国風生肉)、スンデ (韓国式ソーセージ) のコーナーが中央通路沿いに並んでいます。2階は韓服 (ハンボク) 生地、精肉・串焼き、衣料品。地下はヴィンテージ品、古着、雑貨です。

Netflixの「ストリートフード: アジア」エピソード1 韓国編で、広蔵市場 (クァンジャンシジャン) とピンデトク (緑豆チヂミ) 横丁が多数紹介され、外国人認知度No.1の韓国市場となっています。「Asia 50 Best Street Food」にも毎年選出されています。

交通: 地下鉄1号線 鍾路5街駅 (チョンノオガヨク) 8番出口から徒歩3分。1号線と5号線の乗り換えが可能です。

8カテゴリー ディープダイブ

1. ピンデトク (緑豆チヂミ) 横丁 (Bindaetteok Alley) ★ 広蔵市場 (クァンジャンシジャン) No.1

  • 場所: 1階中央
  • シグネチャー: 緑豆チヂミのその場調理。韓国の市場グルメの真髄 — 外国人のインスタ映えNo.1です。
  • 価格: ₩4,000~6,000 (約400~600円) (1個あたり)
  • おすすめ: ピンデトク (緑豆チヂミ) 1個 + マッコリ (米の醸造酒、6~8度) 1杯 (₩8,000 (約800円)) = 韓国式伝統ペアリング
  • ヒント: その場調理の様子はインスタ映えするショットです。マッコリ (米の醸造酒、6~8度) を器ごと飲むのが韓国の市場文化です。

2. マヤクキンパ (麻薬キンパ) 横丁 (Mayak Gimbap Alley)

  • 場所: 2階一帯
  • シグネチャー: 指ほどの小さなキンパ (韓国風海苔巻き)。辛子+醤油ソース — 「中毒性」という意味の「麻薬」という名前がついています。Netflixの「ストリートフード」でも紹介されました。
  • 価格: ₩3,000~4,000 (約300~400円) (1本あたり)
  • おすすめ: 2~3本 + 辛子ソース、グループでシェア
  • ヒント: 外国人観光客に人気の動線No.1です。平日の午前中は比較的空いています。

3. ユッケ (韓国風生肉) 専門店 (Yukhoe / Korean Beef Tartare)

  • 場所: 中央通路
  • シグネチャー: 新鮮な韓牛 (ハヌ) を使用した伝統的なユッケ (韓国風生肉)。ごま油、ニンニク、梨、卵黄を添えて。
  • 価格: ₩15,000~25,000 (約1,600~2,600円) (1人前)
  • おすすめ: ユッケ (韓国風生肉) 1人前 + ソジュ (韓国焼酎、15~25度) 1本
  • ヒント: 衛生面が重要 — 行列のできる店を選びましょう。夏期は特に注意が必要です。

4. スンデ (韓国式ソーセージ) 横丁 (Sundae Alley)

  • 場所: 入口付近
  • シグネチャー: チャプチェ (春雨炒め) 入りスンデ (韓国式ソーセージ) + 内臓・盛り合わせ。韓国式スンデ (血のソーセージ)。
  • 価格: ₩5,000~8,000 (約500~800円) (1皿)
  • おすすめ: スンデ (韓国式ソーセージ) + 内臓盛り合わせ + 塩・胡椒のペアリング

5. トッポッキ (餅の甘辛炒め) 横丁 (Tteokbokki Alley)

  • 場所: 1階東側
  • シグネチャー: 即席トッポッキ (餅の甘辛炒め) + おでん (練り物) + 揚げ物。韓国市場のトッポッキの真髄です。
  • 価格: ₩4,000~6,000 (約400~600円) (1人前)

6. 韓服 (ハンボク) 生地市場 (Hanbok Fabric Market)

  • 場所: 2階
  • シグネチャー: 韓服 (ハンボク) の生地・完成品を購入できます。外国人向け韓服 (ハンボク) 記念品No.1です。
  • 価格: 様々 (生地1メートル ₩10,000 (約1,000円)〜 / 完成韓服 ₩200,000 (約20,000円)〜)
  • ヒント: 英語対応可能な店舗もあります。サイズ測定・オーダーメイドも可能です。

7. 雑貨・ヴィンテージコーナー (Vintage & Goods)

  • 場所: 地下
  • シグネチャー: 古着・生活用品・雑貨。ヴィンテージ好きの外国人向けNo.1です。
  • 価格: ₩5,000~50,000 (約500~5,000円)

8. 馬場洞 (マジャンドン) 精肉・串焼き (Butcher & Skewer)

  • 場所: 2階西側
  • シグネチャー: 精肉のその場焼き・串焼き。新鮮な韓牛 (ハヌ)・豚肉のその場グリル。
  • 価格: ₩10,000~20,000 (約1,000~2,000円) (1人前)

⚙ よくある質問 (FAQ)

Q1. 英語メニュー・決済は？

A. 英語メニューはほとんどありません。写真や陳列を見て指差しで注文できます。決済は現金70%・カード30% — ₩30,000~50,000 (約3,000~5,000円) を事前に引き出しておくことが必須です。

Q2. 必須の韓国語表現は？

A. 「イゴ ジュセヨ (これください)」 (This, please / 指差し) / 「マヤクキンパ トゥジュル ジュセヨ (麻薬キンパ2本ください)」 / 「マッコリ ハンジャン ジュセヨ (マッコリ1杯ください)」 / 「ポジャンヘジュセヨ (持ち帰りをお願いします)」。

Q3. 衛生・健康に関するヒントは？

A. ユッケ (韓国風生肉): 行列のできる店 (回転率 = 鮮度) を選び、夏期は注意。すべての食べ物: 手洗いが難しい場合があるため、ウェットティッシュの持参をおすすめします。食物アレルギー: 英語で店員に直接確認してください。

Q4. 1日コースのおすすめは？

A. 11:00 鍾路5街駅 (チョンノオガヨク) 8番出口 → 11:10 マヤクキンパ (麻薬キンパ) (2本) → 11:30 ピンデトク (緑豆チヂミ) + マッコリ (米の醸造酒、6~8度) → 12:00 ユッケ (韓国風生肉) → 12:30 スンデ (韓国式ソーセージ) + 市場散策 → 13:00 地下雑貨ショッピング → 13:30 鍾路 (チョンノ) 散策と組み合わせ。

Q5. 韓服 (ハンボク) 生地購入は？

A. 2階の韓服 (ハンボク) 生地市場へ。英語対応可能な店舗もあります。サイズ測定 + オーダーメイド韓服 (ハンボク) は₩200,000 (約20,000円)〜、生地1メートルは₩10,000 (約1,000円)〜。アメリカ・ヨーロッパへの配送が可能な店舗もあります。

Q6. 価格交渉は可能ですか？

A. 食べ物は定価販売のため、交渉は失礼にあたります。雑貨・生地・ヴィンテージ品は、多少の交渉が可能です (主に地下の店舗)。大幅な交渉は難しいですが、まとめ買いで₩1,000~5,000 (約100~500円) の割引が可能な場合があります。

Q7. 他の市場との比較は？

A. 広蔵市場 (クァンジャンシジャン) (#24): 1905年開業の最古・最大市場、外国人認知度No.1。

望遠市場 (マンウォンシジャン) (#25): ローカルな地元市場、観光客が少なく、ぼったくりなし。

南大門市場 (ナムデムンシジャン): 服・雑貨が中心。

東大門市場 (トンデムンシジャン): 衣料品 + ナイトショッピング。

Q8. 移動・アクセスは？

A. 地下鉄: 1号線 鍾路5街駅 (チョンノオガヨク) 8番出口から徒歩3分 / 5号線 鍾路4街駅 (チョンノサガヨク)。タクシー: 鍾路5街 (チョンノオガ) 入口までアクセス可能。車椅子でのアクセス: 1階入口はOKですが、2階・地下は階段があるため車椅子での利用は困難です。
