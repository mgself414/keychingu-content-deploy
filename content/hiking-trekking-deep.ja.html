なぜソウルで登山なのか

ソウルは都心のど真ん中に山がある数少ない大都市だ。プッカンサン(Bukhansan / 북한산)の頂上(836m)まで地下鉄でアクセスでき、インワンサン(Inwangsan / 인왕산、338m)はキョンボックン(Gyeongbokgung / 경복궁)駅から30分以内で登れる。外国人観光客にとって特徴的な点が2つある。入場料なし(国立公園内の一部文化財区域を除く)、登山観光センターで装備レンタルが可能。装備なしで来ても基本的な登山ができる。

ソウル登山観光センターはプッカンサン・カンアクサン(Gwanaksan / 관악산)・アンサン(Ansan / 안산)の3か所にある。韓国語・英語・中国語・日本語の案内、登山靴・トレッキングポール・アイゼンの少額レンタル(約5,000〜15,000ウォン/日)。2024年基準で外国人利用客が目立って増えたというメディア報道が多数ある。

外国人がよくする間違い3つ

1. 登山靴なしで頂上に挑戦

プッカンサン・カンアクサンは岩場区間が多い。スニーカーで登って滑る事故が毎年ある。登山観光センターで登山靴をレンタル(要確認)。難しければソールのグリップが良いスニーカーを最低限用意する。

2. 水・軽食の準備不足

プッカンサンのコンビニは山の下にしかない。ペグンデコース基準で最低水1L+軽食。夏の早朝出発時でも脱水に注意。

3. 下山時間の見積もりミス

「頂上から1時間で降りられるだろう」— 岩場コースはむしろ下山の方が時間がかかる。プッカンサン・ペグンデ基準で下山2〜2.5hを見込むのが安全。日没後は登山道の標識が見づらい。

各山の深掘り情報

1. プッカンサン(ペグンデ836m)

位置: ソウル・カンブク区(Gangbuk-gu)・ウンピョン区(Eunpyeong-gu)にまたがり、京畿道コヤン市にも及ぶ。プッカンサン国立公園内。

コース: クギ探訪支援センター → テナムムン → ペグンデ(往復約10km、4〜5h)。初心者はテナムムンまでで十分。

外国人fit: 国立公園公式の英語案内・地図あり。クギドン入口の登山観光センター(装備レンタル・多言語対応)。

入場: 無料(探訪路基準)。国立公園内の寺院の一部は文化財観覧料が別途かかる場合あり — 現地確認推奨。

シーズン: 春(4〜5月)つつじ、秋(10〜11月)紅葉。冬の凍結時はアイゼン必須。

安全: 頂上部の岩稜区間に注意。悪天候時は探訪路が通行止めになる。入口の案内板で現況確認。

アクセス: 3号線クパバル駅 → バス704 → クギドン入口(またはプッカンサンソン入口)。

2. インワンサン(338m)

位置: ソウル・チョンノ区(Jongno-gu)・ソデムン区(Seodaemun-gu)の境界。キョンボックンのすぐ西側。

コース: インワンサン周回路入口(チャハムントンネル付近) → 頂上(往復約4km、1〜1.5h)。ソチョン(西村)・ホンジェドンへの下山も可能。

外国人fit: ソウル都心の眺望No.1。クァンファムン(光化門)・ナムサン・プッカンサンを一つのフレームで一望できる。ただし案内標識の英語表記は部分的。

入場: 無料。

シーズン: 四季を通じてアクセス可能。春はつつじの群生。冬の積雪時は滑りやすいので注意。

安全: 岩の稜線区間が一部ある。全体的な難易度は低い。

アクセス: 3号線キョンボックン駅 → 徒歩25分 or バス7022 → インワンサン入口。

連携: 下山後はソチョンのカフェ・トンイン市場(#589 cross)。

3. カンアクサン(629m)

位置: ソウル・カンアク区(Gwanak-gu)・クムチョン区(Geumcheon-gu)、京畿道クァチョン(Gwacheon)・アニャン(Anyang)と隣接。

コース: ソウル大入口コース(ナクソンデ公園 → 頂上、往復6〜8km、3〜4h)。クァチョン側のコースもある。

外国人fit: ソウル南部の眺望。岩のスケールはプッカンサンに似ているが知名度が低く混雑しない。カンアクサン登山観光センターあり(装備レンタル・多言語案内)。

入場: 無料。

シーズン: 春・秋がベスト。夏は奇岩絶壁の新緑が壮観。冬はアイゼン必須。

安全: 稜線の岩場区間は難易度が高い。プッカンサンより岩の傾斜が急な区間がある。

アクセス: 2号線ソウル大入口駅 → 徒歩20分またはバス。

4. ソウル周回路(156km、8区間)

位置: ソウル外郭の山々の周りを一周つなぐ長距離トレッキングコース。

区間構成: 1区間スラクサン・プラムサン / 2区間ヨンマサン・アチャサン / 3区間コドク・イルチャサン / 4区間テモサン・ウミョンサン / 5区間カンアクサン / 6区間アニャンチョン / 7区間ポンサン・エンボンサン / 8区間プッカンサン。(区間ごとに12〜20km)

外国人fit: 英語公式アプリ・地図あり(ソウル市周回路アプリ)。全区間地下鉄でアクセス可能。各区間を独立して踏破できる。

入場: 無料。

シーズン: 春・秋を強くおすすめ。夏は森林区間を選ぶとよい。

アクセス: 各区間の起点は地下鉄駅から徒歩でつながる。アプリで現在地に基づいた区間へのアクセスも可能。

ヒント: 全区間踏破スタンプブック(ソウル市運営、現地配布)— 踏破認証記念品あり(要確認)。

5. チョンゲサン(オンニョボン618m)

位置: ソウル・ソチョ区(Seocho-gu)、京畿道ソンナム(Seongnam)・クァチョン・ウィワン(Uiwang)の境界。

コース: チョンゲサン入口駅 → オンニョボン(往復約6km、2〜3h)。

外国人fit: カンナムからのアクセスが良い。週末は家族連れが多い。人出の割に安心感がある。

入場: 無料。

アクセス: 新盆唐線チョンゲサン入口駅 → 徒歩15分。

6. ナムサン(262m)

位置: ソウル中心部。ミョンドン(明洞)・イテウォンの間。

コース: ミョンドン → ナムサンケーブルカー or チュンムロ駅 → ナムサン公園 → Nソウルタワー(徒歩1〜1.5h)。

外国人fit: 外国人観光の必須コース。英語・中国語・日本語の案内完備。Nソウルタワー展望台(有料)。ケーブルカー運行(有料、約9,000ウォン/片道 — 価格は現地確認推奨)。

入場: 公園は無料。タワー展望台は別途。

アクセス: 4号線ミョンドン駅3番出口 → 徒歩15分 orケーブルカー乗り場。

シーズン: 通年。夜景は夕方以降が特に美しい。

7. トボンサン(チャウンボン739m)

位置: ソウル・トボン区(Dobong-gu)、京畿道ウィジョンブ(Uijeongbu)。プッカンサン国立公園トボン地区。

コース: トボンサン駅 → チョンチュクサ → トボン主稜線 → チャウンボン(往復約8km、3〜4h)。頂上部の岩壁登攀区間は無許可者立入禁止 — 迂回路を利用。

外国人fit: プッカンサンと同じ国立公園。岩のスケールが壮観。英語案内あり。

入場: 無料。

アクセス: 1号線・7号線トボンサン駅 → 徒歩15分。

8. スラクサン(638m)

位置: ソウル・ノウォン区(Nowon-gu)、京畿道ウィジョンブ・ナミャンジュ(Namyangju)。

コース: スラクサン駅 → キチャバウィ稜線 → 頂上(往復約6km、2.5〜3.5h)。

外国人fit: 奇岩の稜線景観。プッカンサンより空いている。アクセスも便利。

入場: 無料。

アクセス: 7号線スラクサン駅 → 徒歩10分。

9〜12. その他の都心近郊の山

  • プラムサン(508m): 7号線ノウォン駅 → 徒歩+バス。スラクサンと稜線でつながる。
  • アンサン(296m): ソウル登山観光センターのアンサン支店。5号線ソデムン駅近く。ホンジェチョンと連携する周回路。
  • アチャサン(295m): 5号線アチャサン駅 → 徒歩10分。漢江の東側を一望。高句麗の堡塁遺跡地を含む。
  • テモサン・クリョンサン(293m): 3号線イルウォン駅付近。カンナムから近い短いトレッキング。

実用情報: 交通・装備・言語・安全

交通

ソウルの主要な山はほとんどが地下鉄駅から徒歩、またはバス1回でアクセスできる。T-moneyカード1枚で地下鉄+バス+乗換割引。空港でのT-money: 仁川空港第1・第2ターミナルのコンビニで即購入可能。

装備

ソウル登山観光センターでレンタル可能な品目(プッカンサン・クギドン、カンアクサン、アンサン支店):

  • 登山靴、トレッキングポール、アイゼン、レインコート(一部支店)
  • レンタル料: 約5,000〜15,000ウォン/日(価格・営業時間は訪問前に電話確認推奨)

個人で購入する場合はナムデムン市場・トンデムンのスポーツ通りで手頃な登山装備が購入できる。

言語

  • プッカンサン・カンアクサン国立公園 → 英語・中国語・日本語の案内板・地図が比較的完備
  • ナムサン → 4言語案内
  • チョンゲサン・スラクサン・プラムサン → 英語案内は部分的(韓国語の地図の併用推奨)
  • ソウル周回路 → 公式アプリが英語対応
  • ネイバー地図(Naver Map)の英語モード → 登山口検索が可能

安全

  • 緊急電話: 119(消防・救急)、112(警察)、1330(観光通訳24h)、1339(医療相談・英語)
  • 国立公園探訪路の通行止め: 気象・季節状況により一部区間が通行止めになる。入口の案内板または国立公園公団アプリで確認。
  • 夜間登山: 日没後は標識の識別が難しく事故頻度が高い。ヘッドランプなしは非推奨。
  • 雷・豪雨時: 稜線からは直ちに下山。プッカンサン・カンアクサンの頂上部は露出区間が長く落雷の危険がある。
  • 保険: 海外旅行者保険が登山中の傷害を補償するか出発前の確認を推奨。

コース1. 初心者フルセット(インワンサン+ソチョン)

  • 午前10時 — 3号線キョンボックン駅出発、インワンサン頂上(1〜1.5h)
  • 正午 — 頂上眺望後に下山、ソチョン方面
  • 午後1時 — トンイン市場弁当(#589 cross)

  • 総予算: 30,000〜60,000ウォン(交通+食事)

コース2. 中級プッカンサン(日帰り)

  • 午前7〜8時 — 3号線クパバル駅出発、バス704で移動
  • 午前8時30分 — クギドン入口、登山観光センターで装備レンタル(必要な場合)
  • 午後1時 — ペグンデ頂上(約4h所要)
  • 午後3〜4時 — 下山完了
  • 午後5時 — ウンピョン区またはホンジェドンで食事
  • 総予算: 20,000〜50,000ウォン(装備レンタル込み)

  • 総予算: 10,000〜30,000ウォン(交通+軽食)

FAQ

Q1. 外国人の初めての登山、どこから始めるべきか?

インワンサン(338m) または ナムサン(262m)。往復1〜1.5h、特別な装備不要、ソウル都心の眺望。どちらの山も地下鉄アクセスが容易。中級以上ならいきなりプッカンサン・ペグンデでもよい。

Q2. 装備がなくても登山は可能か?

可能だ。プッカンサン・カンアクサン・アンサンには登山観光センターがあり、登山靴・トレッキングポール・アイゼンを少額でレンタルできる。冬の凍結時にアイゼンなしで頂上に向かうのは非推奨。

Q3. 費用はどのくらいかかるか?

  • 山の入場: 無料
  • 装備レンタル: 5,000〜15,000ウォン/日(現地確認)
  • ケーブルカー(ナムサン): 約9,000ウォン/片道(現地確認推奨)
  • ガイド(任意): 50,000〜100,000ウォン程度(ガイド会社は別途検索推奨)
  • 交通: T-money使用、片道1,400〜2,000ウォン程度

Q4. 一番良い季節は?

春(4〜5月) つつじ・桜のシーズン、秋(10〜11月) 紅葉。この2シーズンが外国人訪問のピーク。夏は早朝出発なら可能。冬は雪景色が美しいがアイゼン必須で、体温管理が重要。

Q5. 地図・アプリのおすすめは?

  • ソウル周回路公式アプリ(英語対応) — 区間案内・スタンプ
  • 国立公園公団アプリ — プッカンサン・トボンサンの探訪路通行止め状況
  • ネイバー地図の英語モード — 登山口検索に実用的
