한국 나물 조리·한정식·사찰음식 워크플로우 — 시금치부터 봄 산나물까지

부제: 외국인 관광객용 5-step 워크플로우 + 채식 매너 + 5색 비빔밥 + 영어 발화

ISSUE 03 · #877 · 2026-06-09

🎯 왜 한국 나물 워크플로우 가이드인가

#876 나물 6종 매트릭스 알아도 — 조리·한정식·사찰음식은 별개. 한국 나물은 (a) 한정식 반찬 (무한 리필 4~6종·무료) (b) 사찰음식 코스 (정통 채식 풀세트) (c) 비빔밥 5색 (전주 정통) (d) 가정식 백반 (홈스타일 2~3종) (e) 시장 노포·MZ 한식당 (봄 산나물). 외국인은 (1) 비빔밥 5색 = 나물 풀세트 모름 (2) 사찰음식 = 오신채 X 모름 (3) 봄 산나물 매니아 모름 (4) 무한 리필 = 무료 모름. 본 가이드는 5-step + 채식 매너 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 한정식 / 사찰음식 / 비빔밥 / 가정식 / 시장 즉시 무료·채식·정통·트렌드 목적
2️⃣ 메뉴 주문 코스 / 정식 / 비빔밥 / 백반 / 1팩 1~5분 한정식·가정식 = 무료
3️⃣ 받기·세팅 나물 4~6종 + 김치·장아찌·국·밥 5~15분 무한 리필 OK
4️⃣ 먹기·페어 밥·국·고기·생선 + 나물 30~90분 비빔밥 = 비비기
5️⃣ 결제 카드 OK / 시장 = 현금 일부 / 팁 X 1~3분 사찰음식 = 별도 비용

총 소요 시간: 한정식 = 1.5~2.5h / 사찰음식 = 1.5~2h / 비빔밥 = 30분~1h / 가정식 = 30분~1h

🌿 채널별 워크플로우

Type A — 한정식 반찬 풀세트 (#837)

  • 시그니처: 나물 4~6종 무한 리필·무료 #1
  • 시간: 11:30~22:00
  • 가격: 한정식 코스 40,000~150,000원 (나물 무료)
  • 메뉴: 시금치·도라지·콩나물·고사리 등 4~6종
  • 외국인 친화도: ★★★★

Type B — 사찰음식 코스 (Temple Cuisine)

  • 시그니처: 정통 채식·오신채 X (마늘·파·달래·부추·흥거)·할랄 OK
  • 시간: 점심·저녁 (예약 권장)
  • 가격: 사찰음식 코스 25,000~80,000원/1인
  • 메뉴: 나물 6종 + 두부·버섯·산채
  • 외국인 친화도: ★★★★★ (글로벌 채식 매니아)
  • 추천: 진관사·조계사·봉은사·전국 산사 (관악산·경복궁 인근)

Type C — 전주 비빔밥 (5색 정통) (#856)

  • 시그니처: 5색 나물 풀세트 + 계란 + 고추장
  • 시간: 11:00~22:00
  • 가격: 비빔밥 = 8,000~25,000원/1인
  • 메뉴: 5색 (시금치·당근·콩나물·고사리·도라지) + 계란 + 고추장
  • 외국인 친화도: ★★★★★ (전주 정통·글로벌 인지)

Type D — 가정식 백반·MZ 한식당 (#854)

  • 시그니처: 홈스타일·나물 2~3종 무료
  • 시간: 11:00~22:00
  • 가격: 8,000~15,000원/1인
  • 메뉴: 밥+국+메인+나물 2~3종+김치
  • 외국인 친화도: ★★★★

Type E — 시장 노포 (봄 산나물)

  • 시그니처: 봄 산나물·강원·전라 정통
  • 시간: 09:00~22:00
  • 가격: 1팩 3,000~25,000원
  • 메뉴: 봄 산나물 (도라지·취·미나리·고사리)
  • 외국인 친화도: ★★★ (한국어 정통)

🍯 페어링·5색 비빔밥 매트릭스

비빔밥 5색 풀세트

  • 녹 = 시금치
  • 적 = 당근 (또는 고추장)
  • 백 = 콩나물 (또는 도라지)
  • 갈 = 고사리
  • 황 = 계란
  • + 고추장 + 참기름

나물 + 식사 페어

식사 1순위 나물 비고
한정식 코스 4~6종 풀세트 무료 #1
사찰음식 6종 + 두부·버섯 오신채 X
비빔밥 5색 풀세트 전주 #1
가정식 백반 2~3종 무료
고기 (불고기·삼겹) 시금치·콩나물 가성비
회·매운탕 콩나물·미나리 해독

🌶 외국인 영어 발화 샘플

  • "비빔밥 5색" = "5-color bibimbap with 5 vegetable sides"
  • "사찰음식 오신채 없이" = "Temple cuisine, no five pungent vegetables (no garlic·onion)"
  • "한정식 반찬 무한 리필" = "Free refills of side dishes (banchan), please"
  • "봄 산나물" = "Spring mountain vegetables (Doraji·Chwi·Minari·Gosari)"
  • "채식·비건" = "Vegan / vegetarian — but check for fish sauce·anchovy in some namul"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "나물 = 풀": 나물 = 한정식 반찬 정통·매니아.

2. "비빔밥 = 메인": 비빔밥 = 5색 나물 풀세트 (시금치·당근·콩나물·고사리·도라지).

3. "사찰음식 = 풀만": 사찰음식 = 나물 + 두부·버섯·산채·오신채 X (마늘·파).

4. "채식 = 무조건 OK": 채식 = 나물 일부 멸치 액젓 함유 가능 (사전 확인).

5. "한정식 반찬 = 비용": 한정식 반찬 = 무료 무한 리필.

6. "봄 산나물 = 사계절": 봄 산나물 (도라지·취·미나리) = 봄 3~5월 #1.

7. "전주 비빔밥 = 일반": 전주 비빔밥 = 5색 나물 정통 #1·궁중 비빔밥 cluster.

⚙ FAQ 8개

1. 첫 나물 = 어떤 채널: 전주 비빔밥 (5색 풀세트) → 한정식 반찬.

2. 인스타·vlog: 한정식 반찬·전주 비빔밥·사찰음식 진관사.

3. MZ 트렌드: 사찰음식 정통·MZ 한식당 봄 나물·5색 비빔밥.

4. 할랄·채식·비건: 6종 모두 OK·사찰음식 #1 (오신채 X·멸치액젓 확인).

5. 봄 산나물: 도라지·취·미나리·고사리 (3~5월).

6. 알레르기·임신: #876 disclaimer 참조.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

나물 = 일반 음식·식물 기반. 임신부·어린이 = OK. 알레르기 (마늘·간장 글루텐·도라지 약재·멸치 액젓 일부 첨가 사전 확인) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 OK·사찰음식 #1.
  • 채식·비건: 6종 모두 OK·멸치 액젓 첨가 일부 매장 사전 확인.
  • 글루텐 free: 간장 양념 = 글루텐 (Tamari 대체).
  • 사찰음식 (오신채 X): 마늘 양념 제외 시 OK.
