首尔东西轴① 720路巴士，从独立门到清凉里——车窗外流过的600年东西大路

副标题：南北轴是人工修出的50年直线，东西轴是首尔本来的轴——都城东西大路钟路。独立门上720路，穿西大门、光化门、钟路，东大门车窗而过，到都城外清凉里。约2小时，祭基洞下车一次，光化门·钟路·东大门不下车。

ISSUE · #1356 · 2026-09-07

🎯 定调——横向一次读懂首尔的方法

首尔南北轴(#1353)乘140路巴士，经江南大路、汉南大桥、南山1号隧道，看的是"江南是按什么顺序造出来的"。那条路修建于1969年到1976年之间。这篇的路不同。钟路 (Jongno / 종로) 自1394年汉阳定都以来，就是纵贯都城内东西方向的大路。从西门敦义门 (Donuimun / 돈의문) 到东门兴仁之门 (Heunginjimun / 흥인지문)，人、马、店铺600年来都走在这条路上。

靠地铁移动，首尔看起来像一串孤岛。景福宫前和东大门之间有什么，在地下是看不见的。这条路线在地面上穿过那段中间地带——从独立门 (Independence Gate / 독립문) 出发，坐上市内公交720，途经旧西门遗址、光化门 (Gwanghwamun / 광화문)、钟路1街到5街，车窗外望见东大门，一路到都城外的清凉里。

  • 总耗时：约2小时(乘车约45~55分钟 + 祭基洞下车15分钟 + 余裕)
  • 推荐时段：工作日上午10点出发——钟路路段早高峰结束后就有窗边座位。晚高峰(17~19点)钟路连公交专用车道也会堵
  • 坡度：无——步行区间只有平地15分钟

为何是720——一条线路串起西门·东门·东部关口

在恩平区津宽洞与东大门区踏十里(摄影所十字路口)之间往返的干线公交720，翻过毋岳岘，把独立门站 (Dongnimmun Station / 독립문역) → 西大门站 (Seodaemun Station / 서대문역) → 光化门 → 钟路1街~6街 → 东大门 → 东庙前 (Dongmyo / 동묘앞) → 新设洞 (Sinseol-dong / 신설동) → 祭基洞 → 清凉里站 (Cheongnyangni Station / 청량리역) 串成一条线。这是一条一次性穿过朝鲜都城西门(敦义门)遗址与东门(兴仁之门)，以及都城外东部关口清凉里的路线。首班车凌晨4点发车，工作日发车间隔约6~10分钟(2026年4月减班后基准·可能有变动)。

📖 故事1——钟楼下，人和马曾经走过的路：朝鲜王朝1413年把钟楼迁到现在的钟路十字路口，1440年重建时在楼上悬钟、楼下留出人马通行的空间。钟楼前的那条大街就是云从街 (Unjongga / 운종가)，意为"人如云聚的街"。作为向国家供货的代价换来专卖权的六类官许商铺六矣廛 (Yugui-jeon / 육의전) 沿这条街排开。钟阁获得"普信阁 (Bosingak / 보신각)"之名，是在1895年3月15日。如今那个位置上方，正是公交专用车道经过的地方。

🚶 路线——按车窗外的顺序

起点是地铁3号线独立门站。站在大路上，能看到一座形似凯旋门的石造门——那是1897年建成的独立门。

① 独立门站 → 独立门正面 → 720路站台 (🚶 约3分钟)

  • 出站后先正面看一眼独立门，再到统一路边的独立门站站台，乘坐开往踏十里(摄影所十字路口)方向的720路。站名以App显示为准确认。
  • 好好走一遍独立门、西大门刑务所历史馆、灵泉市场的黄昏路线另见#1357。这里只是上车。

② 灵泉市场 → 西大门站 (🚌 约4分钟·不下车)

  • 一出发，左侧车窗外就掠过独立门灵泉市场 (Dongnimmun Yeongcheon Market / 독립문영천시장) 的拱廊入口(#1357)。统一路到此为止，西大门站站台——这里正是朝鲜都城西门敦义门曾经矗立的地方。
  • 📖 故事2——从西门到东门：敦义门在1915年被朝鲜总督府以电车复线化、道路直线化为由拆除。东门兴仁之门留了下来。这辆巴士从消失的城门遗址开到留存的城门，走的正是都城的东西大路。钟路的总长度，从世宗大路十字路口到新设洞是4.2公里(2010年将兴仁之门~新设洞区间并入钟路后的基准)。

③ 贞洞十字路口 → 光化门 (🚌 约5分钟·不下车)

  • 过了西大门站，右侧车窗外掠过首尔历史博物馆 (Seoul Museum of History / 서울역사박물관) 及其后方的庆熙宫 (Gyeonghuigung / 경희궁)，左侧是敦义门博物馆村。这是已经进入都城内的信号。
  • 光化门站台。右侧车窗能看到光化门广场与尽头的光化门，后方北岳山重叠而现。这一篇不下车——景福宫、光化门广场见#141·#1244，钟路3街 (Jongno 3-ga / 종로3가) 枢纽见#1254。

④ 钟路1街 → 钟路3街 → 钟路5街 (🚌 约5分钟·不下车)

  • 钟路1街：右侧是普信阁，每年12月31日午夜敲钟的地方。钟路3街：左侧巷子里是益善洞，右侧是塔谷公园(#294·#1254)。钟路5街：右侧是广藏市场 (Gwangjang Market / 광장시장) 入口(#1257)。
  • 钟路是首尔公交站最密集的路段之一。每一站乘客上下车的节奏，本身就是这段路的风景。

⑤ 东大门 (🚌 约6分钟·车窗高潮)

  • 过了钟路6街，道路正中央出现一座城门。兴仁之门，1963年被指定为宝物的都城东门。车流从门两侧分开，左后方城墙沿骆山而上(#1340昌信洞路线走的正是它的背面)。
  • 都城到此为止。这是这一篇的高潮，但不下车——东大门购物、DDP见#172·#31·#1252。

⑥ 东庙前 → 新设洞 → 祭基洞下车 (🚌 约8分钟)

  • 兴仁之门外的王山路。过了东庙前(#049二手市场)和新设洞，道路两侧先飘来韩药材的气味。在祭基洞站 (Jegi-dong Station / 제기동역) 站台下车。

⑦ 祭基洞迷你漫步——京东市场入口15分钟 (🚶 约15分钟)

  • 从站台走到京东市场 (Gyeongdong Market / 경동시장) 入口，绕传统市场入口一圈再回来。这座市场1960年6月开业，高山子路西侧是1995年被指定为首尔药令市 (Seoul Yangnyeongsi / 서울약령시) 的韩药材街。好好走一遍市场的清晨路线是#1358——这里只尝一尝气味和声音。
  • 在同一站台再次乘坐开往踏十里方向的720路。

⑧ 清凉里站下车——收尾 (🚌 约3分钟)

  • 在下一站清凉里站下车。都城外的东部关口——1号线与京义中央线交汇、KTX停靠的车站。首尔东西轴到此结束。720路还会继续开到踏十里，但这一篇的首尔横穿在清凉里收尾。
  • 后续动线：乘1号线返回市中心，乘京义中央线到汉江边(#1248)，或转乘开往江原道的KTX。

🚌 乘车方法·座位贴士5

1. 一张卡就够：T-money或非接触式海外卡(#1298)。上车、下车都要刷卡——为了享受换乘优惠，别忘了下车刷卡。

2. 座位选右侧(南侧)靠窗：以踏十里方向为准，坐在右侧能把光化门广场、普信阁、广藏市场、兴仁之门全部收进右边车窗。

3. 下车铃在新设洞按："祭基洞站"广播(韩语·英语)播出前，经过新设洞时先按铃。

4. 快速替代方案：时间紧张的话，可乘5号线西大门站→光化门→东大门历史文化公园，或1号线东大门→清凉里，完成地铁纵贯。只是会错过钟路的车窗风景。

5. 反方向也可以：从清凉里乘坐开往津宽洞方向的720路，能正面看着兴仁之门驶入都城。傍晚反方向路线是系列扩展候选。

🙏 公交礼仪——这条路线的核心

  • 钟路站台是道路正中央的孤岛。只能走人行横道信号灯过街。
  • 钟路路段老年乘客多。前排老弱病残专座请留空，大件行李放后门附近。
  • 拍车窗照片时别让邻座乘客入镜。通话声音放低。

💡 容易懵的点

  • 站名按方向可能不同：即便是同一个十字路口，津宽洞方向和踏十里方向的站名也不一样。先在App里确认方向再按铃。
  • 钟路傍晚会堵：17~19点钟路1~5街连公交专用车道也会拥堵，行程会拉长到3小时。
  • 祭基洞只走15分钟：深入市场内部容易迷路，找不到回720路站台的路。只绕入口一圈就好。
  • 末班车·发车间隔会变：2026年4月减班后发车间隔变长。晚间请用App查看到站时间。

FAQ 6

Q1. 不是观光巴士，是普通市内公交车吗?

  • 是的。不是城市观光巴士，是首尔人每天都在坐的干线公交720。没有讲解，但车窗外就是讲解。票价也是普通市内公交票价。

Q2. 和南北轴(#1353)有什么不同?

  • 南北轴走的是1969~1976年新修的路(江南大路·汉南大桥·隧道)，东西轴走的是1394年就有的旧路(钟路)。两条连着坐，就能把首尔读成一个十字。

Q3. 不能在光化门、钟路下车吗?

  • 可以下车。只是这一篇以通过为原则，那些街区的攻略请看各自的篇章(#141·#1254·#172)。30分钟内再乘坐同方向的720路，可享换乘优惠。

Q4. 总共几站、几分钟?

  • 从独立门站到清凉里站，约15个站左右，乘车约45~55分钟(以工作日白天为基准估计)。因时段不同会有较大差异。

Q5. 兴仁之门不下车看看吗?

  • 正因为门立在道路正中央，从公交车窗看的角度反而更好。想近距离看，可以在东大门站下车往城墙方向走——#1340昌信洞路线走的正是它的背面。

Q6. 晚上坐也可以吗?

  • 可以。普信阁和兴仁之门都有夜间照明。只是这一篇是以白天的钟路节奏为基准设计的，反方向夜间路线会在扩展篇中讲述。
