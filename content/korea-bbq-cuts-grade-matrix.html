한국 BBQ 부위·등급 매트릭스 — 어떤 고기를 시킬까?

> 부제: 외국인 관광객용 돼지·소·닭 부위 12선 + 한우 등급 + 외국인 추천 우선순위

ISSUE 03 · #804 · 2026-06-07

🎯 왜 한국 BBQ 부위·등급 매트릭스인가

외국인 한국 BBQ 페인포인트 #1 = "메뉴판에 뭐가 그렇게 많아?". 한국 BBQ는 일본·미국·브라질 BBQ와 다른 부위별 차별화 문화 — 같은 돼지라도 삼겹살(Pork Belly)·목살(Pork Neck)·항정살(Pork Jowl)·갈비(Pork Rib)가 다 다른 메뉴. 한우는 1++·1+·1·2·3 등급 + 수입(미국·호주 와규) 별도. 외국인은 (a) 부위명 모르고 인기 메뉴만 시키거나 (b) 등급 차이 모르고 비싼 부위만 시키거나 (c) 가성비 부위(차돌박이·갈매기살)를 놓침. 본 가이드는 돼지 6 + 소 6 + 닭 3 + 한우 등급 + 외국인 추천 우선순위 매트릭스.

🏆 한우 등급 시스템

한우 등급 5단계

등급 마블링 가격 (꽃등심 100g) 외국인 추천
1++ 최상급 (마블링 7~9 BMS) 50,000~80,000원 럭셔리·비즈니스 (★★★★★)
1+ 상급 (BMS 6) 35,000~50,000원 외국인 입문 1순위 (★★★★★)

3 낮음 (BMS 1) 15,000~20,000원 비추 (가공·국거리용 多)

수입 와규·미국·호주

  • 미국 와규 (US Wagyu) — 한우 1+ 와 비슷 가격, 마블링 ↑ — 강남 일식·BBQ 일부
  • 호주 와규 (Australian Wagyu) — 가성비 ★★★ (한우 1 대비 70~80%)
  • 미국·호주 등심 (US/AUS Choice·Prime) — 한우 2~3 등급 대비 1.5배 가격

돼지 등급 — 한돈

  • 한돈 (Korean Pork) = 국산 돼지, 1+·1·2 등급 (한돈자조금 운영, 한우와 달리 1++ 없음)
  • 수입 돼지 (스페인·캐나다·칠레 등) = 가성비 ★★★ (한돈 대비 60~70%)
  • 이베리코 (Iberico, 스페인) = 흑돼지 (Bellota 등급은 100% 도토리 사료, 일반 이베리코는 곡물 혼합), 1인분 25,000~40,000원 (특별 메뉴)

> 안전 원칙: 돼지·닭 = well-done 필수 (식중독·살모넬라 리스크). 소(한우·와규)는 medium 가능.

⚠ 외국인 자주 실수 5가지

1. "삼겹살 = 모든 돼지": 삼겹살(belly)은 한 부위. 목살·항정살·갈매기살은 다른 부위·다른 가격·다른 식감.

2. "한우 = 모두 비쌈": 한우 2등급 차돌박이 = 28,000원/100g 가성비 OK. 1++ 1++ 등심 80,000원 vs 한우 1+ 꽃등심 50,000원 = 1+ 입문이 최적.

3. "수입 = 무조건 한우보다 못함": 미국·호주 와규는 한우 1+와 비슷 품질. 가격 70~80%. 가성비 ★

4. "메뉴판 영문 = 다 같은 것": "Beef Ribeye" 표기 = 한우·미국·호주 모두 가능. 원산지·등급 확인 필수.

5. "굽기 = 무조건 well-done": 차돌박이(30초·얇음) / 꽃등심(2~3분·medium) / 항정살(5분 천천히) — 부위별 다름.

⚙ FAQ 8개

1. 외국인 입문 1순위: 삼겹살 (#1) + 차돌박이 (#2) + 한우 1+ 꽃등심 (#3). 3종 묶음 추천.

2. 가성비 부위 Top 3: 차돌박이 (소) + 갈매기살 (돼지) + 닭갈비 (닭)

3. 럭셔리 부위 Top 3: 한우 1++ 안심 + 한우 1++ 꽃등심 + 이베리코 (스페인 흑돼지)

4. 매운맛 옵션: 양념갈비·매운갈비·닭갈비·고추장 양념·청양고추 곁들임

5. 채식·할랄·코셔: BBQ = 원천 비할랄·비코셔·비채식. 채식 fallback = 콩나물국밥·비빔밥·각종 나물 (다른 메뉴)

6. 알레르기: 소·돼지·닭 + 양념(마늘·간장·고추장·꿀) 사전 고지. 글루텐 = 양념에 간장(밀) 포함 多

7. 결제·팁: 카드 OK·팁 문화 없음. 일부 호텔 BBQ는 봉사료 10% 별도

8. 점심 vs 저녁: 점심 특선 (lunch course) 30~50% 저렴, 저녁은 분위기·1차 회식 多

⚠ 의료·안전·식이 disclaimer

BBQ = 직접 조리. 고기 적절한 조리(돼지 well-done·소 medium 이상) 필수. 임신부·면역저하 = 더 익혀서 (well-done). 알레르기 (소·돼지·닭·양념 마늘·간장 + 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 한국 BBQ 매장은 할랄·코셔 인증 미보유. → 한식 외 일반 식당 분리 권장. 이태원·강남 일부 할랄 인증 BBQ 매장 예외 (Eid·Makan·Halal Korean BBQ 등 사전 검색·예약).
  • 채식·비건: BBQ = 육류 중심. → 비빔밥·콩나물국밥·사찰음식 별도 추천 (다른 매장)
  • 이슬람·유대·힌두: 종교적 식이 = 사전 매장 확인 권장

💰 Essential Tourist Tips

  • 1인 평균 예산 (2026년 6월 기준, 시세 변동 가능):
  • 가성비 = 30,000~50,000원 (돼지 삼겹살·차돌박이)
  • 일반 = 50,000~80,000원 (한우 1+ + 양념갈비)
  • 럭셔리 = 100,000~200,000원 (한우 1++ + 와규 + 와인)
  • 음료·술 문화:
  • 소주 4,000~6,000원 / 맥주 4,000~8,000원 / 와인 30,000~100,000원 / 사이다·콜라 2,000~3,000원
  • 소맥 (소주+맥주 폭탄주) = 한국 BBQ 회식 문화 #1, 외국인 호기심 ★. 비율 1:3 또는 1:2. 폭탄주 강요는 거부 OK (1잔만 시도 권장)
  • 어린이 안전: 6세 미만 = 매운 양념·생고기 비추천. 미디엄·웰던 고기 + 쌈 + 밥 권장. 철판·숯불 화상 주의 (어린이 동반 매장 = 가족 좌석 사전 요청)
  • 점심 특선: 평일 11:30~14:00 = 30~50% 할인 (회식 시간 외)
  • 결제: 카드 OK / 팁 X / 호텔 일부 봉사료 10%
  • VAT 환급: 식음료 일반 환급 대상 아님
