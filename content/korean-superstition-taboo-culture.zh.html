韩国 (Hanguk / 한국) 迷信 (Misin / 미신)·禁忌文化 (Geumgi Munhwa / 금기 문화) — 在韩国 (Hanguk / 한국) 不经意间做了会让气氛变冷的行为

> 数字4·红色名字·电风扇死亡说·考试海带汤·送鞋·双手递接礼仪 (Susu Yebbeop / 수수 예법) — 专为外国人准备的韩国 (Hanguk / 한국) 迷信 (Misin / 미신)·禁忌 (Geumgi / 금기) 解释。包含“为何是禁忌”+“应该如何做”的内容。

准备韩国 (Hanguk / 한국) 旅行的人，有一个意想不到却不甚了解的方面。在韩国 (Hanguk / 한국)，有些行为外国人 (Oegugin / 외국인) 并非恶意，却可能让对方感到些许不适。比如用红笔写朋友的名字，出于好意赠送一双漂亮的鞋子，或者单手递名片给长辈等。韩国人 (Hangugin / 한국인) 通常会一笑置之，但如果能提前了解并避免，就能给人留下“这个人对韩国 (Hanguk / 한국) 文化 (Munhwa / 문화) 有所了解”的好印象。本文将这些迷信 (Misin / 미신)·禁忌 (Geumgi / 금기) 并非作为“可怕的规则”，而是从为何产生、现代韩国人 (Hangugin / 한국인) 对其认真程度如何、外国人 (Oegugin / 외국인) 只需要注意什么的角度，进行实用性的解读。这是韩国文化 (Hanguk Munhwa / 한국 문화) 解释系列 (Explainer Series) 的第8篇。

> 首先要指出：这里提到的很多都是迷信 (Misin / 미신) (superstition)。大多数现代韩国人 (Hangugin / 한국인) 只是将其视为半开玩笑或“仅仅是习俗”来遵守。与其说是真心相信，不如说是“没必要制造不愉快，所以不去做”。相反，像递接礼仪 (Susu Yebbeop / 수수 예법) (双手) 这样并非迷信 (Misin / 미신) 而是至今仍在沿用的真正礼仪 (Yebbeop / 예법) 的情况也混杂其中——下文将进行区分和标注。

⚠️ 外国人 (Oegugin / 외국인) 经常误解的3件事

1. “韩国人 (Hangugin / 한국인) 都相信迷信 (Misin / 미신)” ❌ — 大多数人将其视为半开玩笑，半是习俗 (Gwansseup / 관습)。红色笔 (Ppallgan Pen / 빨간 펜) 或4楼 (4 Cheung / 4층) 左右会介意，但像夜晚剪指甲 (Sontop Kkakgi / 손톱 깎기)·吹口哨 (Hwiparam / 휘파람) 这样的现在几乎是玩笑。无需过度紧张——只需避免几项就足够。

2. “迷信 (Misin / 미신) 和礼仪 (Yebbeop / 예법) 是一回事” ❌ — 双手递接 (Du Son Geonnegi / 두 손 건네기) 并非迷信 (Misin / 미신)，而是至今仍在沿用的真正礼仪 (Yebbeop / 예법) (尤其对长辈 (Wit Saram / 윗사람))。相反，电风扇死亡说 (Seonpunggi Samangseol / 선풍기 사망설) 是科学上错误的迷信 (Misin / 미신)。可以将两者区分对待。

3. “犯错 (Silsu / 실수) 就会有大麻烦” ❌ — 韩国人 (Hangugin / 한국인) 几乎不会因为外国人 (Oegugin / 외국인) 不知情而犯的错误 (Silsu / 실수) 而生气。反而会说“外国人 (Oegugin / 외국인) 可能不了解” 并放过。重要的是，比起道歉，下次能了解并避免。

① 不要用红色写名字 (Ireum / 이름) — 最有名的禁忌 (Geumgi / 금기)

在韩国 (Hanguk / 한국)，用红色写人名 (Saram Ireum / 사람 이름) 是最广为人知的禁忌 (Geumgi / 금기)。即使是像用红笔 (Ppallgan Pen / 빨간 펜) 在朋友 (Chingu / 친구) 笔记本 (Noteu / 노트) 上写名字 (Ireum / 이름) 这样的小事，也可能让看到的人感到不适。

  • 为什么？ 在韩国 (Hanguk / 한국)，红色 (Ppallgansaek / 빨간색) 传统上与死亡 (Jeum / 죽음) 相关联。这是因为祭祀桌 (Jesa Sang / 제사상) 上的牌位 (Wipae / 위패)、讣告 (Bugo / 부고)·葬礼 (Jangnye / 장례) 花圈 (Hwahwan / 화환) 上的逝者名字 (Goin Ireum / 고인 이름) 等都习惯用红色 (Ppallgansaek / 빨간색) 书写。因此，产生了“用红色 (Ppallgansaek / 빨간색) 写活人 (San Saram / 산 사람) 的名字 (Ireum / 이름) 不吉利”的观念。
  • 起源说之一：也有说法称，韩国战争 (Hanguk Jeonjaeng / 한국전쟁) 时，为了区分阵亡者 (Jeonsaja / 전사자) 和幸存者 (Saengjonja / 생존자)，阵亡者 (Jeonsaja / 전사자) 的名字 (Ireum / 이름) 用红色 (Ppallgansaek / 빨간색) 书写 (多种说法之一——并非确定的定论)。
  • 现代 (Hyeondae / 현대) 观念：几乎没有人真心相信“会死”，但“让人不舒服所以不去做” 的情绪 (Jeongseo / 정서) 依然强烈。在官方文件 (Gongsig Munseo / 공식 문서)·留言簿 (Bangmyeongnok / 방명록)·祝贺卡 (Chukha Kadeu / 축하 카드) 上写某人的名字 (Ireum / 이름) 时，请使用黑色 (Geomjeong / 검정) 或蓝色 (Parang / 파랑) 笔。
  • 例外：本人的印章 (Dojang / 도장) (印鉴 (Ingam / 인감)) 的红色 (Bulgeun / 붉은) 印泥 (Inju / 인주) 是可以的——这是代替签名 (Seomyeong / 서명) 的传统 (Jeontong / 전통)，属于例外。

> ✅ 外国人 (Oegugin / 외국인) 实战提示：需要写名字 (Ireum / 이름) 时，直接用黑色 (Geomjeong / 검정) 或蓝色 (Parang / 파랑) 笔。只要遵守这一点，就能避免大错。

② 礼物 (Seonmul / 선물) 禁忌 (Geumgi / 금기) — 鞋子 (Sinbal / 신발)·刀具 (Kal / 칼)·剪刀 (Gawi / 가위)·手帕 (Sonsugeon / 손수건)

出于好意赠送的礼物 (Seonmul / 선물) 可能会被解读出与原意完全相反的信息。不过，这也很大程度上取决于对方 (Sangdae / 상대) 和关系 (Gwangye / 관계)，有时也会被轻松带过。

  • 鞋子 (Sinbal / 신발) 👟 — 源于“穿上新鞋 (Sae Sinbal / 새 신발) 就会远走高飞” 的联想，尤其在恋人 (Yeonin / 연인)·暧昧关系 (Sseom / 썸) 之间，送鞋 (Sinbal / 신발) 意味着对方会离开的迷信 (Misin / 미신)。也有说法称，如果真心想送，可以采取让收礼人 (Batneun Saram / 받는 사람) 象征性地支付少量金钱 (Don / 돈) (例如：硬币 (Dongjeon / 동전))，“购买”的形式，这样可以化解厄运 (Aekttaem / 액땜)。
  • 刀具 (Kal / 칼)·剪刀 (Gawi / 가위) ✂️ — 被解读为“切断关系 (Gwangye / 관계)”，因此避免作为礼物 (Seonmul / 선물)。
  • 手帕 (Sonsugeon / 손수건) — 因联想到悲伤 (Seulpeum / 슬픔)·离别 (Ibyeol / 이별) (擦眼泪 (Nunmul / 눈물))，有时也被列为礼物 (Seonmul / 선물) 禁忌 (Geumgi / 금기) 品。
  • 数字4 (Sa / 사) 套装 — 避免赠送4件 (4 Gae / 4개) 묶音的礼物 (Seonmul / 선물) (4=死 (Sa / 사)，见下文④)。

> ✅ 外国人 (Oegugin / 외국인) 实战提示：稳妥的礼物 (Seonmul / 선물) 是零食 (Gansik / 간식)·甜点 (Dijeoteu / 디저트)·水果 (Gwail / 과일) 礼盒 (Seonmul Seteu / 선물세트)·化妆品 (Hwajangpum / 화장품)·高级茶 (Gogeup Cha / 고급 차)/咖啡 (Keopi / 커피)。写名字卡 (Ireum Kadeu / 이름 카드) 时 (①) 禁用红笔 (Ppallgan Pen / 빨간 펜)。

③ 双手递接 (Du Son Euro Jugobatgi / 두 손으로 주고받기) — 这不是迷信 (Misin / 미신) 而是“真正的礼仪 (Yebbeop / 예법)”

与上述项目不同，这不是迷信 (Misin / 미신)，而是至今仍在强烈沿用的礼仪 (Maeneo / 매너)。这也是外国人 (Oegugin / 외국인) 最常忽略，却最能有效加分的要点。

  • 规则 (Gyuchik / 규칙)：在面对长辈 (Wit Saram / 윗사람)·初次见面 (Cheoeum Mannan Saram / 처음 만난 사람) 的人·正式场合 (Gyeoksik Itneun Jari / 격식 있는 자리) 时，递交 (Juda / 주다) 或接收 (Batda / 받다) 物品 (Mulgeon / 물건) (名片 (Myeongham / 명함)·礼物 (Seonmul / 선물)·杯子 (Jan / 잔)·卡片 (Kadeu / 카드)) 时，要用双手 (Du Son / 두 손)。
  • 实战动作 (Siljeon Dongjak / 실전 동작)：用一只手 (通常是右手 (Oreunson / 오른손)) 拿着物品 (Mulgeon / 물건)，另一只手 (Dareun Son / 다른 손) 轻轻托住那只手臂 (Pal / 팔) 的手腕 (Sonmok / 손목) 或前臂 (Paltuk / 팔뚝)。给人一种恭敬地双手递交的感觉即可。
  • 尤其在酒席 (Suljari / 술자리)：长辈 (Eoreun / 어른) 倒的酒杯 (Suljan / 술잔) 要用双手 (Du Son / 두 손) 接收，给长辈 (Eoreun / 어른) 倒酒时也要用双手 (Du Son / 두 손)。 (喝酒时稍微侧头 (Gogae / 고개) 也是礼仪 (Yeui / 예의))
  • 为什么？ 在儒教 (Yugyo / 유교) 文化 (Munhwa / 문화) 中，这是通过手部动作 (Son Dongjak / 손동작) 表达对对方 (Sangdae / 상대) 尊重的态度 (Jonjunghaneun Taedo / 존중하는 태도)。单手随意递交可能会被解读为“缺乏诚意 (Seongui Eopda / 성의 없다)·无礼 (Muryehada / 무례하다)”。

> ✅ 外国人 (Oegugin / 외국인) 实战提示：在咖啡馆 (Kape / 카페) 递卡 (Kadeu / 카드) 时，在餐厅 (Sikdang / 식당) 接杯子 (Jan / 잔) 时，从某人那里接名片 (Myeongham / 명함) 时——用双手 (Du Son / 두 손)。这是韩国人 (Hangugin / 한국인) 最快感受到“有礼貌 (Yeui Bareuda / 예의 바르다)”的行为。

④ 数字4 (Sutja 4 / 숫자 4) — ‘四 (Neok Sa / 넉 사)’与‘死 (Jugeul Sa / 죽을 사)’

在韩国 (Hanguk / 한국) (以及整个东亚地区 (Dongasia Jiyeok / 동아시아 지역))，有避免数字4 (Sutja 4 / 숫자 4) 的倾向。

  • 为什么？ 因为汉字四 (Neok Sa / 넉 사) 的发音与死 (Jugeul Sa / 죽을 사) 相同。这是一种同音异义词 (Dong-eum-i-ui-eo / 동음이의어) 禁忌 (Geumgi / 금기)。
  • 在哪里可以看到？ 在医院 (Byeongwon / 병원)·公寓 (Apateu / 아파트)·电梯 (Ellibeiteo / 엘리베이터) 中，4楼 (4 Cheung / 4층) 会被标记为‘F’，或者有些地方会避开4·14·24号房 (Hosill / 호실)。如果电梯 (Ellibeiteo / 엘리베이터) 按钮上看到F而不是4，就是这个原因。
  • 现代 (Hyeondae / 현대) 观念：与西方的“13恐惧症”类似。与其说是认真恐惧，不如说是“既然没有非用4不可的理由，就避开” 的习俗 (Gwansseup / 관습)。在房号 (Hosill / 호실)·礼物 (Seonmul / 선물) 数量 (Gaesu / 개수) 中出现4时，会稍微介意一下。

> 外国人 (Oegugin / 외국인) 即使被分配到4楼 (4 Cheung / 4층) 的酒店 (Hotel / 호텔) 房间 (Bang / 방) 也完全没问题——介意的人会自行选择F楼 (F Cheung / F층)/其他房号 (Hosill / 호실)。

⑤ 电风扇死亡说 (Seonpunggi Samangseol / 선풍기 사망설) — 韩国 (Hanguk / 한국) 独有的认真“现代 (Hyeondae / 현대) 迷信 (Misin / 미신)”

外国人 (Oegugin / 외국인) 最感到新奇的迷信 (Misin / 미신)。即“在门窗紧闭的房间里开着电风扇 (Seonpunggi / 선풍기) 睡觉可能会死亡 (Jukda / 죽다)” 的说法。

  • 主张 (Jujang / 주장)：电风扇 (Seonpunggi / 선풍기) 会吸走氧气 (Sanso / 산소)/降低体温 (Cheonon / 체온)，导致在密闭空间 (Milpye Gonggan / 밀폐 공간) 中窒息 (Jilsik / 질식)·低温 (Jeocheonon / 저체온) 危险等。
  • 科学事实 (Gwahakjeok Sasil / 과학적 사실)：已被证实为假。在普通家庭 (Gajeong / 가정) 环境 (Hwangyeong / 환경) 中，没有证据表明电风扇 (Seonpunggi / 선풍기) 会导致死亡 (Samang / 사망)。
  • 为何传播 (Wae Peojyeotna / 왜 퍼졌나)：对电动电风扇 (Jeongi Seonpunggi / 전기 선풍기) 的担忧可以追溯到1920年代的报纸 (Sinmun / 신문) 报道 (Gisa / 기사) (警告新技术 (Sae Gisul / 새 기술) 的风险)，此后被媒体 (Eollon / 언론) 长期再生产。也有说法称，1970年代能源危机 (Eneoji Wigi / 에너지 위기) 时，政府 (Jeongbu / 정부) 为了减少用电 (Jeongi Sayong / 전기 사용) 而推波助澜 (说法——并非确定)。
  • 现代 (Hyeondae / 현대) 观念：尽管如此，仍然有不少人认真相信。 这也常被提及为韩国 (Hanguk / 한국) 电风扇 (Seonpunggi / 선풍기) 普遍配备定时器 (Taimer / 타이머) 的原因。外国人 (Oegugin / 외국인) 没必要非得争辩“那不是真的”——只需将其视为一种文化 (Munhwa / 문화) 了解即可。

⑥ 考试 (Siheom / 시험)·吉凶 (Gilhyung / 길흉) 迷信 (Misin / 미신) — 海带汤 (Miyeokguk / 미역국) 禁忌 (Geumji / 금지)，麦芽糖 (Yeot / 엿)·糯米糕 (Chapssealtteok / 찹쌀떡) OK

韩国 (Hanguk / 한국) 的考试文化 (Siheom Munhwa / 시험 문화) 牢牢地与食物迷信 (Eumsik Misin / 음식 미신) 结合在一起。在高考 (Sunung / 수능) (大学修学能力考试 (Daehak Suhagnungnyeok Siheom / 대학수학능력시험)) 季 (Sijeun / 시즌) 尤为突出。

  • 海带汤 (Miyeokguk / 미역국) 禁忌 (Geumji / 금지) 🥣 — 考试 (Siheom / 시험) 当天早上 (Dangil Achim / 당일 아침) 不喝海带汤 (Miyeokguk / 미역국)。因为海带 (Miyeok / 미역) 滑溜溜的，联想到“考试 (Siheom / 시험) 会滑倒 (Mikkureojinda / 미끄러진다) (落榜 (Tteoreojinda / 떨어진다))”。生日 (Saengil / 생일) 必喝的海带汤 (Miyeokguk / 미역국) 在考试 (Siheom / 시험) 日 (Nal / 날) 却成了禁忌食物 (Geumgi Eumsik / 금기 음식)，这是其特点。
  • 麦芽糖 (Yeot / 엿)·糯米糕 (Chapssealtteok / 찹쌀떡) OK 🍬 — 相反，粘性好 (Kkeuneojakhage Jal Butneun / 끈적하게 잘 붙는) 的麦芽糖 (Yeot / 엿) 和糯米糕 (Chapssealtteok / 찹쌀떡) 是幸运食物 (Haengun Eumsik / 행운 음식)。韩语 (Hangugeo / 한국어) “붙다 (Butda / 붙다)” 既有(粘住) + (考试 (Siheom / 시험) 合格 (Hapgyeokhada / 합격하다)) 两种意思，因此作为“考试 (Siheom / 시험) 顺利通过” 的鼓励 (Eungwon / 응원)，会送给考生 (Suheomsaeng / 수험생)。
  • 送叉子 (Pokeu / 포크) 🍴 — 也有人送叉子 (Pokeu / 포크)，寓意“准确地选中答案 (Jeongdap / 정답)” (谐音梗鼓励 (Maljangnan Eungwon / 말장난 응원))。
  • 喜鹊 (Kkachi / 까치) vs 乌鸦 (Kkamagwi / 까마귀) 🐦 — 喜鹊 (Kkachi / 까치) 鸣叫被认为是有喜事 (Bangaun Sonnim / 반가운 손님) 来临的吉兆 (Giljo / 길조)，而乌鸦 (Kkamagwi / 까마귀) 因其黑色 (Geomjeongsaek / 검정색)·叫声 (Ureumsori / 울음소리) 而被视为凶兆 (Hyungjo / 흉조)。(乌鸦 (Kkamagwi O / 까마귀 오) 的发音与“恶 (Nappeul O / 나쁠 오)”相似也被认为是原因之一)。但是，乌鸦 (Kkamagwi / 까마귀) 也是高句丽 (Goguryeo / 고구려) 三足乌 (Samjok-o / 삼족오) 那样太阳 (Taeyang / 태양)·神性 (Sinseong / 신성) 的象征，并非一概而论的坏鸟。
  • 猪梦 (Dwaejikkum / 돼지꿈) = 吉梦 (Gilmong / 길몽) 🐷 — 梦到猪 (Dwaeji / 돼지) 是财运 (Jaemulun / 재물운) 的代表性吉梦 (Gilmong / 길몽)。梦到猪 (Dwaeji / 돼지) 后买彩票 (Bokgwon / 복권) 的情景 (Punggyeong / 풍경) 很常见。

> ✅ 外国人 (Oegugin / 외국인) 备注：如果韩国 (Hanguk / 한국) 朋友 (Chingu / 친구) 即将考试 (Siheom / 시험)，可以送麦芽糖 (Yeot / 엿)·糯米糕 (Chapssealtteok / 찹쌀떡)·巧克力 (Chokollit / 초콜릿)。作为“顺利通过”的鼓励 (Eungwon / 응원) 再合适不过了——海带汤 (Miyeokguk / 미역국) 只需在那天避免。

⑦ 生活 (Saenghwal / 생활) 中的小禁忌 (Jageun Geumgi / 작은 금기) — 指甲 (Sontop / 손톱)·口哨 (Hwiparam / 휘파람)·门槛 (Munjibang / 문지방)

大部分现在几乎是玩笑水平，但在长辈 (Eoreun / 어른) 面前或传统 (Jeontong / 전통) 空间 (Gonggan / 공간) 中，稍微记住一下会比较好。

  • 夜晚剪指甲 (Sontop Kkakgi / 손톱 깎기)·脚趾甲 (Baltop / 발톱) ✂️ — 晚上 (Bam / 밤) 剪指甲 (Sontop / 손톱) 会带来厄运 (Burun / 불운) 的古老迷信 (Yet Misin / 옛 미신)。(也有解释称，这是为了防止在没有电灯 (Jeongi / 전기) 的时代 (Sijeol / 시절)，在黑暗中剪指甲 (Sontop / 손톱) 容易受伤的实用性警告 (Sillyongjeok Gyeonggo / 실용적 경고) 演变为迷信 (Misin / 미신))。
  • 夜晚吹口哨 (Hwiparam Bulgi / 휘파람 불기) 🎵 — 晚上 (Bam / 밤) 吹口哨 (Hwiparam / 휘파람) 会招来鬼 (Gwishin / 귀신) (或蛇 (Baem / 뱀)) 的迷信 (Misin / 미신)。现在 (Yojeum / 요즘) 的年轻人 (Jeolmeun Cheung / 젊은 층) 几乎不介意。
  • 踩门槛 (Munjibang Balgi / 문지방 밟기) 🚪 — 踩门槛 (Munjibang / 문지방) 会带来厄运 (Burun / 불운) 的禁忌 (Geumgi / 금기)。这源于将门槛 (Munjibang / 문지방) 视为阳间 (Iseung / 이승) 与阴间 (Jeoseung / 저승) 的边界 (也有蒙古 (Monggol / 몽골) 入侵时期起源说)。在韩屋 (Hanok / 한옥) (韩国 (Hanguk / 한국) 传统房屋)·古宅 (Gotaek / 고택)·长辈 (Eoreun / 어른) 家中，不踩门槛 (Munjibang / 문지방) 而是跨过去是礼仪 (Yeui / 예의)。
  • 抖腿 (Dari Tteolgi / 다리 떨기) 🦵 — 长辈 (Eoreun / 어른) 会不喜欢，认为“福气 (Bok / 복) (财物 (Jaemul / 재물)) 会流失”。半是迷信 (Misin / 미신)，半是礼仪 (Maeneo / 매너)。

> 这些项目 (Hangmok / 항목) 即使外国人 (Oegugin / 외국인) 不了解而犯错 (Silsu / 실수)，也几乎不会有问题。 只有在与长辈 (Eoreun / 어른) 一同前往传统空间 (Jeontong Gonggan / 전통 공간) 时，稍微注意一下就足够了。

⑧ 为什么会产生这些迷信 (Misin / 미신) — 三个根源

大多数韩国 (Hanguk / 한국) 迷信 (Misin / 미신) 并非随机，而是有其内在逻辑。这也是外国人 (Oegugin / 외국인) 最感兴趣的要点之一。

1. 汉字同音异义词 (Hanja Dong-eum-i-ui-eo / 한자 동음이의어) (文字游戏 (Maljangnan / 말장난))：最大的一个方面。4 (四 / Sa)=死 (死 / Sa)，海带 (Miyeok / 미역) (滑溜 / Mikkureom)=考试 (Siheom / 시험) 滑倒 (Mikkureojim / 미끄러짐)，粘住 (Butda / 붙다)=合格 (Hapgyeok / 합격) — 发音 (Bareum / 발음)·意思 (Tteut / 뜻) 重叠导致吉凶 (Gilhyung / 길흉) 分化。这是汉字文化圈 (Hanja Munhwagwon / 한자 문화권) 特有的思维方式，即意义 (Uimi / 의미) 随着声音 (Sori / 소리) 转移。

2. 儒教 (Yugyo / 유교) 秩序 (Jilseo / 질서)·礼仪 (Yebbeop / 예법)：双手递接 (Du Son Susu / 두 손 수수)·尊敬长辈 (Eoreun Gonggyeong / 어른 공경)·门槛 (Munjibang / 문지방) 礼仪 (Yeui / 예의) 等与其说是迷信 (Misin / 미신)，不如说是区分上下 (Sangha / 상하)·内外 (Naeoe / 내외) 的儒教 (Yugyo / 유교) 礼仪 (Maeneo / 매너) 固化于生活 (Saenghwal / 생활) 之中。

3. 历史 (Yeoksa / 역사)·实用 (Sillyong / 실용) 的痕迹：像红色名字 (Ppallgan Ireum / 빨간 이름) (葬礼 (Jangnye / 장례) 标记)，夜晚剪指甲 (Bam Sontop Kkakgi / 밤 손톱 깎기) (没有照明 (Jomyeong / 조명) 时代的 (Sijeol / 시절) 安全警告 (Anjeon Gyeonggo / 안전 경고)) 等，是过去的实际情况 (Silje Sanghwang / 실제 상황) 随着时间 (Sigan / 시간) 流逝，披上了“迷信 (Misin / 미신)”外衣的情况。

也就是说，韩国 (Hanguk / 한국) 迷信 (Misin / 미신) 更像是文字游戏 (Eoneoyuhi / 언어유희) + 儒教 (Yugyo / 유교) 礼仪 (Yebbeop / 예법) + 古老生活 (Yet Saenghwal / 옛 생활) 智慧 (Jihye / 지혜) 混合而成的文化 (Munhwa / 문화) 化石。与其说是“不合逻辑 (Binonrijeok / 비논리적)”，不如说是“了解原因 (Wae Geureonji Almyeon / 왜 그런지 알면) 就能理解 (Napdeukdoeneun / 납득되는)”的。

❓ 外国人 (Oegugin / 외국인) 常见问题 (FAQ — 犯错 (Silsu / 실수) 时)

  • 不小心用红笔 (Ppallgan Pen / 빨간 펜) 写了朋友 (Chingu / 친구) 的名字 (Ireum / 이름)。严重吗？ — 完全不严重。只需说一句“啊，红色 (Ppallgansaek / 빨간색) 是不行的吧？我不知道” 就足够了。韩国人 (Hangugin / 한국인) 几乎不会介意外国人 (Oegugin / 외국인) 犯这种错误 (Silsu / 실수)。
  • 单手递东西 (Mulgeon / 물건) 给了长辈 (Eoreun / 어른)。 — 下次开始用双手 (Du Son / 두 손) 即可。一次的错误 (Silsu / 실수) 不会让你成为无礼 (Muryehan Saram / 무례한 사람) 的人。表现出注意 (Uisik / 의식) 的样子本身就能给人留下好印象。
  • 酒店 (Hotel / 호텔) 房间 (Bang / 방) 是4楼 (4 Cheung / 4층)/4号 (4 Ho / 4호)，需要更换吗？ — 不需要。只有介意的人才会自行避开，外国人 (Oegugin / 외국인) 住在4楼 (4 Cheung / 4층) 没有任何问题。
  • 这些迷信 (Misin / 미신)，韩国人 (Hangugin / 한국인) 真的相信吗？ — 因人而异。 红色名字 (Ppallgan Ireum / 빨간 이름)·数字4 (Sutja 4 / 숫자 4)·双手礼仪 (Du Son Yebbeop / 두 손 예법) 很多人会遵守，而电风扇 (Seonpunggi / 선풍기)·指甲 (Sontop / 손톱)·口哨 (Hwiparam / 휘파람) 则被视为不重要或玩笑。更多人是“因为是习俗 (Gwansseup / 관습)”而非“因为相信” 而遵守。
  • 礼物 (Seonmul / 선물) 选错了 (鞋子 (Sinbal / 신발)/刀具 (Kal / 칼))。 — 如果收礼人 (Batneun Saram / 받는 사람) 是介意 (Singyeong Sseuneun Taip / 신경 쓰는 타입) 的人，可以开个玩笑，收一枚硬币 (Dongjeon / 동전) 算作“卖出”，轻松化解厄运 (Aekttaem / 액땜)。大多数人都会一笑置之。
