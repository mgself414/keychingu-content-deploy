🍞 チャンネル別ワークフロー

Type A — チェーン (パリバゲット・トゥレジュール)

  • シグネチャー: コスパ・即時・全国cluster
  • 時間: 07:00～22:00 (一部24h)
  • 価格：1,500〜6,000ウォン/ 1個
  • メニュー: ソボロ・ダン小豆・メロン波・MZ変形
  • 外国人親和性: ★★★★★ (英語・即時)

Type B — MZカフェ (ロンドンベーグルミュージアム・ノート・ソウルマリン)

  • シグネチャー: ウェイティング 1～3h・インスタ #1・MZ トレンド #1
  • 時間: 10:00～22:00
  • 価格: 4,500～18,000ウォン/1個・サンドイッチ
  • メニュー: ベーグル・クリームチーズ・ドーナツ・クリームパン
  • 外国人親和性: ★★★★★ (MZ #1・グローバルトレンド)
  • ウェイトマナー：
  • テーブルリングアプリ（韓国1位ウェイティングアプリ） - 事前登録OK
  • 現場綱引き — 入場順番カード
  • テイクアウト =ウェイト30分〜1h
  • 取食 = ウェイティング 1～3h (テーブル回転)

Type C — インディーベーカリー

  • シグネチャー：インディー小売店・MZインディーズ

  • メニュー: 伝統変形・MZインディシグネチャー

＃＃⚠外国人の頻繁なミス7つ

1. "チェーン= MZ": チェーン(パリバゲット) = 苛性比・即時 / MZ (ロンドンベーグル) = ウェイティング 1～3h。

2. 「パリバゲット＝フランス」：パリバゲット＝韓国チェーン#1。

3. "ロンドンベーグル・ノート==即時"：ウェイティング30分～3h・テーブルリングアプリ推奨。

4. "免税店=通関OK":免税店パン=真空1L未満+新鮮式当日推奨。

5. "パン=同じ食べ物": 韓国パン= ソボロ・たんぽ・メロンパ本格 + MZ fusion。

6. "インディー=高価だけ": インディー=MZ インディーマニア・苛性費OK。

7. "カード=すべてOK": MZカフェ=カードOK /インディ=いくつかの現金のみ。

⚙ よくある質問8件

1. ファーストパン=どんなチャンネル: パリバゲットソボロ+ダンパ (#1入門) → ロンドンベーグル (#1 MZ)。

2. インスタ・vlog: ロンドンベーグル（#1）・ノーティッド（#1）・MZインディ。

3. MZ トレンド: ロンドンベーグル(#1)・ノーティド(#1)・ソウルマリン。

4. ウェイトマナー: テーブルリングアプリ・現場ライン・テイクアウト fast。

5. 帰国ギフト: 免税店の真空(当日推奨)。

6. アレルギー・妊娠: [#885 disclaimer](#885)参照。

7. 決済・チップ: カードOK/インディー 一部の現金/チップX。

8. VAT 払い戻し: マート・免税店 = 可能（5万ウォン以上即時）。

⚠医療・安全・食事ダイエット

パン=一般的な食べ物。妊婦・子ども＝OK。アレルギー（小麦粉グルテン・卵・乳製品・ナッツ類）事前告知。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：一部店舗のみOK・MZカフェ事前確認。
  • ベジタリアン・ビーガン: 小豆・そぼろ = 一部OK / ノーティッド・ロンドンベーグル = 事前確認。
  • グルテンフリー: MZベーカリーいくつかのグルテンフリーオプション。
