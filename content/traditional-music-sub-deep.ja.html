📍 ソウル — ソウルナムサン国楽堂・ソウルドンファムン国楽堂・国楽公演 ジニョン

ソウルナムサン国楽堂 (Seoul Namsan Gugakdang / 서울남산국악당) (中区 Toegye-ro 34-gil 28、Pil-dong 2-ga、☎ 02-6358-5500) は、2007年に建てられた国楽専門の公演場です。地上1階の韓屋の建物の下、地下に公演場を置きました。地下1階の公演場ロビーとつながるサンクンガーデン「チムサンウォン (Chimsangwon / 침상원)」は、景福宮 (Gyeongbokgung / 경복궁) のキョテジョン (Gyotaejeon / 교태전) の雰囲気を生かした段々の庭で、地下の公演場ですが自然光が入ります。

  • 開く時間: 09:00~21:00。公演がある日は、公演が終わる時間に合わせて閉まります。休み: 毎週月曜日。
  • 料金: 公演ごとに異なります。客席: 300席。

ソウルドンファムン国楽堂 (Seoul Donhwamun Gugakdang / 서울돈화문국악당) (鍾路区 Yulgok-ro 102、Waryong-dong、☎ 0507-1413-7001) は、昌徳宮 (Changdeokgung / 창덕궁) のドンファムン (Donhwamun / 돈화문) の名を取った国楽専門の公演場です。ソウル市が昌徳宮の向かいのガソリンスタンドの敷地を買い取って建てました。伝統的な韓屋と現代建築の様式を混ぜ、自然音響で国楽を聴く室内公演場と、野外公演用の国楽広場があります。

  • 開く時間: 09:00~18:00。公演の有無によって運営時間が異なります。休み: 毎週月曜日。
  • 料金: 公演ごとに異なります。客席: 140人。

国楽公演 ジニョン (Gugak Gongyeon Jinyeon / 국악공연 진연) (鍾路区 Insadong 5-gil 10、☎ 02-953-0515) は、韓屋コンセプトの公演場で開く60分の伝統芸術公演です。演奏を聴いて芸術家と話ができ、韓国音楽・K-pop・クラシック・世界の民謡を伝統楽器で演奏します。演奏、ソリ、楽器体験までが組み合わされています。2026年1月1日~12月31日の日程で登録されています。

  • 公演時間: 毎日 11:00、14:00、16:00。祝日には公演がありません。観覧年齢: 全年齢。
  • 料金: 一般 65,000ウォン、障害者 50%割引、24か月未満 無料。
  • 構成: 第1部 キルチェ (Gilje / 길제)(井華水を供え、観客の平安を祈る)、第2部 ジニョン (Jinyeon / 진연)(宮中の伝統公演・チョンアク (Jeongak / 정악)・サンジョ (Sanjo / 산조))、第3部 ファハプ (Hwahap / 화합)(伝統楽器でさまざまな国の音楽を演奏)。

📍 地域の国立国楽院 — 珍島・南原・釜山

国立ナムド国楽院 (Gungnip Namdo Gugagwon / 국립남도국악원) (珍島郡 Jindo-daero 3818、☎ 061-540-4031) は、パンソリ (Pansori / 판소리)・シナウィ (Sinawi / 시나위)・サンジョ (Sanjo / 산조)や、ジンドアリラン (Jindo Arirang / 진도아리랑)・カンガンスルレ (Ganggangsullae / 강강술래)・ナムドドゥルノレ (Namdo Deulnorae / 남도들노래)・ジンドッシッキムグッ (Jindo Ssitgimgut / 진도씻김굿)・ジンドプクチュム (Jindo Bukchum / 진도북춤) などの伝統芸術が豊かな珍島にある国楽院です。毎週土曜日 15:00に常設公演が開かれます。520席あまりの国楽専用劇場ジナクダン (Jinakdang / 진악당)、マダンノリ形式の野外公演場タルビッマダン (Dalbitmadang / 달빛마당)、小規模な野外公演場ピョルビッマダン (Byeolbitmadang / 별빛마당)があります。

  • 開く時間: 09:00~18:00。休み: 毎週日曜日・月曜日。
  • 料金: 体験プログラムごとに異なります。体験: 出張教室コンサート、ナムド国楽体験 ポベソム国楽おでかけ (Bobaeseom Gugaknadeuri / 보배섬 국악나들이) など。

国立民俗国楽院 (Gungnip Minsok Gugagwon / 국립민속국악원) (南原市 Yangnim-gil 54、☎ 063-620-2329) は、パンソリの本場である南原で1992年に開館した国の音楽機関で、パンソリとチャングク (Changgeuk / 창극)を中心に民俗楽を伝承・普及しています。イェウォンダン (Yewondang / 예원당)、イェウムホン (Yeeumheon / 예음헌)、国楽展示館、民俗楽資料室があり、土曜常設公演やパンソリマダン (Pansori Madang / 판소리 마당)などの定期公演、パンソリ五つの演目を新たにつくったチャングク公演を開いています。

  • 開く時間: 国楽展示館 09:00~18:00。公演場は公演によって異なります。休み: 国楽展示館 年中無休。
  • 料金: 公演によって異なります。客席: 680席。

国立釜山国楽院 (Gungnip Busan Gugagwon / 국립부산국악원) (釜山鎮区 Gugak-ro 2、☎ 051-811-0114) は、釜山・嶺南地域の伝統公演芸術を伝えるために2008年10月28日に開館した国立の文化芸術機関です。公演、教育、研究を一緒に行っています。

  • 開く時間・休み・料金: 公演ごとに異なります。

📍 国楽博物館 — 国楽の聖地(南原)・ナンゲ国楽博物館(永同)

国楽の聖地 (Gugagui Seongji / 국악의 성지) (南原市 雲峰邑 Bijeon-gil 69、☎ 063-620-5740~2) は、智異山の麓の雲峰邑につくられた国楽博物館であり展示館です。トンピョンジェ (Dongpyeonje / 동편제)を完成させて歌王と呼ばれたソン・フンノク (Song Heungnok / 송흥록)の生家と、国楽展示体験館、トクコンシル (Dokgongsil / 독공실)、野外公演場、国楽人の墓所、祠堂があります。器楽・チョンアク (Jeongak / 정악)の資料と、名唱たちが寄贈した遺物を展示しています。

  • 開く時間: 09:00~18:00。休み: 毎週月曜日、1月1日、旧正月、秋夕。
  • 体験: ハンサム舞踊 (Hansam Muyong / 한삼무용)体験、パンソリを真似て習う体験、ミニチュア国楽器づくり、国楽公演など。
  • 駐車: 可能(無料)。

ナンゲ国楽博物館 (Nangye Gugak Museum / 난계국악박물관) (永同郡 深川面 Gugak-ro 9、☎ 043-740-3886) は、2000年に開館した国楽専門の博物館です。永同で生まれた朝鮮初期の音楽家ナンゲ パク・ヨン (Nangye Bak Yeon / 난계 박연)の生涯と業績を、映像室とナンゲ室で紹介しています。観光公社の紹介によると、パク・ヨンは高句麗のワン・サナク (Wang Sanak / 왕산악)、新羅のウルク (Uruk / 우륵)とともに、韓国の3大楽聖とされています。国楽室には、テグム (Daegeum / 대금)・カヤグム (Gayageum / 가야금)・ヘグム (Haegeum / 해금)・ピョンジョン (Pyeonjong / 편종)など80点を超える国楽器と、世界の民俗楽器があります。

  • 開く時間: 09:00~18:00。休み: 毎週月曜日、1月1日、旧正月・秋夕の連休、祝日の翌日。ナンゲ国楽祭の期間は開きます。
  • 料金: 大人 2,000ウォン、青少年・子ども・軍人・永同郡民 1,500ウォン。30人以上の団体は大人 1,500ウォン、青少年・子ども・軍人・永同郡民 1,000ウォン。

⚠ 事前に知っておきたい3つのこと

  1. 公演場は公演ごとに料金が異なる — ソウルナムサン国楽堂、ソウルドンファムン国楽堂、国立民俗国楽院、国立釜山国楽院は、固定料金が登録されていません。
  2. 月曜日に休む場所が多い — ソウルナムサン国楽堂、ソウルドンファムン国楽堂、国立ナムド国楽院、国楽の聖地、ナンゲ国楽博物館が月曜休みです。国立ナムド国楽院は日曜日も休みます。
  3. ジニョンは祝日に公演しない — それ以外の日は1日3回公演します。

⚙ FAQ 2

Q. 決まった時間に見られる国楽公演は?

A. 観光公社の登録情報では、国楽公演 ジニョン(毎日 11:00・14:00・16:00、祝日を除く)と、国立ナムド国楽院の常設公演(毎週土曜日 15:00)です。国立民俗国楽院も土曜常設公演を開いています。

Q. 国楽を実際に体験できる場所は?

A. 国楽の聖地(ハンサム舞踊、パンソリを真似て習う体験、ミニチュア国楽器づくり)、国楽公演 ジニョン(楽器体験を含む公演)、国立ナムド国楽院の体験プログラム(出張教室コンサート、ナムド国楽体験 ポベソム国楽おでかけ)です。
