⚠ 외국인 자주 실수 5가지

1. "한국 패션 = 동대문만": 한국 패션 = 동대문 (DDP·두산타워) + 홍대 streetwear + 강남 럭셔리 + 신진 디자이너 + 외국인 글로벌 매니아 1번지.

2. "DDP 동대문 = 야경만": DDP = 24h 패션 + 야시장 (#172·#380) + 외국인 매니아 1번지 + 두산타워·밀리오레·헬로APM·도매 22-04시.

3. "한국 럭셔리 = 비쌈만": 한국 럭셔리 = 갤러리아·신세계·롯데백화점 + #406 면세 (외국인 가성비 1번지) + 외국인 럭셔리 매니아·#296·#142.

4. "홍대 streetwear = MZ만": 홍대 streetwear = 외국인 글로벌 매니아 1번지 + 빈티지·구제 + #366·#138 cluster + 외국인 MZ 매니아.

5. "한국 신진 디자이너 = 못 찾음": 한국 신진 = Pushbutton·Wooyoungmi·Andersson Bell + 외국인 글로벌 매니아 1번지 + 외국인 매니아 풀세트.
