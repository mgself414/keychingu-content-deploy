⚠ 外国游客常犯的5个错误

1. “韩国整形 = 只有江南 (Gangnam / 강남)”: 江南 (Gangnam / 강남) 虽是首选地，但新沙 (Sinsa / 신사)·清潭 (Cheongdam / 청담)·狎鸥亭 (Apgujeong / 압구정) 也是外国游客的首选 + 瑞来村 (Seoraemaeul / 서래마을) (#173) 是外国人居住的首选医疗区。有许多分散的店铺。

2. “整形 = 都对外国人开放”: 韩国整形是外国人友好的首选地 + 提供英文·中文·日文·俄语·阿拉伯语翻译 + 外国游客首选的政府认证导游店铺 (K-Medical 认证)。

3. “综合体检 = 无法进行”: 韩国综合体检对外国人友好 + 1晚2天全套服务 (₩200,000~1,000,000 (~145-725 USD / ~1050-5250 RMB / ~22,000-110,000 JPY)) + 英文报告 + 外国游客专属首选。

4. “牙科 = 哪里都行”: 韩国牙科外国游客专属首选 = 梨大牙科街 (Ewha Dental Street / 이대 치과 거리)·江南牙科街 (Gangnam Dental Street / 강남 치과 거리) + 种植牙首选地 + 外国游客费用便宜30~70% (与美国相比)。

5. “韩方 = 外国人无法体验”: 韩国韩方·韩医院 (Korean Traditional Medicine Clinic / 한의원) 对外国人友好OK + 英文指导 + 韩方专属外国游客首选地 (江南 (Gangnam / 강남)·清潭 (Cheongdam / 청담) 韩医院)。
