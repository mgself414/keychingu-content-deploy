서울 지하철 풀가이드 — 외국인 inbound 1순위 도시 교통

> 부제: 1~9호선·신분당·경의중앙·공항철도·우이신설·신림선 + 환승·요금·외국인 친화 풀세트

ISSUE 03 · #237 · 2026-05-19

🎯 왜 서울 지하철 풀가이드인가

외국인 한국 inbound 1순위 페인포인트 = 지하철. 서울 지하철 24개 노선·750+ 역·세계 1번지 대중교통. 외국인 친화 영문·중문·일문 안내 완비 + T-money 24시간. 풀세트 동선 가이드.

★ 한눈에 12선

# 노선·역 4축 시그니처
1 1호선 (서울역·종각·시청) ★ 1974 한국 1번지 핵심 노선 서울역·시청·종각·청량리·인천 (#13·#172)
2 2호선 순환선 (강남·홍대) ★ 외국인 #1 핵심 노선 50.2km·서울 핵심 순환·강남·홍대·잠실·신촌 (#142·#138)
3 3호선 (압구정·경복궁·종로3가) 핵심 노선 압구정 로데오·경복궁·종로3가·익선동 (#142·#207)
4 4호선 (명동·서울역·이촌) 핵심 노선 명동·서울역·동대문·국립중앙박물관·창동 (#187·#172)
5 5호선 (광화문·종로·여의도·김포공항) 핵심 노선 광화문·여의도·잠실·강동·김포공항 (#169·#175)
6 6호선 (이태원·한강진·합정·DMC) ★ 외국인 #2 핵심 노선 이태원·한강진·합정·홍대·DMC (#138·#188)
7 공항철도 (인천공항·서울역·홍대) ★ 외국인 1번지 광역·환승 직통 43분·일반 58분·서울역·홍대·디지털미디어시티 (#87)
8 9호선 급행 (김포공항·여의도·강남·종합운동장) 광역·환승 한국 1번지 급행·김포공항·여의도·강남·잠실 (#82·#169)

10 경의중앙선 (서울역·홍대·일산·문산) 광역·환승 서울역·홍대·일산·문산 외곽 출퇴근 + 한강 view
11 우이신설선 + 신림선 특색·niche 무인 경전철·우이동·강북·신림 외곽

+ 추가 4: GTX-A (2027 개통 예정 강남↔파주)·서울 시내버스 환승·DRT(반응형 셔틀)·따릉이 (서울 공공자전거)

⚠ 외국인 자주 실수 5가지

1. "환승 = 다른 노선 = 새로 결제": T-money 30분 이내 환승 무료. 4 환승까지 OK. 같은 카드 tag 필수.

2. "공항철도 = 직통만": 공항철도 2종 — 직통 (Express, 9,500원·43분) + 일반 (4,250원·58분). MZ·예산 = 일반 OK. 14kg+ 캐리어 = 직통.

3. "막차 = 자정": 막차 23:30~00:30 (노선·역별 상이). 새벽 1시 OK라고 가정하면 위험. 막차 30분 전 출발 필수.

4. "9호선 = 일반차만": 9호선 급행/일반 2종. 급행 김포공항→잠실 25분 / 일반 50분. 외국인 길게 보면 급행 1순위. 단 급행 일부 역 무정차.

5. "외국인 발권 = 어려움": 1회용 T-money 발권기 영문 OK + 환불 500원 보증금. T-money 충전식 (편의점·역) 외국인 친화. 모바일 T-money (Naver Pay·Toss·KakaoPay 결제 OK 2024 확장).

① 핵심 노선 (6)

1. 1호선 (서울역·종각·시청) ★ 1974 한국 1번지

  • 외국인 ★: ◎◎ — 한국 최초 지하철 1974 + 서울역·시청·종각·청량리·인천 (수원)
  • 시그니처: KTX 서울역 + 시청·광화문 + 종각 (#172) + 청량리 + 인천 (1호선 직통)
  • 색상: 진청색

2. 2호선 순환선 (강남·홍대·잠실) ★ 외국인 #1

  • 외국인 ★: ◎◎ — 세계 1번지 도심 순환선 50.2km
  • 시그니처: 강남(#142) → 홍대(#138) → 시청(#172) → 동대문 → 잠실(#82) 순환
  • 색상: 녹색

3. 3호선 (압구정·경복궁·종로3가)

  • 외국인 ★: ◎◎ — 압구정 로데오 + 경복궁 + 종로3가 + 익선동 + 안국 (#226·#207)
  • 색상: 주황색

4. 4호선 (명동·서울역·이촌)

  • 외국인 ★: ◎◎ — 명동(#13)·서울역·동대문(#172)·국립중앙박물관(#187) + 창동·노원
  • 색상: 하늘색

5. 5호선 (광화문·여의도·김포공항)

  • 외국인 ★: ◎◎ — 광화문·종로·여의도(#169)·잠실·강동·김포공항(#175)
  • 색상: 보라색

6. 6호선 (이태원·합정·DMC) ★ 외국인 #2

  • 외국인 ★: ◎◎ — 이태원·한강진(LCT·#172)·합정·홍대·DMC(#188)
  • 색상: 황토색

② 광역·환승 (4)

7. 공항철도 (인천공항·서울역·홍대) ★ 외국인 1번지

  • 외국인 ★: ◎◎ — 외국인 인바운드 1순위 환승 노선
  • 직통 (Express): 9,500원·43분·캐리어 베이·좌석 지정
  • 일반: 4,250원·58분·일반 좌석·MZ·예산 1순위
  • 환승: 서울역(1호선)·홍대(2호선)·DMC(6호선)

8. 9호선 급행 (김포공항·잠실)

  • 외국인 ★: ◎◎ — 한국 1번지 급행 지하철
  • 김포공항(#175) → 여의도(#169) → 강남(#142) → 종합운동장 25분 (일반 50분)

9. 신분당선 (강남·판교·광교)

  • 외국인 ★: ◎ — 강남·양재·판교(외곽 IT 핫존)·정자·광교
  • 요금: 1,400원~ + 추가 운임 노선

10. 경의중앙선 (서울역·홍대·일산·문산)

  • 외국인 ★: ◎ — 서울역·홍대·일산·문산 + 한강 view (한강 다리 통과)

③ 특색·niche (2 + 추가 4)

11. 우이신설선 + 신림선

  • 무인 경전철 + 우이동(#186)·강북·신림(외곽)

12. 수인분당선 + 7호선

  • 수원·인천 + 강북·노원·도봉(#177 등산)

+ 추가 4

  • GTX-A (2027 개통 예정) — 강남↔파주 광역 급행
  • 서울 시내버스 — 지선·간선·광역·마을 4종 + T-money 환승 무료
  • DRT (반응형 셔틀) — 외곽 (강남·은평) 호출 서비스
  • 따릉이 (서울 공공자전거) — 1000원/1시간·외국인 1순위 액티비티

⚙ FAQ 8개

1. 외국인 T-money 발급: 편의점 (CU·GS25·세븐일레븐·이마트24) 4,000원 카드 + 충전. 환불은 카드 잔액 500원 보증금 미환불.

2. 모바일 T-money: 안드로이드 NFC + Naver Pay·KakaoPay·Toss 결제 OK (2024 확장). 아이폰 미지원.

3. 환승 룰: T-money tag 30분 이내 다른 노선·버스 환승 무료 (최대 4 환승). 같은 노선 재진입은 1회.

4. 요금: 기본 1,400원 (10km까지) + 5km당 100원 추가. 외국인 일반 노선 1,400~2,400원.

5. 운행 시간: 보통 05:30~24:00. 막차는 노선·역별 상이 — 네이버 지도·카카오맵 실시간 확인 필수.

6. 외국인 친화: 1·2·4·5·6·9호선·공항철도 = 영·중·일·KR 4lang 안내 풀세트. 외곽 노선은 KR·EN만.

7. 카드 결제: 신용카드 (해외 발급 Visa·Master·JCB OK) 일부 역 직접 결제 (2024 확장). T-money 추천.

8. 사진·녹음: 지하철 내부 사진 OK (개인용)·라이브 방송 비추천 (전동 차량 안전 우선).

🗺 외국인 풀데이 코스 4개

A. 인천공항 → 서울 도심 (도착 첫날)

  • 인천공항 → 공항철도 직통 (Express 43분) → 서울역 → 1호선 또는 4호선 환승 → 명동·홍대·강남 호텔

B. 외국인 1일 풀공략 (지하철 only)

  • 09:00 강남(#142, 2호선) → 12:00 명동(#13, 4호선) → 14:00 종로·인사동(#207, 3호선) → 17:00 홍대(#138, 2호선) → 20:00 이태원(#172, 6호선)

C. 한강 4 코스 (5호선·9호선)

  • 여의도(#169, 5호선) → 반포(#173, 9호선) → 잠실(#82, 9호선) → 뚝섬(#01, 2호선)

D. 외곽 1일 (광역)

  • 김포공항(#175, 5/9호선) → 마곡 서울식물원 → 신분당선 → 판교(외곽 IT) → 광교 호수공원

🌸 시즌·시간대 5

  • 러시아워: 07:30~09:00 / 17:30~19:30 — 2·9호선 급행·공항철도 직통 피하기 권장
  • 막차 후: 24:00 이후 = 택시 (카카오T·우버 OK) + 심야버스 (N15·N16 등)
  • 공항철도 직통 시간대: 06:00~22:30 (약 1시간 간격)
  • 봄 4월: 윤중로(#230 벚꽃) = 5호선 여의나루
  • 단풍 10~11월: 4호선 동대문 → 7호선 어린이대공원(#229)
