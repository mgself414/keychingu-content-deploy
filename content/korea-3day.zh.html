ISSUE 03 · #264 · 2026-05-20

🎯 为什么是外国游客3日行程

外国游客来韩国最常见的行程是 3天2夜短期。对于商务出差或短期休假的外国游客来说，这里是首选。#228 7日行程变体 — 核心3天浓缩全套。

★ 3日全套行程矩阵

Day 1 — 抵达 + 明洞 (Myeongdong / 명동)·N首尔塔 (N Seoul Tower / N서울타워)

  • 09:00 抵达仁川机场 (Incheon Airport / 인천공항) → 机场铁路 (Airport Railroad / 공항철도) (#237) → 酒店 (明洞 (Myeongdong / 명동)·江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대))
  • 12:00 明洞 (Myeongdong / 명동) 午餐 (#13·#172 明洞 (Myeongdong / 명동) 完整攻略)
  • 14:00 明洞 (Myeongdong / 명동) 免税店 + 购物 (乐天 (Lotte / 롯데)·新世界 (Shinsegae / 신세계)·免税店)
  • 17:00 N首尔塔 (N Seoul Tower / N서울타워) + 缆车 (外国游客首选)
  • 20:00 明洞 (Myeongdong / 명동) 韩餐 (#234 韩定食 (Hanjeongsik / 한정식) 或 K-BBQ)
  • 韩定食 (Hanjeongsik / 한정식): 韩式传统套餐。
  • K-BBQ: 韩式烤肉。

Day 2 — 宫殿 (Gunggwol / 궁궐)·韩屋 (Hanok / 한옥)·弘大 (Hongdae / 홍대)

  • 09:00 景福宫 (Gyeongbokgung Palace / 경복궁) + 韩服 (Hanbok / 한복) 体验 (#207 寺庙·宫殿)
  • 韩服 (Hanbok / 한복): 韩国传统服饰。
  • 12:00 北村韩屋村 (Bukchon Hanok Village / 북촌 한옥마을) (#226 韩屋 (Hanok / 한옥))
  • 韩屋 (Hanok / 한옥): 韩国传统房屋。
  • 14:00 益善洞 (Ikseondong / 익선동) 韩屋 (Hanok / 한옥) 咖啡馆 (#225 咖啡馆)
  • 17:00 弘大 (Hongdae / 홍대)·延南 (Yeonnam / 연남) (#138 弘大 (Hongdae / 홍대) 完整攻略)
  • 20:00 弘大 (Hongdae / 홍대) 夜市·居酒屋

Day 3 — 江南 (Gangnam / 강남)·汉江 (Hangang / 한강)·出境

  • 09:00 江南 (Gangnam / 강남) K-pop (#221) + 林荫道 (Garosu-gil / 가로수길)
  • 12:00 江南 (Gangnam / 강남) 韩餐 (#143 江南 (Gangnam / 강남) 韩餐)
  • 14:00 盘浦汉江 (Banpo Hangang / 반포 한강) + 月光彩虹喷泉 (Moonlight Rainbow Fountain / 달빛무지개분수) (#243 汉江 (Hangang / 한강))
  • 17:00 免税店稍作停留 + 仁川机场 (Incheon Airport / 인천공항) (#238 T-money 退款)
  • T-money: 韩国交通卡。
  • 20:00 出境

⚠ 外国游客3日行程常犯的3个错误

1. “3天 = 所有景点都OK”: 3天行程只适合 核心三轴 (明洞 (Myeongdong / 명동)·宫殿 (Gunggwol / 궁궐)·江南 (Gangnam / 강남)) + 额外1个区域。这与5天·7天 (#228) 全套行程有所区别。

2. “3天 = K-pop粉丝有难度”: K-pop粉丝建议选择 Day 3 江南 (Gangnam / 강남)·HYBE Insight + 至少1个时间段。

3. “3天 = 忘记退税”: Day 3 仁川机场 (Incheon Airport / 인천공항) 退税 (Tax Refund) = 出境前务必预留90分钟。

3日行程变体

  • A 短期完整攻略 (本指南标准): 明洞 (Myeongdong / 명동)·宫殿 (Gunggwol / 궁궐)·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남) + 汉江 (Hangang / 한강)
  • B K-pop粉丝: HYBE·SM·YG·江南 (Gangnam / 강남) → 明洞 (Myeongdong / 명동) → 蚕室 (Jamsil / 잠실) (#82)
  • C 美食粉丝: 广藏市场 (Gwangjang Market / 광장시장) → 江南 (Gangnam / 강남) 韩餐 → 弘大 (Hongdae / 홍대) 夜市
  • D 自然·散步: 北汉山 (Bukhansan / 북한산) → 汉江 (Hangang / 한강) → 首尔林 (Seoul Forest / 서울숲)
