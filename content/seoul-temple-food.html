⚠ 외국인 자주 실수 5가지

1. "사찰음식 = 비건과 같음": 사찰음식 = 비건 + 오신채 (마늘·파·부추·달래·흥거) 미사용 + 수행 철학 차이. 일반 비건은 마늘·파 OK·사찰음식 NO.

2. "발우공양 = 미쉐린이라 비쌈만": 발우공양 = 선·원·염·희·법식 5 코스 30K~80K + 한국불교문화사업단 직영 + 외국인 영어 메뉴·프라이빗 룸 + 외국인 게스트 1순위.

3. "예약 없이 OK": 발우공양·아승지·마지 = 2~3일 전 예약 필수. 산촌·일상·비건인사·소이로움 = 워크인 OK (주말은 예약 권장).

4. "향적세계 = 식당": 향적세계 = 식당 아닌 쿠킹클래스 체험관 + 스님 직강 + 외국인 영어 클래스 (토) + 10K~20K 체험 + 외국인 문화 매니아 1순위.

5. "진관사 = 일반 식당처럼": 진관사 = 템플스테이 또는 사전 예약 산사음식 체험 프로그램 필수 + 외국인 매니아 사전 신청.

⚙ FAQ 6개

1. 외국인 미쉐린 1순위: 발우공양·아승지 (예약 필수 2~3일 전).

2. 외국인 워크인 OK: 산촌·일상·비건인사·소이로움 (주말 예약 권장).

3. 외국인 쿠킹클래스: 향적세계 (안국역 6번) 토 영어 수업·10~20K.

4. 외국인 산사 체험: 진관사 (#182) 템플스테이·봉은사·길상사.

5. 외국인 가성비: 일상 (백반 8K)·비건인사·소이로움 12~20K.

6. 외국인 사찰음식 vs 비건: 사찰음식 = 비건 + 오신채 5종 미사용 (마늘·파·부추·달래·흥거) + 수행 철학.
