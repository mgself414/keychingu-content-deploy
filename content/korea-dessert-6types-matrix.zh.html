🎯 为什么选择韩国甜品矩阵？

外国人的韩国甜点痛点= “除了韩剧鱿鱼游戏Dalgona之外我什么都不知道”。韩国甜点 = 传统街头（hotteok，bungeoppang，菊花面包）+宫廷/传统（yakgwa/hangwa）+现代（刨冰/dalgona咖啡馆）全套3种。即使是同一个“韩国甜点”，hotteok（1900年代的街道）、dalgona（1970年代的学校前→鱿鱼游戏2021全球）、bungeoppang（1930年代）、菊花面包、药果（朝鲜王朝的宫廷）、刨冰（1900年代的日本制造）都有不同历史、成分和季节。外国人感到困惑的是（a）只有dalgona，没有其他甜点体验（b）hotteok≠日本hotto蛋糕（c）刨冰=单一菜单的一部分，（d）药果=韩国甜点的一部分等。本指南由6种类型的矩阵+季节+外国人的优先顺序组成。

🥞 6种甜品深度探究

🥞 Hotteok — 外国人介绍#1

  • 签名：随着清朝中国人的涌入，在朝鲜末期（1880年代）定居韩国（词源：胡=清朝，餠=年糕）
  • 类型：
  • 种子 Hotteok（种子）：坚果和葵花籽（釜山一号）
  • 蜂蜜Hotteok（蜂蜜）：红糖+蜂蜜
  • 绿茶 hotteok（绿茶）：MZ Trend
  • 奶酪Hotteok（奶酪）：马苏里拉奶酪（MZ Trend）
  • 推荐商店：
  • 釜山 BIFF Square Hotteok — 釜山签名（种子 Hotteok 韩国#1）
  • 明洞、弘大、钟路街道 — 外国爱好者
  • 仁寺洞韩屋Hotteok集群
  • 外国人友好度：★★★★★（很多英文菜单，Instagram ★）
  • 价格：2,000~4,000韩元
  • 季节：冬季#1（温暖）

🍯 达尔戈纳 — 全球意识 ★

  • 签名：20世纪60年代末和1970年代学校前的街道 + 鱿鱼游戏（2021）全球爆炸
  • 类型：
  • 星形、三角形、伞形（蜂窝形）：正宗的鱿鱼游戏
  • Dalgona Latte：Insta Cafe #1 趋势
  • 达尔戈纳松饼/零食：MZ Cafe
  • 推荐商店：
  • 仁寺洞·钟路街 — 正宗的鱿鱼游戏体验（1,000~2,000韩元）
  • MZ Cafe (首尔全区) — Dalgona Latte·Muffin
  • 外国人友好度：★★★★★（全球意识#1）
  • 价格：1,000~3,000韩元（街边）/ 6,000~9,000韩元（拿铁）
  • 季节：全年

🐟 Bungeoppan — 冬季街

  • 签名：鲷鱼烧（鲷焼き，Taiyaki）在1930年代日本殖民统治期间引入日本→传统的韩国红豆变种
  • 类型：
  • 红豆bungeoppang（红豆）：基本
  • 蛋奶冻：MZ Trend
  • Pizza Bungeobbang（披萨）：变化
  • 推荐商店：街边小摊（冬季十一月至三月）
  • 外国人友好度：★★★★（Insta形状★）
  • 价格：1,000~2,000韩元/个（3个5,000韩元）
  • 季节：仅限冬季（十一月至三月）

🌼 菊花面包（Gukhwappang）——Bungeoppang 的表弟

  • 签名：朝鲜战争前后在街头定居 - 菊花形状
  • 类型：红豆菊花面包（基本款）/奶油菊花面包（流行款）
  • 推荐商店：仁寺洞和钟路的传统摊位
  • 外国人友好度：★★★（Insta形状★）
  • 价格: 1,000~2,000韩元/个
  • 季节：秋季 ~ 冬季

🌾 Yakgwa — 宫廷正统 + MZ 趋势

  • 招牌：朝鲜皇家甜点（蜂蜜+芝麻油+面粉）
  • 类型：
  • 传统药果：仁寺洞/传统韩果屋
  • MZ药果：药果拿铁·药果羊角面包（弘大/江南咖啡厅）
  • 药果冰淇淋：苏冰·MZ Cafe
  • 推荐商店：
  • 仁寺洞传统韩瓦餐厅（正宗）
  • MZ Cafe (弘大、圣水、江南) —药果拿铁·药果面包（Instagram排名第一）
  • 外国人友好度：★★★★（MZ趋势★★★★★）
  • 价格: 1,500~5,000韩元/个
  • 季节：全年（秋季/冬季↑）

🍧 Bingsu — 夏天#1

  • 签名：1920年代日本殖民时期的kakigori（かき冰）的影响+石冰果冰淇淋与朝鲜王朝传统的结合 → 红豆刨冰的正统
  • 类型：
  • 红豆刨冰（红豆）：正宗
  • 芒果刨冰（芒果）：MZ Trend
  • 草莓刨冰（草莓）：春季/初夏
  • 绿茶抹茶：MZ
  • Hotel Bingsu（酒店高级）：新罗·乐天 Signature（40,000~80,000 韩元）
  • 推荐商店：
  • Sulbing（连锁） — 韩国#1刨冰连锁（性价比高）
  • 新罗酒店刨冰 — 豪华（50,000~80,000 韩元）
  • 弘大、江南、梨泰院 MZ Bingsu Cafe
  • 外国人友好度：★★★★★（夏日狂潮#1·Insta★）
  • 价格: 8,000~25,000韩元 (普通) / 40,000~80,000韩元 (酒店)
  • 季节：夏季#1（六月~九月）

⚠ 外国人常犯的5个错误

1. “韩国甜点=Dalgonaman”：全套6件+咖啡馆集群。 Hotteok（冬天#1）+刨冰（夏天#1）疯狂。

2. “Hotteok = 日本 Hotto 蛋糕”：韩国 Hotteok = 红糖 + 坚果 + 温暖的街道（1900 年代）。日本热蛋糕=其他食物。

3. “刨冰=单菜单”：刨冰=6+种（红豆、芒果、草莓、绿茶、酒店豪华）。酒店刨冰=4万~8万韩元的豪华。

4. “Dalgona = 难以制作”：韩国仁寺洞和钟路街道 = 1,000-2,000 韩元即时体验。正宗的鱿鱼游戏体验。

5. “Bunggeoppang = 四个季节”：Bungeoppang = 仅限冬季（11 月至 3 月）。夏天的时候几乎没有路边摊。

⚙ 8 个常见问题解答

1. 没有。 1 适合外国人：Hotteok（冬季）/刨冰（夏季）/Dalgona（全年）。

2. Insta/Vlog #1：Dalgona Latte、Yakgwa Latte、酒店刨冰、仁寺洞韩屋咖啡馆。

3. MZ趋势：达戈纳拿铁·药果羊角面包·苏尔宾·蓝瓶+药果。

4. 豪华·招待：新罗、乐天、威斯汀酒店的刨冰（40,000-80,000韩元）。

5. 季节狂热：春季 = 药果 / 夏季 = 刨冰 / 秋季 = Hotteok、菊花面包 / 冬季 = Hotteok、Bungeobbang、Dalgona。

6. 过敏：麸质（小麦）、坚果（Hotteok seeds）、牛奶（刨冰）、鸡蛋（Yakgwa）、蜂蜜（Yakgwa），需提前通知。

7. 付款/小费：街头 = 建议现金 / 咖啡馆/连锁店 = 刷卡即可 / 酒店 = 10% 服务费 / 小费

8. 增值税退税：一般食品和饮料退税 X.

⚠ 医疗/安全/饮食免责声明

Hotteok、bungeobbang、菊花面包 = 热甜点（90~100°C） — 小心烫伤（尤其是儿童）。刨冰=冷（牛奶过敏、糖↑）注意。孕妇=适量坚果和蜂蜜。过敏（麸质、坚果、牛奶、鸡蛋、蜂蜜、大豆）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

店铺信息免责声明：街边小摊/季节性店铺经常更换——建议参观前使用NAVER/Kakao地图或本地搜索。

饮食限制后备：

  • Halal/Kosher：6种类型中，获得认证的商店很少。 → Yakgwa/Dalgona = 不含动物成分（有些是清真/犹太洁食）。 Hotteok、bungeoppang、刨冰 = 提供牛奶和猪油（需要确认）。
  • 素食/纯素食：药果/达尔戈纳 = 素食还可以（检查蜂蜜和牛奶）/ Hotteok、Bungeobbang、刨冰 = 大量牛奶和鸡蛋 → 独立的纯素食咖啡馆。
  • 不含麸质：所有 6 种类型都含有大量面粉。仅提供刨冰（不包括面粉配料）。
