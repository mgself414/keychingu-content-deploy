韩国烤肉店指南 — 五花肉、猪排骨、牛排骨、韩牛，14家烤肉店与马场畜产品市场 (金猪食堂 (Geumdwaeji Sikdang / 금돼지식당)、三元花园 (Samwon Garden / 삼원가든)、家宝亭排骨 (Gabojeong Galbi / 가보정갈비)、横城韩牛村 (Hoengseong Hanwoo Maeul / 횡성한우마을)) (2026年10月官方数据)

🎯 如何使用本指南

厚厚的五花肉放上烧得滚烫的铸铁烤盘，最先听到的是油花四溅的声音。烤肉店按部位、店家、烤法(煤球炭火、木炭、是否由店员代烤)来区分。本指南分成五类：五花肉 (Samgyeopsal / 삼겹살)·梅花肉 (Moksal / 목살)、猪排骨 (Dwaeji Galbi / 돼지갈비)、首尔牛排骨 (So Galbi / 소갈비)、地方排骨(水原·光州松汀)、韩牛 (Hanwoo / 한우)。店名、地址、营业时间只采用VisitKorea、米其林、VisitSeoul官方页面上的数据，没有一家公布价格。

这是写给想在韩国至少好好烤一次肉的人。入座后怎么用烤盘、剪刀、怎么点餐，请看 #1290 韩国烤肉店餐桌系统，这里不再重复。

旧版指南里的"五花肉每人1斤 (Geun / 근)·180g·5,000~8,000韩元"、"马场韩牛每人5~8万韩元"、"英文菜单99%"、连锁店排名，因为没有出处，全部删除。烤内脏 (Gopchang / 곱창) 和猪肉汤饭 (Dwaeji Gukbap / 돼지국밥) 与烤肉店性质不同，本期已移出(见下方相关内容)。

🐖 五花肉·梅花肉 — 煤球炭火与黑猪

  • 金猪食堂 (Geumdwaeji Sikdang / 금돼지식당) — 首尔中区茶山路 (Dasan-ro / 다산로) 149(新堂洞 (Sindang-dong / 신당동))。招牌是原味五花肉 (Bon Samgyeopsal / 본삼겹살)，另有雪花梅花肉 (Nunkkot Moksal / 눈꽃목살)、背部梅花肉 (Deung Moksal / 등목살)、猪皮 (Kkopdegi / 껍데기)。用约克夏、巴克夏、杜洛克杂交的"YBD"猪，放在煤球 (Yeontan / 연탄) 炭火加热的铸铁烤盘上烤。11:30~23:00，全年无休，无停车位，0507-1307-8750(VisitKorea)。米其林页面标注为烧烤、价格 ₩，并写明预约由店家自行管理(米其林页面)，2021年米其林文章将其列为必比登推介(米其林文章 2021-09-13)。价格未公布
  • 豚舍豚 (Donsadon / 돈사돈) — 济州市牛坪路 (Upyeong-ro / 우평로) 19。济州黑猪五层肉 (Oggyeopsal / 오겹살) 用煤球炭火烤，由店员代烤。蘸腌鱼酱 (Meljeot / 멜젓) 吃。12:00~22:00，每周二休息，064-746-8989(VisitKorea)。价格未公布
  • 熟成度 济州本店 (Sukseongdo Jeju Bonjeom / 숙성도 제주본점) — 济州市济原路 (Jewon-gil / 제원길) 30，2、3楼。济州黑猪用水熟成和干熟成交替熟成，不卖五花肉，而是供应里脊、前腿肉等部位。11:30~22:00(最后点单 21:10)，全年无休(VisitKorea)。价格未公布
  • 烤肉街：济州黑猪街 (Jeju Heukdwaeji-geori / 제주 흑돼지거리)(济州市一道一洞 (Ildo 1-dong / 일도일동)，济州港塔洞广场 (Tapdong Gwangjang / 탑동광장) 附近，各店营业时间不同)· 清州西门市场五花肉街 (Cheongju Seomun Sijang Samgyeopsal-geori / 청주 서문시장 삼겹살거리)(2012年建成，清州式：用酱油浸泡后烤，或撒粗盐烤)— 均出自VisitKorea

🍖 猪排骨 — 腌一天的酱料

  • 城北洞猪排骨 (Seongbuk-dong Dwaeji Galbi / 성북동돼지갈비) — 首尔城北区城北路 (Seongbuk-ro / 성북로) 115。1975年开业。前一天用酱料腌好的肉烤好后作为套餐 (Baekban / 백반) 上桌(猪排骨套餐、猪肉烤肉套餐、烤肉饼套餐)。09:00~20:30，每周二休息，02-764-2420。生菜和小菜 (Banchan / 반찬) 是自助取用(VisitKorea)。价格未公布
  • 马场排骨 (Majang Galbi / 마장갈비) — 首尔城东区马场路 (Majang-ro / 마장로) 292-1。1982年起在马场站前营业。招牌是用12种食材调成的酱料腌3天的大块猪排骨。平日 11:00~22:00(备料时间 15:30~16:30)，周日 11:00~21:00，每周一休息，0507-1370-8601(VisitKorea)。价格未公布
  • 凤飞阳 芳荑店 (Bongpiyang Bangi-jeom / 봉피양 방이점) — 首尔松坡区良才大路71街 (Yangjae-daero 71-gil / 양재대로71길) 1-4。平壤冷面 (Pyeongyang Naengmyeon / 평양냉면) 和猪颈肉本排骨 (Dwaeji Moksim Bon Galbi / 돼지목심본갈비)。11:30~22:00(最后点单 21:00)，全年无休，02-415-5527。VisitKorea简介写"入选米其林指南首尔2023"(VisitKorea)。价格未公布
  • 烤肉街：麻浦饮食文化街 (Mapo Eumsik Munhwa Georie / 마포음식문화거리)(麻浦站1号出口，有拌酱烤猪肉 (Jumulleok / 주물럭)、猪皮 (Kkopdegi / 껍데기)、猪排骨等37家餐厅，各店营业时间不同，VisitKorea)

🐂 首尔牛排骨 — 炭火上的大块排骨

  • 三元花园 (Samwon Garden / 삼원가든) — 首尔江南区彦州路 (Eonju-ro / 언주로) 835。传统排骨、烤肉 (Bulgogi / 불고기)、烤韩牛。平日 11:30~21:30(备料时间 14:30~17:30，最后点单 21:00)，周末 11:00~21:00(最后点单 20:30)，全年无休，02-548-3030。有40多个包间(VisitKorea)。价格未公布
  • 碧蹄排骨 芳荑店 (Byeokje Galbi Bangi-jeom / 벽제갈비 방이점) — 首尔松坡区良才大路71街 (Yangjae-daero 71-gil / 양재대로71길) 1-4(与凤飞阳 芳荑店 (Bongpiyang Bangi-jeom / 봉피양 방이점) 同一地址)。雪花生排骨 (Seolhwa Saeng Galbi / 설화 생갈비)、花里脊 (Kkotdeungsim / 꽃등심)、牛里脊、腌制排骨。11:30~22:00(最后点单 21:00)，全年无休，02-415-5522，全店禁烟(VisitKorea)。官方网站 bjgalbi.com。价格未公布
  • 梦滩 (Mongtan / 몽탄) — 首尔龙山区白凡路99街 (Baekbeom-ro 99-gil / 백범로99길) 50(三角地 (Samgakji / 삼각지))。招牌是厚切牛排骨 (Udae Galbi / 우대갈비)，另有稻草火烤猪颈肉 (Jippul Hangjeongsal / 짚불항정살)、生牛肉 (Yukhoe / 육회)。12:00~22:00(最后点单 21:00)，全年无休，02-794-8592，可刷卡。VisitKorea写"必须提前排队等位"(VisitKorea)。价格未公布

🔥 地方排骨 — 水原大排骨·光州松汀烤肉饼

  • 家宝亭排骨 (Gabojeong Galbi / 가보정갈비) — 京畿道水原市八达区长达里路 (Jangdari-ro / 장다리로) 282。1992年开业。韩牛腌制排骨用炭火烤。平日 11:30~21:30，周六 11:00~22:00，周日 11:00~21:30，全年无休，1600-3883(VisitKorea)。价格未公布
  • 本水原排骨 (Bon Suwon Galbi / 본수원갈비) — 京畿道水原市八达区中部大路223街 (Jungbu-daero 223beon-gil / 중부대로223번길) 41。开业日期1973-10-12。可在生排骨和腌制排骨中选择。周一、周日 11:30~21:00，周二至周六 11:30~21:30，春节 (Seollal / 설)、中秋 (Chuseok / 추석) 假期休息，031-211-8434(VisitKorea)。价格未公布
  • 松汀烤肉饼 1号店 (Songjeong Tteokgalbi 1-hojeom / 송정떡갈비 1호점) — 全南光州统合特别市 (전남광주통합특별시，原光州广域市) 光山区光山路29街 (Gwangsan-ro 29beon-gil / 광산로29번길) 1。1976年开始的松汀烤肉饼 (Tteokgalbi / 떡갈비) 街的元老店。牛排骨肉和猪五花按5比5混合。09:30~21:30(最后点单 21:00)，每周日及每月第一个周一休息，062-944-1439，可刷卡(VisitKorea)。价格未公布

🥗 饮食须知

  • 价位：本指南的14家餐厅，官方页面上都没有韩元价格。米其林只给金猪食堂 (Geumdwaeji Sikdang / 금돼지식당) 标了 ₩ 符号。请打电话确认
  • 素食：烤肉店的素食选择很少，连蘸酱都是动物性的。济州黑猪蘸腌鱼酱 (Meljeot / 멜젓，鱼类腌制酱)(VisitKorea 豚舍豚 (Donsadon / 돈사돈))，凤飞阳 (Bongpiyang / 봉피양) 的平壤冷面汤底是用韩牛熬的(VisitKorea)。点冷面、大酱汤 (Doenjang-jjigae / 된장찌개) 也要先问汤底
  • 清真：猪肉类别不适用。首尔KMF(韩国伊斯兰教中央会 (Hanguk Iseullamgyo Jungangheo / 한국이슬람교중앙회))认证的韩餐厅有伊德 (Eid / 이드) — 龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00，价位1万韩元(VisitSeoul)。本指南中的牛排骨店、韩牛店没有清真标识
  • 过敏：酱料的食材并未全部公开(松汀烤肉饼 (Songjeong Tteokgalbi / 송정떡갈비) 的酱料中有"店主不公开的食材"，VisitKorea)。有过敏的话，请选生排骨、生肉
  • 出示给店员看的卡片见 #1300 饮食需求说明手册

⚠ 常见的4个误区

1. "烤肉店都是自己烤" — 豚舍豚 (Donsadon / 돈사돈) 由店员代烤(VisitKorea)。每家店不同

2. "周一去马场排骨" — 马场排骨 (Majang Galbi / 마장갈비) 每周一休息，城北洞猪排骨 (Seongbuk-dong Dwaeji Galbi / 성북동돼지갈비) 和豚舍豚 (Donsadon / 돈사돈) 每周二休息(VisitKorea)

3. "烤肉饼是牛肉" — 松汀烤肉饼街有混合牛肉和猪肉的店(元老店松汀烤肉饼1号店，VisitKorea)。如果必须避开猪肉，请事先询问

4. "肉铺餐厅要另收摆桌费" — 横城韩牛村 (Hoengseong Hanwoo Maeul / 횡성한우마을) 摆桌费免费(VisitKorea)。每家不同，结账前先问
