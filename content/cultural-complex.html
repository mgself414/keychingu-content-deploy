⚠ 외국인 자주 실수 5가지

1. "복합 문화공간 = 쇼핑몰만": 복합 문화공간 = 카페 + 갤러리 + 편집숍 + 서점 + 디저트 + 라이브 multi-anchor 통합 공간 + 외국인 매니아.

2. "성수연방 = 어디나": 성수연방 = 성수 #1 복합공간 (옛 공장 → 천상가옥) + 외국인 인스타 1번지 (#01·#263).

3. "문화역서울284 = 옛 역사": 문화역서울284 = 1925 옛 서울역 (현 서울역 옆) + 미술관·갤러리·전시·외국인 매니아.

4. "DDP = 야간 LED만": DDP = Zaha Hadid 건축 + 디자인 박물관 + 라이브·전시 + 외국인 인스타 1번지 (#172).

5. "별마당 도서관 = 그냥 도서관": 코엑스 별마당 = 13m wall + 5만권 책 + 외국인 #1 인스타 + 코엑스 통합 매니아.
