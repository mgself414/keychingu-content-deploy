⚠ 외국인 자주 실수 5가지

1. "외국인 운전 = 못 함": 외국인 운전 = 국제운전면허 (IDP) + 모국 발급 1년 유효 + 외국인 영어 OK 렌터카 + #392 코스·#143·#253 외곽 통합.

2. "한국 운전 = 위험": 한국 운전 = 우측 통행·외국인 영어 내비 (T맵·카카오)·고속도로 Hi-pass + 외국인 안전 매니아 1번지·#405 통합.

3. "렌터카 = 비싸기만": 렌터카 = 롯데·SK·KT금호 외국인 가성비 1번지 (1일 5~15만원) + 외국인 영어 OK + Klook·KKday 외국인 패키지.

4. "고속도로 = 어렵기만": 고속도로 = Hi-pass + 외국인 영어 요금소 + 외국인 매니아 1번지 + #398·#414 통합·외국인 영어 내비 풀세트.

5. "외국인 자유여행 = 불가능": 외국인 자유여행 = 렌터카 + 영어 내비 + 외곽 1박2일 (부산·전주·제주·강릉) + 외국인 매니아 1번지·#392·#369 통합.
