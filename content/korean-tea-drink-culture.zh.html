食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과)·红枣茶 (Daechucha / 대추차) — 韩国的无酒精传统饮品解说

> 食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과)·韩方茶·水果茶·谷物茶 — 为外国人准备的韩国无酒精传统饮品文化解说。抛开“烧酒·马格利酒”，聊聊韩国人作为餐后甜点·药·日常饮用的饮品的“为什么·是什么·怎么喝”。

韩国酒 (烧酒·马格利酒) 对外国人来说也相当有名。然而，坐进韩国餐厅，还没点单就会免费送上或热或凉的棕色的水，节日餐桌的最后会端出飘着米粒的甜饮品，仁寺洞 (Insadong / 인사동) 小巷的韩屋 (Hanok / 한옥) 茶馆里则会奉上撒着松子的鲜红又酸爽的茶。这些都属于韩国的无酒精传统饮品世界。韩国人喝茶 (Cha / 차) 和传统饮品就像喝酒一样，融入日常·节日·药用之中。食醯 (Sikhye / 식혜) 是汗蒸幕 (Jjimjilbang / 찜질방) 的常客，水正果 (Sujeonggwa / 수정과) 是春节 (Seollal / 설날) 的餐后甜点，红枣茶 (Daechucha / 대추차)·生姜茶 (Saenggangcha / 생강차) 是感冒时喝的“像药一样的茶”，大麦茶 (Boricha / 보리차)·玉米茶 (Oksususcha / 옥수수차) 则是代替水喝的一生饮品。本文不探讨“哪家茶馆好” (→ cross-link)，而是从外国人的视角，解读这些饮品是什么、为什么喝。这是韩国文化解说系列。

> 核心区分: 食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과)·五味子 (Omija / 오미자) = 饮品·甜点 / 红枣 (Daechu / 대추)·生姜 (Saenggang / 생강)·柚子 (Yuja / 유자)·木瓜 (Mogwa / 모과)·双和 (Ssanghwa / 쌍화) = “像药一样”喝的韩方茶 / 大麦 (Bori / 보리)·玉米 (Oksusu / 옥수수) = 代替水的日常饮品。它们全都无酒精 (酒 → 参见 #1140 聚餐·饮酒文化)。

⚠️ 外国人常有的3大误解

1. “餐厅里送的棕色的水是茶 (tea)？还是免费的？” ✅ — 没错。在韩国餐厅，代替水的是免费无限续杯的大麦茶 (Boricha / 보리차)·玉米茶 (Oksususcha / 옥수수차) (将大麦/玉米炒过后煮成的谷物茶)。几乎不含咖啡因，所以托儿所·幼儿园也像水一样提供。香味不浓，即使觉得“像白开水？”也很正常——这是一种醇香的日常饮品。

2. “韩国的‘茶’应该都是绿茶 (green tea) 吧” ❌ — 在韩国，茶 (Cha / 차) 并不只是绿茶。谷物 (大麦·玉米)、水果 (柚子·木瓜)、根茎果实 (生姜·红枣)、中药材 (双和, Ssanghwa / 쌍화) 泡制或煮成的所有饮品都叫“茶”。其中大部分都不含茶叶。

3. “食醯 (Sikhye / 식혜) 不就跟马格利酒 (Makgeolli / 막걸리) 差不多吗？” ❌ — 两者都与大米·发酵有关，但食醯 (Sikhye / 식혜) 是无酒精的。它是用麦芽 (Yeotgireum / 엿기름) 将米饭发酵制成的甜饮品，几乎不含酒精。是节日餐后·汗蒸幕饮品，而非酒。

① 韩国的传统饮品是什么 — “药”与“甜点”的边界

韩国传统饮品最大的特点在于“一边美味地喝，一边滋补 (補, bo) 身体”的构思。国家遗产厅 (Gukga yusancheong / 국가유산청)·韩食资料将水正果 (Sujeonggwa / 수정과) 和食醯 (Sikhye / 식혜) 列为韩国代表性传统饮品，其共同点在于“使用对身体有益的中药材或谷物，在保留味道与香气的同时滋补身体”。因此，相当一部分传统饮品同时拥有餐后 (甜点) 和药 (藥, yak) 这两副面孔。

  • 餐后饮品: 像食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과) 这样，在油腻的节日饮食后帮助消化的甜饮品。
  • 药茶 (Yakcha / 약차): 像红枣 (Daechu / 대추)·生姜 (Saenggang / 생강)·柚子 (Yuja / 유자)·木瓜 (Mogwa / 모과)·双和 (Ssanghwa / 쌍화) 这样，把茶“当药”来喝、应对感冒·疲劳·消化的韩方茶。
  • 日常饮品: 像大麦茶 (Boricha / 보리차)·玉米茶 (Oksususcha / 옥수수차) 这样，代替水经常饮用的谷物茶。

在西方，饮品通常是“口味·喜好”的问题，但韩国传统饮品与季节·身体状况·节日紧密相连。冷了喝生姜茶，感冒喝柚子茶，节日喝食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과)——存在着这样一种根据情况选择饮用的语法。

② 食醯 & 水正果 — 节日餐桌的两款甜点

节日 (春节·中秋) 餐桌结尾几乎必然登场的两款饮品。也是外国人最先接触到的传统饮品。

食醯 (Sikhye / 식혜) — 飘着米粒的甜米饮

  • 是什么: 用麦芽 (Yeotgireum / 엿기름，发芽大麦粉) 将米饭发酵制成的无酒精甜饮品。做好的食醯 (Sikhye / 식혜) 上会飘着发酵的米粒，有时还会撒上松子。
  • 味道: 淡淡而柔和的甜味。香味不浓，是连外国人也能毫无负担地喜欢上的代表饮品。
  • 为何是餐后甜点: 麦芽的糖化酶 (淀粉酶) 能帮助消化，因此在大吃油腻的节日饮食后饮用。
  • 在哪里能遇到: 节日餐桌、汗蒸幕 (Jjimjilbang / 찜질방) 的常驻菜单 (与煮鸡蛋成套)，超市的罐装·瓶装也很常见。

水正果 (Sujeonggwa / 수정과) — 辛辣的肉桂·生姜潘趣

  • 是什么: 用肉桂和生姜熬煮的水加入糖·蜂蜜，再撒上柿饼 (Gotgam / 곶감，晒干的柿子) 和松子的深红褐色饮品。
  • 味道: 生姜·肉桂辛辣而芳香的辣味 + 甜味。比食醯 (Sikhye / 식혜) 更有刺激感。
  • 何时喝: 冰镇饮用的冬季·春节饮品。因为要放柿饼，所以从晚秋开始制作。
  • 要点: 同样是“节日餐后甜点”，食醯 (Sikhye / 식혜) 是柔和的甜味，水正果 (Sujeonggwa / 수정과) 则是辛辣的潘趣——截然相反的魅力。

> 一句话对比: 食醯 (Sikhye / 식혜) = 柔和而甜 (米粒)。水正果 (Sujeonggwa / 수정과) = 辛辣而芳香 (肉桂·生姜·柿饼)。两者都是无酒精餐后甜点。

③ 韩方茶 — “像药一样”喝的茶 (红枣·生姜·柚子·木瓜·双和)

韩国饮品文化中最独特的一点。把茶当药来喝。VisitKorea 也会将韩方茶 (Hanbang tea / 한방차) 作为免疫·养生内容来介绍——在韩国，“哪里不舒服就喝对应的茶”是一种日常感觉。

韩方茶 味道 常在“这种时候”
红枣茶 (Daechucha / 대추차) 浓郁的甜味，温和 疲劳·压力·睡不着时
生姜茶 (Saenggangcha / 생강차) 辛辣·温热 感冒·浑身酸痛·消化·寒冷时
柚子茶 (Yujacha / 유자차) 酸甜 (柑橘) 预防感冒·喉咙不适·维生素C
木瓜茶 (Mogwacha / 모과차) 芳香·略涩 咳嗽·痰多·消化
双和茶 (Ssanghwacha / 쌍화차) 浓郁的中药味 恢复体力·滋补 (疲劳)
  • 红枣茶 (Daechucha / 대추차): 将干红枣长时间 (有时小火8小时) 熬制而成。甜味浓郁，传统上用于缓解失眠·压力。
  • 生姜茶 (Saenggangcha / 생강차): 辛辣而暖身的冬季代表茶。被认为有助于消化·恢复元气。
  • 柚子茶 (Yujacha / 유자차): 将柚子 (Yuja / 유자，类似小号柚子的柑橘) 制成清 (糖渍) 后用热水冲开。维生素C含量是柠檬的3倍，是预防感冒·喉咙健康的国民饮品。
  • 木瓜茶 (Mogwacha / 모과차): 用芳香的木瓜 (Mogwa / 모과) 泡制的茶。传统上认为对支气管·咳嗽·痰多有益。
  • 双和茶 (Ssanghwacha / 쌍화차): 名字意为“双和 (雙和) = 两种气的调和”。是将当归·熟地黄·肉桂·芍药·甘草等多种中药材熬煮而成的浓郁滋补茶。虽然褒贬不一，但堪称“累的时候喝的药茶”之巅峰。也有茶馆会撒上蛋黄·松子端上来。

> 核心: 这些茶往往不是按“味道”，而是按“功效·季节·身体状况”来选择。韩国朋友推荐“感冒喝柚子茶”“累了喝双和茶”，正是这套语法。

④ 水果·果实茶 — 五味子，五种味道

五味子茶 (Omijacha / 오미자차) 堪称韩国传统饮品的“吉祥物”。五味子 (Omija / 오미자，五味子) 字面意思就是“五种味道的果实”——一颗红色果实 (五味子藤蔓, magnolia berry) 里集甜·酸·咸·苦·辣五味于一身。

  • 味道: 煮制容易发涩，因此传统上用冷水长时间浸泡 (冷沈, Naengchim / 냉침) 制作。成品是鲜红又酸爽的饮品。酸味最为突出。
  • 何时喝: 尤其在夏季冰镇饮用的冷饮。撒上松子端上，也会与梨·花菜 (Hwachae / 화채) 混合做成花菜。
  • 意义: 因“五味俱全”这一点，也常被用作像极了韩国本身的比喻。它也用作中药材，有与五脏 (五臟) 相联系的传统。
  • 在哪里: 仁寺洞 (Insadong / 인사동)·北村 (Bukchon / 북촌) 传统茶馆的招牌。一杯撒着松子的五味子茶 (Omijacha / 오미자차)，正是韩屋 (Hanok / 한옥) 茶馆体验的精髓。

(柚子·木瓜也是水果茶，但“药茶”性质较强，所以归入③。五味子更偏向饮品·传统茶性质，故单独列出。)

⑤ 日常谷物茶 — 代替水喝的大麦茶·玉米茶

外国人最困惑却又最常遇到的饮品。是韩国餐厅·家庭中代替水端出的棕色饮品。

  • 大麦茶 (Boricha / 보리차): 用炒过的大麦煮成的醇香茶。零咖啡因，被认为有助消化。在餐厅里像水一样免费·无限续杯，在家也会煮好放进冰箱。在韩国，它占据着水的位置。
  • 玉米茶 (Oksususcha / 옥수수차): 炒玉米带来的淡淡甜味。玉米的甜能压住大麦微弱的苦味，所以大麦+玉米混合的茶也很常见。金黄色，香醇微甜。
  • 为何代替水？: 几乎没有香味，不会与食物冲突，又不含咖啡因，从小孩到老人都能整天喝。托儿所·幼儿园也用它代替水。

> 外国人提示: 餐厅的棕色的水是免费的。不必为“水的颜色怎么这样？”而慌张，直接喝就好——是醇香的大麦茶/玉米茶。

⑥ 传统茶馆 — 在哪里“正经地”喝

如果想连氛围一起享受传统饮品，韩屋 (Hanok / 한옥) 传统茶馆就是正解。

  • 仁寺洞 (Insadong / 인사동): 每条小巷都密布着韩屋 (Hanok / 한옥)·古家具传统茶馆。也有从1970年代延续至今的老字号茶馆。五味子茶 (Omijacha / 오미자차)·红枣茶 (Daechucha / 대추차)·柚子茶 (Yujacha / 유자차) + 韩菓 (Hangwa / 한과，传统点心) 套餐是经典之选。
  • 北村韩屋村 (Bukchon / 북촌): 在由韩屋改造的茶馆·咖啡馆里，传统茶与现代茶兼有。静静望着院子品茶的氛围。
  • 点什么: 第一次的话就点五味子茶 (Omijacha / 오미자차，酸爽·印象深刻) 或红枣茶 (Daechucha / 대추차)·柚子茶 (Yujacha / 유자차，毫无负担的甜)。双和茶 (Ssanghwacha / 쌍화차) 中药味较重，可作为“药茶挑战”。
  • 一起端上的: 松子 (几乎所有传统茶都会飘着)、韩菓 (Hangwa / 한과，药菓·江米条等传统点心)。茶+韩菓为一套。

> MZ世代 (MZ sedae / MZ세대) 也会在时尚韩屋咖啡馆里重新诠释并享受传统茶 (传统茶 + 刨冰·甜点)。咖啡馆文化脉络 → #1158 咖啡共和国。

⑦ 外国人实战指南 — 如何享用

> 价格·营业为2026年基准的推测，各店有所不同——建议到访前确认。

  • 在餐厅: 棕色的水 (大麦/玉米茶) 是免费·自助续杯。有热的/凉的版本。像喝水一样喝就好。
  • 在超市·便利店: 买食醯 (Sikhye / 식혜)·水正果 (Sujeonggwa / 수정과) 罐装/瓶装 (约 ₩1,500~3,000)，柚子茶·生姜茶则买清 (瓶装) 回去用热水冲泡。大麦茶·玉米茶的茶包也很常见。是最便宜·最简单的入门方式。
  • 在传统茶馆: 一杯约 ₩7,000~12,000 (约 $5~9) (各店不同)。也有含韩菓的套餐。仁寺洞 (Insadong / 인사동)·北村 (Bukchon / 북촌) 交通便利。
  • 在汗蒸幕: 食醯 (Sikhye / 식혜) + 煮鸡蛋套餐是几乎像仪式般的组合——一定要体验。
  • 首次推荐顺序: ① 食醯 (Sikhye / 식혜) (甜而温和，绝不踩雷) → ② 柚子茶 (Yujacha / 유자차) (熟悉的酸甜) → ③ 五味子茶 (Omijacha / 오미자차) (鲜红·五味，印象深刻) → ④ 水正果 (Sujeonggwa / 수정과)/双和茶 (Ssanghwacha / 쌍화차) (辛辣·中药，挑战)。
  • 礼仪·提示: 传统茶里的松子是飘在上面一起吃的配料，不要挑出来。凉喝/热喝随你喜好。

❓ 外国人常见问题 (FAQ)

  • 食醯 (Sikhye / 식혜) 里有酒精吗？ — 几乎没有。虽是发酵米饮，但无酒精。小孩也喝。
  • 餐厅里送的棕色的水，要付钱吗？ — 不用。大麦茶/玉米茶默认免费·无限续杯。
  • 有咖啡因吗？ — 谷物茶 (大麦·玉米)·水果茶·韩方茶大多不含或极低咖啡因。晚上喝也负担小。
  • 双和茶 (Ssanghwacha / 쌍화차) 太像中药味了，正常吗？ — 正常。它是熬煮多种中药材的滋补茶，褒贬差异很大。觉得负担就换红枣茶 (Daechucha / 대추차)·柚子茶 (Yujacha / 유자차)。
  • 柚子茶·生姜茶明明是茶 (tea)，为什么要“像药”一样喝？ — 在韩国有按季节·身体状况喝茶的文化。感冒喝柚子，冷了喝生姜——往往按“功效·情况”而非“味道”来选择。
  • 能买回国吗？ — 柚子清·生姜清·食醯/水正果罐装、大麦茶/玉米茶茶包作为礼物·纪念品很受欢迎。轻便又易于保存。
