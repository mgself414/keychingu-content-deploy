釜山广安里·南川·水营 12家咖啡馆 — 只选外国评论率先用三种语言留下的地方

副标题: 田浦(#246·#1321)、影岛(#1321)与甜点之路(#1324)留白的一条轴线——广安大桥背后的小巷、南川海边路、水营小巷、民乐水边、黄岭山夜景。只选在Naver地图上同时留下英语·日语·中文评论的咖啡馆，共12家，分成4个区域串成半天动线。店内规则(占座·马克杯·归还台)见#1378。

ISSUE 06 · #1381 · 2026-09-17 · 釜山咖啡系列 第4篇

🎯 为什么以"三语评论"为标准

釜山咖啡篇已经有三篇——田浦咖啡街 (Jeonpo / 전포카페거리, #246)、《在冠军之城喝咖啡的方法》(#1321)、《从红豆到意式冰淇淋》(#1324)。但重新跑一遍外国评论数据后发现，釜山81家咖啡馆里有72家不在任何一篇里，其中将近一半集中在水营区 (Suyeong District / 수영구)——广安里 (Gwangalli / 광안리)·南川 (Namcheon / 남천)·水营 (Suyeong / 수영)·民乐 (Millak / 민락)。这一篇补的就是这块空白。

筛选标准只有一个——Naver地图上同时留有英语·日语·中文评论的咖啡馆。不是韩国人气排行，而是判断已经有外国人到访并用三种语言留下痕迹的地方，对下一位外国游客来说最保险。评论数是2026-09的快照，这一篇把每家店的评论数都标了出来。

⚠ 标注原则：营业时间·休息日·菜单只记录公开信息源确认过的内容，未确认的栏位统一标"以Instagram公告为准"。从车站步行的时间只标区域级步行圈——到具体某家店的分钟数，现场看Naver地图的步行导航更准。店内使用规则(占座·马克杯·归还台)见#1378。

① 广安里后巷 — 4家

从广安里海边路往里走一个街区就是小巷。广安站 (Gwangan Station / 광안역)·金莲山站 (Geumnyeonsan Station / 금련산역)(2号线)步行圈。

  • 诺亚咖啡烘焙 — 主打手冲的烘焙工坊。诺亚拼配豆与埃塞俄比亚单品豆、长黑咖啡是招牌。三语评论均衡地留下5·5·5——唯一一家，说明不少外国人是冲着咖啡本身来的。营业时间以Instagram公告为准。
  • 海獭派 — 派大约10种上下(肉派·法式蜗牛派·苹果派)。比起咖啡，派才是主角，当午餐替代很合适。11:30–20:00，周二休息。
  • 野餐咖啡 — 伯爵茶牛奶果酱吐司，店里有两只柴犬(杰克·马可)。11:00–20:00。想看狗狗就白天去。
  • 日记本 — 费南雪·玛德琳烘焙点心店。外语评论只有2条英语，但作为这个区域"打包带走的甜点"角色被收录进来。营业时间以Instagram公告为准。

② 南川海边路 — 3家

南川洞是正面能看到广安大桥的海边路一线。南川站 (Namcheon Station / 남천역)(2号线)步行圈，从广安里沿海边走过来也可以。

  • 苹果咖啡 — 宠物友好咖啡馆 + 甜点。10:00–24:00，全年无休(休息以Instagram公告为准)。这个区域外语评论最多(5·4·4)。
  • BCBL coffee roasters — 烘焙工坊，2楼可看广安大桥景观。美式咖啡·黑橙特调。周二至周日10:00–21:00(点单截止20:30)，周一11:00–21:00。英语评论5条，英语圈比例较高。
  • 新奇咖啡南川店 — 季节浇头松饼(秋天无花果·冬天草莓)、挂耳包与曲奇。看起来与影岛 (Yeongdo / 영도) 店共用一个Instagram，南川店的营业时间要在那个账号上确认。

③ 水营·民乐小巷 — 4家

水营站 (Suyeong Station / 수영역)(2·3号线)后巷与民乐水边。比广安里一侧安静，有一家早晨咖啡馆。

  • 每日幸运 — 以面包为主，希腊酸奶+黑麦面包餐盘，手冲咖啡。07:00开门——这一篇里最早开门的咖啡馆，从这里开始早晨动线才顺。打烊时间以Instagram公告为准。
  • 深睡咖啡 — 水营站10号出口步行1分钟。磅蛋糕与浓郁拿铁，每月更换的本地艺术家展览。10:00–19:00。12家里唯一确认车站可达的一家，雨天首选目的地。
  • 一人事务所 — 每月更换设计的豆沙点心。周一至周六12:00–18:00，周日休息。三语评论3·3·3。
  • 我喜欢 — 咖啡 + 家具·杂货联名空间"伊特姆 (Itteum / 잇틈)"，极简·复古风格。位于民乐水边一侧。营业时间以Instagram公告为准。

④ 黄岭山夜景 — 1家

  • 蓝邦黄岭山店 — 釜山夜景咖啡馆。黄岭山蜂蜜茶₩8,000·拿铁₩7,000·香草豆拿铁₩7,500·冷萃₩6,000。11:00–次日02:00(点单截止01:30)。地铁到不了，在黄岭山观景休息处停车场一带——打车是答案。与半天动线分开，作为单独的晚间行程。

🗺 半天动线 — 广安里 → 南川 → 水营·民乐

1. 早晨 水营站 → 每日幸运(07:00–)面包餐盘 → 深睡咖啡(10:00–，水营站10号出口1分钟)

2. 中午 2号线一站到南川站 → 苹果咖啡 → BCBL 2楼广安大桥景观(→ 新奇咖啡的松饼可选)

3. 下午 从南川沿海边步行到广安里后巷(约15~20分钟) → 诺亚咖啡烘焙的手冲 → 海獭派的派 → 野餐咖啡/日记本二选一

4. 晚上单独安排 打车去黄岭山蓝邦看夜景(到次日02:00)

5. 民乐区域(一人事务所·我喜欢)可以夹在水营站到广安里之间，或配合12:00以后开门的一人事务所安排在白天。

每家咖啡馆的占座·马克杯·归还台规则都一样——第一次来就先看#1378。可带狗的只有苹果咖啡和野餐咖啡。

⚠ 3个常见失误

1. 周日去一人事务所·周二去海獭派 — 两家都休息。先确认星期几。

2. 把黄岭山蓝邦排进步行路线 — 地铁到不了，要单独打车去。

3. 跳过"以Instagram公告为准" — 这一篇里没标营业时间的店，当天答案就在Instagram主页的营业公告里。

⚙ 3个常见问题

1. 只能选一家？ — 咖啡选诺亚咖啡烘焙(三语评论5·5·5)，景观选BCBL 2楼(广安大桥)，夜景选蓝邦。

2. 为什么没有田浦？ — 田浦咖啡街已经在#246·#1321里写过了。这一篇只写田浦之外、外国评论集中的水营区。

3. 支付·点单怎么办？ — 12家都是普通刷卡咖啡馆。点单·取餐·归还流程见#1288·#1378，刷卡登记不了时见#1301。
