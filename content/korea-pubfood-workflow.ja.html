韓国のおつまみ注文・マナーワークフロー — 長寿洞(장수동 / チャンスドン)のチョッパルから広蔵市場(광장시장 / クァンジャンシジャン)のポッサムまで

> 副題：外国人観光客向け5ステップワークフロー + お酒のペアリング・セウジョッ(새우젓 / saeujeot, 塩辛エビの塩辛)のマナー・使える英語フレーズ

ISSUE 03 · #862 · 2026-06-09

🎯 なぜ韓国のおつまみワークフローガイドが必要か

《韓国のおつまみ6種概観》を知っていても、注文・ペアリング・マナーはまた別の話です。韓国のおつまみは四つのまったく異なる場面に登場します：(a) 長寿洞チョッパル横丁(17:00~03:00営業の深夜の定番) (b) 広蔵市場ポッサム横丁(昼間営業、vlogの人気スポット) (c) 鍾路(종로 / チョンノ)のポジャンマチャ(포장마차 / pojangmacha, 屋台)(ソジュ(소주 / soju) + コルベンイムチム(골뱅이무침 / golbaengi-muchim)) (d) 韓定食(한정식 / ハンジョンシク)コース(スユク(수육 / suyuk)・ホンオサマプ(홍어삼합 / hongeo-samhap))。外国人観光客はたいてい(1)セウジョッのマナーを知らない (2)チョッパルとポッサムはサム(쌈 / ssam, 葉野菜で包んで食べるスタイル)で食べるものだと知らない (3)ソジュを飲むときのマナーを知らない (4)ホンオは通好みの食べ物で、日常食ではないことを知らない、という状況です。本ガイドでは5ステップワークフロー、マナー、便利な英語フレーズを紹介します。

★ ひと目でわかる5ステップワークフロー

2️⃣ 注文する 6種 + 1クァン(관, 2~3人前の伝統的な注文単位) / 1人前 1~5分 1クァンは2~3人でシェア
3️⃣ 受け取り·セッティング サム用の葉野菜·にんにく·セウジョッ·キムチ 5~15分 包んで食べる(サム)
4️⃣ 食べる·ペアリング ソジュ·マッコリ·ビールと合わせる 30~90分 飲酒マナー(目上の人が先)

  • 外国人観光客への親切度：★★★★★(英語メニュー、チェーン店で安心)

🍯 サム·セウジョッ·ソジュのマナー概観

包んで食べる(チョッパル·ポッサム·スユク)

1. サム用の葉野菜(サンチュ·エゴマの葉·白菜)を手のひらに乗せる

2. 肉 + にんにく + 少量のセウジョッ + キムチをのせる

3. お好みでサムジャン(쌈장 / ssamjang, 包み用の甘辛みそだれ)を追加(辛口オプション)

4. 手で包んで一口で食べる(全部口に入るサイズに)

5. 口を閉じて噛む(韓国のマナー)

セウジョッのマナー

  • 量：少量でOK(塩気が強い、目安は1mm程度)
  • 用途：チョッパル·ポッサム·スユクに添えて豚肉の臭みを消す
  • 外国人向け説明：「塩辛いエビの塩辛」「ほんの少しでいい」

ソジュのマナー(韓国式)

1. 目上の人に先に注ぐ — 一番年下の人が目上の人に注ぐ

2. 両手で注ぐ — 片手でボトルを持ち、もう片方の手で腕を支える

3. 両手で受け取る — 目上の人に注いでもらうとき

4. 顔をそむけて飲む — 目上の人の前で飲むとき

5. コンベ(건배 / geonbae) — グラスを合わせて「Cheers(치얼스)」と言う

🌶 外国人観光客向け英語フレーズ集

  • 「チョッパル1クァン」 = "One Jokbal set (for 2~3 people)"
  • 「ポッサム + ソジュ」 = "Bossam with soju, please"
  • 「辛くしないで」 = "Less spicy, please"
  • 「ホンオ = 発酵食品」 = "Hongeo = fermented skate (strong smell)"
  • 「割り勘」 = "Split the bill, please"
  • 「乾杯」 = "Cheers! Geonbae!"

⚠ 外国人観光客がよくする7つの勘違い

1. 「チョッパル = ポッサム」：チョッパルは豚足の部位(長寿洞名物) / ポッサムはゆで豚肉 + キムチをサムで包んで食べるもの(広蔵市場名物)です。

2. 「1クァン = 1人前」：1クァンは2~3人でシェアする分量です(1人で食べるなら1人前を別途注文)。

3. 「セウジョッはたくさんつける」：セウジョッは少量だけにしましょう(塩気が強いです)。

4. 「サム = そのまま食べる」：サムは包んで一口で食べるものです(全部口に入るサイズに)。

5. 「お酒を注ぐのは片手でいい」：お酒は両手で注ぐもので、目上の人が先です。

6. 「ホンオ = 普通のおつまみ」：ホンオは通好みの食べ物で、アンモニア臭が強いです。

7. 「チェユク = おつまみ専用」：チェユクはご飯のおかずとしてもおつまみとしても使えます(コスパNo.1)。

⚙ よくある質問8選

1. 最初に食べるならどのチャネル：広蔵ポッサム(昼間、vlogで人気) + 長寿洞チョッパル(夜)。

2. インスタ·vlog向け：広蔵ポッサム横丁、長寿洞チョッパル横丁、鍾路ポジャンマチャ。

3. MZ世代のトレンド：広蔵ポッサム、MZ世代に人気のチョッパルチェーン、チェユク弁当。

4. ソジュ愛好家おすすめ：コルベンイムチム + チョッパル + チェユク。

5. 長寿洞の時間帯：17:00~03:00(深夜の定番)。

6. アレルギー·妊娠中の注意点：《韓国のおつまみ6種概観》の免責事項を参照。

7. 会計·チップ：カードOK / 市場·老舗店は一部現金 / チップ不要。

8. VAT還付：飲食は基本的に還付対象外。

⚠ 医療·安全·食事に関する免責事項

おつまみは一般的な食べ物です。妊婦の方は一部OK(ホンオの発酵食品は避けてください)。子どもも食べられます(辛さは調整してください)。アレルギー(豚肉·魚介類·唐辛子)は事前に伝えてください。お酒は妊婦·未成年NGです。食中毒が疑われる場合は ☎ 1339 へ。本ガイドは一般的な情報提供のみを目的とし、医療アドバイスではありません。

食事制限への対応：

  • ハラール·コーシャ：6種すべて豚肉または魚介類を使用 / ハラール対応なら代わりにビビンバやチャプチェを。
  • ベジタリアン·ビーガン：6種すべて非対応 / 代わりに寺院料理やビビンバを。
  • グルテンフリー：スユク·ポッサム·チョッパルはOK / コルベンイムチムのソミョン(소면 / somyeon, 細めの小麦麺)はNG / チェユクの一部の味付けもNG。
