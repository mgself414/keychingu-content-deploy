🎯 このガイドの使い方

漢江の夜景は夏だけのものではありません。2026年10月も盤浦の噴水は毎晩3回動き、遊覧船には22時出航の便があり、漢江バスは東・西の2路線が走り、ノドゥル島では10/11まで光の祭りが開かれています。以下の時間と料金は、2026-10-08にソウル市のお知らせと運営会社の公式ページで読み取った値だけを載せました。漢江事業本部のサイトは本文が開けなかったため、噴水とプールはソウル市の公式お知らせで代用しています。漢江バスの運賃は公式資料どうしで食い違っており(2,500ウォンと3,000ウォン)、そのまま併記しました。以前のガイドにあった「噴水は世界一」(→ 2008年ギネス「世界一長い橋の噴水」1,140m)、「遊覧船 1.5万~2.5万ウォン」、「12時・21時・21:30の噴水」といった値は現在と異なるため外しました。夏のプール(6/19~8/30)とソウル世界花火祭り(9/5)は終わりました。

⛲ 盤浦月光虹噴水 — 夜3回

  • 盤浦大橋の両側から噴き出す噴水で、2008年ギネス「世界一長い橋の噴水」(1,140m)(ソウル市)。以前のガイドの「世界一」の代わりにこの表現を使います。
  • 2026年は節電運営で1日3回(19:30・20:00・20:30、各20分)に減りました(ソウル市のお知らせ 2026-06-01)。10月の運営の有無・シーズン終了日・強風などの中止基準は公式に未掲示です — 行く前に漢江事業本部のお知らせを確認してください。
  • 公園は無料・24時間。9号線の新盤浦駅 (Sinbanpo / 신반포역) 1番、または高速ターミナル駅 (Gosok Terminal / 고속터미널역) 8-1・8-2番出口です。

🚢 遊覧船・漢江バス — 水の上から

  • イーランドクルーズ (E-Land Cruise / 이랜드크루즈)(汝矣島船着場、汝矣東路290): サンセット18:00 · ムーンライト・ミュージック19:00 · スターライト22:00 · 花火ミュージック19:30(指定日)。料金はツアー19,900 / サンセット・スターライト25,900 / ムーンライト32,900 / 花火45,900ウォン(公式)。
  • 漢江バス (Hangang Bus / 한강버스): 2026-03-01に再開。東線は蚕室~汝矣島、西線は麻谷~汝矣島、船着場は7カ所(+ソウルの森は10月まで)。大人運賃は公式資料が2,500ウォンと3,000ウォンに割れているため、乗船前に確認してください。夜の終電は出典が食い違っています(東線 20:27到着 vs 22:30) — 夜に利用する場合は当日の時刻表を確認しましょう。

🏝 セビッ島・ノドゥル島・ソウルダル

  • セビッ島 (Some Sevit / 세빛섬)(盤浦): レストラン・ルーフトップバー(公式)。時間と入場料は公式に未掲示です。
  • ノドゥル島 (Nodeulseom / 노들섬): ソウルライト漢江光の島祭り 10/2~10/11 18:30~22:30、無料シャトル・汝矣島発の特別遊覧船(ソウル市)。9/18にオープンした1.5kmの水辺の散策路があります。
  • ソウルダル (Seouldal / 서울달): 8~10月 日~木 12~22時・金土 12~23時(ソウル市)。2026年の料金と月曜休みは未掲示です。

🍗 汝矣島 — チメク・ラーメン文化

  • VisitSeoulは、汝矣島漢江公園 (Yeouido Hangang Gongwon / 여의도한강공원) の「必ず食べたいもの」としてチメクとコンビニのインスタントラーメンを挙げています(公式)。汝矣ナル駅 (Yeouinaru / 여의나루역) 2・3番出口。トゥクソム・望遠・蚕院の公園の駅・出口は公式に未掲示です。

🏊 夏のもの — 今年は終わりました

  • 漢江のプール・水遊び場 2026: 6/19~8/30、7/3から22時までの夜間営業、プール 3,000/4,000/5,000・水遊び場 1,000/2,000/3,000ウォン、蚕院 (Jamwon / 잠원) は運営せず(ソウル市)。来年6月にお知らせがあります。
  • ソウル世界花火祭り (Seoul Segye Bulkkot Chukje / 서울세계불꽃축제) 2026は9/5に汝矣島で終わりました。

⚠ よくある失敗 5つ

1. 噴水の21時の回を待つ — 2026年は19:30・20:00・20:30の3回です。

2. 遊覧船を2万ウォンで見積もる — ムーンライト32,900・花火45,900ウォンです。

3. 漢江バスの運賃を決めつける — 2,500~3,000ウォンで食い違いがあります。乗船前に確認を。

4. 10月にプールや花火祭り — 終わりました。代わりにノドゥル島の光の島祭り(~10/11)へ。

5. 夜の漢江バスで帰る — 終電の時間は出典が食い違っています。地下鉄を基本に。

⚙ FAQ 6つ

1. 1日の夕方コースは? — 汝矣島のチメク(汝矣ナル駅 2番)→ 遊覧船 19:00 または 22:00 → または盤浦の噴水 19:30~20:50。

2. 噴水は無料? — 無料です。公園は24時間。

3. 遊覧船はどこから? — 汝矣島船着場(汝矣東路290)。

4. 漢江バスはどこまで? — 蚕室~汝矣島、麻谷~汝矣島。ソウルの森は10月まで。

5. 10月の祭りは? — ノドゥル島の光の島祭り 10/2~11、18:30~22:30、無料。

6. ソウルダルは何時まで? — 金・土は23時、それ以外は22時(8~10月)。
