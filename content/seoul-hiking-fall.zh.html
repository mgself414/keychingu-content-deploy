📍 清溪山 — 清溪山·清溪山Malgeun Sup公园

清溪山(Cheonggyesan / 청계산)，瑞草区(Wonji-dong / 원지동)，☎ 绿色城市科(Seochogu Pureun Dosi-gwa / 서초구 푸른도시과) 02-2155-6869，是位于首尔与京畿道城南(Seongnam / 성남)、果川(Gwacheon / 과천)、义王(Uiwang / 의왕)交界处的山。据说青龙从这里升天，所以也叫Cheongnyong山(Cheongnyongsan / 청룡산)。环绕首尔大公园(Seodaegongwon / 서울대공원)、Seoul Land、国立现代美术馆(Gungnip Hyeondae Misulgwan / 국립현대미술관)的山麓就是清溪山。有森林、溪谷、清溪寺(Cheonggyesa / 청계사)、森林浴场，登山路很多，是家庭登山的热门去处。

  • 山顶望京台(Manggyeongdae / 망경대)(618.2m):设有政府设施，不能攀登。
  • 玉女峰(Oknyeobong / 옥녀봉)·Hyeoleup岭(Hyeoleupjae / 혈읍재)·Geumjeong水(Geumjeongsu / 금정수):从Juam洞(Juam-dong / 주암동)一侧朝望京台方向攀登，会先到玉女峰，那里曾是Chusa金正喜(Gim Jeonghui / 김정희)的生父金鲁敬(Gim Nogyeong / 김노경)的墓地，再经过朝鲜学者郑汝昌(Jeong Yeochang / 정여창)翻越过的Hyeoleup岭，望京台正下方有药水Geumjeong水。
  • 开放时间:全天开放。休息日:全年无休。停车:可以。

清溪山Malgeun Sup公园(Cheonggyesan Malgeun Sup Gongwon / 청계산맑은숲공원)，义王市(Cheonggye-ro 475 / 청계로 475)，☎ 义王市厅公园绿地科(Uiwangsicheong Gongwon Nokji-gwa / 의왕시청 공원녹지과) 031-345-3533，是为在森林中进行芬多精浴和森林浴而建的公园。设有冷杉和水杉林治愈空间、休憩广场、生活体育设施、散步路，并建成了身体不便的人也可以出入的无障碍公园。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。婴儿车租赁:没有。

📍 冠岳山 — 冠岳山·冠岳山自然公园·冠岳山Mujangae Sup路

冠岳山(Gwanaksan / 관악산)，冠岳区(Gwanak-ro / 관악로)，☎ 冠岳区休闲城市科(Gwanak-gu Yeoga Dosi-gwa / 관악구 여가도시과) 02-879-6552，是耸立在汉江以南的632.2m山峰，因山顶的岩石像戴着帽子而得名。1968年被指定为都市自然公园。离市中心近，一天就可以登上。春天入口一带樱花盛开，杜鹃花开时有时举办杜鹃花节，秋天可以赏枫叶，冬天可以看雪景。山顶有Wongak寺(Wongaksa / 원각사)和Yeonju庵(Yeonjuam / 연주암)，所有登山路都汇集在悬崖上的恋主台(Yeonjudae / 연주대)。

  • 代表登山路:从冠岳区(Sillim-dong / 신림동)首尔大学入口(Seouldaehakgyo Ipgu / 서울대학교 입구)出发的路，以及从果川市(Jungang-dong / 중앙동)果川中学(Gwacheon Jung-hakgyo / 과천중학교)后面攀登的路。
  • 休息日:全年无休。停车:可以。

冠岳山自然公园(Gwanaksan Jayeon Gongwon / 관악산자연공원)，冠岳区(Sillim-dong San 27-1 / 신림동 산27-1)，☎ 冠岳区厅公园绿地政策科(Gwanak-gucheong Gongwon Nokji Jeongchaek-gwa / 관악구청 공원녹지정책과) 02-879-6521，是建在冠岳山上的公园。有带凉亭和喷泉的湖水公园、备有儿童图书和环境图书的森林图书馆、传统户外小剧场、Mujangae Sup路、瞭望台。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

冠岳山Mujangae Sup路(Gwanaksan Mujangae Supgil / 관악산 무장애숲길)，冠岳区(Gwanaksan Nadeulgil 149 / 관악산나들길 149)，☎ 冠岳区厅休闲城市科(Gwanak-gucheong Yeoga Dosi-gwa / 관악구청 여가도시과) 02-879-6551，是冠岳山内的木栈道森林路。全程坡度在8%以下，轮椅和婴儿车也可以上去。有像散步一样行走的环形森林路，也有沿之字形上坡边走边看景的攀登型森林路。沿途设有休息处、椅子和野餐桌。

  • 开放时间:全天开放。休息日:全年无休。

📍 步行路线 — 首尔环城步道11路线冠岳山线路

首尔环城步道11路线冠岳山线路(Seoul Dullegil 11-Koseu Gwanaksan Koseu / 서울둘레길 11코스 관악산코스)，铜雀区(Dongjak-daero Jiha 3 / 동작대로 지하3)，☎ 02-779-7902~4，是在全长156.5km、共21条路线环绕首尔一周的首尔环城步道(Seoul Dullegil / 서울둘레길)中，以“民间信仰与佛教相遇的路”为主题的路线。沿途有历史·文化遗迹。靠近地铁舍堂站(Sadang-yeok / 사당역)和冠岳山站(Gwanaksan-yeok / 관악산역)。

  • 长度·时间:共5.7km，约2小时30分钟。
  • 开放时间:全天开放。休息日:全年无休。

⚠ 行前须知 3 点

  1. 清溪山山顶望京台(618.2m)不能攀登 — 设有政府设施。
  2. 冠岳山Mujangae Sup路坡度在8%以下 — 轮椅和婴儿车可以上去。
  3. 首尔环城步道11路线约需2小时30分钟 — 全长5.7km，靠近舍堂站·冠岳山站。

⚙ FAQ 2

Q. 冠岳山从哪里登?

A. 按观光公社登记信息，从冠岳区(Sillim-dong / 신림동)首尔大学入口(Seouldaehakgyo Ipgu / 서울대학교 입구)出发的登山路有代表性，也有从果川市(Jungang-dong / 중앙동)果川中学(Gwacheon Jung-hakgyo / 과천중학교)后面攀登的路。

Q. 有行走不便的人也能去的森林路吗?

A. 冠岳山Mujangae Sup路(坡度8%以下，轮椅·婴儿车可以)和义王清溪山Malgeun Sup公园(无障碍公园)。两处都全天开放。
