🥞 4채널 deep dive

🛒 광장시장 빈대떡 골목 (Gwangjang Bindaetteok)

핵심 가치: vlog #1 + 즉석 부치기 + 노포 정통.

  • 위치: 서울 종로구 광장시장
  • 시그니처: 녹두빈대떡·고기빈대떡·김치빈대떡·즉석 부치기
  • 가격 anchor: 5,000~15,000원/1개
  • 시간: 09:00~22:00
  • 외국인 친화도: ★★★★★ (vlog #1·MZ #1)
  • MZ cross: 마약김밥 골목·보쌈 골목

🍶 전통주점·MZ 한식당 (Traditional Pub·MZ)

핵심 가치: 비 오는 날 파전 + 막걸리 #1 + 한국 정통 문화.

  • 추천 매장:
  • 광장시장·인사동 전통주점 — 정통
  • MZ 한식당 (홍대·강남·성수) — 트렌드
  • 가격 anchor: 파전 8~20k + 막걸리 5~10k
  • 시간: 17:00~24:00
  • 외국인 친화도: ★★★★

🍻 포장마차 (Pojangmacha)

핵심 가치: 소주안주 + 노포 정통 + 골뱅이 cross.

  • 위치: 종로 포장마차 골목·강남 포장마차
  • 시그니처: 김치전·핫바·골뱅이무침
  • 가격 anchor: 5,000~12,000원
  • 시간: 18:00~02:00
  • 외국인 친화도: ★★★ (한국어)

🍱 한정식·명절 동그랑땡 (Hanjeongsik·Holiday)

핵심 가치: 명절·제사 정통 + 동그랑땡 + 한정식 코스.

  • 추천 매장: 신라호텔 라연·삼청각·인사동 한정식
  • 가격 anchor: 한정식 코스 40,000~150,000원 (동그랑땡 포함)
  • 시간: 11:30~22:00
  • 외국인 친화도: ★★★★
  • 명절 시기: 설날 (2026/2/17)·추석 (2026/9/25) ([#846](#846))

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 분위기·페어·매니아 완전 다름. vlog = 광장 / 비 오는 날 = 전통주점 / 소주 = 포장마차 / 명절 = 한정식.

2. "광장 = 일반": 광장 빈대떡 = vlog #1 즉석 부치기 정통.

3. "전통주점 = 어렵다": 전통주점 = 비 오는 날 한국 문화 정통·외국인 친화.

4. "포장마차 = 한국어 X": 포장마차 = 한국어 정통·번역 앱 필요.

5. "명절 = 외국인 X": 한정식 명절 = 연중 동그랑땡 정통 (명절 외 시즌도 OK).

⚙ FAQ 8개

1. 첫 전 채널 = 어디: 광장시장 녹두빈대떡 (#1 vlog) → 전통주점.

2. 인스타·vlog: 광장 빈대떡 (#1)·비 오는 날 파전.

3. MZ 트렌드: 광장 (#1)·전통주점.

4. 막걸리 매니아: 전통주점 (비 오는 날 #1).

5. 명절 매니아: 한정식 동그랑땡.

6. 알레르기·임신: [#882 disclaimer](#882) 참조.

7. 결제·팁: 카드 OK / 시장·포장마차 = 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

전 4채널 모두 일반 음식·기름 사용. 임신부·어린이 = OK (막걸리 X). 알레르기 (밀가루 글루텐·해산물·돼지·계란·녹두) 사전 고지. 막걸리 = 6~8% 알코올. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 파전·감자전·김치전 = OK·동그랑땡·녹두빈대떡·해물파전 X·막걸리 알코올 X.
  • 채식·비건: 파전·감자전·김치전 채식 OK (계란 옵션).
  • 글루텐 free: 어려움·감자전 = 적음 (사전 확인).
