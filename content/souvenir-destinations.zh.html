外国游客购买韩国纪念品时最常犯的3个错误

1. “免税店 = 最便宜”的误解

免税店对于 国际品牌 (如香奈儿·迪奥等) 确实更便宜，但 K-Beauty (韩国美妆)·K-Food (韩国美食)·卡通周边 在市内商店 (如 又来屋 (Olive Young / 올리브영)·大创 (Daiso / 다이소)·LINE FRIENDS (라인프렌즈)) 价格更低或相近，且 种类更加多样。

2. 在 仁寺洞 (Insadong / 인사동) 购买所有传统纪念品

仁寺洞 (Insadong / 인사동) 的优势在于 对外国游客友好 + 英语服务周到，但 价格是普通市场的1.5~2倍。同样是刺绣手包，在 广藏市场 (Gwangjang Sijang / 광장시장) 1楼可能卖8千韩元，而在 仁寺洞 (Insadong / 인사동) 则要1.5万~2万韩元。

3. 在机场免税店集中购买 K-Beauty (韩国美妆)

机场免税店在 出境前1~2小时 人流密集，热门商品容易售罄。建议提前在 市内免税店 (如 乐天 (Lotte / 롯데)·新世界 (Shinsegae / 신세계)) 购买，然后在机场提货柜台领取，这样更稳妥。

外国游客常见问题

Q1. 退税 (Tax Refund / 세금환급) 是如何办理的？

  • 单笔收据 3万韩元以上，出示外国人护照
  • 店内 即时退税 (Instant Refund) 或 机场退税
  • 退税金额: 约 9%~10% (增值税 + 部分个别消费税)
  • 明洞 (Myeongdong / 명동) 又来屋 (Olive Young / 올리브영)·大创 (Daiso / 다이소)·免税店设有即时退税柜台

Q2. 在免税店购买的商品如何领取？

  • 市内免税店支付 → 在 仁川机场 (Incheon Gonghang / 인천공항) 提货柜台 领取
  • T1 14号登机口 / T2 28号登机口附近
  • 建议在出境前3小时抵达

Q3. 可以使用外国银行卡支付吗？

  • 明洞 (Myeongdong / 명동)·仁寺洞 (Insadong / 인사동)·免税店·百货公司·又来屋 (Olive Young / 올리브영)·大创 (Daiso / 다이소): VISA/Master/Amex 均可
  • 广藏市场 (Gwangjang Sijang / 광장시장)·南大门市场 (Namdaemun Sijang / 남대문시장) 摊位 (Jwapan / 좌판): 优先使用现金
  • 部分店铺可能拒绝外国银行卡 → 提前准备10万韩元面值 + 5万韩元面值纸币

Q4. 携带韩国化妆品回国有限制吗？

  • 美国: 化妆品液体通常可以 (遵守机内100毫升规定)
  • 日本: 每件商品少于24个
  • 中国: 化妆品简单产品在5千人民币以内
  • 航空行李液体100毫升规定仅适用于随身行李 — 托运行李不受此限

Q5. 机场免税店 vs 市内免税店 哪个更好？

  • 市内: 种类多样，时间充裕，提货柜台系统完善
  • 机场: 时间不足·少量购买·糖果·饼干等收尾购物
  • 推荐: 市内70%，机场30%

Q6. 只有在韩国才能买到的真正具有韩国特色的礼物是什么？
