⚠ 외국인 자주 실수 5가지

1. "면세점 = 공항만": 면세점 = 시내 면세점 (롯데 명동·신라 장충·신세계) + 공항 (인천 1·2 터미널·김포) + 온라인 (롯데 인터넷·신라 인터넷) + 외국인 매니아 풀세트.

2. "외국인 면세 = 한국인보다 비쌈": 외국인 면세 = 5,000원 면세 한도 + 외국인 가성비 1번지 + 출국 시 재반입·외국인 매니아 1번지·#398 통합.

3. "롯데 명동 = 한국인만": 롯데면세점 명동 = 한국 #1 면세점·외국인 매니아 #1 + 24h + LG생활건강·K-Beauty 풀세트 + 영어·중문·일문 풀세트.

4. "K-Beauty 면세 = 비쌈": K-Beauty 면세 = 올리브영 면세 + LG생활건강·아모레 면세 + 외국인 가성비 1번지 + 외국인 매니아 1순위·#389 통합.

5. "온라인 면세 = 외국인 못 씀": 온라인 면세 = 롯데·신라 인터넷 면세점 영어·중문·일문 풀세트 + 외국인 영어 OK + 외국인 매니아 1번지·#398 통합.
