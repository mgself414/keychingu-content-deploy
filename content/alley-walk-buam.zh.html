小巷漫步⑤ 付岩洞——城门外第一个社区，巷子尽头的秘密溪谷

副标题：景福宫坐10分钟公交，首尔忽然变成山间社区。从尹东柱文学馆经彰义门走进付岩洞巷子，到巷尾展开的白沙室溪谷，约3小时，边走边讲蝾螈溪谷为何留在市中心旁边。Seoul Alley Walks扩展2号。

ISSUE · #1344 · 2026-09-02

🎯 定调——都城外第一个社区

付岩洞 (Buam-dong / 부암동) 是汉阳都城 (Hanyangdoseong / 한양도성) 西北门彰义门 (Changuimun / 창의문) 正外侧的第一个社区。都城内(景福宫、西村)的繁华，只隔一道城门，就变成了巷子和山脚——而巷子尽头，还藏着一处保留朝鲜士大夫别墅遗址的溪谷。这条路线是本系列里"最接近自然的巷子"。

  • 总耗时：约3小时(含展览、咖啡时间)·推荐时段：上午10~11点出发——趁天亮走完溪谷段，下午在咖啡馆收尾
  • 坡度：中~高——山脚社区+溪谷下行路段。务必穿运动鞋，雨后溪谷小径湿滑。
  • 交通：这是一个没有地铁站的社区——景福宫站 (Gyeongbokgung Station / 경복궁역) 3号出口 → 换乘开往紫霞门岘 (Jahamun-gogae / 자하문고개) 方向的公交，约10分钟，是标准进入路线。

🚶 路线——按行走顺序

① 景福宫站3号出口 → 换乘公交 → 紫霞门岘站 (约10分钟)

  • 从公交车爬上山岘的那一刻起，路线就已经开始——车窗外的风景从市中心变成山间社区。

② 紫霞门岘 → 尹东柱文学馆 (Yun Dong-ju Literature Museum / 윤동주문학관) (步行约2分钟)

  • 由旧自来水加压站改建而成的小型文学馆。诗人尹东柱的手稿与以水井为主题的展示空间——规模虽小，密度很高。

③ 文学馆 → 彰义门 (步行约3分钟)

  • 📖 叙事1——一道城门划出的界线：彰义门是汉阳都城四小门中的西北门。门内曾是国王的都城，门外就是付岩洞——城门外第一个社区这个位置，让这里的清静得以延续数百年。城门楼下方可以直接穿行而过。

④ 彰义门 → 付岩洞巷弄 (步行约15分钟)

  • 咖啡馆和小商店零星散落在山脚巷弄里——围墙外北岳山 (Bukaksan / 북악산) 与仁王山 (Inwangsan / 인왕산) 轮流入镜。因为是坡地上的巷子，每走几步风景就换一次，这是这一段的乐趣。

⑤ 付岩洞巷弄 → 白沙室溪谷 (Baeksasil Valley / 백사실계곡)·白石洞天 (Baekseok-dongcheon / 백석동천) (步行约15分钟，下行)

  • 住宅区巷子走到尽头，森林与溪谷突然在眼前展开。
  • 📖 叙事2——秘密溪谷的真面目：白石洞天既是保留朝鲜士大夫别墅(别庄)遗址的名胜古迹指定地，也是首尔市生态·景观保护区——蝾螈和溪蟹栖息的一级生态，罕见地保留在市中心旁边。站在池塘遗址和柱础石上，会有片刻不敢相信这是"首尔市内"。

⑥ 溪谷 → 洗剑亭 (Segeomjeong / 세검정) 方向下山 → 收尾 (步行约15分钟)

  • 沿溪谷往下走，就是洗剑亭亭子——路线在弘济川 (Hongjecheon / 홍제천) 边结束。可搭公交返回景福宫站，或接着走向西村 (Seochon / 서촌)(#014)。

🙏 小巷·溪谷礼仪

  • 白沙室溪谷是保护区——不要下水，不要翻动石头(蝾螈栖息地)，禁止饮食、丢垃圾。
  • 付岩洞巷弄是安静的住宅区——禁止拍摄围墙内部，说话请放低声音。
  • 天黑后不要走溪谷路段——没有照明。

💡 避坑提醒

  • 没有地铁站——即使地图App建议步行30分钟的路线，公交才是正确答案。下车站是"紫霞门岘·尹东柱文学馆"。
  • 溪谷入口夹在巷子之间，第一次很容易找不到——请跟着白沙室溪谷指示牌的箭头走。
  • 餐厅、便利店很少见——水和零食请在进入前备好。
