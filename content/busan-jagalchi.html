ISSUE 03 · #244 · 2026-05-19

🎯 왜 부산 자갈치·국제시장인가

부산 = 한국 1번지 수산시장 도시 + 자갈치시장 (Korea's #1 seafood market) + 국제시장 (Korea's #1 import-export market 1948) + BIFF 거리 (영화 매니아) + 남포동·용두산공원 통합. 부산 정통 시장 1번지 deep dive. 키친구 부산 시리즈 ②.

★ 한눈에 12선

⚠ 외국인 자주 실수 5가지

1. "자갈치 = 일반 시장": 자갈치시장 = 한국 1번지 수산시장 + 외국인 vlog 1순위 + 새벽 경매 (05:00~07:00) + 회·생선 정통 1번지. 부산 정통 culture deep dive 1번지.

2. "국제시장 = 영화에서만": 국제시장 (1948) = 한국 정통 수입 시장 1번지 + 영화 "국제시장" 무대 + 외국인 1순위 + 깡통 시장 + 부평 깡통야시장 통합.

3. "부산 회 = 어디나 같음": 자갈치 정통 회 = 외국인 vlog 매니아 1순위 + 1세대 회 정통 + 한국 1번지 신선도. 50,000~150,000원 1인.

4. "태종대 = 못 감": 태종대 = 부산 1번지 자연 + 절벽·달뜨는 자리 + 외국인 매니아 1순위 + 자갈치·영도 통합.

5. "용두산공원 = 노인만": 용두산공원 + 부산타워 120m 360° = 외국인 인스타 1번지 + 자갈치·BIFF 동선 통합.

⚙ FAQ 6개

1. 외국인 자갈치 동선: 부산역 KTX → 자갈치역 (지하철 1호선) → 자갈치시장.

2. 외국인 자갈치 회 1순위: 자갈치 정통 회·횟집 (50,000~150,000원 1인) + 새벽 경매 매니아.

3. 외국인 국제시장 매니아: 1948 영화 무대 + 부평 깡통야시장 통합.

4. 외국인 영도 인스타: 흰여울 문화마을 + 태종대 + 송도 케이블카 (외국인 vlog 1번지).

5. 외국인 BIFF 매니아: BIFF 거리 (남포동) + #247 BIFF·영화 통합 연결.

6. 외국인 부산 1박2일 추천: Day 1 해운대 (#243) / Day 2 자갈치·국제시장·BIFF.
