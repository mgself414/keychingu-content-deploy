🎯 なぜ限定式4チャンネル比較ガイドなのか

[#831 限定式 6段階マトリックス](#831) + [#832 ワークフロー](#832) 知っていても - チャンネル選択が次の決定。韓国限定式チャンネル＝（1）正統限定レストラン集（仁寺洞・三清洞・龍水山老舗）・（2）ホテル韓食堂（新羅ラヨンミシュラン3スター・ロッテ・ウェスティン）・（3）査察食品限定式（山村・足雨供養・金堂）・（4）地域限定式（全州・江陵京）価格30,000ウォン→500,000ウォン、雰囲気老舗→ラグジュアリー→査察→地域本格。本ガイドは4チャンネル直接比較+セグメント(単独・カップル・家族・MZ・予算型)別1位。 会・BBQ・クッパ・分食・麺類・チキン・デザート・キムチ・保養食・酒clusterパターン**適用限定式バージョン。

🎯 segment別1位おすすめ

👤 ソロ旅行者 (Solo)

  • 1順位: 査察食品（山村・発雨供養） — 1人walk-in OK、30,000～50,000ウォン、静的・マニア
  • 2順位: 正統限定食集 (仁寺洞・三清洞 lunch)
  • 3順位：地域限定式（全州・江陵日帰り）
  • 回避: ホテル韓国料理店 (1人のコスパ ↓)

💑 カップル (Couple)

  • 1順位: ホテル韓食堂(新羅ラヨン・ロッテ) — 1周年・記念日、1人200,000～500,000ウォン、ミシュラン
  • 2順位：正統限定食集（韓屋デート、三清閣・龍水産）
  • 3順位：地域限定式（全州韓屋村）
  • 回避：査察料理（デート雰囲気↓）

👨‍👩‍👧 ファミリー (Family)

  • 1ランキング: ホテル韓国料理店(ルーム+家族) — 4人部屋+サービス料= 500,000～1,000,000ウォン
  • 2順位: 本格限定式集(家族左食)
  • 3ランキング：地域限定式（家族旅行）
  • 回避：査察食品（子供の静的↓）

🎨 MZ トレンド(MZ)

  • 1ランク: ホテル韓国料理店(新羅ラヨンミシュラン) — インスタ・vlog 1番地
  • 2順位: 本格限定式集(韓屋vlog)
  • 3ランキング: 査察食品(査察マニアvlog)
  • 回避：地域限定式のみ（トレンディ↓）

🎒 バックパッカー・予算型 (Budget)

  • 1順位: 査察食品 lunch (30,000～50,000ウォン) — マニアのコスパ
  • 2順位：正統限定式ランチ（40,000～60,000ウォン）
  • 3順位：地域限定式（全州・江陵ランチ）
  • 回避: ホテル韓国料理店（予算超過）

🏛 4チャンネル deep dive

＃＃＃🏛本物の限定レストラン（伝統）

核心価値: 史代部・両班家族正統限定式+韓屋雰囲気+苛性雨正統。

  • おすすめ店（ソウル）：
  • 仁寺洞限定式cluster - 韓日館・美津・駅前会館など
  • 三清洞限定式 — 韓屋正統派
  • 龍水山（1980老舗）・電源（伝統）
  • メニュー: 6段階コース（お粥・前・主料理・湯・ご飯・厚食）＋おかず12+種
  • 価格 anchor: 40,000～150,000ウォン (1人コース)
  • 外国人にやさしい: ★★★★（英語の一部）
  • 予約：1週間前に推奨
  • 決済：カードOK /一部老舗現金/ サービス料X

🏨 ホテル 韓国料理 (Hotel Premium)

核心価値: 宮中正統+ミシュラン+ラグジュアリー+英語+接待1位。

  • おすすめホテル（ソウル）：
  • 新羅ホテルラヨン (La Yeon, ミシュラン 3スター Seoul 2017~連続) — 韓国 韓国料理 #1
  • ロッテホテル韓食堂 — 本格的な限定食
  • ウェスティン朝鮮ソウル — ラグジュアリー
  • フォーシーズンズ・バンヤンツリー — グローバルラグジュアリー
  • メニュー: 宮中正統6～12コース（フレーズ・新鮮路・宮中料理）
  • 価格 anchor: 100,000~500,000ウォン + サービス料 10% + 税 10%
  • 外国人親和性: ★★★★★ (英語・予約・1ランク)
  • 予約: 1～2週間前必須 (キャッチテーブル・電話・ホテルコンシェルジュ)
  • ドレスコード: Smart casual (ジーンズ・ノースリーブ・ショーツX)
  • 決済：ルームチャージ+カード+サービス料10%+税10%

🪷 査察食品限定式 (Buddhist Temple)

核価値: ベジタリアン・ハラール・コーシャ可能 + 5勲菜を除く + 静的マニア。

  • おすすめ店（ソウル）：
  • 山村（仁寺洞、寺院食品老舗）
  • バルウ供養（仁寺洞、査察食品限定式）
  • 金堂 (仁寺洞・江南)
  • 推奨店舗（脂肪）：
  • 陳関寺テンプルステイの食事 - 本格的な寺院
  • 海印寺・通道士テンプルステイ — マニア1番地
  • メニュー: 5勲菜を除く（ニンニク・ネギ・ネギ・タラ・エキスパン）＋山菜・豆腐・きのこ・野菜油・醤油
  • 価格 anchor: 30,000~100,000ウォン
  • 外国人親和性: ★★★★ (菜食・ハラルマニア)
  • 予約：1〜2週間前に推奨
  • 決済：カードOK / サービス料X（査察）
  • 詳細: [#800 査察食品](#800)

🗺 地域限定式 (Regional)

核心価値: 地域シグネチャー+韓屋村+ローカル正統。

  • おすすめエリア:
  • 全州韓屋村 — ビビンバ・もやしクッパ限定食1番地
  • 江陵限定式 — 山菜・シーフード
  • 慶州限定式 — 新羅本格・伝統
  • 安東限定式 — 安東焼酎・干し鮭
  • メニュー：地域シグネチャー6コース（伝統+地域食材）
  • 価格 anchor: 30,000~100,000ウォン
  • 外国人親和性: ★★★ (地域韓国語多)
  • 予約: walk-in 一部OK/人気店=1週間前
  • お支払い：カードOK /一部の現金

＃＃⚠外国人の頻繁な誤り5つ

1. "4チャンネル = 類似": 価格・雰囲気・予約完全相違。苛性比＝査察/正統＝仁寺洞/ラグジュアリー＝ホテル／地域＝全州。

2. "ホテル=高価だけ": 新羅ラヨン= ミシュラン3スター1番地 (正統価値)。

3. "査察食品=マニアのみ": 査察食品=菜食・ハラール・コーシャ1番地 +外国人にやさしい★。

4. 「地域限定式=小さな食堂」: 全州韓屋村限定式=全国#1韓国式マニアcluster。

5. "ドレスコードX": ホテル = smart casual 必須。

⚙ よくある質問8件

1. 初回限定式 = どのチャンネル: 仁寺洞本格限定式1順位(コスパ+正統)。ホテルは記念日。

2. インスタ・vlog 1順位: 新羅ラヨン(ミシュラン3スター)・三清閣・仁寺洞韓屋・査察食品産村。

3. デート・記念日: 新羅ラヨン(#1) + ホテル韓食堂 + 三清閣。

4. 会食・おもてなし: ホテル韓食堂(#1) +本格限定食集。

5. ベジタリアン・ハラール・コーシャ: 査察料理 ([#800](#800)) = #1 + ベジタリアン限定食事前リクエスト。

6. アレルギー・妊娠: [#831・#832 disclaimer](#831)参照。

7. 決済・チップ: 一般 = カードOK / ホテル = サービス料10% +税10% /チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

限定式4チャンネルとも6コース食事（1.5～3h）。妊婦・免疫低下＝煮込んだメニュー推奨。アレルギー（シーフード・牛・豚・卵・ナッツ・蜂蜜）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗情報免責: 限定式・ホテル・査察・地域運営変動 - 訪問前NAVER/Kakao mapまたは公式サイト確認。

食事制限 fallback:

  • ハラール・コーシャー：一般限定式＝ビハラル。 → 査察食品限定式 = #1 ([#800](#800))。
  • ベジタリアン・ビーガン: 査察料理 OR 正統・ホテル・地域 = 事前要請(雑彩・前・チゲ菜食オプション)。
  • グルテンフリー: 味付け（醤油・コチュジャン）多。事前店舗確認。
