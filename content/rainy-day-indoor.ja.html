なぜ梅雨シーズンの室内が必要なのか

ソウルの梅雨（6月中旬~7月）＝雨でも途切れない室内コースが必要 + 聖水・弘大・江南の大型カルチャー複合施設・展示・モール・地下動線フルセット + 傘なしで楽しめる外国人向け雨プラン。外国人のペインポイント＝「雨で予定が台無しになる」→ 室内クラスター + 地下接続動線で解消します。

ソウルの梅雨は、年間降水量の約30~35%が6~7月の2カ月に集中します。1日50mm以上の豪雨が突然降る日も少なくありません。この時期にソウルを訪れる外国人旅行者に共通する悩みは、大きく2つあります。

1. 予約した屋外プランが雨で崩れたとき、代わりの選択肢がない。

2. どこが室内なのか、どのくらいの規模なのか、英語が通じるのかが分からない。

本ガイドはこの2つの悩みを解消します。聖水・弘大・江南の3エリアに雨インフラ軸を加えた4軸12選、実在するスポットのみを掲載しています。

外国人がよくやる失敗TOP3

失敗1：「雨の日はCOEXしかないと思っていた」

COEXは確かに正解ですが、聖水・弘大にも大型室内カルチャー複合施設があります。江南まで1時間以上移動しなくても、宿泊エリアだけで完結できます。弘大に宿泊しているなら、KT&Gサンサンマダン + メセナポリスモールで半日を埋められます。

失敗2：傘一本を信じて地下鉄駅から出たら豪雨

ソウルの梅雨は単なる小雨ではありません。5分で傘が無力になるような豪雨の日もよくあります。COEX・江南エリアは地下鉄駅から室内へ直結する地下動線が完備されています。この動線を事前に把握しておけば、傘なしで移動できます。詳細は本ガイド#10で解説します。

失敗3：無料だと思って行ったらカード不可+現金なし

COEXピョルマダン図書館は完全無料です。アクアリウムは₩29,000でカード利用可能です。聖水の倉庫型カフェの一部は注文必須（入場料の代わりに最低ドリンク1杯）。脱出ゲームは現地予約より事前予約が圧倒的に有利です — 雨の日は同時訪問者が集中し、現地待ちが1~2時間発生します。

12選4軸 深掘り

軸1：聖水（3選）

1. 聖水連邦

タイプ：カルチャー複合施設（旧工場リノベーション）

住所：ソウル城東区聖水二路14キル14（2号線聖水駅3番出口徒歩10分）

入場料：無料（各店舗利用基準）

営業時間：店舗ごとに異なる、おおむね11:00~22:00（要確認）

英語対応：★★★（主要店舗に英文メニュー・案内あり、スタッフの基本的な英語対応可）

聖水連邦は聖水洞の工場地帯を改装した複合セレクトショップ・カフェ・ギャラリーの集合体です。建物自体が室内でつながる構造のため、雨が降っても階を移動できます。外国人に響くポイントは2つあります。一つはフォトスポットとしての空間感 — 高い天井、古びたレンガ、リノベーションの質感がInstagram映えします。もう一つは韓国のローカルブランドを一カ所でまとめて見られる点です。

雨天Tips：カフェでドリンクを1杯注文して2~3時間滞在可能。雨音が建物の中に響く雰囲気も特別だという外国人レビューが多数あります。

予算目安：コーヒー1杯₩6,000~₩8,000。ショッピングを追加する場合は上限なし。

2. アンダースタンドアベニュー

タイプ：コンテナ型複合モール（聖水を代表する屋外型 — 雨天時は室内区域中心に利用）

住所：ソウル城東区往十里路83-21（2号線トゥッコム駅1番出口徒歩5分）

入場料：無料

営業時間：11:00~22:00（要確認）

英語対応：★★★（ポップアップ店舗・セレクトショップ中心、英文案内は部分的）

アンダースタンドアベニューは屋外コンテナの配置が特徴ですが、室内カフェ・セレクトショップ・ポップアップ区域も別途あります。雨が強い日は屋外区域よりも室内中心の動線で回るのが正解です。聖水エリア訪問の起点として適しており、聖水連邦と徒歩圏内にあるため一緒に組み合わせるコースが一般的です。

雨天Tips：雨のときは室内カフェ区域とセレクトショップを中心に周遊。屋外コンテナ区域は短時間の移動のみに。

予算目安：無料入場。カフェ・食事₩8,000~₩15,000。

3. 大林倉庫

タイプ：倉庫型大型カフェ（聖水インスタ人気No.1）

住所：ソウル城東区聖水二路78（2号線聖水駅徒歩5分、またはトゥッコム駅から徒歩15分）

入場料：なし — ドリンク注文必須（最低1杯）

営業時間：10:00~22:00（要確認）

英語対応：★★★（メニュー表に英文併記、注文は基本英語対応可）

1970年代の精米所を改装した空間です。12mの天井高、古びた倉庫の質感、大型の採光窓が特徴です。雨音と倉庫の雰囲気が組み合わさると、外国人が「韓国で最もユニークなカフェ」と表現する体験になります。梅雨シーズンの聖水コースにおける室内の核心アンカーです。

雨天Tips：雨の日の日中が最も写真の質が良いです（曇った光が空間に合います）。週末は30分~1時間の待ちが発生することもあります — 平日訪問がおすすめです。

予算目安：ドリンク₩7,000~₩10,000。

注意：駐車場が狭い。公共交通機関の利用を推奨。

軸2：弘大・合井（3選）

4. KT&Gサンサンマダン弘大

タイプ：カルチャー複合施設 — ギャラリー・シネマ・公演・デザインショップ

住所：ソウル麻浦区オウルマダン路65（2号線・空港鉄道弘大入口駅9番出口徒歩5分）

入場料：ギャラリー無料~₩5,000（展示ごとに異なる）、シネマ₩10,000~₩12,000、公演別途

営業時間：ギャラリー12:00~20:00 / デザインショップ12:00~21:00（要確認）

英語対応：★★★（ギャラリーの一部に英文説明、シネマは英文字幕上映あり）

弘大エリアの室内拠点の中で最も安定した選択肢です。ギャラリーは現代美術・インディーデザイン中心の展示が入れ替わりで開催されます。雨が降っても一日中過ごせる構造 — ギャラリー → デザインショップ探索 → シネマ鑑賞という順で半日を埋められます。外国人にとっては韓国のインディーアート・デザインを実際に見られる数少ない空間の一つです。

雨天Tips：入場前に公式サイトまたはInstagramで現在の展示を確認することをおすすめします。展示の空白期間中はデザインショップのみ営業。

予算目安：ギャラリー無料~₩5,000 + シネマ₩12,000 + カフェ₩6,000。

5. 弘大 脱出ゲーム・ボードゲームカフェ・コインカラオケ

タイプ：室内エンタメ（脱出ゲーム・ボードゲーム・カラオケ）

位置：弘大入口駅徒歩5~10分圏内。弘大正門商圏に密集。

入場料：

  • 脱出ゲーム：₩15,000~₩25,000/人（テーマ・人数により異なる）
  • ボードゲームカフェ：₩5,000~₩10,000/人（時間制または入場料）
  • コインカラオケ：₩500~₩1,000/曲（または時間制₩3,000~₩5,000/10分）

英語対応：★★★★（主要な脱出ゲーム業者は英文案内あり — 例：Iam脱出ゲーム、Codeなど主要フランチャイズは英語・中国語・日本語のヒントを提供）

雨の日の弘大における室内エンタメの集合体です。脱出ゲームは事前のオンライン予約が必須 — 梅雨シーズンの週末は現地予約不可の業者が多いです。コインカラオケは予約なしで即利用可能で、外国人観光客も気軽に入れます。ボードゲームカフェは韓国語のゲームもありますが、主要業者は英文説明書付きゲームの専用区域を運営しています。

雨天Tips：Klook・マイリアルトリップで脱出ゲームを事前予約すると割引が適用される場合があります。雨の日の午後2~5時が最も混雑します。

予算目安：脱出ゲーム₩20,000 + ボードゲーム₩7,000 + コインカラオケ₩5,000 ＝ 約₩30,000~₩35,000/人。

6. 合井 メセナポリスモール・AK&弘大

タイプ：地下鉄直結の複合ショッピングモール

住所：ソウル麻浦区楊花路45（2号線・6号線合井駅直結）

入場料：無料（ショッピングモール）

営業時間：10:30~22:00（フードコートは~23:00、要確認）

英語対応：★★★（主要グローバルブランド店舗は英語対応可、案内デスクは基本英語対応）

合井駅から地下直結で、雨に一滴も濡れずに入場できます。ショッピング・食事・カフェを一カ所で済ませられる構造です。弘大エリアに宿泊する外国人が雨天時に最も近い室内fallbackとして活用しやすいスポットです。AK&弘大とメセナポリスは連絡通路でつながっており、実質的に一つの大型複合モール動線になっています。

雨天Tips：食事タイム（12~14時、18~20時）はフードコートの待ちが長くなることがあります — 前後1時間ずらすか予約を。

予算目安：食事₩12,000~₩20,000。ショッピングを追加する場合は上限なし。

7. COEXモール + ピョルマダン図書館

タイプ：超大型地下複合モール + 公共図書館（外国人ソウル室内No.1）

住所：ソウル江南区永東大路513 COEX（2号線三成駅5・6番出口直結 / 9号線奉恩寺駅7番出口徒歩5分）

入場料：ピョルマダン図書館完全無料 / COEXモール無料

営業時間：COEXモール10:30~22:00 / ピョルマダン図書館10:00~22:00

英語対応：★★★★★（案内標識4カ国語、案内デスク英語対応可、グローバルブランド店舗は当然英語対応）

ピョルマダン図書館はソウル室内における外国人フォトスポット圧倒的No.1です。高さ13mの書架、大型メディアアート設置物、無料開放という3つの条件が重なった空間です。図書館という名前ですが、実際は誰でも座って休んだり写真を撮ったりできる共用空間です。貸出は会員のみ可能ですが、閲覧は外国人も自由にできます。

COEXモール自体は地下4区域にまたがる迷路型の構造です。映画館（メガボックスCOEX）、水族館（次の#8）、SMTOWNアーティウム（次の#9）、フードコート、カフェ、諸施設がすべて室内でつながっています。三成駅から地下直結のため、一度も地上に出ずに入場できます。

雨天Tips：雨の日は三成駅5番・6番出口から地下でそのままCOEXへ。ピョルマダン図書館は午前10~11時が人が少なく写真撮影に向いています。

予算目安：無料入場。食事₩12,000~₩20,000。カフェ₩6,000~₩9,000。

10. 地下接続動線 — 雨に濡れずに移動する方法

ソウル江南エリアの地下接続動線は、外国人にはあまり知られていませんが、知っておくと決定的に便利です。主要ルートは以下の通りです。

COEX直結ルート

  • 2号線三成駅5・6番出口 → COEXモール → ピョルマダン図書館 → アクアリウム → SMTOWNアーティウム方向 全区間地下接続
  • 地上に一度も出ずに三成駅からCOEXの全施設を利用可能

江南地下商店街ルート

  • 新沙駅~江南駅~駅三駅~宣陵駅区間に地下接続通路が存在（区間ごとに接続状況が異なる — 訪問前に地下鉄アプリまたはNAVER地図で「地下経路」を確認することをおすすめします）
  • 江南駅地下商店街はファッション・雑貨・飲食店舗が密集

合井駅直結ルート

  • 合井駅 → メセナポリスモール地下直結（2・6号線乗り換え可能）

実用Tips

  • NAVER地図アプリで「地下鉄経路」を選択すると、乗り換え通路・地下接続の有無を確認できます
  • カカオマップも同様の機能を提供。両アプリとも英語インターフェース対応
  • NAVER Map英語版：maps.naver.com → 言語設定English

11. 梅雨シーズン室内1dayパス & 事前予約戦略

雨の日の室内プランは、事前予約が現地購入よりほぼ常に有利です。

Klook基準（要確認）

  • COEXアクアリウム：現地価格₩29,000 → Klook約₩24,000~₩26,000（時期により異なる）
  • 弘大エリアの脱出ゲーム：Klook・マイリアルトリップのパッケージ₩15,000~₩25,000
  • チムジルバン1日利用（#07連携）：₩10,000~₩15,000（チムジルバン自体の価格）
  • コインカラオケは事前予約なしで即利用可能

KKday基準（要確認）

  • ソウル室内ツアーのパッケージ多数販売。英語・日本語・中国語対応。

実用Tips

  • 雨予報がある日の朝 → Klookアプリで当日予約可能な室内アクティビティを検索
  • 梅雨シーズンの週末の脱出ゲームは2~3日前の予約が安全です。当日現地では待ち1~2時間または満席の可能性。

12. シーズン室内fallback — 梅雨シーズン以外の雨天対応

梅雨シーズン（6月中旬~7月）以外にも、ソウルは年間を通じて突然の雨が多いです。

  • 傘の保管 — 大型ショッピングモール入口に傘用保管バッグまたは傘立てを設置。COEXは入口で傘ケースを無料提供。

FAQ

Q1. 雨の日のソウルで一カ所だけ行くなら？

COEXモール + ピョルマダン図書館。無料、三成駅地下直結、4カ国語案内完備、アクアリウム・SMTOWNの追加選択も可能。半日~終日を室内で完結できます。

Q2. K-popファンだが雨の日はどこへ行けばいい？

SMTOWN COEXアーティウム（#9）。グッズストア無料入場、公式MD購入、フォトブース。COEX地下直結なので雨に濡れません。

Q3. 子供連れの家族旅行だが雨が降ったら？

COEXアクアリウム（#8）を強くおすすめします。650種以上の海洋生物、海底トンネルを含む全区間室内。その後ピョルマダン図書館で休憩。COEXモール内のフードコートで食事まで動線内で完結します。

Q4. 予算1日₩30,000以下で室内を楽しめる？

可能です。ピョルマダン図書館（無料）+ 聖水倉庫型カフェ1杯（₩7,000~₩8,000）+ 弘大コインカラオケ（₩5,000~₩8,000）+ コンビニ食事（₩5,000~₩7,000）＝₩25,000以内。

Q5. 脱出ゲームの予約はどこで？英語でできる？

KlookまたはマイリアルトリップのアプリでEscape room Seoulと検索。英語ヒント提供の有無をフィルターで確認可能。主要な弘大脱出ゲーム業者（Code・Iamなどのフランチャイズ）は英文案内を基本提供。雨予報のある週末は2~3日前の予約をおすすめします。
