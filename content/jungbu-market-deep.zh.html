为什么现在是中部市场 — 1957韩国#1干货批发

中部市场(Jungbu Sijang / 중부시장)是1957年开设·韩国最大干货批发市场，位于首尔中区乙支路(Euljiro / 을지로)4街。与广藏市场(Gwangjang Sijang / 광장시장)(#582 vlog·传统小吃)、南大门市场(Namdaemun Sijang / 남대문시장)(#581正统老字号)相比，差异点只有一个：以干货、海苔、裙带菜、海带、凤尾鱼、干虾批发为核心。零售消费者也能以批发价购买，这是对外国游客来说实实在在的优势。

市场面积约1万3千坪。1层本栋以干货批发商街最为集中，附近巷弄里也分布着60年以上历史的餐厅老字号。中部市场本身就是干货店铺+食材批发+乙支路老字号文化能在一个街区体验完的结构。

本矩阵为干货店铺3选+正统老字号3选+乙支路cross 3选+外国发烧友3选=12选4轴。

12选4轴心化

轴1：干货店铺(3选)

1. 中部市场干货批发本栋

位置：首尔中区乙支路118(本栋1层主要密集区域)

营业时间：平日·周六06:00–18:00 / 周日大多休息(各店铺不同)

价格(2026年)：汤用凤尾鱼1kg ₩12,000–18,000 / 干虾(中虾)500g ₩8,000–14,000 / 海带500g ₩6,000–10,000(比零售价低40–60%)

外国游客适配度：★★★★★——中·日游客为购买"韩国干货伴手礼"而专程前往的第一批发目的地。东南亚游客也在增加。

路线：2·5号线乙支路4街站(Euljiro 4-ga-yeok / 을지로4가역)3号出口步行3分钟

英语可通：有限。谷歌翻译App(相机翻译)实用。打印品项名韩文清单，用手指指认可以购买。

时段建议：07:00–09:00批发商人高峰→10:00–13:00零售外国游客推荐时段

干货携带出境：部分店铺可真空包装——购买时可说"请帮我抽真空"(진공포장 해주세요)，或用翻译App出示。航空携带以干燥未加工干货为基准通常可行——但各国检疫规定需事先确认。

2. 中部市场海苔·海藻类店铺群

位置：本栋及邻近别馆(海苔专门店10余家密集)

营业时间：平日·周六07:00–17:00

价格(2026年)：烤海苔批发100张 ₩3,500–5,000 / 调味海苔礼盒(30袋) ₩15,000–22,000 / 裙带菜海苔200g ₩4,000–7,000

外国游客适配度：★★★★★——韩国海苔是中·日·东南亚·西方游客共同青睐的第一韩国食品伴手礼。中部市场是首尔批发最低价基准点。

时段建议：以批发包装(100张单位)购买可协商额外折扣，也允许小份购买。

干货携带出境：调味烤海苔一般可航空携带——但需确认是否为不含液体成分的干燥状态。

3. 中部市场坚果·谷物店铺群

位置：本栋外围及1层右侧区域

营业时间：平日·周六07:00–18:00

价格(2026年)：国产松子100g ₩5,000–8,000 / 核桃(去壳)500g ₩7,000–12,000 / 黑芝麻200g ₩3,000–5,000

外国游客适配度：★★★★——购买干货后顺路逛。也有为了买韩果原料、凉拌菜用谷物而来的中·日发烧友。

轴2：正统老字号(3选)

4. 中部市场正统老字号cluster

位置：中部市场本栋附近巷弄(乙支路4街站南侧小路)

营业时间：06:00–14:00(以午餐为主，多数下午提早打烊)

价格(2026年)：刀削面·血肠汤 ₩7,000–9,000 / 血肠1份 ₩5,000–7,000

外国游客适配度：★★★★——批发商、面向商人的餐厅起家。与本地人同坐用餐的体验。拍照前务必先示意店家。

英语可通：有限。菜单为韩文+翻译App。用手指指本地食客的菜也能沟通。

注意：部分老字号不接受预约·没座位就排队。09:00前开店初期以批发商人优先。

5. 中部市场附近餐厅巷

位置：中部市场东侧巷弄——清溪4街(Cheonggye 4-ga / 청계4가)方向

营业时间：07:00–15:00(仅限午餐)

价格(2026年)：家常便饭(汤+小菜5种) ₩7,000–10,000

外国游客适配度：★★★——菜单选择较少，需要韩语点餐。适合有挑战精神的外国游客。

6. 中部韩食正统(小菜·腌海鲜·大酱批发)

位置：本栋内部及邻近小菜巷

营业时间：07:00–17:00

价格(2026年)：腌海鲜(虾酱500g) ₩6,000–10,000 / 批发大酱(1kg) ₩5,000–8,000

外国游客适配度：★★★——腌海鲜、大酱因是液体成分，航空托运时必须放入托运行李。旅行最后一天不建议购买。

干货携带注意：虾酱、鱼露等液体发酵产品禁止随身携带上机(超过100ml)——需办理托运包装。

外国游客适配度：★★★★——白天买干货→晚上乙支路老字号路边摊，是完整的一日路线。详情→#11乙支路指南

外国游客适配度：★★★★★——中部市场白天路线+乙支路3街夜间路边摊的组合，是外国游客社交媒体上验证过的"首尔真正本地一日"路线。详情→#086乙支路钟路3街夜生活

外国游客适配度：★★★★★——因Instagram传播，日·中年轻游客偏好度急升。老旧印刷厂巷弄与newtro咖啡厅的反差是关键。

轴4：外国发烧友(3选)

10. 干货发烧友(中·日)——海产culture购物

模式：中国·日本游客以"购买伴手礼干货套装"为目的搜索并专程到访中部市场。海苔+凤尾鱼+海带组成套装，价格通常在₩30,000–50,000。

诀窍：对店家说"Can I make a set?"，或用翻译App出示"请帮忙打包成套"(세트로 묶어주세요)，即可获得打包帮助。

11. K-food性价比发烧友

模式：批发价比一般超市便宜30–50%。主要客户是想长期居住自炊的外国游客(语言研修生·长期游客)。

推荐购买清单：汤用凤尾鱼(替代高汤包)/烤海苔/海带/芝麻/松子。

12. 市场+乙支路夜间全套

路线：10:00中部市场干货→12:00老字号午餐→14:00乙支路印刷巷散步→18:00乙支路3街路边摊夜间

所需时间：约8–9小时(全天)

预算(2026年)：干货购买₩30,000–60,000+午餐₩8,000–10,000+晚上路边摊₩20,000–35,000=共₩58,000–105,000/人

外国游客常见3大失误

失误1：周日到访

中部市场大部分干货批发商周日休息。主要老字号也多数周日不开门。到访前务必确认星期几。平日上午或周六上午最合适。

失误2：只带卡不带现金

干货批发特性上偏好现金交易的店铺很多。小额交易(₩10,000以下)有些只收现金。建议在附近ATM(乙支路4街站内4台)提前取₩50,000–100,000。

失误3：试图随身携带腌海鲜·鱼露登机

虾酱、鱼露、大酱不可随身携带登机(超过100ml的液体)。如果购买当天就是回国日，建议使用托运打包服务(市场附近的快递打包店)，或者把购买计划留到下次到访。

实用信息 — 交通·支付·语言

交通

  • 地铁：2号线·5号线乙支路4街站3号出口→步行3分钟(中部市场本栋)
  • 公交：162·262·301路等清溪4街站下车→步行2分钟
  • 停车：附近路边停车受限。可利用乙支路公营停车场(清溪4街方向，收费)，但建议大众交通

支付

  • 偏好现金：批发店铺·老字号餐厅优先现金。小型店铺拒收刷卡的情况存在
  • 可刷卡：规模较大的店铺(经营10种以上海苔的)可刷卡——现场需确认
  • ATM：乙支路4街站内有KB·友利银行ATM，可用海外卡取现(手续费₩2,000–3,000/次)

语言

  • 英语：市场内大多有限。谷歌翻译相机功能实用度★★★★★
  • 中文·日语：部分大型海苔店铺有中文标示。完全沟通较难期待
  • 旅游通译电话：☎ 1330(韩国观光公社24小时，英·中·日·法语)——可在现场与店主连线通译

FAQ扩展(5问)

Q1. 中部市场第一次到访的动线是？

乙支路4街站3号出口→步行3分钟→本栋1层干货区域。入口基准左侧(西侧)=干货批发密集，右侧(东侧)=海苔·海藻·坚果。逛完一圈约需40–60分钟。

Q2. 和广藏市场·南大门市场有什么不同？

  • 广藏市场(#582)：以小吃(生牛肉·煎饼)·服装为中心，外国游客密集度最高
  • 南大门市场(#581)：生活用品·服装·综合零售，外国游客友好英文菜单多
  • 中部市场：干货·干海产批发专门。小吃比重小，专注于食材购买目的。

Q3. 干货可以航空携带吗？

干燥未加工干货(凤尾鱼·海带·裙带菜·烤海苔)一般可航空行李携带。但各国检疫规定不同，建议提前确认目的地国家检疫机构规定。日本对干货携带在数量·包装状态上有时需要申报。液体·发酵产品(虾酱·鱼露)不可随身携带，需办理托运包装。

Q4. 零售消费者也能以批发价购买吗？

原则上批发店铺也大多允许小量零售购买。但部分店铺会要求最低购买单位(如凤尾鱼500g以上、海苔50张以上)。想拆分购买，建议提前用翻译App确认。

Q5. 附近能便宜吃饭吗？

本栋附近巷弄的刀削面·血肠汤老字号可以₩7,000–9,000用餐。乙支路4街站出口方向的便利店(CU·GS25)简餐也可搭配。午餐高峰(11:30–12:30)抢座激烈——建议11:00前到访。

季节秘诀

  • 春(3–5月)：凤尾鱼新货入市时期，价格有利
  • 夏(6–8月)：注意炎热·潮湿，建议携带干货保存袋。市场内部分区域无空调
  • 秋(9–11月)：干货季节高峰，海带·裙带菜·海苔品质最佳，最佳到访时期
  • 冬(12–2月)：黄花鱼、明太鱼、干明太鱼季节品项入市，批发价协商有利
  • 公休日：春节·中秋前一天+当天休息。连休前一天常因清库存而有降价协商空间
