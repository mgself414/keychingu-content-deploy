釜山デザートロード — 小豆の街からジェラートまで

サブタイトル: コーヒーロード(#1321)の次のコースはデザートだ。釜山はパッピンス(Patbingsu / 팥빙수)・パッチュク(Patjuk / 팥죽)横丁が地域文化大典に登録されるほど小豆の街でありながら、クァンアルリ(Gwangalli / 광안리)のジェラテリアやヨーロッパ風ベーカリーカフェが年々増えている街でもある。ローカル保存シグナルでグルメの次に大きなクラスターがデザートだった——伝統小豆軸、グローバル軸、オーシャンビュー軸の三つに整理した釜山の甘味マップ。

ISSUE · #1324 · 2026-08-23

🎯 釜山デザートの三つの軸

釜山ローカルキュレーションアカウントの保存物を集めてみると、グルメの次に大きな塊がデザートだ(今回の収集で釜山デザートシグナル25件)。軸は三つある:①小豆に代表される伝統軸、②ジェラート・クレープ・ヨーロッパ風ベーカリーのグローバル軸、③海のそばにあるオーシャンビュー軸。ソウルのデザートシーンが「新作スピード」で回るなら、釜山は小豆というルーツ+海という背景があるぶん文法が違う。

① 小豆の街 — 伝統軸

  • 釜山にはパッピンス(Patbingsu / 팥빙수)・パッチュク(Patjuk / 팥죽)横丁が地域文化記録(釜山歴史文化大典)に登録されているほど、小豆文化の根が深い。冬はパッチュク、夏はパッピンスで季節を越すのが釜山式だ。
  • ペクパッチプ (Baekpatjip / 백팥집)(トンネ (Dongnae / 동래)) — 手作り小豆で作るパッピンス・餡パン専門店。甘さ控えめのパッピンスと餡がぎっしり詰まった餡パンの組み合わせがシグネチャーで、早い時間の売り切れが多いため昼の訪問が安全だ。
  • トンネイェンナルパッピンス (Dongnae Yennal Patbingsu / 동래옛날팥빙수)のような老舗型パッピンス店も同じエリアにある——トンネはK-POP巡礼(#1323)のBASECOFFEEと同じ町なので、デザート動線としてまとめやすい。
  • 手土産用K-デザート:餅専門店ヘアンジ (Hyeanji / 혜안지)・焼き菓子専門店イニャンマルリ (Inhyangmalli / 인향만리)のようなローカル工房型店舗がインスタ保存シグナルの上位に入っている——空港免税店の代わりに町の工房で買う手土産が最近の作法だ。

注文のコツ：パッピンスの作法

1. パッピンスは混ぜずに上からすくって食べるのが基本——氷・小豆・トッピングの層が設計だ。

2. 「甘くない」は褒め言葉だ——手作り小豆専門店ほど、砂糖ではなく小豆本来の味で勝負する。

3. 餡パンを添えれば一食になる——釜山の小豆専門店の基本セット感覚だ。

② グローバル軸 — ジェラート・クレープ・ヨーロッパ風

  • La Mia Estate(クァンアルリ(Gwangalli / 광안리)) — ローカルピックで「イタリア政府認証ジェラート」として紹介されるジェラテリア。ピスタチオが代表ピック。クァンアルリのビーチ散策とセットになる立地が強みだ。
  • クレープ専門店(チョンポ (Jeonpo / 전포)→クァンアルリ拡張) — チョンポで始まりクァンアルリに2号店を出すほどクレープシーンが拡大中。トッピングカスタム型が基本の文法だ。
  • モンベルシェルター (Mongbel Shelter / 몽벨쉘터)(ナンポ (Nampo / 남포)・クァンボンノ (Gwangbok-ro / 광복로)) — ヨーロッパ感性の大型ベーカリーカフェ。BIFF広場の近くなので、ナンポ観光動線(#244エリア)と自然につながる。
  • 注意:百貨店・モールのポップアップデザートは期間限定のため今回は扱わない——訪問時のポップアップは現地で出会うボーナスとして。

③ オーシャンビュー軸 — 海と甘味

  • チョンサポ (Cheongsapo / 청사포)(ヘウンデ (Haeundae / 해운대)の東) — オーシャンビューカフェベルトの代表エリア。パノラマの海を見ながらコーヒー+デザートを楽しめる3階建てカフェが密集している(収集シグナルの代表:オブコーヒーサロン(Obeu Coffee Salon / 오브커피살롱))。ヘウンデの繁華街から一駅離れるだけで密度がぐっと下がる。
  • クァンアルリ側はジェラート・クレープを片手にビーチへ出るテイクアウトの作法が通用する——クァンアン大橋 (Gwangan Bridge / 광안대교)の夜景(#243)との組み合わせで。
