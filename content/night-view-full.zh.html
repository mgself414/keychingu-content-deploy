🎯 为什么是韩国夜景完整指南？

首尔夜景 (Seoul Night View / 서울 야경) = 外国游客 Instagram·Vlog 不动的第一选择 + 韩剧 (K-drama)·综艺 (Variety Show / 예능) 节目的常客舞台。本指南整合了 #02 免费夜景景点，提供汉江景观 (Hangang View / 한강뷰)·山景 (Mountain View / 산뷰)·市中心景观 (City View / 도심뷰) 三大轴线的完整套装。

★ 12大景点一览

# 夜景景点 4大轴线 标志性特色
1 N首尔塔 (N Seoul Tower / N서울타워) (南山 / Namsan) ★ 韩国第一地标 地标性高塔 1969年建成·265米 + 南山 (Namsan / 남산)
2 乐天世界塔首尔天空 (Lotte World Tower Seoul Sky / 롯데타워 Seoul Sky) (蚕室 / Jamsil) 地标性高塔 555米·123层 (#82)
3 63大厦 (63 Building / 63 빌딩) (汝矣岛 / Yeouido) 地标性高塔 1985年建成·韩国首座高层建筑 (#169)
4 盘浦汉江公园月光彩虹喷泉 (Banpo Hangang Park Moonlight Rainbow Fountain / 반포 한강공원 달빛무지개분수) 汉江·喷泉 吉尼斯世界纪录最长喷泉 (#173)
5 汝矣岛汉江公园 (Yeouido Hangang Park / 여의도 한강공원) 汉江·喷泉 轮中路 (Yunjoong-ro / 윤중로)·E-Cruise (E-Cruise / 이크루즈) (#169)
6 纛岛汉江公园 (Ttukseom Hangang Park / 뚝섬 한강공원) 汉江·喷泉 自行车·游艇·夜间烧烤 (#178)
7 鹰峰山八角亭 (Eungbongsan Palgakjeong / 응봉산 팔각정) (城东 / Seongdong) 山·观景台 汉江大桥夜景第一地 (#51·#189)
8 骆山公园·汉阳都城 (Naksan Park·Hanyangdoseong / 낙산공원·한양도성) (大学路 / Daehangno) 山·观景台 汉阳都城 (Hanyangdoseong / 한양도성) 夜景 (#170)
9 仁王山 (Inwangsan / 인왕산) (钟路 / Jongno) 山·观景台 338米市中心山脉·汉阳都城 (Hanyangdoseong / 한양도성)
10 DDP 夜间LED (DDP Night LED / DDP 야간 LED) (东大门 / Dongdaemun) 市中心·地标 45,000个LED·扎哈·哈迪德 (Zaha Hadid) 设计 (#172)

+ 额外4大景点: 钟路汉阳都城 (Jongno Hanyangdoseong / 종로 한양도성)·峨嵯山 (Achasan / 아차산) (#178)·江一汉江 (Gangil Hangang / 강일 한강)·鹭梁津汉江大桥 (Noryangjin Hangangdaegyo / 노량진 한강대교) (#181)

⚠ 外国游客常犯的3种错误

1. “夜景 = 只有南山塔 (Namsan Tower / 남산타워)”: 除了南山 (Namsan / 남산) 之外，还有乐天世界塔 (Lotte World Tower / 롯데타워) (#82)·63大厦 (63 Building / 63빌딩) (#169)·鹰峰山 (Eungbongsan / 응봉산) (#51)·骆山 (Naksan / 낙산) (#170)·盘浦喷泉秀 (Banpo Fountain Show / 반포 분수쇼) (#173) 等完整套装。

2. “喷泉秀 = 不知道时间就看不到”: 盘浦月光彩虹喷泉秀 (Banpo Moonlight Rainbow Fountain Show / 반포 달빛무지개분수쇼) 4月至10月夜间 20:00·20:20·20:40·21:00·21:20 (每隔20分钟一场，平日4场·周末5场)。雨天暂停。

3. “DDP东大门设计广场 (DDP Dongdaemun Design Plaza / DDP) 夜间 = 普通建筑”: DDP东大门设计广场 (DDP Dongdaemun Design Plaza / DDP) (东大门设计广场 / DDP) 拥有45,000个LED外墙 + 每小时变化的图案。22:00至24:00达到高潮。是外国游客 Instagram 上的首选。

① 地标性高塔 (3)

1. N首尔塔 (Namsan Seoul Tower) ★ 韩国第一地标

  • 地址: 龙山区南山公园路 (Namsan Gongwon-gil / 남산공원길) 105
  • 外国游客 ★: ◎◎ — 韩国第一夜景地标
  • 标志性特色: 1969年建成·265米 + N首尔塔 (N Seoul Tower / N서울타워) + 环山路 + 爱情锁 (Love Locks / 사랑의 자물쇠)
  • 门票: 观景台 ₩16,000 (~$12 / ~85 RMB / ~1,700 JPY) + 缆车 ₩11,000 (~$8 / ~58 RMB / ~1,200 JPY) (外国游客可购买)
  • 时间: 10:00~23:00

2. 乐天世界塔首尔天空 (Lotte World Tower Seoul Sky / 롯데월드타워 Seoul Sky) (蚕室 / Jamsil)

  • 地址: 松坡区奥林匹克路 (Olympic-ro / 올림픽로) 300 (#82 蚕室 / Jamsil)
  • 外国游客 ★: ◎◎ — 世界第五·韩国第一 555米·123层
  • 标志性特色: 117层天空甲板 (Sky Deck) (玻璃地板) + 日落前后30分钟最佳
  • 门票: ₩31,000 (~$23 / ~165 RMB / ~3,300 JPY)

3. 63大厦 (63 Building / 63 빌딩) (汝矣岛 / Yeouido)

  • 地址: 永登浦区63路 (63-ro / 63로) 50 (#169 汝矣岛 / Yeouido)
  • 外国游客 ★: ◎ — 韩国80年代第一地标
  • 标志性特色: 1985年建成·60层观景台·汉江 (Hangang / 한강) 360度全景·水族馆 (Aqua Planet)

7. 鹰峰山八角亭 (Eungbongsan Palgakjeong / 응봉산 팔각정) ★ 汉江大桥夜景第一地

  • 地址: 城东区鹰峰洞 (Eungbong-dong, Seongdong-gu / 성동구 응봉동) (3号线玉水站 / Oksu Station) (#51·#189)
