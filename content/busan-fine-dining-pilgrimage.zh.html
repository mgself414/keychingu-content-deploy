釜山美食巡礼 — 米其林星星、主厨私房名单，还有邮局职员的推荐

副标题: "当下美食圣地是釜山"(姜雷奥 (Kang Leo / 강레오) 主厨语)。米其林指南进驻釜山已满3年，1星餐厅增至4家。跟着星星走的方法、跟着黑白厨师 (Culinary Class Wars) 主厨私房名单走的方法，还有邮局职员推荐这一釜山式在地信号 — 用三种不同的罗盘巡礼釜山美食的指南。是首尔版主厨巡礼(#1317)的釜山姊妹篇。

ISSUE · #1322 · 2026-08-23

🎯 三个罗盘

釜山的美食信息分成三条线。米其林(官方星级)、主厨私房(厨师们自己掏钱去吃的店)、在地信号(邮米其林 (Usyullaeng / 우슐랭)·蓝丝带调查 (Blue Ribbon Survey / 블루리본서베이) 这类韩式指南)。三者互不重叠 — 所以三者都要了解。米其林指南2024年首次进驻釜山，到2026年版已扩大到精选55家·1星4家。同一时期，出演黑白厨师 (Culinary Class Wars) 的主厨们纷纷把釜山选为"当下最有趣的美食城市"。

① 米其林轴线 — 4颗星，怎么接近

2026年版现状

  • 莫里 (Mori / 모리) — 维持1星。寿司无菜单料理(Omakase)轴线。
  • 帕莱特 (Palette / 팔레트) — 维持1星。当代精致餐饮。
  • 菲奥托 (Fiotto / 피오또) — 同时持有1星 + 绿星(可持续美食)。意大利菜。
  • 勒多海 (Le DORER / 르도헤) — 2026年新晋1星。金昌旭 (Kim Chang-wook / 김창욱) 主厨的当代餐厅 — 是釜山星级"增加"的第一个案例。

现实的应对方法

1. 1星店预约优先 — 韩国精致餐饮的预约语法(CatchTable Global (캐치테이블 글로벌)·爽约政策·酒水规定)与首尔版#1317相同。比起晚餐，午餐套餐无论价格还是预约难度都更低。

2. 必比登推介(Bib Gourmand)·精选51家才是真正的入门途径 — 别只扎堆在4家星级店。在米其林App里打开釜山精选，就能看到价格合理的名单。

3. 米其林轴线晚上只安排一顿 — 白天用猪肉汤饭·小麦冷面(#1320)和咖啡之路(#1321)填满，才是釜山的平衡之道。

② 主厨私房轴线 — 厨师自己掏钱去的店

因〈黑白厨师 (Culinary Class Wars)〉而露脸走红的主厨们，接连公开自己的"釜山私房名单"。代表案例是尹南老 (Yoon Nam-no / 윤남노) 主厨(诺特小酒馆 (Bistro Notre / 비스트로 노뜨르))的釜山一日游路线(YouTube频道'尹南老铺 (Yoon Nam-no-po / 윤남노포)'，2026年5月公开)：

顺序 行程
午餐 在金井区 (Geumjeong-gu / 금정구) 老铺吃厚切冷冻五花肉(冷五花) + 泡菜·葱泡菜
下午 用一碗汤饭收尾 — 流派选择参考#1320
收尾 南川洞 (Namcheon-dong / 남천동) 甜品店

重点不在名单本身，而在模式：主厨私房走的不是精致餐饮，而是老铺+甜品的组合。方向正好与星级指南相反，若在一天内和米其林轴线混搭，就能把釜山美食的两极都走一遍。

③ 在地信号轴线 — 邮米其林与蓝丝带的读法

  • 邮米其林 (Usyullaeng / 우슐랭) — 在本地流传的说法，"比米其林还火"：由邮局职员推荐的社区一餐名单。逻辑是，靠投递·外勤跑遍社区的人最懂当地。在Instagram·YouTube用搜索关键词 (Usyullaeng Busan / 우슐랭 부산) 检索就能看到最新一期 — 名单一直在变，与其记死店名，不如记搜索关键词。
  • 蓝丝带调查 (Blue Ribbon Survey / 블루리본서베이) — 韩国最早的餐厅指南书。米其林覆盖不到的本地老铺·专门店轴线，由它来补上。
  • 读法：米其林 = 外国人标准的安全牌，邮米其林·蓝丝带 = 韩国人日常标准。后两者重叠出现的店，才是真正靠谱的。
