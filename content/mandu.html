외국인이 자주 하는 실수 3가지

1. 한국 만두 = 중국 만두 라는 인식

한국 만두는 개성·평양 이북 출신 + 한국식 변형으로 중국 만두(包子·饺子)와 다른 정체성. 평양만두는 얇은 메밀피 + 두부·돼지고기·김치 소 가 특징. 만두피·소·국물이 모두 한국식.

2. 만두국·만둣국 vs 만두만 시키기

한국 만두는 만두 단품 (찐·군) + 만두국 (만두 + 떡 + 국물) 두 카테고리. 외국인은 단품만 시키는 경우 많은데, 한국인 미식가는 만두 + 만둣국 세트가 정석. 특히 겨울 시즌 만두국 안 먹으면 한식 만두 경험 50% 놓침.

3. 평양만두 vs 김치만두 구별 못 함

평양만두는 슴슴한 두부·돼지·김치 소 + 메밀피 정통. 김치만두는 김치 위주의 매콤한 소. 첫 방문이라면 평양만두 → 김치만두 → 갈비만두 순서가 안전 (입맛 적응).

2. 명소 8곳 (4축 균형)

2-1. 평양식 본가 2곳 — 한식 만두의 정수

① 자하손만두 (Jahasonmandu) — 부암동

1980년대~ 부암동 평양손만두 노포 1순위. 경복궁역에서 버스 7분 또는 도보 25분 (부암동 동선). 1인 ₩15,000~₩18,000. 얇은 메밀피 + 두부·돼지·김치 소 + 손빚음 — 한국 평양손만두의 정통. 만두국 + 떡갈비 정식이 시그니처. 1인 OK, 외국인 미식가 1순위. 영문 메뉴, 카드 OK.

② 개성만두 궁 (Gaeseong Mandu Gung) — 명동

1970년대~ 개성식 만두 노포의 대표. 명동역 6번 출구 도보 5분. 1인 ₩13,000~₩16,000. 개성식은 평양식보다 약간 큰 만두 + 다양한 소. 만두 + 만둣국 + 빈대떡 트리오. 외국인 응대 익숙, 영문 메뉴.

2-2. 종로 노포 2곳 — 가성비 + 정통

③ 북촌손만두 (Bukchon Sonmandu) — 종로 북촌

1990년대~ 북촌 한옥마을 동선 만두 노포. 안국역 도보 7분. 1인 ₩10,000~₩14,000. 수공예 손만두 + 북촌 한옥 산책 동선. 외국인 관광객 동선 1순위, 영문·중문 메뉴. 1인 OK, 평일 점심 30분 줄.

④ 취천루 (Chwicheonru) — 종로

1960년대~ 종로 만두 노포 가성비 라인. 종각역 도보 5분. 1인 ₩9,000~₩12,000. 왕만두 + 물만두 + 만둣국 풀세트 — 한국인 직장인 점심 단골. 영문 메뉴 일부, 사진 메뉴판.

2-3. MZ 트렌디 2곳 — SNS 인기

⑤ 또복이 (Ddobogi) — 강남

MZ 신생 만두 트렌디. 강남역 11번 출구 도보 4분. 1인 ₩10,000~₩14,000. 갈비만두 + 김치만두 + 트러플 만두 풀세트 — SNS·인스타 노출 빈도 ↑. 인스타용 사진 양산 + MZ 데이트 코스. 예약 권장 (주말), 1인 OK.

⑥ 조선만두 (Joseon Mandu) — 홍대

홍대 MZ 만두 트렌디 매장. 홍대입구역 9번 출구 도보 7분. 1인 ₩11,000~₩15,000. 김치만두 + 만두국 + 막걸리 정식. K-아이돌·K-드라마 노출 빈도 ↑, 외국인 MZ 단골. 영문·중문·일문 메뉴.

2-4. 체인·만두국 2곳 — 가성비 + 외국인 친화

⑦ 안동찜닭본가 만두 메뉴 (Andong Jjimdak Bonga) — 전국 체인

찜닭 본가의 만두 메뉴 (만두 단독 매장 아님, 보너스). 전국 30+ 지점. 1인 ₩9,000~₩13,000. 김치만두 + 만두국 사이드 메뉴. 안동찜닭 + 만두 결합 정식이 가성비 우수. 외국인 친화도 ↑.

⑧ 원조부산갈매기 만두국 (Wonjo Busan Galmaegi) — 강남

부산식 만두국 + 부산 갈매기살 결합 매장. 강남역 도보 5분. 1인 ₩12,000~₩15,000. 부산식 만두국 (멸치·다시마 국물) + 갈매기살 사이드 — 만두국 + 한국식 BBQ 결합. 영문 메뉴.

4. FAQ 8문

Q1. 한국 만두 vs 중국 만두 차이는?

A. 한국 평양만두 = 얇은 메밀피 + 두부·돼지·김치 소. 중국 饺子 = 밀가루피 + 다진 고기 위주. 한국 만두는 김치·두부 베이스가 정체성.

Q2. 평양만두 정통 매장 어디?

A. 자하손만두 (부암동) + 개성만두 궁 (명동) 양대 산맥. 평양식 정통 슴슴함을 원하면 자하손만두, 좀 더 다양한 소를 원하면 개성만두 궁.

Q3. 만두국과 만둣국 차이?

A. 같은 음식 (만둣국 = 만두 + 국의 사이시옷 표기). 만두 + 떡 + 소고기 국물 + 김 + 계란의 정식.

Q4. 1인 방문 가능?

A. 8개 매장 모두 1인 OK. 한국 만두는 1인 정식 친화적 — 만두국 + 단품 만두 1인분 메뉴 다수.

Q5. 영문 메뉴 + 영어 응대 가능?

A. 자하손만두·북촌손만두·또복이·조선만두가 가장 익숙. 종로 노포(취천루)는 사진 메뉴판 + 손짓.

Q6. 카드 결제 가능?

A. 8개 매장 모두 카드·간편결제 OK. 노포(자하손·취천루)도 카드기 보유.

Q7. 만두 + 음료 조합?

A. 평양만두 + 막걸리 (정통). 김치만두 + 소주 (MZ 매콤). 만두국 + 따뜻한 차 (겨울 정식).

Q8. 비건·할랄 가능한가요?

A. 한국 만두는 거의 돼지·소고기 베이스라 비건 어려움. 김치만두 일부 매장이 채식 옵션 (두부·야채만), 별도 주문 가능. 할랄 한국 만두집 거의 없음.

5. 키친구 추천 1일 코스 3개

5-1. 외국인 첫 방문 명동·북촌 코스 (인지도 + 노포)

점심 개성만두 궁 명동 (₩15,000) → 명동·종로 산책 → 저녁 북촌손만두 + 북촌 한옥마을 (₩12,000). 평양·개성식 + 북촌 동선. 1인 ₩30,000.

5-2. MZ·SNS 코스 (강남·홍대 트렌디)

점심 또복이 강남 (₩13,000) → 합정 카페 → 저녁 조선만두 홍대 (₩14,000). 만두 트렌디 + 인스타 사진. 1인 ₩30,000.

5-3. 한식 미식가 일주 (평양식 + 시리즈 연결)

(아침) 자하손만두 부암동 (₩18,000) → (점심) 봉피양 평양냉면 + 만두 (₩30,000) → (저녁) 우래옥 우대갈비 + 만두 (₩50,000). #129 냉면·#130 갈비 연결되는 평양식 일주. 1인 ₩100,000.
