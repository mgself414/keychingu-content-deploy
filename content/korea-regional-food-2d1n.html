⚠ 외국인 자주 실수 3가지

1. "한국 = 서울만": 한국 지방 미식 = 외국인 매니아 매트릭스 #1. 전주·부산·강릉 = KTX 1~2시간 30분 = 외국인 1박2일 매트릭스. 서울 1주일 + 지방 1박2일 풀세트.

2. "KTX = 너무 비싸": KTX 서울→전주 (35,000원) / 서울→부산 (60,000원) / 서울→강릉 (28,000원). 외국인 매니아 = KORAIL Pass 3·5·7·10일 외국인 전용 할인 매트릭스 #1. 영어 인터페이스 + 외국인 결제 카드 OK.

3. "지방 미식 = 영어 안 통하나": 전주 한옥마을·부산 해운대·강릉 안목해변 = 외국인 매니아 매트릭스 #1 + 영어 메뉴 多. 다이닝 = 사진 多 + 손가락 주문 OK. 외국인 매니아 fit.

⚙ FAQ 4개

1. 외국인 1박2일 best 시즌: 봄꽃 (4월 전주·강릉) / 여름 해변 (6~8월 부산·강릉) / 가을 단풍 (10월 전주·강릉) / 겨울 (12~2월 부산 매니아 + 해운대 일출). 외국인 매니아 = 봄·가을 best.

2. KTX 예약 방법: (a) KORAIL Pass (외국인 전용) = 3·5·7·10일 패키지 매트릭스 #1 (b) KORAIL 영어 사이트 / 코레일톡 앱 = 외국인 결제 카드 OK (c) klook·trazy = 외국인 매니아 + 영어 인터페이스. 외국인 매니아 = KORAIL Pass 권장.

3. 외국인 1박2일 동선 etiquette: (a) KTX 예약 = 좌석 지정 + 영어 OK (b) 한옥스테이·부티크 호텔 = 영어 직원 매트릭스 (c) 다이닝 = 영어 메뉴 + 사진 매트릭스 (d) 결제 = 카드·현금 OK (e) 한복 체험 = 일부 한옥스테이·전주 한옥마을 제공.

4. 외국인 1박2일 패키지 vs 자유 여행: (a) 패키지 (klook·trazy·관광공사) = 외국인 매니아 + 영어 가이드 + KTX 포함 매트릭스 #1 (b) 자유 여행 = 외국인 매니아 + booking·airbnb + 영어 menu 매트릭스. 외국인 매니아 = 첫 방문 패키지 + 두번째 자유 여행 권장.
