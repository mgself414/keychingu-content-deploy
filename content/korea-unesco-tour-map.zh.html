副标题: 韩国世界遗产17项(文化15·自然2),最新列入的是2025年的盘龟川 (Bangucheon / 반구천) 岩刻画和2026年扩展的滩涂 (Getbol / 갯벌)(UNESCO) · 宗庙 (Jongmyo / 종묘) 周二、昌德宫 (Changdeokgung / 창덕궁) 周一闭馆(宫陵遗迹本部 (Gungneung Yujeok Bonbu / 궁능유적본부)) · 昌德宫后苑须在6天前10点起线上先到先得预订(宫殿参观票价页面) · 城山日出峰 (Seongsan Ilchulbong / 성산일출봉) 每月第一个周一休息(VisitKorea) — 截至2026-10-21

ISSUE 03 · #461 · 2026-05-26

🎯 本指南的使用方法

宗庙正殿 (Jeongjeon / 정전) 前,宽阔的薄石庭院尽头,屋顶排成长长的一线——供奉神主的室有19间(宫陵遗迹本部)。本指南不逐一深入讲解韩国世界遗产。只用官方数值汇总住在哪里、哪一天去会遇到闭门、需要提前预订什么。每处遗产自己的故事,交给各地区指南的链接。本篇写给在首尔 (Seoul / 서울) 住几天、想每天安排一处世界遗产的旅行者。

旧版指南把世界遗产写成“14项”。UNESCO官方名录中的韩国世界遗产是17项(文化15·自然2)。2023年增加了伽倻古坟群 (Gaya Gobungun / 가야고분군),2025年增加了盘龟川岩刻画,滩涂则在2026年扩大了范围(UNESCO)。“世界文化14+自然2+非遗22+档案18=56项”“面积密度世界第一”之类的合计和排名没有出处,已删除。

🏙 首尔市内——宗庙·昌德宫·朝鲜王陵

  • 宗庙 — 首尔钟路区 (Jongno-gu / 종로구) 钟路 (Jongno / 종로) 157号。周二闭馆(遇公休日则开放,之后的第一个工作日闭馆)。11~1月09:00~17:30,2~5月、9~10月09:00~18:00,6~8月09:00~18:30,入场截止于闭馆前1小时。外国人19~64岁1,000韩元(宫陵遗迹本部)。周一、周四、周五是跟随讲解员在规定时间入场的限时参观,英语场次为10:00、12:00、14:00、16:00。周六、周日、公休日、文化日 (Munhwa-ga Itneun Nal / 문화가 있는 날) 为自由参观(宫陵遗迹本部)。从钟路3街站 (Jongno 3-ga / 종로3가) 11号、8号出口步行5分钟
  • 昌德宫 — 首尔钟路区栗谷路 (Yulgok-ro / 율곡로) 99号。周一闭馆。时间与宗庙的季节划分相同。殿阁参观外国人19~64岁3,000韩元。后苑另收5,000韩元,而且必须同时购买殿阁参观票,参观日6天前上午10点起到1天前为止线上先到先得,或当天09:00起现场先到先得。4~5月、10~11月两种方式都很快售罄(宫陵遗迹本部)。从安国站 (Anguk / 안국) 3号出口步行5分钟
  • 朝鲜王陵 — 分布在18处的40座(UNESCO)。首尔市内最近的是宣陵与靖陵(江南区 (Gangnam-gu / 강남구) 宣陵路100街 (Seolleung-ro 100-gil / 선릉로100길) 1号):06:00~21:00,入场截止20:00,周一闭馆(VisitKorea)
  • 串联方法: 周六、周日、公休日、文化日,宗庙栗谷路一侧的北神门 (Bukshinmun / 북신문) 会开放(宫陵遗迹本部)。宫殿综合参观券6,000韩元可用于四大宫和宗庙,6个月有效,不含后苑(宫陵遗迹本部)。一天逛遍宫殿的顺序见#1255 首尔五大宫完全攻略,宗庙祭礼见宗庙大祭观览指南——5月春享·11月秋享一年两次,2026秋享大祭11月7日免费入场,平时宗庙英语讲解时间一并整理

🧰 世界遗产路线实用信息——一个人、预订、支付、交通

  • 闭馆日重叠: 周一昌德宫·朝鲜王陵休息,周二宗庙休息(宫陵遗迹本部)。济州是城山日出峰第一个周一、万丈窟第一个周三(VisitKorea)。排每日行程表时,先把这些对上
  • 预订: 实际上只有昌德宫后苑(6天前线上)需要预订。宗庙限时参观不满10人的话,可以免预订现场购票(宫陵遗迹本部)
  • 一个人·支付: 配合宗庙讲解时间,一个人也能听英语讲解。支付见#527 韩国支付系统
  • 交通: KTX见#1287 第一次乘KTX,市内见#1298 三种交通卡怎么选

⚠ 常犯的4个错误

1. “韩国世界遗产是14项” — UNESCO名录是17项(2026年10月)。这是漏掉了伽倻古坟群(2023)和盘龟川岩刻画(2025)的旧数字

2. “宫殿周一都休息” — 昌德宫周一休息,宗庙周二休息(宫陵遗迹本部)。周一安排宗庙,周二安排昌德宫

3. “有综合参观券后苑也能进” — 宫殿综合参观券不含昌德宫后苑。后苑要另外预订(宫陵遗迹本部)

4. “河回和良洞是同一个地方” — 虽是同一项世界遗产,但相距90km(UNESCO)。河回从安东去,良洞从庆州去
