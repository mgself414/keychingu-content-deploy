한국 나물 6종 매트릭스 — 시금치·도라지·콩나물·고사리·취나물·미나리 풀세트

부제: 외국인 관광객용 한정식 반찬 + 사찰음식 + 비빔밥 정통 6종

ISSUE 03 · #876 · 2026-06-09

🎯 왜 한국 나물 매트릭스인가

외국인 한국 나물 페인포인트 = "나물 = 풀"이라고만 알고 매니아 모름. 한국 나물 = 한정식 반찬 + 사찰음식 정통 + 비빔밥 5색 풀세트 + 채식 글로벌. 같은 "Korean vegetable side"라도 시금치 (전국 #1·비빔밥)·도라지 (산나물 #1·인삼류)·콩나물 (해장 #1·#807 cluster cross)·고사리 (산나물 정통·고사리탕)·취나물 (봄 산나물 #1)·미나리 (봄 향나물·해독) 각자 다른 색·시기·매니아. 외국인은 (a) 비빔밥 = 5색 나물 풀세트 모름 (b) 사찰음식 = 모두 나물 cluster 모름 (c) 콩나물 = 해장수 cross 모름 (d) 산나물 봄 정통 모름. 본 가이드는 6종 매트릭스 + 채식·할랄 OK 강조.

★ 한눈에 나물 6종 매트릭스

종류 한국명·영문 주재료 시기·매니아 외국인 추천도
🥬 시금치나물 (Sigeumchi-namul) Spinach side 시금치 + 참기름·마늘 사계절·비빔밥 #1 ★★★★★ (#1 입문)
🌱 도라지나물 (Doraji-namul) Bellflower root 도라지 (bellflower root) + 양념 봄 산나물 #1·약재 ★★★★ (한정식 정통)
🌿 콩나물 (Kongnamul) Bean sprouts 콩나물 + 참기름·소금 해장 #1·#807 cross ★★★★★ (글로벌 친화)
🍂 고사리나물 (Gosari-namul) Bracken fern 고사리 (말림) + 들기름·간장 봄 산나물·제사 #1 ★★★ (산나물 매니아)
🌳 취나물 (Chwi-namul) Aster leaf 취나물 (봄 산나물) + 양념 봄 4~5월 #1·향 ★★★★ (봄 정통)
💧 미나리나물 (Minari-namul) Water dropwort 미나리 + 양념 봄 3~4월 #1·해독 ★★★ (봄 향 매니아)

외국인 입문 1순위 = 시금치 + 콩나물 (글로벌 친화 + 사계절)

봄 정통 = 도라지 + 취나물 + 미나리 (3~5월 산나물·해독·향)

사찰음식 = 6종 모두 (채식·할랄 OK·#1 cluster)

비빔밥 = 5색 나물 풀세트 (전주 비빔밥 정통)

🌿 6종 deep dive

🥬 시금치나물 (Sigeumchi-namul) — 입문 #1

  • 시그니처: 사계절·비빔밥 5색 정통 #1·글로벌 친화
  • 재료: 시금치 + 참기름·마늘·간장·소금
  • 외국인 친화도: ★★★★★ (#1 입문·글로벌 spinach)
  • 추천 매장: 한정식 ([#837](#837))·가정식·전주 비빔밥·MZ 카페
  • 계절: 사계절·겨울 정통
  • 가격: 한정식 반찬 무료 / 가정식 무료 / 마트 = 3,000~6,000원

🌱 도라지나물 (Doraji-namul) — 봄 산나물·한정식

  • 시그니처: 봄 산나물 #1·인삼류·약재·한정식 정통
  • 재료: 도라지 (bellflower root·말림 또는 활) + 양념
  • 외국인 친화도: ★★★★ (한정식 정통·약재 글로벌)
  • 추천 매장: 한정식 정통·강원 산나물 노포
  • 계절: 봄 3~5월·연중 (말림)
  • 가격: 한정식 무료 / 시장 = 5,000~15,000원/팩

🌿 콩나물 (Kongnamul) — 해장 #1

  • 시그니처: 해장 #1·[#807 국밥 cluster cross](#807)·콩나물국밥
  • 재료: 콩나물 + 참기름·소금·간장 (간단)
  • 외국인 친화도: ★★★★★ (#1 글로벌 bean sprouts)
  • 추천 매장: 한정식·가정식·전주 콩나물국밥·해장 cluster
  • 계절: 사계절
  • 가격: 한정식 무료 / 마트 = 2,000~4,000원

🍂 고사리나물 (Gosari-namul) — 봄·제사 정통

  • 시그니처: 봄 산나물·제사 음식 #1·정통 noodle 별미
  • 재료: 고사리 (bracken fern·말림) + 들기름·간장·마늘
  • 외국인 친화도: ★★★ (산나물 매니아)
  • 추천 매장: 한정식 정통·제사 음식·강원 노포
  • 시기: 봄·제사 (음력 명절 ([#846](#846)))
  • 가격: 한정식 무료 / 시장 = 10,000~25,000원/팩 (말림)

🌳 취나물 (Chwi-namul) — 봄 향 정통

  • 시그니처: 봄 4~5월 #1·향·산나물
  • 재료: 취나물 (aster leaf·봄 산나물) + 양념
  • 외국인 친화도: ★★★★ (봄 정통·향 글로벌)
  • 추천 매장: 한정식 정통·강원·전라 봄 정통
  • 계절: 봄 4~5월 #1
  • 가격: 한정식 무료 / 시장 = 8,000~20,000원/팩

💧 미나리나물 (Minari-namul) — 봄 향·해독

  • 시그니처: 봄 3~4월 #1·해독·향·한정식
  • 재료: 미나리 (water dropwort) + 양념
  • 외국인 친화도: ★★★ (봄 향 매니아·미국 영화 "미나리" 글로벌)
  • 추천 매장: 한정식·청도 미나리 (대구 정통)·MZ 한식당
  • 계절: 봄 3~4월 #1
  • 가격: 한정식 무료 / 시장 = 8,000~15,000원/팩

🍽 한정식·사찰음식·비빔밥 시그니처

한정식 반찬 풀세트 ([#837](#837))

  • 5단계 코스 반찬 = 나물 4~6종 + 김치·장아찌
  • 신라호텔 라연·삼청각·인사동 — 정통
  • 무한 리필 무료

사찰음식 (Temple Cuisine)

  • 사찰음식 = 6종 나물 cluster #1·채식 정통
  • 추천 매장:
  • 진관사 (서울) — 사찰음식 정통
  • 조계사 — 사찰음식 cluster
  • 봉은사·관악산 — 사찰음식 매니아
  • 할랄·코셔·채식 = OK (육류·오신채 X)

비빔밥 5색 정통 ([#856](#856))

  • 5색 = 시금치 (녹)·당근 (적)·콩나물 (백)·고사리 (갈)·도라지 (백) + 계란 (황)
  • 전주 비빔밥 = 정통 #1·궁중 비빔밥 cluster

제사 음식 (Ancestral Rites)

  • 고사리·도라지·시금치 3나물 = 제사 음식 #1
  • 음력 설날·추석 ([#846](#846)) — 정통

⚠ 외국인 자주 실수 5가지

1. "나물 = 풀": 나물 = 한정식 반찬 정통·매니아 음식·채식 글로벌.

2. "비빔밥 = 메인": 비빔밥 = 5색 나물 풀세트 (시금치·당근·콩나물·고사리·도라지).

3. "사찰음식 = 풀만": 사찰음식 = 6종 나물 cluster + 두부·버섯·정통 채식.

4. "콩나물 = 해장만": 콩나물 = 한정식 + 해장 + 가정식 모두.

5. "산나물 = 사계절": 산나물 (도라지·취·미나리·고사리) = 봄 3~5월 #1.

⚙ FAQ 8개

1. 외국인 입문 1순위: 시금치 + 콩나물 (글로벌) → 도라지 (한정식 정통).

2. 인스타·vlog: 한정식 반찬 풀세트·전주 비빔밥·사찰음식.

3. MZ 트렌드: MZ 한식당 봄 나물·전주 비빔밥·사찰음식 정통.

4. 해장 매니아: 콩나물 (#1) + 해장수 ([#870](#870)·[#807](#807)).

5. 봄 산나물: 도라지·취·미나리·고사리 (3~5월).

6. 할랄·채식·비건: 6종 모두 OK (오신채 마늘 함유 시 사찰음식 X).

7. 알레르기: 마늘·간장 글루텐 사전 고지.

8. 결제·팁: 한정식·가정식 = 카드 OK / 팁 X.

⚠ 의료·안전·식이 disclaimer

나물 = 일반 음식·식물 기반. 임신부·어린이 = OK (양념 매콤 조절). 알레르기 (마늘·간장 글루텐·도라지 약재) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 OK (식물 기반).
  • 채식·비건: 6종 모두 OK (#1 채식 정통).
  • 글루텐 free: 간장 양념 = 글루텐 (Tamari 대체).
  • 사찰음식 (오신채 X): 6종 모두 마늘 양념 제외 시 OK.
