ソウルの聖堂・教会・殉教聖地ガイド — 明洞聖堂、ヤッキョン聖堂、聖公会ソウル主教座聖堂、チョンドン教会、ウォンヒョロ イエス聖心聖堂、セナムト・西小門・タンゴゲの聖地、ガフェドン聖堂、スンドン教会

サブタイトル: 明洞聖堂(事務室 月曜日休み、無料) · ヤッキョン聖堂(年中無休、無料) · 聖公会ソウル主教座聖堂(11:00~16:00、週末休み) · チョンドン教会(年中無休、無料) · ウォンヒョロ イエス聖心聖堂(週末のみ開放) · 西小門歴史公園・西小門聖地歴史博物館(09:30~17:30、月曜日休み、博物館は1月1日・旧正月・秋夕の当日も休み、無料) · タンゴゲ殉教聖地(09:00~17:00、年中無休) · ガフェドン聖堂・スンドン教会 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルの古い聖堂と教会、カトリックの殉教聖地をまとめたものです。中区の明洞聖堂・ヤッキョン聖堂 (Yakhyeon Seongdang / 약현성당)・聖公会ソウル主教座聖堂・チョンドン教会 (Jeongdong Gyohoe / 정동교회)、龍山区のウォンヒョロ イエス聖心聖堂 (Wonhyo-ro Yesu Seongsim Seongdang / 원효로 예수성심성당)とセナムト (Saenamteo / 새남터)・タンゴゲ (Danggogae / 당고개)の聖地、中区の西小門歴史公園、鍾路区のガフェドン聖堂 (Gahoe-dong Seongdang / 가회동성당)とスンドン教会 (Seungdong Gyohoe / 승동교회)です。入場料が登録されている場所は、すべて無料です。開く日がそれぞれ違うので、下の表を先に見るとよいです。聖公会ソウル主教座聖堂は週末に休み、ウォンヒョロ イエス聖心聖堂は週末だけ開きます。麻浦区の切頭山殉教聖地は#708 マンウォン・ハプチョンガイドに、ソウルの寺は#800 ソウル精進料理・テンプルステイガイドにあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 中区 — 明洞聖堂・ヤッキョン聖堂・聖公会ソウル主教座聖堂・チョンドン教会

明洞聖堂、中区 Myeongdong-gil 74 (명동길 74)、☎ 02-774-1784 は、ソウル大司教区の主教座、明洞大聖堂です。韓国観光公社の紹介によると、韓国カトリック教会の共同体が初めて生まれた場所で、朝鮮半島で初めて建てられた大規模なゴシック様式のカトリック聖堂であり、韓国初の小教区教会です。1977年11月22日に史跡に指定されました。地下聖堂に、アンベール司教 (Imbert / 엥베르)、モーバン神父 (Maubant / 모방)、シャスタン神父 (Chastan / 샤스탕)などの殉教者の遺骨が安置されています。平日と週末にミサと告解の時間があり、信者でなくても参加できると登録されています。

  • 開く時間: 事務室 火~土 09:00~19:00、日 07:00~21:00。常設の告解 月 13:00~17:00、火~金 11:00~20:00、土・日 10:00~20:00。
  • 休み: 事務室 毎週月曜日。料金: 無料。駐車: 可能。

ヤッキョン聖堂 (Yakhyeon Seongdang / 약현성당)、中区 Cheongpa-ro 447-1 (청파로 447-1)、☎ 02-362-1891 は、1892年に建てたレンガ造りの聖堂です。1886年に宗教の自由が認められたあと信者が増え、明洞聖堂の下の公所として建てられました。ドゥーセ神父 (Doucet / 두세)が敷地を用意し、コスト神父 (Coste / 코스트)が設計と施工監督を担いました。韓国観光公社の紹介によると、韓国で初めて建てた西洋式の聖堂建築物です。ゴシックの要素が一部ありますが、半円形のアーチなど全体的にロマネスク様式です。「ヤッキョン」は、薬草畑がある峠という意味の「ヤクジョンヒョン (Yakjeonhyeon / 약전현)」を縮めた名前です。

  • 休み: 年中無休。料金: 無料。駐車: 可能。

大韓聖公会ソウル主教座聖堂、中区 Sejong-daero 21-gil 15 (세종대로21길 15)、☎ 02-730-6611 は、大韓聖公会ソウル教区の主教座聖堂です。朝鮮聖公会の第3代主教トロロープ (Trollope / 트롤로프)主教が、英国人アーサー・ディクソン (Arthur Dixon / 아더 딕슨)の設計で建て、1993年に英国のある図書館で元の設計図を見つけ、1996年に本来の姿のまま完成しました。ロマネスク様式に韓国の伝統建築技法を加えた建物です。中には12使徒を象徴する石柱とイエス・キリストのモザイクがあり、地下聖堂にトロロープ主教の遺骨が安置された銅板があります。市庁駅3番出口から200mです。

  • 開く時間: 11:00~16:00。休み: 週末。
  • 案内: 韓国語の案内ボランティアが聖堂の中に常時待機しています。外国語の案内は事前の問い合わせと登録されています。駐車: 不可。

チョンドン教会 (Jeongdong Gyohoe / 정동교회)、中区 Jeongdong-gil 46 (정동길 46)、☎ 02-753-0001~3 は、アメリカのメソジスト宣教師アペンゼラー (Appenzeller / 아펜젤러)が1887年にベテル礼拝堂 (Bethel / 베델)で最初の礼拝を始めた教会です。今の建物は1895年に建て始め、1897年12月26日に献堂しました。韓国観光公社の紹介によると、プロテスタントが伝わってから最初に建てられた教会で、今残っている唯一の19世紀の教会建物です。アメリカ式に簡素化したゴシック様式で、1926年に両側の翼部を広げて今の四角い形になりました。

  • 休み: 年中無休。料金: 無料。駐車: 可能。

📍 龍山区 — ウォンヒョロ イエス聖心聖堂・セナムト記念聖堂・タンゴゲ殉教聖地

旧龍山神学校とウォンヒョロ イエス聖心聖堂 (Wonhyo-ro Yesu Seongsim Seongdang / 원효로 예수성심성당)、龍山区 Wonhyo-ro 19-gil 49 (원효로19길 49)、☎ 02-701-5501 は、コスト神父が設計と監督を担った2つの建物です。龍山神学校は1892年、イエス聖心聖堂は1902年に建てられました。韓国観光公社の紹介によると、龍山神学校は韓国初の神学校の建物です。聖堂は丘に建てたため南側は3階、北側は2階で、入口に入ると中央のステンドグラスが見えます。どちらの建物もカトリックの聖地として登録されていて、キム・デゴン神父 (Gim Daegeon / 김대건)の遺骨が50年余り安置されていた場所です。

  • 開く時間: 週末 09:00~17:00。休み: 平日。学生の安全強化のため週末だけ開くと登録されています。
  • 料金: 無料。駐車: 可能。

セナムト記念聖堂 (Saenamteo Ginyeom Seongdang / 새남터기념성당)、龍山区 Ichon-ro 80-8 (이촌로 80-8)、☎ 02-716-1791 は、韓国カトリック教会創立200周年を記念して1984年に着工し、3年で完成した聖堂です。セナムトは朝鮮初期から軍事練武場と処刑場として使われた場所で、1801年の辛酉迫害から己亥迫害、丙午迫害、丙寅迫害の際に、多くのカトリック信者が処刑されました。聖堂の中にセナムト記念館があり、殉教者の遺骨が安置されています。

  • 料金: 無料。駐車: 不可。

タンゴゲ殉教聖地 (Danggogae Sungyo Seongji / 당고개순교성지)、龍山区 Cheongpa-ro 139-26 (청파로 139-26)、☎ 02-711-0933 は、1839年の己亥迫害が終わるころ、男女の信者10人が殉教した場所です。もともとは西小門外の四つ辻で処刑される予定でしたが、西小門外の商人たちが旧正月前の大市を理由に刑場を移してほしいと求め、ここで処刑されました。「野バラの痛み、梅の花の香り」をテーマに造成し、十字架の道行き14処があります。6号線孝昌公園駅5番出口から歩いて15分です。

  • 開く時間: 09:00~17:00。休み: 年中無休。駐車: 無料。

📍 中区 — 西小門歴史公園・西小門聖地歴史博物館

西小門歴史公園、中区 Chilpae-ro 5 (칠패로 5)、☎ 西小門聖地歴史博物館 02-3147-2401 は、「西小門外の四つ辻の処刑地」だった場所に造った公園です。辛酉迫害から丙寅迫害まで多くのカトリック信者がここで処刑され、そのうち44人が聖人になりました。韓国観光公社の紹介によると、国内最大のカトリック聖地です。1984年に建てた殉教者顕揚塔をそのまま残して公園を整えました。

西小門聖地歴史博物館は公園の中に2019年6月に開館しました。地下2階に常設展示館があり、地下3階の「ハヌル広場 (Haneul Gwangjang / 하늘광장)」は天井が開いていて、地下から空を見られます。韓国観光公社の紹介によると、2019年ソウル市建築賞の最優秀賞を受賞しました。毎週木曜日に西小門歴史探訪の解説があります。

  • 開く時間: 09:30~17:30。博物館の入場締切 17:00。
  • 休み: 毎週月曜日。博物館は1月1日、旧正月・秋夕の当日も休みます。
  • 料金: 無料。駐車: 216台、最初の30分 2,000ウォン、その後10分ごとに600ウォン。

📍 鍾路区 — ガフェドン聖堂・スンドン教会

ガフェドン聖堂 (Gahoe-dong Seongdang / 가회동성당)、鍾路区 Bukchon-ro 57 (북촌로 57)、☎ 02-763-1570 があるブクチョン (Bukchon / 북촌)一帯は、韓国観光公社の紹介によると、チュ・ムンモ神父 (Ju Munmo / 주문모)が1795年4月5日の復活大祝日に、チェ・インギル (Choe Ingil / 최인길)の家で朝鮮の地で初めてのミサを執り行った地域です。1949年に正式な小教区教会になり、古い聖堂を取り壊して建てた今の新しい聖堂は、2013年11月21日に竣工しました。東洋と西洋の建築様式を合わせた建物です。

  • ミサ: 日曜日 07:00・10:00・18:00、土曜日 18:00、毎月第1土曜日 07:00。平日 月 07:00、火 19:00、水 10:00、木 19:00、金 10:00。
  • 休み: 毎週月曜日、祝日と登録されています。同じ登録情報のミサ時間表には、月曜日 07:00のミサもあります。
  • 駐車: 可能。

スンドン教会 (Seungdong Gyohoe / 승동교회)、鍾路区 Insadong-gil 7-1 (인사동길 7-1)、☎ 02-732-2341 は、1893年にアメリカ人宣教師サミュエル・ムーア (Samuel Moore / 새뮤얼 무어)牧師が建てた教会です。今の赤レンガの礼拝堂は1910年に建て始め、1912年に完成しました。1919年2月20日、この教会の青年勉励会長だった延禧専門学校の学生キム・ウォンビョク (Gim Wonbyeok / 김원벽)ら学生代表が、独立万歳運動を準備する最初の学生指導者会議をここで開きました。1922年にはこの教会で朝鮮女子基督教青年会が設立されました。

  • 開く時間: 常時開放。礼拝の時間は登録されていません。休み: 年中無休。料金: 無料。駐車: 可能。

⚠ 前もって知っておきたい3つのこと

  1. 聖公会ソウル主教座聖堂は週末に休み、ウォンヒョロ イエス聖心聖堂は週末だけ開きます — 聖公会の聖堂は11:00~16:00、イエス聖心聖堂は週末 09:00~17:00です。
  2. 西小門歴史公園と西小門聖地歴史博物館は月曜日が休みです — 博物館は1月1日、旧正月・秋夕の当日も休み、入場締切は17:00です。
  3. ガフェドン聖堂は休みとミサ時間表が食い違って登録されています — 休みは毎週月曜日・祝日ですが、ミサ時間表には月曜日 07:00のミサがあります。
