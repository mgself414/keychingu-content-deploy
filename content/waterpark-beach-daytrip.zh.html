⚠ 外国人常犯的3个错误

1. “汉江游泳池 (Hangang Suyongjang / 한강수영장) = 在江里游泳” — 不知道是户外泳池

外国游客搜索 "swim in Hangang River" → 以为是在江水里游泳，穿着衣服试图进入汉江 (危险·法律禁止)。实际上，汉江游泳池 (Hangang Suyongjang / 한강수영장) 是汉江公园 (Hangang Gongwon / 한강공원) 旁的户外泳池 (经过净水处理的游泳池) — 7~8月免费开放。出于安全考虑，禁止进入汉江主河道。准确的英文搜索应为 "Hangang outdoor swimming pool"。在盘浦 (Banpo / 반포)·纛岛 (Ttukseom / 뚝섬)·汝矣岛 (Yeouido / 여의도)·蚕室 (Jamsil / 잠실)·广津 (Gwangjin / 광진) 5处运营，具体运营时间请查阅首尔市官方网站。

2. “水上乐园 (Water Park / 워터파크) 都一样” — 不了解韩国四大水上乐园的区别

外国游客只知道“加勒比海湾 (Caribbean Bay / 캐리비안베이)”而抱怨价格昂贵。实际上，韩国有四种主要的水上乐园 (Water Park / 워터파크):

  • 加勒比海湾 (Caribbean Bay / 캐리비안베이) (₩60K+) = 韩国最大，外国人知名度第一，7~8月需等待1小时
  • 乐天水上乐园 (Lotte Water Park / 롯데 워터파크) (₩50K) = 位于金海 (Gimhae / 김해) (釜山圈)，可与釜山 (Busan / 부산) 旅行结合
  • 熊津娱乐城 (Woongjin Playdoci / 웅진플레이도시) (₩40K~₩55K) = 离首尔市中心最近，性价比高
  • 海洋世界 (Ocean World / 오션월드) (₩55K~₩70K) = 位于江原道洪川 (Hongcheon / 홍천)，自然风光 + 可与滑雪季结合
  • 选择规则: 性价比 = 熊津娱乐城 (Woongjin Playdoci / 웅진플레이도시) / 外国人完整体验 = 加勒比海湾 (Caribbean Bay / 캐리비안베이) / 结合釜山 (Busan / 부산) = 乐天水上乐园 (Lotte Water Park / 롯데 워터파크) / 自然风光 = 海洋世界 (Ocean World / 오션월드)

3. “东海 (Donghae / 동해) 和西海 (Seohae / 서해) = 同一片海” — 不了解差异而选择错误

东海 (Donghae / 동해) (江陵 (Gangneung / 강릉)·束草 (Sokcho / 속초)·釜山 (Busan / 부산)) = 清澈的海水·冲浪·沙滩 (sand beach) / 西海 (Seohae / 서海) (乙旺里 (Eulwangni / 을왕리)·仁川永宗岛 (Incheon Yeongjongdo / 인천 영종도)) = 滩涂 (mudflat / 갯벌)·日落·水深较浅。外国游客搜索 "Seoul nearest beach" 时，乙旺里 (Eulwangni / 을왕리) (西海 (Seohae / 서해)) 会排在第一位 — 仁川机场 (Incheon Gonghang / 인천공항) 旁1.5小时。然而，期待沙滩 (sand beach) 的外国游客可能会失望 (以滩涂 (mudflat / 갯벌) 为主)。"Korean beach with clean water" = 东海 (Donghae / 동해) (江陵 (Gangneung / 강릉)·釜山 (Busan / 부산))，需要 KTX (Korea Train eXpress / 韩国高速列车) 2~3小时。初次访韩时请提前考虑行程。

§1. 首尔近郊水上乐园 (₩40,000~₩75,000)

1. 加勒比海湾 (Caribbean Bay / 캐리비안베이) ★ 韩国最大·外国人知名度No.1

  • 位置: 京畿道龙仁 (Yongin / 용인) 爱宝乐园 (Everland / 에버랜드) (地铁盆唐线 (Bundangseon / 분당선) + 穿梭巴士或江南站 (Gangnam-yeok / 강남역) 直达巴士)
  • 价格: 1日通票 ₩60,000~₩75,000 (季节浮动，爱宝乐园 (Everland / 에버랜드) 套票 +₩30,000)
  • 时间: 从首尔江南 (Gangnam / 강남) 出发1小时 (穿梭巴士或自驾)
  • 特色: 韩国水上乐园 (Water Park / 워터파크) 全球第一。外国游客Vlog·Instagram曝光率极高。拥有众多造浪池·滑梯·水上环形滑道
  • 拥挤度: 7~8月周末需等待1小时。建议选择平日或季节开始·结束时 (6月底，8月底)
  • 外国人推荐: 初次体验韩国水上乐园 (Water Park / 워터파크) = 加勒比海湾 (Caribbean Bay / 캐리비안베이)。可选择爱宝乐园 (Everland / 에버랜드) 套票，体验1晚2天的完整行程

2. 乐天水上乐园 (Lotte Water Park / 롯데 워터파크) (釜山圈，可一日游)

  • 位置: 庆尚南道金海 (Gimhae / 김해) (距釜山 (Busan / 부산) 30分钟)
  • 价格: ₩50,000~₩65,000
  • 时间: 从首尔乘坐 KTX (Korea Train eXpress / 韩国高速列车) 2.5小时 → 金海 (Gimhae / 김해) 穿梭巴士30分钟
  • 特色: 可结合釜山 (Busan / 부산) 一日游。水上乐园 (Water Park / 워터파크) + 釜山海云台 (Busan Haeundae / 부산 해운대) 1晚2天完整行程
  • 外国人推荐: 釜山 (Busan / 부산) 游客的首选。相比加勒比海湾 (Caribbean Bay / 캐리비안베이) 人较少

3. 熊津娱乐城 (Woongjin Playdoci / 웅진플레이도시) (离首尔市中心最近)

  • 位置: 京畿道富川 (Bucheon / 부천) (地铁7号线富川综合运动场站 (Bucheon Sports Complex Station / 부천종합운동장역))
  • 价格: ₩40,000~₩55,000 (性价比No.1)
  • 时间: 从首尔江南 (Gangnam / 강남) 出发1小时 (地铁 + 巴士)
  • 特色: 离首尔最近的水上乐园 (Water Park / 워터파크) + 性价比高 — 推荐外国游客短期一日游
  • 外国人推荐: 行程短·预算有限的外国游客。市中心交通便利性极高

4. 海洋世界 (Ocean World / 오션월드) (江原道洪川维瓦尔第公园)

  • 位置: 江原道洪川 (Hongcheon / 홍천) (从首尔江南 (Gangnam / 강남) 乘坐穿梭巴士2小时)
  • 价格: ₩55,000~₩70,000
  • 时间: 穿梭巴士2小时
  • 特色: 自然风光 + 可与滑雪季维瓦尔第公园 (Vivaldi Park / 비발디파크) 结合 (冬季滑雪 + 夏季水上乐园 (Water Park / 워터파크))。适合喜欢江原道 (Gangwon-do / 강원도) 自然风光的外国游客
  • 外国人推荐: 维瓦尔第公园 (Vivaldi Park / 비발디파크) 1晚住宿 + 滑雪季在冬季。夏季 = 海洋世界 (Ocean World / 오션월드) + 江原道 (Gangwon-do / 강원도) 山林一日游

  • 结合: 仁川机场 (Incheon Gonghang / 인천공항) 自由时间 + 乙旺里 (Eulwangni / 을왕리) = 转机外国游客一日游

  • 外国人推荐: 凌晨正东津 (Jeongdongjin / 정동진) 日出 → 镜浦海边 (Gyeongpo Haebyeon / 경포해변) 游泳 → 安木海边 (Anmok Haebyeon / 안목해변) 咖啡街 → KTX (Korea Train eXpress / 韩国高速列车) 返回 = 1日完整体验

  • 价格: KTX (Korea Train eXpress / 韩国高速列车) 单程约 ₩60,000
  • 时间: 从首尔站出发 KTX (Korea Train eXpress / 韩国高速列车) 2.5~3小时
  • 特色: 韩国No.1海滩 + 釜山 (Busan / 부산) 城市完整体验 (广安里 (Gwangalli / 광안리)·札嘎其 (Jagalchi / 자갈치)·国际市场 (Gukje Sijang / 국제시장))
  • 外国人推荐: 建议1晚2天釜山 (Busan / 부산) 完整一日游 (当天往返可能比较紧张)。KTX (Korea Train eXpress / 韩国高速列车) + 1晚酒店总计 ₩200,000~₩300,000

12. 济州 (Jeju / 제주) 一日游 (飞机1小时，建议1晚2天)

  • 位置: 济州岛 (Jeju-do / 제주도) (金浦机场 (Gimpo Gonghang / 김포공항)·仁川机场 (Incheon Gonghang / 인천공항) → 济州机场 (Jeju Gonghang / 제주공항))
  • 价格: 飞机单程 ₩50,000~₩150,000 (季节·航空公司)
  • 时间: 飞机1小时 (从首尔金浦机场 (Gimpo Gonghang / 김포공항) 出发)
  • 特色: 韩国No.1度假胜地 + 汉拿山 (Hallasan / 한라산) + 海滩 + 黑猪肉。外国人必访
  • 外国人推荐: 不建议当天往返，建议1晚2天~2晚3天。机票 + 酒店 + 租车总计约 ₩300,000~₩500,000

外国人友好提示

1. 语言: 加勒比海湾 (Caribbean Bay / 캐리비안베이)·乐天水上乐园 (Lotte Water Park / 롯데 워터파크)·海云台 (Haeundae / 해운대)·江陵 (Gangneung / 강릉) = 英文OK。汉江游泳池 (Hangang Suyongjang / 한강수영장)·熊津娱乐城 (Woongjin Playdoci / 웅진플레이도시)·乙旺里 (Eulwangni / 을왕리) = 韩语为主，可使用Papago翻译软件

2. 预订:

  • 水上乐园 (Water Park / 워터파크) = 旺季 (7~8月周末) 必须在线预订，平日可即时入场
  • KTX (Korea Train eXpress / 韩国高速列车) = SRT高速列车 (SRT / SRT)·韩国铁路公社 (Korail / 코레일) 官方App (支持英文)，建议提前2~3天预订
  • 飞机 = 真航空 (Jin Air / 진에어)·济州航空 (Jeju Air / 제주항공)·德威航空 (T'way Air / 티웨이) 等廉价航空公司 (LCC) 价格便宜60~80% (外国人支付OK)

3. 支付: 水上乐园 (Water Park / 워터파크)·KTX (Korea Train eXpress / 韩国高速列车)·飞机 = 100%刷卡 / 汉江游泳池 (Hangang Suyongjang / 한강수영장) = 免费 / 海滩餐厅 = 部分接受现金

4. 泳衣: 汉江游泳池 (Hangang Suyongjang / 한강수영장) 必须穿泳衣 (短裤·普通衣服禁止入场)。水上乐园 (Water Park / 워터파크) 可在园内购买 (外国人常高价购买 → 建议提前购买)

5. 防晒: 韩国夏季紫外线强，SPF 50+ 必备。便利店 (Pyeonuijeom / 편의점)·Olive Young (Olive Young / 올리브영) 有售，价格 ₩3,000~₩15,000

6. 泳圈·泳圈包: 汉江游泳池 (Hangang Suyongjang / 한강수영장) 可自带泳圈，水上乐园 (Water Park / 워터파크) 门票包含或另行租赁 ₩5,000~₩10,000

7. 酒店: 釜山 (Busan / 부산)·江陵 (Gangneung / 강릉)·济州 (Jeju / 제주) = 众多外国人友好酒店 (Booking.com·Agoda)。7~8月旺季必须提前1周预订

8. 清真·素食:

  • 水上乐园 (Water Park / 워터파크) 内餐厅 = 以韩式 (Hansik / 한식)·炸鸡·拉面为主，清真·素食选项有限
  • 海滨城市 (釜山 (Busan / 부산)·江陵 (Gangneung / 강릉)·济州 (Jeju / 제주)) = 各有1~3家清真·素食餐厅 (可在Booking搜索)
  • 参考 [#202 素食·清真攻略](202_vegan_halal_guide.md)

季节信息

  • 5月中旬~6月: 汉江游泳池 (Hangang Suyongjang / 한강수영장) 开放 (6月开始)，水上乐园 (Water Park / 워터파크) 季节开放

  • 8月底~9月初: 季节尾声，汉江游泳池 (Hangang Suyongjang / 한강수영장) 9月初关闭

  • 10月~次年5月: 全部休园，室内水上乐园 (Water Park / 워터파크) (乐天·部分) 四季开放
