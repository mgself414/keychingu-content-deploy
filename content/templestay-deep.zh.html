⚠ 外国游客常犯3大错误

1. “寺庙 (Sachal / 사찰) = 处处皆是”: 韩国 (Hanguk / 한국) 寺庙 (Sachal / 사찰) = 联合国教科文组织7大山寺 (2018) + 韩国 (Hanguk / 한국) 三宝寺刹 (通度 (Tongdo / 통도)·海印 (Haein / 해인)·松广 (Songgwang / 송광)) + 市中心·郊外 分类。

2. “寺院寄宿 (Templestay / 템플스테이) = 仅限韩国人”: 韩国 (Hanguk / 한국) 寺院寄宿 (Templestay / 템플스테이) = 外国游客友好型首选 + 英文全套 + 1晚2天 ₩50,000~150,000 (约$37~$110 / 约260~780 RMB / 约5,500~16,500 JPY)。

3. “海印寺 (Haeinsa / 해인사) = 仅有八万大藏经 (Palman Daejanggyeong / 팔만대장경)”: 海印寺 (Haeinsa / 해인사) = 世界首屈一指大藏经 联合国教科文组织1995 + 八万大藏经 (Palman Daejanggyeong / 팔만대장경) 81,258块木板。八万大藏经 (Palman Daejanggyeong / 팔만대장경) 是高丽时代 (Goryeo / 고려) 雕刻的佛教大藏经，以其数量庞大和保存完好而闻名于世。
