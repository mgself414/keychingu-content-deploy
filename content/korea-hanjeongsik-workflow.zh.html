#韩式韩定食预约、着装、礼仪流程——Shilla Layeon，从提前1-2周预约到6步课程

副标题：外国游客的5步工作流程+餐桌预订、着装要求、皇家礼仪、付款提示

第03期·#838·2026-06-09

🎯 为什么选择韩国 韩国食品工作流程指南

即使您知道[#831韩定食6步矩阵](#831) — 预订、礼仪和付款流程是分开的。韩国传统餐点是 (a) 预订系统 (Catch Table、Naver、电话提前 1-2 周) (b) 着装要求 (酒店 = 商务休闲 / 仁寺洞 = 免费) (c) 6 步套餐上菜顺序和礼仪 (粥 → 田 → 主菜 → 汤 → 米饭 → 甜点) (d) 免费无限量补充配菜 (e) 服务费 10% + 增值税 10%（酒店）。对于外国人：（1）预订系统只有韩语； (2) 着装要求不明； （三）课程顺序混乱的； (4)付款时的服务费令人惊讶。本指南为5步+礼仪矩阵+英语口语+地道的酒店小贴士。

★ 5 步工作流程概览

步骤 行动 时间 外国人的要点
1️⃣选店+预订 Catch Table·Naver·电话·酒店礼宾 1-2 周前 新罗Rayeon·三清阁=需要提前1-2周
2️⃣ 着装要求 + 抵达 酒店=商务休闲/仁寺洞=自由 波动 提前 5 分钟查看抵达/预订姓名
3️⃣ 座位+菜单信息 韩国料理课程选择/选项 5-10 分钟 查看英文菜单/课程价格
4️⃣ 6 道菜餐 粥→全菜→主菜→汤→米饭→甜点 1.5~3小时 配菜免费无限续杯
5️⃣ 付款 卡+10%服务费+10%增值税（酒店） 1~3分钟 一般 = 卡 OK / 提示 X

所需总时间：仁寺洞/全州韩式餐=1.5~2小时/酒店传统餐=2~3小时

📱 预订系统矩阵

🥇 CatchTable — 韩国#1高级餐厅预订应用程序

  • 功能：韩国#1高级餐厅预订应用程序，许多米其林餐厅，部分英语支持
  • 系统：

1.下载应用程序（韩国电话号码短信验证）

2. 餐厅搜索（“新罗丽宴”·“三清阁”·“龙水山”）

3. 选择日期、时间、人数

4. 支付预订押金（部分店铺=30,000~100,000韩元押金）

5. 预订确认/短信通知

  • 外国人友好度：★★★★（部分英文）

🥈 Naver 预订

  • 功能：韩国#1 搜索/预订一体化/综合韩国食品店
  • 系统：Naver搜索→选择商店→预订→付款
  • 外国人友好度： ★★★（大部分是韩语，一些是英语）

🥉 酒店礼宾部 — 第 1 名外国人

  • 特色：酒店前台英文响应，第一优先通道
  • 优点：英语OK，预订服务，着装信息，交通信息
  • 外国人友好度： ★★★★★（第一名）

🏛电话预订

  • 特色：许多历史悠久的传统韩国餐厅
  • 系统：电话→姓名、人数、日期→预订确认
  • 外国人友好度：★★（韩语/翻译应用程序）

🍽 6步课程礼仪

1️⃣ Juk 礼仪

  • 顺序：先上菜（吊起你的胃口）
  • 方式：小碗=一次吃一口/你可以添加或减少胡椒粉。

2️⃣全的礼仪

  • 顺序：第二（从开胃菜和配菜开始）
  • 方式：手指

3️⃣ Juyori（主菜）礼仪

  • 顺序：中·主（1~3道菜）
  • 方式：排骨·烤肉 = 筷子 + 部分刀/叉 / 九节盘 = 9 格什锦选择

4️⃣唐礼仪

  • 点菜：主菜之后或配米饭
  • 方式：Sinseonro（皇家火锅）=员工煮食物→您一次吃一份。

5️⃣ Bap礼仪

  • 订单：几乎在最后（用餐结束）
  • 方式：12+种配菜=均匀分布 / 免费无限量补充泡菜和萝卜（“请再给我一些泡菜”）

6️⃣ 甜点（Husik）礼仪

  • 顺序：最后
  • 礼仪：药果、水精果、食客、配茶

💰 付款流程

酒店韩餐

1. 刷卡支付（房费或个人）

2. 10% 服务费 + 10% 增值税 自动添加

3. 总价=菜单+20%

4. 小费X（韩国=无小费文化）

一般韩国料理（仁寺洞、全州、老浦）

1. 刷卡支付 或一些现金

2. **服务费

3. 增值税 = 包含菜单（X 单独）

4. 提示X

单独付款

  • 酒店：一人付费 → 房费或接送
  • 通用：一人支付 → Kakao Pay/Toss 转账

⚠ 外国人常犯的7个错误

1. **》预订

2. “着装要求 X”：酒店 = 商务休闲装（牛仔裤、无袖、短裤 X）。

3. “第6步=一起上菜”：第6步= 按顺序上菜（1.5~3小时）。

4. “服务费=小费”：韩国=小费X。 酒店服务费10%=自动收取。

5. “配菜 = 1 份”：免费无限续杯（要求“请更多”）。

6. “端碗”：韩国传统= 碗=放在桌子上 使用勺子和筷子。

7. “包装 = X”：部分商店 = 有包装（“有包装”）。酒店=通常是X。

⚙ 8 个常见问题解答

1. 第一韩定食 = 地点：仁寺洞/全州韩定食（性价比高的介绍）→ Hotel La Yeon（豪华）。

2. Insta·vlog：新罗Layeon（米其林3星）、三清阁、仁寺洞韩屋传统餐点。

3. 日期/周年纪念：Shilla Layeon、乐天酒店、三清阁。

4. 如何预订：Catch Table（韩国#1应用程序）> Naver预订> 酒店礼宾> 电话。

5. 着装要求：酒店=商务休闲/仁寺洞=免费。

6. 过敏·怀孕：参见[#831免责声明](#831)。海鲜、坚果和蜂蜜提前通知。

7. 素食·清真·犹太：[#800寺庙食品](#800)韩国食品或素食韩国食品提前申请。

8. 增值税退税：食品和饮料一般退税

⚠ 医疗/安全/饮食免责声明

韩定食 = 6道菜（1.5~3小时）。孕妇/免疫系统较低=推荐熟食菜单（避免生鱼/生鱼片课程）。过敏（海鲜、牛肉、猪肉、鸡蛋、坚果、蜂蜜）提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

店铺信息免责声明：酒店韩国餐厅/仁寺洞韩国料理运营/价格/菜单变更 — 访问前请查看NAVER/Kakao地图或官方网站。

饮食限制后备：

  • Halal·Kosher：一般韩国食品=非清真食品。 → 寺庙食品韩定食[#800]。
  • 素食/纯素食：寺庙食物或素食限量餐，可根据提前要求提供（素食选项包括杂菜、全菜和炖菜）。
  • 不含麸质：许多韩式调味料（酱油、红辣椒酱）。提前检查商店。
