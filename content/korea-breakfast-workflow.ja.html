🍳チャンネル別ワークフロー

Type A — ホテルの朝食 (06:30～10:00・予約必須)

  • シグネチャー: 5つ星・フルセット・予約必須
  • 時間: 06:30～10:00 (ホテル別)
  • 価格: 60,000~120,000ウォン/1人 (+サービス料10% +税10%)
  • メニュー: 様式・韓国料理・和食フルセット
  • 外国人親和性: ★★★★★ (英語・1順位)
  • 予約: ホテルのフロント・ホームページ（ピークシーズン1～3日前）

Type B — MZブランチ(10:00～14:00・インスタ)

  • シグネチャー: MZトレンド・インスタ #1
  • 時間: 10:00～14:00
  • 価格：15,000〜30,000ウォン/ 1人
  • メニュー: アボカドトースト・エッグベネディクト・キムチベーグル・伝統お粥 fusion
  • おすすめ店：弘大・江南・梨泰院・ソンス・ヨンナムMZカフェ
  • 外国人親和性: ★★★★★ (MZ #1)
  • テーブルリングアプリ事前登録を推奨

Type C — 海装局 (24h・夜明けマニア)

  • シグネチャー：翌日#1・24h
  • 時間: 24h・夜明け 05:00～09:00 マニア
  • 価格：8,000〜15,000ウォン/ 1人
  • メニュー: もやしクッパ・ファンテヘジャン・骨ヘジャン
  • おすすめ：本竹・全州もやし・ソウルファンテ・カンウォン正統
  • 外国人親和性: ★★★★★ (海装#1)

Type D — コンビニ・チェーン (24h・即時)

  • シグネチャー: 24h・苛性雨・即時
  • 時間: 24h
  • 価格: 2,500～12,000ウォン/1食
  • メニュー: キンバプ・三角・弁当・ラーメン（コンビニ）/お粥・分食（チェーン）
  • おすすめ：CU・GS25・セブンイレブン・イマート24・本竹・殺物語・キムガネ
  • 外国人親和性: ★★★★ (24h・英語)

🌶外国人英語発話サンプル

  • "ホテルの朝食の予約" = "Hotel breakfast reservation, please"
  • "MZブランチ+アボカドトースト" = "MZ brunch with avocado toast"
  • "ヘジャングク1人" = "Hangover soup for 1 (Haejang-guk)"
  • "コンビニ弁当" = "Convenience store bento box (Dosirak)"
  • "テイクアウト" = "Takeout, please"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁な誤り5つ

1. 「ホテルの朝食=無料含まれています」：ホテルの朝食= 宿泊+別途またはを含む（評価を確認）。

2. "MZブランチ=即時": MZブランチ=ウェイト30分〜2h(テーブルリングアプリを推奨)。

3. "ヘジャングク=マコムマン": ヘジャングク= もやしクッパ・ファンテヘジャン淡白 OK。

4. 「コンビニエンスストア=英語X」：コンビニエンスストア=英語表示+ MZシールドコスパ比#1。

5. "韓国朝 = 難しさ": 韓国朝 = 5つ星フルセット+ MZ fusionグローバルOK。

⚙ よくある質問8件

1. 最初の朝=任意のチャンネル: ホテルの朝食（高級）+ MZブランチ（トレンド）。

2. インスタ・vlog: MZブランチ(#1)。

3. MZ トレンド: MZ ブランチ (#1)。

4. 海洋マニア: 海装局(#807 cluster cross)。

5. 24hコスパ: コンビニエンスストア(#1)。

6. アレルギー・妊娠: [#888 disclaimer](#888)参照。

7. 決済・チップ：カードOK /ホテル＝サービス料10% /チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

朝食=一般食品。妊婦・子ども＝OK。アレルギー（シーフード・ナッツ・ミルク・卵）事前通知。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：ホテル＝ハラールメニュー一部・ヘジャングク＝もやしクッパOK・コンビニ＝事前確認。
  • ベジタリアン・ビーガン: MZブランチ・コンビニベジタリアンオプション OK・ホテルベジタリアンフルセットOK。
  • グルテンフリー: 醤油味付け=グルテン(タマリ代替)。
