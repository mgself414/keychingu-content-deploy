为什么要去广藏市场二手商店街？

“藏在美食市场楼上的花纹·女装淘宝天堂”

广藏市场 (Gwangjang Sijang / 광장시장) 是享誉全球的韩国代表性美食市场。1楼排队品尝绿豆饼 (Bindaetteok / 빈대떡)、麻药紫菜包饭 (Mayak Gimbap / 마약김밥)、生拌牛肉 (Yukhoe / 육회) 的外国游客景象，是SNS上最常见的画面。

然而，其楼上的2楼几乎是另一个世界。自1980年代起，这里便汇集了约200~300家进口二手商店 (Guje Sangga / 구제상가)，已成为韩国10~20多岁复古淘宝者 (Digging / 디깅) 的又一圣地。由于鲜有外国游客，它也被韩国时尚达人 (Paepi / 패피) 称为“秘密淘宝点”。

KeyChinGu 推荐广藏市场二手商店街而非东庙的4个理由：

1. 女装花纹·连衣裙特色 — 如果说东庙 (Dongmyo / 동묘) 主要是“衣服堆 (混合)”，那么广藏2楼则主打花纹连衣裙、复古衬衫、粗花呢夹克。秋冬外套 (牛仔夹克、军装夹克、大衣) 也非常丰富。

2. 店铺式淘宝 — 无“衣服堆” — 所有衣服都挂在衣架上，按尺码和品类分类。淘宝难度远低于东庙的摊位。

3. 距离美食市场仅1分钟 — 淘宝后下到1楼，即可立即享用麻药紫菜包饭 (Mayak Gimbap / 마약김밥)、绿豆饼 (Bindaetteok / 빈대떡)、宴会面 (Janchi Guksu / 잔치국수)。动线效率广藏完胜。

4. 钟路5街 (Jongno 5-ga / 종로5가) = 韩国旅游发展局100选 — 1楼美食 + 2楼二手 + 附近东大门 (Dongdaemun / 동대문)·乐园商街 (Nagwon Sangga / 낙원상가) 步行30分钟内可达。是外国游客最不易迷路的淘宝入门路线。

了解广藏市场3层结构

广藏市场 (Gwangjang Sijang / 광장시장) 不仅仅是一个简单的1楼市场。它是按楼层和区域划分，完全不同的市场重叠在一起。

楼层 区域 主打 外国游客视角
1楼东侧 美食胡同 (Meokja Golmok / 먹자골목) 绿豆饼 (Bindaetteok / 빈대떡)·麻药紫菜包饭 (Mayak Gimbap / 마약김밥)·生拌牛肉 (Yukhoe / 육회)·宴会面 (Janchi Guksu / 잔치국수) 广藏的标志。排队品尝的地方
1楼西侧 韩服 (Hanbok / 한복)·被褥·布料 韩服 (Hanbok / 한복)·传统布料·被褥 几乎没有外国游客，但很有趣
2楼西侧 进口二手商店街 (Guje Sangga / 구제상가) 复古服饰 本次内容的重点
2楼东侧 配饰·杂货 包包·手表·鞋子 以批发为主，不适合普通游客

从8号出口出来直走 → 穿过美食胡同 (Meokja Golmok / 먹자골목) → 经过“相遇广场 (Mannam-ui Gwangjang / 만남의 광장)”胡同 (Golmok / 골목，小巷) → 建筑2楼楼梯是前往二手商店街 (Guje Sangga / 구제상가) 的标准路线。

二手商店街的商品 — 广藏的4大优势

优势1 — 花纹连衣裙 (韩国复古的精髓)

这里是1970~90年代韩国时尚中，华丽花纹 (碎花、几何、佩斯利) 连衣裙最集中的地方。在东庙 (Dongmyo / 동묘) 几乎看不到这类商品。

  • 价格: ₩10,000~40,000
  • 尺码: 韩式尺码 (偏小) — 标示的“55”大约是美国S码，“66”大约是M码
  • 推荐用途: Instagram拍照用，韩式春秋野餐穿搭

优势2 — 复古衬衫 + 半身裙套装

这里有大量90年代从日本·香港进口的粗花呢、衬衫式上衣、A字裙。许多店铺可以尝试搭配成套。

  • 价格: 一套 ₩30,000~80,000
  • 推荐季节: 春·秋

优势3 — 秋冬外套 (牛仔夹克·军装夹克·大衣)

广藏二手商店街 (Guje Sangga / 구제상가) 真正的优势在于秋冬外套。从日本·美国·欧洲进口的批发外套，其策展水平高于东庙 (Dongmyo / 동묘)。

  • 牛仔夹克: ₩15,000~40,000
  • 军装夹克 (Yasung / 야상，M-65款式等): ₩30,000~60,000
  • 大衣 (羊毛·羊绒混纺): ₩50,000~150,000
  • 名牌大衣 (Burberry, Maxmara等): ₩100,000~500,000

优势4 — 名牌复古店铺 (Burberry, YSL, Aquascutum等)

广藏2楼深处隐藏着一些名牌复古专营店。定位与东庙 (Dongmyo / 동묘) 的Salon de Bong (살롱드봉) 相似，但店铺数量更多。

  • 价格: ₩50,000~200,000 (一件品相良好的名牌大衣)
  • 小贴士: 说一句“老板，有奢侈品吗？ (Sajangnim, myeongpum isseoyo? / 사장님 명품 있어요?)”，很多时候老板会拿出内部保管的商品。

淘宝6步 — 与东庙的不同之处

1步 — 选择时间

  • 平日上午10~12点: KeyChinGu 推荐 #1。新品上架后 + 人流稀少 + 店员也更亲切。可以从容地确认尺码和品相。
  • 平日下午2~4点: 1楼美食人潮会影响到2楼。虽然可以淘宝，但狭窄的通道会让人感到拥挤。
  • 周末: 1楼美食排队 + 2楼二手人潮同时爆发。不建议前往。
  • 周日: 50%以上店铺休息。请勿前往。

2步 — 8号出口 → 进入2楼

  • 钟路5街站 (Jongno 5-ga Yeok / 종로5가역) 8号出口 → 直行约100米 → 广藏市场 (Gwangjang Sijang / 광장시장) 西侧入口 (韩服 (Hanbok / 한복)·被褥街)
  • 在入口处询问“二手商店街 (Guje Sangga / 구제상가) 在哪里？ (Guje sangga eodieyo? / 구제상가 어디예요?)”即可获得指引。
  • 经过“相遇广场 (Mannam-ui Gwangjang / 만남의 광장)”胡同 (Golmok / 골목) → 建筑2楼楼梯。

3步 — 逛一圈店铺 (了解行情)

第一次去不要急着买，先把2楼整体逛一圈，了解一下价格行情。大约需要30分钟。花纹连衣裙 (Pattern Wonpiseu / 패턴 원피스) 的平均价格在₩10,000~40,000之间。

4步 — 进入店铺 (区分二手与无品牌新品)

广藏2楼的核心注意事项：并非所有衣服都是复古商品。这里有两种类型混杂。

种类 特点 价格
进口二手 (Guje / 구제) 真正的二手复古。从日本·欧洲·美国进口 ₩10,000~200,000
无品牌新品 (Bose / 보세) 从东大门 (Dongdaemun / 동대문) 批发市场进货的新品。设计复古但全新 ₩10,000~50,000
假冒名牌 Burberry·LV等伪造标签 冒充正价 ₩50,000~200,000

识别小贴士:

  • 查看标签: 如果是韩文标签，可能是无品牌新品 (Bose / 보세)；如果是日文·英文·意大利文标签，进口二手 (Guje / 구제) 的可能性较高。
  • 衣服状况: 细微的使用痕迹 (领口标签略有磨损、纽扣痕迹) 是真二手。如果看起来太新，可能是无品牌新品 (Bose / 보세)。
  • 如有疑问，直接询问“是二手还是新品？ (Guje yeyo, boseyeyo? / 구제예요 보세예요?)” — 诚实的店主会如实回答。

5步 — 议价 + 支付

  • 广藏2楼店铺明码标价 (Jeongchalje / 정찰제) 较强。议价空间比东庙 (Dongmyo / 동묘) 小 (10~20%)。
  • 捆绑购买 (2~3件以上) 时可协商折扣。
  • 支持刷卡的店铺比例高于东庙 (Dongmyo / 동묘) — 大约70%。
  • 但小额 (₩10,000以下) 建议使用现金 — 减轻店铺负担。

6步 — 1楼美食区午餐

淘宝结束后，下到1楼东侧，以广藏标志性美食收尾。淘宝+美食一站式路线是广藏最大的优势。

1楼广藏美食5选 — 淘宝后的午餐

广藏市场 (Gwangjang Sijang / 광장시장) 的美食内容有单独的指南 ([#15 街头美食圣地](15_seoul_street_food_guide.md))，这里只简短介绍淘宝后最近的5种选择。

1. 绿豆饼 (Nokdu Bindaetteok / 녹두빈대떡)

  • 位置: 1楼美食胡同 (Meokja Golmok / 먹자골목) 入口 (相遇广场 (Mannam-ui Gwangjang / 만남의 광장) 旁边)
  • 价格: 1张 ₩6,000~8,000
  • 菜单: 绿豆饼 (Nokdu Bindaetteok / 녹두빈대떡)、肉饼 (Gogi Bindaetteok / 고기빈대떡)、泡菜饼 (Kimchi Bindaetteok / 김치빈대떡)

2. 麻药紫菜包饭 (Mayak Gimbap / 마약김밥) (母女紫菜包饭 (Monyeo Gimbap / 모녀김밥)、广藏紫菜包饭 (Gwangjang Gimbap / 광장김밥) 等)

  • 位置: 美食胡同 (Meokja Golmok / 먹자골목) 中央
  • 价格: 8个 ₩5,000
  • 特点: 迷你紫菜包饭 + 黄萝卜·胡萝卜。外国游客人气第一。

3. 宴会面 (Janchi Guksu / 잔치국수) 无限续碗 ₩2,000

  • 位置: 美食胡同 (Meokja Golmok / 먹자골목) 尽头
  • 价格与东庙 (Dongmyo / 동묘) 相似。广藏美食胡同 (Meokja Golmok / 먹자골목) 内也有相同的店铺。

4. 生拌牛肉 (Yukhoe / 육회) (姐妹家 (Jamaejip / 자매집)、富村生拌牛肉 (Buchon Yukhoe / 부촌육회) 等)

  • 位置: 广藏美食胡同 (Meokja Golmok / 먹자골mok) 内部
  • 价格: 1人份 ₩15,000 (~$11 / ~80 RMB / ~1,600 JPY) ~25,000
  • 特点: 韩国代表性生拌牛肉 (Yukhoe / 육회) 的发源地。外国游客喜好两极分化。

5. 糖饼 (Hotteok / 호떡)·麻花 (Kkwabaegi / 꽈배기)·甜甜圈 (Donut / 도넛) (甜点)

  • 位置: 美食胡同 (Meokja Golmok / 먹자골목) 出口处
  • 价格: 1个 ₩1,500~3,000

广藏 vs 东庙 — 哪个更适合我？

比较轴 广藏市场二手商店街 (Gwangjang Sijang Guje Sangga / 광장시장 구제상가) 东庙二手市场 (Dongmyo Guje Sijang / 동묘 구제시장)
氛围 店铺型 (室内2楼) 摊位+店铺混合 (户外胡同 (Golmok / 골목))
淘宝难度 ★★ (衣服整齐) ★★★★ (衣服堆)
价格范围 ₩5,000~200,000 ₩1,000~150,000
商品优势 花纹连衣裙、秋冬外套、名牌大衣 牛仔、街头服饰、夹克
美食便利性 1楼即达 (广藏美食胡同 (Meokja Golmok / 먹자골목)) 市场内老字号 (Nopo / 노포) (光州食堂 (Gwangju Sikdang / 광주식당) 等)
外国游客友好度 中等 (借美食人潮之便) 较低 (以韩国常客为主)
停留时间 2~3小时 4~8小时 (汗蒸房 (Jjimjilbang / 찜질방)·户外摊位 (Yajang / 야장) 组合)
周末拥挤 非常高 高
推荐对象 复古入门者、主打女装、美食+购物同时进行 复古狂热者、以淘宝体验本身为目的

KeyChinGu 结论:

  • 复古入门 + 女装 + 美食一站式 → 广藏2楼
  • 本格淘宝 + 性价比 + 组合路线 (汗蒸房 (Jjimjilbang / 찜질방)·户外摊位 (Yajang / 야장)) → 东庙 (Dongmyo / 동묘)
  • 时间充裕的话两者都去 — 广藏上午 + 东庙下午 (地铁1号线两站，可步行)

外国游客常见问题

Q1. 会说英语吗？

1楼美食胡同 (Meokja Golmok / 먹자골목) 的老板很多会说英语·日语·中文 (因为外国顾客多)。2楼二手商店街 (Guje Sangga / 구제상가) 几乎只说韩语。尺码·价格 정도可以用数字沟通。

Q2. 周日可以去吗？

不推荐。1楼美食胡同 (Meokja Golmok / 먹자골목) 营业，但2楼二手店铺50%以上休息。如果目的是淘宝，请选择平日或周六。

Q3. 如果真的分不清是无品牌新品还是二手怎么办？

直接问老板 + 再次确认标签 + 如果看起来太新就怀疑。在₩30,000以上的店铺，如果怀疑，建议换一家店。

Q4. 可以买假冒名牌吗？

在韩国购买假冒商品本身是合法的，但带回本国时，海关有可能会没收 (各国规定不同)。购买名牌标签商品请谨慎。

Q5. 可以试穿吗？

有些店铺内有临时试穿空间，有些则可以在外面套穿。期望值与东庙 (Dongmyo / 동묘) 相似 — 没有镜子的店铺更多。

Q6. 可以和东庙 (Dongmyo / 동묘) 同一天去吗？

可以。广藏上午10点~12点淘宝 → 广藏1楼午餐 → 地铁1号线2站 东庙前站 (Dongmyoap Yeok / 동묘앞역) → 东庙 (Dongmyo / 동묘) 下午淘宝 是很受欢迎的复古全天路线。

季节性注意事项

春季 (3~5月)

  • 花纹连衣裙 (Pattern Wonpiseu / 패턴 원피스) 新品上架季节 — 推荐
  • 1楼美食人潮也开始增多

夏季 (6~8月)

  • 2楼部分区域有空调。部分店铺会比较热。
  • 以美食为主的季节，而非淘宝 (Digging / 디깅)。
  • 日本·大中华区游客比例最高。

秋季 (9~11月)

  • 广藏二手商店街 (Guje Sangga / 구제상가) 最佳季节 — 粗花呢、大衣、军装夹克 (Yasung / 야상) 新品上架。
  • 10月平日上午是淘宝 (Digging / 디깅) 黄金时间。

冬季 (12~2月)

  • 大衣·羽绒服淘宝 (Digging / 디깅) 季节。价格比夏季贵30~50%。
  • 1楼美食胡同 (Meokja Golmok / 먹자골목) 依然座无虚席。
