首尔夜宵9家 — 营业到晚上10点半以后的辣炒年糕·小明太鱼干·整鸡锅·土豆排骨汤·五花肉

副标题: 乙支路的小明太鱼干啤酒屋两家、东大门的整鸡锅、新堂洞的24小时辣炒年糕、药水的金猪食堂，共乙支路·东大门·新堂·药水一带5家，加上龙山的醒酒汤、城北的土豆排骨汤、教大的五花肉、付岩洞的炸鸡4家。只选Kakao地图上店主登记的工作日打烊时间为22:30或更晚的店。打烊时间从22:30到05:00，其中有一家是24小时营业。有些店周日提早打烊，另外标出。小吃店整体见#471，烤肉店整体见#479。

🎯 适合这样的人

适合晚上行程结束得晚、过了晚上10点还在找饭吃的游客，以及想在住处附近喝杯啤酒配下酒菜的人。选择标准只有一个。只留下Kakao地图 (Kakao Map / 카카오맵) 上店主登记的工作日打烊时间为22:30或更晚的店。有名的牛骨汤 (Gomtang / 곰탕)·冷面 (Naengmyeon / 냉면)·参鸡汤 (Samgyetang / 삼계탕) 店我们也列入过候选，但因为16:00~22:00就打烊，所以去掉了。

⚠ 标注原则: 营业时间·休息日·菜单价格是店主登记在Kakao地图 (Kakao Map / 카카오맵) 上的值(2026-11-24确认)。价格只标了每个菜单登记日期在2年以内的，比这更早的菜单标为"以Kakao地图当日确认为准"。饮食提示只写菜名·店主说明上能读出来的内容。食材·过敏原点单前向店员确认。附近的站是Kakao地图导航上显示的站·出口·距离。

① 乙支路·东大门·新堂·药水 — 5家

乙支路三街站 (Euljiro-samga / 을지로3가역) 和新堂站 (Sindang / 신당역) 由2号线相连。东大门的整鸡锅店要从东大门站 (Dongdaemun / 동대문역)(1·4号线)步行，金猪食堂要从药水站 (Yaksu / 약수역)(3·6号线)步行，所以每一段都需要换乘。从小明太鱼干啤酒屋开始，再转到整鸡锅、辣炒年糕 (Tteokbokki / 떡볶이)，这个顺序最不勉强。

啤酒屋 (Wonjo Manseon Hof Nogari Chain Main / 원조만선호프 노가리체인본점)

乙支路小明太鱼干巷 (Nogari-golmok / 노가리골목) 里的啤酒屋 (Hof / 호프)。每天12:00~05:00营业，除了24小时营业的店，是这一篇里最晚打烊的。登记价(2025-10-30)是小明太鱼干 (Nogari / 노가리)₩2,000，海鲜拉面 (Haemul-ramyeon / 해물라면)₩13,000，汤年糕 (Gukmul-tteokbokki / 국물떡볶이)₩13,000，炸鸡胗 (Dakttongjip-twigim / 닭똥집튀김)₩15,000，半干鱿鱼 (Bangeonjo-ojingeo / 반건조오징어)₩16,000。炸鸡菜单没有登记价格。地址是中区 (Euljiro 13-gil 19 / 을지로13길 19) 1层2号，距离乙支路三街站 (Euljiro-samga / 을지로3가역)(2·3号线)3号出口150m。巷子里还有叫"啤酒屋 (Wonjo Manseon Hof / 원조만선호프 2)"·"啤酒屋 (Manseon Hof / 만선호프)"·"啤酒屋 (Manseon / 만선3)"的店，所以按地址找。

  • 饮食提示: 小明太鱼干是晒干的小明太鱼(鱼类)。鱿鱼·海鲜拉面是海鲜，炸鸡胗 (Dakttongjip / 닭똥집) 是鸡胗。手工猪排 (Sujae-donkkaseu / 수제돈까스) 是猪肉。因为是啤酒屋，以酒类为主。登记菜单里没有能读成素食的。

啤酒屋 (Eulji OB Bear / 을지OB베어)

位于乙支路三街站9号出口正前方的啤酒屋，Kakao地图标签上有老店 (Nopo / 노포)。周一至周六15:00~23:30，周日15:00~22:00。登记价是原味小明太鱼干&黄太鱼干 (Orijinal Nogari&Hwangtae / 오리지널 노가리&황태)₩6,000(2026-07-22)，马面鱼干 (Jwipo / 쥐포)₩10,000，蚕蛹 (Beondegi / 번데기)₩11,000，无骨炸鸡 (Sungol Fried Chicken / 순살 후라이드 치킨)₩16,000，无骨甜辣炸鸡 (Sungol Yangnyeom Chicken / 순살 양념치킨)₩17,000(2026-11-04)，芝士火鸡 (Chijeu-bulgak / 치즈불닭)₩23,000。地址是中区 (Chungmu-ro 49-2 Dongju Building / 충무로 49-2 동주빌딩) 1层，距离乙支路三街站9号出口56m。

  • 饮食提示: 小明太鱼干·黄太鱼干·马面鱼干是鱼干类下酒菜。蚕蛹 (Beondegi / 번데기) 是蚕的蛹。约翰维尔香肠 (Johnsonville Sausage / 존슨빌 소시지) 是猪肉。炸鸡是鸡肉，面衣通常用面粉。以酒类为主。

整鸡锅店 (Jinokhwa Halmae Wonjo Dakhanmari Main / 진옥화할매원조닭한마리 본점)

东大门整鸡锅巷 (Dakhanmari-golmok / 닭한마리 골목) 里的餐厅。每天10:30~01:00，全年无休。登记菜单只有整鸡锅 (Dakhanmari / 닭한마리)₩33,000(2025-11-28)一个。地址是钟路区 (Jong-ro 40ga-gil 18 / 종로40가길 18) 1~3层，距离东大门站 (Dongdaemun / 동대문역)(1·4号线)10号出口332m。附近有好几家名字相近的整鸡锅店，所以按地址找。

  • 饮食提示: 这是把一整只鸡连锅一起煮着吃的料理，以鸡肉为主。很多店可以加刀削面 (Kalguksu-sari / 칼국수 사리)，加的面是小麦面。加料·调料的价格Kakao地图上没有，点单时问一下。

辣炒年糕店 (I Love Sindang-dong / 아이러브신당동)

新堂洞辣炒年糕巷 (Sindang-dong Tteokbokki-golmok / 신당동 떡볶이 골목) 里的现煮辣炒年糕 (Jeuksok-tteokbokki / 즉석 떡볶이) 店。登记为24小时营业。登记价是新堂洞辣炒年糕 (Sindang-dong Tteokbokki / 신당동 떡볶이)3人份₩23,000·4人份₩28,000，芝士·海鲜·眼泪 (Nunmul / 눈물)·I Love辣炒年糕 (I Love Tteokbokki / 아이러브 떡볶이)(中)₩27,000·(大)₩32,000，炸酱辣炒年糕 (Jjajang-tteokbokki / 짜장 떡볶이)(中，微辣)₩23,000(2025-08登记)。2人份和(小)份登记超过2年，以Kakao地图当日确认为准。地址是中区 (Toegye-ro 76-gil 50 Seonghwan Building / 퇴계로76길 50 성환빌딩) 1层，距离新堂站 (Sindang / 신당역)(2·6号线)8号出口259m。

  • 饮食提示: 是辣椒酱调味的辣炒年糕，所以辣。菜名里带"眼泪 (Nunmul / 눈물)"的读起来更辣。海鲜辣炒年糕含海鲜，芝士辣炒年糕含乳制品。现煮辣炒年糕里常放鱼饼 (Eomuk / 어묵，鱼类加工品)，吃素的话点单时问一下。炸酱辣炒年糕要确认食材。

烤肉店 (Geumdwaeji Sikdang / 금돼지식당)

药水站一带的烤猪肉店。Kakao地图标签上有"首尔美食100选 (Seoul Misik 100-seon / 서울미식100선)"。每天11:30~23:00，但按店主说明，开到23:00的是1层，2·3层22:00打烊。登记价是雪花颈肉 (Nunkkot-moksal / 눈꽃목살)150g₩23,000，背部颈肉 (Deung-moksal / 등목살)150g₩24,000，猪颈肉 (Hangjeongsal / 항정살)120g₩25,000，整猪泡菜汤 (Tongdwaeji Kimchi-jjigae / 통돼지김치찌개)(小)₩8,000，三得利high ball (Suntory Highball / 산토리하이볼)₩10,000(2026登记)。本五花肉 (Bon-samgyeopsal / 본삼겹) 登记超过2年，以Kakao地图当日确认为准。地址是中区 (Dasan-ro 149 / 다산로 149)，距离药水站 (Yaksu / 약수역)(3·6号线)2号出口237m。

  • 饮食提示: 大部分是猪肉。不吃猪肉的话，有韩牛横隔膜 (Hanu Anchangsal / 한우 안창살)120g₩65,000，韩牛生拌牛肉 (Hanu Yukhoe / 한우육회)120g₩36,000。生拌牛肉是生牛肉。登记了好几种high ball等酒类菜单。

② 其他街区 — 4家

街区彼此分得很开，选离住处近的一家比较好。

醒酒汤店 (Yongmun Haejangguk / 용문해장국)

龙山龙门洞的醒酒汤 (Haejangguk / 해장국) 店。Kakao地图标签上有老店 (Nopo / 노포)·早餐 (Achim-sikssa / 아침식사)。周一至周六06:00~23:00，周日06:00~15:00。登记价是锅巴饭 (Gakbap / 깍밥)₩9,000，托盘面 (Jaengban-yungmyeon / 쟁반육면)₩15,000，西葫芦煎饼 (Hobak-myeonjeon / 호박면전)₩15,000，火锅 (Jeongol / 전골)₩36,000，白切肉 (Suyuk / 수육)₩42,000，辣炖猪骨 (Maeun Ppyeo-jjim / 매운뼈찜)₩42,000(2026登记)。一碗醒酒汤的价格没有登记。地址是龙山区 (Hyochangwon-ro 110 / 효창원로 110)，距离孝昌公园前站 (Hyochang Park / 효창공원앞역)(6号线·京义中央线)3号出口173m。

  • 饮食提示: 猪骨醒酒汤 (Ppyeo-haejangguk / 뼈해장국)·炖猪骨通常用猪脊骨熬。水芹韩牛生拌牛肉 (Minari Hanu Yukhoe / 미나리한우육회)(₩20,000)是生牛肉。汤底食材点单时确认。

土豆排骨汤店 (Taejo Gamjaguk / 태조감자국)

诚信女大入口站 (Sungshin Women's Univ. / 성신여대입구역) 一带的土豆排骨汤 (Gamjatang / 감자탕) 店。Kakao地图标签上有百年老店 (Baeknyeon Gage / 백년가게)·老店 (Nopo / 노포)。每天10:10~23:00。登记价(2025-11)是传统款 (Jeontong Johda / 전통 좋~다)₩25,000·最棒 (Choegoda / 최고다)₩30,000·无尽 (Mujinjang / 무진장)₩35,000，干菜·老泡菜·豆渣土豆排骨汤从Johda (좋~다)₩27,000起，炖猪骨·烤猪骨从Johda (좋~다)₩29,000起。"Johda·Choegoda·Mujinjang (좋~다·최고다·무진장)"是价格依次上升的三个档次。地址是城北区 (Bomun-ro 34-gil 43 Sehak Building / 보문로34길 43 세학빌딩) 1层，距离诚信女大入口站 (Sungshin Women's Univ. / 성신여대입구역)(4号线·牛耳新设线)2号出口315m。

  • 饮食提示: 每个菜单都写着"国产脊骨 (Gukssan Deungppyeo / 국산등뼈)"。土豆排骨汤是猪脊骨料理，不吃猪肉就不合适。豆渣土豆排骨汤 (Kongbiji Gamjatang / 콩비지 감자탕) 里放了大豆。

五花肉店 (Gyodae Icheungjip Gyodae Main / 교대이층집 교대본점)

教大站 (Gyodae / 교대역) 前的五花肉 (Samgyeopsal / 삼겹살) 店。每天12:00~00:30。价格登记在2年以内的菜单只有花五花肉 (Kkot-samgyeop / 꽃삼겹)150g₩18,000(国产，2026-06-26)一个。生五花肉·猪颈肉·汤锅·韩牛菜单登记超过2年，以Kakao地图当日确认为准。地址是瑞草区 (Seochodae-ro 50-gil 24 Cheonghwa Building / 서초대로50길 24 청화빌딩) 2层，距离教大站 (Gyodae / 교대역)(2·3号线)14号出口124m。Kakao地图标签上有免开瓶费 (Corkage-free / 콜키지프리)。

  • 饮食提示: 主菜单是猪肉。韩牛牛腩 (Hanu Chadolbagi / 한우 차돌박이)·西冷 (Chaekkeut-deungsim / 채끝등심) 也在菜单上，但价格要当日确认。有大酱汤 (Doenjang-jjigae / 된장찌개)·泡菜汤 (Kimchi-jjigae / 김치찌개) 这类正餐菜单。

炸鸡店 (Gyeyeolsa / 계열사)

付岩洞的炸鸡店。周二至周六12:00~22:30，周日·公休日12:00~22:00，周一休息。登记价是炸鸡 (Fried Chicken / 후라이드치킨)₩24,000(2026-04-04)，微辣无骨鸡爪 (Maekom Ppyeo-eomneun Dakbal / 매콤 뼈없는 닭발)₩18,000(2025-04-25)。辣炖鸡 (Dakdoritang / 닭도리탕)·海螺拌面 (Golbaengi-somyeon / 골뱅이소면) 等其余登记超过2年，以Kakao地图当日确认为准。地址是钟路区 (Baekseok-dong-gil 7 / 백석동길 7) 1层。Kakao地图导航上没有附近地铁站的信息，所以坐公交或打车去。同一条路61号有同名的另一个地方，所以按7号找。

  • 饮食提示: 炸鸡是鸡肉，面衣通常用面粉。鱼饼汤 (Eomuk-tang / 어묵탕)·秋刀鱼泡菜汤 (Kkongchi Kimchi-jjigae / 꽁치김치찌개)·小鱿鱼干 (Hanchi / 한치)·干明太鱼 (Meoktae / 먹태)·海螺 (Golbaengi / 골뱅이)·鲱鱼干 (Gwamegi / 과메기) 是海鲜，蚕蛹汤 (Beondegi-tang / 번데기탕) 是蚕蛹。登记菜单里没有能读成素食的。

🗺 动线 — 两条路线

A. 乙支路 → 东大门 → 新堂 (傍晚~深夜)

  1. 18:00左右 在啤酒屋 (Eulji OB Bear / 을지OB베어) 吃小明太鱼干喝啤酒(15:00起营业)
  2. 20:00左右 转到整鸡锅店 (Jinokhwa Halmae Wonjo Dakhanmari / 진옥화할매원조닭한마리)(营业到01:00)。在东大门站一带
  3. 23:00以后 新堂站的辣炒年糕店 (I Love Sindang-dong / 아이러브신당동)(24小时)。如果更晚还想喝啤酒，就回到乙支路的啤酒屋 (Wonjo Manseon Hof / 원조만선호프)(营业到05:00)

B. 药水 → 新堂 (肉 + 辣炒年糕)

  1. 21:00前 进烤肉店 (Geumdwaeji Sikdang / 금돼지식당)。开到23:00的只有1层
  2. 饭后 转到新堂站的辣炒年糕店 (I Love Sindang-dong / 아이러브신당동)

店与店之间所需时间，当天用Kakao地图导航确认。

⚠ 3个常见失误

  1. 周日晚上去醒酒汤店 (Yongmun Haejangguk / 용문해장국) — 周日15:00就打烊。啤酒屋 (Eulji OB Bear / 을지OB베어) 周日也是22:00打烊。
  2. 周一安排炸鸡店 (Gyeyeolsa / 계열사) — 周一休息。要输入地址，避免导航定位到同名的另一个地方(白石洞路61号)。
  3. 22点以后才到烤肉店 (Geumdwaeji Sikdang / 금돼지식당) 被带到2层 — 2·3层22:00打烊。去得晚的话只剩1层座位，所以早点进去。

⚙ 3个常见问题

  1. 凌晨1点以后能去哪里？ — 按登记时间，有两家，辣炒年糕店 (I Love Sindang-dong / 아이러브신당동)(24小时)和啤酒屋 (Wonjo Manseon Hof / 원조만선호프)(营业到05:00)。整鸡锅店 (Jinokhwa Halmae Wonjo Dakhanmari / 진옥화할매원조닭한마리) 01:00打烊。
  2. 不吃猪肉怎么办？ — 选整鸡锅 (Jinokhwa / 진옥화)、炸鸡 (Gyeyeolsa·Eulji OB Bear / 계열사·을지OB베어)、小明太鱼干下酒菜(乙支路两家)、辣炒年糕 (I Love Sindang-dong / 아이러브신당동)。土豆排骨汤·醒酒汤·五花肉店以猪肉为主。
  3. 一个人去可以吗？ — 辣炒年糕从3人份起有登记价，2人份当日确认。土豆排骨汤·整鸡锅·火锅是以锅为单位。一个人的话，进店前先问能不能点小明太鱼干啤酒屋或1人份的肉。
