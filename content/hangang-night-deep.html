왜 지금 한강 야간인가 — 외국인 1순위 무료 야경 hub

한강은 서울 도심을 가로지르는 한국 #1 강(495km 중 서울 41km)으로 11개 한강공원 + 24시간 무료 야간 접근 + 글로벌 핫플 한강버스/서울달까지 갖춘 외국인 야간 매니아 1순위 hub다. 특히 반포 달빛무지개분수 (한국 #1 분수·완전 무료)·잠수교 뚜벅뚜벅 축제 (4-6월 매주 일·차 없는 보행)·한강야경투어 (반포달빛길·여의별빛길·무료)·한강버스 외국인 카드 결제 35% = 글로벌 인지도 폭발.

종로 3가 포차 (#585 야간 hub)와 차별화 명확 = "무료·야외·자연·공원·로맨틱·치맥 at 한강" cluster. 외국인 데이트·MZ·가족·솔로 모두 fit. 24h 접근 가능 + 야간 매니아 1순위.

본 매트릭스는 메인 한강공원 3선 + 명소·랜드마크 3선 + 활동·체험 3선 + 인근 cross 3선 = 12선 4축. 반포·여의도·뚝섬 메인 cluster + 잠실·망원 cross.

12선 4축 매트릭스 — 외국인 풀세트

  • 2026 축제: 잠수교 뚜벅뚜벅 (4/26~6/14 매주 일) + 한강야경투어 (6/6까지 매주 금·토)

#3. 뚝섬한강공원 — 서울숲 cross + 자전거 매니아

  • 외국인 tip: 완전 무료 + 잔디밭 자유 좌석 + 시즌 한정 (4-10월). 봄·가을 매니아 1순위. 19:30 1회차 권장.

시즌 5축 — 월별 best 매니아 plan

외국인 매니아 5 tip

Tip 1. 무료 = 한강 매니아 최대 매력

  • 한강공원·잠수교·달빛무지개분수·자전거 도로 = 모두 무료
  • 외국인 1순위 코스 (반포 + 분수 + 잠수교) = 0원
  • 추가 비용: 치맥 (배달 앱) + 한강버스 + 따릉이

Tip 2. 외국인 카드 인프라 (2026년 fit)

  • 한강버스: 외국인 카드 35% 결제 OK
  • 배달 앱: Yogiyo·배민·쿠팡이츠 모두 외국인 카드 OK (치맥 #7)
  • 따릉이: 외국인 카드·앱 OK (1시간 1,000원)
  • 편의점: GS25·CU·세븐일레븐 모두 카드 OK

Tip 3. 달빛무지개분수 회차 전략

  • 시즌: 4-10월 (11-3월 운영 중단)
  • 회차: 평일 12·19:30·20·20:30·21시 / 주말 추가
  • 권장: 19:30 1회차 (일몰 + 첫 분수·인파 적음)
  • 자리: 잠수교 양쪽 잔디밭 자유 좌석 (1시간 전 도착 권장)

Tip 4. 한강버스 외국인 ride 전략

  • 선착장: 여의도 #2 (외국인 #1) > 뚝섬 #3 > 반포 #1 > 잠실
  • 코스: 여의도 ↔ 뚝섬 (약 1시간) — 외국인 매니아 코스
  • 시간: 야간 cruise 19-21시 매니아 #1 (석양 + 야경)
  • 결제: 외국인 카드 OK (영문 가이드)
