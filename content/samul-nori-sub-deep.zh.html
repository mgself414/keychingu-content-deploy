📍 安城 — 男寺党剧场·常设演出Gombaengi-teotda·Baudeogi之墓·Baudeogi庆典

安城男寺党Baudeogi风物团常设演出Gombaengi-teotda (Gombaengi-teotda / 곰뱅이텄다)(安城市 (Bogae-myeon Namsadang-ro 198-2 / 보개면 남사당로 198-2) 安城男寺党剧场，☎ 031-678-2518)，是安城市自2003年起持续举办的常设演出。安城市立男寺党Baudeogi风物团 (Anseong Sirip Namsadang Baudeogi Pungmuldan / 안성시립 남사당 바우덕이 풍물단) 2026年的演出以“集市的兴致，震动景福宫 (Gyeongbokgung / 경복궁)！”为副题，以现代感重新编排了男寺党游戏 (Namsadang Nori / 남사당놀이) 六场。

  • 演出时间:2026年4月4日~11月29日，每周六·周日 14:00。约90分钟。观看年龄:全年龄。
  • 费用:成人12,000韩元，青少年6,000韩元，儿童3,000韩元。安城市民·敬老优惠50%。
  • 六场 (Madang / 마당):风物 (Pungmul / 풍물)(太平箫 (Taepyeongso / 태평소)·小锣·锣·长鼓·鼓·小鼓 (Sogo / 소고))，Eoreum (어름)(在高3m、长10m的绳上走绳并配以诙谐对白 (Jaedam / 재담))，Beona (버나)(用棍子·烟袋转动筛圈或碗的技艺)，Salpan (살판)(用身体表演的杂技)，Deotboegi (덧뵈기)(假面剧)，Deolmi (덜미)(传统木偶戏)。

安城男寺党剧场 (Anseong Namsadang Gongyeongjang / 안성 남사당 공연장)(同一地址，☎ 031-678-2518)，是为演出男寺党游戏等传统游戏而建的圆形剧场。观众席有700席以上，设有20m圆形舞台和13m升降式舞台。户外剧场有1,000席。

  • 开放时间:周末(4~11月) 14:00~16:00。休息日:平日。
  • 费用:成人12,000韩元，青少年6,000韩元，儿童3,000韩元。基础生活保障对象、残疾人、国家有功者、单亲家庭、敬老优待者(满65岁以上)、安城市民等优惠50%。
  • 宠物:不可。

安城男寺党Baudeogi之墓 (Anseong Namsadang Baudeogi Myo / 안성 남사당 바우덕이 묘)(安城市 (Seoun-myeon Seongjin-ro 1279-76 / 서운면 성진로 1279-76)，☎ 安城市文化遗产负责部门 031-678-5889)，安葬着男寺党Baudeogi (바우덕이)(1848~1870)。她的本名是Kim Am-deok (김암덕)，朝鲜末期在Seoun-myeon (서운면) Cheongnyong-ri (청룡리) Buldanggol (불당골) 学习念佛、小鼓舞、走绳等技艺而闻名。据观光公社介绍，高宗 (Gojong / 고종) 2年(1865)兴宣大院君 (Heungseon Daewongun / 흥선대원군) 增修景福宫 (Gyeongbokgung / 경복궁) 时，召来安城男寺党班子表演游戏，因慰劳工匠们有功，获授相当于正三品的Ok-gwanja (옥관자)。安城男寺党风物游戏于1997年9月30日被指定为京畿道非物质遗产第21号，安城的地方人士找到被遗弃的墓并加以整修，于1990年立了墓碑。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。

2026安城Matchum男寺党Baudeogi庆典 (2026 Anseongmatchum Namsadang Baudeogi Chukje / 2026 안성맞춤 남사당 바우덕이축제)(安城市 (Bogae-myeon Namsadang-ro 198 / 보개면 남사당로 198)，☎ 031-678-5414)，是以联合国教科文组织人类非物质文化遗产男寺党游戏为主题的庆典。据观光公社介绍，Baudeogi (바우덕이) 是朝鲜最早的女Kkokdusoe (꼭두쇠)。2026年于10月2~5日在安城Matchum乐园 (Anseongmatchum Land / 안성맞춤랜드) 和安城川 (Anseongcheon / 안성천) 一带举办，时间为10:00~21:00，费用免费。

  • 活动:举办了男寺党游戏·传统婚礼演出、安城古集市 (Anseong Yetjangteo / 안성옛장터)、Baudeogi主题公园体验、Baudeogi灯光节、THE NEXT Baudeogi竞演大会 (THE NEXT Baudeogi Gyeongyeon Daehoe / THE NEXT 바우덕이 경연대회) 等。

📍 全罗道农乐传授馆 — 任实Pilbong·灵光Udo·谷城Jukdong·和顺Hancheon

Pilbong农乐传授馆 (Pilbong Nongak Jeonsugwan / 필봉농악전수관)(任实郡 (Gangjin-myeon Gangun-ro 272 / 강진면 강운로 272)，☎ 063-643-1902/2901)，是建在Pilbong农乐 (Pilbong Nongak / 필봉농악) 发源地的传授馆。设有展示Pilbong农乐历史的风物展示馆 (Pungmul Jeonsigwan / 풍물전시관)，以及体验传统文化的Pilbong韩屋住宿 (Pilbong Hanok Stay / 필봉 한옥스테이)。配备可容纳300余人的Pilbong室内剧场 (Pilbong Silnae Geukjang / 필봉 실내극장)、穹顶型演出场馆Gutsandae (굿산대)、韩屋庭院 (Hanok Madang / 한옥마당) 等演出设施和住宿设施。据观光公社介绍，每年有3万多人为学习、体验、观看Pilbong农乐而前往Pilbong文化村 (Pilbong Munhwachon / 필봉문화촌)。

  • 休息日:全年无休。停车:免费。
  • 体验费用:学习风物游戏·小鼓游戏 学生10,000韩元·成人11,000韩元，制作韩纸灯·Beona (버나) 学生17,000韩元·成人18,000韩元，学习乱打 (Nanta / 난타) 学生10,000韩元·成人11,000韩元，学习圆圈舞 (Ganggangsullae / 강강술래)·传统游戏一场 学生10,000韩元·成人11,000韩元。

Udo农乐传授馆 (Udo Nongak Jeonsugwan / 우도농악전수관)(灵光郡 (Yeonggwang-eup Mulmu-ro 1-gil 11 / 영광읍 물무로1길 11)，☎ Udo农乐保存会 061-351-2666)，是保存、传承非物质遗产Udo农乐 (Udo Nongak / 우도농악) 的地方。Udo农乐延续全罗道西南沿海地区灵光 (Yeonggwang / 영광)·高敞 (Gochang / 고창)·长城·咸平等地的Yeongmujang (영무장) 农乐传统。据观光公社介绍，农乐已被列入联合国教科文组织非物质文化遗产名录。传授馆运营骑着赛格威学习四物农乐的e移动出行四物农乐项目，并开展舞台演出和1人 Changmugeuk (창무극) 等活动。

  • 开放时间:08:30~17:30(周六 09:00~18:00)。休息日:周日。
  • 宠物:不可。

Jukdong农乐传授教育馆 (Jukdong Nongak Jeonsu Gyoyukgwan / 죽동농악전수교육관)(谷城郡 (Gokseong-eup Jukdong-gil 46-1 / 곡성읍 죽동길 46-1)，☎ 061-363-6000)，是教授和传承谷城Jukdong农乐 (Jukdong Nongak / 죽동농악) 的地方。谷城Jukdong农乐于2002年4月19日被指定为非物质文化遗产。2007年建成地上1层、2层建筑共2栋，农乐教育常年进行，并展示民俗游戏器具。有活动时，会在楼前的小型剧场表演Jukdong农乐。

  • 开放时间:全天开放。休息日:全年无休。
  • 费用:免费。

Hancheon农乐传授会馆 (Hancheon Nongak Jeonsu Hoegwan / 한천농악전수회관)(和顺郡 (Dongbok-myeon Gimsatgat-ro 720 / 동복면 김삿갓로 720)，☎ 061-370-1225)，是进行Hancheon农乐 (Hancheon Nongak / 한천농악) 传授教育和演出的地方。1996年建成的地上2层建筑，设有住宿处和练习室。Hancheon农乐在1964年全国民俗竞演大会上获得总统奖而广为人知，1979年被指定为非物质文化遗产。

  • 开放时间·休息日:视演出日程而定。
  • 费用:免费。

📍 高敞 — 高敞农乐Kkotdaerim庆典

第7届高敞农乐Kkotdaerim庆典 (Je-7-hoe Gochang Nongak Kkotdaerim Chukje / 제7회 고창농악 꽃대림축제)(高敞郡 (Seongsong-myeon Hyangsan 1-gil 106 / 성송면 향산1길 106) 高敞农乐传授馆，☎ 063-562-2044)，是传承全北特别自治道非物质遗产高敞农乐 (Gochang Nongak / 고창농악) 的Kkotdaerim-gut (꽃대림굿) 的演出艺术庆典。Kkotdaerim-gut (꽃대림굿) 是在农历七夕前后，村民们一起举行祭祀，消解这段时间的辛劳并祈求余下一年丰饶的共同体仪式。2026年于8月28~30日在高敞农乐传授馆一带举办，时间为11:00~23:30，费用免费。

  • 活动:举办了Kkotdaerim Dangsan-gut (꽃대림 당산굿)、高敞农乐Pungjang-gut (풍장굿)、Pan-gut (판굿)与Japsaek (잡색)、国家非物质遗产Baltal (발탈)、Gumi Mueul Nongak (구미무을농악)、韩日国际交流合作演出、跳蚤市场等。

⚠ 行前须知 3 点

  1. 安城常设演出只在周末举行 — Gombaengi-teotda (곰뱅이텄다) 为2026年4月4日~11月29日每周六·周日 14:00，剧场平日休息。
  2. 两个庆典的2026年日程已结束 — 高敞农乐Kkotdaerim庆典于8月28~30日举办，Baudeogi庆典于10月2~5日举办。
  3. 各传授馆的运营方式不同 — Jukdong农乐传授教育馆全天开放，Udo农乐传授馆周日休息，Hancheon农乐传授会馆视演出日程开放。
