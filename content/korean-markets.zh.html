⚠ 外国游客常犯的 3个错误

1. “只有广藏市场 (Gwangjang Sijang / 광장시장) = 韩国市场”: 广藏 (Gwangjang / 광장) 确实是外国游客 #1，但鹭梁津水产 (Noryangjin Susan / 노량진수산) (vlog #1)·东大门综合 (Dongdaemun Jonghap / 동대문 종합) (批发)·马场畜产 (Majang Chuksan / 마장축산) (肉类)·平和市场 (Pyeonghwa Sijang / 평화시장) (服装批发) 全套 = 韩国市场深度探索。

2. “批发市场 = 外国游客不能去”: 平和 (Pyeonghwa / 평화)·马场 (Majang / 마장)·可乐 (Garak / 가락)·东大门综合 (Dongdaemun Jonghap / 동대문 종합) 都对外国游客友好 + 可议价 + 批发价50~70% (比零售便宜30~50%)。凌晨拍卖 (Saebyeok Gyeongmae / 새벽 경매)·即时解体·市场餐厅均可。

3. “通仁 (Tongin / 통인)·望远 (Mangwon / 망원)·面牧 (Myeonmok / 면목) = 不知道”: 外国游客不太了解的隐藏宝藏 — 避开广藏 (Gwangjang / 광장) 人潮 + 传统本地人市场 (Tobagi Sijang / 토박이 시장) 第一。通仁 (Tongin / 통인) (通仁 (Tongin / 통인) 盒饭 (Dosirak / 도시락) ₩5,000 (~$3.7 / ~27 RMB / ~550 JPY))·望远 (Mangwon / 망원) (MZ)·面牧 (Myeonmok / 면목) ([#184 面牧佑林](184_myeonmok_urim_market.md) 本地人市场)。
