首尔居酒屋指南——烤串·下酒菜·正餐居酒屋6家(Waraku、Tenkai、Marimo、Urang、Grill Ajisai、美东食堂)(2026年10月官方数据)

副标题: Waraku (Waraku / 와라쿠) 18:00~01:00,周日休息(VisitSeoul) · Tenkai (Tenkai / 텐카이) 有40多种烤串,位于汉南洞 (Hannam-dong / 한남동) 君悦酒店LL层(VisitSeoul) · Marimo (Marimo / 마리모) 18:00~04:00(VisitSeoul) · 美东食堂 (Midong Sikdang / 미동식당) 须每人点一份酒(VisitSeoul) · 饮酒从满19岁那年的1月1日起(生活法令易查网) — 截至2026-10-21

ISSUE 03 · #487 · 2026-05-27

🎯 本指南的使用方法

炭火上的烤串滴着油冒起烟,小杯里清酒轻轻晃荡——Waraku (Waraku / 와라쿠) 被介绍为供应正宗串烧(Kushiyaki)的店(VisitSeoul)。本指南写给想在首尔去日式小酒馆(居酒屋) 的旅行者。分为三类:烤串、以下酒菜为主的店、也能吃正餐的店。店家只挑选了在首尔官方旅游网站VisitSeoul上被介绍为居酒屋、日式烤串店、小酒馆,且信息于2026年修订过的地方。这个行业营业变动频繁,未能确认的店没有收录。

旧版指南写了"汉南 (Hannam / 한남) = 韩国最大居酒屋街""梨泰院 (Itaewon / 이태원) 人均3~5万韩元、江南 (Gangnam / 강남) 10~30万韩元"之类的排名和价格。没有官方出处,已全部删除。这次确认的六家里,位于汉南洞 (Hannam-dong / 한남동) 的只有君悦酒店内的Tenkai (Tenkai / 텐카이)(VisitSeoul)。

🍢 烤串——2家

  • Waraku (Waraku / 와라쿠) — 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路4街13-7 (Apgujeong-ro 4-gil / 압구정로4길)。周一至周六18:00~01:00,周日休息。正宗日式串烧,招牌菜有葱肉串 (Negima / 네기마)、小肉 (Shouniku / 쇼우니꾸)、猪颈肉 (Dontoro / 돈도로)、牛舌 (Gyutan / 규단)。距新沙站 (Sinsa-yeok / 신사역) 6号出口721米。电话0507-1416-2295(VisitSeoul韩文版)
  • Tenkai (Tenkai / 텐카이) — 首尔龙山区 (Yongsan-gu / 용산구) 昭月路322号 (Sowol-ro / 소월로)(汉南洞 (Hannam-dong / 한남동),君悦酒店)LL层。周日至周四18:00~24:00,周五、周六18:00~01:00,节假日休息。用肉类、禽类、海鲜、蔬菜烤40多种串,桌子全部是榻榻米。清酒、烧酒、果酒。网站有韩语、英语、日语、汉语、俄语。电话02-799-8274(VisitSeoul韩文版)

🍶 以下酒菜为主——2家

  • Marimo (Marimo / 마리모) — 首尔江南区 (Gangnam-gu / 강남구) 岛山大路49街10-1 (Dosan-daero 49-gil / 도산대로49길)(新沙洞 (Sinsa-dong / 신사동))。周二至周日18:00~04:00,周一及节假日休息。专营豆腐料理的居酒屋。有用黑芝麻做的芝麻豆腐 (Goma Dubu / 고마두부)、加了芝士的麻糬豆腐 (Mochi Dubu / 모찌두부)(VisitSeoul英文版),还有饺子汤 (Gyoja-tang / 교자탕)、关东煮汤 (Odeng-tang / 오뎅탕)、鱼卵汤 (Al-tang / 알탕)、生鱼片拌饭 (Hoedeopbap / 회덮밥)。距狎鸥亭罗德奥站 (Apgujeong Rodeo-yeok / 압구정로데오역) 5号出口480米。电话02-545-5885(VisitSeoul韩文版)
  • Urang清潭店 (Urang Cheongdam-jeom / 우랑 청담점) — 首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路79街79号 (Apgujeong-ro 79-gil / 압구정로79길)(清潭洞 (Cheongdam-dong / 청담동)) JM大厦1层。每天11:00~24:00。点烤肉(Yakiniku)会端来小火炉,自己烤肉、蔬菜和饭团。Urang火锅 (Urang-nabe / 우랑나베)、松叶蟹涮锅、生鱼片。电话0507-1318-4010(VisitSeoul韩文版)

🍱 也能吃正餐的店——2家

  • Grill Ajisai (Grill Ajisai / 그릴아지사이) — 首尔江南区 (Gangnam-gu / 강남구) 德黑兰路13街8-10 (Teheran-ro 13-gil / 테헤란로13길)(东营大厦 (Dongyoung Building / 동영빌딩))。周一至周五11:30~14:00·17:30~23:00,周六、周日休息。日本主厨做日本本土风格的料理。午餐时炸猪排、寿喜烧、蛋包饭要排队,晚上配清酒。加油大叔套餐 (Ganbare Otosan SET / 간바레오또상SET)、白肉鱼 (Shiromi / 시로미)、猪肉涮锅沙拉 (Donshabu Salad / 돈샤브 샐러드)、海鲜盖饭 (Kaisendon / 가이센동)。价位1万韩元左右。距驿三站 (Yeoksam-yeok / 역삼역) 4号出口239米。电话02-565-7442(VisitSeoul韩文版)
  • 美东食堂 (Midong Sikdang / 미동식당) — 首尔西大门区 (Seodaemun-gu / 서대문구) 忠正路6街59号 (Chungjeong-ro 6-gil / 충정로6길) 西小门公寓 (Seosomun Apartment / 서소문아파트) 1层6号。工作日17:15~23:00,周六、周日休息。位于有50多年历史的住商混合公寓1层的小酒馆。按人数点单,厨房会用自己挑选的食材上主厨选配下酒菜。须每人点一份酒,从生啤到瓶装清酒都可以。有人在等位时用餐限2小时30分钟,最多4人。距西大门站 (Seodaemun-yeok / 서대문역) 7号出口293米。电话02-313-0958(VisitSeoul韩文版)

🥗 饮食

  • 素食:六家的官方页面都没有标注素食菜单。Marimo (Marimo / 마리모) 有豆腐料理,Tenkai (Tenkai / 텐카이) 有蔬菜串,但汤和酱汁的材料未能确认——点餐前先问(VisitSeoul)
  • 清真:VisitSeoul将梨泰院 (Itaewon / 이태원) 的Eid(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街15号 (Usadan-ro 10-gil / 우사단로10길),每天12:00~21:00)介绍为韩国伊斯兰教中央会(KMF)认定为清真的少数餐厅之一。认定可能变动,到访前请先确认。本指南中的居酒屋全部都卖酒
  • 过敏:像Urang (Urang / 우랑) 的松叶蟹涮锅、生鱼片,Marimo (Marimo / 마리모) 的鱼卵汤,海鲜菜品很多(VisitSeoul)。甲壳类、鱼类过敏请提前说明
  • 价位:官方公布的只有Grill Ajisai (Grill Ajisai / 그릴아지사이) 的"1万韩元左右"(VisitSeoul韩文版)。其余未公布价格——看菜单点餐
  • 展示卡请见#1300 饮食需求手册

🧰 居酒屋实用信息——年龄、独自用餐、预约、支付、点餐、交通

  • 年龄:韩国法律中的"青少年"是未满19岁的人,到了满19岁那年1月1日的人除外(生活法令易查网)。请带好护照
  • 独自用餐:官方页面没有写是否接待单人。美东食堂 (Midong Sikdang / 미동식당) 最多接待4人(VisitSeoul)。周末休息的店(Grill Ajisai (Grill Ajisai / 그릴아지사이)、美东食堂 (Midong Sikdang / 미동식당))请在工作日去
  • 预约:六家的官方页面都没有预约途径。请打电话询问
  • 支付:银行卡·移动支付请见#527 韩国支付系统
  • 点餐:美东食堂 (Midong Sikdang / 미동식당) 只要说人数,下酒菜就会上桌。语言不通请见#1339 点餐礼仪。酒类场所的比较请见#830 酒馆 vs 居酒屋 vs 酒吧
  • 交通:Marimo (Marimo / 마리모)(04:00)和Waraku (Waraku / 와라쿠)(01:00)比地铁末班车关门晚。回程请见#1395 错过末班车怎么办

⚠ 常见的4个错误

1. "居酒屋都开到天亮"——Grill Ajisai (Grill Ajisai / 그릴아지사이) 23:00关门,周末休息。美东食堂 (Midong Sikdang / 미동식당) 工作日也只营业到23:00(VisitSeoul)

2. "只点下酒菜也可以"——美东食堂 (Midong Sikdang / 미동식당) 必须每人点一份酒(VisitSeoul)

3. "Tenkai是梨泰院巷子里的店"——地址是汉南洞 (Hannam-dong / 한남동) 君悦酒店LL层(昭月路322号 (Sowol-ro / 소월로))(VisitSeoul)

4. "过了满19岁的生日才能喝酒"——标准是满19岁那年的1月1日(生活法令易查网)
