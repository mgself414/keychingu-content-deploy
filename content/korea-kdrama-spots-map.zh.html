🎯 如何使用这份指南

暴雨中，基泽一家走回家的那段又窄又陡的台阶，真的就在首尔钟路区昌信洞 (Changsin-dong / 창신동) 的小巷里。折叠披萨盒的"披萨时代"如今仍在铜雀区营业，鬼怪两位主人公初次相遇的防波堤，就在江陵注文津海岸路 (Haean-ro / 해안로)，一天24小时开放。亲自踩一踩屏幕里的场景 — 这就是取景地之旅。

这份指南把取景地分成首尔市区 · 首尔近郊与仁川 · 江原道海边三条路线，只收录在韩国观光公社 (VisitKorea) 或运营方官网上确认过地址的地方。想深入跟随某一部剧的路线，请看最下面的专题指南。

🍕 寄生虫 — 从半地下到山坡上的房子，首尔6处

电影里阶级的高低，是用首尔真实的山坡和台阶拍出来的。6处都能在韩国观光公社英文官网上查到地址。

  • 天空披萨 (Sky Pizza / 스카이피자) — 铜雀区 (Noryangjin-ro 6-gil 86 / 노량진로6길 86)。电影里的"披萨时代"。一家人在这里折披萨盒，盘算着赶走朴社长家的保姆。营业时间 10:00~20:30。
  • 猪米超市 (Dwaeji Ssal Supermarket / 돼지쌀슈퍼) — 麻浦区 (Son Gijeong-ro 32 / 손기정로 32)。电影里的"我们超市"。基宇在遮阳伞下喝烧酒，从朋友敏赫那里接到做家教提议的场景。
  • 北阿岘洞台阶 — 麻浦区 (Son Gijeong-ro 6-gil 3 / 손기정로6길 3)，就在超市旁边。基婷捧着桃子走上去的台阶。
  • 昌信洞小巷 — 钟路区 (Jibong-ro 11-gil 38 / 지봉로11길 38)。暴雨中走回家的那段又窄又陡的台阶。
  • 紫霞门隧道 (Jahamun Tunnel / 자하문터널) — 钟路区 (Jahamun-ro 219 / 자하문로 219)。从朴社长家逃出来的一家人经过的隧道(Cheongun-dong / 청운동 ~ Buam-dong / 부암동)。
  • 城北洞住宅区 — 城北区 (Seonjam-ro 8-gil 18 / 선잠로8길 18)。基宇去做家教时走上去的街区。朴社长家是拍摄用的布景，拍完就拆除了 — 房子本身已经不存在。

📸 北阿岘洞台阶·昌信洞小巷·城北洞都是有人居住的街区。请压低声音，不要拍大门和窗户。

🌙 梨泰院Class — 单栗街的夜晚

朴世路伊的大排档"单栗"，就在梨泰院 (Nokssapyeong-daero 40-gil / 녹사평대로40길)。据韩国观光公社介绍，现在以 SEOUL BAM 的名字作为餐厅营业，可以品尝剧中的菜品(韩国观光公社)。

  • SEOUL BAM (剧中的单栗) — 龙山区 (Nokssapyeong-daero 40-gil 57 / 녹사평대로40길 57)。工作日 18:00~23:00，周末 18:00~24:00(以韩国观光公社为准 — 去之前请确认是否营业)。
  • 绿莎坪天桥 — 龙山区 (Nokssapyeong-daero 40-gil 19 / 녹사평대로40길 19)，梨泰院小学教育文化馆前。电视剧热播后成为拍照名所的天桥。
  • 天使之翼壁画台阶 (Angel Wings / 엔젤 윙스) — 龙山区 (Itaewon-dong 116-18 / 이태원동 116-18)。
  • G 旅舍 (G Guesthouse / G 게스트하우스) — 龙山区 (Bogwang-ro 60-gil 14-38 / 보광로60길 14-38)。现在仍作为住宿运营，从屋顶可以俯瞰N首尔塔和梨泰院。
  • 白凡广场 (南山公园) — 中区 (Hoehyeon-dong 1-ga 100-115 / 회현동1가 100-115)。

📸 单栗和旅舍是营业中的店铺·住宿。要拍室内请先询问。梨泰院夜间路线见#450 首尔夜晚指南。

🦑 鱿鱼游戏 — 从双门洞小巷到跨海的乔桐岛

  • 双门洞白云市场·八道干货店 (Paldo Dried Seafood / 팔도건어물) — 道峰区 (Samyang-ro 154-gil 36 / 삼양로154길 36)。基勋顺路去"相宇家的鱼"的场景。市场里有鱿鱼游戏体验馆。
  • CU 双门Uicheon店 — 道峰区 (Uicheon-ro 39-gil 11 / 의천로39길 11)。一男和基勋用杯面配烧酒的便利店。
  • Toin (토인，仁寺洞) — 钟路区 (Insadong-gil 48 / 인사동길 48)。以椪糖套餐受欢迎的店。
  • My Land (마이랜드，仁川月尾岛) — 仁川中区 (Wolmi-ro 234beon-gil 7 / 월미로234번길 7)。德洙一伙在雨中见面的场景。是月尾岛上最古老的游乐园。
  • 乔桐小学 (仁川江华) — 江华郡 (Daeryongan-gil 29 / 대룡안길 29)。童年玩鱿鱼游戏的场景。不能进学校，只能在外面看(韩国观光公社)。

📸 市场和便利店正在做生意。请不要挡住排队的顾客。

❄ 冬季恋歌 — 南怡岛，坐船5分钟

南怡岛因电视剧冬季恋歌的取景地而闻名，如今凭借岛上的林间小路和景致，韩国人也常去(韩国观光公社)。岛的地址是江原 春川市 (Namiseom-gil 1 / 남이섬길 1)，但乘船的码头在京畿 加平郡 (Bukhangangbyeon-ro 1024 / 북한강변로 1024)。

📸 想拍岛上的照片，就瞄准首班船出发的早晨。航行时间可能因天气·季节而变化，出发前请查看官网。加平一日路线见#1033 加平·杨平·南怡岛。

🌊 鬼怪·沙漏 — 江原道海边

  • 注文津防波堤 (鬼怪) — 江原 江陵市 (Haean-ro 1609 / 해안로 1609)。00:00~24:00。是两位主人公初次相遇的防波堤，现在仍有很多人来模仿拍摄那个场景(韩国观光公社)。韩国观光公社建议带上红围巾和花束来重现场景。注文津的永津海滩 (Yeongjin Beach / 영진해변) 是安静干净的海滩(韩国观光公社)。
  • 正东津站 (沙漏，1995) — 江原 江陵市 (Jeongdongyeok-gil 17 / 정동역길 17)。1995年电视剧沙漏大受欢迎，这座紧靠大海的火车站因此闻名全国。从首尔清凉里站有看日出的列车(韩国观光公社)。

📸 防波堤是海上的构造物。夜里又黑又滑，请在白天去，下雨天和浪大的日子不要进去。不要爬到外侧的消波块(混凝土块)上。江陵两天路线见#1106 江陵KTX 2天1夜。

🧰 旅行实用 — 取景地礼仪与结算

  • 居民区·营业场所: 寄生虫的台阶和小巷、双门洞市场、单栗街，都是有人居住、有人做生意的地方。请避免清晨·深夜的团体拍摄，不要拍到能看见屋内的角度。
  • 学校: 江华乔桐小学只能在外面看。
  • 结算: 韩国的餐厅·咖啡馆没有小费 → #1275 小费·结算礼仪
  • 交通卡: 首尔地铁·市内公交，一张交通卡就够。龙山~加平的 ITX-青春要另外买车票 → #1298 交通卡3种选择

⚠ 常见的4个失误

1. "去城北洞看朴社长家" — 那栋房子是布景，已经拆除。在城北洞能看到的是基宇走上去的小巷。

2. "鬼怪防波堤 = 江陵安木咖啡街" — 韩国观光公社介绍的鬼怪取景地江陵地点是注文津防波堤 (江陵市 Haean-ro 1609 / 해안로 1609)。安木是咖啡街，要另外去 → #1037 江陵安木海滩咖啡。

3. "南怡岛从加平站直接就是岛" — 要从加平站走约1.5km到码头再坐船。最后一班去岛的船是21:00。

4. "在乔桐小学操场拍鱿鱼游戏场景的照片" — 学校里面禁止进入。只能在围墙外看。

⚙ FAQ 4

Q1. 一天能看几部作品?

首尔市区路线(寄生虫·梨泰院Class·鱿鱼游戏双门洞)都在首尔市内，但分属不同的区 — 仅寄生虫的6处就横跨铜雀·麻浦·钟路·城北4个区。每部作品按半天安排，移动时间用地图应用查看。南怡岛和江原道海边各自要单独安排一天。

Q2. 哪里要门票?

在官网上确认过门票的只有南怡岛(普通19,000韩元，含往返船票)。My Land(游乐园)和双门洞市场里的体验馆没能确认费用，去之前请先了解。其余都是街道·街区·店铺。

Q3. 晚上可以去哪里?

单栗 (SEOUL BAM) 从晚上6点开始营业(以韩国观光公社为准)。注文津防波堤没有出入时间限制，但夜里又黑又滑，请在白天去。居民区的取景地也请在白天去。

Q4. 想拍出和剧里一模一样的照片怎么办?

在注文津防波堤用红围巾和花束，在仁寺洞 Toin 用椪糖套餐 — 一件道具就能让场景活起来。各作品的场景拍照要领见#010 K-电视剧取景地之旅。
