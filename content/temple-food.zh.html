⚠ 外国游客常犯的5个错误

1. “寺庙饮食 = 纯素”: 寺庙饮食 = 纯素 + 不使用五辛 (Osinchae / 오신채) (大蒜·葱·韭菜·小葱·兴渠) + 修行哲学 的区别。一般纯素可以吃大蒜·葱，寺庙饮食则不行。

2. “钵盂供养 (Balwoo Gongyang / 발우공양) = 米其林所以很贵”: 钵盂供养 (Balwoo Gongyang / 발우공양) = 善 (Seon / 선)·圆 (Won / 원)·念 (Yeom / 염)·喜 (Hui / 희)·法食 (Beopsik / 법식) 5道菜套餐 30,000~80,000韩元 + 韩国佛教文化事业团 (Korean Buddhist Cultural Foundation / 한국불교문화사업단) 直营 + 外国游客英语菜单·私人包间 + 外国游客首选。

3. “无需预约即可”: 钵盂供养 (Balwoo Gongyang / 발우공양)·阿胜地 (Aseungji / 아승지)·麻地 (Maji / 마지) = 需提前2~3天预约。山村 (Sanchon / 산촌)·日常 (Ilsang / 일상)·纯素仁寺 (Vegan Insa / 비건인사)·素怡然 (Soiroum / 소이로움) = 可直接入座 (建议周末预约)。

4. “香积世界 (Hyangjeoksegye / 향적세계) = 餐厅”: 香积世界 (Hyangjeoksegye / 향적세계) = 不是餐厅而是烹饪课程体验馆 + 僧侣亲授 + 外国游客英语课程 (周六) + 10,000~20,000韩元体验费用 + 外国文化爱好者首选。

5. “津宽寺 (Jingwansa / 진관사) = 普通餐厅”: 津宽寺 (Jingwansa / 진관사) = 必须参加寺庙寄宿 (Templestay / 템플스테이) 或提前预约的山寺饮食体验项目 + 外国爱好者需提前申请。
