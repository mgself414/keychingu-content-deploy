🐟 4채널 deep dive

🏙 노량진수산시장 (Noryangjin Suisan Market)

핵심 가치: 서울 #1 + 새벽 도매 + 접근성 #1.

  • 위치: 서울 동작구 노량진 (지하철 9호선)
  • 시그니처: 사계절 활어 + 새벽 도매 (3~5AM)
  • 가격 anchor: 광어 25,000원·방어 50,000원·연어 30,000원/1kg + 식당 차림비 8,000~15,000원
  • 시간: 새벽 도매 03:00~07:00 / 일반 09:00~22:00
  • 외국인 친화도: ★★★★★ (영문 메뉴·관광객 친화)
  • 자세히: ([#587](#587)) 새벽 도매 deep dive

🌊 자갈치시장 (Jagalchi Market)

핵심 가치: 부산 #1 + 겨울 방어 정통 + MZ vlog #1.

  • 위치: 부산 중구 자갈치
  • 시그니처: 겨울 방어 #1·MZ 인스타 #1
  • 가격 anchor: 광어 20,000원·방어 40,000원·도다리 25,000원/1kg
  • 시간: 09:00~22:00
  • 외국인 친화도: ★★★★ (부산 정통·MZ)
  • 자세히: ([#590](#590)) 자갈치 deep dive 12선

🏝 통영중앙활어시장 (Tongyeong Central Live Fish Market)

핵심 가치: 남해 정통 + 도미·농어 + 봄·여름.

  • 위치: 경남 통영 (KTX 부산 후 버스)
  • 시그니처: 남해 활어 정통·도미·농어·한치
  • 가격 anchor: 도미 40,000원·농어 30,000원·한치 25,000원/1kg
  • 시간: 06:00~22:00
  • 계절: 봄·여름 #1
  • 외국인 친화도: ★★★ (남해 정통)

🏖 소래포구 (Sorae-pogu)

핵심 가치: 가을 전어·도다리 + 인천 가성비 + 가족.

  • 위치: 인천 남동구 소래
  • 시그니처: 가을 전어 #1 (9~10월)·도다리 (3월)
  • 가격 anchor: 전어 15,000원·도다리 20,000원/1kg
  • 시간: 09:00~21:00
  • 계절: 가을 (9~10월)·봄 (3월)
  • 외국인 친화도: ★★★ (인천 가성비)

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 위치·계절·가격 완전 다름. 서울 = 노량진 / 부산 = 자갈치 / 남해 = 통영 / 가을 전어 = 소래포구.

2. "노량진 = 새벽만": 노량진 = 새벽 도매 (3~5AM) + 일반 09:00~22:00 모두.

3. "자갈치 = 사계절 방어": 자갈치 방어 = 겨울 12~2월 #1 (다른 계절 = 양식/냉동).

4. "통영 = 가까움": 통영 = 부산 KTX 2.5h + 버스 1.5h = 총 4h (서울 출발).

5. "소래포구 = 일반 시장": 소래포구 = 가을 전어·봄 도다리 1순위 (다른 계절 ↓).

⚙ FAQ 8개

1. 첫 회 시장 = 어디: 노량진 (서울 접근성) → 자갈치 (부산 여행).

2. 인스타·vlog: 자갈치 (#1) + 노량진 새벽.

3. MZ 트렌드: 자갈치 (#1) + 노량진 새벽 도매 vlog.

4. 겨울 매니아: 자갈치 방어 (#1).

5. 가을 매니아: 소래포구 전어 (#1) + 강화 전어 마을.

6. 알레르기·임신: [#864 disclaimer](#864) 참조 (임신부 회 X).

7. 결제·팁: 카드 OK / 현금 일부 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

회 시장 4채널 모두 활어 정통·식중독 주의. 임신부 = 회 X (CDC 권고)·매운탕 OK. 어린이 = 한정. 알레르기 (생선·갑각류) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 4채널 모두 어류 = 할랄 OK / 코셔 OK.
  • 채식·비건: 회 = 비채식 / 채식 = 비빔밥·사찰음식.
  • 글루텐 free: 회 자체 OK / 간장 = 글루텐 일부 (Tamari 대체).
