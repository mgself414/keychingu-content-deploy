済州 菜の花ガイド — 城山日出峰菜の花畑・チョルッティ菜の花畑・菜の花栽培団地、カシリ ノクサンロの菜の花ロード・西帰浦菜の花祭り、山房山菜の花畑、中文オンドンムル渓谷

サブタイトル: 日出峰菜の花畑(12~3月、常時開放) · チョルッティ菜の花畑(11月中旬~3月中旬 09:00~18:00) · 菜の花栽培団地(常時開放) · ノクサンロの菜の花ロード(約10km、常時開放) · 山房山菜の花畑(10:00~18:00、撮影料) · オンドンムル渓谷(常時開放) · 2026西帰浦菜の花祭り(4/4~5、終了) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、済州の西帰浦で菜の花が見られる場所をまとめたものです。城山日出峰の周りの菜の花畑三か所、カシリのノクサンロの菜の花ロードと祭り、山房山の菜の花畑、中文のオンドンムル渓谷です。

観光公社の登録値では、冬に見られる菜の花畑もあります。日出峰菜の花畑は12~3月、チョルッティ菜の花畑は11月中旬~3月中旬に開いています。残りは春を中心に紹介されています。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 城山 — 日出峰菜の花畑・チョルッティ菜の花畑・菜の花栽培団地

日出峰菜の花畑、西帰浦市 城山邑 ソンサン里 (Seongsan-ri / 성산리)、☎ 済州観光情報センター (Jeju Gwanggwang Jeongbo Senteo / 제주관광정보센터) 064-740-6000 は、城山日出峰 (Seongsan Ilchulbong / 성산일출봉)とクァンチギ海辺 (Gwangchigi Haebyeon / 광치기해변)の間にある菜の花畑です。たいてい12月から3月まで菜の花が咲き、畑の向こうに海と漢拏山 (Hallasan / 한라산)が見えます。咲く時期は年によって違います。常時開放ですが、観光公社の紹介は、菜の花を見るなら日が沈む前に行くよう勧めています。

  • 利用時期: 12~3月。開く時間: 常時開放。休み: 年中無休。
  • 駐車: 可能。

チョルッティ菜の花畑、西帰浦市 城山邑 Dongnyuam-ro 8 (동류암로 8)、☎ 案内 064-757-2076 は、城山日出峰の近くにある菜の花畑で、城山日出峰、牛島 (Udo / 우도)、葦原が一緒に見えます。菜の花畑の周りを回る乗馬体験もできます。観光公社の紹介によると、以前の開花時期は3~5月でしたが、品種改良と種まき時期の調整で、最近は11月~5月に見られ、いちばんの見ごろは3月です。ハート形の構造物の中に城山日出峰が入るように写真を撮れます。

  • 開く時間: 11月中旬~3月中旬 09:00~18:00。
  • 休む期間: 毎年3月末~11月初め。駐車: 可能。
  • 登録値どうしが食い違っています。開花の紹介は11月~5月(ピーク3月)ですが、開く時間は3月中旬まで、休む期間は3月末からと登録されています。

菜の花栽培団地、西帰浦市 城山邑 コソン里 (Goseong-ri / 고성리)、☎ 済州オルレ旅行者センター (Jeju Olle Yeohaengja Senteo / 제주올레여행자센터) 064-762-2167 は、もとは海だったところに砂と土が積もって城山日出峰とつながった、細長い土地にある菜の花畑です。花畑の両側に海が広がります。近くに牛島行きの旅客船が出るソンサンポ港 (Seongsanpo-hang / 성산포항)、ソプチコジ (Seopjikoji / 섭지코지)、オジョ浦口 (Ojopogu / 오조포구)があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

📍 カシリ — ノクサンロの菜の花ロード・西帰浦菜の花祭り

ノクサンロの菜の花ロード、西帰浦市 表善面 Gasiro 565beon-gil 20 (가시로565번길 20)、☎ 西帰浦総合観光案内所 (Seogwipo Jonghap Gwanggwang Annaeso / 서귀포종합관광안내소) 064-732-1330 は、カシリ (Gasi-ri / 가시리)村の入口から約10kmの区間で菜の花と桜が一緒に咲くドライブコースです。韓国の美しい道100選に選ばれました。朝鮮時代の牧馬場だったノクサンジャン (Noksanjang / 녹산장)とガプマジャン (Gapmajang / 갑마장)を通り、漢拏山とカシリ風力発電団地 (Gasi-ri Pungnyeok Baljeon Danji / 가시리 풍력발전단지)が見えます。近くにチョランマル体験公園 (Jorangmal Cheheom Gongwon / 조랑말체험공원)、ガプソニオルム (Gapseoni Oreum / 갑선이오름)があります。

  • 開く時間: 常時開放。休み: 年中無休。
  • 駐車: 不可能。

2026西帰浦菜の花祭り、表善面 カシリ チョランマル体験公園一帯、☎ 西帰浦市 (Seogwipo-si / 서귀포시) 064-760-3942 は、2026年4月4~5日、10:00~20:00に開かれました。料金は無料でした。ノクサンロ一帯の10万㎡の菜の花畑を歩く祭りで、登録されたプログラムは、夜間開場とランニングプログラムが主なもので、ワンデークラス、村の特色プログラム、バスキング公演などが付帯でした。

📍 西部・中文 — 山房山菜の花畑・オンドンムル渓谷

山房山菜の花畑、西帰浦市 安徳面 サゲ里 (Sagye-ri / 사계리)、☎ 済州オルレ旅行者センター 0507-1435-2179 は、山房山ランド (Sanbangsan Raendeu / 산방산랜드)の前の公営駐車場から行ける菜の花畑です。山房山 (Sanbangsan / 산방산)を背景にした花畑がいくつかあり、その中から選んで入ります。個人が育てている私有地なので、写真撮影料を取ります。たいてい3月に満開になります。近くに山房山、龍頭海岸 (Yongmeori Haean / 용머리해안)、サゲ海岸 (Sagye Haean / 사계해안)があります。

  • 開く時間: 10:00~18:00。休み: 年中無休。
  • 料金: 写真撮影料(金額は登録値なし)。駐車: 可能。

オンドンムル渓谷、西帰浦市 セクタル洞、☎ 済州観光情報センター 064-740-6000 は、中文観光団地 (Jungmun Gwanggwang Danji / 중문관광단지)のLotte Hotel東側の渓谷です。岩が大きくて険しく、水を求める獣も近づけず、お尻だけ突っ込んで用を足して帰っていったことから名前がつきました。春になると渓谷の斜面に沿って菜の花が咲きます。オルレ8コース (Olle 8-gose / 올레 8코스)に入っていて、中文ムーンライトウォーキング公園 (Jungmun Dalbit Geotgi Gongwon / 중문달빛걷기공원)とも呼ばれます。中文海水浴場 (Jungmun Haesuyokjang / 중문해수욕장)の駐車場に車を停めて歩いて行きます。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

⚠ 事前に知っておきたい3つのこと

  1. チョルッティ菜の花畑は3月末~11月初めに休みます — 11月中旬~3月中旬 09:00~18:00に開きます。
  2. 山房山菜の花畑は私有地なので写真撮影料を取ります — 10:00~18:00に開きます。
  3. ノクサンロの菜の花ロードは駐車できません — 駐車可能としては登録されていません。

⚙ FAQ 2

Q. 冬にも済州の菜の花は見られますか?

A. 観光公社の登録情報では、日出峰菜の花畑 (Ilchulbong Yuchaebat / 일출봉유채밭)が12~3月に開き、チョルッティ菜の花畑 (Joltti Yuchaebat / 졸띠유채밭)が11月中旬~3月中旬 09:00~18:00の運営として載っています。

Q. 菜の花と桜を一緒に見られる場所は?

A. カシリのノクサンロの菜の花ロード (Noksanro Yuchaekkot Doro / 녹산로 유채꽃도로)です。約10kmの区間で菜の花と桜が一緒に咲き、常時開放です。駐車はできません。
