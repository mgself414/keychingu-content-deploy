韩纸 — 流传千年的韩国纸，窗棂与工艺的纹理

> 楮树 (Daknamu / 닥나무) 皮 · 单帘抄纸 (Oebal-tteugi / 외발뜨기) · 千年保存 · 无垢净光大陀罗尼经 (Mugujeonggwang Dasdarani-gyeong / 무구정광대다라니경) · 窗户纸 (Changhoji / 창호지)·书法·韩纸工艺 · 卢浮宫与梵蒂冈采用的修复用纸 — 为外国人讲解的韩纸 (Hanji / 한지) 文化。不是“韩国纸很漂亮”，而是为什么要做成能流传千年，以及用在哪里、怎么用。

观察韩国的旧物件，会发现纸特别多。韩屋 (Hanok / 한옥) 的门和窗不是用玻璃而是用纸来封挡，书法家在纸上落墨，灯 (Deung / 등)、函 (Ham / 함)、笔筒之类的生活用品也是把纸叠起来制成的。那种纸就是韩纸 (Hanji / 한지) — 用韩国传统方式抄出楮树 (Daknamu / 닥나무) 皮制成的纸。

西方纸过200~300年就会发黄朽坏，而韩纸能流传千年。实际上，8世纪制作的韩纸印刷品至今仍完好留存。本文不是讲“某家韩纸工坊很漂亮”（→ 场所指南），而是讲解韩纸是什么、如何制作、为什么能保存这么久，以及韩国人用在哪里。这是韩国文化解读系列第70篇。

⚠️ 外国人常误解的3点

1. “韩纸不就是手工纸 (handmade paper) 吗” ❌ — 手工抄的纸世界各地都有，但韩纸是原料 (楮树 / Daknamu / 닥나무)·制法 (单帘抄纸 / Oebal-tteugi / 외발뜨기)·化学性质 (中性) 三者咬合，才达成千年保存。它不是“漂亮的手工纸”，而是为永久保存记录而设计的纸。

2. “韩国·中国·日本的纸不都差不多吗” ❌ — 三者都是楮树类纸，但制法·用途不同。韩纸尤其通过单帘抄纸 (Oebal-tteugi / 외발뜨기) 让纤维纵横交错，发展成坚韧且两面可用的纸。在韩国也称为“楮纸 (Dakjongi / 닥종이)”。

3. “用纸做的门又弱又冷吧” ❌ — 韩屋的窗户纸 (Changhoji / 창호지) 不是普通的纸。它柔和地透入光线、阻挡风，同时让空气·湿气通过，从而调节室内环境。被称为“会呼吸的窗”的缘由 — 不是因为弱，而是被设计成那样使用的（→ 韩屋 #1197）。

① 韩纸是什么 — “楮纸”这个名字的分量

韩纸 (Hanji / 한지) 顾名思义就是“韩国的纸”。关键在原料。韩纸用从楮树 (Daknamu / 닥나무, 楮, paper mulberry) 内皮抽出的长纤维制成。所以在韩国，韩纸也叫“楮纸 (Dakjongi / 닥종이)”。

这为什么重要？现代常见的纸用把木头打碎的纸浆制成，制造过程中掺入酸性物质，时间一久就会发黄变色、碎裂（西方古书朽坏的原因）。而楮树 (Daknamu / 닥나무) 内皮纤维又长又韧，加上传统韩纸制法不用酸，纸保持中性~弱碱性。所以韩纸过几百年也不易朽坏。

对古代韩国人来说，纸不只是消耗品，而是留存记录、建造房屋 (窗棂·地板)、制作生活用品的核心材料。因此制作好纸是受到国家管理的技术，抄纸的匠人被称为韩纸匠 (Hanjijang / 한지장)。

② 如何制作 — 经百道手工的单帘抄纸 (Oebal-tteugi / 외발뜨기)

韩纸能流传千年的一半秘密在于制作方式。传统韩纸几乎所有工序都靠手工，常以“一张纸要过百道手”来形容。大致流程如下。

  • ① 采集 (冬季): 在晚秋~冬季 (大致11~2月) 砍伐当年生长的楮树 (Daknamu / 닥나무)。人们认为寒冷时节的纤维更好。
  • ② 蒸煮剥皮: 把楮树蒸过后剥去外皮，只留下白色内皮 (白楮 / Baekdak / 백닥)。
  • ③ 碱水熬煮: 把内皮放入碱水 (Jaetmul / 잿물, 天然碱液) 熬煮数小时，去除杂质并使纤维松软。这道工序是让纸变成中性的关键。
  • ④ 漂洗·挑杂·捶打: 把煮过的皮在清水中漂洗，逐一挑出杂点后，用木棒捶打把纤维捶散捶细。
  • ⑤ 拌入黄蜀葵 (Dakpul / 닥풀): 把从黄蜀葵 (Dakpul / 닥풀) 根部取出的黏稠黏液拌入水中。这是让纤维均匀悬浮于水中的天然分散剂。
  • ⑥ 单帘抄纸 (Oebal-tteugi / 외발뜨기): 匠人把帘 (Bal / 발, 竹制抄帘) 浸入水中，前后·左右有节奏地晃动来捞起纤维。这样晃动会让长纤维纵横交错缠结，做出韩纸特有的坚韧且两面可用的纸。这种用单把手抄纸的方式叫单帘抄纸 (Oebal-tteugi / 외발뜨기)，被认为比更省力的双帘抄纸 (Ssangbal-tteugi / 쌍발뜨기)纸质更好。
  • ⑦ 晾干·整理: 把抄好的纸一张张叠起沥水，贴在热板上烘干后整理。

> 核心: 不是手工多就贵，而是用单帘抄纸 (Oebal-tteugi / 외발뜨기) 让纤维交错、用碱水调成中性这一工序本身造就了千年保存。韩纸的耐久性不是“做得好的结果”，而是被设计出来的性质。

③ 流传千年的纸 — 无垢净光大陀罗尼经 (Mugujeonggwang Dasdarani-gyeong / 무구정광대다라니경) 这一证据

“韩纸能流传千年”这句话不是夸张，而是有实物证明的。其决定性证据就是无垢净光大陀罗尼经 (Mugujeonggwang Dasdarani-gyeong / 무구정광대다라니경, 無垢淨光大陀羅尼經)。

这件从庆州 (Gyeongju / 경주) 佛国寺 (Bulguksa / 불국사) 释迦塔 (Seokgatap / 석가탑) 出土的佛经印刷品，属于8世纪、统一新罗 (Unified Silla / 통일신라) 时期 (推定制作于751年以前)，被评价为现存世界最古老的木版印刷品，且印刷它的纸也属于现存最古级别。也就是说，约1200年前的韩纸至今仍保持原形留存。

之所以可能，是前面提到的两点 — 楮树 (Daknamu / 닥나무) 长纤维的坚韧和中性~弱碱性的化学稳定性。酸性纸会自我分解而朽坏，而韩纸几乎不发生这种分解反应。所以韩国众多古文书·古籍·佛经都以良好状态被发掘。

> 外国人视角: 与欧洲的羊皮纸或酸性纸浆纸数百年就碎裂相比，韩纸的保存性即便从材料科学角度看也是惊人的水平。这一点引出后文将提到的被采用为世界文物修复用纸。

④ 用在哪里 — 窗户纸·书法·地板纸，韩纸撑起的日常

韩纸在成为博物馆遗物之前，本身就是生活。韩国人把韩纸大致用于三个方向。

  • 窗户纸 (Changhoji / 창호지) — 用纸做的门和窗: 韩屋 (Hanok / 한옥) 的门·窗是在木格上糊上韩纸制成的 (窗户纸)。与玻璃不同，它柔和地滤过光线、阻挡风却让空气·湿气通过，使室内保持舒适。冬日阳光穿过窗户纸，把房间染成温暖的乳白色，正是韩屋的情趣（→ 韩屋 #1197）。
  • 书画纸 (Seohwaji / 서화지) — 书法与绘画的底子: 韩纸很好地吸纳墨汁、晕染细腻。所以古代书法家·画家爱用它，字和画在韩纸上留存了数百年。（如今书法也大量使用中国式宣纸 / 画仙纸 (Hwaseonji / 화선지)，但韩纸作为坚韧且保存性好的底子，仍被视为珍贵。）
  • 地板纸 (Jangpanji / 장판지)·糊墙纸 (Dobaeji / 도배지) — 包裹房屋的纸: 在地面叠糊数层、浸豆油做成油地板 (Jangpan / 장판)，并糊在墙上做壁纸。暖炕 (Ondol / 온돌) 温暖的地板与韩纸油地板是一套。

除此之外，韩纸还用于扇子·风筝 (Yeon / 연)·灯 (Deung / 등)·雨伞等生活用品，甚至用作铠甲加固材料或布料替代品。以至于有“韩国人用纸把房子穿在身上生活”的说法。

⑤ 韩纸工艺 — 把纸叠起来塑成器皿·函·灯

韩纸的另一副面孔是工艺。把韩纸多层粘贴、搓捻或剪裁来制作立体物件的韩纸工艺，是韩国特有的工艺门类，按技法分为几支。

  • 纸绳工艺 (Jiseung craft / 지승공예, 紙繩工藝): 把韩纸搓成细绳般编织，制作篮子·器皿·坐垫的技法。有用纸织出织物般的质感。
  • 纸糊工艺 (Jiho craft / 지호공예, 紙糊工藝): 把废韩纸用水化成糊状后与浆糊混合，像黏土一样塑成器皿·函的技法。是一种“纸陶艺”。
  • 纸花工艺 (Jihwa craft / 지화공예, 紙花工藝): 把韩纸染色制成花，用于仪礼·装饰的技法。
  • 剪纸工艺 (Jeonji craft / 전지공예, 剪紙工藝): 在木·纸框上多层糊上韩纸做成函·针线盒·笔筒等，再用彩纸剪出花纹贴上装饰的技法。

这样制成的函·笔筒·灯·针线盒既坚固又轻巧，彩纸所呈的色彩与花纹很美，作为实用品兼工艺品深受喜爱。给韩纸加上漆 (Otchil / 옻칠) 能提升防水·耐久性，用得更久。如今韩纸工艺也扩展到照明 (灯)·室内小物·饰品·环保袋等现代设计产品。

⑥ 全州韩纸与韩纸的世界化 — 卢浮宫与梵蒂冈选中的纸

提到韩纸，会想到的城市是全州 (Jeonju / 전주)。全州楮树 (Daknamu / 닥나무) 长得好、水质佳，自古就是纸之乡，高丽 (Goryeo / 고려)·朝鲜 (Joseon / 조선) 时代更是王室进贡品，全州韩纸 (Jeonju hanji / 전주한지) 在产量·品质上都名列前茅。如今全州仍是韩纸产业和韩纸文化节的中心。

进入20世纪，韩纸产业一度因廉价机制纸·进口画仙纸 (Hwaseonji / 화선지) 的挤压而大幅萎缩。然而韩纸的千年保存性在意想不到的舞台上再次受到瞩目 — 那就是世界文物修复。

  • 2016年前后，韩纸通过国际认证测试（意大利的文书·图书修复专业机构等）之后，据报道梵蒂冈博物馆将韩纸用于圣方济各亲笔祈祷文“卡尔图拉 (Chartula)” (推定1224年) 等重要文物的修复。
  • 据悉法国卢浮宫博物馆也有采用韩纸修复馆藏家具 (如19世纪马克西米利安二世书桌) 的案例。

由于纸朽坏时修复用纸不能跟着朽坏，数百年后仍稳定的韩纸中性·耐久性作为修复材料获得高度评价。进而，韩国于2024年将韩纸制作的传统知识·技术申请列入 UNESCO 人类非物质文化遗产代表名录，是否列入将在日后会议上决定。

> ※ 修复采用案例·年代·UNESCO 登记进展情况可能随时点而变化，建议自行确认。本文以公开报道·机构资料为准。

⑦ 外国人的韩纸体验 — 看、做、买回家

韩纸不是隔着博物馆玻璃，而是可以亲身体验的文化。外国旅行者享受韩纸的方法大致有三种。

  • 看: 在韩屋 (古宫·韩屋村) 亲眼看窗户纸 (Changhoji / 창호지) 的门·窗，就能体会纸是如何滤光的。在韩纸·纸相关的展览·工坊，有些地方还能看到单帘抄纸 (Oebal-tteugi / 외발뜨기) 演示。
  • 做: 韩纸工坊·体验馆运营抄纸或用韩纸做灯·扇子·小函的体验。亲手晃动抄帘抄一张纸，就能理解“为什么要过百道手”。
  • 买回家: 韩纸笔记本·明信片·扇子·灯·福袋 (Bokjumeoni / 복주머니)·韩纸人偶等既轻巧又有韩国风情，作为纪念品·礼物很受欢迎。楮树 (Daknamu / 닥나무) 纤维特有的质感与淡雅色泽，与量产纸明显不同（→ 礼物文化 #1193）。

> 小贴士: 同样是“韩纸制品”，手工韩纸与机器仿制的普及型在质感·耐久性上不同。慢慢用手摸过再挑选为好。

❓ 外国人常问的问题 (FAQ)

  • 韩纸和日本的和纸 (washi)·中国的纸是一样的吗？ — 三者都是楮树类传统纸，根源相似，但制法·用途不同。韩纸通过单帘抄纸 (Oebal-tteugi / 외발뜨기) 让纤维交错，坚韧且两面可用，朝着保存性极高的方向发展。
  • 真的能流传千年吗？ — 8世纪统一新罗 (Unified Silla / 통일신라) 的无垢净光大陀罗尼经 (Mugujeonggwang Dasdarani-gyeong / 무구정광대다라니경) 有实物留存等，凭借中性·弱碱性，数百~千年的保存得到实证。不过，这是妥善保管时的情况。
  • 为什么那么贵？ — 从采集楮树 (Daknamu / 닥나무) 到单帘抄纸 (Oebal-tteugi / 외발뜨기)，几乎所有工序都是手工，很费工。与其说是“贵的纸”，不如把它看作接近工艺品的纸。
  • 韩纸做的纪念品买什么好？ — 轻巧·体积小的笔记本·明信片·扇子·福袋 (Bokjumeoni / 복주머니)·韩纸灯 (Deung / 등) 比较稳妥。越是手工韩纸，质感越鲜活。
  • 可以体验做韩纸吗？ — 在全州 (Jeonju / 전주) 等韩纸产地及城市的工坊·体验馆，有些地方运营抄纸·韩纸工艺体验。建议出发前确认预约·营业情况。
