首尔东西轴⑦ 汉江巴士，从麻谷到蚕室 — 在江面上横向阅读首尔

副标题：南北轴走的是50年前铺的路(140路公交)，东西轴走的是600年的路(720路公交)与环线(2号线)。第三笔是江——2025年9月，汉江巴士驶上这条比城市更古老的东西直线。麻谷上船，汝矣岛换乘，经狎鸥亭或玉水、首尔林、纛岛到蚕室，水面上约3小时30分钟，中途码头全部通过。首尔东西轴第7篇。

ISSUE · #1362 · 2026-09-07

🎯 定调——第三笔，江

纵向阅读首尔的巴士(#1353)、横向阅读首尔的巴士(#1356)，还有环线东半环(#1359)——这个系列走的都是地上的路。这一篇下到水面。汉江 (Han River / 한강) 是横贯首尔东西的最古老直线，2025年9月18日起，汉江巴士 (Hangang Bus / 한강버스) 作为大众交通驶上这条江。不是游览船。刷交通卡上船，在下一个码头下船，单程3,000韩元的船。

八个码头由西向东排开——麻谷码头 (Magok pier / 마곡 선착장)、望远 (Mangwon / 망원)、汝矣岛 (Yeouido / 여의도)、狎鸥亭 (Apgujeong / 압구정)、玉水 (Oksu / 옥수)、首尔林 (Seoul Forest / 서울숲)、纛岛 (Ttukseom / 뚝섬)、蚕室 (Jamsil / 잠실)。航线在汝矣岛分为西部和东部，从麻谷到蚕室必须在汝矣岛下船换乘一次。这一篇原样把这个结构当作路线：西端麻谷上船，汝矣岛换乘，东端蚕室下船。码头周边的社区全部通过——这一篇的主角是江本身。

  • 总耗时：约3小时30分钟(乘船约2小时 + 汝矣岛换乘等待 + 车站↔码头步行约30分钟——因时刻表差异很大)
  • 推荐时段：平日上午出发——先看时刻表。班次间隔在1小时上下，不掐准出发时间等待会很长。想在船上看夕阳，也可以倒推把东部区间安排在下午晚些时候(2026年8月起下午·夜间班次增加)
  • 坡度：无——步行区间从车站到码头均为平地

为什么是汉江巴士——首尔最新的大众交通

汉江巴士经过2025年7月的市民体验运营，于2025年9月18日正式通航。冬季因机械故障部分区间停运，2026年3月1日全线恢复，此后乘客数快速增长——3月6.2万、4月7.6万、5月9.1万人次，月度屡创新高，截至2026年8月13日累计乘客突破50万人次(首尔市公布)。用户调查(2026年6~7月，3,569人)显示满意度97%。运营方根据附属设施的刷卡比例推算，乘客中约35%为外国人——外国人乘船最多的码头是汝矣岛和纛岛。

📖 故事1——江先于一切存在：南北轴的桥(1969)与隧道(1970)，东西轴的钟路 (Jongno / 종로)(600年)与环线(1984)——全都是人铺的线。汉江在这一切之前就已存在。这条横贯首尔东西的直线，朝鲜时代是渡口与漕运之路，20世纪成了从桥下经过的风景，到2025年又重新变成一条路。这艘船，等于是首尔最新的大众交通，行驶在最古老的轴线上。

🚶 路线——按水路顺序

起点是9号线阳川乡校站 (Yangcheon Hyanggyo Station / 양천향교역)。步行至麻谷码头约12分钟(0.8km)。免费接驳车已于2026年8月停运，只能步行。

① 阳川乡校站 → 麻谷码头 → 购票 (🚶 约12分钟)

  • 从车站径直朝汉江方向走。在码头建筑的售票机购买乘船券——仅限刷卡，不接受预约。交通卡也可以用，比如T-money卡 (티머니)。成人3,000韩元·青少年1,800韩元·儿童1,100韩元(2026年9月官方标准·可能变动)。单船定员199人，周末可能要等下一班。
  • 在这里再次确认时刻表。西部(麻谷↔汝矣岛)和东部(汝矣岛↔蚕室)班次各自独立。

② 麻谷 → 望远 (🚢 约25分钟 · 通过)

  • 船驶到江中央，首尔的西边展开。左侧(北岸)是麻谷·加阳 (Gayang / 가양) 一带的公寓群，右侧是防火大桥 (Banghwa Bridge / 방화대교)·幸州山城 (Haengju Fortress / 행주산성) 方向。每经过一座桥下，首尔的桥名就多认识一个。
  • 望远码头——不下船。望远市场 (Mangwon Market / 망원시장)·望远洞(#489·#25)是从这里过江往上走的社区。

③ 望远 → 汝矣岛 — 换乘 (🚢 约20分钟 · 下船)

  • 过了杨花大桥 (Yanghwa Bridge / 양화대교)，左侧是汝矣岛的玻璃大楼群和63大厦 (63 Building / 63빌딩)。汝矣岛码头全员下船——西部和东部航线在这里终止与起始。要继续同方向前进，下船后要重新搭乘东部(蚕室方向)班次。换乘票价·手续以现场指引为准。
  • 📖 故事2——在汝矣岛换乘：航线在汝矣岛一分为二，正是首尔地理的写照。西首尔与东首尔的铰链就是汝矣岛，江面上人们也在这里换乘。换乘等待时间长的话，可以去码头建筑3楼的观江咖啡馆——星巴克汝矣岛汉江公园店 (Starbucks Yeouido Hangang Park / 스타벅스 여의도한강공원점)，仅举一例代表性店铺——，或步行约4分钟到5号线汝矣渡口站 (Yeouinaru Station / 여의나루역) 方向的汉江公园稍作停留再回来。

④ 汝矣岛 → 狎鸥亭或玉水 (🚢 约30分钟 · 通过)

  • 东部班次依次经过麻浦大桥 (Mapo Bridge / 마포대교)·汉江大桥 (Hangang Bridge / 한강대교)·铜雀大桥 (Dongjak Bridge / 동작대교)·盘浦大桥 (Banpo Bridge / 반포대교) 桥下。右侧(南岸)是龙山 (Yongsan / 용산)·二村 (Ichon / 이촌)，左侧是盘浦和星光岛 (Sebitseom / 세빛섬)。南北轴(#1353)巴士曾经跨越的汉南大桥 (Hannam Bridge / 한남대교)正面出现——这次是从桥下经过。
  • 下一站视班次而定，停靠狎鸥亭或玉水二者之一(按往返班次交叉停靠)。两处都不下船。狎鸥亭距狎鸥亭站 (Apgujeong Station / 압구정역) 步行超过20分钟，玉水距玉水站 (Oksu Station / 옥수역) 3号出口5分钟——玉水社区是南北轴#1354汉南的东邻。

⑤ → 首尔林 → 纛岛 (🚢 约15分钟 · 通过)

  • 过了圣水大桥 (Seongsu Bridge / 성수대교)，左侧是首尔林。首尔林码头自2026年6月8日起限时运营至10月底(配合庭院博览会)，之后可能不再停靠。接着是纛岛码头——外国乘客下船人数仅次于汝矣岛。这一篇在此通过(圣水·首尔林见#1342·#701·#709)。

⑥ 纛岛 → 蚕室 — 收尾 (🚢 约25分钟)

  • 经过清潭大桥 (Cheongdam Bridge / 청담대교)·蚕室大桥 (Jamsil Bridge / 잠실대교) 桥下后，右侧江岸远处，乐天世界塔 (Lotte World Tower / 롯데월드타워)(555米)渐渐靠近。在东端蚕室码头下船。
  • 收尾：蚕室码头离地铁站较远——步行至蚕室新川站 (Jamsilsaenae Station / 잠실새내역) 方向约15分钟上下(以现场指示牌为准)。蚕室社区见#82·#300·#707。2号线东半环(#1359)从蚕室铁桥 (Jamsil Railway Bridge / 잠실철교) 上方跨江而过的同一位置下方，这一篇在此结束。

🚢 乘船指南5条

1. 先看时刻表：班次间隔在1小时上下。在hgbus.co.kr或码头售票机确认当日时刻表，再决定出发时间。

2. 不接受预约·仅限刷卡：在现场售票机刷卡(含交通卡)。不收现金(#1301)。定员199人。

3. 务必在汝矣岛下船：西部·东部航线是分开的。下船后重新搭乘东部班次。

4. 座位选上甲板·靠窗：经过桥下时上甲板视野好，风大时可坐室内靠窗。东部区间右侧(南岸)是江南天际线。

5. 确认是否停运：八堂大坝 (Paldang Dam / 팔당댐) 放流量达每秒3,000立方米以上、潜水桥 (Jamsu Bridge / 잠수교) 水位超过基准、气象恶化时停航。梅雨·台风季出发前请查看公告——替代方案是#1256(地铁汉江沿线)·#1248(京义中央线车窗)。

🙏 船上礼仪——这条路线的核心

  • 不倚靠或攀爬甲板栏杆。听从船员指引。
  • 经过桥下时不要大声喊叫——那会抢走其他乘客听江的声音。
  • 码头建筑和汉江公园是居民的空间。不要在购票队伍中长时间拍摄。
  • 垃圾投入船内分类回收箱。扔进江里更是不可以。

💡 容易懵的点

  • 接驳车没了：麻谷·狎鸥亭·蚕室的免费接驳车已于2026年8月废止。只能从车站步行或搭市内巴士——这也是这一篇把麻谷段定为阳川乡校站步行、蚕室段定为蚕室新川站步行的原因。
  • 狎鸥亭·玉水轮流停靠：视班次只停一处。这一篇本来就是通过，停哪个都不影响，但如果打算下船要先确认班次。
  • 首尔林码头是限时运营：只到2026年10月底。之后可能从时刻表上消失。
  • 票价可能会变：周末·公休日差异化票价正在研议中(截至2026年9月尚未确定)。当天售票机显示的才是准确答案。
  • 换乘等待可能很长：从汝矣岛到下一班东部班次，等待时间可能超过30分钟。3楼咖啡馆或汉江公园可以当候船室。

FAQ 6

Q1. 和游览船有什么不同？

  • 游览船(#704)是往返观光产品，汉江巴士是单程大众交通。刷交通卡上船，在下一个码头下船换乘地铁。票价也只是3,000韩元级别。

Q2. 从麻谷到蚕室能坐同一艘船吗？

  • 不能。必须在汝矣岛下船换乘东部班次。这就是这条路线的结构。

Q3. 全程要多久？

  • 到汝矣岛的西部区间约45分钟，汝矣岛到蚕室的东部区间约1小时20~30分钟上下(视停靠班次而异)。加上换乘等待，总计约3小时30分钟前后。

Q4. 外国人也容易搭乘吗？

  • 售票机支持刷卡·交通卡·有英文指引，运营方推算乘客中约35%为外国人。不过时刻表需要自己确认。

Q5. 下雨怎么办？

  • 气象恶化·八堂大坝放流时停航。请查看当日公告，若停航可改乘地铁汉江沿线(#1256)替代。

Q6. 和南北轴·东西轴怎么衔接？

  • 这艘船会经过南北轴(#1353)的汉南大桥下方，这一篇在东西轴④(#1359)的蚕室铁桥下方结束。三笔在江上相遇。
