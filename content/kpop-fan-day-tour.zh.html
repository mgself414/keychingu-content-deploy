⚠ K-pop粉丝一日路线的5大常见错误

1. 认为“只去SM Town就能看遍K-pop”

外国K-pop粉丝路线的首选是SM Town (COEX / 코엑스)。但实际上，狎鸥亭 (Apgujeong / 압구정) K-pop公司街 (SM·HYBE·YG·JYP·Source Music) + 弘大 (Hongdae / 홍대) Trend Pot K-pop联名店 + 明洞 (Myeongdong / 명동) K-beauty旗舰店 比SM Town更能让外国粉丝满意。只去COEX (코엑스) 可能会浪费时间。

2. 未考虑狎鸥亭 (Apgujeong / 압구정) K-pop公司总部拍照点的地点和时间

SM·HYBE·YG·JYP总部的外部拍照点在位置、可达性和礼仪方面都有所不同。HYBE总部 (位于龙山区 (Yongsan-gu / 용산구) 汉江镇 (Hangangjin / 한강진)) 虽然在外国人中知名度最高，但与江南 (Gangnam / 강남) 路线是分开的 — 需要单独安排行程。SM总部 (位于圣水洞 (Seongsu-dong / 성수동)) 在圣水洞 (Seongsu-dong / 성수동) 内部。YG总部 (位于合井 (Hapjeong / 합정)) 在弘大 (Hongdae / 홍대) 区域。不要试图在一天内看遍所有，选择1-2个即可。

3. 未了解Trend Pot (by Olive Young / 올리브영)

外国K-beauty路线的首选是明洞 (Myeongdong / 명동) Olive Young (올리브영)。但实际上，弘大 (Hongdae / 홍대) Trend Pot (与BTS·NewJeans·SEVENTEEN等K-pop团体合作的限定店) 可以直接购买到明洞 (Myeongdong / 명동) 买不到的限定版周边商品 (굿즈 / goods)。K-pop粉丝必须将明洞 (Myeongdong / 명동) 和Trend Pot (트렌드팟) 结合起来。

4. 时差适应与K-pop粉丝路线时间不匹配

K-pop粉丝抵达韩国的第一天需要适应时差 — 09:00~21:00的行程可能会太累。建议时差适应日 (Day 1) 从下午开始 (只进行 [#19 K-pop追星](content/kpop-fan.md) 中的狎鸥亭 (Apgujeong / 압구정) 散步)，Day 2+ 再进行本一日完整路线。

5. K-pop粉丝路线未结合韩餐·甜点店

只顾着看K-pop而跳过用餐·咖啡馆 → 容易疲劳。必须结合狎鸥亭 (Apgujeong / 압구정) 午餐 ([#206 Mutan / 무탄](content/gangnam-asian-fine-dining.md)) + 江南 (Gangnam / 강남) 咖啡馆 ([#142](content/gangnam-cafe.md)·[#203 Per E Pice / 페르에피스](content/gangnam-cafe-phase2.md)) + 弘大 (Hongdae / 홍대) 甜点 ([#205 K-Cafe特色](content/k-cafe-signature.md))，才能构成真正的一日路线。

K-pop粉丝路线礼仪·注意事项

必备礼仪:

1. 公司总部照片只能在外部拍摄 — 禁止进入内部，禁止拍摄员工

2. K-pop艺人商店排队·商品让步 — 优先考虑韩国粉丝的礼仪

3. Trend Pot (트렌드팟)·SM Town限定周边商品 (굿즈 / goods) 有单人购买限额 — 请确认店内说明

4. K-pop粉丝礼仪 — 声音·噪音·占用 请勿阻碍商店通道

注意事项:

  • K-pop总部外部拍照点请勿使用相机报纸遮挡 (公司礼仪)
  • 周边商品 (굿즈 / goods) 店主要选择支持英文支付的商店 (Trend Pot (트렌드팟)·SM Town)
  • 请提前确认HYBE Insight (하이브 인사이트) 的运营时间 (展览变更频繁)

最终，K-pop粉丝一日路线是

09:00 狎鸥亭 (Apgujeong / 압구정) K-pop公司 → 14:00 SM Town → 17:00 江南 (Gangnam / 강남) 咖啡馆·甜点 → 19:00 弘大 (Hongdae / 홍대) Trend Pot (트렌드팟) → 21:00 夜生活 (nightlife) — 分时段特色路线。

外国K-pop粉丝的真正满意度取决于Trend Pot (트렌드팟) 的限定版商品，而非SM Town。不要去明洞 (Myeongdong / 명동)，优先选择弘大 (Hongdae / 홍대) Trend Pot (트렌드팟)。

通过家庭·单人·情侣等不同变体 + 团体별 (BTS·SM·YG·JYP) 4种变体，覆盖K-pop粉丝从首次访问到再次访问的需求。
