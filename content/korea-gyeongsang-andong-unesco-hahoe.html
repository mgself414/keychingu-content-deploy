ISSUE 04 · #1053 · 2026-06-08

🎯 왜 안동 가이드인가

안동 (Andong) = UNESCO 2010 하회마을 + 양동마을·한국 #1 양반 마을 매트릭스·도산서원 (퇴계 이황)·안동 찜닭·간고등어·하회별신굿탈놀이. 외국인 페인포인트 = (a) "안동 = 안 알려짐" 잘못된 인식 (b) UNESCO 2010 하회마을 + 양동마을 = 한국 양반 매트릭스 #1 (c) 도산서원 = 퇴계 이황 (1501-1570) 매니아 매트릭스 #1 (d) 하회별신굿탈놀이 (1980 무형문화유산)·UNESCO 매니아 (e) 안동 찜닭·간고등어 시그너.

본 가이드는 5축 12 시그니처 + UNESCO + 도산서원 + 찜닭.

🏛 5축 deep dive

① 하회마을 (UNESCO 2010·한국 #1 양반)

  • 시그니처: UNESCO 2010·한국 #1 양반 마을·600년+ 양반 마을·류씨 종택
  • 외국인 친화도: ★★★★★ (영문·다국어 풀세트)
  • 시간: 09:00~18:00·5,000원

② 도산서원 (퇴계 이황·1501-1570)

  • 시그니처: 퇴계 이황 (한국 #1 유학자 매니아 매트릭스 #1)·1560년~
  • 외국인 친화도: ★★★★ (영문·매니아)
  • 시간: 09:00~18:00·1,500원

③ 양동마을 (UNESCO 2010)

  • 시그니처: 경주 인근·한국 양반 매트릭스 #2 (하회 + 양동 = UNESCO 풀세트)
  • 외국인 친화도: ★★★★ (영문·문화 매니아)

④ 안동 찜닭 + 간고등어 (시그너)

  • 시그니처: 한국 #1 찜닭 시그너·안동 간고등어 + 한정식
  • 외국인 친화도: ★★★★ (안 매콤·외국인 입문)
  • 가격: 찜닭 = 25,000~45,000원/2-3인용

⑤ 1박 (한옥 게스트하우스)

  • 시그니처: 하회마을 한옥 + 1박 = 외국인 매니아 매트릭스 #1
  • 가격: 한옥 1박 = 100,000~250,000원/박

⚠ 외국인 자주 실수 5가지

1. "안동 = 안 알려짐": UNESCO 2010 하회마을·한국 양반 매트릭스 #1.

2. "하회마을 = 일반 마을": UNESCO + 600년+ 양반 + 류씨 종택.

3. "도산서원 = 일반 서원": 퇴계 이황 1501-1570·한국 #1 유학자.

4. "찜닭 = 어디서나 동일": 한국 #1 찜닭 시그너 매트릭스·다른 매트릭스.

5. "별신굿탈놀이 = 일반 공연": 1980 무형문화유산·UNESCO 매니아.

⚙ FAQ 6개

1. 외국인 입문 1순위: 하회마을 + 도산서원 + 찜닭 = 1일.

2. 하회별신굿탈놀이: 매주 토 + 일 14:00·무료·매니아 매트릭스.

3. 양동마을 (경주 인근): UNESCO 2010·경주 #1052 cross.

4. 안동 찜닭: 한국 #1 시그너·안 매콤 옵션 OK.

5. 시즌: 봄·가을 베스트.

6. 추천 페르소나: 가족·시니어 = 하회마을 + 찜닭 / MZ·인스타 = 한복 + 카페 / 매니아 = 1박 + 도산서원.

⚠ 의료·안전·식이 disclaimer

안동 = 안전·매니아 친화. 찜닭 = 콩·새우젓 알레르겐 사전 고지. 응급 ☎ 1339·1330.
