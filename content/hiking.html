🎯 왜 서울 등산 가이드인가

서울은 세계에서 도심·산 거리가 가장 가까운 도시 중 하나 — 시청 반경 10km 안 8개+ 산. 외국인 관광객에게 한국 정수 액티비티: 한양도성(UNESCO 잠정 등재)·북한산국립공원·인왕산 정상 view. Reddit r/koreatravel "Bukhansan hike"·"Seoul hiking" 키워드 빈출, YouTube 외국인 vlogger 영상 다수 (시청 5M+). Activity 시리즈 #3 — #146 러닝 / #147 야간 러닝 / #148 등산 묶음.

⚠ 외국인 자주 하는 실수 3가지

1. 운동화로 본격 산 등반 (북한산·도봉산)

남산·낙산은 운동화 OK. 북한산·도봉산은 등산화 필수 — 암릉·계곡·낙엽으로 미끄럼 위험. 대여는 없고 명동·이태원에 데카트론·노스페이스 매장에서 ₩100,000~ 구매 가능.

2. 물·간식 미준비

남산·낙산은 매점 多 OK. 북한산·관악산은 정상까지 매점 0 — 1L 물 + 김밥·초콜릿 준비 필수. 서울 등산 culture: 김밥·막걸리·삶은계란이 정상 시그니처.

3. 북악산 출입증·서울 한양도성 모름

북악산 일부 구간 (청와대 뒤) 출입증 발급 필요 (현장 등록 OK, 신분증 필수). 한양도성은 UNESCO 잠정 등재 18.6km, 6구간 인증 stamp 받기 — 외국인 매니아 인기.

서울 등산 풍경

서울 등산이 외국인 매력적인 이유:

  • 도심·산 거리 < 10km — 지하철에서 30분 안 등산 시작
  • 한양도성 18.6km — UNESCO 잠정 등재, 600년 역사 성벽
  • 북한산국립공원 — 한국 첫 도시 국립공원, 837m
  • 24시간 안전 등산로 — 일부 야간 등산 OK (남산·낙산), 본격 산은 06:00~17:00
  • 시그니처 정상 음식 — 김밥·막걸리·삶은계란·라면 (한국 등산 culture 정수)
  • 무료 입장 — 모든 산 입장료 0 (북한산국립공원 포함)

외국인 4가지 의도:

1. 도심 + 야경 (남산·낙산) — 1~2시간, 야경 best

2. 역사·한양도성 (인왕산·북악산) — 2~3시간, 한국 정수

3. 본격 명산 (북한산·도봉산) — 4~6시간, 매니아 challenge

4. 외곽 + 가성비 (관악산·청계산) — 3~4시간, 강남 근접

4축 매핑

  • ① 도심 입문 (2): 남산·낙산 — 1~2시간, 운동화 OK, 야경 best
  • ② 한양도성·역사 (2): 인왕산·북악산 — 2~3시간, UNESCO 한양도성
  • ③ 본격 명산 (2): 북한산·도봉산 — 4~6시간, 등산화 필수
  • ④ 외곽 매니아 (2): 관악산·청계산 — 3~4시간, 강남·서울대 근접

① 도심 입문 (2 산)

1. 남산 (Namsan, 262m)

외국인 한국 등산 1순위 — 남산타워·케이블카·서울 panorama. 명동에서 도보 10분 시작 → 1~2시간 정상 등반 (계단 위주) → 남산타워 view. 케이블카 대안 (₩14,000 왕복). 야간 OK (조명·CCTV 우수).

  • 시작점: 4호선 명동역·충무로역 도보 10분 (북측순환로 입구)
  • 거리/시간: 등산로 2km / 약 1~2시간
  • 난이도: 입문 (계단 위주, 운동화 OK)
  • 시그니처: 남산타워 + 서울 360° panorama + 케이블카
  • 시간 추천: 일출 5~7시 또는 일몰 18~20시
  • 왜: 외국인 첫 등산 1순위. 케이블카로 등반 부담 0 옵션.

2. 낙산 (Naksan, 125m)

서울에서 가장 낮은 산 — 1시간 도심 산책 + 한양도성 동쪽·야경. 혜화역에서 도보 10분 시작, 낙산공원 정상까지 한양도성 따라 등반. 정상에서 서울 동쪽 panorama. 야경 명소.

  • 시작점: 4호선 혜화역 1번 출구 도보 10분
  • 거리/시간: 1.5km / 약 1시간
  • 난이도: 입문 (가장 쉬움, 운동화·하이힐도 OK)
  • 시그니처: 한양도성 동쪽 + 낙산공원 야경
  • 시간 추천: 일몰 + 야경 18~21시
  • 왜: 가장 짧은 서울 등산. 외국인 가족·연인 + 야경.

② 한양도성·역사 (2 산)

3. 인왕산 (Inwangsan, 338m)

한양도성 정수 + 바위 절경 + 광화문·경복궁 view. 독립문역 또는 경복궁역에서 시작 → 한양도성 따라 등반 → 정상 바위 (선바위·정상바위) view. 외국인 한국 역사·자연 매니아.

  • 시작점: 3호선 독립문역 또는 경복궁역
  • 거리/시간: 4km / 약 2~3시간
  • 난이도: 중급 (바위 일부, 운동화·등산화)
  • 시그니처: 한양도성 + 바위 절경 + 경복궁 view
  • 시간 추천: 오전 9~12시 (일출 + 한산)
  • 왜: 한국 정수 산. UNESCO 한양도성 정수 구간.

4. 북악산 (Bukaksan, 342m)

청와대 뒤·UNESCO 한양도성·일부 출입증. 자하문 또는 말바위 입구에서 시작. 청와대 뒤 구간은 신분증 등록 필요 (현장 출입증, 외국인은 여권). 한양도성 북쪽 구간 절경.

  • 시작점: 자하문 안내소 또는 말바위 안내소 (3호선 안국역 도보 30분)
  • 거리/시간: 4.7km / 약 2~3시간
  • 난이도: 중급
  • 시그니처: 청와대 뒤 + UNESCO 한양도성 북쪽
  • 시간 추천: 09:00~16:00 (출입 시간)
  • 왜: 청와대 뒤 한국 정수 + 한양도성 정수 구간 동시.

③ 본격 명산 (2 산)

5. 북한산 (Bukhansan, 백운대 837m)

한국 첫 도시 국립공원 — 837m 정상 백운대. 다양한 코스 (북한산성·우이·정릉·구파발 등 10+). 정상 백운대 암릉 + 산성·계곡·사찰. 외국인 본격 등산 1순위. 등산화 필수.

  • 시작점: 북한산성 입구 (구파발역 버스) 또는 우이동 입구 (4호선 우이신설선)
  • 거리/시간: 8~10km 왕복 / 약 4~6시간
  • 난이도: 고급 (암릉, 등산화 필수)
  • 시그니처: 백운대 정상·산성·계곡
  • 시간 추천: 06:00~12:00 출발 (정상 일출 가능)
  • 왜: 한국 도시 국립공원 본격 등산 정수. 외국인 등산 매니아 1순위.

6. 도봉산 (Dobongsan, 자운봉 740m)

북한산 옆 암릉 절경 — 자운봉·만장봉. 도봉산역 도보 5분 시작. 북한산보다 험준한 암릉·바위 코스. 외국인 매니아·중상급 등산객 best.

  • 시작점: 1호선·7호선 도봉산역
  • 거리/시간: 6~8km 왕복 / 약 4~5시간
  • 난이도: 고급 (암릉·바위, 등산화 필수)
  • 시그니처: 자운봉·만장봉 절경
  • 시간 추천: 06:00~12:00
  • 왜: 북한산과 다른 톤의 본격 산. 암릉 매니아.

④ 외곽 매니아 (2 산)

7. 관악산 (Gwanaksan, 연주대 632m)

서울대 뒤·연주대 절경. 서울대입구역에서 시작, 연주대(절+정상) 등반. 봄 진달래·가을 단풍 시즌 절정. 외국인 강남 일대 + 등산 결합.

  • 시작점: 2호선 서울대입구역 도보 + 버스
  • 거리/시간: 7~9km / 약 3~4시간
  • 난이도: 중상급 (암릉 일부)
  • 시그니처: 연주대 + 서울대 + 봄 진달래
  • 시간 추천: 봄·가을 오전
  • 왜: 강남 근접 + 정상 절경. 강남 관광 + 등산 결합.

8. 청계산 (Cheonggyesan, 618m)

매봉·옥녀봉·강남 근접. 양재시민의숲역에서 시작, 매봉(582m)·옥녀봉(376m) 등 다양한 코스. 가족·입문 친화 (관악산보다 완만). 강남 코스 + 등산 결합 best.

  • 시작점: 신분당선 양재시민의숲역
  • 거리/시간: 5~7km / 약 3~4시간
  • 난이도: 중급 (완만, 운동화·등산화)
  • 시그니처: 매봉·옥녀봉·강남 panorama
  • 시간 추천: 오전 9~12시
  • 왜: 강남 가족·입문 친화. 관악산보다 완만한 외곽 산.

⚙ FAQ 8개

Q1. 외국인 등산 신분증 필요?

북악산 (청와대 뒤 구간) — 여권 필수. 현장 등록 OK. 북한산국립공원·도봉산 — 무료, 신분증 X. 그 외 산도 신분증 X. 한양도성 인증 stamp 받으려면 일부 매니아 코스에서 신분증 OK.

Q2. 등산화·등산 장비 어디서?

  • 데카트론 (강남·잠실) — 가성비 등산화 ₩50,000~₩100,000
  • 노스페이스·콜핑·블랙야크 (명동·이태원) — 정통 등산화 ₩150,000~₩300,000
  • 호텔 ID 카드 + 등산화 대여 — 일부 호텔 (외국인 친화 호텔만)
  • 다이소 — 등산 양말·작은 배낭 가성비

Q3. 시간대 best?

  • 봄·가을: 오전 8~10시 (일출 + 한산)
  • 여름 (7~8월): 새벽 5~7시 (폭염 회피)
  • 겨울 (12~2월): 10~14시 (가장 따뜻, 등반 안전)
  • 북악산 — 09:00~16:00 출입 시간 엄수

Q4. 한국 정상 음식 culture?

  • 김밥 (₩4,000~₩6,000) — 등산 1번 음식, 정상 도착 후 먹기
  • 막걸리 + 삶은계란 — 한국 등산 culture 정수 (정상 막걸리 한 잔)
  • 컵라면 — 매점 ₩3,000~₩4,000 (북한산 일부 정상 매점)
  • 초콜릿·바나나 — 등반 중 간식

Q5. 비 오는 날·악천후?

남산·낙산 — 우산 OK. 인왕산·북악산 — 우산 가능하나 바위 미끄럼 위험. 북한산·도봉산·관악산 — 절대 X (낙뢰·미끄럼·낙엽 위험). 비 예보 시 박물관·DDP 대체.

Q6. 외국인 등산크루?

Seoul Hash House Harriers (주간 토요일) + Korea Hiking Club (Facebook 그룹). 영어 가능. 북한산·도봉산 본격 코스 가이드 함께.

Q7. 한양도성 18.6km 한 번에?

한양도성 18.6km는 4~6 구간 분할 권장 (북악산·인왕산·낙산·남산 등). 한 번에는 12~14시간 — 매니아만. 북정마을 인증센터에서 stamp 받기 (외국인 매니아 인기).

Q8. 등산 후 마무리 (음식·온천·찜질방)?

  • 북한산성·우이동 — 막걸리·파전 노포 다수
  • 남산 — 명동 칼국수·왕만두 (#134 만두 가이드)
  • 인왕산 — 광화문 국밥 (#133 가이드)
  • 찜질방 — 양재·잠실·홍대 — 등산 후 시그니처 (#7 찜질방 가이드)

🗺 추천 1일 등산+관광 코스 3가지

A코스 — "도심 입문 + 야경" (외국인 입문, 5시간)

오후 14:00 → 남산 1.5시간 등반 (계단 코스) → 남산타워 view → 케이블카 하강 → 명동 저녁 → 야경 시즌이면 낙산 1시간 추가 (혜화역 도보)

B코스 — "한양도성 deep dive" (역사·등산 매니아, 6시간)

아침 8:00 → 인왕산 2.5시간 (독립문 시작 → 정상 → 한양도성 따라 자하문 안내소) → 북악산 연결 2시간 (청와대 뒤 구간) → 자하문 → 광화문 점심 → 한양도성 stamp 인증

C코스 — "북한산 본격" (등산 매니아, 풀 day 8시간)

아침 6:00 → 북한산성 입구 → 북한산 백운대 5시간 왕복 (정상 일출 옵션) → 산성 + 계곡 → 우이동 막걸리 마무리 → 호텔

🌸 시즌·시간대 훅 5개

1. 봄 (4~5월) 진달래·벚꽃: 인왕산·관악산 진달래 절정. 4월 말 ~5월 초.

2. 여름 (7~8월) 새벽 일출: 폭염 회피 + 일출 view. 남산·인왕산·북한산 새벽 5~7시.

3. 가을 (10~11월) 단풍: 북한산·도봉산·청계산 단풍 절정. 10월 말 ~11월 중순. 사진 시즌 best.

4. 겨울 (12~2월) 눈 등반: 북한산·도봉산 눈꽃 절경. 등산화·아이젠 필수.

5. 사계절 야경: 남산·낙산 야경 24시간 OK (조명·CCTV). 외국인 야간 등산 안전.
