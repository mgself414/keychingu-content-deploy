🎯 为何推出江东·千户 (Gangdong·Cheonho) 独立指南

江东·千户 (Gangdong·Cheonho / 강동·천호) 是江东区 (Gangdong-gu / 강동구) 的韩国史前·百济历史第一区·汉江东部·中产家庭聚集区 — 岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) (韩国新石器时代第一遗址，1925年发掘) + 风纳土城 (Pungnaptoseong / 풍납토성) (百济都城遗址，史迹第11号) + 千户汉江公园·广津渡口 (Cheonho Hangang Gongwon·Gwangnaru / 천호 한강공원·광나루) (汉江东部) + 江东I'PARK THE RIVER MALL (Gangdong Aipakeu Deo Ribeo Mol / 강동아이파크더리버몰)·千户罗德奥街 (Cheonho Rodeo Geori / 천호 로데오거리) (江东青年热门区) 浓缩于一区。这里融合了韩国史前·百济历史深度游 + 汉江东部 + 外国游客家庭友好元素。

与弘大 (Hongdae / 홍대) (MZ世代·独立文化)、江南 (Gangnam / 강남) (奢华)、梨泰院 (Itaewon / 이태원) (国际化) 相比，江东·千户 (Gangdong·Cheonho) 具有史前·百济·汉江东部的特色。在外国游客的行程中，它常被蚕室 (Jamsil / 잠실) 掩盖而错过，但岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) 是韩国新石器时代深度游的第一站 (1925年发掘，6,000年前的栉纹陶器 (빗살무늬토기，韩国新石器时代最具代表性的陶器，表面有梳齿状纹路)) + 风纳土城 (Pungnaptoseong / 풍납토성)·梦村土城 (Mongchontoseong / 몽촌토성) 是百济汉城都城遗址 (韩国四大古国深度游)。继 [#138 弘大](138_hongdae_guide.md)·[#173 瑞草](173_seocho_guide.md)·[#174 首尔大](174_seoul_university_guide.md)·[#178 广津](178_gwangjin_guide.md)·[#180 九老](180_guro_guide.md)·[#181 铜雀](181_dongjak_guide.md)·[#182 恩平](182_eunpyeong_guide.md) 之后，ISSUE 03 第21篇 — KeyChinGu首次进入江东区 (Gangdong-gu / 강동구) (共87个地点)。

特别是岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) 是外国游客韩国历史深度游的第一站 (韩国新石器·青铜器·铁器综合博物馆)。千户罗德奥街 (Cheonho Rodeo Geori / 천호 로데오거리) 是江东 (Gangdong / 강동) 青年·MZ世代 (MZ世代，指千禧一代和Z世代，即1980年代初至2000年代初出生的人群) 的热门区。毗邻遁村奥林匹克公园 (Dunchon Ollimpik Pateu / 둔촌 올림픽파크) (蚕室 (Jamsil / 잠실) 东部)。是 [#82 蚕室](82_jamsil_guide.md) 的姊妹区域。

⚠ 外国人常犯的3个错误

1. “江东 (Gangdong / 강동) = 蚕室 (Jamsil / 잠실) 附近，只看蚕室 (Jamsil / 잠실) 就行” — 未认识到江东 (Gangdong / 강동) 的独特价值

这是外国游客行程中最常见的错误。他们将江东 (Gangdong / 강동) 仅视为“蚕室 (Jamsil / 잠실) 旁边”而跳过，但实际上，江东 (Gangdong / 강东) 是韩国史前·百济历史第一区 — 岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) (韩国新石器第一区，1925年发掘) + 风纳土城 (Pungnaptoseong / 풍납토성) (百济汉城都城) + 梦村土城 (Mongchontoseong / 몽촌토성) = 韩国6,000年历史深度游。这与蚕室 (Jamsil / 잠실) (现代主题公园) 有着不同的特色。遁村奥林匹克公园 (Dunchon Ollimpik Pateu / 둔촌 올림픽파크) 是蚕室 (Jamsil / 잠실) 的姊妹区域。

2. “岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) = 只是遗址” — 未认识到韩国新石器第一区的价值

岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) 是1925年发掘的韩国第一史前遗址 — 韩国新石器·青铜器·铁器综合遗址。栉纹陶器 (빗살무늬토기) (6,000年前，韩国最早的陶器) + 窝棚复原 = 外国游客韩国古代史深度游的首选。从岩寺站 (Amsa-yeok / 암사역) 4号出口步行10分钟，门票1,000韩元 (₩1,000 (~$0.75 / ~5 RMB / ~110 JPY)) (提供英文导览 + 博物馆一体化)。

3. “千户 (Cheonho / 천호) = 只是个社区” — 未认识到汉江东部青年热门区的价值

千户 (Cheonho / 천호) 不仅仅是一个社区，更是江东 (Gangdong / 강동) 青年·MZ世代的热门区 — 千户罗德奥街 (Cheonho Rodeo Geori / 천호 로데오거리) + 江东I'PARK THE RIVER MALL (Gangdong Aipakeu Deo Ribeo Mol / 강동아이파크더리버몰) (汉江景观购物中心) + 咖啡馆·特色酒馆·居酒屋热门区。5号线·8号线千户站 (Cheonho-yeok / 천호역) 换乘站 + 毗邻江一 (Gangil / 강일)·岩寺 (Amsa / 암사) 新城。距离蚕室 (Jamsil / 잠실) (2号线) 仅5分钟路程。

江东·千户 (Gangdong·Cheonho) 风景

江东·千户 (Gangdong·Cheonho / 강동·천호) 位于江东区 (Gangdong-gu / 강동구) 东部·西部，是韩国史前·百济历史 + 汉江东部 + 家庭社区结合区 — 1925年岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) 发掘 + 百济汉城 (公元前18年~公元475年) 风纳 (Pungnap / 풍납)·梦村土城 (Mongchon / 몽촌) 遗址 + 2010年代千户 (Cheonho / 천호)·江一 (Gangil / 강일) 新城 + 江东I'PARK THE RIVER MALL (Gangdong Aipakeu Deo Ribeo Mol / 강동아이파크더리버몰) (2014年) 开业，使其成为韩国古代史深度游 + 江东现代结合区。

岩寺 (Amsa / 암사)·风纳 (Pungnap / 풍납) 子区域位于8号线岩寺站 (Amsa-yeok / 암사역)·5号线千户站 (Cheonho-yeok / 천호역) 附近 — 岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) (新石器) + 风纳土城 (Pungnaptoseong / 풍납토성) (百济) + 韩国6,000年历史深度游第一站。

千户 (Cheonho / 천호)·江一 (Gangil / 강일) 子区域位于5号线·8号线千户站 (Cheonho-yeok / 천호역)·9号线江一站 (Gangil-yeok / 강일역) — 千户罗德奥街 (Cheonho Rodeo Geori / 천호 로데오거리) + 江东I'PARK THE RIVER MALL (Gangdong Aipakeu Deo Ribeo Mol / 강동아이파크더리버몰) (汉江景观) + 咖啡馆·特色酒馆热门区。

高德 (Godeok / 고덕)·明逸 (Myeongil / 명일) 子区域位于5号线高德站 (Godeok-yeok / 고덕역)·明逸站 (Myeongil-yeok / 명일역) — 高德商务谷·宜家江东·公寓小区 + 家庭社区。

遁村 (Dunchon / 둔촌)·吉洞 (Gil-dong / 길동) 子区域位于5号线遁村洞站 (Dunchon-dong-yeok / 둔촌동역)·吉洞站 (Gil-dong-yeok / 길동역) — 遁村奥林匹克公园 (Dunchon Ollimpik Pateu / 둔촌 올림픽파크) + 吉洞 (Gil-dong / 길동) 韩餐传统。

广津渡口 (Gwangnaru / 광나루) 子区域位于5号线广津渡口站 (Gwangnaru-yeok / 광나루역) + 汉江东部自行车道。

交通: 5号线·8号线千户站 (Cheonho-yeok / 천호역) (千户 (Cheonho / 천호)·罗德奥 (Rodeo / 로데오)) / 8号线岩寺站 (Amsa-yeok / 암사역) (史前遗址·风纳土城 (Pungnaptoseong / 풍납토성)) / 5号线高德站 (Godeok-yeok / 고덕역)·明逸站 (Myeongil-yeok / 명일역) (高德 (Godeok / 고덕)·宜家) / 5号线遁村洞站 (Dunchon-dong-yeok / 둔촌동역) (奥林匹克公园) / 9号线江一站 (Gangil-yeok / 강일역)。推荐使用Kakao出租车 (Kakao Taeksi / 카카오 택시)。

⚙ 常见问题 (8个)

Q1. 外国人可以参观岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) 吗？

1,000韩元 (₩1,000 (~$0.75 / ~5 RMB / ~110 JPY)) (外国人同价) / 09:30~18:00 (周一休息)。提供英文导览 + 博物馆一体化 (新石器·青铜器·铁器)。6,000年前的栉纹陶器 (빗살무늬토기)·窝棚复原是首选。8号线岩寺站 (Amsa-yeok / 암사역) 4号出口步行10分钟。

Q2. 如何参观风纳土城 (Pungnaptoseong / 풍납토성)？

免费 + 24小时 (可沿土城散步) — 风纳洞 (Pungnap-dong / 풍납동) 一带约3.5公里。汉城百济博物馆 (Hanseong Baekje Bangmulgwan / 한성백제박물관) (松坡区 (Songpa-gu / 송파구)·梦村土城站 (Mongchontoseong-yeok / 몽촌토성역) 附近，免费) 深度游首选。提供英文导览 + 韩国四大古国百济深度游。

Q3. 江东 (Gangdong / 강동) 汉江自行车路线是？

广津渡口 (Gwangnaru / 광나루) → 千户 (Cheonho / 천호) → 蚕室 (Jamsil / 잠실) → 纛岛 (Ttukseom / 뚝섬) → 盘浦 (Banpo / 반포) → 汝矣岛 (Yeouido / 여의도) = 约30公里汉江自行车道 (韩国第一自行车路线)。广津渡口 (Gwangnaru / 광나루) 是汉江自行车东部起点 + 可租借Ttareungi (따릉이，首尔市公共自行车租赁服务)。[#149 自行车指南](149_seoul_bike_guide.md) 的东部起点。

Q4. 江东 (Gangdong / 강동)·千户 (Cheonho / 천호) 有哪些外国人友好商店？

Daram 江东总店 (Daram Gangdong Bonjeom / 다람 강동본점)·河南猪肉店 (Hanam Dwaejijip / 하남돼지집)·Sushi Doku (스시도쿠)·浣熊贝果 (Neoguri Beigeul / 너구리베이글)·Little Chastwood (Liteul Chaeseuudeu / 리틀채스우드) 提供英文菜单 + 银行卡支付 + 外国人友好标准。119鸡爪 (119 Dakbal / 119닭발) 是韩国挑战美食，是外国人Vlog首选。

Q5. 江东 (Gangdong / 강동) + 蚕室 (Jamsil / 잠실) 可以连接吗？

可以 — 江东 (Gangdong / 강동) (5·8号线) → 蚕室 (Jamsil / 잠실) (8号线2站) = 地铁5分钟。岩寺史前遗址 (Amsa Seonsa Yujeokji / 암사 선사유적지) + 风纳土城 (Pungnaptoseong / 풍납토성) (江东 (Gangdong / 강동)) + 梦村土城 (Mongchontoseong / 몽촌토성) + 遁村奥林匹克公园 (Dunchon Ollimpik Pateu / 둔촌 올림픽파크) + 蚕室 (Jamsil / 잠실) (松坡 (Songpa / 송파)) = 一日韩国古代史·汉江东部全套行程。

Q6. 119鸡爪 (119 Dakbal / 119닭발) 的辣度外国人能接受吗？

可选3种辣度 (微辣·普通·特辣)。建议外国人从微辣开始尝试。这是韩国Vlog·吃播中经常出现的外国人挑战美食。支持银行卡支付 + 部分英文菜单。

Q7. 江东I'PARK THE RIVER MALL (Gangdong I-Park The River Mall / 강동아이파크더리버몰) 免税吗？

部分商店支持外国人即时免税退税 (满30,000韩元 (₩30,000 (~$22 / ~160 RMB / ~3,300 JPY)) 以上 + 护照)。汉江景观购物中心 (2014年) + 咖啡馆·餐厅·电影院一应俱全。千户站 (Cheonho-yeok / 천호역) 步行5分钟。

Q8. 江东 (Gangdong / 강동) 夜间安全吗？

24小时安全 — 江东 (Gangdong / 강동) 是韩国中产阶级·家庭社区 + CCTV·便衣警察 (sabok gyeongchal) 标准配置。外国人夜间出行安全。午夜后建议使用Kakao出租车 (Kakao Taeksi / 카카오 택시)。
