＃＃🙏韓国の会食マナーの7つのコア

会食・砲車マナー

1. 乾杯=杯位置: 大人より少し低く(伝統)

2. 自分の杯を埋める X: 他の人が従う

3. 両手フォロー/受け取り: 大人に本物のマナー

4. 頭を回して飲む: 大人前正統派(現代=強要X)

5. ペース調整: 1～2時間以内のカップ2～3個推奨

6. 強制拒否OK：現代韓国の会食=強要拒否マナー違反ではない

7. 深夜マナー: 22:00以降 = 静か + 隣人の配慮

＃＃⚠外国人の頻繁なミス7つ

1. 「砲車＝汚れ」：乙支路路地・鍾路砲車＝観光地店舗定期点検・衛生良好。

2. 「ノガリ＝魚のみ」：ノガリ＝明太子干し・塩・塩味＝ビールフェア本物#1。

3. 「薪 = 日本モツ」: 韓国の薪 = 味付け + 焼き = 他の食べ物。馬場洞入門。

4. 「コウナギ=一般ウナギ」:コムウナギ= 釜山マコム味付け焼き（淡水ウナギとは異なる）。

5. "強制拒否 = マナー違反": 現代韓国 = 強制拒否 OK。 「I don't drink」直接拒否。

6. "飲酒運転 = 軽さ": 韓国 0.03% BAC = 免許停止 (取り締まり強力)。

7. 「深夜マナー＝自由」：22:00以降＝静か・近所配慮本格。

⚙ よくある質問8件

1. 最初の砲車=どこ: をジロノガリ路地 1ランク(外国人vlog#1)。

2. インスタ・vlog：乙支路ノガリ路地・広場市場全+マッコリ・釜山コムウナギ。

3. MZトレンド：乙支路ノガリ路地MZ vlog・ペアリングインスタ。

4. 会食二次愛好家: ノガリホープ+カール+鉄板ホープ。

5. 飲酒マナー: 強要拒否 OK・ペース調整・深夜 22:00 静かなマナー。

6. 飲酒運転: 0.03% BAC免許停止・19歳未満の法的飲酒禁止。

7. アレルギー：シーフード・大豆・卵・ナッツ・スパイシーな味付け事前告知。

8. 決済・チップ:カードOK / 砲車 = 一部現金 / カカオペイ・トス送金 / チップX。

⚠医療・安全・法律 disclaimer

夜食・おつまみ＝夜間食事（消化↓・睡眠影響）。妊婦 = 酒X・腱窓・内臓 = 医療スタッフ相談。子供= 夜の砲車X（酒の雰囲気）。アレルギー（シーフード・大豆・卵・ナッツ類）事前通知。 飲酒運転0.03％BAC免許停止+刑事処罰（韓国取り締まり強力）。 19歳未満=法的飲酒禁止。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

老舗・店舗情報免責: 砲車・ノガリ路地営業時間・メニュー変動 — 訪問前NAVER/Kakao mapまたは公式サイト確認。

食事制限 fallback:

  • ハラール・コーシャー：一般のつまみ＝ビハラル。 →イテウォン一部ハラール店OR ベジタリアン・フルーツのおつまみ。
  • ベジタリアン・ビーガン: 緑豆前・カボチャ前・キムチジョン(オムク減算) =ベジタリアン可能。
  • グルテンフリー: 全・味付け（醤油）多。事前店舗確認。
