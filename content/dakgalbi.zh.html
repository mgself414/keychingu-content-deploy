外国游客常见的3个误区

1. 把鸡排 (Dakgalbi / 닭갈비) 当成普通韩式烤肉

鸡排是在铁板上与卷心菜、红薯、年糕一起翻炒的料理——不是烤肉，准确说法是"铁板炒菜"。店员会亲自翻炒，如果自己动手，店员可能会过来重新整理。初次光顾，交给店员操作最为稳妥。

2. 不点收尾炒饭 (Bokkeumbap / 볶음밥)

鸡排的灵魂在于用剩余酱汁加米饭、海苔、芝士一起翻炒的收尾炒饭（另收 ₩2,000~₩3,000）。不点这道就等于错过了鸡排体验的50%。韩国美食家所说"鸡排=炒饭"正是这个道理。

3. 未确认是否支持单人点餐

유가네 (Yoogane / 유가네)、明洞连锁店支持单人点餐。우리집 (Urijip / 우리집)、1.5닭갈비 (1.5 Dakgalbi / 1.5닭갈비) 等正宗老店建议至少2人份起点（因为卷心菜、年糕等配菜分量较大）。单人前往务必提前确认。

2. 精选8家（四大维度均衡覆盖）

2-1. 春川式正宗老店2家 — 鸡排发源地

① 우리집 닭갈비 (Urijip Dakgalbi / 우리집 닭갈비) — 春川明洞 (Chuncheon Myeongdong / 춘천 명동)

鸡排发源地1960年代老字号。从春川站 (Chuncheon Station / 춘천역) 或南春川站 (Namchuncheon Station / 남춘천역) 乘市内巴士约10分钟，即达明洞鸡排一条街。人均 ₩15,000~₩18,000。春川式正宗——卷心菜、红薯、年糕、芝麻叶搭配鸡腿肉腌制翻炒。推荐4~6人家庭团体。从首尔乘KTX约1小时再加市内交通，适合半日游。提供英文菜单，支持刷卡。鸡排美食爱好者的朝圣第一站。

② 1.5닭갈비 (1.5 Dakgalbi / 1.5닭갈비) — 春川明洞 (Chuncheon Myeongdong / 춘천 명동)

1990年代起以1.5人份（1人份+0.5人份）为概念的春川式正宗老店。位于春川明洞鸡排一条街。人均 ₩14,000~。相比우리집 (Urijip / 우리집)，腌料稍辣，年糕·芝士配料深受欢迎。支持单人点餐（顾名思义，以1.5人份为单位点餐）。外国游客友好度高，提供英文·中文菜单。

2-2. 首尔MZ潮流店2家 — K-剧·SNS打卡热点

③ 유명산 닭갈비 (Yumyeongsan Dakgalbi / 유명산 닭갈비) — 弘大 (Hongdae / 홍대)

弘大MZ + K-剧取景地，SNS超高人气。弘大入口站 (Hongik University Station / 홍대입구역) 9号出口步行5分钟。人均 ₩16,000~。芝士鸡排 + 拉面配料 + 收尾炒饭三连套餐为招牌组合。深受K-偶像·K-剧粉丝喜爱——据悉 TWICE (트와이스)·BLACKPINK (블랙핑크) 均曾到访。支持单人点餐，提供英文·中文·日文菜单。

④ 부담이 (Budamyi / 부담이) — 江南 (Gangnam / 강남)

江南MZ新兴潮流鸡排店。江南站 (Gangnam Station / 강남역) 11号出口步行4分钟。人均 ₩18,000~。INS打卡热点——马苏里拉芝士瀑布 + 黑猪肉配菜 + 炒年糕三重组合。Instagram及Reels曝光频率极高。平日午餐需排队30分钟~1小时，周末晚间需排队2小时以上。建议提前1周预约，支持单人。

2-3. 老字号性价比2家 — 外国游客初次光顾安心之选

⑤ 명동 춘천닭갈비 (Myeongdong Chuncheon Dakgalbi / 명동 춘천닭갈비) — 明洞 (Myeongdong / 명동)

明洞观光动线首选鸡排店。明洞站 (Myeongdong Station / 명동역) 6号出口步行3分钟。人均 ₩14,000~。春川老店分店概念——正宗腌料 + 明洞动线便利兼得。接待外国游客经验丰富，提供英文·中文·日文菜单，部分员工可用英语·中文沟通。支持单人，基本不接受预约（现场排队约30分钟以内）。适合初次来访的外国游客及团体观光路线。

⑥ 새벽집 닭갈비 (Saebyeokjip Dakgalbi / 새벽집 닭갈비) — 新论岘 (Sinnonhyeon / 신논현)

24小时营业的鸡排老字号。新论岘站 (Sinnonhyeon Station / 신논현역) 6号出口步行5分钟。人均 ₩15,000~。营业至凌晨1~3点——深受MZ深夜聚餐收尾及夜间观光客欢迎。鸡排 + 米酒 + 收尾炒饭套餐为招牌。推荐外国游客深夜游览路线。

2-4. 连锁·24h共2家 — 性价比 + 外国游客友好

⑦ 유가네 닭갈비 (Yoogane Dakgalbi / 유가네 닭갈비) — 全国连锁

外国游客认知度第一的鸡排连锁品牌。明洞·弘大·梨泰院 (Itaewon / 이태원)·江南等全国50+门店。人均 ₩12,000~₩15,000。春川式正宗腌料 + 用餐时限（60~90分钟）+ 外国游客友好运营。所有门店均提供英文·中文·日文菜单，员工英语应对熟练。支持单人，无需预约，支持刷卡及移动支付。外国游客初次光顾 + 性价比 + 团体观光首推No.1。

⑧ 봉추찜닭 (Bongchu Jjimdak / 봉추찜닭) — 全国连锁（含鸡排菜单）

以安东炖鸡为主的连锁品牌，同时提供鸡排菜单——安东炖鸡 (Andong Jjimdak / 안동찜닭) 正宗老店。全国30+门店。人均 ₩14,000~。可同时比较炖鸡 (Jjimdak / 찜닭)·鸡排 (Dakgalbi / 닭갈비)·全鸡汤 (Dakhanmari / 닭한마리) 三大菜品。外国游客友好度高，提供英文菜单，支持单人。推荐作为韩式鸡肉料理综合入门门店。

4. 常见问题8问

Q1. 可以自己翻炒鸡排吗？

A. 正宗老店（우리집 (Urijip / 우리집)·1.5닭갈비 (1.5 Dakgalbi / 1.5닭갈비)）由店员代为翻炒——自己动手店员会重新整理。连锁店（유가네 (Yoogane / 유가네)·明洞）可以自行操作。耐心等待才是正规做法，这正是"韩国鸡排文化"的核心体验。

Q2. 哪些门店支持单人就餐？

A. 连锁及潮流店均支持单人（유가네 (Yoogane / 유가네)·明洞·새벽집 (Saebyeokjip / 새벽집)·유명산 (Yumyeongsan / 유명산)·부담이 (Budamyi / 부담이)）。正宗老店（우리집 (Urijip / 우리집)·1.5닭갈비 (1.5 Dakgalbi / 1.5닭갈비)）建议2人份起点。单人前往推荐명동 춘천닭갈비 (Myeongdong Chuncheon Dakgalbi / 명동 춘천닭갈비) 或유가네 (Yoogane / 유가네)。

Q3. 收尾炒饭一定要点吗？

A. 务必要点（另收 ₩2,000~₩3,000）。这才是鸡排的真正灵魂。店员在残余酱汁的铁板上翻炒米饭、海苔、鸡蛋、芝士的那1分钟，正是韩国美食体验的精华所在。

Q4. 可以调整辣度吗？

A. 8家门店均可选择"半量腌料（减半辣度）"。不太能吃辣的外国游客选유가네 (Yoogane / 유가네) 或명동 춘천닭갈비 (Myeongdong Chuncheon Dakgalbi / 명동 춘천닭갈비) 最为安心——腌料浓度调整经验丰富。부담이 (Budamyi / 부담이) 辣度较强，请提前确认。

Q5. 有英文菜单及英语服务吗？

A. 所有门店均提供英文菜单。英语应对最为熟练的是유가네 (Yoogane / 유가네)·명동 춘천닭갈비 (Myeongdong Chuncheon Dakgalbi / 명동 춘천닭갈비)·유명산 (Yumyeongsan / 유명산)·봉추찜닭 (Bongchu Jjimdak / 봉추찜닭)。우리집 (Urijip / 우리집)·1.5닭갈비 (1.5 Dakgalbi / 1.5닭갈비)（春川老店）以韩语为主，配有图片菜单。

Q6. 一人份的量够吗？

A. 一般一人份鸡排约为鸡腿肉200~250g + 配菜蔬菜。外国游客通常反映分量充足。若加点收尾炒饭，人均约 ₩18,000~₩22,000（饮料另计）。

Q7. 可以吃素食或清真食品吗？

A. 鸡排本身含鸡肉，无法满足素食需求。部分门店（유가네 (Yoogane / 유가네)·봉추찜닭 (Bongchu Jjimdak / 봉추찜닭)）提供素食选项——仅限单独点蔬菜、拉面或面条。韩国鸡排店几乎不提供清真认证。

Q8. 鸡排搭配米酒还是烧酒？

A. 春川式鸡排 = 米酒 (Makgeolli / 막걸리)（传统搭配）。辛辣腌料与米酒甘甜相互平衡。烧酒 (Soju / 소주) 更适合MZ潮流店（부담이 (Budamyi / 부담이)·유명산 (Yumyeongsan / 유명산)）。새벽집 닭갈비 (Saebyeokjip Dakgalbi / 새벽집 닭갈비) 则米酒·烧酒均受欢迎。
