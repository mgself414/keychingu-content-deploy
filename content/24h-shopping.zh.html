41 · 24小时购物地图 — 首尔夜晚购物不间断的秘密

> 主清单 ID: 054 (F-Shopping) · 优先级: P1 · 目标: CN● · JP○ · EN○

> 来源: souvenir_research / 31_dongdaemun_night_shopping / 韩国观光公社统计 (키친구 자료/데이터/souvenir_research/50_seoul_cluster_map.json)

一句话简介

首尔以东大门 (Dongdaemun / 동대문) + 便利店 (Pyeonuijeom / 편의점) + 机场三大支柱，实现了事实上的24小时购物。过了一般门店打烊时间 (22:00)，即便是凌晨5点，无需现金、退税手续一气呵成的路线，全部浓缩在这一张地图里。

> 💡 便利店 (Pyeonuijeom / 편의점) — 类似中国24小时便利店，但韩国便利店密度极高，几乎每隔50米一家，是旅行者深夜购物的"最后防线"。

推荐对象

  • 因深夜中转候机在首尔停留6~12小时的独立旅行者 (FIT)
  • 跟团行程结束后自由活动时间仅在22:00以后的中国·日本游客
  • 为批发时尚大量采购、专程赴东大门 (Dongdaemun / 동대문) 凌晨市场的买手
  • 当天夜班机出发前需要最后一刻购物的访客

1. 首尔24小时购物三大支柱

支柱 代表区域 核心时段 主要品类 本指南对应章节
批发·零售时尚 东大门 (Dongdaemun / 동대문) 22:00 ~ 05:00 K-时尚、面料、配饰 §2
便利店24小时 明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남) + 全市 24小时 K-food、零食、日用品 §3
机场免税店 仁川机场 (Incheon Airport / 인천공항) T1·T2 入境厅/出境厅 05:30 ~ 23:00 + 部分24小时 免税K-Beauty、酒类、烟草 §4

韩国一般零售门店标准营业时间为 10:00~22:00。除三大支柱外，几乎所有门店均在22:00关门。换言之，22:00之后"去购物"，意味着前往这三大支柱之一。

2. 东大门 (Dongdaemun / 동대문) — 首尔夜间时尚心脏

深度指南: 参见 31_dongdaemun_night_shopping.md (本地图仅作摘要·导航用)

2-2. 东大门凌晨路线 (23:00 → 04:00)

1. 23:00 — 地铁2号线 东大门历史文化公园站 (Dongdaemun History & Culture Park Station / 동대문역사문화공원역) 14号出口，步行3分钟至斗塔免税店 (Doota! Mall / 두타면세점)

2. 23:30 — 从斗塔8楼向下逛 (5楼女装·4楼男装·3楼杂货)

3. 01:00 — 步行5分钟前往 APM Luxe (APM Luxe / APM Luxe)，深夜买手专属店铺云集

4. 02:30 — 米格里奥雷 (Migliore / 밀리오레) 地下1楼宵夜区 (韩式汤饭·拉面 ₩5,000~8,000，约30~50 RMB)

5. 03:30 — 光熙商街 (Kwanghee Arcade / 광희상가) 批发扫货。个人购买务必询问"能否单件"并议价

6. 04:30 — 步行8分钟前往 DDP (DDP / 동대문디자인플라자) 夜景拍照，之后搭乘东大门站 (Dongdaemun Station / 동대문역) 4号线首班车 05:30

> 💡 首次出现价格：₩5,000 (~$3.5 / ~25 RMB / ~560 JPY)

2-3. 注意事项

  • 东大门批发商街基本要求5~10件以上打包购买。单件购买价格上浮10~20%
  • 部分商家仅收现金 (斗塔·APM Luxe 支持刷卡及外国卡)
  • 退税请前往斗塔1楼或东大门历史博物馆旁退税台 (需携带护照)

3. 便利店 (Pyeonuijeom / 편의점) — 遍布首尔的24小时迷你超市

> 💡 便利店 (Pyeonuijeom / 편의점) — 与中国便利店类似，但韩国三大品牌 CU · GS25 · Emart24 的门店99%全天24小时营业，是游客深夜购物最触手可及的选择。

3-3. 便利店购物贴士

  • 7-Eleven (7-Eleven / 세븐일레븐) 部分门店非24小时，建议优先选择 CU / GS25 规划动线
  • 刷卡·三星支付 (Samsung Pay / 삼성페이)·Apple Pay 100% 可用 (便利店对境外卡接受度较高)

> 💡 간편결제 (Simple Pay / 간편결제) — 韩国通行的移动支付，包括 카카오페이 (Kakao Pay / 카카오페이)、삼성페이 (Samsung Pay / 삼성페이)。功能类似支付宝/微信支付，但需绑定韩国发行卡。部分明洞·东大门门店已支持 微信支付 (WeChat Pay) 和 支付宝 (Alipay)。

  • 退税 (退还增值税)在普通便利店不可操作 — 免税购物请前往§4机场
  • 购买冷藏商品 (如香蕉味牛奶周边，未密封包装)时，长途携带需注意保存条件

4. 仁川机场 (Incheon Airport / 인천공항) — 韩国唯一真正意义的24小时免税

4-1. 出境前 vs 入境后分开了解

韩国机场免税店在结构上严格区分出境厅与入境厅。

类型 位置 营业时间 可使用时间节点
出境厅免税 T1 3楼·T2 3楼 05:30~22:30 (根据航班调整) 登机前1~3小时
入境厅免税 T1 1楼·T2 1楼 部分门店24小时 入境后即可 (旅程开始前)
机场便利店 T1·T2 全区域 24小时 不限

4-2. 24小时运营主要门店

门店 航站楼 备注
城市免税店入境厅纪念品区 (City Duty Free / 시티면세점) T1 全年无休，部分区域24小时
CU / GS25 机场便利店 T1·T2 24小时·零食·饮料·基本日用品
SM免税店T1特色货架 (SM Duty Free / SM면세점) T1 夜间低价纪念品·00:00~05:00 限时运营
  • 乐天·新罗·新世界免税店营业时间为 05:30~22:30。深夜中转旅客唯一选择为入境厅 + 便利店
  • 机场免税烟草·酒类需要出境护照扫描 (入境厅购买亦受限：限额 1L / 200支)

4-3. 登机前3小时行动方案 (仁川机场T1为例)

1. T-180分钟 — 办理值机 + 安检 (约40分钟)

2. T-140分钟 — 进入3楼免税购物区。依次逛 乐天 (Lotte / 롯데)·新罗 (Shilla / 신라)·新世界 (Shinsegae / 신세계) 三大K-Beauty品牌

3. T-80分钟 — CU便利店4楼零食区购买蜂蜜黄油杏仁·拉面套装

4. T-30分钟 — 前往登机口，在登机口附近礼品店做最后检查

5. 分时段综合地图

🌙 22:00 ~ 24:00 — 一般门店开始关闭

  • 可前往: 东大门主要购物中心 (斗塔·米格里奥雷)· 全市便利店 · 明洞部分 OLIVE YOUNG (Olive Young / 올리브영) (23:00关门)
  • 最优选择: 前往东大门斗塔 (Doota! / 두타)；中转旅客可赶22:30前机场免税店末班时间
  • 注意: 明洞·弘大路边店大部分22:00前已关门，22:00后请提前确认目的地

🌌 00:00 ~ 03:00 — 首尔深夜主力时段

  • 可前往: 东大门全部门店 · 便利店 · 仁川机场入境厅免税部分区域
  • 最优选择: 东大门 APM Luxe + 米格里奥雷地下宵夜 → 光熙商街批发扫货
  • 交通: 错过地铁末班车 (00:00前后)可打车 (东大门→住宿约 ₩10,000~15,000，~65~95 RMB)

🌅 03:00 ~ 06:00 — 首班车前最后冲刺

  • 可前往: 东大门大部分商场仍在营业 (光熙商街 (Kwanghee / 광희상가) 至06:00 · 斗塔至05:00)
  • 最优选择: 光熙商街批发收尾 → DDP (DDP / 동대문디자인플라자) 夜景拍照 → 东大门站首班车 (05:30)
  • 打车: 凌晨加收20%夜间附加费 (00:00~04:00)。推荐使用 카카오택시 (Kakao Taxi / 카카오택시) 应用

☀️ 06:00 ~ 10:00 — 一般门店重新开门前

  • 可前往: 便利店 · 部分大型超市 (이마트 (Emart / 이마트) 07:00开门)· 酒店精品店
  • 最优选择: 享用早餐，等待10:00明洞·弘大路边店开门

6. 支付·换汇·退税实用贴士

6-1. 支付

  • 卡片: VISA / Mastercard / JCB / 银联 (UnionPay) — 东大门主要商场·便利店·机场全部可用
  • 移动支付: 三星支付 (Samsung Pay / 삼성페이) (需韩国发行卡)· Apple Pay (2026年部分门店)· 微信支付 (WeChat Pay) · 支付宝 (Alipay) (明洞·东大门部分门店支持)
  • 现金: 东大门批发商街及部分传统市场必备

6-2. 换汇

  • 换汇点: 明洞 (Myeongdong / 명동) 友利银行换汇所 (08:00~22:00)· 仁川机场换汇所 (24小时·T1 3楼)
  • 深夜应急: 便利店 ATM (支持境外卡取款，手续费 ₩3,000~5,000，约20~30 RMB)
  • 建议: 现金保持5~10万韩元小额备用，大额购物刷卡退税更划算

6-3. 退税 (Tax Refund / 택스리펀드)

  • 即时退税 (Immediate Refund): 单次购物满 ₩30,000 可在门店现场退税 (月累计上限 ₩5,000,000)
  • 机场退税: T1 3楼 KIOSK 或退税台 — 需携带护照 + 收据 + 未使用商品
  • 退税限额: 个人每日累计 ₩1,000,000 / 每月 ₩5,000,000
