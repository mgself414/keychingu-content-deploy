🎯 왜 한국 밥 매트릭스인가

외국인 한국 밥 페인포인트 = "공기밥만 알고 다른 밥 모름". 한국 밥 = 한정식 정통 + MZ 트렌드 + 가성비. 같은 "Korean rice"라도 어묵철판 (분식 cluster cross·#1 가성비)·명란밥 (MZ 트렌드 #1·짠맛)·공기밥 (기본·한정식 cross)·솥밥 (한정식 정통·5색 cluster cross)·영양밥 (한정식 5색 cluster)·치즈볶음밥 (MZ 글로벌 #1) 각자 다른 매니아. 외국인은 (a) 어묵철판 = 분식 가성비 모름 (b) 명란밥 = MZ 인스타 모름 (c) 영양밥 = 한정식 5색 모름 (d) 솥밥 = 정통 모름. 본 가이드는 6종 매트릭스 + 한정식 cross.

🍚 6종 deep dive

🍳 어묵철판 (Eomuk-cheolpan) — 가성비 #1

  • 시그니처: 분식 cluster cross·가성비 #1
  • 재료: 어묵 + 밥 + 야채·양념 (철판 볶음)
  • 추천 매장: 분식점·MZ 한식당·체인
  • 가격: 7,000~12,000원/1인
  • 외국인 친화도: ★★★★★ (#1 가성비)

🥚 명란밥 (Myeongran-bap) — MZ #1

  • 시그니처: MZ 트렌드 #1·짠맛·인스타
  • 재료: 명란 (pollock roe) + 밥 + 계란·김
  • 추천 매장: MZ 한식당·홍대·강남·이태원
  • 가격: 10,000~18,000원/1인
  • 외국인 친화도: ★★★★★ (MZ #1)

🍚 공기밥 (Gonggi-bap) — 기본

  • 시그니처: 기본 1공기·한정식 cross
  • 재료: 백미 (또는 잡곡)
  • 추천: 가정식·한정식·MZ 한식당 (사이드)
  • 가격: 1,000~3,000원/1공기
  • 외국인 친화도: ★★★ (기본)

🥘 솥밥 (Sot-bap) — 한정식 정통

  • 시그니처: 한정식 정통·뜨거움·바삭 누룽지
  • 재료: 밥 + 콩·잡곡·연밥 + 솥
  • 추천: 한정식 ([#837](#837))·MZ 한식당
  • 가격: 한정식 코스 40~150k (포함) / 단품 12,000~25,000원
  • 외국인 친화도: ★★★★

🌰 영양밥 (Yeongyang-bap) — 한정식 5색

  • 시그니처: 한정식 5색 cluster·정통·잡곡·견과류
  • 재료: 백미 + 잡곡·콩·견과류·당근·표고
  • 추천: 한정식·전주 한정식
  • 가격: 한정식 무료 / 단품 10,000~20,000원
  • 외국인 친화도: ★★★★

🧀 치즈볶음밥 (Cheese-bokkeum-bap) — MZ 글로벌 #1

  • 시그니처: MZ 글로벌 #1·치즈 fusion·트렌드
  • 재료: 볶음밥 + 치즈·계란·김치 (선택)
  • 추천: MZ 한식당·치즈 카페·홍대·강남
  • 가격: 12,000~20,000원/1인
  • 외국인 친화도: ★★★★★ (MZ 글로벌 #1)

⚠ 외국인 자주 실수 5가지

1. "밥 = 한 가지": 밥 = 6종 매트릭스.

2. "공기밥 = 무료": 공기밥 = 1,000~3,000원 (한정식 무료 포함).

3. "명란밥 = 단가": 명란 = MZ 인스타 #1·10~18k.

4. "솥밥 = 일반": 솥밥 = 한정식 정통·바삭 누룽지.

5. "치즈볶음밥 = 외국 음식": 치즈볶음밥 = 한국 MZ fusion 정통.

⚙ FAQ 8개

1. 외국인 입문 1순위: 어묵철판 + 명란밥 + 치즈볶음밥.

2. 인스타·vlog: 명란 (#1)·치즈볶음밥 (#1).

3. MZ 트렌드: 명란·치즈볶음밥.

밥 = 일반 음식. 임신부·어린이 = OK (명란 짠맛·치즈 유제품 조절). 알레르기 (어란·해산물·유제품·견과류·간장) 사전 고지. 식중독 의심 시 ☎ 1339.
