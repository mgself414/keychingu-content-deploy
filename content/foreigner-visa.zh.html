🎯 为什么需要外国人签证·K-ETA 完整指南

外国人入境韩国的首要痛点 = 签证·K-ETA。自2021年 K-ETA 引入以来，它已成为免签外国人入境的首要要求，并整合了旅游、就业、留学和结婚签证的全套信息。这是外国游客入境韩国前30天准备工作的首选指南。

⚠ 外国人常见错误5项

1. “K-ETA = 免签 = 相同？”: K-ETA = 免签外国人必须提前申请的许可 (自2021年起)。美国、日本、欧盟等112个国家的免签外国人，必须在出发前24小时申请 K-ETA。

2. “签证 = 永久 = 一劳永逸？”: 外国人签证 = 停留期限·次数·续签 的完整体系。必须在到期前30天续签·停留90天以上必须办理外国人登录证 (ARC)。

3. “免签 = 每次都能停留90天？”: 免签90天 = 6个月内累计停留90天 (可能变动) + 韩国出入境管理处 (Chulipguk Gwalliso / 출입국 관리소) 对外国人非常友好。

4. “医疗旅游 = 普通签证即可？”: K-Medical (#242) = C-3-3 医疗旅游签证 + 对外国人友好 + 90天以内停留 + 外国游客首选。

5. “E-2 英语讲师 = 适用于所有外国人？”: E-2 英语讲师 = TEFL/TESOL 证书 + 学位 + 对外国人友好的韩国英语学院首选 = 外国人才热门选择。

⚙ 常见问题6项

1. K-ETA 申请: 官方网站 + 出发前24小时 + ₩10,000 (~$7.3 / ~53 RMB / ~1,100 JPY) + 外国游客必备。

2. 外国人登录证 (ARC): 停留90天以上必须办理 + 外国人才首选 (出入境管理处 (Chulipguk Gwalliso / 출입국 관리소))。

3. 外国人签证续签: 到期前30天 + 通过 Hi Korea (하이코리아) 网站在线办理 + 出入境管理处 (Chulipguk Gwalliso / 출입국 관리소)。

4. 外国劳工 (E-9·E-7): 韩国首要的外国劳工系统 + 外国人才首选。

5. 外国人结婚签证 (F-6): 韩国配偶 + 对外国人友好的热门选择。

6. 外国人1345 (外国人综合咨询): 对外国人友好的综合服务 + 提供英语、中文、日语、俄语、阿拉伯语翻译。
