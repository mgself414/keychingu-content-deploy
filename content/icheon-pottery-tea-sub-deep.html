이천 도자기 + 차 cluster 12선

1. 이천 도자 + 다구 (찻잔·다관·숙우) cross

  • 차별: 이천 UNESCO 창의도시 공예 2010·한국 #1 도자 240+ 공방·찻잔·다관·숙우 등 다구 직접 만들기
  • 체험: 다구 도자기 1시간 30K~/1인·완성품 1주 후 택배 (해외 OK)
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아·#600·#673 cross

2. 사기막골 도예촌 (240+ 공방·차 도자 풀세트)

  • 차별: 이천 도자 #1 cluster 사기막골·240+ 공방·찻잔·다완·다식판 풀세트·기념품 1순위
  • 운영: 대부분 화-일 09:00-18:00·월 휴무
  • 외국인 fit: ★★★★★ EN·JP·CN 1순위·#673 cross

3. 이천 세계도자센터 (KOCEF·차 도자 전시)

  • 차별: 2001 개관·이천 도자 #1 박물관·세계 도자 비엔날레 본거지·차 도자 + 다도 전시 + 체험
  • 운영: 화-일 10:00-18:00·월 휴무·입장료 5,000원
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·#668 K-아트 cross

4. 이천 도자기 축제 (4-5월·다구 매니아)

  • 차별: 매년 4-5월·약 1주·이천 도예촌·한국 최대 도자 축제 5만+ 관람·다구 + 차 도자 풀세트
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·#673·#600 cross

5. 이천 + 여주 + 광주 도자 cluster (3 도시·차 도자)

  • 차별: 이천 + 여주 + 광주 한국 도자 3대 산지·1박 2일 풀세트 가능·여주 도자 비엔날레 격년 (홀수년)
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·#672·#600 cross

6. 이천 차 + 도자 1일 코스 (체험 풀세트)

  • 차별: 오전 차 만들기 체험 + 오후 다구 도자기 체험·완성품 풀세트 1주 후 택배·가격 60K~/1인
  • 외국인 fit: ★★★★★ EN·JP·CN 매니아·가족 1순위

7. 이천 쌀밥 + 차 한정식 (정통 다식)

  • 차별: 이천 쌀밥 한정식 정통 음식·약 30 식당·차 + 다식 풀세트 한정식
  • 가격: 25,000-35,000원/1인·임금님표 이천쌀
  • 외국인 fit: ★★★★ EN·JP 매니아·#673 cross

8. 도자 카페·찻집 (도예촌 cluster 5강)

  • 차별: 도예촌 cluster 도자 카페 5+·한옥 + 도자 인테리어·찻잔 + 다구 직접 사용
  • 시그니처: 카페 초루·도예촌 cafe 풀세트
  • 외국인 fit: ★★★★ EN·JP·CN MZ·SNS 1순위

9. 이천 도예 + 다도 워크숍 (1박 2일 매니아)

  • 차별: 이천 도예 + 다도 워크숍 1박 2일·미란다호텔 또는 펜션 + 체험·가격 250K~/1인
  • 외국인 fit: ★★★★ EN·JP 정통 매니아 1순위·#673·#675 cross

10. 이천 차 (한국 차밭 사이클 + 도자)

  • 차별: 이천 = 평지 도자 산지·보성/하동/제주 = 차밭 산지·다른 cluster·이천은 다구 도자 1순위
  • 외국인 fit: ★★★★ EN·JP 정통 매니아·#675~#678 cross

11. 이천 day-trip (경강선 1시간)

  • 접근: 강남역 → 이천역 경강선 1시간·서울 → 이천 버스 1시간
  • 시티투어: 도예촌 + 차박물관 + 쌀밥 풀 day 6시간 / 3만원
  • 외국인 fit: ★★★★★ EN·JP·CN day-trip 1순위 (수도권 1시간)

12. 한국 도자 + 차 풀세트 (이천·여주·이천 도자 5강)

  • 차별: 한국 도자 + 차 풀세트·이천·여주·광주·강진 청자·문경 도자 5 cluster·한국 도자 매니아 1순위
  • 외국인 fit: ★★★★ EN·JP·CN 정통 매니아·#600·#657 강진 청자 cross

FAQ 6

Q1. 이천 도자 체험 + 다구 만들기? A. 사기막골 도예촌·1시간 30K~/1인·다구 찻잔 다관 풀세트 OK·완성품 1주 후 택배 (해외 OK).

Q2. 이천 + 여주 + 광주 도자 cluster? A. 3 도시 한국 도자 3대 산지·1박 2일 풀세트 OK (이천 → 여주 → 광주).

Q3. 도자기 축제 시기? A. 매년 4-5월 약 1주·세계 도자 비엔날레 격년 (2027 예정).

Q4. 이천 차 + 도자 워크숍? A. 1박 2일 250K~/1인·미란다호텔 + 체험 + 다도·EN 가이드 일부.

Q5. 이천 vs 보성/하동/제주 차이? A. 이천 = 도자 + 다구 1순위 (평지·UNESCO 창의)·보성/하동/제주 = 차밭 산지 (관광 + 정통 + 외국인).

Q6. 이천 도자 + 차 day-trip? A. 경강선 1시간·풀 day 30K 시티투어·도예촌 + 차박물관 + 쌀밥 + 다구 체험.

풀데이 코스 3

A. 정통 day-trip (경강선 1시간)

  • 09:00 강남역 경강선 → 10:00 이천역
  • 10:30 사기막골 도예촌 - 다구 만들기 체험
  • 12:00 이천 쌀밥 한정식 점심
  • 14:00 세계도자센터 + 차 도자 전시
  • 17:00 도자 카페 + 귀가

B. 차 + 도자 매니아 1박 2일

  • Day 1: 이천 도자 체험 + 미란다호텔 1박
  • Day 2: 여주 도자 + 광주 도자 cluster

C. 한국 도자 + 차 풀세트 매니아 2박 3일

  • Day 1: 이천 도예촌 + 다구
  • Day 2: 여주 도자 + 광주
  • Day 3: 강진 청자촌 + 보성 차밭

시즌 5

  • 봄: 3-4월 산수유 + 도자기 축제 4-5월 절정·우전 차 + 다구 매니아 1순위
  • 여름: 6-8월 설봉호 산책·테르메덴 워터파크
  • 가을: 10월 단풍·이천 쌀 추수
  • 겨울: 12-2월 테르메덴 온천 + 따뜻한 약차·실내 도자기
  • 연중: 매월 2·7일 관고시장 오일장

Tip 5

1. 다구 도자기 체험 1시간 30K·완성품 1주 후 택배 (해외 OK)

2. 경강선 1시간 강남 직행 (KTX 불필요)

3. 도자기 축제 4-5월 이천 + 여주 + 광주 cluster

4. 이천 vs 차밭 산지 = 도자 1순위 vs 관광 1순위 차이

5. 미란다호텔 차 + 도자 워크숍 1박 추천
