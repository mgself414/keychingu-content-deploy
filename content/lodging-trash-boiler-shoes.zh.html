韩国住宿第一夜零慌张手册 — 鞋子·锅炉面板·从量制垃圾袋·分类回收

副标题：入住Airbnb·民宿·韩屋后的10分钟 — 玄关脱鞋、墙面板的三个按钮([ 暖气 ]·[ 热水 ]·[ 外出 ])、从量制垃圾袋与厨余垃圾的3种分类方式、晚上10点后的噪音、退房时垃圾袋放哪里。因地区而异的规则一律标注"以住宿告知为准"

ISSUE 06 · #1380 · 2026-09-17 · korea-first-timer系列

🎯 本手册阅读方法 — 标记规约

沿用#1270(点餐机手册)的标记规约。

  • 面板·告示上的文字用引号："请把厨余垃圾控干水分再丢弃"
  • 需要按的按钮用方括号：[ 热水 ]
  • 动手做的动作用加粗：丢出去前先把袋口系好

只谈一个角度。订房、入住App、行李寄存是别的手册的内容 — 这里只讲进门关上门之后必须做的事：锅炉、垃圾、噪音、卫生间。每一项都按是规定还是惯例标注([规定]=法律·条例，[惯例]=几乎所有人都这么做，[可选]=自己决定)。只要是因地区而异的项目，住宿的告知一律优先于本手册。

① 入住前10分钟 — 主流程

步骤 场景 该做的事 陷阱
1 玄关 脱鞋换室内拖鞋 穿着鞋踏进一步的瞬间，房东对你的印象就变了
2 找告示 把冰箱·玄关·桌上的韩英文告示拍下来 垃圾·wifi密码·锅炉的说明大多都在这上面
3 墙面板 确认锅炉遥控器位置，查看当前模式(②) 冬天如果是"外出"模式，房间会很冷 — 切换到"暖气"
4 垃圾 确认垃圾袋和厨余垃圾桶的位置(③) 没有袋子就去便利店买(只有本地区的袋子有效)
5 卫生间 确认厕纸告示和坐浴按钮(⑤) 没有告示的话大多可以直接冲进马桶
6 夜间 10点后保持安静(④) 公寓式住宿的脚步声·关门声会传到楼下

② 锅炉面板 — 只要记住三个按钮

韩国住宿的供暖大多是地板温水地暖(温突 / ondol / 온돌)，墙上的小面板(遥控器)控制锅炉。品牌(Navien、Kiturami、Rinnai、Daesung Celtic)不同，按钮名字和画面也不同，但基本原理是一样的。

按钮 含义 什么时候用
[ 暖气 ] (난방) 打开地暖。用▲▼调节室内温度或地暖(水)温度 房间冷的时候
[ 热水 ] (온수) 只打开淋浴·水龙头的热水 夏天或暖和的日子 — 只要热水不要暖气时
[ 外出 ] (외출) 最小运转(防冻)·节能模式 外出、或冬天退房时
[ 预约 ] (예약) / [ 定时 ] (타이머) 按时间自动运转 只想晚上开的时候
[ 电源 ] (전원) 全部关闭 冬天不要关这个 — 管道可能会冻裂
  • 没有热水 [惯例] — [ 热水 ]没开，或者热水温度设定太低。热水温度通常在30~60℃范围内调节(以Navien机型为准)。打开后等1~2分钟。
  • 地板太烫 — 地暖温度设定太高。用▼调低，或切换到"室内 (실내)"模式。
  • 冬天外出 [惯例] — 不要关掉，用"[ 外出 ]"。大部分品牌都内置"低于设定温度自动运转"的防冻功能。
  • 看不懂屏幕上的字 — 只要找"暖气、热水、外出、预约"这四个字就够了。都在下面⑦生存词里。

③ 垃圾 — 3种袋子，规则由地区决定

种类 装什么 在哪买 标记
一般垃圾 首尔大多是白色从量制垃圾袋 (jongnyangje bongtu / 종량제 봉투)(具体颜色·规格请在便利店确认)。10L、20L等 便利店·超市 — 只有本自治区的袋子有效 [规定]
厨余垃圾 专用袋 / 缴费贴纸 / RFID计量桶(刷卡)，视本地区方式而定 袋子·贴纸在便利店买，RFID用住宿的卡 [规定]
可回收物 纸类·塑料·罐/瓶类·塑料袋4种，装进透明袋 任意透明袋 [规定]
  • 一般垃圾 [规定] — 不是从量制垃圾袋就不会被收走，乱扔垃圾会被罚款(各地不同，首次大约10万韩元左右)。袋子价格由自治区决定(例：江东区20L袋490韩元)。
  • 厨余垃圾 (eumsingmul sseuregi / 음식물 쓰레기) [规定] — "请把厨余垃圾控干水分再丢弃"是通用规则。塑料袋·牙签·瓶盖·骨头·贝壳不能丢进去。首尔各区方式不同(金川区、永登浦区、瑞草区、松坡区等部分地区用RFID计量桶) — 以住宿告知为准。
  • 可回收物 (jaehwaryong / 재활용) [规定] — 把4类分好装进透明袋。公寓有指定投放点，独栋·别墅要放在门前(门前投放)。傍晚到午夜是惯例[惯例]时段(例：中区19:00~24:00)，具体星期几则因地区而异 — 以住宿告知为准。
  • 退房时 [惯例] — 把袋口系好放在告示指定的地方。如果房东说"就放着吧"，那就照做。

④ 噪音·邻居 — 晚上10点是底线

  • 晚上10点后 [可选] — 注意脚步声·洗衣机·玄关门的声音。公寓·别墅对楼层间噪音很敏感，青年旅舍则要注意公共空间的说话音量。
  • 玄关门 [可选] — 智能门锁的门很重，容易"哐"地关上。用手扶着关。
  • 走廊·电梯 [惯例] — 遇到邻居轻轻点头示意即可。不打招呼也不算失礼。

⑤ 卫生间 — 厕纸和坐浴

  • 厕纸 [惯例] — 2018年以后公共卫生间的垃圾桶大多已撤除，住宿也大多直接冲进马桶。例外是贴有"厕纸请丢进垃圾桶"告示的老建筑 — 告示说了算(#1277)。
  • 坐浴 [惯例] — 马桶旁面板上有[ 洗净 ](后方)、[ 坐浴 ](前方)、[ 烘干 ]、[ 停止 ]。坐下前按会喷水 — 坐下之后再按。
  • 排水口异味 [可选] — 长时间空置的房子排水存水弯会干涸而发臭。放一次水通常就能消除。

⑥ 退房30秒

1. 冬天把锅炉调到"[ 外出 ]"，夏天只关掉"[ 热水 ]"(告示不同的话以告示为准)。

2. 把垃圾袋口系好放在指定位置。

3. 确认窗户·燃气，钥匙/门卡放在告示指定的地方。

⑦ 生存词12个 — 面板·告示·垃圾袋上实际会看到的字

屏幕文字 含义 = 该怎么做
暖气 (nanbang 난방) 地暖 — 房间冷就按这个
热水 (onsu 온수) 热水 — 没有热水就按这个
外出 (oechul 외출) 外出模式 — 外出或冬天退房时用
预约 (yeyak 예약) 定时器
室内 / 温突 (silnae / ondol 실내 / 온돌) 室内温度基准 / 地暖(水)温度基准
从量制垃圾袋 (jongnyangje bongtu 종량제 봉투) 规格垃圾袋 — 在便利店买
厨余垃圾 (eumsingmul sseuregi 음식물 쓰레기) 厨余垃圾
可回收物 (jaehwaryong 재활용) 可回收物
分类投放 (bullisugeo 분리수거) 分类排放
控干水分 (mulgi jegeo 물기 제거) 把水分挤干
洗净 / 坐浴 / 停止 (sejeong / bide / jeongji 세정 / 비데 / 정지) 坐浴的3个按钮
垃圾桶 (hyujitong 휴지통) 垃圾桶 — 有这个告示就不能冲马桶

⑧ 慌张场景3例

1. 淋浴水是凉的 — 面板上"[ 热水 ]"没开。打开后用▲升高温度，等1~2分钟再试。还是不行的话给房东发消息："没有热水" (Onsu-ga an nawayo / 온수가 안 나와요)。

2. 便利店说买的袋子不能用 — 那是别的区的袋子。要买印有住宿所在自治区名字(例：麻浦区)的袋子。跟便利店店员说："这个地区的从量制垃圾袋给我一个" (I dongne jongnyangje bongtu juseyo / 이 동네 종량제 봉투 주세요)。

3. 不知道厨余垃圾该丢哪里 — 没有告示的话，问房东最快。在得到回复之前把水控干装在袋子里等着。不要混进一般垃圾袋里。

⑨ 备用方案 — 搞不清楚的时候

  • 面板太复杂就只开"[ 暖气 ]"，设到22~24℃，其他都别碰。
  • 不知道该买哪种袋子？在便利店说："给我一个20升的一般垃圾袋" (Ilban sseuregi bongtu 20 liteo juseyo / 일반 쓰레기 봉투 20리터 주세요) — 就会拿到那家店所在地区的袋子。
  • 担心吵到别人？晚上10点后穿袜子不穿拖鞋走路。
