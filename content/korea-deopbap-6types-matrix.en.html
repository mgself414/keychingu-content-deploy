Korean Deopbap 6-Type Matrix — Jeyuk · Mackerel · Myeongran · Imyeonsu · Salmon · Beef Full Set

Subtitle: For foreign tourists — lunch MZ #1 + home-style · chain best value

ISSUE 03 · #891 · 2026-06-09

🎯 Why a Korean Deopbap Matrix

The foreign visitor pain point with Korean rice bowls = "I only know bibimbap (비빔밥), not deopbap". Korean deopbap (덮밥) = lunch MZ #1 + home-style · chain best value. Even within the same "Korean rice bowl" family: jeyuk-deopbap (제육덮밥) (best value #1 · spicy) · godeungeo-jaban-deopbap (고등어자반덮밥) (Korean classic) · myeongran-deopbap (명란덮밥) (MZ trend #1) · imyeonsu-deopbap (임연수덮밥) (classic fish) · yeoneo-deopbap (연어덮밥) (global fusion · MZ) · sogogi-deopbap (소고기덮밥) (hanjeongsik (한정식) cross). Foreigners typically don't know (a) the difference between bibimbap and deopbap, (b) that jeyuk is a best-value favorite, (c) that myeongran is the MZ Insta #1, and (d) that Hansot (한솥) · Bondosirak (본도시락) offer great value. This guide is a 6-type matrix + lunch cluster.

🍚 6-Type Deep Dive

🐷 Jeyuk-deopbap (Jeyuk-deopbap) — Best Value #1

  • Signature: Best value #1 · spicy · MZ dosirak
  • Ingredients: Pork + gochujang (고추장) + onion · carrot + rice
  • Recommended spots: Hansot · Bondosirak ([#854](#854)) · MZ Korean restaurants · home-style diners
  • Price: ₩6,000–12,000 (~$4.5–9) per person
  • Foreigner-friendliness: ★★★★★ (#1 value)

🐟 Godeungeo-jaban-deopbap (Godeungeo-jaban) — Classic

  • Signature: Korean classic · salty · nopo old-school
  • Ingredients: Salted mackerel (salt-cured) + radish soup (무국) · banchan (반찬) side dishes + rice
  • Recommended spots: Nopo old-school eateries · home-style diners
  • Price: ₩8,000–15,000 (~$6–11) per person
  • Foreigner-friendliness: ★★★★ (classic)

🥚 Myeongran-deopbap (Myeongran-deopbap) — MZ #1

  • Signature: MZ Insta #1 · trendy · salty
  • Ingredients: Myeongran (명란) (pollock roe) + egg · gim (김) seaweed + rice
  • Recommended spots: MZ Korean restaurants · Hongdae (홍대) · Gangnam (강남) · Itaewon (이태원)
  • Price: ₩12,000–22,000 (~$9–17) per person
  • Foreigner-friendliness: ★★★★★ (MZ #1)

🐠 Imyeonsu-deopbap (Imyeonsu) — Classic

  • Signature: Classic · chains · salty
  • Ingredients: Imyeonsu (임연수) (Atka mackerel) + radish soup · banchan + rice
  • Recommended spots: Hansot · Bondosirak · chain Korean restaurants
  • Price: ₩8,000–15,000 (~$6–11) per person
  • Foreigner-friendliness: ★★★★ (classic)

🟠 Yeoneo-deopbap (Yeon-eo-deopbap) — Global

  • Signature: Global fusion · MZ · Japanese influence
  • Ingredients: Salmon (raw or cooked) + wasabi · soy sauce + rice
  • Recommended spots: MZ Korean restaurants · all-you-can-eat salmon ([#864](#864) cross)
  • Price: ₩12,000–25,000 (~$9–19) per person
  • Foreigner-friendliness: ★★★★ (global)

🥩 Sogogi-deopbap (Sogogi-deopbap) — Luxury

  • Signature: Hanjeongsik cross · luxury · beef
  • Ingredients: Beef (bulgogi (불고기) · galbi (갈비)) + onion · carrot · soy-sauce seasoning + rice
  • Recommended spots: Hanjeongsik restaurants · MZ Korean restaurants · beef specialists
  • Price: ₩15,000–35,000 (~$11–26) per person
  • Foreigner-friendliness: ★★★★ (luxury)

⚠ 5 Common Mistakes Foreigners Make

1. "Bibimbap = deopbap": Bibimbap = 5-color namul (나물) vegetables + mixed together / Deopbap = main topping over rice + not mixed.

2. "Jeyuk = ordinary": Jeyuk = best value #1 · MZ dosirak.

3. "Myeongran = pricey for what it is": Myeongran = MZ Insta #1 · ₩12,000–22,000 (~$9–17).

4. "Godeungeo-jaban = just salty": Godeungeo-jaban = Korean classic + radish soup pairing.

5. "Deopbap = fast food": Deopbap = Hansot · Bondosirak authentic best value (Korean food cluster).

⚙ FAQ: 8 Questions

1. Best starter picks for foreigners: Jeyuk (value) + myeongran (MZ).

2. Insta · vlog: Myeongran (#1).

3. MZ trend: Myeongran (#1) · salmon.

4. Best value: Jeyuk (#1) · mackerel · imyeonsu.

5. Luxury: Beef.

6. Allergies: Declare fish roe · seafood allergies in advance.

7. Payment · tipping: Card OK / No tipping.

8. VAT refund: Food and beverages generally not refundable.

⚠ Medical · Safety · Dietary Disclaimer

Deopbap = ordinary food. Pregnant women · children = OK (myeongran = watch the saltiness). Declare allergies (fish roe · seafood · egg · soy sauce gluten) in advance. If food poisoning is suspected, call ☎ 1339. This guide is general information, not medical advice.

Dietary restriction fallback: Halal · kosher = fish · seafood OK · no pork · salmon OK / Vegetarian · vegan = not vegetarian / Gluten-free = substitute Tamari.
