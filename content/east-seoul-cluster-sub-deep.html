1. 구의 + 천호 동쪽 동네 + 광나루 한강 day-trip 풀세트

  • 차별: 서울 동쪽 풀세트·구의 + 천호 + 광나루 한강 cluster·가족 + 자연 매니아 1순위·5호선 + 2호선 + 8호선
  • 외국인 fit: ★★★★ EN·JP·CN 가족·자연 매니아·조용 + 자연

2. 구의 동네 + 테크노마트 (전자상가)

  • 차별: 구의역 강변역 테크노마트·서울 동쪽 #1 전자상가·가성비 매니아 1순위·2호선 강변역·구의역
  • 외국인 fit: ★★★★ EN·JP·CN MZ·가성비 전자

3. 천호 동네 (한강 동쪽 cluster)

  • 차별: 천호 동네·동쪽 #1 쇼핑 + 음식 cluster·천호역 5·8호선·현대 백화점·이마트 트레이더스
  • 외국인 fit: ★★★★ EN·JP·CN 가족 매니아·쇼핑 + 음식

4. 광나루 한강공원 (서울 동쪽 끝 자연)

  • 차별: 서울 동쪽 끝 한강공원·광진·강동 cluster·가족 + 자연 매니아·광나루역 5호선·조용한 분위기
  • 외국인 fit: ★★★★ EN·JP·CN 가족 매니아·#706·#708 cross

5. 천호 광장 + 한강 야경

  • 차별: 천호 광장·한강 야경 + 동쪽 LED 야경·무료·MZ + 가족 매니아·천호역 5·8호선
  • 외국인 fit: ★★★★ EN·JP·CN MZ·야경·#703 cross

6. 구의 + 천호 한강 자전거 풀세트

  • 차별: 광나루 한강공원 따릉이·11 한강공원 자전거 종주 41.5km·가성비 1순위·1일권 1,000원
  • 외국인 fit: ★★★★ EN·JP·CN MZ·자전거 매니아·#697·#706 cross

7. 아차산 (구의 + 광나루 hiking)

  • 차별: 아차산 285m·고구려 정통 토성·5세기·구의 + 광나루 hiking 매니아·구의역·아차산역 5호선
  • 외국인 fit: ★★★★ EN·JP·CN hiking·정통 매니아·#511 cross

8. 풍납토성 (구의 인접·백제 정통)

  • 차별: 풍납토성·백제 정통 토성·BC 18 ~ AD 660·UNESCO 잠정 등재 예정·구의·천호 인접 도보 + 지하철 5분
  • 외국인 fit: ★★★★ EN·JP·CN 정통 매니아·#714 cross

9. 강동 + 천호 시장 cluster

  • 차별: 천호 + 강동 시장 cluster·노포 음식점 풀세트·가성비 1순위·MZ + 가족 매니아·24시간
  • 외국인 fit: ★★★★ EN·JP·CN 가성비 매니아·#380 cross

10. 구의 + 천호 + 광나루 1일 풀세트 (낮+밤)

  • 차별: 구의역 (낮) → 아차산 hiking → 천호 시장 점심 → 광나루 한강 (저녁) → 천호 야경 (밤) 풀세트
  • 외국인 fit: ★★★★ EN·JP·CN 가족·자연 매니아·1일 day-trip

11. 한강 동쪽 끝 + 자전거 종주

  • 차별: 광나루 한강공원 → 잠실 → 뚝섬 → 한강 자전거 종주·서울 동쪽 풀세트·MZ 매니아 1순위
  • 외국인 fit: ★★★★ EN·JP·CN MZ·자전거 매니아·자전거 1순위

12. 동쪽 동네 가족 매니아 cluster

  • 차별: 구의 + 천호 + 광나루 가족 매니아 1순위·조용 + 자연 + 가성비·서울 외곽 동네 day-trip 1순위
  • 외국인 fit: ★★★★ EN·JP·CN 가족 매니아·가성비

FAQ 6

Q1. 구의 + 천호 + 광나루 접근? A. 구의역 2호선·천호역 5·8호선·광나루역 5호선 cluster·도보 + 지하철 20분 풀.

Q2. 동쪽 동네 vs 강남? A. 동쪽 = 가족 + 자연 + 가성비 (조용)·강남 = 럭셔리 + MZ + 명품 (#713 cross).

Q3. 아차산 hiking? A. 285m·고구려 정통 토성 5세기·구의역·아차산역 5호선·MZ + 가족 hiking 1순위.

Q4. 테크노마트? A. 강변역 2호선·서울 동쪽 #1 전자상가·가성비·MZ + 가족 매니아.

Q5. 천호 시장? A. 천호 + 강동 시장 cluster·24시간 노포·가성비·MZ + 가족 매니아.

Q6. 광나루 한강공원? A. 서울 동쪽 끝·조용한 분위기·자전거 + 산책 + 가족 매니아·#708 광나루 sub와 동쪽 동네 cluster 풀세트.
