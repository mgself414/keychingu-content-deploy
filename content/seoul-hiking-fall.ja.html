清溪山・冠岳山ガイド — 清溪山・清溪山マルグンスプ公園、冠岳山・冠岳山自然公園・冠岳山ムジャンエ森の道、ソウルドゥルレギル11コース

サブタイトル: 清溪山(常時開放) · 清溪山マルグンスプ公園(義王、常時開放) · 冠岳山(632.2m、年中無休) · 冠岳山自然公園(常時開放) · 冠岳山ムジャンエ森の道(傾斜8%未満) · ソウルドゥルレギル11コース 冠岳山コース(5.7km、約2時間30分) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルの南にある二つの山、清溪山と冠岳山で歩いたり登ったりできる場所をまとめたものです。清溪山と義王側の森の公園、冠岳山とその中の自然公園・ムジャンエ森の道、冠岳山の名が付いたソウルドゥルレギルのコースです。六か所すべて年中無休で登録されていて、料金の登録値はありません。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 清溪山 — 清溪山・清溪山マルグンスプ公園

清溪山、瑞草区 ウォンジ洞 (Wonji-dong / 원지동)、☎ 緑の都市課 (Pureun Dosi-gwa / 푸른도시과) 02-2155-6869 は、ソウルと京畿道の城南 (Seongnam / 성남)、果川 (Gwacheon / 과천)、義王 (Uiwang / 의왕)の境にある山です。青龍が天に昇った場所だということで、チョンニョン山 (Cheongnyongsan / 청룡산)とも呼ばれます。ソウル大公園 (Seoul Daegongwon / 서울대공원)、ソウルランド (Seoul Land / 서울랜드)、国立現代美術館 (Gungnip Hyeondae Misulgwan / 국립현대미술관)を囲む山すそが清溪山です。森と渓谷、清溪寺 (Cheonggyesa / 청계사)、森林浴場があり、登山道が多くて、家族登山の場所として親しまれています。

  • 頂上 望京台 (Manggyeongdae / 망경대)(618.2m): 政府の施設があって登れません。
  • 玉女峰 (Oknyeobong / 옥녀봉)・ヒョルウプ峠 (Hyeoleupjae / 혈읍재)・クムジョンス (Geumjeongsu / 금정수): ジュアム洞 (Juam-dong / 주암동)側から望京台の方向へ登ると、チュサ 金正喜 (Gim Jeonghui / 김정희)の実父キム・ノギョン (Gim Nogyeong / 김노경)の墓所があった玉女峰に出て、朝鮮の学者 鄭汝昌 (Jeong Yeochang / 정여창)が越えたというヒョルウプ峠を過ぎると、望京台のすぐ下に薬水クムジョンスがあります。
  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

清溪山マルグンスプ公園、義王市 Cheonggye-ro 475 (청계로 475)、☎ 義王市庁 公園緑地課 (Gongwon Nokji-gwa / 공원녹지과) 031-345-3533 は、森でフィトンチッド浴と森林浴ができるように造られた公園です。モミとメタセコイアの森のヒーリング空間、休憩広場、生活体育施設、散策路があり、体の不自由な人も利用できるバリアフリー公園として整えられています。

  • 開く時間: 常時開放。休み: 年中無休。
  • 駐車: 可能。ベビーカー貸出: なし。

📍 冠岳山 — 冠岳山・冠岳山自然公園・冠岳山ムジャンエ森の道

冠岳山、冠岳区 Gwanak-ro (관악로)、☎ 冠岳区 余暇都市課 (Yeoga Dosi-gwa / 여가도시과) 02-879-6552 は、漢江の南にそびえる632.2mの山で、頂上付近の岩が笠をかぶった姿に似ていることからこの名がつきました。1968年に都市自然公園に指定されました。都心から近く、日帰りで登れます。春は入口に桜が咲き、ツツジが咲くころにツツジ祭りが開かれることもあり、秋は紅葉、冬は雪景色が見られます。頂上にはウォンガク寺 (Wongaksa / 원각사)とヨンジュ庵 (Yeonjuam / 연주암)があり、崖の上の恋主台 (Yeonjudae / 연주대)にすべての登山道が集まります。

  • 代表的な登山道: 冠岳区 シルリム洞 (Sillim-dong / 신림동)のソウル大学校入口 (Seouldaehakgyo Ipgu / 서울대학교 입구)から始まる道、果川市 チュンアン洞 (Jungang-dong / 중앙동)の果川中学校 (Gwacheon Junghakgyo / 과천중학교)の裏手から登る道。
  • 休み: 年中無休。駐車: 可能。

冠岳山自然公園、冠岳区 シルリム洞 山27-1 (산27-1)、☎ 冠岳区庁 公園緑地政策課 (Gongwon Nokji Jeongchaek-gwa / 공원녹지정책과) 02-879-6521 は、冠岳山に造られた公園です。あずまやと噴水のある湖の公園、子ども向けの本と環境の本がある森の図書館、伝統的な野外小劇場、ムジャンエ森の道、展望台があります。

  • 開く時間: 常時開放。休み: 年中無休。駐車: 可能。

冠岳山ムジャンエ森の道、冠岳区 Gwanaksan Nadeulgil 149 (관악산나들길 149)、☎ 冠岳区庁 余暇都市課 02-879-6551 は、冠岳山の中にあるデッキの森の道です。全区間で傾斜が8%未満なので、車いすやベビーカーでも登れます。散歩するように歩く周回型の森の道と、ジグザグの上り坂に沿って登りながら眺望を見る登坂型の森の道があります。あちこちに休憩所、いす、ピクニックテーブルがあります。

  • 開く時間: 常時開放。休み: 年中無休。

📍 歩く道 — ソウルドゥルレギル11コース 冠岳山コース

ソウルドゥルレギル11コース 冠岳山コース、銅雀区 Dongjak-daero Jiha 3 (동작대로 지하3)、☎ 02-779-7902~4 は、総延長156.5km、21コースでソウルを一周するソウルドゥルレギルのうち、「民間信仰と仏教が出会う道」をテーマにしたコースです。あちこちに歴史・文化の遺跡があります。地下鉄 舎堂駅 (Sadang-yeok / 사당역)、冠岳山駅 (Gwanaksan-yeok / 관악산역)に近いです。

  • 長さ・時間: 総延長5.7km、約2時間30分。
  • 開く時間: 常時開放。休み: 年中無休。

⚠ 事前に知っておきたい3つのこと

  1. 清溪山の頂上 望京台(618.2m)は登れません — 政府の施設があります。
  2. 冠岳山ムジャンエ森の道は傾斜が8%未満です — 車いすやベビーカーで登れます。
  3. ソウルドゥルレギル11コースは約2時間30分かかります — 総延長5.7kmで、舎堂駅・冠岳山駅に近いです。

⚙ FAQ 2

Q. 冠岳山はどこから登りますか?

A. 韓国観光公社の登録情報では、冠岳区 シルリム洞のソウル大学校入口から始まる登山道が代表的で、果川市 チュンアン洞の果川中学校の裏手から登る道もあります。

Q. 歩くのが大変な人でも行ける森の道はありますか?

A. 冠岳山ムジャンエ森の道(傾斜8%未満、車いす・ベビーカー可能)と、義王の清溪山マルグンスプ公園(バリアフリー公園)です。二か所とも常時開放です。
