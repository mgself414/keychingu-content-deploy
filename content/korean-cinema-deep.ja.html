ソウル・釜山で韓国映画を観る7か所 — 英語字幕の上映、シネマテーク、映画博物館

サブタイトル: 韓国の古典を無料で上映し、英語字幕の回に「E」を付けるサンアムのシネマテークKOFA、同じ建物にある無料の韓国映画博物館、英語の上映表に「*Eng Subtitle」と書く光化門のemu Cinema、弘大の独立映画専用館インディスペース、忠武路のソウル映画センター、釜山の映画の殿堂と釜山映画体験博物館。場所ごとに、行き方、英語字幕の確認のしかた、料金、休みの日を書きました。

ISSUE 03 · #530 · 2026-11-25

🎯 こんな人に

韓国映画を韓国の映画館で観たい旅行者のための回です。むずかしいのは字幕です。2026-11-25に検索しましたが、CGV・メガボックス・ロッテシネマ (Lotte Cinema / 롯데시네마)で韓国映画に英語字幕を付ける定期上映の案内は見つかりませんでした。そこでこの回は、英語字幕の回を別に表示する場所を前に置き、字幕がなくても見どころのある映画博物館を続けました。韓国の独立映画を上映する映画館はその後ろです。そうした場所は英語字幕が回ごとに違うので、確認のしかたを一緒に書きました。

⚠ 表記の原則: 時間・料金の横には出典と確認日を付けました。「公式」は、運営機関のサイトの原文を直接開いて確認した値にだけ使いました。カカオマップの値は、場所のページに登録されている値です(2026-11-25確認)。歩く時間はカカオマップ基準なので、当日、道案内でもう一度見てください。上映スケジュールは週ごとに変わります。

① 英語字幕の回を別に表示する場所 — 2か所

1. シネマテークKOFA (Cinematheque KOFA / 시네마테크KOFA) (ソウル 麻浦区 (Mapo-gu / 마포구)サンアム洞 (Sangam-dong / 상암동))

韓国映像資料院 (Korean Film Archive / 한국영상자료원)が運営する映画館です。韓国映像資料院の建物の地下1階にあります(カカオマップ, 2026-11-25)。すべての上映が無料です(公式の英語案内, 2026-11-25)。

  • 英語字幕の確認法: 韓国語の上映日程ページの凡例に「E 英語字幕」(E 영어자막)があります。作品名の横にEが付いた回が英語字幕の上映です(公式, 2026-11-25)。英語の日程ページは、凡例にEが2つあります。1つはEvent、1つはEnglish Subtitlesなので、「English Subtitles」の色で表示されたEを探します(公式の英語日程)。英語字幕の回は少ないです。2026-11-25に見た11月25日~12月12日の日程でEが付いた回は、「目の置きどころがない」(눈 둘 데가 없네、直訳) 12月2日(水) 17:00と12月8日(火) 19:00の2回だけでした。行く前に、まずE付きの回を探します。韓国映画ではない上映作には、すべて韓国語字幕が付きます(公式の凡例の文言)。
  • 予約: オンライン予約は上映の5日前から開き、毎日午前11時に更新されます。1人2枚までです。オンライン予約の画面は、今は韓国語のみです(公式の英語案内)。現場の発券は上映当日だけで、オンライン予約のあとに残った座席から発券します。最初の上映の1時間前に窓口が開きます(同じ案内)。上映は定時に始まり、遅れると入場できないことがあります。
  • 休み: 火~土曜に上映します。日・月曜、1月1日、韓国映像資料院の創立記念日(1月18日)、5月1日、ソルラル (Seollal / 설날)・チュソク (Chuseok / 추석)の連休は休みです(公式の英語案内)。
  • 行き方: 住所は麻浦区のウォルドカップブク路400 (Worldcupbuk-ro 400 / 월드컵북로 400)です。公式の案内は2通りです。デジタルメディアシティ駅 (Digital Media City / 디지털미디어시티역)(6号線・空港鉄道・京義中央線)2番出口の前で771・6715・7711・7730番のバスに乗り、ヌリクム・スクエア (Nurimkum Square / 누리꿈스퀘어)で降ります(約5分)。または京義中央線のスセク駅 (Susaek / 수색역)から地下通路でDMC団地に入り、歩いて約10分です(公式の英語案内)。カカオマップは、スセク駅1番出口から徒歩13分としています。

2. emu Cinema (emu Cinema / 에무시네마) (ソウル 鍾路区 (Jongno-gu / 종로구)シンムンノ (Sinmunno / 신문로))

キョンヒ宮 (Gyeonghuigung / 경희궁)の裏の路地にある複合文化空間「emu」 (emu / 에무)の2階の映画館です(ソウル市メディアハブ (Seoul Media Hub / 서울시 미디어허브) 2026-06-12)。新人監督の独立映画や多様性映画を主に上映します(同じ記事)。

  • 英語字幕の確認法: emuのサイトのメニューで「English」→「emu Cinema」に入ると、英語の上映表があります。2026-11-25に開いたとき、載っていたのは10月8日~11日の上映表で、一部の作品に「*Eng Subtitle」の表示が付いていました(公式の英語ページ)。この表示が付いた回が、英語字幕の候補です。最新の上映表が英語ページに遅れて載ることがあるので、映画館(02-730-5604)に確認します。GQコリア (GQ Korea / GQ코리아)は、ここを「英語字幕が付く独立・芸術映画」を定期的に上映する場所と紹介しました(2025-08-02)。10 Magazineも、韓国映画を英語字幕で上映する回があると書いています。
  • 料金: emuのサイトの最初の画面では、料金表が見つかりませんでした。予約画面 (Dtrix / 디트릭스)で確認します。ソウル市メディアハブは、光化門 (Gwanghwamun / 광화문)一帯の芸術映画館3か所の大人一般料金を9,000~12,000ウォンほどと紹介しました(2026-06-12)。
  • 行き方: 住所は鍾路区のキョンヒグン1ガ路7 (Gyeonghuigung 1-ga-gil 7 / 경희궁1가길 7)です。カカオマップは、3号線の景福宮駅 (Gyeongbokgung / 경복궁역)7番出口から徒歩13分としています(2026-11-25)。駐車スペースは2~3台だけなので、公共交通をすすめます(ソウル市メディアハブ 2026-06-12)。映画館の電話は02-730-5604(公式)です。

② 映画博物館 — 2か所

3. 韓国映画博物館 (Korean Film Museum / 한국영화박물관) (ソウル 麻浦区 (Mapo-gu / 마포구)サンアム洞 (Sangam-dong / 상암동))

シネマテークKOFAと同じ韓国映像資料院 (Korean Film Archive / 한국영상자료원)の建物の1階です(カカオマップ, 2026-11-25)。常設展「韓国映画を見る」(한국 영화를 보다、直訳)は、韓国映画の約100年を時代ごとに見せます。ポスター・撮影機材・フィルム・映写機といった実物が出てきます(ソウル市メディアハブ (Seoul Media Hub / 서울시 미디어허브) 2026-07-23)。企画展は1年に2~3回入れ替わります(公式の英語案内)。

  • 英語: 案内デスクで受け取るオーディオガイドのアプリに、英語の解説があります(公式の英語案内, 2026-11-25)。
  • 料金: 無料(公式の英語案内, 2026-11-25)。
  • 予約: 公式の案内は事前予約をすすめています。オンライン予約は当日から2日前までで、毎日正午に開きます。現場の発券は当日だけで、回が始まってから、その回が終わる30分前までです。現場分は数が少ないことがあります(公式の英語案内, 2026-11-25)。
  • 時間: 出典によって違います。公式の英語本文は火~土曜 10:30~19:00で、入場は回の終了30分前までです。同じサイトの最初の画面のTODAY表示は10:30~18:30、カカオマップは10:00~19:00です(いずれも2026-11-25)。18:00前に入るほうが安全です。
  • 休み: 日・月曜、1月1日、1月18日、5月1日、ソルラル (Seollal / 설날)・チュソク (Chuseok / 추석)の連休(公式の英語案内)。
  • 行き方: シネマテークKOFAと同じです。午前に博物館を見て、午後にシネマテークの上映を観る、という組み合わせがしやすいです。

4. 釜山映画体験博物館 (Busan Museum of Movies / 부산영화체험박물관) (釜山 中区 (Jung-gu / 중구)トングァン洞 (Donggwang-dong / 동광동))

サイトが「映画のすべてを見て感じる」場所と紹介する、体験型の映画博物館です。常設展と3・4階の体験ゾーン、別の展示館「シネミュージアム」 (Cine Museum / 씨네뮤지엄)があります(公式サイト, 2026-11-25)。

  • 英語: サイトにENメニューがあり、モバイルの展示解説アプリを案内しています(公式)。アプリが英語に対応しているかは確認できませんでした。
  • 料金: 博物館は大人10,000ウォン、子ども・青少年(36か月以上~高校生)7,000ウォン。シネミュージアムまでまとめた統合券は大人14,000ウォン、子ども・青少年11,000ウォンです(公式, 2026-11-25)。
  • 時間: 10:00~18:00、入場・発券は17:00で締め切ります(公式)。
  • 休み: 毎週月曜(祝日ならその翌日)、1月1日、ソルラル (Seollal / 설날)・チュソク (Chuseok / 추석)の当日(公式)。
  • 行き方: 住所は中区のテチョン路126番キル12 (Daecheong-ro 126beon-gil 12 / 대청로126번길 12)です。カカオマップは、1号線の中央駅 (Jungang / 중앙역)1番出口から徒歩5分としています(2026-11-25)。海雲台 (Haeundae / 해운대)センタムシティの映画の殿堂 (Busan Cinema Center / 영화의전당)とは離れた旧市街 (ウォンドシム / 원도심)側なので、1日で2つをまとめるなら移動時間を多めに取ります。

  • 行き方: 住所は海雲台区のスヨンガンビョン大路120 (Suyeonggangbyeon-daero 120 / 수영강변대로 120)です。2号線のセンタムシティ駅 (Centum City / 센텀시티역)12番・6番出口から徒歩5分(公式の行き方ページ)。カカオマップは6番出口から14分としているので、余裕を持ちます。現場の窓口は、6階の映画館の窓口です(公式のプログラム案内の発券場所)。

ソウルアートシネマ (Seoul Art Cinema / 서울아트시네마) (ソウル 中区 (Jung-gu / 중구)チョンドン (Jeongdong / 정동)) — 世界の古典の名作・作家主義の映画・回顧展を上映するシネマテークです(ソウル市メディアハブ 2026-06-12)。運営は(社)韓国シネマテーク協議会 (Korea Cinematheque Council / 한국시네마테크협의회)です(公式サイト)。住所はチョンドン路3 キョンヒャン・アートヒル2階 (Jeongdong-gil 3, Kyunghyang Arthill 2F / 정동길 3 경향아트힐 2층)です(公式サイト)。2026年12月まで企画展の日程が載っています(公式サイト, 2026-11-25閲覧)。ただ、韓国映画の割合と英語字幕の回は確認できなかったので、7か所の数には入れていません。カカオマップは、5号線の西大門駅 (Seodaemun / 서대문역)5番出口から徒歩8分としています。

🗺 動線 — 2コース

A. ソウル サンアムの1日 (火~土曜)

  1. 午前 韓国映画博物館(10:30~、オンライン予約をおすすめ)。英語のオーディオガイドのアプリを案内デスクで受け取ります
  2. 午後 同じ建物の地下のシネマテークKOFA。現場の発券は最初の上映の1時間前から、残った座席で1人2枚までです

E表示の回がある日を選んで行きます。日・月曜は両方とも休みです。

B. 釜山の1日

  1. 午前 旧市街 (원도심)の釜山映画体験博物館(10:00~、月曜休館)
  2. 午後 センタムシティの映画の殿堂で上映を1本

2つは旧市街と海雲台に離れています。移動時間は、カカオマップの道案内で当日確認します。

⚠ よくある失敗3

  1. 月曜に行く — シネマテークKOFA・韓国映画博物館(日・月)、ソウル映画センター、釜山映画体験博物館は月曜が休みです。映画の殿堂は施設が開いていますが、シネマテークの企画展は月曜に上映がありません(各公式案内・ソウル市メディアハブ)。
  2. どの回でも予約して英語字幕を期待する — シネマテークKOFAは、E表示の回が英語字幕です。英語の日程では、Eventを表すEと間違えないよう、「English Subtitles」の色で表示されたEを探します。emu Cinemaは「*Eng Subtitle」表示の回が英語字幕の候補なので、映画館に確認します。表示がないと、韓国語のせりふに英語字幕がないことがあります。
  3. シネマテークKOFAのオンライン予約ができないからとあきらめる — オンライン予約の画面は韓国語のみですが、上映当日、最初の上映の1時間前から、残席があれば現場で無料で発券できます(公式の英語案内)。1人2枚の制限は現場にも適用されます。

⚙ FAQ 3

  1. 大手チェーンの映画館で、韓国の新作を英語字幕で観られますか? — 2026-11-25の検索では、CGV・メガボックス・ロッテシネマの定期的な英語字幕の上映案内は見つかりませんでした。チェーンのアプリの上映情報で、「English subtitles」の表記を自分で探します。
  2. 映画祭の期間は、英語字幕をどう選びますか? — 釜山国際映画祭 (Busan International Film Festival / 부산국제영화제)の英語の上映表は、回ごとに字幕の記号を付けています。表示がなければ「英語字幕+韓国語のせりふ」、KKは「韓国語字幕+韓国語のせりふ」なので英語字幕はありません(biff.kr英語の上映表の凡例, 2026-11-25閲覧)。映画祭の日程と行き方は、#611 韓国映画祭カレンダーと#482 釜山国際映画祭の観覧ガイドにあります。
  3. 映画に出てくる場所に行ってみたいときは? — 映画・ドラマの撮影地は#452に、住所が確認できた場所だけを集めてあります。
