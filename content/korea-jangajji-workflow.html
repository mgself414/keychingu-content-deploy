한국 장아찌 발효·주문·페어 워크플로우 — 한정식 무한 리필부터 마트 진공 포장까지

> 부제: 외국인 관광객용 5-step 워크플로우 + 발효 시기·페어·귀국 선물 가이드

ISSUE 03 · #868 · 2026-06-09

🎯 왜 한국 장아찌 워크플로우 가이드인가

[#867 장아찌 6종 매트릭스](#867) 알아도 — 발효·주문·페어는 별개. 한국 장아찌는 (a) 한정식 무한 리필 (반찬 풀세트·무료) (b) 가정식 백반 (장아찌 2~3종 + 김치) (c) 시장 노포 (광장·남대문·전주) (d) 마트·면세점 (귀국 선물 진공 포장). 외국인은 (1) 한정식 = 반찬 무료 모름 (2) 마트 vs 시장 차이 모름 (3) 1년 숙성 매니아 모름 (4) 귀국 선물 통관 모름. 본 가이드는 5-step + 발효 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 한정식 / 가정식 / 시장 / 마트·면세점 즉시 무료·가성비·노포·귀국 목적
2️⃣ 메뉴 주문 한정식 코스 / 백반 / 장아찌 1팩 / 진공 포장 1~5분 한정식 반찬 = 무료
3️⃣ 받기·세팅 반찬 풀세트 / 1팩 / 진공 포장 5~15분 무한 리필 OK
4️⃣ 먹기·페어 밥·국·고기·생선 + 장아찌 30~90분 매콤 가감 매니아
5️⃣ 결제·통관 카드 OK / 시장 = 현금 / 진공 통관 OK 1~5분 액체류 100ml 룰

> 총 소요 시간: 한정식 = 1.5~2.5h / 가정식 = 30분~1h / 시장 = 10~30분 / 마트 = 15~30분

🥒 채널별 워크플로우

Type A — 한정식 무한 리필 ([#837](#837))

  • 시그니처: 반찬 무료 무한 리필·장아찌 풀세트
  • 시간대: 11:30~22:00
  • 가격: 한정식 코스 40,000~150,000원 (장아찌 무료 포함)
  • 메뉴: 코스 + 장아찌 2~6종 반찬
  • 외국인 친화도: ★★★★ (영문 메뉴)
  • 무한 리필 매니아: 반찬 무료 #1

Type B — 가정식 백반 ([#854](#854))

  • 시그니처: 홈스타일·가성비·장아찌 2~3종
  • 시간대: 11:00~22:00
  • 가격: 8,000~15,000원/1인
  • 메뉴: 밥 + 국 + 메인 + 장아찌 2~3종 + 김치
  • 외국인 친화도: ★★★★ (가성비)

Type C — 시장 노포 (광장·남대문·전주)

  • 시그니처: 노포·1년 숙성·정통
  • 시간대: 09:00~22:00
  • 가격: 5,000~20,000원/팩
  • 메뉴: 장아찌 1팩 + 시식 OK
  • 외국인 친화도: ★★★★ (시식·노포)
  • 노포 매니아: 광장·남대문·전주

Type D — 마트·면세점 (귀국 선물)

  • 시그니처: 진공 포장·통관 OK·귀국 선물
  • 시간대: 마트 = 10:00~22:00 / 면세점 = 06:00~22:00
  • 가격: 3,000~10,000원/팩
  • 메뉴: 단무지·오이장아찌·깻잎장아찌 (소량 진공)
  • 외국인 친화도: ★★★★★ (진공·영문)
  • 귀국 통관: 1L 미만 OK / 액체류 100ml 룰

  • "장아찌 무한 리필" = "Free pickle refills, please"
  • "단무지" = "Korean yellow radish pickle (with turmeric)"
  • "1년 숙성 마늘" = "1-year-aged garlic pickle"
  • "안 맵게" = "Less spicy, please (고추장아찌)"
  • "진공 포장" = "Vacuum-packed, for taking abroad"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "장아찌 = 김치": 김치 = 발효 + 양념 매콤 / 장아찌 = 간장·식초 절임.

2. "한정식 반찬 = 비용": 한정식 반찬 = 무료 무한 리필 (장아찌 포함).

3. "단무지 = 일본": 한국 단무지 = 강황 (노랑)·장아찌 정통.

4. "마늘장아찌 = 빠른 숙성": 마늘장아찌 = 1년 숙성 정통.

5. "마트·시장 = 같음": 마트 = 진공 포장 귀국 OK / 시장 = 노포 정통·시식 OK.

6. "진공 = 통관 X": 진공 = 통관 OK (1L 미만·액체류 100ml 룰).

7. "장아찌 = 안 매콤": 고추장아찌·깻잎장아찌 = 매콤 (고추 함유).

⚙ FAQ 8개

1. 첫 장아찌 = 어떤 채널: 한정식 무한 리필 (무료 풀세트) → 마트 (귀국 선물).

2. 인스타·vlog: 한정식 반찬 풀세트·광장 장아찌 골목·1년 마늘.

3. MZ 트렌드: 한정식 가성비·MZ 카페 장아찌 fusion.

4. 소주 매니아: 고추장아찌 + 마늘장아찌.

5. 귀국 선물: 마트·면세점 진공 (단무지·오이·깻잎).

6. 알레르기·임신: [#867 disclaimer](#867) 참조.

7. 결제·팁: 카드 OK / 시장 = 현금 일부 / 팁 X.

8. VAT 환급: 마트 = 가능 (즉시 환급 5만 원 이상).

⚠ 의료·안전·식이 disclaimer

장아찌 = 일반 음식. 임신부·어린이 = OK (매콤 조절). 알레르기 (간장 글루텐·고추) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 OK (채식·식물 기반).
  • 채식·비건: 6종 모두 OK (채식·비건 정통).
  • 글루텐 free: 간장 = 글루텐 함유 → Tamari 대체 OK.
