庆州佛国寺·石窟庵 — 入场截止时间，两处之间的12路公交车和2.8km山路，从市内去的10路、11路公交车

副标题: 为想在一天内游览庆州佛国寺和石窟庵的旅行者，把时间、票价和交通方式整理在一起。两处的参观费都免费，全年无休。09:00开始入场，入场截止时间是11~1月17:00，2月和10月17:30，3~9月18:00。停车两处都是小轿车2,000韩元。从客运站到佛国寺乘市内公交车10路或11路。从佛国寺到石窟庵换乘12路公交车，或者沿2.8km探访路步行约1小时。从石窟庵停车场到石窟庵步行约10分钟。秋季山火警戒期(2026-11-15~2026-12-15)，佛国寺~石窟庵探访路部分开放。从石窟庵守护站去吐含山顶的1.4km区间，因施工从2026-11-01到2027-03-31管制。数值是2026-11-25查阅到的。

🎯 适合谁，为什么是这两处

这一篇面向想在庆州参观佛国寺 (Bulguksa Temple / 불국사) 和石窟庵 (Seokguram Grotto / 석굴암) 的外国旅行者。即使不懂韩语，也能在出发前对好时间和公交车号码。

石窟庵位于吐含山 (Tohamsan / 토함산) 半山腰。石窟庵官网(2026-11-25查阅)写着"在吐含山半山腰，利用白色花岗岩人工建造了石窟"。国立公园公团 (Korea National Park Service / 국립공원공단) 把从佛国寺到石窟庵的路介绍为吐含山的探访路线。石窟庵官网写着"石窟庵于1995年12月与佛国寺一同被联合国教科文组织共同登录为世界文化遗产。"所以把两处合成了一篇。

这一篇回答四个问题。

  • 几点之前可以进入: 每个月的入场截止时间不同。
  • 要不要花钱: 参观费免费。停车和公交车要花钱。
  • 两处之间怎么往返: 12路公交车、2.8km探访路、自驾，共三种。
  • 冬季有什么不同: 入场截止提前，去吐含山顶的路因施工被封。

庆州市内的遗迹、餐厅、住宿，这一篇不涉及。市内的夜间路线、市场、韩服，在下面Related一节的篇目里。

⚠ 标注原则: 时间、票价、距离、交通方式是2026-11-25查阅到的值。出处是佛国寺官网、石窟庵官网、庆州市厅 (Gyeongju City Hall / 경주시청)、国立公园公团、国家遗产门户 (Korea Heritage Service Portal / 국가유산포털)。票价为成人标准价。17:00、17:30、18:00不是关闭的时刻，而是入场截止时刻。国立公园公团探访消息页面没有显示发布日期。运营时间、票价、公交车运行、管制区间可能变动。

🚌 交通方式

1. 从客运站到佛国寺 — 市内公交车10路、11路

这是庆州市厅官方指南(2026-11-25查阅)的值。

  • 10路: 从客运站出发，经过瞻星台 (Cheomseongdae / 첨성대) 和普门 (Bomun / 보문)，在佛国寺掉头返回。
  • 11路: 按与10路相同线路的相反方向绕行。庆州市指南也把11路的掉头点写作佛国寺。
  • 时间: 10路以客运站为准，首班车06:00，末班车21:40。约每20分钟一班。
  • 直达时的时间: 庆州市厅写着"从起点客运站到掉头点佛国寺，如果中途不停靠直接前往，大约需要35分钟~45分钟。"市厅写着这个值会因交通状况而变化。这条线路经过市内景点，中途停靠的话要更久。
  • 下车处: "佛国寺"站点。从站点到佛国寺步行3~5分钟。
  • 票价: 普通1,500韩元，青少年1,200韩元，儿童800韩元。用交通卡的话，普通票优惠50韩元，儿童和青少年免费(包括外地居民)。
  • 不要乘10-1路: 10-1路不到佛国寺。它在庆州World (Gyeongju World / 경주월드) 掉头返回。

佛国寺官网的交通指南也把去佛国寺的公交车写作10路和11路。

2. 从佛国寺到石窟庵 — 12路公交车

这是石窟庵官方官网交通指南(2026-11-25查阅)的值。

  • 去程: 在佛国寺换乘12路公交车。
  • 回程: 石窟庵官网公布的12路时刻，是从石窟庵去佛国寺的"每小时整点发车"。
  • 到石窟庵后: 从石窟庵停车场到石窟庵步行约10分钟。

进入石窟庵之前，先定好返程的整点。这是本篇的建议。

3. 从佛国寺到石窟庵 — 步行2.8km

国立公园公团官方探访消息(2026-11-25查阅)介绍"佛国寺~石窟庵探访路线"(共2.8km，约1小时)。佛国寺和石窟庵位于庆州国立公园 (Gyeongju National Park / 경주국립공원) 内。两处之间的山路是国立公园探访路。

秋季山火警戒期(2026-11-15~2026-12-15)，公团会让吐含山探访路中的佛国寺~石窟庵区间部分开放。这段期间打算步行的话，也要一起定好12路公交车。这是本篇的建议。

4. 自驾

  • 从市内到佛国寺: 按佛国寺官网指南，沿7号国道往蔚山 (Ulsan / 울산) 方向走。在Gujeong-dong三岔路口 (Gujeong-dong Samgeori / 구정동 삼거리) 左转。沿902号地方道行驶约2.5km。
  • 从佛国寺到石窟庵: 按石窟庵官网指南，跟着石窟庵路标走吐含山路约20分钟。到达石窟庵停车场 (Seokguram parking lot / 석굴암주차장)。
  • 停车费: 佛国寺小轿车2,000韩元。石窟庵小型·中型2,000韩元。

① 佛国寺 (Bulguksa / 불국사)

  • 地址和电话: 庆尚北道庆州市 (Bulguk-ro 385 / 불국로 385)(Jinhyeon-dong 15-1 / 진현동 15-1)。054-746-9913。
  • 时间和票价: 佛国寺官方官网(2026-11-25查阅)写着"根据新修订的《文化财保护法》，从2023年5月4日起参观费免费。"09:00开始入场。入场截止时间是11~1月17:00，2月和10月17:30，3~9月18:00。全年无休。
  • 停车: 小轿车2,000韩元，大型(巴士)4,000韩元。
  • 规则: 佛国寺官网写着"宠物不得入内。"

什么时候建的寺

佛国寺官方官网的历史介绍(2026-11-25查阅)一并介绍了创建记载和大规模修缮记载。

  • 528年: 有记载说新罗 (Silla / 신라) 法兴王 (Beopheung / 법흥왕) 时期首次建寺。官网把这条记载的出处写作《佛国寺古今创记》 (Bulguksa Gogeum Changgi / 불국사고금창기)。同一份介绍还写着这条记载"文献依据薄弱"。
  • 751年: 官网写着"751年(景德王 (Gyeongdeok / 경덕왕) 10年)由金大城 (Kim Dae-seong / 김대성) 大规模修缮，同时也建造了塔和石桥等"。

之后的事也在同一份介绍里。

  • 1593年: "1593年被倭军破坏的佛国寺，从1604年左右起重新开始复原和重建。"
  • 1970~1973年: 1970年2月开始复原工程，1973年6月完工。这时复原了无说殿 (Museoljeon Hall / 무설전)、观音殿 (Gwaneumjeon Hall / 관음전)、毘卢殿 (Birojeon Hall / 비로전)、经楼 (Gyeongnu / 경루)、回廊。

❄ 冬季的不同

  • 入场截止是17:00: 11月、12月、1月，佛国寺和石窟庵的入场截止都是17:00。2月是17:30。
  • 去吐含山顶的路被封: 国立公园公团庆州国立公园页面公告(2026-11-25查阅)把管制区间写作"石窟庵守护站 (Seokguram Jikimteo / 석굴암지킴터)~吐含山顶(1.4km)"，管制期间写作"26.11.1 ~ 2027.3.31"。管制原因是庆州市实施的《庆州石窟庵石窟危险地加固工程(第2次)》(公团庆州国立公园事务所公告第2026-26号，2026-10-22)。公告还写着"根据现场情况，管制期间可能变更"。2027-01-01日出活动时临时开放。
  • 佛国寺~石窟庵探访路: 秋季山火警戒期(2026-11-15~2026-12-15)，公团会让吐含山探访路中的佛国寺~石窟庵区间部分开放。这段期间打算步行的话，也要一起定好12路公交车。这是本篇的建议。
  • 发布气象特报时可能管制石窟庵: 石窟庵官网写着，发布暴雨、台风、暴雪的注意报或警报时，可能管制进入寺内。石窟庵官网的公告列表里，有一条日期只显示为03-04的公告，标题是"3月4日因暴雪无法入场。5日2点起可入场。"这是暴雪时入场可能被挡住的一个例子。
  • 一天看两处: 冬季上午出发。这是本篇的建议。
  • 咨询: 石窟庵 054-746-9933。佛国寺 054-746-9913。庆州国立公园探访咨询处 054-778-4100。

⚠ 常见失误6点

  1. 把17:00读成关闭的时刻。 17:00、17:30、18:00是入场截止时刻。过了这个时刻就不能进入。
  2. 乘10-1路公交车。 10-1路在庆州World掉头返回。去佛国寺的公交车是10路和11路。
  3. 想乘10路或11路直接到石窟庵。 去石窟庵要在佛国寺换乘12路公交车。
  4. 想从石窟庵接着走到吐含山顶。 从石窟庵守护站去吐含山顶的1.4km区间，从2026-11-01到2027-03-31因施工管制。
  5. 以为在石窟庵停车场下车就到石窟庵了。 从停车场到石窟庵步行约10分钟。
  6. 带宠物去。 佛国寺和石窟庵都不能带宠物进入。

⚙ 6个常见问题

  1. 两处要花钱吗？ — 参观费两处都从2023-05-04起免费。开车去的话，停车费按小轿车算，一处2,000韩元。市内公交车票价普通1,500韩元，青少年1,200韩元，儿童800韩元。用交通卡的话，普通票优惠50韩元，儿童和青少年免费(包括外地居民)。
  2. 几点之前可以进入？ — 两处的入场截止时刻相同。11~1月是17:00，2月和10月是17:30，3~9月是18:00。09:00开始入场。
  3. 从佛国寺到石窟庵怎么去？ — 有三种。在佛国寺换乘12路公交车。步行的话探访路2.8km，约1小时。秋季山火警戒期(2026-11-15~2026-12-15)，这个区间部分开放。开车的话走吐含山路约20分钟。
  4. 有休息日吗？ — 佛国寺和石窟庵都全年无休。发布暴雨、台风、暴雪的注意报或警报时，石窟庵可能管制进入寺内。
