首尔芒草·粉黛乱子草 — 秋天版樱花，赏草季完全指南

副标题：春天有樱花，秋天有草 — 银芒草在天空公园 (Haneul Park / 하늘공원)，粉黛乱子草在奥林匹克公园 (Olympic Park / 올림픽공원) 的9月底~11月初赏草指南。5处名所 + 高峰周日历 + 晚霞路线(#1308) + 出发前准备清单。

ISSUE 04 · #1313 · 2026-08-20

🎯 什么是赏草季 — 外国游客错过的秋天另一种颜色

提到韩国的秋天，大家只会想到红色的枫叶(#229)，但首尔的秋天其实还有两种颜色：随风摇曳的银色芒草(silver grass)，以及像棉花糖一样晕开的粉红色粉黛乱子草(pink muhly grass)。花期像樱花一样短，也和樱花一样是为拍照而生的 — 是名副其实的秋天的樱花。

区分 粉黛乱子草 芒草
颜色 粉红 → 紫红 绿色 → 银色 → 金色
高峰期 9月底 ~ 10月中旬 10月中旬 ~ 11月初
代表名所 奥林匹克公园野花山丘 (Olympic Park Wildflower Hill / 올림픽공원 들꽃마루) 天空公园 (하늘공원)
拍照时段 逆光的下午 日落前的黄金时刻 (#1308)
费用 免费 免费

两个花期在10月初、中旬重叠 — 这两周就是首尔赏草季的高潮。

① 5处名所

1. 天空公园 (Haneul Park / 하늘공원) — 芒草的圣地

  • 世界杯公园 (World Cup Park / 월드컵공원) 整片山丘都是芒草地。每年10月中旬都会举办首尔芒草节 (Seoul Silver Grass Festival / 서울억새축제)(免费，以往年为准 — 出发前请确认日程)，节庆周还会夜间开放，可以看到打灯的芒草。
  • 芒草+晚霞的组合是首尔秋日拍照的第一顺位 — 与晚霞指南#1308中的第5处名所是同一个地方，提前45分钟抵达黄金时刻的公式完全一致。
  • 世界杯体育场站 (World Cup Stadium Station / 월드컵경기장역) 步行20分钟以上，或走291级台阶，或搭乘萌蛙电动车 (Maengkkongi electric car / 맹꽁이 전기차)(收费)。

2. 晚霞公园·兰芝一带 (Noeul Park / 노을공원·난지 일대) — 天空公园的清静邻居

  • 天空公园节庆周人潮拥挤时的替代方案。同属上岩 (Sangam / 상암) 一带，可以和天空公园 (하늘공원) 排成半天行程。

3. 奥林匹克公园野花山丘 (Olympic Park Wildflower Hill / 올림픽공원 들꽃마루) — 粉黛乱子草的代表

  • 首尔最知名的粉黛乱子草群落。秋天时粉黛乱子草、黄秋英等花卉会铺满整片山丘(具体种植品种每年可能不同 — 出发前请确认公园公告)。
  • 步行可达梦村土城站 (Mongchontoseong Station / 몽촌토성역)、汉城百济站 (Hanseong Baekje Station / 한성백제역)。也很适合和蚕室 (Jamsil / 잠실) 行程(乐天世界 (Lotte World / 롯데월드)、石村湖 (Seokchon Lake / 석촌호수))串在一起。

4. 首尔林 (Seoul Forest / 서울숲) — 市中心可达性第一

  • 银杏路、芦苇、秋季花园全都集中在一个公园里 — 自然可以接上圣水 (Seongsu / 성수) 行程(#740 首尔林+圣水的秋天)。与其说是单纯赏草，不如说是"秋天综合款"名所。

5. 杨州百合公园 (Yangju Nari Park / 양주 나리공원) — 近郊远征选项

  • 首都圈赏草远征的代表 — 千日红、粉黛乱子草等秋日花卉节，往年多在9月底~10月中旬举办(免费，具体日程请现场确认)。可以搭首尔地铁+巴士当天来回。
  • 规模比市区名所更大 — 如果以拍照为目的，值得专程前往。

② 高峰周日历 — 什么时候来最好

周次 看点 推荐名所
9月底 粉黛乱子草开始上色 奥林匹克公园、杨州
10月第1~2周 粉黛乱子草高峰 + 芒草开始转银(重叠期) 全部名所都值得去 — 最佳窗口期
10月中旬 芒草高峰、芒草节周 天空公园(夜间开放)
10月末~11月初 芒草转金色的尾声 + 银杏开始转黄 天空公园 → 接续银杏指南

🧳 出发前准备清单

  • [ ] 对照旅行周次 — 在上方日历中确认自己的日期落在哪个窗口期。如果目标是粉黛乱子草，10月中旬以后就太晚了
  • [ ] 避开或接受芒草节周末的人潮 — 芒草节周末下午人潮达到高峰。以拍照为目的的话，平日下午 + 晚霞收尾(#1308公式)才是正解
  • [ ] 倒推晚霞时间 — 天空公园的公式是日落前45分钟抵达(10月日落时间约17:30~18:10)。如果要等萌蛙电动车，再加20分钟
  • [ ] 穿着 — 山丘上风很大。建议薄外套+方便走路的鞋(要走291级台阶)
  • [ ] 禁止无人机 — 首尔市区公园大多是禁飞区。请改用自拍杆、迷你三脚架
