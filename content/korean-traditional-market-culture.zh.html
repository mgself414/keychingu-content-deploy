人情与讨价还价交织的韩国传统市场 — 大型超市·网购时代，市场为何还能活下来

> 传统市场 (Jeontong Sijang / 전통시장) · 讨价还价/折价 (Heungjeong/Enuri / 흥정/에누리) · 添头 (Deom / 덤) · 人情 (Jeong / 정) · 广藏市场 (Gwangjang Market / 광장시장) · 通仁市场铜钱便当 (Tongin Market Yeopjeon Dosirak / 통인시장 엽전 도시락) — 一篇为外国人解读韩国市场文化的文章。不是“推荐美食店”，而是“为什么·变什么·怎么变”。

在首尔正中心，闪亮的百货店与24小时便利店之间，一座有百余年历史的市场依旧人头攒动。在这里，摊主一边说“这个也拿去吧”一边往袋里多塞一把葱，邻座的陌生人请你喝一杯马格利酒 (makgeolli / 막걸리)，老奶奶教你怎么煎绿豆煎饼 (bindae-tteok / 빈대떡)。外国人通常把它译作“传统市场”，但对韩国人来说，传统市场 (Jeontong Sijang / 전통시장) 绝不仅是购物场所。它是讨价还价与添头往来、流淌着“人情 (Jeong / 정)”的关系空间，同时也是在大型超市·网购冲击下、站在消失危机与复活之间的变化现场。本文不是“哪个市场哪家好吃” (→ 那是场所指南)，而是用外国人的视角解读那道风景背后的意义·情感·★变化。这是韩国文化解读系列第47篇。

★ 一目了然 — 首尔五大代表性传统市场

市场 以何闻名 一句话
广藏市场 (Gwangjang Market / 광장시장) 美食天堂 1905年韩国首座常设市场。绿豆煎饼·麻药紫菜包饭·生牛肉

> 核心: 同样是“传统市场”，性格各不相同。美食 (广藏·望远)、体验 (通仁)、购物·讨价还价 (南大门)、复古名所 (京东) — 按目的来选。

⚠️ 外国人常有的3种误解

1. “传统市场 = 哪里都得讨价还价” ❌ — 现在已不是这样。韩国市场定价制 (jeongchalje / 정찰제) 迅速普及，尤其是想压低食物价格如今反而被视为失礼。讨价还价仅限于部分品类·市场，例如南大门 (Namdaemun / 남대문) 的杂货·相机 (见下文③)。

2. “添头 (白送多给的东西) = 亏本买卖” ❌ — 添头 (Deom / 덤) 是韩国市场摊主的人情 (insim / 인심)·信任的表示。买生菜会再添上一把葱，就是这种感觉。它不是亏损，而是“下次再来”的关系语言。你若拒绝，对方反而会觉得失落。

3. “传统市场 = 被超市挤垮、都在凋零” ❌ — 只对了一半。统计上顾客确实在减少 (见下文⑤)，但靠青年商城 (cheongnyeon-mol / 청년몰)·社交媒体·旅游名所化，重新聚集人气的市场也在增多。“衰退”与“复活”正同时进行 (见下文⑥)。

① 传统市场是什么 — 曾是社区心脏的空间

传统市场 (Jeontong Sijang / 전통시장) 是在韩国百货店·大型超市进驻之前，作为社区经济·社会中心的常设·定期市场。

  • 广藏市场 (Gwangjang Market / 광장시장) 是1905年开业的韩国首座常设市场，拥有近120年历史的象征性空间。
  • 光复 (1945年) 之后，南大门 (Namdaemun / 남대문)·东大门 (Dongdaemun / 동대문) 等市场迎来鼎盛期，商人讨价还价、吆喝、谈天，正是社区跳动的脉搏本身。
  • 市场不只是卖东西的地方。从鱼鲜·绸缎到街坊消息无所不通，它是人与人摩肩接踵的生活舞台。

也就是说，看一座传统市场不只是单纯购物，而是窥见韩国人如何吃·如何讨价还价·如何分享人情 (Jeong / 정)。

② 美食·街头小吃 — 市场最闪耀的时刻

对外国人来说，传统市场的第一魅力无疑是美食。尤其广藏市场 (Gwangjang Market / 광장시장) 拥有逾5,000家店铺、每日数万名访客，被誉为能一站尝遍最地道韩国美食的地方。

  • 绿豆煎饼 (bindae-tteok / 빈대떡): 把绿豆磨碎，加入猪肉·绿豆芽·泡菜煎成，是广藏市场的招牌。
  • 麻药紫菜包饭 (mayak-gimbap / 마약김밥): 因“麻药 (好吃到上瘾)”而得名的一口大小迷你紫菜包饭。只放胡萝卜·腌萝卜·菠菜的简朴版本。
  • 生牛肉 (yukhoe / 육회)·刀切面 (kal-guksu / 칼국수)·辣炒年糕 (tteokbokki / 떡볶이)·可乐饼等，各市场招牌不同 (望远市场 (Mangwon Market / 망원시장) 以糖醋炸鸡·可乐饼·刀切面闻名)。

街头小吃就摆在眼前，用手指一指就能点单。在长桌旁与陌生人并肩而坐、被劝饮一杯马格利酒 (makgeolli / 막걸리) 的场景，本身就是韩国市场文化。

> ※ 키친구 (KeyChinGu) 不推荐特定美食店。选店·路线属于另设的场所指南范畴。

③ 讨价还价·折价·添头 — 渐淡的风景，却存活下来的“人情” ★

一提传统市场就想到讨价还价/折价 (Heungjeong/Enuri / 흥정/에누리)。但现实与外国人的想象不同。

  • 讨价还价正在减少。 曾经广泛流行的讨价还价文化，随着时间推移渐渐转向定价制 (jeongchalje / 정찰제)。在定价制扎根的市场，已很难像从前那样压价。
  • 因品类·市场而异。 工业制品·鱼鲜·肉类多贴有价签 (定价)，但像蔬菜这种凭目测而非称重出售的品类，仍留有讨价还价与人情 (insim / 인심) 的余地。南大门 (Namdaemun / 남대문) 在服装·杂货·相机上讨价还价文化最浓，摊主甚至会故意开高价、默认会被砍。
  • 食物价别砍。 蔬菜·杂货另当别论，但对食物价格讨价还价如今被视为失礼。街头小吃·餐厅菜单照定价付即可。
  • 添头 (Deom / 덤) 存活了下来。 即便定价制普及，摊主自行多给的“添头”仍留在市场里。生菜配一把葱，辣炒年糕多舀一勺汤——比起靠讨价还价压价，重心已转向靠添头来往人情 (Jeong / 정)。

> 小结: “一律砍价”是旧印象。如今是因品类而异，食物定价，添头是人情 (insim / 인심)。对外国人而言，心怀感激地收下添头的态度比硬讨价还价更契合市场。

④ 人情 (Jeong / 정) 与摊主厚道 — 不是交易而是关系 ★

传统市场与超市的决定性不同，就在于“人情 (Jeong / 정)”。

  • 买生菜时白送多给一把葱、一勺调料的添头 (Deom / 덤)，不是单纯的服务，而是好意与信任的表示。收下它的那一刻，顾客便不再处于交易，而是踏入关系的网络。
  • 所以市场常客会因为“这里的大婶 (ajumma / 아줌마) 总会多照顾我”而光顾同一家店。他们是为人而去，不是为价格。
  • 对外国人来说，添头常令人不知所措。但拒绝添头有点像拒绝一个拥抱。微微低头、微笑着大声说一句“谢谢 (gamsahamnida / 감사합니다)”，便能原原本本地感受那种相信“食物是用来分享的”文化的温度。

这份“人情”并非韩国市场独有的特殊情感，而是贯穿整个韩国社会的关系方式 (→ 更深的脉络见 #1135 人情文化篇)。

⑤ 大型超市·网购 vs 传统市场 — 客人去哪了 ★

传统市场最大的挑战，是流通结构本身的变化。

  • 顾客减少是事实。 据报道，传统市场顾客在最近五年间减少了约31%。 网购在2015年超过大型超市成为第一大流通渠道，2020年起在销售额上也超过了大型超市。
  • 真正的对手变了。 过去是“大型超市 vs 传统市场”的格局，如今却是“线上 vs 线下”的格局。所以即便大型超市因强制休业关门，客人也不会转去传统市场——那天的客人去的不是超市，而是酷澎 (Coupang / 쿠팡) 这类网购。
  • 消费渠道被切分。 人们把消费分开：日用品上网买，大宗采购去大型超市，生鲜去传统市场。市场存活下来的领域主要是生鲜·美食·体验。

> 谨慎结论: “传统市场要死了”的断言过头了。准确地说，是“作为日用品市场在退守，但正被重塑为美食·体验·旅游空间”。

⑥ 变化 — 危机与复活同时上演 ★

传统市场的当下不是单一方向，而是两股潮流叠加。

危机一侧

  • 把日常消费让给网购·凌晨配送，作为一般日用品市场的地位持续走弱。
  • 政府的青年商城 (cheongnyeon-mol / 청년몰) 扶持起初效果也有限——只靠装修整洁的店铺和青年创业补贴，多数情况下并未能招来客人。

复活一侧

  • 体验型转型: 通仁市场 (Tongin Market / 통인시장) 在2012年引入了铜钱便当 (yeopjeon dosirak / 엽전 도시락)。把钱换成旧时铜钱 (yeopjeon / 엽전)，逛市场时一格格装满小菜的 DIY 午餐，成了外国人喜爱的体验。
  • 复古·文化名所化: 京东市场 (Gyeongdong Market / 경동시장) 把改造自1960年代旧影院的“京东1960星巴克 (Gyeongdong 1960 Starbucks / 경동1960 스타벅스)”(星巴克社区门店) 与青年商城·夜市相结合，变身为 MZ世代 (千禧一代与Z世代) 云集的热门地。韩药材市场前排起20多岁年轻人的队伍，这样的风景出现了。
  • 社交媒体·旅游: 像望远市场 (Mangwon Market / 망원시장) 这样本地氛围浓的市场，也越来越多地借Instagram·旅行内容吸引外国人·年轻访客。VisitKorea (비짓코리아) 等官方渠道也积极把传统市场作为旅游内容来介绍。

> 平衡: 并非所有市场都会复活。拥有美食·体验·复古这类“不可替代魅力”的市场得以存活，而单纯的日用品市场则持续艰难。

⑦ 外国人逛市场实战 — 怎么玩

> 营业·价格因店铺·时期而异 — 建议出发前确认。

  • 备好现金。 广藏 (Gwangjang / 광장)·南大门 (Namdaemun / 남대문) 几乎以现金为主(明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 一带对刷卡更友好)。备上约 ₩50,000 (~270 RMB?) 的小额纸币，在所有摊位都能顺畅交易。南大门相机商城用现金可能报价更低(规避刷卡手续费·税)。
  • 讨价还价要看情况。 杂货·服装可轻松一试，但食物价不砍。比起硬讨价还价，心怀感激地收下添头 (Deom / 덤)更受欢迎。
  • 用手指点单。 摊主英语有限但很热情。食物就在眼前，一指就通。 不少摊位也备有多语菜单。
  • 拼桌是常态。 在长桌旁与陌生人并肩而食。邻座请你的一杯马格利酒 (makgeolli / 막걸리) 也是市场文化的一部分。
  • 冲着体验去。 比起单纯购物，像通仁 (Tongin / 통인) 铜钱便当 (yeopjeon dosirak / 엽전 도시락)(DIY)·京东1960星巴克 (Gyeongdong 1960 Starbucks / 경동1960 스타벅스)(复古) 这类体验型，外国人满意度更高。
  • 1~2小时足够。 想多尝几个摊位，留出2小时绰绰有余。

❓ 外国人常见问题 (FAQ)

  • 在传统市场一定要讨价还价吗？ — 不必。定价制 (jeongchalje / 정찰제) 已广泛普及，对食物价讨价还价被视为失礼。 讨价还价仅限南大门 (Namdaemun / 남대문) 杂货·相机等部分品类。通常按报价付款、心怀感激地收下添头 (Deom / 덤) 即可。
  • 人家给“添头”，我有点不好意思。可以拒绝吗？ — 比起拒绝，微笑道谢更好。添头 (Deom / 덤) 不是亏本买卖，而是摊主的人情 (insim / 인심)，拒绝反而让对方失落。
  • 能刷卡，还是只收现金？ — 因市场·店铺而异。广藏 (Gwangjang / 광장)·南大门 (Namdaemun / 남대문) 以现金为主，明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 一带刷卡也很顺畅。备好小额现金最稳妥。
  • 不通英语怎么点单？ — 食物就在眼前，用手指一指即可。不少摊位备有多语菜单，摊主对外国人大多很热情。
  • 超市·便利店明明更方便，非得去市场吗？ — 单看日用品，超市·网购更方便。但市场给的是另一种价值：美食·人情 (Jeong / 정)·体验——它是去买“体验”而非“交易”的地方。
