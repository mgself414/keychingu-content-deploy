韩国森林放空·水边放空·赤脚漫步指南 — Saryeoni森林路·Bijarim·西归浦治愈森林的森林放空，Soesokkak·顺天湾湿地·Dumulmeori的水边放空，Gyejoksan黄土路·Mulmusan幸福森林的赤脚漫步，共20处

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“适合放空发呆”“脚底(赤脚)”两个主题入选的地方中，韩国观光公社登记了运营信息的森林·竹林·水边·天空·赤脚路20处 · 登记了门票的有Bijarim·Jungnogwon(一般3,000韩元)·顺天湾湿地(成人10,000韩元)·巨济孟宗竹主题公园(成人4,000韩元)等7处 · 西归浦治愈森林需提前预约，顺天湾湿地每月最后一个周一休息 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“适合放空发呆”主题和“脚底(赤脚)”主题入选的地方中，韩国观光公社旅游信息登记了运营信息的20处。表中的排名和得票数就是这次投票的结果。两个主题都入选的地方，两个排名都写了。我们按森林·竹林·水边·天空·赤脚路五类挑选了合适的地方，所以赤脚投票中入选的林荫道(潭阳水杉路，赤脚第3名)·古道(闻庆鸟岭)·城市公园(晋州Namgaram公园·金海Yeonji公园)等没有收入。放空投票中入选的海水浴场·遗址·海岬，如挟才海水浴场(협재해수욕장)·月精桥(월정교)·大陵苑(대릉원)·风之丘(바람의 언덕)·涉地可支(섭지코지)等，也出于同样原因没有收入。

“森林放空(숲멍)”“水边放空(물멍)”是投票推荐理由中常用的韩语说法，指望着森林或水面发呆放空、让身心休息。地点分为森林、竹林、水边、开阔的天空、赤脚路五类。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。没有登记值的栏写作“无登记值”。投票名单中的名称或地址与韩国观光公社登记不同的地方，正文中另行说明。

📍 森林放空 — Saryeoni森林路·Bijarim·西归浦治愈森林·Jeolmul自然休养林·Gotjawal道立公园

Saryeoni森林路 (Saryeoni Sup-gil / 사려니숲길)的韩国观光公社登记地址是西归浦市 (Pyoseon-myeon Gasi-ri Bulgeun-oreum Ipgu / 표선면 가시리 붉은오름 입구)。这是一条从Bijarim-ro (비자림로)出发，经过Mulchat-oreum (물찻오름)和Saryeoni-oreum (사려니오름)的柳杉林路。因为一直延伸到Saryeoni-oreum，所以得名。据韩国观光公社介绍，“Saryeoni”的意思是神圣的森林，或是“把线之类的东西不使散开、一圈圈叠着绕起来”。除柳杉外，还生长着枹栎·鹅耳枥·野茉莉·日本扁柏，属于2002年联合国教科文组织指定的济州生物圈保护区。投票名单中的地址是济州市 (Bonggae-dong San 64-5 / 봉개동 산64-5)。

  • 开放时间·休息日·费用:无登记值。

Bijarim (비자림)位于济州市 (Gujwa-eup Bijasup-gil 55 / 구좌읍 비자숲길 55)，☎ 064-710-7911~2，是被指定为天然纪念物的森林。在448,165㎡的面积上，生长着树龄500~800年的榧子树2,800余棵。树高7~14m，直径50~110㎝。据韩国观光公社介绍，这是世界上少见的榧子树林。

  • 开放时间:09:00~18:00(入场截止 17:00)。休息日:全年无休。
  • 费用(个人):一般3,000韩元，青少年·儿童1,500韩元。学龄前儿童免费。

西归浦治愈森林 (Seogwipo Chiyuui Sup / 서귀포 치유의 숲)位于西归浦市 (Sanrungnam-ro 2271 / 산록남로 2271)，☎ 064-760-3067，是海拔320~760m的森林。暖带林·温带林·寒带林均衡生长，据韩国观光公社介绍，有多处平均树龄60年以上的日本扁柏林。设有由森林治愈指导师带领的森林治愈项目。

  • 开放时间:4~10月 08:00~16:00，11~3月 09:00~16:00。需提前预约后使用，有剩余名额时也可以当天在线预约和现场取票。登记的容纳人数为工作日300人，周末600人。
  • 休息日:全年无休。
  • 费用(个人):成人1,000韩元，青少年600韩元。森林治愈项目3小时左右成人20,000韩元，2小时左右成人12,000韩元。

济州Jeolmul自然休养林 (Jeju Jeolmul Jayeonhyuyangnim / 제주절물자연휴양림)位于济州市 (Myeongnim-ro 584 / 명림로 584)，☎ 064-728-1510，是柳杉林休养林。以1960年代中期开始栽种的柳杉为主。介绍中写道，步道坡度平缓、没有台阶，老人和儿童走起来也轻松。附近Jeolmul-oreum (절물오름)山顶的瞭望台上可以看到马蹄形的火山口。

  • 开放时间:3~10月 07:00~18:00，11~2月 07:00~17:00。休息日:全年无休。
  • 费用(个人):成人1,000韩元，青少年600韩元，儿童300韩元。

济州Gotjawal道立公园 (Jeju Gotjawal Doripgongwon / 제주곶자왈도립공원)位于西归浦市 (Daejeong-eup Edusiti-ro 178 / 대정읍 에듀시티로 178)，☎ 064-792-6047，其中的Gotjawal (곶자왈)是指在岩块不规则散布的土地上形成的森林。有Teuri-gil·Hansugi-gil·Bille-gil·Ochani-gil·Gasinang-gil五条路线 (테우리길·한수기길·빌레길·오찬이길·가시낭길)，每天进行两次森林讲解。必须穿登山鞋或运动鞋，穿皮鞋·凉鞋·增高运动鞋不能入内。

  • 开放时间:3~10月 入场 09:00~16:30(游览至 18:00)，11~2月 入场 09:00~15:00(游览至 17:30)。休息日:全年无休。
  • 费用:一般1,000韩元，青少年·军人800韩元，儿童500韩元。

📍 竹林 — Jungnogwon·太和江国家庭园·巨济孟宗竹主题公园·蟾津江竹林路

Jungnogwon (죽녹원)位于潭阳郡 (Damyang-eup Jungnogwon-ro 119 / 담양읍 죽녹원로 119)，☎ 061-380-2680，是2003年5月开放的竹林。总长2.2㎞的步道分为Unsudaetong-gil·Jungmagou-gil·Cheolhakja-ui Gil (운수대통길·죽마고우길·철학자의 길)等八条主题路。在瞭望台上可以俯瞰Damyangcheon (담양천)、Gwanbangjerim (관방제림)和水杉林荫道。竹林里装了灯，夜晚也可以散步。

  • 开放时间:3~10月 09:00~19:00(入场截止 18:00)，11~2月 09:00~18:00(入场截止 17:30)。休息日:全年无休。
  • 费用(个人):一般3,000韩元，青少年·军人1,500韩元，小学生1,000韩元。65岁以上·未满6周岁免费。

太和江国家庭园 (Taehwagang Gukgajeongwon / 태화강 국가정원)位于蔚山中区 (Saetgangnam-gil 5 / 샛강남길 5)，☎ 052-229-3147~8，是沿太和江而建的生态庭园。在总面积835,452㎡的园内，有生态·竹子·四季·水生·参与·木槿花六个空间。据韩国观光公社介绍，十里竹林 (Sibridaesup / 십리대숲)以风吹竹子的声音和安静的小路而闻名。投票名单中以“太和江国家庭园 黄土赤脚路 (Taehwagang Gukgajeongwon Hwangto Maenbal-gil / 태화강 국가정원 황토맨발길)”的名称入选，但韩国观光公社的介绍中没有关于黄土赤脚路的说明，投票名单中的地址 (Taehwagang-gukgajeongwon-gil 154 / 태화강국가정원길 154)也与韩国观光公社登记的地址不同。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

巨济孟宗竹主题公园 (Geoje Maengjongjuk Temagongwon / 거제 맹종죽테마공원)位于巨济市 (Hacheong-myeon Geojebuk-ro 700 / 하청면 거제북로 700)，☎ 055-637-0067，是在孟宗竹林里休息和体验的公园。据韩国观光公社介绍，孟宗竹高10~20m，直径20㎝左右，是竹子中最粗的。有孟宗竹林体验、工艺体验和探险森林体验。投票名单中以“巨济孟宗竹主题乐园 (Geoje Maengjongjuk Temapakeu / 거제 맹종죽테마파크)”的名称入选。

  • 开放时间:3~10月 09:00~18:00，11~2月 09:00~17:30。休息日:全年无休。
  • 费用(个人):成人4,000韩元，青少年3,000韩元，儿童2,000韩元。停车免费。

蟾津江竹林路 (Seomjingang Daenamu Supgil / 섬진강 대나무숲길)位于求礼郡 (Gurye-eup Wonbang-ri 1 / 구례읍 원방리 1)，是沿蟾津江延伸约2.5km的散步道。介绍中写道，可以与江水并行，一边走一边看到智异山的山脊。入口处有月牙形、里面有满月形的拍照点，天黑后会亮灯。

  • 开放时间·休息日·费用:无登记值。

📍 水边放空 — Soesokkak·顺天湾湿地·Wiyangji·Dumulmeori·Uirimji·盘浦汉江公园

Soesokkak (쇠소깍)位于西归浦市 (Soesokkak-ro 104 / 쇠소깍로 104)，☎ 旅游咨询处 (Gwangwang Annae-so / 관광안내소) 064-732-1562，是Hyodoncheon (효돈천)的淡水和海水交汇、形成深潭的地方。据韩国观光公社介绍，“Soe (쇠)”是牛，“So (소)”是水潭，“Kkak (깍)”是尽头。熔岩凝固形成的山谷里，奇岩怪石与松林相映成趣。有小舟和Teu (테우)木筏体验。

  • 开放时间:Soesokkak全天开放。体验夏季 09:00~18:00，冬季 09:00~17:00，天气不好时不运营。
  • 休息日:全年无休。
  • 费用:Soesokkak免费。小舟成人2人20,000韩元，Teu (테우)木筏成人1人10,000韩元。

顺天湾湿地 (Suncheonman Seupji / 순천만습지)位于顺天市 (Suncheonman-gil 513-25 / 순천만길 513-25)，☎ 061-749-3114，是从顺天的Dongcheon (동천)和Isacheon (이사천)汇合处到滩涂前，总面积5.4㎢的芦苇群落铺展开来的地方。有天文台星光体验和芦苇丛滩涂探险等。投票名单中另有“顺天湾湿地 顺天湾芦苇群落地 (Suncheonman Seupji Suncheonmangaldae Gunnakji / 순천만습지 순천만갈대군락지)”以放空第12名(192票)入选。

  • 开放时间:3~4月·9~10月 08:00~18:00，5~8月 08:00~19:00，11~2月 08:00~17:00。登记值中同时写有“入场截止后1小时内可以参观”。
  • 休息日:每月最后一个周一。
  • 费用(个人):成人10,000韩元，青少年·军人7,000韩元，儿童5,000韩元。

密阳 Wiyangji (Miryang Wiyangji / 밀양 위양지)位于密阳市 (Bubuk-myeon Wiyang-ro 273-36 / 부북면 위양로 273-36)，是新罗时代为引农业用水而修筑的水库。水库中间有五座小岛和亭子Wanjaejeong (완재정)。介绍中写道，流苏树花盛开时风景最美。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

杨平 Dumulmeori (Yangpyeong Dumulmeori / 양평 두물머리)位于杨平郡 (Yangseo-myeon Dumulmeori-gil 145 / 양서면 두물머리길 145)，☎ 旅游咨询处 (Gwangwang Annae-so / 관광안내소) 031-775-8700，是北汉江和南汉江汇合的地方。以清晨的水雾和400多年树龄的榉树而闻名，据韩国观光公社介绍，入选了韩国观光100选。投票名单中的地址是 (Yangseo-myeon Yangsu-ri / 양서면 양수리)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

堤川 Uirimji (Jecheon Uirimji / 제천 의림지)位于堤川市 (Uirimji-ro 33 / 의림지로 33)，☎ 043-651-7101，是三韩时代修筑的水库，周长1.8㎞。介绍中写道，称忠清道为“湖西地方 (호서지방)”时的“湖”指的就是Uirimji。湖边有1807年建的Yeongho亭 (Yeonghojeong / 영호정)、1948年建的Gyeongho楼 (Gyeongholu / 경호루)、数百年树龄的松树和垂柳，以及30m高的天然瀑布。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

盘浦汉江公园 (Banpo Hangang Gongwon / 반포한강공원)位于首尔瑞草区 (Sinbanpo-ro 11-gil 40 / 신반포로11길 40)，☎ 02-3780-0541~4，在汉江南侧、以盘浦大桥为中心，位于汉南大桥和铜雀大桥之间。据韩国观光公社介绍，盘浦大桥的月光彩虹喷泉长1,140m，2008年被吉尼斯认定为世界上最长的桥梁喷泉。有环绕盘浦大桥和铜雀大桥之间人工岛Seorae岛 (Seoraeseom / 서래섬)一圈的散步路线。

  • 开放时间:全天开放(喷泉运营时间请参考官网)。休息日:全年无休。费用:免费。

📍 天空放空 — 天空公园·Anbandegi

天空公园 (Haneul Gongwon / 하늘공원)位于首尔麻浦区 (Haneul-gongwon-ro 95 / 하늘공원로 95)，☎ 世界杯公园 (Woldeukeop Gongwon / 월드컵공원) 02-300-5500，在世界杯公园内。这里是把曾经的垃圾填埋场改造成的生态公园。秋天芒草盛开，北汉山和汉江等首尔风景一览无余。也以晚霞和夜景而闻名。“脚底(赤脚)”投票中以“天空公园 Sogonsogon路 (Haneul Gongwon Sogonsogon-gil / 하늘공원 소곤소곤길)”的名称入选。

  • 开放时间:05:00~20:30。休息日:全年无休。费用:免费。

江陵 Anbandegi (Gangneung Anbandegi / 강릉 안반데기)位于江陵市 (Wangsan-myeon Anbandegi-gil 428 / 왕산면 안반데기길 428)，☎ 江陵市观光政策科 (Gangneung-si Gwangwang Jeongchaek-gwa / 강릉시 관광정책과) 033-640-5125，是海拔1,100m高山地带的白菜田。1965年起火田民削山开垦，因为坡度陡，没有机械，全靠人力耕田。约200万㎡的土地成了高冷地白菜田。投票名单中以“Wau Anbandegi (와우안반데기)”的名称和 (Anbandegi-gil 440-1 / 안반데기길 440-1)的地址入选，推荐理由是夜空中的银河。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 赤脚漫步 — Gyejoksan黄土路·Mulmusan幸福森林·Daewangam公园

Gyejoksan黄土路 (Gyejoksan Hwangtotgil / 계족산 황톳길)位于大田 (Daedeok-gu Jang-dong / 대덕구 장동)，是2006年铺了2万多吨黄土修成的赤脚徒步路。介绍中写道，坡度平缓，赤脚走也不吃力。另有穿鞋走的环山路。起点处有森林广场，还有游乐场·凉亭之类的便利设施和洗脚处。

  • 开放时间·休息日·费用:无登记值。

Mulmusan幸福森林 (Mulmusan Haengbok Sup / 물무산 행복숲)位于灵光郡 (Yeonggwang-eup Mulmu-ro 219 / 영광읍 물무로 219)，☎ 灵光郡山林公园科 (Yeonggwang-gun Sallim Gongwon-gwa / 영광군 산림공원과) 061-350-5779，是设有10㎞环山路、2㎞赤脚黄土路、2处日本扁柏Yeongsangwon (편백 영상원)、松林和登山路等的森林。黄土路在Mulmusan后面，分为0.6㎞的泥泞黄土路和1.4㎞的干燥黄土路，可以选择走。投票名单中以“Mulmusan幸福森林 赤脚黄土路 (Mulmusan Haengbok Sup Maenbal Hwangtotgil / 물무산행복숲 맨발황톳길)”的名称和 (Myoryang-myeon Deokheung-ri / 묘량면 덕흥리)的地址入选。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Daewangam公园 (Daewangam Gongwon / 대왕암공원)位于蔚山东区 (Deungdae-ro 95 / 등대로 95)，☎ 052-209-3738，是从入口到Ulgi灯塔 (Ulgi Deungdae / 울기등대)有600m松林路的公园。据韩国观光公社介绍，树龄100多年的松树树荫连绵不断，走出松林后是海岸悬崖和巨大的岩石。投票名单中以“Daewangam公园 松林路 (Daewangam Gongwon Songnimgil / 대왕암공원 송림길)”的名称入选。有吊桥和Ulgi灯塔。

  • 开放时间:全天开放。休息日:全年无休。费用:无登记值。

⚠ 行前须知 3 点

  1. 西归浦治愈森林需要预约 — 需提前预约后使用，登记的容纳人数为工作日300人，周末600人。
  2. Gotjawal道立公园不是赤脚走的地方 — 必须穿登山鞋或运动鞋，穿皮鞋·凉鞋·增高运动鞋不能入内。
  3. 确认冬季时间和休息日 — 11~2月，Jungnogwon·Gotjawal道立公园·Jeolmul自然休养林·顺天湾湿地等多处的关门时间提前，顺天湾湿地每月最后一个周一休息。

⚙ FAQ 3

Q. 离首尔近的地方有哪些?

A. 首尔市内有盘浦汉江公园和天空公园，Gyeonggi 杨平还有Dumulmeori。三处都登记为免费。

Q. 介绍为适合赤脚走的地方有哪些?

A. Gyejoksan黄土路(赤脚徒步路)和Mulmusan幸福森林(2㎞赤脚黄土路)。两处在韩国观光公社的介绍中都写有赤脚路。太和江国家庭园和Daewangam公园在“脚底(赤脚)”投票中是第1名和第2名，但韩国观光公社的介绍中没有关于赤脚路的说明。

Q. 哪些地方要花钱?

A. Bijarim(一般3,000韩元)，西归浦治愈森林(成人1,000韩元)，济州Jeolmul自然休养林(成人1,000韩元)，济州Gotjawal道立公园(一般1,000韩元)，Jungnogwon(一般3,000韩元)，巨济孟宗竹主题公园(成人4,000韩元)，顺天湾湿地(成人10,000韩元)。Soesokkak免费，但乘船体验另收费。
