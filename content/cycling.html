🎯 왜 서울 자전거·라이딩 가이드인가

서울 한강 자전거 도로 130km는 세계 도시 중 손꼽히는 자전거 인프라 — 강서 행주대교에서 강동까지 한강 양쪽 따라 연결, 90% 이상이 자전거 전용도로. 따릉이(서울 공유 자전거) 가입자 330만+, 외국인도 영문 앱으로 가입 가능. Reddit r/koreatravel "Han River bike"·"Seoul cycling" 키워드 빈출. Activity 시리즈 #5 — #146 러닝 / #147 야간 러닝 / #148 등산 / #151 캠핑·BBQ / #149 자전거.

⚠ 외국인 자주 하는 실수 3가지

1. 따릉이 가입 한국 휴대폰 번호 필수

따릉이 앱(영문) — 한국 휴대폰 SMS 인증 필요. 외국인 sim·통신사 가입 + 카드 필수. 단기 외국인은 호텔·한국 친구 도움 또는 사설 자전거 대여 (1577-0190 한강배달 + 자전거 대여 서비스 ₩3,000/시간).

2. 자전거 도로 vs 보행자 도로 구분 모름

한강 자전거 도로는 녹색 표지, 보행자 도로는 회색. 일부 구간 (반포·여의도) 자전거 + 보행자 혼용 — 속도 줄이기. 한강대교·동호대교 등 다리 위 자전거 도로 별도.

3. 여름철 11~16시 직사광·일사병

한강 자전거 도로 그늘 부족 — 여름 새벽 6~9시 또는 저녁 19~22시 권장. 11~16시 직사광 피하기. 헬멧·물·자외선 차단제 필수.

서울 자전거 인프라

서울 자전거 culture·인프라:

  • 한강 자전거 도로 130km = 강서 행주대교 ↔ 강동 (한강 양쪽)
  • 자전거 전용도로 90%+ — 도시 자전거 안전도 최상위
  • 따릉이 (Ttareungi) = 서울 공유 자전거, 가입자 330만+, 1시간 ₩1,000
  • 사설 자전거 대여 = 한강공원 매점·반포·여의도 일대 ₩3,000~₩5,000/시간
  • 자전거 전용 다리 = 잠수교 (반포)·동호·잠실·광나루 등
  • 자전거 + 지하철 = 자전거 휴대 가능 (지하철 일부 시간 + 9호선 1량 후미)

외국인 4가지 의도:

1. 입문 짧은 코스 — 반포·여의도 6~8km (1시간)

2. 야경·인스타 — 한강 야경 13km (따릉이 1위) + 노들 9km (2위)

3. 일주·종주 — 50km 한 바퀴 / 130km 종주

4. 외곽·도심 — 탄천·청계천 (다양한 톤)

4축 매핑

  • ① 입문 (2): 반포·여의도 — 1시간 짧은 코스
  • ② 야경·따릉이 인기 (2): 한강 야경 13km·노들-여의도-샛강 9km — 외국인 따릉이 1·2위
  • ③ 일주·종주 (2): 잠수교-행주대교 50km·한강 종주 130km — 매니아
  • ④ 외곽·도심 (2): 탄천·양재천·청계천 — 한강 외 코스

① 입문 (2 코스)

1. 반포 한강공원 코스

외국인 자전거 입문 1순위 — 반포 한강 8km loop. 반포대교 남단에서 시작, 잠수교 → 한강 남단 → 잠수교 복귀 8km. 따릉이 또는 사설 대여 ₩3,000/시간. 달빛무지개분수 시즌(4~10월) 19:30~21:30 야간 코스 best.

  • 시작점: 9호선 신반포역 1번 출구 도보 5분
  • 거리/시간: 8km / 약 45~60분
  • 난이도: 입문 (평탄·자전거 도로 100%)
  • 시그니처: 달빛무지개분수·잠수교·한강 view
  • 대여: 따릉이 또는 사설 ₩3,000/시간
  • 왜: 외국인 첫 한강 자전거. 풍경·인프라·대여 다 OK.

2. 여의도 한강공원 코스

여의도 한 바퀴 6km — 윤중로 + 63빌딩 view. 5호선 여의나루역 도보 3분. 봄(3~4월) 윤중로 벚꽃 시즌 절정. Runner's Station 무료 locker.

  • 시작점: 5호선 여의나루역 4번 출구
  • 거리/시간: 6km / 약 35~50분
  • 난이도: 입문 (평탄)
  • 시그니처: 윤중로 벚꽃·63빌딩·한강철교
  • 대여: 따릉이 + Runner's Station 사설 대여
  • 왜: 봄 벚꽃 시즌 1순위. Runner's Station 시설 결합.

② 야경·따릉이 인기 (2 코스)

3. 한강 야경 13km (따릉이 1위)

서울시민이 직접 뽑은 따릉이길 1위 — 뚝섬 → 동호대교 → 반포대교 → 노들섬 13km. 한강 야경 명소 한 번에. 자전거 전용도로 정비 best, 초보~숙련자 모두 쾌적.

  • 시작점: 7호선 뚝섬유원지역
  • 거리/시간: 13km / 약 70~90분
  • 난이도: 중급 (평탄·중거리)
  • 시그니처: 뚝섬 야경 → 동호 → 반포 분수 → 노들섬 360°
  • 시간 추천: 일몰 17~20시 (분수 시즌이면 21~22시)
  • 왜: 외국인 자전거 야경 코스 1순위. 따릉이 시민 투표 best.

4. 노들~여의도~샛강~양화 9km (따릉이 2위)

자전거 도로 90% — 안전 best 9km. 노들역 → 여의도 수변광장 → 샛강 생태공원 → 양화 한강공원. 외국인 가족·초보 best (교통사고 걱정 0).

  • 시작점: 9호선 노들역
  • 거리/시간: 9km / 약 50~70분
  • 난이도: 입문 (자전거 도로 90%, 가장 안전)
  • 시그니처: 샛강 생태공원·여의도 수변·양화 한강
  • 시간 추천: 봄·가을 오전 9~11시
  • 왜: 외국인 가족·초보 best. 안전도 1위.

③ 일주·종주 (2 코스)

5. 잠수교~행주대교 남북 순환 50km

한강 양쪽 한 바퀴 — 잠수교 시작, 행주대교 회전, 잠수교 복귀. 한강 남단·북단 모두 경험. 봄·가을 시즌 best. 매니아 입문.

  • 시작점: 반포 잠수교 (9호선 신반포역)
  • 거리/시간: 50km / 약 3.5~5시간
  • 난이도: 중상급 (평탄이지만 거리 김)
  • 시그니처: 한강 양쪽·반포 분수·여의도·잠실·행주대교
  • 준비물: 헬멧·물 2L·간식·공구 (튜브 펑크 등)
  • 왜: 한강 일주 매니아 코스. 1일 코스로 충분.

6. 한강 종주 130km

한강 자전거길 전체 종주 — 강서 행주대교 ↔ 강동 팔당. 한강 전체. 14~16시간 (1일 또는 1박2일). 국토종주 인증 패스 발급 가능.

  • 시작점: 강서 행주대교 또는 잠실 (서울 끝)
  • 거리/시간: 130km / 약 14~16시간 (1일) 또는 1박2일
  • 난이도: 고급 (장거리)
  • 시그니처: 한강 전체·국토종주 인증
  • 준비물: 헬멧·물 4L·간식·공구·예비 튜브·라이트 (야간 가능)
  • 왜: 한강 종주 매니아 챌린지. 외국인 자전거 매니아 1순위 도전 코스.

④ 외곽·도심 (2 코스)

7. 탄천·양재천 강남 외곽

강남 외곽 한적 코스 15~25km. 양재시민의숲역에서 시작, 탄천 따라 한강까지. 한강 자전거 도로보다 한적·자연 풍경. 강남 거주 외국인 출퇴근 + 라이딩 결합.

  • 시작점: 신분당선 양재시민의숲역
  • 거리/시간: 15~25km / 약 1.5~2시간
  • 난이도: 중급 (평탄·한적)
  • 시그니처: 탄천·양재천·강남 외곽 자연
  • 시간 추천: 가을 단풍·봄 벚꽃
  • 왜: 한강 외 옵션. 강남 코스 + 자전거 결합.

8. 청계천 도심 자전거

광화문 → 청계천 LED → 동대문 → DDP 8km. 도심 한가운데 자전거. 자전거 도로 일부 + 보행자 도로 혼용. 야간 LED 조명 best.

  • 시작점: 5호선 광화문역 또는 종각역
  • 거리/시간: 8km / 약 50~60분
  • 난이도: 입문 (평탄·도심)
  • 시그니처: 청계천 LED·광화문·DDP 야경
  • 시간 추천: 야간 19~22시 (LED 조명)
  • 왜: 도심 자전거. 종로·DDP 관광 + 라이딩 결합.

⚙ FAQ 8개

Q1. 외국인 따릉이 가입?

한국 휴대폰 번호 + 한국 카드 필수. 외국인 등록증·여권으로는 직접 가입 X. 호텔·한국 친구 도움 또는 사설 대여 (반포·여의도 매점 ₩3,000/시간) 권장. 외국인 e-SIM 일부 작동.

Q2. 사설 자전거 대여 어디서?

  • 반포 한강공원 — 매점 in-site 대여 ₩3,000~₩5,000/시간
  • 여의도 한강공원 — Runner's Station 인근 + 사설 대여
  • 뚝섬 한강공원 — 매점 + 자전거 보관소
  • 잠실 한강공원 — 사설 대여 풍부
  • 노들섬 — 노들섬 입구 대여

Q3. 헬멧·장비 어디서?

대부분 사설 대여 매점에서 헬멧 포함 (의무는 아니지만 권장). 본격 매니아는 데카트론 (강남·잠실) 헬멧 ₩30,000~₩80,000 구매.

Q4. 시간대 best?

  • 봄·가을: 오전 8~11시 (한산) 또는 일몰 16~19시
  • 여름 (7~8월): 새벽 6~9시 (폭염 회피) 또는 저녁 19~22시
  • 겨울 (12~2월): 낮 11~14시 (가장 따뜻)

Q5. 비 오는 날 대안?

비 오는 한강 자전거 = 위험 (미끄럼·사고). 비 예보 시 대안:

  • 박물관·DDP·인사동 도보 관광
  • 호텔 헬스장 (실내 자전거)

Q6. 외국인 라이딩 크루?

Seoul Cycling Club (Facebook + Strava) — 외국인 위주 weekly 라이딩. Han River Foreign Cyclists (Instagram 그룹). 영어 OK.

Q7. 자전거 + 지하철?

서울 지하철 자전거 휴대 가능 — 일부 시간대 (주말·공휴일) 또는 9호선 후미 1량 (평일 OK). 한강 라이딩 후 멀리 갈 때 활용.

Q8. 라이딩 후 마무리 (음식·찜질방)?

  • 한강 치맥 — 1577-0190 한강배달 (라이딩 후 시그니처)
  • 카페·국밥 — 라이딩 종점 따라 (#142 강남 카페·#133 국밥)
  • 찜질방 — 양재·잠실 (#7 찜질방 가이드)

🗺 추천 1일 자전거 코스 3가지

A코스 — "외국인 입문 + 야경" (외국인 첫 라이딩, 5시간)

오후 15:00 → 반포 한강공원 8km 사설 대여 (1시간) → 야경 시간 17:00 → 한강 야경 13km (뚝섬-반포-노들 1.5시간) → 노들섬 인스타 사진 → 한강 라면 + 치맥 마무리

B코스 — "한강 일주 50km" (중상급 매니아, 5시간)

아침 8:00 → 잠수교 시작 → 잠수교~행주대교 남북 순환 50km (3.5~4시간) → 잠수교 복귀 13:00 → 한강 라면·맥주 → 호텔 휴식

C코스 — "한강 종주 130km" (고급 매니아, 풀 day 14시간)

새벽 5:00 → 강서 행주대교 시작 → 한강 종주 130km → 강동·팔당 도착 19:00 → 인증·기념·찜질방

🌸 시즌·시간대 훅 5개

1. 봄 (4~5월) 윤중로 벚꽃 라이딩: 여의도 6km + 윤중로 벚꽃 절정. 외국인 인스타 1순위.

2. 여름 (7~8월) 새벽·야간: 폭염 회피. 새벽 6~9시 또는 저녁 19~22시.

3. 가을 (10~11월) 단풍 라이딩: 한강 양쪽 + 탄천 단풍 시즌. 절경.

4. 분수 시즌 (4~10월) 반포 야경: 달빛무지개분수 19:30~21:30 + 반포 8km 라이딩.

5. 겨울 (12~2월) 한산한 한강: 영하 위험 — 글램핑/실내로 전환. 라이딩은 영상 4°C+ 일 권장.
