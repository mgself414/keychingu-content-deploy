📍 Gongdeok·Mapo站 — 猪蹄街·饮食文化街·万岁示威地

Gongdeok-dong猪蹄街(Gongdeok-dong Jokbal Golmok / 공덕동 족발골목)，麻浦区(Mallijae-ro 19 / 만리재로 19)，☎ 麻浦旅游信息中心(Mapo Gwangwang Jeongbo Center / 마포관광정보센터) 02-334-7878，是从市场一角的小餐馆发展起来的小巷。当年有家店为市场里的人们煮Sundaeguk(Sundaeguk / 순댓국)当饭，并做猪蹄当下酒菜，生意兴隆后，周围猪蹄店越来越多，渐渐成了一条小巷。据介绍，也有世代相传卖Sundaeguk和猪蹄的店。

  • 开放时间·休息日:各店铺不同。停车:不可以。

麻浦饮食文化街(Mapo Eumsik Munhwa Geori / 마포음식문화거리)，麻浦区Yonggang-dong(Yonggang-dong / 용강동)，是也被称为“Mapo Yonggang Matkkaebi-gil(Mapo Yonggang Matkkaebi-gil / 마포용강 맛깨비길)”的美食街。从Mapo站1号出口起，大路两边排满了餐馆。有很多Jumulleok(Jumulleok / 주물럭)、Kkeopdegi(Kkeopdegi / 껍데기)、猪排骨(Dwaeji Galbi / 돼지갈비)之类的烤肉店，餐馆巷共有37条。这里是Tojeong Yi Ji-ham(Tojeong Yi Ji-ham / 토정 이지함)住过的地方，街上有他的雕像和鱼形雕塑。

  • 开放时间·休息日:各店铺不同。停车:不可以。

麻浦电车终点站 3·1运动万岁示威地(Mapo Jeoncha Jongjeom 3·1 Undong Manse Siwiji / 마포전차종점 3·1운동 만세 시위지)，麻浦区(Mapo-daero 20 / 마포대로 20)，☎ 麻浦区厅文化艺术科(Munhwa Yesul-gwa / 문화예술과) 02-3153-8350，位于现在的地铁5号线Mapo站(Mapo-yeok / 마포역)通往麻浦大桥(Mapo Daegyo / 마포대교)的路段。从日本殖民统治时期到1960年代末，这里一直是电车终点站。1919年3月1日晚上8点左右，约1,000人聚集在这里高呼独立万岁。这里立有纪念碑。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

📍 Seongsan-dong — 文化储备基地·首尔世界杯体育场·麻浦农水产品市场

文化储备基地(Munhwa Bichuk Giji / 문화비축기지)，麻浦区(Jeungsan-ro 87 / 증산로 87)，☎ 02-376-8420，是改造旧麻浦石油储备基地而成的文化公园。1973年石油危机后，在1976~78年建了5个储油罐，储存了6,907万L石油，2002年世界杯前夕因安全问题关闭。2013年通过市民创意征集确定了现在的用途。5个储油罐成了文化空间，用拆除的储油罐钢板建成的T6是社区空间。据介绍这里会举办集市、展览、演出和工作坊。

  • 开放时间:户外公园全天开放。储油罐T1~T6和咖啡厅Tank6周二~周日 10:00~18:00。因空间使用日程，储油罐的出入可能受限。
  • 休息日:储油罐和咖啡厅每周一。若周一是法定节假日则开放。
  • 费用:免费。停车:可以(42辆)，小客车每5分钟150韩元。

首尔世界杯体育场(Seoul Worldcup Gyeonggijang / 서울월드컵경기장)，麻浦区(Worldcup-ro 240 / 월드컵로 240)，☎ 02-2128-2002，是为2002年FIFA世界杯建造的体育场。介绍中写的是最多66,000人，座位项登记为主体育场66,704席、辅助体育场1,012席。这里举办国家队主场比赛和K League比赛。

  • 开放时间:09:00~18:00。休息日:全年无休。
  • 停车:体育场停车场(以西侧为准)小型车每5分钟150韩元，中型车300韩元，大型车450韩元。

麻浦农水产品市场(Mapo Nongsusanmul Sijang / 마포농수산물시장)，麻浦区(Worldcup-ro 235 / 월드컵로 235)，☎ 商户会(Sangin-hoe / 상인회) 02-309-0419，是位于首尔世界杯体育场附近的两层楼市场。介绍中写的是1998年开业，开业日项登记为2026-03-12，两个值不一致。1层有水产品·水果·蔬菜店铺和超市，2层有生鱼片中心(Hoe Center / 회센터)和餐饮街。

  • 开放时间·休息日:各店铺不同。停车:可以。

📍 Sangam-dong — 韩国映像资料院

韩国映像资料院(Hanguk Yeongsang Jaryowon / 한국영상자료원)，麻浦区(Worldcupbuk-ro 400 / 월드컵북로 400)，☎ 02-3153-2001，是1974年以韩国胶片保管所(Hanguk Pilleum Bogwanso / 한국필름보관소)起步的公共机构，位于Sangam DMC园区。负责收集和保存电影资料。在Cinematheque KOFA放映国内外的经典·艺术·独立电影，在韩国电影博物馆(Hanguk Yeonghwa Bakmulgwan / 한국영화박물관)可以了解韩国电影的历史。在映像图书馆(Yeongsang Doseogwan / 영상도서관)可以查阅电影资料。

  • 开放时间:韩国映像资料院 10:00~19:00，韩国电影博物馆 10:30~19:00，映像图书馆 10:00~18:50。
  • 休息日:每周日·周一、1月1日、春节·中秋假期、创立纪念日、劳动节。
  • 费用:免费。

⚠ 行前须知 3 点

  1. 韩国映像资料院周日和周一休息 — 文化储备基地的储油罐和咖啡厅周一休息。
  2. Gongdeok·Mapo站一带的小巷不能停车 — 猪蹄街、饮食文化街、万岁示威地都登记为不可停车。
  3. 文化储备基地的储油罐18:00闭馆 — 户外公园全天开放。

⚙ FAQ 2

Q. 哪里可以免费参观?

A. 按观光公社登记信息，文化储备基地、韩国映像资料院、麻浦电车终点站 3·1运动万岁示威地、麻浦饮食文化街都是免费的。

Q. 世界杯体育场附近能买菜吗?

A. 体育场附近有麻浦农水产品市场(Mapo Nongsusanmul Sijang / 마포농수산물시장)。1层卖水产品·水果·蔬菜，2层有生鱼片中心和餐饮街。
