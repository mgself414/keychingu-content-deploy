⚠ 외국인 자주 실수 5가지

1. "루프탑 = 비쌈": 한국 루프탑 = 15,000~50,000원 1인 (호텔 럭셔리 100,000원+) + 외국인 매니아 1번지 가성비.

2. "호텔 루프탑 = 못 들어감": 5성급 호텔 루프탑·라운지 = 외국인 친화 1순위 + 영문 OK + 외국인 매니아 1번지.

3. "루프탑 = 여름만": 한국 루프탑 = 봄·여름 야경 + 가을 단풍 야경 + 겨울 일루미네이션 연중 매니아.

4. "한남 루프탑 = 어디나": 한남 = 외국인 거주 1번지 (#144) + 루프탑 매장 1순위 + 외국인 매니아.

5. "잠실 롯데타워 = 너무 비쌈": 시그니엘 (#9) 또는 Seoul Sky (#82) = 외국인 매니아 1번지 + 555m 한국 #1 야경.

⚙ FAQ 6개

1. 외국인 루프탑 1순위: 시그니엘 (롯데타워)·반얀트리 Moon Bar·The Griffin·콘래드.

2. 외국인 가성비 루프탑: 15,000~50,000원 1인 + 한남·이태원·강남·DDP·종로.

3. 외국인 럭셔리 루프탑: 시그니엘·JW메리어트·콘래드·반얀트리 100,000원+.

4. 외국인 한강 view 1순위: 콘래드 (여의도)·반얀트리 (남산)·JW메리어트 (강남).

5. 외국인 인스타 1순위: The Griffin (한남)·시그니엘 (잠실)·DDP LED.

6. 외국인 1박2일 루프탑 코스: Day 1 한남·이태원·강남 / Day 2 잠실·여의도·DDP.
