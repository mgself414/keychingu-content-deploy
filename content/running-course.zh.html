首尔跑步路线9处 — 国民投票选出的汉江·市中心·林荫路，距离和交通方式

副标题: 韩国观光公社"名胜发掘100×100"跑步路线主题国民投票中进入前33名的首尔9处，按汉江、市中心、公园·林荫路、江南河川4个片区整理。三处汉江公园的8.4km·7.2km·11.5km不是跑步路线的距离，而是公园长度。奥林匹克公园22:00起不能进入园内，清溪川预计开启水闸时禁止进入。盘浦月光彩虹喷泉只在3月15日到10月运行。距离、开放时间、地铁站和出口、寄存行李的地方，主要整理了机构公布的值。景福宫路线的距离来自媒体报道，到清溪广场的步行时间是Kakao Map的值。

ISSUE 06 · #146 · 2026-11-24 · 서울 러닝 코스

🎯 适合谁，为什么是这9处

这份清单是为在首尔旅行中想跑一天步的人准备的。里面有江边公园、市中心河川、景福宫一带、森林公园、旧铁路公园。

选择标准只有一个。韩国观光公社 (Korea Tourism Organization / 한국관광공사)"名胜发掘100×100" (100×100 Spot Discovery / 명소발굴 100×100)跑步路线主题国民投票中进入前33名的首尔路线9处，照原样收入。第2·6·9名是汉江公园(汝矣岛·盘浦·纛岛)，第15名首尔林，第18名清溪川，第24名奥林匹克公园，第29名景福宫Daengdaeng Run路线，第31名良才川，第33名京义线林荫路紧随其后。第59名(85票)南山北侧环路不在这9处之内，但因为是不通行车辆和自行车的路，所以在最后多加了一处。同一投票中首尔以外的路线，另外整理在#1445。

这9处不是跑步专用跑道，而是和散步的人、自行车、游客共用的路。所以写了长度是多少、什么时候开门关门、从哪个站几号出口出来。

⚠ 标注原则: 距离、使用时间、费用、交通方式，是2026-11-24在首尔市未来汉江本部 (Seoul Metropolitan Government Hangang Project Headquarters / 서울시 미래한강본부)的汉江公园页面、首尔设施公团 (Seoul Facilities Corporation / 서울시설공단)的清溪川页面、韩国体育产业开发 (Korea Sports Industry Development / 한국체육산업개발)的奥林匹克公园页面、国家遗产厅宫陵遗迹本部 (Korea Heritage Service Royal Palaces and Tombs Center / 국가유산청 궁능유적본부)的景福宫页面、江南区厅 (Gangnam-gu Office / 강남구청)的良才川页面、首尔的公园 (Seoul Parks / 서울의공원)的京义线林荫路页面以及首尔市公布的资料中查阅到的值。机构没有公布数值的项目没有写。没有写跑步需要的时间。汉江公园的km数值是公园长度，往返或圈数的计算只是把机构的数值简单相乘。步行到清溪广场的时间是Kakao Map路线值(2026-11-24)。景福宫一带的路线说明转述自媒体报道。得票和名次是韩国观光公社名胜发掘100×100跑步路线主题国民投票的值。运营时间和进入方式可能变动。

🚦 跑步之前 — 共同的安全和礼仪

九处都不是跑步专用的路。下面把设施规定的规则，和在多人共用的路上遵守的一般礼仪分开写。

  • 汉江公园的自行车规则。 按首尔市未来汉江本部的说明，汉江公园里自行车只能在自行车道上骑行，时速20km以下，靠右通行，排成一列。夜间要开灯。
  • 跑步的人不要进入自行车道。 这不是规定，而是礼仪。自行车被规定只能在自行车道上骑行，所以跑步的人使用步行道，可以减少互相碰撞。盘浦汉江公园的介绍写明自行车道和散步路是分开的。
  • 人多的路上放慢速度。 清溪川、京义线林荫路延南洞区段、景福宫一带都在旅游区中心。狭窄的路段改为步行。
  • 设施规定的规则要照做。 清溪川不能骑自行车和滑旱冰，也不能带动物进入(残疾人辅助犬除外)。奥林匹克公园土城内的散步路是行人优先路段，宠物犬要牵绳。汉江公园禁烟，宠物犬不牵绳罚款5万韩元，乱扔垃圾罚款10万韩元。
  • 清溪川预计开启水闸时会管制进入。 听到避难广播就立刻离开河道。不要在桥下躲雨。
  • 发生事故或紧急情况时拨打119。

寄存行李和换衣服的地方

  • 汝矣渡口站的Runner Station: 首尔市2024年5月公布的设施。位于5号线汝矣渡口站内B1~M1层。有更衣室、化妆间、物品保管柜58个(M1层42个、B1层16个)。
  • 地铁站跑者支援空间 (Runner Support Space / 러너지원공간)3处: 首尔市2025年10月公布。设在5号线光化门站、4号线会贤站 (Hoehyeon Station / 회현역)、6号线世界杯体育场站 (World Cup Stadium Station / 월드컵경기장역)。每天05:30~23:00开放，配合地铁运行时间运营。通过Naver QR或KakaoTalk认证进入，首尔市表示没有另外的使用费。有男女更衣室、个人行李保管柜、化妆间、跑步用品自动售货机。
  • 汝矣岛汉江公园开放式淋浴间: 位于汝矣岛汉江公园咨询中心 (Information Center / 안내센터)1楼。每天06:30~22:00开放，08:30~09:30和15:30~16:30是清扫时间。免费，毛巾和洗漱用品自己带。通过Naver应用QR码认证入场。男女淋浴间各5个，有物品保管柜13个、更衣室2间。淋浴要在20分钟内结束，不能洗衣服。咨询电话是汝矣岛咨询中心02-3780-0563。

跑者支援空间通过Naver QR或KakaoTalk认证进入，淋浴间通过Naver应用QR码认证进入。

① 汉江 — 3处

三处都是首尔市未来汉江本部管理的汉江公园。下面的km数值是沿江延伸的公园长度，不是规定好的跑步路线距离。起点和折返点由跑步的人自己定。

汝矣岛汉江公园 (Yeouido Hangang Park / 여의도한강공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票162票·第2名。
  • 公园长度: 8.4km。从汉江铁桥 (Hangang Railway Bridge / 한강철교)中央到国会 (National Assembly / 국회)后面的莎江 (Saetgang / 샛강)一侧。从一端到另一端往返是16.8km。
  • 交通方式: 每个站到达的位置不同。
  • 5号线汝矣渡口站2·3号出口: 步行1分钟，公园中心部。电梯在2号出口附近。
  • 9号线国会议事堂站 (National Assembly Station / 국회의사당역)1号出口: 步行1分钟，国会后面。
  • 9号线莎江站 (Saetgang Station / 샛강역)4号出口: 步行10分钟。
  • 5·9号线汝矣岛站 (Yeouido Station / 여의도역)1号出口: 步行15~20分钟。
  • 在汉江巴士 (Hangang Bus / 한강버스)汝矣岛码头下船，直接连通公园。
  • 设施: 有便利店4处、厕所24处、遮阳棚、座椅。水光广场 (Mulbit Plaza / 물빛광장)的喷泉4~10月运行。
  • 行李和淋浴: 汝矣渡口站内有Runner Station，公园咨询中心1楼有开放式淋浴间。数值写在前面的"寄存行李和换衣服的地方"。
  • 地址·咨询: 首尔永登浦区 (Yeoui-dong-ro 330 / 여의동로 330)。汝矣岛咨询中心02-3780-0561~6。

盘浦汉江公园 (Banpo Hangang Park / 반포한강공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票143票·第6名。
  • 公园长度: 7.2km。公园介绍写明自行车道和散步路在7.2km的范围内分开，并与汝矣岛·蚕院汉江公园 (Jamwon Hangang Park / 잠원한강공원)相连。从一端到另一端往返是14.4km。
  • 潜水桥 (Jamsugyo Bridge / 잠수교): 按公园介绍，潜水桥缩减了车道、加宽了人行道，并设有自行车专用车道。
  • 交通方式:
  • 9号线新盘浦站1号出口: 从盘浦出入口 (Banpo Interchange / 반포나들목)进入，步行约15分钟。
  • 3·7·9号线高速客运站站 (Express Bus Terminal Station / 고속터미널역)8-1·8-2号出口(或GOTO Mall G1): 朝盘浦大桥 (Banpo Bridge / 반포대교)方向步行约15分钟。
  • 4·9号线铜雀站 (Dongjak Station / 동작역)1·2号出口: 沿汉江边朝西来岛 (Seoraeseom Island / 서래섬)方向走。
  • 月光彩虹喷泉 (Banpo Moonlight Rainbow Fountain / 달빛무지개분수): 设在盘浦大桥的喷泉，总长1,140m。2008年11月7日作为"世界最长的桥梁喷泉"载入吉尼斯。观看免费，不用预约，现场观看。
  • 运行期间: 3月15日到10月。11月到次年3月14日不是使用期间。 冬天跑盘浦的话，跑的是没有喷泉的江边。
  • 场次(每场20分钟): 3月15日~5月和10月是12:00、19:30、20:00、20:30、21:00。6~9月在此基础上增加21:30。不分平日和周末。
  • 停止运行的时候: 风速每秒7m以上时、运行时间内有降雨预报时、汉江浊度15NTU以上时。有活动的话时间可能改变。咨询电话02-3780-0578~9。
  • 设施: 有便利店2处、厕所7处。
  • 地址·咨询: 首尔瑞草区 (Sinbanpo-ro 11-gil 40 / 신반포로11길 40)。盘浦咨询中心02-3780-0541~4。

纛岛汉江公园 (Ttukseom Hangang Park / 뚝섬한강공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票136票·第9名。
  • 公园长度: 11.5km。从衿湖洞 (Geumho-dong / 금호동)中浪川桥 (Jungnangcheon Bridge / 중랑천교)到广津桥 (Gwangjingyo Bridge / 광진교)上游一侧的首尔市边界。是三处中最长的。从一端到另一端往返是23km。
  • 交通方式:
  • 7号线慈阳站2·3号出口: 与公园直接相连(步行1分钟)。汉江公园的交通指南写作慈阳站，同一网站的公园介绍页面写作纛岛游园地站2·3号出口。
  • 2号线建大入口站 (Konkuk Univ. Station / 건대입구역)5号出口: 1,000m。
  • 在汉江巴士纛岛码头下船，直接连通公园。
  • 设施: 有便利店3处、厕所18处、遮阳棚、座椅。
  • 地址·咨询: 首尔广津区 (Gangbyeonbuk-ro 2273 / 강변북로 2273)。纛岛咨询中心02-3780-0521~4。

② 市中心 — 2处

5号线光化门站有跑者支援空间，适合放下行李再出发。

清溪川 (Cheonggyecheon Stream / 청계천)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票128票·第18名。
  • 长度: 首尔设施公团写明总长8.12km，复原区段5.84km。区段列表从清溪广场~毛廛桥 (Mojeon Bridge / 모전교)150m开始，到高山子桥 (Gosanja Bridge / 고산자교)~新踏铁桥 (Sindap Railway Bridge / 신답철교)307m结束。第一座桥是毛廛桥，最后一座桥是高山子桥。
  • 交通方式: 按Kakao Map路线，从5号线光化门站5号出口到清溪广场步行3分钟(约120m)。
  • 禁止事项: 市民注意事项的禁止清单里有使用自行车和滑旱冰、带动物进入(残疾人辅助犬除外)、钓鱼、游泳、露营·做饭、吸烟·饮酒。跑步不在这个清单里。打算和宠物犬一起跑的话，选其他路线。
  • 下雨天: 清溪川不是下雨天跑步的地方。
  • 预计因下雨开启水闸时，会管制进入。
  • 即使清溪川周边没有下雨，听到避难广播也要立刻离开河道。上游下的雨也会使水位上涨。
  • 不要在桥下躲雨。下雨时水闸会突然开启，桥下很危险。
  • 为被突然下的雨困住的人设有紧急梯子，共39处。被困时拨打清溪川综合状况室 (Cheonggyecheon Control Room / 청계천 종합상황실)02-2290-7111~3。

景福宫Daengdaeng Run路线 (Gyeongbokgung "Daengdaeng Run" loop / 경복궁 댕댕런)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票111票·第29名。
  • 是什么样的路线(媒体报道): 据媒体报道，这是绕行光化门 (Gwanghwamun / 광화문)、景福宫、青瓦台 (Cheong Wa Dae / 청와대)、三清洞 (Samcheong-dong / 삼청동)、钟路 (Jongno / 종로)、清溪川的跑步路线。把GPS记录的跑步轨迹连成线，会出现长着耳朵和尾巴的小狗形状，因此得名"Daengdaeng Run"。报道写的距离约8km，并称景福宫、西村 (Seochon / 서촌)、仁寺洞 (Insa-dong / 인사동)在路线之内。
  • 距离: 约8km是媒体报道的值。
  • 跑步的路和宫内不同: 报道中的路线经过景福宫、西村、仁寺洞、青瓦台、三清洞一带。宫内是缴纳参观费后进入的参观区域。跑步和参观要分开计划。
  • 交通方式: 5号线光化门站有跑者支援空间。从5号线光化门站5号出口到清溪广场步行3分钟(约120m，Kakao Map路线值)。景福宫的地址是首尔钟路区 (Sajik-ro 161 / 사직로 161)。
  • 旁边的看点 — 景福宫 (Gyeongbokgung Palace / 경복궁): 国家遗产厅宫陵遗迹本部公布的值。
  • 休息日: 每周二。周二与公休日或替代公休日重合时开门，之后第一个非公休日休息。
  • 参观时间: 11~12月和1~2月是09:00~17:00(截止入场16:00)。3~5月和9~10月是09:00~18:00(截止入场17:00)。6~8月是09:00~18:30(截止入场17:30)。可能因情况缩短或调整。
  • 费用: 个人3,000韩元(外国人为满19~64岁)。外国人满18岁以下和满65岁以上免费。穿韩服免费。周三"有文化的日子"免费入场不适用于景福宫。

③ 公园·林荫路 — 3处

首尔林24小时开放，奥林匹克公园22:00起不能进入园内。京义线林荫路是沿着旧铁路修建的狭长公园。

首尔林 (Seoul Forest / 서울숲)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票130票·第15名。
  • 使用时间: 首尔市公布(2026-10-30)写明首尔林全年无休24小时开放。生态林等部分设施另有时间。
  • 公园道路: 按首尔市公布，首尔林内核心公园道路合计22,747.6m是步行者专用道。在这条路上不能骑自行车，要推着走。22,747.6m是把公园道路全部加起来的长度，不是一圈路线的距离。
  • 交通方式: 从水仁盆唐线首尔林站4号出口到公园步行约2分钟。

奥林匹克公园 (Olympic Park / 올림픽공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票118票·第24名。
  • 使用时间·费用: 步行和自行车进入是05:00~22:00。广场区域到24:00。22点以后不能进入公园内部。 梦村土城 (Mongchontoseong Fortress / 몽촌토성)区域为保护文物，使用时间之外禁止进入内部。公园使用免费，停车另外收费。
  • 官方散步/慢跑路线5条: 运营公园的韩国体育产业开发作为"散步/慢跑路线"介绍的路。

京义线林荫路 (Gyeongui Line Forest Park / 경의선숲길)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票104票·第33名。
  • 长度: 首尔的公园写明全长约6.3km。延南洞区段约1.2km。延南洞区段往返约2.4km，往返两次约4.8km。
  • 交通方式: 每个区段的站不同。
  • 延南洞区段: 弘大入口站(2号线·机场铁路·京义中央线)、加佐站 (Gajwa Station / 가좌역)(京义中央线)。首尔市公布(2025-03)写明从弘大入口站3号出口438m。首尔的公园的说明也把这个区段的街头表演地点写作弘大入口站3号出口~延南派出所 (Yeonnam Police Box / 연남파출소)(约200m)。

  • 新水·大兴·盐里洞区段: 6号线孔德站 (Gongdeok Station / 공덕역)、6号线大兴站 (Daeheung Station / 대흥역)

  • 停车: 公园内没有停车场。首尔的公园建议乘坐公共交通。

④ 江南河川 — 1处

良才川 (Yangjaecheon Stream / 양재천)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票106票·第31名。
  • 长度: 江南区厅写明总长15.6km，江南区段3.75km。江南区段往返是7.5km。
  • 两种路: 首尔市报道(2022-05)把散步路介绍为两条。河边散步路由行人和自行车共用，堤坝坡上的散步路仅限行人。想避开自行车的话，走堤坝一侧的路。
  • 交通方式: 以江南区公告(2020-07)为准。
  • 3号线道谷站 (Dogok Station / 도곡역)3号出口: 朝良才川近邻公园 (Yangjaecheon Neighborhood Park / 양재천 근린공원)方向出去，进入良才川。
  • 3号线学如乙站 (Hangnyeoul Station / 학여울역)1号出口: 约280m，步行约4分钟。
  • 水仁盆唐线开浦洞站2·3号出口: 约100m，步行约1~2分钟。
  • 设施: 江南区厅介绍有观景台、景观照明、Media Sapphire。江南区的说明写明散步路各处有厕所指示牌。

➕ 再加一处 — 南山北侧环路 (Namsan North Loop Road / 남산 북측순환로)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票85票·第59名。虽然不在这9处之内，但因为是不用在意车和自行车就能跑的路，所以补充上。
  • 距离: 首尔市报道(2018-08)写明从教育科学院 (Gyoyukgwahagwon / 교육과학원)到国立中央剧场 (National Theater of Korea / 국립중앙극장)约3.3km。往返约6.6km。
  • 车和自行车: 首尔市把这条路介绍为全面禁止车辆和自行车通行、只有行人通行的散步路。车辆全面管制从1996年6月开始。
  • 不要和南侧环路搞混: 按首尔市报道(2025-06)，南侧环路是行人和车共用的道路，车辆和自行车单向通行。要跑的是北侧。
  • 夜晚: 首尔市报道写明到了夜晚灯光会一盏一盏亮起来。

⚠ 3个常见失误

  1. 把汉江公园长度当成路线距离 — 汝矣岛8.4km、盘浦7.2km、纛岛11.5km是沿江延伸的公园长度。这不是绕一圈的路线，所以走到尽头就要原路返回。想按距离跑的话，用手表或应用边测量边自己定折返点。想要一圈距离固定的地方，就用奥林匹克公园的散步/慢跑路线(1,302m~4,290m)。
  2. 下雨天去清溪川 — 桥多看起来可以躲雨，其实正相反。下雨时水闸可能突然开启，桥下很危险，预计开启水闸时连进入本身都会被禁止。晴天听到避难广播也要立刻上来。
  3. 在奥林匹克公园搞错站和时间 — 奥林匹克公园站是5号线和9号线。乘坐8号线的话，从梦村土城站1号出口出来。步行进入到22:00为止，之后不能进入公园内部。傍晚跑步的话，时间要安排在22:00之前进入。

⚙ 3个常见问题

  1. 不回住处也能寄存行李的地方有哪里？ — 汝矣岛汉江公园一侧，5号线汝矣渡口站内的Runner Station有更衣室和58个物品保管柜。光化门站(5号线)、会贤站(4号线)、世界杯体育场站(6号线)的跑者支援空间每天05:30~23:00开放，有更衣室和个人行李保管柜。通过Naver QR或KakaoTalk认证进入。淋浴去汝矣岛汉江公园咨询中心1楼的开放式淋浴间(06:30~22:00，免费，Naver应用QR码认证)。
  2. 天黑之后也能跑的地方有哪里？ — 首尔林全年无休24小时开放。奥林匹克公园步行进入到22:00，只有广场区域到24:00。夜间的灯光和关门时间另外整理在#147首尔夜间跑步路线指南。
  3. 11月底到冬天有什么变化？ — 盘浦月光彩虹喷泉只在3月15日~10月运行，所以冬天看不到。汝矣岛水光广场的喷泉也只在4~10月运行。景福宫在11~12月和1~2月参观时间缩短为09:00~17:00，16:00截止入场。
