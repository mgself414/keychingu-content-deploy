한국 포차 주문·술 페어링 워크플로우 — 을지로 노가리부터 마장동 곱창까지

부제: 외국인 관광객용 5-step 워크플로우 + 안주별 술 페어링·심야 매너·결제 팁

ISSUE 03 · #844 · 2026-06-09

🎯 왜 한국 포차 워크플로우 가이드인가

[#843 야식·안주 6종 매트릭스](#843) 알아도 — 주문·페어링·매너는 별개. 한국 포차는 (a) 천막·실내 구분 (을지로 골목 = 거리 노가리 vs 종로 = 천막) (b) 안주 + 술 동시 주문 (소맥·소주·맥주·막걸리 페어) (c) 회식 2차 매너 (강요 거부·페이스 조절) (d) 계산 패턴 (한 명 결제 + 카카오페이 송금) (e) 심야 매너 (조용·이웃 배려). 외국인은 (1) 골목 매장 vs 천막 차이 모르고 (2) 안주별 술 페어링 모르고 (3) 강요 거부 매너 모르고 (4) 음주운전 0.03% BAC 규제 모름. 본 가이드는 5-step + 페어링 + 영어 발화 + 안전 매너.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 매장 type 선택 을지로 골목 / 종로 포차 / 강남 호프 / 곱창집 즉시 시간대·동행에 맞춤
2️⃣ 자리 + 메뉴 + 술 주문 안주 + 술 동시 5~10분 "추천 안주+술" 직원 OK
3️⃣ 받기 + 페어링 시작 안주 + 첫 잔 + 건배 5~10분 노가리+맥주·전+막걸리·곱창+소주
4️⃣ 회식 매너 + 마시기 강요 거부·페이스 조절·심야 매너 1~3h 페이스 조절·강요 거부 OK
5️⃣ 결제 한 명 결제 → 카카오페이·토스 송금 1~3분 더치페이 일부 매장

총 소요 시간: 호프 = 1~2h / 포차 회식 2차 = 2~3h / 심야 매니아 = 새벽~

🍻 안주별 술 페어링 매트릭스

클래식 페어링 정통

안주 베스트 술 외국인 입문 매니아
노가리 생맥주 (#1 정통) 맥주 페어 글로벌
곱창 소주 (#1) + 맥주 소맥
꼼장어 소주·맥주 소맥 (부산 정통)
닭발 소주 매콤 페어 정통
철판 소주·맥주·소맥 즉석 굽기 + 술
전 (해물파전·녹두전·김치전) 막걸리 (#1 정통) 비 오는 날 정통

한국 회식 2차 패턴

1. 1차 = BBQ·치킨 + 소주·맥주

2. 2차 = 포차·호프 + 노가리·전·곱창

3. 3차 = 노래방 + 술 OR 해장

🌃 매장 type별 워크플로우

Type A — 을지로 노가리 골목 (외국인 vlog #1)

  • 시스템: 거리 노점 + 실내 호프 cluster (만선호프·뮌헨호프 등)
  • 메뉴: 노가리·전·꼬치·생맥주
  • 가격: 1인 15,000~25,000원
  • 시간: 17:00~02:00
  • 결제: 카드·현금 혼용
  • 외국인 친화도: ★★★★ (vlog 1번지·영문 일부)

Type B — 종로·청계 포차 (심야 천막)

  • 시스템: 야간 천막 길거리 술집
  • 메뉴: 노가리·전·우동·라면·곱창·꼬치
  • 가격: 1인 15,000~25,000원
  • 시간: 18:00~02:00 (또는 새벽)
  • 결제: 현금·카드
  • 외국인 친화도: ★★ (한국어 메뉴·심야 분위기)

Type C — 강남·역삼 호프 (직장인)

  • 시스템: 실내 호프 + 회식 2차 매니아
  • 메뉴: 철판·곱창·전·노가리 풀세트
  • 가격: 1인 25,000~40,000원
  • 시간: 17:00~24:00
  • 결제: 카드 OK
  • 외국인 친화도: ★★★ (영문 일부)

Type D — 마장동·왕십리 곱창집 (매니아)

  • 시스템: 곱창 전문점 + 소주 페어
  • 메뉴: 소곱창·돼지곱창·막창 풀세트
  • 가격: 1인 25,000~50,000원
  • 시간: 17:00~24:00
  • 결제: 카드 OK
  • 외국인 친화도: ★★★ (영문 일부)

🙏 한국 회식 매너 핵심 7가지

회식·포차 매너

1. 건배 = 잔 위치: 어른보다 약간 낮게 (전통)

2. 자기 잔 채우기 X: 다른 사람이 따라주기

3. 두 손 따르기·받기: 어른에게 정통 매너

4. 고개 돌려 마시기: 어른 앞 정통 (현대 = 강요 X)

5. 페이스 조절: 1~2시간 내 잔 2~3개 권장

6. 강요 거부 OK: 현대 한국 회식 = 강요 거부 매너 위반 아님

7. 심야 매너: 22:00 이후 = 조용 + 이웃 배려

외국인 영어 발화 샘플

  • "노가리 + 생맥주" = "Nogari with draft beer, please"
  • "막걸리 + 해물파전" = "Makgeolli with seafood pancake, please"
  • "소주 한 병" = "One bottle of soju, please"
  • "안 마실래요" = "I don't drink, thanks"
  • "한 잔만" = "Just one shot, please"
  • "카드 돼요?" = "Card accepted?"
  • "카카오페이 송금" = "Send via KakaoPay"

⚠ 외국인 자주 실수 7가지

1. "포차 = 더러움": 을지로 골목·종로 포차 = 관광지 매장 정기 점검·위생 양호.

2. "노가리 = 생선만": 노가리 = 명태 새끼 말림·소금·짭짤 = 맥주 페어 정통 #1.

3. "곱창 = 일본 모츠": 한국 곱창 = 양념 + 굽기 = 다른 음식. 마장동 입문.

4. "꼼장어 = 일반 장어": 꼼장어 = 부산 매콤 양념 구이 (민물장어와 다른).

5. "강요 거부 = 매너 위반": 현대 한국 = 강요 거부 OK. "I don't drink" 직접 거부.

6. "음주운전 = 가벼움": 한국 0.03% BAC = 면허정지 (단속 강력).

7. "심야 매너 = 자유": 22:00 이후 = 조용·이웃 배려 정통.

⚙ FAQ 8개

1. 첫 포차 = 어디: 을지로 노가리 골목 1순위 (외국인 vlog #1).

2. 인스타·vlog: 을지로 노가리 골목·광장시장 전+막걸리·부산 꼼장어.

3. MZ 트렌드: 을지로 노가리 골목 MZ vlog·페어링 인스타.

4. 회식 2차 매니아: 노가리 호프 + 곱창집 + 철판 호프.

5. 음주 매너: 강요 거부 OK·페이스 조절·심야 22:00 조용 매너.

6. 음주운전: 0.03% BAC 면허정지·19세 미만 법적 음주 금지.

7. 알레르기: 해산물·콩·계란·견과류·매운 양념 사전 고지.

8. 결제·팁: 카드 OK / 포차 = 일부 현금 / 카카오페이·토스 송금 / 팁 X.

⚠ 의료·안전·법률 disclaimer

야식·안주 = 야간 식사 (소화 ↓·수면 영향). 임신부 = 술 X·곱창·내장 = 의료진 상담. 어린이 = 야간 포차 X (술 분위기). 알레르기 (해산물·콩·계란·견과류) 사전 고지. 음주운전 0.03% BAC 면허정지 + 형사처벌 (한국 단속 강력). 19세 미만 = 법적 음주 금지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

노포·매장 정보 면책: 포차·노가리 골목 영업시간·메뉴 변동 — 방문 전 NAVER/Kakao map 또는 공식 사이트 확인.

식이 제한 fallback:

  • 할랄·코셔: 일반 안주 = 비할랄. → 이태원 일부 할랄 매장 OR 채식 전·과일 안주.
  • 채식·비건: 녹두전·호박전·김치전 (어묵 빼기) = 채식 가능.
  • 글루텐 free: 전·양념 (간장) 多. 사전 매장 확인.
