🎯 왜 부산 BIFF·영화 문화인가

부산 = 아시아 1번지 영화제 도시 + 부산국제영화제 (BIFF, 1996~) + 영화의전당·BIFF 거리·기장·해동용궁사·외곽 외국인 풀세트. 부산 매니아 외국인 inbound 1번지 deep dive. 키친구 부산 시리즈 ⑤ (마지막).

⚠ 외국인 자주 실수 5가지

1. "BIFF = 10월만 봄": BIFF (10월·1주일) 외 영화의전당 연중 OK + BIFF 거리 (남포동) 연중 + 외국인 영화 매니아 deep dive.

2. "영화의전당 = 보통 영화관": 영화의전당 = 한국 1번지 영화관 + BIFF 본부 + 외국인 매니아 1번지 + 외부 LED 4,000 m² (BIFF 시 외부 광장 야간 1번지).

3. "해동용궁사 = 못 감": 해동용궁사 = 부산 1번지 사찰 + 바다 위 사찰 + 외국인 인스타 1번지 + 기장 인접 + 외국인 매니아 1순위.

4. "기장 = 외곽 못 감": 기장 = 부산 외곽 1번지 deep dive + 죽성성당·해동용궁사·외곽 해변·외국인 매니아.

5. "Centum City Shinsegae = 백화점만": Centum City Shinsegae = 기네스 세계 1번지 백화점 + 외국인 매니아 1번지 + BIFF 영화의전당 인접.

⚙ FAQ 6개

1. 외국인 BIFF 시기: 매년 10월 (1주일) + 외국인 매니아 + Klook·Trip.com 영문 예약 OK.

2. 외국인 영화의전당 동선: 부산역 KTX → 센텀시티역 (지하철 2호선) → 영화의전당.

3. 외국인 해동용궁사: 부산 1번지 사찰 + 바다 위 사찰 + 외국인 인스타 1번지.

4. 외국인 기장 외곽: 해동용궁사 + 죽성성당 + 외곽 해변 + 외국인 매니아.

5. 외국인 Centum City Shinsegae: 기네스 세계 1번지 백화점 + 외국인 매니아 1번지.

6. 외국인 부산 1주일 추천: Day 1~2 해운대·광안리 (#243) / Day 3~4 자갈치·BIFF 거리 (#244) / Day 5 감천·산복도로 (#245) / Day 6 서면·전포 (#246) / Day 7 BIFF·해동용궁사·외곽 (이 가이드).

🗺 외국인 풀데이 코스 3개

  • 09:00 영화의전당 (Centum City) → 12:00 Centum City Shinsegae 점심 → 14:00 영화의전당 외국인 영화 → 17:00 BIFF 거리 (남포동) → 19:00 외국인 매니아

B. 해동용궁사·기장 1일 (외국인 외곽 인스타·사찰)

  • 09:00 해운대역 → 181번 버스 → 10:00 해동용궁사 → 13:00 기장 점심 → 15:00 죽성성당 → 17:00 외곽 해변 (송정·일광)

C. 부산 외곽 1박2일 풀세트 (BIFF + 외곽 자연)

  • Day 1: 영화의전당 + Centum City + BIFF 거리
  • Day 2: 해동용궁사 + 기장 + 외곽 자연 + KTX 부산→서울
