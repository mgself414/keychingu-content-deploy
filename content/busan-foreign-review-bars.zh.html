釜山酒馆·酒吧14家 — 只选外国评论率先留下的地方

副标题: 继田浦威士忌酒吧·广安里海边酒吧(#1364)与章鱼牛肠虾锅·烤鳗鱼·烤牛肠(#1410)之后的新轴线——西面LP酒吧、田浦小巷鸡尾酒、民乐地下酒吧与海鲜酒馆、南川·水营的爵士与烤串。只选Naver地图上外语评论率先留下的酒馆，共14家，分成4个区域串成晚间动线。选酒吧的方法·每人一杯·点歌文化等酒吧礼仪见#1364

ISSUE 06 · #1436 · 2026-11-23 · 釜山喝酒系列 第3篇

🎯 为什么以"三语评论"为标准

釜山喝酒篇已经有两篇——田浦·广安里酒吧巡游(#1364)与章鱼牛肠虾锅·烤鳗鱼·烤牛肠(#1410)。这一篇只收这两篇里没出现过的店。即使同样是田浦·广安里的小巷，店也不会重叠。

筛选标准只有一个——Naver地图上同时留有英语·日语·中文评论的酒馆。不是韩国人气排行，而是判断已经有外国人到访并用三种语言留下痕迹的地方，对下一位外国游客来说最不陌生。评论数是2026-11的快照，这一篇把每家店的评论数都标了出来。例外有两家——Robata Aki (로바타아키)·漂流 (Pyoryu / 표류)只有英语评论，但店的性格符合这一篇的轴线，所以收录。店的性格与评论语言未必对得上——日式居酒屋Robata Aki的评论也只有英语。

⚠ 标注原则：营业时间·休息日·菜单价格是店主登记在Kakao地图上的值(2026-11-23确认)。没有登记的栏位标"以Kakao地图当日确认为准"。价格只标1杯或1碟下酒菜的单价，不标每人预算——因为要点几杯、几碟，结果会不同。从车站步行的时间是Kakao地图导航的值(以出口为基准)。选酒吧的方法·每人一杯·点歌文化见#1364。

① 西面·釜田 — 3家

从西面站 (Seomyeon Station / 서면역)出口步行5~6分钟以内。这一篇里登记了英文菜单名的三家店，有两家在这里。

  • 望美蓝调 — 放LP的威士忌音乐酒馆。构成是威士忌·高球·啤酒·小食，Kakao地图的菜单名同时登记了英文(whiskey / highball / beer / small food)。外语评论10条(4·3·3)是这一篇里最多的，三种语言都在3条以上。19:00开门，周日至周四到01:00·周五·周六到02:00，周二休息。西面站8号出口步行约5分钟，3楼。店名还沿用望美洞 (Mangmi-dong / 망미동)时期的名字，但现在已搬到西面——如果地图应用上出现旧的望美洞地址，就用西面地址(釜山镇区 (Busanjin-gu / 부산진구) Jungang-daero 680beon-gil 80-20 3楼 (중앙대로680번가길 80-20 3층))重新搜索。价格以Kakao地图当日确认为准。
  • 十月 — 威士忌·鸡尾酒·葡萄酒的LP酒吧。Kakao地图菜单名以Wine Selection·Highball Selection·Non-Alcoholic Selection这样的英文登记，而且有单独的无酒精栏——同行的人不喝酒也能一起去。周二至周四·周日18:00~01:00，周五·周六到02:00，周一休息。西面站8号出口步行约6分钟，2楼202室。价格以Kakao地图当日确认为准。
  • Robata Aki — 坐在炭火前吧台的炉端烧居酒屋。什锦烤蔬菜₩8,000，波士顿海胆50g ₩29,000，6品刺身₩34,000——下酒菜单价₩8,000~34,000。只有4条英语评论。周三至周一18:00~01:00，周二休息。西面站4号出口步行约5分钟。刺身·海胆是生食，想避开生食就选烤物。

② 田浦小巷 — 3家

田浦站 (Jeonpo Station / 전포역)4·7号出口一带的小巷。与#1364的田浦威士忌酒吧属于同一区域，但店不一样。三家都是每天营业，不用担心星期几。

  • Holiday Bar — 放爵士和LP的鸡尾酒吧，下酒菜选择丰富。派类₩16,000·布拉塔奶酪₩16,000·肉酱辣椒芝士薯条₩17,000。鸡尾酒价格以Kakao地图当日确认为准。每天18:30~01:30。田浦站4号出口步行约5分钟。
  • Poster Bar — 电器电子商场大楼1楼的户外露台鸡尾酒吧。下酒菜₩6,000~18,000(巴斯克芝士蛋糕₩10,000，布拉塔奶酪₩18,000)。酒价以Kakao地图当日确认为准。每天18:00~02:00。田浦站7号出口步行约7分钟。冬天露台很冷——先用Kakao地图的照片看看有没有室内座位。
  • 后日谈 — LP鸡尾酒吧。高球·葡萄酒·瓶装啤酒₩9,000，威士忌·鸡尾酒₩10,000——是这一篇里1杯价格已确认的两家中较低的一家。每天18:00~02:00。田浦站7号出口步行约7分钟，2楼。与Poster Bar都是从7号出口步行7分钟的距离。

③ 广安里·民乐 — 4家

从广安里海滩往民乐洞 (Millak-dong / 민락동)方向的小巷。从广安站 (Gwangan Station / 광안역)1号出口步行13~15分钟，所以比起从车站走，从海滩走进去更方便。henry17与Konabari在同一条民乐路27号街 (Millak-ro 27beon-gil / 민락로27번길)上。

  • henry17 (앙리17) — 2楼的地下酒吧式鸡尾酒·威士忌酒吧。招牌上的写法是Angri 17 (앙리17)，所以在地图应用里两个名字都搜一下。高球₩16,000起(以英文指南tablejourney为准)——是1杯价格已确认的两家中较高的一家。下酒菜有水牛城鸡翅₩15,000·西班牙火腿拼盘₩30,000。营业时间Kakao地图上没有登记，英文指南上写的是19:00~03:00(周一20:00开门)——以Kakao地图当日确认为准。同一份指南建议用Naver预约。广安站1号出口步行约13分钟。
  • 漂流 — 以豆浆高球为招牌的高球酒吧。5条评论全是英语。下酒菜₩12,000~17,000(芝士吐司₩12,000，意式土豆团子焗饭₩17,000)。高球价格以Kakao地图当日确认为准。每天18:00~02:00。广安站1号出口步行约14分钟。与#1364的Basement (베이스먼트)在同一条巷子，所以两篇混着走，逛两家酒吧很合适。
  • Konabari — 提供当季海鲜的日式酒馆。麻婆豆腐砂锅₩16,000，浦项花枝₩30,000，当日什锦₩60,000——下酒菜单价₩16,000~60,000，是几个人分着吃的构成。三语评论2·2·2。每天18:00~03:00。广安站1号出口步行约15分钟。与henry17在同一条巷子，所以可以串成第1轮Konabari → 第2轮henry17。
  • Sudal Bar Gwangan — 坐在吧台喝传统酒的韩式酒馆。拌面嫩豆腐锅₩15,000，韩牛生拌牛肉饭₩19,000，鱼饼汤₩25,000——下酒菜单价₩15,000~25,000。周日至周四17:00~02:00，周五·周六到03:00。从车站步行的时间没有登记，用Kakao地图导航确认。生拌牛肉是生牛肉。

④ 南川·水营·望美 — 4家

广安里西侧的南川洞 (Namcheon-dong / 남천동)与水营站 (Suyeong Station / 수영역)周边。比广安里海边更靠小巷里面，离水营站出口近的有两家。

  • Jazzpresso — 放爵士·LP的咖啡酒吧，也会发布现场演出通知。下酒菜₩12,000~18,000(布拉塔奶酪₩17,000，烤香肠配土豆₩18,000)。酒价与现场演出日程以Kakao地图公告当日确认为准。周二至周六19:00~24:00，周一·周日休息——这一篇里唯一一家一周休息两天的店。南川站 (Namcheon Station / 남천역)3号出口步行约13分钟，2楼。
  • Chohissatsu — 炭火烤串居酒屋。烤猪肉串1串₩3,500(2串起点)，炸排骨₩12,000，鸡蛋烧₩13,000——烤串按串算，下酒菜在₩12,000~13,000档。每天17:00~02:00。金莲山站 (Geumnyeonsan Station / 금련산역)3号出口步行约5分钟。
  • Musicology — 地下1楼的LP酒吧，有鸡尾酒·威士忌·葡萄酒。Kakao地图菜单名同时登记了英文(Cocktail, Whisky, red wine)。15:00开门，可以配合白天喝酒或早一点的傍晚。周一·周二·周四·周日到24:00，周五·周六到01:00，周三休息。咖喱饭₩13,000以外的价格以Kakao地图当日确认为准。水营站2号出口步行约8分钟。
  • Bogwangdangtang Jewon — 提供生拌牛肉·刺身下酒菜的料理酒馆。蟹味噌面₩16,000，海胆生拌牛肉₩37,000，刺身拼盘₩40,000——下酒菜单价₩16,000~40,000。周一至周六18:00~24:00，周日休息。水营站3号出口步行约4分钟。下酒菜以生食为主，想避开生食就选蟹味噌面(食材·过敏原点单前向店员确认)。

🗺 晚间动线 — 两条路线

A. 西面·田浦之夜 (西面站 → 田浦站)

  1. 第1轮 西面站4号出口 → Robata Aki炭火下酒菜(18:00起，周二休息)
  2. 第2轮 西面站8号出口一带 → 望美蓝调或十月LP酒吧(周一去望美蓝调，周二去十月)
  3. 第3轮 田浦小巷 → 后日谈1杯(₩9,000~10,000) → 同在7号出口一带的Poster Bar，或4号出口一带的Holiday Bar(到01:30)

B. 广安里·南川·水营之夜 (水营站 → 广安里)

  1. 早一点的傍晚 水营站2号出口 → Musicology(15:00起，周三休息)，或金莲山站3号出口 → Chohissatsu烤串(17:00起)
  2. 第1轮 水营站3号出口Bogwangdangtang Jewon(周日休息)，或南川Jazzpresso(周二至周六)
  3. 第2轮 广安里海滩 → 民乐小巷Konabari海鲜 → 同一条巷子的henry17
  4. 最后 漂流高球，或Sudal Bar Gwangan传统酒(周五·周六到03:00)

周二A线的第1轮(Robata Aki)、周日B线的第1轮(Bogwangdangtang Jewon·Jazzpresso)都休息，所以从第2轮的店开始。如果打算坐地铁回去，出发前先确认釜山地铁末班车时间。错过末班车就只能打车。想加上夜景见#1326。

⚠ 3个常见失误

  1. 周二去望美蓝调·Robata Aki，周一去十月，周三去Musicology，周日去Bogwangdangtang Jewon — 各自休息。Jazzpresso周一·周日休息两天。先看星期几。
  2. 不带身份证件就去 — 韩国的饮酒年龄是按年份计算的19岁(每年1月1日统一加一岁；依据《青少年保护法 (Cheongsonyeon Bohobeop / 청소년보호법)》第2条)。外国人在入口或点单时有时会被要求出示护照，所以要随身携带。
  3. 跳过"以Kakao地图当日确认为准" — henry17的营业时间、多家酒吧的酒价、Jazzpresso的现场演出日程都没有登记。出发前，Kakao地图的营业信息·公告就是当天的答案。

⚙ 3个常见问题

  1. 只能选一家？ — 外语评论最多的是望美蓝调(10条，4·3·3)，1杯价格可确认的店里较低的一家是后日谈(₩9,000~10,000)，和不喝酒的同行者一起就选十月(无酒精菜单)。
  2. 哪里有英文菜单？ — 菜单名登记了英文的是望美蓝调·十月·Musicology三家。其余的不知道有没有英文菜单，请准备好翻译App。
  3. 酒吧礼仪·点单方法？ — 每人一杯、点歌、选吧台座位的方法在#1364。大排档·烤牛肠那边的酒桌见#1410。
