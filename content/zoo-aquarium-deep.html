⚠ 외국인 자주 실수 5가지

1. "한국 동물원 = 작음": 한국 동물원 = 서울대공원 (한국 #1·#143) + 에버랜드 사파리 + 어린이대공원 (무료) + 외국인 가족 1번지 + #440·#143·#533 통합.

2. "수족관 = 코엑스만": 수족관 = 63 아쿠아플라넷·코엑스·롯데월드·일산·여수·제주·부산 풀세트 + #142·#534·#525 통합.

3. "판다 = 못 봄": 에버랜드 판다월드 = 아이바오 (한국 1번지) + 외국인 매니아 1번지 + #440 통합 + 외국인 가족.

4. "외국인 = 영어 안됨": 영어 OK = 서울대공원·에버랜드·63 아쿠아·코엑스 + KTO 영어 가이드 + 외국인 매니아 1번지 + #178·#533 통합.

5. "가족 패키지 = 비쌈": Klook·KKday = 외국인 가족 30~50% 할인 + KTO 인증 + 외국인 매니아 1순위 + #533·#525 통합.
