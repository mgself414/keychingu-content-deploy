在首尔·釜山看韩国电影的7个地方 — 英文字幕放映、电影资料馆、电影博物馆

副标题: 免费放映韩国经典影片、并在英文字幕场次标注"E"的上岩Cinematheque KOFA，同一栋楼里免费的韩国电影博物馆，在英文放映表上标注"*Eng Subtitle"的光化门emu Cinema，弘大的独立电影专门馆Indiespace，忠武路的首尔电影中心，以及釜山的釜山电影殿堂和釜山电影体验博物馆。每个地方都写了怎么去、怎么确认英文字幕、费用和休息日。

🎯 适合哪些人

这一篇写给想在韩国的电影院里看韩国电影的游客。难处在字幕。2026-11-25我们搜索过，没有找到CGV·Megabox·乐天影城 (Lotte Cinema / 롯데시네마)为韩国电影提供英文字幕的定期放映通知。所以这一篇把单独标注英文字幕场次的地方放在前面，后面接上没有字幕也值得一看的电影博物馆。放映韩国独立电影的影院排在最后。这些地方的英文字幕因场次而异，所以一并写了确认方法。

① 单独标注英文字幕场次的地方 — 2处

1. Cinematheque KOFA (시네마테크KOFA) (首尔麻浦区 (Mapo-gu / 마포구)上岩洞 (Sangam-dong / 상암동))

这是韩国影像资料院 (Korean Film Archive / 한국영상자료원)运营的电影院。位于韩国影像资料院大楼地下1层(Kakao地图, 2026-11-25)。所有放映都免费(官方英文说明, 2026-11-25)。

  • 确认英文字幕的方法: 韩文放映日程页面的图例里有"E 英文字幕"(E 영어자막)。作品名旁边带E的场次就是英文字幕放映(官方, 2026-11-25)。英文日程页面的图例里有两个E。一个是Event，一个是English Subtitles，所以要找用'English Subtitles'颜色标示的E(官方英文日程)。英文字幕场次很少。2026-11-25看到的11月25日~12月12日日程里，带E的场次只有《没处放眼睛》(눈 둘 데가 없네，直译) 12月2日(周三) 17:00和12月8日(周二) 19:00两场。去之前先找E场次。非韩国电影的放映作品都带韩文字幕(官方图例文字)。
  • 订票: 在线订票在放映前5天开放，每天上午11点更新。每人最多2张。在线订票页面目前只有韩文(官方英文说明)。现场取票只限放映当天，从在线订票后剩下的座位中出票。首场放映前1小时售票处开门(同一说明)。放映准时开始，迟到可能无法入场。
  • 休息日: 周二至周六放映。周日·周一、1月1日、韩国影像资料院成立纪念日(1月18日)、5月1日、春节 (Seollal / 설날)·中秋 (Chuseok / 추석)假期休息(官方英文说明)。
  • 怎么去: 地址是麻浦区 (Worldcupbuk-ro 400 / 월드컵북로 400)。官方说明有两种方式。在数字媒体城站 (Digital Media City / 디지털미디어시티역)(6号线·机场铁路·京义中央线)2号出口前乘771·6715·7711·7730路公交车，在Nurimkum Square (누리꿈스퀘어)下车(约5分钟)。或者从京义中央线水色站 (Susaek / 수색역)经地下通道进入DMC园区，步行约10分钟(官方英文说明)。Kakao地图显示从水色站1号出口步行13分钟。

2. emu Cinema (에무시네마) (首尔钟路区 (Jongno-gu / 종로구)新门路 (Sinmunno / 신문로))

位于庆熙宫 (Gyeonghuigung / 경희궁)后巷复合文化空间"emu" (에무)2层的电影院(首尔市媒体中心 2026-06-12)。主要放映新锐导演的独立电影和多样性电影(同一报道)。

  • 确认英文字幕的方法: 从emu网站菜单的'English' → 'emu Cinema'进入，有英文放映表。2026-11-25打开时，已上传的是10月8日~11日的放映表，部分作品带有"*Eng Subtitle"标记(官方英文页面)。带这个标记的场次是英文字幕的候选。最新放映表可能较晚才上传到英文页面，所以请向影院(02-730-5604)确认。GQ Korea (GQ Korea / GQ코리아)介绍说这里定期放映"提供英文字幕的独立·艺术电影"(2025-08-02)。10 Magazine也写到有用英文字幕放映韩国电影的场次。
  • 费用: 在emu网站首页没有找到价格表。请在订票页面 (Dtrix / 디트릭스)确认。首尔市媒体中心介绍光化门 (Gwanghwamun / 광화문)一带三家艺术电影院的成人普通票价约为9,000~12,000韩元(2026-06-12)。
  • 怎么去: 地址是钟路区 (Gyeonghuigung 1-ga-gil 7 / 경희궁1가길 7)。Kakao地图显示从3号线景福宫站 (Gyeongbokgung / 경복궁역)7号出口步行13分钟(2026-11-25)。停车位只有2~3个，所以建议乘公共交通(首尔市媒体中心 2026-06-12)。影院电话02-730-5604(官方)。

② 电影博物馆 — 2处

3. 韩国电影博物馆 (Korean Film Museum / 한국영화박물관) (首尔麻浦区 (Mapo-gu / 마포구)上岩洞 (Sangam-dong / 상암동))

和Cinematheque KOFA同在韩国影像资料院 (Korean Film Archive / 한국영상자료원)大楼的1层(Kakao地图, 2026-11-25)。常设展"看韩国电影"(한국 영화를 보다，直译)按时代展示韩国电影约100年的历史。有海报、拍摄设备、胶片、放映机等实物(首尔市媒体中心 (Seoul Media Hub / 서울시 미디어허브) 2026-07-23)。企划展每年更换两三次(官方英文说明)。

  • 英语: 在服务台领取的语音导览应用里有英文解说(官方英文说明, 2026-11-25)。
  • 费用: 免费(官方英文说明, 2026-11-25)。
  • 预约: 官方说明建议提前预约。在线预约可从当天到2天前办理，每天中午开放。现场取票只限当天，从场次开始后到该场次结束前30分钟为止。现场票数量可能较少(官方英文说明, 2026-11-25)。
  • 时间: 各出处不同。官方英文正文是周二至周六10:30~19:00，入场到场次结束前30分钟为止。同一网站首页的TODAY显示是10:30~18:30，Kakao地图是10:00~19:00(均为2026-11-25)。18:00之前入场更稳妥。
  • 休息日: 周日·周一、1月1日、1月18日、5月1日、春节 (Seollal / 설날)·中秋 (Chuseok / 추석)假期(官方英文说明)。
  • 怎么去: 和Cinematheque KOFA相同。适合上午看博物馆，下午看Cinematheque放映。

4. 釜山电影体验博物馆 (Busan Museum of Movies / 부산영화체험박물관) (釜山中区 (Jung-gu / 중구)东光洞 (Donggwang-dong / 동광동))

网站介绍说这里是"观看并感受关于电影的一切"的体验型电影博物馆。有常设展、3·4层的体验区，以及名为"Cine Museum" (씨네뮤지엄)的独立展馆(官方网站, 2026-11-25)。

  • 英语: 网站有EN菜单，并介绍了移动端展览解说应用(官方)。应用是否支持英语未能确认。
  • 费用: 博物馆成人10,000韩元，儿童·青少年(36个月以上~高中生)7,000韩元。含Cine Museum的联票成人14,000韩元，儿童·青少年11,000韩元(官方, 2026-11-25)。
  • 时间: 10:00~18:00，入场·售票17:00截止(官方)。
  • 休息日: 每周一(遇公休日则顺延到次日)、1月1日、春节 (Seollal / 설날)·中秋 (Chuseok / 추석)当天(官方)。
  • 怎么去: 地址是中区 (Daecheong-ro 126beon-gil 12 / 대청로126번길 12)。Kakao地图显示从1号线中央站 (Jungang / 중앙역)1号出口步行5分钟(2026-11-25)。这里在旧城区 (原都心 / 원도심)一侧，和海云台 (Haeundae / 해운대)Centum City的釜山电影殿堂 (Busan Cinema Center / 영화의전당)相距较远，想一天跑两处的话，要多留些移动时间。

5. Indiespace (인디스페이스) (首尔麻浦区 (Mapo-gu / 마포구)东桥洞 (Donggyo-dong / 동교동))

独立电影专门馆(Kakao地图标签)。位于弘大入口站 (Hongik University / 홍대입구역)前乐天影城 (Lotte Cinema / 롯데시네마)弘大入口店大楼的8层(官方公告)。

  • 费用: 普通票10,000韩元，早场(上午11点以前)6,000韩元，青少年·老人6,000韩元。影院公告发布于2022-02-08，与Kakao地图菜单2025-11-03登记的值相同(2026-11-25确认)。折扣需要在现场售票时出示证明(官方公告)。
  • 时间: Kakao地图登记为每天10:00~20:00(2026-11-25)。售票处在放映前30分钟开门，放映开始后10分钟内才能入场(官方公告)。
  • 怎么去: 从2号线·机场铁路·京义中央线弘大入口站8号出口出来直走，从右边的WISEPARK (와이즈파크)入口进去，乘电梯到8层(官方公告)。按Kakao地图步行2分钟。咨询电话02-738-0366(官方)。

6. 首尔电影中心 (Seoul Film Center / 서울영화센터) (首尔中区 (Jung-gu / 중구)草洞 (Chodong / 초동)，忠武路 (Chungmuro / 충무로))

首尔市在2025-11-28开馆的公共电影院。有3个放映厅，312个座位(首尔市媒体中心 (Seoul Media Hub / 서울시 미디어허브) 2025-12-01)。放映独立电影、艺术电影、企划展映和电影节参展片。5~10月的周五晚上会举办楼顶放映"Cinema Sky" (시네마스카이)(首尔市媒体中心 2026-07-15)。

  • 费用: 成人7,000韩元，青少年6,000韩元。周三"有文化的日子" (문화가 있는 날)下午5点以后的场次和工作日第一场是5,000韩元(首尔市媒体中心 2026-07-15)。
  • 时间: 周二至周日10:00~20:00，周一闭馆(首尔市媒体中心 2026-07-15)。Kakao地图上也显示每周一休息(2026-11-25)。
  • 怎么去: 地址是中区 (Mareunnae-ro 38 / 마른내로 38)。从2·3号线乙支路3街站 (Euljiro 3-ga / 을지로3가역)9号出口步行4分钟(Kakao地图, 2026-11-25)。放映日程请在首尔电影中心网站或Dtrix (디트릭스)查看(首尔市媒体中心)。

7. 釜山电影殿堂 (Busan Cinema Center / 영화의전당) (釜山海云台区 (Haeundae-gu / 해운대구)Centum City (Centum City / 센텀시티))

  • 韩国电影节目 (截至2026-11-25, 官方当前放映节目): "电影沙龙 韩国经典电影定期放映会"(영화사랑방 한국고전영화 정기상영회，直译)免费，举办到12月14日。"11月韩国独立电影节目"(11월 한국독립영화 프로그램，直译)普通票8,000韩元，青少年7,000韩元，到11月30日。两个节目的说明里都没有英文字幕标记。

  • 怎么去: 地址是海云台区 (Suyeonggangbyeon-daero 120 / 수영강변대로 120)。从2号线Centum City站 (Centum City / 센텀시티역)12号·6号出口步行5分钟(官方交通页面)。Kakao地图显示从6号出口14分钟，所以要留有余量。现场售票处是6层的电影院售票处(官方节目说明里的取票地点)。

⚠ 常见错误3

  1. 周一去 — Cinematheque KOFA·韩国电影博物馆(周日·周一)、首尔电影中心、釜山电影体验博物馆周一休息。釜山电影殿堂的设施开放，但Cinematheque特别展映周一不放映(各官方说明·首尔市媒体中心)。
  2. 随便订一场就期待有英文字幕 — Cinematheque KOFA带E标记的场次才是英文字幕。在英文日程里，要找用'English Subtitles'颜色标示的E，以免和表示Event的E混淆。emu Cinema带"*Eng Subtitle"标记的场次是英文字幕的候选，请向影院确认。没有标记的话，韩语对白可能没有英文字幕。
  3. 因为Cinematheque KOFA在线订票订不了就放弃 — 在线订票页面只有韩文，但放映当天首场放映前1小时起，如果有剩余座位，可以在现场免费取票(官方英文说明)。每人2张的限制在现场也适用。

⚙ FAQ 3

  1. 在大型连锁影院能用英文字幕看韩国新片吗? — 2026-11-25的搜索没有找到CGV·Megabox·乐天影城的定期英文字幕放映通知。请在连锁影院应用的放映信息里自己找"English subtitles"标记。
  2. 电影节期间怎么挑英文字幕? — 釜山国际电影节 (Busan International Film Festival / 부산국제영화제)的英文放映表给每场都标了字幕符号。没有标记的是"英文字幕+韩语对白"，KK是"韩文字幕+韩语对白"，所以没有英文字幕(biff.kr英文放映表图例, 2026-11-25打开)。电影节日程和去法在#611韩国电影节日历和#482釜山国际电影节观影指南里。
  3. 想去电影里的地方看看? — 电影·电视剧拍摄地在#452里，只收集了地址已确认的地方。
