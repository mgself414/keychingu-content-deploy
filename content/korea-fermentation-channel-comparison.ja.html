🏺 4チャンネル deep dive

🏺 ジャンドクデ村体験 (Heritage Village)

核心価値: 本物+体験・教育+外国人インスタvlog 1番地。

  • おすすめの村:
  • 純昌長流村 (全北) — 伝統コチュジャン本場（地理的表示・伝統食品名人）
  • 潭陽チャンドクデ（全南） - 本格的
  • 昌徳宮ジャンゴ（ソウル） - 朝鮮王朝宮中料理（国家無形遺産第38号）正統
  • 体験メニュー：腸浸・メジュ作り・試食・購入
  • 体験費：20,000～80,000ウォン/人（1～3h）
  • 外国人親和性: ★★★ (韓国語中心、体験vlog)
  • 移動: 全州から車で1時間(純昌)・ソウル都心(昌徳宮)

コアバリュー：帰国ギフト#1+ VAT払い戻し+英語+真空包装。

  • おすすめ免税店:
  • 仁川空港免税店 — 韓国 #1 外国人利用

  • 市内免税店 (ロッテ・新羅・新世界) — 市内ピックアップ・空港ピックアップ
  • メニュー：6種プレミアム・真空包装（帰国プレゼント）
  • 価格 anchor: 15,000~50,000ウォン/kg (免税+プレミアム)
  • 外国人親和性: ★★★★★ (英語・1ランク・免税)
  • お支払い：カード+ VAT払い戻し +免税
  • 運営: 24h (空港) / ダウンタウン = 営業時間
  • 委託手荷物：真空包装OK（液体分類・機内携帯X）

＃＃⚠外国人の頻繁な誤り5つ

1. "4チャンネル=類似": 価格・体験・VAT 完全相違。苛性比＝マート／正統＝長独台／ブランド＝工場／免税＝免税店。

2. 「チャン・ドクデ村＝韓国人のみ」：純昌・潭陽＝外国人体験歓迎（vlog#1）。英語ガイドの一部。

3. "免税店=一般価格":免税店の章=VATの払い戻し+プレミアム。一般価格+払い戻しの節約。

4. "マート=外国人X": イマート・ロッテマート=外国人案内・多言語一部。コスパ比★。

5. "真空包装=どこでも可能":真空包装店= 免税店・一部マート・張独台村（事前確認）。

⚙ よくある質問8件

1. 初発酵食品=どのチャンネル: 免税店(帰国直前) 1順位(簡易・VAT還付)。

2. インスタ・vlog：純昌長流村#1・昌徳宮ジャンゴ・CJグローバルトレンド。

3. 家族同伴: チャン・ドクデ村の体験（子どもの教育）＋マート（コスパ）。

4. MZ トレンド: チャン・ドクデ村のインスタ・CJグローバル・トリュフコチュジャン。

5. VATの払い戻し: 免税店=払い戻し可能 /一般店舗=払い戻しX。

6. アレルギー・妊娠: [#849・#850 disclaimer](#849)参照。

7. 決済・チップ: カードOK 多 / チャン・ドクデ村 = 一部現金 / チップX。

8. 機内携帯: シート=液体・受託手荷物のみ。自国規制事前確認。

⚠医療・安全・食事ダイエット

発酵食品=一般食品。 高塩分注意（味噌・唐辛子・醤油・箸） - 高血圧・腎臓患者の注意。妊婦＝チョングクジャン・強い発酵食品適量。子ども＝チョングク長・箸ガルマニア入門に気をつけて。アレルギー（大豆・シーフード・フルーツ）事前通知。食中毒・食品届 = ☎ 1399 (食薬処) / 医療緊急 = ☎ 1339 (医療、英文)。本ガイドは一般情報、医療助言ではない。

老舗・店舗情報免責：長独大村・工場・マート・免税店運営変動 — 訪問前NAVER/Kakao mapまたは公式サイト確認。

機内携帯・搬入: 章 = 液体・受託手荷物のみ。自国規定事前確認（オーストラリア・ニュージーランド＝食品搬入制限）。

食事制限 fallback:

  • ハラール・コーシャー：味噌・コチュジャン・醤油・酢 = OK / 塩辛 = ビハラル / チョングクジャン = OK（コンマン）。
  • ベジタリアン・ビーガン：味噌・コチュジャン・醤油・酢・チョングクジャン＝OK / 塩辛＝非菜食。
  • グルテンフリー：一般醤油・コチュジャン=グルテンX /醸造醤油=小麦含有(確認必須)。
