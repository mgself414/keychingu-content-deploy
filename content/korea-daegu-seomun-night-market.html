🎯 왜 대구 서문시장 + 야시장 가이드인가

대구 서문시장 (Seomun Market) = 한국 #3 전통시장·100년+·한국 #3 야시장 (매일 19:00-23:30). 외국인 페인포인트 = (a) "서문 = 그냥 시장" 잘못된 인식 (b) 칼국수·납작만두·갈비찜 = 서문시장 특화 K-food (서울·부산 X) (c) 야시장 매일·19:00 시작·소주 + 안주 매니아 (d) 영문 메뉴 일부·결제 카드 多·픽업 OK (e) 광장시장 (서울)·자갈치 (부산) 다음 한국 매니아 매트릭스 #3.

본 가이드는 시장 + 야시장 매트릭스 + 시그니처 K-food 5종 + 3-4h 코스 + 외국인 영문 발화.

🏛 5축 deep dive

① 칼국수 노포 (서문시장 #1)

  • 시그니처: 서문시장 100년+ 노포·면 + 국물 매트릭스
  • 추천: 가나안 칼국수·서문시장 본점·40년+ 노포
  • 외국인 친화도: ★★★★ (안 매콤·담백·영문 메뉴 일부)
  • 가격: 6,000~10,000원/그릇

② 납작만두 (서문시장 특화 K-food)

  • 시그니처: 얇은 만두피·튀김 X = 서울·부산 X·서문시장 단독 시그니처
  • 재료: 만두피·당면·부추·양념간장
  • 외국인 친화도: ★★★★ (안 매콤·신선)
  • 가격: 5,000~8,000원 (10개)

③ 갈비찜 (서문시장 노포)

  • 시그니처: 양념 갈비 + 무·당근·당면·찐 매트릭스
  • 외국인 친화도: ★★★★★ (안 매콤·소고기 + 무 매트릭스)
  • 가격: 25,000~45,000원 (2-3인용)
  • 추천: 갈비찜 + 칼국수 = 외국인 매니아 풀세트

④ 야시장 떡볶이 + 순대 (19:00~23:30)

  • 시그니처: 야시장 매니아·매콤 + 어묵 + 순대 + 소주
  • 외국인 페인포인트: 매콤 단계 (한국 표준 7~8/10)
  • 외국인 친화도: ★★★ (매콤·매니아 매트릭스)
  • 가격: 떡볶이 4,000~7,000원·순대국 10,000~15,000원

⑤ 야시장 소주 + 술 안주 (저녁 매니아)

  • 시그니처: 한국 #1 술 매니아·노점 + 야장 + 소주 매트릭스
  • 추천: 갈비찜 + 소주 / 떡볶이 + 어묵 + 소주 / 순대 + 막걸리
  • 외국인 친화도: ★★★★ (술 매니아 + MZ)

⚠ 외국인 자주 실수 5가지

1. "서문시장 = 그냥 시장": 한국 #3 전통시장·한국 #3 야시장 (매일 19:00-23:30). 광장시장 (서울)·자갈치 (부산) 다음.

2. "납작만두 = 서울 만두와 동일": 납작만두 = 서문시장 단독 시그니처·얇은 만두피·서울·부산 X.

3. "야시장 = 다른 야시장과 동일": 서문시장 야시장 = 매일 19:00-23:30·소주 + 안주 매트릭스·외국인 매니아 매트릭스 #1.

4. "칼국수 = 매콤": 서문시장 칼국수 = 안 매콤·담백 매트릭스. 외국인 입문 1순위.

5. "갈비찜 = 비싼 한식": 서문시장 갈비찜 = 25,000~45,000원 (2-3인용)·가성비 매트릭스·노포 시그니처.

⚙ FAQ 6개

1. 외국인 입문 1순위: 칼국수 + 납작만두 + 갈비찜 = 풀세트·안 매콤 옵션.

2. 야시장 시간: 매일 19:00~23:30 (연중 무휴 X·일부 명절·우천 시 휴장).

3. 결제: 카드 OK·노포 일부 현금·환급 일부 매장 (5만원+ 면세).

4. 언어: 영문 메뉴 일부 (외국인 친화 매장)·손가락 + 사진 주문 OK.

5. 시즌: 봄 (4~5월)·가을 (9~10월) 베스트·여름 폭염·겨울 영하 추위 야시장 매장 일부 휴장.

6. 추천 페르소나: 가족·시니어 = 낮 시장 (칼국수·갈비찜·납작만두) / MZ·매콤 매니아 = 야시장 (떡볶이·순대·소주).

⚠ 의료·안전·식이 disclaimer

야시장 = 매콤·기름 多·노점 위생 차이. 임신부·고혈압·신장 환자 = 빈도 주의. 알레르기 (갑각류·새우젓·견과류·계란·우유·밀가루) 사전 고지. 식중독·복통 ☎ 1339.

식이 제한 fallback:

  • 할랄·코셔: 갈비찜 (소고기 OK·할랄 인증 X) / 떡볶이·순대 = 비할랄. → 칼국수 (채식 OK) 일부 매장
  • 채식·비건: 떡볶이·납작만두 (계란 X 옵션 OK)·갈비찜 = 비채식
  • 글루텐 free: 칼국수·납작만두·갈비찜 당면 = 글루텐 함유 (밀가루)

✈️ 외국인 페인포인트 #1 — 야시장 안전 + 결제

  • 야시장 안전: 한국 야시장 = 전국 안전·범죄율 낮음. 단, 소매치기 일부·휴대폰·지갑 주의.
  • 결제: 카드 OK 80%·현금 1만원·5만원권 미리 환전 권장 (노포 일부 현금 only)
  • 테이블 + 노점: 야장 + 테이블 OK·합석 한국 표준 (외국인 친화)
  • 외국인 친화 매장: 영문 메뉴 + 사진 + 손가락 주문 OK (서울 광장·부산 자갈치와 같은 패턴)
