ISSUE 04 · #1066 · 2026-06-13

🎯 왜 BIFF 가이드인가

BIFF (Busan International Film Festival·부산국제영화제) = 1996년 시작·30년+·아시아 #1 영화제·매년 10월 첫째~둘째 주 10일간·한국 + 글로벌 매니아 매트릭스 #1. 외국인 페인포인트 = (a) "BIFF = 일반 영화제" 잘못된 인식 (b) 아시아 #1·칸·베니스·베를린 다음 글로벌 매니아 매트릭스 #1 (c) 영화의전당 (메인)·센텀시티·BIFF 광장 매트릭스 (d) 티켓 6개월+ 사전 예약·외국인 매니아 #1 (e) 부산 (#1021) cross 풀세트.

본 가이드는 5축 12 시그니처 + BIFF 매트릭스 + 부산 cross.

★ 한눈에 5축 12 시그니처

🏛 5축 deep dive

① 영화의전당 (메인·매니아 #1)

  • 시그니처: 2011년 개관·아시아 #1 영화 시설·오픈시네마 (실외 4000석)·하늘연극장 (1300석)·중극장 (840석)·소극장 (212석)
  • 외국인 친화도: ★★★★★ (영문·다국어 자막 풀세트·매니아 #1)
  • 시간: BIFF 기간 09:00~24:00
  • 추천: 오픈시네마 = 외국인 매니아 매트릭스 #1·매니아 + 인스타

② 센텀시티 영화관 cluster

  • 시그니처: 센텀시티 = 신세계백화점 + 영화관 cluster·MZ + 가족 매니아 매트릭스
  • 외국인 친화도: ★★★★★ (영문·결제 카드·픽업)
  • 추천: 영화 + 쇼핑 + 매니아 풀세트

③ BIFF 광장 (자갈치·남포동)

  • 시그니처: 1996년~ BIFF 시작 광장·한국 영화 매니아 핸드프린팅·자갈치 + 남포동 cluster
  • 외국인 친화도: ★★★★★ (영문·MZ + 매니아)
  • 추천: 광장 + 핸드프린팅 + 자갈치 (#1022 cross)

④ 시즌 매트릭스 (10월 첫째~둘째 주)

  • 2026 BIFF (제31회): 10월 1일 (목)~10월 10일 (토)·10일간 예상
  • 티켓 예약: 6개월+ 사전 (5월~6월 시작)·매니아 매트릭스 #1
  • 외국인 매니아: 영문 사이트·결제 카드 OK

⑤ 부산 cross 풀세트 (#1021)

  • 시그니처: BIFF + 부산 풀세트·자갈치·해운대·감천·해동용궁사 매니아 매트릭스 #1
  • 추천: 3박 + BIFF + 부산 풀세트 = 매니아 매트릭스 #1
  • 가격: 3박 호텔 = 250,000~800,000원/인

⚠ 외국인 자주 실수 5가지

1. "BIFF = 일반 영화제": 아시아 #1·1996년~ 30년+·칸·베니스·베를린 다음 글로벌 매니아 매트릭스 #1.

2. "티켓 = 당일 예약": 6개월+ 사전 예약 필수·매니아 매트릭스 #1.

3. "영문 자막 X": 다국어 자막 풀세트·외국인 매니아 매트릭스 #1.

4. "호텔 = 당일 예약": 3-6개월+ 사전 예약 필수·해운대 매트릭스 #1.

5. "부산 = 영화만": 부산 풀세트 + BIFF = 3박 매니아 매트릭스 #1·자갈치·해운대·감천 cross.

⚙ FAQ 6개

1. 외국인 입문 1순위: 영화의전당 오픈시네마 + BIFF 광장 + 부산 cross = 3박.

2. 2026 일정: 10월 1일~10월 10일·10일간 예상.

3. 티켓 예약: 6개월+ 사전 (5월~6월 시작)·영문 사이트·결제 카드.

4. 영문 자막: 다국어 자막 풀세트·한국 영화 = 영문 자막 OK.

5. 호텔: 3-6개월+ 사전 예약 필수·해운대·센텀 cluster.

6. 추천 페르소나: 가족·시니어 = 영화의전당 + 한정식 / MZ·인스타 = BIFF 광장 + 야경 / 매니아 = 5박+ 풀세트.
