🎯 なぜレストランキムチ入門銅線ガイドなのか

#822キムチ6種マトリックスが韓国キムチシグネチャー perspectiveならば、外国人観光客ペインポイントは"食堂で実際にどのキムチにいつ会ってどのように扱わなければならないのか"銅線perspectiveだ。外国人の99％が韓国到着初日の韓国料理店に行くが - (a)基本的なおかずで敷かれるキムチ1〜4種を区別できず、 (b)「詰め替え無料」サインを読めない（c）店舗別キムチの違い再訪問時に「常連キムチ」要請ノウハウを知らない。

このガイドはレストランの入場→おかずを受け取る→詰め替えリクエスト→再訪問 4段階+店舗タイプ別キムチマトリックス+メニュー-キムチペアリング表+英語発話キット。

🚪 Step 1 — 入場+席（キムチ＝自動無料おかず）

＃＃＃入場時に外国人の5つのコア

1. 「何人ですか？」 = How many people? — 指で表示 OK

2. "ここに座ってください" = This way please — 席案内

3. 基本おかず自動敷き詰め = キムチ1～5種が自動的にオーム — 別途リクエストX・無料

4. 水・タオル自動 =別途請求X

5. メニュー版英文 =明洞・梨泰院・弘大・江南・鍾路主食堂英文OK

＃＃＃座るとすぐに敷設キムチ（店舗別）

  • クッパハウス: カクドゥギ1種・白菜キムチ1種 = 2つの器
  • BBQ: 白菜キムチ・カトゥギ・サムジャン・レタス = 4～6個のボウル
  • 韓国料理: 白菜キムチ・ベクキムチ・ドンチミ・カクヅミ・総角キムチ = 5種フルセット
  • 分食: ダンムジ・白菜キムチ = 2つの器
  • カフェ：キムチX（例外＝キムチベーカリー・キムチトースト）

英語発火キット(Step 1)

  • 「Is the kimchi free?」 →キムチ無料ですか？ = YES（すべての韓国料理レストラン）
  • 「Can I get more kimchi?」 →キムチをもっともらえますか？ = YES・無制限
  • 「Which kimchi is least spicy?」 →一番辛いキムチは？ = ペクキムチ・ドンチミリクエスト

スパイシーなキムチのリクエスト英語

  • 「Do you have white kimchi?」 →白キムチありますか？ （スパイシー）
  • 「Do you have water kimchi?」 →水キムチ（東チミ・ナバク）ありますか？ （スパイシー）
  • 「Mild kimchi please」→辛いキムチでお願いします

＃＃🔄Step 3 - 無料の無制限の詰め替え（すべてのレストラン）

補充要求標準手順

1. キムチボウルが空の場合 = 自動詰め替え信号

2. "キムチもう少しください" = Can I get more kimchi? — 社長・従業員呼び出し

3. 追加ボウル = 5秒～1分以内に到着

4. 無料・無制限 = すべての韓国料理レストラン

5. 例外店舗X =韓国どこでも無料（チェーン・老舗・高級全て）

＃＃＃詰め替えできないケース（まれですが）

  • ビュッフェ・セルフストア = ユーザーが直接行ってインポート
  • チェーン無限詰め替え店舗 =時間制限（1時間30分など）
  • 空港・鉄道駅店 = 一部1回提供（まれですが）

＃＃＃詰め替え頻度（外国人対韓国人）

  • 韓国人平均：1食あたり1〜2回詰め替え
  • 外国人平均：1回または0回（要求の知らない）
  • 外国人マニア：3〜4回（韓国人レベル）

英語発話キット(Step 3)

  • "More kimchi please" = キムチ もっとください
  • 「Different kimchi?」 =他の種類のキムチもありますか？ （限定式・多種店舗）
  • 「Same kimchi」＝同じキムチ（要請時）

🎯 Step 4 — 再訪問+定番ノウハウ

＃＃＃再訪問時のキムチノウハウ

1. 社長の挨拶 =韓国老舗=社長がキムチ直接浸す店舗多

2. "社長のキムチおいしい" = This kimchi is really good — 社長の誇り・サービスのキムチ OK

3. キムチシーズン要請 =春(熱霧開始)・夏(熱舞・ナバク)・秋(キムジャン準備)・冬(キムジャン・ドンチミ) 店舗別シグネチャー相違

4. 発酵段階をリクエスト = "泊まってください" / "表側にしてください" — 常連マトリックス

5. 社長キムチ教え =再訪問常連=社長がキムチ 秘法・材料・シーズン情報 share

外国人再訪問ROI

  • 再訪問=キムチペアリング無料アップグレード（サービスキムチ・ムンウンジ・シーズンキムチ無料）
  • 再訪問=社長の韓国文化・近所おすすめ（現地マニア#1）
  • 再訪問=韓国友達関係開始(社長=近所情報hub)

＃＃⚠外国人の頻繁な誤り5つ

1. 「キムチ＝別途リクエスト・有料」：韓国料理店キムチ＝自動無料おかず・無制限リフィル。別途注文X。

2. 「キムチ詰め替え未要（静かに終わり）」：韓国標準＝詰め替え要請＝正常。 「More kimchi please」 自然さ。韓国人平均1食1～2回詰め替え。

3. 「クッパ屋さんに多様なキムチ期待」：クッパ屋さん = カクドゥギ1種（特化店）。多様なキムチ＝限定式・家庭式。

4. "BBQからキムチのペアリングの知らない": BBQ熟したキムチ=オイルのジュースのマトリックス。日本人#1・中国人#1マニア。

5. 「分食・チキンにキムチないと思う」: 分食＝ダンムジ＋白菜キムチ。チキン＝チキンムー＋白菜キムチ。 キムチ=韓国料理店標準。

⚙ FAQ 6個

1. 外国人初の韓国料理店おすすめ: クッパの家 (カット置きシンプル・スープ暖かい) → BBQ (キムチ豊富) → 限定食 (多様).初訪問＝クッパ屋。

2. "キムチ無料無制限"信号: メニュー版・看板X・当たり前の韓国食堂標準。店舗入場＝自動適用。

3. リフィル頻度: 韓国人＝1～2回・外国人マニア＝3～4回・外国人新規＝0～1回。マニア＝店舗定番。

4. 泊まったか店舗:老舗・30年+家庭食・キムチチゲ専門店舗=泊まったか備蓄。チェーン＝泊まったかX多。

5. シーズンキムチ店舗:春(熱舞開始4～5月)・夏(ナバク・熱​​舞6～8月)・秋(キムジャン準備10～11月)・冬(キムジャン・東チミ11～2月) — 家庭食・老舗シグネチャー。

6. アレルギー：エビ箸（甲殻類）・アンチョビ液煮・ニンニク・コチョウガル・豆（醤油）事前告知。白キムチ・ドンチミ＝マコムX＋一部アレルゲンXオプション。

⚠医療・安全・食事ダイエット

キムチ＝発酵食品（塩分↑・辛味多）。妊婦・高血圧・腎臓患者＝塩分注意。子ども＝白キムチ・ドンチミ（安辛）推奨。アレルギー（エビ箸・アンチョビ液箸・甲殻類・ニンニク・コチョウガル）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。

食事制限 fallback:

  • ハラール・コーシャ: 一般キムチ＝ビハラル・ビコッシャー（エビを含む）。 → 査察料理キムチ = ベジタリアン・ハラール・コーシャ可能
  • ベジタリアン・ビーガン: 一般キムチ = ベジタリアン（エビ箸・アンチョビ液箸）。 →査察食品またはビーガンキムチ（醤油ベース）別売店
  • グルテンフリー: 醤油を抜くとOK。白キムチ・ドンチミ＝醤油X＝OK

＃＃✈️外国人ペインポイント#1 - レストランキムチ対マートキムチの違い

  • 食堂キムチ =社長直接納金(老舗)またはキムチ工場納品(チェーン) — 新鮮・季節・店舗シグネチャー
  • マートキムチ =キムチ工場の大量
  • 体験の違い：レストラン=新鮮・シーズン変化/マート=標準一貫性
  • 帰国プレゼント: マート真空包装キムチ = 受託手荷物OK(液体分類・100ml+) — 機内携帯X
  • おすすめ購入先：仁川空港免税店（真空包装）・イマート・ロッテマート（苛性費）
