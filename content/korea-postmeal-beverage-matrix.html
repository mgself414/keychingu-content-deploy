부제: 외국인 관광객용 식사 후 마무리 + 해장 + 한정식 코스 마지막 음료

ISSUE 03 · #870 · 2026-06-09

🎯 왜 식사 마무리 음료 매트릭스인가

외국인 한국 음료 페인포인트 = "식사 + 술만 알고 식사 후 음료 모름". 한국 식사 마무리 음료 = 한정식 코스 마지막 + 가정식 후식 + 해장 시그니처. 같은 "Korean traditional beverage"라도 식혜 (단맛·한정식 #1)·식해 (생선 발효·강원 정통)·수정과 (계피·생강·곶감)·동동주 (식사 술·마실 + 음료)·매실차 (해장·소화)·해장수 (콩나물 해장 cluster) 각자 다른 역할·매니아. #840 전통음료 cluster와 차별 = "식사 후 마무리 음료" 앵글 (한정식·가정식 마지막 + 해장 다음날). 외국인은 (a) 식혜 vs 식해 차이 모름 (b) 한정식 마지막 음료 모름 (c) 동동주 = 술이지만 음료처럼 모름 (d) 해장수 = 해장 cluster cross 모름. 본 가이드는 6종 매트릭스 + 마무리 + 해장.

★ 한눈에 식사 마무리 음료 6종 매트릭스

외국인 입문 1순위 = 식혜 + 수정과 (한정식 정통 + 글로벌 친화)

강원 정통 = 식해 (생선 발효 매니아)

식사 술 = 동동주 (한정식·가정식·전통주)

해장 다음날 = 매실차 + 해장수 (소화·해장)

🍹 6종 deep dive

🍚 식혜 (Sik-hye) — 한정식 마지막 #1

  • 시그니처: 한정식 코스 마지막 음료 #1·달콤·전통
  • 재료: 쌀밥 + 엿기름 (malted barley) + 설탕 (밥알 떠 있음)
  • 외국인 친화도: ★★★★★ (#1 입문·달콤 글로벌)
  • 추천 매장:
  • 한정식 (#837) — 코스 마지막 #1
  • 신라호텔 라연·삼청각·인사동 — 정통
  • 마트·편의점 (캔·페트병)
  • 온도: 차가운 (얼음 포함)
  • 가격: 한정식 무료 / 마트 = 2,000~5,000원/캔

🐟 식해 (Sik-hae) — 강원 정통

  • 시그니처: 강원 정통·생선 발효 + 쌀·매니아 음식 (식혜와 다름)
  • 재료: 명태·도루묵·가자미 + 쌀·고춧가루·무 (발효)
  • 외국인 친화도: ★★★ (발효 강함·매니아)
  • 추천 매장: 강원 노포·시장
  • 시기: 사계절·강원 정통
  • 가격: 시장 = 10,000~25,000원/팩
  • 주의: 식혜 = 단맛 음료 / 식해 = 발효 반찬·강원 매니아 — 완전히 다른 음식

🍂 수정과 (Sujeong-gwa) — 겨울 정통

  • 시그니처: 겨울 정통·계피·생강 + 곶감 + 잣
  • 재료: 계피·생강 + 곶감 + 잣 (장식)
  • 외국인 친화도: ★★★★ (겨울 정통·매콤 달콤)
  • 추천 매장: 한정식 코스·전통차집·MZ 카페·마트
  • 온도: 차가운 (여름)·따뜻한 (겨울)
  • 계절: 겨울 #1·연중
  • 가격: 한정식 무료 / 마트 = 3,000~7,000원/캔

🍶 동동주 (Dong-dong-ju) — 전통 술·식사 술

  • 시그니처: 식사 술·전통 막걸리류·탁한 발효 술
  • 재료: 쌀 + 누룩 + 발효 (밥알 떠 있음·dong-dong = floating)
  • 외국인 친화도: ★★★★ (MZ 막걸리·전통)
  • 추천 매장: 한정식·전통주점·MZ 막걸리 cluster
  • 시기: 사계절·식사 술
  • 알코올: 6~8%
  • 가격: 5,000~15,000원/병

🌿 매실차 (Maesil-cha) — 해장·소화

  • 시그니처: 해장·소화·한국 전통 약재 음료
  • 재료: 매실 청 + 물 (따뜻한·차가운)
  • 외국인 친화도: ★★★★ (소화·해장 글로벌)
  • 추천 매장: 가정식·전통차집·마트·편의점
  • 온도: 따뜻한 (소화)·차가운 (여름)
  • 시기: 사계절
  • 가격: 가정식 무료 / 마트 = 2,000~5,000원

🍵 해장수·콩나물 국물 (Haejang-su) — 해장 다음날

  • 시그니처: 해장 cluster cross·다음날·콩나물 국물
  • 재료: 콩나물 + 무·파·고추·간장
  • 외국인 친화도: ★★★ (해장 매니아)
  • 추천 매장: 24h 본죽·국밥집·해장 cluster
  • 시기: 술 다음날 새벽·해장
  • 가격: 가정식·국밥집 = 8,000~15,000원
  • 자세히: #807 국밥 cluster

🍽 한정식 마지막 + 가정식 + 해장 시그니처

한정식 코스 마지막 (#837)

  • 6단계 코스 마지막 = 식혜 + 수정과 (디저트 단계)
  • 신라호텔 라연·삼청각·인사동 — 정통
  • 무료 포함

가정식 후식

  • 식혜·매실차 = 가정식 후식 무료
  • 백반집·MZ 한식당 — 가성비

해장 다음날 cluster

  • 매실차 + 해장수 = 해장 다음날 정통
  • 24h 본죽·국밥집 — 해장 매니아

전통주점·MZ 막걸리

  • 동동주·막걸리 = 전통 술 cluster (#840)
  • 광장시장·인사동 전통주점 — 정통

⚠ 외국인 자주 실수 5가지

1. "식혜 = 식해": 식혜 = 단맛 음료 (쌀밥+엿기름) / 식해 = 생선 발효 반찬 (강원 정통) — 완전히 다른 음식.

2. "동동주 = 일반 음료": 동동주 = 6~8% 알코올 술 (식사 술).

3. "수정과 = 차": 수정과 = 계피·생강·곶감 펀치 (차 X·과일 음료).

4. "한정식 음료 = 별도 비용": 한정식 마지막 음료 = 무료 포함 (식혜·수정과).

5. "매실차 = 일반 차": 매실차 = 약재 음료 (소화·해장 매니아).

⚙ FAQ 8개

1. 외국인 입문 1순위: 식혜 (한정식 마지막) + 수정과 (겨울) → 매실차 (소화).

2. 인스타·vlog: 한정식 식혜 (#1)·수정과 곶감·동동주 전통.

3. MZ 트렌드: MZ 카페 식혜 변형·동동주·매실 스파클링.

4. 소화·해장: 매실차 + 해장수.

5. 알레르기: 견과류 (잣) 사전 고지.

6. 알코올: 동동주 = 6~8%·임신부·운전 X.

7. 결제·팁: 한정식·가정식 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

식사 마무리 음료 = 일반 음식. 임신부·어린이 = 식혜·수정과·매실차 OK (동동주 = X 술). 알레르기 (견과류·생강) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 식혜·수정과·매실차·해장수·식해 (지역별) = OK / 동동주 = 알코올 X (할랄 X).
  • 채식·비건: 5종 채식 OK / 식해 = 생선 발효 (비채식).
  • 글루텐 free: 6종 모두 OK (간장 함유 시 Tamari 대체).
