🎯 왜 감천문화마을 + 보수동 가이드인가

감천문화마을 (Gamcheon Culture Village) = "산토리니의 부산"·1950년~·인스타 1번지. 보수동 책방골목 (Bosudong Book Street) = 1950년~·한국 #1 헌책방 거리. 외국인 페인포인트 = (a) "감천 = 일반 마을" 잘못된 인식 (b) 산토리니 매트릭스·파스텔 컬러·MZ + 인스타 1번지 (c) 1950년 한국전쟁 후 피난민 정착·역사적 깊이 (d) 보수동 = 1950년~ 한국 #1 헌책방·MZ + 매니아 매트릭스 (e) 영문 시그너 + 카페 cluster + 매장 매트릭스.

본 가이드는 5축 12 시그니처 + 감천 + 보수동 + 인스타 매트릭스.

🏛 5축 deep dive

① 감천문화마을 (1950년~·산토리니의 부산)

  • 시그니처: 1950년 한국전쟁 후 피난민 정착·태극도 마을 시작·산토리니 매트릭스
  • 명성: CNN 2012·BBC 2014 한국 매니아 매트릭스·인스타 1번지
  • 외국인 친화도: ★★★★★ (영문 시그너·MZ + 인스타)
  • 시간: 09:00~18:00·무료·일부 매장 결제
  • 추천: 산책 + 어린왕자 + 카페 + 인스타 = 1.5-2h

② 보수동 책방골목 (1950년~·한국 #1 헌책방)

  • 시그니처: 1950년 한국전쟁 후·한국 #1 헌책방 거리·100m
  • 외국인 친화도: ★★★★ (영문 일부·MZ + 빈티지 매니아)
  • 추천: 헌책방 산책 + MZ 카페 + 빈티지 = 1-1.5h

③ 카페 cluster (감천·보수동·인스타)

  • 시그니처: 인스타 1번지·MZ + 매니아 매트릭스
  • 외국인 친화도: ★★★★★ (영문 메뉴·결제 카드)
  • 가격: 커피·디저트 = 8,000~16,000원/인

④ 골목투어 (감천·보수동)

  • 시그니처: 1.5h·영문 가이드·외국인 매니아
  • 가격: 5,000~10,000원/인

⑤ 한복 대여 (감천·MZ + 인스타)

  • 시그니처: 한복 + 산토리니 매트릭스 = 인스타 매니아 #1
  • 가격: 한복 대여 1-3h = 15,000~30,000원/인

⚠ 외국인 자주 실수 5가지

1. "감천 = 일반 마을": 산토리니의 부산·CNN 2012·BBC 2014 매니아 매트릭스·인스타 1번지.

2. "감천 = 단순 인스타": 1950년~ 한국전쟁 피난민 정착·태극도 마을 역사.

3. "보수동 = 일반 책방": 1950년~ 한국 #1 헌책방 거리·MZ + 빈티지 매니아.

4. "가파른 골목 = 외국인 X": 평지 + 가파른 골목 매트릭스·걷기 편한 신발 권장.

5. "한복 = 궁궐만": 감천 + 한복 = 인스타 매니아 #1.

⚙ FAQ 6개

1. 외국인 입문 1순위: 감천 + 보수동 = 3시간 인스타 + 카페 코스.

3. 한복 대여: 감천 1-3h = 15,000~30,000원·MZ + 인스타 매니아 #1.

4. 골목투어: 영문 가이드·1.5h·5,000~10,000원·외국인 매니아.
