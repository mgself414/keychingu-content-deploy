K-popミュージックビデオ撮影地7選 — 報道で確認されたMVの場面、今の行き方

サブタイトル: BTS「Spring Day」の楊州イリョン駅、「Epilogue: Young Forever」の堤川飛行場、「Not Today」の清州文化製造廠、「Save ME」の扶安セマングム、SUGA「Daechwita」の龍仁テジャングムパーク、PSY「Gangnam Style」のソウル子ども大公園、NewJeans「Bubble Gum」の済州ファンウチ海岸。報道でMVの撮影地と確認でき、一般の訪問が可能な場所だけを7か所選びました。場所ごとに、どんな場面か、時間・料金、道中の注意点を書きました。

ISSUE 03 · #565 · 2026-11-25

🎯 こんな人に

好きなミュージックビデオの場面を自分の足で歩いてみたいK-popファンのための回です。所属事務所は撮影地を公式に明かさないのがふつうです。そこでこの回は、ニュース記事が「このMVはここで撮った」と書いた場所だけを選びました。ファンコミュニティの投稿にしかない場所は外しています。そのうえで、一般の訪問が可能かどうかを見るために、カカオマップで場所が営業中と表示されるか(2026-11-25確認)を調べ、運営主体の公式ページがあればその案内を確認しました。

⚠ 表記の原則: 時間・料金の横には出典と確認日を付けました。カカオマップの値は、場所のページに登録されている値です(2026-11-25確認)。MVの場面の説明は、かっこ内の記事に出ていた内容だけを移しました。撮影から時間がたち、画面と今の姿が違う場所が多くあります。とくに清州の文化製造廠は、撮影後に改装されました。道順と所要時間は、当日カカオマップの道案内で確認してください。

① ソウル・京畿 — 3か所

  • イリョン駅 (Ilyeong / 일영역) (楊州) — BTS「Spring Day」のミュージックビデオの最初の場面、雪が降る小さな駅がここです(ソウル新聞 2019-03-22)。ソウル新聞は、Vがホームの下に降りて線路に耳を澄ませる場面をここだと紹介しました(2019-03-22)。イリョン駅は2004年に旅客運行が途絶えた郊外線 (Gyoeseon Line / 교외선)の駅でした。郊外線は2025-01-11にふたたび走り始めました。路線はテゴク駅 (Daegok / 대곡역)からウォヌン (Wonneung / 원릉)・イリョン・チャンフン (Jangheung / 장흥)・ソンチュ (Songchu / 송추)の各駅を通って、ウィジョンブ駅 (Uijeongbu / 의정부역)までです(ソウル新聞 2026-09-01)。列車が走る駅なので、線路には入りません。住所は楊州市のイリョン路647番キル25 (Ilyeong-ro 647beon-gil 25 / 일영로647번길 25)、チャンフン面 (Jangheung-myeon / 장흥면)です。カカオマップでは営業中の駅と表示されます(2026-11-25)。運行本数が多くないので、列車の時間はコレールトークのアプリで先に見ておきます。車で10分の距離にチャンフン彫刻公園 (Jangheung Sculpture Park / 장흥조각공원)があります(ソウル新聞 2019-03-22)。
  • 龍仁テジャングムパーク (Yongin Daejanggeum Park / 용인 대장금파크) — SUGA(Agust D)のソロ曲「Daechwita」のミュージックビデオの撮影地として知られ、海外のファンが訪れているとニューズワが報じました(2026-08-02)。チャンドックン (Changdeokgung / 창덕궁)のインジョンジョン (Injeongjeon / 인정전)を模して建てたセットがとくに人気です(同じ記事)。MBCが運営する時代劇の撮影場です。時間は3~10月は毎日 09:00~18:00、11~2月は毎日 09:00~17:00です(カカオマップ登録値, 2026-11-25)。入場料は大人11,000ウォン、青少年・子ども9,000ウォンで、未就学児は無料です(公式お知らせ, 2024-10-01適用分, 2026-11-25確認)。チャングミ・ツアーカー (Janggeumi Tour Car / 장금이 투어카)は1人4,500ウォンです(ニューズワ 2026-08-02)。住所は龍仁市のヨンチョンドラマ路25 (Yongcheondrama-gil 25 / 용천드라마길 25)、ペガム面 (Baegam-myeon / 백암면)、チョイン区 (Cheoin-gu / 처인구)です。公共交通では遠いので、車かタクシーで行くほうがよいです。臨時休館のお知らせが出ることがあるので、行く前に公式サイトのお知らせを見ておきます。
  • ソウル子ども大公園 (Seoul Eorini Daegongwon / 서울어린이대공원) (広津) — ソウル市メディアハブ (Seoul Media Hub / 서울시 미디어허브)は、PSY「Gangnam Style」のミュージックビデオの回転木馬がここで撮影されたと紹介しました(2026-01-30)。公園の入場は無料です。時間は年中無休で 05:00~22:00です(ソウル施設公団 (Seoul Facilities Corporation / 서울시설공단)公式サイト, 2026-11-25)。乗り物のある遊園地は有料で、平日は 10:00~18:30、土・日・祝日は 10:00~19:30に開きます(カカオマップ登録値, 2026-11-25)。住所は広津区のヌンドン路216 (Neungdong-ro 216 / 능동로 216)です。最寄り駅は7号線の子ども大公園駅 (Eorini Daegongwon / 어린이대공원역)1番出口です。カカオマップの道案内で徒歩9分です(2026-11-25)。

② 忠清・全羅 — 3か所 (BTS 2016~2017のMV)

3か所とも、ソウルから日帰りで行けますが、公共交通では遠いです。レンタカーかツアー商品を使うほうがよいです。

  • 堤川飛行場 (Jecheon Airfield / 제천비행장) (母山飛行場 (Mosan Airfield / 모산비행장)) — BTS「Epilogue: Young Forever」(2016)で、メンバーが滑走路を走る場面をここで撮りました。京郷新聞 (Kyunghyang Shinmun / 경향신문)は、MVの2分20秒~2分40秒の場面だと指摘しました(2025-08-06)。1950年代に軍用に造られた飛行場です。堤川市が2004年に軍部隊と協議して、滑走路の一部41,000㎡を市民の憩いの場として開放しました(同じ記事)。堤川市は滑走路920mの区間を買い取って公園にする計画です(同じ記事)。地図では飛行場の名前がうまく出てきません。ソウル新聞は、ナビに「ウィリムジ洞住民センター (Uirimji-dong Community Center / 의림지동주민센터)」を入れるよう案内しました(2019-03-22)。カカオマップには「堤川飛行場」(コアム洞 (Goam-dong / 고암동) 1179-1)と出ます(2026-11-25)。春は菜の花、秋はピンクミューリーが咲きます(カカオマップのタグ)。車で3分の距離に貯水池のウィリムジ (Uirimji / 의림지)があります(ソウル新聞 2019-03-22)。軍施設用地の開放区間です。案内板の人工構造物・ごみ禁止の文言に従い、公園化事業で立ち入れる範囲が変わることがあります。
  • 文化製造廠 (Munhwa Jejochang / 문화제조창) (清州) — BTS「Not Today」のミュージックビデオに出てきた駐車場とビルの屋上が、旧清州煙草製造廠 (Cheongju Tobacco Factory / 청주연초제조창)です(ソウル新聞 2019-03-22)。タバコ工場だった建物は、今は文化製造廠という複合文化空間です。韓国工芸館 (Korea Craft Museum / 한국공예관)、国立現代美術館清州館 (National Museum of Modern and Contemporary Art Cheongju / 국립현대미술관 청주관)(隣の建物)、書店・飲食店が入っています。本館は毎日 10:00~20:00に開きます(カカオマップ登録値, 2026-11-25)。住所は清州市のサンダン路314 (Sangdang-ro 314 / 상당로 314)、チョンウォン区 (Cheongwon-gu / 청원구)です。改装でMVの屋上・駐車場の姿は大きく変わりました。昔のタバコ工場の建物そのものを見に行くつもりで行きます。
  • セマングム広報館 (Saemangeum Promotion Hall / 새만금홍보관)前の干拓地 (扶安) — BTS「Save ME」のミュージックビデオを、セマングムの干拓地で撮りました(ソウル新聞 2019-03-22)。中央日報英語版は、セマングム広報館前の干拓地と具体的に書きました(2018-06-15)。同じ記事は、道のない空き地なので、入口に車を置いて歩いて入るようにと伝えています。近くにトイレ・コンビニがないことも書いています(2018年の記事基準で、今の空き地への立ち入り状況は確認できませんでした。広報館に問い合わせてください)。広報館の時間は 10:00~17:30です(カカオマップ登録値, 2026-11-25)。月曜は定期休館です(公式サイト, 2026-11-25)。トイレは空き地に入る前に広報館で済ませます。住所は扶安郡のセマングム路6 (Saemangeum-ro 6 / 새만금로 6)、ピョンサン面 (Byeonsan-myeon / 변산면)です。

③ 済州 — 1か所

  • ファンウチ海岸 (Hwangwoochi Beach / 황우치해변) (西帰浦) — NewJeans「Bubble Gum」のミュージックビデオを撮った海岸です(ニュース1 2024-05-12、ソウル新聞 2024-05-10)。サンバンサン (Sanbangsan / 산방산)のふもと、ヨンモリ海岸 (Yongmeori Coast / 용머리해안)の隣のサゲ里 (Sagye-ri / 사계리)にあります。同じ記事は、曇りの日はMVのような明るい海の色が見えにくかったと書きました。晴れた日の昼に行きます。公共のビーチなので入場料はありません。カカオマップにビーチとして登録されています(西帰浦市のアンドク面 (Andeok-myeon / 안덕면)サゲ里79-4 (Sagye-ri 79-4 / 사계리 79-4), 2026-11-25確認)。ソウル新聞は、MVにソンアクサン (Songaksan / 송악산)と西帰浦の私有地も背景として出てくると書きました(2024-05-10)。私有地の場面の場所は、訪問をおすすめしません。

📌 おまけ — 根拠が1か所だけ、またはMVではない場所

ノドゥル島 (Nodeul Island / 노들섬) (ソウル 龍山) — コリア・タイムズは、BTS「Run」のMVの場面に出てきたと紹介しました(2026-03-13)。ほかの媒体では確認できませんでした。そのため7か所の数には入れていません。漢江 (Han River / 한강)の真ん中にある複合文化空間で、9号線ノドゥル駅 (Nodeul / 노들역)2番出口から徒歩12分です(カカオマップの道案内, 2026-11-25)。施設は11~2月は火~日 10:00~20:00に開き、月曜は休みです(カカオマップ登録値, 2026-11-25)。

江陵 (Gangneung / 강릉)のジュムンジン・ヒャンホ海岸 (Hyangho Beach / 향호해변)のBTSバス停は、よく「MVの撮影地」と呼ばれます。しかしソウル新聞(2019-03-22)とコリア・タイムズ(2026-03-13)は、ここを「You Never Walk Alone」のアルバムジャケットの撮影地と書いています。撮影のときに小道具として立てて、撤去しましたが、ファンが訪れ続けたのでまた立てました(コリア・タイムズ)。実際のバスは停まりません(ソウル新聞)。カカオマップには「BTSバス停 (BTS Bus Stop / BTS 버스정류장)」(江陵市のジュムンジン邑 (Jumunjin-eup / 주문진읍)ヒャンホ里8-39 (Hyangho-ri 8-39 / 향호리 8-39))と出て、営業中と表示されます(2026-11-25)。アルバムジャケットの撮影地なので、7か所の数には入れていません。江陵に行くなら、立ち寄ってみる価値があります。

🗺 動線 — 2コース

A. ソウル半日 — 子ども大公園

  1. 午後 7号線の子ども大公園駅から公園へ。遊園地は平日18:30、土・日・祝日19:30まで開きます(カカオマップ, 2026-11-25)
  2. 夜 22:00まで開いている公園を散歩します(ソウル施設公団)

「Run」をたどりたいなら、おまけの項のノドゥル島を前に付けます。ノドゥル島の施設は月曜が休みです。

B. 車で1日 — 清州・堤川のBTSコース

  1. 午前 清州の文化製造廠(10:00~)
  2. 午後 車で堤川に移って堤川飛行場の滑走路、続いてウィリムジ

2つの都市の間の移動時間は、当日カカオマップの道案内で確認します。扶安のセマングムは方向が違うので、別に1日を取ります。

⚠ よくある失敗3

  1. 江陵のバス停を「Spring Day」のMVの場所だと思って行く — 報道で確認できる「Spring Day」のMVの最初の場面は、楊州のイリョン駅です。江陵のバス停はアルバムジャケットの撮影地です。2か所は京畿北部と江原の東海岸で遠く離れているので、動線は別に組みます。
  2. イリョン駅の線路に入って写真を撮る — 郊外線は2025-01-11からふたたび走っています(ソウル新聞 2026-09-01)。列車が通る線路に入ってはいけません。写真はホームと駅の外で撮ります。
  3. 月曜にセマングムへ行く — セマングム広報館は月曜が定期休館です(公式サイト)。空き地の近くにはトイレがないので(中央日報英語版 2018-06-15)、広報館が開いている日に行きます。

⚙ FAQ 3

  1. 芸能事務所の社屋も撮影地ですか? — いいえ。社屋はMVの撮影地ではなく、内部も一般の訪問者には開かれていません(コリア・タイムズ 2026-03-13)。社屋前の写真コースは#387と#1260にあります。
  2. ソウルでいちばん行きやすい場所は? — 7号線の子ども大公園駅から徒歩9分のソウル子ども大公園です(カカオマップの道案内, 2026-11-25)。公園の入場は無料です(ソウル施設公団)。根拠が1つの媒体だけのノドゥル島は、おまけの項に別に書きました。
  3. ツアー商品で一度に回れますか? — 韓国観光公社は2026年にHYBE・JYP・SM・スターシップと「BIAS」キャンペーンを行いました。映像に出てくる場所と体験をまとめた商品が、NOLユニバース (NOL Universe / 놀유니버스)・クリエイトリップ (Creatrip / 크리에이트립)・Klook・KKdayに載りました(MTN 2026-06-24)。ただしキャンペーン映像はミュージックビデオではないので、この回の7か所とは重なりません。商品の構成と価格は、それぞれの予約サイトで確認してください。
