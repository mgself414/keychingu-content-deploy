🍱 4채널 deep dive

🍱 한정식 반찬 풀세트 (Hanjeongsik Banchan)

핵심 가치: 나물 4~6종 무한 리필 + 무료 + 정통.

  • 추천 매장: 신라호텔 라연·삼청각·인사동 한정식 (#837)
  • 가격: 코스 40,000~150,000원 (나물 무료)
  • 외국인 친화도: ★★★★

🪷 사찰음식 (Temple Cuisine)

핵심 가치: 정통 채식 + 오신채 X + 할랄 OK + 글로벌 #1.

  • 추천 매장:
  • 진관사 (서울 은평) — 사찰음식 정통 #1
  • 조계사 — 사찰음식 cluster
  • 봉은사·관악산 — 사찰음식 매니아
  • 가격: 코스 25,000~80,000원/1인
  • 외국인 친화도: ★★★★★ (글로벌 채식)
  • 오신채 X: 마늘·파·달래·부추·흥거 제외

🍚 전주 비빔밥 (Jeonju Bibimbap)

핵심 가치: 5색 나물 풀세트 + 정통 #1 + 전주 한옥마을.

  • 추천 매장:
  • 전주 한옥마을 비빔밥 노포 — 정통 #1
  • 서울 전주식 비빔밥집 (강남·홍대) — 가성비
  • 가격: 비빔밥 = 8,000~25,000원/1인
  • 5색: 시금치·당근·콩나물·고사리·도라지 + 계란 + 고추장
  • 외국인 친화도: ★★★★★ (전주 정통·MZ #1)

🏠 가정식 백반·MZ 한식당 (Korean Home-style)

핵심 가치: 홈스타일 + 가성비 + 가족 #1.

  • 추천 매장:
  • 종로·강남·명동 백반집 — 가성비
  • 한솥·본도시락 — 가성비 (#854)
  • 가격: 8,000~15,000원/1인 (나물 무료 포함)
  • 외국인 친화도: ★★★★

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가격·채식·매니아 완전 다름. 무료 = 한정식·가정식 / 채식 = 사찰음식 / MZ = 전주 비빔밥.

2. "한정식 = 채식": 한정식 반찬 = 멸치액젓 일부 함유 가능 (사찰음식 #1).

3. "사찰음식 = 풀만": 사찰음식 = 나물 + 두부·버섯·산채·풀세트.

4. "전주 비빔밥 = 일반": 전주 비빔밥 = 5색 정통 #1·궁중 비빔밥 cluster.

5. "가정식 = 비싸기만": 가정식 = 8,000~15,000원 가성비 #1 (나물 무료 포함).

⚙ FAQ 8개

1. 첫 나물 채널 = 어디: 전주 비빔밥 (#1 입문) → 한정식 반찬.

2. 인스타·vlog: 한정식 반찬 (#1)·전주 비빔밥 (#1)·사찰음식.

3. MZ 트렌드: 전주 비빔밥 (#1)·사찰음식·MZ 한식당.

4. 채식·비건·할랄: 사찰음식 (#1) + 전주 비빔밥.

5. 가족 동반: 가정식 백반 (#1) + 한정식.

6. 알레르기·임신: #876 disclaimer 참조.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

나물 4채널 모두 일반 음식·식물 기반. 임신부·어린이 = OK. 알레르기 (마늘·간장 글루텐·도라지 약재·멸치액젓 일부) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 사찰음식 = #1 정통 / 한정식 = 멸치액젓 확인 / 비빔밥 = 채식·계란 / 가정식 = 확인 필요.
  • 채식·비건: 사찰음식 = #1 / 다른 채널 = 멸치액젓 사전 확인.
  • 글루텐 free: 간장 양념 = 글루텐 (Tamari 대체).
