全州南部市场·青年商城·夜市指南——从韩屋村步行3分钟，2026官方信息

🎯 本指南使用方法

全州南部市场 (Nambu Sijang / 남부시장)离全州韩屋村 (Jeonju Hanok Maeul / 전주 한옥마을)很近，过丰南门 (Pungnammun / 풍남문)后步行3分钟即到（全州市官方）。白天的市场、2层的青年商城 (Cheongnyeon Mall / 청년몰)、周五周六的南部市场夜市 (Nambu Sijang Yasijang / 남부시장 야시장)、凌晨的鬼怪市场 (Dokkaebi Sijang / 도깨비시장)，都挤在同一栋楼和相邻的小巷里，只要把时段对上，就能直接接进韩屋村的行程。下面的数值只收录2026-10-07在全州市·全北观光官方页面上读到的内容；像夜市营业时间这样各出处不一致的数值，也照实标明。旧版指南里没有任何地址和时间。

🏮 南部市场——1473年的集市，就在丰南门旁

  • 全州市官方：这里是1473年起就有的集市，紧邻丰南门（宝物第308号），距韩屋村步行3分钟。地址丰南门1街 19-3，电话 063-284-1344。
  • 市场代表美食（官方）：豆芽汤饭 (Kongnamul-gukbap / 콩나물국밥)（热汤反复浇淋式）和血肠汤饭 (Pisundae-gukbap / 피순대국밥)。官方市场之旅页面上收录的店只有两家：老式血肠店 (Yetnal Pisundae / 옛날피순대)（24小时营业）和丰南门拌饭 (Pungnammun Bibimbap / 풍남문비빔밥)（04:00~18:00）。其他店铺和价格不收录。
  • 市场整体营业时间官方没有公布（二手出处为09:30~22:00），各店不同。

🛍 青年商城——2层，11:00~23:00，周一休息

  • 位于南部市场2层，地址丰南门2街 53。11:00~23:00，周一休息，约20家店（全州市官方）。官方页面写明“各店时间不同”，想去特定店铺请提前确认。
  • 旧版指南里“MZ·潮人成功模式”之类的评价，官方资料中没有，已删除。

🌙 夜市——仅周五·周六

  • 只在周五·周六营业。250米长的小巷里是小吃摊（全北观光官方）。小吃价格 3,000~5,000韩元档（官方）。
  • 营业时间各出处不一致：全北观光为3~10月 18:30~23:30·11~2月 18:00~24:00 / 韩国观光公社文章为18:00~24:00（夏季）·17:00~22:00（冬季）。2026年的确定值没能读到——按“周五·周六晚上，随季节变化”来安排，当天再确认。
  • 曾有报道称冬季（1~2月）停办的先例（2024年）。冬季出行请先确认是否营业。
  • 摊位数量各出处不同，分别为33·40·45个，因此不收录。

🌅 鬼怪市场——凌晨4点

  • 南部市场的凌晨集市，04:00~10:00（全州市官方）。全州清晨散步 + 豆芽汤饭的组合。

🏛 庆基殿——与韩屋村一起安排

  • 太祖路 44号。3~5月·9~10月 09:00~19:00，6~8月 09:00~20:00，11~2月 09:00~18:00，闭馆前1小时停止入场。非全州市民成人 3,000·青少年/军人 2,000·儿童 1,000韩元，每月最后一个周三免费·最后一个周六半价（全州市官方）。
  • 殿洞圣堂 (Jeondong Seongdang / 전동성당)的官方页面未能打开，因此不收录时间和费用。

🚉 交通

  • 全州站 (Jeonju-yeok / 전주역) → 韩屋村·南部市场：公交·出租车的所需时间官方页面上没有，因此不收录。请用地图应用搜索“全州南部市场”。
  • 从韩屋村过丰南门就是市场（官方“步行3分钟”）。

⚠ 常见失误5条

1. 周一去青年商城——休息。

2. 周日~周四去夜市——只在周五·周六营业。

3. 想当然认为冬季有夜市——有停办先例。请确认是否营业。

4. 不知道庆基殿票价就错过——最后一个周三免费，最后一个周六半价。

5. 以为市场的店铺全都开着——各店时间不同（官方提示）。

⚙ 常见问题6

1. 能和韩屋村一天玩完吗？——可以。步行3分钟。白天逛韩屋村·庆基殿 → 晚上去青年商城或周五周六夜市。

2. 夜市几点？——周五·周六晚上。随季节变化的时间各出处不一致，请当天确认。

3. 早餐吃什么？——鬼怪市场（04~10点），或豆芽汤饭（热汤反复浇淋式）·血肠汤饭。

4. 青年商城几点？——11:00~23:00，周一休息。

5. 庆基殿多少钱？——成人3,000韩元。最后一个周三免费。

6. 从全州站过去要多久？——官方未公布。请用地图应用查询。
