🎯 왜 한국 밥상 문화 deep dive인가

외국인 첫 방문자 100% 필수 = 한국 밥상 문화 deep dive (#14 한식·#133 국밥·#400 외국인 친화 식당 후속). 한국 밥상 = 밥·국·반찬 구조 + 먹는 순서·매너 + 외국인 매니아 1번지.

★ 한눈에 12 밥상 매트릭스

⚠ 외국인 자주 실수 5가지

1. "한국 음식 = 김치만": 한국 밥상 = 밥 (정식 한 그릇) + 국·찌개 + 반찬 3~10종 풀세트 + 외국인 매니아 1번지·#357·#388 통합.

2. "반찬 = 무료 무한 리필 안 됨": 한국 반찬 = 무료 + 무한 리필 OK (한식당) + 외국인 매니아·#400 통합·외국인 가성비 1번지.

3. "숟가락 = 일본·중국 같음": 한국 숟가락 = 밥·국 모두 숟가락 사용 (일본·중국과 차이) + 외국인 매니아 풀세트·매너.

4. "한식 = 모두 매움": 한식 = 매운맛 1~5 레벨 + 백반·궁중·사찰음식 안 매움 + 외국인 매니아 1순위·#357 사찰·#143 한정식.

5. "한정식 = 비쌈만": 한정식 = 가성비 (10~25K·#400 외국인 친화) + 럭셔리 (#143·#356 라연 미쉐린 300~800K) + 외국인 매니아 풀세트.

① 밥상 구성 #1 (4)

1. 밥 ★ 쌀밥·잡곡밥·곤드레

  • 종류: 쌀밥·잡곡밥·곤드레·콩밥·솥밥
  • 외국인 ★: ◎◎ — 한식 1번지·외국인 매니아
  • 시그니처: 1인 1공기·외국인 매니아·#400 통합

2. 국·찌개 (Guk·Jjigae)

  • 종류: 된장찌개·김치찌개·미역국·소고기무국·청국장·콩나물국
  • 외국인 ★: ◎◎ — 외국인 매니아·#133·#388 통합
  • 시그니처: 매운맛 1~5 레벨·외국인 매니아

3. 반찬 (Banchan 3~10종) ★

  • 종류: 김치·콩나물·시금치·무생채·계란말이·멸치볶음·생선구이·잡채
  • 외국인 ★: ◎◎ — 외국인 매니아·#357 통합
  • 시그니처: 무료 + 무한 리필·외국인 가성비 #1

4. 한정식 풀세트 ★ #143·#356 라연

  • 매장: 신라호텔 라연 (#356·#358 미쉐린)·반얀트리 페스타 (#360)·강남 한정식 (#143)
  • 외국인 ★: ◎◎ — 외국인 럭셔리 매니아 1번지
  • 시그니처: 12~24첩·외국인 매니아·#356·#358 통합

② 밥상 가성비 (2)

5. 백반·기사식당·#388 노포 ★

  • 매장: 이문설농탕 (1902 #388)·기사식당·백반 cluster (8~12K)
  • 외국인 ★: ◎◎ — 외국인 가성비 #1·외국인 매니아
  • 시그니처: 외국인 매니아·#388·#400 통합

6. 국밥 (#133·#388)

  • 매장: 우래옥 1946 평양냉면 (#388)·이문설농탕 1902 (#388)·#133 국밥
  • 외국인 ★: ◎◎ — 외국인 vlog #1·#129 냉면 통합
  • 시그니처: 외국인 매니아·#388 통합

③ 매너·먹는법 (3)

7. 밥 + 국 + 반찬 먹는 순서 ★

  • 순서: 1) 국 한 숟가락 (먼저 입맛) → 2) 밥 한 숟가락 + 반찬 → 3) 국·밥·반찬 반복
  • 외국인 ★: ◎◎ — 외국인 정통 매니아·#357 통합
  • 시그니처: 한국 정통 매니아·#400 통합

8. 숟가락·젓가락 매너

  • 한국 숟가락 = 밥·국 모두 사용 (일본·중국 차이)·금속 젓가락 (한국 정통)
  • 외국인 ★: ◎◎ — 외국인 매니아·#357·#388 통합
  • 시그니처: 외국인 매니아 풀세트

9. 매운맛 레벨 매트릭스 (Spicy 1~5)

  • 1 (순한): 미역국·갈비탕·삼계탕 / 5 (매운): 불닭볶음면·낙곱새·매운 갈비찜
  • 외국인 ★: ◎◎ — 외국인 매니아·#400 통합
  • 시그니처: 물김치·계란찜·우유 도움·외국인 매니아
