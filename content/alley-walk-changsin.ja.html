路地散策① チャンシンドン (Changsin-dong / 창신동) — 東大門の服が生まれる路地と、崖の上の村

副題: 東大門の服はどこで作られるのか。縫製路地→フェオリギル→崖の村→洛山城郭へと続く2時間30分、坂道を上る順に綴った。Seoul Alley Walks パイロット1。

ISSUE · #1340 · 2026-09-02

🎯 フレーム — 東大門のバックステージ

東大門総合市場 (Dongdaemun Jonghap Sijang / 동대문종합시장)(#1328)の生地が服になる場所こそ、この路地だ。チャンシンドンは数十年来東大門ファッションの背後の生産基地だ — 路地のあちこちからミシンの音が漏れ、バイクが完成した服の束を積んで市場へ下っていく。そして路地の突き当りには、日本統治時代の採石場が残した崖の上の村がある。観光地ではなく、働く場所であり暮らしの場所である路地 — だからこそ歩く順番とマナーが同時に必要なコースだ。

  • 所要時間: 約2時間〜2時間30分(展示・カフェ込みで+30分) · おすすめ時間帯: 平日午後2〜3時スタート → ナクサン (Naksan / 낙산) 城郭で夕焼けフィナーレ
  • 傾斜: 中〜上(上り坂コース — 歩きやすい靴必須、暑い日は水を持参)

🚶 コース — 歩く順番そのままに

① 東大門駅 (Dongdaemun Station / 동대문역) 3番出口 → チャンシンドン縫製通り (Bongje-geori / 봉제거리) (徒歩約5分)

  • 路地に入ると、まず音が変わる — ミシンの音、生地を積んだバイク。働く路地だから、バイクに道を譲りながら歩くのが最初のルールだ。
  • 📖 物語1 — 縫製の路地: チャンシンドンは1970年代から東大門市場の服を作ってきた縫製産業の心臓部だ。路地全体がソウル未来遺産 (Seoul Miraeyusan / 서울미래유산) に指定されており、今も無数の小規模工場が「朝の注文→夕方の納品」というスピードで回っている。あなたが昨日東大門で見た服は、今日この路地で生まれたものかもしれない。

② 縫製通り → イウムピウム縫製歴史館 (Ieumpium Bongje History Museum / 이음피움 봉제역사관) (徒歩約10分、上り坂)

  • 縫製路地の端、ナクサン城郭 (Naksan Fortress Wall / 낙산성곽) 近くにある4階建ての展示館。縫製の歴史展示・ボタン店・マスター展示館 — 無料、火〜日10:00〜18:00(月・祝日休館、訪問前の運営確認推奨)。
  • 路地の音が何を作っていたのか、ここで文脈がつながる。

③ フェオリギル (Hoeori-gil / 회오리길) → 崖の村 (Jeolbyeok-maeul / 절벽마을) 展望 (徒歩約15分)

  • 名前の通り、渦を巻くように旋回する急坂の路地。上っていくと突然視界が開け、切り立った崖の上に載った家々が現れる。
  • 📖 物語2 — 崖になった理由: この崖は自然にできたものではなく、日本統治時代の採石場の跡だ。ソウルの近代石造建築物を建てるために石を切り出した切土の上に、解放と戦争の後に行き場のなかった人々が家を建てた。崖の村は、その現代史の断面だ。
  • チャンシンドンは、ペク・ナムジュン (Baek Nam-june / 백남준) が幼少期を過ごした町でもある — 生家跡には、ペク・ナムジュン記念館 (Baek Nam-june Memorial Hall / 백남준기념관) がチャンシン1洞 (Changsin 1-dong / 창신1동) にある。

④ 崖の村 → ナクサン公園 (Naksan Park / 낙산공원) 城郭路への接続 → 締めくくり (徒歩約15分)

  • 上り坂の報酬がここにある — 漢陽都城 (Hanyangdoseong / 한양도성) の城郭の向こうにソウル市内が広がる。夕焼けの時間帯なら、このコース最高の場面だ。
  • 締めくくりの選択肢: 城郭路沿いにヘファ (Hyehwa / 혜화) ・テハンノ (Daehangno / 대학로) 方面へ下るか(#1254 チョンノ3街 (Jongno 3-ga / 종로3가) ハブ接続)、来た道を引き返して東大門総合市場商人食堂(#1328)で夕食。

🙏 路地マナー — このコースの必須装備

  • この路地の主役は働く人々と住民だ。工場内部・作業者・住宅の庭に向けた撮影は厳禁、風景と路地の表情だけを収めよう。
  • バイクの往来が多い — 路地の内側に寄って歩き、イヤホンは片耳だけに。
  • 声は低めに。特に崖の村区間は100%住宅地だ。

💡 戸惑いポイント

  • 日曜日は縫製路地の「働く音」が静まる — 路地の活気を見るなら平日が正解だ。
  • フェオリギル・崖の村区間は、地図アプリが階段・傾斜を全部教えてくれるわけではない — 時間に余裕を持ち、膝に不安があれば②までにとどめ、城郭はナクサン公園正門(ヘファ側)の迂回路から接続を。
  • カフェ・商店が少ない路地だ — 水は東大門駅のコンビニで事前に。
