跆拳道指南——外国人能看、能体验的地方：国技院（首尔）与跆拳道园（茂朱），2026官方信息

副标题：国技院位于江南站12号出口·驿三站4号出口，示范团定期演出仅有官方介绍，未公布日程与票价 / 跆拳道园（茂朱）10:00~18:00·周一休馆·入场免费·常设示范演出10,000韩元·体验4,000~10,000韩元——以2026-10-08国技院·跆拳道振兴财团官方页面为准。跆拳道未列入联合国教科文组织非物质文化遗产名录（2011年列入的是跆跟）

🎯 本指南使用方法

外国人想在韩国“看跆拳道、练跆拳道”，官方页面能确认的地方只有两处——首尔江南的 国技院 (Kukkiwon / 국기원)（世界跆拳道总部，示范团的大本营）和全北茂朱的 跆拳道园 (Taekwondowon / 태권도원)（跆拳道振兴财团运营，设有博物馆、常设示范演出和体验）。下面只写2026-10-08在这两家机构官方页面上读到的数值；像国技院演出日程、票价这类官方页面没有的内容，一律标为“未公布”。旧版指南中的“跆拳道2011年列入联合国教科文组织”并不属实——2011年列入的是跆跟 (Taekkyeon / 택견)，跆拳道不在联合国教科文组织非物质文化遗产名录中（在 ich.unesco.org 检索结果为0条）。“国技院全年无休”“从江南站步行10分钟”“体验5万~15万韩元”“KTX永同站”等说法也与官方不符，已删除。

🥋 国技院——在首尔能看到吗

  • 开院于1972年、示范团于1974-09-06成立等沿革中，官方页面上能读到的只有示范团成立日（1974-09-06）和“面向外国游客运营定期示范演出”这句介绍。演出的星期、时间、票价、预约方式官方页面上都没有——出发前请先致电 国技院 (Kukkiwon / 국기원)（02-567-1058）询问。
  • 建筑本身就在江南中心（德黑兰路7街32号）。出口为江南站12号·驿三站4号·新论岘站4·5号（官方，步行时间未公布）。
  • 办公时间为周一至周四 09:00~18:30、周五 09:00~16:00，周末·公休日休息——这并不是对游客的开放时间。

🏔 跆拳道园——去了肯定有的地方

  • 由 跆拳道振兴财团 (Taekwondo Jinheung Jaedan / 태권도진흥재단) 运营（官方网站 tpf.or.kr——旧版指南中的 tkdwon.kr 是不存在的网址）。10:00~18:00，09:30起售票，入场截止17:00，国立跆拳道博物馆 (Gungnip Taekwondo Bangmulgwan / 국립태권도박물관) 10:00~17:00。周一、1/1、春节·中秋当天及前一天休馆（官方）。
  • 入场·博物馆·停车免费。收费项目为常设示范演出10,000韩元、呀!体验中心4,000~10,000韩元、单轨列车往返4,000韩元（官方价目表）。首页写着“演出·体验含在门票内”，与价目表不一致——请以现场售票处为准。
  • 演出的星期、时间未核实（10/8查阅时显示“未运营”）。出发前请先看官方演出日历。
  • 住宿：跳跃馆 (Doyakgwan / 도약관)（可容纳1,031人）——房费未查阅。
  • 交通（官方）：首尔南部客运站 → 茂朱长途巴士每天5班，或乘KTX到大田后换乘巴士。当天往返很紧张，住1晚更现实。

🏅 事实梳理——奥运会·联合国教科文组织

  • 联合国教科文组织：跆拳道 (Taekwondo / 태권도) 不在人类非物质文化遗产名录中。2011年列入的是跆跟 (Taekkyeon / 택견)（6.COM 13.44）。旧版指南把两者混为一谈的句子已删除。
  • 奥运会：“2000年悉尼奥运会起成为正式项目”的说法流传很广，但这次未能打开世界跆拳道联盟官方页面，因此不加“官方确认”标签。

🚶 两条路线

  • 首尔半日：江南站12号出口 → 国技院（建筑·示范团演出须提前咨询）→ 江南其他行程。
  • 茂朱1晚：南部客运站乘巴士 → 跆拳道园（博物馆免费 → 常设示范 10,000韩元 → 呀!体验）→ 跳跃馆住宿 → 次日 德裕山 (Deogyusan / 덕유산)。

⚠ 常见错误5则

1. 相信“跆拳道列入联合国教科文组织”——名录中没有，列入的是跆跟。

2. 不打招呼就去国技院看演出——日程·票价未公布，请电话确认。

3. 周一去跆拳道园——休馆。

4. 搜索 tkdwon.kr——不存在的网站，应为 tpf.or.kr。

5. 把体验费按5万~15万韩元预算——官方公布的只有跆拳道园的4,000~10,000韩元。

⚙ FAQ 6则

1. 想确保能看到演出怎么办？——跆拳道园常设示范演出（10,000韩元）。星期请查官方日历。

2. 能从首尔当天往返吗？——可以参观国技院，但演出日程未公布。

3. 到茂朱要多久？——官方只给出方式（南部客运站巴士5班/KTX经大田），所需时间未公布。

4. 带孩子去？——跆拳道园呀!体验中心4,000~10,000韩元，儿童观看演出可享八折。

5. 跆拳道和跆跟有什么区别？——跆跟是朝鲜时代的传统武艺，2011年列入联合国教科文组织名录；跆拳道是20世纪体系化的现代武道。

6. 有外语导览吗？——两家机构官方页面均未标注外语导览，未核实。
