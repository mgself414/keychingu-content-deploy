🎯 なぜカンブク・スユ単独ガイドなのか

カンブク(Gangbuk / 강북)・スユ(Suyu / 수유)は江北区の韓国民主化・北漢山牛耳・伝統エリアが結合したarea — 4・19国立墓地(4.19 National Cemetery) — 1960年4・19革命の埋葬地、韓国民主化の聖地 — + 北漢山牛耳ゲート(Bukhansan Ui Gate / 북한산 우이 게이트) — 韓国No.1都心国立公園 — + スユ駅・ミアサゴリ(外国人があまり知らない地元エリア) + 牛耳・番洞が結合。韓国民主化deep dive+北漢山登山+地元エリアdeep diveに最適です。

ホンデ(MZ世代)・カンナム(ラグジュアリー)・イテウォン(グローバル)と比べると、カンブク・スユは民主化・自然・地元の色が強いエリアです。外国人観光客の動線ではカンナム・ホンデに隠れて素通りされがちですが、4・19墓地は韓国民主化の聖地(1960年4月革命の埋葬地) + 北漢山牛耳(#182 銀平・#177 蘆原とセット) = 外国人の韓国歴史・自然deep diveに最適です。ISSUE 03 ㉔回 — KeyChinGu初の江北区進出(クラスター66件)。

⚠ 外国人がよくする失敗3つ

1. 「カンブク=観光地ではない」— 韓国民主化の聖地としての価値を知らない

外国人はカンブクを「観光エリアではない」と認識しがちですが、4・19国立墓地は韓国民主化の聖地(1960年4月革命の埋葬地) — 韓国現代史のdeep diveに最適です。韓国の国立墓地・民主化deep dive先として(顕忠院以外の韓国民主化の聖地として)おすすめです。

2. 「北漢山=銀平・蘆原だけ」— 牛耳ゲートの価値を知らない

北漢山は銀平(#182)・蘆原(#177)以外に牛耳ゲート(江北区北東部) — 仁寿峰(Insubong / 인수봉)・白雲台(Baegundae / 백운대)への入山口No.1 + 牛耳川(Ucheon / 우이천)サイクリングロードがあります。江北区民・外国人の登山口No.1です。

3. 「スユ・ミアは外国人が知らない」

スユ・ミアは外国人がほとんど知らないhidden gem area — 韓国の地元・庶民エリアの人類学的deep dive先No.1 + 韓国正統の餅屋・韓菓・ベーカリーが豊富です(外国人にとって韓国正統デザートdeep dive)。

カンブク・スユの風景

カンブク・スユは江北区中部 — 4号線スユ駅・ミアサゴリ駅・ミア駅・番洞駅 + 牛耳新設線北漢山牛耳駅・サムヤンサゴリ駅・三陽駅・ソルバッ公園駅。韓国1960〜80年代の地元エリア+1960年4・19革命の埋葬地+北漢山牛耳ゲートが揃っています。

交通: 4号線スユ駅・ミアサゴリ駅・ミア駅・番洞駅 / 牛耳新設線北漢山牛耳駅・サムヤンサゴリ駅。カカオタクシー推奨。

⚙ FAQ(6件)

Q1. 4・19墓地は外国人でも入場できますか?

無料+06:00〜18:00——外国人も自由に入場できます。韓国民主化の聖地+英語案内あり。牛耳新設線4・19民主墓地駅徒歩5分。4月第2週に記念式があります。

Q2. 北漢山牛耳ゲートで登山できますか?

可能です——牛耳新設線北漢山牛耳駅徒歩10分。仁寿峰・白雲台への入山口No.1+牛耳川サイクリングロード。登山初心者向けの周遊路もOKです。

Q3. スユ・ミアは外国人にもフレンドリーですか?

大丈夫です——韓国の地元エリアですが、英語メニューのある店(コスプチプ・ララブレッドなど)+カード決済に対応。外国人の韓国日常deep diveに最適です。

Q4. ミアサゴリチョンノトック・ミンソルギはお土産に向いていますか?

OKです——韓国正統の餅・韓菓のギフトボックスがあります。外国人のお土産・記念品用No.1(#48韓国必須購入TOP20連携)。

Q5. カンブクと蘆原・銀平の連携は?

OKです——4号線・牛耳新設線で乗り換え可能。#177蘆原・道峰の登山+#182銀平・北漢山+カンブク・スユの4・19墓地=1日で楽しむ韓国自然・民主化フルセット。

Q6. 4・19墓地+北漢山の動線は?

4・19墓地(牛耳新設線)→北漢山牛耳駅(1駅)→北漢山牛耳ゲート登山→牛耳川サイクリング→スユ駅で夕食=1日フルコース。
