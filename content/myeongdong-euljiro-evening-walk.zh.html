明洞 (Myeongdong / 명동) → 乙支路 (Euljiro / 을지로) 傍晚徒步路线 — 两小时走遍首尔六种表情，以夜场 (yajang / 야장) 生啤收尾

副标题：19点从明洞站 (Myeongdong Station / 명동역) 出发 · 约4公里6个站点 — 购物(明洞) → 历史建筑(明洞大教堂 (Myeongdong Cathedral / 명동대성당)) → 工业遗产(印刷小巷 (Printing Alley / 인쇄골목)) → 近代建筑(世运商街 (Sewoon Sangga / 세운상가)) → 市中心河流(清溪川 (Cheonggyecheon / 청계천)) → 夜场小巷生啤收尾。白天玩转明洞请看明洞一日全攻略，乙支路全天路线请看乙支路环游一圈——这一篇是把两个街区连起来的傍晚两小时串联路线。

ISSUE 04 · #1309 · 2026-08-19

🎯 这条路线的概念 — 从"游客首尔"步行走进"夜晚首尔"

明洞和乙支路虽然只隔一站地铁，气质却完全相反。明洞是首尔外国游客密度最高的商圈，乙支路则是西方旅行者口中"authentic Seoul"（真实首尔）的现役工业小巷。这条路线的看点就是这种反差本身——两小时内画风切换六次。

项目 内容
出发 明洞站 (4号线) 6号出口，19:00
总距离/时间 约4公里 / 2小时 + 夜场自由活动时间
难度 平地步行——唯一的坡道是明洞大教堂的上坡路
费用 步行免费 + 夜场生啤 ₩4,000~5,000/杯 + 下酒菜 ₩10,000~20,000
最佳季节 春秋两季(夏天是夜场旺季，也是不错的选择)
为什么是19点 正好赶上明洞路边摊开摊(17点起)之后、乙支路霓虹灯亮起、以及21点前后夜场高峰

① 外国游客常犯的3个错误

1. 把整个晚上都花在明洞

明洞的晚间人流在这个时段达到顶峰，逛一小时就够了。在这条路线里，明洞只是出发商圈，真正的夜晚在乙支路。想深入体验明洞，留到白天去看明洞一日全攻略。

2. 在乙支路小巷里因为"没看到店"就转身走人

乙支路很多酒吧、餐厅没有招牌，或者藏在老印刷厂建筑里面。地图软件上明明显示有店，却找不到入口，这很正常——"找入口"本身就是乙支路体验的一半。

3. 把夜场理解成"有露天座位的餐厅"

夜场 (yajang / 야장) 是一种傍晚开始整条小巷摆满折叠桌的文化。座位先到先得，拼桌很自然，点单公式是生啤+干下酒菜。这里没有"预约"这个概念。

② 路线6个站点 (19:00 → 21:00+)

1. 明洞路 (Myeongdong-gil / 명동길) · K-beauty街 — 19:00~19:20

傍晚的明洞路上，路边摊(鸡肉串、糖饼、奶油虾 ₩2,000~12,000)把整条街变成了夜市。像OliveYoung明洞中央店 (Olive Young Myeongdong Central / 올리브영 명동중앙점) 这样的大型K-beauty门店营业到22点，所以购物环节只需要"先看好、记下来"就往前走——这不是一条适合拎着大包小包走的路线。

  • 留意：路边兑换点的汇率牌(比机场划算2~3%)·退税需要单张收据满₩30,000+。
  • 明洞饺子 (Myeongdong Kyoja / 명동교자) 总店门口的排队长龙本身就是一景——用餐不在这条路线内(详见明洞一日全攻略)。

2. 明洞大教堂 (Myeongdong Cathedral / 명동대성당) — 19:20~19:35

1898年建成的韩国第一座哥特式教堂，也是韩国天主教总本山。晚上外墙灯光亮起，拍出来比白天更好看。从山坡上往下看，哥特尖塔和明洞霓虹能同框入镜——只有这个时段才能拍到的画面。外部参观免费·全天24小时开放。

3. 乙支路印刷小巷 (Printing Alley / 인쇄골목) — 19:35~20:05 (含移动时间)

从明洞走到乙支路3街 (Euljiro 3-ga / 을지로3가)，城市的质感瞬间切换。1960~70年代的印刷厂、铁工厂至今仍在营业的小巷里，藏着直接沿用老厂房的酒吧和咖啡馆。19点这个时段是"变身时刻"——印刷厂卷帘门陆续拉下，霓虹灯陆续亮起。

  • 没有招牌的鸡尾酒吧(晚6点起营业)是这条小巷的招牌特色——Negroni价格约₩15,000~22,000。
  • ⚠ 礼仪提醒：这里还有仍在工作的匠人和居民。禁止未经允许拍照，边走边观察就好。
  • 想把乙支路玩一整天，请看乙支路环游一圈·以复古酒吧为主的路线请看乙支路复古文艺游。

4. 世运商街 (Sewoon Sangga / 세운상가) · 大林商街 (Daerim Sangga / 대림상가) — 20:05~20:25

1968年由建筑师金寿根 (Kim Swoo-geun / 김수근) 设计的韩国第一座住商混合巨型建筑。天桥把钟路 (Jongno / 종로) 到退溪路 (Toegyero / 퇴계로) 约1公里连成一体。看点是天桥上的乙支路夜景，加上楼顶眺望宗庙 (Jongmyo / 종묘)~南山 (Namsan / 남산) 轴线的视野(开放时间请现场确认)。如果你在找"brutalist Seoul"(粗野主义风格的首尔)，这里就是这条路线的高光时刻。

  • 注意天桥楼层的店铺结构——只逛一楼会错过一半的内容。

5. 清溪川 (Cheonggyecheon / 청계천) 世运桥 (Sewoon-gyo / 세운교) ~ 水标桥 (Supyogyo / 수표교) — 20:25~20:35

2005年复原的市中心河流。和光化门方向的观光段不同，这一段是下班本地人真正会走的生活区间。沿着灯光亮起的水边走10分钟，再折返回乙支路3街——是进夜场前歇口气的一段。

6. 乙支路老街烤鱼干胡同 (Nogari-golmok / 노가리골목) 夜场 — 20:35~，收尾 🍺

乙支路3街的生啤小巷。1980年从"生啤+노가리 (nogari / 노가리) ₩100"起步，如今整条小巷都变成露天酒馆，成了首尔夜场文化的圣地(被列为首尔未来遗产 (Seoul Future Heritage / 서울미래유산))。21点前后是高峰——正好赶上上班族公司聚餐 (hoesik / 회식，类似中国的团建文化) 和游客混在一起、最具乙支路气质的一幕。

  • 点单公式：生啤 + 노가리 (nogari，干烤明太鱼干配辣椒酱蛋黄酱) + 拌海螺肉。
  • 座位先到先得·大多数店可以刷卡，但部分老字号 (nopo / 노포) 更喜欢收现金。
  • 夜宵地图对比(乙支路 vs 钟路 vs 江南)请看夜宵地图对比。

③ 变体路线

情况 变体
有3小时时间 在第4站之后加入广藏市场 (Gwangjang Market / 광장시장) 夜市(步行10分钟)，再回到夜场
同行的人不想走路 跳过第3~4站，明洞→乙支路3街坐一站地铁→直接去第5~6站
不喝酒 收尾不去夜场，改成延长清溪川夜间散步，或者去乙支路的深夜咖啡馆
还想看夜景 路线结束后往南山方向走——请看南山+明洞夜景之旅·夜景全攻略

④ 实用小贴士

  • 洗手间：最保险的是用明洞站、乙支路3街站的站内设施。夜场小巷内可以用生啤店内部的洗手间。
  • 支付：部分路边摊只收现金——身上带一张₩10,000纸币就够覆盖整条路线的现金需求。
  • 下雨天：印刷小巷、夜场的魅力都会打对折——雨天建议换成室内路线，比如明洞一日全攻略。
  • 一个人也可以吗：夜场里独自一人的客人很常见。如果觉得拼桌文化有压力，比起入口处的大店，小巷深处的小店会更自在。
