⚠ 3 Common Mistakes Foreigners Make

1. "Dado (다도) = too formal": Korean Dado (다도) (tea ceremony) = foreigner enthusiast entry-level matrix #1 + many English explanations OK. Insa (인사), Bukchon (북촌), Jeonju (전주) = Dado (다도) etiquette guide (English) + Hanbok (한복) experience cross. Foreigner enthusiasts = 30 minutes to 1 hour entry-level fit.

2. "Hanok (한옥) experience = too expensive": Hanok (한옥) experience = ₩20,000-₩50,000 (~$15-37 / ~100-250 RMB / ~2,000-5,000 JPY) per person matrix (Dado (다도) 30 minutes to 1 hour) / Hanbok (한복) rental for one day: ₩10,000-₩30,000 (~$7-22 / ~50-150 RMB / ~1,000-3,000 JPY) matrix / Gongbang (공방) (workshop) for 1-2 hours: ₩30,000-₩60,000 (~$22-45 / ~150-300 RMB / ~3,000-6,000 JPY) matrix. Foreigner enthusiasts = Klook, Trazy English booking + card payment OK.

3. "Hanok (한옥) experience = Korean only": All 6 Hanok (한옥) experiences = English guide/explanation matrix #1. Klook, Trazy = English booking + English guide option OK. Insa (인사), Bukchon (북촌), Jeonju (전주) = foreigner enthusiast fit.

⚙ 4 FAQs

1. Best Itinerary for Foreigner Hanok (한옥) Experience: Day 1: Bukchon (북촌) (1·3) → Insa (인사) (2) → Ikseon (익선) Hanok (한옥) golmok (골목) (alley) + Night Hanok (한옥) Dado (다도) ([#1074 Night Hanok Cafe & Dado](1074_night_hanok_cafe_dado.md)). Day 2: Seochon (서촌) (4) → Gyeongbokgung (경복궁) · Changdeokgung (창덕궁). Day 3-4: Jeonju (전주) (5) or Gyeongju (경주) (6) for a 1-night, 2-day trip.

2. Dado (다도) Etiquette (Foreigner's Perspective): (a) Dado (다도) = Korean traditional tea ceremony + how to use Dado (다도) tools (tangwan (탕관 - kettle), chaho (차호 - tea container), chatjan (찻잔 - teacup)) + English explanation OK (b) Jwasik (좌식) (floor seating) = sitting cross-legged (yangban-dari (양반다리)) or with legs extended is OK + take off shoes (c) First cup = Dado (다도) master pours → foreigner enthusiast receives with etiquette (d) Tea types = green tea, oolong tea, black tea, fermented tea, blending tea matrix + English explanation.

3. Hanbok (한복) Experience Etiquette: (a) Hanbok (한복) rental = ₩10,000-₩30,000 per day matrix (b) Sizes = foreigner enthusiast matrix (free size · plus size matrix) (c) Hanbok (한복) + Hanok (한옥) photogenic = foreigner enthusiast fit (d) Hanbok (한복) + Dado (다도) cross = matrix #1.

4. Best Season for Foreigner Hanok (한옥) Experience: Possible all four seasons. Spring flowers (April: Jeonju (전주) · Gyeongju (경주)) / Summer (June-August: Hanok (한옥) courtyard + Dado (다도) cross) / Autumn foliage (October: Bukchon (북촌) · Jeonju (전주) · Gyeongju (경주) · Ikseon (익선)) / Winter Ondol (온돌) (traditional Korean underfloor heating system) + Dado (다도) (December-February: #1 enthusiast matrix). Foreigner enthusiasts = Spring · Autumn best.
