韩国“首次·最高”景点指南 — 庆州瞻星台·广藏市场·荣州绍修书院的“第一”，益山弥勒寺址石塔·三陟幻仙窟·雪岳山土旺城瀑布的“最大·最长”，济州马罗岛·蔚山艮绝岬·江陵正东津站的“终点与起点”等共20处

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“韩国的最初&最高”主题入选的地方中，韩国观光公社介绍文里写有“最早·最大·最”等纪录的20处 · 纪录以观光公社介绍文为准 · 登记了门票的地方有顺天湾国家庭园(成人 10,000韩元)·幻仙窟(成人 4,500韩元)·万丈窟(成人 4,000韩元)·华城行宫·绍修书院(成人 2,000韩元) · 万丈窟每月第一个周三休息，幻仙窟每月18日休息，Space Walk每月第一个周一、顺天湾国家庭园每月最后一个周一休息 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“韩国的最初&最高”主题入选的地方中，韩国观光公社旅游信息的介绍文里直接写有“最早·最大·最”等纪录的20处。表中的排名和得票数就是这次投票的结果。

“首次”或“最高”这类纪录，不同出处往往说法不同。所以没有照录投票推荐理由，只照录了观光公社介绍文里写明的纪录，正文中加了“据韩国观光公社介绍”。候选地是在投票排名60名上下的地方中，查看了有观光公社信息编号的地方的介绍文后挑选的，并没有逐一核对全部100处。石窟庵 (Seokguram / 석굴암)·国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)·汉拿山 (Hallasan / 한라산)·宗庙 (Jongmyo / 종묘)等得票很高的地方，因为介绍文里没有“最早·最大·最”等纪录，所以没有收入(景福宫 (Gyeongbokgung / 경복궁)介绍文里的“朝鲜王朝第一法宫”是等级表述而不是纪录，同样的理由也没有收入)。投票名称·地址与观光公社登记不同的地方(益山弥勒寺址石塔·江陵正东津站高速铁路等)，以观光公社的写法为准。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值，没有登记值的栏写作“无登记值”。

📍 “第一”的地方 — 瞻星台·绍修书院·广藏市场·松岛海水浴场·殿洞圣堂·华城行宫·顺天湾国家庭园

庆州瞻星台 (Gyeongju Cheomseongdae / 경주 첨성대)的地址是庆州市 (Cheomseong-ro 140-25 / 첨성로 140-25)，☎ Singyeongju站游客咨询处 (Singyeongju-yeok Gwanggwang Annaeso / 신경주역 관광안내소) 054-771-1336。这是推测在新罗善德女王 (Seondeok Yeowang / 선덕여왕)(在位632~647)时期建造的天文观测台。据韩国观光公社介绍，该介绍引用了国家遗产厅 (Gukga Yusan-cheong / 국가유산청)的资料，这里被认为是东方最古老的天文台。高约9米，用扇形石块垒了27层。

  • 开放时间:夏季 09:00~22:00，冬季 09:00~21:00。休息日:全年无休。费用:免费。

荣州绍修书院 (Yeongju Sosuseowon / 영주 소수서원)的地址是荣州市Sunheung面 (Sobaek-ro 2740 / 소백로 2740)，☎ 054-639-5852。1542年，Punggi郡守 (Punggi Gunsu / 풍기군수)周世鹏 (Ju Se-bung / 주세붕)建起了祭祀安珦 (An Hyang / 안향)的祠堂，这是书院的开端。1550年应李滉 (Yi Hwang / 이황)的请求，获赐“绍修书院”之名。据韩国观光公社介绍，建筑布局自由，是因为这里是在书院形式确立之前建成的韩国最早的初期书院。

  • 开放时间:11~2月 09:00~17:00，3~5·9~10月 09:00~18:00，6~8月 09:00~19:00。入场到参观结束前1小时为止。
  • 休息日:全年无休。费用(个人):成人 2,000韩元，青少年·军人 1,330韩元，儿童 660韩元。

广藏市场 (Gwangjang Sijang / 광장시장)的地址是Jongno区 (Changgyeonggung-ro 88 / 창경궁로 88)，☎ 02-2267-0291。据韩国观光公社介绍，这是1905年开业的韩国最早的常设市场。现在是经营韩服面料·织物·服装·小吃的综合市场，据韩国观光公社介绍，东门 (Dongmun / 동문)·北2门 (Buk 2-mun / 북2문)·南1门 (Nam 1-mun / 남1문)交汇处的小吃摊区是市场里最热闹的地方。

  • 开放时间·休息日:登记为因店铺而异。

釜山松岛海水浴场 (Busan Songdo Haesuyokjang / 부산 송도해수욕장)的地址是釜山Seo区 (Songdohaebyeon-ro 100 / 송도해변로 100)，☎ 051-240-4000。据韩国观光公社介绍，这是1913年釜山最早开放的海水浴场。与海岸生态公园Amnam公园 (Amnam Gongwon / 암남공원)相连。

  • 开放时间:06:00~23:00。休息日:全年无休。费用:免费。

全州殿洞圣堂 (Jeonju Jeondong Seongdang / 전주 전동성당)的地址是全州市Wansan区 (Taejo-ro 51 / 태조로 51)，☎ 063-284-3222。这座圣堂于1914年在朝鲜时代天主教殉教地上建成。据韩国观光公社介绍，这是湖南地区最早建成的罗马式建筑，有拜占庭式钟塔。

  • 开放时间:09:00~17:00。休息日:全年无休。

水原华城行宫 (Suwon Hwaseong Haenggung / 수원 화성행궁)的地址是水原市Paldal区 (Jeongjo-ro 825 / 정조로 825)，☎ 售票处 031-5191-4677。这是正祖 (Jeongjo / 정조)前往Hyeollyungwon园寝 (Hyeollyungwon / 현륭원)时停留的行宫。据韩国观光公社介绍，华城不仅被列入世界遗产，还被评价为韩国最早的新城开发案例。

  • 开放时间:3~10月 09:00~18:00，11~2月 09:00~17:00。休息日:全年无休。
  • 费用(个人):成人 2,000韩元，青少年·军人 1,500韩元，小学生 1,000韩元。

顺天湾国家庭园 (Suncheonman Gungga Jeongwon / 순천만국가정원)的地址是顺天市 (Gungganjeongwon 1-ho-gil 47 / 국가정원1호길 47)，☎ 061-749-3114。据韩国观光公社介绍，这是大韩民国第1号国家庭园。2013年举办顺天湾国际庭园博览会 (Suncheonman Gukje Jeongwon Bangnamhoe / 순천만국제정원박람회)时建成，926,992平方米的园区内有世界各国的传统庭园和主题庭园。

  • 开放时间:10~6月 09:00~20:00，7~9月 09:00~21:00(两个时期入场截止均为 19:00)。休息日:每月最后一个周一。
  • 费用(个人):成人 10,000韩元，青少年·军人 7,000韩元，儿童 5,000韩元。17:00以后的夜间票成人 5,000韩元。

📍 “最大·最长”的地方 — 全州韩屋村·弥勒寺址·高敞支石墓·幻仙窟·土旺城瀑布·龙门寺银杏树·发旺山缆车

全州韩屋村 (Jeonju Hanokmaeul / 전주 한옥마을)的地址是全州市Wansan区 (Girin-daero 99 / 기린대로 99)，☎ 063-282-1330。据韩国观光公社介绍，这里聚集了700多栋韩屋，是国内规模最大的传统韩屋村，也是全国唯一的城区韩屋群。从1910年开始形成，有Gyeonggijeon殿 (Gyeonggijeon / 경기전)·Omokdae台 (Omokdae / 오목대)·乡校 (Hyanggyo / 향교)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:基本30分钟 1,200韩元，每增加15分钟 600韩元。

益山弥勒寺址 (Iksan Mireuksaji / 익산 미륵사지)的地址是益山市Geumma面 (Mireuksaji-ro 362 / 미륵사지로 362)，☎ 弥勒寺址游客咨询处 063-859-3873。这是百济武王 (Muwang / 무왕)时期建造的寺院遗址，是联合国教科文组织世界遗产。据韩国观光公社介绍，国宝弥勒寺址石塔现高14.24米，是韩国最古老、最大的石塔。这里的“最古老”是指建造年代最早(投票推荐理由中写作“最古”)。介绍文给出的理由是，它用石头忠实再现了此前木塔的样式。东塔于1993年复原为9层(高27.67米)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

高敞支石墓遗址 (Gochang Goindol Yujeok / 고창 고인돌 유적)的地址是高敞郡Gochang邑 (Goindolgongwon-gil 74 / 고인돌공원길 74)，☎ 支石墓博物馆 (Goindol Bangmulgwan / 고인돌박물관) 063-560-8666。2000年被列入联合国教科文组织世界遗产。据韩国观光公社介绍，就单一区域而言，这里是韩国最大的支石墓群，高敞郡有支石墓1,748座(以2023年调查为准。投票推荐理由中写的是447座)。探访路线1~5号线为1.8公里，6号线为1.7公里。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

三陟幻仙窟 (Samcheok Hwanseongul / 삼척 환선굴)的地址是三陟市Singi面 (Hwanseon-ro 800 / 환선로 800)，☎ 1533-8362。据韩国观光公社介绍，这是韩国规模最大的石灰岩洞穴，形成于约5亿3千万年前。洞内发现了47种动物。有单轨列车通到入口。

  • 开放时间:3~10月 09:00~17:00，11~2月 09:00~16:00。休息日:每月18日(遇休息日·连休则顺延至下一个工作日)。
  • 费用(个人):成人 4,500韩元，敬老·青少年 3,000韩元，儿童·军人 2,000韩元。单轨列车13岁以上往返 7,000韩元。

雪岳山土旺城瀑布 (Seoraksan Towangseong Pokpo / 설악산 토왕성폭포)的地址是Sokcho市 (Seorak-dong / 설악동)，☎ 033-801-0900。瀑布上段150米·中段80米·下段90米，总长320米，共3段。据韩国观光公社介绍，这是国内最长的连瀑，冬季还被认为是国内最大的冰瀑。2015年延长Biryong瀑布 (Biryong Pokpo / 비룡폭포)探访路，开放到了观景台，观景台距瀑布超过1公里。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

杨平龙门寺银杏树 (Yangpyeong Yongmunsa Eunhaengnamu / 양평 용문사 은행나무)的地址是杨平郡Yongmun面 (Yongmunsan-ro 782 / 용문산로 782)，☎ 031-773-0088。这是树龄推测约1,100岁的天然纪念物。高42.0米，胸高周长11.0米，据韩国观光公社介绍，它拥有韩国银杏树中树龄和高度都最高的纪录。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:小型车 3,000韩元。

发旺山观光缆车 (Balwangsan Gwangwang Keibeolka / 발왕산 관광케이블카)的地址是平昌郡Daegwallyeong面 (Ollimpik-ro 715 Dragon Plaza 2F / 올림픽로 715 드래곤프라자 2층)。这是连着100个8人座车厢、往返7.4公里的缆车。据韩国观光公社介绍，它是国内最大长度(这个数值是往返标准，投票推荐理由中写的是3.7公里)。到海拔1,458米的发旺山山顶需要18分钟。遇强风等恶劣天气会停运。

  • 开放时间·休息日·费用:无登记值。

📍 “终点与起点” — 艮绝岬·马罗岛·正东津站

蔚山艮绝岬 (Ulsan Ganjeolgot / 울산 간절곶)的地址是Ulju郡Seosaeng面 (Ganjeolgot 1-gil 39-2 / 간절곶1길 39-2)，☎ 052-204-1751~6。据韩国观光公社介绍，这里是朝鲜半岛最早迎来日出的地方，比浦项Homigot岬 (Pohang Homigot / 포항 호미곶)早约1分钟，比江陵正东津 (Gangneung Jeongdongjin / 강릉 정동진)早约5分钟日出。据韩国观光公社介绍，这里还有世界最大尺寸的心愿邮筒，投入明信片后会真的寄出。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

济州马罗岛 (Jeju Marado / 제주 마라도)的地址是Seogwipo市Daejeong邑 (Mara-ro 101beon-gil 46 / 마라로101번길 46)，☎ 064-760-4014。据韩国观光公社介绍，这里是韩国最南端的岛屿。从Unjin港 (Unjin-hang / 운진항)坐船约30分钟，岛的南端有最南端碑 (Choenamdanbi / 최남단비)。绕岛一圈需要1~2小时。

  • 开放时间:全天开放(船运行时间请另行确认)。休息日:全年无休。费用:免费(船费另计)。

江陵正东津站 (Gangneung Jeongdongjin-yeok / 강릉 정동진역)的地址是江陵市Gangdong面 (Jeongdongyeok-gil 17 / 정동역길 17)，☎ 沙漏观光咨询中心 (Moraesigye Gwanggwang Annae Center / 모래시계관광안내센터) 033-640-4536。据韩国观光公社介绍，这里是全国离海最近的车站。因位于景福宫Gwanghwamun门 (Gwanghwamun / 광화문)的正东方向而得名，1995年因电视剧《沙漏 (Moraesigye / 모래시계)》成为日出名胜。

  • 开放时间:登记为因线路而异。休息日:全年无休。

📍 “世界”纪录 — 万丈窟·牛浦沼泽·Space Walk

济州万丈窟 (Jeju Manjanggul / 제주 만장굴)的地址是济州市Gujwa邑 (Manjanggul-gil 182 / 만장굴길 182)，☎ 064-710-7903。这是全长约7,400米的熔岩洞穴，是济州世界自然遗产的一部分。普通游客从第2入口进入，只能看到1公里。据韩国观光公社介绍，开放区间尽头高约7.6米的熔岩石柱被认为是世界上规模最大的。

  • 开放时间:09:00~18:00(入场截止 17:00)。休息日:每月第一个周三。
  • 费用(个人):成人 4,000韩元，青少年·儿童·军人 2,000韩元。

昌宁牛浦沼泽 (Changnyeong Upo-neup / 창녕 우포늪)的地址是昌宁郡Yueo面 (Upo-neup-gil 220 / 우포늪길 220)，☎ 055-530-2121。这是面积2,505千平方米的沼泽湿地。据韩国观光公社介绍，2018年10月25日在《拉姆萨尔公约》第13届缔约方大会上，在世界上首次被认证为拉姆萨尔湿地城市。介绍中写有，沼泽开始形成是在1亿4,000万年前。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

浦项Hwanho公园 (Pohang Hwanho Gongwon / 포항 환호공원) Space Walk的地址是浦项市Buk区 (Hwanho Gongwon-gil 30 / 환호공원길 30)，☎ 054-270-5176。这是轨道长333米、有717级台阶的参与式作品。据韩国观光公社介绍，它曾入选世界最美的19个台阶。遇雨或强风会管制出入。

  • 开放时间:4~10月 工作日 10:00~20:00·周末 10:00~21:00，11~3月 工作日 10:00~17:00·周末 10:00~18:00。
  • 休息日:每月第一个周一(遇法定节假日则顺延至次日)，天气恶劣·检修时也休息。费用:免费。

⚠ 需提前了解的3点

  1. 纪录以观光公社介绍为准 — “最早·最大·最”照录的是观光公社介绍文里的表述，其他资料可能有不同的说法。
  2. 有些地方休息日比较特别 — 万丈窟每月第一个周三、幻仙窟每月18日、Space Walk每月第一个周一、顺天湾国家庭园每月最后一个周一休息。
  3. 有些地方会因天气关闭 — 发旺山缆车和Space Walk遇强风等恶劣天气不运营，去马罗岛需另行确认船运行时间。

⚙ FAQ 3

问:在首尔能看到哪些地方?

答:首尔有广藏市场 (Gwangjang Sijang / 광장시장)。据韩国观光公社介绍，这是1905年开业的韩国最早的常设市场。首都圈还有Gyeonggi水原华城行宫 (Suwon Hwaseong Haenggung / 수원 화성행궁)和杨平龙门寺银杏树 (Yangpyeong Yongmunsa Eunhaengnamu / 양평 용문사 은행나무)。

问:哪些地方要花钱?

答:登记了门票的是顺天湾国家庭园 (Suncheonman Gungga Jeongwon / 순천만국가정원)(成人 10,000韩元)、幻仙窟 (Hwanseongul / 환선굴)(成人 4,500韩元)、万丈窟 (Manjanggul / 만장굴)(成人 4,000韩元)、华城行宫 (Hwaseong Haenggung / 화성행궁)(成人 2,000韩元)、绍修书院 (Sosuseowon / 소수서원)(成人 2,000韩元)。马罗岛的岛本身免费，但船费另计，发旺山观光缆车 (Balwangsan Gwangwang Keibeolka / 발왕산 관광케이블카)没有费用登记值，需另行确认。

问:以日出闻名的地方有哪些?

答:艮绝岬 (Ganjeolgot / 간절곶)和正东津站 (Jeongdongjin-yeok / 정동진역)。据韩国观光公社介绍，艮绝岬是朝鲜半岛最早迎来日出的地方，比正东津早约5分钟日出。
