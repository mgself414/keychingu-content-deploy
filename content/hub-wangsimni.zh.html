为何选往十里枢纽 — 4条线路交汇的城东门户

往十里站 (Wangsimni Station / 왕십리역) 是 2号线·5号线·京义中央线·水仁盆唐线 全部交汇的 四线换乘站。作为首尔东部的门户,从一个站向4个方向延伸出去。而且往十里本身就是坐拥牛肠街 (Gopchang Alley / 곱창골목)·马场畜产市场 (Majang Livestock Market / 마장동 축산시장) 的美食圣地。是一个可以在一个站内规划"在哪吃什么、往哪换乘"的旅行据点。

本指南是与各线路系列(#1241~#1249)正交的新轴。如果说各线路篇是"沿一条线路纵向"介绍,那么本篇则是 "从往十里一个站向4个方向放射" — 以据点为中心,串联起坐哪条线路会遇到什么。这是地铁路线系列(Phase 2)的第一篇。

往十里枢纽 4方向策展 — 在这里换乘的话

🔵 方向 1. 2号线 — 圣水·建大 (Konkuk Univ. / 건대)(MZ·潮)

  • 🚇 方向: 圣水(1站)·纛岛 (Ttukseom / 뚝섬)·建大入口 (Konkuk Univ. Station / 건대입구)(3站)
  • 🍜 吃: 圣水(圣水多乐 (Seongsudarak / 성수다락)·梅普尔塔 (Meipeultap / 메이플탑)·塞迪奇 (Sedichi / 세디치)) · 建大(张美术商 (Jangmisulsang / 장미술상)·优比 (Yobi / 요비)·道乌特 (Douteo / 도우터))
  • 👀 玩: 圣水洞 (Seongsu-dong / 성수동)(#1235·#1236 快闪店·咖啡街·练武场路 (Yeonmujang-gil / 연무장길)) · 首尔林(纛岛站·#1235) · 建大 Common Ground (Common Ground / 커먼그라운드)(#1241)
  • 耗时: 圣水 3分钟·建大 8分钟
  • cross-ref: #1241 2号线 · #1235 安静的首尔(圣水)

🟣 方向 2. 5号线 — 马场洞 (Majang-dong / 마장동)·踏十里 (Dapsimni / 답십리)(美食·本地)

  • 🚇 方向: 马场 (Majang / 마장)(1站)·踏十里
  • 🍜 吃: 马场畜产市场(韩牛·牛肉圣地·马场黄牛牛肠 (Majang Hwangso Gopchang / 마장황소곱창)) · 与往十里牛肠联动
  • 👀 玩: 马场畜产市场(韩国最大的畜产市场·鲜肉餐厅) · 踏十里古美术商街 (Gomisul Sangga / 고미술상가)·汽车配件街 (Jadongcha Bupum Geori / 자동차부품거리)
  • 耗时: 马场 2分钟
  • 外国人 tip: 马场洞是肉类批发圣地 — 在鲜肉餐厅以市价品尝新鲜牛肉。本地美食达人。

🚈 方向 3. 京义中央线 — 汉江·博物馆(江边)

  • 👀 玩: 鹰峰山 (Eungbongsan / 응봉산)(#1248 春季连翘·汉江夜景) · 玉水迎月峰 (Oksu Dalmajibong / 옥수 달맞이봉)(#1248 日落) · 国立中央博物馆 (National Museum of Korea / 국립중앙박물관)(二村·#1240) · 龙山 I'Park商城 (I'Park Mall / 아이파크몰)
  • 耗时: 鹰峰 3分钟·二村 10分钟
  • cross-ref: #1248 京义中央(江边线) · #1240 国立中央博物馆

往十里枢纽放射状一日路线 3

路线 1. MZ·潮 (2号线方向)

  • 往十里(牛肠午餐) → 2号线 圣水(#1236 快闪店·咖啡) → 纛岛 首尔林(散步) → 返回往十里
  • fit: 圣水潮·首尔林散步。年轻的旅行。

路线 2. 汉江·文化 (京义中央方向)

  • 往十里 → 京义中央 二村(国立中央博物馆·免费) → 鹰峰山(#1248 汉江夜景) → 往十里晚餐
  • fit: 博物馆·汉江·夜景。文化·江边。

路线 3. 美食·本地 (5号线方向)

  • 往十里牛肠街 → 5号线 马场畜产市场(鲜肉餐厅 韩牛) → 踏十里古美术商街
  • fit: 肉类圣地·本地美食。美食达人。

换乘·使用贴士 5 — 往十里枢纽 200% 活用

Tip 1. 把往十里当作'放射状据点'来用

以往十里为基准安排住宿·行程的话,2号线(圣水)·5号线(马场)·京义中央(汉江)·盆唐线(首尔林·江南) 4个方向就从一个站打开。

Tip 2. 换乘步行较长

4条线路按深度分布,换乘步行 5~8分钟。请预留充裕时间。可在民资站舍(易买得·CGV)候车顺便购物。

Tip 3. 首尔林哪个方向都能到

首尔林可从2号线(纛岛步行)·盆唐线(首尔林站 1站) 两侧到达。是离往十里最近的大型公园(#1235)。

Tip 4. 马场洞是美食达人必去

马场畜产市场(5号线 1站)是韩国最大的畜产市场。在鲜肉餐厅以市价品尝新鲜韩牛 — 与往十里牛肠构成美食带。

Tip 5. 一张交通卡搞定

用一张 T-money 就能换乘全部4条线路。从往十里到市区任何地方一次直达。

FAQ 6 — 外国人常问的往十里枢纽问题

Q1. 往十里枢纽的优势是什么?

  • 2·5·京义中央·水仁盆唐 四线换乘。从一个站通往圣水(2)·马场(5)·汉江(京义中央)·首尔林/江南(盆唐) 4个方向。放射状据点。

Q2. 与各线路篇(#1241~#1249)有什么不同?

  • 各线路篇是"一条线路纵向",本篇是 "从一个站向多条线路放射" = 正交。以往十里为轴串联4个方向。

Q3. 最近的景点是?

  • 首尔林(2号线 纛岛/盆唐 首尔林 1站)·圣水快闪店(2号线 1站)·鹰峰山夜景(京义中央 1站)·马场畜产市场(5号线 1站)。

Q4. 在往十里吃什么?

  • 往十里牛肠街 + 马场畜产市场(韩牛圣地·5号线 1站)。民资站舍(易买得·Entersix) 餐饮街。

Q5. 美食店信息准确吗?

  • 基于 naver 地图爬取,仅供参考。到访前务必用地图App再次确认。

Q6. 换乘会不会很复杂?

  • 4条线路按深度分布,换乘步行 5~8分钟。跟着指示牌走即可,还能在民资站舍候车顺便购物。
