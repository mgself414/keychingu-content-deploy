🎯 왜 "Seoul Family" 메타인가

방한 외국인 일행 형태 분석에서 가족 동반 비중 35%+ (8 segment 평균). 자녀 동반은 특히 동남아 무슬림(15박+ 장기) + 중국 단체·가족(4박 4인 평균) + 미국 Korean American (1·2·3세 가족 모임) + 일본 가족(1박 2박) 풀체험 동기. 그러나 키친구 콘텐츠는 매니아·일반 동선 위주 — 가족·자녀 동반 친화 풀 메타 가이드 부재.

본 가이드는 자녀 동반·가족 4축 12 시그니처 + 1주 풀패키지. 일행 형태별 메타 시리즈 1편 — #340 Family / #341 Couple / #342 Solo / #343 Budget / #344 Luxury.

⚠ 가족·자녀 동반 실수 3가지

1. "한국=어른 동선만" — 자녀 친화 인프라 미인지: 호텔·식당 어른 위주만 인식. 실제로는 롯데월드(9~22h 종일)·에버랜드(9~22h 사파리)·N서울타워(케이블카) 가족 패키지 + 어린이대공원·서울숲 무료 + 어린이박물관 + 유모차 대여·키즈존 식당 다수. 영문·중문·일문 가이드 우수.

2. "미슐랭·고급 다이닝=가족 불친화" — 가족 매니아 미슐랭 미인지: 미슐랭=어른 동선만 인식. 실제로는 신라호텔·롯데시그니엘·포시즌스 가족 패키지 + 한정식 4~6인 예약 + 자녀 키즈 메뉴 제공 매장 다수. 1박 럭셔리 호텔 + 가족 한정식 풀체험 가능.

3. "가족=동선 1개" — 부모·자녀 동기 매칭 미활용: 어른 매니아 동선(미슐랭·고급 쇼핑) ↔ 자녀 매니아 동선(테마파크·동물원·길거리음식) 분리 인식. 실제로는 부모 1일 + 자녀 1일 분리 + 묶음 1일 = 3일 매트릭스 가능. 잠실(롯데월드 + 시그니엘 + 한강) cluster가 가족 시그니처.

Seoul Family 풍경

서울은 글로벌 도시 가족 친화도 Top 5권 — 안전 #1 + 24h 편의점 + 무료 박물관·동물원·공원 + 영문 가이드 + 키즈존·유모차 대여. 가족 1주 풀패키지 가능.

테마파크·랜드마크: 롯데월드(잠실, 도심 #1) + 에버랜드(용인, 한국 #1, T 익스프레스·사파리) + 서울랜드(과천) + N서울타워 + 롯데월드타워 SkyDeck(555m). 가족 1박2일 잠실 패키지 시그니처.

동물원·자연: 어린이대공원(광진, 무료, 한국 #1 도심 동물원) + 서울숲 사슴공원(116ha 무료) + 서울대공원·과천 동물원 + 한강공원 11권역.

박물관·교육: 국립중앙박물관(용산, 무료, 한국 #1 + 어린이박물관) + 국립과학관(중구) + 국립한글박물관(용산) + 삼성 어린이박물관·한국 호암미술관. 모두 무료 또는 저렴.

한복·전통·체험: 북촌 한복 + 경복궁 + 광장시장 + 한복 사진관. 가족 동시 체험.

한강 야외: 여의도·뚝섬·반포·잠실 한강 가족 자전거 + 돗자리 + 치킨 배달 + 매직카펫 분수쇼. 봄·가을·여름 야외 시그니처.

가족 쇼핑·재미: 명동 라인프렌즈 BT21 + 홍대 BT21 + 라인프렌즈 명동 + K-pop 굿즈 + 길거리음식.
