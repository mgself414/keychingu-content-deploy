韩国酱菜 (jangajji / 장아찌) 6种全指南 — 从黄瓜、萝卜、辣椒到大蒜、紫苏叶、蜂斗菜的发酵小菜完整攻略

🎯 为什么要看这份韩国酱菜全指南

外国游客对韩国酱菜最大的认知痛点："我以为泡菜 (kimchi / 김치) 是韩国唯一的发酵食品。" 实际上酱菜是韩定食小菜的头号主角 + 家常菜必备 + 发酵爱好者的心头好。英文里都统称"Korean pickle"，但黄瓜酱菜 (Oi-jangajji / 오이장아찌，夏季招牌)、萝卜酱菜·黄萝卜 (Mu-jangajji·Danmuji / 무장아찌·단무지，韩国版的日式黄萝卜)、辣椒酱菜 (Gochu-jangajji / 고추장아찌，辛辣、老字号 (nopo / 노포，经营30年以上的传统老店) 常客最爱)、大蒜酱菜 (Maneul-jangajji / 마늘장아찌，腌足整整一年)、紫苏叶酱菜 (Kkaennip-jangajji / 깻잎장아찌，韩定食经典款)、蜂斗菜酱菜 (Meowi-jangajji / 머위장아찌，仅春季限定的老字号招牌) 各自使用不同食材、时令与粉丝群体。多数外国游客不知道：(a) 泡菜和酱菜是不同的食物；(b) 韩定食小菜可以无限免费续加；(c) 有些酱菜要腌足整整一年；(d) 韩国的黄萝卜和日本的沢庵渍不是同一种腌菜。本篇整理6种全指南、韩定食小菜知识，以及新手入门优先顺序。

🥒 6种深度解析

🥒 黄瓜酱菜 (Oi-jangajji / 오이장아찌) — 入门首选

  • 招牌特点：夏季头号·家常菜·小菜 (banchan / 반찬，韩式免费配菜) + 韩定食
  • 食材：黄瓜 + 酱油·糖·醋·大蒜
  • 外国游客亲和度：★★★★★(入门首选，黄瓜全球熟悉)
  • 腌制时间：1~7天(快速腌制)
  • 推荐去处：
  • 韩定食餐厅 (#837) — 头号小菜
  • 家常便饭 (gajeongsik baekban / 가정식 백반，韩式家常套餐) 餐厅 (#854) — 高性价比
  • MZ (MZ，韩国的年轻潮流世代) 咖啡厅聚集区
  • 价格：韩定食小菜内含 / 超市1袋 = 3,000~6,000韩元(约16~32元人民币)

🥕 萝卜酱菜·黄萝卜 (Mu-jangajji·Danmuji / 무장아찌·단무지) — 全球知名度第一

  • 招牌特点：四季皆宜·韩定食小菜全套·黄萝卜(黄色)
  • 食材：萝卜 + 酱油·糖 + 姜黄(黄萝卜黄色的由来)
  • 外国游客亲和度：★★★★★(黄萝卜全球熟知，常联想到日本料理)
  • 腌制时间：7~30天
  • 推荐去处：韩定食餐厅、紫菜包饭 (gimbap / 김밥) 店 (#840)、烤五花肉 (samgyeopsal / 삼겹살) 店、MZ咖啡厅
  • 价格：韩定食小菜内含 / 超市 = 2,000~5,000韩元(约11~26元人民币)

🌶 辣椒酱菜 (Gochu-jangajji / 고추장아찌) — 辛辣·老字号款

  • 招牌特点：辛辣·老字号常客最爱·配烧酒 (soju / 소주，韩式蒸馏酒)
  • 食材：青红辣椒 + 酱油·醋·糖
  • 外国游客亲和度：★★★★(辛辣，配烧酒很搭)
  • 腌制时间：7~30天
  • 推荐去处：老字号、市场、韩定食餐厅、烧酒馆
  • 价格：市场 = 5,000~10,000韩元/袋(约26~53元人民币)

🧄 大蒜酱菜 (Maneul-jangajji / 마늘장아찌) — 一年陈酿

  • 招牌特点：腌足整整一年·紧实辛辣·头号铁杆粉丝款
  • 食材：大蒜 + 酱油·醋·糖，腌足一年
  • 外国游客亲和度：★★★★(一年陈酿铁杆粉丝款，Instagram常见)
  • 腌制时间：1年(正宗做法) / 1个月(快速版)
  • 推荐去处：韩定食餐厅、老字号、全罗道正宗做法
  • 价格：市场 = 8,000~20,000韩元/袋(约42~105元人民币)

🌿 紫苏叶酱菜 (Kkaennip-jangajji / 깻잎장아찌) — 韩定食经典

  • 招牌特点：韩定食小菜正宗经典·紫苏叶特有香气
  • 食材：紫苏叶 + 酱油·辣椒·大蒜调味料
  • 外国游客亲和度：★★★★(韩定食经典款)
  • 腌制时间：1~7天
  • 推荐去处：韩定食餐厅 (#837)、正宗老字号、家常菜
  • 价格：韩定食小菜内含

🍃 蜂斗菜酱菜 (Meowi-jangajji / 머위장아찌) — 春季老字号款

  • 招牌特点：春季(3~4月)正宗老字号款·老字号常客最爱
  • 食材：蜂斗菜 (butterbur) + 酱油·醋
  • 外国游客亲和度：★★★(老字号常客最爱)
  • 腌制时间：7~30天
  • 推荐去处：老字号韩定食餐厅、乡村正宗做法
  • 价格：老字号 = 10,000~20,000韩元/袋(约53~105元人民币)

⚠ 外国游客常见的5个误区

1. "泡菜 = 酱菜"：泡菜 = 发酵 + 辣味调味(白菜、萝卜) / 酱菜 = 酱油·醋腌制(黄瓜、萝卜、辣椒) —— 是不同的食物。

2. "黄萝卜 = 日本食品"：韩国黄萝卜 = 萝卜酱菜 + 姜黄(黄色)·日本沢庵渍是用米糠发酵而成 —— 是不同的食物。

3. "大蒜酱菜只腌一周"：正宗大蒜酱菜要腌足整整一年(紧实·辛辣·铁杆粉丝款)。

4. "酱菜都不辣"：辣椒酱菜 + 紫苏叶酱菜是辣的(含辣椒)。

5. "韩定食小菜要另外收费"：韩定食小菜 = 无限免费续加(含酱菜)。

⚙ 常见问题8则

1. 外国游客入门首选：黄瓜 + 萝卜(全球熟悉) → 紫苏叶(韩定食经典) → 大蒜(一年陈酿铁杆粉丝款)。

2. 拍照·vlog推荐：韩定食小菜全套、腌足一年的大蒜酱菜、广藏市场酱菜小巷。

3. MZ潮流：高性价比的韩定食小菜、MZ咖啡厅的酱菜创意料理。

4. 烧酒爱好者：辣椒酱菜 + 大蒜酱菜(下酒菜首选)。

5. 清真·犹太洁食：6种酱菜都没问题(酱油含部分麸质)。

6. 过敏提醒：请提前告知酱油含麸质的情况。

7. 付款·小费：市场 = 现金·刷卡皆可 / 超市 = 可刷卡 / 无需小费。

8. 退税：餐饮一般不在退税范围内。

⚠ 医疗·安全·饮食注意事项

酱菜属于日常食品，用酱油腌制发酵而成。孕妇、儿童食用没问题。请提前告知过敏情况(酱油含麸质、辣椒辛辣)。如怀疑食物中毒，请拨打 ☎ 1339(医疗热线，提供英语服务)。本指南仅为一般信息，不构成医疗建议。

饮食限制应对方案：

  • 清真·犹太洁食：6种酱菜都没问题(植物性食材)。
  • 素食·纯素：6种酱菜都没问题(全素食)。
  • 无麸质：酱油含麸质 → 可用溜酱油(Tamari)替代。
