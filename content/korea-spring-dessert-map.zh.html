🎯 本指南的使用方法

把粉色樱花形状的面包掰开,粉色豆沙馅露出来,花香先扑鼻而来 — 镇海的樱花面包是用樱花浓缩汁和樱花豆沙馅做成的(VisitKorea)。本指南介绍的是售卖用草莓·樱花·艾草制作的甜品的店铺。每一类都把能在首尔吃到的地方放在前面,产地(清道·山清·镇海·公州·骊州)放在后面。所有店铺都是韩国观光公社旅游信息(VisitKorea, TourAPI)中收录了相关食材菜品的地方。

这里写的菜品是VisitKorea上收录的菜品,没有“春季限定”的标注。不过草莓菜品很多店只在草莓季才供应,季节菜单每年都会变 — 去之前请通过官方社交媒体或电话确认。春季产地节庆的日期每年不同,所以只写了往届的日期。冬季草莓季放在#476 冬季小吃指南,艾草年糕等年糕类放在#473 年糕指南。

🍓 草莓 — 首尔1家·产地4家

  • 地球与我们 (Earth Us / 얼스어스) — 首尔麻浦区 (Mapo-gu / 마포구) 城美山路 (Seongmisan-ro / 성미산로) 150。这是不使用一次性容器的咖啡馆,没有自带容器·保温杯就不能打包。人气菜品是整颗草莓放进去的草莓奶油芝士蛋糕(VisitKorea)。营业时间12:00~21:00，周二休息(VisitKorea)
  • 德南 (Deoknam / 덕남) — 庆北清道郡 (Cheongdo-gun / 청도군) 华阳邑 (Hwayang-eup / 화양읍) 莲池内街 (Yeonjian-gil / 연지안길) 33-11。招牌是用100%动物性鲜奶油和产地草莓做的草莓鲜奶油蛋糕,还有鲜草莓拿铁。有宽敞的庭院,仅限室外可携带宠物。离清道铁路自行车很近。官方渠道Instagram @deoknam_cheongdo(VisitKorea)。营业时间11:00~21:30(最后点单21:00)，全年无休(VisitKorea)
  • 山清窑咖啡 (Cafe Sancheongyo / 카페산청요) — 庆南山清郡 (Sancheong-gun / 산청군) 丹城面 (Danseong-myeon / 단성면) 江楼放牧路499街 (Gangnubangmok-ro 499beon-gil / 강누방목로499번길) 106-13。这是南江边陶艺工坊(山清窑 (Sancheongyo / 산청요))附设的咖啡馆,杯子和碗碟全是手工陶器。菜单上有山清窑草莓刨冰,介绍文字推荐亲手熬制的红豆刨冰(VisitKorea)。营业时间11:00~18:00，周一休息(逢公休日照常营业)(VisitKorea)
  • Planet Coffee 山清店 (Planet Coffee Sancheong / 플래닛커피 산청점) — 庆南山清郡 (Sancheong-gun / 산청군) 金西面 (Geumseo-myeon / 금서면) 景湖路 (Gyeongho-ro / 경호로) 27。用当地特产制作饮品·甜品的咖啡馆,菜单上有山清草莓拿铁。二楼屋顶露台,可携带小型犬(VisitKorea)。营业时间11:00~18:00(最后点单17:30)，全年无休(VisitKorea)
  • 韩屋咖啡小北 (Hanok Cafe Sobuk / 한옥카페소북) — 庆南山清郡 (Sancheong-gun / 산청군) 新等面 (Sindeung-myeon / 신등면) 新车路 (Sincha-ro / 신차로) 526-9。这是翻修老韩屋的咖啡馆,里面有独立书店“拉扯书店 (Mildang Chaekbang / 밀당책방)”。菜单上有丹溪草莓拿铁 (Dangye Ttalgi Latte / 단계딸기라떼)(VisitKorea)。营业时间10:30~18:00(最后点单17:30)，全年无休(VisitKorea)

🌸 樱花 — 镇海2家

  • 美珍糕点店 (Mijin Gwajajeom / 미진과자점) — 庆南昌原市 (Changwon-si / 창원시) 镇海区 (Jinhae-gu / 진해구) 忠庄路130街 (Chungjang-ro 130beon-gil / 충장로130번길) 4。07:00~22:00,全年无休。招牌是樱花蜂蜜玛德琳 (Beotkkot Kkul Madeulen / 벚꽃꿀마드렌느),还有樱花面包·樱花奶油芝士挞·樱花卷。被称为镇海最古老的面包店,是“百年老店 (Baengnyeon Gage / 백년가게)”,与镇海制果一起研发了樱花面包。可打包·可刷卡。电话 055-545-3133(VisitKorea)
  • 镇海制果 (Jinhae Jegwa / 진해제과) — 庆南昌原市 (Changwon-si / 창원시) 镇海区 (Jinhae-gu / 진해구) 中原路43街 (Jungwon-ro 43beon-gil / 중원로43번길) 4(光化洞 (Gwanghwa-dong / 광화동))。招牌面包是樱花面包。还有樱花奶油芝士挞·镇海樱花夹心饼·柠檬面包,面包用盒子包装,适合送礼(VisitKorea)。营业时间08:30~22:00，全年无休(VisitKorea)
  • 镇海赏樱路线请看镇海军港祭樱花节

🌿 艾草 — 首尔4家·产地2家

  • 四月的鱼 (Sawol-ui Mulgogi / 사월의물고기) — 首尔钟路区 (Jongno-gu / 종로구) 仁寺洞街 (Insadong-gil / 인사동길) 62-5(安国洞 (Anguk-dong / 안국동) 小巷)。以艾草为主要食材的烘焙咖啡馆。招牌艾草维也纳 (Ssuk Bienna / 쑥 비엔나)·艾草奶油拿铁在艾草奶油上放着艾草年糕块。当季还供应艾草奶油盐面包(VisitKorea)。营业时间09:00~21:00，全年无休(VisitKorea)
  • 内资商会 (Naeja Sanghoe / 내자상회) — 首尔钟路区 (Jongno-gu / 종로구) 社稷路10街 (Sajik-ro 10-gil / 사직로10길) 3(景福宫站 (Gyeongbokgung-yeok / 경복궁역) 附近)。10:00~22:00,全年无休。招牌是艾草年糕卡斯提拉 (Ssukjeolmi Kaseutella / 쑥절미 카스테라),还有黄豆粉年糕卡斯提拉·内资最中饼 (Naeja Monaka / 내자 모나카)·艾草拿铁。这是朝鲜时代掌管宫廷食品的“内资寺 (Naejasi / 내자시)”旧址上的韩屋咖啡馆。电话 070-7755-0142(VisitKorea)
  • Come to Rest (Competeureseuteu / 컴투레스트) — 首尔东大门区 (Dongdaemun-gu / 동대문구) 回基路 (Hoegi-ro / 회기로) 161-11(庆熙大学 (Gyeonghui-dae / 경희대) 附近)。招牌饮品是在冷萃拿铁上放艾草奶油的Ein-ssukpener (Ain Ssukpeone / 아인쑥페너)。有1人桌(VisitKorea)。营业时间周一12:00~18:00·周二至周五11:00~22:00·周六·周日12:00~22:00，全年无休(VisitKorea)
  • Magpie & Tiger 圣水茶室 (Maekpaiaendataigeo Seongsu Tirum / 맥파이앤타이거 성수티룸) — 首尔城东区 (Seongdong-gu / 성동구) 圣水二路 (Seongsu-iro / 성수이로) 97。11:00~21:30,全年无休。供应茶和甜品的茶室,菜单上有艾草提拉米苏。电话 0507-1306-1629(VisitKorea)
  • Enhagore (Enhakgore / 엔학고레) — 忠南公州市 (Gongju-si / 공주시) 反浦面 (Banpo-myeon / 반포면) 佛场谷路 (Buljanggol-gil / 불장골길) 113-12。俯瞰水库的咖啡馆,菜单上有艾草拿铁(VisitKorea)。营业时间11:00~19:00(最后点单18:30)，全年无休(VisitKorea)
  • 骊州咖啡 (Cafe Yeoju / 카페 여주) — 京畿骊州市 (Yeoju-si / 여주시) 康川面 (Gangcheon-myeon / 강천면) 江文路 (Gangmun-ro / 강문로) 703。有庭院的韩屋咖啡馆,菜单上有艾草拿铁(VisitKorea)。营业时间11:00~21:00(最后点单20:30)，全年无休(VisitKorea)

🥗 饮食须知

  • 价格带: 13家店在VisitKorea收录信息中都没有价格。价格未公布 — 请打电话或看店内菜单确认
  • 乳制品·鸡蛋: 德南 (Deoknam / 덕남) 的草莓鲜奶油蛋糕使用100%动物性鲜奶油(VisitKorea)。芝士蛋糕·提拉米苏·卡斯提拉·玛德琳通常含有乳制品和鸡蛋 — 纯素食者点单前请先问清楚
  • 麸质: 面包·蛋糕·卡斯提拉可能含有小麦粉。本指南中没有介绍为用大米或其他粉制作的店
  • 清真(Halal): VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的伊德 (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙丹路10街 (Usadan-ro 10-gil / 우사단로10길) 15,每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF, 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。本指南中的店铺没有清真标识
  • 出示用卡片请看#1300 饮食需求手册

🧰 春季甜品实用信息 — 独自一人、预约、支付、点单、交通

  • 独自一人: 切块蛋糕·面包·饮品都是1人份,独自去也很方便。Come to Rest (Competeureseuteu / 컴투레스트) 有1人桌(VisitKorea)。适合独自去的地点地图请看首尔单人用餐地图 — 外国人1人餐厅·酒吧·咖啡馆12个招牌
  • 打包: 地球与我们 (Earth Us / 얼스어스) 没有自带容器就不能打包。美珍糕点店 (Mijin Gwajajeom / 미진과자점) 可打包,镇海制果 (Jinhae Jegwa / 진해제과) 的面包用盒子包装(VisitKorea)
  • 支付: 收录为可刷卡的是美珍糕点店 (Mijin Gwajajeom / 미진과자점)(VisitKorea)。银行卡·移动支付请看外国人韩国支付系统深度探索
  • 点单: 咖啡馆里很多是在柜台点单后领取震动叫号器 — 韩国咖啡厅震动叫号器流程,零慌张手册 — 点完餐之后该做什么。语言不通时请看语言不通时的礼仪 — 翻译App与自助点餐机时代的点餐礼仪
  • 交通: 首尔请看韩国交通卡3种选择,零慌张手册 — 按我的行程原样挑卡。清道·山清·镇海·公州·骊州请看韩国高速·城际巴士客运站,流程原样照搬 — App从一开始就完全不同·韩国KTX初次搭乘,跟着流程走 — 在没有闸机的车站不迷路的方法

⚠ 常见的4个错误

1. “草莓节日期每年都一样” — VisitKorea节庆信息中2026年的届次是:完州三礼草莓大庆典 (Wanju Samnye Ttalgi Daechukje / 완주삼례딸기대축제) 3/6~3/8,论山草莓节 (Nonsan Ttalgi Chukje / 논산딸기축제) 3/26~3/29,晋州草莓节 (Jinju Ttalgi Chukje / 진주딸기축제) 4/10~4/12。2027年日程尚未公布。据介绍论山正在筹备2027论山世界草莓产业博览会(VisitKorea)

2. “镇海樱花面包只有军港祭期间才卖” — 美珍糕点店 (Mijin Gwajajeom / 미진과자점) 全年无休,VisitKorea菜单栏里列有樱花面包(VisitKorea) — 有没有这个菜品请打电话确认。2026年镇海军港祭于3/27~4/5举办,2027年日程尚未公布

3. “艾草甜品要去乡下才能吃到” — 首尔市中心也有四家收录了艾草菜品的店(四月的鱼·内资商会·Come to Rest·Magpie & Tiger,VisitKorea)

4. “去年的春季限定菜品今年也会有” — 连锁店·酒店的春季限定菜品,本期未能确认到官方公告。去之前请查看店铺公告
