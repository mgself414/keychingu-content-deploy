⚠ 외국인 자주 실수 5가지

1. "전주 = 1박2일 OK": 전주 외국인 매니아 = 1박2일~2박3일 풀세트 + 한옥마을 (1일) + 외곽 군산·익산 (1일).

2. "전주 비빔밥 = 어디나": 전주 비빔밥 = 유네스코 음식 창의도시 1번지 + 32 정통 비빔밥 매장 + 외국인 매니아 1번지.

3. "전주 한옥마을 = 인스타만": 전주 한옥마을 = 700+ 한옥 + 한복·한정식·한지·전통 공예 + 외국인 매니아 1번지.

4. "전주 한정식 = 비쌈": 전주 한정식 = 15,000~50,000원 1인 + 한국 1번지 한정식 + 외국인 매니아 1순위 (정원·새벽집·궁중 등).

5. "전주 한옥스테이 = 어려움": 전주 한옥스테이 = 외국인 매니아 1번지 + 영문 안내 + 외국인 친화 + 1박 50,000~200,000원.

4. 외국인 전주 한옥스테이: 외국인 매니아 1번지 + 영문 안내 + 1박 50,000~200,000원.

🗺 외국인 풀데이 코스 3개

A. 전주 1박2일 (외국인 첫 전주)

  • Day 1: KTX 서울→전주 → 한옥마을 + 한복 + 비빔밥 → 한옥스테이 1박
  • Day 2: 풍남문·경기전·전동성당 + 한정식 + KTX 전주→서울

B. 전주 외곽 deep dive 2박3일

  • Day 1: 전주 한옥마을 + 비빔밥
  • Day 2: 외곽 군산 + 익산
  • Day 3: 외곽 무주 또는 부안 → 서울

C. 전주 1주일 풀세트 (외국인 매니아)

  • Day 1~3 전주 한옥마을 deep dive
  • Day 4~5 외곽 군산·익산
  • Day 6~7 외곽 무주·부안 + 서울

🌸 시즌 5

  • 봄 3~5월: 전주 한옥마을 봄꽃 + 외국인 매니아 1번지
  • 여름 6~8월: 전주 한옥 시원한 그늘 + 외국인 매니아
  • 가을 9~11월: 전주 한옥마을 단풍 외국인 매니아 1순위
  • 겨울 12~2월: 전주 한옥 + 한정식 외국인 매니아
