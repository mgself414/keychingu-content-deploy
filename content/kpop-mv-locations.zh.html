K-pop音乐录影带拍摄地7处 — 媒体确认的MV场景，现在怎么去

副标题: BTS《Spring Day》的杨州Ilyeong站，《Epilogue: Young Forever》的堤川飞行场，《Not Today》的清州文化制造厂，《Save ME》的扶安新万金，SUGA《Daechwita》的龙仁大长今公园，PSY《Gangnam Style》的首尔儿童大公园，NewJeans《Bubble Gum》的济州Hwangwoochi海滩。只挑出经媒体报道确认为MV拍摄地、并且普通游客可以参观的7处。每个地点都写了是哪个场景、开放时间和费用，以及路上要注意的事项。

ISSUE 03 · #565 · 2026-11-25

🎯 适合哪些人

这一篇写给想亲自走进喜欢的音乐录影带场景的K-pop粉丝。经纪公司通常不会正式公布拍摄地。所以这一篇只挑了新闻报道写明"这支MV在这里拍摄"的地方。只在粉丝社区帖子里出现的地方都去掉了。接着为了确认普通游客能不能参观，我们查看了Kakao地图上该地点是否显示为营业中(2026-11-25确认)，有运营方官方页面的就确认了页面上的说明。

⚠ 标注原则: 开放时间和费用旁边都附上了出处和确认日期。Kakao地图的数值是登记在地点页面上的值(2026-11-25确认)。MV场景的说明只转述括号里报道写到的内容。拍摄之后时间已经过去，很多地方和画面里现在的样子不同。尤其是清州文化制造厂，拍摄后经过了改建。路线和所需时间请当天用Kakao地图导航确认。

① 首尔·京畿 — 3处

  • Ilyeong站 (Ilyeong Station / 일영역) (杨州) — BTS《Spring Day》音乐录影带第一个场景，雪中的小站就是这里(首尔新闻 2019-03-22)。首尔新闻介绍说，V走下站台、把耳朵贴近铁轨的场景就在这里(2019-03-22)。Ilyeong站曾是郊外线 (Gyoeseon Line / 교외선)的车站，2004年客运中断。郊外线在2025-01-11重新开始运行。线路从大谷站 (Daegok / 대곡역)出发，经过元陵 (Wonneung / 원릉)·Ilyeong·长兴 (Jangheung / 장흥)·松楸 (Songchu / 송추)各站，到达议政府站 (Uijeongbu / 의정부역)(首尔新闻 2026-09-01)。这是有列车通行的车站，所以不要进入铁轨。地址是杨州市 (Ilyeong-ro 647beon-gil 25, Jangheung-myeon / 장흥면 일영로647번길 25)。Kakao地图上显示为营业中的车站(2026-11-25)。班次不多，所以请提前在Korail Talk应用里查看列车时间。开车10分钟的距离有长兴雕刻公园 (Jangheung Sculpture Park / 장흥조각공원)(首尔新闻 2019-03-22)。
  • 龙仁大长今公园 (Yongin Daejanggeum Park / 용인 대장금파크) — News-wa报道称，这里被认为是SUGA(Agust D)的个人歌曲《Daechwita》音乐录影带的拍摄地，海外粉丝都会来(2026-08-02)。仿照昌德宫 (Changdeokgung / 창덕궁)仁政殿 (Injeongjeon / 인정전)建造的布景尤其受欢迎(同一报道)。这是MBC运营的古装剧拍摄场。时间是3~10月每天09:00~18:00，11~2月每天09:00~17:00(Kakao地图登记值, 2026-11-25)。门票成人11,000韩元，青少年·儿童9,000韩元，学龄前儿童免费(官方公告, 2024-10-01起适用, 2026-11-25确认)。长今游览车 (Janggeumi Tour Car / 장금이 투어카)1人4,500韩元(News-wa 2026-08-02)。地址是龙仁市 (Yongcheondrama-gil 25, Baegam-myeon, Cheoin-gu / 백암면 처인구 용천드라마길 25)。乘公共交通较远，所以坐车或打车去更好。有时会发布临时闭馆公告，所以去之前先看官方网站的公告。
  • 首尔儿童大公园 (Seoul Children's Grand Park / 서울어린이대공원) (广津) — 首尔市媒体中心 (Seoul Media Hub / 서울시 미디어허브)介绍说，PSY《Gangnam Style》音乐录影带里的旋转木马就是在这里拍摄的(2026-01-30)。公园免费入场。时间是全年无休05:00~22:00(首尔设施公团 (Seoul Facilities Corporation / 서울시설공단)官方网站, 2026-11-25)。设有游乐设施的游乐园收费，工作日10:00~18:30，周六·周日·公休日10:00~19:30营业(Kakao地图登记值, 2026-11-25)。地址是广津区 (Neungdong-ro 216 / 능동로 216)。最近的车站是7号线儿童大公园站 (Children's Grand Park / 어린이대공원역)1号出口。用Kakao地图导航步行9分钟(2026-11-25)。

② 忠清·全罗 — 3处 (BTS 2016~2017 MV)

三处都可以从首尔当天往返，但乘公共交通较远。租车或选旅游产品更好。

  • 堤川飞行场 (Jecheon Airfield / 제천비행장) (牟山飞行场 (Mosan Airfield / 모산비행장)) — BTS《Epilogue: Young Forever》(2016)里成员们在跑道上奔跑的场景就是在这里拍的。京乡新闻 (Kyunghyang Shinmun / 경향신문)指出是MV里2分20秒~2分40秒的场景(2025-08-06)。这是1950年代为军用建造的飞行场。堤川市在2004年与军队协商，把跑道一部分41,000㎡作为市民休息处开放(同一报道)。堤川市计划买下跑道920m区间，建成公园(同一报道)。地图上不太容易搜到飞行场的名字。首尔新闻建议在导航里输入"义林池洞居民中心 (Uirimji-dong Community Center / 의림지동주민센터)"(2019-03-22)。Kakao地图上显示为"堤川飞行场"(高岩洞 (Goam-dong / 고암동) 1179-1, 2026-11-25)。春天油菜花盛开，秋天粉黛乱子草盛开(Kakao地图标签)。开车3分钟的距离有水库义林池 (Uirimji / 의림지)(首尔新闻 2019-03-22)。这是军事设施用地的开放区间。请遵守告示牌上禁止人工构筑物和垃圾的提示，公园化项目可能会改变可进入的范围。
  • 文化制造厂 (Munhwa Jejochang / 문화제조창) (清州) — BTS《Not Today》音乐录影带里出现的停车场和楼顶是原清州烟草制造厂 (Cheongju Tobacco Factory / 청주연초제조창)(首尔新闻 2019-03-22)。曾是烟草工厂的建筑，现在是名为文化制造厂的复合文化空间。韩国工艺馆 (Korea Craft Museum / 한국공예관)、国立现代美术馆清州馆 (National Museum of Modern and Contemporary Art Cheongju / 국립현대미술관 청주관)(隔壁建筑)、书店和餐厅都进驻了。主楼每天10:00~20:00营业(Kakao地图登记值, 2026-11-25)。地址是清州市 (Sangdang-ro 314, Cheongwon-gu / 청원구 상당로 314)。改建让MV里的楼顶·停车场模样变了很多。就当作是去看旧烟草工厂建筑本身吧。
  • 新万金宣传馆 (Saemangeum Promotion Hall / 새만금홍보관)前的围垦地 (扶安) — BTS《Save ME》音乐录影带是在新万金围垦地拍摄的(首尔新闻 2019-03-22)。韩国中央日报英文版具体写明是新万金宣传馆前的围垦地(2018-06-15)。同一报道说这里是没有路的空旷田野，所以要把车停在入口，走着进去。报道还写到附近没有洗手间和便利店(以2018年报道为准，现在能否进入田野未能确认。请向宣传馆咨询)。宣传馆时间是10:00~17:30(Kakao地图登记值, 2026-11-25)。周一定期休馆(官方网站, 2026-11-25)。洗手间要在进入田野之前在宣传馆解决。地址是扶安郡 (Saemangeum-ro 6, Byeonsan-myeon / 변산면 새만금로 6)。

③ 济州 — 1处

  • Hwangwoochi海滩 (Hwangwoochi Beach / 황우치해변) (西归浦) — 拍摄NewJeans《Bubble Gum》音乐录影带的海滩(News1 2024-05-12, 首尔新闻 2024-05-10)。位于山房山 (Sanbangsan / 산방산)下方、龙头海岸 (Yongmeori Coast / 용머리해안)旁边的沙溪里 (Sagye-ri / 사계리)。同一报道写到，阴天很难看到像MV里那样明亮的海水颜色。请在晴天白天去。这是公共海滩，所以没有门票。Kakao地图上登记为海滩(西归浦市 (Andeok-myeon Sagye-ri 79-4 / 안덕면 사계리 79-4), 2026-11-25确认)。首尔新闻写到，松岳山 (Songaksan / 송악산)和西归浦的私有土地也作为MV背景出现(2024-05-10)。我们不建议前往私有土地场景的地点。

📌 附加 — 依据只有一处，或不是MV的地方

Nodeul岛 (Nodeul Island / 노들섬) (首尔龙山) — The Korea Times介绍说它出现在BTS《Run》MV的场景里(2026-03-13)。没能通过其他媒体确认。所以没有算进7处。这是汉江 (Han River / 한강)中间的复合文化空间，从9号线Nodeul站 (Nodeul / 노들역)2号出口步行12分钟(Kakao地图导航, 2026-11-25)。设施在11~2月周二至周日10:00~20:00开放，周一休息(Kakao地图登记值, 2026-11-25)。

江陵 (Gangneung / 강릉)注文津乡湖海滩 (Hyangho Beach / 향호해변)的BTS公交站常被称为"MV拍摄地"。但首尔新闻(2019-03-22)和The Korea Times(2026-03-13)把这里写为《You Never Walk Alone》专辑封面的拍摄地。拍摄时作为道具立起来，后来拆除了，但因为粉丝不断前来，又重新立了起来(The Korea Times)。实际上没有公交车停靠(首尔新闻)。Kakao地图上显示为"BTS公交站 (BTS Bus Stop / BTS 버스정류장)"(江陵市 (Jumunjin-eup Hyangho-ri 8-39 / 주문진읍 향호리 8-39))，并显示为营业中(2026-11-25)。因为是专辑封面拍摄地，所以没有算进7处。去江陵的话，值得顺路看看。

🗺 路线 — 2条

A. 首尔半天 — 儿童大公园

  1. 下午 从7号线儿童大公园站前往公园。游乐园工作日营业到18:30，周六·周日·公休日营业到19:30(Kakao地图, 2026-11-25)
  2. 晚上 在营业到22:00的公园里散步(首尔设施公团)

想跟着《Run》走的话，就把附加部分的Nodeul岛排在前面。Nodeul岛设施周一休息。

B. 开车一天 — 清州·堤川BTS路线

  1. 上午 清州文化制造厂(10:00~)
  2. 下午 开车转到堤川，看堤川飞行场跑道，接着去义林池

两个城市之间的移动时间请当天用Kakao地图导航确认。扶安新万金方向不同，所以另外安排一天。

⚠ 常见错误3

  1. 把江陵公交站当成《Spring Day》MV的地点去 — 经媒体报道确认的《Spring Day》MV第一个场景是杨州Ilyeong站。江陵公交站是专辑封面拍摄地。两处一个在京畿北部，一个在江原东海岸，相距很远，所以路线要分开安排。
  2. 进入Ilyeong站铁轨拍照 — 郊外线从2025-01-11起重新运行(首尔新闻 2026-09-01)。不能进入有列车经过的铁轨。请在站台和车站外面拍照。
  3. 周一去新万金 — 新万金宣传馆周一定期休馆(官方网站)。田野附近没有洗手间(韩国中央日报英文版 2018-06-15)，所以请在宣传馆开放的日子去。

⚙ FAQ 3

  1. 经纪公司大楼也是拍摄地吗? — 不是。大楼不是MV拍摄地，内部也不对普通游客开放(The Korea Times 2026-03-13)。大楼前的拍照路线在#387和#1260里。
  2. 从首尔最容易到达的地方是哪里? — 是从7号线儿童大公园站步行9分钟的首尔儿童大公园(Kakao地图导航, 2026-11-25)。公园免费入场(首尔设施公团)。依据只有一家媒体的Nodeul岛，另外写在附加部分。
  3. 能用旅游产品一次游览吗? — 韩国观光公社在2026年与HYBE·JYP·SM·Starship举办了"BIAS"活动。把视频里的地点和体验打包的产品上架到了NOL Universe平台 (NOL Universe / 놀유니버스)·Creatrip平台 (Creatrip / 크리에이트립)·Klook·KKday(MTN 2026-06-24)。但是活动视频不是音乐录影带，所以和这一篇的7处不重叠。产品构成和价格请在各预订网站确认。
