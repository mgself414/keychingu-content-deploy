ISSUE 03 · #889 · 2026-06-09

🎯 왜 한국 아침 식사 워크플로우 가이드인가

#888 아침 식사 6종 매트릭스 알아도 — 시간대·매너·예약은 별개. 한국 아침은 (a) 호텔 조식 (06:30~10:00 예약·5성급) (b) MZ 브런치 (10:00~14:00 예약·인스타) (c) 해장국 (24h·새벽 매니아) (d) 편의점·체인 (24h 즉시). 외국인은 (1) 호텔 조식 예약 모름 (2) MZ 브런치 웨이팅 모름 (3) 해장국 새벽 매니아 모름 (4) 편의점 영문 표시 모름. 본 가이드는 5-step + 시간대 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 호텔 / MZ 브런치 / 해장국 / 편의점 / 체인 즉시 럭셔리·MZ·해장·가성비 목적
2️⃣ 예약·주문 호텔 = 사전 예약 / MZ = 테이블링 / 즉시 1~30분 호텔 = 예약·MZ = 웨이팅
3️⃣ 받기·세팅 풀세트·MZ 메뉴·해장국·도시락 5~30분 시간대 핵심
4️⃣ 먹기·페어 음료 페어 + 후식 30~90분 MZ = 인스타 #1
5️⃣ 결제 카드 OK / 호텔 = 봉사료 / 팁 X 1~5분 호텔 = 봉사료 10% + 부가세 10%

총 소요 시간: 호텔 = 1~2h / MZ = 1~1.5h / 해장국 = 15~30분 / 편의점 = 5~15분

🍳 채널별 워크플로우

Type A — 호텔 조식 (06:30~10:00·예약 필수)

  • 시그니처: 5성급·풀세트·예약 필수
  • 시간: 06:30~10:00 (호텔별)
  • 가격: 60,000~120,000원/1인 (+봉사료 10% + 부가세 10%)
  • 메뉴: 양식·한식·일식 풀세트
  • 외국인 친화도: ★★★★★ (영문·1순위)
  • 예약: 호텔 프론트·홈페이지 (성수기 1~3일 사전)

Type B — MZ 브런치 (10:00~14:00·인스타)

  • 시그니처: MZ 트렌드·인스타 #1
  • 시간: 10:00~14:00
  • 가격: 15,000~30,000원/1인
  • 메뉴: 아보카도 토스트·에그 베네딕트·김치 베이글·전통 죽 fusion
  • 추천 매장: 홍대·강남·이태원·성수·연남 MZ 카페
  • 외국인 친화도: ★★★★★ (MZ #1)
  • 테이블링 앱 사전 등록 권장

Type C — 해장국 (24h·새벽 매니아)

  • 시그니처: 다음날 #1·24h
  • 시간: 24h·새벽 05:00~09:00 매니아
  • 가격: 8,000~15,000원/1인
  • 메뉴: 콩나물국밥·황태해장·뼈해장
  • 추천: 본죽·전주 콩나물·서울 황태·강원 정통
  • 외국인 친화도: ★★★★★ (해장 #1)

Type D — 편의점·체인 (24h·즉시)

  • 시그니처: 24h·가성비·즉시
  • 시간: 24h
  • 가격: 2,500~12,000원/1식
  • 메뉴: 김밥·삼각·도시락·라면 (편의점) / 죽·분식 (체인)
  • 추천: CU·GS25·세븐일레븐·이마트24·본죽·죽이야기·김가네
  • 외국인 친화도: ★★★★ (24h·영문)

🌶 외국인 영어 발화 샘플

  • "호텔 조식 예약" = "Hotel breakfast reservation, please"
  • "MZ 브런치 + 아보카도 토스트" = "MZ brunch with avocado toast"
  • "해장국 1인" = "Hangover soup for 1 (Haejang-guk)"
  • "편의점 도시락" = "Convenience store bento box (Dosirak)"
  • "테이크아웃" = "Takeout, please"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 5가지

1. "호텔 조식 = 무료 포함": 호텔 조식 = 숙박 + 별도 또는 포함 (등급 확인).

2. "MZ 브런치 = 즉시": MZ 브런치 = 웨이팅 30분~2h (테이블링 앱 권장).

3. "해장국 = 매콤만": 해장국 = 콩나물국밥·황태해장 담백 OK.

4. "편의점 = 영문 X": 편의점 = 영문 표시 + MZ 차밀 가성비 #1.

5. "한식 아침 = 어려움": 한식 아침 = 5성급 풀세트 + MZ fusion 글로벌 OK.

⚙ FAQ 8개

1. 첫 아침 = 어떤 채널: 호텔 조식 (럭셔리) + MZ 브런치 (트렌드).

2. 인스타·vlog: MZ 브런치 (#1).

3. MZ 트렌드: MZ 브런치 (#1).

4. 해장 매니아: 해장국 (#807 cluster cross).

5. 24h 가성비: 편의점 (#1).

6. 알레르기·임신: #888 disclaimer 참조.

7. 결제·팁: 카드 OK / 호텔 = 봉사료 10% / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

아침 식사 = 일반 음식. 임신부·어린이 = OK. 알레르기 (해산물·견과류·우유·계란) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 호텔 = 할랄 메뉴 일부·해장국 = 콩나물국밥 OK·편의점 = 사전 확인.
  • 채식·비건: MZ 브런치·편의점 채식 옵션 OK·호텔 채식 풀세트 OK.
  • 글루텐 free: 간장 양념 = 글루텐 (Tamari 대체).
