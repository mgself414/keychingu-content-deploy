🎯 为什么要看"巨济"指南

庆南巨济 (巨济, Geoje / 거제) = 韩国第二大岛·外岛Botania花园·风之丘悬崖的南海海岛小城。外国人最大误解 = "庆南海岛 = 只有统营"。实际巨济以外岛(海上花园)·风之丘·卵石海滩·游船축与统营·釜山不同。痛点 = (a) 因统营偏重不知巨济 (b) 从釜山到达·巨加大桥 (c) 外岛·每勿岛游船方式 (d) 牡蛎·鳕鱼本地美食。Reddit·YouTube上"Geoje island Korea / Oedo Botania"长尾搜索。

本指南涵盖 巨济12景 + 外岛·风之丘 + 每勿岛游船 + 租车动线 + 牡蛎矩阵。

🏝 巨济6大景点 Deep Dive

① 外岛Botania (Oedo Botania / 외도)

  • 招牌: 一家人打理30年的海上植物园岛·山茶·棕榈·异国花园·游船登岛
  • 外国人友好度: ★★★★★ (海上花园·游船·SNS)
  • 贴士: 长承浦/旧助罗游船·兼海金刚线·春山茶·夏花

② 风之丘 (Windy Hill / 바람의언덕)

  • 招牌: 海上的草原丘·风车·电视剧拍摄地
  • 外国人友好度: ★★★★★ (草原·绝景·打卡)
  • 贴士: 邻神仙台打包·黄昏·道场浦村

③ 神仙台 (Sinseondae / 신선대)

  • 招牌: 奇岩海岸·海景·风之丘旁
  • 外国人友好度: ★★★★☆ (奇岩·眺望·散步)
  • 贴士: 与风之丘一起·停车后步行

④ 每勿岛 (Maemuldo / 매물도)

  • 招牌: 灯塔岛·徒步·多岛海绝景
  • 外国人友好度: ★★★★☆ (海岛徒步·游船·自然)
  • 贴士: 游船时间·小每勿岛灯塔·徒步准备

⑤ 卵石海滩 (鹤洞 Mongdol / 몽돌해변)

  • 招牌: 黑卵石海滩·浪声·海水浴
  • 外国人友好度: ★★★★☆ (卵石·海滩·夏季)
  • 贴士: 鹤洞卵石·浪声名所·夏季海水浴

⑥ 战俘收容所遗址公园 (POW Camp / 포로수용소)

  • 招牌: 韩战战俘收容所历史·遗址公园·博物馆
  • 外国人友好度: ★★★★☆ (历史·教育·展览)
  • 贴士: 古县市区·历史背景·单轨

✈️ 到达·交通 (外国人实战)

  • 到达: 从釜山经巨加大桥1小时(釜山沙上/西部巴士站巴士)·首尔 → 釜山KTX后巨济巴士·近统营
  • 交通: 强烈建议租车(岛大·景点分散)·游船在长承浦/旧助罗码头
  • 住宿基地: 古县·长承浦·鹤洞度假村/民宿·1晚以上
  • 支付: 刷卡·现金·游船预约(旺季)
  • 急救: ☎ 1330(旅游)·112·119

⚠ 外国人5大常见失误

1. "庆南海岛 = 只有统营": 巨济以外岛·风之丘·游船축与统营分开。

2. "外岛船随时": 游船时间·旺季预约·天气停航确认必须。

3. "公交都能到": 巨济大·必须租车·景点分散。

4. "当天往返": 釜山1小时但景点多建议1晚以上。

5. "没啥吃的": 冬牡蛎·鳕鱼汤·海鞘·水产美味丰富。

⚙ FAQ 6个

1. 怎么去?: 釜山巨加大桥1小时·首尔釜山KTX后巨济巴士·近统营。

2. 外岛怎么去?: 长承浦/旧助罗游船·兼海金刚·旺季预约·看天气。

3. 需车吗?: 强烈建议·岛大景点分散·游船在码头。

4. 看什么?: 外岛·风之丘·神仙台·每勿岛·卵石海滩·战俘收容所。

5. 吃什么?: 冬牡蛎·鳕鱼汤·海鞘·海鲜·水产市场。

6. 推荐人群: 绝景 = 风之丘·外岛 / 海岛 = 每勿岛 / 历史 = 战俘收容所。

⚠ 医疗·安全·饮食 disclaimer

巨济有游船·海岸悬崖须注意(停航·气象)。每勿岛徒步需体力·装备。卵石海滩湿滑。租车海岸路安全驾驶。冬牡蛎等贝类过敏·新鲜度。急救去统营/釜山医院。急救 ☎ 1330·112·119。
