⚠ 외국인 자주 실수 5가지

1. "한국 매장 = 24h 항상": 한국 매장 = 편의점·24h 식당만 24h·대부분 10-22시 + 정기 휴무 + 외국인 매니아·#506 통합·KakaoMap 영업시간 확인 필수.

2. "대형마트 = 일요일 OK": 대형마트 = 월 2회 일요일 의무 휴무 (보통 2·4주 일요일) + 외국인 매니아·#506 통합·#421·#398 통합.

3. "백화점 = 365일": 백화점 = 월 1회 월요일 정기 휴무·10:30~20:00 + 외국인 매니아·#406 면세·#457 패션 통합.

4. "박물관 = 항상 OK": 박물관 = 월요일 정기 휴무·국립 09:00~18:00 + 외국인 매니아·#377·#514 통합.

5. "설·추석 = 매장 일부 영업": 설·추석 3일 = 대부분 매장 휴무·명동·강남·홍대 일부 영업 + KakaoMap 확인 필수·#506 통합.
