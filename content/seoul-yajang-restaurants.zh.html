什么是野外餐桌 (Ya-jang)?

"野 (Ye) + 场 (Jang)" — 户外餐桌即是酒馆

野外餐桌 (Ya-jang / 야장) 是指不在店内，而是在店铺外的巷弄 (gol-mok / 골목)、人行道、广场上摆放的塑料桌椅上用餐、饮酒的首尔式街头户外用餐文化。

字面意思:

  • 野 (Ye) = 野外 (Outdoor)
  • 场 (Jang) = 场所·场地 (Place·Ground)

看似相似但不同的事物:

区分 街边帐篷小吃摊 (Po-jang-ma-cha / 포장마차) 楼顶酒吧 (Rooftop Bar) 野外餐桌 (Ya-jang / 야장)
位置 移动式帐篷小吃摊 高层建筑屋顶 店铺延伸至人行道·巷弄
价格 人均 ₩20,000~30,000 人均 ₩40,000~80,000 人均 ₩15,000~30,000
氛围 帐篷内，封闭空间 景观为主，需预约 夜晚街景本身就是空间
食物 以小吃为主 小吃·鸡尾酒 主菜 + 啤酒 (肉类·鸡肉·啤酒)
韩国特色 ⭐⭐⭐⭐ ⭐⭐ ⭐⭐⭐⭐⭐

为什么对外国游客来说如此特别？

1️⃣ 街道变身餐厅的“首尔场景”

首尔巷弄 (gol-mok / 골목) 风景中，游客最常拍摄的场景之一 — 乙支路3街 (Euljiro 3-ga / 을지로3가) 的夜晚，橙色灯光亮起，巷弄 (gol-mok / 골목) 两旁塑料椅子绵延不绝。 这不是导游书上的照片，而是每天真实发生的事情。

道路与餐厅的界限消失，这种景象是首尔特有的有限自由。东京、北京、新加坡都没有这种密度。

2️⃣ “老字号 (No-po / 노포) × 野外餐桌 (Ya-jang / 야장)” 组合 — 金钱买不到的美味

首尔的代表性野外餐桌 (Ya-jang / 야장) 店铺大多是30年以上的老字号 (No-po / 노포)。满鲜啤酒屋 (Manseon Hof / 만선호프) 自1978年开业以来，被誉为乙支路烤干明太鱼 (No-gari / 노가리) 啤酒文化的鼻祖。鲍石亭 (Poseokjeong / 포석정) 和清真营养中心 (Cheongjin Yeongyang Center / 청진영양센타) 也已在同一地点经营数十年。野外餐桌 (Ya-jang / 야장) 是让您直接感受时间沉淀的装置。

3️⃣ 一个人、四个人、二十个人都没问题

野外餐桌 (Ya-jang / 야장) 几乎没有预约的概念。直接过去，有空位就坐。人多的话，可以当场合并桌子；一个人去，和旁边桌的客人分享一份烤干明太鱼 (No-gari / 노가리) 也很常见。这是游客团体 (4人) 不知道点什么而感到困惑的风险最低的韩式酒局。

首尔野外餐桌 (Ya-jang) 美食店 TOP 7

自1978年开业以来，将整个乙支路 (Euljiro / 을지로) 巷弄 (gol-mok / 골목) 打造成“OB熊 (OB Bear / OB베어) (旧海特真露 (HiteJinro / 하이트진로) 直营) 烤干明太鱼 (No-gari / 노가리) 圣地”的创始店。傍晚时分，店前的巷弄 (gol-mok / 골목) 会被塑料椅子挤满。烤干明太鱼 (No-gari / 노가리) (干明太鱼) + 生啤酒组合是这家店定义的首尔式组合。

推荐点餐:

  • 烤干明太鱼 (No-gari / 노가리) (干明太鱼烧烤) — 建议点3条
  • 炸鱼薯条 (Fish & Chips) 或 烤明太鱼干 (Meok-tae-gui / 먹태구이) — 再加一份烧烤类
  • 生啤酒 500cc — 第一杯必点生啤酒

外国人小贴士: 没有英文菜单，但可以指着图片点餐。只需说“Fish + draft beer”也能沟通。

位于乙支路3街 (Euljiro 3-ga / 을지로3가) 野外餐桌 (Ya-jang / 야장) 区域的中心。这是一家在户外餐桌上直接烤制炭火烧烤的店铺，从入口处弥漫的烟雾和烤肉味就充满了整个巷弄 (gol-mok / 골목)。“在满鲜啤酒屋 (Manseon Hof / 만선호프) 喝冰镇啤酒，在迎月广场 (Dalmajigwangjang / 달맞이광장) 吃烤肉”是乙支路 (Euljiro / 을지로) 野外餐桌 (Ya-jang / 야장) 第二轮的经典路线。

  • 鸡蛋羹 (Gye-ran-jjim / 계란-jjim) (特色菜)

3️⃣ 满鲜啤酒屋 (Manseon Hof / 만선호프) 和 迎月广场烧烤 (Dalmajigwangjang Barbecue / 달맞이광장바베큐) 之间 — 乙支路 (Euljiro / 을지로) 烤干明太鱼 (No-gari / 노가리) 巷弄 (gol-mok / 골목) 整体

除了满鲜啤酒屋 (Manseon Hof / 만선호프) 总店，还有满鲜啤酒屋2 (Manseon Hof 2 / 만선호프2)、满鲜啤酒屋9 (Manseon Hof 9 / 만선호프9) 等分店分布在整个巷弄 (gol-mok / 골목) 中。如果总店人多，只需再走一个街区，就会看到一排同系列的野外餐桌 (Ya-jang / 야장) 啤酒屋。“首尔哪里野外餐桌 (Ya-jang / 야장) 密度最高”这个问题的答案就是这里，乙支路13街 (Euljiro 13-gil / 을지로13길) + 忠武路9街 (Chungmu-ro 9-gil / 충무로9길)。

野外餐桌 (Ya-jang) 访问指南与礼仪

✅ DO

  • 晚上 6:45 ~ 7:00 到达: 抢占座位的黄金时间
  • 直接坐在塑料椅子上: 店员喊“坐这里”就坐下
  • 拍照时避免拍到旁边桌的脸: 尊重隐私
  • 一次点 2~3 样: 之后可以追加点餐
  • 垃圾留在桌上: 店员会清理 (切勿自行带走，反而显得奇怪)
  • 晚上 11:00 前考虑让座: 等待第二轮的客人很多

❌ DON'T

  • 一个人坐在空桌上“预订”: 原则上是所有同行者到齐后才能入座
  • 突然尝试与韩国人桌子拼桌: 除非受到邀请，否则分开坐
  • 自带野餐垫·保温杯: 野外餐桌 (Ya-jang / 야장) 是店家服务，严禁自带便利店 (pyeon-ui-jeom / 편의점) 啤酒
  • 大声喧哗干杯: 与旁边桌子只有 30cm 距离
  • 凌晨 1:00 后大声喧哗: 会引起附近居民投诉

实用小贴士

💳 支付

大部分地方接受信用卡，但部分老字号 (No-po / 노포) 只收现金。建议准备人均 ₩30,000 的现金 ₩20,000~30,000 + 备用信用卡。

📱 翻译

  • Papago (Papago / 파파고) 拍照翻译: 菜单韩文 → 英文即时转换
  • 谷歌翻译 (Google Translate) 拍照模式: 基本覆盖
  • 老字号 (No-po / 노포) 有英文菜单的概率为 30%，请做好没有的准备

🦟 夏季蚊虫·炎热

  • 5~9月: 建议携带小型驱蚊剂 (当地便利店 (pyeon-ui-jeom / 편의점) 也有售)
  • 8月正午高峰 (35°C以上): 晚上 8:00 后体感会变得舒适
  • 包里放把扇子·降温湿巾会很实用

🌧️ 下雨天

  • 大部分野外餐桌 (Ya-jang / 야장) 下雨会立即收起 → 室内座位充足反而是机会
  • 部分有帐篷的店铺会继续营业 (满鲜啤酒屋 (Manseon Hof / 만선호프) 部分分店、鲍石亭 (Poseokjeong / 포석정) 等)

常见问题 (FAQ)

Q: 一个人去野外餐桌 (Ya-jang / 야장) 会不会很奇怪？

A: 在满鲜啤酒屋 (Manseon Hof / 만선호프)·迎月广场 (Dalmajigwangjang / 달맞이광장)，独自前来的上班族 (toe-geun-gil / 퇴근길) 很常见。2条烤干明太鱼 (No-gari / 노가리) + 1杯啤酒，一个人可以轻松待上1小时。

Q: 需要预约吗？

A: 满鲜啤酒屋 (Manseon Hof / 만선호프)·迎月广场 (Dalmajigwangjang / 달맞이광장)不可预约。善美屋 (Seonbiok / 선비옥)·首尔鲁登斯 (Seoul Ludens / 서울루덴스)·巡逻街Bibi (Sunragil Bibi / 순라길 비비) 可能在 Naver 地图 (Naver Jido / 네이버 지도) 上可以预约。4人以上建议确认。

Q: 不会韩语也能点餐吗？

A: 可以。指着菜单图片 + 说一句“这个하나요 (ee-guh ha-na-yo)” (这个，请给我一个) 99%能解决。

Q: 野外餐桌 (Ya-jang / 야장) vs 室内，哪个才是真正的首尔体验？

A: 5~9月，毫无疑问是野外餐桌 (Ya-jang / 야장)。冬季 (11~2月) 室内更能展现韩国的特色情调 (温馨感)。

Q: 外国人最常犯的错误是什么？

A:

1. 到达太晚没座位 (晚上 8:00 后)

2. 自带便利店 (pyeon-ui-jeom / 편의점) 啤酒进入 (禁止)

3. 离开时想给小费 (韩国没有小费文化)

Q: 乙支路 (Euljiro / 을지로) 野外餐桌 (Ya-jang / 야장) 巷弄 (gol-mok / 골목) 和街边帐篷小吃摊 (Po-jang-ma-cha / 포장마차) 巷弄 (gol-mok / 골목) 有什么区别？

A: 野外餐桌 (Ya-jang / 야장) 是店铺合法地扩展到人行道，街边帐篷小吃摊 (Po-jang-ma-cha / 포장마차) 是移动式帐篷独立经营。野外餐桌 (Ya-jang / 야장) 价格更实惠，食物种类更多样。街边帐篷小吃摊 (Po-jang-ma-cha / 포장마차) 以酒类小吃为主，氛围是第一位。

最后一句

来到首尔，白天漫步于景福宫 (Gyeongbokgung / 경복궁)·仁寺洞 (Insadong / 인사동)·明洞 (Myeongdong / 명동)，夜晚则坐在乙支路3街 (Euljiro 3-ga / 을지로3가) 街角塑料椅子上吧。

从地铁4号出口出来的那一刻，橙色灯光下展开的“整座城市变成餐厅”的景象，比100张导游书照片更具冲击力。

一杯生啤酒，一条烤干明太鱼 (No-gari / 노가리)，与邻座韩国人尴尬的眼神交流 —

这就是首尔野外餐桌 (Ya-jang / 야장) 的三大构成要素，也是游客会说“我真的来到首尔了”的瞬间。
