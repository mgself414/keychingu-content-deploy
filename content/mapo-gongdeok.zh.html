🎯 为什么是麻浦 (Mapo / 마포)·孔德 (Gongdeok / 공덕) 独立指南

麻浦 (Mapo / 마포)·孔德 (Gongdeok / 공덕) 是麻浦区 (Mapo-gu / 마포구) 的孔德站 (Gongdeok Station / 공덕역)·阿岘 (Ahyeon / 아현)·桃花 (Dohwa / 도화)·大兴 (Daeheung / 대흥) 职场人·MZ世代 (20-35岁) 首选之地 — 与弘大 (Hongdae / 홍대) (#138)·延南 (Yeonnam / 연남)·合井 (Hapjeong / 합정) 不同，是麻浦区 (Mapo-gu / 마포구) 本土区域的深度探索。拥有孔德站 (Gongdeok Station / 공덕역) (5号线·6号线·机场铁路·京义中央线四线换乘站) + 阿岘 (Ahyeon / 아현) 传统社区 + 桃花 (Dohwa / 도화)·大兴 (Daeheung / 대흥) MZ世代咖啡厅聚集区。KeyChinGu (키친구) 首次进入麻浦区 (Mapo-gu / 마포구) 本土区域 (麻浦 (Mapo / 마포) 区域177个地点)。

⚠ 外国游客常犯的3个错误

1. “麻浦 (Mapo / 마포) = 弘大 (Hongdae / 홍대)” — 未认识到本土区域的价值: 麻浦区 (Mapo-gu / 마포구) 除了弘大 (Hongdae / 홍대) (#138) 之外，还有孔德 (Gongdeok / 공덕)·阿岘 (Ahyeon / 아현)·桃花 (Dohwa / 도화)·大兴 (Daeheung / 대흥)·上岩DMC (Sangam DMC / 상암 DMC) = 职场人·MZ世代·媒体深度游。

2. “82年生金敏京 (82nyeonsaeng Kim Minkyeong / 82년생 김민경) = 不知道”: 韩国畅销书作家 + 咖啡厅合作 — 外国游客韩国书籍深度游。

3. “上岩DMC (Sangam DMC / 상암 DMC) = 太远了”: 麻浦 (Mapo / 마포) 汉江西侧 + 毗邻世界杯体育场。6号线数字媒体城站 (Digital Media City Station / 디지털미디어시티역)。

⚙ 常见问题6个

1. 孔德站 (Gongdeok Station / 공덕역) 四线换乘对外国游客意味着什么？是首选的换乘站。直达仁川机场。

2. 82年生金敏京 (82nyeonsaeng Kim Minkyeong / 82년생 김민경) 咖啡厅？与赵南柱 (Jo Nam-joo / 조남주) 畅销书合作，MZ世代 (20-35岁) 首选。

3. 上岩DMC (Sangam DMC / 상암 DMC) MBC 参观？可提前预约。

4. 麻浦汉江公园 (Mapo Hangang Park / 마포 한강공원) 自行车？汉江西侧自行车道起点。

5. 麻浦 (Mapo / 마포) + 弘大 (Hongdae / 홍대) 路线？步行15分钟或6号线1站。

6. 世界杯体育场 (World Cup Stadium / 월드컵경기장)？2002韩日世界杯体育场 + 博物馆。
