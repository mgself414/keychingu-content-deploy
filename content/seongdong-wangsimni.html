ISSUE 03 · #189 · 2026-05-18

🎯 왜 성동·왕십리 단독 가이드인가

성동·왕십리는 성동구의 왕십리·금호·옥수·마장·행당 한강 결합 area — 성수(#01·#145)와 별도 성동구 본 area deep dive. 왕십리역 (2·5·KTX·경의중앙선·수인분당선 5중 환승역, 한국 1번지) + 금호·옥수 한강뷰 + 마장 정통 정육·고기 + 행당 MZ 결합. 키친구 최초 성동구 본 area 진입 (seongdong cluster 168건).

★ 한눈에 비교 (12곳)

4축 매핑

  • ① 한식 3 / ② 카페·디저트 3 / ③ 양식·바 3 / ④ 한강·체험 3+4

⚠ 외국인 자주 실수 3가지

1. "성동 = 성수만" — 본 area 가치 미인지: 성수(#01·#145) 외 왕십리·금호·옥수·마장·행당 = 한강·환승·정육 deep dive.

2. "왕십리역 = 그냥 역": 한국 1번지 5중 환승 (2·5·KTX·경의중앙선·수인분당선). KTX 강릉선 출발지.

3. "마장축산물시장 = 모름": 한국 1번지 정육 도매 시장 (1961 개장). 한우·돼지 직거래 도매. 외국인 가격 협상 OK.

⚙ FAQ 6개

1. 왕십리역 환승? 한국 1번지 5중 환승. KTX 강릉선 출발지.

2. 마장축산물시장 외국인 가능? 가능. 가격 협상 + 즉석 회·구이 OK.

3. 응봉산 야경? 한강 야경 1순위 (#51 응봉산 팔각정).

4. 성동 + 성수 동선? 도보 10분 또는 2호선·수인분당선 1정거장.

5. 한양대 캠퍼스? 자유 입장 OK.

6. 옥수·금호 한강 자전거? 한강 자전거 도로 + 따릉이.
