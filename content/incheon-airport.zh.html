外国人常犯的5大错误

1. 混淆T1与T2航站楼

仁川机场共有2座航站楼 — T1·T2之间乘摆渡车需15分钟。务必核对机票，走错须乘摆渡车+额外耗时30分钟。T2对应大韩航空 (Korean Air / 대한항공)·达美航空·KLM·法航，T1对应其余航空公司。

2. 在机场换汇

机场换汇汇率比明洞 (Myeongdong / 명동)·市区差2~3%。建议在机场仅换₩50,000小额（用于打车·交通卡），到市区后再正式换汇。明洞 (Myeongdong / 명동) 街头换汇店（参见#63）汇率最优。

3. 分不清AREX直通与普通列车

AREX直通列车 = 直达首尔站 (Seoul Station / 서울역) 43分钟 ₩11,000（需预约，06:00~22:00）

AREX普通列车 = 停靠11站 1小时 ₩4,500（24小时运行，无需预约）

同一线路，时间与价格差异明显。行李少则选普通，优先时间则选直通。

4. 未能同步办理SIM卡与换汇

在机场同时办好SIM卡 + 换₩50,000可节省大量时间。SK电信 (SK Telecom / SK텔레콤)·KT服务台位于出口前方，紧邻换汇处。

5. 警惕拉客·不打表的出租车

机场出口拉客出租车属违法行为（正规出租车须在排队区候客）。乘坐普通出租车须确认计价器已启动，并索取收据。推荐使用 卡卡奥T (Kakao T / 카카오T) 英文版App更安全。

★ 仁川机场首6小时全攻略

Step 1：飞机落地 → 入境审查（15~30分钟）

  • K-ETA（韩国电子旅行许可）— 须提前申请（90国免签入境时必填）https://www.k-eta.go.kr
  • 入境申报表 在机上填写（英文版可用）
  • 外国人通道 = 普通外国人 / 持K-ETA = 快速通道
  • 工作日凌晨·周末高峰期可能等待30分钟~1小时

Step 2：取行李（10~30分钟）

  • 确认航班到达显示牌
  • 行李丢失请前往航空公司柜台（提供英文服务）报告
  • 行李推车免费使用

Step 3：通关（5分钟）

  • 无申报物品 = 绿色通道（大多数外国人走此通道）
  • 免税额度：₩800,000 + 酒1升 + 香烟200支
  • 超额请走红色通道

Step 4：换汇 + SIM卡（15~20分钟）

  • 换汇处 = 机场出口多处（推荐仅换₩50,000小额）
  • SIM卡服务台（SK·KT·LG U+）— 提供1日·5日·10日·30日套餐 ₩5,000~50,000
  • e-SIM选项 — 手机兼容时更便捷
  • 外国人韩国手机号 → 可注册 卡卡奥T (Kakao T / 카카오T)·外卖App等

Step 5：前往市区（1~1.5小时）

① AREX直通列车（Express）— 优先时间

线路：仁川机场 (Incheon Airport / 인천공항) T1·T2 → 首尔站 (Seoul Station / 서울역) 直达（中途不停站）

价格：₩11,000（成人）/ 儿童票₩4,500

所需时间：43分钟（T2出发）/ 51分钟（T1出发）

运行时间：06:00~22:00（每30分钟一班）

预约方式：机场铁路英文版App·官网 / 现场购票均可

要点：

  • 指定座位 + 行李可放座位旁
  • 全程提供WiFi·电源插座
  • 到达首尔站 (Seoul Station / 서울역) 后可直接换乘地铁及KTX高铁
  • 优先时间 + 1~2人行李时最适合

一句话总结："43分钟直达 = 外国人优先时间首选"

② AREX普通列车 — 性价比之选

线路：仁川机场 (Incheon Airport / 인천공항) T1·T2 → 首尔站 (Seoul Station / 서울역)（途经11站）

价格：₩4,500

所需时间：1小时（T2）/ 1小时7分钟（T1）

运行时间：24小时（每5~10分钟一班）

预约方式：无需预约（现场刷卡即可）

要点：

  • 座位与普通地铁相同 — 行李略显不便
  • 停靠金浦机场 (Gimpo Airport / 김포공항)·弘大入口 (Hongik University / 홍대입구)·首尔站 (Seoul Station / 서울역) → 可换乘地铁
  • 凌晨航班到达时24小时运行优势突出
  • ₩4,500性价比 = 外国人首选

一句话总结："₩4,500 + 24小时 = 性价比·凌晨到达最优解"

③ 机场巴士（Limousine）— 直达酒店

主要线路：

  • 6001路：T1·T2 → 蚕室 (Jamsil / 잠실)·江南 (Gangnam / 강남)
  • 6015路：T1·T2 → 明洞 (Myeongdong / 명동)·首尔站 (Seoul Station / 서울역)
  • 6021路：T1·T2 → 弘大 (Hongdae / 홍대)·新村 (Sinchon / 신촌)
  • 6101路：T1·T2 → 江南 (Gangnam / 강남)·狎鸥亭 (Apgujeong / 압구정)
  • 其余东大门 (Dongdaemun / 동대문)·梨泰院 (Itaewon / 이태원)·汝矣岛 (Yeouido / 여의도) 等30条以上线路

价格：₩15,000~17,000

所需时间：1~1.5小时（视路况）

运行时间：05:00~23:00（每15~30分钟一班）

预约方式：机场1楼售票处 + 英文版App（KOBUS、EZL）

要点：

  • 停靠酒店或酒店附近 = 无需拖行李转乘
  • 独立行李舱 = 携带大型行李的家庭首选
  • 提供英文广播报站
  • 携老带幼的家庭旅行首选

一句话总结："直达酒店 + 行李舱 = 家庭·大件行李最优解"

④ 卡卡奥T (Kakao T / 카카오T) 出租车 — 便利 + 团体

价格：₩60,000~80,000（T1·T2 → 江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대)·明洞 (Myeongdong / 명동)）

所需时间：1~1.5小时

运行时间：24小时

预约方式：卡卡奥T (Kakao T / 카카오T) 英文版App（支持外国手机号 + 外国信用卡）

要点：

  • 3~4人团体 = 人均₩15,000~20,000（与机场巴士相当）
  • 凌晨到达 + 行李多 = 首选
  • 门到门服务 = 直达酒店门口
  • 部分司机会说英语（可在App内申请英语服务）

一句话总结："团体·凌晨·门到门 = 卡卡奥T (Kakao T / 카카오T) 最优解"

FAQ

Q1. 英语能通吗？

完全没问题。仁川机场是韩国外国人服务最完善的场所。指引·标识·App均提供英文版。

Q2. 凌晨到达怎么办？

AREX普通列车24小时运行 = ₩4,500。或选择卡卡奥T (Kakao T / 카카오T) 出租车24小时。凌晨换汇·办SIM卡同样可行。

Q3. K-ETA申请被拒怎么办？

抵达韩国后可重新申请（1小时内出结果）。但若被拒绝则可能遭拒入境 → 强烈建议提前申请。

Q4. 哪些国家需要签证？

韩国免签90国（美国·日本·EU·澳大利亚等，仅需K-ETA）。其余国家需办理签证 — 请提前前往韩国领事馆申请。

Q5. 超过免税额度怎么办？

前往海关申报 → 缴纳关税。免税额度：酒1升·香烟200支·纪念品₩800,000以内。

Q6. 遗失物品·投诉？

T1·T2失物招领中心（1楼）+ 提供英文服务。航班遗失物请前往航空公司柜台。

季节性提示

春季（3~5月）

  • 外国游客激增 — 入境审查等待30分钟~1小时
  • AREX·机场巴士每30分钟增加一班

夏季（6~8月）

  • 高温时机场巴士空调必备（大多数车辆均配备）
  • 度假旺季 — 凌晨到达·深夜出发人流较多

秋季（9~11月）

  • 外国人赴韩旅游首选季节
  • 机场·市区交通均为平时的1.5倍流量

冬季（12~2月）

  • 注意降雪·结冰 — 视路况出租车·机场巴士可能延误
  • AREX准时运行（受天气影响较小）
