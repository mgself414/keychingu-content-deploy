⚠ 외국인 자주 실수 5가지

1. "K-music = K-pop만": K-music = K-pop + K-indie (잔나비·새소년·실리카겔) + 재즈 (자라섬) + 트로트 (임영웅·송가인) + 국악 + 외국인 매니아 풀세트 + #387·#455·#511 통합.

2. "인디 = 한국 없음": K-indie = 홍대 DGBD·V-Hall·롤링홀 (외국인 1번지) + 펜타포트·뷰티풀 민트 페스티벌 + 외국인 MZ 인디 매니아 1번지 + #138·#404·#455 통합.

3. "재즈 = 1~2개 클럽만": 재즈 = All That Jazz·블루스퀘어 (#511 4.7) + 자라섬 국제 재즈 (10월) + 서울 재즈 페스티벌 (5월) + 외국인 매니아 1번지 + #511·#404 통합.

4. "트로트 = 한국인만": 트로트 = 임영웅·송가인 (외국인 정통 매니아) + 트로트 노래방 (#436) + KBS 가요무대 + 외국인 K-music 매니아 1번지 + #436·#506 통합.

5. "국악 = 박물관만": 국악 = 국립국악원·정동극장 전통공연 + 사물놀이·풍물 체험 + 외국인 정통 매니아 1번지 + #509·#377·#379 통합.
