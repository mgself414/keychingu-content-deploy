外国人钟路韩食深度攻略

600年朝鲜王朝都城——仁寺洞韩定食·广藏市场汤饭·乙支路老字号·宫廷韩食15处矩阵

钟路(Jongno / 종로)是有着600年历史的朝鲜汉阳都城核心区。地处景福宫(Gyeongbokgung / 경복궁)·昌德宫(Changdeokgung / 창덕궁)·昌庆宫(Changgyeonggung / 창경궁)三大宫殿之间,堪称韩国韩食的圣地。从广藏市场(1905年开业、韩国最古老的市场)、仁寺洞(韩定食集群)、乙支路(老字号集群),到昌德宫附近的宫廷韩食一应俱全——对外国细分市场、美食爱好者(foodie)、历史爱好者(history buff)人设而言是韩食深度体验的第一选择。本指南整理了4大区域15处韩食名店 + 一日动线矩阵 + 韩食礼仪。

1. 钟路韩食概览（外国游客适配事实）

600年韩食历史

  • 1392年朝鲜迁都汉阳(Hanyang / 한양) → 钟路成为都城中心
  • 宫廷韩食·两班韩食·平民韩食均集聚于钟路
  • 广藏市场1905年开业 = 韩国最古老的常设市场
  • 仁寺洞 = 朝鲜后期两班(Yangban / 양반)聚居地 → 演变为韩定食集群
  • 乙支路 = 日据时期·光复后老字号集群

韩食4大类型（钟路全部齐全）

  • 宫廷韩食：神仙炉(Sinseollo / 신선로)·九折坂(Gujeolpan / 구절판)·杂菜(Japchae / 잡채)·炖排骨(Galbijjim / 갈비찜)（朝鲜王室菜肴）
  • 两班韩食：韩定食12~20碟套餐（两班家庭菜）
  • 平民韩食：汤饭·面条·汤锅·拌饭(Bibimbap / 비빔밥)（市场菜）
  • 现代韩食：米其林餐厅（现代重新演绎）

为什么是钟路——外国游客数据

  • 韩国观光公社数据显示,外国游客最喜爱的美食类别第一名为韩食（截至2024年）
  • 广藏市场被CNN Travel、NYT多次推荐
  • 又来屋(Uraeok / 우래옥)·朴家绿豆煎饼(Bakgane Bindaetteok / 박가네 빈대떡)连续多年入选米其林必比登推介
  • 景福宫年外国游客访问量300万+人次 → 自然带动周边土俗村(Tosokchon / 토속촌)·仁寺洞人流

2. 外国游客常见错误3例

错误1——在广藏市场支付"游客价"

广藏市场部分摊位对外国游客不出示菜单,只是口头报价。入座前请先要求出示菜单,或先问一句"多少钱？(얼마예요)"。绿豆煎饼1张的市场行情为₩8,000~10,000。若报价超出此区间,建议再次确认。

错误2——嫌又来屋的平壤冷面"太清淡"而剩下不吃

平壤冷面的本色就是清淡。第一次品尝时可能会因味道不够浓烈而失望,标准吃法是根据个人口味逐次加入随附的醋和芥末。若需要剪断面条,可以请店员用剪刀帮忙剪短(英语可说"Please cut the noodles")。

错误3——不预约直接前往韩定食餐厅

韩国之家(Korea House / 한국의 집)·温知苑(Onjium / 온지움)等位于仁寺洞·笔洞的高级韩定食餐厅,当天预约几乎不可能。必须至少提前3~7天通过英文官网或电话预约。仁寺洞韩定食街的中低价餐厅无需预约也可排队入座,但周末午餐时段预计需等待30~60分钟。

3. 仁寺洞·三清洞（韩定食·宫廷韩食）

1. 韩国之家（仁寺洞·笔洞）

  • 位置：首尔中区笔洞(Pil-dong / 필동)（毗邻仁寺洞,步行10分钟）
  • 招牌：正宗宫廷韩食套餐——神仙炉·九折坂·炖排骨·杂菜等
  • 外国人适配度：★★★（英文流利·接待外国常客超50年·多次承办外国VIP活动）
  • 价格（2026）：午餐套餐₩90,000~120,000 / 晚餐套餐₩120,000~150,000（含演出套餐另计）
  • 特色：韩服(Hanbok / 한복)体验 + 传统演出（歌唱·舞蹈·走绳）+ 韩食套餐组合。作为官方运营设施,是接待外国团体·VIP活动最常用的场所。
  • 交通：地铁3·4号线忠武路站(Chungmuro / 충무로)3号出口步行5分钟
  • 预约：官网支持英文预约,建议提前3~7天。
  • 时间：含演出套餐午场12:00·晚场18:00开始,演出时长30~40分钟。

2. 温知苑（孝子洞·景福宫附近）

  • 位置：首尔钟路区孝子路(Hyoja-ro / 효자로)（景福宫以西）
  • 招牌：米其林一星——宫廷韩食的现代化再诠释,以时令食材为主的主厨精选(Omakase)形式。
  • 外国人适配度：★★★（英文菜单·英语员工·外国常客多）
  • 价格（2026）：午餐₩280,000~320,000 / 晚餐₩320,000~360,000（酒水另计）
  • 特色：须提前在线预约。着装要求为商务休闲(smart casual)。套餐由10~14道菜组成,使用宫廷餐具·陶瓷器皿。（参见#1109首尔米其林）
  • 交通：地铁3号线景福宫站3号出口步行8分钟
  • 预约：官网（naverreservations,外国游客可邮件预约）,至少提前1~2周。
  • 时间：午餐12:00~14:00 / 晚餐18:00~21:00。餐桌数量有限,无预约无法入店。

3. 仁寺洞韩定食街

  • 位置：首尔钟路区仁寺洞街(Insadong-gil / 인사동길)·乐园洞(Nagwon-dong / 낙원동)一带
  • 招牌：12碟韩定食——包含汤·炖菜·煎饼·烤肉·凉拌菜·泡菜·小菜
  • 价格（2026）：₩40,000~80,000/人（各店有所不同）
  • 外国人适配度：★★（部分店铺有英文菜单,建议搭配翻译App使用）
  • 特色：与其说是单一餐厅,不如说整条街都是韩定食集群。各店字号不同,门槛比韩国之家·温知苑更亲民。
  • 交通：地铁3号线安国站(Anguk / 안국)6号出口步行3分钟
  • 时间：午餐11:30~14:00,晚餐17:30~20:00。周末午餐预计需等待30~60分钟。

4. 三清洞韩定食·咖啡区

  • 位置：首尔钟路区三清洞街(Samcheong-dong-gil / 삼청동길)（毗邻北村韩屋村）
  • 招牌：韩屋(Hanok / 한옥)建筑内的韩定食·传统茶·甜品集群。（参见#1097北村）
  • 外国人适配度：★★★（韩屋氛围·拍照打卡点多·外国游客比例高）
  • 价格（2026）：正餐₩30,000~70,000 / 传统茶₩8,000~15,000
  • 特色：比起用餐,更多游客是为喝茶·品尝甜品而来。韩餐厅·咖啡馆·画廊混杂分布。
  • 交通：地铁3号线安国站1号出口步行10分钟

4. 广藏市场（平民韩食·1905年至今的市场）

广藏市场是1905年开业的韩国最古老的常设市场。2层建筑加地下层,密集分布着数百个摊位和老字号店铺,是外国游客最容易亲近的平民韩食体验空间。

基本信息

  • 位置：首尔钟路区昌庆宫路88号(Jongno 4-ga / 종로 4가)
  • 营业：每日09:00~23:00（各摊位有所不同）
  • 交通：地铁1·5号线钟路4街站7号出口步行1分钟 / 2号线乙支路4街站(Euljiro 4-ga / 을지로 4가)连接

5. 广藏市场朴家绿豆煎饼（米其林必比登推介）

  • 招牌：绿豆煎饼——用绿豆磨浆制成的传统煎饼,特点是油香浓郁·外皮酥脆·内里湿润。
  • 外国人适配度：★★★（CNN Travel·纽约时报多次推荐·备有图片菜单）
  • 价格（2026）：绿豆煎饼1张₩9,000~10,000 / 什锦煎饼拼盘约₩15,000
  • 时间：上午10点~22点。午晚高峰时段需等待15~20分钟,上午11点前最为清闲。
  • 点餐提示：对店员说"绿豆煎饼一份(빈대떡 하나)"即可。搭配马格利酒(Makgeolli / 막걸리)一起点是当地吃法。

6. 广藏市场迷你紫菜包饭

  • 位置：广藏市场1层中央通道一带（多个摊位经营相似菜品）
  • 招牌：拇指大小的迷你紫菜包饭 + 腌萝卜 + 芥末 + 香油蘸酱
  • 外国人适配度：★★★（外国游客眼中的独特体验·社交媒体·YouTube热门内容）
  • 价格（2026）：1卷（18~20个）₩3,000~5,000
  • 时间：全天供应,下午3~5点的加餐时段相对清闲。
  • 注意：本地俗称"迷你紫菜包饭"为"毒品紫菜包饭"(마약김밥),其中"毒品"只是形容其"让人上瘾"的比喻说法,并非真实成分。

7. 广藏市场生拌牛肉

  • 招牌：生牛肉丝 + 梨·香油·辣椒酱调味——韩国独特的生食文化
  • 外国人适配度：★★（推荐给愿意尝鲜的美食爱好者,对生食有抵触者可跳过）
  • 价格（2026）：₩15,000~25,000（小份）
  • 时间：上午至午间食材最为新鲜,傍晚以后可能售罄。
  • 外国游客提示：因是生牛肉,请根据个人消化能力和喜好选择,也可以先尝一口再决定是否继续食用。

8. 广藏市场煎饼·汤饭集群

  • 招牌：除绿豆煎饼外的各类煎饼（海鲜煎饼·绿豆煎饼·泡菜煎饼）+ 汤饭·血肠(Sundae / 순대)
  • 外国人适配度：★★（市场氛围本身就是体验的一部分,图片菜单较多,翻译App很实用）
  • 价格（2026）：煎饼类₩8,000~15,000 / 汤饭₩10,000~14,000
  • 特色：每个摊位的招牌菜各不相同。与其在一处吃遍所有,不如多个摊位轮流品尝,这才是逛市场的正确方式。

5. 乙支路（老字号韩食·平民·光复后）

乙支路是1940~50年代以后形成的印刷·制造业街区,也是光复后北方避难民老字号店铺的聚集地。如今与时髦的啤酒屋·酒吧共存,成为本地文化的象征性街区。

9. 又来屋（1946年至今,米其林必比登推介）

  • 位置：首尔中区昌庆宫路62-29号（毗邻乙支路）
  • 招牌：平壤冷面·烤牛肉(Bulgogi / 불고기)。1946年开业——韩国现存最古老的冷面专门店之一。
  • 外国人适配度：★★★（英文菜单·图片菜单·外国常客众多）
  • 价格（2026）：平壤冷面₩16,000~18,000 / 烤牛肉₩35,000~45,000（1人份）
  • 交通：地铁2·3号线乙支路3街站(Euljiro 3-ga / 을지로 3가)5号出口步行5分钟
  • 时间：11:30开门。午间高峰12:00~13:30需等待30~40分钟,14:00以后或晚间17:30~18:30之间等待较少。
  • 英语提示：说"Cold noodles, please"即可点到平壤冷面。需要剪面时说"Please cut."
  • 注意：建议现金支付（可刷卡,但现场更偏好现金）。2人以上同行等位效率更高。

10. 平壤面屋（1985年至今）

  • 位置：首尔中区一带（靠近乙支路——建议出发前确认地址）
  • 招牌：平壤冷面。与又来屋并称为首尔平壤冷面两大劲敌。
  • 外国人适配度：★★（部分英文菜单,本地常客比例较高）
  • 价格（2026）：平壤冷面约₩16,000~18,000（价格可能变动——建议出发前确认）
  • 时间：午间等待时间与又来屋相近,上午11点刚开门时相对较快。
  • 外国游客提示：推荐给想对比两家口味的美食爱好者,建议分开两次用餐,而非一顿饭内连吃两家。

11. 乙支路明太鱼干街

  • 位置：首尔中区乙支路3街附近（乙支路3街站周边巷弄）
  • 招牌：明太鱼干（晾干的明太鱼） + 生啤酒。是1970~80年代首尔平民酒馆文化的原型。
  • 外国人适配度：★★★（外国游客眼中的隐藏名店·本地氛围浓厚·门槛低）
  • 价格（2026）：明太鱼干1条₩3,000~5,000 / 生啤酒500ml ₩4,000~5,000 / 2人份约₩20,000~40,000
  • 交通：地铁2·3号线乙支路3街站6号出口步行2分钟
  • 时间：不少店铺从白天（14:00~）就开始营业,晚间18:00~21:00是高峰。这里相对流行"白天小酌"的文化。
  • 外国游客提示：明太鱼干要用手直接撕着吃,是佐酒的下酒菜。对店员说"明太鱼干两个,啤酒两杯(노가리 2개, 맥주 2잔)"就足够了。

12. 乙支路汤饭老字号（河东馆等）

  • 位置：乙支路一带（多家老字号分布于此）
  • 招牌：牛骨汤·雪浓汤(Seolleongtang / 설렁탕)·汤饭——以牛骨长时间熬制的高汤为基底
  • 外国人适配度：★★（多数没有英文菜单,建议使用翻译App·图片菜单）
  • 价格（2026）：₩11,000~15,000
  • 外国游客提示：河东馆(Hadongkwan / 하동관)是历史悠久的牛骨汤专门店,地址·营业时间建议出发前确认（曾有过翻修·搬迁记录）。牛骨汤味道并不浓烈而是清淡,吃法是自己动手调盐调味。

6. 钟路市中心（参鸡汤·现代韩食）

13. 土俗村参鸡汤（景福宫）

  • 位置：首尔钟路区紫霞门路5街(Jahamun-ro 5-gil / 자하문로 5길)（景福宫以北·靠近青瓦台）
  • 招牌：参鸡汤——整鸡加糯米·人参·红枣炖煮而成的滋补食疗菜
  • 外国人适配度：★★★（英文菜单·外国常客多·CNN·《时代》杂志多次推荐）
  • 价格（2026）：参鸡汤₩20,000~25,000（砂锅(Ttukbaegi / 뚝배기)1人份）
  • 交通：地铁3号线景福宫站2号出口步行10分钟
  • 时间：11:30开门。三伏天（初伏·中伏·末伏,7~8月）预计等待1~2小时。工作日上午11:30~12:00刚开门时相对较快。（参见#1112夏季指南）
  • 外国游客提示：砂锅非常烫,开盖时请注意蒸汽。盐·胡椒可根据个人口味自行调节,人参吃与不吃均可。

14. 钟路小吃（参见#132）

  • 位置：钟路一带多家小吃店
  • 招牌：炒年糕(Tteokbokki / 떡볶이)·紫菜包饭(Gimbap / 김밥)·炸物·血肠——韩国街头小吃基本4大类
  • 价格（2026）：₩3,000~10,000（1人份零食价）
  • 外国人适配度：★★★（门槛低·价格实惠·适合拍照分享）
  • 外国游客提示：各店炒年糕的辣度不同。若是初次尝试,可以说"Not too spicy"或要求"不要太辣(덜 맵게)"。

15. 珍珍（麻浦）

  • 位置：首尔麻浦区(Mapo-gu / 마포구)（距钟路乘公交·地铁15分钟）
  • 招牌：韩式中餐精致餐饮,米其林一星。游走于中餐与韩食边界的菜单。（参见#1109）
  • 外国人适配度：★★★（外国常客多·英文菜单·须预约）
  • 价格（2026）：套餐₩100,000~200,000（视套餐内容而定）
  • 注意：不在钟路范围内。建议单独安排行程,不必勉强塞进钟路韩食深度动线中。

8. 实用信息（交通·支付·语言）

交通

  • 地铁：1·3·5号线覆盖钟路区域。充值T-money交通卡后使用最为方便。
  • 景福宫：3号线景福宫站 / 仁寺洞：3号线安国站 / 广藏市场：1·5号线钟路4街站 / 乙支路：2·3号线乙支路3街站
  • 出租车：通过Kakao T App叫车,支持英文界面,可刷卡支付。
  • 步行：广藏市场→乙支路3街步行约15分钟。区域间移动搭地铁更高效。

支付

  • 信用卡：大多数店铺可刷信用卡（Visa·Mastercard）
  • 现金：广藏市场摊位·部分乙支路老字号更偏好现金,甚至只收现金,建议随身携带₩50,000以内现金。
  • 小费：韩国没有小费文化,按账单金额付款即可。
  • 发票：可以要求开具发票(yeongsujeung / 영수증)。普通餐厅不适用退税优惠。

语言·沟通

  • 谷歌翻译App：拍照翻译功能可即时解读韩文菜单
  • Papago：韩语专用翻译App,支持语音输入。
  • 基本用语："请给我这个(이거 주세요)" / "多少钱(얼마예요)" / "请结账(계산해 주세요)"
  • 英文菜单：韩国之家·土俗村·又来屋·朴家绿豆煎饼均备有英文菜单。仁寺洞韩定食部分店铺·乙支路老字号则没有或不完整。

  • 中上（部分英文）：仁寺洞韩定食街部分店铺

  • 模式A 韩食深度体验：₩80,000~120,000
  • 模式B 宫廷·韩定食：₩400,000~550,000（韩国之家 + 温知苑）
  • 模式C 市场·老字号：₩50,000~90,000

按人设分类

  • 美国人设：模式A（一日覆盖多种类型）
  • 欧洲人设：模式B（偏好宫廷·艺术·历史脉络）
  • 美食爱好者·本地探索：模式C（市场·老字号深度体验）

  • 韩剧粉丝：广藏市场·仁寺洞（多处取景地）

按季节

  • 春季（4-5月）：仁寺洞·广藏市场 + 宫殿漫步,天气最宜人。

  • 秋季（10-11月）：韩定食（秋季食材——松茸·斑鰶·传统酱料）,红叶 + 韩食组合。
  • 冬季（12-2月）：汤饭·牛骨汤·火锅(Jeongol / 전골)（乙支路老字号）。一碗热汤成为旅程亮点的季节。

10. 韩食礼仪（外国游客适配指南）

应该做

  • 长辈·年长者先动筷（或等待对方说"请用"再开始）
  • 用双手递接饮料·食物（单手会显得失礼）
  • 不端起饭碗——韩食讲究碗放在桌上用餐
  • 筷子和勺子都要用（饭·汤用勺子,小菜用筷子）
  • 小菜可以共享,吃完也没关系（大多可免费续加——"请再给一点(더 주세요)"）
  • 韩定食：碟数的含义（12碟 = 两班标准·5碟 = 平民标准）

不应该做

  • 不要在餐桌上擤鼻涕
  • 不要把筷子插在饭上（象征祭祀——禁忌）
  • 剩很多饭菜不算美德（韩国更看重吃光）
  • 倒酒时不要单手（双手才是礼貌）
  • 不要用自己的筷子直接把食物夹给别人的筷子（会让人联想到祭祀仪式）

结账·小费

  • 韩国没有小费文化（按账单100%付款）
  • 通常由一人统一结账（比起AA制,更常见的是一人先付总额）
  • 刷卡和现金大多都可以,广藏市场摊位建议用现金

常见问题

Q1. 在广藏市场怎样避免被"宰客"？

入座前请先要求出示菜单。2026年市场行情为绿豆煎饼1张₩9,000~10,000,迷你紫菜包饭1卷₩3,000~5,000。也可以先口头问价("多少钱？"/얼마예요)。

Q2. 第一次尝试平壤冷面,去哪家比较好？

从外国游客的可及性来看,又来屋更适合。有英文菜单·图片菜单,外国常客也多。第一次品尝可能会觉得味道偏淡,逐次加入醋和芥末就能感受到风味变化。若需要,店家会用剪刀帮忙剪断面条。

Q3. 韩国之家和温知苑两家都去预算有压力,只能选一家的话？

若是第一次体验宫廷韩食,想要演出·韩服等文化套装体验,选韩国之家;若想体验米其林韩食精致餐饮和现代重新演绎的套餐,选温知苑。预算在₩100,000~150,000以内的话,韩国之家的午餐套餐性价比更高。

Q4. 素食者·清真饮食者该怎么办？

钟路韩食整体以肉类·海鲜为基础。完全素食比较困难,但仁寺洞韩定食部分店铺若提前提出要求,可以调整为素食搭配（建议提前确认）。清真认证店铺在钟路区域几乎没有——建议改用梨泰院清真集群。

Q5. 如果在钟路只吃一顿饭,推荐哪家？

若是初次到访,土俗村参鸡汤（可与景福宫观光串联）最为稳妥。想体验市场,选广藏市场绿豆煎饼 + 迷你紫菜包饭。想要一顿特别的正餐,选又来屋平壤冷面。这三家都备有英文菜单或图片菜单,点餐门槛不高。
