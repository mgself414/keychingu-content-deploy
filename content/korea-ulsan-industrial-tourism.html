🎯 왜 울산 산업관광 가이드인가

울산 = 한국 #1 GDP 인당 (5만+ 달러)·세계 #1 조선·세계 #5 자동차·정유 1번지. 외국인 페인포인트 = (a) "산업관광 = 외국인 X" 잘못된 인식 (b) 현대중공업 (세계 #1 조선·1972년~)·현대자동차 (세계 #5 자동차·연 300만대) = 글로벌 STEM 매니아 매트릭스 (c) 울산벽화마을 = 산업 + 예술 매니아 (d) 사전 예약 필수·영문 가이드 일부 (e) 매니아·학자·STEM 매트릭스 fit.

⚠ 외국인 자주 실수 5가지

1. "산업관광 = 외국인 X": 울산 산업관광 = STEM·산업 매니아 매트릭스·사전 예약 + 영문 가이드.

2. "현대중공업 = 견학 불가능": 사전 예약 필수·1-2주 전·영문 가이드 일부.

3. "현대자동차 = 박물관만": 박물관 + 견학 (사전 예약) = 매니아 매트릭스.

4. "벽화마을 = 일반 마을": 산업 + 예술 매트릭스·MZ + 인스타 fit·자유 입장.

5. "정유 = 외국인 X": SK이노베이션·S-Oil = 사전 예약 + 매니아 매트릭스·전망대 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: 코스 A (자유) = 박물관 + 벽화마을 + 산업단지 전망.

2. 매니아 1순위: 코스 B (사전 예약) = 현대중공업 + 자동차 견학 + 영문 가이드.

3. 사전 예약: 1-2주 전·울산광역시 공식 사이트 + 영문.

4. 시즌: 봄·가을 베스트·여름·겨울 = 실내 박물관 + 견학 매트릭스.

5. 알레르기·식이 제한: 산업관광 = 식사·카페 매트릭스 일반 표준.

6. 추천 페르소나: 가족·시니어 = 박물관 + 벽화마을 / MZ·인스타 = 벽화마을 + 전망 / 매니아·STEM = 현대중공업 + 자동차 견학.

⚠ 의료·안전 disclaimer

산업관광 = 안전 + 사전 교육 + 안전모·재킷 제공. 현대중공업·자동차 견학 = 안전 시그너 풀세트·임신부·시니어·어린이 = 일부 제한 (사전 확인). 응급 ☎ 1339 (영문).
