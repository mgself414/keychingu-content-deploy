🎯 本指南的使用方法

撕开便利店的面包袋，先碰到手的不是面包，而是一张透明小卡。连着几张都是同一个成员，你就会再买一袋。韩国的联名商品大多是这种结构。本文整理韩国联名有哪些类型，并按类型列出根据企业官方新闻稿确认的过往案例，附上年份。了解了企划结构，在首尔遇到新的联名时，就能一眼看出哪些是限定、哪些是随机。

这里写到的商品全部是已经结束或即将结束的限时商品。现在在哪里买，以及常年做联名的门店和官方渠道，请看寻找韩国联名商品的方法 — 常设门店(光野@首尔·K-POP广场弘大·Ktown4u COEX·Olive Young明洞)与快闪店·官方渠道的看法。

🍞 便利店 × K-pop艺人 — 面包·甜点里的随机周边

最常见的类型。在印有艺人形象的包装里随机放入小卡或贴纸(Ddibuseal / 띠부씰)。BGF Retail解释说，烘焙类商品在3~5千韩元档，负担不大，而随机周边会刺激粉丝的收集欲(BGF Retail官方新闻稿 2026-09-15)。

  • CU × RESCENE (RESCENE / 리센느)「BAKE405」5款 — 2026年9月，限时 — 每位成员负责一种自己喜欢的口味。Wonyi (Wonyi / 원이) 的玉米奶油面包，Minami (Minami / 미나미) 的菠萝包，May (May / 메이) 的肉桂卷，Jena (Jena / 제나) 的草莓三明治，Liv (Liv / 리브) 的巧克力糖饼 (Hotteok / 호떡，韩式夹馅甜煎饼)。9月17日起陆续上市，每包随机附赠27种限定透明小卡中的1张。成员们直接参与了研发过程(BGF Retail官方新闻稿 2026-09-15)。10月的新闻稿称RESCENE面包累计销量已超过100万个(BGF Retail官方新闻稿 2026-10-13)
  • CU × RIIZE (RIIZE / 라이즈)「Little RIIZE」6款 — 2026年6~7月，已结束的商品 — 为纪念RIIZE第二张迷你专辑「II」发行而推出。由3款面包(草莓布里欧 (Strawberry Butsse / 딸기 붓세)·蜂蜜丹麦 (Honey Danish / 허니 데니쉬)·巧克力安巴 (Choco Angba / 초코앙바))附54种贴纸(Ddibuseal / 띠부씰)中的1个，2款马卡龙附12种环氧贴纸中的1个，以及7月8日上市的瓶装糖果1款组成。快闪店在CU圣水甜点公园店 (Seongsu Dessert Park-jeom / 성수디저트파크점) 于6月20日~7月5日开了16天。BGF Retail写道，这家门店的外国顾客销售占比超过30%(BGF Retail官方新闻稿 2026-06-15)
  • CU × ITZY「Twinji」(Twinji / 트윈지) — 2024年10月，已结束的商品 — 采用了把5位成员画成猫的角色「Twinji」。Twinji马卡龙 (Twinji Macaron / 트윈지카롱，5个装9,500韩元) 和Twinji果冻 (Twinji Jelly / 트윈지젤리，2,500韩元) 里附有贴纸。快闪店在CU奥林匹克广场店 (Olympic Gwangjang-jeom / 올림픽광장점)·弘大想象店 (Hongdae Sangsang-jeom / 홍대상상점)·新村Lemeilleur店 (Sinchon Lemeilleur-jeom / 신촌르메이에르점) 开到10月28日(BGF Retail官方新闻稿 2024-10-15)

在同一份新闻稿里，BGF Retail总结说已与aespa·Key·ITZY·TXT·CHUU·安昭熙 (An Sohui / 안소희)·QWER等推出过联名商品(BGF Retail官方新闻稿 2026-06-15)。

🎵 便利店 × 音乐 — 卖歌的便利店

这类是把歌放进食品里，或者直接陈列专辑。

  • CU唱歌糖果 — 2026年7月(第1弹)·9月(第2弹)·10月(第3弹) — 打开电源咬住糖果，振动经由下颌骨传导（骨传导方式），可以听到约40秒的歌。第3弹(5,000韩元)公布于10月14日上市，随机装入RESCENE「Runaway」、CHUU「XO, My Cyberlove」、EVNNE (EVNNE / 이븐)「Baeteo」(Baeteo / 뱉어) 中的一首。第1弹是电视剧「背着善宰跑」(Eoputgo Twyeo / 선재 업고 튀어) 的OST「Sonagi」(Sonagi / 소나기)，第2弹是(G)I-DLE (i-dle / 아이들) 的歌(BGF Retail官方新闻稿 2026-10-13)。第3弹现在门店里有没有，我们没能确认
  • 偶像专辑销售 — CU主要在弘大 (Hongdae / 홍대)、圣水 (Seongsu / 성수) 等外国人访问多的商圈卖专辑。2026年卖过ENHYPEN·TOMORROW X TOGETHER·CORTIS的专辑(BGF Retail官方新闻稿 2026-10-13)
  • CU「CHUU-High」(Chyu-hai / 츄-하이) — 2024年2月 — 以单飞艺人CHUU为模特的高球鸡尾酒(BGF Retail官方新闻稿 2024-02-07)。因为是酒类，结账时可能被要求核对年龄，请带好护照

💄 美妆 × K-pop — 长销品的限定版

与其做新产品，不如给本来就卖得好的产品换上艺人设计，这是这一类型的做法。

  • 防弹少年团 (Bangtan Sonyeondan / 방탄소년단) | 爱茉莉太平洋唇膜紫色版 — 2021年11月，已结束的商品 — 以兰芝 (Laneige / 라네즈) 睡眠唇膜为基础的限定版。为纪念「BTS PERMISSION TO DANCE ON STAGE」巡演而企划，11月26日起在爱茉莉商城 (Amoremall / 아모레몰) 销售(爱茉莉太平洋官方新闻室 2021-11-22)
  • 防弹少年团 (Bangtan Sonyeondan / 방탄소년단) | 爱茉莉太平洋唇膜Lip & Pop版 — 2022年10月，已结束的商品 — 第二次合作的限定版。10月24日起在线上爱茉莉商城 (Amoremall / 아모레몰) 销售(爱茉莉太平洋官方新闻室 2022-10-24)

两次的销售渠道都是线上爱茉莉商城 (Amoremall / 아모레몰)。美妆联名有时只在线上单独发售，而不是在门店，所以先看公告里的销售渠道。

🧸 角色 × 美妆·零食 — 不是K-pop也能联名

这类使用国内外角色来代替偶像。经常只在Olive Young (Olive Young / 올리브영) 这样的特定渠道单独推出。

  • 梦妆 (Mise-en-scène / 미쟝센) Hello Cream残忙鲁比版·悦莱雅 (Illiyoon / 일리윤) 三丽鸥角色版 — 2023年5月，已结束的商品 — 残忙鲁比 (Janmang Loopy / 잔망루피) 版在Olive Young (Olive Young / 올리브영)·爱茉莉商城 (Amoremall / 아모레몰)·酷澎 (Coupang / 쿠팡)·Market Kurly (Market Kurly / 마켓컬리) 等线上商城销售，三丽鸥角色版 (Sanrio Characters / 산리오캐릭터즈) 在Olive Young (Olive Young / 올리브영) 渠道销售。三丽鸥商品和周边在4月官方商城预购开启后一天，备好的库存就卖光了(爱茉莉太平洋官方新闻室 2023-05-02)
  • CU帕特与马特 (Pat & Mat / 패트와 매트) 对半棒 (Banban Bar / 반반바) — 2026年7月 — 用仿照角色造型的专用模具做成的草莓、芒果冰淇淋(3,900韩元)。同月15日还公布将推出冰冻Hello Kitty冰沙·冰冻库洛米冰沙(各5,900韩元)(BGF Retail官方新闻稿 2026-07-13)。这是夏季商品，现在是否在售我们没能确认

🧰 联名商品实用信息 — 独自、预约、支付、交通

  • 看法: 新闻稿里反复出现的词是「业界独家」「陆续上市」「随机附赠」「快闪○天」。独家就只在那个连锁品牌有，陆续上市则每个日期的品项不同。随机的话，可能要买好几个才能抽到想要的成员(BGF Retail官方新闻稿 2026-06-15·2026-09-15)
  • 独自: 便利店·Olive Young (Olive Young / 올리브영) 的商品一个人也容易买。快闪店只在特定的几家门店短暂开设(ITZY 3家，RIIZE 1家 — BGF Retail官方新闻稿)
  • 预约: 像爱茉莉太平洋的三丽鸥版那样，有时官方商城的预购会先开启(爱茉莉太平洋官方新闻室 2023-05-02)。预购是否接受外国信用卡和海外配送，我们没能确认
  • 支付: 外国人韩国支付系统深度探索，无人收银台见韩国自助结账·夜间无人便利店零慌张流程图 — 从刷卡认证到结账全程
  • 交通·门店: 各连锁品牌的差异见韩国便利店四大品牌全面对比 — CU·GS25·7-Eleven·emart24，该走进哪家门 deep dive。常设联名门店见下方相关内容中的「寻找韩国联名商品的方法」
  • 语言不通时: 语言不通时的礼仪 — 翻译App与自助点餐机时代的点餐礼仪

⚠ 常见错误4

1. 「去买以前报道里看到的联名」 — 这里写到的RIIZE·ITZY·防弹少年团联名，全部是销售期限固定的限定商品(BGF Retail官方新闻稿·爱茉莉太平洋新闻室)。现在在售的商品要重新到官方渠道确认

2. 「只买一个就会出现想要的成员的小卡」 — RESCENE面包是27种中随机1张，RIIZE面包是54种贴纸中随机1个(BGF Retail官方新闻稿)

3. 「快闪店在那个连锁品牌的任何门店都有」 — 联名快闪店是在指定的几家门店，限定期间开设(BGF Retail官方新闻稿 2024-10-15·2026-06-15)

4. 「美妆联名去门店就有」 — 防弹少年团的两次版本都是在线上爱茉莉商城 (Amoremall / 아모레몰) 销售(爱茉莉太平洋官方新闻室)
