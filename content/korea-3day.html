ISSUE 03 · #264 · 2026-05-20

🎯 왜 외국인 3일 코스인가

외국인 한국 inbound 가장 흔한 일정 = 2박3일 단기. 비즈니스 + 짧은 휴가 외국인 매니아 1번지. #228 7일 Variant — 핵심 3일 압축 풀세트.

★ 3일 풀세트 매트릭스

Day 1 — 도착 + 명동·N서울타워

  • 09:00 인천공항 도착 → 공항철도 (#237) → 호텔 (명동·강남·홍대)
  • 12:00 명동 점심 (#13·#172 명동 풀공략)
  • 14:00 명동 면세 + 쇼핑 (롯데·신세계·면세점)
  • 17:00 N서울타워 + 케이블카 (외국인 1순위)
  • 20:00 명동 한식 (#234 한정식 또는 K-BBQ)

Day 2 — 궁궐·한옥·홍대

  • 09:00 경복궁 + 한복 체험 (#207 사찰·궁궐)
  • 12:00 북촌 한옥마을 (#226 한옥)
  • 14:00 익선동 한옥 카페 (#225 카페)
  • 17:00 홍대·연남 (#138 홍대 풀공략)
  • 20:00 홍대 야시장·이자카야

Day 3 — 강남·한강·출국

  • 09:00 강남 K-pop (#221) + 가로수길
  • 12:00 강남 한식 (#143 강남 한식)
  • 14:00 반포 한강 + 달빛무지개분수 (#243 한강)
  • 17:00 면세 잠시 + 인천공항 (#238 T-money 환급)
  • 20:00 출국

⚠ 외국인 3일 자주 실수 3가지

1. "3일 = 모든 spot OK": 3일 = 핵심 3축 (명동·궁궐·강남) + 1개 area 추가만. 5일·7일 (#228) 풀세트와 차별.

2. "3일 = K-pop 매니아 어려움": K-pop 매니아 = Day 3 강남·HYBE 인사이트 + 최소 1개 시간.

3. "3일 = 외국인 환급 잊음": Day 3 인천공항 환급 (Tax Refund) = 출국 전 90분 여유 필수.

Variant 3일

  • A 단기 풀공략 (이 가이드 표준): 명동·궁궐·홍대·강남 + 한강
  • B K-pop 매니아: HYBE·SM·YG·강남 → 명동 → 잠실 (#82)
  • C 음식 매니아: 광장시장 → 강남 한식 → 홍대 야시장
  • D 자연·산책: 북한산 → 한강 → 서울숲
