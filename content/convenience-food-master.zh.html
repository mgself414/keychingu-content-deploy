为什么要做类别总整理 — 别在货架前僵住

韩国便利店的货架一家门店就有数千 SKU — 初次到访的外国游客往往不知道该拿什么，最后只抱着一瓶香蕉牛奶 (Banana Milk / 바나나맛우유) 走出来。本指南把便利店美食画成9大类别地图：每个类别都包含"经典款（常年在架的验证款）+ 潮流款（当下走红的系列）+ 挑选方法"，让你走进任何一家便利店（#1261）都能读懂货架。

类别 1. 🍙 三角饭团 (Samgak Gimbap / 삼각김밥)·紫菜包饭 (Gimbap / 김밥)·便当 (Dosirak / 도시락) — 一顿饭的基本款

  • 经典: 金枪鱼蛋黄酱 (Chamchi Mayo / 참치마요) 三角饭团（稳居第一）·全州拌饭 (Jeonju Bibim / 전주비빔) · 便当（金惠子 (Kim Hye-ja / 김혜자)=GS25·白种元 (Baek Jong-won / 백종원) 系列=CU 等品牌招牌）
  • 潮流: 主厨·综艺联名简餐（黑白大厨 (Culinary Class Wars / 흑백요리사) 系列等）— 便利店一餐的高端化
  • 挑选方法: 三角饭团按包装编号顺序拆（①拉开 ②③剥离）· 便当确认微波炉加热时间标注 · 早上常缺货
  • cross-ref: #848 紫菜包饭渠道比较 · #890 早餐渠道比较

类别 2. 🍜 拉面 (Ramyeon / 라면)（杯装·袋装）— 热水机存在的理由

  • 经典: 辛拉面 (Shin Ramyun / 신라면)·真拉面 (Jin Ramen / 진라면) 杯面 · 火鸡面 (Buldak / 불닭볶음면)（辣味挑战鼻祖）· 炸酱风味面 (Chapagetti / 짜파게티)
  • 潮流: 便利店限定联名拉面 · 低糖·非油炸面系列
  • 挑选方法: 热水机免费使用（#289）— 杯面+三角饭团是国民组合。辣度等级按 火鸡面>辛拉面>真拉面 记。
  • cross-ref: #833 拉面×泡菜 (Kimchi / 김치) 搭配 · #813 面类矩阵

类别 3. 🍪 零食·薯片 — 国民饼干与联名薯片

  • 经典: 蜂蜜黄油薯片 (Honey Butter Chip / 허니버터칩) · 乌龟脆 (Kkobuk Chip / 꼬북칩)（巧克力吉拿棒味在海外爆红）· 波卡薯片 (Poca Chip / 포카칩) · 虾条 (Saewookkang / 새우깡) · 鱿鱼花生 (Ojingeo Ttangkong / 오징어땅콩)
  • 潮流: 炸鸡品牌联名薯片（校村蜂蜜康宝 (Kyochon Honey Combo / 교촌 허니콤보) 味系列等还原真实菜单型）· 辣味系列
  • 挑选方法: 袋子大又轻，注意行李箱容积 — 伴手礼选迷你包·盒装更划算。
  • cross-ref: #1218 潮流 K-零食

类别 4. 🧁 甜点·烘焙 — 当下便利店的最前线

  • 经典: 延世牛奶奶油面包 (Yonsei Milk Cream Bread / 연세우유 크림빵) 系列（掰成两半打卡是流行文法）· 瑞士卷·卡斯提拉 (Castella / 카스텔라)
  • 潮流: 迪拜巧克力衍生（酥丝+开心果 — 向曲奇·布朗尼·马卡龙扩散）· 超写实甜点（做成咸食造型的甜味甜点）· 水果三明治·可颂华夫 (Croffle / 크로플)
  • 挑选方法: 话题款要拼上午补货刚到的时段（#1261 情境1）— 先扫冷藏甜点货架。
  • 注意: 这个类别停产·换代最快 — 要用"找这一系列的后续作"的感觉逛。

类别 5. 🍦 冰淇淋 — 四季的偶像

  • 经典: 梅露娜 (Melona / 메로나) · 猪仔雪糕 (Dwaeji Bar / 돼지바) · 世界杯蛋筒 (World Cone / 월드콘) · 栗子雪糕 (Babambar / 바밤바) · 鲫鱼豆沙雪糕 (Bungeo Samanco / 붕어싸만코)
  • 潮流: 甜点联名冰品（迪拜巧克力·提拉米苏系列）· 超写实冰品
  • 挑选方法: 冬天也照吃才是韩式（#752 冬季文化）— 冷冻柜一般在店内深处。

类别 6. 🥛 饮料① 牛奶·乳制品 — 香蕉牛奶之国

  • 经典: 香蕉牛奶（坛子造型 = 纪念照打卡角度）· 草莓牛奶 · 巧克力多蒙 (Choco Emong / 초코에몽) · 养乐多 (Yakult / 야쿠르트)（Grand 大容量装）
  • 潮流: 零糖·低糖加工乳 · 蛋白质饮料（健身热潮）
  • 挑选方法: 坛子香蕉牛奶插吸管打卡是标准文法 — 记得在收银台旁拿吸管。

类别 7. ☕ 饮料② 咖啡·茶 — 从千元档美式开始

  • 经典: 罐装·杯装咖啡（康塔塔 (Cantata / 칸타타)·乔治亚 (Georgia / 조지아)·T.O.P）· 现磨即饮机器咖啡（超低价美式）
  • 潮流: 康普茶·零糖茶饮 · 低因咖啡线
  • 挑选方法: 冰杯+软袋饮料组合是夏季标配 — 结账后自行组装。

类别 8. 🥤 饮料③ 碳酸·电解质·混搭玩法 — 便利店 mixology

  • 经典: 七星汽水 (Chilsung Cider / 칠성사이다)·可乐 · 电解质饮料（宝矿力·佳得乐）· 食醯 (Sikhye / 식혜)·米制饮料（传统系列，#1192）
  • 潮流: 饮料混搭配方 — 在冰杯里混两种饮料的玩法（巴卡斯 (Bacchus / 박카스)+汤力水系"冰博士" (Eolbaksa / 얼박사) 式组合在 SNS 扩散）· 零糖碳酸全线化
  • 挑选方法: 混搭玩法只需一个冰杯 + 两瓶材料饮料 — 在试吃台完成。

类别 9. 🌭 热食·下酒菜 — 收银台旁的诱惑

  • 经典: 热棒 (Hot Bar / 핫바) · 马苏里拉热狗 (Mozzarella Hot Dog / 모짜렐라 핫도그) · 水煮蛋 · 烤红薯（冬季）· 炸鸡块
  • 潮流: 现场即烹扩大（炸鸡·鱼糕 (Eomuk / 어묵)）— 便利店的小吃店化
  • 挑选方法: 热食在柜台点单 — 用手指一指就够。下酒菜区（明太幼鱼干 (Nogari / 노가리)·肉干）与4罐装啤酒是成套文法（#843 夜宵矩阵）。

🎯 实战技巧 5 — 读懂货架的方法

Tip 1. 先从 1+1 贴纸扫起

同一类别里不知道买哪个时，活动贴纸（1+1·2+1）就是答案 — 按月更新（#1261）。

Tip 2. 经典一半 + 潮流一半

把购物篮按"验证过的经典一半 + 第一次见的新品一半"来配 — 失败也有趣，成功就是新发现。

Tip 3. 用好试吃设备

热水机·微波炉·试吃台都免费（#289）。买完当场就吃才是便利店文化。

Tip 4. 伴手礼留到最后一天集中买

零食占体积、甜点要冷藏 — 旅行途中吃就好，要带回去的留到最后一天去机场前再补齐才是正解（#26）。

Tip 5. 用"系列"来记忆

单个商品会停产，但系列会留下 — 像"迪拜巧克力衍生"·"联名薯片"·"超写实甜点"这样用系列名读货架，新品再怎么换也不会迷路。

⚠️ 准确性验证·注意事项

验证时点: 2026-07-21（基于公开流通·潮流信息，网络调研交叉核对）

已验证: 经典单品（香蕉牛奶·梅露娜·蜂蜜黄油薯片·火鸡面等）·试吃设备·1+1 文化已与既有 deep dive（#26·#289·#1218）交叉验证

验证不足（务必再确认）:

  • 潮流单品（迪拜巧克力衍生·超写实·联名薯片·混搭饮料）停产·更替快 — 不保证到店时在售，请按"系列"解读
  • 价格随商品·活动变动 — 本篇刻意省略单品价格（以货架为准）
  • 各品牌铺货差异见 #1261

总体注意:

  • 过敏原标注以韩文为主 — 坚果（开心果等）·乳制品过敏请用翻译 App 确认成分。
  • 冷藏甜点建议当天食用。
  • 垃圾要分类（罐·PET·一般）— 试吃台旁有分类箱。

FAQ 6 — 外国游客常问的便利店美食问题

Q1. 只买5样的话？

  • 金枪鱼蛋黄酱三角饭团 + 杯面 + 香蕉牛奶 + 话题甜点1个 + 乌龟脆 — 经典4 + 潮流1。

Q2. 和 #26 零食指南有什么区别？

  • #26 是入门18选（该买什么），本篇是类别全地图（怎么读货架）。入门看 #26 → 进阶看本篇。

Q3. TikTok 上看到的甜点找不到？

  • 新品寿命短 — 找同系列的后续作，或按 CU→GS25 顺序巡店（#1261）。

Q4. 怕辣怎么办？

  • 火鸡面是顶级辣度 — 从真拉面温和款·炸酱风味面开始。牛奶（类别6）是解辣剂。

Q5. 能当早餐吗？

  • 能 — 三角饭团·三明治·杯装浓汤·现磨咖啡组合（#890 早餐渠道比较）。但人气便当早上常缺货。

Q6. 混搭饮料是什么？

  • 在冰杯里混两种饮料的 SNS 玩法 — 材料货架上全有，没有标准答案。在试吃台做实验。
