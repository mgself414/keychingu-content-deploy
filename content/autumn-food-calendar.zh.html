🎯 为什么"只有秋天这一季" — 出发前必须先知道的理由

在韩国饮食文化里，秋天是一年中时令密度最高的季节。以下6种食材，只要9~11月的时令窗口一关，就要等到明年才能再吃到 (冷冻·养殖除外)。如果你的旅行日期正好落在秋天，到底是哪一周来会直接决定你能吃到什么 — 提前对照这份日历规划吧。

时令 9月 10月 11月

大虾 (Daeha / 대하，明虾) ◎ 开始 ◎ 最佳期 △

① 六种时令食材完整概览

1. 斑鰶鱼 — "连离家出走的儿媳妇都会回来"

  • 韩国最著名的秋季美食俗语里的那条鱼 —— 离家出走的儿媳妇，闻到烤鱼香也会回来 (집 나간 며느리도 돌아온다)，字面意思是"连离家出走的儿媳妇都会回来"，形容烤斑鰶鱼的香味有多诱人。9~10月鱼身开始上油，生鱼片和烤鱼都进入最佳状态。
  • 吃法：连骨切片的生鱼片 (세꼬시，源自日语借词"sebagoshi/segoshi")或撒粗盐整条烤。每人₩15,000~25,000 (约合$11~18 / 约80~140元人民币 / 约1,600~2,700日元)。
  • 在哪吃：鹭梁津 (Noryangjin / 노량진)、蘇萊浦口 (Soraepogu / 소래포구) 等水产市场 (市场路线比较见《水产市场路线比较指南》)，或作为秋季路边摊 (Yajang / 야장，深夜营业的韩式露天大排档) 巷子里的时令下酒菜。

2. 大虾 — 盐烤的季节

  • 9~10月是西海岸的时令期。把粗盐铺满锅底，整只虾带壳烤的大虾盐烤 (Sogeum-gui / 소금구이) 是标配吃法 —— 虾身在锅里蜷起、变红的瞬间，是韩国秋天的招牌画面。
  • 野生与养殖的区别：野生大虾性子急，捕捞后大多已经死亡才上市——所以水缸里"活蹦乱跳的大虾"往往是养殖的白腿虾 (Huindari-saeu / 흰다리새우)，别被骗了 (味道差异其实不大)。
  • 每公斤约₩30,000~50,000 (行情波动很大)。蘇萊浦口一带往年9~10月通常会举办虾类·大虾时令活动 (具体日期请到现场确认)。

3. 梭子蟹 — 秋天要吃公蟹

  • 春天的梭子蟹要挑蟹黄满满的母蟹，秋天的梭子蟹则要挑蟹肉饱满的公蟹——同一种蟹，不同季节，要吃的部位完全不同。
  • 吃法：清蒸蟹或辣汤蟹，还有下饭神器酱油蟹 (간장게장，用酱油腌渍的生蟹)。酱油蟹套餐 (Jeongsik / 정식，含米饭小菜的正餐套餐) 约₩25,000~45,000。
  • 海鲜基础知识见《海鲜六种概览指南》，直接在市场买好再去蘸酱餐厅 (Chojang-jip / 초장집，按位收费、帮你把买来的海鲜配辣醋酱上桌的餐厅) 吃的方法见《水产市场路线比较指南》。

4. 松茸 — 一年中最短也最贵的窗口期

  • 9月中旬到10月上旬，满打满算只有三周左右。因为无法人工栽培、只能靠野生采摘，松茸是韩国秋季美食里价格最高的品项 (视行情不同，每100克要价数万韩元)。
  • 游客的入手方式：在韩定食 (Hanjeongsik / 한정식，多道菜的韩式套餐) 餐厅或烤肉店点"松茸套餐"，或者试试松茸牛肉烤 (松茸配牛肉一起烤)——不必特地跑到襄阳 (Yangyang / 양양)、奉化 (Bonghwa / 봉화) 等产地，首尔的韩定食餐厅在秋季也会推出限定菜单。
  • 香气才是重点——烤到微微上色、蘸一点盐吃，才是标准吃法。

5. 软柿与脆柿 — 晚秋的甜点

  • 10月末到11月，柿子成熟了。软糯的软柿 (Hongsi / 홍시，熟透的软柿子，可以像布丁一样用勺子挖着吃) 和硬脆的脆柿 (Dan-gam / 단감，削皮当水果吃的甜柿子) 是同一棵树上的两种不同吃法。
  • 咖啡厅版本 (软柿刨冰、柿子甜点)可参见《韩国秋季甜品地图》。

6. 新栗与烤栗子 — 街头的秋天味道

  • 10月起，街边会出现烤栗子 (Gunbam / 군밤) 小推车——这是一路延续到冬天的路边小吃季的开端。一袋约₩5,000。
  • 公州栗子 (Gongju albam / 공주 알밤，公州特产的优质板栗) 等产地名物，可以和首尔近郊一日游行程搭配——参见《加平·杨平秋季赏枫一日游指南》或《江原·全罗秋季KTX一日游指南》。

② 去哪吃 — 三种游客动线模式

模式 动线 适合谁
市场直购法 在鹭梁津或蘇萊浦口买好斑鰶鱼、大虾、梭子蟹，再到蘸酱餐厅吃 (另付上桌费) 以美食为目的的旅行者 (参见《水产市场路线比较指南》)
路边摊时令下酒菜 在乙支路 (Euljiro / 을지로)、新堂 (Sindang / 신당) 一带的路边摊吃斑鰶鱼烤、大虾烤等时令菜 适合接在晚间行程后 (参见《明洞→乙支路夜间徒步路线指南》《新堂洞指南》)
韩定食套餐 松茸、蟹酱、软柿一次吃齐——需要预约 追求轻松、适合家庭出行
