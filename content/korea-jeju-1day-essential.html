🎯 왜 제주도 가이드인가

제주도 (Jeju Island) = 한국 #1 섬·UNESCO 자연유산 2007 + 세계지질공원 2010·한라산 (1947m·한국 #1 산)·성산일출봉 (UNESCO)·우도·협재 해변·흑돼지·해녀·갈치회. 외국인 페인포인트 = (a) "제주 = 일반 섬" 잘못된 인식 (b) UNESCO 자연유산 2007 (한라산·성산일출봉·거문오름 용암동굴계) (c) 한라산 = 한국 #1 산·겨울 백록담 매트릭스 #1 (d) 성산일출봉 = UNESCO 일출 매트릭스 #1 (e) 흑돼지·해녀·갈치회 시그너 매트릭스 (f) 비행 1시간·1박+ 권장.

본 가이드는 4축 12 시그니처 + 1박 풀데이 + UNESCO 자연 + 외국인 영문.

① 한라산 (1947m·UNESCO 2007)

  • 시그니처: 한국 #1 산·1947m·UNESCO 자연유산 2007·백록담 (정상 호수)
  • 외국인 친화도: ★★★★★ (영문 풀세트·hiking + 가족)
  • 추천: 윗세오름·영실 = 외국인 매트릭스·정상 = 매니아 매트릭스 5-7h

② 성산일출봉 (UNESCO 2007)

  • 시그니처: UNESCO 자연유산 2007·일출 매트릭스 #1·새해 1/1 매트릭스
  • 외국인 친화도: ★★★★★ (영문·MZ + 매니아)
  • 시간: 04:00~20:00·5,000원

③ 해변 매트릭스 (협재·함덕·중문)

  • 시그니처: 협재 (서쪽·에메랄드)·함덕 (북쪽·MZ)·중문 (남쪽·5성 호텔)
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족)

④ 제주 시그너 음식 (흑돼지·해녀·갈치회)

  • 외국인 친화도: ★★★★★ (영문 + 결제·외국인 매트릭스)

⚠ 외국인 자주 실수 5가지

1. "제주 = 일반 섬": UNESCO 자연유산 2007·세계지질공원 2010·한국 #1 섬 매트릭스.

2. "한라산 = 일반 산": 한국 #1·1947m·UNESCO·백록담.

⚙ FAQ 6개

1. 외국인 입문 1순위: 한라산 + 성산일출봉 + 협재 + 흑돼지 = 2박 3일.

2. 한라산 등산 코스: 윗세오름·영실 = 외국인 매트릭스·정상 = 매니아 5-7h.

3. 성산일출봉 일출: 새해 1/1·연중 OK·04:30~05:30 도착 권장 (시즌별).

5. 렌터카: 제주 = 렌터카 매트릭스 #1·국제운전면허 필수.

6. 추천 페르소나: 가족·시니어 = 협재 + 흑돼지 / MZ·인스타 = 우도 + 함덕 / 매니아 = 한라산 정상 + 1박 풀세트.

👥 5 Segment 동선 추천

혼자 (Solo Traveler)

  • 추천: 1일 풀데이 효율 매트릭스 (KTX/항공 + 시내 핵심 4축 풀세트)
  • 예산: 100,000~180,000원/인 (당일)·150,000~250,000원/인 (1박)
  • 시그너: 카페·인스타·박물관·매니아 매트릭스

커플 (Couple)

  • 추천: 1박 매니아 매트릭스 (저녁 + 야경 + 호텔 + 다음 날 풀세트)
  • 예산: 250,000~500,000원/2인 (1박)
  • 시그너: 야경·해변·한정식·매니아 매트릭스

가족 (Family with Kids)

  • 추천: 안전·교육·박물관·체험 매트릭스 (가족 친화 매장 + 안전 메뉴)
  • 예산: 200,000~400,000원/4인 (당일)·400,000~800,000원/4인 (1박)
  • 시그너: 박물관·체험·안전 메뉴·키 제한 라이드 사전 확인

MZ·인스타 (Millennial/Gen-Z)

  • 추천: 인스타 + 카페 + 야경 + 매니아 매트릭스
  • 예산: 80,000~150,000원/인 (당일)
  • 시그너: 인스타 1번지·카페 cluster·MZ 매장·한복·굿즈 매트릭스

예산형 (Budget Traveler)

  • 추천: 무료 입장 매트릭스 (자연·공원·일부 박물관) + 길거리 음식
  • 예산: 30,000~80,000원/인 (당일)
  • 시그너: 무료 자연·시장·길거리 음식·전국 시외버스 활용
