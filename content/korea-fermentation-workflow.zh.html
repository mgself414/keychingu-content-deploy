🎯 为什么选择韩国发酵食品工作流程指南

即使你知道[#849 6种发酵食品矩阵](#849) — 点餐、炖韩餐、搭配都是分开的。韩国发酵食品是 (a) 所有韩国食品的基础（豆酱炖菜、红辣椒酱拌饭、酱油调味料） (b) 餐厅菜单和家庭烹饪的区别 (c) 免税店真空包装 = 回国礼物#1 (d) 酱德台村（淳昌·潭阳）体验。外国人（1）不知道发酵食品是否=单独的菜单，（2）不知道大酱和红辣椒酱的强度，（3）对草药和健康益处有一定了解，（4）对购买和进口法规感到困惑。本指南是5步+韩国菜炖菜矩阵+英语口语+免税指南。

★ 5 步工作流程概览

步骤 行动 时间 外国人的要点
1️⃣ 频道选择 韩国餐厅/家常菜/超市/酱德台村/免税店 立即 品尝/购买/体验目的
2️⃣ 选择菜单/产品 发酵菜单（炖菜、拌饭）/真空包装 2~5分钟 可以要求“降低强度”
3️⃣ 领取·品尝 餐厅用餐/市场品尝/藏德台体验 波动 推荐强度/味道品尝
4️⃣配对·用餐 配菜、米饭和汤展 30~90分钟 大酱炖+米饭，红辣椒酱+拌饭
5️⃣ 购买/付款 真空包装、免税店、超市 1~5分钟 免税店增值税退税OK

> 所需总时间：餐厅用餐 = 30~60 分钟 / 市场购买 = 10~30 分钟 / 章德台体验 = 1~3 小时

  • 免税店生效 = 可退增值税

⚠ 外国人常犯的7个错误

1. “发酵食品=单独菜单”：发酵食品= 所有韩国食品的基本调味料。单独的菜单

2. “大酱 = 像日本味噌一样柔软”：韩国大酱 = 香气浓郁，味道咸咸。日本人的微笑=温柔、甜美。不同的味道。

3. “Gochujang = 仅辣”：Gochujang = 辣+甜+鲜味复合体。像是拉差一样微辣

4. “Cheonggukjang = 柔软”：Cheonggukjang = 浓郁的香气+东方医学健康。如果你喜欢日本纳豆，可以加入它，否则就避免它。

5. “酱油=同日本酱油”：韩国朝鲜酱油=咸味浓，汤爱好者。日本酿造酱油=甜。不同的类别。

6. “真空包装 = 随身携带”：肠道 = 仅限液体/托运行李。不允许携带登机。

7. “增值税退税X”：免税店=可退税。

⚙ 8 个常见问题解答

1. 第一道发酵食品=任意菜单：大酱炖+米饭（传统）→拌饭+红辣椒酱（全球）步骤。

2. Insta·vlog：淳昌酱流村、昌德宫酱油、酱油蟹爱好者。

3. MZ潮流：松露红辣椒酱、明太鱼籽饭、红辣椒酱奶油意大利面。

4. 全球趋势：韩国辣椒酱韩国食品#1·亚马逊畅销书。

5. 健康狂热：清国酱（益生菌）·大酱（肠道健康）——避免明确的表达。

6. 过敏：提前注意大豆、海鲜、水果、坚果和高盐含量。

7. 付款/小费：免税店/超市=卡/长德台村=一些现金/小费

8. 增值税退税：免税店 = 可退税 / 餐厅/市场 = 退税 X。

⚠ 医疗/安全/饮食免责声明

发酵食品=普通食品（药品X）。 谨防高盐分（黄豆酱、辣椒酱、酱油、咸鱼=盐↑）——高血压、肾病患者慎用。孕妇=适量清酒酱和强发酵食品。儿童=清国酱和咸鱼爱好者请注意进入市场。过敏（大豆、海鲜、水果）需提前通知。食物中毒/食物报告=☎1399（食品药品安全部）/医疗紧急情况=☎1339（医疗、英语）。本指南是一般信息，并非医疗建议。

随身携带/随身携带规定：章节 = 仅限液体分类/托运行李。提前检查您所在国家/地区的法规（澳大利亚/新西兰=食品进口限制）。

饮食限制后备：

  • 清真/犹太洁食：豆酱、红辣椒酱、酱油、醋=酒精、动物成分
  • 素食/纯素食：豆酱、红辣椒酱、酱油、醋、Cheonggukjang = 素食 OK / Jeotgal = 非素食。
  • 不含麸质：普通酱油/红辣椒酱 = 麸质 X / 酿造酱油 = 含有小麦（需要确认）。
