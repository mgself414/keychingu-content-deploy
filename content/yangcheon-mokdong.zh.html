🎯 为什么是阳川·木洞 (Yangcheon·Mokdong / 양천·목동) 独立指南

阳川·木洞 (Yangcheon·Mokdong / 양천·목동) 是阳川区 (Yangcheon-gu / 양천구) 的韩国中产阶级·教育·广播第一区 — 木洞 (Mokdong / 목동) (1985年新城开发，韩国第一中产阶级公寓小区，韩国教育第一区) + SBS电视台 (SBS Bangsongguk / SBS 방송국) (韩国三大电视台之一) + 西首尔湖水公园 (Seoseoul Hosu Gongwon / 서서울호수공원) (家庭友好型) + 木洞运动场 (Mokdong Undongjang / 목동운동장)·溜冰场 (Aiseuringkeu / 아이스링크) + 新亭 (Sinjeong / 신정)·新月 (Sinwol / 신월) 十字路口传统街区 的结合。这里是深入了解韩国中产阶级·教育·广播的第一区。

与弘大 (Hongdae / 홍대) (MZ世代 / MZ sedae: 指千禧一代和Z世代)·江南 (Gangnam / 강남) (奢华)·梨泰院 (Itaewon / 이태원) (国际化) 相比，阳川·木洞 (Yangcheon·Mokdong / 양천·목동) 具有中产阶级·教育·广播的特色。虽然在外国游客的行程中，它常被江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대) 掩盖而错过，但木洞 (Mokdong / 목동) 是韩国第一新城·教育热门区 + SBS电视台 (SBS Bangsongguk / SBS 방송국) K-drama·综艺深度体验 + 西首尔湖水公园 (Seoseoul Hosu Gongwon / 서서울호수공원) 家庭友好 = 外国人深入体验韩国日常生活·中产阶级的第一选择。ISSUE 03 第23篇 — KeyChinGu (키친구) 首次进入阳川区 (Yangcheon-gu / 양천구) (共55个集群)。

⚠ 外国人常犯的3个错误

1. “木洞 (Mokdong / 목동) = 普通公寓小区” — 未认识到韩国中产阶级·教育第一区的价值

木洞 (Mokdong / 목동) 不仅仅是普通的公寓小区，更是1985年新城开发，韩国第一中产阶级 + 教育第一区 — 韩国名牌补习班街·第一学校 + 中产阶级家庭·教育热门区。部分K-drama《天空之城 (SKY Castle)》的舞台。

2. “SBS电视台 (SBS Bangsongguk / SBS 방송국) = 不能进入” — 未认识到外观·参观的价值

SBS登村大厦 (SBS Deungchon Saok / SBS 등촌사옥) 可以参观外观 + 部分内部参观 (需提前预约)。是深入了解韩国K-drama·综艺的好地方。SBS人气综艺《Running Man (런닝맨)》·《我家的熊孩子 (My Little Old Boy / 미운우리새끼)》·《同床异梦 (Same Bed, Different Dreams / 동상이몽)》等节目的常客舞台。

3. “西首尔湖水公园 (Seoseoul Hosu Gongwon / 서서울호수공원) = 普通公园”

西首尔湖水公园 (Seoseoul Hosu Gongwon / 서서울호수공원) 是阳川 (Yangcheon / 양천) 第一湖水公园 + 声音喷泉 (外国游客Instagram热门) + 家庭散步 + 毗邻阳川区厅 (Yangcheon-gu Cheong / 양천구청)。是春季赏樱 + 秋季赏枫的第一选择。

阳川·木洞 (Yangcheon·Mokdong / 양천·목동) 风景

阳川·木洞 (Yangcheon·Mokdong / 양천·목동) 位于阳川区 (Yangcheon-gu / 양천구) 中心 — 5号线梧木桥站 (Omokgyoyeok / 오목교역)·木洞站 (Mokdongnyeok / 목동역)·新亭站 (Sinjeongnyeok / 신정역)·新月站 (Sinwolnyeok / 신월역) 一带。这里在1985年成为韩国新城，1990年代成为中产阶级区，2000年代成为教育第一区。

交通: 5号线梧木桥站 (Omokgyoyeok / 오목교역)·木洞站 (Mokdongnyeok / 목동역)·新亭站 (Sinjeongnyeok / 신정역)·新月站 (Sinwolnyeok / 신월역) / 9号线盐仓站 (Yeomchangnyeok / 염창역)·登村站 (Deungchonnyeok / 등촌역)·曾米站 (Jeungmiyeok / 증미역)。建议使用Kakao Taxi (카카오 택시)。

⚙ 常见问题 (6个)

Q1. SBS电视台 (SBS Bangsongguk / SBS 방송국) 外国人可以参观吗？

可以 — SBS登村大厦 (SBS Deungchon Saok / SBS 등촌사옥) 外观 + 部分内部参观 (需要提前预约，SBS官网提供英文服务)。是K-drama·综艺深度体验的好地方。

Q2. 西首尔湖水公园 (Seoseoul Hosu Gongwon / 서서울호수공원) 门票多少钱？

免费 + 24小时开放 — 外国游客可自由进入。有湖水 + 声音喷泉 + 散步道。从5号线新亭十字路口站 (Sinjeongnegeoriyeok / 신정네거리역) 步行约15分钟。

Q3. 木洞溜冰场 (Mokdong Aiseuringkeu / 목동 아이스링크) 开放吗？

全年运营 — 韩国第一溜冰场。外国游客可正常入场 (季节价格不同)。

Q4. 木洞 (Mokdong / 목동) 和金浦机场 (Gimpo Gonghang / 김포공항) 如何连接？

可以 — 5号线·9号线换乘。木洞 (Mokdong / 목동) (5号线) → 金浦机场 (Gimpo Gonghang / 김포공항) (5号线直达)。

Q5. 木洞 (Mokdong / 목동) 有哪些对外国人友好的店铺？

一味乐 (Ilmirak / 일미락)·青瓦镇 (Cheonggiwa Town / 청기와타운)·面包时间 (Ppangui Sigan / 빵의시간)·NonOff (논오프) 提供英文菜单 + 支持刷卡支付。

Q6. 阳川 (Yangcheon / 양천) 和麻谷 (Magok / 마곡) 如何连接？

可以 — 5号线仅一站之隔。麻谷 (Magok / 마곡) (首尔植物园 / Seoul Singmulwon / 서울식물원·LG) + 阳川 (Yangcheon / 양천) (SBS·木洞 / Mokdong / 목동) = 一日游。
