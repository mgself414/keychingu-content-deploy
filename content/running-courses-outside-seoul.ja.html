ソウル以外のランニングコース9か所 — 国民投票で選ばれた竹林・湖・海辺、距離と行き方

サブタイトル: 韓国観光公社「名所発掘100×100」のランニングコース国民投票で票を得たソウル以外のコース9か所を、蔚山・大邱、慶州、釜山、済州の4エリアにまとめた。蔚山の十里竹林は約4kmで24時間無料、済州のサリョニ林道は約10kmで17:00までに退場する決まりだ。慶州の普門湖は機関ごとに一周の距離の書き方が違い、済州の涯月は歩く道と車道の名前が似ている。距離、開く時間、料金、バス番号を、機関が示した値だけで整理した。

ISSUE 06 · #1445 · 2026-11-24 · ソウル以外のランニングコース

🎯 だれのための、なぜこの9か所なのか

韓国旅行中に1日くらい走りたい人に向けたリストです。ソウルを出て蔚山 (Ulsan / 울산)、大邱 (Daegu / 대구)、慶州 (Gyeongju / 경주)、釜山 (Busan / 부산)、済州 (Jeju / 제주)へ行く日程に、朝か夕方のランニングを足すときに使います。竹林の道、湖のまわり、海辺、森の道、海岸の散策路が混ざっています。

選んだ基準は一つです。韓国観光公社「名所発掘100×100」(Korea Tourism Organization "100×100 Spot Discovery" / 한국관광공사 명소발굴 100×100)のランニングコース国民投票の上位14位から、ソウル以外の湖・海岸・森の道のコースを選びました。1・3・4・5・7・10・11・12・14位がこの号の9か所です。2・6・9位はソウルの漢江公園 (汝矣島・盤浦・纛島)なので、この号からは外しました。13位の嶺南アルプス ハヌルオクセキル (Yeongnam Alps Haneul Eoksae-gil / 영남알프스 하늘억새길)は山の稜線の道なので、トレイルランニングの号 (#1428)に任せました。8位の金泉 蓮花池 (Yeonhwaji Pond / 연화지) (137票)は、韓国観光公社の紹介に、貯水池に沿って散策しやすく整えられていて夜間照明がつくという記述しかないため、正式なコースには入れていません。

この9か所は、ランニング専用のトラックではなく、散歩する人や観光客と一緒に使う道です。そのため、何kmあるのか、いつ開いていつ閉まるのか、どう行くのかを書きました。

⚠ 表記の原則: 距離、利用時間、料金、行き方は、韓国観光公社、各市・区庁と地域の観光ポータル (蔚山市、慶州市、釜山市、水営区、Visit Busan、大邱市、Visit Jeju)、済州バス情報システム (Jeju Bus Information System / 제주 버스정보시스템)で2026-11-24に閲覧した値です。バス番号は閲覧日時点の経由路線です。機関が数値を示していない項目は書いていません。走るのにかかる時間は入れておらず、機関が書いている所要時間だけをそのまま写しました。寿城池駅からの徒歩時間はカカオマップの経路検索の値です (2026-11-24)。得票と順位は、韓国観光公社「名所発掘100×100」ランニングコース国民投票の値です。運営時間とバスの路線は変わることがあります。

🚦 走る前に — 共通の安全とマナー

9か所とも、ランニング専用の道ではありません。以下は法律や施設の規定ではなく、大勢で使う道で守る一般的なマナーです。

  • 車道に接した海岸道路では、車道に降りない。 道頭レインボー海岸道路は、Visit Jejuの利用者レビューにも、道幅が広くないので車に気をつけるようにという声があります。狭い区間では走らずに歩いて、車の動きを見ます。
  • 人が多い道では速度を落とす。 広安里、冬柏島、瞻星台のまわり、ハンダム海岸散策路は、観光地のど真ん中です。狭い区間では歩きます。
  • 施設が決めたルールはそのまま守る。 普門湖の散策路は、自転車とATVが通れません。サリョニ林道は、飲食物を持って入れず、水だけ可能です。ハンダム海岸散策路は、現場の規制と案内が優先です。
  • 天気が悪ければやめる。 サリョニ林道は、豪雨・大雪などの悪天候のとき、一部または全区間を通行止めにすることがあります。龍頭岩 (Yongduam Rock / 용두암)は、波が高い日は、指定された探訪路と安全施設の中でだけ見ます。
  • 事故や緊急時は119に電話する。

① 蔚山・大邱 — 2か所

蔚山と大邱は別々の都市です。一度にまとめるより、それぞれの都市の日程に一つずつ足します。どちらも開く時間の制限はありません。

蔚山 太和江十里竹林道 (Taehwagang Simnidaesup-gil / 태화강 십리대숲길)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 229票·1位。
  • 距離: 蔚山市の太和江国家庭園の案内は、十里竹林を約4kmと書いています。総面積109,866㎡に竹が約50万本育ち、林の中にエコな散策路があると紹介しています。
  • 利用時間・料金: 入場料はとりません。入場の制限なく、24時間出入りできます。案内センターは9~18時に開いています。
  • 夜: 夜間照明区間の銀河水の道 (Eunhasu-gil / 은하수길)は、日没から23時まで点灯します。日が落ちてから走るなら、この時間内に合わせます。
  • 行き方: バスに乗って、「太和江国家庭園 (Taehwagang Gukgajeongwon / 태화강 국가정원) / 東江病院 (Donggang Byeongwon / 동강병원)」停留所で降ります。住所は蔚山 中区 セガンナムギル 5 (Saegangnam-gil 5 / 샛강남길 5)(太和洞)です。
  • 太和江駅発: 523・713・763・1115・1733・9001番
  • KTX蔚山駅発: 523・1733・5001・5003・5004番
  • 市外・高速バスターミナル発: 417・523・713・723・763・1115・1733・9001番
  • 駐車: 駐車場が14か所あります。有料は付設1 (215台)・2 (447台)・3 (123台)で、無料は太和江展望台 (28台)・ドングルピア (55台)・三湖沿岸公営 (175台)です。
  • 問い合わせ: 太和江国家庭園 案内センター 052-229-3147。

大邱 寿城池 (Suseongmot Lake / 수성못)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 134票·11位。
  • 距離: 大邱市の観光ページも韓国観光公社の旅行記事も、一周を約2kmと書いています。韓国観光公社の記事は、歩いて一周40分あまりと書いています。5周すると約10kmです。
  • 区間と路面: 韓国観光公社の記事 (2020年10月作成)は、池のまわりを四つの区間で紹介しています。東側は180mの水辺デッキロード、南側はスワンボートの船着き場と王桜の散策路 (裸足で歩ける道)、西側は粗い砂が敷かれたマサト (真砂土)の散策路、北側は水上ステージの側です。決まった出発点はありません。
  • 利用時間・料金: 大邱市の観光ページは、利用時間を「制限なし」、利用料金を「無料」と書いています。韓国観光公社の記事も、周回路を24時間・年中無休・無料と書いています。
  • 夜: 大邱市の観光ページは、夜に水面に映る照明がきらめくと紹介しています。韓国観光公社の記事は、王柳と水辺デッキロードに照明がつくと書いています。
  • 行き方: カカオマップの経路検索では、都市鉄道3号線 寿城池駅 (Suseongmot Station / 수성못역) 1番出口から徒歩16分 (約950m)です。住所は大邱広域市 寿城区 ヨンハンロ 35-5 (Yonghak-ro 35-5 / 용학로 35-5)です。
  • 施設: 大邱市の観光ページに「無料公営駐車場あり」と書かれています。トイレがあり、おむつ交換台もあります。問い合わせ 053-761-0645。

② 慶州 — 2か所

2か所とも、10番バス (反対方向は11番)の1路線で着きます。慶州市の観光ページは、このバスが慶州高速/市外バスターミナルを出て、「慶州駅 (Gyeongju Station / 경주역)」停留所、瞻星台、芬皇寺、普門観光団地、仏国寺の順に行くと書いています。始発06:00、終バス21:40、運行間隔20分です。終バスが21:40なので、瞻星台と東宮と月池が閉まる22:00より先に終わります。朝に普門湖を回り、夕方に瞻星台の方へ行くというふうに、1日にまとめられます。

慶州 普門湖 (Bomun Lake / 보문호)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 152票·3位。
  • 距離: 機関ごとに数値が違います。韓国観光公社は約8km、慶州市は約6kmと書きました。 どちらも、一周するのに約2時間と書いています。距離を正確に合わせて走るなら、時計かアプリで自分で測ります。
  • ルール: 散策路は自転車とATVが通れません。 韓国観光公社と慶州市が同じ内容を書いています。
  • 行き方: 慶州高速/市外バスターミナルから10番バスに乗ります。普門側の停留所は、「普門団地・慶尚北道文化観光公社 (Bomundanji Gyeongsangbukdo Munhwagwangwang Gongsa / 보문단지·경상북도문화관광공사)」、「ヒルトン・ザ・Kホテル (Hilton · The K Hotel / 힐튼·더케이호텔)」、「KT修練院 (KT Suryeonwon / KT수련원)」、「慶州ワールド (Gyeongju World / 경주월드)」の順です。慶州市のバス案内には「普門湖」という名前の停留所は出てこないので、「普門団地」で探します。10-1番は仏国寺まで行かず、慶州ワールドで折り返します。
  • 休憩場所: 慶州市の案内は、ムルノウルの公園 (Mulneoul Park / 물너울공원)とサランの公園 (Sarang Park / 사랑공원)に小さな休憩所があり、道ばたに朴木月の詩碑があると書いています。

慶州 瞻星台一帯 (Cheomseongdae Observatory area / 첨성대 일대)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 139票·7位。
  • 区間: 投票に挙がった区間は、隍城公園、北川、芬皇寺、東宮と月池、瞻星台をつなぐ道です。この5か所をつなぐ道の距離を示した機関はないため、距離は書いていません。遺跡の間をつないで走る道なので、コースの距離は走る人が自分で決めます。
  • 隍城公園: 韓国観光公社は、松林の散策路に、夏にはヤブランの群落が咲くと紹介しています。
  • 瞻星台: 慶州市の観光ページでは、09:00~22:00に開いています。冬季は21:00までです。年中無休で無料です。夜間の景観照明は、日没後から22:00まで点灯します。
  • 隣の見どころ — 東宮と月池 (Donggung Palace and Wolji Pond / 동궁과 월지): 09:00~22:00に開き、チケット販売は21:30に締め切ります。観覧料は大人3,000ウォン、青少年2,000ウォン、子ども1,000ウォンです。夜間の景観照明は、日没後から22:00までです。
  • 行き方: 慶州高速/市外バスターミナルから10番バス (反対方向は11番)に乗ります。停留所の一覧に、「月城洞事務所 (Wolseong-dong Office / 월성동사무소)」、「瞻星台」、「大陵苑 (Daereungwon / 대릉원)」が順にあります。同じ路線が、芬皇寺、東宮と月池、国立慶州博物館も通ります。

③ 釜山 — 2か所

広安里と冬柏島は、どちらも都市鉄道2号線で行きます。広安里は錦連山駅・広安駅、冬柏島は冬柏駅です。広安里は砂浜の長さが1.4kmの海辺で、冬柏島は短い海岸の周回散策路です。

釜山 広安里海水浴場 (Gwangalli Beach / 광안리해수욕장)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 148票·4位。
  • 距離: 釜山市は海水浴場を「総面積82,000㎡、砂浜の長さ1.4㎞、砂浜の幅は25~110m」と書いています。端から端まで往復すると2.8kmで、2往復すると5.6kmです。
  • 利用時間・料金: Visit Busanは、常時開放、年中無休、無料と書いています。海辺のテーマ通りで散歩やサイクリングができ、夏には公演が開かれると紹介しています。
  • 行き方: 出口の案内が機関ごとに違います。
  • 水営区の案内: 都市鉄道2号線 錦連山駅 (Geumnyeonsan Station / 금련산역) 3番出口から徒歩5分、広安駅 (Gwangan Station / 광안역) 3番出口から徒歩10分。
  • Visit Busanの案内: 2号線 広安駅5番出口から徒歩約13分。
  • バス: 水営区は41・49・38・42・51・62・83・83-1・108-1番に乗り、「広安里海水浴場」で降りて3分と書いています。Visit Busanは42・62番を書いています。
  • 住所: 釜山 水営区 クァンアンヘビョンロ 219 一帯 (Gwanganhaebyeon-ro 219 / 광안해변로 219)(広安洞)。
  • 駐車: Visit Busanは「近くの公営駐車場」を案内しています。

釜山 冬柏島 (Dongbaekseom Island / 동백섬)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 136票·10位。
  • 距離: Visit Busanは、冬柏島の外周の海岸散策路を「950mほど」と書いています。5周すると4.75kmです。投票に挙がった区間は、海雲台のビーチから冬柏島の周回路へつながる道ですが、ビーチの区間まで合わせた距離を示した機関はありません。
  • 勾配: 韓国観光公社のアクセシビリティ案内は、散策路の入口に勾配10度前後の区間があり、休憩スペースと展望デッキのスロープは5~9度と書いています。短いですが、平らなだけの道ではありません。
  • 利用時間・料金: 常時開放、年中無休で、入場料はありません。
  • 行き方: 都市鉄道2号線 冬柏駅 (Dongbaek Station / 동백역) 1番出口から出ます。Visit Busanは、1番出口から徒歩17分と書いています。バスは1003番に乗り、「冬柏島 (Dongbaekseom / 동백섬)」で降ります。
  • 施設: トイレがあります。釜山市のヌリマル案内は、冬柏公園別館の駐車場は有料で、冬柏島のまわりは駐車スペースが狭く、週末と祝日には満車になるとして、公共交通を勧めています。
  • 隣の見どころ — ヌリマルAPECハウス (Nurimaru APEC House / 누리마루 APEC하우스): 09:00~18:00に開き、入場は閉館の1時間前に締め切ります。毎月第1月曜日は休みです。入場は無料です。電話は051-743-1974~5です。

④ 済州 — 3か所

サリョニ林道は島の内陸の森の道で、ハンダムと道頭は海辺の道です。3か所ともバス停があります。バス番号は、済州バス情報システムで停留所の名前で検索した経由路線です。

済州 サリョニ林道 (Saryeoni Forest Trail / 사려니숲길)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 143票·5位。
  • 距離: Visit Jejuは約10kmと書いています。済州市 奉蓋洞 (Bonggae-dong / 봉개동)のビジャリム路の入口から、ムルチャッオルム方面を通り、西帰浦市 表善面 加時里 (Gasi-ri / 가시리)のプルグンオルム (南朝路)の入口までです。名前のついた細かい区間はありません。端から端まで往復すると約20kmです。
  • 路面: プルグンオルムの入口の近くは、赤い火山礫の道です。チョルムル (Jeolmul / 절물)のミヤコザサの道の区間は、地面がでこぼこしていて、高低差があります。
  • 利用時間: 09:00~17:00で、17:00までに出なければなりません。 年中無休です。豪雨・大雪などの悪天候のときは、一部または全区間を通行止めにすることがあります。往復を計画するなら、戻ってくる時間まで入れて早く出発します。
  • ムルチャッオルム: 普段は立ち入りを止めています。入口の近くで引き返さなければなりません。行事のときに予約すると、臨時で開けることがあります。
  • ルール: 飲食物は持って入れません。水は大丈夫です。ペットボトルは案内センターの近くの回収箱に捨てます。
  • 行き方: Visit Jejuは、南朝路の「サリョニ林道」停留所で降りるように案内し、二つの入口とも公共交通で行けると書いています。済州バス情報システムの停留所と経由路線は次のとおりです。
  • 停留所「南朝路サリョニ林道 (Namjoro Saryeoni Forest Path / 남조로 사려니숲길)」: 131、132、231、232番
  • 停留所「サリョニ林道 (Saryeoni Forest Path / 사려니숲길)」: 212、232番 (教来入口方面の停留所には222-1番も表示)
  • 駐車: ビジャリム路の入口のまわりには駐車場がありません。Visit Jejuは、南朝路のプルグンオルム入口の近くの駐車場を勧めています。お年寄りやベビーカーを連れているなら、南朝路の入口から入るように案内しています。

済州 ハンダム海岸散策路 — 投票名称「涯月海岸路」 (Handam Coastal Walk, Aewol / 한담해안산책로)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 134票·12位。投票名称は「涯月海岸路 (Aewol Haeanro / 애월 해안로)」で、区間は郭支海水浴場から涯月港までです。
  • まず名前を区別する: 名前の似た道が二つあります。
  • ハンダム海岸散策路: 涯月港から郭支クァムル海辺 (Gwakji Gwamul Beach / 곽지과물해변)までを結ぶ約1.2kmの歩く道です。クァククム オルレ道 (Gwakgeum Olle-gil / 곽금올레길)とも呼ばれます。投票に書かれた区間 (郭支海水浴場~涯月港)の両端が、この散策路の両端 (郭支クァムル海辺~涯月港)と同じです。
  • 涯月海岸道路: 荷貴 (Hagwi / 하귀)から涯月までの約9kmの海岸ドライブ道路、つまり車道です。Visit Jejuは、道路に沿って自転車道と歩行区間が整えられていて、済州環状自転車道の一部だと紹介しています。
  • 距離: ハンダム海岸散策路は約1.2kmです。往復すると2.4km、2往復すると4.8kmです。
  • 路面: Visit Jejuは「全体的に平坦に造られている」と書いています。メインの出入口のスロープは急なので、車いすの利用者は気をつけるようにという案内があります。
  • 利用時間・料金: Visit Jejuの利用案内は、常時開放、年中無休です。ペットの犬と一緒に行けて、リードやハーネスは2m以下で持ちます。現場の規制と案内が優先です。
  • 夜: Visit Jejuは、日が暮れかかるころに散策路のまわりに照明がつくと書いています。
  • 行き方: 済州バス情報システムの停留所と経由路線です。
  • 停留所「ハンダム洞 (Handamdong / 한담동)」: 202, 202-1, 202-2, 202-4番
  • 停留所「郭支海水浴場 (Gwakji Beach / 곽지해수욕장)」: 202, 202-1, 202-2, 795番
  • 停留所「涯月乗換停留所 (Aewol Hwanseung Jeongnyujang / 애월환승정류장)(涯月里)」: 102, 102-1, 202, 202-1, 202-2, 202-4番
  • 住所: 済州市 涯月邑 郭支里 1359 (Gwakji-ri 1359 / 곽지리 1359)。

済州 道頭レインボー海岸道路 (Dodu Rainbow Coastal Road / 도두 무지개해안도로)

  • 国民投票: 韓国観光公社「名所発掘100×100」ランニングコース国民投票 131票·14位。投票に挙がった区間は、道頭洞のレインボー海岸道路からオヨン公園を通って龍頭岩までです。
  • 距離: Visit Jejuは、虹色の防護壁の区間を歩いて約15~20分の距離とだけ書いています。km単位の数値を示した機関はないため、距離は書いていません。
  • 道の性格: 車道の横の海岸道路です。Visit Jejuの利用者レビューには、道幅が広くないので車に気をつけるようにという声があります。車道に降りず、狭い区間では歩いて車の動きを見ます。
  • 行き方: 済州バス情報システムでの停留所の名前は「道頭峰東側 (Doduboong Dongjjok / 도두봉 동쪽)」です。Visit Jejuは、この停留所で降りればすぐ目の前だと案内しています。
  • 「道頭峰東側[南] (Doduboong Dongjjok Nam / 도두봉 동쪽[남])」: 445, 447, 454, 1113番
  • 「道頭峰東側[北] (Doduboong Dongjjok Buk / 도두봉 동쪽[북])」: 444, 447, 453, 1111, 1112番
  • 駐車: 乗用車とバスで行けます。大型バスは、オレムルグァン広場 (Oraemulgwang Square / 오래물광장)の向かいの駐車スペースを使います。
  • ペットの犬: 一緒に行けます。リードやハーネスは2m以内で持ち、排泄物用の袋を持っていきます。
  • 隣の見どころ — 龍頭岩 (Yongduam Rock / 용두암): Visit Jejuの利用案内は、常時開放、年中無休、展望の観覧は無料です。住所は済州市 ヨンドゥアムギル 15 (Yongduam-gil 15 / 용두암길 15)です。波が高い日は、指定された探訪路と安全施設の中で見ます。観光地の問い合わせ 064-728-3917。

⚠ よくある間違い3

  1. 涯月海岸道路とハンダム海岸散策路を同じ道だと思う — 地図で「涯月海岸道路」を押すと、荷貴~涯月の約9kmのドライブ道路が出ます。郭支クァムル海辺と涯月港をつなぐ歩く道は、約1.2kmのハンダム海岸散策路です。バス停も「ハンダム洞」か「郭支海水浴場」で探します。
  2. サリョニ林道に午後遅く入る — 17:00までに出なければなりません。約10kmを全部往復すると約20kmです。飲食物は持って入れないので、水だけ用意します。雨が強く降る日や雪の日は、通行止めになることがあります。
  3. 距離の数値一つだけを信じて計画する — 普門湖は、韓国観光公社が約8km、慶州市が約6kmと書いています。瞻星台一帯と道頭レインボー海岸道路は、km単位の数値を示した機関がありません。決まった距離を走るなら、寿城池 (約2km)、冬柏島 (約950m)、ハンダム (約1.2km)、広安里 (1.4km)のように数値のある所で、周回数や往復回数で合わせます。

⚙ FAQ 3

  1. 日が沈んだあとも走れるところは? — 十里竹林は24時間出入りでき、銀河水の道の照明が日没から23時まで点灯します。寿城池は利用時間の制限がありません。広安里、冬柏島、ハンダム海岸散策路は常時開放です。ハンダムは、夕暮れどきに散策路のまわりに照明がつきます。瞻星台は22:00 (冬季は21:00)まで開き、日没後に景観照明がつきます。サリョニ林道は17:00までに出なければならないので、夕方は使えません。普門湖と道頭レインボー海岸道路は、機関が利用時間を別に書いておらず、冬柏島は常時開放ですが照明の案内はありません。この3か所は明るいうちに走ります。
  2. お金がかかるところはある? — 走る道そのものに料金をとると示した所はありません。十里竹林、寿城池、広安里、瞻星台は無料と書かれていて、冬柏島は入場料がありません。隣の見どころでお金がかかるのは、東宮と月池 (大人3,000ウォン、青少年2,000ウォン、子ども1,000ウォン)です。ヌリマルAPECハウスの入場と龍頭岩の展望の観覧は無料です。
  3. レンタカーなしで行ける? — 9か所とも、地下鉄の駅かバスで着きます。釜山の2か所は都市鉄道2号線で、慶州の2か所はターミナルから10番バスの1路線です。蔚山の十里竹林は、太和江駅・KTX蔚山駅・ターミナルからバスで行きます。済州の3か所は、停留所「南朝路サリョニ林道」「サリョニ林道」、「ハンダム洞」「郭支海水浴場」、「道頭峰東側」で探します。大邱の寿城池は、都市鉄道3号線 寿城池駅 1番出口から徒歩16分です (カカオマップ)。
