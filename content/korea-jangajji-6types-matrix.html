한국 장아찌 6종 매트릭스 — 오이·무·고추부터 마늘·깻잎·머위까지 외국인 발효 반찬 풀세트

부제: 외국인 관광객용 오이·무·고추·마늘·깻잎·머위 6종 + 한정식·가정식 발효 반찬

ISSUE 03 · #867 · 2026-06-09

🎯 왜 한국 장아찌 매트릭스인가

외국인 한국 장아찌 페인포인트 = "김치만 발효 음식 알고 있다". 한국 장아찌 = 한정식 반찬 #1 + 가정식 풀세트 + 발효 매니아. 같은 "Korean pickle"이라도 오이장아찌 (여름 시그니처)·무장아찌 (단무지 #1)·고추장아찌 (매콤·노포)·마늘장아찌 (1년 숙성)·깻잎장아찌 (한정식 정통)·머위장아찌 (봄 노포) 각자 다른 재료·시기·매니아. 외국인은 (a) 김치 vs 장아찌 차이 모름 (b) 한정식 반찬 = 무한 리필 모름 (c) 1년 숙성 매니아 모름 (d) 단무지 = 일본 vs 한국 차이 모름. 본 가이드는 6종 매트릭스 + 한정식 반찬 + 외국인 입문 우선순위.

외국인 입문 1순위 = 오이장아찌 + 무장아찌·단무지 (글로벌 친화 + 사계절)

한정식 정통 = 깻잎장아찌 + 무장아찌 (반찬 풀세트)

1년 숙성 매니아 = 마늘장아찌 (단단·매콤)

봄 노포 = 머위장아찌 (3~4월 정통)

🥒 6종 deep dive

🥒 오이장아찌 (Oi-jangajji) — 입문 #1

  • 시그니처: 여름 #1·가정식·반찬 + 한정식
  • 재료: 오이 + 간장·설탕·식초·마늘
  • 외국인 친화도: ★★★★★ (#1 입문·글로벌 cucumber 인지)
  • 숙성: 1~7일 (빠른 숙성)
  • 추천 매장:
  • 한정식 ([#837](#837)) — 반찬 #1
  • 가정식 백반 ([#854](#854)) — 가성비
  • MZ 카페 cluster
  • 가격: 한정식 반찬 포함 / 마트 1팩 = 3,000~6,000원

🥕 무장아찌·단무지 (Mu-jangajji·Danmuji) — 글로벌 #1

  • 시그니처: 사계절·한정식 풀세트·단무지 (노랑)
  • 재료: 무 + 간장·설탕 + 강황 (단무지 노랑)
  • 외국인 친화도: ★★★★★ (글로벌 단무지·일본 인지)
  • 숙성: 7~30일
  • 추천 매장: 한정식·김밥 ([#840](#840))·삼겹살 매장·MZ 카페
  • 가격: 한정식 반찬 포함 / 마트 = 2,000~5,000원

🌶 고추장아찌 (Gochu-jangajji) — 매콤·노포

  • 시그니처: 매콤·노포 매니아·소주 안주
  • 재료: 청·홍 고추 + 간장·식초·설탕
  • 외국인 친화도: ★★★★ (매콤·소주 페어)
  • 숙성: 7~30일
  • 추천 매장: 노포·시장·한정식·소주집
  • 가격: 시장 = 5,000~10,000원/팩

🧄 마늘장아찌 (Maneul-jangajji) — 1년 숙성

  • 시그니처: 1년 숙성·단단·매콤·매니아 #1
  • 재료: 마늘 + 간장·식초·설탕 + 1년 숙성
  • 외국인 친화도: ★★★★ (1년 숙성 매니아·인스타)
  • 숙성: 1년 (정통) / 1개월 (빠른 숙성)
  • 추천 매장: 한정식·노포·전라 정통
  • 가격: 시장 = 8,000~20,000원/팩

🌿 깻잎장아찌 (Kkaennip-jangajji) — 한정식 정통

  • 시그니처: 한정식 반찬 정통·깻잎 향
  • 재료: 깻잎 + 간장·고추·마늘 양념
  • 외국인 친화도: ★★★★ (한정식 정통)
  • 숙성: 1~7일
  • 추천 매장: 한정식 ([#837](#837))·노포 정통·가정식
  • 가격: 한정식 반찬 포함

🍃 머위장아찌 (Meowi-jangajji) — 봄 노포

  • 시그니처: 봄 노포 (3~4월) 정통·노포 매니아
  • 재료: 머위 (butterbur) + 간장·식초
  • 외국인 친화도: ★★★ (노포 매니아)
  • 숙성: 7~30일
  • 추천 매장: 노포 한정식·시골 정통
  • 가격: 노포 = 10,000~20,000원/팩

🍽 한정식 + 가정식 + 시장 시그니처

한정식 풀세트 ([#837](#837))

  • 신라호텔 라연·삼청각·인사동 — 장아찌 6종 반찬 무한 리필
  • 무장아찌·깻잎장아찌 = 한정식 정통 #1
  • 무한 리필: 반찬 무료·다 채울 수 있음

가정식 백반 ([#854](#854))

  • 장아찌 2~3종 + 김치 + 나물 = 가정식 반찬 풀세트
  • 가격: 8,000~15,000원/1인 (장아찌 포함)

시장 장아찌 (전통·노포)

  • 광장시장 장아찌 골목 (반찬가게)
  • 남대문 시장 반찬가게
  • 전주 한옥마을 노포 — 정통
  • 가격: 5,000~20,000원/팩

마트·면세점 (귀국 선물)

  • 이마트·롯데마트·홈플러스 — 진공 포장
  • 공항 면세점 — 단무지·오이장아찌 (소량)
  • 가격: 3,000~10,000원/팩

⚠ 외국인 자주 실수 5가지

1. "김치 = 장아찌": 김치 = 발효 + 양념 매콤 (배추·무) / 장아찌 = 간장·식초 절임 (오이·무·고추) — 다른 음식.

2. "단무지 = 일본": 한국 단무지 = 무장아찌 + 강황 (노랑)·일본 takuan = 쌀겨 발효 — 다른 음식.

3. "마늘장아찌 = 1주일": 마늘장아찌 = 1년 숙성 정통 (단단·매콤·매니아).

4. "장아찌 = 안 매콤": 고추장아찌 + 깻잎장아찌 = 매콤 (고추 함유).

5. "한정식 반찬 = 별도 비용": 한정식 반찬 = 무료 무한 리필 (장아찌 포함).

⚙ FAQ 8개

1. 외국인 입문 1순위: 오이 + 무 (글로벌) → 깻잎 (한정식) → 마늘 (1년 매니아).

2. 인스타·vlog: 한정식 반찬 풀세트·1년 숙성 마늘·광장 장아찌 골목.

3. MZ 트렌드: 가성비 한정식 반찬·MZ 카페 장아찌 fusion.

4. 소주 매니아: 고추장아찌 + 마늘장아찌 (안주).

5. 할랄·코셔: 6종 모두 OK (간장 = 글루텐 일부).

6. 알레르기: 간장 글루텐 사전 고지.

7. 결제·팁: 시장 = 현금·카드 / 마트 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

장아찌 = 일반 음식·발효 + 간장 절임. 임신부·어린이 = OK. 알레르기 (간장 글루텐·고추 매콤) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 모두 OK (채식·식물 기반).
  • 채식·비건: 6종 모두 OK (채식·비건 정통).
  • 글루텐 free: 간장 = 글루텐 함유 → Tamari 대체 OK.
