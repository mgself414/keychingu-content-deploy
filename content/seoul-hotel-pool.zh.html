⚠ 外国游客常犯的5个错误

1. “酒店泳池 = 仅限住客”: 部分酒店提供日间通行证 (Day Pass) 允许外部使用 (悦榕庄 (Banyan Tree / 반얀트리) 5万韩元 (约$37 / 265人民币 / 5,800日元)~、新罗 (Shilla / 신라) 8万韩元~、康莱德 (Conrad / 콘래드) 7万韩元~为标准)。必须提前预约。

3. “仅限夏季运营”: 室外泳池7-9月开放·室内泳池全年开放 (新罗 (Shilla / 신라)·悦榕庄 (Banyan Tree / 반얀트리)·西格尼尔 (Signiel / 시그니엘)·康莱德 (Conrad / 콘래드)·JW万豪 (JW Marriott / JW메리어트))。酒店宅度假 (Hokangseu / 호캉스) 全年皆可。
