🎯 本指南的使用方法

打开笔记本电脑,屏幕之外庭院环绕展开 — 这是顺天湾国家庭院内住宿“庭院远程办公 (Jeongwon Wokeisyeon / 정원워케이션)”主打的360度庭院景观办公空间(VisitKorea)。本指南写给带着海外公司的工作来韩国住几周到几个月的远程办公者。内容分三块: 签证(数字游民F-1-D的条件和居留期限)、短期来访的入境文件(K-ETA)、办公空间(釜山2处公共远程度假办公中心,南海岸2处住宿型远程度假办公)。所列数值都是2026-10-21在法务部、釜山市、VisitKorea和运营方官方页面上亲自打开确认的;没能打开的数值,文中会如实说明。

🛂 数字游民(远程度假办公)签证 F-1-D

法务部于2026-07-07宣布,这一自2024年起试运行的签证将自2026年6月30日起正式运营(法务部官方新闻稿)。

  • 对象: 受雇于海外企业、可以远程办公、并且在同一行业工作满1年以上的外国人及其家属(配偶·未成年子女)。年满18岁(随行子女除外)
  • 申请地点: 海外各驻外使领馆(大韩民国大使馆)
  • 收入要求: 申请日当天韩国银行公布的上一年人均国民总收入(GNI)的倍数。以2025年GNI为基准的金额如下(法务部官方新闻稿附件)
年龄 首都圈(不含人口减少·关注地区) 非首都圈·人口减少(关注)地区
18~34岁 GNI的1.5倍 — 7,862万韩元 GNI的1倍 — 5,241万韩元
35岁以上 GNI的2倍 — 1亿483万韩元 GNI的1.5倍 — 7,862万韩元
  • 携家属同来: 首都圈无论年龄均为GNI的2倍,非首都圈·人口减少(关注)地区为1.5倍(法务部)
  • 保险: 涵盖停留期间住院治疗和送返本国的1亿韩元以上个人医疗保险(法务部)
  • 材料: 签证申请表、护照、照片1张、手续费、在职证明·工资单·银行账户交易明细等收入证明、无犯罪记录证明、医疗保险投保证明,携家属时还需家庭关系证明。要适用非首都圈的要求,需提供1个月以上的租赁合同或远程度假办公专门设施·住宿的预订确认书(法务部)
  • 居留期限: 外国人登记时自入境之日起1年,每次延长1年,最长3年(法务部)
  • 不可以做的事: 限制在韩国就业和营利活动(法务部)
  • 变更身份: 持短期旅游签证(B-1·B-2·C-3)入境后,只要符合条件,就可以改为数字游民签证(法务部)
  • 试运行期间(2024年1月~2026年5月)共发放743份。截至2026年5月,以该签证登记的外国人398人中,有340人(约85%)住在首都圈(法务部官方新闻稿)。各使领馆的办理时间·手续费金额没能确认 — 请向要申请的使领馆咨询

✈ 短期来访 — K-ETA

  • K-ETA临时免除: 2026年1月1日~12月31日(K-ETA官方公告,2025-12-23发布)。公告中没有适用国家名单 — 在k-eta.go.kr申请页面扫描护照,就会显示是否属于免除对象
  • 如果没有办理K-ETA,就要填写入境卡。步骤见出发前清单,零慌张手册 — 到机场之前要做完的事
  • 以短期停留身份来后想住得更久,请看上面的“变更身份”一条

🌊 釜山 — 2处公共远程度假办公空间

釜山市把住宿补贴、办公空间(据点中心·卫星中心·共享办公空间·书咖等)和旅游联动打包,运营“釜山型远程度假办公”。申请和咨询窗口是官方网站busaness.com(釜山市官方英文页面“Workation Destination”)。

  • 影岛 (Yeongdo / 영도) 全球卫星中心 — 釜山影岛区拉瓦尔斯酒店。2025年3月起运营,是24小时开放的休息厅型办公空间(釜山市官方新闻稿,2025-08-07)。同一份新闻稿说,2025年邀请约150名海外数字游民,每人停留2周,在8月18日~10月23日举办了4期“釜山全球远程度假办公”。2026年的活动日程没能确认
  • Hue&Work西区远程度假办公中心 — 釜山西区松岛 (Songdo / 송도) 海滩一带。这是远程度假办公专门的公共空间,自2026年2月起运营,供釜山型远程度假办公项目参加者使用。釜山市介绍说,这是继2025年开放的“发呆休息厅 (Mulmeong Raunji / 물멍 라운지)”之后的第二处公共办公空间(釜山市官方新闻稿,2026-02-02)。详细地址·座位数·开放时间新闻稿里没有,没能确认
  • 申请主体: 釜山市新闻稿写明,企业·机构通过busaness.com申请。个人自由职业者的申请流程没能确认(该网站只靠脚本渲染,读不到正文)
  • 釜山站附近阿斯蒂酒店 (Aseuti Hotel / 아스티호텔) 24层的“据点中心(50个座位)”,只在2023年的媒体报道[二手资料]中见到。现在是否运营没能确认

🌿 南海岸 — 2处住宿型远程度假办公

  • 庭院远程办公 (Jeongwon Wokeisyeon / 정원워케이션) — 全南光州统合特别市顺天市 (Suncheon / 순천) 国家庭院1号路 (Gukgajeongwon 1-ho-gil / 국가정원1호길) 152-55(VisitKorea标注)。这是顺天湾国家庭院内的露营风住宿,配有360度庭院景观的办公空间,同时运营庭院讲解导览·体验项目·短期旅行路线(VisitKorea,2026-07-01修改)。价格·预订渠道VisitKorea上没有发布 — 主页栏连接到顺天市网站
  • 海洋恐龙远程办公 (Badagongnyong Wokeisyeon / 바다공룡 워케이션) — 庆南固城郡 (Goseong / 고성) 大加面大加路 (Daega-ro / 대가로) 467-16。由居民企业(株)海洋恐龙 (Badagongnyong / 바다공룡) 以“Yolocation”之名运营的村落型远程度假办公,方式是游览小村庄并一起参加当地社区活动(VisitKorea)。接受企业定制远程度假办公咨询。电话0507-1381-4428,team@dinosea.com(官方网站yolocation.dinosea.com)。价格官方网站上未发布

🧰 远程度假办公实务 — 网络、支付、交通、文件

  • 网络: 公共Wi-Fi见韩国公共WiFi连接不迷路手册 — 选带"Secure"字样的那个,流量见韩国eSIM开通零慌张流程图 — 安装在出国前,激活在抵达后
  • 支付: 外国人韩国支付系统深度探索
  • 交通: 地铁·公交见韩国交通卡3种选择,零慌张手册 — 按我的行程原样挑卡,城市之间见韩国高速·城际巴士客运站,流程原样照搬 — App从一开始就完全不同,釜山市内见釜山大众交通语法 — 只需读懂两条线的城市
  • 准备文件: 要适用非首都圈收入要求,住宿预订确认书或租赁合同可作为证明(法务部)。远程度假办公中心·住宿的预订邮件不要删除,留着
  • 在首尔办公的地方: 外国游客江南自习咖啡馆·共享办公指南

⚠ 常见的4个错误

1. “数字游民签证1年就结束” — 正式运营后每次延长1年,最长3年(法务部,2026-06-30起施行)

2. “收入标准是以美元固定的一个金额” — 是上一年人均GNI的1~2倍,随年龄和居留地区而不同。18~34岁在非首都圈居留则为1倍(5,241万韩元)(法务部)

3. “用这个签证也可以接韩国公司的活” — 限制在韩国就业和营利活动(法务部)

4. “一定要在本国大使馆办好再来” — 持旅游签证(B-1·B-2·C-3)入境后,只要符合条件就可以变更身份(法务部)
