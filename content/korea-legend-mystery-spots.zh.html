📍 化为龙的王与龙的传说 — 文武大王陵·感恩寺址·Daewangam公园·龙头岩·浮石寺

庆州文武大王陵 (Gyeongju Munmudaewangneung / 경주 문무대왕릉)位于庆州市 Munmudaewang-myeon Bonggil-ri 30-1 (문무대왕면 봉길리 30-1)，☎ 054-779-8166，是在位661~681年的新罗第30代 Munmu王 (Munmuwang / 문무왕)的水中陵。位于Bonggil-ri (봉길리)近海200m处。据韩国观光公社介绍，统一三国的Munmu王留下遗言，说自己要化为龙抵御倭寇，请把遗体火化后将骨灰葬在东海，后来便依其心愿安葬。这块岩石被称为Daewangam (대왕암)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

庆州感恩寺址 (Gyeongju Gameunsaji / 경주 감은사지)位于庆州市 Munmudaewang-myeon Yongdang-ri 17 (문무대왕면 용당리 17)，☎ 054-772-9289，是Munmu王为抵御倭寇而开始兴建，由其子Sinmun王 (Sinmunwang / 신문왕)于682年完成的寺院遗址。现在只剩两座三层石塔和建筑遗址。相传金堂下的排水设施是化为海龙的Munmu王进出的通道。据韩国观光公社旅游信息中登载的国家遗产厅介绍，金堂前的两座塔是韩国石塔中最大的。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:免费。

Daewangam公园 (Daewangam Gongwon / 대왕암공원)位于蔚山 Dong-gu Deungdae-ro 95 (동구 등대로 95)，☎ 052-209-3738，介绍中写有这样的传说:Munmu大王的王妃去世后化为护国龙，沉在蔚山东海的岩石下面。从入口到Ulgi灯塔 (Ulgi Deungdae / 울기등대)有600m松林路，公园里有吊桥和Ulgi灯塔。

  • 开放时间:全天开放。休息日:全年无休。

龙头岩 (Yongduam / 용두암)位于济州市 Yongduam-gil 15 (용두암길 15)，☎ 064-740-6000，是被海浪和风雕蚀成龙头模样的岩石。相传有一条龙偷了汉拿山神灵的玉珠逃走，神灵用弓将它射落在海边，它就那样凝固了。还有传说，一匹想化龙升天的白马被将军抓住，变成了岩石。登记为提供英语·汉语·日语导览服务。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

浮石寺 (Buseoksa / 부석사)位于荣州市 Buseok-myeon Buseoksa-ro 345 (부석면 부석사로 345)，☎ 054-633-3464，是676年Uisang大师 (Uisang Daesa / 의상대사)创建的寺院，也是联合国教科文组织世界遗产。据说佛殿西侧的大岩石没有与下面的岩石相连而是悬空，因此得名“悬空之石 (Buseok / 부석)”。相传无量寿殿 (Muryangsujeon / 무량수전)西侧的水井里住着Uisang大师的护法龙。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 难以解释的现象 — 密阳 Eoreumgol·表忠碑·万鱼寺，Seorak Heundeulbawi，珍岛神秘海路

据韩国观光公社介绍，密阳 Eoreumgol·表忠碑·Maneosan (만어산)的磬石(原文“Eosan Buryeong Gyeongseok (어산불영경석)”)被称为“密阳的3大神秘”。

密阳 Eoreumgol (Miryang Eoreumgol / 밀양 얼음골)位于密阳市 Sannae-myeon Sannae-ro 1647 (산내면 산내로 1647)，☎ 055-356-5640，是Jaeyaksan (재약산)北侧半山腰的山谷。据说3月上旬前后岩缝里开始结冰，通常持续到7月中旬，不过介绍中写道，近来雨天增多，结冰的时间已不如从前那么长。冬天反而有热气从岩缝里冒出来。结冰的岩缝夏季平均气温约为摄氏0.2℃。

  • 开放时间:电话咨询。休息日:全年无休。费用:免费。

表忠碑 (Pyochungbi / 표충비)位于密阳市 Muan-myeon Dongbudongan-gil 4 (무안면 동부동안길 4)，☎ 055-359-5640，是1742年为表彰Samyeong大师 (Samyeong Daesa / 사명대사)的忠节而立的碑。介绍中写道，因为每逢国家有大事，石碑上就会流汗的说法，它被称为“会出汗的表忠碑”。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

万鱼寺 (Maneosa / 만어사)位于密阳市 Samnangjin-eup Maneo-ro 776 (삼랑진읍 만어로 776)，☎ 055-356-2010，是位于海拔674m的Maneosan (만어산)上的寺院。据《三国遗事》流传的故事，被佛祖说法感化的东海无数鱼和龙聚集到山上变成了石头，这些石头会发出磬声。至今敲打寺前的石头仍会发出清脆的声音，因此也叫钟石 (Jongseok / 종석)，被指定为Gyeongsangnam-do纪念物 (Gyeongsangnam-do Gininmul / 경상남도기념물)。

  • 开放时间:08:00~18:00。休息日:全年无休。

Seorak Heundeulbawi (Seorak Heundeulbawi / 설악 흔들바위)位于束草市 Seoraksan-ro 1140-200 (설악산로 1140-200)，☎ Seoraksan国立公园事务所 (Seoraksan Gungnip Gongwon Samuso / 설악산국립공원사무소) 033-801-0900，是放在Gyejoam (계조암)入口宽阔岩石上的圆形岩石。看上去轻轻一碰就会倒，但介绍中写道，一个人推和很多人推，晃动的程度差不多。从Seoraksan小公园 (Seoraksan So Gongwon / 설악산 소공원)出发约需1小时。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

珍岛神秘海路 (Jindo Sinbiui Badatgil / 진도 신비의 바닷길)位于珍岛郡 Gogun-myeon Sinbiui Badatgil 148 (고군면 신비의바닷길 148)，☎ 珍岛郡政府观光科 (Jindo Guncheong Gwangwang-gwa / 진도군청 관광과) 061-540-3407，是在Gogun-myeon (고군면)的Hoedong-maeul (회동마을)与Uisin-myeon (의신면)的Modo (모도)之间，露出宽30~40m、长2.8km海路的地方。海路露出约1小时后会再次闭合。相传为躲避老虎而渡海去Modo的村民丢下了Ppong奶奶，Ppong奶奶向龙王祈祷，海路打开，她见到了家人，却就此断了气，此后村民每年都举行祭祀。登记中写道，1975年法国驻韩大使把这一现象介绍为“摩西的奇迹”，使它广为人知。有体验馆，所以无论海路是否开启都可以体验。

  • 开放时间·休息日·费用:无登记值。海路实际开启的日期在韩国观光公社的信息里没有(传说中的“农历2月月底”不是开放日程)。

📍 建国神话与古老故事 — 庆州鸡林·延乌郎细乌女·温达山城·落花岩

庆州鸡林 (Gyeongju Gyerim / 경주 계림)位于庆州市 Gyo-dong (교동)，☎ 054-779-8585，是Cheomseongdae (첨성대)与Wolseong (월성)之间的树林。有庆州金氏 (Gyeongju Gimssi / 경주 김씨)始祖Alji (Alji / 알지)在此诞生的传说。相传新罗Talhae王 (Talhaewang / 탈해왕)时，人们听到树林里有鸡叫声，前去查看，看见树枝上挂着一只发光的金柜，里面走出一个男孩。园内的石碑立于1803年，刻有Kim Alji (Gim Alji / 김알지)诞生的记录。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

延乌郎细乌女主题公园 Gwibigo (Yeonorang Seonyeo Temagongwon Gwibigo / 연오랑세오녀 테마공원 귀비고)位于浦项市 Nam-gu Donghae-myeon Homi-ro 3012 (남구 동해면 호미로 3012)，☎ 054-289-7955，是介绍《三国遗事》中延乌郎细乌女故事的地方。故事讲的是，住在东海边的Yeono (연오)和Seo (세오)夫妇渡海去了日本，新罗的日月便失去了光芒，用细乌织的绢举行祭祀后，光芒才重新恢复。韩国观光公社的介绍中写作韩国唯一的日月神话。展馆Gwibigo (귀비고)通过动画·VR·媒体体验来展现这个传说。

  • 开放时间:公园全天开放，Gwibigo展馆·新罗村 (Silla Maeul / 신라마을) 10:00~18:00(入场截止 17:30)。
  • 休息日:每周一(遇公休日则顺延至之后的第一个工作日)，1月1日，Seolnal·Chuseok当天。费用:免费。

丹阳温达山城 (Danyang Ondalsanseong / 단양 온달산성)位于丹阳郡 Yeongchun-myeon Ha-ri (영춘면 하리)，☎ Ondal旅游区 (Ondal Gwangwangji / 온달관광지) 043-423-8820，是建在海拔427m的Seongsan (성산)上的半月形石城。介绍中写道，《三国史记》记载，高句丽平原王的女婿Ondal (온달)在新罗军队来袭时修筑了这座城并战斗，最终战死。这里流传着傻子Ondal和Pyeonggang公主 (Pyeonggang Gongju / 평강공주)的故事。

  • 开放时间:全天开放。为防止遇险和保证安全，16时以后禁止登山。休息日:全年无休。

落花岩 (Nakhwaam / 낙화암)位于扶余郡 Buyeo-eup Ssangbuk-ri (부여읍 쌍북리)，☎ 041-830-2884，是Buso山 (Busosan / 부소산)北侧面向Baengmagang江 (Baengmagang / 백마강)的悬崖。《三国遗事》中有百济灭亡时宫女们在此跳下的故事流传。相传因为把宫女们比作落下的花，所以称为落花岩。岩壁上刻有Song Si-yeol (Song Si-yeol / 송시열)所书的“落花岩”字样。

  • 开放时间:3~10月 09:00~18:00，11~2月 09:00~17:00。休息日:1月1日，Seolnal·Chuseok当天。
  • 费用(个人):成人2,000韩元，青少年·军警1,100韩元，儿童1,000韩元。包括Buso山城 (Busosanseong / 부소산성)和Goran寺 (Goransa / 고란사)。

📍 与人和自然有关的故事 — 马耳山塔寺·龙门寺·黄池·Kkotji海水浴场·正房瀑布·圣留窟

马耳山塔寺 (Maisan Tapsa / 마이산 탑사)位于镇安郡 Maryeong-myeon Maisannam-ro 367 (마령면 마이산남로 367)，☎ 063-433-0012，是以Yi Gap-ryong居士 (Yi Gap-ryong Cheosa / 이갑룡 처사)所砌的80多座石塔而闻名的地方。相传Yi Gap-ryong (이갑룡)25岁进入Maisan (마이산)，一直砌塔到98岁去世。韩国观光公社的介绍中写道，大雄殿后面的一对天地塔最大。

  • 开放时间:3~11月 08:00~18:30，12~2月 08:00~18:00。休息日:全年无休。
  • 费用:成人3,000韩元，初高中生2,000韩元，小学生1,000韩元。

龙门寺 (Yongmunsa / 용문사)位于杨平郡 Yongmun-myeon Yongmunsan-ro 782 (용문면 용문산로 782)，☎ 031-773-3797，有一棵树龄推测约1,100年、高42m的银杏树，是天然纪念物。相传这棵树是新罗Gyeongsun王 (Gyeongsunwang / 경순왕)的儿子Maui太子 (Maui Taeja / 마의태자)前往Geumgangsan (금강산)途中栽下的，还有一种传说是Uisang大师 (Uisang Daesa / 의상대사)拄过的拐杖插在地上长成的。运营寺院体验(Templestay)。

  • 开放时间:全天开放。休息日:全年无休。

黄池 (Hwangji Yeonmot / 황지연못)位于太白市 Hwangjiyeonmot-gil 12 (황지연못길 12)，☎ 太白市旅游咨询中心 (Taebaek-si Gwangwang Annae-so / 태백시 관광안내소) 033-550-2828，是洛东江 (Nakdonggang / 낙동강)的发源地。介绍中写道，有这样的传说:住在这里的黄姓富翁把粪肥舀给来化缘的老僧，顿时天地震动，房屋所在之处变成了池塘。每天约有5,000吨水涌出。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Kkotji海水浴场 (Kkotji Haesuyokjang / 꽃지해수욕장)位于泰安郡 Anmyeon-eup Seungeon-ri (안면읍 승언리)，☎ Dangam-ri旅游咨询中心 (Dangam-ri Gwangwang Annae-so / 당암리 관광안내소) 041-670-2543，有Halmae岩 (Halmae Bawi / 할매바위)和Halbae岩 (Halbae Bawi / 할배바위)。相传新罗张保皋 (Jang Bogo / 장보고)的基地司令Seungeon (승언)出征后没有回来，一直望着大海等待的妻子Mido (미도)死后变成了Halmae岩。退潮时两块岩石会被沙洲连在一起。

  • 开放时间:3~10月 10:00~17:00，11~2月 10:00~16:00。休息日:全年无休。

正房瀑布 (Jeongbang Pokpo / 정방폭포)位于Seogwipo-si Chilsimni-ro 214beon-gil 37 (서귀포시 칠십리로214번길 37)，☎ 064-733-1530，韩国观光公社的介绍中写作国内唯一从陆地直接落入大海的瀑布。有这样的说法:奉秦始皇之命来寻找不老草的Seobul (서불)没有找到不老草，在悬崖上刻下“Seobulgwaji (서불과지)”几个字后回去了。

  • 开放时间:09:00~17:30。休息日:全年无休。
  • 费用:成人2,000韩元，青少年(13~24岁)·儿童(7~12岁)·军人(下士以下)1,000韩元。

圣留窟 (Seongnyugul / 성류굴)位于蔚珍郡 Seongnyugul-ro 221 (성류굴로 221)，☎ 054-789-5404，是长915m(含水中区段)的石灰岩洞穴。介绍中写道，它原本因为是神仙游玩的地方，被称为Seonyugul (선유굴)；新罗Sinmun王的儿子Bocheon太子 (Bocheon Taeja / 보천태자)在洞内建了寺院，称为Seongnyusa (성류사)；又因岩壁上有小孔，叫作圣留窟。还流传着壬辰倭乱时500多名居民躲进洞里，倭兵堵住洞口，所有人都饿死的故事。

  • 开放时间:3~10月 09:00~18:00，11~2月 09:00~17:00(截止入场时间为闭馆前30分钟)。
  • 休息日:每周一(遇公休日则顺延至次日)。
  • 费用(个人):成人5,000韩元，青少年·军人3,000韩元，儿童2,500韩元，老人1,000韩元。登记值中同时写有65岁以上·国家有功者·残疾人·学龄前儿童免费(须携带证明)，与老人费用不一致，请到现场确认。

⚠ 行前须知 3 点

  1. 传说就是传说 — 正文中写作“相传”“有……的说法”的内容，是韩国观光公社介绍中登载的流传故事。
  2. 珍岛神秘海路的日期要另行确认 — 海路开启的日期和运营时间没有登记。
  3. 确认时间和休息日 — 温达山城16时以后禁止登山，圣留窟和延乌郎细乌女主题公园Gwibigo周一休息。

⚙ FAQ 3

Q. 有龙的故事的地方有哪些?

A. 文武大王陵，感恩寺址，Daewangam公园(护国龙)，龙头岩，浮石寺(住着护法龙的水井)，万鱼寺(鱼和龙变成石头的故事)。庆州Munmudaewang-myeon (문무대왕면)的文武大王陵和感恩寺址连着同一个故事。

Q. 哪些地方要花钱?

A. 马耳山塔寺(成人3,000韩元)，落花岩(成人2,000韩元，包括Buso山城·Goran寺)，正房瀑布(成人2,000韩元)，圣留窟(成人5,000韩元)。

Q. 密阳的“3大神秘”是什么?

A. Eoreumgol，表忠碑，Maneosan的磬石。据韩国观光公社介绍，这三处被称为“密阳的3大神秘”。三处分别位于Sannae-myeon (산내면)·Muan-myeon (무안면)·Samnangjin-eup (삼랑진읍)。
