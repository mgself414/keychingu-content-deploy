韩国登山文化 — 韩国中年为何对山如此认真 (登山服·北汉山的社会学)

> 国土70%是山·北汉山 (北汉山 / Bukhansan / 북한산)·登山会·山顶马格利酒 (马格利酒 / makgeolli / 막걸리)·登山服日常化 — 写给外国人的韩国登山文化 explainer。不是'爬哪条路线'，而是'为何·是什么·怎么做'。

抵达首尔 (首尔 / Seoul / 서울) 的外国人最先吃惊的景象之一: 搭地铁时，即便是工作日的清晨，一群从头到脚用昂贵登山服武装的60·70多岁人群 哗啦啦地下车。拄着登山杖，背着背包，穿着五颜六色的功能性夹克 — 可去的地方不是珠峰，而是 地铁可达的市区后山。在韩国，登山不是少数发烧友的爱好。它是 多数成年人每月至少去一次山的国民活动，对中老年人尤其是 运动·社交·自尊心交织在一起的生活方式。最近MZ世代穿着紧身裤加入，还出现了面向外国游客的 首尔市官方登山旅游中心(用英语出借装备)。本文讲的不是'爬哪座山'(→ cross-link)，而是 韩国人为何对山如此认真，以外国人视角解读其社会面与实战。韩国文化 explainer 系列。

⚠️ 外国人常误解的3点

1. "登山不就是老人的爱好吗?" ❌ — 中老年比例高是事实，但新冠后 2030 MZ世代大量涌入，以'山instagram (山instagram / san-stagram / 산스타그램)'·登山团·百大名山挑战，让登山彻底变年轻了。如今山在韩国是 跨世代的共同活动。

2. "为何去爬后山却穿全套装备?" ❌ — 韩国是 几乎唯一让登山服日常服化的国家。中年人把登山服·背包不仅穿去山上，还穿去散步·外出·上下班。这不是夸张，而是 文化现象(见下文④)。

3. "山会又远又险" ❌ — 韩国 国土70%以上是山地，城市被群山环绕。在首尔 地铁30分钟~1小时就能到国立公园级的山 入口。'市区里的自然'是韩国登山的核心魅力。

① 登山文化是什么 — 从'国土70%是山'这一起点

理解韩国登山文化的第一把钥匙是 地形。朝鲜半岛 国土70%以上是山地。连大城市都四面被山环绕，对韩国人而言，山不是'远行去征服的对象'，而是 家附近一直都在的生活空间。

所以韩国的登山有两副面孔。

  • 生活登山: 登山人口的多数定期攀爬 高度500m以下的家附近小山。与其说是宏大远征，不如说更接近 社区运动。
  • 国民级规模: 据一项调查，多数成年人每月至少去一次山或林间小路(报道数值约78%，按人口算数千万人)。数值因调查·年份而不同，因此关注 '国民活动'这一事实本身 即可。

也就是说，如果在外国登山是'特别的周末活动'，那在韩国登山是 像呼吸一样嵌入日常的文化。这种'日常性'是后面所有现象(登山服时尚·登山会·马格利酒)的基础。

> ※ 统计出处: 韩国山林厅·统计厅相关报道。准确数值随发布年份变动 — 引用时建议核实原始资料。

② 市区里的山 — 北汉山这一世界级特异点

韩国登山的象征无疑是 北汉山 (北汉山 / Bukhansan / 북한산，约836m)。外国人最吃惊的一点是: 这是 紧贴千万人口超级都市旁的真正国立公园。

  • 世界级密集度: 北汉山是毗邻市中心的自然公园，被认为是 单位面积访客数位居世界前列的国立公园(过去与吉尼斯相关的提及也常被谈起)。据报道，年访客达 700万人级，在全国国立公园中持续保持 访客第1。
  • 风景的反转: 花岗岩山峰、朝鲜时代 山城(北汉山城 / Bukhansanseong / 북한산성) 城墙，以及从山顶俯瞰的 首尔市区全景，都装进一条路线里。"搭地铁来，穿上登山鞋，30分钟城市就铺在脚下"的体验，是韩国登山独有的魅力。
  • 相邻的山: 与北汉山以山脊相连的 道峰山 (道峰山 / Dobongsan / 도봉산，740m)、首尔西南的 冠岳山 (冠岳山 / Gwanaksan / 관악산，632m)、景福宫 (景福宫 / Gyeongbokgung / 경복궁) 旁低矮的 仁王山 (仁王山 / Inwangsan / 인왕산，338m)，到市中心正中的 南山 (南山 / Namsan / 남산，262m) — 首尔本身就是 一座巨大的登山城市。

这种'市区可达性'正是韩国中年能对山如此认真的物理条件。无需远行，一趟公交·地铁就到山，于是登山不是特别的活动，而成了 习惯。

③ 中年为何对山认真 — 登山会·山顶·马格利酒的社会学

现在是核心问题。为何唯独韩国的中老年对山如此认真? 不只是为了健康。山对韩国中年而言是 运动场，是社交俱乐部，是身份认同的舞台。

  • 登山会=中年的社交网络: 韩国有按职场·地区·校友·爱好组成的 登山会 (登山会 / sanakhoe / 산악회)，密如蛛网。每所大学都有登山社团，有规模的企业常有公司登山会，每个社区都有居民登山会。对退休前后社会关系减少的中年人而言，登山会 (登山会 / sanakhoe / 산악회) 是 定期见人·获得归属感的核心通道。(→ 这种'以关系为中心'的情感与 #1135 情(情) 文化 (情 / jeong / 정) 相通。)
  • 登顶认证=一起征服的叙事: 登山会在山顶标石前拍 集体认证照。这是分享"我们征服了这座山"这一小小成就的仪式。他们系统地安排登山日程，还一起攻下百大名山。
  • 下山后马格利酒=真正的正戏: 韩国登山不可或缺的一幕，是 山顶或下山后的一碗马格利酒 (马格利酒 / makgeolli / 막걸리)。流汗后配着葱饼 (葱饼 / pajeon / 파전) 喝马格利酒 (马格利酒 / makgeolli / 막걸리)，是一种犒赏仪式。在登山会 (登山会 / sanakhoe / 산악회)，下山后的吃饭·喝酒联谊，实际上是登山的一半。陌生韩国人在山顶请外国登山者喝一杯马格利酒 (马格利酒 / makgeolli / 막걸리) 也不罕见 — 被传为"only in Korea"的瞬间。

概括来说，对韩国中年而言，山 不是孤独的运动，而是共同体活动。健康·自然·人际·成就感都装进一次登山里，自然不可能不认真。

> ⚠️ 参考: 国立公园等部分区域 限制饮酒·野炊。马格利酒文化主要是私人聚会·允许区域的风景，遵守公园规定是原则。

④ 登山服的日常化 — 韩国独有的'户外时尚'现象

外国人最觉得新奇的韩国登山文化的一面: 把昂贵登山服当日常服穿的现象。

  • 是什么现象: 韩国中老年把登山服·功能性夹克·登山背包 不仅穿在山上，也穿去散步·买菜·上下班·旅行。在社区超市、公园，甚至出国旅行的机场，都常见穿着花花绿绿登山夹克的韩国人。说韩国是几乎唯一'登山服=便装'通行的国家也不为过。
  • 为何如此: ① 山是日常，登山服也成了日常; ② 功能性(轻·暖·防水)出色而实用; ③ 2000年代户外热潮时，社会上'备齐像样的登山服'成了一种礼仪·自尊，高价品牌消费随之扩散。
  • 品牌版图: 韩国户外市场上本土与海外品牌竞争激烈。因调查而异，但 Black Yak (블랙야크)·K2 (케이투)·Kolon Sport (코오롱스포츠)·Eider (아이더) 等国内品牌，与 The North Face (노스페이스)·Discovery (디스커버리) 等较强。有趣的是，The North Face 是美国品牌，但 在韩国尤其拥有近乎国民品牌的地位。(品牌排名·占有率因调查·年份而异 — 仅供参考。)

这种登山服日常化不只是时尚，而是 显示'山在生活中扎根多深'的文化指标。衣柜里登山服的数量，等于与山的亲密度。

⑤ MZ世代的加入 — 从'大叔爱好'到'潮流爱好'

登山是中年专属的时代已结束。新冠19之后2030世代大量涌向山，登山文化本身变年轻了。

  • 什么变了: 年轻世代不叫'登山会'，而称 登山团·登山俱乐部，并在社交网络上用 #山instagram (山instagram / san-stagram / 산스타그램) 标签晒认证照。他们不穿登山服，而是穿 紧身裤·短上衣 登山，在山顶留下'潮'照成了一种玩法。把登山视为'大叔爱好'的认知，反转为 '神生(勤奋的人生)' (神生 / gat-saeng / 갓생) 的象征。
  • 为何被吸引: ① 偏好户外而非室内运动; ② 一个人也能轻松享受的 低门槛运动; ③ 与社交晒图的欲望很契合; ④ 与'今日运动完成' (今日运动完成 / owanwan / 오운완)·登山约会等生活方式趋势结合。轻快地走市区低山·环山步道 (环山步道 / dulle-gil / 둘레길) 的 徒步型登山 尤其受欢迎。
  • 约会·社交: 登山团成了新的相遇场。有报道接连指出登山会新加入者中2030比重大增。比起山顶，以 人 为目的的情况也不少。

要之，如今韩国的山是 70多岁登山会与20多岁登山团在同一条登山道上相遇 的有趣世代交叉口。

⑥ 外国人登山实战 — 路线·装备·交通 (K-登山指南)

好消息。K-登山如今已成为 外国人观光必游路线，并由 首尔市官方支援。

> 运营·费用可能变动 — 访问前建议核实官方渠道。

  • 首尔市区登山旅游中心 (强烈推荐): 首尔观光财团运营的外国人专属设施。位于 北汉山 (北汉山 / Bukhansan / 북한산，牛耳站)·冠岳山 (冠岳山 / Gwanaksan / 관악산)·鞍山 (鞍山 / Ansan / 안산) 入口，以 韩语·英语·中文·日语 指导路线。核心是 登山鞋·登山服·登山杖·手套等装备出借(面向外国人，预约制) — 空手而来也能登山。还运营外国人陪同登山项目。北汉山点 距北汉山牛耳站 (北汉山牛耳站 / Bukhansan Ui-yeok / 북한산우이역) 步行5分钟。
  • 路线难度指南:
  • 入门(外国人第一次登山): 仁王山 (仁王山 / Inwangsan / 인왕산，338m) — 城墙路+首尔展望，短而平缓。南山 (南山 / Namsan / 남산，262m) — 实质上是城市散步。
  • 中级: 北汉山 (北汉山 / Bukhansan / 북한산) 环山步道/低难度路线、道峰山 (道峰山 / Dobongsan / 도봉산)·冠岳山 (冠岳山 / Gwanaksan / 관악산) 部分 — 但山顶部是 岩脊(岩脊 / amneung / 암릉) 险峻，登山鞋·手套必备。
  • 注意: 道峰山·冠岳山山顶部、北汉山白云台 (白云台 / Baegundae / 백운대) 等多 岩石路段，对新手有负担。别勉强，按体力·天气选路线。
  • 装备·着装: 韩国的山虽低，但 岩石·台阶多，防滑登山鞋很重要。夏天防紫外线·湿度，冬天防冰面(需冰爪)。水·零食必备。没装备就用上述登山旅游中心出借。
  • 礼仪: 登山道上韩国人意外地友善 — 陌生人可能打招呼或请你吃零食·喝马格利酒 (马格利酒 / makgeolli / 막걸리)，别慌(这是好意)。垃圾带回，走指定登山道，遵守禁烟·禁炊区。

❓ 外国人常见问题 (FAQ)

  • 一件登山装备都没有，可以吗? — 可以。首尔市区登山旅游中心 向外国人出借登山鞋·夹克·登山杖等(预约制)。空手来也OK。仅运动鞋应付仁王山 (仁王山 / Inwangsan / 인왕산)·南山 (南山 / Namsan / 남산) 足够。
  • 能用英语获得帮助吗? — 能。登山旅游中心提供 包括英语在内的4种语言 指导，还运营外国人陪同登山项目。北汉山牛耳站 (北汉山牛耳站 / Bukhansan Ui-yeok / 북한산우이역) 点最具代表性。
  • 新手从哪座山开始? — 建议从 仁王山 (仁王山 / Inwangsan / 인왕산，城墙+展望) 或 南山 (南山 / Namsan / 남산，散步级) 开始。有信心后再上北汉山低难度路线。道峰山·冠岳山山顶部岩石险峻，切勿勉强。
  • 山顶有人请喝马格利酒，可以喝吗? — 是好意，轻轻回应也好，但 国立公园等可能限制饮酒·野炊。看气氛判断，避免过量·野炊才安全。
  • 为何大家都穿贵的登山服? — 因为韩国特有的 登山服日常化文化(见上文④)。外国人不必跟着买 — 舒适的运动服+登山鞋就够，装备可用出借解决。
