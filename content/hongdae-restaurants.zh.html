弘大美食·酒吧60家指南 — 专为外国游客精心策划

> 副标题: 弘大·延南·合井·望远 美食·酒吧分类精选 — #158综合指南的美食·酒吧深度版

ISSUE 03 · #159 · 2026-05-14

🎯 外国游客指南核心5点

1. 延南·合井·望远 = 弘大动线: 从弘大入口站 (Hongdae Ipgu / 홍대입구역) 步行10~15分钟内，4个子区域密集分布。串成一条动线可高效打卡5家以上。

2. 工作日14:00~17:00黄金时段: 周末·深夜排队超1小时以上。外国人友好型店铺在工作日下午14:00~17:00最清静，英语服务也最佳。

3. 吧台席·预约: 日式小店以吧台座位为主。工作日19:00前后是黄金时段。支持英语的店铺可通过 Naver预约 (Naver Yeyak / 네이버 예약) 或 KakaoTalk频道 (KakaoTalk Channel / 카카오톡 채널) 订位。

4. 多数店铺支持外国信用卡: 弘大片区是外国游客首选动线，支持外国信用卡·三星支付 (Samsung Pay / 삼성페이)·卡卡欧支付 (Kakao Pay / 카카오페이，即韩国版微信支付) 的店铺很多。老字号·小店建议备好现金约₩30,000 (~$22 / ~160 RMB / ~3,200 JPY)。

5. ins打卡·拍照动线: 韩屋 (Hanok / 한옥，传统韩式建筑，类似四合院风格) 小巷·画廊·复古装修·主题咖啡馆众多。想拍出好片，推荐上午11:00或19:00之后的清静时段。

1. 美食·酒吧 — 60家

🍶 特色餐厅 — 想沉浸日本·东南亚氛围的日子 (20家)

这些是在弘大能感受到仿佛置身日本小巷氛围的店铺。小店、吧台席、烤串烟气弥漫，配上一杯清酒，再惬意不过。

🍻 酒吧 — 用氛围下酒的一杯 (10家)

比起下酒菜，更以空间取胜的酒吧们。复古装修、老字号 (老字号，30年以上的传统店) 氛围、90年代情调，还有深夜神秘小吧。

  • 电池88 (Battery 88 / 배터리88) — 美式酒吧休闲风
  • 七号房 (7番房 / 7번방) — 神秘包厢概念，名副其实
  • 红骆驼 (Bulgeun Naktda / 붉은낙타) — 强烈概念的氛围酒吧
  • 太阳厨房 (Sun Kitchen / 썬키친) — 厨房兼酒吧，下酒菜是主角
  • 酒神堂 (Jusinidang / 주신당) — 以十二地支·韩国巫俗信仰为主题的鸡尾酒吧
  • 朝鲜时代 (Joseon Sidae / 조선시대) — 韩式复古装修令人震撼
  • 深夜食堂夜 (Simya Sikdang Bam / 심야식당밤) — 日剧《深夜食堂》风格
  • 西桥布查 (Seogyo Pocha / 서교포차) — 布查 (Pocha / 포차，即韩国路边摊酒馆，类似大排档) 原汁原味的街坊感，完全保留
  • 山울림1992 (Sanurim 1992 / 산울림1992) — 90年代情调的正统韩式酒馆
  • 无彩色 (Muchaeksaek / 무채색) — 极简·单色调的沉静酒吧

> #### 🎯 深度精选 — 山울림1992 (Sanurim 1992 / 산울림1992)

> 弘大韩式酒馆的精髓。正如其名，从1992年起就守在同一地方，与昔日 山울림小剧场 (Sanurim Sogeukjang / 산울림 소극장) 在情感上一脉相承的空间。菜单以非融合的正统韩式料理为基础，传统酒·药酒 (Yakju / 약주，即韩国传统酿造酒，类似日本清酒) 阵容扎实。价位比附近居酒屋略高，但"食物真的好吃，下次还会来"的评价始终如影随形。想吃韩食、想静静小酌的日子，这里就是答案。

>

> #### 🎯 深度精选 — 酒神堂 (Jusinidang / 주신당)

> 以十二地支与韩国巫俗信仰为概念的鸡尾酒吧。刚走进去，昏暗神秘的空间会让人忍不住想："这真的是店吗？"招牌是以十二地支为主题的鸡尾酒菜单 — 子(鼠)、丑(牛)、寅(虎)……按自己的生肖点酒，别有一番趣味。一侧墙壁上贴满了客人写下的心愿纸条。下酒菜为韩式融合风格。营业时间为每晚18:00至次日02:00，比起第一摊，更适合作为第二摊·第三摊。

> #### 🎯 深度精选 — 玉东植 (Ok Dongsik / 옥동식)

> 2017年在 西桥洞 (Seogyo-dong / 서교동) 开业的猪骨汤专门店。以主厨本人的名字"玉东植 (Ok Dongsik / 옥동식)"直接作为店名。招牌猪骨汤以智异山 (Jirisan / 지리산) 伯克夏K黑猪的前·后腿肉慢火熬制的清澈汤底为核心 — 与一般猪汤饭的乳白色汤底截然不同，呈现出金黄透明的汤色。自2018年起连续入选米其林指南必比登推介，并于2023年罕见地以韩食之名登上《纽约时报》"年度最佳美食8选"。座位以吧台为主约10席，每日限量100碗运营，午餐时段前便常常售罄。若要前往，开门后至午餐初段是最稳妥的时机。

>

> #### 🎯 深度精选 — 正돈 (Jeongdon / 정돈)

> 弘大猪排排队打卡的代表店。里脊猪排 (Rosu Katsu / 로스카츠) 与菲力猪排 (Hire Katsu / 히레카츠) 两种为主打，厚实之中内里依然保持湿润是其招牌。店内空间较小，平日午餐也需等位，周末则要做好等30分钟~1小时的心理准备。适合在韩国寻找正统日式猪排体验的人。

>

> #### 🎯 深度精选 — 校洞家 (Gyodong Jip / 교동집)

> 位于弘大 骨目 (Golmok / 골목，即韩国特色小巷街道) 深处的整鸡锅·参鸡汤专门店。在浓郁鸡汤底中加入蔬菜·面条·饺子，一套吃到底的正统整鸡锅。因店小翻台慢，等待时间较长，但一碗下肚极为饱腹，晚午餐或早晚餐时段前往，当天一餐便得以圆满解决。
