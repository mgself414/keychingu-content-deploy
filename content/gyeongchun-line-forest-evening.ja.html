蘆原 京春線森の道、夕暮れ — 花郎台の旧駅から京春鉄橋の音楽噴水まで、廃線6.8kmを西へ歩く順番

副題: ソウルの廃線公園は二つある。西の京義線森の道(#491)は2016年完成、東の京春線森の道は2026年6月に6.8kmが全通した。この回は東の道を夕暮れに歩く — 1939年築の旧駅が灯る花郎台から出発し、孔陵洞の市場を抜け、京春鉄橋の20時30分の音楽噴水で終わる。約3時間、火~日曜のみ。

ISSUE · #1363 · 2026-09-07

🎯 フレーム — 東の廃線、日没後が本編

弘大 (Hongdae / 홍대)・延南 (Yeonnam / 연남) の京義線森の道 (Gyeongui Line Forest Trail / 경의선숲길)は外国人でもみな知っている。ソウルにはその対がもう一つある。都市の北東の端、蘆原区 (Nowon-gu / 노원구) を横切る京春線森の道 (Gyeongchun Line Forest Trail / 경춘선숲길) — 2010年に列車が途絶えた京春線の線路跡に作った6.8kmの線形公園だ。京義線森の道より少し長く、完成は10年遅れた。2026年6月29日にようやく最後の870mが開通し、光云大駅 (Gwangun University Station / 광운대역) から花郎台まで一本につながった。

この道は昼より夕方がいい。東の端、花郎台鉄道公園 (Hwarangdae Railroad Park / 화랑대 철도공원) の旧花郎台駅 (old Hwarangdae Station / 옛 화랑대역) の駅舎には日没30分前に灯がともり、西の端、京春鉄橋 (Gyeongchun Railway Bridge / 경춘철교) の音楽噴水は19時30分と20時30分に水を上げる。その間に孔陵洞 (Gongneung-dong / 공릉동) の夕方の市場がある。だからこの回は東から西へ歩く — 点灯から始まり、噴水で終わるように。

  • 総所要時間: 約3時間(徒歩約6km・1時間半 + 滞在時間 — 区間の分数は推定)
  • おすすめ時間帯: 火~日曜、日没30分前出発。9月初めのソウルの日没は18時50分前後なので17時45分花郎台駅 (Hwarangdae Station / 화랑대역) 出発、10月末は日没が17時30分台に早まるため1時間繰り上げる。月曜は蘆原ライトガーデン (Nowon Light Garden / 노원불빛정원)・音楽噴水どちらも休み。
  • 傾斜: なし — 元は鉄道だった道なので平坦、自転車・歩行者は区分

なぜ京春線森の道なのか — 新しく完成した東のバージョン

京春線は1939年に敷かれたソウル–春川 (Chuncheon / 춘천) 鉄道だ。2010年に路線が移設され蘆原区間が廃線となり、2013年に公園化に着手して2017年に約6kmがまず開通した。残りは月渓洞 (Wolgye-dong / 월계동) 側の870m — 2026年6月29日にこの区間が開通し、光云大駅歩行者用陸橋から京春鉄橋、孔陵洞を経て花郎台まで6.8kmが初めて途切れず繋がった。同じ日、京春鉄橋の上には音楽噴水が、半月後には橋の上のカフェが開いた。要するにこの道は2026年に完成した道だ。

京義線森の道(6.3km、2016年完工)が弘大・延南のカフェ街とともに育ったなら、京春線森の道はマンションと学校、市場の間を通る住宅地の道だ。観光地ではなく町が使う公園 — 外国人にとってはそれがむしろ見どころになる。

📖 物語1 — 列車が走っていた道の上を歩く: 旧花郎台駅は1939年7月「泰陵駅」として開業し、1958年に花郎台駅と改称され、2010年まで列車を受け入れた。ソウルに残る最後の簡易駅だ(国家登録文化財、2006年指定)。駅前の線路には今も列車が停まっている — ただし動かない展示用で、その線路が続いていた場所を今夜あなたが歩く。

🚶 コース — 東の端から西の端へ

起点は6号線花郎台駅4番出口。駅名と旧駅舎が同じ「花郎台」で紛らわしいが、地下鉄駅から旧駅舎までは900m、徒歩15分ほど離れている。

① 花郎台駅4番出口 → 花郎台鉄道公園(🚶 約15分)

  • 花郎路 (Hwarang-ro / 화랑로) に沿って東へ。公園入口に旧花郎台駅の駅舎(平屋木造、1939年)と、その前の線路上に展示車両 — 狭軌の蒸気機関車と客車、海外から来た路面電車などが並ぶ(構成は現地表示に準拠)。駅舎の中は展示スペースとして使われている。
  • 日が暮れる前に着いて、列車と駅舎を明るいうちに一度見ておく。コンテナを改装したギャラリー、引退した客車を使った時計展示館、列車カフェが隣にあるが、営業時間は施設ごとに異なるので現地確認。

② 蘆原ライトガーデン点灯(滞在約30分)

  • 鉄道公園一帯の照明庭園。火~日曜、日没30分前に灯り22時に消える。月曜休み、無料、悪天候時は休み。 点灯時刻は季節ごとに動くので、「何時」ではなく「日没30分前」として覚えておく。
  • 灯りがともる瞬間がこのコースの最初のクライマックス。列車と駅舎に灯りが上がったら写真はここで撮り、30分以内に出発する — 西の端の噴水が20時30分に始まるからだ。

③ 鉄道公園 → 京春線森の道を西へ → 孔陵洞(🚶 約40分・推定)

  • 旧線路の方向、つまり西へ森の道に入る。歩道と自転車道が分かれていて、両側はマンション・学校・住宅。散歩に出た地元の人たちと同じ速さで歩く。
  • 📖 物語2 — 二つの廃線の対: ソウルは都心を通っていた鉄道二つを、10年の間隔を置いて公園に変えた。西の京義線森の道は2016年、東の京春線森の道は2026年。どちらも「列車が通っていた幅」をそのまま残したので狭くて長い。弘大側がカフェと旅行者の道になったのに対し、こちらはベビーカーと自転車の道として残った — 同じ設計、違う町。

④ 孔陵洞トッケビ市場 (Gongneung-dong Dokkaebi Market / 공릉동도깨비시장) の夕方(🚶 約10分 + 滞在約20分)

  • 7号線孔陵駅 (Gongneung Station / 공릉역) 2番出口から7分の常設伝統市場。毎日8時~22時営業なので夕方も開いている(全体の定休日は未確認 — 名節当日は閉める店が多い)。粉食・惣菜・果物の路地をひと回りして、夕食を軽く済ませる。店の実名は挙げない — 市場そのものが目的地だ。
  • 時間が足りなければここで終える: 孔陵駅がすぐ隣だ(コースA終了)。噴水は別の日に月渓駅 (Wolgye Station / 월계역) で30分だけ別途見てもいい。

⑤ 孔陵 → 月渓洞・京春鉄橋(🚶 約45~50分・推定)

  • 再び森の道に上がって西へ。この区間が最も長く最も暗い — 森の道全体の夜間照明は確認できていないので(鉄道公園区間のみ確認)、街灯のない区間は大通りに並行する側を歩く。20時15分までに橋に着くのが目標。

⑥ 京春鉄橋 音楽噴水20:30 — 終了(約20分 + 🚶 約10分)

  • 中浪川 (Jungnangcheon / 중랑천) を渡る旧京春線の鉄橋の上。2026年6月30日開場、10月31日まで火~日19:30・20:30の1日2回、1回約20分、月曜・雨天休み。 レーザーと鏡を使った噴水ショーが橋の下の水面に繰り広げられる。橋の上には列車の形をしたカフェ(3~11月9~21時、火曜休み — 噴水と休みの日が違う)があり、噴水を待つのにちょうどいい。
  • 終了: 1号線月渓駅4番出口へ徒歩約10分(約800m)。光云大駅側の進入路(歩行者用陸橋)もあるが、距離は確認できなかった。

🙏 このコースのマナー — 住宅街の公園

  • 森の道の両側はすべて住宅だ。夜に大声を出さない、音楽はイヤホンで。
  • 歩道と自転車道が分かれている。写真を撮るために自転車道に立ち止まらない。
  • 市場で商品や人を正面から撮らない。買う前に触らない。
  • ライトガーデン・鉄橋の欄干に上がらない。噴水の水がかかる場所は前列ではなく後列だ。
  • ゴミは持ち帰る。公園にはゴミ箱が少ない。

💡 戸惑いポイント

  • 月曜日はコースが成立しない: ライトガーデン・音楽噴水どちらも月曜休み。泰陵・康陵 (Taereung and Gangneung Royal Tombs / 태릉·강릉)(王陵)も月曜休館。
  • 花郎台駅 ≠ 花郎台旧駅: 地下鉄6号線花郎台駅(ソウル女子大入口)から旧駅舎まで900m・15分。森の道へ直接行くなら2番出口(8~10分)、鉄道公園へ行くなら4番出口。
  • 点灯時刻は毎日違う: 「日没30分前」なので9月初めは18時20分ごろ、10月末は17時ごろ。出発前にその日の日没時刻を確認する。
  • 噴水は10月31日まで: 11月からは⑥が外れる — その時期は花郎台ライトガーデン(22時まで)だけでコースを半分に縮める。
  • 雨が降ればどちらも休み: ライトガーデンは悪天候時、噴水は雨天時休み。代案は屋内の#280。
  • 市場は現金が便利: カード対応の店が多いが、少額は現金(#1301)。交通カードは#1298。

FAQ 6

Q1. 必ず6kmを全部歩かなければならないか?

  • いや。④孔陵洞で終える短縮版(約1時間半)がある。噴水は月渓駅で別途30分あれば見られる。

Q2. 京義線森の道と何が違うか?

  • 長さは近く(6.3km対6.8km)、性格が違う。京義線森の道はカフェ街、京春線森の道は住宅地の公園。そしてこちらにだけ旧駅舎・展示車両・橋の上の噴水がある。

Q3. 昼に行くと?

  • 昼なら泰陵・康陵 — 朝鮮王陵、9~18時(9~10月基準)・月曜休館・1,000ウォン、6号線泰陵入口駅 (Taereung Station / 태릉입구역) 側 — を前に付けられる。ただしこの回は夕方編なのでコースには入れない。

Q4. 子供と一緒なら?

  • 平坦・無料・トイレは公園と市場にある。展示車両と噴水は子供のほうがより喜ぶ。ただし⑤区間が長いので、ベビーカーなら④で終える。

Q5. いくらかかるか?

  • 入場料0ウォン。市場の夕食1万ウォン前後、交通費片道。このコースはソウルで最も安い夕方コースの一つだ。

Q6. 外国人が行っても浮かないか?

  • 観光地ではなく町だ。英語案内は少ない。その代わり誰もあなたを観光客として見ない — それがこの道の魅力だ。
