ISSUE 03 · #828 · 2026-06-08

🎯 왜 한국 술 매트릭스인가

외국인 한국 술 페인포인트 = "소주만 알고 있다". 한국 술 = K-drama·K-pop 다음 글로벌 인지도 한국 문화 1번지 + 회식·치맥·한정식 페어링 1번지. 같은 "Korean alcohol"이라도 소주 (참이슬·처음처럼 글로벌)·맥주 (카스·테라·하이트)·막걸리 (전통 발효주)·청주 (정통 사미)·전통주 (안동소주·한산소곡주·전주 모주)·하이볼 (위스키+탄산 MZ 트렌드) 각자 다른 도수·페어링·문화. 외국인은 (a) 소주 도수 약 16~17% 모름 (b) 막걸리 흔들기·잔 따르기 매너 모름 (c) 소맥 비율 모름 (d) 폭탄주 강요 거부 매너 모름. 본 가이드는 6종 매트릭스 + 페어링 + 외국인 입문 우선순위.

★ 한눈에 술 6종 매트릭스

종류 한국명·영문 도수 가격 (병/잔) 외국인 추천도
🍶 소주 (Soju) Korean clear distilled 16~17% (저도수 ~12%) 4,000~6,000원/병 ★★★★★ (#1 글로벌)
🍺 맥주 (Maekju) Korean beer 4~5% 4,000~8,000원/병 / 5,000~8,000원/잔 (생맥주) ★★★★★ (#1 입문)
🍯 막걸리 (Makgeolli) Rice wine 5~8% 5,000~10,000원/병 (750ml) ★★★★★ (전통 #1)
🍵 청주 (Cheongju) Korean sake 13~17% 8,000~25,000원/병 ★★★★ (정통)
🏛 전통주 (Jeontongju) Traditional liquors 15~45% (안동소주 45%) 15,000~80,000원/병 ★★★ (매니아)
🥃 하이볼 (Highball) Whisky highball 5~8% (희석) 8,000~15,000원/잔 ★★★★ (MZ 트렌드)

외국인 입문 1순위 = 맥주 + 막걸리 (안전한 도수)

글로벌 인지도 1순위 = 소주 (참이슬·처음처럼)

MZ 트렌드 = 하이볼·과일 소주·저도수 소주

🥃 한국 술 6종 deep dive

🍶 소주 (Soju) — 글로벌 #1

  • 시그니처: 한국 #1 글로벌 인지도 술 + 회식·치맥·BBQ 페어 #1
  • 종류:
  • 참이슬 (JINRO) — 한국 #1 점유율 (1924 진로 창업)
  • 처음처럼 — 부드러움 강조
  • 새로 (Saero) — 저도수 (16.5% → 12%)
  • 과일 소주: 자몽·복숭아·청포도·딸기 (외국인 #1 입문)
  • 도수: 16~17% (저도수 12~14%)
  • 외국인 친화도: ★★★★★ (글로벌 인지도)
  • 가격: 4,000~6,000원/병 (식당) / 1,500~2,500원 (편의점)
  • 추천 페어링: BBQ (삼겹살)·치킨·회·국밥

🍺 맥주 (Maekju)

  • 시그니처: 한국 #1 입문 술 + 치맥 (Chimaek) 글로벌 트렌드
  • 종류:
  • 카스 (Cass) — 한국 #1 점유율 (가성비)
  • 테라 (Terra) — 청정·가벼움
  • 하이트 (Hite) — 클래식
  • 수입 맥주: 칭다오·아사히·하이네켄·기네스 (이태원 펍 ★)
  • 도수: 4~5%
  • 외국인 친화도: ★★★★★ (글로벌 인지도)
  • 가격: 4,000~8,000원/병 / 5,000~8,000원/잔 (생맥주)
  • 추천 페어링: 치킨·BBQ·횟집·분식

🍯 막걸리 (Makgeolli) — 전통 #1

  • 시그니처: 한국 전통 발효주·쌀 베이스·달콤·부드러움
  • 종류:
  • 장수 막걸리 (Jangsu) — 한국 #1 브랜드
  • 국순당 — 정통 + MZ 트렌드
  • 느린마을 — 프리미엄
  • 막걸리 양조장 — 안동·진주 정통 매니아
  • MZ 트렌드 막걸리: 우유 막걸리·복숭아 막걸리·딸기 막걸리
  • 도수: 5~8%
  • 외국인 친화도: ★★★★★ (부드러움 + 전통 매니아)
  • 가격: 5,000~10,000원/병 (750ml)
  • 추천 페어링: 김치전·해물파전·보쌈·녹두전 (비 오는 날 #1)

🍵 청주 (Cheongju) — 정통

  • 시그니처: 한국 청주 (일본 사케 유사)·정통 한식 페어
  • 종류:
  • 국순당 청주
  • 백화수복 — 전통 명문
  • 무알콜 청주 — 한식 코스 페어
  • 도수: 13~17%
  • 외국인 친화도: ★★★★ (정통·한식 코스)
  • 가격: 8,000~25,000원/병
  • 추천 페어링: 한정식·궁중요리·회·일식

🏛 전통주 (Jeontongju) — 매니아

  • 시그니처: 지역 전통주·정통 양조 매니아
  • 종류:
  • 안동소주 (45% 정통 증류주, 희석 20~22% 변형 시판) — 안동 시그니처
  • 한산소곡주 (16% 충남 한산) — 1500년 역사
  • 전주 모주 (10~15%) — 전주 시그니처 (한약재)
  • 진도 홍주 (40%) — 진도 정통
  • 이강주 (25%) — 전주
  • 도수: 15~45%
  • 외국인 친화도: ★★★ (매니아·정통 매장)
  • 가격: 15,000~80,000원/병
  • 추천 페어링: 한정식·궁중요리·접대

🥃 하이볼 (Highball) — MZ 트렌드

  • 시그니처: 위스키 + 탄산수 + 레몬 = 부드러움 + MZ 트렌드 1번지
  • 종류:
  • 위스키 하이볼: 산토리·잭다니엘·시바스
  • 김렛·진토닉 (MZ 변형)
  • 소주 하이볼 (MZ 변형)
  • 도수: 5~8% (희석)
  • 외국인 친화도: ★★★★ (MZ 트렌드)
  • 가격: 8,000~15,000원/잔
  • 추천 페어링: 일식·치킨·MZ 분식

소맥 (Soju + Beer) — 한국 회식 #1

  • 비율: 1:3 (소주 1 : 맥주 3) 또는 1:2.5
  • 만들기: 맥주잔 → 맥주 → 소주잔 → 소주 → 흔들기
  • 외국인 매니아: 한국 회식 정통 1번지

🍶 막걸리 마시는 법

막걸리 매너

1. 흔들기: 그릇 바닥 침전물 + 위쪽 맑은 부분 = 흔들어서 풀기

2. 잔 따르기: 어른에게 두 손으로 따르기

3. 받기: 두 손으로 잔 받기

4. 건배: "건배!" 또는 "위하여!"

5. 첫 잔: 한 입 또는 통째 (개인 취향)

외국인 영어 발화 샘플

  • "막걸리 한 병" = "One makgeolli, please"
  • "소주 두 병" = "Two bottles of soju"
  • "소맥" = "Somaek (soju + beer)"
  • "건배!" = "Cheers!"
  • "안 마실래요" = "I don't drink, thanks"
  • "한 잔만" = "Just one shot, please"

⚠ 외국인 자주 실수 7가지

1. "소주 = 보드카·진처럼 강함": 소주 = 16~17% (보드카 40%의 절반 이하 수준). 부드럽지만 회식 문화에 술잔 많음 = 누적 알코올 ↑.

2. "막걸리 = 약함": 막걸리 = 5~8% 비교적 약하나, 빠른 발효 = 다음 날 숙취 ↑ 가능.

3. "소맥 강요 = 거부 못함": 한국 현대 회식 문화 = 강요 거부 OK. "I don't drink" 또는 손바닥 위 컵 들기.

4. "하이볼 = 약함": 하이볼 = 베이스 위스키 40%+. 희석되어 5~8%지만 1잔당 알코올 = 1.5~2 표준잔.

5. "막걸리 = 흔들기 X": 막걸리 = 반드시 흔들기. 침전물 (효모) + 맑은 부분 섞기.

6. "한국 술 = 음주운전 OK": 한국 = 0.03% BAC = 면허정지. 음주운전 절대 금지 (벌금 + 면허 정지).

7. "전통주 = 흔히 마심": 전통주 = 매니아·정통 매장 한정. 일반 술집 = 소주·맥주·막걸리 多.

⚙ FAQ 8개

1. 외국인 입문 1순위: 맥주 (입문) → 막걸리 (전통) → 소주 (글로벌) → 소맥 (회식) 단계.

2. 인스타·vlog: 막걸리 양조장·전통주 매니아·MZ 하이볼 바.

3. MZ 트렌드: 과일 소주·저도수 소주·하이볼 바·우유 막걸리.

4. 회식·접대: 소주·맥주 (일반)·청주·전통주 (정통 접대).

5. 음주 매너: 어른에게 두 손 따르기·받기·고개 돌려 마시기 (어른 앞).

6. 음주운전: 한국 = 0.03% BAC = 면허정지. 절대 금지.

7. 알레르기: 글루텐 (맥주)·콩 (막걸리·청주)·과일 (과일 소주) 사전 고지.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·법률 disclaimer

한국 술 = 알코올 (도수 4~45%). 음주운전 0.03% BAC 면허정지 + 벌금 + 형사처벌 (강력 단속). 임신부·약물 복용자 = 음주 금지. 어린이·청소년 (만 19세 미만) = 법적 음주 금지. 알레르기 (글루텐·콩·과일·견과류) 사전 고지. 식중독·과음 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

음주 매너:

  • 강요 거부 OK (현대 한국 회식 문화)
  • "I don't drink" 또는 손바닥 위 컵 들기
  • 어른 앞 = 고개 돌려 마시기 (전통)

식이 제한 fallback:

  • 할랄·코셔: 알코올 = 비할랄·비코셔 기본. 무알콜 옵션 (탄산수·식혜·수정과) 추천.
  • 무알콜: 식혜·수정과·국화차 (전통 음료) OR 무알콜 맥주·무알콜 청주.
