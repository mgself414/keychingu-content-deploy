외국인 경상도 1일 메타 가이드 — 경주·안동·통영·진주 4축

> 부제: 외국인 관광객용 경상도 4축 시그니처 12선 + 1일 풀데이 + UNESCO 경주·안동 + 외국인 영문

ISSUE 04 · #1051 · 2026-06-08

🎯 왜 경상도 가이드인가

경상도 (Gyeongsang-do) = 한국 #1 UNESCO 매트릭스 (경주·안동) + 통영·진주 매니아·경주 = 신라 천년고도 (BC 57~AD 935·UNESCO 1995)·안동 = 하회마을 UNESCO 2010·통영 한산도·진주 촉석루. 외국인 페인포인트 = (a) "경상도 = 부산만" 잘못된 인식 (b) 경주 = UNESCO 1995 (불국사·석굴암) + 신라 천년고도 (c) 안동 = UNESCO 2010 하회마을·도산서원 (d) 통영 = 한산도·이순신·해상국립공원 (e) 진주 = 촉석루·진주성·진주냉면·유등축제.

본 가이드는 4축 12 시그니처 + 1일 풀데이 + UNESCO + 외국인 영문.

★ 한눈에 4축 12 시그니처

# 매장·동선 4축 시그니처
1 경주 불국사 (UNESCO 1995) ① 경주 신라 751년·UNESCO
2 경주 석굴암 (UNESCO 1995) ① 경주 석굴 + 부처
3 경주 + 천마총 + 박물관 ① 경주 신라 천년고도
4 안동 하회마을 (UNESCO 2010) ② 안동 한국 #1 양반 마을
5 안동 + 도산서원 ② 안동 퇴계 이황 매트릭스
6 안동 + 찜닭·간고등어 ② 안동 안동 시그너
7 통영 한산도 (이순신) ③ 통영 이순신 + 1597년
8 통영 + 해상국립공원 ③ 통영 한국 #1 해상국립공원
9 통영 + 동피랑·통영 시그너 ③ 통영 MZ + 인스타
10 진주 촉석루 + 진주성 ④ 진주 임진왜란 1592년
11 진주 + 진주냉면 + 유등축제 (10월) ④ 진주 진주 시그너
12 진주 + 한정식 + 카페 ④ 진주 MZ + 매니아

> 외국인 1순위: 경주 + 안동 = 1박 매니아 매트릭스 #1

> 매니아: 통영 + 진주 + 1박 풀세트

🏛 4축 deep dive

① 경주 (UNESCO 1995·신라 천년고도)

  • 시그니처: 불국사 (751년·UNESCO)·석굴암 (UNESCO)·천마총·국립경주박물관·신라 천년고도 (BC 57~AD 935)
  • 외국인 친화도: ★★★★★ (영문 풀세트·UNESCO 매니아 매트릭스 #1)

② 안동 (UNESCO 2010·하회마을)

  • 시그니처: 하회마을 (UNESCO 2010)·도산서원 (퇴계 이황)·찜닭·간고등어
  • 외국인 친화도: ★★★★★ (영문·문화 매니아)

③ 통영 (해상국립공원·이순신)

  • 시그니처: 한국 #1 해상국립공원·한산도 (이순신 1597년)·동피랑
  • 외국인 친화도: ★★★★ (영문·매니아)

④ 진주 (촉석루·유등축제)

  • 시그니처: 촉석루 (임진왜란 1592)·진주성·진주냉면·유등축제 (10월)
  • 외국인 친화도: ★★★★ (영문·매니아)

🗺 외국인 1일 풀데이 코스 (경주)

시간 동선 음식
09:00~10:30 KTX 신경주역 도착 + 경주 시내 + 천마총 -
10:30~13:00 불국사 (UNESCO 1995) + 석굴암 8,000~12,000원
13:00~14:30 점심 = 경주 한정식 25,000~50,000원/인
14:30~16:30 안압지 + 첨성대 + 국립경주박물관 4,000~8,000원
16:30~18:30 경주 야경 + 카페 cluster + 인스타 카페
18:30~20:00 저녁 = 경주 한식 + 막걸리 25,000~50,000원/인
20:00~22:00 KTX 신경주역 귀가 (또는 1박) -

총 소요: 1일·총 비용 = 100,000~200,000원/인

🚄 교통 + 결제

  • 서울→경주: KTX 신경주역 2시간 (45,000원·왕복 90,000원)
  • 서울→안동: KTX 청량리·서울역 → 안동역 2시간 30분
  • 서울→통영: KTX + 시외버스·총 4시간
  • 서울→진주: KTX 진주역 3시간 30분
  • 부산→경주: KTX 30분
  • 결제: 카드 OK·팁 X

⚠ 외국인 자주 실수 5가지

1. "경상도 = 부산만": UNESCO 경주·안동·통영·진주 매트릭스.

2. "경주 = 일반 도시": UNESCO 1995 + 신라 천년고도·매트릭스 #1.

3. "안동 = 안 알려짐": UNESCO 2010 하회마을·도산서원 매니아 매트릭스.

4. "통영 = 일반 항구": 한국 #1 해상국립공원·이순신 + 동피랑.

5. "진주 = 일반 도시": 촉석루·진주성·진주냉면·유등축제 (10월).

⚙ FAQ 6개

1. 외국인 입문 1순위: 경주 + 안동 = UNESCO 풀세트·1박 권장.

2. 불국사·석굴암: UNESCO 1995·외국인 매니아 매트릭스 #1.

3. 하회마을 (안동): UNESCO 2010·한국 #1 양반 마을.

4. 시즌: 봄·가을 베스트·여름·겨울.

5. 부산 + 경주: KTX 30분·1박 패키지 매트릭스.

6. 추천 페르소나: 가족·시니어 = 경주 UNESCO / MZ·인스타 = 통영 동피랑 + 진주 / 매니아·역사 = 안동 + 풀세트.
