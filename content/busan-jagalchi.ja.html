釜山 チャガルチ・国際市場・影島・松島11か所 — 市場の時間、ケーブルカーの料金、行き方

サブタイトル: 釜山に初めて行く旅行者のために、旧市街、影島、松島の3エリア11か所をまとめた。チャガルチ市場は05:00~22:00に開き、第1・第3・第5火曜日に休む。国際市場は09:00~20:00に開き、日曜日に休む。富平カントン夜市は毎日19:30~24:00だ。松島海上ケーブルカーは09:00~21:00(2026-11-24表記、12月から冬季の時間は別途)に動き、大人のエアクルーズ往復が19,000ウォンで、2026-11-30~12-01の2日間は点検のため休む。料金は2026-11-24に確認した大人の定価だ。

🎯 だれのための、なぜこの11か所なのか

釜山に初めて行く外国人旅行者に合わせたリストです。釜山駅に近い昔の中心街の市場と通り、そこからバス1本で着く影島と松島の海辺を、1日か2日で見るときに使います。

3つのエリアに分けました。

  • 旧市街エリア(6か所): チャガルチ市場、国際市場、富平カントン市場(夜市)、BIFF広場、光復路、龍頭山公園・釜山タワー。
  • 影島エリア(2か所): ヒンヨウル文化村、太宗台(ダヌビ列車)。
  • 松島エリア(3か所): 松島海水浴場、松島海上ケーブルカー、松島雲の散歩道。

旧市街の6か所は、都市鉄道1号線の南浦駅 (Nampo / 남포)、チャガルチ駅 (Jagalchi / 자갈치)、中央駅 (Jungang / 중앙) から歩いて行きます。影島と松島は、南浦駅やチャガルチ駅の前からバスで入ります。そのためこの号は、場所ごとに「どの駅の何番出口から、何番のバスに乗るか」を先に書きました。

このエリアは休みの日が場所ごとに違います。市場2か所は休む曜日が互いに違い、太宗台のダヌビ列車は月曜日に休み、松島海上ケーブルカーは2026-11-30~12-01に点検休業があります。曜日ごとに何が閉まるかは、下に別の表でまとめました。

⚠ 表記の原則: 時間、料金、行き方は2026-11-24に閲覧した値です。出典は、Visit Busan、釜山市、太宗台遊園地のサイト、松島海上ケーブルカー運営会社のサイト、韓国空港公社です。料金は大人の定価です。住所と、駅から歩く時間・距離はカカオマップの値で、該当の行に「カカオマップ」と明記しました。旧市街の出口はカカオマップ経路案内の値で、影島・松島のバスに乗る出口はVisit Busanの案内値です。運営時間、料金、バスの路線は変わることがあります。

✈ 金海空港から旧市街へ

  • 空港リムジンには、南浦・チャガルチへ行く路線がありません。 釜山市の英語のお知らせ(2026-11-24閲覧)によると、空港リムジンは2026-01-05の改編後、2方面になりました。海雲台・機張方面が9,500ウォン、西面・釜田方面が6,000ウォンです。
  • 空港からは軽電鉄に乗ります。 韓国空港公社 (Korea Airports Corporation / 한국공항공사) の金海空港案内には、釜山金海軽電鉄に乗り、沙上駅 (Sasang / 사상) で都市鉄道2号線に、大渚駅 (Daejeo / 대저) で3号線に乗り換えると書かれています。
  • 旧市街の駅はすべて1号線です。 この号に出てくる南浦駅、チャガルチ駅、中央駅が都市鉄道1号線です(カカオマップ)。釜山駅も1号線の駅です。
  • 駅は場所ごとに違います。 チャガルチ市場は南浦駅2番出口、国際市場とBIFF広場はチャガルチ駅7番出口、富平カントン市場はチャガルチ駅3番出口、龍頭山公園は中央駅1番出口です(すべてカカオマップ経路案内の基準)。

🚦 歩く前に — 共通の安全とマナー

  • ヒンヨウル文化村は住民が暮らす村です。 Visit Busanは、訪れる人に住民のためのマナーを守るよう書いています。
  • 天気が悪いと乗り物が止まります。 太宗台のダヌビ列車は、雨が降ったり天気が悪かったりすると運行を止めます。松島海上ケーブルカーは、天気と券売の状況によって早く締め切ることがあります。松島雲の散歩道も、天気や施設の補修で立ち入りが制限されることがあります。釜山タワーも、天気によって運営が変わることがあります。
  • 太宗台の海岸には、夜の時間帯の立ち入り規制が登録されています。 カカオマップの登録値(2026-11-24)は20:00~06:00です。
  • 市場の時間は店ごとに違います。 国際市場の09:00~20:00は市場全体の基準で、店舗ごとに違います。
  • 事故や緊急のときは119、犯罪の通報は112に電話します。

① 旧市街エリア — 6か所

都市鉄道1号線の南浦駅、チャガルチ駅、中央駅を使うエリアです。6か所すべて、駅から歩いて行きます。市場3か所は開く時刻が違います。チャガルチ市場は早朝05:00から、国際市場は09:00から、富平カントン夜市は夜19:30からです。1日の中で、朝、昼、夜に分けて入れられます。

チャガルチ市場 (Jagalchi Market / 자갈치시장)

  • どんな所: 海に面した水産物の市場です。
  • 運営時間: Visit Busanの公式案内で05:00~22:00です。カカオマップの登録値(2026-11-24)も毎日05:00~22:00で同じです。
  • 休みの日: Visit Busanの公式案内は、第1・第3・第5火曜日と書いています。
  • 住所(カカオマップ登録値、2026-11-24): 釜山 中区 チャガルチ海岸路 (Jagalchihaean-ro / 자갈치해안로) 52。
  • 行き方: カカオマップ経路案内の基準で、都市鉄道1号線の南浦駅2番出口から徒歩6分(355m)です。Visit Busanの公式案内も、南浦駅2番出口から徒歩6分と書いています。
  • 時間の組み方: 05:00に開き、旧市街の市場3か所のなかで最初に開きます。09:00に開く国際市場より前に入れます。

国際市場 (Gukje Market / 국제시장)

  • どんな所: Visit Busanは、朝鮮戦争のあとにできた市場と紹介しています。
  • 運営時間: Visit Busanの公式案内で09:00~20:00です。店舗ごとに違います。
  • 休みの日: 日曜日。
  • 住所(カカオマップ登録値、2026-11-24): 釜山 中区 新昌洞4街 (Sinchang-dong 4-ga / 신창동4가) 56-4。
  • 行き方: カカオマップ経路案内の基準で、1号線チャガルチ駅7番出口から徒歩8分(462m)です。
  • バス: Visit Busanの公式案内は、15・40・86・126・186番に乗り、「国際市場 (Gukje Market / 국제시장)」で降りて徒歩4分と書いています。
  • 時間の組み方: 20:00に閉まります。19:30に始まる富平カントン夜市より前に入れます。日曜日に釜山にいるなら、国際市場は別の日に移します。

富平カントン市場・富平カントン夜市 (Bupyeong Kkangtong Market / 부평깡통시장)

  • 夜市の時間: Visit Busanの公式案内で毎日19:30~24:00です。曜日を問わず開きます。伝統的な名節には休みます。
  • カカオマップ登録値(2026-11-24): 毎日19:30~24:00で同じです。
  • 住所(カカオマップ登録値、2026-11-24): 釜山 中区 富平洞2街 (Bupyeong-dong 2-ga / 부평동2가) 82。
  • 行き方: カカオマップ経路案内の基準で、1号線チャガルチ駅3番出口から徒歩10分(563m)です。Visit Busanの公式案内も、チャガルチ駅3番出口から徒歩約10分と書いています。
  • 時間の組み方: 19:30~24:00は夜市の時間です。市場の中の店舗の昼の営業は、店ごとに別です。昼に旧市街を回り、夕食の時刻に合わせて最後に入れます。

BIFF広場 (BIFF Square / BIFF광장)

  • どんな所: 南浦洞にある屋外の広場です。Visit Busanの南浦洞案内が、この一帯の主な見どころとしてBIFF広場を挙げています。
  • 住所(カカオマップ登録値、2026-11-24): 釜山 中区 南浦洞3街 (Nampo-dong 3-ga / 남포동3가) 15-1。
  • 行き方: カカオマップ経路案内の基準で、1号線チャガルチ駅7番出口から徒歩4分(238m)です。
  • 組み合わせ方: 国際市場と同じ7番出口を使います。出口からBIFF広場まで徒歩4分、国際市場まで徒歩8分です。

光復路 (Gwangbok-ro Fashion Street / 광복로)

  • どんな所: 店が並ぶショッピング通りです。Visit Busanは「光復路ファッション通り」と紹介しています。
  • 利用時間・料金: Visit Busanの公式案内で常時開放で、通り自体は無料です。営業時間は店ごとに違います。
  • 行き方: 都市鉄道1号線の南浦駅から歩いて行きます。Visit Busanの光復路案内は、南浦駅から徒歩5分と書いています。
  • 龍頭山公園へ上る道: Visit Busanの公式案内によると、光復路から龍頭山公園へ上る87mのエスカレーターがあります。光復路を歩いてから、このエスカレーターで公園に上がる順にします。

龍頭山公園・釜山タワー (Yongdusan Park · Busan Tower / 용두산공원·부산타워)

  • 龍頭山公園: Visit Busanの公式案内で無料で、通年開放です。カカオマップの登録値(2026-11-24)は24時間です。
  • 釜山タワーの運営時間: Visit Busanの公式案内で10:00~22:00で、入場は21:30に締め切ります。天気によって運営が変わることがあります。カカオマップの登録値(2026-11-24)も毎日10:00~22:00です。
  • 料金: 公園は無料です。釜山タワーの展望台は、公園とは別に料金がかかります。
  • 住所(カカオマップ登録値、2026-11-24): 龍頭山公園は釜山 中区 龍頭山通り (Yongdusan-gil / 용두산길) 37-55、釜山タワーは龍頭山通り37-30。
  • 行き方: カカオマップ経路案内の基準で、1号線中央駅1番出口から公園まで徒歩10分(432m)、釜山タワーまで12分(562m)です。
  • ほかの道: 光復路の側からは、87mのエスカレーターで上がれます。
  • 時間の組み方: タワーは22:00まで開いていますが、入場は21:30で終わります。富平カントン夜市(19:30~24:00)を先に見てから上がるなら、21:30前にタワーの入口に着く必要があります。順番を変えて、日暮れ前後にタワーに上がり、夜市へ下りるほうが、時間を合わせやすいです。

② 影島エリア — 2か所

影島には都市鉄道の駅がありません。2か所とも、南浦洞からバスで入ります。ヒンヨウル文化村は住民が暮らす村で、太宗台は遊園地です。太宗台は、周回列車のダヌビ列車が月曜日に休みます。

ヒンヨウル文化村 (Huinnyeoul Culture Village / 흰여울문화마을)

  • どんな所: 影島にある村です。今も住民が暮らしています。
  • 利用時間: Visit Busanの公式案内で毎日開放です。
  • 訪問のマナー: Visit Busanの公式案内は「住民のためのマナーを守ってください」と書いています。観光地である前に、人が住む家と路地です。
  • 行き方(Visit Busanの公式案内): 都市鉄道1号線の南浦駅6番出口を出て、バス7・71・508番に乗ります。ヨンソンドン (Yeongseon-dong / 영선동) のペンニョン寺 (Baengnyeonsa / 백련사) 方面の停留所で降り、階段で村に入ります。
  • 駐車: 絶影海岸散策路 (Jeoryeong Coastal Trail / 절영해안산책로) の入口に有料の公営駐車場があります。
  • 住所(カカオマップ登録値、2026-11-24): 釜山 影島区 ヨンソンドン4街 (Yeongseon-dong 4-ga / 영선동4가) 605-3。
  • 道の性格: 停留所から階段で村に入ります。

太宗台・ダヌビ列車 (Taejongdae · Danubi Train / 태종대)

  • どんな所: 影島にある遊園地です。遊園地の中をダヌビ列車が回ります。
  • 遊園地の利用時間(カカオマップ登録値、2026-11-24): 毎日05:00~24:00(カカオマップ、冬季)。海岸は20:00~06:00に立ち入りを規制します。
  • 入場料: Visit Busanの公式案内で、遊園地の入場は無料です。ダヌビ列車は別に切符を買います。
  • ダヌビ列車の運行(Visit Busanの公式案内): 10~5月は09:20から17:30まで走ります。券売は09:00に始まり、17:30に終わります。カカオマップの登録値(2026-11-24)も09:20~17:30で同じです。
  • 休みの日: ダヌビ列車は毎週月曜日に休みます。
  • 天気: 雨が降ったり天気が悪かったりすると、ダヌビ列車は運行を止めます。
  • 行き方(太宗台遊園地の公式案内):
  • 南浦洞のロッテ百貨店 (Lotte Department Store / 롯데백화점) の向かいからバス8・17・30・88・186番。約30分。
  • 釜山駅のキョウォンビル (Kyowon Building / 교원빌딩) の向かいからバス17・88・101番。約40分。
  • 住所: 釜山 影島区 チョンマン路 (Jeonmang-ro / 전망로) 24。カカオマップの登録住所は釜山 影島区 トンサムドン (Dongsam-dong / 동삼동) 山29-1です。
  • 問い合わせ: 遊園地の施設 051-860-7866(釜山施設公団 (Busan Facilities Corporation / 부산시설공단))、ダヌビ列車 051-405-8745~6(釜山観光公社 (Busan Tourism Organization / 부산관광공사))。
  • 時間の組み方: 11月はダヌビ列車が17:30に終わります。南浦洞からバスで約30分かかるので、午後遅くに出発すると列車に乗れません。午前か早めの午後に入れます。月曜日なら、太宗台は別の日に移します。

③ 松島エリア — 3か所

3か所とも、都市鉄道1号線チャガルチ駅2番出口からバスで行きます。海水浴場と雲の散歩道は「松島海水浴場 (Songdo Beach / 송도해수욕장)」の停留所で、ケーブルカーは「アムナムドン住民センター (Amnam-dong Community Center / 암남동주민센터)」の停留所で降ります。海水浴場と雲の散歩道は06:00~23:00に無料で開いていて、料金がかかるのはケーブルカーだけです。

松島海水浴場 (Songdo Beach / 송도해수욕장)

  • どんな所: Visit Busanは、1913年にオープンした海水浴場と紹介しています。
  • 利用時間・料金: Visit Busanの公式案内で毎日06:00~23:00で、無料です。
  • 行き方(Visit Busanの公式案内): 1号線チャガルチ駅2番出口を出て、バス96・26・30・7・71番に乗ります。「松島海水浴場 (Songdo Beach / 송도해수욕장)」で降りて、徒歩3分です。

松島海上ケーブルカー (Busan Air Cruise / 송도해상케이블카)

海の上を渡るケーブルカーです。下の値は、運営会社の公式サイトの2026-11-24の表記です。

  • 運営時間: 09:00~21:00。カカオマップの登録値(2026-11-24)も毎日09:00~21:00です。
  • 券売の締め切り: 運営終了の30分前に、チケットの販売を終えます。天気と券売の状況によって、さらに早く締め切ることがあります。
  • 休みの日: 2026-11-30~12-01の2日間は、定期点検のため運行しません。
  • 冬の時間: 2026年12月~2027年2月の冬季営業時間は、運営会社が別に告知します。

松島雲の散歩道 (Songdo Cloud Trails / 송도구름산책로)

🗺 動線 — 半日・1日

順番は、各場所の開く時刻と閉まる時刻に合わせて組みました。機関が書いている移動時間は、南浦洞から太宗台までバスで約30分、釜山駅から太宗台まで約40分です。

半日 A — 旧市街の昼 (日曜日と第1・第3・第5火曜日は避ける)

  1. 1号線南浦駅2番出口 → チャガルチ市場(カカオマップ経路案内の基準で徒歩6分)。05:00から開きます。
  2. チャガルチ駅7番出口 → BIFF広場(出口から徒歩4分)。
  3. 国際市場(チャガルチ駅7番出口から徒歩8分)。09:00~20:00。
  4. 光復路を歩いて、87mのエスカレーターで龍頭山公園に上ります。
  5. 釜山タワー。入場は21:30までです。

日曜日なら3番の国際市場を外し、第1・第3・第5火曜日なら1番のチャガルチ市場を外します。

半日 B — 旧市街の夜 (曜日を問わない、伝統的な名節を除く)

  1. 1号線中央駅1番出口 → 龍頭山公園(カカオマップ経路案内の基準で徒歩10分) → 釜山タワー(10:00~22:00)。
  2. エスカレーターで光復路に下りて、通りを歩きます。
  3. 富平カントン夜市。19:30に始まり、24:00まで開きます。チャガルチ駅3番出口から徒歩10分の距離です。

夜市は毎日開くので、曜日を気にしなくて大丈夫です。タワーを先に見れば、21:30の入場締め切りを心配する必要がありません。

⚠ 紛らわしい点3つ

  1. チャガルチ市場は05:00~22:00に開き、第1・第3・第5火曜日に休みます。 国際市場は09:00~20:00に開き、日曜日に休みます。2つの市場を同じ日にまとめるなら、日曜日と該当の火曜日を外した日を選びます。夜に市場を見たいなら、毎日19:30~24:00に開く富平カントン夜市に行きます。
  2. 場所ごとに、駅と出口が違います。 カカオマップ経路案内の基準で、チャガルチ市場は南浦駅2番出口、国際市場とBIFF広場はチャガルチ駅7番出口、富平カントン市場はチャガルチ駅3番出口、龍頭山公園は中央駅1番出口です。松島へ行くバスはチャガルチ駅2番出口から、ヒンヨウル文化村へ行くバスは南浦駅6番出口から乗ります。
  3. 月曜日に影島・松島の日程を入れること — 太宗台のダヌビ列車は毎週月曜日に休み、11月は17:30に終わります。松島海上ケーブルカーは2026-11-30~12-01に点検で休みます。太宗台は、南浦洞のロッテ百貨店の向かいからバス8・17・30・88・186番で約30分で着きます。

⚙ FAQ 3つ

  1. 表で、料金がかかる場所と無料の場所は? — 料金がかかる場所は、松島海上ケーブルカー(大人のエアクルーズ往復19,000ウォン・片道15,000ウォン、クリスタルクルーズ往復24,000ウォン・片道19,000ウォン)、釜山タワー、太宗台のダヌビ列車です。無料の場所は、龍頭山公園、光復路、太宗台遊園地の入場、松島海水浴場、松島雲の散歩道です。ケーブルカーの料金は、2026-11-24に運営会社のサイトで見た値です。
  2. 金海空港からチャガルチ・南浦洞へはどう行く? — 空港リムジンには、南浦・チャガルチへ行く路線がありません。リムジンは、海雲台・機張方面(9,500ウォン)と西面・釜田方面(6,000ウォン)の2方面です。韓国空港公社の案内のとおり、釜山金海軽電鉄に乗り、沙上駅(2号線)か大渚駅(3号線)で都市鉄道に乗り換えます。
  3. 夜遅くまで開いている所は? — 市場のなかでは、富平カントン夜市が毎日19:30~24:00でいちばん遅いです。龍頭山公園はカカオマップの登録値(2026-11-24)が24時間で、光復路は常時開放です。松島海水浴場と松島雲の散歩道は23:00まで、釜山タワーは22:00まで(入場21:30締め切り)、チャガルチ市場は22:00まで、松島海上ケーブルカーは21:00まで(2026-11-24表記、12月から冬季の時間は別途)です。国際市場は20:00に、ダヌビ列車は11月に17:30に終わります。太宗台の海岸は、カカオマップの登録値で20:00から立ち入りを規制します。
