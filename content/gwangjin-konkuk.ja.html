🎯 このガイドの使い方

以前の「12選」は、飲食店・カフェ12軒の料金と時間がすべて根拠なしで、公式の値がある場所も間違っていました — 子ども大公園駅を5号線としていた(正しくは7号線)、公園を「56万坪」としていた(536,094.5㎡ ≒ 16万坪)、動物園を10~18時としていた(10~17時)、「動物園・遊園地・植物園はすべて無料」としていた(無料なのは入場のみ)、トゥクソムを「トゥクソム遊園地駅から5分」としていた(紫陽駅2番出口から438m)、峨嵯山を「漢陽都城」としていた(高句麗の堡塁)。「朴正煕の指示」「1946年開校・留学生6,000人以上」「ヨット/SUPの料金」にも出典がありません。今回は2026-10-08にVisitSeoul・ソウル市施設公団・漢江事業本部・各公式サイトで確認した値だけを載せます。飲食店・カフェは 建大グルメ通り (Konkuk Food Street / 건대 맛의거리)・羊串通り (Yangkkochi Street / 양꼬치거리)(二次情報)の案内にとどめ、お店は地図アプリのレビュー数で選んでください。

🌳 ソウルの森・トゥクソム — 漢江側で半日

  • ソウルの森 (Seoul Forest / 서울숲): 24時間無料。生態の森は05:30~21:30、昆虫植物園・蝶園は月曜休園で、蝶園は5~10月のみです(VisitSeoul)。ソウルの森駅 (Seoul Forest Station / 서울숲역) 3・4番出口(242m)が近く、トゥクソム駅 (Ttukseom / 뚝섬역) 8番出口は537mです。
  • トゥクソム漢江公園 (Ttukseom Hangang Park / 뚝섬한강공원): 24時間無料。以前の「トゥクソム遊園地駅から徒歩5分」ではなく、公式では 紫陽駅 (Jayang / 자양역) 2番出口から438m です(VisitSeoul)。チャボルレ (Jabeolle / 자벌레) は3番出口(漢江事業本部)。チャボルレ (Jabeolle / 자벌레)(漢江プルプル (Hangang Peulpeul / 한강 플플)): 火~木 10~19、金・土 10~22(8/1から延長)、日・祝日 10~20、月曜・1/1・旧正月・秋夕は休館、無料(2階キッズカフェ 5,000)。ヨット・SUP・バーベキュー・自転車シェア「タルンイ」の料金は公式ページに載っていないため記載しません。

🎡 子ども大公園 — 無料、動物園は17時まで

  • 公園 05~22、動物園 10~17、年中無休、入場無料(一部施設は有料 — 「すべて無料」は誤りでした)。1973-05-05開園、536,094.5㎡(ソウル市施設公団)。最寄りは 7号線 子ども大公園駅 (Children's Grand Park Station / 어린이대공원역)(出口番号は公式ページに記載なし)、または5号線の 峨嵯山駅 (Achasan Station / 아차산역) です。

🛍 建大 — コモングラウンド・ロッテ・グルメ通り

  • コモングラウンド (Common Ground / 커먼그라운드)(峨嵯山路200): 11~22。2026-10-08時点で公式サイトに閉店・工事の告知はなく営業中です。休みと出口は記載なし。
  • ロッテ百貨店建大スターシティ店 (Lotte Konkuk Star City / 롯데백화점 건대스타시티점): 10:30~20、飲食店街は21時まで、10/12(月)休業(公式)。2号線 建大入口駅 (Konkuk University Station / 건대입구역) 5番出口・7号線 4番出口。
  • 建大グルメ通り (Konkuk Food Street / 건대 맛의거리)・羊串通り (Yangkkochi Street / 양꼬치거리): 2号線 建大入口駅 1番出口、時間は店舗ごと — どちらも二次情報です。お店の名前と料金は載せません。

⛰ 峨嵯山 — 1km歩いて登山口へ

  • 24時間無料(VisitSeoul)。峨嵯山駅 (Achasan Station / 아차산역) 2番出口から1km、広渡口駅 (Gwangnaru / 광나루역) 1番出口から1.1km — 以前の「5号線徒歩10分」より遠いです。稜線の堡塁は 高句麗 (Goguryeo / 고구려) の遺跡です(漢陽都城 (Hanyang Doseong / 한양도성) ではありません)。

🗺 コース2つ

  • A 公園で一日: ソウルの森駅からソウルの森(午前) → 紫陽駅からトゥクソム漢江公園・チャボルレ(月曜を除く) → 建大入口で建大グルメ通りの夕食(お店は地図アプリで)。
  • B 家族向け: 子ども大公園(動物園は17時前に) → 峨嵯山駅から峨嵯山の登山口まで1km → 建大のコモングラウンド(22時まで)。

⚠ よくある失敗5つ

1. 子ども大公園を5号線と思う — 7号線の子ども大公園駅です(5号線は峨嵯山駅)。

2. 動物園は18時までと思う — 17時までです。

3. 月曜にチャボルレ・ソウルの森の昆虫植物園へ行く — 休館です。

4. トゥクソム遊園地駅で迷う — 公式のアクセスは紫陽駅の2・3番出口です。

5. 以前の飲食店12選の料金を信じる — すべて根拠なしでした。

⚙ FAQ 6つ

1. すべて無料ですか? — ソウルの森・トゥクソム・チャボルレ・子ども大公園の入場・峨嵯山は無料です。大公園の一部施設は有料です。

2. トゥクソムはどこで降りますか? — 7号線紫陽駅2番出口(438m)、チャボルレは3番出口です。

3. 子ども大公園の動物園は? — 10~17時、年中無休です。

4. コモングラウンドはまだやっていますか? — 営業中です(公式、11~22)。

5. 食事は? — 建大グルメ通り・羊串通り(二次情報)。お店は地図アプリで選んでください。

6. 峨嵯山は何時間かかりますか? — 登山口まで1km。登山の所要時間は公式に掲示されていません。
