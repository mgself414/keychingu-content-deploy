🚈 牛耳新设线——这一带的主轴

  • 北汉山牛耳 → 松林公园 → 4·19民主墓地 → 加五里 → 华溪 → 三阳 → 三阳十字路口 → 松泉 → 北汉山普国门 → 贞陵 → 诚信女大入口 → 普门 → 新设洞，共13站（运营方官方）。
  • 工作日北汉山牛耳首班车05:30·末班车24:37，白天间隔5分钟（官方）。可在诚信女大入口（4号线）·普门（6号线）·新设洞（1·2号线）换乘。
  • 旧版指南中的“牛耳站”并不存在——正确名称是北汉山牛耳站 (Bukhansan Ui / 북한산우이역)。

🥾 北汉山环山路·牛耳岭路

  • 1段松林路：从北汉山牛耳站一侧出发，3.1km·约1.5小时（官方）。属于环山路，不穿登山鞋也能走。
  • 2段巡礼路：2.3km·约1小时10分钟，途经国立4·19民主墓地（官方）。1段+2段连走需半天。
  • 牛耳岭路（第21段）：6.8km·约3.5小时，需预约——reservation.knps.or.kr，外国人·65岁以上·残障人士请电话预约（官方）。每日人数限制·需预约的日期请在官方页面确认。
  • 白云台顶峰路线和牛耳探访支援中心的时间，这次没能读到官方页面，故不写。

🕊 4·19民主墓地——位于环山路2段上

  • 1960年4·19革命牺牲者的国立墓地（国家报勋部）。正门3~10月 06:00~18:00·11~2月 07:00~17:00，纪念馆·参拜 09:30~17:30（冬季16:30），纪念馆周一休馆（官方）。费用·英文导览官方未公布。
  • 从牛耳新设线4·19民主墓地站步行600m·5分钟（官方）。

🌲 北首尔梦之森·松林公园·华溪寺

  • 北首尔梦之森：全天开放，月溪路 173号，东门·西门可乘公交·地铁到达（官方）。费用·休息日·夜间灯光官方未公布。
  • 松林公园：三阳路 561号，约1,000棵松树·34,955㎡（江北区）。可与环山路1段连起来走。
  • 华溪寺：华溪寺路 117号，开设寺院体验住宿（官方——申请·费用见寺院页面）。从华溪站前往。

🛒 水逾传统市场·牛耳市场

  • 江北区官方市场名录中有水逾传统市场 (Suyu Jeontong Sijang / 수유전통시장)和牛耳市场 (Ui Sijang / 우이시장)（地址·电话为官方信息）。营业时间·休息日官方未公布——工作日白天最稳妥。

🚶 半天路线2条

  • A 环山路+墓地：北汉山牛耳站 → 环山路1段（1.5h）→ 2段（1h10）·4·19民主墓地（周一纪念馆休馆）→ 4·19民主墓地站 → 水逾站 (Suyu / 수유역) 美食。
  • B 寺院+公园：华溪站 → 华溪寺 → 松林公园 → 北汉山牛耳站 → 晚上去水逾。

⚠ 常见错误5条

1. 搜“牛耳站”——应搜北汉山牛耳站。

2. 不预约去牛耳岭路——需预约。外国人请电话预约。

3. 在环山路1段找4·19墓地——墓地在2段。

4. 周一去纪念馆——休馆（墓区在正门开放时间内可进入）。

5. 轻信美食店时间——本指南没有标注。请当天查地图应用。

⚙ FAQ 6条

1. 不爬山也可以吗？——环山路1·2段是散步级别（3.1km+2.3km）。

2. 墓地开到几点？——正门18:00（11~2月17:00），纪念馆17:30（冬季16:30）。

3. 牛耳岭路在哪里预约？——reservation.knps.or.kr，外国人请电话预约。

4. 公园要门票吗？——松林公园免费。北首尔梦之森的费用官方未公布（公园本身全天开放）。

5. 夜里能坐牛耳新设线吗？——工作日末班车24:37（以北汉山牛耳站为准）。

6. 美食推荐的依据是什么？——KeyChinGu地点库按评论数排序，并非口味评价。
