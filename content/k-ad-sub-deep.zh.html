外国游客常见的3个误区

1. "经纪公司大楼=自由出入"的误区

HYBE·SM·YG·JYP大楼的外部拍照点可以自由参观，但内部为付费展馆(HYBE INSIGHT)或不对外开放。HYBE INSIGHT务必提前通过Naver预约抢位——现场购票在周末通常已售罄。

2. "CF拍摄地=随时开放"的误区

北村韩屋村(Bukchon Hanok Maeul / 북촌한옥마을)是三星·现代汽车CF的常客取景地，上午10点前最接近CF画面中的氛围。周末白天游客密集，很难再现"CF里那种静谧小巷"的感觉。

3. "广告牌·OOH=随时都有"的误区

江南(Gangnam / 강남) K-POP SQUARE(SM外墙)和弘大(Hongdae / 홍대)附近的OOH广告主要集中投放在偶像回归季。粉丝自发投放的广告(生日·应援广告)更换频繁，出发前通过X(推特)"#江南广告" "#COEX广告"等话题标签提前确认投放排期比较现实。

12选4轴 — 场所·体验指南

轴1: K-广告博物馆·经纪公司体验空间(3选)

1. HYBE INSIGHT

  • 位置: 首尔龙山区汉江大路42(龙山站步行5分钟)
  • 门票: 成人₩29,000 / 线上预约可享₩2,000折扣
  • 运营时间: 周二~周日10:00~19:00(周一闭馆，最后入场18:00)
  • 亮点: 展示BTS·SEVENTEEN·NewJeans等HYBE旗下艺人的专辑美术设计·CF幕后花絮·MV制作过程。展出广告活动原始实物(服装·道具·海报原稿)。
  • 外国游客适配度: 全馆提供英语·日语·中文导览。可下载语音导览App。根据Google Maps评论语言分布估算，外国游客占比60%以上。
  • 预约: Naver预约或hybe.com。周末·公假日常在2周前售罄——建议优先选择工作日上午场次。

2. SM Town COEX Artium

  • 位置: 首尔江南区永东大路513 COEX Artium(三成站步行5分钟)
  • 门票: 1~3楼免费自由参观 / 周边商品店·拍照亭需付费
  • 运营时间: 11:00~22:00(全年无休)
  • 亮点: SM官方快闪店·展览·周边商品店。外墙的K-POP SQUARE大型LED屏是江南OOH广告的核心地标。常年陈列EXO·aespa·NCT·SHINee的CF幕后周边。
  • 外国游客适配度: 位于三成站COEX Mall动线上，交通便利无障碍。外国游客占比高。
  • 贴士: K-POP SQUARE的广告是SM官方广告与粉丝自发投放广告交替刊登。想追踪喜欢的偶像广告排期，可提前在X(推特)搜索"K-POP SQUARE 广告"关键词确认。

3. YG大楼外墙 + 弘大YG街区

  • 位置: YG大楼合井站步行10分钟 / YG街区弘大入口站步行5分钟
  • 门票: 免费(外部参观)
  • 亮点: YG街区聚集了BLACKPINK·BIGBANG粉丝周边商店·主题咖啡厅。虽非官方空间，却是最能直接体验粉丝经济生态的街区。
  • 贴士: YG大楼外墙拍照点可自由参观，禁止进入内部。BLACKPINK×Chanel联名广告实物仅在官方快闪活动期间展出。

轴2: CF拍摄地巡礼(3选)

4. 北村韩屋村 — 三星·现代汽车·K-beauty CF取景地

  • 位置: 首尔钟路区桂洞街·北村路一带(安国站步行5分钟)
  • 门票: 免费
  • 最佳到访时间: 上午9:00~10:00(游客高峰前)
  • CF关联: 三星Galaxy S系列·现代汽车IONIQ·雪花秀·悦诗风吟均曾以北村小巷为背景取景。"北村八景"台阶景观在国内外广告中反复出现。
  • 外国游客适配度: 设有英语·中文·日语指示牌。租借韩服后可拍摄CF同款场景照(每人₩15,000~₩30,000)。属于居民居住区——务必在上午10点前安静到访。

5. DDP(东大门设计广场) — K-广告·媒体艺术枢纽

  • 位置: 首尔中区乙支路281(东大门历史文化公园站步行1分钟)
  • 门票: 外部·广场免费 / 策划展₩5,000~₩15,000
  • 运营时间: 外部24小时开放 / 展馆10:00~20:00
  • CF关联: NewJeans×可口可乐、aespa×根特蒙斯特等K-pop品牌联名快闪展多次在此举办。媒体艺术外立面(外墙LED)在晚上8点后最为清晰绚丽。
  • 外国游客适配度: 英语导览完善。扎哈·哈迪德设计的外观是国际建筑地标。策划展档期请提前在ddp.or.kr确认。

6. 光化门广场 + 世宗大路OOH广告街

  • 位置: 首尔钟路区世宗大路172(光化门站步行1分钟)
  • 门票: 免费
  • CF关联: 新品发布·国家活动广告的大型横幅·公交候车亭广告集中区域。三星·LG·现代汽车的全球广告以英韩双语并列刊登。
  • 外国游客适配度: 首尔外国游客到访率第一的景点。世宗大王像·景福宫背景与大型OOH广告同框的拍照构图在社交媒体上反复出现。
  • 贴士: 国家纪念日(三一节·光复节)前后是大型广告活动更换期，OOH密度最高。

轴3: 全球K-广告标志性现场(3选)

7. 江南K-POP SQUARE(SM COEX外墙LED)

  • 位置: 首尔江南区三成洞(三成站6号出口正前方)
  • 门票: 免费 / LED点亮时间日出~22:00
  • 亮点: COEX Artium外墙大型LED屏。aespa·EXO·NCT的官方广告与粉丝自发投放广告(生日广告)交替刊登。
  • 贴士: 粉丝广告投放排期可通过X"#江南广告" "#COEX广告"话题标签追踪。英文推文也不少，外国游客同样可以跟踪。

8. 弘大前K-pop街 + 粉丝广告

  • 位置: 首尔麻浦区弘益路(弘大入口站步行2分钟)
  • 门票: 免费
  • 亮点: 粉丝广告(地铁屏蔽门·公交候车亭·电子屏)密集区域。BTS·SEVENTEEN·NewJeans粉丝广告定期刊登在弘大入口站屏蔽门。
  • 外国游客适配度: 外国游客到访率第一的商圈。粉丝周边商店·二手唱片行密集。
  • 贴士: 屏蔽门广告按日更换。在偶像回归当天到访，遇到官方回归广告的概率最高。回归日程通常在官方社交媒体提前2周公布。

9. 梨泰院·汉南豪华K-AD街(BTS×LV / BLACKPINK×Chanel)

  • 位置: 首尔龙山区梨泰院路·汉南大路一带(梨泰院站·汉南站步行5~10分钟)
  • 门票: 街区免费 / 快闪活动另计(免费~约₩10,000)
  • 亮点: BTS×LV、BLACKPINK×Chanel等全球奢侈品牌联名快闪展主要在汉南·梨泰院旗舰店附近举办。每逢代言人更替时期，外墙都会刊登大型广告。
  • 外国游客适配度: 梨泰院(Itaewon / 이태원)一带汉南洞(Hannam-dong / 한남동)是首尔外国居民·访客占比最高的区域之一。英语沟通无障碍。LV·Dior·Gucci旗舰店集中于此。
  • 贴士: 部分快闪活动需提前预约。建议关注品牌官方韩国社交媒体账号。即使没有快闪活动，旗舰店外观本身也值得作为拍照点到访。

轴4: 外国粉丝特化体验(3选)

10. K-pop粉丝广告巡礼(自助路线)

  • 方法: 无需另购门票。先在粉丝社群(X·粉丝论坛)收集广告投放排期，再逐一到访主要据点。
  • 主要据点: 江南K-POP SQUARE / 弘大入口站屏蔽门 / COEX Mall电子屏 / 新村U-PLEX外墙 / 蚕室乐天塔附近
  • 费用: 一日地铁通票₩5,000即可覆盖全部据点。
  • 外国游客适配度: 日本·东南亚·中东K-pop粉丝专程为"追星广告巡礼"访韩的案例在社交媒体上激增。X上"#广告巡礼 #首尔"韩英混用话题标签下的心得分享十分活跃。
  • 贴士: 粉丝广告在上午7~9点和下班高峰(18~20点)灯光最为清晰。

11. K-广告快闪咖啡厅·周边巡礼

  • 方法: HYBE·SM·JYP·YG不定期运营的官方快闪咖啡厅。通常在回归·专辑发行季于弘大·江南·圣水一带租用快闪空间。
  • 费用: 饮品₩6,000~₩12,000 / 限定周边₩3,000~₩30,000
  • 外国游客适配度: 快闪店内部陈列CF·MV幕后照片·道具，营造出"广告拍摄现场"的氛围。可购买官方照片卡·限定周边。
  • 信息获取: HYBE·SM·JYP·YG官方X账号 / Weverse App公告。通常在快闪开业前一周发布公告。开业首日·周末常需排队2~3小时——建议工作日开业刚开门时段(11:00~12:00)到访。

12. 韩国广告博物馆 + TVCF线上档案库

  • 韩国广告博物馆: 位于果川(Gwacheon / 과천)。展示韩国广告史，从1900年代至今。门票免费(以2026年6月为准，到访前建议再次确认)。从首尔市中心乘地铁约40分钟——建议与果川国立现代美术馆组合成半日行程。
  • TVCF.co.kr: 韩国广告数据库。可免费观看BTS·BLACKPINK广告原版视频。外国游客无需注册即可访问。在搜索栏输入偶像姓名即可自动检索相关CF。
  • 外国游客适配度: 广告影像本身语言门槛低。馆内英语导览有限，但因以观看影像为主，即使不懂英语也能顺利体验。

FAQ — 外国游客常见的5个问题

Q1. HYBE INSIGHT预约已满时有什么替代方案？

工作日刚开馆时常出现取消名额。建议开启Naver预约App通知。替代方案: SM COEX Artium(免费) + DDP策划展组合，可打造密度相近的一日行程。

Q2. 想亲眼看到BTS×LV联名广告该怎么办？

BTS回归季期间会刊登在汉南LV门店外墙、江南K-POP SQUARE、新门路大型外墙广告牌。并非常设展示，务必通过BTS官方X账号(@BTS_twt)或LV韩国官方Instagram确认投放排期。

Q3. 能一次性完成所有经纪公司大楼巡礼吗？

可按HYBE(龙山)→SM COEX(江南)→YG弘大附近(麻浦)→JYP清潭(江南)顺序，以地铁+步行方式安排半日~一日行程。仅HYBE INSIGHT正式提供付费内部参观，其余均只能在外部拍照。

Q4. 粉丝广告巡礼的排期在哪里查询？

在X(推特)搜索"#[偶像名]广告" "#首尔广告"最快捷。英文推文也很多，外国游客同样可以追踪。通常在广告刊登前1~2天发布公告。

Q5. 有哪些适合带儿童同行的地点？

HYBE INSIGHT·DDP·光化门广场·北村韩屋村·SM COEX Artium适合携带儿童同行。弘大·梨泰院的夜间广告巡礼因人流拥挤且需夜间出行，不建议带儿童前往。
