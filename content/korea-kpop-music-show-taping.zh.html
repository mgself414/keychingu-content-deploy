🎯 如何使用这份指南

凌晨四点，天还是漆黑的，你攥着护照和应援棒站在上岩MBC公开厅 (Sangam MBC Gongaeholl / 상암 MBC 공개홀) 前，等着自己的号码被叫到。NCT WISH的Show! 音乐中心 (Show! Music Core / 쇼! 음악중심) 提前录制，真的就是在这个时间开始确认人数的(NCT WISH官方公告，2026-10-15录制)。

这是写给旅行期间想坐进音乐节目观众席的外国粉丝的实战篇。观众席不是买票的演出。经纪公司通过粉丝俱乐部公告，只开放几分钟的先到先得申请，当天凌晨通过证件确认的人才能入场。这里引用的9条公告全部是已经结束的场次。日期和人数每次都会变，所以请用它们来学习如何读懂公告到底要求什么。粉丝活动的整体概览见下方🔗里的《韩国K-pop粉丝活动5大类》一篇。

📺 观众席是这样开放的——从公告到手环

在电视台官网上，我们没有找到外国人能使用的观众席申请入口。SBS人气歌谣 (Inkigayo / 인기가요) 页面虽然有“观众席申请说明”菜单，但截至10月21日正文是空的(SBS官方)。我们实际看到开放的申请，全部是经纪公司通过Weverse (Weverse / 위버스) 艺人公告开启的，流程几乎一样。

1. 公告：Weverse (Weverse / 위버스) 艺人公告里会出现“○○○ 提前录制参与说明”

2. 申请入口：录制前1到2天，在指定时刻只开放10到30分钟的先到先得表单。ILLIT的M Countdown (M Countdown / 엠카운트다운) 是8月19日15:00到15:10，NCT WISH的Show! 音乐中心 (Show! Music Core / 쇼! 음악중심) 是10月13日23:30到23:40(KST)。表单会提前5到15分钟打开，可以先填好个人信息(ILLIT·NCT WISH公告)

3. 号码公布：结果和入场号码在Weverse (Weverse / 위버스) 应用的“活动申请记录” (Event Application History / 이벤트 신청내역) 里查看(TWS·NCT WISH公告)

4. 人数确认：录制前两三个小时，按号码段分时间核对证件和所需物品。ENHYPEN音乐银行 (Music Bank / 뮤직뱅크) 提前录制，1到150号是04:00到04:59，151到300号是05:00到05:55，录制07:00开始(ENHYPEN公告)

5. 手环·印章：确认完毕后领取手腕印章和手环。手环丢失或损坏将限制入场(TXT·ILLIT公告)

正式直播的观众席比提前录制少得多。TXT渊竣的音乐银行 (Music Bank / 뮤직뱅크) 直播(2026-07-17，17:05)招5人和候补3人，CLOSE YOUR EYES的Show Champion (Show Champion / 쇼챔피언) 正式直播(2026-09-09)招20人(各官方公告)。HUI的Show Champion (Show Champion / 쇼챔피언) 公告写明正式直播不让粉丝入场(HUI公告)。

  • 人气歌谣 (Inkigayo / 인기가요，SBS)——TXT渊竣提前录制，2026年7月19日 周日10:45录制。申请在前一天10:30到11:00，先到先得选出120人和候补5人。人数确认08:50到09:50，在登村洞 (Deungchon-dong / 등촌동) SBS公开厅 (Gongaeholl / 공개홀) 前。确认顺序与座位无关(TXT公告)
  • 音乐银行 (Music Bank / 뮤직뱅크，KBS2)——CORTIS提前录制，2026年4月24日 周五08:30录制。300人和候补5人，人数确认从06:20开始，在KBS新馆 (Sin-gwan / 신관) 公开厅 (Gongaeholl / 공개홀) 前(永登浦区 (Yeongdeungpo-gu / 영등포구) 汝矣公园路 (Yeoui-gongwon-ro / 여의공원로) 13)。除了COER Membership，还必须在Weverse Global(韩国境内发货)买3张以上EP或1套专辑(CORTIS公告)。ENHYPEN的8月21日提前录制是在发行前录制，所以只有在前一天19:00之前提交保密承诺书 (NDA) 的人才能接受身份确认(ENHYPEN公告)
  • M Countdown (M Countdown / 엠카운트다운，Mnet)——ILLIT提前录制，2026年8月20日 周四13:20录制。210人，人数确认从11:10开始，在CJ ENM中心 (CJ ENM Center / CJ ENM 센터) 前(麻浦区 (Mapo-gu / 마포구) 上岩山路 (Sangam-san-ro / 상암산로) 66)。需要GLLIT MEMBERSHIP、3张以上Weverse Global专辑或1套、Melon (Melon / 멜론) 下载记录打印件、官方应援棒(ILLIT公告)
  • Show! 音乐中心 (Show! Music Core / 쇼! 음악중심，MBC)——NCT WISH提前录制，2026年10月15日 周四07:00录制，10月17日 周六播出。400人，人数确认1到200号04:00，201到400号05:00。所需物品有7项，其中一项是Melon (Melon / 멜론) “I SPY”100次以上的播放记录。不满100次就不能入场(NCT WISH公告)
  • Show Champion (Show Champion / 쇼챔피언，MBC M)——HUI提前录制，2026年8月5日 周三，一山 (Ilsan / 일산) MBC梦想中心 (MBC Dream Center / MBC 드림센터)。200人，人数确认06:30和07:30，录制08:10左右开始(HUI公告)。梦想中心不在首尔，而在京畿道高阳市 (Goyang-si / 고양시)(CLOSE YOUR EYES公告)
  • The Show (The Show / 더쇼)——有报道称SBS Life频道于2026年7月14日直播了第395期[二手资料]。我们在Weverse (Weverse / 위버스) 上没有找到2026年The Show (The Show / 더쇼) 的观众席公告

🪪 外国人证件与姓名——最容易被刷掉的地方

  • 认可的证件：外国人可用护照、外国人登录证 (Oegugin Deungnokjeung / 외국인등록증)、国内居所申报证 (Gungnae Geoso Singoljeung / 국내거소신고증)、永住证 (Yeongjujeung / 영주증)(ILLIT·TWS·ENHYPEN公告)。只收实物。照片·复印件·打印件·手机截图都不行，学生证也不行(CORTIS·ILLIT公告)。过期证件同样不行(HUI公告)
  • 英文姓名：申请时如果用英文填写姓名，就只用护照核对(CORTIS公告)。申请姓名与证件姓名不同，可能被拒绝入场。TWS公告举了护照上是“TWS”而申请表上是图奥斯 (Tuoseu / 투어스) 这类写法不同的例子(TWS公告)
  • 年龄：以申请日为准，韩国·美国满15周岁以上，其他国家·地区满16周岁以上。未达标准者即使有监护人陪同也不能入场(TXT·ENHYPEN公告)

🚫 现场规则与缺席处罚

  • 禁止拍摄：摄影棚内禁止拍照·录像·录音。录制设备不能带入，违反者当场被请出，并在现场删除记录(TXT·ENHYPEN公告)。也有公告连望远镜都禁止(HUI公告)
  • 应援道具：只允许官方应援棒。标语·横幅·玩偶·扇子·手机LED应用一律禁止(ILLIT·TWS公告)。NCT WISH甚至确认了应援棒的LED能不能亮(NCT WISH公告)
  • 礼物：只能通过工作人员转交信件(CORTIS·ENHYPEN公告)
  • 到场时间：必须在规定时间前5分钟到场，正好准点到算迟到(HUI公告)。迟到者另排一队，最后进场(TXT公告)
  • 缺席处罚：中签后不来或中途离场，在该专辑活动期间不得参加公开录制(TXT·ENHYPEN公告)。NCT WISH规定缺席者限制申请到下个月底，转让·拍摄违规限制6个月，并在活动后公开了缺席21件·转让3件的号码(NCT WISH公告)
  • 取消·转让：不能因个人原因取消或转让(CLOSE YOUR EYES公告)。公布之后，用于申请的专辑也不能退款(ILLIT公告)

🧰 观众席实务——独自前往、准备、支付、交通

  • 独自前往：申请以1人为单位，只有本人能入场。禁止代申请和转让号码(TWS·CORTIS公告)。独自去也不吃亏
  • 准备(来韩国之前)：提前办好艺人粉丝俱乐部会员、Weverse (Weverse / 위버스) 账号和Melon (Melon / 멜론) 账号。大部分公告都要求会员资格·购买专辑·Melon (Melon / 멜론) 记录，而且申请入口在录制前1到2天只开放10到30分钟(ILLIT·NCT WISH·TXT公告)。请打开Weverse (Weverse / 위버스) 推送通知
  • 支付：用于申请的专辑，只认公告指定的销售渠道(Weverse Global韩国境内发货等)购买的(CORTIS·ILLIT·ENHYPEN公告)。韩国境内的支付方式见外国人韩国支付系统深度解析
  • 交通·住宿：很多场次的人数确认在04:00到06:30开始(ENHYPEN·NCT WISH·HUI·CORTIS公告)。住在公开厅附近更好。一山 (Ilsan / 일산) 梦想中心在首尔之外。交通卡见韩国交通卡3选1，零慌张手册——T-money·WOWPASS·气候同行卡 (Gihu Donghaeng / 기후동행) 买哪个

⚠ 常犯的4个错误

1. “到现场排队就能进”——有公告写明，没有提前申请就不能到现场进入正式直播(CLOSE YOUR EYES公告)

2. “手机里存的护照照片就行”——只认实物证件(CORTIS·ILLIT公告)

3. “用韩文姓名申请，也能用护照核对”——申请姓名与护照姓名不同，可能被拒绝入场。要原样填写护照上的英文姓名(CORTIS·TWS公告)

4. “用手机截图出示Melon (Melon / 멜론) 记录”——下载记录要求的是纸质打印件(CORTIS·ILLIT公告)
