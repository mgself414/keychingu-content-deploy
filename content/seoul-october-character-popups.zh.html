🎯 为什么是"10月角色快闪日历"

首尔的角色周边商店本身已有常设指南(#1350 首尔角色周边商店巡礼)。但快闪店的性质不同——只开2~4周就消失。 2026年10月尤其密集地撞上了日本·中华圈粉丝基础深厚的多个IP:宝可梦30周年游乐节、Tooniverse世代记忆里的我们这一家、全职猎人联名咖啡馆,以及先在海外走红、这次终于首次登陆韩国的蜡笔小新体验型展览。对外国旅行者来说,问题不是"哪里是角色圣地",而是"我在首尔的那一周,正开着什么快闪店"。

这一篇只回答这个问题——只把日期·地点·营业时间·预约方式钉进表格。先收集首尔Instagram本地账号在9月下旬集中发布的快闪店公告,再用官方渠道·媒体报道交叉核实。

⚠ 有效期: 本文为2026年10月限定日历。日程以2026-09-29确认为准(蜡笔小新体验展·我们这一家·全职猎人·Usahana于2026-10-18再次确认),快闪店常有提前结束·延期的情况。标注"据Instagram公告"的项目,是运营方官方渠道或媒体未能确认、仅依据Instagram公告得出的信息——出发前请查看该账号的最新公告。"未确认"表示没有官方信息,需要现场确认。

🅰 10月11日前结束的——宝可梦·TWIMI·哈利·波特·三丽鸥文具·Tiny Ville

2026-10-12 更新: TWIMI·宝可梦·Mahou Dokoro·三丽鸥文具·Tiny Ville 均已结束。

  • 宝可梦"皮卡丘的秋日出游"(~10/11): 宝可梦韩国·韩国观光公社·机场铁路联合举办的30周年游乐节。举办地HiKR Ground观光中心(HiKR Ground / 하이커그라운드)是韩国观光公社运营的外国游客综合空间,就在清溪川(Cheonggyecheon / 청계천)前面,在这份名单里最贴合外国人的动线。低楼层是新媒体艺术·体验展览(周二~周日,周一休馆),5楼是快闪店(每天10~20点),卖穿韩服的皮卡丘商品和扭蛋。入场免费。期间在Pokémon GO里能抓到橙色韩服皮卡丘,机场铁路(AREX)直达列车采用宝可梦主题涂装,仁川机场第1·2航站楼 (Incheon Airport Terminal 1·2 / 인천공항 제1·2여객터미널) 和首尔站城市航站楼 (Seoul Station City Airport Terminal / 서울역 도심공항) 设有韩服皮卡丘拍照区,另有从机场铁路主要站点连到HiKR Ground的集章活动(据GameTalk报道)。展览·快闪店的主活动只在HiKR Ground举行,所以入境当天按机场拍照区 → HiKR Ground的顺序安排就行。
  • TWIMI快闪店(~10/4): TWS官方角色的森林寻宝主题快闪店,地点在圣水(Seongsu-dong / 성수)的P&R圣水(P&R Seongsu / P&R성수)。预约渠道是Weverse(위버스)——海外K-pop粉丝已经在用的全球App,比Naver预约对外国人更友好(是否需要韩国手机号未确认)。只有10月第一周人在首尔的粉丝才赶得上。
  • Mahou Dokoro哈利·波特快闪店(~10/11): 龙山 I'Park Mall(Yongsan I'Park Mall / 용산 아이파크몰)Living Park 3楼多巴胺站(Dopamine Station / 도파민 스테이션)。同层还有吉伊卡哇官方店(Chiikawa Shop / 치이카와샵),一次能逛两处(见下文🅳)。
  • 三丽鸥角色文具快闪店(~10/11,据Instagram公告): 弘大(Hongdae / 홍대)AK广场2楼,以日记本·贴纸为主的文具快闪店。公告称入场时需核验实体身份证件——外国人请带好护照(护照是否被认可未确认,同一栋楼4楼9月的快闪店也要求证件)。
  • Tiny Ville(~10/11,据Instagram公告): 新世界江南店(Shinsegae Gangnam / 신세계 강남점)地下1楼甜品厅甜蜜公园里的角色杂货快闪店(海绵宝宝爪机等,含隐藏扭蛋机)。毗邻高速巴士客运站(Express Bus Terminal / 고속터미널),适合安排进江南购物动线,但运营方官方渠道未确认——出发前请查看Instagram公告。

🅱 到10月第三~四周为止——我们这一家·全职猎人·Usahana

2026-10-28 更新: 我们这一家·全职猎人已于10/18结束,Usahana已于10/27结束。目前剩下的是圣水蜡笔小新体验展(~2027/1/24)和2处常设店。

  • 我们这一家(~10/18,已结束): 弘大KT&G想象庭院设计广场2楼。把动画里我们这一家的客厅整个搬了过来,以日记本·眼镜架·钥匙圈等生活周边为主。日本原作(あたしンち)出身,对日本游客也是亲切的IP。未延期,已于10/18结束。
  • 全职猎人快闪店&联名咖啡馆(~10/18,已结束): 建大入口(Konkuk Univ. Ipgu / 건대입구)乐天电影院3楼V广场。在印着角色的桌子上吃以念能力命名的联名餐点的咖啡馆+周边区。未延期,已于10/18结束,10/23起开启线上销售(vsquare.co.kr,据V-SQUARE官方X 10/18)。今年春天在合井·釜山举办的Anyplus联名是另一场活动,别和旧信息混在一起。
  • Usahana首个独立快闪店(~10/27,已结束): 三丽鸥角色Usahana在韩国的首个独立快闪店,曾在龙山 I'Park Mall Living Park(楼层未确认)举办。营业时间为周一~周四10:30~20:30、周五~周日10:30~21:00(popga,二手信息)。3个本地账号公告了相同的日程,但未能得到三丽鸥官方渠道确认。

🅲 10月17日开幕——蜡笔小新体验展一直开到冬天

  • 蜡笔小新:一起玩吧!时空大冒险(10/17~2027/1/24): 先在海外巡展走红的蜡笔小新互动体验展于10/17在韩国首次正式开幕。地址是圣水Yeonmujang 5-gil 9-13(圣水站4号出口步行约5分钟)。不是用眼睛看的展览,而是迷你游戏·体验型的构成,参观时间2小时·不可再入场。营业时间11:00~20:00(平日·周末相同,最晚入场19:00),没有公布休馆日。票价成人(满13岁以上)23,000韩元·儿童(满12岁以下)20,000韩元,未满24个月现场购票免费。预约为制作方自营平台bemill独家销售——对外国人来说重要的一点是:可以用Google·邮箱注册,但海外银行卡能否支付未确认。展览开到冬天,只有10月17日之前的旅行者会错过。

🅳 常设——龙山 I'Park Mall一栋楼,以及国际电子中心

  • 龙山 I'Park Mall Living Park: 本次10月日历里效率最高的一栋楼。3楼多巴胺站有官方吉伊卡哇官方店龙山店(2026年2月开业,常设)(哈利·波特Mahou Dokoro快闪店已于10/11结束),还有Usahana快闪店(10/27已结束),6楼有常设Marvel Store。龙山站直通,KTX·机场铁路换乘前后1~2小时就能逛完。多巴胺站营业到22点。
  • 国际电子中心(瑞草区,南部客运站): 吉伊卡哇剧场版上映后,本地粉丝甚至做出"讨伐地图",2~9楼各处散落着吉伊卡哇玩偶·小物·扭蛋店的公仔·扭蛋商街。不是官方直营店而是多家店铺的集合,能找到官方店里没有的库存。10~20点,每月第1·3个周日休息(据Instagram公告)——想在周日去请先确认日期。

🗓 两天路线——龙山一栋楼 + 圣水蜡笔小新体验展

第1天·龙山→南部客运站: 上午龙山 I'Park Mall(3楼吉伊卡哇官方店 → 6楼Marvel) → 下午去南部客运站的国际电子中心(3号线)找官方店里没有的吉伊卡哇库存。HiKR Ground宝可梦·哈利·波特快闪店已于10/11结束。

第2天·圣水: 圣水蜡笔小新体验展(10/17~,11点开门,参观2小时·最晚入场19:00)——从圣水站4号出口步行约5分钟。弘大我们这一家·建大全职猎人(~10/18)、AK广场三丽鸥文具(~10/11)·圣水TWIMI(~10/4)均已结束——Usahana也已于10/27结束,第1天就只剩吉伊卡哇官方店·国际电子中心。

周日切换: 国际电子中心每月第1·3个周日休息——如果行程碰上那个周日,就把第1天和第2天对调。

⚠ 常见错误3条

1. 相信9月的帖子就出发 — 蚕室Level Two潮玩快闪店(~9/30)·弘大犬夜叉快闪店(~9/22)都已经结束。比起收藏的帖子,快闪店结束日期才是第一位的。这份表格也要按结束日期来看。

2. 想当然认为Naver预约一定能约到 — 没有韩国手机号,Naver预约可能会卡住。优先安排预约渠道是bemill(蜡笔小新——可用Google·邮箱注册,海外银行卡支付未确认)的地方,以及自由入场的地方(吉伊卡哇官方店·国际电子中心),能降低风险。

3. 不带身份证件出门 — AK广场弘大快闪店公告要核验实体身份证件。请带实体护照,而不是手机里的护照照片。

⚙ FAQ 3个

1. 只能选一个的话? — 10/11之前选HiKR Ground宝可梦:面向外国游客的空间,入场免费,还能顺便抓到Pokémon GO限定的韩服皮卡丘。10/11之后选龙山 I'Park Mall(吉伊卡哇官方店+Marvel,一栋楼搞定)。

2. 没有韩国手机号也能预约的地方? — 蜡笔小新体验展的bemill可以用Google·邮箱注册(海外银行卡支付未确认)。常设的吉伊卡哇官方店·国际电子中心无需预约,自由入场。通过Weverse预约的TWIMI已于10/4结束,全职猎人咖啡馆已于10/18结束。

3. 几点去人少? — 快闪店在周末开门时间排队最长。I'Park Mall多巴胺站(开到22点)在工作日晚上比较宽松。蜡笔小新体验展最晚入场时间是19:00。
