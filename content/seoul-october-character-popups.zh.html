🎯 为什么是"10月角色快闪日历"

首尔的角色周边商店本身已有常设指南(#1350 首尔角色周边商店巡礼)。但快闪店的性质不同——只开2~4周就消失。 2026年10月尤其密集地撞上了日本·中华圈粉丝基础深厚的多个IP:宝可梦30周年游乐节、Tooniverse世代记忆里的我们这一家、全职猎人联名咖啡馆,以及先在海外走红、这次终于首次登陆韩国的蜡笔小新体验型展览。对外国旅行者来说,问题不是"哪里是角色圣地",而是"我在首尔的那一周,正开着什么快闪店"。

这一篇只回答这个问题——只把日期·地点·营业时间·预约方式钉进表格。先收集首尔Instagram本地账号在9月下旬集中发布的快闪店公告,再用官方渠道·媒体报道交叉核实。

⚠ 有效期: 本文为2026年10月限定日历。日程以2026-09-29确认为准,快闪店常有提前结束·延期的情况。标注"据Instagram公告"的项目,是运营方官方渠道或媒体未能确认、仅依据Instagram公告得出的信息——出发前请查看该账号的最新公告。"未确认"表示没有官方信息,需要现场确认。

🅰 10月11日前结束的——宝可梦·TWIMI·哈利·波特·三丽鸥文具·Tiny Vill

  • 宝可梦"皮卡丘的秋日出游"(~10/11): 宝可梦韩国·韩国观光公社·机场铁路联合举办的30周年游乐节。举办地HiKR Ground观光中心(HiKR Ground / 하이커그라운드)是韩国观光公社运营的外国游客综合空间,就在清溪川(Cheonggyecheon / 청계천)前面,在这份名单里最贴合外国人的动线。1~3楼是新媒体艺术·体验展览,5楼是快闪店,卖穿韩服的皮卡丘商品和扭蛋。期间在Pokémon GO里能抓到橙色韩服皮卡丘,Pokémon HOME到访纪念徽章则靠现场NFC扫描(每天限1次)。机场铁路(AREX)上跑着宝可梦涂装列车——没有证据显示机场航站楼内另设展场,主会场按HiKR Ground一处来安排就行。
  • TWIMI快闪店(~10/4): TWS官方角色的森林寻宝主题快闪店,地点在圣水(Seongsu-dong / 성수)的P&R圣水(P&R Seongsu / P&R성수)。预约渠道是Weverse(위버스)——海外K-pop粉丝已经在用的全球App,比Naver预约对外国人更友好(是否需要韩国手机号未确认)。只有10月第一周人在首尔的粉丝才赶得上。
  • Mahodokoro哈利·波特快闪店(~10/11): 龙山 I'Park Mall(Yongsan I'Park Mall / 용산 아이파크몰)Living Park 3楼多巴胺站(Dopamine Station / 도파민 스테이션)。同层还有吉伊卡哇官方店(Chiikawa Shop / 치이카와샵),一次能逛两处(见下文🅳)。
  • 三丽鸥角色文具快闪店(~10/11,据Instagram公告): 弘大(Hongdae / 홍대)AK广场2楼,以日记本·贴纸为主的文具快闪店。公告称入场时需核验实体身份证件——外国人请带好护照(护照是否被认可未确认,同一栋楼4楼9月的快闪店也要求证件)。
  • Tiny Vill(~10/11,据Instagram公告): 新世界江南店(Shinsegae Gangnam / 신세계 강남점)地下1楼甜品厅甜蜜公园里的角色杂货快闪店(海绵宝宝爪机等,含隐藏扭蛋机)。毗邻高速巴士客运站(Express Bus Terminal / 고속터미널),适合安排进江南购物动线,但运营方官方渠道未确认——出发前请查看Instagram公告。

🅱 到10月第三~四周为止——我们这一家·全职猎人·Usahana

  • 我们这一家(~10/18): 弘大KT&G想象庭院设计广场2楼。把动画里我们这一家的客厅整个搬了过来,以日记本·眼镜架·钥匙圈等生活周边为主。日本原作(あたしンち)出身,对日本游客也是亲切的IP。仅周末(周六·周日)16~18点限量出售一次2,300韩元、每天200个名额的扭蛋(据Instagram公告)——以扭蛋为目标请挑周末下午去。营业到21点,收得比较晚。
  • 全职猎人快闪店&联名咖啡馆(~10/18): 建大入口(Konkuk Univ. Ipgu / 건대입구)乐天电影院3楼V广场。在印着角色的桌子上吃以念能力命名的联名餐点的咖啡馆+周边区。开业初期是Naver预约者优先,后续改为现场排队,10月第二周以后现场入场的可能性较高(转换时点未确认)。今年春天在合井·釜山举办的Anyplus联名是另一场活动,别和旧信息混在一起。
  • Usahana首个独立快闪店(~10/27,据Instagram公告): 三丽鸥角色Usahana在韩国的首个独立快闪店,龙山 I'Park Mall Living Park 6楼(角色快闪店轮换的楼层)。3个本地账号公告了相同的日程·时间,但未能得到三丽鸥官方渠道确认。Naver预约制——如果约不到,可以试试工作日上午现场排队。

🅲 10月17日开幕——蜡笔小新体验展一直开到冬天

  • 蜡笔小新:一起玩吧!时空大冒险(10/17~2027/1/24): 先在海外巡展走红的蜡笔小新互动体验展首次登陆韩国,地点在圣水Yeonmujang 5-gil。不是用眼睛看的展览,而是迷你游戏·体验型的构成。预约以制作方自营平台bemill为主,分1次早鸟(9/28~10/2,8折)·2次早鸟(10/3~10/6,9折)——普通票价公告为23,000韩元(据IG)。对外国人来说重要的一点是:KKday上也上架了门票商品,可以用海外银行卡预约(价格·语言未确认)。展览开到冬天,只有10月17日之前的旅行者会错过。门牌号在不同帖子里不一样(9-13 / 9-29),出发前请确认预约页面上的地址。

🅳 常设——龙山 I'Park Mall一栋楼,以及国际电子中心

  • 龙山 I'Park Mall Living Park: 本次10月日历里效率最高的一栋楼。3楼多巴胺站有官方吉伊卡哇官方店龙山店(2026年2月开业,常设)和哈利·波特Mahodokoro快闪店(~10/11),6楼有Usahana快闪店(~10/27)和常设Marvel Store。龙山站直通,KTX·机场铁路换乘前后1~2小时就能逛完。多巴胺站营业到22点。
  • 国际电子中心(瑞草区,南部客运站): 吉伊卡哇剧场版上映后,本地粉丝甚至做出"讨伐地图",2~9楼各处散落着吉伊卡哇玩偶·小物·扭蛋店的公仔·扭蛋商街。不是官方直营店而是多家店铺的集合,能找到官方店里没有的库存。10~20点,每月第1·3个周日休息(据Instagram公告)——想在周日去请先确认日期。

🗓 两天路线——龙山一栋楼 + 2号线一条线

第1天·龙山→清溪川: 上午龙山 I'Park Mall(3楼吉伊卡哇官方店·哈利·波特 → 6楼Usahana·Marvel) → 1号线到钟阁(Jonggak / 종각) → 下午HiKR Ground宝可梦(~10/11) → 清溪川散步。10/11之后就把HiKR Ground换成南部客运站的国际电子中心(3号线)。

第2天·2号线弘大→建大→圣水: 上午弘大想象庭院我们这一家(11点开门) + AK广场三丽鸥文具(~10/11) → 2号线直达建大入口全职猎人联名咖啡馆吃午饭 → 再坐两站到圣水TWIMI(~10/4)或蜡笔小新体验展(10/17~)。三处都在2号线上,不用换乘。

周末扭蛋切换: 我们这一家的扭蛋只在周六·周日16~18点出售——如果是周末,就把第2天的顺序倒过来,先逛圣水·建大,16点再进弘大。

⚠ 常见错误3条

1. 相信9月的帖子就出发 — 蚕室Level Two潮玩快闪店(~9/30)·弘大犬夜叉快闪店(~9/22)都已经结束。比起收藏的帖子,快闪店结束日期才是第一位的。这份表格也要按结束日期来看。

2. 想当然认为Naver预约一定能约到 — Usahana·三丽鸥文具以Naver预约为主,没有韩国手机号可能会卡住。优先安排预约渠道是Weverse(TWIMI)·KKday(蜡笔小新)的地方,以及自由入场的地方(吉伊卡哇官方店·国际电子中心·HiKR Ground5楼快闪店),能降低风险。

3. 不带身份证件出门 — AK广场弘大快闪店公告要核验实体身份证件。请带实体护照,而不是手机里的护照照片。

⚙ FAQ 3个

1. 只能选一个的话? — 10/11之前选HiKR Ground宝可梦:面向外国游客的空间,没有提到门票费用,还能顺便抓到Pokémon GO限定的韩服皮卡丘。10/11之后选龙山 I'Park Mall(吉伊卡哇官方店+Usahana+Marvel,一栋楼搞定)。

2. 没有韩国手机号也能预约的地方? — TWIMI在Weverse,蜡笔小新体验展在KKday上架商品。全职猎人咖啡馆过了初期预约期就能现场排队。其余Naver预约的快闪店,现实的替代方案是工作日上午现场排队。

3. 几点去人少? — 快闪店在周末开门时间排队最长。I'Park Mall多巴胺站(开到22点)·我们这一家(开到21点)在工作日晚上比较宽松。
