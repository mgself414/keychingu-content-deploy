⚠ 外国人がよくする間違い5つ

1. 「ホテルプール = 宿泊客のみ」: 一部のホテルではデイパス (Day Pass) で外部利用OK (バンヤンツリー (Banyan Tree) 50,000ウォン (~5,500円)・新羅 (Shilla) 80,000ウォン (~8,800円)・コンラッド (Conrad) 70,000ウォン (~7,700円)～が標準)。事前予約が必須です。

2. 「インフィニティプール = シグニエル (SIGNIEL) のみ」: 韓国 (Korea) のインフィニティプール1位 = バンヤンツリー (Banyan Tree) (南山 (Namsan)) + シグニエル (SIGNIEL) (555m) + JWマリオット東大門 (JW Marriott Dongdaemun) + ホテルナル (Hotel Naru) (漢江 (Hangang)) の4つがマニアに人気です。

3. 「夏のみ営業」: 屋外プールは7月～9月・室内プールは年中 (新羅 (Shilla)・バンヤンツリー (Banyan Tree)・シグニエル (SIGNIEL)・コンラッド (Conrad)・JW (JW Marriott))。ホカンス (ホテルでの休暇) は年中OKです。

4. 「ホテルプール = 高いだけ」: コスパ重視のマニアには = L7弘大 (L7 Hongdae) (150,000～250,000ウォン/泊 (~16,500～27,500円/泊))・ノボテル東大門 (Novotel Dongdaemun) (120,000～200,000ウォン/泊 (~13,200～22,000円/泊))・モンドリアン (Mondrian) (200,000～300,000ウォン (~22,000～33,000円)) + プール込み + 外国人マニアに人気です。

5. 「外国人フレンドリー = ラグジュアリーのみ」: L7 (L7 Hongdae)・ノボテル (Novotel Dongdaemun)・モンドリアン (Mondrian)・ホテルナル (Hotel Naru) = 外国人フレンドリー + 英語・中国語・日本語フルセット + MZ世代 (MZ Sedae) インスタに人気です。
