🎯 왜 DMZ 가이드인가

DMZ (Demilitarized Zone·비무장지대) = 외국인 매니아 매트릭스 #1·판문점·임진각·도라산·평화공원. 외국인 페인포인트 = (a) "DMZ = 위험" 잘못된 인식·안전 + 영문 가이드 풀세트 (b) 분단 + 한국 매트릭스 #1 (c) 판문점 = 정전협정 1953 사인 장소 (d) 임진각 = 평화공원 cluster (e) 사전 예약 필수·여권 필수 (f) 영문 + 일문 + 중문 가이드 풀세트.

본 가이드는 5축 12 시그니처 + DMZ 1일 투어 + 사전 예약·여권.

★ 한눈에 5축 12 시그니처

🏛 5축 deep dive

① 판문점 (JSA·정전협정 1953)

  • 시그니처: 1953년 7월 27일 정전협정 사인 장소·외국인 매니아 매트릭스 #1
  • 외국인 페인포인트: 사전 예약 1-2주 전·여권 필수·의복 단정·만 11세 미만 X
  • 외국인 친화도: ★★★★★ (영문·다국어 풀세트)

② 임진각 (평화공원)

  • 시그니처: 평화공원·자유의 다리 (1953 정전협정)·평화 곤돌라
  • 외국인 친화도: ★★★★★ (영문·가족 + MZ 매니아)
  • 시간: 09:00~18:00·무료·곤돌라 = 9,000~16,000원

③ 도라산 전망대 + 제3땅굴

  • 시그니처: 북한 전망·1978년 발견 제3땅굴·외국인 매니아 매트릭스
  • 외국인 친화도: ★★★★ (영문·매니아)

④ DMZ 평화공원 (파주)

  • 시그니처: 가족 + 산책 + 외국인 매니아 매트릭스
  • 외국인 친화도: ★★★★ (영문·가족)

⑤ DMZ 1일 투어 (KTO 인증·외국인 매니아 #1)

  • 시그니처: 외국인 매니아 매트릭스 #1·KTO (한국관광공사) 인증 투어·영문·일문·중문 풀세트
  • 가격: 70,000~150,000원/인 (1일·셔틀버스 + 영문 가이드 + 점심 포함)
  • 사전 예약: 1-2주 전 권장·여권 필수

⚠ 외국인 자주 실수 5가지

1. "DMZ = 위험": 안전 + 영문 가이드 풀세트·외국인 매니아 매트릭스 #1.

2. "DMZ = 사전 예약 X": 1-2주 전 예약 필수·여권 필수·만 11세 미만 X.

3. "판문점 = 일반 장소": 1953년 정전협정 사인 장소·외국인 매니아 매트릭스 #1.

4. "임진각 = 단순 공원": 평화공원·자유의 다리·평화 곤돌라 가족 매니아.

5. "제3땅굴 = 단순 굴": 1978년 발견·매니아 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: DMZ 1일 투어 (KTO 인증) = 영문·풀세트 매트릭스.

2. 사전 예약: 1-2주 전·여권 필수·만 11세 미만 X.

3. 의복: 단정 (민소매·반바지·운동복 X)·판문점 매너.

5. 시즌: 봄·가을 베스트·여름 폭염·겨울 = 매니아 매트릭스.

6. 추천 페르소나: 가족·시니어 = 임진각 + 평화공원 / MZ·매니아 = 판문점 + 도라산 / 매니아·역사 = 풀세트.
