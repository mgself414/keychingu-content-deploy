外国粉丝的偶像生日咖啡厅指南：怎么找生咖、参与礼仪、读懂地铁生日广告（2026年10月确认）

副标题：生日咖啡厅是粉丝租下咖啡厅举办的非官方活动 [二手资料 Korea Herald] · 限量赠品先到先得 [二手资料 Korea Herald] · 首尔地铁1~8号线的广告需向广告代理公司申请，再经韩国广告自律审议机构 (Korea Advertising Review Board / 한국광고자율심의기구) 审议(首尔交通公社 (Seoul Metro / 서울교통공사) 官方) · 2025年首尔地铁偶像广告共12,433件 [二手资料 Dailian新闻 (Dailian / 데일리안)] — 截至2026-10-21

🎯 本指南的用法

拿到饮料，杯身套着一圈印有偶像脸的纸杯套 (Keopholdeo / 컵홀더)，收银台旁的篮子里堆满明信片和贴纸。生日咖啡厅，简称"生咖" (Saengka / 생카)，就是这样的地方。它是在偶像的生日或出道纪念日，由粉丝租下或预约普通咖啡厅举办的活动，不是经纪公司办的官方活动 [二手资料 Korea Herald 2024-11-18]。

本文写给来韩国想去逛逛生咖 (Saengka / 생카) 的外国粉丝。每场活动的主办人、地点、日期都不同，也没有官方公告，所以不推荐任何具体的咖啡厅。我们依据官方页面和媒体报道，整理了找生咖 (Saengka / 생카) 的方法、去了要遵守的礼仪、现场要注意的事，以及生咖周在车站看到的地铁生日广告是怎么挂上去的。来自媒体、粉丝一方的信息都标注了[二手资料]。

🎂 什么是生咖 (Saengka / 생카)：粉丝办的活动

  • 谁来办：粉丝租下或预约咖啡厅来办。据说即使不会做周边，也可以向网上商家订做后来办 [二手资料 Korea Herald 2024-11-18]。很多是由站姐 (Homma / 홈마，拍摄偶像照片并发布的粉丝摄影师) 举办的，也有报道说她们靠卖照片周边来补贴场地租金 [二手资料 JoongAng Daily 2021-02-02]
  • 咖啡厅一方的条件：有的咖啡厅免费接受预约，有的不是。一位咖啡厅老板说，他们不收场地费，只靠客人买的饮料和甜点的营业额来运营 [二手资料 Korea Herald]
  • 有什么：主办粉丝会制作杯套 (Keopholdeo / 컵홀더)、钥匙扣、明信片、贴纸等周边，在现场出售。限量版赠品按先到先得发放 [二手资料 Korea Herald]。卖什么、送什么、要买几杯饮料才能领，每场活动都不同，以主办方的公告为准
  • 办多少场：有报道称，2023年BTS的V (Bwi / 뷔) 生日时开了约50家生日咖啡厅，其中30家在首尔 [二手资料 Korea Herald]。2月和9月是偶像生日扎堆的月份，据说很难订到场地 [二手资料 Korea Herald]
  • 偶像会来吗：请抱着不会来的想法去。这是没有寿星、粉丝们互相庆祝的场合 [二手资料 JoongAng Daily]

🔍 找的方法：读主办账号的公告

没有官方日程表。信息全都来自主办粉丝的账号。

  • 搜索：在X、Instagram上，用艺人的韩文名或英文名，加上"生咖 (Saengka / 생카)"、"生日咖啡厅 (Saengil Kape / 생일카페)"、"birthday cafe"、"cup sleeve event"搜索。生日临近时，粉丝们会汇总谁在哪家咖啡厅办什么活动，一天跑好几家 [二手资料 JoongAng Daily]
  • 公告里要看什么：期间和营业时间、咖啡厅名称和地址、点饮料的条件、赠品种类和数量以及售罄公告、是否贩售周边及付款方式、排队方式。咖啡厅自己的营业时间和主办活动的时间可能不同，两个都要看
  • 整理地图：把公告里的咖啡厅名称按韩文原样复制，存进地图App，就不容易迷路
  • 生咖 (Saengka / 생카) 汇总服务：也有粉丝做的生咖汇总账号和地图服务，但本文没能打开确认。最终信息请务必回到主办账号再看一遍

🙇 参与礼仪：那里是营业中的咖啡厅

  • 先点饮料：咖啡厅有时靠客人买的饮料和甜点来承担活动费用 [二手资料 Korea Herald]。不要只拍照就走，请点单
  • 排队与顺序：按主办方说明的方式排队。不要堵住咖啡厅门口或隔壁店的入口
  • 赠品：先到先得，可能很早就发完 [二手资料 Korea Herald]。发完了不要找咖啡厅店员理论，店员不是主办人
  • 座位：其他粉丝也要进来。要待很久的话，请追加点单或让出座位
  • 拍照：打卡区和装饰多数可以拍，但要避免拍到其他客人的脸。公告里有拍摄规则的话，照做即可

🚇 地铁生日广告：是怎么挂上去的

生咖周期间，车站里的数字广告牌上也会挂同一位偶像的生日祝贺广告。粉丝们也会把公共交通上的生日广告拍照留念，一路打卡 [二手资料 JoongAng Daily]。

  • 申请结构：首尔交通公社 (Seoul Metro / 서울교통공사) 通过招标选出的广告代理公司，运营1~8号线车厢和车站内的广告。广告要向该广告代理公司申请，经外部审议机构韩国广告自律审议机构 (Korea Advertising Review Board / 한국광고자율심의기구) 的设计稿审议后才能刊登。审议约需3~5天，不含周末和公休日(首尔交通公社 Seoul Metro 官方)
  • 意见广告不行：陈述个人或团体意见的意见广告，自2022年10月21日起暂停审议(首尔交通公社 Seoul Metro 官方)。生日祝贺广告被归为哪一类，我们在公社页面上没能确认
  • 规模：有报道称，2025年经审议后在首尔地铁播出的偶像广告共12,433件，2026年1~8月为8,012件。同一报道称，田柾国 (Jeongguk / 정국) 的生日广告从8月26日到9月1日，挂在24个站、54块数字广告屏上 [二手资料 Dailian新闻 (Dailian / 데일리안) 2026-09-25]
  • 观赏小提示：广告位置也由主办粉丝账号公布。上下班时间车站里很拥挤，不要在通道正中间长时间拍摄

🧰 生咖 (Saengka / 생카) 实务：独自前往、预约、付款、移动

  • 一个人：独自去的粉丝很多。大部分活动不用预约就能进，但如果有预约或入场顺序，会写在主办方的公告里
  • 付款：饮料在咖啡厅付，周边有时要另向主办方付款。周边的付款方式(现金、转账等)请事先在公告里确认。韩国支付的整体情况见外国人韩国支付系统深度解析
  • 杯子：一次性杯子的制度正在变化。环境部 (Hwangyeong-bu / 환경부) 于2023年11月7日把一次性纸杯从店内使用限制品目中剔除，并延长了塑料吸管的引导期(政策简报 (Policy Briefing / 정책브리핑) 官方)。2025年12月有报道称，草案拟禁止免费提供塑料一次性杯，并收取至少100~200韩元 [二手资料 首尔新闻 (Seoul Shinmun / 서울신문) 2025-12-17]。是否实施、何时实施，我们没能确认。咖啡厅如果另收杯子钱，请按其说明处理
  • 移动：一天要跑好几家生咖 (Saengka / 생카) 的话，先备好交通卡。韩国交通卡3选1，不慌手册：T-money、WOWPASS、气候同行卡买哪个

⚠ 常犯的4个错误

1. "这是官方活动，经纪公司会发公告"：生咖 (Saengka / 생카) 是粉丝办的活动 [二手资料 Korea Herald]。要看主办粉丝的账号，而不是经纪公司的公告

2. "去了就能见到偶像"：这是没有寿星、粉丝们互相庆祝的场合 [二手资料 JoongAng Daily]

3. "晚点去赠品也还在"：限量赠品先到先得 [二手资料 Korea Herald]。去之前先确认售罄公告

4. "地铁广告什么内容都能挂"：首尔地铁1~8号线的广告要经过韩国广告自律审议机构 (Korea Advertising Review Board / 한국광고자율심의기구) 的设计稿审议(首尔交通公社 Seoul Metro 官方)
