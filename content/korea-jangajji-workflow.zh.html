韩式酱腌菜 (Jangajji / 장아찌) 发酵·点餐·搭配指南 — 从韩定食 (Hanjeongsik / 한정식) 小菜无限续到超市真空包装

副标题：外国游客版5步指南，涵盖发酵时机、搭配与回国伴手礼

第03期 · #868 · 2026-06-09

🎯 为什么需要一份韩式酱腌菜分步指南

即使已经了解6种酱腌菜综合指南 (#867)，发酵、点餐与搭配仍是另一回事。韩式酱腌菜 (jangajji / 장아찌，用酱油或醋腌制的蔬菜) 常见于：(a) 韩定食 (hanjeongsik / 한정식，韩式套餐料理) 小菜 (banchan / 반찬，免费的韩式配菜) 无限续(整套小菜，免费)；(b) 家常便饭 (baekban / 백반，韩式家庭简餐) 套餐(2~3种酱腌菜 + 泡菜 (김치))；(c) 市场老字号 (nopo / 노포，经营30年以上的传统老店)(广藏 (Gwangjang / 광장)·南大门 (Namdaemun / 남대문)·全州 (Jeonju / 전주))；(d) 超市与免税店(真空包装的回国伴手礼)。外国游客通常不知道：(1) 韩定食小菜是免费的 (2) 超市和市场是不同的体验 (3) 有些铁粉专门找腌了整整一年的大蒜酱腌菜 (4) 回国伴手礼需要过海关。本指南涵盖5步流程、发酵基础知识和英语实用短语。

★ 一图看懂5步流程

步骤 动作 时间 外国游客关键点
1️⃣ 选择渠道 韩定食 / 家常便饭 / 市场 / 超市·免税店 即时 免费·性价比·老字号·回国目的
2️⃣ 点餐 韩定食套餐 / 家常便饭 / 一份酱腌菜 / 真空包装 1~5分钟 韩定食小菜免费
3️⃣ 上桌·摆盘 整套小菜 / 一份 / 真空包装 5~15分钟 可无限续
4️⃣ 用餐·搭配 米饭·汤·肉·鱼 + 酱腌菜 30~90分钟 铁粉会自行调整辣度
5️⃣ 付款·过海关 可刷卡 / 市场=现金 / 真空包装可过海关 1~5分钟 液体100ml规则适用

所需总时长：韩定食 = 1.5~2.5小时 / 家常便饭 = 30分钟~1小时 / 市场 = 10~30分钟 / 超市 = 15~30分钟

🥒 分渠道指南

A类 — 韩定食小菜无限续(#837)

  • 代表性：小菜免费无限续·整套酱腌菜
  • 营业时间：11:30~22:00
  • 价格：韩定食套餐40,000~150,000韩元(约211~790元人民币)，含免费酱腌菜
  • 菜单：套餐 + 2~6种酱腌菜作为小菜
  • 外国游客亲和度：★★★★(英文菜单)
  • 铁粉追求：小菜免费续，人气#1

B类 — 家常便饭(#854)

  • 代表性：家常味·高性价比·2~3种酱腌菜
  • 营业时间：11:00~22:00
  • 价格：8,000~15,000韩元(约42~79元人民币)/人
  • 菜单：米饭 + 汤 + 主菜 + 2~3种酱腌菜 + 泡菜
  • 外国游客亲和度：★★★★(性价比高)

C类 — 市场老字号(广藏·南大门·全州)

  • 代表性：老字号·可腌足一年·地道正统
  • 营业时间：09:00~22:00
  • 价格：5,000~20,000韩元(约26~105元人民币)/份
  • 菜单：一份酱腌菜 + 可免费试吃
  • 外国游客亲和度：★★★★(可试吃·地道老字号)
  • 铁粉追求：广藏·南大门·全州老字号

D类 — 超市·免税店(回国伴手礼)

  • 代表性：真空包装·可过海关·热门伴手礼
  • 营业时间：超市 = 10:00~22:00 / 免税店 = 06:00~22:00
  • 价格：3,000~10,000韩元(约16~53元人民币)/份
  • 菜单：腌黄萝卜 (danmuji / 단무지，加姜黄的韩式腌萝卜)·腌黄瓜 (oi-jangajji / 오이장아찌)·腌紫苏叶 (kkaennip-jangajji / 깻잎장아찌)(小份真空装)
  • 外国游客亲和度：★★★★★(真空包装·英文标签)
  • 过海关：低于1升可以 / 液体100ml规则适用

  • 真空包装："Vacuum-packed, for taking abroad"
  • 可以刷卡吗？："Card accepted?"

⚠ 外国游客常见的7个误区

1. "酱腌菜 = 泡菜"：泡菜 (김치) = 发酵 + 辣味调味 / 酱腌菜 (장아찌) = 酱油或醋腌制。

2. "韩定食小菜要收费"：韩定食小菜 = 免费无限续(含酱腌菜)。

3. "腌黄萝卜是日本的"：韩式腌黄萝卜 = 姜黄黄色·地道酱腌菜。

4. "腌大蒜发酵很快"：腌大蒜 = 传统需腌足一年。

5. "超市和市场一样"：超市 = 真空包装、可过海关的回国伴手礼 / 市场 = 地道老字号、可试吃。

6. "真空包装过不了海关"：真空包装 = 可以过海关(低于1升，遵循液体100ml规则)。

7. "酱腌菜不辣"：腌辣椒·腌紫苏叶 = 辣(含辣椒)。

⚙ 常见问题8个

1. 第一次尝酱腌菜选哪个渠道：韩定食无限续(免费整套) → 超市(回国伴手礼)。

2. Ins·vlog打卡：韩定食整套小菜·广藏酱腌菜小巷·腌一年的大蒜。

3. MZ世代潮流：高性价比韩定食·MZ世代咖啡馆的酱腌菜融合料理。

4. 烧酒爱好者：腌辣椒 + 腌大蒜。

5. 回国伴手礼：超市·免税店真空装(腌黄萝卜·黄瓜·紫苏叶)。

6. 过敏·孕期：参见#867的免责声明。

7. 付款·小费：可刷卡 / 市场 = 部分只收现金 / 无需小费。

8. 增值税退税：超市可退(满5万韩元(约263元人民币)以上可即时退税)。

⚠ 医疗·安全·饮食免责声明

酱腌菜属于普通食物。孕妇·儿童 = 可食用(注意调整辣度)。过敏(酱油中的麸质·辣椒)需提前告知。如怀疑食物中毒，请拨打☎ 1339(医疗咨询，提供英文服务)。本指南仅为一般信息，不构成医疗建议。

饮食限制替代方案：

  • 清真·犹太洁食：6种均可食用(素食·植物基)。
  • 素食·纯素：6种均可食用(传统上即为素食·纯素)。
  • 无麸质：酱油含麸质 → 可用溜酱油(tamari)替代。
