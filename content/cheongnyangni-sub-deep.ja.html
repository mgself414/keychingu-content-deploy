外国人がやりがちなミス3つ

ミス1. 日曜日に訪問する

清涼里総合市場内の常設店舗の多くが日曜日定休です。特に青果・水産卸売エリアは日曜午前から撤収する商人が多くなります。老舗通りも日曜営業店舗は平日の半分以下です。訪問は火~土曜日を推奨、月曜日は一部エリアが在庫補充日のため選択肢が狭くなります。

ミス2. カードだけ持って行く

老舗・屋台は現金専用が多いです。総合市場本棟の一部店舗にはカード端末がありますが、少額(1万ウォン以下)決済を拒否したり、追加手数料を求めたりする場合があります。現金3~5万ウォンを出発前に引き出しておけば問題ありません。清涼里駅構内と駅前コンビニにATMがあります。

ミス3. ピークタイム(11~13時)に老舗に入る

清涼里のソルロンタン・クッパ老舗は、会社員の昼食需要が集中する11時30分~13時の間に30~60分の待ちが発生します。外国人観光客が言葉の壁なく気楽に座るには10~11時または13時30分以降の入店が実用的です。材料切れの早い店は14時前に売り切れることもあります。

12選4軸 — エリア別深掘り

軸1：清涼里総合市場(3選)

#1 清涼里総合市場本棟

清涼里総合市場は1960年代から形成されたソウル東北圏最大の卸売・小売複合市場です。乾物・穀物・ナッツ・薬味類が一つの建物内に集積しています。

  • 営業時間: 06:00~20:00(店舗ごとに異なる、日曜日は多数休業)
  • 価格: 乾物100gあたり2,000~8,000ウォン(品目により差が大きい、2026年)
  • 外国人fit: ★★★★ — 見て回るだけでも楽しく、小分け購入可能な店舗あり
  • アクセス: 1号線清涼里駅1番出口徒歩5分
  • 英語対応: 一部店舗で基本的な英語(数字・品目名)対応可、翻訳アプリ併用推奨
  • タイミング: 午前9~11時が選択肢最も広い。午後18時以降は片付け開始

外国人観光客がよく購入する品目は、乾燥わかめ・昆布・ごま・チャプチェ用春雨・唐辛子粉の小分けパックです。真空パック対応可能な店舗を選べば、機内持ち込み基準に合わせやすくなります。

#2 清涼里青果卸売エリア

総合市場外周の路上と隣接建物に青果卸売エリアが続きます。旬の果物は箱単位の取引が基本ですが、小売も併行する商人がいて、バラ売りでの購入も可能です。

  • 営業時間: 04:00~16:00(卸売ピークは05~09時、小売は10~15時)
  • 価格: いちご1パック(500g)5,000~8,000ウォン／すいか1個15,000~25,000ウォン(シーズン・品種により変動、2026年)
  • 外国人fit: ★★★ — 大量購入単位のため少量購入者にはやや不便な場合あり
  • 英語対応: なし、指差し・電卓での会話
  • タイミング: 小売購入は10~14時が現実的

#3 清涼里水産物横丁

総合市場裏手に続く水産物専門の横丁です。鮮魚、乾物 — クルビ(Gulbi / 굴비)・グチ・イカ・干しダラ — 、塩辛類が集積しています。

  • 営業時間: 06:00~19:00(乾物店基準、鮮魚は14~15時に早く閉まる場合あり)
  • 価格: クルビ10尾15,000~40,000ウォン(サイズ・品種による)、イカ1杯2,000~4,000ウォン(2026年)
  • 外国人fit: ★★★★ — 匂いと視覚的な光景が強烈な市場体験、真空パック依頼可能
  • 英語対応: なし
  • タイミング: 午前が鮮度最高。乾物は午後も購入可能

軸2：清涼里伝統老舗(3選)

#4 清涼里ソルロンタン・クッパ通り

清涼里駅周辺の裏通りに、ソルロンタン・ソンジ(牛血)クッパ・スンデクッパを専門とする老舗が密集しています。営業期間30~50年以上の店が複数あります。看板・内装が数十年前のままの場合が多く、レトロな雰囲気を楽しむJPセグメントに特に評判が良いです。

  • 営業時間: 06:00~15:00(材料切れで早く閉まる場合あり)、一部24時間営業
  • 価格: ソルロンタン1杯9,000~12,000ウォン／クッパ8,000~11,000ウォン(2026年)
  • 外国人fit: ★★★★★ — 注文方法がシンプル(メニュー1~3種)、おかずはセルフ、看板は翻訳アプリで対応可能
  • アクセス: 1号線清涼里駅2~3番出口徒歩3~7分の裏通り
  • 英語対応: なし。指でメニュー表を指すか、Googleレンズを活用
  • タイミング: 10~11時または13時30分以降(ピークタイム11:30~13:00は回避)
  • 注意: 骨スープベースの強い香り — 初めての韓国クッパ体験ならスンデクッパよりソルロンタンのほうが入りやすい

#5 清涼里コムタン横丁

牛骨・牛足を長時間煮込んだコムタン専門老舗clusterです。ソルロンタンよりスープが澄んでいて淡白なため、外国人にとって入りやすい味です。ご飯を入れて食べるスタイルが基本で、カクテキ(Kkakdugi / 깍두기)とカクテキの汁がコムタンとの相性が良いです。

  • 営業時間: 07:00~15:00前後(店舗ごとに異なる、日曜休業多数)
  • 価格: コムタン1杯9,000~13,000ウォン(2026年)
  • 外国人fit: ★★★★ — 澄んだスープの特性上、違和感が少ない
  • 英語対応: なし
  • タイミング: 午前7~10時の朝食訪問、またはブレイクタイム前の11時まで

#6 清涼里粉食・屋台cluster

清涼里市場の入口と裏通りに、トッポッキ・スンデ・オムク・揚げ物を売る屋台と小さな粉食店が集まっています。1人当たり3,000~8,000ウォンでソウル最安値クラスの食体験が可能です。

  • 営業時間: 10:00~22:00(店舗ごとに異なる、夜間屋台は夕方から)
  • 価格: トッポッキ1人前3,000~4,000ウォン／スンデ3,000ウォン／揚げ物1個500~1,000ウォン(2026年)
  • 外国人fit: ★★★★★ — 指差し注文方式、費用負担なし、写真映え良好
  • 英語対応: なし、指差し・電卓
  • タイミング: 昼食直前(10~11時)または夕方(17~20時)が活気あり

軸3：清涼里ナイトマーケット(3選)

#7 清涼里夜間屋台(20~02時)

日が暮れると清涼里駅周辺の裏通りに屋台と夜間露店が並びます。イカ焼き・鶏串・ホットク(Hotteok / 호떡)・ラーメンなど夜食メニューが中心です。外国人が一人で訪れても問題ありませんが、深夜は酔客がいることもあるため同行訪問を推奨します。

  • 営業時間: 20:00~02:00(繁忙期・週末は延長、平日は深夜前後に撤収多数)
  • 価格: イカ焼き5,000~8,000ウォン／鶏串2本3,000ウォン(2026年)

  • 英語対応: なし
  • タイミング: 21~23時の間が屋台数・活気ともに最適

#8 清涼里ナイトマーケットマニアcluster

総合市場周辺の飲食街に、夜間も営業する食堂が並んでいます。ヘジャングク(Haejangguk / 해장국)・サムギョプサル(Samgyeopsal / 삼겹살)・チキンのテイクアウトが夜間の主力メニューで、一人客の外国人でも座れる1人席構造の食堂もあります。

  • 営業時間: 18:00~01:00(店舗ごとに異なる)
  • 価格: サムギョプサル200g 15,000~18,000ウォン／ヘジャングク9,000~12,000ウォン(2026年)
  • 外国人fit: ★★★ — メニューの選択肢あり、夜の韓国料理体験が目的
  • 英語対応: なし、メニュー表の写真・翻訳アプリが必要

#9 清涼里早朝競売エリア(#587 cross)

清涼里の水産物・青果卸売の早朝競売は04~06時に集中します。観光目的の見学は限定的で、卸売取引が目的でなければ競売現場への立ち入りは難しいです。早朝市場全般に関心があるなら、#587(鷺梁津・カラク・馬場)crossの参照が実用的です。

  • 営業時間: 早朝04:00~07:00(競売ピーク)
  • 外国人fit: ★★ — 観光目的の見学難易度は高い
  • アクセス: 一般観光客は清涼里駅周辺の早朝水産屋台レベルで体験するのが現実的

  • 営業時間: 08:00~18:00(店舗ごとに異なる、日曜一部休業)
  • 価格: 紅参エキス30包30,000~80,000ウォン／高麗人参の根15,000~50,000ウォン(品質等級による、2026年)
  • 外国人fit: ★★★★★ — 一部店舗で英語・中国語・日本語対応可。Tax Refund表示店舗あり
  • アクセス: 1号線清涼里駅から徒歩10分、または1号線祭基洞(Jegi-dong / 제기동)駅1番出口徒歩3分
  • 英語対応: 一部可能(漢方卸売の特性上、外国人客対応の経験がある店舗多数)

FAQ 5

Q1. 初めて訪問するならどこから始める？

1号線清涼里駅1番出口 → 総合市場本棟(#1)に入り、乾物・穀物エリアを一周。その後2~3番出口方向の裏通りに移動し、老舗ソルロンタン(#4)や粉食屋台(#6)で昼食。半日の動線で十分です。

Q2. #598薬令市deep diveとどう違う？

#598は清涼里＋京東薬令市の9市場フルセットclusterです。#609(本編)は清涼里総合市場＋伝統老舗＋夜間市場に絞ったsub-deepです。漢方・薬材に関心があれば#598を、市場グルメ・老舗体験が目的なら#609を先に読むのが効率的です。

Q3. 価格水準は？

1人1食8,000~13,000ウォン(クッパ・ソルロンタン)、屋台おやつ3,000~8,000ウォン。京東市場の漢方みやげ予算は30,000~100,000ウォンが現実的な範囲です。半日コース全体を20,000~30,000ウォンで完成できます。

Q4. 日曜日に訪問してもいい？

総合市場の一部店舗と老舗通りの多くが日曜休業です。やむを得ず日曜になる場合は、夜間屋台(#7・#8)と24時間営業のヘジャングク店を中心に動線を組むのが現実的です。訪問前にGoogleマップで営業日を確認することを推奨します。

Q5. 韓国語ができなくても一人で行ける？

可能です。指差し注文(欲しいものを指で示す)と電卓での会話がほとんどの状況で通用します。翻訳アプリのカメラモードでハングルのメニュー表をスキャンすれば、注文に大きな支障はありません。京東市場漢方エリアの一部店舗は基礎英語が可能です。

シーズン5軸

  • 春(3~5月): 市場の旬の春野菜・いちご・マクワウリのシーズン。青果エリア(#2)は見どころ多数。快適な気候で夜間屋台体験にも適する。
  • 夏(6~8月): すいか・マクワウリ・桃の卸売最盛期。午前の青果エリアが活気づく。夜間屋台は暑さのため22時以降に集中。
  • 秋(9~11月): 乾物・穀物の収穫期で最盛期。干しえび・秋のコノシロ・大エビが水産物横丁(#3)に入荷する時期。JP観光客の秋訪問がピーク。
  • 冬(12~2月): コムタン・ソルロンタン老舗(#4・#5)の最盛期。熱いスープが目的の訪問に最適。屋内中心の動線にすれば寒波でも問題なし。
  • 梅雨(6~7月の一部): 屋内市場(総合市場本棟)中心に動線を単純化。夜間屋台は雨天時に撤収の場合あり。

外国人マニア5 tip

1. 1号線清涼里駅ベースキャンプ — 出口によって向かうエリアが異なります。1番出口(市場)、2~3番出口(老舗裏通り)を区別して出れば時間の節約になります。

2. #598・#365漢方cross半日 — 清涼里総合市場と京東薬令市の動線は徒歩でつながっています。漢方みやげのTax Refundは表示のある店舗のみ対応、出発前に確認を。

3. #587早朝フルセット — 早朝市場体験を望むなら鷺梁津・カラク・馬場のほうが完成度が高いです。清涼里の早朝はウォーミングアップ程度に捉えましょう。

4. 現金3~5万ウォンを準備 — 老舗・屋台・夜間屋台村は全て現金必須。清涼里駅構内のATMを利用してください。

5. JP・EN本場マニアfit — インスタ映えよりも韓国の実際の生活市場を体験したい旅行者に最適。写真より味と雰囲気に集中するセグメント向けです。
