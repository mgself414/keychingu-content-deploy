同一品牌，不同配方——韩日化妆品法规逻辑与成分表读法

副标题：「日本用惯的产品，韩版成分怎么不一样？」——不是错觉，是制度差异。日本医药部外品审批制和韩国功能性化妆品公告制有何不同，货架前该确认什么再买。K-Beauty购物成分素养篇。

ISSUE · #1335 · 2026-08-29

🎯 框架——这个疑问问对了

日本游客社群里确实反复出现同一个问题："同款产品，在唐吉诃德买的日版和韩版成分标示不一样。"先说答案：不一定相同，这不是厂商任性，而是两国监管结构上的差异所致。搞懂这套逻辑之后，在橄榄young (Olive Young / 올리브영) (#47) 货架前读成分表的眼光就不一样了。

① 两国的制度逻辑——审批制 vs 公告制

🇯🇵 日本 🇰🇷 韩国
体系 化妆品 / 医药部外品(医薬部外品) 两层 化妆品 / 功能性化妆品 (gineungseong hwajangpum / 기능성화장품) 两层
运作方式 美白等"有效成分"必须先获批为医药部外品才能配方使用——成分与浓度按审批名单管理 美白、抗皱等只要满足食药处 (sigyakcheo / 식약처) 公告的成分与条件，就能标注为"功能性化妆品"
结果 有效成分的种类与浓度控制得比较保守 只要符合公告成分标准(例：美白烟酰胺2%以上、抗皱腺苷0.04%)即可标注——其余成分组合的自由度相对更高
实际感受 "含强效成分的产品比较少见" "复合配方、高浓度宣称的产品很常见"
  • 典型案例是氨甲环酸：在日本它是只能添加进医药部外品的审批有效成分，普通化妆品里不能用。所以即便是同系列产品，配方也会因市场而不同。
  • 反过来，韩国货架上主打视黄醇、复合成分的产品要丰富得多——这不是监管松，而是管理方式不同。

② 对旅行者来说这意味着什么——三句话

1. 确实存在只有韩国才买得到的配方 ——这正是K-Beauty购物的乐趣所在，也是日本游客专程买韩版的原因。

2. "成分强 = 好东西"这件事不成立 ——如果是自己皮肤第一次接触的成分或浓度，就该谨慎(④ 提醒)。

3. 越是一直用同一个牌子的人，越需要养成买前先看成分表的习惯 ——熟悉的名字不代表熟悉的配方。

③ 在货架前怎么确认——三步

1. 找「功能性化妆品 (gineungseong hwajangpum / 기능성화장품)」标示 ——包装上出现这几个字，就代表符合食药处公告标准(旁边还会写明是美白、抗皱还是防晒等具体功能)。

2. 对照全成分表 (jeonseongbunpyo / 전성분표) (INCI) ——韩国强制标注化妆品全成分，背面会写得一清二楚。想跟自己常用的产品比对，最保险的办法是提前拍好日版照片带过来，两相对照。

3. 看不懂就拍照翻译 ——成分名用翻译App的相机功能就能读懂。橄榄young等大型门店试用装很常见，手背试用也没有负担。

货架生存词汇5个

标示 含义
功能性化妆品 (gineungseong hwajangpum / 기능성화장품) 符合食药处公告标准的标示——本篇的核心词汇
美白 (mibaek / 미백) / 抗皱 (jureumgaeseon / 주름개선) 功能性种类(whitening / anti-wrinkle)
全成分 (jeonseongbun / 전성분) 全部成分清单(full ingredients)
敏感性 (mingamseong / 민감성) / 低刺激 (jeojageuk / 저자극) 宣称sensitive / mild——不是法定定义
保质期 (yutonggihan / 유통기한) / 开封后 (gaebong hu / 개봉 후) 使用期限标示

④ 提醒四条——这不是医疗建议

  • 第一次使用的有效成分(视黄醇、酸类等)要从小剂量、低频率开始，皮肤有反应就停用——旅行途中尤其要注意。
  • 如果正在治疗皮肤疾病或刚做完医美项目，尝试新成分前先跟主治医生商量(医美相关见#508、#764)。
  • 具体含量数值因产品、因改版而异——本文只说明制度，不保证单一产品的效果。
  • 化妆品不是药品——一旦抱着"治疗"的期待去买，失望和风险会一起找上门。
