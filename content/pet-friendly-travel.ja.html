⚠ 外国人が犯しやすい 5 つの間違い

1. 「韓国 = ペットの持ち込み不可」: 韓国への輸入 = 狂犬病抗体(血清検査) + マイクロチップ + 検疫報告書 + 仁川空港検疫所(外国人は英語OK) + #398 一体化。

2. 「ペット可 = なし」: ペット可 = ホテル (江南・弘大 50+) + ペンション・プールヴィラ (加平・楊平) + カフェ (#442) + レストラン・#400 + 外国人マニア。

3. 「ペット救急 = 英語不可」: 英語OK = 江南24時間ペット病院 + 外国人医療観光(#401) + #405 救急 + 外国人マニアNo.1。

4. 「ペット日帰り旅行 = いいえ」: ペット日帰り旅行 = 加平・楊平・坡州・済州・江原 + #430・#439 レンタカー + ペット同伴可能なカフェ/レストラン + 外国人ファミリーマニア。

5. 「ペット飛行機 = 高価」: 飛行機 = 機内ケージ (5kg 以下) と貨物 (5kg 以上) + 航空会社ごとのポリシー (大韓航空・アシアナ航空の外国人は英語可) + 検疫書類一式。
