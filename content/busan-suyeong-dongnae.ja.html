釜山の原点、スヨン (Suyeong / 수영) ・トンネ (Dongnae / 동래) — クァンアルリ (Gwangalli / 광안리) の裏側と朝鮮時代の釜山

副題: 海雲台とクァンアルリが観光客の釜山なら、裏には発祥の二町がある。行政中心のトンネと水軍司令部のスヨン — 邑城とパジョンの原点、工場改造文化空間が育つ新興ローカル。地下鉄3号線でつなぐ1日コース。

ISSUE · #1329 · 2026-08-24

🎯 フレーム — 海雲台以前の釜山

釜山は開港(1876年)以降、港湾都市として発展したが、それ以前この地域の中心は海ではなく内陸のトンネだった。壬辰倭乱最初の激戦地だったトンネ邑城 (Dongnae Eupseong / 동래읍성)、伽耶時代の古墳群、そして朝鮮水軍の南方司令部慶尚左水営 (Gyeongsang Jwasuyeong / 경상좌수영)(現在のスヨン区という地名の由来)がその痕跡だ。クァンアン大橋 (Gwangan Bridge / 광안대교) の夜景(#1326)を見たなら、翌日は半日ずつこの二つの町を歩いてみよう — 観光地・釜山の「オリジナルファイル」を開くコースだ。

  • 移動の骨格: 地下鉄2・3号線。スヨンは2・3号線スヨン駅 (Suyeong-yeok / 수영역)、トンネは1・4号線トンネ・スアン (Suan / 수안) 圏 — 3号線がこの二軸を直結する(#1325交通ガイド参照)。

① スヨン半日 — 市場・水営城 (Suyeongseong / 수영성) ・F1963・マンミダンギル (Mangmi-dangil / 망미단길)(徒歩コース)

釜山市公式の徒歩コースとしても紹介されている、実証済みの動線だ。徒歩の合計は約2.5~3時間+滞在時間。

1. スヨン駅5番出口 → スヨン八道市場 (Suyeong Paldo Sijang / 수영팔도시장)(徒歩約3分) — 朝鮮左水営時代の「八道の物産が集まる」という名の通りのアーケード市場。観光市場ではなく町の市場だから、練り物・粉食の物価がやさしい

2. 市場 → スヨン史跡公園 (Suyeong Sajeok Gongwon / 수영사적공원)(徒歩約5分) — かつての左水営城跡。数百年を経たクロマツの木と城門の痕跡が残り、水営城村博物館 (Suyeongseong Maeul Museum / 수영성마을박물관) が隣接する

3. 史跡公園 → F1963(徒歩約15分) — 1963年に建てられた高麗製鋼のワイヤー工場を丸ごと改造した複合文化空間。書店・展示場・カフェ・庭園が工場の骨組みの中に収まっている。ソウル聖水洞スタイルの工場リノベーションを釜山スケールで見られる場所

4. F1963 → マンミダンギル (Mangmi-dangil / 망미단길)(徒歩約5分) — マンミドン (Mangmi-dong / 망미동) の住宅街の路地にカフェ・花屋・小さな食堂が染み込んだ新興横丁。商業地区というより住宅地に近い — 静かに歩くのがマナーだ

クァンアルリ (Gwangalli / 광안리) 海水浴場(#243・#1023)とスヨン駅は徒歩15分の距離 — このコースを午後に歩き、夜はクァンアルリの夕日~クァンアン大橋の夜景へつなげば、一日が完成する。

② トンネ半日 — 市場・パジョン・邑城・古墳群(徒歩コース)

1. スアン駅5番出口 → トンネ市場 (Dongnae Sijang / 동래시장)(徒歩約5分) — チョッパル(豚足)・カルグクス・練り物が豊富な在来市場。目的はひとつ、トンネパジョン (Dongnae Pajeon / 동래파전)だ

2. トンネパジョンの文法: 普通のパジョンと違い、煮干し出汁で溶いた米粉の生地を使うため、外はカリッと、中はもちもち・しっとりしている。朝鮮時代にトンネ府使が王に献上したという由来が伝わるこの町のシグネチャーで、市場内のパジョン横丁と区庁裏の専門老舗(4代続く店が有名)で味わえる

3. 市場 → トンネ邑城北門・歴史館(上り坂徒歩約20分) — 1592年、壬辰倭乱最初の激戦地。城壁沿いを歩くトレッキングコースが整備されており、北門エリアから市街を見下ろせる

4. 邑城 → ポクチョンドン古墳群 (Bokcheon-dong / 복천동고분군) ・ポクチョン博物館 (Bokcheon Museum / 복천박물관)(徒歩約15分) — 尾根の上に伽耶時代の古墳が芝生の丘のように連なる。博物館は無料観覧で、丘そのものが散策路になっている

足が疲れたら締めくくりはトンネ温泉 (Dongnae Oncheon / 동래온천)(#269)の温泉浴 — 市場から温泉場までは地下鉄ひと駅だ。

③ 二つの町を一日で — おすすめタイムテーブル

時間 動線
10:00 スアン駅 → トンネ市場でパジョンの早めの昼食
12:00 トンネ邑城 → ポクチョン博物館
15:00 3号線で移動(約20分) → スヨン八道市場 → スヨン史跡公園
16:30 F1963 → マンミダンギルでコーヒー
18:30 徒歩/バスでクァンアルリへ — 夕日とクァンアン大橋の夜景(#1326)
  • 体力の負担を減らすなら二日に分けて半日ずつ。夏はトンネ邑城の上り坂を朝に配置する方がいい。

💡 戸惑いポイント

  • トンネ邑城は「城がひとつ建っている場所」ではなく、山裾に散らばる遺跡群だ — 北門・歴史館を目的地として地図アプリに登録するのが正確だ。
  • F1963内部の施設(展示など)は曜日によって運営が異なることがある — 訪問前に公式案内を確認しよう。
  • マンミダンギル・スヨンの路地は住宅地だ。写真は店の中で、路地では声を落とすのがローカルマナー。
