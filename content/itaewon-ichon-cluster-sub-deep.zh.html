🎯 如何使用这份指南

这份指南汇集了首尔龙山区可去的地方。有国立中央博物馆和战争纪念馆这样的大型博物馆、建在旧基地旧址上的公园、汉江大桥中间的Nodeul岛、有独立运动家墓园的孝昌公园，还有梨泰院的街道和南山脚下的Haebangchon。博物馆和公园登记为免费入场。国立中央博物馆收费的特别展览除外。

周一休息的地方很多(战争纪念馆·龙山历史博物馆·龙山公园部分开放场地·龙山儿童花园·Nodeul岛)。国立中央博物馆周一多数日子也开放(3月·6月·9月·12月的第一个周一为定期休馆日)，周三和周六开放到21:00。Ichon汉江公园在#706 汉江公园指南里。

📍 博物馆 — 国立中央博物馆·战争纪念馆·龙山历史博物馆

国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)，龙山区 (Seobinggo-ro 137 / 서빙고로 137)，☎ 02-2077-9000，是2005年迁到龙山开馆的博物馆。有按时代和主题划分的7个常设展馆、特别展馆和儿童博物馆，常设展馆展出文物9,884件。展品定期更换。

  • 开放时间:室内展厅周一·周二·周四·周五·周日 09:30~17:30(入场截止 17:00)，周三·周六 09:30~21:00(入场截止 20:30)。户外展场(庭园)07:00~22:00。
  • 休息日:1月1日，春节·中秋节当天。另外每年3月·6月·9月·12月的第一个周一登记为“定期休馆日”。
  • 费用:免费。收费特别展览除外。停车:小轿车基本30分钟900韩元，之后每10分钟300韩元。

国立中央博物馆儿童博物馆(同一地址，☎ 02-2077-9647)是体验式博物馆，孩子可以亲手触摸与常设展馆文物形状·大小相同的复制品。

  • 开放时间:10:00~17:50。休息日:1月1日，春节·中秋节假期，馆长指定日。费用:免费。

战争纪念馆，龙山区 (Itaewon-ro 29 / 이태원로 29)，☎ 02-709-3114，是1994年6月10日建成的纪念馆。在3万3千余件藏品中展出1万余件。室内有护国追悼室、战争历史室、6·25战争室、海外派兵室、国军发展室、大型装备室6个展厅，室外有K-1战车、榴弹炮、导弹、直升机、运输机等大型武器，以及广开土大王碑 (Gwanggaeto Daewang-reungbi / 광개토대왕릉비)、兄弟之像 (Hyeongje-ui Sang / 형제의 상)、和平钟楼 (Pyeonghwa-ui Sigyetap / 평화의 시계탑)。两侧回廊有刻着国军和联合国军阵亡者20余万人姓名的阵亡者名碑。

  • 开放时间:09:30~18:00(入场截止 17:00)。休息日:每周一。
  • 费用:免费。参观时间:约2小时。停车:小型车2小时内4,000韩元，之后每30分钟1,500韩元。
  • 讲解:登记信息称，团体参观和展览讲解可在官网预约。

龙山历史博物馆，龙山区 (Hangang-daero 14-gil 35-29 / 한강대로14길 35-29)，☎ 02-2199-4620，2022年3月作为地区史专门博物馆重新开馆。建筑是日本殖民时期建造的铁路医院，保存·复原医院建筑后使用。有按时代划分的展示空间、体验区和屋顶花园。

  • 开放时间:10:00~18:00(入场截止 17:30)。休息日:每周一，1月1日，春节·中秋节当天。费用:免费。

📍 旧基地旧址上的公园 — 龙山家族公园·龙山公园部分开放场地·龙山儿童花园

龙山家族公园，龙山区 (Seobinggo-ro 185 / 서빙고로 185)，☎ 02-792-5661，是有宽阔草坪和池塘的公园。6·25战争时联合国军和驻韩美军司令部所在的地方，1992年由首尔市接收后建成公园。有散步路、户外雕塑和运动设施。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

龙山公园部分开放场地，龙山区 (Seobinggo-ro 221 / 서빙고로 221)，☎ 070-4224-1708，是旧美军军官宿舍5区旧址。这里是朝鲜时代储存冰块的“Seobinggo (Seobinggo / 서빙고)”所在地，光复后美军部队进驻，据说一带被称为“Camp Seobinggo”。户外有Deulnae Bomnae草坪广场、红色边框的圆形标识牌、Duruduru展亭等拍照的地方。

  • 开放时间:周二至周日 09:00~18:00(入场截止 17:00)。
  • 休息日:每周一，1月1日，春节·中秋节当天。周一为公休日则次日休息。
  • 费用:免费。停车:可以。

龙山儿童花园，龙山区 (Yongsan-dong 5-ga 2-1 / 용산동5가 2-1)，☎ 070-8833-5800，是重新改造龙山基地的地方。有Ieum广场、档案馆、瞭望坡、Bobo之家、儿童环境生态教育馆，还有咖啡厅和医务室。登记信息称无需提前预约即可参观。

  • 开放时间:周二至周五·周日 09:00~18:00(入场截止 17:00)，周六 09:00~21:00(入场截止 20:00)。
  • 休息日:每周一，1月1日，春节·中秋节当天。周一为公休日或替代公休日则次日休息。
  • 费用:免费。停车:不可以。

📍 汉江上的岛与独立运动家墓园 — Nodeul岛·孝昌公园

Nodeul岛，龙山区 (Yangnyeong-ro 445 / 양녕로 445)，☎ 02-749-4500，是位于汉江大桥中间的椭圆形岛屿。据传名字来自意为“白鹭玩耍的石头”的“Nodol (Nodol / 노돌)”。2019年9月作为“以音乐为媒介的复合文化基地”重新开放。

  • 开放时间:冬季(11~2月)周二至周日 10:00~20:00。夏季(3~10月)周二至周五 10:00~21:00，周末·公休日 10:00~22:00。户外空间全天开放，各设施运营时间不同。
  • 休息日:每周一，1月1日，春节·中秋节。
  • 费用:免费。停车:前30分钟1,000韩元，之后每10分钟300韩元，每天最高15,000韩元。

孝昌公园，龙山区 (Hyochangwon-ro 177-18 / 효창원로 177-18)，☎ 龙山区厅公园绿地科 (Yongsan-gucheong Gongwon Nokji-gwa / 용산구청 공원녹지과) 02-2199-7594，是安放独立运动家遗骸的地方。原本是正祖长子文孝世子等人陵墓所在的孝昌园 (Hyochangwon / 효창원)，日本殖民时期成为公园，1944年为建忠灵塔，把陵墓迁到了高阳西三陵。光复后，白凡金九把李奉昌、尹奉吉、白贞基三义士的遗骸安放在这里，并为安重根义士修建了假墓。1948年安放了李东宁、车利锡、曹成焕，1949年安放了金九的遗骸。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

📍 梨泰院与Haebangchon — 旅游特区·古董家具街·Usadan-gil·伊斯兰街·Haebangchon村

梨泰院旅游特区，龙山区 (Itaewon-ro 150 / 이태원로 150)，☎ 梨泰院旅游咨询处 (Itaewon Gwangwang Annaeso / 이태원 관광안내소) 02-3785-0942，据韩国观光公社介绍，是1997年首尔市首次指定的旅游特区，有2万名以上外国人居住，是多国·多文化地区。以皮具、杂牌服装、小商品店闻名，还有外国人亲自经营的餐厅聚集的世界美食街。

  • 开放时间·休息日:各店不同。停车:可以。

梨泰院古董家具街，龙山区 (Bogwang-ro 109-1 / 보광로 109-1)，☎ 龙山区厅地区经济科 (Yongsan-gucheong Jiyeok Gyeongjae-gwa / 용산구청 지역경제과) 02-2199-6784，起源于1960年代附近美军部队的军人回国时，把用过的家具拿出来卖。除了家具，钟表、茶杯、饰品也是热门商品，还卖西洋古董和复古物品。据介绍，春秋两季会举办梨泰院古董节。

  • 开放时间·休息日:各店不同。停车:不可以。

梨泰院 Usadan-gil (Itaewon Usadan-gil / 이태원 우사단길)，龙山区 (Hannam-dong / 한남동)，☎ 梨泰院旅游咨询处 02-3785-0942，是巴基斯坦、土耳其、埃及、黎巴嫩、印度等国的餐厅和阿拉伯语招牌与老旧住宅区小巷混在一起的街道。从2010年代初开始，年轻艺术家和青年创业者陆续入驻。

  • 开放时间·休息日:各设施不同。停车:不可以。

梨泰院伊斯兰街，龙山区 (Usadan-ro / 우사단로)一带，☎ 龙山区 02-2199-6114，从地铁6号线梨泰院站3号出口走上Bogwang小学 (Bogwang Chodeunghakgyo / 보광초등학교)小巷即是起点。以首尔中央清真寺 (Seoul Jungang Seongwon / 서울중앙성원) 为中心，有伊斯兰学校、清真肉店、伊斯兰食材超市、清真餐厅、卖头巾的服装店、伊斯兰书店和图书馆。

  • 开放时间·休息日:各商家不同。

Haebangchon村，龙山区 (Sinheung-ro 3-ga-gil 66 / 신흥로3가길 66)，☎ 龙山旅游咨询处 (Yongsan Gwangwang Annaeso / 용산 관광안내소) 070-7731-7050，是1945年光复后，失去家乡的人、从海外回来的人和躲避战乱的人在南山脚下的山坡上安家形成的村落。保留着狭窄的小巷和山坡。2021年通过城市再生项目，在“108阶梯”设置了斜行电梯。

  • 开放时间:全天开放。停车:可以。

⚠ 行前须知 3 点

  1. 周一有多处休息 — 战争纪念馆、龙山历史博物馆、龙山公园部分开放场地、龙山儿童花园、Nodeul岛登记为周一休息。
  2. 国立中央博物馆周三和周六开放到21:00 — 其他日子的室内展厅开放到17:30。
  3. 龙山儿童花园和古董家具街·Usadan-gil不能停车 — 龙山家族公园、龙山公园部分开放场地、孝昌公园可以停车。

⚙ FAQ 2

Q. 可以免费参观的博物馆有哪些?

A. 按观光公社登记信息，国立中央博物馆(收费特别展览除外)、儿童博物馆、战争纪念馆、龙山历史博物馆全部免费。

Q. 晚上也开放的地方有哪些?

A. 国立中央博物馆室内展厅周三·周六开放到21:00，户外展场开放到22:00。龙山儿童花园周六开放到21:00。Nodeul岛冬季(11~2月)周二至周日开放到20:00，夏季(3~10月)周二至周五开放到21:00，周末·公休日开放到22:00，户外空间全天开放。
