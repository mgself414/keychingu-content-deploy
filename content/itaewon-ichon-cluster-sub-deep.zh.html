龙山指南——梨泰院·汉南·二村汉江，3家免费博物馆与儿童庭园（2026官方信息）

副标题：国立中央博物馆 免费·周三周六开到21点 / 战争纪念馆 免费·周一休馆·09:30~17:40 / 龙山儿童庭园 免费开放（周二至周日，周六到21点） / 龙山家族公园 24小时 / Leeum 汉江镇站·爱茉莉太平洋美术馆 新龙山站 / 梨泰院 10·29记忆与安全之路——2026-10-08 以各机构·首尔市官方页面为准。国立韩文博物馆休馆至2028年下半年

上级 deep: #583 梨泰院·#706 汉江公园

※ 区别——#583 = 梨泰院购物 focus·#710 = 梨泰院国际街区 + 二村汉江 + 龙山 day-trip 路线全套（白天+夜晚 cluster）

🎯 本指南使用方法

龙山是首尔免费博物馆最集中的地方——国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)（免费，周三·周六开到21点）、战争纪念馆 (Jeonjaeng Ginyeomgwan / 전쟁기념관)（免费，周一休馆），以及2025年底全面开放的龙山儿童庭园 (Yongsan Eorini Jeongwon / 용산어린이정원)（免费）。此外，汉南洞 (Hannam-dong / 한남동)的三星美术馆Leeum (Leeum / 리움미술관)和爱茉莉太平洋美术馆 (APMA / 아모레퍼시픽미술관)、二村汉江、梨泰院的夜街，都在三个地铁站的范围内。下面的数值只记录2026-10-08在各机构·首尔市官方页面上读到的内容；二村汉江公园 (Ichon Hangang Gongwon / 이촌한강공원)设施、梨泰院站 (Itaewon / 이태원역)出口、N首尔塔这类没能读到官方页面的项目，一律标为“未核实”。旧版指南中的“龙山公园 (Yongsan Gongwon / 용산공원)2027年开放预定”（儿童庭园已经开放，其余部分未定）、“二村站 (Ichon / 이촌역)1号线”（实为4号线·京义中央线）、“从梨泰院站 (Itaewon / 이태원역)去Leeum”（应走汉江镇站 (Hangangjin / 한강진역)1号出口）、“汉江烟花节在二村”（实际在汝矣岛）都是错的，已经剔除。

🏛 3家博物馆——全部免费

  • 国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)（西冰库路137）：常设展免费，周三·周六开到21点，庭园07~22点，休馆日1/1·春节·中秋（官方）。10月特别展见 #350。从二村站 (Ichon / 이촌역)步行前往（出口编号官方未公布——二手来源第2条）。
  • 战争纪念馆 (Jeonjaeng Ginyeomgwan / 전쟁기념관)（梨泰院路29）：09:30~17:40（17:00停止入场），周一休馆，免费（官方）。室外展区的飞机·坦克，整体逛一圈需1~2小时。最近的是三角地站 (Samgakji / 삼각지역)。
  • 国立韩文博物馆 (Gungnip Hangeul Bangmulgwan / 국립한글박물관)：休馆至2028年下半年（官方横幅）。请勿前往。

🌳 龙山儿童庭园·龙山家族公园——旧美军基地的现在

  • 龙山儿童庭园 (Yongsan Eorini Jeongwon / 용산어린이정원)（汉江大路38街21）：自2025-12-30起无需预约全面开放（首尔市）。周二至周五·周日 09~18，周六 09~21，周一休息。旧版指南里的“龙山公园 (Yongsan Gongwon / 용산공원)2027年开放”并不确定——2026年8月，首尔市和龙山区反对该用地的住宅供应计划，目前未定（报道）。
  • 龙山家族公园 (Yongsan Gajok Gongwon / 용산가족공원)（龙山洞4街13）：24小时·免费，从西冰库站 (Seobinggo / 서빙고역)1号出口步行673m（首尔市2023年资料——是较旧的数值）。

🖼 汉南——Leeum·爱茉莉太平洋美术馆

  • 三星美术馆Leeum (Leeum / 리움미술관)：周二~周日 10~18，周一休馆，通用票25,000·常设展免费，*汉江镇站 (Hangangjin / 한강진역)1号出口（6号线）——不是梨泰院站 (Itaewon / 이태원역)*。提供4种语言的数字导览。
  • 爱茉莉太平洋美术馆 (APMA / 아모레퍼시픽미술관)：周二~周日 10~18，周一休馆，索尔·勒维特展18,000韩元（线上预订），新龙山站 (Sinyongsan / 신용산역)1号出口。详情见 #350。
  • 汉南洞 (Hannam-dong / 한남동)的画廊名称在官方页面上没能读到，所以不列出。

🌃 梨泰院——夜街与追思

  • 梨泰院 (Itaewon / 이태원)被认为是首尔第一个旅游特区（1997），但这次没能打开官方说明页面，所以不加标注。餐厅·酒吧的名字也不列出。
  • 记忆与安全之路10·29 (10.29 Gieokgwa Anjeonui Gil / 10·29 기억과 안전의 길)：2022年发生惨案的汉密尔顿酒店 (Hamilton Hotel / 해밀톤호텔)旁小巷，2023年起作为追思空间开放（二手来源；官方网站证书错误）。路过时请保持安静。
  • 首尔中央清真寺 (Seoul Jungang Seongwon / 서울중앙성원)（伊斯兰寺院）没能打开官方页面，所以不写建成年份。

🌉 二村汉江——参观完博物馆之后

  • 二村汉江公园 (Ichon Hangang Gongwon / 이촌한강공원)是从国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)步行下来就到的汉江。自行车·渡口·便利设施，因官方页面正文打不开而未核实。汉江巴士·游船·喷泉见 #786。
  • 烟花节在汝矣岛（9/5，已结束）——不在二村。

🚶 一日路线

  • 白天：三角地站 (Samgakji / 삼각지역)战争纪念馆 (Jeonjaeng Ginyeomgwan / 전쟁기념관)（免费）→ 龙山儿童庭园 (Yongsan Eorini Jeongwon / 용산어린이정원)（周一休息）→ 二村站 (Ichon / 이촌역)国立中央博物馆 (Gungnip Jungang Bangmulgwan / 국립중앙박물관)（免费）→ 二村汉江散步。
  • 夜晚：周三·周六博物馆开到21点 → 汉江镇站 (Hangangjin / 한강진역) Leeum（开到18点，所以安排在白天）→ 梨泰院晚餐。

⚠ 常见失误5条

1. 周一去战争纪念馆·儿童庭园·Leeum·APMA——全部休馆。只有国立中央博物馆开放。

2. 去国立韩文博物馆——休馆至2028年下半年。

3. 从梨泰院站去Leeum——应走汉江镇站1号出口。

4. 相信“龙山公园开放”——只有儿童庭园开放，其余部分未定。

5. 在二村看烟花节——在汝矣岛。

⚙ FAQ 6

1. 免费玩一天？——战争纪念馆 → 龙山儿童庭园 → 国立中央博物馆，全部免费。

2. 晚上开放的地方？——国立中央博物馆周三·周六到21点，龙山儿童庭园周六到21点。

3. 带孩子去？——龙山儿童庭园（无需预约）·战争纪念馆室外展区。

4. 英语怎么办？——Leeum 有4种语言导览。两家国立馆官方未公布。

5. 二村站是哪条线？——4号线·京义中央线。

6. 梨泰院的追思空间在哪？——汉密尔顿酒店旁小巷，记忆与安全之路10·29。
