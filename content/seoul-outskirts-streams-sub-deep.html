서울 변두리 생태 하천 12선

1. 중랑천 (34.8km·서울 북동부 풀세트)

  • 차별: 34.8km·경기 양주 발원 → 한강 합류·서울 북동부 관통·자전거 종주 1순위
  • 외국인 fit: ★★★★ EN·JP MZ 매니아·자전거 #1

2. 중랑천 장안교 벚꽃길 (중랑 #1 spot)

  • 차별: 중랑천 벚꽃 최고 포인트·4월 초 절정·자전거 + 산책 풀세트·왕십리·뚝섬역 인근
  • 외국인 fit: ★★★★ EN·JP·CN MZ 매니아·SNS

3. 중랑천 자전거 종주 (한강 합류)

  • 차별: 중랑천 풀 자전거 코스·경기 양주 ~ 한강·3-4시간 종주·따릉이 OK
  • 외국인 fit: ★★★★ EN·JP MZ 매니아·#550 cross

4. 안양천 (32.5km·서남부 풀세트)

  • 차별: 32.5km·의왕 발원 → 한강 합류·서남부 (금천·구로·영등포) 관통·자전거길 풀세트
  • 외국인 fit: ★★★★ EN·JP·CN 매니아·서남 #1

5. 안양천 서울 최장 벚꽃 제방길

  • 차별: 서울 최장 벚꽃 제방길·서남부 1순위·자전거 + 벚꽃 풀세트·4월 초 절정
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아 1순위·SNS

6. 안양천 금천 사장교 (2019-2021)

  • 차별: 금천 비대칭 사장교 2019-2021·서남 야경 1순위·가산디지털단지역 (1·7호선)·SNS spot
  • 외국인 fit: ★★★★ EN·JP·CN MZ 매니아·야경 1순위

7. 도림천 (8km·관악 + 신림)

  • 차별: 약 8km·관악산 + 삼성산 발원 → 안양천 합류·관악·신림 cluster·스타라이트 테라스 2020 "별빛천"
  • 외국인 fit: ★★★★ EN·JP MZ 매니아·hidden gem

8. 도림천 스타라이트 테라스 + 버스킹

  • 차별: 2020 "별빛천" 재생·스타라이트 테라스 + 강변 버스킹·신원시장 먹거리 cluster·MZ 야경 매니아
  • 외국인 fit: ★★★★★ EN·JP·CN MZ 매니아 1순위·야경 + 버스킹 1순위

9. 우이천 빛초롱축제 (12월 ~ 1월)

  • 차별: 2025년 12월~2026년 1월 빛초롱축제·우이천 야간 조형물·도봉·강북 cluster
  • 외국인 fit: ★★★★ EN·JP·CN MZ·겨울 야경

10. 자전거 종주 풀세트 (중랑 + 안양 + 도림 풀)

  • 차별: 3 하천 자전거 풀 코스·중랑 + 한강 + 안양 + 도림 cluster·1일 100km 도전 매니아·따릉이 OK
  • 외국인 fit: ★★★★ EN·JP MZ 매니아 1순위·자전거 매니아 1순위

11. 도림천 신원시장 + 신림 cluster

  • 차별: 도림천 + 신원시장 + 신림 cluster·버스킹 + 먹거리 + 야경·로컬 라이프 매니아 1순위
  • 외국인 fit: ★★★★ EN·JP MZ 매니아·로컬 1순위

12. 변두리 생태 1일 cluster (1·2·7호선)

  • 차별: 중랑 (왕십리 2호선) + 안양 (가산 1·7호선) + 도림 (신림 2호선) 1일 cluster·로컬 라이프 + 자전거 + 야경
  • 외국인 fit: ★★★★ EN·JP·CN MZ 매니아·hidden 1순위

FAQ 6

Q1. 중랑천 자전거 시작? A. 왕십리역·뚝섬역 (2호선) 따릉이 시작·3-4시간 한강 합류 종주.

Q2. 안양천 벚꽃 + 사장교? A. 4월 초 벚꽃 + 가산디지털단지역 (1·7호선) 사장교 야경·서남 1순위 cluster.

Q3. 도림천 스타라이트? A. 2020 "별빛천" 재생·테라스 + 버스킹 + 야시장·신원시장 cluster 도보 5분.

Q4. 우이천 빛초롱? A. 2025년 12월~2026년 1월·우이천 야간 조형물·도봉·강북 cluster·#696 청계천 빛초롱과 차별 (#696 = 도심·#699 = 변두리).

Q5. 자전거 풀 종주? A. 중랑 + 한강 + 안양 + 도림 100km 풀 코스·1일 도전 매니아·따릉이 OK.

Q6. 외국인 hidden 매니아? A. 외국인 1순위 적은 cluster·로컬 라이프 + 자전거 + 버스킹·조용한 분위기.
