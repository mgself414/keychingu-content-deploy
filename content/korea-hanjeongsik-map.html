⚠ Hanjeongsik 실수 3가지

1. "한정식 = 일반 한식 코스" — 미슐랭급 미인지: 일반 가정. 실제로는 라연 미슐랭 3★·밍글스 3★·한식공간·온지음 + 한달 fine dining + 사찰음식 (선재 Netflix Chef's Table) — 한국 #1 미슐랭 cluster.

2. "한정식 = 서울만" — 전주·안동 노포 미인지: 서울만. 실제로는 전주 한정식 (#384 UNESCO 음식창의도시·풍년옥·다미·궁)·안동 헛제삿밥 (#397·UNESCO 하회 #456) 한국 #1 노포·전통 본거지.

3. "한정식 = 예약 불필요" — 예약 필수 미인지: 자유. 실제로는 라연·밍글스·한식공간·온지음 = 한 달 전 예약 필수 + 전주·안동 노포 (성수기 주말 예약 권장) + 외국인 영문 예약 가능.

🍯 외국인 5팁

1. 라연·밍글스 = 한 달 전 예약 — 영문 예약 가능·홈페이지·캐치테이블

2. 전주 = UNESCO 음식창의도시 — KTX 1.5h·한옥마을 한정식·1인 5~15만원

3. 안동 헛제삿밥 = 전통 제사 음식 — UNESCO 하회 + 안동소주 페어링

4. 사찰음식 = 외국인 영문 — 진관사·봉은사·해인사 (#463) + 선재 Chef's Table

5. 드레스 코드 — 라연·밍글스 = 스마트 캐주얼·그 외 깔끔한 평상복 OK
