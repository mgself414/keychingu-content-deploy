🎯 왜 BBQ 3채널 비교 가이드인가

외국인 한국 BBQ 페인포인트 = "어디서 먹어야 하나?". [#804 부위·등급](804_외국인_한국_BBQ_부위_등급_매트릭스_가이드.md) + [#805 워크플로우](805_외국인_한국_BBQ_테이블_워크플로우_가이드.md) 알아도 — 채널 선택이 다음 결정. 한국 BBQ 채널 = (1) 정육식당 (Butcher's Restaurant)·(2) BBQ 전문점 (BBQ Specialty)·(3) 시장 BBQ (광장·동대문·마장동) 3가지. 가격 25,000원 → 150,000원+, 분위기 가성비 → 럭셔리, 시스템 셀프 → 직원 굽기 차이. 본 가이드는 3채널 직접 비교 + segment(혼자·커플·가족·비즈니스·예산형)별 1순위 + 시간·예산·동행 기반 결정 매트릭스. 회 cluster #791 채널 비교 대응 BBQ 버전.

🥩 3채널 deep dive

🥩 정육식당 (Butcher's Restaurant)

핵심 가치: 1층 정육 매대 + 2층 식당, 직접 고기 등급·부위 선택. 가성비 ★★★★★ 가성비 한우.

  • 추천 매장 (서울):
  • 마장동 정육식당 cluster (성동구) — 한국 #1 축산물 시장, 한우 1++ 가성비
  • 의정부 정육식당 (의정부 평화로) — 한국 BBQ 매니아 1번지
  • 강남 마장동 cluster (강남구) — 강남 진출 매장
  • 시스템: 1층 매대에서 한우·한돈 부위·등급 선택 (kg/근 단위) → 2층/같은 건물 식당 이동 → 셀프 굽기
  • 가격 anchor (1인):
  • 한우 1+ 차돌박이 150g = 25,000~35,000원
  • 한우 1++ 꽃등심 150g = 50,000~70,000원
  • 한돈 삼겹살 200g = 15,000~22,000원
  • 상차림비 1인 5,000~10,000원
  • 외국인 친화도: ★★★ (영문 메뉴 거의 없음, 사진 메뉴·번역 앱 활용)
  • 결제: 매대 + 식당 = 분리 OR 일괄 (매장별 다름)
  • 장점: 가성비 ★★★★★, 등급·부위 직접 확인, 도매가 근접
  • 단점: 영어 거의 X, 셀프 굽기 (실패 risk), 시스템 복잡

🏮 BBQ 전문점 (BBQ Specialty Restaurant)

핵심 가치: 풀 서비스 + 정통 한국식 한 상 + 직원 굽기. 회식·접대 1순위.

  • 종류:
  • 한우 전문점: 한우 1++ 시그니처 (강남·청담·신라호텔) — 1인 150,000~300,000원
  • 양념갈비 전문점: 마포·태평로·종로 한우갈비집 — 1인 70,000~120,000원
  • 체인 BBQ: 새마을식당·하남돼지집·서가앤쿡 등 — 1인 30,000~60,000원
  • 추천 매장 (서울):
  • 강남·청담 한우집: 우래옥·새벽집·하남식당
  • 종로 정통 갈비집: 한일관·미진·역전회관
  • 신라호텔 한식당 라연 (La Yeon) — 럭셔리 1번지 (미슐랭 가이드)
  • 시스템: 풀 서비스 (직원 굽기 Type A 또는 반자동 Type C)
  • 가격 anchor (1인):
  • 체인 BBQ 30,000~60,000원
  • 한우갈비 정통 70,000~120,000원
  • 한우 1++ 전문점 150,000~300,000원
  • 외국인 친화도: ★★★★★ — 영문 메뉴·영어 응대·관광지 가까움
  • 결제: 카드 OK·카운터 또는 테이블 1회 (호텔 한식당 부가세 10% + 봉사료 10% 별도)
  • 예약: 정통·한우 전문점 = 1~2주 전 필수 (캐치테이블·네이버 예약)
  • 장점: 풀 서비스·영어 응대·격식·접대 적합
  • 단점: 비쌈·예약 어려움

🛒 시장 BBQ (Market BBQ)

핵심 가치: 가성비 ★★★★ + 시장 분위기 + 외국인 vlog ★. 광장시장 마약김밥 (Mayak Gimbap, "addictive" 별명, 정부 권고로 영문 표기 중립화 추세) 옆 갈매기살 골목 = 외국인 인스타 1번지.

  • 추천 시장 (서울):
  • 광장시장 (Gwangjang Market, 종로) — 마약김밥 + 갈매기살·곱창·돼지껍데기 골목, 외국인 매니아 #1
  • 동대문 BBQ 거리 (Dongdaemun BBQ Street) — 심야 운영 매장 多 (24h는 일부 매장 한정), 외국인 동대문 쇼핑 후 1순위
  • 마장동 축산물 시장 (성동구) — 한국 #1 축산 시장, 정육식당과 통합 cluster
  • 공덕 시장 (Gongdeok Market, 마포) — 전·돼지껍데기·갈매기살 매니아
  • 시스템: 시장 매대 walk-in → 즉석 셀프 굽기 → 매대 카운터 결제
  • 가격 anchor (1인):
  • 갈매기살 200g 15,000원~
  • 곱창 1인분 12,000~18,000원
  • 돼지껍데기 1인분 10,000~15,000원
  • 술 (소주·맥주) 4,000~6,000원
  • 외국인 친화도: 광장시장 ★★★★★ (영문 메뉴·관광 통역) / 동대문 ★★★★ / 마장동 ★★★ / 공덕 ★★★
  • 결제: 매대 1회 (현금·카드 혼용, 작은 매대 현금 권장)
  • 예약: walk-in 기본 (광장은 주말 30분~1h 대기)
  • 장점: 가성비·분위기·외국인 vlog ★
  • 단점: 위생 편차·좌석 좁음·환기 약함

⚠ 외국인 자주 실수 5가지

1. "정육식당 = BBQ 전문점": 시스템 완전 다름. 정육식당 = 매대+셀프 / 전문점 = 풀 서비스. 가격·분위기 모두 차이.

2. "한우 = BBQ 전문점만": 정육식당도 한우 1++ 판매. 동일 등급·동일 부위 기준, 정육식당이 도매가 근접 → 일반 전문점 대비 체감 30~40% 가성비 (매장·시즌별 편차 있음).

3. "시장 BBQ = 위생 X": 광장시장·동대문 = 관광지 매장 = 정기 보건 점검 대상. 단 매대별 편차 가능 — 회전율·청결도 직접 확인 권장.

4. "강남·청담 = 무조건 비쌈": 강남에도 정육식당 cluster (1인 35,000원~) 있음. 검색 시 "정육식당 강남" 키워드.

5. "예약 = 다 같은 어려움": 정육식당 = walk-in OK / 한우 전문점 = 1~2주 전 / 시장 = walk-in (광장은 대기).

⚙ FAQ 8개

1. 첫 BBQ = 어디?: BBQ 전문점 풀 서비스 1순위 (영어·직원 굽기). 익숙해지면 정육식당.

2. 한우 1++ 가성비: 정육식당 마장동 (도매가 근접, 동일 등급·부위 기준 일반 전문점 대비 체감 30~40% 가성비 — 매장·시즌별 편차).

3. 인스타·사진: 광장시장 갈매기살 골목 (외국인 vlog 1번지).

4. 회식·접대: BBQ 전문점 강남·청담 한우집. 신라호텔 한식당 = 최상위.

5. 혼자 BBQ: 시장 BBQ (광장) 1인 walk-in OK. 정육식당 일부 1인 OK / 전문점 lunch만 OK.

6. 알레르기·임신 의료: [#804 disclaimer](804_외국인_한국_BBQ_부위_등급_매트릭스_가이드.md) 참조. 시장 BBQ = 환기·좁음 → 임신부 주의.

7. 결제·팁: 카드 OK / 팁 X / 호텔 한식당 봉사료 10% + 부가세 10%.

8. VAT 환급: 식음료 일반 환급 대상 아님.

⚠ 의료·안전·식이 disclaimer

BBQ 3채널 모두 직접 조리 = 화상 위험·돼지/닭 well-done 필수. 시장 BBQ = 환기 약함, 옷·머리 냄새 + 임신부·천식 환자 주의. 광장시장 = 식중독 의심 시 ☎ 1339 (의료, 영문) + ☎ 1330 (관광 통역). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일반 한국 BBQ 매장 = 할랄·코셔 인증 미보유. → 이태원·강남 일부 인증 매장 사전 검색·예약 (Eid·Makan·Halal Korean BBQ).
  • 채식·비건: 3채널 모두 육류 중심. → [#799 채식·비건 매트릭스](799_외국인_한국_채식_비건_매트릭스_12선_deep_dive.md) 참조 OR 다른 매장 분리.
  • 이슬람·유대·힌두: 종교적 식이 = 사전 매장 확인.
