首尔古着·二手购物9家 — 从千元衣服堆到汉南洞展厅

副标题: 东庙跳蚤市场和新设洞的首尔风物市场，卖捐赠物品的两家公益二手店，弘大·上水·望远的三家古着店，再到梨泰院·汉南的两家。只选了在Kakao地图上显示营业中、并且2026年下半年有到访评价的9家，分成3个区域。每个区域都排成半天的路线。

ISSUE 06 · #772 · 2026-11-24 · 首尔古着购物

🎯 适合谁，为什么是这9家

这份清单是为喜欢翻旧衣服和老物件的游客准备的。首尔的二手购物大致有三条路。在东大门一带的市场，翻衣服堆、逛摊位。在美丽商店 (Beautiful Store / 아름다운가게)·善意商店 (Goodwill Store / 굿윌스토어)这类公益二手店，便宜买捐赠物品。在弘大 (Hongdae / 홍대)·望远 (Mangwon / 망원)·汉南 (Hannam / 한남)的古着店，买店主挑选并整理过的衣服。这一篇三条路都收进来了。

选择标准有两个。Kakao地图 (Kakao Map / 카카오맵)的店铺信息必须是"营业中"，并且2026年下半年有博客评价或Kakao地图的评论·照片。最近的动态停在2024~2025年的店，和带有争议评论的店都排除了。

⚠ 标注原则: 营业时间·休息日是Kakao地图上登记的值(2026-11-24确认)。衣服价格Kakao地图上没有登记，所以把博客评价·Kakao地图评论里写的实际购买价连同日期一起抄了下来。那是一个人买的价格，同一件东西换一天价格可能不同。附近的站和出口是Kakao地图导航的值。没能确认是否可以刷卡，所以摊位和小店请备好现金。

① 东大门·钟路 — 3家

两个市场离东庙前站和新设洞站都近，适合一天串起来。美丽商店安国店在北村入口，很容易塞进仁寺洞·北村的行程。

  • 东庙跳蚤市场 (Dongmyo Flea Market / 동묘벼룩시장) — 东庙前站 (Dongmyo-ap / 동묘앞역)3号出口前的小巷里，摊位和古着店聚在一起的街。有在地上堆着的衣服里翻找的地方，也有把衣服挂在衣架上卖的店。价格来自评价，是2026-10末到访时的值。2026-11-17的博客评价写道，堆放的T恤1千~5千韩元，挂在衣架上的衣服1万韩元左右。作者还补充说各店差别很大。Kakao地图上登记为每天10:00~18:00。同一篇评价写道没有官方营业时间，每家店·每个摊位都不一样。地址是钟路区 (Sungin-dong 102-8 / 숭인동 102-8)一带，最近的站是东庙前站 (Dongmyo-ap / 동묘앞역)(1·6号线)3号出口，步行1分钟。这篇评价写道，10月末的一个周六中午人多得超出想象，停车位少，开车去很麻烦。
  • 首尔风物市场 (Seoul Pungmul Market / 서울풍물시장) — 新设洞的室内跳蚤市场。建筑按颜色分成各栋(红·橙·黄·绿·蓝·靛·紫)和青春1号街 (Cheongchun 1-beon-ga / 청춘1번가)(官方网站，2026-11-24)。卖古董·生活用品·碗盘·古着。市场官方博客在2026-11-16的文章里单独介绍了古着专区。2026-10-11的博客评价里写着碗盘大部分1千韩元，玻璃杯约3千韩元。杯子的价格是推测值。Kakao地图的时间是周三至周一10:00~19:00，周二休息。官方博客(2026-11-02)也通知每周二休息。地址是东大门区 (Cheonho-daero 4-gil 21 / 천호대로4길 21)，最近的站是新设洞站 (Sinseol-dong / 신설동역)(1·2号线·牛耳新设线)9号出口，步行4分钟。在室内，适合下雨天去。
  • 美丽商店安国店 (Beautiful Store Anguk / 아름다운가게 안국점) — 卖受捐赠的衣服·包·书·碗盘的公益二手店。2026-06-02的评价里有白色素色T恤₩6,000，包₩15,000~20,000。2026-09-25的评价里有针织衫₩6,000，书₩1,000~3,000，5本笔记本₩1,000。并不是所有东西都便宜。2026-09-30的Kakao地图评论抱怨说，一件二手毛衣标价10万韩元。时间是周一至周五10:30~20:00，周六·周日·公共假日10:30~18:00。春节(设日)·中秋连休的三天和劳动节休息。地址是钟路区 (Bukchon-ro 21 / 북촌로 21)1层，最近的站是安国站 (Anguk / 안국역)(3号线)2号出口，步行5分钟。

② 弘大·上水·望远 — 4家

弘大入口站的一家大型店，上水站前的一家2层店，望远站一带的两家。古着店 (Root Hongdae / 루트 홍대)开到24:00，适合晚上去。古着店 (Terrace Wear / 테라스웨어)周一休息，善意商店麻浦店 (Goodwill Store Mapo / 굿윌스토어 마포점)周日休息。

  • 古着店 (Root Hongdae / 루트 홍대) — 在弘大入口站 (Hongik Univ. / 홍대입구역)前地下的大型古着服装店。2026-10-20的博客评价介绍说店面有250坪。同一篇评价里有买3送1活动、军装夹克₩19,000、夹克1万~15万韩元区间。活动随时会变。每天10:00~24:00营业。地址是麻浦区 (Yanghwa-ro 140 / 양화로 140)地下1层，最近的站是弘大入口站 (Hongik Univ. / 홍대입구역)(2号线·机场铁路·京义中央线)9号出口，步行3分钟。2026-11-15的一篇博客文章标题是"外国人也常去的Root Hongdae"。男装和女装混着挂，标签和尺码要自己看。
  • 古着店 (Vintage Shop Page One / 빈티지샵 페이지원) — 就在上水站 (Sangsu / 상수역)前，用1·2层的古着店。除了衣服还卖配饰·帽子·小物·碗盘。2026-11-04的博客评价里有一个衬衫每件₩3,000的专区。每个星期几时间不同。周二至周四12:30~20:50，周五至周日13:00~20:50，周一13:00~19:55。博客也写道时间经常变。地址是麻浦区 (Dongmak-ro 75 / 독막로 75)1~2层，最近的站是上水站 (Sangsu / 상수역)(6号线)1号出口，步行2分钟。
  • 古着店 (Terrace Wear / 테라스웨어) — 通往望远市场 (Mangwon Market / 망원시장)的小巷入口处的古着店。2026-10-28的博客评价把法式工装夹克选为代表商品。另一篇评价(2026-06-04)说有很多Levi's牛仔裤。价格并不都便宜。2026-08-21的Kakao地图评论写道有超过10万韩元的衣服。时间是周二至周日12:30~20:00，周一休息。地址是麻浦区 (Worldcup-ro 19-gil 25 / 월드컵로19길 25)1层，最近的站是望远站 (Mangwon / 망원역)(6号线)2号出口，步行4分钟。
  • 善意商店麻浦店 (Goodwill Store Mapo / 굿윌스토어 마포점) — 卖受捐赠的衣服·书·生活用品的公益二手店。2026-07-12的博客评价里有一本书₩2,000。2026-05的Kakao地图评论也写道淘到了很多书。很多评价说比起衣服，书和杂货更强。时间是周一至周六10:00~19:00，周日休息。地址是麻浦区 (Worldcup-ro 94 / 월드컵로 94)明大厦 (Myeong Building / 명빌딩)1层，最近的站是望远站 (Mangwon / 망원역)(6号线)1号出口，步行3分钟。

③ 梨泰院·汉南 — 2家

两家都是只挂店主挑选的衣服的小店。古着店 (Plastic Banana / 플라스틱바나나)13:00开门，周一休息。

  • 古着店 (Plastic Banana / 플라스틱바나나) — 绿莎坪站 (Noksapyeong / 녹사평역)和梨泰院之间小巷里的古着店。2026-11-02的Kakao地图评论(英文)把皮革·牛仔·羊毛男士夹克，厚羊毛·法兰绒衬衫，美国尺码牛仔裤列为优点。Kakao地图和最近的评价里都没有确认到价格(2026-11-24)。时间是周二至周日13:00~21:00，周一休息。地址是龙山区 (Noksapyeong-daero 40-gil 41 / 녹사평대로40길 41)1层，最近的站是绿莎坪站 (Noksapyeong / 녹사평역)(6号线)3号出口，步行6分钟。
  • 古着店 (Vintage Shop Of Heart / 빈티지샵 오브하트) — 汉南洞 (Hannam-dong / 한남동)梨泰院路 (Itaewon-ro / 이태원로)上2·3层的展厅。2026-11-03的博客评价里有粗花呢夹克、名牌领带、古董手表、羊毛外套。2025-03的评论写道，衣服全部干洗后再挂出来，所以没有异味。2025-08-27的评论写道，粗花呢偏贵，但面料有瑕疵的也有2~3万韩元的。每天10:00~20:00营业。地址是龙山区 (Itaewon-ro 212 / 이태원로 212)2·3层，最近的站是梨泰院站 (Itaewon / 이태원역)(6号线)3号出口，步行6分钟。

🗺 动线 — 两条半日路线

每个区域的街区相距较远，所以一天只排一两个区域。店与店之间的路，当天用Kakao地图导航确认。

A. 东庙·风物市场·安国 (周二除外)

  1. 上午 东庙跳蚤市场 (Dongmyo Flea Market / 동묘벼룩시장)(Kakao地图10:00起)
  2. 午饭前 新设洞的首尔风物市场 (Seoul Pungmul Market / 서울풍물시장)。从东庙前站坐1号线一站
  3. 下午 安国站的美丽商店安国店 (Beautiful Store Anguk / 아름다운가게 안국점)(周一至周五到20:00，周六·周日到18:00)。和北村·仁寺洞的游览串在一起

周二风物市场休息。如果是周二，去掉第2站，从东庙直接去安国。

B. 上水·弘大·望远 (推荐周二至周六)

  1. 白天 上水站的古着店 (Vintage Shop Page One / 빈티지샵 페이지원)(周二至周四12:30起，周五至周日13:00起)
  2. 下午 望远站一带的古着店 (Terrace Wear / 테라스웨어)(周一休息)和善意商店麻浦店 (Goodwill Store Mapo / 굿윌스토어 마포점)(周日休息)
  3. 晚上 弘大入口站的古着店 (Root Hongdae / 루트 홍대)(到24:00)

周一Terrace Wear休息，周日Goodwill Store休息。想两家都逛的话，周二至周六去。梨泰院·汉南的两家要另外留半天，傍晚串起来。古着店 (Plastic Banana / 플라스틱바나나)13:00开门。

⚠ 3个常见失误

  1. 周二去风物市场，周一去望远·梨泰院 — 首尔风物市场周二休息，Terrace Wear和Plastic Banana周一休息，善意商店麻浦店周日休息。先把星期几对上。
  2. 只找价签，结果空手出来 — 有评价说东庙每家店·每个摊位价格不同。拿着挑好的东西去问价。
  3. 不试穿就买 — 古着同一件只有一件，也混着国外的尺码标注。结账前先问能不能试穿，能不能换货·退款。

⚙ 3个常见问题

  1. 第一次来只去一家的话？ — 想便宜多翻，选东庙跳蚤市场 (Dongmyo Flea Market / 동묘벼룩시장)；下雨天，或者想连碗盘·古董一起看，选首尔风物市场 (Seoul Pungmul Market / 서울풍물시장)(周二休息)；想舒服地试穿挑好的衣服，选古着店 (Root Hongdae / 루트 홍대)(每天到24:00)。
  2. 晚上能去的店有哪些？ — 按登记时间，古着店 (Root Hongdae / 루트 홍대)到24:00，古着店 (Plastic Banana / 플라스틱바나나)到21:00，古着店 (Vintage Shop Page One / 빈티지샵 페이지원)到20:50(周一19:55)，美丽商店安国店 (Beautiful Store Anguk / 아름다운가게 안국점)工作日到20:00。
  3. 衣服之外能当纪念品的东西？ — 首尔风物市场的碗盘·杯子(评价里1千~3千韩元)，美丽商店·善意商店的书，Page One的小物·碗盘。想要全新的工艺品，请看传统纪念品篇#774。
