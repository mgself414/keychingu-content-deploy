サブタイトル: 公州のベーカリー栗村 (ベーカリーパンマウル / 베이커리 밤마을) 09:00~21:00・年中無休(VisitKorea) · 城北洞の寿然山房 (スヨンサンバン / 수연산방) かぼちゃかき氷、月・火休み(VisitKorea) · 永同のカフェ海影 (カフェヘヨン / 카페 해영) 干し柿スイーツ(VisitKorea) · 海南さつまいもパン フィナンシェ (ヘナムゴグマパン ピナンシェ / 해남고구마빵 피낭시에) 小麦粉の代わりにさつまいもと米(VisitKorea) · 干し柿祭りの過去の回は12~2月 — 2026-10-21時点

🎯 このガイドの使い方

紙袋を開けると焼き芋の香りがふわっと立ちのぼり、手にしたパンは本物のさつまいものようにずっしり重い — 海南さつまいもパン (ヘナムゴグマパン / 해남고구마빵) はさつまいもの形をそのまま写しています(VisitKorea)。このガイドは栗・柿(熟柿の「ホンシ (홍시)」と干し柿の「コッカム (곶감)」)・かぼちゃ・さつまいもで作ったスイーツを出すお店を紹介します。グループごとに、ソウルで食べられる店を先に、産地(公州・永同・清道・尚州・海南)を後に並べました。お店はすべて韓国観光公社の観光情報(VisitKorea、TourAPI)にその食材のメニューが登録されている所です。

ここに載せたメニューはVisitKoreaのメニュー欄に載っている定番メニューで、「秋限定」の表示はありません。旧ガイドにあったチェーン店・ホテルの秋限定スイーツは、2026年の公式告知を確認できなかったため外し、順位の表現も根拠がないので削りました。冬の路上の焼き芋は #476 冬のおやつガイド、餅は #473 韓国餅ガイド に分けました。

🌰 栗 — ソウル2店・公州2店

  • レイジーユース (레이지 유스) — ソウル特別市城東区 舞鶴路6街 (ムハンノ6キル / 무학로6길) 22 1階(道仙洞 (ドソンドン / 도선동))。12:00~24:00(ラストオーダー23:10)、年中無休。看板メニューの栗のバスクチーズケーキは、でんぷんも小麦粉も使わずに作ります。テイクアウト可。電話 02-6470-7770(VisitKorea)
  • カフェミウ (카페미우) — ソウル特別市龍山区 新倉路14街 (セチャンノ14キル / 새창로14길) 7 1階(孝昌公園駅 (ヒョチャンゴンウォンヨク / 효창공원역) 方面)。平日09:00~19:00、週末11:00~21:00、月曜休み。ハンドドリップ専門のカフェで、栗の甘露煮を出します。電話 02-813-0315(VisitKorea)
  • ベーカリー栗村 (베이커리 밤마을) — 忠清南道公州市 白米村路 (ペンミゴウルギル / 백미고을길) 5-9(錦城洞 (クムソンドン / 금성동))。09:00~21:00、年中無休。公州特産の栗で作る栗村パイが看板で、栗のエクレア・栗クリームチーズタルト・栗のマドレーヌもあります。箱詰め販売、カード可、無料駐車場。公山城 (コンサンソン / 공산성) の近くです。電話 041-853-3489(VisitKorea)
  • ローカルコーヒー (로컬커피) — 忠清南道公州市 龍堂路 (ヨンダンギル / 용당길) 55-7(校洞 (ギョドン / 교동))。登録値には月~土12:00~21:00、日12:00~18:00と「毎週月曜休み」が併記されています — 月曜は電話で確認してください。1943年に建てた古い家を生かしたカフェで、看板メニューは栗ラテです。電話 0507-1331-4707(VisitKorea)

🍊 柿(ホンシ・コッカム) — ソウル1店・産地3店

  • ソウル (소울) — ソウル特別市鍾路区 紫霞門路 (チャハムンノ / 자하문로) 50(彰義洞 (チャンウィドン / 창성동))。11:30~21:00(ラストオーダー20:30)、火・水休み。米粉で作る米スイーツの専門店です。干し柿巻き (コッカムマリ / 곶감말이) があり、あんクリームの蒸しもち (ソルギ / 설기)・開城風の揚げ餅菓子 (ケソンチュアク / 개성주악)・ふわふわ米ケーキも出します。電話 0507-1318-5194(VisitKorea)
  • カフェ海影 (카페 해영) — 忠清北道永同郡 楊江面 外万1街 (ウェマン1キル / 외만1길) 34-4。11:00~18:00(ラストオーダー17:30)、火・水休み(祝日は営業)。田舎の家を直した韓屋 (ハノク / 한옥) カフェで、自家製の永同の干し柿から干し柿ピューレと干し柿ジャムを作ります。永同干し柿ラテ・チーズ干し柿壺・干し柿ジャムバタークロッフルが看板で、干し柿ジャムとチーズ干し柿壺は単品でも買えます。電話 043-744-4888(VisitKorea)
  • 徳山紡織 (덕산방직) — 慶尚北道清道郡 梅田面 徳山1街 (トクサン1キル / 덕산1길) 6-12。平日10:30~19:00、週末10:30~20:00(ラストオーダーはそれぞれ30分前)、年中無休。1990年代の紡織工場を直したカフェで、清道特産の熟柿で作る熟柿ラテと熟柿スムージーを出します。電話 0507-1347-0618(VisitKorea)
  • 尚州干し柿流通センター 尚州干し柿直売所 (상주곶감유통센터 상주곶감직판장) — 慶尚北道尚州市 嶺南第一路 (ヨンナムジェイルロ / 영남제일로) 1154。08:00~19:00、年中無休。2005年に尚州の干し柿農家600軒余りが出資して作った営農組合です。干し柿・干し柿スライスと、干し柿もち米餅・干し柿飴・干し柿ヤッカ (ヤックァ / 약과)・柿酢を売っています。電話 054-536-0907(VisitKorea)

🎃 かぼちゃ — ソウル3店

  • 寿然山房 (수연산방) — ソウル特別市城北区 城北路26街 (ソンブンノ26キル / 성북로26길) 8(城北洞 (ソンブクトン / 성북동))。水~金11:30~17:50(ラストオーダー17:00)、土11:30~20:00(ラストオーダー19:10)、日11:30~19:50(ラストオーダー19:00)、月・火休み。ソウル市民俗文化遺産「尚虚 李泰俊の家」で、李泰俊の孫娘が営む伝統茶屋です。看板メニューはかぼちゃかき氷で、かぼちゃのポンボク (범벅、かぼちゃを煮てつぶしたもの) もあります。電話 02-764-1736(VisitKorea)。城北洞の路地の歩き方は #1345 路地さんぽ⑥ 城北洞
  • マグパイ&タイガー聖水ティールーム (맥파이앤타이거 성수티룸) — ソウル特別市城東区 聖水二路 (ソンスイロ / 성수이로) 97。11:00~21:30、年中無休。お茶とスイーツを出すティールームで、メニューにかぼちゃパウンドケーキがあります。電話 0507-1306-1629(VisitKorea)
  • ミルパニ (밀파니) — ソウル特別市松坡区 慰礼西路 (ウィレソロ / 위례서로) 273(巨余洞 (コヨドン / 거여동))。09:00~21:30、年中無休。ベーカリーカフェで、メニューにかぼちゃ餅パンがあり、さつまいもの形のさつまいもパンが看板として紹介されています。電話 0507-1480-0824(VisitKorea)

🍠 さつまいも — ソウル2店・海南2店

  • ニードスイート (니드스윗) — ソウル特別市城東区 峨嵯山路1街 (アチャサンノ1キル / 아차산로1길) 9(纛島駅 (トゥクソムヨク / 뚝섬역) 1番出口方面)。12:00~22:00、年中無休。すべてのメニューを自家製で作るケーキカフェで、リアルさつまいもチーズケーキがあります。予約・テイクアウト可。電話 0507-1467-7864(VisitKorea)
  • プラッドカフェ ソウルの森 (플래드카페 서울숲) — ソウル特別市城東区 ソウルの森2街 (ソウルスプ2キル / 서울숲2길) 12-7。毎日11:00~21:00。メニューにさつまいもティラミスがあります。テイクアウト可。電話 0507-1356-8511(VisitKorea)
  • 海南さつまいもパン フィナンシェ (해남고구마빵 피낭시에) — 全羅南道海南郡 邑内路 (ウンネギル / 읍내길) 8。09:30~20:00、海南さつまいもパンが売り切れたら早く閉まります。旧正月 (ソル / 설) と秋夕 (チュソク / 추석) の当日は休み。さつまいもの形の海南さつまいもパンは、小麦粉の代わりに海南産のさつまいもと海南産の米で作ります。さつまいもタルト・蜂蜜さつまいもフィナンシェもあります。当日生産なので、買ったら冷蔵・冷凍保存をすすめます。駐車不可。電話 0507-1393-6262(VisitKorea)
  • モンソベーカリー さつまいもパン (몽소베이커리 고구마빵) — 全羅南道海南郡 海南邑 南部循環路 (ナムブスヌァンノ / 남부순환로) 5 チョンハメディカルセンター102号。07:30~22:00、日曜休み。天然発酵種のパン屋で、海南産さつまいものあんを入れたもちもちさつまいもパンとさつまいものブリオッシュを出します。店の前に駐車場があり、宅配注文もできます。電話 061-533-0085(VisitKorea)

🥗 食事制限

  • 価格帯: 15店とも、VisitKoreaの登録値に価格がありません。価格は未掲載 — 電話か店のメニュー表で確認してください
  • グルテン: 小麦粉の代わりに別の材料を使うと紹介されているのは、レイジーユースの栗のバスクチーズケーキ(でんぷん・小麦粉なし)、ソウル(米粉)、海南さつまいもパン フィナンシェのさつまいもパン(さつまいもと米)です(VisitKorea)。同じ店の別メニューには小麦が入っていることがあります
  • ベジタリアン: チーズケーキ・ティラミス・クロッフルは乳製品、パイやタルトはバターと卵が入るのが普通です — ヴィーガンの方は注文前に聞いてください
  • アルコール: 尚州干し柿直売所で売っている干し柿マッコリ (コッカムマッコリ / 곶감막걸리) はお酒です(VisitKorea)
  • ハラール: VisitSeoulは、梨泰院のイード (Eid / 이드)(龍山区 ウサダンノ10キル (우사단로10길) 15、毎日12:00~21:00)を、韓国イスラム教中央会(KMF)がハラールと認めた数少ない飲食店として紹介しています。認証は変わることがあるので、訪問前に確認してください。このガイドのお店にはハラール表示がありません
  • 見せるカードは #1300 食事リクエストマニュアル

🧰 秋スイーツの実務 — ひとり、予約、支払い、注文、移動

  • ひとり: ケーキ1切れやパンは1人前単位なので、ひとりでも気軽です。ひとりで行ける場所の地図は #348 Seoul Solo Diner Map
  • 予約: 予約可が登録されているのはニードスイート(VisitKorea)。ほかはそのまま行きます。フィナンシェ店のさつまいもパンは売り切れると閉まるので、午前中に行きます
  • 支払い: カード可が登録されているのはベーカリー栗村(VisitKorea)。カード・スマホ決済は #527 韓国の決済システム
  • 注文: カフェではレジで注文して呼び出しベルを受け取る店が多いです — #1288 カフェ呼び出しベルマニュアル。言葉が通じないときは #1339 注文エチケット
  • 移動: ソウルは #1298 交通カード3種の選び方。公州・永同・清道・尚州・海南は #1297 高速・市外バスマニュアル・#1287 KTX初めて乗る

⚠ よくある間違い4つ

1. 「干し柿祭りは秋に開かれる」 — VisitKoreaの祭り情報にある過去の回は、論山陽村干し柿祭り2025-12-12~14、咸安干し柿祭り2026-01-23~25、永同干し柿祭り2026-01-30~02-01です。2026~27年の回の日程はまだ掲載されていません — シーズンのお知らせを確認してください

2. 「栗スイーツは公州まで行かないと食べられない」 — ソウルにも栗のメニューが登録された店があります(レイジーユース・カフェミウ、VisitKorea)

3. 「田舎のカフェは毎日開いている」 — カフェ海影は火・水、モンソベーカリーは日曜が休みです。ソウルのソウル(火・水)・寿然山房(月・火)も平日に休みます(VisitKorea)

4. 「去年の秋限定メニューが今年も出る」 — チェーン店やカフェの2026年秋限定メニューの公式告知は、この版では確認できませんでした。行く前に店のお知らせを見てください
