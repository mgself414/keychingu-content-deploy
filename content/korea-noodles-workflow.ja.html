韓国の麺の注文・食べるワークフロー

サブ: 外国人観光客向け5-stepワークフロー+種類別調味・高命・はさみ・ペアリング・決済のヒント

ISSUE 03・#814・2026-06-07

🎯 なぜ韓国の綿流ワークフローガイドなのか

#813麺類6種マトリックス 知っていても — ご注文・食べる過程は別個。韓国麺類は(a) ジャジャンミョン=ダンムジ+タマネギ+春張必須 (b) 冷麺=ハサミ 韓国式マナー(c) カルグクス=キムチ・多大機加減(d) ラーメン=沸騰する店舗違い(e) チャンポン=辛味加減。外国人は（1）ジャジャンミョンダンムジ・タマネギ無料知らないし（2）冷麺はさみしないで丸ごと食べる試み本ガイドは5-step+種類別調味・ペアリング+英語発火。

★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣桁+注文 入場＋メニュー選択（1～3種） 2〜5分 チャジャン+チャンポンフェア=韓国クラシック
2️⃣を入手+スパイス設定 麺類＋ダンムジ・玉ねぎ・キムチ・多大機即時 ダンムジ・玉ねぎ＝無料無制限（チャジャン面）
3️⃣はさみ（冷麺・カルグクス） はさみで綿を切る30秒 冷麺=はさみ必須マナー（テーブルはさみ提供）
4️⃣調味料加減+食べる
5️⃣決済 カウンターまたはテーブル+レシート 1～3分韓国中華レストラン=カードOK多/老舗=現金推奨

総所要時間（1人基準）：20～30分（チャジャン麺・ラーメン・ごちそう）／30～45分（冷麺・カルグクス）

🍜 麺類種類別味付け・有名マトリックス

🥢 ジャジャンミョン — ダンムジ・玉ねぎ・春張

1. ダンムジー (Yellow pickled radish): 基本提供無料・無制限

2. 玉ねぎ (Onion): 基本提供・春場に撮って食べる

3. 春長 (Black bean paste dipping): 玉ねぎ・ダンムジディップ用

4. 多待機 (Spicy paste): スパイシーな加減 (選択)

5. キムチ: 一部店舗提供

外国人の中核: チャジャンミョン = 玉ねぎを春場に撮って食べる + ダンムジ口。ただ麺だけ食べないでください。

🌶ちゃんぽん - スパイシーな加減

1. コチョウガル: より辛味（味）

2. 多待機: スパイシー追加

3. 酢: 一部店舗（シーフード新鮮度↑）

4. キムチ: 口元

🧊 冷麺 — はさみ+味付け

はさみマナー（韓国式必須）：

1. ボウルを受けた直後 テーブルハサミ（ほとんどの店舗提供）またはスタッフがハサミ

2.綿を3～4等分（食べやすいサイズ）

3. 綿のまま丸ごと食べない（韓国式マナー）

平壌冷麺:

  • 酢 1～2 dip
  • マスタード (Mustard) 1ティースプーン
  • 味付けほとんどなくさっぱり

咸興冷麺：

  • スパイス追加（マコム）
  • ごま油 1ティースプーン
  • 酢・マスタード加減

🔪 カルグクス — キムチ・多待機

1. キムチのそば

2. みじん切り調味料（多待機）加減スパイシー追加

3. シソ粉（シソのカルグクス）たっぷり

4. エビ箸 (シーフードカルグクス) 1ティースプーン

🍜 ラーメン — トッピング

1. 卵 (Egg): 基本的なトッピング

2. チーズ (Cheese): スパイシーな落ち着き

3. 餃子・餅 (Mandu・Tteok): 分食店

4. キムチのそば

🎉ごちそう - 軽さ

1. キムチのそば

2. コチョウガル加減

3. キム粉トッピング

🤝韓国クラシックペアリング

🥢 チャジャンミョン + チャンポン = ** チャムジャンミョン

  • チャジャンミョン+チャンポン=韓国中華#1クラシックコンボ
  • 1つのボウルに半分 = 塩辛い場合 (1人用)
  • 価格：9,000〜14,000ウォン

🍜キンバップ+ラーメン

  • 韓国の分食#1コンボ（5,000〜10,000ウォン）
  • ラーメンスープにキンバップを軽く湿らせて

🧊冷麺+餃子

  • 平壌式老舗（ウレオク・ピルドンミョンオク）標準ペア
  • 価格：25,000〜35,000ウォン（1人）

🔪 カルグクス+餃子

  • 明洞餃子シグネチャー
  • カルグクス+グンマンドゥ=クラシック

🌶辛い段階（ラーメン・チャンポン）

1. 中辛く: ジャジャン麺・ごちそう麺・刀麺・平壌冷麺

2. 軽くスパム: 一般ラーメン・白ちゃんぽん

3. 中-辛さ: 新ラーメン・一般チャンポン

4. スパイム:スパイシーなチャンポン・唐辛子チャンポン・咸興冷麺ビビン

5. 非常にスパイシー: 焼き炒め麺（グローバルチャレンジ）

外国人英語発話サンプル

  • "私をマップしないでください" = "Less spicy, please"
  • "はさみをください" = "Scissors, please"
  • "もっと無駄にしてください" = "More pickled radish, please"
  • "玉ねぎをもっとください" = "More onion, please"
  • "これは辛いですか？" = "Is this spicy?"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁なミス7つ

1. "冷麺=丸ごと食べる": 韓国式= はさみ必須。麺を3～4等分後に食べる。丸ごと=ぎこちない。

2. "チャジャン綿=綿だけ": タマネギ+春のディップ+ダンム紙=必須ペア。無料無制限。

3. 「平壌冷麺＝酢・マスタードを入れない」：平壌食道酢1～2ディップ・マスタード1ティースプーン＝正統マナー。

4. 「焼きたての麺＝普通のラーメン」: とても辛いグローバルチャレンジ。牛乳・チーズの準備。

5. "チャジャン面+チャンポン別にさせる": チャンチャミョン（半分） =韓国中華#1コスパオプション。

6. 「平壌冷麺＝どう食べる？」：はさみ→酢・マスタード→淡白に（味付けX）。咸興はスパイシーに。

7. 「ダンピング= 1回」：無料無制限の詰め替え。 「ちょっと無駄にしてください」リクエスト。

⚙ よくある質問8件

1. 最初の麺類=どこ: 韓国の中華レストラン(チャジャンミョン) 1ランク。ちゃんとしたら＝チャジャン＋ちゃんぽんコスパ。

2. 老舗平壌冷麺: ウレオク(1946 平壌創業) / 筆洞面玉/乙密隊 — 外国人 vlog ★。

3. 夏1順位: 平壌冷麺(淡白) or 咸興冷麺(マコム)。釜山＝小綿（咸興冷麺変形）。

4. 火鶏チャレンジ: 牛乳・チーズ・三角キンバプ準備。とてもとてもミルクで落ち着いて。

5. はさみマナー: 冷麺=必須。カルグクス＝選択。ジャジャンミョン・ラーメン＝しない。

6. アレルギー・妊娠: #813 disclaimer参照。そば（buckwheat）アレルギー＝平壌冷麺注意。

7. 決済・チップ:韓国中華=カードOK/老舗一部現金/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

麺類＝90〜100℃の熱いスープ（冷麺を除く）。やけど注意。 火鶏炒め麺＝とても辛い、外国人の試み時に牛乳・チーズの準備。妊婦＝辛いラーメン・チャンポン注意。子ども＝チャジャン麺・ごちそう麺・刀麺推奨。アレルギー（グルテン・シーフード・豆・卵・そば・甲殻類）事前告知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

老舗情報免責：店舗の営業時間・メニュー・決済方針は変動可

食事制限 fallback:

  • ハラール・コーシャー: 6種のうち認証店舗ほとんどない。 →梨泰院・江南一部認証店舗事前検索。
  • ベジタリアン・ビーガン: きのこ刀麺・野菜ごちそうができます（アンチョビスープ除外要請）。ラーメン・ジャジャンミョン・チャンポン＝非菜食。
  • グルテンフリー：6種ともに小麦粉麺（冷麺＝そば・澱粉） — オプションほとんど無し。
