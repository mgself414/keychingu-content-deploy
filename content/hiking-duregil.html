⚠ 외국인 자주 실수 5가지

1. "서울 = 도시만": 서울 = 북한산·관악산·도봉산 24개 산 + 서울둘레길 156km + 북한산 둘레길 71.5km + 외국인 자연 매니아 1번지·#148·#363 통합.

2. "북한산 = 너무 어렵": 북한산 = 백운대 정상 (836m) + 외국인 매니아 + 다양한 난이도 21개 봉우리 + 초보 우이동 도선사 코스·중급 백운대·#148 통합.

3. "등산복 = 다 필요": 외국인 hiking = 운동화 + 물 1L + 외국인 매니아 가성비 1번지 + 등산화 권장 (북한산 백운대)·외국인 가벼운 차림 OK (남산·#13).

4. "서울둘레길 = 등산": 서울둘레길 156km = 8 코스·도심·자연·평지 다양 + 외국인 매니아 도보·#363 자전거 OK + Stamp tour KTO 인증.

5. "외국인 영어 가이드 = 없음": 외국인 영어 가이드 = Klook·KKday·Seoul Hikers (외국인 동호회) + KTO 인증·외국인 매니아 풀세트.
