⚠ 5 common mistakes foreigners make

1. "T-money = rechargeable only": T-money 3 types — (1) Disposable (station ticket machine) (2) Rechargeable (convenience store) (3) Mobile T-money (NFC). Rechargeable is the number one choice for foreigners (4,000 won + recharge).

2. "Currency exchange = Everywhere": No. 1 currency exchange in Korea = Myeongdong, Incheon Airport, Hongdae, Jonggak, Itaewon + Bank (Foreign Exchange, Woori, Hana, KB). Myeongdong = Best exchange rate (private currency exchange office No. 1). Incheon Airport = worst exchange rate.

3. "Credit card = OK everywhere": Korean credit cards are OK (Visa·Master·JCB·UnionPay·Amex) + some small stores = Cash only. It is recommended to have about 50,000 won in T-money + credit card + cash.

4. "Foreigner Refund = Automatic": Tax Refund = Post Refund (Submission of Receipt + Refund Card). 30,000 won or more + Foreign passport required + Incheon Airport, Gimpo Airport, Hongik University refund location 1.

5. "WOWPASS = Same as Korean T-money": WOWPASS = Foreigners only + foreign currency exchange + payment integration (2022). T-money function + No. 1 foreigner friendliness. 1st priority card for foreign inbound.

⚙ 8 FAQs

1. 1st priority for T-money issuance to foreigners: Incheon Airport + convenience store + WOWPASS (foreigners only + currency exchange integrated).

2. Use mobile T-money: Android NFC + Naver Pay·KakaoPay·Toss payment. iPhone not supported.

3. No. 1 in currency exchange: Myeongdong private currency exchange office (best exchange rate) → Bank (KEB, Woori, Hana, KB) → Incheon Airport (worst exchange rate).

4. Credit card payment: OK in 90%+ stores in Korea (Visa·Master·JCB·UnionPay·Amex). Cash only at some small stores + recommended to have 50,000 won in cash.

5. Foreigner Tax Refund: KRW 30,000 or more + foreign passport + receipt submission + refund booth at Incheon/Gimpo Airport (leave 90 minutes before departure).

6. Foreigners using Kakao T: English OK + Card registration (Visa Master) + Receipt available in English.

7. Foreigner SIM/eSIM: Incheon Airport + Myeongdong + Hongdae + KT·SK·LG U+ + eSIM (Airalo·Holafly Global OK).

8. Foreign currency ATM 24 hours a day: Incheon Airport, Myeongdong, Hongdae, City Hall, Citibank, StanChart, Hana, Shinhan.
