韩国五方色 (Obangsaek / 오방색) 文化 — 丹青 (Dancheong / 단청)·彩条 (Saekdong / 색동)·拌饭 (Bibimbap / 비빔밥) 中强烈色彩组合的规则

五方色 (Obangsaek / 오방색)·阴阳五行 (Eumyangohaeng / 음양오행)·青赤黄白黑·丹青 (Dancheong / 단청)·彩条 (Saekdong / 색동)·太极旗 (Taegeukgi / 태극기) — 为外国人解读韩国传统色彩。这并非“因为好看而使用的颜色”，而是“为何偏偏是这五种颜色”。

在韩国旅行时，你可能会发现某种相同的色彩组合反复出现在眼前。宫殿屋檐下华丽的丹青 (Dancheong / 단청) (韩国传统建筑上的彩色图案)，儿童韩服袖子上的彩虹彩条 (Saekdong / 색동) (由多种颜色布料拼接而成的条纹，常用于韩服袖口)，拌饭 (Bibimbap / 비빔밥) (一种将多种食材和辣酱拌匀食用的韩国料理)上精确摆放的五种配料，甚至太极旗 (Taegeukgi / 태극기) (韩国国旗)的红、蓝、黑、白。外国人通常会觉得“韩国人使用色彩真华丽”，但实际上，这并非品味，而是规则。韩国传统色彩的根源在于五方色 (Obangsaek / 오방색) (指东、西、南、北、中五个方位的代表色)——对应五个方位的五种颜色——其基础正是贯穿韩国饮食和四柱 (Saju / 사주) (根据出生年月日时推算命运的方法)的阴阳五行 (Eumyangohaeng / 음양오행) (古代哲学思想，认为宇宙由阴阳二气和金木水火土五种元素构成)。也就是说，这与 [#1132 韩国小菜文化](1132_korean_banchan_culture.md) 中“五色均衡”的小菜 (Banchan / 반찬) (免费的韩式配菜)和 [#1133 韩国四柱·运势文化](1133_korean_saju_fortune_culture.md) 中“木火土金水”的四柱 (Saju / 사주) 拥有相同的思维方式，只是以色彩的形式表达出来。本文并非介绍“在哪里可以看到”，而是从外国人的视角，解释这五种颜色为何是这五种颜色，以及它们所代表的含义。这是韩国文化解读系列第16篇。

★ 一目了然 — 五方色 (Obangsaek / 오방색) 五色·方位·五行对应表

颜色 (汉字) 方位 五行 季节 核心象征
青 靑 (蓝/绿) 东 (东) 木 (木·树) 春 诞生·生命·成长 → 驱邪招福
赤 赤 (红) 南 (南) 火 (火·火) 夏 创造·热情 → 最强辟邪 (驱赶恶鬼)
黄 黃 (黄) 中央 (中) 土 (土·土) (换季期) 宇宙中心·最尊贵的颜色 (帝王之色)
白 白 (白) 西 (西) 金 (金·金属) 秋 纯洁·真实·清白 → 韩国人最喜爱的颜色
黑 黑 (黑) 北 (北) 水 (水·水) 冬 智慧·黑暗·终结

阅读方法: 东方 = 木 = 春 = 青色… 就像这样，方位·季节·自然元素·颜色被捆绑成一个整体。这五组就是五方色 (Obangsaek / 오방색) 的全部。(来源: 国家遗产厅·我们历史网)

⚠️ 外国人常有的3种误解

1. “彩条 (Saekdong / 색동)·丹青 (Dancheong / 단청) 只是五彩斑斓 = 设计品味” ❌ — 这并非随意的彩虹。它精确地由青·赤·黄·白·黑五种颜色 (+其间的中间色) 组成，每种颜色都代表着方位·季节·自然元素。色彩的顺序和组合本身就蕴含意义。

2. “青 (靑) 色是蓝色，为什么看起来总是像绿色？” ❌ — 五方色 (Obangsaek / 오방색) 中的青 (靑) 并非英语中能精确对应的单一颜色。韩语“청 (cheong)”是涵盖蓝色和绿色的概念 (木·树的颜色)，因此在丹青 (Dancheong / 단청)·食物中，有时也会呈现为绿色 (菠菜·黄瓜)。这是翻译上的陷阱，并非颜色有误。

3. “在韩国，红色是危险/禁止的颜色” ❌ — 恰恰相反。传统上，赤色 (红色) 是最强的辟邪 (辟邪) (驱赶恶鬼) 保护色 (符咒·禁绳 (Geumjul / 금줄)·儿童衣物中加入红色的原因)。这与“不要用红笔写名字”这一另类民间禁忌 (→ [#1139 韩国迷信·禁忌文化](1139_korean_superstition_taboo_culture.md)) 属于不同的语境。

① 什么是五方色 (Obangsaek / 오방색) — 五个方位的五种颜色

五方色 (Obangsaek / 오방색) 字面意思就是“五个方位的颜色”。它将东·西·南·北四个方位加上中央，共五个方位，分别对应一种颜色。

  • 东 (东) = 青 (靑)，南 (南) = 赤 (赤)，中央 (中) = 黄 (黃)，西 (西) = 白 (白)，北 (北) = 黑 (黑)。
  • 这五种颜色被称为五正色 (Ojeongsaek / 오정색) (指不混杂的纯正颜色)或五方正色。“正色 (Jeongsaek / 정색)”意为不混杂的正确颜色，即地位最高的基本色。
  • 核心并非颜色本身，而是颜色即是方位·自然·秩序的符号。在韩国·东亚，颜色在“美观”之前，更是蕴含宇宙秩序的象征语言。

因此，了解五方色 (Obangsaek / 오방색) 意味着读懂了韩国传统美术·服饰·饮食·建筑中隐藏的语法之一。

② 阴阳五行 (Eumyangohaeng / 음양오행) — 五方色 (Obangsaek / 오방색) 的操作系统 (与小菜 (Banchan / 반찬)·四柱 (Saju / 사주) 同根同源)

五方色 (Obangsaek / 오방색) “为何偏偏是这五种颜色”的答案在于阴阳五行 (Eumyangohaeng / 음양오행)。

  • 阴阳 (Eumyang / 음양): 认为太初时阴阳二气分离，形成天地。在五方色 (Obangsaek / 오방색) 中，五方正色 = 阳 (阳)，其间的中间色 (五间色) = 阴 (阴)。
  • 五行 (Ohaeng / 오행): 阴阳二气相遇，产生了木 (木·树)·火 (火·火)·土 (土·土)·金 (金·金属)·水 (水·水) 五种元素。这五种元素分别对应一种颜色——木=青，火=赤，土=黄，金=白，水=黑。
  • 因此，五方色 (Obangsaek / 오방색) 是“为五行披上色彩”。集齐五种颜色 = 集齐五种元素的能量，以达到和谐·平衡。

至此，系列的核心联系得以显现。[#1132 韩国小菜文化](1132_korean_banchan_culture.md) 中“一桌饭菜五色·五味俱全”，[#1133 韩国四柱·运势文化](1133_korean_saju_fortune_culture.md) 中“四柱八字 (Sajupalja / 사주팔자) 的木火土金水是否均衡”，以及这五方色 (Obangsaek / 오방색)——全部都源自阴阳五行 (Eumyangohaeng / 음양오행) 这棵大树的不同枝丫。饮食通过味道，四柱通过命运，五方色通过色彩，表达的都是相同的原理。

③ 各色含义 — 青·赤·黄·白·黑 各自诉说着什么

青 (靑) — 东方·木·春

万物初生，象征春天和生命的颜色。代表新的开始·成长·清澈。传统上，也用作驱邪招福的颜色。如前所述，青 (靑) 是一个涵盖蓝色和绿色的广阔概念。

赤 (赤) — 南方·火·夏

创造与热情，最炽热的生命力之色。同时被认为是辟邪 (辟邪) (驱赶恶鬼)力量最强的颜色。符咒用红字·红印，冬至 (Dongji / 동지) 煮红豆粥 (Patjuk / 팥죽) (一种用红豆熬制的粥，韩国传统上用于冬至驱邪)以红色气息辟邪，都是出于相同的逻辑。

黄 (黃) — 中央·土·中心

占据五个方位正中央，最尊贵的颜色。象征中心·根本·丰饶。在东亚，黄色被帝王所专用的原因就在于此 (非任何人可穿戴的颜色)。

白 (白) — 西方·金·秋

纯洁·真实·清白的颜色。有趣的是，它被认为是韩国人最喜爱的颜色。韩国人喜爱穿白衣，甚至被称为“白衣民族 (Baeguiminjok / 백의민족)” (指韩国人喜爱穿白色衣服的传统)，白色深深植根于韩国人的情感之中。

黑 (黑) — 北方·水·冬

象征智慧与深邃，以及终结·黑暗。如水般包容万物，使其沉淀的性质。士大夫 (Seonbi / 선비) (朝鲜时代的儒生)用墨 (Meok / 먹) 书写绘画的文化，也与这种黑色的格调相通。

★ 还有五间色 (Ogansek / 오간색): 介于正色之间的中间色五种被称为五间色 (Ogansek / 오간색) (指五正色之间的中间色)——青+黄=绿色 (绿)，青+白=碧色 (碧)，赤+白=红色 (红)，黑+黄=硫黄色 (硫黃)，黑+赤=紫色 (紫)。如果说正色是阳 (阳)，那么间色就是阴 (阴)。古人认为正色比间色更尊贵。也就是说，韩国传统色彩是正色5 + 间色5 = 十种颜色体系。(来源: 国家遗产厅·韩国民族文化大百科)

④ 用途 ① — 丹青 (Dancheong / 단청) 和彩条 (Saekdong / 색동) (建筑·服饰)

五方色 (Obangsaek / 오방색) 最华丽地展现的两个地方。

丹青 (Dancheong / 단청) — 宫殿·寺庙·亭子的木柱和屋檐上绘制的彩色图案。字面意思为“红丹 (丹) + 青绿 (靑)”，以五方色 (Obangsaek / 오방색) 为基础绘制纹样。它不仅仅是装饰，还兼具 ▲保护木材免受风雨·虫害 ▲彰显建筑的权威·神圣 ▲辟邪 (辟邪) (驱赶恶鬼) 的功能。景福宫 (Gyeongbokgung / 경복궁)·昌德宫 (Changdeokgung / 창덕궁) 以及全国寺庙中那些强烈的色彩，都遵循着五方色 (Obangsaek / 오방색) 的法则。

彩条 (Saekdong / 색동) — 由多种颜色布料拼接而成的条纹布料。典型应用于彩条上衣 (Saekdong Jeogori / 색동저고리) (儿童韩服 (Hanbok / 한복) 袖口)。父母让孩子从周岁 (Dol / 돌) (婴儿满一周岁时举行的庆祝仪式)到六七岁穿彩条服，是希望借助五方色 (Obangsaek / 오방색) 的力量辟邪 (辟邪) (驱赶恶鬼)，祈求福气·健康·长寿。彩条 (Saekdong / 색동) 不仅用于衣物，也用于包袱皮 (Bojagi / 보자기) (韩国传统布艺包袱)·福袋 (Bokjumeoni / 복주머니) (韩国传统福袋)，在节日·周岁宴上承载着相同的祝福意义。

⑤ 用途 ② — 饮食和太极旗 (Taegeukgi / 태극기) (餐桌·国家象征)

五方色 (Obangsaek / 오방색) 饮食 — 韩式“精美一碗”也有其规则。

  • 拌饭 (Bibimbap / 비빔밥): 中间放黄 (蛋黄)，周围摆放青 (菠菜)·赤 (胡萝卜·辣椒酱 (Gochujang / 고추장))·白 (豆芽·白鸡蛋丝)·黑 (蕨菜·肉) 等配料。五种颜色 = 将五种元素的能量汇聚于一碗，搅拌以求和谐，这正是阴阳五行 (Eumyangohaeng / 음양오행) 在餐桌上的体现。
  • 九折板 (Gujeolpan / 구절판): 宫廷料理。中间放置薄饼，八个格子中分别盛放青 (黄瓜)·赤 (胡萝卜·牛肉)·白 (白鸡蛋丝·绿豆芽)·黑 (木耳·香菇)·黄 (黄鸡蛋丝·松子) 等食材，颜色搭配得宜。
  • 传统上，均衡搭配五方色 (Obangsaek / 오방색) 的餐桌 = 对五脏 (Ojang / 오장) 皆有益的均衡饮食。(→ [#1132 韩国小菜文化](1132_korean_banchan_culture.md) 中“五色·五味”的思维方式完全相同)

太极旗 (Taegeukgi / 태극기) — 韩国国旗中也隐藏着五方色 (Obangsaek / 오방색)。

  • 底色白 (白)，中央太极的青·赤，四角四卦 (乾坤坎离 (Geongongamri / 건곤감리)) 的黑 (黑)。五方色 (Obangsaek / 오방색) 中唯独缺少黄色，使用了白·黑·青·赤四种颜色。
  • 中央太极象征阴阳 (Eumyang / 음양)，四卦分别象征天 (乾)·地 (坤)·水 (坎)·火 (离)。也就是说，太极旗 (Taegeukgi / 태극기) 是将阴阳五行 (Eumyangohaeng / 음양오행) 宇宙观浓缩于一幅旗帜。(来源: 国家记录院·我们历史网)

⑥ 辟邪 (辟邪) 和祈福 (祈福) — 相信色彩能“守护”

五方色 (Obangsaek / 오방색) 华丽的真正原因，在其美感之前，是其巫术性·祈福性功能。

  • 辟邪 (辟邪): 人们相信，集齐五种颜色的能量，不好的气息·恶鬼就无法侵犯。尤其是赤色 (红色) 的辟邪 (辟邪) 力量强大，因此禁绳 (Geumjul / 금줄)·符咒·冬至 (Dongji / 동지) 红豆粥 (Patjuk / 팥죽) 都使用了红色气息。
  • 祈福 (祈福): 同时，彩条 (Saekdong / 색동)·包袱皮 (Bojagi / 보자기)·周岁宴 (Dol / 돌) 上的五方色 (Obangsaek / 오방색) 也象征着招福·健康·长寿。“阻挡 (辟邪)”+“招来 (祈福)”是成套的两个方向。
  • 人生礼仪: 孩子周岁 (Dol / 돌) (彩条 (Saekdong / 색동)·周岁腰带 (Doltti / 돌띠))，婚礼 (Wedding / 혼례) (青·红包袱皮 (Bojagi / 보자기)，新娘的胭脂 (Yeonji / 연지))，节日——在人生的每个关键时刻都出现五方色 (Obangsaek / 오방색)，是为了保护和祝福那一刻。可以说，色彩就是符咒，也是祈祷。

对韩国人而言，五方色 (Obangsaek / 오방색) 并非“漂亮的配色表”，而是长久以来守护生活、祈求福祉的象征语言——这一句话是理解五方色 (Obangsaek / 오방색) 的核心。

⑦ 现代设计中的五方色 (Obangsaek / 오방색) — 14世纪哲学融入21世纪标志

五方色 (Obangsaek / 오방색) 并非博物馆里的文物，而是至今仍在发挥作用的韩国色彩身份。

  • 奥运会: 1988年首尔奥运会 (Seoul Ollimpik / 서울 올림픽)，2018年平昌冬奥会 (Pyeongchang Donggye Ollimpik / 평창 동계올림픽) 的会徽·视觉形象都使用了五方色 (Obangsaek / 오방색)。特别是平昌 (Pyeongchang / 평창) 标志明确采用了黑·青 (绿)·黄·赤·白五种颜色。
  • K-Food·韩服 (Hanbok / 한복)·工艺品: 高级韩服 (Hanbok / 한복)，K-Food包装，现代陶艺·平面设计中，五方色 (Obangsaek / 오방색) 反复出现，作为“韩国特色”的信号。
  • 品牌塑造: 21世纪的科技品牌借鉴14世纪的阴阳五行 (Eumyangohaeng / 음양오행) 色彩来表达身份——五方色 (Obangsaek / 오방색) 是连接传统与现代最短的视觉桥梁。

旅行者小贴士: 在参观博物馆·宫殿的丹青 (Dancheong / 단청)，仁寺洞 (Insadong / 인사동)·北村 (Bukchon / 북촌) 工艺品店的包袱皮 (Bojagi / 보자기)·彩条 (Saekdong / 색동) 饰品，餐厅的拌饭 (Bibimbap / 비빔밥)·九折板 (Gujeolpan / 구절pan)，以及街头随处可见的太极旗 (Taegeukgi / 태극기) 时，只要记住“这五种颜色代表方位·季节·元素”这一句话，同样的风景就会呈现出完全不同的意义。

❓ 外国人常见问题 (FAQ)

  • 五方色 (Obangsaek / 오방색) 是韩国独有的吗？ — 阴阳五行 (Eumyangohaeng / 음양오행)·五色本身是包括中国·日本在内的东亚共同传统。但丹青 (Dancheong / 단청)·彩条上衣 (Saekdong Jeogori / 색동저고리)·白衣 (Baegui / 백의) 偏好等深入日常生活·服饰的形式在韩国尤为发达。
  • 青 (靑) 是蓝色还是绿色？ — 两者皆是。韩语“청 (cheong)”是涵盖蓝色~绿色的概念 (木·树的颜色)，因此根据语境，在丹青 (Dancheong / 단청) 中可能呈现为深蓝色，在食物中则呈现为绿色 (菠菜·黄瓜)。翻译时将其一同译为“blue/green”更为准确。
  • 红色不是不好的颜色吗？ — 传统上，赤色是驱赶恶鬼的保护色，反而是好的颜色。“不使用红笔写名字”是另一个独立的民间禁忌 (→ [#1139 韩国迷信·禁忌文化](1139_korean_superstition_taboo_culture.md))，与五方色 (Obangsaek / 오방색) 中赤色的象征意义语境不同。
  • 在哪里能最好地看到五方色 (Obangsaek / 오방색)？ — 宫殿·寺庙的丹青 (Dancheong / 단청)，博物馆·工艺品店的彩条 (Saekdong / 색동)·包袱皮 (Bojagi / 보자기)，餐厅的拌饭 (Bibimbap / 비빔밥)·九折板 (Gujeolpan / 구절판)，以及街头随处可见的太极旗 (Taegeukgi / 태극기)。了解了色彩的含义，它就存在于日常生活的各个角落。
  • 我想进一步确认准确的颜色-方位-元素对应关系。 — 上述★对应表是基本，具体色调·季节分配在不同文献中可能存在细微差异，建议查阅国家遗产厅·国立民俗博物馆等官方资料进行交叉确认。
