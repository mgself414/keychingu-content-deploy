外国人常犯的3个错误

1. 一开始就把所有调料全放进去

韩国汤饭是自行加盐·胡椒·虾酱来调味的DIY料理。第一口请先品尝原味汤底，再根据口味一勺一勺慢慢添加。上来就全部倒入，反而会掩盖汤底本味，风味层次变得单调。

2. 不把泡菜·辣白菜放进汤里

汤饭配的萝卜块泡菜 (Kkakdugi / 깍두기)·大白菜泡菜 (Kimchi / 김치) 不只是小菜，而是直接放入汤中一起吃的核心搭配。韩国美食家会把1~2块萝卜泡菜泡进汤里，增添爽口的酸味。这才是韩食汤饭体验的50%精髓。

3. 单人前往 + 时间没选对

汤饭是最适合独自用餐的韩国料理 — 所有门店均接受1人就餐。但午餐12~13时是上班族排队高峰，等候时间约1小时，建议选择早上7~9时或下午14~17时，人流较少。老店工作日午餐需等30分钟~1小时，周末则随时需等30分钟以上。

2. 精选8家门店 (4大轴线均衡)

2-1. 百年老店3家 — 韩国汤饭的活历史

① 河东馆 (Hadongkwan / 하동관) — 明洞 (Myeongdong / 명동)

1939年创业，牛骨汤老店首选。明洞站 (Myeongdong Station / 명동역) 6号出口步行4分钟。人均 ₩18,000~₩22,000。牛骨汤 + 萝卜泡菜 (Kkakdugi / 깍두기) + 熟肉片 (Suyuk / 수육) 正统三件套 — 87年来坚守同一调味·同一汤底比例。外国人知名度最高的韩食老店，提供英文菜单，部分员工会英语。接受1人就餐，拼桌自然。工作日午餐需等30分钟~1小时。

② 梨门雪浓汤 (Imun Seolleongtang / 利文牛肉汤 (Imun Seolleongtang / 이문설농탕)) — 钟路 (Jongno / 종로)

1902年创业，首尔雪浓汤发源级老店。钟阁站 (Jonggak Station / 종각역) 4号出口步行3分钟。人均 ₩15,000~₩18,000。120年+历史 — 韩国历史最悠久的餐厅之一。雪浓汤 + 萝卜泡菜 (Kkakdugi / 깍두기) + 泡菜 (Kimchi / 김치) 的纯粹正统组合。接受1人就餐，外国美食爱好者首选。提供部分英文菜单，老店氛围浓厚。

③ 龙金屋 (Yonggumok / 용금옥) — 奖忠洞 (Jangchungdong / 장충동)

1932年创业，牛膝汤·内脏汤老店精华。东大入口站 (Dongdaipgu Station / 동대입구역) 步行5分钟。人均 ₩18,000~₩22,000。94年历史 — 韩牛牛膝 + 内脏慢炖12小时。胶原蛋白 + 弹嫩口感 + 浓郁汤底三重享受。接受1人就餐，工作日午餐等候约1小时。提供部分英文菜单。

2-2. 高性价比连锁2家 — 外国人初次体验安心之选

④ 神仙雪浓汤 (Sinseon Seolleongtang / 神仙牛肉汤 (Sinseon Seolleongtang / 신선설농탕)) — 全国连锁

外国人知名度第一的雪浓汤连锁。明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남)·梨泰院 (Itaewon / 이태원) 等50+门店。人均 ₩9,000~₩12,000。雪浓汤 + 泡菜套餐 + 高性价比 — 多家门店24小时营业。全部门店提供英文菜单，员工习惯英语沟通。接受1人就餐，无需预约。外国人汤饭入门 + 性价比 + 夜间行程首选。

⑤ 斗园 (Duwon / 斗院 (Duwon / 두원)) — 钟路 (Jongno / 종로)

1985年创业，钟路雪浓汤性价比老店。钟阁站 (Jonggak Station / 종각역) 步行5分钟 / 光化门站 (Gwanghwamun Station / 광화문역) 步行7分钟。人均 ₩11,000~₩14,000。老店氛围 + 高性价比 — 是梨门雪浓汤 (Imun Seolleongtang / 이문설농탕) 的竞争对手，但价格便宜约1.5倍。午餐·晚餐上班族常客众多。接受1人就餐，提供部分英文菜单。

2-3. 内脏·牛膝专门店2家 — 美食家进阶挑战

⑥ 孔德洞内脏汤 (Gongdeokdong Naejangtang / 공덕동 내장탕) — 麻浦 (Mapo / 마포)

麻浦 (Mapo / 마포) 内脏汤老店区域代表门店。孔德站 (Gongdeok Station / 공덕역) 步行5分钟。人均 ₩13,000~₩16,000。牛肠·牛百叶·牛肝内脏全套 + 辛辣调味汤底。韩国美食家内脏汤首选，MZ外国游客进阶体验菜单。接受1人就餐，提供部分英文菜单 (图片菜单 + 手势比划也可以)。

⑦ 有趣雪浓汤 (Jaeminneun Seolleongtang / 有趣的牛肉汤 (Jaeminneun Seolleongtang / 잼있는 설렁탕)) — 江南 (Gangnam / 강남)

江南 (Gangnam / 강남) 雪浓汤潮流老店 (1990年代至今)。江南站 (Gangnam Station / 강남역) 11号出口步行4分钟。人均 ₩14,000~₩17,000。雪浓汤 + 牛膝组合菜单 + 萝卜泡菜 (Kkakdugi / 깍두기) 无限续。在社交媒体·美食圈中位列江南雪浓汤首位。提供英文菜单，员工会英语，100%支持刷卡·移动支付。

2-4. 排骨汤组合1家 — 连接#130指南

⑧ 凤飞扬排骨汤 (Bongpiyang Galbi-tang / 凤皮羊 (Bongpiyang / 봉피양) 갈비탕) — 松坡方夷 (Songpa Bangi / 송파 방이)

1968年起，排骨汤 + 平壤冷面套餐 = 韩国汤饭最高端阵营。蚕室站 (Jamsil Station / 잠실역) 步行10分钟。排骨汤 (₩30,000) + 平壤冷面 (Pyongyang Naengmyeon / 평양냉면) (₩18,000) 套餐为招牌组合。与#130烤肉指南 + #129冷面指南相互衔接的门店 — 韩国汤饭指南的终点站。建议4人以上前往，适合外国商务宴请·纪念日场合。提供英文菜单，建议提前预约。

4. FAQ 8问

Q1. 汤饭的调料怎么加？

A. 韩国汤饭的精髓 — 先喝一口原味汤底，再自行加入盐·胡椒·虾酱 (Saeujeot / 새우젓)·蒜末。餐桌上备有4种调料。将萝卜泡菜 (Kkakdugi / 깍두기)·泡菜 (Kimchi / 김치) 泡进汤里一起吃，才是正统吃法。

Q2. 哪些门店可以单人就餐？

A. 8家门店全部接受1人就餐 — 汤饭是韩国最适合独自用餐的料理。拼桌很自然，30分钟内即可用餐完毕。

Q3. 平均等候时间是多少？

A. 工作日午餐12~13时需等30分钟~1小时 (河东馆 (Hadongkwan / 하동관)·龙金屋 (Yonggumok / 용금옥))；早上7~9时 / 下午14~17时几乎无需等候。神仙雪浓汤 (Sinseon Seolleongtang / 신선설농탕)·斗园 (Duwon / 두원) 排队较短。

Q4. 有英文菜单和英语服务吗？

A. 神仙雪浓汤 (Sinseon Seolleongtang / 신선설농탕)·有趣雪浓汤 (Jaeminneun Seolleongtang / 잼있는 설렁탕) 英语服务最完善。河东馆 (Hadongkwan / 하동관)·梨门雪浓汤 (Imun Seolleongtang / 이문설농탕) 以图片菜单为主，韩语优先。龙金屋 (Yonggumok / 용금옥)·孔德洞内脏汤 (Gongdeokdong Naejangtang / 공덕동 내장탕) 韩语 + 手势比划。

Q5. 可以刷卡吗？

A. 8家门店全部支持刷卡·移动支付。百年老店如河东馆 (Hadongkwan / 하동관)·梨门雪浓汤 (Imun Seolleongtang / 이문설농탕) 也已现代化，配备刷卡机。

Q6. 萝卜泡菜·泡菜可以无限续吗？

A. 河东馆 (Hadongkwan / 하동관)·梨门雪浓汤 (Imun Seolleongtang / 이문설농탕)·龙金屋 (Yonggumok / 용금옥) 等老店均可无限续 (向员工要求即可)。神仙雪浓汤 (Sinseon Seolleongtang / 신선설농탕) 连锁也可续。有趣雪浓汤 (Jaeminneun Seolleongtang / 잼있는 설렁탕) 的无限续萝卜泡菜是招牌特色。

Q7. 有素食·清真选项吗？

A. 汤饭本身以牛骨·牛肉为基底，无法素食。素菜菜单几乎没有。韩国汤饭老店无清真认证。素食外国人推荐韩国寺庙饮食·拌饭 (Bibimbap / 비빔밥)。

Q8. 汤饭配什么饮品最好？

A. 烧酒 (Soju / 소주) (正统搭配) — 汤饭 + 一杯烧酒 = 韩国上班族午餐精髓。米酒 (Makgeolli / 막걸리) (老店·龙金屋 (Yonggumok / 용금옥) 推荐)。饮料类与泡菜 (Kimchi / 김치)·萝卜泡菜 (Kkakdugi / 깍두기) 的酸味协同效应较弱。
