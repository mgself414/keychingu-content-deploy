🎯 이 매뉴얼을 읽는 법 — 화면 표기 규약

화면 표기 규약(대괄호 버튼·낫표 화면·굵게 동작)은 #1270 키오스크 편이 SoT다. 이 글도 그대로 따른다.

  • 화면 속 버튼은 대괄호로: [ 결제하기 ]
  • 화면 제목·안내 문구는 낫표로: 「정산 내역」
  • 손으로 하는 동작은 굵게: "팔찌를 리더기에 가볍게 갖다 댄다"

범위 안내: 이 편은 팔찌 = 락커 키 + 결제 수단 "시스템"만 다룬다. 찜질방 자체 이용법(구역 구성·순서)은 #007, 탈의실·목욕탕 에티켓은 #34를 먼저 읽고 오면 이 편이 더 잘 이해된다.

① 팔찌 하나 = 락커 키 + 지갑 + 신분

한국 찜질방은 입장하는 순간 카드나 현금을 몸에 지니지 않는다. 프런트에서 받는 실리콘 팔찌 하나가 옷장 열쇠이자, 매장 안에서 쓰는 전자지갑이자, 몇 번 손님인지 식별하는 신분증 역할을 동시에 한다.

  • 원리는 간단하다 — 팔찌에 숫자/RFID 칩이 들어 있고, 프런트 시스템이 그 번호에 내가 쓴 금액을 계속 누적한다.
  • 안에서는 지갑을 아예 안 갖고 다녀도 된다. 매점에서 뭘 사든, 식당에서 뭘 먹든 팔찌만 태그하면 끝 — 결제는 나갈 때 한 번에.
  • 그래서 한국인들도 찜질방 안에서는 "얼마 나왔지"를 신경 안 쓰고 편하게 소비한다. 현금 없이 다녀도 되는 구조라는 것만 알면 이 편의 절반은 이해한 것이다.

② 입장 마스터 플로우 — 프런트에서 팔찌를 받기까지

단계 화면/현장 하는 일 함정
1 프런트 카운터 입장료 결제 (₩10,000~20,000 수준, 지점·시간대에 따라 다름) 심야 할증이 붙는 지점도 있음
2 프런트 직원이 건네줌 팔찌 + 찜질복(유니폼) + 수건 2장 수령 수건은 한 장은 몸, 한 장은 머리(양머리)용 — #34 참고
3 신발장 (입구 바로 안쪽) 신발 벗고 신발장에 넣은 뒤 잠금 신발장 키가 팔찌와 별도인 지점도 있다 — 아래 ⑤ 동선 표 참고
4 옷장 (탈의실, 남/여 분리) 팔찌를 잠금장치에 태그해 옷장 열고 옷 보관 후 잠금 여기서부터 남탕/여탕 입구가 갈린다

이 4단계가 끝나면 몸에는 팔찌만 남는다. 여기부터는 팔찌 하나로 전부 해결된다.

③ 내부 소비 절차 — 매점도 식당도 세신도 전부 "팔찌 태그 후불"

찜질방 안 어떤 소비든 원리는 하나다 — 주문/이용 시 팔찌 번호를 말하거나 리더기에 태그 → 결제는 나갈 때 한 번에.

장소 흐름
매점 원하는 걸 고르고 직원에게 팔찌 손목 보여주기 or 팔찌 번호 말하기 → 직원이 시스템에 태그
식당(찜질방 내 식당가) 자리에서 주문 → 「손목번호 몇 번이세요?」 질문에 팔찌 확인 → 나올 때 정산
세신(때밀이)·마사지 접수 시 팔찌 제시 → 서비스 종료 후 팔찌 태그로 요금 등록 (현장 즉시 결제를 요구하는 지점도 있음)

의사화면(태그형 리더기 기준):

```

「손목밴드 태그」

─────────────

번호 확인 중...

No. 0247 인식됨

₩3,000 적립 완료

```

  • 지갑도 카드도 꺼낼 필요가 없다 — 이게 이 시스템의 핵심이다.
  • 태그가 안 찍히면 직원이 번호를 손으로 입력해준다. 당황하지 말고 팔찌를 보여주기만 하면 된다.

④ 퇴장 정산 플로우 — 나갈 때 한 번에 계산

단계 화면/현장 하는 일
1 옷장으로 복귀 팔찌 태그해 옷장 열고 옷 갈아입기
2 프런트 or 무인 정산기 팔찌를 리더기에 올려놓기
3 정산 화면 확인 안에서 쓴 내역 합산 금액 확인 → 결제
4 게이트/출구 결제 완료 후 통과

무인 정산기 의사화면:

```

「정산 내역」

입장료 ₩12,000

매점 - 식혜 ₩3,000

매점 - 계란 ₩2,000

──────────────────

합계 ₩17,000

[ 카드 결제 ] [ 현금 결제 ]

```

  • 정산기가 없는 지점은 전부 프런트 직원이 팔찌를 보고 구두로 금액을 불러준다.
  • 입장할 때 낸 돈은 이미 냈으니, 정산 화면에는 "안에서 추가로 쓴 것"만 더해져 나온다는 것만 기억하면 금액이 갑자기 커 보이지 않는다.

⑤ 키 사용 시점 동선 표 — 언제 어디서 팔찌를 쓰나

순서 장소 팔찌 사용 여부
1. 신발장 신발 보관 지점에 따라 별도 키 or 팔찌 태그 (상이)
2. 옷장 옷 보관 팔찌 태그로 열고 잠금
3. 목욕탕(온탕·냉탕·세신) 몸만 입장 사용 안 함 (팔찌는 락커에 두고 오는 경우도 있음 — 프런트 안내 확인)
4. 찜질복 착용 → 찜질존 공용구역 팔찌 착용 유지
5. 매점·식당 소비 팔찌 태그로 후불 등록
6. 옷장 재방문 옷 회수 팔찌 태그로 재개방
7. 프런트/정산기 퇴장 팔찌로 최종 정산

⑦ 당황 시나리오 3

1. 팔찌를 잃어버렸다 — 당황하지 말고 프런트로 바로 가서 신고한다. 대부분 지점이 분실 시 배상 규정(정액 변상 또는 재발급료)을 두고 있으니, 직원이 안내하는 대로 처리하면 된다.

2. 옷장이 안 열린다 — 십중팔구 팔찌 태그 방향 문제다. 리더기 위치를 다시 확인하고 팔찌 면을 뒤집어서 다시 대본다. 그래도 안 되면 근처 직원 호출.

3. 정산 금액이 기억보다 크다 — 당황하지 말고 「내역 확인」을 요청한다. 항목별로 찍혀 나오니 무엇을 언제 태그했는지 그 자리에서 확인 가능하다.

⑧ 플랜B — 말이 안 통할 때

정산 화면 앞에서 막히면 "정산해 주세요 (jeongsanhae juseyo)" 한 마디와 함께 팔찌를 내밀면 된다. 대부분 직원이 알아서 화면을 보여주고 결제를 진행해준다.
