釜山咖啡之路 — 在世界冠军之城喝咖啡的方法

副标题: 2019年韩国首位世界咖啡师冠军全珠妍 (Jeon Ju-yeon / 전주연) 出自釜山的莫莫斯咖啡 (Momos Coffee / 모모스커피)，这并非偶然。生豆进港的港口、仓库改造的烘焙工坊、发端于田浦 (Jeonpo / 전포) 的第一代精品咖啡 — 釜山是一座语法和首尔不同的咖啡城市。这一篇整理了4家烘焙工坊、影岛 (Yeongdo / 영도) 咖啡街动线，还有"6点打烊"的陷阱。是田浦社区篇(#246)·影岛篇(#271)的咖啡深度延伸篇。

ISSUE · #1321 · 2026-08-23

🎯 为什么釜山是咖啡城市

两个数字就能说明问题。第一，韩国进口的生豆大多数经由釜山港进港 — 烘焙工坊聚集在港口城市，是物流的逻辑。第二，2019年世界咖啡师锦标赛上韩国首位夺冠的全珠妍咖啡师，正是釜山本土品牌莫莫斯咖啡的代表。2026年，在《金融时报》(FT) "全球最佳咖啡馆100"评选中，莫莫斯拿下了韩国咖啡馆最高排名的全球第22位。如果说首尔圣水 (Seongsu / 성수)·延南 (Yeonnam / 연남) 的咖啡馆潮流靠"空间"取胜，釜山则是一座靠烘焙和咖啡本身取胜的城市。

① 莫莫斯咖啡 (Momos Coffee / 모모스커피) — 冠军的咖啡，两大据点

该去哪儿

  • 影岛烘焙工坊 & 咖啡吧 — 位于影岛 (Yeongdo / 영도) 蓬莱洞 (Bongnae-dong / 봉래동)。由旧物流仓库改造的大型空间，生豆仓储·烘焙设施与咖啡吧同在一栋楼里，把"咖啡诞生的过程"整个空间都展示出来。2021年底开业以来，事实上已成为釜山咖啡之旅的第一站。
  • 温泉场 (Oncheonjang / 온천장) 本店 — 2007年创立的原点。规模虽不及影岛店，却是从街角咖啡馆到世界冠军这段故事的起点。
  • 还有海云台 (Haeundae / 해운대) 马林城 (Marine City / 마린시티) 店，以及由釜山市长旧官邸改造的道摹轩 (Domoheon / 도모헌) 店(2024年)——想避开人多的地方，选道摹轩。

⚠ 容易慌的点：下午6点打烊

莫莫斯全部门店都在下午6点打烊("咖啡师也要有晚间生活"政策，2022年起)。如果按"吃完晚饭去喝咖啡"的常规旅行节奏走，大概率会扑空。把喝咖啡安排在白天，放在上午到早下午之间，是釜山咖啡之路的基本语法。

② 田浦 — 第一代精品咖啡的发源巷弄

田浦咖啡街(#246)在社区篇里已经讲过，但从咖啡这条主线重新看，能看出一条谱系：

  • FM咖啡 (FM Coffee / 에프엠커피) — 2008年发端于田浦，与莫莫斯·布莱克业咖啡一起开拓了釜山精品咖啡的第一代。
  • 布莱克业咖啡 (Blackup Coffee / 블랙업커피) — 釜山精品咖啡第一代的另一支力量。本店口碑稳定，在本地一直评价不错。
  • 维尔克烘焙工坊 (Werk Roasters / 베르크 로스터스) — 从独立烘焙工坊成长为"釜山精品咖啡四大天王"之一的新兴强者。田浦门店走的是介绍自家咖啡的展示店概念，适合"买豆+试喝"组合顺路造访。也经常出现在广安里 (Gwangalli / 광안리) 一带的活动——咖啡展 (Cafe Show / 카페쇼)上。

点单小贴士(精品咖啡馆通用)

1. 先在菜单上选手冲(滤泡)还是浓缩咖啡系——对烘焙工坊来说，手冲才是主角。

2. 如果豆子有2种以上，只要问店员"是偏水果调还是偏坚果调"就够了(用英文fruity / nutty问也行得通)。

3. 买豆子要确认烘焙日期——烘焙工坊直营店大多是1~2周内的新豆。

③ 影岛蓬莱洞 — 仓库变身咖啡馆的街区

影岛蓬莱洞一带，港口仓库地带正在变成咖啡特色街。以莫莫斯烘焙工坊为锚点，一家家由仓库改造的咖啡馆沿着海景·吊车景观依次排开。和影岛篇(#271)的白藜文化村 (Huinnyeoul Culture Village / 흰여울문화마을) 动线连起来，正好凑成半天行程：白藜漫步 → 蓬莱洞仓库咖啡馆 → (喝咖啡到此为止，6点前结束) → 晚上去札嘎其 (Jagalchi / 자갈치) 的醋辣酱屋 (Chojang-jip / 초장집)(#1320)。

🗺 一日动线示例

时间 动线
上午 田浦 — 在FM咖啡或维尔克展示店喝一杯手冲 + 买豆
中午 在西面 (Seomyeon / 서면) 吃小麦冷面(#1320)
下午 前往影岛 — 白藜文化村(#271) → 蓬莱洞莫莫斯烘焙工坊 & 咖啡吧
晚上 咖啡6点打烊 — 札嘎其醋辣酱屋生鱼片(#1320)或广安里(#243)夜景
