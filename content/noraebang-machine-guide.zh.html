韩国练歌房遥控器零慌张手册 — 照着按钮操作就好

副标题：投币练歌房 (coin noraebang 코인노래방) 结账机流程 · 遥控器按钮对照表(生存词15个) · 英文歌曲搜索主流程(韩英切换 (한/영) 是关键) · 直接输入曲号 · 回声·音调·节奏调节 · 慌张场景实战应对

ISSUE 04 · #1283 · 2026-08-16 · korea-first-timer系列⑭

🎯 本手册阅读方法 — 画面标记规则

沿用本系列SoT(#1270)的伪画面标记规则。

  • 画面·遥控器上的按钮用方括号标注：[ 预约 (예약) ]
  • 画面标题·提示文字用「」标注：「请搜索歌曲 (곡을 검색하세요)」
  • 用手完成的动作用加粗标注："曲号4位数用数字键输入"

  • #008练歌房使用指南：第一次去练歌房的方法(去哪里·怎么预约·礼仪)
  • #436投币练歌房介绍：投币练歌房是什么，和一般练歌房有什么区别(文化介绍)

零韩语基础的人走进投币练歌房，真正的门槛不是"练歌房是什么"，而是"这遥控器20来个按钮该按哪个才能点出我的歌"。本文把这20个按钮浓缩成一张表。

② 投币练歌房结账机流程 — 从选包厢到开始点歌

步骤 画面/机器显示内容 该做的事 陷阱
1 包厢入口指示灯 绿灯/不亮 = 空包厢，红灯 = 使用中 没有空包厢就在等候画面确认排号
2 结账机(包厢墙面或店门口公用) 选择[ 按曲计费 (곡수제) ]或[ 按时计费 (시간제) ] 按曲计费=按歌曲数量收费，按时计费=按分钟包段收费 — 各店默认不同
3 现金投入口/刷卡机 投入纸币·硬币，或刷卡·闪付 结账后画面会显示剩余曲数或剩余时间 — 这个数字就是这次能用的全部
4 包厢内遥控器待机画面 拿起遥控器开始搜歌 结完账找不到遥控器干着急的人不少 — 一般固定放在麦克风旁边的架子上

每首歌的价格因门店·时段而异，大致是几百韩元一档。按时计费也是10分钟为单位的小额结账，负担不大。

③ 遥控器按钮对照表 — 生存词15

品牌不同按钮排列略有差异，但名称和功能几乎一样。下表覆盖遥控器上所有会出现的韩文。

中文 (roman 한글) 含义
开始 (sijak 시작) Start — 输入曲号后立即播放
预约 (yeyak 예약) Reserve — 加进队列末尾(当前歌曲放完接着播)
优先预约 (useon yeyak 우선예약) Priority reserve — 插到队列最前面
取消 (chwiso 취소) Cancel — 只取消最后一笔预约，正在播放的歌不会中断
曲名 (jemok 제목) Title search — 用歌曲名搜索
歌手 (gasu 가수) Artist search — 用歌手名搜索
韩英切换 (han/yeong 한/영) KOR/ENG键盘切换 — 搜英文歌前必按，不按键盘只会出韩文
号码 (beonho 번호) Song number — 直接输入曲号的数字键
删除 (sakje 삭제) Delete — 删掉打错·输错的字
间奏跳过 (ganju jump 간주점프) Interlude skip — 跳过前奏·间奏(只有伴奏的段落)
回声 (eko 에코) Echo — 麦克风回响强弱调节
音调 (ki 키) Key — 半音为单位调音高(配合男女音域)
节奏 (tempo 템포) Tempo — 调播放速度
音量 (volleum 볼륨) Volume — 麦克风或伴奏音量
伴奏 (banju 반주) Instrumental — 不出人声只放MR(练习模式)

小贴士：15个不用全背下来。韩英切换 (han/yeong 한/영)(进英文歌的入口)·预约 (yeyak 예약)(加进队列)·取消 (chwiso 취소)(只删最后一笔预约)这三个是核心。

④ 英文歌搜索主流程 — 本篇核心

不按这个顺序，英文歌绝对搜不到。没按韩英切换 (한/영)就去按曲名 (제목)，键盘还是韩文，根本没办法输入英文。

1. 在遥控器待机画面先按[ 韩英切换 (한/영) ]按钮 — 确认画面角落有没有出现EN/ENG标志

2. 按[ 曲名 (제목) ](或[ 歌手 (가수) ]) → 进入搜索模式

3. 画面出现英文键盘 → 只输入歌名开头几个字母(例如"SHAPE OF")

4. 出现搜索结果列表，每首歌旁边标着曲号

5. 确认想要那首的曲号 → 按[ 预约 (예약) ](加入队列)或[ 开始 (시작) ](立即播放)

  • 陷阱：不按韩英切换 (한/영)就搜索，键盘是韩文字母，英文根本输不进去，就算硬按也常常搜出0个结果。不是"没有这首英文歌"，十有八九是没按那个切换键。
  • 小贴士：比起输入歌手名，只输入歌名前3~4个字母搜索成功率更高(完整曲名·特殊符号常常匹配失败)。

⑤ 直接输入曲号 — 已知曲号时最快的路径

如果在Melon·YouTube上提前查好曲号，或者从搜索结果里已经确认了曲号，这条路最快。

1. 用遥控器数字键输入曲号(通常4~6位数)

2. [ 开始 (시작) ] — 当前没有歌在播就立即播放 / [ 预约 (예약) ] — 加入队列

3. 输错了按[ 删除 (삭제) ]重新输入，想整个重来就按[ 取消 (취소) ]

⑥ 回声·音调·节奏调节 — 配合自己的嗓音和音域

包厢内遥控器或墙面面板上的调节按钮，歌曲播放中也能实时调整。

调节项 按钮 用途
回声 [ 回声 (에코) ] +/- 麦克风回响强弱 — 太强发音会糊
音调 [ 音调 (키) ] ↑/↓ 以半音为单位升降音高 — 原调不合适时(男女音域差异)
节奏 [ 节奏 (템포) ] +/- 播放速度 — 说唱段落太快可以稍微调慢

⑦ 加时·加曲结账 — 剩余额度用完时

  • 按时计费：快结束时画面会跳出剩余时间倒计时。很多门店在唱歌过程中也能去结账机加时(续费) — 不用急着收尾，从容走到结账机就行。
  • 按曲计费：结账的曲数用完，画面会提示、也没法再加预约 → 去结账机加购曲数后回包厢。
  • 价格因门店·时段而异，但大致是每首歌几百韩元的水平。

⑧ 慌张场景3种 — 实际会发生的事与应对

1. 怎么搜都搜不到英文歌 — 90%的原因是没按韩英切换 (한/영)切换键。回到④从第一步重来。

2. 不想中断歌曲，只想取消刚点的预约 — [ 取消 (취소) ]只删最后一笔预约，正在播放的歌会照常继续。不过卡在队列中间的歌，很多机型无法单独取消 — 所以预约前先确认一遍曲号，比事后重输更快。

3. 时间快到了 — 画面出现倒计时不用慌，唱歌过程中直接走到结账机加钱就不会断歌。结账机在包厢外的店，门口就能马上办。

⑨ 备用方案 — 遥控器不听话或搞不懂时

  • 叫店员：投币练歌房大多是无人经营，但也有柜台·对讲机的门店。找对讲机按钮或店门口的柜台。
  • 和一般练歌房的差别：投币练歌房=无人·小规模·便宜的自助方式，一般练歌房(卡拉OK)有店员常驻布置包厢，出问题能立刻叫人。不过遥控器操作方式几乎一样，这张表在哪种店都能直接用。
  • 实在搞不定：只要知道曲号(见⑤)，不搜索也能直接点歌播放 — 记住这条最后的绕行路线。
