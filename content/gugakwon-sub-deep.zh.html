📍 国立国乐院 (首尔瑞草区)

国立国乐院 (Gungnip Gugagwon / 국립국악원)，瑞草区 (Nambusunhwan-ro 2364 / 남부순환로 2364)，☎ 02-580-3300，是传承韩国传统表演艺术的国立艺术机构。除演出外，还开展学术研究、国乐教育和海外交流。

国立国乐院起源于新罗时代以来流传的宫廷音乐机构。光复后宫廷音乐机构被解散，以旧王宫雅乐部 (Gu-wanggung Aakbu / 구왕궁아악부) 的形式保留下来，1951年延续为国立国乐院。编制于1950年公布，但因战争，1951年在釜山开院，收复后经由云泥洞 (Unni-dong / 운니동) 和奖忠洞 (Jangchung-dong / 장충동) 办公楼，1987年迁至现在的瑞草洞 (Seocho-dong / 서초동) 办公楼。据观光公社介绍(2010年为准)，它隶属文化体育观光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)，曾运营正乐团 (Jeongakdan / 정악단)、民俗乐团 (Minsok-akdan / 민속악단)、舞蹈团 (Muyongdan / 무용단)、创作乐团 (Changjak-akdan / 창작악단) 四个演奏团。

  • 开放时间:09:00~18:00。休息日:每周日。
  • 费用:因演出而异。
  • 停车:免费。车位已满时，请自费使用附近的收费停车场。

国立国乐院礼乐堂 (Gungnip Gugagwon Yeakdang / 국립국악원 예악당)(同一地址，☎ 02-580-3300)，是位于国立国乐院内、拥有658余席的国乐专用演出场馆。位于艺术殿堂 (Yesurui Jeondang / 예술의전당) 旁边。观众席分成土墙形状，舞台上方有盾牌风筝 (Bangpaeyeon / 방패연) 形状的音响反射板。是3层建筑，1层和2层不分层相连，3层设有名为“别座 (Byeoljwa / 별좌)”和“别右 (Byeoru / 별우)”的包厢座席。主要演出国乐管弦乐、乐歌舞综合剧、唱剧。

  • 演出时间·费用:因演出而异。休息日:每周日。

📍 国立国乐博物馆 (首尔瑞草区)

国立国乐博物馆 (Gungnip Gugak Bangmulgwan / 국립국악박물관)(同一地址，☎ 02-580-3130)，是展出国乐文物和乐器的国乐专业博物馆，1995年开馆。据观光公社介绍，是韩国国内唯一的国乐专业博物馆。设有介绍韩国传统音乐历史和流派的常设展览，也举办海外音乐文物邀请展、国立国乐院乐器研究成果展等特别展览。2019年新开放的常设展厅加强了聆听功能。可以观看并体验所藏的乐器、乐谱、乐书和服饰文物。

  • 开放时间:10:00~18:00(入场截止 17:30)。休息日:每周一(周一为法定节假日时开馆，次日周二休息)，1月1日。
  • 费用:免费。停车:收费。

📍 宗庙大祭 (首尔钟路区宗庙)

宗庙大祭 (Jongmyo Daeje / 종묘대제)，钟路区宗庙 (Jong-ro 157 / 종로 157, Jongmyo / 종묘)，☎ 1522-2295，是供奉朝鲜王朝历代国王和王后的神主 (Sinju / 신주) 并进行祭祀的祭礼仪式。在宗庙正殿 (Jeongjeon / 정전)，礼乐与佾舞 (Ilmu / 일무) 共同呈现。1969年复原后延续至今，因其仪礼·舞蹈·音乐融为一体的综合仪礼价值而获得认可，2001年被列入联合国教科文组织人类非物质文化遗产代表作名录。自2006年起，作为邀请国内外来宾的国际活动举办。每年5月第一个周日举行。

  • 2026年日程:2026年5月3日在宗庙举办了。时间为10:00~17:30，费用为免费。
  • 节目:永宁殿 (Yeongnyeongjeon / 영녕전) 祭享(10:00~12:00)，正殿 (Jeongjeon / 정전) 祭享(14:00~16:30)，神室参观(16:30~17:30)。在景福宫兴礼门 (Gyeongbokgung Heungnyemun / 경복궁 흥례문) 广场和 YouTube 上进行了直播。
  • 相关机构:国家遗产厅 (Gukga Yusancheong / 국가유산청)，国家遗产振兴院 (Gukga Yusan Jinheungwon / 국가유산진흥원)。

⚠ 行前须知 3 点

  1. 休息日不同 — 国立国乐院 (Gungnip Gugagwon / 국립국악원) 和礼乐堂 (Yeakdang / 예악당) 每周日休息，国立国乐博物馆 (Gungnip Gugak Bangmulgwan / 국립국악박물관) 每周一休息。
  2. 演出费用因演出而异 — 国立国乐院和礼乐堂没有登记固定费用。国立国乐博物馆免费。
  3. 2026年宗庙大祭已经结束 — 2026年5月3日举办了。每年5月第一个周日举行。
