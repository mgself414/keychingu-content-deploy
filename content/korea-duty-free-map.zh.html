🎯 本指南的使用方法

在收银台，店员核对护照，递给你的不是商品而是收据 — 购物袋要在出境那天到机场领取。本指南把离开韩国的旅客去哪家免税店、怎么买分成三类: 市中心的市内免税店、出境区的机场免税店、网页和App上的网上免税店。分店地址和营业时间，只采用今天直接从乐天·新罗·新世界·现代各免税店官方分店介绍读到的数值。

退税(在普通商店购物的增值税返还)与免税店是不同的制度，请看#1231 退税指南。机场提货处的领取流程另有#1332 提货处手册。旧版指南里的东大门 (Dongdaemun / 동대문) 批发市场不是免税店，所以删掉了。东大门购物请看#583 东大门市场购物。

旧版指南把新罗免税店写在"汉南 (Hannam / 한남)"，把新世界免税店写在"江南 (Gangnam / 강남)"。官方分店介绍中，新罗免税店首尔店的地址是中区 (Jung-gu / 중구) 东湖路 (Dongho-ro / 동호로) 249号(新罗酒店旁)。新世界免税店官方分店介绍里只有明洞店·仁川机场店。"销售额第一"、"折扣更好"之类的说法没有出处，已删除。

🏙 市内免税店 — 5处

  • 乐天免税店明洞本店 (Lotte Myeonsejeom Myeongdong Bonjeom / 롯데면세점 명동본점) — 首尔中区 (Jung-gu / 중구) 乙支路 (Eulji-ro / 을지로) 30号，9~12层。09:30~20:00(各品牌打烊时间不同)。分店电话 02-759-6600，总机 1688-3000(乐天免税店官方分店页面)
  • 乐天免税店世界塔店 (Lotte Myeonsejeom Woldeutawojeom / 롯데면세점 월드타워점) — 首尔松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Ollimpik-ro / 올림픽로) 300号，艾维纽尔蚕室店 (Avenuel Jamsiljeom / 에비뉴엘 잠실점) 8·9层。10:30~19:30。分店电话 02-3213-3700(乐天免税店官方分店页面)
  • 新罗免税店首尔店 (Silla Myeonsejeom Seoul-jeom / 신라면세점 서울점) — 首尔中区 (Jung-gu / 중구) 东湖路 (Dongho-ro / 동호로) 249号。09:30~20:00，全年无休。总机 1688-1110。从3号线东大入口站 (Dongdaeipgu-yeok / 동대입구역) 5号出口走到新罗酒店 (Silla Hotel / 신라호텔) 正门，乘坐酒店班车。把出租车收据交给服务台，可领到当日型预付卡10,000韩元(每月1次)(新罗免税店官方分店页面)
  • 新世界免税店明洞店 (Sinsegye Myeonsejeom Myeongdongjeom / 신세계면세점 명동점) — 首尔中区 (Jung-gu / 중구) 退溪路 (Toegye-ro / 퇴계로) 77号，新世界百货本店8~12层。周一~周四 10:30~20:00，周五~周日 10:30~20:30(含公休日)。4号线会贤站 (Hoehyeon-yeok / 회현역) 7号出口。客服中心 1661-8778(新世界免税店官方分店页面)
  • 现代免税店贸易中心店 (Hyeondae Myeonsejeom Muyeokjungsimjeom / 현대면세점 무역센터점) — 首尔江南区 (Gangnam-gu / 강남구) 德黑兰路 (Teheran-ro / 테헤란로) 517号，8·9层。周一~周四 10:30~20:00，周五~周日 10:30~20:30，全年无休。从2号线三成站 (Samseong-yeok / 삼성역) 5号出口可直接通到百货商店地下一层。总机 1811-6688(现代免税店官方分店页面)

✈ 机场免税店 — 3处

  • 新罗免税店仁川机场T2店 (Silla Myeonsejeom Incheon Gonghangjeom T2 / 신라면세점 인천공항점 T2) — 仁川机场第2航站楼。06:30~21:30。以2号出境口为准，主要店铺在251·252·253号登机口一带(新罗免税店官方分店页面)
  • 新世界免税店仁川机场店 (Sinsegye Myeonsejeom Incheon Gonghangjeom / 신세계면세점 인천공항점) — 仁川机场第1·2航站楼3层。第1航站楼 06:30~21:30(全年无休，部分店铺24小时)，第2航站楼 06:30~21:30(新世界免税店官方分店页面)
  • 乐天免税店金浦机场店 (Lotte Myeonsejeom Gimpo Gonghangjeom / 롯데면세점 김포공항점) — 金浦机场国际航站楼3层。06:10~20:30。从金浦飞往日本·中国·台湾时使用(乐天免税店官方分店页面)
  • 机场店铺只有办完出境检查后才能进入。自动通关请看#1412 SES·智能通关手册

💻 网上免税店 — 下单截止取决于出境时间

  • 要用出入境者本人ID登录购买。注册·下单时填写的国籍·出生日期·性别·护照上的英文姓名·护照号码若与护照不同，就无法领取商品(乐天免税店官方使用指南)
  • 下单截止时间由库存位置和出境时间决定。例: 要领取乐天明洞本店库存商品，并在00:00~02:00从仁川出境，需在出境前一天14:30前下单(乐天免税店官方可下单时间)。现代贸易中心店库存商品，03:00~16:59出境的话，截止到前一天19:30(现代免税店官方购物使用指南)
  • 出境日期最晚在出境3天前变更，且只能改为下单日起150天以内的日期(乐天免税店官方使用指南)

📋 谁、带什么去 — 共同条件

  • 谁: 出境前往海外的本国人和外国人。包括济州岛在内的国内旅行不能购买。必须由出境本人购买(乐天免税店官方使用指南)
  • 带什么: 实体护照。在机场提货处出示登机牌和实体护照，确认护照信息一致后签字领取(乐天免税店官方提货处介绍)
  • 限额: 出境时外国人购买免税品没有限额。再次入境韩国时，每人免税限额为800美元(乐天免税店官方使用指南)
  • 领取: 在市内·网上购买的商品，只能在出境当天到指定提货处领取。没有送货上门。出境当天提货处人多，请在出境前1小时前往。自出境日起超过15天不领取，订单将被取消(乐天免税店官方使用指南·提货处介绍)

🥗 饮食 — 在免税店食品区

  • 新罗首尔店介绍说卖食品，乐天金浦机场店介绍说卖红参 (Hongsam / 홍삼)(各官方分店页面)。先看成分表里有没有猪肉·明胶·咸鱼酱 (Jeotgal / 젓갈)
  • 素食: VisitKorea提示购物时要确认"纯素认证标志"(VisitKorea素食旅行提示)
  • 清真: 免税店官方页面上没有确认到清真认证商品的标注。VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的Eid (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15号，每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF / 한국이슬람교중앙회) 认定的少数清真餐厅之一。认证可能变动，访问前请先确认
  • 展示用卡片请看#1300 饮食需求手册

🧰 免税购物实用信息 — 独自·预约·支付·领取·交通

  • 独自·预约: 不需要预约，直接去。只要带上护照和出境航班信息
  • 支付: 银行卡·移动支付的整体介绍请看#527 支付系统
  • 领取: 提货处位置和顺序请看#1332 提货处手册。再次入境韩国时购买的液体·凝胶类商品必须托运(乐天免税店官方使用指南)
  • 与退税搞混时: 在百货商店·超市购买的商品如何退税，请看#1304 机场自助机流程版
  • 交通: 去市内免税店的地铁请看#1298 三种交通卡怎么选。与百货商店串联的路线请看#449 百货商店·购物中心指南

⚠ 常见的4个错误

1. "在市内免税店买的东西可以直接拿走" — 要在出境当天到机场·港口提货处领取(乐天免税店官方使用指南)

2. "去济州的国内航班也能买免税品" — 包括济州在内的国内旅行不能购买(乐天免税店官方使用指南)

3. "新罗免税店在汉南，新世界免税店在江南" — 新罗首尔店在中区 (Jung-gu / 중구) 东湖路 (Dongho-ro / 동호로) 249号，新世界免税店的官方分店是明洞店·仁川机场店

4. "英文姓名拼写大概填一下就行" — 下单信息与护照不一致就无法提货(乐天免税店官方提货处介绍)
