⚠ 免税购物 3 大误区

1. “免税 = 只有机场” — 未了解市内免税店: 以为只有机场。实际上还有乐天 (Lotte / 롯데) 明洞 (Myeongdong / 명동)·蚕室 (Jamsil / 잠실)·新罗 (Shilla / 신라) 汉南 (Hannam / 한남)·新世界 (Shinsegae / 신세계) 江南 (Gangnam / 강남) 市内免税店 + 入境后购物·仁川机场 (Incheon Airport / 인천공항) 提货·#449。

2. “退税 = 自动” — 未了解退税流程: 以为自动退税。实际上需要30,000韩元+收据·退税柜台·仁川机场 (Incheon Airport / 인천공항) 退税 + 退税率 7~10% (#434 子项)。

3. “免税 = 只有韩语” — 未了解 #191 中国 英文服务: 以为只有韩语。实际上乐天 (Lotte / 롯데)·新罗 (Shilla / 신라)·新世界 (Shinsegae / 신세계) 提供英文·中文·日文服务，是外国游客狂热者第一 + #191 中国·#194 美国游客友好。
