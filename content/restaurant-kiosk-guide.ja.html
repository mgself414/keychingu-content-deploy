韓国のキオスク注文、パニックゼロマニュアル — 画面そのまま真似するだけ

🎯 このマニュアルの読み方 — 画面表記のルール

この記事は「何をすべきか」ではなく、「画面に何が表示され、どのボタンを、どんな順番で押すのか」をそのまま書き記したものです。出国前にベッドの中で一度目を通しておけば、機械の前で初めて見る画面ではなくなります。

  • 画面内のボタンは角括弧で表記: [ 持ち帰り (포장) ]
  • 画面タイトル・案内文はかぎ括弧で表記: 「注文方法の選択 (주문 방법 선택)」
  • 手で行う動作は太字: 「カードを下の投入口に奥まで挿入」

① なぜ韓国の飲食店には店員の代わりに機械があるのか

韓国の外食産業では人件費の上昇と非対面志向が重なり、注文の自動化が非常に速いスピードで進みました。マクドナルド・バーガーキング・KFCなど主要ファストフードチェーンはほとんどの店舗でキオスクが基本の注文窓口となっており、格安コーヒーチェーン(メガコーヒー (메가커피)・コンポーズコーヒー (컴포즈커피) など)ではキオスクがなければ注文自体を受け付けない店舗も珍しくありません。焼肉店・粉食店(軽食店)はテーブル上のタブレットへの移行が進んでいます。

つまり「機械がある=不親切」ではなく、「機械こそがカウンター」なのです。この構造さえ理解すれば半分は終わったも同然。残り半分がこのマニュアルです。

  • Aタイプ: まず画面の隅にある国旗アイコンか [ English ] ボタンを探しましょう。あればこの記事の半分は不要になります。

③ 共通6ステップ・マスターフロー — どの機械でもこの順番

韓国のキオスクはブランドが違っても下記の6ステップから外れることはありません。

ステップ 画面に表示されるもの 押すボタン 落とし穴
1 「店内でお召し上がりですか? (매장에서 드시나요?)」 [ 店内 (매장) ] または [ 持ち帰り (포장) ] この画面を飛ばして最後に聞いてくる機械もある
2 メニュー写真のグリッド+左側のカテゴリータブ 欲しいメニューの写真をタッチ 写真がそのまま言語になる — 文字が読めなくても写真で選べる
3 「オプション選択 (옵션 선택)」ポップアップ(セット/サイズ/ショット・シロップ) [ 単品 (단품) ] vs [ セット (세트) ]、選択後 [ 選択完了 (선택 완료) ] オプションのポップアップを閉じないと次に進めない — 操作が止まったら十中八九この画面
4 「カート (장바구니)」(入れた商品リスト+合計) 追加注文 または [ 決済する (결제하기) ] [ 決済する (결제하기) ] は画面の一番下にある大きなボタン
5 「ポイント/クーポン (적립/쿠폰)」ポップアップ [ スキップ (건너뛰기) ] / [ いいえ (아니오) ] 観光客は100%スキップでOK — 韓国の電話番号を入力する画面なので
6 「決済方法の選択 (결제 수단 선택)」→ カード投入 [ カード決済 (카드 결제) ] → カードをICチップを上向きにして奥まで挿入 振動なしで数秒待つ。抜き取りを促す音(「ピッ」)が鳴ったら抜く

終わるとレシートに番号が印字されます。壁のモニターにその番号が表示されたら、ピックアップカウンターで受け取りましょう。これで全部です。

⑤ 決済の分岐点 — 海外カードが拒否された時こそが本番

韓国の決済網(VAN)は独自規格のため、国際EMV標準に対応した端末は少数派です。そのため同じVisa/Mastercardのカードでも、機械では拒否され、カウンターでは通るということがよくあります。これはあなたのカードの問題ではなく、韓国のインフラの特性です。

状況 対応
キオスクがカードを弾く タップ(コンタクトレス)ではなく挿入でもう1回試す → ダメなら未練なくカウンターへ
カウンターのない無人店舗 別のカード(発行会社が違うもの)を試す → 現金併用の機械か確認(紙幣投入口)
何度も韓国を訪れる旅行者なら WOWPASS(外国人向けプリペイドカード、主要駅・空港の発行機で入手可)または ティーマネー (티머니) の残高決済を事前に準備 → 詳細は決済深掘り編 #527
現金しかないのにカード専用の機械 スタッフを呼ぶ([ 呼出 (호출) ] ボタンまたはカウンター) — ほとんどの場合、手動で決済処理してもらえます
  • Samsung Pay・Apple Pay: Apple Payが使える店舗は増えていますが、まだ運次第です。物理カード2枚(発行会社の異なるもの)を持つのが一番安全な組み合わせです。
  • 現金の予備として3~5万ウォンを常に持ち歩いていれば、どんな拒否にあっても平常心を保てます。

⑥ チェーン別・実践ウォークスルー — その店の画面そのまま

🍔 マクドナルド (Aタイプ、英語対応あり)

1. 最初の画面下部の国旗アイコン → [ English ]

2. 「Eat In or Take Out?」 → 選択

3. メニュー → バーガーをタッチ → 「Meal or Item only?」 → オプション(ポテト・ドリンクの変更可)

4. [ Checkout ] → ポイント画面 [ Skip ] → カード挿入

  • 特徴: 翻訳の完成度が一番高い。初めてのキオスク体験はマクドナルドで予行演習するのが最適です。

🍔 ロッテリア (롯데리아)(Bタイプに近い、英語ボタンはあるが一部翻訳のみ)

1. 言語ボタンがあれば切り替える — ただし、メニュー名の一部は韓国語のまま残ります

2. 「店内/持ち帰り (매장/포장)」 → メニュー写真をタッチ → [ 単品 (단품) ] / [ セット (세트) ] の選択が必須ポップアップ

3. [ 決済する (결제하기) ] → ポイントのポップアップ [ スキップ (건너뛰기) ] → カード挿入

  • 特徴: セットオプションのポップアップがマクドナルドより段階が多い。操作が止まったら画面のどこかにある [ 選択完了 (선택 완료) ] を探しましょう。

☕ メガコーヒー (메가커피)(Bタイプ、韓国語オンリーの店が多数)

1. 言語ボタンがない店舗が多い — ④のサバイバル単語で正面突破

2. 「店内/持ち帰り (매장/포장)」 → コーヒーの写真をタッチ → オプションのポップアップ: HOT / ICE、サイズ、ショット追加 (샷 추가)

3. [ カートに入れる (담기) ] → [ 決済する (결제하기) ] → ポイント用の電話番号画面 [ スキップ (건너뛰기) ] → カード

  • 特徴: 格安コーヒーチェーン(コンポーズコーヒー (컴포즈커피)・ペクタバン (빽다방) も同じ構造)は画面の流れがほぼ同じです。1つ覚えれば全部通用します。

⑦ パニックシナリオ3 — 実際に起きることと心理的な対処法

1. 後ろに列が長い — 韓国人でも平均1~2分はかかります。後ろから急かす文化ではないので、深呼吸しましょう。どうしても気になるなら、いったん脇にどいてこのページの③のフローを見直してから再挑戦しても、誰も何も言いません。

2. 押し間違えて変な画面になった — 万能の解決策: [ 最初に戻る (처음으로) ] または左上の [ ← ]。キオスクは決済前まで何も確定しません。

3. じっとしていたら最初の画面に戻った — 30秒~1分入力がないと自動リセットされる機械が多いです。故障ではありません。最初からもう一度押し直せば大丈夫です。

⑧ プランB — どうしても機械がダメな時

  • カウンター注文が可能か見分ける: カウンターにスタッフが常駐していてPOS端末が見えれば、たいてい口頭注文を受け付けてくれます。キオスクの横に「カウンター注文可能 (카운터 주문 가능)」の案内がある店もあります。
  • スタッフを呼ぶひとこと: 「ドワジュセヨ (도와주세요)」(助けてください) — このひとこと+キオスクを指差せばOKです。韓国のスタッフはキオスクのヘルプ要請に慣れています。
  • 画面を見せる方法: Papago/Google翻訳に "I'd like to order this. Card payment doesn't work." を韓国語に翻訳させて、画面ごと見せる → アプリのセットアップは必須アプリ編 #1230。
  • 同行者とのシミュレーション: 同行者の1人がこのページの③の表を読み上げ、もう1人が操作すると、初めての実践が一番楽になります。
