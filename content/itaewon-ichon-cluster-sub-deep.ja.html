龍山ガイド — 梨泰院・漢南・二村漢江、無料博物館3カ所と子ども庭園、2026年公式データ

サブタイトル: 国立中央博物館 無料・水土21時 / 戦争記念館 無料・月曜休館・09:30~17:40 / 龍山こども庭園 無料開放(火~日、土曜は21時) / 龍山家族公園 24時間 / リウムは漢江鎮駅・アモーレパシフィックは新龍山駅 / 梨泰院 10・29 記憶と安全の道 — 2026-10-08 時点の各機関・ソウル市公式ページ基準。国立ハングル博物館は2028年下半期まで休館

カテゴリー: A 郊外・自然

サブクラスター: 街+漢江サブディープ #583・#706 クロス

親ディープ: #583 梨泰院・#706 漢江公園

※ 差別化 — #583 = 梨泰院ショッピング中心・#710 = 梨泰院の国際的な街 + 二村漢江 + 龍山日帰りルートのフルセット (昼+夜クラスター)

🎯 このガイドの使い方

龍山はソウルで無料博物館がいちばん集まっている場所です — 国立中央博物館(無料、水・土は21時まで)、戦争記念館(無料、月曜休館)、そして2025年末に全面開放された龍山こども庭園(無料)。さらに漢南洞のリウム美術館・アモーレパシフィック美術館、二村の漢江、梨泰院の夜の街が、地下鉄で3駅ほどの範囲に収まっています。以下の値は2026-10-08に各機関・ソウル市の公式ページで読み取ったものだけを記し、二村漢江公園の施設・梨泰院駅の出口・Nソウルタワーのように公式ページを読めなかったものは「未確認」としています。以前のガイドにあった「龍山公園 2027年開放予定」(こども庭園はすでに開放済みで、残りは未定)・「二村駅 1号線」(実際は4号線・京義中央線)・「梨泰院駅からリウム」(実際は漢江鎮駅1番)・「漢江花火大会 二村」(実際は汝矣島)は誤りだったため外しました。

🏛 博物館3カ所 — すべて無料

  • 国立中央博物館(ソビンゴ路137): 常設展は無料、水・土は21時まで、庭園は07~22時、休館日は1/1・旧正月・秋夕(公式)。10月の特別展は#350。二村駅から歩きます(出口番号は公式に掲示なし — 二次情報源では2番)。
  • 戦争記念館(梨泰院路29): 09:30~17:40(入場締切 17:00)、月曜休館、無料(公式)。屋外展示場の航空機・戦車まで見て回って1~2時間。最寄りは三角地駅。
  • 国立ハングル博物館: 2028年下半期まで休館(公式バナー)。立ち寄らないでください。

🌳 龍山こども庭園・龍山家族公園 — 旧米軍基地の今

  • 龍山こども庭園(漢江大路38キル21): 2025-12-30から予約なしで全面開放(ソウル市)。火~金・日 09~18時、土 09~21時、月曜休み。以前のガイドにあった「龍山公園 2027年開放」は確定ではありません — 2026年8月に敷地への住宅供給計画をめぐってソウル市と龍山区が反対するなど、未定です(報道)。
  • 龍山家族公園(龍山洞4街13): 24時間・無料、西氷庫駅1番から673m(ソウル市 2023年資料 — 古い値です)。

🖼 漢南 — リウム・アモーレパシフィック

  • リウム: 火~日 10~18、月曜休館、統合チケット 25,000ウォン・常設展無料、漢江鎮駅1番(6号線) — 梨泰院駅ではありません。4言語のデジタルガイドあり。
  • アモーレパシフィック美術館: 火~日 10~18、月曜休館、ソル・ルウィット展 18,000ウォン オンライン予約、新龍山駅1番。詳細は#350。
  • 漢南洞 (Hannam-dong / 한남동) のギャラリー名は公式ページで読み取れなかったため記しません。

🌃 梨泰院 — 夜の街と追悼

  • 梨泰院 (Itaewon / 이태원) はソウル初の観光特区(1997)として知られていますが、今回は公式の説明ページを開けなかったためラベルを付けません。飲食店・バーの名前も記しません。
  • 記憶と安全の道10・29 (10.29 Gieokgwa Anjeonui Gil / 10·29 기억과 안전의 길): 2022年の惨事があったハミルトンホテル (Hamilton Hotel / 해밀톤호텔) の隣の路地で、2023年から追悼の空間として開放(二次情報源; 公式サイトは証明書エラー)。通るときは静かに。
  • ソウル中央聖院 (Seoul Jungang Seongwon / 서울중앙성원)(イスラム寺院)は公式ページを開けなかったため年を記しません。

🌉 二村漢江 — 博物館の次に

  • 二村漢江公園は、国立中央博物館から歩いて下りていく漢江です。自転車・渡し場・便利施設は公式ページの本文が開けず未確認。漢江バス・遊覧船・噴水は#786。
  • 花火大会は汝矣島(9/5、終了)です — 二村ではありません。

🚶 一日のルート

  • 昼: 三角地駅の戦争記念館(無料) → 龍山こども庭園(月曜休み) → 二村駅の国立中央博物館(無料) → 二村漢江を散歩。
  • 夜: 水・土は博物館が21時まで → 漢江鎮のリウム(18時までなので昼に) → 梨泰院で夕食。

⚠ よくある間違い5

1. 月曜日の戦争記念館・こども庭園・リウム・APMA — すべて休館。開いているのは国立中央博物館だけです。

2. 国立ハングル博物館に行く — 2028年下半期まで休館。

3. リウムを梨泰院駅から — 漢江鎮駅1番です。

4. 「龍山公園 開放」を信じる — 開放されているのはこども庭園だけ。残りは未定です。

5. 二村で花火大会 — 汝矣島です。

⚙ FAQ 6

1. 無料で一日? — 戦争記念館 → 龍山こども庭園 → 国立中央博物館、すべて無料です。

2. 夜に開いている所は? — 国立中央博物館は水・土21時、龍山こども庭園は土曜21時。

3. 子ども連れなら? — 龍山こども庭園(予約なし)・戦争記念館の屋外展示。

4. 英語は? — リウムは4言語ガイドあり。国立の2館は公式に掲示なし。

5. 二村駅の路線は? — 4号線・京義中央線。

6. 梨泰院の追悼空間は? — ハミルトンホテルの隣の路地、記憶と安全の道10・29。
