⚠ 외국인 자주 실수 5가지

1. "외국인 인스타 = 시내만": 외국인 인스타 = 도심 (DDP·별마당) + 야경 (반포·남산·롯데) + MZ (성수·도산·익선) + 외곽 (강릉·전주·부산) + 4축 매트릭스.

2. "DDP·별마당 = 그냥 건축": DDP = Zaha Hadid 45,000 LED + 외국인 인스타 1번지 + 별마당 13m wall = 외국인 인스타 #1 + 시너지 (DDP·코엑스 #142·#172).

3. "반포 달빛무지개분수 = 야간만": 반포 = 한국 #1 야경 + 4월 벚꽃 (#385·#303) + 한강 (#06·#308) + 외국인 인스타 1번지 + 4계절 풀세트.

4. "성수·도산·한남 = 카페만": 성수·도산·한남 = 카페 (#381) + 옛 공장 (#366) + MZ 매니아 #1 + 외국인 인스타 1번지 + #387 K-pop + #389 K-Beauty + #401 의료관광 통합.

5. "외곽 인스타 = 못 감": 외곽 = 강릉 도깨비 (#378)·전주 한옥 800채 (#255)·부산 감천 (#143)·#385 4계절 + KTX 1박2일·외국인 매니아 1번지.
