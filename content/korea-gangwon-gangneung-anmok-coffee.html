🎯 왜 강릉 가이드인가

강릉 (Gangneung) = 한국 #1 커피 도시·안목해변 = 한국 #1 커피거리 (40+ 카페)·경포대·정동진 일출·초당두부·강릉 한정식. 외국인 페인포인트 = (a) "강릉 = 일반 해변" 잘못된 인식 (b) 한국 #1 커피 도시·테라로사·보헤미안 등 시그너 카페 (c) 경포대 = 관동팔경 #3 (d) 정동진 = 한국 #1 해돋이 매트릭스 (간절곶 다음) (e) 초당두부 = 강릉 단독 시그너 (f) KTX 1시간 56분.

본 가이드는 5축 12 시그니처 + 안목해변 + 경포대 + 정동진.

⚠ 외국인 자주 실수 5가지

1. "강릉 = 일반 해변": 한국 #1 커피 도시·안목해변 40+ 카페.

2. "커피 = 어디서나 동일": 테라로사·보헤미안 = 한국 #1 스페셜티 매니아 매트릭스.

3. "경포대 = 일반 호수": 관동팔경 #3 1326년·단오제 UNESCO 2005.

4. "정동진 = 일반 해변": 한국 #1 해돋이 매트릭스·1995 SBS 모래시계 드라마.

5. "초당두부 = 일반 두부": 강릉 단독 시그너·다른 도시 X.

⚙ FAQ 6개

1. 외국인 입문 1순위: 안목해변 + 경포대 + 초당두부 = 5시간.

2. 테라로사: 한국 #1 스페셜티 커피·핸드드립 시그너·MZ + 매니아 매트릭스.

3. 단오제 (6월): UNESCO 무형문화유산 2005·외국인 매니아 매트릭스 #1.

4. 정동진 일출: 새해 1/1 매니아·연중 OK·일출 시간 사전 확인.

5. 시즌: 봄·가을 베스트·여름 (해변)·겨울 = 새해 매트릭스.

6. 추천 페르소나: 가족·시니어 = 안목해변 + 초당두부 / MZ·인스타 = 테라로사 + 정동진 / 매니아·문화 = 단오제 + 경포대 + 한정식.
