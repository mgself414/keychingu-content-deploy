🎯 なぜ韓国蒸しマトリックスなのか

外国人韓国蒸しペインポイント= "蒸し鶏だけ知って別の蒸し知らない"。韓国蒸し= 限定式本物+マッコムマニア+ MZトレンド。同じ「Korean steamed/braised dish」でもチキンチム（安東チムチキン本格#1）・カルビチム（韓定食・宮中本物）・アグチム（マコム#1・MZインスタ）・シーフード蒸し正統派）・ドングランチム（名節正統派）。外国人は（a）安東チムチキン=全国#1マニアモール（b）カルビチム＝限定式本物のモル（c）アグチム＝マコム#1モル（d）メギチム＝全裸本物のモル。本ガイドは6種マトリックス+本格+マコムマニア。

🥘 6種 deep dive

🐔 アンドンチムチキン (Andong-jjimdak) — 本物 #1

  • シグネチャー: 安東正統 #1・醤油マコム・当面・全国 #1
  • 材料：鶏+醤油・スパイシーな味付け+当面・じゃがいも・玉ねぎ・にんじん
  • おすすめ店：安東正統・全国安東チムチキンcluster・MZ韓国料理店
  • 価格：25,000〜50,000ウォン/ 1棟（2〜3人）
  • 外国人親和性: ★★★★★ (#1本物)

🥩 カルビチム (Galbi-jjim) — 限定式 #1

  • シグネチャー: 限定式本格・宮中・醤油味付け
  • 材料：牛カルビ+醤油・おなか・にんじん・しいたけ・松の実
  • おすすめ店舗: 限定式 ([#837](#837))・新羅ホテルラヨン・三清閣
  • 価格: 限定式コース 40,000～150,000ウォン(含む) / 単品 30,000～60,000ウォン
  • 外国人親和性: ★★★★★ (限定式#1)

🐟 アグチム (Agu-jjim) — マコム #1

  • シグネチャー: マコム#1・MZインスタ・もやし
  • 材料: アグー(monkfish) + もやし・スパイシースパイス
  • おすすめ店: 馬山正統・ソウル老舗・MZ韓国料理店
  • 価格：25,000〜50,000ウォン/ 1棟（2〜3人）
  • 外国人親和性: ★★★★ (マコムマニア)

🦀 シーフード蒸し (Haemul-jjim) — シーフード

  • シグネチャー：シーフードクロス・マコム
  • 材料: イカ・エビ・貝・もやし+マコム調味料
  • おすすめ店: チャガルチ・統営・シーフード専門店
  • 価格: 30,000～80,000ウォン/1館（2～3人）
  • 外国人にやさしい: ★★★

🐠 メギチム (Megi-jjim) — 全羅本物

  • シグネチャー: 全羅正統・マコム・老舗
  • 材料: ナマズ(catfish) + シラギ・マコム調味料
  • おすすめ店舗:全羅老舗・江原本場
  • 価格：20,000〜40,000ウォン/ 1棟
  • 外国人にやさしい: ★★

🥩 LAカルビチム (LA-style) — グローバル

  • シグネチャー：グローバル・MZトレンド・アメリカ式
  • 材料：LAリブ（薄さ）＋醤油・おなじ味付け
  • おすすめ店: MZ韓国料理店・グローバル店舗
  • 価格：25,000〜50,000ウォン/ 1棟
  • 外国人親和性: ★★★★ (グローバル)

⚠外国人の頻繁な誤り5つ

1. "蒸し=一つ":蒸し=6種マトリックス。

2. "安東蒸し鶏=一般":安東蒸し鶏= 全国正統#1・醤油マコム。

3. "カルビチム=高価だけ": カルビチム= 限定正統・宮中cluster。

4. "アグチム=軽さ": アグチム=マコム#1(韓国で最もスパイシーなメニューの一つ)。

5. "メギチム=一般": メギチム= 全羅正統・老舗。

⚙ よくある質問8件

1. 外国人入門1位：安東蒸し鶏+カルビ蒸し。

2. インスタ・vlog: アグチム（マコム#1）・アンドンチムチキン。

3. MZ トレンド: アグチム・LAカルビチム。

4. マコムマニア：アグチム（#1）。

5. 限定的な本物: カルビ蒸し。

6. アレルギー: シーフード・醤油グルテン事前告知。

7. 決済・チップ: カードOK/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

蒸し＝一般食品・マコム一部。妊婦・子ども＝OK（スパイシー調節）。アレルギー（シーフード・醤油グルテン）事前告知。食中毒の疑いがある場合☎1339。

食事制限fallback：ハラール・コーシャー＝鶏・牛・シーフードOK・豚含有X/ベジタリアン・ビーガン=非菜食/グルテン free=Tamari。
