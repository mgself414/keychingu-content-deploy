⚠ 외국인 자주 실수 5가지

1. "서울만 = 한국": 한국 = 서울 + 부산 (해운대·BIFF) + 인천 (차이나타운) + 대구·광주·대전·울산 6 광역시 + 수원·전주·경주·제주 도청 + 외국인 1번지 풀세트 + #430·#512·#398 통합.

2. "부산 = 해운대만": 부산 = 해운대·광안리·BIFF (10월) + 자갈치·국제시장 (#380) + 외국인 1순위 + 부산 영화제 매니아 1번지 + #380·#530 통합.

3. "전주·경주 = 외국인 어려움": 전주·경주 = KTX 1시간 30분 + 외국인 영어 OK + 한옥마을 (#379) + 불국사·석굴암 UNESCO + 외국인 정통 매니아 1번지 + #379·#509 통합.

4. "KTX = 비쌈": 외국인 KORAIL Pass = 3·5·7·10일 무제한 풀세트 (60~150 USD) + 외국인 영어 OK + 외국인 매니아 1순위 + #398·#414 통합.

5. "제주 = 패키지만": 제주 = 렌터카 자유 여행 (#439) + 올레길 + 한라산 + 외국인 1순위 (Visa-free 30일) + 외국인 가족 1번지 + #430·#439·#525 통합.
