🎯 왜 "Korea Sool Map" 메타인가

방한 외국인 한국 술 인프라 — #190 일본 술 매니아·#193 유럽 매니아·#371 호주·NZ 매니아·#194 미국·#368 브라질 K-pop·#192 동남아 (#465 태국 불교/술 매니아)·#335 홍콩 럭셔리 segment 풀. 핵심: (1) 막걸리 = 한국 전통 발효주·세계화 진행 (장수·국순당·지평·포천도원·서울 막걸리) (2) 소주 = 한국 #1 술 (참이슬·진로·처음처럼·새로) (3) 수제맥주 cluster (이태원·해방촌·서울숲·연남) (4) 전통주 (안동소주 700년 #397·문배주·이강주·전라도 죽력고) (5) 외국인 친화 가양주·바·체험 cluster.

본 가이드는 한국 술 5축 12 시그니처 + 4 동선 + 외국인 5팁. 카테고리 메타 술·음주 axis 1편 (#450 Nightlife·#337 Food sub-deep).

⚠ Sool 실수 3가지

1. "한국 술 = 소주만" — 막걸리·전통주 미인지: 소주만. 실제로는 막걸리 (장수·국순당·지평·포천·서울장수 5대 양조장)·전통주 (안동소주 700년 UNESCO·문배주·이강주 조선왕실주) 풀체험.

2. "술 = 한국어만" — 영문 친화 cluster 미인지: 한국어만. 실제로는 이태원·해방촌 수제맥주 cluster (외국인 70%+ 영문 메뉴)·전통주 갤러리 인사동 (영문 시음)·국순당 가양주 체험 외국인 friendly.

3. "막걸리 = 1종" — 양조장 다양성 미인지: 1종. 실제로는 장수 (서울 부드러움)·국순당 (전국 표준)·지평 (양평 묵직)·포천도원 (포천 청량)·서울장수 (서울 깊은맛) — 5대 양조장 풀체험 + 무알콜 막걸리 신규.

동선 추천

[A] 외국인 술 매니아 1주 풀패키지 (#190·#193·#371)

  • D1: 광장시장 막걸리·빈대떡 (#338·#471 cluster) + 24h 음주 풀체험
  • D2: 종로·을지로 막걸리집·전통주집 + 24h 노가리 골목
  • D3: 이태원·해방촌 수제맥주 cluster (#192 동남아·#194 미국)
  • D4: 인사동 전통주 갤러리 시음 + 국순당 가양주 체험 (외국인 영문)
  • D5: 신라호텔·시그니엘 럭셔리 바 (#344·#469 빙수 연계)
  • D6: 안동 (KTX 2h·#397) + 안동소주 풀체험 (전통주·UNESCO)
  • D7: 인천공항 면세 + 막걸리·소주 픽업 + 출국

[B] 수제맥주 매니아 (#194·#371·#193)

  • 이태원·해방촌·서울숲·연남·홍대 수제맥주 cluster 1일 풀체험 + Magpie·The Booth·Hand & Malt

[C] 전통주 매니아 (#193·#367 인도·#369 중동 종교 친화·무알콜)

  • 안동소주 + 문배주 + 이강주 + 죽력고 + 전통주 갤러리 + 무알콜 막걸리 (KMF 친화·#453)

[D] 럭셔리 (#344·#335·#469 fit)

  • 신라호텔 더 라이브러리·시그니엘 더 라운지 555m + 럭셔리 칵테일 (#450 찰스 H.) + 와인 페어링

🍯 외국인 5팁

1. 막걸리 = 한국식 표준 첫 잔 — 알콜 5~6%·과일 풍미·외국인 입문 #1

2. 소주 = 1병 1,500~2,000원 — 한국 #1 가성비 술·삼겹살 페어링 (#337)

3. 수제맥주 = 이태원·해방촌·연남 — 외국인 친화 cluster·영문 메뉴

4. 전통주 = 인사동 갤러리 — 영문 시음·구매 가능 (#458 Wellness fit)

5. 호텔 바 예약 필수 — 시그니엘·신라·포시즌스 (#344·#469 호텔 빙수와 동일 패턴)
