＃＃＃①月尾島遊園地（海岸1番地）

  • シグネチャー: ディスコ・パンパン・バイキング・観覧車・韓国マニアマトリックス

  • 時間: 10:00~22:00 (季節別)・自由利用券 25,000~45,000ウォン/人

② 月尾海列車（モノレール・2.5km・韓国#1海上）

  • シグネチャー：韓国#1海上モノレール・2.5km・月尾島→仁川駅
  • 外国人親和性: ★★★★★ (英語・ピックアップ・インスタフィット)
  • 時間: 10:00～22:00 (季節別)・往復8,000～12,000ウォン/人

###③ 月尾島沿岸散歩+カフェ

  • シグネチャー：海岸路+カフェcluster・MZ +インスタfit
  • 外国人親和性: ★★★★★（英語＋決済カード）
  • 時間: 年中・夜景マトリックス #1

＃＃＃④ソレポグ水産市場（韓国マニアマトリックス#1）

  • シグネチャー：新鮮な会・シーフード・シーズンマトリックス（夏・秋#1）
  • 外国人親和性: ★★★★ (英語メニュー一部・決済カード・ピックアップ)
  • おすすめ: 市場 = コスパ（回丼8,000～15,000ウォン）・回集＝シグナー（50,000～120,000ウォン/2-3人用）

⑤ ソレポグ回集・回丼

  • シグネチャー: シグナー回集・狂語・ウルク・桃+灰丼
  • 外国人親和性: ★★★★ (英語メニュー一部・ピックアップ)
  • 価格: 回丼 = 8,000~15,000ウォン・シグナー回集 = 50,000~120,000ウォン/2-3人用

＃＃⚠外国人の頻繁な誤り5つ

1. 「月尾島＝小さな遊園地」：海岸1番地・モノレール2.5km韓国#1海上・遊園地+夜景+カフェcluster。

2. "モノレール=単純交通": 月尾海列車=韓国#1海上モノレール・インスタ+MZマニアマトリックス。

3. "ソラポグ=一般市場": 韓国マニアマトリックス#1・シーズンマトリックス（夏・秋#1）・会・シーフード新鮮度。

4. 「会＝ビリン味」：狂魚・ウルク＝アンビリン・外国人入門#1・桃・牡蠣・アワビ・カニ＝マニアマトリックス。

5. 「夏・秋のみ」：シーズンマトリックス＝カキ・カニ（秋・冬）・アワビ（夏・秋）・狂魚・ウルク＝年中OK。

⚙ FAQ 6個

1. 外国人入門1順位: 月尾島モノレール+夜景+ソレポグ回丼。

2. モノレール：往復8,000～12,000ウォン/人・平日の夜・週末=インスタマニアシーズン。

3. ソラポグ市場 vs 回集: 市場 = 苛性費（回丼8,000～15,000ウォン）・回集＝シグナーマニア（50,000～120,000ウォン/2-3人用）。

4. シーズン: 夏・秋＝新鮮な会マトリックス#1・冬＝牡蠣・アワビ・カニ・室内マニア・春＝カニ・マニア。

5. アレルギー: 回・シーフード = 甲殻類・魚アレルギー・事前告知+新鮮度確認必須。

6. おすすめペルソナ: 家族・シニア = 回丼+ウォルミド / MZ・マコムマニア = モノレール + 夜景 + カフェ / マニア = シーズンマトリックス。

⚠医療・安全・食事ダイエット

回・シーフード＝アレルギー（甲殻類・魚）・鮮度+衛生確認必須。妊婦・免疫低下・高齢者＝生会X推奨（調理オプション）。食中毒の疑いがある場合☎1339。

食事制限：

  • ハラール・コーシャ: 会・シーフード=ビハラル(生会)・調理会+クリーン魚種一部OK
  • ベジタリアン・ビーガン: 灰丼・回集 = ベジタリアン/ウォルミドカフェ = ベジタリアンOK
  • グルテンフリー: 会・シーフード自体OK・醤油抜くとOK

✈️ 外国人塗料ポイント #1 — 回衛生＋鮮度

  • 市場: 鮮度も直接確認・活き(生きている会)優先推奨
  • 回集:シグナー店=衛生・鮮度フルセット・外国人にやさしいマトリックス
  • 回丼: 安全マトリックス・市場マニアfit・コスパ
  • アレルギー: 甲殻類・魚 事前告知+店頭英文アレルゲン表記
  • 鮮度信号：活魚+店舗鮮度表示+上司直接お手入れ
