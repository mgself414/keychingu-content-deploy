夕食のあとに、2~3軒を歩いてはしごしながら飲みたい旅行者向けの回です。ひとつの店に長く座るのではなく、街をひとつ決めて店の間を歩いて回る「パブクロール」のやり方です。地下鉄駅から歩いて行けて、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した営業情報があり、2026年10~11月に投稿された訪問レビューや写真がある店だけを残しました。

⚠ 表記の原則: 営業時間・定休日は、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した値です(2026-11-24確認)。価格は、カカオマップのメニューのうち登録日が2年以内のものだけを使いました。カクテルバーのように登録価格が古い店は、日付のあるネイバーブログの訪問レビューの値を使い、出典を横に付けました。食事面のヒントはメニュー名から読み取れるものだけを書いたので、材料とアレルギーは注文前にスタッフに確認してください。店の間を歩く距離はOpenStreetMapの徒歩ルートで測った値で、駅から店まで歩く時間・出口はカカオマップの道案内の値です。

① カンナム駅 — クラフトビール2軒

2軒はカンナム駅の両側にあり、互いに1.2km(歩いて15分あまり)離れています。どちらか1軒を選ぶほうがよいでしょう。

グースアイランド ブリューハウス (Goose Island Brewhouse / 구스아일랜드 브루하우스)

アメリカ・シカゴの醸造所グースアイランドの名を掲げた2階建てのパブです。カカオマップのタグにルーフトップが付いています。月~土 11:30~24:00、日曜 11:30~23:00なので、昼から飲めます。ネイバーブログのレビュー(2026-11-15)に書かれた価格は、黒ビールのブラックホールが₩7,500、カンナムスタイル セゾンが₩9,000、甘柿トリペルが₩10,000、チーズバーガー シカゴピザが₩36,000です。別のレビュー(2026-11-22)には、平日ランチの2人セットが₩38,000と出ています。住所は江南区 (Gangnam-gu / 강남구)のヨクサム路118 (Yeoksam-ro 118 / 역삼로 118)、カンナム駅(2号線・新盆唐線)4番出口から歩いて8分です。

  • 食事面のヒント: シカゴピザはチーズが厚く入り、チーズバーガーピザには牛肉が入っています。バーベキュープラッターのような肉のメニューが中心です。ベジタリアン向けと確認できたメニューはありません。

ビアルーム (Beer Room / 비어룸)

カンナム駅の北側の路地にあるクラフトビールと窯焼きピザの店です。水~日 11:30~23:30、月・火 定休です。お酒はグラス単位でも売っていますが、酒類・ドリンクの飲み放題が目立ちます。カカオマップの登録価格は飲み放題 ₩30,000(2025-08-07)で、ブログレビュー(2026-10-12)には1時間 ₩15,000、3時間 ₩30,000の2種類が書かれています。飲み放題にはクラフトビール・ワイン・ハイボールが入ります。おつまみの登録価格は、ウェッジポテト ₩6,000、プルダックチーズソースを添えたナチョス ₩5,000、マルゲリータ ₩26,000(2025-12-11)、ディアボラピザ ₩36,000です。住所は江南区 (Gangnam-gu / 강남구)のカンナム大路98ギル22 1階 (Gangnam-daero 98-gil 22 / 강남대로98길 22 1층)、カンナム駅11番出口から7分です。

  • 食事面のヒント: マルゲリータには肉は入っていませんが、チーズが入っています。ディアボラとサラミのメニューは、たいてい豚肉の加工肉を使います。ポテトは肉の入っていないメニューです。ナチョスに添えるプルダックチーズソースは辛く、乳製品が入っています。

② チョンダム トサンデロ55ギル — カクテルバー3軒

アックジョンロデオ駅(水仁盆唐線)4番出口から2~4分の路地に3軒が集まっています。3軒ともキャッチテーブルで予約を受けています。ル・チャンバーとアリスは、1人あたりのカバーチャージが別にかかります。

ゼスト (ZEST / 제스트)

果物の皮のように捨てられる材料をカクテルに再利用する「ゼロウェイスト」のバーです。The World's 50 Best Bars 2026のリストで7位に入っています(the50.com, 2026-11-24確認)。月~金 18:30~02:00、土・日 15:00~02:00で、週末は午後から開きます。2026-11-05に投稿されたブログレビューにはカクテル1杯 ₩26,000、ノンアルコールのナチュラルコーラ ₩15,000と書かれていますが、書いた人が約1年前に訪れたときの価格です。2026-02-21のカカオマップのレビューには、バーテンダーが英語でよく説明してくれるという内容があります。住所は江南区 (Gangnam-gu / 강남구)のトサンデロ55ギル26 1階 (Dosan-daero 55-gil 26 / 도산대로55길 26 1층)です。

  • 食事面のヒント: カクテルごとに旬の果物・ハーブ・シェリーなど材料が違います。カカオマップの要約に「一部ノーキッズゾーン」が付いています。

ル・チャンバー (Le Chamber / 르챔버)

本棚の形をした隠し扉から入る地下のバーです。入口の右にある本棚の一番上の段の本を押すと扉が開きます(ブログレビュー 2026-09-27)。月~木 19:00~03:00、金・土 19:00~04:00、日・祝日 19:00~02:00で、この回でいちばん遅くまで開いています。注文とは別にカバーチャージ 1人 ₩10,000がかかります(ブログレビュー 2026-10-05)。カクテルのほかに、ウイスキーをボトルで注文してキープすることもできます(同じレビュー)。カカオマップの要約には、ピアノの生演奏があると出ています。2026-05-20のカカオマップの英語レビューには、スタッフの対応がよく、価格帯は高めだったと書かれています。住所は江南区 (Gangnam-gu / 강남구)のトサンデロ55ギル42 地下1階 (Dosan-daero 55-gil 42 / 도산대로55길 42 지하 1층)です。

  • 食事面のヒント: カカオマップの要約によると、基本のおつまみとしてポテトチップスとプレッツェルが出ます。お酒中心のバーなので、食事のメニューは期待しないでください。

アリス (Alice / 앨리스)

「不思議の国のアリス」をテーマに飾った地下のカクテルバーです。毎日 18:00~02:00です。ブログレビュー(2026-11-20)によると、カバーチャージ 1人 ₩10,000(ウェルカムドリンク込み)で軽いおつまみが一緒に出て、シグネチャーカクテルはすべて₩27,000です。メニューはトランプカードの形で、カードの数字がアルコール度数を表します。焼酎・いちご・コチュジャンを混ぜたカクテルのように、韓国の材料を使った1杯もあります。住所は江南区 (Gangnam-gu / 강남구)のトサンデロ55ギル47 地下1階 (Dosan-daero 55-gil 47 / 도산대로55길 47 지하 1층)です。

  • 食事面のヒント: カクテルの材料に焼酎・果物・タレ類まで使われるので、アレルギーがあれば注文前に伝えてください。お酒が飲めない場合は、ウェルカムドリンクも事前に確認してください。

③ ノクサピョン・ヘバンチョン — 3軒

ノクサピョン駅(6号線)前のノクサピョン大路 (Noksapyeong-daero / 녹사평대로)から、ヘバンチョンのシンフン路 (Sinheung-ro / 신흥로)まで坂道でつながっています。ジニパブとダンクヤードは月曜定休です。サウスサイドパーラーもカカオマップでは月曜定休と登録されていますが、2026-11-19のブログレビューには月曜営業と書かれています。

サウスサイドパーラー (Southside Parlor / 사우스사이드팔러)

アメリカ・テキサス風のタコス・カクテルバーで、4階にあり、カカオマップのタグにダーツとルーフトップが付いています。ブログレビュー(2026-04-26)もカカオマップの要約も、外国人のお客さんが多いと書いています。カカオマップの登録時間は火~木 18:00~01:00、金・土 18:00~02:00、日 18:00~01:00、月 定休です。ただ、2026-11-19のブログレビューは月曜営業と週末17:00オープンを書いているので、月曜はインスタグラムのお知らせを見てください。登録価格(2026-07-01)は、タコス3個 ₩16,000、ケサディーヤ ₩16,000、バッファローまたはフライドチキンサンドイッチ ₩18,000、シーザーサラダ ₩12,000です。ブログレビューによると、カクテルは₩18,000(2026-11-19、シーズンのシグネチャーカクテル2杯を基準)、マグパイ ペールエールとカルメギIPAは₩9,000(2026-09-29)です。同じ11月のレビューによると、お酒を一緒に注文すると、火曜はタコスが1個 ₩4,000、水曜はウィングが半額です。住所は龍山区 (Yongsan-gu / 용산구)のノクサピョン大路218 4階 (Noksapyeong-daero 218 / 녹사평대로 218 4층)、ノクサピョン駅3番出口から7分です。

  • 食事面のヒント: メニューにビーガンチョリソータコスがあります。フィッシュタコスは魚、チキンタコスとウィングは鶏肉です。タコスのトルティーヤと衣の材料は、注文のときに聞いてください。

ジニパブ (Genie Pub / 지니펍)

ヘバンチョンの大通りシンフン路にある3階のカジュアルなカクテルパブです。火~木 18:00~01:00、金 18:00~02:00、土 17:00~02:00、日 18:00~01:00、月 定休です。カカオマップの登録価格(2026-10-06)は、ピーチクラッシュ・キューバリブレ ₩12,000、モスコミュール ₩13,000、ネグローニ・ロングアイランドアイスティー ₩14,000、シグネチャーの「ノクサピョン駅2番出口」 ₩15,000などで、全体で₩12,000~16,000です。ブログレビュー(2026-11-03)には、ビールが1万ウォン未満と書かれています。窓際の席からヘバンチョンの通りが見下ろせます。住所は龍山区 (Yongsan-gu / 용산구)のシンフン路37 3階 (Sinheung-ro 37 / 신흥로 37 3층)、ノクサピョン駅2番出口から12分です。

  • 食事面のヒント: カカオマップのタグにピザパブが付いていますが、おつまみの価格は登録されていません。カクテル中心と考えて行ってください。

ダンクヤード ソウル (DANKYARD / 댕크야드 서울)

自家醸造のビールと音楽を一緒に出す2階のブルワリー兼リスニングバーです。火~木 18:00~24:00、金・土 18:00~01:00、日 16:00~23:00、月 定休です。ビールの登録価格(2025-12-02)は、ラガー ₩9,000、ヌグッ ₩11,500、ポーター・ジニスタウト ₩12,500、キョンポ ダブルIPA ₩16,000、アイスボック ₩27,000です。料理はラザニア ₩20,000(2026-06-16)が登録されています。カカオマップのレビュー(2026-02-07)には、ビールのラインナップが毎月変わると書かれています。住所は龍山区 (Yongsan-gu / 용산구)のシンフン路5ギル11 2階 (Sinheung-ro 5-gil 11 / 신흥로5길 11 2층)で、ジニパブから45mです。

  • 食事面のヒント: カカオマップの要約に「ベジタリアンメニュー」が付いています。どのメニューかは注文のときに聞いてください。ラザニアにはたいていチーズとミートソースが入っています。

④ シンヨンサン — 1軒

ハンドアンドモルト ブリューラボ (Hand and Malt Brew Lab / 핸드앤몰트 브루랩)

クラフトビールの醸造家ハンドアンドモルトのタップルームで、シンヨンサン駅の裏の「ヨンリダン通り (Yongridan-gil / 용리단길)」にあります。月~木 17:00~23:00、金 17:00~24:00、土 14:00~24:00、日 14:00~23:00です。ブログレビュー(2026-10-29)によると、ソウルIPA 340mLが₩8,600です。おつまみの登録価格(2025-09-13)は、コチュジャンラグートッポッキ ₩17,900、おこげチーズじゃがいもチヂミ・カマンのフィッシュアンドチップス ₩19,900、鶏ののど肉の塩焼き ₩22,900です。1階の片側の壁が一面の窓です。住所は龍山区 (Yongsan-gu / 용산구)のハンガン大路38ガギル19 (Hangang-daero 38ga-gil 19 / 한강대로38가길 19)、シンヨンサン駅(4号線)1番出口から5分です。ノクサピョンから2.2km離れているので、梨泰院のコースとつなぐならバスかタクシーに乗ります。

  • 食事面のヒント: カカオマップのメニュー説明によると、コチュジャンラグートッポッキは、牛のひき肉で煮込んだラグーソースに牛バラの焼き肉をのせた米のトッポッキで、カマンのフィッシュアンドチップスはイカ墨の衣をつけて揚げたカレイです。じゃがいもチヂミにはチーズが入っています。鶏ののど肉は鶏肉です。

🗺 歩いて回る2コース

A. チョンダムのカクテル (3軒の間で合計160m)

  1. 18:30 アックジョンロデオ駅4番出口 → ゼスト (ZEST / 제스트)(4分)。週末は15:00から開きます
  2. 20:00ごろ ル・チャンバー (Le Chamber / 르챔버)へ移動(118m、2分)。19:00に開きます
  3. 21:30ごろ アリス (Alice / 앨리스)へ移動(42m、1分)

1杯ずつしか飲まなくても、カバーチャージが2回(1人 ₩20,000)かかります。金・土に遅くまで続けるなら、04:00まで開いているル・チャンバーを最後にします。

B. ノクサピョン → ヘバンチョン (店の間は約650m、坂道)

  1. 18:00 ノクサピョン駅3番出口 → サウスサイドパーラー (Southside Parlor / 사우스사이드팔러)(7分)。タコスとビールで夕食の代わりにします
  2. 20:00ごろ シンフン路沿いにジニパブ (Genie Pub / 지니펍)まで610m(歩いて8分あまり、坂道)
  3. 21:30ごろ 45m隣のダンクヤード (DANKYARD / 댕크야드)でビールで締めます。金・土は01:00までです

火~日に合わせたコースです。月曜はジニパブとダンクヤードが休みで、サウスサイドパーラーはカカオマップ上は定休ですが、2026-11-19のレビューには営業と書かれているので、インスタグラムのお知らせを見て行ってください。

⚠ よくある失敗3つ

  1. 月曜にBコースを組む — ジニパブとダンクヤードは月曜が定休日です。サウスサイドパーラーはカカオマップ上は月曜定休ですが、2026-11-19のレビューには月曜営業と書かれています。ビアルームは月・火が休みです。
  2. カバーチャージを知らずに入る — ル・チャンバーは注文とは別に1人 ₩10,000、アリスはウェルカムドリンク込みで1人 ₩10,000がかかります。アリスはシグネチャー1杯にカバーチャージを足すと1人 ₩37,000です。
  3. 身分証なしで出かける — バー・パブは入店時や注文時に年齢を確認します。外国人はパスポートの原本を持っていくのがいちばん確実です。

⚙ よくある質問3つ

  1. 何歳からお酒を飲める？ — 青少年保護法は19歳未満を青少年としますが、19歳になる年の1月1日を過ぎると青少年から外れます。誕生日とは関係なく生まれた年で数えるので、2026年は2007年以前に生まれた人がお酒を買えます。同じ法律は、青少年にお酒を売ることを禁じ、売る側に年齢と本人かどうかの確認を義務づけています。この回の店はお酒が中心なので、未成年者は一緒に入ってもお酒を注文できず、入店自体を断る店もあります。
  2. ベジタリアンや豚肉を食べない場合は？ — サウスサイドパーラーのビーガンチョリソータコス、ビアルームのマルゲリータとポテトが、メニュー名から確認できます。ダンクヤードはカカオマップの要約にベジタリアンメニューが表示されています。カクテルの材料にバター・卵・乳製品が入ることがあるので、ベジタリアンやビーガンなら注文のときに確認してください。
  3. 予約は必要？ — チョンダムの3軒とサウスサイドパーラー・ハンドアンドモルトは、キャッチテーブルの予約ページがカカオマップにつながっています。金・土の夜にチョンダムへ行くなら、予約しておくほうがよいでしょう。ビアルームの飲み放題は、ブログレビュー(2026-10-26)に、ネイバー予約で利用券を買ったという内容があります。
