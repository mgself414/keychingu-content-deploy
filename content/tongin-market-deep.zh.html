🎯 如何使用这份指南

这份指南汇集了景福宫西边西村可去的地方。1941年开办的Tongin市场和便当咖啡馆、保留着胡同和韩屋的西村村庄、从仁王山流下来的Suseong-dong溪谷、有朝鲜社稷坛的社稷公园、公共韩屋Seochon Lounge。除了Tongin市场(各店不同)和Seochon Lounge，西村村庄·Suseong-dong溪谷·社稷公园·社稷坛登记为全年无休·全天开放。北村·益善洞一带请看钟路区域的各篇，想一次逛多个市场，可以看#604 首尔传统市场入门指南。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 市场 — Tongin市场

Tongin市场 (Tongin Sijang / 통인시장)，钟路区 (Jahamun-ro 15-gil 18 / 자하문로15길 18)，☎ 0507-1378-0940，始于1941年6月为孝子洞 (Hyoja-dong / 효자동) 附近的日本人建立的公设市场。6·25战争后西村人口增加，公设市场周围出现了摊贩和商铺，形成了市场。2005年登记为认定市场后配备了现代化设施，2010年被首尔市和钟路区选为“首尔型文化市场”。

据韩国观光公社介绍，商铺有70多家，餐厅和小菜店等餐饮商户最多。其次是蔬菜·水果·鱼·肉店，也有内衣等工业品和衣服修改店。2012年1月起运营便当咖啡馆“通”。

  • 开放时间:市场商铺07:00~21:00，便当咖啡馆11:00~15:00。
  • 休息日:各店不同。停车:可以。

📍 胡同和溪谷 — 西村村庄·Suseong-dong溪谷

西村村庄 (Seochon Maeul / 서촌마을)，钟路区 (Pirun-daero 45 / 필운대로 45)，☎ Bukchon游客中心 02-2148-4161，是指景福宫西边村子的名字。保留着老店、韩屋和迷宫般的胡同，胡同各处有粉彩色的壁画和图画。据介绍也是电影、电视剧、音乐录影带的取景地。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

Suseong-dong溪谷 (Suseong-dong Gyegok / 수성동계곡)，钟路区 (Ogin-dong / 옥인동)，☎ 02-2148-2844，是从仁王山流下来汇入清溪川的溪谷。水声大而清澈，据说朝鲜时代把这个地方叫做水声洞 (Suseong-dong / 수성동)。收录在谦斋郑敾 (Gyeomjae Jeong Seon / 겸재 정선) 描绘北岳山和仁王山8处景致的“壮洞八景帖 (Jangdong Palgyeongcheop / 장동팔경첩)”里，是朝鲜时代地理书中介绍的名胜。1971年建起Ogin Sibeom公寓 (Ogin Sibeom Apateu / 옥인시범아파트) 后失去了景观，40年后拆除公寓并被指定为文化遗产保护区域，恢复了本来的样子。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

📍 朝鲜的祭坛 — 社稷公园·社稷坛

社稷公园 (Sajik Gongwon / 사직공원)，钟路区 (Sajik-ro 89 / 사직로 89)，☎ 钟路区厅公园营造组 02-2148-2836，是位于仁王山东南山麓的公园，面积188,710㎡。以朝鲜太祖李成桂1395年与宗庙一同最初建造的社稷坛为中心。有儿童游乐场、Yulgok Yi I (율곡 이이) 与Sin Saimdang (신사임당) 的铜像、射箭场Hwanghakjeong (황학정)、市立儿童图书馆。据介绍，沿公园旁的仁王山路走5分钟左右就是仁王山登山路。

  • 开放时间:全天开放。休息日:全年无休。停车:每5分钟300韩元。

社稷坛 (Sajikdan / 사직단)，钟路区 (Sajik-ro 89 / 사직로 89)，☎ 02-739-7205，是祭祀土地神和谷神的祭坛。宗庙供奉国王和王妃的神位，社稷则供奉土地神和谷神。以景福宫为中心，左边是宗庙，右边是社稷。中间不是建筑而是空的祭坛，还有8座Hongsalmun门 (Hongsalmun / 홍살문)，连王陵也只立一座。朝鲜时代只有国王、王族和担任相关职务的人才能进入。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

📍 在韩屋里休息 — Seochon Lounge

Seochon Lounge (Seochon Lounge / 서촌라운지)，钟路区 (Pirun-daero 27-4 / 필운대로 27-4)，☎ 02-736-7909，是首尔公共韩屋。向首尔市民和来韩国的所有人开放，介绍韩屋居住文化。有关于韩屋设计和K-工艺的国内外书籍，介绍文写道，希望这里成为一边喝茶、一边品味首尔韩屋新日常的时光。

  • 开放时间:周二~周四·周六~周日11:00~19:00，周五12:00~20:00。
  • 休息日:每周一、法定节假日。费用:免费。

⚠ 行前须知 3点

  1. Tongin市场便当咖啡馆只在11:00~15:00营业 — 市场商铺是07:00~21:00。
  2. Seochon Lounge周一和法定节假日休息 — 周五是12:00~20:00。
  3. 西村村庄·Suseong-dong溪谷·社稷坛不能停车 — Tongin市场和社稷公园登记为可以停车。

⚙ FAQ 2

Q. Tongin市场便当咖啡馆什么时候营业?

A. 按观光公社登记信息是11:00~15:00。2012年1月起运营。

Q. 不花钱的地方有哪些?

A. 西村村庄、Suseong-dong溪谷、社稷坛、Seochon Lounge登记为免费。
