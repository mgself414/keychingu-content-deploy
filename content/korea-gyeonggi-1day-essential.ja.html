🎯 誰のために、なぜ四つのコースなのか

京畿道はソウルを取り囲んでいるので、「京畿道の一日」は方向を選ぶことです。南(水原・龍仁)、北(坡州DMZ)、東(加平・楊平)は路線が違うため、一日にひとつの方向だけを選びます。

ソウルに泊まって一日を京畿道で過ごしたい旅行者向けです。冬に休むところや時間が変わるところを表示しました(確認できなかったところは、そのように書きました)。場所ごとの詳しい話は#1032・#1033・#1034・#1035にあり、ここでは方向・組み合わせ・閉まる時間だけを整理しました。

⚠ 表記の原則: 時間・料金は運営主体の公式ホームページまたはカカオマップの登録値です(すべて2026-11-25確認)。出典は値の横に書きました。移動時間は公式案内に書かれているものだけを写し、残りはカカオマップの道案内でその日に確認してください。

① 水原 — 城郭ひと回りとトンダク通り

華城行宮から城郭とトンダク通りまで、すべて歩いて行けます。

  • 水原華城 — 朝鮮の正祖 (Jeongjo / 정조)の時代に築かれた城郭で、今は市街地を囲む散歩道です。水原文化財団の観覧案内に「1月~12月常時、年中無休、料金無料」とあり、開放型なので夜も歩けます(2026-11-25確認)。財団のおすすめコースには1~3時間のものがあります。西将台 (Seojangdae / 서장대)のほうは上り坂です。
  • 華城行宮 — 王が水原に滞在するときに使った宮殿です。09:00~18:00、入場は閉まる1時間前まで、年中無休です。大人₩2,000、青少年₩1,500です。華城行宮・水原華城博物館 (Suwon Hwaseong Museum / 수원화성박물관)・水原博物館 (Suwon Museum / 수원박물관)の共通券は大人₩4,000です(すべて水原文化財団、2026-11-25)。韓服 (Hanbok / 한복)(改良韓服を含む)の着用は免除・減免の対象に載っています(公式の表に免除・減免の区別はありません)。毎月最後の水曜日は無料です。夜間開場は2026-05-01~11-01の期間だったので、冬はありません。住所は八達区 (Jeongjo-ro 825 / 정조로 825)です。
  • チンミトンダク (Jinmi Tongdak / 진미통닭) — トンダク通り (Jeongjo-ro 800beon-gil / 정조로800번길)にあるチキン屋です。火~日 11:00~23:00、月曜定休、ソルラル(Seollal)・チュソク(Chuseok)の連休も休みです。登録価格はフライド・丸ごとチキン ₩21,000、ヤンニョム・半半 ₩22,000、カレーチキン・チンチャンポンチキン ₩25,000、生ビール500cc ₩4,500です(カカオマップ オーナー登録、メニュー登録2026-05~06、2026-11-25確認)。住所は八達区 (Jeongjo-ro 800beon-gil 21, 2F / 정조로800번길 21 2층)です。食事面のヒント: 鶏肉の揚げ物なので、衣に小麦粉が入っている可能性があります。豚肉メニューは登録されていません。ヤンニョムは甘みと辛みが混ざったソースです。生ビールとジムビームのウイスキーセットも売っています。
  • ヨンソントンダク本店 (Yongseong Tongdak Main Branch / 용성통닭 본점) — 同じ路地の数軒手前です。カカオマップの登録時間は11:00~23:00ですが、12月1日(火)が休みと表示されています。定休日は登録されていないので、行く前にカカオマップで確認します。登録価格はフライド・田舎チキン ₩21,000、ヤンニョム・半半 ₩22,000、王カルビ ₩24,000です(カカオマップ オーナー登録、メニュー登録2026-08-07、2026-11-25確認)。住所は八達区 (Jeongjo-ro 800beon-gil 15 / 정조로800번길 15)です。食事面のヒント: 鶏肉の揚げ物で、衣に小麦粉が入っている可能性があります。王カルビはメニューの説明が登録されていません。お酒のメニューは登録されていません。

行き方 (水原文化財団「主要地点への行き方」、2026-11-25): 江南駅 (Gangnam / 강남)から直行バス3000番に乗り、八達門 (Paldalmun / 팔달문)で降りると、行宮まで歩いて約5分です。蚕室駅 (Jamsil / 잠실)からは1007番(華城行宮・与民閣 (Hwaseong Haenggung / Yeomingak / 화성행궁·여민각)下車)に乗ります。電車なら、1号線・水仁盆唐線の水原駅 (Suwon / 수원) 4番出口のノボテル停留所で11・13番バスに乗り、華城行宮・水原聖地 (Hwaseong Haenggung / Suwon Seongji / 화성행궁·수원성지)で降ります。

② 龍仁 — エバーランドか韓国民俗村か

どちらも一日かかる場所なので、ひとつだけ選びます。

  • エバーランド — アトラクションとサファリがあるテーマパークです。カカオマップの登録時間は11/25~12/1の毎日10:00~22:00です(2026-11-25確認)。12月2日以降の時間は公式アプリで日付ごとに見ます。一日券は日付の等級別料金です。2026-10-06から₩3,000ずつ上がり、大人は最高₩71,000、繁忙期₩65,000、平時・閑散期₩55,000になりました(Money Today 2026-09-07)。値上げ前の12月が₩52,000だったので(CEO Score Daily 2026-09-24)、12月は₩55,000台と推定されます。実際の料金は決済画面で見ます。住所は処仁区 (Pogok-eup Everland-ro 199 / 포곡읍 에버랜드로 199)です。
  • 韓国民俗村 — 朝鮮時代の村を再現した屋外の民俗村です。カカオマップの登録時間は月~木 10:00~19:00、金~日 10:00~20:00で、公式のメインには「11月25日 10:00~19:00」と出ています(2026-11-25)。12~2月の時間は公式で確認できませんでした(季節・天候によって変わると告知しています)。一日券は大人の平日 ₩37,000、週末 ₩39,000です。外国人はパスポートか外国人登録証を見せると₩22,000です(公式の利用料金、「2026年まで適用」、2026-11-25確認)。12~3月の週末の午後2時入場券は大人₩25,000です。住所は器興区 (Minsokchon-ro 90 / 민속촌로 90)です。

行き方: エバーランドは江南方面の5002番直行バスがあり、2026-08-01からソウル駅 (Seoul Station / 서울역)乗り換えセンターから明洞 (Myeong-dong / 명동)・梨泰院 (Itaewon / 이태원)を通る4105番ができました(約1時間、Korea Times 2026-07-30報道)。韓国民俗村は新論峴駅 (Sinnonhyeon / 신논현) 5001-1番、江南駅1560番、ソウル駅4101番が走っています。水原駅4番出口から37番・10-5番バスに乗り換えてもかまいません(韓国民俗村公式の交通案内、2026-11-25)。

③ 坡州 — 臨津閣から出発するDMZ

個人旅行者は臨津閣 (Imjingak / 임진각)から坡州市DMZ平和観光バスに乗って、DMZの近くまで行けます。外国人はパスポートか外国人登録証の原本が必要で(コピー・スクリーンショット・期限切れは不可)、月曜は運営しません。

  • DMZ平和観光 — 臨津閣の窓口でチケットを買い、シャトルバスで第三トンネル→トラ展望台→統一村を回って臨津閣に戻ります(約3時間)。現地発券・予約発券は09:00~14:30で、一行全員がそろってから発券します。早く売り切れる日が多いです。オンライン予約メニューもありますが、外国人が使えるかは公式に書かれていません。毎週月曜、平日の祝日、ソルラル(Seollal)・チュソク(Chuseok)の当日は休むので、12/25・1/1(平日)の運営は事前に確認します。大人料金はモノレールコース₩12,200、徒歩コース₩9,200です。外国人割引・免除はありません。火~金のバスは09:20から14:40まで10回、土・日は12回出発します。モノレールが止まると徒歩コースに変わり、安全保障・気象の事情で中止されることがあります(坡州市DMZ平和観光 公式英語ページ、2026-11-25。英語サービスは準備中で、韓国語の案内と違うことがあります)。トラ展望台の道路規制の告知(2026-10-23)があってコースが変わることがあるので、行く前に坡州市(031-940-4114)に確認します。
  • 臨津閣 平和ヌリ — 平和の鐘と広い芝生の丘がある屋外公園です。入場は無料、駐車は有料(小型車₩2,000)で、駐車場は08:00~20:00に運営しています(京畿道の英語観光ページ、2026-11-25)。平和観光バスを待ちながら見て回ります。
  • 臨津閣 平和ゴンドラ — 臨津江を渡るゴンドラです。毎日09:00~18:00、年中無休ですが、12月7日(月)は安全点検のため休みます。一般キャビンは大人₩12,000です。身分証がないと乗れませんが、外国人のパスポートが認められるかは公式に書かれていません(平和ゴンドラ公式、2026-11-25)。

行き方 (DMZ平和観光 公式英語案内、2026-11-25): 京義中央線の臨津江駅 (Imjingang / 임진강)から歩いて約20分です。臨津江駅から058A・058Bのシャトルバスもあります。14:30の発券締め切りに間に合わせるには、ソウルから朝早く出発します。

④ 加平・楊平 — 川に沿って東へ

加平(京春線)と楊平(京義中央線)は路線が違うので、一日にどちらかひとつを選びます。

  • 南怡島 — 北漢江に浮かぶ島です。住所は江原道春川ですが、船は加平の船着き場から乗ります。船は毎日08:00から運航し、最終入島21:00・出島21:05です。5分ほどかかります(2026年の告知)。大人の入場券は往復の船を含めて₩19,000です(南怡島公式、2026-11-25確認)。加平駅 (Gapyeong / 가평)から船着き場まで歩いて約20分、10-4番バスやタクシーで約5分です。ソウル直行シャトルバスも毎日あります(弘大入口駅 (Hongik Univ. / 홍대입구) 09:00発、南怡島16:30発。指定業者Ktourstoryで予約)。
  • 朝の静けさの樹木園 — 加平の私設樹木園です。12/3までは08:30~19:00(入場締め切り18:00)です。12/4~2027-03-14の五色星明かり庭園展 (Five-Color Starlight Garden Festival / 오색별빛정원전)の期間は10:00~21:00、土曜だけ23:00までです(樹木園公式の利用案内use01.php、2026-11-25)。点灯は17:00からです(カカオマップ登録)。庭園展期間の入場締め切りと料金が普段と同じかは公式に書かれていません。普段は大人₩11,000で、入場券は現地の窓口のみで買えます。清平駅 (Cheongpyeong / 청평)・清平ターミナル (Cheongpyeong Terminal / 청평터미널)から30-6番バスで終点まで行きます。清平ターミナル発の樹木園行き最終は19:30、樹木園発の清平ターミナル行き最終は20:00です。21:00まで見るなら、帰りはタクシーに乗ります(清平の市街地まで約20分、公式の行き方)。
  • トゥムルモリ — 南漢江と北漢江が出合う川辺の散歩道です。入場料がなく、年中無休です(カカオマップ登録、2026-11-25)。
  • セミウォン — トゥムルモリのそばの水と花の庭園です。09:00~18:00、入場締め切り17:30です。12~3月は毎週月曜休館です(祝日なら翌日)。大人₩7,000です(セミウォン公式の観覧案内、2026-11-25確認)。京義中央線の楊水駅 (Yangsu / 양수)から歩いて700mで、江辺駅 (Gangbyeon / 강변) 2000-1番、蚕室駅2000-2番のバスも走っています(平日限定運行)。

行き方: 加平駅はITX-青春 (ITX-Cheongchun / ITX-청춘)で龍山 (Yongsan / 용산)から約60分、清凉里 (Cheongnyangni / 청량리)から約42分です。京春線の電車なら上鳳 (Sangbong / 상봉)から約50分です(南怡島公式の行き方、2026-11-25)。

🗺 動線 — 冬の一日の例

A. 水原 (毎日、ただしチンミトンダク (Jinmi Tongdak / 진미통닭)は月曜定休)

  1. 午前: 華城行宮(09:00~)。韓服の着用は免除・減免の対象です
  2. 昼過ぎ: 行宮の裏の西将台に登り、華西門 (Hwaseomun / 화서문)・長安門 (Janganmun / 장안문)のほうへ城郭を歩きます
  3. 夕方: トンダク通りでチキン。チンミ (Jinmi / 진미)は月曜に休み、ヨンソン (Yongseong / 용성)は定休日をカカオマップで先に見ます

B. 加平の昼と夜 (12/4以降)

  1. 午前: ITX-青春で加平駅へ、歩いて南怡島の船着き場へ
  2. 午後: 島をひと回りして加平駅に戻り、京春線でソウル方面の清平駅で降ります。30-6番バスで朝の静けさの樹木園へ
  3. 夕方: 五色星明かり庭園展(点灯17:00~)。30-6番の樹木園発最終バスは20:00で、その後はタクシーで清平に出ます(約20分)

C. DMZ (火~日)

  1. 朝早く: 京義中央線で臨津江駅へ、臨津閣の窓口(09:00~)
  2. 午前~昼: 平和観光バス(約3時間)
  3. 午後: 平和ヌリを散策し、時間が余れば平和ゴンドラ(~18:00)

⚠ よくある間違い3

  1. 月曜にDMZへ行く — DMZ平和観光は毎週月曜が休みです。同じ月曜に、セミウォン(12~3月)とチンミトンダク (Jinmi Tongdak / 진미통닭)も休みます。月曜は水原の城郭、エバーランド、南怡島、朝の静けさの樹木園のように年中無休で登録されている場所を選びます。
  2. パスポートの写真・コピーだけ持っていく — DMZ平和観光は外国人にパスポートか外国人登録証の原本を求め、コピー・スクリーンショット・期限切れのパスポートは受け付けません。平和ゴンドラも身分証がないと乗れません。韓国民俗村の外国人料金(₩22,000)もパスポートか外国人登録証を見せる必要があります。
  3. 一日に二つの方向を組む — 水原と加平、坡州と龍仁はソウルを横切ります。一日にひとつのコースだけを選び、DMZの日は14:30の発券締め切り前に着くように出発します。

⚙ FAQ 3

  1. 初めてで一日だけなら? — 歩くのが好きなら水原(城郭無料、行宮₩2,000)を選びます。分断の現場を見たいなら、火~日にDMZへ行きます。子どもといっしょならエバーランドか韓国民俗村へ行きます。
  2. 板門店 (Panmunjeom / 판문점)(JSA)にも行けますか? — この回の動線には入れませんでした。2026-11-25に一般の外国人見学を運営しているという公式告知を確認できませんでした。
  3. 冬の夕方に見るところは? — 朝の静けさの樹木園の五色星明かり庭園展(12/4~、点灯17:00、21:00まで・土曜は23:00まで)とエバーランド(カカオマップ登録で22:00まで)です。水原華城の城郭は夜も開いていますが、華城行宮の夜間開場は11/1に終わりました。
