한국 해산물 6종 매트릭스 — 조개·굴·꽃게·오징어·새우·낙지 풀세트

> 부제: 외국인 관광객용 해산물 6종 + 시장·횟집·꽃게탕 + 자갈치·통영·서해 정통

ISSUE 03 · #873 · 2026-06-09

🎯 왜 한국 해산물 매트릭스인가

외국인 한국 해산물 페인포인트 = "회만 알고 다른 해산물 모름". 한국 해산물 = 3해 (동해·남해·서해) + 사계절 시그니처 + 시장 매니아. 같은 "Korean seafood"라도 조개 (서해 정통·바지락·홍합)·굴 (겨울 #1·통영 정통)·꽃게 (서해 가을 #1·간장게장)·오징어 (동해 정통·울릉·동해)·새우 (전국·MZ)·낙지 (서해 정통·목포·산낙지) 각자 다른 지역·시기. 외국인은 (a) 회 cluster vs 해산물 cluster 차이 모름 (b) 통영 굴 = 겨울 1순위 모름 (c) 꽃게 = 가을 정통 (간장게장 매니아) 모름 (d) 산낙지 = 목포 정통 모름. 본 가이드는 6종 매트릭스 + 3해 + 외국인 매니아.

🦐 6종 deep dive

🐚 조개 (Jogae·바지락·홍합·키조개) — 입문 #1

  • 시그니처: 사계절·바지락 칼국수·홍합탕
  • 재료: 바지락 (clams)·홍합 (mussels)·키조개 (scallops)
  • 외국인 친화도: ★★★★ (#1 입문·글로벌)
  • 추천 시장·매장:
  • 소래포구·강화 ([#587](#587)) — 서해 정통
  • 자갈치시장 ([#590](#590)) — 남해
  • MZ 칼국수집·홍합탕 — 가성비
  • 시기: 사계절·봄 (3~5월)
  • 가격: 시장 = 10,000~25,000원/1kg / 칼국수 = 8,000~15,000원

🦪 굴 (Gul) — 겨울 #1

  • 시그니처: 통영 남해 정통 #1·생굴·12~3월 매니아
  • 재료: 굴 (oysters) 생굴·익힘
  • 외국인 친화도: ★★★★★ (글로벌 oysters·겨울 매니아)
  • 추천 시장·매장:
  • 통영 굴 전문점 — 정통 #1
  • 서울 굴국밥집 (강남·종로) — 가성비
  • 광장시장 — 시장 정통
  • 시기: 겨울 12~3월 #1 (생굴)
  • 가격: 통영 = 10,000~25,000원/1kg / 굴국밥 = 8,000~15,000원

🦀 꽃게 (Kkotge) — 가을 #1·간장게장

  • 시그니처: 서해 가을 9~11월 #1·간장게장 매니아 #1
  • 재료: 꽃게 (blue crab) 활어 + 간장 양념·매콤 양념
  • 외국인 친화도: ★★★★★ (간장게장 글로벌 #1)
  • 추천 매장:
  • 마포·강남 간장게장 전문점 — 정통 #1
  • 서해 안면도·태안·소래포구 — 가을 정통
  • 꽃게탕집 — 가성비
  • 시기: 가을 9~11월 #1
  • 가격: 간장게장 1인 = 30,000~80,000원 / 꽃게탕 = 15,000~30,000원

🦑 오징어 (Ojingeo) — 동해 정통

  • 시그니처: 동해 정통·울릉·강원 + 사계절·여름 (6~9월)
  • 재료: 오징어 (squid) 회·찜·구이·MZ 아이스
  • 외국인 친화도: ★★★★ (글로벌 squid)
  • 추천 시장·매장:
  • 울릉도·강원 동해 — 정통
  • 노량진수산시장 — 활어
  • MZ 카페 오징어 fusion (해남 매니아)
  • 시기: 여름 6~9월·사계절
  • 가격: 시장 = 5,000~15,000원/마리 / 회 = 15,000~30,000원/1인

🦐 새우 (Saewoo·대하) — 전국·가을

  • 시그니처: 전국·가을 대하 #1·새우장 MZ 트렌드
  • 재료: 대하 (king prawn) 소금구이·새우장 (간장 양념)
  • 외국인 친화도: ★★★★ (글로벌 shrimp)
  • 추천 시장·매장:
  • 서해 안면도·태안 — 가을 대하 정통
  • MZ 새우장집 (홍대·강남) — 트렌드
  • 시기: 가을 10~11월 대하 #1
  • 가격: 시장 = 15,000~30,000원/1kg / 새우장 = 25,000~50,000원/1인

🐙 낙지 (Nakji·산낙지) — 서해 목포 #1

  • 시그니처: 서해 목포 정통·산낙지 매니아 #1·낙지탕탕이
  • 재료: 낙지 (small octopus)·세발낙지·산낙지 (live)
  • 외국인 친화도: ★★★ (산낙지 = 강한 매니아·살아있는 채로)
  • 추천 매장:
  • 목포 종합수산시장 ([#671](#671)) — 정통 #1
  • 서울 산낙지 전문점 (마포·종로) — 정통
  • 시기: 가을·연중
  • 가격: 산낙지 1마리 = 15,000~40,000원 / 낙지탕 = 15,000~30,000원
  • 주의: 산낙지 = 살아있는 채로 잘게 잘라 먹음 (질식 위험·천천히 씹기)

🌊 3해 시그니처

🌊 동해 (East Sea·강원·울릉)

  • 시그니처: 오징어 (#1 동해)·대게 (속초)·문어
  • 시즌: 사계절·여름 오징어
  • 추천 시장: 동해 묵호·삼척·속초·강릉

🏝 남해 (South Sea·통영·자갈치·목포)

  • 시그니처: 굴 #1 (통영 12~3월)·도미·낙지 (목포)
  • 시즌: 겨울 굴·봄 도미·가을 낙지
  • 추천 시장: 자갈치·통영·목포·여수

🌅 서해 (West Sea·인천·소래·안면)

  • 시그니처: 꽃게 #1 (가을 9~11월)·대하·바지락
  • 시즌: 가을 꽃게·대하·봄 바지락
  • 추천 시장: 소래포구·강화·안면도·태안

⚠ 외국인 자주 실수 5가지

1. "회 = 해산물": 회 ([#864](#864)) = 활어 회 / 해산물 = 조개·굴·꽃게·새우 등 (회 X·익혀 먹기).

2. "굴 = 사계절": 굴 = 겨울 12~3월 #1 (다른 계절 = 양식 + 식중독 위험).

3. "꽃게 = 1년 내내": 꽃게 = 가을 9~11월 #1 (간장게장 정통).

4. "산낙지 = 위험": 산낙지 = 천천히 씹기·질식 위험 (작게 자르고 천천히).

5. "통영 굴 = 일반": 통영 굴 = 남해 정통 #1·생굴·연근해.

⚙ FAQ 8개

1. 외국인 입문 1순위: 조개 (바지락) + 새우 + 오징어 → 굴 (겨울).

2. 인스타·vlog: 통영 굴·서해 꽃게·목포 산낙지·자갈치.

3. MZ 트렌드: 새우장·MZ 오징어·간장게장.

4. 간장게장 매니아: 마포 (#1)·강남 정통.

5. 알레르기: 갑각류·연체동물 사전 고지.

6. 질식 위험: 산낙지 = 천천히 씹기·작게.

7. 결제·팁: 시장 = 현금·카드 / 횟집 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

해산물 = 식중독 주의 (특히 굴 = 봄·여름). 임신부 = 익힌 것 OK·생굴 X (CDC 권고). 어린이 = 한정 (산낙지 질식 위험·5세 이상). 알레르기 (갑각류·연체동물·간장 글루텐) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 6종 = 갑각류·연체동물 = 할랄 일부 OK (저자별 의견 차이·매장 확인) / 코셔 = 갑각류·연체동물 X.
  • 채식·비건: 6종 모두 비채식 / 채식 = 비빔밥·사찰음식.
  • 글루텐 free: 회·구이 OK / 간장게장·새우장 = 글루텐 일부 (Tamari 대체).
