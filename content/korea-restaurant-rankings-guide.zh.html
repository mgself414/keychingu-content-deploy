韩国美食排名怎么读 — 蓝丝带调查(Blue Ribbon Survey)·首尔美食100选·米其林指南，谁来评选、各自代表什么

副标题:本指南比较韩国美食榜单上常见的三种标志 · 蓝丝带是以读者评价评选的民间指南(《首尔的美食店2027》收录首尔1,602家，3个丝带42家) · 首尔美食100选是首尔市根据60位美食专家的推荐评选出的100家(2026年，新入选25家) · 米其林指南首尔2026的星级餐厅为42家 — 各运营方的官方发布已确认(2026-11-18)，仅地图App星级一项依据报道

🎯 如何使用这份指南

韩国餐厅的招牌、地图App和SNS上，常常出现“蓝丝带”“首尔美食100选”“米其林”这样的标志。三者评选的人、评选的方法、标志的含义都不同。这份指南整理了三者各是什么，以及最新一期各收录了多少家。

数值摘自各运营方亲自发布的官方资料(蓝丝带官方网站、首尔市新闻稿和官方网站、米其林指南官方网站)。没能确认官方原文的内容，另用“据报道”标出。

米其林指南首尔的详细内容已在#1109 首尔米其林指南2026中介绍，所以这里只写了比较所需的数字。

📍 蓝丝带调查 — 由读者评选的丝带

蓝丝带调查 (Blue Ribbon Survey / 블루리본 서베이)是民间出版社 (BR Media / 비알미디어)自2005年起发行的美食指南。据官方新闻稿，2027年版是发行的第22年。

  • 评选方法:据官方介绍，全年在官方网站收集读者评价，一年出一次书。据官方新闻稿，自2019年版起不再有专家评审团的最终评价，只凭读者评价评选，并以丝带数量而不是分数来标示结果。2027年版的评价有9万名以上读者参与。
  • 丝带的含义:据官方介绍，书中收录的餐厅都值得一去，丝带越多，意味着无论何时去都满意的概率越高。3个丝带被介绍为首尔各类别的最佳美食店。
  • 最新一期《首尔的美食店2027》 (Seoul-ui Matjip 2027 / 서울의 맛집 2027):2026年10月13日发行。收录首尔1,602家(比上年增加42家)，其中3个丝带42家，2个丝带314家，1个丝带685家。
  • 新获3个丝带的餐厅:共2家，即餐厅 (Gigas / 기가스)，地中海料理，位于Namchang洞 (Namchang-dong / 남창동)；以及餐厅 (La Yeon / 라연)，现代韩餐，位于酒店 (The Shilla Seoul / 서울신라호텔)内。3个丝带中的其余40家与上年一样保持。官方发布的3个丝带餐厅中有餐厅 (Mingles / 밍글스)·餐厅 (Mosu Seoul / 모수서울)·餐厅 (Kwonsooksoo / 권숙수)·餐厅 (Onjium Restaurant / 온지음레스토랑)·餐厅 (Jungsik / 정식당)等。
  • “新美食店19家”的含义:2027年版新闻稿中的19家不是新获丝带的餐厅数，而是最近1年内开业的“值得关注的新美食店”数量。
  • 查看渠道:官方网站(bluer.co.kr)和App。据官方网站消息(2026-10-15)，预约App CatchTable入选“2026官方合作伙伴”。未能确认英文界面。

📍 首尔美食100选 — 首尔市根据专家推荐评选的100家

首尔美食100选 (Seoul Misik 100-seon / 서울미식 100선)是首尔市评选的餐厅名单。据首尔市新闻稿，2026年版于2026年10月6日发布。

  • 评选方法:美食记者、美食旅行家、学界研究者、厨师、旅游专家等60位美食专家，每人在7个类别中每个类别推荐3家，共21家。首尔市新闻稿写的是“国内美食专家60人”，官方网站写的是“国内外美食专家60人”。评价标准，新闻稿写的是世界性·专业性·话题性，官方网站写的是独创性·专业性·话题性。
  • 2026年100家的类别:韩餐27家，西餐23家，亚洲料理15家，烧烤10家，素食8家，咖啡&甜点9家，酒吧&酒馆8家。其中25家是新入选的。今年还首次另行发布了“首尔咖啡·甜点50选”。
  • 新入选示例:首尔市新闻稿中列有新入选25家的名称。韩餐有餐厅 (Seoryeong / 서령)·餐厅 (Yurok / 유록)·餐厅 (Haenam Cheonilgwan / 해남천일관)，亚洲料理有餐厅 (Palsun / 팔선)·餐厅 (Hobin / 호빈)，西餐有餐厅 (L'Amant Secret / 라망시크레)·餐厅 (Muoki / 무오키)，烧烤有餐厅 (Mongtan / 몽탄)，酒吧&酒馆有酒馆 (Baekgom Makgeolli / 백곰막걸리)等。100家的完整名单请在官方网站查看。
  • 查看渠道:官方网站“Taste of Seoul”(tasteofseoul.visitseoul.net)。网站上有英文菜单链接，并可连接到Naver地图·Kakao地图·CatchTable·谷歌地图。未能确认英文正文。
  • 首尔美食周 (Seoul Misik Jugan / 서울미식주간):据首尔市新闻稿，2026年首尔美食周于10月23~29日举行的消息已发布。

📍 米其林指南首尔2026 — 星级·必比登推介·入选餐厅

米其林指南首尔&釜山2026，据米其林官方网站，于2026年3月5日在釜山发布。

  • 首尔星级42家:3星1家，2星10家，1星31家。据米其林官方网站，首尔的3星餐厅是餐厅 (Mingles / 밍글스)，这次也保持了3星。
  • 入选总数:首尔178家，釜山55家，合计233家。必比登推介71家和入选餐厅116家是以首尔和釜山合计的数字发布的。
  • 星级·必比登推介·入选餐厅各代表什么，以及首尔的餐厅信息，已在#1109 首尔米其林指南2026中介绍。

📍 地图App的星级有什么不同

与首尔美食100选·米其林不同，Naver地图·Kakao地图这类地图App的星级是访客留下的分数。蓝丝带同样采用读者评价，但不同之处在于一年一次以丝带的形式收入书中。

  • 据报道，Naver在2021年停止了星级显示，2026年又重新引入了星级。
  • 未能确认两个App对星级如何计算有官方帮助说明。

📍 三者放在一起看

  • 评选主体不同 — 据官方说明，蓝丝带由读者评选，首尔美食100选由首尔市汇集的美食专家评选，米其林由米其林评审员评选。丝带数量和星星数量是按不同标准标示的标志。
  • 同时上了两份以上名单的餐厅 — 餐厅 (Mingles / 밍글스)在蓝丝带2027年版3个丝带名单中，在米其林官方网站上则以3星收录。餐厅 (Palsun / 팔선)·餐厅 (Hobin / 호빈)·餐厅 (L'Amant Secret / 라망시크레)·餐厅 (Muoki / 무오키)同时在首尔美食100选2026年新入选名单和蓝丝带2027年版3个丝带名单中。
  • 每一期都会变 — 蓝丝带一年出一次书(官方介绍)，首尔美食100选2026年版有25家是新入选的。请确认餐厅所挂的标志是哪一年版，最新名单请在官方网站查看。

⚠ 事先要知道的3点

  1. “新美食店19家”不是新丝带数 — 蓝丝带2027年版的19家是最近1年内开业的“值得关注的新美食店”，新获3个丝带的是餐厅 (Gigas / 기가스)·餐厅 (La Yeon / 라연)共2家。
  2. 营业情况要另行确认 — 本指南中写的餐厅名称取自官方发布，访问前的营业情况和预约方法未作确认。
  3. 英语支持因体系而异 — 米其林有英文官方网站，首尔美食100选的官方网站有英文菜单链接。蓝丝带只确认了韩语网站。

⚙ FAQ 3

问:蓝丝带的3个丝带和米其林的星星是同一标准吗?

答:不是。据官方说明，蓝丝带由读者评价评选，米其林由评审员评选。据蓝丝带官方介绍，丝带数量表示“无论何时去都满意的概率”。

问:首尔美食100选由谁来评选?

答:据首尔市新闻稿，由60位美食专家在7个类别中推荐的结果来评选(新闻稿标为“国内”，官方网站标为“国内外”专家)。2026年版为100家，其中25家是新入选的。

问:外国人在哪里查看名单?

答:米其林请看英文官方网站(guide.michelin.com)，首尔美食100选请看官方网站Taste of Seoul(tasteofseoul.visitseoul.net)。蓝丝带请在官方网站bluer.co.kr查看，目前只确认有韩语版。
