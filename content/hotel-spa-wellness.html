⚠ 외국인 자주 실수 5가지

1. "호텔 SPA = 투숙객만": 반얀트리 SPA·신라 게란디·시그니엘·포시즌스 = 외부 데이패스 OK + 사전 예약 (특히 주말).

2. "한국 SPA = 럭셔리만": 한국 SPA = 럭셔리 호텔 SPA (50~200K) + 드래곤힐스파 (#227 24h 15K) + 외국인 매니아 풀세트.

3. "드래곤힐스파 = 찜질방만": 드래곤힐스파 = 한국 1번지 24h 찜질방 + SPA 트리트먼트 풀세트 + 외국인 vlog 1번지 (용산 #187).

4. "호텔 SPA = 비쌈": 호텔 SPA = 시그니처 트리트먼트 80~250K + 외국인 매니아 + 신혼 (#277) 1순위.

5. "외국인 호캉스 = 단독": 호캉스 = 수영장 (#356) + 조식 (#358) + 다이닝·바 (#360) + SPA (#364) 풀세트 + 외국인 매니아.

① 럭셔리 SPA (4)

  • 주소: 용산구 장충동2가 (남산)
  • 외국인 ★: ◎◎ — 한국 1번지 SPA·인피니티 풀 결합 (#356·#358·#360)
  • 가격: 시그니처 SPA 150~300K·외국인 매니아 1번지
  • 시그니처: 남산 view·라이트하우스 트리트먼트

🗺 외국인 풀데이 코스 3개

A. 럭셔리 호캉스 풀세트 (반얀트리·신라·시그니엘)

  • Day 1: 14:00 체크인 → 15:00 수영장 (#356) → 17:00 SPA 트리트먼트 (150~300K) → 19:00 다이닝 (#360) → 22:00 BAR 81
  • Day 2: 09:00 조식 (#358) → 11:00 SPA 마무리 → 12:00 체크아웃

B. 외국인 신혼 SPA 1박2일 (#277)

  • Day 1: 반얀트리 커플 SPA → BAR 81 야경 → 시그니엘 1박
  • Day 2: 조식 + 신혼 SPA 패키지

C. 가성비 호캉스 + 드래곤힐 (#227)

  • 14:00 L7 홍대 체크인 → 19:00 드래곤힐스파 (#227 24h 15K) → 익일 09:00 조식

  • 봄 3~5월: 야외 풀 + SPA 시즌 시작 + 외국인 매니아
