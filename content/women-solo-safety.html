⚠ 외국인 자주 실수 5가지

1. "한국 = 100% 안전": 한국 = 글로벌 안전 상위권 (Numbeo 75+/100) + but 외국인 여성 솔로 risk 존재 (소매치기·바가지·신체 접촉) + 매너 학습 필수.

2. "심야 택시 = 위험": 심야 택시 = KakaoT 카카오택시 (영어 OK + 위치 공유 + GPS 기록) + 외국인 안전 1번지·#398 통합·심야 N16·N26 버스.

3. "클럽·바 = 무조건 위험": 클럽·바 = #454 외국인 영어 OK 매장 + 친구 동행 + 음료 무방치 + 외국인 매니아 안전 매트릭스.

4. "사기 = 못 당함": 외국인 사기 = 명동·강남 택시 바가지 (정식 미터 요구)·환전 (#421 명동 시내 환율 #1) + #406 면세 사기 패턴 + 외국인 매니아 풀세트.

5. "119·112 = 한국어만": 119·112·1330 = 24h 영어·중문·일문·러시아·아랍어 5개 언어 + 외국인 매니아 1번지·#405 안전 풀세트.
