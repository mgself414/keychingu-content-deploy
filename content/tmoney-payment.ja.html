韓国T-money・決済・乗り換え完全ガイド — 外国人インバウンドの最優先課題

副題: T-money・Cashbee・モバイル決済・クレジットカード・外国人向け決済フルセット (地下鉄・バス・KTX・タクシー統合)

ISSUE 03 · #238 · 2026-05-19

🎯 なぜ韓国T-money完全ガイドなのか

外国人観光客の韓国インバウンドにおける最優先課題は、決済と交通カードです。韓国のT-money (ティーマネー) とCashbee (キャッシュビー)、モバイル決済、クレジットカード、そして外国人フレンドリーな決済方法 (Visa・Master・JCB・UnionPay (銀聯)・Amex (アメックス)) を網羅した完全ガイドです。外国人観光客が到着後30分以内に解決すべき最重要事項です。

★ 一目でわかる12選

⚠ 外国人がよくする間違い5選

1. 「T-moneyはチャージ式だけ」: T-moneyには3種類あります — (1) 1回用 (駅の券売機) (2) チャージ式 (コンビニエンスストア) (3) モバイルT-money (NFC)。チャージ式が外国人向けNo.1です (₩4,000 + チャージ)。

2. 「両替はどこでも」: 韓国で両替するならNo.1は明洞 (ミョンドン)・仁川空港 (インチョンゴンハン)・弘大 (ホンデ)・鐘閣 (チョンガク)・梨泰院 (イテウォン) + 銀行 (外換銀行 (ウェファンウネン)・ウリィ銀行 (ウリウネン)・ハナ銀行 (ハナウネン)・KB国民銀行 (KBクンミンウネン))。明洞が最もレートが良いです (私設両替所No.1)。仁川空港は最もレートが悪いです。

3. 「クレジットカードはどこでもOK」: 韓国ではクレジットカードは一般的にOKですが (Visa・Master・JCB・UnionPay (銀聯)・Amex (アメックス))、一部の小さな店では現金のみの場合があります。T-money + クレジットカード + 現金₩50,000 (約5,600円) 程度の携帯をおすすめします。

4. 「外国人払い戻しは自動」: 免税払い戻し (Tax Refund) は事後払い戻し (レシート提出 + 払い戻しカード)です。₩30,000 (約3,400円) 以上 + 外国人パスポート必須 + 仁川空港 (インチョンゴンハン)・金浦空港 (キンポゴンハン)・弘大 (ホンデ) が払い戻しNo.1です。

5. 「WOWPASSは韓国のT-moneyと同じ」: WOWPASS (ワオパス) は外国人専用 + 外貨両替 + 決済統合 (2022年) です。T-money機能に加え、外国人フレンドリーなNo.1カードであり、外国人インバウンドの最優先カードです。

① 交通カード (4)

1. T-money カード ★ 韓国No.1

  • 外国人向け★: ◎◎ — 韓国No.1交通カード
  • 発行: コンビニエンスストア (CU (シーユー)・GS25 (ジーエス25)・セブンイレブン・E-mart24 (イーマート24)・Ministop (ミニストップ)) で₩4,000 (約450円) + チャージ
  • 乗り換え: 30分以内に異なる路線・バスに無料で乗り換え可能 (最大4回まで)
  • 残額払い戻し: ₩500 (約60円) の保証金は払い戻し不可

2. Cashbee (キャッシュビー)

  • 外国人向け★: ◎ — T-moneyの代替 + ロッテ・BCカード統合
  • 発行: コンビニエンスストア + 一般のカードのように使用

3. RailPlus (レイルプラス)

  • 外国人向け★: ◎ — KTX・SRT + 一般の地下鉄・バス統合
  • 発行: KORAIL (コレール) 駅 + 外国人KTXマニア向けNo.1

4. WOWPASS (ワオパス) ★ 外国人専用

  • 外国人向け★: ◎◎ — 外国人専用カード + 外貨両替 + T-money + 決済
  • 発行: 明洞 (ミョンドン)・仁川空港 (インチョンゴンハン)・弘大 (ホンデ) のWOWPASSキオスク + USD・JPY・CNY・EUR両替 + 即時発行

② 外国人向けカード (1)

5. Korea Tour Card (コリアツアーカード)

  • 外国人向け★: ◎ — 外国人専用カード + 免税・観光地割引
  • 発行: 仁川空港 (インチョンゴンハン) + 明洞 (ミョンドン) + 公式ウェブサイト

③ モバイル決済 (3)

6. モバイルT-money (Android NFC)

  • 外国人向け★: ◎ — Android NFC + Naver Pay (ネイバーペイ)・Toss (トス)・KakaoPay (カカオペイ) 決済 (2024年拡大)
  • iPhoneは非対応

7. Samsung Pay (サムスンペイ) + Apple Pay (アップルペイ)

  • 外国人向け★: ◎ — 外国人カード登録 (Visa・Master) + 店舗決済
  • 韓国の店舗の90%以上が対応

8. クレジットカード直接決済

  • 外国人向け★: ◎ — 2024年拡大 + 地下鉄・バスの一部駅で直接決済
  • Visa・Master・JCB・UnionPay (銀聯)・Amex (アメックス) OK

④ タクシー・車両 (2)

9. Kakao T (カカオティー) タクシー (Kakao Taxi)

  • 外国人向け★: ◎◎ — 韓国No.1タクシーアプリ + 英語対応OK + カード決済

10. Uber Korea (ウーバーコリア) + Tada (タダ) + UT (ユーティー)

  • 外国人向け★: ◎ — Uberグローバル・UT日本統合・Tadaは韓国型

⑤ 外国人払い戻し (2 + 追加4)

11. カードキャッシュバック・払い戻し

  • ₩30,000 (約3,400円) 以上免税払い戻し (Tax Refund) + 外国人パスポート + 仁川空港 (インチョンゴンハン)・金浦空港 (キンポゴンハン) で払い戻し

12. 外国人両替 + 外貨ATM

  • 明洞 (ミョンドン)・仁川空港 (インチョンゴンハン)・弘大 (ホンデ)・鐘閣 (チョンガク) の両替所・銀行 + Citibank (シティバンク)・StanChart (スタンダードチャータード)・ハナ銀行 (ハナウネン)・シンハン銀行 (シンハンウネン) の外貨ATM

+ 追加4

  • T-money乗り換えルール: 30分以内に異なる路線・バスに無料で乗り換え可能 (最大4回まで)
  • 海外端末決済: 韓国の店舗は一般的にOK + 端末は外国のカードを認識 (ごく一部例外あり)
  • 外国人SIM: 仁川空港 (インチョンゴンハン) + 明洞 (ミョンドン) + 弘大 (ホンデ) の外国人SIM (KT (ケーティー)・SK (エスケー)・LG U+ (エルジーユープラス)) + eSIM (イーシム) 拡大
  • 外国人向けATM: 仁川空港 (インチョンゴンハン)・明洞 (ミョンドン)・弘大 (ホンデ) の24時間外貨ATM (Citibank (シティバンク)・StanChart (スタンダードチャータード)・ハナ銀行 (ハナウネン)・シンハン銀行 (シンハンウネン))

⚙ FAQ 8選

1. 外国人向けT-money発行No.1: 仁川空港 (インチョンゴンハン) + コンビニエンスストア + WOWPASS (ワオパス) (外国人専用 + 両替統合)。

2. モバイルT-moneyの使用: Android NFC + Naver Pay (ネイバーペイ)・KakaoPay (カカオペイ)・Toss (トス) 決済。iPhoneは非対応。

3. 両替No.1: 明洞 (ミョンドン) の私設両替所 (最もレートが良い) → 銀行 (外換銀行 (ウェファンウネン)・ウリィ銀行 (ウリウネン)・ハナ銀行 (ハナウネン)・KB国民銀行 (KBクンミンウネン)) → 仁川空港 (インチョンゴンハン) (最もレートが悪い)。

4. クレジットカード決済: 韓国の90%以上の店舗でOK (Visa・Master・JCB・UnionPay (銀聯)・Amex (アメックス))。一部の小さな店では現金のみの場合があるため、現金₩50,000 (約5,600円) 程度の携帯をおすすめします。

5. 外国人払い戻し (Tax Refund): ₩30,000 (約3,400円) 以上 + 外国人パスポート + レシート提出 + 仁川空港 (インチョンゴンハン)・金浦空港 (キンポゴンハン) の払い戻しブース (出国90分前には余裕を持って)。

6. Kakao T (カカオティー) の外国人利用: 英語対応OK + カード登録 (Visa・Master) + レシートも英語で発行可能。

7. 外国人SIM・eSIM: 仁川空港 (インチョンゴンハン) + 明洞 (ミョンドン) + 弘大 (ホンデ) + KT (ケーティー)・SK (エスケー)・LG U+ (エルジーユープラス) + eSIM (イーシム) (Airalo (アイラロ)・Holafly (ホラフライ) グローバルOK)。

8. 外貨ATM 24時間: 仁川空港 (インチョンゴンハン)・明洞 (ミョンドン)・弘大 (ホンデ)・市庁 (シチョン) のCitibank (シティバンク)・StanChart (スタンダードチャータード)・ハナ銀行 (ハナウネン)・シンハン銀行 (シンハンウネン)。

🗺 外国人向け1日フルコース4選

A. 仁川空港 (インチョンゴンハン) 到着後すぐ (外国人観光客の最初の30分)

  • 入国 → 両替 (仁川空港または明洞 (ミョンドン) 到着後) → T-moneyまたはWOWPASS (ワオパス) 発行 → 空港鉄道 (コンハンチョル) → ホテル

B. 外国人向け決済1日フルセット

  • 09:00 明洞 (ミョンドン) の両替所 → 10:00 T-moneyチャージ → 13:00 地下鉄・バス乗り換え無料 → 17:00 店舗でクレジットカード → 20:00 Kakao T (カカオティー) タクシー

C. 外国人免税払い戻し (出国前)

  • 08:00 ホテルチェックアウト → 10:00 明洞 (ミョンドン)・弘大 (ホンデ) でレシート整理 → 11:00 仁川空港 (インチョンゴンハン) 払い戻しブース (出国90分前には余裕を持って) → 免税払い戻し

D. 外国人向け郊外1日 (広域 + 多様な決済)

  • 09:00 T-money → 広域9号線 (クァンヨク9ホソン) → 江南 (カンナム) でクレジットカード → Kakao T (カカオティー) タクシー → 郊外でモバイル決済

🌸 シーズン・時間帯5選

  • 年中: T-moneyは24時間利用可能 + コンビニエンスストアでのチャージOK
  • 仁川空港 (インチョンゴンハン) 到着19:00～22:00: 両替ブースは比較的空いている (到着する外国人観光客が少ないため)
  • 明洞 (ミョンドン) 両替所: 09:00～21:00 (外貨直接決済) + 為替レートはリアルタイムで変動
  • モバイルT-money利用状況: 2024年拡大 + Naver Pay (ネイバーペイ)・KakaoPay (カカオペイ)・Toss (トス) の外国人決済
  • 外国人払い戻し: 祝日 (旧正月 (ソルラル)・秋夕 (チュソク)) は仁川空港 (インチョンゴンハン) の払い戻しブースが非常に混雑 → 出国2時間前には余裕を持って
