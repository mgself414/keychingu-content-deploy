⚠ 외국인 자주 실수 5가지

1. "1주일 = 서울만": 7일 = 서울 5일 + 외곽 2일 (부산/전주/강릉) 권장 + 외국인 매니아 1번지·KTX 2시간.

2. "2주일 = 너무 김": 14일 = 외국인 매니아 평균 + 서울 7일 + 부산 3일 + 전주 2일 + 제주 2일 + 외국인 매니아 1순위.

3. "외국인 7일 = 강행군": 7일 = 하루 3 매장 + 1박 호텔 + 2박 1박2일 + 외곽 1박2일 + 외국인 가성비 + 매니아 통합.

4. "신혼 = 비쌈만": 신혼 7박8일 = 시그니엘·신라·반얀트리 호텔 + 한복 + 청담 SPA + 외국인 럭셔리 매니아 패키지 + 200만~500만원/2인 가성비.

5. "솔로 = 위험": 외국인 솔로 14박 = 백패커 호스텔 + 4G·WiFi + KTO 인증·#226 호스텔 + 외국인 매니아 자유 1번지.
