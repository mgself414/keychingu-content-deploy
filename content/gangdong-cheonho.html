🎯 왜 강동·천호 단독 가이드인가

강동·천호는 강동구의 한국 선사·백제 역사 1번지·한강 동쪽·중산층 가족 결합 area — 암사 선사유적지 (한국 신석기 시대 1번지 유적, 1925 발굴) + 풍납토성 (백제 도성 유적, 사적 11호) + 천호 한강공원·광나루 (한강 동쪽) + 강동아이파크더리버몰·천호 로데오거리 (강동 청춘 핫존) 가 한 area에 압축. 한국 선사·백제 역사 deep dive + 한강 동쪽 + 외국인 가족 friendly 결합.

홍대(MZ·인디)·강남(럭셔리)·이태원(글로벌)과 비교하면 강동·천호는 선사·백제·한강 동쪽 결. 외국인 관광객 동선상 잠실에 가려져 패스되지만, 암사 선사유적지는 한국 신석기 시대 1번지 deep dive (1925 발굴, 6,000년 전 빗살무늬토기) + 풍납토성·몽촌토성은 백제 한성 도성 유적 (한국 4대 고대 국가 deep dive). #138 홍대·#173 서초·#174 서울대·#178 광진·#180 구로·#181 동작·#182 은평에 이어 ISSUE 03 ㉑편 — 키친구 최초 강동구 진입 (cluster 87건).

특히 암사 선사유적지는 외국인 한국 역사 deep dive 1번지 (한국 신석기·청동기·철기 통합 박물관). 천호 로데오거리는 강동 청춘·MZ 핫존. 둔촌 올림픽파크 인접 (잠실 동쪽). #82 잠실 자매 area.

⚠ 외국인이 자주 하는 실수 3가지

1. "강동 = 잠실 근처라 잠실만 보면 됨" — 강동 독자 가치 미인지

외국인 동선상 가장 흔한 실수. 강동을 "잠실 옆"으로만 인식해 패스하지만, 실제로는 강동은 한국 선사·백제 역사 1번지 — 암사 선사유적지 (한국 신석기 1번지, 1925 발굴) + 풍납토성 (백제 한성 도성) + 몽촌토성 = 한국 6,000년 역사 deep dive. 잠실(현대 테마파크)과 다른 결. 둔촌 올림픽파크는 잠실 자매 area.

2. "암사 선사유적지 = 그냥 유적" — 한국 신석기 1번지 가치 미인지

암사 선사유적지는 1925년 발굴, 한국 신석기·청동기·철기 통합 유적 — 한국 1번지 선사 유적지. 빗살무늬토기 (6,000년 전, 한국 최초 도자기) + 움집 복원 = 외국인 한국 고대사 deep dive 1순위. 암사역 4번 출구 도보 10분, 입장료 1,000원 (외국인 영문 안내 + 박물관 통합).

3. "천호 = 그냥 동네" — 한강 동쪽 청춘 핫존 미인지

천호는 단순 동네가 아니라 강동 청춘·MZ 핫존 — 천호 로데오거리 + 강동아이파크더리버몰 (한강뷰 쇼핑몰) + 카페·요리주점·이자카야 핫존. 5호선·8호선 천호역 환승역 + 강일·암사 신도시 인접. 잠실(2호선) 5분 거리.

강동·천호 풍경

강동·천호는 강동구 동부·서부에 위치한 한국 선사·백제 역사 + 한강 동쪽 + 가족 동네 결합 area — 1925년 암사 선사유적지 발굴 + 백제 한성(BC 18~AD 475) 풍납·몽촌토성 유적 + 2010s 천호·강일 신도시 + 강동아이파크더리버몰(2014) 개관으로 한국 고대사 deep dive + 강동 현대 결합 area로 자리잡음.

암사·풍납 sub-area는 8호선 암사역·5호선 천호역 인근 — 암사 선사유적지(신석기) + 풍납토성(백제) + 한국 6,000년 역사 deep dive 1번지.

천호·강일 sub-area는 5호선·8호선 천호역·9호선 강일역 — 천호 로데오거리 + 강동아이파크더리버몰(한강뷰) + 카페·요리주점 핫존.

고덕·명일 sub-area는 5호선 고덕역·명일역 — 고덕 비즈밸리·이케아 강동·아파트단지 + 가족 동네.

둔촌·길동 sub-area는 5호선 둔촌동역·길동역 — 둔촌 올림픽파크 + 길동 한식 정통.

광나루 sub-area는 5호선 광나루역 + 한강 동쪽 자전거 도로.

교통: 5호선·8호선 천호역 (천호·로데오) / 8호선 암사역 (선사유적지·풍납토성) / 5호선 고덕역·명일역 (고덕·이케아) / 5호선 둔촌동역 (올림픽파크) / 9호선 강일역. 카카오 택시 권장.

⚙ FAQ (8개)

Q1. 암사 선사유적지 외국인 입장?

1,000원 (외국인 동일) / 09:30~18:00 (월 휴무). 외국인 영문 안내 + 박물관 통합 (신석기·청동기·철기). 6,000년 전 빗살무늬토기·움집 복원 1순위. 8호선 암사역 4번 출구 도보 10분.

Q2. 풍납토성 어떻게 보나?

무료 + 24시간 (토성 둘레 산책 가능) — 풍납동 일대 약 3.5km. 한성백제박물관 (송파구·몽촌토성역 인근, 무료) 통합 deep dive 1순위. 외국인 영문 안내 + 한국 4대 고대 국가 백제 deep dive.

Q3. 강동 한강 자전거 코스?

광나루 → 천호 → 잠실 → 뚝섬 → 반포 → 여의도 = 약 30km 한강 자전거 도로 (한국 1번지 자전거 코스). 광나루는 한강 자전거 동쪽 출발지 + 따릉이 대여 OK. #149 자전거 가이드 동쪽 시작점.

Q4. 강동·천호 외국인 친화 매장은?

다람 강동본점·하남돼지집·스시도쿠·너구리베이글·리틀채스우드가 영어 메뉴 + 카드 결제 + 외국인 친화 표준. 119닭발은 한국 도전 음식이라 외국인 vlog 1순위.

Q5. 강동 + 잠실 연결 가능?

OK — 강동(5·8호선) → 잠실(8호선 2정거장) = 지하철 5분. 암사 선사유적지 + 풍납토성 (강동) + 몽촌토성 + 둔촌 올림픽파크 + 잠실 (송파) = 1일 한국 고대사·한강 동쪽 풀세트.

Q6. 119닭발 매운맛 외국인 가능?

3단계 매운맛 선택 OK (순한 맛·보통·매운맛). 외국인은 순한 맛부터 시작 권장. 한국 vlog·먹방에 자주 등장하는 외국인 도전 음식. 카드 결제 + 영어 메뉴 일부 OK.

Q7. 강동아이파크더리버몰 면세?

일부 매장 외국인 즉시 면세 환급 OK (30,000원 이상 + 여권). 한강뷰 쇼핑몰 (2014) + 카페·식당·영화관 풀세트. 천호역 도보 5분.

Q8. 강동 야간 안전?

24시간 안전 — 강동은 한국 중산층·가족 동네 + CCTV·사복 경찰 표준. 외국인 야간 OK. 자정 후 카카오 택시 권장.
