🍞 4채널 deep dive

🏪 체인 (Chain Bakery·파리바게뜨·뚜레쥬르)

핵심 가치: 가성비 + 즉시 + 전국 cluster #1.

  • 추천 매장:
  • 파리바게뜨 — 전국 #1 체인 (파리크라상)
  • 뚜레쥬르 — 정통 (CJ)
  • 가격 anchor: 1,500~6,000원/1개
  • 외국인 친화도: ★★★★★ (영문·즉시)

🥯 MZ 카페 (London Bagel·Knotted·MZ Cafe)

핵심 가치: MZ 인스타 #1 + 웨이팅 1~3h + 트렌드 #1.

  • 추천 매장:
  • 런던베이글뮤지엄 (안국·잠실·도산) — MZ 베이글 #1
  • 노티드도넛 (청담·도산·홍대) — MZ 도넛 #1
  • 서울마린 (강남·홍대) — MZ 크림빵 #1
  • 가격 anchor: 베이글 4,500~6,500원·도넛 3,500~5,500원
  • 외국인 친화도: ★★★★★ (MZ #1·글로벌)
  • 웨이팅: 평일 30분~1h·주말 1~3h

🥖 인디 베이커리 (Indie·연남방앗간·인디)

핵심 가치: 인디 작은 매장 + MZ 매니아 + 시그니처.

  • 추천 매장:
  • 연남방앗간 (홍대·연남) — 전통 변형
  • 인디 베이커리 (성수·이태원) — 작은 카페 cluster
  • 가격 anchor: 3,000~6,000원/1개
  • 외국인 친화도: ★★★★ (인디)

🛍 면세점·공항 (Duty-free)

핵심 가치: 진공 포장 + 통관 + 귀국 선물 #1.

  • 추천 매장:
  • 인천공항 — 단팥·소보로 진공
  • 김해공항 — 정통
  • MZ 베이커리 차밀 (런던베이글·노티드 일부) — 트렌드
  • 가격 anchor: 5,000~15,000원/팩
  • 외국인 친화도: ★★★★★ (VAT·영문)
  • 통관: 진공 1L 미만 OK·신선식 당일 권장

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 가성비·웨이팅·트렌드 완전 다름. 즉시 = 체인 / MZ = MZ 카페 / 인디 = 인디 / 귀국 = 면세점.

2. "파리바게뜨 = 프랑스": 파리바게뜨 = 한국 체인 #1.

3. "MZ = 즉시": MZ 카페 = 웨이팅 1~3h (테이블링 앱·테이크아웃).

4. "인디 = 비싸기만": 인디 = 3~6k 가성비 OK·MZ 인디 매니아.

5. "면세점 = 통관 OK": 면세점 빵 = 진공 1L 미만 + 신선식 당일 권장.

⚙ FAQ 8개

1. 첫 빵 채널 = 어디: 체인 (#1 즉시 가성비) → MZ 카페 (#1 트렌드).

2. 인스타·vlog: MZ 카페 (#1).

3. MZ 트렌드: MZ 카페 (#1)·인디.

4. 귀국 선물: 면세점 진공 (당일).

5. 가족 동반: 체인 (#1) + 면세점.

6. 알레르기·임신: [#885 disclaimer](#885) 참조.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 마트·면세점 = 가능 (5만 원 이상 즉시).

⚠ 의료·안전·식이 disclaimer

빵 4채널 모두 일반 음식. 임신부·어린이 = OK. 알레르기 (밀가루 글루텐·계란·유제품·견과류) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 일부 매장만 OK·MZ 카페 사전 확인.
  • 채식·비건: 단팥·소보로 = 일부 OK / 노티드·런던베이글 = 사전 확인.
  • 글루텐 free: MZ 베이커리 일부 글루텐 free 옵션.
