韓国の冬、何を食べる — 寒い日にシーン別で選ぶ一杯: 朝はソルロンタン・ヘジャンク、昼はカルグクス・クッパ、夜はチョンゴル・チゲ、道端ではブンオッパン・ホトク、冬至の小豆粥と旧正月連休の休業確認まで、詳細記事へのリンクと食事制限の表記

サブタイトル: 朝6~8時に開くクッパ・ヘジャンクの老舗 · 皆で囲む豆腐チョンゴル・キムチチゲ · 冬のおやつ(12~2月)は屋台の場所が固定されておらず価格は現地で · 冬至 2026-12-22 小豆粥 · 旧正月 2027-02-07(暫定、月暦要項の発表前の資料) · 牛のスープと確認できたのはソルロンタン・コムタンのみ、それ以外はスープのベースを尋ねる · 店・時間の詳細はクッパ #477・チゲ #486・麺 #480・おやつ #476・滋養食 #827で

🎯 このガイドの使い方

寒い朝、宿を出て歩いていると、いちばん欲しいのは熱いスープ一杯だ。ところが「韓国 冬 料理」で検索しても、メニュー名が並ぶだけで、今この時間にどこが開いているか、豚の出汁を避けるには何を選べばいいかは教えてくれない。このガイドはその問いにシーン別に答えるハブだ。メニューを説明する代わりに、今の自分の状況(朝・昼・夜・歩いている途中・特定の日付)に合う系統を選び、店名・営業時間・休業日が公式ページで確認できた詳細記事へ案内する。

この記事が直接書く数字は、韓国天文研究院 (Korea Astronomy and Space Science Institute / 한국천문연구원) の暦資料(冬至・旧正月の日付)と、詳細記事が2026年10月にVisitKoreaとミシュランのページで確認した営業時間・開業年・仕込み量の数点だ。料理の価格は、どの詳細記事にもウォン建てで掲載されている箇所がないため金額は書かない。ミシュランの価格記号がある店はすべて₩(最も低い段階)だ(#477・#480・#486)。残りは注文前に尋ねるのが正直な答えだ。

🍲 クッパ・タン一杯 — 老舗は朝に開き、仕込んだ分だけ売る

  • 冬の朝にいちばん役立つのは早く開く老舗だ。鍾路区のチョンジノク (Cheongjinok / 청진옥)は06:00~22:00(ラストオーダー21:30)で年中無休、骨だし (sagol / 사골)のスープに血の塊 (seonji / 선지)と牛の内臓を入れたヤンソンジ ヘジャンク (yangseonji haejangguk / 양선지 해장국)を、市庁裏のムギョドン プゴクチプ (Mugyo-dong Bugeoguk-jip / 무교동 북어국집)は平日07:00~20:00・週末07:00~15:00で年中無休、干しスケトウダラのヘジャンク一種類を出す(#486、VisitKorea 2026-10確認)。明洞のハドングァン (Hadongwan / 하동관)は月~土07:00~16:00(日曜休み)でコムタン (gomtang / 곰탕)を出し、その日に仕込んだ量が終わると閉まる(#477、ミシュラン 2026-10確認)。
  • 「午後に行くと閉まっている」が老舗のデフォルトだ。ハドングァンのように午後4時で終わる店、ハプチョンオク (Hapjeong-ok / 합정옥)のように一日約100人前がなくなると閉める店があるので(#477)、朝・昼に行くのが安全だ。ソウル8軒・釜山3軒の時間・休業日・メニューは#477に、クッパ六種類の違いは#807に、席に着いて何をどうするかは#808にある。
  • スープのベースは店ごとに違う。#477が牛骨・牛肉のスープと書いているのはソルロンタン (seolleongtang / 설렁탕)・コムタンで、テジクッパ (dwaeji-gukbap / 돼지국밥)は名前どおり豚だ。ヘジャンクは骨だし (sagol / 사골)に血の塊 (seonji / 선지)・牛の内臓(チョンジノク)か、干しスケトウダラ(プゴクチプ)だ。食材を避けたいときはメニュー名ではなくスープのベースを尋ねる — 下の🥗。

🍜 カルグクス・チョンゴル — 皆で囲む冬

  • 一人ならカルグクス (kalguksu / 칼국수)が早い。明洞のミョンドンギョジャ (Myeongdong Gyoja / 명동교자)は毎日10:30~21:00、1966年から家族で営み、メニューは四種類だけなので選びやすい(#480、ミシュラン 2026-10確認)。北村のファンセンガ カルグクス (Hwangsaengga Kalguksu / 황생가 칼국수)(骨だしスープ)・瑞草のイム・ビョンジュ サンドン カルグクス (Im Byeong-ju Sandong Kalguksu / 임병주 산동 칼국수)(アサリの澄んだスープ)も同じ記事に時間・休業日がある。
  • 複数人ならチョンゴル (jeongol / 전골)・チゲ (jjigae / 찌개)が冬の夜の基本だ。麻浦のファングムコンバッ (Hwanggeum Kongbat / 황금콩밭)は国産大豆で自家製の豆腐を使って豆腐チョンゴルを煮込み(月~金11:30~21:00・土・日11:00~21:00)、芳山市場のウンジュジョン (Eunjujeong / 은주정)は包んで食べるキムチチゲで11:30~22:00(ラストオーダー21:30)、日曜日・旧正月・秋夕の連休は休みだ(#486、VisitKorea・ミシュラン 2026-10確認)。ハム・ソーセージ入りのプデチゲ (budae-jjigae / 부대찌개)の元祖と公認されているのは議政府のオデンシクタン (Odeng Sikdang / 오뎅식당)で、ソウルでは駅三のテウプデチゲ (Daewoo Budae-jjigae / 대우부대찌개)が同じ記事にある。
  • チョンゴル・チゲは食卓の上で煮ながら皆で分けて食べるメニューだ。1人ならチゲ定食かカルグクスが楽だ。

🐟 屋台のおやつ — 屋台は場所が変わり、価格は現地で見る

  • ブンオッパン (bungeoppang / 붕어빵)・焼き芋・焼き栗・ケランパン (gyeran-ppang / 계란빵)・ホトク (hotteok / 호떡)は12~2月の冬のおやつの定番だ。屋台は場所が固定されていないので「どこにある」とは書けず、価格も公式ページに掲載されている店がない。詳細記事#476はそのため販売先のタイプ(ポジャンマチャ・コンビニ・地下鉄駅の中)と、公式に登録された固定店舗(平昌のブンオランオデン (Bungeorang Odeng / 붕어랑 오뎅)、群山・清州・釜山のホトク店、済州東門市場のホトク横丁)だけを移した。
  • 屋台が集まる場所としてVisitKoreaが案内しているのは明洞駅 (Myeongdong Station / 명동역)のフードストリート(4号線 明洞駅6番出口から左へまっすぐ)だ(#476)。
  • 焼き栗・焼き芋は今ではコンビニや地下鉄駅の中でも売っていて、蒸しパン・王マンドゥは冬にはコンビニで簡単に買える(VisitKorea、#476)。屋台が見つからなかったときの代案だ。
  • ホトクの中身にはナッツが入り、ケランパンには卵が丸ごと入っている。生地の牛乳・卵の有無は公式ページにないので、アレルギーがあれば買う前に尋ねる(#476 🥗)。

🥣 冬至の小豆粥 — 2026年12月22日

  • 2026年の冬至は12月22日(火)05:50だ(韓国天文研究院 天文宇宙知識情報 2026年暦資料。公式発表は月暦要項 (Wollyeok Yohang / 월력요항))。一年でいちばん夜が長い日で、小豆粥を食べると一つ年を取ると考えられ、小豆粥を門に撒いて厄を払った(国立民俗博物館 (National Folk Museum of Korea / 국립민속박물관)、#476)。
  • 小豆粥の専門店は冬至の一日だけ開くわけではない。ソウルの新堂洞チョン小豆粥 (Sindangdong Cheon Patjuk / 신당동천팥죽)(10:30~20:00・日曜休み)、全州の昔の小豆粥店 (Yetnal Patjukjip / 옛날팥죽집)(10:00~20:00・年中無休)、楊平のムノ里小豆粥 (Munhori Patjuk / 문호리팥죽)(11:00~19:20・月曜休み)など五軒の住所・時間は#476にあり、五軒とも価格は未掲載だ。
  • 小豆粥のスープに肉の出汁を使うかどうかは、店の公式ページにない。ベジタリアンなら注文前に尋ねる(#476 🥗)。

🍗 サムゲタンと滋養食 — 伏日に多く食べるが老舗は年中無休の表記

  • サムゲタン (samgyetang / 삼계탕)は若鶏に高麗人参・ナツメ・もち米・ナッツを詰めて煮込んだ湯で(VisitKorea、#827)、夏の伏日の料理として知られるが、鍾路区の土俗村 (Tosokchon / 토속촌)参鶏湯は10:00~22:00(ラストオーダー21:00)・年中無休、明洞の高峰参鶏湯 (Gobong Samgyetang / 고봉삼계탕)・百済参鶏湯 (Baekje Samgyetang / 백제삼계탕)は毎日09:00~22:00と掲載されている(#827、VisitKorea 2026-10確認)。三軒とも価格は未掲載だ。ナッツアレルギーは下の🥗。
  • 韓方茶で体を温めるなら#681 韓方茶と薬令市 — ソウル韓方振興センターと京東市場が一つの記事にある。

🧧 旧正月連休 — 2027年2月6~9日(暫定)、休業の表記を先に見る

  • 2027年の旧正月は2月7日(日)、連休は2月6日(土)~2月8日(月)で、2月9日(火)が振替休日と表示されている(韓国天文研究院 2027年暦資料)。ただしこのページは、宇宙航空庁 (Korea AeroSpace Administration / 우주항공청)を通じて月暦要項が公式発表される前の資料だと明記しているため暫定値だ — 旅行の直前に祝日を再確認する。
  • 詳細記事には旧正月・秋夕の休業と書かれた店がある — ウンジュジョン(旧正月・秋夕の連休休み、#486)、ファンセンガ カルグクス(旧正月・秋夕の当日休み、#480)、済州の城邑昔の小豆粥 (Seongeup Yetnal Patjuk / 성읍 옛날팥죽)(月曜日・旧正月・秋夕の連休休み、#476)。連休に老舗を狙っていたら、詳細記事の休業表記を先に見て、電話で確認する。
  • 旧正月の食べ物・風習は#752 旧正月ガイドで扱う。

🥗 食事制限 — 避けたい食材があれば「メニュー」ではなく「スープのベース」を尋ねる

  • 豚肉を避ける: 詳細記事で牛骨・牛肉のスープと確認できたのはソルロンタン・コムタン(#477)だ。テジクッパ・スンデクッ (sundae-guk / 순대국)は豚で、キムチチゲ・プデチゲには豚肉が入っていることが多い。それ以外のスープ・チゲ・カルグクスは店ごとにベースが違うので「牛のスープですか、豚のスープですか?」と尋ねる。キムチの薬味にはほとんどの場合、塩辛・魚醤や肉の出汁が使われている(#477・#486)。
  • 海鮮アレルギー: おでんは魚のすり身で、アサリのカルグクス(イム・ビョンジュ)・干しスケトウダラのヘジャンクは海鮮そのものだ。スンドゥブチゲ (sundubu-jjigae / 순두부찌개)・豆腐の煮付けにはほとんどの場合アミの塩辛が入り(#486)、キムチにも塩辛・魚醤が使われているので「塩辛は入っていますか?」と尋ねる。
  • ベジタリアン: 完全菜食と確認できた店はこの系統にない。豆腐チョンゴル・テンジャンチゲ・小豆粥・ホトク・ブンオッパンが候補だが、出汁・塩辛・生地の材料は公式ページに掲載されていないので、注文前に確認する(#486は「豆腐のチゲはベジタリアン」と思い込むのをよくある間違いとして挙げている)。見せるためのカードは#1300 食事リクエストマニュアル。
  • その他のアレルギー: カルグクス・ミルミョン (milmyeon / 밀면)は小麦(#480)、豆腐・味噌・チョングッチャン (cheonggukjang / 청국장)は大豆(#486)、ホトクの中身はナッツ、ケランパンは卵(#476)、サムゲタンにはナッツが入る(#827)。
  • ハラール: この記事が移した店の公式ページにはハラール表記がない。詳細記事五本が共通して挙げるハラール食堂は梨泰院 (Itaewon / 이태원)のイード (Eid / 이드)(龍山区 ウサダンロ10キル 15 (Usadan-ro 10-gil 15 / 우사단로10길 15)、毎日12:00~21:00、韓国イスラム教中央会の認定 — VisitSeoul、#476)で、国籍別のハラール4分類は#192 東南アジアのムスリム旅行者ガイド。
  • 価格: ウォンの価格が公式に掲載された店は、どの詳細記事にもない。ミシュランの価格記号がある店はすべて₩(最も低い段階)だ(#477 11軒・#480 12軒・#486 ファングムコンバッ)。屋台のおやつは現地の価格表を、食堂は入口のメニューを見る。

⚠ よくある間違い4つ

  1. 「老舗は夜に行ってもいい」 — ハドングァンは16:00に、プゴクチプの週末は15:00に終わり、ハプチョンオクは100人前がなくなると閉まる。朝・昼に行く(🍲)。
  2. 「ブンオッパン・ホトクの生地はどれも似たようなもの」 — ホトクの中身にはナッツ、ケランパンには卵が丸ごと入っている(VisitKorea)。アレルギーがあれば買う前に尋ねる(🐟)。
  3. 「豆腐料理はベジタリアン向け」 — スンドゥブチゲ・豆腐の煮付けにはほとんどの場合アミの塩辛が入っている(#486)。出汁と塩辛を尋ねる(🥗)。
  4. 「旧正月の連休でも市場は開いているだろう」 — 旧正月・秋夕の休業と書かれた店がある(ウンジュジョン・ファンセンガ・済州の昔の小豆粥)。2027年2月6~9日(暫定)に来るなら、休業の表記を先に見る(🧧)。

⚙ FAQ 4つ

Q1. 朝7時に開いているスープの店はある?

ある。鍾路区のチョンジノク(06:00~)と市庁裏のプゴクチプ(07:00~)、明洞のハドングァン(月~土 07:00~)が、#486・#477に住所・休業日とともにある。宿の近くなら、地図アプリで「ヘジャンク (haejangguk / 해장국)」を検索して営業時間を確認する。

Q2. 豚肉を食べないがクッパは食べられる?

ソルロンタン・コムタンは牛骨・牛肉のスープと確認できた(#477)。テジクッパ・スンデクッは豚だ。ヘジャンクは店ごとにベースが違うので「牛のスープですか、豚のスープですか?」と尋ねる(🥗)。メニュー名だけを見て選ばない。

Q3. ブンオッパンの値段はいくら?

公式ページに掲載された価格がなく、屋台ごとに違う。現地の価格表を見て、現金を少し用意しておくと安心だ(#476の固定店舗の中にもカード「なし」と表記された店がある)。

Q4. 冬至とは何で、その日に何を食べる?

2026年12月22日、一年でいちばん夜が長い日だ。小豆粥を食べる風習があり、小豆粥専門店五軒の時間・休業日は#476にある。
