⚠ 외국인 자주 실수 5가지

1. "한국 = 우주 없음": 한국 우주 = KARI (한국항공우주연구원) + KASI (한국천문연구원) + 누리호 발사 + 외국인 매니아 1번지 풀세트 + #534·#377·#178 통합.

2. "천문대 = 박물관만": 천문대 = 보현산 (세계 #1 청정 하늘) + 소백산·BOAO + 별마로 + 외국인 매니아 1번지 + #534·#539 통합.

3. "별자리 = 한국 없음": 별자리 = 강원도·청송 (외국인 매니아 1번지) + 보현산 천문대 + 외국인 영어 OK + #534·#539 통합.

4. "과학관 = 어린이만": 국립과천과학관 = 한국 #1 + 외국인 영어 OK + 외국인 매니아 1번지 + #143·#377·#533 통합.

5. "누리호 = 못 봄": 누리호 = 전남 고흥 발사장 + 외국인 매니아 1번지 + 발사 일정 1~2년 전 예약 + #534·#178 통합.
