韩国黄金路线① 首尔→庆州→釜山，按什么顺序、各住几晚 — 首尔要减、庆州要住

副标题：首访韩国的标准路线是首尔·庆州·釜山三城。Reddit上每周都有人问同样的问题——顺序怎么排、各住几晚、庆州值不值得去。答案很明确：首尔坐KTX南下，庆州住一晚，釜山住三晚，再坐KTX回首尔。这篇给出理由和7·8·10日分配表——不讲景点，那交给各城市专篇。

ISSUE · #1372 · 2026-09-10

🎯 定调——一路向南

初访韩国的人，行程表大多收敛到三座城市：首都首尔，新罗 (Silla / 신라) 千年古都庆州，海边釜山。三座城市在同一条线上——京釜高速线 (Gyeongbu High-Speed Line / 경부고속선) 从首尔一路南下到釜山，庆州站 (Gyeongju Station / 경주역) 就在这条线上。所以顺序不需要纠结：首尔→庆州→釜山，再从釜山坐KTX回首尔，从首尔坐飞机回国。

Reddit上关于这条路线的帖子，三分之一是"帮我看看行程表"这种格式。回复总是趋同——首尔排太多了，釜山一天两个地方就够，庆州别当天来回、要住一晚。这一篇把这个收敛值整理成一张表。

  • 总体结构：首尔3~5晚 → 🚄 约2小时 → 庆州1~2晚 → 🚄 约30分钟 → 釜山3晚 → 🚄 约2小时40分钟 → 首尔(仁川出境)
  • 票价(2026-09-01统一降价后)：首尔–釜山普通座54,400韩元，首尔–庆州4万韩元左右，庆州–釜山1万韩元上下——三张合计10万韩元上下
  • 总天数：7日·8日·10日三种方案(见下文📅)
  • 下车的地方：只有三个车站。景点交给各城市专篇(#1115·#1366·#1114等)

为什么是这个顺序——地理、行李、时刻表

地理。 庆州站和釜山站 (Busan Station / 부산역) 坐KTX只要30分钟出头。首尔到庆州是2小时，庆州等于是"顺路"在去釜山的路上。先去釜山的话，看完庆州要么往回绕到釜山方向再北上首尔，要么从庆州直接北上首尔——不管哪种都浪费一段路程。Reddit上一条评论精准地点出了这种混乱："geographically speaking, gyeongju then busan would make more sense."

行李。 这条路线上出现频率最高的实务烦恼不是观光，是行李箱。"I'll have a heavy suitcase, so I'd prefer fewer hotel changes"——在首尔购物，行李就会变多。首尔排在前面，就得拖着变多的行李跑庆州、釜山；首尔排在后面，就留到最后再买。两种都说得通。这一篇把首尔排在前面，但把购物安排到最后半天的首尔或釜山。庆州一晚轻装出行——大件行李寄放在住处，这一天是轻装移动日(#1373)。

时刻表。 首尔→庆州的KTX上午班次密，釜山→首尔的傍晚班次密。早上南下、傍晚北上的方向和时刻表最合拍。反方向(釜山入境→首尔出境)也行——金海国际机场 (Gimhae International Airport / 김해공항) 有日本、中国、东南亚航线，从那边过来的人可以反过来走釜山in、首尔out。这一篇以仁川in/out为基准。

📖 故事1——庆州是后来才挤进来的：1905年铺设的京釜线 (Gyeongbu Line / 경부선) 铁路本是连接首尔和釜山的线，2004年KTX也跑在这条线上。庆州挤上这条线是在2010年11月，京釜高速线二期通车，原新庆州站 (former Singyeongju Station / 구 신경주역) 随之而设。车站没有设在市区，而是设在西边的乾川邑 (Geoncheon-eup / 건천읍)——穿过市区会碰到新罗的陵墓和寺址，这是一条为了避开文物而绕行的路线。于是庆州变成了一座"从车站到市区要30分钟"换乘的城市(#1373)。2023年，这座车站改名为庆州站，市区里的旧庆州站则在2021年底关闭。

🚶 路线——三个车站，三次下车

起点是首尔站 (Seoul Station / 서울역)或水西站 (Suseo Station / 수서역)——两个都是KTX。从2026年9月1日起，水西发的SRT并入KTX，统一App Korail Plus 应用 (코레일+) 就能买票(#1374)。从仁川国际机场 (Incheon / 인천공항) 到首尔站，坐机场铁路 AREX (공항철도)。

① 首尔站 → 庆州站 (🚄 约2小时)

  • 坐早班车。庆州站在市区西边的乾川邑——下车后还要再往市区移动。标注为"庆州站(原新庆州站)"。地图App里就算留着旧名字，也是同一个车站。

② 庆州站 → 皇理团路 (🚌 约30分钟 · 1~2晚)

  • 市内公交50、51、70路或座位巴士700号段驶入市区(约30分钟，以庆州市公交信息当天确认为准)。出租车约20公里，1万韩元中后段。住宿选大陵苑 (Daereungwon / 대릉원) 旁的皇理团路 (Hwangnidan-gil / 황리단길)·皇南洞 (Hwangnam-dong / 황남동)——这是唯一一条夜景(#1366)和市区移动都能靠走路解决的轴线。
  • 1晚是基本配置，想连佛国寺 (Bulguksa / 불국사)、石窟庵 (Seokguram / 석굴암) 一起看就住2晚(在#1373里决定)。

③ 皇理团路 → 庆州站 → 釜山站 (🚌 约30分钟 + 🚄 约30分钟)

  • 再坐公交回车站，KTX 30分钟。或者从市内的庆州市外客运站 (Gyeongju Intercity Bus Terminal / 경주 시외버스터미널) 坐开往老圃客运站 (Nopo Bus Terminal / 노포) 的市外巴士约50分钟(一天50班上下，7,700韩元)——住宿在市区的话，巴士更方便。两者的比较见#1373。

④ 釜山站 → 西面 (🚇 约10分钟 · 3晚)

  • 从釜山站坐釜山地铁1号线到西面 (Seomyeon / 서면)。釜山3晚遵循"一天两个地方"原则(#1114·#1325)。别拖着大件行李箱坐市内公交——用地铁、出租车。

⑤ 釜山站 → 首尔站 (🚄 约2小时40分钟)——收尾

  • 坐傍晚班次北上，在首尔过最后一晚。第二天坐机场铁路AREX去仁川。从釜山直接出境(金海)的反方向方案见FAQ 5。

📖 故事2——为什么大家都往首尔塞7晚：去过的人的回顾都是一个方向——首尔比想象中一天天都差不多，庆州和釜山比想象中短。首尔不是用来"看"的，是用来"住"的，塞满一周也留不下什么。所以这一篇从首尔省下一天给庆州。夜里走在新罗陵墓之间的一天，比首尔第六条咖啡街留下的记忆更久。

📅 天数——7·8·10日三种方案

把Reddit行程表里实际用过的分配收集起来，常见的是首尔5~7晚、庆州1~3晚、釜山3~4晚。大多数都会听到"首尔太长"这个回复。下面是这个收敛值。

天数 首尔 庆州 釜山 首尔(收尾) 备注
7日 3晚 1晚 2晚 0~1晚 最后一天釜山→首尔→仁川直达，首尔可0晚
8日 3晚 1~2晚 3晚 1晚 标准方案。庆州2晚含佛国寺、石窟庵
10日 4晚 2晚 3晚 1晚 首尔4晚可加1天近郊(#1104)
  • 庆州1晚：下午抵达 → 夜景 → 第二天上午出发。2晚：加一天佛国寺、石窟庵(从市区坐公交40分钟)。
  • 釜山3晚：海云台 (Haeundae / 해운대)、广安里 (Gwangalli / 광안리) 一天，老城区、札嘎其 (Jagalchi / 자갈치) 一天，留一天余裕。一天两个地方(#1114)。
  • 首尔的正确答案是要减。7日的话3晚就够(#228是首尔专属7日——和这一篇是不同的方案)。

🙏 礼仪——火车与住宿

  • KTX座位是对号入座。大件行李放在车厢两端的行李架，不要堵在过道。
  • 韩屋住宿(庆州)很多入住时间较晚。提前问清楚能不能寄放行李。
  • 车厢内打电话、看视频请用耳机。虽然没有"安静车厢"这个概念，大家其实都很安静。
  • 站台排队按地面标线的位置。

💡 容易懵的点

  • 庆州站不在市区：下车后还要再走30分钟。订"车站附近的住宿"会让观光变得不方便——住皇理团路。
  • 庆州站有两个名字：2023年前叫原新庆州站。就算旧文章、旧地图上写的是原新庆州站，也是同一个车站。市区里的旧庆州站已经没了。
  • 釜山一天两个地方：把海云台和甘川文化村 (Gamcheon / 감천마을) 塞进同一天，一整天都在赶路。这是Reddit回复里的一致意见。
  • 拖着行李坐市内公交：釜山站→广安里拖着行李坐市内公交后悔的经验分享很常见。改坐地铁、出租车。
  • 传统节日：中秋 (Chuseok / 추석)、春节 (Seollal / 설) 前后KTX会卖光。市外巴士是替代方案(#1374)。
  • 别被庆州→釜山KTX只要30分钟骗了：容易忘掉从庆州站再出发的那30分钟。住市区的话，市外巴士可能门到门更快。

FAQ 6

Q1. 反方向(釜山→庆州→首尔)不行吗？

  • 可以。从釜山入境，或者想把首尔购物留到最后，就反过来走。庆州在中间这一点不变。

Q2. 从釜山当天往返庆州呢？

  • 可以，很多人这么做。不过看不到夜景，往返要花两小时在路上。这条路线建议住1晚——理由见#1373。

Q3. 只有7天。

  • 首尔3、庆州1、釜山2。首尔还可以再压缩。

Q4. 想加上济州呢？

  • 常见方案是从釜山坐国内航班去济州 (Jeju / 제주)，再从济州飞回首尔。比这一篇的3座城市多花两天以上。

Q5. 从釜山直接出境呢？

  • 金海国际机场有日本、中国、东南亚航线。坐这些航线就能省掉返回首尔的一段。欧洲、美洲航线大多还是走仁川。

Q6. 票要提前买吗？

  • KTX通常当天买也行，但周末、传统节日要提前。三段车票和交通证的划算与否见#1374。
