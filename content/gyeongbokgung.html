🎯 왜 경복궁 단독 가이드인가

경복궁은 조선왕조 최대 궁궐 (1395 건립) — 외국인 관광객 한국 역사 체험 1순위. 무료 영어 가이드 투어 + 수문장 교대식 + 한복 무료 입장 등 외국인 친화. ISSUE 02 #37 v2 풀 보강.

1 광화문 (정문) 수문장 교대식 10:00·14:00

⚠ 외국인이 자주 하는 실수 3가지

1. 화요일 휴무 무시 — 경복궁 매주 화요일 휴무. 사전 확인 필수.

2. 한복 + 무료 입장 못 활용 — 한복 착용 시 입장료 무료. 한복 대여 ₩15K → 무료 입장으로 절약.

3. 수문장 교대식 시간 못 맞춤 — 10:00·14:00 정각 (월 휴무). 5분 전 도착 권장.

4축 매핑

  • ① 정문·교대식 — 광화문 + 수문장 교대식
  • ② 본전·궁궐 — 근정전·경회루·향원정
  • ③ 박물관 — 국립민속·국립고궁
  • ④ 결합 동선 — 북촌·삼청동·인사동

⚙ FAQ

Q1. 입장료·예약은?

A. 입장료 ₩3,000, 한복 착용 시 무료. 영어 가이드 투어 무료 (11:00·13:30·15:30 1일 3회). 사전 예약 X 워크인 OK.

Q2. 영어 가이드 투어는?

A. 무료 영어 가이드: 11:00 / 13:30 / 15:30 (월 휴무). 1시간 30분. 광화문 안내소 집결.

Q3. 한복 결합은?

A. 경복궁 인근 한복남·오감 매장 (도보 5분). #33 한복 가이드 참조.

Q4. 시즌별 추천은?

A. 봄(4월 벚꽃): 경복궁 벚꽃 + 한복 1순위. 가을(11월 단풍): 경회루 단풍 + 한복. 겨울(12~2월): 한산 + 한복 + 외투.

Q5. 1일 결합 코스는?

A. 10시 경복궁 → 14시 수문장 교대식 → 15시 북촌 한옥마을 → 17시 삼청동 카페 → 19시 한식 디너.

🗺 결합 코스 3개

[A] 경복궁 + 북촌 (1일 6시간) — 10시 경복궁 + 한복 → 14시 교대식 → 15시 북촌 → 17시 카페

[B] 경복궁 + 인사동 (반나절) — 10시 경복궁 → 13시 인사동 점심 + 쇼핑
