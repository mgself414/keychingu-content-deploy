外国人がよくやりがちなミス5選

1. 「キンパプはどれも同じ」という誤解

韓国のキンパプは市場老舗 / プレミアムチェーン / トレンディチェーン / コンビニによって食材・価格・味がまったく異なります。Gwangjang Market (광장시장) のマヤクキンパプ ₩4,000 と Lee Gimbap (리김밥) のキトキンパプ ₩5,800 は同じキンパプでも別の食べ物です。本文「チェーン3大王者比較」参照。

2. グァンジャンのマヤクキンパプにからしをつけない

Gwangjang Market (광장시장) のマヤクキンパプはからし+醤油ソースが肝心です。つけないと風味が半減。外国人が「ただの小さいキンパプじゃん」と評価してしまう理由は、ほぼ確実にソースをつけていないから。

3. 深夜コンビニのキンパプ = まずいという偏見

韓国コンビニのキンパプ (CU ヤンバンキンパプ、GS25 キムヘジャキンパプ、セブン-イレブン) は24時間フレッシュ回転で、外国人の満足度も非常に高いです。早朝フライト+初日ホテル到着時は₩3,500 キムヘジャキンパプ + カップラーメンが韓国初めての食事の正解。

4. チュンムキンパプ (충무김밥) を普通のキンパプのように注文する

チュンムキンパプ (Tongyeong (통영) 発祥の地域名産) はキンパプ + カクテキ + イカの和え物が別皿で提供されます。「キンパプだけ頼めばいい」ではなくセット注文 (₩7,000〜10,000)。ミニキンパプにカクテキ・イカの和え物を添えるのが本来のスタイル。

5. キトキンパプ・ビーガンオプションを知らずにそのまま注文する

韓国のキンパプはご飯の代わりに卵焼きを使ったキトキンパプ、肉・魚介を抜いて野菜だけ使ったビーガンキンパプまで選択肢が広がっています。グルテンフリー・低糖質・ビーガン食の方はLee Gimbap (리김밥) キト / Barda Kim Seonsaeng (바르다김선생) 野菜キンパプから確認しましょう。

外国人向け注意事項8点 (チェックリスト)

✅ アレルギー確認

  • よく使われる食材: ツナ・卵・ほうれん草・にんじん・ごぼう・たくあん
  • 特殊食材: 明太子 (魚卵)、いりこ (小魚)、魚肉練り製品 (オムク)
  • アレルギーがある場合は「○○ 빼주세요 (○○ ppae-ju-se-yo / ○○を抜いてください)」

✅ ビーガンオプションの確認

  • 野菜キンパプでもツナエキス・卵が入っていることがある
  • 完全ビーガン = 店舗で「비건이에요 (vegan-ieyo)」と明示 + メニューを直接確認
  • 安全オプション: Barda Kim Seonsaeng (바르다김선생) 野菜 (肉を抜く要請可)、Lee Gimbap (리김밥) キト変形

✅ 辛さの程度

  • スパイシーツナマヨ・スパイシー豚肉炒め・スパイシーソーセージ = 韓国式の辛さ (中辛)
  • 辛いものが苦手なら野菜・チーズ・ツナマヨ (non-spicy) がおすすめ
  • 「덜 매워요 (deol mae-wo-yo / 辛さ控えめで)」が通じる店舗は一部のみ

✅ たくあん・ごぼうの独特な香り

  • たくあん (黄色い漬け大根) + ごぼう (rolled burdock root) = 好みが分かれる
  • 慣れるまで1〜2回かかることも。初訪問なら野菜を少なくして、ツナ・チーズ中心に

✅ キンパプのカット

  • 1本 = 8〜10切れにカットして提供 (市場マヤクキンパプは10切れのミニサイズ)
