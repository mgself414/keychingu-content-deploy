外国游客中，有纪念日·商务晚餐·深度美食探索需求的群体，最优先需要江南米其林·高级餐厅的信息。米其林指南首尔韩食餐厅8家以上集中于江南区·钟路区——是外国美食爱好者、商务出行、蜜月·纪念日游客的首选动线。

⚠ 外国游客常犯的3个错误

1. 忽略预约——几乎100%无法Walk-in

江南米其林餐厅须提前2周~1个月预约。家温 (Gaon / 가온)·权叔洙 (Kwon Sook Soo / 권숙수) 需提前1个月以上。不接受Walk-in。请提前通过酒店礼宾部·OpenTable·Catch Table·Naver预约。

2. 忽视着装要求——可能被拒绝入场

米其林餐厅建议Smart Casual以上着装。拖鞋·短裤·无袖上衣可能被拒绝入场。家温 (Gaon / 가온)·权叔洙 (Kwon Sook Soo / 권숙수) 建议接近正装。请提前查看餐厅Instagram·官网。

3. 未提前告知过敏·素食·宗教饮食需求

米其林套餐菜单为预先固定菜单。如未提前告知过敏原·素食·清真·犹太洁食需求，当日无法更改。预约时务必以英文书面备注："I have nut allergy"、"I am vegetarian"、"halal-only required"。

江南·道山·清潭高级餐厅风貌

江南区是韩国米其林指南的核心据点——道山公园 (Dosan Park / 도산공원)·清潭·新沙一带集中了米其林1·2·3星餐厅。家温 (Gaon / 가온) (3星)·权叔洙 (Kwon Sook Soo / 권숙수) (2星)·明格斯 (Mingles / 밍글스)·定食堂 (Jungsik / 정식당) 等传统韩食与现代融合餐厅分布在同一动线上。

道山公园 (Dosan Park / 도산공원) 是米其林韩食热门聚集地——家温 (Gaon / 가온)·明格斯 (Mingles / 밍글스)·温知饮食工坊 (Onjium / 온지음 맛공방) 周边步行可达。外国美食爱好者首选路线。

清潭·新沙 (Cheongdam·Sinsa / 청담·신사) 是奢华餐厅云集之地——权叔洙 (Kwon Sook Soo / 권숙수)·妙安 (Myoan / 묘안) 等韩国顶级美食本营。韩服 + 韩食 + 葡萄酒相融合。

宣陵·驿三 (Seolleung·Yeoksam / 선릉·역삼) 是现代韩食区域——定食堂 (Jungsik / 정식당) 等现代摆盘餐厅汇聚。在纽约·欧洲亦设有分店。

共收录8家餐厅 (江南区6家 + 汉南1家 + 钟路区1家加赠)。

⚙ 常见问题 (FAQ)

Q1. 哪些餐厅提供英文菜单·预约？

A. 全部8家餐厅均提供英文菜单 + 英文服务。可通过酒店礼宾部·OpenTable·Catch Table·Naver预约。国际信用卡100%可用。3星家温 (Gaon / 가온) 须提前1个月以上预约。

Q2. 米其林1·2·3星有什么区别？

A. 3星 (家温 / Gaon / 가온)：韩国顶级。2星 (权叔洙 / Kwon Sook Soo / 권숙수)：传统韩食精髓。1星 (明格斯 / Mingles / Mingles (Mingles / 밍글스)·定食堂 / Jungsik / Jungsik定食堂 (Jungsik / 정식당)·温知饮食工坊 / Onjium / 온지음 맛공방·明格斯 by Park / Mingles by Park / Mingles (Mingles / 밍글스) by Park·妙安 / Myoan / 묘안·小说汉南 / Soseol Hannam / 소설한남)：米其林指南推荐餐厅。

Q3. 哪些餐厅支持素食·清真·过敏原需求？

A. 须提前告知——预约时以英文书面传达："I have nut/milk/seafood allergy"、"I am vegetarian/vegan"、"halal-only required"。家温 (Gaon / 가온)·定食堂 (Jungsik / 정식당)·明格斯 (Mingles / 밍글스) 等可提供素食套餐。清真方面，江南餐厅较为困难——建议选择汉南餐厅 (小说汉南 / Soseol Hannam / 소설한남)或梨泰院 (Itaewon / 이태원) 国际餐厅。

Q4. 葡萄酒·传统酒配对推荐？

> 약주 (药酒 / Yakju) 和 청주 (清酒 / Cheongju) 均为韩国传统粮食酒，酒精度较低，风味接近日本清酒，但口感更柔和甜润，是高级韩食套餐的经典配对选择。米酒 (Makgeolli / 막걸리) (马格利 / Makgeolli) 为韩国传统米酒，口感微甜带气，类似中国的米酒或浊酒，酒精度约6~8度。

A. 葡萄酒配对: 家温 (Gaon / 가온)·定食堂 (Jungsik / 정식당)·明格斯 (Mingles / 밍글스) (韩国·世界葡萄酒精选)。

传统酒配对: 权叔洙 (Kwon Sook Soo / 권숙수)·温知饮食工坊 (Onjium / 온지음 맛공방) (韩国传统酒深度精选——药酒 (Yakju / 약주)·清酒 (Cheongju / 청주)·蒸馏酒)。

配对附加价格: ₩50,000~120,000。

Q5. 午餐 vs 晚餐套餐有什么区别？

A. 午餐套餐: 大部分餐厅价格便宜30~50% (₩100K~200K)。部分餐厅平日午餐可Walk-in。

晚餐套餐: 完整套餐，₩200K~350K。须预约。纪念日·约会首选。

Q6. 着装要求是什么？

A. Smart Casual以上: 建议穿衬衫·上衣·连衣裙·正装。可能被拒绝入场: 拖鞋·短裤·无袖上衣·运动服。家温 (Gaon / 가온)·权叔洙 (Kwon Sook Soo / 권숙수) 建议正装。请提前查看Instagram·官网确认。

Q7. 纪念日·约会推荐？

A. 纪念日·蜜月首选: 家温 (Gaon / 가온) (3星)。

情侣约会: 明格斯 (Mingles / 밍글스)·定食堂 (Jungsik / 정식당)·妙安 (Myoan / 묘안)。

商务晚餐: 权叔洙 (Kwon Sook Soo / 권숙수)·温知饮食工坊 (Onjium / 온지음 맛공방)·小说汉南 (Soseol Hannam / 소설한남)。

现代美食爱好者: 定食堂 (Jungsik / 정식당)·明格斯 by Park (Mingles by Park / 밍글스 by Park)。

Q8. 江南米其林一日动线是什么？

> 회식 (公司聚餐 / Hoesik): 韩国职场饭局文化，类似中国的"团建"或"商务宴请"，通常在高级餐厅进行，常伴随多轮饮酒，是韩国社交文化的重要组成部分。

A. 奢华一日: 13:00 家温 (Gaon / 가온) 午餐 (3星)→ 16:00 道山公园 (Dosan Park / 도산공원)·清潭散步 → 19:30 权叔洙 (Kwon Sook Soo / 권숙수) (2星)或定食堂 (Jungsik / 정식당) 晚餐。

美食爱好者一日: 19:00 明格斯 (Mingles / 밍글스) → 22:00 清潭葡萄酒吧。

情侣动线: 12:00 定食堂 (Jungsik / 정식당) 午餐 → 14:00 道山公园 (Dosan Park / 도산공원) → 17:00 清潭酒店 → 19:00 权叔洙 (Kwon Sook Soo / 권숙수) 晚餐。
