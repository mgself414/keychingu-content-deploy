⚠ 外国游客常犯的3个错误

1. “电视剧取景地 = 都属于同一区域”: 每部电视剧的取景区域都很明确：

  • 青春浪漫剧 = 延世大学 (Yonsei University / Yeonseidae / 연세대)·高丽大学 (Korea University / Goryeodae / 고려대)·弘大 (Hongdae / 홍대)·梨泰院 (Itaewon / 이태원)
  • 上班族剧 = 鹭梁津 (Noryangjin / 노량진)·钟路 (Jongno / 종로)·汝矣岛 (Yeouido / 여의도)
  • 奇幻·高级剧 = DDP (Dongdaemun Design Plaza / 동대문디자인플라자)·乐天塔 (Lotte Tower / Rotte Tawo / 롯데타워)·清潭洞 (Cheongdam-dong / 청담동)

2. “拍摄地 = 去了也认不出来”: KeyChinGu (키친구) 指南会明确标注 K-drama 取景地 + Instagram (인스타) 热门打卡点。#181 鹭梁津考试村 (Noryangjin Gosichon / 노량진 고시촌) = 《未生》、《梨泰院Class》的常客，明确标注。

  • 考试村 (Gosichon / 고시촌): 韩国特有的考试准备区，通常聚集了大量备考学生，提供住宿、补习班和餐饮服务。

3. “K-drama 剧迷 = 只有日本·中国游客”: K-drama 外国剧迷遍布全球 — 美国、欧洲、中东、南美。Netflix (넷플릭스) 效应使其每年都在增加。

① 青春·浪漫 K-drama (3个区域)

1. 梨泰院 Class (Itaewon Keullasseu / 이태원 클라쓰) — 梨泰院 (Itaewon / 이태원)

  • 取景地: 梨泰院街 (Itaewon Geori / 이태원 거리)·绿莎坪 (Noksapyeong / 녹사평)·鹭梁津水产市场 (Noryangjin Susan Sijang / 노량진수산) (#144·#181)
  • 外国游客 ★: ◎◎ — 全球首选取景地
  • 标志性: 朴叙俊 (Park Saeroyi / 박새로이) 的“甜夜 (Danbam / 단밤)”酒馆·绿莎坪 (Noksapyeong / 녹사평) 汉江大桥 (Hangangdaegyo / 한강대교) + 鹭梁津水产市场 (Noryangjin Susan Sijang / 노량진수산시장)

2. 奶酪陷阱 (Cheese in the Trap / Chijeu In Deo Teuraep / 치즈 인 더 트랩)·那年我们 (Geu Hae Urineun / 그 해 우리는) — 延世大学 (Yonsei University / Yeonseidae / 연세대)·弘大 (Hongdae / 홍대)

  • 取景地: 延世大学白杨路 (Yonsei University Baengyang-ro / 연세대 백양로)·弘大街 (Hongdae Geori / 홍대 거리) (#171·#138)
  • 外国游客 ★: ◎ — 青春·浪漫首选地

3. 请回答1988 (Eungdaphara 1988 / 응답하라 1988) — 双门 (Ssangmun / 쌍문)·道峰 (Dobong / 도봉)

  • 取景地: 双门老街巷 (Ssangmun Yet Golmok / 쌍문 옛 골목)·猪肉汤饭 (Dwaejigukbap / 돼지국밥)·豆芽汤饭 (Kongnamulgukbap / 콩나물국밥) (#177)
  • 猪肉汤饭 (Dwaejigukbap / 돼지국밥): 韩国南部特色美食，以猪骨熬制汤底，加入猪肉片和米饭。
  • 豆芽汤饭 (Kongnamulgukbap / 콩나물국밥): 以豆芽为主料的清爽汤饭，常作为解酒或早餐。
  • 外国游客 ★: ◎ — 深度体验韩国怀旧风情
