サブタイトル: 21コース総延長156.5km(紹介文基準) · コース別 4.6km~10.7km、約2時間5分~4時間50分 · 常時開放、年中無休 · 13・14コースのアニャンチョン (Anyangcheon / 안양천)区間は夜も利用可能 · 案内センター ☎ 02-779-7902~4 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

ソウルトゥルレギル (Seoul Dulle-gil / 서울둘레길)は、ソウルを一周する歩道です。韓国観光公社の紹介によると総延長156.5km、21コースで、ソウルの歴史・文化・自然生態を物語として編んだ道です。道のあちこちに休憩施設とブックカフェ、休憩所があります。

このガイドは21コースの区間、距離、歩く時間、最寄りの地下鉄駅を1つの表にまとめました。コースごとに始点と終点が区間の欄に登録されています。21コースすべてが常時開放、年中無休で登録されています。

運営情報は韓国観光公社の観光情報(TourAPI)に登録された値をそのまま写しました。

🥾 1~5コース — スラクサン (Suraksan / 수락산)・プラムサン (Buramsan / 불암산)・ヨンマサン (Yongmasan / 용마산)・アチャサン (Achasan / 아차산)

  • 1コース スラクサン (Suraksan / 수락산): テーマは「俗世を離れなかった昔の人の道」。上り下りが繰り返されますが、展望台からソウルを囲む山々を眺められると紹介されています。
  • 2コース トンヌンゴゲ (Deongneung Pass / 덕릉고개): テーマは「都市と自然をつなぐ生態の道」。岩と花を見られる道です。
  • 3コース プラムサン (Buramsan / 불암산): テーマは「空を抱く穏やかな森の道」。韓国観光公社の紹介によると、ソウルトゥルレギル (Seoul Dulle-gil / 서울둘레길)のなかで最も楽に歩ける森の道です。
  • 4コース マンウ・ヨンマサン (Mangu·Yongmasan / 망우·용마산): テーマは「都市を抜け出して出会う道」。ヨンマサン (Yongmasan / 용마산)は整備が行き届いていて楽に歩け、眺めがよいコースと紹介されています。
  • 5コース アチャサン (Achasan / 아차산): テーマは「人と歴史をつなぐ道」。眺めがよく歴史・文化資源が多く、アチャサン生態公園 (Achasan Ecological Park / 아차산 생태공원)があります。アチャサン (Achasan / 아차산)一帯は#740 ソウル北東部の森・公園ガイドにあります。

🥾 6~9コース — コドクサン (Godeoksan / 고덕산)・イルジャサン (Iljasan / 일자산)・タンチョン (Tancheon / 탄천)・テモサン (Daemosan / 대모산)

  • 6コース コドクサン (Godeoksan / 고덕산): テーマは「漢江に沿って広がる歴史の道」。比較的平坦なコースです。
  • 7コース イルジャサン (Iljasan / 일자산): テーマは「都心で出会う小さな森の道」。標高が高くなく楽だと紹介されています。イルジャサン (Iljasan / 일자산)一帯は#715 江東ガイドにあります。
  • 8コース チャンジ・タンチョン (Jangji·Tancheon / 장지·탄천): テーマは「自然生態が復元された都市の川の道」。川に沿って歩きます。タンチョン (Tancheon / 탄천)一帯は#697 ヤンジェチョン (Yangjaecheon / 양재천)・タンチョン (Tancheon / 탄천)ガイドにあります。
  • 9コース テモ・クリョンサン (Daemo·Guryongsan / 대모·구룡산): テーマは「自然生態の遊覧の道」。標高が高くなく山林資源が豊富で、ソウルの眺めがよいと紹介されています。21コースのなかで登録距離が10.7kmと最も長いです。

🥾 10~12コース — ウミョンサン (Umyeonsan / 우면산)・冠岳山 (Gwanaksan / 관악산)・ホアムサン (Hoamsan / 호암산)

  • 10コース ウミョンサン (Umyeonsan / 우면산): テーマは「山の中から見るソウルの道」。傾斜が緩やかで、森の散策と森林浴ができると紹介されています。
  • 11コース 冠岳山 (Gwanaksan / 관악산): テーマは「民間信仰と仏教が出会う道」。歴史・文化遺跡があちこちにあります。冠岳山 (Gwanaksan / 관악산)一帯は#738 ソウル チョンゲサン (Cheonggyesan / 청계산)・冠岳山 (Gwanaksan / 관악산)ガイドにあります。
  • 12コース ホアムサン (Hoamsan / 호암산): テーマは「説話と風水、歴史を込めた道」。歴史・文化遺跡を見られます。

🥾 13~16コース — アニャンチョン (Anyangcheon / 안양천)・ノウル・ハヌル公園 (Noeul·Haneul Park / 노을·하늘공원)・ポンサン・エンボンサン (Bongsan·Aengbongsan / 봉산·앵봉산)

  • 13コース アニャンチョン (Anyangcheon / 안양천)上流: テーマは「線路に沿って歩く桜の道」。春に桜が咲きます。アニャンチョン (Anyangcheon / 안양천)コースは全区間を夜も利用でき、地下鉄駅があちこちにあると登録されています。
  • 14コース アニャンチョン (Anyangcheon / 안양천)下流: テーマは「アニャンチョン (Anyangcheon / 안양천)の昔の思い出の道」。川と漢江に沿って歩く道で、運動施設・散策路・便益施設・休憩施設があちこちにあります。夜も利用できます。アニャンチョン (Anyangcheon / 안양천)一帯は#699 チュンナンチョン (Jungnangcheon / 중랑천)・アニャンチョン (Anyangcheon / 안양천)ガイドにあります。
  • 15コース ノウル・ハヌル公園 (Noeul·Haneul Park / 노을·하늘공원): テーマは「復元された自然の道」。カヤン大橋南端 (Gayang Bridge South End / 가양대교 남단)を過ぎて漢江と江南を眺められます。ノウル・ハヌル公園 (Noeul·Haneul Park / 노을·하늘공원)は#741 ソウル西部の公園ガイドにあります。
  • 16コース ポンサン・エンボンサン (Bongsan·Aengbongsan / 봉산·앵봉산): テーマは「稜線に沿って静けさを感じる山道」。急な斜面は整備が行き届いていて、スグクサ (Suguksa Temple / 수국사)やソオルン (Seooreung Royal Tombs / 서오릉)のような歴史遺産があります。

🥾 17~21コース — 北漢山 (Bukhansan / 북한산)の区間

17コースから20コースまでは北漢山トゥルレギル (Bukhansan Dulle-gil / 북한산 둘레길)と重なる区間があると登録されています。21コースには重なる区間の登録値がありません。

  • 17コース 北漢山 ウンピョン (Bukhansan Eunpyeong / 북한산 은평): テーマは「空と接する道」。傾斜は急ではありませんが、やや難しいことがあると紹介されています。ソルリムサ (Seollimsa Temple / 선림사)からは北漢山トゥルレギル (Bukhansan Dulle-gil / 북한산 둘레길) 8コース クルムジョンウォンギル (Gureumjeongwon-gil / 구름정원길)と重なります。
  • 18コース 北漢山 チョンノ (Bukhansan Jongno / 북한산 종로): テーマは「渓谷と山が出会った都心の道」。村の道の雰囲気があり、あちこちに展示施設があります。北漢山トゥルレギル (Bukhansan Dulle-gil / 북한산 둘레길) 7コース イェッソンギル (Yetseong-gil / 옛성길)、6コース ピョンチャンマウルギル (Pyeongchangmaeul-gil / 평창마을길)と重なります。コースの終点はバスと地下鉄で行けると登録されています。
  • 19コース 北漢山 ソンブク (Bukhansan Seongbuk / 북한산 성북): テーマは「思索にふけって歩く静かな森の道」。大部分が森の道で、途中に寺があります。北漢山トゥルレギル (Bukhansan Dulle-gil / 북한산 둘레길) 5コース ミョンサンギル (Myeongsang-gil / 명상길)、4コース ソルセムギル (Solsaem-gil / 솔샘길)、3コース フィングルムギル (Huingureum-gil / 흰구름길)と重なります。コースの始点は地下鉄とバスで行けると登録されています。
  • 20コース 北漢山 カンブク (Bukhansan Gangbuk / 북한산 강북): テーマは「墓地の前で国を思う道」。歴史上の人物や文化芸術人の遺跡が多くあります。北漢山トゥルレギル (Bukhansan Dulle-gil / 북한산 둘레길) 3コース フィングルムギル (Huingureum-gil / 흰구름길)、2コース スルレギル (Sullye-gil / 순례길)、1コース ソナムスプギル (Sonamusup-gil / 소나무숲길)と重なります。
  • 21コース 北漢山 トボン (Bukhansan Dobong / 북한산 도봉): テーマは「深い歴史の響きがある道」。歴史・文化遺跡が何か所かあります。

⚠ 前もって知っておきたい4つのこと

  1. コースごとの歩く時間は距離に比例しません — 14コース アニャンチョン (Anyangcheon / 안양천)下流は10.2kmで約2時間25分、16コース ポンサン・エンボンサン (Bongsan·Aengbongsan / 봉산·앵봉산)は9.1kmで約4時間15分です。
  2. 夜も利用できると登録されているのは13・14コースのアニャンチョン (Anyangcheon / 안양천)区間です — 21コースすべてが常時開放、年中無休で登録されています。
