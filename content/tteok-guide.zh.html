1. 年糕是什么？ — 专为外国人准备的简单介绍

1-1. 年糕 (Tteok / 떡) 的基本知识

年糕 (Tteok / 떡) 是将糯米或粳米蒸熟后揉搓或塑形而成的韩国传统食品。与面包不同，它不使用面粉，基本不含麸质。其特点是口感Q弹软糯，种类繁多，从甜味到香醇清淡的都有。

在节日 (如春节、中秋节)、生日或搬家等特殊日子，韩国人有分享年糕的文化，因此年糕也广泛以礼品套装的形式出售。近年来，咖啡馆式年糕店越来越多，与咖啡一同享用年糕的现代消费方式也逐渐普及。

3. 按时间·季节推荐

3-1. 作为早餐点心

在韩国，年糕传统上也被当作早餐点心或简餐替代品。白雪糕 (Baekseolgi / 백설기)、压花年糕 (Jeolpyeon / 절편)、打糕 (Injeolmi / 인절미) 等糖度较低、口感柔软的种类，非常适合作为清淡的早餐。街坊年糕店通常在清晨就能买到刚蒸好的年糕，因此建议您在前往前确认营业开始时间。

3-2. 周末下午茶点

年糕咖啡馆 (如同病相怜 (Dongbyeongsangryeon / 동병상련)、雅珍堂年糕商店 (Ajindang Tteoksangjeom / 아진당 떡상점)、药岘年糕坊 (Yaknyeon Tteokbang / 약현떡방)) 是与咖啡或传统茶一同享用年糕的空间，您可以自然地将其纳入周末下午的咖啡馆之旅。这里有座位，也可以在观光途中稍作休息。

3-3. 节日·特殊日子 (春节·中秋节)

节日 (如春节 (1-2月) 和中秋节 (9-10月)) 前后，礼品年糕套装的需求会大幅增加，很快就会售罄。如果您在这些季节访问，最好提前前往百年花片 (Baengnyeon Hwapyeon / 백년화편)、京畿年糕店 (Gyeonggi Tteokjip / 경기떡집)、韩果美意食 (Hangwamieuisik / 한과미의식) 等包装精美的店铺，或同时进行在线订购。

4. 点餐·包装·送礼小贴士 (以外国游客视角)

价格范围概论: 街坊年糕店价格相对便宜，而入驻百货公司的店铺或品牌礼品套装则属于高端价位。具体价格因店铺而异，建议您在访问时确认。例如，一份年糕可能售价 ₩15,000 (约80人民币)。

包装要求: 如果是送礼目的，购买时可以说“请帮我包装成礼物 (선물 포장 해주세요)”，大多数店铺都会提供包装服务。入驻百货公司的店铺 (如京畿年糕店 (Gyeonggi Tteokjip / 경기떡집)、年糕盒 (Tteokhamji / 떡함지)) 包装水平通常较高。

注意事项:

  • 年糕几乎不使用防腐剂，因此建议当天食用。特别是糯米糕 (Chapssaltteok / 찹쌀떡) 和打糕 (Injeolmi / 인절미) 需要冷藏保存，并且容易变硬。
  • 有些产品可以冷冻保存，但这因店铺而异，请在购买时确认。
  • 如果带出国，务必考虑机舱温度和运输时间，确认是否可以在常温下保存。

语言沟通: 大多数街坊年糕店没有英文菜单。拍照给店员看或使用翻译App可以帮助您更顺利地点餐。

5. 推荐路线

5-1. 半日钟路 (Jongno / 종로) 年糕之旅 (3家)

与钟路 (Jongno / 종로)·仁寺洞 (Insadong / 인사동) 观光路线自然连接的半日游。

1. 钟路年糕店 (Jongno Tteokjip / 종로떡집) / 乐园年糕店 (Nagwon Tteokjip / 낙원떡집) (三一大路 (Samil-daero / 삼일대로)) — 上午前往，体验街坊老字号 (拥有30年以上历史的传统老店) 年糕店的氛围，购买点心。

2. 雅珍堂年糕商店 (Ajindang Tteoksangjeom / 아진당 떡상점) (敦化门路11街 (Donhwamun-ro 11-gil / 돈화문로11길) / 益善洞 (Ikseondong / 익선동) 附近) — 午餐后参观年糕咖啡馆，品尝传统茶。

3. 韩果美意食安宁仁寺洞店 (Hangwamieuisik Annyeong Insadongjeom / 한과미의식 안녕인사동점) (仁寺洞街 (Insadong-gil / 인사동길)) — 在仁寺洞 (Insadong / 인사동) 购物的最后，前往购买礼品包装的年糕·韩果 (Hangwa / 한과)。

交通: 均在步行15分钟以内区域。以地铁3号线安国站 (Anguk Station / 안국역) 为基准。

5-2. 1日南北年糕比较路线 (4家)

上午在江北，下午前往江南 (Gangnam / 강남)，比较两个区域的年糕店氛围。

1. 五福年糕店 (Obok Tteokjip / 오복떡집) (圣水 (Seongsu / 성수)) — 在圣水 (Seongsu / 성수) 咖啡馆之旅开始前，参观本地年糕店。

2. 同病相怜 (Dongbyeongsangryeon / 동병상련) (钟路 (Jongno / 종로)) — 午餐后体验年糕咖啡馆，参观地下制作室。

3. 狎鸥亭公主年糕 (Apgujeong Gongju Tteok / 압구정공주떡) (江南 (Gangnam / 강남)) — 前往江南 (Gangnam / 강남) 后，享用下午点心。

4. 百年花片 (Baengnyeon Hwapyeon / 백년화편) (江东 (Gangdong / 강동)) — 一天结束时购买高级礼品套装。

交通: 依次乘坐地铁2号线圣水站 (Seongsu Station / 성수역) → 3号线安国站 (Anguk Station / 안국역) → 3号线狎鸥亭站 (Apgujeong Station / 압구정역) → 5号线明逸站 (Myeongil Station / 명일역) (江东 (Gangdong / 강동))。

6. 注意事项·礼仪

新鲜度和当天食用: 大多数年糕都遵循当天制作、当天食用的原则。存放时间越长，越容易变硬或变味。因此，与其在旅行第一天购买，不如在回国前一天或在住宿附近购买更为实际。

冷冻保存: 部分糯米糕 (Chapssaltteok / 찹쌀떡) 和打糕 (Injeolmi / 인절미) 可以在冷冻后解冻食用。但能否冷冻以及解冻方法因店铺而异，务必在购买时确认。

常温限制: 夏季 (6-8月) 气温较高，年糕在常温下很难保存半天。建议在此期间购买后立即冷藏。

传统市场内年糕店: 像名家年糕店 (Myeongga Tteokjip / 명가떡집) 这样位于市场内的店铺，其营业日和营业时间与市场同步。建议您在前往前确认。

拍照: 在狭窄的街坊年糕店里过度拍照可能会给其他顾客带来不便。在年糕咖啡馆或宽敞的空间里可以自由拍照。
