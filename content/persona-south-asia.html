🎯 왜 인도·남아시아 페르소나인가

인도·남아시아 = 한국 inbound 신흥 매니아 segment (인도·파키스탄·스리랑카·네팔·방글라데시). IT 인력 (E-7 비자) + K-content + 채식·할랄 친화 + 외국인 매니아.

⚠ 남아시아 외국인 자주 실수 3가지

1. "한국 = 채식 어려움": 한국 = 사찰음식 + 비건 매장 (#291) + 외국인 채식 매니아.

2. "인도 IT = 어디": 인도 IT = 판교·강남 E-7 비자 + 한국 1번지 외국인 IT.

3. "남아시아 = 적음": 남아시아 = 신흥 외국인 매니아 segment + 이슬람·힌두 친화 풀세트.

⚙ FAQ 4개

1. 남아시아 외국인 1순위: K-content + 채식 + 인도 음식 + 이슬람.

2. 인도 IT 거주: 판교·강남·이태원 외국인 매니아.

3. 채식·힌두 친화: 사찰음식 + 비건 매장.

4. 남아시아 1박2일: 이태원 + 판교 + 외국인 매니아.
