康津市场指南 — Ogamtong市场4·9日集市、马良Nolto水产市场、高丽青瓷博物馆、Gau岛、茶山草堂

副标题：康津Ogamtong市场 (Gangjin Ogamtong Market / 강진오감통시장)（每月逢4·9日的集市） · 马良Nolto水产市场 (Maryang Nolto Fish Market / 마량 놀토수산시장)（4~10月每周六） · 高丽青瓷博物馆 (Goryeo Celadon Museum / 고려청자박물관)（09:00~18:00，周一闭馆） · Gau岛 (Gau Island / 가우도)（全天开放） · 茶山草堂 (Dasan Chodang / 다산초당)（09:00~18:00） — 已对照韩国观光公社旅游信息（TourAPI）

🎯 如何使用这份指南

这份指南介绍的康津市场有两处。一处是康津邑的常设市场、逢4·9日开集的康津Ogamtong市场，另一处是4月到10月只在周六开市的马良港马良Nolto水产市场。此外还加入了观赏高丽青瓷的高丽青瓷博物馆、步行进入的岛屿Gau岛，以及丁若镛居住过的茶山草堂。

这份指南只介绍两处市场和这三个地点，营业信息照录韩国观光公社旅游信息（TourAPI）登记的数值。康津旅行整体内容请接着看下方相关内容。

🛒 康津Ogamtong市场 — 常设市场与4·9日集市

康津Ogamtong市场，地址康津郡康津邑 (Sijang-gil / 시장길) 17-14，电话 061-430-5513，是康津邑的传统市场。有常设店铺300多家，每月逢4·9的日子还会开5日集市。

  • 集市日：4日、9日、14日、19日、24日、29日。
  • 营业时间·休息日：各店铺不同。
  • 卖什么：水产品、农产品、杂货。
  • 便利设施：有洗手间、停车场。
  • 康津Ogamtong (Gangjin Ogamtong / 강진 오감통)，地址康津邑 (Ogam-gil / 오감길) 2，电话 061-433-3636（音乐创作所 (Music Creation Studio / 음악창작소)）：综合文化空间。设有音乐创作所、美食市集、韩定食体验馆，09:00~24:00全年无休营业。

🐟 马良Nolto水产市场 — 周六的港口市场

马良Nolto水产市场，地址康津郡马良面 (Mihang-ro / 미항로) 164，电话 061-430-3263（康津郡海洋山林科 (Gangjin-gun Marine and Forestry Division / 강진군 해양산림과)），是在马良港4月到10月每周六才开市的水产市场。

  • 开市日：4~10月每周六。周日到周五不营业。
  • 卖什么：时令水产品、生鱼片和鱼贝类、干货、康津农·畜产特产。
  • 玩什么：同一时期每周六举办周六音乐会。可停车。
  • 马良美港 (Maryang Mihang / 마량미항)，电话 061-430-3267：全天开放。有防波堤步道，港口入口处有一座因树林看上去发黑而被称为“Kkamakseom (까막섬)”的岛。秋天会举办Jeoneo (전어)节。

🏺 高丽青瓷博物馆 — 观赏与制作青瓷

康津高丽青瓷博物馆，地址康津郡大口面 (Cheongjachon-gil / 청자촌길) 33，电话 061-430-3755，是展出高丽青瓷、并开办用黏土制作青瓷体验的博物馆。

  • 营业时间：博物馆 09:00~18:00（17:30停止入场）。数字博物馆 10:00~17:00（12:00~13:00为准备时间，11:30、16:30停止入场）。
  • 休息日：每周一（周一若是法定节假日则开放，在之后的第一个工作日休息）。青瓷制作体验场和青瓷销售处全年无休。
  • 费用：成人2,000韩元，青少年1,500韩元，儿童1,000韩元。停车免费。
  • 青瓷制作体验场：09:00~18:00，12:00~13:00为准备时间。11:00、17:00停止入场。
  • 青瓷销售处：09:00~17:30，12:00~13:00为准备时间。

🌉 Gau岛 — 走桥步行进入的岛

Gau岛，地址康津郡道岩面 (Singi-ri / 신기리)，电话 061-430-3349（文化观光科 (Culture and Tourism Division / 문화관광과)），是康津湾8个岛中唯一有人居住的岛。通过不通车的两座吊桥（青瓷桥 (Cheongja Bridge / 청자다리)·茶山桥 (Dasan Bridge / 다산다리)）步行进入。

  • 营业时间：全天开放，全年无休。
  • 步行：环岛生态探访路“一起走的路 (Hamkkehae-gil / 함께해 길)”长2.5㎞，步行需要1小时~1小时30分钟。
  • 单轨列车，电话 061-433-8856：每隔15分钟开往岛顶的青瓷塔 (Celadon Tower / 청자타워)。10~2月 09:00~16:30，3·9月 09:00~17:00，4~8月 09:00~18:00，12:00~13:00为午餐时间。车票按往返计算。
  • 注意：垃圾必须带出岛外，食物不能带入。

📜 茶山草堂 — 丁若镛居住过的地方

茶山草堂，地址康津郡道岩面 (Dasan Chodang-gil / 다산초당길) 68-35，电话 061-430-3911，是朝鲜后期实学家丁若镛在康津流放期间，从1808年起居住10多年、教授弟子和著书的地方。《牧民心书》《经世遗表》就是在这一时期完成的。

  • 营业时间：09:00~18:00，全年无休。可停车。
  • 看点：复原的东庵 (Dongam / 동암)和西庵 (Seoam / 서암)、相传由丁若镛亲手刻下的“丁石”、烧水煮茶的药泉 (Yakcheon / 약천)、天一阁 (Cheonilgak / 천일각)。

⚠ 常见的3个失误

  1. 以为马良Nolto水产市场每天都开 — 只在4~10月的周六营业。
  2. 周一去高丽青瓷博物馆 — 博物馆每周一休息。青瓷制作体验场和销售处营业。
  3. 带便当去Gau岛 — 禁止带入食物，垃圾必须带出岛外。
