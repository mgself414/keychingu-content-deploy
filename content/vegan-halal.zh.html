外国人常犯的5个误区

1. "纯素=韩国没有"的误解

韩国纯素餐厅自2020年后爆发式增长 — 梨泰院 (Itaewon / 이태원)·汉南 (Hannam / 한남)·弘大 (Hongdae / 홍대)·延南 (Yeonnam / 연남)·圣水 (Seongsu / 성수) 已有100+家纯素餐厅。加上寺庙料理·素食系列，外国纯素游客一周饮食完全没问题。

2. 寺庙料理=纯素的简单假设

寺庙料理是肉·海鲜 X + 五辛菜 (葱·蒜·韭菜·野蒜·兴渠) X，与一般纯素属于不同类别。韩国寺庙料理餐厅数量有限，但堪称正统韩式纯素首选。

3. 韩国餐厅"纯素"菜单100%信任

韩国普通餐厅的"可纯素"，往往未验证高汤·食用油·发酵调料。若追求真正纯素，请选择认证纯素餐厅或外国人纯素餐厅。

4. 以为清真=只有梨泰院 (Itaewon / 이태원)

清真餐厅遍布梨泰院 (Itaewon / 이태원) 伊斯兰清真寺街 + 江南 (Gangnam / 강남)·明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 部分门店。东南亚·中东·土耳其餐厅是主力。韩国清真寺认证门店可在韩国伊斯兰中央会 (KMF / 한국이슬람중앙회) 官网查询。

5. 依赖过敏原标注

韩国餐厅的过敏原标注仅部分为英文。麸质·坚果·甲壳类·鸡蛋·牛奶·大豆过敏者，须英文菜单 + 直接询问员工 + 图片辅助三重确认。

1️⃣ 纯素 (Vegan) — 一切动物性食材 X

韩国纯素餐厅分布：

  • 梨泰院 (Itaewon / 이태원)·汉南 (Hannam / 한남)：外国人友好纯素咖啡·早午餐 30+家
  • 延南 (Yeonnam / 연남)·圣水 (Seongsu / 성수)·弘大 (Hongdae / 홍대)：MZ世代潮流纯素餐厅 20+家
  • 仁寺洞 (Insadong / 인사동)·钟路 (Jongno / 종로)：正统寺庙料理 5+家

经验证的韩国纯素品牌 (参考)：

  • 普兰提 (Planty / 플랜티)：纯素韩食 (汉南 (Hannam / 한남)·梨泰院 (Itaewon / 이태원))
  • 乐施纯素咖啡 (Lush Vegan Cafe)：纯素早午餐 (弘大 (Hongdae / 홍대))
  • 瓦蒂德 (Vatted / 바티드)：纯素西餐 (圣水 (Seongsu / 성수)·延南 (Yeonnam / 연남))
  • Whole Foods Market (韩国部分门店)：纯素食材
  • 禅材 (Seonjae / 선재)：正统寺庙料理 (仁寺洞 (Insadong / 인사동))

纯素韩食菜单推荐：

  • 拌饭 (Bibimbap / 비빔밥)：要求去掉肉·鸡蛋 + 确认辣椒酱是否纯素
  • 紫菜包饭 (Gimbap / 김밥)：要求去掉鸡蛋·火腿·金枪鱼
  • 喜宴面 (Janchi-guksu / 잔치국수)：要求去掉小鱼干·肉汤底 (较难实现)
  • 寺庙料理：豆腐·山野菜·杂粮饭 100% 纯素

确认关键词：

  • "비건이에요 (Vegan-ieyo)" = "我是纯素者"
  • "고기·생선·계란·우유·꿀 다 빼주세요" = "请去掉肉·鱼·鸡蛋·牛奶·蜂蜜"

2️⃣ 清真 (Halal) — 伊斯兰饮食

韩国清真餐厅分布：

  • 梨泰院 (Itaewon / 이태원) 伊斯兰清真寺街：清真主街 (梨泰院站 (Itaewon-yeok / 이태원역) 步行5~10分钟)
  • 江南 (Gangnam / 강남)·明洞 (Myeongdong / 명동)·弘大 (Hongdae / 홍대) 部分门店：印度·土耳其·马来西亚·印度尼西亚餐厅

经验证的韩国清真品牌 (参考)：

  • 梨泰院 (Itaewon / 이태원) 伊斯兰清真寺街：土耳其·巴基斯坦·埃及·马来西亚·印度尼西亚餐厅 20+家
  • 伊德清真餐厅 (Eid Halal / 이드)：韩式清真 (首尔部分地区)
  • 印度餐厅 (梨泰院 (Itaewon / 이태원)·江南 (Gangnam / 강남))：Bombay Curry·Saffron 等

韩国清真寺认证门店：

  • KMF (韩国伊斯兰中央会 / 한국이슬람중앙회) 认证门店查询 = 官方网站
  • 门店入口设有"Halal Certified"标识

清真韩食选项 (有限)：

  • 韩式排骨·烤五花肉 = 猪·牛屠宰方式常不符合清真标准 → 须提前确认清真认证韩食餐厅
  • 韩式辣炒鸡·海鲜 = 部分门店可清真
  • 韩式拌饭·喜宴面 = 可要求去掉高汤·肉 (实质上接近纯素)

3️⃣ 无麸质 (Gluten-Free)

韩国无麸质餐厅 (有限)：

  • 韩国料理的酱油·辣椒酱多含小麦 → 须直接确认
  • 汉南 (Hannam / 한남)·狎鸥亭 (Apgujeong / 압구정)·江南 (Gangnam / 강남) 无麸质咖啡·餐厅 10+家
  • 以米为基底的韩食 (米饭·杂粮·年糕 (Tteok / 떡)) 通常可无麸质

确认关键词：

  • "글루텐 알레르기예요 (Gluten allergy-ieyo)" = "我有麸质过敏"
  • "밀가루·간장 빼주세요" = "请去掉面粉·酱油" (酱油是韩食核心，较难实现)

4️⃣ 洁食 (Kosher) — 犹太教饮食

韩国洁食餐厅 (极度有限)：

  • 梨泰院 (Itaewon / 이태원) 部分门店提供洁食选项
  • 以色列·中东餐厅部分可提供
  • 韩国目前几乎没有官方洁食认证门店 → 建议自行备餐或使用纯素选项替代

FAQ

Q1. 英语通用吗？

纯素咖啡·清真餐厅 95%可用英语沟通。寺庙料理·正统韩食部分提供英文菜单。

Q2. 纯素·清真认证在哪里确认？

  • 清真：KMF (韩国伊斯兰中央会 / 한국이슬람중앙회) 官方网站 / 门店入口标识
  • 纯素：韩国纯素协会网站 / Happy Cow App

Q3. 韩国普通餐厅"可纯素"？

需要确认。高汤·食用油·发酵调料·鱼露可能混入。100%保证纯素只有认证门店。

Q4. 全家纯素·清真？

梨泰院 (Itaewon / 이태원)·汉南 (Hannam / 한남)·弘大 (Hongdae / 홍대) = 家庭友好纯素·清真门店众多，英文菜单 + 过敏原标注 + 儿童椅普及。

Q5. 基于韩国料理的纯素·清真选项？

  • 纯素：寺庙料理·拌饭 (去肉·去蛋)·豆腐韩食
  • 清真：清真认证韩食餐厅 (有限) → 韩食 + 提前确认认证

Q6. 便利店纯素·清真？

韩国纯素协会认证便利店系列 (CU·GS25·7-Eleven部分门店 — 纯素紫菜包饭 (Gimbap / 김밥)·便当·零食)。清真几乎没有 → 建议选择水果·坚果·矿泉水。
