⚠ 외국인 자주 실수 5가지

1. "박물관 = 다 비쌈": 한국 박물관 = 국립 5+ 무료 (국립중앙·MMCA 일부·민속·한글·SeMA·간송 정기) + 외국인 가성비 1번지·외국인 매니아.

2. "영어 도슨트 = 없음": 영어 도슨트 = 국립중앙·MMCA·리움·SeMA·호암 외국인 영어 OK + 1일 2-3회·예약 권장·외국인 매니아.

3. "리움 = 비쌈만": 리움 = 한국 #1 사립 + 정기 무료 입장 + Mario Botta·Jean Nouvel·Rem Koolhaas 3 건축·외국인 인스타 1번지.

4. "DDP = 야경만": DDP = Zaha Hadid 건축 + 디자인 박물관 + 외국인 매니아 1번지 + #172·#366·#260 통합.

5. "외곽 박물관 = 못 감": 외곽 박물관 = 호암 (용인 #512)·뮤지엄 산 (원주 안도 다다오)·외국인 매니아 외곽 + 1박2일 KTX·#430·#512 통합.
