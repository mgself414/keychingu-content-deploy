📍 南山公园·南山首尔塔·南山八角亭

南山公园(Namsan Gongwon / 남산공원)，中区(Samil-daero 231 / 삼일대로 231)，☎ 02-3783-5900，正式名称是南山都市自然公园(Namsan Dosi Jayeon Gongwon / 남산도시자연공원)。本来的名字是Ingyeong山(Ingyeongsan / 인경산)，朝鲜太祖把都城从开城迁到首尔之后，因为是位于南面的山，就叫作南山。1991年起8年间，通过"南山恢复原貌"工程(Namsan Jemoseup Gakkugi / 남산제모습 가꾸기)，迁移了公园内89栋设施，并建起了野外植物园。2005年5月1日起，公园内禁止一般小客车和出租车通行。前往南山首尔塔，要从明洞(Myeongdong / 명동)、忠武路(Chungmuro / 충무로)、东大入口站(Dongdaeipgu-yeok / 동대입구역)乘坐循环巴士或南山缆车(Namsan Keibeulka / 남산케이블카)，或者步行攀登。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

南山首尔塔(Namsan Seoul Taweo / 남산서울타워)，龙山区(Namsan Gongwon-gil 105 / 남산공원길 105)，☎ 02-756-2486，是兼具广播电波收发和观光瞭望功能的塔。据韩国观光公社介绍，这是韩国国内第一座综合电波塔。也以综艺和电视剧拍摄地而闻名。通往塔上瞭望台的路上挂着"爱情锁"。

  • 开放时间:平日10:00~22:30，周末10:00~23:00。休息日:全年无休。
  • 停车:可以。

南山八角亭(Namsan Palgakjeong / 남산 팔각정)，中区(Yejang-dong 8-1 / 예장동 8-1)，☎ 南山公园 02-3783-5900，是南山山顶的亭子，可以俯瞰首尔市区和夜景。可以步行攀登，也可以乘南山循环巴士或南山缆车上去。

  • 开放时间:全天开放。休息日:全年无休。

📍 步行路 — 南山环城步道·南山国耻路

南山环城步道(Namsan Dullegil / 남산둘레길)，中区(Namsan Gongwon-gil 609 / 남산공원길 609)，☎ 南山公园 02-3783-5900，是以首尔塔为起点绕南山一圈的路，全长7.3km，大约要走2小时30分钟。依次连接北侧循环路(Bukcheuk Sunhwanno / 북측순환로)、历史文化路(Yeoksa Munhwagil / 역사문화길)、自然生态路(Jayeon Saengtaegil / 자연생태길)、野花园路(Yasaenghwawongil / 야생화원길)、山林森林路(Sallim Supgil / 산림숲길)。

  • 北侧循环路(Bukcheuk Sunhwanno / 북측순환로):从南山缆车入口到国立剧场(Gungnip Geukjang / 국립극장)共3.4km。禁止汽车和自行车通行，路中间有盲道。被选定为轮椅、婴儿车使用者和视障人士容易行走的无障碍散步路。
  • 沿路可见的地方:安重根义士纪念馆(An Junggeun Uisa Ginyeomgwan / 안중근 의사 기념관)、蚕头峰Photo Island(Jamdubong Poto Aillaendeu / 잠두봉 포토아일랜드)、爱情锁、南山首尔塔。
  • 开放时间:全天开放。休息日:全年无休。

南山国耻路(Namsan Gukchigil / 남산국치길)，中区Juja洞(Juja-dong / 주자동)，☎ 明洞观光咨询处(Myeongdong Gwangwang Annaeso / 명동관광안내소) 02-774-3238，是南山Yejang山麓(Yejang Jarak / 예장자락)约1.7km的历史探访路。首尔市为铭记1910年庚戌国耻等丧失国权的现场而修建。从曾是韩国统监官邸(Hanguk Tonggam Gwanjeo / 한국통감관저)所在地、签订韩日合并条约的南山Yejang公园(Namsan Yejang Gongwon / 남산예장공원)出发，沿着地面上形如韩文字母giyeok(ㄱ)的标志，经过韩国统监府(Hanguk Tonggambu / 한국통감부)旧址、乃木神社(Nogi Sinsa / 노기신사)旧址、甲午战争获胜后日本殖民者建立的Gabo Yeok纪念碑(Gabo Yeok Ginyeombi / 갑오역기념비)、京城神社(Gyeongseong Sinsa / 경성신사)旧址，通向朝鲜神宫(Joseon Singung / 조선신궁)旧址。路的尽头有首尔日军"慰安妇"受害者纪念碑(Seoul Ilbongun Wianbu Pihaeja Girimbi / 서울 일본군 '위안부' 피해자 기림비)。

  • 开放时间:全天开放。休息日:全年无休。

📍 南山野外植物园·南山谷韩屋村

南山野外植物园(Namsan Yaoe Sikmulwon / 남산 야외식물원)，龙山区梨泰院洞(Itaewon-dong / 이태원동)，☎ 02-798-3771，建在因"南山恢复原貌"工程而拆除的汉南洞(Hannam-dong / 한남동)外国人住宅旧址上，1997年2月18日开放。沿着散步路可以看到随季节变化的花和树。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

南山谷韩屋村(Namsangol Hanokmaeul / 남산골한옥마을)，中区(Toegye-ro 34-gil 28 / 퇴계로34길 28)，☎ 传统住宅运营办公室(Jeontong Gaok Unyeong Samusil / 전통가옥 운영사무실) 02-6358-5533，文化观光解说 02-2133-6269，1998年建在南山北侧原首都防卫司令部(Sudo Bangwi Saryeongbu / 수도방위사령부)旧址的79,934㎡土地上。迁建或复原了散布在首尔各处的5栋韩屋，设有传统工艺馆(Jeontong Gongyegwan / 전통공예관)、Cheonu阁(Cheonugak / 천우각)、传统庭园、首尔南山国乐堂(Seoul Namsan Gugakdang / 서울남산국악당)、首尔千年时间胶囊(Seoul Cheonnyeon Taimkaepsyul / 서울천년타임캡슐)广场。

  • 体验:穿韩服(Hanbok / 한복)、折韩纸(Hanji / 한지)、写韩文(Hangeul / 한글)、喝传统茶、传统礼仪学校、韩方体验。周六、周日会真实举办传统婚礼，也可以体验传统婚礼。在Pigeum亭(Pigeumjeong / 피금정)院子里可以玩踢毽子(Jegichagi / 제기차기)、掷柶游戏(Yutnori / 윷놀이)、打碑石(Biseokchigi / 비석치기)，并有传统文化遗产解说员常驻。
  • 开放时间:4~10月09:00~21:00，11~3月09:00~20:00。
  • 休息日:每周一。周一为公休日时，次日休息。
  • 停车:可以。婴儿车租赁:可以。

📍 活动 — 南山烽燧仪式等传统文化活动

南山烽燧仪式等传统文化活动(Namsan Bongsuuisik Deung Jeontong Munhwa Haengsa / 남산봉수의식 등 전통문화행사)，南山烽燧台(Namsan Bongsudae / 남산 봉수대)和普信阁(Bosingak / 보신각)，☎ 活动现场 02-319-1220，运营方 02-737-6444，是再现朝鲜时代通信手段烽燧(Bongsu / 봉수)的首尔市活动。南山烽燧台是汇集全国烽火台传来的烽火并报告都城的地方。2026年于1月1日~12月31日11:00~15:40举办，费用免费。

  • 节目:南山烽燧台的烽火仪式和历史解说、每天正午普信阁市民常设敲钟、南山塔八角亭广场的四物游戏(Samulnori / 사물놀이)表演和传统武艺示范、一日烽燧军(Bongsukkun / 봉수꾼)体验。

⚠ 提前了解的3点

  1. 南山公园禁止一般小客车和出租车进入 — 乘循环巴士、南山缆车或步行攀登。
  2. 南山谷韩屋村周一休息 — 11~3月20:00关门。
  3. 南山烽燧仪式的登记期间截至2026年12月31日 — 11:00~15:40，免费。

⚙ FAQ 2

Q. 怎么上南山首尔塔?

A. 按观光公社登记信息，从明洞、忠武路、东大入口站乘循环巴士或南山缆车，或者步行攀登。一般小客车和出租车不能进入公园。

Q. 有行走不便的人也能去的路吗?

A. 南山环城步道北侧循环路(南山缆车入口~国立剧场3.4km)。被选定为无障碍散步路，禁止汽车和自行车通行。
