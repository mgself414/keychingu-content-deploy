🎯 왜 한국 죽 매트릭스인가

외국인 한국 죽 페인포인트 = "전복죽만 알고 있다". 한국 죽 = 호텔 조식 #1 + 해장 매니아 + 한정식 입맛 돋움. 같은 "Korean porridge"라도 전복죽 (제주·럭셔리 #1)·호박죽 (가을·따뜻)·황태죽 (해장 정통)·참깨죽 (한정식 코스 1단계)·잣죽 (궁중 정통)·녹두죽 (해독·여름) 각자 다른 재료·계절·매니아. 외국인은 (a) 전복죽 = 일본 오카유 차이 모름 (b) 황태죽 = 해장음식 모름 (c) 호텔 조식 죽 표준 모름 (d) 한정식 죽 = 코스 1단계 모름. 본 가이드는 6종 매트릭스 + 호텔 조식·해장·한정식 + 외국인 입문 우선순위.

🍚 6종 deep dive

🦪 전복죽 (Jeonbok-juk) — 럭셔리 #1

  • 시그니처: 제주 정통·호텔 조식 #1·럭셔리 입문
  • 재료: 전복 + 쌀 + 참기름 + 김 + 달걀·소금
  • 외국인 친화도: ★★★★★ (글로벌 럭셔리·일본 오카유 인지)
  • 추천 매장:
  • 제주 전복죽 전문점 — 정통 #1
  • 신라호텔·롯데호텔 조식 — 럭셔리
  • 죽 전문점 (본죽·죽이야기) — 체인 가성비
  • 가격: 12,000~25,000원 (전문점) / 30,000~50,000원 (호텔)

🎃 호박죽 (Hobak-juk) — 가을

  • 시그니처: 가을 시그니처·따뜻·달콤
  • 재료: 단호박 + 쌀가루 + 꿀·잣
  • 외국인 친화도: ★★★★ (글로벌 호박 인지·달콤)
  • 계절: 가을 (9~11월)
  • 추천 매장: 죽 전문점·전통 식당·MZ 카페
  • 가격: 8,000~15,000원

🐟 황태죽 (Hwangtae-juk) — 해장 #1

  • 시그니처: 강원 정통·술 다음날 해장 #1·따뜻
  • 재료: 황태 (말린 명태) + 쌀 + 참기름 + 김 + 계란
  • 외국인 친화도: ★★★★★ (해장 정통·#1 매니아)
  • 추천 매장:
  • 강원 황태 마을 (인제·평창) — 정통
  • 서울 황태죽 노포 — 종로·강남
  • 죽 전문점 (본죽) — 체인 가성비
  • 계절: 연중 (겨울 #1)
  • 가격: 10,000~18,000원

⚪ 참깨죽 (Chamkkae-juk) — 한정식 정통

  • 시그니처: 한정식 코스 1단계·정통
  • 재료: 검은깨·흰깨 + 쌀 + 꿀
  • 외국인 친화도: ★★★★ (정통 매니아)
  • 추천 매장: 한정식집·호텔 한식당
  • 가격: 한정식 코스 포함

🌰 잣죽 (Jat-juk) — 궁중 정통

  • 시그니처: 궁중 정통·럭셔리·달콤
  • 재료: 잣 + 쌀 + 꿀
  • 외국인 친화도: ★★★★★ (궁중 정통·신라 라연)
  • 추천 매장: 한정식 코스·호텔 한식당·궁중요리
  • 가격: 한정식 코스 포함

🌱 녹두죽 (Nokdu-juk) — 해독·여름

  • 시그니처: 녹두 + 해독 효능 (전통)·여름·시원
  • 재료: 녹두 + 쌀
  • 외국인 친화도: ★★★ (건강 매니아)
  • 계절: 여름 (6~9월)
  • 가격: 8,000~15,000원

🍽 호텔 조식·해장·한정식 시그니처

호텔 조식 #1

  • 신라호텔·롯데호텔·웨스틴 조선·포시즌스 — 죽 6종 풀세트 조식
  • 가격: 호텔 조식 = 60,000~120,000원/인 (죽 포함)
  • 외국인 친화도: ★★★★★ (영어·1순위)

해장 1순위 매니아

  • 황태죽 = 강원 인제·평창 정통
  • 녹두죽 = 여름 해장
  • 본죽 24h = 도심 해장

한정식 코스 1단계

  • 참깨죽·잣죽 = 한정식 6단계 코스 1단계 (입맛 돋움)
  • 신라호텔 라연·삼청각·인사동 한정식 — 정통 매장

⚠ 외국인 자주 실수 5가지

1. "한국 죽 = 일본 오카유": 한국 죽 = 참기름·김·계란 정통·일본 오카유 = 우메보시. 다른 음식.

2. "황태죽 = 일반 죽": 황태죽 = 해장 1순위 + 강원 정통.

3. "잣죽 = 일반 견과류죽": 잣죽 = 궁중 정통·럭셔리.

4. "전복죽 = 흔함": 전복죽 = 제주 정통 + 호텔 조식 럭셔리.

5. "죽 = 환자식": 죽 = 한국 정통 음식 (환자식·아침·해장·한정식 모두).

⚙ FAQ 8개

1. 외국인 입문 1순위: 전복죽 (럭셔리) + 호박죽 (가을·따뜻) → 황태죽 (해장).

2. 인스타·vlog: 호텔 조식 전복죽·강원 황태 마을·한정식 잣죽.

3. MZ 트렌드: MZ 카페 호박 라떼·전복죽 빙수 등 변형.

4. 해장 매니아: 황태죽 #1 (강원) + 녹두죽 (여름).

5. 호텔 조식: 신라·롯데·웨스틴 (60,000~120,000원/인).

6. 알레르기: 해산물 (전복)·견과류 (잣)·계란·꿀 사전 고지.

7. 결제·팁: 호텔 = 봉사료 10% + 부가세 10% / 일반 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

죽 = 일반 음식·소화 친화. 임신부 = OK. 어린이 = OK (뜨거움 주의). 알레르기 (해산물·견과류·계란·꿀) 사전 고지. 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 전복죽 (어류 OK 일부)·잣죽·참깨죽·호박죽·녹두죽 = OK / 황태죽 = 어류 (할랄 일부 OK).
  • 채식·비건: 호박죽·참깨죽·잣죽·녹두죽 = 채식 OK (꿀 함유 시 비건 X) / 전복죽·황태죽 = 비채식.
  • 글루텐 free: 6종 모두 쌀 100% = 글루텐 free OK.
