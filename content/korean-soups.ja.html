ISSUE 03 · #200 · 2026-05-19

🎯 なぜ韓国のクク・タン・チゲガイドなのか

韓国の食事の核心はクク（汁物）・タン（スープ）・チゲ（鍋物） — キムチチゲ・テンジャンチゲ・カルビタン・サムゲタン・ソルロンタン・プデチゲ・ヘジャンクク・メウンタンが韓国を代表する汁物料理です。外国人向け韓国料理のディープダイブで最優先されるものの一つ (外国人VloggerがBBQの次に最も頻繁に挑戦する料理)。

キーチング #14 韓国料理必須体験・#62 韓国の鶏料理に加え、韓国のクク・タン・チゲのフルセットを徹底解説します。

⚠ 外国人がよくする間違い3つ

1. 「辛い料理＝キムチチゲ・プデチゲ」: 辛い料理以外にも、テンジャンチゲ・カルビタン・ソルロンタン・サムゲタンといったマイルドなスープも韓国を代表する料理です。

2. 「サムゲタン＝冬の料理」: サムゲタンは夏の滋養食 (栄養補給のための料理) No.1です (韓国の三伏 (サムボク) — 初伏・中伏・末伏は7〜8月)。

3. 「プデチゲ＝韓国伝統」: プデチゲ (Budae Jjigae) は韓国戦争後 (1950年代) に米軍部隊の食材と韓国式のアレンジで生まれました。東豆川 (トンドゥチョン)・議政府 (ウィジョンブ) が発祥の地として有名です。

① キムチチゲ (Kimchi Stew) ★★

  • シグネチャー: 韓国の全ての韓国料理店 + ペクパン (定食)
  • 価格: ₩7,000~12,000 (~780 JPY~)
  • 食べ方: キムチ + 豚肉・ツナ + 豆腐 + ご飯 + 大根の甘酢漬け
  • 外国人需要: K-dramaで最もよく登場する料理
  • なぜ: 韓国No.1の家庭料理だから。

② テンジャンチゲ (Doenjang Stew)

  • シグネチャー: 本格的な韓国料理店
  • 価格: ₩7,000~12,000
  • 食べ方: テンジャン (韓国味噌) + 豆腐 + 野菜 + ご飯
  • なぜ: 韓国伝統の発酵味噌を使った料理だから。

③ カルビタン (Galbitang)

  • シグネチャー: 韓国のカルビ店 + ペクパン (定食)
  • 価格: ₩12,000~18,000
  • 食べ方: カルビ + 大根 + 麺 + キムチ
  • なぜ: 韓国のカルビスープの本格派だから。

④ サムゲタン (Samgyetang) ★ 夏の滋養食No.1

  • シグネチャー: トソクチョンサムゲタン (토속촌삼계탕) (光化門 (クァンファムン))・コリョサムゲタン (고려삼계탕) (北倉洞 (プクチャンドン))
  • 価格: ₩18,000~25,000
  • 食べ方: 鶏一羽 + 人参・もち米・ナツメ + ニンニク
  • 外国人需要: BBC・CNNで頻繁に紹介 + 夏の7〜8月は最優先
  • なぜ: 韓国No.1の夏の滋養食だから。外国人向け韓国料理のディープダイブで最優先されるものの一つ。

⑤ ソルロンタン (Seolleongtang) ★ 韓国No.1の牛骨スープ

  • シグネチャー: イムンソルロンタン (이문설농탕) (鍾路 (チョンノ), 韓国No.1の老舗 (30年以上の伝統店) 1904年創業)
  • 価格: ₩12,000~18,000
  • 食べ方: 白濁した牛骨スープ + 麺・ご飯 + ネギ・塩・胡椒は自由にセルフで
  • なぜ: 韓国No.1の牛骨スープの老舗 (イムンソルロンタンは韓国で最も古い食堂の一つ) だから。

⑥ プデチゲ (Budae Jjigae, Army Stew) ★★★

  • シグネチャー: ノルブプデチゲ (놀부 부대찌개)・東豆川 (トンドゥチョン)・議政府 (ウィジョンブ) の本格派
  • 価格: ₩12,000~18,000/人
  • 食べ方: ハム・ソーセージ・チーズ・ラーメン・キムチ・豆 + 辛いスープ
  • 外国人需要: K-dramaで最もよく登場 + 外国人にも馴染みのあるハム・チーズとの組み合わせ
  • なぜ: 韓国戦争後 (1950年代) に米軍部隊の食材と韓国式のアレンジで生まれ、韓国の本格料理となったから。

⑦ ヘジャンクク (#198 挑戦料理参照)

#198 外国人挑戦料理TOP 10を参照してください。

⑧ メウンタン (Maeuntang) ★★★★

  • シグネチャー: 鷺梁津水産市場 (ノリャンジン水産市場) (#181 銅雀 (トンジャク)・鷺梁津 (ノリャンジン)) の即席メウンタン
  • 価格: ₩15,000~30,000/人
  • 食べ方: 即席の刺身 + メウンタン (タラ・イシモチ・アンコウ・メバル)
  • なぜ: 韓国伝統の即席刺身 + 辛いスープだから。鷺梁津水産市場が一番です。

⑨ スンドゥブチゲ (Sundubu Jjigae) ★★

  • シグネチャー: プクチャンドン スンドゥブ (북창동 순두부)・本格的な韓国料理店
  • 価格: ₩9,000~13,000
  • 食べ方: 純豆腐 + 辛い味付け + 卵 + ご飯
  • なぜ: 韓国伝統の豆腐料理 (#175 麻谷 (マゴク)・メットルロマン (맷돌로만) の姉妹店) だから。

⑩ ユッケジャン (Yukgaejang) ★★★

  • シグネチャー: 韓国の全ての韓国料理店
  • 価格: ₩10,000~14,000
  • 食べ方: 辛い牛肉スープ + ワラビ・長ネギ・唐辛子油
  • なぜ: 韓国No.1の辛い牛肉スープだから。外国人にとって辛さへの挑戦No.1。

⑪ トックク (Tteokguk)

  • シグネチャー: 旧正月 (ソルラル) の家庭料理 + 本格的な韓国料理店
  • 価格: ₩9,000~13,000
  • 食べ方: 餅 + 牛肉スープ + 海苔・卵
  • なぜ: 韓国の旧正月 (旧暦の1月1日) No.1の料理 — 一杯食べると一つ歳をとると言われています。

⑫ コンナムルクッパ (Kongnamul Gukbap) ★ 全州式本格

  • シグネチャー: 全州式コンナムルクッパ + 鍾路 (チョンノ) チョンジン洞 (청진동) 24時間営業
  • 価格: ₩7,000~10,000
  • 食べ方: 豆もやし + 卵 + ご飯 + 海苔
  • 外国人需要: 24時間営業 + 外国人の二日酔い対策No.1
  • なぜ: 全州 (チョンジュ) 式の本格派 + 24時間営業で二日酔い対策になるから。

⚙ FAQ 6つ

1. サムゲタンの外国人向け店舗: トソクチョンサムゲタン (토속촌삼계탕) (光化門 (クァンファムン))、コリョサムゲタン (고려삼계탕) (北倉洞 (プクチャンドン)) — 英語メニュー + 外国人Vlogでよく紹介されています。

2. ソルロンタンの老舗: イムンソルロンタン (이문설농탕) (1904年創業) — 韓国で最も古い老舗の一つです。

3. プデチゲの発祥地: 東豆川 (トンドゥチョン)・議政府 (ウィジョンブ) (1950年代の米軍部隊 + 韓国式)。

4. メウンタンの辛さの段階: 鷺梁津水産市場 (ノリャンジン水産市場) の店舗で辛さの調節が可能です。

5. トッククは外国人でも大丈夫？: 1月の旧正月 (ソルラル) + 祝日の食堂 — 外国人でも自由に入店できます。

6. コンナムルクッパは24時間営業？: チョンジン洞 (청진동) (#198 ヘジャンクク) + 全州 (チョンジュ) の本格的な店舗。
