为什么现在要选乙支路sub——老字号+印刷+新复古潮人集群

与#597中部市场（1957年干货批发市场）的差异化＝乙支路集群全套（老字号·印刷街·新复古潮人·MZ）。乙支路4街·3街一带是1970年代印刷·工具·灯具老字号集群 + 2020年后新复古潮人咖啡厅·酒吧·快闪店达人数量暴增之地。

本矩阵由老字号集群3选 + 印刷·工具街3选 + 新复古潮人3选 + 周边cross 3选＝12选4轴构成。

乙支路对外国游客而言特别的理由：首尔其他地方难得一见的几层"时代"在同一区域共存。1970年代的五金·印刷·灯具巷弄依然照常营业,而这些巷弄深处的建筑2~3楼却入驻了潮人酒吧和咖啡厅。这和伦敦Shoreditch或东京高圆寺"老旧+崭新"并存的格局相似,不同的是这里真正的匠人白天依然在巷子里工作。

轴1：老字号集群深度攻略（3选）

1. 乙支面屋 (Euljimyeonok / 을지면옥)

位置：首尔中区乙支路16街一带（乙支路3街站步行5分钟）

营业时间：周一~周六11:00~21:00(食材售完提前打烊) / 周日·公休日休息

价格(2026)：冷面14,000韩元 / 饺子8,000韩元 / 水煮肉30,000韩元起

结算：可刷卡

位于乙支路巷弄深处的冷面老字号。自1960年代起营业至今,招牌菜是自家熬制高汤的水冷面。午间12~13点会排队,建议11点30分前入店。

外国人适配度：冷面对习惯汤类料理的日本游客尤其受欢迎。没有英文菜单——可用Google翻译App应对。说一句"naengmyeon"就能点单。

外国人注意事项：冷面面条非常长。用剪刀剪断食用是韩式吃法,提出要求店家会帮忙剪。

建议确认：营业时间·价格建议出发前在Naver地图等门户网站再次确认。

2. 于来屋 (Uraeok / 우래옥)

位置：首尔中区昌庆宫路62-29（乙支路4街站步行8分钟）

营业时间：11:30~21:30(休息时段15:00~17:00) / 周一休息

价格(2026)：平壤冷面15,000~16,000韩元 / 烤肉1人份25,000韩元起

结算：可刷卡

1946年开业,是首尔平壤冷面的代表性老字号。曾入选米其林指南首尔必比登推介,在外国达人间颇有名气。高汤以牛肉·雉鸡·鸡肉调配熬制而成,面条荞麦比例高,带有特有的清淡口感。

外国人适配度：★★★★★。得益于米其林认证,吸引不少英语圈美食旅行者(food traveler)专程前来。即使排队也大多在40分钟以内。

最佳时段：开门后立即入店(11:30)等待最短。周六·周日12~14点可能等待1小时以上。

英语应对：部分员工可用基础英语。没有图片菜单——建议参考Google地图评论中的照片。

3. 河东馆 (Hadongkwan / 하동관)

位置：首尔中区明洞9街12（乙支路入口站步行5分钟）——建议确认地址

营业时间：07:00~16:00(食材售完提前打烊) / 周日休息

价格(2026)：牛骨汤13,000~16,000韩元(单一菜品)

结算：优先现金,部分可刷卡(建议确认)

1939年开业,是首尔历史最悠久的牛骨汤老字号之一。盛在砂锅里的牛骨汤以牛骨·内脏·牛胸肉长时间熬制而成。白米饭配萝卜块泡菜·辣白菜为基本配菜,以盐调味。

外国人适配度：★★★。适合喜欢清淡汤品的游客。汤中可能含有气味较重的内脏肉,有饮食限制的游客点单前需确认。

最佳时段：早上7~9点提早前往无需等待。中午12点后可能没有座位。

注意事项：没有英文菜单。菜品单一(牛骨汤),说一句"gomtang"就能解决点单。

轴2：印刷·工具·灯具街深度攻略（3选）

4. 乙支路印刷街

位置：乙支路3街~4街一带（乙支路3街站4号出口步行3分钟）

营业时间：工作日09:00~18:00 / 周末·公休日大多歇业

费用：免费探访

乙支路印刷街在1970~80年代曾是首尔市中心印刷产业的中心地带。如今仍有100余家小型印刷厂在营业,许多店铺可按张订购名片·贴纸·海报。巷弄深处还混杂着DTP(数码排版)工作室、装订店、覆膜店。

外国人适配度：★★★★★。对想体验首尔"活着的工业街区"的外国游客来说是隐藏瑰宝。可以近距离看到店铺白天真实作业的样子。拍摄店内画面前请先征得许可。

外国人实用提示：英语沟通较难。若只是探访,看看巷弄本身就足够。若想少量印制名片,建议在Naver地图搜索"乙支路印刷名片"后电话预约。

5. 乙支路工具街

位置：乙支路4街·5街一带（乙支路4街站步行5分钟）

营业时间：工作日09:00~18:00 / 周末部分歇业

销售螺丝、螺栓、电动工具、管道建材的零售·批发店铺密集的区域。市中心正中央还保留着这样的工具集散地本身就很特别。

外国人适配度：★★★。相较印刷街,为探访而来的外国游客较少。对工业·制造业基础设施感兴趣的旅行者来说是独特体验。若非实际购买零件,20~30分钟穿行探访即可。

6. 乙支路灯具街

位置：乙支路3街~4街印刷街附近（乙支路3街站步行5分钟）

营业时间：工作日10:00~19:00 / 周末部分营业

销售荧光灯、LED、装饰灯具、灯泡类商品的店铺集中区域,从单个到批量均可购买。夜间灯具店点亮的样品灯光,让整条巷弄本身呈现出明亮而独特的氛围。

外国人适配度：★★★★。对关注室内装饰的旅行者或摄影旅行者尤其有吸引力。光是欣赏独特的灯光就很值得,部分店铺也接受个人少量购买。

最佳时段：傍晚18~19点前往时灯具样品大多亮灯,有利于拍照。

轴3：新复古潮人深度攻略（3选）

7. 乙支路新复古咖啡厅·酒吧集群

位置：乙支路3街站周边巷弄（乙支路3街站2·4号出口半径300米）

营业时间：咖啡厅13:00~22:00 / 酒吧18:00~02:00(各店不同)

价格(2026)：咖啡·饮品8,000~15,000韩元 / 啤酒9,000~14,000韩元 / 鸡尾酒14,000~22,000韩元

结算：大多可刷卡

大约从2018年起,印刷·五金巷弄的建筑内开始陆续入驻咖啡厅和酒吧。特色是保留旧工厂建筑的水泥墙面与锈蚀铁架结构,只添加照明的装潢风格。进入2020年代后,随着潮流媒体的集中报道,外国游客数量快速增长。

代表区域特性：乙支路3街站附近被称为"潮乙支路 (Hipjiro / 힙지로)"的巷弄,并非某一家有招牌的店铺,而是分散在多条巷弄中的集群形态。建议在Naver地图或Google地图搜索"乙支路Hipjiro咖啡厅"确认当前营业中的店铺——开关店频繁。

外国人适配度：★★★★★。不少店铺有会说英语的员工。Instagram友好型空间多,深受MZ外国旅行者青睐。是想体验韩国"潮流社区"的外国游客的第一选择。

注意事项：具体店名开关店速度快,建议出发前在Google地图查看最新评论。本指南推荐以区域探访方式,而非依赖特定店名。

8. 乙支路快闪区域（3·4街一带）

位置：乙支路3~4街巷弄一带

营业时间：以周末为主,日程因活动而异

价格：免费~收费(因活动而异)

2022年以后,这里成为首尔快闪文化的核心据点之一。时尚品牌、K-beauty、唱片公司、独立艺术家团体会临时租下乙支路巷弄内的空置仓库或工厂建筑,举办为期数天至数周的快闪活动。

外国人适配度：★★★★。可就地体验韩国品牌快闪活动的机会。关注Instagram @hipjiro(힙지로)·@euljiropopup(을지로팝업)等账号可确认日程(建议确认——是否为官方账号尚不明确,建议同时用Google搜索核实)。

实用信息：若不事先了解日程,现场很难确认。建议出发前一天通过Google地图评论或Instagram确认当前正在进行的快闪活动。

9. 乙支路隐藏酒吧巷

位置：乙支路3街站周边狭窄巷弄深处

营业时间：夜间20:00~02:00(各店不同) / 多数周一休息

价格(2026)：啤酒9,000~14,000韩元 / 鸡尾酒15,000~25,000韩元

结算：可刷卡

许多小型酒吧没有招牌或招牌很小,藏身于铁门·窄楼梯之后。这些店铺常以"隐藏酒吧"、"无招牌酒吧"的形式在社交媒体上被介绍。因空间小(10~20个座位),部分店铺需要预约。

外国人适配度：★★★★。可用英语预约·点单的店铺正在增加。但未预约到访可能无法入场,建议通过Instagram或Google地图确认是否需要预约。

注意事项：为避免杜撰具体店名,本指南不记载具体店名。出发前请在Google地图搜索"乙支路酒吧Hipjiro"的最新结果,确认当前正在营业的店铺。

⚠️ 外国人常犯的3个失误

失误1：在老字号店期待英文菜单

乙支面屋·河东馆等老字号大多只有韩文菜单。可以准备Google翻译App的相机功能(图像翻译),或者如果是单一菜品(比如伸手指数量说"牛骨汤一份")即可解决。于来屋因米其林认证访客众多,备有可讲基础英语的员工。

失误2：周末造访印刷·工具街

这些巷弄是真实营业的商户聚集地。周末和公休日大多店铺都拉下卷帘门。工作日上午10点~下午5点之间才是巷弄"活着"的时段。

失误3：未预约就在夜间前往新复古酒吧

乙支路隐藏酒吧空间小,许多店铺实行预约制。尤其是周五·周六夜间,未预约往往无法入场。出发前务必通过Google地图评论或Instagram确认预约方式。

实用信息——交通·结算·语言

交通

  • 基本据点：乙支路3街站(2·3号线)或乙支路4街站(2·5号线)
  • 老字号(乙支面屋·于来屋)：从乙支路3~4街站步行5~10分钟
  • 河东馆：乙支路入口站(2号线)步行5分钟
  • 印刷·工具街：乙支路3街站4号出口步行3分钟
  • 新复古集群：乙支路3街站2·4号出口半径300米

移动提示：乙支路3街站与4街站直线步行15分钟。以两站为据点,按老字号(午餐)→印刷·工具街(下午)→新复古(傍晚·夜间)的顺序安排,可以轻松组成一日行程。

结算

  • 大多数老字号：可刷卡 / 河东馆建议优先确认是否收现金
  • 新复古咖啡厅·酒吧：大多可刷卡
  • 现金应急准备：部分老字号、工具·印刷街小型商户可能只收现金
  • ATM：乙支路3街站内部,周边便利店(CU、GS25、7-Eleven)均可使用

语言

  • 老字号：以韩语为主。务必准备Google翻译App(相机模式)
  • 新复古咖啡厅·酒吧：多数备有可讲英语的员工
  • 印刷·工具街：英语沟通较难。若只是探访则无需语言
  • 紧急电话：☎ 1330(旅游翻译,24小时)、☎ 1339(医疗英语)、☎ 112(警察)

常见问题6

Q1. 第一次造访乙支路该从哪里开始?

乙支路3街站4号出口。午餐前往附近老字号(乙支面屋或于来屋),下午探访印刷街,傍晚~夜间接续新复古咖啡厅·酒吧,这样的动线效率最高。

Q2. 老字号和新复古,哪个更"乙支路"?

两者都是乙支路的不同侧面。老字号代表1950~70年代的乙支路,新复古集群代表2020年代的乙支路。时间允许的话,午餐老字号+夜间新复古,两层都体验才能完整感受这个区域的魅力。

Q3. 价格水平如何?

老字号1人用餐13,000~20,000韩元。新复古咖啡厅饮品8,000~15,000韩元,酒吧饮品12,000~25,000韩元。若在广藏市场追加小吃,1人1天预算50,000~80,000韩元即可充分游览。

Q4. 能用英语点单·沟通吗?

新复古咖啡厅·酒吧集群大多可用英语。老字号则较为有限。大部分情况用Google翻译App就能解决。也可拨打1330旅游翻译(24小时免费电话)寻求帮助。

Q5. 一个人去也没问题吗?

老字号一个人用餐也很自然(设有柜台座位)。新复古酒吧独自到访的人也不少。工具·印刷街探访反而一个人更方便。

Q6. 相关指南系列?

按#597(中部市场)→#086(乙支路夜生活)→#585(钟路3街布帐马车)→#582(广藏市场)→#608(乙支路老字号·新复古,本指南)的顺序阅读,可以掌握乙支路·钟路区域的整体地形。
