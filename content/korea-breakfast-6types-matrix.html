🎯 왜 한국 아침 식사 매트릭스인가

외국인 한국 아침 페인포인트 = "호텔 조식만 알고 한식 아침 모름". 한국 아침 = (a) 한식 정통 (해장국·쌀공명·콩나물국밥) (b) 호텔 조식 (5성급 풀세트) (c) MZ 브런치 (서양·한식 fusion) (d) 가성비 (편의점·체인). 외국인은 (1) 해장국 = 다음날 #1 모름 (2) 호텔 조식 06:30~10:00 시간대 모름 (3) MZ 브런치 = SNS 인스타 모름 (4) 편의점 아침 = 24h 가성비 모름. 본 가이드는 6종 매트릭스 + 4채널 + 해장 cluster cross.

🍳 6종 deep dive

🍲 해장국 (Haejang-guk) — 다음날 #1

  • 시그니처: 다음날 #1·#807 국밥 cluster cross
  • 종류: 콩나물국밥·황태해장국·뼈해장국·꼬리곰탕
  • 시간: 24h·새벽 05:00~09:00 매니아 #1
  • 추천: 본죽·전주 콩나물·서울 황태·강원 정통
  • 가격: 8,000~15,000원/1인
  • 외국인 친화도: ★★★★★ (해장 #1)

🍚 쌀공명·돌솥 (Korean Rice Meal) — 정통

  • 시그니처: 한식 풀세트 + 반찬·국·김치
  • 재료: 밥 + 국 + 메인 + 반찬 풀세트
  • 시간: 06:00~10:00 (가정식)
  • 추천: 한정식·가정식 (#854)
  • 가격: 8,000~25,000원/1인
  • 외국인 친화도: ★★★★ (정통)

🏨 호텔 조식 (Hotel Breakfast) — 럭셔리 #1

  • 시그니처: 5성급 풀세트·양식·한식·일식
  • 시간: 06:30~10:00 (호텔별)
  • 추천: 신라호텔·롯데호텔·웨스틴 조선·포시즌스·반얀트리
  • 가격: 60,000~120,000원/1인 (+봉사료 10% + 부가세 10%)
  • 외국인 친화도: ★★★★★ (#1 글로벌)

🥐 MZ 브런치 (MZ Brunch) — MZ #1

  • 시그니처: 서양·한식 fusion·인스타 #1
  • 메뉴: 아보카도 토스트·에그 베네딕트·한식 fusion (김치 베이글·전통 죽 fusion)
  • 시간: 10:00~14:00
  • 추천: MZ 카페·홍대·강남·이태원·성수·연남
  • 가격: 15,000~30,000원/1인
  • 외국인 친화도: ★★★★★ (MZ #1·글로벌)

🥪 편의점 아침 (Convenience Breakfast) — 24h #1

  • 시그니처: 24h 가성비 #1·#810 편의점 cluster cross
  • 메뉴: 김밥·삼각김밥·도시락·차밀·핫바
  • 시간: 24h
  • 추천: CU·GS25·세븐일레븐·이마트24
  • 가격: 2,500~6,000원/1식
  • 외국인 친화도: ★★★★ (24h·영문 일부)

🍳 체인 분식·죽 (Chain Bunsik·Juk) — 가성비

  • 시그니처: 본죽·죽이야기·김가네·MZ 한식당
  • 메뉴: 죽·김밥·라면·MZ 한식
  • 시간: 06:00~22:00
  • 가격: 4,000~12,000원/1인
  • 외국인 친화도: ★★★★ (가성비)

⚠ 외국인 자주 실수 5가지

1. "호텔 조식 = 시간 자유": 호텔 조식 = 06:30~10:00 한정 (호텔별).

2. "해장국 = 매콤": 해장국 = 콩나물국밥(담백)·황태해장(맑음) 매콤 X·외국인 입문 OK.

3. "편의점 = 신선도 X": 편의점 = 24h 신선도 보장·가성비 #1.

4. "MZ 브런치 = 외국 음식": MZ 브런치 = 한식·서양 fusion (김치 베이글·전통 죽 fusion).

5. "쌀공명 = 일반 밥": 쌀공명 = 한식 풀세트 + 반찬·국 정통.

⚙ FAQ 8개

1. 외국인 입문 1순위: 호텔 조식 (럭셔리) + MZ 브런치 (트렌드).

2. 인스타·vlog: 호텔 조식·MZ 브런치 (#1).

3. MZ 트렌드: MZ 브런치 (#1).

4. 해장 매니아: 해장국 (#807 cross).

5. 24h 가성비: 편의점 (#1).

6. 알레르기·임신: 해산물·견과류·우유 사전 고지.

7. 결제·팁: 카드 OK / 호텔 = 봉사료 10% / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

아침 식사 = 일반 음식. 임신부·어린이 = OK. 알레르기 (해산물·견과류·우유·계란) 사전 고지. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.
