🎯 本指南使用方法

这是一份把秋季红叶与K-剧取景地合在一起的指南。我们按两条原则重写了它——① 红叶时间以2026年预报为准（韩国观光公社9/8·山林厅9/22·江原气象厅9/28），按来源原样列出；② 剧名只在观光公社官方页面直接写在该地点下时才使用。因此旧版指南中的“永宗岛=鬼怪”“松岛=阳光先生”“全州韩屋村=云画的月光”“南怡岛16,000韩元·07:30~21:40”“红叶盛期10/27~11/2”与官方信息不符，已删除。时间和票价依据2026-10-08的VisitKorea英文页面，可能比运营方官网更新得慢——出发前请再确认一次。

🎬 官方明确标注剧集的三处

  • 注文津防波堤 (Jumunjin Bangpaje / 주문진 방파제)（江陵 (Gangneung / 강릉)）：VisitKorea明确标注为《鬼怪》（2016）取景地。免费，户外。虽然没有红叶，但可以与江陵的秋日海景串联。旧版指南中的“永宗岛鬼怪”在官方页面上并不存在。
  • 宝城大韩茶园 (Boseong Daehan Dawon / 보성 대한다원)：官方页面写明了《夏日香气》《蓝色大海的传说》《逆贼》。门票4,000韩元。到11月仍是绿色茶园 + 周边红叶。
  • 安东河回村 (Andong Hahoe Maeul / 안동 하회마을)：提到是剧集取景地，但查阅的文本中没有剧名，所以不写。门票5,000韩元。河回村自家官网无法访问。

🍂 红叶本身——四座山·一座岛·一条路

  • 雪岳山 (Seoraksan / 설악산)：9/28观测到初红（江原气象厅），盛期10/20（山林厅）~10/25（观光公社）。缆车运行时间前一天公告，票价未公布（VisitKorea）。
  • 内藏山 (Naejangsan / 내장산)：盛期11/4~11/11。缆车往返8,000韩元·09~18时（VisitKorea）。红叶节只写了“10月”——井邑 (Jeongeup / 정읍) 市2026年日期未公布。
  • 北汉山 (Bukhansan / 북한산)：盛期11/4，免费。离首尔最近的红叶山（环山步道见#196）。
  • 南怡岛 (Namiseom / 남이섬)（春川 (Chuncheon / 춘천)）：08:00~21:00，成人19,000韩元（16,000韩元是优惠价）——更正旧版指南的数值。官网（namisum.com）返回403，所以采用VisitKorea的数值。
  • 潭阳水杉路 (Damyang Metasequoia-gil / 담양 메타세쿼이아길)：2,000韩元，仅春节·中秋休息。11月中旬呈黄褐色。

🏯 首尔宫阙——记住星期几

  • 昌德宫后苑 (Changdeokgung Huwon / 창덕궁 후원)：周一休息，宫3,000 + 后苑5,000韩元，只能参加导览参观入场。秋季特别参观·月光之旅2026年日期官方未核实（昌德宫网站无法访问）。
  • 景福宫 (Gyeongbokgung / 경복궁)：周二休息，3,000韩元，时间按季节。旧版指南的“两处都是09~18时·3,000韩元”是错的。

⚠ 常见错误5条

1. 把“盛期10/27~11/2”当作通用时间——2026年预报因山而异，从10/20到11/13。见上表。

2. 南怡岛16,000韩元——成人是19,000韩元。

3. 周一去昌德宫·周二去景福宫——休息日。

4. 把后苑当作自由参观——仅限导览参观，另收5,000韩元。

5. 到永宗岛找鬼怪——官方标注的是注文津防波堤。

⚙ FAQ 6条

1. 从首尔当天往返看红叶？——北汉山（11/4盛期）或昌德宫后苑（周一休息）。

2. 现在去雪岳山可以吗？——9/28起开始变红，盛期10/20~25。

3. 剧集取景地里秋天适合去哪？——宝城大韩茶园（4,000韩元）、南怡岛（19,000韩元）。

4. 内藏山的红叶节呢？——10月，2026年日期官方未公布。

5. 缆车票价多少？——内藏山往返8,000韩元。雪岳山未公布·前一天公告。

6. 为什么预报不一样？——观光公社（9/8）·山林厅（9/22）·气象厅（9/28）的发布时间和方法不同，最多相差1周。
