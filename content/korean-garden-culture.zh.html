韩国庭园文化 —— 借景，借自然入园的庭园（昌德宫后苑·潇洒园）

> 借景 (Chagyeong / 차경) · 自然原貌 · 极简人工 · 不对称 —— 写给外国人的韩国庭园文化解读。重点不是"哪座最美"，而是"韩国庭园为什么看起来很空，而这份空又为何是刻意为之"。

第一次走进昌德宫后苑或潇洒园 (Soswaewon / 소쇄원) 的外国人常常一头雾水。"说是庭园……这不就是一片树林加一汪池水吗？" 它既没有日本京都庭园那样梳得一丝不苟的碎石，也没有中国苏州庭园那般密密麻麻的奇石与楼阁。然而正是这份"空",才是韩国庭园的核心。韩国庭园并非征服自然、另起炉灶地新建，而是选择把现有的山、水、岩石原样留下，让人轻轻栖居其间。

本文不谈"哪座庭园美"（→那是地点指南），而是解读韩国庭园追求什么、为何长成这副模样，以及它与邻邦日本、中国的庭园有何不同。有一个词是解开它的钥匙 —— 借景 (Chagyeong / 차경)，也就是"把风景借来用"的发想。韩国文化解读系列第 73 篇。

⚠️ 外国人常误解的3件事

1. "既然这么空，大概是没打理好/还没建完吧" ❌ —— 韩国庭园的留白是刻意,而非懒惰或未完成。把人工物降到最低、让自然站到台前，正是其目标。哪怕一座亭子、一汪池塘，也只是"为了让人更好地享受自然"才安放，绝不自我炫耀。

2. "韩·中·日的庭园不都是相似的东方庭园吗" ❌ —— 这三者在哲学与外形上都判然不同。中国雄壮地再现，日本将自然缩小·抽象后精雕细琢，而韩国尽量不动手，栖居于现成的自然之中。同属东亚根源，结论却各异。

3. "昌德宫后苑 = 秘密花园（花圃）" ❌ —— 因英文别称"Secret Garden"，人们容易想象成华丽花圃，但后苑 (huwon / 후원) 是一座由树林·丘陵·池塘·亭子构成的自然式庭园。秘苑 (biwon / 비원)、禁苑 (geumwon / 금원) 意为"非请莫入（王室专用）的庭园",并非花圃之意。

① 何谓韩国庭园 —— 不是"造"自然，而是"引"自然

如果说西方庭园把自然重新排列成几何（凡尔赛宫左右对称的花坛），中国庭园把自然再现·压缩于一处，那么韩国庭园的出发点恰恰相反 —— 尽量不去触碰已有的自然。

造园的人挑选好地时，与其推平平地另造一番风景，不如寻一处有水流淌、有岩盘踞、有山环抱的所在，再于其间轻轻安上屋舍与亭子。若有余力凿池，便凿池植莲、于侧建亭来眺望；若有溪流，便傍水筑亭来聆听水声。关键动词不是"造",而是"眺望·享受"。因此韩国庭园中总会出现三样东西。

  • 池塘：方池之中置圆岛（天圆地方 (cheonwon-jibang / 천원지방)，天圆而地方）—— 东方宇宙观的缩影。
  • 楼亭 (nujeong / 누정)：无墙、只有立柱与屋顶的开敞建筑。四面通透，把外界风景原样引入。形状多为四角·六角·八角。
  • 流水·溪流：不是人工喷泉，而是把天然溪谷之水原样引来或留在身旁。

这份留白与节制，在外国人眼里或许"乏味",但对韩国人而言，正是自然为主角、人为宾客这一态度的表达。

② ★ 借景 (Chagyeong / 차경) —— 借风景而用的庭园核心哲学

若要用单一概念来说明韩国庭园，那便是借景 (Chagyeong / 차경)。字面即"把景致借来"之意 —— 与其把一切都造进庭园围墙之内，不如把墙外的山·天·江·远峰引入,使之成为庭园的一部分。

其原理简单而深邃。坐在亭中，越过立柱与屋檐、窗与门所构成的"画框"眺望外面的山，那座山纵非己有，却在那一刻成了自家庭园的风景。无须削山移入院中 —— 需要时"借"来看便是。韩国士人就这样透过窗与门这一人工框景来欣赏外界的自然。这一发想背后有着分明的世界观。

  • 人是自然的一部分（道教的无为自然 (muwi-jayeon / 무위자연) · 儒教的天人合一 (cheonin-habil / 천인합일)）。人并非占有·征服自然，而是融入其中。
  • 既如此，便没有理由把美景临摹一遍据为己有。自然本已完美，人只需备好一处善于眺望它的座位（亭子·窗）即可。
  • 庭园不是占有的对象，而是沉思·赋诗·治学的舞台。士人坐于亭中观自然、作诗、修心。

懂了借景，韩国庭园的"空"便有了不同的意味。那片空白，是为了让外面的风景进来而特意留出的位置。若说日本与中国的庭园把围墙之内填得满满当当，造出"自足圆满的世界",韩国庭园则降低围墙、敞开视野，志在一个与外界相连的开放世界。（日本也有同一概念 —— 借景，日语称 shakkei (シャッケイ)，但韩国几乎不动山势，日本则连借来的风景也要精密修整，纳入构图之中。）

③ 昌德宫后苑（秘苑）—— 君王的庭园，顺应自然的设计

最能体现借景与顺应自然之美的，是昌德宫后苑 (huwon / 후원)。这是朝鲜王室所用、位于宫殿后侧的庭园，由芙蓉池 (Buyongji / 부용지) · 爱莲池 (Aeryeonji / 애련지) · 观览池 (Gwallamji / 관람지) · 玉流川 (Ongnyucheon / 옥류천) 等数个区域构成。1997年整座昌德宫被列入UNESCO世界文化遗产，其核心价值正是原样保留自然地形的庭园设计。

  • 名称之意：后苑 (huwon / 후원) 指宫殿北侧·后侧的庭园；禁苑 (geumwon / 금원) 意为非请莫入、王室专用的庭园。秘苑 (biwon / 비원，Secret Garden) 这一名称自1900年代初开始使用。英文别称"Secret Garden"即源于此。
  • 不违逆自然的布局：后苑真正的可贵之处，在于不削不移地保留丘陵·溪谷·树林·水道，于其间安置建筑。从地下涌出的泉水注满爱莲池·芙蓉池并溢流而出，连水道也顺着自然的流向。此举被誉为"天与人合而为一"的天人合一 (cheonin-habil / 천인합일) 之体现。
  • 芙蓉池与芙蓉亭：方池（芙蓉池 (Buyongji / 부용지)）中央置圆岛的天圆地方 (cheonwon-jibang / 천원지방) 构成。坐于池畔之亭芙蓉亭 (Buyongjeong / 부용정)，池水·树林·天空尽收一框 —— 这是借景的教科书级场景。
  • 玉流川 (Ongnyucheon / 옥류천)：后苑深处，于岩石上凿出细小水道，君臣傍着流水赋诗之处。不取庞大的人工瀑布，而享小巧自然的溪流，韩国式的情致于此显露。

后苑背离了"君王的庭园想必华丽"的预想。王室没有选择炫耀权力的巨型造型，而是择取最谦卑地栖居于自然的庭园—— 这正是韩国庭园观的精髓。

④ 潇洒园与别墅庭园 —— 士人隐入自然的庭园

若说宫廷庭园属于王室，那么韩国庭园文化的另一根轴，便是士人的别墅庭园 (byeolseo-jeongwon / 별서정원)。"别墅"指辞官离朝后于自然中营建的别业式居所。其代表，便是全南潭阳的潇洒园 (Soswaewon / 소쇄원)。

  • 诞生背景：朝鲜中期士人梁山甫 (Yang San-bo / 양산보，1503~1557) 因恩师赵光祖于己卯士祸 (gimyo-sahwa / 기묘사화) 中罹难，遂绝意仕途，归乡而建此园。故潇洒园是士人欲背世而栖于自然之心所凝成的空间。
  • 名称之意：潇洒 (soswae / 소쇄) 意为"清而洁"，寄寓着离开政治浊流、清白度世的决心。
  • 以溪谷为中心的设计：潇洒园不是推平平地造出的庭园，而是把天然溪谷（溪流）原样置于正中，顺其流向布置建筑。不堵不改、留住水道，正是其核心。
  • 光风阁 (Gwangpunggak / 광풍각) 与霁月堂 (Jewoldang / 제월당)：溪畔之亭光风阁 (Gwangpunggak / 광풍각) 是迎客的舍廊，意为"雨过初晴吹来的清风"；霁月堂 (Jewoldang / 제월당) 是主人所居，意为"雨霁天空高悬的明月"。二名取自宋代学者称颂人格清明者为"光风霁月 (gwangpung-jewol / 광풍제월)"之语 —— 建筑之名本身,便是对清明人格的一份自勉。

潇洒园对外国人尤为有趣。它没有华丽看点，却把士人"在自然中如何安身立命"的人生观刻进每一处角落—— 庭园即其人之心,这正是极具韩国意味的发想。

⑤ 楼亭·池塘 —— 构成韩国庭园的小装置

懂了韩国庭园的"语法",到哪座庭园都能读出趣味。反复出现的核心装置有二。

楼亭 (nujeong / 누정) —— 无墙之亭

楼亭是韩国庭园的心脏。几乎不设墙壁，仅以立柱与屋顶四面敞开，坐于其中，外界风景便毫无阻碍地涌入 —— 它正是实现借景的装置。在亭中，人不"占有"自然，而"迎接"自然。在韩国·中国·越南等东亚地区，人们爱把它立于山间与庭园，形状多为四角·六角·八角。

池塘 —— 盛天纳地的器皿

池塘也不是单纯的水洼。以方池+圆岛的天圆地方 (cheonwon-jibang / 천원지방) 构成，承载着"天圆地方"的东方宇宙观。池中常植莲花、于侧设亭，以眺望映于水面的天·月·莲（昌德宫芙蓉池 (Buyongji / 부용지) 即为代表）。

二者一旦合而为一，韩国庭园的典型便告完成 —— 坐在临水的开敞之亭中，越过窗与檐眺望自然的那一处座位。在那里，人不再是征服自然的征服者，而成了欣赏自然的宾客。

⑥ ★★ 韩·中·日庭园 —— 同根，异果

同属东亚庭园，韩·中·日对待自然的态度却判然不同。借庭园学界爱用的比喻来梳理便是 —— 若韩国把自然1比1地移来，中国便是1比10（放大），日本则是1比1/10（缩小）地处理。

区分 🇨🇳 中国庭园 🇯🇵 日本庭园 🇰🇷 韩国庭园
态度 把自然再现·压缩 把自然缩小·抽象 把自然原样引入
规模感 雄壮（一眼难尽） 精密·小巧 自然原本的大小
人工美 奇石·楼阁密布，炫耀人工 碎石·苔藓·石块精巧排布 人工极简，不留斧凿痕
代表样式 苏州园林（奇石·回廊） 枯山水 —— 不用水，以沙·石抽象出风景 后苑·别墅庭园·楼亭
感受 压倒·壮阔 冥想·精密（修得齐整的微缩） 留白·素朴·开敞
  • 中国庭园把山·洞·瀑·奇石如实再现于庭园之内，以"规模"压倒为美德，宏大到一眼难以尽收。其发想是"把整个自然都搬进我心中"。
  • 日本庭园把自然缩小并抽象，精密修整。其代表是枯山水 (karesansui / カレサンスイ)—— 一滴水也不用，以沙的梳纹表水波、以石表岛屿与山峦的禅庭。每日梳理碎石以维持完美图案，是高度受控的"修得齐整的自然压缩本"。
  • 韩国庭园立于另一端。几乎不去触动现有的自然。 不移山，也不梳石。人所做的，不过是轻置一亭一池，造出一处更善于眺望自然的座位罢了。因此韩国庭园既不如日本精巧，也不如中国雄壮，但自然与人工的界线最为模糊。

一句话概括：中国把自然搬来，日本把自然修整，韩国栖居于自然。 三国同出道教·佛教·儒教之根，却在该把自然控制到何种程度上抵达截然相反的结论，颇为耐人寻味。

⑦ 外国人赏园实战 —— 这样看，韩国庭园就看懂了

以寻找"漂亮打卡点"的眼光去看，韩国庭园很乏味。换一种看法，它便会全然不同地向你走来。

  • 坐进亭中，去寻"画框"：韩国庭园的精髓，在你坐上亭子地板时开启。越过立柱·屋檐·窗所构成的框，望见的山·池·天 —— 那就是借景。别站着走过，坐下来眺望外面。
  • 把"空"读作刻意，而非缺陷：别因没有满满的花坛而失望。那份空，是为让外面的风景进来、也为让心歇息而特意留出的位置。
  • 连水声·清风·季节一同品味：韩国庭园不是仅供视觉的艺术。溪流的水声、穿亭而过的清风、春之新绿与秋之红叶般的季节变化，都是庭园的一部分。（→ 季节如何改变风景，参见 #1194。）
  • 参观贴士：昌德宫后苑为保护起见，只能以定时导览（建议预约·庭园入场另收费）入内 —— 出行前请查阅昌德宫官方指引。潇洒园位于潭阳，离首尔较远，但若想一睹"士人的庭园",值得一去。
  • 最佳季节：新绿的春（4~5月）与红叶的秋（10~11月），韩国庭园的借景最为生辉。因为所借的外界风景本身，正于此时最美。

> 实战一句话：到了韩国庭园，要问的不是"造了什么"，而是"坐在这里能看见什么"。这便是品味借景之道。

❓ 外国人常问的问题（FAQ）

  • 韩国庭园为何看起来比日本庭园"更不整齐"？ —— 是刻意如此。日本庭园把自然缩小·抽象、精密修整，而韩国庭园则以尽量不动自然为美德。这不是"不整齐",而是追求"自然原貌"的结果。
  • 借景 (Chagyeong / 차경) 究竟是什么？ —— 意为"把风景借来"。与其把一切都造进庭园围墙之内，不如把墙外的山·天引入庭园、视为其一部分来欣赏。坐在亭中越过窗与檐望外面的山，那座山便成了自家庭园的风景。
  • 昌德宫后苑可以随便进去吗？ —— 为保护起见，通常以导览方式限人数·限时段入场（庭园入场与宫殿入场另行收费·建议预约）。出行前务必在昌德宫官方指引中确认时间与预约方式。
  • 潇洒园在哪、为何有名？ —— 是位于全南潭阳的朝鲜时代别墅庭园 (byeolseo-jeongwon / 별서정원)。士人梁山甫 (Yang San-bo / 양산보) 离世隐于自然而建，以原样留住溪谷的设计及光风阁·霁月堂等亭子，代表了"士人的庭园"。
  • 韩·中·日庭园，一句话区分？ —— 中国把自然搬来（雄壮·再现），日本把自然修整（缩小·精巧·枯山水），韩国栖居于自然（原貌·留白·借景）。
