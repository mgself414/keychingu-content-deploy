한국 식사 마무리 음료 주문·페어 워크플로우 — 한정식 식혜부터 해장 매실차까지

부제: 외국인 관광객용 5-step 워크플로우 + 페어·시기·해장·온도·영어 발화

ISSUE 03 · #871 · 2026-06-09

🎯 왜 한국 식사 마무리 음료 워크플로우 가이드인가

[#870 식사 마무리 음료 6종 매트릭스](#870) 알아도 — 페어·시기·해장은 별개. 한국 식사 마무리 음료는 (a) 한정식 코스 마지막 (식혜 + 수정과·무료) (b) 가정식 후식 (식혜·매실차) (c) 해장 다음날 (매실차 + 해장수) (d) 전통주점 (동동주·식사 술). 외국인은 (1) 한정식 코스 끝 = 식혜 모름 (2) 동동주 = 술인지 음료인지 모름 (3) 매실차 = 따뜻 vs 차가운 시기 모름 (4) 해장수 = 다음날 새벽 매니아 모름. 본 가이드는 5-step + 페어 + 영어 발화.

★ 한눈에 5-step 워크플로우

Step 동작 시간 외국인 핵심 포인트
1️⃣ 채널 선택 한정식 / 가정식 / 해장 / 전통주점 즉시 마무리·후식·해장·술 목적
2️⃣ 메뉴 주문 식혜·수정과·매실차·동동주·해장수 1~3분 한정식 = 무료 포함
3️⃣ 받기·세팅 차가운 / 따뜻한 1~5분 시기·온도 매칭
4️⃣ 먹기·페어 식사 후·해장 다음날·식사 중 술 5~15분 매너
5️⃣ 결제 한정식 무료 / 가정식 카드 / 마트 영수증 1~3분 음료 단품 = 마트·카페

총 소요 시간: 한정식 마지막 = 5~10분 / 가정식 후식 = 5~10분 / 해장 = 15~30분 / 전통주점 = 1~3h

🍹 채널별 워크플로우

Type A — 한정식 마지막 ([#837](#837))

  • 시그니처: 6단계 코스 마지막 = 식혜·수정과·무료 포함
  • 시간대: 11:30~22:00 코스 끝
  • 가격: 한정식 코스 무료 포함
  • 메뉴: 식혜 + 수정과 (디저트)
  • 외국인 친화도: ★★★★

Type B — 가정식 후식 ([#854](#854))

  • 시그니처: 홈스타일·식혜·매실차·후식
  • 시간대: 식사 후
  • 가격: 가정식 무료 포함
  • 메뉴: 식혜·매실차
  • 외국인 친화도: ★★★★ (가성비)

Type C — 해장 다음날 ([#807](#807))

  • 시그니처: 해장 매니아·매실차 + 해장수·다음날 새벽
  • 시간대: 새벽·아침
  • 가격: 8,000~15,000원 (국밥집·24h 본죽)
  • 메뉴: 매실차 + 해장수·콩나물 국물
  • 외국인 친화도: ★★★ (해장 매니아)

Type D — 전통주점·MZ 막걸리 ([#840](#840))

  • 시그니처: 동동주·식사 술·전통주
  • 시간대: 18:00~24:00
  • 가격: 5,000~15,000원/병
  • 메뉴: 동동주 + 안주
  • 외국인 친화도: ★★★★ (MZ 막걸리)

🌶 외국인 영어 발화 샘플

  • "식혜 1잔" = "One Sik-hye (sweet rice drink), please"
  • "한정식 마지막 음료" = "The final drinks (rice sweet drink + cinnamon punch)"
  • "동동주 = 술" = "Dong-dong-ju is a traditional rice wine (6~8% alcohol)"
  • "매실차 따뜻하게" = "Plum tea, hot, please"
  • "해장수" = "Hangover cleansing soup-drink for the next morning"
  • "카드 돼요?" = "Card accepted?"

⚠ 외국인 자주 실수 7가지

1. "식혜 = 식해": 식혜 = 음료 (단맛) / 식해 = 반찬 (생선 발효) — 다른 음식.

2. "동동주 = 음료": 동동주 = 6~8% 알코올 술 (식사 술·전통).

3. "한정식 음료 = 비용": 한정식 마지막 음료 = 무료 포함.

4. "수정과 = 차": 수정과 = 계피·생강·곶감 펀치 (차 X).

5. "매실차 = 일반 차": 매실차 = 약재 음료 (소화·해장).

6. "해장수 = 일반 국물": 해장수 = 다음날 새벽 콩나물 국물·해장 매니아.

7. "마트 음료 = 비싸다": 마트 캔 = 2,000~7,000원 (한정식 무료 포함 시 마트 X).

⚙ FAQ 8개

1. 첫 마무리 음료 = 어디서: 한정식 코스 마지막 (#1 무료 식혜+수정과) → 가정식 후식.

2. 인스타·vlog: 한정식 식혜 #1·수정과 곶감·동동주 전통.

3. MZ 트렌드: MZ 카페 식혜 변형·동동주·매실 스파클링.

4. 소화·해장: 매실차 (소화) + 해장수 (다음날).

5. 알코올·임신: 동동주 = 6~8%·임신부·운전 X.

6. 알레르기·임신: [#870 disclaimer](#870) 참조.

7. 결제·팁: 한정식·가정식 = 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

식사 마무리 음료 = 일반 음식. 임신부·어린이 = 식혜·수정과·매실차·해장수 OK (동동주 = X 술). 알레르기 (잣·생강) 사전 고지. 운전·임신 = 동동주 X. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 식혜·수정과·매실차·해장수 = OK / 동동주 = 알코올 X (할랄 X) / 식해 = 어류 OK.
  • 채식·비건: 5종 채식 OK / 식해 = 비채식.
  • 글루텐 free: 6종 모두 OK (간장 함유 시 Tamari 대체).

💰 Essential Tourist Tips

  • 1인 평균 비용 (2026년 6월 기준):

  • 가정식 후식 (식혜·매실차) = 무료
