首尔日票健身房·运动9处 — 在弘大·梨泰院·江南·圣水只运动一天

副标题: 不办长期会员、只付一天费用就能进的首尔健身房6家、攀岩馆2家，以及圣水的K-pop舞蹈工作室1家。它们集中在弘大入口站·梨泰院站·江南站周边，很容易选到离住处近的一家。每家店都标了一天的费用、入场方式、运动服·毛巾·淋浴和营业时间。

#769 · 2026-11-24 修订 · 首尔运动

🎯 适合这样的人

适合旅行中也想把运动习惯保持下去的人。首尔的健身房一般按几个月办会员，但也有不少卖一天使用票(日票)的店。这一篇只留下了日票或单次票的价格能在官方页面或标有日期的到访评价里确认的店。这些店在Kakao地图 (Kakao Map / 카카오맵) 上都显示营业中，并且有2026年10~11月发布的评价或照片。

⚠ 标注原则: 营业时间是Kakao地图的值(2026-11-24确认)。店主按星期登记了时间的店标为"Kakao地图店主登记"，只有本周显示时间的店标为"Kakao地图显示时间"。Kakao地图上没有的值取自官方页面或标有日期的评价，并附上了出处。价格优先用官方页面的值(2026-11-24确认)，没有的话用2024-11-24以后写的Naver博客到访评价里的值。价格可能因分店情况而变动。地铁出口和步行时间是Kakao地图导航的值。

① 弘大入口站 — 健身房3家 + 攀岩馆1家

四家店都在弘大入口站(2号线·机场铁路·京义中央线)步行1~2分钟的距离。这里是从仁川机场乘机场铁路直达的街区，抵达当天就去运动也很合适。

Able Gym健身房 弘大入口站店 (Able Gym Hongik Univ. Station / 에이블짐 홍대입구역점)

位于LC Tower地下2层的大型健身房。Kakao地图上的店主登记时间是周一06:00起到周五24:00不间断营业，公休日是09:00~21:00。Kakao地图上没有周末时间。博客评价(2026-01-10)里写的是周六00:00~21:00, 周日09:00~21:00, 每月第二个周日休息。按博客评价(2025-09-29)，日票是30,000韩元，连停车一起是35,000韩元。在服务台登记后用App打卡(评价 2025-04-25)。运动服按尺码和毛巾一起备好(同一篇评价)。评价里没写是否含在日票里。当日入场说明上写着只能入场1次、"不是24小时"。还写着没有室内鞋就不能使用，贵重物品要寄存在柜台(评价 2025-07-27)。地址是麻浦区 (Yanghwa-ro 186 / 양화로 186)，从弘大入口站4号出口步行1分钟。

Healthboy Gym Pilates Girl弘大店 (Healthboy Gym Pilates Girl Hongdae / 헬스보이짐필라걸 홍대점)

健身房和器械普拉提一起经营。周一06:00至周五24:00连续营业, 周六00:00~21:00, 周日·公休日10:00~21:00(Kakao地图店主登记)。公司官方博客(2025-09-22)上用英文并列写着日票25,000韩元(Day Pass: KRW 25,000)和"外国人也可以使用"。2026-09-13的评价也是25,000韩元，并写着写Naver评价可以优惠到20,000韩元。2026-06-21的评价说运动服和毛巾放得很充足。评价里没写是否含在日票里。地址是麻浦区 (Yanghwa-ro 176 / 양화로 176) 地下1层，从弘大入口站8号出口步行2分钟。

Gymboxx健身房 弘大入口站店 (Gymboxx Fitness Hongik Univ. Station / 짐박스피트니스 홍대입구점)

位于Mercure Ambassador首尔弘大酒店 (Mercure Ambassador Seoul Hongdae / 머큐어 앰배서더 서울 홍대) 大楼的地下1~2层。官方网站上写的是单次票(1 TIME PASS)15,000韩元, 当天使用1次, 含会员服。这是这一篇里最便宜的。官方时间是工作日06:00~24:00, 周末09:00~21:00, 全年无休，Kakao地图显示时间也一样。按2026-02-15的评价，打卡后去更衣室，提供毛巾，淋浴间有6间。地址是麻浦区 (Yanghwa-ro 144 / 양화로 144)，从弘大入口站9号出口步行2分钟。

The Climb攀岩馆 延南店 (The Climb Yeonnam / 더클라임 연남점)

是不用绳子攀爬低矮岩壁的抱石专门攀岩馆。按官方会员页面，一日使用票是22,000韩元(当天1个分店)。攀岩鞋租赁3,000韩元、镁粉1,000韩元另付(官方英文页面)。官方问答说，完全没有攀岩经验的话，要和有经验的人一起去，或者上完体验课再使用。体验课30,000韩元里含必修课程、一日使用和攀岩鞋租赁。体验课按各分店固定的时间、4人名额预约制进行(官方问答)。Kakao地图店主登记时间是周一至周五07:30~24:00, 周六·周日·公休日08:00~22:00。官方英文页面写的是工作日从07:00开始。博客评价(2026-10-12)里写着工作日白天人也很多，外国人也很多。地址是麻浦区 (Yanghwa-ro 186 / 양화로 186) 3层，和Able Gym健身房 弘大入口站店在同一栋楼。从弘大入口站4号出口步行1分钟。

② 梨泰院 — 健身房2家

梨泰院健身房 (Itaewon Gym / 이태원짐)

位于东湖广场 (Dongho Plaza / 동호프라자) 6层的地上健身房。Kakao地图店主登记时间是周一至周五24小时, 周六·周日·公休日09:00~21:00，同一个Kakao地图上还写着每月第三个周日定期休馆(2026-11-24)。2025-07的两篇评价写着周一06:00开门。日票是22,000韩元(评价 2025-07-29, 2025-07-31)。2025-03-05的评价作者写道，会员服和毛巾好像含在日票里。按同一篇评价，女更衣室·淋浴间在6层，男用的在下一层。2026-10-22的Kakao地图评价作者说，来梨泰院的话会用日票来使用。地址是龙山区 (Itaewon-ro 17-gil 8 / 이태원로17길 8)，从梨泰院站1号出口步行5分钟。

This Is Gym健身房 (This Is Gym / 디스이즈짐)

位于梨泰院路大路边3层的健身房。不是走1层的门，而要从建筑左侧的石阶走上去才是入口(评价 2025-09-07)。工作日06:00~23:00, 周六·周日10:00~18:00, 公休日12:00~17:00(Kakao地图店主登记)。日票是22,000韩元(评价 2025-10-20, 2025-09-07)。按2025-10-20的评价，没有公用运动服，只给毛巾。有淋浴间，室内鞋要自己带。穿着运动服去，或者另外带上。地址是龙山区 (Itaewon-ro 216 / 이태원로 216)，从梨泰院站3号出口步行7分钟。

③ 江南站 — 健身房1家 + 攀岩馆1家

Healthboy Gym江南站店 (Healthboy Gym Gangnam Station / 헬스보이짐 강남역점)

位于江南站3号出口前Fastfive大楼 (Fastfive Building / 패스트파이브빌딩) 地下的大型健身房。Kakao地图显示时间(2026-11-24)是周一至周五06:00~24:00, 周六·周日08:00~21:00。日票是25,000韩元(评价 2026-09-12)。按2025-02-23的评价，日票含毛巾和运动服，储物柜也不另收费。同一篇评价写着淋浴间很多、有吹风机。地址是江南区 (Teheran-ro 2-gil 27 / 테헤란로2길 27)，从江南站3号出口步行3分钟。

The Climb攀岩馆 江南店 (The Climb Gangnam / 더클라임 강남점)

和延南店是同一家公司，所以价格和体验课规定相同。一日使用票22,000韩元, 攀岩鞋3,000韩元(官方)，日票当天只能在一个分店使用。Kakao地图店主登记时间是周一至周五09:30~23:30, 周六·周日·公休日08:00~22:00。官方英文页面写的是工作日从07:00开始。同一页面提示要从室外楼梯下面的入口进去。地址是江南区 (Teheran-ro 8-gil 21 / 테헤란로8길 21) 地下1层，从江南站3号出口步行8分钟。

④ 圣水 — 舞蹈1家

1MILLION舞蹈工作室 (1MILLION Dance Studio / 원밀리언댄스스튜디오)

以K-pop编舞视频闻名的舞蹈工作室。官方网站(英语·韩语·日语)的票务页面上写的是1 Class 30,000 KRW。不用办正式课程券，只买单次票就能上一节课。Kakao地图显示时间(2026-11-24)是周一至周五16:00~22:00, 周六·周日15:00~21:30，实际课程要看网站的课表。按带有联盟佣金声明的博客文章(2026-10-10)，流程是这样的。在网站或App上注册，上传露脸的头像照片，买票后预约课程。在工作室用我的页面里的二维码入场。同一篇文章说，课前60分钟之前可以取消，直接不去的话会扣票。2026-08-02的Kakao地图英文评价写道，空间氛围很好，但不适合一步一步地学舞。第一次的话先选入门课。地址是城东区 (Ttukseom-ro 13-gil 33 / 뚝섬로13길 33)，从圣水站3号出口步行9分钟。

🗺 一天组合2种

A. 弘大抵达日 — 从机场铁路直接过来

  1. 从仁川机场乘机场铁路在弘大入口站下车
  2. 在4号出口LC Tower 3层的The Climb攀岩馆 延南店 (The Climb Yeonnam / 더클라임 연남점) 用体验课(30,000韩元)试一试抱石。体验课是预约制，按各分店固定的时间、4人名额开课，所以要通过官方网站或Naver预约提前订好时间
  3. 想再做力量训练的话，换到同一栋楼地下2层的Able Gym(30,000韩元)或9号出口的Gymboxx(15,000韩元)。日票原则上一天入场1次，所以在一个地方做完比较好

B. 梨泰院周末早晨

  1. 在周六·周日09:00开门的梨泰院健身房 (Itaewon Gym / 이태원짐) 运动。每月第三个周日休馆(Kakao地图)
  2. 如果是第三个周日，或者上午晚了，就换成10:00开门的This Is Gym健身房 (This Is Gym / 디스이즈짐)。周六·周日18:00关门
  3. 运动后走下来到梨泰院站一带吃午饭

⚠ 常见错误3

  1. 不带室内鞋就去 — Able Gym健身房 弘大入口站店说明没有室内鞋就不能使用，This Is Gym健身房 (This Is Gym / 디스이즈짐) 也有评价说要带室内鞋。带一双和在外面穿的鞋不同的干净运动鞋。
  2. 以为附近的大型连锁店都行 — Spoany健身房 (Spoany / 스포애니) 的官方问答只介绍了1年会员和Prestige会员，没有日票的说明。日票每家店不一样，所以像这一篇一样，去一天费用已确认的店。
  3. 以为周末时间和工作日一样 — 工作日通宵营业的健身房，周末也有很多在21:00关门。This Is Gym健身房 (This Is Gym / 디스이즈짐) 周六·周日18:00关门。Able Gym健身房 弘大入口站店每月第二个周日休息，梨泰院健身房 (Itaewon Gym / 이태원짐) 第三个周日休息。

⚙ FAQ 3

  1. 需要护照吗? — 这一篇9处店的官方说明里，没有买日票时要求护照的内容。1MILLION按带有联盟佣金声明的博客文章，注册时要上传露脸的头像照片。
  2. 可以不带运动服去吗? — 确认日票含运动服的店有Gymboxx(官方, 含会员服)和Healthboy Gym江南站店(评价 2025-02-23)。梨泰院健身房 (Itaewon Gym / 이태원짐) 是评价作者写好像含在内。This Is Gym健身房 (This Is Gym / 디스이즈짐) 只给毛巾。攀岩馆按官方说明带上长裤和袜子。
  3. 第一次攀岩，只买日票可以吗? — The Climb官方问答说，完全没有经验的话，要和有经验的人一起来，或者上完体验课再使用。体验课(30,000韩元)里含一日使用和攀岩鞋租赁。按官方标准，初中2年级(15岁)以上可以使用。
