🎯 このガイドの使い方

秋の紅葉とK-ドラマのロケ地を一度にまとめたガイドです。次の二つの原則で書き直しました。① 紅葉の時期は2026年の予報(韓国観光公社 9/8・山林庁 9/22・江原気象庁 9/28)を出典ごとにそのまま記載し、② ドラマ名は韓国観光公社の公式ページがその場所に直接書いている場合にのみ使います。そのため、以前のガイドにあった「永宗島=トッケビ」「松島=ミスター・サンシャイン」「全州韓屋村=雲が描いた月明かり」「南怡島 (Namiseom / 남이섬)16,000ウォン・07:30~21:40」「紅葉の見頃 10/27~11/2」は公式と異なるため外しました。時間・料金は2026-10-08時点のVisitKorea英語ページ基準で、運営会社のサイトより更新が遅れている場合があります。出発前にもう一度ご確認ください。

🎬 ドラマが公式に結びついている3カ所

  • 注文津防波堤 (Jumunjin Bangpaje / 주문진 방파제)(江陵 (Gangneung / 강릉)): VisitKoreaが『トッケビ』(2016)のロケ地として明記しています。無料、屋外。紅葉はありませんが、江陵 (Gangneung / 강릉)の秋の海と組み合わせられます。以前のガイドにあった「永宗島のトッケビ」は公式ページにありません。
  • 宝城大韓茶園 (Boseong Daehan Dawon / 보성 대한다원): 公式ページが夏の香り・青い海の伝説・逆賊を挙げている場所です。入場4,000ウォン。11月まで緑の茶畑 + 周辺の紅葉を楽しめます。
  • 安東河回村 (Andong Hahoe Maeul / 안동 하회마을): ドラマのロケ地として言及されていますが、タイトルは閲覧したテキストにないため記載しません。入場5,000ウォン。河回村の公式サイトは接続できませんでした。

🍂 紅葉そのもの — 山4つ・島1つ・道1つ

  • 雪岳山 (Seoraksan / 설악산): 9/28に初紅葉を観測(江原気象庁)、見頃は10/20(山林庁)~10/25(観光公社)。ケーブルカーは運行時間を前日に告知し、料金は未掲示です(VisitKorea)。
  • 内蔵山 (Naejangsan / 내장산): 見頃は11/4~11/11。ケーブルカー往復 8,000ウォン・09~18時(VisitKorea)。紅葉まつりは「10月」とだけあり、井邑 (Jeongeup / 정읍)市の2026年の日程は未掲示です。
  • 北漢山 (Bukhansan / 북한산): 見頃は11/4、無料。ソウルからいちばん近い紅葉の山です(トゥレギルは#196)。
  • 南怡島 (Namiseom / 남이섬)(春川 (Chuncheon / 춘천)): 08:00~21:00、一般 19,000ウォン(16,000ウォンは割引価格) — 以前のガイドの値を訂正。公式サイト(namisum.com)は403のため、VisitKoreaの値です。
  • 潭陽メタセコイア並木道 (Damyang Metasequoia-gil / 담양 메타세쿼이아길): 2,000ウォン、旧正月・秋夕のみ休み。11月中旬に黄褐色になります。

🏯 ソウルの宮殿 — 曜日を覚えておく

  • 昌徳宮後苑 (Changdeokgung Huwon / 창덕궁 후원): 月曜日休み、宮 3,000 + 後苑 5,000ウォン、ガイドツアーでのみ入場できます。秋の特別観覧・月明かり紀行の2026年の日程は公式に未確認です(昌徳宮のサイトに接続できません)。
  • 景福宮 (Gyeongbokgung / 경복궁): 火曜日休み、3,000ウォン、時間は季節ごと。以前のガイドの「どちらも09~18時・3,000ウォン」は誤りでした。

⚠ よくある間違い5つ

1. 「見頃は10/27~11/2」と決めてしまう — 2026年の予報は山ごとに10/20~11/13です。上の表をご覧ください。

2. 南怡島 (Namiseom / 남이섬)16,000ウォン — 一般は19,000ウォンです。

3. 月曜日の昌徳宮・火曜日の景福宮 — 休みです。

4. 後苑を自由観覧だと思う — ガイドツアーのみで、5,000ウォンが別にかかります。

5. 永宗島でトッケビを探す — 公式は注文津防波堤 (Jumunjin Bangpaje / 주문진 방파제)です。

⚙ FAQ 6

1. ソウルから日帰りで紅葉を見るなら? — 北漢山 (Bukhansan / 북한산)(11/4が見頃)または昌徳宮後苑 (Changdeokgung Huwon / 창덕궁 후원)(月曜休み)。

2. 雪岳山 (Seoraksan / 설악산)は今行っても大丈夫? — 9/28から色づき始め、見頃は10/20~25です。

3. ドラマのロケ地で秋におすすめの場所は? — 宝城大韓茶園 (Boseong Daehan Dawon / 보성 대한다원)(4,000ウォン)、南怡島 (Namiseom / 남이섬)(19,000ウォン)。

4. 内蔵山 (Naejangsan / 내장산)の紅葉まつりは? — 10月、2026年の日程は公式に未掲示です。

5. ケーブルカーの料金は? — 内蔵山 (Naejangsan / 내장산)は往復 8,000ウォン。雪岳山 (Seoraksan / 설악산)は未掲示で、前日に告知されます。

6. なぜ予報が違うの? — 観光公社(9/8)・山林庁(9/22)・気象庁(9/28)で発表時点と方法が異なるため、最大1週間の差が出ます。
