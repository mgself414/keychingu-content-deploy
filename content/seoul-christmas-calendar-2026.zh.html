① 百货店外观·媒体立面 — 傍晚集中去看

新世界总店 (Shinsegae Main Store / 신세계 본점)从17:00到午夜播放影像。现代百货·加勒里亚的装饰在营业时间内观看。现代首尔 H Village (The Hyundai Seoul H Village / 더현대 서울 H빌리지)(11/10~12/31)见#746。

  • 新世界总店「新世界广场」 (Shinsegae Square / 신세계스퀘어) — 在总店外墙的媒体立面上放映圣诞影像。期间到2027年1月31日，每天17:00~24:00播放。公开日是11月6日(新世界集团新闻中心 (Shinsegae Group Newsroom / 신세계그룹 뉴스룸) 2026-11-05)。地址是中区 (Sogong-ro 63 / 소공로 63)，最近的站是会贤站 (Hoehyeon / 회현역)(4号线)(Kakao地图)。影像在建筑外面观看，所以和百货店的休息日(11/30等，Kakao地图登记)无关，都能看。
  • 现代百货贸易中心店「纽约城圣诞节」 (Christmas in New York City / 크리스마스 인 뉴욕 시티) — 现代百货从10月27日的贸易中心店开始，在全部门店推出了纽约街道主题装饰(现代百货新闻稿·News1 10/30)。正门广场有13m的圣诞树和拍照区，10层有6m的猫咪造型和黄色出租车。结束日期没有公告。地址是江南区 (Teheran-ro 517 / 테헤란로 517)，最近的站是三成站 (Samseong / 삼성역)(2号线)。
  • 加勒里亚名品馆 (Galleria Luxury Hall / 갤러리아 명품관) — 与诺悠翩雅(Loro Piana)合作布置的外观装饰和名品馆东广场的圣诞树，10月30日~12月31日悬挂(Etoday·News1 2026-11-02报道)。Kakao地图登记名是「加勒里亚百货 WEST店」 (Galleria Department Store WEST / 갤러리아백화점 WEST점)。地址是江南区 (Apgujeong-ro 343 / 압구정로 343)，最近的站是狎鸥亭罗德奥站 (Apgujeong Rodeo / 압구정로데오역)(水仁盆唐线)。

  • 饼干咖啡馆 (All the Ugly Cookie & Tremont / 올더어글리쿠키&트레몽) — 合井站 (Hapjeong / 합정역)7号出口一侧土亭路上的饼干咖啡馆。使用1~2层。其他登记价是拿铁₩5,500、奶茶₩7,500。地址是麻浦区 (Tojeong-ro 45 / 토정로 45)，最近的站是合井站 (Hapjeong / 합정역)(2·6号线)。没有停车场。饮食提示: 饼干通常含面粉·黄油·鸡蛋。Kakao地图标签里有迪拜软糯饼干，迪拜式通常用开心果(坚果)和卡达依夫(小麦)。拿铁·奶茶含牛奶。
  • 甜点咖啡馆 (Jamsi / 잠시) — 首尔站西侧青坡路 (Cheongpa-ro / 청파로)的甜点咖啡馆。很多菜单以睡眠为主题取名。其他登记价是晚安·甜睡₩6,000、Jamsi₩6,500、安眠饼干₩3,500。地址是龙山区 (Cheongpa-ro 330-32 / 청파로 330-32)，最近的站是首尔站 (Seoul Station / 서울역)13号出口(按Kakao地图步行约8分钟)。有可携带宠物的标签。饮食提示: 安眠饼干在店主说明里写有巧克力·燕麦·核桃·花生酱，有坚果过敏的话要避开。布蕾菜单会配冰淇淋(乳制品)。
  • 咖啡酒吧 (Iceberg Lounge / 아이스버그 라운지) — 文来洞 (Mullae-dong / 문래동)印刷厂小巷里的咖啡馆兼鸡尾酒吧。Instagram介绍(@cafe.ing，11/20)里出现了红地毯·水晶吊灯·圣诞树。白天卖咖啡和甜点，晚上卖鸡尾酒。其他登记价是芝士蛋糕·提拉米苏₩10,000、The Black(波本鸡尾酒)₩18,000。Kakao地图时间是每天12:00~24:00(最后点单23:30)，但Instagram介绍里写的是周一休息。周一不要排进行程。地址是永登浦区 (Dorim-ro 143-gil 14 / 도림로143길 14)，最近的站是文来站 (Mullae / 문래역)(2号线)。没有停车场。饮食提示: 鸡尾酒菜单含酒精。「The Iceberg」(₩8,000)在店主说明里写的是无酒精威士忌冷萃。「The Cloud」(₩7,000)含夏威夷果(坚果)奶油。芝士蛋糕·提拉米苏含乳制品。
  • 大型咖啡馆 (Another Side / 어나더사이드) — 鉢山站 (Balsan / 발산역)附近的大型咖啡馆。Instagram介绍(@cafe.ing，11/14，标注广告)里出现了圣诞树和圣诞拍照区。其他登记价是可颂套餐₩7,500、火腿黄油三明治套餐₩10,300。地址是江西区 (Gangseo-ro 318 / 강서로 318)，最近的站是鉢山站 (Balsan / 발산역)(5号线)。大楼地下停车场免费2小时(Kakao地图)。饮食提示: 火腿黄油三明治含猪肉火腿和黄油。胡萝卜丝鸡蛋三明治含鸡蛋，金枪鱼三明治含鱼。拿铁·可颂含牛奶·黄油。

🗺 路线 — 晚上两条线

A. 明洞~光化门~清溪川 (12/11以后)

  1. 白天 在世宗文化会馆帘幕花园 (Curtain Call Garden / 커튼콜가든)冬季市集(11:00~21:00)吃鲷鱼烧·喝热红酒
  2. 黄昏 新世界总店 (Shinsegae Main Store / 신세계 본점)媒体立面(17:00起)
  3. 晚上 在清溪广场 (Cheonggye Plaza / 청계광장)沿着首尔灯笼庆典 (Seoul Lantern Festival / 서울빛초롱축제)(18:00~23:00)向三一桥 (Samil Bridge / 삼일교)方向步行

12月11日之前请走B路线。

B. 蚕室的晚上

  1. 下午 乐天世界冒险乐园 (Lotte World Adventure / 롯데월드 어드벤처)巡游(14:00) — 只限有门票的日子
  2. 18:00~21:00 乐天世界购物中心 (Lotte World Mall / 롯데월드몰)时间秀(整点)。如果预约了乐天城圣诞市集 (Lotte Town Christmas Market / 롯데타운 크리스마스 마켓)就一起看(#746)
  3. 夜晚 石村湖圣诞灯饰 (Seokchon Lake Luminarie / 석촌호수 루미나리에)(~22:30)

⚠ 常见失误 3

  1. 11月下旬第一周就期待爱宝乐园巡游 — 圣诞心愿 (Christmas Wish / 크리스마스 위시)11/21开始，但11/21~26只有圣诞树。巡游·烟花从27日开始。
  2. 12月初去找灯笼 — 清溪川首尔灯笼庆典 (Seoul Lantern Festival / 서울빛초롱축제)12月11日开始。那之前的晚上去看新世界总店 (Shinsegae Main Store / 신세계 본점)立面或石村湖圣诞灯饰 (Seokchon Lake Luminarie / 석촌호수 루미나리에)。
  3. 把圣诞假期当成平常的晚上来安排 — 12/25(周五)~27(周日)是三天假期，纛岛 (Ttukseom / 뚝섬)市集也在这段时间(12/24~27)举行。户外活动人多，要搭配室内的咖啡馆·百货店。防寒准备见#1318。

⚙ FAQ 3

  1. 只有一天的话? — 如果是12月11日以后，推荐A路线。明洞 (Myeongdong / 명동)新世界立面(17:00~)和清溪川 (Cheonggyecheon / 청계천)灯笼(18:00~23:00)距离比较近。
  2. 12月24日夜里哪里开放? — 按表格，新世界立面(~24:00)、灯笼(~23:00)、石村湖 (Seokchon Lake / 석촌호수)(~22:30)、纛岛市集(~21:00)、帘幕花园(~21:00)当天都在运营期间内。咖啡馆·酒吧里，按Kakao地图登记，Iceberg Lounge (Iceberg Lounge / 아이스버그 라운지)营业到24:00。
  3. 光化门市集·明洞大教堂圣诞活动呢? — 光化门市集 (Gwanghwamun Market / 광화문 마켓)只公布了12/11~2027/1/10的日期，地点·时间未公开。明洞大教堂 (Myeongdong Cathedral / 명동대성당)没有2026年公告(截至2026-11-24)。上一季的信息见#746，灯光景点见#745。
