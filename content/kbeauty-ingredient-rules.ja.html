同じブランド、違う処方 — 韓日化粧品規制の文法と成分表の読み方

副題: "同じ製品なのに日本版と韓国版で成分が違う?"――思い違いではなく制度の違いだ。医薬部外品の承認制と機能性化粧品の告示制がどう違うのか、売り場で何を確認すべきかを解説する成分リテラシー編。

ISSUE · #1335 · 2026-08-29

🎯 フレーム——その疑問は正しい

日本人旅行者コミュニティで実際に繰り返し出てくる質問がある。「同じ製品なのに、ドン・キホーテで買った日本版と韓国版で成分表示が違う」。まず答えから言うと——違うことはあり得るし、それはメーカーの気まぐれではなく、両国規制の構造の違いによるものだ。この文法を知っておくと、オリーブヤング (Olive Young / 올리브영) (#47) の売り場で成分表を読む目が変わる。

① 両国の制度の文法 — 承認制 vs 告示制

🇯🇵 日本 🇰🇷 韓国
枠組み 化粧品 / 医薬部外品の2段階 化粧品 / 機能性化粧品 (gineungseong hwajangpum / 기능성화장품) の2段階
仕組み 美白などの「有効成分」は医薬部外品として承認されないと配合できない——成分・濃度が承認リストで管理される 美白・シワ改善などは食薬処 (Sikyakcheo / 식약처) 告示の成分・条件を満たせば「機能性化粧品」として表示できる
結果 有効成分の種類・濃度が保守的に管理される 告示成分基準(例:美白はナイアシンアミド2%以上、シワはアデノシン0.04%)を満たせば表示可能——それ以外の成分配合の自由度は相対的に高い
体感 「強い成分が入った製品は少ない」 「複合処方・高濃度をうたう製品が多い」
  • 代表例がトラネキサム酸だ——日本では医薬部外品にしか配合できない承認有効成分のため、一般化粧品には配合できない。だから同じ系統の製品でも、市場によって処方が分かれる。
  • 逆に韓国の売り場には、レチノール・複合成分を前面に出した製品がはるかに多い——規制が緩いからではなく、管理方式が違うだけだ。

② では旅行者にとって何を意味するのか — 三つの文

1. 韓国でしか出会えない処方が実際に存在する——これがK-ビューティー買い物の醍醐味であり、日本人旅行者が韓国版を買って帰る理由だ。

2. 「強い成分=良いもの」ではない——自分の肌が初めて触れる成分・濃度なら慎重になるべきだ(④ガード)。

3. 同じブランドをいつも使っている人ほど成分表を確認してから買う習慣が必要だ——見慣れた名前が見慣れた処方を保証してくれるわけではない。

③ 売り場での確認方法 — 3ステップ

1. 機能性化粧品 (gineungseong hwajangpum / 기능성화장품)の表示を探す——パッケージにこの6文字があれば、食薬処 (Sikyakcheo / 식약처) 告示基準を満たしたという表示だ(美白・シワ改善・UVカットなど、どの機能かも併記される)。

2. 全成分表示(INCI)の照合——韓国は化粧品の全成分表示が義務のため、裏面にすべて記載されている。いつも使っている製品と比較したいなら、日本版の写真を事前に撮っておいて並べて見るのが一番確実だ。

3. わからなければ撮って翻訳——成分名は翻訳アプリのカメラで十分読み取れる。オリーブヤング (Olive Young / 올리브영) など大型店はテスターが豊富なので、手の甲でのパッチテストも気軽にできる。

売り場生存ワード5

表記 意味
機能性化粧品 (gineungseong hwajangpum / 기능성화장품) 食薬処 (Sikyakcheo / 식약처) 告示基準を満たした表示——この記事の核心ワード
미백 (mibaek / 美白) / 주름개선 (jureumgaeseon / シワ改善) 機能性の種類(whitening / anti-wrinkle)
전성분 (jeonseongbun / 全成分) 全成分リスト(full ingredients)
민감성 (mingamseong / 敏感性) / 저자극 (jeojageuk / 低刺激) sensitive / mildをうたう表示——法的定義ではない
유통기한 (yutonggihan / 消費期限) / 개봉 후 (gaebong hu / 開封後) 使用期限の表示

④ ガード4行 — これは医療アドバイスではない

  • 初めて使う有効成分(レチノール・酸系など)は少量・低頻度から始め、肌反応が出たら中止する——旅行中は特に。
  • 皮膚疾患の治療中、または施術の直後なら、新しい成分を試す前にまず主治医に相談すること(施術の軸は#508・#764)。
  • 含有量の数値は製品・リニューアルごとに異なる——この記事は制度を説明するだけで、個別製品の効果を保証するものではない。
  • 化粧品は医薬品ではない——「治療」を期待して買った瞬間、失望とリスクが一緒にやってくる。
