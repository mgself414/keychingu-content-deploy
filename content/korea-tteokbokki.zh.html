外国人常犯的5个错误

1. 挑战"最辣款"后崩溃

韩国炒年糕中，叶奇炒年糕 (Yupdduk / 엽기떡볶이) 辣味 = 辣椒素 ★★★★★。外国人第一次点最辣级别往往根本吃不下。建议从 0级(温和) → 1~2级(普通) 开始。

2. 只点炒年糕

韩国小食的精髓是 炒年糕 + 炸物 + 猪血肠 (Sundae / 순대) 套餐。炸物蘸炒年糕汤汁才是正确吃法。只点炒年糕等于损失一半体验。

3. 把炒年糕当正餐

韩国炒年糕属于 小吃·夜宵 品类。人均 ₩6,000~8,000，分量偏少。若想当正餐，建议加点拉面或紫菜包饭 (Gimbap / 김밥)。

4. 分不清即时炒年糕与普通炒年糕

即时炒年糕 (Jeuksuk Tteokbokki / 즉석떡볶이)（用电磁炉现煮、可加配料）与普通炒年糕是完全不同的品类。即时炒年糕价格约 ₩15,000~25,000，适合2人以上，边煮边加配料。

5. 不用外卖App

韩国炒年糕是 外卖夜宵No.1。在酒店使用 酷澎吃 (Coupang Eats / 쿠팡이츠)、Baemin (배민) 或 Yogiyo (요기요)（均有英文界面）即可下单，无需出门。

★ 韩国炒年糕三大品牌深度对比 — 叶奇 vs 鲨鱼 vs 新殿

1️⃣ 叶奇炒年糕 (Yupdduk / 엽기떡볶이) — 辣味天花板

品牌定位：韩国辣味炒年糕No.1 — "叶奇式超辣"品牌形象

菜单：

  • 温和味 (0级)：₩7,500 — 外国人可入门
  • 辣味 (2级)：₩8,000 — 韩国平均辣度
  • 辣味 (3~4级)：₩8,500 — 仅限自信能吃辣的人
  • 叶奇炒年糕 (最终级)：₩9,000 — 辣椒素 ★★★★★，韩国人也视为挑战
  • 配菜：芝士 ₩2,000 / 炸物 ₩4,000 / 饭团 (Jumeokbap / 주먹밥) ₩2,000

核心亮点：

  • 0~5级辣度可调 = 外国人友好
  • 温和味 = 不能吃辣也可以 (以甜味为底)
  • 门店平均30~50座 + 外卖No.1
  • 部分门店提供英文菜单

一句话总结："辣度分级可调 = 外国人也能挑战 — 从0级开始"

2️⃣ 鲨鱼炒年糕 (Jaws / 죠스떡볶이) — 第一代小食连锁

品牌定位：1990年代起步的韩国小食第一代连锁 — 门店数1,500+

菜单：

  • 炒年糕1人份：₩4,500
  • 炒年糕+炸物+猪血肠套餐：₩6,000~8,000
  • 拉炒年糕 (Rabokki / 라볶이，炒年糕+拉面)：₩6,000~7,000
  • 即时炒年糕2人份：₩15,000~18,000

核心亮点：

  • 第一代小食 = 韩国正统炒年糕 身份认同
  • 辣度 ★★★ — 韩国平均水准
  • 炒年糕+炸物+猪血肠套餐为招牌 — 外国人入门首选
  • 门店氛围接近社区小食店

一句话总结："韩国正统小食第一代 — 炒年糕+炸物+猪血肠经典套餐"

3️⃣ 新殿炒年糕 (Sinjeon / 신전떡볶이) — 综合小食 + 配菜丰富

品牌定位：釜山 (Busan / 부산) 起源 — 炒年糕+炸物+猪血肠+炒饭综合小食

菜单：

  • 新殿炒年糕1人份：₩6,500
  • 新殿套餐 (炒年糕+炸物+猪血肠)：₩9,500
  • 新殿狂热套餐 (大容量)：₩14,000~17,000
  • 新殿炒饭：₩5,000~7,000

核心亮点：

  • 配菜(炸物·猪血肠·炒饭)丰富度No.1
  • 辣度 ★★★ — 平均水准
  • 釜山酱料底（甜味稍重）
  • 门店平均20~40座 + 外卖

一句话总结："釜山起源综合小食 — 一次性体验韩国小食全套配菜"

FAQ

Q1. 能用英语沟通吗？

叶奇 (Yupdduk / 엽기떡볶이)·鲨鱼 (Jaws / 죠스떡볶이)·新殿 (Sinjeon / 신전떡볶이)·Dookki (두끼) = 图片菜单 + 辣度标示。市场老字号以韩语为主。

Q2. 不能吃辣怎么办？

叶奇炒年糕 (Yupdduk / 엽기떡볶이) 0级(温和味) — 不辣。或选 Dookki (두끼) 即时炒年糕 (甜度可调节)。

Q3. 可以1人用餐吗？

连锁品牌均有1人菜单。即时炒年糕 (Dookki / 두끼) 从2人起。

Q4. 纯素可以吃吗？

鱼饼·炸物含鱼类·鸡蛋成分。纯素者建议单点炒年糕 (酱料需确认成分)。

Q5. 适合家庭出游？

Dookki (두끼) 即时炒年糕 = 家庭首选 (甜度可调 + 配料多样)。鲨鱼套餐 (Jaws / 죠스떡볶이) = 儿童也可。

Q6. 深夜夜宵？

便利店即时 ₩3,000 = 24小时。连锁外卖24小时 = 江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대) 部分门店可用。
