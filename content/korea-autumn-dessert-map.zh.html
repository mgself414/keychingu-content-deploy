韩国秋季甜品指南 — 栗子·柿子·南瓜·红薯甜品15家(栗村烘焙坊·守然山房·海影咖啡·海南红薯面包费南雪)首尔与产地篇 (2026年10月官方数据)

副标题: 公州栗村烘焙坊 (Bakery Bammaeul / 베이커리 밤마을) 09:00~21:00·全年无休(VisitKorea) · 城北洞守然山房 (Suyeonsanbang / 수연산방) 南瓜刨冰,周一、周二休息(VisitKorea) · 永同海影咖啡 (Cafe Haeyoung / 카페 해영) 柿饼甜品(VisitKorea) · 海南红薯面包费南雪 (Haenam Goguma-ppang Pinangsie / 해남고구마빵 피낭시에) 用红薯和大米代替面粉(VisitKorea) · 往届柿饼节都在12~2月 — 截至2026-10-21

🎯 如何使用这份指南

打开纸袋,烤红薯的香气扑面而来,握在手里的面包沉得像真红薯 — 海南红薯面包 (Haenam Goguma-ppang / 해남고구마빵) 完全仿照红薯的形状制作(VisitKorea)。这份指南介绍用栗子、柿子(红柿 (Hongsi / 홍시) 与柿饼 (Gotgam / 곶감))、南瓜、红薯做甜品的店。每一类都先列首尔能吃到的店,再列产地(公州、永同、清道、尚州、海南)。所有店家都是韩国观光公社旅游信息(VisitKorea、TourAPI)中登记了相应食材菜单的店。

这里写的菜单是VisitKorea菜单栏中登记的常规菜单,没有"秋季限定"标注。旧版指南里的连锁店、酒店秋季限定甜品,因无法确认2026年官方公告而删除,排名说法因无依据也已删除。冬季街头烤红薯请看 #476 冬季小吃指南,年糕请看 #473 年糕指南。

🌰 栗子 — 首尔2家·公州2家

  • 懒青年 (Lazy Youth / 레이지 유스) — 首尔城东区舞鹤路6街 (Muhak-ro 6-gil / 무학로6길) 22号1层(道仙洞 (Doseon-dong / 도선동))。12:00~24:00(最后点单23:10),全年无休。招牌栗子巴斯克芝士蛋糕不加淀粉和面粉。可打包。电话 02-6470-7770(VisitKorea)
  • 咖啡米宇 (Cafe Miu / 카페미우) — 首尔龙山区新窗路14街 (Saechang-ro 14-gil / 새창로14길) 7号1层(孝昌公园站 (Hyochanggongwon-yeok / 효창공원역) 一带)。工作日09:00~19:00,周末11:00~21:00,周一休息。手冲专门咖啡馆,供应糖渍栗子。电话 02-813-0315(VisitKorea)
  • 栗村烘焙坊 (Bakery Bammaeul / 베이커리 밤마을) — 忠南公州市白米村路 (Baekmigoeul-gil / 백미고을길) 5-9号(金城洞 (Geumseong-dong / 금성동))。09:00~21:00,全年无休。招牌是用公州特产栗子做的栗村派,还有栗子泡芙、栗子奶油芝士塔、栗子玛德琳。盒装销售,可刷卡,免费停车。离公山城 (Gongsanseong / 공산성) 很近。电话 041-853-3489(VisitKorea)
  • 本地咖啡 (Local Coffee / 로컬커피) — 忠南公州市龙堂路 (Yongdang-gil / 용당길) 55-7号(校洞 (Gyo-dong / 교동))。登记信息同时写了周一至周六12:00~21:00、周日12:00~18:00和"每周一休息" — 周一请先打电话确认。由1943年建造的老房子改成的咖啡馆,招牌是栗子拿铁。电话 0507-1331-4707(VisitKorea)

🍊 柿子(红柿、柿饼) — 首尔1家·产地3家

  • 灵魂 (Soul / 소울) — 首尔钟路区紫霞门路 (Jahamun-ro / 자하문로) 50号(彰义洞 (Changseong-dong / 창성동))。11:30~21:00(最后点单20:30),周二、周三休息。用米粉做米制甜品的专门店。有柿饼卷 (Gotgam-mari / 곶감말이),还供应豆沙奶油蒸糕 (Seolgi / 설기)、开城油炸糯米点心 (Gaeseong Juak / 개성주악) 和软糯米蛋糕。电话 0507-1318-5194(VisitKorea)
  • 海影咖啡 (Cafe Haeyoung / 카페 해영) — 忠北永同郡阳江面外万1街 (Oeman 1-gil / 외만1길) 34-4号。11:00~18:00(最后点单17:30),周二、周三休息(遇公休日则营业)。由乡间房屋改成的韩屋 (Hanok / 한옥) 咖啡馆,用自制的永同柿饼熬柿饼泥和柿饼酱。招牌有永同柿饼拿铁、芝士柿饼罐、柿饼酱黄油可颂华夫,柿饼酱和芝士柿饼罐可以单独购买。电话 043-744-4888(VisitKorea)
  • 德山纺织 (Deoksan Bangjik / 덕산방직) — 庆北清道郡梅田面德山1街 (Deoksan 1-gil / 덕산1길) 6-12号。工作日10:30~19:00,周末10:30~20:00(最后点单均为闭店前30分钟),全年无休。由1990年代纺织工厂改成的咖啡馆,供应用清道特产红柿做的红柿拿铁和红柿冰沙。电话 0507-1347-0618(VisitKorea)
  • 尚州柿饼流通中心 尚州柿饼直销店 (Sangju Gotgam Yutong Center Sangju Gotgam Jikpanjang / 상주곶감유통센터 상주곶감직판장) — 庆北尚州市岭南第一路 (Yeongnamjeil-ro / 영남제일로) 1154号。08:00~19:00,全年无休。2005年由600多户尚州柿饼农户出资成立的农业合作社。出售柿饼、柿子干,以及柿饼糯米糕、柿饼饴糖、柿饼药果 (Yakgwa / 약과)、柿子醋。电话 054-536-0907(VisitKorea)

🎃 南瓜 — 首尔3家

  • 守然山房 (Suyeonsanbang / 수연산방) — 首尔城北区城北路26街 (Seongbuk-ro 26-gil / 성북로26길) 8号(城北洞 (Seongbuk-dong / 성북동))。周三至周五11:30~17:50(最后点单17:00),周六11:30~20:00(最后点单19:10),周日11:30~19:50(最后点单19:00),周一、周二休息。位于首尔市民俗文化遗产"尚虚李泰俊故居",由李泰俊的孙女经营的传统茶馆。招牌是南瓜刨冰,还有南瓜糊 (Beombeok / 범벅)。电话 02-764-1736(VisitKorea)。城北洞小巷路线请看 #1345 小巷漫步⑥ 城北洞
  • 喜鹊与老虎圣水茶室 (Magpie & Tiger Seongsu Tearoom / 맥파이앤타이거 성수티룸) — 首尔城东区圣水二路 (Seongsui-ro / 성수이로) 97号。11:00~21:30,全年无休。供应茶和甜品的茶室,菜单上有南瓜磅蛋糕。电话 0507-1306-1629(VisitKorea)
  • 米尔帕尼 (Milpani / 밀파니) — 首尔松坡区慰礼西路 (Wirye-seoro / 위례서로) 273号(巨余洞 (Geoyeo-dong / 거여동))。09:00~21:30,全年无休。烘焙咖啡馆,菜单上有南瓜麻薯面包,招牌介绍的是红薯形状的红薯面包。电话 0507-1480-0824(VisitKorea)

🍠 红薯 — 首尔2家·海南2家

  • 尼德甜品 (Need Sweet / 니드스윗) — 首尔城东区牙车山路1街 (Achasan-ro 1-gil / 아차산로1길) 9号(纛岛站 (Ttukseom-yeok / 뚝섬역) 1号出口一带)。12:00~22:00,全年无休。所有菜品都自己制作的蛋糕咖啡馆,有真红薯芝士蛋糕。可预约、可打包。电话 0507-1467-7864(VisitKorea)
  • 普莱德咖啡首尔林 (Plaid Cafe Seoul Forest / 플래드카페 서울숲) — 首尔城东区首尔林2街 (Seoulsup 2-gil / 서울숲2길) 12-7号。每天11:00~21:00。菜单上有红薯提拉米苏。可打包。电话 0507-1356-8511(VisitKorea)
  • 海南红薯面包费南雪 (Haenam Goguma-ppang Pinangsie / 해남고구마빵 피낭시에) — 全南海南郡邑内路 (Eupnae-gil / 읍내길) 8号。09:30~20:00,海南红薯面包售罄就提前打烊。春节 (Seollal / 설) 和中秋 (Chuseok / 추석) 当天休息。红薯形状的海南红薯面包用海南红薯和海南大米代替面粉制作。还有红薯塔、蜂蜜红薯费南雪。当天生产,购买后建议冷藏或冷冻保存。不能停车。电话 0507-1393-6262(VisitKorea)
  • 梦所烘焙坊 红薯面包 (Mongso Bakery Goguma-ppang / 몽소베이커리 고구마빵) — 全南海南郡海南邑南部循环路 (Nambusunhwan-ro / 남부순환로) 5号 正河医疗中心102号。07:30~22:00,周日休息。天然发酵种面包店,供应夹有海南红薯豆沙的软糯红薯面包和红薯布里欧修。店前有停车场,可快递订购。电话 061-533-0085(VisitKorea)

🥗 饮食

  • 价格带: 15家店在VisitKorea登记信息中都没有价格。价格未公布 — 请打电话或看店内菜单确认
  • 麸质: 介绍为不用面粉、改用其他材料的店,有懒青年的栗子巴斯克芝士蛋糕(无淀粉、无面粉)、灵魂(米粉)和海南红薯面包费南雪的红薯面包(红薯和大米)(VisitKorea)。同一家店的其他品项可能含小麦
  • 素食: 芝士蛋糕、提拉米苏、可颂华夫含乳制品,派和塔通常含黄油和鸡蛋 — 纯素食者点单前请先询问
  • 酒精: 尚州柿饼直销店出售的柿饼马格利酒 (Gotgam Makgeolli / 곶감막걸리) 是含酒精饮品(VisitKorea)
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区乌沙团路10街 (Usadan-ro 10-gil / 우사단로10길) 15号,每天12:00~21:00)是韩国伊斯兰教中央会 (Korea Muslim Federation, KMF / 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。这份指南里的店家都没有清真标注
  • 出示用卡片请看 #1300 饮食需求手册

⚠ 常见的4个误区

1. "柿饼节在秋天举办" — VisitKorea节庆信息中的往届是论山阳村柿饼节2025-12-12~14、咸安柿饼节2026-01-23~25、永同柿饼节2026-01-30~02-01。2026~27届的日期尚未公布 — 请留意季节公告

2. "栗子甜品得去公州才吃得到" — 首尔也有登记了栗子菜单的店(懒青年、咖啡米宇,VisitKorea)

3. "乡间咖啡馆每天营业" — 海影咖啡周二、周三休息,梦所烘焙坊周日休息。首尔的灵魂(周二、周三)和守然山房(周一、周二)工作日也会休息(VisitKorea)

4. "去年的秋季限定菜单今年也会出" — 这一版没能确认连锁店和咖啡馆2026年秋季限定菜单的官方公告。出发前请看店里的公告
