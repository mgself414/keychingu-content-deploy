⚠ 외국인 자주 실수 5가지

1. "LoL Park = 외국인 못 들어감": LoL Park 외국인 매니아 1순위 + Klook·Interpark·OP.GG 외국인 영문 OK + 1주일 전 사전 예약 OK. 종로 + LCK 본거지 1번지.

2. "페이커 = 못 봄": 페이커 (Faker, T1) 매니아 = LoL Park LCK 경기 직접 관전 + 외국인 매니아 vlog 1순위 + T1 본사 (성수·홍대 등) 외부 매니아.

3. "한국 PC방 = 못 들어감": 한국 PC방 외국인 친화 + 영문 안내 + 1000~2000원/시간 + 24시간 + 외국인 K-PC방 vlog 1순위 + 한국 정통 매니아 culture.

4. "LCK = 영문 안내 부족": LCK 외국인 친화 1번지 + OP.GG·Liquipedia·LoL Esports 영문 풀세트 + 외국인 vlogger 매니아 deep dive.

5. "Worlds = 외국인 못 봄": Worlds (LoL World Championship) 한국 개최 = 외국인 inbound 1순위 + 부산 + 서울 1박2일 풀세트 (2014·2018·2023 한국 개최).

① LCK 메인 경기장 (1)

1. LoL Park (종로 그랑서울) ★ 한국 1번지

  • 주소: 종로구 그랑서울 (1호선·5호선 광화문역)
  • 외국인 ★: ◎◎ — 한국 1번지 LCK 본거지 (2018·400석)
  • 시그니처: LCK 스프링·서머 정기 경기 + 외국인 매니아 1순위
  • 입장권: 22,000~88,000원 + Klook·Interpark 영문 1주일 전 예약 OK
  • 외국인 매니아 동선: 광화문(#172) + 종로(#207) 통합

⚙ FAQ 8개

1. 외국인 LoL Park 입장: Klook·Interpark·OP.GG·LoL Esports 영문 1주일 전 예약 OK.

2. 외국인 페이커 매니아: LCK 경기 + T1 본사 + 페이커 1번지 매니아 vlog (한국 정통).

3. 외국인 PC방 진입: 영문 안내 OK + 외국인 친화 + 1000~2000원/시간 + 24h + 외국인 K-vlog 1순위.

4. LCK 시즌 (Spring·Summer): 스프링 (1~4월)·서머 (5~9월) + 외국인 매니아 사전 예약 1순위.

5. Worlds 한국 개최: 외국인 inbound 1순위 (2014·2018·2023 한국 개최) + 부산·서울 1박2일 풀세트.

6. LCK 외국인 굿즈: T1 굿즈 (T1 Shop)·Gen.G·DRX 외국인 매니아 1순위.

7. 외국인 e스포츠 vlogger: YouTube + 외국인 매니아 1번지 한국 정통 culture.

8. 외국인 e스포츠 1박2일: 종로 LoL Park + T1 본사 + PC방 + 외국인 vlog 매니아.
