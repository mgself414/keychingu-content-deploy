🎯 なぜ韓国蒸しワークフローガイドなのか

#894蒸し6種マトリックス 知っていても - 注文・マナー・ペアは別個。韓国蒸しは（a）安東蒸し鶏専門店（全国#1）（b）限定食のカルビ蒸し（宮中）（c）マサンアグチム（マコム）（d）ジャガルチシーフード蒸し（シーフードクロス）。外国人は（1）1館= 2〜3人の共有の知らない（2）マコム加減の知らない（3）当面＝安東蒸し鶏の本物の知らない。本ガイドは5-step+英語発話。

🌶外国人英語発話サンプル

  • "安東蒸し鶏1館" = "1 Andong Jjimdak set (for 2~3 people)"
  • "カルビチム" = "Galbi-jjim (braised short ribs)"
  • "アグチムメコム加減" = "Agu-jjim, adjust spice level please"
  • "アンマッグ" = "Less spicy, please"
  • "1/N" = "Split the bill, please"
  • "カードですか？" = "Card accepted?"

⚠外国人の頻繁な誤り5つ

1. "1館=1人前": 1館=2～3の共有。

2. 「マコム加減X」：マコム加減OK。

3. "安東蒸し鶏=一般":安東正統#1。

4. 「カルビチム＝高価のみ」：限定式本物のOK・単品30,000ウォン可能。

5. 「アグチム＝軽さ」：マコム#1。
