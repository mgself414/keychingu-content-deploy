📍 江陵 — 正东津·Anmok迎日公园

正东津(Jeongdongjin / 정동진)，江陵市江东面(Gangdong-myeon / 강동면) Jeongdongyeok路(Jeongdongyeok-gil / 정동역길) 17，☎ 033-640-4536~7，是江陵市江东面正东津里(Jeongdongjin-ri / 정동진리)的海边。名字的意思是位于汉阳光化门正东方、有渡口的村庄。它在江陵市区沿东海岸往南约18km处。很多人来这里看新年日出，2000年作为国家指定活动举办了千禧年日出庆典。这里以电视剧《沙漏》的拍摄地而闻名，随着清凉里站开出的日出列车而出了名。日出列车可以在釜山、东大邱、大田、光州、全州、春川等多个车站乘坐。

  • 正东津站(Jeongdongjin-yeok / 정동진역):据观光公社介绍，是世界上离大海最近的车站，被收录进吉尼斯世界纪录。从车站出发有绕沙漏公园(Moraesigye Gongwon / 모래시계공원)一周的铁路自行车。
  • 丰渔祭(Pungeoje / 풍어제):每年正月十五和端午，举行两次兼作洞祭的丰渔祭。
  • 休息日:全年无休。停车:可以(残疾人车位4个)。

Anmok迎日公园(Anmok Haemaji Gongwon / 안목해맞이공원)，江陵市Gyeonso洞(Gyeonso-dong / 견소동)，☎ 江陵站旅游咨询处(Gangneungnyeok Gwangwang Annaeso / 강릉역관광안내소) 033-642-8692，是与Anmok海边相连的公园，是看日出的名所。园内有“ANMOK”字样的造型物，还有可以面朝大海休息的长椅和小舞台。舞台上在特别活动日或夏季避暑季会有演出。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。婴儿车租借:无。

往届活动 — 丙午年迎日活动(Byeongo-nyeon Haemaji Haengsa / 병오년 해맞이 행사)，☎ 江陵市 033-640-5130，于2025年12月31日~2026年1月1日在镜浦海边和正东津沙漏公园(Moraesigye Gongwon / 모래시계공원)举办。12月31日 20:00~00:30举行送旧活动，1月1日 06:00~08:00举行迎日活动，费用免费。

📍 浦项·蔚山·盈德 — 虎尾串迎日广场·艮绝串·盈德迎日公园

虎尾串迎日广场(Homigot Haemaji Gwangjang / 호미곶 해맞이광장)，浦项市南区虎尾串面(Homigot-myeon / 호미곶면) Daebo里(Daebo-ri / 대보리)，☎ 054-270-5855，位于朝鲜半岛东端、地形上相当于老虎尾巴的虎尾串。这里举办过两次国家指定迎日庆典，每年举办韩民族迎日庆典。广场上有分别以右手和左手的形状立于海中和陆地的青铜造型物“相生之手(Sangsaeng-ui Son / 상생의 손)”、永恒火种箱(Yeongwon-ui Bulssiham / 영원의 불씨함)，以及当地传说主人公延乌郎细乌女(Yeonorang Seonyeo / 연오랑세오녀)的雕像。

  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以。婴儿车租借:无。

艮绝串(Ganjeolgot / 간절곶)，蔚山蔚州郡Seosaeng面(Seosaeng-myeon / 서생면) Ganjeolgot 1路(Ganjeolgot 1-gil / 간절곶1길) 39-2，☎ 蔚州郡山林公园科公园组(Ulju-gun Sallim Gongwon-gwa Gongwontim / 울주군 산림공원과 공원팀) 052-204-1751~6，是新年第一天许多人来看日出的地方。据观光公社介绍，这里是朝鲜半岛最早迎来日出的地方，比浦项虎尾串早1分钟，比江陵正东津早约5分钟。1920年代建成的艮绝串灯塔(Ganjeolgot Deungdae / 간절곶등대)与公园一起构成散步路线。据观光公社介绍，这里有世界最大规模的心愿邮筒(Somang Ucheton / 소망우체통)，投入明信片可以寄往全国各地。在蔚州郡特产品销售处(Ganjeolgot Haeolje / 간절곶해올제)免费发放明信片。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

往届活动 — 蔚州艮绝串迎日(Ulju Ganjeolgot Haemaji / 울주 간절곶 해맞이)，艮绝串，☎ 蔚州文化财团(Ulju Munhwa Jaedan / 울주문화재단) 052-980-2232，自2025年12月31日的送年演唱会开始，2026年1月1日凌晨接着举行了烟花秀和无人机秀，还有展览和体验活动。费用免费。

盈德迎日公园(Yeongdeok Haemaji Gongwon / 영덕해맞이공원)，盈德郡盈德邑(Yeongdeok-eup / 영덕읍) Changpo里(Changpo-ri / 창포리)，☎ 054-730-7052，是沿着从江口面(Gangu-myeon / 강구면)延伸到丑山面(Chuksan-myeon / 축산면)的64km海岸公路修建的海岸自然公园。是修复1997年因火灾烧毁的土地建成的。约1,500级木台阶构成连接海岸公路和大海的步道，有两处观景台。公园的象征是Changpomal灯塔(Changpomal Deungdae / 창포말 등대)。不仅在新年，平日也有很多人来看日出。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 济州 — 城山日出峰

城山日出峰(Seongsan Ilchulbong / 성산일출봉) [联合国教科文组织世界自然遗产]，西归浦市城山邑(Seongsan-eup / 성산읍)日出路(Ilchul-ro / 일출로) 284-12，☎ 064-783-0959，海拔180m，是约5,000年前在海中发生水下喷发的火山体。原本是火山岛，后来沙子和砾石堆积，与陆地连在了一起。山顶有直径600m的火山口。据观光公社介绍，自古以来，从山顶看日出被誉为瀛州十景(济州的名胜)之首。

  • 开放时间:11~2月 06:00~18:00(售票截止 17:00)。3·4·9·10月 05:00~19:00(售票截止 18:00)。5~8月 04:30~20:00(售票截止 19:00)。
  • 休息日:每月第一个周一。遇公休日则次日休息。
  • 停车:可以。

⚠ 行前须知 3 点

  1. 2026-27年迎日活动尚未登记 — 这份指南中的活动信息是2025年12月31日~2026年1月1日的数值。
  2. 城山日出峰在11~2月于 06:00 开放 — 17:00 截止售票，每月第一个周一休息。
  3. 艮绝串比虎尾串早1分钟、比正东津早约5分钟日出 — 这是韩国观光公社介绍中的数值。

⚙ FAQ 2

Q. 朝鲜半岛哪里最先看到日出?

A. 据观光公社介绍，是蔚山艮绝串(Ganjeolgot / 간절곶)。比浦项虎尾串早1分钟，比江陵正东津早约5分钟。艮绝串全天开放。

Q. 有日出列车吗?

A. 据观光公社介绍，正东津因清凉里站开行日出列车而出了名，在釜山、东大邱、大田、光州、全州、春川等多个车站可以乘坐观光列车。
