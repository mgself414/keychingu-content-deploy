#455《现场音乐精选12》已经涵盖了爵士、独立音乐和蓝调。本篇#605子深度指南聚焦爵士·蓝调专属矩阵——日语·英语游客细分第一顺位、奢华达人客群、正统文化轴线。深入解析All That Jazz 梨泰院(Itaewon / 이태원) 1976年创立·韩国#1爵士俱乐部，以及清潭(Cheongdam / 청담)奢华路线、弘大(Hongdae / 홍대)独立爵士全套。

12选4轴深度解析

轴1：梨泰院·正统爵士（3选）

1. All That Jazz（梨泰院，1976年创立 — 韩国#1正统爵士）

首尔历史最悠久的爵士乐专门俱乐部。自1976年开业以来，一直是韩国爵士乐圈的象征性存在。位于梨泰院主街巷弄深处的地下空间，常客以外国长期居留者和日本乐迷为主。

位置：首尔龙山区梨泰院洞梨泰院路（梨泰院站1号出口步行5分钟）

入场费：无。须至少点一杯饮品（约₩12,000~15,000）。

演出时间：周一至周五21:00开始，周六20:30开始。周日休息（建议提前确认）。

演出风格：标准爵士、拉丁爵士、声乐爵士。以驻场乐队为主，穿插客座艺人，场次之间会轮换。

外国人友好度：★★★★★。可用英语沟通，外国常客比例高。着装要求为商务休闲（牛仔裤+衬衫程度即可）。

交通：梨泰院站1号出口 → 沿梨泰院路步行5分钟 → 拐入巷弄后走地下楼梯。建议在Naver地图搜索"All That Jazz 梨泰院"(All That Jazz 이태원)。

预约：没有专门的预约系统。周末晚上提前20~30分钟到场排队即可入场，平日则比较宽松。

最佳时间：演出开始前30分钟入场是抢到好座位的关键。演出中也可以入场，但座位选择会变少。

2. Onefive Jazz Bar（清潭）

清潭洞的奢华爵士酒吧，装潢与音响均属高端水准。主要客群为居住在清潭一带的外国人、日语·英语商务人士以及情侣。

位置：首尔江南区清潭洞（狎鸥亭罗德奥(Apgujeong Rodeo / 압구정로데오)站步行10~15分钟，或清潭站步行8分钟）

入场费：₩20,000~30,000（通常含一杯饮品，建议出发前确认）。

演出时间：周五·周六21:00开始。平日是否营业需另行确认。

外国人友好度：★★★★。备有英文菜单，音量控制在可以轻声交谈的程度。

预约：周末建议提前预约。可通过Naver预约或电话预约。

最佳时间：10月~11月秋季的周五·周六场氛围最佳。

3. Evans俱乐部（梨泰院）

梨泰院爵士俱乐部群中实际营业的一家。客群比All That Jazz更年轻，演奏风格以现代爵士·融合爵士为主。

位置：首尔龙山区梨泰院洞一带（梨泰院站附近，建议用Naver地图确认）

入场费：无（以点饮品为消费基础）。

演出时间：周三~周日21:00开始。

外国人友好度：★★★★。氛围对外国人友好，欢迎聊音乐话题。

交通：以梨泰院站1号出口为准，步行5~10分钟。

预约：无需预约。周末晚上建议早点到场。

轴2：清潭·奢华（3选）

4. 清潭奢华爵士酒吧群

清潭·狎鸥亭一带有多家独立经营的奢华爵士酒廊。与其记住某个固定店名，不如先了解这一区域的整体特点，再依此挑选，更实用。

特点：座位精简（20~40席），音响用心打造，饮品价位约₩20,000~40,000。

外国人友好度：★★★★。多数店家可用英语沟通。着装要求：商务休闲以上。

实用提示：出发前可在Google地图搜索"清潭爵士酒吧"(청담 재즈 바) / "Cheongdam jazz bar"，查看近期评价。Naver英文版或Kakao地图也可用同样方式搜索。

5. 狎鸥亭爵士酒廊区域

位于狎鸥亭罗德奥街一带，多为餐厅兼现场酒廊的复合形式。

特点：晚餐+爵士演出打包形式，人均₩50,000~80,000（含餐）。

外国人友好度：★★★★。部分店家可用英语预约。

预约：必须提前预约。

6. 五星级酒店现场演出（清潭·江南(Gangnam / 강남)区域，#577交叉引用）

Signiel Seoul、InterContinental Gangnam等五星级酒店的酒吧·酒廊，会在周五·周六安排现场爵士演出，是外国游客最容易上手的选项之一。

入场费：最低消费1杯饮品₩25,000~40,000，或另收门票₩50,000~100,000+，各酒店不同。

演出时间：通常周五·周六20:00开始。

外国人友好度：★★★★★。常驻英语员工，可用英语预约。

预约：建议提前1~2周直接向酒店餐厅预约，也可通过OpenTable或酒店官网预约。

轴3：弘大·独立爵士（3选）

7. Boogie Woogie（弘大，#455 #11）

弘大独立爵士圈的代表俱乐部。空间不大（50席以下），演奏的艺人与观众距离很近。

位置：首尔麻浦区弘大入口站附近（以2号出口为准，步行约10~15分钟，建议用Naver地图确认）。

入场费：₩10,000~15,000（部分场次含饮品）。

演出时间：周四~周日20:30开始。

外国人友好度：★★★★。可用英语沟通，氛围以音乐为中心。

交通：弘大入口站2号出口 → 沿弘大前街巷弄一路步行探索。

预约：无需预约。场地小，早到更有优势。

8. EBS Space Gonggam（麻浦·上岩 — 公开录制旁听）

EBS电视台运营的公开音乐录制节目，涵盖爵士、世界音乐、独立音乐等多种曲风，可以免费旁听实际的电视录制现场。

位置：首尔麻浦区上岩洞EBS总部（数码媒体城(Digital Media City / 디지털미디어시티)站步行10分钟）。

入场费：免费（须提前申请旁听资格）。

演出时间：视播出排期而定。

外国人友好度：★★★。现场引导以韩语为主，但音乐本身不受语言限制。申请页面为韩语。

申请方式：EBS官网 > 旁听申请板块。务必确认申请截止时间。

最佳时间：春·秋两季的节目编排更丰富多样。

9. 弘大独立爵士小场馆群

弘大一带有不少以快闪或定期演出形式经营的小型爵士空间，不像连锁店那样有固定招牌。

特点：演出当天才在SNS上公告，入场费₩5,000~10,000，规模较小。

实用提示：可在Naver或Google地图搜索"弘大爵士演出"(홍대 재즈 공연) / "Hongdae jazz live"，确认当月排期。Instagram上"#弘大爵士"标签同样有效。

轴4：外国人达人客群矩阵

10. 日语客群达人（正统爵士）

日本游客对爵士乐品质的鉴别力普遍较高。All That Jazz（1976年正统）与Evans俱乐部（现代风格）是首选和次选。演出前先搜索一下当晚艺人的名字，现场就多了聊天的话题。虽然没有日语菜单，但用英语加肢体语言足以应付。

推荐路线：梨泰院站 → All That Jazz → 转场至Evans俱乐部（同一区域）。

11. 英语圈外籍居民爵士首选

在梨泰院的外国居民社群里，All That Jazz被视为"官方指定爵士圣地"，在Trazy和外籍人士Facebook群组的推荐榜上都排第一。周末晚上去，很容易遇到能用英语聊天的对象。

预算：以2杯饮品计，人均₩25,000~35,000。

12. 中文客群奢华爵士 + 清潭

中文圈游客中偏好奢华体验的客群，更青睐清潭与五星级酒店的现场演出。提前预约酒店时，建议确认是否有能用英语或中文对接的员工。

推荐：Signiel Seoul现场酒吧 → 衔接Onefive的组合路线。

⚠️ 外国人常犯的3大失误

失误1 — 周末不预约就去

All That Jazz虽然不需要预约，但周末21点场次开演前30分钟就会开始排队。如果不打算排队等候，不如直接选实行预约制的俱乐部（Onefive、五星级酒店）。

失误2 — 忽视着装要求

清潭和五星级酒店的现场演出，商务休闲是基本要求。穿拖鞋、短裤前往，有被拒绝入场的案例。梨泰院的俱乐部相对宽松，但整洁的着装更符合现场氛围。

失误3 — 低估饮品预算

即使没有入场费，至少点一杯饮品也是基本规矩。爵士俱乐部的饮品价格是便利店的5~10倍。以2人计，单次至少要预留₩30,000~60,000的预算才够尽兴。

实用信息：交通·购票·语言

交通

  • 梨泰院俱乐部：梨泰院站(6号线)1号出口。深夜可搭乘公交（路线建议用Naver地图实时确认）。
  • 弘大俱乐部：弘大入口站(2号线·机场铁路)2号出口。
  • 清潭·江南：可利用狎鸥亭罗德奥站(水仁盆唐线)·清潭站(7号线)后步行前往。
  • 深夜返程：凌晨1点后地铁末班车结束，建议提前安装Kakao T或Uber应用。

购票·预约

  • All That Jazz·Evans俱乐部·Boogie Woogie：无需另外购票，现场先到先得。
  • Onefive·五星级酒店：可通过Naver预约、各酒店官网或OpenTable预约。
  • EBS Space Gonggam：需在EBS官网申请公开录制旁听资格（韩语页面）。

语言

  • All That Jazz·Evans俱乐部：可用英语沟通（员工基本能说英语）。
  • 清潭·五星级酒店：英语服务完备。
  • 弘大小型俱乐部：以韩语为主 → 建议提前准备翻译App（Papago、Google翻译）。
  • 演出中主持人的报幕是韩语，但音乐本身不受语言限制。

常见问题

Q1. 第一次来首尔，只能去一家爵士俱乐部的话？

选All That Jazz（梨泰院，1976年创立）。它是韩国历史最悠久的正统爵士俱乐部，外国常客多，无需预约，只要点一杯饮品就能入场——没有特别理由时的默认答案。

Q2. 预算大概要留多少？

以梨泰院俱乐部为例，2人单次消费约₩30,000~60,000（2~3杯饮品）。清潭与五星级酒店则要₩100,000~200,000+（含餐套餐）。记住：没有入场费不等于预算是0。

Q3. 只想去英语能通的俱乐部？

优先级依次为All That Jazz > 五星级酒店现场演出 > Onefive。弘大的小俱乐部只要备好翻译App，基本没问题。

Q4. 有着装要求吗？

梨泰院是商务休闲（牛仔裤+衬衫程度）。清潭与五星级酒店建议正装休闲以上。曾有拖鞋、短裤在清潭俱乐部被拒绝入场的案例。

Q5. 有什么办法提前了解韩国爵士演出排期？

  • All That Jazz官方SNS（搜索Instagram·Facebook）
  • 在Interpark、YES24搜索演出（关键词"爵士 Jazz"）
  • Naver搜索"梨泰院爵士演出"(이태원 재즈 공연) → 查看博客·社区最新帖子
  • 弘大独立演出排期：Instagram"#弘大爵士 #弘大演出"标签

路线A — 梨泰院正统爵士全套

晚餐（梨泰院露台餐厅或韩餐）→ 21:00进入All That Jazz → 转场至Evans俱乐部续场（同一区域）。人均总预算₩60,000~100,000。

弘大街区漫步 → 晚餐 → 20:30进入Boogie Woogie。人均总预算₩40,000~70,000。
