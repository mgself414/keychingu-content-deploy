韩国看病，零慌张流程表 — 凭一本护照从挂号走到药房

副标题: 专为旅途中非急诊的情况而写 — 感冒、肚子痛 — 内容包括 医院 (uiwon / 의원)、综合医院 (byeongwon / 병원) 与急诊室的区分 · 从挂号到药房的6个步骤 · 只凭护照即可挂号 · 无保险时的实际花费 · 语言不通时如何用 1339 与医疗口译 (急诊与安全请看 #405，进入药房之后的流程请看 #1278)

ISSUE 04 · #1307 · 2026-08-18 · korea-first-timer 系列 ㊳

🎯 阅读本流程表的方法 — 画面标记规约

这篇不讲"韩国医疗是什么样的"，而是原样写下"身体不舒服时站在挂号窗口前，该按什么顺序做什么"。标记规约沿用 #1270 确定的3种。

  • 画面与机器上的按钮用方括号：[ 挂号 ]
  • 窗口牌子与文件名称用引号：挂号·缴费 (jeopsu-sunap / 접수·수납)
  • 用手做的动作用粗体：把护照递交到窗口

⚠️ 请先确认：如果出现意识不清、呼吸困难、出血不止、剧烈胸痛，不要按本流程表操作，请立即拨打 119。急诊应对由 #405 急诊医院·安全指南专门负责。这篇只适用于非急诊情况。

① 这篇只讲"非急诊就诊流程" — 与 #405、#1278 角度不同

三篇连成一条线。按当下的情况选择对应的一篇即可。

情况 对应篇目
急诊 — 119、急诊室、事故、安全 #405 急诊医院·安全指南
需要看医生 — 挂号、就诊、缴费、处方笺 本篇 (#1307)
只需要药 — 买药或凭处方配药 #1278 药房使用手册

#1278 在第⑤节告诉你处方药必须先拿到医生的 处方笺 (cheobangjeon / 처방전)，到此为止。本篇正是从那一点开始 — 走进那家诊所，直到手里拿着处方笺走出来。

② 去哪里 — 医院 (uiwon / 의원) 还是 综合医院 (byeongwon / 병원)，旅行者几乎总是前者

韩国的医疗机构按规模区分名称。旅途中感冒或肚子痛，答案几乎总是 医院 (uiwon / 의원)。

类别 招牌上的字 预约 对旅行者的适合度
诊所 — 医院 (uiwon / 의원) 内科 (naegwa / 내과)、耳鼻喉科 (ibiinhugwa / 이비인후과) 等 不用预约，直接走进去 ★★★ 感冒、肠胃不适、轻伤
综合医院 (byeongwon / 병원) 综合医院 (byeongwon / 병원) 视科室而定，等候较久 ★ 诊所转诊时
三级综合医院 大学医院 没有转诊单基本进不去 ✕ 直接去等于白跑
  • 感冒、喉咙痛 → 内科 (naegwa / 내과) 或 耳鼻喉科 (ibiinhugwa / 이비인후과)
  • 肚子痛 → 内科 (naegwa / 내과)
  • 皮肤问题 → 皮肤科 (pibugwa / 피부과)
  • 扭伤、挫伤 → 骨科 (jeonghyeongoegwa / 정형외과)

在地图 App 里搜 内科 (naegwa / 내과)，住处附近的诊所就会出来。如果地图 App 本身不会用，请先看 #1295。

一开始就去大医院反而吃亏。 大学医院没有转诊单会被拒绝挂号，或者费用高得多。症状轻的话，社区诊所更快也更便宜。

③ 从挂号到药房的6个步骤 — 全部就这些

步骤 地点 要做的事 陷阱
1 挂号·缴费 (jeopsu-sunap / 접수·수납) 窗口 递交护照，说明是第一次来 有取号机就先取号
2 窗口 填写简单的个人信息表 很多地方只有韩文 → 见⑤翻译 App
3 候诊室 等待叫到名字 名字会用韩式发音叫 — 担心听不出就先跟窗口说一声
4 诊室 向医生说明症状，通常 10~20分钟 用⑤的句子卡展示更快
5 挂号·缴费 (jeopsu-sunap / 접수·수납) 窗口 当场结账，并拿到 处方笺 (cheobangjeon / 처방전) 离开前把费用结清
6 附近的药房 递交处方笺，领药 诊所不给药

第6步是本篇最重要的一点。 韩国实行医药分业，医生看病、药师配药，所以几乎不可能拿着药走出诊所。你拿到的是一张叫处方笺的纸，要带着它走出去到药房。不知道这一点的旅行者会以为"没给药"，就这样空手回住处。

药房通常在同一栋楼的一层，或者正对面马路。找绿色十字或 药 (yak / 약) 的招牌即可。药房里面发生的事由 #1278 专门负责。

④ 处方笺 — 一张纸，但有有效期

  • 处方笺在任何一家药房都能用，不限于诊所旁边那家。
  • 它有使用期限。 通常是开具之日起7天，但诊所也可能写更短的，比如3天 — 请自己确认纸上写的 使用期限 (sayonggigan / 사용기간)。
  • 过期就领不到药，需要重新就诊。当天就直接去药房最保险。
  • 一般会给两张 — 一张交给药房，一张自己保管。两张都要收好。

自己保管的那张处方笺和收据不要扔 — 回国后申请旅行保险理赔时需要用到。

⑤ 语言不通时 — 按这个顺序试

1. 事先把症状句子翻译好，用手机屏幕展示给挂号窗口和诊室即可。下面这几句值得先存起来：

  • 我有感冒症状 (gamgi jeungsang-i isseoyo / 감기 증상이 있어요)
  • 我肚子痛 (baega apayo / 배가 아파요)
  • 我发烧了 (yeoli nayo / 열이 나요)
  • 我喉咙痛 (mogi apayo / 목이 아파요)
  • 我是旅行者，没有健康保险 (yeohaengja-imnida. geongangboheom-i eopseoyo / 여행자입니다. 건강보험이 없어요)

2. 1339 — 多语种健康·急救咨询电话，也可以帮你找附近的诊所和药房。

3. e-gen.or.kr — 查询此刻正在营业的医院和药房的官方门户。夜间和公休日尤其有用。

4. 医疗口译 — Medical Korea 支援中心可连接专业医疗口译，语种包括英语、日语、中文、俄语、阿拉伯语等。

5. 首尔、釜山的大医院设有国际诊疗中心，有会说英语的协调员。不过比社区诊所贵也更花时间 — 症状轻的话没必要去。

⑥ 费用 — 没有韩国医保时到底要花多少

韩国居民通过国民健康保险只承担一部分。旅行者没有这项保障，需要全额自付 — 大约是参保居民的 3~5倍。

项目 无保险旅行者，大致
社区诊所诊疗费 ₩30,000 ~ ₩80,000
药房处方药 ₩5,000 ~ ₩15,000
  • 会因诊所、科室、是否做检查而有很大差别。以上是区间，不是固定价。
  • 加上 X 光、验血等检查会更高。就诊前问一句检查要多少钱并不失礼。
  • 大多数诊所可以刷卡。 少数小诊所只收现金，建议带一点现金 — 参考 #1301。
  • 如果有旅行保险，收据、诊疗费明细单、处方笺都要留好。 理赔时三样都需要。

⑦ 在诊所会遇到的生存词

画面·牌子用语 对应英文 含义 = 该做的事
挂号 (jeopsu / 접수) Registration 最先去的窗口
缴费 (sunap / 수납) Payment 结账窗口，常与挂号同一处
诊室 (jillyosil / 진료실) Consultation room 叫到名字后进的房间
候诊室 (daegisil / 대기실) Waiting room 等候区
处方笺 (cheobangjeon / 처방전) Prescription 要拿去药房的那张纸
使用期限 (sayonggigan / 사용기간) Validity 处方笺上写的期限 (④)
内科 (naegwa / 내과) Internal medicine 感冒、肠胃不适
耳鼻喉科 (ibiinhugwa / 이비인후과) ENT 喉咙、鼻子、耳朵
骨科 (jeonghyeongoegwa / 정형외과) Orthopedics 扭伤、挫伤
皮肤科 (pibugwa / 피부과) Dermatology 皮肤问题
诊疗费收据 (jillyobi yeongsujeung / 진료비 영수증) Receipt 理赔用，别扔
保险 (boheom / 보험) Insurance 回答"没有"即可
药房 (yakguk / 약국) Pharmacy 处方笺的下一站

提示：13个不用全记。记住四个就能看清整个流程 — 挂号 (jeopsu / 접수)（开始）· 处方笺 (cheobangjeon / 처방전)（要拿到手的东西）· 药房 (yakguk / 약국)（下一个目的地）· 内科 (naegwa / 내과)（感冒肚子痛就挂这个科）。

⑧ 三个慌张场景

1. 看完病却没给药。 这是正常的。韩国医药分业，诊所只给你 处方笺 (cheobangjeon / 처방전) 这张纸。拿着它到楼下或马路对面的药房才能拿到药。误以为"什么都没给"的旅行者，会带着病空手回住处。

2. 去大学医院却挂不上号。 三级综合医院需要其他医疗机构开的转诊单。既不是系统故障，也不是歧视。感冒或肚子痛本来就该去社区的 医院 (uiwon / 의원)，那里更快也更便宜。在地图 App 上重新搜 内科 (naegwa / 내과) 即可。

3. 拿到一张韩文表格，一个字也看不懂。 挂号表通常只问姓名、出生年月日、联系方式和症状。用翻译 App 的相机一照就能读。也可以出示护照请窗口工作人员帮忙 — 旅行者挂号并不罕见。
