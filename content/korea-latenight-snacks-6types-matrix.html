🎯 왜 한국 야식·안주 매트릭스인가

외국인 한국 나이트라이프 페인포인트 = "포차에서 뭘 시켜야 하지?". 한국 야식·안주 = 회식 2차 + 포차 + 호프 + K-drama vlog 1번지. 같은 "Korean late-night snacks"라도 노가리 (을지로 노가리 골목·맥주 페어 #1)·곱창 (소·돼지·내장 매니아)·꼼장어 (부산 시그니처·매콤)·닭발 (술 안주 정통)·철판 (해물·고기 즉석)·전 (해물파전·녹두전·막걸리 페어) 각자 다른 매장·시간대·페어링. 외국인은 (a) 노가리 = 안주인지 몰라 (b) 곱창·내장 거부감 (c) 꼼장어 = 매운맛 단계 모름 (d) 포차 시간대 모름. 본 가이드는 6종 매트릭스 + 포차 cluster + 외국인 입문 우선순위.

⚠ 외국인 자주 실수 5가지

1. "포차 = 술집만": 포차 = 야간 천막 술집 + 안주 + 길거리 분위기 = 한국 정통 나이트라이프.

2. "곱창 = 내장 거부": 곱창 = 일본 모츠나베·유럽 트라이프 유사. 입문 = 마장동 노포 추천.

3. "노가리 = 가벼움": 노가리 = 소금·짭짤 = 맥주 페어링 무한 정통.

4. "꼼장어 = 일반 장어": 꼼장어 = 부산 매콤 양념 구이 (민물장어와 다른 음식).

5. "닭발 = 어디나 같은 매운맛": 닭발 = 무뼈 vs 뼈 + 매운 단계 5단계. 외국인 = 무뼈 + 안 매움 입문.

⚙ FAQ 8개

1. 외국인 입문 1순위: 노가리 + 생맥주 (을지로 골목) → 전 + 막걸리 (광장시장) → 철판 (강남) 단계.

2. 인스타·vlog: 을지로 노가리 골목 #1 + 광장시장 전 + 부산 꼼장어.

3. 회식 2차: 노가리 호프 + 곱창집 + 철판 호프.

4. 매운맛 입문: 무뼈 닭발 안 매운 → 일반 닭발 → 불닭발 단계.

5. 알레르기: 해산물 (노가리·꼼장어·해물파전)·견과류·콩 (전 양념)·계란 사전 고지.

6. 채식·할랄·코셔: 전 일부 (녹두전·호박전·김치전 채식 가능) / 노가리·곱창·꼼장어·닭발 = 비채식.

7. 결제·팁: 카드 OK 多 / 포차 = 현금·카드 혼용 / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

야식·안주 = 야간 식사 (소화 ↓·수면 영향). 임신부 = 술 X·매운맛 X·곱창·내장 = 의료진 상담. 어린이 = 야간 포차 X (술 분위기·법적 음주 19세 미만). 알레르기 (해산물·콩·계란·견과류·매운 양념) 사전 고지. 음주운전 0.03% BAC 면허정지 (한국 단속 강력). 식중독 의심 시 ☎ 1339 (의료, 영문). 본 가이드는 일반 정보, 의료 자문이 아님.

노포·매장 정보 면책: 포차·노가리 골목 영업시간·메뉴 변동 — 방문 전 NAVER/Kakao map 또는 공식 사이트 확인.

식이 제한 fallback:

  • 할랄·코셔: 일반 야식·안주 = 비할랄. → 이태원 일부 할랄 매장 OR 채식 전·과일 안주.
  • 채식·비건: 녹두전·호박전 (계란 X 옵션)·김치전 (어묵 빼기) = 채식 가능. 노가리·곱창·꼼장어·닭발·해물파전 = 비채식.
  • 글루텐 free: 전·양념 (간장) 多. 사전 매장 확인.
