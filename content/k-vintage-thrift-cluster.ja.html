ソウルのヴィンテージ・古着ショッピング9軒 — 千ウォンの服の山からハンナムドンのショールームまで

サブタイトル: トンミョのフリーマーケットとシンソルドンのソウル風物市場、寄付品を売る分かち合いの店二軒、ホンデ・サンス・マンウォンのヴィンテージショップ三軒、イテウォン・ハンナムの二軒まで。カカオマップで営業中と確認でき、2026年下半期に訪問レビューが投稿された店だけを9軒選び、3エリアに分けた。一エリアを半日で回るコースに組んだ。

ISSUE 06 · #772 · 2026-11-24 · ソウルのヴィンテージショッピング

🎯 だれのための、なぜこの9軒なのか

古着や古い物を掘り出すショッピングが好きな旅行者に向けたリストです。ソウルの古着ショッピングは大きく三つに分かれます。トンデムン (Dongdaemun / 동대문)の市場では、服の山や露店を掘り出します。アルムダウンカゲ (Beautiful Store / 아름다운가게)やグッドウィルストア (Goodwill Store / 굿윌스토어)のような分かち合いの店では、寄付品を安く買えます。ホンデ (Hongdae / 홍대)・マンウォン (Mangwon / 망원)・ハンナム (Hannam / 한남)のヴィンテージショップでは、オーナーが選んで手入れした服を買います。この回は三つとも入れました。

選定基準は二つです。カカオマップ (Kakao Map / 카카오맵)の店舗情報が「営業中」で、2026年下半期にブログのレビューやカカオマップのレビュー・写真が投稿されていること。最近の活動が2024~2025年で止まっている店と、物議を醸したレビューが付いている店は外しました。

⚠ 表記の原則: 営業時間・定休日はカカオマップに登録された値です(2026-11-24確認)。服の価格はカカオマップに登録されていないので、ブログのレビューやカカオマップのレビューに書かれた実際の購入価格を日付とともに写しました。一人が買った値段なので、同じ物でも別の日には違う値段になることがあります。最寄り駅と出口はカカオマップの道案内の値です。カード決済ができるかは確認できていないので、露店や小さな店のために現金を用意してください。

① トンデムン・ジョンノ — 3軒

市場二軒はトンミョアプ駅とシンソルドン駅に近く、一日にまとめやすい位置です。アルムダウンカゲ アングク店はプクチョン (Bukchon / 북촌)の入口にあり、インサドン・プクチョンの日程に挟みやすい店です。

  • トンミョ蚤の市 (Dongmyo Flea Market / 동묘벼룩시장) — トンミョアプ駅 (Dongmyo-ap / 동묘앞역)3番出口前の路地に、露店と古着店が集まる通りです。床に積まれた服の山を掘る店と、ハンガーに掛けて売る店が混ざっています。価格はレビューによるもので、2026-10末に訪れたときの値です。2026-11-17のブログのレビューには、山積みのTシャツが1千~5千ウォン、ハンガーの服が1万ウォン前後と書かれていました。書き手は、店によって差が大きいとも付け加えています。カカオマップには毎日10:00~18:00と登録されています。同じレビューは、公式の営業時間はなく、店・露店ごとに違うと書いています。住所はジョンノ区 (Sungin-dong 102-8 / 숭인동 102-8)一帯、最寄り駅はトンミョアプ駅 (Dongmyo-ap / 동묘앞역)(1・6号線)3番出口で、徒歩1分です。このレビューは、10月末の土曜の昼に人が想像以上に多く、駐車スペースが少なくて車で行くのは面倒だと書いています。
  • ソウル風物市場 (Seoul Pungmul Market / 서울풍물시장) — シンソルドン (Sinseol-dong / 신설동)の屋内フリーマーケットです。建物が色ごとの棟(赤・橙・黄・緑・青・藍・紫)とチョンチュン1番街 (Cheongchun 1-beon-ga / 청춘1번가)に分かれています(公式ホームページ, 2026-11-24)。骨董品・生活用品・器・古着を売っています。市場の公式ブログは、2026-11-16の記事で古着コーナーを別に紹介しました。2026-10-11のブログのレビューには、器はほとんどが1千ウォンで、ガラスのカップは3千ウォンほどと書かれています。カップの値段は推定です。カカオマップの時間は水~月10:00~19:00で、火曜定休です。公式ブログ(2026-11-02)も毎週火曜休みと知らせています。住所はトンデムン区 (Cheonho-daero 4-gil 21 / 천호대로4길 21)、最寄り駅はシンソルドン駅 (Sinseol-dong / 신설동역)(1・2号線・ウイシンソル線)9番出口で、徒歩4分です。屋内なので雨の日に向いています。
  • アルムダウンカゲ アングク店 (Beautiful Store Anguk / 아름다운가게 안국점) — 寄付された服・かばん・本・器を売る分かち合いの店です。2026-06-02のレビューには、白の無地Tシャツ ₩6,000、かばん ₩15,000~20,000台が出てきます。2026-09-25のレビューには、ニット ₩6,000、本 ₩1,000~3,000、ノート5冊 ₩1,000が出てきます。すべてが安いわけではありません。2026-09-30のカカオマップのレビューは、中古のセーターに10万ウォンの値が付いていたと不満を書いています。時間は月~金10:30~20:00、土・日・祝日10:30~18:00です。ソルラル(旧正月)とチュソク(秋夕)の連休の三日間とメーデーは休みます。住所はジョンノ区 (Bukchon-ro 21 / 북촌로 21)1階、最寄り駅はアングク駅 (Anguk / 안국역)(3号線)2番出口で、徒歩5分です。

② ホンデ・サンス・マンウォン — 4軒

ホンデイック駅の大型店が一軒、サンス駅前の2階建ての店が一軒、マンウォン駅寄りが二軒です。ルート ホンデは24:00まで開いているので夜に向いています。テラスウェアは月曜、グッドウィルストアは日曜が休みです。

  • ルート ホンデ (Root Hongdae / 루트 홍대) — ホンデイック駅 (Hongik Univ. / 홍대입구역)前の地下にある大型のヴィンテージ衣料店です。2026-10-20のブログのレビューは、店の広さを250坪と紹介しました。同じレビューに、3+1セール、ミリタリージャケット ₩19,000、ジャケット1万~15万ウォン台が出てきます。セールはそのときどきで変わります。毎日10:00~24:00営業です。住所はマポ区 (Yanghwa-ro 140 / 양화로 140)地下1階、最寄り駅はホンデイック駅 (Hongik Univ. / 홍대입구역)(2号線・空港鉄道・京義中央線)9番出口で、徒歩3分です。2026-11-15のブログ記事のタイトルは「外国人もたくさん行くルート ホンデ」でした。男性服と女性服がまざって掛かっているので、ラベルとサイズは自分で見る必要があります。
  • ヴィンテージショップ ペイジワン (Vintage Shop Page One / 빈티지샵 페이지원) — サンス駅 (Sangsu / 상수역)のすぐ前で1・2階を使っているヴィンテージショップです。服のほかに、アクセサリー・帽子・小物・器も売っています。2026-11-04のブログのレビューに、ブラウスを一枚 ₩3,000で売るコーナーが出てきます。曜日ごとに時間が違い、火~木12:30~20:50、金~日13:00~20:50、月曜13:00~19:55です。ブログも、時間がよく変わると書いています。住所はマポ区 (Dongmak-ro 75 / 독막로 75)1~2階、最寄り駅はサンス駅 (Sangsu / 상수역)(6号線)1番出口で、徒歩2分です。
  • テラスウェア (Terrace Wear / 테라스웨어) — マンウォン市場 (Mangwon Market / 망원시장)へ向かう路地の入口にあるヴィンテージショップです。2026-10-28のブログのレビューは、フレンチワークジャケットを代表的な品に挙げました。別のレビュー(2026-06-04)には、リーバイスのジーンズが多かったとあります。値段は安いとは限りません。2026-08-21のカカオマップのレビューには、10万ウォンを超える服があったと書かれています。時間は火~日12:30~20:00で、月曜定休です。住所はマポ区 (Worldcup-ro 19-gil 25 / 월드컵로19길 25)1階、最寄り駅はマンウォン駅 (Mangwon / 망원역)(6号線)2番出口で、徒歩4分です。
  • グッドウィルストア マポ店 (Goodwill Store Mapo / 굿윌스토어 마포점) — 寄付された服・本・生活用品を売る分かち合いの店です。2026-07-12のブログのレビューに、本一冊 ₩2,000が出てきます。2026-05のカカオマップのレビューも、本をたくさん見つけたと書いています。服より本・雑貨が強いというレビューが多い店です。時間は月~土10:00~19:00で、日曜定休です。住所はマポ区 (Worldcup-ro 94 / 월드컵로 94)ミョンビル (Myeong Building / 명빌딩)1階、最寄り駅はマンウォン駅 (Mangwon / 망원역)(6号線)1番出口で、徒歩3分です。

③ イテウォン・ハンナム — 2軒

二軒とも、オーナーが選んだ服だけを掛ける小さな店です。プラスチックバナナは13:00に開き、月曜が休みです。

  • プラスチックバナナ (Plastic Banana / 플라스틱바나나) — ノクサピョン駅 (Noksapyeong / 녹사평역)とイテウォンの間の路地にあるヴィンテージショップです。2026-11-02のカカオマップのレビュー(英語)は、レザー・デニム・ウールの男性ジャケット、厚手のウールとフランネルのシャツ、アメリカサイズのジーンズを長所に挙げました。価格はカカオマップと最近のレビューで確認できた値がありません(2026-11-24)。時間は火~日13:00~21:00で、月曜定休です。住所はヨンサン区 (Noksapyeong-daero 40-gil 41 / 녹사평대로40길 41)1階、最寄り駅はノクサピョン駅 (Noksapyeong / 녹사평역)(6号線)3番出口で、徒歩6分です。
  • ヴィンテージショップ オブハート (Vintage Shop Of Heart / 빈티지샵 오브하트) — ハンナムドン (Hannam-dong / 한남동)のイテウォンロ (Itaewon-ro / 이태원로)沿い、2・3階のショールームです。2026-11-03のブログのレビューに、ツイードジャケット、高級ネクタイ、ヴィンテージ時計、ウールのアウターが出てきます。2025-03のレビューは、服はすべてドライクリーニングして掛けてあるのでにおいがないと書いています。2025-08-27のレビューは、ツイードは高めだが、生地に難ありの物には2~3万ウォン台もあると書いています。毎日10:00~20:00に開いています。住所はヨンサン区 (Itaewon-ro 212 / 이태원로 212)2・3階、最寄り駅はイテウォン駅 (Itaewon / 이태원역)(6号線)3番出口で、徒歩6分です。

🗺 動線 — 半日コース二本

エリアごとに街が離れているので、一日にエリアは一つか二つだけにします。店と店の間の道は、その日にカカオマップの道案内で確認してください。

A. トンミョ・風物市場・アングク (火曜を除く)

  1. 午前 トンミョ蚤の市 (Dongmyo Flea Market / 동묘벼룩시장)(カカオマップ10:00~)
  2. 昼前 シンソルドンのソウル風物市場 (Seoul Pungmul Market / 서울풍물시장)。トンミョアプ駅から1号線で一駅です
  3. 午後 アングク駅のアルムダウンカゲ アングク店 (Beautiful Store Anguk / 아름다운가게 안국점)(月~金は20:00まで、土・日は18:00まで)。プクチョン・インサドンの観光とまとめます

火曜は風物市場が休みです。火曜なら2番を抜いて、トンミョからそのままアングクへ行きます。

B. サンス・ホンデ・マンウォン (火~土がおすすめ)

  1. 昼 サンス駅のヴィンテージショップ ペイジワン (Vintage Shop Page One / 빈티지샵 페이지원)(火~木12:30~、金~日13:00~)
  2. 午後 マンウォン駅寄りのテラスウェア (Terrace Wear / 테라스웨어)(月休み)とグッドウィルストア マポ店 (Goodwill Store Mapo / 굿윌스토어 마포점)(日休み)
  3. 夕方 ホンデイック駅のルート ホンデ (Root Hongdae / 루트 홍대)(~24:00)

月曜はテラスウェアが休み、日曜はグッドウィルストアが休みです。二軒とも見るなら火~土に行きます。イテウォン・ハンナムの二軒は、夕方遅めにまとめて、別に半日を取ります。プラスチックバナナは13:00に開きます。

⚠ よくある失敗3つ

  1. 火曜に風物市場、月曜にマンウォン・イテウォンへ行く — ソウル風物市場は火曜、テラスウェアとプラスチックバナナは月曜、グッドウィルストア マポ店は日曜が休みです。まず曜日を合わせます。
  2. 値札だけ探して何も買わずに出る — トンミョは店・露店ごとに値段が違うというレビューがあります。選んだ物を持って値段を聞きます。
  3. 試着せずに買う — ヴィンテージは同じ物が一点だけで、海外のサイズ表記もまざっています。試着ができるか、交換・返金ができるかを、会計の前に聞きます。

⚙ よくある質問3つ

  1. 初めてで一軒だけ行くなら? — 安くたくさん掘りたいならトンミョ蚤の市 (Dongmyo Flea Market / 동묘벼룩시장)、雨の日や器・骨董まで見たいならソウル風物市場 (Seoul Pungmul Market / 서울풍물시장)(火曜休み)、選んだ服をゆっくり試着したいならルート ホンデ (Root Hongdae / 루트 홍대)(毎日24:00まで)です。
  2. 夜に行ける店は? — 登録時間でみると、ルート ホンデ (Root Hongdae / 루트 홍대)が24:00、プラスチックバナナ (Plastic Banana / 플라스틱바나나)が21:00、ペイジワン (Page One / 빈티지샵 페이지원)が20:50(月曜は19:55)、アルムダウンカゲ アングク店 (Beautiful Store Anguk / 아름다운가게 안국점)が平日20:00まで開いています。
  3. 服以外でお土産になる物は? — ソウル風物市場の器・カップ(レビューでは1千~3千ウォン)、アルムダウンカゲ・グッドウィルストアの本、ペイジワンの小物・器があります。新しい工芸品がほしければ、伝統お土産の回#774を見てください。
