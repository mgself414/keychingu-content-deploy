🏪 广藏市场 (Gwangjang Market / 광장시장) — 钟路饮食第一名

营业: 每日09:00–23:00（美食街部分24小时）· 部分摊位周日休息

⚠ 初次前往的外国游客常犯的3个错误

1. "钟路 (Jongno / 종로) = 只有景福宫 (Gyeongbokgung / 경복궁)" — 不了解各街区

很多游客只知道钟路有景福宫 (Gyeongbokgung / 경복궁) 和清溪川 (Cheonggyecheon / 청계천)。实际上共有光化门 (Gwanghwamun / 광화문)（市中心）+ 仁寺洞 (Insadong / 인사동)（传统）+ 益善洞 (Ikseondong / 익선동)（韩屋胡同）+ 北村 (Bukchon / 북촌)（韩屋村）+ 钟阁 (Jonggak / 종각)（商业）5个步行可达的sub-area，皆在地铁1·3号线范围内。

2. 将仁寺洞 (Insadong / 인사동) 和益善洞 (Ikseondong / 익선동) 误以为是同一地方

两处同有韩屋 (Hanok / 한옥) 氛围，但仁寺洞 (Insadong / 인사동)（传统食品·文化·纪念品）≠ 益善洞 (Ikseondong / 익선동)（MZ世代咖啡馆·酒吧·ins打卡地）。从仁寺洞 (Insadong / 인사동) 步行约7分钟可到益善洞 (Ikseondong / 익선동)。

3. 只在光化门 (Gwanghwamun / 광화문) 寻找参鸡汤 (Samgyetang / 삼계탕)·传统食品

60年老字号长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 在光化门 (Gwanghwamun / 광화문) 附近，而仁寺洞 (Insadong / 인사동)·益善洞 (Ikseondong / 익선동) 也有热门现代韩食（砧板 (Doma / 도마)·炉锅 (Solsot / 솔솥)）。各sub-area饮食风格不同——先决定想吃什么，再选择sub-area。

Q1. 钟路区 (Jongno-gu / 종로구) 首次游览1日路线？

景福宫 (Gyeongbokgung / 경복궁) 10:00 → 长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 午餐（12:00）→ 🏪 广藏市场 (Gwangjang Market / 광장시장) 绿豆饼 (Bindaetteok / 빈대떡)·麻药紫菜卷 (Mayak Gimbap / 마약김밥)（13:00）→ 光化门广场 (Gwanghwamun Square / 광화문 광장) → 标准班 (Standard Bun / 스탠다드번) 休息 → 韩果美意识 (Hangwa Mi-Uisik / 한과미의식) + 砧板 (Doma / 도마) 仁寺洞 (Insadong / 인사동) 路线（16:00）→ 步行至益善洞 (Ikseondong / 익선동) → 韩屋朗松 (Hanok Ransom / 한옥랑솜) + 炉锅 (Solsot / 솔솥) 晚餐 → 虎先生 (Ho-Sunsaeng / 호선생전) 夜间收尾

Q2. 仁寺洞 (Insadong / 인사동) vs 益善洞 (Ikseondong / 익선동) 去哪个？

仁寺洞 (Insadong / 인사동)：传统食品·纪念品·正宗韩食（韩果美意识 (Hangwa Mi-Uisik / 한과미의식)·砧板 (Doma / 도마)）。益善洞 (Ikseondong / 익선동)：MZ咖啡馆·酒吧·韩屋ins打卡（韩屋朗松 (Hanok Ransom / 한옥랑솜)·炉锅 (Solsot / 솔솥)·虎先生 (Ho-Sunsaeng / 호선생전)）。根据喜好选择——传统=仁寺洞 (Insadong / 인사동) / MZ+ins=益善洞 (Ikseondong / 익선동)。

Q3. 英文菜单·服务如何？

质哈布罗斯 (Quill Bros / 질할브로스) / 标准班 (Standard Bun / 스탠다드번) / 韩果美意识 (Hangwa Mi-Uisik / 한과미의식) / 砧板 (Doma / 도마) — 英文友好度高。炉锅 (Solsot / 솔솥) / 虎先生 (Ho-Sunsaeng / 호선생전) 英文部分支持。长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 为老字号，以韩语为主。

Q4. 老字号正宗 vs 现代韩食？

老字号正宗：长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕)（60年）/ 砧板仁寺洞 (Doma Insadong / 도마 인사동점)（正宗）。现代韩食：炉锅益善洞 (Solsot Ikseon / 솔솥 익선점)（铁锅）/ 韩果美意识 (Hangwa Mi-Uisik / 한과미의식)（现代摆盘）。外国人入门推荐现代风，老字号适合资深爱好者。

Q5. 益善洞 (Ikseondong / 익선동) 韩屋 (Hanok / 한옥) 咖啡馆最佳时段？

工作日上午（11:00–13:00） 座位充裕。周末14:00–17:00排队30分钟以上。拍韩屋 (Hanok / 한옥) 氛围照建议13:00–15:00自然光最佳。

Q6. 价位？

西餐（质哈布罗斯 (Quill Bros / 질할브로스)）₩15,000–30,000 / 韩食（砧板 (Doma / 도마)·炉锅 (Solsot / 솔솥)）₩15,000–25,000 / 咖啡·甜点₩7,000–12,000 / 韩果 (Hangwa / 한과) ₩15,000–30,000 / 参鸡汤 (Samgyetang / 삼계탕) ₩18,000–25,000。

Q7. 休息日·营业时间注意？

大部分每日营业。长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 节假日休息。虎先生 (Ho-Sunsaeng / 호선생전) 部分周一休息。韩果美意识 (Hangwa Mi-Uisik / 한과미의식) 根据季节有变动。建议提前确认。

Q8. 轮椅·婴儿车通行？

质哈布罗斯 (Quill Bros / 질할브로스) / 标准班 (Standard Bun / 스탠다드번) / 砧板 (Doma / 도마) — 路线平坦。韩屋朗松 (Hanok Ransom / 한옥랑솜)·炉锅 (Solsot / 솔솥)·虎先生 (Ho-Sunsaeng / 호선생전)·益善洞 (Ikseondong / 익선동) 胡同较窄，多有台阶·门槛。

Q9. 广藏市场 (Gwangjang Market / 광장시장) 有什么著名美食？（What is Gwangjang Market famous for?）

绿豆饼 (Bindaetteok / 빈대떡)·麻药紫菜卷 (Mayak Gimbap / 마약김밥)·牛肉生拌 (Yukhoe / 육회) 是外国游客前三名。铁板现煎绿豆饼 (Bindaetteok / 빈대떡) 和拇指大小麻药紫菜卷 (Mayak Gimbap / 마약김밥) 在SNS大火。首尔首家近代市场（1905年开业）室内美食街。

Q10. 广藏市场 (Gwangjang Market / 광장시장) 值得去吗？（Is Gwangjang Market worth visiting?）

强烈推荐。备好₩30,000–40,000现金，即可体验绿豆饼 (Bindaetteok / 빈대떡)·麻药紫菜卷 (Mayak Gimbap / 마약김밥)·牛肉生拌 (Yukhoe / 육회) 全部美食。约需2小时。钟路5街站 (Jongno 5-ga Station / 종로5가역) 步行2分钟。

Q11. 钟路 (Jongno / 종로) 一日游中广藏市场 (Gwangjang Market / 광장시장) 何时去最好？

午餐时段（11:30–13:00） 最佳——上午游览景福宫 (Gyeongbokgung / 경복궁) 或仁寺洞 (Insadong / 인사동) → 广藏市场 (Gwangjang Market / 광장시장) 午餐 → 下午益善洞 (Ikseondong / 익선동)，是钟路 (Jongno / 종로) 最优一日动线。

🌸 5个季节·时段攻略

1. 春季（3~5月）景福宫 (Gyeongbokgung / 경복궁) 樱花：景福宫 (Gyeongbokgung / 경복궁) + 长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) + 仁寺洞 (Insadong / 인사동) 路线 — 韩国春天精华。

2. 夏季（6~8月）三伏 (Sambok / 삼복)：长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 旺季。外国游客也可体验韩国滋补美食。

3. 秋季（9~11月）益善洞 (Ikseondong / 익선동) 红叶：韩屋朗松 (Hanok Ransom / 한옥랑솜)·炉锅益善洞 (Solsot Ikseon / 솔솥 익선점) 韩屋 (Hanok / 한옥) 胡同红叶季。

4. 冬季（12~2月）虎先生 (Ho-Sunsaeng / 호선생전) 料理酒馆：温暖料理酒馆 + 马格利 (Makgeolli / 막걸리) 套餐。

5. 清晨（08:00–10:00）：光化门 (Gwanghwamun / 광화문)·景福宫 (Gyeongbokgung / 경복궁) 人少。长寿参鸡汤 (Jangsu Samgyetang / 장수삼계탕) 11:00开门，提前到达午餐无压力。
