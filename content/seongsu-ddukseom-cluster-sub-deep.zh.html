Ttukseom汉江公园·Eungbongsan指南 — Ttukseom汉江公园·Byeokcheon Madang·风帆冲浪场·游泳池·雪橇场，Eungbongsan山·攀岩公园，Salgoji桥·Salgoji体育公园，Jayang-dong羊肉串街·往十里美食巷

副标题:Ttukseom汉江公园(全天开放，免费) · Byeokcheon Madang(喷泉·岩壁) · Ttukseom风帆冲浪场(5~10月) · Ttukseom雪橇场(12月底~2月中旬 10:00~17:00) · Eungbongsan山(约95m，全天开放) · Eungbongsan攀岩公园(免费，需预约，周一闭馆) · 首尔Salgoji桥(全天开放) · Salgoji体育公园 · Jayang-dong羊肉串街 · 往十里美食巷 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了首尔广津区Ttukseom汉江公园(Ttukseom Hangang Gongwon / 뚝섬한강공원)和城东区Eungbongsan山(Eungbongsan / 응봉산)周边值得一去的地方。随季节变换玩法的Ttukseom汉江公园、观赏日落和夜景的Eungbongsan山与人工岩壁、朝鲜前期的石桥Salgoji桥，以及Geondae-ipgu站附近的羊肉串街和往十里站附近的美食巷。Seoul Forest和Seongsu-dong在#701 Seoul Forest·Seongsu指南里。

随季节开放的设施不同。风帆冲浪场登记为5~10月，雪橇场登记为12月底~2月中旬。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 Ttukseom汉江公园 — 公园·Byeokcheon Madang·风帆冲浪场·游泳池·雪橇场

Ttukseom汉江公园(Ttukseom Hangang Gongwon / 뚝섬한강공원)，广津区(Gangbyeonbuk-ro 2273 / 강변북로 2273)，☎ 02-3780-0521~4，在成为汉江公园之前就以江边游乐园闻名。有水边广场、玫瑰园、自然学习场、儿童游乐场、X Games场(X Game-jang / X게임장)、人工攀岩场和游览船码头。夏天可以玩风帆冲浪、水上滑水、摩托艇等水上运动，据介绍冬天会变成雪橇场和滑冰场。有一个长243m的尺蠖形展览空间，与地铁Ttukseomyuwonji站(Ttukseom Yuwonji-yeok / 뚝섬유원지역)相连。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。
  • 停车:可以(674辆)。前30分钟 1,000韩元，之后每10分钟200韩元。

Ttukseom汉江公园 Byeokcheon Madang(Ttukseom Hangang Gongwon Byeokcheon Madang / 뚝섬한강공원 벽천마당)，广津区Jayang-dong(Jayang-dong / 자양동)，☎ Ttukseom Information Center(Ttukseom Annae Center / 뚝섬안내센터) 02-3780-0521~4，有从地面涌出的喷泉和攀岩设施。据韩国观光公社介绍，它与Yeouido汉江公园(Yeouido Hangang Gongwon / 여의도한강공원)的水上喷泉、Nanji汉江公园(Nanji Hangang Gongwon / 난지한강공원)的镜面喷泉一起，是首尔汉江三大喷泉公园之一。夜晚可以看到灯光喷泉。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。
  • 停车:前30分钟 1,000韩元，之后每10分钟200韩元，每天最高10,000韩元。

Ttukseom风帆冲浪场(Ttukseom Windsurfing-jang / 뚝섬 윈드서핑장)，广津区(Gangbyeonbuk-ro 2326 / 강변북로 2326)，☎ Ttukseom Information Center(Ttukseom Annae Center / 뚝섬안내센터) 02-3780-0521~4，是位于Ttukseom汉江公园网球场旁的水上休闲设施。可以玩风帆冲浪、桨板、皮划艇、桨板瑜伽和香蕉船，多家私营企业提供课程和设备租赁。

  • 运营期间:5~10月。开放时间:各企业不同。

Ttukseom游泳池(室外)(Ttukseom Suyeongjang / 뚝섬수영장)，广津区(Jayang-dong 112 / 자양동 112)，是Ttukseom汉江公园内的露天游泳池，可容纳约3,500人。有成人池、儿童池、幼儿池和漂流池，还有高4m的Aqua Ring(Akuaring / 아쿠아링)和日光浴场。运营期间和费用无登记值。

  • 优惠:65岁以上、残疾人、国家功勋者等减免50%。

汉江公园Ttukseom雪橇场(Hangang Gongwon Ttukseom Nunseolmaejang / 한강공원 뚝섬 눈썰매장)，广津区(Gangbyeonbuk-ro 139 / 강변북로 139)，☎ 02-452-5955，分为大型滑道和小型滑道。有雪地游乐园、游乐设施和公鱼冰钓体验区。门票可以在现场购买，也可以在线预约。小型滑道主要供儿童使用，监护人也要一起上去，乘坐雪圈滑下来。有男女更衣室和收费储物柜。

  • 开放时间:12月底~2月中旬 10:00~17:00。登记有期间可能变动。

📍 Eungbongsan — Eungbongsan山·攀岩公园

Eungbongsan山(Eungbongsan / 응봉산)，城东区(Eungbong-dong / 응봉동)，☎ 02-2286-6061，是一座高约95m的山。朝鲜时代国王在这里放鹰狩猎，所以也称为Maebongsan(Maebongsan / 매봉산)。南边曾有储存冰块的Dongbinggo(Dongbinggo / 동빙고)。如今是邻里公园，人们来这里看首尔的日落和夜景。园内有儿童公园、攀岩公园和羽毛球场。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

Eungbongsan攀岩公园(Eungbongsan Ambyeok Deungban Gongwon / 응봉산 암벽등반공원)，城东区(Dokseodang-ro 60-gil 13-1 / 독서당로60길 13-1)，☎ Eungbongsan管理事务所(Eungbongsan Gwanri Samuso / 응봉산 관리사무소) 02-2286-6061，位于登上Eungbongsan山的路口。在采石后废弃的地方建起了人工岩壁，有抱石场和高直壁。有更衣室和广场。需在首尔市公共预约系统(Seoul-si Gonggong Yeyak System / 서울시 공공예약 시스템)预约后使用。使用费免费，但不出借也不出售攀岩装备，所需装备要自己带。

  • 开放时间:工作日 10:00~21:00，周末·法定节假日 10:00~18:00。休息日:每周一。

📍 Jungnangcheon — 首尔Salgoji桥·Salgoji体育公园

首尔Salgoji桥(Seoul Salgoji Dari / 서울 살곶이 다리)，城东区Seongsu-dong(Seongsu-dong / 성수동)，☎ 城东区厅文化体育科(Munhwa Cheyuk-gwa / 문화체육과) 02-2286-5193，是1420年开始建造、中途停工，1475年重新施工并于1483年建成的石桥。因走在上面像走在平地上，也称为济盘桥(Jebangyo / 제반교)。据韩国观光公社介绍，它是朝鲜前期建造的桥中最大的，用了64根石柱。石柱为减小水的阻力而做成菱形。1920年代的暴雨冲走了一部分，1970年代修复，但右侧接上了混凝土，稍微失去了原貌。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

Salgoji体育公园(Salgoji Cheyuk Gongwon / 살곶이체육공원)，城东区(Jungnangcheon-seo Jajeongeo-gil 209 / 중랑천서자전거길 209)，☎ 02-2286-6090，位于清溪川与Jungnangcheon(Jungnangcheon / 중랑천)交汇处附近。有轮滑场、足球场、篮球场和羽毛球场，自行车道与步行道分开。据介绍夏天运营免费戏水场。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:每5分钟50韩元。

📍 美食街 — Jayang-dong羊肉串街·往十里美食巷

Jayang-dong羊肉串街(Jayang-dong Yangkkochi-geori / 자양동 양꼬치거리)，广津区Jayang-dong(Jayang-dong / 자양동)，☎ Seongsu Tourist Information Center(Seongsu Gwangwang Annaeso / 성수관광안내소) 02-466-2286，也称为“中国饮食文化街”。从地铁2号线·7号线Geondae-ipgu站(Geondae-ipgu-yeok / 건대입구역)5号出口出来，穿过Rodeo街(Rodeo-geori / 로데오거리)，朝汉江方向往下走约50m就到。这里聚集了中国朝鲜族同胞经营的羊肉串专卖店和融合中餐馆，中文招牌比韩文招牌还多。

  • 开放时间·休息日:各店铺不同。停车:每5分钟250韩元。

往十里美食巷(Wangsimni Matgolmok / 왕십리맛골목)，城东区(Majo-ro 17 / 마조로 17)，是往十里站(Wangsimni-yeok / 왕십리역)附近的美食街。聚集了韩餐、中餐和日餐餐厅。开放时间和休息日无登记值。

⚠ 行前须知 3 点

  1. 风帆冲浪场5~10月开放，雪橇场12月底~2月中旬开放 — 登记有雪橇场期间可能变动。
  2. Eungbongsan攀岩公园要预约，并自带装备 — 使用费免费，周一休息。
  3. Salgoji桥不能停车 — Salgoji体育公园每5分钟50韩元。

⚙ FAQ 2

Q. 冬天在Ttukseom汉江公园能做什么?

A. 按观光公社登记信息，Ttukseom雪橇场在12月底~2月中旬 10:00~17:00开放，有雪地游乐园和公鱼冰钓体验。Ttukseom汉江公园的介绍中还提到冬季滑冰场。

Q. 哪里能看夜景?

A. Eungbongsan山以日落和夜景著称，全天开放。在Ttukseom汉江公园Byeokcheon Madang(Ttukseom Hangang Gongwon Byeokcheon Madang / 뚝섬한강공원 벽천마당)，夜晚可以看到灯光喷泉。
