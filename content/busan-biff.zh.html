⚠ 外国人常犯的5个错误

1. “BIFF = 只在10月看”: BIFF (10月·1周) 之外，电影殿堂 (Dureraum / 영화의전당) 全年开放 + BIFF 广场 (BIFF Gwangjang / BIFF 거리) (南浦洞 / Nampo-dong / 남포동) 全年开放 + 外国人电影爱好者深度游。

2. “电影殿堂 (Dureraum / 영화의전당) = 普通影院”: 电影殿堂 (Dureraum / 영화의전당) = 韩国第一影院 + BIFF 总部 + 外国爱好者首选地 + 外部LED 4,000平方米 (BIFF 期间外部广场夜间首选地)。

3. “海东龙宫寺 (Haedong Yonggungsa / 해동용궁사) = 无法前往”: 海东龙宫寺 (Haedong Yonggungsa / 해동용궁사) = 釜山 (Busan / 부산) 第一寺庙 + 海上寺庙 + 外国人 Instagram 首选地 + 毗邻机张 (Gijang / 기장) + 外国爱好者首选。

4. “机张 (Gijang / 기장) = 周边无法前往”: 机张 (Gijang / 기장) = 釜山 (Busan / 부산) 周边第一深度游 + 竹城教堂 (Jukseong Catholic Church / 죽성성당)·海东龙宫寺 (Haedong Yonggungsa / 해동용宫寺)·周边海滩·外国爱好者。

5. “Centum City 新世界百货 (Shinsegae Department Store / 신세계백화점) = 只有百货商店”: Centum City 新世界百货 (Shinsegae Department Store / 신세계백화점) = 吉尼斯世界第一百货商店 + 外国爱好者首选地 + 毗邻 BIFF 电影殿堂 (Dureraum / 영화의전당)。
