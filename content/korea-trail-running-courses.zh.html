韩国越野跑路线指南 — 汉阳都城巡城路·北汉山环山路·Achasan山的首尔山路，Igidae海岸散步路·济州Olle第7线路·南海Barae路的海岸路，Gajisan山·无等山·香积峰的山岳路线，共20处

副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“越野跑”主题入选的地方中，找到了与投票路线相符的韩国观光公社登记信息的20处 · 登记了路线长度和所需时间的有北汉山环山路(3.1~5.2㎞)·首尔环山路第5线路 Achasan线路(4.6㎞)·南海Barae路第11线路(13.6㎞)·大关岭旧道(13.4㎞)·盈德蓝色之路第3线路(17.6㎞)等 · 庆州南山·德裕山香积峰·无等山登记了使用时间段 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南介绍的是在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“越野跑”主题入选的100处中，韩国观光公社旅游信息里找到了与投票路线相符的登记信息的20处。表中的排名和得票数就是这次投票的结果。韩国观光公社的登记是否与投票路线相符不确定的地方(首尔南山环山路 (Seoul Namsan Dulle-gil / 서울 남산 둘레길)·南汉山城环山路 (Namhansanseong Dulle-gil / 남한산성 둘레길)·雉岳山环山路 (Chiaksan Dulle-gil / 치악산 둘레길)·清风湖Jadeurak路 (Cheongpungho Jadeurak-gil / 청풍호 자드락길)等)，以及没有找到登记信息的地方(济州Olle第10线路 (Jeju Olle 10-course / 제주올레 10코스)·汉拿山探访路 (Hallasan Tambang-ro / 한라산 탐방로)等)没有收入。以森林路为主的Saryeoni森林路 (Saryeoni Sup-gil / 사려니숲길)·西归浦治愈森林 (Seogwipo Chiyuui Sup / 서귀포 치유의 숲)·济州Jeolmul自然休养林 (Jeju Jeolmul Jayeonhyuyangnim / 제주절물자연휴양림)已在#1427 韩国森林放空·水边放空·赤脚漫步指南中介绍，Saebyeol小火山 (Saebyeol-oreum / 새별오름)·Yongnuni小火山 (Yongnuni-oreum / 용눈이오름)已在#1423 济州小火山指南中介绍，所以这里没有收入。

越野跑是在像山路一样的非铺装道路上奔跑的运动。正文中的路线长度和所需时间是韩国观光公社登记的步行标准值。韩国观光公社信息中没有关于是否适合跑步的说明，表中的排名只是投票结果。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。没有登记值的栏写作“无登记值”。投票名单中的名称或地址与韩国观光公社登记不同的地方，正文中另行说明。

📍 从首尔市区出发的山路 — 汉阳都城巡城路·北汉山环山路·Achasan山·冠岳山

汉阳都城巡城路 (Hanyang Doseong Sunseong-gil / 한양도성 순성길)的韩国观光公社登记地址是钟路区 (Nusang-dong San 1-29 / 누상동 산1-29)。这是沿着连接北岳山·仁王山·骆山·南山、全长18.6㎞的首尔城郭一圈步行的路。分为白岳段(彰义门~惠化门)、骆山段(惠化门~兴仁之门)、南山(木觅山)段(奖忠体育馆~白凡广场)、仁王段(敦义门旧址~彰义门)四条线路。投票名单中的地址是中区 (Sindang-dong 229-41 / 신당동 229-41)。

  • 开放时间·休息日·费用:无登记值。

北汉山环山路 (Bukhansan Dulle-gil / 북한산 둘레길)是为了在北汉山山脚缓缓行走、把原有的小路连起来修成的低地平路。全长71.5㎞，共21个路段。投票中有三个路段单独入选。

  • 第10段 内侍墓域路 (Naesi Myoyeok-gil / 내시묘역길)位于恩平区 (Jingwan-dong / 진관동)，从Bangpae教育队 (Bangpae Gyoyukdae / 방패교육대)前到孝子洞公设墓地 (Hyoja-dong Gongseol Myoji / 효자동공설묘지)，3.5㎞，约1小时45分钟。有8m高的环山桥。
  • 第1段 Sonamusup路 (Sonamu Sup-gil / 소나무숲길)位于江北区 (Ui-dong / 우이동)，从Uiryeong-gil入口 (Uiryeong-gil Ipgu / 우이령길 입구)到Solbat近邻公园 (Solbat Geunrin Gongwon / 솔밭근린공원)上端，3.1㎞，约1小时30分钟。路宽而平缓，部分路段沿着Ui溪谷 (Ui Gyegok / 우이계곡)而行。
  • 第8段 Gureumjeongwon路 (Gureum Jeongwon-gil / 구름정원길)位于恩平区 (Bulgwang-dong / 불광동)，从北汉山生态公园 (Bukhansan Saengtae Gongwon / 북한산생태공원)上端到Jingwan生态桥 (Jingwan Saengtae-gyo / 진관생태다리)前，5.2㎞，约2小时30分钟。有一条横跨Gugi隧道 (Gugi Teonnel / 구기터널)上方溪谷、长60m的木栈道(天空步道)。
  • 开放时间·休息日·费用:三个路段均无登记值。

Achasan山 (Achasan / 아차산)位于首尔广津区 (Gingorang-ro 213 / 긴고랑로 213)，☎ Achasan管理事务所 (Achasan Gwalli Samuso / 아차산관리사무소) 02-450-1655，海拔295.7m。据韩国观光公社介绍，走登山路约40分钟可到山顶。在山顶可以360度眺望蚕室·南山·北汉山·道峰山一带的首尔风景。首尔环山路第5线路 Achasan线路 (Seoul Dulle-gil 5-course Achasan Course / 서울둘레길 5코스 아차산코스)是从Kkaldak-gogae休息处 (Kkaldak-gogae Swimteo / 깔딱고개 쉼터)到Gwangnaru站 (Gwangnaru-yeok / 광나루역)，4.6㎞，约2小时10分钟。投票名单中以“Achasan山顶路线 (Achasan Jeongsang-gil Course / 아차산 정상길코스)”的名称入选，但这是否与首尔环山路第5线路是同一条路，无法从登记信息得知。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

冠岳山 (Gwanaksan / 관악산)位于冠岳区 (Daehak-dong Ildae / 대학동 일대)，☎ 冠岳区Yeoga Dosi科 (Gwanak-gu Yeoga Dosi-gwa / 관악구 여가도시과) 02-879-6552，高632.2m。从首尔大学入口 (Seoul Daehakgyo Ipgu / 서울대학교 입구)出发的登山路最具代表性，也有从果川中学 (Gwacheon Junghakgyo / 과천중학교)后面上去的路。介绍中写道，冠岳山所有的登山路都汇聚到悬崖上的Yeonjudae台 (Yeonjudae / 연주대)。投票名单中的地址是京畿道果川市 (Jungang-dong / 중앙동)。

  • 开放时间·费用:无登记值。休息日:全年无休。

📍 沿海岸行走的海岸路 — Igidae·济州Olle第7线路·南海Barae路

Igidae海岸散步路 (Igidae Haean Sanchaekro / 이기대해안산책로)位于釜山南区 (Yongho-dong San 25 / 용호동 산25)，属于釜山国家地质公园，也是釜山海岸路Galmaet-gil第2线路 (Galmaet-gil 2-course / 갈맷길 2코스)的一段。经过Dongsaengmal (동생말)·Eoulmadang (어울마당)·Nongbawi (농바위)，一直到五六岛日出公园 (Oryukdo Haemaji Gongwon / 오륙도 해맞이공원)，由岩石悬崖·吊桥·木栈道连接。可以一边眺望海云台·广安大桥·Marine City一边行走，尽头的日出公园有五六岛天空步道 (Oryukdo Skywalk / 오륙도스카이워크)。

  • 开放时间·休息日·费用:无登记值。

济州Olle第7线路 (Jeju Olle 7-course / 제주올레 7코스)的出发地是西归浦市 (Jungjeong-ro 22 / 중정로 22)的济州Olle旅行者中心 (Jeju Olle Yeohaengja Center / 제주올레 여행자센터)，☎ 064-762-2190。这是从旅行者中心经过Beophwan浦口 (Beophwan Pogu / 법환포구)一直到Wolpyeong (월평)的海岸Olle。路线经过Oedolgae (외돌개)，以及Olle守护人 (Ollejigi / 올레지기) Gim Subong (김수봉)先生用铁锹和镐头开出来的路“Subong路 (Subong-ro / 수봉로)”。济州Olle整体共27条线路、437km。

  • 开放时间:全天开放。休息日:全年无休。费用:无登记值。

南海Barae路第11线路 Darangi Jigeot路 (Namhae Barae-gil 11-course Darangi Jigeot-gil / 남해바래길 11코스 다랭이지겟길)位于南海郡 (Nam-myeon / 남면)，起点是Gacheon Darangi村 (Gacheon Darangi Maeul / 가천다랭이마을)，终点是南海Barae路小美术馆 (Namhae Barae-gil Jageun Misulgwan / 남해바래길 작은미술관)。这是从Gacheon Darangi村经过Sachon海滩 (Sachon Haebyeon / 사촌해변)一直到Pyeongsan港 (Pyeongsan-hang / 평산항)沿海岸行走的路。13.6㎞，需要5小时30分钟。介绍中写道，“Barae (바래)”指南海人按潮汐时间，在滩涂·礁石上只采所需海产的活动。投票名单中的地址是南面 (Impo-ri 1193 / 임포리 1193)。

  • 开放时间·休息日·费用:无登记值。

📍 山岳路线 — Gajisan山·蔚山岩·香积峰·无等山·太白山·鸡龙山·庆州南山

Gajisan山 (Gajisan / 가지산)在韩国观光公社登记为Gajisan道立公园 (Gajisan Doripgongwon / 가지산도립공원)，位于密阳市 (Sannae-myeon / 산내면)，☎ 密阳市厅山林绿地科 (Miryang-sicheong Sallim Nokji-gwa / 밀양시청 산림녹지과) 055-359-5297。这是位于密阳·蔚州郡·清道交界处的山。据韩国观光公社介绍，它是被称为“岭南阿尔卑斯 (Yeongnam Alps / 영남 알프스)”的山群中最高的，沿山脊可以纵走到云门山 (Unmunsan / 운문산)。秋天，从Seongnam岭 (Seongnam-gogae / 석남고개)到山顶铺展开芒草田。投票名单中的地址是蔚山蔚州郡 (Sangbuk-myeon / 상북면)。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。登记值中写明详情请电话咨询。

蔚山岩 (Ulsanbawi / 울산바위)位于束草市 (Seoraksan-ro 1140-115 / 설악산로 1140-115)，☎ 雪岳山国家公园 (Seoraksan Gungnip Gongwon / 설악산국립공원) 033-801-0900，是海拔近900m、像屏风一样环绕着六座山峰的岩山，周长4㎞。从小公园 (Sogongwon / 소공원)出发，经过神兴寺 (Sinheungsa / 신흥사)和摇摆岩 (Heundeulbawi / 흔들바위)向上攀登。

  • 开放时间:全天开放(详情登记为电话咨询)。休息日:全年无休。费用:免费。

德裕山香积峰 (Deogyusan Hyangjeokbong / 덕유산 향적봉)位于茂朱郡 (Seolcheon-myeon / 설천면)，☎ 德裕山国家公园事务所 (Deogyusan Gungnip Gongwon Samuso / 덕유산국립공원사무소) 063-322-3174，海拔1,614m，据韩国观光公社介绍，是南韩第四高峰。乘缆车上去的雪川峰 (Seolcheonbong / 설천봉)到香积峰路段，作为短线路很受欢迎。第1线路0.6㎞，第2线路8.5㎞，也可以走到南德裕山 (Namdeogyusan / 남덕유산)约14.8㎞的纵走。投票名单中的地址是茂朱郡 (Anseong-myeon Deoksan-ri San 1 / 안성면 덕산리 산1)。

  • 开放时间(登记值):4~10月 04:00~15:00，11~3月 05:00~14:00。可能因天气限制入山。
  • 休息日:全年无休。费用:免费。

无等山国家公园 (Mudeungsan Gungnip Gongwon / 무등산국립공원)位于光州东区 (Dongsan-gil 7beon-gil 5 / 동산길7번길 5)，☎ 无等山国家公园事务所 (Mudeungsan Gungnip Gongwon Samuso / 무등산국립공원사무소) 062-227-1187，2013年被指定为国家公园。最高峰天王峰 (Cheonwangbong / 천왕봉)海拔1,187m，瑞石台 (Seoseokdae / 서석대)·立石台 (Ipseokdae / 입석대)·广石台 (Gwangseokdae / 광석대)的柱状节理带被介绍为最大特点。投票名单中的地址是北区 (Mudeungsan Cheonwangbong-gil 460 / 무등산천왕봉길 460)。

  • 开放时间(登记值):3~11月 04:00~17:00，12~2月 04:00~16:00。3~11月的结束时间是把登记表述“04:00~1700”读作17:00得出的。
  • 休息日:全年无休。费用:免费。

太白山国家公园 (Taebaeksan Gungnip Gongwon / 태백산국립공원)位于太白市 (Beonyeong-ro 59 / 번영로 59)，☎ 033-550-0013，以设有天祭坛的灵峰 (Yeongbong / 영봉)(1,560m)为中心，将军峰 (Janggunbong / 장군봉)(1,567m)·文殊峰 (Munsubong / 문수봉)(1,517m)·Buswae峰 (Buswaebong / 부쇠봉)(1,546m)相连，最高峰是咸白山 (Hambaeksan / 함백산)(1,572m)。山顶一带以东北红豆杉群落闻名。投票名单中的地址是太白市 (Hyeol-dong / 혈동)。

  • 开放时间:登记值中写明因路段而异，请参考官网。休息日:全年无休。费用:免费。

鸡龙山国家公园 (Gyeryongsan Gungnip Gongwon / 계룡산국립공원)位于公州市 (Banpo-myeon Donghaksa 1-ro 327-6 / 반포면 동학사1로 327-6)，☎ 鸡龙山国家公园事务所 (Gyeryongsan Gungnip Gongwon Samuso / 계룡산국립공원사무소) 042-820-3100，1968年被指定为韩国第二个国家公园。以主峰天皇峰 (Cheonhwangbong / 천황봉)(847m)为中心，有16座山峰和约10条溪谷。

  • 开放时间·休息日:登记值中写明因气象条件管制，请参考官网。

庆州南山 (Gyeongju Namsan / 경주 남산)位于庆州市 (Bae-dong / 배동)，☎ 庆州南山研究所 (Gyeongju Namsan Yeonguso / 경주남산연구소) 054-777-7142，是由从金鳌峰 (Geumobong / 금오봉)(468m)和高位峰 (Gowibong / 고위봉)(494m)流下的40多条山谷构成的山。寺址100多处、石佛80多尊、石塔60多座散布其间，被介绍为露天博物馆。

  • 开放时间(登记值):4~10月 04:00~16:00，11~3月 05:00~15:00。休息日:全年无休。费用:免费。停车:登记为不可。

📍 森林路·古道等 — Solmaru路·大关岭旧道·五台山Seonjae路·Sanmagi古道·Meochewat森林路·盈德蓝色之路

Solmaru路 (Solmaru-gil / 솔마루길)位于蔚山南区 (Dotjil-ro 233 / 돋질로 233)，是连接松树茂密的山脊的登山路。据韩国观光公社介绍，它以“城市里的60里名品散步路”闻名，全路段都有公园灯，夜里也有人使用。较晚的时间会关掉公园灯。投票名单中以“Solmaru路 南山线路 (Solmaru-gil Namsan Course / 솔마루길 남산코스)”的名称和南区 (Sinjeong-dong San 107-2 / 신정동 산107-2)的地址入选。

  • 开放时间·休息日·费用:无登记值。

大关岭旧道 (Daegwallyeong Yet-gil / 대관령 옛길)是江陵Bau-gil第2段 (Gangneung Bau-gil 2-section / 강릉 바우길 2구간)，出发地是平昌郡大关岭面 (Gyeonggang-ro 5754 / 경강로 5754)。从大关岭顶上的新再生能源展示馆 (Sinjaesaeng Eneoji Jeonsigwan / 신재생에너지전시관)前，到江陵市 (Seonsang-myeon Bogwang-ri / 선상면 보광리)(照登记表述)，是13.4㎞、6~7小时的中级路线。这是连接岭东和岭西的路，2010年被指定为名胜。投票名单中的地址是江陵市 (Seongsan-myeon Eoheul-ri / 성산면 어흘리)。

  • 开放时间·休息日·费用:无登记值。

五台山Seonjae路 (Odaesan Seonjae-gil / 오대산 선재길)位于平昌郡 (Jinbu-myeon / 진부면)，是从月精寺 (Woljeongsa / 월정사)到上院寺 (Sangwonsa / 상원사)约9㎞的森林路。介绍中写道，大部分是平地，走起来方便。1960年代末道路修建之前，这里就是僧侣和信徒往来的古道。投票名单中的地址是五台山路 (Odaesan-ro 713-77 / 오대산로 713-77)。

  • 开放时间·休息日·费用:无登记值。

Sanmagi古道 (Sanmagi Yetgil / 산막이옛길)位于槐山郡 (Chilseong-myeon Myeongtaejae-ro Oesa 4-gil 1 / 칠성면 명태재로외사4길 1)，是复原了从Saorang村 (Saorang Maeul / 사오랑 마을)通往山村Sanmagi村 (Sanmagi Maeul / 산막이 마을)的古道的散步路。大部分路段是木栈道，沿着槐山大坝 (Goesan-dam / 괴산댐)的湖边行走。有两条线路。

  • 开放时间·休息日·费用:无登记值。

Meochewat 森林路 (Meochewat-supgil / 머체왓숲길)位于西归浦市 (Namwon-eup Seoseong-ro 755 / 남원읍 서성로 755)，是同时穿行牧场·草原和原始林的森林路。据韩国观光公社介绍，“Meoche (머체)”指石头堆积、杂木丛生的地方，“Wat (왓)”是济州语的“田”。沿着石墙出发，经过扁柏群落地和Seojungcheon瞭望台 (Seojungcheon Jeonmangdae / 서중천 전망대)。也可以与解说员同行。

  • 开放时间·休息日·费用:无登记值。

盈德蓝色之路第3线路 风之丘 (Yeongdeok Blue Road 3-course Baram-ui Eondeok / 영덕 블루로드 3코스 바람의 언덕)位于盈德郡江口面，☎ 盈德郡厅文化观光科 (Yeongdeok-guncheong Munhwa Gwangwang-gwa / 영덕군청 문화관광과) 054-730-6349，起点是江口Daege街 (Gangu Daege-geori / 강구대게거리)，终点是Changpomal灯塔 (Changpomal Deungdae / 창포말등대)。总长17.6㎞，单程约4小时55分钟，据韩国观光公社介绍，是连接盈德山林观光名胜的主题旅行路线。从江口Daege街出发，经过日出登山路入口 (Haemaji Deungsanro Ipgu / 해맞이 등산로 입구)·Geumjin吊桥 (Geumjin Gureum-dari / 금진 구름다리)·Gobulbong入口 (Gobulbong Ipgu / 고불봉 입구)，到Changpomal灯塔。投票名单中没有路线编号，以“盈德蓝色之路 (Yeongdeok Blue Road / 영덕 블루로드)”的名称入选。

  • 开放时间:全天开放。休息日:全年无休。

⚠ 行前须知 3 点

  1. 有使用时间段的山 — 德裕山香积峰(11~3月 05:00~14:00)、庆州南山(11~3月 05:00~15:00)、无等山(12~2月 04:00~16:00)登记了时间段。香积峰可能因天气限制入山，鸡龙山也因气象条件管制。
  2. 长线路要留足时间 — 按登记的步行标准，盈德蓝色之路第3线路单程约4小时55分钟，大关岭旧道6~7小时，南海Barae路第11线路需要5小时30分钟。
  3. 表中的排名是投票结果 — 韩国观光公社信息中没有关于是否适合跑步的官方说明。

⚙ FAQ 3

Q. 首尔有哪些路线?

A. 汉阳都城巡城路、北汉山环山路第1·8·10段、Achasan山、冠岳山。按登记的长度，北汉山环山路第1段(3.1㎞)最短。

Q. 登记为沿海岸行走的路线有哪些?

A. 釜山Igidae海岸散步路、济州Olle第7线路、南海Barae路第11线路。盈德蓝色之路第3线路在韩国观光公社的介绍中写作连接山林观光名胜的路线。

Q. 投票第1名是哪里?

A. Gajisan山(145票)。据韩国观光公社介绍，它是“岭南阿尔卑斯”山群中最高的山。第2名是釜山Igidae海岸散步路(125票)。
