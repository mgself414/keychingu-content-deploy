🎯 왜 망원 단독 가이드인가

망원은 홍대권 동네 hidden gems sub-area — 망원역·망원로·망원시장 메인. 외부 #138 홍대·#139 카페 가이드와 다르게, 본 가이드는 망원동 specific 8선 deep dive. 망원 한강공원 + 망원시장 + 동네 hidden 결합.

T6.6 cluster 분석에서 망원동 매장 외국인 신호 매장 5+개 (비캔드 signal 112.2 holdae권 cluster 최강 신호). 망원시장 + 한강 + 트렌디 카페·브런치 영역.

⚠ 망원 외국인 5대 실수

1. "망원 = 망원시장만" 인식

외국인 동선상 흔한 실수. 망원을 시장 단일 spot으로 인식. 실제로는 망원 카페·브런치·이탈리안 hidden gems 밀집 — 시장 산책 후 디너·디저트 코스 가능.

2. 망원시장 + 한강 + 브런치 동선 모름

외국인 망원 동선이 시장만 보고 끝. 실제로는 망원시장 산책 → 비캔드 브런치 → 망원 한강 → 카페 디저트 4-5시간 풀 동선 가능.

3. 비캔드 (망원 브런치 cluster 1위) 미인지

외국인 망원 브런치 1위 매장 (signal 112.2, 외국인 리뷰 25건). 한국인 인스타 핫스팟이지만 외국인 가이드북에 부재.

4. 망원시장 영업시간 + 음식 매너 모름

망원시장 오전 9시~오후 9시. 떡볶이·전·해산물·시장 음식 외국인 친화. 시장 음식 베이커리 + 한식 시그니처.

5. 망원 → 합정·연남 도보 미인지

망원역 ↔ 합정역 도보 12분, 망원 ↔ 연남 도보 15분. 한 동선으로 묶기 좋음.

4축 매핑

  • ① 망원 브런치 시그니처 (2): 비캔드 + 클로벨리 — 망원 브런치 최강 매장
  • ② 망원 카페 hidden (3): Uig + 리벌티 망원 + 망원 지튼 — 망원로 카페 골목
  • ③ 망원 디저트 (1): 에브리데이해피벌스데이 — 생일 케이크 컨셉
  • ④ 망원 한강·동네 (2): Alive214 + 아우룸 — 월드컵로 브런치·이탈리안

① 망원 브런치 시그니처 (2곳)

1. 비캔드 (Beyond)

  • 시그니처: 망원 브런치 최강 신호 매장. 외국인 리뷰 25건 (signal 112.2) — 홍대권 cluster 최강.
  • 외국인 친화도: ★★★★★ — 외국인 리뷰 최강
  • 추천 메뉴: 시그니처 브런치 플레이트, 시즌 음료
  • 팁: 망원역 도보 5분. 외국인 첫 망원 1순위 추천. 주말 브런치 10-14시 피크.

2. 클로벨리 (Clovelly)

  • 시그니처: 망원 브런치 hidden. 외국인 리뷰 10건 (signal 46.1).
  • 외국인 친화도: ★★★★☆ — 영문 매장명
  • 추천 메뉴: 시그니처 브런치, 시즌 메뉴
  • 팁: 망원로 인근. 비캔드와 같은 동선.

② 망원 카페 hidden (3곳)

3. Uig

  • 시그니처: 망원로 스페셜티 hidden. 외국인 리뷰 6건 (signal 30).
  • 외국인 친화도: ★★★★☆ — 영문 매장명
  • 추천 메뉴: 시그니처 핸드드립, 스페셜티 음료
  • 팁: 망원로3길 7. Reddit·외국인 vlogger 사이 인기.

4. 리벌티 망원 (Reverty Mangwon)

  • 시그니처: 망원로7길 카페. 외국인 리뷰 9건 (signal 27.1).
  • 추천 메뉴: 시그니처 음료, 디저트
  • 팁: 망원시장 인접. 시장 산책 후 카페 코스.

5. 망원 지튼 (Mangwon Jiteun)

  • 시그니처: 망원로 카페 hidden. 외국인 리뷰 11건 (signal 32).
  • 추천 메뉴: 시그니처 음료, 시즌 디저트
  • 팁: 망원역 도보권. 평일 권장.

③ 망원 디저트 (1곳)

6. 에브리데이해피벌스데이 (Everyday Happy Birthday)

  • 시그니처: 망원 생일 케이크 컨셉. 외국인 리뷰 15건 (signal 45.6).
  • 외국인 친화도: ★★★★☆ — 인스타 핫컷 컨셉
  • 추천 메뉴: 생일 케이크 디저트, 시그니처 음료
  • 팁: 망원 연희로 33. 데이트·기념일 인스타 1위.

④ 망원 한강·동네 (2곳)

7. Alive214

  • 시그니처: 망원 월드컵로 브런치카페. 모던 인테리어 + 양식 플레이트.
  • 외국인 친화도: ★★★★☆ — 영문 매장명 (#153 양식 가이드 포함)
  • 추천 메뉴: 브런치 플레이트, 시그니처 음료
  • 팁: 망원 월드컵로13길 34. 망원 카페 산책 코스. 주말 브런치 10-14시 피크.

8. 아우룸 (Aurum)

  • 시그니처: 망원 월드컵로 이탈리안 본격 (#153 양식 가이드 포함).
  • 추천 메뉴: 시그니처 이탈리안, 와인
  • 팁: 망원역 도보 8분. 망원시장 산책 후 디너 코스.

동선 추천

[A] 망원시장 + 브런치 + 카페 풀 (반나절)

망원시장 산책 (#24 광장시장 패턴) → 비캔드 브런치 → 망원 지튼 또는 Uig 카페 → 에브리데이해피벌스데이 디저트

  • 추천 시간: 10시 ~ 17시

[B] 망원 한강 + 디너 (저녁 4-5시간)

망원 한강공원 → Alive214 또는 아우룸 디너 → 망원 카페 마무리

  • 추천 시간: 16시 ~ 22시

[C] 풀 망원 1일 코스

오전 망원시장 + 브런치 → 오후 카페 산책 → 한강 → 저녁 디너

  • 추천 시간: 10시 ~ 22시

결국, 망원은

홍대권 동네 hidden gems sub-area — 망원시장 + 한강 + 트렌디 브런치·카페·이탈리안 결합. 외국인 첫 망원이라면 비캔드 + 망원시장 + Alive214 3매장으로 브런치·시장·한강·이탈리안 4축 한 번에 경험. 비캔드 signal 112.2가 홍대권 cluster 최강 — 망원 외국인 인지도 가장 높은 매장.
