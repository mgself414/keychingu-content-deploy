🎯 なぜ「Seoul Art」メタなのか

訪韓外国人のart・museumへの関心比重が上昇↑ — 特にヨーロッパ・アメリカ自由旅行マニア + 日本マニア。韓国art = 国立現代美術館3館(ソウル・果川・清州・徳寿宮) + リウム美術館 (Leeum / 리움미술관) + ホアム美術館 (Hoam / 호암미술관) + ギャラリークラスター — 清潭 (Cheongdam / 청담)・三清 (Samcheong / 삼청)・仁寺洞 (Insadong / 인사동) + UNESCO韓国美術 + K-artトレンド。外国人向け英語ガイド + 無料多数。

本ガイドはart 4軸12シグネチャー + 1週間フル体験。

⚠ Artでよくある勘違い3つ

1. 「美術館=景福宮だけ」— 国立4館クラスター未認知: MMCAソウルのみ認識。実際にはMMCA 4館(ソウル・果川・清州・徳寿宮) + 国立中央博物館 = 韓国artフル体験マトリックス。

2. 「私立=リウムだけ」— ホアム・アモーレマニア未認知: リウムのみ認識。実際にはリウム(漢南) + ホアム(龍仁) + アモーレパシフィック(龍山) 3私立クラスター + 英語ガイドマニア。

3. 「ギャラリー=清潭だけ」— 三清・仁寺洞との違い未認知: 清潭だけラグジュアリーと認識。実際には三清洞(50+韓屋ギャラリー) + 仁寺洞(伝統・韓紙) + 清潭(ラグジュアリー・現代) 3種の異なるクラスター。
