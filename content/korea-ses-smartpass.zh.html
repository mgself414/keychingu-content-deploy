韩国机场自动通关(SES)·Smart Pass零慌乱手册——入境自动通关覆盖42个国家和地区,出境无需登记,还有刷脸登机的Smart Pass

副标题: 入境自动通关 = 42个国家·地区的免签入境者(2026-03-16扩大到42个,含日本·台湾·香港·澳门 / 不含美国·中国大陆) · 出境自动通关 = 入境时已录入指纹·人脸的17岁以上短期访客无需事先登记即可使用 · Smart Pass = 仁川 (Incheon / 인천) 机场出境专用的人脸认证服务——以2026-10-12为准

🎯 先了解——"SES"其实有两种

游记和博客里的登记时间有07~18时、07~22时、24小时等各种说法,是有原因的。入境时用的自动通关和出境时用的自动通关是两套不同的制度,登记地点和时间也不一样。再加上仁川 (Incheon / 인천) 机场运营的Smart Pass(人脸认证出境),就更容易搞混了。

类别 是什么 适用对象 在哪里 确认
入境自动通关 入境检查走自动通关通道 42个国家·地区的国民,免签入境 仁川 (Incheon / 인천) T1·T2、济州 (Jeju / 제주) 到达厅 官方(法务部)
出境自动通关 出境检查走自动通关通道 入境时已提供指纹·人脸的17岁以上短期访客 出境检查区 官方(法务部)
Smart Pass 登记人脸 → 通过出境区·登机口 7岁以上(外国人能否使用见下文③) 仁川 (Incheon / 인천) T1·T2 出境 官方(仁川国际机场公社)

① 入境自动通关——属于42个国家·地区,排队更短

2025-11-03从德国·台湾·香港·澳门4个开始,2025-12-01增至18个,2026-03-16扩大到42个国家·地区(法务部)。2026年中秋连休期间(9/24~27),仁川 (Incheon / 인천) 机场出入境旅客(含本国人·外国人)77万7,766人中有62.3%使用了自动通关闸机(法务部 2026-10-01)。

适用的42个国家·地区(法务部 2026-06-01资料)

  • 亚洲·中东·美洲·大洋洲: 日本·台湾·香港·澳门·新加坡·阿联酋·墨西哥·加拿大·澳大利亚·新西兰
  • 欧洲: 德国·英国·法国·意大利·西班牙·葡萄牙·荷兰·比利时·卢森堡·爱尔兰·奥地利·瑞士·列支敦士登·捷克·匈牙利·波兰·斯洛伐克·斯洛文尼亚·克罗地亚·芬兰·瑞典·丹麦·挪威·冰岛·爱沙尼亚·拉脱维亚·立陶宛·希腊·马耳他·塞浦路斯·罗马尼亚·保加利亚

⚠ 美国·中国大陆不在42个国家·地区名单上——入境时请做好走普通检查通道的准备(美国SES互认注册者如何处理,官方尚未确认)。出境自动通关按②的说明可以使用。

首次使用方法

1. 到达入境检查区后,按"自动出入境登记"指示牌前往登记队伍

2. 扫描护照 → 录入指纹 → 拍摄人脸 → 登记完成

3. 通过自动通关闸机。护照上会贴SES贴纸,下次入境时会有标记,请不要撕掉(日本游记中的实际案例)

  • 孩子多半走普通通道。 法务部的介绍资料里也是大人走自动通关闸机、孩子走家庭通道。入境方面的年龄标准未能在官方说明中确认,全家一起排普通队伍更省事。
  • 登记窗口的运营时间在官方文件中没有查到。二手资料写的是T1 07~22时、T2为24小时/05~20时,但现场说法不一——深夜到达的话,请做好排普通队伍的准备。
  • 登记费用在官方页面上没有记载(二手资料称免费)。旺季时登记队伍本身可能很长(2026-03报道: 有等候1~2小时的案例)。

② 出境自动通关——入境时录过指纹·人脸就不用登记

入境时以任何方式提供过指纹·人脸的17岁以上短期访客,出境时无需事先登记即可使用自动通关通道(法务部)。中国大陆·美国护照只要入境时在普通检查中录过指纹·人脸,也属于这一类。

  • 使用自动通关通道: 绿色箭头闸机 → 将护照照片页放在读取器上(2~3秒) → 门打开 → 指纹 → 摄像头
  • 如果想在出境一侧单独登记: 仁川 (Incheon / 인천) T1 3层H柜台对面、T2 2层法务部出入境服务中心,两处均为07:00~18:00全年无休,仅限出境旅客(仁川国际机场公社)
  • 出境自动通关在仁川 (Incheon / 인천)·金浦 (Gimpo / 김포)·金海 (Gimhae / 김해)·济州 (Jeju / 제주)·大邱 (Daegu / 대구)·清州 (Cheongju / 청주) 等主要机场和港口运营(法务部)

③ Smart Pass——刷脸通过出境区和登机口

Smart Pass是独立于法务部自动通关的仁川国际机场公社服务。提前登记护照·人脸·登机牌,就能通过出境区专用通道和部分登机口的人脸认证。

  • 仅限出境,入境不能用。仅限仁川 (Incheon / 인천) T1·T2
  • 法务部的出境检查要另外办理。"不带护照、只刷脸就能出境"的说法是错的——请带好实体护照·登机牌
  • 7岁以上(未满14岁需法定监护人同意),人脸信息有效期5年,换了新护照需要重新登记
  • 登记: Smart Pass App·机场自助机·合作银行/支付App
  • 登机口人脸认证仅限参与的航空公司——T1: 济州航空 (Jeju Air / 제주항공)·Air Premia (Air Premia / 에어프레미아)·易斯达航空 (Eastar Jet / 이스타항공)·Trinity (Trinity / 트리니티)·国泰航空 (Cathay Pacific / 캐세이퍼시픽)·长荣航空 (EVA Air / 에바항공) / T2: 大韩航空 (Korean Air / 대한항공)·韩亚航空 (Asiana / 아시아나)·真航空 (Jin Air / 진에어)·首尔航空 (Air Seoul / 에어서울)·釜山航空 (Air Busan / 에어부산)。出境区专用通道与航空公司无关

⚠ 外国人能否使用,官方页面没有明确说明。 引用公社发布内容的2023年报道写的是"7岁以上本国人·外国人",2026-06报道写的是"韩国国民",说法不一。如果登记界面不支持外国护照,直接走普通出境区即可。咨询: 仁川机场客服中心 1577-2600。

⚠ 实际会踩的5个坑

1. 把入境SES和出境SES当成同一个东西 —— 登记地点·时间·对象都不同。

2. 带孩子一起排自动通关队 —— 孩子多半要走普通通道。

3. 晚上去找出境一侧的登记中心 —— 07~18时,仅限出境旅客。

4. 以为有了Smart Pass就不需要护照 —— 出境检查要另外办,护照·登机牌必带。

5. 不属于42个国家·地区却去排自动通关队 —— 美国·中国大陆护照入境时请做好走普通通道的准备(出境自动通关可以使用)。

⚙ FAQ 3

1. 我是日本护照,第一次来,可以直接用自动通关吗? —— 首次入境时在登记队伍录入指纹·人脸,当天起就能使用自动通关通道。

2. 和K-ETA·e-Arrival有关系吗? —— 是不同的制度。入境文件请看#1289 e-Arrival·#248 签证·K-ETA篇。

3. 我从金浦 (Gimpo / 김포)·金海 (Gimhae / 김해)入境。 —— 入境自动通关的外国人登记在仁川 (Incheon / 인천)·济州 (Jeju / 제주) 到达厅运营(2026-06法务部资料)。出境自动通关在金浦 (Gimpo / 김포)·金海 (Gimhae / 김해) 也可以使用。在仁川 (Incheon / 인천)·济州 (Jeju / 제주) 登记后,从金浦 (Gimpo / 김포)·金海 (Gimhae / 김해) 等地方机场入境时也能再次使用自动通关闸机(法务部新闻稿: 地方机场再使用率66.6%)。
