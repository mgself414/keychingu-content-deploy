韩国24小时城市文化 — 为什么首尔凌晨3点还醒着？

> 24小时便利店 (Pyeonuijeom / 편의점)·猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스)·汗蒸幕 (Jjimjilbang / 찜질방)·凌晨配送 (Saebyeokbaesong / 새벽배송)·夜宵 (Yasik / 야식) — 为外国人解读韩国“不眠之城”文化。不是“夜里有很多玩乐去处”，而是“为什么整座城市被设计成24小时不停运转、能实现什么、以及代价是什么”。

凌晨3点。在世界上大多数大城市，这是街道空荡、店铺拉下卷帘门的时刻。但首尔 (Seoul / 서울)不同。巷子尽头的便利店 (Pyeonuijeom / 편의점)招牌亮着灯，汤饭 (Gukbap / 국밥)店里热气腾腾，24小时咖啡馆 (Kape / 카페)里有学生在备考，网吧 (PC bang / PC방)里有人在打游戏，汗蒸幕 (Jjimjilbang / 찜질방)里有错过末班车的上班族正在入睡。在公交停运的街道上，猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스) (深夜巴士)在奔驰，昨夜用手机订购的矿泉水和牛奶，在你睡醒的凌晨已送到门口。

外国人通常把这幅景象理解为“首尔夜生活很华丽 (nightlife)”。但这只解释了一半。真正的核心不是华丽的夜店或酒吧，而是城市的整套生活功能——吃、行、休息、购买、收货——被整体设计成24小时不停运转。不是一家便利店开到很晚，而是餐饮·交通·休息·物流相互咬合，构成了“不眠之城”这一个完整系统。本文不是“晚上去哪里玩”(→ 场所指南)，而是从外国人的视角，均衡地解读韩国城市为何变得如此不眠，以及这个系统造就的光与影。这是韩国文化解读系列第40篇。

⚠️ 外国人常有的3个误解

1. “24小时城市 = 夜生活 (夜店·酒)很华丽” ❌ — 华丽的夜生活只是一部分，24小时城市的本质是生活基础设施。核心不是夜店，而是便利店 (Pyeonuijeom / 편의점)·汤饭 (Gukbap / 국밥)店·深夜巴士·汗蒸幕 (Jjimjilbang / 찜질방)这些“平凡的生活功能”24小时运转。即使不喝酒，凌晨的首尔 (Seoul / 서울)也足够鲜活。

2. “熬夜到凌晨是因为韩国人爱玩” ❌ — 享乐的一面确实有，但其根源是漫长的劳动时间·加班·轮班工作。结束得晚的工作、学到很晚的备考·求职，以及24小时运转的产业，催生了“深夜需求”，基础设施也随之发展。更多是从必要而非便利开始的。

3. “凌晨独自外出不危险吗” ❌ (大体上) — 韩国，尤其是首尔 (Seoul / 서울)，被公认为世界上治安较好的地方之一。高密度的闭路电视 (CCTV)和24小时亮灯的便利店·深夜店铺，实际上扮演着“街道之眼”的角色。但与任何地方一样，烂醉·人迹罕至处·随身物品管理等基本注意仍是必要的 (→ #1167 安全)。

① “24小时城市”是什么 — 永不停歇的生活基础设施

24小时城市 (不眠之城)并不仅仅是“开到很晚的店铺很多的城市”。核心在于城市的基本生活功能即使在深夜也连续运转。

  • 吃: 即使过了午夜，找一顿热饭也不难。甚至有外媒形容说，“在首尔 (Seoul / 서울)，午夜到凌晨5点之间，几乎不存在难以找到一顿热饭的时段”(媒体表达 — 实际体感因地区·星期而异)。
  • 行: 即使公交·地铁停运，也能靠深夜巴士·深夜出租车在市内移动。
  • 休息: 即使错过末班车，也能在汗蒸幕 (Jjimjilbang / 찜질방)·网吧 (PC bang / PC방)·24小时咖啡馆 (Kape / 카페)撑到早上。
  • 买·收: 24小时便利店和凌晨配送 (Saebyeokbaesong / 새벽배송)填补“夜里所需”。

韩国式24小时城市的特点在于，这些功能是相互连接而非各自独立的。工作或玩到很晚的人 → 在深夜解决一餐 → 乘深夜巴士移动 → 在汗蒸幕 (Jjimjilbang / 찜질방)睡觉 → 第二天凌晨收到配送物品，这是一条不中断的完整流程。

> 参考: 最强的地方是首尔 (Seoul / 서울)，但釜山 (Busan / 부산)·大邱 (Daegu / 대구)等大城市也共享24小时便利店·深夜餐厅·汗蒸幕 (Jjimjilbang / 찜질방)基础设施。“24小时城市”既是首尔 (Seoul / 서울)的象征，也是韩国大城市整体的特征。

② 深夜饮食·店铺 — 夜宵 (Yasik / 야식)之国

韩国甚至有夜宵 (Yasik / 야식)这个专门的词，可见夜里进食的文化已深深扎根于日常。晚上10点以后的一餐在社会上是自然的。

  • 24小时便利店: GS25·CU·7-Eleven等主要便利店几乎每个街区都有，相当一部分以24小时营业为基本 (2000年代后期以后标准化)。从即食食品·三角紫菜包饭 (Samgak Gimbap / 삼각김밥)·拉面 (Ramyeon / 라면)到酒类·快递·取现，是“深夜的万能据点”。(部分门店深夜缩短营业 — 建议确认。)
  • 汤饭 (Gukbap / 국밥)·醒酒汤 (Haejangguk / 해장국)店: 24小时汤饭 (Gukbap / 국밥)·醒酒汤 (Haejangguk / 해장국)·先农汤 (Seolleongtang / 설렁탕)店，是加班·饮酒后的扎实一餐，也是解酒的象征。热气腾腾的24小时餐厅是韩国深夜风景的代表场景。
  • 24小时紫菜包饭 (Gimbap / 김밥)·小吃 (Bunsik / 분식): 凌晨也供应紫菜包饭 (Gimbap / 김밥)·拉面 (Ramyeon / 라면)·辣炒年糕 (Tteokbokki / 떡볶이)的小吃 (Bunsik / 분식)店。
  • 路边摊 (Pojangmacha / 포장마차): 在街头帐篷里卖鱼糕 (Eomuk / 어묵)·串·简单下酒菜的摊位。在钟路 (Jongno / 종로)·乙支路 (Euljiro / 을지로)·东大门 (Dongdaemun / 동대문)·弘大 (Hongdae / 홍대)等地开到很晚。
  • 东大门 (Dongdaemun / 동대문)夜市: 东大门 (Dongdaemun / 동대문)一带以“不眠之市”闻名。服装批发商城在夜间开门，运转到凌晨，周边餐厅·便利店·咖啡馆 (Kape / 카페)一同醒着 (各门店营业时间不一)。

> 外国人提示: 即使不去找酒馆，凌晨仅凭24小时便利店 + 汤饭 (Gukbap / 국밥)店的组合，就足以体验“首尔之夜”。价格负担也不大。

③ 深夜交通 — 猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스)与深夜出租车

24小时城市要运转，就必须有“夜里移动的手段”。韩国为此给出了公共基础设施的答案。

  • 猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스) (深夜巴士): 首尔市 (Seoul / 서울)运营的深夜专用市内公交。在普通公交·地铁停运的晚上11点左右到次日凌晨6点左右运行，多条线路覆盖首尔 (Seoul / 서울)主要轴线 (线路数·时间随首尔市 (Seoul / 서울)政策变动 — 建议官方确认)。基本票价据称比普通市内公交略高，交通卡换乘折扣也适用 (费用变动 — 建议确认)。它作为用大数据 (如深夜通话量等)设计线路的案例，在海外也受到关注。
  • 深夜出租车加成: 出租车在夜间时段 (大体为晚上10点～凌晨4点)会有深夜加成。部分时段加成率会进一步上升 (费率·时间随首尔市 (Seoul / 서울)公告变动 — 建议确认)。也就是说，凌晨移动是可行的，但要知道比白天费用更高。
  • 地铁末班车: 首尔 (Seoul / 서울)地铁通常运行到午夜前后 (因线路·车站而异)，根据时期也曾讨论·实施过末班车延长政策。末班车时间因线路而异，用App确认更稳妥。

> 外国人提示: 凌晨返回住处时，按以下顺序: ① 确认末班车时间 → ② 错过的话确认猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스)线路 → ③ 仍不合适就 (考虑加成)打出租车。若完全错过末班车，也有在汗蒸幕 (Jjimjilbang / 찜질방)待到早上的选项 (见下方④)。

④ 24小时休息 — 汗蒸幕 (Jjimjilbang / 찜질방)·网吧 (PC bang / PC방)·投币练歌房 (Coin Noraebang / 코인노래방)

韩国深夜基础设施的独特之处在于，“度过夜晚的空间”本身已经产业化。即使错过末班车，即使无处可去，也有可以停留的地方。

  • 汗蒸幕 (Jjimjilbang / 찜질방) (24小时): 大型沐浴·桑拿设施，大多24小时运营，可以在里面睡觉。许多还配有餐厅·小卖部·网吧 (PC bang / PC방)等便利设施。对错过末班车的人、需要廉价过夜的旅行者来说，实际上成了“深夜歇脚处”(→ #1146 汗蒸幕·沐浴文化中详述)。
  • 网吧 (PC bang / PC방) (24小时): 按时间使用游戏·办公电脑的空间。多数24小时运营。不仅能游戏，还备有拉面 (Ramyeon / 라면)·零食，是“适合通宵的空间”(→ #1156 网吧·游戏文化)。
  • 投币练歌房 (Coin Noraebang / 코인노래방) (kono / 코노): 用硬币·小额短时唱歌的无人型练歌房。开到很晚的地方很多，成了不喝酒也能享受夜晚的MZ世代游乐空间。
  • 24小时咖啡馆 (Kape / 카페): 24小时咖啡馆是学习·办公·交谈的深夜据点。(不过受疫情·人力成本影响，减少24小时运营的门店很多，比以前更难找了 — 建议确认。)

> 青少年注意: 网吧 (PC bang / PC방)·汗蒸幕 (Jjimjilbang / 찜질방)·练歌房 (Noraebang / 노래방)等，有些情况下限制未满19岁青少年在深夜 (晚上10点以后)出入·使用。家庭旅行时请参考。

⑤ 为何变得不眠 — 压缩增长·加班·快点快点 (Ppalli-ppalli / 빨리빨리)

韩国城市变得24小时清醒，有着明确的历史·社会背景。绝非单纯“因为韩国人爱夜晚”。

  • 压缩增长与轮班工作: 韩国从战后废墟中，仅用两代人就跻身发达国家 (汉江奇迹 (Hangang-ui Gijeok / 한강의 기적))。在这个过程中，工厂·产业24小时运转，为夜间工作的人们服务的深夜餐厅·交通·店铺需求很早就产生了。
  • 漫长劳动时间与加班: 韩国在经合组织 (OECD)中属于劳动时间较长的国家。2024年韩国年度劳动时间约为1,865小时，长于经合组织平均 (约1,736小时) (统计来源不同数值有差异 — 建议确认)。结束得晚的工作和加班·聚餐 (Hoesik / 회식)文化，造就了“深夜生活”。
  • 备考·求职之夜: 学生·求职者学到深夜的文化，扩大了24小时咖啡馆 (Kape / 카페)·自习室 (Dokseosil / 독서실)·便利店的需求。
  • 快点快点 (Ppalli-ppalli / 빨리빨리)·高密度城市: “快即美德”的快点快点 (Ppalli-ppalli / 빨리빨리)文化 (→ #1143)，与公寓·商铺密集堆叠的高密度城市结构相遇，使“深夜也能即时填补的基础设施”成为可能。因为需求必须在狭小半径内密集，24小时营业·深夜配送才能划算。

也就是说，24小时城市既是便利的结果，也是一个长时间劳动·移动到深夜的社会的镜子。

⑥ ★ 光与影 — 便利的背面，睡眠不足与过劳

24小时城市对外国人无疑很有魅力。凌晨也能吃饭·移动·休息，还有城市鲜活的动感。但这种便利建立在某些人的睡眠与劳动之上。需要均衡地看待。

光明的一面

  • 便利·安全网: 一张能解决夜里突然所需 (药·生活必需品·一餐·移动)的密集安全网。
  • 动感·文化: 24小时鲜活的城市所造就的活力，以及在其之上生长出的夜宵 (Yasik / 야식)·汗蒸幕 (Jjimjilbang / 찜질방)·深夜咖啡馆 (Kape / 카페)等独特生活文化。
  • 治安据点: 彻夜亮灯的店铺实际上支撑着街道的安全。

阴暗的一面 ★

  • 睡眠不足: 据报告，韩国人的平均睡眠时间约为6小时58分，比经合组织平均 (约8小时22分)短约1小时30分，处于最末位(多项调查 — 数值因来源·年份而异，建议确认)。“不眠之城”的背面，是“睡不够的人们”。
  • 过劳与倦怠: 漫长的劳动时间导致慢性疲劳·倦怠 (Beonaut / 번아웃)，严重时甚至到了“过劳死 (Gwarosa / 과로사)”一词在社会上通用的程度。24小时运转的产业和轮班·深夜劳动，是以某些人的健康为代价的。
  • 深夜劳动的阴影: 要有撑起夜晚的劳动——24小时便利店夜间值班者、深夜外卖骑手 (Raideo / 라이더)、深夜运输劳动者等——城市才能保持清醒。便利的背后，是他们的夜间劳动。
  • 反作用与变化: 出于对这种负担的社会反思，工作生活平衡 (Wollaebael / 워라밸)的讨论日益升温，缩短劳动时间的政策动向 (如每周4.5天工作制的引入讨论·施行等)持续推进 (政策细节变动 — 建议确认)。这是想把“不眠之城”转变为“可以稍微睡一会儿的城市”的动向。

> 核心: 24小时城市既难以简单断定为“因为便利所以好”，也难以断定为“因为是过劳社会所以坏”。理解便利·动感与睡眠不足·过劳是同一枚硬币的两面，就能更立体地看待韩国城市。

⑦ 给外国人的深夜利用指南

> 营业时间·费用·线路因门店·时期而异且经常变动 — 建议在现场·官方渠道确认。

  • 错过末班车时: 别慌。① 确认猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스)线路 (App/首尔市 (Seoul / 서울)) → ② 不合适就深夜出租车 (考虑加成) → ③ 仍不明确就在汗蒸幕 (Jjimjilbang / 찜질방)待到早上(廉价·安全的应急住所)。在时差还没倒过来的第一晚尤其有用的选项。
  • 凌晨饿了时: 最简单的是24小时便利店(即食食品·拉面 (Ramyeon / 라면))。想要正经的一餐就去附近的24小时汤饭 (Gukbap / 국밥)·醒酒汤 (Haejangguk / 해장국)店。两者价格负担都不大，即使没有英文菜单，也能用照片·指点来下单。
  • 通宵或打发时间时: 24小时咖啡馆 (Kape / 카페) (学习·办公)、网吧 (PC bang / PC방) (游戏·上网)、投币练歌房 (Coin Noraebang / 코인노래방) (短歌)。但24小时咖啡馆 (Kape / 카페)比以前减少，提前确认更稳妥。
  • 安全: 首尔 (Seoul / 서울)市中心凌晨也相对安全，但烂醉·人迹罕至的小巷·随身物品管理等基本注意是必须的 (→ #1167 安全·治安文化)。
  • 视觉: 想用一个场景感受“不眠之城”，可以看东大门 (Dongdaemun / 동대문)夜市的凌晨，或亮灯的巷子便利店与热气腾腾的汤饭 (Gukbap / 국밥)店一起看。

❓ 外国人常见问题 (FAQ)

  • 凌晨3点独自闲逛安全吗？ — 首尔 (Seoul / 서울)市中心被认为相对安全，闭路电视 (CCTV)和24小时店铺扮演着“街道之眼”的角色。但与任何地方一样，烂醉·偏僻处·随身物品要注意 (→ #1167)。
  • 错过末班车但酒店很远，怎么办？ — 请按猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스) → 深夜出租车 (加成) → 汗蒸幕 (Jjimjilbang / 찜질방)的顺序考虑。汗蒸幕 (Jjimjilbang / 찜질방)24小时运营还能睡觉，作为应急住所很受欢迎 (→ #1146)。
  • 便利店真的都是24小时吗？ — 相当一部分是24小时，但并非全部。部分门店深夜缩短营业，所以凌晨的话，在地图App上确认正在营业的门店更稳妥。
  • 深夜移动贵吗？ — 出租车在夜间时段 (大体为晚上10点～凌晨4点)有加成，比白天贵。猫头鹰巴士 (Olppaemi Beoseu / 올빼미버스)是与普通公交相当的低廉票价，性价比好 (费用变动 — 建议确认)。
  • 韩国人真的那么不睡吗？ — 平均睡眠时间被报告短到处于经合组织最末位。“不眠之城”的便利背后，有睡眠不足·过劳的阴影，最近也有不少想减少它的社会动向。
