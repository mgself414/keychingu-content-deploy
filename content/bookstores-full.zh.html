⚠ 外国人常犯的3个错误

1. “书店 = 只有教保文库 (Kyobo Book Centre / 교보문고)”: 韩国书店的4大支柱 — 大型 (教保 (Kyobo / 교보)·永丰 (Youngpoong / 영풍)·YES24·阿拉丁 (Aladdin / 알라딘)) + 独立书店 (Your Mind·寂静书社 (Goyoseosa / 고요서사)·小说家书店 (Soseollist / 소설리스트)) + MZ一代 (MZ Yīdài)·主题 (星空图书馆 (Starfield Library / 별마당 도서관)·Arc.N.Book·1982年生的金敏京) + 郊区·旅游 (北村 (Bukchon / 북촌)·仁寺洞 (Insadong / 인사동))。四种类型都值得探索。

2. “星空图书馆 (Starfield Library / 별마당 도서관) = 普通图书馆”: 星空图书馆 (Starfield Library / 별마당 도서관) 是 2017年在COEX (COEX / 코엑스) 内·13米高书架墙 = 韩国MZ一代 (MZ Yīdài) Instagram·外国人拍照打卡首选。免费入场 + 自由阅览书籍。

3. “独立书店 = 太小找不到”: Your Mind (延禧 (Yeonhui / 연희))·寂静书社 (Goyoseosa / 고요서사) (圣水 (Seongsu / 성수))·小说家书店 (Soseollist / 소설리스트) (梨泰院 (Itaewon / 이태원)) = 各区域的招牌店铺 + 区域指南交叉参考。
