本地人推荐 ① 釜山·蔚山·庆南 — 韩国观众在评论里点名的15家饭馆，只用Naver核实过

副标题：釜山的汤饭·milmyeon·生鱼片(#1320)、KTX两天三夜(#1114)、咖啡厅系列(#1321·#1324·#1381)都没有涉及的一条线索——从韩国观众在YouTube评论区推荐的地方饭馆整理表中，只挑出釜山、蔚山、庆南15家，用Naver本地搜索核实了是否存在、地址和行业类别，不做评价。釜山7家→蔚山1家→昌原·晋州·梁山·昌宁·居昌7家，每座城市附车站/客运站交通方式和一条外国游客提示。

🎯 为什么"评论区推荐"是标准

KeyChinGu的地方美食篇至今靠两种信号做成——外国评论率先留下的地方(#1381)，以及一座城市的代表菜(#1320)。这个专栏是第三种信号。一个韩国YouTube频道上传的"全国美食"视频下，观众在评论区写下了自己家乡的饭馆，其中按地区整理得最系统的一份评论汇总表，收录了217家。这是韩国人推荐给韩国人的名单，所以几乎没有外国评论，反而有不少Instagram上找不到的老字号、乡镇小馆。

KeyChinGu只做了一件事——用Naver本地搜索确认店名·地址·行业类别是否真实存在(2026-09-17)。217家里有192家得到确认，釜山·蔚山·庆南是16家里的15家。没能确认的1家被剔除。没有到店评价、排名、星级。营业时间和价格这一篇也没有——去的当天查Naver Place才是答案。

① 釜山 — 7家，地铁和东海线可达

釜山的三大代表菜——猪肉汤饭 (dwaeji gukbap / 돼지국밥)、milmyeon、生鱼片——连点法都在#1320里写清楚了。这七家是韩国观众在那份名单之外另写的家乡饭馆——两家汤饭，另外四家是炖鸡汤、石锅拌饭、饺子、粥这类很少上旅游榜单的菜。

  • 莲山炖鸡汤 (Yeonsan Dakdoritang / 연산닭도리탕) · 釜山莲堤区果亭路236号 (236 Gwajeong-ro, Yeonje-gu / 부산 연제구 과정로 236) · 韩餐 · 炖鸡汤 · 莲山站，1·3号线，步行可达

炖鸡汤(dakbokkeumtang / 닭볶음탕)，也叫dakdoritang(닭도리탕)，是把一整只鸡和土豆·洋葱一起用辣汤炖煮的锅物。按整只鸡计量，2–3人份起。

  • 友情石锅拌饭 (Ujeong Dolsot Bibimbap / 우정돌솥비빔밥) · 釜山镇区东川路85巷3号 (3 Dongcheon-ro 85beon-gil, Busanjin-gu / 부산진구 동천로85번길 3) · 韩餐 · 拌饭 (bibimbap / 비빔밥) · 西面站，1·2号线，往东川路方向步行可达

石锅拌饭 (dolsot bibimbap / 돌솥비빔밥) 是用滚烫石锅盛饭的拌饭——锅底的锅巴才是重点。店就在西面正中间，是十五家里最容易塞进#1114动线的一家。

  • 宜宁食堂 (Uiryeong Sikdang / 의령식당) · 海云台区牛洞1路50巷15号 (15 Udong 1-ro 50beon-gil, Haeundae-gu / 해운대구 우동1로50번길 15) · 韩餐 · 汤饭 · 海云台站，2号线，4号出口步行3–4分钟

一家藏在海云台站后方旧铁道边巷子里的汤饭店，位于海里丹路 (Haeridan-gil / 해리단길)。适合安排在去海云台海滩前后的一餐。

  • 陕川汤饭 (Hapcheon Gukbap / 합천국밥) · 南区龙湖路235号 (235 Yongho-ro, Nam-gu / 남구 용호로 235) · 韩餐 · 汤饭 · 从支架谷站，2号线，乘24或27路公交，在庆星大·釜庆大站 (Gyeongseongdae-Bukyeongdae Station / 경성대·부경대역) 转乘也可以

龙湖洞是地铁不能直达的住宅区。安排在去二妓台、五六岛的那天顺路最自然。

  • 福星饺子 (Bokseong Mandu / 복성만두) · 影岛区大平路34巷5-8号 (5-8 Daepyeong-ro 34beon-gil, Yeongdo-gu / 영도구 대평로34번길 5-8) · 小吃 · 饺子 · 影岛没有地铁——从南浦站，1号线，转乘往影岛的公交

去影岛咖啡(#1321)或白瀑村 (Huinnyeoul Village / 흰여울마을) 路上的一家饺子店。饺子适合打包带走，也当移动途中的零食。

  • 松园食堂 (Songwon Sikdang / 송원식당) · 西区城山路23号 (23 Seongsan-gil, Seo-gu / 서구 성산길 23) · 韩餐 · 土城站，1号线，6号出口→在釜山大医院站转乘村庄巴士(沙下1-1·西区2·西区2-2)

紧邻甘川文化村 (Gamcheon Culture Village / 감천문화마을) 住宅区里的一家韩餐馆。和游览村子坐同一趟公交。

  • 尽头小馆 (Kkeutjip / 끝집) Gijang Kkeutjip Ilgwang分店 · 机张郡日光邑日光路293号 (293 Ilgwang-ro, Ilgwang-eup, Gijang-gun / 기장군 일광읍 일광로 293) · 韩餐 · 粥 · 日光站，东海线通勤电铁，步行可达

粥类专门店。日光海水浴场 (Ilgwang Beach / 일광해수욕장) 从车站走路就能到，可以和海滩安排在同一个半天。

外国游客提示 — 在釜山的汤饭店坐下后，虾酱 (saeujeot / 새우젓)、剁碎调料、韭菜 (jeongguji / 정구지) 会分开端上来。自己加进汤里调味才是本地吃法，"不要辣"只要把剁碎调料去掉就行。点餐用语、milmyeon、生鱼片详见#1320。

② 蔚山 — 1家，太和江边

  • 竹田谷猪肉汤饭 (Daebatgol Dwaeji Gukbap / 대밭골돼지국밥) · 蔚山中区太和江国家庭园路229-2号 (229-2 Taehwagang-gukgajeongwon-gil, Jung-gu / 울산 중구 태화강국가정원길 229-2) · 韩餐 · 汤饭 · 从太和江站，东海线，打车约15分钟(公交约40分钟，班次稀疏)——从KTX蔚山站坐5001路机场大巴约49分钟，要远得多

紧邻太和江国家庭园 (Taehwagang National Garden / 태화강국가정원)，也叫十里竹林 (Simni Bamboo Grove / 십리대숲)。从釜山出发的人，乘东海线电铁到太和江站比坐KTX离庭园更近；从首尔坐KTX来的人要先知道，蔚山站 (Ulsan Station / 울산역) 在市区西侧外围。

外国游客提示 — 猪肉汤饭是釜山、蔚山共有的早餐菜。很多店开门很早，相应地，食材卖完了也会提前打烊。时间以Naver Place为准。

③ 庆南 — 7家，昌原·晋州·梁山·昌宁·居昌

庆南五座城市分成KTX/SRT能到的(昌原马山·昌原中央·晋州)和只能坐公交去的(昌宁梨房·居昌)。釜山2号线的终点站是梁山，这一点在这份名单里也用得上。

  • 平壤冷面 (Pyeongyang Naengmyeon / 평양냉면) · 昌原市马山会原区阳德旧2路73号 (73 Yangdeokyet 2-gil, Masanhoewon-gu / 창원시 마산회원구 양덕옛2길 73) · 韩餐 · 冷面 · 马山站一带(KTX全车停靠)——从车站坐公交或打车：以Naver地图为准

店名就是菜名。平壤式冷面的特点是汤底清淡，要用桌上的醋、芥末自己调味。

  • 田央庄 (Jeonangjang / 전앙장) · 昌原市马山合浦区3·15大道116号 (116 3·15-daero, Masanhappo-gu / 창원시 마산합포구 3·15대로 116) · 中餐 · 中餐厅 · 马山老城区——从马山站转乘公交(路线以Naver地图为准)

马山原老城区里的一家中餐厅。韩式中餐的基本款是炸酱面 (jjajangmyeon / 짜장면)、什锦炒码面 (jjamppong / 짬뽕)、糖醋肉 (tangsuyuk / 탕수육)，都可以单点一人份。

  • 富他屋 (Butaok / 부타옥) · 昌原市城山区龙池路225号 (225 Yongji-ro, Seongsan-gu / 창원시 성산구 용지로 225) · 韩餐 · 从昌原中央站，KTX，转乘公交

位于昌原新城区(上南洞 / 상남동、龙池路)一带的韩餐馆。昌原中央站是KTX、ITX-新村号、无穷花号都停靠的车站。

  • 第一食堂 (Jeil Sikdang / 제일식당) · 晋州市中央市场路37-8号 (37-8 Jungangsijang-gil, Jinju-si / 진주시 중앙시장길 37-8) · 韩餐 · 从晋州站，KTX/SRT，市内公交或打车(路线以Naver地图为准)

一家开在晋州中央市场 (Jinju Central Market / 진주중앙시장) 里的食堂。晋州素有拌饭与冷面之都的名声，市场里的食堂也完全沿用这套逻辑。

  • 海阳山汤饭 (Haeyangsan Gukbap / 해양산국밥) · 梁山市三成6路10号 (10 Samseong 6-gil, Yangsan-si / 양산시 삼성6길 10) · 韩餐 · 汤饭 · 梁山站一带，釜山2号线终点——从车站步行或坐公交：以Naver地图为准

一家坐釜山地铁就能到的庆南汤饭店。2号线坐到底就是梁山。

  • 梨房食堂 (Ibang Sikdang / 이방식당) 牛皮下肉汤饭 · 昌宁郡梨房面玉野路1号 (1 Ogya-gil, Ibang-myeon / 창녕군 이방면 옥야길 1) · 韩餐 · 汤饭 · 从昌宁长途汽车站(昌宁邑 / 창녕읍)转乘乡镇巴士或打车——是否直达梨房面：待确认

牛皮下肉 (sugure / 수구레) 指牛皮内侧的那层肉。牛皮下肉汤饭是昌宁梨房集市 (Ibang market / 이방장) 的乡土菜，在这份名单里是"最本地"的一个名字。和牛浦沼泽 (Upo Wetland / 우포늪) 同一个方向。

  • 春川泉土炭火鸡排 (Chuncheon Saemto Chamsut Dakgalbi / 춘천샘토참숯닭갈비) · 居昌郡居昌邑公需坪4路17号 (17 Gongsudeul 4-gil, Geochang-eup / 거창군 거창읍 공수들4길 17) · 韩餐 · 鸡排 · 居昌长途汽车站(主要靠大邱西部客运站 / 대구서부정류장 方向的班线)，步行可达

居昌属于大邱生活圈，从大邱发车的班次比从釜山的多。鸡排是把鸡肉、卷心菜、年糕放在铁板上炒的菜，2人份起点。

外国游客提示 — 邑、面一级的餐馆和市场里的摊位能刷卡的越来越多，但现金、转账依然是这个文化更习惯的方式。需要用现金的情况详见#1301。汤饭、冷面可以点一人份，炖鸡汤、鸡排则以2人份起点为基本单位。

🚄 如何融入地方路线

  • 融入釜山两晚三天行程(#1114) — 西面(友情石锅拌饭)、海里丹路(宜宁食堂)、机张日光(尽头小馆)都在既有动线的车站旁，直接可达。影岛(福星饺子)、甘川(松园食堂)分别要在南浦站、土城站下车后转公交，按半天为单位安排。
  • 釜山 → 蔚山 — 坐东海线电铁到太和江站。太和江国家庭园和竹田谷猪肉汤饭可以一次搞定。
  • 首尔 → 晋州、昌原 — 坐KTX/SRT到晋州站，坐KTX到马山站、昌原中央站。晋州中央市场(第一食堂)还要从晋州站再进市区一段。
  • 黄金路线(#1372–1374)的变体 — 从庆州南下到釜山、再拿一天去庆南的人，现实一点的做法是马山、晋州二选一，别贪多。
  • 只能坐公交去的地方 — 昌宁梨房、居昌。班线主要靠大邱西部客运站，和大邱·庆北篇(#1383)搭配安排更合理。

⚠ 3个常见误区

1. 从KTX蔚山站直接去太和江庭园 — 蔚山站在市区西侧外围，坐机场大巴约49分钟。从釜山方向来，东海线的太和江站才是正确答案。

2. 晚上才去找汤饭店 — 汤饭店以早、午餐为主，有些店食材用完就提前打烊。时间请在Naver Place当天确认。

3. 一个人点炖鸡汤、鸡排 — 这两样按整只鸡、2人份起点计量。一个人的话，汤饭、冷面、饺子、粥更合适。

⚙ 常见问题3则

1. 这份名单是谁挑的？ — 是一张由韩国YouTube观众在评论区写下的地方饭馆整理而成的表。KeyChinGu只确认了是否存在、地址和行业类别，没有排名。

2. 不会韩语也能点餐吗？ — 汤饭、冷面、饺子指着菜单点就行。一句"这个给我一份"(이거 하나 주세요)就够用，详细点餐说法见#1320。

3. 能预约吗？ — 这类饭馆大多不接受预约，靠排队。团体的话需要打电话，号码在Naver Place上能找到。
