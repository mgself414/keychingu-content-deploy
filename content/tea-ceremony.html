⚠ 외국인 자주 실수 5가지

1. "한국 차 = 녹차만": 한국 차 = 녹차 (보성·하동·제주) + 발효차 + 황차 + 홍차 + 꽃차 + 약초차 다양 + 외국인 매니아 deep dive.

2. "오설록 = 카페만": 오설록 = 제주 티 뮤지엄 (2001 아모레퍼시픽·한국 #1 차 박물관) + 삼청·강남·이태원 모던 티하우스 + 외국인 매니아 1번지.

3. "다도 체험 = 한국인만": 인사동·북촌 다도 체험 = 외국인 영어 OK + 한복 결합 + Klook·Airbnb 외국인 매니아 1순위.

4. "수희찻집 = 카페": 수희찻집 (인사동) = 1960s 한국 정통 다실 1번지 + 외국인 매니아 + 전통 차·한과 풀세트.

5. "사찰 다도 = 따로": 사찰 다도 = #357 사찰음식 + 다도 + 명상 풀세트 (진관사·봉은사·길상사) + 외국인 wellness 1번지.
