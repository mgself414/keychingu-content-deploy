🎯 为什么选择韩国食品矩阵？

外国人韩国零食的痛点=“街头小吃种类太多”。小吃=性价比+清淡+街头小吃+Ttteongi+外国人Instagram排名第一的帖子。同样的炒年糕在新堂洞、明洞、釜山的情况不同，紫菜包饭也不同，有药紫菜包饭、小紫菜包饭、金枪鱼紫菜包饭等。外国人 (a) 很难选择，因为菜单项太多； (b) 不知道如何调节辣度； (c) 因价格太便宜（1,500韩元至5,000韩元不等）而产生怀疑； （四）不知道怎么吃。本指南由8种矩阵+区域特征+外国人优先事项组成。

🍢 8种零食深度探究

🌶 辣年糕 — 外国人#1

  • 签名：新堂洞Mabokgrim（1953年发明即食炒年糕）/明洞炒年糕胡同
  • 类型：
  • 辣汤：最常见
  • 即食炒年糕（在餐桌上烹制）：新堂洞风格
  • Gungjung Tteokbokki（宫廷）：酱油调味，宫廷传统
  • 玫瑰炒年糕：MZ趋势（奶油+辣）
  • 口味等级：不辣→微辣→辣→极辣。 “请少辣” =“请少辣”
  • 价格: 3,500~6,000韩元 / 即时 = 30,000韩元~ 4人

🍙紫菜包饭 — 外国人介绍#1

  • 签名：广藏市场麻辣紫菜包饭（绰号“上瘾”）/天堂紫菜包饭（连锁#1）
  • 类型：
  • 金枪鱼紫菜包饭（金枪鱼）——外国人第一名（失败概率#1低）
  • 药紫菜包饭（麻辣烫，迷你）——广藏市场第一街
  • 小紫菜包饭（迷你）— 1bit 大小，适合儿童
  • Ponk cutlet（炸猪排）·芝士紫菜包饭（芝士） — MZ Trend
  • 外国人友善度：★★★★★（多种英文菜单、图片菜单、韩式寿司）
  • 价格: 3,000~5,000韩元

🩸 圣代

  • 签名：广藏市场圣代胡同 / 新林洞圣代城
  • 外国人入境障碍：圣代 = 血肠。不推荐第一次吃韩国菜，适合好奇的爱好者
  • 推荐配料：炒年糕汤、dadaegi、紫苏籽粉
  • 价格：4,000~7,000韩元

🍤 油炸 (Twigim) — 零食狂热

  • 种类：炸鱿鱼、炸虾、炸红薯、炸紫菜卷、炸饺子、炸青菜
  • 推荐搭配：浸入炒年糕汤中（最常见）
  • 价格: 1,000~3,000韩元/个
  • 外国人友好度：★★★★（类似于日本天妇罗）

🥟 曼杜

  • 招牌：明洞饺子（1966年——老字号刀削面+饺子店，深受外国人认可）/广藏市场饺子
  • 类型：
  • 肉饺子（肉类）：猪肉、牛肉
  • 泡菜饺子（泡菜）：辣
  • 粉丝：杂菜饺子
  • 水饺（水煮）·蒸饺（煎）
  • 外国人友好度：★★★★★（类似于中国点心和日本饺子）
  • 价格：4,000~7,000韩元

🍜 拉博基

  • 招牌：拉面+炒年糕+鱼饼+饺子组合。 MZ 狂热 No.1
  • 类型：辛拉面拉博基、三养拉博基、奶油玫瑰拉博基
  • 外国人友好度：★★★★（拉面意识）
  • 价格: 5,000~8,000韩元

🍢 鱼饼 (Eomuk) — 冬季狂热

  • 签名：釜山三津鱼饼（1953韩国#1）/街头鱼饼（串状）
  • 类型：
  • 串烧鱼饼 (1,000韩元/个): Street Mania
  • 釜山鱼饼（各种形状和口味）：釜山鱼饼1号
  • 鱼饼汤（乌冬面汤+鱼饼）：冷天#1
  • 外国人友好度：★★★★（类似于日本关东煮）
  • 价格: 1,000~2,000韩元/个

🌭 韩国热狗 — 老外vlog #1

  • 签名：明洞、弘大和江南热狗店集群
  • 类型：
  • 马苏里拉芝士热狗（芝士融化）：国外vlog第一名

⚠ 外国人常犯的5个错误

1. “零食=一切都是辣”：辣零食=只有炒年糕、拉布基和泡菜饺子。 紫菜包饭、饺子、热狗、油炸食品=不辣。

2. “价格太便宜=可疑”：零食价格3,000~7,000韩元=正常。韩国零食性价比★★★★★。

3. “圣代=普通香肠”：圣代=血肠。不推荐您第一次吃韩国餐。

4. “Drug Gimbap = Drugs in”：“Drugs” = 昵称（意思是“上瘾”）。 2021年，食品药品安全部会同相关部委联合“建议避免使用毒品词语”→替代符号（迷你紫菜包饭）。不过广藏市场的招牌是“Mayak紫菜包饭”，外国人最常搜索的关键词就是“Mayak紫菜包饭”。

5. “Sindang-dong Tteokbokki = 一家商店”：Sindang-dong = Tteokbokki Alley cluster（Mabokrim 和许多其他商店）。即食炒年糕的发源地。

⚠ 医疗/安全/饮食免责声明

小吃=很多街头/市场商店。卫生=直接检查货架周转和清洁度。儿童 = 推荐辣炒年糕和拉博基，推荐不辣的紫菜包饭、饺子和热狗。孕妇=小心咸虾、大酱和圣代（血粉）。过敏（海鲜、麸质、大豆、坚果）提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

饮食限制后备：

  • 清真·犹太：炒年糕、紫菜包饭、饺子、热狗=非清真（调味料、肉类）。 → 梨泰院一些清真小吃店。
  • 素食·纯素：紫菜包饭（金枪鱼除外）·芝士紫菜包饭 = 提供素食。 Tteokbokki = 不含鱼饼。 → [#799 素食·素食](799_Foreigner_Korean_Vegetarian_Vegan_Matrix_12_deep_dive.md).
  • 不含麸质：炒年糕调味料、拉博基、饺子 = 大量麸质。 油炸食品=面粉·海鲜 提前查询。
