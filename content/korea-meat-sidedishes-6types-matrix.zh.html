🎯 为什么选择韩国肉类配菜矩阵？

韩国肉类配菜对于外国人的痛点=“只有烧烤知道”。韩国肉类配菜= 韩国主菜#1 + 全球公认的烤肉·杂菜韩餐潮流。即使是同样的“韩式肉配菜”，也有排骨鸡（韩式主菜、周年庆）、杂菜（粉丝+蔬菜、正宗#1）、炒肉（辣肉、MZ潮流）、烤肉（全球K-food）、酱油炖菜（传统酱油炖菜）、炒菜（紫苏油、山菜、经典），每个都有不同的食谱和搭配。外国人不知道 (a) Galbijjim = 韩国与日本 (b) Japchae = 误认为面条 (c) 不知道 Jeyuk 与 Bulgogi 之间的区别 (d) Jangjorim = 类似于日本佃煮 (Tsukudani)。本指南以6种矩阵+韩餐主菜爱好者+外国人优先为主。

🍖 6 种深度潜水

🍖 Galbi-jjim (Galbi-jjim) — 韩国美食 #1

  • 签名：韩国传统主餐#1·纪念日·节日
  • 材料：牛肋骨+酱油+梨+蒜+洋葱+香菇+大枣、松子
  • 特点：炖5~8小时，香甜嫩滑，骨头完整
  • 外国人友好度：★★★★★（正统韩国料理）
  • 推荐店铺：韩国餐厅、酒店韩国餐厅、全州韩国料理、宫廷料理店
  • 季节：全年（节假日#1）
  • 与日本排骨的区别：韩国排骨 = 正宗炖肉 / 日本排骨 = 烧烤

🍜杂菜 — 外国人介绍#1

  • 招牌：正宗韩国料理#1·全球认可·韩国小菜
  • 材料：粉丝（红薯淀粉）+菠菜+胡萝卜+洋葱+牛肉+酱油+香油
  • 特点：甜、咸、咸、面条+蔬菜组合
  • 外国人友好度：★★★★★（全球/面条认可）
  • 类型：
  • 牛肉杂菜（正宗）
  • 海鲜杂菜（变体）
  • Gungjung Japchae（正宗酱油）
  • MZ 纯素杂菜（肉类
  • 推荐店铺：韩国餐厅、家常菜、MZ咖啡厅、盒饭
  • 季节：全年（假期#1）

🌶 Jeyuk-bokkeum — MZ #1

  • 签名：麻辣猪·上班族午餐#1·MZ潮流
  • 原料：猪肉（颈肉、前腿肉）+红辣椒酱+红辣椒粉+大蒜、洋葱
  • 特色：辣、甜、饭对#1
  • 外国人友善度：★★★★★（MZ，辣介绍）
  • 推荐店铺：家常菜、连锁店（专卖肉类）、MZ Cafe
  • 类型：
  • 正宗 Jeyuk Bokkeum
  • 酱油 Jeyuk（少辣）
  • Pepper Jeyuk（非常辣）
  • 季节：全年（午餐#1）

🥩 烤肉 — 全球 #1

  • 签名：全球K-food意识#1 + 对外国人的真实介绍
  • 材料：牛肉（薄片）+酱油+梨+蒜，姜，洋葱+麻油
  • 特点：甜、咸、嫩、烧烤
  • 外国人友好度：★★★★★（全球/甜蜜介绍）
  • 类型：
  • 首尔烤肉（正宗，带汤，加粉丝）
  • 光阳烤肉（全南烤肉，酱油底料）
  • Eonyang Bulgogi（蔚山，肉末，辣）
  • 宫中烤肉（正宗酱油）
  • 季节：全年（入门#1）

🟫 长久林

  • 招牌：正宗酱油炖菜、饭盒、配菜#1
  • 材料：牛肉（红豆芝麻肉）、鸡蛋、辣椒+酱油+大蒜、洋葱
  • 特点：咸、甜、可保存时间长，正宗饭盒
  • 外国人友好度：★★★★（认识日本佃煮）
  • 推荐店铺：家常菜、盒饭店、限定款式小菜
  • 与日本佃煮的区别：韩国酱煮= 以牛肉/鸡蛋为中心·咸/日本佃煮=海鲜·甜。不同的食物。

⚠ 外国人常犯的5个错误

1. “Korean Galbi = BBQ Galbi”：Galbijjim = 炖，甜，嫩。烧烤排骨=烤的、辣的、有嚼劲的。不同的菜单。

2. “杂菜=面条”：杂菜=粉丝+蔬菜+肉类全套。只有面条X。

3. “Jeyuk = Bulgogi”：Jeyuk = 辣猪 / Bulgogi = 甜牛肉。不同的菜单。

4. “烤肉=正宗烧烤”：烤肉=季节+汤·粉丝正宗。 BBQ=正宗的烧烤食品。

5. “Namul = 一种”：Namul = 6+ 种（siraegi、蕨类植物、豆芽等） 每一种都有不同的质地和味道。

⚠ 医疗/安全/饮食免责声明

肉类配菜=普通的韩国菜。孕妇=红烧排骨、烤肉煮得好，还可以。儿童 = 带或不带排骨（骨头）的辣肉 儿童要小心。过敏（大豆、海鲜、坚果）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。
