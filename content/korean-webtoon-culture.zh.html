韩国Webtoon文化 — 用竖屏滚动征服世界的韩式漫画

> 网漫 (Webtoon / 웹툰)·竖屏滚动·Naver Webtoon (네이버웹툰)·Kakao (카카오)·等待免费 (Gidarimyeon muryo / 기다리면 무료)·Webtoon原作剧 — 为外国人打造的韩国Webtoon文化解读。把“韩国创造的新漫画形式”按“为什么·是什么·怎么样”，一直讲到★它的光与影。

如果你在Netflix上看过〈地狱公使 (Hellbound / 지옥)〉·〈梨泰院Class (Itaewon Class / 이태원 클라쓰)〉·〈Moving异能 (Moving / 무빙)〉 — 其实你早已踏入了韩国网漫 (Webtoon / 웹툰) 的世界。这些剧全都是Webtoon原作。当〈我独自升级 (Solo Leveling / 나 혼자만 레벨업)〉以动画在全球爆红时，它的起点也是一部韩国Webtoon。

网漫 (Webtoon = web + cartoon / 웹툰) 是韩国创造的竖屏滚动数字漫画。它既不是用纸质书阅读的日本漫画 (manga / 만화)，也不是翻页阅读的美国美漫 (comics / 코믹스)。它贴合智能手机屏幕，用手指从上往下滑动阅读，是全彩的全新形式。从一开始就为屏幕而生而非为纸张而生的漫画 — 所以被称为“数字原生 (digital-native / 디지털 네이티브)”。本文不是“哪部作品好看”(推荐清单)，而是站在外国人的视角，解读Webtoon这一形式为何特别·如何征服世界·华丽背后又有怎样的阴影。这是韩国文化深度解读系列第43篇。

★ 一目了然 — Webtoon vs 漫画 vs 美漫

项目 网漫 (Webtoon / 웹툰，韩国) 漫画 (manga / 만화，日本) 美漫 (comics / 코믹스，美国)
形式 竖屏滚动数字 纸质书 (页) 纸质书 (页)
阅读方向 上 → 下 (无限滚动) 右 → 左 左 → 右
色彩 默认全彩 大多黑白 全彩
起点 屏幕 (移动端) 原生 纸质出版 → 后来数字化 纸质出版
阅读载体 智能手机App 单行本·杂志 单行本
单话长度 纵向很长 (数千~万像素以上) 固定页数 固定页数

> 核心：“Webtoon”指的是形式，而非国籍。说明漫画“出身”的是韩漫 (manhwa / 만화)·日漫 (manga，日本)·国漫 (manhua / 만화，中国)，而Webtoon说的是“如何呈现给你 (竖屏滚动·数字)”。大多数人气Webtoon是韩漫 (manhwa / 만화)，但这一形式本身是韩国发明并推向世界的。

⚠️ 外国人常误解的3点

1. “Webtoon = 用数字方式看的漫画 (manga) 吧？” ❌ — 二者形式本身就不同。漫画 (manga / 만화) 是把纸质书搬到屏幕上 (翻页·黑白·左右)，而Webtoon是从一开始就为竖屏滚动·全彩·智能手机而设计的。它不是切分翻页的画格，而是在上下流动的无限画布上，把留白·节奏·色彩当作导演工具来用。它不是“数字漫画”，而是全新的媒介。

2. “Webtoon不都是免费的吗？” ❌ — 虽从免费起步，但盈利模式很精巧。代表性的就是“等待免费 (Gidarimyeon muryo / 기다리면 무료，等一等就免费)” — 等待一定时间后下一话免费开放，等不及的人就用小额支付提前看。这一模式养大了Webtoon产业 (见下文③)。

3. “是漫画就是给小孩看的吧？” ❌ — Webtoon涵盖言情·惊悚·奇幻·职场剧·恐怖，是全年龄·全类型的。〈未生 (Misaeng / 미생，意为“未完成的人生”)〉描绘了韩国上班族的现实，〈地狱公使 (Hellbound / 지옥)〉则画出了沉重的社会寓言。成人读者是主力，所以Netflix·Disney+才争相把它们改编成剧 (见下文④)。

① 什么是Webtoon — “网络 + 卡通”

网漫 (Webtoon / 웹툰) 是把网络 (web / 웹) 和卡通 (cartoon / 카툰) 合在一起的韩式造词。它诞生于2000年代初，韩国门户网站 (Daum (다음)·Naver (네이버)) 开始在互联网上连载漫画之时，又在智能手机时代完成了如今的形态。

  • 生来就是数字的：它不是把纸质漫画扫描，而是从一开始就为在屏幕上阅读而绘制。所以被称为“数字原生 (digital-native / 디지털 네이티브)”形式。
  • 被出口到世界的韩语：“webtoon”如今在英语圈也被直接使用，成了专有名词。日本的“manga”、韩国的“webtoon” — 形式本身成了一个国家的文化品牌。

也就是说，看Webtoon并不只是把漫画数字化地看，而是体验韩国全新设计的漫画语法。

② 竖屏滚动 — 智能手机催生的革新

Webtoon的身份认同在于竖屏滚动 (vertical scroll / 세로 스크롤)。这是它与漫画·美漫拉开决定性差距的地方。

  • 无限纵向画布：单话纵向延伸数千乃至1万像素以上。没有“页”这一固定框架，作者便拉长画格之间的留白来制造紧张感，把屏幕拉得很长来导演坠落·反转·惊吓 (jump scare)。这是纸质漫画无法做到的“时间的导演”。
  • 拇指单手阅读：在通勤地铁里、在床上 — 用一只手的拇指轻轻下滑着看。它100%适配智能手机的竖屏。
  • 全彩·强化导演：大多为全彩，部分作品还会加上背景音乐 (BGM)·音效·简单的动画效果。它正从“阅读的漫画”走向更接近体验的漫画。

> 一句话总结：如果说漫画 (manga / 만화) 是“翻动纸张的节奏”之艺术，那么Webtoon就是“下滑屏幕的流动”之艺术。

③ 平台与盈利模式 — Naver·Kakao两强，“等待免费”

Webtoon产业由两大巨头拉动。

平台 特征 全球
Naver Webtoon (네이버웹툰) (WEBTOON) 免费连载 + 广告·付费抢先看。挖掘本土作者·IP (“本地化”) 全球WEBTOON App。全球月活用户1.7亿+ (因报告时点而异，建议确认)
Kakao (카카오) (KakaoPage (카카오페이지)·Kakao Webtoon (카카오웹툰)) 以“等待免费”养大的付费化。以K-content为中心供应 日本的Piccoma (픽코마) 曾在非游戏App收入上位居世界前列

★ “等待免费 (wait-to-free / Gidarimyeon muryo / 기다리면 무료)”模式是Webtoon商业的核心。

  • 2014年由KakaoPage (카카오페이지) 首次引入。等待一定时间 (如24小时) 后下一话免费开放，等不及的读者用小额支付 (现金·硬币) 提前看。
  • “让人因焦急而花钱，但只要等待人人都能免费读完”的精妙平衡 — 这一公式成了Webtoon·网络小说变现的基本语法，在海外也以“Wait Free”·“Daily Pass”原样出口。
  • 正在变化：约从2025年起，包月订阅 (如WEBTOON Premium)·扩大免费等模式又在重新进化。具体政策·价格变化很快，建议在App内直接确认。

④ IP力量 — Webtoon为何会变成剧·电影·动画

Webtoon真正的力量来自原作IP (知识产权)。拥有经过验证的故事·角色·粉丝群的Webtoon，被视为剧·电影·动画的“票房保证”。

代表性的Webtoon原作影视化 (★ 作品·制作方因时点而增减·变动 — 建议确认)：

  • 〈梨泰院Class (Itaewon Class / 이태원 클라쓰)〉 — Kakao (카카오) Webtoon原作剧。作者甚至参与了剧本编写的话题作。
  • 〈地狱公使 (Hellbound / 지옥)〉 — 延尚昊 (Yeon Sang-ho / 연상호)·崔奎硕 (Choi Gyu-seok / 최규석) 的Webtoon原作，以Netflix剧集在全球爆红。
  • 〈Moving异能 (Moving / 무빙)〉 — 姜草 (Kang Full / 강풀) 作家的Webtoon原作，Disney+剧集。以巨额制作费在多国登顶的超大型IP。
  • 〈未生 (Misaeng / 미생)〉 — 尹胎镐 (Yoon Tae-ho / 윤태호) 作家的职场现实Webtoon，剧集被称为“上班族的教科书”。
  • 〈我独自升级 (Solo Leveling / 나 혼자만 레벨업)〉 — 全球超级爆款Webtoon，以动画风靡世界。
  • 此外还有许多言情Webtoon的影视化，如〈金秘书为何那样 (What's Wrong with Secretary Kim / 김비서가 왜 그럴까)〉 等。

> 为什么Webtoon是IP宝库？① 粉丝群已被验证，票房风险低；② 画格·构图·台词几乎达到分镜 (Konti / 콘티) 水平，影视化容易；③ 全彩·导演华丽，能激发视觉化想象力。K-drama·K-content热潮的源头富矿正是Webtoon。

⑤ 全球扩散 — 韩国形式成为世界标准

Webtoon已成为继K-pop·K-drama之后韩流 (Hallyu / 한류) 的又一支柱。

  • 全球WEBTOON App：Naver Webtoon (네이버웹툰) 于2014年以“LINE Webtoon”(现WEBTOON) 进军海外，聚集了全球数亿量级的用户 (数字因报告时点而异 — 建议确认)。
  • 席卷北美·日本·东南亚：在北美Webtoon市场，Naver (네이버) 系占据很大份额，而Kakao (카카오) 的Piccoma (픽코마) 掌控了日本市场。也正快速扩散到印度尼西亚·泰国·印度等地。
  • 形式的出口：更惊人的是，韩国创造的竖屏滚动形式本身成了世界标准。如今美国·日本的创作者也用Webtoon形式作画，诞生了“vertical-scroll comic”这一类型。作为形式发明国，韩国的影响力是压倒性的。

⑥ ★ 光与影 — 全球成功背后作者们的劳动

这里必须保持均衡。Webtoon是韩国的骄傲，但也有阴暗的一面：那华丽的成功，是建立在作者们严苛的劳动之上的。

  • 要命的截稿：每周必须产出规定的分量 (数十个画格) 的周更连载结构。许多作者削减睡眠、长时间劳动。也有指出，由于画格数·上色负担比纸质漫画更大，劳动强度更高。
  • 健康危机：一项实态调查发现，Webtoon作者的抑郁症患病率明显高于一般人群 (约28.7% vs 7.7%上下)，自杀未遂率等精神健康指标也被严重地报告出来。长时间久坐工作带来的肌肉骨骼疾病、被截稿追赶产生的肠胃·膀胱疾病等身体伤害也很常见。
  • 真实的悲剧：绘制〈我独自升级 (Solo Leveling / 나 혼자만 레벨업)〉的作者 (工作室代表) 因与宿疾相关的脑出血离世等，这些与过劳相关的令人痛心的案例，在产业内敲响了警钟。
  • 不公平合约之忧：由于保密条款使合约条件难以共享，新人作者容易暴露在不利合约之下的问题也一直被提出。

> 想对外国读者传达的核心：你所享受的一部Webtoon，可能是一位作者削减睡眠换来的成果。产业正认识到这一问题，并在讨论劳动·合约的改善。如果你热爱Webtoon，在正规平台上正当地消费，就是支持作者最简单的方式。

⑦ 外国人想看Webtoon — 在哪·怎么看

> App·服务·翻译提供范围变化很快 — 出行前请在应用商店·官方渠道确认。

  • 全球WEBTOON App (Naver (네이버))：提供英语等多语言官方翻译。对外国人入门最为省心。在应用商店搜索“WEBTOON”。
  • 其他英文平台：Tapas · Tappytoon · Manta · Lezhin Comics 等提供官方英译韩国Webtoon的服务多种多样 (作品阵容·免费付费政策因服务而异)。
  • 韩国Naver Webtoon (네이버웹툰) 原版：韩国Naver Webtoon (네이버웹툰) 网站·App的原版大多为韩语专用，想直接读需要韩语。也有用浏览器翻译扩展来看的方法，但官方全球WEBTOON App更方便。
  • 阅读方法：因为是竖屏滚动，所以用手指从上往下滑动着看。没有翻页动作 — 起初会不习惯，但很快就能适应。
  • 入门推荐流程：如果有喜欢的K-drama，从它的原作Webtoon看起门槛最低 (因为剧情·角色已经熟悉)。

❓ 外国人常问的问题 (FAQ)

  • Webtoon和漫画 (manga)，归根结底不是一回事吗？ — 不是。漫画 (manga / 만화) 是纸质书 (黑白·左右翻页)，Webtoon是竖屏滚动数字 (全彩·移动端)。从起点到形式都不同，是两种独立的媒介。
  • 韩漫 (manhwa / 만화) 和webtoon有什么区别？ — 韩漫 (manhwa / 만화) = 韩国漫画 (出身)，webtoon = 竖屏滚动数字形式 (传递方式)。大多数人气Webtoon是韩漫 (manhwa / 만화)，但webtoon是指代形式的更宽泛的词。
  • 能用英语免费看吗？ — 在全球WEBTOON App上，相当一部分可以免费·以广告为基础观看。像“等待免费”那样，一定时间后下一话开放，而抢先看多为小额支付。政策请在App内确认。
  • 我看的K-drama也是Webtoon原作吗？ — 〈梨泰院Class (Itaewon Class / 이태원 클라쓰)〉·〈Moving异能 (Moving / 무빙)〉·〈地狱公使 (Hellbound / 지옥)〉·〈未生 (Misaeng / 미생)〉等相当多的人气剧都是Webtoon原作。看看作品页面上的“based on webtoon”标注，会发现意外地多。
  • 去韩国有Webtoon相关的“可去之处”吗？ — Webtoon本质上是App内的内容，所以不是“场所体验”。不过韩国也会举办漫画·Webtoon相关的展览·庆典，若有兴趣，可配合出行时期去找找看 (本文以“文化理解”为中心)。
