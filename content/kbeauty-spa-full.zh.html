⚠ 外国人常犯的3个错误

1. “K-beauty = 只有明洞 (Myeongdong / 명동)”: 除了明洞 (Myeongdong / 명동)，还有江南 (Gangnam / 강남) (悦诗风吟 (Innisfree / 이니스프리)·兰芝 (Laneige / 라네즈) 旗舰店 (Flagship Store))·弘大 (Hongdae / 홍대) (MZ)·欧利芙洋 (Olive Young / 올리브영) (全国门店)·爱茉莉太平洋 (Amorepacific / 아모레퍼시픽) 总部 (龙山 / Yongsan)·免税店 (江南 / Gangnam·明洞 / Myeongdong·首尔现代百货 (The Hyundai Seoul / 더현대 서울)) 全套。

2. “韩国汗蒸房 (Jjimjilbang / 찜질방) = 可怕”: 韩国汗蒸房 (Jjimjilbang / 찜jilbang，一种韩式公共浴场和桑拿房，提供各种休闲设施) = 外国人友好型24小时开放 + ₩6,000 (~$4.5 / ~32 RMB / ~600 JPY) ~ ₩25,000 (~$18.5 / ~130 RMB / ~2,500 JPY) + 韩国传统休闲首选地。龙山汗蒸幕 (Dragon Hill Spa / 드래곤힐스파) (龙山 / Yongsan)·Spa Land (스파랜드) (蚕室 / Jamsil)·韩松汗蒸房 (Hansol Jjimjilbang / 한솔찜질방) (弘大 / Hongdae) 对外国人友好。

3. “个人色彩 (Personal Color / 퍼스널컬러) = 韩国传统”: 个人色彩 (Personal Color / 퍼스널컬러，一种分析个人肤色、发色、瞳孔颜色，以确定最适合的色彩搭配的咨询服务) 是2010年代韩国 K-beauty 潮流首选 + 外国专业爱好者入境旅游首选。清潭 (Cheongdam / 청담)·江南 (Gangnam / 강남) 首选咨询店需提前预约。
