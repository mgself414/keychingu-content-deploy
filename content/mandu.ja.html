外国人がよくやってしまう3つのミス

1. 韓国のマンドゥ = 中国の餃子という思い込み

韓国のマンドゥ (Mandu / 만두) は、開城 (Gaeseong / 개성)・平壌 (Pyeongyang / 평양) など北の出身 + 韓国式のアレンジという点で、中国の包子・饺子 (包子·饺子) とは異なるアイデンティティを持つ。平壌マンドゥ (Pyeongyang Mandu / 평양만두) は薄いそば粉の皮 + 豆腐・豚肉・キムチの餡が特徴。皮・餡・スープのすべてが韓国式。

2. マンドゥククとマンドゥだけの注文

韓国のマンドゥはマンドゥ単品 (蒸し・焼き) + マンドゥクク (Mandu-guk / 만두국) (マンドゥ + お餅 + スープ) の2カテゴリー。外国人は単品だけ頼むことが多いが、韓国の美食家にはマンドゥ + マンドゥクク (Mandut-guk / 만둣국) のセットが定番。特に冬にマンドゥクク (Mandu-guk / 만두국) を食べないと、韓国式マンドゥ体験の50%を逃す。

3. 平壌マンドゥとキムチマンドゥの区別がつかない

平壌マンドゥ (Pyeongyang Mandu / 평양만두) はあっさりした豆腐・豚肉・キムチの餡 + そば粉の皮が正統。キムチマンドゥ (Kimchi Mandu / 김치만두) はキムチ中心のピリ辛の餡。初めての訪問なら平壌マンドゥ (Pyeongyang Mandu / 평양만두) → キムチマンドゥ (Kimchi Mandu / 김치만두) → カルビマンドゥ (Galbi Mandu / 갈비만두) の順が安全 (味覚の慣らし)。

2. 名所8か所 (4軸バランス)

2-1. 平壌式の本家2か所 — 韓国式マンドゥの真髄

① ジャハソンマンドゥ (Jahasonmandu / 자하손만두) — プアムドン (Buam-dong / 부암동)

1980年代~ プアムドン (Buam-dong / 부암동) の平壌手作りマンドゥ老舗の第1位。景福宮駅 (Gyeongbokgung Station / 경복궁역) からバスで7分または徒歩25分 (プアムドンの動線)。1人 ₩15,000~₩18,000。薄いそば粉の皮 + 豆腐・豚肉・キムチの餡 + 手包み — 韓国の平壌手作りマンドゥの正統。マンドゥクク (Mandu-guk / 만두국) + トッカルビ (Tteokgalbi / 떡갈비) の定食がシグネチャー。1人OK、外国人美食家の第1位。英語メニュー、カードOK。

② 開城マンドゥ宮 (Gaeseong Mandu Gung / 개성만두 궁) — ミョンドン (Myeongdong / 명동)

1970年代~ 開城式マンドゥ老舗の代表格。明洞駅 (Myeongdong Station / 명동역) 6番出口から徒歩5分。1人 ₩13,000~₩16,000。開城式は平壌式よりやや大きいマンドゥ + 多彩な餡。マンドゥ + マンドゥクク (Mandut-guk / 만둣국) + ピンデトク (Bindaetteok / 빈대떡) のトリオ。外国人対応に慣れており、英語メニューあり。

2-2. 鍾路の老舗2か所 — コスパ + 正統

③ プクチョン ソンマンドゥ (Bukchon Sonmandu / 북촌손만두) — 鍾路 北村 (Bukchon / 북촌)

1990年代~ 北村韓屋村 (Bukchon Hanok Village / 북촌 한옥마을) の動線にあるマンドゥ老舗。安国駅 (Anguk Station / 안국역) から徒歩7分。1人 ₩10,000~₩14,000。手仕事の手作りマンドゥ + 北村の韓屋 (Hanok / 한옥) 散策動線。外国人観光客の動線で第1位、英語・中国語メニューあり。1人OK、平日昼は30分待ち。

④ チュィチョンル (Chwicheonru / 취천루) — 鍾路 (Jongno / 종로)

1960年代~ 鍾路のマンドゥ老舗のコスパ路線。鐘閣駅 (Jonggak Station / 종각역) から徒歩5分。1人 ₩9,000~₩12,000。ワンマンドゥ (Wang Mandu / 왕만두) + ムルマンドゥ (Mul Mandu / 물만두) + マンドゥクク (Mandu-guk / 만두국) のフルセット — 韓国人会社員の昼の常連。英語メニューは一部、写真メニュー。

2-3. MZトレンド2か所 — SNSで人気

⑤ トボギ (Ddobogi / 또복이) — 江南 (Gangnam / 강남)

MZ向け新世代のトレンドマンドゥ。江南駅 (Gangnam Station / 강남역) 11番出口から徒歩4分。1人 ₩10,000~₩14,000。カルビマンドゥ (Galbi Mandu / 갈비만두) + キムチマンドゥ (Kimchi Mandu / 김치만두) + トリュフマンドゥのフルセット — SNS・インスタへの露出頻度が高い。インスタ用の写真が量産でき、MZのデートコースにも。週末は予約推奨、1人OK。

⑥ チョソンマンドゥ (Joseon Mandu / 조선만두) — 弘大 (Hongdae / 홍대)

弘大のMZ向けトレンドマンドゥ店。弘大入口駅 (Hongik Univ. Station / 홍대입구역) 9番出口から徒歩7分。1人 ₩11,000~₩15,000。キムチマンドゥ (Kimchi Mandu / 김치만두) + マンドゥクク (Mandu-guk / 만두국) + マッコリ (Makgeolli / 막걸리) の定食。K-アイドル・K-ドラマへの露出頻度が高く、外国人MZの常連。英語・中国語・日本語メニュー。

4. FAQ 8問

Q1. 韓国のマンドゥと中国の餃子の違いは?

A. 韓国の平壌マンドゥ (Pyeongyang Mandu / 평양만두) = 薄いそば粉の皮 + 豆腐・豚肉・キムチの餡。中国の餃子 (饺子) = 小麦粉の皮 + 刻み肉中心。韓国のマンドゥはキムチ・豆腐ベースがアイデンティティ。

Q2. 平壌マンドゥの正統店はどこ?

A. ジャハソンマンドゥ (Jahasonmandu / 자하손만두) (プアムドン) + 開城マンドゥ宮 (Gaeseong Mandu Gung / 개성만두 궁) (ミョンドン) の二大巨頭。平壌式の正統なあっさり味ならジャハソンマンドゥ (Jahasonmandu / 자하손만두)、より多彩な餡なら開城マンドゥ宮 (Gaeseong Mandu Gung / 개성만두 궁)。

Q3. マンドゥククとマンドゥトククの違いは?

A. 同じ料理 (マンドゥトクク (Mandut-guk / 만둣국) は、マンドゥ + クク (Mandu + guk / 만두 + 국) にサイシオッ (Sai-siot / 사이시옷) を入れた表記)。マンドゥ + お餅 + 牛肉スープ + 海苔 + 卵の定食。

Q4. 1人でも入れる?

A. 8店舗すべて1人OK。韓国のマンドゥは1人定食向きで、マンドゥクク (Mandu-guk / 만두국) + マンドゥ単品1人前のメニューが多い。

Q5. 英語メニューと英語対応は可能?

A. ジャハソンマンドゥ (Jahasonmandu / 자하손만두)・プクチョン ソンマンドゥ (Bukchon Sonmandu / 북촌손만두)・トボギ (Ddobogi / 또복이)・チョソンマンドゥ (Joseon Mandu / 조선만두) がもっとも慣れている。鍾路の老舗チュィチョンル (Chwicheonru / 취천루) は写真メニュー + 身振り手振り。

Q6. カード決済は可能?

A. 8店舗すべてカード・スマホ決済OK。老舗 (ジャハソン (Jahason / 자하손)・チュィチョンル (Chwicheonru / 취천루)) もカード端末あり。

Q7. マンドゥと飲み物の組み合わせは?

A. 平壌マンドゥ (Pyeongyang Mandu / 평양만두) + マッコリ (Makgeolli / 막걸리) (正統)。キムチマンドゥ (Kimchi Mandu / 김치만두) + 焼酎 (Soju / 소주) (MZのピリ辛)。マンドゥクク (Mandu-guk / 만두국) + 温かいお茶 (冬の定食)。

Q8. ビーガン・ハラールは可能?

A. 韓国のマンドゥはほぼ豚肉・牛肉ベースなのでビーガンは難しい。キムチマンドゥ (Kimchi Mandu / 김치만두) の一部の店舗にベジタリアンオプション (豆腐・野菜のみ) があり、別注文可能。ハラールの韓国マンドゥ店はほぼない。
