访韩外国人K-drama·电影动机 = 韩流达人全覆盖——日本·中国·东南亚·美国·欧洲皆然。韩国电影 = 2020《寄生虫》奥斯卡4冠 + K-drama全球爆发 + 釜山国际电影节(Busan Gukje Yeonghwaje / 부산국제영화제) + 电影院·多厅影院 + 韩国影像资料院(Yeongsang Jaryowon / 영상자료원)。K-drama拍摄地·CGV·Megabox·乐天影城·韩国影像资料院·电影博物馆cluster。

⚠ Cinema常见误区3种

1. "K-drama拍摄地=只有南怡岛"——不了解4处郊外·市中心cluster：只认知南怡岛。实际上有南怡岛 + 仁川鬼怪 + 付岩洞禹英禑 + DDP多部 + KTO·Hana Tour英文·中文套餐。

2. "电影院=普通影院"——不了解IMAX·艺术影院区别：只认知普通多厅影院。实际上有CGV 4DX·IMAX + Megabox IMAX + CINECUBE艺术影院差异化达人。

3. "电影节=只在某个季节"——不了解BIFF·全州·首尔达人资源：以为没有电影节。实际上有釜山BIFF 10月 + 全州5月 + 首尔11月 = 电影达人每年3大电影节。
