鍾路・北村カフェ 徹底ガイド

韓屋 cafe・伝統茶・宮殿隣接 cluster — 鍾路・北村の主要カフェ + 1日動線マトリックス

鍾路 (Jongno / 종로)・北村 (Bukchon / 북촌) は、景福宮 (Gyeongbokgung / 경복궁)・昌徳宮 (Changdeokgung / 창덕궁)・昌慶宮 (Changgyeonggung / 창경궁) の3大宮殿に挟まれたエリア。韓屋が200棟以上集まる北村韓屋村 (Bukchon Hanok Village / 북촌 한옥마을) を中心に、韓屋カフェの密度はソウルで最も高い。伝統茶屋の老舗、スペシャルティコーヒー、ベーカリー cluster まで — ヨーロッパの art lover・hanok pilgrim・history buff ペルソナにとって、ソウル1日 deep dive の最優先エリアだ。

注意: 北村は住民の居住区域 — 午前9時前の早い訪問は控えるのが望ましい。

外国人がよくやるミス 3つ

1. 韓屋カフェにスニーカー・スリッパだけで行く

座敷席のある韓屋カフェは、靴を脱ぐ造りのところが多い。入口で確認せずに入って戸惑うケースがよくある。厚手の靴下か、脱ぎ履きしやすい靴がおすすめ。座敷がつらければ、入店前に「table seat available?」と聞けばよい。

2. 北村の路地での撮影 — 住民のプライバシー侵害

北村韓屋村は、実際に住民が暮らす生活空間だ。開いた門・窓・庭の中を無断で撮影するのはマナー違反。カフェ・公共エリアを中心に撮影し、個人宅の前で三脚を立てて長時間占拠する行為は苦情の対象になる。案内看板があちこちに設置されているので、指示に従う。

3. ピークタイムに事前予約なしで訪問

カフェ オニオン 安国やブルーボトル 三清などの人気店は、週末の午後1~4時に30分以上の行列ができる。平日の午前10時前か午後4時以降が余裕がある。現地で並ぶ以外に別途予約システムがない店が多いので、時間帯の調整が最も実用的な対策だ。

韓屋カフェ (北村・三清洞・益善洞)

茶マシヌンツル (北村)

  • 位置: 鍾路区 (Jongno-gu / 종로구) 北村路11ギル (Bukchon-ro 11-gil / 북촌로11길) 26 (安国駅3番出口、徒歩10分)
  • 営業時間: 11:00~19:00、月曜休み (訪問前に確認推奨)
  • シグネチャーメニュー: 伝統茶セット — ナツメ茶・五味子茶・梅花茶など8種 / 茶菓セット付き
  • 価格 (₩、2026): 茶セット ₩12,000~18,000 / 伝統茶菓の追加 ₩5,000~8,000
  • 外国人 fit: ★★★ — 英語メニュー、外国人客が多く、茶の種類の英語案内板あり
  • 空間: 築600年以上の韓屋の母屋。板の間・部屋は座敷、庭にテーブル席。靴の脱ぎ履き必須
  • タイミング: 平日の午前11~12時、午後4時以降が余裕あり。週末午後は待ち
  • 韓屋マナー: 室内では大声を控える / 茶セットは30~60分ゆったり楽しむ空間 / 写真OK (スタッフに事前確認推奨)

カフェ オニオン 安国 (北村)

  • 位置: 鍾路区 桂洞路 (Gyedong-gil / 계동길) 5 (安国駅3番出口、徒歩5分)
  • 営業時間: 08:00~22:00 (年中無休 — 祝日は短縮の可能性あり、確認推奨)
  • シグネチャーメニュー: クロワッサン・塩パン + シグネチャーラテ / 餡バター系のパン
  • 価格 (₩、2026): ドリンク ₩6,000~9,000 / パン・デザート ₩4,000~8,000
  • 外国人 fit: ★★★ — 外国人リピーターの比率が高く、英語メニュー、英語対応可能なスタッフ多数、SNS シグネチャー空間
  • 空間: 1960年代の韓屋 + 倉庫建物のリノベーション。オープンキッチン・高い天井・庭。写真 fit
  • タイミング: オープン直後 (08~09時) か平日午後4時以降が余裕あり。週末の昼は30分以上の待ちを想定
  • 韓屋マナー: 屋外の庭席は雨天時使用不可 / パンは午後の早い時間に売り切れることがあるので、朝の訪問をおすすめ

スローパーク (三清洞)

  • 位置: 三清洞一帯 (正確な住所は Naver Map で確認推奨)
  • シグネチャーメニュー: 韓屋空間のデザートセット / 抹茶・緑茶系ドリンク
  • 価格 (₩、2026): ₩8,000~14,000
  • 外国人 fit: ★★ — 英語メニューあり
  • 空間: 三清洞の韓屋の路地内にある。庭・室内ともに韓屋の造り
  • タイミング: 三清洞のギャラリー巡りと組み合わせるなら午後2~4時がおすすめ
  • 参考: 営業状況は訪問前に確認推奨 (小規模店)

益善洞の韓屋カフェ cluster

  • 位置: 鍾路区 益善洞一帯 / 3号線 鍾路3街駅 (Jongno 3-ga Station / 종로3가역) 徒歩5分
  • 規模: 路地内の韓屋カフェ7~10軒の cluster
  • 特徴: 1930年代の韓屋の路地。伝統的な造り + トレンディなインテリアのミックス。MZ 世代をターゲットに運営
  • 外国人 fit: ★★ — 個別店舗によって異なる。picture menu・Papago 翻訳アプリ推奨
  • 価格 (₩、2026): ₩7,000~14,000 (店舗ごとに異なる)
  • おすすめの方法: 路地の入口で外観を見てから入る。写真 fit な空間が多い
  • タイミング: 平日の昼12~3時が MZ のピーク。午前10~11時は空いている

伝統茶・緑茶カフェ

オソルロク 仁寺洞 (仁寺洞)

  • 価格 (₩、2026): ドリンク ₩8,500~13,000 / ティーセット ₩15,000~20,000

実用情報

交通

  • 3号線 安国駅: 北村・三清洞・仁寺洞へ入る基本の駅。2番・3番出口を利用
  • 5号線 光化門駅: テラロッサ・アントラサイトなど都心スペシャルティへのアクセス
  • 3号線 鍾路3街駅: 益善洞への入口。1・3・5番出口
  • T-money カードまたは クレジットカードで地下鉄に乗車可能 (海外発行カードの端末設置駅が増加中 — 事前確認推奨)
  • 徒歩移動: 安国駅を基準に、北村・三清洞・仁寺洞はいずれも半径1km以内。歩きがおすすめ

決済

  • カード (海外発行を含む) — ほとんどの店舗で利用可。ブルーボトル・テラロッサ・オソルロクなどのブランドは100%カード OK
  • 小規模な韓屋カフェ・老舗 — 現金を好む店舗あり。現金 ₩50,000~100,000 の用意を推奨
  • 免税 (tax refund): 同一店舗で ₩30,000 以上の購入時に該当。空港の還付カウンターを活用
  • チップ文化なし — 会計金額をそのまま支払う

言語

  • 高: ブルーボトル・テラロッサ・オソルロク・カフェ オニオン — 英語対応可能なスタッフか英語メニューを完備
  • 中上: 茶マシヌンツル・スローパーク — 英語メニュー + 基本的な英語対応
  • ローカル: 益善洞のインディーカフェ・小規模な韓屋カフェ — 韓国語中心。Papago または Google 翻訳アプリ + 写真メニューを活用
  • Naver Map: 英語での検索・レビューに対応。リアルタイムの営業確認は必須

FAQ

Q1. 韓屋カフェで英語で注文できますか?

カフェ オニオン 安国・オソルロク・ブルーボトル・テラロッサは英語対応が可能です。小規模な韓屋カフェ (茶マシヌンツルを含む) には英語メニューがありますが、スタッフの英語が基本レベルの場合があります。メニューを指さして注文すれば問題なく通じます。

Q2. 北村韓屋村の写真撮影 — どこまで大丈夫ですか?

カフェの店内・公共の路地・展望ポイント (北村8景の案内板を参照) は撮影可能です。個人宅の門・窓の中を撮影したり、住宅前の路地を長時間占拠したりする行為は控えてください。住民の生活に直接支障を与える行為は苦情の対象です。現場の案内看板に従うのが基準です。

Q3. 北村・三清洞のカフェは予約が必要ですか?

ほとんどのカフェは現地での入店方式で、別途予約システムがありません。例外として、茶マシヌンツルのような体験型のティーハウスは、繁忙期に待ちが発生することがあります。週末午後1~4時を避けるか、平日午前の訪問が最も効率的です。

Q4. 益善洞と北村韓屋村 — どちらが「本物の韓屋」体験ですか?

北村韓屋村は、朝鮮時代の韓屋の原型を保存した住居地が基盤で、歴史の密度が高いです。益善洞は、1930年代の都市型韓屋がトレンディなカフェ・レストランとして再活用された空間です。歴史・伝統的な雰囲気を優先するなら北村、若々しい雰囲気・インスタ映えを優先するなら益善洞が合っています。

Q5. 1日の予算はどのくらい見ておけばよいですか?

カフェ3~4軒ホップの場合:

  • 韓屋 deep dive (Pattern A): ₩60,000~90,000 (茶セット含む)
  • トレンディ・MZ (Pattern B): ₩40,000~70,000 (4~5杯ホップ)
  • スペシャルティマニア (Pattern C): ₩40,000~65,000

交通費 ₩3,000~5,000 を追加。現金 ₩50,000 の予備を推奨します。
