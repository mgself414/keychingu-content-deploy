🎯 如何使用这份指南

鼻子凑近展示柜的玻璃,黄油的香味先飘过来,店员用刀切好蛋糕装盘端给你(感花堂 (Gamkkotdang / 감꽃당) 不给叉子和刀,而是店员切好再给,VisitKorea)。这份指南只收录以蛋糕、甜甜圈、曲奇、面包为主角、而不是咖啡的店。分为三类:蛋糕·法式甜点、甜甜圈·曲奇、老字号面包店。所有店家都是韩国观光公社旅游信息(VisitKorea、TourAPI)中登记的店。以咖啡和空间为主角的咖啡馆归入 #913 首尔咖啡馆指南,用秋季食材做的甜品归入 #475 秋季甜品指南。

旧版指南把群山的李盛堂 (Isungdang / 이성당) 放进了全州路线,但VisitKorea上的李盛堂位于全北群山市中央路 (Jungang-ro / 중앙로) 177号。伦敦贝果博物馆 (London Bagel Museum / 런던베이글뮤지엄) 也被写成"可颂店",但VisitKorea将其介绍为贝果专门店。"韩国最好的马卡龙""外国人人气第1"之类的排名表述因没有出处已删除。

🎂 蛋糕·法式甜点 — 首尔4家

  • Passion 5 (Passion 5 / 패션5) — 首尔龙山区梨泰院路 (Itaewon-ro / 이태원로) 272号(汉南洞 (Hannam-dong / 한남동))。面包房07:30~22:00,冰淇淋咖啡馆11:00~20:00,全年无休。从蛋糕、手工巧克力、曲奇、布丁到各国面包,陈列了300~400余种,像逛画廊一样边看边选。招牌是 Awesome Apple Pie,还有闪电泡芙、可颂、可丽露。凭购买小票可免费停车1小时。电话 0507-1416-9505(VisitKorea)
  • MAILLET (Maillet / 마얘) — 首尔瑞草区沙坪大路22街 (Sapyeong-daero 22-gil / 사평대로22길) 14号(盘浦洞西来村 (Banpo-dong Seorae Maeul / 반포동 서래마을))。11:00~21:30,全年无休。正宗法式甜品店,拿破仑香草 (Mille-feuille Vanilla / 밀푀유바니)、达克特香草 (Ttakteu Bani / 딱뜨바니) 和法式马卡龙是招牌。可打包。电话 02-749-1411(VisitKorea)
  • 蒙布朗 (Le Mont Blanc / 르몽블랑) — 首尔龙山区新兴路 (Sinheung-ro / 신흥로) 99-4号(解放村 (Haebangchon / 해방촌))。周二至周四12:00~19:00,周五、周六12:00~20:00,周一休息。由做了20年针织工厂的建筑改造而成。所以招牌是毛线慕斯和针织T恤蛋糕。1层是制作间和展示柜,2层是座位,3层是露台。电话 070-8887-8200(VisitKorea)
  • 感花堂 (Gamkkotdang / 감꽃당) — 首尔钟路区敦化门路11多街 (Donhwamun-ro 11da-gil / 돈화문로11다길) 38号。10:30~22:00,全年无休。保留了老柿子树的韩屋 (Hanok / 한옥) 咖啡馆。招牌是用苹果做的苹果派、发酵黄油司康、蛋挞。不给叉子和刀,店员切好后递上湿巾。电话 02-747-3999(VisitKorea)

🍩 甜甜圈·曲奇 — 首尔3家

  • 甜甜圈贞秀 (Donut Jeongsu / 도넛정수) — 首尔钟路区昌信12街 (Changsin 12-gil / 창신12길) 40号。11:30~21:00(最后点单20:30),全年无休。灵感来自把糯米下油锅炸制的开城传统点心"油炸糯米点心 (Juak / 주악)"的韩式甜甜圈店,供应用全国特产做的9种甜甜圈。有牛奶 (Tarak / 타락)、抹茶、柠檬酸奶甜甜圈等。有坐地座位和椅子座位,窗外能看到首尔风景。电话 0507-1386-5775(VisitKorea)
  • Overdose 甜甜圈咖啡 (Overdose Donut & Coffee / 오버도즈도넛앤커피) — 首尔城东区往十里路10街 (Wangsimni-ro 10-gil / 왕십리로10길) 19号(纛岛站 (Ttukseom-yeok / 뚝섬역) 7号出口约110米)。11:30~20:30,周一休息。每天凌晨熬卡仕达酱,奶油当天制作,没卖完的甜甜圈当天丢弃。招牌是开心果覆盆子甜甜圈和伯爵茶奶油甜甜圈。店在1.5层。电话 0507-1319-7369(VisitKorea)
  • 贞爱曲奇 (Jeongae Cookie / 정애쿠키) — 首尔麻浦区东桥路46街 (Donggyo-ro 46-gil / 동교로46길) 33号(延南洞 (Yeonnam-dong / 연남동))。11:00~19:00,全年无休。老奶奶店主用韩国产全麦面粉、不加黄油烤曲奇。招牌是辣椒曲奇,还有贞爱曲奇和巧克力豆曲奇。可打包。电话 02-747-0178(VisitKorea)

🏛 老字号面包店 — 首尔·木浦·镇海3家

  • 太极堂 (Taegeukdang / 태극당) — 首尔中区东湖路24街 (Dongho-ro 24-gil / 동호로24길) 7号(奖忠洞2街 (Jangchung-dong 2-ga / 장충동2가))。08:00~21:00,全年无休。VisitKorea的介绍文将其写为1945年光复前后开业的首尔最老的面包店,已传到第三代。招牌是60年代起售卖的牛奶味冰淇淋最中(夹馅的威化饼),还有红豆面包、黄油面包、奶油面包、传统黄油蛋糕。电话 02-2279-3152(VisitKorea)
  • 科隆邦面包店 (Colombang Bakery / 코롬방제과점) — 全南木浦市灵山路75巷 (Yeongsan-ro 75beon-gil / 영산로75번길) 7号(务安洞 (Muan-dong / 무안동))。08:00~21:00,休息日未公布。招牌是奶油芝士法棍和鲜虾法棍。电话 061-244-0885(VisitKorea)
  • 美珍点心铺 (Mijin Gwajajeom / 미진과자점) — 庆南昌原市镇海区忠壮路130巷 (Chungjang-ro 130beon-gil / 충장로130번길) 4号。07:00~22:00,全年无休,可刷卡,可打包。被称为镇海最老的面包店,与镇海制果 (Jinhae Jegwa / 진해제과) 一起研发了樱花面包、樱花卷、樱花蜂蜜玛德琳。樱花面包的主要原料是樱花浓缩液和粉色樱花豆沙。VisitKorea登记名称上带有"百年老店 (Baeknyeon Gage / 백년가게)"标记。电话 055-545-3133(VisitKorea)
  • 群山李盛堂 (Isungdang / 이성당) 和大田圣心堂 (Sungsimdang / 성심당) 另有专文 — 外国人群山 KTX 一晚两天完整指南 · 大田圣心堂烘焙坊

🥗 饮食

  • 价格带: 10家在VisitKorea登记信息中都没有价格。价格未公布 — 看展示柜价签或打电话确认
  • 素食: 蛋糕、甜甜圈、曲奇通常含黄油、牛奶和鸡蛋。贞爱曲奇介绍为不用黄油(VisitKorea),但是否含鸡蛋、牛奶没能确认 — 纯素食者请直接询问
  • 麸质: 贞爱曲奇使用韩国产全麦面粉(VisitKorea) — 是面粉甜点。米粉甜点请看 #475 秋季甜品指南 中的米制甜品店
  • 坚果·乳制品: Overdose 的招牌甜甜圈含开心果,太极堂的最中含牛奶味冰淇淋(VisitKorea)
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区乌沙团路10街 (Usadan-ro 10-gil / 우사단로10길) 15号,每天12:00~21:00)是韩国伊斯兰教中央会 (Korea Muslim Federation, KMF / 한국이슬람교중앙회) 认定为清真的少数餐厅之一。认证可能变动,请在访问前确认。这份指南里的甜品店都没有清真标注。慕斯、果冻类里的明胶,蛋糕糖浆里的洋酒,各店不同,点单前请询问
  • 出示用卡片请看 #1300 饮食需求手册

⚠ 常见的4个误区

1. "李盛堂是全州的面包店" — VisitKorea上李盛堂的地址是全北群山市中央路177号

2. "伦敦贝果博物馆是可颂店" — VisitKorea将其介绍为贝果专门店

3. "甜品店每天都营业到很晚" — 蒙布朗周一休息、周二至周四19:00打烊,贞爱曲奇19:00打烊。Overdose 甜甜圈咖啡周一休息(VisitKorea)

4. "蛋糕自己拿叉子吃" — 感花堂不给叉子和刀,而是店员切好再给(VisitKorea)
