ソウル10月第1週の祭りウィーク — 開天節連休の2日間に江南パレードと潜水橋グルメロードが重なってやってくる

サブタイトル: 10/3(土)江南フェスティバル グランドパレード(ピカチュウバルーン)・10/4(日)車のない潜水橋「グルメロード」・10/1~11高陽秋の花祭り・10/17~23ソウルススキ祭りプレビュー — 2026年限定イベントレイヤー

🎯 なぜ「10月第1週」なのか

ソウルの秋の名所(ススキ・紅葉・イチョウ)は10月中旬以降が本編です(#1313・#1314)。ところが2026年10月第1週末はカレンダーが作った特殊な区間です — 10月3日の開天節 (Gaecheonjeol / 개천절)が土曜日で連休になり、その2日間に島山大路 (Dosan-daero / 도산대로)を丸ごと封鎖する江南パレード(土)と車両が消えた潜水橋 (Jamsu-gyo / 잠수교)の上のフードトラック通り(日)が1日ずつ割り当てられています。どちらも年に一度きりで、潜水橋側は「車のない潜水橋」という形では今年が最後のシーズンです。

この回はその2日間をどうつなげるか、近郊・翌週に広げると何があるかの日付が刻まれたカレンダーです。常設の夜景・漢江動線(#586・#702)はいつ行ってもあるので、ここではこの期間にだけ重なるものだけを扱います。

⚠ 有効期間: この回で紹介するイベントは2026年限定の日程です。各イベントは雨天・現場事情で変更になる可能性があるので、出発前に公式チャンネル(下のSOURCES)で当日告知を確認してください。

🎈 10/3(土)江南グランドパレード — 島山大路2kmが舞台になる2時間

江南区 (Gangnam-gu / 강남구)が初めて開く大規模ストリートパレードです。午後4時から6時まで清潭交差点から島山公園交差点まで行列が続きます — 子どもブラスバンドと伝統行列で始まり、ポロロ (Pororo / 뽀로로)など大型キャラクターバルーン・ゲーム形のパレードカー・ロボット・ファッションモデル・ストリートパフォーマンスが順に登場し、フィナーレはポケモン30周年記念の大型ピカチュウ (Pikachu / 피카츄)バルーン行列とダンスパフォーマンスです。江南22洞の住民が直接行列に参加する方式なので、「観光客向けショー」というより地域祭りのスケールを大きくした感覚に近いです。

  • 観覧ポジション: 行列は清潭側から出発し島山公園側へ下ります。島山公園交差点付近がフィナーレ(ピカチュウ)区間なのでキャラクターが目的ならそちら、最初から見るなら清潭交差点側に4時前到着してください。
  • アクセス: パレードの時間帯、島山大路は車両が通行止めになります。タクシー・バスで道路上まで入ろうとするのはやめて地下鉄を使いましょう — 狎鴎亭ロデオ (Apgujeong Rodeo / 압구정로데오)駅(水仁盆唐線)が島山公園交差点に、清潭駅(7号線)が清潭交差点に隣接しています。
  • 続く夜: パレードが終わると19:00から同じ島山大路の舞台でファミリーコンサートが開かれます。夕食は狎鴎亭ロデオ・島山公園の裏路地(#1088編集ショップ参照)、または漢南 (Hannam / 한남)の夜バー(#1073参照)へ流れると自然です。
  • フェスティバル自体は10/3~5の3日間開かれるので、パレードを逃しても日・月にストリートプログラムは残ります。ただしパレードは3日間でたった1回だけです。

🍢 10/4(日)潜水橋グルメロード — 車のない橋の上のフードトラック、今年が最後

「車のない潜水橋トゥボクトゥボク祭り」は9月6日から10月25日まで毎週日曜日午後2時~10時、潜水橋と盤浦 (Banpo / 반포)漢江公園一帯の車両を止めて開く歩行者祭りです。5年目を迎えたソウルを代表する漢江祭りで、普段も南端・北端に約30台規模のフードトラック「タルビッ食堂」が並びます。その中でも10月4日は「グルメロード」週間 — 韓国・アメリカ・ベトナム・インドなど世界各国のグルメフードトラックを大幅に増やして橋の南端から北端まで埋め尽くし(主催側予告基準で普段の3倍前後)、最大800人が同時に座れる大型飲食スペースを別途設けます。

この祭りが特別なもう一つの理由があります。潜水橋は2027年下半期に全面歩行者専用橋へ変わる予定なので、「車のない潜水橋」という名前の祭りは今年のシーズンが最後です。車線が引かれた橋の上を歩く光景は、この秋で終わりです。

  • 動線: 地下鉄高速ターミナル駅(3・7・9号線)または銅雀 (Dongjak / 동작)駅(4・9号線) → 盤浦漢江公園 → 潜水橋南端。昼2時に入って食べて歩き、日暮れ時に盤浦大橋の月光虹の噴水 (Dalbit Mujigae Bunsu / 달빛무지개분수)(#702)へつなげるのが定石です — 噴水のタイムスケジュールは当日告知を確認してください。
  • 夜10時まで: 日が沈んだ後、橋の上から見る漢江夜景(#586・#703)がこの祭りの後半戦です。昼は食べて夜は歩く、2つのパートに分けて計画してください。
  • 雨天・安全: 河川イベントなので降雨・水位によって当日中止になることがあります。主催側の告知(下のSOURCES)を朝一度確認してください。

🌼 近郊オプション — 10/1~11高陽秋の花祭り(一山湖水公園)

ソウルの外へ1時間出る余裕があれば、一山湖水公園の秋の花祭りが同じ期間開かれます。菊・コスモス系の花畑と湖の散策がワンセットで、3号線チョンバルサン (Jeongbalsan / 정발산)駅から歩いて行けます。パレード・潜水橋と重ならない平日(10/1・2または10/5以降)に配置すると週末の混雑を避けられます。全国単位ではチャラソム (Jaraseom / 자라섬)花フェスタ(加平、~10/5)・泰安 (Taean / 태안)秋の花博覧会(~11/1)なども同じ時期に開かれますが、この回はソウル日帰り動線の中で届く場所だけを記します。

🌾 翌週プレビュー — 10/17~23ソウルススキ祭り(ハヌル公園)

10月第1週にハヌル公園へ行くとススキはありますがライティングショーはありません。第25回ソウルススキ祭りは10月17日(土)から23日(金)までワールドカップ公園ハヌル公園で開かれ、今年も夜間景観照明・ライティングショー・フォトゾーン・バスキングが付く夜型祭りです。ススキ自体のシーズンガイド(どこが銀色なのか、ピンクミューリーとの違い)は#1313にあるので、この回では日付だけ覚えておけば十分です — 第1週にソウルにいて第3週まで滞在するなら、ハヌル公園は17日以降に回してください。

🗓 二日間コース — 開天節連休をつなげて使う

10/3(土): 午後3時30分狎鴎亭ロデオ駅 → 島山公園交差点観覧ポジション → 16:00~18:00パレード(ピカチュウフィナーレ) → 島山公園・狎鴎亭ロデオの路地で夕食 → 19:00コンサート または 漢南夜バー(#1073)。

10/4(日): 午後2時高速ターミナル駅 → 盤浦漢江公園・潜水橋グルメロード → 日暮れ時に月光虹の噴水(#702) → 夜は橋の上で夜景 → 22:00終了。

雨の日の代案: 両イベントとも屋外です。9月末~10月はソウルの展覧会が特に多い年です — カウズ (KAWS / 카우스)個展 ~12/27・ガウディ (Gaudi / 가우디) ~10/31・マーティン・パー (Martin Parr / 마틴 파)写真展 ~10/18など — 屋内レイヤーに切り替えることができます。

⚠ よくある失敗3つ

1. パレードの時間にタクシーで島山大路へ進入 — 通行止め区間なので入れません。地下鉄の狎鴎亭ロデオ・清潭駅を使ってください。

2. 潜水橋を土曜日に訪れる — この祭りは日曜日のみ開かれます。10/3土曜日の潜水橋はいつも通り車が走っています。

3. 第1週にハヌル公園の夜間ライティングショーを期待する — ススキ祭りは10/17からです。第1週は昼のススキだけです。

⚙ FAQ3つ

1. 一日だけ選ぶなら? — 外国人旅行者基準で10/4潜水橋グルメロードです。漢江夜景とつながり、「車のない潜水橋」は今年が最後です。キャラクター・パレードが目的なら10/3。

2. 入場料は? — 両イベントとも入場無料です。潜水橋のフードトラック・手工芸体験などは有料です。

3. 連休だからどれくらい混む? — 開天節連休の週末なので両方とも混雑を覚悟する必要があります。パレードは4時前、潜水橋は2時の開場直後の入場がまだ余裕があります。
