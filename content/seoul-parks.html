🎯 왜 서울 공원 풀가이드인가

서울은 한강 11개 공원 + 도심 5대 공원 (서울숲·올림픽·어린이대공원·양재 시민의숲·서서울호수) + 3대 국립공원 (남산·북한산·관악산) 이 한 도시에 압축된 세계 1번지 공원 도시. 외국인 한국 vlog·인스타 1순위 콘텐츠 + 가족·자녀·MZ·등산 매니아 풀세트 demand.

⚠ 외국인이 자주 하는 실수 3가지

1. "한강공원 = 다 같음" — 11개 한강공원 개성 미인지

서울에는 11개 한강공원 (여의도·반포·뚝섬·잠실·잠원·이촌·망원·난지·강서·양화·광나루·강북강변 등). 각 공원 개성 다름:

  • 여의도 = 윤중로 벚꽃·이크루즈·달빛광장 (도심·랜드마크)
  • 반포 = 잠수교·달빛무지개분수 (인스타·야경)
  • 뚝섬 = 자전거·요트·BBQ (액티비티)
  • 잠실 = 가족·올림픽파크 인접 (#82)
  • 망원·난지 = 한적·자연 (서울 서쪽)
  • 광나루 = 한강 자전거 동쪽 출발지 (#183)

2. "어린이대공원 = 아이용만" — 한국 1번지 무료 도심 동물원 미인지

어린이대공원 (1973 박정희 대통령 지시 설립)은 한국 1번지 도심 동물원·놀이공원·식물원 (56만 평) 무료 입장. 외국인 자녀 동반 + 한국 전통 정원 + 가족 산책 1순위. 5호선 어린이대공원역 직결.

3. "3대 국립공원 = 등산만"

북한산·관악산·남산은 등산 외 둘레길 (등산 초보·가족 OK) + 사찰 (북한산 진관사·관악산 연주암·남산 동국대) + 외국인 photo spot 1순위. 등산 초보·가족도 OK.

⚙ FAQ 8개

Q1. 한강공원 11곳 중 외국인 1순위?

봄 4월: 여의도 (윤중로 벚꽃) / 여름: 뚝섬 (액티비티·BBQ) / 연중 야경: 반포 (잠수교·달빛무지개분수). 한 번에 추천 = 뚝섬 (다양성 최강).

Q2. 한강공원 자전거 어떻게?

따릉이 (서울시 공공자전거) — 1시간 1,000원. 광나루 → 잠실 → 뚝섬 → 반포 → 여의도 30km 코스 (한국 1번지 자전거 코스). 외국인 신용카드 OK.

Q3. 한강 BBQ 지정 구역?

뚝섬·반포·잠실·여의도 한강공원 일부 지정 구역. 사전 예약 (서울시 한강공원 홈페이지, 영문 OK). 1구역 30,000원/4인. 5~10월 1순위.

Q4. 어린이대공원 무료?

무료 + 24시간 (동물원 10:00~18:00). 외국인 자녀 동반 1순위. 5호선 어린이대공원역.

Q5. 서울숲 + 한강공원 동선?

서울숲 (분당선 서울숲역) → 도보 5분 → 뚝섬 한강공원. 한국 1번지 "숲 + 한강" 결합 1순위 동선.

Q6. 북한산·관악산·남산 중 등산 초보?

남산 (265m, 30분~1시간) → 관악산 둘레길 → 북한산 둘레길. 모두 둘레길은 등산 초보·가족 OK.
