🎯 为什么城东·往十里值得单独指南

城东 (Seongdong / 성동)·往十里 (Wangsimni / 왕십리) 是城东区 (Seongdong-gu / 성동구) 的 往十里 (Wangsimni / 왕십리)·金湖 (Geumho / 금호)·玉水 (Oksu / 옥수)·马场 (Majang / 마장)·杏堂 (Haengdang / 행당) 汉江 (Hangang / 한강) 结合区域 — 与圣水 (Seongsu / 성수) (#01·#145) 不同的 城东区 (Seongdong-gu / 성동구) 核心区域深度游。这里结合了 往十里站 (Wangsimni Station / 왕십리역) (2号线·5号线·KTX·京义中央线 (Gyeongui Jungangseon / 경의중앙선)·水仁盆唐线 (Suin Bundangseon / 수인분당선) 五线换乘站，韩国第一) + 金湖 (Geumho / 금호)·玉水 (Oksu / 옥수) 汉江 (Hangang / 한江) 景观 + 马场 (Majang / 마장) 传统肉铺·肉类 + 杏堂 (Haengdang / 행당) MZ世代 (MZ / 엠제트, 指千禧一代和Z世代)。KeyChinGu (키친구) 首次进入城东区 (Seongdong-gu / 성동구) 核心区域 (城东 (Seongdong / 성동) 区域共168处)。

⚠ 外国游客常犯的3个错误

1. "城东 (Seongdong / 성동) = 只有圣水 (Seongsu / 성수)" — 未认识到核心区域价值: 除了圣水 (Seongsu / 성수) (#01·#145) 外，往十里 (Wangsimni / 왕십里)·金湖 (Geumho / 금호)·玉水 (Oksu / 옥수)·马场 (Majang / 마장)·杏堂 (Haengdang / 행당) = 汉江 (Hangang / 한강)·换乘·肉类深度游。

2. "往十里站 (Wangsimni Station / 왕십리역) = 只是个车站": 韩国第一五线换乘 (2号线·5号线·KTX·京义中央线 (Gyeongui Jungangseon / 경의중앙선)·水仁盆唐线 (Suin Bundangseon / 수인분당선))。KTX 江陵线 (Gangneung-seon / 강릉선) 始发站。

3. "马场畜产品市场 (Majang Chuksammul Sijang / 마장축산물시장) = 不知道": 韩国第一肉类批发市场 (1961年开业)。韩牛 (Hanwoo / 한우)·猪肉直销批发。外国人可以议价 OK。

⚙ 6个常见问题

1. 往十里站 (Wangsimni Station / 왕십리역) 换乘？ 韩国第一五线换乘。KTX 江陵线 (Gangneung-seon / 강릉선) 始发站。

2. 马场畜产品市场 (Majang Chuksammul Sijang / 마장축산물시장) 外国人可以去吗？ 可以。可以议价 + 现场生鱼片·烤肉 (hoe·gui / 회·구이) OK。

3. 鹰峰山 (Eungbongsan / 응봉산) 夜景？ 汉江 (Hangang / 한강) 夜景首选 (#51 鹰峰山八角亭 (Eungbongsan Palgakjeong / 응봉산 팔각정))。

4. 城东 (Seongdong / 성동) + 圣水 (Seongsu / 성수) 路线？ 步行10分钟或乘坐2号线·水仁盆唐线 (Suin Bundangseon / 수인분당선) 1站。

5. 汉阳大学 (Hanyang University / 한양대) 校区？ 自由进入 OK。

6. 玉水 (Oksu / 옥수)·金湖 (Geumho / 금호) 汉江 (Hangang / 한강) 骑行？ 汉江 (Hangang / 한강) 自行车道 + Ttareungi (따릉이, 首尔公共自行车)。

🗺 1日路线

A. 城东 (Seongdong / 성동)·汉江 (Hangang / 한강) 深度游:
