🎯 为什么需要韩国海鲜流程指南

即使了解海鲜6种全指南，点餐·烹饪法·搭配仍是独立环节。韩国海鲜分为 (a) 市场正宗(统营 (Tongyeong / 통영)·札嘎其 (Jagalchi / 자갈치)·苏莱浦口 (Sorae-pogu / 소래포구)·木浦 (Mokpo / 목포)，1楼活鱼摊位 + 2楼餐厅)(b) 生鱼片店·专门店(首尔江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대))(c) 酱油腌蟹 (ganjang-gejang / 간장게장) 专门店(麻浦 (Mapo / 마포)·江南)(d) MZ潮流酱虾 (saeu-jang / 새우장)·花蟹汤 (kkotge-tang / 꽃게탕)。烹饪法共5种：生鱼片、蒸煮、烧烤、汤·锅、酱油腌制。外国游客通常不知道 (1) 活章鱼 (san-nakji / 산낙지) 要慢慢咀嚼 (2) 生牡蛎和熟牡蛎的区别 (3) 酱油腌蟹要用手掰开吃 (4) 花蟹汤是秋季的正宗料理。本指南将提供5步流程 + 烹饪法 + 英文对话。

★ 5步流程一览

步骤 操作 时间 外国游客核心要点
1️⃣ 选择渠道 市场 / 生鱼片店·专门店 / 酱油腌蟹专门店 / MZ潮流店 即时 性价比·正宗·发烧友·潮流目的
2️⃣ 点餐 按种类·kg·1贯 (gwan / 관，传统计量单位，约3.75kg) / 1人份 / 1只 1~5分钟 市场 = 按公斤计价
3️⃣ 上菜·摆盘 生鱼片·蒸煮·烧烤·汤·酱油腌制5种烹饪法 10~30分钟 活鱼·生牡蛎·熟制
4️⃣ 品尝·搭配 韩式辣酱 (chojang / 초장)·酱油·烧酒·啤酒 30~90分钟 活章鱼 (san-nakji / 산낙지) 要慢慢吃
5️⃣ 结账 接受刷卡 / 市场 = 部分接受现金 / 无小费 1~5分钟 AA制 (1/N) OK

总耗时：市场 = 1~2小时 / 生鱼片店 = 1.5~2.5小时 / 酱油腌蟹 = 1~2小时 / MZ潮流店 = 1~1.5小时

🦐 不同渠道的流程

Type A — 市场(统营 (Tongyeong / 통영)·札嘎其 (Jagalchi / 자갈치)·苏莱浦口 (Sorae-pogu / 소래포구)·木浦 (Mokpo / 목포))

  • 特色：现杀活鱼·1楼活鱼摊位 + 2楼餐厅
  • 营业时间：各市场不同 (06:00~22:00)
  • 价格：按公斤计价 + 餐厅餐位费 (charimbi / 차림비) ₩5,000~15,000
  • 菜单：活鱼·生牡蛎·活章鱼 (san-nakji / 산낙지)·花蟹·大虾 (daeha / 대하)
  • 外国游客友好度：★★★★ (有英文)

Type B — 生鱼片店·专门店(江南 (Gangnam / 강남)·弘大 (Hongdae / 홍대)·梨泰院 (Itaewon / 이태원))

  • 特色：正宗一桌全席·中高档
  • 营业时间：17:00~24:00
  • 价格：₩50,000~150,000/1人
  • 菜单：生鱼片 (hoe / 회) + 辣鱼汤 (maeuntang / 매운탕) + 酱虾 (saeu-jang / 새우장) + 活章鱼
  • 外国游客友好度：★★★★ (有英文)

Type C — 酱油腌蟹 (ganjang-gejang / 간장게장) 专门店(麻浦 (Mapo / 마포)·江南 (Gangnam / 강남))

  • 特色：酱油腌蟹第一·MZ世代Ins热门·正宗
  • 营业时间：11:30~22:00
  • 价格：₩30,000~80,000/1人 (酱油腌蟹一只)
  • 菜单：酱油腌蟹·花蟹汤 (kkotge-tang / 꽃게탕)·蟹酱拌饭 (gejang-bibimbap / 게장비빔밥)
  • 外国游客友好度：★★★★★ (全球发烧友)
  • 推荐：麻浦酱蟹一条街·江南正宗店

Type D — MZ潮流酱虾 (saeu-jang / 새우장)·花蟹汤 (kkotge-tang / 꽃게탕)(弘大 (Hongdae / 홍대)·江南 (Gangnam / 강남)·圣水 (Seongsu / 성수))

  • 特色：MZ潮流·酱虾Ins热门·酱油腌制
  • 营业时间：11:30~24:00
  • 价格：₩25,000~50,000/1人
  • 菜单：酱虾·迷你酱油腌蟹·MZ创意变化款
  • 外国游客友好度：★★★★★ (MZ世代第一)

🍳 5种烹饪法总览

烹饪法 招牌海鲜 发烧友焦点
生鱼片 (hoe / 회) 活鱼生鱼片 + 活章鱼 + 生牡蛎 活鱼第一
蒸煮 (jjim / 찜) 蒸花蟹 + 蒸贝类 + 蒸虾 正宗
烧烤 (gui / 구이) 烤牡蛎 + 盐烤大虾 + 烤鱿鱼 秋季第一
汤·锅 (guk·tang / 국·탕) 牡蛎汤饭 (gul-gukbap / 굴국밥) + 花蟹汤 + 章鱼汤 (nakji-tang / 낙지탕) 醒酒·正宗
酱油腌制 (ganjang-yangnyeom / 간장 양념) 酱油腌蟹 + 酱虾 酱油腌制发烧友第一

🌶 外国游客英文对话范例

  • "活鱼牡蛎" = "Live oysters, please (生牡蛎, saeng-gul / 생굴)"
  • "活章鱼慢慢吃" = "Live octopus — chew slowly! (有噎住风险)"
  • "酱油腌蟹1人份" = "1 person serving of soy sauce crab"
  • "花蟹汤微辣" = "Spicy blue crab stew, please"
  • "酱虾" = "Shrimp in soy sauce (MZ潮流)"
  • "可以刷卡吗？" = "Card accepted?"

⚠ 外国游客常犯的7个错误

1. “牡蛎四季都有”：牡蛎 = 冬季12~3月第一·春夏季生牡蛎食物中毒风险较高。

2. “活章鱼和普通生鱼片一样”：活章鱼 (san-nakji / 산낙지) = 趁活切成小段，要慢慢吃(有噎住风险)。

3. “花蟹一年四季都有”：花蟹 = 秋季9~11月第一(酱油腌蟹的正宗时令)。

4. “酱油腌蟹要用筷子吃”：酱油腌蟹 = 用手掰开吃·蟹酱拌饭也是不错的选择。

5. “酱虾是蒜蓉调味”：酱虾 = 酱油腌制(和蒜蓉虾不同)。

6. “统营牡蛎没什么特别”：统营牡蛎 = 南海正宗第一(生食，12~3月)。

7. “花蟹汤只有辣的”：花蟹汤 = 辣味 + 清淡两种都有。

⚙ 8个常见问题

1. 第一次尝试海鲜 = 哪个渠道：酱油腌蟹专门店(发烧友第一) → 统营牡蛎(冬季)。

2. Instagram·vlog：麻浦酱油腌蟹·统营牡蛎·西海花蟹·木浦活章鱼。

3. MZ潮流：酱虾·MZ风花蟹汤·迷你酱油腌蟹。

4. 酱油腌蟹发烧友：麻浦酱蟹一条街·江南正宗店。

5. 孕妇：生牡蛎·活章鱼禁食 / 熟制可以。

6. 过敏：甲壳类·软体动物请提前告知。

7. 结账·小费：可刷卡 / 市场 = 部分接受现金 / 无小费。

8. 增值税退税：餐饮一般不退税。

⚠ 医疗·安全·饮食免责声明

海鲜 = 请注意食物中毒(尤其是春夏季生牡蛎)·活章鱼 = 有噎住风险。孕妇 = 熟制可以·生牡蛎、活章鱼禁食。儿童 = 建议5岁以上食用熟制海鲜。过敏(甲壳类·软体动物·酱油中的麸质)请提前告知。如怀疑食物中毒 ☎ 1339 (医疗服务, 英文)。本指南为一般信息, 非医疗建议。

饮食限制备选方案：

  • 清真 (Halal)·犹太洁食 (Kosher)：甲壳类·软体动物 = 清真部分可食(依商家而定)/ 犹太洁食 = 不可食。
  • 素食·纯素：6种海鲜均为非素食 / 素食 = 拌饭 (bibimbap / 비빔밥)·寺庙饮食。
  • 无麸质：生鱼片·烧烤类OK / 酱油腌制 = 含麸质(可用溜酱油Tamari替代)。
