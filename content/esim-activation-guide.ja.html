韓国eSIM開通、パニックゼロの手順書 — インストールは出国前、アクティベーションは到着後

🎯 この手順書の読み方 — 画面表記のルール

この記事は「eSIMとは何か」ではなく、「自分のスマホ画面で何を、いつ、どの順番で押すのか」をそのまま書く。eSIM自体の紹介・物理USIMとの料金・購入先比較は#250ですでに扱った — この記事はインストール・アクティベーション手順専用だ。

(表記ルールは#1270で確定した3種 — 角括弧ボタン・かぎ括弧画面・太字動作 — をそのまま使用する)

① この記事が扱うもの — 「インストール」と「アクティベーション」を混同すると空港で詰まる理由

eSIM失敗談のほとんどは、たった一つの勘違いから始まる。「空港に着いてからeSIMを入れればいいだろう。」

間違いだ。eSIMをスマホに埋め込む工程(インストール、install)はQRコードをスキャンしてプロファイルをダウンロードする作業なので、インターネット接続が必要だ。ところが空港に着いたばかりの時点では、まだローミングもWi-Fiもつながっていない状態 — つまり「QRをスキャンするにはデータが必要なのに、データをオンにするにはまずQRをスキャンしなければならない」という逆説にはまる。空港Wi-Fiをつかめばいいじゃないかと思うだろうが、ログイン画面で迷う・速度低下で荷物を受け取って出てくるその短い時間に冷や汗をかくケースが実際には最も多い。

正解は順序を分けることだ。

  • インストール(install)は出国前、自宅Wi-Fiで — 時間に余裕があるうちにQRスキャンまで終わらせておく
  • アクティベーション(activate)は到着後 — 飛行機を降りてローミングをオンにした瞬間から実際にデータがつながる

この一文さえ覚えておけば、この記事の半分は終わったも同然だ。残り半分は③④⑥だ。

② eSIMか物理USIMか — まず自分のスマホを確認

eSIMはすべてのスマホで使えるわけではない。eSIM対応モデル(iPhone XS以降のほとんど・ここ3~4年のGalaxy/Pixelフラッグシップなど)であり、かつSIMフリーまたはロック解除(unlock)状態である必要がある。自国キャリアでeSIMロックがかかっていたり旧機種だったりすると、そもそも開かない。

  • 対応の有無がはっきりしなければ出国前に設定 → 一般(または端末情報) → eSIM対応の有無を確認するか、購入先の案内でモデル名から確認するのが一番早い。
  • eSIMが使えない機種だったり不安が残るなら物理USIMにすればいい — 空港のキャリアブースやコンビニで実物のUSIMを買って差し替える方式には、このQR・タイミング問題自体がない。
  • eSIM vs 物理USIMの料金・データオプション・購入先の全体比較は#250で扱った。この記事は「すでにeSIMに決めた人」のインストール・アクティベーション手順だけに絞る。

③ インストールマスターフロー — 出国前、自宅Wi-Fiで

eSIMは通常メールでQRコードが届く(購入サイト・プロバイダから発行)。そのQRを以下の順にスキャンすればインストールは終わる。必ず出国前、自宅Wi-Fi接続の状態で進める。

手順 iPhone Android
1 「設定」アプリを開く 「設定」アプリを開く
2 [ モバイル通信 ](または[ モバイルデータ ])をタップ [ ネットワークとインターネット ]をタップ
3 [ eSIMを追加 ]または[ モバイル通信プランを追加 ] [ SIM管理 ]をタップ
4 [ QRコードを使用 ]を選択 [ eSIMを追加 ]をタップ
5 カメラでメール内のQRコードをスキャン [ 代わりにQRコードでダウンロード ] → QRスキャン
6 「モバイル通信プランが追加されました」を確認 → ラベル設定(例: "Korea") 「eSIMのダウンロードが完了しました」を確認
  • QRは一度しかスキャンできない場合が多い — スキャン前に画面を消したり開き直したりせず、スクリーンショットではなくメール原本から直接スキャンすること。
  • インストールが終わってもすぐデータがつながるわけではない。今はスマホにeSIMが埋め込まれただけで、次の段階(④)を経て初めて実際にオンになる。

④ 到着直後アクティベーションチェックリスト — 3段階

飛行機を降りて電源を入れたら、この順番でやるだけでいい。

1. 該当eSIMをモバイルデータに指定 — 設定 → モバイル通信/モバイルデータ → 先ほどインストールした「Korea」回線をデフォルトのデータ回線として選択

2. データローミングをON — 同じ画面内の[ データローミング ]トグルをオンにする。eSIMを入れてもこのトグルがオフのままだとデータがつながらないプロバイダが多い — 最もよく見落とす段階

3. 機内モードをオフ→オン — 二つの設定が終わったら機内モードを一瞬ONにしてから再びOFFにする。アンテナが新しい設定を再取得してつながるケースがほとんど

三段階が終わると画面上部にキャリア名と信号表示(LTE/5G)が出る。1~2分かかることがあるので、すぐに出ないからといって再起動から始めず、少し待ってみよう。

⑤ スマホ画面のサバイバル単語6 — 混同しやすいものだけ

三つの言葉が似ていて間違って押してしまうケースが多い。混乱したらこの表に戻ってこよう。

用語 意味 混同しやすい理由
モバイル通信 / モバイルデータ通信 (셀룰러 / 모바일 데이터) データ回線全体を管理するメニュー名 iPhoneは「モバイル通信」、Androidは「モバイルデータ」と呼び名が違うだけ — 同じ場所
eSIMを追加 (eSIM 추가) 新しいQRを取り込むインストールボタン すでにインストール済みのeSIMを再度ここで押してはいけない — ④は別メニュー
データローミング (데이터 로밍) 海外でデータを使えるようにするスイッチ モバイルデータONとは別物 — 両方オンにしないとつながらない
既定回線 (기본 회선) 2つのSIMのうち実際にデータを使う回線の指定 ホームSIMが既定のままだとeSIMを入れても使われない
APN キャリア接続設定値 自動設定が失敗したときだけ手動入力(⑥)
SIM管理 (SIM 관리자, Android) eSIM・物理USIMをまとめて管理する画面 iPhoneの「eSIMを追加」に相当するAndroidの呼び名

⑥ つながらない時の3段階トラブルシューティング

④を全部やってもつながらなければ、この順番で確認する。順番通りに、一つずつ。

1. ローミングONの再確認 — 最も多い原因。設定 → モバイル通信/モバイルデータ → 先ほどオンにしたeSIM回線 → [ データローミング ]が本当にオンになっているか、もう一度目で確認

2. APN手動入力 — 自動設定が失敗した可能性がある。購入時に届いたメール・プロバイダ案内に記載のAPN値を設定 → モバイル通信 → eSIM回線 → [ APN設定 ]にそのまま入力する。創作禁止 — 必ずプロバイダ案内の値をそのまま入力

3. 機内モードトグル → それでもダメなら再起動 — ④の3段階をもう一度繰り返し、それでもダメならスマホ自体の電源を切って入れ直す

三段階をすべて試してもダメなら、eSIM自体の問題(インストール失敗・QR期限切れ)の可能性が高い — ⑨プランBへ。

⑦ ホーム回線(元のSIM)維持のコツ — 高額請求を防ぐ

eSIMを追加で入れても、もともと使っていたホームSIMはスマホの中にそのまま残っている。これを放置すると、韓国にいる間もホームキャリアが自動でローミングデータをつかんで使ってしまい、帰国後の請求書に驚くことになる。

  • ホームSIM(または物理USIM)のデータローミングは必ずOFFに変えておく — ④でオンにしたのは新しいeSIM側のローミングで、こちらは逆にオフにすべきもの
  • 電話・SMSだけホーム回線で受けたいなら、データはeSIM、通話はホーム回線に指定するデュアルSIM個別設定が可能だ(⑤「既定回線」メニューでデータ/通話を別々に指定)
  • 帰国直後は逆にeSIM側のローミングをオフにしておくと、残ったデータが無駄に消費されるのを防げる

⑧ パニックシナリオ3

1. 到着したのにデータがつながらない — ④のチェックリスト3段階をもう一度確認し、それでもダメなら⑥のトラブルシューティングへ。ほとんどはデータローミングがオフになっているのが原因だ。

2. QRメールが見つからない — 購入サイトのアカウント(ログイン)から注文履歴で再確認できる場合が多い。迷惑メールフォルダも確認しよう。空港Wi-Fiがつかめればその場で再発行の問い合わせも可能だが、そもそも③を出国前に終わらせておくのがこのシナリオ自体を防ぐ方法だ。

3. 自分のスマホがeSIM非対応だと分かった — 慌てる必要はない。②に戻って物理USIMに切り替えればいい — 空港でその場で購入・開通可能だ(⑨)。

⑨ プランB — eSIMがどうしてもダメな時

  • 空港のキャリアブースで物理USIMを受け取る — 入国審査通過後に通信3社(SKT・KT・LG U+)のブースがある。パスポート提示後すぐに開通するUSIMをその場で買える。
  • 公共Wi-Fiでまず急場をしのぐ — 空港・地下鉄・主要観光地の公共Wi-Fi実用法は#1302で扱う。eSIM問題を解決するまでの一時しのぎとして便利だ。
  • 出国前の準備を一度に終わらせたいなら — eSIMインストールを含む到着前の準備物セットは#1289 e-Arrival手続きガイドとセットで整理しておくと、空港で開く画面が減る。
