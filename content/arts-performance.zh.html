🎯 为什么是韩国电影·音乐剧·演出爱好者指南

除了 K-drama·K-pop 之外，对韩国电影、音乐剧和独立演出有需求的外国爱好者。将 #170 大学路 (Daehangno / 대학로) 独立演出、#173 艺术殿堂 (Seoul Arts Center / 예술의전당)、#175 LG 艺术中心 (LG Arts Center / LG 아트센터)、#181 鹭梁津 (Noryangjin / 노량진) (中央大学电影·戏剧) 区域分散的内容整合为深度探索。

★ 12选一览

⚠ 外国人常犯的3个错误

1. “演出 = 只有韩语”: 韩国第一演出场所 = 部分演出提供英文字幕 (LG 艺术中心 (LG Arts Center / LG 아트센터)·艺术殿堂 (Seoul Arts Center / 예술의전당))。独立音乐剧、爵士乐、舞蹈 = 无语言障碍。

2. “大学路 (Daehangno / 대학로) 演出 = 韩语”: 大学路 (Daehangno / 대학로) 50+ 小剧场 (Small Theater / 소극장) 主要以韩语独立演出为主，但季节性提供英文作品 + 舞蹈·音乐剧等无语言障碍作品。

3. “韩国电影节 = 只有釜山”: 除了 BIFF (釜山 (Busan / 부산)) + BFFC (富川 (Bucheon / 부천)) + JIFF (全州 (Jeonju / 전주))，还有首尔环境电影节 (Seoul Eco Film Festival)·首尔国际骄傲电影节 (Seoul International Pride Film Festival) 等全年5+国际电影节。

① 综合演出场所 (3)

1. 艺术殿堂 (Seoul Arts Center / 예술의전당) ★ 韩国第一演出场所

  • 地址: 瑞草区 (Seocho-gu / 서초구) 南部循环路 (Nambusunhwan-ro / 남부순환로) 2406 (3号线 (Line 3) 南部客运站站 (Nambu Bus Terminal Station / 남부터미널역)) (#173)
  • 外国人 ★: ◎◎ — 韩国第一综合演出 + 翰伽蓝美术馆 (Hangaram Art Museum / 한가람미술관)·书法博物馆 (Calligraphy Art Museum / 서예박물관)·歌剧院 (Opera House / 오페라하우스)·音乐厅 (Concert Hall / 콘서트홀)
  • 特色: 1988年开馆 + 音乐厅 (2,500席)·歌剧院 (2,300席)·自由小剧场 (Jayu Small Theater / 자유소극장)·翰伽蓝美术馆 (Hangaram Art Museum / 한가람미술관)
  • 预订: 售票网站提供英文用户界面 (UI) (#206 姐妹篇)

2. LG 艺术中心 (LG Arts Center / LG 아트센터) (Magok / 마곡)

  • 地址: 江西区 (Gangseo-gu / 강서구) 麻谷中央路 (Magokjungang-ro / 마곡중앙로) 136 (#175)
  • 外国人 ★: ◎ — 2022年从江南 (Gangnam / 강남) 迁至麻谷 (Magok / 마곡) 的韩国第一演出场所
  • 特色: 音乐会·音乐剧·话剧·芭蕾 + 部分演出提供英文字幕
  • 详情: #175 麻谷 (Magok / 마곡)·金浦机场 (Gimpo International Airport / 김포공항) 姐妹篇

3. 世宗文化会馆 (Sejong Center for the Performing Arts / 세종문화회관) (Gwanghwamun / 광화문)

  • 地址: 钟路区 (Jongno-gu / 종로구) 世宗大路 (Sejong-daero / 세종대로) 175
  • 外国人 ★: ◎ — 韩国第一市立演出场所
  • 特色: 1978年开馆·音乐厅 (Concert Hall / 콘서트홀)·大剧场 (Grand Theater / 대극장) + 毗邻光化门广场 (Gwanghwamun Square / 광화문 광장)

② 大学路 (Daehangno / 대학로) 独立·音乐剧 (3)

4. ARKO 艺术剧场 (ARKO Arts Theater / 아르코예술극장) ★ 韩国独立音乐剧第一场所

  • 地址: 钟路区 (Jongno-gu / 종로구) 大学路 (Daehangno / 대학로) 100 (4号线 (Line 4) 惠化站 (Hyehwa Station / 혜화역)) (#170)
  • 外国人 ★: ◎ — 韩国独立·实验演出第一场所
  • 特色: 1981年开馆·1981年韩国第一公共独立演出场所 + 部分演出提供英文字幕

5. 东崇艺术中心 (Dongsoong Art Center / 동숭아트센터)

  • 地址: 钟路区 (Jongno-gu / 종no-gu) 大学路 (Daehangno / 대학로) 一带 (#170)
  • 外国人 ★: ◎ — 50+ 小剧场 (Small Theater / 소극장) 街区第一场所
  • 特色: 大学路 (Daehangno / 대학로) 独立音乐剧·话剧集群

6. 学田蓝色剧场 (Hakchun Blue / 학전블루)

  • 地址: 钟路区 (Jongno-gu / 종로구) 大学路 (Daehangno / 대학로) (#170)
  • 外国人 ★: ○ — 韩国独立演出第一场所 (1991年至今)
  • 特色: 韩国独立摇滚发源地 + 金光石 (Kim Kwang-seok / 김광석)·郑泰春 (Jeong Tae-chun / 정태춘)·寻找歌声的人们 (Nochatsa / 노찾사) 等韩国独立音乐第一场所

③ 电影院·IMAX (3)

7. CGV 龙山 I'PARK Mall (CGV Yongsan I'PARK Mall / CGV 용산아이파크몰) ★ IMAX 第一场所

  • 地址: 龙山区 (Yongsan-gu / 용산구) 汉江大路23街 (Hangang-daero 23-gil / 한강대로 23길) 55 (#187 龙山 (Yongsan / 용산))
  • 外国人 ★: ◎ — 韩国第一 IMAX·SoundX 影院
  • 特色: 韩国最大屏幕 + 外国人英文字幕

8. Megabox COEX (Megabox COEX / 메가박스 코엑스) (Gangnam / 강남)

  • 地址: 江南区 (Gangnam-gu / 강남구) 永东大路 (Yeongdong-daero / 영동대로) 513 COEX Mall (COEX Mall / 코엑스몰)
  • 外国人 ★: ◎ — COEX (COEX / 코엑스) 综合体·杜比影院 (Dolby Cinema)

9. 乐天影院世界大厦店 (Lotte Cinema World Tower / 롯데시네마 월드타워) (Jamsil / 잠실) ★ Superplex

  • 地址: 松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Olympic-ro / 올림픽로) 300 乐天世界购物中心 (Lotte World Mall / 롯데월드몰) (#82 蚕室 (Jamsil / 잠실))
  • 外国人 ★: ◎ — 韩国第一 Superplex + 乐天世界大厦 (Lotte World Tower / 롯데타워) 综合体

④ 电影节 (3 + 额外4)

10. 釜山国际电影节 (BIFF, Busan International Film Festival / 부산국제영화제)

  • 时间: 每年10月第一个星期 (为期10天)
  • 外国人 ★: ◎◎ — 亚洲第一电影节
  • 特色: 1996年创办·亚洲最大电影节·海云台 (Haeundae / 해운대) 电影殿堂 (Busan Cinema Center / 영화의전당)

11. 富川国际奇幻电影节 (BFFC, Bucheon International Fantastic Film Festival / 부천국제판타스틱영화제)

  • 时间: 每年7月
  • 外国人 ★: ◎ — 韩国第一奇幻·恐怖电影节
  • 特色: 1997年创办·外国人爱好者首选

12. 全州国际电影节 (JIFF, Jeonju International Film Festival / 전주국제영화제)

  • 时间: 每年4月~5月
  • 外国人 ★: ◎ — 韩国第一独立·实验电影节
  • 特色: 2000年创办·外国人爱好者深度探索

+ 额外4

  • 首尔环境电影节 (Seoul Eco Film Festival / 서울 환경영화제) (5月) — 韩国第一环境电影节
  • 首尔国际骄傲电影节 (Seoul International Pride Film Festival / 서울국제프라이드영화제) (11月)
  • 首尔国际舞蹈节 (Seoul International Dance Festival / 서울 국제 댄스 페스티벌) (10月)
  • 独立摇滚俱乐部街区 (弘大 (Hongdae / 홍대)) — #138 弘大 (Hongdae / 홍대) 独立音乐第一场所

⚙ 常见问题 (FAQ) 6个

1. 预订: 售票网站提供英文用户界面 (UI) (Interpark / 인터파크·Yes24 / 예스24·Ticketlink / 티켓링크)。外国人支付无障碍。

2. 英文字幕: LG 艺术中心 (LG Arts Center / LG 아트센터)·艺术殿堂 (Seoul Arts Center / 예술의전당)·世宗文化会馆 (Sejong Center for the Performing Arts / 세종문화회관) 部分综合演出提供。

3. 大学路 (Daehangno / 대학로) 独立舞台: 主要以韩语为主，但无语言障碍的舞蹈·爵士乐演出也可。

4. 电影院外国人观影: 几乎所有电影院都提供英文字幕。

5. 国际电影节: BIFF (10月 釜山 (Busan / 부산))·BFFC (7月 富川 (Bucheon / 부천))·JIFF (4~5月 全州 (Jeonju / 전주))。

6. 韩国第一演出·电影爱好者一日游: 艺术殿堂 (Seoul Arts Center / 예술의전당) 翰伽蓝美术馆 (Hangaram Art Museum / 한가람미술관) + 演出 + 结合 LG 艺术中心 (LG Arts Center / LG 아트센터)·CGV IMAX。

🗺 一日游路线

A. 韩国演出全天: 10:00 艺术殿堂 (Seoul Arts Center / 예술의전당) 翰伽蓝美术馆 (Hangaram Art Museum / 한가람미술관) + 演出 → 14:00 大学路 (Daehangno / 대학로) ARKO (ARKO / 아르코)·东崇 (Dongsoong / 동숭) → 18:00 LG 艺术中心 (LG Arts Center / LG 아트센터) (麻谷 (Magok / 마곡)) 或 世宗文化会馆 (Sejong Center for the Performing Arts / 세종문화회관) → 21:00 CGV 龙山 IMAX (CGV Yongsan IMAX / CGV 용산 IMAX)
