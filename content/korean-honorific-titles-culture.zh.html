韩国称谓文化 — 为什么韩国人会称初次见面的人为“姐姐”、“阿姨”或“老板”

拟亲属称谓 (fictive kinship terms of address / 의제가족 호칭)、姐姐 (eonni / 언니) / 哥哥 (oppa / 오빠) / 哥哥 (hyeong / 형) / 姐姐 (nuna / 누나)、阿姨 (imo / 이모)、老板 (sajangnim / 사장님)、这里 (yeogiyo / 여기요) — 专为外国人准备的韩国称谓文化解读。本文并非“学习敬语 (jondaetmal / 존댓말)”，而是探讨“为什么韩国人对陌生人使用家庭称谓，以及在餐厅和商店应该如何称呼”。

在首尔的一家小吃店 (bunsikjip / 분식집)。一位外国游客举手想点紫菜包饭 (gimbap / 김밥)，而旁边坐着的韩国朋友却对着服务员喊道：“阿姨 (imo / 이모)~ 给我一份紫菜包饭 (gimbap / 김밥)！” 外国游客大吃一惊。刚才他把那个人叫做“aunt (imo / 이모)”？他们是家人吗？ 不，他们完全是陌生人。在咖啡馆里，看起来年龄相仿的店员被称为“老板 (sajangnim / 사장님)”，常去的服装店老板是“姐姐 (eonni / 언니)”，出租车司机大叔则自然地被称为“叔叔 (samchon / 삼촌)”。在外国人看来，韩国似乎是一个毫无血缘关系的人们之间也普遍使用家庭称谓的国家。

语言学中有一个正式术语来指代这种现象 — 拟亲属称谓 (fictive kinship terms of address / 의제가족 호칭)。它是指对并非实际亲属的人使用亲属称谓 (如：姐姐 (eonni / 언니)、阿姨 (imo / 이모)、叔叔 (samchon / 삼촌) 等) 的现象。有趣的是，在类似的儒家文化圈 (包括部分东南亚地区) 中也存在这种用法，但研究表明，其范围像韩国这样广泛的国家却很少见。本文并非“韩语敬语 (jondaetmal / 존댓말) 课程”。这里要探讨的是为什么韩国人会称陌生人为家人，其背后的心理和意义是什么，以及作为外国人的我，在餐厅和商店应该如何称呼。这是韩国文化解读系列第19篇。

★ 一目了然 — 谁 → 如何称呼谁

拟亲属称谓 (fictive kinship terms of address / 의제가족 호칭) 的核心：“我的性别” 和 “对方比我年长/年幼” 决定了称谓。

称呼者 称呼年长男性 称呼年长女性 称呼年幼者
女性 哥哥 (oppa / 오빠) 姐姐 (eonni / 언니) 弟弟/妹妹 (dongsaeng / 동생)
男性 哥哥 (hyeong / 형) 姐姐 (nuna / 누나) 弟弟/妹妹 (dongsaeng / 동생)
对方 常用称谓 称呼对象
亲切的中年女性 阿姨 (imo / 이모) 餐厅服务员、社区阿姨
亲切的中年男性 叔叔 (samchon / 삼촌) / 大叔 (ajeossi / 아저씨) 出租车司机、社区大叔
商店·餐厅老板 (通用) 老板 (sajangnim / 사장님) 咖啡馆、餐厅、商店的任何人
值得尊敬的对象 (中立) 老师 (seonsaengnim / 선생님) 陌生成人、普通专业人士
姓名后敬语表达 -nim (님) / -ssi (씨) 无头衔的成年人 (-ssi (씨) 用于同辈或晚辈)

核心要点：即使是同样的“姐姐 (eonni / 언니) / 阿姨 (imo / 이모)”，如果将对方视为同辈，则称呼“姐姐 (eonni / 언니) / 哥哥 (oppa / 오빠)”；如果视为母亲辈，则称呼“阿姨 (imo / 이모) / 大妈 (ajumma / 아줌마)”。一个称谓中蕴含着“我将您视为多少岁” 的信息 — 因此非常微妙 (见下文 ④)。

⚠️ 外国人常有的3个误解

1. “以为称呼‘姐姐 (eonni / 언니) / 阿姨 (imo / 이모)’就是真家人” ❌ — 在韩国，家庭称谓是对陌生人也常使用的亲切社会称谓。餐厅的“阿姨 (imo / 이모)”和顾客并非家人。它只是一个表示“距离感和亲近感” 的工具，而非血缘关系。

2. “称谓只是一个词，随便用哪个都行” ❌ — 在韩国，称谓是确定关系定位的信号。直接称呼长辈的名字或使用错误的称谓可能会被视为无礼。因此，韩国人在初次见面时会先询问年龄 (见下文 ④)。

3. “这篇文章最终还是在讲‘韩国有敬语 (jondaetmal / 존댓말)’吧” ❌ — 敬语 (jondaetmal / 존댓말) (或称敬语 (nopimmal / 높임말)) 是关于如何结束句子 的问题，而本文的重点是“如何称呼对方 (称谓 / hoching / 호칭)”。两者虽相伴而行，但属于不同层面。这里我们专注于称谓 (hoching / 호칭)。

① 什么是拟亲属称谓 — 将“陌生人”称为“家人”的用法

拟亲属称谓 (fictive kinship terms of address / 의제가족 호칭)，顾名思义，就是“假装是家人 (拟制) 的称谓”。它指的是对并非实际亲属的人使用姐姐 (eonni / 언니)、哥哥 (oppa / 오빠)、哥哥 (hyeong / 형)、姐姐 (nuna / 누나)、阿姨 (imo / 이모)、叔叔 (samchon / 삼촌)、奶奶 (halmeoni / 할머니) 等亲属称谓。

  • 在英语国家，通常称呼陌生人时会说“Excuse me”或直呼其名，社会关系从水平 (equal) 开始。年龄通常只是在对话中偶然提及，很少决定说话的语气。
  • 韩国则相反。关系首先被定位为垂直 (年长–年幼)，并通过称谓来表示这种位置。因此，即使是“陌生人”也会自然地使用家庭称谓。
  • 研究表明，这种亲属称谓的普遍扩展一直在进行，特别是“阿姨 (imo / 이모)”、“叔叔 (samchon / 삼촌)”和“姐姐 (eonni / 언니)”已成为称呼服务业从业人员的常用语。

也就是说，韩国人称呼餐厅服务员为“阿姨 (imo / 이모)”，是一种试图为陌生关系披上家庭般亲近和温暖的语言习惯。这与韩国人试图用“我们 (uri / 우리)”来维系共同体意识 (→ #1135 情感文化) 的根源相同。

② 姐姐 (eonni / 언니) / 哥哥 (oppa / 오빠) / 哥哥 (hyeong / 형) / 姐姐 (nuna / 누나) — 我的性别改变称谓

这是外国人最容易混淆的部分。即使是同样的“姐姐 (eonni / 언尼) (或姐姐 (nuna / 누나))”，根据称呼者的性别，词语也会不同。

  • 女性 称呼年长男性 → 哥哥 (oppa / 오빠)，称呼年长女性 → 姐姐 (eonni / 언니)
  • 男性 称呼年长男性 → 哥哥 (hyeong / 형)，称呼年长女性 → 姐姐 (nuna / 누나)
  • 称呼年幼者，无论性别 → 弟弟/妹妹 (dongsaeng / 동생)

也就是说，即使是同一个人 (例如：比我年长的女性)，如果我是女性，会称呼“姐姐 (eonni / 언니)”；如果我是男性，则称呼“姐姐 (nuna / 누나)”。与英语的 brother/sister 不同，称呼者的性别也被嵌入到称谓中。K-剧和K-pop粉丝可能已经听过“哥哥 (oppa / 오빠)” — 这就是该称谓
