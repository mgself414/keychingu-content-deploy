副标题:文化体育观光部·韩国观光公社“名胜发掘 100×100”国民投票“济州小火山”主题入选的地方中的20处 · 按登记值收门票的是城山日出峰(成人5,000韩元)·山君不离(成人7,000韩元)·拒文岳(成人2,000韩元) · 拒文岳周二休息，09:00~14:00每30分钟一班出发 · Saebyeol小火山到山顶约20分钟，Ttarabi小火山·Gunsan小火山·Baegyagi小火山约30分钟 — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

小火山(Oreum)是指济州的小型火山体的说法。韩国观光公社的介绍中写道，济州岛分布着360多座寄生火山。这份指南介绍的是其中在文化体育观光部·韩国观光公社“名胜发掘 100×100”(由旅游专家推荐候选地、国民投票选出)的“济州小火山”主题入选的53处中，在韩国观光公社旅游信息里确认了运营信息的20处。表中的排名和得票数就是这次投票的结果。

大部分免费，20处中有10处登记为全天开放。登记了费用的地方中，收门票的是城山日出峰·山君不离·拒文岳三处，Jeoji小火山没有登记费用值。拒文岳要按规定时间出发。山房山免费，但登记为只能参观从售票处到Sanbanggulsa寺 (Sanbanggulsa / 산방굴사) 的步道。

Sara小火山·Witse小火山·Andol小火山·Abu小火山·Gunsan小火山附有可能被管制，请电话咨询的提示，Sarabong (Sarabong / 사라봉) 附有请电话确认管制区域的提示。运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。

📍 登记了门票的三处 — 城山日出峰·山君不离·拒文岳

城山日出峰 (Seongsan Ilchulbong / 성산일출봉)(西归浦市 Seongsan-eup (Ilchul-ro 284-12 / 성산읍 일출로 284-12)，☎ 064-783-0959)海拔180m，是约5,000年前在海底水下喷发形成的火山体，属联合国教科文组织世界自然遗产。山顶有直径600m的火山口。原本是火山岛，后来沙子和砾石堆积，与陆地连在了一起。据韩国观光公社介绍，从山顶看日出，自古以来被誉为Yeongju十景 (Yeongju Sipgyeong / 영주 10경) 之首。

  • 开放时间:11~2月 06:00~18:00(售票截止 17:00)，3·4·9·10月 05:00~19:00(售票截止 18:00)，5~8月 04:30~20:00(售票截止 19:00)。
  • 休息日:每月第一个周一(遇公休日则顺延至次日)。
  • 费用(个人):成人5,000韩元，青少年·军人·儿童2,500韩元。停车:免费。
  • 导览:自然遗产讲解员导览 09:00~17:00(在游客咨询处等候)。登记为外语导览可提供中文。

山君不离 (Sangumburi / 산굼부리)(济州市 Jocheon-eup (Bijarim-ro 768 / 조천읍 비자림로 768)，☎ 064-783-9900)是周长超过2km的火山口，为天然纪念物。不喷出熔岩或火山灰、只发生爆发而仅留下一个坑的火山叫做 Maar (Maar / 마르)，据韩国观光公社介绍，韩国只有这一处。火山口内植被分为两部分，北侧崖壁是暖温带常绿阔叶林，南侧崖壁是温带落叶林群落。

  • 开放时间:3~6月·9~10月 09:00~18:40(入场截止 18:00)，7~8月·11~2月 09:00~17:40(入场截止 17:00)。截止时间可能随天气变化。
  • 休息日:全年无休。
  • 费用(个人):成人7,000韩元，青少年·儿童(满4岁以上)6,000韩元。满65岁以上出示身份证件为5,000韩元。

拒文岳 (Geomunoreum / 거문오름)(济州市 Jocheon-eup (Seongyo-ro 569-36 / 조천읍 선교로 569-36)，☎ 064-710-8981)因被森林覆盖、看上去发黑，也叫 Geomeun小火山 (Geomeun Oreum / 검은오름)。从火山口流出的熔岩形成了绵延约4km的山谷。

  • 开放时间:09:00~14:00，每30分钟一班出发。每天可参观11次，登记为详细参观时间请见官方网站。
  • 休息日:每周二，Seol·Chuseok连休。天气不好时全面管制。
  • 费用(个人):成人2,000韩元，青少年·军人1,000韩元，儿童1,000韩元。6岁以下和65岁以上免费。

📍 Seongsan·Gujwa·Pyoseon — 涉地可支·Yongnuni小火山·Darangswi小火山·Abu小火山·Andol小火山·Baegyagi小火山·Ttarabi小火山

涉地可支 (Seopjikoji / 섭지코지)(西归浦市 Seongsan-eup (Seopjikoji-ro 262 / 성산읍 섭지코지로 262)，☎ 064-784-2810)据韩国观光公社介绍，是在 Seongsan-eup Sinyang-ri (Sinyang-ri / 신양리) 海岸突出的地形。“Koji (Koji / 코지)”是表示岬角的济州方言。山坡上有古烽燧台 Hyeopjayeondae (Hyeopjayeondae / 협자연대)，它东北侧的山峰是由红色火山灰 (Songi / 송이) 构成的 Bulgeun小火山 (Bulgeun Oreum / 붉은오름)。通往山顶白色灯塔的路上铺设有铁楼梯。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Yongnuni小火山 (Yongnuni Oreum / 용눈이오름)(济州市 Gujwa-eup (Jongdal-nonggil / 구좌읍 종달논길)，☎ 济州旅游信息中心 (Jeju Gwangwang Jeongbo Center / 제주관광정보센터) 064-740-6000)海拔247.8m，高88m，周长2,685m。韩国观光公社的介绍写道，在360多座小火山中，唯独这里有3个火山口。春夏覆盖着草坪，秋冬覆盖着芒草。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

Darangswi小火山 (Darangswi Oreum / 다랑쉬오름)，又称 Wollangbong (Wollangbong / 월랑봉)(济州市 Gujwa-eup (Segwa-ri San 6 / 구좌읍 세화리 산6)，☎ 064-740-6000)是四面都是陡坡的圆锥形小火山。顶部有漏斗状的深火山口。据说因为火山口像月亮一样圆，所以得名Darangswi。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

Abu小火山 (Abu Oreum / 아부오름)(济州市 Gujwa-eup (Songdang-ri San 164-1 / 구좌읍 송당리 산164-1)，☎ 064-740-6000)介绍称不难走到小火山周围。山顶有像木瓢一样圆的火山口 (Gumburi / 굼부리)，里面圆形生长着柳杉。

  • 开放时间:部分区域可能禁止出入，请出发前电话咨询。休息日:全年无休。费用:免费。

Andol小火山 (Andol Oreum / 안돌오름)(济州市 Gujwa-eup (Songdang-ri San 66-2 / 구좌읍 송당리 산66-2)，☎ 064-740-6000)是有马蹄形火山口的草地小火山。火山口内侧只有被冲刷出沟的地方树木茂密，形成森林。

  • 开放时间:可能被管制，请出发前电话咨询。休息日:全年无休。费用:免费。

Baegyagi小火山 (Baegyagi Oreum / 백약이오름)(西归浦市 Pyoseon-myeon (Seongeup-ri San 1 / 표선면 성읍리 산1)，☎ 064-740-6000)据说因为药草生长得多而得名。爬30分钟左右就到山顶，会看到像圆形竞技场一样凹陷的火山口。沿着跑道形状的山顶，可以看到周边的多座小火山。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Ttarabi小火山 (Ttarabi Oreum / 따라비오름)(西归浦市 Pyoseon-myeon (Gasi-ri San 62 / 표선면 가시리 산62)，☎ 064-740-6000)由3个火山口和6座山峰构成。到山顶需要30分钟左右。据韩国观光公社介绍，芒草在10~11月开得最多，会留到冬天。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 Aewol·Hallim·Hangyeong — Saebyeol小火山·Geum小火山·Jeoji小火山

Saebyeol小火山 (Saebyeol Oreum / 새별오름)(济州市 Aewol-eup (Bongseong-ri San 59-8 / 애월읍 봉성리 산59-8)，☎ 济州旅游信息中心 (Jeju Gwangwang Jeongbo Center / 제주관광정보센터) 064-740-6000)据说因“像傍晚天空中的启明星一样孤零零地立着”而得名。有5座山峰。10月小火山上芒草盛开。到山顶需要20分钟左右。

  • 开放时间:全天开放。费用:免费。停车:可以。

Geum小火山 (Geum Oreum / 금오름)(济州市 Hallim-eup (Geumak-ri San 1-1 / 한림읍 금악리 산1-1)) 表高427.5m，周长2,861m。山顶有深52m的圆形火山口。登记信息显示，火山口内的湖以前水很多，现在湖底裸露。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

Jeoji小火山 (Jeoji Oreum / 저지오름)(济州市 Hangyeong-myeon，☎ 064-728-7952)是有周长约900m、深约60m的陡峭漏斗形火山口的小火山。山坡是以黑松为主的茂密森林。2007年在第8届“美丽森林全国大会 (Areumdaun Sup Jeonguk Daehoe / 아름다운 숲 전국대회)”上获得生命奖(大奖)。设有Jeoji小火山休息站 (Jeoji Oreum Hyugeso / 저지오름휴게소)和瞭望台。

  • 休息日:全年无休。开放时间和费用没有登记值。

📍 Andeok·Daejeong — 山房山·Gunsan小火山·松岳山

山房山 (Sanbangsan / 산방산)(西归浦市 Andeok-myeon (Sagye-ri San 16 / 안덕면 사계리 산16)，☎ 064-794-2940)是耸立在平坦地形上的穹顶形火山。从西南侧半山腰的 Sanbanggul窟 (Sanbanggul / 산방굴) 可以看到龙头海岸。因为是保护名胜的开放限制区域，登记为只能参观从售票处到Sanbanggulsa寺的步道。

  • 开放时间:09:00~17:50(入场截止 17:30)。可能随日落时间和天气变化或被管制。
  • 休息日:全年无休。费用:免费。停车:免费。

Gunsan小火山 (Gunsan Oreum / 군산오름)(西归浦市 Andeok-myeon (Changcheon-ri 564 / 안덕면 창천리 564)，☎ 064-740-6000)的路已铺装，步行需要30分钟左右。山顶有两块像角一样耸起的岩石。从山顶可以看到汉拿山、Jungmun旅游园区 (Jungmun Gwangwangdanji / 중문관광단지)、马罗岛、山房山。

  • 开放时间:部分路段可能被管制，请出发前电话咨询。休息日:全年无休。费用:免费。停车:Gunsan小火山停车场 (Gunsan Oreum Jucha-jang / 군산오름주차장)，免费。

松岳山 (Songaksan / 송악산)(西归浦市 Daejeong-eup (Songak Gwangwang-ro 421-1 / 대정읍 송악관광로 421-1)，☎ 西归浦市政府气候环境科 (Seogwipo-sicheong Gihuhwangyeong-gwa / 서귀포시청 기후환경과) 064-760-2917)是在第一个火山口里又形成第二个火山口的双重火山口火山。从济州Olle (Jeju Olle / 제주 올레) 10号线经过的环山路上，可以看到Hyeongjeseom岛 (Hyeongjeseom / 형제섬)、加波岛，远处还有马罗岛。路不险，但风很大。海岸悬崖上有15个第二次世界大战时日军动员济州人挖出的人工洞穴。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 汉拿山登山路线上的小火山与湿地小火山 — Sara小火山·Witse小火山·Mulyeongari小火山

Sara小火山 (Sara Oreum / 사라오름)(西归浦市 Namwon-eup (Sinrye-ri San 2-1 / 남원읍 신례리 산2-1)，☎ 064-740-6000)位于汉拿山 Seongpanak (Seongpanak / 성판악) 登山路线的南侧。火山口里积水形成山顶火口湖，湖周边于2011年被指定为名胜。韩国观光公社的介绍写道，海拔1,300m的结冰湖面和积雪景色蔚为壮观，所以有很多登山爱好者到访。

  • 开放时间:可能被管制，请电话咨询。休息日:全年无休。费用:免费。

Witse小火山 (Witse Oreum / 윗세오름)(济州市 Aewol-eup (Gwangnyeong-ri San 183-1 / 애월읍 광령리 산183-1)，☎ 汉拿山办公室 (Hallasan Samuso / 한라산 사무소) 064-713-9950)是沿着汉拿山 Yeongsil (Yeongsil / 영실) 登山路线相连的三座小火山。从上往下依次叫 Bulgeun小火山 (Bulgeun Oreum / 붉은오름)、Nuun小火山 (Nuun Oreum / 누운오름)、Jogeun小火山 (Jogeun Oreum / 족은오름)。春天杜鹃和映山红盛开。登山路旁有 Noru泉 (Noru Saem / 노루샘)。

  • 开放时间:部分路段可能被管制，请出发前电话咨询。休息日:全年无休。费用:免费。

Mulyeongari小火山 (Mulyeongari Oreum / 물영아리오름)(西归浦市 Namwon-eup (Taesu-ro 552 / 남원읍 태수로 552)，☎ 064-728-6200)是火山口里有湿地的小火山。2006年被指定为拉姆萨尔湿地。探访要先绕牧场走半圈才开始。登记为电影《狼少年 (Neukdae Sonyeon / 늑대소년)》的拍摄地。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。

📍 济州市区 — Sarabong

Sarabong (Sarabong / 사라봉)(济州市 (Sarabong-dong-gil 61 / 사라봉동길 61)，☎ 064-740-6000)是济州港东侧海边的小火山。从Sarabong看到的晚霞 Sabong落日 (Sabong Nakjo / 사봉낙조) 入选Yeongju十景 (Yeongju Sipgyeong / 영주십경)。从山顶向北可以看到大海，向南可以看到汉拿山，脚下是济州市区。一带是公园，设有八角亭。

  • 开放时间:全天开放(管制区域请出发前电话咨询)。休息日:全年无休。费用:免费。

⚠ 行前须知 3 点

  1. 拒文岳不能随时进入 — 09:00~14:00每30分钟一班出发，周二和Seol·Chuseok连休休息。
  2. 山房山的参观区间有规定 — 登记为只能参观从售票处到Sanbanggulsa寺的步道，可能随日落时间和天气被管制。
  3. 标有“可能被管制”的小火山，出发前先打电话 — Sara小火山、Witse小火山、Andol小火山、Abu小火山、Gunsan小火山登记为这样。Sarabong要电话确认管制区域，拒文岳在天气不好时全面管制。

⚙ FAQ 3

Q. 短时间就能登顶的小火山有哪些?

A. 登记信息中写有所需时间的地方是Saebyeol小火山(到山顶20分钟左右)、Ttarabi小火山(30分钟左右)、Baegyagi小火山(30分钟左右)、Gunsan小火山(步行30分钟左右)。

Q. 要花钱的地方有哪些?

A. 城山日出峰(成人5,000韩元)、山君不离(成人7,000韩元)、拒文岳(成人2,000韩元)。其余登记为免费，Jeoji小火山没有费用登记值。

Q. 哪里可以看芒草?

A. 韩国观光公社介绍中写到芒草的地方是Saebyeol小火山(10月)、Ttarabi小火山(10~11月开得最多，留到冬天)、Yongnuni小火山(秋·冬)。
