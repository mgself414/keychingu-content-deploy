🎯 本指南的使用方法

购物篮里方便面袋子沙沙作响，收银台前堆着要放进回国行李的零食盒。本指南按分店挑选了旅客容易顺路去的首尔大型超市和便利店。地址、营业时间、休息日，只采用今天直接从乐天玛特·易买得官方门店页面和VisitKorea旅游信息(TourAPI)读到的数值。便利店即食区的用法请看#1292 即食区手册，便利店各品牌的差异请看#1261 便利店四大品牌对比。

  • 乐天玛特Zetta Plex首尔站店 (Lotte Mateu Jetapeulleksseu Seoul-yeokjeom / 롯데마트 제타플렉스 서울역점) — 首尔中区 (Jung-gu / 중구) 汉江大路 (Hangang-daero / 한강대로) 405号。10:00~24:00，每月第二、第四个周三休息(2026年10月14日·28日)。电话 02-390-2500(乐天玛特官方门店查询)。退税方式 即时+事后，可刷卡(VisitKorea旅游信息)。有报道称设有免费行李寄存·行李箱打包台·外币兑换机·无人退税机[二手资料，韩国经济日报 (Hangukgyeongje / 한국경제) 2026-01-15]
  • 乐天玛特世界塔店 (Lotte Mateu Woldeutawojeom / 롯데마트 월드타워점) — 首尔松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Ollimpik-ro / 올림픽로) 300号(乐天世界商场 (Lotte Woldeumol / 롯데월드몰) 地下2层)。10:00~23:00，每月第二、第四个周日休息(2026年10月11日·25日)。电话 02-2057-2500(乐天玛特官方门店查询)。退税 即时+事后(VisitKorea旅游信息)
  • 易买得麻浦店 (Imateu Mapojeom / 이마트 마포점) — 首尔麻浦区 (Mapo-gu / 마포구) 白凡路 (Baekbeom-ro / 백범로) 212号。10:00~23:00。每月第二、第四个周日义务休业(2026年10月11日·25日，11月8日·22日)。5·6号线孔德站 (Gongdeok-yeok / 공덕역) 7号出口前，步行1分钟。客服中心 02-2197-1234(易买得官方门店页面)。退税 即时+事后(VisitKorea旅游信息)

📅 义务休业日的读法

  • 大型超市每月休息两次，但休息的星期因门店所在的区而异。上面5处中，中区的首尔站店·清溪川店在第二、第四个周三休息，麻浦·龙山·松坡的门店在周日休息(乐天玛特·易买得官方门店页面)。乐天玛特官方列表里，瑞草店 (Seocho-jeom / 서초점)·清凉里店 (Cheongnyangni-jeom / 청량리점)·行堂站店 (Haengdangyeok-jeom / 행당역점) 也是周三休息
  • 不要断定整个首尔在同一天休息，去之前先看该门店页面上的休息日
  • 夜间，首尔站店营业到24:00，其余4处到23:00(官方门店页面)

🥗 寻找清真·素食食品的方法

  • 素食: VisitKorea介绍，购物时分辨纯素产品最简单的方法是看包装上的"纯素认证标志"(VisitKorea素食旅行提示)。没有标志时，就在背面原料名里找猪肉·牛肉·鸡肉·明胶·凤尾鱼·虾·鱼露
  • 泡菜·小菜: 泡菜调料大多含有咸鱼酱 (Jeotgal / 젓갈)·鱼露·肉汤(VisitKorea素食旅行提示)。不要想当然地认为超市泡菜或便当小菜 (Banchan / 반찬) 是素食
  • 清真: 本指南11处的官方信息中，没有确认到清真认证专区的标注。VisitSeoul介绍梨泰院 (Itaewon / 이태원) 的Eid (Eid / 이드)(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15号，每天 12:00~21:00)是韩国伊斯兰教中央会 (KMF / 한국이슬람교중앙회) 认定的少数清真餐厅之一。认证可能变动，访问前请先确认。7-Eleven梨泰院2号店(乌沙坛路 (Usadan-ro / 우사단로) 46号)就在同一条乌沙坛路上
  • 展示用卡片请看#1300 饮食需求手册，素食餐厅请看#291 首尔素食纯素全攻略

🧰 超市·便利店实用信息 — 独自·支付·退税·行李·交通

  • 独自: 超市和便利店一个人去都不会不方便。自助收银和夜间无人店请看#1306 自助收银流程版
  • 支付: 便利店6处和乐天玛特2处、易买得麻浦店登记为可刷卡(VisitKorea旅游信息)。移动支付的整体介绍请看#527 支付系统
  • 退税: 乐天玛特首尔站店·世界塔店、易买得麻浦店登记为即时+事后退税(VisitKorea旅游信息)。结账时出示护照。流程请看#1231 退税指南
  • 行李: 超市没有寄存柜时，请看#1232 行李寄存指南
  • 交通: 首尔站店连着首尔站 (Seoul-yeok / 서울역)，易买得龙山店连着龙山站 (Yongsan-yeok / 용산역)(官方门店页面)。地铁请看#1298 三种交通卡怎么选。想与免税店要买的东西分开购买，请看#915 免税店指南

⚠ 常见的4个错误

1. "大型超市只在周日休息" — 易买得清溪川店·乐天玛特首尔站店在周三休息(官方门店页面)

2. "超市都开到午夜" — 营业到24:00的只有首尔站店，其余4处23:00打烊(官方门店页面)

3. "便利店都是24小时" — GS25南山首尔塔店是09:00~22:30(VisitKorea旅游信息)

4. "超市不能退税" — 乐天玛特首尔站店·世界塔店、易买得麻浦店登记为即时+事后退税(VisitKorea旅游信息)
