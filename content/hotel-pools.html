🎯 왜 서울 호텔 수영장 풀가이드인가

외국인 호캉스·MZ 인생샷 1순위 = 서울 5성급 호텔 수영장 12선. 여름 풀 + 인피니티 풀 + 한강·도심 view + 외국인 매니아 vlog 1번지. 7~9월 절정·연중 실내 풀 매니아.

★ 한눈에 12선

⚠ 외국인 자주 실수 5가지

1. "호텔 수영장 = 투숙객만": 일부 호텔 = 데이패스 (Day Pass) 외부 이용 OK (반얀트리 50K·신라 80K·콘래드 70K~ 표준). 미리 예약 필수.

2. "인피니티 풀 = 시그니엘만": 한국 인피니티 풀 1번지 = 반얀트리 (남산) + 시그니엘 (555m) + JW메리어트 동대문 + 호텔 나루 (한강) 4 매니아.

3. "여름만 운영": 야외 풀 7~9월·실내 풀 연중 (신라·반얀트리·시그니엘·콘래드·JW). 호캉스 연중 OK.

4. "호텔 풀 = 비쌈만": 가성비 매니아 = L7 홍대 (15~25만/박)·노보텔 동대문 (12~20만/박)·몬드리안 (20~30만) + 풀 포함 + 외국인 매니아.

5. "외국인 친화 = 럭셔리만": L7·노보텔·몬드리안·호텔 나루 = 외국인 친화 + 영문·중문·일문 풀세트 + MZ 인스타.

① 럭셔리 5성급 (5)

1. 반얀트리 클럽&스파 서울 ★ 한국 #1 인피니티 풀

  • 주소: 용산구 장충동2가 산5-5 (남산)
  • 외국인 ★: ◎◎ — 한국 1번지 인피니티 풀·외국인 인스타 #1
  • 시그니처: 남산 view 인피니티 풀 + 야외·실내·럭셔리 스파
  • 가격: 1박 60~100만원·데이패스 50K원~

2. 시그니엘 서울 (잠실 롯데타워 85F)

  • 주소: 송파구 올림픽로 300 (#82 잠실)
  • 외국인 ★: ◎◎ — 555m·세계 최고층 인피니티 풀
  • 시그니처: 85F 인피니티 + 잠실·한강·서울 panorama + 외국인 럭셔리 #1
  • 가격: 1박 80~150만원

3. 서울 신라호텔 ★ 1979 한국 정통

  • 주소: 중구 동호로 249
  • 외국인 ★: ◎◎ — 1979 한국 5성급 정통 1번지
  • 시그니처: 야외 풀 + 남산 view + 어반 아일랜드 (사파리)
  • 가격: 1박 50~80만원·데이패스 80K원

4. 포시즌스 호텔 서울 (광화문)

  • 주소: 종로구 새문안로 97
  • 외국인 ★: ◎◎ — 광화문 + 외국인 럭셔리
  • 시그니처: 인도어 풀 + 광화문·경복궁 view

5. 콘래드 서울 (여의도)

  • 주소: 영등포구 국제금융로 10 (#169 여의도)
  • 외국인 ★: ◎◎ — 한강·여의도 panorama
  • 시그니처: 인도어 풀 + 한강 view + 외국인 럭셔리

② 한강·도심 view (3)

6. 그랜드 하얏트 서울 (용산 소월로 322)

  • 주소: 용산구 소월로 322 (남산 자락)
  • 외국인 ★: ◎◎ — 야외 풀 + 남산 view + 외국인 매니아 1번지
  • 시그니처: 야외 풀 (여름 절정)·남산 자락 위치·외국인 vlog #1
  • 가격: 1박 40~70만원

7. 그랜드 인터컨티넨탈 파르나스 (강남)

  • 주소: 강남구 테헤란로 521 (COEX #142)
  • 외국인 ★: ◎◎ — COEX·강남 인접·외국인 매니아
  • 시그니처: 인도어 풀 + 강남·COEX 외국인 매니아

8. 호텔 나루 서울 엠갤러리 (마포 마포대로 8)

  • 주소: 마포구 마포대로 8 (마포·공덕 #188)
  • 외국인 ★: ◎◎ — Accor MGallery·한강 view·외국인 매니아
  • 시그니처: 한강 view·MGallery 럭셔리 부티크·외국인 인스타

③ 인스타·MZ (3)

9. JW메리어트 동대문 스퀘어 서울

  • 주소: 종로구 청계천로 279 (#172 동대문)
  • 외국인 ★: ◎◎ — DDP·동대문 view·인피니티 풀
  • 시그니처: 동대문성곽 + DDP view 인피니티 풀

10. 몬드리안 서울 이태원 (장문로 23)

  • 주소: 용산구 장문로 23 (#144 이태원)
  • 외국인 ★: ◎◎ — 부티크·MZ·외국인 인스타
  • 시그니처: 이태원 부티크·외국인 매니아·MZ 인스타·풀 + 루프탑

11. L7 홍대 바이 롯데 (양화로 141)

  • 주소: 마포구 양화로 141 (#138 홍대)
  • 외국인 ★: ◎◎ — 홍대 1번지·MZ·외국인 매니아
  • 시그니처: 홍대 도심 부티크·MZ·외국인 매니아·L7 루프탑 + 풀
  • 가격: 1박 15~25만원 가성비

④ 가성비·MZ (1 + 추가 4)

12. 노보텔 앰배서더 동대문 (을지로 238)

  • 주소: 중구 을지로 238 (#172 DDP·동대문)
  • 외국인 ★: ◎◎ — DDP 인접·외국인 매니아·MZ 가성비
  • 시그니처: 인도어 풀·DDP·동대문 야시장 인접·외국인 매니아
  • 가격: 1박 12~20만원 가성비

+ 추가 4

  • 페어몬트 앰배서더 서울 (여의도) — 2021 신축·한강 view·인피니티 풀
  • 안다즈 강남 — Hyatt 럭셔리·강남 MZ·외국인 매니아
  • 롯데호텔 본점 (명동) — 한국 정통 5성·외국인 매니아
  • 웨스틴 조선 서울 (시청·광화문) — 한국 #1 호텔 1914·외국인 정통

⚙ FAQ 6개

1. 외국인 호캉스 1순위: 반얀트리·시그니엘·신라·콘래드·그랜드 하얏트.

2. 외국인 데이패스 (Day Pass): 반얀트리 50K·신라 80K·콘래드 70K~ + 사전 예약.

3. 외국인 인피니티 풀: 반얀트리·시그니엘·JW메리어트·호텔 나루 4 매니아.

4. 외국인 가성비: L7 홍대·노보텔 동대문·몬드리안 15~30만/박.

5. 외국인 인스타: 시그니엘 555m·반얀트리 남산·JW DDP·몬드리안 부티크.

6. 외국인 가족·자녀 (#232 가족): 그랜드 하얏트·신라 (어반 아일랜드)·롯데호텔·인터컨티넨탈.

🗺 외국인 풀데이 코스 3개

A. 럭셔리 호캉스 1박 (반얀트리·시그니엘·신라)

  • 14:00 체크인 → 15:00 풀·스파 → 19:00 호텔 다이닝 → 23:00 야경 풀 → 익일 12:00 체크아웃

B. MZ 호캉스 1박 (L7 홍대·몬드리안)

  • 15:00 체크인 → 17:00 풀·루프탑 → 19:00 홍대·이태원 외출 → 23:00 야경 풀

C. 외국인 가족 호캉스 (신라·하얏트·인터컨티넨탈)

  • 14:00 체크인 → 15:00 풀·키즈 클럽 → 19:00 패밀리 다이닝 → 익일 09:00 조식·풀

🌸 시즌 5

  • 봄 4~5월: 야외 풀 오픈 시작 + 호캉스 시즌
  • 여름 6~8월: 야외 풀 절정·외국인 인스타 1순위 (1박 사전 예약 필수)
  • 가을 9~10월: 야외 풀 마감 + 실내 풀·스파 매니아
  • 겨울 12~2월: 실내 풀 + 호텔 일루미네이션·연말 호캉스
  • 연중: 실내 풀 (신라·반얀트리·시그니엘·콘래드·JW·인터컨티넨탈)
