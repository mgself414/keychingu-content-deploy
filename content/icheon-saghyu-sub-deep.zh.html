利川Sagimakgol陶艺村指南 — 陶瓷传统市场、Deulkkotmaeul陶艺工坊体验、利川陶瓷节

副标题：Sagimakgol陶艺村 (Sagimakgol Doyecheon / 사기막골 도예촌)（11:00~18:00，全年无休） · Deulkkotmaeul陶艺工坊 (Doyegongbang Deulkkotmaeul / 도예공방 들꽃마을)（10:00~18:00，休息12:00~13:00，全年无休） · 利川陶瓷节 (Icheon Dojagi Chukje / 이천도자기축제)（2026年第40届 4/24~5/5，免费） — 已确认韩国观光公社旅游信息（TourAPI）

🎯 如何使用这份指南

Sagimakgol陶艺村 (Sagimakgol Doyecheon / 사기막골 도예촌)是国家认定的传统市场，按观光公社的介绍，是全国唯一以陶瓷这一单一品类构成的传统市场。"Sagimakgol (Sagimakgol / 사기막골)"的意思是"曾有烧制陶瓷的窑棚的地方"。

这份指南只介绍Sagimakgol陶艺村、Sindun-myeon (신둔면)的体验工坊和利川陶瓷节，营业信息照录韩国观光公社旅游信息（TourAPI）登记的数值。利川陶瓷艺术村 (Icheon Dojayesul Maeul, Yespark / 이천도자예술마을, 예스파크)·陶艺村米饭街 (Ssalbap Georigil / 쌀밥거리)·京畿陶瓷美术馆 (Gyeonggi Dojamisulgwan / 경기도자미술관)整理在#673 利川指南中。

🏺 Sagimakgol陶艺村 — 陶瓷单一品类传统市场

Sagimakgol陶艺村 (Sagimakgol Doyecheon / 사기막골 도예촌)（利川市 Gyeongchung-daero 2993beon-gil 56 (Gyeongchung-daero / 경충대로2993번길)，Sa-eum-dong (사음동)，☎ 031-638-8388）是被雪峰山 (Seolbongsan / 설봉산)环抱的村庄。按观光公社的介绍，这里容易找到制作陶瓷所需的黏土、窑、木柴和釉料原料。

  • 看点：穿过有雕塑的入口，从传统瓷器到生活瓷器，各种陶瓷一字排开。把窑址当游乐场长大的本地陶艺家，和在大学、陶瓷业高中学习陶艺的陶艺家聚在一起，各自推出自己的作品。
  • 营业时间：11:00~18:00，全年无休。
  • 停车：可以。

🖐 Deulkkotmaeul陶艺工坊 — 体验与住宿

Deulkkotmaeul陶艺工坊 (Doyegongbang Deulkkotmaeul / 도예공방 들꽃마을)（利川市 Sindun-myeon (신둔면) Dojayesul-ro 5beon-gil 95 (Dojayesul-ro / 도자예술로5번길)，☎ 010-7335-6832）是2001年5月1日开业的工坊，同时提供制作陶瓷的体验和住宿。按观光公社的介绍，由在大学、研究生院主修陶瓷的老师指导，从幼儿园小朋友到外国人、团体、老人，按水平因材施教。

  • 设施：庭院、草坪场、画廊工坊楼、展示室。
  • 营业时间：10:00~18:00（休息 12:00~13:00），全年无休。
  • 停车：可以。
  • 周边：雪峰公园 (Seolbong Park / 설봉공원)、利川温泉 (Icheon Oncheon / 이천온천)、山茱萸村 (Sansuyu Maeul / 산수유마을)。

📅 利川陶瓷节 — 2026年4/24~5/5

利川陶瓷节 (Icheon Dojagi Chukje / 이천도자기축제)2026年第40届在利川陶瓷艺术村和Sagimakgol陶艺村一带，于4月24日~5月5日 10:00~18:00免费举办。主办方是利川市和利川文化财团 (Icheon Munhwa Jaedan / 이천문화재단)（☎ 031-645-3683）。

  • 展览：名匠作品展、当代艺术家征集展、特别展、外国艺术家邀请展览·演示、韩国陶瓷技术院展。
  • 售卖：观光公社的节目介绍中列有240多家陶艺工坊参加的陶瓷展览·售卖。
  • 体验：拉坯体验、制作陶瓷杯、在大型陶瓷上写心愿、陶瓷游乐场。
  • 附带活动：名匠工作坊、露天烧制陶瓷制作、名品陶瓷拍卖、寺院饮食演示·试吃。

⚠ 常见的3个失误

  1. 一大早去Sagimakgol — 登记的营业时间从11:00开始。
  2. 赶在午饭时间去Deulkkotmaeul — 12:00~13:00是休息时间。
  3. 把Sagimakgol和Yespark当成同一个地方 — Sagimakgol陶艺村在Sa-eum-dong，利川陶瓷艺术村（Yespark）在Sindun-myeon，地址不同。

A. 观光公社信息中登记为全年无休。

Q. 节日期间有门票吗？

A. 2026年利川陶瓷节登记为免费。
