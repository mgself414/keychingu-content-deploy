🎯 如何使用这份指南

这份指南汇集了首尔西部的大型公园。分别是把垃圾填埋场兰芝岛改造而成的世界杯公园及其中的Haneul公园·Noeul公园、曾是净水场的仙游岛公园、建在空军士官学校旧址上的Boramae公园，以及Noeul·Haneul公园一段的首尔环城步道15路线。全部登记为全年无休。汉江公园在#706 汉江公园指南中。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 世界杯公园 — 世界杯公园·Haneul公园·水杉森林路·Noeul公园

世界杯公园(Worldcup Gongwon / 월드컵공원)，麻浦区(World Cup-ro 243-60 / 월드컵로 243-60)，☎ 02-300-5500，是为纪念2002年世界杯和新千年，把1978年到1993年15年间埋过首尔垃圾的兰芝岛(Nanjido / 난지도)填埋场改造成的公园。面积为270万㎡，由和平公园(Pyeonghwa Gongwon / 평화의 공원)、Haneul公园、Noeul公园、兰芝川公园(Nanjicheon Gongwon / 난지천공원)、兰芝汉江公园(Nanji Hangang Gongwon / 난지한강공원)五个主题公园组成。有92种73万3千棵树，还有展示兰芝岛历史的世界杯公园展览馆(Worldcup Gongwon Jeonsigwan / 월드컵공원 전시관)和可以观鸟的兰芝池塘(Nanji Yeonmot / 난지연못)。

  • 开放时间:每月不同。休息日:全年无休。
  • 停车:可以。婴儿车租赁:没有。

Haneul公园(Haneul Gongwon / 하늘공원)，麻浦区(Haneulgongwon-ro 95 / 하늘공원로 95)，☎ 世界杯公园 02-300-5500，按观光公社介绍，是世界杯公园中离天空最近的公园，展现了填埋场贫瘠的土地回归自然的样子。有芒草种植地、混生草地、岩石园、向日葵种植地、观景休息处和风力发电机。秋天银色的芒草花盛开，可以看到北汉山(Bukhansan / 북한산)和汉江，以日落和夜景闻名。

  • 开放时间:05:00~20:30。休息日:全年无休。停车:可以。

Haneul公园水杉森林路(Haneul Gongwon Metasekwoia Supgil / 하늘공원 메타세쿼이아 숲길)，麻浦区(Sangam-dong / 상암동)，☎ 西部公园休闲中心(Seobu Gongwon Yeoga Senteo / 서부공원여가센터) 02-300-5501，是1999年在Haneul公园东侧步道450m和南侧步道900m建成的可观赏水杉的路。2023年在东侧路下方建成了庭园式绿地，在南侧步道建成了四季花路。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

Noeul公园(Noeul Gongwon / 노을공원)，麻浦区(Sangam-dong / 상암동)，☎ 世界杯公园 02-300-5500，是在宽阔的草坪上设有雕塑和观景台的公园，按观光公社介绍，不少人为了日落时的景色而来。有公园高尔夫球场(Pakeu Golpeujang / 파크골프장)、Noeul露营场(Noeul Kaemping-jang / 노을캠핑장)、蚕生态体验场(Nuae Saengtae Cheheomjang / 누에생태체험장)、萤火虫生态馆(Bandibul-i Saengtaegwan / 반딧불이생태관)、都市农夫花园(Dosi Nongbu Jeongwon / 도시농부정원)。

  • 开放时间:05:30~20:00。休息日:全年无休。停车:可以。

📍 汉江岛 — 仙游岛公园

仙游岛公园(Seonyudo Gongwon / 선유도공원)，永登浦区(Seonyu-ro 343 / 선유로 343)，☎ 02-2631-9367~8，位于汉江中间的小山峰岛仙游岛上。1978年到2000年是给首尔西南部供应自来水的净水场，2002年4月再生为生态公园。有用送水泵房改造的展览馆故事馆(Iyagigwan / 이야기관)、拆掉净水池屋顶只留下柱子的绿色柱子花园(Noksaek Gidung-ui Jeongwon / 녹색기둥의 정원)、水生植物净化水质的水质净化园(Sujil Jeonghwawon / 수질정화원)，以及四个圆形空间。从汉江南侧经步行桥(Seonyugyo / 선유교)进入。

  • 开放时间:06:00~24:00。休息日:全年无休。
  • 停车:不可以。

📍 铜雀 — Boramae公园

Boramae公园(Boramae Gongwon / 보라매공원)，铜雀区(Yeouidaebang-ro 20-gil 33 / 여의대방로20길 33)，☎ 02-2181-1114，是1985年起整修空军士官学校旧址，于1986年5月5日开放的公园。名字来自空军士官学校的象征Boramae(Boramae / 보라매)。有运动设施和休息处。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

📍 步行路线 — 首尔环城步道15路线Noeul·Haneul公园线路

首尔环城步道15路线Noeul·Haneul公园线路(Seoul Dullegil 15-Koseu Noeul·Haneul Gongwon Koseu / 서울둘레길 15코스 노을·하늘공원코스)，江西区(Gayang-dong / 가양동)，☎ 02-779-7902~4，是在全长156.5km、共21条路线环绕首尔一周的首尔环城步道(Seoul Dullegil / 서울둘레길)中，以“复原的自然之路”为主题的路线。经过加阳大桥(Gayang Daegyo / 가양대교)时可以看到汉江和江南。靠近地铁Gayang站(Gayang-yeok / 가양역)、Jeungsan站(Jeungsan-yeok / 증산역)。

  • 长度·时间:共7.7km，约2小时10分钟。开放时间:全天开放。

⚠ 行前须知 3 点

  1. Haneul公园05:00~20:30开放，Noeul公园05:30~20:00开放 — 世界杯公园整体的时间每月不同。
  2. 仙游岛公园不能停车 — 06:00~24:00开放，经步行桥进入。
  3. 首尔环城步道15路线约需2小时10分钟 — 全长7.7km，靠近Gayang站·Jeungsan站。

⚙ FAQ 2

Q. 想看芒草应该去哪里?

A. 按观光公社登记信息，世界杯公园内的Haneul公园设有芒草种植地，秋天银色的芒草花盛开。05:00~20:30开放。

Q. 净水场变成公园的地方是哪里?

A. 是仙游岛公园。1978~2000年是净水场，2002年4月再生为生态公园。06:00~24:00开放，不能停车。
