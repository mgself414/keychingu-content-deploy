全部指南 › 漫步清潭洞：路易威登之家与迪奥之家建筑，松隐、路易威登艺术空间、爱马仕工作室画廊，岛山公园

漫步清潭洞 (Cheongdam-dong / 청담동)：路易威登之家与迪奥之家建筑，松隐、路易威登艺术空间、爱马仕工作室画廊，岛山公园 (2026年10月核实)

副标题：弗兰克·盖里 (Frank Gehry / 프랭크 게리) 设计的路易威登首尔之家 (Louis Vuitton Maison Seoul / 루이비통 메종 서울) 于2019年10月开馆 (路易威登官方)，松隐 (SongEun / 송은) 周一至周六 11:00~18:30 免费 (松隐官方)，首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울) 位于4层，免费但须提前预约 (Visit Gangnam)，岛山公园 (Dosan Park / 도산공원) 全天开放 (VisitKorea)，截至 2026-10-22

ISSUE 03 · #296 · 2026-05-20

🎯 本指南的用法

走过狎鸥亭路 (Apgujeong-ro / 압구정로) 上光洁的玻璃外立面，只要拐进一条小巷，混凝土建筑里就会映出松树的影子，再往前走一点，脚下便是岛山公园 (Dosan Park / 도산공원) 的泥土小径。本指南写给想把清潭洞 (Cheongdam-dong / 청담동) 当作可以边走边看的街区，而不只是购物的人。路线分三条：奢侈品旗舰店建筑(从外面欣赏的建筑)，画廊(奢侈品大楼里或旁边的免费与收费展览空间)，岛山公园 (Dosan Park / 도산공원)(公园与纪念馆)。地址，时间，门票只写了我们直接打开官方机构与品牌页面，江南区旅游网站 Visit Gangnam，VisitKorea TourAPI 后确认的数值，没有查到的数值都写作“未能确认”。

店内买什么，免税与退税怎么办理，本篇不涉及，请看外国游客江南 (Gangnam / 강남) 奢侈品购物 12 个 cluster 深度指南。

🏛 旗舰店建筑：从外面欣赏清潭

品牌独栋建筑位于狎鸥亭路 (Apgujeong-ro / 압구정로) 454~464号和岛山大路45街 (Dosan-daero 45-gil / 도산대로45길)。本篇不涉及价格与库存。

  • 路易威登首尔之家 (Louis Vuitton Maison Seoul / 루이비통 메종 서울)：首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 454号。由弗兰克·盖里 (Frank Gehry / 프랭크 게리) 设计，2019年10月开馆。每天11:00~21:00，1月1日，春节 (Seollal / 설날) 和中秋 (Chuseok / 추석) 当天休息 (路易威登官方门店页面)。顶层有艺术展览空间首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울)(见下面的画廊部分)
  • 迪奥之家 (House of Dior / 하우스 오브 디올)：首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 464号。外观像白色花苞一样弯出曲线，是6层的独栋精品店，5层有迪奥咖啡厅 (Café Dior / 카페 디올)。周一至周六11:00~20:00，周日11:00~19:00，电话 02-513-0300 (Visit Gangnam)。VisitKorea TourAPI 写的是每天 11:00~20:00，各来源不一致，周日去之前请打电话确认。7号线清潭站 (Cheongdam Station / 청담역) 很近 (Visit Gangnam)
  • 古驰清潭旗舰店 (Gucci Cheongdam Flagship / 구찌 청담 플래그십)：首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 462号。每天 11:00~20:00，传统节日休息 (VisitKorea TourAPI)。
  • 普拉达清潭店 (Prada Cheongdam / 프라다 청담점)：首尔江南区 (Gangnam-gu / 강남구) 狎鸥亭路 (Apgujeong-ro / 압구정로) 463号，1~2层。每天 11:00~20:00，传统节日休息 (VisitKorea TourAPI)。
  • 爱马仕之家岛山公园店 (Maison Hermès Dosan Park / 메종 에르메스 도산 파크)：首尔江南区 (Gangnam-gu / 강남구) 岛山大路45街 (Dosan-daero 45-gil / 도산대로45길) 7号。由法国设计事务所 RDAI 设计，2006年开馆 (爱马仕基金会官方)。与岛山公园 (Dosan Park / 도산공원) 在同一条岛山大路45街 (Dosan-daero 45-gil / 도산대로45길) 上。爱马仕官方页面打不开，所以门店营业时间未能确认

🖼 画廊：奢侈品大楼里的展厅

清潭，新沙一带的艺术空间大多免费，但各自的休馆日不同。安排行程时最先要看的是星期几。

  • 首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울)：位于路易威登首尔之家 (Louis Vuitton Maison Seoul / 루이비통 메종 서울) 4层〔狎鸥亭路 (Apgujeong-ro / 압구정로) 454号〕。12:00~19:00，1月1日，春节 (Seollal / 설날)，中秋 (Chuseok / 추석) 休馆。入场免费，但须提前预约。以路易威登基金会的藏品举办巡回展 (Visit Gangnam)。目前正在展出的展览名称未能确认，请到预约页面查看
  • 松隐 (SongEun / 송은)：首尔江南区 (Gangnam-gu / 강남구) 岛山大路 (Dosan-daero / 도산대로) 441号。这是赫尔佐格和德梅隆 (Herzog & de Meuron / 헤르조그 & 드 뫼롱) 在韩国建造的第一座建筑 (松隐官方)。周一至周六 11:00~18:30(入场截止 18:10)，周日与公休日休息，布展期间也休息。所有展览免费。自由参观与导览团(周一至周六 15:00，17:00)通过 Naver 预约。不能停车。从7号线清潭站 (Cheongdam Station / 청담역) 8号出口步行15分钟，从水仁盆唐线狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 4号出口步行13分钟。下一场展览是《LIGHT, FORM AND VISION: Roman Heritage in Dialogue with Korean Contemporary Art》(2026年10月29日~11月14日)(松隐官方)。电话 02-3448-0100
  • 爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스)：位于爱马仕之家岛山公园店 (Maison Hermès Dosan Park / 메종 에르메스 도산 파크) 地下1层〔岛山大路45街 (Dosan-daero 45-gil / 도산대로45길) 7号〕。入场免费，由爱马仕基金会自2008年起运营 (爱马仕基金会官方)。周一，周二，周四，周五，周六11:00~19:00，周日12:00~19:00，周三休馆 (Visit Gangnam)。不是从正面橱窗一侧进，而是从停车场一侧入口乘电梯下去，穿过咖啡厅就是展厅 (Visit Gangnam)。目前的展览没有登在基金会页面上，所以未能确认。电话 02-3015-3248
  • 壶林博物馆新沙分馆 (Horim Museum Sinsa Annex / 호림박물관 신사분관)：首尔江南区 (Gangnam-gu / 강남구) 岛山大路 (Dosan-daero / 도산대로) 317号壶林艺术中心 (Horim Art Center / 호림아트센터)。与前面三处不同，这里是古美术博物馆。周二至周六 10:30~18:00(闭馆前1小时截止入场)，周日，周一，1月1日，春节 (Seollal / 설날) 与中秋 (Chuseok / 추석) 长假休馆。门票成人10,000韩元，青少年，残障人士，老人7,000韩元。新沙分馆目前举办《时间 (Sigan / 시時간間)》(2026年9月1日~12月12日)。从水仁盆唐线狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 5号出口朝鹤洞十字路口 (Hakdong Intersection / 학동사거리) 方向直走400米，再朝新沙站 (Sinsa Station / 신사역) 方向走 (壶林博物馆官方)。

🌳 岛山公园：奢侈品街中央的森林

  • 岛山公园 (Dosan Park / 도산공원)：首尔江南区 (Gangnam-gu / 강남구) 岛山大路45街 (Dosan-daero 45-gil / 도산대로45길) 20号。全天开放，全年无休，1973年11月10日开园。咨询电话：江南区厅公园绿地科 (Gangnam-gu Office Parks and Greenery Division / 강남구청 공원녹지과) 02-3423-6244 (VisitKorea TourAPI)。这是纪念独立运动家岛山安昌浩 (Dosan Ahn Changho / 도산 안창호) 的公园，有铜像，纪念馆，以及与夫人李惠练 (Lee Hyeryeon / 이혜련) 合葬的墓园。每年3月10日举行追思活动 (VisitKorea)。可乘3号线狎鸥亭站 (Apgujeong Station / 압구정역) 或水仁盆唐线狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) 前往 (Visit Gangnam)
  • 岛山安昌浩纪念馆 (Dosan Ahn Changho Memorial Hall / 도산안창호기념관)：位于岛山公园 (Dosan Park / 도산공원) 内〔岛山大路45街 (Dosan-daero 45-gil / 도산대로45길) 20号〕。10:00~18:00(入场截止 17:30)，1月1日，春节 (Seollal / 설날) 与中秋 (Chuseok / 추석) 长假休馆，门票免费，电话 02-541-1800 (VisitKorea TourAPI)。建于1998年，展出安昌浩 (Ahn Changho / 안창호) 的生平与遗物 (VisitKorea)。纪念馆自己的网站这次没能正常打开

同一条路上的爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스) → 岛山公园与纪念馆 (Dosan Park / 도산공원) → 壶林博物馆新沙分馆 (Horim Museum Sinsa Annex / 호림박물관 신사분관) 可以一次串起来。周三爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스) 休馆，周日，周一壶林博物馆休馆。

🧰 清潭漫步实用信息：独行，预约，支付，交通

  • 独行：画廊，公园，纪念馆都适合一个人去。一个人吃饭请看Seoul Solo Diner Map：外国人单人餐厅，酒吧，咖啡厅完整指南 12 家代表店
  • 预约：首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울) 须提前预约 (Visit Gangnam)。松隐 (SongEun / 송은) 通过 Naver 预约 (松隐官方)。爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스)，岛山安昌浩纪念馆 (Dosan Ahn Changho Memorial Hall / 도산안창호기념관)，壶林博物馆新沙分馆 (Horim Museum Sinsa Annex / 호림박물관 신사분관) 这次打开的页面上都没有必须预约的字样
  • 按星期安排：周日松隐 (SongEun / 송은) 和壶林博物馆新沙分馆 (Horim Museum Sinsa Annex / 호림박물관 신사분관) 休息，周一壶林博物馆新沙分馆休息，周三爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스) 休息。在非公休日的周二，周四，周五，周六去，四家画廊都能看到
  • 支付与退税：画廊大多免费，需要付款的地方很少。店内支付与退税请看外国游客韩国支付系统深度指南和前面的奢侈品购物篇
  • 交通：东边的旗舰店街乘7号线清潭站 (Cheongdam Station / 청담역)，岛山公园 (Dosan Park / 도산공원) 一侧乘3号线狎鸥亭站 (Apgujeong Station / 압구정역) 或水仁盆唐线狎鸥亭罗德奥站 (Apgujeong Rodeo Station / 압구정로데오역) (Visit Gangnam)。松隐 (SongEun / 송은) 不能停车，请乘公共交通前往 (松隐官方)。交通卡请看韩国交通卡 3 种选择，零慌乱手册：T-money，WOWPASS，气候同行卡 (Climate Companion Card / 기후동행카드) 买哪个
  • 展厅礼仪：松隐 (SongEun / 송은) 展厅内禁止带入饮食，拍照规定因展览而异，不能使用闪光灯。轮椅和24个月以下婴幼儿的婴儿车可以进入 (松隐官方)

⚠ 常见错误 4 则

1. “奢侈品大楼里的画廊只有 VIP 才能进”：首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울)，爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스)，松隐 (SongEun / 송은) 入场都免费。不过首尔路易威登艺术空间 (Espace Louis Vuitton Seoul / 에스파스 루이 비통 서울) 须提前预约 (Visit Gangnam，爱马仕基金会，松隐官方)

2. “周日把画廊集中着看”：松隐 (SongEun / 송은) 周日与公休日休息，壶林博物馆新沙分馆 (Horim Museum Sinsa Annex / 호림박물관 신사분관) 周日，周一休馆 (松隐官方，壶林博物馆官方)

3. “爱马仕工作室 (Atelier Hermès / 아뜰리에 에르메스) 从门店正门进”：要从停车场一侧入口乘电梯下到地下1层。周三休馆 (Visit Gangnam)

4. “岛山公园 (Dosan Park / 도산공원) 夜里关门”：公园全天开放。关门的是公园里的纪念馆(10:00~18:00)(VisitKorea TourAPI)
