韩国聚餐 (Hoesik)·饮酒文化 — 为什么韩国人喜欢一起喝酒，酒桌礼仪又如此之多？

聚餐 (Hoesik / 회식)·饮酒礼仪 (Judo / 주도)·双手敬酒·侧头饮酒·一轮二轮三轮·烧啤 (Somaek / 소맥) — 为外国游客准备的韩国饮酒文化解说。本文不探讨“去哪家酒吧”，而是“为什么·有什么意义·有哪些礼仪·★如今有何变化”。

在韩剧里，经常能看到同事们蜂拥而至 烤肉店 (Gogitjip / 고깃집)，碰响 烧酒杯 (Sojujan / 소주잔) 的场景。有人会双手接杯，在长辈面前稍微侧过头喝酒。而且通常不会只去一个地方，从第一轮 (1cha / 1차) 的烤肉店，到第二轮 (2cha / 2차) 的 练歌房 (Noraebang / 노래방)，甚至可能延续到第三轮 (3cha / 3차)。在外国人看来，这一切都笼罩在“韩国人被迫喝很多酒”的旧印象中。然而，韩国人所说的聚餐 (Hoesik / 회식) 和饮酒礼仪 (Judo / 주도，指饮酒时的规矩) 并非简单的酗酒文化。其中蕴含着软化垂直组织、积累“情 (Jeong / 정)”这种情感纽带的人际交往技巧——更重要的是，如今这种文化正在迅速变化。本文不探讨“在哪里喝酒” (→ 请参考酒吧指南)，而是从外国人的视角，解读聚餐的意义、必须了解的实际礼仪以及在 MZ世代 (MZ sedae / MZ세대) 影响下变化的现实。这是韩国文化解说系列第9篇。

★ 一目了然 — 聚餐轮次与酒类

核心: 聚餐 (Hoesik / 회식) 的目的并非“喝酒本身”，而是通过共同经历多个轮次来增进人际关系的时间。因此，无论是礼仪还是变化，都围绕着“人与人之间”的故事。

⚠️ 外国人常有的3大误解

1. “韩国聚餐 (Hoesik / 회식) = 无条件强制酗酒” ❌ — 过去确实存在过劝酒文化，但现在正在迅速消失。最新调查显示，认为酒局“具有强制性”的人仅占2.1%，超过80%的人表示“可以拒绝劝酒”。2019年《职场欺凌防治法 (Jikjang nae goeropim bangjibeop / 직장 내 괴롭힘 방지법)》 实施后，强制劝酒被视为“欺凌行为” (见下文⑥)。

2. “韩国上班族每天都聚餐 (Hoesik / 회식)” ❌ — 聚餐通常是团队或公司每年举办几次的活动。在每周52小时工作制 (Ju 52 sigan geunmuje / 주 52시간 근무제) 实施后，团体聚餐本身已大幅减少，“午餐聚餐”和“无酒精聚餐”也越来越多。

3. “不能拒绝喝酒” ❌ — 过去拒绝喝酒压力很大，但现在不同了。特别是对外国人会宽容得多。当然也有礼貌的拒绝方式 (见下文⑦·FAQ)。体谅“不能喝酒的人”是如今的礼仪。

① 聚餐 (Hoesik) 是什么 — “一起吃饭”也是工作

聚餐 (Hoesik / 회식) 字面意思是“聚(會)食(食)”。指在职场中，以团队或公司为单位一起吃饭喝酒的场合。它与国外的“team dinner”相似，但在韩国，它具有超越简单用餐的社会功能。

核心在于：韩国职场中，上下级等级 (Wigye / 위계，即资历或职位顺序) 相对分明。在办公室里，由于职级、敬语和正式场合的限制，上司和下属很难轻松交流。聚餐 (Hoesik / 회식) 正是暂时打破这种拘束的机制。在推杯换盏、在练歌房 (Noraebang / 노래방) 一起唱歌的过程中，平时难以接近的上司也会显得有些不同。会议室里绝不会出现的话题，却会在这样的场合中被提及。

因此，韩国人将聚餐 (Hoesik / 회식) 称为“积累情 (Jeong / 정) 的场合” (韩国特有的深厚人际情谊“情” → #1135)。聚餐 (Hoesik / 회식) 既是工作的延伸，同时也是连接人与人之间关系的技巧。

② 为什么“一起”喝 — 情 (Jeong) 与关系的逻辑

在西方，酒通常是“个人喜好”。想喝就喝，各自倒满自己的杯子。韩国传统的酒桌逻辑则不同——酒是“一起”喝的，酒杯是“互相”斟满的。

  • 我的杯子我不自己倒酒 (不自斟自饮)。 传统上不提倡自己给自己倒酒的“自斟自饮 (Jajak / 자작)”行为，而是旁边的人给我倒酒，我给旁边的人倒酒，这是基本规矩。这种互相倒酒的行为本身就是“我在关心你”的关系信号。
  • 如果对方的杯子空了，就给他倒满。 观察同伴的酒杯是否空了并为其斟满，被视为一种体贴。

也就是说，聚餐 (Hoesik / 회식) 的饮酒礼仪 (Judo / 주도) 并非“如何饮酒”，而是“如何关怀彼此”的语法。双手倒酒、先照顾长辈、留意酒杯是否空了——所有这些动作，最终都是表达人际关系的姿态。 (但如后文所述，像“轮流饮酒”等一些习俗正因卫生原因而减少。)

③ 饮酒礼仪 (Judo) ① — 双手与侧头饮酒 (务必了解)

外国人在酒桌上只需了解两件事，就能应对80%的场合。这两点都是在长辈 (指年龄或职级较高的人) 面前的礼仪，根源在于儒家文化中对等级的尊重。

1) 双手倒酒，双手接杯。

  • 给长辈倒酒时——用双手握住酒瓶 (单手握瓶，另一只手轻托持瓶手臂也可)。
  • 长辈给我倒酒时——用双手接过酒杯。
  • 双手即意味着“我尊敬您”。朋友或同辈之间单手操作也很随意。

2) 在长辈面前饮酒时，侧头饮酒。

  • 与年龄或职级较高的人一起喝酒时，正对着他们将酒杯送到嘴边被认为是不礼貌的。
  • 因此，会稍微侧过头 (通常是向左)，并用手或酒杯稍微遮住嘴巴饮酒。这是不直接展示饮酒姿态的谦逊表现。

这两个动作正是韩剧中反复出现的场景。如果外国人能自然地做到，韩国人几乎都会“哇，你怎么知道的？”并表示赞赏。

④ 饮酒礼仪 (Judo) ② — 禁忌“添盏”与碰杯

再深入一点，韩国酒桌上有一个独特的禁忌，叫做添盏 (Cheomjan / 첨잔)。

  • 添盏 (Cheomjan / 첨잔) = 在酒杯中还有酒时再次倒酒。 在韩国传统中，这被视为禁忌。因为在酒杯未空时再次斟酒，被认为是祭祀亡者 (祭桌上)的方式。
  • 因此，原则是“喝完杯中酒后再重新斟满”。如果想给对方倒酒，需要等到对方酒杯空了，或者问一句“再来一杯吗？”
  • (但这是传统规范，如今在休闲场合也会放宽要求。这是韩国特有的习俗，常与日本文化进行比较。)

碰杯礼仪: 与长辈碰杯时，将自己的酒杯稍微低于对方的酒杯被认为是礼貌。这是一个小动作，但表达了“我尊敬您”的等级观念。

⑤ 第一轮 (1cha)·第二轮 (2cha)·第三轮 (3cha) — 为什么要不断换地方？

韩国聚餐 (Hoesik / 회식) 的另一个特点是“轮次”文化。它不会在一个地方结束，而是会不断更换场所。

  • 第一轮 (Ilcha / 일차): 通常在烤肉店 (Gogitjip / 고깃집) 或餐厅，边吃饭边喝酒。这是聚餐 (Hoesik / 회식) 的“主场”。
  • 第二轮 (Icha / 이차): 换个地方再喝一杯——啤酒屋 (Hopeujip / 호프집)·酒吧，或练歌房 (Noraebang / 노래방)。
  • 第三轮 (Samcha / 삼차): 练歌房 (Noraebang / 노래방) (韩国练歌房提供饮料和酒水，边唱歌边喝酒)、路边摊 (Pojangmacha / 포장마차) 等。

为什么要特意换地方呢？因为场所的改变会带来氛围和参与人员构成的变化。第一轮 (1cha / 1차) 的拘谨会在第二轮 (2cha / 2차) 中放松，在练歌房 (Noraebang / 노래방) 一起唱歌会拉近彼此的距离。随着轮次的增加，只剩下更随意的人，大家会进行更深入的交流。

★ 然而，这里也在发生变化。 如今，“只进行第一轮 (1cha / 1차) 并干净利落地结束”成为新的美德。无休止的第三轮 (3cha / 3차)·第四轮 (4cha / 4cha) 被认为是MZ世代 (MZ sedae / MZ세대) 最讨厌的旧文化之一 (见下文⑥)。
