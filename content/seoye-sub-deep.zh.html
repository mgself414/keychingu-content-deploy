韩国书法之旅指南 — 首尔书艺博物馆、果川秋史博物馆、礼山秋史故居·秋史纪念馆·韩国书艺碑林博物馆、济州秋史馆、全州Gangam书艺馆、麟蹄Yeocho书艺馆、天安Chwimukheon书艺馆、春川笔的故事博物馆

副标题：首尔书艺博物馆（艺术殿堂内，周一休馆） · 秋史博物馆（成人2,000韩元） · 秋史故居·秋史纪念馆（礼山） · 韩国书艺碑林博物馆（全年无休，免费） · 济州秋史馆（免费） · Gangam书艺馆（周日休馆，免费） · Yeocho书艺馆（免费） · Chwimukheon书艺馆（免费） · 笔的故事博物馆（制作毛笔体验） — 已对照韩国观光公社旅游信息（TourAPI）

🎯 如何使用这份指南

这份指南汇集了能欣赏韩国书法作品和毛笔文化的书艺馆·博物馆·故居10处。朝鲜后期学者兼书法家秋史 金正喜 (Chusa Kim Jeong-hui / 추사 김정희)（1786~1856）相关的地方分布在果川·礼山·济州（下方FAQ中另行汇总）。首尔仁寺洞 (Insa-dong / 인사동) 一带已收录在#297 仁寺洞指南中。

运营信息照录韩国观光公社旅游信息（TourAPI）登记的数值。大多数地方周一休息，但全州 Gangam书艺馆周日休息，礼山韩国书艺碑林博物馆全年无休。

📍 首尔·果川 — 首尔书艺博物馆·秋史博物馆

首尔书艺博物馆 (Seoul Calligraphy Museum / 서울서예박물관)（首尔瑞草区 (Seocho-gu / 서초구) Nambusunhwan-ro 2406, 瑞草洞 (Seocho-dong / 서초동)，☎ 0507-1382-1656）位于艺术殿堂 (Seoul Arts Center / 예술의전당) 内，1988年与音乐厅一同开馆。据韩国观光公社介绍，馆内收藏《Geunyeok Seohwasa》(Geunyeok Seohwasa / 근역서화사) 等近现代书画史资料和东亚现代书法作品1,300余件，2002年3月升格为书法专门博物馆。

  • 开放时间：10:00~19:00。休息日：每周一。
  • 门票：因展览而异。

秋史博物馆 (Chusa Museum / 추사박물관)（果川市 (Gwacheon-si / 과천시) Chusa-ro 78, Juam洞 (Juam-dong / 주암동)，☎ 02-2150-3650）2013年6月3日开馆。据韩国观光公社介绍，这里是研究·展示·体验秋史 金正喜 (Chusa Kim Jeong-hui / 추사 김정희) 的生平、学问和艺术的地方，设有3个常设展厅（2层 秋史的生平、1层 秋史的学问与艺术、地下1层 藤塚捐赠室 (Fujitsuka Donation Room / 후지츠카 기증실)）和常设体验室，户外有复原的 Gwajicho草堂 (Gwajichodang / 과지초당)。

  • 开放时间：09:00~18:00（截止入场 17:00）。
  • 休息日：每周一（周一为公共假日则顺延至次日）、1月1日、春节·中秋节假期、果川市市长指定的休馆日。
  • 门票（个人）：成人2,000韩元，初高中生·军人1,000韩元，小学生500韩元。团体（20人以上）成人1,000韩元，初高中生·军人500韩元，小学生300韩元。6岁以下、65岁以上免费。

📍 礼山 — 秋史故居·秋史纪念馆·韩国书艺碑林博物馆

秋史 金正喜先生故居 (Chusa Kim Jeong-hui Seonsaeng Gotaek / 추사 김정희 선생 고택)（礼山郡 (Yesan-gun / 예산군) 新岩面 (Sinam-myeon / 신암면) Chusagotaek-ro 261，咨询请致电秋史纪念馆 ☎ 041-339-8248）是秋史 金正喜 (Chusa Kim Jeong-hui / 추사 김정희) 的旧居。据韩国观光公社旅游信息（出处标注为国家遗产厅 (Korea Heritage Service / 국가유산청)），故居由金正喜的曾祖父 (Kim Han-sin / 김한신) 所建，由正房和舍廊房共2栋组成。

  • 开放时间：夏季（3~10月）09:00~18:00，冬季（11~2月）09:00~17:00。
  • 休息日：每周一（周一为公共假日则顺延至次日）、1月1日、春节·中秋节当天。
  • 停车：可以。

秋史纪念馆 (Chusa Memorial Hall / 추사기념관)（礼山郡 (Yesan-gun / 예산군) 新岩面 (Sinam-myeon / 신암면) Chusagotaek-ro 295，☎ 041-339-8248）据韩国观光公社介绍，是在秋史诞辰240周年之际于故居旁新开的展览空间。展出济州流放时期秋史体的变化和岁寒图 (Sehando / 세한도)，在体验室可以体验书写毛笔字和拓碑。从2层瞭望台可以俯瞰天然纪念物龙宫里白松 (Yonggungni Baeksong / 용궁리 백송)。

  • 开放时间：夏季（3~10月）09:00~18:00（截止入场 17:30），冬季（11~2月）09:00~17:00（截止入场 16:30）。
  • 休息日：每周一（周一为公共假日则顺延至之后第一个工作日）、1月1日、春节·中秋节当天。
  • 门票：观光公社登记信息中写为"无"。

韩国书艺碑林博物馆 (Korea Calligraphy Stele Forest Museum / 한국서예비림박물관)（礼山郡 (Yesan-gun / 예산군) 新阳面 (Sinyang-myeon / 신양면) Nokmunbaksalmi-gil 7，☎ 0507-1414-8610）据韩国观光公社介绍，展出近现代书画家的书法和四君子刻在石头上立起的作品700余件。可以欣赏篆书·隶书·楷书·行书·草书以及韩文 (Hangeul / 한글) 书法作品。

  • 开放时间：09:30~17:00。休息日：全年无休。
  • 门票：免费。

📍 济州 — 济州秋史馆

济州秋史馆 (Jeju Chusagwan / 제주추사관)（西归浦市 (Seogwipo-si / 서귀포시) 大静邑 (Daejeong-eup / 대정읍) Chusa-ro 44，☎ 064-710-6865）为纪念秋史 金正喜 (Chusa Kim Jeong-hui / 추사 김정희)，于2010年12月建成。据韩国观光公社介绍，设有秋史纪念厅和3个展厅，展出秋史的匾额书法和书信书法等。

  • 开放时间：09:00~18:00（截止入场 17:30）。
  • 休息日：每周一（周一为公共假日则顺延至之后第一个非公共假日的日子）、1月1日、春节·中秋节当天。
  • 门票：免费。

📍 全州·麟蹄·天安 — 书法家纪念馆

Gangam书艺馆 (Gangam Calligraphy Hall / 강암서예관)（全州市 (Jeonju-si / 전주시) 完山区 (Wansan-gu / 완산구) Jeonjucheondong-ro 74，☎ 063-285-7442）据韩国观光公社旅游信息（出处标注为Gangam书艺馆官方网站），是书法家 (Gangam Song Seong-yong / 강암 송성용) 为了把一生收藏回馈社会而开设的书法专门博物馆，收藏书画·书籍·文房四宝等1,300余件。

  • 开放时间：09:00~18:00。休息日：每周日、春节·中秋节当天。
  • 门票：免费。停车：免费。

Yeocho书艺馆 (Yeocho Calligraphy Hall / 여초서예관)（麟蹄郡 (Inje-gun / 인제군) 北面 (Buk-myeon / 북면) Manhae-ro 154，☎ 033-461-4081）是为纪念书法家 (Yeocho Kim Eung-hyeon / 여초 김응현) 而建的书法专门博物馆。据韩国观光公社介绍，馆藏Kim Eung-hyeon的作品、遗物和书法相关资料等6,000余件，由建筑师 (Lee Seong-gwan / 이성관) 设计的建筑获得2012年韩国建筑文化大奖 (Korean Architecture Culture Awards / 한국건축문화대상) 优秀奖。

  • 开放时间：09:00~18:00（截止入场 17:30）。
  • 休息日：每周一、1月1日、春节·中秋节当天。
  • 门票：免费。停车：免费。

Chwimukheon书艺馆 (Chwimukheon Calligraphy Hall / 취묵헌서예관)（天安市 (Cheonan-si / 천안시) 东南区 (Dongnam-gu / 동남구) 木川邑 (Mokcheon-eup / 목천읍) Jonghaphyuyangji 1-gil 3，咨询请致电文化政策科 ☎ 041-521-5167）据韩国观光公社介绍，展出书法家 (Chwimukheon In Yeong-seon / 취묵헌 인영선) 的书法、档案和影像。

  • 开放时间：10:00~18:00（截止入场 17:30）。
  • 休息日：每周一（周一为公共假日则顺延至次日）、1月1日、春节·中秋节当天。筹备展览期间会另行公告临时休馆。
  • 门票：免费。停车：免费。

📍 春川 — 笔的故事博物馆

笔的故事博物馆 (Butiyagi Museum / 붓이야기박물관)（春川市 (Chuncheon-si / 춘천시) 西面 (Seo-myeon / 서면) Baksa-ro 906，☎ 033-255-0580）是2017年建成的毛笔专门博物馆。据韩国观光公社介绍，1层可以了解传统毛笔的历史和制作过程，2层可以体验制作书法作品和制作专属毛笔，在毛笔工坊还能看到匠人制笔的情景。馆长 (Park Gyeong-su / 박경수) 是江原特别自治道 (Gangwon Special Self-Governing Province / 강원특별자치도) 无形遗产春川笔匠 (Chuncheon Piljang / 춘천필장) 的持有者。

  • 开放时间：10:00~18:00（截止入场 17:30）。
  • 休息日：每周一、春节·中秋节当天。
  • 门票：免费。参观时间登记为约1小时。

⚠ 提前要知道的3点

  1. 只有Gangam书艺馆周日休息 — 其余书艺馆·博物馆大多周一休息。韩国书艺碑林博物馆全年无休。
  2. 礼山两处冬季关门早 — 秋史故居和秋史纪念馆在11~2月开放到17:00（韩国书艺碑林博物馆全年开放到17:00）。
  3. 首尔书艺博物馆的门票每次展览都不同 — 观光公社登记信息中写为"因展览而异"。

⚙ FAQ 2

Q. 哪里有体验项目？

A. 本指南的10处中，观光公社登记信息里写有体验的地方是秋史纪念馆（书写毛笔字·拓碑）、笔的故事博物馆（制作书法作品·制作毛笔）、秋史博物馆（常设体验室，体验内容登记信息中没有）。明确写有书写毛笔字的地方是秋史纪念馆。

Q. 与秋史 金正喜相关的地方在哪里？

A. 果川秋史博物馆、礼山秋史 金正喜先生故居和秋史纪念馆、西归浦济州秋史馆。
