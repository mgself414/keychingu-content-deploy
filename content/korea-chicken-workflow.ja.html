★一目で5ステップのワークフロー

Step アクション時間 外国人のコアポイント
1️⃣チャンネル選択 配信アプリ/電話/ストア/ホテルコンシェルジュ 即時 ホテル配達1位（外国人英語OK）
2️⃣メニュー注文 ブランド+種類+ハーフ・スパイシーな味を選ぶ 3〜10分 バンバン（Banban）=外国人1ランク
3️⃣お支払い+住所を入力 カード・口座振替・配送料＋ホテルアドレス 1～3分ホテル=「ホテル名+客室番号」
4️⃣を入手 30〜60分配達/店舗15〜30分ピックアップ 30〜60分 配達=到着通知/ピックアップ=高速

📱配信システムdeep dive

  • 特徴: 韓国 #1 配信アプリ・チキン店舗全包含・英語一部サポート
  • システム:

1.アプリダウンロード（外国人電話番号SMS認証）

3. カテゴリ→チキン→ブランド選択

4. メニュー+オプション（半分・辛味）

5.決済（カード＋口座振替＋バミンペイ）

  • 外国人親和性: ★★★★ (英語一部・アプリUI 韓国語多)
  • 所要時間：30〜60分（注文後）

  • 特徴: 英文支援最も多い・外国人にやさしい★

##🍗メニューオーダーマトリックス

種類の選択

1. 半分 (Banban) — 味付け+フライド半分ずつ(#1入門おすすめ)

2. シングル — 味付け・フライド・醤油単一種類

3. 3分の1 — 3種類の半分ずつ（一部店舗）

4. 単品・半マリ — 一人用（10,000～14,000ウォン）

5. セット — チキン+ドリンク/ビール/サイド

オプション(すべての店舗)

  • スパイシーなステップ: スパイシー/ノーマル/スパイシー/非常にスパイシー
  • 追加トッピング：チーズ・プリング粉末（別途請求）
  • サイド：チキン大根（無料）・コーラ・ビール（別途）
  • テイクアウト対配達：配達=配達費3,000〜5,000ウォン

###外国人英語発話サンプル

  • "半分にしてください" = "Banban (half-half), please"
  • "私をマップしないでください" = "Less spicy, please"
  • "チーズ追加" = "Add cheese, please"
  • "コーラのボトル" = "One Coke, please"
  • "ホテルへの配達" = "Delivery to hotel, please"
  • "カードですか？" = "Card accepted?"

4. 配達到着 = コンシェルジュ→ルーム配達

5. ホテルサービスチャージ10～20%追加

###ダイレクトオーダー(コスト比)

1. ヨギヨアプリダウンロード

2. ホテルアドレス登録（「Hotel Name + Room Number」英語）

3. メニュー注文

4. ホテルロビーピックアップ OR 客室配達（ホテルポリシーに準じて）

> 外国人コア: 5つ星・新羅・ロッテ・ウェスティン＝コンシェルジュ1位。 3つ星以下=直接注文。

⚠外国人の頻繁なミス7つ

1. "半分=メニューにはありません": すべてのチキンハウスOK。 「半分」（バンバン）または「Half and half」リクエスト。

2. "配達費=無料":配達費3,000～5,000ウォン別途。一部店舗＝一定金額以上無料。

3. 「ホテルの配達 = 難しさ」: ホテルのコンシェルジュ = 外国人1位システム。英語OK。

4. 「スパイシーな味=表示しない」：すべての店舗のスパイシーなステップを表示します。 「アンスパイク」可能。

5. 「チメック＝店舗のみ」：ホテルルーム・通り・漢江市民公園OK。

6. "チキン1匹 = 1人食事": 1匹 = 2〜3人前。一人で=半羽または単品。

7. "お支払い=現金のみ": すべての配信アプリカードOK。韓国＝カード使用率#1グローバル。

⚙ よくある質問8件

1. 最初のチキン=どのチャンネル: ホテルコンシェルジュ 1ランク(英語・簡易)。コスパ＝店舗ピックアップ。

2. 外国人にやさしい配達アプリ: ヨギヨ (英語 ★) > バミン > クパンイツ。

3. 半分人気の組み合わせ: 味付け+フライド(#1)/醤油+味付け/プリンクル+フライド。

4. チメック店のおすすめ：鍾路・乙支路・江南・弘大・梨泰院のチマク集クラスタ。

5. 24時間配達：一部店舗（江南・梨泰院中心）24h配達OK。

6. アレルギー・妊娠: [#816 disclaimer](#816)参照。グルテン・ソイ・卵・ナッツ類の注意。

7. 決済・チップ: カードOK / ホテルコンシェルジュ = 10～20% サービスチャージ/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

チキン=高脂肪フライ。妊婦・免疫低下＝辛味＋過食注意。子ども＝辛い味付け・フライド推奨。 配達チキン= 30分〜1h以内の摂取を推奨（食中毒risk）。アレルギー（グルテン・ソイ・卵・ナッツ類）事前通知。食中毒の疑いがある場合☎ 1339（医療、英語）。本ガイドは一般情報、医療助言ではない。

店舗・ブランド情報免責：配達アプリ・ブランド店舗ポリシー・メニュー変動頻度 — ご使用前にNAVER/Kakao mapまたは公式サイト・アプリ確認お勧め。

食事制限 fallback:

  • ハラール・コーシャ: 韓国チキン認証ほとんどなし。 →イテウォン一部ハラール店OR BBQグローバル進出ハラールオプション。
  • ベジタリアン・ビーガン：チキン=非ベジタリアン。 →[#799ベジタリアン・ビーガン](#799)参照。
  • グルテンフリー: 天ぷら服=小麦粉。ヒール（オーブン）=グルテンフリーオプションの一部。
