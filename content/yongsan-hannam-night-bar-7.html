🎯 왜 용산·한남 야간 바 가이드인가

용산·한남·이태원 = 외국인 매니아 nightlife 매트릭스 #1. 외국인 관광객 페인포인트 = (a) "용산 = 전자상가만" / "한남 = 부촌만" 잘못된 인식 — 용산·한남·이태원 = 외국인 매니아 야간 바 매트릭스 #1 (b) catchtable·인스타 큐레이션 매트릭스 + 외국인 시각 분위기 deep dive (c) "낮부터 밤까지" 한국 nightlife 2-track (낮술·야간) → 낮 = #1075 와인바·야 = 본 가이드 (d) 외국인 매니아 한남대로·대사관로·한강대로 cluster + 영어 메뉴·외국인 직원 多 (e) 야간 바 + 야장(#1071)·야경(#1072)·낮술 와인바(#1075) cross.

⚠ 외국인 자주 실수 3가지

1. "용산 = 전자상가만" / "한남 = 부촌만": 용산·한남·이태원 = 외국인 매니아 nightlife 매트릭스 #1. 한강대로·한남대로·이태원로·대사관로 cluster 7선 = 외국인 매니아 동선.

2. "한국 바 = 영어 안 통하나": 용산·한남·이태원 바 = 영어 메뉴·외국인 직원 매트릭스 #1. 한남·이태원 = 외국인 거주 多 → 영어 OK 매트릭스. catchtable 예약 = 영어 인터페이스 OK.

3. "한국 바 = 술만 마시는 곳": 한국 바 = 낮부터 밤까지 (오오비·인바이티드·울프소셜클럽·해이커피앤바) = 커피·디저트·바 fusion 매트릭스 #1. 외국인 매니아 fit.

⚙ FAQ 4개

1. 외국인 야간 바 best 시간대: 저녁 7~10시 best. 평일 = walk-in 가능. 주말 8~11시 = 만석 多 → catchtable 예약 권장 (오오비·쎄오). 마지막 주문 = 자정 (마감 24~02시 매장별 다름).

2. 예약 방법: catchtable.co.kr (외국인 사용 가능) / 인스타 DM (탱글드 카세트·해이커피앤바) / walk-in (잔비어·인바이티드·울프소셜클럽). 외국인 매니아 = catchtable + 영어 인터페이스 OK.

3. 외국인 야간 동선 추천: 이태원역(저녁 식사) → 쎄오(이태원로54길) → 울프소셜클럽(한남대로) → 오오비(한강대로) → 잔비어(한강대로) → 야장 8선 cluster cross (#1071).

4. 외국인 야간 바 etiquette: (a) catchtable 예약 = no-show 시 페널티 + 카드 등록 (b) 입장 시 ID 체크 가능 (만 19세 이상) — 외국인 여권 필요 (c) 팁 문화 X (서비스 차지 포함) (d) 흡연 = 매장 내 금지, 외부 흡연 구역 (e) 영어 메뉴 = 한남·이태원 多, 용산 일부 제한.
