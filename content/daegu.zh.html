⚠ 外国游客常犯的3个错误

1. “大邱 (Daegu / 대구) = 首尔 (Seoul / 서울) 之后的城市”: 大邱 (Daegu / 대구) = 韩国第三大城市 + KTX 1小时40分钟 + 外国游客最爱的外围城市。

2. “东城路 (Dongseong-ro / 동성로) = 简单”: 东城路 (Dongseong-ro / 동성로) = 韩国第三大市中心购物区 + MZ世代最爱之地。

3. “大邱炸鸡啤酒节 (Daegu Chimac Festival / 대구치맥페스티벌) = 没去过”: 每年7月在头流公园 (Duryu Gongwon / 두류공원) 举办 = 韩国第一炸鸡啤酒节 + 外国游客首选。
