テコンドーガイド — 外国人が見て体験できる場所: 国技院(ソウル)とテコンドー院(茂朱)、2026年の公式情報

サブタイトル: 国技院は江南駅12番・駅三駅4番出口、示範団の定期公演は公式の紹介文のみで日程・料金は未掲示 / テコンドー院(茂朱)は10:00~18:00・月曜休館・入場無料・常設示範公演10,000ウォン・体験4,000~10,000ウォン — 2026-10-08 時点の国技院・テコンドー振興財団の公式ページ基準。テコンドーはUNESCO無形遺産リストに登録されていません(2011年に登録されたのはテッキョン)

親 deep: #686 伝統音楽・#720 宗教

🎯 このガイドの使い方

外国人が韓国でテコンドーを「見る・体験する」とき、公式ページで確認できる場所は二つです。ソウル江南の国技院 (Kukkiwon / 국기원)(世界テコンドー本部、示範団の本拠地)と、全羅北道茂朱 (Muju / 무주)のテコンドー院 (Taekwondowon / 태권도원)(テコンドー振興財団、博物館・常設示範・体験)です。以下の値は2026-10-08に両機関の公式ページで読み取ったものだけを記し、国技院の公演日程・料金のように公式にない値は「未掲示」としています。以前のガイドにあった「テコンドーUNESCO 2011年登録」は事実ではありません — 2011年に登録されたのはテッキョン (Taekkyeon / 택견)で、テコンドーはUNESCO人類無形文化遺産リストにありません(ich.unesco.org の検索結果は0件)。「国技院は年中無休」「江南駅から徒歩10分」「体験5万~15万ウォン」「KTX永同駅」も公式と異なるため外しました。

🥋 国技院 — ソウルで見られる?

  • 1972年開院・1974-09-06示範団創設などの沿革のうち、公式ページで読み取れたのは示範団の創設日(1974-09-06)と「外国人観光客向けの定期示範公演を運営している」という紹介文だけです。公演の曜日・時間・料金・予約方法は公式ページにありません — 訪問前に国技院 (Kukkiwon / 국기원)(02-567-1058)へ問い合わせてください。
  • 建物自体は江南の真ん中(テヘラン路7ギル32)。出口は江南駅12番・駅三駅4番・新論峴駅4・5番(公式、徒歩時間は未掲示)。
  • 事務の時間は月~木 09:00~18:30、金 09:00~16:00、週末・祝日は休みです — 見学者向けの開放時間ではありません。

🏔 テコンドー院 — 行けば確実な場所

  • テコンドー振興財団 (Taekwondo Jinheung Jaedan / 태권도진흥재단)が運営(公式サイト tpf.or.kr — 以前のガイドにあった tkdwon.kr は存在しないアドレス)。10:00~18:00、発券は09:30から、入場締切17:00、国立テコンドー博物館は10:00~17:00。月曜日・1/1・旧正月・秋夕の当日と前日は休館(公式)。
  • 入場・博物館・駐車場は無料。有料なのは常設示範公演10,000ウォン、ヤップ!体験センター4,000~10,000ウォン、モノレール往復4,000ウォン(公式料金表)。メインページには「公演・体験は入場料に含まれる」とあり、料金表と食い違っています — 現地の券売所を基準にしてください。
  • 公演の曜日・時間は未確認です(10/8の閲覧時は「未運営」と表示)。行く前に公式の公演カレンダーを確認しましょう。
  • 宿泊: 跳躍館 (Doyakgwan / 도약관)(1,031人収容) — 料金は未閲覧。
  • アクセス(公式): ソウル南部ターミナル → 茂朱 市外バス1日5便、またはKTXで大田まで行ってからバス。日帰りは厳しく、1泊が現実的です。

🏅 事実の整理 — オリンピック・UNESCO

  • UNESCO: テコンドー (Taekwondo / 태권도)は人類無形文化遺産リストにありません。2011年に登録されたのはテッキョン(6.COM 13.44)です。両者を混同していた以前のガイドの文は削除しました。
  • オリンピック: 2000年シドニー大会から正式種目という通説は広く知られていますが、今回は世界テコンドー連盟の公式ページを開けなかったため、「公式確認」のラベルは付けません。

🚶 二つの動線

  • ソウル半日: 江南駅12番出口 → 国技院(建物・示範団の公演は事前に問い合わせ) → 江南の予定へ。
  • 茂朱1泊: 南部ターミナルからバス → テコンドー院(博物館 無料 → 常設示範 10,000ウォン → ヤップ!体験) → 跳躍館に宿泊 → 翌日は 徳裕山 (Deogyusan / 덕유산)。

⚠ よくある間違い5つ

1. 「テコンドーはUNESCO」と信じる — リストにありません。テッキョンです。

2. 国技院へ公演を見にノープランで行く — 日程・料金は未掲示。電話で確認を。

3. 月曜日のテコンドー院 — 休館です。

4. tkdwon.kr で検索する — 存在しないサイトです。tpf.or.kr へ。

5. 体験料を5万~15万ウォンで見積もる — 公式に掲示されているのはテコンドー院の4,000~10,000ウォンだけです。

⚙ FAQ 6つ

1. 確実に公演を見るには? — テコンドー院の常設示範公演(10,000ウォン)。曜日は公式カレンダーで確認してください。

2. ソウルから日帰りで? — 国技院の訪問はできますが、公演日程は未掲示です。

3. 茂朱までどれくらい? — 公式は手段のみ(南部ターミナルからバス5便/KTX 大田経由)。所要時間は未掲示です。

4. 子どもと一緒に? — テコンドー院のヤップ!体験センター 4,000~10,000ウォン、子ども公演は20%割引です。

5. テコンドーとテッキョンの違いは? — テッキョンは朝鮮の伝統武芸で2011年にUNESCO登録、テコンドーは20世紀に体系化された現代武道です。

6. 英語の案内は? — 両機関とも公式ページに外国語案内の表記がなく、未確認です。
