📍 Seorae村与山坡公园 — Seorae村·Montmartre公园·Seoripul公园

Seorae村 (Seorae Maeul / 서래마을)，瑞草区 (Seorae-ro 32 / 서래로 32)，☎ 02-120，是有法式餐厅、咖啡厅、红酒吧和商店的街区。名字的意思是“村前的小溪蜿蜒曲折地流淌”。1985年驻韩法国学校 (Juhan Peurangseu Hakgyo / 주한 프랑스학교) 迁到这里后，法国人开始聚居，其他国家的人也陆续搬来。街上有首尔法国学校，还有用法语写着“Attention Ecole”的道路标识牌。

  • 开放时间:全天开放。休息日:全年无休。各店可能不同。费用:免费。

Montmartre公园 (Mongmareutteu Gongwon / 몽마르뜨공원)，瑞草区 (Banpo-dong / 반포동)，☎ 瑞草区厅绿色城市科 (Seocho-gucheong Pureun Dosi-gwa / 서초구청 푸른도시과) 02-2155-5483，是2003年在Seorae村上方开放的公园。因为紧邻法国人聚居的Seorae村而得名。有法国诗人的诗和造型作品、梵高·高更·毕加索的半身像，还有歌手Imija (Imija / 이미자) 的纪念空间“Imija Tteul (Imija Tteul / 이미자 뜰)”和游乐场。从公园尽头过Nuedari桥 (Nuedari / 누에다리) 就通向Seoripul公园。

  • 开放时间:全天开放。休息日:全年无休。停车:不可以。

Seoripul公园，瑞草区 (Seocho-dong / 서초동)，☎ 瑞草区厅绿色城市科 02-2155-6861，1970年代起有军队驻扎而无法进入，2015年军队迁走后，于2019年建成。从Banpo-dong (Banpo-dong / 반포동) 到Bangbae-dong (Bangbae-dong / 방배동)，横穿瑞草区中央的约4km步行道一直通到Montmartre公园。Nuedari桥和Seoripul桥 (Seoripul-dari / 서리풀다리) 连接被道路截断的路，向北可见汉江，向南可见牛眠山。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:不可以。

📍 书与演出 — 国立中央图书馆·艺术殿堂

国立中央图书馆，瑞草区 (Banpo-daero 201 / 반포대로 201)，☎ 02-590-0500，是收集和保存国家文献的图书馆。1988年5月28日从南山 (Namsan / 남산) 迁到现址，由主馆和附属建筑组成。

  • 开放时间:周四至周二 09:00~18:00，周三 09:00~21:00。
  • 休息日:每月第二个·第四个周一，周日以外的法定公休日。费用:免费。

艺术殿堂，瑞草区 (Nambusunhwan-ro 2406 / 남부순환로 2406)，☎ 1668-1352，是位于牛眠山下的复合文化艺术空间。有上演歌剧·戏剧·舞蹈·音乐剧的歌剧院、有古典乐专用厅的音乐厅、Hangaram美术馆 (Hangaram Misulgwan / 한가람미술관)、Hangaram设计美术馆 (Hangaram Dijain Misulgwan / 한가람디자인미술관)、首尔书法博物馆 (Seoul Seoye Bangmulgwan / 서울서예박물관)。有7个剧场，3个美术馆·博物馆。据介绍，台阶广场和音乐广场会举办户外放映会和世界音乐喷泉等活动。

  • 开放时间·休息日·费用:各演出和展览不同。
  • 停车:30分钟内出场免费，普通费用每10分钟1,000韩元。演出观众5小时6,000韩元，展览观众3小时4,000韩元。

📍 牛眠山 — 愿望塔·自然生态公园·首尔Dulle-gil第10段

牛眠山愿望塔，瑞草区 (Seocho-dong / 서초동)，☎ 瑞草区绿色城市科 02-2155-6883，是牛眠山山顶的石塔。来访的人带着心愿一块一块地垒上石头，成了大塔。牛眠山位于瑞草区和京畿道果川市的交界处，因形似睡觉的牛而得名。坡度平缓，据介绍成年人大多1小时多就能登上愿望塔。塔附近有瞭望台，可以看夜景。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

牛眠山自然生态公园，瑞草区 (Umyeon-dong / 우면동)，☎ 瑞草区厅绿色城市科 02-2155-6883，是2004年7月23日开放的公园。牛眠山高293m，南麓有青铜器时代遗迹支石墓。散步路和登山路周围有药水泉、Daeseong寺 (Daeseongsa / 대성사)、郑道传之墓、艺术殿堂。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

首尔Dulle-gil第10段牛眠山路段，瑞草区 (Yangjae-dong / 양재동)，☎ 02-779-7902~4，是总长156.5km、共21个路段环绕首尔一圈的首尔Dulle-gil中，以“山中看首尔的路”为主题的路段。从Maeheon市民之林 (Maeheon Simin-ui Sup / 매헌시민의숲) 到Sadang站 (Sadang-yeok / 사당역) 岔路口，坡度平缓。离地铁Yangjae Simin-ui Sup站 (Yangjae Simin-ui Sup-yeok / 양재시민의숲역) 和Sadang站很近。

  • 长度·时间:总长7.6km，约3小时20分钟。开放时间:全天开放。费用:免费。

📍 Yangjae·Banpo — 瑞草文化艺术公园·江南高速巴士客运站嫁妆商街

瑞草文化艺术公园，瑞草区 (Baumoe-ro 12-gil 40 / 바우뫼로12길 40)，☎ 管理事务所 02-2155-8601，是1994年5月在Maeheon市民之林第3区建成的公园。有雕塑公园、企划展览场、户外演出场、相聚广场，还有两条水杉路。

  • 开放时间:全天开放。休息日:全年无休。费用:免费。停车:可以。

江南高速巴士客运站嫁妆商街，瑞草区 (Sinbanpo-ro 194, 4F / 신반포로 194, 4층)，☎ 02-533-2489，是主要卖寝具、窗帘、绸缎的嫁妆·家居装饰商街。从1982年起嫁妆店陆续入驻，有寝具店250余家、窗帘专卖店100余家、缝纫加工所40余家。还卖韩服、刺绣品和面料。

  • 开放时间:09:30~19:30。休息日:每周日。
  • 停车:每15分钟1,500韩元，1小时6,000韩元。

⚠ 行前须知 3 点

  1. 国立中央图书馆每月第二个·第四个周一休息 — 周三开放到21:00。
  2. Montmartre公园和Seoripul公园不能停车 — 牛眠山愿望塔、牛眠山自然生态公园、瑞草文化艺术公园可以停车。
  3. 高速巴士客运站嫁妆商街周日休息 — 09:30~19:30开放。

⚙ FAQ 2

Q. 到牛眠山愿望塔、首尔Dulle-gil牛眠山路段，各需要多长时间?

A. 据观光公社介绍，按成年人计，大多1小时多就能登上愿望塔。首尔Dulle-gil第10段牛眠山路段总长7.6km，约3小时20分钟。

Q. Seorae村附近的公园有哪些?

A. Seorae村上方有Montmartre公园，从公园尽头过Nuedari桥就通向Seoripul公园。
