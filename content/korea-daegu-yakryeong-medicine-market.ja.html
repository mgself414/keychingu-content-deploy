＃＃⚠外国人の頻繁な誤り5つ

1. 「漢方薬=苦味のみ」: 双和茶・ゆず茶・生姜茶・ナツメ茶=苦苦・甘いマトリックス。入門1ランク。

2. 「薬令時＝漢方薬店のみ」：漢方茶カフェ+薬材K-food+博物館+5月まつり+漢方マッサージ5軸フルセット。

3. 「漢方アレルギーX」：漢方薬・薬材＝薬草アレルギー可能（高麗人参・糖鬼・葛筋など）。事前通知+漢方の事前相談をお勧めします。

4. 「5月祭り＝ただの市場祭り」：5月の薬令時祭り＝漢方・韓服・伝統音楽・5日間フルセット。外国人#1マニア・文化fit。

5. "博物館 = 英文X": 薬令市博物館・韓国韓医学博物館 = 英文案内フルセット・外国人マニアマトリックス#1。

⚙ FAQ 6個

1. 外国人入門1順位:博物館(英語)+漢方茶カフェ+薬材ビビンバ=2時間コース。

2. シーズン: 毎年5月 薬令時祭りシーズン = 外国人#1マニア。祭りの時期＝博物館＋カフェ＋老舗マニア。

3. 漢方薬の購入：外国人=漢方薬の処方の際に漢方の事前相談をお勧めします。簡易漢方車（双和車・ゆず茶）＝自由購入OK。

4. 帰国ギフト: 真空包装漢方車(双和車・ゆず茶・ショウガ車) = 受託手荷物OK。漢方薬=一部の国持ち込み制限の確認必須。

5. アレルギー: 高麗人参・唐辛子・葛筋・シナモン・ハニー＝一般アレルゲン。 事前漢方の相談+アレルギー事前通知必須。

6. おすすめペルソナ: ウェルネスマニア・シニア・女性 = #1 / MZ・インスタマニア = カフェ薬令時 + 韓服レンタル / 家族・子供 = 博物館 + 茶試飲。

⚠医療・安全・食事ダイエット

漢方薬・薬材＝薬物相互作用（ワルファリン・糖尿薬・高血圧薬など）。妊婦＝漢方薬材一部禁忌（唐帰・紅花など）。こども＝薬材ビビンバ一部マコム・薬草アレルギー注意。食中毒・腹痛☎1339。

食事制限 fallback:

  • ハラール・コーシャー：薬材ビビンバベジタリアンオプション=ハラール可能/漢方茶=ほとんどOK
  • ベジタリアン・ビーガン：薬材ビビンバ（ベジタリアンオプションOK）・漢方茶
  • グルテンフリー: 漢方茶OK・薬材ビビンバ（醤油抜けばOK）

✈️ 外国人ペインポイント #1 — 漢方車帰国プレゼント

  • おすすめ: 真空包装 双和車・ゆず茶・生姜茶・大推車 = 受託手荷物OK
  • 価格: 双和車100g 5,000～10,000ウォン・遊磁車1kg 15,000～25,000ウォン
  • 購入先：薬田路地老舗・薬令市博物館店舗・イマートトレーダーズ
  • 国別輸入制限: オーストラリア・ニュージーランド・アメリカ一部 = 薬草・漢方薬輸入制限 — 自国規定事前確認必須
  • 賞味期限：真空包装漢方差＝6ヶ月～1年（密封）・開封後3ヶ月
