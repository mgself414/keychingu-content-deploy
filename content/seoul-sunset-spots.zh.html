首尔晚霞名所12选 — 日落前45分钟，黄金时刻观景指南

副标题：与夜景(#224)不同时段的首尔 — 必须在日落前45分钟抵达才能看到的12处黄金时刻名所 + 分类型选择矩阵 + 逐月日落时刻表 + 直接接续夜景的动线(连接汉江西侧#305·鹰峰山#051)

🎯 为何把"晚霞"单独拿出来讲 — 与夜景指南的角度不同

首尔内容里，夜景(night view)已经讲过很多次了(#002 免费夜景·#224 夜景完全指南)。但是晚霞和夜景完全是两种玩法。

区分 晚霞(本篇) 夜景(#224)
黄金时段 日落前45分钟~日落后20分钟 — 一天只有短短1小时 日落后~深夜，时间充裕
方向 只有西边天空开阔的地方才有效 与方向无关，灯光密度才是关键
失败因素 晚到 = 当天结束，只能明天再来 几乎没有
最佳季节 9~11月(细尘↓·晚间空气凉爽) 四季皆宜

在旅行日程里，晚霞是恰好能塞进"晚饭前1小时"的免费内容。本篇12处全部免费入场，并按公共交通可达性挑选。

① 外国人常犯的3个错误

1. 卡着日落"时刻"抵达

晚霞的高潮不是官方日落时刻，而是日落前15~30分钟(天空由橙转粉的那段时间)。等到日落时刻才到，其实已经结束了。提前45分钟抵达才是公式。

2. 只看高度不看方向

南山塔(남산타워)虽然高，但西侧视野会被楼群挡住。晚霞不是由高度决定的，而是由西边地平线开阔与否决定 — 所以本篇排名靠前的地方都集中在汉江西侧和朝西的山丘。

3. 看完晚霞就直接下山

一半的晚霞名所会在20分钟后变身为夜景名所。鹰峰山(응봉산 / Eungbongsan，#051)·梅峰山便是代表 — 在同一个地方从晚霞接续看到夜景，动线效率最高。

③ 12选详情

汉江水面倒影型

1. 仙游岛公园 (Seonyudo Park / 선유도공원) — 杨花(양화)汉江正中央的岛屿公园。夕阳从旧净水场的构造物之间落下，是本篇里最"不像首尔"的画面。9号线仙游岛站 (Seonyudo Station / 선유도역) 步行10分钟。(汉江西部详情见#305)

2. 鹭得岛 (Nodeul Island / 노들섬) — 汉江大桥 (한강대교) 上的文化岛。西侧草坪广场朝汝矣岛 (여의도) 方向的日落，若恰逢周末晚间的现场演出，那天最棒。9号线鹭得站 (Nodeul Station / 노들역) 步行10分钟。

3. 盘浦汉江公园 (Banpo Hangang Park / 반포 한강공원) — 夕阳落在世光岛 (Some Sevit / 세빛섬) 后方。晚霞结束后自然接续到月光彩虹喷泉 (Moonlight Rainbow Fountain / 달빛무지개분수)(4~10月)。高速巴士客运站 (Express Bus Terminal Station / 고속터미널역) 步行15分钟。

4. 望远汉江公园 (Mangwon Hangang Park / 망원 한강공원) — 本地人密度最高的晚霞。是24小时便利店 (convenience store / 편의점) 泡面配野餐垫组合的圣地。望远站 (Mangwon Station / 망원역) 步行12分钟。(汉江文化完全指南见#209·#700)

山丘全景型

5. 天空公园 (Haneul Park / 하늘공원) — 世界杯公园 (월드컵공원) 内的芒草山丘。10月芒草季+晚霞的组合是全首尔第一。291级台阶，或搭乘萌蛙小火车 (Maengkkongi car / 맹꽁이차)(收费)。世界杯体育场站 (World Cup Stadium Station / 월드컵경기장역) 步行20分钟以上。

6. 鹰峰山八角亭 (Eungbongsan Pavilion / 응봉산 팔각정) — 唯一能朝西俯瞰汉江东侧的陡坡山丘。晚霞转夜景 (#051) 在这里最为戏剧化。鹰峰站 (Eungbong Station / 응봉역) 步行15分钟台阶。

7. 梅峰山八角亭 (Maebongsan Pavilion / 매봉산 팔각정) — 藏在汉南 (Hannam / 한남)·步提岭 (Beotigogae / 버티고개) 后方的隐秘山丘。将南山塔 (Namsan Tower / 남산타워) 与汉江收进同一画面，同时接住西边晚霞的构图。步提岭站 (Beotigogae Station / 버티고개역) 步行15分钟。几乎没有游客。

8. 龙骧凤翥亭公园 (Yongyangbongjeojeong Park / 용양봉저정공원) — 从鹭梁津 (Noryangjin / 노량진) 的山丘上，太阳落在汉江铁桥 (Hangang Railroad Bridge / 한강철교) 与汝矣岛天际线的背后。鹭得站或鹭梁津站 (Noryangjin Station / 노량진역) 步行15分钟。本地人的晚间散步路线。

城墙+市区剪影型

9. 仁王山虎岩 (Inwangsan Beombawi / 인왕산 범바위) — 城墙路半山腰的岩石观景台。俯瞰景福宫 (Gyeongbokgung / 경복궁)·光化门 (Gwanghwamun / 광화문) 轴线的同时看夕阳西下 — 唯一能把市区和晚霞同时收进画面的构图。以独立门站 (Dongnimmun Station / 독립문역) 为起点登山40分钟。(登山基础见#148)

10. 骆山公园 (Naksan Park / 낙산공원) — 东大门 (Dongdaemun / 동대문) 上方的山丘。城墙之外的市区剪影沉入逆光中的画面。惠化站 (Hyehwa Station / 혜화역) 步行15分钟 — 不用爬山也能看到城墙晚霞的高性价比路线。

11. 北岳八角亭 (Bugak Pavilion / 북악 팔각정) — 可开车、打车抵达的观景台。是步行困难的同伴(家庭·长辈同行)的备选方案。从市区北侧俯瞰首尔全景+晚霞。

下班路上高性价比型

12. 汝矣岛水光广场 (Yeouido Mulbit Square / 여의도 물빛광장) — 就在汝矣渡口站 (Yeouinaru Station / 여의나루역) 正前方。12处中可达性排名第1。混在金融街下班人潮 (퇴근길，下班回家的路上) 里一起看，本身就是"首尔的平日傍晚"。

⑤ 实战贴士

  • 下山照明：鹰峰山·仁王山·梅峰山日落后台阶很暗。手机手电筒够用，但千万别穿人字拖。
  • 三脚架：山丘型八角亭有护栏，迷你三脚架就够。汉江型反而是野餐垫上的低角度更有利。
  • 觅食动线：望远(→望远市场 (Mangwon Market / 망원시장) 美食)·鹰峰山(→圣水 (Seongsu / 성수) 晚餐)·骆山(→大学路 (Daehangno / 대학로))— 晚霞后紧邻晚餐街区的这3处，对初来者效率最高。
  • 全部免费。唯一要花钱的只有天空公园的萌蛙小火车和晚饭钱。
