ISSUE 03 · #254 · 2026-05-19

🎯 왜 강릉·평창 풀가이드인가

강릉 = 한국 1번지 동해 도시 + 평창 = 2018 동계올림픽 + 한국 1번지 스키 + KTX 강릉선 1시간 40분. 외국인 매니아 외곽 1순위 (제주 다음).

⚠ 외국인 자주 실수 5가지

1. "강릉 = 1박2일 OK": 강릉 외국인 매니아 = 2박3일~3박4일 풀세트 + 강릉 + 평창 + 정선·속초 외곽 매니아.

2. "KTX 강릉선 = 안 빠름": KTX 강릉선 = 서울 → 강릉 1시간 40분 (2017 평창 동계올림픽 대비 개통) + 외국인 매니아 1번지.

3. "용평·하이원 = 비쌈": 용평·하이원·곤지암·휘닉스 = 외국인 매니아 1번지 + 1박2일~1주일 풀세트 + 외국인 친화 영문 OK.

4. "안목 커피거리 = 카페만": 안목 커피거리 = 한국 1번지 카페 + 테라로사 본점·보헤미안 1번지 + 외국인 매니아 1번지.

5. "평창 = 겨울만": 평창 = 여름 (오대산·양떼목장)·가을 (단풍 #229)·겨울 (스키 #231)·봄 (꽃 #230) + 외국인 매니아 1번지.

⚙ FAQ 6개

1. 외국인 강릉 동선: KTX 서울→강릉 1시간 40분 → 안목 커피거리·정동진.

2. 외국인 평창 스키: 용평·하이원·휘닉스·알펜시아 (#231) + 외국인 친화 영문 OK.

3. 외국인 강릉 안목 커피: 한국 카페 1번지 + 테라로사 본점·보헤미안 + 외국인 매니아.

4. 외국인 정동진 일출: 한국 1번지 일출 + 외국인 매니아 1번지.

5. 외국인 강릉·평창 1박2일: Day 1 강릉 안목 + 정동진 + 경포대 / Day 2 평창 스키 + 오대산.

6. 외국인 강원도 외곽: 속초·양양 (서핑)·정선·강릉 옥계 외국인 매니아.

🗺 외국인 풀데이 코스 3개

A. 강릉·평창 1박2일 (외국인 매니아)

  • Day 1: KTX 서울→강릉 → 안목 커피거리·정동진 일출 → 강릉 1박
  • Day 2: 용평·평창 스키 → 오대산 → KTX 강릉→서울

B. 강원도 외곽 2박3일 (외국인 deep dive)

  • Day 1: 강릉 안목·정동진
  • Day 2: 평창 스키 + 오대산
  • Day 3: 설악산 (속초) → 서울

C. 강원도 1주일 풀세트 (외국인 매니아)

  • Day 1~2 강릉·정동진·경포대 / Day 3~4 평창 스키 / Day 5~6 속초·양양·설악산 / Day 7 서울

  • 봄 4~5월: 강릉 벚꽃·평창 꽃 매니아
  • 여름 6~8월: 오대산·강릉·속초 외국인 매니아 1번지
  • 가을 10~11월: 강릉 단풍·평창·설악산 외국인 단풍 1순위
