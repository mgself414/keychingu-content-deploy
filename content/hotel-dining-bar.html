⚠ 외국인 자주 실수 5가지

1. "호텔 다이닝 = 비쌈만": 라연 200~500K+ 미쉐린 3스타·비채나 100~300K + 점심 코스 가성비 (60~100K) + 외국인 매니아 1순위.

2. "호텔 바 = 투숙객만": 시그니엘 BAR 81·반얀트리 문 바·콘래드 37·JW 그리핀 = 외부 이용 OK + 사전 예약 권장 (특히 주말 야경).

3. "미쉐린 = 한식만": 라연 (한식)·비채나 (한식 fine)·유유안 (중식)·반얀트리 페스타 (4종)·롯데 모모야마 (일식) 외국인 매니아 다양.

4. "BAR 81 = 비쌈": BAR 81 81F·555m view = 칵테일 25~40K + 외국인 매니아 1순위 + 야경 view (사전 예약 필수).

5. "호텔 바 = 야경만": 호텔 바 = 야경 + 시그니처 칵테일 + 셰프 메뉴 + 외국인 데이트·신혼 (#277) 1번지.

① 미쉐린 다이닝 (5)

1. 시그니엘 비채나 ★ 미쉐린 (잠실 81F)

  • 주소: 송파구 올림픽로 300 (잠실 롯데타워 81F #82)
  • 외국인 ★: ◎◎ — 555m·한식 fine·외국인 럭셔리 1번지
  • 가격: 런치 100K~·디너 200~300K
  • 시그니처: 한식 fine + 555m view + 외국인 매니아 #1

2. 신라호텔 라연 ★ 미쉐린 3스타

  • 주소: 중구 동호로 249 (#13 남산)
  • 외국인 ★: ◎◎ — 한국 #1 한정식·1979
  • 가격: 런치 200K~·디너 300~500K
  • 시그니처: 한국 정통 한정식·외국인 #1 + #309 한정식 3단계 럭셔리

3. 반얀트리 페스타

  • 외국인 ★: ◎◎ — 한식·이태리·중식·일식 4 다이닝 + 남산
  • 가격: 런치 80~150K·디너 150~300K

4. 포시즌스 유유안 ★ 미쉐린 중식

  • 주소: 종로구 새문안로 97 (광화문)
  • 외국인 ★: ◎◎ — 광동·홍콩 셰프·외국인 매니아
  • 시그니처: 광동·홍콩 정통 + 광화문 view

5. 롯데호텔 무궁화 ★ 한식 정통

  • 주소: 중구 을지로 30 (명동)
  • 외국인 ★: ◎◎ — 1979 한국 정통 한정식
  • 가격: 200~400K·외국인 매니아 1번지

  • 시그니처: 세계 최고층 바·외국인 vlog 1번지

⚙ FAQ 6개

1. 외국인 미쉐린 1순위: 라연 3스타·비채나·유유안·반얀트리·롯데 무궁화.

2. 외국인 호텔 바 1순위: 시그니엘 BAR 81·반얀트리 문 바·콘래드 37·JW 그리핀.

3. 외국인 외부 이용: 미쉐린 다이닝·호텔 바 모두 OK + 사전 예약 (특히 주말).

4. 외국인 가성비: L7 홍대 (칵테일 15~25K)·점심 코스 (60~100K).

5. 외국인 데이트·신혼 (#277): 시그니엘 BAR 81·반얀트리 문 바·라연·비채나.

6. 외국인 호캉스 풀세트: 수영장 (#356) + 조식 (#358) + 다이닝·바 (#360) 1박2일.

  • Day 2: 09:00 조식 (#358) → 12:00 체크아웃

B. 야경 바 hopping (시그니엘·반얀트리·콘래드)

  • 18:00 콘래드 37 (여의도 한강) → 20:00 반얀트리 문 바 (남산) → 22:00 시그니엘 BAR 81 (잠실 555m)

C. 가성비 MZ 호캉스 (L7·노보텔·몬드리안)

  • Day 1: 15:00 체크인 → 17:00 풀·루프탑 → 19:00 L7 루프탑·강남 라운지 → 익일 09:00 조식 12~25K
