韓国での支払い方 — 海外カード・ATM・両替・プリペイド交通カード・スマホ決済・免税還付を、場面ごとに選ぶ

サブタイトル: 短期の旅行者が韓国で会計するときに選ぶ順番を整理しました。海外カードが使える範囲と使えない場所、海外カードを受け付けるATMの探し方と手数料のかかり方、空港・銀行・両替所、T-money・WOWPASS・NAMANE・CHECK iN SEOULなどのプリペイドカード、Alipay+・WeChat Pay・カカオペイ・ネイバーペイ、現金を受け付けないバスと無人レジ、店頭での即時還付の限度まで。どの項目も「こんなときはこれ」で終わります。

ISSUE 03 · #527 · 2026-11-25

🎯 こんな人に

韓国に数日から数週間滞在する旅行者のための回です。韓国の銀行口座も韓国の携帯番号もないと想定しました。この回は、支払い手段を一つずつ深く掘り下げることはしません。どの場面で何を出すかを決めるための地図です。カード一枚ごとの詳しい手順は別の回があるので、各節の終わりにリンクでつなぎました。

⚠ 表記の原則: 手数料・限度額・料金の横には出典と確認日を付けました。「公式」は、運営機関や会社のサイトの原文を直接開いて確認した値にだけ使いました。報道一つにしか出てこない内容は「要確認」と書きました。支払い条件はよく変わるので、大きな金額がかかるときは、当日にアプリとサイトでもう一度見てください。どの店が何を受け付けるかは店ごとに違います。会計の前に聞くほうが早いです。

① 海外カード — たいてい使えるが、使えない店がある

韓国観光公社 (Korea Tourism Organization / 한국관광공사)の英語サイトは、韓国の店の大半がクレジットカードを受け付け、大きなホテル・百貨店・一般の店でVisa・MasterCard・American Expressが使えると書いています。同じ記事に、カードを受け付けない店もあるので買う前に確認するようにという一文もあります(VisitKorea公式、ページの表記日2023-03-27、2026-11-25閲覧)。

  • 銀聯 (UnionPay): 銀聯国際のサイトは、韓国の加盟店の大半が署名方式の銀聯カードを受け付け、PIN方式は300万 (300만) か所以上で受け付けると書いています(銀聯公式)。銀聯の会社発表で、ほかの出典では確認できませんでした。受け付けない店もあります。中国本土発行カードの海外利用設定は#1333に書きました。
  • JCB: 韓国の加盟範囲を示した公式資料は見つかりませんでした(2026-11-25)。JCB一枚だけで来ないで、別ブランドのカードをもう一枚持ってきてください。
  • 決済通貨はウォン (KRW) で: カード端末やレシートに、自国通貨で請求するかを聞く画面が出たら、ウォンを選びます。現地通貨以外の通貨で決済すると両替がもう一度起こり、請求額が上がります(KB国民カード (KB Kookmin Card / KB국민카드) 海外利用案内、公式)。この案内は韓国のカードを海外で使うときの説明で、外国のカードにも同じ原理が当てはまるというのは、この回の推測です。

こんなときはこれ

  • カードが拒否された → 別ブランドのカードを出してみる。それでもだめならプリペイドカード(④)か現金を使う。
  • 市場や屋台のようにカード端末が見えない → 現金かQR決済が使えるか先に聞く。現金が必要な場所は#1301にまとめました。

② 海外カードでATMから引き出す — 海外カードを受け付ける機械を選ぶ

  • どの機械でもいいわけではない: 韓国のATMには、海外発行のカードを受け付けない機械があるそうです。同じ銀行のATM数台のうち一部だけ使えることもあり、海外カードを受け付ける機械が一台もない銀行もあるそうです。ステッカーや表示で知らせている場合があり、表示がなければ、メニューでカードの発行国を聞かれるか見ます。国内カードのメニューしか出なければ、その機械では使えないそうです(基礎科学研究院 (Institute for Basic Science / 기초과학연구원) 外国人生活案内、2019年ごろの作成と推定、2026-11-25閲覧)。
  • 銀行ごとの対応範囲: どの銀行のATMが海外カードを受け付けるのかを銀行自身が示した公式の一覧は見つかりませんでした(要確認)。銀聯のサイトは、韓国で銀聯カードでウォンを引き出せるATMが7万 (7만) 台を超えると書いています(銀聯公式、会社自身の数字)。
  • 手数料は二重にかかることがある: シティバンク (Citibank Korea / 씨티은행)とKB国民カード (KB Kookmin Card / KB국민카드)の案内は、韓国のカードを海外のATMで使うときの説明です。そこでは、現地ATMの利用手数料はATM事業者が決めて機械ごとに違い(シティバンク海外ATM案内、公式)、発行会社が国際ブランド手数料と1件ごとの手数料を別に取ります。たとえばKB国民カード (KB Kookmin Card / KB국민카드)のデビットカードは、Visaが1.0~1.1%、Mastercardが1.0%のブランド手数料に、1件3ドルです(韓国のKBカードの例、KB国民カード公式)。外国のカードで韓国のATMを使うときも、韓国のATM手数料と自分の発行会社の手数料が二重にかかるというのは、この回の推測です。実際の金額は#1286と、自分のカード発行会社の案内で確認してください。
  • クレジットカードで引き出すとキャッシングになることがある: 海外のATMでは、クレジットカードに現金引き出しとキャッシング(短期の借入)のメニューが一緒に出るので、ほしいメニューを正確に選ぶ必要があります(シティバンク公式)。KB国民カード (KB Kookmin Card / KB국민카드)は、自社のクレジットカードでは海外での現金引き出しはできず、キャッシングだけできると案内しています(KB国民カード公式)。どちらも韓国のカードを海外で使うときの案内です。自分のクレジットカードがどう扱われるかは、発行会社で確認してください。

こんなときはこれ

  • 機械の画面が韓国語の国内カードメニューだけ → 別の機械に移る。
  • 画面に手数料が出て確認を求められる → 金額を見て進めるか取り消す。通貨を選ぶ画面が出たら、ウォン (KRW) を押す。
  • 画面を一つずつたどる手順と、カードが出てこないときの対処は#1286を見る。

③ 両替 — 空港、銀行、公認の両替所

韓国観光公社 (Korea Tourism Organization / 한국관광공사)は、銀行か公認の両替所で両替するよう案内し、たいていの旅行者には空港の両替所がいちばん簡単だと書いています(VisitKorea FAQ、公式、2026-11-25閲覧)。

場所 時間 (出典) メモ
仁川空港 (Incheon Airport / 인천공항) の両替所 標準06:00~22:00、一部は24時間 (VisitKorea公式、2026-09-11更新) 到着してすぐ両替できる
仁川空港 (Incheon Airport / 인천공항) の銀行支店 (KB国民 (KB Kookmin / KB국민)・ハナ (Hana / 하나)・ウリ (Woori / 우리)) 平日09:00~16:00、週末・祝日は休み (同じページ) 第1・第2旅客ターミナルのどちらにもある

こんなときはこれ

  • 夜遅く着いた → 空港の両替所の基本の営業時間は06:00~22:00で、24時間開いているのは一部だけ。22時を過ぎたら、カードや海外カードを受け付けるATMでしのいで、翌日に両替する。空港の銀行支店は平日16:00に閉まる。
  • 大金を持って入国する、または出発のときに余ったウォンを替え戻す → 申告の基準と替え戻し方は#435にある。

⑤ スマホ決済 — 自分のアプリが使えるかは、レジのQRで決まる

  • Alipay+の提携ウォレット: 韓国観光公社 (Korea Tourism Organization / 한국관광공사)が普及させたゼロペイの標準QRは、AlipayやWeChat Payなど海外のモバイル決済17個とつながっていて、韓国のアプリを入れなくても自国のアプリで払えます(korea.net、2024-11-29。2024-11の資料で、加盟店数はなし)。Korea Timesは、韓国でAlipay+を通して決済できるウォレットとして、Alipay(中国本土)、AlipayHK、Touch 'n Go(マレーシア)、PayPay(日本)、MPay(マカオ)、GCash(フィリピン)を挙げました(2025-12-09報道、要確認)。自分のウォレットが使えるかは、ウォレットアプリの海外決済の案内で見ます。
  • WeChat Pay: 上のゼロペイ標準QRの接続一覧に入っています(korea.net、2024-11-29)。そのQRがない店で使えるかは、店ごとに違います。
  • カカオペイ: カカオペイは2025年9月、国内のカカオペイのオフライン加盟店で日本のPayPay決済を始めると発表しました(ヘラルド経済 (Herald Business / 헤럴드경제) 2025-09-24報道、加盟店数は出ていない、要確認)。外国人がカカオペイのアプリに直接登録して海外カードで使う条件は、公式の案内が見つかりませんでした(要確認)。
  • ネイバーペイ・ネイバー地図: ネイバーは2026年6月4日にパスポート認証を導入しました。海外のパスポートを持つ外国人が、韓国の携帯番号なしでネイバー地図の予約・注文・決済を使えます(ネイバー公式プレスリリース、2026-06-09)。プレスリリースには、海外カードで決済できるかは書かれていません。ネイバーペイに海外発行のクレジットカードを登録する機能は、2025年5月に「導入予定」と報じられただけで、公式の原文では確認できませんでした(亜洲経済 (Asia Economy / 아시아경제) 2025-05-16、要確認)。

こんなときはこれ

  • レジにQRの表示がある → 自分のウォレットのロゴがあるか見て、「QR gyeolje dwaeyo? (QR 결제 돼요?)」(QR決済できますか?)と聞く。
  • 表示がない → カードかプリペイドカードで払う。
  • Alipay・WeChat Pay・銀聯を合わせて使う中華圏の旅行者の順番は#1333にまとめました。

⑥ 無人キオスク、現金を受け付けない所

  • 現金なしバス: ソウル市 (Seoul / 서울시)は、2026年1月時点の「現金なしバス」の運行路線の一覧を交通サイトに載せています(ソウル市公式)。南山循環バス01A・01Bも現金を受け付けません(ソウル市メディアハブ (Seoul Media Hub / 서울시 미디어허브) 2024-11-28)。ソウル市は、交通カードなしで乗った乗客をいったん乗せて、口座振込かモバイルT-moneyで運賃を払わせ、外国人乗客向けの英語・中国語・日本語の案内文を作ったと発表しました(2024-02-15)。Korea Timesは、2026年4月時点でソウルのバス394路線のうち180路線が現金を受け付けないと報じました(2026-11-11、要確認)。
  • 現金なしの店: 現金を受け付けない店や銀行の支店もあります。韓国銀行 (Bank of Korea / 한국은행)は、現金の受け入れを増やす政策が必要だと報告書に書きました(Korea Times 2026-11-11報道)。どの店が現金を受け付けないかは店ごとに違うので、この回には一覧を載せません。
  • キオスク: 食堂・カフェの注文キオスクやセルフレジが海外カードを受け付けるかを一般化した公式資料は、見つかりませんでした(要確認)。カードが読み取られなければ、有人のレジに行きます。

こんなときはこれ

  • バスに乗る → 乗る前に交通カードの残高を入れておく(④)。
  • キオスクの画面が韓国語だけ → 画面の順にたどる方法は#1270、セルフレジ・夜間の無人コンビニは#1306。

⑦ 免税還付 — 店頭の即時還付、市内還付、空港還付

方式 条件 (出典)
共通 韓国に6か月未満滞在する外国人、購入額15,000ウォン以上、新品(未開封・未使用)、購入日から3か月以内に出国 (VisitKorea公式、2025-10-21更新)
店頭の即時還付 1回の決済が15,000ウォン以上100万ウォン (100만 원) 未満、旅行全体の合計が500万ウォン (500만 원) 以下 (VisitKorea公式 · 外国人観光客等に対する付加価値税及び個別消費税特例規定 (외국인관광객 등에 대한 부가가치세 및 개별소비세 특례규정) 第6条 ②、国家法令情報センター (Korea Law Information Center / 국가법령정보센터))
市内の還付窓口 その窓口を運営する還付会社のレシートだけを処理する。レシート1枚あたり600万ウォン (600만 원) 以下。海外のクレジットカード(AlipayやWeChat Payを含む)で受け取るか、現金ですぐ受け取る (VisitKorea公式)
空港・港の還付 すべての還付会社のレシートを受け付ける。滞在中の購入に限度なし。現金は保安検査のあとの免税エリアで受け取る。海外のクレジットカード・Alipay・WeChat Payで受け取ると、届くまで1~2か月かかる。窓口がない、または閉まっているときは、レシートに受け取り先を書いて指定の箱に入れる。手続きは空港・港ごとに違うので、現場の係員に確認する (VisitKorea公式)

こんなときはこれ

  • 一つの店で100万ウォン (100만 원) 未満の買い物をする → 会計のときにパスポートを出して、即時還付を受ける。
  • 市内の窓口で受け取れなかった → 空港・港の窓口はすべての会社のレシートを受け付ける。三つの方式のうち自分の買い物はどれかを選ぶには#1231。空港キオスクの画面の順番は#1304。免税店での買い物は#775。

⚠ よくある失敗3

  1. 決済画面で自国の通貨を選ぶ — カード端末やATMが通貨を聞いてきたら、ウォン (KRW) を選びます。ほかの通貨を選ぶと、両替がもう一度起こります(KB国民カード (KB Kookmin Card / KB국민카드) 公式案内の原理で、外国のカードへの適用はこの回の推測)。
  2. 海外カードを受け付けないATMで試し続ける — 同じ銀行のATMの中にも、海外カードを受け付ける機械は別にあります。国内カードのメニューしか見えなければ、別の機械に移ります(基礎科学研究院 (Institute for Basic Science / 기초과학연구원) 生活案内、2019年ごろの作成と推定)。
  3. 交通カードなしでバスに乗る — ソウルには現金を受け付けないバス路線があります(ソウル市公式)。空港を出る前に、交通機能のあるカードを買ってチャージしておきます。

⚙ FAQ 3

  1. 現金はどのくらい持ち歩く? — 日程によって違います。現金が必要な場所と、1日に持ち歩く目安は#1301にまとめました。
  2. チップは払う? 会計はどこで? — カウンターで払う方法とチップの習慣は#1275を見てください。
  3. タクシーは何で払う? — カカオTのアプリにカードが登録できないとき、運転手に直接払う方法は#1273にあります。
