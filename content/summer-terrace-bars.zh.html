为什么是夏夜首尔 — 屋顶·户外露台的季节

首尔的夏天白天炎热,但太阳一落山,城市就变了样。屋顶上 N首尔塔 (N Seoul Tower / N서울타워) 与 汉江 (Hangang / 한강) 的夜景亮起,小巷里的自然派葡萄酒吧开门营业,解放村 (Haebangchon / 해방촌)·经理团 (Gyeongnidan / 경리단) 的露台聚满了人。外国人在谷歌上搜索 "best rooftop bars Seoul"、"natural wine bar Seoul"、"Seoul terrace dining" 的季节,正是现在。

这份指南把三种类型分开来讲。屋顶观景酒吧(景观即武器)、自然派葡萄酒吧小巷(乙支路 (Euljiro / 을지로)·圣水 (Seongsu / 성수)·狎鸥亭 (Apgujeong / 압구정) 的时髦一杯)、户外露台餐饮(在户外享用塔帕斯·欧式料理)。还有一点 — 诚实地讲出 夏季户外的真相。首尔盛夏的白天又湿又热。露台其实最好的季节是 春·秋,夏天则是 太阳完全落山后的晚8点以后,或者搭配空调室内才现实。了解这个时机再去,夏夜也能尽情享受。

本矩阵为 屋顶观景3选 + 自然派葡萄酒吧3选 + 户外露台餐饮3选 + 特色一杯·社区夜摊3选 = 12选4轴。

12选4轴矩阵 — 夏夜首尔一杯

轴 1:屋顶观景酒吧(3选)

#1. 克劳德屋顶酒吧 (Rooftop KLOUD / 루프탑 클라우드) — 360度 N首尔塔·汉江全景

  • 📍 位置: 江南区 (Gangnam-gu / 강남구) 德黑兰路25街 (Teheran-ro 25-gil / 테헤란로25길),AC酒店21层(驿三站 (Yeoksam Station / 역삼역) 附近)
  • 🕐 推荐时间: 傍晚日落~夜间(暑气散去后)
  • 招牌: 360度全景(N首尔塔·江南 (Gangnam / 강남) 天际线·汉江)· 柚子烧酒鸡尾酒 · 入选 World's 50 Best Rooftop Bars
  • 💵 价格带: 鸡尾酒 ₩18,000~28,000 (~$14~21)
  • 外国人 tip: 酒店屋顶,英语接待·刷卡顺畅。夜景巅峰在日落刚过时。周末傍晚建议预约。

#2. 南区客厅 (Southside Parlor / 사우스사이드 팔러) — 德州概念屋顶露台

  • 📍 位置: 龙山区 (Yongsan-gu / 용산구) 绿莎坪 (Noksapyeong / 녹사평)·经理团一带(绿莎坪站 (Noksapyeong Station / 녹사평역))
  • 🕐 推荐时间: 傍晚~深夜
  • 招牌: 德州式概念 · 烟熏牛胸肉塔可 · 认真的鸡尾酒项目 · 入选亚洲最佳酒吧排名 · 惬意的屋顶露台(绿莎坪景观)
  • 外国人 tip: 外国人经营·英语沟通顺畅,是梨泰院 (Itaewon / 이태원) 圈的代表性屋顶。南山 (Namsan / 남산)·绿莎坪视野开阔。

#3. 特权酒吧 (Privilege Bar / 프리빌리지 바) — 蒙德里安酒店屋顶,日落绝佳位

  • 📍 位置: 龙山区长门路23 (Jangmun-ro 23 / 장문로 23),首尔梨泰院蒙德里安酒店 (Mondrian Seoul Itaewon / 몬드리안 서울 이태원) 楼顶(RF)(梨泰院站 (Itaewon Station / 이태원역))
  • 🕐 推荐时间: 日落时段(天空染成橙→粉→紫时)
  • 招牌: 灵感来自世界8篇童话的鸡尾酒(灰姑娘·爱丽丝梦游仙境)· 户外露台 · 首尔在脚下被染色的落日景观
  • 💵 价格带: 鸡尾酒 ₩25,000~35,000 (~$19~26)
  • 外国人 tip: 特别的日子·约会绝佳地。日落前40分钟到达占位。建议智能休闲装。

轴 2:自然派葡萄酒吧小巷(3选)

#4. MXL酒吧 (MXL / 엠엑스엘) — 乙支路印刷巷的香港氛围葡萄酒吧

  • 📍 位置: 中区 (Jung-gu / 중구) 乙支路印刷·包装巷(乙支路3街站 (Euljiro 3-ga Station / 을지로3가역))
  • 🕐 推荐时间: 傍晚~深夜
  • 招牌: 满是红色的香港风内饰 · 全部为自然派葡萄酒的酒单 · 意面·沙拉·土豆煎饼
  • 为何特别: 藏在被称作"潮乙支路 (Hipjiro / 힙지로)"的印刷厂小巷正中央、只有识货者才找得到的自然派葡萄酒吧。韩式下酒菜(土豆煎饼)与自然派葡萄酒的搭配很新鲜。
  • 外国人 tip: 招牌不显眼,请用 Instagram·Naver 地图保存位置。座位少,傍晚早些时候更从容。

#5. 多米克斯首尔 (Domix Seoul / 도믹스 서울) — 圣水小巷的自然派葡萄酒 + 融合韩餐

  • 📍 位置: 城东区 (Seongdong-gu / 성동구) 圣水洞 (Seongsu-dong / 성수동),圣水站 (Seongsu Station / 성수역) 附近小巷
  • 🕐 推荐时间: 傍晚
  • 招牌: 小巷里的隐藏葡萄酒吧 · 主菜8种·小菜3种的简洁下酒菜 · 多样的自然派葡萄酒
  • 为何特别: 在"首尔的布鲁克林"圣水,避开大型快闪人潮的巷内一杯。融合韩餐与自然派葡萄酒。
  • 外国人 tip: 圣水快闪之旅(#001)结束后来收尾一杯。规模小,周末傍晚可能需要等位。

#6. 库乔洛露台 (Cucciolo Terraza / 쿠치올로 테라짜) — 狎鸥亭隐秘内院露台

  • 📍 位置: 江南区狎鸥亭(狎鸥亭站 (Apgujeong Station / 압구정역))
  • 🕐 推荐时间: 傍晚(夏天太阳落山后内院凉爽)
  • 招牌: 隐秘内院(courtyard)露台 · 手工意面·面包等意式料理 · 自然派葡萄酒搭配
  • 为何特别: 本榜单中最适合夏季户外的一档。因为是建筑内侧的内院,隔绝了市区噪音。
  • 外国人 tip: 户外内院座位很抢手,建议预约。兼作意式餐厅与葡萄酒吧,晚餐也能一并解决。

轴 3:户外露台餐饮(3选)

#7. 蹦蹦 (Bangbang / 방방) — 解放村新兴市场屋顶露台葡萄酒吧

  • 📍 位置: 龙山区解放村新兴市场 (Sinheung Market / 신흥시장)(绿莎坪站·解放村)
  • 🕐 推荐时间: 凉爽的夏夜(户外露台)
  • 招牌: 现代欧式餐饮葡萄酒吧 · 享受解放村独特氛围的户外露台 · 迎着晚风品酒
  • 为何特别: 夏季傍晚户外露台的代表。在新兴市场之上,伴着解放村夜景来一杯葡萄酒。
  • 外国人 tip: 露台座位必须预约(夏季傍晚尤其抢手)。解放村是坡道,鞋子请穿舒适的。

#8. 四季花园露台 (Four Seasons Garden Terrace / 포시즌스 가든 테라스) — 市中心酒店屋顶花园

  • 📍 位置: 钟路区 (Jongno-gu / 종로구) 光化门 (Gwanghwamun / 광화문),首尔四季酒店 (Four Seasons Hotel Seoul / 포시즌스 호텔 서울)(光化门·市厅站 (City Hall Station / 시청역))
  • 🕐 推荐时间: 傍晚
  • 招牌: 酒店屋顶花园露台餐饮 · 庭园式户外休闲区 · 市中心里的绿色景观
  • 为何特别: 与小巷时髦酒吧形成对比的精致酒店花园餐饮。适合商务·纪念日。
  • 外国人 tip: 英语接待完美·刷卡。价格偏高,适合特别的日子。

#9. APT首尔 (APT Seoul / 에이피티 서울) — 梨泰院全景屋顶休闲吧

  • 📍 位置: 龙山区梨泰院(梨泰院站)
  • 🕐 推荐时间: 傍晚~深夜
  • 招牌: 精致的屋顶休闲吧 · 全景市区视野 · 创意招牌鸡尾酒 · 高档酒吧小食
  • 为何特别: 深受年轻上班族·旅行者喜爱的时尚屋顶。景观与鸡尾酒·下酒菜兼得。
  • 外国人 tip: 位于梨泰院圈,对外国人友好。与轴1的屋顶们串成梨泰院一日动线很合适。

轴 4:特色一杯 + 社区夜摊(3选)

#10. 参吧 (Bar Cham / 바 참) — 西村百年韩屋的传统酒鸡尾酒

  • 📍 位置: 钟路区紫霞门路7街34 (Jahamun-ro 7-gil 34 / 자하문로7길 34),西村 (Seochon / 서촌)(景福宫站 (Gyeongbokgung Station / 경복궁역),景福宫 (Gyeongbokgung / 경복궁) 附近)
  • 🕐 推荐时间: 傍晚~夜间
  • 招牌: 由百年韩屋改造 · 以韩国传统酒为基底的鸡尾酒(忠州·咸阳等地名)· 吱呀作响的原木地板·柔和灯光
  • 💵 价格带: 鸡尾酒 ₩20,000~25,000 (~$15~19)
  • 为何特别: 与屋顶·葡萄酒吧完全不同的调性。在韩屋里用韩国传统酒调制的鸡尾酒 = 对外国人而言最"K"的一杯。
  • 外国人 tip: 安静的韩屋酒吧,氛围沉静。与 #1235 西村·付岩洞 (Buam-dong / 부암동) 安静白天行程作昼夜 cross。

#11. 乙支路夜摊巷 (Euljiro Night-Terrace Alleys / 을지로 야장 골목) — 老店户外桌的"潮乙支路"

  • 📍 位置: 中区乙支路3街 (Euljiro 3-ga / 을지로3가) 明太鱼干巷 (Nogari Alley / 노가리골목)·印刷巷 (Print Alley / 인쇄골목) 一带(乙支路3街站)
  • 🕐 推荐时间: 夏季傍晚~深夜(户外桌)
  • 招牌: 老店摆在巷子里的户外塑料桌 · 明太鱼干·啤酒 · 藏在老建筑里的时髦咖啡馆·酒吧
  • 为何特别: 韩式"夜摊 (yajang / 야장,即户外露天酒局)"文化的精髓。与高档屋顶截然相反的本地夏夜。
  • 外国人 tip: 现金·刷卡混用,不少店没有招牌。傍晚6点以后巷子里铺开桌子。就是K-剧里的"乙支路情调"。

#12. 圣水演武场路露台聚集区 (Seongsu Rooftop & Terrace Cluster / 성수 연무장길 테라스 클러스터) — 仓库风屋顶密集

  • 📍 位置: 城东区圣水洞演武场路 (Yeonmujang-gil / 연무장길) 一带(圣水站)
  • 🕐 推荐时间: 傍晚(夏天太阳落山后)
  • 招牌: 由旧工厂·仓库改造的屋顶酒吧·露台咖啡酒吧密集 · 工业风氛围 · MZ热门地
  • 为何特别: 不是某一家,而是整条巷子都是选项。圣水快闪·买手店(#001)白天之旅后,接续到傍晚的露台。
  • 外国人 tip: 与其选单店,不如边逛巷子边挑中意的露台。周末傍晚要考虑排队。

FAQ 6 — 外国人常问的夏夜首尔问题

Q1. 景观最好的屋顶是?

  • 360度全景: #1 KLOUD(N首尔塔·江南·汉江尽收眼底)
  • 日落绝佳位: #3 Privilege Bar(蒙德里安屋顶)
  • 梨泰院圈露台: #2 Southside Parlor · #9 APT Seoul

Q2. 自然派葡萄酒去哪喝?

  • 乙支路时髦: #4 MXL(印刷巷·土豆煎饼搭配)
  • 圣水小巷: #5 Domix Seoul
  • 夏季户外内院: #6 Cucciolo Terraza(狎鸥亭)

Q3. 听说夏天露台不怎么样?

  • 没错 — 首尔盛夏白天又热又湿。晚8点以后 才舒适,真正的露台季节是 春·秋。夏天现实的做法是把 #6·#7 露台安排在晚傍晚去,或者搭配屋顶·葡萄酒吧的室内。

Q4. 需要预约吗?

  • 露台座位(#6 Cucciolo·#7 Bangbang): 夏季傍晚必须预约。
  • 周末傍晚屋顶(#1·#3): 建议预约。
  • 社区夜摊(#11 乙支路·#12 圣水): 大多 walk-in,6点后巷子摆桌。

Q5. 最"K"的一杯是?

  • #10 Bar Cham — 西村百年韩屋里用韩国传统酒调制的鸡尾酒。与屋顶·葡萄酒吧截然不同,对外国人而言最印象深刻的K-体验。

Q6. 预算·支付?

  • 屋顶鸡尾酒 ₩18,000~35,000(~$14~26)/杯。葡萄酒吧有瓶·杯多种单位。
  • 酒店屋顶刷卡·英语顺畅。乙支路老店夜摊现金混用。
  • 饮酒须满19岁以上,携带护照。

半日行程 3 — 按地区串联的夏夜动线

行程 1. 梨泰院·经理团屋顶巡游(龙山)

  • PM 19:00 — Privilege Bar #3(蒙德里安屋顶,日落)
  • PM 20:30 — Southside Parlor #2(绿莎坪,牛胸肉塔可 + 鸡尾酒)
  • PM 22:00 — Bangbang #7(解放村新兴市场露台,收尾葡萄酒)
  • fit: 对外国人友好的梨泰院圈屋顶·露台全套。

行程 2. 乙支路·圣水自然派葡萄酒(市中心·江北)

  • PM 18:30 — MXL #4(乙支路印刷巷,自然派葡萄酒 + 土豆煎饼)
  • PM 20:00 — 乙支路夜摊巷 #11(明太鱼干巷户外一杯)
  • PM 21:30 — 移动至圣水 → Domix #5 或演武场路 #12(圣水小巷收尾)
  • fit: 潮乙支路 + 圣水,MZ·本地情调。

行程 3. 江南·狎鸥亭高档(江南)

  • PM 19:00 — Rooftop KLOUD #1(驿三,360度夜景 + 柚子烧酒鸡尾酒)
  • PM 21:00 — Cucciolo Terraza #6(狎鸥亭内院露台,意式料理 + 葡萄酒)
  • fit: 景观 + 餐饮,约会·纪念日。

季节笔记 4 — 户外饮酒的季节性

夏季(6~8月)— 晚傍晚·室内搭配

  • 避开白天酷暑,晚8点以后 屋顶·露台 · 搭配室内葡萄酒吧(#4·#5)
  • #7 Bangbang·#11 乙支路夜摊在凉爽的夜晚去

春·秋(4~5月·9~11月)— 露台最佳季节

  • 户外露台真正的季节。#6 Cucciolo 内院·#7 Bangbang·#12 圣水露台 100%
  • 凉爽的傍晚 = 屋顶·夜摊的黄金时段

冬季(12~2月)— 室内屋顶·葡萄酒吧

  • 以有室内座位的酒店屋顶(#1·#8)·葡萄酒吧(#4·#5·#10 韩屋)为主
  • 户外夜摊为淡季(部分运营暖气帐篷)

梅雨(6月末~7月)— 室内优先

  • #10 Bar Cham 韩屋·#4·#5 自然派葡萄酒吧等室内
  • 屋顶·露台雨天运营受限 — 到访前确认

外国人贴士 5 — 正确享受夏夜首尔的方法

Tip 1. 户外要晚8点以后

首尔盛夏白天又湿又热。屋顶·露台真正的魅力在太阳完全落山的晚8点以后展开。白天时段请搭配室内葡萄酒吧。

Tip 2. 露台座位提前预约

Cucciolo·Bangbang 这类热门露台,夏季傍晚位子很快就满。用 Instagram DM·Naver预约·CatchTable 提前订好。

Tip 3. 混搭三种类型

景观(屋顶)→ 一杯(自然派葡萄酒)→ 收尾(露台 or 韩屋),把性格不同的场所串起来,夏夜就丰盛了。参考3个半日行程。

Tip 4. 支付·语言因场所而异

酒店屋顶(KLOUD·Privilege·Four Seasons)英语·刷卡完美。而乙支路老店夜摊现金混用·无招牌。巷子里的店请用 Naver 地图保存位置。

Tip 5. 来一杯最"K"的

不只是西式鸡尾酒·葡萄酒,像 #10 Bar Cham 那样在韩屋里用韩国传统酒调制一杯鸡尾酒,旅行的记忆会不一样。
