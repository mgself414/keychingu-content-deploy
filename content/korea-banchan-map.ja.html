🎯 このガイドの使い方

ご飯を一膳頼むと、小皿が一つ二つと並び、キムチの皿を空にすると黙って新しい皿が置かれる。このガイドが扱うのは、そのパンチャン (반찬、ご飯に添える小さなおかず) そのものだ。パンチャンの出方とおかわり、パンチャンがずらりと並ぶペクパン (백반、定食) 屋・運転手食堂、パンチャンを買って帰る市場、キムチ。韓定食コース・ミシュランの韓国料理・精進料理は #478 韓定食ガイド に回す。住所・時間はVisitKorea・VisitSeoul・UNESCOで読み取れた値だけを載せた。高いコースではなく、街の食堂でパンチャンをしっかり味わいたい人のための一冊だ。

以前のガイドは、宗家 (종갓집)・両班家 (반가)・宮中・精進料理をパンチャンとしてまとめ、「眞鑑寺の精進料理 = 国家無形文化財」「ソンジェ師 (선재스님) がChef's Tableに出演」と書いていた。どちらも誤りだ — 指定されたのは眞鑑寺の水陸斎 (진관사 수륙재、仏教儀礼) で、Chef's Tableに出たのは白羊寺 (백양사) のジョングァン師 (정관스님) だ (訂正の根拠は#478)。「通仁市場の弁当5,000ウォン」のような価格も公式の出典がなく削除した。

🍚 パンチャンの出方 — おかわりのルール

  • おかわり無料、チップなし: 韓国の食堂ではチップは要らず、水やパンチャンを追加でもらっても追加料金はかからない (VisitKorea)
  • セルフのパンチャン: 水とパンチャンを自分で取りに行くセルフ方式や、無人の注文機を使う食堂が増えている (VisitKorea)
  • 呼ぶとき: 追加で頼みたいときや聞きたいことがあるときは「ヨギヨ (여기요)!」(「ここです!」の意味) と呼ぶ (VisitKorea)
  • パンチャンがなぜこんなに多く出るのかは #1132 韓国のパンチャン文化

🥢 ペクパン・運転手食堂 — パンチャンが並ぶ街の食堂

  • カムナムジプ運転手食堂 (감나무집기사식당): ソウル麻浦区延南路 (연남로) 25。豚プルコギが看板で、パンチャンもたっぷり出る。24時間、年中無休。02-325-8727。京義線の森道に近い (VisitKorea)
  • ポグァン運転手食堂 (보광기사식당): ソウル龍山区長門路 (장문로) 6ギル97 (東氷庫洞)。豚ペクパン・豚辛炒め。一人注文可、水・ご飯・パンチャンはセルフ、食べ残すと追加料金。08:00~22:00、日曜休み。0507-1402-8579 (VisitKorea)
  • トルサンペクパン (돌산백반): 全南麗水市江南8ギル (강남8길) 13。トルサンペクパンは毎日違うおかず9種、焼き魚は2人前から。06:30~20:00 (休憩15:00~17:00)、日曜休み。0507-1333-7374 (VisitKorea)
  • イルロ市場ペクパン (일로장터백반): 全南務安郡市場通り (시장길) 17-12。メニューはペクパン一つ — 漬物・ネギキムチなど全羅道風のパンチャン。09:30~16:00、月曜休み。061-282-8074 (VisitKorea)
  • パンチャン食堂 (반찬식당): 大田中区宝文山公園路 (보문산공원로) 484。麦ご飯の専門店で、野菜・ナムル・キムチ・チゲが一膳にのる。07:00~20:00 (平日休憩14:30~16:00)、月曜休み、カード可。042-253-2794 (VisitKorea)
  • 五か所とも価格は未掲載

🛒 パンチャンを売る市場 — 買って帰るおかず

  • 通仁市場 (통인시장): ソウル鍾路区紫霞門路 (자하문로) 15ギル18。約70店舗のうち、食堂・おかず店などの飲食店がいちばん多い。2012年から弁当カフェ「トン (통)」を運営している。店舗 07:00~21:00、弁当カフェ 11:00~15:00、休みは店舗ごと。0507-1378-0940 (VisitKorea)。銅銭弁当の動線は #589 通仁市場ガイド
  • 延曙市場 (연서시장): ソウル恩平区統一路 (통일로) 850 (延新内駅の近く)。農産物・水産物・精肉・おかずを売る。時間・休みは店舗ごと。02-355-1272 (VisitKorea)
  • 江陵東部市場 (강릉 동부시장): 江陵市玉川路 (옥천로) 48。法事・祭祀の料理などおかずの材料と、塩辛・キムチを売る。06:00~23:00 (店舗により異なる)、カード可、1時間無料駐車。033-647-7999 (VisitKorea)

🥬 キムチ — 博物館と漬け込み体験

  • キムジャン: キムチは調味料と塩辛で和えた野菜の保存食だ。キムジャン (キムチを漬けて分かち合うこと) は2013年にユネスコ無形文化遺産の代表一覧表に登録された (UNESCO)
  • ミュージアム キムチ間 (뮤지엄 김치간): ソウル鍾路区仁寺洞通り (인사동길) 35-4 仁寺洞マル (인사동마루) 本館4~6階。10:00~18:00 (最終入場17:30)、月曜・1月1日・ソルラル・秋夕の連休・12月25日は休館。体験「It's Kimchi」「Kimchi Basic」「Kimchi Master」(有料) とキムチスクール (無料)、事前予約必須、6歳以上。02-2088-8531 (VisitKorea)。料金は公式サイトkimchikan.comで確認する
  • キムチスクール釜山支店 (김치스쿨 부산지점): 釜山機張郡機張邑東釜山観光9路 (동부산관광9로) 15、2階。キムチ作り体験・販売。09:30~16:00、カード可 (VisitKorea)
  • 済州キムチスクール (제주김치스쿨): 済州市西海岸路 (서해안로) 136。キムチ漬け体験・販売。08:00~17:00、カード可。064-712-9688 (VisitKorea)
  • 海南キムチ村 (해남김치마을): 全南海南郡北平面東海通り (동해길) 97。季節ごとの体験村、常時開放・年中無休。0507-1326-1743 (VisitKorea)
  • キムジャン体験のシーズン情報は #751 キムジャンキムチ体験

🥗 食事

  • 価格帯: このガイドに公式掲載のウォン価格はない。ペクパン屋・市場・キムチ体験とも価格の欄が空だ
  • ベジタリアン: キムチは塩辛で和える (UNESCO) — おかずのキムチ・ナムル・漬物にも塩辛や肉のだしが入っているか、注文前に聞く。肉なしの希望は #1300 食事リクエストマニュアル の見せるカードを使う
  • ハラール: VisitSeoulは梨泰院のイード (이드)を、韓国イスラム教中央会(KMF)がハラールと認めた数少ない店の一つとして紹介している(龍山区ウサダン路10ギル15、毎日12:00〜21:00)。認証は変わることがあるので、訪問前に確認する。このガイドのペクパン屋にハラール表記はなく、豚プルコギが看板の店が二つある
  • アレルギー: 塩辛 (エビ・カタクチイワシなどの海産物) がキムチに使われる (UNESCO)。甲殻類アレルギーは事前に伝える

🧰 パンチャンの実務 — 一人、予約、支払い、注文、移動

  • 一人: ポグァン運転手食堂 (보광기사식당) は一人注文可 (VisitKorea)。トルサンペクパン (돌산백반) の焼き魚は2人前からだ。一人で座りやすい食堂は #348 Seoul Solo Diner Map
  • 予約: ペクパン屋に予約案内はない。ミュージアム キムチ間 (뮤지엄 김치간) の体験は事前予約必須 (VisitKorea)
  • 支払い: パンチャン食堂 (반찬식당)・江陵東部市場 (강릉 동부시장)・キムチスクール2か所はカード可 (VisitKorea) — それ以外は #527 韓国の決済システム
  • 注文: パンチャンを追加でもらうときは「ヨギヨ (여기요)!」(VisitKorea)。言葉が通じないときは #1339 注文エチケット
  • 移動: 麗水・務安・大田は #1297 高速・市外バスマニュアル、ソウル市内は #1298 交通カード3種の選び方

⚠ よくある間違い4つ

1. 「パンチャンをもっと頼むとお金がかかる」 — 水・パンチャンの追加は無料だ (VisitKorea)

2. 「残しても構わない」 — ポグァン運転手食堂 (보광기사식당) は食べ残すと追加料金を取る (VisitKorea)。セルフのパンチャンは食べられる分だけ取る

3. 「チップを置いて出る」 — 韓国の食堂にチップはない (VisitKorea)

4. 「月曜にキムチ博物館」 — ミュージアム キムチ間 (뮤지엄 김치간) は月曜休館だ (VisitKorea)
