🎯 なぜ韓国ハーブワークフローガイドなのか

[#876ハーブ6種マトリックス](#876) 知っていても — 調理・限定食・査察料理は別個。韓国ハーブは(a) 韓食式おかず (無限詰め替え4～6種・無料) (b) 査察料理コース (本格ベジタリアンフルセット)外国人は（1）ビビンバ5色＝ハーブフルセットモール（2）査察食品＝五信彩×モール（3）春山菜マニアモール（4）無限詰め替え＝無料モール。このガイドは5ステップ+ベジタリアンマナー+英語発話。

＃＃🌿チャンネル別ワークフロー

Type A — 限定式おかずフルセット ([#837](#837))

  • シグネチャー：ハーブ4～6種無限詰め替え・無料 #1
  • 時間: 11:30～22:00
  • 価格: 限定式コース 40,000～150,000ウォン(ハーブ無料)
  • メニュー：ほうれん草・虎、もやし、シダなど4～6種
  • 外国人親和性: ★★★★

Type B — 査察料理コース (Temple Cuisine)

  • シグネチャー：本物のベジタリアン・オ・シンチェX
  • 時間: ランチ・ディナー（予約推奨）
  • 価格: 査察食品コース 25,000～80,000ウォン/1人
  • メニュー：ハーブ6種+豆腐・きのこ・山菜
  • 外国人親和性: ★★★★★ (グローバルベジタリアンマニア)
  • おすすめ: 鎮関寺・曹渓寺・奉恩寺・全国産寺（冠岳山・景福宮付近）

Type C — 全州ビビンバ (5色本物) ([#856](#856))

  • シグネチャー: 5色ハーブフルセット +卵+コチュジャン
  • 時間: 11:00～22:00
  • 価格：ビビンバ= 8,000〜25,000ウォン/ 1人
  • メニュー: 5色
  • 外国人親和性: ★★★★★ (全州正統・グローバル認知)

Type D — 家庭式白斑・MZ韓国料理店 ([#854](#854))

  • シグネチャー：ホームスタイル・ハーブ2～3種無料
  • 時間: 11:00～22:00
  • 価格：8,000〜15,000ウォン/ 1人
  • メニュー：ご飯+国+メイン+ハーブ2〜3種+キムチ
  • 外国人親和性: ★★★★

Type E — 市場老舗（春の山菜）

  • シグネチャー:春山菜・江原・全羅本格
  • 時間: 09:00～22:00
  • 価格：1パック3,000〜25,000ウォン
  • メニュー: 春の山菜（ドラジ・酔・ミナリ・シダ）
  • 外国人親和性: ★★★ (韓国語正統)

＃＃🌶外国人英語発話サンプル

  • "ビビンバ5色" = "5-color bibimbap with 5 vegetable sides"
  • "査察食品を誤信せずに" = "Temple cuisine, no five pungent vegetables (no garlic·onion)"
  • "限定式おかず無限リフィル" = "Free refills of side dishes (banchan), please"
  • "春の山菜" = "Spring mountain vegetables (Doraji・Chwi・Minari・Gosari)"
  • "ベジタリアン・ビーガン" = "Vegan / vegetarian — but check for fish sauce・anchovy in some namul"
  • "カードですか？" = "Card accepted?"

＃＃⚠外国人の頻繁なミス7つ

1. "ハーブ=草": ハーブ=限定式のおかず本物・マニア。

2. "ビビンバ=メイン": ビビンバ=5色ハーブフルセット（ほうれん草・にんじん・もやし・シダ・ドラジ）。

3. "査察食品=プルマン":査察食品=ハーブ+豆腐・きのこ・山菜・五新菜X（ニンニク・ネギ）。

4. "ベジタリアン=無条件OK": ベジタリアン= ハーブ いくつかのアンチョビアクチョン含有可能（事前確認）。

5. "限定式のおかず=費用": 限定式のおかず= 無料の無限詰め替え。

6. 「春の山菜＝四季」：春の山菜（ドラジ・臭・セリ）＝春3～5月#1。

7. "全州ビビンバ=一般": 全州ビビンバ=5色ハーブ本物#1・宮中ビビンバcluster。

⚙ よくある質問8件

1. 最初のハーブ=どのチャンネル: 全州ビビンバ (5色フルセット) → 限定式のおかず。

2. インスタ・vlog: 限定式おかず・全州ビビンバ・査察食品陳関寺。

3. MZ トレンド: 査察料理本格・MZ 韓国料理 春のハーブ・5色ビビンバ。

4. ハラール・ベジタリアン・ビーガン：6種全てOK・査察食品#1

5. 春の山菜: キキョウ、臭、セイヨウ、シダ（3～5月）。

6. アレルギー・妊娠: [#876 disclaimer](#876)参照。

7. 決済・チップ: カードOK / マーケット=現金一部/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

ハーブ＝一般食品・植物基盤。妊婦・子ども＝OK。アレルギー（ニンニク・醤油グルテン・キキョウ薬材・アンチョビ アクチョン一部添加事前確認） 事前告知。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：6種すべてOK・査察料理#1。
  • ベジタリアン・ビーガン：6種すべてOK・アンチョビアクチョン添加一部店舗事前確認。
  • グルテンフリー: 醤油味付け=グルテン(タマリ代替)。
  • 査察食品（オ・シンチェX）：ニンニク調味料を除くときにOK。
