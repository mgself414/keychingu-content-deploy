韩国KTX初次搭乘，跟着流程走 — 在没有闸机的车站不迷路的方法

① 订票3种途径 — 在哪里、怎么买

方式 在哪里 海外卡 备注
官方App(코레일톡, Korail Talk) App Store/Google Play ★ 比官网通过率高很多 出发前30天开放订票，可直接选座
官网(letskorail.com) 电脑/手机浏览器 被拒频率高(VAN基础设施特性) 没装App时的备用方案

韩国支付网络只部分支持国际EMV标准，所以在网页上海外卡经常被拒(结构详见#527)。Korail Talk App是首选途径 — 出国前先装好(参考#1230必备App篇)。

② Korail Talk订票操作全流程 — 照画面走

1. 「出发站(출발역)」搜索框 → 用英文输入站名(如Seoul) → 点选列表里的结果

2. 「到达站(도착역)」同样用英文搜索

3. 选日期·时间的日历 → [ 查询(조회) ]

4. 列车列表(KTX/无穷花号(무궁화)/SRT混合显示——务必确认是KTX) → 点想要的时间[ 选择(선택) ]

5. 在座位分布图上直接点想要的座位(靠窗/靠走道) → [ 下一步(다음) ]

6. 结算画面 → 输入银行卡信息 → [ 结算(결제하기) ]

订票完成后，App画面本身就是车票。不需要打印纸质票——删掉App或退出登录就等于丢票，一直留到列车抵达为止。

③ "没有闸机" — 最大的文化冲击

和地铁(#1281)不同，KTX站台入口没有闸机(개찰구)、没有闸门。就算没票，物理上也能直接走进去。这不是漏洞，而是免验票的信任制度——设计前提是乘客本来就应该持有有效车票。

  • 查票员会在车厢内不定期巡查确认车票
  • 截图不被承认为凭证 — 只有登录状态下Korail Talk App里的实际订票画面才有效
  • 一旦被查出逃票，会被处以罚款(票价的数倍)

别因为"没看到查票的人"就放松警惕——车票必须随时保持在能打开App查看的状态。

④ 读懂电子显示屏 — 找乘车处(站台)

车站候车厅的电子显示屏上会显示「列车号·目的地·出发时间·乘车处(타는 곳)」。关键陷阱：乘车处(站台号)要到出发前约15分钟才会公开。没提前显示是正常的，空着也不用担心。

列车号 目的地 出发 乘车处
KTX 401 釜山 Busan 09:15 7
KTX 105 大田 Daejeon 09:20 —(未公开)

用订票画面上的列车号去电子显示屏上对应那一行。如果目的地·时间相近的列车有好几班，列车号就是唯一的识别标志。

⑤ 首尔站的规模感 — 什么时候、往哪走

首尔站的KTX站台分布在3~14号这个范围，向地下大幅延伸。建议出发前20~30分钟到站——虽然没有闸机不会卡住你，但车站本身很大，候车厅→确认电子显示屏→扶梯/楼梯移动这一路实际要花不少步行时间。

动线：进候车厅 → 在电子显示屏确认乘车处(提前15分钟) → 往对应号码方向走楼梯/扶梯下去 → 站台。

⑥ 找座位 — 车厢号·座位号，反向座位

列车车门旁会标出车厢号(호차)。对照订票画面上的车厢号，从对应的门上车。座位由数字(排)+字母(左右)组成。要注意：部分座位朝向和行进方向相反(反向座位)——订票时如果没有方向选择选项，可能会被随机分配。觉得不舒服的话，上车前可以在售票处或App重新选座画面换座位。

⑦ 车厢礼仪一段话

打电话请到车厢之间的过道空间小声进行。允许带饭盒等食物上车食用(手推车贩卖也很常见)。行李架方面，车门附近另设有大件行李箱专用架——放在座位边的过道上会挡住其他乘客通行。

⑨ 慌张场景3种

1. 电子显示屏上不显示乘车处 — 不知道"提前15分钟才公开"这个规则就会慌。应对：在候车厅电子显示屏附近等到出发前15分钟即可。

2. 错过列车了 — KTX是对号入座制，不会自动改签到下一班车。去售票处或Korail Talk App的「车票管理(승차권 관리)」办理改签·退款手续。

3. 上错车厢了 — 因为是免验票结构，不会被当场拦下。到站前顺着过道走到正确的车厢·座位就行。

⑩ 备用方案 — 还是搞不定的话

把Korail Talk画面(订票记录)给站务员(역무원)看，大多数情况都能解决。要跑多个城市的常旅客，也可以考虑外国人专用通票Korail Pass。
