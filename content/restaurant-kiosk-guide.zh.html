韩国自助点餐机零慌张手册 — 照着屏幕操作

副标题：韩国餐厅·咖啡厅自助点餐机 (키오스크) 完全攻略 — 3种类型区分 · 通用6步屏幕流程 · 纯韩语界面生存词15个 · 海外卡被拒应对 · 麦当劳/乐天利/MEGA咖啡实战演练

ISSUE 04 · #1270 · 2026-08-13 · korea-first-timer 系列①

🎯 本手册使用说明 — 屏幕标记规则

本文不写"要做什么"，而是原样记录"屏幕上会出现什么、要按哪个按钮、按什么顺序按"。出发前躺在床上读一遍，站到机器前时，屏幕就不再是第一次看到。

  • 屏幕上的按钮用方括号标注：[ 打包 (포장) ]
  • 屏幕标题·提示语用书名号标注：「选择用餐方式 (주문 방법 선택)」
  • 手动操作用加粗标注："把卡片插入下方插卡口，插到底"

① 为什么韩国餐厅用机器代替服务员

韩国餐饮业因人工成本上涨和非接触消费偏好叠加，点餐自动化推进得非常快。麦当劳 (McDonald's)·乐天利 (Lotteria)·汉堡王 (Burger King) 等主要快餐连锁，大多数门店都以自助点餐机 (키오스크) 为基本点餐窗口；廉价咖啡连锁中，以MEGA咖啡 (메가커피)·Compose咖啡为代表，完全不设自助点餐机就不接受点单的门店也很常见。烤肉店·小吃店则正在转向桌面平板点餐。

也就是说，"有机器 = 不友好"并不成立，"机器就是柜台"才是真相。理解这个结构，事情就成了一半，剩下的一半就是这份手册。

② 自助点餐机3种类型 — 我面前的机器是哪一种

类型 在哪里遇到 语言 难度
A. 全球快餐型 麦当劳 McDonald's·汉堡王 Burger King·KFC 🇺🇸🇨🇳🇯🇵 可用国旗按钮切换语言 ★☆☆
B. 韩国本土咖啡·汉堡型 MEGA咖啡·Compose咖啡·乐天利 (Lotteria)·Mom's Touch 多为纯韩语界面(即使有英文按钮也只翻译部分) ★★★
C. 桌面点餐平板型 烤肉店·紫菜包饭天国 (김밥천국)·啤酒屋 — 桌面上的平板 各店不同，图片较大 ★★☆
参考 便利店自助收银台另有说明 → 参见#1219无人商店篇
  • A类型：先找屏幕角落的国旗图标或[ English ]按钮。如果有，这篇文章一半内容都用不上。
  • B类型：本手册的主要目标。用下方④生存词15个来突破。
  • C类型：可以坐在座位上慢慢按，心理负担最小。只需记住最后要按[ 下单 (주문하기) ]才会发送到后厨。

③ 通用6步主流程 — 无论什么机器都是这个顺序

韩国自助点餐机无论品牌不同，都不会偏离下面这6个步骤。

步骤 屏幕上显示的内容 要按的按钮 陷阱
1 「是在店内用餐吗？(매장에서 드시나요?)」 [ 堂食 (매장) ] 或 [ 打包 (포장) ] 有些机器会跳过这一屏(留到最后才问)
2 菜单图片网格 + 左侧分类标签 点击想要的菜品图片 图片就是语言 — 不认字也能靠图片挑选
3 「选择选项 (옵션 선택)」弹窗(套餐/尺寸/加浓缩·糖浆) [ 单品 (단품) ] vs [ 套餐 (세트) ]，选完后按[ 选择完成 (선택 완료) ] 必须关闭选项弹窗才能进入下一步 — 卡住的话十有八九是这一屏
4 「购物车 (장바구니)」(已选清单 + 合计) 继续加点 或 [ 结账 (결제하기) ] [ 结账 (결제하기) ]是屏幕最下方的大按钮
5 「积分/优惠券 (적립/쿠폰)」弹窗 [ 跳过 (건너뛰기) ] / [ 否 (아니오) ] 游客100%应该跳过 — 因为这是输入韩国电话号码的界面
6 「选择支付方式 (결제 수단 선택)」→ 插卡 [ 刷卡支付 (카드 결제) ] → 卡片芯片朝上插到底 无震动静等几秒。听到"滴"一声提示拔卡时再拔

完成后小票上会印出取餐号。等墙上的显示屏出现这个号码，去取餐台领取即可。就这么简单。

④ 纯韩语界面生存词15个 — "看到这几个字就是这个意思"

这里只挑选了会在B类型(纯韩语)机器上实际遇到的文字。建议截图带走，或把这一页保存下来。

屏幕文字 含义 = 该怎么做
堂食 (maejang 매장) Eat in — 堂食用餐时
打包 (pojang 포장) Takeout — 打包带走时
加入 (damgi 담기) Add to cart 加入购物车
购物车 (jangbaguni 장바구니) Cart — 已选清单
单品 (danpum 단품) Item only 单点(非套餐)
套餐 (seteu 세트) Combo/set 套餐
选项 (opsyeon 옵션) Options 选项弹窗
选择完成 (seontaek wallyo 선택 완료) Done/Confirm — 关闭弹窗
结账 (gyeoljehagi 결제하기) Pay — 最重要的按钮
积分 (jeongnip 적립) Points — 与游客无关
跳过 (geonneottwigi 건너뛰기) Skip — 逃离积分界面
售罄 (pumjeol 품절) Sold out — 灰色显示的菜品
小票 (yeongsujeung 영수증) Receipt — 兼作取餐号
重新开始 (cheoeumeuro 처음으로) Start over — 按错时重置
呼叫 (hochul 호출) Call staff — 呼叫店员

提示：15个不必全部背下来。结账 (gyeoljehagi 결제하기) 推进 · 跳过 (geonneottwigi 건너뛰기) 逃离 · 重新开始 (cheoeumeuro 처음으로) 重置，这三个是核心动词。

⑤ 支付分支 — 海外卡被拒才是重头戏

韩国的支付网络 (VAN) 是自成一体的独立规格，支持国际EMV标准的终端只是少数。所以即使是同一张Visa/Mastercard卡，也常常出现机器上被拒、柜台却能刷过的情况。这不是你的卡有问题，而是韩国基础设施的特性。

情况 应对
自助点餐机吐卡 改用插卡代替感应(Tap)再试一次 → 不行就干脆去柜台
没有柜台的无人商店 换一张卡(不同发卡行) → 确认机器是否兼收现金(有纸币投入口)
如果是多次访韩的旅行者 提前准备好WOWPASS(外国人专用预付卡，主要车站·机场设有发卡机)或T-money余额支付 → 详见支付深度篇#527
只有现金但机器是刷卡专用 呼叫店员(按[ 呼叫 (호출) ]按钮或去柜台) — 大多数情况下店员会手动处理付款
  • 三星支付 (Samsung Pay)·苹果支付 (Apple Pay)：支持苹果支付的门店在增加，但目前还是看运气。带两张实体卡(不同发卡行)是最保险的组合。
  • 随身备好3万~5万韩元现金，无论遇到什么拒付情况都能保持淡定。

⑥ 各连锁品牌实战演练 — 照搬该门店屏幕

🍔 麦当劳 (McDonald's) (A类型，支持英文)

1. 首屏底部国旗图标 → [ English ]

2. 「Eat In or Take Out?」 → 选择

3. 菜单 → 点击汉堡 → 「Meal or Item only?」 → 选项(可换薯条·饮料)

4. [ Checkout ] → 积分界面[ Skip ] → 插卡

  • 特点：翻译完成度最高。第一次体验自助点餐机，最适合拿麦当劳来演练。

🍔 乐天利 (Lotteria) (接近B类型，有英文按钮但只翻译部分)

1. 如果有语言按钮就切换 — 但部分菜品名称仍会保留韩语

2. 「堂食/打包 (매장/포장)」 → 点击菜品图片 → [ 单品 (단품) ] / [ 套餐 (세트) ]选择是必经弹窗

3. [ 结账 (결제하기) ] → 积分弹窗[ 跳过 (건너뛰기) ] → 插卡

  • 特点：套餐选项弹窗比麦当劳步骤更多。卡住时，找找屏幕上某处的[ 选择完成 (선택 완료) ]。

☕ MEGA咖啡 (B类型，多为纯韩语)

1. 很多门店没有语言按钮 — 靠④生存词正面突破

2. 「堂食/打包 (매장/포장)」 → 点击咖啡图片 → 选项弹窗：HOT / ICE、尺寸、加浓缩 (샷 추가)

3. [ 加入 (담기) ] → [ 结账 (결제하기) ] → 积分电话号码界面[ 跳过 (건너뛰기) ] → 插卡

  • 特点：廉价咖啡连锁(Compose咖啡、Paik's咖啡 (빽다방) 结构相同)的屏幕流程几乎一致。学会一个，全部通用。

⑦ 慌张场景3种 — 真实会发生的事和心理应对

1. 后面排的队很长 — 韩国人平均也要花1~2分钟。这里没有从后面催促的文化，深呼吸就好。实在有压力的话，先让到一边，重新看一遍本页③的流程再挑战，也不会有人说什么。

2. 按错跳出奇怪的画面 — 万能解法：[ 重新开始 (처음으로) ] 或左上角[ ← ]。自助点餐机在付款之前什么都不会确定。

3. 站着不动就跳回首屏了 — 很多机器在30秒~1分钟无操作时会自动重置。这不是故障，从头再按一遍就行。

⑧ 备选方案B — 机器实在搞不定时

  • 判断能否柜台点餐：如果柜台有店员常驻、能看到POS终端，大多数情况下可以口头点餐。有些店在自助点餐机旁还会挂出「可柜台点餐 (카운터 주문 가능)」的提示。
  • 呼叫店员的一句话："请帮帮我 (dowajuseyo 도와주세요)" — 说出这一句 + 手指自助点餐机就够了。韩国店员对这种求助请求很熟悉。
  • 出示屏幕求助法：在Papago/谷歌翻译里把"I'd like to order this. Card payment doesn't work."翻译成韩语，直接把整个屏幕给对方看 → App设置详见必备App篇#1230。
  • 同伴模拟演练：同行的人中一人念本页③表格，另一人来按，这样第一次实战最轻松。
