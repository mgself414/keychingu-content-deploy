ソウル東西軸④ 地下鉄2号線東半円、乙支路入口駅 (Euljiro 1-ga Station / 을지로입구역) から舎堂駅 (Sadang Station / 사당역) まで — 高架の上で漢江を渡る車窓コース

副題: 東西軸はここまでバスだったが、今回は地下鉄2号線のみ。乙支路から漢江を渡り蚕室・江南・舎堂へ、漢陽大~蚕室ナルは地上、蚕室鉄橋で渡る東半分の車窓。約2時間、下車は建大入口1回。Seoul E-W Axis 4回目。

ISSUE · #1359 · 2026-09-07

🎯 フレーム — バスがなければ地下鉄が軸だ

ソウル南北軸(#1353)は江南大路を、東西軸第1回(#1356)は鍾路をバス一台で通った。この回の拠点 — 乙支路、聖水 (Seongsu / 성수)、建大、蚕室 (Jamsil / 잠실)、三成駅 (Samseong Station / 삼성역)、江南駅 (Gangnam Station / 강남역)、教大駅 (Seoul Nat'l Univ. of Education Station / 교대역)、舎堂 — を一本でつなぐバスはない。代わりにあるのが地下鉄2号線だ。ソウルを一周する循環線の東半分が、まさにこの順序で走る。

そして2号線の東半分は、循環線で唯一地上に上がって漢江を渡る区間だ。漢陽大駅 (Hanyang University Station / 한양대역)から蚕室ナル (Jamsillaru / 잠실나루)まで七駅が続けて地上で、江辺駅 (Gangbyeon Station / 강변역)と蚕室ナルの間で列車は蚕室鉄橋 (Jamsil Railway Bridge / 잠실철교)の上を漢江を渡る。地下鉄が車窓コースになる珍しい区間だ。聖水・蚕室・江南は車窓からだけ見る。降りるのは建大入口駅 (Konkuk University Station / 건대입구역)1回 — 7号線で二駅隣の君子 (Gunja / 군자) (#1360)へ抜ける支線を案内するためだ。

  • 総所要時間: 約2時間(乗車約45~50分推定 + 建大入口下車15分 + 余裕)
  • おすすめ時間帯: 平日午前10時出発 — 通勤ラッシュが終わり右側の窓側席が空き、正午前に舎堂に着く。夕方ラッシュ(17~19時)の2号線江南区間はソウルで最も混雑する
  • 傾斜: なし — 歩く区間は平地15分のみ

なぜ2号線東半円なのか — 循環線が漢江を渡る唯一の場所

2号線は1980年10月31日、新設洞~総合運動場駅 (Sports Complex Station / 종합운동장역)区間で開通し、1982年に総合運動場~教大、1983年に乙支路入口~聖水とソウル大入口~教大、そして1984年5月22日にソウル大入口~乙支路入口がつながって循環線になった。一周するのに約1時間30分。時計回りに回る列車を内回り (inner circle line / 내선순환)、逆方向を外回り (outer circle line / 외선순환)と呼ぶ — この回は内回りに乗る。

📖 物語1 — なぜこの区間だけ地上なのか: 循環線を作るとき、中浪川 (Jungnangcheon / 중랑천)と漢江を渡らなければならない東側は、地下を掘る代わりに高架で上げた。そのため漢陽大・纛島 (Ttukseom / 뚝섬)・聖水・建大入口・九宜 (Guui / 구의)・江辺・蚕室ナル七駅が続けて地上駅で、聖水と九宜の間の高架の下には今も往復6車線の道路が通る。江辺と蚕室ナルの間の蚕室鉄橋は、道路が1979年10月、鉄道が1980年10月に竣工した、韓国で初めて鉄道と道路を一緒に載せた橋だ。2006年からは道路の一部が自転車・歩行者路に変わり、人もこの橋で漢江を渡る。

🚶 コース — 車窓の順番そのままに

起点は2号線乙支路入口駅。内回り(時計回り、聖水・蚕室方面)のホームから乗る。聖水までは地下だ — 車窓は漢陽大から始まる。

① 乙支路入口 → 東大門歴史文化公園 → 往十里 → 漢陽大 (🚇 約12分・地下 → 地上)

  • 乙支路3街・4街の卸売路地(#1346)とDDP(#1252)の下を過ぎ、新堂・上往十里・往十里 (Wangsimni / 왕십리)。漢陽大駅で列車が地上に出る — 聖水方面のホームが地上なので、ここから窓が明るくなる。
  • この区間の地上の街の案内は#1250往十里ハブが扱う。ここでは暗い窓が明るくなる瞬間だけ。

② 纛島 → 聖水 → 建大入口下車 (🚇 約3分・高架)

  • 高架の上で左に纛島・ソウルの森方向、右に聖水洞の赤レンガ屋根群(#1342)が見下ろせる。聖水駅は通過する — 聖水には#001・#145・#1342がある。
  • 建大入口駅で降りる。この回の唯一の下車。

③ 建大入口ミニウォーク15分 — そして君子への支線 (🚶 約15分)

  • 駅周辺をひと回り。高架下の建大路地の昼の風景だけを味わう — 建大・纛島の詳細は#178。
  • 支線: 同じ駅で7号線に乗り換え、子供大公園駅・君子駅まで二駅乗れば、軸から少し外れて無料公園とコプチャン路地の街がある。その朝コースは#1360。軸に乗り続けるなら2号線内回りに戻る。

④ 九宜 → 江辺 → 蚕室鉄橋 → 蚕室ナル (🚇 約10分・車窓のクライマックス)

  • 江辺駅の右手に東ソウル総合ターミナル (Dong Seoul Bus Terminal / 동서울터미널) (1990)とテクノマート。列車が駅を出ると建物が消えて漢江が開ける — 蚕室鉄橋の上だ。左手上流側に光津橋と峨嵯山 (Achasan / 아차산)、右手下流側にオリンピック大橋、正面南の川向こうにロッテワールドタワー (Lotte World Tower / 롯데월드타워) (555m、2017)が近づく。
  • 📖 物語2 — 橋の上の地下鉄: 地下鉄が川の上を走る1分ほどが、この回の頂点だ。南北軸は漢南大橋をバスで、東西軸は蚕室鉄橋を列車で渡る。橋の脇の歩道でも渡ることができる — 歩くバージョンは#1256・#308に任せる。
  • 蚕室ナル駅を過ぎると、列車は再び地中に入る。

⑤ 蚕室 → 蚕室セネ → 総合運動場 → 三成 (🚇 約5分・降車なし)

  • 蚕室駅: ロッテワールドタワーのすぐ下。降りない — 蚕室には#82・#300・#707がある。蚕室セネ (Jamsilsaenae / 잠실새내)は2016年末に「新川」から名前を変えた駅。総合運動場を過ぎて三成駅 — 5・6番出口がCOEX (COEX / 코엑스)に直結する(#366・#449)。ここも通過。

⑥ 宣陵 (Seolleung / 선릉) → 駅三 (Yeoksam / 역삼) → 江南 (🚇 約6分・降車なし)

  • テヘラン路 (Teheran-ro / 테헤란로)の下を走る。地上だったならガラスのオフィスビルが続く道。江南駅 — ソウルで最も混雑する駅のひとつであり、南北軸(#1353)が車窓を過ぎたあの交差点だ。二つの軸がここで十字に出会う。降りない(#301・#1355)。

⑦ 教大 → 方背 → 舎堂 (🚇 約7分)

  • 教大駅10・11番出口の上にソウル中央地方法院 (Seoul Central District Court / 서울중앙지방법원) — 瑞草洞の法曹タウンだ。方背 (Bangbae / 방배)を過ぎ、舎堂駅で降りる。2号線東半円の終わり。

⑧ 舎堂駅で締めくくり (🚶 約3分)

  • 出口14カ所、冠岳・銅雀・瑞草の三区が出会う場所。京畿南部へ向かう広域バスが列をなす夕方の風景と冠岳山入口は#1361が別に歩く。この回はここで終わる。

🚇 乗り方・座席のコツ5

1. 内回りに乗る: 乙支路入口のホームで「聖水・蚕室方面」(時計回り)。逆(外回り)に乗ると市庁・弘大方向へ回る。

2. 右側の窓側: 進行方向右側(南側)に座ると、蚕室鉄橋で下流とロッテワールドタワー、江辺駅のターミナルが入ってくる。左側は上流と峨嵯山。

3. 漢陽大までは席を気にしなくていい: 地下区間だ。往十里あたりで窓側に移る。

4. 乗り換え割引: 建大入口で改札を出て30分以内に再び乗れば乗り換え料金。7号線君子への支線は駅構内乗り換えなので追加料金なし。

5. 速い代案なし: この区間は2号線が最も速い。代わりにラッシュアワーは避ける — 午前10時以降。

🙏 地下鉄マナー — このコースの核心

  • 車窓の撮影は座って、他の乗客がフレームに入らないように。通話は小声で。
  • 妊婦席・交通弱者席は空けておく。2号線江南区間は昼でも立っている人が多い。
  • 大きなキャリーバッグはドア横のスペースに — 特に建大入口・蚕室・江南で乗降が多い。

💡 戸惑いポイント

  • 方向を間違えやすい: 2号線は両方向とも「循環」だ。案内板の「内回り・聖水・蚕室」方面を確認する。
  • 車窓は漢陽大から蚕室ナルまでだけ: その前後は地下だ。約15分の地上区間がこの回の全てなので見逃さない。
  • 建大入口の乗り換え通路が長い: 7号線の支線に乗るには案内標識に沿って数分歩く。
  • 舎堂駅の出口14カ所: 降りた後に出口を決めてから出る — #1361参照。

FAQ 6

Q1. なぜ今回はバスではないのか?

  • この八つの拠点を一本でつなぐ市内バスはない。360番が蚕室→三成→江南駅までは来るが、その後論峴・高速ターミナルへ抜ける。2号線が唯一の軸だ。

Q2. #1241 2号線編と何が違うか?

  • #1241は観光の核心8駅で「降りて何をするか」を扱う駅別案内だ。この回は降りずに順番通り通過し、車窓と高架区間の物語を見る。降りる場所を探すなら#1241へ。

Q3. 漢江が見える区間はどのくらい長いか?

  • 蚕室鉄橋の上、1分ほど。その前後の高架区間まで合わせると、車窓が明るい時間は約15分だ。

Q4. 蚕室・江南で降りたい場合は?

  • 降りてもいい。この回は通過が原則なので、その街の案内は各回(#82・#300・#301・#366)を見る。30分以内に同じ方向で再び乗れば乗り換え割引。

Q5. 子供・荷物があっても大丈夫か?

  • 大丈夫だ。歩く区間は15分だけ。ただしラッシュアワーは避け、キャリーバッグはドア横に。

Q6. 南北軸とどうつなぐか?

  • 江南駅で二つの軸が交差する。この回を舎堂まで乗って4号線で戻るか、江南駅で降りて南北軸バス140番(#1353)に乗り換えれば、ソウルを十字に読むことになる。
