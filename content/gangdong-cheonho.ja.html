江東・千戸は江東区の韓国先史・百済歴史の一番地・漢江東側・中間層家族が結びつくエリアです — アムサ (Amsa / 암사) 先史遺跡地(韓国新石器時代の一番地遺跡、1925年発掘) + プンナプ土城 (Pungnaptoseong / 풍납토성)(百済都城遺跡、史跡11号) + チョノ漢江公園・クァンナル (Gwangnaru / 광나루)(漢江東側) + カンドンアイパークザリバーモール・チョノロデオ通り(江東の若者ホットゾーン)が一つのエリアに凝縮されています。韓国先史・百済歴史のディープダイブ + 漢江東側 + 外国人家族フレンドリーが結びついています。

弘大(MZ・インディーズ)・江南(ラグジュアリー)・梨泰院(グローバル)と比べると、江東・千戸は先史・百済・漢江東側という色合いです。外国人観光客の動線上、蚕室に隠れて素通りされがちですが、アムサ先史遺跡地は韓国新石器時代の一番地ディープダイブ(1925年発掘、6,000年前の櫛目文土器)+ プンナプ土城・モンチョン土城は百済漢城の都城遺跡(韓国4大古代国家ディープダイブ)です。#138弘大・#173瑞草・#174ソウル大・#178広津・#180九老・#181銅雀・#182恩平に続くISSUE03第21編 — キチングゥ初の江東区進出(クラスター87件)。

特にアムサ先史遺跡地は外国人向け韓国歴史ディープダイブの一番地です(韓国新石器・青銅器・鉄器統合博物館)。チョノロデオ通りは江東の若者・MZホットゾーン。トゥンチョン (Dunchon / 둔촌) オリンピックパークが隣接(蚕室東側)。#82蚕室の姉妹エリアです。

⚠ 外国人がよくする間違い3つ

1. 「江東 = 蚕室の近くだから蚕室だけ見ればいい」— 江東固有の価値を認識していない

外国人観光客の動線でもっともよくある間違いです。江東を「蚕室の隣」としてしか認識せず素通りしてしまいますが、実際には江東は韓国先史・百済歴史の一番地です — アムサ先史遺跡地(韓国新石器の一番地、1925年発掘) + プンナプ土城(百済漢城都城) + モンチョン土城 = 韓国6,000年の歴史のディープダイブ。蚕室(現代的なテーマパーク)とは違う色合いです。トゥンチョンオリンピックパークは蚕室の姉妹エリアです。

2. 「アムサ先史遺跡地 = ただの遺跡」— 韓国新石器一番地としての価値を認識していない

アムサ先史遺跡地は1925年発掘、韓国新石器・青銅器・鉄器統合遺跡です — 韓国一番地の先史遺跡地。櫛目文土器(6,000年前、韓国最初の陶器) + 竪穴住居の復元 = 外国人向け韓国古代史ディープダイブの第一候補です。アムサ駅4番出口から徒歩10分、入場料1,000ウォン(外国人向け英語案内 + 博物館統合)。

3. 「千戸 = ただの町」— 漢江東側の若者ホットゾーンとしての価値を認識していない

千戸は単なる町ではなく、江東の若者・MZホットゾーンです — チョノロデオ通り + カンドンアイパークザリバーモール(漢江ビューのショッピングモール) + カフェ・料理酒場・居酒屋のホットゾーン。5号線・8号線千戸駅の乗換駅 + カンイル・アムサ新都市に隣接。蚕室(2号線)まで5分の距離です。

江東・千戸の風景

江東・千戸は江東区の東部・西部に位置する韓国先史・百済歴史 + 漢江東側 + 家族の町が結びついたエリアです — 1925年のアムサ先史遺跡地発掘 + 百済漢城(紀元前18年~紀元475年)のプンナプ・モンチョン土城遺跡 + 2010年代の千戸・カンイル新都市 + カンドンアイパークザリバーモール(2014年)の開館により、韓国古代史のディープダイブ + 江東の現代性が結びついたエリアとして定着しました。

アムサ・プンナプサブエリアは8号線アムサ駅・5号線千戸駅の周辺 — アムサ先史遺跡地(新石器)+ プンナプ土城(百済)+ 韓国6,000年の歴史のディープダイブ一番地です。

千戸・カンイルサブエリアは5号線・8号線千戸駅・9号線カンイル駅 — チョノロデオ通り + カンドンアイパークザリバーモール(漢江ビュー)+ カフェ・料理酒場のホットゾーンです。

コドク・ミョンイルサブエリアは5号線コドク駅・ミョンイル駅 — コドクビジネスバレー・イケア江東・アパート団地 + 家族の町です。

トゥンチョン・キルドンサブエリアは5号線トゥンチョン洞駅・キルドン駅 — トゥンチョンオリンピックパーク + キルドン正統韓国料理です。

クァンナルサブエリアは5号線クァンナル駅 + 漢江東側のサイクリングロードです。

交通: 5号線・8号線千戸駅(千戸・ロデオ)/ 8号線アムサ駅(先史遺跡地・プンナプ土城)/ 5号線コドク駅・ミョンイル駅(コドク・イケア)/ 5号線トゥンチョン洞駅(オリンピックパーク)/ 9号線カンイル駅。カカオタクシー推奨。

1,000ウォン(外国人も同額)/ 09:30~18:00(月曜休館)。外国人向け英語案内 + 博物館統合(新石器・青銅器・鉄器)。6,000年前の櫛目文土器・竪穴住居の復元が第一候補。8号線アムサ駅4番出口から徒歩10分。

Q2. プンナプ土城はどう見ればいい?

無料 + 24時間(土城の周囲を散策可能)— プンナプ洞一帯 約3.5km。漢城百済博物館(松坡区・モンチョン土城駅近く、無料)との統合ディープダイブが第一候補。外国人向け英語案内 + 韓国4大古代国家・百済のディープダイブ。

Q3. 江東の漢江サイクリングコースは?

クァンナル → 千戸 → 蚕室 → トゥクソム → 盤浦 → 汝矣島 = 約30kmの漢江サイクリングロード(韓国一番地のサイクリングコース)。クァンナルは漢江サイクリングロード東側の起点 + タルンイ(公共レンタサイクル)レンタルOK。#149サイクリングガイド東側スタート地点。

Q4. 江東・千戸の外国人フレンドリーな店は?

タラム江東本店・ハナムトェジチプ・スシドク・タヌキベーグル・リトルチェスウッドが英語メニュー + カード決済 + 外国人フレンドリーの標準です。119タッパルは韓国チャレンジフードなので外国人vlogの第一候補です。

Q5. 江東 + 蚕室の連結は可能?

OK — 江東(5・8号線)→ 蚕室(8号線2駅)= 地下鉄5分。アムサ先史遺跡地 + プンナプ土城(江東)+ モンチョン土城 + トゥンチョンオリンピックパーク + 蚕室(松坡) = 1日で韓国古代史・漢江東側をフルセット体験。

Q6. 119タッパルの辛さは外国人でも大丈夫?

3段階の辛さから選択OK(マイルド・普通・辛口)。外国人はマイルドから始めることを推奨。韓国のvlog・モッパンによく登場する外国人チャレンジフードです。カード決済 + 一部英語メニューOK。

Q7. カンドンアイパークザリバーモールは免税?

一部店舗で外国人その場免税還付OK(30,000ウォン以上 + パスポート)。漢江ビューのショッピングモール(2014年)+ カフェ・レストラン・映画館のフルセット。千戸駅から徒歩5分。

Q8. 江東の夜間の安全性は?

24時間安全— 江東は韓国の中間層・家族の町 + 防犯カメラ・私服警察が標準です。外国人の夜間外出もOK。深夜0時以降はカカオタクシーを推奨。
