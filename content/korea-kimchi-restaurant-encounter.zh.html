🎯 为什么要介绍餐厅泡菜的入门路线指南？

如果说【#822 6种泡菜矩阵】(#822)是韩国泡菜招牌视角，那么外国游客的痛点就是“我在餐厅里到底应该遇到什么样的泡菜，什么时候处理它？”就是动线视角。 99%的外国人在到达韩国的第一天会去韩国餐馆，但（a）他们不知道作为基本配菜的1到4种泡菜之间的区别，（b）他们没有看到“免费补充”标志，（c）他们不知道不同商店的泡菜差异（老字号韩国餐厅与小吃店与烧烤与汤店），（d）他们不知道泡菜的优先顺序点菜单时配对，并且（e）他们不知道返回时如何要求“常规泡菜”。

本指南包括 4 个步骤：进入餐厅 → 领取配菜 → 请求补充 → 再次光临 + 按商店类型分类的泡菜矩阵 + 菜单-泡菜搭配表 + 英语套件。

🚪 步骤 1 — 入场 + 座位（泡菜 = 自动免费配菜）

###外国人入境时的5个要点

1. “你们有多少人？” = 有多少人？ — 用手指标记“确定”

2. “请坐在这里” = 请这边走 — 座位说明

3. 自动提供基本配菜 = 自动提供1到5种泡菜 — **单独要求

4. 水/湿毛巾自动 = 单独收费

5. 英文菜单 = 明洞、梨泰院、弘大、江南和钟路的主要餐厅都可以使用英语。

一坐下就上泡菜（按店家）

  • 国饭馆：萝卜泡菜1种、白菜泡菜1种=2碗
  • 烧烤：白菜泡菜、萝卜、萝卜、包饭、生菜=4到6碗
  • 韩定食：白菜泡菜、白泡菜、冬菜、萝卜泡菜、学士泡菜=5种全套
  • 零食：腌萝卜白菜泡菜=2碗
  • 咖啡馆：泡菜

英语口语套件（第 1 步）

  • “泡菜免费吗？” → 泡菜免费吗？ = 是（所有韩国餐厅）
  • “我可以再买点泡菜吗？” → 我可以再买点泡菜吗？ = 是·无限制
  • “哪种泡菜最不辣？” → 最不辣的泡菜是什么？ = 白泡菜·东吉米 要求

要求不辣泡菜英文

  • “你们有白泡菜吗？” → 有白泡菜吗？ （不辣）
  • “有水泡菜吗？” → 有水泡菜吗？ （不辣）
  • “请淡味泡菜” → 请使用不辣的泡菜

🔄 第 3 步 — 免费无限续杯（所有餐厅）

补充请求的标准程序

1. 当泡菜碗空时 = 自动补充信号

2. “请给我更多的泡菜” = 我可以得到更多的泡菜吗？ — 给老板/员工打电话

3. 额外的碗 = 5 秒到 1 分钟内到达

4. 免费/无限制 = 所有韩国餐厅（韩国菜、汤、烧烤、小吃）

5. **异常存储

无法收到补充品的情况（虽然很少见）

  • 自助餐/自助商店 = 用户自己去拿食物
  • 连锁无限充值店 = 时间限制（1小时30分钟等）
  • 机场/火车站商店 = 一些一次性优惠（尽管很少见）

补充频率（外国人与韩国人）

  • 韩国平均水平：每餐 1-2 份续杯
  • 外国人平均：1或0次（不确定要求）
  • 外国狂热：3~4次（韩国水平）

英语口语套件（第 3 步）

  • “请再来点泡菜” = 请给我更多泡菜
  • “不同的泡菜？” =还有其他类型的泡菜吗？ (韩国食品/杂货店)
  • “相同的泡菜”=相同的泡菜（应要求提供）

🎯 步骤 4 — 重访 + 常规知识

###泡菜知识回访

1. 来自店主的问候=韩国老字号店=店主亲自制作泡菜的店

2. “老板家的泡菜很好吃”=这个泡菜真的很好吃——老板的自豪感和服务泡菜都可以

3. 泡菜季节要求 = 春季（幼萝卜开始）、夏季（幼萝卜、nabak）、秋季（准备泡菜）、冬季（泡菜、dongchimi）。签名因商店而异。

4. 发酵阶段请求 =“请给我老泡菜”/“请给我geotjeori” - 常规矩阵

5. 店主教泡菜=常客=店主分享泡菜秘诀、食材、季节信息

常规疯狂泡菜矩阵

狂热阶段 订购泡菜 老板反应

第二次访问 “请再给我昨天的泡菜” 老板的记忆力和服务泡菜
第三次访问 “你有旧纸吗？” 老字号=很多商店都备有旧纸

###国外回访ROI

  • 重访=免费泡菜搭配升级（免费泡菜、陈年泡菜、时令泡菜）
  • 重游=店主推荐的韩国文化和街区（当地爱好者#1）
  • 重访=韩国友谊的开始（所有者=邻里信息中心）

⚠ 外国人常犯的5个错误

1. “泡菜=单独要求/收费”：韩国餐厅泡菜= 自动免费配菜·无限续杯。单独订购

2. “不要求补充泡菜（安静结束）”：韩国标准 = 要求补充 = 正常。 “请再来点泡菜”很自然。韩国人平均每餐补充1-2次。

3. “期待汤店里的各种泡菜”：汤包店= 1种kkakdugi（专卖店）。各种泡菜=韩国菜，家常菜。

4. “不确定烧烤时的泡菜搭配”：烧烤成熟的泡菜=油汁基质。日本#1·中国#1爱好者。

5. “我以为零食和鸡肉里没有泡菜”：零食=腌萝卜+白菜泡菜。鸡肉=鸡肉萝卜+白菜泡菜。 泡菜=韩国餐厅标准。

⚙ 6 个常见问题解答

1. 为外国人推荐的第一家韩国餐厅：Gukbap餐厅（简单的萝卜萝卜，温热的汤）→烧烤（浓郁的泡菜）→韩定食（各种）。第一次来=汤餐厅。

2. “免费无限量泡菜”信号：菜单板，招牌X，明显的韩国餐厅标准。商店条目 = 自动应用。

3. 充值频率：韩国=1~2次，外国爱好者=3~4次，外国人新品=0~1次。爱好者=常客。

4. 老纸店：老店、30年+家常菜、泡菜炖菜专卖店=库存老纸。链条=老化纸

5. 季节性泡菜店：春季（4月至5月开始生萝卜）、夏季（6月至8月为白萝卜和幼萝卜）、秋季（10月至11月为泡菜准备）、冬季（11月至2月为泡菜和冬菜）——家常菜，老字号。

6. 过敏：虾酱（甲壳类）、鳀鱼鱼露、大蒜、红辣椒粉、黄豆（酱油），需提前告知。白泡菜·东池米=辣

⚠ 医疗/安全/饮食免责声明

泡菜=发酵食品（盐度↑，辣度高）。孕妇、高血压、肾病患者=小心盐。儿童=推荐白泡菜和东池米（不辣）。过敏（虾盐、凤尾鱼鱼露、甲壳类动物、大蒜、红辣椒粉）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。

饮食限制后备：

  • 清真·犹太洁食：普通泡菜=非清真·非犹太洁食（包括咸虾）。 → 寺庙食品泡菜 = 提供素食、清真、犹太洁食
  • 素食/纯素食：普通泡菜=非素食（虾盐、凤尾鱼鱼露）。 → 单独的寺庙食品或纯素泡菜商店（以酱油为主）
  • 无麸质：如果你不加酱油也可以。白泡菜·东池米=酱油

✈️外国人的痛点#1 — 餐厅泡菜和超市泡菜的区别

  • 餐厅泡菜 = 店主亲自制作泡菜（老店）或送到泡菜工厂（连锁） — 新鲜、时令、店家招牌
  • Mart Kimchi = 散装泡菜工厂（Jonggajip、Pulmuone、CJ 等） — 标准/真空/长期储存
  • 体验差异：餐厅=新鲜度/季节变化/超市=标准一致性
  • 回礼：超市真空包装泡菜 = 托运行李可以（液体分类/100ml+） — 随身携带X
  • 推荐购买地点：仁川机场免税店（真空包装）、易买得、乐天玛特（性价比高）
