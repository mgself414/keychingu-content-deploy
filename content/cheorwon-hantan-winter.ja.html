鉄原 漢灘江の冬ガイド — 氷トレッキング祭り・ムルウィッキル・柱状節理の道、孤石亭・チクタンの滝、DMZ平和観光

サブタイトル: 鉄原 漢灘江氷トレッキング祭り(2027年1月16日~2月14日の登録) · 漢灘江ムルウィッキル(10~3月運営、09:00~17:00) · 柱状節理の道(3.6km、冬季 09:00~15:00) · ウナスギョ・ヘッブル展望台 · 孤石亭・チクタンの滝・サムブヨンの滝 · 平和展望台・第2トンネル(引率観光) · 労働党舎 · 渡り鳥の飛来地 — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、江原道 鉄原郡の漢灘江とその周辺で、冬に行ける場所をまとめたものです。漢灘江一帯はユネスコ世界ジオパークです。川の上を歩くムルウィッキル (Murwitgil / 물윗길)と、その道で開かれる氷トレッキング祭り、断崖に架けた柱状節理の道、漢灘江の峡谷にある孤石亭と滝、DMZ平和観光コース、分断の痕跡である労働党舎、冬の渡り鳥が来る鉄原平野です。

多くの場所が火曜日に休みます(ムルウィッキル・柱状節理の道・ヘッブル展望台・平和展望台・第2トンネル・鉄原観光情報センター)。平和展望台と第2トンネルは同じ受付から決まった時刻に出発し、第2トンネルは個人での見学ができず、引率者と一緒に行くと登録されています。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 川の上を歩く冬 — 氷トレッキング祭り・ムルウィッキル

鉄原 漢灘江氷トレッキング祭り、トンソンウプ (Dongsong-eup / 동송읍) チャンフンリ (Jangheung-ri / 장흥리) 725、ムルウィッキル トレッキングコース一帯、☎ 鉄原文化財団 (Cheorwon Munhwa Jaedan / 철원문화재단) 033-455-7072 は、2027年1月16日~2月14日、10:00~17:00と登録されています。漢灘江ムルウィッキル トレッキングコースとつながる祭りで、メイン会場はスンイルギョ (Seungilgyo / 승일교)の下です。観光公社の紹介によると、「大韓民国祭りコンテンツ大賞」の殿堂入りを果たし、2026-27年の優秀祭りに指定されました。

  • 料金: 10,000ウォン(鉄原サラン商品券 5,000ウォン還付)。ムルウィッキル トレッキングの料金と連携すると登録されています。
  • 登録されたプログラム(2026年の内容基準): 氷トレッキングコース、スンイルギョの下のメイン会場、「トンバラム・アルトン・クボ大会 (Ttongbaram Altong Gubo Daehoe / 똥바람알통구보대회)」、雪そり場、屋台村、農特産物の販売、クウムト (Guumteo / 구움터)、ステージ公演、平日のど自慢。2027年のプログラムはまだ更新中と書かれています。

漢灘江ムルウィッキル、カルマルウプ (Galmal-eup / 갈말읍) サンサリ (Sangsa-ri / 상사리)、☎ 033-455-7072 は、漢灘江の柱状節理を水の上から見ながら歩くトレッキングコースです。登録情報では毎年10月に開いて翌年3月まで運営します。孤石亭・スンダム (Sundam / 순담)渓谷など一部の区間に置いていた浮橋を、2017年からテボン (Taebong / 태봉)大橋からスンダム渓谷までの全区間に広げ、観光公社の紹介によると、毎年10万人以上が訪れます。

  • 開く時間: 09:00~17:00(入場締切 16:00)。
  • 休み: 毎週火曜日、1月1日、旧正月・秋夕の当日。

📍 断崖の上を歩く道 — 柱状節理の道・ウナスギョ・ヘッブル展望台

漢灘江 柱状節理の道(桟道)、カルマルウプ クンタンリ (Guntan-ri / 군탄리)、☎ スンダム券売所 0507-1431-2225、ドゥルニ (Deureuni / 드르니)券売所 0507-1374-9825 は、水面から20~30mの高さの垂直な断崖の途中に架けた、長さ3.6kmの道です。スンダムゲートかドゥルニゲートから出発し、片道約1時間30分かかります。ドゥルニゲートから出発すると下り階段が多く、スンダムゲートから出発すると上り階段が多くなります。展望休憩所が10か所あります。週末はシャトルバスが両側の入口を行き来すると紹介されています。

  • 開く時間: 冬季(12~2月) 09:00~15:00、夏季(3~11月) 09:00~16:00。大雨注意報が出ると運営を止めます。
  • 休み: 毎週火曜日、1月1日、旧正月・秋夕の当日。

ウナスギョ(トンソンウプ チャンフンリ、☎ 鉄原郡庁 観光政策課 033-450-5530)は、ソンデソ (Songdaeso / 송대소)のハンヨウルギル (Hanyeoul-gil / 한여울길)に架けた、長さ180m、幅3mの吊り橋です。柱状節理の道1コース(トンソンウプ チャンフンリ)と2コース(カルマルウプ サンサリ)をつなぎます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 可能。

ヘッブル展望台、カルマルウプ Galmal-ro 653-3 (갈말로 653-3)、☎ 033-452-1104 は、ウナスギョとともにハンヨウルギルの動線にある、高さ約53mの展望台です。上部に透明な強化ガラスの床があります。

  • 開く時間: 冬季 09:00~17:30(券売締切 16:30)、夏季 09:00~18:00(券売締切 17:00)。
  • 休み: 毎週火曜日、1月1日、旧正月・秋夕の当日。
  • 料金: 個人 大人 6,000ウォン、子ども 3,000ウォン。「鉄原商品券交換」 大人 3,000ウォン、子ども 1,000ウォンでも登録されています。

📍 漢灘江の峡谷と滝 — 孤石亭・チクタンの滝・サムブヨンの滝

孤石亭、トンソンウプ Taebong-ro 1825 (태봉로 1825)、☎ 033-450-5558 には、漢灘江の峡谷の中に高さ約15mの花崗岩の岩「孤石」があり、そばに楼閣「孤石亭」があって、一帯の峡谷をまとめて孤石亭とも呼びます。孤石は約1億1千万年前に地中でできた花崗岩で、火山活動のときに玄武岩の溶岩に覆われ、漢灘江が削ることで再び姿を現しました。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 小型 2,000ウォン、大型 5,000ウォン。

チクタンの滝、トンソンウプ チャンフンリ、☎ 漢灘江地質公園ビジターセンター (Hantangang Jijil Gongwon Bijiteo Senteo / 한탄강지질공원 방문자센터) 033-450-4810 は、漢灘江本流の滝です。平らな玄武岩の上にできていて、高さは約3mですが幅が約80mあり、階段のように広がっています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

サムブヨンの滝、カルマルウプ シンチョルォンリ (Sincheorwon-ri / 신철원리)、☎ 鉄原郡庁 033-450-4810 は、ミョンソン山 (Myeongseongsan / 명성산)の中腹にある、高さ約20mの3段の滝です。水の流れが三度折れ、下が釜のようにくぼんでいて「サムブヨン(三釜淵)」と呼びます。駐車場からトンネルを通って展望台まで歩きます。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 可能。

📍 DMZ平和観光 — 平和展望台・第2トンネル

鉄原 平和展望台、トンソンウプ ヤンジリ (Yangji-ri / 양지리) 457-7、☎ 033-450-5559、鉄原DMZ平和・安保観光受付 は、2007年に建てた3階建ての展望台で、非武装地帯(DMZ)と北朝鮮の地域を見下ろします。ピョンガン (Pyeonggang / 평강)高原、ソンジョン (Seonjeon / 선전)村、ペンマゴジ (Baengmagoji / 백마고지)などが見えます。50人乗りのモノレールで上れます。

第2トンネル(同じ受付、☎ 033-450-5559)は、1975年に発見されたトンネルです。全長3.5kmのうち500mを見学できます。

  • 出発時刻: 09:30、10:30、13:30、14:30。冬は最終出発が14:00です(平和展望台は「冬季」、第2トンネルは「11~2月」で登録)。出発の15分前に受付を締め切ります。
  • 入り方: 第2トンネルは民間人統制区域の中のため個人での見学はできず、引率者に従って一緒に出発すると登録されています。第2トンネルの韓国国内向けの案内は、見学当日に身分証を持って受付で申請書を書き、出入証を受け取る方式です。受付場所は「孤石亭 観光案内所 1階」としても、「DMZドゥルミ平和タウン (DMZ Durumi Pyeonghwa Taun / DMZ두루미평화타운) 平和・安保観光受付、ヤンジリ 457-7」としても登録されています。
  • 料金(個人): 平和展望台は大人 4,000ウォン、青少年・軍人 3,000ウォン、子ども・高齢者 2,000ウォン。第2トンネルは一般 4,000ウォン、青少年 3,000ウォン、子ども 2,000ウォン。モノレールは別に大人 2,000ウォン、青少年・軍人 1,500ウォン、子ども・高齢者 1,000ウォン。
  • 休み: 平和展望台は毎週火曜日、1月1日、旧正月・秋夕の連休。第2トンネルは毎週火曜日、1月1日、旧正月・秋夕などの名節の連休、国際マラソン大会の日と登録されています(マラソンの日付は登録値なし)。

📍 分断の痕跡と冬の渡り鳥 — 労働党舎・渡り鳥の飛来地・観光情報センター

鉄原 労働党舎、鉄原邑 Geumgangsan-ro 265 (금강산로 265)、☎ 033-450-5520 は、光復後に北朝鮮の地だった1946年に、朝鮮労働党 鉄原郡党の党舎として建てた3階建ての建物です。戦争で焼け焦げ、砲弾・銃弾の跡が残る姿のまま立っています。2002年に国家登録文化遺産となり、ソテジ・ワ・アイドゥル (Seo Taiji and Boys / 서태지와 아이들)の「渤海を夢見て (Balhaereul Kkumkkumyeo / 발해를 꿈꾸며)」のミュージックビデオを撮った場所です。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 無料。

鉄原 渡り鳥の飛来地(鉄原平野)(鉄原邑、☎ 033-450-5114)は、冬でも地中から温かい水が出て凍らないため、渡り鳥がとどまる場所です。9月中旬~10月中旬からタンチョウ、マナヅル、ガンなどが降りて冬を越します。1973年に天然記念物に指定されました。DMZドゥルミ平和タウンで、タンチョウの探鳥プログラムに参加できると紹介されています。

  • 開く時間: 常時開放。料金: 無料。駐車: 不可能。

鉄原観光情報センター(トンソンウプ Taebong-ro 1825、孤石亭国民観光地の中、☎ 033-450-5558)は、鉄原の歴史・安保・鉄原平野・観光名所を展示で紹介する案内施設です。

  • 開く時間: 09:00~18:00。休み: 毎週火曜日、旧正月・秋夕の連休、DMZマラソン大会の当日。料金: 無料。

⚠ 事前に知っておきたい3点

  1. 火曜日は多くの場所が休みます — ムルウィッキル、柱状節理の道、ヘッブル展望台、平和展望台・第2トンネル、鉄原観光情報センターが火曜休みと登録されています。
  2. 柱状節理の道の冬季の運営時間は09:00~15:00と登録されています — 片道約1時間30分かかります。
  3. DMZ平和観光は冬の最終出発が14:00です — 出発の15分前に受付を締め切り、第2トンネルは引率者と一緒に行きます。

⚙ FAQ 2

Q. 氷トレッキング祭りはいつ開かれますか?

A. 観光公社の登録情報では、2027年1月16日~2月14日、10:00~17:00です。料金は10,000ウォンで、鉄原サラン商品券 5,000ウォンが戻ります。プログラムは2026年の内容基準で登録されています。

Q. お金がかからない場所は?

A. 孤石亭、チクタンの滝、サムブヨンの滝、ウナスギョ、労働党舎、渡り鳥の飛来地、鉄原観光情報センターが無料で登録されています。孤石亭の駐車は小型 2,000ウォンです。
