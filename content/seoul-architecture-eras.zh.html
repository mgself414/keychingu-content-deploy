首尔建筑时代漫步 — 传统·近代·现代15选 + 建筑鉴赏视角

> 副标题: 景福宫 (Gyeongbokgung / 경복궁) 木造架构式 → 明洞圣堂 (Myeongdong Cathedral / 명동성당)·文化站首尔284 (Culture Station Seoul 284 / 문화역서울284) 近代砖石建筑 → DDP东大门设计广场 (Dongdaemun Design Plaza / DDP 동대문디자인플라자)·乐天世界大厦 (Lotte World Tower / 롯데월드타워) 现代摩天大楼 — 按时代顺序解读首尔建筑600年的深度指南(deep dive)。不同于宫殿古迹漫步(#207)·博物馆(#206)·DDP夜景(#172),而是首次聚焦"建筑本身"的时代视角。

ISSUE 03 · #1267 · 2026-07-23

🎯 为什么选择首尔建筑时代漫步

首尔是一座将600年王朝的木造宫殿 → 开港·殖民时期的西式砖石建筑 → 世界级明星建筑师的现代摩天大楼压缩在地铁几站之内的城市。不像纽约·巴黎那样由单一时代风格主导,而是各时代风格层层叠加,走一走就能通读整部建筑史 — 这正是首尔的强项。

KeyChinGu (키친구) 此前按区域·主题介绍过宫殿·寺庙(#207)·博物馆(#206)·DDP夜间购物(#172),但以建筑风格与时代脉络本身为视角尚属首次。尤其是近代建筑(1880s~1945) — 明洞圣堂 (Myeongdong Cathedral / 명동성당)·旧首尔站·韩国银行 (Bank of Korea / 한국은행)·贞洞 (Jeongdong / 정동) 一带 — 是外国建筑·历史爱好者暗藏的第一志愿,却是KeyChinGu此前未覆盖的领域。这正是本篇内容真正的亮点。

⚠ 外国游客常犯的3个错误

1. "韩国传统建筑=和中国·日本相似": 外观同为木造瓦顶,看似相近,但原理不同。韩国建筑的核心在于不违背自然的克制美(宗庙正殿 (Jongmyo Jeongjeon / 종묘 정전) 没有华丽装饰,仅凭101m回廊便震撼人心)+ 借景 (chagyeong / 차경)(昌德宫后苑 (Changdeokgung Huwon / 창덕궁 후원) 并非人工造园,而是"借"来山势本身)+ 卷杀柱与斗栱的结构美,这与中国的宏大、日本的精细截然不同。鉴赏视角详见下文①。

2. "近代建筑=普通老房子": 明洞圣堂 (Myeongdong Cathedral / 명동성당)·旧首尔站·韩国银行 (Bank of Korea / 한국은행) 是开港(1876)~殖民(1910~45)~大韩帝国的历史被镌刻在每一块砖上的史料。了解"是谁、为何、以何种风格建造",便能通读首尔近代史。而且大部分免费+位于市中心步行圈(贞洞路线2km内密集分布着8处近代建筑)。这是外国游客拍照·历史深度游暗藏的第一志愿。

3. "现代建筑=只有DDP": DDP东大门设计广场 (Dongdaemun Design Plaza / DDP 동대문디자인플라자)(扎哈·哈迪德 Zaha Hadid 设计)固然出名,但它并非首尔现代建筑的起点。金寿根 (Kim Swoo-geun / 김수근)·金重业 (Kim Chung-up / 김중업)(1960~70年代韩国第一代建筑大师,代表作空间社屋 (Gonggan Sagok / 공간사옥)·三一大厦 (Samil Building / 삼일빌딩))播下种子,延续至DDP·乐天世界大厦 (Lotte World Tower / 롯데월드타워)·Leeum美术馆 (Leeum Museum of Art / 리움미술관)·爱茉莉太平洋 (Amorepacific / 아모레퍼시픽) 的60年谱系。世界级建筑师(博塔 Mario Botta·努维尔 Jean Nouvel·库哈斯 Rem Koolhaas·奇普菲尔德 David Chipperfield·赫尔佐格和德梅隆 Herzog & de Meuron)的作品如此密集地汇聚在首尔,也是惊人的看点。

① 传统 — 朝鲜的木造建筑 (1395~) · 鉴赏视角 + 代表3选

> 宫殿·宗庙·寺庙的具体探访详见 #207。这里只聚焦"该如何欣赏建筑"的3个视角。

鉴赏视角3

  • 架构式木结构: 不用钉子,以榫卯结构 (gyeolgu / 결구) 咬合木材。柱子上方的斗栱 (gongpo / 공포) 分散屋顶荷载,使屋檐得以长长挑出 — 这片屋檐的阴影夏天遮阳、冬天引入阳光(科学+美学兼备)。
  • 顺应自然的位阶与借景 (chagyeong / 차경): 建筑依自然而立。昌德宫后苑 (Changdeokgung Huwon / 창덕궁 후원) 是代表案例 — 并非人工造园,而是原样"借"来山谷与溪流。
  • 丹青 (Dancheong / 단청) 与留白: 宫殿·寺庙以丹青装点得绚丽,而宗庙·书院则极度克制。同样是木造建筑,却依用途调节色彩的感觉。

1. 景福宫勤政殿 (Gyeongbokgung Geunjeongjeon) ★ 朝鲜正宫

  • 地址: 钟路区 (Jongno-gu / 종로구) 社稷路 (Sajik-ro / 사직로) 161 (3号线 景福宫站 (Gyeongbokgung Station / 경복궁역))
  • 竣工: 1395年始建,1867年重建(壬辰倭乱焚毁后由兴宣大院君 (Heungseon Daewongun / 흥선대원군) 重建)
  • 外国游客 ★: ◎◎ — 朝鲜建筑的巅峰·守卫换岗仪式拍照首选
  • 鉴赏要点: 二层月台之上的重檐歇山顶·品阶石·薄石广场的位阶秩序。门票₩3,000 (~$2.25)(穿韩服 (Hanbok / 한복) 免费)。详情 #207

2. 宗庙正殿 (Jongmyo Jeongjeon) ★ 联合国教科文组织·世界最长木造建筑

  • 地址: 钟路区 (Jongno-gu / 종로구) 钟路 (Jongno / 종로) 157 (1·3·5号线 钟路三街站 (Jongno 3-ga Station / 종로3가역))
  • 竣工: 1395年始建,1608年重建,后经增建达101m
  • 外国游客 ★: ◎◎ — 摒弃华丽装饰、克制美的极致。建筑师们在首尔最钟爱的空间
  • 鉴赏要点: 19间连绵不绝的单一回廊。剔除装饰的极简主义。详情 #207

3. 昌德宫后苑 (Changdeokgung Huwon) ★ 借景的庭园

  • 地址: 钟路区 (Jongno-gu / 종로구) 栗谷路 (Yulgok-ro / 율곡로) 99 (3号线 安国站 (Anguk Station / 안국역))
  • 竣工: 1405年(后苑营造始于17世纪)
  • 外国游客 ★: ◎ — 借自然而成的庭园·须提前预约参观
  • 鉴赏要点: 芙蓉池 (Buyongji / 부용지)·宙合楼 (Juhamnu / 주합루)·爱莲亭 (Aeryeonjeong / 애련정)。将人工痕迹降到最低的韩国庭园原型。详情 #207

② 近代 — 开港·近代化的砖石建筑 (1880s~1945) · 精华

> 历经开港(1876)·大韩帝国(1897)·日据时期(1910~45),西式建筑被移植·折衷的时期。KeyChinGu首次覆盖的领域,也是本篇内容的核心轴线。

4. 明洞圣堂 (Myeongdong Cathedral) ★ 韩国最早的砖造哥特式建筑

  • 地址: 中区 (Jung-gu / 중구) 明洞路 (Myeongdong-gil / 명동길) 74 (4号线 明洞站 (Myeongdong Station / 명동역)·2号线 乙支路入口站 (Euljiro 1-ga Station / 을지로입구역))
  • 竣工: 1898年(科斯特神父 Eugène Coste / 코스트 신부 设计)· 史迹第258号
  • 外国游客 ★: ◎◎ — 韩国最早的纯哥特式建筑·由20余种红砖砌成的尖塔
  • 标志性特色: 尖拱·肋拱穹顶·玫瑰窗。韩国天主教的象征,亦是近代民主化的圣地。免费入场(弥撒时间外可参观教堂内部)

5. 文化站首尔284 (Culture Station Seoul 284) ★ 旧首尔站舍

  • 地址: 中区 (Jung-gu / 중구) 统一路 (Tongil-ro / 통일로) 1 (1·4号线·机场铁路 首尔站 (Seoul Station / 서울역))
  • 竣工: 1925年(塚本靖 Tsukamoto Yasushi / 츠카모토 야스시 设计)· 史迹第284号
  • 外国游客 ★: ◎◎ — 文艺复兴样式+拜占庭式穹顶。旧京城站蜕变为复合文化空间
  • 标志性特色: 中央穹顶大厅·头等候车室。现作为展览·演出场地免费入场(依展览而异)。抵达首尔站后可即刻顺路欣赏

6. 韩国银行货币博物馆 (Bank of Korea Money Museum) ★ 辰野金吾设计

  • 地址: 中区 (Jung-gu / 중구) 南大门路 (Namdaemun-ro / 남대문로) 39 (2号线 乙支路入口站 (Euljiro 1-ga Station / 을지로입구역)·4号线 会贤站 (Hoehyeon Station / 회현역))
  • 竣工: 1912年(旧朝鲜银行本馆,辰野金吾 (Tatsuno Kingo / 다쓰노 긴고) 设计)· 史迹第280号
  • 外国游客 ★: ◎ — 设计东京站的大师留在首尔的作品·文艺复兴式石造建筑
  • 标志性特色: 左右对称的花岗岩立面·穹顶屋顶。作为货币博物馆免费开放。可与新世界总店 (Shinsegae Main Store / 신세계 본점)·明洞 (Myeongdong / 명동) 串联

7. 德寿宫石造殿 (Deoksugung Seokjojeon) ★ 大韩帝国西式宫殿

  • 地址: 中区 (Jung-gu / 중구) 世宗大路 (Sejong-daero / 세종대로) 99 (1·2号线 市厅站 (City Hall Station / 시청역))
  • 竣工: 1910年(哈丁 J.R. Harding 设计)· 新古典主义
  • 外国游客 ★: ◎ — 建于宫殿之内的欧式石造宫殿。东方(传统宫殿)与西方(石造殿)同处一道宫墙之内
  • 标志性特色: 爱奥尼式列柱·大韩帝国历史馆(预约制)。德寿宫门票₩1,000 (~$0.75)。详情 #207

8. 贞洞近代建筑群 (Jeongdong Historic District) ★ 步行近代建筑露天博物馆

  • 地址: 中区 (Jung-gu / 중구) 贞洞 (Jeongdong / 정동) 一带 (1·2号线 市厅站 (City Hall Station / 시청역)) — 2km步行圈内密集分布
  • 构成: 贞洞第一教会 (Jeongdong First Methodist Church / 정동제일교회)(1897,韩国最早的新教教堂建筑,史迹第256号)·旧俄罗斯公使馆 (Russian Legation / 러시아공사관)(1890,俄馆播迁 (Agwan Pacheon / 아관파천) 的舞台,位于贞洞公园 (Jeongdong Park / 정동공원))·培材学堂东馆 (Baejae Hakdang East Building / 배재학당 동관)(1916)·梨花女高辛普森纪念馆 (Ewha Girls' High School Simpson Memorial Hall / 이화여고 심슨기념관)(1915)·旧新亚日报别馆 (구 신아일보 별관) 等
  • 外国游客 ★: ◎◎ — 与德寿宫石墙路相连的近代史漫步第一去处。大部分免费
  • 标志性特色: 开港期传教士·外交官留下的西式建筑汇聚一村。参见下方近代一日游路线

9. 迪尔库沙 (Dilkusha) ★ 西方人的首尔宅邸

  • 地址: 钟路区 (Jongno-gu / 종로구) 社稷路2街 (Sajik-ro 2-gil / 사직로2길) 17 (3号线 独立门站 (Dongnimmun Station / 독립문역))
  • 竣工: 1923年(美国人阿尔伯特·泰勒 Albert Taylor 宅邸,意为"喜悦之心的宫殿")
  • 外国游客 ★: ○ — 400年银杏树旁的红砖宅邸·日据时期外国人的生活印记
  • 标志性特色: 修复后作为住宅博物馆免费开放(建议预约)。可与权栗将军 (Gwon Yul / 권율) 故居遗址·杏村洞 (Haengchon-dong / 행촌동) 小巷串联

③ 现代 — 摩天大楼与解构主义 (1960s~) · 60年谱系

> 金寿根 (Kim Swoo-geun / 김수근)·金重业 (Kim Chung-up / 김중업) 第一代大师(1960~70s)→ 世界级明星建筑师的地标(2000s~)。DDP·Leeum美术馆·爱茉莉太平洋已在 #172·#206 从区域·展览的角度介绍过,这里聚焦建筑师与风格的视角。

10. 阿拉里奥美术馆·SPACE(原空间社屋) ★ 韩国现代建筑第一圣地

  • 地址: 钟路区 (Jongno-gu / 종로구) 栗谷路 (Yulgok-ro / 율곡로) 83 (3号线 安国站 (Anguk Station / 안국역))
  • 竣工: 1971·1977年(金寿根 Kim Swoo-geun 设计)· 现为美术馆
  • 外国游客 ★: ◎ — 爬满常春藤的黑色传统砖建筑。被誉为"韩国现代建筑圣地"的金寿根代表作
  • 标志性特色: 如迷宫般错落半层的错层结构。紧邻昌德宫 (Changdeokgung / 창덕궁),与传统对话。美术馆参观收费

11. DDP东大门设计广场 (Dongdaemun Design Plaza) ★ 扎哈·哈迪德

  • 地址: 中区 (Jung-gu / 중구) 乙支路 (Euljiro / 을지로) 281 (2·4·5号线 东大门历史文化公园站 (Dongdaemun History & Culture Park Station / 동대문역사문화공원역))
  • 竣工: 2014年(扎哈·哈迪德 Zaha Hadid,2004年普利兹克奖得主)· 非线性参数化设计
  • 外国游客 ★: ◎◎ — 世界最大规模的非线性建筑·无柱流线型曲面
  • 标志性特色: 45,000片铝板·夜间LED灯光秀。普通展览免费。夜间购物·展览详情 #172·#206

12. 乐天世界大厦 (Lotte World Tower) ★ 韩国最高楼555m

  • 地址: 松坡区 (Songpa-gu / 송파구) 奥林匹克路 (Olympic-ro / 올림픽로) 300 (2·8号线 蚕室站 (Jamsil Station / 잠실역))
  • 竣工: 2017年(KPF设计)· 123层555m
  • 外国游客 ★: ◎◎ — 取自毛笔与瓷器曲线的轮廓·主宰首尔天际线
  • 标志性特色: 118~123层首尔天空 (Seoul Sky / 서울스카이)观景台(收费,建议出行前确认价格·时间)·超高层玻璃天空步道

13. Leeum美术馆 (Leeum Museum of Art) ★ 三位大师·三栋建筑

  • 地址: 龙山区 (Yongsan-gu / 용산구) 梨泰院路55街 (Itaewon-ro 55-gil / 이태원로55길) 60-16 (6号线 汉江镇站 (Hangangjin Station / 한강진역))
  • 竣工: 2004年 · 马里奥·博塔 (Mario Botta)(1号美术馆,陶瓷与赤陶)+ 让·努维尔 (Jean Nouvel)(2号美术馆,锈蚀钢板)+ 雷姆·库哈斯 (Rem Koolhaas)(儿童教育文化中心)
  • 外国游客 ★: ◎◎ — 三位大师在同一片场地上各展所长、各写各的语言。仅为建筑本身也值得一游
  • 标志性特色: 常设展免费·特展收费(需预约)。位于汉南洞 (Hannam-dong / 한남동) 山丘。馆藏详情 #206

14. 爱茉莉太平洋总部 (Amorepacific HQ) ★ 大卫·奇普菲尔德

  • 竣工: 2017年(大卫·奇普菲尔德 David Chipperfield)· 取自白瓷月亮罐意象的立方体
  • 外国游客 ★: ◎ — 中间镂空的立方体·中庭与屋顶花园。克制的极简风格
  • 标志性特色: 1楼大堂·美术馆(APMA)·中庭对外开放。K-Beauty总部建筑巡礼

15. 首尔市厅新厅舍 (Seoul City Hall) ★ 刘杰·玻璃波浪

  • 地址: 中区 (Jung-gu / 중구) 世宗大路 (Sejong-daero / 세종대로) 110 (1·2号线 市厅站 (City Hall Station / 시청역))
  • 竣工: 2012年(刘杰 Yoo Kerl 设计)· 玻璃幕墙
  • 外国游客 ★: ○ — 旧厅舍(1926文艺复兴式,现为首尔图书馆 (Seoul Library / 서울도서관))身后耸起的玻璃波浪。将传统屋檐曲线诠释为现代语言
  • 标志性特色: 超大型室内绿墙·市民厅。免费开放。旧厅舍(近代)与新厅舍(现代)同框可见

⚙ 常见问题(FAQ)6个

1. 一天能看完三个时代吗?: 可以。以市厅 (City Hall / 시청) 为起点,近代(贞洞 (Jeongdong / 정동)·德寿宫 (Deoksugung / 덕수궁))→步行→钟路 (Jongno / 종로) 传统(宗庙 (Jongmyo / 종묘)·景福宫 (Gyeongbokgung / 경복궁))→地铁前往现代(DDP·乐天世界大厦 (Lotte World Tower / 롯데월드타워))。但密度较高,建议每个时代安排半天。参见下方路线。

2. 哪些建筑可以免费参观?: 明洞圣堂 (Myeongdong Cathedral / 명동성당)·文化站首尔284 (Culture Station Seoul 284 / 문화역서울284)·韩国银行货币博物馆 (Bank of Korea Money Museum / 한국은행 화폐박물관)·贞洞近代建筑群 (Jeongdong Historic District / 정동 근대건축군) 大部分·迪尔库沙 (Dilkusha / 딜쿠샤)·DDP普通展览·Leeum美术馆常设展·爱茉莉太平洋大堂·首尔市厅 (Seoul City Hall / 서울시청)·星空图书馆 (Starfield Library / 별마당도서관)。近代建筑几乎全部免费。

3. 穿韩服有优势的地方?: 宫殿(景福宫 (Gyeongbokgung / 경복궁)·昌德宫 (Changdeokgung / 창덕궁)·德寿宫 (Deoksugung / 덕수궁))穿韩服 (Hanbok / 한복) 免费入场。近代·现代建筑与韩服无关,但贞洞 (Jeongdong / 정동)·石造殿 (Seokjojeon / 석조전) 为背景拍照颇受欢迎。

4. 建筑摄影胜地?: 宗庙正殿 (Jongmyo Jeongjeon / 종묘 정전) 回廊·明洞圣堂 (Myeongdong Cathedral / 명동성당) 正面·石造殿 (Seokjojeon / 석조전) 列柱·DDP夜间曲面·倒映在石村湖 (Seokchon Lake / 석촌호수) 中的乐天世界大厦 (Lotte World Tower / 롯데월드타워)·爱茉莉太平洋中庭。

5. 有英文导览吗?: 文化站首尔284 (Culture Station Seoul 284 / 문화역서울284)·货币博物馆·Leeum美术馆·DDP·贞洞导览牌均有英文标注。明洞圣堂 (Myeongdong Cathedral / 명동성당)·石造殿 (Seokjojeon / 석조전) 提供英文宣传册。

6. 雨天替代方案?: 货币博物馆·文化站首尔284 (Culture Station Seoul 284 / 문화역서울284)·Leeum美术馆·星空图书馆 (Starfield Library / 별마당도서관)·爱茉莉太平洋美术馆均为室内场所,不受降雨影响。
