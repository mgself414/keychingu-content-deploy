全州 南部市場・青年モール・夜市ガイド — 韓屋村から徒歩3分、2026年 公式情報

🎯 このガイドの使い方

全州の南部市場 (Nambu Sijang / 남부시장)は、全州韓屋村 (Jeonju Hanok Maeul / 전주 한옥마을)から豊南門 (Pungnammun / 풍남문)を渡って徒歩3分です(全州市公式)。昼の市場・2階の青年モール (Cheongnyeon Mall / 청년몰)・金土の南部市場夜市 (Nambu Sijang Yasijang / 남부시장 야시장)・早朝のトッケビ市場 (Dokkaebi Sijang / 도깨비시장)が一つの建物と路地に重なっているので、時間帯さえ合わせれば韓屋村の日程にそのまま組み込めます。以下の値は2026-10-07に全州市・全北観光の公式ページで読み取ったものだけを載せており、夜市の時間のように出典で食い違う値はそのように記しています。以前のガイドには住所も時間もまったくありませんでした。

🏮 南部市場 — 1473年の市場、豊南門の隣

  • 全州市公式: 1473年に始まった市場で、すぐ隣が豊南門(宝物 第308号)、韓屋村まで徒歩3分。住所は豊南門1ギル 19-3、063-284-1344。
  • 市場の代表的な食べ物(公式)は、豆もやしクッパ (Kongnamul-gukbap / 콩나물국밥)(トリョム式)とピスンデクッパ (Pisundae-gukbap / 피순대국밥)です。公式の市場ツアーのページに載っているお店は、イェンナルピスンデ (Yetnal Pisundae / 옛날피순대)(24時間営業)と豊南門ビビンバ (Pungnammun Bibimbap / 풍남문비빔밥)(04:00〜18:00)の2軒です。それ以外のお店と料金は載せていません。
  • 市場全体の営業時間は公式に掲載がなく(二次情報では09:30〜22:00)、店舗ごとに異なります。

🛍 青年モール — 2階、11:00〜23:00、月曜休み

  • 南部市場の2階、住所は豊南門2ギル 53。11:00〜23:00、月曜休み、約20店舗(全州市公式)。公式ページに「店舗ごとに時間が異なる」とあるので、特定のお店が目当てなら事前に確認してください。
  • 以前のガイドにあった「MZ・ヒップスターの成功モデル」のような評価は公式資料にないため、削りました。

🌙 夜市 — 金・土のみ

  • 金・土曜日だけ開きます。250mの路地に食べ物の屋台が並びます(全北観光公式)。食べ物は3,000〜5,000ウォン台(公式)。
  • 時間は出典で食い違います: 全北観光は3〜10月 18:30〜23:30・11〜2月 18:00〜24:00 / 韓国観光公社の記事は18:00〜24:00(夏)・17:00〜22:00(冬)。2026年の確定値は確認できませんでした — 「金・土の夜、季節ごと」程度に捉えて、当日確認してください。
  • 冬(1〜2月)に休業した前例が報じられています(2024年)。冬に訪れるなら、まず営業しているかを確認してください。
  • 屋台の数は出典ごとに33・40・45と異なるため、載せていません。

🌅 トッケビ市場 — 早朝4時

  • 南部市場の早朝市で、04:00〜10:00(全州市公式)。全州の早朝散歩と豆もやしクッパの組み合わせです。

🏛 慶基殿 — 韓屋村とセットで

  • 太祖路 44。3〜5月・9〜10月 09:00〜19:00、6〜8月 09:00〜20:00、11〜2月 09:00〜18:00、入場締切は1時間前。全州市民以外の大人 3,000・青少年/軍人 2,000・子ども 1,000ウォン、毎月最終水曜日は無料・最終土曜日は半額(全州市公式)。
  • 殿洞聖堂 (Jeondong Seongdang / 전동성당)は公式ページを開けなかったため、時間・料金を載せていません。

🚉 行き方

  • 全州駅 (Jeonju-yeok / 전주역)から韓屋村・南部市場へ: バス・タクシーの所要時間は公式ページにないため載せていません。地図アプリで「全州 南部市場」を検索してください。
  • 韓屋村からは豊南門を渡ればすぐ市場です(公式「徒歩3分」)。

⚠ よくある失敗5つ

1. 月曜日の青年モール — 休みです。

2. 日〜木曜日の夜市 — 金・土だけ開きます。

3. 冬の夜市を当たり前と思う — 休業した前例があります。営業しているか確認を。

4. 慶基殿の料金を知らずに通り過ぎる — 最終水曜は無料、最終土曜は半額です。

5. 市場のお店がすべて開いていると思い込む — 店舗ごとに時間が異なります(公式の注意書き)。

⚙ FAQ 6つ

1. 韓屋村と一日で回れますか? — 回れます。徒歩3分です。昼は韓屋村・慶基殿 → 夜は青年モールか金土の夜市。

2. 夜市は何時からですか? — 金・土の夜です。季節ごとの時間は出典で食い違うので、当日確認してください。

3. 朝ごはんは? — トッケビ市場(4〜10時)か、豆もやしクッパ(トリョム式)・ピスンデクッパ。

4. 青年モールの時間は? — 11:00〜23:00、月曜休みです。

5. 慶基殿はいくら? — 大人 3,000ウォン。最終水曜は無料です。

6. 全州駅からどのくらいかかりますか? — 公式には掲載がありません。地図アプリで確認してください。
