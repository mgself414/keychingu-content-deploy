＃＃⚠外国人の頻繁なミス7つ

1. 「発酵食品=別メニュー」：発酵食品=すべての韓国料理の基本調味料。別のメニューX。

2. "味噌=日本の笑顔のような柔らかさ": 韓国味噌= 濃い香・塩味。日本の笑顔＝柔らかさ・甘い。他の味。

3. "コチュジャン=スパイシーな味だけ":コチュジャン=スパイシー+甘味+コクの複合。 Srirachaのような鍛造スパイシーX。

4. 「チョングクジャン=柔らかさ」:チョングクジャン=強い香+漢方保養。日本納豆好きなら入門OK・もしくは回避。

5. "醤油=日本soy sauceのような":韓国朝鮮醤油=濃い塩味・国マニア。日本醸造醤油＝甘い。他のカテゴリ。

6. "真空包装=機内持ち運び": 章= 液体・受託手荷物のみ。機内持ち込み禁止。

7. "VAT 払い戻し X": 免税店長 = VAT 払い戻し可能。

⚙ よくある質問8件

1. 最初の発酵食品=どのメニュー:味噌チゲ+ご飯(本物)→ビビンバ+コチュジャン(グローバル)段階。

2. インスタ・vlog: 淳昌長流村・昌徳宮ジャンゴ・醤油ゲジャンマニア。

3. MZトレンド：トリュフコチュジャン・明太子ご飯・コチュジャンクリームパスタ。

4. グローバルトレンド: コチュジャンK-food #1・アマゾンベストセラー。

5. 健康マニア: チョングクジャン(プロバイオティクス)・味噌(ジャンヘルン) — 断定表現回避。

6. アレルギー: 豆・シーフード・フルーツ・ナッツ・高塩分事前告知。

7. 決済・チップ: 免税店・マート=カード/ジャンドクデ村=一部現金/チップX。

8. VAT 払い戻し: 免税店長 = 払い戻し可能 / レストラン・市場 = 払い戻し X.

⚠医療・安全・食事ダイエット

発酵食品=一般食品（医薬品X）。 高塩分注意（味噌・唐辛子・醤油・塩辛＝塩分↑） — 高血圧・腎臓患者注意。妊婦＝チョングクジャン・強い発酵食品適量。子ども＝チョングク長・箸ガルマニア入門に気をつけて。アレルギー（大豆・シーフード・フルーツ）事前通知。食中毒・食品届 = ☎ 1399 (食薬処) / 医療緊急 = ☎ 1339 (医療、英文)。本ガイドは一般情報、医療助言ではない。

機内携帯・搬入規定：章＝液体分類・委託手荷物のみ。自国規定事前確認（オーストラリア・ニュージーランド＝食品搬入制限）。

食事制限 fallback:

  • ハラール・コーシャー：味噌・コチュジャン・醤油・酢 = アルコール・動物材料 X = OK / 塩辛 = ビハラル / チョングクジャン = OK (コンマン)。
  • ベジタリアン・ビーガン：味噌・コチュジャン・醤油・酢・チョングクジャン=ベジタリアンOK / 塩辛=非菜食。
  • グルテンフリー：一般醤油・コチュジャン=グルテンX /醸造醤油=小麦含有(確認必須)。
