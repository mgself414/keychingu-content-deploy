国乐 — 盘索里·四物游戏·阿里郎，韩国之声

> 盘索里 (Pansori / 판소리, 唱者·鼓手·恨) · 四物游戏/风物 (Samulnori / 사물놀이) · 阿里郎 (Arirang / 아리랑) · 国乐器 (伽倻琴 Gayageum / 가야금·奚琴 Haegeum / 해금) · 正乐 (Jeongak / 정악) vs 民俗乐 (Minsogak / 민속악) · 现代国乐韩流 — 为外国人讲解的国乐 (Gugak / 국악, 韩国传统音乐) 文化。不是“有什么乐器”，而是“韩国人用这种声音表达什么、又能在哪里听到”。

早在K-pop震动世界之前，韩国就有属于自己的声音。国乐 (Gugak / 국악) — 字面意思即“国家的音乐”，也就是韩国传统音乐。一位唱者 (Sorikkun / 소리꾼) 用一面鼓撑起数小时故事的盘索里 (Pansori / 판소리)，四件打击乐器炸开的四物游戏 (Samulnori / 사물놀이)，人人都能哼唱的阿里郎 (Arirang / 아리랑) — 这是一个音阶、节奏、情绪都与西方音乐不同的世界。

本文不是讲“哪个演出场好”（→ 场所指南），而是讲解国乐是什么、分成哪些支系、韩国人用这种声音表达什么。同样是“传统音乐”，宫廷庄严的正乐 (Jeongak / 정악) 与庶民鲜活的民俗乐 (Minsogak / 민속악) 是完全不同的音乐。这是韩国文化解读系列第71篇。

⚠️ 外国人常误解的3点

1. “国乐＝就是老旧的背景音乐 (BGM) 吧” ❌ — 国乐不是用来烘托气氛的音效，而是精密的音乐体系。其核心在于与西方多来咪不同的音阶 (平调 Pyeongjo / 평조·界面调 Gyemyeonjo / 계면조)、不是节拍而是叫长短 (Jangdan / 장단) 的固有周期节奏框架，以及让音颤动转折的装饰韵 (Sigimsae / 시김새, 弄弦)。不是“简单”，而是“不同”。

2. “盘索里大概像短小的民谣吧” ❌ — 盘索里是一篇长达数小时的大叙事。一位唱者用歌 (唱 Sori / 소리)·说白 (Aniri / 아니리)·身段 (Neoreumsae / 너름새)，独自扮演数十个角色。它是接近歌剧的独角音乐剧，而非短歌。

3. “国乐是只存在于博物馆里的死音乐” ❌ — 大谬不然。李娜耳赤的《虎下山》(범 내려온다) 在YouTube上以数亿播放逆袭走红，乐团光七 (ADG7 / 악단광칠) 在海外巡演。把传统之声披上摇滚·朋克·电子的融合国乐 (Fusion gugak / 퓨전 국악)，正是当下韩国年轻世代的新潮流。

① 国乐是什么 — “国家的音乐”两大主干

国乐 (Gugak / 국악) 是指韩国传统音乐整体的词。为与西方音乐 (洋乐 Yangak / 양악) 区分而得名，它广泛涵盖从宫廷音乐、仪礼音乐到庶民的歌·舞。理解的钥匙在于它分成两大支系。

  • 正乐 (Jeongak / 정악): “端正的音乐”。宫廷与两班 (Yangban / 양반, 士大夫) 所享的有格调且节制的音乐。宗庙祭礼乐 (Jongmyo Jeryeak / 종묘제례악)、灵山会相 (Yeongsanhoesang / 영산회상, 风流 Pungnyu / 풍류)、正歌 (Jeongga / 정가, 歌曲·时调) 都属于此。舒缓而庄严，比起流露情感更偏向治理情感。
  • 民俗乐 (Minsogak / 민속악): 百姓所享的自由而情感鲜活的音乐。盘索里 (Pansori / 판소리)·散调 (Sanjo / 산조)·民谣 (Minyo / 민요)·风物 (Pungmul / 풍물, 农乐) 都是民俗乐。即兴与神明 (Sinmyeong / 신명) 满溢，悲与喜都毫无保留地倾吐。

外国人最先遇到的盘索里·四物游戏·阿里郎几乎都在民俗乐一侧 — 所以国乐常被感觉为“情感浓烈、充满神明”。另一个特征是长短 (Jangdan / 장단)。不是去数4/4拍，而是在真养调 (Jinyangjo / 진양조, 舒缓)·中莫里 (Jungmori / 중모리)·自进莫里 (Jajinmori / 자진모리, 快) 这类有名字的节奏框架上流动，越往后越快，从而把张力推上去。

② 盘索里 — 唱者·鼓手，以及“恨 (Han / 한)”的音乐

盘索里 (Pansori / 판소리) 是国乐中最戏剧化的支系。台上只有两个人。

  • 唱者 (Sorikkun / 소리꾼, 演唱者): 手持一把扇子站着演唱。在歌 (唱 Sori / 소리)、以说白讲出的台词 (Aniri / 아니리)、手势·身段的表演 (Neoreumsae / 너름새) 之间往返，独自扮演所有人物。
  • 鼓手 (Gosu / 고수, 打鼓的人): 席地而坐，用一面鼓 (Buk / 북) 把握节奏，并不时以“哎嗦！”“好啊！”的助兴喝彩 (Chuimsae / 추임새) 来添兴。观众也一起喊助兴 — 这是观众参与演奏的音乐。

盘索里五场 (五马当) (今日传下的五篇):

马当 故事
春香歌 (Chunhyangga / 춘향가) 跨越身分的春香与李梦龙之爱，以及节操
沈清歌 (Simcheongga / 심청가) 为让父亲复明而舍命的孝女沈清
兴夫歌 (Heungbuga / 흥부가) 善良的兴夫与贪婪的孬夫，劝善惩恶的兄弟故事
水宫歌 (Sugungga / 수궁가) 兔子与鳖 (龟) 的斗智 — 充满诙谐的动物寓言
赤壁歌 (Jeokbyeokga / 적벽가) 把《三国志》赤壁之战谱成歌的英雄叙事

把盘索里的情绪压缩成一句话就是恨 (Han / 한, 恨)。它用凄切的嗓音倾吐被压抑的悲伤·思念·郁结，而其中又混合着诙谐与兴。唱者为了刻意造出沙哑粗粝的嗓音 (Suriseong / 수리성)，常年在瀑布前磨练嗓子 — 不是顺滑的美声，而是带着人生重量的浊声才是盘索里的美德 (→ 恨的情绪参见 #1138)。

> UNESCO: 盘索里于2003年被选定为联合国教科文组织人类口头及非物质遗产代表作 (其后于2008年编入代表名录)。

③ 四物游戏·风物 — 四件乐器造出的神明

如果说盘索里是“恨”，那四物游戏就是恰恰相反的神明 (兴)。

四物游戏 (Samulnori / 사물놀이) 字面意思即“用四样 (四物) 来玩 (놀이)”的音乐。四件打击乐器合在一起，叠出爆发性的节奏。

乐器 是什么 象征
锣 (Kkwaenggwari / 꽹과리) 小黄铜钲，用竹槌敲打 雷 — 由领奏者持握并发出信号
钲 (Jing / 징) 大钲，浑厚回响 风
长鼓 (Janggu / 장구) 沙漏形双面鼓 雨
鼓 (Buk / 북) 圆木双面鼓，低音 云

这些乐器原本来自风物 (Pungmul / 풍물, 农乐)。风物是在农村祈求丰年、驱除村中灾厄、众人一同敲打起舞的共同体音乐。把这在田野间露天铺展的农乐，由金德洙等人于1978年重构为舞台上四人坐奏，便是四物游戏。也就是说，四物游戏是从传统 (风物) 诞生的现代舞台样式。

四物游戏的魅力在于越来越快的长短 (Jangdan / 장단)。从舒缓起步，经自进莫里 (Jajinmori / 자진모리)·挥莫里 (Hwimori / 휘모리) 加速，瞬间把观众席推向兴奋。即便不懂歌词，外国人也能用全身去享受，是最直观的国乐。

④ 阿里郎 — 每个地域各异，韩国人的歌

阿里郎 (Arirang / 아리랑) 是只要是韩国人就无人不知的国民民谣。它没有特定作曲家。是数百年间普通人共同创作、传唱下来的集体创作物。

结构很简单。“阿里郎 阿里郎 阿拉里哟…”这段副歌是共通的，而唱词 (Saseol / 사설) 因地域而异。所以阿里郎不是一首歌，而是分化为约60种、3600余种变体的庞大歌曲家族。

  • 旌善阿里郎 (Jeongseon Arirang / 정선 아리랑) (江原道): 被视为最古老的原型。太白山脉深山沟壑的孤绝所酿成的舒缓而哀婉的曲调。
  • 珍岛阿里郎 (Jindo Arirang / 진도 아리랑) (全南海岛): 受南道巫俗·sinawi 的影响，带有浑厚耐听的韵致。
  • 密阳阿里郎 (Miryang Arirang / 밀양 아리랑) (庆南): 又快又轻快，近乎劳动号子的欢腾曲调。带着边干农活边齐唱的南部农耕文化的色彩。

阿里郎歌咏悲伤 (离别·艰辛的生活)，却在其中盛着不是认命，而是慰藉与情 (Jeong / 정)。所以在殖民时期它是抗争之歌，今日则被视为南北可以同唱的民族之歌。

> UNESCO: 阿里郎于2012年列入联合国教科文组织人类非物质文化遗产。

⑤ 国乐器 — 伽倻琴·奚琴·大笒，韩国声音的纹理

国乐独特的音色来自乐器。这些代表乐器与西方乐器似像非像。

  • 伽倻琴 (Gayageum / 가야금, 12-string zither): 国乐器的门面。用手指弹拨、按压12根蚕丝弦的弹拨乐器。靠按弦使音颤动的弄弦 (Nonghyeon / 농현, 装饰韵) 发出深远余韵。(现代也有18·21·25弦的改良型。)
  • 玄琴 (Geomungo / 거문고, 6-string zither): 6弦的厚重弹拨乐器。用拨棒 (Suldae / 술대) 击弦演奏，声音比伽倻琴更低沉、更具沉思，故作为士大夫的乐器受到喜爱。
  • 奚琴 (Haegeum / 해금, 2-string fiddle): 2弦擦弦乐器 (韩式小提琴)。用弓摩擦，发出如人声般凄婉婉转的声音。是融合国乐中最受欢迎的旋律乐器。
  • 大笒 (Daegeum / 대금, large bamboo flute): 大型横吹竹笛。芦苇膜 (Galdaecheong / 갈대청) 振动，发出特有的如风般的颤音与清越之声。
  • 筚篥 (Piri / 피리): 小型竖吹竹制双簧管乐器。体型虽小但音量大，撑起合奏的中心。
  • 长鼓 (Janggu / 장구): 打击乐之核。沙漏形，两面皮发出不同声音(高的鼓面 Chaepyeon / 채편·低的鼓面 Bukpyeon / 북편)，几乎进入所有合奏。

如果说西方乐器追求精准的音高，那国乐器更看重在音与音之间颤动、推送的表现 (装饰韵 Sigimsae / 시김새)。可以说是“纹理与颤动”而非“精准”的音乐。

⑥ 正乐 vs 民俗乐 — 宫廷的格调与庶民的神明

把①中点到的正乐·民俗乐的差别再展开一点。会区分这两者，国乐听起来就有了层次。

  • 正乐 (Jeongak / 정악, 宫廷·上流): 舒缓庄严、节制的音乐。代表是宗庙祭礼乐 (Jongmyo Jeryeak / 종묘제례악) — 朝鲜 (Joseon / 조선) 王室向历代君王祭祀时演奏的音乐·歌·舞综合艺术，自15世纪延续500余年。它不爆发情感，而表达品位与秩序。(宗庙祭礼·祭礼乐于2001年列入联合国教科文组织。)
  • 民俗乐 (Minsogak / 민속악, 庶民): 又快又自由、情感鲜活的音乐。盘索里·散调·民谣·风物属于此。即兴与神明、恨与兴毫无保留地显现。

打个比方，正乐是熨烫整齐的正装，民俗乐是舒适的便服。外国人若觉得“国乐充满神明、情感浓烈”，那多半是听了民俗乐；若觉得“庄严而舒缓”，那是听了正乐。两者都是国乐。

⑦ 现代国乐韩流 — 《虎下山》掀开的新浪潮

国乐不是被做成标本的过去。进入2020年代，它作为最时髦的音乐之一复活了。

  • 李娜耳赤 (Leenalchi / 이날치): 盘索里人声搭配贝斯·鼓的7人乐队。借用盘索里水宫歌 (Sugungga / 수궁가) 一段的《虎下山》(범 내려온다)，与韩国观光公社的宣传影片相互呼应，在YouTube上以数亿播放逆袭走红。
  • 乐团光七 (ADG7 / 악단광칠): 以黄海道巫俗音乐·西道民谣为底，仅用传统乐器喷发摇滚·朋克能量的9人组。他们驰骋美国·欧洲的舞台，不断增加海外粉丝。

粉丝把这股潮流称为融合国乐 (Fusion gugak / 퓨전 국악)。核心在于不抛弃传统而是重新诠释 — 保留盘索里发声、长鼓长短、奚琴旋律，同时披上现代的外衣。K-pop走向世界的路，国乐也正以自己的方式追随。

⑧ 外国人的国乐体验 — 在哪里听、怎么学

外国人完全可以享受并学习国乐。即使不懂歌词，仅凭节奏与音色就很强烈。

  • 国立国乐院 (National Gugak Center / 국립국악원, 首尔瑞草): 国乐的大本营。周六常设 (Toyosangseol / 토요상설) 演出 (每周六下午) 尤其适合入门 — 在一处就能品味宫廷乐·民俗乐·舞蹈。自2001年延续的国际国乐工作坊是外国人亲手学习盘索里·奚琴·伽倻琴·长鼓的项目。
  • 演出·体验一口尝: 在仁寺洞·贞洞的传统演出场、四物游戏一日班、韩屋村常设演出可以短暂品味。最近还会举办外国人盘索里唱者的展演。
  • 先用耳朵入门: 不妨依李娜耳赤《虎下山》(범 내려온다) → 四物游戏影片 → 阿里郎的顺序来听。这是最快打破“很难”成见的路线。

> 实战: 演出门票·时间随季节变动，请在出发前确认国立国乐院·VisitKorea 的官方日程。四物游戏·盘索里越靠前的座位，助兴喝彩与振动越生动。

❓ 外国人常问的问题 (FAQ)

  • 国乐到底是什么？ — 是指韩国传统音乐整体的词 (“国家的音乐”)。大致分为宫廷·上流的正乐 (Jeongak / 정악) 与庶民的民俗乐 (Minsogak / 민속악)。盘索里·四物游戏·阿里郎都属民俗乐系。
  • 盘索里为什么那么长、嗓音那么粗？ — 盘索里一篇是数小时的叙事，由唱者一人扮演所有人物。沙哑粗粝的嗓音 (Suriseong / 수리성) 不是缺陷，而是多年修炼才得来的美德 — 被视为承载人生重量的声音。
  • 阿里郎为什么有好几个版本？ — 它没有作曲家，是各地域的人配上不同唱词传唱的歌，所以分化出旌善·珍岛·密阳等约60种。只有副歌相同，曲调与唱词各异。
  • 国乐如今还有人听吗，还是老音乐？ — 都有。原汁原味的传统演出依旧活跃，李娜耳赤·乐团光七这类融合国乐在年轻世代中很受欢迎。
  • 外国人能直接学吗？ — 可以。在国立国乐院的国际国乐工作坊或四物游戏一日班，可以体验长鼓·盘索里。即使不懂歌词，凭节奏来享受也很合适。
