本地人推荐 ⑦ 全南·光州·济州 — 韩国观众点名的10家饭馆，从松汀站前到摹瑟浦

副标题：光州一日游综述（#1026）、木浦儒达山（#1050）、济州本地人美食篇（#1348）都没有覆盖的一条线——从韩国观众在YouTube评论区推荐的全国饭馆汇总表中，只挑出全南、光州、济州10家，逐一在Naver本地搜索上核实店名、地址、行业类别，不做评价。光州·木浦·罗州5家 → 宝城·海南2家 → 济州3家。罗州和海南都是KeyChinGu第一次介绍的城市，这片土地的行政名称在2026年7月发生了变化。

ISSUE 06 · #1388 · 2026-09-18 · 本地人推荐 ⑦

🎯 为什么以"评论区推荐"为标准

这个专栏只有一个来源。韩国某YouTube频道发布了一期"全国饭馆"视频，观众在评论区写下了自己家乡的饭馆，其中按地区整理得最系统的评论被制成表格，共217家。这是韩国人推荐给韩国人的名单，所以外语评论很少，很多是不会出现在观光名单上的小城饭馆。这个专栏的标准和局限，写在①篇（#1382）里。

KeyChinGu只用Naver本地搜索核实了店名、地址、行业类别是否真实存在（2026-09-17）。全南·光州·济州11家里确认了10家，未确认的1家（高敞）已剔除。没有探店评价、排名、星级，也没有营业时间和价格——去之前请查Naver Place。

这一篇里地址看起来陌生是有原因的。2026年7月1日，光州广域市和全罗南道合并为一个全南光州统合特别市 (Jeonnam-Gwangju Consolidated Special City / 전남광주통합특별시)——简称光州特别市 (Gwangju Special City / 광주특별시)。木浦市、罗州市、宝城郡、海南郡这些基础单位的名称保持不变，所以地图应用上显示"全南光州统合特别市 木浦市……"是正常的。旅行者实际上不需要改变任何行程，只是名称变了。

① 光州·木浦·罗州 — 5家湖南线沿线城市的饭馆

湖南线 (Honam Line / 호남선) 从益山分出，一路向下经过光州松亭、罗州、木浦（益山的故事在#1385）。这5家都在这条线上，其中一家是少数几个能从车站直接走过去的例子。

  • 永明汤饭 (Yeongmyeong Gukbap / 영명국밥) · 光山区松汀路8街5号 (5 Songjeong-ro 8-gil, Gwangsan-gu / 광산구 송정로8번길 5) · 韩餐 · 解酒汤 · 从光州松亭站步行约8分钟

光州松亭站前的小巷以聚集了约200米长的烤牛肉饼 (tteokgalbi / 떡갈비) 店而闻名。这家汤饭店就在同一条巷子里，是唯一能让人拖着行李从KTX下车后直接走到的地方。解酒汤可以单人点。

  • 元祖戒指 (Wonjo Garakji / 원조가락지) · 木浦市荣山路258街8-2号 (8-2 Yeongsan-ro 258-gil, Mokpo-si / 목포시 영산로258번길 8-2) · 餐馆 · 韩餐 · 木浦老城区——木浦站一带，步行分钟数以Naver地图为准
  • 汉城黑猪 (Hanseong Heuk Dwaeji / 한성흙돼지) · 木浦市荷堂南部路61街8号 (8 Hadangnambu-ro 61-gil, Mokpo-si / 목포시 하당남부로61번길 8) · 韩餐 · 韩定食 · 荷堂新城区——离木浦站有一段距离。自2026年9月1日起，一条新的市郊巴士开始直接连接木浦站与荷堂、南岳、五龙

木浦这座城市分为老城区（车站、儒达山一带）和荷堂·南岳新城区。两处属于不同的生活圈，一天内两边都跑要多花不少路程。

  • 老安家 (Noanjip / 노안집) · 罗州市锦城馆街1-3号 (1-3 Geumseonggwan-gil, Naju-si / 나주시 금성관길 1-3) · 韩餐 · 牛肉汤及牛骨汤 · 罗州邑城锦城馆 (Naju Eupseong Geumseonggwan / 나주읍성 금성관) 前的街道——从罗州站坐巴士或打车
  • 南平奶奶家 (Nampyeong Halmaejip / 남평할매집) · 罗州市锦城馆街2号 (2 Geumseonggwan-gil, Naju-si / 나주시 금성관길 2) · 餐馆 · 韩餐 · 街对面

罗州是以牛肉汤闻名的城市，这两家店隔着同一条锦城馆街面对面。不过，锦城馆这栋建筑本身截至2026年9月仍在拆除维修施工中，预计2027年重新开放，不要抱着能参观的期待过去。饭馆街本身照常营业。

给外国游客的提示 — 牛肉汤和解酒汤可以单人点，韩定食通常要2人以上起点。牛肉汤的当地吃法是自己用盐和葱调味，再倒一点萝卜块泡菜 (kkakdugi / 깍두기) 汤汁进去。

② 宝城·海南 — 2家铁路最近有变化的南方饭馆

这两个郡在2025年铁路情况发生了变化。随着木浦宝城线 (Mokpo–Boseong Line / 목포보성선)通车，海南第一次有了车站，宝城则分成了原有车站和新车站。另一方面，庆全线 (Gyeongjeon Line / 경전선) 光州松亭至顺天段电气化截至2026年仍在施工中（通车目标为2030年），目前还不是旅行者能用的线路。

  • 未力羊汤 (Miryeok Yangtang / 미력양탕) · 宝城郡未力面礼才路2号 (2 Yejae-ro, Miryeok-myeon, Boseong-gun / 보성군 미력면 예재로 2) · 餐馆 · 韩餐 · 车站要选对——宝城同时有原有的宝城站 (Boseong Station / 보성역) 和2025年8月随木浦宝城线开通而新建的新宝城站 (Sinboseong Station / 신보성역)。未力面离哪一站更近尚未确认，订票前请先按目的地核对路线

宝城是绿茶田（#426·#676）所在的郡。未力面是这条观光动线之外的一个面所在地。

  • 花墙 (Kkotdam / 꽃담) · 海南郡海南邑海南路160-12号1楼 (1F, 160-12 Haenam-ro, Haenam-eup, Haenam-gun / 해남군 해남읍 해남로 160-12 1층) · 韩餐 · 韩定食 · 海南站2025年9月27日才新开通，但位于市区外围，距市区约8公里，必须换乘巴士。市外巴士从木浦每天8班，从光州每天24班

海南是以地尽头 (Ttangkkeut / 땅끝) 闻名的郡，又称土末 (Tomal / 토말)。韩定食在这个南道地区上菜格外丰盛，按2人以上安排才合适。

给外国游客的提示 — 南道韩定食小菜数量多，大多数情况下很难单人点。如果只有一个人，牛肉汤·解酒汤那一组（①组）更现实。

③ 济州 — 3家机场巴士能到的三个方向

济州岛不用租车，从机场坐巴士也能到大部分地方。名单上的这3家分别在市区、东南、西南三个不同方向。

  • 林济 (Imje / 임제) · 济州市塔洞路126号2楼 (2F, 126 Tapdong-ro, Jeju-si / 제주시 탑동로 126 2층) · 韩餐 · 烤猪肉 · 从济州机场 (Jeju Airport / 제주공항) 坐机场巴士或316路到塔洞 (Tapdong / 탑동) 约20分钟

塔洞是济州市一个有海边步道的街区。济州烤猪肉以黑猪 (heuk dwaeji / 흑돼지) 闻名，通常从2人份起点。

  • 耽罗酱蟹 (Tamna Ganjang Gejang / 탐라간장게장) · 西归浦市表善面表善唐浦路10-4号 (10-4 Pyoseondangpo-ro, Pyoseon-myeon, Seogwipo-si / 서귀포시 표선면 표선당포로 10-4) · 餐馆 · 韩餐 · 从济州机场坐121路（经城邑）可到表善 (Pyoseon / 표선)，所需时间以Naver地图为准

酱油蟹 (ganjang gejang / 간장게장) 是用生螃蟹泡在酱油里腌渍发酵而成的食物，配米饭吃。表善是济州东南部一个有海水浴场和民俗村的面。

  • 美英家 (Miyeongine / 미영이네) · 西归浦市大静邑下摹港口路42号 (42 Hamohanggu-ro, Daejeong-eup, Seogwipo-si / 서귀포시 대정읍 하모항구로 42) · 韩餐 · 生鱼片 · 从济州机场坐151路快线可到大静·摹瑟浦方向（终点站标注为云津港）

摹瑟浦是济州西南部的一个港口小镇。Naver的分类是生鱼片。

给外国游客的提示 — 济州的巴士分快线（蓝色系编号）和干线，用交通卡可以衔接换乘。生鱼片、酱油蟹、烤肉都是2人以上比较合适的菜式，独自一人的话，最好提前打电话确认能不能单点。

🚄 怎么接进地方行程里

  • 光州松亭站换乘途中吃一顿 — 下KTX步行8分钟。这个专栏里离车站最近的一家。
  • 在木浦住一晚 — 把行程分成老城区（车站、儒达山）和荷堂新城区两段。2026年9月新开的市郊巴士把两边直接连了起来。
  • 罗州 — 从罗州站坐巴士或打车到锦城馆街。锦城馆这栋建筑在施工中，只看饭馆街就好。
  • 宝城·海南 — 绿茶田（#426）和地尽头是观光主轴，这两家店在轴线之外。海南以坐巴士为主。
  • 济州 — 从机场出发三个方向。市区（塔洞）、东南（表善）、西南（摹瑟浦）一天全跑完不太现实。
  • 从全北下来 — 从益山坐湖南线到光州松亭、木浦。全北篇是#1385。

⚠ 3个常见失误

1. 把锦城馆观光排进行程 — 截至2026年9月仍在拆除维修施工中，预计2027年重新开放。饭馆街照常营业。

2. 笼统地用"宝城站"订票 — 原有的宝城站和新宝城站是两个不同的车站。订票前请先按目的地核对路线。

3. 在海南站下车后步行去市区 — 距市区约8公里，必须换乘巴士或打车。

⚙ 3个常见问题

1. 这份名单是谁选的？ — 是把韩国YouTube观众在评论区写下的地方饭馆整理成的表格。KeyChinGu只核实了是否存在、地址和行业类别，没有做任何排名。

2. 和济州本地人美食篇（#1348）有什么不同？ — #1348是介绍如何识别本地人美食信号、以及五日市的方法论篇。这一篇只写汇总表里提到的3家的位置和交通方式。

3. 为什么光州只有一家？ — 汇总表里光州的条目只有松亭这一个。光州的观光动线在#1026、#319、#643里。
