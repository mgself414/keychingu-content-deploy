釜山の居酒屋・バー14軒 — 外国人レビューが先に残った店だけ

サブタイトル: チョンポのウイスキーバー・クァンアルリの海辺バー(#1364)、ナッコプセ・ゴムジャンオ・ヤンコプチャン(#1410)に続く軸——ソミョンのLPバー、チョンポ路地のカクテル、ミルラクのスピークイージーと海鮮酒場、ナムチョン・スヨンのジャズと串焼き。Naverマップに外国語レビューが先に残った居酒屋だけを14軒選び、4エリアにまとめて夜の動線でつないだ。バーの選び方・1人1杯・リクエスト曲の文化といったバーマナーは#1364

ISSUE 06 · #1436 · 2026-11-23 · 釜山のお酒 3本目

🎯 なぜ「三言語レビュー」が基準なのか

釜山のお酒編はすでに二本あります——チョンポ・クァンアルリのバーホッピング(#1364)と、ナッコプセ・ゴムジャンオ・ヤンコプチャン(#1410)。今回は、その二本に出てこなかった店だけを集めました。同じチョンポ・クァンアルリの路地でも、店は重なりません。

選定基準はひとつだけです——Naverマップに英語・日本語・中国語のレビューがそろって残る居酒屋。韓国人の人気ランキングではなく、すでに外国人が訪れて三言語で足跡を残した場所こそ、次の外国人旅行者にとって最も馴染みやすい選択だという判断です。レビュー数は2026-11時点で、この回では店ごとにその数を記載しました。例外は二つ——ロバタアキ (Robata Aki / 로바타아키)とピョリュ (Pyoryu / 표류)は英語レビューしか残っていませんが、店の性格がこの回の軸に合うため入れました。店の性格とレビューの言語が必ずしも一致するわけではありません——和食の居酒屋ロバタアキも、レビューは英語だけです。

⚠ 表記の原則：営業時間・定休日・メニュー価格は、カカオマップ (Kakao Map / 카카오맵)にオーナーが登録した値です(2026-11-23確認)。登録がない項目は「カカオマップで当日確認」としました。価格は1杯または肴1皿の単価だけを記載し、1人あたりの予算は書きません——何杯、何皿頼むかによって変わるからです。駅からの徒歩時間はカカオマップの道案内の値(出口基準)です。バーの選び方・1人1杯・リクエスト曲の文化は#1364。

① ソミョン・ブジョン — 3軒

ソミョン駅 (Seomyeon Station / 서면역)の出口から徒歩5~6分圏内です。この回で英語メニュー名が登録されている3軒のうち2軒がここにあります。

  • マンミブルース — LPをかけるウイスキーのミュージックパブです。ウイスキー・ハイボール・ビール・スモールフードの構成で、カカオマップのメニュー名が英語でも登録されています(whiskey / highball / beer / small food)。外国語レビューは10件(4・3・3)でこの回では最多、三言語すべてが3件以上です。19:00オープン、日~木は01:00・金・土は02:00まで、火曜定休。ソミョン駅8番出口から徒歩約5分、3階。店名はマンミ洞 (Mangmi-dong / 망미동)時代のままですが、今はソミョンに移転しました——地図アプリに旧マンミ洞の住所が出たら、ソミョンの住所(ブサンジン区 (Busanjin-gu / 부산진구)のジュンアンデロ680番ガギル80-20 (Jungang-daero 680beon-gagil 80-20 / 중앙대로680번가길 80-20) 3階)で探し直してください。価格はカカオマップで当日確認。
  • シウォル — ウイスキー・カクテル・ワインのLPバーです。カカオマップのメニュー名がWine Selection・Highball Selection・Non-Alcoholic Selectionと英語で登録されていて、ノンアルコールの項目が別にあります——お酒が飲めない連れがいても一緒に行けます。火~木・日は18:00~01:00、金・土は02:00まで、月曜定休。ソミョン駅8番出口から徒歩約6分、2階202号。価格はカカオマップで当日確認。
  • ロバタアキ — 炭火の前のカウンターに座る炉端居酒屋です。野菜盛り合わせ焼き₩8,000、ボストンウニ50g ₩29,000、6品の刺身盛り合わせ₩34,000——肴の単価は₩8,000~34,000。英語レビューのみ4件。水~月 18:00~01:00、火曜定休。ソミョン駅4番出口から徒歩約5分。刺身・ウニは生ものなので、生ものを避けたいなら焼き物から選びましょう。

② チョンポ路地 — 3軒

チョンポ駅 (Jeonpo Station / 전포역)の4・7番出口側の路地です。#1364のチョンポのウイスキーバーと同じエリアですが、店は別です。3軒とも毎日営業なので、曜日の心配がありません。

  • ホリデーバー — ジャズとLPをかけるカクテルバーで、肴の品ぞろえが豊富です。パイ類₩16,000・ブッラータ₩16,000・ミートチリチーズフライ₩17,000。カクテルの価格はカカオマップで当日確認。毎日 18:30~01:30。チョンポ駅4番出口から徒歩約5分。
  • ポスターバー — 電気電子商店ビルの1階にある屋外テラスのカクテルバーです。肴は₩6,000~18,000(バスクチーズケーキ₩10,000、ブッラータ₩18,000)。お酒の価格はカカオマップで当日確認。毎日 18:00~02:00。チョンポ駅7番出口から徒歩約7分。冬はテラスが寒いので、室内席があるかどうかをカカオマップの写真で先に確認しましょう。
  • フイルダム — LPカクテルバーです。ハイボール・ワイン・瓶ビール₩9,000、ウイスキー・カクテル₩10,000——この回で1杯の価格が確認できた2軒のうち安いほうです。毎日 18:00~02:00。チョンポ駅7番出口から徒歩約7分、2階。ポスターバーとはどちらも7番出口から歩いて7分の距離です。

③ クァンアルリ・ミルラク — 4軒

クァンアルリのビーチからミルラク洞 (Millak-dong / 민락동)側の路地です。クァンアン駅 (Gwangan Station / 광안역)1番出口から徒歩13~15分なので、駅よりもビーチから歩いて入るほうが楽です。henry17とコナバリは同じミルラクロ27番ギル (Millak-ro 27beon-gil / 민락로27번길)にあります。

  • henry17 — 2階のスピークイージーのカクテル・ウイスキーバーです。看板の表記は「アンリ17 (Angri 17 / 앙리17)」なので、地図アプリでは両方の名前で検索してみてください。ハイボールは₩16,000から(英語ガイドtablejourney基準)——この回で1杯の価格が確認できた2軒のうち高いほうです。肴はバッファローウイング₩15,000・スパニッシュハムプラッター₩30,000。営業時間はカカオマップに登録がなく、英語ガイドでは19:00~03:00(月曜は20:00オープン)と出ています——カカオマップで当日確認。同じガイドがNaver予約を勧めています。クァンアン駅1番出口から徒歩約13分。
  • ピョリュ — 豆乳ハイボールが看板のハイボールバーです。レビュー5件はすべて英語。肴は₩12,000~17,000(チーズトースト₩12,000、ニョッキグラタン₩17,000)。ハイボールの価格はカカオマップで当日確認。毎日 18:00~02:00。クァンアン駅1番出口から徒歩約14分。#1364のベースメント (Basement / 베이스먼트)と同じ路地なので、二本を組み合わせてバーを2軒はしごするのに向いています。
  • コナバリ — 旬の海鮮を出す日本風の酒場です。麻婆豆腐の土鍋₩16,000、ポハン産アオリイカ₩30,000、その日のバリ盛り合わせ₩60,000——肴の単価は₩16,000~60,000で、みんなで分け合う構成です。三言語レビューは2・2・2。毎日 18:00~03:00。クァンアン駅1番出口から徒歩約15分。henry17と同じ路地なので、1軒目コナバリ → 2軒目henry17とつなげられます。
  • スダルバー クァンアン — カウンターに座って伝統酒を飲む韓食酒場です。チョルミョン入りスンドゥブチゲ₩15,000、韓牛ユッケの丼₩19,000、トクと練り物のおでん鍋₩25,000——肴の単価は₩15,000~25,000。日~木 17:00~02:00、金・土は03:00まで。駅からの徒歩時間は登録がないので、カカオマップの道案内で確認してください。ユッケは生の牛肉です。

④ ナムチョン・スヨン・マンミ — 4軒

クァンアルリの西側、ナムチョン洞 (Namcheon-dong / 남천동)とスヨン駅 (Suyeong Station / 수영역)周辺です。クァンアルリのビーチ沿いより路地の奥まったところで、スヨン駅の出口から近い店が二つあります。

  • ジャズプレッソ — ジャズ・LPをかけるカフェバーで、ライブ公演の案内も投稿されます。肴は₩12,000~18,000(ブッラータ₩17,000、焼きソーセージとポテト₩18,000)。お酒の価格とライブの日程はカカオマップのお知らせで当日確認。火~土 19:00~24:00、月・日曜定休——この回で休みが2日あるのはここだけ。ナムチョン駅 (Namcheon Station / 남천역)3番出口から徒歩約13分、2階。
  • チョヒッサツ — 炭火串焼きの居酒屋です。ヤキトン1本₩3,500(2本から注文)、スペアリブの唐揚げ₩12,000、トッペイヤキ₩13,000——串は1本単位、肴は₩12,000~13,000台。毎日 17:00~02:00。クムニョンサン駅 (Geumnyeonsan Station / 금련산역)3番出口から徒歩約5分。
  • ミュージコロジー — 地下1階のLPバーで、カクテル・ウイスキー・ワインがあります。カカオマップのメニュー名が英語でも登録されています(Cocktail, Whisky, red wine)。15:00オープンなので、昼飲みや早めの夕方に合わせられます。月・火・木・日は24:00、金・土は01:00まで、水曜定休。カレーライス₩13,000のほかの価格はカカオマップで当日確認。スヨン駅2番出口から徒歩約8分。
  • ポグァンダンタンジェウォン — ユッケ・刺身の肴を出す料理居酒屋です。カニ味噌ヌードル₩16,000、ウニユッケ₩37,000、刺身盛り合わせ₩40,000——肴の単価は₩16,000~40,000。月~土 18:00~24:00、日曜定休。スヨン駅3番出口から徒歩約4分。肴は生ものが中心なので、生ものを避けたいならカニ味噌ヌードルを(材料・アレルギーは注文前にスタッフに確認)。

🗺 夜の動線 — 二つのルート

A. ソミョン・チョンポの夜 (ソミョン駅 → チョンポ駅)

  1. 1軒目 ソミョン駅4番出口 → ロバタアキの炭火の肴(18:00~、火曜定休)
  2. 2軒目 ソミョン駅8番出口側 → マンミブルースまたはシウォルのLPバー(月曜はマンミブルース、火曜はシウォル)
  3. 3軒目 チョンポ路地 → フイルダムで1杯(₩9,000~10,000) → 同じ7番出口側のポスターバー、または4番出口側のホリデーバー(01:30まで)

B. クァンアルリ・ナムチョン・スヨンの夜 (スヨン駅 → クァンアルリ)

  1. 早めの夕方 スヨン駅2番出口 → ミュージコロジー(15:00~、水曜定休)、またはクムニョンサン駅3番出口 → チョヒッサツの串焼き(17:00~)
  2. 1軒目 スヨン駅3番出口のポグァンダンタンジェウォン(日曜定休)、またはナムチョンのジャズプレッソ(火~土)
  3. 2軒目 クァンアルリのビーチ → ミルラクの路地でコナバリの海鮮 → 同じ路地のhenry17
  4. 締め ピョリュのハイボール、またはスダルバー クァンアンの伝統酒(金・土は03:00まで)

火曜はAの1軒目(ロバタアキ)、日曜はBの1軒目(ポグァンダンタンジェウォン・ジャズプレッソ)がどちらも休みなので、2軒目の店から始めましょう。地下鉄で戻るなら、出発前に釜山地下鉄の終電の時間を確認してください。終電を逃したらタクシーです。夜景を組み込むなら#1326。

⚠ よくある失敗3つ

  1. 火曜にマンミブルース・ロバタアキ、月曜にシウォル、水曜にミュージコロジー、日曜にポグァンダンタンジェウォン — それぞれ定休日です。ジャズプレッソは月・日の2日休みます。まず曜日を確認しましょう。
  2. 身分証なしで行く — 韓国で酒が飲める年齢は、年単位の数え方で19歳(その年の1月1日を基準に、毎年1月1日に一斉に1歳加算。青少年保護法第2条)です。日本の20歳基準とは異なります。外国人は入口や注文のときにパスポートの提示を求められることがあるので、持って行きましょう。
  3. 「カカオマップで当日確認」を飛ばす — henry17の営業時間、複数のバーのお酒の価格、ジャズプレッソのライブ日程は登録がありません。行く前にカカオマップの営業情報・お知らせを見れば、その日の答えが載っています。

⚙ よくある質問3つ

  1. ひとつだけ選ぶなら？ — 外国語レビューが最も多く残っているのはマンミブルース(10件、4・3・3)、1杯の価格が確認できた店のうち安いほうはフイルダム(₩9,000~10,000)、お酒を飲まない連れと一緒ならシウォル(ノンアルコールメニュー)。
  2. 英語メニューがある店は？ — メニュー名が英語で登録されているのは、マンミブルース・シウォル・ミュージコロジーの3軒。ほかは英語メニューがあるかどうかわかっていないので、翻訳アプリを用意しましょう。
  3. バーのマナー・注文方法は？ — 1人1杯、リクエスト曲、バー席の選び方は#1364にあります。ポチャ・ホルモン系の酒席は#1410。
