韩国素食·清真指南——首尔12家餐厅(Eid、Legume、钵盂供养、五世界香、蕨菜快餐)与祈祷室(2026年10月官方数据)

副标题: Eid (Eid / 이드) 是韩国伊斯兰教中央会(KMF)认定为清真的少数餐厅之一(VisitSeoul) · Legume (Legume / 레귬) 是米其林1星纯素餐厅(米其林页面) · 钵盂供养 (Balwoo Gongyang / 발우공양) 营业时间11:30~21:00,周日休息(VisitKorea) · 首尔中央清真寺 (Seoul Jungang Seongwon / 서울중앙성원) 于1976年5月启用(VisitSeoul) · 仁川机场祈祷室4处全天24小时开放(仁川旅游官方网站) — 截至2026-10-21

🎯 本指南的使用方法

紫苏汤里泡着刀削面,蘑菇饺子在火锅里冒着热气——这是一桌不用肉煮成的韩餐(绿园餐厅 (Chorokddeul Sikdang / 초록뜰식당),VisitSeoul)。本指南写给不吃肉和鱼的旅行者与需要清真饮食的穆斯林旅行者。分为四类:清真餐厅、寺院料理·素食韩餐、上榜米其林的纯素·蔬菜料理、纯素咖啡馆·烘焙店。另附两处祈祷室。餐厅只挑选了登载于VisitSeoul、VisitKorea旅游信息和米其林指南的店家。

旧版指南写过"KMF清真认证餐厅30家以上"。这没有依据。VisitSeoul穆斯林旅行指南(2018年撰写、2022年修订)所列的KMF认证餐厅是10家,其中Eid的地址(乌沙坛路10街67号)也与现在的地址(15号)不同。名单在几年之间也会变动。"犹太洁食餐厅""明星厨师"之类的说法找不到出处,已删除。

🕌 清真餐厅——梨泰院3家

  • Eid (Eid / 이드) — VisitSeoul将梨泰院的Eid(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街15号 (Usadan-ro 10-gil / 우사단로10길),每天12:00~21:00)介绍为韩国伊斯兰教中央会(KMF)认定为清真的少数餐厅之一。认定可能变动,到访前请先确认。三样小菜和汤每天现做(VisitSeoul英文版)。韩文版有两个Eid页面:2026-06-29修订版写的是11:30~21:00(最后点餐20:30)、070-8899-8210,另一个页面写的是0507-1404-8219,两者不同。修订版写有穆斯林厨师在岗、不售酒,烤肉(Bulgogi)15,000韩元(VisitSeoul韩文版)
  • 亚当斯曼迪 (Adams Mandi / 아담스만디) — 龙山区 (Yongsan-gu / 용산구) 绿莎坪大路218号 (Noksapyeong-daero / 녹사평대로)。11:00~24:00(最后点餐23:00),周一休息。阿拉伯厨师做的也门·阿拉伯料理。曼迪(Mandi)是把羊肉或鸡肉用小火长时间焖熟、盖在香料饭上的菜。"只使用100%清真认证食材"。02-797-7776(VisitSeoul,2026-10-13登录)
  • PB Plus (PB Plus / PB플러스) — 龙山区 (Yongsan-gu / 용산구) 乌沙坛路33号 (Usadan-ro / 우사단로),1层。用清真认证食材制作的汉堡和披萨。牛肉芝士汉堡7,500韩元,意式辣香肠披萨(M)17,000韩元。每天12:00~23:45(2026-10-19修订版,2019年的页面是13:00~23:00)。0507-1369-4883(VisitSeoul韩文版)
  • 区分:"KMF认定为清真的餐厅"与"使用清真认证食材的餐厅"不同。餐厅四分类请见#467 马来西亚旅行者指南

🍚 寺院料理·素食韩餐——首尔3家

  • 寺院料理专门店钵盂供养 (Balwoo Gongyang / 발우공양) — 钟路区 (Jongno-gu / 종로구) 邮政局路56号 (Ujeongguk-ro / 우정국로)。11:30~21:00,准备时间15:00~18:00,周日休息。套餐有禅食 (Seonsik / 선식)、元食 (Wonsik / 원식)、心食 (Maeumsik / 마음식)、喜食 (Huisik / 희식)、法食 (Beopsik / 법식)。可电话(02-733-2081)或通过官网预约,全部座位禁烟(VisitKorea)。旅游信息中没有套餐价格
  • 素食料理专门店五世界香 (Osegyehyang / 오세계향) — 钟路区 (Jongno-gu / 종로구) 仁寺洞12街14-5 (Insadong 12-gil / 인사동12길)。11:30~21:00,午餐最后点餐15:00,准备时间16:00~17:00,晚餐最后点餐20:00。周四及春节、中秋假期休息。酸梅糖醋菜、香菇卷、调味"炸鸡"、纯素炒年糕。02-735-7171(VisitKorea)
  • 绿园餐厅 (Chorokddeul Sikdang / 초록뜰식당) — 东大门区 (Dongdaemun-gu / 동대문구) 忘忧路18街36号 (Mangu-ro 18-gil / 망우로18길)。11:00~20:00,周六休息。蘑菇饺子火锅、紫苏刀削面、素饺子,米粉10,000韩元、橡子凉粉饭(Mukbap)7,000韩元。不售酒。02-2243-7733(VisitSeoul韩文版)
  • 更多寺院料理店请见#493 首尔寺院料理专门店全指南

🥬 上榜米其林的纯素·蔬菜料理——3家

  • Legume (Legume / 레귬) — 江南区 (Gangnam-gu / 강남구) 江南大路652号 (Gangnam-daero / 강남대로),Sinsa Square 2层207室。周二至周六 12:00~15:00·18:00~22:00,周日、周一休息。米其林1星,纯素·素食,₩₩。Seong Si-u (Seong Si-u / 성시우) 主厨只用蔬菜做出套餐。吧台座位,可刷信用卡。+82 50-71365-1567(米其林页面)
  • Base Is Nice (Base Is Nice / 베이스 이즈 나이스) — 麻浦区 (Mapo-gu / 마포구) 桃花2街20号 (Dohwa 2-gil / 도화2길)。周二至周日11:00~15:00,周一休息。素食,₩。蔬菜饭、汤、小菜按韩餐结构上桌,菜单每3~4周更换。主厨一人经营,必须预约。+82 50-71306-6724(米其林页面)
  • 蕨菜快餐 (Gosari Express / 고사리 익스프레스) — 中区 (Jung-gu / 중구) 退溪路85街12-10 (Toegye-ro 85-gil / 퇴계로85길),新堂中央市场内。周二至周五 11:00~14:00·17:00~20:30,周六11:00~20:30,周日、周一休息。纯素,₩。用蕨菜油酱汁拌的面和台式煎饼。仅限电话预约。+82 2-2039-3140(米其林页面)

☕ 纯素咖啡馆·烘焙店——3家

  • Prana Table (Prana Table / 프라나 테이블) — 城东区 (Seongdong-gu / 성동구) 圣水日路3街3-9 (Seongsu-il-ro 3-gil / 성수일로3길),2层·屋顶。周一至周五10:00~20:00,周六、周日09:00~19:00,无休息日。巴西莓碗15,000韩元,豆腐蔬菜卷12,000韩元。莓果碗配清真认证燕麦脆。010-9842-5127(VisitSeoul韩文版)
  • The Rabbit (The Rabbit / 더래빗) — 瑞草区 (Seocho-gu / 서초구) 方背川路4安街38号 (Bangbaecheon-ro 4an-gil / 방배천로4안길),1层。12:00~20:00。植物性贝果·奶油奶酪,土豆泥贝果4,800韩元。有售酒。0507-1353-7847(VisitSeoul)
  • 纯素咖啡馆达娘 (Dalnyang / 달냥) — 钟路区 (Jongno-gu / 종로구) 明伦1街31-20 (Myeongnyun 1-ga / 명륜1가),2层。11:00~21:00(最后点餐20:30),周二、周三休息。豆奶冰淇淋、泰式青咖喱、满满蔬菜的拌饭。0507-1467-0388(VisitKorea)

🛐 祈祷室——梨泰院·仁川机场

  • 首尔中央清真寺 (Seoul Jungang Seongwon / 서울중앙성원) — 龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街39号 (Usadan-ro 10-gil / 우사단로10길),距梨泰院站 (Itaewon-yeok / 이태원역) 3号出口477米。韩国第一座清真寺,1976年5月21日启用。每天开放,礼拜时间随日出变化,请在清真寺网站查看。不可穿无袖上衣、短裙、短裤,也不可吸烟,可在警卫室旁的更衣室借裙子和头巾。非穆斯林也可入内,但不要在祈祷的人面前举起相机。02-793-6908(VisitSeoul,2026-09-17修订)
  • 仁川国际机场 — 4处。第一航站楼免税区3层、登机楼东侧4层,第二航站楼普通区地下1层、免税区4层。全年00:00~24:00(仁川旅游官方网站,2026-06-22修订)

🥗 饮食

  • 素食陷阱:泡菜调料大多含有虾酱·鱼露·肉汤,嫩豆腐汤和炖豆腐通常放虾酱。拌饭大多会放肉和鸡蛋,专设素食菜单的餐厅很少(VisitKorea英文版)
  • 清真:VisitSeoul将梨泰院的Eid(龙山区 (Yongsan-gu / 용산구) 乌沙坛路10街15号 (Usadan-ro 10-gil / 우사단로10길),每天12:00~21:00)介绍为韩国伊斯兰教中央会(KMF)认定为清真的少数餐厅之一。认定可能变动,到访前请先确认。即使是纯素餐厅,也有像The Rabbit (The Rabbit / 더래빗) 这样卖酒的(VisitSeoul)
  • 过敏:蕨菜快餐 (Gosari Express / 고사리 익스프레스) 用芝麻粉,Prana Table (Prana Table / 프라나 테이블) 用燕麦脆和火麻籽(米其林页面·VisitSeoul)。点餐前先问清楚
  • 价位:韩元金额只有VisitSeoul的菜单价格(5家),米其林的三家只有₩、₩₩符号
  • 展示卡请见#1300 饮食需求手册,担心辣请见#1398 不辣韩餐地图

🧰 素食·清真实用信息——独自用餐、预约、支付、点餐、交通

  • 独自用餐:Legume (Legume / 레귬) 和蕨菜快餐 (Gosari Express / 고사리 익스프레스) 设有吧台座位(米其林页面)
  • 预约:Base Is Nice (Base Is Nice / 베이스 이즈 나이스) 必须预约,蕨菜快餐 (Gosari Express / 고사리 익스프레스) 仅限电话预约(米其林页面)。钵盂供养 (Balwoo Gongyang / 발우공양) 可电话·官网预约(VisitKorea)
  • 支付:米其林的三家都可刷信用卡(米其林页面)。整体情况请见#527 韩国支付系统
  • 点餐:"请不要放肉、鱼、鸡蛋、虾酱"用卡片展示给店员。翻译软件请见#1339 点餐礼仪
  • 交通:梨泰院的3家清真餐厅和清真寺都在梨泰院站 (Itaewon-yeok / 이태원역)、绿莎坪站 (Noksapyeong-yeok / 녹사평역) 步行范围内(VisitSeoul)。交通卡请见#1298 三种交通卡怎么选

⚠ 常见的4个错误

1. "梨泰院的清真餐厅都是KMF认证"——写有KMF认定的是Eid (Eid / 이드)。亚当斯曼迪 (Adams Mandi / 아담스만디) 和PB Plus (PB Plus / PB플러스) 是"使用清真认证食材"(VisitSeoul)

2. "首尔唯一的KMF认证韩餐厅"——这是2017~2018年前后名单上的说法。现在Eid的英文页面写的是"少数餐厅之一"

3. "豆腐·蔬菜小菜就是素食"——泡菜里常有虾酱,嫩豆腐汤里常放虾酱(VisitKorea英文版)

4. "清真寺内可以随便拍照"——请避免在祈祷的人面前拍摄(VisitSeoul)
