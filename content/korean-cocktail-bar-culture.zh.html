韩国鸡尾酒吧文化 — 为什么首尔 (Seoul / 서울) 成了亚洲的"鸡尾酒之都"

> Bar Cham · Zest · 传统酒 (Jeontongju / 전통주) 鸡尾酒 · Asia's 50 Best — 写给外国人的韩国鸡尾酒吧文化 explainer。不是"哪家酒吧好",而是"为什么首尔 (Seoul / 서울) 突然成了全世界都在关注的鸡尾酒城市"。

很多外国人一提到韩国的酒,首先想到的是烧酒 (Soju / 소주)、啤酒、马格利酒 (Makgeolli / 막걸리)。可一旦来到首尔 (Seoul / 서울) 走进一家鸡尾酒吧,就会两次惊讶。第一,在由韩屋 (Hanok / 한옥) 改造的酒吧里,会端出用济州 (Jeju / 제주) 柑橘、忠州 (Chungju / 충주) 苹果等韩国食材调制的鸡尾酒。第二,其完成度和服务是世界顶级水准。事实上,首尔 (Seoul / 서울) 的酒吧每年都在亚洲50最佳酒吧 (Asia's 50 Best Bars) 中名列前茅,其中一家还跻身世界50最佳酒吧前列(截至2025年 — 建议核实)。本文不讲"在哪里喝"(→ cross-link),而是以外国人的视角,讲解短短十多年间首尔 (Seoul / 서울) 如何崛起为亚洲鸡尾酒之都的背景与意义。韩国文化 explainer 系列第34篇。

⚠️ 外国人常有的3个误解

1. "韩国人只喝烧酒 (Soju / 소주) 和啤酒" ❌ — 传统的酒席(→ #1140 聚餐·饮酒文化)依旧存在,但首尔 (Seoul / 서울) 有一个与之完全不同层次的鸡尾酒吧场景。它也是全世界酒吧评论家每年都会造访的美食鸡尾酒城市。

2. "鸡尾酒是西方文化,韩国的会不会只是模仿" ❌ — 恰恰相反。首尔 (Seoul / 서울) 酒吧的全球差异点正是传统酒 (Jeontongju / 전통주) 和韩国食材。把马格利酒 (Makgeolli / 막걸리)、烧酒 (Soju / 소주)、传统果酒,以及济州 (Jeju / 제주) 柑橘、忠州 (Chungju / 충주) 苹果等地方物产融入鸡尾酒,调出"只有在韩国才能喝到的一杯"。

3. "高级酒吧又贵又不亲切" ❌ — 价格大约每杯2万~2.5万韩元(~110~135 RMB),比东京、香港更为合理(建议核实),而首尔 (Seoul / 서울) 酒吧场景以亲切又博学的款待(hospitality)著称。即使你不太懂鸡尾酒,调酒师也会询问你的口味再推荐。

① 首尔成了"亚洲鸡尾酒之都"

Asia's 50 Best Bars 是每年评选亚洲最佳酒吧、最具权威的榜单。在2025年的发布中,首尔 (Seoul / 서울) 多家酒吧同时入选正赛榜(第1~50名)和扩展榜(第51~100名)(合计7家以上 — 建议以官方榜单核实)。以单一城市而言,这与东京、新加坡、香港不相上下。

尤其是清潭洞 (Cheongdam-dong / 청담동) 的 Zest,在 Asia's 50 Best Bars 2025 中位列第2名,并且在 *World's 50 Best Bars(世界50最佳酒吧)中也跻身前列(第16名 — 建议核实)。这意味着它在亚洲之外、也获得了世界舞台的认可*,是韩国酒吧进入全球顶尖行列的标志性事件。想到仅仅十多年前首尔 (Seoul / 서울) 几乎还没有这样的场景,这个速度令人惊叹。

> 排名与年份每年都会变化。前往之前请在 Asia's 50 Best Bars 官方榜单(theworlds50best.com)上确认最新信息。

② 为何崛起 ① — 名为"传统酒鸡尾酒"的武器

让首尔 (Seoul / 서울) 酒吧场景走向世界的第一个秘诀,是韩国独有的食材。他们没有照搬西方酒吧,而是用只有韩国才有的酒和食材打造了自己的身份。

最具代表性的是钟路 (Jongno / 종로) 西村 (Seochon / 서촌) 的 Bar Cham。在由韩屋 (Hanok / 한옥) 改造的空间里,把菜单分成全国6个地区,用各地区的传统酒 (Jeontongju / 전통주) 和物产调制鸡尾酒 — 比如济州 (Jeju / 제주) 区用柑橘,南部区用梨、苹果。光是喝,就像把韩国的地理与历史绕了一圈。这种farm-to-bar 的方式 — 直接与当地农户、酿酒厂连接,使用应季食材 — 已成为首尔 (Seoul / 서울) 场景的共同语言。

马格利酒 (Makgeolli / 막걸리)、烧酒 (Soju / 소주)、传统果酒(→ #136 马格利酒·#203 韩国酒)与金酒、威士忌并列作为鸡尾酒基酒使用,这是在世界上任何城市都难得一见、首尔 (Seoul / 서울) 独有的风景。

③ 为何崛起 ② — 零废弃·可持续

第二个秘诀是可持续性(sustainability)。最接近世界第一的 Zest,不仅以美味的鸡尾酒闻名,更以几乎不留废弃物的运营方式而著称。

  • 食材再利用:把面包边、果皮等本会被丢弃的食材重新用进鸡尾酒。
  • 本地·自产:尽可能在离酒吧近的地方采购食材,部分还亲自种植(如通过城市养蜂获取蜂蜜 — 细节建议核实)。
  • 极简:撕掉标签、去掉多余装饰,让人只专注于酒与味道本身。

这种理念并非只是"善意营销",而是真正带来更好的味道与创意 — 在证明了这一点之后,可持续性已成为整个亚洲酒吧场景的新标准。

④ 为何崛起 ③ — 世界级调酒师与"团队"文化

第三个秘诀是人。首尔 (Seoul / 서울) 有多位世界大赛冠军级的调酒师。Bar Cham 的林炳镇 (Lim Byung-jin / 임병진)、Le Chamber 的严道焕 (Eom Do-hwan / 엄도환) 等人,曾在帝亚吉欧世界级(Diageo World Class)等全球鸡尾酒大赛中夺冠(年份·赛事建议核实),他们是把首尔 (Seoul / 서울) 场景技术水平提升一个台阶的第一代。

另一个特点是以"团队"为单位培育多家酒吧的结构。一个团队运营多家概念各异的酒吧,在其中相互培养人才 — 例如运营 Cricket 和 Pine & Co 的团队,或先后开出 Bar Cham、Pomme (뽐)、Cham in Season (참앤시즌) 的团队。曾在某家传奇酒吧(如 Alice (앨리스))工作的调酒师独立出来,开出又一处名所(如 Zest)的良性循环,让这个场景快速成长。

⑤ 从 speakeasy 到科学实验室 — 概念的多样性

首尔 (Seoul / 서울) 鸡尾酒吧的另一个魅力,是空间与概念的多样性。卖的不只是酒,而是"体验"。

  • 隐藏入口(speakeasy):清潭 (Cheongdam / 청담) 的 Le Chamber 要按下书架上的按钮门才会打开,Alice 则要从花店内的暗门进入。
  • 时代概念:光化门 (Gwanghwamun / 광화문) 四季酒店的 Charles H 重现了1920~30年代的 Art Deco speakeasy。
  • 空间概念:江南 (Gangnam / 강남) 地下的 Villa Records 是1960~70年代太空时代风格的黑胶聆听沙龙,MIXOLOGY 则把鸡尾酒当作科学来对待。
  • 韩国式深度:北村 (Bukchon / 북촌) 韩屋村的 Gong-Gan 用鸡尾酒诠释童年记忆,并实践 upcycling(升级再造),因而入选 Asia's 50 Best。

同样一杯鸡尾酒,因为附上的故事不同,就会变成完全不同的体验 — 这场故事讲述的竞争,提升了首尔 (Seoul / 서울) 场景的水准。

⑥ 从江南到钟路·恩平 — 场景的扩散

早期首尔 (Seoul / 서울) 的鸡尾酒吧集中在江南 (Gangnam / 강남)(清潭 (Cheongdam / 청담)·狎鸥亭 (Apgujeong / 압구정))。Le Chamber、Alice、Zest 等先驱在这一地区开启了场景。如今重心已扩散到全城 — 传统犹存的钟路 (Jongno / 종로)(西村 (Seochon / 서촌)·北村 (Bukchon / 북촌)·安国 (Anguk / 안국))、年轻气息的麻浦 (Mapo / 마포)(孔德 (Gongdeok / 공덕)),甚至到恩平区 (Eunpyeong-gu / 은평구) 北汉山 (Bukhansan / 북한산) 山脚。离市中心很远的郊外酒吧,有时还被评为"调酒师最推荐的地方"。好酒吧不再困在一个街区,而是扩散到整座城市,这意味着场景已变得又深又厚。

⑦ 外国人如何享受首尔的鸡尾酒吧

  • 预约:人气酒吧(尤其是入选 Asia's 50 Best 的)排队长或需要预约。最好提前通过 CatchTable 等预约 app、Instagram DM 或电话订位。
  • 英语:越有名的酒吧,英语接待越到位。即使不太懂鸡尾酒,只要说出"喜欢的味道(清爽的/烟熏的/不甜的)",调酒师就会为你推荐。
  • 费用:鸡尾酒每杯大约2万~2.5万韩元(~110~135 RMB),酒店·品鉴套餐更高(建议按时点·汇率核实)。通常已含服务费,无需另外给小费。
  • 礼仪:座位少的酒吧很多,因此遵守预约·人数很重要。人多的话请选宽敞的酒吧(如 Villa Records)。为了身份确认(满19岁以上),请带好护照。
  • 动线:一个街区聚集多家酒吧的江南 (Gangnam / 강남) 清潭 (Cheongdam / 청담)、钟路 (Jongno / 종로) 西村 (Seochon / 서촌),很适合 bar hopping(连续跑吧)。

> 具体的酒吧清单·动线,将在另一篇场所指南(首尔精酿鸡尾酒吧指南)中介绍。

❓ 常见问题

1. 不太懂鸡尾酒也能去吗? — 能。首尔 (Seoul / 서울) 酒吧场景以款待闻名。只要说出口味,调酒师就会量身推荐。没有菜单的酒吧也一样。

2. 烧酒 (Soju / 소주)、马格利酒 (Makgeolli / 막걸리) 鸡尾酒真的好喝吗? — 传统酒 (Jeontongju / 전통주) 的醇厚风味与鸡尾酒很搭。这是只有在韩国才能喝到的组合,非常值得一试。

3. 一个人去也可以吗? — 坐在吧台座位(bar seat)上,单人前往很自然,也方便和调酒师聊天。

4. 是不是只有贵的地方才好? — 不是。一些街区小酒吧(如 Notes (노츠))也能做出世界级品质。首尔 (Seoul / 서울) 场景的平均水准本身就很高。

5. 什么时候去比较好? — 平日(周日~周四)晚上较清静,周五·周六较拥挤。人气酒吧在刚开门时最容易占到位子。
