① 韩国食物里隐藏的动物性食材

这一节的内容，是韩国观光公社英文官网的官方文章 "Tips for Vegetarians"(2026-11-26查阅)所写的。文章标注最后修改是2023年10月。

1. 高汤

韩国观光公社写道，韩国食物经常用肉和鱼熬的高汤烹制("Korean food is often prepared with meat and fish broth")。看起来只有蔬菜的食物，也可能放了高汤。

2. 泡菜

韩国观光公社写道，泡菜的调味料经常含有鱼虾酱、鱼露、肉高汤("kimchi seasoning most often contains salted seafood, fish sauce, meat broth")。

地方泡菜里也会放鲍鱼、带鱼、猪肉之类的食材("ingredients such as abalone, cutlass fish, and pork")。

泡菜 (Kimchi / 김치) 在韩国餐厅经常作为小菜端上来。即使看起来是蔬菜小菜，也可能含有上面的食材。

3. 拌饭

拌饭 (Bibimbap / 비빔밥) 是把蔬菜和米饭用辣椒酱或酱油拌着吃的食物。韩国观光公社写道，大部分拌饭菜单会把肉和鸡蛋作为配料放上去。建议点餐时说把这些食材去掉("Most bibimbap menus include meat and eggs as toppings so ask to exclude these ingredients when you order.")。

4. 煎饼

煎饼 (Jeon / 전) 是在食材上裹面糊，用油煎的食物。韩国观光公社写道，根据做法，面糊里也会加鸡蛋("some recipes may call for adding eggs in the batter.")。

5. 蔬菜紫菜包饭

韩国观光公社写道，蔬菜紫菜包饭 (Chaeso Gimbap / 채소 김밥) 里也可能放火腿、鸡蛋、蟹味棒("even vegetable gimbap may contain ham, eggs, and crab-flavored meat")。即使名字里带"蔬菜"，也要看里面的馅料。

6. 作为配料放的鸡蛋

韩国观光公社写道，有时会在食物上面放鸡蛋作为配料("eggs may be placed on top as a garnish.")。

点餐时说的话

要求去掉食材时，这样说。

  • "请不要放肉 (Gogi ppae juseyo / 고기 빼 주세요)。"
  • "请不要放鸡蛋 (Dalgyal ppae juseyo / 달걀 빼 주세요)。"

在屏幕上显示给店员看的请求卡和更多表达，在#1300里。

品目是食品安全国发布(2024-07-19)的19种，"法令标示"的文字，是《关于食品等标示·广告的法律施行规则》附表2的写法。

动物性食材是10种。 蛋类、牛奶、鲭鱼、蟹、虾、猪肉、鸡肉、牛肉、鱿鱼、贝类。

这个标示是为过敏准备的。 名单上只有19种。蜂蜜、鳀鱼、三文鱼不在这个名单里。所以，过敏标示里没有动物性文字，并不意味着那个食品里没有动物性食材。不要只凭过敏标示来判断。这是本篇的建议。

③ 首尔市素食餐厅现状的用法

首尔特别市在官网上放了《首尔市素食餐厅现状》。下面是2026-11-26亲自打开那个画面看到的值。

  • 网址: func.seoul.go.kr/user/vegetarian/restaurantList.do
  • 收录数: 画面上显示"共838条"。
  • 表的栏目: 序号、商号名、业种、联系方式、自治区、所在地、销售菜单(素食类型)。
  • 语言: 画面是韩语。

3种查找方法

  1. 选择自治区。 从首尔的25个自治区中选一个。选住宿所在的自治区，就会出现附近的店。
  2. 选择业种。 业种的选项有11个。咖啡厅、印度/中东、酒吧、韩餐、烘焙店、东南亚、中餐、西餐、小吃、日餐、韩餐,西餐。
  3. 输入搜索词。 搜索词会在商号名、联系方式、所在地、销售菜单中查找。

画面上也有下载Excel的按钮。

菜单上标的素食类型

这个名单不是给餐厅，而是给菜单标素食类型。点每一行的"查看 (Bogi / 보기)"，就会出现菜单名和括号里的类型。

名单画面上没有类型的定义。2021-01-19首尔市文章(Media Hub)对类型作了如下解释。

韩文标示 读法 含义
纯素 (Bigeon / 비건) bigeon "不允许动物性食品以及源自动物的任何食品的阶段"
奶素 (Rakto / 락토) rakto "允许摄取乳制品的素食主义"
蛋素 (Obo / 오보) obo "不允许肉类、鱼、家禽、乳制品，但吃动物的蛋的素食主义"
鱼素 (Peseuko / 페스코) peseuko "不允许吃肉，但允许乳制品、蛋类、海鲜和鱼的素食主义"
普通餐 (Ilbansik / 일반식) ilbansik "平时作为非纯素菜单运营。可根据顾客的要求选择素食选项"
可做纯素 (Bigeon-ganeung / 비건가능) bigeon-ganeung 这篇文章里没有定义

也有一个菜单上贴了两个标签的，比如"鱼素 (Peseuko / 페스코)，可做纯素 (Bigeon-ganeung / 비건가능)"或"普通餐 (Ilbansik / 일반식)，可做纯素 (Bigeon-ganeung / 비건가능)"。不要把"可做纯素 (Bigeon-ganeung / 비건가능)"读成"纯素 (Bigeon / 비건)"。把它看作点餐时要说改成纯素的菜单。这是本篇的建议。

画面上的标注例子是"Ria Miracle汉堡 (Ria Mirakeul Beoga / 리아미라클버거)"和"Awesome汉堡 (Eosseom Beoga / 어썸버거)"，括号里标的是纯素 (Bigeon / 비건)。

靠这个名单不能知道的事

名单画面上没有只筛选素食专门餐厅的栏目。只是每个菜单标了素食类型。所以名单上收录的餐厅里，也可能有不是素食的菜单。不要看餐厅名，要看菜单名和括号里的类型。这是本篇的建议。

首尔市在2021年1月发表这个名单时，收录的是948家(首尔市Media Hub文章，2021-01-19)。

画面是韩语，所以打开浏览器的翻译功能来看。这是本篇的建议。

④ 寺院饮食和纯素不一样

官方定义

韩国佛教文化事业团运营的寺院饮食官网的官方介绍(2026-11-26查阅)写道: "寺院饮食禁止除乳制品以外的所有动物性食品和'五辛菜'。"

这句话里，乳制品不在禁止之列。不吃乳制品的人，吃寺院饮食 (Sachal eumsik / 사찰음식) 时也要询问食材。这是本篇的建议。

韩国观光公社的 "Tips for Vegetarians" 写道，寺院饮食是修行僧人的食物，所以完全不用肉("does not use any meat at all")。

五辛菜的五种

同一个官网把五辛菜解释为"带来辛辣味的五种蔬菜"。五种如下。

  • 葱 (Pa / 파)
  • 蒜 (Maneul / 마늘)
  • 韭菜 (Buchu / 부추)
  • 野蒜 (Dallae / 달래)
  • 兴渠 (Heunggeo / 흥거)

寺院饮食不用这五种。这个定义里写的五种是葱、蒜、韭菜、野蒜、兴渠。没有写洋葱。

⑤ 认证标志

韩国纯素认证院的3项标准

韩国纯素认证院官方官网的认证指南(2026-11-26查阅)把标准写成三项。

  1. "不得使用源自动物的原料。"
  2. "不得进行使用动物的实验。"
  3. "必须防止产品生产工序前、中、后的交叉污染。"

韩国观光公社的指南

韩国观光公社的 "Tips for Vegetarians" 写道，要找经过认证的纯素标志("look for a certified vegan logo")。

上面三项标准，是针对该机构认证的产品。这一篇不放标志图。过敏标示只涉及19种食材。

⑥ 在快餐和便利店

乐天利

  • 乐天Eats的菜单画面: 乐天Eats (Lotteeatz / 롯데잇츠) 菜单画面(2026-11-26查阅)上有 "Miracle汉堡 (Mirakeul Beoga / 미라클버거)" 和 "Double Miracle汉堡 (Deobeul Mirakeul Beoga / 더블 미라클버거)"，没有植物性标示。

  • 两个名字的关系: 首尔市名单上的名字和乐天Eats上的名字是不是同一个菜单，两个画面上都没有写。

赛百味

赛百味官方官网的三明治菜单(2026-11-26查阅)里，没有标为植物性或纯素的菜单。官网菜单画面(2026-11-26查阅)里有 "Veggie (Beji / 베지)"，说明是"用刚烤好的面包和新鲜的8种蔬菜享用的清爽一餐"。面包、酱料、奶酪的食材，这个画面上没有写。

CU

BGF零售的官方新闻稿(2023-01-25，2026-11-26查阅)写道: "CU于2019年在便利店中率先创立'素食主义'品牌，从便当到意大利面，持续推出了40多种素食简便食品。"

这份新闻稿公布的商品是 "素食中华套餐便当 (Chaesik Junghwa Jeongsik Dosirak / 채식 중화 정식 도시락)"、"满满罗勒素食三明治 (Chaesik Bajil Gadeuk Saendeuwichi / 채식 바질 가득 샌드위치)"、"素食蛋味蛋黄酱豆腐皮寿司 (Chaesik Chaeran Mayo Yubuchobap / 채식 채란마요 유부초밥)"。新闻稿把 "Egg Mayo三明治和豆腐皮寿司 (Egeu Mayo Saendeuwichi wa Yubuchobap / 에그 마요 샌드위치와 유부초밥)" 写作"使用替代鸡蛋的100%植物性食品"。便当没有这句话。新闻稿里没有叙述是否使用牛奶和蜂蜜。

这一篇打开的CU素食新闻稿是2023-01-25的资料。是2023年1月的商品名，可能和现在门店的陈列不同。

在便利店买包装食品时，一起看②的过敏标示和⑤的认证标志。这是本篇的建议。

  • 饮食: 韩国观光公社的文章(2024-06-12)就这家餐厅的菜单写道 "these menus are made with only plant-based ingredients."(这些菜单只用植物性食材制作)。
  • 地址: 首尔龙山区 (Bogwang-ro 109 / 보광로 109)(Kakao Map登记值，2026-11-26)。
  • 营业时间: Kakao Map登记值(2026-11-26)是每天11:30~22:00。韩国观光公社的文章在11:30~22:00之外，还写了15:00~17:00休息。要避开15:00~17:00去。这是本篇的建议。
  • 走法: 从6号线梨泰院站 (Itaewon Station / 이태원역) 4号出口步行4分钟，267m(按Kakao Map路线，2026-11-26)。

韩国寺院饮食文化体验馆

  • 做什么: 参加寺院饮食烹饪课 "Temple Food Cooking Class"。
  • 饮食: 寺院饮食禁止除乳制品以外的动物性食品和五辛菜(④的官方定义)。
  • 地址: 首尔钟路区 (Yulgok-ro 39 / 율곡로 39) 安国大厦新馆 (Anguk Building Annex / 안국빌딩 신관) 2层(寺院饮食官网英文画面)。
  • 开放时间: 周二~周日09:00~18:00。周一和公休日休息。
  • 走法: 从3号线安国站 1号出口步行2分钟(按Kakao Map路线，2026-11-26)。

⑧ 机上餐食 — 大韩航空

这是大韩航空官方官网的特殊餐食指南(2026-11-26查阅)里的值。

  • 素食机上餐: 大韩航空写道，为素食乘客提供多种定制素食餐("We offer a variety of customized vegetarian meals for our vegetarian passengers.")。
  • 申请截止: 出发24小时前之前申请("please request a special meal at least 24 hours before departure.")。
  • 代码共享航班: 出发48小时前之前申请("For codeshare flights, requests must be made at least 48 hours before departure.")。
  • 限制: 大韩航空写道，短途航线上一部分特殊餐食可能受限，从海外出发的航班，根据当地情况，菜单可能受限或被替代。

代码共享航班的标准，大韩航空官网没有解释。预订确认书上的承运航空公司不是大韩航空的话，就以48小时前为标准。这是本篇的建议。

⚠ 常见失误6点

  1. 以为泡菜只是蔬菜小菜。 泡菜的调味料经常含有鱼虾酱、鱼露、肉高汤。地方泡菜里也会放鲍鱼、带鱼、猪肉。
  2. 只看"蔬菜紫菜包饭"这个名字就买。 蔬菜紫菜包饭里也可能放火腿、鸡蛋、蟹味棒。
  3. 原样点拌饭。 大部分拌饭菜单会把肉和鸡蛋作为配料放上去。点餐时说"请不要放肉 (Gogi ppae juseyo / 고기 빼 주세요)。"、"请不要放鸡蛋 (Dalgyal ppae juseyo / 달걀 빼 주세요)。"
  4. 以为过敏标示里没有动物性文字就是纯素。 标示对象只有19种。蜂蜜、鳀鱼、三文鱼不在这个名单里。
  5. 以为寺院饮食和纯素一样。 在寺院饮食的官方定义里，乳制品不在禁止之列。
  6. 以为首尔市名单上收录的餐厅是素食专门餐厅。 名单上没有只筛选素食专门餐厅的栏目。要看每个菜单上标的素食类型。

⚙ 5个常见问题

  1. 在韩国点蔬菜食物，就没有动物性食材吗? — 不是。韩国观光公社写道，韩国食物经常用肉和鱼熬的高汤烹制。煎饼的面糊里有时加鸡蛋。有时也会在食物上面放鸡蛋作为配料。
  2. 包装食品要看什么? — 在过敏原标示里，看蛋类 (Nallyu / 난류)、牛奶 (Uyu / 우유)、鲭鱼 (Godeungeo / 고등어)、蟹 (Ge / 게)、虾 (Saeu / 새우)、猪肉 (Dwaejigogi / 돼지고기)、鸡肉 (Dakgogi / 닭고기)、牛肉 (Soegogi / 쇠고기)、鱿鱼 (Ojingeo / 오징어)、贝类 (Jogaeryu / 조개류) 这10种。这个标示只涉及19种食材。也要看有没有经过认证的纯素标志。
  3. 在首尔怎么找有素食菜单的餐厅? — 在首尔市素食餐厅现状(func.seoul.go.kr/user/vegetarian/restaurantList.do)里，按自治区、业种、搜索词来选。2026-11-26的画面上共收录838条。点每一行的"查看 (Bogi / 보기)"，就会出现菜单名和括号里的类型。类型有纯素 (Bigeon / 비건)、奶素 (Rakto / 락토)、蛋素 (Obo / 오보)、鱼素 (Peseuko / 페스코)、普通餐 (Ilbansik / 일반식)、可做纯素 (Bigeon-ganeung / 비건가능)。"可做纯素 (Bigeon-ganeung / 비건가능)"和"纯素 (Bigeon / 비건)"不同。画面是韩语。
  4. 寺院饮食是纯素吗? — 不一样。韩国佛教文化事业团的寺院饮食官网写道，"禁止除乳制品以外的所有动物性食品和'五辛菜'"。乳制品不是禁止对象。作为五辛菜的葱、蒜、韭菜、野蒜、兴渠是不用的。
  5. 大韩航空的素食机上餐要在什么时候之前申请? — 出发24小时前之前。代码共享航班是出发48小时前之前。
