🎯 왜 "Seoul 24h Map" 통합 메타인가

방한 외국인 풀체험의 압도적 차별점 = 서울은 24시간 깨어있는 도시 (#176 walkable_seoul 5 reasons 중 "24/7 Safety"). 그러나 외국인 관광객은 통상 09~22시 동선만 인식 → 새벽 02~06시 + 심야 24~02시 풀체험 미활용 패턴. K-drama·먹방 영상에서 본 야간·새벽 풍경의 실제 매니아 풀체험 가이드 부재.

⚠ 외국인 24h 실수 3가지

1. "한국=야간 위험" — 22시 이후 호텔 칩거 패턴: 글로벌 도시 안전 인식이 서울에 그대로 적용. 실제로는 OECD 최저 범죄율 + CCTV 100만대 + 24h 편의점·인적 풍부. 명동·홍대·이태원·강남·종로 일대는 24h 인적·상권 활성. 22시 이후 명동·종로 산책 권장.

2. "새벽 02~06시 = 잠자는 시간" — 노량진·동대문 새벽 미인지: 외국인 통상 09~22시 동선만 인식 → 새벽 풀체험 미활용. 실제로는 노량진 수산 새벽 경매(02~06) + 동대문 의류 도매·거리음식(22~04) + 24h 편의점·찜질방이 24h 풀체험 시그니처. 일본·홍콩·대만 매니아 1순위.

3. "심야 21~02시 = 술집·클럽만" — 야장·노가리골목 미인지: 외국인이 야간을 클럽 동선으로만 인식. 실제로는 을지로 노가리골목(노가리 + 생맥주 야장)·종로3가 포장마차 거리(전·국수 + 막걸리)·홍대 노상 테이블이 K-drama 풍경 매니아 시그니처. 술집/클럽 ≠ 야장 문화.

Seoul 24h Map 풍경

서울은 글로벌 도시 안전·24h 인프라 #1. OECD 도시안전지수·Numbeo Safety Index 글로벌 Top 5권 + CCTV 100만대 + 24h 편의점 그리드 + 심야버스(N버스, 자정~05시) + 24h 찜질방·헬스장 + 24h 식당·카페·약국 일부 + 24h 인천공항 환승.

새벽 02~06시 = 노량진 수산시장 경매(매일 02~04시 한국 #1 수산 도매·새벽 회) + 동대문 의류 도매(22~04시 두타·밀리오레·헬로APM) + 24h 편의점(전역 5분 이내) + 일부 24h 식당(국밥·해장국·찜질방 식당) + 24h 찜질방(드래곤힐스파·한솔 등).

아침 06~10시 = 광장시장 빈대떡·해장국(06~10 한국 매니아 아침) + 북촌 한복 + 카페 어니언(07~10 일본·대만 매니아 일찍) + 명동 이삭토스트(08~10 일본 매니아).

오전 10~12시 = 경복궁 수문장 교대 10시 + 창덕궁 후원 영문 가이드 11·13시 + 시장 점심 준비.

점심 11~14시 = 광장시장 마약김밥·통인 도시락 카페·시장 풀체험 + 한정식·BBQ.

오후 14~17시 = 삼청동 한옥 카페·서촌 통인시장·카페 hopping·박물관·미술관·갤러리 + 14~17시 한적.

저녁 18~21시 = 명동 BBQ·한강 치맥(여의도·뚝섬·반포)·N서울타워 야경·경복궁·창덕궁 야간 개방(주말 한정).

밤 19~24시 = 종로3가 포장마차 거리·홍대 노상 테이블·N서울타워 야경·롯데월드타워 SkyDeck·잠실 야간·한강 야경 자전거.

심야 21~02시 = 을지로 노가리골목(노가리·생맥주 야장 1980s) + 24h 편의점·찜질방 + 일부 24h 식당 + 24h 인천공항 환승.
