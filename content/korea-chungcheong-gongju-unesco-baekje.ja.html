公州 — 百済・熊津の王城と王陵、ユネスコ遺産を1日で歩く方法（2026年10月 公式基準）

サブタイトル: 公山城・武寧王陵と王陵園（ユネスコ2015）・国立公州博物館（無料）・麻谷寺（ユネスコ2018、無料）・石荘里・韓屋村 — 料金・時間・休館日・バス番号は公州市観光・博物館の公式基準 · 百済文化祭2026（10/3～11、公州・扶余で同時開催） · KTX公州駅 ↔ 龍山 約1.5時間

ISSUE 04 · #1043 · 2026-06-08

🎯 なぜ公州に行くのか

公州 (Gongju / 공주) は、百済が漢江を失って南へ下り、64年間（475～538年）都とした熊津 (Ungjin / 웅진) です。その王城が錦江 (Geumgang / 금강) 沿いの丘にある公山城 (Gongsanseong / 공산성)、その王が眠る場所が武寧王陵 (Muryeong-wangneung / 무령왕릉) です。この2か所を扶余・益山の遺跡と合わせて、2015年にユネスコ世界遺産「百済歴史地区」となり、山あいの麻谷寺 (Magoksa / 마곡사) は2018年に「山寺・韓国の山地僧院」として別に登録されました。ソウルからKTXで公州駅まで約1時間30分なので日帰りができ、秋は栗と百済文化祭 (Baekje Munhwaje / 백제문화제) が重なります。以下の料金・時間は、2026-10-07時点の公州市観光・国立公州博物館・百済文化祭の公式ページに基づきます。

① 公山城 — 熊津百済の王城

  • 錦江に沿って巡る城壁の道（2.6km前後 — 現地の案内板に従って歩く）が見どころです。錦西楼 (Geumseoru / 금서루)（西門）から上がり、拱北楼 (Gongbungnu / 공북루) 側の川沿いの区間が最も開けています。
  • 百済文化祭の期間（10/3～11）は城の内外がイベント会場になるため、普段と動線が変わります。平日の午前が静かです。
  • 共通券（6,000ウォン）を買えば、同じ日に武寧王陵と王陵園まで見られます。

② 武寧王陵と王陵園 + 国立公州博物館 — セットで

  • 王陵園は古墳7基が集まる丘です。武寧王陵は1971年に排水路工事中に発見され、盗掘を受けずに出てきた唯一の百済王陵で、墓誌石のおかげで被葬者がわかる墓です（公式案内）。現地の展示館で墓の構造を見ます。
  • 出土品（棺の装飾・金製冠飾など）は道の向かいの国立公州博物館 (Gungnip Gongju Bakmulgwan / 국립공주박물관) 熊津百済室にあります。無料で、月曜は休みなので、王陵園 → 博物館の順で、平日の火～日曜に行きます。

③ 麻谷寺 — 2018年ユネスコの山寺

  • 入場料なしで通年開いています。小川をはさんで南院・北院に分かれた伽藍配置が特徴で、テンプルステイも運営しています（予約はお寺のホームページ）。
  • 770番バスは公州総合バスターミナルから約40分、1日14便なので、先に時刻表を確認します。タクシーなら時間を節約できます。

④ 石荘里博物館 — 旧石器

  • 錦江沿いの石荘里遺跡は、韓国で旧石器の発掘が初めて行われた場所です。博物館は公山城と同じ時間に開き、1/1・旧正月・秋夕に休みます。KTX公州駅 (Gongju-yeok / 공주역) の利用者は無料（公式）。

⑤ 公州韓屋村 — 泊まるなら

  • 韓屋の宿泊団地で、伝統文化の体験プログラムが付いています。チェックインは15:00。2027年9月から宿泊予約を停止すると公州市が予告しているので、それ以降の日程なら別の宿を探します。

⑥ グルメ — 公州の栗

  • 公州は栗の産地です。韓国観光公社の案内に載っているのは、栗村 (Bammaeul / 밤마을)（栗パイ・栗エクレア）、ルチアの庭 (Lucia-ui Tteul / 루치아의뜰)、ミマジ (Mimaji / 미마지)、清信牧場 (Cheongsin Mokjang / 청신목장)。冬には冬の公州 焼き栗祭り（2026年2月4～8日開催）があります。収穫時期は現地で確認してください。

🎪 百済文化祭2026 — 10月3日（土）～11日（日）、公州・扶余で同時開催

  • 第72回。公州（錦江新館公園・公山城・王都心一帯）と扶余 (Buyeo / 부여)（定林寺跡・官北里遺跡一帯）で同じ期間に開催されます（公式）。この記事を読む時点が10月7日以降なら、すでに開催中か終わっています — 公式サイトで当日のプログラムを確認してください。
  • 祭りの期間は公山城周辺が混雑・規制されます。遺跡だけ見るなら、祭りの前後が楽です。

⚠ よくある間違い5つ

1. 「公山城は泗沘の都」 — 泗沘は扶余です。公州は熊津（475～538年）。

2. 月曜に博物館へ行く — 国立公州博物館は月曜休館。王陵園・公山城は1/1・旧正月・秋夕だけ休みです（公山城の休日は現地で確認）。

3. 共通券を知らずに別々に買う — 公山城 + 王陵園の共通券は6,000ウォン。

4. 麻谷寺へバスの時間を見ずに行く — 770番は1日14便。

5. 祭りの期間に遺跡だけ見に行く — 10/3～11は公山城一帯がイベント会場。静かに見るならその前後に。

⚙ FAQ 6

1. ソウルから日帰りできる？ — KTX公州駅まで約1.5時間。公山城 + 王陵園 + 博物館で半日。

2. 入場料は？ — 公山城・王陵園は各3,000ウォン、共通券6,000ウォン。博物館・麻谷寺は無料。

3. 武寧王陵の中に入れる？ — 現地の展示館で構造を見て、出土品は国立公州博物館で見ます。

4. 百済文化祭はいつ？ — 2026年10月3～11日、公州・扶余で同時開催。

5. 韓屋に泊まるには？ — 公州韓屋村（チェックイン15:00、☎ 041-881-2828）。2027年9月から予約停止を予告。

6. 扶余まで一緒に回るには？ — 1泊で。扶余編（#1044）へ。
