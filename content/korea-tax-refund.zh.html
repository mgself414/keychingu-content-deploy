🎯 为什么要看"退税"指南

韩国退税 (Tax Refund) = 外国人购物时缴的增值税(VAT 10%)退还制度。外国人最大误解 = "自动全退"。实际要懂即时退税/事后退税区分·最低金额·护照·海关确认·自助机流程才不吃亏。痛点 = (a) 即时退税与机场事后退税区别 (b) 最低购买金额·适用店铺 (c) 海关盖章·物品确认 (d) 退税方式(现金/卡/App)。Reddit·YouTube上"Korea tax refund / VAT refund airport"反复搜索。

本指南涵盖 退税12要素 + 即时vs事后 + 最低金额·海关 + 机场自助机 + 退税率矩阵。

💳 退税6大要素 Deep Dive

① 事后免税 (Tax Refund / 사후면세) 概念

  • 招牌: 购买时含增值税结算 → 出境时退还·领退税单
  • 外国人友好度: ★★★★☆ (正规·退税率·需流程)
  • 贴士: 退税店·出示护照·保管单据·机场/市内退税

② 即时退税 (Immediate / 즉시환급)

  • 招牌: 店内直接扣增值税·小额限额(单次·总额限制)
  • 外国人友好度: ★★★★★ (便捷·即时·小额)
  • 贴士: 单件·总额限额(如单次不足100万韩元等)·护照·便捷

③ 最低金额·适用店 (Eligibility)

  • 招牌: 每店₩15,000以上·退税标识店
  • 外国人友好度: ★★★★☆ (条件·确认店铺)
  • 贴士: 百货·Olive Young·免税标识·部分个体户除外

④ 海关确认 (Customs / 세관)

  • 招牌: 机场海关盖章/扫描·物品确认·电子扫描自助机
  • 外国人友好度: ★★★☆☆ (流程·留时间)
  • 贴士: 未开封·随身带物·电子海关自助机·留时间(出境前)

⑤ 退税自助机·柜台 (Kiosk / 키오스크)

  • 招牌: 机场自助退税机·退税柜台·现金/卡
  • 外国人友好度: ★★★★☆ (自动·多语言)
  • 贴士: 仁川机场3层·扫单据·现金/卡·留排队时间

⑥ 市内退税 (Downtown / 시내환급)

  • 招牌: 明洞·市内柜台·先退(卡担保)
  • 外国人友好度: ★★★★☆ (提前退·便利)
  • 贴士: 明洞等·卡担保·出境须海关确认(未确认则扣卡)

✈️ 退税流程 (外国人实战)

  • 购买时: 退税店·出示护照·确认₩15,000+·领退税单(事后)或即时退税
  • 机场: 海关确认(盖章/电子扫描) → 退税自助机/柜台 → 现金/卡退税
  • 留时间: 出境前2~3小时·海关+退税排队·随身带物(托运前确认)
  • 注意: 市内先退出境海关未确认则扣卡·保持未开封
  • 急救: ☎ 1330(旅游)·125(海关)

⚠ 外国人5大常见失误

1. "自动全退": 退税需护照·海关确认·自助机流程。

2. "任何店都行": 仅退税标识·₩15,000+店·部分个体户除外。

3. "机场直接全办": 先海关确认·随身带物·留时间。

4. "市内退就完事": 市内先退也出境海关未确认则扣卡。

5. "托运后退税": 可能查验物品·托运前办海关。

⚙ FAQ 6个

1. 多少起?: 每店₩15,000以上·退税店。

2. 退多少?: VAT 10% - 手续费 = 约7-8%。

3. 即时退税是啥?: 店内直接扣增值税·小额限额。

4. 机场流程?: 海关确认(盖章/扫描) → 自助机/柜台 → 现金/卡。

5. 市内退税?: 明洞等先退·须出境海关确认(未确认扣卡)。

6. 推荐人群: 小额 = 即时退税 / 高额 = 机场事后 / 购物族 = 市内+机场。

⚠ 医疗·安全·消费 disclaimer

保管退税单·护照。市内先退须出境海关确认(漏则扣卡)。保持未开封。托运前办海关。确认运营商·手续费。防欺诈退税诱导。急救 ☎ 1330·125(海关)·112。
