🎯 왜 야간 한옥 카페·다도 가이드인가

야간 한옥 카페·다도 = 외국인 매니아 + 시그너 fusion 매트릭스 #1. 외국인 관광객 페인포인트 = (a) "북촌·익선 = 낮만 가는 곳" 잘못된 인식 — 야간 한옥 = 등불·고요·다도 매니아 매트릭스 #1 (b) "한국 카페 = 모던만" — 한옥 카페·찻집 = 전통차·다도 외국인 매니아 (c) 한옥 야간 = 등불·마당·고요 = 외국인 photogenic + 명상 매니아 (d) 다도(茶道) = 한국 전통차 의식 = 외국인 매니아 wellness 매트릭스 (e) 야간 한옥 + 야장(#1071)·야경(#1072)·야간 바(#1073)·낮술 와인바(#1075) cross.

본 가이드는 외국인 시각 야간 한옥 카페·다도 6선 + 시간대 + 다도 etiquette + 동선 매트릭스.

★ 한눈에 야간 한옥 카페·다도 6선 매트릭스

# 한옥 카페·찻집 시그니처 동네 외국인 매니아 포인트 운영시간
1 북촌 한옥 마당 찻집 ★ 마당+안채+사랑채+별채 좌식·바테이블·툇마루 + 전통차 도구 종로 북촌 (안국역) 마당 야간 등불 + photogenic + 다도 체험 11~22시 (매장별 다름)
2 익선 한옥 카페 (야간 등불) 한옥 골목 + 등불 + 카페 종로 익선 (종로3가역) 익선 한옥 골목 야간 photogenic 매트릭스 #1 11~23시
3 인사동 한옥 다도 찻집 전통차 + 다도 + 한복 체험 가능 종로 인사동 (안국역) 한복 + 다도 체험 cross 10~22시
4 서촌 한옥 카페 (저녁 운영) 서촌 한옥 + 모던 fusion 종로 서촌 (경복궁역) 외국인 매니아 매트릭스 + 서촌 고요 10~22시
5 북촌 한옥 와인바 (야간 한옥+와인 fusion) 한옥 + 와인 + 야간 종로 북촌 (안국역) 외국인 매니아 한옥+wine fusion 17~24시
6 익선 한옥 칵테일 바 (야간 한옥+칵테일) 한옥 + 칵테일 + 야간 등불 종로 익선 (종로3가역) 외국인 매니아 한옥+cocktail fusion 18~01시

⚠ 외국인 자주 실수 3가지

1. "북촌·익선 = 낮만 가는 곳": 북촌·익선·인사·서촌 한옥 = 야간 등불·다도·한옥 카페 매트릭스 #1. 야간 한옥 = 외국인 매니아 photogenic + 명상 wellness 매트릭스. 18~22시 = 야간 한옥 best.

2. "다도 = 너무 formal": 한국 다도(茶道) = 외국인 매니아 wellness 매트릭스 #1 + 영어 설명 OK 多. 인사·북촌 다도 찻집 = 다도 etiquette guide (영어) + 한복 체험 cross. 외국인 매니아 entry-level fit.

3. "한옥 카페 = 신발 벗어야": 좌식 (다도·툇마루) = 신발 벗기. 바테이블·의자형 = 신발 OK. 매장 입구 신발장·신발 OK 표지 多. 외국인 매니아 = 좌식+의자형 양쪽 선택 가능.

⚙ FAQ 4개

1. 야간 한옥 best 시간대: 일몰 후 18~22시 best (등불·고요 매트릭스 #1). 다도 = 10~17시 best (다도 체험 매장 운영시간). 야간 한옥 와인바·칵테일 바 = 19~24시 best.

2. 예약 방법: 다도 체험 매장 = 네이버 예약 또는 인스타 DM 권장 (영어 OK). 한옥 카페·와인바·칵테일 바 = catchtable 또는 walk-in. 외국인 매니아 = 영어 인터페이스 OK.

3. 다도 etiquette (외국인 시각): (a) 다도 = 한국 전통차 의식 + 다도 도구 (탕관·차호·찻잔) 사용법 + 영어 설명 OK (b) 좌식 = 양반다리·다리 펴고 OK + 신발 벗기 (c) 첫 잔 = 다도 master 부어줌 → 외국인 매니아 받기 etiquette (d) 차 종류 = 녹차·우롱차·홍차·발효차·블렌딩차 매트릭스 + 영어 설명.

4. 외국인 야간 한옥 동선 추천: 북촌(저녁) → 한옥 마당 찻집 (18~20시) → 익선 한옥 골목 (20~21시 등불) → 익선 칵테일 바 (21~24시) → 야장 8선 cluster (#1071).
