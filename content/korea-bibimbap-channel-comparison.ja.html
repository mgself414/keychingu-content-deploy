🥬 4チャンネル deep dive

🥬 全州韓屋村 (Jeonju Hanok Village)

核価値: UNESCO 無形遺産本物 #1 + 5色 + 宮中正統。

  • おすすめ店：
  • 全州韓屋村ビビンバ老舗 — 本格#1
  • ソウル全州式ビビンバハウス（江南・弘大）
  • 価格 anchor: 12,000~25,000ウォン(全州) / 8,000~20,000ウォン(ソウル)
  • 外国人親和性: ★★★★★ (UNESCO)
  • UNESCO 無形遺産: 宮中料理 cluster (2023)

🍲 石釜ビビンバ (Dolsot Bibimbap)

核心価値: グローバル #1 + 暑さ + サクサクヌルジ。

  • おすすめ店舗: 限定食・MZ韓国料理店・チェーン(ハン釜など)
  • 価格 anchor: 10,000~22,000ウォン
  • 外国人親和性: ★★★★★ (グローバル#1)
  • 注意: 非常に熱さ・皿受けの使用・子供注意

＃＃＃🥄セルフビビンバ（Self Bibimbap）

コアバリュー: MZ DIY #1 + 材料フルセット + コスパ比。

  • おすすめ店：
  • MZセルフビビンバ店（弘大・江南・ソンス） - トレンド
  • セルフ韓国料理ビュッフェ - コスパ
  • 価格 anchor: 8,000~18,000ウォン (セルフ無限詰め替え)
  • 外国人親和性: ★★★★ (MZ #1)

🌳 山菜・査察料理 (Sanchae・Temple Cuisine)

コアバリュー: ベジタリアン・ハラール#1 + 春の山菜 + 寺院グルメ。

  • おすすめ店：
  • 陳関寺 — 査察料理本格#1
  • 曹渓寺・奉恩寺 — 査察食品cluster
  • 江原・全羅山菜ビビンバ屋 — 春本物
  • 価格 anchor: 山菜屋 10,000~25,000ウォン / 査察コース 25,000~80,000ウォン
  • 外国人親和性: ★★★★★ （ベジタリアン#1・グローバル）

＃＃⚠外国人の頻繁な誤り5つ

1. 「4チャンネル＝似ている」：本物・トレンド・ベジタリアンとは全く違う。 UNESCO=全州/グローバル=石釜/MZ=セルフ/ベジタリアン=山菜。

2. 「全州＝一般」：全州＝UNESCO無形遺産本格（5色・宮中）。

3. 「石釜=一般器」: 石釜=非常に熱い・サクサクの麓マニア#1。

4. "セルフ=苛性肥満": セルフ=MZトレンド#1・材料フルセット。

5. "山菜=高価だけ": 山菜屋= 10,000～25,000ウォン lunch コスパ OK・査察コースのみ高価。

⚙ よくある質問8件

1. 最初のビビンバチャンネル=どこ: 石釜(#1グローバル)→全州(UNESCO本物)。

2. インスタ・vlog: 全州韓屋村・石釜熱さ・セルフDIY。

3. MZ トレンド: セルフ (#1)。

4. ベジタリアン・ハラール: 山菜・お寺料理（#1） + セルフ（自由選択）。

5. 家族同伴: セルフ(#1) + 全州。

6. アレルギー・妊娠: [#879 disclaimer](#879)参照。

7. 決済・チップ: カードOK/チップX。

8. VATの払い戻し: 飲食の一般的な払い戻しX。

⚠医療・安全・食事ダイエット

ビビンバ4チャンネルすべて一般食品。妊婦・子ども＝OK（石釜焼け注意）。アレルギー（卵・シーフード・ニンニク・醤油グルテン）事前告知。石釜火傷注意。食中毒の疑いがある場合☎1339。本ガイドは一般情報、医療助言ではない。

食事制限 fallback:

  • ハラール・コーシャー：山菜 = #1 / セルフ = 自由選択 / 全州・石釜 = 牛肉を除く。
  • 菜食・ビーガン: 山菜 = #1 / セルフ = 自由選択。
  • グルテンフリー：醤油・コチュジャン＝グルテン（タマリ代替）。
