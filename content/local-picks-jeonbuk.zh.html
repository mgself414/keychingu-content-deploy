本地人推荐 ④ 全北 — 韩国观众在评论里点名的13家饭馆，答案不只在全州

副标题：韩屋村(#255)、KTX两天一夜(#1107)、韩屋村外的小巷(#1367)都没有涉及的一条线索——从韩国观众在YouTube评论区推荐的地方饭馆整理表中，只挑出全北13家，用Naver本地搜索核实了是否存在、地址和行业类别，不做评价。全州·完州7家→益山2家→群山4家，每座城市附车站/客运站交通方式和一条外国游客提示。益山和群山是KeyChinGu几乎没写过的城市。

ISSUE 06 · #1385 · 2026-09-18 · 本地人推荐 ④

🎯 为什么"评论区推荐"是标准

这个专栏的来源只有一个。一个韩国YouTube频道上传的"全国美食"视频下，观众在评论区写下了自己家乡的饭馆，其中按地区整理得最系统的一份评论汇总表，收录了217家。这是韩国人推荐给韩国人的名单，所以几乎没有外国评论，反而有不少上不了旅游榜单的乡镇小馆。专栏的标准和局限写在①篇(#1382)里。

KeyChinGu只做了一件事——用Naver本地搜索确认店名·地址·行业类别是否真实存在(2026-09-17)。全北15家里有13家得到确认，没能确认的2家(群山、全州各1家)被剔除。没有到店评价、排名、星级，营业时间和价格也没有——去的当天查Naver Place才是答案。

全北篇的特点是韩屋村 (Hanok Village / 한옥마을) 之外。KeyChinGu此前的全北篇大多集中在全州韩屋村和拌饭上(11篇里的大部分)，而观众写下的地方是全州德津区 (Deokjin-gu / 덕진구)、平和洞 (Pyeonghwa-dong / 평화동) 这类生活区，加上益山、群山。益山是湖南线、全罗线分岔的换乘站城市，群山则是有两家中餐厅并排上榜的城市。

① 全州·完州 — 7家，韩屋村之外的全州

外国游客在全州去的地方是韩屋村和南部市场 (Nambu Market / 남부시장) (#255·#642·#1107)。观众写下的七家在那之外——德津区，也就是全州站、全北大 (Jeonbuk National University / 전북대) 一带的生活区，完山区的平和洞、西部新市区，以及全州东北方向的完州郡。全州站和韩屋村之间有79路观光巴士相连。

  • 都巨里牛神汤 (Dugeori Usintang / 두거리우신탕) · 全州市德津区东部大路1106号 (1106 Dongbu-daero, Deokjin-gu, Jeonju-si / 전주시 덕진구 동부대로 1106) · 韩餐 · 炖菜·火锅 · 全州站所在的东部大路沿线——站点、步行时间以Naver地图为准

Naver的分类是炖菜·火锅。店在全州站进市区的必经之路上，很适合当作抵达当天的第一顿。

  • 马耳山血肠 (Maisan Pi Sundae / 마이산피순대) · 德津区杜干10街8号 (8 Dugan 10-gil, Deokjin-gu / 덕진구 두간10길 8) · 韩餐 · 血肠·血肠汤 · 德津区杜干洞——交通以Naver地图为准

血肠 (pi sundae / 피순대) 是加了大量猪血、颜色偏红的血肠，是全州常见的做法。血肠汤可以单点一人份。

  • 金岩面屋 (Geumam Myeonok / 금암면옥) · 德津区麒麟大路400-3号 (400-3 Girin-daero, Deokjin-gu / 덕진구 기린대로 400-3) · 韩餐 · 刀切面·饺子 · 金岩洞、全北大一带——以Naver地图为准

面屋 (myeonok / 면옥) 是面条·冷面馆的旧式称呼。Naver的分类是刀切面·饺子。

  • 白松会馆 (Baeksong Hoegwan / 백송회관) · 完山区麒麟大路177号 (177 Girin-daero, Wansan-gu / 완산구 기린대로 177) · 韩餐 · 拌饭 · 与韩屋村(麒麟大路99号)同一条路——步行时间以Naver地图为准

一家卖全州拌饭的店。五种拌饭的差异整理在#879。是名单里唯一能直接接进韩屋村行程的一家。

  • 世意都 (Seito / 세이토) · 完山区麻田中央路13号 (13 Majeon-jungang-ro, Wansan-gu / 완산구 마전중앙로 13) · 日餐 · 乌冬面·荞麦面 · 西部新市区——以Naver地图为准

开在全州新商圈西部新市区的乌冬面店。吃腻韩餐时的备选，才上了这份名单。

  • 土房 (Tobang / 토방) · 完山区平和18街19号 (19 Pyeonghwa 18-gil, Wansan-gu / 완산구 평화18길 19) · 餐厅 · 韩餐 · 平和洞住宅区——以Naver地图为准

完全脱离观光动线、开在居民区里的一家韩餐馆。打车去更现实。

  • 终南山庄 (Jongnam Sanjang / 종남산장) · 完州郡所养面松广水满路429号 (429 Songgwangsuman-ro, Soyang-myeon, Wanju-gun / 완주군 소양면 송광수만로 429) · 餐厅 · 韩餐 · 从全州坐市内公交或打车前往所养面方向——公交路线号以Naver地图为准(只确认了全州市内公交能开到所养面)

位于全州东北方完州郡所养面、通往松广寺 (Songgwangsa / 송광사) 路上的一家山庄式餐馆。店名里的终南山 (Jongnamsan / 종남산) 就是这一带的山。

外国游客提示 — 在全州，拌饭、血肠汤、刀切面可以点一人份，韩定食则以2人份起点为基本单位。全州站和韩屋村之间有79路公交，第一天带着行李的话可以坐这趟。

② 益山 — 2家，湖南线与全罗线分岔的车站城市

益山站是湖南高铁 (Honam KTX / 호남고속철도)、湖南线 (Honam Line / 호남선)、全罗线 (Jeolla Line / 전라선)、长项线 (Janghang Line / 장항선) 交汇的分岔站。从首尔下来，是走全罗线去全州，还是走湖南线去木浦·光州，在这里分岔。所以益山很容易被当成"路过的城市"，但名单里这两家都在同一条高峰路沿线上。

  • 别味家 (Byeolmijip / 별미집) · 益山市高峰路176-1号 (176-1 Gobong-ro, Iksan-si / 익산시 고봉로 176-1) · 餐厅 · 韩餐 · 从益山站坐公交或打车——站点以Naver地图为准
  • 满浦乌冬 (Manpo Udon / 만포우동) · 益山市高峰路34街44号 (44 Gobong-ro 34-gil, Iksan-si / 익산시 고봉로34길 44) · 日餐 · 乌冬面·荞麦面 · 同一条高峰路沿线——以Naver地图为准

一家韩餐馆和一家乌冬面店在同一个街区。如果转乘还剩一个小时，值不值得出站看看，先在Naver地图查一下步行时间。

外国游客提示 — 益山站是换乘枢纽，行李寄存很重要。用车站的储物柜，轻装出站更省心。全罗线、湖南线换乘方法整理在#1374(三种车票)里。

③ 群山 — 4家，客运站比车站更靠近市区

群山有一点容易让外国游客搞混。群山站2008年因长项线改线搬到了市郊内兴洞 (Naeheung-dong / 내흥동)，到市区要坐20~30分钟公交。而群山市外客运站在海望路18号，位于老城区京岩洞一侧。下面四家里有两家就在客运站那片区域。

  • 伽倻庄 (Gayajang / 가야장) · 群山市京岩4街4号 (4 Gyeongam 4-gil, Gunsan-si / 군산시 경암4길 4) · 中餐 · 中餐厅 · 京岩洞，市外客运站所在片区
  • 荣华园 (Yeonghwawon / 영화원) · 群山市旧营5街112号 (112 Guyeong 5-gil, Gunsan-si / 군산시 구영5길 112) · 中餐 · 中餐厅 · 老城区旧营街一带

群山以源自华侨商圈的深厚中餐传统闻名，名单里也有两家中餐厅并排上榜。炸酱面、什锦炒码面、糖醋肉都可以单点一人份。

  • 群山传说炭火排骨 (Gunsan Jeonseol Sutbul Galbi / 군산전설숯불갈비) · 群山市西水松安2街9号 (9 Seosusong-an 2-gil, Gunsan-si / 군산시 서수송안2길 9) · 韩餐 · 肉类料理 · 水松洞新城区——从群山站到新城区坐公交约15分钟
  • 名山大盆排骨 (Myeongsan Yangpun Wang Galbi / 명산양푼왕갈비) · 群山市巨石街5号 (5 Geoseok-gil, Gunsan-si / 군산시 거석길 5) · 韩餐 · 肉类料理 · 群山市区——以Naver地图为准

两家烤排骨店。炭火排骨、大盆排骨都以2人份起点为基本单位。

外国游客提示 — 群山的行程按客运站、老城区为基准来安排更方便，不要以车站为基准。近代文化街 (Modern History Street / 근대문화거리)、京岩洞铁路村 (Gyeongam-dong Railroad Village / 경암동 철길마을) 都在那片区域，群山两天一夜行程在#1108。

🚄 如何融入地方路线

  • 融入全州两天一夜行程(#1107) — 白松会馆和韩屋村在同一条麒麟大路上，全州其余六家分布在德津区、平和洞、西部新市区，要打一趟车。
  • 益山 = 换乘站 — 从首尔下来，全罗线(去全州)和湖南线(去光州、木浦)在这里分岔。如果行程正好路过，高峰路那两家是出站选项。
  • 群山(#1108) — 按市外客运站、老城区为基准。全州↔群山市外巴士一天7班，益山↔群山最密，一天8班。
  • 完州终南山庄 — 从全州市内往所养面方向。公交路线号没能确认，出行按打车为基本方案。
  • 继续往湖南以南走 — 从益山坐湖南线南下就是光州、木浦。那片区域在⑦篇(#1388)。

⚠ 3个常见误区

1. 从群山站走去老城区 — 车站在市郊，坐公交要20~30分钟。客运站一侧才是离市区近的一端。

2. 把全州六家硬塞进韩屋村徒步路线 — 除白松会馆外都在德津区、平和洞。打车是基本方案。

3. 认定完州终南山庄能坐公交就出发 — 只确认了全州市内公交能开到所养面。路线号、班次要当天确认。

⚙ 常见问题3则

1. 这份名单是谁挑的？ — 是一张由韩国YouTube观众在评论区写下的地方饭馆整理而成的表。KeyChinGu只确认了是否存在、地址和行业类别，没有排名。

2. 全州拌饭到底哪家对？ — 这一篇不排名。名单里的拌饭店只有白松会馆一家，各类拌饭的差异见#879、#881。

3. 只单独去益山或群山可以吗？ — 益山是换乘站，顺路看看就好；群山值得住一晚(#1108)。两地之间的市外巴士最密，一天8班。
