首尔以外的跑步路线9处 — 国民投票选出的竹林·湖泊·海边，距离和交通方式

副标题: 韩国观光公社"名胜发掘100×100"跑步路线主题国民投票中获得票数的首尔以外路线9处，按蔚山·大邱、庆州、釜山、济州4个片区整理。蔚山十里竹林约4km，24小时免费；济州思连伊林荫路约10km，17:00前必须出园。庆州普门湖各机构写的环湖长度不同，济州涯月步行道和车道名字相近。距离、开放时间、费用、公交车号码，只整理了机构公布的值。

ISSUE 06 · #1445 · 2026-11-24 · 서울 밖 러닝 코스

🎯 适合谁，为什么是这9处

这份清单是为旅行中想跑一天步的人准备的。离开首尔去蔚山、大邱、庆州、釜山、济州的行程里，想在早上或傍晚加一段跑步时可以用。里面有竹林路、环湖路、海边、林荫路、海岸散步路。

选择标准只有一个。从韩国观光公社 (Korea Tourism Organization / 한국관광공사)"名胜发掘100×100" (100×100 Spot Discovery / 명소발굴 100×100)跑步路线主题国民投票前14名里，选出首尔以外的湖泊·海岸·林荫路。第1·3·4·5·7·10·11·12·14名就是这一篇的9处。第2·6·9名是首尔汉江公园(汝矣岛·盘浦·纛岛)，所以这一篇没有收。第13名岭南阿尔卑斯天空紫芒路 (Yeongnam Alps Haneul Eoksae-gil / 영남알프스 하늘억새길)是山脊路，留给越野跑篇(#1428)。第8名金泉莲花池 (Yeonhwaji Pond / 연화지)(137票)在韩国观光公社的介绍里只有沿着水库散步很好、夜间亮灯的描述，所以没有作为正式路线收入。

这9处不是跑步专用跑道，而是和散步的人、游客共用的路。所以写了多少km、什么时候开门关门、怎么去。

⚠ 标注原则: 距离、使用时间、费用、交通方式，是2026-11-24在韩国观光公社、各市·区厅和地方旅游门户(蔚山市、庆州市、釜山市、水营区、Visit Busan、大邱市、Visit Jeju)、济州巴士信息系统 (Jeju Bus Information System / 제주 버스정보시스템)查阅到的值。公交车号码是查阅当天的途经线路。机构没有公布数值的项目没有写。没有写跑步需要的时间，只照抄了机构写的所需时间。从寿城池站步行的时间是Kakao Map路线值(2026-11-24)。得票和名次是韩国观光公社名胜发掘100×100跑步路线主题国民投票的值。运营时间和公交线路可能变动。

🚦 跑步之前 — 共同的安全和礼仪

九处都不是跑步专用的路。下面不是法律或设施规定，而是在多人共用的路上遵守的一般礼仪。

  • 在紧挨车道的海岸公路上，不要走下去到车道上。 道头彩虹海岸公路在Visit Jeju的使用评价里也有道路不宽、要小心车辆的话。窄的路段不要跑，要走着留意车辆。
  • 人多的路上放慢速度。 广安里、冬柏岛、瞻星台周边、汉潭海岸散步路都在景点正中间。窄的路段要走。
  • 设施定的规则照样遵守。 普门湖散步路上自行车和ATV不能通行。思连伊林荫路不能带食物入内，只可以带水。汉潭海岸散步路以现场管制和提示为先。
  • 天气不好就放弃。 思连伊林荫路遇到暴雨·暴雪等恶劣天气，会管制部分或全部路段。龙头岩 (Yongduam Rock / 용두암)在浪大的日子只在指定的观览路线和安全设施里观看。
  • 发生事故或紧急情况，打119。

① 蔚山·大邱 — 2处

蔚山和大邱是不同的城市。比起一次串联，更适合分别附在各城市的行程里。两处都没有开放时间限制。

蔚山太和江十里竹林路 (Taehwagang Simnidaesup Bamboo Forest / 태화강 십리대숲길)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票229票·第1名。
  • 距离: 蔚山市太和江国家庭园 (Taehwagang National Garden / 태화강 국가정원)介绍里，写十里竹林约4km。总面积109,866㎡，约50万棵竹子生长，介绍说林里有环保散步路。
  • 使用时间·费用: 不收门票。没有入场限制，24小时都可以进出。服务中心9~18时开放。
  • 夜间: 夜间亮灯路段银河水路 (Eunhasu-gil / 은하수길)从日落到23时亮灯。天黑以后跑步的话，要配合这个时间。
  • 交通方式: 乘公交车在"太和江国家庭园 / 东江医院"站 (Taehwagang Gukgajeongwon / Donggang Byeongwon / 태화강 국가정원 / 동강병원)下车。地址是蔚山中区 (Saetgangnam-gil 5 Taehwa-dong / 샛강남길 5 태화동)。
  • 太和江站 (Taehwagang Station / 태화강역)出发: 523·713·763·1115·1733·9001路
  • KTX蔚山站 (KTX Ulsan Station / KTX울산역)出发: 523·1733·5001·5003·5004路
  • 市外·高速巴士客运站 (Intercity and Express Bus Terminal / 시외·고속버스터미널)出发: 417·523·713·723·763·1115·1733·9001路
  • 停车: 有14个停车场。收费的是附设1(215位)·2(447位)·3(123位)，免费的是太和江瞭望台 (Taehwagang Observatory / 태화강전망대)(28位)·洞窟乐园 (Donggulpia / 동굴피아)(55位)·三湖沿岸公营 (Samho Yeonan Public / 삼호연안 공영)(175位)。
  • 咨询: 太和江国家庭园服务中心 052-229-3147。

大邱寿城池 (Suseongmot Lake / 수성못)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票134票·第11名。
  • 距离: 大邱市旅游页面和韩国观光公社的旅行文章，都写环湖约2km。韩国观光公社文章写步行一圈40多分钟。跑五圈约10km。
  • 路段和路面: 韩国观光公社文章(2020年10月撰写)把湖周围介绍成四个路段。东边是180m的水边木栈道，南边是鸭子船码头和王樱花散步路(可以赤脚走的路)，西边是铺着粗沙的真沙土散步路，北边是水上舞台一侧。没有固定的起点。
  • 使用时间·费用: 大邱市旅游页面写使用时间"无限制"、使用费用"免费"。韩国观光公社文章也写环湖路24小时·全年无休·免费。
  • 夜间: 大邱市旅游页面介绍夜里水面上映出的灯光闪烁。韩国观光公社文章写王柳树和水边木栈道有灯光亮起。
  • 交通方式: 按Kakao Map路线，从城市铁路3号线寿城池站 (Suseongmot Station / 수성못역)1号出口步行16分钟(约950m)。地址是大邱广域市水城区 (Yonghak-ro 35-5 / 용학로 35-5)。
  • 设施: 大邱市旅游页面写"有免费公营停车场"。有卫生间，也有换尿布台。咨询 053-761-0645。

② 庆州 — 2处

两处都乘10路公交车(反方向是11路)这一条线路就能到。庆州市旅游页面写这趟公交车从庆州高速/市外巴士客运站 (Gyeongju Express/Intercity Bus Terminal / 경주 고속/시외버스터미널)出发，依次经过"庆州站" (Gyeongju Station / 경주역)站、瞻星台、芬皇寺 (Bunhwangsa Temple / 분황사)、普门观光园区 (Bomun Tourist Complex / 보문관광단지)、佛国寺 (Bulguksa Temple / 불국사)。首班车06:00，末班车21:40，发车间隔20分钟。末班车是21:40，比瞻星台和东宫与月池关门的22:00更早结束。可以早上绕普门湖，傍晚去瞻星台一带，在一天里串起来。

庆州普门湖 (Bomun Lake / 보문호)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票152票·第3名。
  • 距离: 各机构的数值不同。韩国观光公社写约8km，庆州市写约6km。 两处都写走完约需2小时。想精确地按距离跑，要用手表或应用自己测量。
  • 规则: 散步路上自行车和ATV不能通行。 韩国观光公社和庆州市写了同样的内容。
  • 交通方式: 在庆州高速/市外巴士客运站乘10路公交车。普门一侧的站依次是"普门园区·庆尚北道文化观光公社"站 (Bomundanji·Gyeongsangbuk-do Munhwagwangwang Gongsa / 보문단지·경상북도문화관광공사)、"希尔顿·The-K酒店"站 (Hilton·The-K Hotel / 힐튼·더케이호텔)、"KT研修院"站 (KT Suryeonwon / KT수련원)、"庆州World"站 (Gyeongju World / 경주월드)。庆州市公交车说明里没有出现名叫"普门湖"的站，所以用"普门园区"来找。10-1路不到佛国寺，在庆州World掉头回来。
  • 休息的地方: 庆州市介绍写，水浪公园 (Mulneoul Park / 물너울공원)和爱情公园 (Sarang Park / 사랑공원)有小休息处，路边有朴木月诗碑 (Park Mok-wol / 박목월)。

庆州瞻星台一带 (Cheomseongdae Observatory area / 첨성대 일대)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票139票·第7名。
  • 路段: 投票中列出的路段是连接隍城公园 (Hwangseong Park / 황성공원)、北川 (Bukcheon / 북천)、芬皇寺、东宫与月池 (Donggung Palace and Wolji Pond / 동궁과 월지)、瞻星台 (Cheomseongdae Observatory / 첨성대)的路。没有机构公布连接这五处的路的距离，所以没有写距离。这是在遗址之间连着跑的路，路线距离由跑步的人自己决定。
  • 隍城公园: 韩国观光公社介绍，松林散步路上夏天会开麦冬群落。
  • 瞻星台: 按庆州市旅游页面，09:00~22:00开放。冬季到21:00。全年无休，免费。夜间景观灯光从日落后亮到22:00。
  • 旁边的看点 — 东宫与月池: 09:00~22:00开放，21:30停止售票。门票成人3,000韩元，青少年2,000韩元，儿童1,000韩元。夜间景观灯光从日落后到22:00。
  • 交通方式: 在庆州高速/市外巴士客运站乘10路公交车(反方向11路)。站点列表里依次有"月城洞事务所"站 (Wolseong-dong Office / 월성동사무소)、"瞻星台"站、"大陵苑"站 (Daereungwon Tomb Complex / 대릉원)。同一条线路也经过芬皇寺、东宫与月池、国立庆州博物馆 (Gyeongju National Museum / 국립경주박물관)。

③ 釜山 — 2处

广安里和冬柏岛都乘城市铁路2号线去。广安里是金莲山站·广安站，冬柏岛是冬柏站。广安里是沙滩长度1.4km的海边，冬柏岛是短的海岸环形散步路。

釜山广安里海水浴场 (Gwangalli Beach / 광안리해수욕장)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票148票·第4名。
  • 距离: 釜山市写海水浴场"总面积82,000㎡，沙滩长度1.4㎞，沙滩宽度25~110m"。从一头到另一头往返是2.8km，往返两次是5.6km。
  • 使用时间·费用: Visit Busan写全天开放、全年无休、免费。介绍说在海边主题街可以散步和骑自行车，夏季有演出。
  • 交通方式: 各机构的出口说明不同。
  • 水营区说明: 城市铁路2号线金莲山站3号出口步行5分钟，广安站3号出口步行10分钟。
  • Visit Busan说明: 2号线广安站5号出口步行约13分钟。
  • 公交车: 水营区写乘41·49·38·42·51·62·83·83-1·108-1路，在"广安里海水浴场"站下车后走3分钟。Visit Busan写了42·62路。
  • 地址: 釜山水营区 (Gwangan Haebyeon-ro 219 / 광안해변로 219)一带(广安洞)。
  • 停车: Visit Busan介绍"附近公营停车场"。

釜山冬柏岛 (Dongbaekseom Island / 동백섬)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票136票·第10名。
  • 距离: Visit Busan写冬柏岛环岛海岸散步路"950m左右"。跑五次是4.75km。投票中列出的路段是从海云台海边连到冬柏岛环形路的路，没有机构公布包括海边路段在内的距离。
  • 坡度: 韩国观光公社无障碍说明写，散步路入口有坡度10度左右的路段，休息空间和观景台的坡道是5~9度。虽然短，但不是只有平地的路。
  • 使用时间·费用: 全天开放，全年无休，没有门票。
  • 交通方式: 从城市铁路2号线冬柏站1号出口出去。Visit Busan写从1号出口步行17分钟。公交车乘1003路，在"冬柏岛"站 (Dongbaekseom / 동백섬)下车。
  • 设施: 有卫生间。釜山市世峰楼说明写，冬柏公园别馆停车场收费，冬柏岛周边停车空间窄，周末和公共假日会停满，建议乘公共交通。
  • 旁边的看点 — 世峰楼APEC会议厅 (Nurimaru APEC House / 누리마루 APEC하우스): 09:00~18:00开放，关门前1小时停止入场。每月第一个周一休息。免费入场。电话是051-743-1974~5。

④ 济州 — 3处

思连伊林荫路是岛内侧的林荫路，汉潭和道头是海边的路。三处都有公交车站。公交车号码是在济州巴士信息系统里按站名查到的途经线路。

济州思连伊林荫路 (Saryeoni Forest Trail / 사려니숲길)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票143票·第5名。
  • 距离: Visit Jeju写约10km。从济州市峰盖洞榧子林路入口经水察岳 (Mulchat Oreum / 물찻오름)方向，到西归浦市表善面加时里红岳 (Bulgeun Oreum / 붉은오름)(南造路)入口。没有另外命名的细分路段。从一头到另一头再走回来约20km。
  • 路面: 红岳入口附近是红色火山渣路。绝物 (Jeolmul / 절물)矮竹路路段地面凹凸不平，有高低差。
  • 使用时间: 09:00~17:00，17:00前必须出园。 全年无休。暴雨·暴雪等恶劣天气会管制部分或全部路段。计划往返的话，要把返程的时间也算进去，早点出发。
  • 水察岳: 平时禁止进入。只能在入口附近折返。举办活动时预约，有时会临时开放。
  • 规则: 不能带食物入内。可以带水。塑料瓶丢在服务中心附近的回收箱。
  • 交通方式: Visit Jeju介绍在南造路"思连伊林荫路"站下车，写两个入口都能乘公共交通到达。济州巴士信息系统的站点和途经线路如下。
  • "南造路思连伊林荫路"站 (Namjo-ro Saryeoni-sup-gil / 남조로 사려니숲길): 131、132、231、232路
  • "思连伊林荫路"站 (Saryeoni-sup-gil / 사려니숲길): 212、232路(朝教来入口方向的站还标有222-1路)
  • 停车: 榧子林路入口周边没有停车场。Visit Jeju推荐南造路红岳入口附近的停车场。如果带着老人或婴儿车，介绍说从南造路入口进去。

济州汉潭海岸散步路 — 投票名称"涯月海岸路" (Handam Coastal Walk, Aewol / 한담해안산책로, 애월)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票134票·第12名。投票名称是"涯月海岸路"，路段是从郭支海水浴场 (Gwakji Beach / 곽지해수욕장)到涯月港。
  • 先分清名字: 有两条名字相近的路。
  • 汉潭海岸散步路 (Handam Coastal Walk / 한담해안산책로): 连接涯月港和郭支果物海边 (Gwakji Gwamul Beach / 곽지과물해변)约1.2km的步行路。也叫郭金奥莱路 (Gwakgeum Olle-gil / 곽금올레길)。投票上写的路段(郭支海水浴场~涯月港)的两端，和这条散步路的两端(郭支果物海边~涯月港)相同。
  • 涯月海岸公路 (Aewol Coastal Road / 애월해안도로): 从下贵到涯月约9km的海岸兜风公路，也就是车道。Visit Jeju介绍沿着公路修建了自行车道和步行路段，是济州环岛自行车路的一部分。
  • 距离: 汉潭海岸散步路约1.2km。往返是2.4km，往返两次是4.8km。
  • 路面: Visit Jeju写"整体修建得很平坦"。有提示说主入口的坡道很陡，轮椅使用者要小心。
  • 使用时间·费用: Visit Jeju使用说明是全天开放，全年无休。可以带宠物狗同行，牵引绳或胸背带要拉在2m以下。以现场管制和提示为先。
  • 夜间: Visit Jeju写天快黑的时候散步路周边亮灯。
  • 交通方式: 济州巴士信息系统的站点和途经线路。
  • "汉潭洞"站 (Handam-dong / 한담동): 202、202-1、202-2、202-4路
  • "郭支海水浴场"站 (Gwakji Haesuyokjang / 곽지해수욕장): 202、202-1、202-2、795路
  • "涯月换乘站"站 (Aewol Hwanseung Jeongnyujang, Aewol-ri / 애월환승정류장 애월리): 102、102-1、202、202-1、202-2、202-4路
  • 地址: 济州市涯月邑 (Gwakji-ri 1359 / 곽지리 1359)。

济州道头彩虹海岸公路 (Dodu Rainbow Coastal Road / 도두 무지개해안도로)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票131票·第14名。投票中列出的路段是从道头洞彩虹海岸公路经过鱼泳公园 (Eoyeong Park / 어영공원)到龙头岩。
  • 距离: Visit Jeju只写彩虹色防护墙路段步行约15~20分钟的距离。没有机构公布km数值，所以没有写距离。
  • 路的性质: 是车道旁的海岸公路。Visit Jeju的使用评价里有道路不宽、要小心车辆的话。不要走下去到车道上，窄的路段要走着留意车辆。
  • 交通方式: 按济州巴士信息系统，站名是"道头峰东侧" (Dodubong Dongjjok / 도두봉 동쪽)。Visit Jeju介绍在这个站下车就在眼前。
  • "道头峰东侧[南]"站: 445、447、454、1113路
  • "道头峰东侧[北]"站: 444、447、453、1111、1112路
  • 停车: 小轿车和巴士可以到达。大型巴士使用奥来水光广场 (Oraemulgwang Square / 오래물광장)对面的停车空间。
  • 宠物狗: 可以同行。牵引绳或胸背带要拉在2m以内，带好排泄物袋。
  • 旁边的看点 — 龙头岩 (Yongduam Rock / 용두암): Visit Jeju使用说明是全天开放，全年无休，观景免费。地址是济州市 (Yongduam-gil 15 / 용두암길 15)。浪大的日子在指定的观览路线和安全设施里观看。景点咨询 064-728-3917。

⚠ 3个常见失误

  1. 以为涯月海岸公路和汉潭海岸散步路是同一条路 — 在地图上搜"涯月海岸公路"，出来的是下贵~涯月约9km的兜风公路。连接郭支果物海边和涯月港的步行路是约1.2km的汉潭海岸散步路。公交车站也要用"汉潭洞"或"郭支海水浴场"来找。
  2. 下午很晚才进思连伊林荫路 — 17:00前必须出园。把约10km全部走一个来回是约20km。不能带食物入内，只带水。下大雨或下雪的日子可能被管制。
  3. 只相信一个距离数值来做计划 — 普门湖韩国观光公社写约8km，庆州市写约6km。瞻星台一带和道头彩虹海岸公路没有机构公布km数值。想跑够规定的距离，就在有数值的地方，像寿城池(约2km)、冬柏岛(约950m)、汉潭(约1.2km)、广安里(1.4km)那样，用圈数或往返次数来凑。

⚙ 3个常见问题

  1. 天黑以后也能跑的地方有哪些？ — 十里竹林24小时可以进出，银河水路的灯从日落亮到23时。寿城池没有使用时间限制。广安里、冬柏岛、汉潭海岸散步路全天开放。汉潭在傍晚时散步路周边亮灯。瞻星台开到22:00(冬季21:00)，日落后亮景观灯。思连伊林荫路17:00前必须出园，所以晚上不行。普门湖和道头彩虹海岸公路机构没有另外写使用时间，冬柏岛虽然全天开放，但没有灯光说明。这三处要在天亮时跑。
  2. 有要花钱的地方吗？ — 没有哪处写明跑的路本身收费。十里竹林、寿城池、广安里、瞻星台写的是免费，冬柏岛没有门票。旁边的看点里要付钱的是东宫与月池(成人3,000韩元，青少年2,000韩元，儿童1,000韩元)。世峰楼APEC会议厅入场和龙头岩观景是免费的。
  3. 没有租车也能去吗？ — 九处都能乘地铁站或公交车到达。釜山两处是城市铁路2号线，庆州两处是从客运站乘10路公交车这一条线路。蔚山十里竹林从太和江站·KTX蔚山站·客运站乘公交车去。济州三处用站名"南造路思连伊林荫路"·"思连伊林荫路"、"汉潭洞"·"郭支海水浴场"、"道头峰东侧"来找。大邱寿城池是从城市铁路3号线寿城池站1号出口步行16分钟(Kakao Map)。
