⚠ 외국인 자주 실수 5가지

1. "호텔 조식 = 투숙객만": 일부 호텔 조식 외부 이용 OK (시그니엘 STAY·신라 파크뷰·JW그리핀 60~80K). 사전 예약 필수.

2. "애프터눈티 = 영국식만": 한국 호텔 애프터눈티 = 한국 정통 한과·전통차 + 영국식 융합 (시그니엘 BAR 81·신라 더 라이브러리·포시즌스 마루) + 외국인 매니아 인스타 1번지.

3. "이그제큐티브 라운지 = 비쌈": 클럽 룸 (Club Floor) 1박 +50~100K → 조식·티타임·해피아워(주류 무제한)·체크인 별도 풀세트 = 가성비 매니아 1번지.

4. "호텔 조식 = 양식만": 한국 5성급 조식 = 양식 + 한식 + 일식 + 중식 + 인도식 + 비건 코너 풀세트 + 외국인 친화 다국적.

5. "가성비 = 별로": L7 홍대 (15K)·노보텔 동대문 (20K) 조식 = 외국인 매니아 가성비 1순위 + 한식·양식 다양.

① 럭셔리 조식 (6)

1. 시그니엘 서울 STAY 조식 ★ 555m 80F

  • 주소: 송파구 올림픽로 300 (#82 잠실 롯데타워 80F)
  • 외국인 ★: ◎◎ — 555m·세계 최고층 조식·외국인 #1
  • 가격: 투숙객 무료 / 외부 90K (예약)
  • 시그니처: 잠실·한강 panorama + 한·양·일·중·인도 풀세트

2. 신라호텔 더 파크뷰 ★ 한국 #1 조식 뷔페

  • 주소: 중구 동호로 249 (#13 남산)
  • 외국인 ★: ◎◎ — 1979 한국 정통 뷔페 1번지
  • 가격: 외부 95K·런치 110K·디너 140K
  • 시그니처: 한국 정통 + 사파리 view + 외국인 매니아 1순위

3. 반얀트리 클럽&스파 조식

  • 외국인 ★: ◎◎ — 남산 view·인피니티 풀 결합
  • 가격: 투숙객 무료 / 외부 60K
  • 시그니처: 럭셔리 풀세트·#356 풀 패키지

4. 포시즌스 광화문 더 마켓 키친

  • 외국인 ★: ◎◎ — 광화문·경복궁 view·외국인 럭셔리
  • 가격: 외부 75K
  • 시그니처: 광화문 도심·외국인 매니아

5. 콘래드 서울 라운지 & 조식

  • 외국인 ★: ◎◎ — 여의도·한강 panorama
  • 가격: 투숙객 무료 / 외부 70K

6. JW메리어트 동대문 그리핀

⚙ FAQ 6개

1. 외국인 조식 1순위: 시그니엘 80F·신라 파크뷰·반얀트리·포시즌스·콘래드.

2. 외국인 애프터눈티: 시그니엘 BAR 81·신라 더 라이브러리·포시즌스 마루·JW 그리핀.

3. 외국인 가성비: L7 홍대·노보텔 동대문·페어몬트·롯데.

4. 외국인 이그제큐티브 라운지: 클럽 룸 (+50~100K) 조식·해피아워 무제한 풀세트.

5. 외국인 외부 이용: 시그니엘·신라·반얀트리·포시즌스·콘래드·JW 60~120K 사전 예약.

6. 외국인 호캉스 풀세트: 조식 (#358) + 수영장 (#356) + 애프터눈티 통합 1박2일.
