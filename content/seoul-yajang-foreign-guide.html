외국인 서울 야장(野場) 가이드 — 한국 노포 야외 평상 야간 식문화 8선

부제: 외국인 관광객용 서울 야장 8선 (익선·광장·을지로·신촌·인사·홍대·종로·청계) + 야장 etiquette·시즌·동선 매트릭스

ISSUE 04 · #1071 · 2026-06-13

🎯 왜 서울 야장 가이드인가

야장(野場·Yajang) = 한국 노포 야외 평상 야간 식문화. 외국인 관광객 페인포인트 = (a) "야장 = 노점(street food)" 잘못된 인식 — 야장 = 정식 식당의 야외 평상 좌석 + 정식 메뉴 + 주문 가능 (b) "Korean street food at outdoor benches" Reddit·Quora 외국인 검색 多 — 키친구 풀가이드 0편 (c) 5~10월 야장 시즌 = 외국인 한국 여행 peak 시즌 일치 (d) 한국 nightlife = 클럽·바 + 야장 평상 = 2-track. 클럽·바는 #450 Nightlife Map·#454 외국인 클럽 — 야장 = 키친구 매니아 매트릭스 #1 (외국인 미생소 + 가장 한국적) (e) 야장 = 서울 동네 8선 cross (익선·광장·을지로·신촌·인사·홍대·종로·청계).

본 가이드는 외국인 야장 etiquette + 8선 매트릭스 + 시즌·시간대 + 동선 추천 + 매니아 풀세트.

⚠ 외국인 자주 실수 3가지

1. "야장 = 노점(street food)?": 야장 = 정식 식당의 야외 평상 좌석 + 정식 메뉴 + 주문 가능 + 결제 가능. 노점(포장마차·길거리 음식)과 다름. 야장 = restaurant outdoor seating, not street food.

2. "신발 벗어야 하나?": 평상 = 신발 벗고 좌식 (1·2·5·7) 또는 신발 신고 의자형 (3·4·6·8) 양쪽 있음. 매장마다 다름. 입구에 신발장·평상 안내 표지 多. 좌식 평상 = 양반다리·다리 펴고 OK.

3. "외국인도 OK?": 익선·종로 5가·홍대·신촌 야장 = 외국인 환영 + 영어 메뉴 부분 가능. 메뉴 = 사진 多. 인사·광장 = 한국어 only인 곳 일부 — 사진으로 주문 OK. 합석(sharing table) = 야장 문화 (외국인 처음엔 어색해도 한국 야장 etiquette).

⚙ FAQ 4개

1. 언제 가나: 5~10월 야장 시즌. 7~9월 best. 11~4월 = 다수 야장 close (실내 좌석만). 외국인 한국 여행 peak (5·6·9·10월) = 야장 시즌 일치.

2. 예약 가능?: 익선 고운돈·인사 한옥 야장 = 일부 예약 가능 (catch table·네이버 예약). 광장·을지로·신촌·홍대·청계 = walk-in 다수. 주말 7~10시 = 평상 만석. 권장 = 평일 7~9시 또는 주말 5~6시 도착.

3. 혼자 가도?: 신촌·홍대·종로 5가 = 혼자 OK + 합석 가능. 익선 고운돈 = 2인 이상 추천. 광장·청계 = 시장 평상 = 혼자 OK + 외국인 매니아 fit.

4. 외국인 야장 etiquette: (a) 시끄러움 허용 (다른 평상 큰 목소리 자연스러움) (b) 합석 = 야장 문화 (자리 부족 시 다른 평상에 합석) (c) 잔 부딪힘 = 건배 = 한국 야장 etiquette (d) 신발 벗고 좌식 평상 = 양반다리 또는 다리 펴고 (e) 결제 = 카드·현금 OK 다수.
