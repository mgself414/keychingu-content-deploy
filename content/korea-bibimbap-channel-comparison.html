🥬 4채널 deep dive

🥬 전주 한옥마을 (Jeonju Hanok Village)

핵심 가치: UNESCO 무형유산 정통 #1 + 5색 + 궁중 정통.

  • 추천 매장:
  • 전주 한옥마을 비빔밥 노포 — 정통 #1
  • 서울 전주식 비빔밥집 (강남·홍대) — 가성비 정통
  • 가격 anchor: 12,000~25,000원 (전주) / 8,000~20,000원 (서울)
  • 외국인 친화도: ★★★★★ (UNESCO)
  • UNESCO 무형유산: 궁중요리 cluster (2023)

🍲 돌솥 비빔밥 (Dolsot Bibimbap)

핵심 가치: 글로벌 #1 + 뜨거움 + 바삭 누룽지.

  • 추천 매장: 한정식·MZ 한식당·체인 (한솥 등)
  • 가격 anchor: 10,000~22,000원
  • 외국인 친화도: ★★★★★ (글로벌 #1)
  • 주의: 매우 뜨거움·접시 받침 사용·아이 주의

🥄 셀프 비빔밥 (Self Bibimbap)

핵심 가치: MZ DIY #1 + 재료 풀세트 + 가성비.

  • 추천 매장:
  • MZ 셀프 비빔밥 매장 (홍대·강남·성수) — 트렌드
  • 셀프 한식 뷔페 — 가성비
  • 가격 anchor: 8,000~18,000원 (셀프 무한 리필)
  • 외국인 친화도: ★★★★ (MZ #1)

🌳 산채·사찰음식 (Sanchae·Temple Cuisine)

핵심 가치: 채식·할랄 #1 + 봄 산나물 + 사찰음식 cluster.

  • 추천 매장:
  • 진관사 — 사찰음식 정통 #1
  • 조계사·봉은사 — 사찰음식 cluster
  • 강원·전라 산채 비빔밥집 — 봄 정통
  • 가격 anchor: 산채집 10,000~25,000원 / 사찰 코스 25,000~80,000원
  • 외국인 친화도: ★★★★★ (채식 #1·글로벌)

⚠ 외국인 자주 실수 5가지

1. "4채널 = 비슷": 정통·트렌드·채식 완전 다름. UNESCO = 전주 / 글로벌 = 돌솥 / MZ = 셀프 / 채식 = 산채.

2. "전주 = 일반": 전주 = UNESCO 무형유산 정통 (5색·궁중).

3. "돌솥 = 일반 그릇": 돌솥 = 매우 뜨거움·바삭 누룽지 매니아 #1.

4. "셀프 = 가성비만": 셀프 = MZ 트렌드 #1·재료 풀세트.

5. "산채 = 비싸기만": 산채집 = 10,000~25,000원 lunch 가성비 OK·사찰 코스만 비쌈.

⚙ FAQ 8개

1. 첫 비빔밥 채널 = 어디: 돌솥 (#1 글로벌) → 전주 (UNESCO 정통).

2. 인스타·vlog: 전주 한옥마을·돌솥 뜨거움·셀프 DIY.

3. MZ 트렌드: 셀프 (#1).

4. 채식·할랄: 산채·사찰음식 (#1) + 셀프 (자유 선택).

5. 가족 동반: 셀프 (#1) + 전주.

6. 알레르기·임신: [#879 disclaimer](#879) 참조.

7. 결제·팁: 카드 OK / 팁 X.

8. VAT 환급: 식음료 일반 환급 X.

⚠ 의료·안전·식이 disclaimer

비빔밥 4채널 모두 일반 음식. 임신부·어린이 = OK (돌솥 화상 주의). 알레르기 (계란·해산물·마늘·간장 글루텐) 사전 고지. 돌솥 화상 주의. 식중독 의심 시 ☎ 1339. 본 가이드는 일반 정보, 의료 자문이 아님.

식이 제한 fallback:

  • 할랄·코셔: 산채 = #1 / 셀프 = 자유 선택 / 전주·돌솥 = 소고기 제외.
  • 채식·비건: 산채 = #1 / 셀프 = 자유 선택.
  • 글루텐 free: 간장·고추장 = 글루텐 (Tamari 대체).
