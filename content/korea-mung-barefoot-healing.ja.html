韓国の森ぼんやり・水ぼんやり・裸足ウォーキングガイド — サリョニ森道・ビジャリム・西帰浦 癒しの森の森ぼんやり、ソェソッカク・順天湾湿地・トゥムルモリの水ぼんやり、ケジョクサン黄土の道・ムルムサン 幸せの森の裸足ウォーキングまで20か所

サブタイトル: 文化体育観光部・韓国観光公社「名所発掘 100×100」国民投票の「ぼんやりするのにいい」「足の裏(裸足)」二つのテーマで選ばれた場所のうち、観光公社に運営情報が登録された森・竹林・水辺・空・裸足の道20か所 · 入場料が登録された場所はビジャリム・チュンノグォン(一般 3,000ウォン)・順天湾湿地(大人 10,000ウォン)・巨済 孟宗竹テーマ公園(大人 4,000ウォン)など7か所 · 西帰浦 癒しの森は事前予約、順天湾湿地は毎月最終週の月曜日休み — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、文化体育観光部 (Munhwa Cheyuk Gwangwangbu / 문화체육관광부)・韓国観光公社の「名所発掘 100×100 (Myeongso Balgul 100×100 / 명소발굴 100×100)」(旅行専門家が推薦した候補を国民が投票)の「ぼんやりするのにいい (Meong Ttaerigi Joeun / 멍 때리기 좋은)」テーマと「足の裏 (Balbadak / 발바닥)」(裸足)テーマで選ばれた場所のうち、韓国観光公社の観光情報に運営情報が登録された20か所を扱います。表の順位と得票数は、その投票結果です。両方のテーマに入った場所は順位を二つとも書きました。森・竹林・水辺・空・裸足の道の五つの系統に合う場所を選んだので、裸足の投票に入った並木道の潭陽 メタセコイア並木道 (Damyang Metasekwoia-gil / 담양 메타세쿼이아길, 裸足 3位)や古道のムンギョンセジェ (Mungyeong Saejae / 문경새재)、都心の公園の晋州 ナムガラム公園 (Jinju Namgaram Gongwon / 진주 남가람공원)と金海 ヨンジ公園 (Gimhae Yeonji Gongwon / 김해 연지공원)などは入れていません。ぼんやりの投票に入った海水浴場・遺跡・岬、たとえばヒョプチェ海水浴場 (Hyeopjae / 협재해수욕장)・月精橋 (Woljeonggyo / 월정교)・大陵苑 (Daereungwon / 대릉원)・風の丘 (Baramui Eondeok / 바람의 언덕)・ソプチコジ (Seopjikoji / 섭지코지)なども同じ理由で外しました。

「森ぼんやり (Sup-meong / 숲멍)」「水ぼんやり (Mul-meong / 물멍)」は投票の推薦理由によく使われた韓国語の表現で、森や水を眺めてぼんやり休むことを指します。場所は、森、竹林、水辺、空が開けた場所、裸足の道の五つに分けました。

運営情報は韓国観光公社の観光情報(TourAPI)に登録された値を写しました。登録値がない欄は「登録値なし」と書きました。投票名簿の名前や住所が観光公社の登録と違う場所は、本文に別に書きました。

📍 森ぼんやり(スプモン) — サリョニ森道・ビジャリム・西帰浦 癒しの森・チョルムル自然休養林・コッチャワル道立公園

サリョニ森道、観光公社の登録住所は西帰浦市 (Seogwipo-si / 서귀포시) ピョソン面 (Pyoseon-myeon / 표선면) カシ里 (Gasi-ri / 가시리) プルグンオルム入口 (Bulgeun Oreum Ipgu / 붉은오름 입구)で、ビジャリムロ (Bijarim-ro / 비자림로)から始まり、ムルチャッオルム (Mulchat Oreum / 물찻오름)とサリョニオルム (Saryeoni Oreum / 사려니오름)を通っていく杉の森道です。サリョニオルムまで続いているので、この名前が付きました。観光公社の紹介によると、「サリョニ」は神聖な森、または「糸などをばらけないように丸く重ねて巻く」という意味です。杉のほか、コナラ・アカシデ・エゴノキ・ヒノキが育ち、2002年にユネスコが指定した済州生物圏保存地域に含まれます。投票名簿には、住所が済州市 (Jeju-si / 제주시) ポンゲ洞 (Bonggae-dong / 봉개동) 山64-5と載っています。

  • 開く時間・休み・料金: 登録値なし。

ビジャリム、済州市 クジャ邑 (Gujwa-eup / 구좌읍) ビジャスプギル 55 (Bija-supgil 55 / 비자숲길 55)、☎ 064-710-7911~2 は、天然記念物に指定された森です。448,165㎡の面積に、樹齢500~800年のカヤの仲間のビジャ (Bija / 비자)の木2,800本あまりが育っています。木の高さは7~14m、直径は50~110㎝に達します。観光公社の紹介には、世界的にも珍しいビジャの木の森と書かれています。

  • 開く時間: 09:00~18:00(入場締切 17:00)。休み: 年中無休。
  • 料金(個人): 一般 3,000ウォン, 青少年・子ども 1,500ウォン。未就学児は無料。

西帰浦 癒しの森、西帰浦市 サンノクナムロ 2271 (Sanroknam-ro 2271 / 산록남로 2271)、☎ 064-760-3067 は、海抜320~760mにある森です。暖帯林・温帯林・寒帯林がまんべんなく育ち、観光公社の紹介によると、平均樹齢60年以上のヒノキの森が何か所もあります。山林治癒指導士が進める山林治癒プログラムがあります。

  • 開く時間: 4~10月 08:00~16:00, 11~3月 09:00~16:00。事前予約のうえ利用でき、空きがあれば当日のオンライン予約と現地発券もできます。登録された収容人数は平日 300人、週末 600人です。
  • 休み: 年中無休。
  • 料金(個人): 大人 1,000ウォン, 青少年 600ウォン。山林治癒プログラムは3時間前後で大人 20,000ウォン, 2時間前後で大人 12,000ウォン。

済州チョルムル自然休養林、済州市 ミョンニムロ 584 (Myeongnim-ro 584 / 명림로 584)、☎ 064-728-1510 は、杉の森の休養林です。1960年代中ごろから植えた杉が中心になっています。散策路は傾斜がゆるやかで階段がなく、高齢者や子どもも歩きやすいと紹介されています。近くのチョルムルオルム (Jeolmul Oreum / 절물오름)の頂上展望台からは、馬蹄形の噴火口を見られます。

  • 開く時間: 3~10月 07:00~18:00, 11~2月 07:00~17:00。休み: 年中無休。
  • 料金(個人): 大人 1,000ウォン, 青少年 600ウォン, 子ども 300ウォン。

済州コッチャワル道立公園、西帰浦市 テジョン邑 (Daejeong-eup / 대정읍) エデュシティロ 178 (Edyusiti-ro 178 / 에듀시티로 178)、☎ 064-792-6047 の「コッチャワル」は、岩の塊が不規則に散らばった土地にできた森を指します。テウリギル (Teuri-gil / 테우리길)・ハンスギギル (Hansugi-gil / 한수기길)・ビルレギル (Bille-gil / 빌레길)・オチャニギル (Ochani-gil / 오찬이길)・カシナンギル (Gasinang-gil / 가시낭길)の五つのコースがあり、1日に二回、森の解説があります。登山靴かスニーカーを履く必要があり、革靴・サンダル・厚底スニーカーでは入れません。

  • 開く時間: 3~10月 入場 09:00~16:30(探訪 18:00まで), 11~2月 入場 09:00~15:00(探訪 17:30まで)。休み: 年中無休。
  • 料金: 一般 1,000ウォン, 青少年・軍人 800ウォン, 子ども 500ウォン。

📍 竹林 — チュンノグォン・テファガン国家庭園・巨済 孟宗竹テーマ公園・ソムジンガン竹林の道

チュンノグォン、潭陽郡 (Damyang-gun / 담양군) 潭陽邑 (Damyang-eup / 담양읍) チュンノグォンロ 119 (Jungnogwon-ro 119 / 죽녹원로 119)、☎ 061-380-2680 は、2003年5月にオープンした竹林です。総延長2.2㎞の散策路が、ウンスデトンギル (Unsudaetong-gil / 운수대통길)・チュンマゴウギル (Jungmagou-gil / 죽마고우길)・哲学者の道 (Cheolhakjaui Gil / 철학자의 길)など八つのテーマの道に分かれています。展望台からは、タミャンチョン (Damyangcheon / 담양천)とクァンバンジェリム (Gwanbangjerim / 관방제림)、メタセコイア並木道が見渡せます。夜にも歩けるように、竹林に照明を付けました。

  • 開く時間: 3~10月 09:00~19:00(入場締切 18:00), 11~2月 09:00~18:00(入場締切 17:30)。休み: 年中無休。
  • 料金(個人): 一般 3,000ウォン, 青少年・軍人 1,500ウォン, 小学生 1,000ウォン。65歳以上・満6歳未満は無料。

テファガン国家庭園、蔚山 (Ulsan / 울산) チュン区 (Jung-gu / 중구) セッカンナムギル 5 (Saetgangnam-gil 5 / 샛강남길 5)、☎ 052-229-3147~8 は、テファガン (Taehwagang / 태화강)に沿った生態庭園です。総面積835,452㎡に、生態・竹・季節・水生・参加・ムクゲの六つの空間があります。観光公社の紹介によると、シプリ竹林 (Sipri Daesup / 십리대숲)は風に当たる竹の音と静かな道で有名です。投票名簿には「テファガン国家庭園 黄土裸足道 (Taehwagang Gukga Jeongwon Hwangto Maenbalgil / 태화강 국가정원 황토맨발길)」という名前で載っていますが、観光公社の紹介には黄土裸足道についての説明がなく、投票名簿の住所 (Taehwagang Gukgajeongwon-gil 154 / 태화강국가정원길 154)も観光公社の登録住所と違います。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

巨済 孟宗竹テーマ公園、巨済市 ハチョン面 (Hacheong-myeon / 하청면) コジェブクロ 700 (Geojebuk-ro 700 / 거제북로 700)、☎ 055-637-0067 は、孟宗竹の森で休んだり体験したりできる公園です。観光公社の紹介によると、孟宗竹は高さ10~20m、直径20㎝ほどで、竹の中でいちばん太いです。孟宗竹の森体験と工芸体験、冒険の森体験があります。投票名簿には「巨済 孟宗竹テーマパーク (Geoje Maengjongjuk Tema Pakeu / 거제 맹종죽테마파크)」という名前で載っています。

  • 開く時間: 3~10月 09:00~18:00, 11~2月 09:00~17:30。休み: 年中無休。
  • 料金(個人): 大人 4,000ウォン, 青少年 3,000ウォン, 子ども 2,000ウォン。駐車は無料。

ソムジンガン竹林の道、求礼郡 (Gurye-gun / 구례군) 求礼邑 (Gurye-eup / 구례읍) ウォンバン里 (Wonbang-ri / 원방리) 1 は、ソムジンガン (Seomjingang / 섬진강)に沿って約2.5km続く散策路です。川と並んで歩きながら、チリ山 (Jirisan / 지리산)の稜線を眺められると紹介されています。入口に三日月、奥に満月の形のフォトゾーンがあり、日が暮れると照明が灯ります。

📍 水ぼんやり(ムルモン) — ソェソッカク・順天湾湿地・ウィヤンジ・トゥムルモリ・ウィリムジ・パンポ漢江公園

ソェソッカク、西帰浦市 ソェソッカクロ 104 (Soesokkak-ro 104 / 쇠소깍로 104)、☎ 観光案内所 (Gwangwang Annaeso / 관광안내소) 064-732-1562 は、ヒョドンチョン (Hyodoncheon / 효돈천)の淡水と海水が出会って深い淵になった場所です。観光公社の紹介によると、「ソェ」は牛、「ソ」は淵、「カク」は終わりを意味します。溶岩が固まってできた谷に、奇岩怪石と松林が調和しています。小舟とテウ (Teu / 테우)の体験があります。

  • 開く時間: ソェソッカクは常時開放。体験は夏季 09:00~18:00、冬季 09:00~17:00で、天気が悪いと運航しません。
  • 休み: 年中無休。
  • 料金: ソェソッカクは無料。小舟は大人2人 20,000ウォン, テウは大人1人 10,000ウォン。

順天湾湿地、順天市 スンチョンマンギル 513-25 (Suncheonman-gil 513-25 / 순천만길 513-25)、☎ 061-749-3114 は、順天のトンチョン (Dongcheon / 동천)とイサチョン (Isacheon / 이사천)が出会う所から干潟の手前まで、総面積5.4㎢のアシの群落が広がる場所です。天文台の星明かり体験とアシ原の干潟探検などがあります。投票名簿には「順天湾湿地 順天湾アシ群落地 (Suncheonman Seupji Suncheonman Galdae Gunnakji / 순천만습지 순천만갈대군락지)」が別に、ぼんやり 12位(192票)で載っています。

密陽 ウィヤンジ、密陽市 プブク面 (Bubuk-myeon / 부북면) ウィヤンロ 273-36 (Wiyang-ro 273-36 / 위양로 273-36)は、新羅時代に農業用水を引くために築いた貯水池です。池の真ん中に小さな島が五つと、東屋のワンジェジョン (Wanjaejeong / 완재정)があります。ヒトツバタゴの花が咲くころの景色がいちばんいいと紹介されています。

堤川 ウィリムジ、堤川市 ウィリムジロ 33 (Uirimji-ro 33 / 의림지로 33)、☎ 043-651-7101 は、三韓時代に築いた貯水池で、周囲は1.8㎞です。忠清道 (Chungcheongdo / 충청도)を「ホソ地方 (Hoseo Jibang / 호서지방)」と呼ぶときの湖が、ウィリムジだと紹介されています。湖の周りに、1807年に建てたヨンホジョン (Yeongho-jeong / 영호정)、1948年に建てたキョンホル (Gyeongho-ru / 경호루)、数百年たった松としだれ柳、30mの自然の滝があります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

パンポ漢江公園、ソウル 瑞草区 (Seocho-gu / 서초구) シンバンポロ11ギル 40 (Sinbanpo-ro 11-gil 40 / 신반포로11길 40)、☎ 02-3780-0541~4 は、パンポ大橋を中心に、ハンナム大橋とトンジャク大橋の間の漢江の南側にあります。観光公社の紹介によると、パンポ大橋の月光の虹噴水 (Dalbit Mujigae Bunsu / 달빛무지개분수)は長さ1,140mで、2008年に世界でいちばん長い橋梁噴水としてギネスに載りました。パンポ大橋とトンジャク大橋の間の人工島ソレ島 (Seoraeseom / 서래섬)を一周する散策コースがあります。

  • 開く時間: 常時開放(噴水の運営時間はホームページを参照)。休み: 年中無休。料金: 無料。

📍 空ぼんやり(ハヌルモン) — ハヌル公園・アンバンデギ

ハヌル公園、ソウル 麻浦区 (Mapo-gu / 마포구) ハヌルゴンウォンロ 95 (Haneulgongwon-ro 95 / 하늘공원로 95)、☎ ワールドカップ公園 (Worldcup Gongwon / 월드컵공원) 02-300-5500 は、ワールドカップ公園の中にあります。ごみ埋立地だった土地を生態公園によみがえらせた場所です。秋にはススキが咲き、ブカンサン (Bukhansan / 북한산)や漢江などソウルの景色が一望できます。夕焼けと夜景でも知られています。「足の裏」投票には「ハヌル公園 ソゴンソゴンギル (Haneul Gongwon Sogon Sogon-gil / 하늘공원 소곤소곤길)」という名前で載っています。

  • 開く時間: 05:00~20:30。休み: 年中無休。料金: 無料。

江陵 アンバンデギ、江陵市 ワンサン面 (Wangsan-myeon / 왕산면) アンバンデギギル 428 (Anbandegi-gil 428 / 안반데기길 428)、☎ 江陵市 観光政策課 (Gangneung-si Gwangwang Jeongchaekgwa / 강릉시 관광정책과) 033-640-5125 は、海抜1,100mの高山地帯にある白菜畑です。1965年から焼畑民が山を切り開いて耕し、傾斜が急で、機械を使わず人の手で畑を耕しました。約200万㎡の土地が高冷地の白菜畑になりました。投票名簿には「ワウアンバンデギ (Wau Anbandegi / 와우안반데기)」という名前と、アンバンデギギル 440-1 (Anbandegi-gil 440-1 / 안반데기길 440-1)の住所で載っていて、推薦理由に夜空の天の川が挙げられました。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

📍 裸足ウォーキング — ケジョクサン黄土の道・ムルムサン 幸せの森・テワンアム公園

ケジョクサン黄土の道、大田 (Daejeon / 대전) テドク区 (Daedeok-gu / 대덕구) チャンドン (Jang-dong / 장동)は、2006年に黄土2万トンあまりを敷いて作った裸足トレッキングコースです。傾斜がゆるやかで、裸足で歩いても無理がないと紹介されています。靴を履いて歩く周遊道も別にあります。出発地点に森の中の広場があり、遊び場・東屋などの設備と足洗い場があります。

ムルムサン 幸せの森、霊光郡 (Yeonggwang-gun / 영광군) 霊光邑 (Yeonggwang-eup / 영광읍) ムルムロ 219 (Mulmu-ro 219 / 물무로 219)、☎ 霊光郡 山林公園課 (Yeonggwang-gun Sallim Gongwongwa / 영광군 산림공원과) 061-350-5779 は、周遊道10㎞、裸足の黄土の道2㎞、ヒノキのヨンサンウォン (Yeongsangwon / 영상원)2か所、松林、登山道などを備えた森です。黄土の道はムルムサンの裏側にあり、ぬかるんだ黄土の道0.6㎞と乾いた黄土の道1.4㎞に分かれていて、選んで歩けます。投票名簿には「ムルムサン幸せの森 裸足黄土の道 (Mulmusan Haengbokssup Maenbal Hwangtotgil / 물무산행복숲 맨발황톳길)」という名前と、ミョリャン面 (Myoryang-myeon / 묘량면) トクフン里 (Deokheung-ri / 덕흥리)の住所で載っています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。

テワンアム公園、蔚山 トン区 (Dong-gu / 동구) トゥンデロ 95 (Deungdae-ro 95 / 등대로 95)、☎ 052-209-3738 は、入口からウルギ灯台 (Ulgi Deungdae / 울기등대)まで600mの松林の道が続く公園です。観光公社の紹介によると、100年あまり育った松の木陰が続き、松林を抜けると海岸の断崖と大きな岩が現れます。投票名簿には「テワンアム公園 松林の道 (Daewangam Gongwon Songnimgil / 대왕암공원 송림길)」という名前で載っています。吊り橋とウルギ灯台があります。

  • 開く時間: 常時開放。休み: 年中無休。料金: 登録値なし。

⚙ FAQ 3

Q. ソウルから近い場所は?

A. ソウル市内にはパンポ漢江公園とハヌル公園があり、キョンギの楊平にはトゥムルモリがあります。三か所とも無料で登録されています。

Q. 裸足で歩くのによいと紹介された場所は?

A. ケジョクサン黄土の道(裸足トレッキングコース)とムルムサン 幸せの森(裸足の黄土の道 2㎞)です。二か所とも観光公社の紹介に裸足の道が書かれています。テファガン国家庭園とテワンアム公園は「足の裏」投票で1位と2位でしたが、観光公社の紹介に裸足の道の説明はありません。

Q. お金がかかる場所は?

A. ビジャリム(一般 3,000ウォン)、西帰浦 癒しの森(大人 1,000ウォン)、済州チョルムル自然休養林(大人 1,000ウォン)、済州コッチャワル道立公園(一般 1,000ウォン)、チュンノグォン(一般 3,000ウォン)、巨済 孟宗竹テーマ公園(大人 4,000ウォン)、順天湾湿地(大人 10,000ウォン)です。ソェソッカクは無料ですが、舟の体験は別に払います。
