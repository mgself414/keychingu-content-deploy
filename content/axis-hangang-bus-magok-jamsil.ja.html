ソウル東西軸⑦ 漢江バス、麻谷から蚕室まで — 川の上から横に読むソウル

副題: 南北軸はバス140、東西軸はバス720と2号線の道を通った。三本目は川だ。2025年9月、最も新しい公共交通、漢江バスが東西の直線に乗る。麻谷から汝矣島で乗り換え、蚕室まで水面から約3時間半。Seoul E-W Axis 7回目。

ISSUE · #1362 · 2026-09-07

🎯 フレーム — 三本目の線、川

ソウルを縦に読むバス(#1353)と横に読むバス(#1356)、そして循環線の東半円(#1359)まで — このシリーズは地上の道だけを走ってきた。この回は水の上へ下りる。漢江 (Han River / 한강) はソウルを東西に横切る最も古い直線であり、2025年9月18日からその上を漢江バス (Hangang Bus / 한강버스) が公共交通として走る。遊覧船ではない。交通カードをタッチして乗り、次の船着場で降りる、片道3,000ウォンの船だ。

八つの船着場が西から東へ並ぶ — 麻谷 (Magok / 마곡)・望遠 (Mangwon / 망원)・汝矣島 (Yeouido / 여의도)・狎鴎亭 (Apgujeong / 압구정)・玉水 (Oksu / 옥수)・ソウルの森 (Seoul Forest / 서울숲)・纛島 (Ttukseom / 뚝섬)・蚕室 (Jamsil / 잠실)。路線は汝矣島で西部と東部に分かれ、麻谷から蚕室まで行くには汝矣島で必ず一度降りて乗り換える。この回はその構造をそのままコースにする — 西の端の麻谷で乗り、汝矣島で乗り換え、東の端の蚕室で降りる。船着場周辺の町はすべて通過 — この回の主役は川そのものだ。

  • 総所要時間: 約3時間30分(乗船約2時間 + 汝矣島の乗り換え待ち + 駅↔船着場の徒歩約30分 — 時刻表によって大きく変わる)
  • おすすめ時間帯: 平日午前出発 — まず時刻表を確認する。運航間隔が1時間前後のため、出発時刻を合わせないと待ち時間が長くなる。夕焼けを船上で見たいなら東部区間を午後遅くに合わせる逆算も可能(2026年8月から午後・夜間便が増えた)
  • 傾斜: なし — 歩く区間は駅から船着場まで平地

なぜ漢江バスなのか — ソウルで最も新しい公共交通

漢江バスは2025年7月の市民体験運航を経て、2025年9月18日に正式運航を始めた。冬に機関故障で一部区間が止まったが、2026年3月1日に全区間が再開され、その後乗客が急速に増えた — 3月6.2万人、4月7.6万人、5月9.1万人と月間最多を更新し、2026年8月13日時点で累積乗客が50万人を超えた(ソウル市発表)。利用者調査(2026年6~7月、3,569人)では満足度97%。運営会社は付帯施設のカード決済比率から見て乗客の約35%が外国人と推算する — 外国人が最も多く乗る船着場は汝矣島と纛島。

📖 物語1 — 川が先にあった: 南北軸の橋(1969)とトンネル(1970)、東西軸の鍾路 (Jongno / 종로)(600年)と循環線(1984) — すべて人が敷いた線だ。漢江はそれより前からあった。ソウルの東西を分けるこの直線は、朝鮮時代には渡し場と漕運の道であり、20世紀には橋の下を通り過ぎる風景になり、2025年に再び道になった。この船は、ソウルで最も新しい公共交通が最も古い軸を走る、ということになる。

🚶 コース — 水面の順序そのままに

起点は9号線陽川郷校駅 (Yangcheon Hyanggyo Station / 양천향교역)。麻谷船着場 (Magok pier / 마곡 선착장) まで徒歩約12分(0.8km)。シャトルバスは2026年8月になくなったので歩く。

① 陽川郷校駅 → 麻谷船着場 → 発券 (🚶 約12分)

  • 駅から漢江方向へまっすぐ。船着場建物の発券機で乗船券を買う — カード決済のみ、予約なし、交通カードのT-money (티머니) なども使える。大人3,000ウォン・青少年1,800ウォン・子供1,100ウォン(2026年9月公式基準・変動の可能性あり)。船1隻の定員は199人なので、週末は次の便に回されることもある。
  • 時刻表をここでもう一度確認する。西部(麻谷↔汝矣島)と東部(汝矣島↔蚕室)の便は別々にある。

② 麻谷 → 望遠 (🚢 約25分・通過)

  • 船が川の真ん中へ出るとソウルの西側が開ける。左側(北岸)の川辺に麻谷・加陽 (Gayang / 가양) 側のマンション団地、右側に傍花大橋 (Banghwa Bridge / 방화대교)・幸州山城 (Haengju Fortress / 행주산성) 方面。橋の下を通るたびにソウルの橋の名前が一つずつ付いていく。
  • 望遠船着場 — 降りない。望遠市場 (Mangwon Market / 망원시장)・望遠洞 (Mangwon-dong / 망원동)(#489・#25) はここで川を渡って上がる町だ。

③ 望遠 → 汝矣島 — 乗り換え (🚢 約20分・下船)

  • 楊花大橋 (Yanghwa Bridge / 양화대교) を過ぎると左側に汝矣島のガラスビル群と63ビル (63 Building / 63빌딩)。汝矣島船着場で全員降りる — 西部と東部の路線がここで終わり、始まる。同じ方向へ進み続けるには下船後、東部(蚕室方面)の便に再び乗る。乗り換え運賃・手続きは現地案内に従う。
  • 📖 物語2 — 汝矣島で乗り換える: 路線が汝矣島で二つに分かれるのは、ソウルの地理そのままだ。西のソウルと東のソウルの蝶番が汝矣島であり、川の上でも人はここで乗り換える。乗り換え待ち時間が長ければ、船着場建物3階の川の眺めが良いカフェ、スターバックス汝矣島漢江公園店 (Starbucks Yeouido Hangang Park / 스타벅스 여의도한강공원점) が代表例の1店だ。そこや5号線汝矣ナル駅 (Yeouinaru Station / 여의나루역) 方面(徒歩約4分)の漢江公園へ少し出てみてもいい。

④ 汝矣島 → 狎鴎亭または玉水 (🚢 約30分・通過)

  • 東部便は麻浦大橋 (Mapo Bridge / 마포대교)・漢江大橋 (Hangang Bridge / 한강대교)・銅雀大橋 (Dongjak Bridge / 동작대교)・盤浦大橋 (Banpo Bridge / 반포대교) の下を順に通る。右側(南岸)に龍山 (Yongsan / 용산)・二村 (Ichon / 이촌)、左側に盤浦 (Banpo / 반포) とセビッソム (Sebitseom / 세빛섬)。南北軸(#1353)がバスで渡った漢南大橋 (Hannam Bridge / 한남대교)が正面に現れる — 今回はその下を通る。
  • 次の停船は便によって狎鴎亭または玉水のどちらか一方(便ごとに交互停船)。どちらも通過する。狎鴎亭は狎鴎亭駅 (Apgujeong Station / 압구정역) から徒歩20分以上離れており、玉水は玉水駅 (Oksu Station / 옥수역) 3番出口から5分だ — 玉水の町は南北軸#1354漢南の東隣。

⑤ → ソウルの森 → 纛島 (🚢 約15分・通過)

  • 聖水大橋 (Seongsu Bridge / 성수대교) を過ぎると左側にソウルの森。ソウルの森船着場は2026年6月8日から10月末までの期間限定運航(庭園博覧会連携)のため、その後は停船しないことがある。続いて纛島船着場 — 外国人乗客が汝矣島に次いで多く降りる場所。この回では通過(聖水・ソウルの森は#1342・#701・#709)。

⑥ 纛島 → 蚕室 — 締めくくり (🚢 約25分)

  • 清潭大橋 (Cheongdam Bridge / 청담대교)・蚕室大橋 (Jamsil Bridge / 잠실대교) の下を過ぎると、右側の川辺の向こうにロッテワールドタワー (Lotte World Tower / 롯데월드타워)(555m)が近づく。東の端の蚕室船着場で降りる。
  • 締めくくり: 蚕室船着場は地下鉄駅から遠い — 蚕室セネ駅 (Jamsilsaenae Station / 잠실새내역) 方向へ徒歩15分前後(現地案内板基準)。蚕室の町は#82・#300・#707。2号線東半円(#1359)が蚕室鉄橋 (Jamsil Railway Bridge / 잠실철교) の上で川を渡った、まさにその場所の下でこの回は終わる。

🚢 乗り方 5

1. 時刻表が先だ: 運航間隔は1時間前後。hgbus.co.kr または船着場の発券機で当日の時刻表を確認し、出発時刻を決める。

2. 予約なし・カードのみ: 現地の発券機でカード(交通カード含む)で。現金不可(#1301)。定員199人。

3. 汝矣島で必ず降りる: 西部・東部路線が分離されている。下船後、東部便に再乗船。

4. 座席は上甲板・窓際: 橋の下を通るときは上甲板が良く、風が強ければ室内の窓際。東部区間は右側(南岸)が江南 (Gangnam / 강남) のスカイライン。

5. 運休を確認する: 八堂ダム (Paldang Dam / 팔당댐) の放流量が毎秒3,000㎥以上、潜水橋 (Jamsu Bridge / 잠수교) の水位基準超過、悪天候時は運航中止。梅雨・台風シーズンは出発前に告知を確認 — 代替は#1256(地下鉄漢江ライン)・#1248(京義中央線の車窓)。

🙏 船上のマナー — このコースの核心

  • デッキの手すりに寄りかかったり乗り上がったりしない。乗務員の案内に従う。
  • 橋の下を通るとき大声を出さない — 他の乗客から川の音を奪うことになる。
  • 船着場の建物と漢江公園は住民の空間。発券の列で長時間撮影しない。
  • ゴミは船内の分別回収箱へ。川に捨てるのは論外だ。

💡 戸惑いポイント

  • シャトルバスがなくなった: 麻谷・狎鴎亭・蚕室の無料シャトルは2026年8月廃止。駅から歩くか市内バスに乗る — この回が麻谷を陽川郷校駅の徒歩に、蚕室を蚕室セネ駅の徒歩に決めた理由。
  • 狎鴎亭・玉水は交互に停まる: 便によってどちらか一方だけ停船。どちらに停まってもこの回は通過なので問題ないが、降りる予定なら便を確認する。
  • ソウルの森船着場は期間限定運航: 2026年10月末まで。以降は時刻表から外れる可能性がある。
  • 料金が変わる可能性がある: 週末・祝日で異なる料金が検討中だ(2026年9月時点で未定)。当日の発券機表示が正解。
  • 乗り換え待ちが長くなることがある: 汝矣島で次の東部便まで30分以上待つこともある。3階のカフェや漢江公園が待合室だ。

FAQ 6

Q1. 遊覧船と何が違うのか?

  • 遊覧船(#704)は往復の観光商品で、漢江バスは片道の公共交通だ。交通カードで乗り、次の船着場で降りて地下鉄に乗り換える。料金も3,000ウォン台。

Q2. 麻谷から蚕室まで一隻の船で行けるのか?

  • 行けない。汝矣島で必ず降りて東部便に乗り換える。それがこのコースの構造だ。

Q3. どのくらいかかるのか?

  • 汝矣島までの西部区間が約45分、汝矣島から蚕室までの東部区間が約1時間20~30分前後(停船便によって異なる)。乗り換え待ちまで合わせると3時間半前後。

Q4. 外国人でも乗りやすいのか?

  • 発券機のカード決済・交通カード・英語案内があり、乗客の約35%が外国人という運営会社の推算がある。ただし時刻表の確認は自分でする必要がある。

Q5. 雨が降ったら?

  • 悪天候・八堂ダム放流時は運休。当日の告知を見て、運休なら地下鉄漢江ライン(#1256)に代える。

Q6. 南北軸・東西軸とどうつながるのか?

  • 南北軸(#1353)の漢南大橋の下をこの船が通り、東西軸④(#1359)の蚕室鉄橋の下でこの回が終わる。三本の線が川で出会う。
