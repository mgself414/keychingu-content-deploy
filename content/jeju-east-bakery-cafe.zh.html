济州东部面包店一线——从大麦面包·蒜香法棍到金宁六家

副标题: "济州海景咖啡厅"的清单已经够多了。这一篇看另一边——把济州人愿意排队的面包店和甜点专门店沿东部海岸公路串成一线。济州大麦面包 (Boribbang / 보리빵) 的始祖店、用济州方言里的"蒜"命名的蒜香法棍 (Manong Baguette / 마농바게트)(马农 (Manong / 마농)是济州方言的大蒜),还有在地图上标出来后让人吃惊的地方——金宁里 (Gimnyeong-ri / 김녕리) 1公里范围内有六家。连休息日分散在周二·周三·周四的陷阱也一并说清

🎯 为什么是"面包"而不是"海景"

搜索济州东部咖啡厅,结果总是偏向同一个方向:能看见海的窗、白色建筑、翡翠色的月汀里 (Woljeongri / 월정리)。都是好咖啡厅,但不管翻哪份清单,出现的都是同样几家。

这一篇换了一条轴线。依据是美食家评分平台上累积的评价,而从这些数据里留在济州东部的不是海景咖啡厅,而是面包店和甜点专门店:济州大麦面包 (Boribbang / 보리빵) 的始祖店、放入济州方言里表示大蒜的马农 (Manong / 마농) 的法棍、连续三年获得蓝丝带的巧克力专门店之类。这些在旅游咖啡厅清单里几乎不会出现。

把它们全部标到地图上,又发现了一件事。九左邑金宁里 (Gimnyeong-ri / 김녕리),1公里半径内有六家咖啡厅·甜点店。金宁的知名度不如咸德 (Hamdeok / 함덕) 或月汀里,但就可以步行转着逛的密度而言,是东部最密集的地方。

所以这一篇的结构很简单。新村 (Sinchon / 신촌) → 咸德 (Hamdeok / 함덕) → 金宁 (Gimnyeong / 김녕) → 月汀里 (Woljeongri / 월정리)·松堂 (Songdang / 송당) → 细花 (Sehwa / 세화) → 城山 (Seongsan / 성산)。沿济州东部海岸公路由西向东一条线,从哪个点开始,都能接到下一格。

⚠ 有效期: 本文为2026年9月末确认信息。店铺存续与道路名地址已通过Naver地区搜索全部确认,营业时间在表中一并标注了确认依据。济州东部的咖啡厅工作日固定某天休息很常见,也有冬季缩短营业的店——"未确认"请出发前电话确认。

🌾 新村——济州大麦面包的始祖,只卖三样

新村德仁堂 (Sinchon Deogindang / 신촌덕인당)(朝天邑新北路36号 / 조천읍 신북로 36)是说起济州大麦面包时最先被提到的名字。卖的只有老式红豆大麦面包·老式大麦面包·艾草蒸包三样。

大麦面包之所以是济州食物,原因在土地。济州是火山岛,水渗得快,难以种水稻,大麦反而是主粮。大米普及之前济州人吃的谷物,就这样原样留成了面包。它不像小麦面包那样蓬松,而是扎实、味道淡——期待华丽甜点的人会失望,想尝尝古早谷物味道的人则正合适。

09:00~17:00,每月第二个·第四个周日休息。下午晚些去,热门品种可能已经卖完。

🥖 咸德——"马农"在济州方言里是大蒜

奥德朗面包房咸德店 (Odrang Bakery Hamdeok / 오드랑베이커리 함덕점)(朝天邑朝咸海岸路552-3号 / 조천읍 조함해안로 552-3)的招牌是蒜香法棍 (Manong Baguette / 마농바게트)。马农 (Manong / 마농)在济州方言里就是大蒜——如果是标准韩语菜单,写的会是"蒜香法棍"。蛋挞也是经常被一起提到的品种。

这家店在本篇里最实用的理由是时间。07:00~22:00,全年无休——是这份清单里唯一从清晨一直开到深夜的店。东部行程一早开始或很晚结束时,可以把它当作基准点。位于咸德海水浴场的海岸公路上,与海滩在同一范围内。

从海滩后面的小巷再往里走一个街区,就是丹尼什 (Danish / 다니쉬)(咸德16街56号 / 함덕16길 56)和紫色屋顶 (Borajibung / 보라지붕)(咸德19街6号 / 함덕19길 6)。两家之间步行即可往返。

☕ 金宁——1公里内六家

这是本篇的发现。九左邑金宁里的咖啡厅·甜点店六家都在1公里半径内。停一次车就能步行逛完。

  • 古阿宇巧克力 (Guawoo Chocolat / 구아우쇼콜라)(金宁港2街14号 / 김녕항2길 14)——巧克力专门店。连续三年获得蓝丝带。10:30~17:00,周二·周三休息——休息日有两天,所以如果以这家为目标,请先看星期几。
  • 大海是金宁 (Badaneun Gimnyeong / 바다는김녕)(金宁路21街25号 / 김녕로21길 25)——早午餐咖啡厅。靠窗能看见海。09:00~17:00,周四休息。11月~2月也是同样的时间段营业。
  • 黑黑热狗 (Kkamang Dog / 까망도그)(金宁路21街23号 / 김녕로21길 23)——与大海是金宁在同一条路上,紧挨着的门牌号。
  • 金宁The Moment (The Moment Gimnyeong / 더모먼트김녕)(金宁路22街3号 / 김녕로22길 3)——1·2层。
  • 住在金宁的金永勋 (Gimnyeonge Saneun Kim Yeonghun / 김녕에사는김영훈)(金宁路6街2号 / 김녕로6길 2)——名字就是招牌。
  • 青春堂糯米麻花金宁店 (Cheongchundang Chapssal Kkwabaegi Gimnyeong / 청춘당찹쌀꽈배기 김녕점)(金宁路70-1号 / 김녕로 70-1)——糯米麻花。

金宁路21街上有两家紧挨着,金宁路22街就在旁边,所以只走21街·22街就有三家。一家休息的话,换到旁边就行——休息日各不相同,在这个区域反而成了优势。

🍮 月汀里·松堂——海滩后面再走一个街区

月汀里海滩前排已经有众所周知的海景咖啡厅。这一篇放进来的是它们的后面。

  • 坐下来吃早午餐（2万韩元档） — 大海是金宁 (Bada-neun Gimnyeong / 바다는김녕) 约21,600韩元，是本清单唯一的一顿正餐。

素食在这里比汤那一篇 (#1406) 容易。 那篇的菜以猪肉高汤为核心，无从回避；这里是面包与甜点，不涉及肉汤。特别是新村德仁堂 (Sinchon Deokindang / 신촌덕인당) 的三样——红豆大麦面包、原味大麦面包、艾草蒸包，主料是红豆、艾草与大麦。

不过黄油、牛奶、鸡蛋是否使用要到店询问——面包店多半用乳制品，表中没有一家是纯素专门店或清真认证店。若严格遵守纯素或清真，请把询问原料当作前提。可能含明胶的甜点（慕斯、果冻类）同理。

🚗 路线——海岸公路一条线

济州东部由一条海岸公路串起来,顺序自然而然就定了。以下以租车为前提,没有车的话请一并参考#1212(不租车徒步)·#1402(出租车游)。

从济州市出发向东

1. 新村 — 新村德仁堂(09:00开门)。距济州市最近的第一格。

2. 咸德 (从新村开车约10分钟) — 奥德朗面包房。与咸德海水浴场在同一范围。小巷里的丹尼什·紫色屋顶步行前往。

3. 金宁 (从咸德约10分钟) — 在这里停车,步行逛21街·22街。只对上休息日,选两家左右。

4. 月汀里 (从金宁约10分钟) — 今天也晴朗。海滩在前排,这家在后面的小巷。

5. 细花 (从月汀里约10分钟) — 咖啡汉拿山。

6. 城山 (从细花约15分钟) — 奥伦或弗里茨。与日出峰行程串起来。

穿插中山间的变化路线: 从金宁或月汀里向南绕出去,经过松堂(友情园面包房),就能与榧子林·龙眼岳串成一线。

早上先看日出峰 → 向西返回的逆序也可以。弗里茨(08:00) → 奥伦(10:30) → 细花 → 金宁 → 咸德 → 新村。不过新村德仁堂17:00关门,把最后一格放在那里时间会很紧。

⚠ 常见错误3条

1. 不看休息日就去金宁 — 古阿宇巧克力是周二·周三,大海是金宁是周四休息。以金宁为目标的那天,先定星期几。六家聚在一起,一家关门也能换,但如果是专程为某一家去的,就是白跑一趟。

2. 把德仁堂·奥伦的隔周休息当成按月休息 — 新村德仁堂是每月第二个·第四个周日,奥伦是每月第二个·第四个周三休息。不是"周日休息"或"周三休息",而是当月的第二个·第四个。

3. 下午晚些才出发 — 营业时间已确认的6家中有一半17:00关门(德仁堂·古阿宇巧克力·大海是金宁)。营业到晚上的只有奥德朗面包房(22:00)·奥伦(20:00)·弗里茨(19:00~20:00)左右。东部咖啡厅的行程以上午开始为基本。

⚙ 常见问题解答(FAQ)3个

Q. 为什么几乎没有海景咖啡厅?

是故意去掉的。"济州海景咖啡厅"的清单已经很多,不管看哪里出现的都是同样几家。这一篇以面包店·甜点专门店为轴来挑选,避免与那些清单重复。如果想要能看见海的位置,本篇的大海是金宁·奥伦·弗里茨济州城山店同时满足这个条件。

Q. 一天能去几家?

面包店不会在一家坐很久,所以四五家没有压力。在金宁步行串联两三家,数字会涨得很快。不过如果每家咖啡厅都要坐下来休息,三家左右比较现实。

Q. 在Naver地图上搜什么?

直接输入韩文店名更准确。也可以把表中的道路名地址粘贴进去。用品项搜索,如济州大麦面包 (Jeju Boribbang / 제주 보리빵)·蒜香法棍 (Manong Baguette / 마농바게트),会一并出现同系列的其他分店——德仁堂和奥德朗面包房在济州岛内有多家分店,所以要确认是总店还是分店。
