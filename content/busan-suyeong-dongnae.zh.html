釜山原点，水营·东莱 — 广安里背后的朝鲜王朝釜山

副标题: 如果说海云台、广安里是"游客的釜山"，其背后还有釜山发轫的两个老城——朝鲜行政中心东莱，与水军营地水营。地铁3号线串起的"原版釜山"一日路线。

ISSUE · #1329 · 2026-08-24

🎯 框架——海云台之前的釜山

釜山自开港(1876年)以后才作为港口城市兴起，在此之前，这一带的中心不是海边，而是内陆的东莱 (Dongnae / 동래)。壬辰倭乱首战之地东莱邑城、伽倻时代古坟群，以及朝鲜水军南部司令部庆尚左水营 (Gyeongsang Jwasuyeong / 경상좌수영)(如今"水营区"地名的由来)，都是那段历史留下的痕迹。看过广安大桥夜景(#1326)的话，不妨隔天各花半天走一走这两个老城——这是打开观光釜山"原始文件"的路线。

  • 交通骨架：地铁2·3号线。水营对应2·3号线水营站 (Suyeong Station / 수영역)，东莱对应1·4号线东莱站 (Dongnae Station / 동래역)、水安站 (Suan Station / 수안역) 一带——3号线直接连通两条轴线(参见#1325交通篇)。

① 水营半日——市场·水营城·F1963·望美单街(步行路线)

这是釜山市官方步行路线也收录的成熟动线，总步行约2.5~3小时，外加停留时间。

1. 水营站5号出口 → 水营八道市场 (Suyeong Paldo Market / 수영팔도시장)(步行约3分钟)——名副其实的拱廊市场，源自朝鲜左水营时代"汇聚八道物产"之意。不是旅游市场而是社区市场，鱼糕、小吃物价亲民

2. 市场 → 水营史迹公园 (Suyeong Sajeok Park / 수영사적공원)(步行约5分钟)——旧左水营城遗址。数百年树龄的黑松和城门遗迹尚存，旁边还有水营城村落博物馆

3. 史迹公园 → F1963(步行约15分钟)——由1963年建成的高丽制钢钢丝工厂整体改造而成的复合文化空间。书店、展厅、咖啡馆、庭院都嵌进原厂房骨架里，是以釜山尺度呈现首尔圣水洞式工厂改造的地方

4. F1963 → 望美单街 (Mangmi-dangil / 망미단길)(步行约5分钟)——望美洞住宅区巷弄里渗入咖啡馆、花店、小餐馆的新兴街区。与其说是商圈，更接近居民区——安静漫步是基本礼貌

广安里海滩(#243·#1023)与水营站步行相距15分钟——下午走完这条路线，傍晚接上广安里日落到广安大桥夜景，一天就完整了。

② 东莱半日——市场·葱煎饼·邑城·古坟群(步行路线)

1. 水安站5号出口 → 东莱市场 (Dongnae Market / 동래시장)(步行约5分钟)——猪蹄、刀削面、鱼糕琳琅满目的传统市场。目的只有一个：东莱葱煎饼

2. 东莱葱煎饼的门道：与普通葱煎饼不同，用鳀鱼高汤调和的米粉面糊煎制，外酥内软糯。相传朝鲜时代东莱府使曾以此进贡国王，是这一带的招牌——市场内的煎饼巷弄和区厅后方的专门老店(传承四代的名店最有名)都能尝到

3. 市场 → 东莱邑城北门·历史馆 (Dongnae Eupseong / 동래읍성)(上坡步行约20分钟)——1592年壬辰倭乱首战之地。沿城墙徒步的路线已修整完善，北门一带可俯瞰市区

4. 邑城 → 福泉洞古坟群 (Bokcheon-dong Gobungun / 복천동 고분군)·福泉博物馆(步行约15分钟)——伽倻时代古坟沿山脊如草坪山丘般延展。博物馆免费参观，山丘本身就是散步道

如果腿脚发软，就用东莱温泉(#269)泡汤收尾——从市场到温泉场只隔地铁一站。

③ 一天走完两个老城——推荐时间表

时间 动线
10:00 水安站 → 东莱市场吃葱煎饼早午餐
12:00 东莱邑城 → 福泉博物馆
15:00 乘3号线移动(约20分钟)→ 水营八道市场 → 水营史迹公园
16:30 F1963 → 望美单街喝咖啡
18:30 步行/公交前往广安里——日落与广安大桥夜景(#1326)
  • 想减轻体力负担，可以分两天各走半天。夏天最好把东莱邑城的上坡路安排在上午。

💡 慌张点

  • 东莱邑城不是"一座孤立城池"，而是散落在山脚下的遗迹群——在地图App上把北门·历史馆设为目的地才准确。
  • F1963内部设施(展览等)可能按星期不同而变动——出发前请查看官方公告。
  • 望美单街、水营的巷弄都是居民区。拍照请在店内进行，在巷弄里放低音量才是本地礼仪。
