釜山K-pop圣地巡礼 — 在BTS故乡,以粉丝身份行走的方法

副标题: 如果说首尔K-pop之旅(#221)是经纪公司大楼与周边店的城市,釜山就是根源之城。这里是智旻 (Jimin / 지민)·田柾国 (Jungkook / 정국) 两人的故乡,父亲经营的咖啡店与童年时的巷弄都原样留存。从不被假招牌骗到的方法、居民区里的粉丝礼仪,到新兴圣地(BOYNEXTDOOR)与追星远征结合的动线 — 整理了在釜山追星的语法。

ISSUE · #1323 · 2026-08-23

🎯 为什么是釜山

BTS七人中有两人 — 智旻和田柾国出身釜山。如果说首尔的K-pop圣地是"公司"(HYBE·SM·JYP),釜山的圣地就是"故乡":父亲开的咖啡店、上小学的上学路、童年时的街区。所以釜山巡礼与首尔的语法不同 — 这是一段用脚步丈量日常痕迹而非华丽展馆的旅程,礼仪也因此更加重要。这甚至是釜山市官方旅游网站(visitbusan)会直接介绍巡礼路线的公认主题。

① BTS轴线 — 智旻·田柾国的釜山

智旻 (Jimin / 지민): 父亲的咖啡店 ⚠ 招牌注意

  • 智旻父亲经营的咖啡店原名是ZM-illennial(原名'Magnate')。因商标问题改了名字,附近挂着'Magnate'招牌的店与其家人无关、是另一家独立店铺,官方甚至为此发过公告。粉丝该去的是ZM-illennial — 这是本篇最重要的一句话。
  • 每逢退伍·纪念日都会举办粉丝应援活动,连海外阿米(ARMY)的信箱都挂在店里,是一处现役圣地。

田柾国 (Jungkook / 정국): 北区万德洞 (Mandeok-dong / 만덕동)的童年街区

  • 乐高村 (Lego Village / 레고마을) — 五颜六色的屋顶看起来像乐高积木、建于1986年的小型公寓区。已成为粉丝之间公认的、田柾国成长街区的象征地标。
  • 白杨小学 (Baekyang Elementary School / 백양초)·白杨中学 (Baekyang Middle School / 백양중) 等学校景点都是有在校生就读的真实学校 — 只能在校外安静观看。

两人共同: 甘川文化村 (Gamcheon Culture Village / 감천문화마을) 壁画

  • 甘川文化村里有一幅田柾国·智旻手持玫瑰的壁画 — 与釜山代表性拍照点和追星路线重叠,是最容易加进一般旅行动线的一站。

② 新生代轴线 — BOYNEXTDOOR的BASECOFFEE

位于东莱 (Dongnae / 동래) 福泉洞 (Bokcheon-dong / 복천동)、要走下台阶的地下咖啡店BASECOFFEE,因被认出是BOYNEXTDOOR 李韩 (Han / 이한) 家人经营的店而成为粉丝圣地。贴满墙面的粉丝便利贴、随处可见的痕迹,乃至仔细找就能看到的签名 — 都在昭示第四代粉丝巡礼的开端。因为紧邻东莱邑城 (Dongnae Eupseong / 동래읍성)·福泉博物馆 (Bokcheon Museum / 복천박물관),很自然就能并入东莱散步动线。

③ 活动轴线 — 亚运主竞技场就是K-pop赛场

釜山亚运主竞技场 (Asiad Main Stadium / 아시아드 주경기장) 如今已是K-pop日历上的固定舞台:

  • 2022年BTS《Yet to Come in BUSAN》 — 为申办世博会祈愿而举办的免费演唱会,那天整座城市都染成了紫色。
  • 2026年6月BTS釜山演唱会 — 七人全员回归巡演的釜山场。
  • 2026年9月19日The Fact Music Awards — RIIZE·崔艺娜 (Choi Yena / 최예나) 等阵容的颁奖典礼。

模式只有一个:追演唱会+圣地巡礼一次搞定 — 演唱会前一天安排万德·甘川,当天亚运主竞技场,第二天东莱咖啡店轴线,两天三夜的行程就此完成(骨架参考#1114)。

🙏 粉丝礼仪五条(本篇正体)

1. 在咖啡店圣地,先点单 — 不要只顾拍照就离开。

2. 乐高村·住宅区是居民生活的地方 — 禁止拍摄大门·窗户,压低音量。

3. 学校只能在校外。无论出于什么理由都不可进入校内。

4. 便利贴·留言本只能贴在店家准备好的空间里。

5. 禁止在壁画·招牌上涂鸦 — 为下一位粉丝原样留住它。
