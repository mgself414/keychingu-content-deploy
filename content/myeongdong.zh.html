外国游客在明洞 (Myeongdong / 명동) 常犯的5个错误

1. 没有在明洞路边兑换点换汇

明洞 (Myeongdong / 명동) 路边有比机场汇率更好的兑换点 — 比仁川机场 (Incheon Airport / 인천공항) 或银行好2~3%。兑换₩100,000可多得₩2,000~3,000。先换汇再逛街是正确打开方式。

2. 忘记收集退税收据 (₩30,000+)

韩国外国人退税：单张收据₩30,000以上 + 外国护照 = 退还9~10%。将美妆·百货收据放在信封里保管 → 在店内即时退税台 (Olive Young (Olive Young / 올리브영) / Innisfree (Innisfree / 이니스프리) 等) 或仁川机场 (Incheon Airport / 인천공항) 退税柜台统一处理。

3. 分不清明洞饺子 (Myeongdong Gyoja / 명동교자) 和普通饺子店

明洞饺子 (Myeongdong Gyoja / 명동교자)（60年老店）是韩国手工饺子与刀切面第一名。价格看似相近，但品质差距巨大。想吃饺子：明洞饺子本店 (Myeongdong Gyoja / 명동교자)，别无其他。

4. 只吃街头小吃错过正餐名店

街头小吃 (₩3,000~5,000) 性价比高，但跳过明洞饺子 (Myeongdong Gyoja / 명동교자) · 河东馆 (Hadongwan / 하동관) · 晋州会馆 (Jinjuhoeegwan / 진주회관) 就少了明洞一半的体验。午餐去老字号是正确选择。

5. 没有拍明洞圣堂 (Myeongdong Cathedral / 명동성당) 和明洞街 (Myeongdong-gil / 명동길)

明洞圣堂 (Myeongdong Cathedral / 명동성당)（1898年，韩国首座哥特式大教堂）+ 明洞街 (Myeongdong-gil / 명동길)（购物主街）= Instagram首选打卡地。只购物不拍照等于只体验了明洞的一半。

换汇·退税全指南

换汇 (Money Exchange)

  • 明洞 (Myeongdong / 명동) 路边兑换点 = 韩国汇率最优 — 比仁川机场 (Incheon Airport / 인천공항) 或银行好2~3%
  • 明洞街 (Myeongdong-gil / 명동길) 一带多处（招牌：换汇 / Exchange）
  • 兑换₩100,000多得₩2,000~3,000
  • 营业时间 10:00~22:00
  • 推荐现金换汇后用于街头美食

退税 (Tax Refund)

  • 单张收据₩30,000以上 + 外国护照 = 退还9~10%
  • 即时退税台（Olive Young (Olive Young / 올리브영)·Innisfree (Innisfree / 이니스프리) 等店内）— 结账时直接扣减
  • 机场退税柜台 — 仁川机场 (Incheon Airport / 인천공항) 出境通道内
  • 需凭收据·护照·同一张卡

FAQ

Q1. 能用英语沟通吗？

100%。明洞 (Myeongdong / 명동) 门店是韩国最擅长接待外国游客的地方。

Q2. 在哪里换汇？

明洞 (Myeongdong / 명동) 路边兑换点 = 汇率第一。不推荐银行。

Q3. 有素食餐厅吗？

明洞饺子 (Myeongdong Gyoja / 명동교자) 和河东馆 (Hadongwan / 하동관) 均以肉类为主。素食请参考 #69。

Q4. 带孩子同行？

河东馆 (Hadongwan / 하동관) 牛骨汤 + 百货美食广场均OK。明洞饺子 (Myeongdong Gyoja / 명동교자) 也有儿童友好菜单。

Q5. 只有1小时？

Olive Young (Olive Young / 올리브영) 30分钟 + 明洞饺子 (Myeongdong Gyoja / 명동교자) 30分钟 = 1小时速览路线。

Q6. 周日营业吗？

大多数营业。百货公司每月第三个周日部分休业。

Q7. 明洞 (Myeongdong / 명동) 街头美食哪个最好吃？(Best street food in Myeongdong?)

炸鸡串 (닭꼬치) + 煎饼 (Hotteok / 호떡) + 奶油虾 (크림새우) 是外国游客前三名。17:00后摊位全开 — 准备现金₩20,000~30,000。

Q8. 明洞 (Myeongdong / 명동) 以什么著名？(What is Myeongdong famous for?)

K-Beauty（Olive Young (Olive Young / 올리브영) · Innisfree (Innisfree / 이니스프리) · ETUDE (ETUDE / 에뛰드)）+ 街头美食夜间摊位 + 明洞饺子 (Myeongdong Gyoja / 명동교자) 60年老店 + 换汇·免税 — 外国游客购物·美食·体验一站式街区。

Q9. 在明洞 (Myeongdong / 명동) 需要待多久？(How long to spend in Myeongdong?)

最少2小时（Olive Young (Olive Young / 올리브영) + 街头美食）。推荐半天（4~5小时） — 美妆三巨头 + 午餐老字号 + 夜间街头摊位 + 明洞圣堂 (Myeongdong Cathedral / 명동성당)。
