外国人常犯的5大错误

1. 不在明洞路边换汇所换钱

明洞有许多汇率比机场更优惠的路边换汇所。比仁川机场或银行汇率高出2~3% — 换₩100,000 可多得₩2,000~3,000。初次来访请务必先在明洞换汇再开始游览。

2. 忘记收集退税小票 (₩30,000以上)

韩国外国人退税规则：单张发票满₩30,000 + 外国护照 即可享受9~10%退税。建议将美妆·免税店发票统一放入信封，在明洞即时退税窗口 (悦诗风吟 / 悦诗风吟 (Innisfree / 이니스프리)·爱丽小屋 (Aritaum / 아리따움) 店内) 或机场退税柜台统一办理。

3. 分不清明洞饺子 vs 普通饺子店

明洞饺子 (Myeongdong Gyoja / 명동교자) 拥有60年历史，是韩国手工饺子正宗第一名 — 手工包制刀削面+饺子。与普通明洞饺子店价格相近，但品质差距极大。想吃饺子，认准明洞饺子本店 (Myeongdong Gyoja / 명동교자)。

4. 只吃街头小吃就离开

明洞街头小吃 (₩3,000~5,000) 性价比高，但若错过明洞正宗老店 (明洞饺子 / Myeongdong Gyoja / 명동교자·河东馆 / Hadongwan / 하동관·晋州会馆 / Jinjuhoegwan / 진주회관)，等于损失了一半体验。午餐请选择正宗老字号。

5. 不拍明洞大教堂·明洞街照片

明洞大教堂 (Myeongdong Cathedral / 명동대성당，1898年韩国首座哥特式建筑) + 明洞街 (Myeongdong-gil / 명동길，购物主街) = Instagram打卡第一选择。只购物不拍照，等于只体验了半个明洞。

换汇·退税完整指南

换汇 (Money Exchange)

  • 明洞路边换汇所 = 比仁川机场·银行汇率高出2~3%
  • 明洞街一带多处 (招牌写有"환전 / Exchange")
  • 换₩100,000 可多得₩2,000~3,000
  • 营业时间 10:00~22:00
  • 推荐换现金而非刷信用卡

退税 (Tax Refund)

  • 单张发票满₩30,000 + 外国护照 = 退税9~10%
  • 即时退税窗口 (Olive Young / 올리브영·悦诗风吟 / Innisfree / 이니스프리 等店内) — 结账时直接扣除
  • 机场退税柜台 — 仁川机场出境安检区内
  • 须携带发票·护照·原支付卡

FAQ

Q1. 能说英语吗？

100%可以。明洞是韩国接待外国游客经验最丰富的区域。

Q2. 在哪里换汇？

明洞路边换汇所 = 汇率最优。不推荐银行换汇。

Q3. 有纯素食餐厅吗？

明洞饺子 (Myeongdong Gyoja / 명동교자)·河东馆 (Hadongwan / 하동관) 均以肉类为底。纯素食请参考 #69 素食指南。

Q4. 带小朋友合适吗？

河东馆 (Hadongwan / 하동관) 牛骨汤 + 百货美食广场适合亲子。明洞饺子 (Myeongdong Gyoja / 명동교자) 亦有儿童友好菜品。

Q5. 只有1小时怎么安排？

Olive Young (올리브영) 30分钟 + 明洞饺子 (Myeongdong Gyoja / 명동교자) 30分钟 = 1小时精华压缩版。

Q6. 周日营业吗？

大部分正常营业。百货公司每月第三个周日部分门店可能休息。
