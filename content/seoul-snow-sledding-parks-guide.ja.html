ソウル雪ソリ場ガイド — 6,000ウォンの漢江ゲレンデからテーマパークの無料ソリまで、初めて雪を見る家族のための料金・期間・駅の出口

サブタイトル: 漢江の3つの雪ソリ場(トゥクソム・蚕院・汝矣島)は全年齢6,000ウォンでチューブ型ソリ込み、毎日13~14時は整備でゲレンデが使えない(ソウル市公式) · 子ども大公園のSLP子ども会館雪ソリ場は15,000ウォン · ソウルランド・エバーランドは入園券を買えばソリは無料(二次情報) · 蘆原・瑞草などの区営雪ソリ場は2,000~8,000ウォン — 日付・料金は2025-26シーズンの公告基準、2026-27シーズンは12月の公告で再確認

ISSUE 03 · #1416 · 2026-10-19

🎯 この回が答える質問

「子どもが雪を見たことがないのですが、ソウルで雪ソリに乗れますか」「スキー場まで行かずに半日で済ませたい」 — 東南アジア・台湾・香港から来る家族旅行者が冬になると必ず聞く質問です。答えは「乗れるし、安い」。ソウル市は漢江 (Hangang / 한강) 沿いの公園3か所に人工雪のゲレンデを作り、各区は大学のグラウンドやプール跡地に臨時のソリ場を設け、郊外のテーマパークは入園者にソリを無料で乗せてくれます。この回では9か所の料金・期間・地下鉄の出口を1枚の表にまとめ、外国人向けの記事でいつも抜けている整備時間と無料入場の証明のルールを補います。

⚠ 日付・料金は2025-26シーズン(2025年12月~2026年2月)の公告基準です。雪ソリ場は毎年12月上旬~中旬にその年の運営計画を公告し、予告された開場日が後ろにずれることもあります。2025-26の漢江雪ソリ場は12月19日開場と予告されていましたが、実際には12月31日に開きました。出発前に下のSOURCESにあるソウル市の冬ガイドページを一度開いてみてください。

① 漢江の雪ソリ場3か所 — ソウル市が直営する基本形

3か所のルールは同じです。ソウル市の公告(2025-26)をそのまま写します。

  • 期間・時間: 2025-12-31~2026-02-18、50日間休みなし · 毎日10:00~17:00
  • 整備時間: 毎日13:00~14:00は雪面の整備でゲレンデが使えません。昼食をこの時間に合わせれば損がありません
  • 料金: 全年齢6,000ウォン均一。チューブ型ソリのレンタル・雪遊び広場 (nunnori-dongsan / 눈놀이동산) ・休憩スペースの利用が含まれ、ソリのレンタル料は別にかかりません
  • 無料・割引: 36か月未満は生年月日の証明書類を出せば無料(安全上ソリには乗れません) · 65歳以上・障がい者・国家功労者・ソウル市の多子女カード (Dadungi Card / 다둥이카드) 保持者は証明で50%割引。外国人旅行者の証明はパスポート — 幼児の無料入場を望むなら必ず持参
  • ゲレンデ: 大型80m(6歳以上~大人) · 小型30m(36か月~6歳) · 幼児向けの雪遊び広場
  • 安全: 3か所とも医務室(AED付き)を運営

2025-26は3か所ともポロロ (Pororo / 뽀로로) をテーマに飾られました。トゥクソム「ポロロ世界雪祭り」、汝矣島「ルーピー (Loopy / 루피) と雪の花パーティー」、蚕院「雪に覆われたポロロの森の村」です。汝矣島では11:00にキャラクターパレード、12:30・14:30にシングアロングショーがあり、テントのフードコートでラーミョン (ramyeon / 라면) ・トッポッキ (tteokbokki / 떡볶이) ・カップパプ (cup-bap / 컵밥) ・ホットドッグ・サンドイッチを売っていました。荷物預かりは5,000ウォン(ポロロのバッグ付き)、ワカサギ釣り (bingeo-japi / 빙어잡이) やミニバイキングなどの有料遊具は4,000~7,000ウォン台でした(二次)。

場所別の行き方(ソウル市メディアハブ実測)

  • トゥクソム: 7号線紫陽駅2番出口 → 徒歩5分。ソウル市の案内ページはトゥクソム遊園地駅 (Ttukseom Yuwonji Station / 뚝섬유원지역) でも案内しています — ソリ場は2つの駅の間の公園内にあります。問い合わせ 02-452-5955
  • 蚕院: 3号線蚕院駅4番出口 → 徒歩20分。3か所で最も遠い。ベビーカーや小さな子ども連れならトゥクソム・汝矣島が楽です。夜間は12/31から1月上旬まで毎日、その後は土・日・祝日に20時まで営業 — 夜間の日程は情報源ごとに日付の表記が違うので訪問前に確認。問い合わせ 02-536-8263
  • 汝矣島: 9号線国会議事堂駅1番出口 → 徒歩15分。汝矣島漢江公園のプール跡地(第3駐車場の隣)にあります。問い合わせ 02-785-0478

入場券: 現地の券売所で買います。2025-26はオンライン予約も案内されていました(二次)。カードが使えるかは今回確認できませんでした — 少額の現金を持っていきましょう。

② 子ども大公園のSLP子ども会館雪ソリ場 — ワカサギ釣りまでセットで

  • 料金: 雪ソリ場の入場券15,000ウォン · ワカサギ釣り体験券6,000ウォン(網・バケツ付き)
  • 期間: 2025-12-21~2026-02-23、天候により変動。運営時間は公告にないので電話で確認(1800-5309)
  • ゲレンデ: 初級・上級の2本。36か月未満は上級を利用できず、36か月以上7歳未満は初級のみ
  • 行き方: 7号線子ども大公園駅2番出口
  • 漢江より2.5倍高い代わりにワカサギ釣りが付き、子ども大公園そのものは入園無料なので動物園・遊び場まで半日が埋まります

③ テーマパーク2か所 — 入園券を買えばソリは無料

  • ソウルランド・スノーファンランド(果川): 120mの一般ゲレンデ + 50mの幼児ゲレンデ、約8,500㎡の規模。雪ソリ場・雪遊び場はソウルランド入園者なら誰でも無料、ワカサギ釣りは別料金で現地先着順。2025年12月27日開場、終了日は公告にありません(通常は2月)。4号線大公園駅2番出口から象列車(有料)または徒歩(ニューシス 2025-12-29 [二次])
  • エバーランド・スノーバスター(龍仁): 12月12日にレーシングコース・スノーヤード、12月19日にスノープレイグラウンド(雪の滑り台・ボディスライド・雪合戦の的・木のソリコース)が順次開場。200mのエクスプレスコース(丸いチューブ、最大4人)は天候により1~2月に運営。エバーランド利用者は無料、通常2月中旬まで。龍仁軽電鉄エバーランド駅から無料シャトル(ヘラルド経済 2025-12-10 [二次])
  • 2園の入園券の値段は毎年変わり、外国人向けの割引商品も多いので、この回には書きません。公式サイトで確認してください

④ 区営の雪ソリ場 — 区民は無料、旅行者は「それ以外」料金

各区が冬にひと月余り運営する臨時のソリ場です。漢江より安いか無料ですが、期間が短く、月曜休みが多いです。

  • 蘆原シンシン雪ソリ場: ソウル科学技術大学の総合グラウンド。2025-12-23~2026-01-25、10~17時。大人用ゲレンデ90m・7レーン、子ども用50m・5レーン(自動スタート台)。蘆原区民は無料、それ以外は3,000ウォン。ワカサギ釣り・焼き栗 (gunbam / 군밤) ・ユーロバンジー。1月に大学入試の関係で2日休場 — 日付は情報源ごとに違うので訪問前に確認(ソウル新聞 2025-12-08 [二次])
  • 瑞草・良才川冬の雪遊び場: 良才川プール。2025-12-20~2026-02-22、火~日10~17時、月曜とソルラル (Seollal / 설날) 当日(2/17)は休み。瑞草区民6,000ウォン、それ以外8,000ウォン。大人用・幼児用ゲレンデ、トランポリン・幼児用エアバウンス・ワカサギ釣り・カーリング・売店(ヘラルド経済 2025-12-17 [二次])
  • 道峰ウィンタースノーランド: 道峰駅前のグラウンド跡地。2024-25シーズンは12/27~2/2、火~日10~17時、道峰区民は無料・それ以外2,000ウォン、バンパーカー・ミニ列車・ワカサギ釣り。2025-26の運営有無は今回確認できませんでした(ソウル市メディアハブ 2025-01-21)
  • 区民料金は住民登録基準なので、旅行者は全員「それ以外」料金です。それでも2,000~8,000ウォンなら漢江と同じか安い

⑤ 半日コース3案

A. トゥクソム(東側、開場直後を狙う)

10:00 紫陽駅2番出口 → 徒歩5分 → トゥクソム雪ソリ場(開場直後は待ち時間が短い) → 12:50にソリを切り上げ → 13:00~14:00の整備時間にフードコートでラーミョン → 14:00にもう一度乗るか、紫陽駅 → 7号線で1駅 → 建大入口駅 (Konkuk University Station / 건대입구역) の飲食店街・Common Ground

B. 汝矣島(西側、屋内避難と組み合わせ)

10:30 国会議事堂駅1番出口 → 徒歩15分 → 汝矣島雪ソリ場 → 11:00パレード → 13:00の整備時間に昼食 → 14:30シングアロングショー → 汝矣島駅 (Yeouido Station / 여의도역) → 汝矣島駅と地下でつながるThe Hyundai Seoulで体を温める

C. 子ども大公園(子どもが2人以上)

10:00 子ども大公園駅2番出口 → SLP子ども会館雪ソリ場 → ワカサギ釣り → 子ども大公園の動物園・遊び場(無料) → 7号線で1駅 → 建大入口駅

⑥ 服装・持ち物・現地のルール

  • 防水パンツ・手袋・防水の靴: チューブ型ソリはズボンが濡れます。替えの靴下1組とホットパック (hot pack / 핫팩) (コンビニで1,000~2,000ウォン)を持参。寒さ対策全般は #1318
  • 年齢基準: 大型ゲレンデは6歳以上、36か月未満はソリ禁止(無料入場のみ)。小型ゲレンデも保護者同伴
  • 13~14時: 漢江の3か所は整備で止まります。昼食の時間に使いましょう
  • 混雑: 週末の午後は列が長い。平日か開場直後のほうが良い
  • 天気: 人工雪なので雪が降らなくても開きます。雨・強風・寒波警報では短縮・中止もあるので当日の告知を見ましょう

⚠ 実際にはまる落とし穴5つ

1. 13時に到着 — 整備時間なので1時間待ちます。10時か14時に合わせましょう。

2. 蚕院駅から20分歩く — ベビーカー・小さな子ども連れにはつらい。トゥクソム(5分)・汝矣島(15分)を選びましょう。

3. 36か月未満の無料は証明があるときだけ — パスポートがなければ6,000ウォンを払います。

4. 区営ソリ場の「無料」は区民だけ — 旅行者は2,000~8,000ウォン。

5. 予告された開場日を信じて日程を組む — 2025-26の漢江は12/19予告 → 12/31開場。12月中旬に旅行する人は出発前に公告をもう一度見ましょう。

⚙ FAQ 3

1. 雪が降らないと乗れませんか? — 人工雪なので関係ありません。漢江の3か所は2025-26に50日間休みなしで開きました。

2. 大人も乗れますか? — 大型ゲレンデは6歳以上から大人まで、料金は全年齢同じです。

3. スケートはどこで? — ソウル広場スケート場 (Seoul Plaza Skating Rink / 서울광장 스케이트장) が1回1時間1,000ウォン(ヘルメット・スケート靴のレンタル込み、2025-12-19~2026-02-08、ソウル市公式)。雪景色・アイスリンクは #1319。
