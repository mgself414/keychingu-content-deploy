한국 T-money·결제·환승 풀가이드 — 외국인 inbound 1순위 페인포인트

> 부제: T-money·캐시비·모바일 페이·신용카드·외국인 친화 결제 풀세트 (지하철·버스·KTX·택시 통합)

ISSUE 03 · #238 · 2026-05-19

🎯 왜 한국 T-money 풀가이드인가

외국인 한국 inbound 페인포인트 1순위 = 결제·교통카드. 한국 T-money + 캐시비 + 모바일 페이 + 신용카드 + 외국인 친화 (Visa·Master·JCB·UnionPay·아멕스) 풀세트 통합. 외국인 첫 도착 30분 안에 해결해야 할 1순위.

★ 한눈에 12선

# 결제·카드 4축 시그니처
1 T-money 카드 ★ 한국 1번지 교통카드 4,000원·편의점·역·외국인 1순위
2 캐시비 교통카드 T-money 대안·롯데·BC카드 통합
3 레일플러스 (RailPlus) 교통카드 KTX·SRT + 일반 교통 통합
4 WOWPASS ★ 외국인 전용 외국인 카드 T-money + 외화 환전 + 결제 통합 (2022)
5 Korea Tour Card 외국인 카드 외국인 전용 + 면세·관광 할인
6 모바일 T-money (안드로이드 NFC) 모바일 페이 Naver Pay·Toss·KakaoPay 결제 OK
7 삼성페이 + Apple Pay 모바일 페이 외국인 카드 등록 가능 (Visa·Master)
8 신용카드 직접 결제 (지하철·버스 일부) 모바일 페이 2024 확장·해외 Visa·Master·JCB·UnionPay·아멕스 OK
9 KakaoT 택시 (Kakao Taxi) 택시·차량 외국인 1순위 + 영문 OK + 카드 결제
10 Uber Korea + Tada + UT 택시·차량 외국인 매니아·Uber 글로벌·UT 일본 통합
11 카드 캐시백·환급 외국인 환급 30,000원 이상 면세 환급 + 외국인 환급 1번지
12 외국인 환전 + 외화 ATM 외국인 환급 명동·인천공항·홍대·종각 환전소·은행

+ 추가 4: T-money 환승 룰·해외 단말기 결제·외국인 SIM·외국인 친화 ATM (Citibank·StanChart·하나·신한)

⚠ 외국인 자주 실수 5가지

1. "T-money = 충전식만": T-money 3종 — (1) 1회용 (역 발권기) (2) 충전식 (편의점) (3) 모바일 T-money (NFC). 충전식이 외국인 1순위 (4,000원 + 충전).

2. "환전 = 어디나": 한국 환전 1번지 = 명동·인천공항·홍대·종각·이태원 + 은행 (외환·우리·하나·KB). 명동 = 가장 좋은 환율 (사설 환전소 1번지). 인천공항 = 가장 나쁜 환율.

3. "신용카드 = 어디나 OK": 한국 신용카드 일반 OK (Visa·Master·JCB·UnionPay·아멕스) + 일부 작은 가게 = 현금만. T-money + 신용카드 + 현금 50,000원 정도 보유 권장.

4. "외국인 환급 = 자동": 면세 환급 (Tax Refund) = 사후 환급 (영수증 제출 + 환급 카드). 30,000원 이상 + 외국인 여권 필수 + 인천공항·김포공항·홍대 환급 1번지.

5. "WOWPASS = 한국 T-money와 같음": WOWPASS = 외국인 전용 + 외화 환전 + 결제 통합 (2022). T-money 기능 + 외국인 친화 1순위. 외국인 inbound 1순위 카드.

① 교통카드 (4)

1. T-money 카드 ★ 한국 1번지

  • 외국인 ★: ◎◎ — 한국 1번지 교통카드
  • 발급: 편의점 (CU·GS25·세븐일레븐·이마트24·미니스톱) 4,000원 + 충전
  • 환승: 30분 이내 다른 노선·버스 무료 (최대 4 환승)
  • 잔액 환불: 500원 보증금 미환불

2. 캐시비 (Cashbee)

  • 외국인 ★: ◎ — T-money 대안 + 롯데·BC카드 통합
  • 발급: 편의점 + 일반 카드처럼 사용

3. 레일플러스 (RailPlus)

  • 외국인 ★: ◎ — KTX·SRT + 일반 지하철·버스 통합
  • 발급: KORAIL 역 + 외국인 KTX 매니아 1순위

4. WOWPASS ★ 외국인 전용

  • 외국인 ★: ◎◎ — 외국인 전용 카드 + 외화 환전 + T-money + 결제
  • 발급: 명동·인천공항·홍대 WOWPASS 키오스크 + USD·JPY·CNY·EUR 환전 + 즉시 발급

② 외국인 카드 (1)

5. Korea Tour Card

  • 외국인 ★: ◎ — 외국인 전용 카드 + 면세·관광지 할인
  • 발급: 인천공항 + 명동 + 홈페이지

③ 모바일 페이 (3)

6. 모바일 T-money (안드로이드 NFC)

  • 외국인 ★: ◎ — 안드로이드 NFC + Naver Pay·Toss·KakaoPay 결제 (2024 확장)
  • 아이폰 미지원

7. 삼성페이 + Apple Pay

  • 외국인 ★: ◎ — 외국인 카드 등록 (Visa·Master) + 매장 결제
  • 한국 매장 90%+ 지원

8. 신용카드 직접 결제

  • 외국인 ★: ◎ — 2024 확장 + 지하철·버스 일부 역 직접 결제
  • Visa·Master·JCB·UnionPay·아멕스 OK

④ 택시·차량 (2)

9. KakaoT 택시 (Kakao Taxi)

  • 외국인 ★: ◎◎ — 한국 1번지 택시 앱 + 영문 OK + 카드 결제

10. Uber Korea + Tada + UT

  • 외국인 ★: ◎ — Uber 글로벌·UT 일본 통합·Tada 한국형

⑤ 외국인 환급 (2 + 추가 4)

11. 카드 캐시백·환급

  • 30,000원 이상 면세 환급 (Tax Refund) + 외국인 여권 + 인천·김포공항 환급

12. 외국인 환전 + 외화 ATM

  • 명동·인천공항·홍대·종각 환전소·은행 + Citibank·StanChart·하나·신한 외화 ATM

+ 추가 4

  • T-money 환승 룰: 30분 이내 다른 노선·버스 환승 무료 (최대 4 환승)
  • 해외 단말기 결제: 한국 매장 일반 OK + 단말기 외국 카드 인식 (소수 예외)
  • 외국인 SIM: 인천공항 + 명동 + 홍대 외국인 SIM (KT·SK·LG U+) + eSIM 확장
  • 외국인 친화 ATM: 인천공항·명동·홍대 24시간 외화 ATM (Citibank·StanChart·하나·신한)

⚙ FAQ 8개

1. 외국인 T-money 발급 1순위: 인천공항 + 편의점 + WOWPASS (외국인 전용 + 환전 통합).

2. 모바일 T-money 사용: 안드로이드 NFC + Naver Pay·KakaoPay·Toss 결제. 아이폰 미지원.

3. 환전 1순위: 명동 사설 환전소 (가장 좋은 환율) → 은행 (외환·우리·하나·KB) → 인천공항 (가장 나쁜 환율).

4. 신용카드 결제: 한국 90%+ 매장 OK (Visa·Master·JCB·UnionPay·아멕스). 일부 작은 가게 현금만 + 현금 50,000원 보유 권장.

5. 외국인 환급 (Tax Refund): 30,000원 이상 + 외국인 여권 + 영수증 제출 + 인천·김포공항 환급 부스 (출국 전 90분 여유).

6. 카카오T 외국인 사용: 영문 OK + 카드 등록 (Visa·Master) + 영수증 영문 가능.

7. 외국인 SIM·eSIM: 인천공항 + 명동 + 홍대 + KT·SK·LG U+ + eSIM (Airalo·Holafly 글로벌 OK).

8. 외화 ATM 24시간: 인천공항·명동·홍대·시청 Citibank·StanChart·하나·신한.

🗺 외국인 풀데이 코스 4개

A. 인천공항 도착 즉시 (외국인 첫 30분)

  • 입국 → 환전 (인천공항 또는 명동 도착 후) → T-money 또는 WOWPASS 발급 → 공항철도 → 호텔

B. 외국인 결제 1일 풀세트

  • 09:00 환전소 명동 → 10:00 T-money 충전 → 13:00 지하철·버스 환승 무료 → 17:00 매장 신용카드 → 20:00 카카오T 택시

C. 외국인 면세 환급 (출국 전)

  • 08:00 호텔 체크아웃 → 10:00 명동·홍대 영수증 정리 → 11:00 인천공항 환급 부스 (출국 전 90분 여유) → 면세 환급

D. 외국인 외곽 1일 (광역 + 다양 결제)

  • 09:00 T-money → 광역 9호선 → 강남 신용카드 → 카카오T 택시 → 외곽 모바일 페이

🌸 시즌·시간대 5

  • 연중: T-money 24시간 + 편의점 충전 OK
  • 인천공항 도착 19~22시: 환전 부스 한산 (도착 외국인 적음)
  • 명동 환전소: 09:00~21:00 (외환 직접 결제) + 환율 실시간 변동
  • 모바일 T-money 사용량: 2024 확장 + Naver Pay·KakaoPay·Toss 외국인 결제
  • 외국인 환급: 명절 (설날·추석) 인천공항 환급 부스 인파 폭발 → 출국 전 2시간 여유 필수
