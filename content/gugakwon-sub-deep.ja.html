このガイドは、ソウル 瑞草洞 (Seocho-dong / 서초동) の国立国楽院1か所にまとまっている機関・公演場・博物館と、朝鮮王室の祭礼音楽を見られる宗廟大祭をまとめたものです。国立国楽院、礼楽堂、国立国楽博物館は住所が同じです。公演の料金は公演ごとに異なるため登録されている固定料金はなく、博物館は入場無料で登録されています。

📍 国立国楽院 (ソウル 瑞草区)

国立国楽院 (Gungnip Gugagwon / 국립국악원) (瑞草区 Nambusunhwan-ro 2364 (남부순환로 2364)、☎ 02-580-3300) は、韓国の伝統公演芸術を受け継ぐ国立の芸術機関です。公演とともに、学術研究、国楽教育、海外交流を行っています。

国立国楽院は、新羅時代以降に伝わってきた宮中音楽機関に起源があります。光復の後に宮中音楽機関が解体されて旧王宮雅楽部 (Gu-wanggung Aakbu / 구왕궁아악부) として残り、1951年に国立国楽院へとつながりました。職制は1950年に公布されましたが、戦争のため1951年に釜山で開院し、奪還の後、雲泥洞 (Unni-dong / 운니동) と奨忠洞 (Jangchung-dong / 장충동) の庁舎を経て、1987年に現在の瑞草洞の庁舎に移りました。観光公社の紹介(2010年基準)によると、文化体育観光部の所属機関で、正楽団・民俗楽団・舞踊団・創作楽団の四つの演奏団を運営していました。

  • 開く時間: 09:00~18:00。休み: 毎週日曜日。
  • 料金: 公演ごとに異なります。
  • 駐車: 無料。満車のときは、近くの有料駐車場を自己負担で利用します。

礼楽堂 (Yeakdang / 예악당) (同じ住所、☎ 02-580-3300) は、国立国楽院の中にある658席あまりの国楽専用公演場です。芸術の殿堂 (Yesurui Jeondang / 예술의전당) の隣にあります。客席は土塀の形に分かれていて、舞台の上には盾形の凧 (Bangpaeyeon / 방패연) の形をした音響反射板があります。3階建てで、1階と2階は階の区切りなくつながっていて、3階には「ピョルジャ (Byeoljwa / 별좌)」「ピョルウ (Byeoru / 별우)」というバルコニー席があります。おもに国楽管弦楽、楽歌舞総合劇 (Akgamu Jonghapgeuk / 악가무종합극)、ソリ劇 (Sorigeuk / 소리극) を公演します。

  • 公演時間・料金: 公演ごとに異なります。休み: 毎週日曜日。

📍 国立国楽博物館 (ソウル 瑞草区)

国立国楽博物館 (Gungnip Gugak Bangmulgwan / 국립국악박물관) (同じ住所、☎ 02-580-3130) は、国楽の遺物と楽器を展示する国楽専門の博物館で、1995年に開館しました。観光公社の紹介によると、国内唯一の国楽専門博物館です。韓国伝統音楽の歴史とジャンルを紹介する常設展示があり、海外の音楽遺物を招いた展示や、国立国楽院の楽器研究の成果展示などの特別展示も開かれます。2019年に新しく開いた常時展示室は、聴く機能を強化しました。所蔵する楽器、楽譜、楽書、服飾遺物を見て、体験できます。

  • 開く時間: 10:00~18:00(入場締切 17:30)。休み: 毎週月曜日(月曜日が祝日の場合は開き、翌日の火曜日に休みます)、1月1日。
  • 料金: 無料。駐車: 有料。

📍 宗廟大祭 (ソウル 鍾路区 宗廟)

宗廟大祭 (Jongmyo Daeje / 종묘대제) (鍾路区 Jong-ro 157 (종로 157) 宗廟 (Jongmyo / 종묘)、☎ 1522-2295) は、朝鮮王朝の歴代の王と王妃の位牌 (Sinju / 신주) をお祀りして捧げる祭礼儀式です。宗廟の正殿 (Jeongjeon / 정전) で、礼楽と佾舞 (Ilmu / 일무) がともに繰り広げられます。1969年に復元されて今まで続いていて、儀礼・舞踊・音楽が調和した総合儀礼としての価値が認められ、2001年にユネスコ人類無形文化遺産の代表一覧表に登録されました。2006年からは、国内外の来賓を招待する国際行事として開かれています。毎年5月の第1日曜日に開きます。

  • 2026年の日程: 2026年5月3日に宗廟で開かれました。時間は10:00~17:30、料金は無料でした。
  • プログラム: 永寧殿 (Yeongnyeongjeon / 영녕전) 祭享(10:00~12:00)、正殿祭享(14:00~16:30)、神室 (Sinsil / 신실) 観覧(16:30~17:30)。景福宮 興礼門 (Gyeongbokgung Heungnyemun / 경복궁 흥례문) の広場とYouTubeで生中継しました。
  • 関係機関: 国家遺産庁 (Gukgayusancheong / 국가유산청)、国家遺産振興院 (Gukgayusan Jinheungwon / 국가유산진흥원)。

⚠ 事前に知っておきたい3つのこと

  1. 休みの日が異なる — 国立国楽院と礼楽堂は毎週日曜日、国立国楽博物館は毎週月曜日に休みます。
  2. 公演料金は公演ごとに異なる — 国立国楽院と礼楽堂は、固定料金が登録されていません。国立国楽博物館は無料です。
  3. 2026年の宗廟大祭は終わった — 2026年5月3日に開かれました。毎年5月の第1日曜日に開きます。

Q. 宗廟大祭はいつ見られますか?
