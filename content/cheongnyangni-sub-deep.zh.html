外国游客常见的3个失误

失误1. 周日前往

清凉里综合市场内多数常设店铺周日休息。尤其青果·水产批发区,许多商户从周日上午起就开始收摊。老字号一条街周日营业的店铺也不到平日的一半。建议周二至周六前往,周一部分区域在补货,可选项目较少。

失误2. 只带信用卡出门

老字号与摊贩大多只收现金。综合市场本馆部分店铺虽有刷卡机,但对小额(1万韩元以下)消费常拒收或要求额外手续费。出发前取出现金3万~5万韩元即可从容应对。清凉里站内及站前便利店设有ATM。

失误3. 高峰时段(11~13点)进入老字号店铺

清凉里雪浓汤·汤饭老字号在上班族的午餐需求集中的11点30分~13点之间,排队时间可达30~60分钟。外国游客若想没有语言障碍地从容入座,10~11点或13点30分以后入店更为实际。部分店铺备料提前售罄,14点前就可能打烊。

12选4轴 — 分区深度解析

轴1:清凉里综合市场(3选)

#1 清凉里综合市场本馆

清凉里综合市场是自1960年代起形成的首尔东北部最大的批发·零售综合市场。干货·谷物·坚果·调味料集中在同一栋建筑内。

  • 营业时间:06:00~20:00(各店铺不同,周日多数休息)
  • 价格:干货每100克约₩2,000~8,000(品类差异较大,2026年)
  • 适合外国游客:★★★★ — 适合参观游览,部分店铺可小份量购买
  • 交通:1号线清凉里站1号出口步行5分钟
  • 是否可英语沟通:部分店铺可用基础英语(数字·品名),建议搭配翻译App
  • 最佳时段:上午9~11点选择最多。下午18点后开始收摊

外国游客常购买的品类是干海带·海带芽·芝麻·杂菜用粉丝·辣椒粉小份包装。挑选可提供真空包装的店铺,更容易符合登机行李规定。

#2 清凉里青果批发区

综合市场外围的路边摊与连接建筑内延伸着青果批发区。虽以箱为单位的应季水果批发交易为主,但也有商户兼营零售,可以单件购买。

  • 营业时间:04:00~16:00(批发高峰05~09点,零售10~15点)
  • 价格:草莓1盒(500克)₩5,000~8,000 / 西瓜1个₩15,000~25,000(依季节·品种浮动,2026年)
  • 适合外国游客:★★★ — 以大量购买为单位,少量购买者可能不便
  • 是否可英语沟通:不通,靠手指指认·计算器沟通
  • 最佳时段:零售购买以10~14点较为现实

#3 清凉里水产胡同

综合市场后方连接着水产专门胡同。新鲜鱼类、干货(黄花鱼干·明太鱼干·鱿鱼干·干明太鱼)、腌鱼类集中于此。

  • 营业时间:06:00~19:00(以干货店铺为准,鲜鱼可能14~15点提前打烊)
  • 价格:黄花鱼干10条₩15,000~40,000(依大小·品种),鱿鱼1条₩2,000~4,000(2026年)
  • 适合外国游客:★★★★ — 气味与视觉冲击强烈的市场体验,可要求真空包装
  • 是否可英语沟通:不通
  • 最佳时段:上午新鲜度最佳。干货下午也可购买

轴2:清凉里传统老字号(3选)

#4 清凉里雪浓汤·汤饭一条街

清凉里站周边的小巷内,聚集着以雪浓汤(Seolleongtang / 설렁탕)、血肠汤(Seonji Gukbap / 선지국밥)、血肠汤饭(Sundae Gukbap / 순대국밥)为主打的老字号。不少店铺营业年限在30~50年以上。招牌与内部装潢多年未变,复古氛围尤其受到JP客群的欢迎。

  • 营业时间:06:00~15:00(备料售罄可能提前打烊),部分24小时营业
  • 价格:雪浓汤1碗₩9,000~12,000 / 汤饭₩8,000~11,000(2026年)
  • 适合外国游客:★★★★★ — 点餐方式简单(菜单1~3种),小菜自助,可用翻译App应对招牌
  • 交通:1号线清凉里站2~3号出口步行3~7分钟的小巷内
  • 是否可英语沟通:不通。用手指点菜单或使用Google镜头
  • 最佳时段:10~11点或13点30分以后(避开高峰11:30~13:00)
  • 提示:骨汤为主的浓郁气味 — 若是第一次尝试韩式汤饭,雪浓汤比血肠汤饭门槛更低

#5 清凉里牛骨汤胡同

长时间炖煮牛骨·牛蹄制成的牛骨汤(Gomtang / 곰탕)专门老字号cluster。汤色比雪浓汤更清澈、味道更清淡,对外国游客而言接受门槛较低。基本吃法是将米饭拌入汤中,萝卜泡菜及其汤汁与牛骨汤相得益彰。

  • 营业时间:07:00~15:00前后(各店铺不同,周日多休息)
  • 价格:牛骨汤1碗₩9,000~13,000(2026年)
  • 适合外国游客:★★★★ — 汤色清澈,违和感较小
  • 是否可英语沟通:不通
  • 最佳时段:上午7~10点早餐时段,或11点休息前

#6 清凉里小吃·摊贩cluster

清凉里市场巷口及小巷内聚集着售卖辣炒年糕(Tteokbokki / 떡볶이)·血肠(Sundae / 순대)·鱼糕(Eomuk / 어묵)·油炸小吃的摊贩与小型小吃店。人均₩3,000~8,000,是首尔最低价位的小吃体验之一。

  • 营业时间:10:00~22:00(各店铺不同,夜间摊贩傍晚起营业)
  • 价格:辣炒年糕1人份₩3,000~4,000 / 血肠₩3,000 / 油炸小吃1个₩500~1,000(2026年)
  • 适合外国游客:★★★★★ — 指认点餐方式,花费低,适合拍照
  • 是否可英语沟通:不通,靠指认·计算器
  • 最佳时段:午餐前(10~11点)或傍晚(17~20点)人气最旺

轴3:清凉里夜市(3选)

#7 清凉里夜间摊贩(20~02点)

日落之后,清凉里站周边小巷会出现大排档与夜间摊贩。以鱿鱼烧烤·鸡肉串·糖饼(Hotteok / 호떡)·拉面等夜宵为主。外国游客单独前往也可以,但深夜可能有醉酒者出没,建议结伴前往。

  • 营业时间:20:00~02:00(旺季·周末延长,平日多在午夜前后收摊)
  • 价格:鱿鱼烧烤₩5,000~8,000 / 鸡肉串2串₩3,000(2026年)
  • 适合外国游客:★★★ — 若目的是体验夜间氛围则不错
  • 是否可英语沟通:不通
  • 最佳时段:21~23点摊贩数量与人气最佳

#8 清凉里夜市发烧友cluster

综合市场周边的美食街上分布着夜间营业的餐厅。醒酒汤(Haejangguk / 해장국)·五花肉(Samgyeopsal / 삼겹살)·炸鸡外卖是夜间主打菜品,也有适合独自用餐外国游客的单人座式餐厅。

  • 营业时间:18:00~01:00(各店铺不同)
  • 价格:五花肉200克₩15,000~18,000 / 醒酒汤₩9,000~12,000(2026年)
  • 适合外国游客:★★★ — 菜品选择较多,适合体验夜间韩餐
  • 是否可英语沟通:不通,需用菜单照片·翻译App

#9 清凉里凌晨拍卖区(#587关联)

清凉里水产·青果批发的凌晨拍卖集中在04~06点进行。观光性质的参观受限,若非以批发交易为目的,很难进入拍卖现场。若对凌晨市场整体感兴趣,参考#587 — 鹭梁津(Noryangjin / 노량진)·可乐(Garak / 가락)·马场(Majang / 마장) — 关联篇更为实际。

  • 营业时间:凌晨04:00~07:00(拍卖高峰)
  • 适合外国游客:★★ — 观光性质参观难度较高
  • 交通:一般游客在清凉里站周边的凌晨水产摊贩层面体验更为现实

轴4:附近关联(3选)

#10 京东市场韩方区(#598关联)

从清凉里综合市场步行10分钟(约700米)可达京东市场(Gyeongdong Sijang / 경동시장)。这里集中了韩药材·人参·红参·保健食品批发,是外国游客购物目的地访问较多的区域。与#598药令市深度篇联动,可完成半日行程。

  • 营业时间:08:00~18:00(各店铺不同,周日部分休息)
  • 价格:红参浓缩液30包₩30,000~80,000 / 人参根₩15,000~50,000(依品质等级,2026年)
  • 适合外国游客:★★★★★ — 部分店铺可用英语·中文·日语。部分店铺标示Tax Refund
  • 交通:1号线清凉里站步行10分钟,或1号线祭基洞(Jegi-dong / 제기동)站1号出口步行3分钟
  • 是否可英语沟通:部分可(因韩方批发行业接待外国顾客经验较多)
  • 最佳时段:上午至下午选择最多。傍晚18点后开始打烊

#11 药令市(#598·#365关联)

京东市场的韩药一条街(药令市,Yangnyeongsi / 약령시)自朝鲜时代延续至今,是韩方药材的集散地。经营干人参·鹿茸·当归·黄芪等传统药材的店铺鳞次栉比。相较于韩药处方,更多外国游客是以购买保健食品·送礼用药材为目的前来。详情参见#598·#365。

  • 营业时间:08:00~18:00
  • 适合外国游客:★★★★ — 具有观赏价值与K-Medical体验价值
  • 是否可英语沟通:部分店铺可基础沟通

#12 鹭梁津·可乐·马场(#587全套关联)

若想更深入体验清凉里凌晨市场,建议联动#587凌晨市场深度篇(鹭梁津水产市场·可乐市场·马场洞畜产市场)。可乘地铁移动,能规划出凌晨03~06点的完整行程。

常见问题5

Q1. 第一次前往应该从哪里开始?

1号线清凉里站1号出口 → 进入综合市场本馆(#1)逛干货·谷物区一圈。之后往2~3号出口方向的小巷移动,在老字号雪浓汤店(#4)或小吃摊(#6)吃午餐。半日行程即可完成。

Q2. 与#598药令市深度篇有何不同?

#598是清凉里+京东药令市9个市场的完整cluster。#609(本篇)则是聚焦清凉里综合市场+传统老字号+夜市的子深度篇。若对韩方·药材感兴趣,建议先读#598;若目的是市场美食·老字号体验,先读#609更有效率。

Q3. 价格水平如何?

一人一餐₩8,000~13,000(汤饭·雪浓汤),摊贩小吃₩3,000~8,000。京东市场韩方伴手礼预算₩30,000~100,000较为现实。整体半日行程可用₩20,000~30,000完成。

Q4. 周日前往可以吗?

综合市场部分店铺与老字号巷多数周日休息。若不得已选在周日,建议以夜间摊贩(#7·#8)与24小时醒酒汤店为中心规划路线。出发前建议用谷歌地图确认营业日。

Q5. 不会韩语也能独自前往吗?

可以。指认点餐(用手指点想要的东西)与计算器沟通在大多数情况下都能通用。用翻译App相机模式扫描韩文菜单,点餐基本不会有困难。京东市场韩方区部分店铺可用基础英语。

  • 20:30 夜间摊贩(#7)鱿鱼烧烤·糖饼
  • 22:00 夜市美食街(#8)五花肉或醒酒汤
  • 04:00 出发前往鹭梁津水产市场(#587凌晨全套)

预算:人均₩25,000~50,000(夜宵+凌晨行程)

路线3. K-Medical半日(#598关联)

  • 10:00 抵达清凉里站 → 老字号早餐(#4·#5)
  • 11:30 步行移动 → 京东市场·药令市韩方区(#10·#11)
  • 13:00 韩方体验·购买伴手礼
  • 14:00 返程或延伸至#598深度篇

预算:人均₩10,000~80,000(依韩方伴手礼购买规模浮动)

季节5轴

  • 春季(3~5月):市场应季春菜·草莓·香瓜旺季。青果区(#2)看点多。天气宜人,夜间摊贩体验也很适合。
  • 夏季(6~8月):西瓜·香瓜·桃子批发旺季。上午青果区最热闹。夜间摊贩因炎热多集中在22点以后。
  • 秋季(9~11月):干货·谷物丰收旺季。干虾·秋刀鱼·大虾在此时进入水产胡同(#3)。JP游客秋季来访达到高峰。
  • 冬季(12~2月):牛骨汤·雪浓汤老字号(#4·#5)旺季。以热汤为目的的到访最为适宜。以室内为主规划路线,寒流天气也无妨。
  • 梅雨季(6~7月部分):以室内市场(综合市场本馆)为中心简化路线。夜间摊贩雨天可能收摊。

外国发烧友5贴士

1. 1号线清凉里站大本营 — 不同出口通往不同区域。分清1号出口(市场)、2~3号出口(老字号小巷)再出站可节省时间。

2. #598·#365韩方半日关联 — 清凉里综合市场+京东药令市的动线可步行连接。韩方伴手礼Tax Refund仅限有标示的店铺,出发前务必确认。

3. #587凌晨全套 — 若想体验凌晨市场,鹭梁津·可乐·马场的完整度更高。清凉里凌晨可作为热身体验。

4. 准备现金3万~5万韩元 — 老字号·摊贩·夜间大排档均需现金。可在清凉里站内ATM取现。

5. JP·EN正宗发烧友适配 — 比起Ins风打卡,更适合想体验韩国真实日常市场的旅行者。是比起拍照更注重味道与氛围的客群。
