🎯 こんな人に

ソウルでDJの音楽を聴きながら朝まで踊りたい旅行者向けの回です。ジャンルで選ぶと簡単です。テクノ・ハウスは梨泰院、ヒップホップ・K-popとバンドのライブはホンデ、大きなステージのEDMはチョンダムです。カカオマップ (Kakao Map / 카카오맵)で営業中(status Y)と確認でき、2026年に投稿された訪問レビューやイベント案内がある店だけを残しました。

⚠ 表記の原則: 営業時間は、オーナーがカカオマップに登録した値です(2026-11-24確認)。カカオマップに時間がない店は、日付のあるイベント案内や訪問レビューの値を使い、出典を添えました。クラブの入場料は、曜日とその日に出演するDJによって変わります。以下の金額は、日付のあるレビュー・イベント案内に出てきた例なので、行く前に各クラブのインスタグラムでその日のお知らせを見てください。歩く距離はOpenStreetMapの徒歩ルートで測った値で、駅の出口と歩く時間はカカオマップの経路案内の値です。

① ノクサピョン~梨泰院 — テクノ・ハウス4軒

4軒とも、ノクサピョン駅と梨泰院駅の間の梨泰院路の周辺にあります。ケイクショップからボルノストまでは311m(歩いて4分)、ボルノストからファウストまでは471m(6分)、ファウストからソープまでは392m(5分)です。テクノ・ハウスのクラブは、その日に誰がかけるかが大切なので、各クラブがDJのラインナップをインスタグラムとResident Advisor(RA)に事前に載せます。

ケイクショップ (Cakeshop / 케이크샵)

ノクサピョン駅の近くの地下にある小さなクラブで、海外DJの来日公演が開かれることもあります。カカオマップの登録時間は金・土 22:00~05:00です。2026-11-03に投稿された訪問レビューによると、2026-07-04の海外DJ公演のチケットをRAで₩22,500で予約し、中のドリンクは1杯₩10,000ほどでした。同じ書き手の別のレビュー(2026-11-02)は、1月30日の公演をアーリーバード約₩20,000で予約し、有名ゲストが来る日は再入場ができなかったと書いています。ジャンルはイベントごとに、テクノ・ハウス・ベースミュージックを行き来します(ブログ2026-09-12)。大きなゲストが来る日は、メインDJが午前2時ごろにやっと出たというレビューがあります(カカオレビュー2026-02-03)。同じレビューは、中がひどく暑くなるので上着は預けるようにと書いています。住所は龍山区 (Yongsan-gu / 용산구)の梨泰院路134 地下1階 (Itaewon-ro 134 / 이태원로 134)、ノクサピョン駅(6号線)3番出口から歩いて6分です。

  • 入口で: 大きなゲストが来る日は、RA予約が先に終わることがあるので、予約を確認してから行きます。

ボルノスト (Volnost / 볼노스트)

暗い照明と重いテクノに集中するクラブです。名前はチェコ語で「自由」という意味です。カカオマップの登録時間は木 20:00~02:00、金・土 23:00~06:00で、日~水は休みです。The Editブログ(2026-10-14)には、入場料₩14,000、ジャンルはダーク・実験的なテクノと載っていて、撮影が制限されると書かれています。同じ記事によると、入口はビルとビルの間の狭い通路の奥にあります。2026-01-25のカカオマップのレビューには、ロッカーを一度出すと、また料金を払わなければならなかったという内容があります。住所は龍山区 (Yongsan-gu / 용산구)の梨泰院路142 (Itaewon-ro 142 / 이태원로 142)、ノクサピョン駅3番出口から6分です。

  • 入口で: 看板ではなく音をたどって探す店です。ロッカーに荷物を入れたなら、終わるまで出さないほうがよいでしょう。

ファウスト (FAUST / 파우스트)

メインフロアはテクノ、隣の「タンツバー (Tanz Bar / 탄츠바)」はハウスをかける3階建てのクラブです(訪問レビュー2026-03-24)。カカオマップには金・土 23時~だけが登録されていて、終了時刻はありません。2026-10-24(土)の海外テクノデュオの公演は23:00~翌日05:00と案内されました(ブログ2026-10-20)。2026-03-24のレビューでは、入場料₩15,000、荷物預かり₩2,000です。ファウストの公式ハウスルールによると、未成年に見えるときは身分証を求められることがあり、どんな身分証も出せなければ入場できません。スーツ・制服・ワイシャツ姿の男性は入場を断られることがあります。男性だけのグループやバチェラーパーティーのように雰囲気を壊すグループと、その日のプログラムを知らないお客さんは、入場が制限されることがあります。店内の撮影は商業目的なら禁止で、携帯電話はしまっておくよう勧めています。住所は龍山区 (Yongsan-gu / 용산구)のポグァン路60ギル7 3階 (Bogwang-ro 60-gil 7 / 보광로60길 7 3층)、梨泰院駅(6号線)3番出口から2分です。

  • 入口で: 自由な服装を歓迎する店です。その日のDJの名前くらいは知って行きます。

ソープ ソウル (Soap Seoul / 소프 서울)

2026年に今の場所へ移ったハウス・エレクトロニックミュージックのクラブです(ブログ2026-11-20)。公式サイトの住所は龍山区 (Yongsan-gu / 용산구)の梨泰院路217 地下2階 (Itaewon-ro 217 / 이태원로 217)です。カカオマップに時間がないため、通常の営業曜日は確認できませんでした。通常の営業曜日は、ソープのインスタグラム(@soapseoul)で確認してください。イベントの例として、2026-11-20(金)のイベントは22:00~05:00、現場販売₩20,000(ドリンク1杯込み)、2007年生まれ以前の人だけ入場可と案内されました。2026-09-25の訪問レビューも入場料は₩20,000(その日のイベントの場合)で、店内は禁煙(電子たばこのみ可)、早い時間にはグルーヴ感のあるR&Bやハウスがかかっていたと書いています。2026-09-12のカカオマップのレビューも、店内は喫煙できず、DJごとに音楽が変わると書いています。梨泰院駅2番出口から6分です。

  • 入口で: イベントごとに生まれ年の条件が案内されます。実物の身分証を持っていきます。

② サンス駅 — ヒップホップとライブ2軒

2軒は149m(歩いて2分)離れています。どちらもホンイク大学駅よりサンス駅(6号線)のほうが近いです。

クラブ NB2 (Club NB2 / 클럽 NB2)

1999年から続くホンデのヒップホップクラブです(レビュー2026-01-20 'since 1999')。カカオマップの登録時間は月~金 22:00~06:00、土・日 21:30~07:00で、毎日開いています。2025-07-08の訪問レビューによると、入口で₩10,000を払うとリストバンドとフリードリンクのクーポン1枚がもらえ、ヒップホップとK-popがかかり、外国人観光客が多いそうです。2026-01-20のレビュー(明け方の時間帯に訪問)でも入場料は₩10,000です。入場料は時間帯・曜日によって変わることがあります。テーブルでボトルを頼むと、テキーラ1本が₩99,000でした(レビュー2025-10-06)。住所は麻浦区 (Mapo-gu / 마포구)のワウサン路72 地下1~2階 (Wausan-ro 72 / 와우산로 72)、サンス駅2番出口から6分です。

  • 入口で: この回でいちばんハードルが低い店です。平日も開いているので、日程を合わせやすいです。

クラブ FF (Club FF / 클럽 FF)

バンドの公演とダンスパーティーをあわせて行う地下のクラブです。公式ブログは「ライブ&ダンスクラブ」と紹介し、会場の収容人数はスタンディング160人と書いています。カカオマップの登録時間は水~日 19:00~06:00です。公演がある日は、夕方にバンドのステージが先に開きます(レビュー2026-08-28)。2026-08-28の訪問レビューによると、バンド4組が出た日の入場料は₩40,000(現場で口座振込)で、入口で身分証を確認されました。カカオマップのメニュー登録価格(2025-06-11)は、カクテル₩8,000、炭酸飲料₩3,000、ウイスキーなどのボトル1本₩60,000です。住所は麻浦区 (Mapo-gu / 마포구)のワウサン路17ギル12 地下1階 (Wausan-ro 17-gil 12 / 와우산로17길 12)、サンス駅1番出口から6分です。

  • 入口で: レビューには現場で口座振込で払ったと出ています。支払い方法とその日の価格は、クラブ FFのインスタグラムのお知らせを見てください。韓国の口座がなければ、訪問前に支払い方法を問い合わせます。

③ チョンダム — 大型EDM 1軒

ライオンスーパークラブ (LION SUPER CLUB / 라이언슈퍼클럽)

2026年の初めにオープンした大型EDMクラブです。カカオマップと公式サイトのどちらも金・土 23:00~06:00です。2026-02-21の訪問レビュー(2026-02-25投稿)によると、入場料はイベントごとに₩80,000・₩30,000・₩10,000・無料などと違い、オンライン予約(dumbsアプリ)と現場購入のどちらもできます。同じレビューは、フェスのように飾った照明・スクリーンと、テックハウス・EDMのセット、たばこのにおいがしない店内を書いています。公式サイトには「忘れ物探し」のメニューがあります。住所は江南区 (Gangnam-gu / 강남구)のトサンデロ535 (Dosan-daero 535 / 도산대로 535)、チョンダム駅(7号線)13番出口から歩いて12分なので、バスやタクシーが便利です。

  • 入口で: イベントごとに入場料が大きく違うので、@lionseoulでその日の価格を見ます。

🗺 ひと晩のコース2つ

A. 梨泰院のテクノ (クラブの間は歩いて4~6分)

  1. 22:00~23:00 ノクサピョン駅3番出口 → ケイクショップ(金・土)またはボルノスト(木~土)
  2. 01:00ごろ 金・土ならファウストへ移動(ボルノストから471m)。メインフロアとタンツバーを行き来します
  3. 再入場できない日があるので、1軒でその日のメインDJを聴いてから移るほうがよいでしょう

B. サンス駅 (クラブの間は149m)

  1. 19:00~ クラブ FFに入場(水~日営業)。バンドの公演日かどうか、インスタグラムのお知らせで確認します
  2. 23:00ごろ NB2へ移ってヒップホップ・K-popでつなぎます
  3. 地下鉄が止まったあとは、下の「安全と帰り道」にあるフクロウバスかタクシーで帰ります

🛡 安全と帰り道

  • ドリンク: 中身がわからないお酒や飲み物は飲みません。踊りに行くときやお手洗いに行くときも、グラスを持って行くか、新しくもらいます。急に意識がぼんやりしたり、記憶が途切れたりしたら疑い、飲んでいたグラスは捨てずに112に通報します。警察を通じて血液・尿の検査を受けられます(仁川広域市の薬物性犯罪予防の心得、2024-12-19)。韓国では警察は112、救急車は119です(英国政府の海外渡航情報)。
  • 通訳: 韓国観光公社の観光通訳案内電話1330は英語に対応し、07:00~24:00には3者通話の通訳もできます(英国政府の海外渡航情報)。
  • 帰り道: ソウル市のフクロウバス(深夜バス)は14路線が23:00~06:00に走り、運賃はカード払いで₩2,500です(ソウル市交通ホームページ、2026-03-20修正)。停留所と路線は、乗る場所で事前に確認します。タクシーは大通りに出て拾います。
  • 忘れ物: バス・タクシーで失くした物は、ソウル市の「公共交通統合遺失物センター」で探します。運営機関が7日間保管したあと警察署に引き渡し、その後は警察庁の遺失物統合ポータル(lost112.go.kr)で探します。120タサンコールセンターに尋ねることもできます(ソウル市交通ホームページ、2025-04-16修正)。クラブの預かり所に預けたバッグは、ファウストのハウスルールのように貴重品の紛失に責任を負わない店もあるので、パスポートと財布は身につけておきます。

⚠ よくある失敗3つ

  1. 日曜~水曜に梨泰院のクラブを組む — カカオマップ登録の営業日は、ケイクショップとファウストが金・土、ボルノストが木~土です。ソープは通常の営業曜日を確認できませんでした。平日の夜なら、毎日開くNB2と、水曜から開くクラブ FFが現実的です。
  2. 入場料を固定の値だと思う — 同じクラブでも、イベントによって無料から₩80,000まで違います(ライオンスーパークラブのレビュー2026-02-25)。海外DJの公演は、RAで事前に予約することがあります(ケイクショップのレビュー2026-11-03)。
  3. 身分証の写真だけ持っていく — 携帯の写真・コピーを入口で受け付けない店があります。外国人はパスポートの原本を持っていきます。クラブは入口で年齢を確認し、ファウストのハウスルールも身分証の確認を受けることがあると書いています。

⚙ よくある質問3つ

  1. 何歳からクラブに入れる？ — 青少年保護法は19歳未満を青少年としますが、19歳になる年の1月1日を過ぎると青少年から外れます。誕生日とは関係なく生まれた年で数えるので、2026年は2007年以前に生まれた人がお酒を買えます。同じ法律は、青少年にお酒を売ることを禁じ、売る側に年齢と本人かどうかの確認を義務づけています。ソープ ソウルの2026-11-20のイベントも「2007年生まれおよびそれ以前の人入場可」と案内されました。クラブごとに、これより厳しい独自の基準を設けることがあり、クラブ独自の規定が18歳でも、韓国の法律の生まれ年の基準が優先されます。
  2. ドレスコードはある？ — 公式の規定を確認できたのはファウストです。自由で大胆な服装を歓迎し、スーツ・制服・ワイシャツ姿の男性は入場を断られることがあると書いています。ほかのクラブは決まった規定を確認できませんでした。テクノのクラブは長く立っているので、楽な靴のほうがよいでしょう。
  3. 予約は必要？ — 海外DJが来る日のケイクショップはRA予約(レビュー2026-11-03)、ライオンスーパークラブはdumbsアプリの予約と現場購入ができます(レビュー2026-02-25)。NB2とボルノストは予約の情報を確認できませんでした。行く前に各クラブのインスタグラムを見てください。
