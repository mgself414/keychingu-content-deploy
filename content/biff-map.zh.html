釜山国际电影节(BIFF)观影指南 — 以海云台中心城的电影殿堂 (Yeonghwaui Jeondang / 영화의전당) 为中心，普通场次1万韩元的订票方法与2026年第31届回顾(秋季，2026年10月官方数值)

摘要：2026年第31届BIFF于10月6~15日举行(BIFF官方)· 8家影院31块银幕，大多集中在海云台区 (Haeundae-gu / 해운대구) 中心城(BIFF官方)· 普通场次10,000韩元，开幕式·闭幕式30,000韩元(BIFF官方订票说明)· 英文订票需通过邮箱验证注册(BIFF官方英文订票说明)· 2027年第32届日程尚未公布 — 截至2026-10-21

ISSUE 03 · #482 · 2026-05-27

🎯 本指南的使用方法

太阳落山后，人们成排坐在电影殿堂 (Yeonghwaui Jeondang / 영화의전당) 屋顶下的露天剧场里，银幕的光在吹向水营江 (Suyeonggang / 수영강) 一侧的夜风中摇曳。电影节把这种露天放映称为“开放影院 (Open Cinema)”，2026年放映了7部影片(BIFF官方概要)。本指南写给第一次去看釜山国际电影节(BIFF)的旅行者，只依据官方页面的数值，整理在哪里放映、怎么买票、电影节之外的时间怎么使用釜山的电影空间。

2026年的电影节已经结束。因此2026年的数值写成“当年是这样举办的”，明年的日程在公告发布之前留空。订票方式和价格每年都可能变化，2027年请再次查看biff.kr的公告。

📅 2026年第31届是怎样举办的

  • 时间：2026年10月6日(周二)~15日(周四)。从2026年起，开幕日从周三提前一天到周二(BIFF官方概要)
  • 规模：8家影院31块银幕。官方邀请影片来自59个国家共246部，社区BIFF放映影片69部(含露天放映)(BIFF官方结算资料)
  • 观众：总计277,027人，其中电影观众200,043人(BIFF官方结算资料)
  • 开幕片：金钟官导演的《白天与黑夜彼此相望》(Nat-gwa Bam-eun Seoro-ege / 낮과 밤은 서로에게)(BIFF官方概要)
  • 竞赛单元：2025年新设，2026年是第二届。釜山奖大奖是马吉德·马基迪导演的《面包与书》(Ppang-gwa Chaek / 빵과 책)(BIFF官方获奖名单)
  • 电影节地位：2026年入选国际电影制片人协会联合会(FIAPF)“A类电影节”，釜山奖大奖得主获得美国奥斯卡最佳国际影片的报名资格(BIFF官方概要)。电影节自称“韩国第一个国际电影节”“亚洲最大的电影盛会”(BIFF官方介绍)。首届开幕式于1996年9月13日举行(BIFF官方介绍)
  • 2027年第32届：日期和订票日程均尚未公布(BIFF官方，2026-10-21确认)。不要推测日期，等待官方公告

🎬 放映厅 — 集中在中心城

电影节放映厅集中在海云台区 (Haeundae-gu / 해운대구) 中心城一带，可以步行往返。地址均为电影节放映厅运营说明中所写的数值(BIFF官方)。

  • 电影殿堂 (Yeonghwaui Jeondang / 영화의전당) — 海云台区水营江边大路120号 (Suyeonggangbyeon-daero / 수영강변대로 120)。从2号线中心城站 (Centum City-yeok / 센텀시티역) 12号·6号出口步行5分钟(电影殿堂官方交通指引)。露天剧场“屋顶剧场 (Roof Theater / 루프씨어터)”举办开放影院和露天舞台见面会。2026年开放影院入场时间为10月7~14日18:30(预定)，全部为非指定座位(BIFF官方放映厅运营说明)
  • CGV中心城 (CGV Centum City / CGV센텀시티) — 海云台区中心南大路35号 (Centumnam-daero / 센텀남대로 35)，新世界百货店7层。百货店开门前，从中心城站12号出口前的3号门进入(BIFF官方)
  • 乐天影院中心城 (Lotte Cinema Centum City / 롯데시네마 센텀시티) — 海云台区中心南大路59号 (Centumnam-daero / 센텀남대로 59)，乐天百货店8层。开店前使用1层正门(地铁8号出口一侧)最左边的门(BIFF官方)
  • 韩国电影振兴委员会标准试映室 (Yeonghwajinheungwiwonhoe Pyojun Siasil / 영화진흥위원회 표준시사실) — 海云台区水营江边大路130号 (Suyeonggangbyeon-daero / 수영강변대로 130)，韩国电影振兴委员会 (Yeonghwajinheungwiwonhoe / 영화진흥위원회) 2层(BIFF官方)
  • 昭香剧院友利银行厅 (Sohyang Theater Uri Bank Hall / 소향씨어터 우리은행홀) — 海云台区中心中央路55号 (Centumjungang-ro / 센텀중앙로 55)(BIFF官方)
  • 釜山观众媒体中心公开厅 (Busan Sicheongja Media Center Gonggaeho / 부산시청자미디어센터 공개홀) — 海云台区中心中央路42号 (Centumjungang-ro / 센텀중앙로 42)，2层(BIFF官方)
  • 社区BIFF (Community BIFF / 커뮤니티비프) — 在Megabox釜山剧场 (Megabox Busan Geukjang / 메가박스 부산극장) 和天主教中心空间101.1 (Catholic Center Space 101.1 / 가톨릭센터 공간 101.1) 放映(BIFF官方结算资料)。这两处的地址在电影节页面上没有确认到

🎟 买票方法 — 以2026年订票说明为准

  • 订票开放：2026年，开幕式·闭幕式、开放影院、午夜时尚 (Midnight Passion)、演员之家 (Actors' House)、社区BIFF于9月17日14:00开放；普通场次、大师班、电影班于9月21日14:00开放(BIFF官方订票说明)
  • 价格：开幕式·闭幕式30,000韩元，普通场次·电影班10,000韩元，演员之家·大师班15,000韩元，午夜时尚20,000韩元(BIFF官方订票说明)
  • 外国人注册：英文订票说明写明，首次注册要进行邮箱验证，之后用注册的邮箱和6位数字密码登录。即使去年注册过，也要重新注册(BIFF官方英文订票说明)。韩文说明则是手机号验证
  • 支付：按英文说明为信用卡·借记卡(BIFF官方英文订票说明)。现场BIFF售票处收卡和现金(BIFF官方订票说明)
  • 张数：每个场次代码最多2张。访问人数多时会分配排队号。建议使用Chrome浏览器(BIFF官方订票说明)
  • 现场购买：所有普通座位先在线上销售。没有售罄或出现退票时，电影节期间可以在BIFF售票处购买(BIFF官方订票说明)
  • 取消：放映前60分钟。放映日前6天之前免手续费，5~3天前1,000韩元，2天前起3,000韩元(开幕式·闭幕式为3,000韩元·9,000韩元)(BIFF官方订票说明)
  • 入场：放映前15分钟起可入场，开场15分钟后限制入场。手机票截图或KakaoTalk通知消息无法入场。未满4周岁的儿童即使有监护人陪同也不能入场(BIFF官方放映厅运营说明)

🎤 不用票也能看的

  • 露天舞台见面会：导演和演员用约20分钟介绍电影。2026年于10月7~11日在电影殿堂 (Yeonghwaui Jeondang / 영화의전당) 屋顶剧场 (Roof Theater / 루프씨어터) 举行(BIFF官方露天舞台见面会)
  • 开放对谈 (Open Talk) 和露天舞台见面会无需费用或申请，按准备好的座位数入座观看。电影节公告称，观众自行排的队与电影节运营无关(BIFF官方露天舞台见面会)

🏛 电影节之外 — 电影殿堂

  • 电影殿堂 (Yeonghwaui Jeondang / 영화의전당) 在电影节期间之外也全年放映。2026年时间表中，“电影资料馆 (Cinematheque)”板块下挂着“2026 Cine Replay”“2026 大众电影节目”“2026 艺术电影节目”，日期为2026-01-01~12-31(电影殿堂官方)。总机电话051-780-6000(电影殿堂官方)
  • 观影费和休馆日在电影殿堂主页上没有确认到

🧰 BIFF实用信息 — 独自、预约、支付、交通

  • 独自一人：座位1张起就能买。放映厅内为指定座位制(BIFF官方放映厅运营说明)
  • 预约时机：2026年订票在开幕前约3周开放(BIFF官方订票说明)。2027年的开放日尚未公布。消息通过电影节新闻邮件获取(BIFF官方)
  • 支付：刷卡支付的一般情况见外国人韩国支付系统深度探索
  • 首尔→釜山：KTX所需时间在韩铁 (Korail / 코레일) 官方页面上没有确认到。各趟列车的时间和票价请在韩铁订票画面查看 — 韩国KTX初次搭乘，跟着流程走 — 在没有闸机的车站不迷路的方法
  • 釜山市内：中心城站是2号线(电影殿堂官方)。釜山地铁的看法见釜山大众交通语法 — 只需读懂两条线的城市
  • 携带食物：放映厅内禁止酒类和外带食物，部分放映厅只允许带矿泉水。露天屋顶剧场 (Roof Theater / 루프씨어터) 可以带有盖的饮料和三明治·紫菜包饭 (Gimbap / 김밥) 之类的简单食物，但不能带酒类(含无酒精啤酒)和带汤的食物(BIFF官方放映厅运营说明)
  • 咨询：BIFF客服中心1666-9177，工作日10:00~17:00。邮箱cs@biff.kr(BIFF官方)

⚠ 常见的4个错误

1. “票到现场买就行” — 普通座位全部先在线上销售。现场售票处只会出现剩余票和退票(BIFF官方订票说明)

2. “用手机截图入场” — 手机票截图或通知消息无法入场(BIFF官方放映厅运营说明)

3. “住哪儿都行” — 2026年官方放映厅6处的地址都在海云台区 (Haeundae-gu / 해운대구) 中心城。一天想看好几部的话，选择容易往返中心城站的地方更方便(BIFF官方放映厅运营说明)

4. “去年注册过，直接订票” — 订票人注册每年都要重新进行(BIFF官方订票说明)
