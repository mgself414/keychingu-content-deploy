🎯 机张这样逛

釜山机张郡 (Gijang-gun / 기장군) 就在海云台正东边的海边。很多人只看一眼海上寺庙海东龙宫寺 (Haedong Yonggungsa / 해동용궁사) 就回去了,但同一条公交线上还依次排着奥西里亚海岸步道·大边港(鳀鱼)·机张市场。在海云台站 (Haeundae-yeok / 해운대역) 7号出口搭181路公交,一班车几乎全部可达。这一篇就按这个顺序安排一日行程。

没有官方时刻表的路段,所需时间标注为[推测]。出发前请再用地图App(Naver Map·KakaoMap)确认一遍。

① 海东龙宫寺——越早去越好

  • 免费入场,每天04:30~19:20(最后入场18:50),地址 机张邑龙宫路86号 (Gijang-eup Yonggung-gil 86 / 기장읍 용궁길 86) (Visit Busan)
  • 交通: 从海云台站2号线7号出口搭181·100·海云台9路公交,或从东海线奥西里亚站1号出口搭139路公交 (Visit Busan)
  • 山门后的108级台阶和海边一侧的路台阶很多。带婴儿车或腿脚不便的同行者,请把时间留宽裕
  • 有收费停车场,但这次没能确认费用。宠物装进笼子或戴上口套即可入内

② 奥西里亚海岸步道——龙宫寺旁的海边小路

全天开放·免费,没有停车场。这是一条经过海边岩石上龙王坛的海边小路 [二手]。官方的长度·所需时间没能确认。如果想走更远,这一段属于海浪路 (Haparang-gil / 해파랑길) 第2段(公须村 (Gongsu Maeul / 공수마을)→龙宫寺→大边港,约8km)(机张郡)。

⚠ 奥西里亚站正前方站点的185路是反方向(开往 Jangsan站 (Jangsan-yeok / 장산역))。想去科学馆,请到站对面搭车。

④ 大边港——鳀鱼之港

大边港的生鳀鱼生鱼片·鳀鱼汤是这里的代表美食(机张郡)。鳀鱼在春·秋两季捕捞,机张鳀鱼节每年4月前后举办(2026年第30届4/24~26,报道 [二手])。从海云台站搭181路,在"大边港入口 (Daebyeonhang Ipgu / 대변항입구)"下车 (Visit Busan)。不是产季的话,可能吃不到鳀鱼生鱼片。

⑤ 机张市场——海带与帝王蟹

位于机张邑大罗里 (Daera-ri / 대라리),每天07:00~22:00(无休息日),从东海线机张站1号出口步行约6分钟。春季机张海带、秋季带鱼、帝王蟹街很有名 (Visit Busan)。

⑥ 再往远走——竹城·日光·漆岩·九山林

  • 竹城教堂 (Jukseong Seongdang / 죽성성당): 并不是真正的教堂,而是为2009年SBS电视剧"Dream"搭建的布景而建的建筑(2016年翻新,机张郡)。海边外观是拍照名所。内部是否开放,各来源说法不一。没有公共交通信息,打车比较方便
  • 日光海水浴场 (Ilgwang Haesuyokjang / 일광해수욕장)·漆岩 (Chiram / 칠암): 位于海浪路第3段(大边港→竹城→日光→林浪,约20.5km)上。漆岩以星鳗闻名(机张郡)
  • 九山林 (Ahopsan Sup / 아홉산숲)(铁马面): 每天09:00~18:00(17:00前入场),成人₩8,000,个人无需预约。宠物·婴儿车不可入内 (Visit Busan)

⚠ 真正会踩的5个坑

1. 科学馆185路方向 — 不是奥西里亚站前,而是对面站点。周一闭馆。

2. 卢吉关门时间 — 各来源不同,18点/20点。请在官方网站当天确认。

3. 步行去龙宫寺 — 从奥西里亚站走过去很远。请搭139路公交。

4. 竹城教堂是布景 — 不是做弥撒的教堂。请打车前往。

5. 鳀鱼季 — 生鳀鱼生鱼片限春·秋季。现在是10月,鳀鱼节(4月)已经结束。

⚙ FAQ 3

1. 在海云台待一天够吗? — 龙宫寺·步道·大边港·机张市场,181路线一天就能逛完。再加上卢吉·科学馆的话,请像B方案那样分开安排。

2. 哪些地方要门票? — 海东龙宫寺·步道·竹城教堂外观免费。科学馆₩3,000,九山林₩8,000。乐天世界·卢吉请在官方网站确认票价。

3. 东海线车费是多少? — 这次没能确认官方票价表。刷交通卡(#1298)即可。
