⚠ 외국인 자주 실수 5가지

1. "한국 = 산만": 한국 자연 = 22 국립공원 (산악 17 + 해양 4 + DMZ 1) + UNESCO 자연유산 + 외국인 매니아 1번지 풀세트 + #515·#430 통합.

2. "국립공원 = 어려움": 국립공원 = KNPS 영어 OK + Korea Tourism Pass + 외국인 영어 가이드 + 외국인 매니아 1번지 + #515·#534 통합.

3. "등산 = 장비 비쌈": 장비 = 코오롱·노스페이스 (한국 #1) + 외국인 영어 OK + 30~50% 할인 (면세점) + 외국인 매니아 + #406·#138·#142 통합.

4. "제주 한라산 = 어려움": 한라산 = UNESCO + Visa-free 30일 + 외국인 1번지 + 5 코스 (영실·관음사·성판악·돈내코·어리목) + #534·#525 통합.

5. "올레길 = 한국인만": 올레길 = 27 코스 437km + 외국인 영어 OK + 외국인 매니아 1번지 (영국 코츠월드 매니아) + #534·#515 통합.
