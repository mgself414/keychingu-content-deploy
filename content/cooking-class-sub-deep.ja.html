ソウル韓食文化体験ガイド — ミュージアム・キムチガン、トック博物館、韓食文化空間 イウム、伝統酒ギャラリー、ブクチョン伝統発酵工房 ビッタム、チュンプン醸造場、オミ料理研究所

サブタイトル: ミュージアム・キムチガン(10:00~18:00、19歳以上 5,000ウォン、月曜日休館) · トック博物館(月~土 10:00~18:00、大人 3,000ウォン、日曜日休館) · 韓食文化空間 イウム(クッキングクラス 15,000ウォン、月曜日休み) · 伝統酒ギャラリー(無料、英語の試飲 3時・4時) · ビッタム(ワンデイクラス 36,000ウォン・材料費別、月・火休み) · チュンプン醸造場(ツアー 110,000ウォン、満19歳以上) · オミ料理研究所(授業 110,000ウォン、予約必須) — 韓国観光公社の観光情報(TourAPI)で確認

🎯 このガイドの使い方

このガイドは、ソウルでキムチ・トック・醤・伝統酒のような韓食文化を見て、自分で作れる場所をまとめたものです。インサドン (Insa-dong / 인사동)のミュージアム・キムチガン (Myujieom Gimchigan / 뮤지엄 김치간)、ドンファムン路 (Donhwamun-ro / 돈화문로)のトック博物館 (Tteok Bangmulgwan / 떡박물관)、Bukchon-ro 18 (북촌로 18)の韓食文化空間 イウム (Hansik Munhwa Gonggan Ieum / 한식문화공간 이음)と伝統酒ギャラリー (Jeontongju Gaelleori / 전통주갤러리)、ブクチョン韓屋村 (Bukchon Hanok Maeul / 북촌한옥마을)のビッタム (Bitdam / 빚담)、シンダンドン (Sindang-dong / 신당동)のチュンプン醸造場 (Chunpung Yangjojang / 춘풍양조장)、チェギドン (Jegi-dong / 제기동)のオミ料理研究所 (Omi Yori Yeonguso / 오미요리연구소)です。キムチガンの体験とオミ料理研究所の授業は予約必須、伝統酒ギャラリーの試飲はインターネット予約制で、休みが場所ごとに違います。下の表を先に見るとよいです。精進料理の体験は#800 ソウル精進料理・テンプルステイガイドにあります。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 見て学ぶ — ミュージアム・キムチガン・トック博物館

ミュージアム・キムチガン (Myujieom Gimchigan / 뮤지엄 김치간)、鍾路区 Insadong-gil 35-4 (인사동길 35-4) インサドンマル (Insadong-maru / 인사동마루)本館4~6階、☎ 02-2088-8531 は、キムチとキムジャン文化を紹介する食品博物館です。中区ピルドン (Pil-dong / 필동)でキムチ博物館という名前で初めて開館し、1987年に食品企業プルムウォン (Pulmuone / 풀무원)が引き継いで運営を始めました。韓国観光公社の紹介によると、韓国初でありソウル唯一のキムチ博物館です。名前の「ガン (gan / 간)」は、スラガン (Suragan / 수라간)・コッカン (Gotgan / 곳간)のように空間を意味する言葉から取りました。

  • 開く時間: 10:00~18:00(最終入場 17:30)。休み: 毎週月曜日、1月1日、旧正月・秋夕の連休、12月25日。
  • 料金: 19歳以上 5,000ウォン、8~18歳 3,000ウォン、36か月~7歳 2,000ウォン。20人以上の団体はそれぞれ 4,000ウォン、2,000ウォン、1,000ウォン。36か月未満、65歳以上、障害者とその引率者は無料で、年齢を確認できる身分証を持っていく必要があります。
  • 体験: 有料プログラムの It's Kimchi、Kimchi Basic、Kimchi Masterと、無料プログラムのキムチ学校 (Gimchi Hakgyo / 김치학교)があります。事前予約必須、6歳以上。駐車: 不可。

トック博物館 (Tteok Bangmulgwan / 떡박물관)、鍾路区 Donhwamun-ro 71 (돈화문로 71)、☎ 02-741-5447 は、2002年1月に昔の台所道具の所蔵品3,000点余りを集めて開館した博物館です。トックを時節と一生の儀礼、作り方によって分けて展示し、トックを作る調理道具も展示します。トックを自分で作って味わう体験プログラムを運営しています。

  • 開く時間: 月~土 10:00~18:00(入場締切 17:30)。休み: 毎週日曜日、旧正月・秋夕。
  • 料金: 大人 3,000ウォン、36か月~19歳未満 2,000ウォン。36か月未満と65歳以上は無料。

📍 Bukchon-ro 18 (북촌로 18) — 韓食文化空間 イウム・伝統酒ギャラリー

韓食文化空間 イウム (Hansik Munhwa Gonggan Ieum / 한식문화공간 이음)、鍾路区 Bukchon-ro 18 (북촌로 18)、☎ 0507-1465-8488 は、韓食振興院 (Hansik Jinheungwon / 한식진흥원)が運営する複合文化空間です。赤レンガの建物の中に展示館、図書館、カフェ、体験場があります。展示館では伝統の醤類と伝統酒の歴史を見せ、地下の韓食図書館は誰でも無料で閲覧できます。ハンシク・ペウムト (Hansik Baeumteo / 한식배움터)で、トックク (Tteokguk / 떡국)のような節気の料理から、コッカムダンジ (Gotgamdanji / 곶감단지)、ススプクミ (Susubukkumi / 수수부꾸미)のような伝統デザートまで実習し、完成した料理を容器に入れて持ち帰れます。クッキングクラスの日程は毎月変わり、公式ホームページで予約します。

  • 開く時間: 火~日 10:00~19:00。休み: 毎週月曜日。
  • 料金: クッキングクラス 15,000ウォン。予約: ホームページ。

伝統酒ギャラリー (Jeontongju Gaelleori / 전통주갤러리)、鍾路区 Bukchon-ro 18 (북촌로 18)、☎ 0507-1406-6220 は、農林畜産食品部と文化体育観光部が共同で作った伝統酒の広報空間です。伝統酒ソムリエのような専門家が運営し、毎月テーマを変えて伝統酒を紹介し試飲するイベントを開きます。韓国観光公社の紹介文には「インサドン」にあると書かれていますが、登録住所は韓食文化空間 イウムと同じBukchon-ro 18 (북촌로 18)です。

  • 開く時間: 10:00~19:00。休み: 毎週月曜日、1月1日、伝統的な祝日の当日。料金: 無料。
  • 試飲: 韓国語 12時、1時、2時、5時、6時。英語 3時、4時。試飲はインターネット予約制で、外国人向けプログラムは事前予約必須です。団体は最低1か月前に問い合わせる必要があります。

📍 学んで体験する — ビッタム・チュンプン醸造場・オミ料理研究所

ブクチョン伝統発酵工房 ビッタム (Bukchon Jeontong Balhyo Gongbang Bitdam / 북촌전통발효공방 빚담)、鍾路区 Bukchon-ro 12-gil 5-12 (북촌로12길 5-12)、☎ 02-766-7858 は、ブクチョン韓屋村にある韓屋の工房で、ヌルクを使った発酵を体験できます。ヌルク作り、アルメジュ作り、低塩ヌルク塩作り、季節の伝統酒体験のようなプログラムと、ヌルクの理論と実習を学ぶ正規課程があります。

  • 開く時間: 11:00~17:00。休み: 毎週月曜日~火曜日。
  • 料金: ワンデイクラス 36,000ウォン(材料費別)。正規課程の費用は別途問い合わせるよう登録されています。駐車: 不可。

チュンプン醸造場 (Chunpung Yangjojang / 춘풍양조장)、中区 Dasan-ro 101-3 (다산로 101-3)、☎ 1899-8876 は、マッコリを造る醸造場です。醸造場ツアーと試飲を行い、海外の観光客にマッコリを紹介すると登録されています。

  • 開く時間: 営業 11:00~19:00。ツアー 11:00、15:00、17:00。
  • 休み: 毎週日曜日、月曜日。休業日のツアーは別途問い合わせるよう登録されています。
  • 料金: ツアーA 110,000ウォン。満19歳以上。駐車: 不可。

オミ料理研究所 (Omi Yori Yeonguso / 오미요리연구소)、東大門区 Yangnyeongsi-ro 97-1 (약령시로 97-1) 1階、☎ 010-5060-5250 は、キョンドン市場 (Gyeongdong Sijang / 경동시장)、チョンニャンニ市場 (Cheongnyangni Sijang / 청량리시장)、ヤンニョン市場 (Yangnyeong Sijang / 약령시장)で買った旬の食材で韓食を学ぶ料理教室です。発酵文化が込められた韓食を学べ、ベジタリアン、アレルギー、宗教上の要望に合わせてメニューを組みます。授業は英語と中国語で行い、一般授業の定員は8~10人です。2021年にソウル観光大賞 (Seoul Gwangwang Daesang / 서울관광대상)を受賞しました。

  • 授業時間: 10:00~13:00。予約必須(オンライン)。休み: 年中無休。
  • 料金: 110,000ウォン。駐車: 可能。クレジットカード: 可能。

⚠ 前もって知っておきたい3つのこと

  1. 予約が必要な体験があります — キムチガンの体験プログラムとオミ料理研究所の授業は予約必須、伝統酒ギャラリーの試飲はインターネット予約制で、イウムのクッキングクラスはホームページで予約できます。
  2. 休みが場所ごとに違います — キムチガン・イウム・伝統酒ギャラリーは月曜日、トック博物館は日曜日、ビッタムは月・火曜日、チュンプン醸造場は日・月曜日に休みます。オミ料理研究所は年中無休です。このほかキムチガンは1月1日・旧正月・秋夕の連休・12月25日、伝統酒ギャラリーは1月1日・伝統的な祝日の当日、トック博物館は旧正月・秋夕にも休みます。
  3. チュンプン醸造場のツアーは満19歳以上だけ参加できます — ツアーの時間は11:00、15:00、17:00です。

⚙ FAQ 2

Q. 英語で行うプログラムはある?

A. 韓国観光公社の登録情報では、伝統酒ギャラリーの英語の試飲が3時と4時にあり、オミ料理研究所の授業は英語と中国語で行います。

Q. 作る体験の料金は場所ごとにいくら?

A. 韓国観光公社の登録情報では、韓食文化空間 イウムのクッキングクラス 15,000ウォン、ビッタムのワンデイクラス 36,000ウォン(材料費別)、オミ料理研究所 110,000ウォンです。キムチガンの有料プログラムとトック博物館の体験は料金が登録されておらず、キムチガンのキムチ学校は無料プログラムとして登録されています。
