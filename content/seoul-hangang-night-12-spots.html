🎯 왜 한강 야경 12선 가이드인가

서울 야경 = 한강·도심·산·다리 4축 매트릭스. 외국인 관광객 페인포인트 = (a) "서울 야경 = N서울타워만" 잘못된 인식 (b) 한강 야경 spot 12+선·외국인 매니아 매트릭스 #1 (c) 시간대 (해질녘·일몰 후·심야)·계절 (봄꽃·여름 야장·가을 단풍·겨울 야경) cross (d) 교통 (지하철·따릉이·한강 페리·버스) 외국인 시각 deep dive (e) 야경 + 야장(#1071)·야간 바(#1073)·한옥 다도(#1074)·낮술 와인바(#1075) cross.

본 가이드는 외국인 시각 한강 야경 12선 + 시간대 + 교통 + 동선 매트릭스 + 매니아 풀세트.

# 야경 spot 4축 시간대 교통
1 N서울타워 전망대 + 사랑의 자물쇠 산·전망 일몰·심야 명동역 + 케이블카 / 남산순환버스
2 남산 둘레길 야경 ★ 산·산책 일몰~22시 명동·충무로역 + 도보
3 한강공원 반포 무지개 분수 + 달빛광장 한강·분수쇼 일몰·20·21시 분수 고속터미널역 + 도보
4 여의도 한강공원 + 63빌딩 야경 한강·전망 일몰·심야 여의나루역 + 도보
5 뚝섬 한강공원 + 잠실 야경 한강·피크닉 일몰~23시 뚝섬유원지역 + 도보
6 반포대교 무지개분수 야경 전망 다리·분수 20·21시 분수 동작·고속터미널역
7 잠수교 도보 야경 + 한강 트레일 다리·산책 일몰 후 동작역 + 도보
8 청계천 + 광교·수표교 야경 청계·도심 18~23시 종각·종로3가역
9 DDP 동대문 야간 LED + 야시장 도심·매니아 18~22시 동대문역사문화공원역
10 청담 도산공원·한강뷰 공원 도심·매니아 일몰~22시 압구정·청담역
11 삼성해맞이공원 (청담대교 옆 한강뷰) 한강·매니아 일몰~심야 삼성중앙역 + 도보
12 응봉산 야경 (성동·한강뷰) 산·매니아 일몰·심야 응봉역 + 도보 (등산 30분)

⚠ 외국인 자주 실수 3가지

1. "서울 야경 = N서울타워만": N서울타워 = 1번 매니아 spot. 외국인 매니아 spot #2~12 = 한강 12선 풀세트. 한강 = 외국인 매니아 매트릭스 #1 야경 자원 (한강공원 11개 cluster + 다리 27개 + 전망대).

2. "한강 야경 = 여름만": 사계절 야경 가능. 봄꽃 (4월 여의도 벚꽃) / 여름 (6~8월 야장·물놀이) / 가을 (10월 단풍 응봉산) / 겨울 (12~2월 잠수교 눈) 매니아 매트릭스 #1.

3. "한강 야경 = 너무 멀어서 못 가": 외국인 매니아 = 지하철 한강공원 직결 11개역. 여의나루·뚝섬유원지·반포(고속터미널)·잠실(뚝섬·잠실나루)·반포대교(동작) 도보 5~10분. 한강 페리(서울 한강 유람선) + 따릉이 (서울 공용 자전거) 외국인 매니아 매트릭스 #1.

⚙ FAQ 4개

1. 한강 야경 best 시간대: 일몰 30분 전 도착 + 일몰~21시 best. 반포 무지개 분수쇼 = 4~10월 평일 20:00·20:20·20:40, 주말 17:00·19:30·20:00·20:20·20:40 (시즌 변동, 공식 사이트 확인). 야경 사진 = 일몰 후 30분 (blue hour) best.

2. 외국인 한강 동선 추천: Day 1: N서울타워(저녁) → 명동(저녁 식사) → 청계천 야경 도보. Day 2: 여의도 한강공원(낮) → 63빌딩 전망(일몰) → 반포 무지개 분수(20시). Day 3: 뚝섬 한강공원 + 잠실 야경 + 응봉산 매니아.

3. 한강 야경 + 야장 cross 코스: 여의도 한강공원(일몰) → 여의도 야장 호프 → 청계천 도보(심야) → 야장 8선 cluster (#1071). 외국인 매니아 매트릭스 #1.

4. 외국인 한강 야경 etiquette: (a) 한강공원 = 음식·음료·돗자리 OK + 쓰레기 분리수거 필수 (b) 한강 페리 = 야간 운항 (외국인 매니아 fit) (c) 따릉이 = 외국인 24시간 day-pass 카드 가능 (d) 일부 산(N서울타워·응봉산) = 야간 등산 자제 + 케이블카 권장.
