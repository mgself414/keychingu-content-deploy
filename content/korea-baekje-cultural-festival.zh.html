百济文化节 指南——第72届 2026 公州·扶余（10/3~10/11），官方节目·费用·交通

副标题: 公州锦江新官公园·公山城与扶余定林寺址·石塔路·官北里，两座城市在同一时期各自举办。以 2026-10-07 官方网站为准 · 熊津幻想曲 10/7~10 21:00 · 公山城媒体艺术每天 19:30~22:00 · 扶余历史文化游行 10/9 · 夜间巡游与落花表演 10/10 · 闭幕 10/11

ISSUE 04 · #1068 · 2026-06-13

🎯 怎么用这份指南

百济文化节 (Baekje Munhwaje / 백제문화제) 是公州与扶余在同一时期各自举办的两个活动。官方网站也有两个（公州 gongju.baekje.org / 扶余 baekjeculturalfestival.kr），节目和舞台也不同。旧版指南里的“九德来主舞台”或“公山城百济游行 11 点”，在官方日程中并不存在。以下内容依据 2026-10-07 在两个官方网站上读到的第72届（2026-10-03~10-11，共 9 天），只列出 10/7 之后剩余的日程。每年 9~10 月举办，下一年的日程通常在上半年公布于官方网站。

📅 剩余日程——截至 10/7（官方）

日期 公州 (Gongju / 공주)（锦江新官公园 (Geumgang Singwan Gongwon / 금강신관공원)·公山城 (Gongsanseong / 공산성)） 扶余 (Buyeo / 부여)（定林寺址 (Jeongnimsaji / 정림사지)·石塔路 (Seoktap-ro / 석탑로)·官北里 (Gwanbuk-ri / 관북리)·九德来 (Gudeurae / 구드래)）
10/7(周三)~10/10(周六) 熊津幻想曲 (Ungjin Fantasia / 웅진판타지아)《青铜镜》21:00~21:30，锦江新官公园主舞台 —
每天至 10/11 公山城媒体艺术 19:30~22:00 —
10/8(周四) 忠南交响乐团演出 19:00 —
10/9(周五) — 百济历史文化游行 (Baekje Yeoksa Munhwa Haengnyeol / 백제역사문화행렬) 15:30~17:00 · 韩中日文化交流演出 19:00
10/10(周六) 熊津幻想曲最后一场 21:00 百济文化夜间巡游 (Baekje Munhwa Naiteu Peureideu / 백제문화 나이트 퍼레이드) 19:30~20:30 · 落花表演 (Nakhwa Nori / 낙화놀이) 19:00~21:00 九德来河滩
10/11(周日) 闭幕式 19:00~21:20 闭幕式 18:30~21:30

已经结束的：10/3 开幕、公山城实景演出《接·境：王妃渡过的夜晚》（10/4~5）、熊津城巡游（10/4）。烟花·无人机表演只有媒体报道，在官方日程中没有读到。

🏯 公州——锦江新官公园 + 公山城

  • 主题“青铜镜，照亮 1500 年百济之光”。主舞台是锦江新官公园（锦江河滩），夜间媒体艺术在公山城（UNESCO）。
  • 费用（官方公布部分）：锦江上的弥勒岛 (Mireuseom / 미르섬)与浮桥 (Baedari / 배다리)入场券，成人 7,000韩元 · 青少年 6,000韩元——穿百济服者·65 岁以上·小学生·公州市民免费，入场券内含 3,000韩元优惠券。舞台演出和媒体艺术没有公布费用，因此不断言是否收费。
  • 公山城本身与节日无关，成人 3,000韩元 · 09:00~18:00（#1043）。与武宁王陵 (Muryeong Wangneung / 무령왕릉)的王陵园联票 6,000韩元。
  • 交通（官方“交通指南”）：KTX·SRT 公州站 (Gongju-yeok / 공주역)（距龙山约 1.5 小时）→ 市内公交·出租车 / 自驾走公州 IC。停车场·接驳车信息只以图片形式发布，未能读取——以现场指引为准。
  • 在公州官网首页没有找到英文菜单（未核实）。

🪷 扶余——定林寺址 + 石塔路 + 官北里

  • 主题“美丽的百济，闪耀的泗沘”。舞台设在定林寺址·石塔路·官北里遗址一带。九德来是落花表演和波斯菊花田所在地。
  • 有英文网站：baekjeculturalfestival.kr/en。
  • 剩余重点：10/9 百济历史文化游行 15:30 · 10/10 夜间巡游 19:30 + 落花表演 19:00 九德来河滩 · 10/11 闭幕。
  • 遗迹费用与节日无关：定林寺址（博物馆免费）· 夫苏山城 (Busosanseong / 부소산성) 2,000韩元 · 国立扶余博物馆免费（周一休馆）· 百济文化园区 6,000韩元（周一休馆）——#1041。
  • 交通：扶余没有铁路。乘首尔南部客运站的长途客车，或从公州乘长途客车（所需时间请在订票网站确认）。接驳车·停车页面是图片，未核实。

🚶 公州 + 扶余 住一晚（按剩余日期）

  • 10/9(周五)：下午扶余历史文化游行 15:30 → 晚上韩中日演出 19:00 → 住扶余。
  • 10/10(周六)：白天定林寺址·夫苏山城 → 晚上只选一个：扶余夜间巡游 19:30 + 落花表演 19:00（同一个晚上）或者公州熊津幻想曲 21:00 + 公山城媒体艺术。晚上不要在两座城市之间往返。
  • 10/11(周日)：公州武宁王陵·国立公州博物馆 (Gungnip Gongju Bakmulgwan / 국립공주박물관) → 闭幕式 19:00。

⚠ 常见错误 5 条

1. 以为是一个节日而只看一处——公州·扶余的节目不同。官方网站也有两个。

2. 旧链接 baekje.kr——打不开。请用 gongju.baekje.org / baekjeculturalfestival.kr。

3. 去看实景演出·熊津城巡游——10/4~5 已经结束。

4. 晚上在两座城市之间往返——公州↔扶余坐公交移动会错过演出。晚上只留在一座城市。

5. 断言“全部免费”——弥勒岛·浮桥收费（7,000韩元），其余没有公布费用。

⚙ FAQ 6 条

1. 2026 年的日期？——10/3(周六)~10/11(周日)，9 天，第72届（官方）。

2. 晚上看什么？——公州媒体艺术 19:30~22:00（每天）+ 熊津幻想曲 21:00（至 10/10）/ 扶余 10/10 夜间巡游·落花表演。

3. 穿韩服的话？——穿百济服者免费进入公州弥勒岛·浮桥（官方）。

4. 有英文信息吗？——扶余网站有英文版。公州未核实。

5. 明年呢？——通常 9~10 月。上半年请到官方网站确认。

6. 住哪里？——公州韩屋村（#1043）·扶余市区。节日周末很早就会订满。
