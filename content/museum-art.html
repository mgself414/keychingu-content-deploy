⚠ 외국인 자주 실수 5가지

1. "한국 미술관 = 비쌈만": 한국 미술관 = 국립 + 시립 다수 무료 (국립중앙·SeMA·국립민속·국립현대 일부) + 외국인 매니아 가성비 1번지.

2. "국립중앙박물관 = 그냥 박물관": 국립중앙박물관 = 한국 #1 종합 (용산 2005) + 15,000점 + 영어 도슨트·앱·반가사유상 + 외국인 art 매니아 1순위.

3. "리움 = 비싸기만": 리움 = 한국 #1 사립 미술관 (한남) + Mario Botta·Jean Nouvel·Rem Koolhaas 3 건축가 + 외국인 인스타 1번지 + 무료 입장 (정기).

4. "간송 = 일반 미술관": 간송 = 한국 정통 미술 1번지 (성북) + 청자·백자·신윤복 미인도·김홍도 + 1년 2회 (봄·가을) 특별전 + 외국인 매니아.

5. "DDP·아모레 = 박물관 X": DDP 디자인 박물관·아모레퍼시픽 APMA = 건축 + 박물관 통합 1번지 + 외국인 매니아 (#172·#366).

⚙ FAQ 6개

1. 외국인 1순위 (한국 art 처음): 국립중앙·리움·MMCA 서울·SeMA·간송.

2. 외국인 무료 매니아: 국립중앙·SeMA·국립민속·MMCA 일부·리움 정기.

3. 외국인 인스타 1순위: 리움·디뮤지엄·DDP·아모레·뮤지엄 산.

4. 외국인 정통 한국 매니아: 간송·국립민속·환기·이중섭·간송.

5. 외국인 외곽 1박2일: 호암 (용인)·뮤지엄 산 (원주)·아라리오 (천안)·광주 비엔날레.
