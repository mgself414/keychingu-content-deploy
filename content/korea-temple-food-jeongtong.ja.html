🎯 このガイドの使い方

このガイドは、ソウルで精進料理(寺院料理)とテンプルステイを知り、体験できる場所をまとめたものです。僧侶から精進料理を学べる体験館、テンプルステイの案内と体験をする広報館、そしてテンプルステイや教育プログラムを運営するソウルの寺4か所です。韓国寺院料理文化体験館は事前予約制で、月曜日と祝日が休みです。

運営情報は韓国観光公社の観光情報(TourAPI)に登録されている値を写しました。このガイドは、韓国観光公社の観光情報に登録されている場所だけを扱います。

📍 学んで知る — 韓国寺院料理文化体験館・テンプルステイ広報館

韓国寺院料理文化体験館 (Hanguk Sachal Eumsik Munhwa Cheheomgwan / 한국사찰음식문화체험관)、鍾路区 Yulgok-ro 39 (율곡로 39)、☎ 02-733-4650 は、精進料理の調理法を伝える文化センターです。韓国観光公社の紹介によると、国内初の精進料理に特化した文化センターです。現役の僧侶が講師として登場し、人工調味料を使わず旬の食材で作る精進料理を教えます。伝統文様の茶食(タシク)を自分で押して作るワンデークラスのようなプログラムがあります。すべての体験は公式ウェブサイトで事前に予約しなければならないと登録されています。

  • 開く時間: 09:00~18:00。準備時間 11:30~13:00。
  • 休み: 毎週月曜日、祝日。
  • 料金: 1日体験 1人 10,000ウォン~30,000ウォン。正規講座はプログラムごとに異なります。
  • 駐車: 体験館の授業のときは1時間無料で、そのあとの料金は「10あたり 1,500ウォン」と登録されています。

テンプルステイ広報館 (Templeseutei Hongbogwan / 템플스테이 홍보관)、鍾路区 Ujeongguk-ro 56 (우정국로 56)、☎ 02-2031-2000 は、テンプルステイと精進料理を案内する場所です。僧侶との茶談 (Chadam / 차담)、伝統文様の彩色、蓮の花の紙花 (Jihwa / 지화)作りのような体験を運営し、韓国を訪れた外国人に私たちの文化を紹介しています。テンプルステイは、山寺で修行者の日常を体験するプログラムで、2002年の日韓ワールドカップをきっかけに始まりました。韓国観光公社の紹介によると、これまで200万人余りが参加しました。

  • 開く時間: 09:00~18:00。休み: 元日、旧正月・秋夕の連休、法定祝日。
  • 駐車: 可能。ペット: 不可。

📍 ソウルの寺 — 津寛寺・金仙寺・吉祥寺・奉恩寺

津寛寺 (Jingwansa / 진관사)、ウンピョン区 Jingwan-gil 73 (진관길 73)、☎ 02-359-8410 は、大韓仏教曹渓宗の直轄寺院です。韓国観光公社の紹介によると、プラムサ (Buramsa / 불암사)・サンマクサ (Sammaksa / 삼막사)・スンガサ (Seunggasa / 승가사)とともに、昔からソウル近郊の四大名刹に数えられてきました。高麗のヒョンジョン (Hyeonjong / 현종)が1011年にチングァン大師 (Jingwan Daesa / 진관대사)のために建て、韓国戦争のときの爆撃で廃墟になりましたが、復旧されたと伝えられています。2009年に七星閣 (Chilseonggak / 칠성각)を解体する過程で、太極旗に包まれた独立新聞など、独立運動に関する遺物20点余りが出てきました。テンプルステイが登録されています。

  • 開く時間: 09:00~18:00。休み: 年中無休。料金: 無料。駐車: 可能。

金仙寺 (Geumseonsa / 금선사)、鍾路区 Bibong-gil 137 (비봉길 137)、☎ 02-395-9911 は、鍾路区のクギドン (Gugi-dong / 구기동)、北漢山国立公園 (Bukhansan Gungnip Gongwon / 북한산국립공원)の碑峰 (Bibong / 비봉)コースへ登る道にある寺です。般若殿 (Banyajeon / 반야전)を過ぎると200年を超える松があり、108段の階段を上ると主仏を祀る大寂光殿 (Daejeokgwangjeon / 대적광전)に着きます。テンプルステイを運営していて(韓国人の予約案内 ☎ 02-395-9955)、事前に申し込めば英語で実施できると登録されています。

  • 開く時間: 常時開放。休み: 年中無休。料金: 無料。駐車: 可能。

吉祥寺 (Gilsangsa / 길상사)、ソンブク区 Seonjam-ro 5-gil 68 (선잠로5길 68)、☎ 02-3672-5945 は、ソンブクドン (Seongbuk-dong / 성북동)のサムガクサン (Samgaksan / 삼각산)の麓にある寺です。1987年にキム・ヨンハン (Gim Yeonghan / 김영한)さんが、ポプチョン (Beopjeong / 법정)僧侶の「無所有 (Musoyu / 무소유)」の思想に感動して、敷地7,000坪余りと不動産40棟余りを寄贈したことから始まり、1997年12月14日に吉祥寺として創建されました。極楽殿 (Geungnakjeon / 극락전)、説法殿 (Seolbeopjeon / 설법전)、地蔵殿 (Jijangjeon / 지장전)、梵鐘閣 (Beomjonggak / 범종각)があり、チェ・ジョンテ (Choe Jongtae / 최종태)彫刻家の観世音菩薩像があります。2013年にポプチョン僧侶の遺品と著書を展示する真影閣 (Jinyeonggak / 진영각)を開きました。説法殿で、仏教大学、ヨガ、写経、禅瞑想などの教育プログラムを運営しています。

  • 開く時間: 09:00~18:00。休み: 年中無休。駐車: 可能。

奉恩寺 (Bongeunsa / 봉은사)、江南区 Bongeunsa-ro 531 (봉은사로 531)、☎ 02-3218-4800 は、江南区サムソンドン (Samseong-dong / 삼성동)の寺です。794年にヨンファ国師 (Yeonhwa Guksa / 연화국사)がキョンソンサ (Gyeonseongsa / 견성사)という名で建て、1498年に成宗の継妃 チョンヒョン王后 (Jeonghyeon Wanghu / 정현왕후)が大きく建て直して奉恩寺に名前を変えました。テンプルステイや仏教大学、経典学校のようなプログラムを運営しています。

  • 開く時間: 09:00~18:00。休み: 年中無休。料金: 無料。駐車: 可能。

⚠ 前もって知っておきたい3つのこと

  1. 韓国寺院料理文化体験館は事前予約制です — 月曜日と祝日が休みで、11:30~13:00は準備時間です。
  2. テンプルステイ広報館は法定祝日が休みです — 元日と旧正月・秋夕の連休も休みです。
  3. 金仙寺のテンプルステイは、英語での実施を事前に申し込みます — テンプルステイの韓国人の予約案内の電話は02-395-9955と登録されています。

⚙ FAQ 2

Q. 精進料理を自分で作ってみられますか?

A. 韓国観光公社の登録情報では、韓国寺院料理文化体験館で僧侶が教える精進料理と茶食のワンデークラスがあり、1日体験は1人 10,000ウォン~30,000ウォンです。事前予約制です。

Q. 外国語でテンプルステイができますか?

A. 金仙寺は、事前に申し込めばテンプルステイを英語で実施できると登録されています。
