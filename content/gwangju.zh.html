🎯 为何选择光州 (Gwangju / 광주) 全攻略

光州 (Gwangju / 광주) = 韩国民主化运动的起点 (5·18民主化运动 1980) + 艺术·文化之城 + 起亚 (KIA / 기아) 棒球 (KTX 高速列车 (Korean Train eXpress) 从龙山 (Yongsan / 용산) 到光州松汀 (GwangjuSongjeong / 광주송정) 仅需2小时)。这里是外国游客深度游的目的地，也是光州双年展 (Gwangju Biennale / 광주비엔날레) 的发源地。

⚠ 外国游客常犯的3个错误

1. “光州 (Gwangju / 광주) = 小城市”: 光州 (Gwangju / 광주) = 韩国第六大城市 + 民主化运动的起点 + 艺术之城。

2. “5·18民主化运动 = 难懂”: 国立5·18民主墓地 (Gukrip 5·18 Minju Myoji / 국립5·18민주묘지) + 国立亚洲文化殿堂 (ACC / 국립아시아문화전당) = 外国游客深度游首选 + 提供完善的英文导览。

3. “起亚 (KIA / 기아) = 棒球强队”: 起亚冠军场 (KIA Champions Field / KIA 챔피언스 필드) = 韩国夺冠次数最多的球队 (11次夺冠) + 外国KBO棒球 (韩国职业棒球联赛) 爱好者必去。
