외국인 광주 ACC (국립아시아문화전당) — 아시아 #1 문화복합 2014

> 부제: 외국인 관광객용 ACC 2014년~ 11.3만m² + 5·18 옛 도청 + 어린이문화원 + 영문 풀세트

ISSUE 04 · #1027 · 2026-06-08

🎯 왜 광주 ACC 가이드인가

ACC (Asia Culture Center·국립아시아문화전당) = 2014년~ 아시아 #1 문화복합·11.3만m²·아시아 문화·미술·공연 매트릭스. 외국인 페인포인트 = (a) "ACC = 일반 박물관" 잘못된 인식 (b) 2014년 개관·아시아 매트릭스 #1 (c) 5·18 옛 도청 부지·민주화 매트릭스 통합 (d) 어린이문화원 = 가족 매니아 #1 (e) 영문 풀세트·결제 카드·외국인 친화 매트릭스.

본 가이드는 5축 12 시그니처 + ACC + 어린이문화원 + 5·18 옛 도청.

★ 한눈에 5축 12 시그니처

> 매니아: 공연 + 갤러리 + 박물관 풀세트 = 4-5시간

🏛 5축 deep dive

① ACC 메인 (2014~·11.3만m²)

  • 시그니처: 2014년~ 아시아 #1 문화복합·11.3만m²·아시아 문화·미술·공연 매트릭스
  • 외국인 친화도: ★★★★★ (영문 풀세트·MZ + 가족)
  • 시간: 09:00~18:00·휴관 월요일·무료 또는 5,000원 (특별전)

② 어린이문화원 (가족 매니아 #1)

  • 시그니처: 무료·어린이·가족 매니아 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문·다국어·결제 카드)
  • 추천: 가족 + 어린이 = 풀데이 매트릭스

③ 5·18 옛 도청 (1980·민주화 매트릭스)

  • 시그니처: 1980 5·18 민주화 운동·전두환 군부·한국 민주주의 매트릭스 #1
  • 외국인 친화도: ★★★★★ (영문·교육적·역사 매니아)
  • 시간: 09:00~18:00·무료

④ ACC 공연장

  • 시그니처: 아시아 공연·연극·무용·국악·매니아 매트릭스
  • 외국인 친화도: ★★★★ (영문 자막·MZ)
  • 가격: 공연 = 20,000~80,000원/회

⑤ F&B + 굿즈 + 면세점

  • 시그니처: 카페·식당·한국 + 아시아 굿즈
  • 외국인 친화도: ★★★★★ (영문·결제 카드)

🚶 외국인 ACC 2.5시간 코스

시간 동선 활동
10:00~11:00 ACC 메인 + 아시아 박물관 + 갤러리 -
11:00~11:30 어린이문화원 (가족 매니아) 무료
11:30~12:30 5·18 옛 도청 + 박물관 + 추모공간 무료

총 소요: 2.5시간·총 비용 = 5,000~15,000원/인 (입장·체험)·대부분 무료

⚠ 외국인 자주 실수 5가지

1. "ACC = 일반 박물관": 2014~ 아시아 #1 문화복합·11.3만m²·아시아 매트릭스 #1.

2. "어린이문화원 = 어린이만": MZ + 가족 + 매니아 매트릭스·체험관 + 공연.

3. "5·18 옛 도청 = 일반 건물": 1980 민주화 매트릭스 #1·박물관 + 추모공간 + 영문 풀세트.

4. "공연 = 한국어만": 영문 자막 + 다국어 풀세트·외국인 매니아 매트릭스.

5. "굿즈 = 일반 면세점": 한국 + 아시아 매트릭스·MZ 매니아 매트릭스.

⚙ FAQ 6개

1. 외국인 입문 1순위: ACC 메인 + 어린이문화원 + 5·18 옛 도청 = 2.5시간.

2. 시간: 09:00~18:00·휴관 월요일·평일 베스트.

3. 공연: 사전 예약·영문 자막 + 다국어·20,000~80,000원/회.

4. 5·18 박물관 영문: 영문 풀세트·외국인 매니아 매트릭스 #1.

5. 알레르기·식이: 카페·식당 알레르겐 사전 고지.

6. 추천 페르소나: 가족·어린이 = 어린이문화원 + 카페 / MZ·매니아 = 갤러리 + 공연 + 굿즈 / 매니아·역사 = 5·18 옛 도청.
