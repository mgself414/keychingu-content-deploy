⚠ 外国人がよくやる失敗5つ

1. 「4チャンネルはどれも似たようなもの」: 価格・雰囲気・営業時間はまったく違う。夜食=ジャンスドン / vlog=クァンジャン / ソジュ=ポジャンマチャ / 本格派=ハンジョンシク。

2. 「ジャンスドンは昼間営業」: ジャンスドンは実際は17:00~03:00の夜食マニアの聖地・昼間ではない。

3. 「ポジャンマチャは英語が通じる」: ポジャンマチャは韓国語オンリーの本格派・翻訳アプリが必須。

4. 「クァンジャンポッサムは食事扱い」: クァンジャンはvlog映えの軽食にも食事にもなる・1皿は2~3人でシェアするサイズ。

5. 「ハンジョンシクは常に高い」: ハンジョンシクの価格帯は40,000~150,000ウォン(ランチならコスパの良い選択肢もある)。

⚙ FAQ 8つ

1. 初めてのおつまみ体験はどのチャンネルから?: クァンジャンポッサム (昼間・入門No.1) → ジャンスドンチョッパル (夜食) へ。

2. インスタ・vlog向けは?: クァンジャンポッサム (No.1)・ジャンスドンチョッパル・チョンノのポジャンマチャ。

3. ソジュマニア向けは?: ポジャンマチャ (最も本格派No.1) + ジャンスドンチョッパル。

4. デート・記念日向けは?: ジャンスドンチョッパル・ハンジョンシク。

5. 家族連れ向けは?: クァンジャンポッサム + ハンジョンシク。

6. アレルギー・妊娠中の注意は?: #861の免責事項 参照。

7. 支払い・チップは?: カードOK / 市場・ポジャンマチャは一部現金のみ / チップ不要。

8. VAT還付は?: 飲食は一般的に還付対象外。

⚠ 医療・安全・食事に関する免責事項

おつまみ4チャンネルはすべて一般的な韓国料理。妊婦・子供は限定的にOK (飲酒・ホンオは不可)。アレルギー (豚肉・魚介類・唐辛子) は事前申告を。飲酒は妊婦・未成年不可。食中毒が疑われる場合は☎1339(医療、英語対応)へ。本ガイドは一般情報であり、医療アドバイスではない。

食事制限の代替案:

  • ハラール・コーシャ: 4チャンネルすべてに豚肉・魚介類が含まれる → 代替はビビンバ・チャプチェ・寺院料理 (#854)。
  • ベジタリアン・ヴィーガン: 4チャンネルすべてが非菜食 → 菜食は寺院料理・ビビンバへ。
  • グルテンフリー: スユク・ポッサム・チョッパル=OK / コルベンイムチムのソミョン (소면) は不可 / チェユク (제육) の一部のタレは不可。
