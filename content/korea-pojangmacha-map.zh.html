韩国路边摊指南 — 首尔夜间露天摊街3处(钟路3街、乐园洞、乙支路干明太鱼巷)、海边路边摊街4处、按店名寻访的路边摊·啤酒馆7家(满船啤酒馆 (Manseon Hof / 만선호프)、浪漫24路边摊 (Nangman 24 Pocha / 낭만24포차)等) (2026年10月官方数据)

副标题：首尔的摊贩实行需取得道路占用许可的"街边店 (Geoligage / 거리가게)"许可制(首尔市，2019年起)· 乙支路干明太鱼巷 (Euljiro Nogari Golmok / 을지로 노가리골목) 1980年11月开始，2015年入选首尔未来遗产(VisitKorea、VisitSeoul)· 乐园洞 (Nakwon-dong / 낙원동) 路边摊只收现金(VisitKorea)· 丽水浪漫路边摊街 (Yeosu Nangman Pocha-geori / 여수 낭만포차거리) 共18个摊位，夏季 18:00~01:00(VisitKorea)— 截至2026-10-21

🎯 如何使用本指南

天一黑，店门前摆出塑料桌椅，橙色帐篷里升起烤串的烟。本指南把路边摊 (Pojangmacha / 포장마차，简称"포차 (Pocha / 포차)")分成三类：首尔市中心夜间露天摊街、海边路边摊街、挂着"路边摊"招牌的室内店。店名、位置、营业时间只采用在VisitKorea、VisitSeoul、首尔市官方页面上读到的数据。

路边摊比其他餐厅更常换位置、换时间。首尔市把摊贩称为"街边店 (Geoligage / 거리가게)"，自2019年起实行必须取得道路占用许可才能经营的许可制(首尔市)。中区 (Jung-gu / 중구) 另有《街边店运营规定》(自治法规信息系统)。所以VisitKorea对各条街的营业时间也只写"各店不同"。本期没有营业时间的地方，标注为营业有变动。本期写给想体验一次路边摊的人。

旧版指南的"钟路3街干明太鱼巷"把两个地方混在了一起。在VisitKorea上，干明太鱼巷 (Nogari Golmok / 노가리골목) 位于乙支路3街 (Euljiro 3-ga / 을지로3가)(中区)，而钟路3街 (Jongno 3-ga / 종로3가) 是路边摊街(钟路区观水洞 (Gwansu-dong / 관수동))。"朱马洞摊贩巷 (Jumadong Nojeom Golmok / 주마동 노점 골목)"在官方页面上找不到，安全排名和"18:00~02:00"没有出处，已删除。

🏮 首尔市中心夜间露天摊街

  • 钟路3街路边摊街 (Jongno 3-ga Pojangmacha-geori / 종로3가 포장마차 거리) — 钟路区观水洞 (Gwansu-dong / 관수동)，钟路3街站1号线和5号线出入口一侧。也叫"钟路3街露天摊街 (Yajang-geori / 야장 거리)"，每个出口都有路边摊。VisitKorea写13号出口一侧的路边摊由"经验20年以上的老板"经营。通常从傍晚开到凌晨，菜单每家不同，从活章鱼 (Sannakji / 산낙지)、海鞘 (Meongge / 멍게)、海参 (Haesam / 해삼) 到乌冬面、拉面都有(VisitKorea)。营业时间、休息日各店不同 — 营业有变动
  • 乐园洞路边摊街 (Nakwon-dong Pojangmacha-geori / 낙원동 포장마차거리) — 钟路区钟路3街站5号出口，乐园乐器商街 (Nakwon Akgi Sangga / 낙원악기상가) 前。天色渐暗，室外桌椅就坐满了。大多只收现金。有烤串、海鲜、汤、炒菜(VisitKorea)。南仁寺洞旅游咨询处 02-737-7885。营业时间各店不同 — 营业有变动
  • 乙支路干明太鱼巷 (Euljiro Nogari Golmok / 을지로 노가리골목) — 中区，乙支路3街站附近(VisitKorea写4号出口，VisitSeoul写3号出口86m，出口编号不同)。1980年11月从第一家干明太鱼苗啤酒馆 (Hof / 호프)"乙支OB熊 (Euljiro OB Bear / 을지OB베어)"开始，是印刷巷的工人们就着干明太鱼苗喝生啤的地方(VisitKorea)。2015年入选首尔未来遗产(VisitSeoul)
  • 满船啤酒馆 (Manseon Hof / 만선호프) · 草原啤酒馆 (Chowon Hof / 초원호프) — VisitSeoul线路页面(韩文版写作"满船啤酒馆 (Manseon Hof / 만선호프)、草原啤酒馆 (Chowon Hof / 초원호프)")点名这两家为巷子的代表店，并写"街边桌子在下午6点以后"(VisitSeoul)。各店营业时间未公布 — 营业有变动
  • 乙支OB熊 (Euljiro OB Bear / 을지OB베어) 现在是否营业、位置在哪里，未能确认
  • 想与首尔傍晚散步结合，见 #1309 明洞→乙支路傍晚步行路线

🌊 海边路边摊街

  • 浪漫路边摊街 (Nangman Pocha-geori / 낭만포차거리)(丽水) — 全南丽水市河梅路 (Hamel-ro / 하멜로) 102，龟船大桥下的广场。18个摊位在营业。夏季(3~10月) 18:00~01:00，冬季(11~2月) 17:00~24:00，每月第一周的周三休息(假期、4~6月、8~10月除外)，可刷卡，061-659-4553(VisitKorea)
  • 浪漫24路边摊 (Nangman 24 Pocha / 낭만24포차) — 丽水市河梅路 (Hamel-ro / 하멜로) 78，在浪漫路边摊街内。石章鱼牛腩三合 (Dolmuneo Chadol Samhap / 돌문어 차돌삼합)、螯虾生鱼片 (Ttaksaeu Hoe / 딱새우 회)、烤章鱼卷 (Nakji Horyeongi / 낙지호롱이)。周一至周四 11:30~03:00，周五至周日 11:30~04:00，全年无休，0507-1336-9881(VisitKorea)。价格未公布
  • 东明港路边摊街 (Dongmyeonghang Pojangmacha-geori / 동명항 포장마차 거리)(束草) — 江原道束草市永郎海岸1街 (Yeongnang Haean 1-gil / 영랑해안1길) 13。烤海螺 (Golbaengi-gui / 골뱅이구이)、岩龙虾、花虾生鱼片、明太鱼炖锅 (Dorumuk-jjigae / 도루묵찌개)。16:00~01:00(各店不同)，永郎海岸路 (Yeongnang Haeangil / 영랑해안길) 公共停车场免费(VisitKorea)。日出旅游咨询处 (Haemaji Gwangwang Annaeso / 해맞이 관광안내소) 033-635-2003
  • 蛇来浦口路边摊街 (Sorae Pogu Pocha-geori / 소래포구 포차거리)(仁川) — 仁川南洞区蛇来站路 (Soraeyeok-ro / 소래역로) 12，距蛇来浦口站约350m。傍晚搭起帐篷，供应盐烤大虾、清蒸花蟹。也可以把在鱼市场买的海鲜带到路边摊吃(VisitKorea)。营业时间各店不同 — 营业有变动
  • 莲花里海鲜路边摊村 (Yeonhwa-ri Haemul Pojangmacha-chon / 연화리 해물 포장마차촌)(釜山机张) — 釜山机张郡机张邑莲花里 (Yeonhwa-ri / 연화리)。鲍鱼粥、烤鲍鱼、海鲜拼盘。营业时间、休息日写的是"电话咨询"，且不能刷卡，机张郡文化观光科 051-709-4086(VisitKorea)。附近路线见 #270 釜山机张一日路线

🦪 挂"路边摊"招牌的室内店

这些是在建筑物内供应路边摊菜单的地方，营业时间和休息日有官方公布。

  • 京城路边摊 (Gyeongseong Pocha / 경성포차)(江陵) — 江原道江陵市海岸路 (Haean-ro / 해안로) 280，1楼5号(江门洞 (Gangmun-dong / 강문동))。招牌是烤贝类，另有什锦贝汤、白骨螺汤 (Baekgolbaengi-tang / 백골뱅이탕)。周二至周五 04:30~24:00，周六、周日 16:00~24:00，每周一休息(VisitKorea)。周二至周五的开门时间04:30照官方数据照录 — 去之前请确认
  • 浪漫路边摊 (Nangman Pocha / 낭만포차)(江陵) — 江原道江陵市江陵大路 (Gangneung-daero / 강릉대로) 435(浦南洞 (Ponam-dong / 포남동))。五花肉杜鲁炒 (Samgyeop Durichigi / 삼겹두루치기)、鸡胗 (Dakttongjip / 닭똥집)、干明太鱼 (Meoktae / 먹태)。16:00~23:00，全年无休，电话预约 033-653-8495(VisitKorea)
  • 贝类路边摊 (Jogae Pocha / 조개포차)(始兴乌耳岛) — 京畿道始兴市乌耳岛路 (Oido-ro / 오이도로) 215。烤贝类一桌，有自助吧。平日 11:00~01:00，周五 11:00~03:00，周六 10:00~03:00，周日 10:00~01:00，全年无休，0507-1406-7338(VisitKorea)
  • 海女金今丹路边摊 (Haenyeo Kim Geumdan Pojangmacha / 해녀김금단포장마차)(统营欲知岛) — 庆南统营市欲知面欲知环岛路 (Yokji Ilju-ro / 욕지일주로) 91-5。海女和渔民捕捞的海鲜，招牌是鲭鱼生鱼片。09:00~20:00，全年无休，0507-1382-5136(VisitKorea)。是岛屿，所以也要看船班时间
  • 五家都没有公布价格 — 请打电话确认

🥗 饮食须知

  • 价位：本指南的街道和店家都没有官方韩元价格。VisitKorea只写乐园洞路边摊"大多便宜"
  • 素食：路边摊菜单以海鲜和肉为主(VisitKorea菜单列表)。乌冬面、拉面的汤也可能是鳀鱼或海鲜高汤，请先问清楚
  • 清真：本期的路边摊没有清真标识，且都卖酒。首尔KMF认证的韩餐厅有伊德 (Eid / 이드) — 龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00(VisitSeoul)
  • 过敏：贝类、甲壳类(虾、蟹)、软体类(小章鱼 (Nakji / 낙지)、章鱼)是基本菜单。也有像活章鱼 (Sannakji / 산낙지) 这样生吃的菜(VisitKorea)
  • 出示给店员看的卡片见 #1300 饮食需求说明手册

🧰 路边摊实用信息 — 独自用餐、预约、付款、点餐、交通

  • 独自用餐：夜间露天摊街是抢座位的战场 — VisitKorea写乐园洞"傍晚早些时候也会满座"。适合一个人坐的店见 #348 首尔独食餐厅地图
  • 预约：街边路边摊视为没有预约，早点去。室内店中，江陵浪漫路边摊 (Nangman Pocha / 낭만포차) 接受电话预约(VisitKorea)
  • 付款：乐园洞只收现金，机张莲花里不能刷卡，丽水浪漫路边摊街可以刷卡(VisitKorea)。带一点现金 — #527 韩国支付系统
  • 点餐·喝酒：路边摊的点单顺序和选酒见 #844 路边摊点餐·配酒流程，语言不通时见 #1339 点餐礼仪。买酒不按周岁，而是从年满19岁那年的1月1日起才可以(便捷生活法令 (Chatgi Swiun Saenghwal Beopnyeong / 찾기쉬운 생활법령))
  • 交通：丽水、束草见 #1297 高速·城际巴士手册，交通卡见 #1298 三种交通卡怎么选

⚠ 常见的4个误区

1. "干明太鱼巷在钟路3街" — 干明太鱼巷在乙支路3街，钟路3街是路边摊街(VisitKorea)。车站不同

2. "路边摊随处都开通宵" — 街边路边摊每家营业时间不同(VisitKorea)，在许可制之下位置也会变(首尔市)。丽水浪漫路边摊街冬季24点关门(VisitKorea)

3. "一张卡就够了" — 乐园洞只收现金，机张莲花里不能刷卡(VisitKorea)

4. "露天摊的桌子白天也有" — VisitSeoul写乙支路的街边桌子在下午6点以后
