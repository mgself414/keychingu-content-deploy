首尔约会路线指南——7大区域按2026年10月官方数据：免费美术馆·画廊·汉江夜景·巷弄漫步

🎯 本指南使用方法

约会路线说到底就是"去哪里、做什么"，但旧版指南只有各区域的氛围和人设表，没有是否开放、多少钱。这次只收录今天（2026-10-08）在官方页面确认过的地点——美术馆·画廊（#285·#350）、弘大·延南（#216）、汉江（#786）、龙山（#710）——并重新分配到7个区域。餐厅·咖啡馆·酒吧没有官方出处，所以不列名称，交给"地图应用的评价数"。核心有两条：周一画廊·三星美术馆Leeum·首尔市立美术馆休馆，只有国立现代美术馆首尔馆·国立中央博物馆开放；周三·周六晚上国立现代美术馆（18~21点免费）·国立中央博物馆（到21点）开放。

🌆 晚间·夜景——按星期来选

  • 周三·周六：国立现代美术馆首尔馆18~21点免费 → 国立中央博物馆开到21点 → 盘浦喷泉3场（19:30~20:50，2026年节能运营）。
  • 周五·周六：首尔月亮开到23点 · 汝矣岛游船22点星光航次（25,900韩元）。
  • 周一：画廊·三星美术馆Leeum·首尔市立美术馆休馆 → 改去国立现代美术馆首尔馆 + 国立中央博物馆 + 汉江。
  • 首尔世界烟花节（9/5）·汉江泳池（~8/30）今年已结束（#786）。

🖼 白天——两条步行路线

  • 三清画廊漫步（周二~周六）：安国站1号口 → 国立现代美术馆首尔馆 → 国际画廊·PKM·Arario（未标注免费，通常免费）→ 韩美博物馆（15,000）→ 首尔工艺博物馆（免费）。10月展览见 #285。
  • 汉南画廊漫步（周二~周六）：汉江镇站 (Hangangjin / 한강진역) 1号口 三星美术馆Leeum（常设展免费）→ 梨泰院路 Pace·Lehmann Maupin → 读书堂路 ROPAC → 新龙山 APMA（需预约）。10/9 韩文节，Pace·Esther Schipper 休馆。

🌳 漫步——两个不花钱的地方

  • 京义线林荫路延南段：弘大入口站3号口447m，6.3km线形公园，免费（VisitSeoul）。
  • 盘浦汉江公园：新盘浦站1号口·高速巴士客运站站8-1，24小时免费，夜间喷泉3场。

🍽 为什么没有餐厅·咖啡馆

  • 没有任何官方页面把特定餐厅·咖啡馆指定为约会路线。店铺请按地图应用的评价数 + 当天是否营业来选，本指南只写到"哪个站、哪条路"。

⚠ 常见的5个错误

1. 周一去汉南·三清画廊约会——全部休馆。改去国立现代美术馆首尔馆·国立中央博物馆。

2. 盘浦喷泉21点场次——2026年是19:30·20:00·20:30共3场。

3. 把游船票价当成2万韩元——月光航次32,900·烟花航次45,900。

4. APMA 现场入场——需线上预约。

5. 在汉南找贝浩登·白立方——它们在清潭道山公园。

⚙ FAQ 6

1. 第一次约会路线？——周三·周六：安国站国立现代美术馆（18点免费）→ 三清晚餐 → 汉江喷泉19:30。

2. 只想全免费？——京义线林荫路 → 弘大红路街头演出 → 盘浦喷泉。全部免费。

3. 下雨怎么办？——国立现代美术馆·国立中央博物馆·三星美术馆Leeum常设展（免费）。见 #280。

4. 纪念日晚上？——游船月光航次19点（32,900）或星光航次22点。

5. 周一？——国立现代美术馆首尔馆 + 国立中央博物馆 + 汉江。

6. 推荐餐厅？——本指南没有。看地图应用的评价数。
