⚠ 외국인 자주 실수 5가지

1. "한국어 = 학원만": 한국어 = KIIP (정부 무료) + 학원 (#403) + TTMIK (YouTube 6M) + HelloTalk·Tandem + K-pop·드라마 + 외국인 매니아 1번지 풀세트 + #403·#516 통합.

2. "KIIP = 못 들음": KIIP = 외국인 거주 1년+ + 정부 무료 (415시간 풀세트) + 외국인 매니아 1번지 + 영어 OK + #252·#403 통합.

3. "TTMIK = 입문만": TTMIK = YouTube 6M + 입문~고급 풀세트 + 외국인 영어 OK + 외국인 1번지 + #178·#403 통합.

4. "한국어 = 어려움": 한국어 = 한글 24시간 학습 + 회화 cluster + HelloTalk·Tandem + 외국인 매니아 1번지 + #520·#516 통합.
