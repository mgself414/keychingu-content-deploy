芦原京春线林荫路，傍晚 — 从花郎台旧站到京春铁桥音乐喷泉，沿6.8公里废线向西走的顺序

副标题：首尔有两条废线公园：西边的京义线林荫路(#491)2016年建成，东边的京春线林荫路直到2026年6月才连通6.8公里全程。这一篇傍晚走东边这条路——从1939年老站亮灯的花郎台铁路公园出发，经孔陵洞市场，到月溪洞京春铁桥20:30的音乐喷泉收尾。约3小时，仅周二至周日。

ISSUE · #1363 · 2026-09-07

🎯 定调——东边的废线，日落之后才是正片

弘大 (Hongdae / 홍대)、延南 (Yeonnam / 연남) 一带的京义线林荫路 (Gyeongui Line Forest Trail / 경의선숲길)，外国游客大多知道。首尔还有一条它的姊妹线。城市东北端，横穿芦原区 (Nowon-gu / 노원구) 的京春线林荫路 (Gyeongchun Line Forest Trail / 경춘선숲길)——建在2010年停运的京春线铁轨之上，全长6.8公里的线形公园。比京义线林荫路稍长，建成却晚了10年。直到2026年6月29日，最后870米路段开通，光云大站 (Gwangun University Station / 광운대역) 到花郎台才第一次连成一条完整的线。

这条路傍晚比白天好。东端花郎台铁路公园 (Hwarangdae Railroad Park / 화랑대 철도공원)的旧站舍，在日落前30分钟亮灯；西端京春铁桥 (Gyeongchun Railway Bridge / 경춘철교)的音乐喷泉，19:30和20:30各喷一次水。两者之间是孔陵洞 (Gongneung-dong / 공릉동) 的傍晚市场。所以这一篇从东走到西——从点灯开始，到喷泉结束。

  • 总耗时：约3小时(步行约6公里·1.5小时 + 停留时间——区间分钟数为估算)
  • 推荐时段：周二至周日，日落前30分钟出发。9月初首尔日落约在18:50，故17:45从花郎台站 (Hwarangdae Station / 화랑대역) 出发；10月末日落提前到17:30左右，需相应提前1小时出发。周一芦原灯光花园 (Nowon Light Garden / 노원불빛정원) 和音乐喷泉都休息。
  • 坡度：无——原是铁路，路面平坦，自行车道与步行道分开

为什么是京春线林荫路——新近完工的东边版本

京春线是1939年铺设的首尔—春川 (Chuncheon / 춘천) 铁路。2010年线路迁移，芦原区段废弃，2013年启动公园化，2017年先开通约6公里。剩下的是月溪洞 (Wolgye-dong / 월계동) 一侧870米——2026年6月29日这一段开通后，从光云大站人行天桥经京春铁桥、孔陵洞到花郎台的6.8公里才第一次不间断连通。同一天京春铁桥上开了音乐喷泉，半个月后桥上又开了咖啡馆。简言之，这条路是2026年才完工的路。

如果说京义线林荫路(6.3公里，2016年完工)是伴着弘大、延南的咖啡街一起长大的，那京春线林荫路就是穿过公寓楼、学校和市场之间的居民区道路。不是观光地，而是社区居民自己用的公园——对外国游客来说，这一点反而是看点。

📖 故事1——走在曾经跑火车的路上：花郎台旧站舍1939年7月以"泰陵站"之名开业，1958年改名花郎台站，运营到2010年才停运。这是首尔留存的最后一座简易站(国家登录文化财，2006年指定)。站前铁轨上如今仍停着火车——只是静止的展示品，而铁轨曾经延伸的方向，正是你今晚要走的路。

🚶 路线——从东端走到西端

起点是6号线花郎台站4号出口。地铁站名和旧站舍都叫"花郎台"，容易搞混——地铁站到旧站舍相距900米，步行约15分钟。

① 花郎台站4号出口 → 花郎台铁路公园 (🚶 约15分钟)

  • 沿花郎路 (Hwarang-ro / 화랑로) 向东走。公园入口处是花郎台旧站 (old Hwarangdae Station / 옛 화랑대역)站舍(单层木造，1939年)，站舍前铁轨上停着几列展示列车——窄轨蒸汽机车与客车、还有来自国外的有轨电车等(具体构成以现场标示为准)。站舍内部现作展览空间使用。
  • 建议在天黑前抵达，趁天还亮着看一眼列车和站舍。旁边还有集装箱改造的画廊、用退役客车做的钟表展馆、火车主题咖啡馆，营业时间各设施不同，请现场确认。

② 芦原灯光花园点灯 (停留约30分钟)

  • 铁路公园一带的灯光庭院。周二至周日，日落前30分钟亮灯，22:00熄灯。周一休园，免费，天气恶劣时休园。点灯时间随季节变动，记住的不是"几点"，而是"日落前30分钟"。
  • 灯光亮起的瞬间是这段行程的第一个高潮。列车和站舍被灯光点亮时在这里拍照，然后30分钟内出发——因为西端的喷泉20:30开始。

③ 铁路公园 → 京春线林荫路西段 → 孔陵洞 (🚶 约40分钟·估算)

  • 沿着旧铁轨方向，也就是向西走上林荫路。步行道与自行车道分开，两旁是公寓楼、学校和住宅。跟着出来散步的当地居民同一个速度走。
  • 📖 故事2——两条废线的姊妹篇：首尔把两条穿过市区的铁路，隔了10年先后改成公园。西边的京义线林荫路是2016年，东边的京春线林荫路是2026年。两条路都保留了"火车曾经通过的宽度"，又窄又长。弘大一带成了咖啡馆与旅行者的路，这一边则留给了婴儿车和自行车——同样的设计，不同的社区。

④ 孔陵洞鬼怪市场 (Gongneung-dong Dokkaebi Market / 공릉동도깨비시장) 的傍晚 (🚶 约10分钟 + 停留约20分钟)

  • 7号线孔陵站 (Gongneung Station / 공릉역) 2号出口步行7分钟的常设传统市场。每天08:00~22:00营业，晚上也开着(全场统一休市日未确认——传统节日当天不少店铺会关门)。绕小吃、小菜、水果那几条巷子转一圈，简单解决晚饭。不写具体店名——市场本身就是目的地。
  • 时间不够就在这里收尾：孔陵站就在旁边(路线A收尾)。喷泉可以改天单独去月溪站看，只要30分钟。

⑤ 孔陵洞 → 月溪洞 (Wolgye-dong / 월계동) 京春铁桥 (🚶 约45~50分钟·估算)

  • 重新回到林荫路继续向西。这一段最长也最暗——整条林荫路的夜间照明未经确认(只确认了铁路公园段)，没有路灯的区间就靠大路一侧走。目标是20:15前抵达桥边。

⑥ 京春铁桥音乐喷泉20:30——收尾 (约20分钟 + 🚶 约10分钟)

  • 跨越中浪川 (Jungnangcheon / 중랑천) 的旧京春线铁桥上。2026年6月30日开放，至10月31日，周二至周日19:30、20:30各一场，每场约20分钟，周一及雨天休演。用激光和镜面做的喷泉秀在桥下水面上展开。桥上有一家火车造型的咖啡馆(3~11月09:00~21:00营业，周二休息——和喷泉的休息日不同)，等喷泉时可以在这里坐坐。
  • 收尾：步行约10分钟(约800米)到1号线月溪站 (Wolgye Station / 월계역) 4号出口。光云大站方向也有一条进出路线(人行天桥)，但距离未确认。

🙏 这条路线的礼仪——住宅区里的公园

  • 林荫路两侧全是住家。晚上不要大声喧哗，听音乐请用耳机。
  • 步行道和自行车道是分开的，别为了拍照站在自行车道上。
  • 在市场不要正面拍摄商品和人。东西没买之前不要用手摸。
  • 不要爬上灯光花园或铁桥的栏杆。喷泉溅水的位置站后排，不要站前排。
  • 垃圾自己带走，公园里垃圾桶很少。

💡 容易懵的点

  • 周一整条路线走不通：灯光花园和音乐喷泉周一都休息。泰陵·康陵 (Taereung and Gangneung Royal Tombs / 태릉·강릉) 也周一闭馆。
  • 花郎台站 ≠ 花郎台旧站：从地铁6号线花郎台站(首尔女大入口)到旧站舍900米·15分钟。想直接上林荫路走2号出口(8~10分钟)，去铁路公园走4号出口。
  • 点灯时间每天都不一样：按"日落前30分钟"算，9月初约18:20，10月末约17点。出发前查一下当天的日落时间。
  • 喷泉只演到10月31日：11月起⑥这一站没有了——那时只靠花郎台灯光花园(演到22:00)把路线砍半。
  • 下雨两个都休：灯光花园遇天气恶劣休园，喷泉遇雨休演。备选方案是室内的#280。
  • 市场现金更方便：能刷卡的店不少，但小额还是现金好用(#1301)。T-money卡 (티머니) 见#1298。

FAQ 6

Q1. 一定要走完6公里吗？

  • 不用。有在④孔陵洞收尾的短版(约1.5小时)。喷泉可以改天单独去月溪站看，只要30分钟。

Q2. 和京义线林荫路有什么不同？

  • 长度差不多(6.3公里 vs 6.8公里)，性格不一样。京义线林荫路是咖啡街，京春线林荫路是居民区公园。而且旧站舍、展示列车、桥上喷泉，只有这一条路才有。

Q3. 白天去呢？

  • 白天可以把泰陵·康陵——朝鲜王陵，9~10月09:00~18:00，周一闭馆，门票1,000韩元，靠近6号线泰陵入口站 (Taereung Station / 태릉입구역)——接在前面。不过这一篇是傍晚路线，就不把它编进来了。

Q4. 带孩子一起？

  • 路面平坦、免费，公园和市场里都有洗手间。展示列车和喷泉小孩通常更喜欢。只是⑤这一段比较长，推婴儿车的话建议在④收尾。

Q5. 大概花多少钱？

  • 门票0韩元。市场晚饭大约1万韩元，加单程交通费。这是首尔最便宜的傍晚路线之一。

Q6. 外国游客去会不会显得奇怪？

  • 这里是社区，不是景点，英文标识不多。但也没人会把你当成游客看——这正是这条路的魅力所在。
