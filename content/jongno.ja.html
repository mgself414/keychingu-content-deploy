Insadong (인사동): 伝統食品・お土産・正統韓食 (ハングァ (한과)・ドマ (Doma))。Ikseondong (익선동): MZ カフェ・バー・ハノク (한옥) インスタ映え (ハノクランソム (Hanok Ransom)・ソルソット (Solsot)・ホソンセンジョン (Ho-Sunsaeng Bar))。外国人の好みに応じて — 伝統 = Insadong (인사동) / MZ + インスタ映え = Ikseondong (익선동)。

Q3. 英語メニュー・サービスはある?

クイルブロス (Quill Bros) / スタンダードバン (Standard Bun) / ハングァミウィシク (Hangwa Mi-Uisik) / ドマ (Doma) — 英語フレンドリー度 high。ソルソット (Solsot) / ホソンセンジョン (Ho-Sunsaeng Bar) は英語が一部対応。チャンスサムゲタン (Jangsu Samgyetang) は老舗のため韓国語中心。

Q4. 老舗・正統 vs モダン韓食、どちらが向いている?

老舗正統: チャンスサムゲタン (Jangsu Samgyetang) (60年) / ドマ インサドン (Doma Insadong) (正統)。モダン韓食: ソルソット イクソン (Solsot Ikseon) (カマソット (가마솥)) / ハングァミウィシク (Hangwa Mi-Uisik) (モダンプレーティング)。外国人入門はモダン、老舗はマニア向け。

Q5. Ikseondong (익선동) ハノク (한옥) カフェのベストタイムは?

平日午前 (11~13時) は席に余裕あり。週末 14~17時は30分以上待ちあり。ハノク (한옥) 雰囲気の写真は自然光の良い 13~15時がおすすめ。

Q6. 価格帯は?

洋食 (クイルブロス (Quill Bros)) ₩15,000~30,000 / 韓食 (ドマ (Doma)・ソルソット (Solsot)) ₩15,000~25,000 / カフェ・デザート ₩7,000~12,000 / ハングァ (한과) ₩15,000~30,000 / サムゲタン (삼계탕) ₩18,000~25,000。

Q7. 定休日・営業時間の注意点は?

ほとんどが毎日営業。チャンスサムゲタン (Jangsu Samgyetang) は祝祭日休業あり。ホソンセンジョン (Ho-Sunsaeng Bar) は一部月曜休業あり。ハングァミウィシク (Hangwa Mi-Uisik) はシーズンにより変動。訪問前に要確認。

Q8. 車いす・ベビーカーのアクセスは?

クイルブロス (Quill Bros) / スタンダードバン (Standard Bun) / ドマ (Doma) — フラットな動線。ハノクランソム (Hanok Ransom)・ソルソット (Solsot)・ホソンセンジョン (Ho-Sunsaeng Bar)・Ikseondong (익선동) 路地は狭く、段差・敷居が多い。

Q9. 広蔵市場 (Gwangjang Market / 광장시장) は何で有名? (What is Gwangjang Market famous for?)

ビンデトック (빈대떡)·マヤクキンパプ (마약김밥)·ユクフェ (육회) の3つが外国人の第1位。鉄板即席ビンデトック (빈대떡) と親指サイズのマヤクキンパプ (마약김밥)がSNSでバイラル。ソウル初の近代市場（1905年開業）の室内グルメ横丁。

Q10. 広蔵市場 (Gwangjang Market / 광장시장) は行く価値ある? (Is Gwangjang Market worth visiting?)

強くおすすめ。現金₩30,000–40,000あればビンデトック (빈대떡)·マヤクキンパプ (마약김밥)·ユクフェ (육회) すべて体験可能。約2時間あれば十分。鍾路5街駅 (Jongno 5-ga Station / 종로5가역) から徒歩2分。

Q11. 鍾路 (Jongno / 종로) 1日観光で広蔵市場 (Gwangjang Market / 광장시장) はいつ行く?

ランチ時間帯（11:30–13:00） がベスト — 午前に景福宮 (Gyeongbokgung / 경복궁) または仁寺洞 (Insadong / 인사동) 観光 → 広蔵市場 (Gwangjang Market / 광장시장) ランチ → 午後に益善洞 (Ikseondong / 익선동) が鍾路 (Jongno / 종로) 最適1日コース。

🗺 おすすめ1日コース 3パターン

Aコース — 「鍾路 (종로) 初訪問 完全コース」(外国人初心者、10時間)

Gyeongbokgung (경복궁) 10:00 → チャンスサムゲタン (Jangsu Samgyetang) ランチ (12:00、1時間) → 🏪 広蔵市場 (Gwangjang Market / 광장시장) ビンデトック (빈대떡)·マヤクキンパプ (마약김밥) (13:00、1時間) → Gwanghwamun (광화문) 広場散策 → スタンダードバン (Standard Bun) 休憩 (30分) → ハングァミウィシク (Hangwa Mi-Uisik) + ドマ インサドン (Doma Insadong) (16:00、2時間) → Ikseondong (익선동) 徒歩 → ハノクランソム (Hanok Ransom) カフェ (1時間) → ソルソット イクソン (Solsot Ikseon) ディナー (1.5時間) → ホソンセンジョン (Ho-Sunsaeng Bar) 深夜 (1時間)

Bコース — 「伝統文化 deep dive」(韓国伝統マニア、6時間)

Gyeongbokgung (경복궁) 09:00 → Changdeokgung (창덕궁) → チャンスサムゲタン (Jangsu Samgyetang) ランチ → ハングァミウィシク (Hangwa Mi-Uisik) + ドマ インサドン (Doma Insadong) (伝統韓食 + ハングァ (한과) コース、3時間) → Tongin Market (통인시장) 散策

Cコース — 「MZ + インスタ映え (Ikseondong (익선동) フル)」(MZ 外国人、5時間)

Jongno 3-ga Station (종로3가역) 12:00 → ハノクランソム (Hanok Ransom) Ikseondong (익선동) カフェ (1.5時間 インスタ撮影) → ソルソット イクソン (Solsot Ikseon) ランチ (1時間) → Ikseondong (익선동) ハノク (한옥) 路地散策 → ホソンセンジョン (Ho-Sunsaeng Bar) ディナー (1.5時間 料理居酒屋)

🌸 シーズン・時間帯フック 5つ

1. 春 (3~5月) Gyeongbokgung (경복궁) 桜: Gyeongbokgung (경복궁) + チャンスサムゲタン (Jangsu Samgyetang) + Insadong (인사동) コース — 韓国の春の真髄。

2. 夏 (6~8月) サンボク (삼복、三伏): チャンスサムゲタン (Jangsu Samgyetang) が最盛期シーズン。外国人も韓国の滋養食を体験。

3. 秋 (9~11月) Ikseondong (익선동) 紅葉: ハノクランソム (Hanok Ransom)・ソルソット イクソン (Solsot Ikseon) の ハノク (한옥) 路地の紅葉シーズン。

4. 冬 (12~2月) ホソンセンジョン (Ho-Sunsaeng Bar) 料理居酒屋: 温かい料理居酒屋 + マッコリ (막걸리) コース。

5. 早朝 (08~10時): Gwanghwamun (광화문)・Gyeongbokgung (경복궁) が空いている。チャンスサムゲタン (Jangsu Samgyetang) は11時オープン後のランチが空いている。
