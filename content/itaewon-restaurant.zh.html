⚠ 外国游客常犯的3个错误

1. "梨泰院 = 夜店·酒吧" — 直接跳过餐厅

外国游客最常见的误区。把梨泰院 (Itaewon / 이태원) 只当成夜店·酒吧·街头小吃的地盘，却错过了汉南 (Hannam / 한남)·新龙山 (Sinyongsan / 신용산) 的现代餐饮和全球风餐厅。事实上，汉南才是韩国全球餐饮的第一核心区域 — 酒店餐厅 + 米其林推荐餐厅 + 现代西餐高度集中。夜店·酒吧 + 精致餐饮组合打卡，梨泰院魅力翻倍。

2. 把"梨泰院·汉南·新龙山"当成三个独立街区

很多外国人只认梨泰院站，但50%的餐厅集中在汉南·新龙山。从梨泰院站 (Itaewon Station / 이태원역)·汉江镇站 (Hangangjin Station / 한강진역)·新龙山站 (Sinyongsan Station / 신용산역) 步行均在10~15分钟内。串成一条动线，可以高效拿下4~5家餐厅。梨泰院 → 汉南汉江镇站 → 新龙山 → 龙山 (Yongsan / 용산) 四区一日游是外国人的最优动线。

3. 忽略酒店餐厅·景观餐厅的预约

蒙德里安首尔梨泰院 盲点 (Mondrian Blind Spot / 몬드리안서울이태원 블라인드 스팟)·韩食 N首尔塔店 (Hankuk N Seoul Tower / 한쿡 N서울타워점)·克利夫首尔 (Cliff Seoul / 클리프 서울) 等酒店·景观餐厅必须提前2~4周预约。walk-in 前往，十有八九没有座位。OpenTable·酒店礼宾部·Naver 预约务必提前安排。支持英语预约的餐厅：蒙德里安 盲点·韩食塔·克利夫首尔·卡萨科罗纳 (Casa Corona / 카사 코로나)·多曼达 (Domanda / 도만다)·丑陋社会 (Ugly Society / 어글리소사이어티) — 共6家。

11. 韩食 N首尔塔店 (Hankuk N Seoul Tower / 한쿡 N서울타워점) ★4.62
