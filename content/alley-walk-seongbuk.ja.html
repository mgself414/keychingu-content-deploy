路地散策⑥ ソンブクドン (Seongbuk-dong / 성북동) — 料亭が寺になった路地、詩人の家を過ぎて城郭の村へ

副題: ソンブクドンの路地には物語が幾層にも積もる。料亭から寺になったキルサンサ、詩人の家シムウジャン、城郭村プクジョンマウルまで約2時間30分。漢城大入口駅から歩く文人コース。Seoul Alley Walks 拡張3号。

ISSUE · #1345 · 2026-09-02

🎯 フレーム — 文人の町

ソンブクドンは、韓国近現代の文人・芸術家たちが集まって暮らした町だ。都城のすぐ外の山裾にあって静かだったため、その静けさが物書きたちを呼び寄せた。このコースは、その痕跡 — 旧家・寺・城郭村 — を上り坂の順番通りにつなぐ。最後には漢陽都城の城郭から町全体を見下ろせる。

  • 総所要時間: 約2時間30分(屋内観覧込みで3時間) · おすすめ時間帯: 午後1〜2時スタート → 城郭の眺めで締めくくり
  • 傾斜: 中 — 緩やかな上り坂が続き、プクジョンマウル区間で急になる。

🚶 コース — 歩く順番そのままに

① 漢城大入口駅 (Hansung Univ. Station / 한성대입구역) 6番出口 → チェ・スヌ旧家 (Choi Sun-u Old House / 최순우 옛집) (徒歩約7分)

  • 国立中央博物館長を務めたヘゴク・チェ・スヌ (Choi Sun-u / 최순우, 1916〜1984) が住んでいた韓屋。「無量寿殿の胴張り柱にもたれて」のあの人物 — 韓国美を文章で伝えた人物の家らしく、庭と障子の桟の風合いが教科書のようだ。

② チェ・スヌ旧家 → ソンジャムダンジ (Seonjamdanji / 선잠단지) → キルサンサ (Gilsangsa / 길상사) (徒歩約20分、上り坂)

  • 朝鮮王妃が蚕の神に祭祀を捧げたソンジャムダンジを過ぎて路地を上ると、キルサンサに着く。
  • 📖 物語1 — 料亭が寺になった話: キルサンサの敷地は、もともとソウルの名だたる高級料亭テウォンガク (Daewongak / 대원각) だった。その主人が晩年に敷地と建物一式を法頂 (Beopjeong / 법정) 僧に施主し、1997年に寺として生まれ変わった — 「無所有」の僧と料亭の主人の縁として語り継がれる、ソウルで最も劇的な用途転換の空間だ。料亭の別棟の構造が残っており、他の寺とは趣が異なる。

③ キルサンサ → シムウジャン (Simujang / 심우장) (徒歩約15分)

  • 詩人であり独立運動家だったマンヘ・ハン・ヨンウン (Han Yong-un / 한용운) が晩年を過ごした家。朝鮮総督府と向き合いたくないという理由で北向きに建てたという逸話が、この家のアイデンティティだ。無料観覧(09:00〜18:00基準 — 訪問前に確認)。

④ シムウジャン → プクジョンマウル (Bukjeong-maeul / 북정마을) (徒歩約10分、急な上り坂)

  • 📖 物語2 — 城郭の下の村: 漢陽都城の暗門(非常出入口)の外の斜面に、1960〜70年代に建てられた小さな瓦屋根の家数百軒が集まる城郭村だ。ソウルでこうした風景が残る場所は、今ではごくわずかだ — 路地が狭く、全て住居地であるため、この区間は静かに通り過ぎるのが礼儀だ。

⑤ プクジョンマウル → 漢陽都城暗門 → 城郭の眺めで締めくくり (徒歩約10分)

  • 暗門を抜けて城郭の内側の道に立つと、ソンブクドンの谷と歩いてきた路地が一望できる。このコースのエンディングだ。
  • 締めくくりの選択肢: 城郭路沿いにヘファムン (Hyehwamun / 혜화문) 方面へ下山(#1239 歴史コース接続)、または来た道を戻ってソンブクドンのカフェ路地で休憩。

🙏 路地マナー

  • キルサンサは修行中の寺だ — 法堂内部の撮影禁止、静粛に。境内の服装は端正に。
  • プクジョンマウルは100%住宅地 — 門・庭の撮影禁止、集団で立ち止まらない、声は最小限に。
  • シムウジャン・チェ・スヌ旧家は観覧時間がある — 午後遅くのスタートなら屋内観覧を先に。

💡 戸惑いポイント

  • このコースはほぼ全区間が上り坂だ — 地図アプリの所要時間に+20%を見込むこと。
  • キルサンサの無料循環バス・行事日には境内が混み合う — 釈迦誕生日前後は静かなコースに合わないため避けるのが無難。
  • 城郭の暗門は開放時間がある(夜間閉鎖区間あり)— 日没前に通過すること。
