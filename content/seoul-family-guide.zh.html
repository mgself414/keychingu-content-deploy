⚠ 外国人家庭伴游5大常见错误

1. “孩子就待在酒店儿童房” — 不出门

外国人家庭首次韩国行最常见的错误。因带孩子出行压力大，只待在酒店。实际上，韩国的家庭友好型基础设施非常完善 — 博物馆、科学馆、汉江公园、汗蒸房 (Jjimjilbang / 찜질방)、游乐园都设有安全的家庭游览路线。

2. “广藏市场 (Gwangjangsijang / 광장시장) 是大人去的地方” 认知

外国人认为广藏市场 (Gwangjangsijang / 광장시장) 是大人的酒局场所。实际上，绿豆饼 (Bindaetteok / 빈대떡) · 麻药紫菜包饭 (Mayakgimbap / 마약김밥) · 传统甜点都适合孩子 + 市场氛围本身就是孩子体验的特色。广藏市场 (Gwangjangsijang / 광장시장) 强烈推荐5-10岁儿童家庭首选。

3. 韩服 (Hanbok / 한복) 体验未了解儿童尺寸

外国人家庭韩服 (Hanbok / 한복) 体验只为大人准备。实际上，景福宫 (Gyeongbokgung / 경복궁) · 昌德宫 (Changdeokgung / 창덕궁) 附近的韩服 (Hanbok / 한복) 店都备有儿童尺寸 — 适合拍摄家庭热门照片。提前预约韩服 (Hanbok / 한복) 店时，请告知需要儿童尺寸。

4. 汗蒸房 (Jjimjilbang / 찜질방) 家庭伴游礼仪不了解

外国人家庭首次访问汗蒸房 (Jjimjilbang / 찜질방) — 不了解哪些店铺允许带孩子，哪些不允许。实际上，龙山汗蒸幕 (Dragon Hill Spa / 드래곤힐 스파) · Sijonespa (Sijonespa / 시조네스파) · Spa Lei (Spa Lei / 스파레이) 是家庭友好型 (有儿童入场费、儿童房、儿童菜单)。请提前学习 [#34 汗蒸房 (Jjimjilbang / 찜질방) 礼仪](34_jjimjilbang_etiquette.md)。

5. K-pop (K-pop / K-pop) 粉丝家庭认为无法伴游

外国人家庭中若有 K-pop (K-pop / K-pop) 粉丝，认为带孩子进行 K-pop (K-pop / K-pop) 路线很困难。实际上，SMTOWN Coex Artium (SM Taun Coex / SM타운 코엑스) (家庭友好型) + Trend Pot (Teurendeupot / 트렌드팟) K-pop (K-pop / K-pop) 联名店 都可带孩子。 [#207 K-pop (K-pop / K-pop) 粉丝路线](207_kpop_fan_day_trip.md) 中的14:00行程 (SMTOWN) 适合家庭。

家庭伴游礼仪·注意事项

必知礼仪:

1. 博物馆·美术馆: 保持安静 + 拍照礼仪
