외국인 한국 강릉 단오제 — UNESCO 2005·음력 5/5·1000년+ 전통

부제: 외국인 관광객용 강릉 단오제 UNESCO 무형문화유산 2005 + 음력 5/5 (양 6월 초·중순) + 1000년+ 전통 + 강원도

ISSUE 04 · #1065 · 2026-06-13

🎯 왜 강릉 단오제 가이드인가

강릉 단오제 (Gangneung Danoje) = UNESCO 인류무형문화유산 2005 등재·음력 5월 5일 (양력 6월 초·중순)·1000년+ 전통. 외국인 페인포인트 = (a) "단오 = 일반 명절" 잘못된 인식 (b) UNESCO 2005·한국 #1 단오 매트릭스·연 100만+ 방문 (c) 그네뛰기·씨름·창포 머리감기 + 한복 매트릭스 (d) 무료·다국어 풀세트·외국인 매니아 매트릭스 #1 (e) 강릉 cluster (#1037) + 1박 풀세트.

본 가이드는 5축 12 시그니처 + 단오제 매트릭스 + UNESCO 컨텍스트.

★ 한눈에 5축 12 시그니처

매니아: 강릉 cross + 안목해변 + 1박 풀세트

🏛 5축 deep dive

① 남대천 단오장 (메인·UNESCO 시그너)

  • 시그니처: UNESCO 2005·1000년+ 강릉 #1 매니아 매트릭스·관노가면극·산신제·국사성황제 매트릭스
  • 외국인 친화도: ★★★★★ (영문·다국어 풀세트·매니아 #1)
  • 시간: 단오 기간 24h 일부·무료
  • 추천: 가면극 + 산신제 + 인스타 매트릭스 #1

② 전통 활동 (그네·씨름·창포)

  • 시그니처: 그네뛰기 + 씨름 + 창포 머리감기 + 한복 매트릭스·MZ + 매니아 + 인스타 매트릭스
  • 외국인 친화도: ★★★★★ (체험 매트릭스·MZ 매니아 매트릭스 #1)
  • 가격: 무료·일부 한복 대여 15,000~30,000원

③ 강릉 cluster cross (#1037)

  • 시그니처: 안목해변 (한국 #1 커피)·경포대·정동진 일출·강릉 한정식·초당두부 시그너
  • 외국인 친화도: ★★★★★ (1박 매니아 매트릭스 #1)
  • 추천: 단오제 + 강릉 풀세트 = 1박 매니아 매트릭스 #1

④ 시즌 매트릭스

  • 2026 강릉 단오제: 6월 24일 (수)~7월 1일 (수)·음 5/5 = 6/19·행사 6/24~7/1 8일간
  • 2027: 6월 9일 (수)·행사 6/4~6/11
  • 외국인 매니아: 사전 호텔 예약 권장 (1-2개월)

⑤ 교통

  • 시그니처: KTX 강릉선 1시간 56분 (27,600원·왕복 55,200원)·2018 평창 동계 올림픽 KTX 강릉선 개통
  • 당일 매트릭스 fit: 서울 1일 풀데이·1박 매니아 매트릭스 #1

⚠ 외국인 자주 실수 5가지

1. "단오 = 일반 명절": UNESCO 2005·1000년+·한국 #1 단오 매니아 매트릭스 #1.

2. "강릉 = 멀다": KTX 1시간 56분·당일 OK·1박 매트릭스 #1.

1. 외국인 입문 1순위: 단오장 + 그네 + 한복 + 강릉 cross = 1박.
