韩国炖锅与醒酒汤指南 — 泡菜锅、大酱/豆腐锅、部队锅、醒酒汤8家 — 清津屋 (Cheongjinok / 청진옥)、武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집)、鱼糕食堂 (Odeng Sikdang / 오뎅식당)、银珠亭 (Eunjujeong / 은주정) (2026年10月官方数据)

副标题: 清津屋 (Cheongjinok / 청진옥) 1937年开业、2013年入选首尔未来遗产，06:00~22:00全年无休 (VisitKorea) · 武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집) 1968年起，工作日 07:00开门 (VisitKorea) · 议政府部队锅街 (Uijeongbu Budae Jjigae-geori / 의정부 부대찌개거리) 有12家餐厅，每年10月举办美食节 (VisitKorea) · 黄金豆田 (Hwanggeum Kongbat / 황금콩밭) 豆腐火锅为必比登推介 (米其林) — 截至2026-10-21

ISSUE 03 · #486 · 2026-05-27

🎯 如何使用本指南

桌上电磁炉上的锅一滚，火腿和水芹就从汤面浮起来 — 驿三洞 (Yeoksam-dong / 역삼동) 的大宇部队锅 (Daewoo Budae Jjigae / 대우부대찌개) 每张桌子都配电磁炉，点单之后才开始煮 (VisitKorea)。本指南介绍整锅煮好、在桌上分着吃的炖锅 (Jjigae / 찌개)和早晨的醒酒汤 (Haejangguk / 해장국)。分四类：泡菜锅 (Kimchi-jjigae / 김치찌개)、大酱·清曲酱 (Cheonggukjang / 청국장)·豆腐、部队锅 (Budae-jjigae / 부대찌개)、醒酒汤。把饭泡在汤里端上来的雪浓汤 (Seolleongtang / 설렁탕)、牛肉清汤 (Gomtang / 곰탕)、猪肉汤饭另归入 #477 汤饭指南。店家只选了VisitKorea旅游信息和米其林指南官网上列出的。写给想原样吃一顿韩国人工作日午餐的人。

旧版指南的"议政府部队锅 乘KTX 1小时"没有依据。VisitKorea给出的路线是议政府轻轨 议政府中央站 (Uijeongbu Jungang-yeok / 의정부중앙역) 2号出口。泡菜锅、清曲酱上附带的人气排行也没有出处，已删除。

🌶 泡菜锅 — 首尔2家

  • 银珠亭 (Eunjujeong / 은주정) — 首尔中区昌庆宫路8街 (Changgyeonggung-ro 8-gil / 창경궁로8길) 32 (清溪川防山市场 (Bangsan Sijang / 방산시장))。11:30~22:00 (最后点单 21:30)，每周日及春节 (Seol / 설)、中秋 (Chuseok / 추석) 假期休息。招牌是包叶菜吃的泡菜锅，也有大酱汤 (Doenjang-jjigae / 된장찌개)、五花肉 (Samgyeopsal / 삼겹살)。已经营业30多年的老店。电话 0507-1406-4669，全店禁烟 (VisitKorea)
  • 涵洞食堂 (Guldari Sikdang / 굴다리식당) — 首尔麻浦区新昌路 (Saechang-ro / 새창로) 8-1 (桃花洞 (Dohwa-dong / 도화동))。08:00~22:00，全年无休。招牌是泡菜锅，也有辣炒猪肉 (Jeyuk-bokkeum / 제육볶음)、鸡蛋卷 (Gyeran-mari / 계란말이)。1公里以内有京义线广场 (Gyeongui-seon Gwangjang / 경의선광장) 和京义线公园 (Gyeongui-seon Gongwon / 경의선공원)。电话 02-712-0066 (VisitKorea)
  • 价格: 两家在VisitKorea上都没有公布价格 — 请看菜单确认

🫘 大酱·清曲酱·豆腐 — 2家

  • 福男家清曲酱 (Boknamine Cheonggukjang / 복남이네청국장) — 京畿道高阳市一山东区江村路26街 (Gangchon-ro 26beon-gil / 강촌로26번길) 7-7 (白石洞 (Baekseok-dong / 백석동))。11:00~22:00 (最后点单 20:30)，全年无休。用100%国产豆煮清曲酱 (Cheonggukjang / 청국장) 和大酱汤，点清曲酱会附带大麦饭和豆芽、蕨菜、生拌菜 (Saengchae / 생채) 之类的野菜小菜 (Namul / 나물)，倒进大铝盆 (Yangpun / 양푼) 里拌着吃。电话 031-904-6115，全店禁烟 (VisitKorea)
  • 黄金豆田 (Hwanggeum Kongbat / 황금콩밭) — 首尔麻浦区麻浦大路16街 (Mapo-daero 16-gil / 마포대로16길) 9。周一至周五 11:30~21:00，周六、周日 11:00~21:00。用100%国产豆自己做豆腐的专门店。豆腐火锅 (Dubu-jeongol / 두부전골)、浓汁豆腐 (Jjabak-dubu / 짜박두부)、炖豆腐 (Dubu-jorim / 두부조림)、豆腐炒肉 (Dubu Duruchigi / 두부 두루치기)，以及用米、酒曲 (Nuruk / 누룩) 和水酿成的浊酒 (Takju / 탁주)。可通过Naver预约，可停车 (米其林页面，必比登推介)

🌭 部队锅 — 2家

  • 鱼糕食堂 (Odeng Sikdang / 오뎅식당) — 京畿道议政府市护国路1309街 (Hoguk-ro 1309beon-gil / 호국로1309번길) 7。08:30~21:30。议政府最早卖部队锅的店，现在是第三代经营。最初是小摊，后来把主打菜换成了部队锅。部队锅、铁板部队炒 (Cheolpan Budae-bokkeum / 철판부대볶음)。电话 031-842-0423，官方网站 odengsikdang.com (VisitKorea)
  • 议政府部队锅街 (Uijeongbu Budae Jjigae-geori / 의정부 부대찌개거리) — 以鱼糕食堂 (Odeng Sikdang / 오뎅식당) 为中心聚集了12家餐厅的特色美食街。议政府市认证的元祖餐厅是鱼糕食堂，每年10月举办议政府名物炖锅美食节 (Uijeongbu Myeongmul Jjigae Eumsik Chukje / 의정부명물찌개 음식축제)。就在议政府轻轨议政府中央站2号出口外 (VisitKorea)
  • 大宇部队锅 (Daewoo Budae Jjigae / 대우부대찌개) — 首尔江南区德黑兰路25街 (Teheran-ro 25-gil / 테헤란로25길) 34 (驿三洞 (Yeoksam-dong / 역삼동))。11:00~21:00，备料时间 15:00~17:00，每周六休息。1984年开业。放了水芹 (Minari / 미나리)，汤底清爽。里脊部队锅 (Deungsim Budae-jjigae / 등심부대찌개)、烤香肠、烤里脊，可打包。电话 02-552-1663 (VisitKorea)
  • 由来: "部队" (Budae / 부대) 指朝鲜战争刚结束后驻扎的美军部队。来自在美军基地周边，把火腿、香肠、培根加上泡菜、辣椒酱 (Gochujang / 고추장)、年糕 (Tteok / 떡) 一起煮来吃 (VisitKorea)

🐟 醒酒汤 — 首尔2家

  • 清津屋 (Cheongjinok / 청진옥) — 首尔钟路区钟路3街 (Jong-ro 3-gil / 종로3길) 32 (清进洞 (Cheongjin-dong / 청진동))。06:00~22:00 (最后点单 21:30)，全年无休。1937年在避马巷 (Pimatgol / 피맛골) 起家，现在是第三代。招牌是牛血块醒酒汤 (Yangseonji Haejangguk / 양선지 해장국)：牛骨汤里放牛血块 (Seonji / 선지)、牛内脏、干菜叶 (Ugeoji / 우거지) 和豆芽；还有内脏白煮肉 (Naejang Suyuk / 내장수육)、什锦白煮肉 (Modeum Suyuk / 모듬수육)。2013年入选首尔未来遗产。电话 02-735-1690 (VisitKorea)
  • 武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집) — 首尔中区乙支路1街 (Eulji-ro 1-gil / 을지로1길) 38 (多洞 (Da-dong / 다동)，首尔市厅后面)。工作日 07:00~20:00 (最后点单 19:30)，周末 07:00~15:00，全年无休。1968年起在同一个地方，只有明太鱼干醒酒汤 (Bugeo Haejangguk / 북어해장국) 一个菜单，上菜很快，饭和汤可以一直续。电话 02-777-3891，全店禁烟 (VisitKorea)
  • 济州式醒酒汤见 #1406 济州式汤品四种

🥗 饮食

  • 价格区间: 8家里没有官方公布韩元价格的。黄金豆田 (Hwanggeum Kongbat / 황금콩밭) 只有米其林的 ₩ 符号。2017年VisitKorea文章写清津屋 (Cheongjinok / 청진옥) 的醒酒汤为10,000韩元，但现在的价格未能确认
  • 素食: 嫩豆腐锅 (Sundubu-jjigae / 순두부찌개)、炖豆腐里大多放腌虾 (Saeujeot / 새우젓) (VisitKorea)。泡菜的调料里也大多含有腌制海鲜、鱼露或肉汤 (VisitKorea) — 泡菜锅、大酱汤也要先问汤底和腌制海鲜。部队锅含火腿、香肠，醒酒汤含牛骨、牛血块、内脏
  • 清真: VisitSeoul介绍梨泰院的伊德 (Eid / 이드)(龙山区牛沙坛路10街 (Usadan-ro 10-gil / 우사단로10길) 15，每天 12:00~21:00) 是少数获韩国伊斯兰教中央会 (KMF) 认证为清真的餐厅之一。本指南里的炖锅店没有清真标识，泡菜锅、部队锅里常放猪肉、火腿 — 银珠亭 (Eunjujeong / 은주정) 还一并供应五花肉 (VisitKorea)
  • 过敏: 清曲酱、大酱、豆腐都是大豆。明太鱼干 (Bugeo / 북어)、牛血块 (Seonji / 선지)、内脏也要提前确认
  • 出示用的卡片见 #1300 饮食需求手册

🧰 炖锅实用信息 — 独自用餐、预约、付款、点餐、交通

  • 独自用餐: 醒酒汤 (清津屋 (Cheongjinok / 청진옥)、武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집)) 是一人一碗，适合一个人去。整锅炖锅有的店可能两人份起做 — 进门时竖起一根手指问一下。单人用餐地图见 #348 Seoul Solo Diner Map
  • 预约: 黄金豆田 (Hwanggeum Kongbat / 황금콩밭) 可通过Naver预约 (米其林页面)。其余的官方页面没有预约说明 — 排队或打电话
  • 付款: 刷卡和移动支付见 #527 韩国支付系统
  • 点餐: 武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집) 菜单只有一种，坐下后只需说人数 (VisitKorea)。语言不通时见 #1339 点餐礼仪
  • 交通: 议政府、高阳在首尔之外 — 交通卡见 #1298 三种交通卡怎么选

⚠ 常见的4个误区

1. "去议政府坐KTX" — VisitKorea指引的是议政府轻轨议政府中央站 (Uijeongbu Jungang-yeok / 의정부중앙역) 2号出口

2. "周末午餐去大宇部队锅" — 每周六休息 (VisitKorea)

3. "醒酒汤通宵营业" — 清津屋 (Cheongjinok / 청진옥) 营业 06:00~22:00，武桥洞明太鱼汤店 (Mugyo-dong Bugeoguk-jip / 무교동 북어국집) 周末15:00打烊 (VisitKorea)

4. "豆腐锅是素食" — VisitKorea写道嫩豆腐锅、炖豆腐大多放腌虾 (Saeujeot / 새우젓)
