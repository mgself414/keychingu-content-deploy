⚠ 외국인 자주 실수 5가지

1. "한국 의료관광 = 강남만": K-Medical = 압구정·청담 (#296) #1 + 이태원 (#144) + 경희 (청량리) + 외국인 매니아 1번지 + 영어·중문·일문·러시아·아랍어 풀세트.

2. "K-Medical = 비싸기만": K-Medical = 외국인 가성비 1번지 (일본 60%·미국 40% 저렴) + 보험 적용 일부 + 외국인 럭셔리 매니아.

3. "외국인 의료 비자 = 어려움": 의료 비자 = 60일 단기 + 외국인 매니아 패키지 + KTO 인증 + 메디컬 비자 풀세트·외국인 첫 방문.

4. "외국인 영어 OK = 강남만": 외국인 영어 K-Medical = 압구정·청담 (#296) + 이태원 (#144) + 경희 + 자생 + 외국인 거주 1번지 + 통역 서비스 풀세트.

5. "K-Medical = 미용만": K-Medical = 피부 + 성형 + 치과 + 한방 + 종합검진 + 안과 + 외국인 럭셔리 매니아 + 외국인 wellness 통합 (#365·#384·#357·#359).
