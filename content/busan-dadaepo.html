⚠ 외국인 자주 실수 5가지

1. "다대포 = 못 감": 다대포 = 부산 외곽 1번지 + 외국인 hidden gem + 부산 1번지 노을.

2. "꿈의 낙조분수 = 단순": 꿈의 낙조분수 = 세계 #1 음악분수 (기네스 등록 2009) + 외국인 인스타 1번지.

3. "낙동강 = 강만": 낙동강 하구 = 한국 1번지 철새 도래지 + 을숙도 생태 + 외국인 매니아.

4. "다대포 노을 = 어디나": 다대포 노을 = 부산 1번지 노을 + 외국인 vlog 1번지 + 사진관 매니아.

5. "몰운대 = 못 감": 몰운대 = 다대포 1번지 자연·역사 + 외국인 매니아 hidden gem.

⚙ FAQ 6개

1. 외국인 다대포 동선: KTX 부산역 → 다대포해수욕장역 (지하철 1호선 종점) 50분.

2. 외국인 꿈의 낙조분수 시기: 4~10월 (저녁 7~10시 음악분수) + 외국인 인스타 1번지.

3. 외국인 다대포 노을: 부산 1번지 노을 + 외국인 vlog 1번지.

4. 외국인 낙동강 하구 생태: 한국 1번지 철새 + 을숙도 + 외국인 생태 매니아.

5. 외국인 다대포 1박2일: Day 1 다대포·낙동강·을숙도 / Day 2 자갈치·감천·해운대.

6. 외국인 다대포 + 부산 풀세트: 다대포 + 사직·동래·기장·송도·영도 외국인 매니아.
