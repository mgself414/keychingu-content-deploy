① 2026年已上线的6部

  • 杜娅女士 (Redi Dua / 레이디 두아)(Netflix) — 申惠善 (Shin Hye-sun / 신혜선) 饰演 Sara Kim (사라킴),李濬赫 (Lee Jun-hyuk / 이준혁) 饰演追查她的刑警 Mugyeong (무경) 的Netflix系列剧。Sports Kyunghyang (스포츠경향) 在2026-02-06的报道中称"将于本月13日在Netflix上线"。上线日为2026-02-13。
  • 韩国制造第2季 (Meideu in Korea Sijeun2 / 메이드 인 코리아 시즌2)(Disney+) — 玄彬 (Hyun Bin / 현빈) 饰 Baek Gi-tae (백기태),郑雨盛 (Jung Woo-sung / 정우성) 饰 Jang Geon-young (장건영),两人再度交锋的年代剧第2季。禹到焕 (Woo Do-hwan / 우도환) (饰 Baek Gi-hyeon (백기현))、Seo Eun-soo (서은수)、Won Ji-an (원지안)、Jung Sung-il (정성일)、Noh Jae-won (노재원) 同台出演。自2026-09-09起每周三播出2集,共6集全部上线 (Sports Kyunghyang 2026-08-04)。故事发生在第1季的9年后,所以先看第1季 (Sports Kyunghyang 2026-08-04)。
  • 给我充电 (Nareul Chungjeonhaejwo / 나를 충전해줘)(Netflix) — 拥有电力能力的编剧和人工心脏电池耗尽的财阀三代,为"充电"而签约恋爱的爱情喜剧。金英光 (Kim Young-kwang / 김영광)、蔡秀彬 (Chae Soo-bin / 채수빈) 主演,Park Su-won (박수원) 执导。改编自同名网络小说。上线日为2026-10-09 (Netflix官方公告 2026-09-10)。适合想找轻松爱情剧的人。
  • 再婚皇后 (Jaehon Hwanghu / 재혼 황후)(Disney+) — 改编自全球累计观看量29亿7000万次 (原作网络漫画,日刊体育 2026-08-26) 的网络漫画的宫廷爱情奇幻剧。申敏儿 (Shin Min-a / 신민아) 饰皇后 Navier (나비에),朱智勋 (Joo Ji-hoon / 주지훈) 饰皇帝 Sovieshu (소비에슈),李世荣 (Lee Se-young / 이세영) 饰 Rastah (라스타),李钟硕 (Lee Jong-suk / 이종석) 饰西王国王子 Heinley (하인리)。这是Disney+原创剧,上线日为2026-11-04 (同一报道)。读过原作网络漫画的粉丝,可以一边对比演员对角色的诠释一边观看。
  • 蓝色之路 (Pureun-gil / 푸른길)(Netflix) — 首尔和东京的两名刑警追查四肢扭曲的尸体、神秘信息和跨越国境的连环杀人案。孙锡久 (Son Suk-ku / 손석구) 饰首尔警察厅刑警 Kim Seok (김석),永山瑛太 (Eita Nagayama / 나가야마 에이타) 饰东京警视厅刑警 Inose (이노세)。Kim Sin-rok (김신록)、Choi Seong-eun (최성은)、Jung Jae-young (정재영) 也参演。导演是 Han Jun-hee (한준희)。Netflix在2026-11-05的公告中宣布2026-11-20 (周五) 上线。这是韩日两名刑警跨国境合作的刑侦剧。
  • 代考修能 (Daeri Suneung / 대리수능)(TVING) — 名牌自私高三学生在高考 (修能) 前夕纠缠在一起并走向犯罪的惊悚剧。Bae Hyun-sung (배현성) 饰表面看似完美的模范生 Nam Jae-yeop (남재엽)。2026-11-23在TVING (티빙) 独家上线 (日刊体育 2026-11-04)。要在TVING应用里看,而不是Netflix或Disney+。

② 即将上线的5部 (2026年12月~2027年)

  • 缓慢而强烈 (Cheoncheonhi Gangryeolhage / 천천히 강렬하게)(Netflix, 2026-12-11) — 一无所有的人们在唱片行业追逐成功的故事 (背景为1960~80年代)。宋慧乔 (Song Hye-kyo / 송혜교)、孔刘 (Gong Yoo / 공유)、金雪炫 (Kim Seol-hyun / 김설현)、车胜元 (Cha Seung-won / 차승원)、李荷妮 (Lee Ha-nee / 이하늬) 出演。编剧 Roh Hee-kyung (노희경),导演 Lee Yoon-jung (이윤정)。Netflix在2026-10-22的官方公告中宣布2026-12-11 (周五) 下午5点上线。同一公告写明将在全球上线。英文片名为 Tantara。全22集分3次上线,12月11日、18日、25日 (What's on Netflix 2026-11-23)。如果12月在韩国,也可以配合每周五的上线时间观看。
  • 满球数 (Pul-kaunteu / 풀카운트)(SBS, 2027年2月) — 讲述棒球教练们故事的SBS新周五周六剧。Kim Rae-won (김래원) 饰代理总教练兼投捕教练 Hwang Jin-ho (황진호),Park Hoon (박훈) 饰被视为下任总教练人选的投手教练 Jo Dong-hui (조동희)。SBS已确定2027年2月的档期 (日刊体育 2026-10-19)。
  • 噩梦 (Akmong / 악몽)(SBS, 2027年) — 为法律无法惩罚的罪犯设计噩梦而不是监狱的故事。金南佶 (Kim Nam-gil / 김남길) 饰结束长期卧底调查后回到南部署 (Nambu-seo / 남부서) 的刑警 Kim Tae-i (김태이)。Lee Yu-mi (이유미) 饰从受害者支援警察成为"梦境设计师"的 Jang Gyu-eun (장규은)。日刊体育在2026-03-18的报道中称"将于2027年首播"。
  • 伟大的方玉淑 (Widaehan Bang Ok-suk / 위대한 방옥숙)(tvN, 2027年上半年) — 想守住房价的公寓妇女会与觊觎重建收益的组合长对决的故事,被介绍为"大妈黑色片"。全度妍 (Jeon Do-yeon / 전도연) 饰妇女会实权人物 Bang Ok-suk (방옥숙),朴海秀 (Park Hae-soo / 박해수) 饰重建组合长 Yun Tae-ung (윤태웅)。Kim Sun-young (김선영)、Kim Geum-sun (김금순)、Kim Guk-hee (김국희)、Baek Hyun-jin (백현진) 等同台出演。导演 Kim Hyung-sik (김형식),编剧 Lee Gi-cheol (이기철)。据报道"将于2027年上半年首播" (日刊体育 2026-09-10)。
  • 韩国人们 (Korieonjeu / 코리언즈)(Disney+, 2027年) — 把美国FX剧集《The Americans》搬到1990年首尔公寓小区的谍战剧。李秉宪 (Lee Byung-hun / 이병헌) 饰在韩国生活10年的朝鲜特工 Kim Myeong-jun (김명준),韩志旼 (Han Ji-min / 한지민) 饰伪装夫妻、一同南下的特工 Yun Hwa-gyeong (윤화경)。搬到隔壁的重案组出身、现任反共调查科刑警 Cha Gi-seok (차기석) 由李熙俊 (Lee Hee-joon / 이희준) 饰演。导演 Ahn Gil-ho (안길호),编剧 Park Eun-gyo (박은교)。Disney+官方宣布2027年独家上线 (Sports Kyunghyang 2026-03-25)。具体月份尚未公布。

⚠ 常见错误3个

  1. 把预定播出日当作确定日期来安排旅行 — 2027年的作品大多只公布了"2月""上半年""2027年"这样的时间。档期也有被推迟的情况。SBS 的有胜算 (Seungsan Itseumnida / 승산 있습니다) 退出了2月周五周六档,改为满球数 (Pul-kaunteu / 풀카운트),新档期未定 (日刊体育 2026-10-19)。首播日期请在电视台公布之后再安排。
  2. 用海外账号找TVING作品 — 代考修能 (Daeri Suneung / 대리수능) 是TVING独家上线 (日刊体育 2026-11-04)。在Netflix或Disney+上搜也搜不到。
  3. 从第2季开始看 — 韩国制造第2季 (Meideu in Korea Sijeun2 / 메이드 인 코리아 시즌2) 是第1季9年后的故事 (Sports Kyunghyang 2026-08-04)。人物关系是延续的,所以从第1季开始看。

⚙ 常见问题3个

  1. 在海外也能看吗? — 官方公告写明"全球上线"的作品是缓慢而强烈 (Cheoncheonhi Gangryeolhage / 천천히 강렬하게) (Netflix 2026-10-22)。其他作品由平台按国家分别决定是否提供。请在自己使用的应用里搜索片名。
  2. SBS、tvN的剧在哪里看? — 在韩国通过首播频道观看。本期查证的报道中没有出现《满球数》(Pul-kaunteu / 풀카운트)、噩梦 (Akmong / 악몽)、伟大的方玉淑 (Widaehan Bang Ok-suk / 위대한 방옥숙) 的海外流媒体平台。临近播出时请查看电视台公告。
  3. 2027年Netflix的韩剧没有更多了吗? — Netflix公布了《魂:三角的时间》(Hon: Samgakui Sigan / 혼: 삼각의 시간) (姜东元 (Kang Dong-won / 강동원)·金高银 (Kim Go-eun / 김고은),2026-11-12公布) 和重症外伤中心 (Jungjeung Oesang Senteo / 중증외상센터) 第2、3季 (2026-10-19确定制作)。但尚未公布上线时间,所以没有列入本期的11部。
