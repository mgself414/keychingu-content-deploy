⚠ 5 Common Mistakes by International Visitors

1. "Hotel dining = only expensive": La Yeon (라연) ₩200,000~500,000 (~$150-375 / ~1,000-2,500 RMB / ~20,000-50,000 JPY) Michelin 3-star·Bicena (비채나) ₩100,000~300,000 + lunch course for value for money (₩60,000~100,000) + top priority for international enthusiasts.

2. "Hotel bars = only for guests": Signiel BAR 81 (시그니엘 BAR 81)·Banyan Tree Moon Bar (반얀트리 문 바)·Conrad 37 (콘래드 37)·JW Griffin (JW 그리핀) = external guests OK + advance reservation recommended (especially for weekend night views).

3. "Michelin = only Korean food": La Yeon (라연) (Korean)·Bicena (비채나) (Korean fine dining)·Yu Yuan (유유안) (Chinese)·Banyan Tree Festa (반얀트리 페스타) (4 types)·Lotte Momoyama (롯데 모모야마) (Japanese) offer diverse options for international enthusiasts.

4. "BAR 81 = expensive": BAR 81 (바 81) 81st floor·555m view = cocktails ₩25,000~40,000 + top priority for international enthusiasts + night view (advance reservation essential).

5. "Hotel bars = only night view": Hotel bars = night view + signature cocktails + chef's menu + No. 1 spot for international dates/honeymoons ([#277 honeymoon couples](277_seoul_honeymoon_guide.md)).

🗺 3 Full-Day Courses for International Visitors

A. Luxury Hocance (호캉스) Full Set (Signiel·Shilla·Banyan Tree)

  • Day 1: 2:00 PM check-in → 3:00 PM swimming pool ([#356](356_seoul_hotel_pool_guide.md)) → 5:00 PM afternoon tea → 7:00 PM Michelin dining (La Yeon (라연)·Bicena (비채나)) → 10:00 PM BAR 81 (바 81)·Moon Bar (문 바) night view
  • Day 2: 9:00 AM breakfast ([#358](358_seoul_hotel_breakfast_guide.md)) → 12:00 PM check-out

B. Night View Bar Hopping (Signiel·Banyan Tree·Conrad)

  • 6:00 PM Conrad 37 (콘래드 37) (Yeouido (여의도) Han River (한강)) → 8:00 PM Banyan Tree Moon Bar (반얀트리 문 바) (Namsan (남산)) → 10:00 PM Signiel BAR 81 (시그니엘 BAR 81) (Jamsil (잠실) 555m)

C. Value for Money MZ (Millennial and Gen Z) Hocance (호캉스) (L7·Novotel·Mondrian)

  • Day 1: 3:00 PM check-in → 5:00 PM pool·rooftop → 7:00 PM L7 Rooftop (L7 루프탑)·Gangnam Lounge (강남 라운지) → Next day 9:00 AM breakfast ₩12,000~25,000
