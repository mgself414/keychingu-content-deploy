加平·杨平一日游指南 — 南怡岛·Achimgoyo树木园·小法国，两水头·洗美苑·杨平山茱萸村·龙门寺银杏树

副标题:南怡岛(08:00~21:00) · Achimgoyo树木园(08:30~19:00) · 小法国(09:00~18:00) · 两水头(全天开放) · 洗美苑(09:00~18:00，11~3月周一休馆) · 杨平山茱萸村(3~4月开花，全天开放) · 龙门寺·银杏树(全天开放) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了首尔以东京畿道加平、杨平一天可以去的地方。加平三处(南怡岛码头·Achimgoyo树木园·小法国)和杨平四处(两水头·洗美苑·山茱萸村·龙门寺)。只有洗美苑在11~3月周一休息，其余登记为全年无休。

春天，杨平山茱萸村在3~4月会染成一片黄色。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 加平 — 南怡岛·Achimgoyo树木园·小法国

南怡岛(Nami-seom / 남이섬)，春川市(Namiseom-gil 1 / 남이섬길 1)，☎ 031-580-8114，是以"童话王国，歌之岛"为主题，举办文化活动、演唱会和展览的岛。虽然隶属江原道春川，但进岛要去京畿道加平的南怡岛码头。因电视剧《冬季恋歌》(Gyeoul Yeonga / 겨울연가)的拍摄地而闻名。岛上有歌曲博物馆、绘本游乐场、联合国儿童基金会休息室、自行车、分享列车、Jeonggwan楼酒店(Jeonggwanru / 정관루)。

  • 开放时间:08:00~21:00。船的运行时间另行运营。
  • 休息日:全年无休。停车:可以(约600辆)。
  • 体验:玻璃·陶瓷手工艺、制作柴火披萨等。

Achimgoyo树木园(Achimgoyo Sumogwon / 아침고요수목원)，加平郡Sang面(Sumogwon-ro 432 / 수목원로 432)，☎ 1544-6703，是以祝灵山(Chukryeongsan / 축령산)为背景的园艺树木园，1996年5月开园。园内有20个主题不同的庭园，还有按韩半岛地形布置的Hagyeong庭园(Hagyeong Jeongwon / 하경정원)，即下沉式花园。有包括300多种白头山(Baekdusan / 백두산)植物在内的5,000多种植物。冬天据介绍用灯光举办五色星光庭园展(Osaek Byeolbit Jeongwonjeon / 오색별빛정원전)。是多部电视剧和综艺的拍摄地。

  • 开放时间:08:30~19:00(停止入场 18:00)。休息日:全年无休。
  • 停车:可以。体验:苔藓·花卉玻璃景观瓶、绘画花盆等。

小法国(Ppeti Peurangseu / 쁘띠프랑스)，加平郡清平面(Hoban-ro 1063 / 호반로 1063)，☎ 031-584-8200，是从清平水坝(Cheongpyeong Dam / 청평댐)沿湖边路向南怡岛方向约10km处的法国文化村，主题是"花与星星，还有小王子"。设有圣埃克苏佩里纪念馆、可以听到有200年历史的八音盒的八音盒之家、法国传统住宅展览馆、古董展览馆。是多部电视剧的拍摄地。

  • 开放时间:09:00~18:00。关门时间随季节和天气变化，夜间开放时间另行通知。
  • 休息日:全年无休。停车:可以。体验:小王子体验·石膏体验、雪橇场体验等。

📍 杨平 — 两水头·洗美苑

杨平两水头(Dumulmeori / 두물머리)，杨平郡Yangseo面(Dumulmeori-gil 145 / 두물머리길 145)，☎ 两水头游客咨询处(Dumulmeori Gwangwang Annaeso / 두물머리 관광안내소) 031-775-8700，是北汉江(Bukhangang / 북한강)和南汉江(Namhangang / 남한강)两条水汇合的地方，是汉江的起点。有清晨的水雾和日出、黄布帆船、400多年的榉树。入选韩国旅游100选，也留存在谦斋郑敾(Gyeomjae Jeong Seon / 겸재 정선)等人的作品中。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

洗美苑(Semiwon / 세미원)，杨平郡Yangseo面(Yangsu-ro 93 / 양수로 93)，☎ 031-775-1835，是三面被Paldang湖(Paldang-ho / 팔당호)环绕的水与花的庭园，有水生植物等约270种植物。2019年6月被指定为京畿道第1号地方庭园。据说是丁若镛(Jeong Yak-yong / 정약용)在南汉江上架设船桥的地方。设有莲花博物馆、睡莲温室、Seokchang苑(Seokchangwon / 석창원)、Sangchun苑(Sangchunwon / 상춘원)。

  • 开放时间:09:00~18:00。入场券卖到关门前30分钟。莲花节期间时间另行运营。
  • 休息日:4~10月全年无休，11~3月每周一(周一为公休日时，次日替代休馆)。
  • 停车:可以。体验:水生植物体验教室、制作莲花扇、天然手帕染色等。

📍 杨平 — 山茱萸村·龙门寺

杨平山茱萸村(Yangpyeong Sansuyu Maeul / 양평 산수유마을)，杨平郡Gaegun面(Sansuyu 1-gil 1 / 산수유1길 1)，☎ 031-772-2257，聚集了7千多棵100多年的山茱萸树。每年3~4月村子染成黄色，秋天挂满红色的果实。每年4月上旬前后以山茱萸花为主题举办山茱萸韩牛节(Sansuyu Hanu Chukje / 산수유한우축제)，开展农村体验。据介绍可品尝用山茱萸果实和花制成的美食与茶，以及Gaegun面(Gaegun-myeon / 개군면)特产本土韩牛。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

龙门寺(Yongmunsa / 용문사)，杨平郡Yongmun面(Yongmunsan-ro 782 / 용문산로 782)，☎ 031-773-3797，是龙门山(Yongmunsan / 용문산)脚下的大韩佛教曹溪宗(Daehan Bulgyo Jogyejong / 대한불교조계종)寺院，相传由Daegyeong大师(Daegyeong Daesa / 대경대사)于新罗神德王(Sindeok-wang / 신덕왕)2年(913)建造。设有大雄殿(Daeungjeon / 대웅전)、Sanryeong阁(Sanryeonggak / 산령각)、Chilseong阁(Chilseonggak / 칠성각)、寺院体验修炼馆，寺院体验可在休息型和体验型中选择。从寺院沿山谷上行2km有Yonggak岩(Yonggak Bawi / 용각바위)，再走1km有Madang岩(Madang Bawi / 마당바위)。

  • 龙门寺银杏树(Yongmunsa Eunhaengnamu / 용문사 은행나무)，☎ 龙门山旅游区咨询办公室(Yongmunsan Gwangwangdanji Annaesamusil / 용문산 관광단지 안내사무소) 031-773-0088:推测树龄约1,100年、高42m的天然纪念物。据韩国观光公社旅游信息中收录的国家遗产厅资料，在韩国的银杏树中，树龄和高度都是最高纪录。流传着麻衣太子(Maui Taeja / 마의태자)所植的传说，也流传着义湘大师(Uisang Daesa / 의상대사)的拐杖长成的传说。
  • 开放时间:全天开放。休息日:全年无休。
  • 停车:可以(约700辆)。微型车1,500韩元，小型车3,000韩元，中·大型车5,000韩元。

⚙ FAQ 2

Q. 春天适合去看花的地方是?

A. 按观光公社登记信息，杨平山茱萸村在3~4月被山茱萸染黄，据介绍4月上旬前后举办山茱萸韩牛节。全天开放。

Q. 南怡岛从哪里进?

A. 南怡岛隶属江原道春川，但要去京畿道加平的南怡岛码头才能进入。船的运行时间另行运营。
