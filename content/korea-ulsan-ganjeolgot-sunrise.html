🎯 왜 간절곶 일출 가이드인가

간절곶 (Ganjeolgot) = 한국 #1 일출 1번지·동해·1920년~ 등대 100년+. 외국인 페인포인트 = (a) "간절곶 = 그냥 해안" 잘못된 인식 (b) 한국 #1 일출 (한반도 새해 일출 매니아 매트릭스 #1) (c) 1920년 등대 100년+·인스타 + MZ fit (d) 새해 1월 1일 = 한국인 매니아 매트릭스 #1 (10만+ 방문) (e) 연중 일출 매니아·MZ + 인스타 fit (f) 해안 산책 + 카페 cluster.

본 가이드는 5축 12 시그니처 + 일출 매트릭스 + 등대 + 외국인 영문 발화.

🏛 5축 deep dive

① 한국 #1 일출 (간절곶)

  • 시그니처: 한반도 #1 일출 1번지·동해·연중 매니아 매트릭스
  • 새해 1월 1일: 10만+ 방문·한국 매트릭스 #1·MZ + 가족
  • 외국인 친화도: ★★★★★ (영적 매니아 + MZ + 인스타 fit)
  • 추천: 일출 30분 전 도착·시즌·날씨 확인

② 간절곶 등대 (1920년~ 100년+)

  • 시그니처: 1920년~·100년+·한국 100년+ 등대·인스타 매트릭스 #1
  • 외국인 친화도: ★★★★★ (MZ + 인스타 + 영문 시그너)
  • 추천: 등대 + 박물관 + 인스타 = 1h

③ 해안 산책 + 카페 + 우체통

  • 시그니처: 동해 해안 산책 + 카페 cluster + 한국 #1 큰 우체통 (5m+)
  • 외국인 친화도: ★★★★★ (인스타 + 우체통 = MZ 매니아 매트릭스)
  • 추천: 산책 + 카페 + 우체통 = 1-2h

④ K-드라마 매트릭스 ("발리에서 생긴 일")

  • 시그니처: K-드라마 "발리에서 생긴 일" (2004) + 다수 드라마 촬영지
  • 외국인 친화도: ★★★★ (K-드라마 매니아 fit·MZ + 인스타)
  • 추천: 드라마 + 인스타 = K-드라마 매니아 매트릭스

⑤ 식당·1박 매니아

  • 시그니처: 동해 회·해산물·인근 호텔 1박 + 일출 매니아 매트릭스
  • 외국인 친화도: ★★★★ (영문 메뉴 일부)
  • 가격: 회·해산물 = 50,000~120,000원/2-3인용·호텔 1박 = 80,000~250,000원

⚠ 외국인 자주 실수 5가지

1. "간절곶 = 그냥 해안": 한국 #1 일출 1번지·새해 1월 1일 10만+ 방문·연중 매니아 매트릭스.

2. "새해 일출만 = 매니아": 연중 일출 + 봄·가을 매트릭스 = MZ + 인스타 매니아 매트릭스.

3. "등대 = 그냥 등대": 1920년~ 100년+·한국 #1 등대·인스타 매트릭스 #1.

4. "우체통 = 일반 우체통": 한국 #1 큰 우체통 (5m+)·인스타 매트릭스·MZ 매니아 #1.

5. "일출 시간 = 어디서나 동일": 월별 일출 시간 다름·사전 확인 필수·30분 전 도착 권장.

⚙ FAQ 6개

1. 외국인 입문 1순위: 새해 1월 1일 일출 + 등대 + 우체통 = 한국 매니아 매트릭스 #1.

2. 일출 시간: 월별 다름·1월 = 07:30·6월 = 05:10·사전 확인 + 30분 전 도착.

3. 새해 1월 1일: 10만+ 방문·사전 호텔 예약 (3개월+) 권장·외국인 매니아 매트릭스 #1.

4. 연중 매니아: 봄·가을 = 일출 + 카페 + 인스타 매니아 베스트.

5. 이동: 시외버스 또는 차량·대중교통 새벽 시간 제한 (1박 권장).

6. 추천 페르소나: 가족·시니어·영적 매니아 = 새해 일출 / MZ·인스타 = 등대 + 우체통 + K-드라마 / 매니아 = 연중 일출 매트릭스.

⚠ 의료·안전 disclaimer

새벽 일출 = 추위·바람 주의 (1-2월 영하)·방한복 풀세트 권장. 절벽 + 해안 = 안전 주의·임신부·시니어 + 어린이 부모 동반 권장. 응급 ☎ 1339 (영문).
