  • チャムシ (Jamsi / 잠시) — ソウル駅の西側、チョンパ路 (Cheongpa-ro / 청파로)のデザートカフェです。眠りをテーマに名づけたメニューが多くあります。そのほかの登録価格は、おやすみ・ぐっすり₩6,000、チャムシ₩6,500、安眠クッキー₩3,500です。住所はヨンサン区 (Cheongpa-ro 330-32 / 청파로 330-32)、最寄り駅はソウル駅 (Seoul Station / 서울역)13番出口です(カカオマップで歩いて約8分)。ペット同伴のタグがあります。食事の注意: 安眠クッキーはオーナーの説明にチョコ・オートミール・クルミ・ピーナッツバターと書かれているので、ナッツアレルギーがあれば避けてください。ブリュレのメニューにはアイスクリーム(乳製品)がつきます。
  • アイスバーグ・ラウンジ (Iceberg Lounge / 아이스버그 라운지) — ムンレ洞 (Mullae-dong / 문래동)の印刷所の路地にある、カフェ兼カクテルバーです。インスタグラムの紹介(@cafe.ing、11/20)にレッドカーペット・シャンデリア・ツリーが出てきます。昼はコーヒーとデザート、夜はカクテルを出します。そのほかの登録価格は、チーズケーキ・ティラミス₩10,000、ザ・ブラック(バーボンのカクテル)₩18,000です。カカオマップの時間は毎日12:00~24:00(ラストオーダー23:30)ですが、インスタグラムの紹介では月曜休みと出ています。月曜は予定に入れません。住所はヨンドゥンポ区 (Dorim-ro 143-gil 14 / 도림로143길 14)、最寄り駅はムンレ駅 (Mullae / 문래역)(2号線)です。駐車場はありません。食事の注意: カクテルのメニューにはお酒が入ります。「ジ・アイスバーグ」(₩8,000)は、オーナーの説明にノンアルコールのウイスキーコールドブリューと書かれています。「ザ・クラウド」(₩7,000)にはマカダミア(ナッツ)のクリームが入ります。チーズケーキ・ティラミスは乳製品が入ります。
  • アナザーサイド (Another Side / 어나더사이드) — バルサン駅 (Balsan / 발산역)の近くの大型カフェです。インスタグラムの紹介(@cafe.ing、11/14、広告表記)にツリーとクリスマスのフォトゾーンが出てきます。そのほかの登録価格は、クロワッサンセット₩7,500、ジャンボンブールサンドイッチセット₩10,300です。住所はカンソ区 (Gangseo-ro 318 / 강서로 318)、最寄り駅はバルサン駅 (Balsan / 발산역)(5号線)です。建物の地下駐車場が2時間無料です(カカオマップ)。食事の注意: ジャンボンブールには豚肉のハムとバターが入ります。キャロットラペ卵サンドイッチは卵、ツナサンドイッチは魚が入ります。ラテ・クロワッサンは牛乳・バターが入ります。

🗺 動線 — 夜の2コース

A. ミョンドン~クァンファムン~チョンゲチョン (12/11以降)

  1. 昼 世宗文化会館カーテンコールガーデン (Curtain Call Garden / 커튼콜가든)のウィンターマーケット(11:00~21:00)でブンオパンとホットワイン
  2. 夕暮れ 新世界百貨店本店 (Shinsegae Main Store / 신세계 본점)のメディアファサード(17:00から)
  3. 夜 チョンゲ広場 (Cheonggye Plaza / 청계광장)からソウル光の提灯祭り (Seoul Lantern Festival / 서울빛초롱축제)(18:00~23:00)に沿って、サミル橋 (Samil Bridge / 삼일교)の方へ歩きます

12月11日より前はBコースを使います。

B. チャムシルの夜

  1. 午後 ロッテワールド アドベンチャー (Lotte World Adventure / 롯데월드 어드벤처)のパレード(14:00) — 入場券がある日だけ
  2. 18:00~21:00 ロッテワールドモール (Lotte World Mall / 롯데월드몰)のタイム・ショー(毎正時)。ロッテタウン クリスマスマーケット (Lotte Town Christmas Market / 롯데타운 크리스마스 마켓)の予約があれば一緒に見ます(#746)
  3. 夜 ソクチョン湖ルミナリエ (Seokchon Lake Luminarie / 석촌호수 루미나리에)(~22:30)

⚠ よくある失敗 3

  1. エバーランドのパレードを11月末の第1週に期待する — クリスマス・ウィッシュ (Christmas Wish / 크리스마스 위시)は11/21に始まりましたが、11/21~26はツリーだけです。パレード・花火は27日からです。
  2. 12月初めに提灯を探す — チョンゲチョンのソウル光の提灯祭り (Seoul Lantern Festival / 서울빛초롱축제)は12月11日に始まります。それより前の夜は、新世界百貨店本店 (Shinsegae Main Store / 신세계 본점)のファサードかソクチョン湖ルミナリエ (Seokchon Lake Luminarie / 석촌호수 루미나리에)を見ます。
  3. クリスマス連休を普段の夜と同じように組む — 12/25(金)~27(日)は3連休で、トゥクソム (Ttukseom / 뚝섬)のマーケットもこの頃(12/24~27)に開きます。屋外の行事は混むので、室内のカフェ・百貨店を混ぜます。防寒の準備は#1318です。

⚙ FAQ 3

  1. 1日しかないなら? — 12月11日以降ならAコースをおすすめします。ミョンドン (Myeongdong / 명동)の新世界ファサード(17:00~)とチョンゲチョン (Cheonggyecheon / 청계천)の提灯(18:00~23:00)は近いほうです。
  2. 12月24日の夜はどこが開いている? — 表を基準にすると、新世界ファサード(~24:00)、提灯(~23:00)、ソクチョン湖 (Seokchon Lake / 석촌호수)(~22:30)、トゥクソムのマーケット(~21:00)、カーテンコールガーデン(~21:00)がこの日、運営期間内にあります。カフェ・バーでは、アイスバーグ・ラウンジ (Iceberg Lounge / 아이스버그 라운지)がカカオマップの登録基準で24:00まで開いています。
  3. 光化門マーケット・明洞大聖堂のクリスマス行事は? — 光化門マーケット (Gwanghwamun Market / 광화문 마켓)は12/11~2027/1/10と日付だけが出ていて、場所・時間は未公開です。明洞大聖堂 (Myeongdong Cathedral / 명동대성당)は2026年の告知がありません(2026-11-24現在)。昨シーズンの情報は#746、イルミネーションの名所は#745です。
