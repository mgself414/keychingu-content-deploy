Jungmisan天文台需预约，登记的运营时间为20:30~01:30。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 北汉江 — Jara岛·Jara岛花卉节

Jara岛(Jara-seom / 자라섬)，加平郡(Jaraseom-ro 60 / 가평읍 자라섬로 60)，☎ 031-8078-8028，是1943年清平水坝(Cheongpyeong Dam / 청평댐)建成时在北汉江(Bukhangang / 북한강)形成的岛，与南怡岛(Nami-seom / 남이섬)直线距离约800m。因是"像鳖一样的山丘"所望着的岛而得名。由东岛(Dongdo / 동도)、西岛(Seodo / 서도)、中岛(Jungdo / 중도)、南岛(Namdo / 남도)四个岛组成。西岛有汽车露营地，中岛有拥有直径100多米草坪广场的生态文化公园，露营地西端有自然生态主题公园二和园(Ihwawon / 이화원)。是举办Jara岛国际爵士音乐节(Jara-seom Gukje Jaejeu Peseutibeol / 자라섬국제재즈페스티벌)的地方。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

2026 Colorful Garden Jara岛花卉节(2026 Colorful Garden Jara-seom Kkot Peseuta / 2026 Colorful Garden 자라섬 꽃 페스타)，Jara岛(Jara-seom / 자라섬)，☎ 加平郡厅旅游科(Gapyeonggunchung Gwangwangwa / 가평군청 관광과) 031-580-2601，于2026年9月12日~10月5日 08:00~18:00举办。7,000韩元的入场费中有5,000韩元以地区货币返还，加平郡居民免费。

  • 登记的2026年项目:花园疗愈路线、街头表演·乐队演出、农特产品销售、气球艺术等体验、北汉江船舶运行、Jara岛入口~活动场地的电动车往返。

📍 铁道·湖泊 — 加平铁路自行车·清平湖畔

加平铁路自行车(Gapyeong Reilbaikeu / 가평 레일바이크)，加平郡(Jangteo-gil 14 / 가평읍 장터길 14)，☎ 031-582-7788，是从加平站(Gapyeong-yeok / 가평역)出发，经过北汉江铁桥、榉树隧道，再从Gyeonggang站(Gyeonggang-yeok / 경강역)返回的往返路线。北汉江铁桥高30m。不得超过乘坐定员乘坐，运行中请避免急停、擅自下车、与身旁的人打闹，禁止饮酒、吸烟。必须在完全停稳后再下车。

  • 开放时间:平日 09:00~18:00，周末·公休日 09:00~18:30。
  • 发车时间:平日6趟(10:00、11:30、13:30、15:00、16:30、18:00)，周末·公休日7趟(09:00、10:30、12:00、14:00、15:30、17:00、18:30)。
  • 休息日:全年无休。停车:免费。

清平湖畔(Cheongpyeong Hoban / 청평호반)，加平郡(Yumyeong-ro 1906-15 / 설악면 유명로 1906-15)，☎ 加平郡游客咨询处(Gapyeong-gun Gwangwang Annaeso / 가평군 관광안내소) 031-582-8830，是在北汉江建清平水坝时形成的清平湖(Cheongpyeong-ho / 청평호)的周边，是加平八景(Gapyeong Palgyeong / 가평 8경)之一。距首尔约50km。在Ureopsan山(Ureopsan / 울업산)岩石绝壁上立钢筋柱建成的木栈道清平湖步道(Cheongpyeong Hosu-gil / 청평 호수길)，可以一边看岩山和湖水一边散步，是Sinseon峰(Sinseonbong / 신선봉)环形步道(Sinseonbong Sunhwan Dullaegil / 신선봉 순환 둘레길)的一部分。

  • 开放时间:全天开放。休息日:全年无休。婴儿车:不可。

📍 森林·星空 — 国立有明山自然休养林·Jungmisan天文台

国立有明山自然休养林(Gungnip Yumyeongsan Jayeonhyuyangnim / 국립유명산자연휴양림)，加平郡(Yumyeongsan-gil 79-53 / 설악면 유명산길 79-53)，☎ 031-589-5487，是1989年开园的休养林。设有2.8km的散步路、森林修炼场(Supsok Suryeonjang / 숲속수련장)、原木屋、露营地。在约79,338㎡的自生植物园中种有木本42种、草本322种，设有香炉植物园(Hyangno Sikmurwon / 향로식물원)、岩石园、湿地植物园、草坪广场。有免费森林讲解、森林疗愈项目、木工艺体验。

  • 开放时间:每日开放 09:00~18:00。住宿入住 15:00，退房 11:00。
  • 休息日:全年无休。停车:可以。容纳人数:3,000人。

Jungmisan天文台(Jungmisan Cheonmundae / 중미산 천문대)，杨平郡(Jungmisan-ro 1268 / 옥천면 중미산로 1268)，☎ 0507-1319-0306，是天文·自然·科学体验学习场。据韩国观光公社介绍，是韩国国内第一个开展幼儿·儿童天文宇宙科学体验学习的机构，也是首都圈附近可以看到最多星星的地方之一。

  • 开放时间:20:30~01:30。需预约，时间随人数变化。
  • 休息日:全年无休。停车:可以。
  • 项目:当日星座之旅、团体项目(2天1夜、夜间、白天、全天编排)等。

⚠ 提前了解的3点

  1. Jungmisan天文台需预约 — 登记的运营时间为20:30~01:30，随人数变化。
  2. 加平铁路自行车只在固定时间发车 — 平日6趟，周末·公休日7趟。
  3. 2026 Jara岛花卉节已经结束 — 于9月12日~10月5日举办。

⚙ FAQ 2

Q. 加平铁路自行车几点发车?

A. 按观光公社登记信息，平日 10:00·11:30·13:30·15:00·16:30·18:00，周末·公休日 09:00·10:30·12:00·14:00·15:30·17:00·18:30发车。全年无休。

Q. 哪里可以看星星?

A. 杨平Jungmisan天文台(Jungmisan Cheonmundae / 중미산 천문대)。需预约，20:30~01:30运营，设有当日星座之旅项目。
