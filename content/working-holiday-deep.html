⚠ 외국인 자주 실수 5가지

1. "워홀 = 18~30세만": 18~30세 = 호주·캐나다·일본·뉴질랜드 + 일부 국가 18~35세 + 외국인 영어 OK + 신청 timeline 3~6개월.

2. "워홀 = 1년만": 1년 = 기본 + 1년 연장 가능 (호주·캐나다 농업·서비스업) + 2년 풀세트 + 외국인 매니아 1번지.

3. "워홀 = 영어 안됨": 영어 OK = 외국인 한국 워홀 한국어 학원 (#403·KIIP) + 외국인 영어 서비스업 + 외국인 매니아 풀세트 + #252·#504 통합.

4. "워홀→영주권 X": 영주권 = 워홀 → E-9 → F-2 → F-5 (5년 거주) + 외국인 매니아 1순위 코스 + #252·#504 통합.

5. "워홀 = 비자 어려움": 비자 = 온라인 신청 + 3~6개월 timeline + 외국인 영어 OK + KOWHEA·KTO 패키지 + 외국인 매니아 1번지.
