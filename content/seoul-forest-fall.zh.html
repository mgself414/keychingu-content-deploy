首尔东北部森林·公园指南 — 首尔儿童大公园，峨嵯山·峨嵯山城·高句丽亭，首尔环城步道5路线，龙马瀑布公园·龙马山Skywalk

副标题:首尔儿童大公园(公园05:00~22:00) · 峨嵯山(295.7m，全天开放) · 峨嵯山城(全天开放) · 峨嵯山高句丽亭(全天开放) · 首尔环城步道5路线峨嵯山线路(4.6km，约2小时10分钟) · 龙马瀑布公园(全天开放) · 龙马山Skywalk(约160m，全天开放) — 已对照韩国观光公社旅游信息(TourAPI)

🎯 如何使用这份指南

这份指南汇集了首尔东北部广津区、中浪区的公园和山，分别是广津区的首尔儿童大公园、有三国时代遗迹的峨嵯山及步行路线、中浪区龙马山的人工瀑布公园和观景平台。七处全部登记为全年无休。首尔林和圣水请看#701 首尔林·圣水指南。

运营信息照录韩国观光公社旅游信息(TourAPI)登记的数值。这份指南只收录韩国观光公社旅游信息中登记的地方。

📍 广津 — 首尔儿童大公园

首尔儿童大公园(Seoul Eorini Daegongwon / 서울어린이대공원)，广津区(Neungdong-ro 216 / 능동로 216)，☎ 02-450-9311，是1973年5月5日儿童节开放的536,094.50㎡公园。有动物园、游乐设施、教养设施。2009年5月5日重新开放时，新开了可以看北极熊和海豹的海洋动物馆、小动物村(Kkoma Dongmul Maeul / 꼬마동물마을)、鹦鹉村(Aengmu Maeul / 앵무마을)和音乐喷泉。公园中央有可容纳8,000个座位的露天演出场Neungdong林中舞台(Neungdong Supsogui Mudae / 능동 숲속의 무대)，八角堂(Palgakdang / 팔각당)里有儿童室内游乐场。

  • 开放时间:公园05:00~22:00。动物园10:00~17:00。游乐园平日10:00~18:30，周末10:00~19:30。
  • 休息日:全年无休。停车:可以。

📍 峨嵯山 — 峨嵯山·峨嵯山城·高句丽亭·首尔环城步道5路线

峨嵯山(Achasan / 아차산)，广津区(Gingorang-ro 213 / 긴고랑로 213)，☎ 峨嵯山管理事务所(Achasan Gwalli Samuso / 아차산관리사무소) 02-450-1655，是横跨首尔和九里市(Guri-si / 구리시)、海拔295.7m的山。沿登山路攀登约40分钟，在山顶可以一眼望见蚕室、南山、北汉山、道峰山等整个首尔。山势不险。三国时代百济把这里作为抵御高句丽的军事据点，据说是百济·新罗·高句丽为争夺汉江而交战的地方。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

峨嵯山城(Achasanseong / 아차산성)，广津区(Gwangjang-dong / 광장동)，☎ 广津区厅文化艺术科(Gwangjin-gucheong Munhwa Yesul-gwa / 광진구청 문화예술과) 02-450-7593，是百济为抵御高句丽入侵而建的城。据说高句丽长寿王把百济盖卤王拖到这里杀死，也说高句丽温达将军在这里被新罗军的箭射中阵亡。发掘出了高句丽的城墙、建筑遗址、池塘遗址，2015年起又出土了新罗的排水设施和高句丽陶器等。

  • 开放时间:全天开放。休息日:全年无休。停车:不可以。
  • 峨嵯山城的登记信息把峨嵯山的高度写为海拔285m，与峨嵯山条目中的295.7m登记值互不相同。

峨嵯山高句丽亭(Achasan Goguryeojeong / 아차산 고구려정)，广津区(Guui-dong / 구의동)，☎ 广津区厅公园绿地科(Gwangjin-gucheong Gongwon Nokji-gwa / 광진구청 공원녹지과) 02-450-7776，是经过历史学者考证，于2009年7月重建的亭子。1984年建的混凝土八角亭倾斜，2008年1月被拆除。名称从八角亭(Palgakjeong / 팔각정)改为高句丽亭。可以俯瞰汉江和首尔。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

首尔环城步道5路线峨嵯山线路(Seoul Dullegil 5-Koseu Achasan Koseu / 서울둘레길 5코스 아차산코스)，中浪区(Myeonmok-dong / 면목동)，☎ 02-779-7902~4，是在全长156.5km、共21条路线环绕首尔一周的首尔环城步道(Seoul Dullegil / 서울둘레길)中，以“连接人与历史的路”为主题的路线。峨嵯山生态公园(Achasan Saengtae Gongwon / 아차산 생태공원)被介绍为景点，靠近地铁Sagajeong站(Sagajeong-yeok / 사가정역)和Gwangnaru站(Gwangnaru-yeok / 광나루역)。

  • 长度·时间:共4.6km，约2小时10分钟。开放时间:全天开放。

📍 龙马山 — 龙马瀑布公园·龙马山Skywalk

龙马瀑布公园(Yongma Pokpo Gongwon / 용마폭포공원)，中浪区(Yongmasan-ro 250-12 / 용마산로 250-12)，☎ 管理事务所(Gwalli Samuso / 관리사무소) 02-2094-2965，是利用曾为采砂场的龙马山岩壁，于1993年5月开放的公园。有三座人工瀑布。中间的龙马瀑布为2级，高51.4m，左边的青龙瀑布(Cheongnyong Pokpo / 청룡폭포)21m，右边的白马瀑布(Baengma Pokpo / 백마폭포)21.4m。有足球场、攀岩场、篮球场、脚排球场(Jokgu-jang / 족구장)和儿童游乐场。

  • 开放时间:全天开放。休息日:全年无休。停车:可以。

龙马山Skywalk(Yongmasan Seukaiwokeu / 용마산 스카이워크)，中浪区(Myeonmok-dong San 1-3 / 면목동 산1-3)，☎ 02-2094-2382，是2025年11月通过首尔环城步道2.0项目，在龙马山山顶附近建成的长约160m、最高10m的木制平台步道。从南山首尔塔到Bonghwa山(Bonghwasan / 봉화산)、道峰山、北汉山都能看到，还可以看日落和夜景。它属于首尔环城步道4路线(Mangu·Yongmasan / 망우·용마산)，与从Sagajeong公园(Sagajeong Gongwon / 사가정공원)出发的无障碍步道龙马山Donghaeng路(Yongmasan Donghaenggil / 용마산 동행길)相连。坡度做得平缓，轮椅和婴儿车也能上到观景台。据观光公社介绍，仅2026年2月一个月就有约23万人到访。

  • 开放时间:全天开放。休息日:全年无休。停车:不可以。

⚠ 行前须知 3 点

  1. 首尔儿童大公园的动物园10:00~17:00开放 — 公园是05:00~22:00，游乐园平日开到18:30，周末开到19:30。
  2. 峨嵯山城和龙马山Skywalk不能停车 — 峨嵯山·高句丽亭·龙马瀑布公园可以停车。
  3. 首尔环城步道5路线约需2小时10分钟 — 全长4.6km，靠近Sagajeong站·Gwangnaru站。

⚙ FAQ 2

Q. 有轮椅能到的观景台吗?

A. 按观光公社登记信息，龙马山Skywalk是坡度平缓的平台，轮椅和婴儿车可以上到观景台。全天开放。

Q. 到峨嵯山山顶要多久?

A. 沿登山路约40分钟。介绍为海拔295.7m(峨嵯山城条目登记为285m)，山势不险。
