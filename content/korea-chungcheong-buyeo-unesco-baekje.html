🎯 왜 부여 가이드인가

부여 (Buyeo) = UNESCO 백제역사유적지구 2015·백제 마지막 도성 (538~660년 사비 도성)·정림사지 5층 석탑 (1300년+)·부소산성·낙화암·백제문화단지. 외국인 페인포인트 = (a) "부여 = 작은 군" 잘못된 인식 (b) UNESCO 2015 백제 4 cluster (부여) (c) 정림사지 5층 석탑 = 1300년+ 백제 매니아 매트릭스 #1 (d) 낙화암 = 백제 멸망 (660년)·3000궁녀 매니아 매트릭스 (e) 백제문화단지 = 복원·테마파크 (f) 영문 풀세트.

본 가이드는 5축 12 시그니처 + UNESCO + 백제 + 낙화암.

🏛 5축 deep dive

① 정림사지 (UNESCO·1300년+ 5층 석탑)

  • 시그니처: 백제 5층 석탑 (한국 #1 백제 석탑)·1300년+·UNESCO 2015
  • 외국인 친화도: ★★★★★ (영문·다국어)
  • 시간: 09:00~18:00·1,500원

② 부소산성 + 낙화암 (백제 마지막·660년)

  • 시그니처: 백제 마지막 도성·낙화암 = 660년 백제 멸망 (3000궁녀 전설)
  • 외국인 친화도: ★★★★ (영문·매니아)
  • 시간: 09:00~18:00·2,000원

③ 백제문화단지 (복원·테마파크)

  • 시그니처: 백제 복원·테마파크 매트릭스·한복 + 인스타
  • 외국인 친화도: ★★★★★ (영문·MZ + 가족)
  • 시간: 09:00~18:00·5,000~10,000원

④ 부여 음식 (한정식·굴비·연근)

  • 시그니처: 충청도 + 부여 시그너 매트릭스
  • 외국인 친화도: ★★★★ (안 매콤·외국인 입문)

⑤ 공주 + 부여 1박 풀세트

  • 시그니처: UNESCO 백제 풀세트·매니아 매트릭스 #1

⚠ 외국인 자주 실수 5가지

1. "부여 = 작은 군": UNESCO 백제 2015·4 cluster·매니아 매트릭스.

2. "정림사지 = 일반 사지": 5층 석탑 1300년+·백제 시그너 #1.

3. "낙화암 = 일반 절벽": 660년 백제 멸망·3000궁녀 매니아 매트릭스.

4. "백제문화단지 = 작은 테마파크": 백제 복원 풀세트·MZ + 가족.

5. "부여 한정식 = 일반 한식": 부여 시그너 (굴비·연근·한정식).

⚙ FAQ 6개

1. 외국인 입문 1순위: 정림사지 + 부소산성·낙화암 + 백제문화단지 = 4-5시간.

2. 공주 + 부여 1박: UNESCO 풀세트·매니아 매트릭스 #1.

3. 백제문화제 (10월): 공주·부여 합동·매니아 매트릭스 #1.

4. 한복 체험: 백제문화단지·15,000~30,000원·MZ + 인스타.

5. 시즌: 봄·가을 베스트.

6. 추천 페르소나: 가족·시니어 = 정림사지 + 박물관 / MZ·인스타 = 백제문화단지 + 한복 / 매니아 = 1박 풀세트 + 공주.
