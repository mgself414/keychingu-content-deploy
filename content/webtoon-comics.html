⚠ 외국인 자주 실수 5가지

1. "한국 만화·웹툰 = 한국어만": 한국 웹툰 = 외국인 영어 OK 글로벌 1번지 (LINE Webtoon)·Tower of God·Solo Leveling + 외국인 글로벌 매니아 #1·#444 통합.

2. "웹툰 = 무료만": 웹툰 = 네이버·카카오 무료 + 유료 미리보기 + 외국인 글로벌 매니아 1번지 + 외국인 영어 OK 풀세트.

3. "만화 카페 = 한국인만": 만화 카페 = 외국인 영어 OK + 외국인 매니아 1번지 (시간당 3~5K) + 강남·홍대·이태원·#138·#142·#144 cluster.

4. "Solo Leveling = TV만": Solo Leveling = 외국인 글로벌 매니아 1번지 + 웹툰·애니메이션·#387 K-pop 통합 + 외국인 매니아·#404 통합.

5. "부천 만화 박물관 = 못 감": 부천 만화 박물관 = 한국 #1 만화 박물관 + 외국인 영어 OK 풀세트 + 외국인 매니아·KTX 1박2일.
