🎯 なぜ「バター餅」ガイドなのか

バター餅 (Butter Tteok) = 伝統的なチャプサル餅 (찹쌀떡) に温かいバターをかけたフュージョンデザートで、2026年上半期韓国で最も検索されたデザートキーワード。「外はサクサク、中はもちもち (겉바속쫀)」が特徴で、ドゥジョンク (두쫀쿠 - ドバイチューイークッキー) のブームを受け、InstagramやTikTokを席巻中。外国人観光客の最大の悩みは、(a) 「餅＝昔のおやつ」という誤解 — 実際はヒップな最新デザート (b) どこで買えるのか (延南 (ヨンナム)・聖水 (ソンス) の特定の店舗) (c) 午後には品切れ — 有名店は午前中のオープンラン (開店待ち行列) (「バターラン」) が必須 (d) 種類・価格。RedditやYouTubeで「butter rice cake Seoul / 버터떡 맛집」の検索が急増しています。

このガイドでは、バター餅のシグネチャー店・種類 + オープンラン戦略 + 地域 (延南 (ヨンナム)・聖水 (ソンス)) + 種類マトリックス + FAQをご紹介します。

🧈 バター餅 6大ディープダイブ

① ジョンガジャジョム (정과자점) — 延南洞 (ヨンナムドン)

  • シグネチャー: 日本のデザート風濃厚チーズ味 + バター餅・外はゴールデンブラウンでサクサク・中はもちもち・温かいうちにバターの香り
  • 位置: 麻浦区 (マポグ) 東橋路38キル (동교로38길) 22 (延南洞 (ヨンナムドン))
  • 外国人フレンドリー度: ★★★★☆ (延南 (ヨンナム) のアクセス性・フォトジェニック)
  • ヒント: 米本来の味を重視・過度なデコレーションなし・温かいうちにすぐに食べる

② イウッチプトンットンイ (이웃집통통이)

  • シグネチャー: ソウル初の上海スタイルバター餅・小麦粉不使用グルテンフリー・よりもちもち
  • 外国人フレンドリー度: ★★★★☆ (グルテンフリー需要・品質)
  • ヒント: 昼頃に完売することが頻繁 → 開店時間帯の「バターラン」必須

③ オウド (오우드) — 聖水洞 (ソンスドン)

  • シグネチャー: マドレーヌ型に焼いたバター餅・カヌレのように外はサクサク・中はチャプサル (もち米) でもちもち・聖水 (ソンス) 感性カフェ
  • 外国人フレンドリー度: ★★★★☆ (聖水 (ソンス) のヒップな場所・カフェ併設)
  • ヒント: カフェの雰囲気 + バター餅・聖水 (ソンス) のポップアップストア巡りと連携

④ オボクットクチプ (오복떡집) — 聖水洞 (ソンスドン)

  • シグネチャー: 伝統餅店ベースのバター餅・聖水 (ソンス) の人気店・伝統+最新のハイブリッド
  • 外国人フレンドリー度: ★★★☆☆ (伝統餅店の体験)
  • ヒント: 伝統餅店のバター餅 = 本格的なもちもち感・聖水 (ソンス) のローカル体験

⑤ ハツベーカリー (Heart's Bakery)

  • シグネチャー: ワンバター餅 (왕버터떡) (既存より大きい大型)・SNS認証ショット
  • 外国人フレンドリー度: ★★★★☆ (ビジュアル・シェア用)
  • ヒント: 大型 = シェアして食べる・認証ショット・品切れ注意

⑥ アンバター餅 (앙버터떡)

  • シグネチャー: インジョルミ (きな粉餅) + 甘いあんこ + バター・もちもち+甘さ+香ばしさの3重バランス
  • 外国人フレンドリー度: ★★★★☆ (あんこ、親しみやすい+新鮮)
  • ヒント: あんこ (甘味) + バター (香ばしさ) の組み合わせ・伝統+フュージョン入門用

🍽 食べ方 & 「バターラン」実践 (外国人向け)

  • バターラン (Butter-Run): 有名店に午前中の開店時間帯に訪問 → 午後の品切れを回避 (聖水 (ソンス)・カロスキル (가로수길) は特に)
  • 温かいうちに: バターが溶けて香り・食感が最高 → 受け取ったらすぐに
  • 支払い: カード・モバイル決済 (カカオペイ・サムスンペイなど)・少額現金 (店舗による)
  • グルテンフリー: イウッチプトンットンイ (이웃집통통이) など小麦粉不使用の店舗を確認
  • 緊急時: ☎ 1330 (観光通訳)・112

⚠ 外国人がよくする間違い 5つ

1. 「餅は昔のおやつ」: バター餅は2026年の最新トレンドデザート・ヒップな場所の新作。

2. 「いつでも行けばある」: 有名店は午後には品切れ・午前中の「バターラン」必須。

3. 「冷めても大丈夫」: バター餅は温かいうちにバターの香り・食感が最高。

4. 「餅＝グルテン」: 米ベースなのでほとんどが小麦粉不使用・ただし店舗ごとに確認(一部小麦粉使用)。

5. 「ドゥジョンク (두쫀쿠) と同じ」: ドゥジョンク (두쫀쿠) (クッキー) ≠ バター餅 (チャプサル餅)・両方を併売する店舗も多い。

⚙ FAQ 6つ

1. バター餅って何？: 伝統的なチャプサル餅 (찹쌀떡) + 温かいバター・2026年最多検索デザート・外はサクサク中はもちもち (겉바속쫀)。

2. どこで買えるの？: 延南 (ヨンナム) (ジョンガジャジョム (정과자점))・聖水 (ソンス) (オウド (오우드)・オボクットクチプ (오복떡집))・イウッチプトンットンイ (이웃집통통이) (グルテンフリー)。

3. オープンランは必須？: 有名店は午後には品切れが多いため → 午前中の訪問が安全。

4. 価格帯は？: トレンドデザートとしては手頃な価格帯・店舗により異なる (1個あたり約₩3,000~8,000 (~330~880 JPY))。

5. グルテンフリー？: イウッチプトンットンイ (이웃집통통이) など小麦粉不使用・ただし店舗ごとに確認必須。

6. おすすめのタイプは？: 入門者向け=ジョンガジャジョム (정과자점) / 聖水 (ソンス) 巡り=オウド (오우드) / グルテン敏感=イウッチプトンットンイ (이웃집통통이)。

⚠ 医療・安全・アレルギー免責事項

バター餅はチャプサル餅 (찹쌀)・乳製品 (バター)・あんこ (팥) を含みます → 乳糖・ナッツ・アレルギーに注意。グルテンフリーを謳う店舗でも交差汚染の可能性 → 重度のアレルギーの方は店舗に直接確認してください。餅は喉に詰まらせる危険があります (お子様・高齢者)。価格・営業時間・品切れは店舗/シーズンにより変動 → 訪問前に確認してください。緊急時 ☎ 1330・112。

  • 国別: 乳製品の持ち込み規制は国ごとに確認 (ほとんどの国で個人消費は問題なし)
