首尔夜间跑步 — 天黑后能跑的地方、关门时间和冬天停止运行的设施

副标题: 想在天黑后于首尔跑步的人，要事先知道三件事。哪里几点关门，冬天什么会停止运行，跑完后在哪里洗澡、取行李。奥林匹克公园22:00起不能进入园内，汝矣岛汉江公园的淋浴间也在22:00关门。地铁站跑者支援空间开到23:00。盘浦月光彩虹喷泉只在3月15日到10月运行，所以11月到次年3月14日看不到。从国民投票中入选的首尔跑步路线里，挑出机构有夜间相关说明的7处，以机构公布的值为主整理。

ISSUE 06 · #147 · 2026-11-24 · 서울 야간 러닝

🎯 适合谁，为什么是这7处

这篇文章是为白天游览、傍晚或夜里想跑一小时步的旅行者准备的。白天跑步只需要知道长度和交通方式，夜里要考虑的事情更多。公园关门的时间、寄存行李的地方关门的时间、随季节关掉的设施。

选择标准有两个。第一，是韩国观光公社 (Korea Tourism Organization / 한국관광공사)"名胜发掘100×100" (100×100 Spot Discovery / 명소발굴 100×100)跑步路线主题国民投票中入选的首尔路线。第二，管理机构或首尔市公布了夜间相关内容(关门时间、照明、夜间使用的设施)。满足这两个条件的路线中，这篇文章介绍7处。汝矣岛汉江公园、盘浦汉江公园、首尔林、清溪川、奥林匹克公园、京义线林荫路、南山北侧环路。

同一投票第9名(136票)的纛岛汉江公园，以及白天路线全部的长度和交通方式，整理在#146。这篇文章减少了与#146重复的地点介绍，只收集夜里需要的信息。

⚠ 标注原则: 使用时间、费用、设施、交通方式，是2026-11-24在首尔市未来汉江本部 (Seoul Metropolitan Government Hangang Project Headquarters / 서울시 미래한강본부)的汉江公园页面、首尔设施公团 (Seoul Facilities Corporation / 서울시설공단)的清溪川页面、韩国体育产业开发 (Korea Sports Industry Development / 한국체육산업개발)的奥林匹克公园页面、首尔的公园 (Seoul Parks / 서울의공원)的京义线林荫路页面以及首尔市公布的资料中查阅到的值。机构没有公布的项目没有写。所以灯光亮起和熄灭的时刻、日落时刻、跑步需要的时间，这篇文章里都没有。步行到清溪广场的时间是Kakao Map路线值(2026-11-24)。得票和名次是韩国观光公社名胜发掘100×100跑步路线主题国民投票的值。运营时间和进入方式可能变动。

🚦 夜间跑步之前 — 共同的安全和礼仪

七处都不是跑步专用的路。和散步的人、自行车、游客共用。把机构规定的规则，和在多人共用的路上遵守的一般礼仪分开写。

机构规定的规则

  • 汉江公园的自行车规则。 按首尔市未来汉江本部的说明，汉江公园里自行车只能在自行车道上骑行，时速20km以下，靠右通行，排成一列。夜间要开灯。
  • 清溪川。 不能骑自行车和滑旱冰，也不能带动物进入(残疾人辅助犬除外)。吸烟和饮酒也在禁止清单里。跑步不在这个清单里。
  • 奥林匹克公园。 22点以后不能进入公园内部。土城内的散步路是行人优先路段，宠物犬要牵绳。
  • 汉江公园。 禁烟。宠物犬不牵绳罚款5万韩元，乱扔垃圾罚款10万韩元。

夜路礼仪

下面不是规定，而是在共用的路上遵守的礼仪。

  • 跑步的人不要进入自行车道。 自行车被规定只能在自行车道上骑行，所以跑步的人使用步行道，可以减少互相碰撞。盘浦汉江公园的介绍写明自行车道和散步路是分开的。
  • 穿浅色衣服或反光材质的衣服。 深色衣服会让自行车和其他行人更晚看到。
  • 调低耳机音量。 要能听到后面传来的自行车铃声和广播。即使清溪川周边没有下雨，也可能响起避难广播。
  • 狭窄的路上放慢速度。 清溪川和京义线林荫路延南洞 (Yeonnam-dong / 연남동)区段都在旅游区中心。人多的路段改为步行。

紧急时

  • 事故或紧急情况拨打119，报警拨打112。
  • 在清溪川被突然下的雨困住时，拨打清溪川综合状况室 (Cheonggyecheon Control Room / 청계천 종합상황실)02-2290-7111~3。

① 汉江 — 2处

汝矣岛·盘浦汉江公园的交通指南写明，咨询中心的执勤是00:00~24:00，行政业务是09:00~18:00。

汝矣岛汉江公园 (Yeouido Hangang Park / 여의도한강공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票162票·第2名。
  • 夜间使用的设施: 跑完后可以洗澡的开放式淋浴间在公园咨询中心1楼。每天06:30~22:00开放。5号线汝矣渡口站内有配备更衣室和物品保管柜的Runner Station。两处设施的详细数值写在下面的"洗澡和寄存行李的地方"。
  • 关门时间: 淋浴间22:00关门。淋浴规定在20分钟内结束，所以跑完的时刻要比22:00提前得宽裕一些。
  • 交通方式:
  • 5号线汝矣渡口站2·3号出口: 步行1分钟，公园中心部。电梯在2号出口附近。
  • 9号线国会议事堂站 (National Assembly Station / 국회의사당역)1号出口: 步行1分钟，国会 (National Assembly / 국회)后面。
  • 冬天停止运行的设施: 水光广场 (Mulbit Plaza / 물빛광장)的喷泉只在4~10月运行。

盘浦汉江公园 (Banpo Hangang Park / 반포한강공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票143票·第6名。
  • 月光彩虹喷泉 (Banpo Moonlight Rainbow Fountain / 달빛무지개분수): 设在盘浦大桥 (Banpo Bridge / 반포대교)的喷泉，总长1,140m。首尔市未来汉江本部介绍，夜间使用景观照明营造夜景。观看免费，不用预约，现场观看。
  • 运行期间: 3月15日到10月。11月到次年3月14日不运行。 11月~3月14日跑盘浦的话，跑的是没有喷泉的江边。
  • 场次(每场20分钟): 3月15日~5月和10月是12:00、19:30、20:00、20:30、21:00。6~9月在此基础上增加21:30。不分平日和周末。只看傍晚场次的话，从19:30起每隔30分钟一场。
  • 停止运行的时候: 风速每秒7m以上时、运行时间内有降雨预报时、汉江浊度15NTU以上时。有活动的话时间可能改变。咨询电话02-3780-0578~9。
  • 潜水桥 (Jamsugyo Bridge / 잠수교): 按公园介绍，潜水桥缩减了车道、加宽了人行道，并设有自行车专用车道。
  • 交通方式:
  • 9号线新盘浦站1号出口: 从盘浦出入口 (Banpo Interchange / 반포나들목)进入，步行约15分钟。
  • 3·7·9号线高速客运站站 (Express Bus Terminal Station / 고속터미널역)8-1·8-2号出口(或GOTO Mall G1): 朝盘浦大桥方向步行约15分钟。
  • 4·9号线铜雀站 (Dongjak Station / 동작역)1·2号出口: 沿汉江边朝西来岛 (Seoraeseom Island / 서래섬)方向走。
  • 无论从哪个站出发，到公园都要走一段路。想赶上喷泉场次，要把这段时间加上再出发。
  • 冬天停止运行的设施: 月光彩虹喷泉(11月~3月14日)。公园内的汉江循环观光车(Haechi Car)5~11月运营，运行到20点为止(周一至周五14~20点，周末11~20点，16~17点休息)。

② 公园·林荫路 — 3处

三处的夜间情况各不相同。首尔市公布首尔林夜间也开放，奥林匹克公园22:00起不能进入园内。京义线林荫路按首尔的公园的说明，公园厕所有两处，其中一处傍晚关门。

首尔林 (Seoul Forest / 서울숲)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票130票·第15名。
  • 使用时间: 首尔市公布(2026-10-30)写明首尔林全年无休24小时开放。生态林等部分设施另有时间。
  • 夜晚: 首尔市2026-10-30的报道介绍了下班后沿着灯光走的秋夜花园散步。
  • 公园道路: 按首尔市公布，首尔林内核心公园道路合计22,747.6m是步行者专用道，所以要推着自行车走。
  • 交通方式: 从水仁盆唐线首尔林站4号出口到公园步行约2分钟。

奥林匹克公园 (Olympic Park / 올림픽공원)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票118票·第24名。
  • 关门时间: 七处中只有这里公布了公园内部停止进入的时刻。
  • 步行和自行车进入是05:00~22:00。
  • 广场区域到24:00。
  • 22点以后不能进入公园内部。
  • 梦村土城 (Mongchontoseong Fortress / 몽촌토성)区域为保护文物，使用时间之外禁止进入内部。
  • 有深夜活动的日子，出入口开关的时间可能调整。
  • 费用: 公园使用免费，停车另外收费。
  • 夜间选择的路线: 运营公园的韩国体育产业开发作为"散步/慢跑路线"介绍的路有5条。每条的一圈距离固定，容易挑出能在22:00之前跑完的长度。
  • 湖畔之路 (Hobanui-gil / 호반의 길)1,302m，土城之路 (Toseongui-gil / 토성의 길)2,210m，青春之路 (Jeoleumui-gil / 젊음의 길)3,150m，回忆之路 (Chueogui-gil / 추억의 길)3,350m，恋人之路 (Yeoninui-gil / 연인의 길)4,290m。各路线的路径写在#146。
  • 土城之路、回忆之路、恋人之路经过梦村土城区域。这个区域在使用时间之外禁止进入，所以晚上避开。
  • 青春之路是自行车环路。要留意自行车。
  • 交通方式: 有三个站，线路不同。
  • 8号线梦村土城站1号出口
  • 5号线·9号线奥林匹克公园站 (Olympic Park Station / 올림픽공원역)3·4号出口
  • 9号线汉城百济站 (Hanseong Baekje Station / 한성백제역)2号出口
  • 公园介绍把东1门 (East Gate 1 / 동1문)归在奥林匹克公园站一侧，把南4门 (South Gate 4 / 남4문)和和平之门广场 (Peace Gate Plaza / 평화의문광장)归在梦村土城站·汉城百济站一侧。

京义线林荫路 (Gyeongui Line Forest Park / 경의선숲길)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票104票·第33名。
  • 夜间要考虑的事 — 厕所: 首尔的公园说明中的公园厕所有两处。管理事务所厕所只在平日09:00~18:00开放，盐里洞厕所24小时开放。晚上6点以后能用的公园厕所只有盐里洞一处。跑步前先去地铁站的厕所。
  • 长度: 首尔的公园写明全长约6.3km。延南洞区段约1.2km。选一个区段往返。
  • 交通方式: 每个区段的站不同。
  • 延南洞区段: 弘大入口站(2号线·机场铁路 (Airport Railroad / 공항철도)·京义中央线 (Gyeongui-Jungang Line / 경의중앙선))、加佐站 (Gajwa Station / 가좌역)(京义中央线)。首尔市公布(2025-03)写明从弘大入口站3号出口438m。
  • 卧牛桥 (Wau Bridge / 와우교)区段: 弘大入口站、西江大学站 (Sogang Univ. Station / 서강대역)(京义中央线)
  • 新水·大兴·盐里洞区段: 6号线孔德站 (Gongdeok Station / 공덕역)、6号线大兴站 (Daeheung Station / 대흥역)
  • 新昌岭·元晓路区段: 6号线孝昌公园前站 (Hyochang Park Station / 효창공원앞역)

③ 市中心 — 2处

清溪川 (Cheonggyecheon Stream / 청계천)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票128票·第18名。
  • 夜晚: 首尔设施公团写明清溪川照明为10,419盏。
  • 长度: 首尔设施公团写明总长8.12km，复原区段5.84km。
  • 交通方式: 按Kakao Map路线，从5号线光化门站5号出口到清溪广场 (Cheonggye Plaza / 청계광장)步行3分钟(约120m)。光化门站内有开到23:00的跑者支援空间。
  • 下雨就关闭: 清溪川是因天气而不是因时间关闭的地方。
  • 预计因下雨开启水闸时，会管制进入。
  • 即使清溪川周边没有下雨，听到避难广播也要立刻离开河道。上游下的雨也会使水位上涨。
  • 水位上涨时，按广播和安全员的指引，从最近的出入口上去。
  • 不要在桥下躲雨。 下雨时水闸会突然开启，桥下很危险。
  • 为被突然下的雨困住的人设有紧急梯子，共39处。
  • 不能做的事: 使用自行车和滑旱冰、带动物进入(残疾人辅助犬除外)、钓鱼、游泳、露营·做饭、吸烟·饮酒。打算和宠物犬一起跑的话，选其他地方。

南山北侧环路 (Namsan North Loop Road / 남산 북측순환로)

  • 国民投票: 韩国观光公社名胜发掘100×100跑步路线主题国民投票85票·第59名。
  • 夜晚: 首尔市报道(2018-08)谈到这条路时写道，到了夜晚灯光一盏一盏亮起，城郭路 (Fortress Wall Road / 성곽길)的韵味更深。
  • 车和自行车: 首尔市把这条路介绍为全面禁止车辆和自行车通行、只有行人通行的散步路。车辆全面管制从1996年6月开始。
  • 区段和距离: 首尔市报道写明从教育科学院 (Gyoyukgwahagwon / 교육과학원)到国立中央剧场 (National Theater of Korea / 국립중앙극장)约3.3km。往返约6.6km。在地图应用上，把两处中离住处近的一侧设为目的地。
  • 不要和南侧环路搞混: 按首尔市报道(2025-06)，南侧环路是行人和车共用的道路，车辆和自行车单向通行。南侧环路是车和自行车单向通行的道路，所以这篇文章只介绍北侧。

🚿 洗澡和寄存行李的地方

夜里跑步，经常不回住处就直接出门。把能寄存行李和换衣服的地方、能洗澡的地方，连同关门时间一起写出来。

  • 地铁站跑者支援空间 (Runner Support Space / 러너지원공간)3处: 首尔市2025年10月公布。是光化门站(5号线)、会贤站 (Hoehyeon Station / 회현역)(4号线)、世界杯体育场站 (World Cup Stadium Station / 월드컵경기장역)(6号线)3处。每天05:30~23:00开放，配合地铁运行时间运营。首尔市表示进入没有另外的使用费。通过Naver QR或KakaoTalk认证进入。有男女更衣室、个人行李保管柜、化妆间、跑步用品自动售货机。从清溪广场出发的话，有光化门站的这一处。
  • 汝矣岛汉江公园开放式淋浴间: 每天06:30~22:00开放。08:30~09:30和15:30~16:30是清扫时间。免费，毛巾和洗漱用品自己带。通过Naver应用QR码认证入场。男女淋浴间各5个，有物品保管柜13个、更衣室2间。淋浴要在20分钟内结束，不能洗衣服。咨询电话是汝矣岛咨询中心02-3780-0563。
  • 汝矣渡口站的Runner Station: 首尔市2024年5月公布的设施。位于5号线汝矣渡口站内B1~M1层。有更衣室、化妆间、物品保管柜58个(M1层42个、B1层16个)。

跑者支援空间通过Naver QR或KakaoTalk认证进入，淋浴间通过Naver应用QR认证进入。使用日之前，先在自己的手机上看看认证画面能不能打开。考虑到认证不通过的情况，也同时准备好在住处换好衣服再出门的计划。

⚠ 3个常见失误

  1. 冬天去盘浦看喷泉 — 月光彩虹喷泉只在3月15日到10月运行。11月到次年3月14日，傍晚去也没有喷泉。汝矣岛水光广场的喷泉也只在4~10月运行。
  2. 把奥林匹克公园当作深夜跑步的地方 — 步行进入到22:00为止，之后不能进入公园内部。只有广场区域到24:00。傍晚跑步的话，时间要安排在22:00之前出来。
  3. 超过寄存行李的地方的关门时间 — 地铁站跑者支援空间23:00关门，汝矣岛汉江公园淋浴间22:00关门。要把跑完回来的时间也算进去。淋浴间有20分钟的使用限制，所以22:00前一刻才到的话，洗澡的时间不够。

⚙ 3个常见问题

  1. 哪里开到很晚？ — 首尔市表示首尔林全年无休24小时开放。奥林匹克公园步行进入到22:00，只有广场区域到24:00。汝矣岛·盘浦咨询中心的执勤是00:00~24:00。清溪川预计因下雨开启水闸时禁止进入。
  2. 冬季停止运行的设施有哪些？ — 盘浦月光彩虹喷泉(3月15日~10月运行)、汝矣岛水光广场喷泉(4~10月运行)、盘浦汉江公园的汉江循环观光车(Haechi Car)(5~11月运营)。
  3. 跑完有洗澡的地方吗？ — 汝矣岛汉江公园咨询中心1楼有开放式淋浴间。每天06:30~22:00，免费，通过Naver应用QR码认证进入。毛巾和洗漱用品要带上。地铁站跑者支援空间3处是使用更衣室和个人行李保管柜的地方。
