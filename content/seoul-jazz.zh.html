外国人常犯的5个错误

1. 误解：“爵士酒吧都一样”

首尔 (Seoul / 서울) 的爵士乐场景范围非常广，从1976年开业的老字号 (Nopo / 노포) (All That Jazz / 올댓재즈) 到 2021年开业的潮流酒廊 (Dido / 디도)，再到 市场内迷你空间 (Sound Dog / 사운드독)。韩国三大爵士俱乐部 (Jazz Club / 재즈 클럽) 的老字号 (Nopo / 노포) 传承、清潭 (Cheongdam / 청담) 的奢华酒廊，以及延南 (Yeonnam / 연남) 的秘密酒吧，即使花费同样的 ₩30,000，也能获得截然不同的体验。请参考正文§三大俱乐部比较。

2. 不知道鼓掌时机

爵士乐的正确鼓掌时机是每位乐手即兴独奏结束后。而不是歌曲的开始或结束。如果不确定，跟着旁边的韩国 (Hanguk / 한국) 客人做是最好的方法。

3. 午夜后地铁停运 — 未安装 Kakao T (카카오T)

首尔 (Seoul / 서울) 地铁在平日午夜前后停运。爵士乐演出的核心时段是21:00~24:00，因此务必提前安装 Kakao T (카카오T) App (支持英文) 并绑定支付银行卡。

4. 未发送 Instagram (인스타그램) DM (私信) 直接前往

韩国 (Hanguk / 한국) 爵士酒吧的标准预订方式是Instagram (인스타그램) DM (私信) 预订。老字号 (Nopo / 노포) 可通过电话·短信，新开的酒吧可通过 Catchtable (캐치테이블) (支持英文) 预订。周末或热门演出几乎无法直接前往。

5. 只带银行卡去老字号 (Nopo / 노포)

Chunnyundoando (천년동안도)·Sound Dog (사운드독) 等老字号 (Nopo / 노포) 有些地方没有银行卡刷卡机。务必备足 ₩50,000 现金。

★ 韩国三大爵士俱乐部深度比较 — Janus (야누스) vs Chunnyundoando (천년동안도) vs All That Jazz (올댓재즈)

在首尔 (Seoul / 서울) 爵士乐界，外国人最常比较的三大老字号 (Nopo / 노포)。它们都始于1970~80年代，承载着韩国 (Hanguk / 한국) 爵士乐的历史 — 即使花费同样的“现场演出 + 饮品 ₩30,000”，时间和氛围也截然不同。

1️⃣ Janus (야누스) — 韩国 (Hanguk / 한국) 爵士之母朴星渊 (Park Sung-yeon / 박성연) 打造的主唱舞台

位置: 首尔 (Seoul / 서울) 钟路区 (Jongno-gu / 종로구) 光化门 (Gwanghwamun / 광화문) 一带 (2025年9月重新开业)

开业: 1978年新村 (Sinchon / 신촌) — 2025年将在光化门 (Gwanghwamun / 광화문) 迎来第七次舞台

代表氛围: 韩国 (Hanguk / 한국) 爵士主唱的活历史博物馆，传统主唱现场演出

价格范围 (2026年5月为准):

  • 入场费 + 1~2杯饮品: ₩30,000~50,000
  • 无晚餐选项 (以饮品为主)

核心特点:

  • 由韩国 (Hanguk / 한국) 第一代爵士歌手故朴星渊 (Park Sung-yeon / 박성연) 于1978年亲自创立 — 韩国 (Hanguk / 한국) 爵士主唱历史的起点
  • 47年间搬迁6次 (新村 (Sinchon / 신촌)→大学路 (Daehangno / 대학로)→梨花女子大学后门 (Ewha Womans University Rear Gate / 이대후문)→清潭 (Cheongdam / 청담)→瑞草 (Seocho / 서초)→狎鸥亭 (Apgujeong / 압구정)→光化门 (Gwanghwamun / 광화문)) — “流浪的爵士俱乐部 (Jazz Club / 재즈 클럽)”本身就是一种内容
  • 位于光化门 (Gwanghwamun / 광화문) 中心 — 与景福宫 (Gyeongbokgung / 경복궁) 夜间开放 + 清溪川 (Cheonggyecheon / 청계천) 夜景自然衔接

常见问题

Q1. 英语能沟通吗？

All That Jazz (올댓재즈)·Asome Ground (어썸그라운드)·Dido (디도)·SEOB's 明确表示可提供英语服务。Janus (야누스)·Chunnyundoando (천년동안도)·Sound Dog (사운드독) 以韩语 (Hanguk-eo / 한국어) 为主，但可通过 Instagram (인스타그램) DM (私信) 提前咨询。

Q2. 单人 (Solo / 솔로) 可以去吗？

Asome Ground (어썸그라운드) (设有单人座位)、SEOB's (吧台)、All That Jazz (올댓재즈) (座位宽敞) 最适合。Once In A Blue Moon (원스인어블루문) 是晚餐酒廊，不建议单人前往。

Q3. 可以带小孩去吗？

大部分场所限19岁以上 (销售酒类)。可携带家人前往的场所仅限All That Jazz (올댓재즈) 的部分时段。未成年人同行务必提前确认。

Q4. 价格有负担怎么办？

Club Evans (클럽 에반스) (入场 ₩15,000~20,000 + 1杯饮品)、Asome Ground (어썸그라운드) (₩20,000 含饮品) — 性价比最高的两家。韩国 (Hanguk / 한국) 爵士入门 ₩20,000 即可。

Q5. 不预订直接前往可以吗？

Chunnyundoando (천년동안도)·Boogie Woogie (부기우기)·Club Evans (클럽 에반스) 平日可直接前往。Janus (야누스)·Once In A Blue Moon (원스인어블루문)·Dido (디도) 周末几乎无法直接前往。周末前往需提前1~2周预订。

Q6. 营业到很晚 (23:00以后) 的有吗？

Boogie Woogie (부기우기) (~02:00)·All That Jazz (올댓재즈) (~24:00) 可利用。其他场所24:00关门。午夜后乘坐 Kakao T (카카오T) 返回酒店。
