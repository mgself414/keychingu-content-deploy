> 副标题：圣代、雪莲汤、高汤、猪肉汤、油菜酱、外国游客的豆芽汤+地方特色菜+推荐给外国人

🎯 为什么选择韩国汤矩阵？

外国人韩式汤饭的痛点=“就是汤+饭，怎么有这么多种类？”。韩国米汤不是简单的“汤加米饭”，而是根据成分、地区、时间和季节分为六种以上。即使是同一个“汤饭”，也是圣代汤饭（平安·全罗菜）/雪陵汤（首尔贵族的招牌）/贡汤（明洞1号）/猪肉汤饭（釜山1号）/辣鸡汤（辣辣汤）/孔纳姆汤（全州汤1号）。外国人（a）看不懂菜单上的字，（b）不知道什么是辣的，（c）不喜欢肉和内脏，或者（d）不知道如何添加或减少调味料。该指南由6种矩阵+外国人优先权+按地区的商店签名组成。

🍲 汤包深入 6 个部分

🩸 圣代汤饭

  • 签名：广藏市场圣代胡同（钟路）/新林洞圣代街（冠岳）/平壤风格（流离失所者）与全罗风格（Gsu）
  • 外国人入境门槛：圣代=血肠（猪血、粉丝、糯米）。 不推荐第一次吃韩国菜
  • 推荐配料：调味酱（dadaegi）+咸虾+紫苏籽粉
  • 加减量：“少辣酱”/“多紫苏子”（多紫苏粉）

🐮 Seolleongtang — 外国人的第一选择

  • 签名：明洞一门雪农堂（1907年韩国#1老字号店）/钟路新宣雪农堂
  • 外国人入门级 ★★★★★：白汤，不辣，加盐/胡椒调味
  • 如何吃：

1. 收到碗后立即加入1茶匙盐+胡椒（未调味）

2.加入葱花+切碎的调味料

3. 附红豆和泡菜（老店免费提供）

4. 米饭卷起来吃或者分开吃

  • 价格锚：12,000~18,000韩元+水煮猪肉选项（15,000韩元~）

🍖 贡汤

  • 签名：Jongno Hadonggwan（1939年韩国#2No-po）/光化门黄生家
  • 与宣陵汤的区别：清汤+浓郁的牛肉味（与宣陵汤白汤相比）
  • 推荐店：河东馆Gomtang=首尔正宗老餐厅，外国爱好者#1老餐厅体验
  • 价格: 13,000~18,000韩元 (水煮猪肉另加10,000韩元)

🐷 猪肉汤包 (Dwaeji-gukbap) — 釜山第一名

  • 特色：札嘎其、富平、西面老店群
  • 小麦风格与釜山风格：
  • 小麦种植 = 清汤、咸虾
  • 釜山风味 = 浓郁的汤汁，韭菜和胡椒调味
  • 推荐店铺：釜山西面和札嘎其老店群（建议提前查看NAVER/Kakao地图了解各个店铺名称——经常搬迁和重新开业）
  • 外国人友善度：★★★★（釜山旅游第一美食，很多英文菜单）
  • 价格：10,000~14,000韩元

🌶 油菜酱

  • 签名：大邱东仁洞集群（从太郎汤饭开始）/光化门孝子洞老餐馆
  • 辣：红辣椒粉+Dadaegi。 推荐给外国人介绍辛辣食物
  • 成分：牛肉、蕨类植物、葱、鸡蛋（正宗韩国葬礼食品）
  • 推荐：炎热的夏天=酷暑/冬天=宿醉
  • 价格: 11,000~16,000韩元

🌱 Kongnamul-gukbap — 全州 Haejang No. 1

  • 签名：全州丰南门老屋（韩国#1全州拌饭集群） — 拌饭指南交叉链接
  • Sambaekjip vs Yeotjip：Sambaekjip = 辣 daaegi / Yeotjip = 咸虾 + 泡菜
  • 外国人友善度：★★★★（性价比+轻盈+解酒效果）
  • 材料：豆芽+鸡蛋（荷包蛋）+咸虾+红辣椒粉
  • 如何吃：

1.荷包蛋打入汤中。

2.加入1茶匙咸虾

3.海藻粉+额外的红辣椒粉

  • 价格：8,000~12,000韩元（全州当地=7,000韩元~）

🍶酒精+米汤搭配（解酒酱的精髓）

汤包饭 搭配酒精 效果
宣陵堂·贡堂 烧酒/药酒 简单配对
猪肉汤 烧酒·啤酒 釜山第一届经典赛
孔纳姆汤包 豆芽汤（不含酒精）没有。 1 次宿醉 第二天宿醉
油菜酱 烧酒（辛辣，舒缓） 麻辣搭配
圣代汤包 烧酒 和平正统

> 韩国模式：第一次烧烤·生鱼片+酒精→第二次→ 豆芽汤解酒·宣陵汤（第二天早上）

⚠ 外国人常犯的5个错误

1. “汤包=全部相似”：6种汤包的成分、口味、地区、店铺都完全不同。 如果您阅读韩语菜单有困难，请使用照片菜单/翻译应用程序。

2. “Seolleongtang = 从头开始​​调味”：Seolleongtang和Gomtang 不加任何调味料。自己添加盐、胡椒粉和切碎的调味料。 （外国人往往觉得鸡肋）

3. “圣代=普通香肠”：圣代=血肠（猪血、粉丝、糯米）。不推荐第一次吃韩国菜，但适合好奇的爱好者。

4. “Kongnamul-gukbap = 结束时的便餐”：解酒食物。全州和光州店使用海藻粉、咸虾和红辣椒粉设置。

5. “Yukgaejang = 各种辣度”：Yukgaejang = 中辣（推荐初学者）。比泡菜炖菜或炒章鱼弱。

⚙ 8 个常见问题解答

1. 没有。外国人的1选：宣陵汤或高汤（白汤/清汤，不辣，正宗贵族）。

2. 没有。 1解酒：豆芽汤（全州）。轻盈+咸虾效果。

3. 辣度简介：Yukgaejang（中辣）。比泡菜炖菜弱。

4. 没有。 1 当地狂热：釜山 = 猪肉汤饭 / 全州 = 豆芽汤饭 / 大邱 = 太郎汤饭 / 明洞 = Seolleongtang。

5. 过敏：牛肉、猪肉、大豆、鸡蛋、咸虾+麸质（大酱油）提前告知。

6. 素食·清真·犹太：素食

7. 付款/小费：可以刷卡/一些老牌商店建议使用现金/无小费文化。

8. 时区：午餐和晚餐价格相同（无折扣）。 宿醉时间为第二天早上 06:00 至 10:00 在历史悠久的 Mania。

⚠ 医疗/安全/饮食免责声明

Gukbap = 热汤（90-100°C）。 小心烫伤（尤其是儿童 - 远离碗，食用前冷却）。孕妇= 注意咸虾和大大吉（豆芽汤和猪肉汤）的盐含量过高。免疫力低=汤煮够就可以了。儿童 = 推荐辣汤（yukgaejang、猪肉汤）或白汤（seolleongtang、gomtang）。过敏（牛肉、猪肉、大豆、鸡蛋、咸虾+麸质）需提前通知。如果怀疑食物中毒，请致电 ☎ 1339（医疗、英语）。本指南是一般信息，并非医疗建议。

饮食限制后备：

  • Halal/Kosher：6种类型中，几乎没有Halal认证的商店。 → 预先搜索梨泰院和江南的一些经过认证的商店。
  • 素食/纯素：豆芽汤和米饭还含有咸虾和鸡蛋。 → [#799 素食/素食](799_Foreigner_Korean_Vegetarian_Matrix_12_selection_deep_dive.md) 或 [#800 寺庙食品](800_Foreigner_Korean_Temple_Food_Authentic_Full_Set_12Selection_deep_dive.md) 单独商店。
  • 无麸质：Dadaegi 和大量酱油（小麦）调味 — 要求“无调味料”或仅白汤。
